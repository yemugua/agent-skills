# 「被贷款」与异常账单的排查处理

征信报告的年度自查、发现陌生贷款记录的核查与异议、冒名贷款的报案与银行交涉、网贷多头借贷的清理。

## 操作路径
1. **征信自查（每年 2 次免费）**：中国人民银行征信中心官网/云闪付 App「信用报告」查询（每年前 2 次免费）；看三类异常——陌生贷款/信用卡账户、查询记录里的陌生机构（「贷款审批」查询=有人在用你名义申贷）、担保记录（被担保）；网贷记录（借呗/微粒贷等都在征信里——别只查银行）。
2. **发现陌生记录的处理阶梯**：①先核对自己（家人代贷/自己忘了的小额网贷——先排除）；②陌生贷款→联系放贷机构（App 客服/网点）要求「冒名贷款核查」（提供身份证+报案回执）；③银行核实为冒名→「征信异议申请」+消除记录（银行有自查义务——通常 15-30 天）；④银行推诿→人民银行金融消费权益保护投诉（12363）+银保监 12378；⑤涉刑事（伪造签名/骗贷）→报案（经济犯罪侦查）——报案回执是所有渠道的通用钥匙。
3. **「被担保」的专项处理**：为陌生人担保的担保记录——查担保合同（签名真伪）；非本人签署→主张合同无效（笔迹鉴定）+征信异议；本人签过的历史担保→担保责任的真实存在（别混淆「忘了」与「被冒名」）。
4. **多头借贷的清理（自陷型）**：自查发现自己 N 个小贷——列清单（平台/余额/利率）；高利率（>24%）优先结清或协商；注销额度（每个 App 的额度注销——防止「再次点借」）；征信「连三累六」前的自我修复（按时还款 2 年覆盖）；以贷养贷的破局（见债务条目——协商路线）。
5. **预防与习惯**：不点不明短信链接（钓鱼 App 盗信息申贷）；身份证复印件注记；「人脸识别贷款」的平台警惕（正规机构才有资质）；每年查 2 次征信+开「账户变动短信提醒」；被冒名贷款起诉自己时——「积极应诉」（缺席判决=默认担责；出庭+笔迹鉴定+报案材料翻盘率高）。

## 避坑红线 ⚠️
- 「征信有记录=必须还」——冒名贷款的核心救济就是「证明非本人+异议消除」，先核实再谈还钱。
- 收到「网贷逾期」电话直接转账——先查征信确认真实性（诈骗话术常伪造逾期）。
- 被起诉冒名贷款不出庭——缺席=败诉+强制执行；应诉是免费的翻盘机会。

## 求助渠道
征信中心（异议申请）；12363（人行消保）/12378（金融监管）；公安经侦（骗贷报案）；法院（应诉+鉴定）；12345。

## 法律效力
《民法典》（冒名合同对本人不生效——表见代理的边界）；《征信业管理条例》（异议 20 日内答复+错误信息删除）；《个人信息保护法》；刑法骗取贷款罪。

## 真实价格
征信自查 0 元（年 2 次）；异议申请 0 元；笔迹鉴定 2000-5000 元；报案 0 元；冒名贷款逾期一年的征信修复=5 年记录期——每年两次自查防的是这 5 年。

## 红线
> ⚠️ 提醒：被贷款的路线图——「先查征信核实→报案拿回执→银行核查+征信异议→推诿就 12363/12378」。被起诉别缺席；冒名的债不是你的债，但证据链要自己建。
