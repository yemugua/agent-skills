# 家暴安全：证据清单·保护令申请·求助路径全套

# 家暴安全全套工具包

一句话：家暴的对抗核心是「人身安全优先 + 证据链 + 人身安全保护令」——三者顺序不能错。本技能给证据清单、保护令申请模板、求助路径，以及「准备离开前」的安全计划。

## 一、人身安全永远第一（离开前的安全计划）

- **安全包**（藏在信任的朋友家/办公室）：身份证、银行卡、现金、常用药品、孩子出生证明、钥匙
- **可去的地方**提前确定：亲友家 / 妇联庇护所 / 反家暴庇护站（民政局/妇联可安排临时庇护）
- **危险信号识别**：施暴者控制钱财/手机、威胁「你敢走试试」、掐脖史（掐脖是致死率最高的前兆）——有掐脖史的家暴，升级风险极高，优先物理隔离
- 紧急时刻：**110 + 说「家暴」关键词**（出警记录本身是证据）；附近便利店/物业求助

## 二、证据清单（每次都存，别挑「严重的」才存）

| 证据 | 操作 |
|---|---|
| 伤情照片 | 每次受伤 24h 内拍（带日期水印 App），全身+特写 |
| 出警记录 | 报警后**必须要**《报警回执》/受案回执——「调解了」的记录也是证据 |
| 告诫书 | 《反家庭暴力法》16 条：可要求公安出具**家庭暴力告诫书**——法院认可度极高 |
| 伤情鉴定 | 24-48h 内验伤（公安委托或自行到司法鉴定机构） |
| 医疗记录 | 病历+诊断证明+缴费单（病历主诉写「被 XX 殴打」而不是「摔伤」） |
| 微信记录 | 威胁、道歉承认的聊天（「我保证再也不打你了」= 自认） |
| 录音录像 | 施暴过程/威胁过程（家里装摄像头合法；自己被殴打时录音合法） |
| 证人 | 邻居/物业/亲目睹者的联系方式 |

**取证心态**：家暴是重复性行为——第一次的告诫书 + 第二次的伤情照 = 模式证据；等「攒够大的那次」再取证的思路，等于放弃保护自己的时机。

## 三、人身安全保护令（免费·72 小时内裁定）

**依据**：《反家庭暴力法》23 条——遭受家暴或**面临现实危险**即可申请，不需要离婚、不需要伤到轻伤。

**申请材料**：
1. 申请书（模板见下）
2. 身份证复印件
3. 证据：出警记录/告诫书/伤情照/医疗记录/聊天记录
4. 居住地址（不需要对方知道你住哪）

**申请书模板**：
> 人身安全保护令申请书
> 申请人：XXX，住 XX（可申请不向被申请人披露）
> 被申请人：XXX，系申请人配偶/前男友
> 请求事项：1. 禁止被申请人殴打、威胁、骚扰、跟踪申请人；2. 禁止被申请人在申请人住所、工作单位 200 米范围内活动；3. 责令被申请人迁出共同住所。
> 事实与理由：X 年 X 月 X 日，被申请人殴打申请人致 XX（附报警记录、照片、病历）。X 年 X 月再次威胁（附聊天记录）。申请人面临现实危险。
> 此致 XX 区人民法院

**结果**：法院 72 小时内裁定（紧急 24h）；有效期 ≤6 个月可续；违反保护令 = 拘留/罚款/刑责。

| 妇联 | 庇护所/法律援助/协调 | 线下/12338 |

| 庇护站 | 临时食宿（带孩子的） | 民政/妇联转介 |
| 人身安全保护令 | 法院 | 直接向居住地/经常居住地法院申请 |

## 五、离婚时的家暴加分项

- 家暴是法定判决离婚情形 + **无过错方可主张损害赔偿**（《民法典》1091 条）
- 家暴证据影响抚养权（施暴者原则上不利于抚养）
- 告诫书/保护令历史 = 财产分割与抚养权的有力筹码

## 红线
> ⚠️ 提醒：家暴的公式——「安全计划先于证据、每次都取证不挑大小、告诫书必须索要、保护令免费 72h 裁定、掐脖史=最高危信号、离婚时家暴=赔偿+抚养权筹码」。家暴只有零次和无数次——但证据可以一次比一次重；你留的每一页记录，都是保护令和赔偿的地基。
