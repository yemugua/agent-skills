# 精装房收房验查清单

精装房交付时的验房重点清单与问题整改流程，交付前必看。

## 操作路径
1. **验房顺序**：先看文件（《住宅质量保证书》《使用说明书》《竣工验收备案表》、面积实测表）→ 再验房 → 问题写入《验房问题交接单》双方签字 → 整改后再收钥匙。
2. **水路**：卫生间闭水试验24-48小时（联系楼下确认）；冷热水位置左热右冷；角阀软管无渗水；地漏泼水排水速度。
3. **电路**：每个插座用相位检测仪（20元）验三线；配电箱分路标识清晰；空开跳闸测试。
4. **墙面地面**：空鼓锤全屋敲（瓷砖空鼓率超标整片返工）；阴阳角垂直度；地板走线异响、起翘；油漆流坠色差。
5. **门窗**：进户门锁具灵活、防撞条；窗户密封胶条完整、开合顺畅、打胶无断点；中空玻璃内无水汽（有=失效）。
6. **整改**：开发商保修期通常2年，交付问题清单注明整改时限；拒不整改的留存证据（拍照+函件），影响收房造成的物业费争议以实际交付日计算。

## 避坑红线 ⚠️
- 「先签字收钥匙再看房」=放弃议价筹码，顺序绝不能反。
- 精装房最常翻车的是隐蔽工艺（防水、隔音棉），交付后无法查，验房时尽量要求看阳台/卫生间顶部结构。
- 面积误差超3%可主张多退少不补（司法解释），实测表必须留。

## 维权阶梯
验房问题单 → 开发商整改 → 住建质监站投诉 → 民事诉讼。

## 法律效力
《商品房买卖合同（预售）》附件约定的装修标准是索赔依据（样板间/宣传册可作为标准证据，最高法已有判例支持）；交付条件=竣工验收备案+合同约定，二者缺一可拒收。

## 真实价格
专业验房师300-800元/套（100㎡内）；相位检测仪20-50元；空鼓锤10-30元。

## 红线
> ⚠️ 提醒：精装房验房最佳时机是同楼栋早收房业主反馈后——前人踩过的坑清单直接拿来用。
