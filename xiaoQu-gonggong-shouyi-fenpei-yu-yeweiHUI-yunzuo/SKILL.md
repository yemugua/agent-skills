# 小区公共收益核查与业委会运作

一句话：电梯广告、停车费、快递柜进场费——这些钱属于全体业主，多数小区从未公示过。本技能给公共收益的追查清单 + 业委会成立的步骤 + 业主大会的表决规则。

## 一、小区的公共收益有哪些（先知道该查什么）

| 收益项 | 典型规模（中型小区/年） |
|---|---|
| 电梯广告（框架+视频屏） | 2-10 万 |
| 公共车位/地面停车费 | 10-50 万 |
| 快递柜/自动售货机进场费 | 0.5-3 万 |
| 外墙/道闸广告 | 1-5 万 |
| 通信基站场地费 | 1-5 万 |
| 公共区域租赁（便民摊位） | 0.5-2 万 |

**一个中型小区年公共收益 15-70 万**——归全体业主所有（《民法典》282 条），可用于抵物业费/补充维修基金/按户分配。**从未见过公示？大概率被物业收进了自己的口袋。**

## 二、追查路径（业委会缺位时业主个人的打法）

1. **书面要求公示**（《民法典》943 条：物业必须公开公共收益收支）——微信+纸质给物业，限期 7 日
2. **拒不公示**：住建部门物业科投诉（公示是法定义务）+ 12345
3. **起诉要求公开**：单个业主即可起诉（知情权诉讼，有大量胜诉判例）——不需要业委会
4. **拿到数据后**：收益去向审计 → 不当挪用的可要求返还 + 追责

**向物业要的清单**：
- 电梯/道闸广告合同（与广告商签的）
- 停车收费系统流水
- 快递柜协议与到账记录
- 公共收益专户对账单（应有独立账户）

## 三、业委会成立全流程（从 0 到 1）

```
1. 筹备：5% 以上业主联名 → 向街道/乡镇提出成立申请
2. 筹备组：街道指导+业主代表组成（筹备组公示）
3. 草拟《管理规约》《议事规则》
4. 业主大会选举：双过半（面积过半+人数过半参与）选出业委会委员（5-11 人）
5. 备案：30 日内向街道/房管部门备案（取得合法身份——银行开户/起诉都需要）
6. 换届与监督：任期 3-5 年，业主大会有权罢免
```

**筹备的实战经验**：
- 先建楼栋群网络（每栋 1 个联络人）——表决与联名的组织基础
- 第一议题选「公共收益公示」（共识最大、阻力最小）——用小胜建立信任
- 核心成员选「有时间+懂财务/法律/工程」的组合
- 遭遇物业阻力：向街道施压（物业对街道有考核关系）

## 四、业委会的核心武器（成立后干什么）

1. **审计物业账目**：委托第三方审计（公共收益+物业费收支）
2. **物业选聘/续聘表决**：到期合同重新招标——竞争性选聘直接压价提质
3. **公共收益自管**：收益转入业委会专户，公示使用
4. **维修基金动用决策**：电梯/外立面大修的业主大会表决主导
5. **对物业的监督合同**：服务标准量化（保洁频次/保安岗数）+ 考核挂钩付款

## 五、业主大会的表决规则速查

| 事项 | 表决要求（民法典 278 条） |
|---|---|
| 一般事项（选物业/审议收益） | 双过半参与 + 参与者过半同意 |
| 重大事项（维修基金使用/改建/物业费调整） | 双 2/3 参与 + 参与者过半同意 |
| 线上表决 | 多数城市有电子投票平台（政务 APP/微信小程序）——**降低双 2/3 达成难度的关键工具** |

## 六、真实案例

> 案例：某小区业主起诉物业要求公示公共收益（个人起诉，知情权）。
> 判决：物业 15 日内公示近 3 年收支 → 查出电梯广告年收入 6.8 万未入公共账户 → 业委会筹备组以此为议题 → 当选后物业合同重签，公共收益入专户，年度按户抵扣物业费 200 元。
> 起点成本：一份起诉状 + 50 元诉讼费。

## 红线
> ⚠️ 提醒：公共收益的公式——「收益归全体业主是民法典明文、个人可起诉要求公示、业委会从『公示收益』议题起步、电子表决破解双 2/3、审计+选聘是两大武器、电梯广告费先查再说」。小区的钱不是物业的钱——民法典站在你这边，缺的只是有人推开公示那扇门；推开它的人，就是业委会的种子。
