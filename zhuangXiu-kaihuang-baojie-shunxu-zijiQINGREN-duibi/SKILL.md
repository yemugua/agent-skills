# 装修开荒保洁

一句话：开荒保洁的顺序错了=「擦完地又扬灰」白干一遍——「从上到下、从里到外、先干后湿」是铁律；请人（500-1,500）与 DIY 的差价要算上「两天腰」。本技能给标准顺序 + 分区清单 + DIY/请人决策。

## 一、开荒保洁的标准顺序（铁律）

**总原则：从上到下（先擦顶后扫地）、由内向外（先擦屋内最后门口）、先干后湿（先吸尘擦灰再拖水）**

1. **废弃物清运**：保护膜/纸箱/多余材料清场（快递员都进不来的工地没法扫）
2. **全屋吸尘/干扫**：天花→墙面→窗框→家具表面→地面（**粉尘先吸后擦**——湿擦干灰=泥浆涂墙）
3. **从上到下擦**：灯具/吊顶/柜顶→墙面污渍→门窗玻璃（**玻璃是重头**：水泥点/涂料点用铲刀+清洁剂——先湿敷软化再铲，硬铲=划玻璃）
4. **柜体内外**：定制柜内部擦净（**柜内粉尘=衣物进柜的隐患**——衣柜内侧最后检查）
5. **厨卫深度**：瓷砖面水泥渍/美缝残料/五金保护膜撕净（水龙头保护膜撕完=撕开新家的感觉）
6. **地面最后**：吸尘→拖地→（木地板养护）
7. **收尾检查**：排水试水/开关测试/门窗开合（保洁过程顺手验收——发现问题趁保洁队还在）

## 二、分区域重点清单（开荒的脏点地图）

| 区域 | 重头脏点 | 工具 |
|---|---|---|
| 玻璃门窗 | 水泥点/涂料点/贴膜残胶 | 铲刀+玻璃清洁剂+双面擦 |
| 定制柜 | 柜内粉尘/保护膜残胶/铰链灰 | 吸尘器+酒精擦胶 |
| 厨房 | 瓷砖水泥渍/台面涂料点/下水口杂物 | 除水泥剂+铲刀 |
| 卫生间 | 水泥点/硅胶残留/五金保护膜 | 除水泥剂+美工刀 |
| 地面 | 涂料点/胶点/水泥疙瘩 | 铲刀+除胶剂（**先除点后拖地**） |
| 灯具吊顶 | 粉尘/指纹 | 梯子+干布（**断电操作**） |

**除水泥渍的技巧**：专用除水泥剂（10-20 元）湿敷 5 分钟软化→铲刀平推——**硬铲瓷砖=釉面划伤**（不可逆）。

## 三、DIY vs 请人的决策账

- **请人行情**：100㎡ 开荒 500-1,500 元（按面积 5-15 元/㎡）——**选「按面积报价」的正规队**（按小时/人头报价的模糊空间大）
- **DIY 成本**：工具 200 元（伸缩杆/铲刀/玻璃刮/清洁剂）+两天体力+4 天腰痛
- **决策**：面积 >90㎡ 或有高空/外窗保洁 → 请人（性价比+安全）；小户型/体力好 → DIY 可行
- **混合方案（性价比之王）**：请人做「玻璃+高空+厨卫重脏区」，自己收尾地面与柜内——省 40%
- 请人的验收：玻璃无划痕（**划痕是保洁队铲玻璃的最常见事故——验收时逆光看**）/瓷砖釉面完好/五金无划/柜内干净

## 四、时机与后续（开荒不是终点）

- 时机：全屋安装完工后（灯具/柜/门都装完）+家具进场前——**家具进场前的最后窗口**
- 完工通风：保洁后开始正式通风散味（参考甲醛技能——保洁先于通风，否则灰尘锁进漆膜）
- 精保洁概念：入住前再做一次「入住保洁」（家具进场后轻清洁——开荒+入住两段是行业惯例）
- 日常保洁的起步：入住后前两周勤擦（装修灰残留会持续落——**前两周的勤快省后面一个月**）

## 五、工具清单（DIY 版 200 元）

- [ ] 伸缩杆+平板拖头（天花板/高墙）
- [ ] 双面玻璃擦/玻璃刮
- [ ] 铲刀+除水泥剂+除胶剂
- [ ] 吸尘器（家用即可）
- [ ] 微纤维抹布 ×10（分色分区：玻璃/瓷砖/家具）
- [ ] 梯子+手套+口罩（粉尘防护——**口罩是必配**：装修粉尘伤肺）

## 六、真实对照

> 案例 A：120㎡ 请人开荒 800 元（一天完成全屋+玻璃）——自己两天搞定不了玻璃的高层外窗；DIY 省的钱=买安全绳的胆子没有。
> 案例 B：自己开荒顺序错——先拖地后擦墙，粉尘落满拖好的地板，重做一遍（**顺序就是效率**）。
> 开荒的公式：**从上到下由内向外先干后湿、玻璃湿敷软化再铲、柜内粉尘是隐患、家具进场前是最后窗口、DIY 算上腰、混合方案省 40%、验收逆光看玻璃划痕**——开荒保洁是装修的最后一公里；顺序对了，两天顶五天。

## 红线
> ⚠️ 提醒：开荒保洁的公式——「先吸尘后湿擦、玻璃先湿敷后铲刀、断电擦灯、柜内是重灾区、验收逆光看划痕、高空外包给专业、家具进场前完成、保洁后才开始通风」。开荒是「把工地变成家」的仪式——顺序就是全部技术。
