# 节后返工首日与请假衔接

一句话点题：春节假期结束，先算清调休哪天上班、再办返工交接和剩余年假——三件事一天内搞定，避免节后被动。

## 一、工具表：调休规则速查

| 情形 | 规则 |
|---|---|
| 法定节假日（初一到初三等） | 3倍工资，不得用调休替代 |
| 调休凑假挪用的休息日 | 2倍工资或补休 |
| 节后周末上班 | 属补班，之后应安排补休或2倍工资 |
| 未休年假离职 | 按300%折算（含正常工资部分） |

## 二、返工首日交接清单

1. 查看节前待办清单/邮件未读（先回最紧急3件，其余当天分批处理）。
2. 与直属领导10分钟对齐：节前遗留事项、本周优先级、需他人配合项。
3. 客户/合作方通知：节前挂的"假期后回复"事务逐一闭环。
4. 考勤自查：调休/补班日打卡是否正确，HR系统核对。

## 三、精确算例

- 调休算例：某年春节休7天（含挪用1个周六+1个周日补班）。小王节后想连休3天拼后半程假期，他年假余额10天，用3天年假+周末即可连休5天，剩余年假7天。提醒：年假通常当年有效、部分公司允许跨年（最多1年），先查公司手册。
- 年假余额查询路径：企业微信/OA「假期余额」入口 → 或问HR → 按工龄算：工龄1-10年=5天/年，10-20年=10天，20年+=15天。
- 请假话术："领导，我节前XX项目已交付，节后前三天可安排在家响应紧急事项，申请X月X日-X日休年假3天，交接给XX同事，交接文档已挂共享目录。"

## 四、可复制话术/模板

- 节后返工首日给领导的状态汇报："领导，假期值班事项已处理完毕，节前遗留2件事今天闭环，本周计划如下：……"
- 节后综合征缓解模板：返工第一天只排上午半天核心任务，下午整理归档，避免一上来满负荷。
- 加班补偿申请："节后补班当日按休息日加班，申请2月X日补休一天。"

## 红线

> ⚠️ 提醒：法定节假日的3倍工资不能被"调休"冲抵——公司用补休替代初一到初三加班费属违法，可先与HR沟通、无效则向当地劳动监察（12333）投诉；年假书面申请留痕，口头批准易引发争议；返工首日不到岗且未请假按旷工处理，可能触发解除条款，务必提前报备。
