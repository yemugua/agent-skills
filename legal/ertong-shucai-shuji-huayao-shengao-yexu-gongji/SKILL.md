物业不作为的最有力武器是依法成立业委会，先算清表决门槛再动手。

## 一、成立业委会时间线（民法典第277-278条 + 各地物业管理条例）

| 阶段 | 动作 | 法定时限参考 |
|---|---|---|
| 1. 申请 | 5%以上业主书面申请街道办/乡镇政府组建筹备组 | 街道30日内书面答复 |
| 2. 筹备组 | 街道牵头，业主代表≥50%，名单公示 | 公示7日 |
| 3. 草拟文件 | 管理规约、议事规则、委员候选人 | 筹备期≤90日（各地常见） |
| 4. 业主大会 | 书面/APP表决 | 会前15日公告议题 |
| 5. 备案 | 选举结果报街道+区住建局备案 | 备案后刻章开户 |

## 二、表决比例公式与算例

**一般事项**：双过半——专有面积过半数且人数过半数参与，参与人中面积过半+人数过半同意。
**重大事项**（选聘解聘物业、使用维修资金等）：参与面积≥2/3 且参与人数≥2/3，同意票占参与面积和人数的过半。

算例：小区1000户、总面积10万㎡。
- 解聘物业（重大事项）：需≥667户且≥6.67万㎡参与表决；若700户/7.2万㎡参与，同意需≥351户且≥3.61万㎡。**实操**：动员目标是先凑700户参与，再锁351户同意，倒推需建楼栋群逐楼扫楼，纯靠业主群转发参与率通常只有 30-40%，失败主因。
- 公共收益不公示（一般事项维权）：双过半即可决议要求物业公示账目并移交。

## 三、常见维权阶梯

1. 物业费质疑：书面要求公示收费依据与公共收益账目（留快递/拍照证据）
2. 街道办物管科投诉（各地12345转办，15日内答复）
3. 双过半决议解聘物业 → 招标新物业
4. 诉讼：业委会备案后具原告资格，可诉物业返还公共收益（历史判例追偿期常见3年，年公共收益利息/广告费按小区规模数万至数十万不等）

## 四、可复制模板

```
关于组建业主大会筹备组的申请书
XX街道办事处：
XX小区（XX路XX号）共X户，建成于X年，已交付满X年，入住率达X%。依据《民法典》第277条及《XX市物业管理条例》，我们（联署业主名单及房产证号附后，共X户，占5%以上）申请贵办组建业主大会筹备组。
联署代表：XXX 电话XXX  日期：
```

## 红线

> ⚠️ 提醒：业主大会决议按「面积+人数」双口径计票，只凑人数不核面积会决议无效；维权留痕（书面函件用EMS并注明文件名）；不要以拒缴物业费对抗——单个业主拒缴必败诉且承担违约金，正确路径是大会决议与诉讼。
