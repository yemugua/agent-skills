正规领养的核心文件是领养协议，签之前把费用和回访条款算清楚，避免领养变纠纷。

## 一、领养全流程与办理算例

| 步骤 | 内容 | 常见费用 |
|---|---|---|
| 1. 选源 | 救助站/流浪动物保护组织/医院待领养 | 免费 |
| 2. 资质审核 | 身份证+居住稳定性+家人同意 | 免费 |
| 3. 签领养协议 | 权利义务、回访、绝育条款 | 免费（个别收押金100-300元，绝育后退还） |
| 4. 接猫犬当月体检 | 体内外驱虫+疫苗基础免疫 | 200-400元 |
| 5. 绝育（6月龄后） | 犬400-1000元/猫300-600元 | 母比公贵约200元 |
| 6. 办犬证（犬类） | 公安/城管登记 | 首年300-500元（各地不同），年审100-200元 |

**首年总成本算例**（领养一只猫）：免费领养 + 押金200（绝育后退）+ 疫苗驱虫300 + 绝育400 + 粮 litter 首年约1500 ≈ **2200-2400元**。对比购买：品种猫3000-8000元 + 同样医疗支出 → 领养省下购宠款，但医疗预算必须照出，「免费领养=零成本」是最大误区。

## 二、领养协议必备条款（缺一条都易起纠纷）

1. 双方身份信息+动物特征（花色/芯片号/照片）
2. 回访条款：领养后1个月内1-2次视频/上门回访（可接受的回访≠骚扰，超出可拒绝）
3. 绝育时限：通常领养后X个月内完成，未绝育押金不退
4. 不得转卖/遗弃：违约回购条款+违约金（常见1000-5000元）
5. 医疗与死亡告知义务
6. 退养机制：无法继续饲养归还救助方而非二次送人

## 三、可复制领养协议模板（要点版）

```
宠物领养协议
甲方（送养人）：___ 乙方（领养人）：___
动物信息：___（品种/花色/年龄/芯片号）
1. 乙方无偿领养，不得转卖、转让、遗弃；违约支付违约金___元并归还动物。
2. 乙方同意于领养后___个月内完成绝育；甲方可在领养后1个月内回访___次（提前1天约定）。
3. 乙方保证科学饲养（疫苗、驱虫、不散养）；无法继续饲养时归还甲方。
4. 犬只领养：乙方于___日内办理犬只登记。
甲方签字：___ 乙方签字：___ 日期：___
```

## 四、避坑表

| 坑 | 对策 |
|---|---|---|
| 「免费领养」实为强绑月供粮卡（含2000-5000元分期） | 见协议外任何付费分期条款直接走人 |
| 无协议只口头约定 | 回访/回购无依据，必须签书面协议 |
| 借「回访」骚扰上门 | 协议写明次数与提前约定，超范围拒绝 |
| 领养犬不办犬证 | 被查处没收+罚款（各地500-5000元） |
| 幼龄未打疫苗直接接走 | 细小/猫瘟风险高，接走即安排疫苗 |

## 红线

> ⚠️ 提醒：拒绝一切「免费领养但必须买粮/分期」变相销售；领养协议必须书面签署，口头承诺维权无据；犬只领养后按当地规定时限办证，无证饲养是没收风险最高的违规；回访以协议约定为限，双方的边界都写在纸上而不是靠情面。
