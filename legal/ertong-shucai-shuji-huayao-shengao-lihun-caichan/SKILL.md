离婚分财产先分"哪些是共同财产"，再谈"怎么分"——判错性质，一半家产就走错方向。一句话点题：**婚前全款房是个人财产，婚后共同还贷部分及对应增值要补偿对方。**

## 财产性质速判表

| 财产 | 判定 | 分割方式 |
|---|---|---|
| 婚前全款房 | 个人财产 | 不分；婚后共同还贷部分+对应增值补偿对方 |
| 婚后共同买房 | 共同财产 | 原则均分，照顾子女/女方/无过错方可倾斜 |
| 婚前房产婚后出售换新房 | 大概率共同财产（资金混同） | 均分 |
| 婚后工资/奖金/公积金 | 共同财产 | 均分（公积金余额也是！） |
| 婚前存款 | 个人财产（未混同） | 不分；混同后举证困难 |
| 人身损害赔偿/保险理赔金 | 个人财产 | 不分 |

## 核心算例

**① 房产补偿**：婚前一方购房100万，婚内共同还贷60万（本金30万+利息30万），离婚时房价300万。补偿公式=共同还贷本息÷购房成本×现价÷2=60÷100×300÷2=**90万**补偿对方。
**② 公积金**：婚内一方公积金账户余额48万（其中婚前缴存8万）→共同部分40万，对方分得20万。
**③ 隐匿转移少分**：离婚前一年对方转出60万给其弟（无合理用途），法院可判该60万仍按共同财产分割且对方**少分**——实操中常判对方分得35-40%：60万×0.6=36万归你，相当于多拿6万。

## 取证清单（离婚前提早做）

1. 银行流水：本人+对方卡号（工资卡流水在离婚诉讼中可申请法院调取，自己先存日常对账单截图）。
2. 不动产登记查询：线下带身份证打印本人名下清单；对方名下需律师凭立案后调查令。
3. 支付宝/微信年度账单：APP内导出，含大额转账对象。
4. 对方收入证明：个税APP「收入纳税明细」可查本人；对方的靠银行流水+社保缴费基数倒推。

## 可复制分割清单模板

```
财产名称｜登记/开户人｜取得时间｜现值评估｜主张比例｜证据编号
XX房产   ｜双方      ｜2020.6  ｜300万   ｜各50%   ｜证1
公积金    ｜对方      ｜累计     ｜48万    ｜各50%   ｜证2
 suspect转账｜对方→其弟｜2025.8  ｜60万    ｜追回+少分｜证3
```

## 红线
- 签"净身出户"协议前逐条核对财产清单，漏列的房产/股权签完也难翻案。
- 自己转移财产同样适用少分条款——情绪性转钱给父母"保管"会被对方反诉。
> ⚠️ 提醒：隐匿转移的追诉不限于离婚时——离婚后发现的，发现之日起3年内可请求再次分割，所以流水证据无论如何先存档。
