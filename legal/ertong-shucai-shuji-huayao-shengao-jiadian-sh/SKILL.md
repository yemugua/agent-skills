# 家电维修套路与配件欺诈：举证清单+投诉模板，一次反杀

一句话点题：维修欺诈的胜负手在证据——师傅动手前你没拍照、没留工单，事后投诉基本靠口说；按本文清单取证，能追回虚报金额甚至主张三倍赔偿。

## 六大套路与对应证据动作

| 套路 | 典型话术 | 现场应对（动手前） |
|---|---|---|
| 小病大修 | "主板烧了，要换板600元" | 要求当面检测并拍检测仪读数；多报2家对比 |
| 以换代修 | "整体换总成800元" | 问"单独换这个件多少钱？"配件+人工拆分报价 |
| 虚报配件原装 | "原装件，市面没有" | 要求配件带包装/防伪码拍照，索要购买凭证 |
| 旧件充新 | 换下的"旧件"其实是好的 | 动手前先拍故障件；换下旧件带走留存 |
| 加氟按压计价 | "补5个压，一个压80" | 坚持按公斤/按台计价，拍压力表 |
| 检测费陷阱 | "上门检测100，不修也收" | 事前谈定：检测费修后折抵，不修只收30-60 |

## 取证清单（动手前5分钟做完）

1. 拍：机器铭牌（型号+序列号）、故障现象（报错代码/不亮/漏水）、师傅的检测仪表读数。
2. 录：师傅口头报价+保修承诺的对话录音（手机即可，自己参与的对话录音合法可用）。
3. 写：微信文字确认"换XX配件，总价X元含人工，保6个月，换下旧件归我"——对方回复"好的"即合同证据。
4. 留：维修工单/收据要写明配件名称、数量、保修期；收好旧件。
5. 查：配件型号上网比价，原装件市面价一查便知。

## 维权阶梯（按成本从低到高）

1. 平台投诉：通过58/美团/京东服务下单的，直接平台投诉，通常48小时内退款调解，最省力。
2. 商家协商：出示照片+录音+工单，主张虚报部分退款。话术："配件网上零售价X元，你收我X元且未事先告知价格，要求退还差价并按承诺保修。"
3. 12315：电话或全国12315平台（微信小程序即可），提交：订单/收据照片、报价聊天记录、配件比价截图。投诉模板：
   > "本人X月X日在XX维修服务报修空调（型号XX），经营者未事先明示价格，更换配件收费X元，市面同型号配件零售价X元，涉嫌价格欺诈。依据《消费者权益保护法》第五十五条，请求：退还多收费用；如查实欺诈，主张三倍赔偿。附：聊天记录、工单、比价截图。"
4. 虚构故障+虚高收费金额大、有组织（维修黑作坊），向12315举报移交市场监管查处。

## 红线

> ⚠️ 提醒：①所有取证必须在师傅动手前完成，动手后现场由对方控制，取证窗口一过就难补；②"原装配件"要求出示包装防伪码并拍照，口头声称无效；③录音仅限自己参与的对话，偷录他人私密场合不可用；④金额<200元的小额纠纷走平台投诉即可，12315调解也有受理时效（7个工作日内答复），别为50元耗两周；⑤任何"先付全款再修"的陌生上门维修直接拒绝，正规流程是修好验收后付款。
