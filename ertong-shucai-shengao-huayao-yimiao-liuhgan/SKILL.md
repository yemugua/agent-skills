流感对全家不是同一风险：65岁以上老人和5岁以下儿童的重症率是青壮年的数倍。本文给优先级排序、疫苗时机表、家庭隔离规则和用药边界。

## 一、全家防护优先级（资源有限时先保谁）

| 优先级 | 人群 | 理由 | 动作 |
|---|---|---|---|
| 1 | 家中65岁以上老人 + 慢病者（心肺/糖尿病） | 重症与死亡率最高 | 第一时间接种；家中有人感染立即物理分开 |
| 2 | 6月龄-5岁儿童 | 重症风险高，且是家庭内主要传播源 | 接种；幼儿园疫情期强化手卫生 |
| 3 | 孕妇（任何孕周） | 重症风险高且疫苗对胎儿有保护 | 孕期可接种灭活流感疫苗（这是明确推荐） |
| 4 | 家庭青壮年 | 通常轻症 | 接种主要为切断传给1-3的链条 |
| 不接种 | <6月龄婴儿 | 疫苗无效 | 靠「全家都打」形成包围保护 |

## 二、疫苗时机表（含金额）

| 事项 | 规则 |
|---|---|
| 最佳接种窗口 | 9-11月，流感季来临前2-4周完成 |
| 现在还没打怎么办 | 整个流感季（至次年3月）任何时候打都有价值，别等「明年」 |
| 三价/四价 | 四价多覆盖乙型系别，社区接种点约128-168元/针；三价约几十元 |
| 儿童首针 | 6月龄-8岁首次接种需2针间隔≥4周；以前打过只需1针 |
| 每年都要打 | 流感病毒株每年变化，去年打过今年仍需 |
| 在哪打 | 社区卫生服务中心接种门诊；部分城市可用医保个人账户支付 |

**算例**：一家4口（老人×2、成人×2）四价疫苗168元/针 = 672元，医保个账可覆盖大部分。一次儿童流感住院自付通常2000-5000元——全家接种是最划算的一笔健康支出。

## 三、家里有人中招：隔离与消毒规则

| 规则 | 内容 |
|---|---|
| 隔离天数 | 成人退热后继续居家至症状消失后24小时（通常全程5-7天）；儿童/学生按学校要求一般热退后48小时返校 |
| 房间安排 | 单独房间+单独卫生间（做不到则分时使用并随时擦手接触面）；患者戴口罩 |
| 照护者 | 固定1人（最好是打过疫苗的青壮年），接触时戴医用外科口罩，接触后洗手 |
| 消毒重点 | 门把手/马桶按钮/手机/玩具——含氯消毒液（84按说明稀释）擦拭，每日1次；餐具煮沸或洗碗机高温 |
| 通风 | 每天开窗2-3次每次30分钟；**酒精喷雾对流感病毒意义有限，飞沫传播靠通风+距离** |
| 洗衣 | 患者衣物被褥正常洗即可，56℃以上热水更好，无需丢弃 |

## 四、用药边界（48小时是关键线）

- **奥司他韦/玛巴洛沙韦**：越早用越好，**48小时内启动**显著缩短病程、降低重症率；超过48小时仍有高热不退/肺炎表现时仍有价值，但轻症过了48小时不必为了「补救」而吃。
- 处方药，需医生开具；适合：确诊/高度疑似流感 + 重症高危人群（老人、儿童、孕妇、慢病者）或症状重的青壮年。
- 算例：社区医院奥司他韦颗粒5天量约30-60元；比一次住院自付数千元便宜两个数量级。高危人群接触过确诊流感患者后，可请医生评估「暴露后预防」（75mg×1次/日×7-10天）。
- **普通感冒药（对乙酰氨基酚/布洛芬）只退热不抗病毒**，别叠加多种复方感冒药——对乙酰氨基酚每日总量不超2g（肝损伤线）。
- **不要给儿童用阿司匹林**（瑞氏综合征风险）。

## 五、就医红色信号（出现任一立即去）

| 人群 | 信号 |
|---|---|
| 成人 | 呼吸困难/胸痛/持续高热3天不退/意识模糊/严重呕吐脱水 |
| 儿童 | 呼吸急促费力、口唇发紫、精神差到不玩不说话、抽搐、尿量明显减少、发热伴皮疹 |
| 老人 | 上述任一 + 不吃不喝一天以上、原本慢病指标突然恶化 |

## 红线
> ⚠️ 提醒：疫苗禁忌以接种点医生现场评估为准（对疫苗成分严重过敏者不接种；鸡蛋过敏者按现行指南多数可正常接种，告知医生即可）。抗病毒药必须凭处方由医生决定，本文只提供「该不该尽快去问医生」的判断线，不构成用药指导；家庭消毒勿将84消毒液与洁厕灵混用（产生氯气），也勿以消毒液代替洗手。
