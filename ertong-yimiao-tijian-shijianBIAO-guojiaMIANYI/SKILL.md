# 儿童疫苗与体检时间表

一句话：0-6 岁的疫苗和体检都有法定时间表——漏种影响入园入学，体检漏项错过发育干预窗口。本技能给国家免疫规划对照表 + 自费疫苗选择逻辑 + 体检的关键节点。

## 一、国家免疫规划疫苗时间表（免费必打）

| 月龄 | 疫苗 | 预防 |
|---|---|---|
| 出生 | 乙肝①+卡介苗 | 乙肝/结核 |
| 1 月 | 乙肝② | |
| 2 月 | 脊灰① | 小儿麻痹 |
| 3 月 | 脊灰②+百白破① | |
| 4 月 | 脊灰③+百白破② | |
| 5 月 | 百白破③ | |
| 6 月 | 乙肝③+流脑A① | |
| 8 月 | 麻腮风①+乙脑①（减毒） | |
| 9 月 | 流脑A② | |
| 18 月 | 百白破加强+麻腮风②+甲肝①+乙脑② | |
| 2 岁 | 乙脑（若未完成） | |
| 3 岁 | 流脑A+C① | |
| 4 岁 | 脊灰加强 | |
| 6 岁 | 白破加强+流脑A+C②+（部分地区）乙脑加强 | |

**接种纪律**：
- 多针可同日不同部位（衔接期漏种的补种方案由接种点排）
- 漏种不慌：**补种即可**（入园前补齐是常见操作）——接种证每次随身
- 发热/急性病期缓种；轻微感冒流涕不影响（以接种点评估为准）

## 二、自费疫苗的选择逻辑（花钱的优先级）

| 疫苗 | 建议 | 理由 |
|---|---|---|
| 五联（替代脊灰+百白破+hib） | **强烈推荐** | 一针顶三针=少挨 8 针；约 600-800/针×4 |
| 手足口（EV71） | 推荐 | 重症手足口由 EV71 引起 |
| 水痘 | 推荐 | 传染性强；部分已入免规 |
| 流感（6 月龄+） | 每年推荐 | 幼儿重症流感风险 |
| 13 价肺炎 | 推荐（婴幼儿） | 2/4/6 月+12-15 月；进口国产均有 |
| 轮状（口服） | 推荐 | 婴幼儿秋季腹泻 |
| 甲肝灭活/乙肝加强 | 按情况 | |

**自费疫苗不是「可选的坑」**——是免规的补充；预算优先级：五联 > 13 价肺炎 > 手足口 > 流感。

## 三、体检时间表（关键节点）

| 年龄 | 关键体检 | 查什么 |
|---|---|---|
| 新生儿 | 足跟血+听力筛查（出生医院） | 先天代谢病/听力 |
| 满 1/3/6/8 月 | 社区儿保体检（免费） | 身高体重曲线/运动发育/髋关节 |
| 1 岁 | 走稳/叫人检查 | 发育里程碑 |
| 1.5-2 岁 | **语言发育关键评估** | 2 岁不开口说话的干预窗口 |
| 2-3 岁 | 视力初筛/龋齿 | 3 岁前是视力发育敏感期 |
| 入园前 | 幼儿园入园体检 | 必备材料 |
| 每年 | 身高体重曲线+视力+龋齿 | 曲线偏离同龄 P3/P97 → 就诊 |

**发育预警线**（超过了就去儿保科）：
- 3 月不抬头 / 6 月不会翻身 / 9 月不会独坐 / 12 月不会扶站 / 18 月不会走 / 2 岁无意义音节少 / 3 岁不成句
- 「贵人语迟」是最大的延误借口——2 岁的语言评估是性价比最高的干预窗口

## 四、接种证与档案管理

- 《预防接种证》= 入园入学必备（丢了凭出生记录到接种点补办）
- 电子档案：各地「预防接种服务」APP/小程序——补种计划自动排
- 每次接种后核对：疫苗批号/下次接种时间写进手机日历
- 入园前 2 个月查漏补种（接种点出「补种单」照单完成）

## 五、接种后的正常反应与异常信号

- **正常**：接种 24-48h 内低热（<38.5）/局部红肿硬结/哭闹烦躁——多喝水+观察
- **处理**：硬结可温敷（卡介苗除外——脓肿化是正常过程勿处理）
- **就医信号**：高热 >39 / 热性惊厥 / 精神萎靡持续 / 局部化脓异常扩大
- 「接种后发烧是疫苗失效」的说法错误——反应与效果无关

## 六、真实提醒

> 案例：2 岁 3 月仍只会叫爸妈，家人说「贵人语迟」。儿保评估为语言发育迟缓 → 早期语言干预 3 个月 → 词汇量追赶至同龄。
> 医生的原话：「家长口中的『再等等』，是我们最想纠正的三个字——2 岁的评估不花几个钱，但 4 岁再来的干预成本和效果完全是两个世界。」

## 红线
> ⚠️ 提醒：儿童健康的公式——「免规时间表照单打、自费优先五联和肺炎、发育预警线背下来、2 岁语言评估是黄金窗口、接种证入园必备、漏种补种即可别焦虑」。疫苗表是国家的科学；体检表是发育的雷达——两张表贴在冰箱上，就是 0-6 岁的育儿主干。
