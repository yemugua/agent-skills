# 地址解析与标准化

## 触发场景
当用户的需求涉及：清洗；解析分级；地理编码；质检 时使用本技能。

### Step 1 · 清洗
去噪（全半角、错别字常见表）、补全省市区、统一行政区划名（最新区划对照表）。

### Step 2 · 解析分级
正则+词典拆出省/市/区/街道/详址；无法解析的归人工队列。

### Step 3 · 地理编码
批量调 Nominatim/高德 API 取经纬度，注意限流与缓存；输出置信度。

### Step 4 · 质检
抽样比对与误差分级，低置信度标记复核。

## 红线
- 遵守地图 API 限流与条款，禁止爬取
- 低置信度结果必须标记，不得混入高置信输出
