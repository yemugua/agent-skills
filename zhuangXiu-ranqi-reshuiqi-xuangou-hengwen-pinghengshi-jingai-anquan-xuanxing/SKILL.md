# 燃气热水器选购

一句话：燃气热水器的核心矛盾=「**升数（热水量）+安全（排气方式）+恒温（体验）**」——升数选小了冬天洗澡冰凉，排气方式选错了是安全大事；价格差主要在恒温技术与风机。本技能给升数公式 + 类型对比 + 安全要点 + 选购清单。

## 一、升数公式（热水量的账）

- 升数=每分钟升温 25℃ 的出水量（13L=每分钟 13L 温升 25℃ 的热水）
- **需求公式**：一个淋浴点 13L/一个淋浴+厨房同时 16L/大浴缸或两卫 16L+
- **冬季折扣**：北方/冬季进水 5℃ 时实际出力打折（**标 16L 冬季实感 11L——升数往上报一档**是实践共识）
- 与花洒联动：大顶喷/恒温花洒=更高流量需求（**先定花洒再定升数**）

| 场景 | 推荐升数 |
|---|---|
| 一厨一卫·单淋浴（南方） | 13L |
| 一厨一卫·冬季进水低温 | 16L |
| 一厨两卫/大花洒/浴缸 | 16-20L |
| 两卫同时用 | 20L+ 或考虑双机 |

## 二、类型与排气方式（安全的第一位）

- **强排式（主流）**：强制排烟+室内取氧——装浴室**必须强排**（禁止直排式——**直排已在淘汰名录，二手房看到直排机=立即换**）
- **平衡式**：室外取氧+室外排烟——**可装浴室**（密闭燃烧）；预算高但安全等级最高
- 冷凝式：回收烟气余热（省气 10%+）——价格高+冷凝水排水预留
- 安装铁律：燃气热水器**禁止装在浴室**（强排/平衡的例外）+排烟管通室外+燃气专用软管+燃气报警器（参考厨房安全技能）

## 三、恒温技术（体验差距的主战场）

- 水气双调（入门恒温）< **记忆合金/水量伺服器**（中高端——**多点用水/水压波动时温度稳定的关键**）
- 「忽冷忽热」的来源：水压波动+多点取水——水量伺服器是答案（预算够直接上）
- 零冷水功能（循环预热）：体验好但**燃气电耗双升**（全天循环模式月增气费 50-150——**用定时循环模式**）+需要回水管或加装单向阀

## 四、选购清单（对参数单用）

- [ ] 升数按需求公式+冬季报一档
- [ ] 强排起步/浴室位选平衡式
- [ ] 恒温：水量伺服器 > 记忆合金 > 水气双调
- [ ] 变频风机（比定频省气+稳）
- [ ] CO 防护（一氧化碳监测+超标自动停机——**中高端的标配**）
- [ ] 防冻机型（北方/阳台安装——防冻裂）
- [ ] 能效一级（燃气费年差 10-15%）
- [ ] 安装费用口径（**排烟管/软管/辅材另计是「安装刺客」**——下单前问清全包价）

## 五、安全与寿命（使用层的账）

- 使用年限：**8 年强制退役**（燃气具国家规定——超龄=CO 风险+效率衰减，参考灶具年限）
- 每年检查：软管/排烟管/报警器（参考燃气安全体系）
- 冬季防冻：低温环境排水防冻（说明书流程）
- 报警器联动：CO 报警器独立安装（**CO 是无味杀手**）

## 六、真实对照

> 案例 A：13L 机冬季冰凉——换 16L 后解决（**升数=冬季体验的第一变量**）；对照直接上水量伺服 16L 的：多点用水也恒温。
> 案例 B：安装报价「免费」——上门后管材+排烟管 800；问清全包的对照户实付 0（**安装费口径在下单前谈**）。
> 燃气热水器选购的公式：**升数公式+冬季报一档、强排起步浴室选平衡、水量伺服器是恒温答案、零冷水算气费账、CO 防护+报警器双保险、8 年强制退役、安装费下单前全包价、北方选防冻机型**——热水器的决策顺序=「安全类型→升数→恒温→能效」——顺序对了，钱花在体感上；顺序错了，钱花在返修上。

## 红线
> ⚠️ 提醒：燃气热水器选购的公式——「直排机立即淘汰、浴室安装只认平衡式、升数按同时点数+冬季报一档、恒温看水量伺服器、CO 报警器与监测双配、8 年强制换新、安装辅材先问全包价、零冷水用定时模式控制气费」。热水器的风险全部藏在「看不见的地方」——排烟、CO、超龄——参数表上的数字决定体验，安全项决定底线。
