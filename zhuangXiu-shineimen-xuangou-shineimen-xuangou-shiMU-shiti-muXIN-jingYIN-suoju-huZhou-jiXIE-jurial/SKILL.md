# 室内门选购

一句话：室内门的决策=「**材质（实木复合为主流）/静音锁具/五金合页/安装精度**」——「门=每过一次都要摸的东西」——质量差天天遇到（参考门锁技能的安全层）。本技能给材质对比 + 五金清单 + 安装验收。

## 一、材质的对比（主流的分级）

| 材质 | 优劣 |
|---|---|
| **实木复合（主流）** | **性价比+稳定性**（桥洞力学板芯+实木框） |
| 实木门 | 高端+怕潮易变形（贵 3-5 倍） |
| 免漆门 | 便宜（**「膜一破就丑」**——出租房级） |
| 烤漆门 | 颜值+耐用（工艺溢价） |
| 铝合金/玻璃门 | 厨卫/现代感 |
- **「实木复合=90% 家庭的正确答案」**（**「实木信仰」与「烤漆工艺」的平衡**）
- 「门的厚度」：**门扇 40mm+（**「38mm 薄扇」=隔音弱**——参考隔音技能）
- 「门套的材质」：**门套比门扇更易坏（**「包边脱落」=门套的账**）
- 「防潮门」的卫生间专属（**PVC/铝合金——参考卫浴技能**）

## 二、锁具与静音（每天摸的账）

- **静音磁吸锁的体验升级**（**「砰一声」vs「咔哒」**——参考隐形门技能）
- 「锁舌的静音胶条」的实用
- 「执手的质量」：**锌合金执手一年晃动**（**「执手松动」的高频维修**——参考五金技能）
- 「反锁的功能」（**「隐私锁」=卧室的尊重**——参考防盗技能）
- 「门的隔音组合」：**40mm 门+静音锁+门底密封条=卧室的隔音三角**（参考隔音技能）
- 「智能锁进室内」的不必要（**室内门=机械锁足够**）

## 三、五金的清单（合页与门吸）

- **合页的位次**：**子母合页/平开合页（铜质）×3 个/扇（**「2 个合页」=门下坠**——参考隐形门技能）
- 「合页的数量公式」：**门高 >2.1m 或重门=4 个**
- **门吸的必要**：**「门把手撞墙」的墙面修补税**（**「没装门吸」的常见遗漏**）
- 「防撞条」的补充（推拉门位）
- 「闭门器的室内不必要」（**「自动关门」=办公感**——参考隐形门）

## 四、安装的精度（平不齐的账）

- **「门=毫米级工艺」**：**门缝均匀（上下 2-3mm/左右 3-4mm）+门板垂直（**「斜着开的门」=洞口不正**）
- 「洞口的预核」：**量洞三次（毛坯/贴完砖/装前）**——**「贴砖后洞变小」的复测**（参考门槛石技能）
- 「门与地板的时序」：**地板先装门后（**「门高按地板高度裁」**——参考地板技能）
- 「发泡胶的填缝」（**「门框晃动」=填缝不足**）
- 「安装的验收清单」：**开关顺滑/无自开自关（**「门自己滑开」=垂直误差**）/锁位准/门缝均匀/门吸到位**
- 「修补的预留」：**同色补漆笔（**「磕碰」的日常**——参考踢脚线技能）
