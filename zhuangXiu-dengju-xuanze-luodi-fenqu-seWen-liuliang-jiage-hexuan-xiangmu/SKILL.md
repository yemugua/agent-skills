# 装修灯具选择

一句话：灯光是「家的高级感的 80%」——**色温统一/照度够用/光源策略（基础+重点+氛围）**三原则决定了灯买得对不对；「灯好看」与「光好用」是两回事。本技能给分区灯具方案 + 色温照度标准 + 选购清单。

## 一、光的三个参数（先懂参数再买灯）

- **色温（K）**：3000K 暖黄/4000K 中性/5000-6500K 冷白——**全屋统一在 3000-4000K**（参考照明技能——混色温=菜市场感）
- **照度（lux）**：客厅 100-300/阅读区 300-500/**厨房操作台 300+**（主灯不够=柜下灯带补）
- **显色指数 Ra**：≥90（**衣物/食物/皮肤的真实色**——Ra<80=色彩发灰）
- 频闪：无可视频闪（手机相机对灯——画面条纹=频闪）
- **瓦数 ≠ 亮度**：看流明（lm）——参考观影技能的流明逻辑

## 二、分区灯具方案（空间策略）

| 区域 | 主方案 | 补充 |
|---|---|---|
| 客厅 | 无主灯（磁吸/筒灯）或大灯+射灯 | 灯带洗墙（背景墙） |
| 餐厅 | **餐桌吊灯（距桌 70cm）** | 吊灯对桌=食欲光 |
| 厨房 | 平板主灯+**柜下灯带** | 水槽上方补光 |
| 卧室 | 漫射主灯低照度+**床头壁灯/阅读灯** | 起夜感应灯 |
| 卫生间 | 镜前灯（**显色 Ra95+**）+浴霸照明 | 镜前光是化妆的真实光 |
| 书房 | 台灯（读写 300lux+）+顶灯 | 参考写字姿势技能 |
| 玄关/走廊 | 感应灯（自动亮=体验神器） | 参考插座技能的遗漏清单 |

## 三、光源策略的三层（专业感的来源）

1. **基础照明**：均匀照亮（筒灯/平板——照度达标）
2. **重点照明**：射灯打向挂画/植物/操作台（**「被照亮的对象」**——重点照明的美学价值）
3. **氛围照明**：灯带/落地灯/壁灯（2700K 微光——**晚间的「调暗模式」**）
- 三层齐备=有层次的灯光；只有主灯=「学校教室感」
- **分控开关/智能调光**：场景切换（观影模式/阅读模式）——线控改造在水电期定（参考插座技能）

## 四、选购清单（避坑点）

- [ ] 色温全屋统一（3000K 或 4000K 二选一）
- [ ] 显色 Ra≥90（客厅/餐厅/镜前）
- [ ] 筒灯/射灯选防眩（深藏光源——**「见光不见灯」**）
- [ ] 灯带选高压安全款+铝槽散热（胶粘裸带=脱落+光斑难看）
- [ ] 吊灯高度：餐桌上方 70-80cm（不挡视线不刺眼）
- [ ] 变频/无频闪认证
- [ ] 灯口通用性（E27/GU10——**后期换光源的灵活性**）
- [ ] 瓦数小灯多盏 > 一盏大灯（**均匀光 > 单点亮**）

## 五、灯具风格的克制（颜值的边界）

- 造型复杂的水晶灯/开口朝上的灯：**积灰+积虫的清洁噩梦**（参考开荒技能的「从上到下」逻辑——灯是最难擦的）
- 开口朝下/漫射罩=易维护的造型
- 大主灯的颜值税：**无主灯设计的美观与实用双解**（预算允许时）
- 灯的价格分界：常规筒灯射灯 30-150/个（**百元内国产已够用**——灯具是「设计与工艺」的钱不是「必需」的钱）

## 六、真实对照

> 案例 A：全屋混色温（客厅 6500K 卧室 3000K 餐厅 4000K）——「每个房间像不同店铺」；统一 3500K 后整体感回归（**统一是灯光美学的第一原则**）。
> 案例 B：厨房只装主灯——切菜背光人影挡台面；柜下灯带加装后体验质变（**「作业区的灯」>「房间的灯」**）。
> 灯具选择的公式：**色温全屋统一、Ra≥90 显色、三层光源（基础+重点+氛围）、流明不看瓦数、防眩见光不见灯、餐桌吊灯 70cm、柜下灯带是厨房灵魂、感应灯进走廊、造型选易维护、小灯多盏胜大灯**——灯光的预算分配：参数（色温/显色）先于造型——好看的灯很多；好用的光要靠设计。

## 红线
> ⚠️ 提醒：灯具选择的公式——「全屋色温 3000-4000K 统一、显色 Ra≥90、基础+重点+氛围三层布局、柜下灯带与镜前灯是体验刚需、防眩深藏光源、流明选灯不看瓦数、分控与智能调光水电期预留、造型复杂=清洁税」。灯光是「装修完才后悔最多的部分」——因为它是每天开 6 小时的体验，而选灯时只看了 3 分钟的颜值。
