# 消防技术服务质量体系（QMS）认证材料

一句话：**把机构现状（人、设备、文件、项目）整理成一份能拿去答辩的受控文件包自查报告。**

## 为什么不是通用的 ISO9001 技能

| 维度 | 通用 QMS 技能 | 本技能 |
|---|---|---|
| 要素骨架 | GB/T 19001 通用条款 | 14 个过程要素，按消防维保/检测/评估业务铺开 |
| 行业红线 | 无 | 人员资质（注册消防工程师 + 操作员 + 社保）、测量溯源（校准证书） |
| 周期约束 | 通用 | 2026 版认证规则排期（一二阶段 ≥5 天、审核员年上限 180 天） |
| 输出物 | 模板文件 | 自查报告 + 补件清单（含建议编号）+ 高风险项 + 内审闭环表 |
| 数据来源 | 抽象输入 | 真实机构现状表，不编数据 |

## 报告能答的六个问题

1. 现在能不能申报？缺几项？
2. 14 个过程要素，哪几个是「没文件」、哪几个是「有文件没记录」？
3. 谁的证书过期了？哪台设备校准超期了？
4. 内审、管理评审是不是已经超过 12 个月？
5. 要补哪些受控文件？建议编号多少？谁负责？
6. 哪些问题会直接把审核现场挂掉？

## 典型用法

```bash
python scripts/qms_check.py --file 现状.md --today 2026-10-04 --json qms.json
```

三步：填现状表 → 跑脚本 → 用复核表逐条确认 + 把补件做成内审记录。
