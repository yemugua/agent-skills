# 期限、周期与 2026 新规

## 一、认证周期硬约束

| 项目 | 要求 | 说明 |
|---|---|---|
| 证书有效期 | 3 年 | 第 3 年换证；**证书被撤销后 1 年内任何认证机构均不受理重新申请**，成本极高 |
| 一阶段/二阶段间隔 | ≥ 5 天 | 2026-01-01 起新版认证规则：两阶段审核间隔至少 5 天，排期要留缓冲 |
| 审核员年度审核上限 | ≤ 180 天 | 2026 新规：每位审核员全年审核不超过 180 天，认证机构排期普遍变长 |
| 专职审核员全程参与 | 强制 | 审核组必须有一名专职审核员全程参与，直接推高认证成本 |
| 监督审查 | 获证后每年 | 年度监督审查不通过会暂停证书 |
| 整改回复时限 | 一般 ≤ 7 个工作日 | 不符合项整改回复原则上 7 个工作日内；重大隐患按法规单独定期限 |

### 排期倒推模板

```
T-3 个月：锁定认证机构、签订协议、提交申请材料
T-2 个月：完成缺项补件、内审、管理评审（都要落在认证受理之前）
T-1 个月：一阶段审核（文件审查）
         ↓ 至少隔 5 天
        二阶段审核（现场 + 现场试验）
T+1~2 周：不符合项整改 → 验证关闭 → 发证
```

## 二、体系内部周期

| 项目 | 频次 | 超时后果 |
|---|---|---|
| 内部审核 | 每年 ≥ 1 次 | 超 12 个月未做 = 无法证明体系在运行，体系性不符合 |
| 管理评审 | 每年 ≥ 1 次 | 缺管理评审 = 最高管理者未对体系有效性作评价 |
| 文件评审/更新 | 适时 + 定期 | 标准换版、机构人员变动后必须更新受控文件 |
| 校准/检定 | 按设备校准周期（常见 12 个月） | 超期即测量溯源失效 |
| 应急演练 | 每年 ≥ 1 次（消防技术服务机构建议每半年） | 无演练记录 = 预案未验证 |
| 客户回访 / 满意度调查 | 每半年或每年 | 走过场（全 5 分无意见）本身是近年监管重点 |

## 三、人员证书

- 一级/二级注册消防工程师：注册证书有效期与继续教育同步，到期前 3 个月做换证预警。
- 消防设施操作员：职业资格证书长期有效，但**执业/继续教育与社保关系**才是抽查重点。
- 二级建造师：三年有效 + 延续注册，注意延续窗口。

## 四、处罚与监管速查（常见触发点）

| 情形 | 后果方向 |
|---|---|
| 超出资质范围从事消防技术服务 | 责令改正、罚款、记入诚信记录 |
| 出具虚假文件/报告 | 严厉处罚，可能吊销资质；责任人连带 |
| 未按规定配备注册消防工程师/操作员 | 责令限期改正，逾期可撤销资质 |
| 检测设备未校准/超期使用 | 结论不可信 + 不符合项 |
| 记录造假（补签、倒填日期） | 性质最严重，宁可缺项也不能编 |

> 以上为常见情形归纳，具体处罚幅度以现行法规和当地消防救援机构/市场监管部门口径为准。

## 五、跨年计算规则

- 期限按「到期日」算，不按「整天数」四舍五入：如 2026-04-09 到期，
  4 月 10 日起即超期。
- 年度周期看「上次日期 + 1 年」，跨年不进位：
  2025-11-20 上次内审 → 下次截止 2026-11-20，不是 2027 年。
- 二月末兜底：非闰年 2 月 29 日 +1 年按 2 月 28 日。
