# 受控文件与内审闭环（怎么把材料真正做扎实）

## 一、受控文件四件套

任何一份受控文件发布时，必须同时具备：

1. **文件本体**（含版本号、生效日期、页码、编制/审核/批准签字栏）
2. **受控清单**（登记编号、版本、生效日期、持有部门）
3. **发放/回收记录**（旧版回收销毁，不能只发不收）
4. **修改记录页**（改了哪一条、为什么、谁批的）

缺任何一件，审核员都会问「这个文件怎么受控的」，然后判不符合。

## 二、编号规则（沿用机构现有体系）

- 程序文件：`DXCX` + 两位序号，如 `DXCX07 服务质量控制程序`
- 记录表单：`DX/JL` + 三位序号 + 版本，如 `DX/JL013-A 客户回访登记表`
- 作业指导书：`DX/ZY` + 序号
- 设备校准证书：单独归档，台账里指向证书编号即可，不占用体系编号

> 补件清单里给的编号是**建议值**，起点从 40 之后开始，避免与现行 DXCX01~27 撞号。
> 最终编号以本机构《文件控制程序》为准。

## 三、内审流程（六步）

1. **策划**：年度内审计划 → 本次内审通知 → 成立内审组（不能审自己）
2. **准备**：翻受控清单 → 按要素分工 → 准备检查表
3. **现场抽查**：文件符合性 + 记录真实性 + 现场一致性，三条都要看
4. **开不符合项**：至少开几条（全 0 条 = 内审无效），分级见下表
5. **整改闭环**：责任人在期限内提交纠正措施，内审员验证关闭
6. **报告**：内审报告 → 提交管理评审

## 四、不符合项分级

| 等级 | 判据 | 典型例子 |
|---|---|---|
| 严重 | 体系性缺失、直接导致服务结果不可信 | 无合同评审就签合同、无校准就出检测报告 |
| 一般 | 局部执行不到位，但有替代证据 | 某次维保记录漏签、培训签到表缺一人 |
| 观察项 | 风险较低，提醒即可 | 记录表格版式不一致、归档目录乱 |

> 判定原则：**看后果，不看态度**。整改承诺写得再漂亮，找不到证据也是一般不符合。

## 五、纠正措施怎么写才不被退回

合格写法（四要素齐全）：

```
不符合描述：XX 项目 2026-03 月度维保记录缺 y 月巡检签字
根本原因（至少 2 条）：① 记录模板未包含巡检人签字栏；② 安全员交接时未核对签字完整性
纠正措施：① 修订维保记录模板（DX/JLXXX-B），2026-05-01 起生效
          ② 每月 3 日前由项目负责人复核上月签字，复核记录留档
          ③ 对相关 3 人做一次记录填写培训（签到 + 试卷/考核）
完成期限：2026-05-15
验证方式：查 4 月记录签字完整率 100% + 查培训签到
验证人 / 日期：XXX / 2026-05-20
```

不合格写法（一眼被退回）：

```
原因：人员疏忽
措施：加强管理，提高认识
期限：立即
```

## 六、管理评审输入输出（防「两张皮」）

**输入**：内审结果、客户反馈与满意度、过程绩效与目标达成、不符合及纠正措施、
监视测量结果（含校准）、法规标准变化、上次评审决议的落实、改进机会。

**输出**：体系变更决定、资源需求、目标调整、下一步改进事项（要带责任人和期限）。

**三必须**：最高管理者必须出席并讲话；输入输出一一对应；改进事项必须能追到关闭证据。

## 七、七类高频「形式化」问题（自查用）

1. 文件形式化：抄模板，公司名/业务范围没改。
2. 工艺不精细：作业指导书没有本机构真实参数（用的别的项目的数值）。
3. 外部供方控制薄弱：计量校准机构没评价、没查资质。
4. 满意度调查走过场：全 5 分、无具体意见、无改进。
5. 知识积累缺失：问题复盘后没沉淀成检查表/作业指导书。
6. 监视测量失控：设备台账和校准证书对不上。
7. 质量意识不足：一线人员不知道自己该填什么表、什么时候填。
