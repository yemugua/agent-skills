# 消防隐患与整改材料清单

> 用法：把【】换成你自己的；拍照要带**部位编号**；
> 找不到的先别急——很多在单位/维保手里，走「索要 → 责令整改 → 报消防救援机构」。

## 一、问题条目（现场干活的人用）

每条问题写成四件套：**部位 + 设施 + 故障 + 数量**

| # | 字段 | 怎么填 | 状态 |
|---|---|---|---|
| 1 | 发现时间 | 精确到点，跟聊天记录时间戳对齐 | ☐ |
| 2 | 部位 | 楼层/分区/房间/设备房（写清东段/西段、B2/B1） | ☐ |
| 3 | 设施系统 | 从 10 类里选一个：火灾自动报警 / 自动喷水灭火 / 消火栓系统 / 灭火器 / 防烟排烟 / 应急照明与疏散指示 / 防火分隔 / 消防给水 / 消防广播与电话 / 消防控制室与值班 | ☐ |
| 4 | 故障描述 | 「12 只烟感连续误报（疑似积灰）」，不要写「烟感有问题」 | ☐ |
| 5 | 数量 | 只 / 处 / 台 / 盏 —— **没数量就没法复核** | ☐ |
| 6 | 照片 | 拍到**设备编号牌** + 全貌，最好有参照物 | ☐ |
| 7 | 责任方 | 甲 / 总包 / 分包 / 维保 / 监理 / 供货 / 设计单位 | ☐ |
| 8 | 整改期限 | ⚠️ 要**书面**文书，微信口头期限不算数 | ☐ |
| 9 | 复检安排 | 复检日期 > 到期日，有照片 + 验收人签字 | ☐ |

**反面示例（别这么写）**：「三楼消防有问题」
**正面示例**：「3 层东区 12 只感烟探测器 3 月 8 日 14:20 起连续误报，疑似积灰，拍照 3 张」

> ⚠️ **未经消防验收/备案合格就投入使用**，是商业综合体、厂房、教学楼项目上最容易爆的雷。

## 四、最容易翻车的三样

1. **消防泵、阀门被关 / 消防水被断** —— 最典型、最容易罚的项，看到就当天报
2. **控制室没人值班、记录缺失** —— 比某个烟感坏掉更扎眼，因为它证明「你根本没做」
3. **只发微信、不落书面** —— 微信是证据，但闭环凭证在整改单上

## 五、提交前自查 13 项

☐ 每条都有部位（不是「某处」）+ 数量
☐ 照片带设备编号牌
☐ 问题归到了 10 类设施之一
☐ 有责任方（不是「大家一起看看」）
☐ 有**书面**期限，不是只微信说了
☐ 复检日期晚于到期日，且复检有照片 + 验收人签字
☐ 整改回复单有编号、发出日、签收人
☐ 重大隐患单独拎出来判要素，没当小毛病
☐ 完整连续记录（含对自己不利的部分），没剪辑
☐ 三处备份：本机 + 云盘 + 项目归档
☐ 记录日期**没有倒签**
☐ 台账分文件夹按月存（值班日志 / 巡检记录 / 检测报告）
☐ 模板里【待现场填写】的都填了，没填的直接删掉
