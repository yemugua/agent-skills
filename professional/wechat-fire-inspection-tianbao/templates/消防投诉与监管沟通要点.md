# 报监管 / 投诉时的沟通要点

> 对方一直拖、只回「在做了」的时候，别在微信里陪他耗。
> 该报就报——那不是多管闲事，是**把责任从你身上移到监管方**。

## 一、报之前先备齐三样

1. **完整连续记录**（聊天导出 + 照片，含对你不利的部分）
2. **问题清单**：部位 + 设施系统 + 故障 + 数量（跑一遍脚本就有初稿）
3. **催办痕迹**：至少书面催过一次，有发出时间、有签收/回复

## 二、打 12345 / 报消防救援机构，怎么说

```
我在【项目名称 / 地址】负责【消防维保 / 现场管理 / 施工】。
【日期】发现【部位】的【设施系统】存在【故障描述】，共【数量】。
已书面催办【日期】一次，对方至今未整改（附聊天记录与照片）。
存在问题：可能严重影响公共安全 / 已持续 X 天。
请派员现场核查。联系人【姓名】 电话【手机号】。
```

**四句话讲清**：哪、是什么、多久了、要什么（派员核查）。

## 三、升级顺序（别一步跳到最狠）

| 阶段 | 做什么 | 留什么 |
|---|---|---|
| 1. 内部 | 发整改通知 + 抄送单位负责人 | 通知单、签收、抄送截图 |
| 2. 书面催办 | 二次书面，写清后果 | EMS / 邮件 / 微信长文 + 已读回执 |
| 3. 报监管 | 12345 / 消防救援机构 | 工单号、受理回执 |
| 4. 重大隐患 | 判定要素 → 整改方案 → 专家论证 → 申请延期 | 书面方案、论证意见、延期申请批复 |
| 5. 行政处罚 | 配合调查、如实提供图纸与记录 | 现场笔录、询问笔录（逐字核对再签） |

⚠️ **记录别藏**：图纸、值班日志、巡检记录要如实提供，
藏了比原来那个隐患严重得多。

## 四、常见提问预判（去之前先想好）

| 对方问 | 怎么答 |
|---|---|
| 「有书面整改单吗？」 | 有，编号 X、发出日 X、签收人 X（提前翻出来） |
| 「微信算不算？」 | 电子数据只要真实完整、能核对原始载体就有效；但闭环凭证在书面 |
| 「问题早就改了」 | 整改前照片 + 整改后照片 + 复检日期，对不上就是没改 |
| 「这是产品问题」 | 不影响我对项目/单位的责任，另案向供货商追偿 |
| 「整改没到期」 | 期限以**书面文书**为准，微信口头说的要有对应文书 |
| 「你们自己巡检怎么没发现」 | ⭐ 这句话正好证明「你方未落实消防安全管理责任」，是重点，接住它 |

## 五、现场笔录三条铁律

1. **逐字核对再签字**，听不懂或记不清的地方当场问清楚、改过来
2. 修改处**自己签个名或按手印**，别让别人代改
3. 拿到一份自己留底；只给看的、不给你复印的，当场拍照/记下编号

## 六、报完之后

- 工单号/受理回执存进项目文件夹，按日期命名
- 把「已报监管」同步到内部群 + 留痕（证明你已尽管理责任）
- 监管来了配合检查，但**先把自己那份材料理顺**再开口
