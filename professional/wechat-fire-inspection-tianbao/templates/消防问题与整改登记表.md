| 1 | | | | 发书面催办（第 1 次） |
| 2 | | | | 再发 + 抄送单位负责人 |

**超期三步走**：
1. 书面催办（留送达凭证）
2. 仍不动 → 报消防救援机构 / 打 **12345**
3. 可能严重影响公共安全 → 走重大隐患流程（判定 → 方案 → 专家论证 → 申请延期）
