# 期限速查：整改、复检、验收备案、追责时效

> 消防这件事，**日期比技术更容易翻车**：整改单哪天发的、限几天、复检哪天做、
> 验收备案卡在哪一步、出了事多久内必须报告——全都挂在时间上。
> 本技能脚本的核心就是**把聊天里的时间点全抽出来，排成一条时间线，标出谁超期了**。

## 一、四类期限，别混

| 类别 | 谁定 | 起点 | 特点 |
|---|---|---|---|
| **整改期限** | 消防救援机构《责令限期改正通知书》/ 甲方要求 / 自己排期 | 文书送达日或通知日 | ⚠️ 以**文书**为准，微信里口头说的不算限 |
| **复检安排** | 自己（或单位申请） | 整改到期后 | 到期未复检 = 默认「没改完」 |
| **验收/备案时限** | 住建部门规定 | 工程完工/备案受理 | 以当地住建部门口径为准 |
| **追责时效** | 《行政处罚法》 | 违法行为终了之日 | 2 年（涉及公民生命健康安全、金融安全的有 5 年） |

## 二、整改与复检

1. **先要文书**：对方说「限你 7 日内改」，先问一句「**有没有限期改正通知书？哪天发的？**」
   —— 口头期限在复议时等于没有，而你做的是记录，得有据可查。
2. **期限从送达日起算**，不是从聊天那天起算。差一天，超期认定就反过来了。
3. **到期未改 → 升级**：
   普通隐患 → 再发一次书面整改 + 留痕；
   ⚠️ 拒不整改或可能严重影响公共安全 → **报消防救援机构 / 12345**，
   这不是「多管闲事」，是把责任从你身上转到监管方。
4. **复检要在到期后尽快做**，并且**复检时间 > 整改期限**才说明闭环；
   同日「已整改」+「已复检」= 事后补材料，对方一问就穿。
5. **整改回复单**要写：整改部位、措施、数量、完成时间、验收人、复检结论。
   缺验收人签字，等于没闭环。

## 三、重大火灾隐患的时间线（多一层）

- 发现 → **判定**（按《重大火灾隐患判定规则》，要素客观）
- 判定后 → 报单位主要负责人 → 报消防救援机构 → 制定整改方案
- 涉及复杂技术的 → **专家论证**
- 限期整改 → 确有困难的 → **申请延期**（要书面、要理由、要政府/机构批准）
- 整改完成 → 复核销号

⚠️ 重大火灾隐患**没有"拖一拖就过去了"这种选项**，到点不销号会往停产停业走。

## 四、验收备案的时间线

```
消防设计审查（特殊建设工程）→ 施工 → 完工 → 检测/联动调试
→ 【特殊建设工程】消防验收  |  【其他工程】验收备案 + 抽查
→ 合格 / 整改 → 复验 → 合格 → 投入使用
```

- 备案后住建部门会**随机抽取抽查**；抽查中发现不符合的 → 整改 → 可能转为验收
- **未经消防验收/备案合格就投入使用**：这是最容易在教学楼、商场、厂房项目上爆的雷
- 抽查比例、时限、材料清单**各地口径不同**，以项目所在地住建部门窗口为准

## 五、维保与值班的"硬性周期"

| 事项 | 周期 | 依据口径 |
|---|---|---|
| 消防控制室值班 | **每日 24 小时、每班不少于 2 人、持证上岗** | 《消防控制室通用技术要求》，证书为消防设施操作员 |
| 单位日常防火巡查 | **每日** | 《消防法》第 16 条（消防安全重点单位） |
| 消防设施巡检/维保 | 按合同频次（月检/季检/年检） | 合同 + 消防设施维护管理要求 |
| 消防设施年度检测 | **每年**至少一次 | 消防设施维护管理要求 |
| 灭火器配置与点检 | 按月点检 | 灭火器配置与维护管理要求 |

> 这些是**最容易在检查当场被翻出来**的：值班记录缺一天、巡检签到缺一周，
> 比某个烟感坏掉更扎眼——因为它证明的是「你根本没做」。

## 六、追责时效（出了事往前倒查）

- 一般行政处罚追责时效：**2 年**，从违法行为终了之日起算
- 涉及**公民生命健康安全**、金融安全等：延长到 **5 年**
- 火灾事故调查：火灾扑灭后公安消防机构（现消防救援机构）现场勘验、调查认定，
  单位应**及时提供真实图纸、记录、值班日志**——**别藏，藏了性质变 worse**
- 消防技术服务机构（维保/检测）出具虚假报告的：撤销资质、列入失信、连带追责

## 七、可主张/可申诉的时机

| 你说什么 | 什么时候有用 |
|---|---|
| 「已发整改单，限 X 日前，有回复单」 | 证明已履职、已尽到管理责任 |
| 「故障是产品本身缺陷，供货商供货前就有」 | 追偿，不影响你对单位的责任 |
| 「我们已报消防救援机构/12345」 | 把风险外移，避免自己担「明知不改」 |
| 「整改未到期限」 | ⚠️ 期限以**文书**为准，微信说的期限要能对应到文书 |
| 「已申请延期，在批复中」 | 需书面证据，口头申请基本不认 |

## 八、常见错误（全都是踩过的）

1. ❌ 只发微信不落书面 → 期限无据、责任无据
2. ❌ 整改单写「烟感有问题」→ 复检时无法判定是否改完
3. ❌ 复检日期 = 整改到期日 → 看起来像补材料
4. ❌ 只拍优点、不拍问题 → 反过来成了「你明知有隐患」
5. ❌ 后期补记录（日期倒签）→ 一经发现，整本记录可信度归零
6. ❌ 把「重大火灾隐患」当普通隐患慢慢改 → 拖成停产停业
7. ❌ 消防泵/阀门被关了没人管 → 这是最典型、最容易罚的项
8. ❌ 控制室值班记录一个月补一张 → 检查当场就露馅

## 九、法条速查（只列常用，的版本以现行文本为准）

- 《消防法》第 16 条 — 单位消防安全职责、重点单位每日巡查
- 《消防法》第 60 条 — 违反消防安全规定的责令改正与罚款
- 《消防法》第 62 条 — 个人违规（占用堵塞、擅自动用消防设施）
- 《消防法》第 61 条 — 动火作业违规
- 《建设工程消防设计审查验收管理暂行规定》（住建部令）— 消防验收 / 备案抽查
- 《重大火灾隐患判定规则》— 重大隐患要素判定
- 《消防控制室通用技术要求》— 值班、持证、记录
- 消防设施维护管理相关国标 — 巡检、检测、维修、保养、存档
- 地方标准：上海 DB31/T 1380《社会消防技术服务机构质量管理要求》等（**以当地现行版本为准**）
