# 要件速查：消防隐患、整改闭环、验收备案

> 用法：这份是**扫描前先定性**的口径。先看你现在站哪一边——
> 是**现场干活的人**（要把问题一条条记清楚、催甲方/施工方改），
> 还是**被检查的人**（要证明自己改了、请复检），
> 还是**维保单位**（要证明自己履职、留痕、别被追责）。
> 三边的要件不一样。

## 一、先定性：消防问题分三类

| 类型 | 谁发 | 后果 | 你要做什么 |
|---|---|---|---|
| **火灾隐患/违法行为** | 日常检查、消防救援机构监督检查 | 责令改正、罚款（《消防法》第 60 条：责令改正，单位处 **5000 元以上 5 万元以下**罚款） | 列问题 + 定责任方 + 定期限 + 留复检证据 |
| **重大火灾隐患** | 消防救援机构判定 / 自己排查发现 | 可能停产停业、报政府挂牌督办 | ⚠️ 判定、整改方案、专家论证、延期审批，一步都不能跳 |
| **消防设施故障/未合规** | 维保巡检、检测、验收抽查 | 整改回复单、复检、影响验收备案 | 故障登记 → 维修 → 复测 → 记录归档 |

⚠️ **重大火灾隐患判定**按《重大火灾隐患判定规则》，**要素客观、无裁量空间**，一条即可能构成；
别当成普通隐患凑合改——顺序错了，项目会被挂住。

## 二、消防设施子系统（问题必须按系统归类）

| # | 子系统 | 典型问题 |
|---|---|---|
| 1 | **火灾自动报警** | 烟感误报/脏/脱落、温感失效、手报玻璃碎、模块离线、主机故障/备电故障、联动失效、地址编码错 |
| 2 | **自动喷水灭火** | 喷淋头被遮挡/锈蚀/漏水、末端试水压力不足、水流指示器无信号、湿式报警阀组故障、稳压泵启停异常 |
| 3 | **消火栓系统** | 栓箱无水带/水枪、门被锁、压力不足、按钮损坏、管网漏、水泵接合器缺失/遮挡、消防泵不能自动启 |
| 4 | **灭火器** | 欠压/过期/未按月点检、被挪作他用、配置数量不足、type 与目标场所不匹配 |
| 5 | **防排烟** | 风口被堵/被吊顶封死、风机不启、正压送风不足、排烟窗打不开、联动逻辑没写 |
| 6 | **应急照明与疏散指示** | 灯不亮/没电/没充上电、指示方向反了、被货架挡住、蓄电时间不足、断电不发光 |
| 7 | **防火分隔** | 防火门闭门器坏/常开未联动、门框缝隙、防火封堵漏、管道井未分层封堵、卷帘下降不到位 |
| 8 | **消防给水（水系统）** | 消防水池水位低、消防泵房积淹、阀门被关（⚠️ 最容易被罚）、稳压装置故障 |
| 9 | **消防广播与消防电话** | 广播无声/分区错、话筒故障、消防专用电话插孔没装 |
| 10 | **消防控制室** | 无人值班、无证上岗、记录缺失、图形显示装置故障、应急值班表没有 |

> 归类不细 → 整改单写不出可验收的描述，复检时对方一句「没改到位」就把你打回来。
> 写问题要写「**部位 + 设施 + 具体故障 + 数量**」四件套，比如
> 「3 层东区 12 只感烟探测器连续误报，3 月 8 日起，疑似积灰」——不是「烟感有问题」。

## 三、问题条目八要件

| 要件 | 说明 | 举例 |
|---|---|---|
| 1. 发现时间 | **精确到点**，跟聊天记录时间戳对齐 | 3月8日 14:20 巡检发现 |
| 2. 部位 | 楼层/分区/房间/设备房 | B2 车库东段 |
| 3. 设施系统 | 按上面 10 类归 | 火灾自动报警 |
| 4. 具体故障 | 可验证的描述 | 12 只烟感误报 |
| 5. 数量 | ⭐ 有数的才算条目，才谈得上复核 | 12 只 / 3 处 / 1 台 |
| 6. 责任方 | 甲/总包/分包/维保/监理/供货 | 由总包负责 |
| 7. 整改期限 | 谁定的、哪天到 | 限 3 月 15 日前 |
| 8. 复检安排 | 谁复检、哪天 | 3 月 16 日我方复检 |

**缺一样都会翻车**：没数量 → 说不清改完没有；没责任方 → 扯皮；没期限 → 超期还不算你的；
没复检 → 到最后变成「你说改了、他说没改」，证据在你手里就赢。

## 四、整改闭环六步（缺一步就是把活留给自己）

```
发现登记（聊天/照片/记录）→ 定级（隐患/重大）→ 下发整改（书面+人）
→ 整改实施（谁改、改到几点）→ 复检确认（照片+时间）→ 归档（整改回复单）
```

⚠️ **只发微信、不落书面**：微信是证据，但整改单才是闭环凭证。
微信里回一句「收到，3 月 15 日前改完」= 既证明你通知了，也给他一个期限。

## 五、责任方识别（扯皮现场）

| 角色 | 典型甩锅话 | 你回 |
|---|---|---|
| 甲方/建设单位 | 「这是维保单位的事」「我们不知道」 | 消防设计审查、施工、维保的责任主体不同，按合同和法条分 |
| 总包/施工方 | 「验收时就是这个状态」「等甲方确认」 | 已交付/已验收部分，施工方对既有缺陷仍有整改义务 |
| 维保单位 | 「我们只做保养，故障要甲方换件」 | 看合同范围；**未发现/未报告 = 履职缺失**，这是追责重点 |
| 监理 | 「我们只管验收程序」 | 监理对整改闭环有签发权 |
| 供货商 | 「产品是合格的」 | 合格 ≠ 安装合格，安装和联动调试归施工/维保 |

## 六、维保履职要件（维保单位自保用）

- **合同**：维保范围、频次（月检/季检/年检）、响应时限、备件责任
- **巡检记录**：谁、哪天、哪栋、什么问题、照片
- **故障处理**：报修 → 派工 → 修复 → 验收签字，**闭环要能串成一条线**
- **值班记录**：控制室 24h 值班（每日 24 小时、每班不少于 2 人、持证上岗，
  口径见《消防控制室通用技术要求》），交接班签字
- **检测报告**：年检/局部检测，由具备资质机构出
- **整改通知与回复**：留痕，别只口头
- ⚠️ **没发现 = 没履职**：漏检烟感这种高频问题，出了事第一句话就是「你们巡检怎么写的」

## 七、验收备案要件（施工/甲方用）

- 消防设计审查合格 / 备案凭证
- 消防施工过程记录、隐蔽工程验收
- 消防设施检测报告（有资质机构）
- 消防联动调试记录、消防系统竣工图
- 消防控制室值班人员证书、管理制度、值班表
- 整改回复单 + 复检记录（有问题的必须闭环）
- 特殊建设工程验收：按《建设工程消防设计审查验收管理暂行规定》
  走**消防验收**；其他工程走**验收备案 + 抽查**
  （抽查比例与时限以当地住建部门口径为准，别套外地口径）

## 八、金额与处罚速查

| 事项 | 口径 |
|---|---|
| 单位违反消防安全规定（设施停用、通道堵、值班缺位等） | 责令改正，处 **5000 元—5 万元**罚款（《消防法》第 60 条） |
| 个人违反规定（堵塞通道、擅自动用消防设施） | 警告或 **500 元以下**罚款（《消防法》第 60 条、第 62 条） |
| 消防设施未保持完好有效 | 同上，按未整改项累计 |
| 火灾隐患举报 | 打 **12345** 政务服务热线（原 96119 已并入）；也可直接报辖区消防救援机构 |
| 拒不整改 / 重大火灾隐患 | 可责令停产停业、报政府挂牌督办 |

> 具体处罚档次、限期长短**各地裁量不同**，以当地消防救援机构《责令限期改正通知书》为准。
