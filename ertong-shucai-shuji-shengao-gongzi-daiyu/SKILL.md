两个 offer 数字一样，实际收入可能差 3 万+/年。方法：把所有科目折算成"确定性现金"再比。

## 一、薪酬包逐项折现规则

| 科目 | 折算系数 | 理由 |
|---|---|---|
| base 月薪 | 1.0 | 确定现金，且是社保公积金基数、年终基数 |
| 年终奖 | 宣称值 × 0.6-0.8 | 大厂普遍打折，离职当年可能归零；新公司首年按入职月份折算 |
| RSU 期权 | 上市：市值 × 0.8（4 年分批，按当前价）；未上市：估值 × 0.1-0.3 | 流动性与行权税双重折损；未上市随时改期 |
| 签字费 | 1.0 | 确定现金，但通常服务不满 1 年需退还 |
| 现金补贴（餐补/交通/房补） | 0.9 | 看是否随工资发放、是否计税 |
| 五险一金基数 | 见下表 | 基数差异是隐藏差价最大项 |

## 二、五险一金差异算例（公积金 12% 口径）

offer A：base 15000，年终 3 个月；offer B：base 18000，无年终宣称"总包一样"（A 年薪 21 万 vs B 21.6 万）。

| 项目 | A（base 15000） | B（base 18000） |
|---|---|---|
| 公积金月缴存（12%+12%） | 3600/月 | 4320/月 |
| 年公积金差额 | 8640/年（其中个人账户合计全归自己） | |
| 养老/医疗个人账户差 | 约 2200/年 | |
| 失业金/工伤待遇基数 | 低 3000 | |

**结论**：B 的公积金+个人账户优势约 1 万/年，且 base 高带来年终、裁员赔偿（N 月工资按前 12 月平均）、产假工资、房贷额度全部上抬——**base 每差 3000，综合差价通常 >1.5 万/年**。选高 base 是常态，除非年终兑现率有书面把握。

## 三、完整比价算例（第一年现金口径）

| | offer A：base 15000+3 月年终+20 万 RSU/4 年 | offer B：base 18000+1 月年终 |
|---|---|---|
| base×13 | 195000 | 234000 |
| RSU 折现 | 200000×0.8÷4 = 40000 | 0 |
| 公积金年差额 | — | +8640 |
| **第一年折现合计** | **≈235000** | **≈242640** |

B 反超——表格里"总包 A 更高"的叙事经折现后反转。把 RSU 系数从 0.8 降到 0.5（股价下跌/离职 forfeit），差距拉大到 4 万。

## 四、谈薪话术模板

> "感谢 offer。我对比后更看重固定现金部分，希望能将 base 调整到____，或把年终从__个月提高为____且写入 offer（含兑现条件）。公积金缴存比例与基数请按全额工资标准确认并写入 offer。如果 base 无法调整，是否可用签字费____元补齐第一年差距？"

**关键动作**：①要求 base、年终月数、公积金比例写进 offer 正文（口头承诺仲裁时几乎无证据力）；②问清年终发放节点（如次年 3 月）——2 月入职可能只拿 1/12；③RSU 问 vesting 周期、离职处理、是否有回购条款。

## 五、跳槽时点与归零风险

- 年终发放前（如 3 月前）跳槽 → 年终归零，谈判时用它换签字费或 base。
- 股票 vesting cliff（通常 1 年）：不满 1 年离职全归零。
- 计算"跳槽机会成本"= 放弃的年终 + 未 vest 股票现值 ÷ 剩余年数。

## 红线

> ⚠️ 提醒：任何"绩效面议""总包含期权上限"不写进 offer 一律视为不存在；未上市期权价值按 1-3 折估，不要按公司宣传估值计入决策；社保基数按实际工资申报是法定义务，被压低可稽核投诉；本文折现系数为通行经验值，具体以 offer 条款与当地社保口径为准。
