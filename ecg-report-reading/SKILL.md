一句话：体检心电图上80%的"异常"提示（窦性心动过缓、轻度ST-T改变、偶发早搏）在无症状人群中属良性，先按危险信号分流再决定花不花钱查。

## 一、常见报告术语对照表

| 报告用语 | 含义 | 无症状时处理 |
|---|---|---|
| 窦性心律 | 正常节律 | 无需处理 |
| 窦性心动过缓(50-59次) | 运动员/正常人常见 | 观察 |
| 窦性心动过速(<100) | 紧张/咖啡/发热 | 复测一次 |
| 轻度ST-T改变 | 非特异性，最常见"虚惊" | 无高危因素→不追查 |
| 偶发房早/室早 | 健康人约1/3都有 | 观察，频发(>1万次/24h)再查 |
| 完全性右束支阻滞 | 良性变异 | 无需处理 |
| 左束支阻滞/二度以上房室阻滞 | 需评估 | 心内科就诊 |
| 房颤 | 必须处理 | 尽快就诊(卒中风险) |

## 二、危险信号分流（有任一条→就诊，无论报告结论）

- 症状类：胸痛/压榨感、晕厥或近晕厥、活动后气短进行性加重、心悸伴黑朦。
- 心血管高危因素≥2个+新发ST-T改变：高血压/糖尿病/吸烟/男>45或女>55/早发心梗家族史。
- 报告出现：房颤、左束支阻滞、二度以上房室阻滞、Q波(提示陈旧心梗可能)。

## 三、进一步检查费用测算（参考价，±30%）

- 复查普通心电图：20-40元（紧张性心动过速多一次即正常）。
- 24h动态心电图(Holter)：150-300元——用于频发早搏计数、阵发房颤捕捉。
- 心脏超声：200-300元——左束支阻滞/杂音/心衰线索时做。
- 运动平板/冠脉CT：300-800元/1000-1800元——仅高危因素+典型症状者需要；无症状轻度ST-T改变直接上冠脉CT属过度检查。

## 四、就诊描述模板（直接抄）

```
症状：____（胸痛/心悸/晕厥/气短），每次持续____分钟
诱因：活动时/静息/夜间；伴随：出汗/放射到左臂下颌
频率：____次/周；首次出现时间：____
既往：高血压/糖尿病/吸烟____年；家族心梗史：____
已做检查：____（带纸质或原始报告）
```

## 五、易踩的坑

- 轻度ST-T改变=冠心病：非特异性改变在女性、年轻人中大量假阳性，需结合症状与高危因素。
- 偶发早搏自己吓自己装支架：先Holter定量再评估。
- 用一次心电图排除/确诊一切：心电图正常≠心脏没事，发作性心律失常要Holter抓。
- 体检机构"建议复查心脏彩超+冠脉CT"全单照做：按危险信号分流，多数人只需复查心电图。

## 红线

> ⚠️ 提醒：持续胸痛>15分钟、冷汗、放射痛，立即拨打120并原地静卧，勿自行开车就诊；本技能判读基于静息心电图，不能替代动态心电图与心脏超声结论；服用心率类药物者解读"过缓/过速"前先报用药情况。
