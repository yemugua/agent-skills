# 社保基数被压低的稽核投诉流程

一句话：合同工资 15,000 但公司按 6,000 最低基数缴社保——这是普遍违法，不是行业惯例。你的损失 = 养老金 + 公积金 + 医疗报销额度三重被偷。本技能给查证方法 + 稽核投诉的完整流程。

## 一、先查证：你被压了多少

**查缴基数**：掌上 12333 / 电子社保卡 APP → 社保缴费明细 → 看「缴费基数」列
**对比标准**：基数应 = 上年月平均工资（应发总额含奖金提成），新入职按首月工资
**损失测算（月薪 15,000 按基数 6,000 缴）**：

| 损失项 | 全额缴 | 被压缴 | 年差 |
|---|---|---|---|
| 公积金（12%×2） | 3,600/月 | 1,440/月 | 25,920 |
| 养老个人账户 | 1,200/月 | 480/月 | 8,640（+复利与统筹） |
| 养老金影响 | 30 年累计少缴 → 退休金每月差 1,000+ 级别 | | |

**年度总损失轻松超 3.5 万**——比任何年终奖都值钱的暗账。

## 二、法律定性（谈判与投诉的底气）

- 《社会保险法》60 条：用人单位应**按时足额**缴纳——「员工同意按最低基数」的协议**无效**（法定强制义务不能约定排除）
- 最高法院及人社部口径：即使员工签了「自愿放弃/按最低基数」承诺书，公司仍违法
- 滞纳金：公司补缴时按日加收万分之五滞纳金——由公司承担

## 三、行动路径（从温和到强硬）

### 第 1 步：内部沟通（留痕）
> 邮件/微信书面：「查询社保记录发现缴费基数 6,000，与我应发工资 15,000 不符。根据《社会保险法》第六十条，请公司按实际工资足额申报基数，并于本月调整。」

**多数公司在此步调整**（尤其知名公司怕稽核记录）——书面留痕是后面一切的证据。

### 第 2 步：社保稽核投诉（核心武器）
- **渠道**：参保地社保经办机构「稽核部门」/ 12333 电话投诉 / 当地人社局官网
- **材料**：身份证、劳动合同、工资条/银行流水（证明真实工资）、社保缴费记录截图
- **流程**：受理 → 稽核核查公司缴费情况 → 责令补缴 → 拒不补缴的可移交处罚
- **匿名性**：可要求对单位保密（实践中大公司多能猜到，小公司通常不知道是谁）——**在职时投诉是权利，法律保护投诉人**

### 第 3 步：公积金同步投诉
- 公积金中心投诉（同基数问题独立受理）——公积金中心的补缴执行力强（可强制划扣公司账户）

### 第 4 步：离职时的组合拳
- 以「未依法缴纳社保」为由**被迫解除**（《劳动合同法》38 条）→ 主张经济补偿 N（38 条解除也有 N）
- 操作要点：先书面通知公司补缴并留证 → 公司拒不改 → 发《被迫解除通知书》→ 仲裁主张 N + 补缴
- ⚠️ 注意：38 条解除要程序严谨（先催告、给改正期再解除），操作前细读或咨询 12348

## 四、常见顾虑与事实

| 顾虑 | 事实 |
|---|---|
| 「投诉会被穿小鞋/开除」 | 报复性解雇 = 违法解除 = 2N；且稽核补缴是行政行为，公司报复是新的违法行为 |
| 「大家都这样」 | 普遍违法 ≠ 合法；稽核补缴案例逐年增多 |
| 「离职再说」 | 可行（38 条路线），但在职投诉能让全公司受益且你立即受益（公积金月月多进钱） |
| 「会得罪 HR」 | 你书面沟通时 HR 已知道；区别只在于有无正式记录 |

## 五、避坑红线 ⚠️

- ❌ 「自愿放弃社保拿补贴」协议——无效且两头坑（无保障+公司随时被告你也是共谋证据）
- ❌ 直接仲裁「要求补缴社保」——社保补缴归行政稽核管（不是仲裁受理范围），走错门白跑；仲裁管的是「38 条解除的补偿金」
- ❌ 挂靠代缴补空窗——违法且自险（资金+征信）
- ❌ 只投诉公积金忘社保（或反之）——两个系统独立受理，分别投诉

## 六、真实案例

> 案例：月薪 18,000，公司按基数 7,000 缴 3 年。
> 员工离职时走 38 条：书面催告（公司不改）→ 被迫解除 → 仲裁主张 N=3.5 个月 × 18,000 ≈ 6.3 万 + 稽核补缴 3 年差额（社保+公积金合计约 9 万）。
> 关键证据：劳动合同 + 银行流水 3 年 + 书面催告记录。

## 红线
> ⚠️ 提醒：基数的公式——「先查缴基数对合同工资、书面催告留痕、稽核投诉是主战场、公积金中心并行投诉、38 条被迫解除要程序严谨、放弃社保协议无效」。被压基数是「沉默的税」——你每年沉默一次，就替公司省 3.5 万；查一次、发一封邮件，钱就开始回你账户。
