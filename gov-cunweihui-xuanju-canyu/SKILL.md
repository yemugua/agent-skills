# 村委会选举的参与与监督

村委会选举的资格与程序、候选人提名与投票实操、选举违规的举报与救济、村民对村务的日常监督权。

## 操作路径
1. **选举的基本制度**：村委会每届 5 年（2018 年起），由本村登记参选村民直接选举；「登记参选村民」资格——户籍在本村+年满 18 周岁（户籍迁入时间与居住年限按地方办法）；外出务工者可委托投票（书面委托，1 人接受委托 ≤5 人——各地上限不同）；流动票箱（老弱病残上门收票）。
2. **参与选举的实操**：选民登记公示期核对（漏登=当场申诉——村委会/选举委员会）；候选人提名（联名提名是主要方式——10 人以上村民联名可提候选人）；投票日（秘密写票间——强制设置）；唱票计票公开（当场唱票+公布结果）；对程序违规（代填选票/票箱管理混乱）当场提出+拍照留证。
3. **想被选/想推动候选人**：报名条件（村民口碑+无违纪违法记录的实务门槛）；竞选宣传的合规边界（不得贿选——请客送礼承诺好处=贿选，可举报）；联名提名书的规范（名单+签名真实）；当选后的第一次村民会议（把竞选承诺转为村务议题）。
4. **选举违规的举报与救济**：贿选/破坏选举——举报到乡镇政府/县民政局（村委会组织的指导监督机关）；选举无效的认定（程序严重违规——可申请重新选举）；「乡镇干预选举」的投诉（民政部门+纪检）；证据（录音/照片/联名信）是关键。
5. **日常监督权（比选举更常用）**：村务公开（村务/财务/党务三公开——每季度，财务收支明细有权查阅）；村民代表会议（重大事项必须经会议——如集体资产处置）；村账乡管（村级财务由乡镇代理记账）；对村干部的罢免程序（1/5 以上村民联名→村民会议表决罢免）；审计权（村干部任期与离任审计——村民可申请）。

## 避坑红线 ⚠️
- 「选举与我无关」的弃权——村集体资产处置（土地/分红）都由当选者主导，一票影响数年分红。
- 拿好处投他人——贿选的「受贿」端也可能被追责；坚持秘密写票。
- 举报没有证据——先取证（联名/录音/账目复印件）再举报；匿名举报效率低。

## 求助渠道
乡镇政府/县民政局（选举指导与违规查处）；纪检监察（村干部违纪）；农业农村部门（村务公开监督）；12345。

## 法律效力
《村民委员会组织法》（选举程序/村务公开/罢免与监督的完整框架）；各省实施办法（委托投票/资格细则）。

## 真实价格
参与选举 0 元；查账与监督 0 元；选举维权（取证+举报）成本几乎为零——保护的是全村数年的集体资产分红权。

## 红线
> ⚠️ 提醒：村委会事务的三个抓手——「选举时投票、日常看村务公开、重大事项盯村民会议」。外出务工也别忘书面委托投票；对账目的查阅权是法律给的，不用不好意思。
