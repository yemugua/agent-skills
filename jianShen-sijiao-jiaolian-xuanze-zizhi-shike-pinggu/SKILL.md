# 健身私教与教练选择

一句话：私教课的坑=「销售型的『教练』+卖课 KPI+退课难」——好教练的识别不是看肌肉是看「评估-计划-教学」的专业流程。本技能给资质识别 + 试课评估表 + 买课策略 + 退费预案。

## 一、教练资质的真实识别（证书水分大）

**有含金量的证书**：
- 国职（健身教练国家职业资格证书）——基础门槛
- NSCA-CPT/CSCS、ACE、ACSM（国际四大）——运动科学体系扎实
- 特殊人群认证：孕产、老年、康复相关（如 FMS 功能动作筛查）——带伤/产后必备

**水分信号**：
- ❌ 「XX 学院高级认证」（花钱速成班，3 天拿证）——查发证机构
- ❌ 只秀身材不谈方法论——「练得好」≠「教得好」（教学是另一门技能）
- ✅ 问一句「我的体态问题你打算怎么评估」——答出「先做体态/体测评估再定计划」的才专业

## 二、试课评估表（买课前必做，好机构会免费提供）

试课时观察这 8 项（每项 ✅/❌）：
- [ ] 先问目标与健康史（伤病史/慢病）——不问就开练=危险
- [ ] 有体态/动作评估环节（蹲/推/拉的动态观察）
- [ ] 动作讲解有「为什么」（肌肉发力逻辑）而非只喊口令
- [ ] 全程看你的动作并纠正（玩手机/看镜子=不合格）
- [ ] 强度循序渐进（第一节课就往死里练=拉伤风险+「见效错觉」营销）
- [ ] 课后给书面/电子的训练计划框架（不是口头）
- [ ] 不过度推销课包（课后立刻逼单 50 节=销售型教练）
- [ ] 愿意回答「不买课在家怎么练」——好教练不怕这个问题

**≥6 个 ✅ 才考虑买课**。

## 三、买课策略（钱的防御在买之前）

- **最小课包起步**：先买 10-20 节（不是 50 节送 20）——「大课包折扣」的数学=把退课难的风险折现给你
- 课时频率：每周 1-2 次私教+自主训练——**纯私教依赖=停止上课就反弹**；好教练会教你自主训练（这是判断标准）
- 单价锚点：一线 300-500/节、二三线 200-350/节——显著低于此的多为新人教练练手
- 合同条款：**写明「未上课程可退」+「教练离职可换或退」**（健身房教练流失率高——教练走了课就废是常见事故）
- 缴费留凭证+合同拍照

## 四、常见套路反制

| 套路 | 反制 |
|---|---|
| 「今天买 50 节送 15，明天恢复原价」 | 优惠长期存在——按最小包走，愿等「明天」 |
| 「你体测指标很差，必须练」 | 体测恐惧营销——拿报告问第三方（问两个教练交叉验证） |
| 「私教区不能自己练」 | 换场馆或要求公共区教学——条款没有这条 |
| 教练频繁换人 | 合同写明教练离职的处理（换/退）——没写就投诉到市场监管 |
| 「不上够频次没效果别怪我们」 | 频次是销售话术——合同只管课时消耗 |

## 五、退费预案（课包沉没时的路径）

1. 合同+缴费凭证+上课记录（刷卡记录/预约记录）齐备
2. 健身房不退费的常见借口：「课时过期」「已开卡」——反制：有效期条款若为格式条款且未显著提示，可主张无效（消保法）
3. 路径：书面申请 → 商场物业/品牌总部投诉（连锁品牌有用）→ 12315 → 小额诉讼（25-50 元一审终审）
4. 跑路预防：办卡前查机构司法风险（企查查——「教育培训合同纠纷」被告记录多的=高危）；**单月消费上限原则**（一次充值 ≤3 个月课费）

## 六、比私教更重要的三个事实

- **饮食占减脂效果 70%**——私教练的是动作与习惯，嘴在食堂
- 新手前 3 个月自重训练+固定器械（免费教学视频/入门计划）已够——私教的核心价值在「动作纠错与个性化」（体态问题/伤后恢复/力量瓶颈期）
- 「教练身材=专业」是最贵的错觉——教学能力与个人身材相关性弱

## 七、真实对照

> 案例 A：会员买 50 节课包（2 万），教练 3 个月后离职，健身房拒绝转课→凭合同「教练离职可换」条款转课成功。
> 案例 B：试课 8 项评估只有 2 项 ✅（不评估+第一节课就高强度+课后逼单）——换一家，评估 7 ✅，半年体态改善明显。
> 私教的公式：**证书查发证机构、试课 8 项打分 ≥6 才买、最小课包起步、合同写教练离职条款、一次充值 ≤3 个月**——私教买的是「专业的教学关系」不是「打折的课时堆」。

## 红线
> ⚠️ 提醒：选教练的公式——「国职/NSCA/ACE 是硬通货、试课先评估再开练、讲解有『为什么』、第一节课不往死里练、最小课包+合同写退换条款、体测恐惧是营销、教练身材≠教学能力、充值不超 3 个月」。健身房的利润在「你坚持不下来」；你的利益在「每节课都值回票价」——用评估表守住第二次交钱之前的选择权。
