# 忠诚协议：签之前先知道哪一半是废纸

夫妻签「忠诚协议」很常见，但多数人不知道：**约定过错方「净身出户」「放弃全部财产」这类条款，法院基本不支持**；而约定具体金额的「损害赔偿」，在财产分割时可能被酌情考虑。签之前把效力边界搞清楚，比事后打官司省几十万。

## 效力速查表

| 协议条款写法 | 司法态度 | 原因 |
|---|---|---|
| 出轨方「净身出户」、放弃全部财产 | ⛔ 基本无效 | 限制离婚自由、剥夺法定财产权，多数法院不予支持 |
| 出轨方赔偿对方 5万/20万 具体金额 | ⚠️ 各地不一 | 部分法院酌情支持或作为分割参考，部分认为超出法定范围 |
| 约定「过错方少分财产」 | ✅ 可能被参考 | 与《民法典》第1087条照顾无过错方原则方向一致 |
| 约定「不得提出离婚」 | ⛔ 无效 | 限制婚姻自由，直接违反法律 |
| 约定「谁提离婚谁净身出户」 | ⛔ 无效 | 同上，典型「离婚自由受限」条款 |
| 约定出轨方承担子女抚养权归对方 | ⛔ 无效 | 抚养权按子女利益判定，不能约定 |
| 约定「房产过户给无过错方」并已实际过户 | ✅ 有效 | 属财产赠与/约定财产制，过户后不可随意撤销 |

## 关键法条

- 《民法典》第1043条：夫妻应当互相忠实——是倡导性规定，不是可强制执行的义务本身。
- 《民法典》第1065条：夫妻可以约定财产归属（书面形式）——**忠诚协议里真正站得住脚的是财产约定部分**。
- 《民法典》第1091条：重婚、与他人同居、家暴、虐待遗弃等法定过错，无过错方可请求离婚损害赔偿——**这条不需要协议也有效**，协议只是补充。

## 算例：同一句写法差出 80 万

- 婚前房产 A（男方，市价 300 万），婚内房产 B（共同，市价 400 万）+存款 100 万。
- 写法一：**「男方出轨则净身出户」** → 法院通常仍按共同财产均分，男方分到约 250 万+婚前房；协议形同虚设。
- 写法二：**「男方若存在重婚/与他人同居情形，双方同意婚内房产 B 归女方所有，女方补偿男方合理折价款 60 万；本条系双方对第1065条财产的特别约定」** → 属约定财产制范畴，被支持概率显著更高；且女方还可依1091条另主张损害赔偿。
- 差距：同一情形，写法二比写法一可能多保障女方 100 万以上（B 房一半即 200 万权益方向的差异）。

## 可复制的条款框架（财产约定型）

> 第X条 双方确认，任何一方存在下列情形之一：①重婚；②与他人持续、稳定地共同居住；③对另一方实施家庭暴力——视为对该方重大过错。
> 第X+1条 出现上述情形的，双方同意：位于____的房产（产权证号____）归无过错方个人所有，车辆（车牌____）归无过错方所有；无过错方另有权依据《民法典》第1091条主张离婚损害赔偿。
> 第X+2条 本条为双方依据《民法典》第1065条对婚姻关系存续期间所得财产及婚前财产归属的特别约定。

红线：别写「净身出户」「不得离婚」，写了等于给对方留一个「整份协议可能被认定无效」的攻击点。

## 红线

> ⚠️ 提醒：①忠诚协议≠离婚损害赔偿的替代品，1091条法定情形（重婚/同居/家暴等）即使没签协议也能主张，注意收集证据（聊天记录、报警记录、开房记录须合法取得——**偷装定位器、闯入他人住宅取证本身违法，反而让自己成为过错方**）；②协议签署时间如果在离婚诉讼中「抓奸现场」胁迫签订，可主张可撤销；③各地法院对金额型忠诚条款裁判尺度不一，重大财产安排优先做**书面夫妻财产约定+必要时公证**，不要赌忠诚协议的金额条款。
