# 手机↔电脑文件互传：一句话，临时传几个文件用微信/QQ文件传输助手（快但压缩画质），批量传照片视频用数据线或局域网工具（无损不限速），别再用网盘中转。

## 方案对照表
| 方式 | 速度 | 无损 | 适合 | 前提 |
|---|---|---|---|---|
| 数据线+USB | 30-80MB/s（USB3） | ✓ | 相册批量导出/大视频 | 手机选「文件传输」模式 |
| Windows「手机连接」/苹果AirDrop | 10-30MB/s | ✓ | 日常照片 | 同账号/同一WiFi |
| 微信文件传输助手 | 2-8MB/s | ✗（图片视频压缩） | 文档、临时传 | 登录电脑端 |
| LocalSend/Feem（开源局域网） | 20-50MB/s | ✓ | 任意跨平台 | 同一WiFi，免登录 |
| 网盘中转 | 受会员限速 | ✓ | 异地/定时传 | — |

> 同一WiFi下 LocalSend（Android/iOS/Windows/macOS 全平台）是最省事的跨品牌方案；苹果生态 AirDrop 秒传。

## 算例
导出50GB手机视频（搬家导出）：数据线USB3约15分钟；微信传会压缩到1080P且50GB需10小时以上——**大文件用数据线，省9小时+画质无损**。电脑清空手机空间场景（iPhone 128G满）连电脑用「图像捕获/Image Capture」直读相册，只挑选导入。

## 可复制操作
- Windows：手机连USB→通知栏选「传输文件」→资源管理器出现手机盘→DCIM/Camera 复制。
- 跨平台无数据线：两台设备装 LocalSend →同WiFi→发送端选文件→接收端点接受。
- 微信无损传图：发送时勾「原图」，视频走「文件」入口发送可绕过压缩。

## 红线
> ⚠️ 提醒：①微信电脑端登录要在手机上确认，离开公共电脑务必退出登录，聊天记录会同步残留；②数据线选原装或标USB3的，杂牌线只有USB2（约30MB/s上限变2.5MB/s，慢10倍）；③局域网互传工具只在可信WiFi用，公共热点下文件可被同网抓包，敏感文件走数据线。
