# 未成年人防沉迷充值上限规则账

一句话点题：未成年人游戏充值有**法定上限**，超限充值可依规申请退款——家长要做两件事：提前把监护工具设置好；出了事按取证清单把材料备齐，退款路径是通的。

## 一、充值上限与时长规则（法定）

| 年龄段 | 充值上限 | 游戏时长 |
|---|---|---|
| 8 周岁以下 | 网络游戏企业不得提供付费服务（不能充值） | 仅限规定时段登录 |
| 8-16 岁 | 单次 ≤ 50 元，每月累计 ≤ 200 元 | 周五六日及法定节假日 20-21 时 |
| 16-18 岁 | 单次 ≤ 100 元，每月累计 ≤ 400 元 | 同上，每天 1 小时 |

- 时长规则（2021 年"830 新规"）：未成年人仅可在**周五、周六、周日和法定节假日的 20-21 时**登录网游，其余时间企业不得提供服务。
- **金额账**：8-16 岁孩子一个月合规充值上限 200 元、一年 2,400 元；若账单出现单月 2,000 元以上的游戏消费，基本可判定为**绕过实名或盗用家长支付**的超限充值，属于可主张退款的范围。
- 孩子用家长身份注册的，家长有监护过错，但企业实名风控存在漏洞仍可主张退款，两者不冲突。

## 二、家长监护工具设置步骤

1. **腾讯系**：微信/QQ 搜"腾讯家庭守护"小程序 → 绑定孩子账号 → 设"禁止充值"或单日限额 + 时段限制 + 登录提醒。
2. **网易系**：网易家长关爱平台 → 绑定账号 → 设置充值限制与时段管理。
3. **通用兜底**：手机系统层关闭"免密支付/面容支付"；支付密码由家长保管；微信/支付宝开启大额交易验证。
4. 设置完成的标准：孩子拿到手机也刷不出钱——**免密支付一关，八成的误充值当场消失**。

## 三、发现违规充值的取证清单

1. 支付记录：微信/支付宝/银行卡账单逐笔截图或导出（时间、金额、收款方为游戏公司）；
2. 账号信息：游戏 ID、区服、角色名、实名信息截图；
3. 未成年人身份证明：出生证明或户口页（证明充值发生时是未成年人）；
4. 行为证据：孩子操作的过程描述、相关聊天记录（如与同学代充的对话）；
5. 消费明细：要求客服提供该账号完整订单列表并邮件发送。

**时间敏感**：越早申请越好，超过 6-12 个月的历史订单部分企业受理难度明显上升。

## 四、退款申请路径衔接

1. **游戏官方客服/家长热线**（如腾讯未成年人家长服务专线 950926、网易家长服务）→ 说明未成年人误充值 → 按清单提交材料 → 审核通过后退款（通常按消费流水核算，已消耗的虚拟道具价值会扣除）。
2. 客服不受理或拖延 → **12315 平台**（App/小程序）投诉，写明"未成年人未经监护人同意超额充值，违反防沉迷规定"。
3. 金额较大且企业拒不处理 → 走民事诉讼路径（未成年人事后未追认的行为效力待定），小额以 12315 调解为主。

**可复制话术**（12315 投诉要点）：
"X 年 X 月至 X 月，我未成年的孩子（X 岁）使用本人支付账户向 XX 游戏（运营公司：XX 公司）充值共 X 笔、合计 X 元，单笔最高 X 元，超出未成年人充值法定上限。现申请退款，联系方式 XXX。"

**可复制话术**（游戏客服）：
"我是账号 XXX 的监护人，孩子未满 X 岁，于 X 月 X 日充值 X 元，超过法定单次/每月上限。请提供该账号消费明细，并告知未成年人退款的材料清单与办理时限。"

## 红线

> ⚠️ **退款只找官方渠道**：社交平台上"游戏退款代办""内部关系退款"100% 是诈骗，还会套走你的账号与证件照片。
- 不伪造身份证明、不教孩子冒充家长骗客服：材料造假会导致永久拒退并可能承担法律责任。
- 退款通常扣除已消耗道具价值，"全额退"不符合多数企业规则，预期先摆正。
- 治本靠两道闸：**支付免密关闭 + 监护平台限额**；退款是补救手段，不是日常管理方式。
