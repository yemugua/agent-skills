# 阳台改造利用

一句话：阳台是「家里最被低估的平方米」——同一块地可以做洗衣区/花园/储物/书房的复合体；改造的核心=「功能分区+承重与排水红线+封闭与否」。本技能给功能方案 + 施工红线 + 预算表。

## 一、功能定位（先想用途再动手）

| 功能 | 需求条件 | 投入 |
|---|---|---|
| **洗衣+晾晒区**（最常见） | 上下水/洗衣机位/晾衣架 | 2,000-5,000 |
| 花园/种植区 | 承重/防水/日照方向 | 1,000-3,000 |
| 休闲区（茶座/吊椅） | 封闭阳台/遮阳 | 2,000-6,000 |
| 储物区 | 定制柜（防晒防潮选材） | 1,500-4,000 |
| 复合方案（洗衣+绿植+储物） | 分区设计 | 5,000-10,000 |

**判断顺序**：①阳台封闭与否（开放阳台=防风防雨优先，种植/晾晒为主；封闭=可做休闲书房）②上下水现状（洗衣功能的前提——**没有上下水的加管改造 500-1,500**）③承重红线（见下）。

## 二、施工红线（阳台改造的三大安全线）

1. **承重红线**：阳台设计荷载有限（悬挑结构）——**巨型鱼缸/堆土种菜/满墙储物柜=超载风险**（堆土种菜 30cm 深 ≈ 每平米 300kg+）；花盆用轻质盆+轻质土
2. **排水红线**：洗衣机排水必须接专用地漏（**不能改接雨水管**——违规+返味）；阳台地面坡向地漏（2% 坡——参考防臭技能）
3. **结构红线**：不拆阳台与室内的配重墙（**拆配重墙=悬挑结构隐患**——装修拆改红线的成员）；封闭阳台=物业报备（**外立面统一管理**——私封被要求恢复的案例常见）

## 三、分项改造要点

**洗衣区**：
- 洗烘套装叠放（空间翻倍）+专用地漏+柜体收纳（洗衣液/脏衣篮）
- 台盆加装的实用价值（手洗/拖把池——**小台盆 500 元的日常回报率高**）
- 留扫地机器人基站位（阳台=基站Preferred位——上下水款）

**种植区**：
- 日照评估：南向=果蔬/多肉；北向=耐阴绿植（**先看光再买花**——买错的植物是阳台最大的沉没成本）
- 自动滴灌（旅行/懒人方案 100-300 元）+接水盘（**浇水的楼下渗漏=邻里事故第一名**）
- 花架靠内墙（防台风坠落——**高空坠物=法律责任**）

**休闲/储物**：
- 封闭阳台做休闲：防晒帘/遮光卷帘（西晒治理）
- 储物柜选材：**多层实木/金属柜**（颗粒板在阳台=受潮变形——阳台柜的选材红线）
- 吊椅/秋千：**吊顶承重确认**（打在混凝土顶不是吊顶石膏板内）

## 四、预算表（典型复合方案）

| 项 | 价格 |
|---|---|
| 洗烘位柜体定制 | 1,500-3,000 |
| 台盆+龙头 | 400-800 |
| 地漏/排水改造 | 200-500 |
| 晾衣架（电动/手动） | 300-1,500 |
| 花架+植物+滴灌 | 500-1,500 |
| 封闭窗（如需报批） | 300-800/㎡（整体 5,000-15,000） |

## 五、真实对照

> 案例 A：洗衣+绿植+储物复合改造（8,000）——洗烘叠放+侧墙花架+顶柜储物：3.5㎡ 干出 3 个功能区（**分区设计>面积大小**）。
> 案例 B：堆土种菜 30cm+满墙柜——阳台下挠开裂（超载）；改轻质盆+吊挂后安全（**承重是看不见的预算**）。
> 阳台改造的公式：**先定功能分区再动手、承重/排水/配重墙三红线、洗衣机接专用地漏、阳台柜选防潮材质、先看日照再买植物、浇水渗漏用接水盘、高空花架防坠落、封闭阳台走物业报备**——阳台是「小面积大工程」的典型——3.5㎡ 的改造，红线与大平米一样多。

## 红线
> ⚠️ 提醒：阳台改造的公式——「功能分区先行、配重墙不可拆、承重按每平米算、洗衣机专用地漏防返味、柜体选防潮材料、种植先看光照、接水盘防楼下渗漏、封闭走报备、高空坠物是法律责任」。阳台改造的成败不在美不美；在「超没超载、漏没漏水」——安全线之内的自由，才是真的自由。
