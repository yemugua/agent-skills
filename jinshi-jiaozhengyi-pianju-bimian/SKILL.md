# 近视矫正仪与防控产品的避坑

近视不可治愈的医学共识、常见智商税产品（按摩仪/护眼台灯夸大/矫正仪/护眼贴/叶黄素神话）、它们的宣传套路、真正有效的方法清单、发现被骗后的处理。

## 操作路径
1. **医学共识**：真性近视不可逆——眼轴变长如身高不能缩回（「降度数/摘镜/治愈」的宣传=违规话术——国家六部门的明令禁令）；「可做的是」——延缓进展（户外/离焦镜/OK 镜/低浓度阿托品的循证清单）；「假性例外」——调节痉挛的可逆（散瞳后消失才是「假性」——不是产品治好的）。
2. **智商税地图**：按摩/振动仪——「放松睫状肌降度数」（眼轴是物理长度，揉不出来）；「矫正/训练仪」——「视功能训练摘镜」（乱码训练的假性改善——眯眼技巧的短期提升）；「护眼贴/明目贴」——凉感≠治疗；「叶黄素神话」——护眼底≠治近视（营养补充的边界）；「护眼台灯治近视」——灯只减负不逆转（好的照明是防控的一环不是全部）；「降度数眼镜」——视力表 game 的短期效果。
3. **宣传套路**：话术信号——「治愈/恢复/降度数/视力回退」（真性近视的医学不可能——任何机构用这些词=不专业）；「案例」——「XX 孩子摘镜」（假性/调节痉挛的个案≠真性可治）；「资质包装」——「XX 协会认证」的野鸡组织；「焦虑营销」——「不治就瞎」的恐吓（高度近视的风险是真的——但「我们的仪器」不是答案）。
4. **有效清单**：每日户外 2h——最强的循证防控（阳光多巴胺的眼轴抑制——免费且证据最强）；「离焦镜片/OK 镜」——50-60% 的进展延缓（医院的正规选择）；「低浓度阿托品」——0.01% 的夜间一滴（遵医嘱）；「用眼习惯」——20-20-20/距离/光线（行为防控的日常）；「定期复查」——眼轴监测的预警。
5. **被骗处理**：证据留存——宣传页/聊天记录/付款凭证（「治愈近视」话术的违规证据）；「投诉」——12315/市场监管的虚假宣传举报；「退款」——协商+投诉的组合；「止损」——停用产品回到循证路线（时间成本的最大损失认知）。
