# 驾照降级被拒原因

## 场景
办理"驾照降级"事务中的"被拒原因"环节，面向首次办理、补正、异地办理人群。

## 办理渠道
1. 线上：交管12123（车驾管）/ 当地政务服务网/APP / 公积金中心线上大厅 / 一网通办。
2. 线下：车管所/交警大队/公积金中心/公证处/学校或教育局窗口。
3. 热线：12345 总机；车驾管 12122；公积金 12329。

## 通用材料清单
- 身份证原件及复印件
- 申请表（签名与证件一致）
- 佐证材料：按事项提供（行驶证/登记证书/购房合同/缴存证明/户口本/出生证明/原证书等）
- 异地办理：居住证或居住登记凭证（部分事项已取消）
- 委托代办：委托书+双方身份证复印件

## 流程要点
1. 预约或线上提交 → 2. 受理（缺件一次性告知）→ 3. 缴费/审核 → 4. 领取结果（电子证照与纸质同效）。

## 时限与费用
- 以受理回执或公示标准为准；车驾管与政务服务收费均有公开依据，"加急费"可拒付举报。

## 常见驳回原因
1. 材料过期或非原件
2. 前置条件缺失（未处理违章/未缴清/未备案）
3. 信息不一致（证件升位、曾用名）
4. 不符合当地准入条件（限购/积分/缴存年限）

## 申诉与维权
- 驳回有异议：索要书面凭证 → 行政复议（60日内）/行政诉讼（6个月内）。
- 乱收费、推诿：12345、12388 实名举报。

## 提示
车驾管业务优先使用"交管12123"APP（大部分业务支持线上办+电子凭证）；谨防"代办消分""内部关系年检"等骗局，正规渠道均按公示标准收费。
