# 油烟机安装避坑指南

## 场景
处理"油烟机安装"事务中的"避坑指南"环节，面向首次消费、被坑维权、比价优化三类人群。

## 信息/办理渠道
1. 官方渠道：12315（消费投诉）、12345（总机）、市场监管部门；涉装修投诉可找住建/消协。
2. 行业渠道：品牌官方渠道、连锁机构、认证平台；服务人员核验证件（健康证/资格证/上岗证）。
3. 比价：至少对比3家，线上线下同款比价，警惕"最后名额"催单话术。

## 通用准备清单
- 需求清单：先明确自己的预算、周期、验收标准再谈
- 合同/订单：逐条确认服务内容、型号、数量、工期、违约金、退费条款
- 付款留痕：大额预付分期付、走可追溯渠道、索要发票
- 证据链：宣传页截图、沟通记录、现场照片/视频全程保存

## 流程要点
1. 需求确认 → 2. 多方比价 → 3. 资质核验（机构证照/人员证件/产品认证）→ 4. 签约（重点读退费与违约条款）→ 5. 分阶段履约验收 → 6. 保留全部凭证至服务结束+保修期满。

## 费用与行情
- 以当地主流平台与市场均价参考；明显低价多有增项/降配套路。
- 预付类消费（卡/课/充值）单次充值金额尽量低、周期尽量短。

## 常见坑
1. 低价引流→开工/开课加价
2. 口头承诺不写进合同
3. 预付后门店转让/跑路
4. 材料以次充好（装修/母婴用品假货）
5. 人员资质造假（月嫂/教练/施工队）

## 维权路径
- 协商 → 平台申诉 → 12315 投诉（注明退一赔三情形）→ 消协调解 → 起诉（小额诉讼）。
- 跑路涉诈骗：报警 110 + 向商务/市监举报，联合其他受害人集体维权。

## 提示
装修纠纷核心在合同与验收留证：分阶段付款、每阶段书面验收、增项须书面确认；保修条款写进合同（隐蔽工程一般保修5年）。本技能为验收与流程参考。
