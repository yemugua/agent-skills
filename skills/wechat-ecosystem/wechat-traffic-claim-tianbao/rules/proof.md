# 交通事故证据在索赔中的证明力

> 事故现场消失得最快。交警来了、车拖走了、对方拉黑了——**微信里的记录往往是唯一还活着的东西。**

---

## 一、微信记录的法定类别

《最高人民法院关于民事诉讼证据的若干规定》第十四条第（四）项列举电子数据，
包括"电子数据的交换、传输、存储、检索、复制、提取所形成的能够证明案件事实的信息"。

微信聊天记录属**第（四）项**。提交时注意三点：

| 事项 | 做法 |
|---|---|
| **主体同一性** | 证明聊天账号就是对方本人微信号 |
| **完整性** | 提交连续、不跳段的完整对话 |
| **原始载体** | 保留手机/电脑本机，别只留截图 |

**最有效的主体证明**：对方微信号绑定的手机号实名信息截图 + 事故后他主动发消息认责的记录。
**最强手段**：公证处证据保全。**千元级费用，但对方一旦否认"这不是我发的"，公证书直接终结争议。**

## 二、对方（司机 / 保险公司）七大抗辩

按实战强度排序：

| 抗辩 | 频率 | 你的应对 |
|---|---|---|
| **"责任认定书写的次要责任"** | ★★★★★ | 认定书是交警依勘验作出的公文，**推翻难度极大**。有异议必须在 **3 日内复核** |
| **"这是旧伤 / 你本来就有病"** | ★★★★★ | 提交伤前体检、就诊记录；申请因果关系/参与度鉴定 |
| **"医嘱只写了休息一周"** | ★★★★ | 申请**三期鉴定**（误工期/护理期/营养期），以鉴定结论为准 |
| **"我们只赔交强险范围"** | ★★★★ | 交强险是最低保障，**三者险必须赔超出部分**，这是《民法典》第 1213 条的硬规则 |
| **"你没住院，护理费不给"** | ★★★★★ | 护理期看**医嘱或鉴定**，不看住院天数 |
| **"你没报警 / 现场没了"** | ★★★ | 补报警记录；有现场照片视频证人可佐证；或申请调取路口监控 |
| **精神损害抚慰金太高 / 不该赔** | ★★★ | 与伤残等级挂钩（十级起赔），法院酌定；一般刑事附带民事不支持 |

## 三、承诺 vs 意愿表达（索赔场景版）

| 强度 | 表述 | 作用 |
|---|---|---|
| **★★★★★ 责任自认** | "这事怪我""我全责""下Trouble找我" | 对方自认责任，最硬 |
| **★★★★★ 已实际赔付** | 转账记录 / "钱已转你" | 双方对损失项目已臻一致 |
| **★★★★ 具体赔付方案** | "我们赔你 5 万，签协议吧" | 锁定对方认可的口径 |
| **★★★ 认可损失项目** | "医药费我们认，营养费再说" | 逐项突破，很有用 |
| **★★ 流程推进** | "材料收到了，在走流程" | 证明程序进行，未认可金额 |
| **★ 协商语气** | "再看看""可能要商量" | 容易被解释为"未达成一致" |

**使用建议**：把强证据单独摘出来形成**证据清单**，别和弱证据混着交。
对方一旦指出你的弱证据有争议，容易连带质疑整份材料。

## 四、六种取证/保全手段（强度递进）

| 手段 | 成本 | 证明力 | 适用 |
|---|---|---|---|
| 截图 | 0 | ★★ | 快速留存，易被质疑完整性 |
| **聊天记录导出为文本** | 0 | ★★★ | **优于截图**，带时间戳、完整、便于核对 |
| 录屏（从头播放带上下文） | 0 | ★★★★ | 证明连续性 |
| 可信时间戳 / 第三方存证 | 低 | ★★★★★ | 证明"这段记录在某时已存在" |
| 区块链存证 | 中 | ★★★★★ | 同上，司法认可度更高 |
| **公证处证据保全** | 高（千元级） | ★★★★★★ | 对方质疑身份/完整性时的终极手段 |

**推荐组合**：日常用**导出 + 录屏**；发现对方开始耍赖、或准备起诉，**立即做一次公证**。

## 五、索赔场景的补强清单：微信之外还缺什么

微信记录只能证明"沟通发生过"。真正决定赔多少的是这些**外部凭证**：

| 材料 | 作用 | 去哪里拿 |
|---|---|---|
| **《道路交通事故认定书》** | 决定责任比例，最核心 | 交警队 |
| 病历 / 诊断证明 / 出院小结 | 伤情与治疗过程 | 医院 |
| 医疗费发票 / 费用清单 | 医疗费金额 | 医院 |
| **医嘱（必须含"加强营养""建议护理"）** | **营养费、护理费的依据** | 主治医生 |
| **三期鉴定（误工/护理/营养期）** | 三项期限的唯一依据 | 有资质的鉴定机构 |
| **伤残鉴定书** | 残疾赔偿金 + 精神损害抚慰金 | 有资质的鉴定机构 |
| 事故现场照片 / 视频 | 还原现场 | 你自己 / 路人 / 路口监控 |
| 监控录像 | 认定书之外的最强佐证 | 交警调取 / 沿街商户 |
| 车辆维修清单 + 发票 | 车损金额 | 4S / 修理厂 |
| 施救费票据 | 拖车、救援费 | 救援公司 |
| **事发前 12 个月工资流水** | **误工费计算基准** | 银行 / 工资卡 |
| 单位误工证明 | 证明收入实际减少 | 单位人事 |
| 被扶养人关系证明 + 无劳动收入证明 | 被扶养人生活费 | 居委会 / 派出所 / 单位 |
| 假肢/轮椅等辅助器具证明 | 辅助器具费 | 装配机构 |
| 营运证 / 客运营运资质 | 停运损失 | 运管部门 |

> ⚠️ **微信是"串"的作用** —— 把上述材料按时间线串起来，证明"我在第一时间报案、过程中提交了什么、对方承诺了什么"。
> **外部凭证才是"节点"** —— 没有这些，微信里聊得再热闹也赔不到钱。

## 六、提交前自查清单

- [ ] 事故认定书已拿到，责任比例看清楚
- [ ] 认定书 3 日复核期**已过或已用**（没异议就别动）
- [ ] 聊天记录是**完整连续**的，没有裁剪跳跃
- [ ] 每段关键对话都**带时间戳**
- [ ] 对方账号主体身份已固定（实名/绑定手机/公证）
- [ ] 医嘱里**明确写了"加强营养""建议护理/陪护"**（没有就去补开）
- [ ] 三期鉴定已做（误工期/护理期/营养期）
- [ ] 如涉残：**伤残鉴定书已出**，且是在治疗终结后做的
- [ ] 误工费有**事发前 12 个月工资流水**
- [ ] 所有金额与票据已**交叉核对一致**
- [ ] 计算顺序是**先交强险、后三者险**（没按责任比例先打折）
- [ ] 时效尚在，且**已留下最近一次催告记录**
- [ ] 全部材料至少三处备份（本机 + 云盘 + 原件）

## 七、常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 只截有利片段 | 对方指"断章取义"，整份可信度崩塌 | 完整提交，主动解释不利内容 |
| 收到认定书不复核 | 责任划分锁死 | **3 日内**申请复核 |
| 营养费/护理费没医嘱 | 这两项直接赔不了 | 就诊时主动请医生写进医嘱 |
| 直接按责任比例算总账 | 少拿一大截 | 先交强险全额，再按责任比 |
| 误工费没流水 | 按当地最低工资算 | 提前保存工资流水 |
| 先签调解协议后鉴定 | 事后无法反悔 | **先鉴定，后签字** |
| 伤残鉴定做太早 | 等级偏低，少赔很多 | 治疗终结后（一般伤后 3–6 个月） |
| 只留截图 | 对方质疑完整性 | 导出文本 + 保留原始记录 |
| 口头承诺不落文字 | 对方否认后无据 | 通话后**立刻微信复述确认** |
| 拖延不催告 | 时效耗尽 | 每 6–12 个月正式催告一次 |
