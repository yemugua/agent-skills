# 交通事故索赔要件库

> 按"责任确定 → 损失举证 → 金额计算 → 保险赔付"四段式拆解。
> 每一项写清：**要件是什么 / 谁举证 / 微信里能找什么 / 缺了会怎样**。

---

## 通用判定框架

任何交通事故索赔都过这四关，**缺一关就不用往下算钱**：

| 关卡 | 问题 | 不通过的后果 |
|---|---|---|
| **责任是否确定** | 有《事故认定书》吗？责任怎么分？ | 无认定书则举证责任在你，赔多少全靠对方心情 |
| **损失是否真实** | 每一项费用都有凭证吗？ | 无凭证的项目法院不支持 |
| **金额是否算对** | 伤残有鉴定吗？标准对吗？ | 十级和一级差 9 倍 |
| **赔付顺序是否对** | 交强险先赔还是三者险先赔？ | 顺序错了少拿一大截，这是最常见的吃亏点 |

## 一、责任认定（最重要的一步）

### 前置文件：《道路交通事故认定书》

| 要件 | 举证方 | 微信里能找什么 | 缺失后果 |
|---|---|---|---|
| **事故认定书存在** | 受害方主张 | 搜"认定书""责任认定""交警" | **没有它，索赔无从谈起** |
| 责任比例 | 交警依勘验认定 | 认定书原文 | 主次责直接影响赔多少（常见 7:3 / 8:2） |
| 是否在复核期 | 受害方 | 搜"复核""3日""复议" | 收到认定书 3 日内可申请复核，**过期不再受理** |
| 事故是否属交警管辖 | 双方 | 搜"报了警""交警队""事故科" | 有单方现场无报警的，事后很难认定 |
| 是否逃逸 | 对方抗辩 | 搜"逃逸""掉头就走""跑了" | 逃逸者全额承担（交强险也不赔，保险公司垫付后可追偿） |
| 是否酒驾/醉驾 | 对方抗辩 | 搜"酒驾""醉驾""吹了""酒精" | 醉驾属交强险免责范围，保险公司垫付后追偿 |
| 是否无证/未年检 | 对方抗辩 | 搜"没证""年检""审车" | 商业三者险可拒赔 |

**责任划分的五种常见结果：**

| 责任形态 | 赔偿比例 | 说明 |
|---|---|---|
| 全部责任 | 100% | 对方全责 |
| 主要责任 | 70%–80% | 常见主次责 |
| 同等责任 | 50% | 机动车之间 |
| 次要责任 | 20%–30% | |
| **无责** | 0% | 但仍可从对方交强险无责限额获赔（≤1.8万伤残/1800医疗/100财产） |

> ⚠️ **机动车之间**同等责任是 5:5；**机动车与非机动车/行人**同等责任时，机动车一方通常要担 60%。这个差别很多人不知道，直接少拿一截。

## 二、赔偿项目清单（人伤）

按《最高人民法院关于审理人身损害赔偿案件适用法律若干问题的解释》。

| # | 赔偿项目 | 举证方 | 微信里能找什么 | 缺失后果 |
|---|---|---|---|---|
| 1 | **医疗费** | 受害方 | 搜"发票""医药费""花了""住院" | 只有总额无票据的不予支持 |
| 2 | 住院伙食补助费 | 受害方 | 搜"住院""住了几天""出院" | 需住院记录，**门诊不给这项** |
| 3 | **营养费** | 受害方 | 搜"营养""加强营养""医嘱" | **医嘱没写"加强营养"就赔不了**，这是高频漏项 |
| 4 | **误工费** | 受害方 | 搜"误工""请假""病假""休息" | 需：误工时间（医嘱）+ 收入减少证明 |
| 5 | **护理费** | 受害方 | 搜"护理""护工""陪护""请假照顾" | 需医嘱 + 护理人员收入或护工票据 |
| 6 | 交通费 | 受害方 | 搜"打车""急诊""复查" | **凭实际票据**，一般按病历/就医次数酌定 |
| 7 | 残疾赔偿金 | 受害方 | 搜"伤残""鉴定""等级" | **没有鉴定书，十级也赔不了** |
| 8 | 精神损害抚慰金 | 法院酌定 | 搜"精神""抚慰""十级""伤残" | 与伤残等级挂钩，**一般不支持刑事附带民事** |
| 9 | 辅助器具费 | 受害方 | 搜"假肢""轮椅""支具""矫形" | 需假肢装配机构证明 + 更换周期 |
| 10 | 丧葬费、死亡赔偿金 | 受害方 | 搜"死亡""丧葬""后事" | 致死情形专用 |
| 11 | **被扶养人生活费** | 受害方 | 搜"孩子""父亲""母亲""抚养""赡养" | 需证明无劳动收入 + 被扶养人身份 |
| 12 | 后续治疗费 | 受害方 | 搜"后续""取钢板""二次手术" | 需医疗证明或鉴定结论 |

### 关键概念辨析

| 容易搞混 | 区别 |
|---|---|
| **误工时间 vs 护理时间** | 误工是"你自己不能上班"（看医嘱休息期）；护理是"有人照顾你"（看住院天数/医嘱） |
| **营养费看医嘱** | 不是看你花了多少营养品，是看**医嘱有没有写"加强营养"** |
| **护理期限** | 一般计算至"受伤日起至鉴定日前一天"，不是住院天数 |
| **精神损害抚慰金** | 十级伤残起赔，逐级递增；各地标准不同（常见每级 3000–5000 元） |

## 四、金额计算

### 4.1 伤残等级系数（十级至一级）

依据《人体损伤致残程度分级》。多数人不知道**十级和一级差 10 倍**。

| 等级 | 系数 | 等级 | 系数 |
|---|---|---|---|
| **一级** | 100% | **六级** | 50% |
| 二级 | 90% | 七级 | 40% |
| 三级 | 80% | 八级 | 30% |
| 四级 | 70% | 九级 | 20% |
| 五级 | 60% | **十级** | **10%** |

> 级差通常为 **1%**（相邻两级差一个百分点，如二级 90% → 一级 100%）。
> **多处伤残要"合并计算"**：多个十级不等于十级，按"最高等级 + 级差累加"规则确定最终系数。

**残疾赔偿金公式：**

```
残疾赔偿金 = 受诉法院所在地上年度城镇居民人均可支配收入
             × 赔偿年限（20年；60岁以上每增1岁减1年；75岁以上按5年）
             × 伤残系数
```

### 4.2 交强险限额（2020年车险综合改革后）

| 责任 | 死亡伤残 | 医疗费用 | 财产损失 |
|---|---|---|---|
| **有责** | **180,000** | **18,000** | **2,000** |
| 无责 | 18,000 | 1,800 | 100 |

**医疗费用项下**包含：医疗费、住院伙食补助费、营养费、**后续治疗费**。这一项限额只有 1.8 万，**超出的部分走商业三者险或侵权人**。

### 4.3 赔付顺序（算错就少拿钱）

```
第 1 层  交强险          有责限额内全额赔，不分责任比例
            ├─ 死亡伤残  18万
            ├─ 医疗费用  1.8万
            └─ 财产损失  0.2万

第 2 层  商业三者险      超出交强险部分 × 责任比例（如次责 30%）
                        保额常见 100万 / 200万 / 300万

第 3 层  侵权人个人      三者险不足、免赔、或者对方根本没买三者险
```

**常见算错点：**

| 错误 | 正确 |
|---|---|
| 直接按责任比例算总账 | **先走交强险全额，剩下的才按责任比** |
| 把伤残赔偿金算进"死亡伤残"限额里 | 对，**十级伤残的残疾赔偿金属于交强险"死亡伤残"项下**，限额 18 万 |
| 交强险不分责任 | **有责/无责是两档**，全责和无责限额差 10 倍 |

### 4.4 误工费 / 护理费 通用公式

```
误工费 = 日均收入 × 误工天数
日均收入 = 事发前12个月平均实际收入（不足12个月按实际月数）
```

| 情形 | 举证方式 |
|---|---|
| 有固定工资 | 单位营业执照副本复印件 + 劳动合同 + **事发前12个月工资流水** + 单位出具的误工证明 |
| 个体/自由职业 | 营业执照 / 劳务合同 + 银行流水，**举证不足时按当地最低工资标准计** |
| 无业人员 | 一般不支持误工费，除非能证明有实际劳动收入 |

> ⚠️ **事发前 12 个月的工资流水是关键。** 很多人拿不出，法院就会按当地最低工资标准算，直接少一大截。

## 五、对方 / 保险公司 八大抗辩

| 抗辩 | 出现频率 | 应对 |
|---|---|---|
| **"你没住院，凭什么给护理费"** | ★★★★★ | 护理期看**医嘱**（护理期限鉴定），不是看住院天数 |
| **"医嘱没写加强营养"** | ★★★★★ | 补医嘱或营养期鉴定；否则该项确实难支持 |
| **"误工时间太长"** | ★★★★ | 对误工时间做**三期鉴定**（误工期/护理期/营养期），以鉴定为准 |
| **"这是旧伤"** | ★★★★ | 提交伤前体检/就诊记录，证明伤与事故有因果关系 |
| **"我们只认可交强险范围"** | ★★★★ | 交强险是最低保障，**三者险必须赔超出部分** |
| **"你没报警，责任没法认定"** | ★★★ | 补报警记录；有现场照片/视频/证人可佐证 |
| **"精神损害抚慰金不合理"** | ★★★ | 与伤残等级挂钩，十级起赔，法院酌定 |
| **"这是你自己撞的"** | ★★★★★ | **《事故认定书》是决定性证据**，认证书上怎么写就怎么来 |

## 七、金额构成总表

```
总损失
├─ 人身损害
│  ├─ 医疗费（票据）
│  ├─ 住院伙食补助费（住院天数 × 当地标准，常见 30–100 元/天）
│  ├─ 营养费（医嘱/鉴定营养期 × 30–50 元/天）
│  ├─ 误工费（日均收入 × 误工期，三期鉴定）
│  ├─ 护理费（日均标准 × 护理期，三期鉴定）
│  ├─ 交通费（票据/酌定）
│  ├─ 残疾赔偿金（可支配收入 × 20年 × 伤残系数）★
│  ├─ 精神损害抚慰金（10级起，级差递增）
│  ├─ 辅助器具费（假肢等 × 更换周期）
│  ├─ 丧葬费 / 死亡赔偿金（致死情形）
│  └─ 被扶养人生活费
├─ 财产损失
│  ├─ 车辆维修费、施救费
│  ├─ 车载物品、随身物品
│  └─ 停运损失（营运车）
└─ 程序费用
   ├─ 鉴定费
   └─ 诉讼费（败诉方承担）

赔付计算
┌─ 第1层 交强险（有责/无责两档，限额内不分比例）
├─ 第2层 商业三者险（超出部分 × 责任比例）
└─ 第3层 侵权人个人（三者险不足 / 免赔 / 未购三者险）
```

## 八、三个险种对比速查

| 维度 | 交强险 | 商业三者险 | 车上人员险（司乘） |
|---|---|---|---|
| 赔谁 | **第三方**（你撞的人/车） | 第三方 | **你自己和乘客** |
| 是否强制 | 强制 | 自愿 | 自愿 |
| 是否按责任比例 | 否（限额内全额） | 是 | 是 |
| 常见保额 | 强制 12.2 万级别 | 100万–500万 | 每座 1万–10万 |
| 免责情形 | 故意、醉驾、无证、逃逸 | +未年检、不适驾、违反安全装载 | 类似 |
| 车损算吗 | 财产损失 2000 内 | 赔超出部分 | — |

> ⚠️ **你自己的车损和你车上的人，靠"车损险"和"车上人员责任险"，交强险和三者险都不赔自己。** 撞了护栏修自己的车，走的是车损险。

## 九、事故类型速判

| 事故类型 | 主要索赔项 | 前置条件 |
|---|---|---|
| 纯车损 | 维修费 + 施救费 | 责任认定 |
| 人伤未致残 | 医疗 + 伙食 + 营养 + 误工 + 护理 + 交通 | 医疗票据 + 医嘱/三期鉴定 |
| 人伤致残 | 上述 + **残疾赔偿金 + 精神损害抚慰金** | **伤残鉴定（必备）** |
| 致死 | 死亡赔偿金 + 丧葬费 + 被扶养人生活费 + 精神损害抚慰金 | 死亡证明 + 户籍关系 |
| 营运车 | 上述 + **停运损失** | 营运证 + 停运天数证明 |
