# 交通事故索赔时间线（按事件倒推：先算窗口，再排动作）

> 用法：把【待现场填写】的位置换成你的真实日期。**时间线排错了，材料再全也拿不到钱。**
> 图省事的人通常栽在三个窗口：复核 3 日、先鉴定后签字、2 年交强险时效。

---

## 第 0 步：先算三个倒计时（动手前先做这个）

| 事项 | 起算点 | 期限 | 逾期后果 |
|---|---|---|---|
| 事故认定书**复核** | 收到认定书之日 | **3 日** | 认定书生效，基本无从翻盘 |
| 交警**调解申请** | 收到认定书/车损确定之日 | 10 日 | 调解程序关闭，转自行协商或诉讼 |
| **诉讼时效**（人伤） | 知道权利受损之日（一般事故日） | **3 年**（民法典 188） | 丧失胜诉权 |
| **诉讼时效**（交强险财产） | 财产损坏之日 | **2 年**（保险法 26） | 财产部分更难主张 |
| **伤残鉴定时机** | 治疗终结 | 一般伤后 **3–6 个月** | 做早了等级低，做晚了拖过时効 |

> 保守做法：按**最早到期的那个**设提醒（通常财产 2 年）。

---

## 第 1 步：事发当天（T 日）

- [ ] 报警 + 报保险（没报警的，后面责任认定会很被动）【待现场填写】
- [ ] 拍照取证：全景、碰撞点、车牌、道路标线、交通信号、双方车牌
- [ ] 找目击者留联系方式
- [ ] 有人伤：立即送医，保留全部票据
- [ ] 别私了就走 —— 尤其是有人伤的

## 第 2 步：拿到认定书（一般 T+7 至 T+10）

- [ ] 去交警队领《道路交通事故认定书》【待现场填写日期】
- [ ] **先看责任划分对不对**（全责/主责/同责/次责/无责）
- [ ] 不服 → **3 日内**申请复核，别拖
- [ ] 认了 → 在清单里锁定对方保险信息

> 机动车与非机动车（行人）事故即使判同等责任，**机动车一方通常仍要担 60%** ——
> 这点很多人不知道，按 50% 谈就吃亏了。

## 第 3 步：治疗与固定证据（T+1 至 出院）

- [ ] 出院时**请医生在医嘱上写「加强营养」「建议护理 / 陪护」**
- [ ] 收集病历、诊断证明、费用明细、发票
- [ ] 保留所有交通票据
- [ ] 每周存一次照片，别只留聊天文字

## 第 4 步：鉴定（治疗终结后）

- [ ] 先向医生确认「治疗终结」的书面意见
- [ ] 委托有资质的司法鉴定机构（**别用对方指定的，除非别无选择**）
- [ ] 同时或另行做**三期鉴定**（误工期 / 护理期 / 营养期）
- [ ] 拿到报告：先看伤残等级 → 算系数（十级 10%、九级 20%…一级 100%）

## 第 5 步：算账（鉴定报告到手后）

先算交强险（有责）：
```
死亡伤残项：限额 180,000   → 残疾赔偿金 + 精神损害抚慰金 + 被扶养人生活费 先填这里
医疗费用项：限额  18,000   → 医疗费 + 住院伙食补助 + 营养费 + 后续治疗费
财产损失项：限额   2,000   → 车损 + 随身/车载物品
三者保险：  (总损失 − 交强险各分项) × 责任比例
侵权人：    三者险赔完仍不足的部分
```
【待现场填写：总损失 ____ 元 / 交强险分项 ____ / 责任比 ____%】

## 第 6 步：谈（别在这步签字）

- [ ] 带着自己算的清单去谈，**先报总额，别让对方先开价**
- [ ] 逐项问：这一项为什么给/不给
- [ ] 对方每条拒赔理由都记下来，逐条回怼（见《拒赔抗辩分析》模板）
- [ ] 每 6–12 个月发一次**书面催告**（微信文字即可，要求对方回复）→ 时效中断
- [ ] **签字前必须做完鉴定** —— 签了「一次性了结」再发现伤残，基本要不回来了

## 第 7 步：签字 / 打款 / 留痕

- [ ] 调解协议写清：项目清单 + 金额 + 付清时间 + 「再无其他主张」
- [ ] 走银行转账，别收现金
- [ ] 到账后把流水截图存档
- [ ] 还有缺口 → 拿协议 + 转账记录去起诉

## 第 8 步：五条途径（谈不拢时按顺序走）

1. **自行协商** —— 最省事，但要有心理准备对方不认账
2. **交警调解** —— 需在**收到认定书起 10 日内**书面申请，过时关闭
3. **保险理赔** —— 直接找对方保险公司，走交强险 + 三者险
4. **人民调解委员会** —— 交警队可移送，不收费
5. **向法院起诉** —— 人伤 3 年、财产 2 年；标的额小的走**小额诉讼**，一审终审、诉讼费很低

> 管辖：一般由**事故发生地**或**被告住所地**法院管。
> 上海地区交通事故人伤案件诉讼费极低（1 万以下 50 元），别被「打官司很贵」劝退。

## 微信催告模板（可直接复制改）

> 催告的核心是：**明确表达要求 + 给出期限 + 指向后果 + 留在可查的文字里**。

** mild 版（对方态度还行）：**
> 上次聊的赔偿这块，我这边材料都齐了（医疗费我垫了 ____ 元，鉴定做了 ____ 级）。
> 麻烦这周内给个具体方案，我们要是没收到回复就按法定项目自己算一版了。

** 强硬版（拖了三个月以上）：**
> 本次事故自 ____ 年 ____ 月 ____ 日发生至今已 ____ 天，我方多次催告未获实质回应。
> 现正式催告：请在 7 日内就赔偿方案给出明确答复并支付；逾期我将向 ___ 人民法院提起诉讼，
> 届时所有诉讼费用及因此产生的律师费等将由贵方承担，并同步向保险监管机构反映。
> 本条微信作为时效中断的证据保留。

> 提醒：催告留痕要**可查、可导出、可公证**。微信转账、语音转文字、对方已读回执都是加分项。
