# 微信聊天记录转交通事故索赔材料

撞了人、被撞了，或者对方在微信里拖着不给钱——你手里的聊天记录其实已经把案子的骨架说清楚了：
什么时候撞的、责任怎么分的、住了几天院、做了几级伤残、给了多少、拖了多久。
问题是这些散在几百条消息里，你没人在旁边帮你把它们变成一张能用的清单。

这个技能就是干这个的。倒进聊天记录，本机跑一遍，出来的是**缺什么、有什么、还剩几天、对方哪句话站不住**。

---

## 为什么不能只靠 AI 聊天

你把聊天记录贴给通用 AI，它会给你一段「建议先报警、注意诉讼时效」的正确废话。
缺的东西是三样实打实的：**结构化抽取**、**本地可复跑**、**离线不出数据**。

- 通用 AI 看不见你 2000 条里的第 1376 条说了句「医嘱只写了一个月」——这条恰恰决定护理费能算多久
- 通用 AI 每次问都要重新贴一遍全部记录，而且你没法让它反复核对票据
- 更关键的：聊天记录是隐私数据，贴出去就不可控了

这个技能在你自己机器上跑，用 Python 标准库，不联网、不上传。

## 四种场景，一套骨架

| 场景 | 覆盖要件 | 典型问题 |
|---|---|---|
| **injury 人伤** | 17 项 | 医嘱有没有写「加强营养」「建议护理」？误工期多久？十级伤残能赔多少？ |
| **property 车损** | 9 项 | 定损单和维修发票对不对得上？停运损失算不算？随身物品要不要价值凭证？ |
| **fatal 致死** | 9 项 | 死亡证明、丧葬费、被扶养人关系、直系亲属继承顺序 |
| **all 全查** | 35 项 | 分不清是车损还是人伤，先全扫一遍再定 |

## 报告八段（导出即为成品）

1. **结论先行** —— 要件覆盖率、**时效剩余天数**、伤残等级系数、交强险限额、金额笔数、拒赔条数
2. **要件命中表** —— 每条命中几处、命中了哪个关键词，一眼看出哪块松动了
3. **缺失要件与补强方向** —— 聊天里没提到 ≠ 没有材料，标出去交警队／医院／银行哪里补
4. **争议焦点** —— 对方每条拒赔原话单列，底下挂破局法条
5. **关键程序节点** —— 报警、认定书、复核、医疗、鉴定、定损、拒赔、到账、催告
6. **金额梳理** —— 每笔带时间和上下文，供和票据逐笔交叉核对
7. **关键证据片段** —— 附一句「别只截有利片段」
8. **下一步行动清单** —— 按优先级排好

## 六类拒赔话术，逐条对表

对方和理赔员最爱说的，都有固定拆解：

- 「我们只赔交强险，超出的不赔」→ 1213 条：交强险之后还有三者险，按责任比
- 「你旧伤是之前落下的」→ 要证明关联度／加重因素，做因果关系鉴定
- 「医嘱只写一周」→ 三期鉴定说话，营养／护理期不以医嘱天数为准
- 「没住院不给护理费」→ 护理看护理事实，不以住院为唯一门槛
- 「十级伤残不算」→ 系数 10%，构成即赔
- 「手机坏了不属赔偿范围」→ 随身物品属财产损失，但要价值凭证

完整拆解表里还有责任类、项目类、金额类、程序类共二十来种说法，
每条对应「法律依据 + 我方回应 + 要补什么材料」。

## 三个算错就少拿一大截的地方

**第一层：先交强险，再责任比。**
交强险有责限额内不打折全额赔（死亡伤残 18 万 / 医疗费用 1.8 万 / 财产 2000），
超出部分才 × 责任比例走商业三者险，还不足由侵权人赔。很多人在聊天里被对方一开价就顺着谈，
结果从头到尾都在按「总损失 × 责任比」算，白白少拿一大块。

**第二层：医嘱上那两行字。**
「加强营养」「建议护理 / 陪护」——没有这两行，营养费和护理费基本赔不了。
要么出院时请医生补写，要么做三期鉴定。

**第三层：事发前 12 个月工资流水。**
误工费全靠它。没有流水法院按最低工资算，月薪一万和按最低标准，差出来的钱可能比伤残赔偿金还多。

## 参数怎么用得上

```bash
# 全量扫描
python scripts/extract.py --file 聊天记录.md

# 只盯人伤，看还剩几天时效
python scripts/extract.py --file 聊天记录.md --scenario injury --as-of 2026-09-01

# 对方一直在扯皮，只看拒赔相关消息
python scripts/extract.py --file 聊天记录.md --focus 拒赔

# 要拿去别处处理
python scripts/extract.py --file 聊天记录.md --format json --out out.json
```

`--focus` 认类别也认字面词：拒赔 / 金额 / 鉴定 / 时效 / 保险 / 医疗 / 责任，
也可以传任意词比如「伤残鉴定」。真人在微信里不会写「拒赔」两个字，说的是「不赔」「只赔交强险」，
所以类别匹配把常见说法都收进去了。

## 边界在哪

- 它是**材料整理和规则对照**，不是律师。涉及死亡、伤残鉴定结论、或者金额较大的，签字前务必找律师
- 它给计算口径，不给判决预测
- 它不替你编事实——需要你现场确认的，模板里直接标【待现场填写】
- 引用的法条有时效性，提交前请核对自己那份条文是不是现行有效

## 顺带的 nudges

- 拿到认定书**3 日内**还能复核，过了基本翻不了盘——报告里会顺手提醒
- 签字和解之前，伤残鉴定必须已经做完。签了「一次性了结」再发现等级不够，基本要不回来
- 每 6–12 个月发一次书面催告（微信文字即可），维持时效中断，这步别省

需要先把微信本地聊天库导出来的，配套技能 `wechat-local-reader-tianbao` 是同样的零上传本地方案。
