# 微信聊天记录转交通事故索赔材料

被撞了、撞人了，或者对方一直在微信里扯皮不给钱——把微信聊天记录倒进来，
本地脚本扫出**赔偿要件命中与缺口**、**金额清单**、**程序时间点**和**时效倒计时**，
再按模板整理成能提交的东西。全程在本机跑，聊天记录不上传。

## 硬边界（先读，别越界）

| 能做 | 不能做 |
|---|---|
| 扫描聊天记录、提取金额与时间节点 | 不代写起诉状终稿（给结构和模板，不替你定稿） |
| 列出赔偿项目缺什么、去哪里补 | 不预测法院会判多少（只给计算口径，不给结果承诺） |
| 算交强险/三者险/责任比的**计算口径** | 不代替律师专业意见（死亡、伤残、金额超 5 万要找律师） |
| 拆解对方每条拒赔理由对应的法条 | 不编造任何你的案件里没有的事实 |
| 生成材料清单、时间线、催告话术 | 不能帮你伪造、剪辑、只截有利片段 |

## 三步上手

```bash
# 1) 先把聊天记录导成本地文件（每行一条：日期 + 发送者 + 内容）
python scripts/extract.py --file 聊天记录.md --scenario injury

# 场景：injury 人伤 | property 车损 | fatal 致死 | all 全部（默认 all）
python scripts/extract.py --file 聊天记录.md --scenario all --format json
```

支持的输入行格式（导出时保持一致即可）：

```
[2026-05-12 18:42] 陈立: 人没事吧我马上打120
[2026-05-20 15:40] 周敏: 认定书拿到了 我主要责任 你次要责任
```

常用参数：

| 参数 | 作用 |
|---|---|
| `--scenario` | `injury` 人伤 / `property` 车损 / `fatal` 致死 / `all` 全查（默认） |
| `--as-of YYYY-MM-DD` | 时效基准日，默认今天。**临期案件用它倒推还剩几天** |
| `--focus 拒赔` | 只看拒赔相关消息；也支持 `金额` `鉴定` `时效` `保险` `医疗` `责任` 或任意字面词 |
| `--format json` | 输出 JSON，便于自己二次处理 |
| `--out 文件` | 写入文件，不打印到终端 |

## 报告里有什么

1. **结论先行** —— 要件覆盖率、时效剩余天数、伤残等级、交强险限额、金额数、拒赔条数
2. **要件命中表** —— 事故认定书、责任比例、医嘱营养/护理、误工期、护理期、伤残鉴定、后续治疗费等 **人伤 17 项**；车损 9 项；致死 9 项
3. **缺失要件与补强方向** —— 聊天里没提到≠没有，标出去哪里补
4. **争议焦点** —— 把每条拒赔/推诿原话列出来，附破局法条（1213 / 1179 / 188 / 3 日复核）
5. **关键程序节点** —— 报警、认定书、复核、医疗、鉴定、定损、拒赔、到账、催告
6. **金额梳理** —— 每笔金额 + 时间 + 上下文，供和票据交叉核对
7. **关键证据片段** —— 提示不要只截有利片段
8. **下一步行动清单**

## 三个最容易少拿钱的地方（先看这个）

1. **先算交强险，再谈责任比例。** 交强险有责限额内**全额赔、不打折**（死亡伤残 18 万 / 医疗费用 1.8 万 / 财产 2000），超出部分才 × 责任比走三者险。一上手就把总损失 × 责任比，必然少拿一大截。
2. **医嘱上必须有两个词：「加强营养」「建议护理」。** 没有这两行字，营养费和护理费基本赔不了；要么让医生补写，要么做三期鉴定。
3. **误工费全靠事发前 12 个月工资流水。** 没有流水法院按最低工资算，月薪 1 万和按最低标准算能差好几倍。

## 隐私

`extract.py` 只用 Python 标准库，**不联网、不上传、不写外部文件**（除你显式给的 `--out`）。
聊天记录全程留在你的机器上。需要导出微信本地库的话，配套技能 `wechat-local-reader-tianbao`
是同样零上传的本地方案。
