# 微信聊天记录转排班考勤

夜班上了半年、法定节假日一次没落下、加班费一条没发——
这些事全在微信里：主管发排班、你回「收到」、月底他说「算值班不算加班、没审批、我们是不定时工时」。

这个技能把聊天记录倒进来，本机扫一遍，告诉你
**班钉没钉死、夜班算几小时、加班费该按哪一档算、单位哪句话在赖账、时效还剩几天**，
再给你能直接抄去算的加班费表和仲裁申请结构。

## 硬边界（先读）

| 能做 | 不能做 |
|---|---|
| 抽班次时间、算跨天时长与小时数 | 不代写仲裁申请书终稿（给结构，不替你定稿） |
| 判断「值班 vs 加班」、拆单位七大抗辩 | 不预测裁决会判多少 |
| 给加班费 150%/200%/300% 计算口径 | 不代替律师（金额大、涉及违法解除要找律师） |
| 算仲裁时效倒计时（含在职不受 1 年） | 不编造你案件里没有的事实 |
| 列材料缺口与补强渠道 | 不能伪造、剪辑、只截有利片段的记录 |

## 三步上手

```bash
# 1) 聊天记录导成本地文件，每行一条
python scripts/extract.py --file 聊天记录.md

# 场景：roster 排班考勤 | overtime 加班费 | leave 假期离职 | all 全部（默认）
python scripts/extract.py --file 聊天记录.md --scenario overtime

# 2) 看时效还剩几天（基准日可指定）
python scripts/extract.py --file 聊天记录.md --as-of 2026-09-01

# 3) 只看排班 / 只看对方怎么赖账
python scripts/extract.py --file 聊天记录.md --focus 排班
python scripts/extract.py --file 聊天记录.md --focus 拒付
```

输入行格式：

```
[2025-11-18 16:20] 王主管: 十二月排班 5号白班9点到18点，6号夜班22点到6点
[2025-11-18 16:35] 小李: 收到，6号夜班我上
```

参数：

| 参数 | 说明 |
|---|---|
| `--file` | 聊天记录文件（.md / .txt），必填 |
| `--scenario` | roster 排班考勤 / overtime 加班费 / leave 假期离职 / all（默认） |
| `--as-of` | 时效基准日 YYYY-MM-DD，默认今天 |
| `--focus` | 只看含该词/类别的消息。类别：排班、加班、调休、拒付、时效 |
| `--format` | md（默认） / json |
| `--out` | 输出文件；不填打印到终端 |

## 报告九段

1. **结论先行** —— 覆盖率、抽出几个班次共几小时、时效剩余天数、**在职/离职判定**
2. **要件命中表** —— 排班 8 项 / 加班 10 项 / 假期 6 项，标了**举证方在谁**
3. **缺失要件与补强方向** —— 考勤去哪要、台账谁保管、不定时工时要什么批复
4. **争议焦点** —— 对方每条「算值班/没审批/不定时」原话 + 破局法条
5. **⭐ 班次抽取** —— 日期 / 班次类型 / 起止 / 是否跨天 / 时长，逐条列
6. **主张表述质量评估** —— 每条催告按「日期 / 时段 / 小时数 / 主张」四项打分
7. **关键程序节点** —— 排班通知、收到确认、加班安排、考勤、调休、拒付、协商、法律途径
8. **关键证据片段**
9. **下一步行动清单**

## 三个别人不说的点

**一、夜班是跨天的，别少算两小时。**
22:00–6:00 是 **8 小时**，不是 6 小时。脚本会把跨天班单独标出来。

**二、值班 ≠ 加班，但要按三步拆。**
看「能不能干私事 / 有没有业务产出 / 有没有休息条件」。
消防控制室是争议高发区——要盯火警、要应急处置、要填记录的，多数地区倾向**算加班**；
纯坐岗待命、能自由活动还有休息位的，才算值班。

**三、在职期间追讨加班费，不受 1 年限制。**
加班费属劳动报酬（《劳动争议调解仲裁法》第 27 条第 3 款第四项），
**只要你还在职，就没过时效**；离职那天才开始跑 1 年。
很多人自己吓自己，离职三个月就以为废了——没废。

## 中文写法是真的会碰到的

排班通知里最常见的是「**9点到18点**」「**22点到6点**」「**二十二号夜班**」，
不是 `9:00-18:00`。第一版脚本只认冒号，直接抽不到；少了「几号」也定位不了日期。
现在四种写法都吃：

| 写法 | 抽出来 | 时长 |
|---|---|---|
| `9:00-18:00` | 09:00–18:00 | 9 h |
| `9点到18点` | 09:00–18:00 | 9 h |
| `22点到6点` | 22:00–06:00（跨天） | 8 h |
| `22:00~6:00` | 22:00–06:00（跨天） | 8 h |

一句话排多个班（`5号白班9点到18点，6号夜班22点到6点`）会**逐个抽出来**，
还会各自认自己的班次类型，而不是全算成夜班。
