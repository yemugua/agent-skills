# 微信聊天记录转排班考勤

主管在群里发排班：「5号白班9点到18点，6号夜班22点到6点」
你回：「收到，6号夜班我上」
月底一算：加班费一分没有，回一句「算值班不算加班、没审批、我们是不定时工时制」。

聊天记录里那一句「收到，6号夜班我上」——**是整个案子里最值钱的九个字**。
排班通知 + 对方确认 = 加班事实直接钉死，比十张截图都顶用。

这个技能把聊天记录倒进来，本机跑一遍，告诉你**班钉没钉死、夜班算几小时、单位哪句话在赖账、时效还剩几天**，
再给你能直接抄去算的加班费表和仲裁申请结构。

---

## 为什么通用 AI 帮不上排班考勤

把聊天记录贴给通用 AI，它给你一段「建议保留证据、注意劳动仲裁时效」的正确废话。
缺的是三样：**结构化抽取**、**可复跑**、**聊天记录不出本机**。

- 通用 AI 看不见你 200 条里的第 63 条「收到，24号夜班22点到6点」——
  这一条既是排班确认，又是加班事实，还顺手把日期钉死了
- 通用 AI 每次问都要重贴全部记录，你没法让它反复核对你第 47 条到底写的几点到几点
- 而且聊天记录是隐私，贴出去就不可控

这个技能在你机器上跑，Python 标准库，不联网、不上传。

## 三个场景，一套骨架

| 场景 | 典型 | 要证明什么 |
|---|---|---|
| **roster 排班考勤** | 排班表、夜班、倒班 | 排班了 + 你确认了 + 上过了 |
| **overtime 加班费** | 加班没给钱、值班算不算加班 | 加班事实 + 时长 + 倍率 + 基数 |
| **leave 假期离职** | 未休年假、离职结算、没签合同 | 年假天数 + 折算 + 二倍工资 |
| **all 全查** | 分不清是哪类 | 三套都扫一遍再定 |

共同骨架只有一句：**证明「排了班 + 你上过 + 上了多久 + 该按几倍算 + 他没给」。**

## 报告九段

1. **结论先行** —— 覆盖率、抽出的班次与总小时、时效剩余天数、在职/离职判定
2. **要件命中表** —— 排班 8 项 / 加班 10 项 / 假期 6 项，**标了举证方在谁**
3. **缺失要件与补强方向** —— 考勤去哪要、台账谁保管、不定时工时要什么批复
4. **争议焦点** ——「算值班」「没审批」「不定时」每条原话 + 破局法条
5. **⭐ 班次抽取** —— 日期/类型/起止/是否跨天/时长，逐条列
6. **主张表述质量评估** —— 每条催告按「日期/时段/小时数/主张」四项打分
7. **关键程序节点** —— 排班通知、收到确认、加班安排、考勤、调休、拒付、协商、法律途径
8. **关键证据片段**
9. **下一步行动清单**

## 最值钱的功能一：把夜班算对

夜班是跨天的，这是加班费里最容易白丢的两小时。

```
22:00 – 6:00  →  8 小时（不是 6 小时）
```

脚本会把跨天班单独标出来，也认四种中文写法：

| 写法 | 抽出来 | 时长 |
|---|---|---|
| `9:00-18:00` | 09:00–18:00 | 9 h |
| `9点到18点` | 09:00–18:00 | 9 h |
| `22点到6点` | 22:00–06:00（跨天） | 8 h |
| `22:00~6:00` | 22:00–06:00（跨天） | 8 h |

一句话排多个班（`5号白班9点到18点，6号夜班22点到6点`）会**逐个抽出来**，
各自认自己的班次类型——不是整句一起压成「夜班」。

## 最值钱的功能二：给你的催告打分

催加班费这件事，**催了不等于有效**。

「在吗？」「钱呢？」「??」——法律上不认定为你提出了权利主张，时效照走。
「11月两个夜班、12月元旦三天，共 43 小时，小时工资 20 元，应补 1290 元，这周结一下」——
日期、小时数、金额、主张，四样齐了。

脚本把每条按四项打分，**≤2 分的直接标警告**，告诉你哪条该怎么补写。

## 最值钱的功能三：分清值班和加班

单位拒付加班费的第一句话永远是「这算值班，不算加班」。
拆它只需要三步：

1. **能不能干私事** —— 允许玩手机、自由走动、能离岗 → 更像值班
2. **有没有业务产出** —— 只是「看着不出事」，还是要处置、要记录、要履职
3. **有没有休息条件** —— 有床有休息位，和只能坐控制室熬一整晚，不是一回事

**消防控制室是争议高发区**：要盯火警、要应急处置、要填值班记录的，多数地区倾向**算加班**。

## 一个很多人自己吓自己的点

**在职期间追讨加班费，不受 1 年限制。**

加班费属劳动报酬（《劳动争议调解仲裁法》第 27 条第 3 款第四项），
只要你还在这班上，时效就没开始跑；**离职那天才起算 1 年**。

很多人离职三个月就以为「过时效了，算了」，其实完全没过。

## 加班费三档，别混成一个总数

| 情形 | 倍率 | 能不能补休替代 |
|---|---|---|
| 工作日延长 | **150%** | ❌ 必须给钱 |
| 休息日（周末） | **200%** | ✅ 可以补休；不补休就得给钱 |
| 法定节假日 | **300%** | ❌ **不能调休替代** |

顺手核一项常被漏掉的：入职满 1 个月没签书面劳动合同 → **二倍工资**，最高 11 个月，
金额经常比加班费还高。

## 参数怎么用得上

```bash
# 全量扫描（默认 all）
python scripts/extract.py --file 聊天记录.md

# 只看加班费，看时效还剩几天
python scripts/extract.py --file 聊天记录.md --scenario overtime --as-of 2026-09-01

# 对方一直扯皮，只看他怎么推脱
python scripts/extract.py --file 聊天记录.md --focus 拒付

# 只看排班相关
python scripts/extract.py --file 聊天记录.md --focus 排班

# 拿去别处处理
python scripts/extract.py --file 聊天记录.md --format json --out out.json
```

## 边界在哪

- 它是**材料整理和规则对照**，不是律师。金额大、涉及违法解除、时效快到了，签字前找律师
- 它给计算口径（150%/200%/300%、年假 200%、小时工资怎么算），不给裁决预测
- 它不替你编事实——需要你现场确认的，模板里直接标【待现场填写】
- 各地对「值班 vs 加班」「二倍工资时效」裁审口径有差异，提交前按当地核一遍

需要先把微信本地聊天库导出来的，配套技能 `wechat-local-reader-tianbao` 是同样的零上传本地方案。
