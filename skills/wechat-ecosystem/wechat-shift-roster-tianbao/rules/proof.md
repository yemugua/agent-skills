# 排班考勤的微信取证（什么能当证据、单位怎么狡辩）

> 加班费官司打赢打不赢，八成取决于**你手里那几张排班截图行不行**。
> 微信排班通知在实务中**是被认的**——它是单位管理行为的直接体现。

---

## 一、微信记录的法律位置

和所有微信证据一样，排班记录属于**电子数据**（《民事诉讼法》第 66 条证据种类、
《最高人民法院关于民事诉讼证据的若干规定》第 14 条第四项）。

过三关：

| 关 | 要什么 | 排班场景怎么满足 |
|---|---|---|
| **真实性** | 原生、未篡改 | 完整导出，别只截通知那一条；重要月份录屏（从群聊点进通知，显示群名/时间） |
| **完整性** | 前后连贯 | 一个月的排班要从头到尾导，别只截"上夜班"那几行 |
| **关联性** | 能证明谁、什么时候、什么班 | 群名明确、时间明确、班次明确——**三样缺一样都弱** |

## 二、微信排班记录的证明力分级（⭐ 重点）

同样一句"排班通知"，不同写法的分量差很远：

| 强度 | 典型表述 | 为什么值钱 |
|---|---|---|
| ★★★★★ | 「本周排班：23号白班 9:00–18:00，23号夜班 22:00–6:00，收到请回复」 | 时间 + 班次 + 管理行为 + 要求确认 → **全** |
| ★★★★★ | 「这周三到周五我上夜班，晚上10点到早上6点」 | 你自己在群里说 = 自认 + 单位未否认 |
| ★★★★ | 「下周六要加班，大家注意」 | 有安排、有时间，但没写几点几点 |
| ★★★ | 「周六别缺席」 | 只说明要来，没时长 |
| ★★ | 群里发了个表格图片 | 有内容但要靠 OCR/辨认，最好配合文字复述 |
| ★ | 「排班表发你了」「看下群公告」 | 指向了东西，但**没把内容固定下来** |

> ⭐ **最强的一招：对方一回复「收到」两个字。**
> 排班通知 + 对方确认 = 单位认可"我安排了、你认了"，整个加班事实就钉死了。
> 所以收到排班通知，**别只看一眼就划走，回一句"收到"并顺便复述一遍时间**。
> 哪怕回「收到，23 号夜班 10 点到 6 点」——这一句顶十张截图。

## 三、单位七大抗辩（排班考勤高频）

| # | 单位说法 | 怎么拆 |
|---|---|---|
| 1 | 「那是排班意向，不是让你真上」 | 你实际去了、有考勤 = 已履行，意向不能反悔 |
| 2 | 「加班要审批，你没走流程」 | 审批制度要**公示/告知过**；且单位**实际安排**的加班，不因没申请而免付 |
| 3 | 「已经调休抵了」 | 休息日可以补休；**法定节假日不能补休**，必须给 3 倍 |
| 4 | 「我们是不定时/综合工时」 | 要**人社部门批复**；没有就按标准工时算 |
| 5 | 「打卡记录显示你没上那么久」 | 要求他提供**完整**考勤；对不上的部分争议由他举证 |
| 6 | 「工资已经含加班费了」 | 要他举证**分项和算法**；笼统写"含"不成立 |
| 7 | 「这是值班，不是加班」 | 按「能不能干私事 / 有没有产出 / 有没有休息条件」三步拆 |

## 四、值班 vs 加班：三步判断（对方说"是值班"时用）

1. **能不能干私事？** 值班时睡了觉、玩了手机、能离开 → 值班；被锁死在岗、不能离 → 加班
2. **有没有业务产出？** 在干活、在生产、在处理本职业务 → 加班；只是"人在这儿待命" → 值班
3. **有没有休息条件？** 有床、有休息室、能躺 → 值班；椅子坐着不能动 → 加班

> 消防控制室、监控室、门卫夜岗这类：**人在岗、不能睡、得随时 responding**——
> 实务大多按**加班**处理（或至少认定"值班也应给津贴，不能零报酬"）。
> 这个岗位特别适合拿来做例子。

## 五、六种取证手段（递进，越往后越硬）

1. **截图** —— 最快，单张弱，但群聊排班记录截图 + 群名完整，实务中够用
2. **完整导出文本** —— 保留时间线，能从"通知了 → 确认了 → 实际上了"连起来
3. **录屏** —— 从群聊列表点进群 → 打开排班通知 → 上下滑动，**显示群名、发送者、时间**
4. **往回补文字** —— 事后在群里问一句「那 23 号晚上我是不是 10 点到 6 点来着？」让他回「对」
5. **时间戳 / 区块链存证** —— 金额大（几个月的加班费）才值得
6. **公证** —— 一般不用。成本几百到几千，不如把精力花在逐小时算清楚上

> 性价比排序：**第 3 录屏 > 第 2 导出 > 第 1 截图 > 第 4 补问 > 第 5/6**。
> 别一上来公证——欠 3000 块花 2000 做公证，不如花 10 分钟录屏 + 逐天算表。

## 六、必须补的外部凭证（微信之外）

| 凭证 | 从哪来 | 作用 |
|---|---|---|
| **考勤记录** ⭐ | 钉钉/企微导出、打卡机导出（**向单位索要，不给就申请仲裁责令提供**） | 证明实际时长 |
| **工资条 / 银行流水** ⭐ | 单位发 / 银行柜台打印带章 | 看有没有"加班费"分项、基数多少 |
| **劳动合同** ⭐ | 入职时签的，单位必须给一份 | 工时制度、工资标准、岗位 |
| **加班审批记录** | 单位系统 | 他拿来抗辩，你提前要一份 |
| **调休记录 / 请假单** | 单位系统 | 证明调没调、调了几天 |
| **门禁 / 监控** | 可向单位或物业申请调取 | 证明在岗（注意隐私边界，别非法获取） |
| **工作群时间戳** | 微信/企微导出 | 夜里 2 点在群里发工单 = 在岗痕迹 |
| **同事证言** | 同岗同事 | 补强用，一个两个不够，多个更有力 |

> 考勤记录保存义务：按《工资支付暂行规定》第 6 条，单位须将工资支付台账保存 **2 年以上**备查。
> 所以 2 年内的加班费主张，他躲不掉。

## 七、提交前自查 13 项

- [ ] 排班通知有没有**具体时间**（几点到几点）
- [ ] 有没有写明是**白班/夜班/通宵**
- [ ] 对方有没有**回复确认**（"收到"最好，能复述时间更好）
- [ ] 是群通知还是私聊——群通知更好证明"管理行为"
- [ ] 考勤记录拿到了吗（没拿到就申请仲裁责令单位提供）
- [ ] 逐天算清楚了吗：**工作日 / 休息日 / 法定节假日** 分开了吗
- [ ] 法定节假日那几天单独拎出来了吗（**不能调休**）
- [ ] 加班费基数怎么定的？合同有约定吗？没约定按正常出勤工资
- [ ] 小时工资算对了吗（月工资 ÷ 21.75 ÷ 8）
- [ ] 二倍工资（没签合同）算进诉求了吗
- [ ] 未休年假结了吗（离职时一次性结）
- [ ] 还在职吗？在职的话加班费**不受 1 年时效限制**
- [ ] 离职的话，离职那天起算 1 年，够不够时间申请

## 八、常见错误

| 错误 | 后果 |
|---|---|
| 只截"我上夜班"这几行，没带群名和时间 |  authenticity 被质疑，认可度降一截 |
| 把单位发的排班表图片存了，但从没让对方确认 | 图片可以否认"看不清/不是这个版本" |
| 只有口头排班，从没留文字 | 全靠别人记忆，最容易输 |
| 把"值班"当"加班"一起要（或反过来） | 项目定性错了，金额算错，还显得不专业 |
| 一次性算"经常加班"不给小时数 | 仲裁委算不了，支持不了 |
| 超过 2 年太久远的部分硬要 | 单位台账没了，你也说不清，按比例风险 |
| 直接去法院 | 不受理，白跑 |
| 签了"自愿放弃加班费"就以为没了 | 这类协议通常无效，照样能要 |
