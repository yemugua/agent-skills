# 加班费计算表（自己先算一遍）

## 一、先定工时制度（定错了整张表白算）

| 制度 | 认定标准 | 加班费怎么给 |
|---|---|---|
| **标准工时** | 每天 8 小时、每周 40 小时，默认 | 按下面三档正常算 |
| **综合计算工时** | 以周/月/季/年为周期，需要**人社部门批复** | 周期内总超时才算加班，按 150%/300% |
| **不定时工时** | 同样要**人社部门批复** | 一般不算加班（法定节假日例外，另行按规定） |

> 单位说「我们是综合/不定时」，**让他拿出人社局的批复**。
> 拿不出来 → 一律按标准工时算。这是最常见的翻盘点。

## 二、算小时工资基数

```
年工资 ÷ 12 = 月工资
月工资 ÷ 21.75 = 日工资
日工资 ÷ 8 = 小时工资        ← 加班费一律按小时工资算
```

- 合同有约定按约定；没约定按**正常出勤工资**（含岗位工资、绩效、补贴中固定发放的部分）
- 下限：不得低于当地最低工资标准
- 别让他按「最低工资」糊弄你

【待现场填写】月工资 = ______ 元　→　小时工资 = ______ 元

## 三、三档倍率（《劳动法》第 44 条）

| 情形 | 倍率 | 能不能用补休替代 |
|---|---|---|
| 工作日延长工作时间的加班 | **150%** | ❌ 不能，必须给钱 |
| 休息日（周末）安排工作 | **200%** | ✅ 可以安排补休；不补休就得给钱 |
| 法定休假日（元旦/春节/清明/劳动/端午/中秋/国庆） | **300%** | ❌ **不能调休替代**，必须给钱 |

> **值班 ≠ 加班**（下面第四部分单独说）——夜班、值守、待命要按三步判断。

## 四、值班还是加班：三步判断

1. **能不能干私事** —— 允许玩手机、自由走动、能离岗 → 更像值班
2. **有没有业务产出** —— 只是「看着不出事」，还是有具体活要干、要处置、要记录
3. **有没有休息条件** —— 有床有夜宵有休息位，和只能坐在控制室熬整晚，不是一回事

**消防控制室值班是争议高发区**：多数地区倾向——
如果值班期间**实际在岗履职**（要盯火警、要应急处置、要填记录），**算加班**；
如果纯粹坐岗待命、能自由活动、还有休息条件，才算值班（按值班津贴，一般远低于加班费）。

| 【待现场填写】 | | | | | | 工作日加班 | 150% | |
| | | | | | | 休息日加班 | 200% | |

**金额 = 小时工资 × 倍率 × 时长**

小抄：
- 工作日 1 小时 = 小时工资 × 1.5
- 休息日 1 小时 = 小时工资 × 2
- 法定节假日 1 小时 = 小时工资 × 3
- 夜班 22:00–6:00 = **8 小时**（跨天，别按 6 小时算）

## 六、未休年假折算（离职必结）

```
应休天数：满 1 年不满 10 年 = 5 天；满 10 年不满 20 年 = 10 天；满 20 年 = 15 天
（新入职或离职当年，按当年已过日历天数折算：应休 = (当年已过天数 ÷ 365) × 全年应休）
折算金额 = 日工资 × 应休未休天数 × 200%   （另 100% 是正常工资，所以是额外 200%）
```

【待现场填写】已休 ____ 天，未休 ____ 天 → 折算 ________ 元

## 七、容易被漏掉的一项：未签书面合同

```
入职满 1 个月起满 1 年没签书面劳动合同 → 二倍工资（差额那一倍），最高 11 个月
```
时效：一般用**在职期间 + 离职后 1 年**（各地裁审口径有差异，别拖）。
**金额往往比加班费高，算加班费时顺手核一下这个。**

## 八、单位七大抗辩 & 反手

| 他说 | 你回 |
|---|---|
| 没有加班审批 | 制度**公示告知过我**吗？实际安排的加班不因没申请而免付 |
| 算值班不是加班 | 按「能不能干私事／有没有业务产出／有没有休息条件」三步拆 |
| 我们是不定时工时 | 拿**人社部门批复**出来，没有就按标准工时 |
| 考勤上没有 | 考勤、工资台账**你保管 2 年以上**，你拿不出 → 对单位不利的认定 |
| 加班费含在工资里了 | 工资条分项呢？计算方式呢？笼统「含」不成立 |
| 已经给你调休了 | 什么时候调的？休息日能补休，法定节假日**不能补休** |
| 过时效了 | 我还在职（或离职不满 1 年），追讨加班费**不受 1 年限制** |
