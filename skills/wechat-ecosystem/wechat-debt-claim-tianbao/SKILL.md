# 微信聊天记录转催款材料

借出去的钱要不回来、干完的活尾款拖着、货款结不掉、工程质保金到期不退——
这些事在微信里聊过几百条，但**你手里真正有用的信息只有几句**：
哪天借的、说好哪天还、还了多少、还剩多少、催过几次、他哪句话算认账。

这个技能把聊天记录倒进来，本机扫一遍，告诉你**债有没有钉死、还剩多少钱、催告有没有效、三年时效还剩几天**，
再给你能直接复制发出去的催告话术。

## 硬边界（先读）

| 能做 | 不能做 |
|---|---|
| 扫描聊天记录、提取金额与日期 | 不代写起诉状终稿（给结构，不替你定稿） |
| 判断催告表述有没有效（四要素打分） | 不预测法院会判多少 |
| 拆解对方拒付抗辩与举证责任归属 | 不代替律师（金额大、对方不认账、临近时效要找律师） |
| 列材料缺口与补强渠道 | 不编造你案件里没有的事实 |
| 给催告话术模板与途径选择 | 不能伪造、剪辑、只截有利片段的记录 |

## 三步上手

```bash
# 1) 聊天记录导成本地文件，每行一条
python scripts/extract.py --file 聊天记录.md

# 场景：loan 借贷 | goods 货款服务费 | project 工程款 | all 全部（默认）
python scripts/extract.py --file 聊天记录.md --scenario loan

# 2) 看三年时效还剩几天（基准日可指定）
python scripts/extract.py --file 聊天记录.md --as-of 2026-09-01

# 3) 只看催告相关 / 只看拒付说法
python scripts/extract.py --file 聊天记录.md --focus 催告
```

输入行格式：

```
[2025-03-12 14:20] 老周: 小王 手头急用两万 能不能先借我
[2025-03-12 14:35] 小王: 行 我转你20000元 下个月还我
```

参数：

| 参数 | 作用 |
|---|---|
| `--scenario` | `loan` 借贷 / `goods` 货款服务费 / `project` 工程款 / `all` 全查（默认） |
| `--as-of YYYY-MM-DD` | 时效基准日，默认今天 |
| `--focus` | `催告` `金额` `拒付` `承诺` `时效`（类别），也可传任意字面词 |
| `--format json` / `--out 文件` | 输出 JSON / 写入文件 |

## 报告里有什么（九段）

1. **结论先行** —— 要件覆盖率、诉讼时效剩余天数、有效催告条数、**偏弱催告警告**、拒付条数、金额数
2. **要件命中表** —— 借贷 10 项 / 货款 8 项 / 工程款 8 项，命中几处、命中哪个词
3. **缺失要件与补强方向** —— 去微信账单导出？去要结算单？去查实名？
4. **争议焦点** —— 对方每条拒付/推诿原话 + 破局法条
5. **催告质量评估** —— ⭐ 特色：每条催告按「**有金额 / 有事由 / 有期限 / 有后果指向**」四项打分，≤2 分的一律标警告
6. **关键程序节点** —— 借款达成、交付、约定还款日、欠条、催告、承诺还款、部分还款、拒付、还款计划、法律行动
7. **金额梳理** —— 阿拉伯数字 + **中文数字**（八千、两万二）都能抽
8. **关键证据片段**
9. **下一步行动清单**

## 三条最要命的（先看这个）

1. **光有转账记录不算借贷。** 转账只证明钱过去了，不能证明为什么过去。对方说「这是赠与」，性质就变了。
   必须留下「借 / 欠 / 还」这类定性表述。
2. **「在吗」「钱呢」不是有效催告。** 必须写清**金额 + 事由 + 期限**，法律上才认"提出履行请求"，
   才构成一个合法的时效中断。报告第五节会给你每条催告打分。
3. **每年发一次有效催告。** 3 年诉讼时效听着长，但每年 5 分钟就能续上；
   一次都不催，对方一句"过了时效了"你就没招。

## 隐私

`extract.py` 只用 Python 标准库，**不联网、不上传、不写外部文件**（除你显式给的 `--out`）。
聊天记录全程留在本机。要导出微信本地库的话，配套技能 `wechat-local-reader-tianbao` 是同样零上传的本地方案。

## 免责

本技能输出的是**材料整理与规则对照**，不是法律意见，不预测追讨结果。
金额较大、对方拒不认账、或者时效只剩几个月的，请咨询执业律师——尤其在**签还款计划**之前。

> 技能里引用的法条有时效性，地方法院口径也会有差异，提交前请核对你那份条文是否现行有效。
