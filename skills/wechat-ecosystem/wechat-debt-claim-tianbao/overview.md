# 微信聊天记录转催款材料

借出去的钱要不回来、干完活尾款拖着、货款结不掉、工程质保金到期不退——
你跟对方在微信里来回聊了几百条，但真正有用的其实只有几句：
哪天借的、说好哪天还、还了多少、还剩多少、催过几次、他哪句话算认账。

这个技能把聊天记录倒进来，本机跑一遍，告诉你**债钉没钉死、还剩多少、催告有没有效、三年时效还剩几天**，
再给你能直接复制发出去的催告话术。

---

## 为什么 AI 聊天帮不上催款

把聊天记录贴给通用 AI，它给你一段「建议先保留证据、注意诉讼时效」的正确废话。
缺的是三样：**结构化抽取**、**可复跑**、**聊天记录不出本机**。

- 通用 AI 看不见你 600 条里的第 487 条「我认这笔账，七月中旬前转你」——
  这一条既是债务自认，又是时效中断，是整个案子的支点
- 通用 AI 每次问都要重贴全部记录，你没法让它反复核对票据
- 而且聊天记录是隐私，贴出去就不可控

这个技能在你机器上跑，Python 标准库，不联网、不上传。

## 三种债，一套骨架

| 场景 | 典型 | 要证明什么 |
|---|---|---|
| **loan 借贷** | 朋友借钱、熟人周转 | 借贷合意 + 款项交付 + 还款约定 |
| **goods 货款服务费** | 发货没收到款、做完服务没结账 | 合同 + 交付凭证 + 对账结算 |
| **project 工程款** | 尾款、质保金、进度款 | 工程量确认 + 结算单 + 付款节点 |
| **all 全查** | 分不清是哪种 | 三套都扫一遍再定 |

三种债的共同骨架只有一句：**证明「欠款事实 + 欠款金额 + 到期或已催告 + 没还 + 谁欠的」。**

## 报告九段

1. **结论先行** —— 覆盖率、时效剩余天数、有效催告数、**偏弱催告警告**
2. **要件命中表** —— 借贷 10 项 / 货款 8 项 / 工程款 8 项
3. **缺失要件与补强方向** —— 去微信账单导出？去要结算单？去查实名？
4. **争议焦点** —— 对方每条拒付原话 + 破局法条
5. **⭐ 催告质量评估** —— 每条催告按「有金额 / 有事由 / 有期限 / 有后果指向」四项打分
6. **关键程序节点** —— 借款达成、交付、约定还款日、欠条、催告、承诺还款、部分还款、拒付、还款计划、法律行动
7. **金额梳理** —— 阿拉伯数字 + 中文数字都能抽
8. **关键证据片段**
9. **下一步行动清单**

## 最值钱的那个功能：给你的催告打分

催款这件事，**催了不等于有效**。

「在吗？」「钱呢？」「??」——法律上不认定为"提出履行请求"，时效照走。
「上次那笔 3 万你说下月还」——有金额 + 事由，够了。
「借款 3 万已逾期 40 天，请本周末前结清，否则我起诉」——四要素齐全。

脚本把每条催告按四项打分，**≤2 分的直接标警告**，告诉你哪一条该怎么补写。
这不是文字游戏，是你 3 年时效能不能续住的区别。

## 中文金额是真的会碰到的

「八千」「两万二」「三万四千」——真人口语里这些比 `22000` 常见得多。
第一版脚本只认阿拉伯数字，测试结果直接 FAIL。加了中文数字解析之后：

- 两万二 → 22000
- 八千 → 8000
- 三万四千 → 34000
- 两万 → 20000

而且做了防误伤：「万一你不同意」这种不会抽成 10000。

## 三条最容易翻车的

**第一层：光有转账记录不算借贷。**
转账只证明钱过去了，不证明为什么过去。对方一句「这是赠与」「这是货款」，性质就变了。
所以催款聊天里必须留下「借」「欠」「还」这类字眼。

**第二层：只截对自己有利的片段。**
对方最容易攻击的就是"剪辑"。主动提交完整连续记录，反而更有力。

**第三层：三年一次都没催。**
3 年诉讼时效，每年发一条有效催告只要 5 分钟，能把风险整个清掉。
一次都不催，对方一句"过了时效了"，你只能认。

## 顺带拿到的几个武器

- **支付令**：他认账只是拖，债权又清晰——法院催他 15 天，不异议就能强制执行，比起诉快还便宜。很多人不知道有这条。
- **加速到期条款**：谈分期时加一句「任意一期逾期，剩余全部到期」，他一拖整笔就全到期，不用再等。
- **微信账单导出**：微信账单里选"用作证明材料"会发一份**带电子章**的 PDF，法院认这个形式，比自己截图强。

## 参数怎么用得上

```bash
# 全量扫描（默认 all）
python scripts/extract.py --file 聊天记录.md

# 只看借贷，看三年还剩几天
python scripts/extract.py --file 聊天记录.md --scenario loan --as-of 2026-09-01

# 对方一直扯皮，只看催告相关
python scripts/extract.py --file 聊天记录.md --focus 催告

# 只看他怎么推脱
python scripts/extract.py --file 聊天记录.md --focus 拒付

# 拿去别处处理
python scripts/extract.py --file 聊天记录.md --format json --out out.json
```

## 边界在哪

- 它是**材料整理和规则对照**，不是律师。金额大、对方不认账、时效快到了，签字前找律师
- 它给计算口径（LPR 四倍、砍头息、逾期利息），不给判决预测
- 它不替你编事实——需要你现场确认的，模板里直接标【待现场填写】
- 引用的法条和地方法院口径有时效性，提交前自己核一遍

需要先把微信本地聊天库导出来的，配套技能 `wechat-local-reader-tianbao` 是同样的零上传本地方案。
