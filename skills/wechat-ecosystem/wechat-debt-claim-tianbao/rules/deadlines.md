# 催款时效与程序（哪些窗口过了就没了）

> 催款这件事，**催得越勤越安全，拖得越久越难**。
> 时效不是你催了它就不走，而是你催的方式得**有效**——不是发个emoji就算数。

---

## 一、诉讼时效（最要命的一个）

| 情形 | 时效 | 起算点 | 依据 |
|---|---|---|---|
| 有约定还款日 | **3 年** | 约定还款日次日起算 |《民法典》188 |
| 没约定还款日 | **3 年** | 从你第一次催告、宽限期届满次日起算 |《民法典》188 + 民法典司法解释 |
| 分期还款 | **3 年** | 最后一期到期日起算 |《民法典》189（同一债务分期履行的，诉讼时效从最后一期履行期限届满之日起算） |
| 借款没写日期 | **3 年** | 从催告的合理宽限期届满起算 | 实务口径 |
| 主张权利（催告） | 中断，**重新计算 3 年** | 催告到达对方时 |《民法典》195 |

> **诉讼时效唯一的作用不是"拖过它"，是给你一个"我一直在要"的证据。**
> 过了时效不代表不能告，只是对方一提你就可能败诉——所以宁可每年催一次。

## 二、时效中断的四种法定情形（民法典 195）

1. **权利人向义务人提出履行请求** —— 微信催告就属这类，**最常用也最省事**
2. 义务人同意履行义务（对方回一句「下月还」「认这笔账」）
3. 权利人起诉或申请仲裁
4. 与起诉/申请仲裁同一事由的，法院调解、支付令申请、公证债权文书、破产申报也算

**微信催告要有效，得满足三点：**
- 能定位到**谁**（对方本人，昵称也好、实名备注也好，要能对应上）
- 能看出**你主张什么**（金额、事由）
- 能证明**到达了**（对方已读不是硬证据，但"对方回话"就是你到过的证据）

### 四条能真正中断时效的微信表述（照抄改数字都行）

> ①「张哥，上次 X 月 X 日借你的 **3 万元** 说好 X 月还，到现在还没收到，麻烦这两天安排一下。」
> ②「这批货尾款 **2.8 万** 已到付款日（合同 X 月 X 日签），请于本周内结清，否则我按约定主张逾期利息。」
> ③「今天 X 号是约定还款日，我再次确认：**本金 5 万 + 利息 X 元**，请 X 月 X 日前付清；逾期我会走法律程序。」
> ④「这两笔（X 月 8,000 / X 月 12,000 共 2 万）你已确认过，现在仍未支付，我这边保留追责权利。」

> 反例（无效或凑合）：「在吗？」「钱呢？」「快点啊」「??」
> —— 看不出主张什么金额、什么事由，法律上难以认定"提出履行请求"。

## 三、催款的五条途径（从省事到硬气，按需上位）

| 途径 | 适合 | 优点 | 代价 |
|---|---|---|---|
| **1. 微信/电话自行协商** | 还欠着、关系没僵 | 零成本、快 | 对方拖，没约束力 |
| **2. 书面催告（EMS + 微信双发）** | 催了两次没用 | 留痕强、每 6–12 个月做一次就能保时效 | 还是要靠自觉付 |
| **3. 人民调解 / 司法确认** | 金额不大、对方愿谈 | 调解书可申请强制执行 | 要双方到场 |
| **4. 申请支付令** ⭐ | **债权清晰、对方不赖账只是拖**（有欠条/结算单/明确欠多少） | **最省事**：法院 15 天内对方不提异议就直接强制执行，诉讼费比一审低得多 | 对方提异议就废，转诉讼 |
| **5. 起诉（小额诉讼）** | 支付令不成 / 金额较大 / 对方抵赖 | 有强制力 | 要交诉讼费、花时间 |

> **支付令是高性价比武器，但很多人不知道。** 前提链条要干净：
> 债权债务关系明确 + 有合法给付内容 + 能送达。适合"他认账，就是拖"的经典场景。
> ⚠️ 具体能不能申请、要交什么材料，各地法院口径有差异，**要不要申请咨询当地法院或律师**。

### 途径选择速判

| 对方态度 | 推荐 |
|---|---|
| 说好还、一直拖 | 书面催告 → 支付令 |
| 认账但哭穷（分期还） | 签**还款计划/和解协议**（写明每期金额、日期、违约条款），司法确认 |
| 不认账、说已经还了 | 先取证（见 proof.md），再起诉 |
| 换号、拉黑、失踪 | 找共同熟人 / 户籍信息立案，别放弃 |
| 是公司，说走流程 | 先确认谁签字、钱进谁账，看是个人债还是公司债 |

## 四、管辖（去哪儿告）

一般是**被告住所地**或**合同履行地**法院。
- 借贷纠纷：被告住所地 / 接收货币一方所在地（**你作为出借人，你的所在地法院也能管**——这一条很友好）
- 买卖/服务纠纷：被告住所地 / 合同履行地
- 合同约定了管辖法院的，**按合同来**；约定仲裁的，**不能起诉，只能仲裁**

> 标的额小的走**小额诉讼程序**：一审终审、诉讼费很低（1 万元以下 50 元）。别被"打官司贵"劝退。

## 五、常见错误速查

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 只用语音/电话催 | 没有可导出的文字证据 | 通话后补一条微信文字确认 |
| 催完就删聊天记录 | 证据没了 | 催完截图 + 导出完整文本 |
| 「在吗？」当催告 | 不构成"提出履行请求" | 写清金额 + 事由 + 期限 |
| 只催不留存证 | 对方说"没催过" | 每次催都截屏，附日期 |
| 催了却没让对方回应 | 难证到达 | 发完让他回个「收到」「过两天」 |
| 过了 3 年才想起来 | 对方一抗辨就悬 | 每年 1 次书面催告，成本极低 |
| 用微信昵称起诉 | 立案都难 | 先确认真实身份（手机号 / 身份证 / 实名信息） |
| 直接暴力催收 | 涉嫌违法，反而被动 | 走合法途径 |

## 七、三个最容易错过的窗口

1. **3 年诉讼时效** —— 每年发一次有效催告，成本 5 分钟，保 3 年安全。
2. **对方说「我认账，分期还」的那一刻** —— 这是签书面还款计划的最佳时机；口头答应不算数，
   让他回一条微信承认金额 + 还款日期，这就是**中断时效 + 固定债权**的双保险。
3. **支付令申请窗口** —— 债权清晰时先问一句能不能申请支付令，比起诉快得多、便宜得多。
