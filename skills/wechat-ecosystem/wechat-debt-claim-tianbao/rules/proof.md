# 催款场景的微信取证（什么能当证据、对方怎么狡辩）

> 催款打官司，九成的败因不是"欠了没还"，是**证明不了"是他欠的"**。
> 微信转账只能证明钱过去了，证明不了为什么过去。

---

## 一、微信聊天在法律上属于什么

《最高人民法院关于民事诉讼证据的若干规定》第 14 条第四项：**电子数据**是法定证据种类之一。
微信记录、转账凭证、语音（转文字后）、朋友圈、小程序记录都算。

但电子数据要被采信，要过三关：

| 关 | 要什么 | 怎么办 |
|---|---|---|
| **真实性** | 记录是原生的、未被篡改 | 完整导出，别只截片段；重要节点录屏（从聊天列表点进去，显示对方头像/昵称/时间） |
| **完整性** | 前后连贯，没有剪裁 | 导出完整对话；对方指"你删了几句"时很被动 |
| **关联性** | 能证明是谁、欠多少 | 把微信昵称 ↔ 真实身份对应起来 |

## 二、对方七大抗辩（催款高频）

| # | 对方说法 | 怎么拆 |
|---|---|---|
| 1 | 「钱我已经还了」 | **举证责任在他**（谁主张谁举证）。要求他出示转账记录/收条。说不清就让他写「我还没还清」 |
| 2 | 「这是赠与 / 送你的」 | 要证明借贷合意。大额转账必须留「借」「还我」这类字眼，靠转账记录本身站不住 |
| 3 | 「这是货款不是借款」 | 定性不同 → 时效、利息、管辖都不同。先定性再谈，别被他带偏 |
| 4 | 「是合伙账 / 算不清」 | 账算不清是他的账；反过来逼他**书面确认一个金额**（「那你说还欠多少？」） |
| 5 | 「老板没批 / 公司没走流程」 | 看当时以谁的名义、钱进谁的账。**个人借个人 = 个人债**，公司不背 |
| 6 | 「货有问题 / 活有瑕疵」 | 这是反诉或抗辩，要他自己举证；不影响本金主张，但可以拿来压价 |
| 7 | 「过了诉讼时效」 | 出示催告记录，主张中断重新起算（民法典 195） |

## 三、催款场景的「承诺 vs 意愿」分级

对方那句话到底算不算"认账"，直接决定你能不能拿到有力证据。分级如下：

| 强度 | 典型表述 | 法律含义 |
|---|---|---|
| ★★★★★ | 「我借了 3 万，X 月还你」 / 「还差你 2 万没给」 | **债务自认**，最值钱。一定要让他把金额说出来 |
| ★★★★★ | 「钱我认，下个月一定还」（书面） | **同意履行 → 时效中断** |
| ★★★★ | 「下个月给你」「过两天转你」 | 还款意向，配合催告可构成中断；最好让他补一句具体金额和日期 |
| ★★★ | 「收到」「嗯」「知道了」 | 只确认收到催告，**不必然构成债务自认** |
| ★★ | 「在吗？」「最近忙」 | 基本没用，视听不出主张 |
| ★ | 「哈哈」 / 已读不回 | 无意义 |

> 技巧：催告时把**数字写进问句里**，逼他回应数字。
> 「上次那 3 万你打算什么时候还？」——他回「下周五还你」，就锁定了 3 万 + 下周五，两个要素齐了。

## 四、六种取证手段（递进，越往后越硬）

1. **截图** —— 最快，但单张截图证明力有限，只能当线索
2. **完整导出文本** —— 从聊天窗口完整导出，保留时间戳和发送顺序（配套 `wechat-local-reader` 技能）
3. **录屏** —— 从微信通讯录点进对方头像 → 进对话 → 上下滑动，**能显示对方昵称/头像/完整时间**，证明力明显强于截图
4. **时间戳 / 可信时间戳** —— 第三方时间戳服务，成本极低
5. **区块链存证** —— 几个大平台都接入了法院链，费用几十到几百
6. **公证** —— 最硬，但成本高（几百到几千），**只在金额大、对方态度极端、准备诉讼时用**

> 一般到 3（录屏）就够用了，别一上来就公证。**成本和配置难度要跟金额匹配**：
> 欠 3000 块花 2000 做公证，不如花 5 分钟录屏 + 保留完整导出。

## 五、必须补的外部凭证（聊天记录之外）

| 凭证 | 从哪来 | 作用 |
|---|---|---|
| **转账记录** | 微信账单（导出带章） / 银行流水 | 证明交付了 |
| **借条 / 欠条** | 对方手写或打印签收 | 最强的债权凭证 |
| **结算单 / 对账单** | 双方签字或微信确认 | 证明还剩多少 |
| **合同 / 订单 / 报价单** | 微信里确认的价格也行 | 证明欠款关系 |
| **物流单 / 签收单 / 验收单** | 快递 / 客户签收 | 证明已履行义务 |
| **发票** | 税控开票系统 | 佐证金额 |
| **对方身份信息** | 微信实名手机号、身份证照片、共同熟人 | **立案必需** |
| **录音**（通话） | 手机自带录音 | 对方亲口承认「欠你 X 万」 |

> **微信账单导出**：微信 → 我 → 服务 → 钱包 → 账单 → 右上角「常见问题」→ 下载账单 →
> 选「用作证明材料」→ 会发邮件给你一份**带电子章**的 PDF（这个是法院认可的形式，比自己截图强）。

## 六、提交前自查 13 项

- [ ] 微信昵称能对应到**真实姓名**吗？（立案需要）
- [ ] 转账记录能显示**对方姓名/账号**吗？
- [ ] 金额聊清楚了吗（别只说「钱」）
- [ ] 有没有「借 / 欠 / 还」这类定性字眼
- [ ] 有没有约定还款时间
- [ ] 有没有对方**承认**的回复（★★★★★ 级表述）
- [ ] 催告记录能证明时效中断吗
- [ ] 记录是**完整连续**的吗（没剪裁）
- [ ] 重要节点做了录屏吗
- [ ] 借条/欠条/结算单有没有
- [ ] 已还了多少，扣掉了吗（别把旧账算进来）
- [ ] 利息约定清楚吗，超过 LPR 四倍了吗
- [ ] 是个人债还是公司债，告谁

## 七、常见错误

| 错误 | 后果 |
|---|---|
| 只截对自己有利的片段 | 对方指"剪辑过"，整段记录的可信度会被质疑 |
| 删掉对方的回应（自证清白式的清理） | 变成"选择性提供证据"，反而被动 |
| 用别人手机/陌生设备导出的记录 | 身份对应混乱，真实性受质疑 |
| 把语音当证据却不转文字 | 法院要求可读，得有文字版 |
| 超过三年完全没催过 | 对方一提抗辩就没招 |
| 催告只发「钱该给了」 | 没有金额、没有事由，不构成有效主张 |
| 用威胁、骚扰方式催收 | 自己先违法，从有理变无理 |
