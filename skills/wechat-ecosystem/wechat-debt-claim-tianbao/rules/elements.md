# 欠款追讨要件库

> 三条主线：**借贷型**（别人借了我的钱）、**货款/服务型**（我干了活/发了货没拿到钱）、
> **工程款/结算型**（做了工程、留了质保金、说好的尾款拖着）。
> 三条线的共同骨架只有一句：**证明「欠款事实 + 欠款金额 + 到期 / 催告 + 没还 + 谁欠的」。**

---

## 一、通用四关（不管哪种欠款，先过这四关）

| 关 | 要证明什么 | 缺了会怎样 |
|---|---|---|
| **① 欠款关系成立** | 你们之间到底是哪一种债？借条？买卖合同？劳务/工程合同？ | 连告谁、告什么都定不了，白搭时间 |
| **② 欠款金额确定** | 剩多少没还？本金、利息/逾期利息、违约金各多少 | 金额不确定，法院难支持全额 |
| **③ 已到期或已催告** | 约定了还款日？没约定的，从催告宽限期届满起算 | 没到期就起诉，会被驳回 |
| **④ 催收与中断** | 催过几次、什么形式、对方有没有回应 | 超过 3 年诉讼时效，直接丧失胜诉权 |

## 二、借贷型（最常见的催款场景）

| # | 要件 | 举证方 | 关键提示 |
|---|---|---|---|
| 1 | **借贷合意** | 出借人 | 「借给我」「还你」「欠我」这类表述最关键；光有转账记录不够 |
| 2 | **款项交付** | 出借人 | 银行/微信转账凭证，要有对方姓名或账号 |
| 3 | **借条 / 欠条** | 出借人 | 有借条最好；没有借条，微信里的聊天记录可以证明 |
| 4 | **约定还款日期** | 出借人 | 有约定从约定日；没约定，从催告的宽限期届满起算 |
| 5 | **利息约定** | 出借人 | 书面/微信里说过利息；口头说过很难举证 |
| 6 | **利率是否合规** | 双方 | 借贷双方约定利率不得超过 **LPR 的 4 倍**；没约定利息的视为不收息 |
| 7 | **是否已还部分** | 债务人 | 对方还过多少，从本金里扣 |
| 8 | **担保 / 抵押 / 保证人** | 出借人 | 谁担保的、有没有写进聊天、有没有联系方式 |
| 9 | **身份对应** | 出借人 | 微信昵称 ≠ 真实姓名，要能对应上（见 proof.md） |
| 10 | **诉讼时效** | 出借人 | 3 年，从约定还款日/催告届满起算 |

> **微信转账 ≠ 借贷。** 转账只能证明「钱过去了」，不能证明「 why过去了」。
> 对方一句话「这钱是还你的货款」「这是赠与的」，性质就变了。
> 所以催款聊天里**必须留下「借」「还我」「欠」这类字眼**。

## 三、货款 / 服务型（做了活、发了货）

| # | 要件 | 举证方 | 关键提示 |
|---|---|---|---|
| 11 | 合同 / 订单 / 报价单 | 债权人 | 微信里确认过价格式、规格、数量也算 |
| 12 | **交付凭证** | 债权人 | 物流单、签收单、验收单、服务完成记录 |
| 13 | **欠条 / 结算单** | 债权人 | 「还欠 3 万」「上次那笔还没给」这类确认 |
| 14 | 对账记录 | 债权人 | 微信对账、月底结算截图 |
| 15 | 发票 | 债权人 | 开了票、对方收了没 |
| 16 | 质保金 / 押金 / 定金 | 债权人 | 约定什么时候退、退多少 |
| 17 | 逾期利息 / 违约金约定 | 债权人 | 合同有没有写「逾期按日万分之五」 |
| 18 | 催告记录 | 债权人 | 每次催都要留痕 |

## 四、工程款 / 结算型（工程人最常踩的坑）

| # | 要件 | 举证方 | 关键提示 |
|---|---|---|---|
| 19 | 施工合同 / 分包协议 | 债权人 | 微信里确认单价、面积、工程量也算 |
| 20 | **工程量确认** | 债权人 | 施工日志、验收单、甲方签字；只靠口头不算 |
| 21 | **进度款 / 结算单** | 债权人 | 到底做到哪一步、该付多少 |
| 22 | **质保金（保修金）** | 债权人 | 一般有 2%~5% 质保金，约定缺陷责任期满后退还 |
| 23 | 签证 / 变更单 | 债权人 | 增项部分有没有书面确认 |
| 24 | 甲方/总包付款节点 | 债权人 | 约定「验收后付 80%」这类节点到了没 |
| 25 | 停工 / 解除合同 | 双方 | 什么时候停的、谁的责任 |
| 26 | 违约金 / 逾期付款利息 | 债权人 | 建设工程施工合同中逾期付款可主张利息 |

## 五、金额怎么算

### 1. 借贷型
```
可主张 = 剩余本金 + 合法利息（或不逾期利息）
本金    = 转出总额 − 已还部分
利息上限 = 本金 × 起诉时一年期LPR × 4 × 借款天数/365
```
> 没约定利息 → 借期内不收息，但**逾期后可以主张逾期利息**（约定了从约定日，没约定从催告届满）。
> 「砍头息」（先扣一刀再转账）违法，按实收金额算本金。

### 2. 货款 / 服务型
```
可主张 = 欠款本金 + 逾期付款利息（按合同标准；没约定按LPR）
逾期利息 = 欠款 × LPR × 逾期天数 / 365
```

### 3. 工程款型
```
可主张 = 未付工程款 + 利息（按LPR，从应付之日起）
质保金 = 结算价 × 质保比例（通常2%~5%），缺陷责任期满应退
```
> 工程欠款还有个特殊武器：如果对方是发包人，实际施工人可以主张**突破合同相对性**
> （建工司法解释一 第 43 条），在欠付工程款范围内向发包人主张。**这条很实用，但涉及专业判断，建议找律师。**

### 4. 常见抗辩对应的金额陷阱
- 对方说「已经还了」——**举证责任在对方**（谁主张谁举证），要他拿出转账记录
- 对方说「这是合伙账，算不清」——账算不清是对方的账，不是你放弃的理由；留好对账记录
- 对方说「老板没批」——个人欠款与职务行为要分清，看他是以个人名义还是公司名义

## 六、五种欠款类型速判

| 情形 | 定性 | 关键证据 | 时效起算 |
|---|---|---|---|
| 朋友借了 2 万，说下月还 | 民间借贷 | 转账记录 + 「下月还」的聊天 | 约定还款日次日起 3 年 |
| 没写借条，只转了账 | 疑似借贷（需证明合意） | 转账 + 借还款语境聊天 | 从催告届满起算 |
| 给了货没收到钱 | 买卖合同 | 订单 + 物流/签收 + 对账 | 交货日或约定付款日 |
| 干完工程尾款没给 | 建设工程/承揽 | 合同 + 验收/结算单 | 结算日或约定付款日 |
| 质保金到期不退 | 合同违约 | 结算单 + 质保金条款 | 缺陷责任期满日 |

## 七、对方七大常见抗辩（催款场景）

| # | 对方说法 | 怎么拆 |
|---|---|---|
| 1 | 「钱我已经还了」 | 举证责任在他，要求提供转账/收条；说不清就认，先做时效止损 |
| 2 | 「这是赠与 / 送礼」 | 要证明借贷合意；大额转账更要留痕，单笔几万以上别靠口头 |
| 3 | 「是货款不是借款」 | 定性不同 →  statute 不同、利息不同、管辖不同，先分清再谈 |
| 4 | 「公司没批 / 走流程」 | 看当时是以谁的名义借的、钱进谁的账；个人欠个人，公司不背 |
| 5 | 「账还没结 / 算不清」 | 要求书面对账，微信催一句「X月X日对一下还剩多少」逼他确认 |
| 6 | 「你也有问题（货有问题/活有缺陷）」 | 这是反诉/抗辩，要他举证；不影响本金主张 |
| 7 | 「过诉讼时效了」 | 出示催告记录，主张时效中断重新计算（民法典 195） |
