# 欠款追讨材料清单

> 按项打勾。标 ⚠️ 的是**最常漏、一漏就取证失败**的。
> 需要你自己现场确认的，直接标【待现场填写】，不要靠猜、不要编。

---

## 一、先把"谁欠多少"钉死（最关键的三样）

| # | 材料 | 从哪拿 | 说明 |
|---|---|---|---|
| 1 | **债权凭证**：借条 / 欠条 / 结算单 ⚠️ | 对方写或签 | 有它最省事，没有就用下面的聊天补 |
| 2 | **转账记录（带电子章）** ⚠️ | 微信 → 我 → 服务 → 钱包 → 账单 → 下载账单 → 用作证明材料 | 法院认这个形式，比自己截图强得多 |
| 3 | **完整聊天记录导出** ⚠️ | 聊天窗口完整导出，别只截片段 | 要能看出"谁、什么时候、说了什么、欠多少" |

> 光有转账记录只能证明"钱过去了"，证明不了"为什么过去"。
> 对方一句话「这是赠与」「这是货款」，性质就变了。**必须有"借/欠/还"这类定性表述。**

## 二、身份对应（立案必需，很多人卡在这）

| # | 材料 | 从哪拿 |
|---|---|---|
| 4 | 对方真实姓名 | 微信备注 / 实名信息 / 共同熟人 ⚠️ |
| 5 | 手机号 / 微信号 | 微信号、手机号、实名认证页 |
| 6 | 身份证号（至少部分） | 借条、转账备注、共同朋友、报警记录 |
| 7 | 住址 / 户籍信息 | 微信实名、户籍查询、律师调查令 |
| 8 | 如果是公司：公司名称 + 统一社会信用代码 | 企查查 / 天眼查 / 营业执照 |

> 微信昵称不能当被告。**先确认身份，再谈催款**，不然聊半天白聊。

## 三、借贷型

| # | 材料 | 从哪拿 | 说明 |
|---|---|---|---|
| 9 | 借条 / 借款协议 ⚠️ | 对方写 | 有还款日期最好 |
| 10 | 转账凭证 | 微信账单 / 银行流水 | 含对方姓名或账号 |
| 11 | 聊天中的借贷表述 ⚠️ | 微信导出 | 「借给我」「下月还你」这类原话 |
| 12 | 利息约定 | 聊天 / 书面 | 没约定 = 借期内不收息 |
| 13 | 已还部分（要从本金扣）⚠️ | 对方转账记录 | 别把旧账算进来 |
| 14 | 担保人 / 抵押物信息 | 聊天 / 借条 | 谁担保、怎么担保 |
| 15 | 催告记录 | 微信文字 | 见《催告话术》模板 |

## 四、货款 / 服务费型

| # | 材料 | 从哪拿 | 说明 |
|---|---|---|---|
| 16 | 订单 / 报价单 / 合同 ⚠️ | 微信确认过价格也算 | 规格、数量、单价 |
| 17 | 交付凭证 ⚠️ | 物流单 / 签收单 / 验收单 | 证明你履行了 |
| 18 | 对账 / 结算记录 | 微信对账截图 | 「还差 2.8 万」这种 |
| 19 | 发票 | 税控系统 | 含税点、抬头 |
| 20 | 质保金 / 押金条款 | 合同 | 什么时候退、退多少 |
| 21 | 逾期利息约定 | 合同 / 微信 | 没约定按 LPR 主张 |

## 五、工程款 / 结算型

| # | 材料 | 从哪拿 | 说明 |
|---|---|---|---|
| 22 | 施工 / 分包合同 | 自己留存 | 单价、面积、工程量 |
| 23 | 工程量确认 ⚠️ | 施工日志 / 验收单 / 甲方签认 | 只靠口头不算 |
| 24 | 进度款节点证明 | 合同 + 进度确认 | 该付 80% 到了没 |
| 25 | 结算单 / 决算书 ⚠️ | 双方签认 | 还剩多少全靠它 |
| 26 | 签证 / 变更单 | 增项书面确认 | 活加了多少 |
| 27 | 质保金条款 + 缺陷责任期证明 | 合同 + 验收日期 | 到期该退 |
| 28 | 停工 / 撤场 / 解除记录 | 通知函、聊天 | 什么时候停的、谁的责任 |

## 六、证明"一直在要"（时效）

| # | 材料 | 说明 |
|---|---|---|
| 29 | **每次催告的截图 + 原聊天** ⚠️ | 必须写清"金额 + 事由 + 期限"才算有效主张 |
| 30 | 对方承认的回复 ⚠️ | 他说"下月还""我认"，就是债务自认 + 时效中断 |
| 31 | 分期还款计划（书面） | 每期金额 + 日期 + 违约条款 |
| 32 | 通话录音 + 文字整理 | 他亲口说「欠你 X 万」 |

## 七、提交前自查 11 项

- [ ] 被告是谁？姓名、身份、住址齐了吗
- [ ] 欠多少算清楚了吗（本金/利息/违约金分项）
- [ ] 已经还的部分扣掉了吗
- [ ] 利息有没有超过 LPR 四倍（超出部分不受保护）
- [ ] 有没有"借/欠"这种定性表述
- [ ] 有没有约还款日期（没有就从催告届满起算）
- [ ] 催告记录能证明时效中断吗（不是"在吗"）
- [ ] 记录完整吗，没剪裁吗
- [ ] 是个人债还是公司债
- [ ] 有没有担保人/抵押物（能多要一份债主）
- [ ] 金额和聊天里说的对得上吗

## 八个最常被对方一句话打掉的坑

1. **只转了钱没留定性话** → 「这是赠与」一句话性质就变了
2. **只截对自己有利的片段** → 对方直接指"剪辑过"，整段可信度崩
3. **催告写"在吗"** → 不构成有效主张，时效照走
4. **把旧账混进来** → 对方一旦拿出当年还款记录，整笔账说不清
5. **过了 3 年一次都没催** → 对方一提抗辩就悬
6. **用昵称当被告** → 连立案窗口都进不去
7. **口头说分期** → 必须落到书面，否则不认
8. **暴力催收** → 自己先违法，从有理变无理
