# 催款时间线（先看倒计时，再排动作）

---

## 第 0 步：先算倒计时

| 事项 | 起算点 | 期限 | 逾期后果 | 怎么保 |
|---|---|---|---|---|
| **诉讼时效**（有约定还款日） | 约定还款日次日 | **3 年** | 丧失胜诉权 | 3 年内催告一次 |
| **诉讼时效**（没约定还款日） | 你第一次催告、宽限期届满次日 | **3 年** | 同上 | 立刻催告并留痕 |
| **分期债务** | 最后一期到期日 | **3 年** | 同上 | 每期别漏催 |
| **申请强制执行** | 判决/调解书生效 | **2 年** | 不能再强制 | 生效后马上申请 |
| **支付令异议期** | 法院发出支付令 | **15 天** | —（对方提异议就转诉讼） | 申请前先确认他不会赖 |

> 3 年听起来长，但**它是你用 5 分钟就能续的**。每年发一条有效催告，成本极低，收益是整个债权还有保障。

### 催告要"有效"才算中断（民法典 195）

| 写什么 | 算不算有效催告 |
|---|---|
| 「在吗」「钱呢」「快点」「??」 | ❌ 看不出主张什么 |
| 「钱该还了」 | ⚠️ 没有金额、没有事由 |
| 「上次那笔 3 万你说下月还，现在还没到吧？」 | ✅ 有金额 + 事由 |
| 「借款 3 万，逾期 40 天，请于本周内结清，否则我起诉」 | ✅✅ 四要素齐全 |

## 第 1 步：确认身份（先做，别跳过）

- [ ] 真实姓名、手机号、微信号【待现场填写】
- [ ] 住址 / 公司全称 + 统一社会信用代码
- [ ] 有没有担保人、抵押物、共同借款人

> 立案要真实姓名。昵称、备注名都不行。**这一步省了，后面全白干。**

## 第 2 步：固定债权（趁还没拖黄）

- [ ] 借条 / 欠条 / 结算单拿到了吗？没有就现在要
- [ ] 让他在微信里确认一句话：**"我借了 X 元，还欠 Y 元，X 月 X 日还"**
- [ ] 导出转账记录（微信账单 → 用作证明材料 → 带章 PDF）
- [ ] 完整导出聊天记录（含不利内容）

> 这一步是在**给整件事定性**。定性之后，后面才谈得上"要多少"。

## 第 3 步：第一次有效催告

- [ ] 发一条四要素齐全的微信（见话术模板）
- [ ] 截图 + 导出，两份备份
- [ ] **等他回一句话**——他回「收到」「下月还」就是债务自认 + 时效中断

## 第 4 步：看他怎么回（三种分支）

| 他的回应 | 你的动作 |
|---|---|
| 认账 + 给日期 | 锁死：让他回「X 月 X 日还 X 元」，再补书面还款计划 + 加速到期条款 |
| 认账 + 要分期 | 立刻谈还款计划：每期多少、哪天付、逾期整笔到期 |
| 不认 / 拖 / 失踪 | 进第 5 步（走途径） |

## 第 5 步：五条途径逐个上

1. **书面催告（微信 + EMS 双发）** —— 便宜、快，留痕强
2. **人民调解 / 司法确认** —— 双方到场，调解书可强制执行
3. **⭐ 申请支付令** —— 他认账只是拖的时候最好用，比起诉快
4. **小额诉讼起诉** —— 1 万以下 50 元诉讼费，一审终审
5. **强制执行** —— 判完 2 年内申请，提前备好财产线索（银行卡、支付宝/微信、房、车、社保、公积金）

## 第 6 步：每 6–12 个月一次例行催告（别停）

- [ ] 发一条四要素齐全的催告
- [ ] 截屏存档
- [ ] 在日历里记下一次

> 这件事的价值不在"催到钱"，在**让 3 年永远不开始跑**。

---

## 三个最容易翻车的时刻

1. **他一说「我认，分期还」，你口头答应了** —— 没落到书面 = 白认。当场发文字确认。
2. **过了 3 年一次都没催过** —— 他说"过了时效了"，你只能认。每年一条，5 分钟的事。
3. **只顾着催，没留财产线索** —— 判赢了拿不到钱最憋屈。催的过程中顺手记下他上班、车、房、账户。

## 微信催告自查表（发出前过一遍）

- [ ] 写清了**具体金额**吗（别写"几千块"）
- [ ] 说清是**哪笔账**（借钱 / 哪批货 / 哪份工程）
- [ ] 给了**付款期限**吗
- [ ] 提了**不付的后果**吗
- [ ] 发完**截图存档**了吗
- [ ] 对方**回了话**吗（回了才算到过）
