# 开头写法与模板库

> 写开头前先读本文件。**没有核心承诺的开头就是自我介绍。**

---

## 一、五类开头写法详解

### 1. 结论先行型

```
结构：一句话核心结论 + 为什么值得往下看

模板：
  这篇讲的不是 [常见理解]，是 [真正的核心]。
  看完你能 [具体动作]。

示例：
  「这篇讲的不是方法论，是三个可以直接抄的操作。
    看完你今天下午就能改掉 XX 环节的重复劳动。」

适用：教程、复盘、干货类
优点：读者立刻知道能得到什么
```

### 2. 场景切入型

```
结构：还原一个具体场景 + 引出普遍性

模板：
  [时间] + [地点]，我 [具体事件]。
  那一刻我发现 [一个规律或冲突]。
  [这个规律适用于哪些人]

示例：
  「周三晚上十点，第七版方案改到第 3 页。
    这时候你会发现一个规律：越是改到后半程，越容易改回去。」

适用：故事、观察、行业分析
优点：具体场景比抽象论述留人更久
```

### 3. 数字清单型

```
结构：给出数量 + 每个的数量 + 第一个是什么

模板：
  我统计/复盘了 [数量] 的 [对象]。
  发现 [N] 个共性问题。第一个是：[结论]。

示例：
  「我复盘了最近半年做的 40 份方案，
    总结了 3 个共同问题。第一个是：目标写得越具体，改稿越多。」

适用：清单、总结类
优点：数量给出预期管理，降低跳出
```

### 4. 反常识型

```
结构：违反直觉的判断 + 站得住的解释

模板：
  [违反直觉的判断]。
  [支撑数据或样本量]。
  原因其实是 [解释]。

示例：
  「写得越详细，改稿越多。
    过去半年我统计了 40 份方案，方向越明确的那批，
    反而平均少改 1.8 版。原因其实很简单。」

适用：观点、行业分析
优点：认知冲突制造阅读张力
```

### 5. 提问切入型

```
结构：读者正在经历的问题 + 暗示本文能回答

模板：
  为什么 [读者的具体困境]？
  不是 [常见归因]，是 [真实原因]。
  下面 [N] 个层面拆开说。

示例：
  「为什么你写的方案总是改到第七版？
    不是写得不好，是你在写别人要的结果。
    下面三个层面拆开说。」

适用：问题导向、答疑类
注意：问题必须后文真的回答
```

## 二、首段标准速查

| 项 | 标准 | 说明 |
|---|---|---|
| 长度 | 首段 80-150 字 | 移动端首屏约 4-5 行 |
| 信息点 | 1 个核心承诺 + 1 个信息钩子 | 不要塞三个论点 |
| 首句长度 | 15-30 字 | 一口气能读完 |
| 与标题重复度 | ≤ 40% 字面 | 重复会让读者觉得已经知道了 |
| 自我介绍 | 不出现 | 「大家好我是」是完读率杀手 |
| 排版 | 每段 2-4 行换行 | 密集文字块降低阅读意愿 |

---

## 三、首段必须包含的三件事

| # | 内容 | 示例句式 | 缺失后果 |
|---|---|---|---|
| 1 | 核心承诺 | 「看完你能……」 | 读者不知道为什么要读下去 |
| 2 | 相关性 | 「这个问题的原因是……」 | 读者觉得与自己无关 |
| 3 | 阅读指引 | 「下面讲三点……」 | 长文读者中途放弃 |

**三件事缺一件，开头就存在问题。**

## 四、四类应避开的写法（附改写）

### 避法一：自我介绍式开场

```
✗ 大家好，我是 XX，某大厂 XX 年 XX，从业 XX 年，今天给大家分享……

✓ 「做了 6 年方案之后，我发现改稿最多的那批，
    往往不是写得最差的那批。」

原理：第一行要的是「这篇跟我有关」，不是「写作者是谁」。
```

### 避法二：标题原句复述

```
✗ 标题：为什么你的方案总是改到第七版
  开头：为什么你的方案总是改到第七版。这个问题困扰了很多人……

✓ 标题：为什么你的方案总是改到第七版
  开头：上周三，第七版改到第 3 页。同一个方案，第三版到第七版
       只改了两行字。

原理：重复会让读者觉得「我已经知道了」，直接滑走。
```

### 避法三：长铺垫

```
✗ 先写 300 字背景、行业趋势、公司介绍，再进入主题

✓ 场景 + 冲突 + 承诺，三句话进主题：
  「周三晚上十点，第七版改到第 3 页。
    这次又改回去了。
    改到第七版还在改，问题可能不在态度。」

原理：移动端首屏只有 4-5 行，超过就等于没写。
```

### 避法四：空话开场

```
✗ 在当今快速发展的时代，效率已经成为衡量企业竞争力的重要标准……

✓ 「同样一件事，流程走 6 步和 3 步，团队一周差 4 小时。」

原理：空话在信息流里没有任何竞争力。
```

## 七、开头自检清单

- [ ] 核心承诺已写成一句话
- [ ] 首段 80-150 字
- [ ] 首句 15-30 字
- [ ] 包含核心承诺、相关性、阅读指引
- [ ] 无「大家好我是」
- [ ] 与标题重复度 ≤ 40%
- [ ] 属于五类写法之一
- [ ] 无「在当今……的时代」类空话
- [ ] 背景铺垫不超过 2 句
- [ ] 标题承诺在正文已兑现
