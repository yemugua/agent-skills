# 微信支付：账单、退款、免密、限额、收款

> 路径层级以中文版微信 8.x 为例，版本差异以用户实际客户端为准。
> 每条都给「入口方向 + 搜索兜底 + 校验方式」。

## 一、查账单与交易明细

**入口方向**：我 → 服务 → 钱包 → 账单
**搜索兜底**：微信首页搜索「账单」或「微信支付」
**校验**：进入后页面标题含「账单」，能看到按月份分组的交易列表，每条可点开看详情

账单详情页能拿到的关键字段：
- 交易时间、金额、支付方式（零钱 / 银行卡）
- 商户名称、商户单号
- 订单号（投诉和查询时最重要）
- 「对订单有疑惑」「联系商户」等入口（有则优先用）

## 二、账单导出（用于报销、签证、财务或纠纷举证）

**入口方向**：我 → 服务 → 钱包 → 账单 → 右上角「…」→ 账单下载
**搜索兜底**：搜索「账单下载」
**校验**：可选择用途（个人对账 / 证明材料）、时间区间，导出会发送到指定邮箱，文件带签章

用途说明：
- 个人对账：流水清单
- 证明材料：带微信支付签章的凭证文件，可用于签证、财务报销、纠纷举证

注意：导出需要验证支付密码，文件含敏感交易信息，提醒用户妥善保管、不要随意转发。

## 三、退款与交易纠纷

**判断顺序**：

```
1. 有没有订单号？        → 没有就先去账单里找
2. 商品/服务类交易？      → 先找商户（订单详情里的客服入口）
3. 商户不处理？          → 账单 → 订单详情 → 「对订单有疑惑」发起投诉
4. 涉及欺诈 / 商户失联？  → 投诉同时保留证据，金额较大直接报警
```

**入口方向**：我 → 服务 → 钱包 → 账单 → 选中该笔 → 页面底部的「对订单有疑惑」/「联系商户」
**校验**：进入后能看到该笔订单的商户信息与问题分类选项

退款到账时间取决于原支付方式（零钱 / 银行卡 / 信用卡），具体以平台公示为准，**不要承诺具体天数**。

## 四、免密支付与自动续费（"莫名其妙被扣钱"的第一嫌疑）

**入口方向**：我 → 服务 → 钱包 → 底部「支付设置」→ 免密支付 / 自动扣费
**搜索兜底**：搜索「免密支付」
**校验**：页面列出所有已签约的免密项目，逐个可查看签约方与解约入口

处理顺序：
1. 先**关闭**不想继续的自动续费（避免下个周期再扣）
2. 再处理**已扣款项**（找商户协商退款，或通过订单投诉）
3. 关闭不代表自动退回已扣金额——这一点必须跟用户讲清楚

提醒：视频会员、网盘、外卖会员、网课分期、先用后付类都常在此处。

## 五、亲属卡

**入口方向**：我 → 服务 → 钱包 → 亲属卡
**搜索兜底**：搜索「亲属卡」
**校验**：能看到已赠送/收到的亲属卡与额度

要点：
- 亲属卡由赠卡方设置额度，实际消费从赠卡方账户扣
- 赠卡方和收卡方都可以解绑
- 纠纷按普通微信支付交易处理（走账单 → 订单）

## 六、转账限额与实名

- 未实名或实名不完善 → 收付款会受限
- 限额由账户实名等级、绑卡情况、风控策略共同决定，**具体额度以钱包内页面提示为准**
- 提升额度通常需要完善实名信息、绑定银行卡

**入口方向**：我 → 服务 → 钱包 → 底部「支付设置」/ 身份信息
**校验**：页面会显示当前实名状态与可用的提升方式

## 七、收款与商户（做生意的一方）

| 场景 | 说明 |
| --- | --- |
| 个人收款 | 收款码 / 转账，适合小额偶发收款 |
| 经营性收款 | 应使用商户收款码或商业支付，走 `pay.weixin.qq.com` |
| 对账与提现 | 商户平台与服务商后台提供对账单 |

重要提示：
- 个人收款码用于经营性收款存在合规风险，建议接入正规商户支付
- 不得协助套现、虚假交易、绕过风控

## 八、支付安全底线

- 支付密码、短信验证码、身份证号 **不告诉任何人**，微信官方不会索要
- 验证码是最后一道锁，任何索要验证码的都是诈骗
- 收到扣款通知先核对自己是否在账单里找到对应订单，不要点通知里的陌生链接
- 疑似被骗：先改支付密码 → 关免密 → 报警（96110 / 110）

## 九、回答支付类问题的固定顺序

```
止损 → 定位订单 → 找商户 → 平台投诉 → 监管/报警 → 材料清单
```

材料清单（让用户一次备齐）：
交易时间、金额、订单号、商户名称、问题说明、截图（订单页 + 聊天记录 + 扣款通知）。
