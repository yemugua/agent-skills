# 小程序：查找、授权、缓存、订单、开发入口

## 一、找到小程序

| 需求 | 入口方向 | 搜索兜底 |
| --- | --- | --- |
| 打开最近用过的 | 微信首页下拉，或 发现 → 小程序 | 搜索小程序名 |
| 找新的 | 发现 → 小程序 → 搜索 | 首页顶部搜索框 |
| 朋友分享的 | 聊天里的卡片直接点开 | — |
| 公众号关联的 | 公众号主页 / 菜单 | — |

**校验**：小程序页面右上角有「…」胶囊按钮，能打开「关于」「设置」「反馈」等菜单。

## 二、授权管理（位置、相册、麦克风、用户信息）

**入口方向**：我 → 设置 → 个人信息与权限 → 授权管理
**搜索兜底**：搜索「授权管理」
**校验**：能看到按小程序/应用分组的授权列表

也支持从小程序内进入：小程序右上角「…」→ 设置 → 查看或修改权限。

要点：
- 关闭授权后，小程序相关功能会失效（如关闭位置就无法定位）
- 重新授权一般在小程序触发该功能时再次弹窗
- 解除授权 ≠ 注销小程序账号；账号注销需在小程序的运营方处处理

## 三、缓存清理与"打不开 / 很卡"

处理顺序：

```
1. 检查网络与微信版本（更新到最新版）
2. 彻底关闭该小程序（从最近使用中移除）后重进
3. 清理小程序缓存：我 → 设置 → 通用 → 存储空间 → 清理小程序缓存
4. 仍不行 → 微信重启 / 手机重启
5. 还不行 → 用小程序内「…」→ 反馈与投诉，提交给开发者
```

**谨慎提醒**：清理缓存可能清掉本地草稿或未上传的数据，先提醒用户确认重要内容已保存。

## 四、小程序里的订单与退款

责任主体是**小程序的运营方**，不是微信。

```
1. 在小程序内找「我的 → 订单 / 我的订单」
2. 订单详情里找客服入口或售后入口
3. 小程序不处理 → 微信账单里找到该笔 → 对订单有疑惑
4. 金额大 / 商户失联 → 12315 或报警
```

**取证**：小程序名称、订单号、支付时间金额、与客服的聊天截图。

## 五、小程序开发 / 运营相关入口

| 事项 | 入口 |
| --- | --- |
| 注册小程序 | `mp.weixin.qq.com`（公众平台 → 小程序） |
| 开发与调试 | 微信开发者工具（官方客户端） |
| 接口与文档 | 微信开放文档（developers.weixin.qq.com） |
| 服务器域名、类目、审核 | 公众平台小程序后台 |
| 第三方平台 / 网站应用 | `open.weixin.qq.com` |

常见卡点与原则：
- 小程序需**类目与资质**匹配（涉及支付、医疗、教育、食品等类目要相应资质）
- 服务器域名必须在后台配置且为 HTTPS，否则请求失败
- 提审被拒以审核反馈为准，按其给出的原因逐条整改，不要尝试绕过
- 涉及用户信息的接口需先在后台申请并通过审核

## 六、小程序合规红线

- 不做诱导分享、诱导关注
- 不收集与功能无关的用户信息
- 不提供破解、外挂、刷量、越权抓取其他平台数据的能力
- 涉及支付必须走合规支付通道，不得用个人收款码做经营性收款

## 七、用户常见问题的标准答案骨架

| 问法 | 回答骨架 |
| --- | --- |
| "小程序找不到了" | 首页下拉 / 发现页 / 搜索名；确认是否被移除或改名 |
| "小程序一直转圈" | 网络 → 版本 → 清缓存 → 反馈开发者 |
| "想取消某个授权" | 授权管理路径 + 关闭后影响说明 |
| "小程序里买的东西要退款" | 先找小程序内订单客服 → 再走微信账单投诉 |
| "我要做一个小程序" | 注册入口 + 类目资质提醒 + 开发文档 |
