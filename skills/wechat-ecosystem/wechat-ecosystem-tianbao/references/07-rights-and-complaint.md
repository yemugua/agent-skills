# 投诉维权：平台投诉、12315、未成年充值、报警

## 一、处理阶梯（从轻到重）

```
第 1 级：与商户协商（订单页客服入口）
第 2 级：微信平台投诉（账单 → 订单 → 对订单有疑惑）
第 3 级：12315 / 消协（涉消费纠纷）
第 4 级：报警 / 反诈（涉诈骗、盗刷，金额较大）
```

原则：**不要跳级，也不要只停留在第 1 级**。商户明显失联或涉嫌欺诈时，直接同时启动 2 和 4。

## 二、微信内投诉（交易类）

**入口方向**：我 → 服务 → 钱包 → 账单 → 选中该笔订单 → 「对订单有疑惑」
**搜索兜底**：搜索「账单」
**校验**：进入后能看到问题分类选项与提交入口

提交要点：
- 选对问题类型（未收到货 / 商品问题 / 退款未到账 / 涉嫌欺诈 …）
- 描述用**事实**（时间、金额、承诺内容、实际结果），不用情绪词
- 附件上传：聊天截图、商品页截图、物流截图

## 三、账号 / 内容类投诉

| 对象 | 入口方向 |
| --- | --- |
| 个人账号 | 对方资料页 → 右上角「…」→ 投诉 |
| 群 | 群聊天 → 右上角「…」→ 投诉 |
| 公众号文章 | 文章页 / 公众号主页 → 投诉 |
| 小程序 | 小程序右上角「…」→ 反馈与投诉 |

## 四、12315 与消协

- **全国 12315 平台**：网站 `www.12315.cn`，也有 12315 微信小程序与 App
- **电话**：12315

适用：消费纠纷（商品质量、虚假宣传、拒绝退款、预付卡跑路等）。

提交要点：
- 被投诉方要写**经营主体全称**（不是店名），可从微信支付的商户信息或营业执照查
- 附上：订单号、支付凭证、聊天记录、商品页截图
- 写清诉求（退款 / 赔偿 / 退货）

## 五、未成年人充值退款

**顺序**：
1. 收集证据：充值记录（微信账单）、游戏/平台账号、未成年人使用证据
2. 通过对应游戏或平台的**未成年人退款通道**提交（多数在其客服/家长守护页面）
3. 平台不处理或不满意 → 12315 投诉 / 消协
4. 同时**立即**关闭免密支付、设置支付限额，防止继续充值

注意：退款认定需要证明是未成年人操作，材料越完整越有利。

## 六、涉嫌诈骗 / 盗刷

**立即做**：
1. 改微信密码与支付密码
2. 关闭免密支付与自动扣费
3. 冻结/挂失银行卡（若银行卡有风险）
4. 拨打 **96110**（反诈中心）或 **110** 报警
5. 保留全部证据：聊天记录、转账记录、对方账号、链接

**不要做**：
- 不要相信"能帮你追回"的陌生人（二次诈骗高发）
- 不要私下转账给所谓"维权机构"
- 不要删除任何聊天记录

## 七、材料清单（让用户一次备齐）

| 类别 | 内容 |
| --- | --- |
| 交易 | 时间、金额、订单号、商户全称、支付方式 |
| 沟通 | 与商户/对方的完整聊天截图（含时间） |
| 承诺 | 商品页、宣传页、活动规则截图 |
| 履约 | 物流信息、收货照片、问题描述照片 |
| 身份 | 本人联系方式（用于回执） |

## 八、时效与预期管理

- 平台投诉有处理周期，具体以平台公示为准，**不承诺天数**
- 投诉后留意微信内的通知与「服务消息」
- 如超时未处理，可凭投诉记录向 12315 反映
- 金额较大或涉嫌犯罪的，不要只等平台，同步报警

## 九、不能做的事

- 不提供"追款神器""黑客追回"类渠道
- 不教用户伪造证据、虚构损失
- 不提供绕过平台规则、恶意投诉、恶意退款的方法
- 不提供骚扰商户、曝光他人隐私的"维权"手段
