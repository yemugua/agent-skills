# 账号与安全：被盗、封禁、换绑、换机迁移

> 账号类问题一律先止损，再处理。顺序不能颠倒。

## 一、账号被盗 / 异常登录

**止损顺序（先做这四步，再谈别的）**：

```
1. 修改微信密码（若还能登录）
2. 冻结/保护账号：微信安全中心
3. 检查并踢出陌生登录设备：我 → 设置 → 账号与安全 → 登录设备管理
4. 检查支付：钱包内确认有没有陌生交易，必要时改支付密码、关免密
```

**入口方向**：我 → 设置 → 账号与安全
**搜索兜底**：搜索「微信安全中心」
**校验**：账号与安全页能看到手机号、微信号、登录设备管理、微信密码等条目

**若已无法登录**：走微信安全中心的账号找回流程，按页面提示做身份验证（好友辅助验证 / 绑定信息验证等），具体方式以页面当时提供为准。

**提醒用户**：微信官方不会主动索要密码和验证码；任何自称"客服"要验证码的都是诈骗。

## 二、功能被限制 / 账号被封

**判断**：先搞清楚是哪种限制（加好友限制、群聊限制、朋友圈限制、支付限制、整体封禁），不同限制对应不同申诉入口。

**入口方向**：
- 登录时若有封禁提示，页面通常直接给出「申请解封 / 申诉」入口
- 否则走微信安全中心的申诉页面

**申诉准备材料**：
1. 微信号 / 绑定手机号
2. 封禁提示的完整截图（含限制类型与时间）
3. 本人身份证明（按页面要求）
4. 情况说明：做了什么、是否本人操作、是否知悉规则

**原则**：
- 说明真实使用情况，不要虚构
- 若确实存在违规，承认并说明整改，比辩解更容易通过
- 不要尝试用多个账号绕过限制，会加重处罚

## 三、手机号换绑 / 微信号设置

**入口方向**：我 → 设置 → 账号与安全 → 手机号 / 微信号
**校验**：换绑需要验证原手机号或走身份验证流程

注意：
- 微信号一年通常只能修改有限次数，具体以页面提示为准
- 换绑后及时检查登录设备管理，踢掉旧设备
- 换手机号前先确认绑定的银行卡、支付、第三方登录是否需要同步更新

## 四、换手机迁移聊天记录

**入口方向**：我 → 设置 → 通用 → 聊天记录迁移与备份
**搜索兜底**：搜索「聊天记录迁移」
**校验**：页面提供「迁移到另一台设备」和「备份到电脑」两类选项

要点：
- **迁移**：两台设备连同一 Wi-Fi（或热点），旧机选聊天记录 → 新机扫码接收
- **备份**：电脑版微信 → 左下角菜单 → 迁移与备份 → 备份到电脑
- 迁移过程保持两台设备常亮、网络稳定、不要中途断
- 迁移只搬聊天记录，**不搬**支付设置、登录状态

**边界提醒**：只能迁移**本人自己**账号的数据；他人账号数据需账号本人操作与授权，不提供代替他人导出的方案。

## 五、聊天记录备份与恢复

| 方式 | 适用 | 说明 |
| --- | --- | --- |
| 备份到电脑 | 长期归档 | 需要电脑版微信，恢复需同一台电脑的备份文件 |
| 迁移到新手机 | 换机 | 一次性，两台设备同时在线 |
| 收藏 / 转发 | 少量重要内容 | 手动，适合关键对话 |

提醒：备份文件含完整聊天内容，属于高敏感数据，提醒用户加密保存、不要传到网盘或发给他人。

## 六、隐私设置

**入口方向**：
- 我 → 设置 → 朋友权限（朋友圈与状态、加我为朋友时的验证方式）
- 我 → 设置 → 个人信息与权限（授权管理、个性化推荐等）

常见项：
- 加好友验证方式（是否需要验证、通过哪些途径找到我）
- 朋友圈可见范围、允许查看的范围
- 陌生人查看朋友圈条数
- 个性化广告/推荐（按页面实际提供的开关为准）

## 七、安全习惯清单（可直接给用户）

1. 支付密码与登录密码不相同
2. 开启登录设备提醒，定期清理陌生设备
3. 不点陌生链接、不扫来历不明的码
4. 验证码永不外泄
5. 重要账号绑定手机号与邮箱，并保持可用
6. 换手机前先迁移聊天记录，再解绑旧设备
7. 不装来历不明的"微信多开""微信助手"类外挂（有封号风险）
