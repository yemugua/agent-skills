# 公众号、视频号、搜一搜：使用、入驻、违规申诉

## 一、公众号（订阅号 / 服务号）

### 读者侧

| 需求 | 入口方向 | 说明 |
| --- | --- | --- |
| 看已关注的内容 | 微信首页「订阅号消息」 | 按时间聚合 |
| 找某个号 | 通讯录 → 公众号 | 或首页搜索号名 |
| 取关 / 设置免打扰 | 进入公众号 → 右上角「…」 | 可设置不再关注或消息免打扰 |
| 看历史文章 | 公众号主页 → 历史消息 / 菜单 | — |

提醒用户：公众号由**第三方运营**，内容责任在运营者，微信是平台。对内容有异议可通过公众号页的投诉入口反馈。

### 创作者 / 运营侧

| 事项 | 入口 |
| --- | --- |
| 注册与登录 | `mp.weixin.qq.com` |
| 发文、素材、菜单、自动回复 | 公众平台后台 |
| 用户管理与留言 | 后台「互动管理」 |
| 数据统计 | 后台「数据统计」 |
| 认证与资质 | 后台「设置」→ 认证相关 |

要点：
- 个人主体与企业主体的能力不同（认证、支付、接口权限），注册时按主体选
- 服务号与订阅号的推送频次规则不同，以平台公示为准
- 名称、头像、简介的修改有次数与审核限制

## 二、视频号

### 用户侧

**入口方向**：发现 → 视频号
**搜索兜底**：搜索「视频号」或创作者名称

常见操作：
- 关注 / 不感兴趣 / 举报（长按或右上角菜单）
- 直播：视频号内进入直播间
- 视频号小店：购物与售后走小店自身的订单与客服

### 创作者侧

| 事项 | 入口 |
| --- | --- |
| 开通与发布 | 微信内 发现 → 视频号 → 右上角个人中心 |
| 创作者中心 / 数据 | 视频号个人中心内 |
| 直播与带货 | 视频号后台相关入口（按页面实际提供为准） |
| 违规与申诉 | 通知中心的违规提示内通常带申诉入口 |

要点：
- 带货需要相应资质与类目审核
- 内容违规以平台通知为准，申诉在通知内提交
- 搬运他人内容、刷量、导流违规都会影响推荐与账号状态

## 三、搜一搜 / 看一看

- **搜一搜**：微信首页顶部搜索，可搜公众号文章、小程序、视频号、朋友圈、百科等，结果按来源分类
- **看一看**：发现页内，基于社交推荐的内容流

用户问"为什么搜不到我的号"时，说明：
1. 搜索结果受账号活跃度、内容质量、是否被限制影响，平台不保证收录
2. 确认账号状态正常（无违规限制）
3. 以平台搜索规则为准，不提供任何"提升收录"的作弊手段

## 四、内容违规与申诉

**流程**：

```
1. 看清违规通知：哪条内容、违反哪条规则、有什么后果
2. 判断是自己误发还是被盗用/被误判
3. 按通知内的申诉入口提交（通常在通知详情页）
4. 提交材料：说明情况 + 证据截图 + 整改说明
5. 等待复核，结论以平台为准
```

**若账号被盗导致发布违规内容**：先走账号安全流程（改密、踢设备），申诉时说明被盗情况。

**不提供**：绕过审核的技巧、规避关键词检测的话术、批量搬运工具。

## 五、内容生态红线

- 不搬运、不洗稿、不盗用他人原创内容
- 不做诱导分享、诱导关注、集赞营销
- 不发未经核实的信息（尤其涉医疗、财经、时政）
- 不刷量、不买粉、不刷播放
- 不利用公众号/视频号做违规导流（如导流到违规交易）

## 六、常见问题骨架

| 问法 | 回答骨架 |
| --- | --- |
| "怎么开公众号" | 主体选择 → `mp.weixin.qq.com` 注册 → 认证与资质提醒 |
| "公众号发的东西能信吗" | 内容为第三方责任，给出核实建议与举报入口 |
| "视频号被限流了" | 说明影响因素，查违规通知，走申诉；不提供作弊手段 |
| "视频号买的东西要退" | 走视频号小店的订单与客服，再走支付账单投诉 |
| "公众号文章想投诉" | 文章页 / 公众号主页的投诉入口 → 平台处理 |
