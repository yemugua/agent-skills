# 企业微信：外部联系人、客户群、管理后台

> 企业微信与微信是两个独立产品，数据不互通，管理主体是企业。

## 一、先区分：个人微信 vs 企业微信

| 维度 | 个人微信 | 企业微信 |
| --- | --- | --- |
| 归属 | 个人 | 企业/组织 |
| 管理者 | 本人 | 企业管理员（后台可管理成员与客户） |
| 客户管理 | 无体系化能力 | 外部联系人、客户群、客户标签 |
| 后台 | 无 | `work.weixin.qq.com` |
| 离职继承 | 无 | 管理员可分配客户给其他成员 |

用户问"为什么企业微信里看不到微信好友"时，说明二者体系和权限不同，不是故障。

## 二、常见使用问题

| 需求 | 入口方向 | 说明 |
| --- | --- | --- |
| 加外部微信客户 | 企业微信内「客户联系 / 外部联系人」 | 由企业开通该能力后才可用 |
| 客户群 | 工作台 / 客户群入口 | 群成员可含微信用户 |
| 审批、打卡、汇报 | 工作台对应应用 | 应用由企业管理员配置 |
| 企业通讯录 | 通讯录页 | 由管理员维护 |
| 与微信消息互通 | 需在后台开启相关能力 | 由管理员设置 |

**关键判断**：很多"用不了"的问题实际上是**管理员没开通/没配置**。遇到功能缺失，先让用户问本企业管理员，而不是找微信客服。

## 三、管理侧（管理员）

**入口**：`work.weixin.qq.com`

常见管理动作：
- 成员与部门管理、邀请加入
- 应用与工作台配置
- 客户联系权限、客户群、客户标签规则
- 离职继承（把离职成员的客户分配给他人）
- 安全与管理后台登录保护

## 四、员工离职 / 换岗时的客户归属

原则：企业微信的客户关系归属**企业**，由管理员分配。这一点与个人微信完全不同，需要在用户问"离职后客户怎么办"时讲清楚。

## 五、合规边界

- 不提供批量爬取企业微信通讯录、客户信息的方法
- 不提供绕过企业管理的"私域搬运"工具
- 员工导出客户数据需获得企业授权，遵守企业的数据管理规定
- 不提供外挂式自动加人、群发工具（违反平台规范且有封禁风险）

## 六、常见问题骨架

| 问法 | 回答骨架 |
| --- | --- |
| "企业微信怎么加微信客户" | 说明需企业开通客户联系，找管理员 |
| "我能把企业微信客户导出来吗" | 受企业权限与管理规定约束，需管理员授权，不提供绕过方法 |
| "打卡/审批用不了" | 管理员配置问题，找企业管理员 |
| "离职了客户还在吗" | 归属企业，由管理员分配 |
| "企业微信和个人微信哪个好" | 按场景：个人社交用微信，经营协同用企业微信 |
