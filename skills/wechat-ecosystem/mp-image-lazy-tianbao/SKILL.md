# 小程序图片懒加载优化

## 适用场景
小程序图片懒加载与体积优化指引。

## 输入
按 `templates/场景表单.md` 填写场景、程度、可用工具与约束。

## 操作步骤
1. 打开 `templates/场景表单.md`，填写本次场景信息。
2. 运行：`python scripts/mp_image_lazy.py <你填写后的表单路径>`

4. 每阶段完成后做阶段验收，禁止跳步。
