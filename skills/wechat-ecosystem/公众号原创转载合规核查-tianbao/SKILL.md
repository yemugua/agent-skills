# 公众号原创转载合规核查

## 适用范围
- 运营微信公众号、需要定期发布图文/音频/视频的账号主体。
- 典型场景：把转载文章标成原创、未授权转载他人内容、洗稿改头换面、配图字体音乐未授权、转载违规内容连带担责。
- 与「小程序内容安全合规」「小程序广告与流量主合规」「小程序隐私合规」互补，覆盖图文内容生产的版权与合规链条。

## 工作流
1. 让运营者填写 `templates/采集表.md`（公众号名称 + 原创声明/转载授权/素材版权等字段）。
2. 运行核查脚本：
   ```
   python scripts/official_account_reprint_compliance.py <采集表.md>
   ```
3. 脚本输出多段报告：结论摘要 → 分项核查 → 阻断项与风险 → 整改清单 → 边界。
4. 按阻断项（必须处理）与风险项（建议处理）逐条整改，留存授权凭证与自查记录。

## 核查维度（6 大域）
1. **原创声明合规**：原创声明仅限本人原创，将转载/改编/汇编标原创属滥用（阻断）。
2. **授权转载合规**：转载须取得授权（白名单/书面/邮件），并保留署名与来源（未授权=阻断）。
3. **洗稿与抄袭边界**：实质性相似（改头换面/同义替换/照搬数据）属侵权（阻断）。
4. **素材版权**：配图/字体/背景音乐须解决版权，避免图片字体音乐侵权（风险）。
5. **转载平台规则与连带责任**：转载违规/虚假/敏感内容须承担连带责任（阻断）。
6. **原创权益与维权**：授权记录留存、跨平台发布归属、违规投诉历史（风险）。

## 判定规则
- 任一**阻断项**命中 → 总体结论「不通过」。
- 仅有**风险/待办项** → 总体结论「有风险」。
- 均无 → 总体结论「通过」。
- 采集表全空 → 退出码 2，输出「待补正」。

## 边界
- 仅做合规核查与整改指引，**不替代《著作权法》、微信平台规则与正式法律意见**；重大侵权场景请咨询律师。
- 原创声明仅限本人原创；转载须授权；洗稿（实质性相似）属侵权；转载方对转载内容承担连带责任。
- 详细规则见 `rules/原创声明与授权转载要点.md` 与 `rules/洗稿边界与素材版权.md`。
