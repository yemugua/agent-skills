# 微信聊天记录转保险理赔材料

> 保险理赔是场证据战。对方是持牌机构，有法务、有模板。
> **扫要件** → **算时效** → **找拒赔破绽** → **列下一步**

---

## 解决什么问题

被保险公司拒赔的时候，最难受的不是"钱没拿到"，是**不知道到底缺什么、还有没有救**。

而理赔沟通几乎全在微信里——报案、提交材料、核定金额、拒赔理由、催告往来。几千条消息里真正关键的可能只有十几条，淹没在"你好""收到""在吗"里。

这个技能把微信聊天记录拆成理赔案件的四件套：

- **要件齐不齐** —— 按险种逐项对照，缺什么、去哪里补
- **时效还剩多少** —— 按《保险法》第 26 条算，精确到天
- **拒赔理由怎么破** —— 把对方的话拆开，对照条款和法条找破绽
- **下一步做什么** —— 按紧迫度排序的行动清单

## 为什么 AI 单独做不好

| 环节 | AI 直接做的典型错误 | 本技能的做法 |
|---|---|---|
| 时效起算 | 从"事故发生日"起算 2 年 | 从"**知道或应当知道**事故发生之日"起算，两者可能差好几年 |
| 金额 | 看到 38650 就报 38650 | 提示**医保统筹 / 第三方已赔 / 保单免赔额**三重扣除 |
| 拒赔 | 说"保险公司拒赔不合理" | 指出《保险法》**第 19 条**：免责条款未提示说明的不产生效力，且**举证责任在保险公司** |
| 证据 | 建议"多收集证据" | 区分承诺与意愿，列出对方**八大抗辩**及各自应对 |
| 闲聊噪声 | 把"在吗"当线索 | 关键节点白名单过滤，只认程序性表述 |

**最要命的是时效。** 很多人以为"保单一直交着钱，时效就不会过"——错。同一保单下多次出险，**每一次单独计算时效**，前面的没处理，后面的一年就悄悄过完了。

## 四类场景

| 场景 | 险种 | 核心争议 | 首要动作 |
|---|---|---|---|
| `health` | 健康保险 | 既往症、等待期 | 查投保告知记录 |
| `accident` | 意外伤害保险 | 是否属意外、伤残等级 | **尽快做伤残鉴定** |
| `property` | 财产保险 | 是否属标的、金额多少 | 找评估 / 维修凭证 |
| `liability` | 责任保险 | 行为与损害的因果关系 | 固定损害事实 |
| `all` | 全部 | 不知道属于哪种 | 先扫一遍，再针对性深挖 |

**要件库共 39 项**，每项写清四件事：要件是什么、谁举证、微信里能找什么、缺了会怎样。

## 三步上手

```bash
# 1. 导出聊天记录
#    依赖技能 wechat-local-reader-tianbao
#    手动整理成每行 [YYYY-MM-DD HH:MM] 发送者: 内容 也行

# 2. 选场景扫描
python scripts/extract.py --file 聊天记录.md --scenario accident

# 3. 换个视角复核
python scripts/extract.py --file 聊天记录.md --scenario all --as-of 2026-10-04
```

> `--as-of` 用来按指定日期算时效。**做正式材料时务必显式指定**，别用默认的今天。

## 报告结构

固定八段，每段对应一个实务问题：

| 段 | 回答什么 |
|---|---|
| 一、结论先行 | 覆盖率多少？时效还剩几天？争议焦点是什么？ |
| 二、要件命中表 | 每项要件谁举证、命中几处、命中什么词 |
| 三、缺失要件与补强 | 缺什么、**去哪里补**（附具体渠道） |
| 四、争议焦点 | 拒赔原话 + 破局点 + 必查法条 |
| 五、关键程序节点 | 报案 / 材料 / 定损 / 拒赔 / 到账 / 催告 |
| 六、金额梳理 | 时间倒序表格，提示三重扣除 |
| 七、关键证据片段 | 带要件归属与举证责任 |
| 八、下一步行动清单 | 按紧迫度排序 |

**实测样例**：健康险场景要件覆盖 8/11（73%），正确抽出 38650 / 26800 / 6800 / 10000 四个金额，识别出 4 条拒赔表述与 5 类程序节点。

## 六个最常见的拒赔理由

| 拒赔理由 | 破局方向 |
|---|---|
| **未如实告知** | 《保险法》第 16 条：告知义务**以询问范围为限**，如实回答了不得拒赔 |
| **免责条款** | 第 19 条：**未作提示或明确说明的，该条款不产生效力**，举证责任在保险公司 |
| **等待期内出险** | 核对实际等待期与起算日；关注是否属"2 年"类特殊条款 |
| **既往症** | 提交投保前的体检 / 门诊记录证明此前无此病 |
| **不属于意外伤害** | 逐条对"意外"四要件举证，尤其病因链条 |
| **已过时效** | 核查中断事由：《民法典》第 195 条四种情形 |

## 完整参数

| 参数 | 必填 | 说明 |
|---|---|---|
| `--file` | ✅ | 聊天记录文件（`.md` / `.txt`） |
| `--scenario` | | `health` / `accident` / `property` / `liability` / `all` |
| `--as-of` | | 时效基准日 `YYYY-MM-DD`，默认今天 |
| `--focus` | | 只分析含该关键词的消息（调试用） |
| `--out` | | 输出文件；不填打印到屏幕 |
| `--format` | | `md`（默认）/ `json` |

**输入格式**：`[2026-03-05 14:32] 对方姓名: 消息内容`
兼容 markdown 导出的 `- ` 前缀、秒级时间、无发送者行。

## 边界

**能做**：扫描要件、抽取金额日期、算时效倒计时、识别拒赔表述、生成材料与行动清单、指出程序性权利窗口

**不能做**：

- ❌ 出具法律意见、预测赔付金额或胜诉率
- ❌ 代你与保险公司交涉
- ❌ **修改、剪辑或伪造任何记录**——这是刑事红线，且在任何争议中都会被"完整记录"抗辩击穿
- ❌ 代替执业律师

**触发即转律师**：金额较大（十万以上）、已收到书面拒赔、临近时效、涉及伤残等级争议、涉及刑事风险。
