# 拒赔抗辩分析与应对

> 收到拒赔后，把每一条拒赔理由拆开、找依据、找破绽。
> **对方是持牌机构、有法务、有模板。你要做的是把战场拉回条款和法条。**

## 一、拒赔理由逐条分析

### 理由 1：________（照抄对方的原话）

**对方依据的条款**：________________

**条款性质检查**：

- [ ] 这是**免除保险人责任**的条款吗？
  - 是 → 进入下方"第 19 条攻防"
  - 否 → 不能直接作为拒赔依据

**《保险法》第 19 条攻防**（核心武器）：

> 格式条款中免除保险人责任的条款，保险人在订立合同时应当予以提示投保人注意，
> 并对该条款的内容以书面或口头形式向投保人作出**明确说明**；
> **未作提示或明确说明的，该条款不产生效力。**

举证责任在**保险公司**。他们必须拿出：

- [ ] 投保时的**投保提示单**（带投保人签字）
- [ ] **明确说明的证据**（书面说明回执、录音录像、双录）
- [ ] 系统中"已阅读并确认"的点击记录

**如果拿不出** → 该条款对你不生效，可主张赔付。

### 理由 2：未如实告知

**《保险法》第 16 条核心规则**：

> **投保人的告知义务仅限于保险人询问的范围。**
> 投保人如实回答了询问表的，**保险人不得以未告知为由解除合同、拒赔**。

三步检验：

| 检验项 | 结论 | 证据 |
|---|---|---|
| 保险人**是否询问**了该情况？ | ☐ 询问了 ☐ **没询问** | 投保问卷 |
| 我**是否如实回答**了？ | ☐ 如实 ☐ 部分不实 | 问卷原件/投保录音 |
| 该情况**是否重要**？ | ☐ 重要 ☐ 不重要 | 条款中的询问范围 |

**结论**：

- 保险人**没询问** → 不得以未告知拒赔
- 我**如实回答**了 → 不得以未告知拒赔
- 确实**未如实回答且该项属于询问范围** → 保险人有权解除，但**须在知道之日起 30 日内**（《保险法》第 16 条第 6 款），且需退还保费

> 举证关键：**投保时的健康告知问卷原件或投保录音录像**。这是本案最有力的单据。

### 理由 3：等待期内出险

| 检验项 | 结论 |
|---|---|
| 保单约定的等待期是多少天？ | ________ |
| 投保日 = ? | ________ |
| 等待期届满日 = ? | ________ |
| 确诊/事故日 = ? | ________ |
| **是否真的在等待期内**？ | ☐ 是 ☐ 否 ☐ 差几天：______ |

**两个可能的破局角度**：

1. **等待期条款本身未提示说明** → 按第 19 条不生效
2. **"2 年等待期"条款** → 部分产品（尤其防带病投保型）约定投保后 2 年内出险不赔，
   **这个约定必须在投保时明确提示**，否则同样适用第 19 条

> 提醒：不同产品等待期差异极大，**30 天 / 90 天 / 180 天 / 2 年**都存在。
> 销售口头说的等待期不可信，**以条款书面为准**。

### 理由 4：既往症 / 属于疾病而非意外

**这一条是意外险拒赔的主力。**

判断结构：

| 检验项 | 结论 |
|---|---|
| 事故是否"外来的"？ | ☐ 是 ☐ 否 |
| 是否"突发的"？ | ☐ 是 ☐ 否 |
| 是否"非本意的"？ | ☐ 是 ☐ 否 |
| 是否"非疾病的"？ | ☐ 是 ☐ **否** ← 关键 |
| 是否有**旧伤/基础病**证据？ | ☐ 有 ☐ 无 |

**如果"非疾病的"这一项填"否"** → 不属于意外伤害，保险公司拒赔有依据。

**破局方向**：

- 举证**投保前的体检报告/病历**，证明此前无此疾病
- 论证事故有**独立的外部诱因**（如路面湿滑致摔、他人撞击）
- 检查事故前是否已投保其他同类险（多份保单可相互佐证"非既往症"）

**猝死、猝倒、疾病发作后摔伤**通常按疾病处理，这是行业惯例，很难突破。

### 理由 5：材料不全 / 证据不足

**关键：保险公司必须出具书面《拒赔通知书》并说明理由（《保险法》第 24 条，3 日内）。**

- [ ] 收到书面拒赔通知了吗？**没有** → 口头拒赔无依据，要求出具书面
- [ ] 拒赔通知写明理由了吗？**没有** → 可主张程序违法
- [ ] 通知里列的缺项，与我在聊天里发过的一致吗？→ **不一致即为把柄**

**已提交材料记录**（回溯聊天记录，逐项列出并附时间）：

| 材料 | 提交日期 | 提交方式 | 对方确认收到 |
|---|---|---|---|
| | | ☐微信 ☐邮寄 ☐上传 | 聊天记录第____ 条 |
| | | ☐微信 ☐邮寄 ☐上传 | 聊天记录第____ 条 |

> 对方说"没收到"而聊天记录里明确"收到""我发你""请查收"——**这是极好的反驳证据**。

### 理由 6：已过诉讼时效

**《保险法》第 26 条**：非人寿保险 **2 年**，人寿保险 **5 年**，交强险 **1 年**（道交法第 88 条）。

- [ ] ① 我方提出履行请求（催告）—— 记录：________

> **已过时效不是死路**：可核查是否存在中断事由、是否存在对方承诺履行的记录。
> 但**必须尽快咨询律师**，自行处理风险很高。
