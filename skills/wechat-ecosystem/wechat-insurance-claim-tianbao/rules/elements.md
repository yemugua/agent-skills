# 保险理赔要件库

> 按"谁主张谁举证"拆解三大险种的理赔要件。每一项写清四件事：**要件是什么 / 谁举证 / 微信里能找什么 / 缺了会怎样**。

## 通用判定框架

任何理赔争议都过这三关，缺一关就不用往下看：

| 关卡 | 问题 | 不通过的后果 |
|---|---|---|
| **保险合同是否成立** | 保单有效吗？在保险期间内吗？ | 一切免谈 |
| **保险责任是否触发** | 这次事故属于保险责任范围吗？ | 属于免责情形就没戏 |
| **损失是否真实、是否举证** | 损失有证据吗？金额算对吗？ | 只能拿到自己证明的那部分 |

## 一、健康保险（疾病/医疗）

**核心特征**：保额高、周期长、拒赔理由集中在"既往症"和"等待期"。

| 要件 | 举证方 | 微信里能找什么 | 缺失后果 |
|---|---|---|---|
| 投保生效日 | 保险公司 | 投保成功通知、扣款记录、保单截图 | 无法确认等待期起算点，保险公司大概率以此拒赔 |
| 等待期是否经过 | 被保险人主张 | 投保日期 vs 首次确诊/就诊日期 | **等待期内出险是健康险第一拒赔理由** |
| 既往症除外 | 保险公司主张 | 投保前的就诊记录、体检报告、问诊记录 | 你无法自证"没看过病"，保险公司拿历史记录一否就成立 |
| 疾病确诊事实 | 被保险人 | 检查报告、诊断证明、病理报告、出院小结 | 无诊断只有症状，理赔直接驳回 |
| 治疗行为与疾病的因果关系 | 保险公司可抗辩 | 病历中"主诉/诊断/治疗方案"的记录 | 保险公司主张"既往症导致"时的抗辩点 |
| 医疗费用明细 | 被保险人 | 发票、费用清单、医保结算单 | 只报总额，不报明细会被扣减 |
| 医保已报销部分 | 保险公司 | 医保结算单 | **重复报销问题**：已走医保的不能再报一次 |
| 免赔额约定 | 保险公司主张 | 保单条款 | 免赔额部分必然被扣，需提前知道 |
| 社保身份与就诊医院等级 | 双方 | 就诊记录 | 约定"限二级及以上公立医院"，去私立/社区医院可能不赔 |
| 出险通知及时性 | 被保险人 | 出险通知记录 | 保险法要求**及时通知**，故意拖延可能影响赔付 |
| 等待期内特殊情况 | 被保险人 | 智能核保问卷、体检记录 | 投保时已告知的智能核保结论是有利证据 |

**健康险最大陷阱**：**"两年内"条款**。银保监会规定，健康保险等待期不得超过 2 年，部分产品为了防带病投保，会在条款里约定"投保后 2 年内因疾病就诊的，保险公司不承担责任且可退还保费"。买之前看不出来，理赔时才知道。

## 二、意外伤害保险

**核心特征**：争议集中在"是否属于意外"、"是否属于除外责任"、"伤残等级"。

| 要件 | 举证方 | 微信里能找什么 | 缺失后果 |
|---|---|---|---|
| 意外事故的客观发生 | 被保险人 | 事故现场照片、视频、报警记录、急救记录 | 没有客观发生记录，只有单方陈述易被否 |
| "意外伤害"四要件 | 被保险人 | 外来的、突发的、非本意的、非疾病的 | 四要素任一不满足即不属意外 |
| **是否疾病导致** | 保险公司抗辩 | 病历记载的病因 | **猝死、猝倒、疾病发作后摔伤**通常按疾病处理不赔 |
| 既往伤残/疾病基础 | 保险公司抗辩 | 既往病史记录 | "旧伤复发"是常见拒赔理由 |
| 意外险四大除外责任 | 保险公司主张 | 事故性质判断 | 猝死、食物中毒、酒精中毒、故意行为、妊娠分娩 —— **这些都不赔** |
| 伤残等级评定 | 被保险人 | 伤残鉴定书（需正规机构） | **没有鉴定书，一级伤残赔不了** |
| 误工费 | 被保险人 | 工资流水、误工证明、单位证明 | 需要实际收入减少的证据 |
| 护理费 | 被保险人 | 护理人员身份、护理必要性说明 | 无医嘱或无实际护理的不予支持 |
| 交通/航空/公共交通等额外保障 | 被保险人 | 事故类型证明 | 属于特定场景的额外责任，需单独确认 |
| 施救费用 | 被保险人 | 施救行为的相关凭证 | 施救费通常单独限额，需与医疗费区分 |
| 伤残津贴/一次性伤残金 | 被保险人 | 伤残等级 + 保单约定 | 等级决定金额，差额必须靠鉴定书主张 |

**意外险理赔三步走**：① 事故性质定性（意外 or 疾病）→ ② 伤残等级鉴定 → ③ 金额按等级套用。

**最容易忽略的一步**：**伤残鉴定必须在治疗终结后做**，且要在规定时限内。做完治疗立刻去鉴定和拖延几个月再鉴定，结果可能不同。

## 三、财产保险

**核心特征**：争议集中在"损失是否属于保险标的"、"损失金额怎么算"、"免责情形是否适用"。

| 要件 | 举证方 | 微信里能找什么 | 缺失后果 |
|---|---|---|---|
| 保险标的与损失对象同一 | 被保险人 | 受损物品的购买凭证、型号、归属 | 受损的不是投保标的 → 不赔，这是财产险第一拒赔点 |
| 保险金额是否覆盖损失 | 保险公司主张 | 保单保额、损失评估 | **不足额保险要按比例赔付**，这点很多人不知道 |
| 损失的实际金额 | 被保险人 | 维修单、购置发票、鉴定评估报告 | 只能赔到实际损失，哪怕物品全新 |
| 事故原因 | 双方 | 事故现场记录、报案记录 | 原因不明时举证责任在受益人 |
| 自然磨损 vs 意外损坏 | 保险公司抗辩 | 维修单明细 | 折旧、老化不算意外损坏 |
| 免赔额与免赔率 | 保险公司主张 | 保单条款 | 免赔部分必然被扣 |
| 是否重复保险 | 保险公司 | 多份保单 | 重复投保的部分不能重复获赔 |
| 施救、清除残骸费用 | 被保险人 | 相关发票 | 需区分财产损失与施救费用 |
| 第三方代位求偿 | 保险公司主张 | 责任方信息 | 已从第三方获赔的部分不能重复索赔 |
| 危险物处置合规 | 双方 | 处置资质、仓储记录 | 危险品、无证经营等特殊标的另有限制 |
| 自然灾害专属条款 | 被保险人 | 气象/地震证明 | 部分自然灾害需专门举证 |

**财产险关键认知**：**保险金额 ≠ 赔付金额**。保额 50 万的卡贝，丢了赔 50 万；保额 50 万的旧手机，丢了可能只赔几千。

## 四、责任保险（含雇主责任、公众责任、产品责任）

**核心特征**：第三方索赔，责任方通常是被保险人。

| 要件 | 举证方 | 微信里能找什么 | 缺失后果 |
|---|---|---|---|
| 损害事实发生 | 受害方主张 | 事故记录、诊疗记录、现场照片 | 无损害事实 → 责任险无从触发 |
| 被保险人行为与损害的因果关系 | 受害方 | 行为描述、时间线 | 单纯损害结果无因果关系不赔 |
| 受害方确已受损 | 受害方 | 诊断、票据、误工证明 | 主张金额需有对应凭证 |
| 被保险人在保险期内 | 保险公司 | 事故发生时间 vs 保险期间 | **事故必须在保险期内**，出险后投保无效 |
| 每次事故限额 | 保险公司主张 | 保单条款 | 超过限额部分不赔 |
| 免赔额 | 保险公司主张 | 保单条款 | 免赔部分由被保险人承担 |
| 附加险覆盖 | 双方 | 保单批单 | 雇主责任险需附加"职业病""上下班"等才覆盖特定场景 |
| 追偿权 | 保险公司 | 责任方信息 | 理赔后可向第三方追偿 |

## 五、拒赔理由清单与破局

保险公司拒赔时**必须在合同中找依据**，常见的是这九类：

| 拒赔理由 | 法律依据 | 破局方法 |
|---|---|---|
| **未如实告知健康状况** | 保险法第 16 条 | 区分"询问范围"与"主动告知"。**投保人如实回答了询问表的，保险公司不得以未告知为由拒赔**。看投保时的健康告知问卷记录 |
| **属于免责条款** | 合同约定 | 核对该条款是否属于**免除保险人责任的条款**。依保险法第 19 条，**此类条款必须做显著提示和明确说明**，未提示的条款不产生效力 |
| **等待期内出险** | 合同约定 | 核对实际等待期条款与起算日，注意是否有"2 年"类特殊约定 |
| **既往症** | 合同约定 + 健康告知 | 提交投保前的体检/就诊记录，证明既往无此病 |
| **不属于意外伤害** | 保险法定义 | 逐条对"意外"四要件举证，尤其病因链条 |
| **未按约定方式通知** | 保险法第 21 条 | **保险人已知事故发生**的情况下仍要求通知的，不得以未通知为由拒赔，但可能影响定损 |
| **超过诉讼时效** | 保险法第 26 条 | 见 `deadlines.md`，人身险各险种不同 |
| **不属于保险标的** | 合同约定 | 提交标的归属证明（购买凭证、权属登记） |
| **损失金额不足** | 不足额保险规则 | 核对保额与实际价值比例 |

**保险法第 19 条是关键武器**：格式条款中免除保险人责任的条款，**保险人在订立合同时应当予以提示投保人注意，并对该条款的内容以书面或口头形式向投保人作出明确说明；未作提示或明确说明的，该条款不产生效力**。

→ 实务中：保险公司拿不出"已明确说明"的证据时，该免责条款对被保险人不生效。

## 六、微信里能挖到的理赔证据清单

按证据强度从高到低：

| 证据类型 | 微信里怎么找 | 证明力 |
|---|---|---|
| **保险公司出具的书面结论** | 搜"拒赔""核定""赔付""审核" | ★★★★★ 对方自认，最硬 |
| **理赔款到账记录** | 搜"已到账""赔款""转账"金额 | ★★★★★ 自证已实际赔付，是后续计算的基准 |
| **保险公司的方案/报价消息** | 搜"方案""赔付金额""计算" | ★★★★ 能锁定保险公司认可的口径 |
| **报案与受理记录** | 搜"报案""已受理""立案" | ★★★★ 证明时效链未断 |
| **双方对事实的一致陈述** | 事故经过描述 | ★★★★ 无争议事实最佳证据 |
| **保险公司的要求清单** | 搜"需要提供""请上传""材料" | ★★★ 能反证哪些材料保险公司认可 |
| **沟通中对责任的确认** | 搜"我们责任""我们这边""会赔" | ★★★★ 责任自认 |
| **催促与答复** | 搜"什么时候""尽快""催" | ★★★ 证明催告，可中断时效 |
| **伤残/病历/发票的传递记录** | 搜文件名、日期 | ★★★ 证明材料已交付 |
| 口头承诺类消息 | 泛泛的"再看看" | ★ 弱，易被解释为协商 |

## 七、金额构成

不同险种的赔付算法完全不同：

### 医疗费用报销类
```
可报金额 = (总医疗费 − 医保统筹支付 − 第三方已赔 − 保单免赔额) × 赔付比例
```
注意：多数产品设**年度免赔额**（如 1 万元起赔，超过部分才按比例报）。

### 意外伤残类
```
伤残金 = 保额 × 伤残等级系数
```
等级系数（按《人身保险伤残评定标准》十级一等的部分）：

| 等级 | 系数 | 等级 | 系数 |
|---|---|---|---|
| 一级 | 100% | 六级 | 50% |
| 二级 | 90% | 七级 | 40% |
| 三级 | 80% | 八级 | 30% |
| 四级 | 70% | 九级 | 20% |
| 五级 | 60% | 十级 | 10% |

> 多数意外险身故赔 100%、伤残按等级赔，也有产品按"伤残按比例 + 意外身故赔 100%"的双轨设计，以保单为准。

### 误工费
```
误工费 = 实际减少的收入（或日均收入 × 误工天数）
```
举证要点：**收入流水 + 单位出具的误工证明 + 具体误工天数**。收入证明不足时，通常按受诉法院所在地上年度职工平均工资计算。

### 财产损失类
```
赔付 = 实际损失 × 保险金额 / 保险标的实际价值
```
（不足额保险按比例赔付；足额保险则赔实际损失，全损才给满额）

## 八、三大险种对比速查

| 维度 | 健康险 | 意外险 | 财产险 |
|---|---|---|---|
| 核心争议 | 既往症、等待期 | 是否属意外、伤残等级 | 是否属标的、金额多少 |
| 首要动作 | 查投保告知记录 | **做伤残鉴定** | **找评估/维修凭证** |
| 时效压力 | 2 年（部分条款） | 2–5 年 | 2 年 |
| 最强拒赔理由 | 未如实告知 | 不属于意外 | 不属于保险标的 |
| 有利单据 | 投保问卷、医保结算单 | 鉴定书、事故证明 | 购置发票、评估报告 |
| 能否重复获赔 | 医保已报部分不能重复 | 不能 | 第三方已赔不能重复 |
