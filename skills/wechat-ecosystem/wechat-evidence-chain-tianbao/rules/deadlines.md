# 时效、管辖与金额速查

> ⚠️ **本文件为速查参考，不构成法律意见。** 各地裁判尺度差异明显，涉及具体金额或已接近时效临界时，务必咨询律师或当地法律援助中心。

---

## 一、诉讼时效速查

| 纠纷类型 | 时效 | 起算点 | 法条 |
|---|---|---|---|
| 一般民事纠纷 | **3 年** | 自知道或应当知道权利受损且义务人之日起 | 民法典 第 188 条 |
| 劳动争议（仲裁） | **1 年** | 自知道或应当知道权利被侵害之日起 | 劳动争议调解仲裁法 第 27 条 |
| 拖欠劳动报酬（劳动关系存续期间） | 不受 1 年限制 | — | 同上 |
| 劳动关系终止后的欠薪争议 | **1 年** | 自劳动关系终止之日起 | 同上 |
| 人身损害 | 3 年 | 自知道或应当知道之日起 | 民法典 第 188 条 |
| 离婚诉讼 | 无固定时效 | — | — |
| 涉外民事 | 3 年 | 特殊规则，另有规定 | 涉外民事关系法律适用法 |

### 特殊规则

- **最长保护期**：自权利受损害之日起超过 **20 年**的，法院不予保护（有特殊情况可申请延长）
- **不适用时效**：请求停止侵害、排除妨碍、消除危险；请求返还不动产及孳息；请求支付抚养费、赡养费、扶养费

### 时效中断（《民法典》第 195 条）

以下任一情形发生，**时效中断并从中断时起重新计算**：

| 中断情形 | 微信里的证据 |
|---|---|
| 权利人向义务人提出履行请求 | 催款/催工薪消息 |
| 义务人同意履行义务 | "下月还你""我知道了""我安排一下" |
| 权利人提起诉讼或申请仲裁 | 提交材料回执、受理通知书 |
| 义务人同意以某种方式履行 | 部分还款记录 |

> **战术价值**：一次有效催收 = 时效重新起算。
> 但注意——只有**有效**的催收才中断（如实主张权利、指向明确、留有记录），空泛的抱怨不算。

### 时效届满的后果

- **被告提出时效抗辩** → 法院可能驳回诉讼请求
- **法院不主动适用** → 被告不提，法院不主动说
- **时效届满后自愿履行** → 履行后不得请求返还（除欺诈、胁迫等情形）

> ⚠️ 因此：**每次自认债务、同意还款、承诺付款，都会让时效重新起算** —— 对方可能正是靠这个让你错过时效。

## 二、管辖速查

| 纠纷类型 | 管辖法院 | 依据 |
|---|---|---|
| 一般民事 | 被告住所地 或 合同履行地 | 民事诉讼法 第 21 条 |
| 劳动争议 | 劳动合同履行地 或 用人单位所在地 | 劳动争议调解仲裁法 第 21 条 |
| 租房合同 | 房屋所在地（不动产专属管辖） | 民事诉讼法 第 34 条 |
| 建设工程合同 | 不动产所在地（专属管辖） | 民事诉讼法 第 34 条 |
| 合同约定管辖 | 依有效约定（不能违反级别、地域管辖） | 民事诉讼法 第 35 条 |
| 涉外 | 依合同约定；无约定按法定连接点 | 涉外民事关系法律适用法 |

### 专属管辖（不能协商、不能改）

- **不动产**：房屋所在地
- **建设工程**：不动产所在地
- **港口作业**：港口所在地
- **继承遗产**：被继承人死亡时住所地或主要遗产所在地

> 注意：约定管辖**不能违反专属管辖和级别管辖**。约定了也会被裁定无效。

### 消费维权

- 经营者住所地 或 商品销售地
- 可向**消费者所在地**法院起诉（有利于维权人）
- 平台购物：一般可向平台所在地或商家所在地

## 三、金额门槛与程序

| 争议金额 | 程序 | 建议 |
|---|---|---|
| 基层法院管辖（一般） | 民事一审 | 上限各省不同，多为当地上年GDP或年平均工资的一定倍数 |
| 劳动仲裁 | **免费，不预交费用** | 无论金额一律免费 |
| 小额诉讼程序 | 一审终审 | 简单金钱给付，通常 30% 以下标准（各省不同），审限短 |
| 速裁程序 | 简易程序中 | 简单金钱给付，通常 20% 以下标准 |
| 支付令 | 督促程序 | 需债务人明确，2—3 个月出结果 |
| 一审不服 | 上诉 | 15 日内提起 |
| 二审不服 | 申请再审 | 6 个月内，且有法定理由 |

### 劳动仲裁特别提示

- **不收费**，且不得以无档案理由拒绝受理
- 必须先仲裁，**未经仲裁不能直接起诉**（劳动争议是前置程序）
- 仲裁时效 1 年
- 对裁决不服 → 15 日内向法院起诉
- 建议：金额较大或事实复杂时委托律师；金额较小可自行申请，劳动仲裁委一般有法律援助窗口

### 小额诉讼限额速查（各地不同，需核对当地标准）

| 案件类型 | 常见限额 |
|---|---|
| 简单金钱给付（小额诉讼） | 上年就业人员年平均工资 30% 以内 |
| 简单金钱给付（速裁） | 上年就业人员年平均工资 20% 以内 |
| 劳动争议小额 | 上年职工月平均工资 50% 以内（部分地区） |

> **务必核对当地现行标准**，各地每年调整。

## 四、费用速查

| 项目 | 标准 |
|---|---|
| 案件受理费 | 按标的额分段累计，1 万以下约 50 元，10 万约 2300 元，100 万约 1.18 万 |
| 劳动仲裁 | **免费** |
| 小额诉讼 | 受理费减半 |
| 财产保全 | 按保全金额比例，通常不超过 5000 元 |
| 保全担保 | 需提供担保（保函或现金） |
| 鉴定费 | 按项目数与标准，另行收取 |
| 律师费 | 劳动争议中由败诉方承担的情形有限，民事一般自行承担（可约定由对方承担，但法院通常不支持） |
| 诉讼费胜诉后由对方负担 | ✅ 是（败诉方负担原则） |

### 律师费能否让对方承担

| 场景 | 能否 |
|---|---|
| 劳动争议（符合条件时） | ✅ 特定情形可由用人单位承担 |
| 合同中明确约定违约方承担律师费 | ✅ 通常可主张，但需举证约定存在 |
| 格式条款排除对方主要权利 | ❌ 该约定可能无效 |
| 一般侵权/一般合同 | ❌ 一般自行承担 |
| 知识产权侵权 | ✅ 法律规定可主张 |

## 五、时效与金额的计算方法

### 时效剩余天数

```
剩余天数 = 起算日 + 时效年限 - 基准日
```

- 起算日一般是**知道或应当知道权利受损之日**，不是"发生之日"，实务中常按"确认受损之日"
- 劳动争议特别：**拖欠劳动报酬在劳动关系存续期间不受 1 年限制**
- 每次有效催收 → **起算日重置为催收日**，重新算满时效

### 金额主张

```
主张金额 = 已付部分 ÷ 无争议部分 ÷ 有争议部分
```

- 不要合并不同性质的费用（如把借款本金和利息、工资和加班费混算）
- 各项分别列明，分别给依据
- 不确定的部分标注"待核实"，**不要自己取平均或估算后当作确定数额**

### 利息计算

| 类型 | 规则 |
|---|---|
| 民间借贷无约定 | 视为无息，可主张逾期资金占用损失 |
| 民间借贷有约定 | 不得超过合同成立时一年期 LPR 的 4 倍 |
| 逾期利息 | 可按全国法院统一标准主张 |
| 迟延履行金 | 判决生效后不履行，按日万分之一点七五计 |

> LPR 每年调整，**具体倍数需查合同成立时的一年期 LPR 数值**。

## 六、时效临界情况的处理原则

**剩余 < 30 天**：
1. 立即做一次**证据固定**（全量导出 + 备份）
2. 咨询律师或当地法律援助中心（劳动仲裁找法律援助窗口）
3. 不要等——过了就很难补救

**剩余 30–90 天**：
1. 做一次有效催收（可中断时效）——但要评估是否打草惊蛇
2. 同步咨询律师

**超过 90 天**：
1. 证据链仍要整理（时效抗辩可能被提，也可能不提）
2. 评估成本收益后再决定是否主张

> **重要**：时效是被告的抗辩权，法院不主动适用。
> 也就是说——**过了时效的案件，如果对方不提时效抗辩，仍然能赢。**
> 但主动权在对方，一旦提示，很可能立即主张。
