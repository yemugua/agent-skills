# 质证风险提示（模板）

> 用途：提前推演对方会怎么攻击，提前补强。
> 原则：**不隐瞒己方弱点，但也不主动放大。**

---

## 一、结论先行

| 项目 | 内容 |
|---|---|
| 己方证据强度自评 | 强 / 中 / 弱 |
| 最大风险点 | 【一句话】 |
| 可补强空间 | 【一句话】 |
| 是否建议当庭硬刚 | 【是 / 建议先补强】 |

## 三、金额层面的风险

| 风险点 | 说明 | 应对 |
|---|---|---|
| 主张金额无对应证据 | | 补转账记录、结算单 |
| 对方认可金额与我方主张不一致 | | 全部列出，标注来源与说话人 |
| 金额被指为"玩笑" | | 找履行行为佐证 |
| 已过期未主张的部分 | | 核对时效，评估是否放弃 |

---

## 四、时间线层面的风险

| 风险点 | 说明 | 应对 |
|---|---|---|
| 时效已过 | 对方一提即可能驳回 | 评估是否仍有其他时效依据 |
| 关键节点无证据 | 主张的事实没有时间支撑 | 补第三方印证 |
| 记录时间跨度太短 | 只导了争议片段 | 补全量导出 |
| 对方拖延时间线 | 制造"双方各说各话" | 用转账、通话记录等客观时间锚点 |

---

## 五、程序层面的风险

| 风险点 | 说明 | 应对 |
|---|---|---|
| 管辖错误 | | 核对管辖法院 |
| 主体不清 | 昵称无法证明身份 | 补实名/工商信息 |
| 超过小额诉讼标准 | 只能走简易程序，审限短 | 提前评估 |
| 前置程序未完成 | 劳动争议必须先仲裁 | |

---

## 六、我方应当避免的动作

- ❌ 在微信里直接对质、摊牌、骂人（**对方会立刻开始删记录**）
- ❌ 编辑、剪辑、拼接导出文件
- ❌ 删除己方不利的聊天内容
- ❌ 把材料发给无授权的第三方
- ❌ 在社交平台公开对方个人信息
- ❌ 委托律师后又自行对外交涉（口径不一致）
