# 证据清单（模板）

> 用途：提交给仲裁员 / 法院的证据目录。
> 要求：编号连续、来源清晰、证明对象明确。

---

## 案件基本信息

| 项目 | 内容 |
|---|---|
| 案由 | 【劳动争议 / 民间借贷 / 租赁合同 / …】 |
| 申请人（原告） | 姓名、身份证号、联系方式、住址 |
| 被申请人（被告） | 名称 / 姓名、身份证号或统一社会信用代码、住所地 |
| 争议金额 | 人民币 ____ 元 |
| 主张事项 | 【简明扼要，3-5 条】 |

---

## 电子数据证据

### 证据 1：微信聊天记录导出文件

| 项目 | 内容 |
|---|---|
| 证据名称 | 微信聊天记录（【会话名称】） |
| 证据形式 | 电子数据（微信聊天记录导出文件） |
| 来源 | 申请人本机微信，【会话名称】，时间范围 ____ 至 ____ |
| 数量 | 共 ____ 条 |
| 完整性说明 | 为【会话名称】**全量连续导出**，未做删减、剪辑或编辑 |
| 载体 | 原始导出文件（.md / .txt），另存 ______ 份 |
| 证明对象 | 见下表逐段列明 |

**分段列明：**

| 序号 | 时间 | 发言人 | 内容摘要 | 证明对象 |
|---|---|---|---|---|
| 1 | ____-__-__ __:__ | 【对方】 | 【原文照录】 | 【证明____事实】 |
| 2 | | | | |

> ⚠️ 原文照录，**不要改写、不要概括**。概括会削弱真实性。

### 证据 2：微信支付 / 银行转账记录

| 项目 | 内容 |
|---|---|
| 证据名称 | 微信支付账单（【年度】） |
| 证据形式 | 电子数据 |
| 来源 | 微信支付官方账单导出 |
| 证明对象 | 【证明实际支付金额 ____ 元、支付时间 ____】 |

> 转账记录是**独立于聊天记录**的客观证据，务必单独列一份。
