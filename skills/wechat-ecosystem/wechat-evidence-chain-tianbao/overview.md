# 微信聊天记录转法律证据

> 聊天记录本身不是证据，**整理成要件齐全的证据包才是**。
> 扫出要件 → 算清时效 → 列出缺什么。

---

## 解决什么问题

摊上一场纠纷，最难的不是"要不要维权"，而是**不知道手里这些东西够不够、缺什么、还能不能告**。

这个技能把散落在几千条聊天里的关键信息自动捞出来，告诉你：

- 哪几项法律要件**有材料**、哪几项**完全没有**
- 对方认过哪些**金额**、时间线长什么样
- 时效**还剩多少天**
- 缺的部分**去哪儿补、拿不到怎么办**
- 对方会怎么**攻击**你的证据、怎么提前防

---

## 核心能力

| 能力 | 说明 |
|---|---|
| **要件扫描** | 六类场景 × 43 项要件，关键词自动命中归类 |
| **金额抽取** | 识别「5万」「1.5 万元」「50000块」，标注说话人 |
| **时效倒计时** | 自动计算剩余天数，标注是否已过期 |
| **时间线提取** | 自动识别入职、离职、催款、承诺还款等关键节点 |
| **缺失项报告** | 缺什么、缺了会怎样、去哪儿补 |
| **质证风险预演** | 对方六条抗辩 + 事前补强清单 |

### 六类场景

`labor` 劳动争议 · `rent` 租房押金 · `loan` 民间借贷 · `contract` 合同纠纷 · `tort` 侵权 · `family` 婚姻家事

## 三步上手

### 1. 拿到聊天记录

用配套技能 `wechat-local-reader-tianbao` 导出：

```bash
wechat-cli export "群名或对方昵称" --format markdown \
  --start-time "2024-01-01" --end-time "2026-10-01" --output "D:\证据\某某.md"
```

> ⚠️ **时间区间要拉满**，不要只导有印象的那几段——时效可能从"你第一次知道"起算，中间断了会被对方主张你早就知道。

已经导好了？直接进第 2 步。

### 2. 跑扫描

```bash
python scripts/extract.py --file "D:\证据\某某.md" --scenario labor --as-of 2026-10-04
```

不确定场景就先 `--scenario all` 摸底，看哪个场景命中密度最高再细跑。

### 3. 按报告出材料

按 `templates/` 下的四份模板产出：证据清单、时间线、缺失项报告、质证风险提示。

---

## 完整参数

| 参数 | 说明 |
|---|---|
| `--file` | 必填。`wechat-cli export` 出的 .md 或 .txt |
| `--scenario` | `labor`/`rent`/`loan`/`contract`/`tort`/`family`/`all` |
| `--as-of` | 时效基准日，默认今天 |
| `--since` / `--until` | 只扫指定时间区间 |
| `--focus "张三"` | 只看某个人的发言 |
| `--out` | 报告输出路径 |
| `--format` | `md`（人读）或 `json`（AI 继续处理） |

**仅依赖标准库，Python ≥ 3.8，不需要装任何东西。**

---

## 报告长什么样

```
一、结论先行        要件覆盖 8/9、时效剩余 __ 天、抽取金额 __ 种
二、要件命中表      哪项有、哪项缺，一眼看清
三、命中片段明细    原文照录，带时间和发言人
四、缺失要件补强    缺什么、后遗症、去哪儿补
五、金额梳理        每个金额谁说的、什么时候说的
六、关键节点时间线
七、时效提示        届满日、剩余天数、法条依据
```

## 为什么 AI 单独做不好这个

因为需要三样东西：

1. **要件规则表** —— 43 项要件、举证责任分配、缺失后果，这些是结构化知识，靠临场发挥会漏
2. **机械化扫描** —— 几千条消息里捞出关键片段，人工翻不动，AI 不确定也不稳定
3. **时效计算** —— 起算日、届满日、剩余天数要算准，错了整个判断就废了

这个技能把这三样固化下来了。

## 边界（重要）

| 能做 | 不能做 |
|---|---|
| 按要件归类聊天片段 | ❌ 出具法律意见 |
| 提取金额、日期、主体 | ❌ 预测胜诉率或赔偿金额 |
| 生成清单 / 时间线 / 缺项报告 | ❌ 代替律师或法律援助 |
| 提示证明力风险 | ❌ 伪造、剪辑、补造证据 |
| 计算法定时效剩余天数 | ❌ 保证结果 |

**以下情况务必建议咨询律师或当地法律援助中心：**
争议金额较大、涉及刑事风险、涉外、一审已败诉拟上诉、时效剩余不足 30 天。

劳动争议仲裁**免费**，多数仲裁委设法律援助窗口。

> **永远不要为了"补齐要件"而建议用户修改、拼接或伪造聊天记录。**
> 剪辑过的记录在质证中通常直接被否，还可能反过来损害可信度。缺什么就如实写"缺"。

- 只读取你指定的导出文件
- 生成报告含敏感信息，**对外发送前务必脱敏**
