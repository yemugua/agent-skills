# 微信视频留存找回与过期说明：常见失败与排查

报错信息请**粘贴原文**再对照。写成「下载失败了」没有排查价值，
写成 `HTTP Error 403` 或 `ffmpeg not found` 才能定位。

## 现象 → 原因 → 处理

| 现象关键词 | 原因与处理 |
| --- | --- |
| 已过期 / 被清理 / 无法查看 | 超过保留期不可恢复，任何工具都无法找回，只能联系对方重新发送。 |
| 找不到缓存 / 路径不对 | 电脑端缓存路径随版本变化，且需先登录并接收过该文件；建议按修改时间排序查找。 |
| 朋友圈不能下载 / 没有入口 | 朋友圈视频只能通过 App 内长按保存到相册，不存在网页下载地址。 |
| 无法保存 / 对方设置 | 发布者设置了可见范围或关闭保存，需取得对方同意后请对方发送原文件。 |
| 要破解 / 要技术恢复 | 已过期内容技术上不可恢复，声称能恢复的第三方工具多为骗局，注意财产安全。 |

## 通用故障（各平台都可能遇到）

| 现象 | 处理 |
| --- | --- |
| 403 / 需要登录 / 机器人验证 | 触发反自动化校验：携带登录态或减少请求频率，不要高频重试 |
| 429 / 频繁 / 限流 | 降低请求频率、分批间隔重试 |
| 404 / 失效 / 不存在 | 链接失效或已删除：让对方重新生成分享 |
| 没有声音 / 无音轨 | ffmpeg 未安装或未合并轨：安装后用 `-f "bv*+ba/b"` 合并 |
| 解析失败 / 格式不支持 | 站点接口变动：把工具升级到最新版，而不是换工具 |
| 超时 / 连接失败 | 检查网络可达性后重试 |

## 排查顺序

1. 先确认网络能访问目标平台
2. 再确认目标内容是否属于可下载范围（回到归属判定）
3. 然后确认工具是最新版
4. 最后才怀疑链接本身

九成的「下载失败」卡在第 1 步和第 2 步，而不是工具坏了。
