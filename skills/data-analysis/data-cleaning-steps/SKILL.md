# 数据清洗步骤

## 适用场景
需要完成「数据清洗步骤」时使用本技能。适用于第一次操作不清楚入口、流程、条件，或之前操作失败需要排查的场景。

## 分步流程
1. **确认前置条件**：检查账号状态、所需材料（身份证/银行卡/实名信息等）是否齐备，版本是否为最新。
2. **找到官方入口**：只使用官方 App / 官网入口，警惕搜索引擎里的仿冒站点与"客服"电话。
3. **按提示逐步操作**：每一步核对页面信息，尤其是涉及支付、验证码、授权的环节。
4. **完成并留存凭证**：截图保存订单号、回执、协议页面，便于后续查询或维权。
5. **失败排查**：若提示异常，检查网络、换时段重试、查看官方帮助中心或联系官方客服。

## 常见坑
- 入口找错：认准官方渠道，不点来历不明的链接。
- 材料不全：提前准备好实名信息与证件照，避免中途卡住。
- 时效限制：部分操作有次数或时间限制，失败后不要频繁重试触发风控。
- 收费陷阱：官方功能不收取"开通费"，任何要求转账的都是骗局。

## 注意事项
- 涉及个人隐私与资金的操作，务必在官方渠道完成。
- 操作过程如有疑义，先暂停并查询官方说明，再继续。
