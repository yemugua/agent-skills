# Linux 性能瓶颈定位

## 适用场景
面向运维的 Linux 性能瓶颈定位指南，USE 方法 + 工具组合拳。

## 输入
按 `templates/场景表单.md` 填写场景、程度、可用工具与约束。

## 操作步骤
1. 打开 `templates/场景表单.md`，填写本次场景信息。
2. 运行：`python scripts/linux_perf_bottleneck.py.py <你填写后的表单路径>`
3. 按输出的分阶段清单逐项执行并打勾。
4. 每阶段完成后做阶段验收，禁止跳步。
