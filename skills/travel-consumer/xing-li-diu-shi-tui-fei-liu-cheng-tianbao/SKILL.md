# 行李丢失退费流程

## 场景
处理"行李丢失"事务中的"退费流程"环节，面向首次消费避坑、已遇纠纷维权两类人群。

## 信息/办理渠道
1. 官方渠道：12315（消费）、12301（旅游）、12378（银保监/贷款）、12345（总机）；医美涉医疗事故向卫健部门反映。
2. 行业渠道：平台官方客服、品牌总部、行业协会。
3. 司法渠道：消协调解 → 人民调解 → 起诉（小额诉讼程序标的小成本低）。

## 证据清单（维权成败关键）
- 合同/订单/付款凭证（发票优先）
- 宣传材料截图（承诺"包过""效果"的截图尤其重要）
- 沟通记录：微信/录音（本人参与的通话录音合法可用）
- 现场/术后影像：施工、手术、毁损部位多角度带时间水印
- 伤情/损失证明：病历、鉴定报告、误工证明、票据

## 流程要点
1. 固定证据（第一时间，防删改）→ 2. 书面协商（明确诉求与期限）→ 3. 平台/主管部门投诉 → 4. 调解 → 5. 起诉。
- 涉贷款的先查放贷方资质，培训贷常可主张与培训机构承担连带责任。

## 费用与赔偿参考
- 欺诈可主张退一赔三（消法55条）；人身损害含医疗费/误工费/护理费/精神抚慰金。
- 退费按合同约定；无约定的按实际课时/进度折算。

## 常见坑
1. 口头承诺不落纸面
2. "内部关系""限量名额"催单
3. 分期贷隐藏利率与服务费
4. 修复承诺二次收割

## 维权路径
- 12315/12301/12378 专线 → 消协 → 仲裁（有约定时）→ 法院起诉。
- 涉诈骗（虚构资质、卷款跑路）：报警 110 + 经侦。

## 提示
旅游消费留证是关键：合同/订单/宣传页/现场影像全保存；强制购物可向 12301（全国旅游服务热线）或 12315 投诉，出境游另可向领事馆求助。
