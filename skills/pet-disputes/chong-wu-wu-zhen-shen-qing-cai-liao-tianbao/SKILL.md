# 宠物误诊申请材料

## 场景
处理"宠物误诊"事务中的"申请材料"环节，面向首次办理、被拒补正、异地/代办人群。

## 办理/处理渠道
1. 线上：对应官方平台（当地政务服务网、民政/退役军人事务/农业农村/海关 12360、12315 平台等）。
2. 线下：对应窗口（民政殡仪馆/公墓管理处/退役军人服务站/动物诊疗机构/海关/住建部门等）。
3. 热线：12345 总机（转各主管部门）。

## 通用材料清单
- 身份证原件及复印件
- 申请表/合同（签名与证件一致）
- 佐证材料：按事项提供（死亡证明/关系证明/优待证/宠物病历/订单凭证/租赁合同等）
- 涉委托：委托书+双方身份证复印件

## 流程要点
1. 咨询或线上提交 → 2. 受理（缺件一次性告知）→ 3. 缴费/办理（索取正规票据）→ 4. 领取结果或达成处理方案。

## 时限与费用
- 以受理回执或合同约定为准；政府定价项目遇加价可拒付举报（12345/12315）。

## 常见问题与驳回原因
1. 材料缺失或过期（关系证明、死亡证明等须开具有效版本）
2. 前置手续未办（未销户/未鉴定/未备案）
3. 信息不一致（曾用名、证件升位）
4. 证据不足（纠纷类须有完整记录链）

## 申诉与维权
- 驳回有异议：索要书面凭证 → 行政复议（60日内）/行政诉讼（6个月内）。
- 民事纠纷：先调解（12345/行业主管部门）→ 不成起诉（小额诉讼程序）。
- 涉欺诈、乱收费：12315、12345、12388 实名举报。

## 提示
宠物医疗纠纷维权关键在证据：病历、缴费单、影像资料、沟通记录须全程保留；协商不成可向当地农业农村局（动物诊疗监管）投诉或 12315 平台申诉，必要时起诉。本指南不含诊疗建议，宠物急症请立即送医。
