# 4S店套路比价

## 场景
处理"4S店套路"事务中的"比价"环节，面向首次消费、被坑维权、比价优化三类人群。

## 信息/办理渠道
1. 官方渠道：12315（消费投诉）、12345（总机）；涉宠物诊疗向农业农村部门反映；涉车辆向交通/市监反映。
2. 行业渠道：官方售后/认证服务商/连锁品牌；核验人员证件与机构资质。
3. 比价：至少3家，警惕"最后名额""今日特价"催单。

## 通用准备清单
- 需求清单：预算、验收标准、服务范围先明确
- 合同/订单：服务内容、型号数量、工期档期、违约与退款条款逐条确认
- 付款留痕：大额分期付、索发票、拒私下转账
- 证据链：宣传截图、沟通记录、现场影像全程保存

## 流程要点
1. 需求确认 → 2. 多方比价 → 3. 资质核验 → 4. 签约（重点读退费/违约条款）→ 5. 分阶段履约验收 → 6. 凭证保留至服务结束。

## 费用与行情
- 参考当地市场均价；明显低价多伴随增项或降配。
- 预付充值（卡/课）金额尽量低、周期尽量短。

## 常见坑
1. 低价引流→中途加价
2. 口头承诺不写进合同
3. 预付后跑路/转让
4. 以次充好、旧件冒充新件
5. 资质造假

## 维权路径
- 协商 → 平台申诉 → 12315 → 消协调解 → 起诉（小额诉讼）。
- 跑路涉诈骗：报警 110，联合其他受害人集体维权。

## 提示
汽修避坑：换件要求退还旧件、先报价后施工、维修项目书面确认；重大维修可要求看旧件损坏部位。价格争议可 12315 投诉，事故理赔走保险定损流程。
