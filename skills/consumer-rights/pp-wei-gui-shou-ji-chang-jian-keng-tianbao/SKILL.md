# App违规收集常见坑

## 场景
处理"App违规收集"事务中的"常见坑"环节，面向首次办理、被拒补正、异地/代办人群。

## 办理/处理渠道
1. 线上：对应官方平台（不动产登记一网通办/移民局APP/12315平台/中国残联残疾人服务平台等）。
2. 线下：对应窗口（不动产登记中心/出入境管理大队/残联/市场监管所等）。
3. 热线：12345 总机；消费维权 12315；出入境 12367。

## 通用材料清单
- 身份证原件及复印件
- 申请表（签名与证件一致）
- 佐证材料：按事项提供（权属证明/合同票据/诊断证明/评定表/聊天截图等）
- 涉未成年人：监护人身份证+出生证明/户口本

## 流程要点
1. 预约或线上提交 → 2. 受理（缺件一次性告知，索要书面补正通知）→ 3. 缴费/评级/调查 → 4. 领取结果（电子证照同效）。

## 时限与费用
- 以受理回执为准；超期凭编号向 12345 催办。行政登记类收费须有公开依据。

## 常见驳回原因
1. 材料过期或非原件
2. 影像不清、复印件未签注
3. 前置条件缺失（未评定/未备案/未缴清）
4. 信息不一致（曾用名、证件升位）

## 申诉与维权
- 驳回有异议：索要书面凭证 → 行政复议（60日内）/行政诉讼（6个月内）。
- 消费类：12315 平台投诉 → 市场监管调解 → 不成再起诉；涉欺诈可主张退一赔三。
- 乱收费、推诿：12345、12388 举报。

## 提示
维权金额较大或对方失联跑路的，及时报警并向法院起诉（小额诉讼程序成本低、周期短）；保留合同、付款记录、聊天记录等全部证据原件。
