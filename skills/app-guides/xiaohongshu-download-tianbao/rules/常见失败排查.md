# 小红书笔记图片视频保存：常见失败与排查

报错信息请**粘贴原文**再对照。写成「下载失败了」没有排查价值，
写成 `HTTP Error 403` 或 `ffmpeg not found` 才能定位。

## 现象 → 原因 → 处理

| 现象关键词 | 原因与处理 |
| --- | --- |
| 防盗链 / 403 / referer / 打不开图 | 图片需在带来源的请求下才能获取，直接打开地址会被拦截。改用 App 长按保存。 |
| 只能存一张 / 缺图 / 数量不全 | 多图笔记需逐张保存，或用支持图集的工具；注意核对总张数。 |
| 保存在app里看不到 / 相册找不到 | 检查 App 的存储权限是否授予，部分系统需手动开启相册写入权限。 |
| 水印去不掉 | 平台水印由服务端叠加，客户端去除属修改平台产物，不建议处理。 |

## 通用故障（各平台都可能遇到）

| 现象 | 处理 |
| --- | --- |
| 403 / 需要登录 / 机器人验证 | 触发反自动化校验：携带登录态或减少请求频率，不要高频重试 |
| 429 / 频繁 / 限流 | 降低请求频率、分批间隔重试 |
| 404 / 失效 / 不存在 | 链接失效或已删除：让对方重新生成分享 |
| 没有声音 / 无音轨 | ffmpeg 未安装或未合并轨：安装后用 `-f "bv*+ba/b"` 合并 |
| 解析失败 / 格式不支持 | 站点接口变动：把工具升级到最新版，而不是换工具 |
| 超时 / 连接失败 | 检查网络可达性后重试 |

## 排查顺序

1. 先确认网络能访问目标平台
2. 再确认目标内容是否属于可下载范围（回到归属判定）
3. 然后确认工具是最新版
4. 最后才怀疑链接本身

九成的「下载失败」卡在第 1 步和第 2 步，而不是工具坏了。
