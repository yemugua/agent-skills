# 小红书笔记图片视频保存：途径、限制与合规边界

## 一、先判定：能不能下

| 归属类别 | 能否下载 | 允许的用途 |
| --- | --- | --- |
| 自有作品 | 可以，优先用原始导出文件 | 任意 |
| 已授权素材 | 可以 | 仅限授权范围内 |
| 作者开放了保存 | 可以，走官方途径 | 个人留存，**不得二次分发** |
| 第三方作品（未授权） | **不建议下载** | 不应用于任何对外场景 |

技术上能不能下载，和法律上能不能用，是两回事。

## 二、途径，按稳定性排序

| 途径 | 操作要点 |
| --- | --- |
| 图片长按保存 | App 内长按图片 → 保存。这是最稳的方式，但一次只能存一张，多图需逐张操作，且带平台昵称水印。 |
| 视频官方保存 | 视频笔记：分享 → 保存到相册，取决于作者是否开放保存权限。 |
| 创作者后台 | 蒲公英/创作中心可管理自有笔记，自有图片建议保留发布时的原图。 |
| 通用命令行工具 | 多为社区维护解析器，站点改版后失效频繁；受限于小红书的接口策略，**稳定性明显低于App内操作**，仅限自有内容批量留存。 |

## 三、本平台的真实限制

- 小红书以图文笔记为主，所谓"下载小红书"绝大多数场景其实是**导出一组图片**，不是视频。
- 图床有防盗链策略，直接复制链接下的图片地址在浏览器打开常常失效或被替换，这是访问限制而非链接损坏。
- 水印是自动叠加的作者昵称与小红书标识，位置通常在角落。去水印后二次发布风险高。
- 多图笔记常含正文排版与贴纸，单张保存会丢失整体版式，需要完整还原时应向作者索取原图。

## 四、画质与水印

- 小红书图片会被压缩，App 保存得到的是压缩后版本。想要原图只能向作者索取或从发布端导出，下载途径无法还原原始画质。
- 水印含作者昵称，属于署名性质。去除后发布风险高于保留。

## 五、合规红线

1. 不得去除作者署名后二次分发
2. 不得将他人作品搬运至自己的账号（含剪辑、配音后发布）
3. 不得下载或传播私密账号、付费内容
4. 受版权或 DRM 保护的内容不支持下载，也不提供任何破解方法
5. 商用前必须取得书面授权
6. 批量高频抓取可能违反平台服务协议，导致账号受限
