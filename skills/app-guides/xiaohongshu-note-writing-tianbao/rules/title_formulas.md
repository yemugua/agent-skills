# 标题公式与模板库

> 拟标题时先选公式类型，再填内容。**所有数字、身份、体验必须真实。**

---

## 一、五类标题公式与结构

| 公式 | 结构 | 适用 | 风险提示 |
|---|---|---|---|
| 数字型 | [数量] + [对象] + [结果/收益] | 有明确清单、可计数内容 | 数字要真实，虚报属虚假宣传 |
| 痛点型 | [人群/场景] + [痛点] + [解法承诺] | 解决具体困扰，收藏率高 | 痛点要具体 |
| 对比型 | [A] vs [B] + [结论] | 测评、选购、决策类 | 对比要公平，不贬低特定品牌 |
| 悬念型 | [反常识结论] + [留白] | 有反差感的笔记 | 正文必须兑现，否则是标题党 |
| 身份标签型 | [身份] + [场景/限制] + [结果] | 人设类、长期系列 | 身份要真实 |

## 二、标题模板库（30 个，按公式分类）

### 数字型（6 个）

1. `[N] 个 [工具/方法]，每天省 [X] 小时`
2. `[N] 步搞定 [目标]，最快 [X] 分钟`
3. `[N] 天 [某习惯] 实录，第 [X] 天最难熬`
4. `[N] 个 [场景] 解决方案，收藏这一个就够`
5. `[N] 款 [物品] 横评，第 [X] 个回购了 [X] 次`
6. `[N] 个 Excel 公式，[人群] 每天省 [X] 小时`

### 痛点型（6 个）

7. `[人群] [痛点] 怎么办？我总结了 [N] 个方案`
8. `[场景] 总是 [失败情况]？问题可能在这 [N] 个地方`
9. `[人群] 不会 [某事]？这套流程直接抄`
10. `[N] 招解决 [具体痛点]，第 [X] 招最关键`
11. `[场景] 想省事又怕踩坑，这份清单帮你避开`
12. `[人群] [痛点]，我踩过 [N] 个坑才明白`

### 对比型（6 个）

13. `[A] vs [B]，实测差在哪`
14. 早八 vs 早九，一周下来差了很多
15. `[方案1] 和 [方案2] 怎么选？看这一张表`
16. 花了 [金额] 买的 [物品]，和 [低价替代] 差在哪
17. `[做法A] 一周 vs [做法B] 一周，真实记录`
18. 自制 vs 外卖，一周成本和健康都算给你看

### 悬念型（6 个）

19. `[常见做法] 了 [时长]，效果和我想的不一样`
20. 存款 [金额] 和负债 [金额]，一年后差距出乎意料
21. 我删了 [某习惯]，效率反而更高了
22. [行业/人群] 最看重的其实不是 [常见认知]
23. 为什么 [现象]？答案和我猜的不一样
24. [看似正确的事]，其实一直在做错

### 身份标签型（6 个）

25. `[年龄] 岁转行第 [N] 年，我做对了哪 [N] 件事`
26. `i 人独居 [N] 年，这些东西真的提升了生活质量`
27. `[职业] 入行第 [N] 年，最有用的 [N] 个习惯`
28. `[身份] 的 [时间安排]，我的具体方案`
29. 作为 [身份]，我劝你别在这 [N] 件事上花时间
30. `[身份] 的 [物品清单]，都是我实际在用的`

## 三、标题长度规则

| 项 | 建议 | 说明 |
|---|---|---|
| 字数 | 16-20 字为主 | 超过 24 字易被截断 |
| 关键信息位置 | 前 8 字 | 前 8 字决定点开率 |
| 数字位置 | 前半段 | 不要放末尾 |
| 分隔符 | 空格、竖线或标点 | 不要连排 |
| 表情 | 0-1 个 | 堆表情会被判营销号风格 |
| 禁止 | 「你绝对想不到」「必看」类空洞承诺 | 与正文不符会拉低完读率 |

### 截断示例

```
✗ 「一个普通上班族的周末两天时间安排的完整记录和心得分享（附清单）」
  31 字，被截断，且前 8 字无有效信息

✓ 「周末两天怎么安排？我这 6 个时间段不累」
  18 字，前 8 字有场景和信息
```

## 五、标题自检清单

- [ ] 字数在 24 字以内
- [ ] 前 8 字有有效信息（场景、人群、数字或结果）
- [ ] 有明确的点击理由，不是正文摘要
- [ ] 属于五类公式之一（数字/痛点/对比/悬念/身份标签）
- [ ] 数字、身份、体验全部真实
- [ ] 承诺在正文中已兑现
- [ ] 无极限词与违禁表述
- [ ] 表情不超过 1 个
- [ ] 不含「必看」「你绝对想不到」类空洞承诺
