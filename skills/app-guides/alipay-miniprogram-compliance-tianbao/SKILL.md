# 支付宝小程序开发合规核查

## 适用范围
- 开发/运营支付宝小程序、准备从微信小程序跨平台移植到支付宝的开发者。
- 典型场景：类目未设置或与经营范围不符、特殊类目无资质、未备案、虚拟商品/会员售卖不合规、无隐私协议、SDK 未申报、UGC 无处置、诱导分享、虚假宣传。
- 与「微信生态合规线」（xpay/隐私/内容安全/广告/备案）互补，覆盖支付宝侧的准入、交易、数据、内容、营销合规链条。

## 工作流
1. 让开发者填写 `templates/采集表.md`（小程序名称 + 类目/支付/隐私/内容/营销等字段）。
2. 运行核查脚本：
   ```
   python scripts/alipay_miniprogram_compliance.py <采集表.md>
   ```
3. 脚本输出多段报告：结论摘要 → 分项核查 → 阻断项与风险 → 整改清单 → 边界。
4. 按阻断项（必须处理）与风险项（建议处理）逐条整改，留存记录。

## 核查维度（6 大域）
1. **类目资质与备案**：类目设置、类目与经营范围匹配、特殊类目资质、备案/主体认证。
2. **支付与虚拟商品**：支付接入、虚拟商品/会员售卖合规、订单与资金合规。
3. **隐私与数据**：隐私协议、用户授权、第三方 SDK 申报、敏感信息处理。
4. **内容安全**：内容审核机制、UGC 举报与处置。
5. **营销与诱导**：诱导分享/关注、虚假宣传/违规广告、红包优惠券营销。
6. **违规处罚与历史**：违规处罚历史与整改闭环。

## 判定规则
- 任一**阻断项**命中 → 总体结论「不通过」。
- 仅有**风险/待办项** → 总体结论「有风险」。
- 均无 → 总体结论「通过」。
- 采集表全空 → 退出码 2，输出「待补正」。

## 边界
- 仅做合规核查与整改指引，**不替代《个人信息保护法》《广告法》、支付宝平台规则与正式法律意见**；重大场景请咨询律师。
- 类目须与经营范围一致，特殊类目须持资质；虚拟商品须明示规则，资金合规结算，严禁场外交易。
- 详细规则见 `rules/类目资质与备案要点.md` 与 `rules/支付隐私与内容营销要点.md`。
