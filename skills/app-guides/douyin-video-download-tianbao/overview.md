# 抖音视频下载与去水印保存

面向需要把自己发布的抖音作品导出到本地、或已获得作者授权需要留存素材的创作者、运营与合规人员。

## 与其他工具的区别

大多数"去水印下载"工具只给一个解析链接，用两天就失效。本技能解决的是另一个问题：

- **先判能不能下**。自有作品、已授权素材、第三方作品，三类的处理方式完全不同。把第三方作品判成"可下载"是侵权风险。
- **给多条途径而不是一条**。官方保存 > 创作者后台 > 浏览器扩展 > 命令行工具，按稳定性排序，前面通了就不用折腾后面的。
- **讲清水印**。平台自动生成的水印和作者自行添加的署名水印，处理方式不一样；去除后者可能侵犯署名权。
- **覆盖失败场景**。链接失效、口令过期、私密账号、仅 App 可见——这些才是实际最常卡住的地方。

## 适用与不适用

适用：
1. 导出自己账号发布的作品做备份或二次剪辑
2. 已书面授权，需要留存合作方的素材
3. 自己账号开启了"允许他人保存"，帮同事取回

不适用（本技能会明确拒绝并说明原因）：
1. 搬运他人作品到自己的账号
2. 去除作者署名水印后二次分发
3. 下载私密账号或付费内容

## 使用流程

1. 抄录 `templates/抖音视频下载信息采集表.md` 填好
2. 运行脚本生成核查报告
3. 先看第一节的「能否下载」判定——若判不可下载，后面不用继续
4. 按推荐的途径顺序往下试

## 边界

本结果依通用规则整理，不替代专业法律意见。下载他人作品用于搬运、二次分发或商用可能构成侵权；最终以平台规则与《中华人民共和国著作权法》及司法机关认定为准。
