# 抖音视频下载与去水印保存

面向需要把自己发布的抖音作品导出到本地、或已获得作者授权需要留存素材的创作者、运营与合规人员。

## 它能做什么
- 判断目标视频属于「自有作品 / 已授权 / 第三方作品」三类中哪一类，能否下载
- 按可用性排序给出四条保存途径：官方保存 → 创作者后台下载 → 浏览器扩展 → 命令行工具
- 说明水印的性质：平台水印能否去除、去水印的法律边界
- 覆盖单条视频、图文、合集三种形态
- 排查常见失败：链接失效、口令失效、限流、仅 App 可看、私密账号

## 使用方式
把你的情况按 `testdata/样例.md` 的字段填好（| 字段 | 值 | 两列表），交给本技能即可生成核查报告。

## 边界
本结果依通用规则整理，不替代专业法律意见。下载他人作品用于搬运、二次分发或商用可能构成侵权；最终以平台规则与《中华人民共和国著作权法》及司法机关认定为准。
