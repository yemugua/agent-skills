# 抖音视频下载途径与合规规则

## 一、先判定：这视频能不能下

| 归属类别 | 判定依据 | 能否下载 | 允许的用途 |
| --- | --- | --- | --- |
| 自有作品 | 自己的账号发布，或用发布时的原文件 | 可以，优先用原文件 | 任意 |
| 已授权素材 | 有作者的书面/聊天授权记录 | 可以 | 仅限授权范围内 |
| 平台允许保存 | 作者在发布设置里开了「允许他人保存」 | 可以，用官方保存 | 个人留存，**不得二次分发** |
| 第三方作品（未授权） | 别人的账号，无授权 | **不建议下载** | 不应用于任何对外场景 |

**关键提醒**：技术上能不能下载，和法律上能不能用，是两回事。本技能只在前三类给出下载途径。

## 二、四条途径，按稳定性排序

### 途径 1：原文件（最优）
自己在手机上拍的、剪映里导出的成品。**永远优先用这个**。
- 画质无损，无平台压缩
- 无水印问题
- 建议养成导出后本地归档的习惯

### 途径 2：官方「保存本地/保存到相册」
- 条件：作者在发布设置里开启了「允许他人保存」
- 位置：分享面板 → 保存本地 / 保存到相册
- 结果：带平台水印，画质接近原上传
- 限制：作者关闭了该开关时，此入口不会出现

### 途径 3：创作者后台 / 创作服务平台（自用最佳）
- 入口：抖音创作服务平台（creator.douyin.com）
- 条件：仅限**自己账号**发布的作品
- 优势：可下载自己作品的原画质版本
- 适用：换设备、迁号、做作品备份

### 途径 4：通用命令行工具（yt-dlp 等）
- 适用：已授权素材、自有作品的批量留存
- 前置：本机需已安装 Python 与 ffmpeg
- 通用命令形态：
  ```
  yt-dlp <视频链接>
  yt-dlp -f "bv*+ba/b" <链接>          # 选最佳画质+音轨并合并
  yt-dlp --cookies-from-browser chrome <链接>   # 需要登录态时
  ```
- 特点：站点接口变动会导致短期失效，需更新到新版本重试
- **不得**用于付费内容、私密账号或任何未授权作品

## 三、水印的两类，别混为一谈

| 类型 | 谁加的 | 处理建议 |
| --- | --- | --- |
| 平台水印（右下角抖音 logo、昵称、抖音号） | 平台自动叠加 | 属平台标识。去除后二次发布可能违反平台规则 |
| 作者署名水印（作者自己压上去的署名、Logo） | 作者手动添加 | **属于署名**，去除可能侵犯署名权，法律风险更高 |

实践建议：
- 自有作品 → 用原始导出文件，本就没有水印
- 已授权素材 → 保留水印或按授权约定处理
- 不确定 → 保留水印最安全

## 四、三种形态的处理差异

| 形态 | 说明 | 可用途径 |
| --- | --- | --- |
| 单条视频 | 最常见 | 四条途径均可 |
| 图文（多图/轮播） | 多张图片组成 | 途径 1/4 可导出图片；Official 保存通常只存第一张 |
| 合集 | 系列视频 | 途径 4 支持按合集批量，需提供合集链接而非单条链接 |

## 五、常见失败与排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 解析报「链接无效」 | 用了不完整链接或过期短链 | 重新在 App 内复制分享链接（含完整参数） |
| 口令失效 | 分享口令有时效 | 让对方重新生成分享 |
| 需要登录 | 目标账号内容要求登录可见 | 用带 cookies 的方式，或改用自有账号途径 |
| 私密账号 | 作者设为私密 | **不可下载**，应联系作者获取授权 |
| 工具报 403 / 429 | 触发平台限流 | 降低频率、换网络环境、更新工具版本，不要高频重试 |
| 只有画面没声音 | 未合并音轨 | 用 `-f "bv*+ba/b"` 让工具自动合并，确认 ffmpeg 已安装 |
| 画质远低于预期 | 源码源只提供低码率版本 | 该视频本身上传质量有限，无法提升 |

## 六、合规红线

1. 不得去除作者署名后二次分发
2. 不得将他人作品搬运至自己的账号（含剪辑、配音后发布）
3. 不得下载或传播私密账号、付费内容
4. 商用前必须取得书面授权
5. 批量高频抓取可能违反平台服务协议，导致账号受限

## 七、给创作者的建议

如果目的是「让别人方便取用自己的素材」：
- 发布时开启「允许他人保存」
- 重要作品在发布设置中提供原始文件下载渠道
- 在简介里写明授权范围与联系方式

这样比事后去水印干净得多，也不产生争议。
