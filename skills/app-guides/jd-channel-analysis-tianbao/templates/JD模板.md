# 招聘岗位 JD 模板

> JD 是**招聘的第一份产品说明书**：七段齐全、动词开头、硬性/加分分开、无歧视表述。写完先过一遍体检脚本。

## 一、JD 七段

| 段 | 内容要求 | 示例 |
|---|---|---|
| ① 职位名称 | 市场通用叫法，不带内部黑话 | 消防维保工程师 |
| ② 汇报线 | 汇报对象与下属（如有） | 向工程部经理汇报，无下属 |
| ③ 岗位职责 | 动词开头（负责/组织/编制/维护），一条一个动作，4-6 条 | 1. 负责消防设施月度维保…… |
| ④ 任职资格 | **硬性项 ≤5 条**，与加分项分列 | 硬性：一级注册消防工程师、3 年以上经验 |
| ⑤ 薪酬 | 明确区间与结构，不写"面议"（除非高管岗） | 10-15K·13 薪 |
| ⑥ 工作地点 | 城市+是否需要驻场/出差 | 上海（含驻场） |
| ⑦ 团队与业务 | 团队规模、汇报氛围、业务前景 | 工程部 8 人，服务商场/医院项目 |

## 二、职责动词库

| 推荐动词 | 禁用/慎用 |
|---|---|
| 负责、主导、组织、编制、搭建、优化、维护、复盘、推动 | 参与、协助（过半即为凑数） |

## 三、任职资格拆分

| 类型 | 内容 | 数量 |
|---|---|---|
| 硬性（缺一即淘汰） | 学历/证书/年限/技能 | ≤5 条 |
| 加分（有则优先） | 项目经验/其他证书/工具 | 2-4 条 |

## 四、渠道-岗位匹配

| 渠道 | 适合岗位类型 | 注意点 |
|---|---|---|
| BOSS 直聘 | 初中级通用岗 | 响应时效<2h，简历/沟通比 |
| 猎聘 | 中高端/持证岗 | 硬性证书前置写明 |
| 行业社群/公众号 | 消防/质量垂直岗 | 专业术语准确 |
| 内推 | 全类型 | 设内推奖 |

## 五、漏斗指标（发布后跟踪）

| 环节 | 数值 | 转化率基准（参考） |
|---|---|---|
| 曝光→沟通 | | ≥10% |
| 沟通→简历 | | ≥15% |
| 简历→面试 | | ≥20% |
| 面试→Offer | | ≥25% |
| Offer→入职 | | ≥80% |

**合规提示**：不得出现性别、户籍、婚育、年龄上限等歧视性表述；涉及年龄/健康的须与岗位胜任有直接关联且依法设定。
