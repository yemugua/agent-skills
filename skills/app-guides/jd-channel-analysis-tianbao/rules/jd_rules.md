# JD 与渠道规则库（jd_rules）

> 本文件是 jd-channel-analysis 技能的规则支撑。平台规则以各平台现行规定为准。

## 一、合规红线

- 不得含性别、年龄、地域、婚育、健康等歧视性限制
- 不得虚假描述薪酬、职级、工作内容
- 不得盗用他司 JD 原文

## 二、JD 七段完整性判定

| 段 | 判定 |
|---|---|
| 职位名称 | 市场通用叫法 |
| 部门与汇报线 | 明确 |
| 岗位职责 | 5~8 条、动词开头 |
| 任职资格 | 硬性与加分分开 |
| 薪酬福利 | 区间透明 |
| 地点时间 | 含出差班次 |
| 团队成长 | 构成与路径 |

缺段 WARN；职责"参与/协助"满屏 WARN。

## 三、资格项拆分口径

- 硬性：学历/证书/年限/必备技能/到岗时间，缺一即筛
- 加分：行业经验/工具/语言，同等优先
- 硬性项 >5 条提示收紧（影响简历量）

## 四、渠道匹配口径

| 渠道 | 岗位 | 特点 |
|---|---|---|
| BOSS 直聘 | 初中级批量岗 | 量大需主动 |
| 猎头 | 中高级稀缺 | 精准费率高 |
| 内推 | 各层级 | 质量高留存好 |
| 垂直社区 | 技术专业 | 精准量小 |
| 校招/社招活动 | 储备批量 | 季节性 |

## 五、漏斗诊断口径

| 指标 | 低值诊断 |
|---|---|
| 沟通转化率 | 薪酬/JD 开头不吸引 |
| 投递率 | 需求不匹配/回复慢 |
| 约面率 | 邀约话术/时间问题 |
| 到面率 | 缺确认与提醒 |
| offer 接受率 | 薪酬竞争力/面试体验 |
| 试用期留存 | JD 失真/面试失真 |

## 六、常见不合规情形

- JD 抄模板与业务两张皮
- 硬性项堆砌
- 薪酬面议
- 渠道单一不调
- 约面不确认
