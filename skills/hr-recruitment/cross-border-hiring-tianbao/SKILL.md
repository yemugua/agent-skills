# 异地与跨境雇佣合规（cross-border-hiring）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据劳动合同法与外籍人员就业管理规定，生成清单：用工主体与合同适用、社保公积金缴纳地、外国人工作许可与居留、个税扣缴与双边协定、数据与跨境远程管理。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 异地招聘合规
- 外籍员工雇佣
- 外国人工作许可证
- 跨地区社保
- 外派人员管理

## 三、工作流
1. 确定用工主体与适用法律
2. 明确社保公积金缴纳地
3. 办理外国人工作许可与居留
4. 规范个税扣缴并适用协定
5. 管理跨境数据与远程安排

## 四、核心内容（检查清单与判定）
外籍人士就业必须先取得工作许可与工作类居留，否则构成非法就业；社保属地与个税居民身份的判定也须提前厘清，事后补缴代价很高。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含用工主体与合同适用 | 主体 |
| Q2 | FAIL | 未含社保公积金缴纳地确定 | 社保 |
| Q3 | FAIL | 未含工作许可与居留手续 | 许可 |
| Q4 | WARN | 未含个税扣缴与协定适用 | 个税 |
| Q5 | WARN | 未含跨境数据与远程管理 | 跨境管理 |

> 脚本 `cross-border-hiring_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python cross-border-hiring_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python cross-border-hiring_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
