# 离职手续与交接管理（offboarding-process）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据劳动合同法离职管理要求，生成清单：离职申请与协商方式选择、工作交接清单与知识留存、资产回收与账号权限注销、薪资结算与竞业确认、离职证明与关系关闭。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 离职手续办理
- 离职交接清单
- 离职资产回收
- 离职证明出具
- 账号权限注销

## 三、工作流
1. 确认离职申请与协商方式
2. 编制交接清单并留存知识
3. 回收资产并注销账号权限
4. 结算薪资并确认竞业义务
5. 出具离职证明并关闭关系

## 四、核心内容（检查清单与判定）
离职处理不当会引发欠薪、未休年假与竞业纠纷。交接完成才可结算，账户权限应即时回收，离职证明须在法定时限内出具。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含离职申请与协商方式确认 | 协商 |
| Q2 | FAIL | 未含交接清单与知识留存 | 交接 |
| Q3 | FAIL | 未含资产回收与权限注销 | 回收 |
| Q4 | WARN | 未含薪资结算与竞业确认 | 结算 |
| Q5 | WARN | 未含离职证明与关系关闭 | 证明 |

> 脚本 `offboarding-process_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python offboarding-process_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python offboarding-process_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
