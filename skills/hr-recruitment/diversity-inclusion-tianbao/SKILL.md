# 多元化与公平包容（diversity-inclusion）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据公平就业与包容性管理方法，生成清单：招聘JD 中性化与去偏见、面试评分结构化、晋升与薪酬公平性分析、反歧视投诉渠道、数据看板与问责机制。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 多元化招聘
- 公平就业审查
- 无意识偏见培训
- 薪酬公平性分析
- 包容文化建设

## 三、工作流
1. 审阅招聘文本去除偏见
2. 结构化面试与评分校准
3. 分析晋升与薪酬公平性
4. 建立反歧视投诉渠道
5. 搭建数据看板与问责机制

## 四、核心内容（检查清单与判定）
去偏见最有效的干预是结构化：统一题目、统一评分表、多面试官独立打分。仅做一次意识培训往往几周后效果即消退。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含招聘文本中性化审阅 | 文本 |
| Q2 | FAIL | 未含结构化面试与评分校准 | 结构化 |
| Q3 | WARN | 未含晋升与薪酬公平性分析 | 公平性 |
| Q4 | FAIL | 未含反歧视投诉渠道 | 渠道 |
| Q5 | WARN | 未含数据看板与问责机制 | 看板 |

> 脚本 `diversity-inclusion_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python diversity-inclusion_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python diversity-inclusion_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
