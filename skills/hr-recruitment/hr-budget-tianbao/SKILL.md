# 人力成本预算编制（hr-budget）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据预算管理与 HR 财务分析逻辑，生成清单：岗位编制与人员计划、薪酬福利与五险一金测算、招聘培训与遣散成本、预算科目与部门分摊、执行监控与差异分析。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 人力成本预算
- 编制管控
- 薪酬总额预算
- 人效分析
- 预算差异

## 三、工作流
1. 确定岗位编制与人员计划
2. 测算薪酬福利与社保
3. 预算招聘培训与遣散成本
4. 划分科目并分摊到部门
5. 执行监控与差异分析

## 四、核心内容（检查清单与判定）
人力成本预算常漏估隐性支出：加班、招聘费、遣散补偿与外包差额。建议按部门分摊并与人效指标挂钩，否则预算只能算总数、管不住过程。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含编制与人员计划 | 编制 |
| Q2 | FAIL | 未含薪酬福利与社保测算 | 薪酬 |
| Q3 | WARN | 未含招聘培训与遣散成本 | 隐性成本 |
| Q4 | WARN | 未含科目划分与部门分摊 | 分摊 |
| Q5 | FAIL | 未含执行监控与差异分析 | 监控 |

> 脚本 `hr-budget_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python hr-budget_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python hr-budget_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
