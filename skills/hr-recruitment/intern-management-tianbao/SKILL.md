# 实习用工管理（intern-management）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据劳动法与实习相关规定，生成清单：实习协议与三方安排、岗位与导师配置、工时上限与安全防护、实习津贴与考勤、考核评价与转正通道。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 实习用工管理
- 实习协议
- 实习生岗前安全
- 实习津贴
- 实习生转正

## 三、工作流
1. 签订实习协议并确认三方安排
2. 配置适岗岗位与导师
3. 控制工时并落实安全防护
4. 明确津贴标准与考勤
5. 实施考核评价与转正通道

## 四、核心内容（检查清单与判定）
在校学生实习原则上不构成劳动关系，但仍须签实习协议并落实安全培训与防护；禁止安排实习生单独从事危险作业，工时与夜班须严控。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含实习协议与三方安排 | 协议 |
| Q2 | WARN | 未含岗位与导师配置 | 导师 |
| Q3 | FAIL | 未含工时上限与安全防护 | 安全 |
| Q4 | WARN | 未含津贴标准与考勤 | 津贴 |
| Q5 | WARN | 未含考核评价与转正通道 | 转正 |

> 脚本 `intern-management_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python intern-management_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python intern-management_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
