# 人事档案与员工数据管理（personnel-file-management）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据人事档案管理与个保合规要求，生成清单：档案目录与材料清单、入职材料核对与更新机制、借阅审批与保密权限、电子档案备份与留存期限、离职后档案转移。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 人事档案整理
- 员工材料清单
- 档案借阅审批
- 电子人事档案
- 离职档案转移

## 三、工作流
1. 制定档案目录与材料清单
2. 核对入职材料并定期更新
3. 执行借阅审批与保密权限
4. 落实电子档案备份与留存期限
5. 办理离职后档案转移

## 四、核心内容（检查清单与判定）
员工档案涉及大量个人信息，借阅审批与权限最小化是底线；关键材料缺失会在劳动争议中直接导致举证不能，须在入职环节就把齐。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含档案目录与材料清单 | 目录 |
| Q2 | FAIL | 未含入职核对与更新机制 | 更新 |
| Q3 | FAIL | 未含借阅审批与保密权限 | 权限 |
| Q4 | WARN | 未含备份与留存期限管理 | 留存 |
| Q5 | WARN | 未含离职后档案转移 | 转移 |

> 脚本 `personnel-file-management_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python personnel-file-management_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python personnel-file-management_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
