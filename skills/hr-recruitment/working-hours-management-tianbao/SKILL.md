# 工时与加班管理（working-hours-management）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《劳动法》工时制度规定，生成清单：标准工时与综合计算工时制审批、加班自愿与时长上限、考勤记录完整性、调休与加班费支付、超时预警与整改。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 工时管理合规
- 综合计算工时制
- 不定时工作制
- 加班费争议
- 超时加班排查

## 三、工作流
1. 确定工时制度并完成审批
2. 控制加班自愿性与时长上限
3. 保证考勤记录完整可证
4. 落实调休与加班费支付
5. 设置超时预警并整改

## 四、核心内容（检查清单与判定）
每月加班不得超过三十六小时是法定上限，超时不仅违法还增加事故风险；特殊工时制度必须经人社部门审批，用人单位无权自行决定。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含工时制度与行政审批 | 审批 |
| Q2 | FAIL | 未含加班自愿与时长上限 | 上限 |
| Q3 | FAIL | 未含考勤记录完整性 | 考勤 |
| Q4 | WARN | 未含调休与加班费支付 | 支付 |
| Q5 | WARN | 未含超时预警与整改 | 预警 |

> 脚本 `working-hours-management_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python working-hours-management_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python working-hours-management_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
