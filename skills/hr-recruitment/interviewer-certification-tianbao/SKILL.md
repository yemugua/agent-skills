# 面试官体系与认证（interviewer-certification）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据结构化面试方法论，生成清单：面试官分级与资格标准、结构化题库与评分表、面试技能培训与演练、考官数量与回避规则、评价一致性与质量抽检。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 面试官认证
- 面试官培训
- 结构化面试题库
- 考官回避
- 面试评分一致性

## 三、工作流
1. 建立面试官分级与资格标准
2. 配置结构化题库与评分表
3. 开展培训演练与考核
4. 落实考官数量与回避规则
5. 实施评价一致性与质量抽检

## 四、核心内容（检查清单与判定）
未经训练的面试官会凭直觉打分且偏好与自己相似的人；通过分级认证、统一题库评分表与回避规则，可显著提升选人准确率并降低用人风险。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含面试官分级与资格标准 | 分级 |
| Q2 | FAIL | 未含结构化题库与评分表 | 题库 |
| Q3 | WARN | 未含培训演练与考核 | 培训 |
| Q4 | WARN | 未含考官数量与回避规则 | 回避 |
| Q5 | WARN | 未含评价一致性与质量抽检 | 抽检 |

> 脚本 `interviewer-certification_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python interviewer-certification_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python interviewer-certification_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
