# 直通率与良率提升（yield-improvement）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据过程能力分析与损失分解方法，生成清单：良率漏斗与损失工序定位、缺陷 Pareto 与主要损失、要因验证与参数优化、标准化与防错导入、效果固化与再发防止。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 良率提升
- 直通率分析
- 良率漏斗
- 缺陷 Pareto
- 报废率降低

## 三、工作流
1. 搭建良率漏斗定位损失工序
2. 做缺陷帕累托抓主要矛盾
3. 验证要因并优化参数
4. 导入防错与作业标准化
5. 固化成果并防再发

## 四、核心内容（检查清单与判定）
没有逐工序的良率数据，就无法找到真实损失点。先把测量口径统一起来，再用帕累托聚焦前三项缺陷，往往远胜于全面开花。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含良率漏斗与损失定位 | 漏斗 |
| Q2 | FAIL | 未含缺陷帕累托分析 | 帕累托 |
| Q3 | WARN | 未含要因验证与参数优化 | 要因 |
| Q4 | WARN | 未含标准化与防错导入 | 防错 |
| Q5 | FAIL | 未含效果固化与再发防止 | 固化 |

> 脚本 `yield-improvement_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python yield-improvement_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python yield-improvement_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
