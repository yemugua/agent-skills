# 可靠性试验与寿命验证（reliability-testing）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据可靠性试验标准 GB/T 5080 系列与 GB/T 2423 环境试验，生成清单：环境应力与工况剖面、试验方案与样本量、加速试验与失效判据、试验设备与监控、结果分析与寿命推断。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 可靠性试验
- 老化试验
- 寿命验证
- 加速寿命试验
- 环境试验

## 三、工作流
1. 梳理环境应力与工况剖面
2. 确定试验方案与样本量
3. 设定加速条件与失效判据
4. 配备试验设备并全程监控
5. 分析结果并推断寿命

## 四、核心内容（检查清单与判定）
可靠性试验的价值在于「试验条件贴近真实工况」。样本量过小、判据模糊、监控缺失会让试验结论失真，据此推算的 MTBF 往往过于乐观。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含环境应力与工况剖面 | 剖面 |
| Q2 | FAIL | 未含试验方案与样本量 | 样本量 |
| Q3 | FAIL | 未含加速条件与失效判据 | 判据 |
| Q4 | WARN | 未含试验设备与全程监控 | 监控 |
| Q5 | WARN | 未含结果分析与寿命推断 | 推断 |

> 脚本 `reliability-testing_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python reliability-testing_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python reliability-testing_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
