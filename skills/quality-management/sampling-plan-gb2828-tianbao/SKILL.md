# GB/T 2828.1 抽样方案应用（sampling-plan-gb2828）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《计数抽样检验程序》GB/T 2828.1，生成清单：批量与样本量字码确定、检验水平与 AQL 选取、抽样方案检索与转移规则、批处置与不合格品处理、抽样记录与统计。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- GB/T 2828.1
- AQL 确定
- 抽样方案检索
- 转移规则
- 样本量字码

## 三、工作流
1. 确定批量与样本量字码
2. 选取检验水平与 AQL
3. 检索抽样方案并应用转移规则
4. 执行批处置与不合格品处理
5. 留存抽样记录并统计

## 四、核心内容（检查清单与判定）
AQL 不是「合格质量水平」的承诺，而是过程平均的可接受上限；忽略正常/加严/放宽的转移规则，长期会让抽样失去对质量波动的敏感性。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含批量与样本量字码 | 字码 |
| Q2 | FAIL | 未含检验水平与 AQL | AQL |
| Q3 | FAIL | 未含抽样方案与转移规则 | 转移 |
| Q4 | WARN | 未含批处置与不合格品处理 | 处置 |
| Q5 | WARN | 未含抽样记录与统计 | 记录 |

> 脚本 `sampling-plan-gb2828_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python sampling-plan-gb2828_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python sampling-plan-gb2828_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
