# 目视检验与检验员能力验证（visual-inspection-competency）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据检验人员能力管理要求，生成清单：视力与色觉要求、标准样件与缺陷限度样本、培训考核与持证上岗、检验照明与视角距离、复检轮岗与差错统计。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 目视检验管理
- 检验员能力验证
- 限度样本制作
- 检验照明标准
- 漏检率统计

## 三、工作流
1. 确认视力与色觉要求
2. 制作标准样件与缺陷限度样本
3. 开展培训考核并持证上岗
4. 规范照明条件与视角距离
5. 实施复检轮岗与差错统计

## 四、核心内容（检查清单与判定）
目视检验依赖人的感官状态，疲劳与光线不足会使漏检率陡增。没有缺陷限度样本、没有定期复训验证，再好的作业指导书也难以统一判定尺度。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含视力与色觉要求 | 视力 |
| Q2 | FAIL | 未含标准样件与限度样本 | 限度样本 |
| Q3 | FAIL | 未含培训考核与持证上岗 | 持证 |
| Q4 | WARN | 未含照明条件与视角距离 | 照明 |
| Q5 | WARN | 未含复检轮岗与差错统计 | 差错统计 |

> 脚本 `visual-inspection-competency_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python visual-inspection-competency_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python visual-inspection-competency_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
