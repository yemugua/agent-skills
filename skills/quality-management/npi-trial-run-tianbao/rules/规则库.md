# 新品试产管理 — 规则库

> 依据：试产的目的是暴露问题而非赶产量。把试产当生产跑、问题不闭环就放行量产，是新品上市后批量返工和质量事故的主要来源。

## Q1（FAIL）未含试产方案与准入条件

- 判定依据：方案
- 核查要点：未含试产方案与准入条件；不达标即记 FAIL。

## Q2（FAIL）未含物料与工装准备确认

- 判定依据：工装
- 核查要点：未含物料与工装准备确认；不达标即记 FAIL。

## Q3（WARN）未含过程参数与偏差记录

- 判定依据：参数
- 核查要点：未含过程参数与偏差记录；不达标即记 WARN。

## Q4（FAIL）未含问题清单与责任闭合

- 判定依据：闭环
- 核查要点：未含问题清单与责任闭合；不达标即记 FAIL。

## Q5（WARN）未含量产放行评审

- 判定依据：放行
- 核查要点：未含量产放行评审；不达标即记 WARN。
