# 食品安全管理体系与 HACCP（iso22000-haccp）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据 GB/T 22000 / ISO 22000 与 HACCP 原理，生成清单：前提方案与良好操作规范、危害分析与 CCP 确定、关键限值与监控系统、纠偏与验证、追溯撤回与演练。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- ISO 22000
- HACCP 计划
- 关键控制点确定
- 关键限值监控
- 食品追溯演练

## 三、工作流
1. 建立前提方案与操作规范
2. 实施危害分析并确定关键控制点
3. 设定关键限值与监控系统
4. 执行纠偏与验证活动
5. 开展追溯撤回演练

## 四、核心内容（检查清单与判定）
HACCP 的关键是把 CCP 控制在真正的产品安全点上；CCP 定得过多会增加成本，定错则会让安全屏障失效，必须用判定树系统推导。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含前提方案与操作规范 | 前提方案 |
| Q2 | FAIL | 未含危害分析与关键控制点 | 关键控制点 |
| Q3 | FAIL | 未含关键限值与监控系统 | 监控 |
| Q4 | WARN | 未含纠偏与验证活动 | 验证 |
| Q5 | WARN | 未含追溯撤回与演练 | 撤回 |

> 脚本 `iso22000-haccp_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python iso22000-haccp_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python iso22000-haccp_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
