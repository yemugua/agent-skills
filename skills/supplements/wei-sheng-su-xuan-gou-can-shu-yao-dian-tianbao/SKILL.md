# 维生素选购参数要点

## 场景
处理"维生素选购"事务中的"参数要点"环节，面向首次购买、被坑维权、进阶选购三类人群。

## 信息/选购渠道
1. 官方渠道：品牌旗舰店/官方授权店，核对授权证书与防伪。
2. 电商平台：优先平台自营或验货宝/官鉴定服务；查看追评与差评。
3. 线下：实体店试穿/试用/试戴后线上比价；二手选平台担保或当面验货。

## 通用准备清单
- 需求清单：用途、预算、核心参数先明确，不被"顶配话术"带偏
- 参数对照：品牌型号、执行标准、认证标志（3C/蓝帽子/CE等）
- 凭证：发票/电子订单、保修卡、防伪溯源
- 证据链：页面宣传截图（尤其"全网最低""正品保证"承诺）

## 流程要点
1. 明确需求与预算 → 2. 列3款候选对比参数 → 3. 查真实评价（追评/差评/晒图）→ 4. 核验授权与认证 → 5. 低价大件选验货服务 → 6. 保留凭证至保修期满。

## 价位与行情
- 心理价=主流渠道均价±10%；明显低于均价的多为假货/瑕疵/翻新。
- 二手按成色分级（充新/95新/9新…），看实物细节图再砍价。

## 常见坑
1. 山寨/高仿/瑕疵当正品
2. 虚标参数（容量/防晒指数/承重）
3. "专供款""电商特供"缩水配置
4. 二手隐瞒维修史/暗病
5. 收藏品赝品与虚高估价

## 维权路径
- 协商 → 平台仲裁 → 12315（假货主张退一赔三）→ 起诉。
- 收到大额假货/涉诈骗：报警 110。

## 提示
保健食品认准"蓝帽子"标志与批准文号，食品不能宣传疗效；本技能不构成医疗或营养处方，特殊人群（孕产/慢病）使用前咨询医生。
