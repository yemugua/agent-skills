# 跨省搬家流程要点

## 场景
处理"跨省搬家"事务中的"流程要点"环节，面向首次消费、被坑维权、比价优化三类人群。

## 信息/办理渠道
1. 官方渠道：12315（消费投诉）、12345（总机）；保险类 12378（金融监管总局热线）。
2. 行业渠道：官方售后/品牌旗舰店/持牌机构；核验资质证照（营业执照、生产许可、执业牌照）。
3. 比价：至少3家，警惕"最后优惠""今日截止"催单话术。

## 通用准备清单
- 需求清单：预算、数量/周期、验收或理赔标准先明确
- 合同/保单：条款逐条读，重点看免责、退费、违约责任
- 付款留痕：大额分期付、索发票、拒私下转账
- 证据链：宣传截图、沟通记录、开箱/装车影像全程保存

## 流程要点
1. 需求确认 → 2. 多方比价 → 3. 资质核验 → 4. 签约（重点读免责与退费条款）→ 5. 履约验收/出险报案 → 6. 凭证保留至结束。

## 费用与行情
- 以当地市场价与官方指导价为准；明显低价多伴随加价、减配、缩水。
- 预付类金额尽量低、周期尽量短。

## 常见坑
1. 低价揽客→中途加价（搬家/维修典型）
2. 口头承诺不落合同
3. 免责条款藏在附件
4. 以次充好（假粮/翻新件/非原厂配件）
5. 销售话术隐瞒关键信息（保险健康告知、宠物粮成分）

## 维权路径
- 协商 → 平台申诉 → 12315/12378 → 消协调解 → 起诉（小额诉讼）。
- 涉假货/欺诈：主张退一赔三；涉诈骗报警 110。

## 提示
搬家纠纷多为"低价揽客、坐地加价"：下单前要求书面报价单（明确车型、米数、楼层费、拆装费），装车前拍照留证，到新址再付尾款。被加价可 12315 投诉或报警。
