# 环境影响评价与竣工环保验收（eia-management）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《环境影响评价法》与建设项目竣工环保验收规定，生成清单：环评类别判定与文件层级、批复意见与三同时衔接、施工期环境监理、自主验收程序与公开、台账与后评价。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 环境影响评价
- 竣工环保验收
- 自主验收公开
- 环评登记表
- 批复符合性

## 三、工作流
1. 判定环评类别与文件层级
2. 衔接批复意见与同时设计施工投产
3. 实施施工期环境监理
4. 履行自主验收程序并公开
5. 建立台账并开展后评价

## 四、核心内容（检查清单与判定）
未批先建与批建不符是两类高频违法情形。竣工验收由审批制改为自主验收后，主体责任更重，程序不规范同样会被追责。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含环评类别与文件层级判定 | 类别 |
| Q2 | FAIL | 未含批复意见与同时落实衔接 | 批复 |
| Q3 | WARN | 未含施工期环境监理 | 监理 |
| Q4 | FAIL | 未含自主验收程序与公开 | 验收 |
| Q5 | WARN | 未含台账与后评价 | 后评价 |

> 脚本 `eia-management_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python eia-management_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python eia-management_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
