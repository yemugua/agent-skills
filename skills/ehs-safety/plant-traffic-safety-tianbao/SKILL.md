# 厂内交通与人车分流（plant-traffic-safety）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据厂区道路与场内车辆安全要求，生成清单：道路宽度与转弯半径、人车分流与标志标线、限速与减速设施、车辆准入与驾驶员管理、路口盲区与作业区域隔离。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 厂内交通安全
- 人车分流
- 厂区限速
- 厂区道路标线
- 路口盲区

## 三、工作流
1. 核查道路宽度与转弯半径
2. 落实人车分流与标线标志
3. 设置限速与减速设施
4. 管理车辆准上与驾驶员资质
5. 治理路口盲区与作业区隔离

## 四、核心内容（检查清单与判定）
车辆伤害是工厂高频事故。人车分流、路口限速与盲区治理是三大要点；单纯靠提醒行人「注意车」几乎无效，必须用物理隔离与工程措施。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含道路宽度与转弯半径 | 道路 |
| Q2 | FAIL | 未含人车分流与标志标线 | 分流 |
| Q3 | WARN | 未含限速与减速设施 | 限速 |
| Q4 | WARN | 未含车辆准入与驾驶员管理 | 准入 |
| Q5 | WARN | 未含路口盲区与作业隔离 | 盲区 |

> 脚本 `plant-traffic-safety_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python plant-traffic-safety_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python plant-traffic-safety_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
