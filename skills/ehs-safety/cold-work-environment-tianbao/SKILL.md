# 低温作业防护（cold-work-environment）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《低温作业分级》GB/T 14440 与防寒装备要求，生成清单：低温分级与暴露时长、个体防寒装备配备、作业轮换与取暖点、设备与介质防冻、手足冻伤处置与健康管理。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 低温作业防护
- 冷库作业安全
- 防寒服配备
- 冻伤预防
- 冬季施工防护

## 三、工作流
1. 分级判定低温与暴露时长
2. 配齐个体防寒装备
3. 安排作业轮换与取暖点
4. 落实设备介质防冻措施
5. 处置冻伤并管理健康档案

## 四、核心内容（检查清单与判定）
低温会引起操作灵活度下降与感知迟钝，从而间接引发事故。除了防寒服，更要以缩短暴露时长与设置取暖点来控制总冷负荷。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含低温分级与暴露时长 | 分级 |
| Q2 | FAIL | 未含个体防寒装备配备 | 防寒服 |
| Q3 | WARN | 未含作业轮换与取暖点 | 轮换 |
| Q4 | WARN | 未含设备与介质防冻 | 防冻 |
| Q5 | WARN | 未含冻伤处置与健康管理 | 健康 |

> 脚本 `cold-work-environment_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python cold-work-environment_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python cold-work-environment_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
