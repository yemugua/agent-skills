# 气体检测报警仪配置与管理（gas-detector-config）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《可燃气体探测器》GB 15322 与 GB 12358 有毒气体检测报警要求，生成清单：检测点布设与泄漏源识别、探测器选型与量程、报警值设定与联动、检定校准周期与台账、便携式仪器配备与使用记录。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 可燃气体报警器
- 有毒气体检测
- 探测器布点
- 报警值设定
- 便携气体检测仪

## 三、工作流
1. 识别泄漏源并布设检测点
2. 完成探测器选型与量程确认
3. 设定报警值并配置联动
4. 执行检定校准并建立台账
5. 配备便携仪器并做使用记录

## 四、核心内容（检查清单与判定）
探测器装了不等于有效：布点位置不当、量程选错、报警值随意设定、长期不检定，都会让整套系统在真正泄漏时沉默。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含检测点布设与泄漏源识别 | 布点 |
| Q2 | FAIL | 未含探测器选型与量程 | 量程 |
| Q3 | FAIL | 未含报警值设定与联动 | 联动 |
| Q4 | FAIL | 未含检定校准周期与台账 | 检定 |
| Q5 | WARN | 未含便携仪器配备与使用记录 | 便携 |

> 脚本 `gas-detector-config_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python gas-detector-config_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python gas-detector-config_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

- 留痕记录（谁/何时/依据）

## 八、常见坑

- 只看有无、不看有效性（如制度上墙但从未演练）。
