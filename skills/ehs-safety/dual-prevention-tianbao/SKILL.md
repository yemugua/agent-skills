# 双重预防机制建设（dual-prevention）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《安全生产风险分级管控和隐患排查治理双重预防机制》要求，生成清单：风险点划分与辨识清单、风险评估分级与管控层级、责任人与管控措施、隐患排查清单与频次、信息化与动态更新。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 双重预防机制
- 风险分级管控
- 隐患排查治理
- 风险四色图
- 管控措施

## 三、工作流
1. 划分风险点并形成辨识清单
2. 开展风险评估分级与管控层级
3. 落实责任人与管控措施
4. 编制排查清单并明确频次
5. 推进信息化与动态更新

## 四、核心内容（检查清单与判定）
双重预防的关键是「两道防火墙都要真」，常见的失败形态是风险清单与隐患清单互不相干、评估后没有管控措施、做完一版就再不更新。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含风险点清单与辨识 | 清单 |
| Q2 | FAIL | 未含评估分级与管控层级 | 分级 |
| Q3 | FAIL | 未含责任人与管控措施 | 措施 |
| Q4 | WARN | 未含排查清单与频次 | 频次 |
| Q5 | WARN | 未含信息化与动态更新 | 更新 |

> 脚本 `dual-prevention_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python dual-prevention_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python dual-prevention_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
