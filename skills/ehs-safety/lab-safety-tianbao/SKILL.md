# 实验室安全管理（lab-safety）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《高等学校实验室安全规范》与通用实验室安全管理要求，生成清单：危险源分类与台账、危化品采购领用与储存、通风柜与防护设施、人员培训与着装要求、废弃物处置与应急。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 实验室安全
- 化验室安全
- 实验室危化品
- 通风柜
- 实验室废弃物

## 三、工作流
1. 建立危险源分类与台账
2. 规范危化品采购领用储存
3. 配置并维护通风柜等防护设施
4. 落实人员培训与着装要求
5. 组织废弃物处置与应急演练

## 四、核心内容（检查清单与判定）
实验室事故多为化学品灼伤、火灾与中毒。危化品必须做到台账清晰、限量储存、分类隔离；通风柜不得兼作储柜，废弃物须由有资质单位收运并保留联单。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含危险源分类与台账 | 台账 |
| Q2 | FAIL | 未含危化品采购领用储存 | 危化品 |
| Q3 | WARN | 未含通风柜与防护设施 | 通风柜 |
| Q4 | WARN | 未含人员培训与着装要求 | 培训 |
| Q5 | FAIL | 未含废弃物处置与应急 | 废弃物 |

> 脚本 `lab-safety_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python lab-safety_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python lab-safety_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
