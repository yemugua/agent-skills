# 激光设备作业安全（laser-safety）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《激光产品的安全》GB 7247.1，生成清单：激光等级判定与安全标识、防护围封与联锁装置、操作员培训与个体防护镜、光路布置与漫反射控制、警示标识与区域管控。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 激光安全
- 激光等级划分
- 激光防护镜
- 激光联锁装置
- 激光切割安全

## 三、工作流
1. 判定激光等级并设置标识
2. 配置防护围封与联锁
3. 培训操作员并配防护镜
4. 规范光路并控制漫反射
5. 设置警示标识与区域管控

## 四、核心内容（检查清单与判定）
激光伤害以眼损伤与皮肤灼伤为主，且多数无明显痛感。不同波长与功率需对应不同防护镜，用错镜片等于没有防护；围封联锁比管理要求更可靠。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含激光等级判定与标识 | 等级 |
| Q2 | FAIL | 未含防护围封与联锁装置 | 联锁 |
| Q3 | FAIL | 未含培训与个体防护镜 | 防护镜 |
| Q4 | WARN | 未含光路布置与漫反射控制 | 光路 |
| Q5 | WARN | 未含警示标识与区域管控 | 警示 |

> 脚本 `laser-safety_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python laser-safety_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python laser-safety_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
