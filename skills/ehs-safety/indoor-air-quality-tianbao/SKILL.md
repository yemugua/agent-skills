# 室内空气质量与新风管理（indoor-air-quality）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《室内空气质量标准》GB/T 18883 与 GB 50325，生成清单：污染来源辨识、新风量与换气次数、空调系统清洗与滤网更换、检测点位与指标限值、超标治理与复测闭环。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 室内空气检测
- 甲醛超标治理
- 新风量不足
- 空调系统清洗
- 办公室空气品质

## 三、工作流
1. 辨识室内污染来源
2. 核算新风量与换气次数
3. 安排空调清洗与滤网更换
4. 确定检测点位与限值
5. 实施超标治理与复测闭环

## 四、核心内容（检查清单与判定）
新装修后急于入驻、新风量不足、空调长期不清洗是三大成因。治理后必须复测确认，且应优先源头控制而非依赖空气净化器。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含污染来源辨识 | 来源 |
| Q2 | FAIL | 未含新风量与换气次数核算 | 新风 |
| Q3 | WARN | 未含空调清洗与滤网更换 | 清洗 |
| Q4 | FAIL | 未含检测点位与指标限值 | 检测 |
| Q5 | WARN | 未含超标治理与复测闭环 | 复测 |

> 脚本 `indoor-air-quality_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python indoor-air-quality_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python indoor-air-quality_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
