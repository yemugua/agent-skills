# 电弧灼伤与电气作业防护（electric-arc-protection）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据低压配电安全与电气作业防护要求，生成清单：电弧危害分析与计算、带电作业接近距离限制、防弧服与面部防护、工具绝缘与验电接地、警示标签与作业许可。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 电弧灼伤防护
- 防弧服配备
- 带电作业距离
- 验电接地规范
- 闪弧风险评估

## 三、工作流
1. 开展电弧危害分析与能量计算
2. 限定带电作业的接近距离
3. 配备防弧服与面部防护
4. 使用绝缘工具并验电接地
5. 设置警示标签并实行作业许可

## 四、核心内容（检查清单与判定）
电弧温度可达上万度，普通棉质衣物遇弧会熔融造成深度烧伤。必须先断电，无法断电时须依据计算结果选择相应等级的防弧装备。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含电弧危害分析与能量计算 | 分析 |
| Q2 | FAIL | 未含带电作业接近距离限制 | 距离 |
| Q3 | FAIL | 未含防弧服与面部防护 | 防弧服 |
| Q4 | FAIL | 未含绝缘工具与验电接地 | 接地 |
| Q5 | WARN | 未含警示标签与作业许可 | 标签 |

> 脚本 `electric-arc-protection_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python electric-arc-protection_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python electric-arc-protection_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
