# 职业心理健康与压力管理（psychosocial-risk）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据职业健康促进与工作场所心理风险管理理念，生成清单：压力源识别与评估、工作量与角色冲突、管理支持与沟通机制、员工援助计划（EAP）、培训宣传与效果评估。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 职业心理健康
- 职场压力管理
- 员工援助计划
- 职业倦怠
- 压力大导致事故

## 三、工作流
1. 开展压力源识别与评估
2. 治理工作量与角色冲突
3. 建立管理支持与沟通机制
4. 引入员工援助与咨询服务
5. 组织培训宣传并评估效果

## 四、核心内容（检查清单与判定）
长期高压会放大操作失误风险。心理健康工作须严守保密原则，避免把评估结果用于人事考核，否则员工不信任、干预也失效。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含压力源识别与评估 | 评估 |
| Q2 | WARN | 未含工作量与角色冲突治理 | 工作量 |
| Q3 | WARN | 未含管理支持与沟通机制 | 沟通 |
| Q4 | FAIL | 未含员工援助与咨询服务 | 援助 |
| Q5 | WARN | 未含培训宣传与效果评估 | 培训 |

> 脚本 `psychosocial-risk_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python psychosocial-risk_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python psychosocial-risk_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
