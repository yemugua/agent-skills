# 压力管道安全（pressure-pipeline-safety）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《压力管道安全技术监察规程》与 TSG D0001，生成清单：管道级别与设计文件、安装告知与监督检验、在线检验与全面检验周期、安全附件与支吊架、腐蚀防护与隐患排查。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 压力管道检验
- 压力管道安装告知
- 在线检验周期
- 管道防腐检查
- 支吊架检查

## 三、工作流
1. 确认管道级别与设计文件
2. 办理安装告知与监督检验
3. 安排在线与全面检验周期
4. 检查安全附件与支吊架
5. 落实腐蚀防护与隐患排改

## 四、核心内容（检查清单与判定）
压力管道常被忽视，事故多发生在弯头与阀门等薄弱环节。安装阶段必须履行告知与监检，投用后按期在线检验与壁厚检测是关键。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含管道级别与设计文件 | 级别 |
| Q2 | FAIL | 未含安装告知与监督检验 | 告知 |
| Q3 | FAIL | 未含检验周期管理 | 周期 |
| Q4 | WARN | 未含安全附件与支吊架 | 附件 |
| Q5 | WARN | 未含腐蚀防护与隐患整改 | 防腐 |

> 脚本 `pressure-pipeline-safety_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python pressure-pipeline-safety_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python pressure-pipeline-safety_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
