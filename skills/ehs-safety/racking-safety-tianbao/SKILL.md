# 仓储货架与堆垛安全（racking-safety）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据仓储货架使用安全要求，生成清单：额定载荷标识与不超载、货架安装与地脚固定、横梁挂扣与安全销、货物堆码与平衡、定期巡检与变形报废。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 仓储货架安全
- 货架承重标识
- 横梁安全销
- 货架巡检
- 货物堆高

## 三、工作流
1. 标注额定载荷并严禁超载
2. 核查安装与地脚固定
3. 检查横梁挂扣与安全销
4. 规范货物堆码与平衡
5. 开展定期巡检与变形报废

## 四、核心内容（检查清单与判定）
货架倒塌往往由超载、叉车撞击与横梁未落锁引起。额定载荷牌与防撞护栏是基础配置；发现立柱变形应即停用由厂家评估，不可带病使用。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含额定载荷标识与防超载 | 载荷 |
| Q2 | FAIL | 未含安装与地脚固定 | 固定 |
| Q3 | WARN | 未含横梁挂扣与安全销 | 安全销 |
| Q4 | WARN | 未含货物堆码与平衡 | 堆码 |
| Q5 | FAIL | 未含定期巡检与变形报废 | 巡检 |

> 脚本 `racking-safety_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python racking-safety_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python racking-safety_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
