# 污水处理设施安全（wastewater-station-safety）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据有限空间作业与污水处理安全措施要求，生成清单：构筑物防护栏与盖板、有限空间作业审批与气体检测、加药间化学品存储与投加安全、用电与潮湿环境防护、污泥脱水间通风与职业健康。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 污水站安全
- 污水池有限空间
- 加药间安全
- 硫化氢中毒
- 污水站防护栏

## 三、工作流
1. 完善构筑物防护栏与盖板
2. 执行有限空间审批与检测
3. 规范加药间化学品存储投加
4. 落实潮湿环境用电防护
5. 改善污泥间通风与职业健康

## 四、核心内容（检查清单与判定）
污水站的典型致命风险是硫化氢中毒与淹溺，且常因盲目施救造成伤亡扩大；必须先通风再检测后作业，并严禁无防护施救。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含构筑物防护栏与盖板 | 防护栏 |
| Q2 | FAIL | 未含有限空间审批与检测 | 有限空间 |
| Q3 | FAIL | 未含加药间化学品安全管理 | 加药 |
| Q4 | WARN | 未含潮湿环境用电防护 | 用电 |
| Q5 | WARN | 未含污泥间通风与职业健康 | 通风 |

> 脚本 `wastewater-station-safety_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python wastewater-station-safety_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python wastewater-station-safety_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
