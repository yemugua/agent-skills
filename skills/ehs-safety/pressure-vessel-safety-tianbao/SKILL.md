# 压力容器与锅炉安全（pressure-vessel-safety）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《特种设备安全法》与 TSG 规程，生成清单：使用登记与检验周期、安全附件校验（安全阀/压力表）、作业人员持证、运行参数与巡回检查、应急预案与停用手续。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 压力容器检验
- 锅炉定期检验
- 安全阀校验
- 特种设备使用登记
- 锅炉房安全

## 三、工作流
1. 核实使用登记与检验周期
2. 组织安全附件校验
3. 确认作业人员持证上岗
4. 监控运行参数并巡回检查
5. 编制应急预案并办停用手续

## 四、核心内容（检查清单与判定）
压力容器与锅炉属特种设备，必须依法登记、按周期检验、由持证人员操作；安全附件超期未校是最常见的现场隐患，停用与过户也须依法办手续。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含使用登记与检验周期 | 登记 |
| Q2 | FAIL | 未含安全附件校验 | 安全阀 |
| Q3 | FAIL | 未含作业人员持证 | 持证 |
| Q4 | WARN | 未含运行参数与巡回检查 | 巡检 |
| Q5 | WARN | 未含应急预案与停用手续 | 预案 |

> 脚本 `pressure-vessel-safety_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python pressure-vessel-safety_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python pressure-vessel-safety_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
