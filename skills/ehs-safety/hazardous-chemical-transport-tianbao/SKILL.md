# 危化品运输安全（hazardous-chemical-transport）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《危险货物道路运输安全管理办法》与 JT/T 617，生成清单：承运单位与车辆资质、驾驶员押运员持证、包装标识与随车文件、装卸作业与防静电、应急预案与事故处置。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 危化品运输安全
- 危险货物道路运输
- 承运商资质审查
- 押运员配备
- 危化品装卸

## 三、工作流
1. 审查承运单位与车辆资质
2. 核验驾驶员押运员持证
3. 检查包装标识与随车文件
4. 规范装卸作业与防静电
5. 编制应急预案并处置事故

## 四、核心内容（检查清单与判定）
运输环节风险在于流动性与不可控。资质、持证、随车文件三位一体核查缺一不可，装卸环节则要重点控制静电与泄漏。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含承运单位与车辆资质 | 资质 |
| Q2 | FAIL | 未含驾驶员押运员持证 | 押运员 |
| Q3 | FAIL | 未含包装标识与随车文件 | 随车文件 |
| Q4 | WARN | 未含装卸作业与防静电 | 防静电 |
| Q5 | WARN | 未含应急预案与事故处置 | 预案 |

> 脚本 `hazardous-chemical-transport_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python hazardous-chemical-transport_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python hazardous-chemical-transport_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
