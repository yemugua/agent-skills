# 放射与射线作业安全（radiation-safety）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《放射性同位素与射线装置安全和防护条例》与 GB 18871，生成清单：辐射源许可与台账、场所分区与警示标志、个人剂量监测与体检、屏蔽与联锁防护、废源处置与运输。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 辐射安全许可
- 放射源管理
- 射线探伤
- 个人剂量计
- 废源处置

## 三、工作流
1. 核实许可并建立源台账
2. 划分场所分区并设置警示
3. 开展个人剂量监测与体检
4. 配置屏蔽与联锁防护
5. 办理废源处置与运输手续

## 四、核心内容（检查清单与判定）
辐射危害无形且后果严重。许可与台账、场所分区警示、个人剂量档案三者缺一不可；废源必须交回原生产单位或省库，严禁自行处置。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含许可与放射源台账 | 许可 |
| Q2 | FAIL | 未含场所分区与警示标志 | 分区 |
| Q3 | FAIL | 未含个人剂量监测与体检 | 剂量 |
| Q4 | WARN | 未含屏蔽与联锁防护 | 屏蔽 |
| Q5 | WARN | 未含废源处置与运输 | 废源 |

> 脚本 `radiation-safety_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python radiation-safety_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python radiation-safety_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
