# 再生资源堆场防火（recycling-yard-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据再生资源回收场所防火要求，生成清单：分区堆放与垛距通道、废纸塑料橡胶分类管控、易燃液体与危险废物隔离、消防水源与器材配置、电气线路与明火查禁。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 废品回收站消防
- 再生资源堆场防火
- 废纸堆垛防火
- 塑料堆场消防
- 露天垃圾堆场

## 三、工作流
1. 实施分区堆放并控制垛距通道
2. 分类管控废纸塑料与橡胶
3. 隔离易燃液体与危险废物
4. 配置消防水源与灭火器材
5. 查禁违规电气与明火

## 四、核心内容（检查清单与判定）
回收物资混杂、自燃风险高且火势蔓延快。分区分垛、控制堆高与留出检查通道是最经济的手段，同时必须具备可靠的消防水源。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含分区堆放与垛距通道 | 垛距 |
| Q2 | WARN | 未含废纸塑料分类管控 | 分类 |
| Q3 | FAIL | 未含易燃液体与危废隔离 | 隔离 |
| Q4 | FAIL | 未含消防水源与灭火器材 | 水源 |
| Q5 | WARN | 未含电气线路与明火查禁 | 明火 |

> 脚本 `recycling-yard-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python recycling-yard-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python recycling-yard-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
