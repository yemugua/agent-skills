# 大空间与钢结构建筑防火（large-space-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据 GB 50016 与《建筑钢结构防火技术规范》GB 51249，生成清单：钢结构耐火极限与防火涂料、防火分区面积折减与隔离带、自然排烟与机械排烟、大空间自动灭火选型、火源控制与疏散演练。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 钢结构防火
- 防火涂料厚度
- 大空间排烟
- 体育馆消防
- 钢梁柱耐火极限

## 三、工作流
1. 确定构件耐火极限要求
2. 核查防火涂料类型与厚度
3. 校核防火分区与隔离带
4. 组织自然或机械排烟
5. 选型大空间自动灭火系统

## 四、核心内容（检查清单与判定）
钢结构在 500℃左右即丧失承载力，必须按构件类型与耐火极限施作防火保护；防火涂料厚度不足、脱落是大空间建筑验收与日常检查的高频问题。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含构件耐火极限要求 | 耐火极限 |
| Q2 | FAIL | 未含防火涂料类型与厚度 | 防火涂料 |
| Q3 | WARN | 未含防火分区与隔离带 | 分区 |
| Q4 | WARN | 未含排烟系统配置 | 排烟 |
| Q5 | FAIL | 未含自动灭火系统选型 | 灭火 |

> 脚本 `large-space-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python large-space-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python large-space-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。
