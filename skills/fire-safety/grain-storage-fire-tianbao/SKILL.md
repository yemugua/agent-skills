# 粮食仓储防火（grain-storage-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《粮食钢板筒仓设计规范》与粮库防火要求，生成清单：仓房耐火等级与防火间距、除尘与防爆、熏蒸药剂与火源管控、电气防火与防雷、消防设施与值班巡查。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 粮库消防
- 粮食仓储防火
- 筒仓防爆
- 熏蒸作业安全
- 粮库除尘

## 三、工作流
1. 核定仓房耐火等级与防火间距
2. 配置除尘系统并落实防爆
3. 管控熏蒸药剂与一切火源
4. 落实电气防火与防雷接地
5. 配置消防设施并值班巡查

## 四、核心内容（检查清单与判定）
粮库火灾多伴粉尘爆炸风险，且熏蒸药剂遇水或明火会释放有毒气体；粮堆阴燃难以发觉，依靠温度监测与巡查及早处置尤为关键。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含耐火等级与防火间距 | 间距 |
| Q2 | FAIL | 未含除尘与防爆措施 | 防爆 |
| Q3 | FAIL | 未含熏蒸药剂与火源管控 | 熏蒸 |
| Q4 | WARN | 未含电气防火与防雷接地 | 防雷 |
| Q5 | WARN | 未含消防设施与值班巡查 | 巡查 |

> 脚本 `grain-storage-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python grain-storage-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python grain-storage-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
