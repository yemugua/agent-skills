# 金属冶炼防火防爆（metal-smelting-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《有色金属工程设计防火规范》与冶金企业安全要求，生成清单：熔融金属与水接触防控、炉窑冷却系统冗余与断电保障、液压站与油库防火、高温区域可燃物清理、钢包吊运与事故坑保障。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 冶金防火
- 熔融金属防爆
- 炉窑冷却系统
- 液压站防火
- 钢铁厂消防

## 三、工作流
1. 防控熔融金属与水接触
2. 配置冷却系统冗余与应急电源
3. 落实液压站与油库防火
4. 清理高温区域可燃杂物
5. 保障钢包吊运与事故坑

## 四、核心内容（检查清单与判定）
冶金最大灾难是熔融金属遇水爆炸。冷却系统必须有双电源与应急水，场地不得积水；周围严禁存放潮湿物料与易燃液压油是一贯的红线。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含熔融金属遇水防控 | 防水 |
| Q2 | FAIL | 未含冷却系统冗余与断电保障 | 冷却 |
| Q3 | FAIL | 未含液压站与油库防火 | 油库 |
| Q4 | WARN | 未含高温区可燃物清理 | 清理 |
| Q5 | WARN | 未含吊运与事故坑保障 | 事故坑 |

> 脚本 `metal-smelting-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python metal-smelting-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python metal-smelting-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。
