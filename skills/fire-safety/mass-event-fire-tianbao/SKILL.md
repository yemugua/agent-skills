# 大型群众性活动临时消防（mass-event-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《大型群众性活动安全管理条例》与临时建筑防火要求，生成清单：临时设施搭建材料燃烧性能、疏散通道宽度与人流控制、临时电气线路敷设、明火与烟花管控、现场执勤与应急疏散预案。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 大型活动消防
- 临时舞台防火
- 展台搭建防火
- 人流疏散控制
- 篷房电气安全

## 三、工作流
1. 控制临时设施材料燃烧性能
2. 保障疏散通道宽度与人流控制
3. 规范临时电气线路敷设
4. 管控明火与烟火燃放
5. 落实现场执勤与疏散预案

## 四、核心内容（检查清单与判定）
大型活动风险集中在短时间内人流激增与临时设施。临时线路过载、篷房用易燃夹芯板、出口被占，是历年活动火灾与踩踏的三个主因。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含搭建材料燃烧性能 | 材料 |
| Q2 | FAIL | 未含疏散通道与人流控制 | 人流 |
| Q3 | FAIL | 未含临时电气线路敷设 | 临时用电 |
| Q4 | WARN | 未含明火与烟火管控 | 明火 |
| Q5 | WARN | 未含执勤与疏散预案 | 预案 |

> 脚本 `mass-event-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python mass-event-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python mass-event-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
