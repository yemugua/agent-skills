# 建设工程施工现场消防（construction-site-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《建设工程施工现场消防安全技术规范》GB 50720，生成清单：总平面布置与消防车道、临时消防设施与给水、临时用房防火与疏散、动火作业管理与保温材料、临时用电与消防教育培训。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 施工现场消防
- 在建工地消防
- 临时消防给水
- 工地临时用房
- 动火作业管理

## 三、工作流
1. 核查总平面与消防车道
2. 配置临时消防设施与给水
3. 规范临时用房防火与疏散
4. 管控动火作业与保温材料
5. 落实临时用电与消防培训

## 四、核心内容（检查清单与判定）
GB 50720 明确在建工程须同步设置临时消防给水系统并保持充水；工地火灾多起源于电焊动火与临时用电，可燃保温材料堆放亦须严控。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含总平面与消防车道 | 总平面 |
| Q2 | FAIL | 未含临时消防设施与给水 | 给水 |
| Q3 | WARN | 未含临时用房防火与疏散 | 临时用房 |
| Q4 | FAIL | 未含动火作业与保温材料管控 | 动火 |
| Q5 | WARN | 未含临时用电与消防培训 | 培训 |

> 脚本 `construction-site-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python construction-site-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python construction-site-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
