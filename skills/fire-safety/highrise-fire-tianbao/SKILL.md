# 高层民用建筑防火（highrise-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《建筑设计防火规范》GB 50016，生成清单：建筑高度与分类判定、防火分区与安全疏散、避难层（间）与消防电梯、竖向管井与防火封堵、消防救援口与扑救面。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 高层建筑防火
- 民用建筑分类
- 避难层设置
- 消防救援窗口
- 竖向管井封堵

## 三、工作流
1. 判定建筑高度与分类
2. 核查防火分区与安全疏散
3. 核查避难层与消防电梯
4. 检查竖向管井与防火封堵
5. 核查消防救援口与扑救面

## 四、核心内容（检查清单与判定）
GB 50016 对高层民用建筑的分类决定了其后全部防火要求；竖向管井封堵不严、避难层被占用、救援窗口被遮挡，是既有高层最常见的三类隐患。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含建筑高度与分类判定 | 分类 |
| Q2 | FAIL | 未含防火分区与安全疏散 | 疏散 |
| Q3 | WARN | 未含避难层与消防电梯 | 避难层 |
| Q4 | FAIL | 未含竖向管井与防火封堵 | 封堵 |
| Q5 | WARN | 未含消防救援口与扑救面 | 救援口 |

> 脚本 `highrise-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python highrise-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python highrise-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
