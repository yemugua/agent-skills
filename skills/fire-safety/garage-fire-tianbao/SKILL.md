# 汽车库与修车库防火（garage-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《汽车库、修车库、停车场设计防火规范》GB 50067，生成清单：库类别划分与耐火等级、防火分区与人员疏散、机械停车设备防火、修车库动火与危废品存放、自动喷水与排烟。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 汽车库消防
- 修车库防火
- 地下车库防火分区
- 机械立体车库消防
- 车库排烟

## 三、工作流
1. 判定库类别与耐火等级
2. 核查防火分区与疏散
3. 配置机械停车设备防火
4. 管控修车库动火与危废品
5. 校核自动喷水与排烟系统

## 四、核心内容（检查清单与判定）
GB 50067 按停车数量与建筑形式划分库类别并确定防火要求；机械立体车库疏散困难、修车库存在动火与油品，是两类需重点关注的对象。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含库类别与耐火等级判定 | 类别 |
| Q2 | FAIL | 未含防火分区与人员疏散 | 疏散 |
| Q3 | WARN | 未含机械停车设备防火 | 机械停车 |
| Q4 | FAIL | 未含修车库动火与危废存放 | 动火 |
| Q5 | WARN | 未含自动喷水与排烟系统 | 排烟 |

> 脚本 `garage-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python garage-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python garage-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
