# 宾馆饭店防火（hotel-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《建筑设计防火规范》GB 50016 与旅馆建筑设计防火要求，生成清单：客房层疏散距离与安全出口、厨房与燃气用房分隔、内部装修材料燃烧性能、消防设施与应急广播、夜间巡查与客人疏散引导。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 宾馆消防
- 饭店防火
- 客房层疏散
- 旅馆装修材料
- 酒店消防演练

## 三、工作流
1. 核查客房层疏散距离与出口
2. 分隔厨房与燃气用房
3. 控制装修材料燃烧性能
4. 配置消防设施与应急广播
5. 落实夜间巡查与疏散引导

## 四、核心内容（检查清单与判定）
宾馆饭店人员密集且夜间住客对疏散路线不熟，装修可燃化是典型隐患；要通过应急广播、房门疏散图与演练弥补夜间疏散的天然劣势。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含客房层疏散距离与出口 | 疏散 |
| Q2 | FAIL | 未含厨房与燃气用房分隔 | 分隔 |
| Q3 | WARN | 未含装修材料燃烧性能 | 装修 |
| Q4 | FAIL | 未含消防设施与应急广播 | 广播 |
| Q5 | WARN | 未含夜间巡查与疏散引导 | 夜间 |

> 脚本 `hotel-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python hotel-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python hotel-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构

- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
