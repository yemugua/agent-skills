# 注册消防工程师继续教育（fire-engineer-continuing-ed）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据注册消防工程师继续教育要求，生成清单：学时组成与年度要求、课程范围与标准更新、学习记录与证明留存、执业签章与执业档案、常见违规与信用风险。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 消防工程师继续教育
- 继续教育学习平台
- 学时证明
- 执业签章管理
- 注册有效期延续

## 三、工作流
1. 明确学时组成与年度要求
2. 选择课程并跟进标准更新
3. 留存学习记录与证明
4. 规范执业签章与执业档案
5. 识别常见违规与信用风险

## 四、核心内容（检查清单与判定）
继续教育不仅是凑学时，标准更新正是历年新增考点。注册有效期延续须提前准备，执业档案缺失或证书挂靠会带来严重执业风险。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含学时组成与年度要求 | 学时 |
| Q2 | WARN | 未含课程范围与标准更新 | 课程 |
| Q3 | FAIL | 未含学习记录与证明留存 | 证明 |
| Q4 | WARN | 未含执业签章与执业档案 | 执业档案 |
| Q5 | WARN | 未含违规与信用风险管理 | 信用 |

> 脚本 `fire-engineer-continuing-ed_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python fire-engineer-continuing-ed_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python fire-engineer-continuing-ed_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
