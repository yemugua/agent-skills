# 消防标准检索与应用（fire-standard-retrieval）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据现行工程建设标准体系，生成清单：检索渠道与现行有效性核对、强制性条文与推荐性条文区分、适用范围判定、标准冲突时的优先级、更新跟踪与清单维护。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 消防标准检索
- 消防规范查询
- 强制性条文
- 标准更新跟踪
- 规范冲突处理

## 三、工作流
1. 通过权威渠道检索并核对现行有效性
2. 区分强制性条文与推荐性条文
3. 判定标准适用范围
4. 处理标准间冲突时的优先级
5. 跟踪更新并维护标准清单

## 四、核心内容（检查清单与判定）
引用作废版本的标准是常见错误。强制性条文必须严格执行，推荐性条文可在合同约定下偏离；不同标准冲突时通常以专用且更严格者为准。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含检索渠道与现行有效性核对 | 现行有效 |
| Q2 | FAIL | 未含强制性与推荐性条文区分 | 条文 |
| Q3 | WARN | 未含适用范围判定 | 适用范围 |
| Q4 | WARN | 未含冲突优先级处理 | 优先级 |
| Q5 | WARN | 未含更新跟踪与清单维护 | 更新 |

> 脚本 `fire-standard-retrieval_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python fire-standard-retrieval_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python fire-standard-retrieval_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
