# 燃煤储运系统防火（coal-yard-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据电力行业防火与运煤系统设计要求，生成清单：煤场堆放高度与压实、堆取料与消防设施配置、皮带输送机防火与沿线停线、煤粉制备系统惰化与防爆、温度监测与堆场计划。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 煤场消防
- 输煤皮带防火
- 煤粉系统防爆
- 储煤自燃
- 煤场测温

## 三、工作流
1. 控制堆放高度并压实分层
2. 配置堆取水枪与消防设施
3. 落实皮带防火与沿线停线
4. 实施煤粉系统惰化与防爆
5. 开展温度监测与堆场计划

## 四、核心内容（检查清单与判定）
燃煤长期堆放会缓慢氧化蓄热导致自燃，须按先进先出控制存期并定期测温；输煤皮带与煤粉系统则应重点防控摩擦引燃与粉尘爆炸。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含堆放高度与压实分层 | 堆高 |
| Q2 | WARN | 未含消防设施配置 | 设施 |
| Q3 | FAIL | 未含皮带防火与沿线停线 | 皮带 |
| Q4 | FAIL | 未含煤粉惰化与防爆 | 惰化 |
| Q5 | WARN | 未含温度监测与堆场计划 | 测温 |

> 脚本 `coal-yard-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python coal-yard-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python coal-yard-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
