# 消防安全网格化管理（fire-safety-grid）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据消防安全责任制实施办法与基层网格化管理要求，生成清单：网格划分与责任到人、基础台账与重点对象、日常巡查与隐患上报、宣传培训与演练、考核问责与通报。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 消防网格化管理
- 网格员消防巡查
- 九小场所排查
- 群租房整治
- 责任片区考核

## 三、工作流
1. 划分网格并落实责任人
2. 建立基础台账与重点对象清单
3. 开展日常巡查与隐患上报
4. 组织宣传培训与演练
5. 实施考核问责与通报

## 四、核心内容（检查清单与判定）
网格化的生命力在于巡查能发现问题且问题能闭环。只填表不见整改、隐患上报后无人认领，网格就会退化成形式主义台账。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含网格划分与责任到人 | 网格 |
| Q2 | FAIL | 未含基础台账与重点对象 | 台账 |
| Q3 | FAIL | 未含日常巡查与隐患上报 | 上报 |
| Q4 | WARN | 未含宣传培训与演练 | 演练 |
| Q5 | WARN | 未含考核问责与通报 | 考核 |

> 脚本 `fire-safety-grid_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python fire-safety-grid_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python fire-safety-grid_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
