# 分布式屋顶光伏防火（pv-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据光伏电站安全与屋面防火要求，生成清单：组件与逆变器选型资质、直流拉弧与热斑防控、屋面布置与疏散通道、断电隔离与标识、运维检修与应急通道保障。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 屋顶光伏防火
- 光伏组件火灾
- 直流拉弧保护
- 逆变器消防
- 分布式光伏检查

## 三、工作流
1. 核查组件逆变器选型与资质
2. 防控直流拉弧与热斑风险
3. 优化屋面布置并保留疏散通道
4. 设置断电源点与警示标识
5. 落实运维检修与应急处置

## 四、核心内容（检查清单与判定）
光伏系统断电难、屋面作业风险高，直流拉弧是主要起火诱因；必须保证组件与逆变器具备合格认证，并留出屋面检修与疏散通道，同时设置明显断电源点。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含组件与逆变器选型资质 | 选型 |
| Q2 | FAIL | 未含直流拉弧与热斑防控 | 拉弧 |
| Q3 | WARN | 未含屋面布置与疏散通道 | 通道 |
| Q4 | FAIL | 未含断电隔离与警示标识 | 断点 |
| Q5 | WARN | 未含运维检修与应急处置 | 运维 |

> 脚本 `pv-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python pv-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python pv-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

- 重大隐患/高风险判定需由具备资质人员签字确认。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
