# 纺织服装厂房防火（textile-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《纺织工程设计防火规范》与丙类厂房防火要求，生成清单：原料与成品仓库防火、清梳并粗车间飞花粉尘清理、印染车间蒸汽与导热油、防火分区与安全疏散、电气防火与下班断电。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 纺织厂防火
- 服装厂消防
- 飞花粉尘清理
- 印染车间防火
- 丙类厂房消防

## 三、工作流
1. 管控原料与成品仓库防火
2. 清理车间飞花与粉尘
3. 管控印染汽热与导热油系统
4. 划分防火分区并保障疏散
5. 落实电气防火与下班断电

## 四、核心内容（检查清单与判定）
纺织原料多为丙类可燃物且伴有飞花积聚，起火后蔓延极快；定期清理飞花、控制仓储存量、下班断电是成本最低也最关键的防火措施。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含仓库防火与储量控制 | 仓库 |
| Q2 | FAIL | 未含飞花与粉尘清理 | 清理 |
| Q3 | WARN | 未含印染汽热与导热油管控 | 导热油 |
| Q4 | FAIL | 未含防火分区与安全疏散 | 疏散 |
| Q5 | WARN | 未含电气防火与下班断电 | 断电 |

> 脚本 `textile-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python textile-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python textile-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
