# 住宅小区消防管理（residential-community-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《消防法》与住宅物业消防管理要求，生成清单：消防设施日常维保与标识、疏散通道与电动车集中充电、物业管理履职与巡查频次、业主装修与明火管控、微型站与初期处置。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 住宅小区消防
- 物业消防管理
- 楼道堆物清理
- 小区电动车充电
- 社区微型消防站

## 三、工作流
1. 落实消防设施维保与标识
2. 治理疏散通道与充电管理
3. 明确物业履职与巡查频次
4. 管控业主装修与明火
5. 建设微型站并组织初期处置

## 四、核心内容（检查清单与判定）
住宅小区火灾伤亡多发生在楼道与卧室，而疏散通道堆放杂物、电动车违规充电入户是最普遍的两个致命隐患；物业履职不到位会被依法追责。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含消防设施维保与标识 | 维保 |
| Q2 | FAIL | 未含疏散通道与充电管理 | 通道 |
| Q3 | WARN | 未含物业履职与巡查频次 | 巡查 |
| Q4 | WARN | 未含装修与明火管控 | 明火 |
| Q5 | WARN | 未含微型站与初期处置 | 微型站 |

> 脚本 `residential-community-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python residential-community-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python residential-community-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
