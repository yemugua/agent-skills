# 消防水炮与自动射流灭火系统（fire-monitor-system）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《自动跟踪定位射流灭火系统》GB 25204，生成清单：场所适用性判定与选型、探测定位组件配置、供水压力与流量校核、联动控制与手动优先、调试验收与维护。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 消防水炮
- 自动射流灭火系统
- 射流式灭火
- 水炮选型
- 水炮联动调试

## 三、工作流
1. 判定场所适用性与系统选型
2. 配置探测与定位组件
3. 校核供水压力与流量
4. 设置联动控制与手动优先
5. 完成调试验收与维护

## 四、核心内容（检查清单与判定）
GB 25204 规定该类系统适用于净空较高且不宜设置喷头的大空间场所；选型须与水幕喷淋区分，调试必须做全覆盖喷水试验并保留视频记录。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含场所适用性与选型 | 选型 |
| Q2 | FAIL | 未含探测与定位组件配置 | 定位 |
| Q3 | FAIL | 未含供水压力与流量校核 | 流量 |
| Q4 | WARN | 未含联动控制与手动优先 | 联动 |
| Q5 | WARN | 未含调试验收与维护 | 调试 |

> 脚本 `fire-monitor-system_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python fire-monitor-system_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python fire-monitor-system_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
