# 尿不湿合同要点

## 场景
处理"尿不湿"事务中的"合同要点"环节，面向零基础入门、遇坑维权、进阶优化三类人群。

## 信息/办理渠道
1. 官方渠道：对应主管部门（城管/市场监管/民政/卫健/交通等）、热线 12345/12315/12328。
2. 行业渠道：正规平台/协会/连锁品牌官方入口，核验证照与备案。
3. 本地渠道：街道就业服务站、社区服务中心、老年大学、批发市场。

## 通用准备清单
- 身份证/健康证（涉食品、接触人的服务）
- 证照：涉经营先办营业执照与相关许可；涉车辆核验双证
- 书面协议：服务类签合同，明确内容、价格、违约责任
- 收费留痕：所有付款走可追溯渠道，拒私下转账

## 流程要点
1. 需求确认与比价（至少3家）→ 2. 资质核验 → 3. 签约/申请 → 4. 履约留证 → 5. 验收评价。

## 费用与行情
- 以当地公示价/平台指导价为准；明显低于市场价的风险高。
- 设备/物料采购认准正规渠道，"加盟大礼包"多为溢价坑。

## 常见坑
1. 位置/选址陷阱（转让费虚高、人流造假）
2. 押金不退、口头承诺不认
3. 无证经营被处罚（占道、无证餐饮、无资质护理）
4. 平台规则不清导致扣款/封号

## 维权路径
- 协商 → 平台申诉 → 12315/12345 → 民事起诉（小额诉讼）。
- 涉诈骗（虚构项目、卷款跑路）：立即报警 110。

## 提示
涉老消费与护理服务以老人安全为先：选机构核验资质（民政备案/医疗资质），买用品认准医疗器械注册证号；重大健康决策遵医嘱。本技能不构成医疗建议。
