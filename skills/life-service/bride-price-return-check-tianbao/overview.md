# 彩礼返还情形与比例核算

## 你会得到什么

一个**有顺序**的处理框架，跳过任何一步主张都会落空：

**第一步，定范围。** 哪些钱算彩礼，哪些不算。以结婚为目的、按习俗给付的大额财物（彩礼现金、三金五金、为结婚给付的车房款）算；恋爱期间的一般性赠与（节日红包、日常消费、小额礼物）、婚礼开销（酒席婚庆）不算；**嫁妆是独立的一笔财产关系，不能拿来抵扣彩礼**。这一步最常出错的地方是把恋爱期间所有转账都加进来——加进来也会被剔除，还会拖累整体主张的可信度。

**第二步，过门槛。** 三种法定情形：未办理结婚登记；已登记但确未共同生活（**以离婚为条件**）；婚前给付导致给付人生活困难（**以离婚为条件**，且"生活困难"是高标准，指依靠个人财产和离婚分得财产无法维持当地基本生活水平，不是"手头紧"）。已登记且已共同生活的，彩礼返还一般不予支持，正确路径是共同财产分割。

**第三步，算比例。** 按共同生活时长给基准区间（未共同生活 80%~100%，不满 3 个月 70%~90%，3 个月至 1 年 50%~70%，1 至 2 年 30%~50%，2 年以上 0%~30%），再逐项调整：已登记下调、已生育子女大幅下调、给付方重大过错下调、收受方重大过错上调、构成生活困难上调。最后输出**区间**而不是单一数字。

同时给出重复计算核查（已用于共同生活的部分和已转化为共同财产的部分要先从基数中扣除）、诉讼主体（列**实际给付人**与**实际收受人**）、时效（一般三年）与举证要点（礼单、转账备注、媒人证言、订婚仪式证据）。

## 脚本

`scripts/bride_price_calc.py` 读入案件参数，先判情形门槛是否成立，再算可返还基数、基准比例区间与各项调整，输出返还金额区间。带 `--selftest`。脚本输出的是估算区间，不是裁判结论。

## 边界

不作司法裁判结论。是否返还与返还多少由人民法院结合当地习俗、共同生活情况、过错与财产状况综合确定，各地掌握存在差异。金额大、财产类型复杂或已进入诉讼的，请委托婚姻家事律师。
