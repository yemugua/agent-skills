# 规则表一：彩礼范围界定、三种返还情形、比例梯度与调整因素

> 依据民法典婚姻家庭编及现行司法解释关于彩礼返还的规定整理。**具体条款与裁判口径以现行法律和司法解释为准**，本表不编造条款号，比例区间为实务参考区间而非裁判标准。

## 第 1 节 彩礼范围界定表

### 1.1 一般认定为彩礼

| 项目 | 说明 |
|---|---|
| 彩礼现金/转账 | 以结婚为目的、按当地习俗给付，转账备注或聊天记录中体现"彩礼""聘礼" |
| 三金 / 五金 | 金银首饰，多数认定为彩礼性质；给付时间与目的明确为结婚的尤然 |
| 为结婚给付的购车款、购房款或首付 | 需有证据证明给付目的为结婚 |
| 大额"聘礼""礼金" | 按习俗给付且金额明显超出一般赠与 |

### 1.2 一般不认定为彩礼

| 项目 | 处理 |
|---|---|
| 恋爱期间的一般性赠与 | 节日红包、生日礼物、日常消费、小额转账 —— **不返还** |
| 见面礼、改口费 | 依当地习俗与金额个案判断，争议较大 |
| 婚礼开销（酒席、婚庆、婚车、摄影） | 一般由举办方自行承担；有明确约定的从约定 |
| 已共同消费的部分 | 不返还 |
| 嫁妆 / 陪嫁 | **独立处理**，属女方财产或对家庭的投入，不抵扣彩礼 |

### 1.3 判定要点

- 看**给付目的**（是否为结婚）与**给付时间**（是否在订婚、谈婚论嫁阶段）。
- 看**金额**是否明显超出当地一般赠与水平。
- 看**当地习俗**是否有对应的彩礼名目。
- 三金性质存在争议：明确为结婚给付的倾向认定彩礼；纯恋爱赠与的倾向认定赠与，**不要一刀切**。

## 第 2 节 三种返还情形（门槛）

| 情形 | 构成要件 | 附加条件 |
|---|---|---|
| 一 | 双方**未办理结婚登记**手续 | 无 |
| 二 | **已登记**但**确未共同生活** | **以双方离婚为条件** |
| 三 | 婚前给付并导致给付人**生活困难** | **以双方离婚为条件** |

**门槛之外**：已登记且已共同生活、且不构成生活困难的，彩礼返还**一般不予支持**。此时应走**夫妻共同财产分割**路径，不要坚持彩礼返还主张。

**"生活困难"的认定标准**：指依靠个人财产和离婚时分得的财产**无法维持当地基本生活水平**。这是高标准，不是"给完彩礼手头紧"。需提供收入、负债、家庭支出与当地生活水平的证据。

## 第 3 节 基准比例梯度（按共同生活时长）

| 共同生活时长 | 参考比例区间 |
|---|---|
| 未共同生活（0 个月） | 80% ~ 100% |
| 不满 3 个月 | 70% ~ 90% |
| 3 个月 ~ 1 年 | 50% ~ 70% |
| 1 年 ~ 不满 2 年 | 30% ~ 50% |
| 2 年及以上 | 0% ~ 30% |

**原理**：彩礼具有以共同生活为目的的给付性质，共同生活时间越长，给付目的实现程度越高，返还比例越低。

## 第 4 节 调整因素（双向，不要只算一边）

| 因素 | 方向 | 幅度参考 |
|---|---|---|
| 已办理结婚登记 | 下调 | 约 10% ~ 20% |
| 已生育子女 | **大幅下调** | 约 20% ~ 40% |
| 给付方存在重大过错（家暴、出轨、恶意悔婚） | 下调 | 约 10% ~ 20% |
| 收受方存在重大过错（恶意悔婚、隐瞒重大疾病、借婚姻索取财物） | 上调 | 约 10% ~ 20% |
| 构成生活困难（情形三） | 上调 | 约 10% |
| 彩礼已用于共同生活 | **从基数中扣除**，不按比例调整 | 全额扣除 |
| 彩礼已转化为共同财产 | **从基数中扣除**，按共同财产分割 | 全额扣除 |
| 当地经济水平与习俗 | 综合考量 | 个案 |

**要点**：调整是**双向**的。只计算对方过错、不计算自身过错，比例预期会严重偏离。

## 第 5 节 可返还基数（防重复计算）

```
可返还基数 = 核定彩礼总额
           − 已用于共同生活的部分
           − 已转化为夫妻共同财产的部分

返还区间 = 可返还基数 × [调整后下限比例 , 调整后上限比例]
```

**重复计算的三种典型形态**：
1. 彩礼已用于购置共同财产，又在彩礼返还中全额主张，同时在共同财产分割中再分一次 —— **重复**。
2. 已共同消费的部分未扣除 —— **虚增基数**。
3. 用嫁妆抵扣后主张 —— **性质错误**（嫁妆独立处理）。

## 第 6 节 综合示例

**示例 A**：未登记，共同生活 5 个月，彩礼 20 万元，其中 3 万元已用于共同生活，无子女，无重大过错。
- 情形一成立（未登记）。
- 共同生活 3~12 个月 → 基准区间 50%~70%。
- 未登记，不做登记下调。
- 基数 = 20 − 3 = 17 万元。
- 返还区间 = 17 × 50% ~ 17 × 70% = **8.5 万 ~ 11.9 万元**。

**示例 B**：已登记且已离婚，共同生活 14 个月，彩礼 20 万元，已生育子女，5 万元转化为共同财产。
- 情形一不成立（已登记）；情形二不成立（有共同生活）；情形三需看是否生活困难。
- 若生活困难成立 → 基准 30%~50%，已登记 −15%，有子女 −25% → 区间约 0%~10%，基数 15 万 → **0 ~ 1.5 万元**。
- 若生活困难不成立 → **一般不予支持**，应走共同财产分割。

**示例 C**：已登记但确未共同生活，已离婚，彩礼 20 万元，无子女，无过错。
- 情形二成立。
- 未共同生活 → 基准 80%~100%；已登记 −15% → 65%~85%。
- 返还区间 = 20 × 65% ~ 20 × 85% = **13 万 ~ 17 万元**。

## 第 7 节 常见误判对照表

| 情形 | 不要判成 | 正确判法 |
|---|---|---|
| 未办理结婚登记 | 必然全额返还 | 情形成立 ≠ 全额，仍受时长、子女、过错影响 |
| 已登记但未共同生活，未离婚 | 可单独主张彩礼 | **以离婚为条件** |
| 给付后手头紧张 | 构成生活困难 | 需达到无法维持当地基本生活水平 |
| 嫁妆 | 可抵扣彩礼 | 独立处理 |
| 恋爱期间转账 | 全部是彩礼 | 一般赠与部分应剔除 |
| 三金 | 一律算彩礼 / 一律不算 | 依给付时间与目的判断 |
| 已转化为共同财产 | 可在彩礼中再主张一次 | 属重复，应走共同财产分割 |
| 对方悔婚 | 必然大幅多退 | 结合过错程度，非绝对 |
| 彩礼纠纷 | 只告女方本人 | 应列**实际收受人**（可能是其父母） |
