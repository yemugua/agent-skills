# 规则表二：举证清单、诉讼主体、时效、协商与起诉路径

## 第 1 节 举证清单（彩礼纠纷的关键在"名目"）

| # | 证据 | 固化要点 |
|---|---|---|
| 1 | 给付凭证 | 银行转账流水（含收款账户与户名）、微信/支付宝转账记录、现金给付的取款凭证与交付现场证据 |
| 2 | **名目证据**（最关键） | 转账备注"彩礼""聘礼"，聊天记录中明确给付目的为结婚，礼单（书面清单） |
| 3 | **礼单** | 订婚时的书面礼单，载明各项名目与金额，双方或媒人签字 |
| 4 | 订婚/结婚仪式证据 | 仪式照片、视频、请柬，用于佐证给付目的与当地习俗 |
| 5 | 媒人/介绍人证言 | 证人证言（需出庭或书面），证明给付的是彩礼及金额 |
| 6 | 三金五金凭证 | 购买发票、付款记录、交付照片 |
| 7 | 共同生活时长证据 | 共同居住证明、水电燃气缴费记录、邻居证言、聊天记录 |
| 8 | 未登记/已离婚证据 | 婚姻登记机关查询结果、离婚证或离婚裁判文书 |
| 9 | 生活困难证据 | 收入证明、负债凭证、家庭支出、当地生活水平材料 |
| 10 | 过错证据 | 悔婚的聊天记录、家暴的报警记录与伤情鉴定、疾病诊断与隐瞒证据 |
| 11 | 彩礼用途证据 | 用于共同生活的支出凭证、转化为共同财产的购置凭证 |
| 12 | 嫁妆清单 | 嫁妆的购买凭证与清单（用于独立处理，不参与抵扣） |

**最要命的一环**：彩礼纠纷败诉最常见的原因不是金额算错，而是**证明不了这笔钱是彩礼**。给付现金又无任何名目证据的，主张极难成立。因此：
- 给付时**务必转账**并备注"彩礼"；
- 现金给付的，应在聊天中确认金额与名目，或制作礼单双方签字；
- 事后沟通时引导对方承认收到的是彩礼并录音或保留聊天记录。

## 第 2 节 诉讼主体

| 角色 | 列谁 |
|---|---|
| 原告 | **实际给付人**：给付方本人；彩礼由父母出资的，父母也可作为共同原告或单独主张 |
| 被告 | **实际收受人**：女方本人；彩礼实际由其父母收取的，应将其父母一并列为被告 |

**要点**：列错主体会导致执行困难（赢了判决拿不到钱）。应通过转账流水确认**收款账户户名**，据此确定被告。

## 第 3 节 时效

- 一般为 **三年**，自知道或者应当知道权利受到损害以及义务人之日起算（以现行规定为准）。
- 未办理结婚登记的：一般自**婚约解除/分手**时起算。
- 已办理结婚登记的：一般自**离婚**时起算。
- 久拖不决的，应通过**书面催告、调解申请、起诉**等方式主张权利并留痕。

## 第 4 节 处理路径

| 顺序 | 路径 | 适用 | 要点 |
|---|---|---|---|
| 1 | 自行协商 | 金额小、关系尚可 | 达成书面协议，写明金额、期限与"了结"范围 |
| 2 | 人民调解（人民调解委员会） | 大多数纠纷 | 免费；调解协议可依法申请**司法确认**，确认后有强制执行力 |
| 3 | 村委会/居委会、家族长辈调解 | 农村地区常见 | 可形成书面协议，但执行力有限 |
| 4 | 诉讼（婚约财产纠纷/离婚后财产纠纷） | 协商不成 | 需准备起诉状、证据清单、主体材料 |
| 5 | 财产保全 | 有转移财产迹象 | 由当事人或律师依法申请 |

**调解协议要点**：
- 写明返还金额、支付方式与期限；
- 写明是否"一次性了结"；
- 约定逾期违约责任；
- **申请司法确认**，否则一方反悔需另行起诉。

## 第 5 节 起诉材料清单

1. 起诉状（写明诉讼请求：请求返还彩礼 ×× 元）；
2. 原告身份证明；
3. 被告身份信息（姓名、住址、联系方式，必要时调取户籍信息）；
4. 证据清单与证据材料（按第 1 节清单整理，编号装订）；
5. 结婚证/离婚证或婚姻登记查询结果；
6. 委托律师的，授权委托书。

## 第 6 节 常见误判对照表（否定词防误伤）

| 文本/情形 | 不要判成 | 正确判法 |
|---|---|---|
| 未登记 | 必然全额返还 | 情形成立 ≠ 全额，比例仍受多因素影响 |
| 已登记并共同生活 | 一定能要回一部分 | 除生活困难情形外**一般不予支持**，走共同财产分割 |
| 给付后生活水平下降 | 构成生活困难 | 需达到无法维持当地基本生活水平的高标准 |
| 嫁妆 | 抵扣彩礼 | 独立处理 |
| 恋爱期间转账 | 全部算彩礼 | 一般赠与剔除 |
| 三金 | 一刀切认定 | 依给付时间与目的判断 |
| 已用于共同生活 | 仍可全额主张 | 应从基数中扣除 |
| 已转化为共同财产 | 彩礼中再算一次 | 重复计算，走共同财产分割 |
| 只告女方本人 | 主体适格 | 应列**实际收受人** |
| 收受方悔婚 | 必然多退 | 结合过错程度综合判断 |
| 已过三年 | 绝对不能主张 | 需看**起算点**（分手/离婚时），并以现行规定为准 |
| 未共同生活但已登记且未离婚 | 情形二成立 | **以离婚为条件**，未离婚不成立 |

## 第 7 节 协商函要点（可直接套用）

```
关于返还彩礼的协商函

致：________
双方于 ____年__月__日 订婚，本人（及家人）按习俗给付彩礼共计 ____ 元
（其中现金 ____ 元、三金 ____ 元，附转账凭证与礼单）。

事实：
□ 双方未办理结婚登记，婚约已解除
□ 双方已登记但确未共同生活，现已离婚
□ 给付彩礼导致本人生活困难，现已离婚
共同生活时长：____ 个月；是否生育子女：____

依据与核算：
1. 核定彩礼总额 ____ 元（已剔除一般赠与与婚礼开销）
2. 扣除已用于共同生活部分 ____ 元
3. 可返还基数 ____ 元
4. 参考返还比例 ____% ~ ____%
5. 建议返还金额 ____ 元 ~ ____ 元

请求：于收到本函之日起 __ 日内返还彩礼 ____ 元，或就返还事宜进行协商。
逾期未回复的，本人将通过人民调解委员会调解并依法提起诉讼。

联系人：________  电话：________  日期：____
```

**留痕**：EMS 邮寄保留寄单与签收记录；微信发送保留完整对话；当面提交索取回执。
