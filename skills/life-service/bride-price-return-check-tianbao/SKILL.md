# 彩礼返还情形与比例核算

彩礼纠纷有个顺序不能乱：**先定范围（哪些钱算彩礼）→ 再定门槛（三种法定情形成不成立）→ 最后定比例（多少）**。跳过前两步直接谈比例，主张往往一头扎空。而且彩礼返还从来不是"全退"或"不退"的二选一，是**一个区间**。

## 一、硬边界（能做 / 不能做）

| 能做 | 不能做 |
|---|---|
| 按习俗与给付目的界定彩礼范围 | 把恋爱期间所有转账都算成彩礼 |
| 核对三种法定返还情形的成立条件 | 断言"未登记就必须全额返还" |
| 按共同生活时长、子女、过错、用途给出比例区间 | 给出"必然判多少"的确定结论 |
| 提示嫁妆、共同财产与彩礼不得重复计算 | 用嫁妆直接抵扣彩礼 |
| 梳理举证要点与诉讼主体 | 认定"借婚姻索取财物"（需证据与司法认定） |
| 输出协商与起诉的路径与材料 | 承诺返还结果 |

**必须转交专业人士的情形：**
- 涉及金额大、财产类型复杂（房产、车辆、股权）的——委托婚姻家事律师。
- 已起诉或需要申请财产保全的——由律师办理。
- 涉及子女抚养、共同财产分割与彩礼交织的——需整体方案，非单一计算能解决。

## 二、什么时候用

| 用户说法 | 用不用 | 说明 |
|---|---|---|
| 彩礼能退多少 | 用 | 先定范围，再定门槛，最后算比例 |
| 没领证，彩礼要得回来吗 | 用 | 属三种情形之一，走门槛判定 |
| 领了证但没共同生活 | 用 | 需**以离婚为条件**，门槛判定 |
| 三金/五金算彩礼吗 | 用 | 走彩礼范围界定 |
| 嫁妆能抵彩礼吗 | 用 | 走范围与重复计算核查 |
| 给了彩礼家里很困难 | 用 | 走"生活困难"标准核查（门槛很高） |
| 恋爱时转的钱能要回来吗 | 用 | 走一般性赠与 vs 彩礼的区分 |
| 对方悔婚，能多要吗 | 用 | 走过错调增调减 |

## 三、完整工作流

### 步骤 1：界定彩礼范围（先把"盘子"定下来）

**属于彩礼**（以结婚为目的、按当地习俗给付的大额财物）：
- 订婚/彩礼现金（含转账，备注或聊天中明确为彩礼）
- 三金、五金等金银首饰（多数认定为彩礼性质，但存在个案争议）
- 为结婚给付的大额购车款、购房款或首付
- 按习俗给付的大额"聘礼""礼金"

**不属于彩礼 / 另行处理**：
- 恋爱期间的**一般性赠与**：节日红包、生日礼物、日常消费、小额转账
- **见面礼、改口费**：依当地习俗与金额个案判断，往往争议较大
- **婚礼开销**（酒席、婚庆、婚车）：一般由举办方自行承担，除非有明确约定由对方承担
- **嫁妆/陪嫁**：属于女方财产或对家庭的投入，**不能用来抵扣彩礼**；已转化为共同财产的按共同财产分割处理
- **已共同消费的部分**：不返还

**这一步最关键**：把恋爱期间的普通转账都算进彩礼，主张会被大幅剔除，还会削弱整体可信度。

### 步骤 2：核对三种法定情形（门槛）

| 情形 | 条件 | 附加条件 |
|---|---|---|
| 一、双方**未办理**结婚登记手续 | 未登记 | 无 |
| 二、**已登记**但**确未共同生活** | 登记 + 未共同生活 | **以双方离婚为条件** |
| 三、婚前给付并导致给付人**生活困难** | 生活困难达到法定标准 | **以双方离婚为条件** |

**三种情形之外**，已登记且已共同生活的，彩礼返还一般**不予支持**；此时应转向**夫妻共同财产分割**路径，而不是彩礼返还。

**"生活困难"是高标准**：指依靠个人财产和离婚时分得的财产**无法维持当地基本生活水平**，不是"给完彩礼手头紧"。以现行司法解释为准。

### 步骤 3：按比例因素调整（给出区间）
见第四节与脚本。

### 步骤 4：核查重复计算（易错点）

| 项目 | 处理 |
|---|---|
| 已用于共同生活的部分 | 从彩礼总额中扣除，不返还 |
| 已转化为夫妻共同财产的部分 | 按共同财产分割，**不在彩礼返还中重复计算** |
| 嫁妆 | 独立处理，不抵扣彩礼 |
| 婚礼开销 | 一般不计入，除非有约定 |

### 步骤 5：确定诉讼主体与时效
- **主体**：给付方（本人或实际给付的家庭成员）为原告；实际收受方（女方本人或其父母/家庭）为被告。**谁实际收的钱，就列谁**。
- **时效**：一般为**三年**，自知道或应当知道权利受到损害以及义务人之日起算（未登记的，一般自分手/婚约解除时起算；已登记的，一般自离婚时起算），以现行规定为准。

### 步骤 6：举证与路径
见 `rules/02-举证与诉讼路径.md`。

## 四、核心规则（核算前必读）

**先读这两个文件，不要凭印象算：**
- `rules/01-彩礼范围与返还比例核算.md` —— 范围界定表、三种情形门槛、比例梯度表、调增调减因素、重复计算核查、生活困难标准。
- `rules/02-举证与诉讼路径.md` —— 举证清单、礼单与聊天记录的固化、诉讼主体、时效、协商与起诉路径、误判对照表。

**比例核算骨架：**

```
可返还基数 = 核定彩礼总额 − 已用于共同生活的部分 − 已转化为共同财产的部分

基准比例（按共同生活时长）：
  未共同生活        80% ~ 100%
  不满 3 个月       70% ~ 90%
  3 个月 ~ 1 年     50% ~ 70%
  1 年 ~ 2 年       30% ~ 50%
  2 年以上           0% ~ 30%

调整项：
  − 已办理结婚登记            下调
  − 已生育子女                大幅下调
  − 给付方存在重大过错        下调
  + 收受方存在重大过错        上调
  + 构成生活困难              上调

返还区间 = 可返还基数 × [调整后下限比例 , 调整后上限比例]
```

## 五、脚本用法

脚本：`scripts/bride_price_calc.py`（Python 3 标准库）

```bash
python scripts/bride_price_calc.py --file 彩礼.json
python scripts/bride_price_calc.py --file 彩礼.json --json
python scripts/bride_price_calc.py --selftest
```

| 字段 | 说明 |
|---|---|
| `total` | 经核定的彩礼性质总额（元），**只填属于彩礼的部分** |
| `registered` | 是否已办理结婚登记（true/false） |
| `cohabitation_months` | 共同生活月数（未共同生活填 0） |
| `has_child` | 是否生育子女（true/false） |
| `used_for_common` | 已用于共同生活或已转化为共同财产的部分（元） |
| `payer_fault` | 给付方过错等级：0 无 / 1 一般 / 2 重大 |
| `receiver_fault` | 收受方过错等级：0 无 / 1 一般 / 2 重大 |
| `payer_hardship` | 给付方是否构成生活困难（true/false） |
| `divorce` | 是否已离婚或解除婚姻关系（登记情形下必填） |

输出：情形门槛是否成立、可返还基数、基准比例区间、各项调整、返还金额区间。

## 六、人工确认清单（不能省）

- [ ] 彩礼总额已按**性质**拆分（彩礼 vs 一般赠与 vs 婚礼开销），不是把所有转账加总？
- [ ] 三金/五金的**购买凭证与交付证据**已固定？
- [ ] 是否办理结婚登记已确认（以登记机关记录为准）？
- [ ] 共同生活时长有可佐证的材料（共同居住证明、水电、邻居证言）？
- [ ] 已用于共同生活的部分已**从基数中扣除**，没有重复主张？
- [ ] 嫁妆是**独立处理**的，没有用来抵扣彩礼？
- [ ] 生活困难是否达到法定标准已有证据（收入、负债、当地生活水平）？
- [ ] 已登记的情形是否已**离婚**（门槛条件）？
- [ ] 诉讼主体是**实际给付人**与**实际收受人**？
- [ ] 诉讼时效未经过（一般三年）？

## 七、最常见的坑

1. **把恋爱期间全部转账算成彩礼**。节日红包、日常消费属一般赠与，会被剔除，还会让整体主张失去可信度。
2. **未登记就主张全额返还**。未登记只是**情形成立**，比例仍受共同生活时长、子女、过错影响，长期共同生活的通常不支持全额。
3. **已登记但未共同生活，不离婚就单独起诉彩礼**。该情形**以离婚为条件**，未提出离婚的，主张难以成立。
4. **把"手头紧"当"生活困难"**。生活困难是高标准，指依靠个人财产和离婚分得财产无法维持当地基本生活水平。
5. **用嫁妆抵扣彩礼**。嫁妆是另一笔财产关系，应独立处理，直接抵扣会在法庭上被否定。
6. **已转化为共同财产的部分重复计算**。这部分应走共同财产分割，在彩礼返还中再算一次属重复主张。
7. **忽略过错的双向性**。只算对方过错不算自己过错，比例预期会严重偏高；给付方存在家暴、出轨、悔婚等情形的同样会下调。
8. **超时效**。一般为三年，久拖不决应及时书面主张并留痕。
9. **诉讼主体写错**。实际收受人往往是女方父母，只列女方本人可能执行不到。
10. **三金性质一刀切**。三金多数认定为彩礼性质，但如果明确是恋爱赠与则另论，需结合给付时间与目的判断。
11. **把"借婚姻索取财物"挂在嘴边**。这是需要证据支撑的特定事实，不是主张返还的必要条件，滥用会削弱主张。

## 八、边界与免责

本技能输出的是**范围界定方法、情形门槛与比例区间估算**，不是司法裁判结论。彩礼是否返还、返还多少，由人民法院结合当地习俗、共同生活情况、过错与财产状况综合确定；各地法院对比例的具体掌握存在差异。涉及金额大、财产类型复杂或已进入诉讼的，请委托婚姻家事律师。法律依据以现行法律和司法解释为准。
