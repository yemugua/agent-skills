# 雅思写作四项评分标准分档对照表

> 本表是官方公开评分标准（band descriptors）的**整理与简化表述**，用于自查定位。完整口径以官方发布版本为准。
> 四项标准各占 25%，四项平均后取到最近的 0.5 档，即写作单项报道分。

---

## 一、任务类型与硬指标

| 项目 | Task 1 | Task 2 |
|---|---|---|
| 建议用时 | 20 分钟 | 40 分钟 |
| 字数下限 | 150 词 | 250 词 |
| 建议区间 | 170~190 词 | 270~300 词 |
| 分数权重 | 约 1/3 | 约 2/3 |
| 核心看点（TR/TA） | A 类：选全数据、写准特征；G 类：覆盖三要点、语气得体 | 立场明确、论证充分、结论呼应 |

**字数与档位的关系**：低于字数下限会被限制档位上限；超过建议区间不额外加分，且会增加错误暴露面。

---

## 二、TR / TA（任务回应与任务完成度）

| 档 | 表现描述 |
|---|---|
| 9 | 全面充分回应所有要求；立场清晰且贯穿全文；论证深入，例证贴切充分 |
| 8 | 充分回应所有要求；立场一贯；论证展开充分，例证相关但可能略有不平衡 |
| 7 | 回应了所有要求；立场清晰；主要论点有展开与支持，结论可能略显突兀或重复 |
| 6 | 回应了各项要求但部分展开不足；立场可辨但结论不清；例证相关但不充分 |
| 5 | 只回应了部分要求；立场发展不清；例证有限或与题目关系弱 |
| 4 | 尝试回应但内容与题目关联弱；格式可能不对；几乎没有立场 |
| ≤3 | 字数严重不足、内容基本无关或完全跑题 |

**Task1 的 TA 具体看三点**：① 有没有写总趋势 / 总特征（overview）；② 有没有挑出关键数据并对比；③ 有没有漏掉主要对象。缺 overview 是 Task1 最常见的失分点。

**Task2 的 TR 具体看三点**：① 立场句写没写；② 每个主体段的论点有没有展开到"为什么"；③ 结论有没有回到立场。

---

## 三、CC（连贯与衔接）

| 档 | 表现描述 |
|---|---|
| 9 | 衔接极自然，几乎不显痕迹；分段完全合理；指代与替代手段用得充分 |
| 8 | 逻辑推进顺畅；分段恰当；衔接手段多样且用得准 |
| 7 | 有清晰的总体推进；分段合理但可能略机械；衔接词有时用得过多或不够准 |
| 6 | 总体上能看懂；分段有逻辑但不一贯；衔接手段有限或生硬 |
| 5 | 组织松散，缺乏推进；分段混乱或缺失；衔接手段少且重复使用 |
| 4 | 基本没有逻辑组织；看不到分段意图 |

**CC 的三条可执行判定**：
1. 一个段落是否只讲一个中心（出现两个中心就该分段）
2. 段落之间是否用"关键词复现"或"代词指代"承接，而不是只靠衔接词
3. 每段衔接词不超过 2 个（超过就判为堆砌）

---

## 四、LR（词汇资源）

| 档 | 表现描述 |
|---|---|
| 9 | 用词精准、地道、多样；搭配完全自然；偶有拼写失误纯属笔误 |
| 8 | 词汇量大且用得灵活；能用不太常见的词；搭配偶尔不自然；拼写偶有错 |
| 7 | 词汇足够灵活，能表达准确意义；能使用一些低频词；偶尔搭配不当或拼写错 |
| 6 | 词汇量够完成写作任务；尝试用不熟悉的词但不准；搭配错误不影响理解 |
| 5 | 词汇有限；重复严重；拼写与构词错误明显，读者需要费力理解 |
| 4 | 只掌握基础词汇；错误频繁，严重影响理解 |

**LR 的三条可执行判定**：
1. 同一个核心词（如 important / good / people）在全文出现超过 4 次 → 判重复
2. 是否为"更难的替换词"牺牲了准确性 → 判为硬套，反而降档
3. 拼写错误按"错误数量"计入，不按"是否影响理解"

---

## 五、GRA（语法多样性与准确性）

| 档 | 表现描述 |
|---|---|
| 9 | 句型极其多样且完全准确；标点完全正确；几乎没有错误 |
| 8 | 句型多样；多数句子无误；标点基本正确，偶有失误 |
| 7 | 句型有变化且复杂度不错；多数句子无错；部分复杂句有错但不影响理解 |
| 6 | 简单句与复杂句混用但灵活性有限；复杂句错误较多但意思仍可懂 |
| 5 | 句型单一，多为简单句；错误频繁，读者需要猜测意思 |
| 4 | 只会用极少数句型；错误极多，几乎难以理解 |

**GRA 的三条可执行判定**：
1. 全文是否出现至少 3 种从句（定语、状语、名词性从句）
2. 主谓一致、单复数、冠词、时态是否每 3 句就有 1 处错
3. 一句话里从句超过两个 → 判定为"过度堆砌"，不认为加分

---

## 六、总分折算口径

写作单项 = (TR + CC + LR + GRA) / 4，取到最近的 0.5 档：

- 平均 6.25 → 6.5（.25 向上取到相邻半档）
- 平均 6.75 → 7.0
- 平均 7.125 → 7.0（取最近半档）
- 平均 6.0 → 6.0

总分（overall）是听力、阅读、写作、口语四项的算术平均，同样取到最近的 0.5 档。

> 官方由两名受过训练的阅卷员独立评分，差值过大时由第三名复核，实际结果与自评存在偏差，**以官方成绩单为准**。

---

## 七、档位差距的实际含义（用于排提分优先级）

| 从 | 到 | 最该补什么 |
|---|---|---|
| 5.0 → 6.0 | | 句子正确性（主谓一致、时态、单复数）+ 覆盖全部题目要求 |
| 6.0 → 6.5 | | 减少重复词 + 每段一个中心 + 结论回到立场 |
| 6.5 → 7.0 | | 论证展开到"为什么" + 衔接手段多样化 + 减少复杂句错误 |
| 7.0 → 8.0 | | 用词精准度与地道搭配 + 论证层次 + 几乎无误的复杂句 |

**关键判断**：四项里最低的那一项决定训练方向；四项都差不多时，先冲 LR 与 CC（这两项在短期内最容易被训练抬升）。
