# 田口方法（taguchi-method）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据田口质量工程学，生成田口方法应用清单：信噪比（SN比）评价、参数设计、正交表试验、稳健性优化、质量损失函数。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 田口方法
- 参数设计
- 稳健设计
- 信噪比
- 正交试验

## 三、工作流
1. 界定质量特性与噪声因素
2. 构造信号-噪声比（SN比）指标
3. 选用正交表安排参数设计
4. 寻找稳健参数组合（内/外设计）
5. 用质量损失函数量化收益

## 四、核心内容（检查清单与判定）
田口方法通过参数设计使产品/过程对噪声不敏感，以SN比衡量稳健性，并用质量损失函数把波动折算为经济损失，追求低成本下的高稳健。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含信噪比（SN比）评价 | SN比 |
| Q2 | FAIL | 未含参数设计 | 参数设计 |
| Q3 | WARN | 未含正交表试验安排 | 正交 |
| Q4 | FAIL | 未含稳健性优化目标 | 稳健 |
| Q5 | WARN | 未含质量损失函数 | 损失 |

> 脚本 `taguchi-method_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python taguchi-method_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python taguchi-method_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
