# 车险险种选择与理赔影响核查

车险选方案的核心矛盾只有一个：**保费省下来的那几百块，能不能扛住一次事故的自付缺口**。三者险买低档，一年省一两百；真出一次人伤事故，缺口可能是几十万。

这个技能做五件事：**列险种 → 选保额 → 比方案 → 测缺口 → 核理赔**。

---

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 说明各险种的保障范围与常见除外情形 | 推销具体保险公司或具体产品 |
| 对比不同保额档次的保费与保障 | 承诺一定能赔、一定能赔多少 |
| 按给定场景测算自付缺口 | 编造事故损失、伤情或赔偿金额 |
| 提示投保、续保、理赔的材料与流程 | 代替保险公司作核赔认定 |
| 提示保费浮动与出险记录的关联 | 提供骗保、虚构事故、夸大损失的方案 |

涉及以下情形，应停下来交由保险公司、交警部门、律师或公估机构处理：**人伤事故的责任认定与赔偿协商、伤残等级鉴定、诉讼中的赔偿争议、保险公司拒赔或定损争议、涉及酒驾/无证/逃逸等法定免责情形**。

**绝对不做**：不虚构事故、不夸大损失、不提供骗保或故意制造事故的方案。**骗保是刑事犯罪，代价远大于任何保费节省。**

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「车险买哪几种就够了」 | 用，按法定险种与商业主险核 |
| 「三者险买 100 万还是 200 万」 | 用，测缺口并比保费差 |
| 「车损险要不要买」 | 用，按车辆价值与风险核 |
| 「交强险能赔多少」 | 用，按现行责任限额核 |
| 「不计免赔还要单独买吗」 | 用，说明现行条款的并入情况 |
| 「出险一次第二年涨多少」 | 用，说明浮动机制口径 |
| 「附加险哪些值得买」 | 用，按使用场景核 |
| 「怎么把定损做高一点」 | 不用，拒绝提供夸大损失方案 |

## 三、完整工作流

```
第 1 步  确认车辆与使用情况：车型、车龄、实际价值、年行驶里程、主要使用人、停放环境
第 2 步  读规则文件 rules/auto-insurance-rules.md（险种、限额、除外责任、附加险、理赔流程）
第 3 步  定法定险：交强险为强制投保，核责任限额与赔付顺序
第 4 步  定商业主险：三者险保额档次、车损险、车上人员责任险
第 5 步  核附加险：按使用场景取舍，不为「全险」幻觉买单
第 6 步  跑脚本对比：scripts/auto_insurance_compare.py --file plans.json
第 7 步  测自付缺口：按人伤、车损、全责致人死亡等场景分别测算
第 8 步  看性价比：每万元保额的保费成本，判断加保是否划算
第 9 步  核条款：保险责任、责任免除、免赔额/免赔率、赔偿限额与特别约定
第 10 步 理赔与复核：报案时效、现场与证据、定损与维修、赔款核对
```

## 四、险种与限额口径

### 4.1 交强险（强制投保）

| 项目 | 口径 |
|---|---|
| 性质 | 法定强制，**未投保不得上路** |
| 赔付结构 | 分死亡伤残、医疗费用、财产损失三项责任限额 |
| 有责限额 | 按现行规定的责任限额执行（**以监管部门公布与保险合同为准**） |
| 无责限额 | 按现行规定执行，额度显著低于有责限额 |
| 赔付顺序 | 一般先由交强险在限额内赔付，不足部分由商业三者险按责任比例赔付 |

> 交强险的具体责任限额以现行规定为准，**不要凭记忆引用数字**，核查时应查阅监管部门与保险合同载明的最新限额。

### 4.2 商业险主险

| 险种 | 保什么 | 选择要点 |
|---|---|---|
| 机动车第三者责任险 | 对第三方的人身伤亡与财产损失，超出交强险部分按责任比例赔付 | **保额档次是核心决策**，按当地人身损害赔偿水平与自身风险承受能力选 |
| 机动车损失保险 | 被保险车辆本身的损失 | 现行条款已整合多项原附加责任（如盗抢、玻璃单独破碎、自燃、发动机涉水等），**以保险合同条款为准** |
| 车上人员责任险 | 司机与乘客的人身伤亡 | 按核定载客数与每人保额选择 |

### 4.3 附加险（按场景取舍）

| 附加险 | 适用场景 |
|---|---|
| 医保外医疗费用责任险 | 人伤事故中第三方自费药与医保外费用 |
| 车身划痕损失险 | 新车、无固定车位、停放环境复杂 |
| 修理期间费用补偿险 | 修车期间依赖替代交通工具 |
| 车上货物责任险 | 营运或经常载货 |
| 法定节假日限额翻倍险 | 节假日长途出行多 |
| 精神损害抚慰金责任险 | 涉及人伤的赔偿争议 |

**不要为「全险」三个字买单**：附加险的价值取决于你的实际使用场景，与销售话术无关。

## 五、金额测算口径

### 5.1 自付缺口公式

```
自付缺口 = max(0, 事故损失金额 − 交强险对应限额 − 商业险对应保额)
```

其中商业险赔付还需扣除**免赔额或免赔率**部分，并按事故责任比例计算。

### 5.2 场景测算示例（口径）

| 场景 | 计算 |
|---|---|
| 撞伤他人，医疗费 30 万元 | 自付 = 30 万 − 交强险医疗费用限额 − 三者险赔付部分 |
| 全责致人死亡，赔偿金 X 万元 | 自付 = X − 交强险死亡伤残限额 − 三者险保额 |
| 本车全损 | 赔付按保险金额与保险价值的关系及条款约定处理，扣除残值与免赔 |

**赔偿金 X 不是拍脑袋的数**：人身损害赔偿涉及医疗费、误工费、护理费、残疾赔偿金、死亡赔偿金、被扶养人生活费、精神损害抚慰金等多项，按受诉法院所在地相关标准计算，**以法律规定与实际核定为准**。

### 5.3 性价比口径

```
每万元保额的保费成本 = 该险种保费 ÷ 保额（万元）
加保增量成本 = 高档方案保费 − 低档方案保费
加保增量保额 = 高档保额 − 低档保额
```

**判断方法**：如果多花很少的钱就能把保额翻倍，通常值得加；如果增量成本接近增量保额对应的风险溢价，按自身风险承受能力决定。

### 5.4 保费浮动口径

- 保费与**出险记录、交通违法记录、车型、使用性质、地区、自主定价系数**等因素相关
- 出险次数会影响无赔款优待系数，进而影响续保保费
- 小额损失是否报案，应权衡**维修成本与次年保费上浮**后决定

**以保险公司实际报价与合同约定为准。**

给建议或下结论前，**必须先读**：

- `rules/auto-insurance-rules.md`：险种与限额、常见责任免除、附加险取舍、投保与续保材料、理赔流程与时效、定损与维修、争议处理与代位求偿。

## 七、脚本用法

```bash
python scripts/auto_insurance_compare.py --file plans.json --out 车险方案对比.md
python scripts/auto_insurance_compare.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：方案列表（名称、保费、三者保额、是否含车损、车上人员保额等）+ 场景损失设定 |
| `--text` | 直接给 JSON 字符串 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检 |

输入 JSON 示例：

```json
{
  "ctp_limits": {"death_disability": 180000, "medical": 18000, "property": 2000},
  "scenarios": [
    {"name": "人伤医疗费", "type": "medical", "loss": 300000},
    {"name": "全责致死赔偿", "type": "death", "loss": 1500000}
  ],
  "plans": [
    {"name": "基础方案", "premium": 3200, "third_party": 1000000,
     "has_damage": true, "driver": 10000, "passenger": 10000},
    {"name": "加保方案", "premium": 3550, "third_party": 3000000,
     "has_damage": true, "driver": 50000, "passenger": 50000}
  ]
}
```

脚本输出：各方案保费、三者的每万元保额保费成本、各场景下的自付缺口、加保增量成本与增量保额、缺口提醒与「以合同条款为准」的标注。

> 脚本按你填的参数做静态测算，**未含免赔率、责任比例、免赔额、绝对免赔、特别约定与保险公司的实际核赔**；责任限额与保障范围以保险合同条款与监管部门公布口径为准。

## 八、人工确认清单（这步不能省）

- [ ] 交强险责任限额查阅的是**现行**规定，不是几年前的记忆
- [ ] 三者险保额按当地人身损害赔偿水平与自身承受能力选择，不是按保费最低
- [ ] 已逐条阅读**保险责任**与**责任免除**，特别是酒驾、无证、逃逸、改装、营运等情形
- [ ] 免赔额/免赔率、绝对免赔与特别约定已确认
- [ ] 附加险按实际使用场景取舍，没有为「全险」名头买单
- [ ] 车辆实际价值与车损险保险金额的关系已核（避免超额投保或不足额投保）
- [ ] 使用性质（家用/营运）申报准确，营运车辆按家用投保会直接影响理赔
- [ ] 报案时效、现场证据、定损与维修流程已了解
- [ ] 续保前已核对出险记录与无赔款优待系数

## 九、最常见的坑

1. **三者险只买 50 万或 100 万。** 一线城市一起全责人伤事故的赔偿金额可能远超这个数，超出部分自付。**加保 100 万保额通常只多花一两百元，是车险里性价比最高的一笔钱。**
2. **以为买了「全险」就什么都赔。** 没有任何保险什么都赔。酒驾、无证驾驶、肇事逃逸、车辆未按规定年检、改变使用性质从事营运等，都属于常见责任免除情形。
3. **交强险限额凭记忆。** 责任限额会调整，核查时必须查阅监管部门与保险合同载明的现行限额，凭几年前的记忆报数是典型错误。
4. **小额事故一律报案。** 一次出险可能影响次年保费，维修费用低于保费上浮幅度时，自行处理可能更划算。**先算后报。**
5. **车辆使用性质申报不实。** 家用车从事网约车等营运活动的，出险时可能被拒赔。**这一条代价极高。**
6. **不看免赔额与绝对免赔。** 保单上的免赔额、免赔率、绝对免赔与特别约定，直接决定实际到手赔款，不看等于白买。
7. **定损前自行修车。** 未经定损自行维修，可能导致部分损失无法核定。正确做法是先报案、先定损、再维修，并保留现场照片与维修清单。
8. **忽略医保外费用。** 人伤事故中的自费药与医保外医疗费用，可能不在基础赔付范围内，需确认是否已投保医保外医疗费用责任险。
9. **车损险按新车价投保多年不变。** 车辆实际价值逐年下降，长期按原值投保属于超额投保，多交的保费不对应更多赔付。
10. **退保与犹豫期混淆。** 车险通常为一年期短期险，**一般不适用长期人身保险的犹豫期规则**；退保按合同约定的未满期保费与手续费口径处理。**犹豫期天数以合同约定为准，退保损失以合同约定与未满期保费口径为准**，不要想当然。

## 十、边界与免责

- 本技能用于投保前方案对比与条款核查，**不构成保险代理、经纪或法律意见**，不替代保险合同的约定与保险公司的核赔
- 责任限额、保障范围、责任免除、免赔与特别约定，**均以保险合同条款与监管部门公布口径为准**
- 本测算为**静态口径**，未含免赔率、责任比例、绝对免赔、特别约定与实际核赔结果
- **不推销具体保险公司或产品，不承诺一定能赔、一定能赔多少**
- 人身损害赔偿涉及具体法律标准与个案事实，**以法律规定与实际核定为准**；争议应及时咨询律师
- **犹豫期天数以合同约定为准；退保损失以合同约定与未满期保费口径为准**，不劝诱退保
- 不提供骗保、虚构事故、夸大损失的任何方案
