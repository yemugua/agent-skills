# 犬猫绝育手术前后核查（pet-neuter-surgery-check）

绝育是**最典型的"该做但要挑时候做"的手术**。挑错时机（体重不够、发情刚结束、正在生病）会明显抬高风险；术后护理不到位（过早活动、舔伤口、吃错东西）也会把好手术做成并发症。

这个技能做三件事：**术前核 → 择时机 → 术后盯**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出术前检查项清单与核实口径 | ❌ 代替兽医面诊做手术适宜性判断 |
| 给出年龄体重窗口与时机的参考口径 | ❌ 判断具体某只动物能否承受麻醉 |
| 给出术后日程表与护理口径 | ❌ 推荐任何药物名称、剂量与用法 |
| 列出并发症识别信号与就医红线 | ❌ 承诺并发症发生率与手术风险大小 |
| 给出就诊前的问题清单与记录要求 | ❌ 给出替代手术的其他方案建议 |

**就医红线（出现任一条，尽快联系兽医；标注急诊的直接去急诊）**

- **术后出血不止**：切口渗血持续超过 20 分钟未减少、纱布浸透、血滴在地板上持续滴落
- **切口裂开**：切口边缘分开、可见皮下组织、腹腔内容物外露迹象
- **持续呕吐无法进水**：术后 12 小时以上反复呕吐、拒水
- **公猫术后 24-48 小时内排不出尿**（龟头长时间露在包皮外、频繁进猫砂盆却尿不出）——**尿闭是急症**
- **母猫术后持续大量阴道分泌物、有臭味或发热**
- **精神沉郁、持续不吃不喝超过 24 小时**（幼宠尤其危险）
- **腹胀明显、触碰腹部疼痛反应剧烈**
- **伤口红肿热痛、有脓性分泌物、结痂处崩开**
- **术后超过 48 小时体温明显升高或明显偏低**
- **怀疑麻醉并发症：持续呕吐、抽搐、呼吸急促、牙龈发白或发绀**
- **体重低于品种成熟体重的一定比例、年龄过小或过老**——须由兽医评估
- **有心脏病、肾病、糖尿病、激素相关疾病或长期用药史**

## 二、完整工作流

```
第 1 步  排就医红线：先排完红线，再谈手术安排
第 2 步  核实术前检查项：按清单逐项确认已完成并拿到结果
第 3 步  确认年龄与体重窗口：品种体型差异大，以兽医评估为准
第 4 步  选时机：避开发情期与换毛高压力期，选宠物状态稳定的时间
第 5 步  术前准备：禁食禁水时长按医嘱执行，不自行延长或缩短
第 6 步  术后按日程表盯：体温、饮食、活动、切口、饮水与排尿
第 7 步  拆线与复查：按医嘱时间，不自行拆
第 8 步  长期管理：体重监测与行为观察记录
```

**顺序不能颠倒**：不确认术前检查结果就定手术日，是最常见的返工原因。

## 三、术前检查项清单

**是否做过、结果是否拿到，以就诊机构实际安排为准。以下为常见项目与核对口径。**

| 检查项 | 核对什么 | 异常时的意义 |
|---|---|---|
| 体温 | 是否在正常范围 | 发热提示可能存在感染，需先处理 |
| 心肺听诊 | 有无杂音、心率是否异常 | 心肺异常会显著改变麻醉风险 |
| 血常规 | 白细胞、红细胞、血小板 | 贫血影响耐受，感染或炎症需先处理 |
| 生化（肝肾） | 肝肾功能指标 | 肝肾功能异常需调整麻醉方案 |
| 凝血功能 | 出血风险 | 部分机构会做，尤其是深部手术 |
| 传染病筛查 | 按机构规定项目 | 阳性需先处理或改变方案 |
| 体重与体况评分 | 体重与脂肪覆盖 | **过瘦风险高，过胖增加麻醉与伤口愈合风险** |
| 皮肤与毛发状况 | 是否有皮肤病、剃毛区域 | 感染区域避开切口 |
| 疫苗与驱虫状态 | 是否处于有效期 | 未完成免疫需与医生确认时序 |
| 既往病史 | 慢性病、长期用药、过敏史 | **如实告知，不隐瞒** |
| 发情与妊娠状态 | 母犬母猫是否处于发情期或妊娠 | 直接影响时机与方案 |

**两条硬要求**：

1. **既往病史必须如实告知**，包括正在吃的所有药与保健品。隐瞒会直接影响麻醉方案选择。
2. **检查结果要拿到手**，不能只听一句"看着还行"。术后出问题回看，往往就是术前某项没查或没看结果。

## 四、年龄与体重窗口

| 情况 | 参考口径 | 说明 |
|---|---|---|
| 幼宠过小 | 一般不建议在很小的月龄做 | 过小会影响发育，具体月龄**由兽医按品种评估** |
| 成年但体型偏小 | 需达到品种成熟体重的相当比例 | **大型犬与小型犬差异极大**，不能套同一标准 |
| 成年犬 | 已达成年、发育基本完成 | 通常时机更从容 |
| 成年猫 | 已达成年、体重稳定 | 需控制体重，肥胖猫麻醉风险明显更高 |
| 高龄 | 需评估肝肾功能与心肺状态 | 高龄可做但风险评估更严格，**由兽医决定** |
| 超重 | 建议先减重再评估 | 肥胖会显著增加麻醉与伤口愈合风险 |

**关键原则**：**不要按"几个月"这种统一标准**，要按**品种体型 + 发育状态 + 体重**三项一起评估。这三项的组合差异极大，**最终由兽医面诊判断**。

**公母差异**：

- 母犬母猫绝育需考虑发情期状态与是否可能妊娠
- 公犬公猫绝育主要考虑年龄、体力与前列腺相关状况
- **老年未绝育个体绝育的收益与风险需要单独评估**，不适用年轻个体的标准

## 五、时机选择

| 避开 | 原因 |
|---|---|
| 母猫母犬发情期 | 子宫与血管充血明显，出血风险上升 |
| 刚发情结束不久 | 生殖系统仍处活跃状态，需由兽医判断具体间隔 |
| 正在生病、腹泻、呕吐 | 麻醉耐受与恢复能力下降 |
| 刚换环境、刚搬家 | 应激状态下恢复更慢 |
| 体重不稳定、快速增减 | 补液与用药量难以准确计算 |
| 毛发极长且难打理（如长毛猫打结严重） | 术后护理困难，影响伤口观察 |

**相对合适的时间窗口（通用口径）**：

| 项目 | 口径 |
|---|---|
| 状态 | 宠物整体健康、体重稳定、精神与食欲正常 |
| 季节 | 避开极端高温与严寒，减少术后并发症 |
| 与其他事件错开 | 不要与搬家、换笼、长途出行、疫苗接种同时安排 |
| 发情结束后的间隔 | **具体间隔由兽医按品种与个体判断**，本技能不给固定天数 |
| 安排缓冲 | 手术日选在能连续观察 3-5 天的时段 |

**为什么不能给固定天数**：发情结束后的间隔需求在不同品种、不同个体之间差异很大，**固定天数容易误导**。正确做法是**问医生，记下医生给的具体日期**。

## 六、术后日程表

| 时间 | 关注点 | 口径 |
|---|---|---|
| 术后当天 | 体温、精神、饮水、切口 | 未清醒属正常；**清醒后不喝水超过 12 小时需联系医生** |
| 术后 1-2 天 | 进食、排尿、呕吐 | **排不出尿是急症**；呕吐反复需联系医生 |
| 术后 3-5 天 | 切口有无红肿渗液、精神、食量 | 出现脓性分泌物需就诊 |
| 术后 7 天 | 拆线或复查 | **按医嘱时间，不自行拆线** |
| 术后 10-14 天 | 拆线后切口状况、活动恢复 | 切口完全愈合前限制剧烈活动 |
| 术后 1-2 周 | 活动量逐级恢复 | 逐步增加，不一步到位 |
| 术后 1 个月 | 体重监测 | **体重增长是绝育后常见问题**，需调整饮食 |
| 长期 | 行为与泌尿状况观察 | 记录变化，供下次就诊参考 |

**饮食口径**：

| 项目 | 口径 |
|---|---|
| 禁食禁水时长 | **按医嘱执行**，不自行延长也不自行缩短 |
| 术后早期 | 部分兽医会建议一段时间内流质或软食，**按医嘱** |
| 恢复后 | 转回日常食物，逐步过渡 |
| 体重管理 | **绝育后代谢率下降，需按月监测体重并相应调整喂食量** |
| 加餐 | 绝育后不因"补偿心理"额外加餐 |

**活动限制**：

| 项目 | 口径 |
|---|---|
| 猫 | 术后限制跳跃攀爬，**尤其母猫**；限制进入高处 |
| 狗 | 限制奔跑、跳跃、上下沙发与楼梯 |
| 时长 | 切口完全愈合前（**按医嘱**） |
| 牵引 | 外出全程牵引，避免突然冲脱 |
| 逐步恢复 | 每天小幅度增加，1-2 周内回到正常 |

**关于伊丽莎白圈**：

| 情况 | 口径 |
|---|---|
| 需要佩戴 | 舔咬切口风险高的个体，或医生明确要求 |
| 进食影响 | 佩戴期间可能出现拒食或吃不下，**若完全不进食需及时联系医生** |
| 替代方案 | 部分情况可用合适的局部遮挡替代，**须经医生同意** |
| 佩戴时长 | 按医嘱，愈合前不取 |

## 七、并发症识别

| 并发症 | 识别信号 | 处置 |
|---|---|---|
| **出血** | 切口持续渗血、纱布浸透、地上持续有血滴、黏膜苍白 | **渗血 20 分钟不减少即为红线**；保持安静、压迫观察，持续不止立即就医 |
| **切口裂开** | 切口边缘分开、可见皮下组织、缝线断裂或崩脱 | **红线，立即就医**；不要自行按压或涂抹 |
| **粘连** | 术后长期腹部或腹股沟出现硬结、牵拉感、局部皮肤凹陷 | 非急症，但**需就诊评估**，可能需要康复处理 |
| **感染** | 切口红肿热痛、脓性分泌物、发热、周围皮肤发烫 | 尽快就医；**不自行涂抹任何药膏** |
| **尿闭**（公猫高发） | 频繁进猫砂盆却尿不出、蹲坐时间异常长、龟头长时间露在包皮外、舔下体频繁 | **急症，立即就医** |
| **呕吐与不进食** | 反复呕吐、拒水、精神沉郁 | 超过 12 小时未改善需联系医生，幼宠更早 |
| **发热** | 体温明显升高、精神差、食欲低 | 联系医生 |
| **出血倾向加重** | 手术部位以外的出血点、牙龈渗血 | 就医排查凝血问题 |
| **麻醉后并发症** | 呼吸急促、持续呕吐、抽搐、牙龈发白或发绀 | **急症** |
| **持续疼痛未缓解** | 术后超过 2-3 天疼痛姿态不减、活动明显受限 | 就医评估疼痛管理方案 |

**粘连是最容易被忽略的**：它不红不肿不化脓，只是摸到腹部有一块硬结或皮肤被"拉住"。**发现牵拉感就应该就诊**，不要以为"过几个月就好了"。

## 八、脚本用法

```
python scripts/neuter_check.py --file case.json
python scripts/neuter_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`species`（dog/cat）、`age_months`、`weight_kg`、`breed_size`（small/medium/large）、`in_heat`、`pregnant`、`preop_done`（检查项清单）、`red_flags`、`postop_symptoms`、`days_after`、`cat_intact` |
| `--json` | 以 JSON 输出 |
| `--out` | 结果写入指定文件，默认 `scripts/_last_result.txt` |
| `--selftest` | 运行自检 |

脚本做四件事：**排就医红线并给出急症标识 → 核实术前检查项完成度并列出缺项 → 按年龄体重给窗口判定并标注须兽医评估 → 按术后天数给日程与并发症排查**。脚本**不给药物名称与剂量，不判断手术适宜性**。

- [ ] 禁食禁水时长按医嘱执行，未自行调整

- [ ] 拆线按医嘱时间，未自行拆线
- [ ] 饮食过渡按医嘱执行，未因"补偿心理"额外加餐

- [ ] 未自行使用任何药物；用药严格遵医嘱

## 十、最常见的坑

**坑一：猫体重不到 1 kg 就急着做。**
错误做法：奶猫看着好养，几个月就带去绝育。正确做法：**体重与发育状态要同时评估**，过小会影响发育。**不能按"几个月"的统一标准**，大型犬与小型犬差异极大，最终由兽医面诊判断。

**坑二：发情刚结束就安排。**
错误做法：发情结束第二天就预约。正确做法：**生殖系统在发情结束后仍处活跃状态**，具体间隔由兽医按品种与个体判断。本技能不给固定天数，因为**固定天数容易误导**。正确做法是问医生、记下医生给的具体日期。

**坑三：术前检查做了但没看结果。**
错误做法：机构说"查了没问题"，就直接约手术。正确做法：**检查结果要拿到手**。术后出问题回看，往往就是术前某项没查或没看结果。既往病史与长期用药也必须如实告知，隐瞒会直接影响麻醉方案。

**坑四：术后当天不喝水就慌。**
错误做法：术后宠物蔫了、没喝水，急着喂水喂食。正确做法：**未清醒属正常**；清醒后不喝水超过 12 小时需联系医生。**不要强行灌水**，呛入气道风险很高。

**坑五：公猫术后尿不出来没当回事。**
错误做法：以为猫砂盆里没尿就是在睡觉。正确做法：**公猫尿闭是急症**。频繁进猫砂盆却尿不出、蹲坐时间异常长、龟头长时间露在包皮外——**立刻就医**。尿闭拖延会危及生命。

**坑六：术后觉得它憋屈，就让它多跳多跑。**
错误做法：宠物想跳上柜子就让它跳，觉得活动有助于恢复。正确做法：**切口完全愈合前限制剧烈活动**。过早活动会导致切口裂开或出血，母猫尤其要限制跳跃攀爬。逐步恢复，不要一步到位。

**坑七：摸到腹部有硬结以为没事。**
错误做法：术后摸到腹部一块硬结，认为"在恢复"。正确做法：**粘连的信号就是牵拉感与硬结**，它不红不肿不化脓，最容易被忽略。**发现牵拉感就应该就诊**，不要以为过几个月就好了。

**坑八：伊丽莎白圈戴着，几天不吃就放弃。**
错误做法：宠物戴着圈不吃不喝，就自行取下。正确做法：**若完全不进食需及时联系医生**，而不是自行取圈。佩戴时长按医嘱。圈的目的就是防止舔咬切口，取下来等于放弃了这层保护。

**坑九：绝育后心疼它，加餐补回来。**
错误做法：觉得手术亏欠了它，开始额外加零食。正确做法：**绝育后代谢率下降，需按月监测体重并相应调整喂食量**。不加餐、调整结构比"补偿加餐"更有利。
