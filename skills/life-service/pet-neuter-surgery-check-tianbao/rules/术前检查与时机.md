# 术前检查与时机选择

> 手术适宜性、麻醉方案与时机由执业兽医决定。本文件是**核实清单与沟通口径**，不是手术决策依据。

## 一、术前检查项清单

是否做过、结果是否拿到，以就诊机构实际安排为准。

| 检查项 | 核对什么 | 异常时的意义 |
|---|---|---|
| 体温 | 是否在正常范围 | 发热提示可能存在感染，需先处理 |
| 心肺听诊 | 有无杂音、心率是否异常 | 心肺异常显著改变麻醉风险 |
| 血常规 | 白细胞、红细胞、血小板 | 贫血影响耐受，感染或炎症需先处理 |
| 生化（肝肾） | 肝肾功能指标 | 肝肾功能异常需调整麻醉方案 |
| 凝血功能 | 出血风险 | 部分机构会做，尤其深部手术 |
| 传染病筛查 | 按机构规定项目 | 阳性需先处理或改变方案 |
| 体重与体况评分 | 体重与脂肪覆盖 | 过瘦风险高，过胖增加麻醉与伤口愈合风险 |
| 皮肤与毛发状况 | 有无皮肤病、剃毛区域 | 感染区域避开切口 |
| 疫苗与驱虫状态 | 是否处于有效期 | 未完成免疫需与医生确认时序 |
| 既往病史 | 慢性病、长期用药、过敏史 | 如实告知，不隐瞒 |
| 发情与妊娠状态 | 母犬母猫是否处于发情期或妊娠 | 直接影响时机与方案 |

## 二、两条硬要求

1. **既往病史必须如实告知**，包括正在吃的所有药与保健品。隐瞒会直接影响麻醉方案选择。
2. **检查结果要拿到手**，不能只听一句"看着还行"。术后出问题回看，往往就是术前某项没查或没看结果。

## 三、年龄与体重窗口

| 情况 | 参考口径 | 说明 |
|---|---|---|
| 幼宠过小 | 一般不建议在很小的月龄做 | 过小会影响发育，具体月龄由兽医按品种评估 |
| 成年但体型偏小 | 需达到品种成熟体重的相当比例 | 大型犬与小型犬差异极大，不能套同一标准 |
| 成年犬 | 已达成年、发育基本完成 | 通常时机更从容 |
| 成年猫 | 已达成年、体重稳定 | 需控制体重，肥胖猫麻醉风险明显更高 |
| 高龄 | 需评估肝肾功能与心肺状态 | 高龄可做但评估更严格，由兽医决定 |
| 超重 | 建议先减重再评估 | 肥胖显著增加麻醉与伤口愈合风险 |

**关键原则**：不要按"几个月"这种统一标准，要按**品种体型 + 发育状态 + 体重**三项一起评估，最终由兽医面诊判断。

**公母差异**：

- 母犬母猫绝育需考虑发情期状态与是否可能妊娠
- 公犬公猫绝育主要考虑年龄、体力与前列腺相关状况
- 老年未绝育个体绝育的收益与风险需单独评估，不适用年轻个体标准

## 四、应避开的时机

| 避开 | 原因 |
|---|---|
| 母猫母犬发情期 | 子宫与血管充血明显，出血风险上升 |
| 刚发情结束不久 | 生殖系统仍处活跃状态，具体间隔由兽医判断 |
| 正在生病、腹泻、呕吐 | 麻醉耐受与恢复能力下降 |
| 刚换环境、刚搬家 | 应激状态下恢复更慢 |
| 体重不稳定、快速增减 | 补液与用药量难以准确计算 |
| 毛发极长且难打理（如长毛猫打结严重） | 术后护理困难，影响伤口观察 |

## 五、相对合适的窗口

| 项目 | 口径 |
|---|---|
| 状态 | 宠物整体健康、体重稳定、精神与食欲正常 |
| 季节 | 避开极端高温与严寒 |
| 与其他事件错开 | 不与搬家、换笼、长途出行、疫苗接种同时安排 |
| 发情结束后的间隔 | **具体间隔由兽医按品种与个体判断，本技能不给固定天数** |
| 安排缓冲 | 手术日选在能连续观察 3-5 天的时段 |

**为什么不给固定天数**：发情结束后的间隔需求在不同品种、不同个体之间差异很大，固定天数容易误导。正确做法是**问医生，记下医生给的具体日期**。

## 六、就诊提问清单

1. 术前检查做哪几项？结果什么时候能出？
2. 是否需要额外的检查项目？为什么要做？
3. 麻醉方式是什么？有什么风险点？
4. 手术预计多长时间？术后需要住院观察吗？
5. 禁食禁水从什么时候开始？术后什么时候开始喂？
6. 用药方案是什么？哪些需要我回家后自己给？
7. 什么时候拆线？需要复查几次？
8. 活动限制到什么时候？
9. 术后哪些情况需要立刻联系医院？
10. 有哪些情况我可以自己判断处理，什么情况必须回来？

## 七、记录要求

| 项目 | 记录什么 |
|---|---|
| 术前 | 检查项目与结果、既往病史、医生给出的手术日与注意事项 |
| 手术当天 | 麻醉开始与结束时间、清醒时间、当天进食与饮水情况 |
| 术后每天 | 体温、精神状态、饮水量、排尿次数与是否顺畅、进食量、呕吐次数、切口有无渗液 |
| 拆线 | 拆线日期、切口愈合情况、医生交代的注意事项 |
| 长期 | 体重（按月）、行为变化、泌尿状况变化 |

**为什么要逐日记录**：术后出问题回看，**逐日记录比事后回忆可靠得多**，尤其是"第一次拒水""第一次呕吐"这类时间点。
