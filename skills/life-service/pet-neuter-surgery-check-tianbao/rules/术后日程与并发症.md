# 术后日程与并发症识别

> 用药严格遵医嘱。本文件不提供任何药物名称、剂量与用法。

## 一、术后日程表

| 时间 | 关注点 | 口径 |
|---|---|---|
| 术后当天 | 体温、精神、饮水、切口 | 未清醒属正常；清醒后不喝水超过 12 小时需联系医生 |
| 术后 1-2 天 | 进食、排尿、呕吐 | 排不出尿是急症；呕吐反复需联系医生 |
| 术后 3-5 天 | 切口有无红肿渗液、精神、食量 | 脓性分泌物需就诊 |
| 术后 7 天 | 拆线或复查 | 按医嘱时间，不自行拆线 |
| 术后 10-14 天 | 拆线后切口状况、活动恢复 | 切口完全愈合前限制剧烈活动 |
| 术后 1-2 周 | 活动量逐级恢复 | 逐步增加，不一步到位 |
| 术后 1 个月 | 体重监测 | 体重增长是绝育后常见问题 |
| 长期 | 行为与泌尿状况观察 | 记录变化，供下次就诊参考 |

## 二、饮食口径

| 项目 | 口径 |
|---|---|
| 禁食禁水时长 | 按医嘱执行，不自行延长也不自行缩短 |
| 术后早期 | 部分兽医会建议一段时间内流质或软食，按医嘱 |
| 恢复后 | 转回日常食物，逐步过渡 |
| 体重管理 | 绝育后代谢率下降，需按月监测体重并相应调整喂食量 |
| 加餐 | 绝育后不因补偿心理额外加餐 |

## 三、活动限制

| 项目 | 口径 |
|---|---|
| 猫 | 术后限制跳跃攀爬，尤其母猫；限制进入高处 |
| 狗 | 限制奔跑、跳跃、上下沙发与楼梯 |
| 时长 | 切口完全愈合前，按医嘱 |
| 牵引 | 外出全程牵引，避免突然冲脱 |
| 逐步恢复 | 每天小幅度增加，1-2 周内回到正常 |

## 四、伊丽莎白圈

| 情况 | 口径 |
|---|---|
| 需要佩戴 | 舔咬切口风险高的个体，或医生明确要求 |
| 进食影响 | 佩戴期间可能出现拒食或吃不下；完全不进食需及时联系医生 |
| 替代方案 | 部分情况可用合适的局部遮挡替代，须经医生同意 |
| 佩戴时长 | 按医嘱，愈合前不取 |

## 五、并发症识别表

| 并发症 | 识别信号 | 处置 |
|---|---|---|
| 出血 | 切口持续渗血、纱布浸透、地上持续有血滴、黏膜苍白 | 渗血 20 分钟不减少即为红线；保持安静、压迫观察，持续不止立即就医 |
| 切口裂开 | 切口边缘分开、可见皮下组织、缝线断裂或崩脱 | 红线，立即就医；不自行按压或涂抹 |
| 粘连 | 术后长期腹部或腹股沟出现硬结、牵拉感、局部皮肤凹陷 | 非急症但需就诊评估，可能需要康复处理 |
| 感染 | 切口红肿热痛、脓性分泌物、发热、周围皮肤发烫 | 尽快就医；不自行涂抹任何药膏 |
| 尿闭（公猫高发） | 频繁进猫砂盆却尿不出、蹲坐时间异常长、龟头长时间露在包皮外、舔下体频繁 | 急症，立即就医 |
| 呕吐与不进食 | 反复呕吐、拒水、精神沉郁 | 超过 12 小时未改善需联系医生，幼宠更早 |
| 发热 | 体温明显升高、精神差、食欲低 | 联系医生 |
| 出血倾向加重 | 手术部位以外的出血点、牙龈渗血 | 就医排查凝血问题 |
| 麻醉后并发症 | 呼吸急促、持续呕吐、抽搐、牙龈发白或发绀 | 急症 |
| 持续疼痛未缓解 | 术后超过 2-3 天疼痛姿态不减、活动明显受限 | 就医评估疼痛管理方案 |

## 六、粘连为什么容易被忽略

粘连**不红、不肿、不化脓**，只是摸到腹部有一块硬结，或皮肤被"拉住"有牵拉感。很多人以为"过几个月就好了"，结果拖到需要康复处理时才处理。

**发现牵拉感就应该就诊**，不要等。

## 七、公猫尿闭的识别

尿闭是术后最需要警惕的急症之一，因为**猫会痛苦但常常不叫**，容易被当成"在睡觉"。

| 信号 | 说明 |
|---|---|
| 频繁进猫砂盆 | 反复进出，蹲坐时间异常长 |
| 猫砂盆里几乎无尿 | 或只有几滴 |
| 频繁舔下体 | 反复舔同一处 |
| 龟头长时间露在包皮外 | 常见于尿闭表现 |
| 叫声异常、躲藏、食欲下降 | 疼痛表现 |

**任一条出现立即就医**，尿闭拖延会危及生命。

## 八、就医红线（出现任一条）

| 情况 | 紧急程度 |
|---|---|
| 切口出血 20 分钟不减少、血滴持续滴落 | 尽快就医 |
| 切口裂开、可见皮下组织 | 立即就医 |
| 公猫 24-48 小时内排不出尿 | 立即就医 |
| 术后 12 小时以上反复呕吐、拒水 | 尽快联系医生 |
| 母猫持续大量阴道分泌物、有臭味或发热 | 尽快就医 |
| 精神沉郁、不吃不喝超过 24 小时（幼宠更早） | 尽快就医 |
| 腹胀明显、触碰腹部疼痛反应剧烈 | 尽快就医 |
| 伤口红肿热痛、脓性分泌物、结痂崩开 | 尽快就医 |
| 术后超过 48 小时体温明显升高或偏低 | 联系医生 |
| 呼吸急促、持续呕吐、抽搐、牙龈发白或发绀 | 立即就医 |
| 发现腹部或腹股沟硬结与牵拉感 | 就医评估（粘连） |
| 体重与年龄窗口存疑、有基础疾病 | 须兽医评估手术适宜性 |
