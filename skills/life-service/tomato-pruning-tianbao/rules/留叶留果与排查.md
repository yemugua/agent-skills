# 留叶留果数量关系与问题排查

## 一、留果量上限公式

```
留果穗数 <= 功能叶数 / 每穗所需功能叶数
```

| 穗次 | 每穗需留功能叶数（经验值） | 同节位叶片可否同时采收 |
|---|---|---|
| 第一穗（门果） | 2-3 片 | 不可同时采收 |
| 第二穗 | 2 片 | 不可同时采收 |
| 第三穗 | 1.5-2 片 | — |
| 第四穗及以后 | 1-1.5 片 | 可与上穗错开采收 |

## 二、功能叶自查方法

1. 在植株中部选一片主功能叶。
2. 往上找它供给的果穗。
3. 判断：如果这片叶被剪掉，那穗果还能不能正常膨大。
4. 不能，说明功能叶不足，该穗要疏果或增加叶片。

## 三、四条硬规则

1. **留果量超载后果**：功能叶不够 → 果实膨大慢、落果、脐腐、日灼、顶端小叶卷曲。一株挂十几穗果而叶片稀疏，就是超载。
2. **留果要分级留**：同一穗留周正、大小一致的果，去掉畸形果与畸形穗尖。一穗留 4-6 个（视品种与整枝方式）。
3. **功能叶老化是正常的**：从下往上第 5-6 片叶开始陆续采收，但同一节位不能一次全去。
4. **摘心位置**：短季栽培在最后 1-2 穗上方摘心，留 2-3 片叶；长季栽培（温室）不摘心，靠落蔓续接。

## 四、症状排查顺序（不能跳步）

| 症状 | 排查顺序 |
|---|---|
| 只长叶不结果 | ① 直射光是否达 5 小时以上 → ② 夜温是否过高 → ③ 氮肥是否过量、磷钾是否不足 → ④ 打杈是否过狠、功能叶是否不足 → ⑤ 是否遇连续阴雨或高温高夜温 |
| 果实小、不膨大 | ① 留果是否超载 → ② 根区是否缺水 → ③ 功能叶是否不足 → ④ 温度是否过低影响吸收 |
| 果实底部发黑 | ① 钙供给波动（重点是根区水分波动）→ ② 土壤是否忽干忽湿 → ③ 氮肥是否过量 → ④ 是否果实超载 |
| 果实表面日灼斑 | ① 是否阴雨天骤晴突然暴晒 → ② 叶片是否被剪太多失去遮荫 → ③ 是否高温 |
| 打杈后枝条萎蔫 | ① 工具是否消毒 → ② 是否湿剪 → ③ 剪除量是否超 1/4 → ④ 是否伤到主蔓 |
| 植株徒长、细高 | ① 夜温是否过高 → ② 氮肥是否过量 → ③ 光照是否不足 → ④ 是否未及时抹腋芽 |

## 五、易混淆的两组概念

| 容易混 | 实际区别 |
|---|---|
| 脐腐 vs 病害斑 | 脐腐从果顶脐部开始、褐色干缩，与钙供给波动和根区水分波动相关；不是病原引起的 |
| 果实日灼 vs 霜冻 | 日灼是高温强光下的灼伤斑，发生在向阳面；霜冻是低温造成的组织坏死，发生在受寒面 |

## 六、明确禁止

- 不推荐任何农药、植物生长调节剂与伤口处理产品
- 不给药剂名称、浓度与安全间隔期
- 不把排查表当作病害诊断结论
- 不在雨后、露水未干、浇水后进行整枝
- 不单次剪除超过全株枝叶 1/4
- 不留剪口长桩
- 不把剪下的枝叶堆在棚内田埂上
