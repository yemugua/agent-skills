# 番茄整枝打杈与留叶留果

## 你会得到什么

一套**每片叶都有它该供给的果**的整枝口径，避免番茄整枝的两个极端：剪狠了光长叶不结果，剪懒了光照不足烂果子。

- **整枝方式选择表**：单干、双干、四干、换头、简化整枝五种方式的适用条件与代价，配「看光照、看株距、看整枝人力」三条原则（含株距 < 35 cm 只能单干、35-50 cm 可双干、> 50 cm 才考虑四干的量化口径）。
- **整枝时间窗**：定植后 5-7 天只吊蔓不剪叶、7-15 天清第一穗花下方腋芽、坐果后至采收前逐次打杈、目标穗数坐住后摘心、生育期中后期落蔓；含每周至少一次与单次剪除不超全株 1/4 两条硬边界。
- **伤口处理口径**：斜剪略高于腋芽、不留长桩、不涂牙膏草木灰等非推荐物质、每换一株重新消毒、不在雨后露水未干时剪、枝叶当天带出田外。
- **留叶留果数量关系**：`留果穗数 <= 功能叶数 / 每穗所需功能叶数`，附各穗次每穗所需功能叶数表与功能叶自查三步法。
- **六类症状的排查顺序**：只长叶不结果、果实不膨大、果实底部发黑、日灼斑、打杈后萎蔫、徒长细高，每条都按不能跳步的顺序排。
- **剪除量的四级估算口径**：少量、中等、偏多、过量，含过量（> 50%）的后果判断。

## 典型用法

- 番茄定植后第一件事不知道干什么
- 单干还是双干拿不定主意，量一下株距和光照
- 一个枝上挂十几个果，不知道该疏几个
- 只长叶不结果，按顺序排查一遍
- 打杈伤口发黑腐烂，找原因

## 边界

不替代农技推广部门的栽培技术指导。不推荐任何农药、植物生长调节剂与伤口处理产品，药剂与调节剂的品种、浓度、次数与安全间隔期**以产品标签说明和当地农技部门要求为准**。病害与病毒症状的确认以专业鉴定结论为准，排查表只用于定位方向。不承诺产量与果实品质，整枝参数受品种、密度、光照与栽培方式影响很大。棚室通风、环流、供电与结构改动由具备资质的专业人员实施。
