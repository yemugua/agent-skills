# 止损操作卡与报案话术

## 卡片 A：黄金止损三步（转账后 72 小时内）

```
第 1 步  止付
  到开户行柜台 / 手机银行 / 客服电话 → 申请紧急止付或账户冻结
  拿到：止付受理凭证 + 完整流水（含对方账号、户名、时间）

第 2 步  报案
  110 或 96110 → 说明：何时、被谁、以什么名义、转了多少、转到哪个账户
  拿到：受案回执（必须索要，记下案件编号）

第 3 步  续冻
  把受案回执交回银行 → 申请延长止付 + 调取对方账户信息
  注意：止付有期限，到期前必须续
```

**顺序不能颠倒**：先止付再报案，晚了钱就转走了。

## 卡片 B：报案时怎么说（60 秒版本）

> 我要报案。我（或我家老人）于 ______ 年 __ 月 __ 日，通过 ______（电话/微信群/讲座/上门）认识自称 ______ 的 ______（身份），对方以 ______（名义）为名，让我向 ______（账户名/账号）转账，共 __ 笔，合计 ______ 元。最近一笔是 __ 月 __ 日。我现在提供银行流水、聊天记录（或宣传单、合同）。申请止付并立案。

**必须说清的四个要素**：时间、对方身份与名义、金额与笔数、收款账户。

## 卡片 C：索取回执话术

- 对民警：「请给我一份受案回执，我需要案件编号去银行申请续冻。」
- 到期查询：「案件编号是 ××××，请问是否已立案？若不予立案，请出具《不予立案通知书》。」
- 对银行：「我已报案，这是受案回执，申请延长止付并协助调取对方账户流水。」

## 卡片 D：家属介入话术（避免二次受骗）

**不要说**：
- 「你怎么这么傻」「跟你说过多少次了」
- 「这么大岁数还被人骗」

**应该说**：
- 「这不是你的错，他们是有剧本的，专门研究怎么说服人。」
- 「我们一起把钱追回来，你先别跟对方联系了，剩下的我来跑。」
- 「你记得多少说多少，哪怕记不清也没关系，我们有流水。」

**立刻做**：陪同报案 → 调低银行卡日限额与单笔限额 → 关闭小额免密 → 拉黑对方。

## 卡片 E：对方还在联系时的应对

| 对方说 | 你要做 |
| --- | --- |
| 「再投一笔就能返本」 | 一律视为诈骗延续，不再转一分钱 |
| 「报警就拿不回钱了」 | 典型阻止报警话术，照常报警 |
| 「别告诉子女，公司有规定」 | 隔绝家属是诈骗成立的必要条件，立即告知家属 |
| 「把聊天记录删掉，免得麻烦」 | 删除前先完整导出备份，绝不配合删除 |
| 「我们是正规公司，有执照」 | 到国家企业信用信息公示系统核对，重点看经营范围与异常名录 |

## 卡片 F：房产已被涉及时的额外动作

1. 到**不动产登记中心**打印登记簿，查是否已被抵押、过户或设定居住权
2. 已办理公证的，向**公证机构**申请复查
3. 已签署全权委托的，**书面撤销委托**并留存送达凭证
4. 咨询律师评估撤销之诉或确认合同无效之诉
5. 撤销权应在知道或应当知道撤销事由之日起一年内行使，**不要等刑事判决**
