> 本模板为脚本输出结构示意。实际报告由 `scripts/elder_fraud_check.py` 依据采集表生成。

## 一、结论摘要

| 项 | 结论 |
| --- | --- |
| 识别类型 | 待填 |
| 案件定性 | 待填 |
| 止损窗口 | 待填（黄金止损期 / 可止损期 / 追损期 / 待补正） |
| 资金核查 | 待填 |
| 高危红线 | 待填（n 项） |
| 净损失 | 待填 |
| **总体结论** | **通过 / 有风险 / 不通过 / 待补正** |

结论四态含义：

- **通过**：尚未实际转账，且未识别到高危红线——立即终止接触即可
- **有风险**：存在可疑信号或证据缺口，需按待办补正后推进
- **不通过**：命中高危红线（个人账户收款、房产抵押、冒充公检法、被威胁等）——立即报案
- **待补正**：核心事实未填，不下任何实质结论

## 二、骗局类型识别

命中类型与理由、接触渠道、机构与执照情况、合同签署情况。

## 三、红线信号核查

- 高危（立即停止接触并报警）
- 可疑（需进一步核验）

## 四、止损窗口与时效

以最近转账日为起算点：3 日内为黄金止损期，30 日内为可止损期，超过 30 天为追损期。

## 五、资金流水与账户核查

投入 − 已追回 = 净损失；账户性质与户名一致性核验。

## 六、证据固定清单

已具备 / 仍缺失，按重要性排序。

## 七、案件定性与处置路径

定性 → 处置建议 → 按序号排列的动作清单 → 投诉举报入口。

## 八、待办补正动作

按优先级编号列出，可直接当作执行清单。

## 九、边界与纪律

不替代法律意见，最终以公安机关与司法机关认定为准。
