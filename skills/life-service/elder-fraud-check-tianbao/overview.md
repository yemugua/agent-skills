# 养老诈骗识别与止损追回

面向老年人或其家属，遇到"高息理财""以房养老""保健品会销""冒充子女""代办养老服务"等话术后已转账、无法挽回或想挽回的当事人。

## 与其他工具的区别

- **止损优先于定性**。多数家属第一反应是"怎么追回"，但钱能不能回来取决于是否在黄金窗口内报案，而不是对方是谁。本技能把止损动作排在最前。
- 区分**诈骗 / 非法集资 / 职务侵占 / 民事纠纷**，这四类的处置部门和追回难度完全不同，认错方向会浪费关键时间。
- 给出可执行的话术：家属怎么劝阻、当事人如何向银行写冻结申请、报案材料怎么组织。

## 典型适用场景

1. 老人被"养老公寓床位认购"骗走养老金
2. 被推销"能根治的高价保健品"，刷卡、贷款消费
3. 冒充子女或警察来电，要求转账解冻、缴纳"保证金"
4. "以房养老"签约后房子被过户或拿不到养老钱
5. 参加会销后被引导"以分期理财名义投资"，出事才发现是非法集资
6. 老年朋友已受骗，老人本人拒绝报案

## 使用流程

1. 抄录 `templates/养老诈骗信息采集表.md` 填好（关键项未知就写"不清楚"，别猜）
2. 运行脚本生成核查报告
3. 报告第一节是**紧急止损动作**，先照着做，别等到看完全文
4. 按"维权路径"推进报案与冻结

## 边界

本结果依通用规则整理，不替代专业法律意见。最终以公安机关及司法机关认定为准；涉及刑事案件的应立即拨打 110 报案，不要依赖本技能自行处置。
