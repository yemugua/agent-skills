# 止损、取证与报案路径操作规则

## 一、黄金止损：按分钟算的三步

转账后 72 小时内是止付成功率最高的窗口，顺序不能颠倒：

| 顺序 | 动作 | 找谁 | 要拿到什么 |
| --- | --- | --- | --- |
| ① | 紧急止付/冻结 | 开户行柜台、手机银行、拨打银行客服 | 止付申请受理凭证、流水明细 |
| ② | 报案 | 110 / 96110 反诈专线 / 国家反诈中心 App | **受案回执**（必须索取，含案件编号） |
| ③ | 提交回执给银行 | 原受理网点 | 延长止付、调取对方账户信息 |

**注意**：止付有期限（各地操作口径不同，通常为 48~72 小时），到期前需凭报案回执申请续冻。

## 二、超过止损窗口还能做什么（追损期）

1. **立案后追赃挽损**：向办案民警提交完整的资金流向清单（每笔时间、金额、对方账号、户名）。
2. **查询对方账户性质**：对公账户可通过国家企业信用信息公示系统核对主体；个人账户重点查是否与机构有关联。
3. **民事追偿并行**：涉合同纠纷的，可在刑事程序之外另行起诉；已签合同的重点审查格式条款与欺诈撤销。
4. **涉房产的另行动作**：不动产登记中心查登记簿 → 申请异议登记 → 公证复查 → 律师评估撤销之诉。
5. **涉机构的举报**：民政（养老机构备案）、市场监管（无照经营、虚假宣传）、地方金融监管（非法集资）。

## 三、报案材料清单（照单准备）

- 身份证原件
- **银行流水**（盖章版，含对方账号、户名、交易时间；手机银行导出的需带电子印章）
- 转账凭证（回单、支付记录截图）
- 聊天记录（**连上下文完整导出**，不要只截单张图）
- 通话录音（原始文件，不要剪辑）
- 宣传单、合同、收据、产品外包装原件
- 对方名片、联系方式、工号、机构名称
- 事情经过的**书面陈述**（按时间顺序写清：何时何地通过什么方式认识、对方说了什么、每笔转账的时间金额与理由）

## 四、报案后的三个节点

| 节点 | 时限 | 该做什么 |
| --- | --- | --- |
| 受案 | 当天 | 索取受案回执，核对案件编号 |
| 立案审查 | 一般 7 日内（重大复杂案件可延长） | 到期主动查询是否立案 |
| 不予立案 | 收到通知后 | 索取《不予立案通知书》，可在收到后 7 日内申请复议，或向检察院申请立案监督 |

> 具体时限以公安机关适用程序与当地口径为准，本表为通用参考。

## 五、证据固定的技术要点

- **流水**：要完整版而非截图拼接；需含对方账号与户名，缺户名的向银行申请补充。
- **聊天记录**：使用导出功能生成完整文本或打包文件，保留时间戳；单张截图易被质疑篡改。
- **录音**：保留原始文件与设备，剪辑过的录音证明力下降。
- **宣传材料**：会销现场尽量拍照录像，保留产品批号与外包装。
- **见证人**：一同参加的老年人可作证，但需独立陈述，不要串供。

## 六、家属介入与防二次受骗

1. **不要在群里指责老人**——羞耻感会导致隐瞒，是二次受骗的直接原因。
2. 立即做三件事：陪同报案、接管银行卡与手机支付限额、把对方联系方式拉黑。
3. 调整支付限额：把老人的银行卡日限额与单笔限额调低，关闭小额免密。
4. 请社区民警或网格员定期回访；很多地区有老年人反诈宣传与预警机制。
5. 对方若继续联系要求「再投一笔就返本」，一律视为诈骗延续。

## 七、常见误区

| 误区 | 正确做法 |
| --- | --- |
| 「钱不多就算了」 | 小额也要报案，多人报案才能并案，追赃率显著提高 |
| 「先自己找对方要」 | 打草惊蛇会导致对方销毁证据、注销账户 |
| 「对方说报警就拿不回钱」 | 这是典型话术，目的是阻止报警 |
| 「已经签了合同就认了」 | 因欺诈订立的合同可请求撤销，且诈骗情形下合同本身可能无效 |
| 「删了聊天记录就没证据了」 | 银行流水与对方账户信息才是核心证据，仍可报案 |
