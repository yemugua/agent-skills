# 定性区分：民事纠纷 / 非法集资 / 诈骗 / 消费欺诈

判断走哪条路，取决于对方行为的性质，而不是金额大小。

## 一、四条路的区分

| 定性 | 核心特征 | 主要路径 | 关键材料 |
| --- | --- | --- | --- |
| **电信网络诈骗** | 虚构事实、冒充身份、无真实交易、收款后失联 | 110 / 96110 报案，刑事侦查 | 流水、聊天记录、通话记录 |
| **非法集资**（非法吸收公众存款 / 集资诈骗） | 公开宣传、承诺还本付息、面向不特定公众吸收资金 | 报案 + 地方金融监管部门 | 合同、宣传材料、返息流水 |
| **消费欺诈 / 虚假宣传** | 有真实商品或服务，但功效、资质、价格虚假 | 12315 投诉举报 + 市场监管 | 商品、宣传单、检测报告 |
| **民事合同纠纷** | 双方对服务内容、退款条件有争议 | 协商 → 消协调解 → 法院起诉 | 合同、付款凭证、履约记录 |

**多数养老诈骗是复合的**：先用消费欺诈引流（送鸡蛋、免费体检），再转入非法集资或诈骗。报案时应把全过程一并说明，不要只讲最后一笔。

## 二、关键判断点

1. **有没有真实标的**：有实体床位、实体产品的，可能是消费欺诈或合同纠纷；项目「还在规划」的，多为诈骗。
2. **钱进谁的账户**：进对公账户且户名与合同主体一致的，民事纠纷可能性高；进个人账户或现金的，诈骗/非法集资概率极高。
3. **承诺的性质**：承诺「保本保息、固定回报」是非法集资的核心特征——真正投资的收益是不确定的。
4. **有没有针对不特定公众**：讲座、微信群、传单面向社会公众的，符合非法集资的「公开性」与「社会性」。
5. **是否虚构身份**：冒充子女、公检法、银行、社保工作人员的，直接是诈骗。

## 四、涉刑与涉民交叉时的处理

- **先刑后民**：同一事实已进入刑事程序的，民事案件一般中止审理，待刑事结论。
- **可并行的部分**：刑事追赃与民事撤销合同可以并行推进，尤其涉房产抵押的，不要等刑事判决再处理不动产。
- **撤销权有期限**：因欺诈订立的合同，撤销权应在知道或应当知道撤销事由之日起一年内行使，逾期消灭——不要因为等刑事结果而错过期限。
