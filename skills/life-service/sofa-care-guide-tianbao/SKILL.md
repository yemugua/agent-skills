# 沙发保养

## 1. 硬边界（能做什么 / 不能做什么）

| 能做 | 不能做（转专业人士） |
|---|---|
| 按材质除尘、专用剂擦拭 | 真皮深度翻新 / 补伤 |
| 布艺拆套机洗（可拆款） | 不可拆布艺整体浸泡 |
| 局部去渍、阴干 | 暴晒、强碱 / 漂白剂处理 |

皮面大面积龟裂、框架松动、海绵塌陷，转家具维修。

## 2. 什么时候用

| 用户说法 | 用不用 |
|---|---|
| 真皮发干、有裂纹 | 用（上护理剂） |
| 布艺沾油渍 | 用（局部去渍） |
| 不知什么材质怎么清 | 用（先识别材质） |
| 皮面大面积破损 | 不用（转翻新） |

## 3. 完整工作流

1. **识别材质**：看标签 / 触感区分布艺、真皮、科技布、实木。
2. 选专用清洁剂：真皮用皮革护理剂，布艺用中性沙发清洁剂，实木用木蜡油。
3. 先吸尘除尘，去除浮灰。
4. 在不显眼处做**局部测试**，确认不掉色再大面积。
5. 按材质手法擦拭（真皮打圈上剂、布艺蘸擦、实木顺纹）。
6. 阴干通风，勿暴晒、勿吹风机烘。

材质对应口径见 `rules/sofa-rules.md`。

## 4. 核心规则 / 要件说明

生成保养方案前**先读 `rules/sofa-rules.md`**：材质 → 清洁剂 / 手法映射、禁用清单。不合格带原因，如「真皮用了漂白剂：腐蚀皮面掉色，必须换皮革专用剂」。

## 5. 脚本用法

`scripts/sofa_check.py` 自检「保养操作清单」：

```
python scripts/sofa_check.py --file steps.json
python scripts/sofa_check.py --selftest
```

## 6. 人工确认清单

- [ ] 已识别材质
- [ ] 清洁剂与材质匹配
- [ ] 已做局部测试
- [ ] 未用漂白 / 强碱
- [ ] 阴干未暴晒

## 7. 最常见的坑

1. 不分材质乱用剂：真皮遇漂白 / 强碱掉色开裂，必须专用。
2. 没局部测试直接大面积：掉色才发现有损，先试隐蔽处。
3. 布艺整体泡水：不可拆款芯材发霉变形，只局部蘸擦。
4. 真皮用酒精湿巾猛擦：脱脂干裂，用皮革剂。
5. 暴晒快干：皮布都老化褪色，阴干。
6. 长期不除尘：灰嵌入纤维难清，每周吸尘。

## 8. 边界与免责

覆盖常见家用沙发日常清洁保养。深度皮具翻新、框架结构维修不在范围。贵重真皮建议先小样测试或请专业养护。
