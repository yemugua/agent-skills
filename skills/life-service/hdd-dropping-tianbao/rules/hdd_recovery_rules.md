# 机械硬盘掉盘与数据抢救规则库

> 生成处置建议、跑状态评估之前，先读这份文件，不要凭印象写。

---

## 一、掉盘征兆对照表

| 征兆 | 含义 | 紧急度 | 首步动作 |
|---|---|---|---|
| 咔哒声、咔咔响、刮擦声 | 磁头无法正常寻道 | 立即停用 | 断电，不再通电 |
| 启动时咔一下然后正常 | 磁头复位，寿命末期 | 立即停用 | 断电，转专业机构 |
| 完全不识别 | 供电、接口、盘体或控制器 | 高 | 换线换口验证后停用 |
| 时好时坏、反复掉线 | 盘体不稳定或接触不良 | 高 | 换线换口验证后停用 |
| 拷贝大文件到某百分比就断 | 该区域不可读 | 高 | 停止，改为镜像抢救 |
| SMART 属性异常 | 见预警项表 | 高 | 按预警项分级处理 |
| 打开文件很慢但能读 | 坏道或缓存问题 | 中 | 先完整备份 |
| 电脑偶尔认不到盘 | 接口或供电 | 中 | 先换线换口验证 |

**判断口径**：异响是最强信号。有异响时，无论其他指标多好，一律按最坏情况处理。

## 二、SMART 关键预警项分级

| 预警项 | 含义 | 级别 |
|---|---|---|
| 待映射扇区数不为零 | 有扇区未完成重映射 | 高 |
| 重新分配扇区数持续增长 | 已有扇区不可用，靠备用区顶替 | 高 |
| 无法校正扇区数不为零 | 多次尝试仍读不出 | 高 |
| 底层数据错误率上升 | 读出的数据本身就有误 | 高 |
| 通电超时计数增长 | 磁头寻道时间异常 | 高 |
| 寻道错误率异常 | 机械寻道不稳定 | 中高 |
| 出厂校准计数异常 | 厂商自检未通过 | 中 |
| 温度告警 | 长期高温加速老化 | 中 |
| 通电小时数很高 | 老盘，各项性能同步下降 | 中 |

**关键口径**：「SMART 全绿」不等于盘健康。**异响盘即使 SMART 全绿也应停用**，因为机械故障往往来不及反映到这些数值上。

## 三、抢救流程（顺序不能乱）

| 步骤 | 动作 | 为什么 |
|---|---|---|
| 1 | 停止使用，不再往这块盘写任何数据 | 避免覆盖残余可读区域 |
| 2 | 断电、静置，必要时降温，避免震动 | 减少进一步损伤 |
| 3 | 做整盘或分区镜像到健康介质 | 原盘只被动读一次 |
| 4 | 在镜像件上跑恢复工具 | 可重复操作，中途失败有退路 |
| 5 | 核对镜像件里的文件完整性 | 确认结果可用 |

**绝对不要做**：

- 把恢复出来的文件写回故障盘
- 格式化故障盘「试试看还能不能用」
- 继续往故障盘拷新数据

---

## 四、镜像优先于恢复（对照表）

| 直接恢复 | 先镜像 |
|---|---|
| 反复读原盘，风险累积 | 原盘只读一次，风险最小 |
| 中途失败没有退路 | 镜像件可重复操作 |
| 恢复软件可能写回原盘 | 不动原盘，随时可重来 |

---

## 五、放弃数据的判定线

出现下列任一情况，**停止自行尝试**，转专业机构或接受损失：

| 情况 | 理由 |
|---|---|
| 有异响且数据无任何有效备份 | 自行操作会持续损伤盘面 |
| 已反复通电多次仍读不出 | 可救范围已大幅缩小 |
| 需要开盘才能读 | 家庭与办公环境不具备条件 |
| 盘片有物理变形或液体痕迹 | 属硬件损坏，自行处理无意义 |
| 数据量大且分散多块盘 | 需专业工具与经验 |

**核心原则**：**备份优先于修复。** 抢救之前先回答：这块盘的数据有没有第二份？没有的话，慎重的理由就是它不可再生。

## 六、处置级别与对应动作

| 级别 | 触发条件 | 动作 |
|---|---|---|
| L0 立即停用 | 有任何异响征兆 | 断电停用，转专业机构 |
| L1 高优先处理 | 不识别、时好时坏、大文件拷贝断 | 停止写入，评估镜像抢救 |
| L2 先备份 | 打开文件慢、SMART 中低级预警 | 尽快完整备份后再评估 |
| L3 继续观察 | 偶发认不到盘、无预警项 | 先换线换口验证 |

**否定项提醒**：级别判定不能只看 SMART 总状态，异响与机械征兆优先级最高。

---

## 七、专业机构转交清单

| 触发条件 | 说明 |
|---|---|
| 需开盘处理 | 家庭与办公环境不具备条件 |
| 异响 + 重要数据 + 无备份 | 自救会缩小可救范围 |
| 阵列或多盘系统单盘故障 | 需要整体评估 |
| 合约、账务、研发等不可再生数据 | 直接委托更稳妥 |
| 已反复通电多次 | 风险已升高 |

## 八、常见误区对照

| 说法 | 是否成立 |
|---|---|
| 异响了多试几次说不定能好 | 不成立，持续损伤盘面 |
| SMART 全绿就没事 | 不成立，机械故障可能不反映在数值上 |
| 格式化一下看看还认不认 | 不成立，写操作会毁掉残余可读区域 |
| 能识别就说明还健康 | 不成立，只说明通信正常 |
| 先恢复再镜像更省事 | 不成立，中途失败没有退路 |
| 拷贝断掉说明文件全没了 | 不成立，已拷贝部分通常还在 |
