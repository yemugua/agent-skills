# 卫生许可证申办条件与材料清单（公共场所 / 餐饮 / 饮用水）

> 发证机关为县级以上卫生健康主管部门（多地已划转行政审批服务局），餐饮类食品经营许可由市场监督管理部门核发。**申办条件、材料清单、办理时限以当地主管部门公示为准**，本文件只给通行口径，不引用具体条款号。

## 一、先分清你要的是哪一张证

| 你要开的 | 需要什么证 | 发证机关 |
|---|---|---|
| 宾馆、旅店、招待所、民宿 | 公共场所卫生许可证 | 卫生健康主管部门 / 行政审批局 |
| 公共浴室、桑拿、足浴 | 公共场所卫生许可证 | 同上 |
| 理发店、美容店 | 公共场所卫生许可证 | 同上 |
| 游泳场（馆） | 公共场所卫生许可证 | 同上 |
| 影剧院、歌舞厅、游艺厅 | 公共场所卫生许可证 | 同上 |
| 商场、书店、候车（机、船）室 | 公共场所卫生许可证 | 同上 |
| 展览馆、博物馆、美术馆、图书馆 | 公共场所卫生许可证 | 同上 |
| 体育馆、公园 | 公共场所卫生许可证 | 同上 |
| 饭店、小吃店、饮品店、食堂 | **食品经营许可证**（不是卫生许可证） | 市场监督管理部门 |
| 集中式供水单位 | 饮用水供水单位卫生许可证 | 卫生健康主管部门 |
| 二次供水设施管理单位 | 饮用水供水单位卫生许可证（按当地口径） | 卫生健康主管部门 |
| 涉及饮用水卫生安全产品（管材、水处理剂、消毒设备等）生产企业 | 涉水产品卫生许可批件 | 卫生健康主管部门 |

**防误伤**：餐饮开的不是"卫生许可证"而是"食品经营许可证"，两者发证机关、条件、有效期都不同。跑错窗口是最常见的时间浪费。

## 二、公共场所卫生许可证申办条件

| # | 条件 | 核查要点 |
|---|---|---|
| 1 | 场所选址、建筑设计符合卫生要求 | 不与有毒有害场所相邻，无污染源 |
| 2 | 功能分区合理，流程不交叉污染 | 住宿业布草间与清洗消毒间分设 |
| 3 | 有与经营规模相适应的卫生设施 | 清洗消毒间、保洁柜、通风换气、防蝇防鼠、垃圾收集 |
| 4 | 公共用品用具一客一换一消毒 | 有消毒设施与消毒记录 |
| 5 | 主要卫生指标检测合格 | 空气、微小气候、水质、采光照明、噪声、公共用品用具消毒效果 |
| 6 | 使用集中空调通风系统的，有卫生检测或评价报告 | 新风量、风管积尘、冷却水（如有） |
| 7 | 从业人员取得健康合格证明 | 直接为顾客服务的人员全部持证 |
| 8 | 有卫生管理制度与专（兼）职卫生管理人员 | 制度上墙、记录可查 |
| 9 | 二次供水（如有）符合饮用水卫生要求 | 有清洗消毒记录与水质检测报告 |

## 三、餐饮（食品经营许可）申办条件

| # | 条件 | 核查要点 |
|---|---|---|
| 1 | 有与经营品种、数量相适应的场所 | 面积、布局与业态匹配 |
| 2 | 场所环境整洁，与有毒有害场所保持规定距离 | 距粪坑、污水池、垃圾场等污染源的距离 |
| 3 | 有相应的经营设备与设施 | 冷藏冷冻、清洗消毒、防蝇防鼠、废弃物处理 |
| 4 | 工艺流程合理，防止交叉污染 | 生进熟出、荤素分开、成品半成品分开 |
| 5 | 有专职或兼职食品安全管理人员与管理制度 | 制度、培训记录 |
| 6 | 用水符合生活饮用水卫生标准 | 自备水源需有水质检测报告 |
| 7 | 从业人员取得健康证明 | 每年体检一次 |
| 8 | 餐具、饮具自行清洗消毒的具备消毒设施 | 消毒记录、保洁设施 |

## 四、饮用水供水单位卫生许可申办条件

| # | 条件 | 核查要点 |
|---|---|---|
| 1 | 水源选择与水源防护符合卫生要求 | 有水源保护区与防护设施 |
| 2 | 有水质净化消毒设施且正常运转 | 加药、消毒、混合、反应、沉淀、过滤、清水池 |
| 3 | 有水质检验室与检验人员、检验设备 | 自检能力或与有资质机构签订委托检验 |
| 4 | 涉水产品具有卫生许可批件 | 管材、管件、水处理剂、消毒设备、水质处理器 |
| 5 | 水质符合国家生活饮用水卫生标准 | 出厂水、管网末梢水检测报告 |
| 6 | 有水质检测制度与检测记录 | 频次按当地要求 |
| 7 | 从业人员取得健康证明 | 直接从事供管水的人员 |
| 8 | 有污染事件应急预案 | 报告与处置流程 |

## 五、通用材料清单（三类共用部分）

| # | 材料 | 说明 |
|---|---|---|
| 1 | 卫生许可申请表 | 加盖申请人印章或签字 |
| 2 | 营业执照或主体资格证明 | 先照后证，经营范围应涵盖拟经营项目 |
| 3 | 法定代表人（负责人）身份证明 | — |
| 4 | 场所合法使用证明 | 房产证或租赁协议 |
| 5 | 场所平面布局图、卫生设施布局图 | 按比例绘制，标注功能分区 |
| 6 | 卫生管理制度文本 | 制度目录与关键制度全文 |
| 7 | 从业人员健康合格证明与名册 | 全员覆盖，有效期内 |
| 8 | 卫生检测或评价报告 | 由具备资质的检测机构出具 |
| 9 | 委托书与经办人身份证明（委托办理时） | — |
| 10 | 承诺书（按当地要求） | 部分地区实行告知承诺 |

## 六、分类补充材料

| 类别 | 补充材料 |
|---|---|
| 公共场所 | 集中空调通风系统卫生检测或评价报告；公共用品用具清洗消毒设施说明；二次供水设施情况（如有） |
| 游泳场所 | 池水循环净化消毒设备说明；池水检测报告；救生设施与救生员配置 |
| 住宿业 | 布草间与洗涤消毒设施说明；集中空调检测报告 |
| 美容美发 | 烫染分区（如涉及）；皮肤病顾客专用工具；消毒设施说明 |
| 餐饮（食品经营） | 食品经营许可申请表；设备布局与工艺流程；食品安全自查与从业人员培训制度；自备水源水质检测报告（如适用）；网络经营的还需入网相关信息 |
| 饮用水供水 | 水源防护说明；水处理工艺流程图；水质检验室设备与人员清单；涉水产品卫生许可批件复印件；出厂水与末梢水检测报告 |

## 七、办理流程与时限

| 环节 | 口径 |
|---|---|
| 申请 | 窗口、政务服务网或当地政务 APP 提交 |
| 受理 | 材料齐全的当场或短时限内受理，出具受理凭证 |
| 审查 | 材料审查 + **现场核查**（重点环节） |
| 决定 | 符合条件的作出准予许可决定 |
| 发证 | 领取许可证或电子证照 |
| 时限 | 法定时限与承诺时限各地不同（常见承诺时限为十余个工作日），**以当地主管部门公示为准** |
| 不予许可 | 书面告知理由，可依法申请行政复议或提起行政诉讼 |

**现场核查高频不通过项**：消毒间缺失或挪作他用；布草间与消毒间混用；防蝇防鼠设施不到位；健康证缺人或过期；检测报告项目不全或超期；平面布局图与实际不一致；集中空调无检测报告。

## 八、从业人员健康证

| 事项 | 口径 |
|---|---|
| 体检频次 | **每年至少一次**，取得健康合格证明后方可上岗 |
| 覆盖范围 | 直接为顾客服务的人员、直接从事供管水的人员、接触直接入口食品的从业人员 |
| 不得从事的情形 | 患有痢疾、伤寒、甲型/戊型病毒性肝炎、活动性肺结核、化脓性或者渗出性皮肤病等有碍公共卫生/食品安全疾病的人员，治愈前不得从事相关岗位 |
| 管理要求 | 建立健康晨检制度与记录，发现上述症状立即调离岗位 |

## 九、卫生检测频次口径

| 项目 | 频次（通行口径，以当地要求为准） |
|---|---|
| 公共场所主要卫生指标检测 | 通常每年不少于一次 |
| 集中空调通风系统卫生检测/评价 | 通常每两年不少于一次（部分地区要求更严） |
| 游泳场所池水检测 | 按当地要求，开放期间定期检测并公示 |
| 饮用水水质检测 | 按当地要求，出厂水与末梢水定期检测 |
| 二次供水设施清洗消毒 | 通常每半年不少于一次，并做水质检测 |

## 十、有效期与延续

| 类别 | 有效期（通行口径） |
|---|---|
| 公共场所卫生许可证 | 一般为 **4 年** |
| 食品经营许可证 | 一般为 **5 年** |
| 饮用水供水单位卫生许可证 | 一般为 **4 年** |

**以当地主管部门核定的有效期为准**，证件上印的有效期才是最终依据。

延续申请应在有效期届满前提出（常见为届满前 30 日，部分地区要求更早就受理），**逾期未延续的许可证自行失效，需重新申办**。详见 `rules/renewal_and_change.md`。
