# 卫生许可证延续、变更、补办与注销

> 延续、变更的具体时限与材料**以当地主管部门公示为准**，本文件只给通行口径与操作顺序，不引用具体条款号。

## 一、延续（最容易被忽略的时点）

| 事项 | 口径 |
|---|---|
| 申请时点 | 应在许可证有效期届满前提出延续申请，**常见为届满前 30 日内**（部分地区要求更早，或可在届满前 60 日内受理） |
| 逾期后果 | 有效期届满未延续的，许可证失效，**需重新申办**，不能"补办延续" |
| 审查方式 | 材料审查 + 必要时现场核查 |
| 关键材料 | 延续申请表；原许可证；营业执照；场所合法使用证明；从业人员健康证明；卫生检测报告；原许可条件未发生变化的说明 |
| 检测结果 | 延续时通常要求提供**在有效期内的卫生检测报告**，检测超期会导致延续被卡 |
| 不予延续 | 卫生条件已不符合现行要求、检测不合格、存在重大卫生安全隐患、提供虚假材料的 |

**操作顺序（建议提前 90 天启动）**：

```
届满前 90 天：核对原许可条件是否变化、从业人员健康证是否齐全有效
届满前 60 天：安排卫生检测（检测出报告需要时间，别卡在最后一周）
届满前 45 天：备齐延续材料，自查材料是否在有效期内
届满前 30 天：提交延续申请，取得受理凭证
届满前  7 天：查询办理进度，未办结的主动催办
```

## 二、变更（四种情形分开处理）

| 变更内容 | 处理方式 | 特别注意 |
|---|---|---|
| 单位名称变更 | 办理变更 | 需先完成营业执照名称变更，名称须与执照一致 |
| 法定代表人（负责人）变更 | 办理变更 | 需身份证明与任命文件 |
| **经营地址变更（迁址）** | **一般需重新申请** | 新址要重新现场核查、重新做卫生检测，不能只办变更 |
| 经营项目/类别变更（增加项目） | 办理变更或重新申请 | 新增项目涉及新卫生要求的，需补充检测与核查 |
| 减少经营项目 | 办理变更 | 同步核对从业人员与设施配置 |

**防误伤**：把"迁址"当成"变更"来办，是延续/变更环节最高频的错误。换了地方就要重新核查、重新检测，按新办准备。

## 三、补办与注销

| 事项 | 触发情形 | 要点 |
|---|---|---|
| 补办 | 许可证遗失、损毁 | 一般需刊登遗失声明（按当地要求）或提交说明，提交补办申请 |
| 注销 | 停止经营活动、主体资格终止、许可证被吊销或撤销 | 主动办理注销，避免长期挂证 |
| 吊销/撤销后 | 被吊销的，通常在一定期限内不得再次申请同类许可 | 以主管部门决定为准 |

## 四、延续窗口计算口径

| 概念 | 定义 |
|---|---|
| 有效期届满日 | 许可证上印的有效期截止日 |
| 延续申请窗口 | `[届满日 - 提前天数, 届满日]`（提前天数按当地要求，默认按 30 天测算） |
| 剩余有效期天数 | `届满日 - 核查基准日` |
| 距窗口开启天数 | `窗口起始日 - 核查基准日`（为正表示尚未到申请时间） |

四种状态：

| 状态 | 判定 | 动作 |
|---|---|---|
| 距届满 > 窗口期 | 未到申请窗口 | 先安排卫生检测与材料准备，别提前提交 |
| 剩余 ≤ 窗口期且 > 0 | 可以申请延续 | 立即提交，取得受理凭证 |
| 剩余 0（当日届满） | 届满当日 | 立即提交；当天未办结的，证件次日失效 |
| 剩余 < 0 | 已失效 | **重新申办**，按新办准备，期间不得经营 |

## 五、常见不通过原因（现场核查环节）

| 类别 | 具体问题 | 整改方向 |
|---|---|---|
| 设施 | 消毒间缺失、被占用、消毒设施不能正常使用 | 恢复消毒间功能，配齐消毒设施 |
| 布局 | 平面布局图与实际不一致 | 改图或改现场，二者必须一致 |
| 检测 | 检测报告超期、缺项目、非资质机构出具 | 委托具备资质的机构重做全项目检测 |
| 人员 | 从业人员无健康证或过期 | 全员体检，建立健康证到期台账 |
| 用品 | 公共用品用具无清洗消毒记录、无保洁设施 | 建立一客一换一消毒记录，配保洁柜 |
| 空调 | 集中空调无检测报告、新风量不足、风管积尘 | 委托检测并清洗消毒风管 |
| 二次供水 | 无清洗消毒记录、无水质检测报告 | 每半年清洗消毒并检测（按当地要求） |
| 制度 | 制度未上墙、无自查记录、无专人负责 | 建制度、定专人、留记录 |
| 材料 | 营业执照经营范围不含拟经营项目 | 先变更营业执照经营范围 |

## 六、与"证后监管"相关的日常要求

| 事项 | 要求 |
|---|---|
| 亮证经营 | 许可证应在经营场所醒目位置公示 |
| 卫生检测 | 按规定频次委托检测，报告留存备查 |
| 健康证 | 到期前完成体检，建立到期提醒台账 |
| 自查记录 | 定期开展卫生自查并留存记录 |
| 公共用品消毒 | 一客一换一消毒，记录可追溯 |
| 集中空调 | 定期清洗消毒，按频次检测 |
| 二次供水 | 定期清洗消毒并检测，设施加锁、专人管理 |
| 变更报告 | 条件发生变化可能影响卫生安全的，及时向原发证机关报告 |

## 七、防误伤清单

1. **餐饮办的是食品经营许可证**，不是公共场所卫生许可证，窗口不同、条件不同
2. **迁址 ≠ 变更**，换地方要重新申请并重新核查检测
3. **延续逾期不能补办**，只能重新申办，期间不得经营
4. **检测报告超期**会让延续直接卡住，检测出报告需要时间，要提前排
5. **健康证过期**是现场核查与日常监管的高频处罚项，要建到期台账
6. **亮证经营**是最容易被罚的小事，证件要挂在醒目位置
7. **先照后证**：营业执照经营范围要先涵盖拟经营项目，再去办许可
8. **不要照抄别人的材料**：平面图、制度、检测结果必须与本场所实际情况一致
