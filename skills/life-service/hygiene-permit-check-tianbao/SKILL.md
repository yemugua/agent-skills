# 卫生许可证申办与延续核查（hygiene-permit-check）

办证前先解决一件事：**你要的到底是哪一张证**。三条线的发证机关、条件、有效期都不一样。

这个技能做四件事：**分线** → **核条件** → **算窗口** → **出清单**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 分清公共场所/餐饮/饮用水三条许可线 | ❌ 代替主管部门受理申请或作出许可决定 |
| 核查申办条件与材料是否齐备 | ❌ 代替现场核查与卫生检测 |
| 计算延续申请窗口与剩余有效期 | ❌ 保证一定拿到证或延续一定通过 |
| 给出变更、补办、注销手续清单 | ❌ 代替检测机构出具检测报告 |
| 提示健康证、卫生检测、亮证等日常要求 | ❌ 认定场所"实际符合卫生要求" |

**遇到以下情况，务必向当地主管部门窗口或行政审批服务局确认：**
- 经营业态跨类别（既有住宿又有餐饮、既有泳池又有浴室）
- 涉及集中空调通风系统、二次供水、自备水源
- 迁址、改扩建、变更主要经营项目
- 许可证已过期、被吊销或曾被不予许可
- 各地"告知承诺制""一照多址""一业一证"改革口径不同

**永远不要把"延续"和"变更"、"变更"和"重新申办"混为一谈。** 迁址一般要重新申请并重新核查检测，只办变更会白跑一趟。

## 二、先分清三条线

| 你要开的 | 需要的证 | 发证机关 |
|---|---|---|
| 宾馆、旅店、招待所、民宿 | 公共场所卫生许可证 | 卫生健康主管部门 / 行政审批局 |
| 公共浴室、桑拿、足浴 | 公共场所卫生许可证 | 同上 |
| 理发店、美容店 | 公共场所卫生许可证 | 同上 |
| 游泳场（馆） | 公共场所卫生许可证 | 同上 |
| 影剧院、歌舞厅、游艺厅、商场书店、候车室、展览馆、体育馆、公园 | 公共场所卫生许可证 | 同上 |
| **饭店、小吃店、饮品店、食堂** | **食品经营许可证** | **市场监督管理部门** |
| 集中式供水单位、二次供水管理单位 | 饮用水供水单位卫生许可证 | 卫生健康主管部门 |
| 涉水产品（管材、水处理剂、消毒设备）生产企业 | 涉水产品卫生许可批件 | 卫生健康主管部门 |

> 餐饮开的不是"卫生许可证"。跑错窗口是最常见的时间浪费。

## 三、申办条件（三类共用骨架 + 分类要点）

完整表在 `rules/permit_conditions.md`，骨架：

| 维度 | 公共场所 | 餐饮（食品经营） | 饮用水供水 |
|---|---|---|---|
| 场所 | 选址、建筑与功能分区符合卫生要求 | 与污染源保持距离、环境整洁 | 水源选择与防护符合卫生要求 |
| 设施 | 消毒间、通风、防蝇防鼠、公共用品消毒 | 冷藏、清洗消毒、防蝇防鼠、废弃物处理 | 净化消毒设施、检验室与设备 |
| 用品/水质 | 一客一换一消毒 | 餐具消毒、用水符合饮用水标准 | 涉水产品有卫生许可批件、水质达标 |
| 检测 | 空气、微小气候、采光照明、噪声、用品消毒效果；集中空调另测 | 自备水源需水质检测 | 出厂水、管网末梢水检测 |
| 人员 | 从业人员持健康证 | 食品安全管理人员 + 健康证 | 供管水人员持健康证 |
| 制度 | 卫生管理制度、专兼职管理人员 | 食品安全自查、培训制度 | 水质检测制度、应急预案 |

## 四、通用材料清单

1. 许可申请表（盖章或签字）
2. 营业执照或主体资格证明（**经营范围要先涵盖拟经营项目**）
3. 法定代表人（负责人）身份证明
4. 场所合法使用证明（房产证或租赁协议）
5. 场所平面布局图、卫生设施布局图
6. 卫生管理制度文本
7. 从业人员健康合格证明与名册
8. 卫生检测或评价报告（具备资质的机构出具）
9. 委托书与经办人身份证明（委托办理时）
10. 承诺书（部分地区实行告知承诺制）

分类补充材料见 `rules/permit_conditions.md`（游泳场所、住宿业、美容美发、餐饮、供水单位各有补充项）。

## 五、办理流程与时限

| 环节 | 口径 |
|---|---|
| 申请 | 窗口、政务服务网或当地政务 APP |
| 受理 | 材料齐全的当场或短时限内受理，出具受理凭证 |
| 审查 | 材料审查 + **现场核查**（关键环节） |
| 决定与发证 | 符合条件的准予许可，领取证件或电子证照 |
| 时限 | **以当地主管部门公示的法定时限与承诺时限为准**（各地差异较大） |
| 不予许可 | 书面告知理由，可依法申请行政复议或提起行政诉讼 |

**现场核查高频不通过项**：消毒间缺失或挪作他用；布草间与消毒间混用；防蝇防鼠不到位；健康证缺人或过期；检测报告超期或项目不全；平面图与现场不一致；集中空调无检测报告。

## 六、有效期与延续

| 类别 | 有效期（通行口径） |
|---|---|
| 公共场所卫生许可证 | 一般 4 年 |
| 食品经营许可证 | 一般 5 年 |
| 饮用水供水单位卫生许可证 | 一般 4 年 |

**以许可证上印的有效期为准。**

延续申请应在有效期届满**前**提出（常见为届满前 30 日内，部分地区要求更早或可在更早受理）。**逾期未延续的许可证失效，需重新申办，不能"补办延续"。**

建议节奏：届满前 90 天核对条件变化与人员 → 60 天安排卫生检测 → 45 天备齐材料 → 30 天提交申请 → 7 天查进度。

---

## 七、变更 / 补办 / 注销

| 情形 | 处理 |
|---|---|
| 单位名称变更 | 办变更（先改营业执照，名称须一致） |
| 法定代表人变更 | 办变更 |
| **经营地址变更（迁址）** | **一般需重新申请**，重新核查 + 重新检测 |
| 增加经营项目 | 办变更或重新申请，涉及新要求的需补检测 |
| 减少经营项目 | 办变更 |
| 证件遗失、损毁 | 办补办（按当地要求提交说明或声明） |
| 停止经营、主体终止 | 办注销，避免长期挂证 |

## 八、脚本用法

```bash
python scripts/permit_check.py --file 许可台账.json --as-of 2026-10-08 --out 核查结果.md
python scripts/permit_check.py --file 许可台账.json --lead-days 60
python scripts/permit_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 必填。许可台账 JSON |
| `--as-of` | 核查基准日，默认今天 |
| `--lead-days` | 延续申请提前天数，默认 `30`（**按当地要求调整**） |
| `--out` | 结果写入文件 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置自检（14 条断言） |

台账字段：

| 字段 | 说明 |
|---|---|
| `name` | 单位名称 |
| `type` | `public` / `food` / `water` |
| `expiry` | 有效期截止日（优先） |
| `issue` | 发证日期（无 expiry 时按 4/5/4 年推算，仅供参考） |
| `last_test` | 上次卫生检测日期（默认按 12 个月到期） |
| `test_interval_months` | 检测周期月数，可选 |
| `health_expiry` | 最近一批健康证到期日 |

输出四种状态：未到申请窗口 / 可以申请延续 / 届满当日 / 已失效（需重新申办），并列出检测报告与健康证到期情况。

> ⚠️ 提前天数与材料清单**以当地主管部门公示为准**，脚本只是把时间算出来。

## 九、人工确认（这步不能省）

- [ ] 许可证类别是否选对（餐饮是食品经营许可，不是卫生许可）
- [ ] 营业执照经营范围是否已涵盖拟经营项目
- [ ] 平面图、设施清单是否与现场一致
- [ ] 检测报告是否在有效期内、项目是否齐全、机构是否具备资质
- [ ] 从业人员健康证是否全员覆盖、是否在有效期内
- [ ] 集中空调、二次供水是否按规定检测与清洗消毒
- [ ] 迁址、改造是否按"重新申请"准备，而不是只办变更
- [ ] 延续材料是否按当地最新清单准备（清单会更新）

## 十、最常见的坑

**坑一：餐饮去办"卫生许可证"。**
餐饮核发的是食品经营许可证，由市场监管部门办理。跑错窗口，材料全白准备。

**坑二：迁址只办变更。**
换经营地址一般要重新申请、重新现场核查、重新检测，只办变更会被退回。

**坑三：延续拖到过期。**
有效期届满未延续的，证件失效，不能"补办延续"，只能重新申办，期间不得经营。

**坑四：检测报告卡住延续。**
延续通常要求在有效期内的检测报告，出报告需要时间，卡在最后一周一定来不及。

**坑五：健康证过期。**
现场核查与日常监管的高频处罚项。要建立到期台账，提前体检。

**坑六：平面图与现场不一致。**
照搬模板图纸，现场核查时对不上，直接不通过。

**坑七：证下来了就不管了。**
亮证经营、定期检测、健康证到期换证、公共用品消毒记录，这些是证后监管的常规检查项。

## 十一、边界与免责

- 本技能只做**条件核查与材料整理**，不代替主管部门受理、现场核查与许可决定
- 申办条件、材料清单、办理时限、有效期与延续提前天数**以当地主管部门公示为准**，本技能不引用具体条款号
- 各地告知承诺制、一业一证、一照多址等改革口径差异较大，需向当地窗口确认
- 本技能不得用于伪造检测报告、健康证明或申请材料
