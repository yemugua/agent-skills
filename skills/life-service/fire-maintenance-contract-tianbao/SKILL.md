# 消防设施维保服务管理（fire-maintenance-contract）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《消防法》与消防设施维护管理要求，生成清单：维保单位资质与合同、维保范围与频次、维保记录与报告、故障响应与修复时限、服务考核与更换机制。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 消防设施维保
- 维保合同
- 维保单位
- 消防维保记录
- 维保考核

## 三、工作流
1. 审查维保单位资质并签订合同
2. 明确维保范围与频次
3. 规范维保记录与报告
4. 约定故障响应与修复时限
5. 开展服务考核并设更换机制

## 四、核心内容（检查清单与判定）
消防设施应委托具备资质的机构维护保养；合同须明确范围、频次与响应时限，以记录报告和考核保障履约质量。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含维保单位资质与合同 | 资质 |
| Q2 | FAIL | 未含维保范围与频次 | 范围 |
| Q3 | WARN | 未含维保记录与报告 | 记录 |
| Q4 | FAIL | 未含故障响应与修复时限 | 响应 |
| Q5 | WARN | 未含服务考核与更换机制 | 考核 |

> 脚本 `fire-maintenance-contract_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python fire-maintenance-contract_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python fire-maintenance-contract_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
