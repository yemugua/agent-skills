# 动物伤人取证与索赔操作卡

## 一、被伤后 24 小时内做什么（顺序别乱）

- [ ] **立即就医**（轻重都要）——病历首页 + 诊断证明是最核心的证据
- [ ] **接种狂犬病疫苗**（必要时加免疫球蛋白、破伤风）——保存接种记录
- [ ] **拍照录像**：伤口特写 + 全身 + 现场环境，**带时间地点水印，保留原图**
- [ ] **报警 110**：说明"被动物咬伤"，要求**出警回执 + 询问笔录**
- [ ] **申请监控**：立刻书面要求物业/小区监控保留，**留存书面答复**（监控常 7~30 天就覆盖）
- [ ] **不要急着找对方理论**：先固定证据，人身安全优先

## 二、锁定饲养人

- [ ] 物业登记/养犬备案信息
- [ ] 居委会走访，请出具**书面说明**
- [ ] 邻居、保安**书面证言**（含联系方式）
- [ ] 监控视频（人物特征、遛狗时间、狗的牵引情况）
- [ ] 无主动物：投喂点、救助记录、居委会说明

## 三、治疗终结后

- [ ] 咨询**有司法鉴定资质的机构**（可先问当地司法局或法院立案窗口要名单）
- [ ] 准备：病历、影像资料、诊断证明、手术记录
- [ ] **不要过早鉴定**：等治疗终结、伤情稳定

## 四、赔偿项目清单（一张都别漏）

| 项目 | 凭证 |
|---|---|
| 医疗费（含疫苗、破伤风、换药、复查） | 病历 + 费用清单 + 发票 |
| 误工费 | 工资流水 + 单位误工证明 |
| 护理费 | 护理人收入证明 / 护工票据 |
| 交通费 | 就医、复诊、鉴定的票据 |
| 住院伙食补助 | 住院天数证明 |
| 营养费 | 医嘱或出院医嘱 |
| 残疾赔偿金 | **伤残等级鉴定**（有等级才有） |
| 精神损害抚慰金 | 依伤情与伤残酌定 |

## 五、四级维权路径

1. 直接协商 → **要书面协议**（项目、金额、支付时间、是否一次性了结后续治疗）
2. 居委会 / 物业 / 派出所调解
3. 12315 消费投诉（保留受理编号）
4. 诉讼（**侵权行为地或被告住所地法院**）

**另**：犬类违规饲养可向**当地农业农村部门或城管**举报。

## 六、和解协议的三个坑

1. **别只写"一次性了结"就放弃后续治疗**——后续手术、复查费用无法再主张。写清是否包含后续治疗。
2. **别在没鉴定前签终局协议**——等级未知就签字，可能低价和解。
3. **付款要有凭证**——每笔转账备注写"赔偿款"，留聊天记录与转账截图。

## 七、时限提醒

| 事项 | 时间 |
|---|---|
| 民事诉讼时效 | 3 年 |
| 监控保存 | 通常 7~30 天 |
| 狂犬病疫苗 | 越早越好，按程序全程接种 |
| 伤情鉴定 | 治疗终结、伤情稳定后 |
