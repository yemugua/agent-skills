# 动物伤人责任与索赔核查报告模板

> 报告由 `scripts/animal_injury_check.py` 自动生成。此模板供人工复核时对照。

## 报告结构（11 段）

| 段 | 标题 | 回答什么问题 |
|---|---|---|
| 一 | 结论摘要 | 能不能赔、能赔多少、卡在哪 |
| 二 | 责任主体与法律定性 | 谁担责、对方能拿什么免责理由 |
| 三 | 免责事由核查 | 经过里有没有把柄被对方抓 |
| 四 | 赔偿项目与金额测算 | 哪些项目能主张、已知支出多少、缺什么 |
| 五 | 伤情处置与取证 | 就医、疫苗、拍照、报警做了没 |
| 六 | 维权路径与调解 | 协商、调解、投诉、诉讼走了哪几步 |
| 七 | 时效与鉴定时机 | 还能不能告、什么时候做鉴定 |
| 八 | 证据清单与缺口 | 六类证据齐不齐 |
| 九 | 维权路径排序 | 第 1 步到第 7 步怎么走 |
| 十 | 证据缺口速查 | 每个缺口怎么补 |
| 十一 | 待办补正动作 | 可直接照着做的动作 |
| — | 边界与纪律 | 免责与口径说明 |

## 四态判定口径

| 状态 | 含义 | 处理方式 |
|---|---|---|
| **通过** | 条件满足、无隐患 | 无需动作 |
| **有风险** | 可主张但有隐患或对方有抗辩空间 | 按说明提前准备 |
| **不通过** | 找不到责任主体等硬障碍 | 必须先解决 |
| **待补正** | 信息未填或填了无法判断 | **未填一律不算通过** |

## 复核要点

1. **责任主体**是否已锁定（这是能不能起诉的前提）
2. **事发经过**里有没有"逗狗""翻越""未经允许"这类被对方利用的表述
3. **已支出金额**是否逐项对应票据，合计是否与票据一致
4. **是否已做鉴定**——未鉴定则没有残疾赔偿金，赔偿预期要下调
5. **监控是否已申请保全**（时效极短）
6. 报告里所有"不通过"项在第九段路径里是否有对应动作
7. 金额是否标注为**预估**（必须以票据与法院认定为准）
