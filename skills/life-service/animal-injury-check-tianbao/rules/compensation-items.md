# 赔偿项目、口径与鉴定时机

## 一、可以主张的赔偿项目

| 项目 | 依据凭证 | 常见口径 |
|---|---|---|
| **医疗费** | 急诊/住院病历、诊断证明、费用清单、发票 | 实际支出，含检查、药费、手术、住院 |
| **误工费** | 工资流水、单位误工证明、完税凭证 | 按实际减少的收入；无固定工作的可参考当地居民人均可支配收入 |
| **护理费** | 护理人员收入证明、护工费票据 | 按护理人员实际收入或护工标准 |
| **交通费** | 打车、公交票据 | 就医、复诊、鉴定往返 |
| **住院伙食补助** | 住院天数证明 | 按当地标准 |
| **营养费** | 医嘱或出院医嘱 | 按医嘱，酌情 |
| **残疾赔偿金** | **伤残等级鉴定文书** | **有无此项完全取决于鉴定等级** |
| **精神损害抚慰金** | 伤情与伤残情况 | 酌定，一般伤残或重伤情形可主张 |

> 未构成伤残的，通常**没有残疾赔偿金**，但医疗费、误工费等实际损失照常主张。

## 二、伤情鉴定：决定赔偿上限的关键

**什么时候做**：**治疗终结、伤情稳定之后**。过早鉴定可能因后续恢复导致评估偏差；过晚可能因完全恢复而评不出等级。

**去哪儿做**：
- 具备司法鉴定资质的社会司法鉴定机构（出具的文书法院更容易采纳）
- 部分案件可由**公安机关或法院委托**，出具意见书
- 咨询当地司法局或法院立案窗口，**了解本地受理的鉴定机构名单**

**需要什么**：病历、影像资料、诊断证明、手术记录，由鉴定机构审查伤情与因果关系。

**等级影响**：伤残等级直接决定残疾赔偿金数额，也影响精神损害抚慰金的酌定空间。**等级评定是民事诉讼中常见的专业判断，结论以鉴定机构为准**。

## 三、金额怎么算才算得靠谱

1. **票据优先**：所有主张都要有票据或符合法律规定的证明材料。
2. **不要漏项**：受伤后除了医疗费，还有误工、护理、交通、伙食、营养；构成伤残再加残疾赔偿金与精神损害抚慰金。
3. **保险也要算**：饲养人可能投保了动物责任险或第三方责任险，**有保险的可以直接向保险公司索赔**，不必先和主人扯皮。
4. **别一次性放弃后续项目**：伤情可能有后遗症、可能需要二次手术，**和解协议要写清是否包含后续治疗**，否则后期再主张会很难。

## 四、哪些钱容易漏主张

| 容易漏 | 说明 |
|---|---|
| 狂犬病疫苗与免疫球蛋白 | 属于医疗必需，通常计入医疗费 |
| 破伤风注射 | 同上 |
| 换药、拆线、复查 | 都是医疗费的一部分，票据要留全 |
| 护理人员请假损失 | 需护理人员收入证明 |
| 因伤产生的交通与陪护支出 | 票据或记录 |
