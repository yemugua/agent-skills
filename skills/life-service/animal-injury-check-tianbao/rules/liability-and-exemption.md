# 责任主体认定、免责事由与特殊责任

## 一、责任主体：先锁定"谁养的、谁管的"

按《民法典》侵权责任编，**饲养的动物造成他人损害的，由动物饲养人或者管理人承担侵权责任**。

| 情形 | 责任指向 | 怎么找 |
|---|---|---|
| 有明确主人（登记、物业档案） | 该饲养人 | 物业登记、居委会走访、邻里指认 |
| 主人不承认但有固定住所 | 该饲养人 | 监控、门牌、走访记录 |
| **无主 / 流浪动物** | **原饲养人**；能查明管理人时由管理人承担 | 投喂点、救助记录、监控 |
| 动物经营者（犬舍、宠物店、繁育者） | 经营者 | 交易记录、营业执照、疫苗备案 |
| 动物园、景区、公园 | 管理者（更高的安全义务） | 园区公告、监控、工作人员证言 |
| 动物被他人代为喂养（代管） | 实际管理人 | 邻里证言、物业记录 |

**找不到人的破局办法**：
1. 请**居委会出具书面说明**（含走访情况与可能的饲养人线索）
2. 请**物业提供监控**并留存说明（注意监控保存期限，通常 7~30 天，**要尽快申请**）
3. 申请**公安机关协助查找**，虽不必然立案，但可留下记录
4. 邻居、物业保安的**书面证言**也是证据

## 二、三类免责事由（必须由饲养人举证）

| 免责/减责事由 | 含义 | 实务要点 |
|---|---|---|
| **受害人故意** | 受害人故意挑逗、激怒、扑打动物致伤 | 举证难度高，**"我只是摸了一下"通常不够** |
| **受害人重大过失** | 未经允许进入养犬区域、翻越围栏、明确警示仍靠近 | 只造成**减轻责任**，不是当然免责 |
| **第三人过错** | 他人挑逗、驱赶、投喂动物 | **应把第三人列为共同被告**，不能只找主人 |

**不是免责事由的常见说法**：
- "它平时很温顺 / 从没咬过人" —— 动物性格不能免除责任
- "我牵绳了 / 我有备案" —— 尽到管理义务只影响过错程度，**不免除赔偿责任**
- "我赔了医药费" —— 补偿部分费用不免除其他赔偿项目
- "它可能是流浪狗" —— 举证责任在主张的一方，需先查清来源

## 三、特殊责任类型（责任更重、举证压力更小）

| 类型 | 说明 | 额外动作 |
|---|---|---|
| **禁养烈性犬等危险犬只** | 饲养本身违反管理规定 | 向**当地农业农村部门或城管**举报违规饲养；可作为加重责任依据 |
| **动物经营者** | 经营者有更强的安全与查验义务 | 主张经营者责任，注意留存交易与疫苗记录 |
| **动物园 / 园区** | 管理者安全保障义务更高 | 留存园区公告、警示牌、监控；注意是否有免责提示牌 |
| **无主 / 流浪动物** | 由原饲养人承担 | 举证较难，**先请居委会与救助部门出具记录** |

> 各地对"禁养犬只"的具体种类规定不同（常见为烈性犬、部分大型犬），**以当地农业农村、城管部门公布的目录为准**。
