# 动物伤人责任与索赔核查

被狗咬、被猫抓、被动物踢伤之后，最容易吃亏的两件事：**证据没留住**（伤口愈合、监控覆盖、对方不承认）和**没做鉴定就谈赔偿**（不知道自己能主张到什么等级）。

## 它管什么

| 常被问 | 它给的结论 |
|---|---|
| "找不到主人怎么办" | 锁责任主体的四种路径 + 请居委会出书面说明 |
| "他说是我自己逗狗" | 逐条对照三类免责事由，看对方能站住哪一条 |
| "我能主张哪些钱" | 八个赔偿项目 + 对应凭证 + 已识别金额 |
| "什么时候做鉴定" | 治疗终结、伤情稳定后；过早点评不准、过晚评不出 |
| "监控还在不在" | 监控保存期极短，第一时间书面申请保全 |

## 它不管什么

- 不替你打官司、不代你提交材料
- 不预测公安机关是否立案、法院支持多少金额
- 禁养犬只种类与赔偿标准**以当地农业农村、城管部门口径为准**

## 怎么用

1. 填 `templates/动物伤人信息采集表.md`（关键四项：事发经过、是否就医、已支出金额与项目、是否报警）
2. 跑 `scripts/animal_injury_check.py`，输出十一段核查报告
3. 照第九段路径做：**先止损 → 锁定饲养人 → 治疗终结后鉴定 → 再谈赔偿**

> 监控通常只留 7~30 天。要调监控，第一天就去。
