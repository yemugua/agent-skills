# 动物伤人责任与索赔核查

被动物伤了最常见的两个失误：**没及时留证据**（伤口愈合、监控覆盖、对方不承认），和**没做鉴定就谈赔偿**（不知道自己能主张到什么等级，白白按低标准和解）。

## 什么时候用

- 被狗咬伤、被猫抓伤、被动物踢伤、踩伤
- 对方说"是你自己逗狗""你未经允许进院子"，责任被推给受害人
- 找不到主人，或者对方是流浪动物、无主动物
- 治疗结束不知道能主张哪些赔偿，房东/邻居/物业都不肯出面
- 对方一直不认账、不接电话、说"你也去告我"
- 想知道什么时候该做伤残鉴定、鉴定找谁做

## 怎么做

**第 1 步**：复制 `templates/动物伤人信息采集表.md` 填写（事发经过、是否就医、已支出金额与项目、是否报警是关键项）。

**第 2 步**：跑脚本

```bash
python scripts/animal_injury_check.py 采集表.md --base 2026-10-05 --out 核查报告.md
```

**第 3 步**：按第九段路径走——**先止损（就医、疫苗、拍照、报警）→ 锁定饲养人 → 治疗终结后做鉴定 → 再谈赔偿**。

## 三句话定性的核心规则

1. **责任原则很明确**：按《民法典》侵权责任编，**饲养的动物造成他人损害，由饲养人或管理人承担侵权责任**。也就是说**找不到主人时最难，但"找不到"不等于没人负责**——要靠物业登记、居委会走访、监控锁定。
2. **免责只有三条路**：受害人故意、受害人重大过失、第三人过错。**"它平时很温顺""我牵绳了"都不算免责事由**；而且免责要由饲养人自己举证。
3. **鉴定决定赔偿上限**：能不能拿到伤残等级，直接决定有没有**残疾赔偿金**。**治疗终结、伤情稳定后尽早做鉴定**，拖到完全恢复可能评不出等级。

## 边界与纪律

- 依**通用规则**整理，**不替代律师意见**
- **禁养犬只种类、赔偿标准与当地管理规定差异大**，以当地农业农村、城管等部门口径为准；犬类伤人可向当地农业农村部门或城管举报违规饲养
- 报告里的金额是按已填票据汇总的**预估**，**不得作为索赔主张的最终数额**
- 不预测公安机关是否立案、法院是否支持具体金额
- **未填的一律不算通过**，只按已填内容判断
- 涉及病历、伤情照片等隐私信息，本地处理，不要外发
