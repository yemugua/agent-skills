# 宠物狗训练（dog-training-basics）

狗学不会指令，**八成不是狗笨，是人的训练节奏错了**：一次练太久、罚得太晚、跳过了前置步骤、还没学好就叫名字过去骂它。其中「叫名字过去惩罚」一条，能在一周内把召回练废。

这个技能做三件事：**排顺序 → 定时长 → 卡时机**。

---

## 一、硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出基础服从训练的阶段顺序与进阶口径 | ❌ 进行攻击行为的矫正（咬人、咬狗、护食升级） |
| 给出按犬龄划分的单次时长与每日频次 | ❌ 使用或建议体罚、电击项圈、针刺项圈、强行按压 |
| 给出奖励时机、标记词、响片的操作口径 | ❌ 判断犬的行为是否由疾病或疼痛引起 |
| 给出常见手段的禁止清单与安全替代做法 | ❌ 保证任何犬只都能达到某一训练效果 |
| 给出何时必须转交专业训犬师的判断线 | ❌ 替代兽医对异常行为的诊断 |

**必须转交专业训犬师（或兽医）的情况**

- 出现过咬人、咬破皮肤、攻击其他犬，或已有咬脸、咬喉咙目标的扑咬
- 护食、护窝、护主人的资源守护行为已升级到咆哮或追咬
- 分离焦虑迹象明显：离家后持续嚎叫、破坏门窗、自伤舔爪至破溃
- 突然出现的行为改变（原来会的动作不做了、出现定向障碍、无故攻击），先去兽医排除疼痛或疾病
- 多犬家庭的持续打斗，或有幼童在场 + 犬表现出回避与僵住

## 二、什么时候用

| 用户说法 | 用不用 | 说明 |
|---|---|---|
| 「怎么教狗坐下」 | ✅ 用 | 走完整五个动作的步骤，先看有没有建立标记词 |
| 「狗叫不回来」 | ✅ 用 | 召回要单独拆成四小步，且必须检查有没有误惩罚召回 |
| 「遛狗总是拽着我跑」 | ✅ 用 | 随行暴冲，室内离线位 → 三步 → 户外转移干扰 |
| 「狗总是扑人」 | ✅ 用 | 属于后置替换行为，不是单纯压住别动 |
| 「幼犬多大开始训练」 | ✅ 用 | 到家当天就能开始，但按幼犬时长口径折算 |
| 「狗咬了人怎么办」 | ❌ 不用 | 攻击行为必须转交专业训犬师 |
| 「狗突然变傻了不爱动」 | ⚠️ 部分 | 只给就医判断清单，先看兽医排查疼痛与疾病 |

## 三、完整工作流

1. **确认基础状态**：犬龄、疫苗与免疫接种进度（不确定就问兽医）、是否已排除疼痛问题。
2. **检查是否已建立标记**：响片或标记词（如「好」）与食物奖励的配对是否完成。**没有完成配对就练动作，等于跳过地基。**
3. **按阶段顺序排**：注意力 → 坐下 → 趴下 → 等待 → 随行 → 召回。每一步达标才进下一步。
4. **定时长与频次**：按犬龄取单次分钟数与每日次数，短而多次，不要一次练到狗走神。
5. **卡奖励时机**：目标行为出现后 2 秒内必须给出标记加奖励，超过就强化不到这个行为。
6. **规定失败降级规则**：同一提示重复三次仍无响应，降回上一步的难度重来，不许加码重喊。
7. **安排环境递进**：室内安静 → 室内带干扰 → 院子或楼道 → 户外。直接上户外是最常见的失败点。
8. **核对**：用 `--file` 跑一遍训练计划，先看有没有踩禁止手段，再看节奏和时长。

## 四、核心规则说明

**设计训练计划前，必须先读这两个文件，不要凭印象写：**

- `rules/基础服从训练步骤表.md` —— 六个阶段各自的分解步骤、达标标准、常见错误动作
- `rules/奖惩时机与安全红线.md` —— 奖励窗口、每日节奏、禁止手段清单、降级规则、就医判断线

要点三条：

1. **标记的准时性比奖励本身重要**。奖励晚给也没关系，但标记必须落在行为发生的那一刻，晚了就标记到了下一个行为。
2. **拆一动作成多小步**。坐下不是一个动作，是「看人的脸 → 抬手引诱至坐下 → 标记 → 给食 → 加手势 → 加口令 → 加距离 → 加时长 → 加干扰」。跳过前面几步直接喊口令，狗当然听不懂。
3. **召回永远不能被惩罚**。叫回来之后不许骂、不许拽、不许当场惩罚。叫来就放回去玩——这才是让召回稳固的做法。

## 五、脚本用法

```
python scripts/dog_training_plan.py --selftest
python scripts/dog_training_plan.py --file plan.json
```

输入字段：

| 字段 | 说明 | 示例 |
|---|---|---|
| age_months | 月龄 | 4 |
| minutes_per_session | 单次训练分钟 | 8 |
| sessions_per_day | 每天训练次数 | 3 |
| target | 当前训练目标 | 「坐下」「召回」「随行」 |
| done_stages | 已完成阶段列表 | 见规则文件 |
| marker_established | 是否已建立标记词 | true |
| reward_delay_sec | 从行为到给奖励的延迟秒数 | 1.5 |
| repeat_on_fail | 同一口令无响应时的重复次数 | 3 |
| tools | 使用的器具列表 | 「响片」「零食包」「胸背带」 |
| env | 训练环境 | 「室内安静」「户外」 |
| punish_recall | 召回后是否惩罚 | false |

结论分三档：**先处理**（踩了禁止手段、时长或时机超硬口径、跳过前置阶段）、**待确认**（信息不足）、**可照此执行**。存在真实缺陷时，即使信息也不完整，仍判先处理。

结果写入 `scripts/_last_result.txt`，每条不合格带原因。

## 六、人工确认清单（这步不能省）

- [ ] 已确认犬没有疼痛或疾病问题（尤其是行为突然改变时）
- [ ] 标记词或响片的配对已完成
- [ ] 单次时长与每日次数在犬龄对应区间内
- [ ] 奖励延迟不超过 2 秒
- [ ] 前置阶段已达标，没跳步
- [ ] 器具清单里没有任何禁止项
- [ ] 召回后的处理是放回去玩，不是惩罚
- [ ] 环境递进是从室内安静开始，不是在户外起步
- [ ] 同一口令重复不超过 3 次，超了就降级重来

## 七、最常见的坑

1. **叫名字过去惩罚**。狗把「来」和坏事连起来，两周内召回垮掉。正确做法是叫来就奖励，就算它刚才做错事也要先放过。
2. **惩罚时机不对**。事过三分钟再骂，狗完全不知道为什么被骂，只学到「主人回家有时很可怕」，进而发展成躲藏与防御。
3. **一次练三十分钟**。狗的注意力撑不住，后半段全在练习「不看你」，等于在练走神。幼犬单次 5 到 10 分钟就够。
4. **直接上户外这种高干扰环境**。在客厅都做不安稳的动作，到小区里必然失灵。环境的干扰级别必须逐步提升。
5. **口令和手势同时给却只夸手势**。狗学的是那个同时出现的手势，去掉手势就不灵。
6. **重复喊口令十遍**。喊到第五遍狗已经学会「前四遍可以不当回事」，口令被自己稀释掉了。
7. **只看结果不看标记时机**。给了很多零食却没效果，原因是标记晚了半秒，强化到了下一个动作。
8. **把电击项圈当成提效手段**。短期压住行为，长期制造恐惧与防御性攻击，且掩盖了真正的问题。
