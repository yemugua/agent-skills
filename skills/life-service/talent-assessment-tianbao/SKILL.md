# 人才测评（talent-assessment）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：生成人才测评清单：测评维度/模型设计、工具选择（胜任力/心理/情景/笔试）、信效度与公平、结果应用（录用/发展）。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 人才测评
- 员工测评
- 测评工具
- 胜任力测评
- 心理测验
- 情景模拟

## 三、工作流
1. 设计测评维度/模型
2. 选择测评工具（笔试/面试/系统）
3. 保证信度效度与公平
4. 实施与结果判定
5. 结果应用于录用/发展

## 四、核心内容（检查清单与判定）
人才测评须明确维度与工具，重视信度（一致性）与效度（预测力），并遵循公平非歧视原则，结果应服务于录用与发展。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未设计测评维度/模型 | 维度 |
| Q2 | WARN | 未选测评工具（笔试/面试/测评系统） | 工具 |
| Q3 | FAIL | 未考虑信效度与公平 | 效度 |
| Q4 | WARN | 未含结果应用（录用/发展） | 应用 |

> 脚本 `talent-assessment_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python talent-assessment_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python talent-assessment_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
