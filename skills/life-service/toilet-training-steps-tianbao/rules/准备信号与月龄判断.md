# 幼儿如厕训练准备信号与月龄判断

## 一、准备信号逐项清单（8 项）

每项只记「是 / 否 / 不确定」，不要凭印象。**建议至少 3 项明确为「是」并持续 2 周以上再正式开始**。

| 编号 | 信号 | 怎么观察（可照做的判定口径） |
|---|---|---|
| S1 | 能自己走稳 | 能独立走上台阶或坡道不扶扶手，行走时不常踉跄 |
| S2 | 能表达尿意或便意 | 会用词、动作或表情表示，如「尿尿」「要拉」「指着裤子」，不一定说完整句子 |
| S3 | 能自己坐下并站起来 | 借助马桶圈或踏凳能自己坐到位、站稳后转身，不需要抱 |
| S4 | 对坐便器有兴趣 | 看到大人如厕会模仿，主动要求坐马桶圈，不是持续强烈抗拒 |
| S5 | 保持干燥的时间变长 | 白天尿布连续保持干燥 2 小时以上，且间隔在拉长 |
| S6 | 能解开并提上裤子 | 能配合完成拉裤子的动作（有时需协助但不抗拒） |
| S7 | 排便时间相对规律 | 大便时间大致可预期，如早餐后或固定的某个时段 |
| S8 | 能听懂简单指令 | 能听懂「去尿尿」「坐马桶上」这类一句话指令并照做 |

**判定口径**：
- 8 项中 ≥ 6 项为「是」→ 信号充足，可以开始
- 8 项中 4-5 项为「是」→ 部分具备，先做 2-4 周准备期（只练 S3、S6、S8，不穿裤子练坐便）
- 8 项中 ≤ 3 项为「是」→ 不具备，继续观察或先咨询儿科医生，**不要强行开始**

**注意**：S1-S3 与 S5 常是最关键的三项。若 S2（表达尿意便意）长期为「否」，且已满 3 周岁，请按就医红线处理。

## 二、月龄参考区间

| 区间 | 常见情况 |
|---|---|
| 18 个月以下 | 极少开始训练。此时多为反射性排泄，控制括约肌的神经发育尚未成熟 |
| 18-36 个月 | 常见开始区间（男童普遍偏晚，女孩普遍偏早）。这是**参考区间，不是达标线** |
| 36 个月以上仍未表达排泄意愿 | 建议就诊评估，不建议继续在家加压训练 |
| 已入托幼且需要穿尿裤 | 常见且正常，托幼园所通常仍要求穿可自行脱换的裤子，不必强行戒 |

**必须写明的免责口径**：月龄只是参考，是否开始以准备信号为准；**以儿科医生评估和最新版儿科发育相关指南为准**。不得用「X 岁前必须戒掉」制造焦虑。

## 三、开始前的环境准备（照着做）

1. **坐便器或马桶圈**：稳固不晃，成年人站在旁边能扶稳孩子，孩子脚能平踩地面
2. **踏凳**：小马桶必备，两级踏凳足够让孩子脚踏实
3. **防滑**：坐便器周边铺防滑垫，光脚或棉袜不滑
4. **周边无硬物**：洗手台、马桶水箱、暖气片角部包软垫
5. **固定如厕位**：家里固定一个位置，不到处放小马桶，减少混乱
6. **湿度与通风**：室温不过高，衣物可脱到腰部不会冷
7. **易脱衣物**：裤子选前开扣或腰围宽松款，尿裤换成可自行提拉的内裤过渡

## 四、准备期 2-4 周做什么（只有部分具备时）

- 每天在固定时段（如早餐后、午睡后）带孩子坐马桶圈 3-5 分钟，不要求成功
- 不穿裤子练习：在家里换尿裤时就说「尿尿了，换裤子」，让孩子知道身体信号和换裤子的关系
- 让孩子看大人如厕，不评论、不指导动作细节
- 全程不批评不催促，可以说「等一会儿尿尿了我们就坐马桶」

## 五、常见误区（本技能不采用）

| 误区 | 为什么不采用 |
|---|---|
| 按月龄硬开始 | 月龄不代表准备度，强行开始会拉长周期 |
| 追求速成 | 「几天戒掉」的承诺不成立，挫败感影响亲子关系 |
| 打屁股、羞辱、惩罚 | 破坏排便意愿，可能诱发憋便与恐惧 |
| 把屎把尿 | 干扰孩子学习识别自身排泄信号，可能致尿频、便秘、脱肛 |
| 限制饮水减少尿裤子 | 脱水与尿路感染风险 |
| 深夜反复叫醒把尿 | 破坏睡眠，对夜尿本身无改善，除非有医生明确建议 |
| 便秘当成「不肯训练」 | 需就医排查，不能靠训练解决 |

## 六、必须记录的可测量指标

- 每天如厕尝试次数、成功次数
- 每天尿裤/尿湿发生次数与大致时段
- 白天最长连续干燥小时数（每周对比，看是否在拉长）
- 是否有排便困难、哭闹、憋便行为
- 家长使用过的禁止性话术次数（目标为 0）
