# 幼儿如厕训练步骤与准备判断

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 逐项核查准备信号并给出「可以开始 / 再等等 / 建议就诊评估」三档判断 | 判断孩子是否存在发育迟缓、自闭症谱系等疾病并下诊断结论 |
| 给出四阶段训练排期（白天定时坐便 → 提示语 → 夜间把尿 → 渐进撤尿布） | 给出任何用药、补充剂或「延迟排泄」类药物方案 |
| 提供各阶段的目标、时长参考与记录表 | 承诺「几天见效」「保证一个月戒掉」 |
| 给出倒退期的识别口径与处理话术 | 主张打屁股、羞辱、比较、惩罚性训斥 |
| 说明月龄常见区间并注明以儿科医生评估为准 | 用月龄单一标准断言「必须 X 岁才能开始」 |
| 提示环境安全、坐便器选择与防滑要点 | 推荐具体品牌、产品型号或商业课程 |

**就医红线（出现任一条，停止自行训练并尽快咨询儿科医生；情况紧急的直接就医）**

- 已满 3 周岁仍完全无法表达尿意便意，且对坐便器持续强烈抗拒（超过 4-6 周）
- 排尿排便明显费力、尿线细弱、排尿疼痛、异味明显、泡沫尿 —— 可能提示泌尿系统问题，先就医
- 排便干硬带血、排便疼痛哭闹、长期便秘或长期腹泻 —— 先就医排查
- 训练后出现明显憋尿憋便、尿路感染症状（发热、尿频、尿急、排尿灼痛）
- 已入托幼后长期憋尿导致尿裤使用，与其他发展项目（语言、社交、运动）明显落后同步出现
- 任何怀疑神经系统发育问题、感觉异常、疼痛回避的表现
- 孩子对排尿排便表现出恐惧、强烈抗拒到影响正常生活

**绝对禁止的「训练方法」**：把屎把尿、按压腹部助排、强行固定住孩子、打屁股、羞辱性语言、限制饮水以减少尿裤、「不写尿裤子就不许出门」式惩罚。这些做法可能造成憋尿、便秘、脱肛、恐惧和排便障碍。

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「孩子多大可以开始戒尿不湿」 | 用，按准备信号判断 |
| 「如厕训练具体步骤是什么」 | 用，给四阶段排期 |
| 「半夜要不要把尿」 | 用，给夜间方案与判断依据 |
| 「孩子 2 岁半还不会说要尿尿」 | 用，先看信号再谈方法；并提示何时该就诊 |
| 「训练了一阵又尿裤子了」 | 用，倒退期处理 |
| 「怎么让孩子快点学会」 | 用，明确说明不可加速，给可加速的做法 |
| 「要不要买坐便器」 | 用，给环境要点，不推荐品牌 |
| 「孩子便秘要不要用开塞露」 | 不用，用药与诊断由医生决定 |
| 「是不是太晚了，再不训练会不会有问题」 | 用，给月龄区间与个体差异说明 |

## 三、完整工作流

1. **先问月龄与当前状态**：孩子月龄、是否已在托幼、用的是尿布还是尿裤、目前白天保持干燥的最长时间。
2. **逐项核查准备信号**：按 `rules/准备信号与月龄判断.md` 的 8 项信号打分，判断属「信号充足 / 部分具备 / 不具备」。
3. **排就医红线**：逐条核对，命中即转诊，不给训练方案。
4. **选定起始阶段**：信号充足则从「白天定时坐便」起步；部分具备则先做两周准备期。
5. **排四阶段计划**：按 `rules/训练步骤与倒退期处理.md` 生成阶段目标、每阶段观察指标与预计周期。
6. **给出夜间方案**：是否把尿、时机、逐步撤除路径。
7. **建立记录表**：用 `templates/如厕训练记录表.md` 记录日期、成功次数、尿裤时段、倒退事件。
8. **设定复评时点**：设定 4 周复评，明确「到期未进步」的处理是放宽周期还是转诊。

## 四、核心规则与要件库

生成任何训练方案前，**必须先读**：

- `rules/准备信号与月龄判断.md`：8 项准备信号、月龄参考区间、常见误区。
- `rules/训练步骤与倒退期处理.md`：四阶段步骤、夜间把尿、退步期处理、就医转交口径。

不得用「训练不成功」给家长施压，不得承诺时长。不得推荐具体产品或商业课程。

## 五、脚本用法

```
python scripts/toilet_training_plan.py --file case.json
python scripts/toilet_training_plan.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`age_months` 月龄，`signals` 准备信号标记列表，`dry_hours` 白天最长干燥小时数，`night_vomit` 是否有夜间把尿习惯，`regress_days` 已训练天数 |
| `--stage` | 只输出某一阶段计划：`1` 到 `4` |
| `--json` | 以 JSON 输出 |
| `--out` | 结果写入指定文件，默认 `scripts/_last_result.txt` |
| `--selftest` | 运行自检 |

脚本输出准备度判定、建议起始阶段、阶段排期与红旗提示。**脚本不输出任何药物或剂量。**

## 六、人工确认清单

- [ ] 月龄已确认，未用月龄单一标准做结论
- [ ] 8 项准备信号已逐条核实，不是凭印象
- [ ] 就医红线已逐条核对
- [ ] 已明确告知不催、不骂、不羞辱、不打屁股
- [ ] 已排除把屎把尿、强行固定、按压助排等有害做法
- [ ] 坐便器稳固防滑、脚下有踏凳、周围无硬物
- [ ] 记录表已建立，复评时点已写入日历
- [ ] 家长已理解倒退期正常，不会因一两周反复而责骂孩子
- [ ] 已说明何时该转诊儿科，而不是继续加压训练

## 七、最常见的坑

1. **按月龄硬开始**：18 个月开始训练但孩子一个信号都没有，结果拖半年还落下一堆坏习惯。信号比月龄重要。
2. **追求速度**：一两周就想戒掉，孩子没准备好就退回尿裤，最后大人孩子都挫败。倒退是常态不是失败。
3. **打屁股和羞辱**：「不听话就打」「再尿裤子就没饭吃」短期可能见效，长期破坏亲子关系和排便意愿，还可能诱发憋便。
4. **把屎把尿**：定时把尿、按压腹部助排，可能造成尿频、便秘、脱肛，且孩子学不会识别自己的尿意信号。
5. **夜间不把尿也不设限**：睡整觉的孩子继续用尿布很正常，不必强行半夜叫醒，反而破坏睡眠。
6. **用喝水多少来控制尿裤子**：限制饮水导致脱水、尿路感染风险。
7. **忽略便秘**：大便干硬排不出，孩子怕疼而憋便，憋便又加重便秘，形成恶性循环，还常被误当成「不肯训练」。
8. **两家标准不一致**：爸妈一套、爷爷奶奶一套，孩子在两套规则间来回，彻底学不会。以一位主要照顾者为主，另一位同步。
9. **把「不坐马桶」当成抗拒**：坐便器太高、没有踏凳、腿够不到地，都会导致坐不住，这是环境问题不是态度问题。

## 八、边界与免责

本技能提供幼儿如厕训练的准备信号判断与家庭训练步骤参考，**不提供任何药物、诊断结论或发育评估结论**。月龄区间仅为常见参考，个体差异很大，**以儿科医生评估和最新版儿科发育相关指南为准**。出现排尿排便疼痛、血便、尿路感染症状、长期无法表达排泄意愿、或与其他发育项目同步落后时，必须就诊评估。本技能不替代儿科诊疗。
