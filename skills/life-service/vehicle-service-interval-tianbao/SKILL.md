# 汽车保养周期与项目核对（vehicle-service-interval）

保养这件事最容易出问题的不是漏做，而是**被安排做一堆用不上的项目**。知道每个项目是干什么的，比记住周期表更重要。

这个技能做四件事：**判时机** → **认项目** → **调工况** → **留记录**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 说明按里程还是按时间的判定逻辑 | ❌ 给出具体周期数字 |
| 说明常见保养项目的作用 | ❌ 判断某个具体项目的必要性 |
| 说明不同工况的调整方向 | ❌ 指导用户拆装或改装车辆 |
| 说明 4S 店与独立店的取舍 | ❌ 评价具体品牌或门店 |
| 说明保养记录的作用 | ❌ 承诺记录能替代实际车况检查 |

**具体保养周期、项目与用量一律以车辆说明书和厂家要求为准**，本技能只讲**判定逻辑与项目作用**，不写死任何周期数字，也不引用条款号。不同车型、不同发动机类型的差异很大，抄别人的周期表很容易出问题。

**遇到以下情况，咨询厂家或专业维修人员：**

- 车辆出现异常症状（异响、抖动、报警、油耗异常升高）
- 使用的是非常规燃料或机油标号
- 车辆经过重大维修或改装后
- 二手车首次保养，车辆使用状况不明

## 二、周期判定：按里程还是按时间

**核心规则：里程与时间双轨判定，先到者为准。**

| 判定维度 | 为什么重要 |
|---|---|
| 里程 | 反映机械磨损与油液消耗 |
| 时间 | 反映油液自然劣化、橡胶件老化、腐蚀 |

**两种情况都常见**：

- **里程到了但时间没到**：短途行驶的车辆常见，机械磨损可能不大但油液已在劣化
- **时间到了但里程没到**：长途少的车辆或新车常见，里程很低但橡胶件与油液已到周期

**核心口径**：**只按里程保养的车辆，短途行驶容易让油液超期使用；只按时间保养的车辆，里程已经很高却没换，也是问题。** 两个维度要一起看，**先到者为准**。

**具体周期数值以车辆说明书和厂家要求为准。** 不同机型的要求差别很大，本技能不给数字。

## 三、常见保养项目与作用

**知道每个项目是干什么的，才能判断它有没有必要。**

| 项目 | 主要作用 | 常见周期口径 |
|---|---|---|
| 机油 | 润滑、清洁、带走磨损颗粒与热量 | 里程与时间先到者为准 |
| 机滤 | 拦截机油中的颗粒杂质 | 通常与机油同步或更频繁 |
| 空滤 | 过滤进入发动机的空气 | 通常按里程，尘土多的地区更频繁 |
| 汽滤 | 过滤燃油中的杂质 | 通常按里程 |
| 刹车 | 制动功能，涉及安全 | **按实际磨损检查，不是固定周期** |
| 轮胎 | 抓地与承载 | **按磨损状态与年限，不是固定周期** |
| 冷却液 | 带走发动机热量、防冻防沸 | 通常按里程与时间，部分车型需定期更换 |
| 变速箱油 | 润滑与液压传动 | 按里程与时间，自动变速箱通常更敏感 |
| 刹车油 | 制动液压传递 | 通常按时间为主，含水量会随时间上升 |
| 火花塞 | 点火 | 按里程，不同类型差异很大 |
| 雨刷 | 视野 | 按使用状态，橡胶会老化 |

**两个重要区别**：

- **刹车和轮胎属于安全件，按实际状态检查，不是等到周期到了才看**
- **刹车油更看时间，含水量随时间上升是主要劣化因素**

## 四、不同工况的调整

**同一辆车，用途不同，周期可能要调。**

| 工况 | 影响 | 调整方向 |
|---|---|---|
| 长期短途 | 里程跑不到，发动机无法充分热透 | **可能需要缩短周期** |
| 频繁拖挂 | 负荷加重 | 可能需要缩短周期 |
| 恶劣环境（沙尘、泥浆） | 滤芯消耗快 | 空滤等可能需要缩短周期 |
| 高原 | 空气稀薄、工况不同 | 按厂家要求，必要时咨询 |
| 长期高速 | 匀速巡航 | 通常在正常范围内 |
| 停车怠速时间长 | 油液与积碳相关 | 可能需要缩短周期 |
| 长期高负荷 | 磨损加快 | 可能需要缩短周期 |
| 新车 | 各部件磨合期 | 按厂家磨合期要求 |

**核心口径**：**「正常周期」是按常规工况给的。** 如果你的实际用车明显偏离常规（长期短途、恶劣环境、重载），**周期可能要缩短，但要以厂家要求为准，不要自己拍数字**。

## 五、4S 店与独立店的取舍

| 维度 | 厂家门店 | 独立店 |
|---|---|---|
| 保养记录 | 通常能记入厂家系统 | 可能不进系统 |
| 用件 | 通常用原厂或指定件 | 件源需自行判断 |
| 价格 | 通常更高 | 通常更低 |
| 项目解释 | 通常按厂家清单 | 可能有额外推荐 |
| 质保相关 | 涉及质保的保养更规范 | 需注意质保要求 |
| 技术能力 | 厂家培训体系 | 水平差异较大 |

**取舍思路**：

- **在质保期内**：优先考虑能提供规范记录的地方，避免影响质保
- **出保后**：价格与项目透明度更重要，但要确认件源
- **始终要做的事**：**每次保养都问清楚做了哪些项目、用了什么件、记录在哪**

**核心口径**：**无论去哪家，能拿到清楚的项目清单和记录才是关键。** 说不清做了什么的门店，不管便宜还是贵都要警惕。

## 六、保养记录留存的作用

| 作用 | 说明 |
|---|---|
| 判断车况 | 知道历史上做过什么、什么时候做的 |
| 二手车评估 | 记录完整的车更容易被合理估价 |
| 质保依据 | 质保期内有记录更稳妥 |
| 定位问题 | 出现异常时能追溯最近改动了什么 |
| 避免重复或遗漏 | 知道已经做过什么 |

**留存要点**：

- 每次保养后**索取记录**，包括日期、里程、项目、用件
- **电子记录要确认真的进了系统**，不要只听口头说记了
- 记录保存好，**不要随手丢**
- 二手车交易时记录是重要的参考

**核心口径**：**保养记录不是走形式，是车况历史。** 没有记录，你无法知道这台车被怎么对待过。

## 七、被要求做不必要项目时怎么判断

**判断框架**：

| 问自己 | 说明 |
|---|---|
| 这个项目是干什么的？ | 说不清作用的项目，先别急着答应 |
| 它属于周期保养还是状态检查？ | 很多属于检查，不是必须更换 |
| 说明书上有没有这一项？ | **以车辆说明书为准** |
| 我的工况需要缩短这个周期吗？ | 有理由才缩短 |
| 这个项目影响质保吗？ | 影响则优先考虑 |
| 不做会有什么后果？ | 分清「不严重」和「有安全影响」 |

**几个具体判断口径**：

- **清洗节气门、喷油嘴等**：属于状态相关，不是所有车到点就必须做
- **变速箱深度保养**：**按里程与时间为主，自动变速箱通常更敏感**，不是想洗就洗
- **燃油添加剂**：不属于常规必备项目
- **刹车和轮胎**：**安全相关**，按状态检查的结论应该照做
- **空调滤芯**：灰尘多的地区确实需要更频繁，但要按说明书周期

**核心口径**：**不同车型差异很大，不要拿别人的清单套自己的车。** 判断依据是**车辆说明书**，不是别人的经验。

**拒绝不必要项目的方式**：先问清楚这个项目的作用与依据，说明书上有还是没有。**这比直接说「不需要」更有说服力。**

## 八、最常见的坑

**坑一：只按里程保养。**
短途行驶的车辆里程跑不到，但油液已在劣化，容易超期使用。

**坑二：只按时间保养。**
长途少的车辆里程很低却该换的没换，同样是问题。**两个维度要一起看。**

**坑三：抄别人的周期表。**
不同车型的要求差别很大，抄别人的很容易出问题。**以自己的说明书为准。**

**坑四：安全件也等到周期才看。**
刹车和轮胎是按实际状态检查的，磨损到了就该换，不是因为「周期没到」。

**坑五：说不清作用的项目也照做。**
先问清楚是干什么的、说明书上有没有，再决定做不做。

**坑六：不做记录。**
不知道车上做过什么、二手车不好估价、出问题无法追溯。

**坑七：厂家清单全照做不判断。**
有些项目属于状态相关或额外推荐，不是每台车都需要。

**坑八：长期短途还按正常周期保养。**
工况明显偏离常规时周期可能要缩短，以厂家要求为准。

**坑九：轮胎该换了等周期。**
安全件按状态，不按周期。

**坑十：质保期内外不做区分。**
质保期内优先考虑能提供规范记录的地方，避免影响质保。

## 九、脚本用法

```bash
python scripts/service_interval_check.py --last_km 42000 --now_km 52000 --months_since 8 --consumption 8.5
python scripts/service_interval_check.py --file car.json --out 核对结论.md
python scripts/service_interval_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--last_km` | 上次保养时的里程 |
| `--now_km` | 当前里程 |
| `--months_since` | 距上次保养的月数 |
| `--condition` | 工况：`normal` / `shorttrip` / `harsh` / `trailer` |
| `--items` | 逗号分隔的待核对项目 |
| `--file` | 从 JSON 读（自动兼容带 BOM 的文件） |
| `--out` | 结果落盘路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本输出**里程与时间的双轨判定结论、工况调整提示、项目作用与核对清单、记录留存提醒**。

> 脚本只做双轨判定的结构性提示，**具体周期数值以车辆说明书和厂家要求为准**，本脚本不内置任何周期数字。

## 十、人工确认清单（这步不能省）

- [ ] 里程与时间两个维度都算了，不是只看一个
- [ ] 按先到者判定，不是等里程到齐了才做
- [ ] 周期数值来自自己车的说明书，不是抄别人的
- [ ] 刹车与轮胎按实际状态检查，不只看周期
- [ ] 确认了实际工况是否偏离常规
- [ ] 不明白作用的项目先问清楚再决定
- [ ] 每次保养都索取了记录，并确认进了系统
- [ ] 记录保存好了，没有随手丢

## 十一、边界与免责

- 本技能**只讲判定逻辑与项目作用**，**具体保养周期、项目与用量以车辆说明书和厂家要求为准**
- 不给出任何周期数字，也不引用条款号
- 不指导用户拆装、维修或改装车辆
- 不评价具体品牌、车型或门店的服务质量
- 车辆出现异常症状时，应由专业维修人员判断，本技能不替代实际车况检查
