# 汽车保养周期与项目核对规则库

> 生成核对结论、解释项目作用之前，先读这份文件，不要凭印象写。
> 具体周期以车辆说明书和厂家要求为准。

---

## 一、周期判定规则

| 判定维度 | 为什么重要 |
|---|---|
| 里程 | 反映机械磨损与油液消耗 |
| 时间 | 反映油液自然劣化、橡胶件老化、腐蚀 |

**两种典型情况**：

- 里程到了但时间没到：短途行驶常见，机械磨损不大但油液已劣化
- 时间到了但里程没到：长途少或新车常见，里程很低但橡胶件与油液已到周期

**核心口径**：里程与时间双轨判定，**先到者为准**。

---

## 二、常见保养项目与作用

| 项目 | 主要作用 | 周期口径 |
|---|---|---|
| 机油 | 润滑、清洁、带走磨损颗粒与热量 | 里程与时间先到者为准 |
| 机滤 | 拦截机油中的颗粒杂质 | 通常与机油同步或更频繁 |
| 空滤 | 过滤进入发动机的空气 | 按里程，尘土多的地区更频繁 |
| 汽滤 | 过滤燃油中的杂质 | 按里程 |
| 刹车 | 制动功能，涉及安全 | **按实际磨损检查，不是固定周期** |
| 轮胎 | 抓地与承载 | **按磨损状态与年限** |
| 冷却液 | 带走热量、防冻防沸 | 按里程与时间 |
| 变速箱油 | 润滑与液压传动 | 按里程与时间，自动变速箱更敏感 |
| 刹车油 | 制动液压传递 | **按时间为主，含水量随时间上升** |
| 火花塞 | 点火 | 按里程，类型差异大 |
| 雨刷 | 视野 | 按使用状态，橡胶会老化 |

**两个重要区别**：

- 刹车与轮胎是安全件，**按实际状态检查，不等周期**
- 刹车油更看时间，含水量上升是主要劣化因素

## 三、工况调整对照

| 工况 | 影响 | 调整方向 |
|---|---|---|
| 长期短途 | 发动机无法充分热透 | 可能需要缩短周期 |
| 频繁拖挂 | 负荷加重 | 可能需要缩短周期 |
| 恶劣环境（沙尘、泥浆） | 滤芯消耗快 | 空滤等可能缩短周期 |
| 高原 | 空气稀薄、工况不同 | 按厂家要求，必要时咨询 |
| 长期高速 | 匀速巡航 | 通常在正常范围内 |
| 长期怠速 | 油液与积碳相关 | 可能需要缩短周期 |
| 长期高负荷 | 磨损加快 | 可能需要缩短周期 |
| 新车 | 磨合期 | 按厂家磨合期要求 |

**核心口径**：正常周期是按常规工况给的。工况明显偏离时周期可能要缩短，**以厂家要求为准，不要自己拍数字**。

## 四、4S 店与独立店对照

| 维度 | 厂家门店 | 独立店 |
|---|---|---|
| 保养记录 | 通常能记入厂家系统 | 可能不进系统 |
| 用件 | 通常用原厂或指定件 | 件源需自行判断 |
| 价格 | 通常更高 | 通常更低 |
| 项目解释 | 通常按厂家清单 | 可能有额外推荐 |
| 质保相关 | 涉及质保的保养更规范 | 需注意质保要求 |
| 技术能力 | 厂家培训体系 | 水平差异较大 |

**取舍思路**：

- 质保期内：优先考虑能提供规范记录的地方
- 出保后：价格与项目透明度更重要，但要确认件源
- 始终要做：每次问清楚做了哪些项目、用了什么件、记录在哪

**核心口径**：**能拿到清楚的项目清单和记录才是关键。**

---

## 五、保养记录的作用

| 作用 | 说明 |
|---|---|
| 判断车况 | 知道历史上做过什么 |
| 二手车评估 | 记录完整的车更容易被合理估价 |
| 质保依据 | 质保期内有记录更稳妥 |
| 定位问题 | 出现异常时能追溯最近改动 |
| 避免重复或遗漏 | 知道已经做过什么 |

**留存要点**：

- 每次索取记录：日期、里程、项目、用件
- 电子记录要确认真的进了系统
- 记录保存好，不要随手丢
- 二手车交易时记录是重要参考

## 六、不必要项目的判断框架

| 问自己 | 说明 |
|---|---|
| 这个项目是干什么的 | 说不清作用的项目先别急着答应 |
| 属于周期保养还是状态检查 | 很多属于检查不是必须更换 |
| 说明书上有没有这一项 | **以车辆说明书为准** |
| 我的工况需要缩短周期吗 | 有理由才缩短 |
| 影响质保吗 | 影响则优先考虑 |
| 不做会有什么后果 | 分清不严重与有安全影响 |

**具体判断口径**：

| 项目 | 判断 |
|---|---|
| 清洗节气门、喷油嘴 | 状态相关，不是所有车到点必须做 |
| 变速箱深度保养 | 按里程与时间为主，自动变速箱更敏感 |
| 燃油添加剂 | 不属于常规必备项目 |
| 刹车与轮胎 | 安全相关，按状态检查的结论应照做 |
| 空调滤芯 | 灰尘多的地区需更频繁，但要按说明书周期 |

**核心口径**：**判断依据是车辆说明书，不是别人的经验。**

## 七、常见误区对照

| 说法 | 是否成立 |
|---|---|
| 到公里数才需要保养 | 不成立，时间维度也要看 |
| 里程远就按远周期 | 不成立，要看自己的说明书 |
| 安全件也等周期 | 不成立，按实际状态检查 |
| 说不清作用的项目照做 | 不成立，先问清楚 |
| 厂家清单全照做 | 不成立，有状态相关与额外推荐项 |
| 不做记录没关系 | 不成立，记录是车况历史 |
| 短途车辆按正常周期 | 通常不成立，可能需要缩短 |
| 别人怎么保养我就怎么保养 | 不成立，车型差异很大 |
