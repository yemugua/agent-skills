# 批准文号核查与违法宣称识别

## 一、先查批准文号：这一条最硬

**保健食品批准文号格式**（国产）
- 现行为：`国食健注G+4位年代号+4位顺序号`（注册制）或 `国食健备G+4位年代号+4位顺序号`（备案制）
- 历史遗留：`卫食健字(年份)第×××号`、`国食健字G+4位年代号+4位顺序号`
- 进口产品：把 `G` 换成 `J`

**官方查询入口**
- 国家市场监督管理总局「特殊食品信息查询平台」，可查保健食品注册与备案信息
- 查询时要用**包装上印的完整文号**，少一位都查不到

**查到之后还要核对三项**
| 核对项 | 为什么 |
| --- | --- |
| 产品名称是否与包装一致 | 套用他人文号是常见手法 |
| 保健功能是否与宣传一致 | 批准的只有「辅助降血脂」这类表述，宣传成「降血脂」就越界 |
| 生产企业是否与包装一致 | 不一致即为冒用 |

**查不到意味着什么**
- 它可能根本不是保健食品，只是普通食品甚至三无产品
- 普通食品宣称保健功能、疾病治疗功能，违法性质更重
- 这是举报材料里最硬的一条，截图留存

## 二、蓝帽子与警示语

- 保健食品的最小销售包装上应有**蓝帽子标志**与批准文号。
- 现行规定要求保健食品标签设置警示用语区，标注
  **「保健食品不是药物，不能代替药物治疗疾病」**。
- 没有蓝帽子却宣称保健功能的，按普通食品论处。

## 三、违法宣称的几类与法律性质

| 宣称类型 | 典型话术 | 法律性质 |
| --- | --- | --- |
| **疾病预防、治疗功能** | 降血压、降血糖、根治糖尿病、抗癌、包治百病、吃了就不用吃药 | 《食品安全法》明确规定保健食品标签与说明书不得涉及疾病预防、治疗功能；《广告法》第十八条明确保健食品广告不得涉及疾病预防、治疗功能 |
| **功效与安全性的断言保证** | 绝对有效、无副作用、百分之百安全、无效退款 | 《广告法》第十八条禁止表示功效、安全性的断言或者保证 |
| **医疗用语** | 疗效、治愈率、处方、疗程、主治 | 易使消费者误认为是药品，属违法宣称 |
| **暗示为健康必需** | 不吃就会得癌、人人都必须补 | 《广告法》第十八条禁止声称或暗示商品为保障健康所必需 |
| **利用代言人作推荐证明** | 专家推荐、患者现身说法、明星代言 | 《广告法》第十八条禁止利用广告代言人作推荐、证明 |
| **与药品或其他保健食品比较** | 比药还管用、比某某品牌强 | 《广告法》第十八条禁止与药品、其他保健食品比较 |

**「辅助降血脂」与「降血脂」只差两个字，性质完全不同**——
前者是经批准的保健功能表述，后者是疾病治疗功能宣称，属违法。

## 四、普通食品冒充保健品的后果更重

如果产品根本没有保健食品批准文号，却宣称保健功能或疾病治疗功能，
则不受「保健食品」这一相对宽容的框架保护，
直接按《食品安全法》关于食品标签、说明书不得涉及疾病预防治疗功能的规定处理，
处罚力度通常更重。

## 五、销售场景的风险分级

| 场景 | 风险 | 取证要点 |
| --- | --- | --- |
| **会销 / 讲座** | 最高 | 现场录音录像、宣传单、签到表、收款收据；常见没收手机、制造抢购氛围 |
| **直播口播** | 高 | 主播口播往往不在商品详情页里，必须**当场录屏**才能固定 |
| **微商私域** | 高 | 聊天记录里的功效承诺是关键；收款常走个人转账 |
| **门店推销** | 中 | 店内海报、店员话术录音、小票 |
| **电视购物** | 中 | 节目录像、广告播出时间、订购单 |

## 六、纪律边界

- 本技能只做信息核查与路径指引，不作医学判断、不评价产品功效。
- 批准文号的唯一权威来源是官方查询平台，本技能不代替官方核验。
- 服用后出现不适的，先就医并保留诊疗记录，这既是健康需要，也是证据。
