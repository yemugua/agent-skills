# 退费依据、举报材料与路径

## 一、退费怎么算

**基础口径**
```
未使用部分 = 已付总额 − 已开封/已食用部分 − 已退金额
```

**可以全额退的情形**
1. 产品**根本不是保健食品**（无批准文号）却按保健食品销售——构成欺诈
2. 宣称**疾病治疗功能**——违法且构成虚假宣传，可主张欺诈
3. 产品**在官方平台查不到**——主体身份存疑
4. 会销/直播场景下**未履行七天无理由告知义务**的，网购情形可主张七日无理由退货

**构成欺诈的，可主张增加赔偿**
《消费者权益保护法》第五十五条规定，经营者提供商品或者服务有欺诈行为的，
应当按照消费者的要求增加赔偿其受到的损失，增加赔偿的金额为消费者购买商品的价款或者接受服务的费用的三倍；
增加赔偿的金额不足五百元的，为五百元。

**通常难以全额退的情形**
- 产品本身合规（有文号、宣传合规），仅因个人原因不想吃了——属协商退货
- 已开封食用过半且无质量问题的——按未使用部分退

## 二、举报材料清单（照单准备）

| 序号 | 材料 | 说明 |
| --- | --- | --- |
| 1 | 产品外包装与标签照片 | 拍全六面，批准文号与警示语要清晰 |
| 2 | 官方查询平台查询结果截图 | 查不到也要截图，注明查询日期 |
| 3 | 宣传单、海报、说明书原件 | 这是「宣称了什么」的直接证据 |
| 4 | 直播/会销的录屏或录音 | 口播内容必须当场固定，事后平台不会给你 |
| 5 | 聊天记录完整导出 | 微商渠道的核心证据 |
| 6 | 付款凭证与发票 | 核对收款主体与销售主体是否一致 |
| 7 | 会销现场的签到表、礼品清单 | 证明营销场景与受众 |
| 8 | 服用后的诊疗记录 | 涉及身体不适的，这是关键证据 |

## 三、举报路径

| 情形 | 向谁举报 | 说明什么 |
| --- | --- | --- |
| 虚假宣传、违法宣称 | 12315 / 市场监管部门 | 产品名、文号、宣传原话、渠道、金额 |
| 无批准文号、冒用文号 | 市场监管部门 | 附官方查询截图 |
| 会销欺诈、针对老年人大额推销 | 市场监管部门 + 公安 | 涉诈骗的报警 |
| 服用后身体损害 | 市场监管部门 + 公安 | 附诊疗记录与剩余产品 |
| 直播平台不作为 | 平台投诉 + 12315 | 附录屏与订单号 |

**举报要点**：说清「什么产品、什么文号、谁在卖、在哪里卖、宣称了什么原话、我付了多少钱」，
并附上截图。多人受骗的，联合举报会被优先处理。

## 四、话术：举报时怎么说

> 我于 ×年×月×日在 ××（渠道）购买「××」产品，支付 ¥××。
> 该产品宣传称「××（原话）」，涉及疾病治疗功能，违反《食品安全法》《广告法》
> 关于保健食品不得宣称疾病预防、治疗功能的相关规定。
> 我在国家市场监督管理总局特殊食品信息查询平台查询其批准文号 ××，查询结果为 ××。
> 现举报其虚假宣传与违法宣称，请求依法查处并协调退费。
> 附件：产品包装照片、查询结果截图、宣传材料、付款凭证。

## 五、时间纪律

- 直播口播内容平台不会长期保存，**当场录屏**，事后无法补
- 会销现场尽量录音，离开后证据即灭失
- 服用后出现不适的，先就医，诊疗记录要在就诊时就说明服用过该产品
- 民事诉讼时效三年，但举报越早越容易查获现场与库存

## 六、常见误区

| 误区 | 正确做法 |
| --- | --- |
| 「老人自愿买的，没办法」 | 针对老年人的误导性营销本身就是查处重点 |
| 「开封了就不能退」 | 是否可退取决于是否存在欺诈与违法，不取决于是否开封 |
| 「对方有营业执照就是正规的」 | 有执照不等于产品合规，关键看批准文号与宣传内容 |
| 「保健品嘛，夸大宣传很正常」 | 涉及疾病治疗功能是明确违法，不是行业惯例 |
| 「金额小不值得举报」 | 举报促成查处能保护更多人，且可一并协调退费 |

## 七、纪律边界

- 本技能只做信息核查与路径指引，不作医学判断、不代办举报。
- 是否构成欺诈与违法宣称，最终以市场监管部门认定为准。
- 涉及身体损害的应立即就医并保留诊疗记录。
