# 保健品虚假宣传举报与退费

面向买到宣称能治病、降三高、根治慢性病的保健品，或家中老人在会销、直播、微商渠道大额购买后想退费举报的当事人。

## 与其他工具的区别

- **从批准文号这一硬事实切入**：宣传话术可以抵赖，批准文号在官方平台查不到就是查不到，
  这是举报材料里最硬的一条。本技能把文号核查排在最前。
- **把「宣称了什么」逐条对照法律**：不是笼统说「虚假宣传」，
  而是把话术拆成「疾病治疗功能」「医疗用语」「安全性断言」等几类，各自对应不同的违法性质。
- **区分渠道风险**：会销讲座、直播口播、微商私域的取证难度与举报路径完全不同，
  本技能按渠道给出不同的留证重点。

## 典型适用场景

1. 老人参加讲座后被引导购买上万元保健品，宣称能治高血压糖尿病
2. 直播里主播口播「吃了就不用吃药」，但商品详情页没有这句话
3. 产品包装上没有批准文号，或文号在官方平台查不到
4. 会销现场没收手机、制造抢购氛围
5. 服用后出现不适，怀疑产品有问题
6. 想退费被拒，对方说「开封了就不能退」

## 使用流程

1. 抄录 `templates/保健品购买信息采集表.md` 填好（不知道写「未填写」，别猜）
2. 运行脚本生成核查报告
3. 先按报告去官方平台核验批准文号并截图，再按举报路径提交

## 边界

不替代专业法律意见与医学判断，最终以市场监管部门及司法机关认定为准。
涉及身体不适的应立即就医。
