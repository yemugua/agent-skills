# 保健品核查报告（模板）

> 本模板为脚本输出结构示意，实际报告由 `scripts/health_product_check.py` 生成。

## 一、结论摘要

| 项 | 结论 |
| --- | --- |
| 批准文号核查 | 待填 |
| 违法宣称命中 | 待填（n 项） |
| 渠道风险 | 待填 |
| 退费性质 | 待填 |
| 参考应退 | 待填 |
| 高危项 | 待填（n 项） |
| **总体结论** | **通过 / 有风险 / 不通过 / 待补正** |

四态含义：

- **通过**：文号可查、宣传合规、渠道规范
- **有风险**：存在需核验或需补正的问题
- **不通过**：命中高危项（文号查不到、宣称疾病治疗功能、会销骗老等）
- **待补正**：核心信息未填，不下实质结论

## 五、退费测算与退货依据

## 六、证据清单与固定要点

## 七、举报与维权路径

## 八、待办补正动作

## 九、边界与纪律
