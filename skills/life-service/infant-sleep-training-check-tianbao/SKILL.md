# 婴幼儿睡眠训练与作息安排核查

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 按月龄给出总睡眠时长区间、清醒时长上限与小睡次数参考 | 诊断睡眠障碍、发育问题、神经系统疾病或做睡眠病判定 |
| 整理固定入睡流程、房间光线与温度的调整口径 | **推荐任何助眠药物、褪黑素或保健品的品类与剂量** |
| 说明渐进式训练、安抚存在下基线拉长 | 推行「哭到睡着不管」式一刀切，尤其小月龄、疾病期、应激期 |
| 列出必须执行的安全睡眠环境口径 | 允许趴睡、装床围、同床睡、用松软卧具、长时间用汽车安全座椅当床 |
| 输出每日作息表与睡眠日记 | 承诺某种训练几天就能让孩子睡整夜 |

**就医红线（出现任一条，先看这一节，不再谈训练）**

- **睡眠中呼吸暂停（呼吸停止超过 10-20 秒、胸廓用力起伏却吸不进气）、面色发青发绀、口吐白沫、肢体抽动僵直** —— 急诊
- **被发现趴睡后无反应、发生过窒息或濒死事件** —— 急诊并按急救流程处理后再次评估
- 习惯性打鼾、张口呼吸、夜间频繁憋醒、出汗多、白天嗜睡或注意力差（警惕腺样体扁桃体肥大相关睡眠呼吸问题）—— 儿科或耳鼻咽喉科评估
- 头颅外伤后出现呕吐、嗜睡、叫不醒、抽搐、瞳孔不等大 —— 急诊
- 惊厥样发作：睡眠中四肢强直抽动、意识丧失、咬牙、尿失禁、发作后意识模糊 —— 急诊，同时记录视频
- 发热伴意识改变、颈部僵直、皮疹压不褪色 —— 急诊
- 喷射性呕吐、囟门膨隆、持续尖声哭叫难以安抚（尤其婴儿）—— 急诊
- 生长迟缓、体重不增伴喂养困难与异常多睡
- 白天功能明显受损：上课睡觉、情绪暴躁、注意力之差影响学习与安全
- 夜惊频繁且造成自伤或伤人、梦游出现危险行为（爬窗、出门）—— 儿科或儿童睡眠专科评估
- 母亲出现明显产后抑郁、有伤害自己或孩子的想法 —— 立即向专业人员或急诊求助，**这比睡眠训练重要得多**

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「每天几点睡、小睡几次合适」 | 用，按月龄给作息框架 |
| 「抱睡、奶睡怎么改」 | 用，给渐进式替代路径 |
| 「要不要让孩子哭一会儿」 | 用，**明确不推行一刀切哭声免疫**，给有安抚的调整方式 |
| 「趴睡会不会睡得更实」 | 用，明确仰睡是硬要求 |
| 「床围、枕头、被子能不能用」 | 用，明确 1 岁内不用 |
| 「夜醒要不要叫醒喂奶」 | 用，按月龄与出生体重增长情况给口径，具体遵医嘱 |
| 「打鼾、张嘴呼吸正常吗」 | 只作就医提示，不做腺样体判定 |
| 「缺锌缺钙所以要做噩梦」 | 不用，**不用补剂治睡眠**，转医生评估 |
| 「能不能吃褪黑素」 | 不用，药物剂量由医生决定 |

## 三、完整工作流

1. **先排红线**：逐条过就医红线清单。命中任一条即停止给作息与训练建议，转为就医或急诊提示。**这一步不能跳过。**
2. **算总睡眠基线**：连续 3-7 天用同一个本子记录就寝、入睡、夜醒、晨起、小睡的起止时间，先算出真实的 24 小时总睡眠，再谈调整。
3. **按月龄核对时长**：对照 `rules/月龄睡眠时长与安全睡眠环境.md` 的区间表，判断是「真的少」还是「家长以为少」。个体差异大，只要生长曲线正常、白天精神好，区间偏低端也可能正常。
4. **排清醒时长**：先按最大清醒时长排白天的小睡节点，再倒推夜间入睡窗口；睡得晚常常是最后一个小睡结束太晚导致。
5. **做固定入睡流程**：流程 3-4 步，总时长控制在 20-30 分钟，顺序固定、天天一样：喂奶 → 洗澡/擦脸手 → 换睡衣睡袋 → 关灯拉窗帘 → 放床和告别用语（或书/歌），**最后一步发生在床上、在孩子还醒着时结束**，让孩子在床上学入睡。
6. **处理入睡依赖**：入睡依赖（奶睡、抱睡、摇晃）不是错，但要逐步松动 —— 先保留安抚存在，把落地时机从「深睡后」前移到「昏昏欲睡但仍有点醒」，逐步减少摇晃幅度和喂养时长。
7. **夜醒处理口径**：夜里先等 30 秒到 1 分钟看能否自己接觉，不行则先观察是不是真的需要（饥饿、尿布、身体不适、环境过冷过热），回应保持低调、不开大灯、不玩不聊太久，处理完立刻回床。
8. **安全环境复核**：按 rules 里的安全清单逐项打勾，任何不安全项目优先整改，**可以先改环境再改行为**。
9. **复评**：执行 2 周后看入睡潜伏期、夜醒次数与总时长、白天精神与合作度。无改善或加重 → 转儿童保健或睡眠专科评估。

## 四、核心规则与要件库

生成作息表、训练建议或安全检查结论前，**必须先读**：

- `rules/月龄睡眠时长与安全睡眠环境.md`：按月龄的总睡眠时长区间、清醒时长上限与小睡次数、入睡流程模板、夜醒处理口径、五项安全硬要求与常见误区。
- `templates/作息安排与睡眠日记.md`：连续记录模板与 2 周复评表。

不得推荐任何助眠药物、褪黑素或保健品。不得因为调整作息而推迟必要喂养（夜奶何时减、减多少由儿科医生结合生长曲线判断）。不得以任何理由允许趴睡、装床围或用松软卧具凑合。**0-3 月龄不建议做任何形式的睡眠训练。**

## 五、脚本用法

```
python scripts/sleep_schedule.py --file case.json
python scripts/sleep_schedule.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`age_months` 月龄、`total_sleep_hours` 24 小时总睡眠、`naps` 白天小睡次数、`night_wakings` 夜醒次数、`longest_awake_hours` 最长清醒时长、`settle_method` 入睡方式（奶睡/抱睡/摇晃/自主）、`quiet_env` 是否独立房 labels、`unsafe` 未整改的安全项列表、是否命中红线项 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--json` | 以 JSON 输出 |
| `--selftest` | 运行自检 |

脚本输出年龄档的时长核对结论、建议小睡次数与清醒时长上限、一个样例作息表、安全项缺口清单和入睡依赖松动步骤。**命中红线或年龄不足 3 个月时，脚本只输出就医/等待结论，不输出训练步骤。**

## 六、人工确认清单

- [ ] 就医红线逐条核对完毕，命中的已转就医
- [ ] 连续记录了 3-7 天真实睡眠数据，不是凭印象估计
- [ ] 年龄档对应的总睡眠区间与清醒时长上限已核对
- [ ] 夜间睡眠环境始终仰卧、硬实平整、无松软物品，不使用床围
- [ ] 同房不同床（建议在父母房间放置独立婴儿床）
- [ ] 室内温度与穿着合适，未用过厚被褥或电热毯过度保暖
- [ ] 入睡流程已写成固定的 3-4 步，全家人执行一致
- [ ] 正在生病、出牙、打疫苗、搬家、入园、旅行期间暂缓训练
- [ ] 夜奶是否减少已与儿科医生确认，未因训练而限量喂养
- [ ] 照顾者自身状态已评估，睡眠严重不足时优先找人分担而不是硬撑
- [ ] 2 周后复评时间点已定，知道无改善要转儿科评估

## 七、最常见的坑

1. **趴睡更实**：仰睡是被证明显著降低婴儿猝死风险的睡姿，任何「趴着睡得更香」的理由都不能推翻这条，会翻身也不代表可以趴睡入睡。
2. **用床围防卡**：床围带来的缠绕、窒息和攀爬风险远大于它解决的问题，1 岁内不用。
3. **睡大人床方便喂奶**：成人床的软床垫、被子、枕头和大人体位对婴儿不安全，正确做法是同房不同床、喂完放回婴儿床。
4. **白天少睡晚上睡得好**：白天过度剥夺睡眠会让孩子应激激素升高，反而更闹、更难入睡、夜醒更多。
5. **哭声免疫一刀切**：这是具体的训练选择，不是普适方案；小月龄、生病、分离焦虑期、家庭变故期都不适合让婴儿长时间独哭。
6. **推迟入睡时间能攒觉**：睡得越晚通常睡得越差，清醒时长超限后孩子会越精神。
7. **摇晃或移动到深睡才放下**：入睡地点和醒后地点不一致，是「放下就醒」的常见成因。
8. **用开着的大灯和屏幕陪睡**：光线与屏幕会推迟入睡，夜醒处理时也应当保持昏暗环境与低调回应。
9. **夜里一有动静立刻抱起**：夜里短暂发声、翻身属于正常睡眠周期，过早介入反而把孩子弄醒成习惯。
10. **以为打鼾是睡得香**：习惯性打鼾、张口呼吸需要就医评估，不是「睡得沉」。
11. **沙发或躺椅上抱睡到天亮**：成人抱着睡着后的沙发、躺椅是最危险的睡眠场所之一。

## 八、边界与免责

本技能提供婴幼儿睡眠作息的通用口径、安全睡眠环境要求与渐进式调整路径，**不构成诊断，不提供任何药物、褪黑素或保健品的品类与剂量建议**。月龄区间、训练方式的选择需结合早产、基础疾病、生长曲线和家庭具体情况，**以最新版儿科相关指南和儿科医生的判断为准**。0-3 月龄不做睡眠训练。出现就医红线中的任一情况，请立即就医或急诊评估，不要先自行调整作息。本技能不替代诊疗。
