# 电动汽车充电设施防火（ev-charging-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据充电设施防火要求与相关国家标准，生成清单：场所选择与布置、充电设备与配电保护、防火分隔与疏散、灭火器材与水源、运维巡检与应急处置。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 充电桩防火
- 充电站消防
- 充电设施检查
- 新能源汽车充电安全
- 充电站布局

## 三、工作流
1. 核查场所选择与总体布置
2. 核查充电设备与配电保护
3. 落实防火分隔与疏散
4. 配置灭火器材与水源
5. 建立运维巡检与应急处置

## 四、核心内容（检查清单与判定）
充电设施宜集中布置并采取防火分隔，配电须具备过载漏电保护；场所应配灭火器材并具备应急处置能力，运维巡检是降低热失控风险的关键。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含场所选择与布置 | 布置 |
| Q2 | FAIL | 未含充电设备与配电保护 | 配电 |
| Q3 | WARN | 未含防火分隔与疏散 | 分隔 |
| Q4 | FAIL | 未含灭火器材与水源 | 灭火 |
| Q5 | WARN | 未含运维巡检与应急处置 | 运维 |

> 脚本 `ev-charging-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python ev-charging-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python ev-charging-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
