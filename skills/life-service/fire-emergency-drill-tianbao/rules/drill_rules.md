# 演练策划与评估规则库（drill_rules）

> 本文件是 fire-emergency-drill 技能的规则支撑。引用条款以现行有效文本为准；地方有更严要求的，从其规定。

## 一、法规依据速查

| 文件 | 关键要求 | 与本技能的关联 |
|---|---|---|
| 《中华人民共和国消防法》 | 单位应当制定灭火和应急疏散预案，并组织演练 | 演练义务的法源 |
| 公安部令第61号《机关、团体、企业、事业单位消防安全管理规定》 | 第四十条：消防安全重点单位应当按照灭火和应急疏散预案，至少每半年进行一次演练，并结合实际不断完善预案；其他单位至少每年组织一次演练 | **频次红线的直接依据** |
| 《消防安全责任制实施办法》（国办发〔2017〕87号） | 单位消防安全职责含组织消防演练 | 责任落实 |
| GB/T 38209-2019《社会单位灭火和应急疏散预案编制及实施导则》 | 预案编制流程、演练分类与评估要求 | 类型选择与评估的方法来源 |
| 《高层民用建筑消防安全管理规定》（应急管理部令第5号） | 高层建筑对演练另有更高要求 | 高层建筑适用 |

## 二、频次规则细化

1. **间隔口径**：重点单位两次演练间隔 ≤ 6 个月；非重点单位 ≤ 12 个月。
2. **计划倒排**：年度计划把演练日期排在间隔上限的 80% 处（重点单位约 5 个月一次），给整改、补办留缓冲。
3. **触发加练**（不计入法定频次，但建议安排）：
   - 新员工入职集中期（岗前培训后）
   - 建筑改扩建、用途变更、疏散路线调整
   - 发生火警、燃气泄漏等事件后
   - 季节性风险期（冬季用电高峰、节假日人流高峰）
4. **常见不合格排期**：
   - 两次演练都在 3 月和 12 月（间隔 9 个月）
   - 全年只排 1 次，下半年被检查撞上
   - 演练日期在计划之外、无方案支撑

## 三、方案九要素检查口径

| 要素 | 合格口径 | 常见不合格表述 |
|---|---|---|
| 目的 | 明确检验对象（预案/人员/设施/疏散） | "提高消防意识" |
| 依据 | 预案名称+版本号 | "根据有关规定" |
| 时间地点 | 起止时刻+楼层部位 | "近期""厂区内" |
| 组织机构 | 到人到组 | "成立领导小组" |
| 情景设定 | 部位+燃烧物+报警方式+被困假设 | "假设发生火灾" |
| 实施步骤 | 分钟级时间线 | "先报警后疏散" |
| 保障措施 | 医疗/交通/通信/警戒逐项 | "做好后勤保障" |
| 评估安排 | 评估人+表格+计时点 | "演练后总结" |
| 整改要求 | 问题口径+责任+复查时限 | "对存在问题及时整改" |

## 四、演练类型定义

- **桌面推演**：围桌讨论式，按预案流程口头推演，检验指挥与协调，不动用设施。
- **功能演练**：针对某一应急功能（报警、疏散、灭火、广播）的单项实战练。
- **疏散演练**：以人员疏散与集结清点为核心的演练，人员密集场所首选。
- **专项演练**：针对薄弱环节或特定风险（夜间、地下空间、燃气、化学品）。
- **综合演练**：两个以上应急功能联动、多部门参与的全流程演练。

## 五、评估指标表

| 维度 | 指标 | 记录方式 |
|---|---|---|
| 时间 | 报警响应时间 | 模拟报警时刻→现场确认时刻 |
| 时间 | 疏散用时 | 警报响起→集结清点完毕 |
| 时间 | 设施联动到位时间 | 广播/防排烟/卷帘动作时刻 |
| 人员 | 参演率、到位率 | 签到表统计 |
| 人员 | 关键岗位持证率 | 证书台账核对 |
| 设施 | 各系统动作符合性 | 评估员现场记录 |
| 管理 | 预案偏差、指挥流畅度、记录完整性 | 评估员评分 |

## 六、整改闭环五步法

1. **发现问题**：评估员按四维度填写问题清单，一项一列，不合并。
2. **定措施定责任人**：每项问题对应责任部门/责任人，不接受"相关部门"。
3. **定期限**：具体日期；一般问题 30 日内，涉及资金的按计划排期但要有节点。
4. **整改销项**：完成后留存证据（照片、更换记录、培训签到）。
5. **复查验证并归档**：复查人签字、注明复查日期，未通过的重新挂账。

## 七、演练记录留存清单

- 演练方案（九要素齐全，有审批）
- 签到表（全口径参演人员）
- 时间线记录（分钟级关键节点）
- 影像资料（覆盖报警、疏散、集结关键节点）
- 评估表（四维度，有问题清单）
- 整改台账（问题、责任人、期限、复查）
- 演练总结（简短，含结论与下一步）

## 八、迎检常见问法

- "请提供近两年的演练记录" → 频次+要素+闭环三样齐全才过关
- "演练和预案是什么关系" → 演练是预案的检验，方案要引用预案版本号
- "这些问题整改了吗" → 拿复查记录说话
