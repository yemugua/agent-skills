# 火灾自动报警系统核查（fire-alarm-system）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《火灾自动报警系统设计规范》GB 50116，生成火灾自动报警系统核查清单：探测器布置、报警主机与回路、手动报警按钮、消防联动（广播/切非/电梯）、线路与接地、维护检测。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 火灾自动报警系统
- 消防报警系统
- 探测器布置
- 报警主机
- 消防联动

## 三、工作流
1. 核查探测器类型与布置（烟/温/火焰）
2. 检查报警主机、回路与地址编码
3. 确认手动报警按钮与声光警报
4. 验证消防联动（广播/切非/电梯迫降）
5. 检查线路接地与定期维护检测

## 四、核心内容（检查清单与判定）
GB 50116 规定火灾自动报警系统的探测、报警与联动要求；系统应与消防设备联动并定期检测，确保火警可靠上传与处置。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含探测器类型与布置 | 探测器 |
| Q2 | FAIL | 未含报警主机与回路编码 | 主机 |
| Q3 | WARN | 未含手动报警与声光警报 | 手报 |
| Q4 | FAIL | 未含消防联动验证 | 联动 |
| Q5 | WARN | 未含线路接地与维保 | 维保 |

> 脚本 `fire-alarm-system_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python fire-alarm-system_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python fire-alarm-system_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
