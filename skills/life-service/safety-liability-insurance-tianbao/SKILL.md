# 安全生产责任保险（安责险）（safety-liability-insurance）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《安全生产责任保险实施办法》与新《安全生产法》第五十一条，生成安责险清单：强制投保范围、投保主体与责任限额、保险+事故预防服务、理赔衔接与台账续保。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 安责险
- 安全生产责任保险
- 高危行业保险
- 事故预防服务
- 保险风控
- 雇主责任

## 三、工作流
1. 明确强制投保范围（高危行业/八大行业）
2. 投保主体与责任限额
3. 保险+事故预防服务（风控排查）
4. 理赔与事故报告衔接
5. 台账与到期续保

## 四、核心内容（检查清单与判定）
新《安全生产法》鼓励生产经营单位投保安责险，高危行业领域强制实施；安责险应配套事故预防服务，保险机构提供风险隐患排査。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未明强制投保范围（高危行业/八大行业） | 范围 |
| Q2 | FAIL | 未含投保主体与责任限额 | 投保 |
| Q3 | WARN | 未含保险+事故预防服务（安责险风控） | 预防 |
| Q4 | FAIL | 未含理赔与事故报告衔接 | 理赔 |
| Q5 | WARN | 未含台账与到期续保 | 台账 |

> 脚本 `safety-liability-insurance_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python safety-liability-insurance_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python safety-liability-insurance_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
