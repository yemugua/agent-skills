# MSA 测量系统分析（msa-analysis）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据 AIAG MSA 手册与 ISO 22514，生成测量系统分析清单：重复性再现性（GRR）、偏倚/稳定性/线性研究、可接受准则（%GRR≤10%/NDC≥5）与改进。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- MSA
- 测量系统分析
- 量具分析
- GRR
- 重复性再现性
- 偏倚线性

## 三、工作流
1. 明确测量系统对象（量具/检具/测试台）
2. 开展重复性与再现性（GRR）分析
3. 偏倚/稳定性/线性研究
4. 判定可接受准则（%GRR、NDC）
5. 改进措施（换量具/培训）

## 四、核心内容（检查清单与判定）
MSA 用于评价测量数据的质量；通常要求 %GRR≤10% 为可接受、10%~30% 需改进、>30% 不可接受，NDC（分辨率）应≥5。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未明确测量系统对象（量具/检具/测试台） | 对象 |
| Q2 | FAIL | 未含重复性与再现性（GRR）分析 | 重复性 |
| Q3 | WARN | 未含稳定性/偏倚/线性研究 | 偏倚 |
| Q4 | FAIL | 未含可接受准则（%GRR<=10%/NDC>=5） | 准则 |
| Q5 | WARN | 未含改进措施（更换量具/培训） | 改进 |

> 脚本 `msa-analysis_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python msa-analysis_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python msa-analysis_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
