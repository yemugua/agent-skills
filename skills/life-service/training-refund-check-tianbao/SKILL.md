# 培训退费核算与维权

退费纠纷里最容易被坑的不是"能不能退"，而是**退多少、按什么单价扣**。
同样一单 30000 元的课，按优惠后折算单价算和按机构临时抬高的"原价"算，能差出一两万元。

## 什么时候用

- 报了班不想继续上，机构说"概不退费""开课一律不退"
- 机构停业、跑路、闭店、迁址，或者约好的班一直没开、长期停课
- 招生时说"名师授课、保过、包就业"，上课后发现完全不是那么回事
- 退费时机构按"原价 400 元/课时"（实际成交价 200）扣已消耗课时
- 一次性交了几万块，怀疑超过 3 个月 / 60 课时的预收费监管上限
- 报了"培训贷/0 元入学/先学后付"，退费的同时不知道月供还不上怎么办、征信会不会花
- 无办学许可证的机构，想确认能不能据此主张全额退费

## 怎么做

**第 1 步**：复制 `templates/培训退费信息采集表.md` 填写，填不出的留空。

**第 2 步**：跑脚本

```bash
python scripts/training_refund_check.py 采集表.md --base 2026-10-05 --out 核查报告.md
python scripts/training_refund_check.py 采集表.md --json   # 结构化输出
python scripts/training_refund_check.py 采集表.md --base 2026-10-05   # 直接看结果
```

**第 3 步**：按第九段"待办补正动作"执行，需要原始话术的照 `templates/退费维权操作卡.md` 发。

## 三句话定性的核心规则

1. **退费公式**：应退 = 实付总额 − 已消耗课时费 −（已发放且不可回收、且事先有约定的）教材物品费 − 合理违约金。**实付**是基数，不是机构标的原价。
2. **课时单价**：合同写明的按合同；没写或是优惠价买的，按**优惠后折算单价 = 实付总额 ÷（购买课时＋赠课课时）**——赠课不单独计价但要摊薄单价；机构临时抬高的**原价不能用来扣款**。
3. **"概不退费"无效**：排除消费者主要权利、加重消费者责任的不公平不合理格式条款**无效**；违约金以**实际损失**为限且机构须举证，明显过高的可主张调减；**培训贷绝不能靠"不还钱"维权**，逾期先伤自己的征信。

## 输入 / 输出

| | 内容 |
|---|---|
| 输入 | 采集表 Markdown（机构课程 / 收费课时 / 教材违约金 / 合规现状 / 培训贷 / 交涉证据） |
| 输出 | 九段报告：结论摘要 / 退费金额核算 / 课时单价认定 / 格式条款与违约金 / 办学许可与双减预收费 / 机构违约情形 / 培训贷与征信风险 / 交涉路径与时效 / 待办补正动作 |
| 退出码 | 0 正常；2 关键信息缺失（给提示串，不崩） |

## 边界与纪律

- 依**通用规则**整理，**不替代律师意见**；最终以主管部门认定与司法机关裁判为准。
- 预收费监管细则、退费比例、可退范围**各地不同**，一律以当地教育/人社主管部门、
  市场监督管理部门口径为准。
- 违约金是否调减、能否全额退费**由司法机关认定**，本表只给测算口径与证据方向，不对结果作承诺。
- **未填的一律不算通过**，只按已填内容判断。
- 双减的具体时段要求、预收费上限**以现行规定及当地口径为准**，本表给的是通行口径。
