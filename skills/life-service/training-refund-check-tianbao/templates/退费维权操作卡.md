# 退费维权操作卡（可直接照着念、照着发）

## 一、0~24 小时：先固定证据

| # | 动作 | 怎么留痕 |
|---|---|---|
| 1 | 截图课时余额、课程表、考勤记录 | App/小程序里**录屏**（含时间、账号、向上滑动刷新） |
| 2 | 拍下宣传页、课表、机构门头 | 照片连拍，能看见日期 |
| 3 | 导出付款记录与发票 | 微信/支付宝账单导出、POS 小票、收据照片 |
| 4 | 保存顾问聊天与录音 | 聊天长按导出；电话录音并写清时间、号码、经办人 |
| 5 | 合同与电子签页面截全 | 含签约时间、签约主体、电子签编号 |
| 6 | 若已办培训贷：导出合同与还款流水 | 还款计划表、每月扣款记录 |

> 课时余额、考勤这类"后台数据"最容易在几天后被改，**第 1 步必须在当天做**。

## 二、1~7 天：书面交涉（发这段）

向机构前台/课程顾问/财务 + 总部/品牌方同时发送（微信或短信均可，注明年月日）：

```
【退费申请】
本人（姓名/手机号）于 X 年 X 月 X 日与 XX 机构签订培训合同
（合同编号：XXX），实付 X 元，合计 X 课时（含赠课 X 课时），
已上 X 课时。现因（长期停课 / 虚假宣传保过未兑现 / 无办学许可 /
个人重大疾病）申请解除合同并要求退费。

退费计算口径（我方主张）：
实付 X 元 − 已消耗 X 课时 × X 元/课时（折算单价）= X 元
− 教材物品费 X 元（事先有约定且已发放不可回收）
− 违约金 X 元（以实际损失为限）
= 应退 X 元。

请于收到本函 7 日内：
1）出具书面《退费方案与计算明细》（课时单价依据、已消耗课时、
   教材费、违约金逐项列明）；
2）明确退款金额与到账时间；
3）说明合同「概不退费」条款是否已向你方尽到提示说明义务。
逾期未书面答复的，本人将向教育/人社主管部门、市场监督管理
（12315）、12345 及消费者协会投诉，并保留提起诉讼的权利。
```

**同时抄送**：总部/总校/品牌方邮箱或官方客服。

## 三、8~15 天：往上追

1. **总部/品牌方**：很多校区是加盟店，钱进了校区账，责任在总部。书面投诉到总部，
   在工单里写明"校区已停业/长期停课，请总部承担连带责任"。
2. **主管部门**：
   - 学科类/非学科类 → **教育**主管部门
   - 职业技能/人社许可类 → **人力资源社会保障**主管部门
3. **同步**：**市场监督管理（12315）**（合同欺诈、虚假宣传、格式条款）、
   **12345** 市民热线、**消费者协会**。
4. 投诉正文第一段就写：
   `一次性收费 X 个月 / X 课时，超过 3 个月或 60 课时上限；无办学许可证 / 超范围经营。`
5. 工单**要求在办结回复里写清"不支持退费的理由"**——这段文字常能反推对方的计算口径。

## 四、培训贷：先保征信（别跳）

- 当天：**书面/电话+工单号**联系贷款方，发第五部分的话术，要求暂停自动扣款或协商还款。
- 绝不停还。机构跑路不能成为你逾期的理由，逾期记在**你自己**名下。
- 退费到账后优先结清贷款，留结清证明。

## 五、谈判桌上的四句话

1. **「赠课要摊进单价」**：总额 ÷（购买课时＋赠课课时），不能把赠课当作白送还却按原价扣款。
2. **「原价不用于扣费」**：退费按实付折算单价，不按机构临时抬高的原价。
3. **「违约金要举证实际损失」**：机构主张扣 30%，就得证明它损失了 30%，否则超出实际损失部分可请求调减。
4. **「概不退费是格式条款」**：排除消费者主要权利的不公平不合理条款无效，签了字也无效。

## 六、最后一步：小额诉讼 / 集体维权

- 金额小的走**小额诉讼**（当地有标的额上限、一审终审、诉讼费低），最快最省。
- 同类学员做**联名投诉**：同店、同招生批次、同一份"概不退费"合同，
  把每个人的合同页、付款额、课时余额做成一份共同材料。
- 起诉状主张写全：**解除培训合同、返还剩余培训费、资金占用利息、合理维权成本**；
  有转移财产迹象的申请**财产保全**。
- **民事诉讼时效 3 年**，自知道或应当知道权利被侵害之日起算，别拖到只剩几天。

## 七、证据目录（起诉/投诉时按顺序摆）

1. 培训合同/电子签存页（含签约主体、成立时间）
2. 付款凭证、发票、收据、流水
3. 课时余额与考勤（录屏）
4. 课程表、开课/停课公告、机构现状照片
5. 宣传页与"保过/包就业/名师"的聊天与录音
6. 书面退费申请与对方回复（含快递单号）
7. 投诉工单号与办结回复
8. 培训贷合同、放款凭证、还款流水（如有）
9. 医院证明/事故认定等（因重大疾病或不可抗力解除的）
