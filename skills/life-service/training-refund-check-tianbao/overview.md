# 培训退费核算与维权（training-refund-check）

## 解决什么问题

交了培训费不想继续、机构跑路停课、承诺的保过保就业没兑现，最后卡在"到底能退多少"。
网上搜到的答案大多是"构不成违法，按合同扣除已上课时费"这类一句话，
既算不出具体金额，也说不清该找谁、要什么材料、什么时候必须动。

## 什么时候用

- 退费金额谈不拢：机构按"原价课时单价"扣，自己算下来差几千甚至一两万
- 机构拿"概不退费""开课后不退"挡回来，不知道这招是不是有效
- 发现机构无办学许可、一次性收费超过 3 个月或 60 课时（双减/预收费监管）
- 义务教育阶段学科类机构还在寒暑假、周末排课
- 签了培训贷，"先学后付"退不掉又怕月供逾期影响征信
- 机构停业、迁址、闭店，想确认算不算"可全额退"的情形

## 和通用法律咨询 / 通用计算器有什么区别

| | 本技能 |
|---|---|
| 金额 | **真的算**：折算单价、已消耗课时费、教材费、违约金分项出数，给下限/上限区间 |
| 单价规则 | 明确"合同没写就按优惠后折算单价、赠课摊薄分母、原价不用于扣款" |
| 格式条款 | 直接判"概不退费"类条款无效，并指出机构要承担的举证责任 |
| 培训贷 | 单独立一节讲退费与还贷是两个法律关系、征信红线、给贷款方的话术 |
| 抓手 | 把"超 3 个月/60 课时""无办学许可""节假日排课"识别为可主张全额退的抓手 |
| 路径 | 分级：书面交涉 → 总部 → 教育/人社+市场监管+12345+12315 → 仲裁 → 小额诉讼 |

## 输出

- **九段 Markdown 报告**（结论摘要/退费金额核算/课时单价认定/格式条款与违约金/
  办学许可与双减预收费/机构违约情形/培训贷与征信风险/交涉路径与时效/待办补正动作）
- `--json` 输出结构化结果（含结论、风险项、待办、建议退费金额）
- 退出码 0 / 2（关键信息缺失时给提示串，不崩）

## 边界

依通用规则整理，**不替代律师意见**；预收费监管细则、退费比例、可退范围**各地不同**，
一律以当地教育/人社主管部门、市场监督管理部门口径为准；
违约金是否调减、能否全额退费由司法机关认定，本表只给测算口径与证据方向，不作结果承诺。
