# 退费怎么算：课时单价、教材费、违约金

培训退费的核心争议几乎都集中在**三个扣减项**上：已消耗课时费、教材教辅物品费、违约金。
先把这三项算清楚，再去谈比例、谈投诉、谈起诉。

## 一、退费总公式

```
应退金额 = 实付总额
         − 已消耗课时费
         − 已发放且不可回收的教材教辅物品费（须事先约定）
         − 合理违约金（以实际损失为限）
```

- **实付总额**：以你实际掏出去的钱为准，含现金、刷卡、微信支付宝、以及**培训贷/分期实际放款**的部分。
  不要被"标价原价 39800、成交优惠价 30000"这种标价游戏绕进去，退费基数是**实付**，不是原价。
- **不应扣**：机构为促销虚高的"原价课时费"、未经事先约定的教材费、高于实际损失的违约金、
  已可回收却整笔扣除的教材、以及任何以"概不退费"为名的扣款。

## 二、课时单价怎么定（最关键的一步）

已消耗课时费 = 已消耗课时数 × **课时单价**。单价怎么来，按下列顺序：

1. **合同写明了课时单价的** → 用合同单价。
   但若合同单价明显高于"优惠后折算单价"（见下），且该课程确实是优惠价买的，
   可以主张按优惠后折算单价计扣。
2. **合同没写单价，或属优惠价/团购价买入的** → 用**优惠后折算单价**：
   ```
   折算单价 = 实付总额 ÷ (购买课时数 + 赠送课时数)
   ```
   **不按机构临时抬高的"原价"扣。** 机构最常用的套路是：报名时说"原价 400 元/课，
   今天给你 200"，退费时却按 400 扣 36 课时——多扣 7200 元。
3. **赠课（赠课时数）不单独计价，但摊薄单价**：分母要算上赠课。
   例：实付 30000 元、购买 120 课时、赠 30 课时，折算单价 = 30000 ÷ 150 = **200 元/课时**，
   而不是 30000 ÷ 120 = 250 元/课时。这几千元的差额就是赠课帮你省出来的。
4. **已消耗课时数以考勤/课时余额为准**：以机构单方后台数据为唯一依据的，要要求出示原始考勤；
   发现"已消耗课时 > 购买＋赠课总数"的，属于数据错误或恶意扣费，先书面异议。

## 三、教材教辅物品费能不能扣

| 情形 | 能否扣 |
|---|---|
| 已发放、不可回收（如已装订的教材、定制服装、拆解的器材），且**事先有约定** | 可以扣 |
| 已发放但**可以退货/回收**（全新未拆封教材、可退回的器材） | **先退货再结算差额**，不能整笔扣 |
| **未事先约定**就收的教材教辅费 | 不能当然扣；可要求返还未使用部分 |
| 纯口头"资料费""茶水费" | 无书面约定、无清单的，主张不扣 |

要点：**"事先约定"是硬门槛**。报名时口头说一句"教材费不退"通常不够，要有合同、收据、聊天记录
或缴费清单中的书面约定。

## 四、违约金：以实际损失为限，过高可主张调减

1. **法定/约定口径**：合同约定的违约金，以** actual 实际损失**为上限；主张违约金的机构要**举证**
   自己损失了多少。机构只拿一张"合同写了扣 30%"的纸，不能证明损失，就不足以支撑全额违约金。
2. **司法实践参考区间**：约定违约金明显超出实际损失、或超出**实付总额 20%~30%**区间的，
   实践中通常不全额支持，超出部分可主张**调减**。这是谈判和起诉时最常用的一句话。
3. **操作**：在采集表里把"实际损失金额"填上（如已支付的改期费、另找机构的差价、
   已发生的交通与时间成本），脚本会自动按下限/上限给出退费区间。
   没填实际损失的，先按机构主张数进入计算，同时把"请说明并举证实际损失"写进书面回函。

## 五、什么时候可以全额或高比例退

出现下列任一情形，通常可以主张**全额或高比例退费**，而不只是扣完课时费再补一点：

- 机构**停业、跑路、失联、闭店**，或长期不在约定地点办学
- 机构**迁址**至明显不便的地点（单方变更履行地点，学员可解约）
- **未按约定开课**、开课后**长期停课**或长期不开课
- **师资与承诺严重不符**（承诺名师、实际是无资质人员执教）
- **虚假宣传**：保过、包就业、名校保录、"名师"实际查无此人
- **无办学许可证**，或所报课程**超出许可范围**经营
- 机构**单方面变更课程地点/时间/形式**且拒绝协商
- 学员因**重大疾病、意外、不可抗力**无法继续（需医院证明、事故认定等证明材料）

## 六、格式条款：概不退费无效

- 合同里出现「概不退费」「开课后不退」「一经报名不退费」「费用不退」等表述的，
  属于**排除消费者主要权利、加重消费者责任的不公平不合理条款，无效**。
- 判断要点：是不是**格式条款**（对方预先拟好、未与你协商）、有没有尽到**提示说明义务**
  （加黑加粗、单独说明、签字确认）、是不是免除了机构自身责任。
- 即便条款写在合同里、你签了字，**不影响**你主张退费；口头承诺"可以退"的聊天记录同样有效。
- 机构拿"你签了合同"当挡箭牌时，正确的回应是：要求其**出具书面退费方案与计算明细**，
  并说明该条款的提示与协商过程。

## 六之二、三口径对照（谈判前先看差多少）

| 口径 | 适用情况 | 怎么算 |
|---|---|---|
| **机构主张口径** | 机构按合同原价＋最高违约金扣 | 用合同单价、扣教材费、按约定比例扣违约金 |
| **中性口径** | 消费者个人原因退费、合同有有效约定 | 折算单价、封顶 30% 违约金、有约定才扣教材费 |
| **有利口径** | 存在机构违约情形 | 折算单价、不扣违约金、教材费未约定不扣 |

三个口径都列出来，一眼就能看出机构开的价掉了多少，也知道谈判的地板在哪。

## 六之三、常见无效条款清单

| 条款写法 | 为什么站不住 |
|---|---|
| "一经报名，概不退费" | 排除消费者主要权利（解除权、返还请求权） |
| "开课后一律不退" | 同上，且不分违约方是谁 |
| "本机构对退费事宜拥有最终解释权" | 排除争议处理的正当途径 |
| "课时过期作废" | 未履行提示说明义务＋排除主要权利；机构自己没排课更站不住 |
| "违约金 50%，概不协商" | 明显高于实际损失，可主张调减 |
| "转班、转让仅限一次且需本机构同意" | 限制消费者权利，但不能据此认定不退 |

## 六之四、容易吃亏的算法错误

| 错误 | 正确做法 |
|---|---|
| 按"原价"扣已上课时 | 按合同约定单价，无约定按**优惠后折算单价** |
| 赠课不算进课时 | 赠课摊薄单价，必须算进总课时 |
| 教材费直接扣 | 没事先约定不扣；未拆封可二次销售的应退实物或折价 |
| 违约金按约定比例照扣 | 超过实际损失部分可主张调减，参考区间 20%~30% |
| 先扣完再看还剩多少 | 先判断机构有没有违约；机构违约时不适用"个人原因退费"算法 |
| 只看余额 | 要看合同还履行得了没有；履行不了谈的是**解除＋返还**，不是"剩余课时费" |

## 七、算完之后怎么用这个数

1. 拿测算金额当作**谈判底线**，不是目标值——谈成的数通常落在下限与上限之间。
2. 把公式和每一项依据写进给机构的书面回函（模板见 `templates/退费维权操作卡.md`），
   **要求对方出具同样口径的退费明细**。对方给不出或口径明显更高的，就是投诉与起诉的抓手。
3. 金额较小、证据较全的，可以直接走小额诉讼，比反复打电话有效。
