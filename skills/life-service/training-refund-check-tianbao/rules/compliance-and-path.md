# 合规抓手与投诉路径：从书面交涉到起诉

很多退费最后不是"算不清"，而是**找错人、走错门、错过时间**。这一节讲机构哪类问题能当抓手、
按什么顺序去要钱、找哪个部门、多长时间以内必须动。

> 所有时限与管辖口径以现行规定为准；地方差异大的，**以当地主管部门口径为准**。

## 零、课程类型自查（决定适用哪套规定）

| 类型 | 判定要点 |
|---|---|
| **学科类** | 语文、数学、外语、物理、化学、生物、道德与法治、历史、地理等学科类课程内容 |
| **非学科类** | 体育、艺术（音乐/美术/舞蹈）、科技、编程、综合素质类 |
| **职业技能类** | 面向成人的职业资格、技能等级、岗位培训（归人社部门） |
| **成人学历/自考助学** | 另有监管口径 |

**面向义务教育阶段学生的学科类培训，监管最严**——不得占用国家法定节假日、休息日、寒暑假，
一次性收费不得超过 3 个月或 60 课时。先自查这一条，命中就是最强的违规抓手。

## 一、先分清"你的培训属于哪一类"（决定找哪个部门）

| 类型 | 主管部门 | 说明 |
|---|---|---|
| 面向中小学学生的**学科类**培训（语数英物化生等） | **教育**主管部门 | 需办学许可（或审批/备案，各地口径不同） |
| **非学科类**培训（体育、艺术、编程、研学等） | **教育**或**文化旅游、体育**等主管部门（按当地分工） | 备案制居多，各地归口不一 |
| **职业技能**培训、考培（会计、医师、人社类资格） | **人力资源社会保障**主管部门 | 看其许可/备案类别 |
| 成人学历、留学、考研、兴趣班 | 无专门许可的，多半属**市场监管/消协**管辖 | 按合同关系处理 |
| 涉及**预收费存管**的 | 教育/人社 + 市场监管 | 可查是否纳入资金存管 |

一句话：**先看有没有办学许可、许可类别是什么**，这决定了投诉往哪递、也决定了机构有没有硬伤。

## 二、双减与预收费监管：最有力的两个抓手

### 1. 培训时间（学科类、义务教育阶段）

面向义务教育阶段学生的**学科类**培训机构，**不得占用国家法定节假日、休息日及寒暑假期**
组织培训。若发现机构在周末、寒暑假集中排课上课，属违规，可作为退费与投诉的直接理由。
非学科类、以及高中阶段/成人培训的时段安排，按当地规定执行，**以现行规定为准**。

### 2. 一次性收费上限

培训机构一次性收费**不得超过 3 个月或 60 课时**（预收费监管的通行要求；
非学科类的预收费监管各地也在趋同，具体上限以当地规定为准）。

**关键点：超期超额收费本身即属违规**，不是"多收了再退回来"那么简单——
它可以让整笔交易处于不规范状态，是谈判时最有分量的筹码之一：

- 谈判用法：先主张"这笔收费本身违规"，再主张退费，机构通常比只谈退费更容易让步；
- 投诉用法：把"一次性收费 6 个月 / 120 课时，超 3 个月 60 课时上限"写进投诉正文第一段。

## 三、阶梯式交涉路径（按顺序走，别跳步）

### 第 1 步 · 书面交涉（必做，且必须留痕）

- 对象：机构前台、课程顾问、收银/财务，最好同时抄送其**总部/品牌方**。
- 形式：书面退费申请书（微信/短信/邮件皆可），**注明年月日**，要求签收回执；
  没回执就发"已送达+请于 X 日内回复"的文字，用可查看、可导出的方式。
- 内容四要素：**要求退多少 → 怎么算出来的 → 依据哪几条 → 几日内答复**。
- 明确要求机构出具**退费方案与计算明细**（课时单价依据、已消耗课时、教材费、违约金）。

### 第 2 步 · 总部 / 总校 / 品牌方

很多"校区"只是加盟店，钱收进来就交了租金和提成，**真正的收费主体与责任方是总部或品牌方**。
投诉只投到校区的，常常被一句"这是我们校区行为"打发。第 2 步一定要往上追一层。

### 第 3 步 · 主管部门 + 12345 + 12315/消协

- **教育**主管部门（学科类、非学科类）、**人力资源社会保障**主管部门（职业技能类）
- **市场监督管理（12315）**：合同欺诈、虚假宣传、格式条款、价格问题
- **12345** 市民热线：统一派单，适合跨部门、需要督办的
- **消费者协会（消协）**：消费争议调解，可请求支持起诉
- 涉及**预收费超期超额、无办学许可、超范围经营**的，把这两点写进正文，命中率高。

### 第 4 步 · 仲裁（合同有仲裁条款时）

合同里订有仲裁条款的，按约定的仲裁机构申请仲裁；**没有仲裁条款的才能直接起诉**，
不要以为"签了合同"就等于必须仲裁。

### 第 5 步 · 小额诉讼 / 集体维权

- 涉案金额小的走**小额诉讼**（标的额符合当地小额诉讼标准的，多数地区实行一审终审、
  流程快、成本低、诉讼费低），性价比最高。
- 同类学员多的（同一家店、同一批招生、同样的"概不退费"条款）做**集体维权/联名投诉**：
  共同投诉材料 + 各自的合同与付款凭证，处理速度和结果明显优于单人。
- 起诉主张写全：**解除培训合同、返还剩余培训费用、支付资金占用利息、承担合理维权成本**；
  有转移财产迹象的可申请**财产保全**。

## 四、时效与证据（别拖）

| 事项 | 期限 |
|---|---|
| **民事诉讼时效** | **3 年**，自知道或应当知道权利被侵害及义务人之日起算 |
| 向主管部门投诉举报 | 无硬性前置期限，但**尽早**；拖久会出现证据灭失、主体注销、经办人离职 |
| 协商交涉 | 建议 7~15 日内完成一轮书面交涉，再走主管部门 |
| 贷款还款 | 按贷款合同约定，逾期影响征信，不因退费争议停还（详见 `rules/training-loan.md`） |

## 五、材料清单（交涉和投诉都要带）

1. **培训合同/协议**（含补充协议、电子签存的截图）
2. **付款凭证与发票、收据**（微信/支付宝账单、POS 单、分期还款计划表）
3. **课程表、课时余额截图、考勤记录**（App/小程序里导出，最好录屏）
4. **招生宣传页、课件招生话术、"保过/包就业/名师"的聊天与录音**
5. **机构现状证据**：闭店照片、停业公告、搬迁通知、PE 门头换成别的牌子的照片
6. **书面交涉记录**：退费申请、对方回复、聊天截图、通话录音、快递单号
7. **贷款合同与还款流水**（如有培训贷）
8. **身份证明与学员关系证明**（学员本人/监护人关系证明）

## 五之二、可主张强度分级（从强到弱）

| 序 | 事由 | 通常能主张到什么程度 |
|---|---|---|
| 1 | 机构**跑路/停业/注销**、联系不上 | 未履行部分全额返还，可集体维权 |
| 2 | **从未开课**或未履行主要义务 | 全额返还 |
| 3 | **无办学许可 / 超范围经营** | 全额返还为主谈判诉求 |
| 4 | **虚假宣传**（保过、保就业、名师） | 全额返还＋可主张欺诈赔偿（另行认定） |
| 5 | **预收费超期超额**（超 3 个月或 60 课时） | 超期超额部分本身即违规，可作全额/高比例退还的抓手 |
| 6 | **长期停课**、未按约定开课 | 未履行部分全额或高比例 |
| 7 | **师资严重不符**、擅自变更课程/地点/时长 | 协商不成可主张解除并高比例返还 |
| 8 | **迁址明显不便** | 未履行部分返还，宜主张不扣违约金 |
| 9 | **重大疾病 / 不可抗力**（需证明） | 可主张免除或减轻违约金，退还剩余部分 |
| 10 | **单纯个人原因**（搬家、没兴趣了） | 按合同约定处理，违约金以实际损失为限并可主张调减 |

**关键区分：事由的性质决定算法。** 机构违约 → 走"有利口径"；个人原因 → 走"中性口径"。
别错用了口径，把自己砍一刀。

## 五之三、查证入口与材料清单

- 查机构资质：当地教育局官网"校外培训机构白名单/黑白名单"、
  全国校外教育培训监管与服务综合平台、**国家企业信用信息公示系统**（查营业执照经营范围）。
- 常用材料：培训合同/报名协议/电子签页｜银行流水与微信支付宝账单、POS 单、收据发票（**收款方是不是机构本身很关键**）｜课程表、App 课时余额、考勤签到与消课记录（**余额截图要带日期**）｜宣传页、简章、公众号推文、销售聊天、直播回放｜停业照片、搬空教室、失联截图、注销信息｜借款合同与还款流水（如有）｜书面催告函（EMS 面单＋内件详情）、投诉工单号、回复截图。
- **证据形态要点**：截图要**带时间和对方头像/昵称**；最好做**录屏**（从"添加好友"翻到全部聊天记录）；
  必要时用时间戳、公证或可信时间戳固定。

## 五之四、时效会中断，别只打电话

- **一般民事诉讼时效 3 年**，自知道或应当知道权利受到损害及义务人之日起算。
- **时效会中断**：你向对方提出履行请求（书面催告、投诉、起诉）或对方同意履行的，
  时效**从中断之日起重新计算 3 年**。
- 所以：书面催告＋留底单据，既是主张权利的凭证，也是中断时效的手段。
- 按金额选路径：

| 金额 | 建议路径 |
|---|---|
| 1000 元以下 | 书面交涉＋12345/12315＋消协调解，成本最低 |
| 1000~20000 元 | 书面交涉＋主管部门＋**小额诉讼**（自己起诉，不必请律师） |
| 20000 元以上 | 完整路径，必要时委托律师 |
| 涉及培训贷 | **不论金额都要正式处理**，因为不还会影响征信，成本远高于课时费本身 |

## 六、别踩的坑

- **别只看"不退费条款"就退缩**：条款无效不等于你不能退（见 `rules/refund-calc.md` 第六节）。
- **别拖到时效届满**：3 年从"知道权利被侵害"起算，跑路门店的注销日期、最后一次上课日、
  最后一次交涉日都可以作为起算点，越早动越好。
- **别只打 12345 不要求在办结页写理由**：要求把"不支持退费的理由"写进工单回复，
  这段文字往往能反推出机构自己的计算口径，成为下一步证据。
- **别在证据不全时先起诉**：起诉状里算错的金额，会被对方拿来论证你"不讲道理"。
  先把课时余额、付款额、合同条款固定好。
