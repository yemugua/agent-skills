# 吉他调音（guitar-tuning-method）

调音问题的核心是：**「听着差不多」不是标准，音分才是。**

同样差 1 赫兹，在低音弦上是几音分，在高音弦上是几十音分。**必须用相对的音分，不能用绝对的频率差。**

这个技能做三件事：**算标准音 → 量化偏差 → 核调弦步骤**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出标准调弦下六根空弦的频率与音分判定 | ❌ 设定特殊调弦法（DADGAD、降半音等）的具体音高 |
| 核查五品调弦法与泛音法的步骤 | ❌ 调整琴颈弯曲度、弦距、琴枕琴桥补偿 |
| 说明调音方法与跑音原因 | ❌ 推荐具体品牌型号的调音器、琴弦与变调夹 |
| 提示何时应找专业维修 | ❌ 替代专业琴行或维修师傅的判断 |

**遇到以下情况，按各自渠道处理：**

- **空弦准但按品偏高（八度音准不准）** → 属琴枕或琴桥补偿问题，**应找专业琴行或维修师傅处理，调音解决不了**
- **琴颈弯曲、打品、弦距过高** → 属维修调整范围，找专业琴行
- 需要**特殊调弦法**的音高设定 → 不在本技能范围
- 需要**选购调音器或琴弦** → **本技能不推荐品牌型号**

**安全提示**：调音时**不要把弦调得过紧超出该弦设计张力**，尤其换用更粗规格的弦时，过紧有断弦伤人的风险。

## 二、完整工作流

### 第一步：先定 6 弦

用调音器或参照音源把 **6 弦调到标准 E（82.41 赫兹）**。

**这一步不能跳。** 五品调弦法只能保证六根弦彼此的相对关系正确，**6 弦不准，全琴都不在标准音高上**。

### 第二步：按 6→1 的顺序推

| 步骤 | 操作 | 目标 |
|---|---|---|
| 1 | 6 弦 **5 品** 按音 | 与 5 弦空弦同高 |
| 2 | 5 弦 **5 品** 按音 | 与 4 弦空弦同高 |
| 3 | 4 弦 **5 品** 按音 | 与 3 弦空弦同高 |
| 4 | **3 弦 4 品** 按音 | 与 2 弦空弦同高 ← **唯一例外** |
| 5 | 2 弦 **5 品** 按音 | 与 1 弦空弦同高 |

**为什么第 4 步是 4 品**：3 弦 G 到 2 弦 B 是**大三度**（4 个半音），不是纯四度。**如果这一步还按 5 品，二弦就会被调低半音，整把琴的和弦都会是错的。**

### 第三步：每根调完回弹一次

新调的弦会牵动琴颈张力，**前面的弦会轻微跑掉**。

### 第四步：最后复核一遍

从 6 弦到 1 弦再走一遍，确认全部在 **5 音分以内**。

### 第五步：弹常用和弦验证

弹 **C、G、Em** 各一遍，耳朵听着舒服才算完。

**调弦的省力技巧**：**先把弦调低一点再往上调到目标音高**，不要从高往低调。从高往低调时弦在弦枕处容易卡住，之后弹奏会跑音。

## 三、核心规则（生成结论前先读规则文件）

**必须先读 `rules/调音方法与音准检查.md`，不要凭印象写。** 规则文件里有：

- 六根空弦的音名、科学音高与频率表
- 音分公式与四级判定表
- 四种调音方法的精度与前提
- 五品调弦法五步与唯一例外的原理
- 泛音法四步与听拍音的方法
- 调音五步操作与新弦跑音等四个坑
- 判定顺序说明与八条高频坑

**判定顺序不能颠倒**：先看严重项（任意一根弦偏差超过 10 音分、五品法第 4 步用错品数），再看可改进项，最后才看信息是否完整。

**为什么这条重要**：若先判信息完整度，会出现「某根弦已经偏了 40 音分，却因为少填一根弦而被判成待确认」——把问题说轻了，比漏判更糟。

## 五、脚本用法

```bash
python scripts/guitar_tuning_check.py --file tuning.json --out 调音核查.md
python scripts/guitar_tuning_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`strings` 为六根弦的实测频率，`method` 为调音方法，`steps` 为五品法步骤 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检（63 条断言，含 BOM 两条路径） |

输入 JSON 示例：

```json
{
  "reference_a4": 440,
  "method": "fifth_fret",
  "strings": [
    {"key": "s6", "freq": 82.41},
    {"key": "s5", "freq": 110.00},
    {"key": "s4", "freq": 146.83},
    {"key": "s3", "freq": 196.00},
    {"key": "s2", "freq": 246.94},
    {"key": "s1", "freq": 329.63}
  ],
  "steps": [
    {"from": "s6", "fret": 5, "to": "s5"},
    {"from": "s5", "fret": 5, "to": "s4"},
    {"from": "s4", "fret": 5, "to": "s3"},
    {"from": "s3", "fret": 4, "to": "s2"},
    {"from": "s2", "fret": 5, "to": "s1"}
  ]
}
```

`strings` 的 `key` 取 `s6` 到 `s1`（也可用音名 `E2` / `A2` / `D3` / `G3` / `B3` / `E4`）；
`method` 取 `tuner` / `fifth_fret` / `harmonic` / `reference` / `ear`；
`reference_a4` 为参考音高，默认 440 赫兹；
`steps` 只在用五品法时必填，`from` 与 `to` 必须是相邻的两根弦。
另有 `capo`（是否用变调夹）与 `retune_for_capo`（是否因变调夹改了调音目标）两个布尔字段。

脚本输出：总体判定、六根弦逐根判定表（标准频率、实测频率、音分偏差、判定）、问题与整改表、五品调弦法表、调音方法表、音分阈值表、人工确认清单，并给出偏差最大的弦作为优先整改对象。

## 六、人工确认清单（这步不能省）

- [ ] 6 弦已用调音器或参照音源调到标准 E
- [ ] 五品法第 4 步用的是 4 品，不是 5 品
- [ ] 每根弦是从低往高调上去的，不是从高往低调
- [ ] 六根调完后再复核一遍
- [ ] 弹 C、G、Em 各一遍，耳朵听着舒服
- [ ] 换弦或换环境后重新调过
- [ ] 没有把弦调得过紧超出设计张力

---

## 七、最常见的坑

**坑一：五品法第 4 步按了 5 品。**
错误做法：一路五品推下来，到 3 弦对 2 弦也是 5 品。正确做法：**3 弦到 2 弦是大三度，必须按 4 品**。按成 5 品，二弦会被调低半音，整把琴的和弦全是错的。

**坑二：五品法没先定 6 弦。**
错误做法：拿起琴就从 6 弦 5 品开始对。正确做法：**先用调音器或参照音源把 6 弦调到标准 E**。五品法只保证相对关系，6 弦不准全琴都不在标准音高上。

**坑三：纯靠耳朵调，没有参照音源。**
错误做法：凭记忆哼个音就开调。正确做法：**没有参照音高时，人很容易把整把琴整体调高或调低**，六根弦彼此是准的，但整体不在标准音高上。

**坑四：从高往低调弦。**
错误做法：弦紧了就往回松一点。正确做法：**先把弦调低再往上调到目标音高**。从高往低调时弦在弦枕处容易卡住，弹一会儿就跑音。

**坑五：调完不复核。**
错误做法：六根走一遍就收工。正确做法：**调后面几根时前面的会轻微跑掉**，全部调完必须从 6 弦到 1 弦再走一遍。

**坑六：换了新弦调一次就完事。**
错误做法：换完弦调一遍就开始弹。正确做法：**新弦需要拉伸稳定**，换完弹几分钟再调，反复两三次才稳。换弦时可以沿弦长方向轻拉几下帮助拉伸。

**坑七：换了环境不重调。**
错误做法：在家里调好，到现场直接弹。正确做法：**温度湿度变化会让琴弦热胀冷缩**，到了现场要重新调一次。

**坑八：空弦准但和弦难听，就一直调。**
错误做法：和弦难听就反复调音，越调越乱。正确做法：**先确认是不是八度音准问题**——空弦准、按品偏高，那是琴枕或琴桥补偿的问题，调音解决不了，**应找专业琴行或维修师傅处理**。

## 八、边界与免责

- 本技能讲的是**民谣/古典吉他标准调弦（EADGBE）下的调音方法与音准检查**
- **不涉及特殊调弦法**（如 DADGAD、降半音调弦）的具体音高设定
- **不涉及琴颈弯曲度、弦距、琴枕琴桥补偿**的调整；**八度音准不准应找专业琴行或维修师傅处理，不是调音能解决的**
- **不推荐具体品牌型号**的调音器、琴弦与变调夹
- 标准频率以 **A4 等于 440 赫兹** 为基准；若乐队或录音使用其他参考音高，请自行调整 `reference_a4`
- **调音时不要把弦调得过紧超出该弦设计张力**，尤其换用更粗规格的弦时，过紧有断弦伤人的风险
- 本技能不构成任何调音结果或演奏效果的担保
