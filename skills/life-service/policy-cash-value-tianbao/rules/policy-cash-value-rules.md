# 保单现金价值与退保损失规则库

> 本规则库按长期人身保险合同的常见结构整理。**现金价值以合同载明的现金价值表为准**；**犹豫期天数与退还范围以合同约定为准**；**退保、部分领取、减额交清与保单贷款的办理口径以合同约定与承保公司实际流程为准**。本库不劝诱退保，也不劝诱继续持有，不推荐产品。

---

## 一、退保损失公式

```
退保损失 = 已交保费 − 退保时可退金额

损失率 = 退保损失 ÷ 已交保费 × 100%
```

| 情形 | 退保时可退金额 |
|---|---|
| 犹豫期内解除合同 | **合同约定的退还范围**（可能扣除合同约定的费用），**以合同约定为准** |
| 犹豫期届满后解除合同 | **合同载明的现金价值表**对应保单年度的金额 |

**三句必读**：

1. **现金价值以合同载明的现金价值表为准。**
2. **犹豫期天数以合同约定为准。**
3. **犹豫期内的退还范围以合同约定为准**，可能扣除合同约定的费用。

**绝对禁止**：

- 「现金价值 = 已交保费」
- 「退保能拿回全部保费」
- 「再交几年一定回本」
- 「犹豫期内一定全额退还」（无合同依据时）

---

## 二、现金价值表的读法

| 步骤 | 操作 |
|---|---|
| 1 | 在合同或附件中找**现金价值表**（有时叫「退保金额表」「保单现金价值表」） |
| 2 | 找**保单年度**列（年度通常从第 1 保单年度开始编号） |
| 3 | **按当前保单年度**读金额，**不是按已过自然年数读** |
| 4 | 核对保单状态（有效 / 失效 / 复效中、是否欠费） |
| 5 | 表上有多个方案或多个责任时，分别读取后合计 |

### 2.1 常见误读

| 误读 | 正确口径 |
|---|---|
| 把「缴费第 5 年」当「第 5 保单年度」 | **保单年度**按合同约定起算，不一定等于缴费年数 |
| 用已交保费按比例折算现金价值 | **现金价值按表读，不按比例折算** |
| 看宣传页「现金价值走势图」代替合同表 | **以合同载明的表为准** |
| 忘了有多个责任或多个档次 | 分别读取后合计 |
| 以为失效保单也能按表退 | **失效保单处理口径与有效保单不同，须向承保公司确认** |

### 2.2 多责任多档次

同一张保单可能包含多个责任（如主险 + 附加责任），或同一产品分多个档次。**每个责任或档次对应各自的现金价值**，**必须分别读取后合计**，不能只读主险那一行。

---

## 三、保单年度与回本年度判定

```
第 n 保单年度现金价值 = 现金价值表第 n 行金额
第 n 保单年度已交保费 = 截至第 n 保单年度实际已缴的保费累计
第 n 保单年度是否已回本 = 第 n 保单年度现金价值 ≥ 第 n 保单年度已交保费
```

**三条必读**：

1. **回本年度只能由现金价值表判断**，不能凭感觉报
2. **表上还没有到你缴费结束的年度，就不存在「回本」这一说**（未交保费不算已交保费，退出时也拿不回未交部分）
3. **回本不等于应该退**：回本后继续持有还是退出是另一个问题，本规则库只给数据

**禁止**：用「快回本了」劝人继续交，或用「还没回本」劝人退保。

---

## 四、犹豫期内与犹豫期外对照

| 情形 | 可退金额口径 | 必写 |
|---|---|---|
| **犹豫期内**解除合同 | **合同约定的退还范围**，可能扣除合同约定费用 | **以合同约定为准**，不得说成一定全额退还 |
| **犹豫期届满后**解除合同 | **现金价值表**对应保单年度金额 | **退保损失 = 已交保费 − 现金价值**，前期可能接近甚至超过全部已交保费 |
| **缴费期内**解除合同 | 只能拿现金价值 | **未交的未来保费不退** |
| **缴费期满后**解除合同 | 按现金价值表 | 与犹豫期无关，**犹豫期只在前段有效** |

**表述纪律**：犹豫期内的退还口径**不是**「已交保费全额」；犹豫期外的退还口径**不是**「已交保费」。

## 五、三种「少拿点」的路径

| 方式 | 机制 | 口径 | 注意 |
|---|---|---|---|
| **部分领取**（部分支取） | 在保单现金价值中支取一部分，**保单继续有效** | 可支取比例、每次上限、次数限制**以合同约定为准** | 部分领取后**剩余现金价值与后续利益会变化**，不能简单按比例推算，须向承保公司确认 |
| **减额交清** | 用现金价值抵扣未来应交保费，**保额相应减少** | **以合同载明的现金价值与减保规则为准** | 减额交清后**保额下降**，保障范围随之变化 |
| **保单贷款** | 以保单为担保借款，到期归还 | 额度通常不超过现金价值的一定比例，**有利息与还款期限** | **贷款不等于领取**，到期未还可能影响保单效力 |

**必须说明的三组区别**：

- **部分领取 ≠ 退保**（合同是否继续有效）
- **减额交清 ≠ 退保**（保额是否下降）
- **保单贷款 ≠ 领取**（是否需要还本付息）

---

## 六、费用口径

| 费用项 | 口径 |
|---|---|
| 犹豫期内解除的费用 | **以合同约定为准**，可能存在约定的扣除项 |
| 退保手续费 | 是否存在、怎么算，**以合同约定为准** |
| 保单贷款利息 | 利率与计息方式，**以合同约定为准** |
| 减额交清后的保额 | **以合同载明的现金价值与减保规则为准** |

**不得编造具体费率与扣除金额。**

---

## 七、保单状态对核算的影响

| 状态 | 影响 |
|---|---|
| 有效 | 按合同正常计算 |
| 欠费宽限期内 | 效力状态与利益可能受影响，须确认 |
| 已失效 | **处理口径与有效保单不同**，不能直接按表算 |
| 复效中 / 已复效 | 复效条件、复效费用会影响后续利益 |
| 减额交清后 | **保额已下降**，后续现金价值与利益已变 |

**必须先确认保单状态，再算钱。**

## 八、防误伤（否定词）清单

| 见到这些情况 | 必须这样判 | 严禁这样写 |
|---|---|---|
| 现金价值表有该年度金额 | 判为**按表读数** | 按已交保费折算 |
| 现金价值低于已交保费 | 判为**正常现象**，退保损失为正 | 「亏了，公司坑人」 |
| 在犹豫期内 | 判为**退还范围以合同约定为准** | 「一定全额退还」 |
| 犹豫期已届满 | 判为**按现金价值表** | 「按已交保费退」 |
| 缴费期内退保 | 判为**未交保费不退** | 「把剩下的交完再退」 |
| 表上未到缴费结束年度 | 判为**不存在回本这一说** | 「再交几年就回本」 |
| 已提交退保申请 | 判为**退保办理中，未退保** | 「已退保」 |
| 款项已到账、合同已解除 | 判为**已退保** | 仍写成「办理中」 |
| 保单失效 | 判为**处理口径须向承保公司确认** | 直接按表算 |
| 部分领取 | 判为**合同继续有效，剩余利益变化** | 「等于退保」 |
| 减额交清 | 判为**保额下降** | 「等于退保」 |
| 保单贷款 | 判为**需还本付息** | 「等于领取」 |
| 未如实告知 | 判为**可能导致不承担给付责任** | 「已如实告知」 |

## 九、争议处理路径

| 情形 | 建议路径 |
|---|---|
| 现金价值金额有争议 | 调取合同载明的现金价值表与对应保单年度行 |
| 保单年度认定有争议 | 调取合同成立日与保单状态记录，核对起算点 |
| 犹豫期是否届满有争议 | 向承保公司以书面/官方渠道确认并留存记录 |
| 部分领取金额有争议 | 调取领取时的现金价值与可支取比例约定 |
| 减额交清后保额有争议 | 调取减保申请记录与合同减保规则 |
| 拒绝受理退保 | 走正规投诉与调解渠道，必要时咨询律师 |

**不建议**：在争议未解决前继续缴费或贸然办理减额交清，以免影响自身权益主张。

---

## 十、免责

本规则库为投保实践整理，**不构成保险代理、保险经纪、投资建议或法律意见**。**现金价值以合同载明的现金价值表为准**；**犹豫期天数与退还范围以合同约定为准**；**退保、部分领取、减额交清与保单贷款的办理口径以合同约定与承保公司实际流程为准**；**费用项以合同约定为准**。本库**不劝诱退保，也不劝诱继续持有**，不推荐具体产品，不承诺回本或全额退还，争议以承保公司核定结论为准。
