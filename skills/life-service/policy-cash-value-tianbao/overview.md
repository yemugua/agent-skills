# 保单现金价值与退保损失核算

## 你会得到什么

一套把「现在退能拿回多少、要亏多少、哪一年才算回本」按合同载明的现金价值表算清楚的口径，避免用已交保费高估能拿回的钱。

- **退保损失公式**：**退保损失 = 已交保费 − 退保时可退金额**，**损失率 = 退保损失 ÷ 已交保费**。可退金额在犹豫期内按**合同约定的退还范围**，犹豫期届满后按**合同载明的现金价值表对应保单年度的金额**。
- **现金价值表读法五步**：找到表 → 找保单年度列 → 按当前保单年度读数 → 核对保单状态 → 多个责任/档次分别读取后合计。附**五类常见误读**（把缴费年数当保单年度、按比例折算现金价值、用宣传页走势图代替合同表、漏读附加责任、以为失效保单也能按表退）。
- **保单年度与回本年度判定**：**回本 = 当年现金价值 ≥ 当年已交保费**，**只能由表判断**；表上还没到缴费结束年度就不存在「回本」这一说，未交的未来保费退时也拿不回。
- **犹豫期内 vs 犹豫期外对照表**：犹豫期内**退还范围以合同约定为准**（不得说成一定全额退还）；犹豫期届满后**只能按现金价值表**，前期可能接近甚至超过全部已交保费。
- **三种「少拿点」的路径分清**：**部分领取**（合同继续有效，剩余现金价值与后续利益会变化）、**减额交清**（**保额下降**）、**保单贷款**（**要还本付息**，到期未还可能影响保单效力）。
- **保单状态对核算的影响**：有效 / 欠费宽限 / 已失效 / 复效中 / 减额交清后各不相同，**必须先确认状态再算钱**。
- **防误伤清单**：现金价值 ≠ 已交保费；犹豫期内 ≠ 一定全额退还；回本 ≠ 值得退；「已提交退保申请」≠「已退保」；部分领取 ≠ 退保；减额交清 ≠ 退保；保单贷款 ≠ 领取。
- **脚本核算**：`scripts/cash_value_calc.py` 一次算出当前保单年度现金价值、已交保费、退保损失与损失率、是否已回本、逐年损失率对照与口径提示。

## 典型用法

- 交了几年了，现在退能拿多少、亏多少
- 学会看合同里的现金价值表，定位自己那一行
- 判断按现在的保费水平，哪一年才可能回本
- 犹豫期过了没，现在退和再交几年哪个损失小
- 想只拿一部分，不想全退，区分部分领取、减额交清、保单贷款
- 保单失效了还能不能按表退

## 边界

不构成保险代理、保险经纪、投资建议或法律意见，不替代保险合同约定与承保公司核定。**现金价值以合同载明的现金价值表为准**；**犹豫期天数与犹豫期内退还范围以合同约定为准**；**退保、部分领取、减额交清与保单贷款的办理口径以合同约定与承保公司实际流程为准**；费用项以合同约定为准，不编造具体费率与扣除金额。测算为静态口径，未含保单贷款利息累计、宽限期、复效条件、红利分配方式、缴费方式变更、受益人变更等情形。**不劝诱退保，也不劝诱继续持有**，不承诺回本或全额退还，不推荐具体产品。争议以承保公司的核定结论为准，涉及纠纷走正规投诉与调解渠道。
