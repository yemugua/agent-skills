# 保单现金价值与退保损失核算

退保这件事只有一个公式：**退保损失 = 已交保费 − 现金价值**。

关键在第二步：**现金价值必须从合同载明的现金价值表里按保单年度读出来，不能用已交保费替代，也不能按「每年交多少倒推」估。**

这个技能做五件事：**取表 → 定位年度 → 减已交 → 出损失率 → 判回本**。

---

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 按现金价值表逐保单年度读数并核算退保损失 | 推荐具体产品、劝诱退保、劝诱继续持有 |
| 区分犹豫期内与犹豫期外的退还口径 | 承诺「退保不亏」「再交几年就回本了」而无表可依 |
| 输出各保单年度的损失率对照表 | 用已交保费、按年保费折算等方式替代现金价值表 |
| 说明部分领取、减额交清、保单贷款的口径区别 | 承诺部分领取一定能领到多少 |
| 提示现金价值表的读法与常见误读 | 编造具体条款号、产品名与现金价值数值 |
| 提示退保办理的流程与材料口径 | 代替承保公司作退保受理与金额核定 |

涉及以下情形，应停下来交由承保公司、持牌保险代理人或律师处理：**退保金额争议、现金价值表与实际给付不一致的投诉、保单效力状态异常（失效、复效）、减保与保单贷款后利益变化的确认、涉及退保纠纷的投诉与调解**。

**绝对不做**：**不劝诱退保，也不劝诱继续持有**。**现金价值以合同载明的现金价值表为准**；**犹豫期天数以合同约定为准**；**退保办理口径以合同约定与承保公司实际流程为准**。

## 三、完整工作流

```
第 1 步  取三样材料：保险合同、现金价值表（合同组成部分或附件）、缴费记录
第 2 步  确认保单状态：有效 / 失效 / 复效中；确认保单年度起算点
第 3 步  读规则文件 rules/policy-cash-value-rules.md（现金价值表读法、
        退保损失公式、犹豫期内外口径、部分领取与减额交清、防误伤清单）
第 4 步  定位当前保单年度对应的现金价值表行
第 5 步  汇总已交保费（按缴费记录，不含未缴期数）
第 6 步  跑脚本：scripts/cash_value_calc.py --file case.json
第 7 步  算退保损失 = 已交保费 − 现金价值，算损失率
第 8 步  逐年度列出损失率对照，判断回本年度（若表中有对应年度）
第 9 步  分情形说明：犹豫期内 / 犹豫期外 / 部分领取 / 减额交清 / 保单贷款
第 10 步 输出结论口径与「必须由合同与承保公司确认」的事项，不下买卖指令
```

## 四、核心口径（必须算得出来）

### 4.1 退保损失公式

```
退保损失 = 已交保费 − 退保时可退金额

其中：
  犹豫期内解除合同 → 退保时可退金额 = 合同约定的退还范围（以合同约定为准）
  犹豫期届满后解除合同 → 退保时可退金额 = 合同载明的现金价值表
                                    对应保单年度的金额

损失率 = 退保损失 ÷ 已交保费 × 100%
```

**必须写清的三句**：

1. **现金价值以合同载明的现金价值表为准。**
2. **犹豫期天数以合同约定为准。**
3. **犹豫期内的退还范围以合同约定为准**，可能扣除合同约定的费用；**不得说成「一定全额退还」**。

**绝对禁止**：「现金价值 = 已交保费」「退保能拿回全部保费」「再交几年一定回本」。

### 4.2 现金价值表的读法

| 步骤 | 操作 |
|---|---|
| 1 | 在合同或附件中找到**现金价值表**（有时叫「退保金额表」「保单现金价值表」） |
| 2 | 找到**保单年度**列（年度通常从第 1 保单年度开始编号，与「缴费第几年」不是同一个概念） |
| 3 | **按当前保单年度**读出对应金额，**不是按已过自然年数读** |
| 4 | 核对读取的年度与保单状态（是否失效、是否复效、是否有欠费） |
| 5 | 若表上有多个方案或多个责任，分别读取后合计 |

**常见误读**：

| 误读 | 正确口径 |
|---|---|
| 把「缴费第 5 年」当「第 5 保单年度」 | **保单年度**按合同约定起算，不一定等于缴费年数 |
| 用已交保费按比例折算现金价值 | **现金价值按表读，不按比例折算** |
| 看产品宣传页的「现金价值走势图」代替合同表 | **以合同载明的表为准** |
| 忘了有多个责任或多个档次 | 分别读取后合计 |
| 以为失效保单也能按表退 | **失效保单的处理口径与有效保单不同，须向承保公司确认** |

### 4.3 保单年度与回本年度

```
第 n 保单年度现金价值 = 现金价值表第 n 行金额
第 n 保单年度已交保费 = 截至第 n 保单年度实际已缴的保费累计
第 n 保单年度是否已回本 = 第 n 保单年度现金价值 ≥ 第 n 保单年度已交保费
```

**必须说明**：

- **回本年度只能由现金价值表判断**，不能凭感觉报
- **如果表上还没有到你缴费结束的年度，就没有「回本」这一说**（未交完的保费不算已交保费，但退出时也拿不回未交部分）
- **回本不等于值得退**：回本后继续持有还是退出，是两个不同的问题，**本技能只给数据**

### 4.4 犹豫期内与犹豫期外的差异（必写）

| 情形 | 可退金额口径 | 必须写清 |
|---|---|---|
| **犹豫期内**解除合同 | **合同约定的退还范围**，可能扣除合同约定的费用 | **以合同约定为准**，**不得说成一定全额退还** |
| **犹豫期届满后**解除合同 | **合同载明的现金价值表**对应保单年度金额 | **退保损失 = 已交保费 − 现金价值**，前期可能接近甚至超过全部已交保费 |
| **缴费期内**解除合同 | 只能拿现金价值 | **未交的未来保费不退**，也不能「交完再退」 |
| **缴费期满后**解除合同 | 按现金价值表 | 与犹豫期无关，**犹豫期只在前段有效** |

**表述纪律**：犹豫期内的退还口径**不是**「已交保费全额」，犹豫期外的退还口径**不是**「已交保费」。

### 4.5 三种「少拿点」的路径（必须分清）

| 方式 | 机制 | 口径 | 需要注意 |
|---|---|---|---|
| **部分领取**（部分支取） | 在保单现金价值中支取一部分，保单继续有效 | 可支取比例、每次上限、次数限制**以合同约定为准** | 部分领取后，**剩余现金价值与后续利益会变化**，不能简单按比例推算，须向承保公司确认 |
| **减额交清** | 用现金价值抵扣未来应交保费，保额相应减少 | **以合同载明的现金价值与减保后的保额为准** | 减额交清后**保额下降**，保障范围随之变化 |
| **保单贷款** | 以保单为担保借款，到期归还 | 贷款额度通常不超过现金价值的一定比例，**有利息与还款期限** | **贷款不等于领取**，到期未还会影响保单效力 |

**必须说明**：

- **部分领取 ≠ 退保**：退保是解除合同，部分领取后合同继续有效
- **减额交清 ≠ 退保**：保额会下降
- **保单贷款 ≠ 领取**：要还本付息，到期未还可能影响保单效力
- 三者的具体比例、上限、利息与期限**均以合同约定与承保公司实际流程为准**

### 4.6 相关费用的口径

| 费用项 | 口径 |
|---|---|
| 犹豫期内解除的费用 | **以合同约定为准**，可能存在约定的扣除项 |
| 退保手续费 | 是否存在、怎么算，**以合同约定为准** |
| 保单贷款利息 | 利率与计息方式，**以合同约定为准** |
| 减额交清后的保额 | **以合同载明的现金价值与减保规则为准** |

**不得编造具体费率与扣除金额。**

## 五、核心规则与要件库

出结论前，**必须先读**：

- `rules/policy-cash-value-rules.md`：现金价值表读法与常见误读、退保损失公式、犹豫期内外口径对照、保单年度与回本年度判定、部分领取与减额交清与保单贷款三者区别、费用口径、防误伤（否定词）清单、争议处理路径。

**不得用已交保费替代现金价值**；**不得按缴费年数直接当保单年度**；**不得说成「一定全额退还」**；**不得承诺回本年度而无表可依**。

## 六、脚本用法

```bash
python scripts/cash_value_calc.py --file case.json --out 退保损失测算.md
python scripts/cash_value_calc.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：合同成立日、当前保单年度、现金价值表（保单年度→金额的映射）、各保单年度已交保费累计、是否在犹豫期内 |
| `--text` | 直接给 JSON 字符串 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检 |

输入 JSON 示例：

```json
{
  "policy_years": [
    {"year": 1, "cash_value": 800, "paid_cumulative": 5000},
    {"year": 2, "cash_value": 1800, "paid_cumulative": 10000},
    {"year": 3, "cash_value": 3200, "paid_cumulative": 15000},
    {"year": 4, "cash_value": 5000, "paid_cumulative": 20000},
    {"year": 5, "cash_value": 7200, "paid_cumulative": 20000}
  ],
  "current_year": 3,
  "in_cooling_off": false
}
```

脚本输出：当前保单年度现金价值、已交保费、退保损失与损失率、是否已回本、逐年损失率对照、犹豫期内外口径对照、以及必须由合同与承保公司确认的事项清单。

> 脚本按你提供的**现金价值表数据**做静态核算。**现金价值以合同载明的现金价值表为准**；犹豫期天数与退还范围**以合同约定为准**；退保、部分领取、减额交清与保单贷款的实际办理口径**以合同约定与承保公司实际流程为准**。脚本不劝诱退保，也不劝诱继续持有，不推荐产品。

## 七、人工确认清单（这步不能省）

- [ ] **现金价值表**已从合同或其附件中取到，不是宣传页的走势图
- [ ] **保单年度**已按合同约定起算点核对，不是直接用缴费年数
- [ ] 读取的是**当前保单年度对应行**，不是最近一年
- [ ] 若表上有多个责任/档次，**已分别读取并合计**
- [ ] **已交保费**取自实际缴费记录，未把未交的期数算进来
- [ ] 保单状态已确认（有效 / 失效 / 复效中），失效保单的处理口径已向承保公司确认
- [ ] **犹豫期天数**取自合同条款载明值
- [ ] 若在犹豫期内，**退还范围与扣除项**已按合同约定确认，未假设全额退还
- [ ] 若考虑部分领取，**可支取比例、上限、次数**已确认，且知道剩余利益会变化
- [ ] 若考虑减额交清，**减保后的保额**已确认
- [ ] 若考虑保单贷款，**利息与还款期限**已确认，且知道到期未还可能影响保单效力
- [ ] 结论中**没有出现「一定能拿回」「一定回本」**这类表述

## 八、最常见的坑

1. **用已交保费当退保能拿的钱。** 退保能拿的是**现金价值表对应保单年度的金额**，不是已交保费。长期人身险前期现金价值通常明显低于已交保费，**用已交保费估算会让你严重高估能拿回的钱**。
2. **把「缴费第几年」当「第几保单年度」。** 保单年度按合同约定的起算点编号，不一定等于你交了多少年保费。**读错行，读出来的数就是错的。**
3. **以为犹豫期内能全额拿回。** **犹豫期内的退还范围以合同约定为准**，可能扣除合同约定的费用。**不得说成「一定全额退还」。**
4. **以为犹豫期过了还能按已交保费退。** 犹豫期届满后，**只能按现金价值表**，而现金价值与已交保费是两回事。
5. **以为「再交几年就回本了」可以现在放弃。** 回本年度**只能由现金价值表判断**。而且回本后继续持有还是退出是另一个问题，**不能用「快回本了」说服自己现在不退，也不要用「快回本了」劝人继续交**。
6. **把部分领取当退保。** 部分领取后**合同继续有效**，但**剩余现金价值与后续利益会变化**，不能简单按比例推算。
7. **把减额交清当退保。** 减额交清**保额会下降**，保障范围随之变化，用它来「保住保障」和退保是完全不同的结果。
8. **把保单贷款当领取。** 贷款**要还本付息**，到期未还可能影响保单效力。**借出来的钱不是白拿的。**
9. **拿宣传页的现金价值走势图代替合同表。** 走势图是示意，**合同载明的表才是依据**。不同产品的走势差别很大。
10. **以为失效保单也能按表退。** **失效保单的处理口径与有效保单不同**，须向承保公司确认，不能自己按表算。
11. **忽略保单状态对保额的影响。** 欠费、失效、复效都会影响保单效力与利益，**必须先确认状态再算钱**。
12. **把「已提交退保申请」写成「已退保」。** 只有解除完成且款项到账，才算已退保。**未退保不能判成已退保。**

## 九、边界与免责

- 本技能用于退保前后的口径梳理与损失核算，**不构成保险代理、保险经纪、投资建议或法律意见**，不替代保险合同的约定与承保公司的核定
- **现金价值以合同载明的现金价值表为准**；**犹豫期天数以合同约定为准**；**犹豫期内退还范围以合同约定为准**；**退保、部分领取、减额交清与保单贷款的办理口径以合同约定与承保公司实际流程为准**
- 本测算为**静态口径**，未含保单贷款利息累计、宽限期、复效条件、红利分配方式、缴费方式变更、受益人变更等情形
- **不劝诱退保，也不劝诱继续持有**；不承诺「一定回本」「一定拿回全部」；不推荐具体产品
- 争议以承保公司的核定结论为准；涉及投诉与纠纷的，走正规投诉与调解渠道，必要时咨询律师
