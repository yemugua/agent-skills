# 智慧消防平台建设（smart-fire-platform）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《城市消防远程监控系统技术标准》GB 50440 与智慧消防建设要求，生成智慧消防平台建设清单：物联感知（烟感/用电/水压/视频）、平台架构、预警联动、数据看板、运维与处置闭环。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 智慧消防
- 智慧消防平台
- 消防物联网平台
- 消防远程监控
- 消防可视化

## 三、工作流
1. 梳理物联感知对象（烟感/电气/水压/消防水池/视频）
2. 规划平台架构与数据接入
3. 配置分级预警与联动处置规则
4. 建立运行数据看板与值守
5. 形成告警-派单-处置-复核闭环

## 四、核心内容（检查清单与判定）
智慧消防以物联感知与数据平台为基础，依据 GB 50440 等实现远程监控、早期预警与快速响应；应保证告警闭环与值守运维，避免「建而不用」。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含物联感知对象（烟感/电气/水压/视频） | 感知 |
| Q2 | FAIL | 未含平台架构与数据接入 | 架构 |
| Q3 | WARN | 未含分级预警与联动规则 | 联动 |
| Q4 | FAIL | 未含运行数据看板与值守 | 看板 |
| Q5 | WARN | 未含告警处置闭环 | 闭环 |

> 脚本 `smart-fire-platform_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python smart-fire-platform_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python smart-fire-platform_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
