# 地漏返味与防臭芯更换（floor-drain-odor-fix）

地漏返味，**第一反应不该是买防臭芯**。真实原因里，相当一部分是水封干涸、管道堵塞、或者味道根本不是从地漏来的。换错芯、换完还臭，是最常见的白花钱。

这个技能做四件事：**定来源** → **判原因** → **选型号** → **规范换**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 判断异味是不是地漏来的 | ❌ 认定"换芯一定能除味" |
| 区分水封干涸、芯体失效、管道堵塞 | ❌ 代替管道疏通机处理主管堵塞 |
| 按管径与安装深度选防臭芯型号 | ❌ 代替防水施工、瓷砖修复 |
| 给出更换步骤与验收方法 | ❌ 判断楼板、防水层结构问题 |
| 提示什么情况必须停用并报修 | ❌ 建议使用强酸强碱破坏性通堵 |

**遇到以下情况，立即停止自行操作，转交专业维修或物业：**

- 楼下天花板出现渗水、水印、滴水
- 撬动地漏时发现周边瓷砖空鼓、水泥层酥松、有积水渗出
- 异味伴随污水从地漏**反涌**上来（主管堵塞征兆）
- 需要破坏地面、拆除旧地漏底座、动防水层
- 铸铁管、老旧管道锈蚀严重，一碰就掉渣
- 同一楼层多个地漏同时返味（可能是立管或化粪池问题）
- 闻到燃气味（立即开窗、关阀、不动电器开关、到户外报燃气公司）

**永远不要为了"止味"用玻璃胶把地漏完全封死。** 封死会堵住排水通道，下次排水会从别处溢出，且检修时更难处理。

## 二、完整工作流

```
第 1 步  定位来源：确认味道是不是从这个地漏出来的
第 2 步  先读规则文件 rules/drain_odor_rules.md（故障树 + 选型表 + 红线）
第 3 步  跑故障树脚本
    python scripts/drain_odor_check.py --text "长期不用的地漏返味，倒水后好转"
第 4 步  按脚本给出的顺序做三条低成本验证（补水 / 灌水试排 / 塑料袋压味）
第 5 步  确认是芯的问题后，量尺寸、选型号、买材料
第 6 步  按更换作业顺序施工，做排水与密封验收
第 7 步  24 小时与 7 天两次复闻，判断有没有真正解决
```

## 三、先定位来源（这步跳过就白换芯）

| 验证动作 | 怎么做 | 怎么读结果 |
|---|---|---|
| 塑料袋压味法 | 地漏灌少量水，用湿塑料袋紧贴压住面板，静置 30 分钟 | 味没了 → 确实来自这个地漏；味还在 → 查别处 |
| 逐个排除法 | 把所有地漏、洗手盆下水、马桶底座依次封堵，每次闻一次 | 定位到具体排水点 |
| 纸巾擦拭法 | 擦干地面与地漏周边，1 小时后摸是否有新渗水 | 有水 → 不是气味问题，是渗漏 |

**味道不一定来自地漏**，高频的"背锅侠"还有：马桶法兰圈老化、洗手盆下水管没有 S 弯、洗衣机排水管直插立管、地漏周边瓷砖缝发霉、吊顶内排水管接口漏。

---

## 四、故障树（按处理顺序，不是按概率）

完整判定口径在 `rules/drain_odor_rules.md`，顺序如下：

| 顺序 | 可能原因 | 一眼判断方法 | 处理 |
|---|---|---|---|
| 1 | 存水弯 / 水封干涸 | 长期不用（出差、空置、客卫） | 倒 500ml 清水，无需换芯；长期不用每月补一次 |
| 2 | 下水管部分堵塞 | 排水变慢、有咕噜声、偶有反涌 | 先疏通再谈换芯，芯解决不了堵塞 |
| 3 | 防臭芯失效 | 硅胶嘴粘连、翻盖不复位、弹簧锈死、有破损 | 按型号换新芯 |
| 4 | 芯与管壁不匹配留缝 | 新换的芯装进去晃、周边有空隙 | 换带密封圈/可调外径的芯，或用硅胶补缝 |
| 5 | 排水管本身没有存水弯 | 装修时直排、老房子 | 装深水封芯或用防臭地漏整体 |
| 6 | 管道接口漏气 / 破损 | 吊顶内或楼下有水印、敲击管壁空响 | 停用，转专业人员 |

**顺序不能颠倒**：先做第 1、2 步的低成本验证，都没有问题再拆地漏。

## 五、防臭芯选型（选错等于白换）

| 类型 | 原理 | 适合 | 不适合 | 寿命 |
|---|---|---|---|---|
| 硅胶嘴（V 型） | 硅胶开口重力闭合 | 湿区常用、排水量大 | 长期不用会粘连 | 1-2 年 |
| T 型弹簧 / 磁吸 | 弹簧或磁力顶住盖板 | 干湿区通用 | 弹簧锈蚀后失效 | 2-3 年 |
| 重力翻盖 | 翻板自重回落 | 排水量大的淋浴区 | 杂物卡住翻板 | 2-3 年 |
| 深水封（U 型） | 存水隔绝 | 长期有水的湿区 | **干区必干涸失效** | 3-5 年 |

**选型三要素，缺一不可：**

1. **内径**：量地漏内管壁直径，常见 40mm、50mm，小口径芯 32-40mm
2. **安装深度**：从面板到管口的深度，深水封芯通常要 ≥8cm 才有效
3. **干湿区**：干区（阳台、厨房、长期不用）**不能选纯水封**，选硅胶或 T 型

买之前**把旧芯拆下来带着去比对**，这是最不容易买错的方法。

## 六、更换作业顺序（严格照做）

**工具与材料**：卷尺、一字螺丝刀、尖嘴钳、旧牙刷、手电、橡胶手套、抹布、塑料袋、新防臭芯、中性硅酮密封胶（可选）、除垢剂。

1. **清场**：挪开地漏上的杂物，戴手套，备好塑料袋装旧芯
2. **取面板**：多数是卡扣或旋转式，用一字螺丝刀从边缘轻轻撬起，**不要用蛮力**（塑料面板脆、铸铁面板会崩瓷）
3. **取旧芯**：多数可直接拔出或用尖嘴钳夹住旋转取出；**取之前先用绳子或铁丝拴住**，掉进管道就麻烦了
4. **清管壁**：旧牙刷刷掉管壁泥垢与旧胶，手电照进去看有没有裂缝、锈穿
5. **量尺寸**：量内径与深度，记录后再买或比对
6. **试放**：新芯先干放一次，确认能坐稳、不晃、盖板能自由开合
7. **装芯**：按型号压入或旋入，带密封圈的确认圈没有翻边
8. **装面板**：卡回原位，确认踩上去不晃动、不塌陷
9. **验收排水**：连续倒两盆水（约 5L），看排水是否顺畅、有没有从底座边缘返水
10. **验收密封**：倒水后静置 10 分钟，凑近闻；24 小时后再闻一次

**旧芯掉进管道**：不要继续冲水。先用铁丝弯钩尝试勾出，勾不出就停用该地漏并报专业人员，避免形成堵塞。

## 七、脚本用法

```bash
python scripts/drain_odor_check.py --text "客卫地漏长期不用，最近返味，排水正常"
python scripts/drain_odor_check.py --file 描述.txt --out 结果.md
```

| 参数 | 说明 |
|---|---|
| `--text` | 直接给现象描述 |
| `--file` | 从文件读描述（`.txt` / `.md`） |
| `--out` | 结果落盘路径，不给则打印到屏幕 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本做三件事：按故障树匹配可能原因并**按处理顺序**排好、给出每条的验证动作与处置、命中红线时输出"停用并报修"提示。

> 脚本只做关键词匹配，**不代表现场判断**。写"干"不一定就是干涸，仍要按第 1、2 步实测。

## 八、人工确认清单（这步不能省）

- [ ] 味道是否确认来自这个地漏（塑料袋压味法验证过）
- [ ] 排水速度是否正常（堵的问题要先解决）
- [ ] 干区还是湿区，有没有选错芯型
- [ ] 旧芯尺寸与安装深度有没有实测过
- [ ] 新芯装好后盖板能不能自由开合、有没有卡滞
- [ ] 面板装回后踩上去是否稳固
- [ ] 倒水测试有没有从底座边缘返水
- [ ] 24 小时后复闻结果记录

## 九、最常见的坑

**坑一：返味就换芯，结果白换。**
长期不用的地漏，水封早就蒸发干了，倒两杯水就好。这是出租房、客卫返味最常见的真实原因。

**坑二：把堵塞当防臭芯问题。**
排水变慢、有咕噜声、偶有反涌，是管道部分堵塞。芯只管气味，管不了通畅。

**坑三：干区装深水封。**
阳台、厨房地漏可能一个月才用一次，水封蒸发后深水封芯和普通直排没区别。干区必须选硅胶或 T 型。

**坑四：不量尺寸凭感觉买。**
芯外径小了留缝漏气，大了塞不进去或顶坏管壁。带旧芯去比对最稳。

**坑五：换完还臭，第一反应是"新芯也不行"。**
更常见的是芯与管壁之间留缝、面板座没坐实、或者味道本来就来自马桶法兰圈和洗手盆下水管。

**坑六：用玻璃胶把地漏封死。**
短期没味，长期排水不畅，且下次检修要破坏性拆除。

**坑七：旧芯掉进管道后继续冲水。**
冲水会把芯推进更深处，从"能勾出来"变成"必须拆管"。

**坑八：用强酸强碱猛灌。**
PVC 与老旧铸铁管都可能被腐蚀，接口漏水后维修成本远高于疏通。

## 十、边界与免责

- 本技能**不替代**管道疏通、防水施工、瓷砖修复等专业作业
- 管道材质、楼龄、装修做法差异大，**以现场实际情况与专业人员判断为准**
- 涉及公共立管、楼下渗水、结构层问题时，应通过物业或专业维修处理，**不要自行拆改**
- 任何需要破坏地面、动防水层、拆旧地漏底座的操作，都应交由专业人员
- 操作中如发现管道破损、楼板渗水，应立即停止并报修
