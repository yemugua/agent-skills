# 抽样检验（AQL）（sampling-inspection）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据 GB 2828.1《计数抽样检验程序》与 ISO 2859，生成抽样检验清单：抽样标准、检验水平与 AQL、正常/加严/放宽转移规则、接收/拒收判定（Ac/Re）与不合格处置。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 抽样检验
- AQL
- GB 2828
- 计数抽样
- 来料抽检
- 批接收判定
- 转移规则

## 三、工作流
1. 确定抽样标准（GB 2828.1/ISO 2859）
2. 设定检验水平与 AQL
3. 制定抽样方案（正常/加严/放宽转移）
4. 接收/拒收判定（Ac/Re）
5. 不合格品处置（返工/拣用/让步）

## 四、核心内容（检查清单与判定）
GB 2828.1 以 AQL 为质量界限，按检验水平抽取样本；通过正常-加严-放宽转移规则动态控制接收风险。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未明确抽样标准（GB 2828.1/ISO 2859） | 标准 |
| Q2 | FAIL | 未定检验水平与AQL | 参数 |
| Q3 | WARN | 未含抽样方案（正常/加严/放宽转移） | 方案 |
| Q4 | FAIL | 未含接收/拒收判定（AC/RE） | 判定 |
| Q5 | WARN | 未含不合格处置（返工/拣用/让步） | 处置 |

> 脚本 `sampling-inspection_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python sampling-inspection_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python sampling-inspection_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
