# 老年人照料设施消防（elderly-care-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《建筑设计防火规范》GB 50016 老年人照料设施章节与《养老机构消防安全管理规定》，生成清单：建筑耐火与楼层布置、疏散与避难间、独立安全出口与护理单元、消防设施与应急照明、夜间值守与疏散预案。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 养老院消防
- 老年人照料设施
- 养老机构消防
- 老年公寓消防
- 老年人疏散

## 三、工作流
1. 核查建筑耐火与楼层布置
2. 明确疏散与避难间要求
3. 确认独立安全出口与护理单元
4. 配置消防设施与应急照明
5. 落实夜间值守与疏散预案

## 四、核心内容（检查清单与判定）
老年人照料设施因人员行动不便，GB 50016 对其楼层布置、疏散与避难间有专门要求；管理上须强化夜间值守与针对性疏散预案。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含建筑耐火与楼层布置 | 布置 |
| Q2 | FAIL | 未含疏散与避难间要求 | 疏散 |
| Q3 | WARN | 未含独立安全出口与护理单元 | 出口 |
| Q4 | FAIL | 未含消防设施与应急照明 | 设施 |
| Q5 | WARN | 未含夜间值守与疏散预案 | 值守 |

> 脚本 `elderly-care-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python elderly-care-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python elderly-care-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

- 重大隐患/高风险判定需由具备资质人员签字确认。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
