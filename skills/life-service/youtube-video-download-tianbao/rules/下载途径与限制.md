# YouTube 视频下载与字幕保存：途径、限制与合规边界

## 一、先判定：能不能下

| 归属类别 | 能否下载 | 允许的用途 |
| --- | --- | --- |
| 自有作品 | 可以，优先用原始导出文件 | 任意 |
| 已授权素材 | 可以 | 仅限授权范围内 |
| 作者开放了保存 | 可以，走官方途径 | 个人留存，**不得二次分发** |
| 第三方作品（未授权） | **不建议下载** | 不应用于任何对外场景 |

技术上能不能下载，和法律上能不能用，是两回事。

## 二、途径，按稳定性排序

| 途径 | 操作要点 |
| --- | --- |
| Premium 官方离线 | 订阅 Premium 后可使用 App 内离线下载，但为加密格式，**不可导出为通用文件**。 |
| YouTube Studio | 登录**自己的频道**进入 Studio，在内容里下载自己上传的原始文件。 |
| 通用命令行工具 | 需 Python + ffmpeg：`pip install -U yt-dlp`。常用形态：`yt-dlp -f "bv*+ba/b" <链接>`。适用于公开且无版权保护的视频。 |
| 字幕单独下载 | `yt-dlp --write-auto-subs --write-subs --sub-langs zh-Hans,en <链接>` 可带走字幕轨道，与视频本体分开获取。 |

## 三、本平台的真实限制

- **可访问性是前置条件**：在中国大陆内地通常无法直接访问 YouTube，需先具备合规的网络条件，否则一切下载步骤无从谈起。
- 付费购买的内容、会员专享内容、含 DRM 的电影与剧集**不支持下载**，破解 DRM 在多数司法辖区违法，本技能不提供任何相关方法。
- YouTube 分离了视频轨与音频轨，高画质下载必须指定合并策略并由 ffmpeg 合成，否则容易出现无音轨的情况。
- 站点接口频繁改版，工具失效时应先升级到最新版本而非更换工具。

## 四、画质与水印

- 可选清晰度取决于源：常见有 1080p、1440p、4K，部分提供 8K。工具 `-F` 参数可先列出全部可用格式再挑选。
- YouTube 一般不叠加平台水印，但转载他人作品时作者信息仍需保留。

## 五、合规红线

1. 不得去除作者署名后二次分发
2. 不得将他人作品搬运至自己的账号（含剪辑、配音后发布）
3. 不得下载或传播私密账号、付费内容
4. 受版权或 DRM 保护的内容不支持下载，也不提供任何破解方法
5. 商用前必须取得书面授权
6. 批量高频抓取可能违反平台服务协议，导致账号受限
