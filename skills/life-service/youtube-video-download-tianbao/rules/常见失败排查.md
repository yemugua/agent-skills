# YouTube 视频下载与字幕保存：常见失败与排查

报错信息请**粘贴原文**再对照。写成「下载失败了」没有排查价值，
写成 `HTTP Error 403` 或 `ffmpeg not found` 才能定位。

## 现象 → 原因 → 处理

| 现象关键词 | 原因与处理 |
| --- | --- |
| drm / 加密 / widevine / 付费电影 | 含 DRM 的内容不支持也不应下载，请通过官方渠道观看。 |
| 网络不通 / 连接超时 / 无法访问 | 先确认网络可达性，这是中国大陆用户最常见的失败原因。 |
| 403 / sign in to confirm / 机器人验证 | 触发了平台的反自动化校验，需携带登录态或减少请求频率，勿高频重试。 |
| 没有声音 / 只有画面 | 流媒体音视频分离，须用 `-f "bv*+ba/b"` 合并，并确认 ffmpeg 已安装。 |
| 字幕没有 / sub not found | 该视频可能无字幕轨道，或需指定语言代码如 zh-Hans。 |
| 播放列表只下了一个 | 播放列表需工具默认支持；如被限制，逐条处理或检查是否设置了播放列表范围参数。 |

## 通用故障（各平台都可能遇到）

| 现象 | 处理 |
| --- | --- |
| 403 / 需要登录 / 机器人验证 | 触发反自动化校验：携带登录态或减少请求频率，不要高频重试 |
| 429 / 频繁 / 限流 | 降低请求频率、分批间隔重试 |
| 404 / 失效 / 不存在 | 链接失效或已删除：让对方重新生成分享 |
| 没有声音 / 无音轨 | ffmpeg 未安装或未合并轨：安装后用 `-f "bv*+ba/b"` 合并 |
| 解析失败 / 格式不支持 | 站点接口变动：把工具升级到最新版，而不是换工具 |
| 超时 / 连接失败 | 检查网络可达性后重试 |

## 排查顺序

1. 先确认网络能访问目标平台
2. 再确认目标内容是否属于可下载范围（回到归属判定）
3. 然后确认工具是最新版
4. 最后才怀疑链接本身

九成的「下载失败」卡在第 1 步和第 2 步，而不是工具坏了。
