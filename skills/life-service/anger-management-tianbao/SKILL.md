# 愤怒管理与冲动控制

愤怒管理的**第一动作永远是生理降温，不是讲道理**。人在愤怒时负责理性思考的区域功能下降，此时讲道理基本讲不进去——**降温之后才有资格讲道理**。

## 一、硬边界（能做 / 不能做）

| 能做 | 不能做 |
|---|---|
| 给出可执行的生理降激活动作 | 提供心理诊断或判断是否有愤怒障碍 |
| 说明早期信号识别方法 | 替代专业心理治疗 |
| 给出表达句式与冲突处理方法 | 教唆或合理化任何暴力、伤害他人的行为 |
| 说明认知重评与表达训练的区别 | 保证「学会了就不会发火」 |
| 提示何时求助 | 评价用户的愤怒「不该有」 |

**本技能不提供诊断，不替代专业心理治疗。严重或持续的症状请寻求专业评估。**

## 二、求助红线（先看）

**出现以下情况，请立刻寻求专业帮助或拨打当地心理援助热线 / 急救：**

| 红线信号 | 说明 |
|---|---|
| **自伤或自杀的念头、计划，或工具已在手** | 危机状态，需即时人工支持 |
| **出现伤害他人、动手、动手砸物的冲动且难以控制** | 立即离开现场并求助，不要独处 |
| **失控后有实际伤害行为，或反复暴力行为** | 需专业干预，可能涉及他人安全 |
| 持续两周以上情绪低落、兴趣丧失、失眠或嗜睡 | 已达专业评估时长 |
| 社会功能明显受损 | 需专业干预 |
| 出现幻觉或妄想 | 需立即评估 |
| 躁狂表现：少睡却不困、异常兴奋、思维奔逸 | 需立即评估 |
| 严重焦虑伴惊恐反复发作 | 需专业治疗 |
| 进食障碍倾向：体重骤降、催吐、过度运动 | 需专业干预 |
| 物质滥用失控（酒精等常被用作发泄手段） | 需专业干预 |

**如果有伤害自己或他人的冲动，请立即远离他人与危险物品，联系身边可信任的人，并拨打当地心理援助热线或急救电话。**

## 三、绝对红线：不可用暴力或伤害性方式发泄

**砸东西、摔门、动手、毁物、驾车发泄、酗酒后发泄，全部不可用。**

这些行为：
1. 会伤及无辜（物品、家人、路人）；
2. 会强化愤怒循环（发泄后更想发泄，而不是更平静）；
3. 可能构成违法；
4. 让你事后更难修复关系。

**如果冲动强烈到必须动身体，应立即离开现场**，而不是寻找可砸之物。

## 四、完整工作流

### 步骤 1：识别早期身体信号（最关键）

**身体早期信号出现时介入最有效；等到爆发就晚了。** 见第五节。

### 步骤 2：立即降温（生理优先）

**这一步优先于讲道理。** 见第六节。

### 步骤 3：等强度降下来再处理问题

降到能正常思考（主观感觉降到 4 以下）再进入沟通。

### 步骤 4：认知重评（事后，不是在愤怒中）

认知重评是**事后**的工作，不是在愤怒现场。

### 步骤 5：表达而不压抑

见第七节句式。

## 五、核心规则（发火前必读）

**先读 `rules/愤怒信号与干预顺序.md`，不要临场找方法。**

### 愤怒信号的三层（越早越有效）

| 层级 | 信号 | 介入效果 |
|---|---|---|
| **一级：早期身体信号** | 下巴紧、肩颈僵、呼吸变浅变快、手心出汗、声音变高、心跳加快 | **最佳介入点** |
| **二级：情绪升级** | 明显烦躁、语速加快、反复打断、体温上升 | 需主动离场 |
| **三级：失控边缘** | 音量失控、开始人身攻击、摔东西、说不出话 | **必须立即离开现场** |

**大多数人只在三级才「发现」自己在生气，那时已经太晚。** 训练目标是识别一级信号并立即介入。

### 生理降激活动作（按优先级）

| 动作 | 做法 | 机制 |
|---|---|---|
| **延长呼气** | 吸气后**呼气比吸气长**（如吸 4 秒、呼 6—8 秒），做 10—15 轮 | 延长呼气可加快心率回落 |
| **暂停离场** | 说明「我现在需要冷静一下」，走到安静处 | 脱离触发环境是最快的降温 |
| **物理降温** | 用凉水洗脸、洗手，冷水敷颈侧 | 降低生理唤醒水平 |
| **用力握拳再松开** | 握拳用力数 5 秒，慢慢松开，重复 | 释放肌肉紧张 |
| **放慢语速与音量** | 有意识地把语速降低一半 | 语速是可控的，能反过来带动情绪 |
| **离开现场** | 走到户外或另一个房间 | 最有效但需要提前约定 |

**「立即降温」优先于「讲道理」**：愤怒时负责理性判断的功能被抑制，此时试图说服自己或对方通常失败，且会让冲突升级。

## 六、认知重评 vs 表达训练（重要区分）

两者针对不同环节，**不能混用**：

| 对比 | 认知重评 | 表达训练 |
|---|---|---|
| **做什么** | 改变对事件的**解释** | 改变**说出来的方式** |
| **何时用** | **事后平静时** | 冲突中（已降温后） |
| **示例** | 「他没回我不是针对我，可能在忙」 | 「我有点着急，想确认一下进度」 |
| **误区** | 在愤怒时对自己说「冷静」——**无效** | 压抑不表达——会积累 |

**常见误区**：把「我应该冷静」当作认知重评。愤怒时用理性语言对自己说话**几乎无效**，因为此时理性区域功能下降。

**顺序永远是**：先降温 → 再重评 → 最后表达。

## 七、关系冲突中的表达句式

**降温之后**用「我」陈述，避免「你」开头（指责句式）：

```
我感到 _____（描述情绪，不评价对方）
因为 _____（描述事实与影响）
我希望 _____（提出具体请求）
```

| 指责句式 | 改为 |
|---|---|
| 「你从来不听我说话」 | 「我感到没有被重视，因为我说的时候常被打断」 |
| 「你就是不关心我」 | 「我感到有点失落，因为这两周都没什么交流」 |
| 「你能不能别这样」 | 「我希望我们能换个说法，我有点招架不住」 |

**要点**：第一句说自己的感受（而非对方的错误），第二句说事实而非动机猜测，第三句给具体可执行的请求。

## 八、常见误区

| 误区 | 为什么错 | 正确做法 |
|---|---|---|
| **强行压制不表达** | 情绪会累积，最终更激烈爆发 | 降温后表达 |
| **把愤怒当敌人** | 愤怒是信号不是敌人，读懂信号才能处理 | 先问「什么在提醒我」 |
| **砸东西发泄** | 伤人、违法、且强化愤怒循环 | 离开现场或做用力握拳 |
| **愤怒时讲道理** | 理性区域功能下降，讲不进去 | 先降温 |
| **用「我应该冷静」重评** | 愤怒时无效 | 事后平静时重评 |
| **等到爆发才察觉** | 介入太晚 | 训练识别一级信号 |
| **用酗酒发泄** | 加重失控与健康损害 | 不作为发泄方式 |
| **只讲道理不降温** | 顺序错误 | 降温优先 |

## 九、脚本用法

脚本：`scripts/anger_signal_check.py`

```bash
python scripts/anger_signal_check.py --file 情境.json
python scripts/anger_signal_check.py --selftest
```

| 字段 | 说明 |
|---|---|
| `signals` | 出现的身体与行为信号 |
| `level` | 当前层级（early / rising / out_of_control） |
| `violence_intent` | 是否存在伤害自己或他人的意图 |
| `cooling_done` | 是否已做生理降激活 |
| `rerating_done` | 是否已做认知重评 |

输出：信号层级判定、介入时机提示、降温动作建议、顺序检查（降温是否早于重评与表达）、暴力意图的强制转介提示。

## 十、人工确认清单（不能省）

- [ ] 是否已过一遍求助红线（尤其伤害他人倾向与失控行为）？
- [ ] 是否能识别自己的一级身体信号（不只是「我很生气」）？
- [ ] 愤怒时是否**先降温**，而不是先讲道理？
- [ ] 是否用了延长呼气、暂停离场等生理动作？
- [ ] 认知重评是否放在**事后平静时**？
- [ ] 是否存在「压抑不表达」的倾向？
- [ ] 是否避免了砸东西、动手、酗酒等伤害性发泄？
- [ ] 表达时是否用了「我感到—因为—我希望」句式？
- [ ] 冲动强烈时是否**离开现场**而非发泄？

## 十一、最常见的坑

1. **等爆发才察觉**。一级的身体信号出现时介入才有效。
2. **愤怒时讲道理**。理性区域被抑制，此时沟通注定失败。
3. **用「我应该冷静」当认知重评**。这句话在愤怒时无效。
4. **砸东西发泄**。伤人、可能违法，而且会强化愤怒循环。
5. **强行压制不表达**。情绪不消失，只会积累到更严重。
6. **把愤怒当敌人要消灭**。愤怒是信号，读懂信号比压住它有用。
7. **事后不重评**。每次都「算了」，同样的触发下次照样发火。
8. **压抑而不是表达**。累积后会在小事上剧烈爆发。
9. **用酒精助发泄**。显著削弱判断力并加重失控。
10. **不离开现场硬撑**。三级时唯一有效动作是离开现场。

本技能提供愤怒管理方法与冲动控制动作，**不提供诊断，不替代专业心理治疗，不保证学会后不再发火**。本技能**不教唆、不合理化任何暴力或伤害他人的行为**，使用伤害性方式发泄既是安全风险也可能构成违法。若愤怒频繁失控、存在伤害倾向、影响到他人安全，请务必寻求专业评估，并可咨询当地心理援助热线。
