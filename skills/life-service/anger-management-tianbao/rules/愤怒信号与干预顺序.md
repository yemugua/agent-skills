# 愤怒信号与干预顺序

> 发火前必读。**顺序永远是：先降温 → 再重评 → 最后表达。**

## 零、绝对红线：不可用暴力或伤害性方式发泄

**砸东西、摔门、动手、毁物、驾车发泄、酗酒后发泄，全部不可用。**

| 为什么不可 | 说明 |
|---|---|
| 伤及无辜 | 物品、家人、路人都是受害者 |
| 强化愤怒循环 | 发泄后往往更想发泄，而非更平静 |
| 可能构成违法 | 毁物、伤害他人均有法律后果 |
| 关系更难修复 | 事后修复成本远高于忍耐成本 |

**冲动强烈到必须动身体时，正确动作是立即离开现场**，而不是寻找可砸之物。

## 一、求助红线（先看）

**出现以下情况请立刻寻求专业帮助或拨打当地心理援助热线 / 急救：**

| 红线信号 | 性质 |
|---|---|
| 自伤或自杀的念头、计划，或工具已在手 | 危机，最高优先 |
| 出现伤害他人、动手、砸物的冲动且难以控制 | 立即离开现场并求助，不独处 |
| 失控后有实际伤害行为，或反复暴力行为 | 需专业干预，涉及他人安全 |
| 持续两周以上情绪低落、兴趣丧失、失眠或嗜睡 | 需专业评估 |
| 社会功能明显受损 | 需专业干预 |
| 出现幻觉或妄想 | 需立即评估 |
| 躁狂表现：少睡却不困、异常兴奋、思维奔逸 | 需立即评估 |
| 严重焦虑伴惊恐反复发作 | 需专业治疗 |
| 进食障碍倾向：体重骤降、催吐、过度运动 | 需专业干预 |
| 物质滥用失控 | 需专业干预 |

**有伤害自己或他人的冲动时**：立即远离他人与危险物品 → 联系身边可信任的人 → 拨打当地心理援助热线或急救电话。

## 二、愤怒信号三层（核心）

| 层级 | 信号 | 介入方式 |
|---|---|---|
| **一级：早期身体信号** | 下巴紧、肩颈僵、呼吸变浅变快、手心出汗、声音变高、心跳加快 | **最佳介入点**：立刻做生理动作 |
| **二级：情绪升级** | 明显烦躁、语速加快、反复打断、体温上升 | 主动离开现场 |
| **三级：失控边缘** | 音量失控、人身攻击、摔东西、说不出话 | **必须立即离开现场** |

**大多数人只在三级才「发现」自己在生气——那时已经太晚。** 训练目标是识别一级信号并立即介入。

## 三、生理降激活动作（优先级顺序）

| 优先级 | 动作 | 做法 | 机制 |
|---|---|---|---|
| 1 | **延长呼气** | 吸气后呼气比吸气长（吸 4 秒、呼 6—8 秒），10—15 轮 | 延长呼气加快心率回落 |
| 2 | **暂停离场** | 说明「我现在需要冷静一下」，走到安静处 | 脱离触发环境，降温最快 |
| 3 | **物理降温** | 凉水洗脸洗手、冷水敷颈侧 | 降低生理唤醒水平 |
| 4 | **用力握拳再松开** | 握拳用力数 5 秒，慢慢松开，重复 | 释放肌肉紧张 |
| 5 | **放慢语速音量** | 有意识地把语速降低一半 | 语速可控，可带动情绪 |
| 6 | **离开现场** | 走到户外或另一个房间 | 最有效但需提前与对方约定 |

### 为什么「立即降温」优先于「讲道理」

愤怒时负责理性判断与语言组织的脑区功能被抑制，此时：
- 试图说服自己：**无效**
- 试图说服对方：**通常失败且升级冲突**
- 事后回想「当时我应该理性」：因为当时**生理上不具备**那个能力

**这不是意志力问题，是生理状态问题。** 所以先处理生理，再处理认知。

## 四、认知重评 vs 表达训练

| 对比 | 认知重评 | 表达训练 |
|---|---|---|
| 做什么 | 改变对事件的**解释** | 改变**说出来的方式** |
| 何时用 | **事后平静时** | 冲突中（已降温后） |
| 示例 | 「他没回我不是针对我，可能在忙」 | 「我有点着急，想确认一下进度」 |
| 误区 | 愤怒时对自己说「冷静」——**无效** | 压抑不表达——会累积 |

**常见误区**：把「我应该冷静」当作认知重评。愤怒时用理性语言对自己说话几乎无效。

## 五、关系冲突表达句式

**降温之后**使用，避免「你」开头：

```
我感到 _____（描述自己的情绪）
因为 _____（描述事实与影响，不猜测动机）
我希望 _____（提出具体可执行的请求）
```

| 指责句式 | 改为 |
|---|---|
| 「你从来不听我说话」 | 「我感到没有被重视，因为我说的时候常被打断」 |
| 「你就是不关心我」 | 「我感到有点失落，因为这两周都没什么交流」 |
| 「你能不能别这样」 | 「我希望我们换个说法，我有点招架不住」 |

**三个要点**：第一句说自己的感受（不评价对方），第二句说事实（不猜动机），第三句给具体请求。

## 六、常见误区对照

| 误区 | 为什么错 | 正确做法 |
|---|---|---|
| 等爆发才察觉 | 介入太晚 | 识别一级信号 |
| 愤怒时讲道理 | 理性被抑制 | 先降温 |
| 用「我应该冷静」重评 | 此时无效 | 事后平静时重评 |
| 砸东西发泄 | 伤人、违法、强化循环 | 离场或握拳松开 |
| 强行压制不表达 | 情绪累积 | 降温后表达 |
| 把愤怒当敌人 | 愤怒是信号 | 读懂信号 |
| 事后不重评 | 下次照旧发火 | 每次复盘解释 |
| 压抑不表达 | 小事剧烈爆发 | 表达出来 |
| 酒精助发泄 | 削弱判断力 | 不作为方式 |
| 硬撑不离场 | 三级时无效 | 立即离开 |

## 七、事后复盘（每次发火后）

```
1. 这次的触发点是什么？
2. 我的一级身体信号是什么？下次能不能更早识别？
3. 我用了降温动作吗？顺序对吗（降温是否早于表达）？
4. 当时的想法是什么？有没有过度解读？
5. 有没有出现伤害性发泄？下次如何避免？
6. 需要补一句什么或做一件什么修复关系？
```

**第 2 项是训练重点**：把这次的信号记下来，下次就是提前量。
