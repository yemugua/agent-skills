# 危险化学品存储合规检查（hazmat-storage-check）

危化品仓库是单位的**火药桶管理**：一旦混存、超量、失控，就不是火灾是爆炸。合规检查的核心就三句话——**分库存、控环境、管住账**。

这个技能做四件事：**定场所** → **分禁忌** → **控五距环境** → **管台账应急**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 讲解存储合规要求与检查方法 | ❌ 替代法定监管与安全评价 |
| 生成检查表与库存体检报告 | ❌ 处置不明化学品 |
| 整理台账与应急配置要点 | ❌ 保证处置结果 |

**遇到以下情况立即停止使用并上报，不得自行处置：**
- 标识不清、来源不明的化学品
- 包装变形、渗漏、发热的容器
- 禁忌物已经混存且无法当场分离

**永远不要**把危化品当普通货物堆放——办公室抽屉里的一瓶酒精，也是隐患。

## 三、储存场所要求

1. **专用仓库**：危化品应储存在专用仓库、专用场地或专用储存室内，**不得与普通货物混存**；储存方式、数量应符合国家标准和有关规定（《危险化学品安全管理条例》口径）。
2. **建筑条件**：耐火等级、层数、防火分区、泄压、通风按规范执行；易燃易爆品库房应采取防爆电气、防雷防静电措施。
3. **气瓶**：氧气与乙炔等助燃/可燃气瓶分间存放、直立固定、防倾倒、防晒；空瓶与实瓶分区。
4. **领用**：领用登记、限量领用、现场使用不得超当天用量。

## 四、禁忌物混存（常见组合，节选）

| 品类 | 不能同库/同区存放 |
|---|---|
| 酸类 | 碱类、氰化物、遇湿易燃品 |
| 氧化剂 | 还原剂、易燃物、有机物 |
| 遇湿易燃品（钠、电石等） | 含水物质、酸类 |
| 压缩气瓶 | 油类、油脂（氧气瓶尤其） |

> 完整禁忌表以 GB 15603《常用危险化学品储存通则》及化学品安全技术说明书为准；**拿不准的一律分库存放**。

---

## 五、五距与环境控制

| 项目 | 要求 |
|---|---|
| 顶距 | ≥ 50 cm（喷淋场所另按规范留够） |
| 灯距 | ≥ 50 cm |
| 墙距 | ≥ 30~50 cm |
| 柱距 | ≥ 10~30 cm |
| 垛距 | ≥ 1 m（主通道 ≥ 1.8~2 m） |
| 温湿度 | 按品种要求控制并记录，超限处置 |
| 通风 | 良好通风，禁止明火，电气防爆 |
| 静电 | 装卸、转运有导静电措施 |

---

## 六、台账与应急

1. **出入库台账**：品名、规格、数量、出入日期、经手人、库存余量
2. **MSDS**：每种在库品都有安全技术说明书，可随时取用
3. **应急配置**：按品类配吸附、灭火、洗消器材；人员知道泄漏处置流程和上报电话
4. **定期盘点**：账物一致，超储预警；废弃危化品按法规处置，不得随意倾倒

---

## 七、脚本用法（库存体检）

```bash
python scripts/hazmat_storage_check.py --file "D:\安全\库存.json"
```

脚本检查五类问题：**禁忌混存、温湿度超限、五距不足、台账要素缺失、气瓶混放/超期**。

> ⚠️ 脚本只做结构与逻辑检查，**不判定现场实际状态**。

---

## 八、人工确认（这步不能省）

- [ ] 在库品种是否都有清单、有 MSDS
- [ ] 防爆电气是否检测合格
- [ ] 温湿度记录是否连续、超限是否处置
- [ ] 气瓶是否固定、是否有防晒防倾倒措施
- [ ] 应急物资是否匹配在库品类、人员是否会用
- [ ] 废弃危化品处置渠道是否合规

---

## 九、输出结构（固定三段）

1. **能不能过关**——结论先行：合规 / 有缺口 / 有红线问题
2. **核对清单**——逐项标合规/缺失/存疑
3. **整改与补资料建议**——先后顺序、责任岗位、留存材料

## 十、最常见的坑

**坑一：拿普通仓库凑合。** 耐火等级不够、没通风、没防爆，等于把火药桶放木头房。

**坑二：酸碱氧化剂混放。** 一瓶高锰酸钾挨着一瓶乙醇，等着出事。

**坑三：五距只写在制度里。** 垛挨着墙、灯贴着顶，查消防时现搬。

**坑四：台账月底一起补。** 账物不符，丢了半瓶都发现不了。

**坑五：气瓶躺着放。** 乙炔瓶倒卧取气，丙酮带出，一遇火星就炸。
