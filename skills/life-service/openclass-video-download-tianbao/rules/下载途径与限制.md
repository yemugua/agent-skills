# 公开课与慕课视频离线留存：途径、限制与合规边界

## 一、先判定：能不能下

| 归属类别 | 能否下载 | 允许的用途 |
| --- | --- | --- |
| 自有作品 | 可以，优先用原始导出文件 | 任意 |
| 已授权素材 | 可以 | 仅限授权范围内 |
| 作者开放了保存 | 可以，走官方途径 | 个人留存，**不得二次分发** |
| 第三方作品（未授权） | **不建议下载** | 不应用于任何对外场景 |

技术上能不能下载，和法律上能不能用，是两回事。

## 二、途径，按稳定性排序

| 途径 | 操作要点 |
| --- | --- |
| 原文件 | 优先。若是本校或本机构的课程，向教务或主讲教师索取原始文件通常最直接，也最完整。 |
| 官方离线缓存 | 多数慕课平台 App 支持课程视频离线缓存，只能在**官方客户端内**观看，不能导出成通用文件。 |
| 课件与字幕单独保存 | 课件 PDF、讲义与字幕文件通常可单独下载，这部分保存下来对学习帮助往往比视频更大。 |
| 通用命令行工具 | 需 Python + ffmpeg：`pip install -U yt-dlp`。仅适用于**明确公开的免费课程**；在校与付费课程不适用。 |

## 三、本平台的真实限制

- **先分清三类内容**：免费公开课、在校课程（需选课或身份认证）、付费证书项目。三者的授权范围完全不同。
- 在校课程视频通常只授权给当期的选课学生，结课或退课后访问权会收回，下载后长期留存与分享存在风险。
- 付费证书项目（含专项课程、微专业）明确不允许下载与分发，本技能不提供任何绕过方式。
- **课件与字幕往往比视频更值得保存**：PPT 与讲义的知识密度高、体积小，且多数平台明确允许下载。
- 讲座与学术报告的录像权属归主办方，公开与否取决于主办方是否开放。

## 四、画质与水印

- 课程视频多为录制转码，画质以满足教学为目的；课件 PDF 通常更清晰也更便于检索。
- 课程视频含机构与教师署名，学习自用可以，去除署名后分发存在侵权风险。

## 五、合规红线

1. 不得去除作者署名后二次分发
2. 不得将他人作品搬运至自己的账号（含剪辑、配音后发布）
3. 不得下载或传播私密账号、付费内容
4. 受版权或 DRM 保护的内容不支持下载，也不提供任何破解方法
5. 商用前必须取得书面授权
6. 批量高频抓取可能违反平台服务协议，导致账号受限
