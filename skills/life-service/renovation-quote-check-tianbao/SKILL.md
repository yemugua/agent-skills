# 装修报价单核查与增项防范

## 一句话

回答四个问题：**这份报价单缺了什么、哪里留了开口条款、钱该不该现在付、合同里必须补哪几句话**。

## 三步上手

1. 用 `templates/装修报价采集表.md` 把报价单抄进来。
   **备注栏照抄对方原话**——"按实际""按市价""另计""不含"这些词是判断增项风险的关键，抄干净了脚本才判得准。
2. 跑一次核查：
   ```bash
   python scripts/quote_check.py 装修报价采集表.md --json
   ```
   可选 `--base 2026-10-04` 固定基准日。
3. 拿着报告第六段的**三段话**去谈、第七段的**六句话**写进合同；现场用
   `templates/隐蔽工程验收与付款卡.md` 卡住付款。

## 它算什么

- **九项必看完整性**：拆除、垃圾清运、水电、防水、瓦工、木工、油漆、主材型号、工期付款节点，
  逐项判"报价单里有没有"+"缺了会怎样"。
- **可疑表述逐条揪出**：8 类开口条款（按实际 / 按市价 / 另计 / 不含 / 视情况 / 以实际为准 / 多退少补 / 仅供参考），
  每条给风险说明和"现在怎么改"的改法。
- **注水信号**：项数少于 15 项视为漏项压总价（**同户型同档次少一项就少一个信息**）、
  没写工程量的项单独列出、单价是否异常低要自己比价。
- **付款节点红线表**：开工 ≤30%、水电验收后累计 ≤50%、泥木 ≤70%、竣工 ≤95%、留 5% 尾款到质保期满。
  采集表里填的约定会跟建议上限逐行对照，超了就打 ⚠️。
- **谈判与合同**：增项三段话（把力气花在"写不写进合同"而不是"多少钱"）+ 合同必写六句话（可直接抄）。

## 硬边界（必须遵守）

- **不估市场价**。各城市各楼盘各档次差异极大，本技能只提示"该项建议自行比价三处"，
  绝不编造任何单价基准。价格判断是用户的活。
- **不评价施工工艺和师傅水平**。纸面核查能看出报价单的问题，看不出现场偷工减料。
- **不代拟合同全文**。给"必须写进合同的六句话"，不冒充律师起草正式文本。
- 不代替现场监理与第三方验房。

## 文件

- `rules/quote-basics.md`：全包/半包/整装三分法、九项必看、八类开口条款、三种注水手法、付款节点表、合同六句话
- `rules/extra-charges.md`：增项三种来源、五句当场必问、三个"到此为止"信号、谈判三段话、合同五个坑、隐蔽工程验收标准与付款卡
- `templates/装修报价采集表.md`：输入模板（八节）
- `templates/隐蔽工程验收与付款卡.md`：现场逐项打勾 + 付款节点对照 + 四条收手条件
- `templates/模板说明.md`：三份模板怎么用
- `scripts/quote_check.py`：核查脚本（唯一可执行部分）

## 三个最容易踩的地方

- **项数比总价更能说明问题**。同户型同档次的报价单，谁的项数多谁靠谱；
  少于 15 项基本是漏项压总价，签完再一项一项加回来。
- **"按实际"不给上限 = 把账留到完工**。所有写"按实际"的项都要配一个数（不超多少米/平），
  超出必须你书面确认。
- **隐蔽工程验收不过，不付下一笔**。水电一旦封槽、防水一旦铺贴，返工成本翻十倍，而钱已经付走了。
  付款节点必须挂在验收节点上。
