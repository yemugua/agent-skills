# 装修报价单核查与增项防范 · 概览

## 它解决什么

装修报价单最常见的坑不是"贵"，而是**报价单本身没写清楚**：
拆除费漏了、水电写"按实际"、垃圾清运"不含"、只报一项不报量、开工就要付 60%。
等你想问清楚，合同已经签了，钱已经付了，墙已经砸了。

这个技能把一份报价单拆成四件能当场判断的事：

1. **缺什么**——九项必看逐项对照，缺哪几项、缺了会怎样、当场怎么要
2. **哪里留了口子**——"按实际/按市价/另计/不含/视情况/多退少补/仅供参考"八类开口条款逐条揪出来，每条给改法
3. **钱该不该现在付**——付款节点跟你填的约定逐行对照，超红线就打 ⚠️，隐蔽工程验收不过不付下一笔
4. **合同里必须补哪几句话**——六句可直接抄的话，缺了前面所有核查都白做

## 输入 / 输出

| | 内容 |
|---|---|
| 输入 | 一张 `templates/装修报价采集表.md`（基本情况 + 报价单明细 + 九项自查 + 增项 + 付款 + 合同 + 隐蔽工程现状） |
| 输出 | `templates/装修报价采集表.md` → 九段核查报告：摘要 / 九项完整性 / 可疑表述 / 注水信号 / 付款节点 / 增项应对 / 合同六句话 / 隐蔽工程验收 / 待办 |
| 现场用 | `templates/隐蔽工程验收与付款卡.md`（水电 10 项、防水 8 项逐项打勾 + 付款节点对照卡） |

## 三条硬边界

- **不估市场价**：只提示"这项建议自行比价三处"，不编任何单价基准
- **不评价工艺**：师傅水平、现场用料要现场看，本技能只做**纸面核查**
- **不代拟合同全文**：给"必须写进合同的六句话"，不冒充律师起草正式文本

## 三个最容易踩的地方

- **项数比总价更能说明问题**：同户型同档次的报价单，项数少于 15 项基本是漏项压总价
- **"按实际"不给上限 = 把账留到完工**：所有"按实际"的项都要配一个上限数
- **隐蔽工程验收不过，不付下一笔**：水电封槽、防水铺贴之后返工成本翻十倍

## 配套规则

- `rules/quote-basics.md`：全包/半包/整装三分法、九项必看、八类开口条款、三种注水手法、付款节点表
- `rules/extra-charges.md`：增项三种来源、五句当场必问、三个"到此为止"信号、谈判三段话、合同五个坑
