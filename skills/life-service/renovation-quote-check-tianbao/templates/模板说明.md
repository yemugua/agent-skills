# 装修报价与增项核查 · 三份模板

| 模板 | 什么时候用 |
|---|---|
| `装修报价采集表.md` | **输入**：把报价单抄进来 + 自查九项必看 + 付款节点 + 合同条款有无 |
| `装修报价核查报告.md` | **输出骨架**：脚本生成的九段报告（摘要 / 完整性 / 可疑条目 / 注水信号 / 付款风险 / 增项应对 / 合同六句话 / 隐蔽工程验收 / 待办） |
| `隐蔽工程验收与付款卡.md` | **现场用**：隐蔽工程（水电、防水）验收逐项打勾，对应付款节点才放款；反过来也用它卡住"要求提前付钱"的施工方 |

## 三步上手

1. 抄一份采集表（**备注栏照抄报价单原话**，尤其"按实际""按市价""另计""不含"）
2. 跑脚本：
   ```bash
   python scripts/quote_check.py 装修报价采集表.md --json
   ```
3. 拿着报告里「合同必写六句话」和「增项谈判三段话」去谈；**谈不拢就换人，别在"多少钱"上耗**

## 核心判断只有三条

- **报价单缺不缺项**——同户型同档次少于 15 项的报价单，大概率漏项压总价
- **哪些是"按实际"**——写"按实际"却不写上限，等于把账留到完工再算
- **付款有没有卡在验收节点上**——隐蔽工程验收不过就不付下一笔

## 三条硬边界

- **不估市场价**：各城市各楼盘差异极大，只提示"该项建议自行比价三处"，不编单价基准
- **不评价工艺**：师傅水平、实际用料要现场看，本技能只做纸面核查
- **不代拟合同全文**：给"必须写进合同的六句话"，不冒充律师起草正式文本
