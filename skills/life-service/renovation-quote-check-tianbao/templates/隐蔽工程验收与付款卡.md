# 隐蔽工程验收与付款卡（现场逐项打勾）

> 原则：**验收不过，不付下一笔**。隐蔽工程一旦封住，返工成本翻十倍，而且钱已经付走了。

## 一、水电验收（封槽前，必看）

| # | 检查项 | 合格标准 | 结果 | 备注 |
|---|---|---|---|---|
| 1 | 水管走向 | 横平竖直；该走顶的部位没有偷走地 | 合格 / 不合格 |  |
| 2 | 强弱电分管 | 分开走，**间距 ≥ 300mm** | 合格 / 不合格 |  |
| 3 | 单管穿线 | 一根管里没塞多根线 | 合格 / 不合格 |  |
| 4 | 承重结构开槽 | **梁、柱、承重墙没有开槽** | 合格 / 不合格 |  |
| 5 | 打压试验 | 打压稳压，**无持续掉压** | 合格 / 不合格 |  |
| 6 | 通水试验 | 全屋水通、无积水无堵塞 | 合格 / 不合格 |  |
| 7 | 开关插座位置 | 与图纸一致，开关在门侧、插座不挡家具 | 合格 / 不合格 |  |
| 8 | 线管电料品牌型号 | 与报价单写的一致 | 一致 / 不一致 |  |
| 9 | 点位数量 | 与你确认的图纸一致，**没被"优化"减掉** | 合格 / 不合格 |  |
| 10 | 强弱电交叉处 | 有锡纸包裹或按规范处理 | 合格 / 不合格 |  |

**验收不通过就不封槽**。封了再返工，砸墙、恢复地面、重新走线，损失远大于当时停工几天。

## 二、防水验收（铺贴前，必看）

| # | 检查项 | 合格标准 | 结果 | 备注 |
|---|---|---|---|---|
| 1 | 淋浴区墙面防水高度 | **≥ 1800mm**，顶面也刷 | 合格 / 不合格 |  |
| 2 | 其余墙面防水高度 | ≥ 300mm | 合格 / 不合格 |  |
| 3 | 地面防水范围 | 淋浴区、洗手台、阳台（若有可能积水）全覆盖 | 合格 / 不合格 |  |
| 4 | 涂刷遍数 | 不少于 2 遍 | 合格 / 不合格 |  |
| 5 | 材料型号 | 与报价单一致（常见问题：用便宜一档） | 一致 / 不一致 |  |
| 6 | 门槛石/挡水条 | 已装且高于地面 | 合格 / 不合格 |  |
| 7 | **闭水试验** | 蓄水 **≥ 24 小时**，楼下不漏 | 合格 / 不合格 |  |
| 8 | 楼下天花检查 | 观察楼下顶面有无渗水痕迹 | 合格 / 不合格 |  |

**闭水试验没过，防水等于没做**。这一项最容易被跳过，也最贵。

## 三、付款节点对照卡

| 节点 | 应验收内容 | 建议累计付款上限 | 已付（%） | 是否放款 |
|---|---|---|---|---|
| 开工 | 材料进场、水电放线确认 | 30% |  | ☐ |
| **水电验收后** | 上表 1–10 项全过 | 50% |  | ☐ |
| **防水验收后** | 上表 1–8 项全过，闭水试验合格 | 60% |  | ☐ |
| 泥木验收 | 瓷砖空鼓、铺贴平整、吊顶牢固 | 70% |  | ☐ |
| 油漆验收 | 墙面平整、阴阳角顺直、无开裂 | 85% |  | ☐ |
| 竣工验收 | 五金、灯具、门、洁具、水路全通 | 95% |  | ☐ |
| 质保期满 | 遗留问题修完 | 100% |  | ☐ |

## 四、四条收手条件（出现就别再往下付钱）

1. **要求开工前付 80% 以上** → 停止
2. **要求一次付清** → 停止
3. **验收不合格但要求继续下一笔款** → 停止，先整改
4. **水电已封槽但没有做过打压试验记录** → 停止，砸开验

## 五、验收现场必做

- **当场拍照录像**：水管走向、防水涂刷高度、闭水试验蓄水状态，每项拍全景+近景
- **让对方在验收单上签字**，写明"水电验收合格"和日期
- **微信文字确认一次**（保留聊天记录，以后是证据）
- 验收单自己留一份，**不签空白验收单**

## 六、发现问题怎么办

| 情况 | 说法 |
|---|---|
| 验收不合格要返工 | 「这一项按标准没过，先整改。整改合格后我按合同节点付款，节点不变。」 |
| 对方说"先付钱才整改" | 「合同写的是验收后付款。整改费用本来就该你承担，我不承担返工费用。」 |
| 对方要以"进度"为由要钱 | 「进度款按节点走，节点没过就是没过。这一条我们合同里有。」 |
