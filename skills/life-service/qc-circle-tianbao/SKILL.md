# QC 小组活动（qc-circle）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《QC 小组活动准则》T/CAQ 10201，生成 QC 小组活动清单：小组组建与注册、PDCA 活动程序、课题类型、工具应用与成果发表巩固。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- QC小组
- 质量管理小组
- QCC
- QC成果
- QC发表
- 群众性质量活动

## 三、工作流
1. 小组组建与注册（课题/成员）
2. 按PDCA开展活动（十大步骤）
3. 明确课题类型（现场/攻关/管理/服务型）
4. 应用新老七种工具
5. 成果发表与巩固

## 四、核心内容（检查清单与判定）
QC 小组是群众性质量管理活动；活动应遵循 PDCA 循环，按课题类型选择工具，成果经验固化为标准并持续推广。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未明确小组组建（注册/课题/成员） | 组建 |
| Q2 | FAIL | 未含活动程序（十大步骤/PDCA） | 程序 |
| Q3 | WARN | 未含课题类型（现场/攻关/管理/服务型） | 课题 |
| Q4 | FAIL | 未含工具应用（新老七种工具） | 工具 |
| Q5 | WARN | 未含成果发表与巩固 | 成果 |

> 脚本 `qc-circle_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python qc-circle_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python qc-circle_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

- 重大隐患/高风险判定需由具备资质人员签字确认。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
