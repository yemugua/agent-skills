# 题型动作与选项陷阱

> 答题前必读。**判题型 → 执行动作 → 四项全比对**，顺序不能颠倒。

## 一、六类题型的完整动作表

### 1. 概括题

| 项 | 内容 |
|---|---|
| 识别词 | 概括、归纳、简述、main idea 概述 |
| 定位 | 中心句：段首句、段尾句、转折/结论句 |
| 动作 | 先给每段写一句「这段在说什么」，再合并 |
| 硬约束 | 不得加入原文没有的判断；不得只写某一段 |
| 常见错 | 把细节当概括（太细）；把作者未说的话补进去（超纲） |

### 2. 推断题

| 项 | 内容 |
|---|---|
| 识别词 | 推断、可以推出、说明、表明、imply |
| 动作 | 找原文依据句 → 用**原文的限定词**复述 |
| 硬约束 | **不得超出原文**。常识合理但原文没写，一律不选 |
| 自查 | 把选项改写成「作者说过 X」，回原文找这句话；找不到就排除 |
| 常见错 | 用常识补全；把「可能」读成「一定」；选项比原文更强 |

**强度检验**：原文说 may，选项若说 will，直接排除；原文说部分，选项若说全部，排除。

### 3. 词句理解题

| 项 | 内容 |
|---|---|
| 识别词 | 加粗词、划线句、代词指代、in this paragraph |
| 动作 | **回原文定位**该词，看它在本句与上下文中的义 |
| 顺序 | 先定本句义 → 再看上下文 → 最后排除一词多义干扰项 |
| 常见错 | 用词典第一个义项；只看本句不看上下文；被常见搭配带偏 |

### 4. 主旨题

| 项 | 内容 |
|---|---|
| 识别词 | 主要意思、最佳标题、main idea、purpose、best title |
| 定位 | 首段首句、末段末句、转折句、结论句 |
| **面的大小** | 选面必须**覆盖全文主体**，不能只覆盖一段 |
| 自查 | 「这个选项在第几段能被完整支持？」只在一段成立 → 段落主旨 |
| 常见错 | 选太小（段落主旨）；选太大（作者没谈的宏大话题）；选标题党式修辞 |

### 5. 态度题

| 项 | 内容 |
|---|---|
| 识别词 | 作者态度、看法、opinion、attitude |
| 定位 | **评价性词汇与态度副词**（而非中性叙述句） |
| 动作 | 圈出褒贬词 → 判断方向（支持/反对/中立/保留）→ 定强度 |
| 硬约束 | 区分**作者态度**与**文中他人被引述的态度** |
| 自查 | 若去掉引述后作者没表明立场，答案就不是它 |

常见评价词方向：褒义（effective、crucial、promising）／贬义（fail、harmful、disappointing）／保留（may、appears、arguably）。

### 6. 细节题

| 项 | 内容 |
|---|---|
| 识别词 | 哪项正确/符合原文、according to the passage |
| 动作 | 提取选项中**最独特的名词或数字** → 回原文定位 → 逐字比对 |
| 三处高危 | **数字**、**时间**、**范围**（all/most/some/部分） |
| 常见错 | 数字微调（比例、年份）；范围偷换；把「相关」当「因果」 |

## 二、选项陷阱类型清单（核心资产）

**每个选项都要过一遍这张表。** 陷阱按出现频率排序：

| # | 陷阱类型 | 特征 | 识别动作 | 典型表述 |
|---|---|---|---|---|
| 1 | **无中生有** | 原文完全没有该信息 | 回原文搜关键词，搜不到即排除 | 凭空加入的背景、动机、结果 |
| 2 | **偷换概念** | 关键词相同但所指对象不同 | 找出选项与原文的主语是否同一 | 把「部分学生」写成「学生」 |
| 3 | **绝对化** | 语气比原文更强 | 比较强度词 | may→will、可能→一定 |
| 4 | **过度推断** | 由原文可推出，但结论跨了一步 | 把结论改写回原文找依据 | 从「相关」推出「导致」 |
| 5 | **以偏概全** | 只覆盖局部却说得像整体 | 问「第几段能支持」 | 个例→普遍 |
| 6 | **答非所问** | 话题相关但没回答题干问的 | 重读题干问的是什么 | 问原因选原因的例子 |
| 7 | **范围与数字偷换** | 数字、时间、范围被改 | 逐字核对这三处 | 30%→40%、大部分→全部 |
| 8 | **因果倒置或混淆** | 把因果颠倒，或把相关当因果 | 检查「因为/导致」方向 | 结果→原因 |

## 三、比对流程（防止漏检）

```
1. 提取题干的核心问法（谁、什么、何时、为何、态度）
2. 判题型 → 确定动作
3. 对四个选项逐个做：
   a. 找出选项中最独特的名词/数字
   b. 回原文定位该处
   c. 逐字比对，比对数字/时间/范围/主语/强度
   d. 套用陷阱清单八类逐项过
   e. 记录该选项被排除的**具体原因**
4. 只在四项都比对完后才确定答案
```

**排除原因必须写下来**，这是错题归因的唯一可靠来源。

## 四、止损规则（卡住怎么办）

| 已用时间 | 动作 |
|---|---|
| 达到单题平均时间上限 | 标记跳过，先做下一题 |
| 跳过两题后回头 | 仍超时则**猜最没有陷阱特征**的选项（无绝对化词、覆盖面适中） |
| 剩余时间充裕 | 回头处理标记题，只验证排除原因 |

**猜也要有依据**：排除绝对化、范围偷换、覆盖面过大的选项后剩下的那个，命中率高于随机。

## 五、限时训练配比（不是速度承诺）

| 阶段 | 做法 | 目的 |
|---|---|---|
| 精读期 | 不限时，逐项比对并写排除原因 | 建立动作与排除理由 |
| 计时期 | 按考试实际时间限制，训练在压力下定位 | 缩短定位时间 |
| 复盘期 | 只看错题，**归类到八类陷阱** | 防止同类陷阱重复发生 |

**顺序不能反**：先无计时建立正确动作，再计时提速。直接上计时会导致错误动作被固化。

时间分配比例以官方现行试卷结构与考试规定为准，不要套用通用比例。

## 六、错因归类表（复盘时填）

| 题号 | 题型判对？ | 定位正确？ | 陷阱类型 | 排除原因是否写清 | 下次动作 |
|---|---|---|---|---|---|

**只有「排除原因写清」这一列打勾的错题才算复盘完成**。

## 七、常见误操作

1. **先选答案再找依据**。应先比对再选。
2. **只验倾向项**。错误项常埋在没细看的地方。
3. **把「读过了」当「支持」**。读过不等于支持，必须定位到具体句。
4. **推断题凭常识**。原文没写就不成立。
5. **态度题跟着引述走**。引述≠作者立场。
6. **主旨题不检查覆盖面**。必须问「第几段能支持」。
7. **错题只记对错**。不记排除原因就归不了因，下次照错。
