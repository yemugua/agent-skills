# 阅读理解答题技巧与失分点

阅读理解丢分**极少是因为没读懂**，绝大多数是因为**用错了动作**：题型判断错、定位偏、把「读过」当成「答对」。本技能给的是「题型 → 该做什么动作」的对照表，以及选项陷阱的比对方法。

## 一、硬边界（能做 / 不能做）

| 能做 | 不能做 |
|---|---|
| 按题型给出定位与判断动作 | 承诺阅读得分率或提分幅度 |
| 识别选项的陷阱类型 | 断言某个选项「一定错」而未看原文 |
| 给出限时训练的分配方法 | 代替考生做具体某篇文章的答案 |
| 归纳错因分类 | 判定某考生「阅读能力差」 |
| 提供复盘表字段 | 提供考试真题或官方答案（以官方现行资料为准） |

**必须转交专业人士：** 阅读困难伴明显注意力、社交或情绪问题，或出现阅读理解完全无法完成的状况——应排查学习障碍，必要时转专业评估，不要靠答题技巧硬补。

## 二、什么时候用

| 用户说法 | 用不用 | 说明 |
|---|---|---|
| 明明看懂了却选错 | 用 | 多为题型判断与定位动作错误 |
| 推理题能不能猜 | 用 | 明确「不得超出原文」的判定线 |
| 态度题看不出立场 | 用 | 给评价性词汇定位法 |
| 主旨题总选太小的选项 | 用 | 给主旨题的覆盖范围检查法 |
| 细节题怎么找 | 用 | 给回原文比对动作 |
| 阅读怎么提速 | 用 | 给限时训练与顺序安排 |
| 想知道选项陷阱类型 | 用 | 规则文件有完整清单 |
| 帮我做这篇文章 | 部分用 | 可讲方法，具体作答需本人完成 |

## 三、完整工作流

### 步骤 1：先判题型（判错则全盘皆错）

题干关键词直接对应动作，见第四节题型对照表。**先判题型再回原文**，不要边读边猜。

### 步骤 2：执行对应的定位动作

定位的落点是**选项里那个最独特的名词或数字**，不是凭印象翻。

### 步骤 3：比对选项与原文（陷阱检查）

见 `rules/题型动作与选项陷阱.md`。**每个选项都要做一次比对**，不能只验证自己倾向的那个——这是最常见的失分来源。

### 步骤 4：超过时间阈值就按规则处理

单题卡住超过约定时间，按规则文件里的止损动作处理，不要死磕。

### 步骤 5：限时训练（提升速度的唯一途径）

不计时地练只会让准确率好看、上考场依然崩。给的是配比方法，不是速度承诺。

## 四、核心规则（答题前必读）

**先读 `rules/题型动作与选项陷阱.md`，不要凭印象答。**

### 六类题型的答题动作

| 题型 | 识别词 | 核心动作 | 硬约束 |
|---|---|---|---|
| **概括题** | 概括、归纳、简述 | 找中心句（段首/段尾/转折后） | 不能加入原文没有的概括性判断 |
| **推断题** | 推断、可以推出、表明 | 找原文依据句，**逐字限定** | **不得超出原文**，常识补充一律不算 |
| **词句理解题** | 加粗词、划线句、指代 | **回原文定位**该词出现处及其上下文 | 先看在本句中的义，再看上下文 |
| **主旨题** | 主要意思、标题、purpose | 看首尾句与转折处，覆盖全文 | 选面过大或过小都要警惕 |
| **态度题** | 作者态度、opinion、看法 | 找评价性词汇与态度副词 | 区分作者态度与文中他人态度 |
| **细节题** | 哪项、正确、符合 | 定位选项关键词 → 逐字比对 | 数字、时间、范围三处最易被偷换 |

### 核心原则

- **推断题不是发挥题**：常识再合理，只要原文没写就不选。
- **主旨题要覆盖全文**：只覆盖某一段的选项通常是段落主旨，不是全文主旨。
- **态度题看评价性词汇**，不看「作者说了什么」，看「作者怎么评价」。

## 五、脚本用法

脚本：`scripts/answer_trap_scanner.py`

```bash
python scripts/answer_trap_scanner.py --file 选项.json
python scripts/answer_trap_scanner.py --selftest
```

| 字段 | 说明 |
|---|---|
| `stem` | 题干文本 |
| `options` | 四个选项文本列表 |
| `source_passage` | 判断依据提示语（可选） |

输出：题型推断、六类陷阱类型命中情况、需回原文比对的提示项。

## 六、人工确认清单（不能省）

- [ ] 是否已先判题型再回原文？
- [ ] 定位是否落在选项中最独特的名词/数字上？
- [ ] 是否**四个选项都**做过一次比对（而非只验倾向项）？
- [ ] 推断题的每个判断能否在原文找到逐字依据？
- [ ] 主旨题选的是全文主旨还是某段主旨？
- [ ] 态度题依据的是作者的评价还是引述他人的看法？
- [ ] 细节题的数字、时间、范围是否逐字核对过？
- [ ] 错题是否已按错因归类（而非只记「做错了」）？

## 七、最常见的坑

1. **凭印象选，不回原文比对**。读过的印象会被记住的错觉替代，必须逐字比对。
2. **只验证自己倾向的那个选项**。错误选项往往在没细看的地方埋雷，四个都要比对。
3. **推断题用常识补全**。这是推断题最主要的失分来源，原文没写就不选。
4. **主旨题选段落主旨**。选项说得对但只覆盖一段，通常是陷阱。
5. **态度题把文中他人的看法当成作者态度**。引述的观点不等于作者认同。
6. **细节题漏看数字与范围**。「部分」「大多数」「几乎」是最容易被偷换的位置。
7. **词句理解题凭印象解释**。词义随上下文变，必须回原文定位。
8. **卡住就死磕**。超过时间阈值不处理，会连带吃掉后面几题的时间。
9. **不计时训练**。准确率高但速度上不去，考试时同样做不完。
10. **错题只记答案不记错因**。下次遇到同类陷阱还会再错，必须归类。

## 八、边界与免责

本技能提供答题动作与陷阱判别方法，**不提供真题、不代替考生作答、不承诺得分率**。各考试的题型、分值与时间分配以官方现行规定和试卷结构为准，请勿以本技能的比例为准。阅读能力的真实差异需要专业评估，不要用技巧掩盖能力缺口。
