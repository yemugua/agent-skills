# 行为安全管理 BBS（behavioral-safety）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据行为安全管理（BBS）方法，生成行为安全清单：关键安全行为观察、观察卡与频次、反馈与沟通、数据分析与趋势、正向激励。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 行为安全
- BBS
- 安全观察
- 行为观察卡
- 不安全行为

## 三、工作流
1. 识别关键安全行为与风险点
2. 制定观察卡与观察频次
3. 开展现场观察与即时反馈沟通
4. 汇总数据识别趋势与短板
5. 正向激励与持续改进

## 四、核心内容（检查清单与判定）
行为安全（BBS）通过结构化观察与反馈减少不安全行为；强调非惩罚性观察、即时沟通和正向强化，数据用于识别系统性短板。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含关键安全行为识别 | 行为 |
| Q2 | FAIL | 未含观察卡与频次 | 观察 |
| Q3 | WARN | 未含现场反馈沟通 | 反馈 |
| Q4 | FAIL | 未含数据汇总与趋势 | 数据 |
| Q5 | WARN | 未含正向激励 | 激励 |

> 脚本 `behavioral-safety_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python behavioral-safety_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python behavioral-safety_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
