# 安全生产许可证（safety-production-license）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《安全生产许可证条例》，生成清单：取证范围与条件、安全投入与机构人员配备、安全评价与工伤保险、申报材料与审查、有效期延期与变更管理。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 安全生产许可证
- 安许证
- 安全生产许可
- 安许延期
- 安全生产条件

## 三、工作流
1. 明确取证范围与法定条件
2. 保障安全投入与机构人员
3. 完成安全评价并参加工伤保险
4. 准备申报材料配合审查
5. 管理有效期延期与变更

## 四、核心内容（检查清单与判定）
《安全生产许可证条例》对矿山、建筑施工和危化品等高危行业实行许可；须具备法定安全生产条件并按期延期。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含取证范围与条件 | 范围 |
| Q2 | FAIL | 未含安全投入与机构人员 | 投入 |
| Q3 | WARN | 未含安全评价与工伤保险 | 评价 |
| Q4 | FAIL | 未含申报材料与审查 | 申报 |
| Q5 | WARN | 未含延期与变更管理 | 延期 |

> 脚本 `safety-production-license_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python safety-production-license_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python safety-production-license_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
