# 规则表二：退一赔三判定、取证清单、投诉路径与误判对照

## 第 1 节 退一赔三：三个要件必须同时成立

1. 相对方是**经营者**；
2. 购买行为属于**生活消费**；
3. 经营者存在**欺诈行为**：故意告知虚假情况，或故意隐瞒真实情况，诱使消费者作出错误意思表示。

满足时：可要求退还已付款项，并**增加赔偿三倍**；增加赔偿金额不足**五百元**的，按五百元计算（以现行规定为准）。

## 第 2 节 会员卡场景中"较可能构成欺诈"的情形

| 情形 | 说明 |
|---|---|
| 明知即将停业/转让，仍大量售卡并**隐瞒**该事实 | 典型隐瞒型欺诈 |
| 收款后**从未提供**任何服务即关门 | 无履约意图 |
| 虚假承诺"全国通用""终身有效""随时退"但实际不具备条件 | 告知虚假情况 |
| 虚构品牌授权、连锁门店、资质证书 | 告知虚假情况 |
| 收银方与经营主体不一致且未披露，收款后失联 | 隐瞒真实情况 |
| 伪造单用途预付卡备案信息 | 告知虚假情况 |

## 第 3 节 否定情形：这些**不能当然主张退一赔三**（防误伤重点）

| 情形 | 通常结论 | 说明 |
|---|---|---|
| 经营不善、资金链断裂导致停业 | 一般**不构成欺诈** | 属商业风险，可主张退费而非三倍赔偿 |
| 合同明确约定不可退且已显著提示 | 属**合同条款争议** | 争议焦点是条款效力，不是欺诈 |
| 已正常提供大部分服务，仅剩余额争议 | 属**退费金额争议** | 走核算，不走欺诈 |
| 商家愿意退费只是金额谈不拢 | 属**履约争议** | 不适用三倍赔偿 |
| 门店正常搬迁且提供替代门店 | 属**履约方式变更** | 需个案判断是否影响合同目的 |
| 消费者用于经营目的的批量购卡 | 不适用 | 非生活消费 |
| 平台团购券未消费产生的退款 | 依平台规则与网络交易规则 | 路径不同 |

**一句话区分**：
- **欺诈 → 退一赔三**（以已付款为基数）
- **条款争议 → 主张条款不成为合同内容**
- **金额争议 → 按核算口径退费**
- **停业/跑路 → 退费 + 向责任主体追索 + 涉嫌犯罪的报案**

四条路径不能混用。把"停业"一律说成"欺诈"，主张往往不被支持，还会拖慢退费进度。

## 第 4 节 取证清单（顺序固化）

| # | 证据 | 固化要点 |
|---|---|---|
| 1 | 办卡合同/协议 | **全部条款拍照**，含背面小字、补充协议 |
| 2 | 付款凭证 | 看**收款方名称**，截图含商户全称与交易单号 |
| 3 | 经营主体信息 | 国家企业信用信息公示系统查询截图（名称、状态、股东） |
| 4 | 卡面与卡号 | 正反面照片、电子卡截图 |
| 5 | 余额记录 | 商家系统/小程序余额页截图，含日期；**商家拒不提供时书面要求其提供** |
| 6 | 消费记录 | 历次消费明细、签字单 |
| 7 | 宣传承诺 | "随时退""全国通用""终身有效"的页面截图、海报照片、聊天记录 |
| 8 | 停业/转让证据 | 门店现场照片（含门头与停业告示）、公告截图、物业或邻居佐证 |
| 9 | 沟通记录 | 完整聊天记录、通话录音（依法取得）、书面函件与回执 |
| 10 | 联合维权信息 | 其他消费者的金额统计与联系方式（注意依法保护个人信息） |

## 第 5 节 投诉路径顺序（不要跳步）

| 顺序 | 路径 | 适用 |
|---|---|---|
| 1 | 与商家书面协商 | 全部类型；留工单号或回执 |
| 2 | 支付渠道争议 | 通过第三方支付、银行卡支付的，可申请交易争议处理（注意申请时限） |
| 3 | **12315** / **12345** | 消费纠纷、格式条款、虚假宣传 |
| 4 | **商务主管部门** | 单用途商业预付卡未备案、发卡企业违规 |
| 5 | 行业主管部门 | 健身、教育培训、美容等行业的专门监管 |
| 6 | 消费者协会调解 | 需双方同意调解 |
| 7 | **公安机关报案** | 涉嫌诈骗、集资诈骗、合同诈骗 |
| 8 | 人民法院诉讼 | 小额诉讼程序（金额较小的），或普通程序 |

**组合建议**：商家已失联的，走 2 + 3 + 4 + 7 同步推进，不要只等一个渠道。

## 第 6 节 保全与执行提醒（钱能不能拿到，看这步）

1. **尽早固定主体信息**：营业执照名称、统一社会信用代码、股东、经营状态。
2. **尽早固定财产线索**：收款账户、门店资产、关联主体（金额大或人数多的尤其重要）。
3. **人数多的联合维权**：统一证据格式与金额统计，提高谈判与处理效率。
4. **考虑财产保全**：有转移资产迹象的，可依法申请诉前或诉中财产保全（由律师或当事人依法申请）。
5. **不要签"自愿放弃追索"类文件**：签署前务必看清，必要时咨询专业人士。
6. **破产情形**：进入破产程序的，务必在法定期限内**申报债权**，逾期可能丧失受偿机会。

## 第 7 节 常见误判对照表（否定词防误伤）

| 文本/情形 | 不要判成 | 正确判法 |
|---|---|---|
| 商家停业 | 一定是欺诈 | 需证明停业前已明知且故意隐瞒 |
| 已受理投诉 | 已退款 | 需核对**到账金额** |
| 卡内余额 3000 | 应退 3000 | 需按折扣系数折算，赠送部分不退本金 |
| 合同写了"概不退换" | 绝对不能退 | 属格式条款效力争议，可主张不成为合同内容 |
| 开卡时没说手续费 | 可以扣手续费 | **未约定不得收取** |
| 换老板 | 无人负责 | 受让方继续履行，原经营者仍可能承担责任 |
| 卡过期 | 余额归零 | 过期条款存在效力争议，余额一般仍可主张 |
| 已消费金额按原价扣 | 必然合法 | 需有明确约定并显著提示 |
| 赠送金额 | 应退还本金 | 一般不折算退还 |
| 商家愿意退 | 纠纷已解决 | 需核对金额与到账 |
| 门店招牌名 | 被告名称 | 应使用**营业执照上的主体名称** |
| 团购券未消费 | 适用实体卡规则 | 依平台规则与网络交易规则处理 |
