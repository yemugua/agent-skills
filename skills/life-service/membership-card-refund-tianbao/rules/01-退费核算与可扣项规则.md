# 规则表一：会员卡/储值卡退费核算口径、可扣项上限与责任主体

> 依据消费者权益保护、合同与单用途商业预付卡管理的通行规则整理。**具体条款与执行口径以现行规定和当地主管部门要求为准**，本表不编造条款号。

## 第 1 节 卡类型判别表（决定投诉到哪个门）

| 类型 | 判别要点 | 典型场景 | 主管部门方向 |
|---|---|---|---|
| 单用途商业预付卡 | 仅在**本企业或同一品牌连锁**内使用 | 超市卡、餐饮储值卡、美容卡 | 商务主管部门（发卡企业备案） |
| 多用途预付卡 | 可跨**不同法人**的商户使用，由专营机构发行 | 通用购物卡 | 支付结算主管部门 |
| 会员资格/服务卡 | 兼具预付费与服务合同性质 | 健身年卡、游泳卡、课时包 | 市场监管 + 行业主管部门 |
| 平台充值余额 | 通过电商平台/App 充值 | 电商余额、游戏币 | 市场监管 / 行业主管部门 |

**判别口诀**：先看**能不能跨法人用**，再看**谁收的钱**。收款方名称决定后续主张的相对方。

## 第 2 节 应退金额的两套口径

### 2.1 口径 A —— 价格摊销法（消费者口径，优先主张）

```
折扣系数 k = 实付本金 / (实付本金 + 赠送金额)
应退本金   = 剩余卡内可用余额 × k
```

原理：赠送金额不是消费者支付的，其对应的额度不应折算为可退本金；整张卡的每一元可用额度实际只花了 k 元。

**示例**：实付 5000 元，赠送 1000 元，卡内总可用 6000 元，剩余余额 3000 元。
k = 5000 / 6000 = 0.8333；应退 = 3000 × 0.8333 = **2500 元**（不是 3000 元）。

### 2.2 口径 B —— 门市价法（商家常用口径）

```
应退 = 实付本金 − 已消费项目按门市价（原价）合计     （下限为 0）
```

特点：已消费按原价计算，会把享受过的折扣全部追溯扣回，**通常明显低于口径 A**。

**示例**：实付 5000 元、赠送 1000 元，已消费项目门市价合计 3200 元。
口径 B 应退 = 5000 − 3200 = **1800 元**。

### 2.3 何时哪个口径更站得住

| 条件 | 倾向 |
|---|---|
| 合同**明确约定**"退卡时已消费按门市价结算"，且办卡时**已显著提示**（加粗、口头说明、单独签字确认） | 口径 B 更可能被支持 |
| 合同**未约定**或约定在背面小字、未作提示说明 | 主张该格式条款未成为合同内容，按口径 A |
| 约定导致"退卡比继续消费还亏" | 主张显失公平，请求调整 |
| 商家从未实际提供服务（未开卡、门店未营业） | 主张全额退本金，不适用任何折算 |

### 2.4 主张区间

```
建议主张区间 = [ 口径 B 结果 , 口径 A 结果 ]
优先按口径 A 提出，底线不低于口径 B
```

## 第 3 节 可扣项与不可扣项（防乱扣）

| 项目 | 能否扣 | 条件 |
|---|---|---|
| 已消费金额（按约定折算） | 能 | 需有系统消费记录 |
| 赠送金额对应部分 | 不退 | 赠送部分本身不是实付本金，不折算退还 |
| 已领取的实物赠品 | 有争议 | 需合同明确约定可追回或折价；未约定的不得事后扣款 |
| 已享受的折扣优惠 | 有争议 | 同上，需明确约定并显著提示 |
| 实体卡工本费 | 小额可扣 | 需合同明确约定且金额合理 |
| 退卡手续费/违约金 | 有条件 | **必须开卡时已约定并显著提示**；事后新增的不得收取 |
| "概不退换"条款 | 不当然有效 | 属排除消费者主要权利的格式条款，可主张不成为合同内容 |
| 商家自身经营损失 | 不能 | 经营风险不由消费者承担 |

## 第 4 节 违约金与手续费上限

```
约定扣款 = 应退金额 × 约定比例
上限校验 = min(约定扣款, 商家实际损失)
实际可扣 = 有约定且已显著提示 ? 上限校验 : 0
```

- **没有约定 → 一分钱不能扣**。这是最高频的乱扣来源。
- **有约定但明显高于实际损失** → 可请求适当调整（以现行规定为准）。实务中"超过实际损失 30%"常被作为判断过高的参考，但**不是绝对标准**，需个案判断。
- **不得重复扣**：已按门市价追溯折扣的，不能再叠加违约金。

## 第 5 节 有效期与"过期作废"

| 情形 | 处理口径 |
|---|---|
| 卡面标注有效期，且办卡时已明确告知 | 有效期本身可能被认可，但**余额不当然归零** |
| 商家未提示有效期或条款在背面小字 | 可主张该条款未成为合同内容 |
| 过期系商家原因（长期停业、预约不上） | 可主张顺延或退费 |
| 过期后商家仍在经营 | 主张退还余额，可要求扣除有约定且合理的工本费 |
| 长期未消费且商家已尽提示义务 | 仍可主张退还本金余额 |

"过期作废"属典型的**排除消费者主要权利**的格式条款方向，存在效力争议，最终由监管部门或法院认定。

## 第 6 节 停业、转让、搬迁的责任主体

| 情形 | 责任主体方向 |
|---|---|
| 个体工商户 | 经营者**个人**承担责任 |
| 有限责任公司正常经营 | 公司承担，股东以认缴出资为限 |
| 股东未届出资期限 / 抽逃出资 / 人格混同 | 可依法主张股东承担相应责任（**需证据**） |
| **转让、换老板** | 受让方继续履行；拒绝履行的向**原经营者**主张 |
| 同一品牌其他门店可用 | 判断是否构成合同目的无法实现（距离过远、服务内容不同可主张退费） |
| 门店搬迁 | 搬迁显著增加履约成本的，可主张退费 |
| 已注销 | 向清算义务人/股东主张（**需证据**） |
| 进入破产程序 | 在法定期限内申报债权 |
| 涉嫌诈骗跑路 | 向公安机关报案，同时走民事路径 |

**关键动作**：付款凭证上的**收款方名称**就是主张对象，务必与营业执照名称核对。写成门店招牌名会被驳回。

## 第 7 节 举证责任分配

| 待证事实 | 举证方 | 常见证据 |
|---|---|---|
| 充值金额与实际支付 | 消费者 | 付款凭证、充值记录 |
| 卡内余额 | **商家**（掌握系统数据） | 商家系统截图/打印；消费者应自行截图固定 |
| 已消费明细 | 商家 | 消费记录、签字单 |
| 已尽提示说明义务 | 商家 | 加粗条款、单独签字确认页、告知录音 |
| 实际损失金额 | 商家 | 成本凭证 |
| 停业/转让事实 | 消费者 | 现场照片、公告、企信网查询结果 |

**要点**：余额和消费明细在商家系统里，消费者应**第一时间截图固定**，商家拒不提供的，可在投诉或诉讼中要求其提供。

## 第 8 节 时效

普通民事争议的诉讼时效一般为**三年**，自知道或应当知道权利受到损害以及义务人之日起算（以现行规定为准）。**久拖不决的应及时主张权利并留痕**（书面催告、投诉记录均可作为主张权利的证明）。
