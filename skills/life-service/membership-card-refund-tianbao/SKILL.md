# 会员卡储值卡退费与商家停业转让核查

会员卡退费争议有三个真正的分水岭：**卡是什么类型**（决定找哪个部门）、**钱怎么算**（决定要多少）、**找谁要**（决定能不能拿到）。只谈"能不能退"没有意义，必须落到这三点。

## 一、硬边界（能做 / 不能做）

| 能做 | 不能做 |
|---|---|
| 判定预付卡类型并对应主管部门 | 认定商家构成诈骗（由公安机关认定） |
| 按价格摊销法与门市价法给出应退区间 | 承诺"一定能拿到全额退款" |
| 判定停业/转让/搬迁后的责任主体方向 | 认定股东必须承担连带责任（需出资、人格混同等证据） |
| 识别格式条款风险点（概不退换、过期作废） | 断言某条款"当然无效"（由监管部门或法院认定） |
| 给出退一赔三的适用与不适用场景 | 一律主张三倍赔偿 |
| 输出取证清单、投诉顺序与保全建议 | 提供诉讼代理意见 |

**必须转交专业人士的情形：**
- 商家跑路且涉及人数众多、金额较大——建议联合维权并委托律师。
- 已进入破产程序的——需在法定期限内申报债权，请咨询专业人士。
- 涉嫌集资诈骗、合同诈骗的——向公安机关报案，由司法机关认定。
- 需要申请财产保全、强制执行的——必须由律师或当事人依法申请。

## 二、什么时候用

| 用户说法 | 用不用 | 说明 |
|---|---|---|
| 健身年卡一次没用能退吗 | 用 | 走未消费/部分消费退费核算 |
| 商家关门跑路了 | 用 | 走责任主体 + 保全 + 报案路径 |
| 换老板了卡不能用了 | 用 | 走转让承继与责任主体判定 |
| 退卡要扣 30% 手续费 | 用 | 走可扣项与违约金上限核算 |
| 卡过期了余额作废 | 用 | 走过期条款与余额退还 |
| 赠送的钱为什么不退 | 用 | 走赠送金额性质与折算系数 |
| 帮我把钱追回来 | 部分用 | 本技能给路径与材料，执行需自行或委托律师 |
| 这个商家是诈骗吧 | 部分用 | 可提示报案材料，定性由公安机关作出 |

## 三、完整工作流

### 步骤 1：先定卡的类型（决定找谁）

| 类型 | 判别 | 主管部门方向 |
|---|---|---|
| **单用途商业预付卡** | 零售、住宿餐饮、居民服务业企业发行，只在本企业或同一品牌连锁内使用 | 商务主管部门（发卡企业备案） |
| **多用途预付卡** | 专营发卡机构发行，可跨法人使用 | 支付结算主管部门 |
| **会员资格/服务卡** | 健身年卡、游泳卡、课时包（兼具预付与服务合同性质） | 市场监管（消费合同）+ 行业主管部门 |
| **平台充值余额** | 电商、游戏、App 内余额 | 市场监管 / 行业主管部门 |

**判别要害**：看**能不能跨法人使用**和**谁发的卡**，不是看卡片叫什么名字。

### 步骤 2：确认责任主体（钱向谁要）

| 情形 | 责任方向 |
|---|---|
| 个体工商户经营 | 经营者个人承担责任 |
| 公司正常经营 | 公司承担；股东以认缴出资为限 |
| 股东未届出资期限/抽逃出资/人格混同 | 可依法主张股东承担相应责任（需证据） |
| **转让/换老板** | 受让方继续履行；未约定或拒绝履行的，向原经营者主张 |
| 同一品牌其他门店仍在营业 | 需判断是否构成合同目的无法实现 |
| 已注销 | 向清算义务人/股东主张（需证据） |
| 进入破产 | 在法定期限内申报债权 |

### 步骤 3：核算应退金额（见第四节，用脚本算）
### 步骤 4：识别可扣项与不可扣项（防商家乱扣）
### 步骤 5：判断能否主张退一赔三（见规则表第 5 节）
### 步骤 6：取证与保全（见规则表第 6 节）
### 步骤 7：按顺序投诉与主张（见第六节）

## 四、核心规则（核算前必读）

**先读这两个文件，不要凭印象算：**
- `rules/01-退费核算与可扣项规则.md` —— 卡类型判别、两种折算口径（价格摊销法 vs 门市价法）、赠送金额处理、违约金与手续费上限、过期条款、责任主体判定表。
- `rules/02-退一赔三判定与投诉取证.md` —— 退一赔三的适用与否定情形、取证清单、投诉路径顺序、保全建议、误判对照表。

**核算骨架（详见规则表）：**

```
折扣系数 k = 实付本金 / (实付本金 + 赠送金额)

价格摊销法（消费者口径）：
    应退 = 剩余卡内余额 × k

门市价法（商家口径）：
    应退 = 实付本金 − 已消费项目门市价合计（下限为 0）

建议主张区间 = 两者之间，优先按价格摊销法主张
```

**关键规则**：赠送金额对应的部分一般不退还本金；但商家若主张"已消费按原价扣减"，须有**明确约定并已显著提示**，否则可主张该格式条款不成为合同内容。

## 五、脚本用法

脚本：`scripts/prepaid_card_refund.py`（Python 3 标准库）

```bash
python scripts/prepaid_card_refund.py --file 卡片.json
python scripts/prepaid_card_refund.py --file 卡片.json --json
python scripts/prepaid_card_refund.py --selftest
```

输入 JSON 字段：

| 字段 | 说明 |
|---|---|
| `paid` | 实付本金（元） |
| `gift` | 赠送金额（元），无则填 0 |
| `remaining` | 剩余卡内可用余额（元，含赠送未用部分） |
| `consumed_list_price` | 已消费项目按门市价/原价合计（元），用于门市价法对比 |
| `penalty_rate` | 合同约定的退卡违约金比例（0~1），无约定填 0 |
| `actual_loss` | 商家实际损失（元，如已享赠品成本），用于违约金上限校验 |
| `expired` | 卡面约定有效期是否已过（true/false） |
| `notice_penalty` | 开卡时是否已显著提示该违约金条款（true/false） |

输出：折扣系数、两种口径的应退金额、违约金上限校验、建议主张金额与区间、可扣项提示。

## 六、人工确认清单（不能省）

- [ ] 办卡协议/合同的**全部条款**已拍照（含背面小字），不是只拍了卡面？
- [ ] 付款凭证上的**收款方名称**与商家营业执照名称一致（决定被告是谁）？
- [ ] 已通过国家企业信用信息公示系统核到经营主体存续状态？
- [ ] 卡内余额以**商家系统记录**为准并已截图/打印，不是只凭记忆？
- [ ] 赠送金额与本金在系统中是分账记录还是混在一起（影响折算）？
- [ ] 合同中的违约金/手续费条款在办卡时**已显著提示**（加粗、口头说明）？
- [ ] "随时退""全国通用""终身有效"等承诺是**书面**还是口头？
- [ ] 停业/转让的公告、通知、现场照片已固定？
- [ ] 涉及人数多的，是否已建立联系并统计金额？
- [ ] 所有主张均**书面提出**并保留工单号或回执？

## 七、最常见的坑

1. **只谈"能不能退"，不算"退多少"**。商家同意退费后按门市价扣减已消费，退到手的可能远低于预期，必须先算清楚再谈。
2. **把赠送金额当本金主张**。赠送部分一般不折算成可退本金，主张全额会削弱可信度，正确做法是主张"剩余余额 × 折扣系数"。
3. **口头承诺没留证**。"随时退""全国通用"只靠口述，事后难以证明，必须落到书面或录音（依法取得）。
4. **商家换老板就放弃追索**。转让不消灭原经营者的责任，变更后的主体也可能需要继续履行。
5. **把"经营不善停业"当"欺诈"**。经营失败本身不当然构成欺诈，一律主张退一赔三往往不被支持。
6. **忽略违约金上限**。约定的手续费比例过高、或与实际损失明显不成比例的，可请求调整；**开卡时未约定的手续费不得事后加收**。
7. **把"卡过期"当"余额归零"**。过期作废条款存在效力争议，余额一般仍可主张退还（以现行规定与司法实践为准）。
8. **把"已受理"当"已退款"**。必须核对**到账金额**，受理通知不等于退款完成。
9. **只投诉不保全**。商家一旦跑路或转移资产，赢了也执行不到；金额大或人数多的应尽早考虑财产保全并委托律师。
10. **责任主体写错**。起诉对象写成门店名而非营业执照上的主体名称，会被驳回；个体工商户与公司的责任承担方式也不同。
11. **团购券与会员卡混淆**。平台购买的团购券受平台规则与网络交易规则约束，与实体会员卡的处理路径不同。

## 八、边界与免责

本技能提供**类型判别、核算方法与维权路径**，不构成法律意见，也不承诺退款结果。格式条款的效力、是否构成欺诈、股东是否承担责任，由市场监督管理部门或人民法院依法认定。涉及人数众多、金额较大、已进入破产或涉嫌刑事犯罪的，请及时委托律师等专业人士并向有关部门报案。各地对单用途商业预付卡的具体管理口径存在差异，请以当地现行规定为准。
