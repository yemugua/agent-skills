# 长视频平台离线缓存正确用法：常见失败与排查

报错信息请**粘贴原文**再对照。写成「下载失败了」没有排查价值，
写成 `HTTP Error 403` 或 `ffmpeg not found` 才能定位。

## 现象 → 原因 → 处理

| 现象关键词 | 原因与处理 |
| --- | --- |
| drm / 加密 / 版权 / 受保护 | 受版权保护内容不支持导出为通用文件，请通过官方渠道观看，不要寻找破解方法。 |
| 会员到期 / 失效 / 看不了了 | 离线内容需定期联网校验授权，会员到期后已缓存内容会失效，续费或联网后恢复。 |
| 找不到缓存文件 / dat / 加密片段 | 缓存为分片加密格式，不能拷出来当普通视频用，这是平台既定设计。 |
| 投屏失败 / 搜不到设备 / 投不了 | 投屏需设备在同一局域网且支持对应协议，检查路由器 AP 隔离与设备协议支持。 |
| 录屏黑屏 / 只有声音 / 录不到画面 | 含 DRM 的内容录屏时会出现黑屏，是版权保护生效，不是录屏工具故障。 |

## 通用故障（各平台都可能遇到）

| 现象 | 处理 |
| --- | --- |
| 403 / 需要登录 / 机器人验证 | 触发反自动化校验：携带登录态或减少请求频率，不要高频重试 |
| 429 / 频繁 / 限流 | 降低请求频率、分批间隔重试 |
| 404 / 失效 / 不存在 | 链接失效或已删除：让对方重新生成分享 |
| 没有声音 / 无音轨 | ffmpeg 未安装或未合并轨：安装后用 `-f "bv*+ba/b"` 合并 |
| 解析失败 / 格式不支持 | 站点接口变动：把工具升级到最新版，而不是换工具 |
| 超时 / 连接失败 | 检查网络可达性后重试 |

## 排查顺序

1. 先确认网络能访问目标平台
2. 再确认目标内容是否属于可下载范围（回到归属判定）
3. 然后确认工具是最新版
4. 最后才怀疑链接本身

九成的「下载失败」卡在第 1 步和第 2 步，而不是工具坏了。
