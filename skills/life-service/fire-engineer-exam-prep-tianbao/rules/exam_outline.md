## 二、六大模块知识地图

### 1. 建筑防火
- 总平面：防火间距、消防车道、登高操作场地
- 耐火等级：构件耐火极限、等级判定（memorize 表格）
- 防火分区：面积表（带条件：自喷、性质、高度）
- 平面布置：设备用房、人员密集场所、儿童活动场所
- 安全疏散：疏散距离、宽度、百人宽度指标、避难层
- 构造：防火墙、防火门窗、管道井、变形缝

### 2. 消防设施（案例主战场）
- 消火栓系统：静压/动压、充实水柱、水泵接合器、稳压
- 自动喷水系统：报警阀组、末端试水、作用面积、喷头选型
- 火灾自动报警系统：探测器选型、联动逻辑、主备电
- 防排烟系统：自然/机械排烟、正压送风、余压
- 应急照明与疏散指示：照度、持续时间
- 灭火器：配置基准、保护距离、报废年限
- 气体灭火、泡沫、干粉：适用场所与禁忌

### 3. 安全管理
- 消防安全重点单位界定标准
- 消防安全责任制：责任人、管理人、部门、岗位
- 制度建设：教育培训、防火检查、巡查、隐患整改
- 应急预案：编制、演练（频次要求）
- 消防档案：分册内容与保存期限

### 4. 法律法规
- 《消防法》：方针、原则、重点单位制度、处罚种类
- 《消防安全责任制实施办法》
- 《高层民用建筑消防安全管理规定》（应急管理部令第5号）
- 部门规章与技术标准体系：GB、GB/T、XF 的关系

### 5. 其他建筑与场所
- 人员密集场所（商场、医院、学校、养老院）
- 地下建筑
- 高层民用建筑
- 石油化工设施
- 古建筑、地铁等特殊场景的特殊要求

### 6. 安全评估与方法
- 评估方法分类与适用
- 性能化防火设计的基本思路
- 风险识别与管控

## 三、高频易混点（考前必看）

| 易混 | 口径 |
|---|---|
| 防火检查 vs 防火巡查 | 巡查频次高、内容简；检查频次低、内容全 |
| 检测 vs 维护保养 | 检测是对状态的年度判定；维保是周期性保养 |
| 甲/乙/丙类液体划分 | 闪点：甲<28℃、乙28~60℃、丙≥60℃（带条件记） |
| 耐火极限 vs 耐火等级 | 极限是构件的；等级是建筑的 |
| 稳压泵 vs 消防水泵 | 稳压保压，水泵灭火供水 |
| 微型消防站 vs 专职消防队 | 建设标准、人员、装备要求不同 |
| 严重/较大/一般火灾等级 | 按死亡人数、重伤人数、直接财产损失划分 |

## 四、案例题高频设问方式

1. "指出……存在的问题" → 定性+条款，逐条列
2. "说明……是否符合规范要求，并说明理由" → 结论+依据
3. "指出……违反了哪些规定" → 法条原文要点
4. "简述……的整改措施" → 可执行动作，拒绝"加强管理"
5. "计算……" → 公式+代入+单位+结论
