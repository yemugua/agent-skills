# 个人所得税年度汇算清缴规则库

> 本规则库按现行常见口径整理。**具体标准以现行税法及税务机关公布口径为准**。不得据此对外承诺补退税结果。

---

## 一、汇算公式

```
综合所得年收入额 = 工资薪金所得
                + 劳务报酬所得 × 80%
                + 稿酬所得 × 56%（即 × 80% 再减按 70% 计算）
                + 特许权使用费所得 × 80%

应纳税所得额 = 综合所得年收入额
             − 60000                   基本减除费用
             − 专项扣除                 三险一金等个人负担部分
             − 专项附加扣除              七项
             − 依法确定的其他扣除        个人养老金、商业健康险等（按各自限额）

应纳税额 = 应纳税所得额 × 适用税率 − 速算扣除数

应退 / 应补 = 应纳税额 − 已预缴税额
   > 0  → 应补税
   < 0  → 应退税（可申请）
```

**应纳税所得额为负时，应纳税额为 0，已预缴税额可申请退还。**

## 三、收入归集口径

| 所得类型 | 计入综合所得的比例 | 常见来源 |
|---|---|---|
| 工资薪金 | 全额 | 任职受雇单位发放的工资、奖金、津贴、补贴 |
| 劳务报酬 | × 80% | 兼职、临时劳务、顾问费 |
| 稿酬 | × 56% | 出版、发表 |
| 特许权使用费 | × 80% | 专利权、著作权等许可使用 |

**不并入综合所得的**：经营所得、利息股息红利所得、财产租赁所得、财产转让所得、偶然所得，按各自规定计算，**以现行税法为准**。

**归集要点**：所有任职受雇单位都要归集，包括已离职的单位。漏一家，补退税结论可能完全相反。

## 四、扣除口径

| 项目 | 口径 |
|---|---|
| 基本减除费用 | 60000 元/年 |
| 专项扣除 | 基本养老保险、基本医疗保险、失业保险等**个人负担部分**，按实际缴费记录 |
| 专项附加扣除 | 婴幼儿照护、子女教育、继续教育、大病医疗、住房贷款利息或住房租金、赡养老人，按各自标准 |
| 其他扣除 | 个人养老金、商业健康险、税延养老保险等，**按各自限额与条件** |

## 五、是否需要办理年度汇算

| 情形 | 判断 |
|---|---|
| 已预缴 > 应纳税额，不申请退税 | 可以不办理 |
| 已预缴 > 应纳税额，申请退税 | **需办理** |
| 已预缴 < 应纳税额，需要补税 | 原则上需办理；符合免于办理条件的除外 |
| 已预缴 = 应纳税额 | 无需办理 |
| 有多处任职受雇、有劳务报酬稿酬等 | 通常需要办理以归集数据 |

### 5.1 免于办理的口径（以税务机关公布为准）

按现行规定，纳税人在一定条件下可免于办理年度汇算，常见情形包括：

- 年度综合所得收入**不超过 12 万元**且需要汇算补税的
- 年度汇算需补税金额**不超过 400 元**的

**判断顺序**：先算补退 → 再看收入与补税额 → 最后看是否申请退税。
**表述要求**：只能写「可能免于办理，以税务机关口径为准」，**不得写成绝对的「无需办理」**。

## 六、办理时间与渠道

| 项目 | 口径 |
|---|---|
| 办理期间 | 一般为**次年 3 月 1 日至 6 月 30 日**，以税务机关公告为准 |
| 办理渠道 | 个人所得税 App、自然人电子税务局网页端、办税服务厅、扣缴义务人集中办理等，以公布渠道为准 |
| 退税 | 需本人确认银行账户信息，退税到账以税务机关处理为准 |
| 补税 | 应在汇算期内完成缴纳，逾期按税法规定处理 |

---

## 七、逾期后果口径

| 情形 | 后果 |
|---|---|
| 逾期未办理补税 | 税务机关责令限期改正；**从滞纳税款之日起按日加收滞纳金**；可并处罚款（按税法规定执行，以税务机关核定为准） |
| 未如实申报 | 纳税人对申报数据真实性、准确性、完整性负责；造成少缴税款的，按规定追缴并加收滞纳金 |
| 编造扣除或隐瞒收入 | 属于违法行为，按规定处理；情节严重的承担相应法律责任 |

**滞纳金按日累积，拖得越久金额越大。** 补税情形应尽早办理。

---

## 八、补退税差异的常见来源

| 差异来源 | 说明 |
|---|---|
| 年中换工作 | 新单位按累计预扣法重新起算，易产生差异 |
| 多处任职受雇 | 各单位分别预扣，基本减除费用重复扣除 |
| 劳务报酬预扣率 | 预扣率与年度适用税率不同 |
| 专项附加扣除年中才填报 | 前期多预扣，汇算时退还 |
| 全年一次性奖金计税方式 | 单独计税与并入综合所得结论不同 |
| 三险一金基数调整 | 缴费基数变化影响专项扣除 |
| 大病医疗 | 只能在年度汇算时扣除 |

## 九、奖金计税方式对比（必做）

```
方案 A：全年一次性奖金单独计税
  应纳税额 = 奖金 × 税率(按奖金÷12 查月度表) − 速算扣除数
  其余综合所得单独按年度表计算

方案 B：并入综合所得
  (综合所得 + 奖金) 统一按年度税率表计算

比较两者合计税额，取低者（以本人申报选择为准）
```

**两种方式都要算。** 收入结构不同，结论可能相反，凭印象选择往往选到税负更高的那个。

## 十、否定词防误伤清单（输出前逐条比对）

| 见到这些情况 | 必须这样判 | 严禁这样写 |
|---|---|---|
| 已预缴 > 应纳税额 | 判为**可申请退税** | 「应补税」 |
| 应纳税所得额 ≤ 0 | 判为**应纳税额为 0**，已预缴可退 | 「没有税也没有退税」 |
| 不征税项目 | 判为**不征税** | 「免税」 |
| 免税项目 | 判为**免税** | 「零税率」 |
| 补税金额不超过 400 元 | 判为**可能免于办理，以税务机关口径为准** | 「绝对无需办理」 |
| 已申报未缴款 | 判为**未完成** | 「已办结」 |
| 暂存 / 待确认 | 判为**未完成申报** | 「已申报成功」 |
| 预缴数据为估算 | 判为**数据未核实** | 用于最终结论 |
| 未申请退税 | 判为**未行使退税权利** | 「不能退税」 |
| 收入仅含主职单位 | 判为**归集不完整** | 「收入已归集完整」 |

## 十一、免责

本规则库为办税实践整理，**不构成税务代理或法律意见**。税率表、扣除口径、免于办理情形、办理时间与逾期处理，**均以现行税法及税务机关公布口径为准**。不得用于虚增扣除、隐瞒收入或任何以少缴税为目的的虚假安排。
