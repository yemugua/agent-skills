# 小鹅通知识店铺视频留存边界：途径、限制与合规边界

## 一、先判定：能不能下

| 归属类别 | 能否下载 | 允许的用途 |
| --- | --- | --- |
| 自有作品 | 可以，优先用原始导出文件 | 任意 |
| 已授权素材 | 可以 | 仅限授权范围内 |
| 作者开放了保存 | 可以，走官方途径 | 个人留存，**不得二次分发** |
| 第三方作品（未授权） | **不建议下载** | 不应用于任何对外场景 |

技术上能不能下载，和法律上能不能用，是两回事。

## 二、途径，按稳定性排序

| 途径 | 操作要点 |
| --- | --- |
| 原文件 | 优先。若是商家或主讲方，向店铺运营索取授权后的原始文件最直接完整。 |
| 官方缓存 | 小鹅通 App 支持已购内容的离线缓存，只能在官方客户端内观看，不能导出成通用文件。 |
| 配套资料单独保存 | 讲义 PDF、课件与资料包通常可单独下载，比视频更便于留存。 |
| 联系商家获取 | 机构培训等场景，向店铺申请授权后的原始文件是最稳妥的方式。 |

## 三、本平台的真实限制

- 已购内容的离线缓存只能在官方客户端内观看，不能导出成通用视频文件。
- 付费专享内容明确不允许下载与分发，本技能不提供任何绕过方式。
- 配套资料往往比视频更值得保存：体积小、便于检索。
- 课程下架或店铺关闭后，已购内容的访问可能受影响，重要资料应提前保存。

## 四、画质与水印

- 课程视频多为录制转码，画质以满足教学为目的；配套资料通常更清晰更便于留存。
- 课程视频含商家与教师署名，学习自用可以，去除署名后分发存在侵权风险。

## 五、合规红线

1. 不得去除作者署名后二次分发
2. 不得将他人作品搬运至自己的账号（含剪辑、配音后发布）
3. 不得下载或传播私密账号、付费内容
4. 受版权或 DRM 保护的内容不支持下载，也不提供任何破解方法
5. 商用前必须取得书面授权
6. 批量高频抓取可能违反平台服务协议，导致账号受限
