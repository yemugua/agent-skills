# Grounding 约束与幻觉防控规则库

> 设计提示词、配置置信阈值、审核答案输出前，先读这份规则。

---

## 一、幻觉四成因与处置

| 成因 | 判定动作 | 处置 | 无效做法 |
|---|---|---|---|
| 检索不到 | 检索结果中无正确答案 | 修检索：切分/top_k/rerank | 改提示词 |
| 检索到但没用上 | 结果中有答案，模型忽略 | 修提示词：强化引用、降温 | 换更大模型 |
| 超出知识边界 | 知识库无此事实 | 加拒答 | 让模型推测 |
| 被诱导/注入 | 用户或文档藏指令 | 输入输出防护 | 提示词声明 |

**分水岭动作：先确认检索结果里有没有正确答案。** 没有 → 修检索；有但没用 → 修提示词。

---

## 二、grounding 六条硬约束

```
1. 只用给定材料：只能依据提供的资料回答
2. 每句结论挂来源：事实性结论后标注 [来源N]
3. 禁止编造：不得编造条款、数据、日期、价格、联系方式
4. 不确定就不确定：资料不足时说明「资料不足以回答」
5. 数值必须原文出现：金额/天数/比例不得换算或推算
6. 区分事实与建议：建议部分需明确标注非资料内容
```

**第 5 条最易被忽略**：「7 天」被推算成「15 天」是最典型的数值幻觉。

**第 4 条须写成授权而非限制**：「回答『未找到相关信息』是被鼓励的正确行为」优于「不要编造」。

---

## 三、引用溯源四要素

| 要素 | 示例 |
|---|---|
| 来源标识 | `[来源3]` |
| 来源标题 | 《XX 售后政策 v3》 |
| 定位信息 | 第 2 章 / 第 4 段 |
| 原文摘录 | 「自签收起 7 日内可申请无理由退货」 |

**「根据相关规定」不是引用，是幻觉的伪装。** 引用必须能定位、能核对。

---

## 四、三级置信判定

| 等级 | 条件 | 输出 |
|---|---|---|
| 可答 | 相似度 ≥ 高阈值 **且** 来源 ≥ 2 **且** 无冲突 **且** 命中要点 | 回答 + 引用 |
| 需人工 | 相似度在灰区间 **或** 单一来源 **或** 存在冲突 | 基于检索的初步答复 + 标注 + 转人工 |
| 拒答 | 相似度 < 低阈值 **或** 结果为空 **或** 超边界 | 明确未收录 + 兜底话术 + 转人工 |

### 阈值标定

| 阈值 | 起始参考 | 说明 |
|---|---|---|
| 高置信下限 | 0.75（余弦） | 必须在评测集上标定 |
| 低置信上限 | 0.50 | 低于一律拒答 |
| 灰区间 | 0.50–0.75 | 转人工 |

**标定方法**：抽 100 个已知答案问题，比较「有答案」与「无答案」两组的相似度分布，取区分切点。不同 embedding 模型分布差异大，不可照搬。

### 三条不可协商规则

1. 结果为空 → 必须拒答，禁止「根据一般情况」
2. 单一来源 → 至少标注需人工
3. 来源冲突 → 必须显式告知冲突

## 五、提示词约束五类

| 手段 | 示例 | 必做 |
|---|---|---|
| 限定来源 | 「只依据以下资料回答」 | ✅ |
| 引用强制 | 「每句结论后标注 [来源N]」 | ✅ |
| 拒答授权 | 「回答『未找到相关信息』是被鼓励的正确行为」 | ✅ |
| 角色约束 | 「你是客服助手，只陈述政策，不做额外承诺」 | 场景适用 |
| 格式约束 | 「输出格式：结论 + 引用」 | 场景适用 |

**降低 temperature 不能单独解决幻觉**，它只影响输出随机性，不影响是否有依据。

---

## 六、事后校验三步

| 步骤 | 检查 | 失败处理 |
|---|---|---|
| 1 | 引用覆盖率：每个事实句是否有引用 | 补充引用要求或人工补 |
| 2 | 引用有效性：来源编号是否真实存在 | **伪造引用，按严重错误处理** |
| 3 | 数值一致性：数值是否在原文出现 | 拒绝该答案 |

---

## 七、幻觉率评估口径

```
幻觉率 = 无依据的事实性结论数 ÷ 全部事实性结论数
```

| 要求 | 说明 |
|---|---|
| 样本量 | ≥ 100 条，覆盖全部高频问题类型 |
| 抽样方式 | 按业务量加权，不只抽高频 |
| 核验人 | 业务专家 |
| 分类统计 | 编造条款 / 数值篡改 / 伪造引用 / 无依据推测 |

**必须分类统计**：总数 3% 若含 2% 数值篡改，对客服场景仍是灾难。

## 八、兜底话术

### 三要素

```
1. 说明状态：未找到相关信息
2. 不做推测：不猜、不说「大概」
3. 给出下一步：转人工入口 / 补充信息引导
```

| ❌ 不合格 | ✅ 合格 |
|---|---|
| 「抱歉，我不知道。」 | 「我没有找到关于该问题的政策记录。为准确答复，已为您转接人工客服。」 |
| 「一般来说应该是 7 天。」 | 「现有资料中没有相关规定，无法给出准确答复。已转人工。」 |
| 「大概需要 15 个工作日吧。」 | 「资料不足以确认具体时长，已为您转接人工核实。」 |

**高危词清单（高风险场景禁用）**：
大概、应该是、一般来说、通常、估计、可能是吧、差不多、我记得。

---

## 九、转人工硬编码触发条件

| 条件 | 说明 |
|---|---|
| 置信为中/低 | 主要触发 |
| 用户表达不满（关键词命中） | 情绪识别 |
| 连续两轮未解决 | 会话计数 |
| 涉及金额争议、退款、投诉 | **无条件** |
| 涉及医疗、法律、金融具体建议 | **无条件** |

**触发条件必须硬编码，不依赖模型自行判断。** 模型在合规敏感问题上「敢答」的损失远大于转人工成本。

## 十、审核清单

**提示词层**
- [ ] 六条硬约束齐备？
- [ ] 含拒答授权？
- [ ] 明确禁止数值换算与推算？

**检索层**
- [ ] 验证过检索结果里有正确答案？
- [ ] 空结果会拒答吗？
- [ ] 相似度阈值在评测集上标定过？

**输出层**
- [ ] 引用四要素齐备且能定位？
- [ ] 做了伪造引用检测？
- [ ] 做了数值一致性校验？
- [ ] 来源冲突会显式告知？

**兜底层**
- [ ] 拒答话术无高危词？
- [ ] 高风险场景无条件转人工？
- [ ] 转人工触发条件已硬编码？

**度量层**
- [ ] 幻觉率按类型分别统计？
- [ ] 抽样按业务量加权、样本 ≥100？
