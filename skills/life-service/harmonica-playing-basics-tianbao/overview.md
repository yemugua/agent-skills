# 口琴吹奏：你会得到什么

口琴是门槛最低的乐器之一，但新手最容易卡在两点：吹和吸搞反、一吹就破音一串含混。这个技能把入门拆成三件可核查的事：**对音孔、核吹吸、排基础顺序**。

## 你会得到什么

- **十孔吹吸对照**：C 调十孔口琴每个孔「吹」和「吸」分别是什么音、什么频率，直接对照，不用靠猜。
- **旋律逐步核查**：把一首歌按「音孔 / 吹或吸 / 音名」逐步填进去，脚本逐点名哪一步孔错了、吹吸反了，并给出正确孔与正确吹吸。
- **单音与气息基础核查**：指出破音、含混、鼓腮等常见错误的根因与改法。
- **八条高频坑**：孔靠猜、吹吸反、破音、含混、鼓腮、回避吸音、一上来快歌、沙哑硬吹。

## 典型用法

- 「口琴怎么吹、每个孔吹吸是什么音」→ 给十孔吹吸对照表
- 「为什么破音、单音怎么练」→ 给单音发声三法与气息要点
- 「小星星用哪些孔吹、吹和吸怎么配合」→ 跑旋律音孔核查
- 「复音和十孔区别、吸音比吹音难」→ 给基础区别与吸音练习提示

## 边界

本技能覆盖 C 调十孔（含复音）口琴的入门吹奏与音孔自查，**不**涉及压音/超吹/舌颤等进阶技巧、**不**指导琴簧与琴格维修（这类找专业琴行）、**不**推荐具体品牌型号的琴与配件、**不**替代专业老师的现场纠正。其他调性口琴音高整体平移，以实际琴为准。所有判定均为通用方法论整理，不构成演奏水平评价或学习进度担保。
