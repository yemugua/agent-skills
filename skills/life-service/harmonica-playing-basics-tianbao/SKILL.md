# 口琴吹奏（harmonica-playing-basics）

口琴看着简单，但新手最容易卡在两件事：一是「吹和吸搞反」，二是「一吹就破音、一串音含混」。根子都在基础——音孔对照没记熟、单音没练稳。

这个技能做三件事：**对音孔 → 核吹吸 → 排基础顺序**。

---

| 核对旋律每一步的音孔与吹吸是否一致 | ❌ 讲解具体品牌琴的选购与配置 |

| 说明复音与十孔口琴的基础区别 | ❌ 指导压音、超吹等进阶技巧 |

**遇到以下情况，按各自渠道处理：**

## 二、完整工作流

### 第一步：记熟十孔吹吸对照

C 调十孔口琴，每个孔「吹」和「吸」是两个不同的音。先背下对照表（见 `rules/口琴吹奏基础与音孔对照.md`）。**不要靠猜**——猜孔是破音和走调的根源。

### 第二步：先练单音，再练旋律

单音没稳就吹整首歌，出来的一定是一串含混的和音。用「小口含一孔」或「舌堵法」先把单个音吹干净、吹稳。

### 第三步：填 JSON 跑音孔核查

把要吹的旋律按「音孔 / 吹或吸 / 音名」逐步填进去，脚本一次性告诉你哪一步孔或吹吸弄错了、正确该用哪个孔、吹还是吸。

### 第四步：按基础顺序推进

持琴姿势 → 单音发声 → 单孔吹吸切换 → 简单旋律（如小星星）→ 气息与表情。不要一上来就追求快歌。

### 第五步：每天短时、慢起步

入门每天 **10 到 20 分钟**，从最慢的速度开始，确保每个音孔都找准。

## 三、核心规则（生成结论前先读规则文件）

**必须先读 `rules/口琴吹奏基础与音孔对照.md`，不要凭印象写。** 规则文件里有：

- 十孔吹吸音名对照与频率（吹/吸各 10 个音）
- 单音发声三法（小口含孔法、舌堵法、U 形含法）与唇形/舌位要点
- 呼吸配合原则：吹吸交替用腹部气息，不鼓腮
- 八条高频坑

**判定顺序不能颠倒**：先看真实缺陷（孔错、吹吸反），再看单音/气息基础是否到位，最后才看信息是否完整。

## 四、十孔吹吸对照（节选）

| 孔 | 吹（blow） | 吸（draw） |
|---|---|---|
| 1 | C4 | D4 |
| 2 | E4 | G4 |
| 3 | G4 | B4 |
| 4 | C5 | D5 |
| 5 | E5 | F5 |
| 6 | G5 | A5 |
| 7 | C6 | B5 |

**反例**：把 1 孔当成「吹出 D」——1 孔吹是 C、吸才是 D。脚本会逐点名「1 孔吹应为 C4，实为 D4」。

## 五、脚本用法

```bash
python scripts/harmonica_play_check.py --file melody.json --out 核查.md
python scripts/harmonica_play_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`sequence` 为旋律步骤列表，每步含 `hole` / `breath` / `note` |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检（≥8 条断言，含 BOM 两条路径与反例） |

输入 JSON 示例：

```json
{
  "sequence": [
    {"hole": 1, "breath": "blow", "note": "C4"},
    {"hole": 1, "breath": "blow", "note": "C4"},
    {"hole": 6, "breath": "blow", "note": "G5"}
  ]
}
```

脚本输出：逐音孔判定、错误步骤表（含正确孔与吹吸）、单音/气息基础核查、整改顺序、人工确认清单。

## 七、最常见的坑

**坑一：孔和吹吸靠猜。**
错误做法：凭感觉吹，觉得差不多就行。正确做法：每个孔吹吸是两个音，先背对照表再上手，猜是走调根源。

**坑二：吹吸反了。**
错误做法：把 1 孔吹当成 D、吸当成 C。正确做法：1 孔吹 C、吸 D；记不住就写张对照贴琴套上。

**坑三：一吹就破音。**
错误做法：嘴唇包太松、含太多孔。正确做法：小口只含一个孔（或舌堵其余），唇形放松贴紧琴格。

**坑四：一串音含混。**
错误做法：单音没稳就吹整首歌。正确做法：先把每个单音吹干净，再连成旋律。

**坑五：鼓腮吹气。**
错误做法：靠脸颊鼓气逼出声音。正确做法：用腹部（丹田）气息支撑，脸颊放松，吹吸都省力且稳。

**坑六：吸音比吹音难就回避。**
错误做法：只练吹音，遇到吸音旋律就卡。正确做法：吸音靠舌尖轻抵下齿、气流更集中；单独慢练吸音列（1孔D、3孔B、5孔F、6孔A）。

**坑七：一上来就快歌。**
错误做法：第一天练快旋律。正确做法：从最慢速度、最少的音开始（小星星只有 C D E F G A），找准再加速。

**坑八：琴沙哑还硬吹。**
错误做法：簧片变形漏气继续练，越吹越伤琴。正确做法：发音异常找专业琴行检修，不自行撬簧片。
