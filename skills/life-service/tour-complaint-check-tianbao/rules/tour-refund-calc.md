# 二、退款核算：可退多少、扣得合不合理

## 1. 三种退款场景分开算

| 场景 | 核算口径 |
|---|---|
| **行程未完成时的退未发生的费用** | 合同总价 − 已实际发生且不可退还的费用 = 可退 |
| **旅行社违约的赔偿** | 未发生项目的退款 + 实际损失（住宿差价、交通改签、临时住宿等） |
| **不可抗力取消** | 已支付且不可退还费用扣除后退还余款；额外食宿费游客担、返程费双方分担 |

**核心原则：没享受的服务必须退；已经花掉且退不回来的，才能扣。**

## 2. 退团扣费阶梯（合同示范文本常见口径）

大多数地方旅游合同示范文本按"距出发时间"设阶梯，**越临近出发扣得越多**（比例供参考，**以你手上的合同与当地示范文本为准**）：

| 距离出发 | 常见扣费比例 |
|---|---|
| 出发前 15 日以上（或 30 日以上，各地示范文本不同） | 扣旅游费用 5% 以内（或仅扣已实际发生的费用） |
| 出发前 7~15 日 | 扣约 10%~20% |
| 出发前 4~7 日 | 扣约 20%~40% |
| 出发前 1~3 日 | 扣约 40%~60% |
| 出发当日 / 未通知就不到 | 扣约 60%~80%，已发生费用另计 |

**怎么判断合不合理**：

1. 先看**合同怎么写**——示范文本的比例只在合同援引或当地文旅部门推荐时才具参考性，**合同约定优先**；
2. 再算**旅行社实际损失**——旅行社已付给地接的机票/酒店/门票/车款能不能退、退多少（要它出示采购凭证与退款凭证）；
3. **扣费不得超过实际损失 + 合理违约金**，明显畸高的可主张过高而请求调减；
4. **因旅行社原因**（如它自己要改团、被大面积投诉、熔断不退团）**不得扣游客的钱**，应全额退或改期无损失；
5. **因不可抗力/公共卫生事件**取消的，一般应**全款退**（或按当地主管部门口径退），不适用上述扣费阶梯。

> 报告里给的是**可退区间**，不是单一数字——因为合同版本、是否已出票、是否已产生订金各不相同。

## 3. 购物退货：30 日规则（最值钱的一条）

- 旅行社以不合理低价组织旅游、并通过安排购物获取回扣等不正当利益的，旅游者在**行程结束后 30 日内**，可以要求旅行社**办理退货并先行垫付退货货款**；
- 操作流程：**保留购物凭证 + 商品存在问题的证据（照片/视频/鉴定）+ 向旅行社书面提出退货要求** → 旅行社应在合理期限内办理 → 旅行社不办的，向文旅主管部门/市场监管投诉；
- 实物证据关键：**购物小票/发票要写清商品名称与价格**，不要只收一张"礼品卡"；**商品问题**最好当场拍开箱视频；
- 已离团、已回国的，**不要签"自愿购买、概不退货"的确认单**；
- 线上一键退：部分 OTA 对"虚假宣传购物店"有先行赔付通道，同时走不冲突。

## 4. 常用金额口径

| 项目 | 怎么算 |
|---|---|
| 未发生的景点/项目退款 | 该项在合同中的列明价格（没有列明的按市场同类价格合理折算） |
| 住宿降级差价 | 承诺星级/房型的协议价 − 实际住宿实际价（有发票/订单为证） |
| 餐标缩水 | 约定标准 − 实际标准 × 实际餐数 |
| 临时改签/额外住宿 | 实际票据金额，属违约损失可一并主张 |
| 惩罚性赔偿 | 旅游费用（总额）× 1~3 倍，仅在符合法定情形时主张 |

- 所有金额统一用 `¥`，数值输出去掉 `.0`；
- **举证不能的金额不写死**，标注"需凭票据核定"。

## 5. 算不出来的部分怎么处理

- 合同总价填了、各项单价没填 → 给**定性结论 + 待补正清单**，不硬造数字；
- 只有"退款金额"一个总数、没有明细 → 提示要求旅行社出具**扣费明细与凭证**，这是它举证的责任；
- 涉及航空/铁路/酒店的**第三方不可退规则**，以承运人或酒店的政策为准，旅行社应协助索赔而非把损失转嫁给游客。

## 6. 别只盯"退多少钱"

- 违约金/赔偿金与退款可以**并行主张**，不是二选一；
- 人身损害赔偿（受伤、滞留导致的额外支出）另算，不与旅游费用混同；
- 团体投诉（同一团多人受损）比单人投诉的处置力度大得多，可串联立证。
