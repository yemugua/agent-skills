# 一、纠纷类型定性与责任归属

## 1. 先分三类：旅行社违约 / 不可抗力 / 平台与第三方

| 类型 | 典型表现 | 承担责任方式 |
|---|---|---|
| **旅行社违约** | 擅自变更行程、减少/取消景点、压缩游览时间、降低住宿餐饮标准、导游服务与承诺不符、拒载返程 | 继续履行 + 补救 + 赔偿；造成人身损害或滞留等严重后果的，可主张**旅游费用一倍以上三倍以下**的赔偿金 |
| **不可抗力** | 地震、洪水、台风、疫情等不能预见、不能避免且不能克服的客观情况；含政府管制、交通中断 | 旅行社**扣除已支付且不可退还的费用后退还余款**；**增加的食宿费由旅游者承担**，**返程费由双方分担** |
| **平台/第三方** | OTA 订单与实际不符、商家拒住、酒店单方面毁约、航班高铁变动、景区临时闭园 | 平台先行赔付/协调；涉及经营者违法的走 12315 市场监管 |

**判定要点**：旅行社本身原因造成的，走违约路径（可主张惩罚性赔偿）；确实属于不能克服的客观情况的，走不可抗力路径（只退余款、损失共担）。**谁主张不可抗力，谁举证。**

## 2. 《旅游法》要点（写名称与内容，条号不确定处写"相关规定"）

- **不合理低价与购物回扣**：旅行社不得以不合理的低价组织旅游活动、诱骗旅游者，并通过安排购物或者另行付费项目获取回扣等不正当利益。违反的，**旅游者在行程结束后 30 日内，可要求旅行社办理退货并先行垫付退货货款**（这是购物店假货最有效的抓手）。
- **违约责任的一般形式**：旅行社不履行包价旅游合同义务或者履行不符合约定的，应当**继续履行、采取补救措施或者赔偿损失**；造成旅游者人身损害、财产损失的，应当依法赔偿。**旅行社不履行或者不完全履行**的，还应在承担赔偿责任后向履行义务一方追偿。
- **惩罚性赔偿**：旅行社有下列情形之一的，旅游者还可以要求旅行社**支付旅游费用一倍以上三倍以下的赔偿金**；（一）擅自改变行程、遗漏旅游景点、减少旅游服务项目、降低服务标准的；（二）未为旅游者提供安全保障服务的；（三）强行推销商品、擅自安排另行付费项目的。
- **安全保障义务**：旅行社应当为旅游者提供符合保障人身、财产安全需要的服务和条件；对可能危及人身财产安全的事项，应作出**明示警示**，并采取必要的**防范措施**（如提示不适合人群参加的项目）。
- **不可抗力**：因不可抗力或者**旅行社、履行辅助人已尽合理注意义务仍不能避免的事件**（如交通工具延误、景区临时闭园）导致行程不能实施的，旅行社**应当及时报道、妥善安置**；合同不能履行的，旅行社**扣除已支付且不可退还的费用后退还余款**，**合同变更前**应经旅游者同意。
- **包价旅游合同**：旅行社应当向旅游者提供**行程单**（载明服务项目、标准、时间、地点等），应当**事先说明**另行付费项目与自费项目，不得强迫或者变相强迫。
- **个人信息与保险**：旅行社应当提示旅游者投保**旅游意外保险**；组团社委托地接社履行的，应签订委托合同并**向旅游者告知**。
- **投诉与时效**：向旅游投诉处理机构提出的投诉，一般应在**旅游合同结束之日起 90 日内**提出（以现行旅游投诉处理办法为准）；旅游投诉处理机构应当及时受理、处理，一般应在 **60 日内办结**并可延长。

> 条文号不确定的一律写成"《旅游法》相关规定"，**不编造条号**。

## 3. 八类高频纠纷与对应主张

| 纠纷 | 关键证据 | 可主张 |
|---|---|---|
| 擅自变更行程/减少景点 | 原行程单、变更通知、实际游览记录 | 退未发生的费用 + 一倍以上三倍以下赔偿（造成严重后果时） |
| 强迫或变相强迫购物 | 购物店进店时间、全程无自由时间、导游原话录音、购物小票 | 退货退款（30 日内）；拒绝退的可向文旅执法投诉 |
| 另行付费未事先说明 | 宣传页/合同/行程单、现场收费凭证 | 拒绝支付 + 退已收费用 |
| 降低服务标准 | 住宿照片、餐标照片、实际房型与承诺对比 | 退差价 + 赔偿 |
| 导游与承诺不符 | 宣传页承诺、录音、同行证言 | 补救/赔偿 |
| 退团扣费 | 退团通知时间、合同扣费条款、已发生费用凭证 | 核扣比例的合理性 |
| 不可抗力取消 | 官方预警/管制公告、取消通知 | 退余款、食宿自担、返程分担 |
| 平台订单与实际不符 | OTA 订单页截图、到店照片、前台记录 | 平台先行赔付、差价退还 |

## 4. 责任主体别找错

- **组团社**（你签合同的）：主要责任主体，向它主张；
- **地接社 / 履行辅助人**（当地地接、酒店、车队、景区）：组团社对其履行辅助人的行为**承担责任**（不是"地接自己负责"）；
- **OTA 平台**：作为销售方承担合同责任；同时向商家追偿。平台"第三方入驻、我只做信息中介"的抗辩，不能当然免除其对消费者的先行赔付义务；
- **景区 / 航空公司 / 铁路**：属于外部履行辅助人，各自按运输合同或景区规定处理，一般不由旅行社赔，但旅行社应协助索赔。

## 5. 别做的事

- 不要在现场签署"自愿放弃索赔/概不追究"的**免责协议**（签了也不一定有效，但会大幅提高举证难度，务必拍照留存并注明受胁迫）；
- 不要在群里和导游/客服**只吵架不留痕**——要文字确认事实（"今天原计划 A 景区没去，改成了 B 购物店，travel 时间少了 3 小时"）；
- 不要先撤回 OTA 的退款申请再重复提交，会被判为重复投诉；
- 不要把"所谓投诉"只发在朋友圈，旅游局不受理朋友圈截图作为主证据，但可作为辅助。
