# 三、证据清单、渠道阶梯、时效与管辖

## 1. 证据清单（缺一张就少一分胜算）

| 证据 | 要什么形式 | 证明什么 |
|---|---|---|
| **旅游合同 / 电子合同** | 全文截图（含附件行程单），不要只截首屏 | 约定内容，最核心 |
| **行程单** | 逐日行程、景点、餐标、住宿标准、时间安排 | 与实行的对比依据 |
| **付款凭证** | 订单页、支付流水、发票/开票信息 | 金额、付款时间、相对方 |
| **宣传页 / 广告** | 网页快照、海报、销售聊天记录里的承诺 | 口头/书面承诺，起诉时可主张虚假宣传 |
| **现场照片视频** | 住宿房间、餐食、车况、景点门口未到达、购物店门头 | 实际服务标准 |
| **沟通记录** | 微信群、短信、通话录音（要能听清对方是谁） | 变更、强迫、拒绝退费的过程 |
| **门票 / 住宿票据** | 发票、电子发票、房卡记录、订单确认单 | 已发生费用与标准 |
| **购物凭证** | 小票、发票、刷卡/扫码记录、商品照片与鉴定 | 30 日退货的前提 |
| **同行证言** | 同团游客书面证言 + 联系方式（最好多人） | 辅助证明 |
| **官方公告** | 气象、交通、政府管制、景区闭园公告 | 不可抗力/影响范围 |

**取证纪律**：
- 截图要**含时间戳与对方账号**（微信聊天截全、显示微信号与姓名）；
- 录音要**表明身份与时间**，别偷拍隐私部位，公共场合对话可录；
- **先拍照后签字**，任何"免责单""放弃索赔书"都要拍照留存；
- 旅游途中就做**每日小结发到群里**（"今日原定 A 景区改为 B 购物店"），这是事后最有力的自证；
- 回到出发地后 **7 日内**整理一套完整材料包（合同、行程、票据、照片、沟通记录），越拖越难补。

## 2. 渠道阶梯（按顺序，别跳步，也别只走一步）

| 顺位 | 找谁 | 做什么 |
|---|---|---|
| 第 1 步 | **旅行社（组团社）书面交涉** | 提交书面投诉（写明事实、依据、诉求、期限 7~15 日），索要书面回复；同步给 OTA 客服 |
| 第 2 步 | **OTA 平台介入 / 先行赔付** | 走平台的"退款/赔付"通道；平台对商家有管理能力，通常会先协调；有先行赔付承诺的按承诺 |
| 第 3 步 | **12345 政务服务热线**（原 12301 旅游服务热线已并入政务热线） | 最有效的行政入口，会派单到属地文旅部门；投诉工单过程留痕 |
| 第 4 步 | **文旅主管部门 / 文化市场综合执法** | 查证旅行社违规（不合理低价、强迫购物、擅自变更行程）；可现场调取旅行社的采购与结算记录 |
| 第 5 步 | **全国旅游监管服务平台**（各地文旅局入口） | 正式的旅游投诉受理渠道，可查处理进度 |
| 第 6 步 | **12315 市场监管（拨打 12315 或通过全国 12315 平台）** | 涉购物店假货、虚假宣传、价格欺诈的走这里 |
| 第 7 步 | **仲裁 / 诉讼** | 合同有有效仲裁条款的申请仲裁；否则向被告住所地或合同履行地法院起诉（诉讼时效 3 年） |

**实操提示**：
- **12345 与文旅投诉要写清三件事**：哪个团（团号/合同号）、发生了什么（时间地点人物）、你要什么（退多少钱/赔多少/改什么）；
- 涉及**强迫购物、虚假宣传、低价团诱导**的，尽量多人共同投诉，文旅部门处置力度明显更大；
- 旅行社跑路/失联的，仍可走 12345 与文旅部门查询其**保证金**缴纳情况（旅行社质量保证金可用于赔偿，具体以当地文旅部门口径为准）；
- 行程在外地时，**先打 12345 与当地文旅执法**，别只在国内平台反复申诉。

## 3. 时效（最容易踩的坑）

| 事项 | 期限 |
|---|---|
| 旅游投诉提出 | 一般应在**旅游合同结束之日起 90 日内**提出（以现行旅游投诉处理办法为准） |
| 旅游投诉办结 | 一般应在 **60 日内办结**，情况复杂可延长（以受理机构告知为准） |
| 民事诉讼时效 | **3 年**，自知道或应当知道权利受损及义务人之日起算 |
| 购物退货主张 | **行程结束后 30 日内**提出 |
| 行政救济（不服处理决定） | 一般 60 日内申请行政复议、6 个月内提起行政诉讼 |

**现在就查两个日期**：① 行程/合同结束日（算投诉 90 日还剩几天）；② 是否还有未主张的购物退货（30 日）。

## 4. 管辖与文书要点

- **投诉文书**：投诉人信息 + 被投诉主体（全称、统一社会信用代码最好有）+ 事实与时间线 + 证据清单 + 明确诉求（退 ¥xxx / 赔偿 ¥xxx / 恢复条款）+ 要求的答复期限；
- **起诉状**：被告为旅行社（组团社），可在被告住所地或合同履行地（旅游目的地/出发地各有实践）法院起诉，具体按民诉法关于合同纠纷管辖的规定确定；
- **仲裁前置**：合同里写了"提交××仲裁委员会仲裁"的，先走仲裁，不能直接起诉。

> 本文件依通用规则整理；各地投诉受理细则、质量保证金赔付条件、示范文本扣费比例**以当地文旅主管部门与市场监管部门口径为准**（查询入口：全国旅游监管服务平台、当地文旅局官网/公众号、12345）。

## 5. 纪律

- 不预测行政查处结果与诉讼胜负；
- 不代写最终法律文书，只给要点；
- **未填的一律不算通过**，只按已填内容判断。
