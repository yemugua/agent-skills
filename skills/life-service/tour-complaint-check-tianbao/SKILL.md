# 旅游投诉维权与退款核算

跟团游出了事，最难受的不是玩得差，而是**不知道该找谁、能退多少钱、过没过时效**。

## 什么时候用

- 旅行社擅自改行程、砍掉景点、压缩游览时间
- 被强迫或变相强迫购物、另行付费项目（自费晚会、缆车、演出）
- 承诺的四星级住成了三星、餐标从 30 提到 10、说好的自由活动时间没了
- 退团被扣一大笔钱，想弄清扣得合不合理
- 疫情/极端天气/政策管制导致团取消，退多少、损失谁担
- OTA 下单，到店发现订单与宣传完全不符
- 购物店买到假货，想退货但旅行社说"已经离店没法退"
- 导游态度恶劣、甩团、拒载返程

## 怎么做

**第 1 步**：复制 `templates/旅游投诉信息采集表.md` 填写，把**合同、行程单、付款凭证、宣传页**都对照着填。

**第 2 步**：跑脚本

```bash
python scripts/tour_check.py 采集表.md --base 2026-10-05 --out 核查报告.md
```

**第 3 步**：按第九段"待办补正动作"执行；第八段是渠道阶梯与时效。

## 三句话定性的核心规则

1. **旅行社违约 vs 不可抗力**，结论完全相反：旅行社违约的，要继续履行、补救并**赔偿损失**，造成严重后果的还可主张**旅游费用一倍以上三倍以下**的赔偿金；因不可抗力或已尽合理注意仍不能避免的事件致行程受影响的，旅行社**扣除已支付且不可退还的费用后退还余款**，增加的食宿费由旅游者承担、返程费双方分担。
2. **"不合理低价 + 购物回扣"是重罚区**：以不合理低价组织旅游、诱骗旅游者并通过安排购物或另行付费项目获取回扣等不正当利益的，旅游者在**行程结束后 30 日内**可要求旅行社办理退货并**先行垫付退货货款**——这条很多人不知道，也是购物店假货最有效的维权路径。
3. **退团扣费没有唯一数**：按合同示范文本的常见阶梯（越临近出发扣费比例越高）给的是**可退区间**，不是某个数；无约定时按旅行社已实际支付且不可退还的费用举证。

## 输入 / 输出

| | 内容 |
|---|---|
| 输入 | 采集表 Markdown（合同/行程/费用/违约事实/购物/退团/不可抗力/已交涉/证据） |
| 输出 | 九段报告：结论摘要 / 纠纷定性与法条依据 / 违约项逐条核查 / 退团扣费与可退区间 / 购物与退货 / 不可抗力与退费 / 证据清单 / 渠道阶梯与时限 / 待办补正 |
| 退出码 | 0 正常；2 关键信息缺失（给提示串，不崩） |

## 边界与纪律

- 依《旅游法》《民法典》**通用规则**整理，**不替代律师意见**
- 不预测行政处理与诉讼结果；**以文旅主管部门认定、仲裁机构裁决与司法机关裁判为准**
- 各地旅游投诉处理细则、退团扣费阶梯、先行垫付的具体操作有差异，**以当地文旅主管部门与市场监管口径为准**（查询：全国旅游监管服务平台、当地文旅局官网、12345）
- **未填的一律不算通过**，只按填了的判断
