# 概览：旅游投诉维权与退款核算

## 解决什么问题

旅游纠纷里最消耗人的不是"没玩好"，而是这四件事：

1. **找不到主张依据**——说旅行社违约，到底违约在哪一条、能要什么；说不可抗力，又能退多少；两者结论完全相反，混在一起最容易不了了之；
2. **算不清退款**——退团被扣 60% 还是 80% 到底合不合理，没人给个区间；OTA 与旅行社互相踢皮球，最后只能认亏；
3. **证据没留全**——行程单是口头承诺、宣传页没截图、购物小票没要发票，到投诉时"我说有、他说没有"；
4. **过了时效**——旅游投诉一般应在**合同结束后 90 日内**提出，拖到一年后再去，连受理都可能被卡。

## 输入 → 输出

```
采集表（合同/行程/费用/违约事实/购物/退团/不可抗力/已交涉/证据）
        │
        ▼
  ┌──────────────────┐
  │ 纠纷定性         │  旅行社违约 vs 不可抗力 vs 平台责任
  ├──────────────────┤
  │ 违约项逐条核查   │  改行程/砍景点/强迫购物/降标准/退团扣费
  ├──────────────────┤
  │ 退款核算         │  可退区间（不是单一数）
  ├──────────────────┤
  │ 购物与退货       │  30 日内要求退货并先行垫付
  ├──────────────────┤
  │ 证据清单         │  合同/行程单/宣传页/票据/沟通记录
  ├──────────────────┤
  │ 渠道与时效       │  旅行社→OTA→12345→文旅执法→12315→仲裁/诉讼
  └──────────────────┘
```

## 和其他工具的区别

- 常见攻略讲"怎么玩"，法律科普讲"法条是什么"；本技能做的是**个案判定**：你这趟团、这份合同、这些金额，该向谁主张、大概能退多少区间、现在还来不来得及；
- 给**可退区间**而不是一句"可以全额退"或"肯定退不回来"；
- 把所有地域差异项（投诉受理细则、扣费阶梯、先行垫付操作）全部转成**查询入口 + 兜底口径**，不编造地方数。

## 不做的事

- 不内置任何城市的投诉受理细则与具体扣费比例
- 不预测行政查处与诉讼结果
- 不代写投诉文书终稿（只给要点与话术）
- 不评估行程安全风险与旅行建议

## 适用人群

跟团游/自由行打包产品消费者、OTA 平台下单后被改单的人、购物店买到假货的游客、退团被高额扣费的人、不可抗力取消的团客、导游服务态度纠纷当事人、旅行社与门店客服。
