# 旅游投诉信息采集表

> 把**合同、行程单、付款凭证、宣传页**摊开对照着填。抄不出来就留空——**留空 = 未填，脚本按"待补正"处理，不算通过。**

## 一、基本信息

| 字段 | 填什么 |
|---|---|
| 投诉人姓名* | 与证件一致 |
| 联系方式 | 手机号 / 邮箱 |
| 被投诉主体 | 组团社全称（合同签章处） |
| 地接社/履行辅助人 | 合同或行程单上写的是哪一家 |
| 下单平台（OTA） | 例如：某程 / 某团 / 门店 |
| 团号 / 合同号* | 合同或订单页上的编号 |
| 旅游形式 | 跟团游 / 半自由行 / 包价定制 / 自由行打包产品 |
| 出发日期* | YYYY-MM-DD |
| 行程结束日期* | YYYY-MM-DD（算投诉 90 日从这天起） |
| 合同总价（元）* | 例如：5680 |

## 二、行程与约定

| 字段 | 填什么 |
|---|---|
| 合同约定的住宿标准 | 例如：四星/准四、双人间、某酒店名 |
| 实际住宿情况 | 例如：三星、老旧、无窗、低于承诺 |
| 合同约定餐标 | 例如：30 元/人/餐 |
| 实际餐标 | 例如：10 元/人/餐、十人一桌没菜 |
| 原定景点与游览时间 | 逐条列（第几天：景点 + 时长） |
| 实际游览情况 | 逐条对比（改成了什么、少了几小时） |
| 是否有另行付费项目 | 无 / 有（合同中是否事先说明） |
| 另行付费项目 | 例如：自费晚会、缆车、游船 |
| 是否有强迫或变相强迫购物 | 无 / 有 |
| 购物店名称与进店时长 | 例如：某某珠宝店，停留 90 分钟 |
| 宣传页/销售承诺 | 例如："四星标准""纯玩无购物""含 5 顿特色餐" |

## 三、费用与退款

| 字段 | 填什么 |
|---|---|
| 已支付总额（元） | 例如：5680 |
| 旅行社已退金额（元） | 例如：0 / 1200 |
| 已扣款项名目 | 例如：手续费、机票损失、房费损失 |
| 是否因个人原因退团 | 是 / 否 |
| 退团/取消通知日期 | YYYY-MM-DD |
| 距出发还有几天 | 数字（未出发填负数的绝对值） |
| 合同中的扣费条款 | 原话摘录 |
| 是否已发生机票/酒店等不可退费用 | 有 / 无 / 不清楚 |
| 购物消费金额（元） | 例如：3800 |
| 购物商品问题 | 假货 / 以次充好 / 价格虚高 / 无问题 |
| 是否已申请退货 | 未申请 / 已向旅行社提出 / 已拒绝 |

## 四、交涉与渠道

| 字段 | 填什么 |
|---|---|
| 是否已向旅行社书面投诉 | 未 / 已（提交日期 / 方式） |
| 旅行社回复情况 | 无回复 / 口头推脱 / 书面拒绝（摘录） |
| 是否向平台（OTA）申诉 | 未 / 已 / 平台已介入 / 平台已赔付 |
| 是否已拨打 12345 | 未 / 已（工单号） |
| 是否已向文旅主管部门投诉 | 未 / 已（受理编号） |
| 是否已向 12315 投诉 | 未 / 已 |
| 是否已签署免责/放弃索赔协议 | 无 / 签了（是否受胁迫、是否拍照） |
| 处理诉求（你想拿到什么） | 例如：退未游景点费 ¥1200 + 赔偿 ¥4000 |
