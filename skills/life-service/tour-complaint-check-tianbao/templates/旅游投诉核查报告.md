## 二、纠纷定性与法条依据

| 定性 | 是否成立 | 依据 |
|---|---|---|
| 旅行社违约（擅自变更/减少/降标） |  | 《旅游法》相关规定：应继续履行、补救、赔偿；造成严重后果的可主张旅游费用一倍以上三倍以下赔偿 |
| 强迫或变相强迫购物、另行付费未事先说明 |  | 《旅游法》相关规定：不得强迫或变相强迫，违反的可主张退货并先行垫付 |
| 不合理低价 + 购物回扣 |  | 《旅游法》相关规定：30 日内可要求旅行社办理退货并先行垫付退货货款 |
| 不可抗力/已尽合理注意仍不能避免 |  | 扣除已支付且不可退还费用后退还余款；额外食宿费游客承担、返程费双方分担 |
