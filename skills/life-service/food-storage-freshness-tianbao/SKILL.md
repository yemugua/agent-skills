# 食材储存保鲜与期限核查（food-storage-freshness）

判断食材还能不能吃，**不能只靠闻一闻看一眼**。闻不出问题不代表安全——沙门氏菌、李斯特菌在食物里的代谢产物常常没有任何气味和外观变化。

这个技能做四件事：**对品类 → 算期限 → 查硬指标 → 定处置**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 按品类给出冷藏与冷冻保存期参考口径 | ❌ 做微生物、毒素、农残的检测判定 |
| 按实际存放天数核算期限进度与状态 | ❌ 给出「这个肯定能吃」的担保结论 |
| 列出变质三条硬指标与感官不可靠场景 | ❌ 替代食品检验机构出具检测结论 |
| 给出开封后处理与不可冷冻清单 | ❌ 判定餐饮门店的食品安全合规状态 |

**遇到以下情况，直接按最坏情况处理，不要给「可能没事」的结论：**

- 存放时长已超过口径上限，且**无法确认购买或制作的确切日期**
- 已出现**异味、质地变化、外观霉变中任一条** —— 三条中命中一条即按变质处理
- 罐头类**鼓包、胀气、漏气、开启时喷溅**
- 冷冻室**曾长时间断电或温度失控**，且期间存放了生鲜食品
- **老人、婴幼儿、孕妇、免疫力低下者、正在服药或化疗者**要吃的食物 —— 这类人群的判断门槛应更严，感官可疑即弃用
- 用户描述已经出现**腹泻、呕吐、发热**并怀疑是某次进食 —— 属健康问题，转医疗建议，本技能不诊断

> **保存期口径说明**：下表天数是家庭冷藏（不高于 4℃）、冷冻（不高于 −18℃）条件下的**参考上限**，用于判断「是否明显超期」。包装上的生产日期、保质期、开封后期限**优先于本表**。数值以现行食品安全标准与产品标签为准，本技能不检测、也不替代检测。

## 二、完整工作流

```
第 1 步  过安全红线：是否已出现硬指标异常、是否高风险人群食用
第 2 步  确认品类与状态：生鲜/熟食/开封/加工后，完整还是已切
第 3 步  读规则文件 rules/保存期对照与变质判定.md（20 类对照表 + 三条硬指标）
第 4 步  确认存放条件：冷藏 / 冷冻 / 常温，条件是否达标
第 5 步  确认存放天数：购买日、开封日、制作日，逐项问清，不要猜
第 6 步  跑脚本核算期限进度与状态
第 7 步  感官三项核对：异味、质地、外观，逐项过
第 8 步  给处置结论：立即食用 / 优先食用 / 冷冻延长 / 弃用
第 9 步  给储存改进建议（这条最容易产生长期价值）
```

**第 5 步最容易被跳过**：不知道放了几天，就只能靠感觉判断，而感觉正是本技能要纠正的东西。**日期不确定时，按「已超期」从宽处理，不要往乐观方向估。**

## 三、感官不可靠——本技能最重要的一条

以下情形**闻、看、尝都不能作为安全依据**：

| 场景 | 为什么 |
|---|---|
| 沙门氏菌污染的禽肉与蛋 | 蛋白水解后无明显异味，外观与正常肉完全一致 |
| 李斯特菌污染的冷藏即食食品 | 可在冷藏温度下缓慢增殖，感官正常 |
| 弯曲菌污染的禽肉 | 加热可杀灭，但生食阶段无任何感官提示 |
| 蜡样芽孢杆菌污染的米饭剩菜 | 部分毒素**耐热**，复热也消除不了 |
| 组胺降解的海鲜 | 加热不破坏，可引起不适，感官正常 |
| 冻藏期内解冻复温的生鲜 | 微生物已大量繁殖，之后回冻不再抑制 |

**结论：感官正常 ≠ 安全。** 感官只能用来**排除**明显变质的，不能用来**确认**安全。要确认安全，靠的是温度与时间，而不是鼻子。

## 四、保存期对照表（家庭冷藏 / 冷冻）

| 品类 | 冷藏参考上限 | 冷冻参考上限 | 保存要点 |
|---|---|---|---|
| 叶菜类（青菜、菠菜、生菜） | 3 天 | **不可冷冻** | 洗净后吸水烂根，擦干或垫吸水纸，袋内留缝隙 |
| 切开的菜（切丝切段） | 2 天 | 30 天 | 切面暴露，氧化与污染加快 |
| 菌菇类 | 3 天 | 30 天 | 食用前才清洗，勿长时间密封塑料膜 |
| 根茎类（土豆、洋葱、红薯） | 14 天 | 120 天 | 阴凉通风亦可存，冷藏延缓发芽 |
| 结球类与瓜类（白菜、冬瓜、南瓜） | 20 天 | 60 天 | 完整状态耐存，切开按叶菜口径 |
| 畜肉类（生） | 3 天 | 90 天 | 冷藏两天更稳，分装到用完为止 |
| 禽肉类（生） | 2 天 | 90 天 | 冷藏口径比畜肉更短，与即食食品分格 |
| 鱼类海鲜（生） | 1 天 | 90 天 | 冷冻前尽量去内脏血水 |
| 贝类海鲜（生） | 1 天 | 60 天 | 吐沙后再烹调 |
| 蛋类（带壳） | 30 天 | **不可冷冻** | 尖端朝下，不洗不擦，冷冻会碎裂 |
| 牛奶 | 7 天 | 30 天 | 巴氏奶开封后按标签，一般三到七天 |
| 酸奶与奶制品 | 10 天 | 60 天 | 发酸、胀气、有气泡即弃 |
| 熟食剩菜 | 3 天 | 60 天 | 绿叶菜类现炒现吃优先 |
| 米饭面条 | 3 天 | 60 天 | 凉透后尽快冷藏，室温放置风险高 |
| 汤类 | 2 天 | 60 天 | 含奶与淀粉的汤更易坏，冷却要分浅容器 |
| 开封酱料 | 30 天 | — | **以标签开封期为准**，开封后不返冷冻室 |
| 开封食用油 | 180 天 | — | 避光常温，远离灶台，出现哈喇味即弃 |
| 面包糕点 | 5 天 | 60 天 | 含奶油的更短，密封减缓氧化 |
| 冷冻面点与速食 | — | 120 天 | 生熟分开包装，防串味与破损 |
| 切开的水果 | 2 天 | **不可冷冻** | 只适合即食或榨汁 |
| 冰淇淋 | **按包装标注** | — | 融化后不得再冻，结晶且口感不可接受 |

**不可冷冻的完整清单**：叶菜、切开的水果、带壳鸡蛋、牛奶（分层）、冰淇淋、开封食用油（凝固结块）。

## 五、变质三条硬指标

**命中任意一条，立即弃用，不做「再洗洗」「再炒炒」的挽救尝试。**

| 指标 | 具体口径 |
|---|---|
| **异味** | 酸馊味、腐败味、氨味、哈喇味（油脂氧化）、任何不该有的味道 |
| **质地变化** | 发黏、变滑、拉丝异常、结块分层、汤汁变稠发浑 |
| **外观霉变** | 白色或彩色绒毛状霉菌、绿斑、发臭水泡；罐头鼓包胀气 |

**必须知道的三点：**

- 三条都没命中，**不等于安全**，只说明「没有明显变质证据」
- **耐热毒素**：蜡样芽孢杆菌毒素加热不破坏，变质后复热无法挽救
- **闻着「香」不等于好**：变质过程中某些产物（如酯类）会给出香味错觉

## 六、期限核算与状态判定

```
期限进度 = 已放天数 ÷ 保存期参考上限 × 100%
```

| 进度 | 状态 | 处置 |
|---|---|---|
| < 70% | 正常 | 按计划食用，保持温度 |
| 70% - 100% | 临近期限 | 优先安排食用，或在安全期内转冷冻 |
| ≥ 100% | 已超期 | **按最坏情况弃用**，不建议继续食用 |

**注意「临近期限」不是「还能放」**：它是提示你**现在就吃或转冷冻**，而不是告诉你还能再放几天。

## 七、脚本用法

```bash
python scripts/food_storage_check.py --file store.json --out 储存核查.md
python scripts/food_storage_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`today` 核查日期、`items` 食材列表、`fridge_temp_ok` / `freezer_temp_ok` 温度达标标记 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检（30 条断言，含 BOM 输入两条） |

输入 JSON 示例：

```json
{
  "today": "2026-05-10",
  "fridge_temp_ok": true,
  "freezer_temp_ok": true,
  "items": [
    {"name": "小白菜", "category": "leafy", "mode": "冷藏", "fresh_days": 4},
    {"name": "鸡胸肉", "category": "poultry", "mode": "冷藏", "fresh_days": 2},
    {"name": "鸡蛋", "category": "egg", "mode": "冷藏", "fresh_days": 18},
    {"name": "牛肉", "category": "meat", "mode": "冷冻", "fresh_days": 45}
  ]
}
```

可选品类：`leafy` `root` `cabbage` `mushroom` `meat` `poultry` `seafood_fish` `seafood_shell` `egg` `milk` `yogurt` `leftover` `rice_noodle` `soup` `opened_sauce` `opened_oil` `bakery` `frozen_dumpling` `ice_cream` `cut_fruit`；`mode` 只接受 `冷藏` 或 `冷冻`。

脚本输出：逐项期限进度与状态（按紧急度排序）、感官不可靠提示、变质三条硬指标、不建议冷冻清单、处置提示与人工确认清单。**脚本只做期限核算，不做感官判断，也不给「可安全食用」的结论。**

## 八、人工确认清单（这步不能省）

- [ ] 每项食材的**存放天数**已确认，不是估计值
- [ ] 品类判定正确（生/熟、开封/未开封、完整/已切）
- [ ] 存放条件已确认，冷藏不高于 4℃、冷冻不高于 −18℃
- [ ] 异味、质地、外观三项已逐项实际核对
- [ ] 生肉生禽与即食食品已分格，包装完整无破损
- [ ] 开封酱料与食用油已标注开封日期
- [ ] 高风险人群（老人、婴幼儿、孕妇、免疫力低下者）食用的食物已按更严标准处理
- [ ] 存疑项已按最坏情况处理，未以「看起来还行」放行

## 九、最常见的坑

**坑一：只闻味道，没味道就放心吃。**
错误做法：闻着没异味，判断没问题。正确做法：感官只能**排除**明显变质，**不能确认**安全。沙门氏菌、李斯特菌污染的食物可以完全没有任何气味。判断依据是温度和时长。

**坑二：日期靠猜。**
错误做法：「大概放了三四天吧」——三四天在叶菜上就是超期。正确做法：购买时就在包装上写日期，或买完立刻分装贴标签。日期不确定时按已超期处理。

**坑三：叶菜洗完再存。**
错误做法：买回青菜洗一遍再放冰箱，想着干净。正确做法：洗净的叶菜细胞已吸水破损，存一天就烂。要吃时再洗，或者洗后彻底沥干、垫吸水纸、袋内留缝隙。

**坑四：冻肉化了又冻回去。**
错误做法：冻肉拿到常温解冻一下，回头又塞回冷冻。正确做法：**化冻即已复温**，微生物开始大量繁殖，再冻不能逆转。应在冷藏室解冻，或直接按未解冻状态烹调。

**坑五：把闻着香的当没坏的。**
错误做法：变质过程中有酯类产生，香味明显，就觉得是香了。正确做法：出现任何不该有的香味，同样按变质处理。判断气味是否「正常」，依据是你对这种食物的既有认知，不是它好不好闻。

**坑六：剩饭放凉再处理。**
错误做法：米饭放着等完全凉透再收。正确做法：米饭里的蜡样芽孢杆菌在室温下即可繁殖并产生**耐热毒素**，且要长时间累积。要么趁热快速降温，要么尽快吃完，不要长时间留在台面上。

**坑七：买回一大堆一起洗一起切。**
错误做法：周末买一周的菜，洗好切好放保鲜盒。正确做法：切开的菜冷藏只有 2 天、叶菜只有 3 天。**分装不能延长保存期**，一次备餐吃一周的做法会大量浪费。

**坑八：把不可冷冻的放进冷冻室延长存放。**
错误做法：牛奶冻起来反正能放久一点、鸡蛋冻起来省地方。正确做法：牛奶冷冻后分层、蛋白变性，风味与质地不可接受；带壳鸡蛋冷冻会爆裂。需要延长就用小份分装冷藏。

**坑九：只看包装上的保质期。**
错误做法：保质期到了一直扔，说明没问题。正确做法：包装上的**保质期是未开封条件下的**；开封后有独立的期限，且很多标注「开封后请尽快食用」——这句话本身就是一条有时限要求的信号。

**坑十：给高风险人群用同样的标准。**
错误做法：闻着没味，给七十岁老人吃。正确做法：老人、婴幼儿、孕妇、免疫力低下者、正在服药者的食物，**感官有任何可疑即弃用**，不要靠「大概率没事」放行。

## 十、边界与免责

- 本技能提供家庭条件下的**储存期限参考口径与变质识别方法**，**不做微生物、毒素、农残检测，也不判定食品是否达到安全标准**
- 食品是否安全，**以具备资质的检测机构结果与产品标签为准**
- 保存期天数以现行食品安全标准、产品说明书与标签标示为准；标签与本表不一致时**以标签为准**
- 涉及餐饮门店、食品生产经营的合规判定，不属于本技能范围
- 已出现消化道症状者应及时就医，本技能不作任何健康或医疗建议
- 本技能不构成任何食品安全担保，「闻着正常」不构成可食用结论
