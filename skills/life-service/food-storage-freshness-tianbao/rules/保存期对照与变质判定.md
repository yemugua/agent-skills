# 保存期对照与变质判定

> 生成任何储存建议前先读这份文件，不要凭印象写天数。
> 表中天数为家庭冷藏（≤4℃）／冷冻（≤−18℃）条件下的**参考上限**，
> 用于判断「是否明显超期」。**产品标签标示的开封后期限优先于本表。**

## 二、感官不可靠场景（核心）

**这些情形闻、看、尝都不能作为安全依据：**

| 情形 | 机制 | 应对 |
|---|---|---|
| 沙门氏菌污染禽肉与蛋 | 蛋白水解无异味，外观与正常一致 | 严格控温控时，彻底加热 |
| 李斯特菌污染冷藏即食食品 | 冷藏温度下缓慢增殖，感官正常 | 即食食品不做二次加热风险控制 |
| 弯曲菌污染禽肉 | 生食阶段无任何感官提示 | 生禽不生食，加热要彻底 |
| 蜡样芽孢杆菌污染米饭 | 部分毒素**耐热**，复热无法消除 | 缩短室温时间，快速冷却 |
| 组胺降解的海鲜 | 加热不破坏，可致不适 | 低温保存，新鲜食用 |
| 反复解冻复温的生鲜 | 微生物大量繁殖后回冻不再抑制 | 一次性解冻用完 |

**结论**：感官正常 ≠ 安全。感官只能排除明显变质，不能确认安全。

## 三、变质三条硬指标

| 指标 | 具体口径 | 命中后 |
|---|---|---|
| **异味** | 酸馊味、腐败味、氨味、哈喇味（油脂氧化）、任何不该有的味道 | 立即弃用 |
| **质地变化** | 发黏、变滑、拉丝异常、结块分层、汤汁变稠发浑 | 立即弃用 |
| **外观霉变** | 白色或彩色绒毛状霉菌、绿斑、发臭水泡；罐头鼓包胀气 | 立即弃用 |

**三条都没命中 ≠ 安全**，只说明「没有明显变质证据」。

## 四、不可冷冻清单

| 品类 | 原因 |
|---|---|
| 叶菜类 | 解冻成糊状，不可逆 |
| 切开的水果 | 质地崩坏，只适合榨汁 |
| 带壳鸡蛋 | 冷冻爆裂 |
| 牛奶 | 分层、蛋白变性，风味不可接受 |
| 冰淇淋 | 融化后不可复冻，结晶口感不可接受 |
| 开封食用油 | 低温凝固结块，影响使用与风味 |

## 五、储存操作要点

- **冷藏**：生肉生禽放最下层或专用格，**防止滴液污染下层**；即食食品放上层
- **叶菜**：食用前再洗；或洗后彻底沥干、垫吸水纸、袋内留缝隙
- **分装**：按一次用量分成小份冷冻，**分装不延长保存期**，只方便取用
- **日期标记**：购买日、开封日、制作日**用记号笔直接写在包装上**
- **冷却**：熟食要在短时间内降温，汤类分装到**浅容器**加速散热
- **温度**：冷藏不高于 4℃，冷冻不高于 −18℃；温度计比「感觉」可靠

## 六、高风险人群（判断门槛应更低）

| 人群 | 加严规则 |
|---|---|
| 婴幼儿（尤其 6 个月以下） | 感官有任何可疑即弃用；不喂剩菜隔夜 |
| 孕妇 | 同上；避免生食与未彻底加热的肉蛋 |
| 65 岁以上老人 | 味觉与嗅觉减退，**感官判断本身就不可靠**，应更依赖时间与温度 |
| 免疫力低下者 / 化疗 / 长期用药者 | 任何可疑即弃；避免生冷与即食凉拌 |

## 七、否定词与防误伤

- 「**未超期**」不等于「安全」，只等于「没有明显超期证据」
- 「**闻起来正常**」不等于「可以食用」
- 「**标签没写开封期限**」不等于「可以长期存放」，应按最短周期处理
- 「**冷冻过**」不等于「安全」，化冻复温后风险已不可逆
- 「**标签上的保质期**」只适用于未开封状态，开封后另有期限

## 八、处置决策树

```
1. 日期能否确认？
   ├─ 不能 → 按已超期从宽处理
   └─ 能 → 继续
2. 是否命中三条硬指标任一条？
   ├─ 是 → 弃用，不做挽救
   └─ 否 → 继续
3. 期限进度 < 70%？
   ├─ 是 → 正常，按计划食用
   └─ 否 → 继续
4. 期限进度 < 100%？
   ├─ 是 → 临近期限，现在就吃或转冷冻
   └─ 否 → 已超期，弃用
5. 食用者是否高风险人群？
   ├─ 是 → 上述每一档门槛再降一档
   └─ 否 → 按上表执行
```
