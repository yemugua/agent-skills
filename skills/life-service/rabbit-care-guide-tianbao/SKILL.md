# 兔子饲养（rabbit-care-guide）

兔子不是小宠物鼠，**它的消化系统很娇气、牙齿一辈子都在长**。养好兔子的关键就两条：**牧草当主食 + 环境够大够干净**。很多「突然不吃东西」的急症，根子在平时饮食和空间错了。

这个技能做三件事：**搭笼具 → 定饮食 → 判异常**。

---

## 一、硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出兔笼空间、垫料与清洁口径 | ❌ 给出任何药物的名称、剂量与疗程 |
| 给出以牧草为主的饮食结构 | ❌ 判断兔子患的是什么病，给出治疗方案 |
| 给出禁忌食物表与每日护理清单 | ❌ 建议给兔子洗澡（应激与失温风险高） |
| 给出牙齿、消化道异常的观察清单 | ❌ 承诺任何饲养或健康结果 |
| 给出必须就医的判断线 | ❌ 指导兔子繁殖与幼兔接生操作 |

**必须停止自行处理，联系异宠兽医的情况**

- 超过 12 小时完全不进食、不排便（消化道停滞风险高）
- 流涎、牙关紧、嘴角湿毛（牙齿/口腔问题）
- 持续软便、水样便、便血或便形明显变小
- 腹胀如鼓、趴着不动、呼吸急促
- 打喷嚏频繁、流鼻涕、眼肿、食欲差
- 抽搐、瘫软、明显外伤

## 二、什么时候用

| 用户说法 | 用不用 | 说明 |
|---|---|---|
| 「兔子笼要多大」 | ✅ 用 | 按体重给最小笼底面积 |
| 「兔子主食喂什么」 | ✅ 用 | 以牧草为主，颗粒粮为辅 |
| 「兔子能吃什么菜」 | ✅ 用 | 给安全蔬菜清单与禁忌清单 |
| 「兔子软便怎么办」 | ⚠️ 部分 | 只给观察与就医判断，不诊断 |
| 「兔子牙齿过长」 | ⚠️ 部分 | 给护理口径，严重需就医磨牙 |
| 「兔子突然不吃东西」 | ❌ 不可 | 直接就医判断线，不自行处理 |

## 三、完整工作流

1. **量体重**：所有饮食与空间都按体重算。
2. **定笼具**：按体重给最小底面积，配垫料与定点排便区。
3. **定饮食**：牧草为主（占比 ≥ 70%），颗粒粮控量，安全蔬菜少量。
4. **配饮水**：常备凉白开或过滤水，每天换。
5. **配磨牙与玩具**：牧草本身磨牙，再加磨牙木/枝条。
6. **排清洁**：每天清粪、每周换垫料、每月深度消毒。
7. **做记录**：体重、进食量、排便形态、饮水量。
8. **判异常**：对照观察清单，命中就医线立刻停手。
9. **核对**：用 `--file` 跑一遍配置，把红线和不达标项先排掉。

## 四、核心规则说明

**动手之前必须先读这两个文件，不要凭印象写：**

- `rules/兔笼环境与每日护理.md` —— 笼底面积、垫料、清洁与磨牙配置
- `rules/饮食结构与禁忌.md` —— 牧草占比、颗粒粮控量、安全蔬菜与禁忌食物表

要点三条：

1. **牧草是主食不是零食**。苜蓿草（高钙）适合幼兔，提摩西草适合成兔。牧草占比低于六成，牙齿和肠道都容易出问题。
2. **颗粒粮是配角**。按体重每天 20 ～ 50 克/公斤即可，喂多了容易肥胖和肠道负担。
3. **兔子要喝水**。必须常备清洁饮水，不喝水往往是不舒服的信号。

## 五、脚本用法

```
python scripts/rabbit_care_check.py --selftest
python scripts/rabbit_care_check.py --file rabbit.json
```

输入字段：

| 字段 | 说明 | 示例 |
|---|---|---|
| cage_length_cm | 笼长厘米 | 100 |
| cage_width_cm | 笼宽厘米 | 60 |
| litter_trained | 是否定点排便 | true |
| hay_pct | 牧草占日粮比例 | 80 |
| pellet_g_per_kg | 颗粒粮克/公斤体重/天 | 30 |
| water_available | 是否常备饮水 | true |
| veg_items | 蔬菜列表 | 「油麦菜」「胡萝卜」 |
| chew_toys | 是否有磨牙物 | true |
| weight_kg | 体重公斤 | 2.0 |
| symptoms | 观察到的异常列表 | 见规则文件 |

结论分三档：**先处理**（空间不足、牧草过低、无饮水、禁忌食物、出现就医症状）、**待确认**（信息不足）、**可照此执行**。存在真实缺陷时即使信息也不完整仍判先处理。

结果写入 `scripts/_last_result.txt`，每条不合格带原因。

## 六、人工确认清单（这步不能省）

- [ ] 笼底面积达到该体重的最小要求，兔能完全伸展和站立
- [ ] 牧草全天不断，且占比 ≥ 70%
- [ ] 颗粒粮按体重控量，没有一把抓
- [ ] 常备清洁饮水，每天更换
- [ ] 蔬菜只给安全种类，且是少量配菜不是主食
- [ ] 食物清单里没有任何禁忌项（葱蒜韭、马铃薯、巧克力、乳制品、面包）
- [ ] 有磨牙物，牙齿未见明显过长
- [ ] 每天清粪、定期换垫料，笼内无持续异味
- [ ] 体重、进食、排便有记录
- [ ] 出现不食/流涎/持续软便等就医症状已停手联系兽医

## 七、最常见的坑

1. **把蔬菜当主食**。兔子的肠胃靠高纤维牧草运转，蔬菜水分大、纤维低，长期当主食必软便。
2. **颗粒粮随便撒**。喂多最直接的是肥胖和肠道停滞。
3. **不给水**。有人认为兔子吃菜就够了，错；缺水是健康大忌。
4. **喂葱蒜韭菜马铃薯巧克力**。这类对兔有毒性或强刺激，碰到即停。
5. **不给磨牙物**。牙齿不停长，缺磨牙会过长、扎嘴、流涎。
6. **笼子太小**。空间不足运动量低，脚皮炎和肥胖都来。
7. **给兔子洗澡**。应激和失温风险高，脏了局部擦就行。
8. **不食超过半天还观望**。兔消化道停滞进展快，应尽早就医。
