# 兔子饲养（兔子饲养 / rabbit-care-guide）

你会得到什么：一份按体重落地的兔子家庭饲养方案——兔笼最小底面积、垫料与清洁频率、以牧草为主的饮食结构（牧草占比、颗粒粮控量）、安全蔬菜与禁忌食物表、磨牙与常备饮水要求，以及一份「什么时候必须停手联系异宠兽医」的异常观察清单。技能内置 `rabbit_care_check.py`，把你的配置写成 JSON 跑一遍，自动标出笼具太小、牧草占比过低、无常备饮水、禁忌食物、颗粒粮过量、出现就医症状等不合格项并附原因。

典型用法：兔笼买多大才够；兔子主食到底喂什么、颗粒粮抓一把行不行；哪些菜不能喂；兔子突然不吃东西、软便、流涎该不该马上去医院。把这些写成字段交給脚本，立刻拿到「先处理 / 待确认 / 可照此执行」的结论。

边界：本技能只做家庭饲养的环境与管理口径，**不诊断疾病、不开药、不给剂量，也不建议给兔子洗澡**。兔子出现不食超半天、持续软便、腹胀、流涎等情况，请直接联系专业异宠兽医。
