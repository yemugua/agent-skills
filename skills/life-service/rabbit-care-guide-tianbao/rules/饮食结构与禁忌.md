# 饮食结构与禁忌口径

本文件是「兔子饲养」技能的核心资产。**定饮食方案前先读这里。** 兔是严格草食、高纤维消化，结构错了最容易出事。

## 1. 日粮结构（按占比）

| 组成 | 占比 | 说明 |
|---|---|---|
| 牧草（提摩西/苜蓿等） | ≥ 70% | 主食，提供纤维与磨牙；幼兔可用苜蓿，成兔转提摩西 |
| 颗粒粮 | 配角 | 20 ～ 50 克/公斤体重/天，控量 |
| 安全蔬菜 | 少量配菜 | 每日一小把，洗净沥干 |
| 水果/零食 | 极少量 | 高糖，偶尔指尖一小块即可 |

- 牧草占比低于 60% 判为不合格（牙齿与肠道风险）。
- 颗粒粮超过 50 克/公斤/天判为过量。

## 2. 安全蔬菜（常见可给，少量）

油麦菜、生菜（罗马生菜为宜，散叶少用）、芹菜叶、胡萝卜（带缨，少量）、西兰花嫩茎、香菜、薄荷。新菜一种一种试，观察便形。

## 3. 禁忌食物（碰到即判不合格）

- 葱、蒜、韭菜、洋葱（葱属，对兔有毒）
- 马铃薯、红薯生块茎
- 巧克力、糖果、饼干、面包、人的高糖高盐零食
- 牛奶、酸奶、乳制品（兔不消化乳糖）
- 豆类生品、坚果（高脂难消化）
- 未洗净带农药残留的菜叶

## 4. 进食与排便观察（只观察，不做诊断）

| 观察项 | 正常 | 需警惕 |
|---|---|---|
| 进食 | 每天规律吃草 | 超过半天不进食 |
| 粪便 | 圆润干燥成串 | 软便、黏连、变小、水样、带血 |
| 饮水 | 每天稳定 | 突然不喝或猛喝 |
| 体重 | 平稳 | 短期内明显掉秤 |

命中「不食超半天 / 持续软便 / 便血 / 腹胀 / 流涎」任一项，停手联系异宠兽医。

## 5. 就医判断线（只列观察清单）

不食超 12 小时、流涎、持续软便或便血、腹胀如鼓、瘫软不动、频繁打喷嚏流脓涕、抽搐。出现即联系异宠兽医，不自行用药。
