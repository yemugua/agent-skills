# 跑步姿势

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 给出各项姿势指标的判定口径与纠正动作 | 诊断跑步膝、髂胫束综合征、跟腱炎或应力性骨折 |
| 说明负荷递增上限与减量原则 | 给伤后康复方案、拉伸处方或力量训练治疗剂量 |
| 整理疼痛停跑清单与就医提示 | 承诺改姿势一定能解决所有疼痛 |
| 说明鞋具与场地选择的核对口径 | 推荐药物、膏药、护具品牌或注射治疗 |
| 输出姿势不合格项与纠正优先级 | 建议忍痛坚持跑完或靠意志突破 |

**必须停跑并转交专业人士的情况**

- 单侧疼痛进行性加重，或疼痛改变跑姿、出现跛行
- 夜间痛、静息痛，或负重时骨性锐痛（警惕应力性损伤）
- 跟腱处突发剧痛、有「被踢一脚」感，或局部明显肿胀
- 膝关节肿胀、交锁、打软腿
- 跑中胸闷胸痛、头晕、心悸、异常气短 —— 立即停止并就医
- 小腿前侧痛在休息时也不缓解，或单侧局限性骨性压痛

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「跑步姿势对不对，怎么自查」 | 用 |
| 「前脚掌还是后脚跟着地」 | 用，说明落地点比触地部位更重要 |
| 「步频多少合适」 | 用，给区间与提高方式 |
| 「怎么判断自己有没有跨步」 | 用，给落地点与落地声的自查法 |
| 「跑步膝盖外侧疼」 | 只作停跑与就医提示，不做诊断 |
| 「跑完小腿前面疼还能跑吗」 | 只作停跑提示 |
| 「跑量怎么加才不受伤」 | 用，给 10% 原则 |
| 「跑步呼吸怎么配合步子」 | 用 |
| 「帮我看看跑步视频姿势」 | 不提供视频判读，只给自查清单 |

## 三、完整工作流

1. **先排疼痛**：逐条过疼痛停跑清单，命中任一条先停跑并就医，不要边疼边改姿势。
2. **量基础数据**：用运动手表或手机 App 取步频、垂直振幅、触地时间、左右触地平衡；没有设备时用手机慢动作录像从侧面拍 20 秒。
3. **按指标逐项判定**：对照 `rules/姿势指标判定与纠正.md` 的阈值，先看落地点与步频这两项，它们决定其余指标能不能改得动。
4. **定纠正优先级**：一次只改一项。落地点在前 → 先提步频；步频达标但垂直振幅大 → 再练放松与重心稳定。
5. **查负荷**：周跑量增幅是否超过 10%，单次最长距离是否超过周跑量的 30%。姿势再好，负荷加太快一样会出问题。
6. **查鞋与场地**：鞋底磨损部位、鞋龄、路面硬度。
7. **记录与复评**：每两周复测同样的配速与距离下的步频与触地指标。

## 四、核心规则与要件库

生成姿势建议或纠正方案前，**必须先读**：

- `rules/姿势指标判定与纠正.md`：步频、落地点、垂直振幅、触地时间、躯干与摆臂、呼吸的阈值与纠正动作。
- `rules/负荷递增与疼痛停跑.md`：10% 原则、鞋具与场地核对、疼痛停跑清单与就医提示。

不得把「跑步膝疼」简单归因于姿势并给单一纠正动作。疼痛是停跑信号，不是靠改姿势硬扛的对象。

## 五、脚本用法

```
python scripts/running_posture_check.py --file case.json
python scripts/running_posture_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：步频、垂直振幅、触地时间、落地点、躯干姿态、摆臂、左右平衡、周跑量与上周跑量、疼痛部位 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--json` | 以 JSON 输出 |
| `--selftest` | 运行自检 |

脚本输出各项指标判定、不合格项与原因、纠正优先级、负荷递增判定和疼痛停跑提示。**判定顺序是先查真实缺陷（跨步、步频过低、垂直振幅超标、左右失衡、腰前倾、跑量增幅超限、疼痛），再看信息是否完整**，只填了步频却填了疼痛时，会直接判不合格而不是待确认。

## 六、人工确认清单

- [ ] 疼痛停跑清单逐条确认，未命中的才做姿势纠正
- [ ] 步频与落地点这两项已先查，其余指标后查
- [ ] 一次只改一项，改完稳定两周再改下一项
- [ ] 周跑量增幅未超过 10%
- [ ] 单次最长距离未超过周跑量的 30%
- [ ] 鞋龄与鞋底磨损部位已核对，路面已评估
- [ ] 纠正动作有配套练习（原地小步跑、节拍器跟频）
- [ ] 两周后复评的配速与距离已定，保证可比

## 七、最常见的坑

1. **主动加大步幅**：步幅是步频提高后的结果，主动跨大步会让落地点跑到重心前方，形成刹车效应，冲击全部由膝盖承担。
2. **只看触地部位不看落地点**：前脚掌着地但落在重心前方，冲击比后脚跟着地还大。落地点比触地部位重要得多。
3. **步频低于 160 还在练间歇**：低步频下做速度训练，等于反复练习跨步。
4. **跑量一周翻倍**：姿势再标准，周跑量增幅超过 10% 也会显著提高受伤风险，这是最容易被忽视的一条。
5. **腰前倾当身体前倾**：从腰部折下去会压迫腰椎且限制摆髋，正确是从脚踝整体微前倾。
6. **摆臂横过身体中线**：横向摆臂会带动躯干旋转，浪费能量且影响下肢力线。
7. **疼了改姿势继续跑**：疼痛是负荷信号，改姿势不能替代减量与就医。
8. **只练跑不练力量**：臀中肌与核心力量不足是很多跑姿问题的根因，光靠跑步解决不了。

## 八、边界与免责

本技能提供跑步姿势的自查口径、纠正动作与负荷递增原则，不构成医学诊断、运动康复方案或训练治疗剂量。各项指标的合理区间因身高、配速、路面、鞋具和既往伤病史而异，以最新版运动医学共识和专业教练的现场评估为准。出现进行性疼痛、夜间痛、静息痛、关节肿胀、跑中胸闷头晕等情况，请停止跑步并就医。
