# 负荷递增与疼痛停跑

## 一、周跑量递增（10% 原则）

| 项目 | 口径 |
|---|---|
| 周跑量增幅上限 | 不超过上周的 10% |
| 单次最长距离 | 不超过周跑量的 30% |
| 减量周 | 每 3-4 周安排一周跑量降到 60-70% |
| 连续增量 | 不超过 3 周，第 4 周必须回落 |
| 新增强度 | 一周内只新增一种（距离、配速、坡度三选一） |

**姿势再标准，周跑量增幅超过 10% 也会显著提高受伤风险**，这是最容易被忽视的一条。跑量翻倍常见于备赛冲刺期，也是最集中的受伤窗口。

## 二、鞋具核对

| 项目 | 口径 |
|---|---|
| 鞋龄 | 常规跑鞋约 500-800 公里更换，看中底是否明显压塌 |
| 磨损部位 | 外侧后跟磨损常见于正常落地；内侧过度磨损提示过度内翻，需要试穿时注意支撑 |
| 鞋码 | 脚趾前留约一指宽，跑后脚会微肿 |
| 更换时机 | 中底出现明显褶皱、回弹变差、或跑后不适增加 |
| 不要把鞋当诊断 | 磨损形态仅供参考，不作为伤情判断依据 |

## 三、路面与场地

| 路面 | 特点 |
|---|---|
| 塑胶跑道 | 缓冲最好，适合速度课与恢复跑 |
| 土路、草地 | 缓冲好但注意坑洼与湿滑 |
| 沥青 | 常见且硬度适中 |
| 水泥、石板 | 最硬，减少在这类路面的长距离与速度课 |
| 倾斜路面 | 长期单侧倾斜跑会加大左右失衡，尽量挑平整路线 |

## 四、疼痛停跑清单

出现以下任一项，停止跑步并转就医评估，不要靠改姿势硬扛：

| 情况 | 说明 |
|---|---|
| 单侧疼痛进行性加重 | 每次跑都比上次更疼，或疼得更早出现 |
| 疼痛改变跑姿、出现跛行 | 说明身体已经在代偿 |
| 夜间痛、静息痛 | 不跑也疼，属于需要评估的信号 |
| 骨性锐痛或局限压痛 | 小腿前侧、足部局限骨性压痛需警惕应力性损伤 |
| 跟腱突发剧痛或肿胀 | 有「被踢一脚」感时立即停跑 |
| 膝关节肿胀、交锁、打软腿 | 不属于靠休息就能处理的情况 |
| 跑中胸闷胸痛、头晕心悸 | 立即停止并就医 |

## 五、需要降低强度而非完全停止的情况

- 跑后轻度肌肉酸痛，48 小时内缓解，属正常反应，可降低强度继续
- 换了更硬的路面后不适，先换回软路面并减量 30%
- 换了新鞋后不适，先换回旧鞋观察

判断口径：**酸痛在活动后减轻、次日可缓解，通常属于正常；疼痛在活动中加重、次日更疼，属于停跑信号。**

## 六、力量与恢复

| 项目 | 建议 |
|---|---|
| 臀中肌与核心 | 每周 2 次基础力量，很多跑姿问题的根因在力量不足 |
| 睡眠 | 跑量增加期保证睡眠，恢复不足会直接体现为姿势变形 |
| 疲劳信号 | 静息心率明显升高、睡不好、跑同样配速更费劲，先减量 |

## 七、禁止的做法

- 疼了继续跑或用改姿势代替减量
- 一周内同时加距离、加速度、加坡度
- 连续 4 周以上不安排减量周
- 用止痛药支撑完成训练
- 把他人跑姿数据当成自己的目标值
