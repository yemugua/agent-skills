# 姿势指标判定与纠正

## 一、步频

| 步频（步/分钟） | 判定 | 说明 |
|---|---|---|
| ≥ 180 | 优 | 精英跑者常见区间，非人人必须达到 |
| 170-179 | 合格 | 业余跑者的实用目标区间 |
| 160-169 | 需改进 | 多半伴随跨步，先提 5% 再观察 |
| < 160 | 不合格 | 几乎必然伴随落地点靠前，冲击显著增大 |

提高方式：用节拍器设在当前步频 +5%（不超过 +10%），原地小步跑跟频 2 分钟，再慢跑跟频 5 分钟，每周做 3 次。**不要同时提步频和提速**，一次只改一项。

## 二、落地点（最重要的一项）

| 落地点 | 判定 | 说明 |
|---|---|---|
| 重心正下方 | 合格 | 触地瞬间小腿基本垂直地面 |
| 略在重心前方 | 可接受 | 小幅前越是正常的 |
| 明显在重心前方 | 不合格 | 跨步刹车，冲击全部由膝盖承担 |

判断方式：侧面慢动作录像，看触地瞬间支撑腿的小腿是否垂直；或听落地声——声音大、有「咚咚」的砸地感，多半落地点靠前。

**触地部位（前脚掌 / 全脚掌 / 后脚跟）不是决定性因素**。前脚掌着地但落在重心前方，冲击比后脚跟着地更大。先解决落地点，再谈触地部位。

## 三、垂直振幅

| 垂直振幅（厘米） | 判定 | 说明 |
|---|---|---|
| ≤ 8 | 优 | 重心平稳，能量利用率高 |
| 8-10 | 合格 | 业余跑者的合理区间 |
| 10-12 | 需改进 | 上下起伏浪费能量 |
| > 12 | 不合格 | 明显在「跳」而不是「跑」 |

纠正：想象头顶有一层天花板，跑时不要顶到它；加强核心与臀中肌，减少躯干左右晃动。

## 四、触地时间

| 触地时间（毫秒） | 判定 |
|---|---|
| < 250 | 优 |
| 250-300 | 合格 |
| 300-330 | 需改进 |
| > 330 | 不合格，说明推蹬效率低 |

触地时间随配速变化，比较时要在同一配速下比。

## 五、左右触地平衡

| 左右差值 | 判定 |
|---|---|
| ≤ 2% | 合格 |
| 2-3% | 需改进 |
| > 3% | 不合格，提示单侧力量或活动度不对称 |

单侧失衡常与臀中肌力量不足、旧伤侧的回避动作有关。持续超过 3% 建议做单侧力量训练，仍不改善请专业人士评估。

## 六、躯干与头部

| 项目 | 合格 | 不合格 |
|---|---|---|
| 前倾 | 从脚踝整体微前倾，约 5-10 度 | 从腰部折下去（压迫腰椎、限制摆髋） |
| 躯干稳定 | 平稳不左右晃 | 明显左右摇摆、耸肩 |
| 头部 | 目视前方 20-30 米 | 低头看脚（改变颈椎与躯干力线） |
| 肩部 | 放松下沉 | 耸肩、端肩 |

## 七、摆臂

| 项目 | 合格 | 不合格 |
|---|---|---|
| 方向 | 前后摆 | 横向摆、手越过身体中线 |
| 肘角 | 约 90 度，随配速略变 | 伸直甩臂或过度夹紧 |
| 手部 | 虚握放松 | 握拳紧绷、手指伸直 |
| 幅度 | 前不过胸、后不过腰 | 大幅抡臂 |

摆臂横过身体中线会带动躯干旋转，是能量浪费的常见来源。

## 八、呼吸

| 配速 | 建议节奏 |
|---|---|
| 轻松跑 | 2 步吸 2 步呼，或 3 吸 2 呼 |
| 节奏跑 | 2 吸 1 呼或 2 吸 2 呼 |
| 冲刺 | 以能说短句为上限 |

固定用一种节奏，不要忽快忽慢。跑中能说完整短句，说明强度基本合适。

## 九、纠正优先级

1. 落地点（影响冲击，优先级最高）
2. 步频（决定落地点能不能改得动）
3. 躯干前倾与稳定
4. 垂直振幅与摆臂
5. 触地时间与左右平衡（属于结果指标，改完前面再看）

一次只改一项，稳定两周再改下一项。
