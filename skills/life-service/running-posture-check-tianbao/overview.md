# 跑步姿势

跑步姿势自查里，最容易搞错的是优先级：多数人一上来就纠结「前脚掌还是后脚跟着地」，但真正决定冲击大小的是落地点在重心的前方还是下方，其次是步频。落地点跑到重心前面，冲击全部由膝盖承担，改触地部位毫无用处。

## 你会得到什么

- 步频、落地点、垂直振幅、触地时间、左右触地平衡的判定阈值
- 躯干前倾、摆臂、头部与呼吸的姿势口径
- 落地点与落地声的现场自查法，不需要任何设备
- 周跑量 10% 递增原则与单次距离上限
- 鞋具、路面核对清单，以及疼痛停跑与就医提示

## 典型用法

适合刚开始跑步的成年人、准备半马但配速上不去的跑者、跑步后反复出现不适想排查原因的人。有一块运动手表最好，没有也能用手机慢动作录像完成大部分自查。

## 边界

技能不做伤情诊断，也不提供康复方案。进行性疼痛、夜间痛、静息痛、关节肿胀、跟腱突发剧痛、跑中胸闷头晕，这些属于需要停跑就医的信号。指标区间因人而异，以专业教练的现场评估为准。
