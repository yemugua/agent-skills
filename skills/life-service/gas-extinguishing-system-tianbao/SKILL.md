# 气体灭火系统（gas-extinguishing-system）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据 GB 50370《气体灭火系统设计规范》，生成清单：防护区与容积核定、灭火剂类型与设计用量、泄压口与围护结构密闭性、手自动转换与延时、钢瓶检验与维护。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 气体灭火
- 气体灭火系统
- 七氟丙烷
- IG541
- 泄压口

## 三、工作流
1. 核定防护区与容积
2. 确定灭火剂类型与设计用量
3. 检查泄压口与密闭性
4. 确认手自动转换与延时
5. 落实钢瓶检验与维护

## 四、核心内容（检查清单与判定）
GB 50370 规定气体灭火系统的防护区、灭火剂用量与泄压口要求；防护区须密闭并设泄压口，人员进入前须确认手自动转换与延时。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含防护区与容积核定 | 防护区 |
| Q2 | FAIL | 未含灭火剂类型与用量 | 灭火剂 |
| Q3 | WARN | 未含泄压口与密闭性 | 泄压 |
| Q4 | FAIL | 未含手自动转换与延时 | 控制 |
| Q5 | WARN | 未含钢瓶检验与维护 | 维护 |

> 脚本 `gas-extinguishing-system_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python gas-extinguishing-system_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python gas-extinguishing-system_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
