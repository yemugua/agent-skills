# 乳胶漆选购与施工核查（paint-selection-check）

刷墙这件事，**成品好不好八成取决于基层和施工条件，不取决于品牌**。基层没处理、环境不对、养护不够，再贵的漆都会起皮、开裂、透底。

另一个高频困惑是环保指标怎么看。**指标的"口径"比"数值"更重要**——同一个"零甲醛"说法，可能是真的零添加，也可能是检出量低于检测方法下限，这两者完全不同。

这个技能做五件事：**区分涂料类型** → **看懂指标口径** → **处理基层与环境条件** → **失败原因与责任归属** → **判断 DIY 范围**。

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 区分四类涂料的特性与适用场景 | ❌ 编造或引用具体标准号与数值 |
| 说明环保指标应该怎么看口径 | ❌ 承诺"零甲醛""零 VOC" |
| 给出基层处理与环境条件要求 | ❌ 代替专业涂装施工与大面积施工 |
| 说明常见失败原因与责任归属参考 | ❌ 认定责任归属（需合同、记录与检测） |
| 判断 DIY 适用范围与安全要求 | ❌ 判断室内空气是否达标（需检测） |

**遇到以下情况，转交专业涂装施工方：**

- 单个房间面积较大且需要整体重做
- 需要铲除旧漆至基层（尤其涉及旧漆含铅等历史情况）
- 基层有空鼓、开裂、渗水痕迹
- 墙面有结构裂缝或墙体渗水
- 需要高处作业（层高较高、需搭梯或吊顶作业）
- 房屋有孕妇、婴幼儿、呼吸道敏感者居住且面积较大
- 涉及租客与房东的墙面责任与恢复原状争议

## 三、第 2 步：四类涂料特性对照

| 类型 | 质感与工艺 | 主要优势 | 主要限制 | 适合位置 |
|---|---|---|---|---|
| 乳胶漆 | 刷涂或滚涂，平面效果 | 施工快、成本低、修补容易、颜色选择多 | 质感单一，遮盖力受基层影响大 | 大面积墙面与顶面 |
| 艺术漆 | 多种肌理（刮涂、批刮、滚涂等） | 质感强、装饰性高、耐脏性较好 | 成本高、施工手法要求高、**修补困难**（局部补色会留下明显痕迹） | 背景墙、局部造型墙 |
| 硅藻泥 | 无机类，肌理明显 | 透气、调湿、无明显光泽 | 怕水、耐擦洗性差、**遇水易粉化** | 卧室、追求质感且不常擦拭的墙面 |
| 贝壳粉 | 无机类，细腻肌理 | 质感细腻、透气 | 耐擦洗性差、怕水、部分产品易掉粉 | 局部造型、儿童房（需确认产品说明） |

**关键差异**：**艺术漆与硅藻泥的"难修补"是最需要提前知道的**。乳胶漆局部补一块 relatively 不显眼；艺术漆局部补一块，色差与手法痕迹几乎必然可见。所以选艺术漆前要想清楚"以后磕碰了怎么办"。

## 四、第 3 步：环保指标怎么看口径

这一节不写具体数值，因为**数值随现行国家标准与产品实际变化，写死反而会误导**。正确的说法是：以现行国家标准和检测报告为准。这里给出的是**应该问什么、怎么看**。

| 指标 | 该看什么 | 常见误区 |
|---|---|---|
| VOC（挥发性有机化合物） | 检测报告中的实测值与检测方法；单位与限值口径 | 把"低 VOC"当成"无 VOC" |
| 甲醛与甲醛释放 | 区分"甲醛含量"与"甲醛释放量"，两者检测方法不同 | 把"未检出"当成"零添加"，这两者含义不同 |
| 有害物质限量 | 是否属于现行国家标准规定范围内的指标项目 | 用"某国标准"暗示高于国标 |
| 耐擦洗次数 | 次数对应的是特定测试方法下的结果 | 直接把次数当作日常耐擦能力 |
| 抗霉菌 | 是否有对应检测与等级 | 把"添加了防霉成分"当成"经过检测" |

**看检测报告的四个动作：**

1. 确认报告对应的产品型号与批次，**不是同系列另一款**
2. 确认检测依据的是现行国家标准
3. 确认单位与检测方法，避免拿不同口径的数值横向比较
4. 有条件时看报告出具机构，不接受只有产品宣传页的说法

**"未检出"不等于"零添加"**："未检出"表示低于检测方法的下限，不表示配方里完全没有。这两种说法差别很大，销售话术里经常混用。

## 五、第 4 步：基层处理要求

**基层决定成品，这是最容易被跳过的一步。**

| 检查项 | 方法 | 要求 |
|---|---|---|
| 空鼓 | 敲击听空音 | 有空鼓必须先处理，空鼓区域的漆会随之脱落 |
| 裂缝 | 目视，重点看新旧裂缝 | 裂缝应先按裂缝性质处理，未处理的裂缝会继续开裂 |
| 渗水痕迹 | 检查是否有水渍、泛碱、返潮 | 有渗水必须先解决漏源，湿基层刷漆必起皮 |
| 旧漆状况 | 检查是否起壳、粉化、空鼓 | 粉化层需铲除至坚实基层 |
| 平整度 | 侧光观察 | 明显凹凸需先用腻子找平 |
| 清洁度 | 检查油污、灰尘 | 有油污的基层需要先用适宜方法处理 |

**腻子与找平**：基层不平时需要用腻子找平。腻子的干燥时间与打磨要求**以产品说明书为准**。**没干透就刷漆是起皮最常见的原因之一**。

---

## 六、第 5 步：环境条件对照

| 条件 | 要求方向 | 说明 |
|---|---|---|
| 温度 | 按产品说明书的施工温度范围 | 过低会导致成膜不良、附着力差 |
| 湿度 | 按产品说明书要求 | 湿度过高时干燥时间长，易出现表干里不干 |
| 通风 | 施工时保持通风 | 有利于挥发物扩散，但**不代表通风能让不达标的产品达标** |
| 干燥时间 | 每遍之间与最终成膜时间按说明书 | 干燥不足就涂下一遍或提前入住，是常见问题 |
| 避开阳光直射与强风 | 施工时段选择 | 表面干燥过快会造成表干里不干 |
| 成品保护 | 施工期间与养护期内 | 避免磕碰、沾水、覆盖未干表面 |

> 具体数值以**产品说明书**为准，不同产品差异较大，不要套用其他产品的参数。

## 七、第 6 步：DIY 面积判断

| 情形 | 能否自己动手 |
|---|---|
| 局部修补（磕碰、污渍、小面积起皮） | ✅ 可以 |
| 单个墙面、面积不大、基层状况好 | ⚠️ 可以，但需注意干燥与养护 |
| 房间内多面墙或含顶面 | ⚠️ 难度与工程量明显上升 |
| 需铲除旧漆至基层 | ❌ 转专业施工 |
| 整户翻新或面积很大 | ❌ 转专业施工 |
| 基层有空鼓、裂缝、渗水痕迹 | ❌ 先处理基层问题，必要时转专业 |
| 需高处作业或高空作业 | ❌ 转专业施工 |

**判断原则**：看**面积**、看**基层状况**、看**是否需要铲除**、看**是否高处作业**。四项中有任一项落到 ❌，就不要自己做了。

---

## 八、第 7 步：施工安全

| 人群或情形 | 要求 |
|---|---|
| 孕妇 | **避免接触涂料与施工区域**，施工期间离开该房间，充分通风后再进入 |
| 婴幼儿 | 同上，施工期间不在该房间活动 |
| 呼吸道敏感者、哮喘患者 | 不参与施工；施工期间不进入该房间 |
| 高处作业 | 转专业施工，不自行搭梯或站在家具上 |
| 通风条件差的密闭空间 | 不施工，先改善通风条件 |
| 皮肤敏感者 | 佩戴手套，避免长时间接触未干涂料 |

**通用要求**：开窗通风，佩戴手套口罩，涂料装在原包装内不随意分装，剩余涂料按说明书处理。

## 九、常见失败原因与责任归属参考

| 失败现象 | 常见原因 | 责任归属参考 |
|---|---|---|
| 起皮 | 基层不牢、有渗水、旧漆粉化未铲除、干燥不足 | 视情况属基层处理或施工方责任 |
| 开裂 | 基层裂缝未处理、材料收缩、干燥过快 | 裂缝未处理属施工方；材料收缩需看产品说明 |
| 流挂 | 一次涂刷过厚或未按说明书配比 | 施工方 |
| 透底 | 遮盖力不足或底色与面色差异大、未按说明书配比使用 | 施工方或选型问题 |
| 色差 | 不同批次混用、涂刷不均、光线不同 | 批次混用属施工方；同批号轻微色差属常见现象 |
| 发花 | 水分或助剂分布不均、施工环境湿度过高 | 施工方 |
| 掉粉 | 基层粉化未处理、产品附着要求不满足 | 基层问题或选型问题 |
| 龟裂 | 厚涂、干燥过快或过厚 | 施工方 |

> **责任归属的最终认定以施工合同约定、现场记录、产品检测报告与专业检测结论为准**。本表只作常见情形的对照参考，不构成责任认定。

## 十、验收标准

| 验收项 | 方法 | 合格表现 |
|---|---|---|
| 外观 | 正常光线下目视 | 颜色均匀，无明显接茬、色块、流挂、发花 |
| 平整度 | 侧光观察 | 无明显凹凸、波浪、颗粒不均 |
| 附着 | 手指轻触（非破坏性） | 干燥后不轻易脱落、不掉粉 |
| 气味 | 靠近闻 | 无明显刺激性气味残留 |
| 干燥程度 | 按说明书时间后检查 | 达到说明书规定时间后表面已充分干燥 |
| 成品保护 | 目视 | 无磕碰、沾污、未干被覆盖的痕迹 |

**重要提醒**：**"无味"不等于"达标"**。气味强弱受通风、温度、涂刷量与产品配方影响。是否达标涉及检测，结论以有资质的检测为准。

## 十一、脚本用法

```bash
python scripts/paint_check.py --text "墙面起皮了，孕妇在家"
python scripts/paint_check.py --file 情况.json --out 结果.md
```

| 参数 | 说明 |
|---|---|
| `--text` | 描述墙面状况与居住情况 |
| `--file` | 从文件读，支持 `.txt` / `.md` / `.json`（JSON 用 `{"desc": "..."}`） |
| `--out` | 结果输出路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本做三件事：按墙面状况匹配常见原因与责任归属参考、给出材料选型建议、检查是否命中安全红线人群（孕妇、婴幼儿、呼吸道敏感者）。

> 脚本是关键词匹配，**不等于现场判断**。基层状况要实际敲、实际看。

## 十三、最常见的坑

**坑一：把"零甲醛"当成"零添加"。**
"未检出"只表示低于检测方法下限。销售话术里这两个说法经常混着说，看到这类宣传时直接问检测报告。

**坑二：拿 A 产品的检测报告说 B 产品安全。**
报告必须对应具体型号与批次。同一系列不同型号差异可能很大。

**坑三：基层没处理就刷。**
起皮、空鼓、粉化层没解决，刷上去只是把问题盖住，几个月后成片脱落。

**坑四：腻子没干透就刷漆。**
这是起皮的常见原因。每遍干燥时间按说明书，不要为了赶进度压缩。

**坑五：墙上有渗水还刷漆。**
湿基层刷漆必起皮。先解决漏源，再做墙面。

**坑六：不同批次的漆混着用。**
同房间出现明显色差。同一区域尽量用同一批次。

**坑七：选了艺术漆，之后磕碰没法补。**
艺术漆局部补色几乎必然留下痕迹。选之前想清楚以后的修补问题。

**坑八：硅藻泥用在需要经常擦拭的墙面。**
硅藻泥耐擦洗性差、遇水易粉化，厨房与高频接触区域不合适。

**坑九：通风半个月就认为达标。**
气味强弱不等于是否达标。是否达标涉及检测。

**坑十：孕妇在正在刷漆的房间待着。**
施工期间离开，充分通风后再进入，这一条没有商量余地。

**坑十一：自己站家具上刷高墙。**
高处作业交给专业施工。

## 十四、边界与免责

- 本技能**不替代**专业涂装施工、铲除旧漆、基层结构处理与室内空气检测
- 环保指标限值与检测方法**以现行国家标准和产品检测报告为准**，不同产品差异很大
- 施工温度、湿度、干燥时间等参数**以产品说明书为准**，不要套用其他产品
- 责任归属以**施工合同约定、现场记录与检测结论**为准
- 涉及租房墙面恢复原状与押金争议的，按**租赁合同约定与相关主管部门要求**办理
