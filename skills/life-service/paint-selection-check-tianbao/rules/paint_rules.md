# 乳胶漆选购与施工规则表

生成选型与施工方案前先读本文件，不要凭印象写。

---

## 一、四类涂料特性对照

| 类型 | 质感与工艺 | 主要优势 | 主要限制 | 适合位置 |
|---|---|---|---|---|
| 乳胶漆 | 刷涂或滚涂，平面效果 | 施工快、成本低、修补容易、颜色选择多 | 质感单一，遮盖力受基层影响大 | 大面积墙面与顶面 |
| 艺术漆 | 多种肌理（刮涂、批刮、滚涂） | 质感强、装饰性高、耐脏性较好 | 成本高、手法要求高、修补困难（局部补色痕迹明显） | 背景墙、局部造型墙 |
| 硅藻泥 | 无机类，肌理明显 | 透气、调湿、无明显光泽 | 怕水、耐擦洗差、遇水易粉化 | 卧室、追求质感且不常擦拭的墙面 |
| 贝壳粉 | 无机类，细腻肌理 | 质感细腻、透气 | 耐擦洗差、怕水、部分产品易掉粉 | 局部造型、儿童房（需确认产品说明） |

**关键差异**：艺术漆与硅藻泥的"难修补"必须提前知道。乳胶漆局部补一块相对不显眼，艺术漆局部补一块几乎必然留下色差与手法痕迹。

## 二、环保指标应该怎么看口径

**数值随现行国家标准与产品实际变化，本表不写死数值，以现行国家标准和检测报告为准。**

| 指标 | 该看什么 | 常见误区 |
|---|---|---|
| VOC | 检测报告中的实测值与检测方法；单位与限值口径 | 把"低 VOC"当成"无 VOC" |
| 甲醛与甲醛释放 | 区分"甲醛含量"与"甲醛释放量"，两者检测方法不同 | 把"未检出"当成"零添加" |
| 有害物质限量 | 是否属于现行国家标准规定的指标项目 | 用"某国标准"暗示高于国标 |
| 耐擦洗次数 | 次数对应特定测试方法下的结果 | 直接把次数当作日常耐擦能力 |
| 抗霉菌 | 是否有对应检测与等级 | 把"添加防霉成分"当成"经过检测" |

### 看检测报告的四个动作

1. 确认报告对应产品型号与批次，不是同系列另一款
2. 确认检测依据的是现行国家标准
3. 确认单位与检测方法，避免拿不同口径的数值横向比较
4. 有条件时看报告出具机构，不接受只有产品宣传页的说法

**"未检出"不等于"零添加"**：前者表示低于检测方法下限，不表示配方里完全没有。

## 三、基层处理要求

| 检查项 | 方法 | 要求 |
|---|---|---|
| 空鼓 | 敲击听空音 | 有空鼓必须先处理 |
| 裂缝 | 目视，重点看新旧裂缝 | 裂缝先按性质处理，未处理的裂缝会继续开裂 |
| 渗水痕迹 | 检查水渍、泛碱、返潮 | 有渗水必须先解决漏源 |
| 旧漆状况 | 检查是否起壳、粉化、空鼓 | 粉化层需铲除至坚实基层 |
| 平整度 | 侧光观察 | 明显凹凸需先用腻子找平 |
| 清洁度 | 检查油污、灰尘 | 有油污的基层需先处理 |

腻子的干燥时间与打磨要求以产品说明书为准。没干透就刷漆是起皮常见原因之一。

---

## 四、环境条件对照

| 条件 | 要求方向 | 说明 |
|---|---|---|
| 温度 | 按产品说明书的施工温度范围 | 过低导致成膜不良、附着力差 |
| 湿度 | 按产品说明书要求 | 湿度过高干燥慢，易表干里不干 |
| 通风 | 施工时保持通风 | 有利挥发物扩散，但不等于通风能让不达标产品达标 |
| 干燥时间 | 每遍之间与最终成膜时间按说明书 | 干燥不足就涂下一遍或提前入住是常见问题 |
| 避开阳光直射与强风 | 施工时段选择 | 表面干燥过快造成表干里不干 |
| 成品保护 | 施工期间与养护期内 | 避免磕碰、沾水、覆盖未干表面 |

具体数值以产品说明书为准，不同产品差异较大。

## 五、DIY 面积与情形判断

| 情形 | 能否自己动手 |
|---|---|
| 局部修补（磕碰、污渍、小面积起皮） | 可以 |
| 单个墙面、面积不大、基层状况好 | 可以，但需注意干燥与养护 |
| 房间内多面墙或含顶面 | 难度与工程量明显上升 |
| 需铲除旧漆至基层 | 转专业施工 |
| 整户翻新或面积很大 | 转专业施工 |
| 基层有空鼓、裂缝、渗水痕迹 | 先处理基层，必要时转专业 |
| 需高处作业 | 转专业施工 |

**判断四项**：面积、基层状况、是否需要铲除、是否高处作业。任一项落到转专业就不要自己做。

## 六、施工安全

| 人群或情形 | 要求 |
|---|---|
| 孕妇 | 避免接触涂料与施工区域，施工期间离开该房间，充分通风后再进入 |
| 婴幼儿 | 施工期间不在该房间活动 |
| 呼吸道敏感者、哮喘患者 | 不参与施工；施工期间不进入该房间 |
| 高处作业 | 转专业施工，不自行搭梯或站在家具上 |
| 通风条件差的密闭空间 | 不施工，先改善通风 |
| 皮肤敏感者 | 佩戴手套，避免长时间接触未干涂料 |

通用要求：开窗通风，佩戴手套口罩，涂料保持原包装，剩余涂料按说明书处理。

## 七、常见失败原因与责任归属参考

| 失败现象 | 常见原因 | 责任归属参考 |
|---|---|---|
| 起皮 | 基层不牢、有渗水、旧漆粉化未铲除、干燥不足 | 视情况属基层处理或施工方 |
| 开裂 | 基层裂缝未处理、材料收缩、干燥过快 | 裂缝未处理属施工方 |
| 流挂 | 一次涂刷过厚或未按说明书配比 | 施工方 |
| 透底 | 遮盖力不足或底色面色差异大、未按说明书配比 | 施工方或选型问题 |
| 色差 | 不同批次混用、涂刷不均、光线不同 | 批次混用属施工方；同批号轻微色差属常见现象 |
| 发花 | 水分或助剂分布不均、施工环境湿度过高 | 施工方 |
| 掉粉 | 基层粉化未处理、产品附着要求不满足 | 基层问题或选型问题 |
| 龟裂 | 厚涂、干燥过快或过厚 | 施工方 |

责任归属的最终认定以施工合同约定、现场记录、产品检测报告与专业检测结论为准。

## 八、验收标准

| 验收项 | 方法 | 合格表现 |
|---|---|---|
| 外观 | 正常光线下目视 | 颜色均匀，无明显接茬、色块、流挂、发花 |
| 平整度 | 侧光观察 | 无明显凹凸、波浪、颗粒不均 |
| 附着 | 手指轻触（非破坏性） | 干燥后不轻易脱落、不掉粉 |
| 气味 | 靠近闻 | 无明显刺激性气味残留 |
| 干燥程度 | 按说明书时间后检查 | 达到规定时间后表面已充分干燥 |
| 成品保护 | 目视 | 无磕碰、沾污、未干被覆盖痕迹 |

**"无味"不等于"达标"**：气味强弱受通风、温度、涂刷量与配方影响。是否达标涉及检测，结论以有资质的检测为准。

## 九、必须转专业涂装的情形

1. 单个房间面积较大且需要整体重做
2. 需要铲除旧漆至基层（尤其涉及旧漆含铅等历史情况）
3. 基层有空鼓、开裂、渗水痕迹
4. 墙面有结构裂缝或墙体渗水
5. 需要高处作业（层高较高、需搭梯或吊顶作业）
6. 房屋有孕妇、婴幼儿、呼吸道敏感者居住且面积较大
7. 涉及租客与房东的墙面责任与恢复原状争议

## 十、常见误判清单

1. 把"零甲醛"当成"零添加"——未检出只表示低于检测下限
2. 拿 A 产品报告说 B 产品安全——必须对应型号与批次
3. 基层没处理就刷——成片脱落后果更贵
4. 腻子没干透就刷漆——起皮常见原因
5. 墙上有渗水还刷漆——湿基层必起皮
6. 不同批次漆混用——同房间明显色差
7. 选艺术漆不考虑以后修补——局部补色痕迹明显
8. 硅藻泥用在高频擦拭区域——遇水易粉化
9. 通风半个月就认为达标——气味不等于达标
10. 孕妇在刷漆房间待着——必须离开
11. 站家具上刷高墙——高处作业转专业
