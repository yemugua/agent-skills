# 广告发布前合规自查与禁用词核查

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 按词库和规则扫描风险表达 | 代替广告审查机关、平台或监管部门的认定 |
| 区分绝对化用语、功效宣称、比较广告和风险等级 | 未核验证据就认可疗效、排名、销量或检测数据 |
| 输出改写建议、留证清单和内部复核意见 | 保证不被处罚、不被平台下架或不被投诉 |
| 提示医疗、药品、医疗器械、保健食品、特殊食品、教育培训、金融、房地产等特殊规则 | 处理专利、商标争议诉讼或监管调查的最终应对 |
| 整理整改、申诉和沟通材料 | 编造检测报告、销量、患者案例或授权证明 |

医疗、药品、医疗器械、保健食品、特殊医学用途配方食品、婴幼儿配方食品、农药兽药、金融、教育培训、房地产等受特别监管的品类，以及可能涉及未成年人保护、公序良俗或公共安全的表达，发布前应经法务、合规或主管部门核验。

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「这句话算不算极限词」 | 用，按上下文判断 |
| 「我们行业第一，可以写吗」 | 用，提示需可验证证据和限定语 |
| 「保健食品能不能写增强免疫力」 | 用，需与获批或备案内容一致 |
| 「教育培训能说保过吗」 | 用，属高风险承诺 |
| 「帮我写个绝对有效、根治的宣传语」 | 不用，明确拒绝 |
| 「已收到市场监管询问通知」 | 只做材料整理，建议转法务或律师 |

## 三、完整工作流

1. **建广告档案**：广告主、经营者、发布者、商品或服务、媒介、受众、发布地域和排期。
2. **分品类**：判断普通商品还是医疗、药品、医疗器械、保健食品、特殊食品、化妆品、教育培训、金融、房地产、酒类等受特别监管对象。
3. **扫表达**：按 `rules/ad-rules.md` 检查绝对化用语、极限词、医疗用语、功效宣称、比较广告、诱导性表述和未成年人相关表达。
4. **核证据链**：排名、销量、专利、检测、认证、数据来源、授权、案例与用户评价逐一要原始凭证，标注有效期和适用范围。
5. **查特殊规则**：医疗药品等需审查或批准的品类，先确认是否已取得相应审查证明或是否在禁止发布情形内。
6. **出风险分级**：红、橙、黄三级；红色先别发，橙色改后复核，黄色留证并谨慎表述。
7. **改文案**：保留真实卖点，去掉无法验证的绝对表述，加限定语、适用范围和提示语。
8. **留档**：保存终稿、证据、审批记录、发布时间、版本和平台规则，便于复查与整改。

## 四、核心规则与要件库

输出自查意见前，**必须先读**：

- `rules/ad-rules.md`：词库、分级口径、特殊品类规则、证据链、整改与救济。
- `templates/review-checklist.md`：广告审查台账、风险分级表、留证清单和整改记录。

不得只做关键词删除。「无副作用」「零风险」「未添加」等否定式表达同样可能是功效或安全承诺，不能因不含常见极限词就判定安全。

## 五、人工确认清单

- [ ] 广告主、商品、服务和媒介信息真实完整
- [ ] 所有排名、第一、销量、领先等表述有可验证来源和截止时间
- [ ] 功效、数据、专利、认证、检测报告在有效期内且适用范围匹配
- [ ] 医疗药品等特别监管品类已核验审查或批准状态
- [ ] 代言、用户评价、案例已取得授权且不虚构
- [ ] 价格、赠品、限时、清仓等促销信息真实可举证
- [ ] 未成年人、疾病、焦虑、歧视类表达已复核
- [ ] 终稿、证据、审批与发布日期已归档

## 六、最常见的坑

1. **只删极限词就以为安全**：没有证据的「领先」「首选」「销量领先」同样构成风险。
2. **把医疗用语用在普通商品**：普通食品、化妆品、日用品不得暗示治疗疾病或替代药物。
3. **普通食品说保健功能**：保健功能宣称与保健食品、特殊食品的批准或备案内容不一致时风险高。
4. **否定式承诺**：「无副作用」「吃不胖」「绝对安全」不是保守表达，仍是功效或安全保证。
5. **证据过期或范围不符**：检测报告型号、批次、有效期与广告商品不一致。
6. **比较广告不写范围**：未说明比较对象、时间、口径和数据来源。
7. **教育、金融、房地产承诺结果**：保过、保收益、包升值等表述风险极高。
8. **直播话术无留痕**：口播承诺、字幕、评论区回复均可能被认定为广告内容，需与脚本一致并存证。

## 七、边界与免责

本技能提供发布前自查与文案整理，不构成法律意见，不替代广告审查、行政认定或平台审核。禁用词、特殊品类规则、处罚标准与平台口径会随地区、时间和媒介变化，**以现行规定和当地主管部门要求为准**。不得用于虚构功效、伪造证据或规避监管。
