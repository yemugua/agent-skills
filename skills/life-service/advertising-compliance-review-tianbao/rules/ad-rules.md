# 广告合规自查规则表

> 词表和口径用于内部初筛，最终以现行规定和当地主管部门要求为准。

## 一、风险分级

| 等级 | 含义 | 处置 |
|---|---|---|
| 红 | 绝对化、无法验证的功效或结果承诺、特别监管品类缺少必要审查 | 先不要发布，补全证据或改稿 |
| 橙 | 需要限定语、数据来源、适用范围或授权 | 修改后由法务或负责人复核 |
| 黄 | 表述可保留，但需留证据并跟踪平台口径 | 留档发布，定期复查 |

## 二、高频风险表达

| 类型 | 典型表达 | 常见处理 |
|---|---|---|
| 绝对化用语 | 国家级、最高级、最佳、第一、顶级、极致、绝对、唯一、史无前例 | 删除或改为可验证事实并写明范围与时间 |
| 排名与领先 | 销量第一、行业领先、市场第一、遥遥领先 | 需权威可验证来源，写明统计口径、时间和范围 |
| 疗效宣称 | 治疗、根治、治愈、消炎、降压、抗癌、包好 | 普通商品禁用；特别监管品类须与审查内容一致 |
| 安全承诺 | 无副作用、零风险、绝对安全、不反弹、吃不胖 | 属安全或功效保证，应删除 |
| 结果承诺 | 保过、包就业、包收益、包升值、一次见效 | 教育、金融、房地产等品类高风险 |
| 比较广告 | 比某某好、效果最强、全网最低 | 写明比较对象、口径、时间和数据来源，不得贬损他人 |
| 焦虑与歧视 | 不用就完了、穷人别买、地域或性别贬损 | 删除，复核公序良俗与未成年人保护 |
| 促销诱导 | 清仓价、最后一天、原价虚高 | 价格、时限、库存真实可举证 |

## 三、否定式表达同样有风险

以下不含常见极限词，但仍可能构成功效或安全承诺，不能判定为安全：

- 「无副作用」「无依赖」「不含激素」——安全承诺
- 「不反弹」「不会复发」「无效退款」——结果承诺
- 「未添加蔗糖」——需核对含量与适用标准，不能暗示更健康或适用于特定人群
- 「不是药但效果一样」——暗示疗效

## 四、特殊品类规则

| 品类 | 关键核查 |
|---|---|
| 医疗、药品 | 是否取得相应审查证明；不得含保证治愈、有效率、利用代言或患者形象作证明等内容 |
| 医疗器械 | 与注册或备案的适用范围一致；不得超范围宣称 |
| 保健食品 | 不得声称疾病预防治疗功能；须与批准或备案内容一致并载明提示语 |
| 特殊医学用途配方食品、婴幼儿配方食品 | 按特别监管要求核验，不得与普通食品混同宣传 |
| 普通食品 | 不得宣称保健功能或疗效 |
| 化妆品 | 区分化妆品与医疗器械、药品边界；不得宣称医疗作用 |
| 教育培训 | 不得对升学、通过考试、就业等作保证性承诺，不得利用受益者名义作推荐证明 |
| 金融理财 | 不得承诺保本保收益或隐瞒风险 |
| 房地产 | 不得承诺升值、投资回报或隐瞒规划、学区等不确定信息 |
| 酒类 | 不得倡导过量饮酒或诱导未成年人 |

## 五、证据链清单

| 主张类型 | 至少需要的凭证 | 有效期与范围 |
|---|---|---|
| 排名、销量 | 第三方或权威统计来源、口径、时间 | 明确统计区间与范围 |
| 检测数据 | 检测报告原件，型号批次一致 | 核对有效期与适用标准 |
| 专利 | 专利证书、法律状态 | 核对有效性与类别 |
| 认证、荣誉称号 | 证书、授予单位、授予时间 | 核对是否在有效期 |
| 代言与案例 | 书面授权、真实使用记录 | 不得虚构或跨品类使用 |
| 用户评价 | 可追溯订单或反馈记录 | 不得刷单或选择性造假 |
| 价格促销 | 历史成交或标价记录 | 核对时限与库存 |

## 六、整改、申诉与救济

- 收到平台或监管提示后，先固定证据：终稿、发布时间、页面截图、视频、脚本、审批记录。
- 立即下架或修正高风险表述，保留修改前后版本和撤回记录。
- 整理事实说明：错误原因、影响范围、整改动作、已采取措施和责任人。
- 对平台处理有异议，按平台规则提交申诉材料；对行政处理有异议，按文书载明渠道依法申请复核、行政复议或诉讼。
- 建立前置审查台账，避免同一表述重复出现。

所有禁用词、特殊规则和处罚口径可能调整，**以现行规定和当地主管部门要求为准**。
