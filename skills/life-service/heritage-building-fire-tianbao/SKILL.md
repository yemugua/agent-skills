# 古建筑与文物建筑消防管理（heritage-building-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《文物建筑消防安全管理》（GA/T 1463）与《古建筑消防管理规则》，生成文物建筑消防清单：禁火管控、防雷、用电限负荷、专兼职消防队与避难。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 古建筑消防
- 文物建筑消防
- 寺庙消防
- 文保单位消防
- 木结构消防
- 宗教场所消防

## 三、工作流
1. 明确文物级别与建筑类型
2. 制定禁火/动火管控（香火灯烛定点看护）
3. 电气线路穿管与限负荷
4. 设置专（兼）职消防队或微型站
5. 防雷/避雷装置定期检测

## 四、核心内容（检查清单与判定）
GA/T 1463 要求文物建筑严格用火用电管理，宗教活动场所燃香点烛须定点看护；木结构建筑应控制电气负荷并设独立探测。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未明确文物级别/建筑类型 | 文保要求 |
| Q2 | FAIL | 未含禁火/动火管控（宗教活动用火） | 禁火 |
| Q3 | WARN | 未含电气线路穿管/限负荷 | 用电 |
| Q4 | FAIL | 未设专（兼）职消防队或微型站 | 扑救 |
| Q5 | WARN | 未含防雷/避雷装置检测 | 防雷 |

> 脚本 `heritage-building-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python heritage-building-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python heritage-building-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
