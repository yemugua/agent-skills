# 瓷砖美缝规则表

生成美缝方案前先读本文件，不要凭印象写。

## 一、三类材料特性对照

| 特性 | 填缝剂（水泥基） | 美缝剂（双组份树脂类） | 环氧彩砂 |
|---|---|---|---|
| 组成 | 水泥基粉末 | 树脂加固化剂双组份 | 环氧树脂加彩色砂粒 |
| 颜色 | 多为白、灰、黑 | 十几种以上，可选色卡 | 颗粒质感，颜色偏哑光 |
| 表面效果 | 哑光，颗粒感明显 | 光亮或半哑，质感细腻 | 哑光砂面，接近天然石感 |
| 防霉能力 | 弱，吸水率高 | 较强 | 强 |
| 耐水能力 | 弱，长期浸水易失效 | 中等 | 强 |
| 抗污能力 | 弱，易脏 | 较强 | 强 |
| 掉粉问题 | 常见 | 不易 | 不易 |
| 施工要求 | 较低 | 较高，需按配比调匀 | 较高，需清洗与固化控制 |
| 固化时间 | 数小时 | 通常需 24 小时以上 | 通常更长 |
| 适用区域 | 干区为主 | 干区与一般湿区 | 湿区、淋浴区、商用空间 |
| 成本 | 低 | 中 | 高 |

## 二、厨房卫生间环氧彩砂适用性判定

| 位置 | 是否适合环氧彩砂 | 说明 |
|---|---|---|
| 厨房墙面 | 适合 | 长期浸水少，环氧耐水优势能发挥 |
| 厨房地面 | 谨慎 | 有油污与频繁清洁需求，哑光砂面挂油后清洁难度上升 |
| 卫生间墙面 | 适合 | 有水溅但非持续浸水 |
| 卫生间地面（非淋浴区） | 适合 | 长期潮湿，环氧耐水优势明显 |
| 淋浴区地面 | 需慎重评估 | 长期持续浸水，材料表现取决于产品说明书，建议由施工方给出方案 |
| 阳台封闭区 | 适合 | |
| 阳台开放区 | 谨慎 | 紫外线直晒、温差大，材料老化加快 |
| 长期积水区域 | 不建议 | 应先解决积水与排水问题 |

**判断原则**：环氧彩砂优势是耐水防霉抗污；代价是成本高、施工要求高、哑光面在油污环境清洁难度大。先确认位置会不会长期泡水，再决定值不值。

## 三、施工前四项必检

### 1. 空鼓检查

- 方法：空鼓锤或硬币轻敲每块砖，听空音
- 判定：明显空音、手感松动、边缘翘起即为空鼓
- 处理：空鼓必须先返修，再谈美缝

### 2. 破损检查

- 检查边角崩缺、裂纹、釉面破损
- 处理：破损砖先更换或评估，缝隙施工掩盖不了砖体问题

### 3. 基层清理

- 方法：清理缝内残留、旧填缝、水泥渣、灰尘
- 要求：缝内无浮灰、无残留、旧缝清空到位
- 常见失败：清缝不彻底直接施工，新材料与旧界面结合差，后期整条脱落

### 4. 缝隙深度与干燥度

- 方法：确认缝宽在材料适用范围内；缝深满足产品说明书要求
- 要求：缝内必须干燥，有渗水或返潮的缝不能施工
- 常见失败：基层潮湿施工，水汽被封在里面，后期起鼓变色发黑

**补充必检**：确认瓷砖是否留缝。不留缝的无缝铺贴或密缝无法做美缝，强行施工只是覆盖表面。

## 四、五种不适宜美缝的情况

| 情况 | 原因 | 怎么办 |
|---|---|---|
| 后期还要在该区域铺地板或地板革 | 美缝层被覆盖并承受踩踏，开裂后影响铺装 | 该区域不做美缝，或推迟到铺装完成后处理 |
| 长期持续浸水且无法改善 | 材料长期浸泡老化，根源在防水与排水 | 先解决渗水与排水，再评估材料 |
| 瓷砖已经松动或空鼓 | 基层已失效，美缝层会随之开裂脱落 | 先做瓷砖返修 |
| 旧水泥填缝已满且未清理 | 新材料无法与旧界面结合 | 需清除旧填缝后再做，属破坏性操作，建议交专业施工 |
| 缝隙宽度超出材料适用范围 | 超宽容易脱落或收缩开裂 | 确认产品适用缝宽，必要时改用其他工艺 |

## 五、颜色选择搭配逻辑

| 原则 | 说明 |
|---|---|
| 深色砖配浅色缝 | 强化网格感，适合小砖与造型墙面 |
| 浅色砖配深色缝 | 视觉对比强，适合大规格砖与地面 |
| 同色系搭配 | 整体感强，适合大面积与极简风格 |
| 与主色调呼应 | 让缝色成为设计的一部分 |
| 地面深、墙面浅 | 常见搭配逻辑，地面耐脏，墙面清爽 |

选色以**实物色卡**为准，屏幕与实物有色差。同一区域尽量用**同一批次**，避免明显接缝。

## 六、常见失败原因对照

| 失败现象 | 常见原因 | 责任归属参考 |
|---|---|---|
| 整条脱落 | 清缝不彻底、基层有残留 | 施工方 |
| 局部开裂 | 固化时间不足被提前踩踏 | 施工方与使用方共同责任 |
| 表面起鼓脱胶 | 基层潮湿，水汽被封住 | 施工方 |
| 胶体溢出到砖面 | 施胶量过多，未按说明书控制 | 施工方 |
| 发黑变脏 | 填缝剂吸水或厨房油污；厨房地面选错材料 | 材料选型或施工方 |
| 掉粉 | 水泥基填缝剂用于湿区 | 材料选型 |
| 局部色差 | 不同批次混用 | 施工方 |

责任归属的最终认定以施工合同约定、现场记录与检测结论为准。

## 七、验收检查方法

| 检查项 | 方法 | 合格表现 |
|---|---|---|
| 外观饱满度 | 侧光观察缝隙表面 | 平顺饱满，无明显凹陷或鼓包 |
| 与砖面齐平 | 目视与手触 | 基本齐平，无胶体溢出到砖面 |
| 颜色一致性 | 对照色卡与相邻区域 | 同区域无明显色差 |
| 清洁度 | 手摸或白纸擦拭 | 表面不粘手、无残胶 |
| 固化程度 | 按说明书时间后再踩 | 达到规定时间后无变化 |
| 粘结强度 | 按产品说明书的方式检测 | 以说明书与施工方检测记录为准 |

**养护要求**：施工后按产品说明书给足固化时间，养护期内设围挡、不踩踏、不沾水、不放置物品。

## 八、必须转专业施工的情形

1. 瓷砖空鼓（敲击有空音、明显松动、边缘翘起）
2. 大面积（单个空间缝隙超过 30 平方米）
3. 淋浴区长期浸水
4. 旧缝已被水泥填满需要清除（破坏性操作）
5. 瓷砖已破损或基层开裂需返修
6. 涉及地暖回填层或地面基层问题

---

## 九、常见误判清单

1. 不检查空鼓就做美缝——基层已失效，缝跟着脱落
2. 缝里有残留直接施工——新贴旧，整条掉
3. 缝还潮着就施工——后期起鼓变色发黑，最难返工
4. 美缝第二天就踩——开裂最常见原因
5. 厨房地面用环氧彩砂——哑光面挂油后难清洁
6. 后期铺地板区域先美缝——开裂影响铺装层
7. 不同批次料混用——同区域明显色差
8. 只看屏幕选色——以实物色卡为准
9. 砖缝发黑就想重做——先分清污渍还是填缝失效
10. 认为美缝能掩盖瓷砖问题——砖体问题美缝改变不了
