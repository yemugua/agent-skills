# 瓷砖美缝与填缝核查（tile-grout-care）

美缝做得好不好，**八成在施工前的判断，不在施工本身**。砖缝没清干净、基层还潮着、瓷砖本身已经空鼓——这三样里只要有一项没处理，做完的美缝半年内就会出问题。

另一个高频误解是"厨房卫生间能不能用环氧彩砂"。答案是**要看具体位置和长期浸水情况，不是简单的一刀切**。

这个技能做五件事：**选材料类型** → **判断适用性** → **施工前四项必检** → **排除不适宜情况** → **验收**。

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 区分三类材料特性与适用场景 | ❌ 承诺美缝的年限与效果 |
| 判断厨房卫生间是否适合环氧彩砂 | ❌ 代替瓷砖铺贴返修与空鼓处理 |
| 给出施工前必检项与顺序 | ❌ 在瓷砖已松动或基层不干燥时指导施工 |
| 列出不适宜美缝的五种情况 | ❌ 指导拆砖、铲除旧缝等破坏性操作 |
| 给出验收检查方法 | ❌ 判断瓷砖本体质量与铺贴规范问题 |

**遇到以下情况，先停止美缝，转交瓷砖铺贴方或专业施工方处理：**

- **瓷砖空鼓**：敲击有空音、明显松动、边缘翘起
- **大面积**：单个空间缝隙超过 30 平方米
- **淋浴区长期浸水**：淋浴区地面、地漏周边
- **旧缝已被水泥填满**：需要先清除旧填缝才能做美缝
- **瓷砖已破损或基层开裂**：需要先返修
- 涉及**地暖回填层或地面基层**问题的处理

## 三、三类材料的特性对照

| 特性 | 填缝剂（水泥基） | 美缝剂（双组份树脂类） | 环氧彩砂 |
|---|---|---|---|
| 组成 | 水泥基粉末 | 树脂加固化剂双组份 | 环氧树脂加彩色砂粒 |
| 颜色 | 多为白、灰、黑 | 十几种以上，可选色卡 | 颗粒质感，颜色偏哑光 |
| 表面效果 | 哑光，颗粒感明显 | 光亮或半哑，质感细腻 | 哑光砂面，接近天然石感 |
| 防霉能力 | 弱，吸水率高 | 较强 | 强 |
| 耐水能力 | 弱，长期浸水易失效 | 中等 | 强 |
| 抗污能力 | 弱，易脏 | 较强 | 强 |
| 掉粉问题 | 常见 | 不易 | 不易 |
| 施工要求 | 较低 | 较高，需按配比调匀 | 较高，需清洗与固化控制 |
| 固化时间 | 数小时 | 通常需 24 小时以上 | 通常更长 |
| 适用区域 | 干区为主 | 干区与一般湿区 | 湿区、淋浴区、商用空间 |
| 成本 | 低 | 中 | 高 |

## 四、厨房卫生间能不能用环氧彩砂（重点）

**不能简单回答"能"或"不能"，要看具体位置。**

| 位置 | 是否适合环氧彩砂 | 说明 |
|---|---|---|
| 厨房墙面（瓷砖立面） | ✅ 适合 | 长期浸水少，环氧的耐水优势能发挥 |
| 厨房地面 | ⚠️ 谨慎 | 有油污与频繁清洁需求，哑光砂面挂油后清洁难度上升 |
| 卫生间墙面 | ✅ 适合 | 有水溅但非持续浸水 |
| 卫生间地面（非淋浴区） | ✅ 适合 | 长期潮湿，环氧耐水优势明显 |
| **淋浴区地面** | ⚠️ **需慎重评估** | 长期持续浸水，树脂类材料长期浸泡下的表现取决于具体产品说明；建议按产品说明书并由施工方给出方案 |
| 阳台封闭区 | ✅ 适合 | |
| 阳台开放区 | ⚠️ 谨慎 | 紫外线直晒、温差大，材料老化加快 |
| 长期积水区域 | ❌ 不建议 | 应先解决积水与排水问题 |

**判断原则**：环氧彩砂的优势是耐水、防霉、抗污；代价是成本高、施工要求高、哑光表面在油污环境下清洁难度大。**先确认位置会不会长期泡水，再决定值不值。**

## 五、施工前四项必检（这步跳过等于白做）

### 1. 空鼓检查

- 方法：空鼓锤或硬币轻敲每块砖，听空音
- 判定：出现明显空音、手感松动、边缘翘起即为空鼓
- 处理：**空鼓必须先返修，再谈美缝**

### 2. 破损检查

- 检查：边角崩缺、裂纹、釉面破损
- 处理：破损砖应先更换或评估，缝隙施工掩盖不了砖体问题

### 3. 基层清理

- 方法：用工具清理缝内残留、旧填缝、水泥渣、灰尘
- 要求：缝内无浮灰、无残留、旧缝清空到位
- 常见失败：清缝不彻底直接施工，新材料与旧界面结合差，后期整条脱落

### 4. 缝隙深度与干燥度

- 方法：确认缝宽是否在材料适用范围内；缝深是否满足产品说明书要求
- 要求：缝内必须干燥，**有渗水或返潮的缝不能施工**
- 常见失败：基层潮湿施工，水汽被封在里面，后期起鼓、变色、发黑

**补充必检**：确认瓷砖是否留缝。**不留缝的铺贴（无缝铺贴或密缝）无法做美缝**，强行施工只是覆盖表面。

## 六、五种不适宜美缝的情况

| 情况 | 原因 | 应该怎么办 |
|---|---|---|
| 后期还要在该区域铺地板或地板革 | 美缝层会被覆盖并承受踩踏，开裂后影响铺装 | 该区域不做美缝，或推迟到铺装完成后处理 |
| 长期持续浸水且无法改善 | 材料长期浸泡老化，且问题根源在防水与排水 | 先解决渗水与排水，再评估材料 |
| 瓷砖已经松动或空鼓 | 基层已失效，美缝层会随之开裂脱落 | 先做瓷砖返修 |
| 旧水泥填缝已满且未清理 | 新材料无法与旧界面结合 | 需清除旧填缝后再做，**这是破坏性操作，建议交专业施工** |
| 缝隙宽度超出材料适用范围 | 超出范围的宽度容易脱落或收缩开裂 | 确认产品适用缝宽，必要时改用其他工艺 |

## 七、颜色选择的搭配逻辑

| 原则 | 说明 |
|---|---|
| 深色砖配浅色缝 | 强化网格感，适合小砖与有造型需求的墙面 |
| 浅色砖配深色缝 | 视觉对比强，适合大规格砖与地面 |
| 同色系搭配 | 整体感强，适合大面积与极简风格 |
| 与主色调呼应 | 让缝色成为设计的一部分，而不是单纯的深色线条 |
| 地面深、墙面浅 | 常见搭配逻辑，地面耐脏，墙面保持清爽 |

**注意事项**：选色以实际**色卡**为准，屏幕与实物有色差。色差与批次差异属正常现象，**同一区域尽量用同一批次**，避免明显接缝。

## 八、常见失败原因对照

| 失败现象 | 常见原因 | 责任归属参考 |
|---|---|---|
| 整条脱落 | 清缝不彻底、基层有残留 | 施工方 |
| 局部开裂 | 固化时间不足被提前踩踏 | 施工方与使用方共同责任（未按说明书养护） |
| 表面起鼓脱胶 | 基层潮湿，水汽被封住 | 施工方（未检查干燥度） |
| 胶体溢出到砖面 | 施胶量过多，未按说明书控制 | 施工方 |
| 发黑变脏 | 填缝剂吸水或厨房油污；厨房地面选错材料类型 | 材料选型或施工方 |
| 掉粉 | 使用了水泥基填缝剂用于湿区 | 材料选型 |
| 局部色差 | 不同批次混用 | 施工方 |

> 责任归属的最终认定以**施工合同约定、现场记录与检测结论**为准，本表只作常见情形的对照参考。

## 九、验收检查方法

| 检查项 | 方法 | 合格表现 |
|---|---|---|
| 外观饱满度 | 侧光观察缝隙表面 | 平顺饱满，无明显凹陷或鼓包 |
| 与砖面齐平 | 目视与手触 | 基本齐平，无胶体溢出到砖面 |
| 颜色一致性 | 对照色卡与相邻区域 | 同区域无明显色差 |
| 清洁度 | 手摸或白纸擦拭 | 表面不粘手、无残胶 |
| 固化程度 | 施工后按说明书时间后再踩 | 达到说明书规定时间后无变化 |
| 粘结强度 | 施工方按产品说明书的方式检测 | 以产品说明书与施工方检测记录为准 |

**养护要求**：施工完成后按**产品说明书**给足固化时间，养护期内**设围挡、不踩踏、不沾水、不放置物品**。第二天就踩是最高频的失败原因。

## 十、脚本用法

```bash
python scripts/grout_material_check.py --text "厨房卫生间想用环氧彩砂"
python scripts/grout_material_check.py --file 情况.json --out 结果.md
```

| 参数 | 说明 |
|---|---|
| `--text` | 描述使用位置与瓷砖现状 |
| `--file` | 从文件读，支持 `.txt` / `.md` / `.json`（JSON 用 `{"desc": "..."}`） |
| `--out` | 结果输出路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本做三件事：按使用位置给出材料类型建议、命中不适宜情况时直接给出"先不要做"的结论、列出施工前必检项与验收项。

> 脚本是关键词匹配，**不等于现场判断**。空鼓、旧缝、干燥度这三项必须实际敲、实际看、实际确认。

## 十二、最常见的坑

**坑一：不检查空鼓就做美缝。**
空鼓区域的基层已经失效，美缝层跟着开裂脱落。做之前先敲一遍。

**坑二：缝里有残留就直接施工。**
旧水泥渣和浮灰不清干净，新材料贴不住，最后整条掉下来。

**坑三：缝还潮着就施工。**
水汽被封在里面，后期起鼓、变色、发黑。这是最难返工的一种失败。

**坑四：美缝第二天就踩。**
没到固化时间就踩踏，是开裂最常见的原因。按说明书养护。

**坑五：厨房地面用环氧彩砂。**
哑光砂面挂油之后清洁难度上升，厨房地面这种高频油污区域，填缝剂或美缝剂更合适。

**坑六：后期要铺地板的区域先做了美缝。**
覆盖后承受踩踏，开裂还会影响铺装层。施工前先想清楚后续工序。

**坑七：不同批次的料混着用。**
同区域出现明显色差。同一区域尽量用同一批次。

**坑八：选了颜色只看屏幕。**
色卡与实际有色差，到现场才发现不搭。选色以实物色卡为准。

**坑九：砖缝发黑就想重新做。**
先判断是污渍还是填缝剂本身吸水或失效，方法完全不同。

**坑十：认为美缝能掩盖瓷砖问题。**
破损、崩边、空鼓是砖体和铺贴的问题，美缝只能让缝好看，改变不了砖本身。

## 十三、边界与免责

- 本技能**不替代**瓷砖铺贴返修、空鼓处理与专业美缝施工
- 材料适用范围、固化时间与施工要求**以产品说明书为准**，不同产品差异很大
- 缝隙宽度、留缝做法等技术要求以**现行施工规范与产品说明书**为准
- 施工责任归属以**施工合同约定、现场记录与检测结论**为准
- 涉及卫生间防水的渗漏问题，应先按渗漏排查流程定位并处理
