# 概览：社保转移接续办理核查

## 解决什么问题

换城市工作的人，绝大多数不知道三件事：

1. 社保**不会自动转**，必须主动申请；
2. 男 50 / 女 40 后在非户籍地参保，建的是**临时账户**，外地年限转不进来——很多人材料交了一趟才知道白跑；
3. 退休前不算清**待遇领取地**，可能要来回补手续，甚至影响按哪里的标准计发。

本技能把这三件事连同材料、时限、断缴影响一次算清楚。

## 输入 → 输出

```
采集表（性别 / 出生年月 / 户籍地 / 参保地 / 各地年限 / 卡点 / 材料）
        │
        ▼
  ┌──────────────┐
  │ 硬性阻断检查  │  已领养老金 / 临时账户 / 重复缴费 / 欠费 / 领失业金
  ├──────────────┤
  │ 账户性质判定  │  首次参保时年龄 vs 男 50 女 40 门槛
  ├──────────────┤
  │ 待遇领取地    │  户籍地 → 满 10 年 → 回户籍地
  ├──────────────┤
  │ 能转什么      │  养老 / 医疗 / 失业 可转；工伤生育不转
  ├──────────────┤
  │ 材料 + 时限   │  45 个工作日，三段各 15
  ├──────────────┤
  │ 风险 + 待办   │  断缴影响、可执行动作
  └──────────────┘
```

## 和其他工具的区别

市面上的社保工具做的是**政策查询**（比例多少、在哪办）。本技能做的是**个案判定**：

- 给的是"你这种情况能不能办"，不是"转移政策是什么"
- 年龄门槛、10 年规则都是**可计算的硬逻辑**，不是查表
- 输出直接落到"下一步做什么"

## 不做的事

- 不内置任何城市的缴费基数、社平工资、医保最低年限
- 不代填政务表单、不代拟正式文书
- 不承诺办结时间与结果
- 用户没填的不猜

## 适用人群

跨省换工作的人、多地参保临近退休的人、转移申请被卡住的人、HR 与人事经办。
