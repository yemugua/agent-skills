# 社保转移接续办理核查

换城市工作后，社保**不会自动跟着走**。本技能把"要不要办、能不能办、办了会怎样"一次算清。

## 什么时候用

- 换城市工作，想把老家的养老/医保年限转过来
- 多地参保，不知道退休后在哪领养老金
- 转移申请被卡住，想知道卡在哪一段
- 担心断缴影响买房、落户、生育津贴、医保报销
- 快退休了，才发现年限散在好几个城市

## 怎么做

**第 1 步**：复制 `templates/社保转移信息采集表.md`，照实填。填不出来就留空，脚本会列成待办——**不要编**。

**第 2 步**：跑脚本

```bash
python scripts/transfer_check.py 采集表.md --base 2026-10-04 --out 核查报告.md
```

`--base` 是"以哪天为基准算年龄"，不填就用今天。`--json` 出摘要。

**第 3 步**：按报告第九段"待办动作"逐条执行。

## 核心判定规则

### 临时账户（最容易白跑）

男 ≥ 50 周岁 / 女 ≥ 40 周岁，在**非户籍地首次参保** → 建立临时基本养老保险缴费账户。

- 看的是**首次参保时的年龄**，不是现在
- 临时账户**只出不进**：外地账户转不进来
- 里面的钱和年限不作废，退休前转到真正的待遇领取地合并

### 待遇领取地（国办发〔2009〕66 号）

```
① 养老关系在户籍地？ → 是：户籍地
② 否：有没有某地累计缴满 10 年？ → 有：最后一个满 10 年的参保地
③ 都没有 → 回户籍地
```

"满 10 年"是累计，不要求连续。

### 能转什么

| 险种 | 结论 |
|---|---|
| 养老 | 可转：个人账户全额 + 统筹基金 12% |
| 医疗 | 可转：个人账户余额 + 职工医保年限累计（居民医保不累计） |
| 失业 | 可转：缴费年限累计（领金期间不能办） |
| 工伤 / 生育 | **不转**，新参保地重新参保 |

### 时限

新参保地发函 15 个工作日 + 原参保地出表 15 + 新参保地办结 15 = **45 个工作日**，实务常 1–3 个月。

## 输入 / 输出

| | 内容 |
|---|---|
| 输入 | 采集表 Markdown（性别、出生年月、户籍地、原/新参保地、各地缴费年限、卡点自查、材料） |
| 输出 | 十段报告：结论摘要 / 硬性阻断 / 账户性质 / 待遇领取地 / 能转什么 / 前置条件与材料 / 流程时限 / 风险 / 待办 / 纪律 |
| 退出码 | 0 正常；2 关键信息缺失（给提示串，不崩） |

## 边界与纪律

- **不内置任何城市的缴费基数、社平工资、医保最低年限**——各地差异极大，一律以参保地经办机构答复为准
- 年限、金额、账户性质只做**形式逻辑推演**，最终以经办机构核定为准
- 不代拟正式申请文书、不代填政务表单、不承诺办结时间
- 用户填什么就用什么，不补、不猜、不估算
