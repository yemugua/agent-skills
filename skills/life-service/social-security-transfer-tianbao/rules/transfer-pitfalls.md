# 社保转移：十个高频坑与自检

## 一、十个高频坑

| # | 坑 | 真相 | 怎么避 |
|---|---|---|---|
| 1 | "换城市会自动转" | **不会**。必须本人（或单位）主动申请，系统不会自动迁移 | 新参保当月就提交申请 |
| 2 | "医保年限清零了" | 不是清零，是**没办转移所以在新系统里看不到**。年限还在原地 | 办转移后合并显示 |
| 3 | "年龄大了跨省参保照样转" | 男 ≥50 / 女 ≥40 在非户籍地**首次**参保 = **临时账户**，外地账户转不进来 | 先确认账户性质，别白跑 |
| 4 | "重复缴费能全额退" | 重复时段的**统筹部分不退**，只清退个人账户部分，且只能保留一个参保关系 | 先办清退再转移 |
| 5 | "转移期间社保还在缴" | 转移本身**不产生缴费记录**。空窗期不缴就是断缴 | 离职前衔接好新单位增员 |
| 6 | "断几个月没事" | 断缴可能影响**购房、落户、摇号、子女入学**的连续缴费年限要求（尤其一线城市） | 先查当地连续缴费要求 |
| 7 | "办了养老就都办好了" | 医保、失业要**分别申请**，工伤生育根本不转 | 三件事分开提 |
| 8 | "领失业金期间也能转" | 领金期间**不能办**转移 | 领完或书面放弃后再办 |
| 9 | "退休当月去办就行" | 45 个工作日只是法定下限，实务常 1–3 个月，出问题还要补正 | 提前 1 年以上启动 |
| 10 | "灵活就业都能跨省转" | 部分城市对**灵活就业人员**跨省转移有额外限制，有的只受理单位职工 | 先打 12333 问参保地口径 |

## 二、断缴的连带影响（按影响面排序）

| 影响项 | 说明 |
|---|---|
| **医保报销** | 停保次月起待遇中断，转移期间看病全自费；重新参保可能有等待期 |
| **购房/落户/摇号资格** | 多数城市要求"连续缴纳 N 个月/年"，补缴通常**不算连续** |
| **生育津贴** | 要求分娩前连续参保满一定期限，断缴即不符合 |
| **工伤待遇** | 断缴期间发生事故，工伤保险基金不支付 |
| **养老累计年限** | 断缴只是不增加年限，**已缴年限不作废**（这条不用担心） |

**一句话**：养老断缴不亏年限，但医保断缴立刻不能报销，资格类（购房/落户/生育）最怕断。

## 三、转移前后的自检清单

**申请前**

- [ ] 新参保地已经有参保缴费记录
- [ ] 原参保地已停保
- [ ] 确认自己是不是临时账户（男 50 / 女 40 门槛）
- [ ] 确认没有重复缴费、没有欠费
- [ ] 想清楚转移哪些险种（养老 / 医疗 / 失业）

**申请后**

- [ ] 记下申请编号
- [ ] 第 15 个工作日：看有没有发出《联系函》
- [ ] 第 30 个工作日：看原参保地有没有生成《信息表》
- [ ] 第 45 个工作日：看是否办结，个人账户到账没有
- [ ] 转医保的：单独查医保进度

**办结后**

- [ ] 在新参保地系统上核对养老累计年限
- [ ] 核对医保累计年限（很多地方要手动申请年限认定）
- [ ] 核对个人账户余额是否与预期一致
- [ ] 有差错的，向新参保地经办机构提出复核

## 四、该认栽 / 别折腾的情形

| 情形 | 建议 |
|---|---|
| 原参保地年限极短（几个月）且年龄已过临时账户线 | 转移成本高于收益，可考虑放弃合并，但**先问经办机构** |
| 重复缴费时段很短 | 清退手续麻烦，算清退金额后再决定 |
| 已在领取养老金 | 办不了，不用提交了 |
| 两地都是城乡居民养老 | 城乡居民养老保险的关系转移规则与企业职工不同，按城乡居民办法办 |
| 距离退休只剩几个月 | 来不及走完 45 个工作日，先办待遇核定的咨询，别只盯转移 |

## 五、输出纪律

- 不代拟正式申请文书、不代填政务系统表单；
- 不承诺办结时间与结果，只给法定时限与常见区间；
- 不内置各城市缴费基数、社平工资、最低年限——一律标注"以参保地经办机构答复为准"；
- 涉及年限、金额、账户性质的判定，只做**形式逻辑推演**（年龄门槛、10 年规则），最终以经办机构核定为准；
- 用户填了什么就用什么，**不补、不猜、不估算**。
