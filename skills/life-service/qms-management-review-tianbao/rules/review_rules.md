# 管理评审规则库（review_rules）

> 本文件是 qms-management-review 技能的规则支撑。输入输出以 ISO 9001 现行版本为准。

## 一、法规依据速查

| 文件 | 关键要求 | 关联 |
|---|---|---|
| ISO 9001 | 9.3 管理评审：最高管理者按策划间隔评审体系 | 评审义务来源 |
| 单位体系文件 | 管理评审程序 | 执行口径 |

## 二、输入九项判定口径

| # | 输入 | 合格口径 |
|---|---|---|
| 1 | 内审结果 | 方案执行 + 不符合分布 + 闭环 |
| 2 | 顾客反馈 | 满意度 + 投诉 + 交付 |
| 3 | 过程绩效与产品符合性 | 目标达成率 + 数据 |
| 4 | 不符合与纠正措施 | 趋势 + 重复问题 |
| 5 | 监视测量结果 | 指标趋势 |
| 6 | 供方绩效 | 来料/交付/服务 |
| 7 | 变更与风险 | 内外变化 + 应对 |
| 8 | 改进机会 | 提案 + 标杆 |
| 9 | 资源需求 | 人员/设备/资金 |

判定：缺项 FAIL；只有文字无数据 WARN。

## 三、会议流程口径

1. 会前 2 周发议程与材料
2. 议程：总评 → 逐项输入 → 专题 → 决议
3. 最高管理者主持决策
4. 决议可执行、有责任人、有期限、可验证
5. 签到与决议记录

## 四、报告要素

目的/时间/地点/参加人；输入逐项评述；三性结论（适宜/充分/有效）；目标达成与调整；输出三件套（改进机会/变更需求/资源需求）；决议清单；上次决议回顾。

## 五、决议跟踪口径

决议 → 责任人 → 期限 → 证据 → 管理者代表验证 → 下次评审回顾。完成率纳入下年输入；跨年决议需原因说明。

## 六、常见不合规情形

- 输入材料无数据
- 会议开成汇报会
- 决议无责任人无期限
- 一年只开一次且无中期复盘
- 上次决议不回顾
