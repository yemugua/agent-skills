# 保险免责条款阅读规则库

> 本规则库按保险合同的常见结构整理。**责任免除、免赔、给付比例、限额与等待期均以保险合同条款为准**；**格式条款的解释适用以现行法律规定与司法实践为准，由司法机关认定**。本库**不对具体情形下赔或不赔下结论**，不承诺理赔结果，不编造条款号与疾病定义编号。

---

## 一、定位方法（六步）

```
第 1 步  检索关键词：责任免除、不承担、除外、免除责任、拒赔
第 2 步  记下每一处所在的章节名与页码
第 3 步  逐条抄录原文，不改写、不概括
第 4 步  标出每条里的限定词：时间、次数、金额、医院范围、诊断标准
第 5 步  归类到七类框架中
第 6 步  交叉核对保险责任条款，看同一事项在两处的表述是否一致
```

**必须说明**：**抄原文，不改写**。免责条款里的每个限定词（多少天内、几家医院、什么诊断标准、什么金额以下）都直接决定结论，**概括会丢掉关键信息**。

**不要只看主险条款**：附加险、特别约定、批单都可能改变责任范围。

---

## 二、七类免责归类框架

| 类别 | 常见表述方向 | 投保前必须问清 |
|---|---|---|
| **既往症类** | 投保前已存在的疾病、症状、检查异常、就诊记录 | 「投保前的就诊与体检记录算什么口径」「多早之前算既往」 |
| **先天与遗传类** | 先天性、遗传性疾病 | 「家族史算不算」「确诊年龄有限制吗」 |
| **特定疾病类** | 条款单独列明的特定疾病或特定状态 | 「列了哪几种」「和我有什么关系」 |
| **特定行为类** | 特定时间段内的特定行为、危险活动、酗酒等 | 「时间窗口多长」「哪些行为算」 |
| **非约定原因类** | 非合同约定的疾病、非约定的诊疗方式 | 「必须达到什么诊断标准」 |
| **主观故意类** | 故意行为、欺诈行为 | 「主观故意的判定标准是什么」 |
| **未按约就医类** | 未按约定期限就医、擅自中断治疗等 | 「间隔多久算未按约就医」 |

**必须说明**：**以上是归类框架，不是判定标准**。某个具体情形是否落入免责，**以合同条款原文与保险公司的认定为准**。

## 三、量化约定清单

| 项目 | 核查点 |
|---|---|
| 免赔额 | 多少、是否按次、按年、按项 |
| 免赔率 | 百分之多少、是否与免赔额叠加 |
| 给付比例 | 赔多少比例、是否分档 |
| 给付限额 | 上限多少、是否分组限额 |
| 等待期 | 多少天、起算点、期满前出险的处理口径**以条款约定为准** |
| 医院范围 | 限公立二级及以上还是不限、是否含私立与境外 |
| 药品与器材范围 | 医保目录内还是含目录外、是否限指定药品 |
| 诊断标准 | 临床诊断还是病理确诊、是否要求达到特定分级 |

**计算口径**：

```
赔付金额 = 按责任范围计算后的金额 × 给付比例 − 免赔额 − 免赔额对应部分
```

**具体计算顺序以合同条款约定为准。** **不看这些数字，等于不知道自己能拿多少。**

## 四、格式条款的不利解释原则

```
对格式条款存在两种以上解释的，人民法院应当作出不利于提供格式条款一方的解释。
```

### 4.1 三条必读

1. **适用前提是「存在两种以上解释」**。条款含义清楚、没有争议的，不适用这一原则
2. **前提是「格式条款」**。双方协商起草的条款与保险公司单方拟定的格式条款，适用路径可能不同
3. **最终由司法机关认定**，不是投保人自行认定，也不是保险公司自行认定

### 4.2 禁止表述

| 禁止 | 原因 |
|---|---|
| 「条款对我不利，所以这条无效」 | 结论绝对化，适用前提不成立时不适用 |
| 「保险公司的条款都是无效的」 | 一刀切是错的 |
| 「按对我有利的解释就行」 | 不是投保人单方决定的 |

### 4.3 正确表述

> 「该条款存在两种以上解释的可能，按现行法律规定与司法实践，格式条款争议由人民法院作出不利于提供格式条款一方的解释；**具体适用以司法认定为准**。」

## 五、如实告知义务与责任免除的区别

| 项目 | 如实告知义务 | 责任免除条款 |
|---|---|---|
| 性质 | 投保人的**法定义务** | 合同约定的**不赔情形** |
| 触发时点 | **投保时** | **保险期间内出险时** |
| 后果 | 可能导致保险人不承担给付责任并解除合同 | 该情形不属保险责任范围 |
| 依据 | **法律规定 + 合同约定** | **合同条款** |
| 判定主体 | 保险公司核定，争议可诉 | 保险公司核定，争议可诉 |

**必须说明**：**这两条是不同的机制，不能混为一谈**。一个是「投保时没说」，一个是「合同说不赔」。**都可能导致拿不到赔款，但依据和时点完全不同**。

**表述纪律**：**「未如实告知」不能写成「已如实告知」**；**「属免责情形」不能写成「必然拒赔」**。

## 六、文件效力关系

| 文件 | 效力关系 |
|---|---|
| 特别约定 | **通常优先于一般条款约定** |
| 批单 | 对原保单的修改，**以批单载明的内容为准** |
| 附加险条款 | 与主险条款**一并构成完整责任范围** |
| 投保单与告知问卷 | 构成合同组成部分，**告知内容影响理赔判定** |

**不能只看主险条款就下结论。**

---

## 七、投保前重点核对十二项

| 序号 | 核对项 |
|---|---|
| 1 | 合同是**完整文本**（含附加条款、特别约定、批单），不是只有首页 |
| 2 | 「责任免除」章节已**逐页定位**，页码已记录 |
| 3 | 每条免责**已抄录原文**，没有被概括或改写 |
| 4 | 每条中的**限定词**已标出 |
| 5 | 七类归类完成，**与自身既往病史、职业、爱好、就医习惯相关**的条目已标出 |
| 6 | **保险责任条款**与责任免除条款已**交叉核对** |
| 7 | **免赔额、免赔率、给付比例、给付限额、等待期**已抄下具体数字 |
| 8 | **医院范围、药品范围、诊断标准**已核对 |
| 9 | **附加险、特别约定、批单**已一并核对 |
| 10 | **健康告知问卷**已逐问比对 |
| 11 | 合同全文与投保过程沟通记录**已留存** |
| 12 | 结论中**没有出现「一定赔」「一定不赔」**这类表述 |

## 八、防误伤（否定词）清单

| 见到这些情况 | 必须这样判 | 严禁这样写 |
|---|---|---|
| 条款含义清楚无争议 | 判为**不适用不利解释原则** | 「对我不利所以无效」 |
| 条款存在两种以上解释 | 判为**由司法机关作不利解释，结论待司法认定** | 「这条肯定无效」 |
| 落入免责情形 | 判为**属不赔情形，以条款与公司认定为准** | 「一定拒赔」 |
| 不属免责情形 | 判为**属保险责任范围，仍需按责任范围与量化约定计算** | 「一定全赔」 |
| 未如实告知 | 判为**可能导致不承担给付责任** | 「已如实告知」 |
| 已如实告知 | 判为**需核保结论确认** | 「肯定没影响」 |
| 等待期内出险 | 判为**处理方式以条款约定为准** | 「一定赔」/「一定不赔」 |
| 已扣免赔额 | 判为**已扣** | 「没扣」 |
| 未扣免赔额 | 判为**未扣** | 「已扣」 |
| 条款约定限公立医院 | 判为**限该范围，范围外不属约定责任** | 「任何医院都赔」 |
| 确诊 | 判为**确诊** | 「确诊＝达到合同诊断标准」 |
| 已受理理赔申请 | 判为**办理中** | 「已理赔完成」 |
| 已核定赔付 | 判为**已核定** | 「还在申请中」 |

## 九、争议处理路径与材料留存

### 9.1 材料留存清单

| 材料 | 留存理由 |
|---|---|
| 保险合同完整文本（纸质扫描件或电子件） | 责任范围与免责约定的直接依据 |
| 投保单与健康告知问卷 | 告知义务范围与填写内容 |
| 全部批单与特别约定 | 修改与特别约定优先于一般条款 |
| 缴费记录与保单状态记录 | 合同效力与已交保费 |
| 投保过程的沟通记录（聊天、邮件、录音说明其合法性） | 了解投保时的说明情况 |
| 病历、检查报告、诊断证明 | 保险事故的证明材料 |
| 索赔申请书与理赔通知书 | 核定结论与理由 |

### 9.2 处理路径

| 情形 | 路径 |
|---|---|
| 对免责条款归属有异议 | 先向保险公司书面提出复核申请并留存记录 |
| 收到拒赔通知 | 核对拒赔理由所依据的条款原文与量化约定 |
| 复核未果 | 走正规投诉渠道与调解机制 |
| 争议金额较大或已涉诉 | 咨询律师，走诉讼途径 |
| 格式条款效力有争议 | 由司法机关认定，**不是投保人自行认定** |

**不建议**：在争议未解决前签署任何放弃权利的文件；不要通过非正规渠道施压。

---

## 十、免责

本规则库为投保实践整理，**不构成保险代理、保险经纪或法律意见**。**责任免除、免赔、给付比例、限额、等待期与诊断标准均以保险合同条款为准**；**格式条款的解释适用以现行法律规定与司法实践为准，由司法机关认定**；**如实告知义务的判定与理赔结论以法律规定、合同约定与保险公司的核定为准**。本库**不对具体情形下赔或不赔下结论**，**不承诺理赔结果**，不编造具体条款号、疾病定义编号与产品名，不提供虚构事实、夸大伤情或骗保的任何方案。
