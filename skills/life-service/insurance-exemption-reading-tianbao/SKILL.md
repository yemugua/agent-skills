# 保险免责条款阅读核查

保险合同里最容易翻过去的一节，就是**责任免除**。它写得和正文一样正式，但决定了「什么情况不赔」。

不读这一节，等于不知道自己买了什么、也买了什么。

这个技能做五件事：**定位章节 → 逐条归类 → 对照自身 → 记住解释原则 → 留好争议路径**。

---

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 逐段定位责任免除章节并按类别归类 | 判断某个具体情形「赔」或「不赔」 |
| 说明格式条款争议时的不利解释原则口径 | 代替保险公司作理赔认定或拒赔决定 |
| 输出投保前必须重点核对的条款清单 | 承诺一定能赔、一定能争取到 |
| 提示争议处理路径与材料留存 | 编造具体条款号、疾病定义编号与产品名 |
| 解释常见免责类别的含义与边界 | 替代法律意见、代写诉讼材料 |
| 提示如实告知义务与免责的关联 | 提供任何虚构事实、夸大伤情或骗保的方案 |

涉及以下情形，应停下来交由保险公司理赔部门、专业代理人或律师处理：**理赔申请的受理与核定、拒赔通知的效力判断、争议金额较大的索赔、二次手术与复发认定、涉及诉讼的理赔纠纷、格式条款效力的司法认定**。

**绝对不做**：不承诺理赔、不下「一定赔」或「一定不赔」的个案结论。**责任免除以保险合同条款为准**；**格式条款的解释适用以现行法律规定与司法实践为准**。

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「免责条款怎么看」 | 用，给定位方法与归类框架 |
| 「这些情况赔不赔」 | 用，讲类别与口径，个案转专业渠道 |
| 「既往症赔不赔」 | 用，说明既往症类别的条款口径与边界 |
| 「投保前得过病会不会不赔」 | 用，讲告知义务与免责的关联 |
| 「条款看不懂」 | 用，逐段定位 + 归类 |
| 「保险公司说不赔怎么办」 | 用，给争议处理路径，不下结论 |
| 「格式条款是不是对我有利」 | 用，说明不利解释原则口径 |
| 「帮我看看这份条款」 | 用，出核查清单 |
| 「帮我写一份拒赔申诉」 | 只给路径与材料清单，实体主张交律师 |

## 三、完整工作流

```
第 1 步  取完整合同文本（含条款正文、附加条款、特别约定、批单）
第 2 步  读规则文件 rules/insurance-exemption-rules.md（定位方法、
        七类免责归类、不利解释原则、重点核对清单、防误伤清单、争议路径）
第 3 步  定位「责任免除」「不承担」「除外」等关键词所在章节，记下页码
第 4 步  逐条抄录免责项，按七类归类（既往症、先天与遗传、特定疾病、
        特定行为、非约定原因、主观故意、未按约就医）
第 5 步  对照自身情况：哪几条与自己的既往病史、职业、爱好、就医习惯相关
第 6 步  交叉核对：保险责任条款 vs 责任免除条款，看是否存在冲突表述
第 7 步  核对免赔额、免赔率、给付比例、给付限额、等待期等量化约定
第 8 步  核对特别约定与批单（特别约定的效力优先于一般约定）
第 9 步  输出重点核对清单 + 必须留存的材料 + 争议路径
第 10 步 涉及具体理赔认定的，明确转交专业渠道，不下个案结论
```

## 四、核心口径

### 4.1 责任免除的七类常见归属（用于定位，不是判定标准）

| 类别 | 常见表述方向 | 投保前必须问清 |
|---|---|---|
| **既往症类** | 投保前已存在的疾病、症状、检查异常、就诊记录 | 「投保前的就诊与体检记录算什么口径」「多早之前算既往」 |
| **先天与遗传类** | 先天性、遗传性疾病 | 「家族史算不算」「确诊年龄有限制吗」 |
| **特定疾病类** | 条款单独列明的特定疾病或特定状态 | 「列了哪几种」「和我有什么关系」 |
| **特定行为类** | 特定时间段内的特定行为、危险活动、酗酒等 | 「时间窗口多长」「哪些行为算」 |
| **非约定原因类** | 非合同约定的疾病、非约定的诊疗方式 | 「必须达到什么诊断标准」 |
| **主观故意类** | 故意行为、欺诈行为 | 「主观故意的判定标准是什么」 |
| **未按约就医类** | 未按约定期限就医、擅自中断治疗等 | 「间隔多久算未按约就医」 |

**必须说明**：**以上是归类框架，不是判定标准**。某个具体情形是否落入免责，**以合同条款原文与保险公司的认定为准**。

### 4.2 定位方法（可照着做）

```
第 1 步  检索关键词：责任免除、不承担、除外、免除责任、拒赔
第 2 步  记下每一处所在的章节名与页码
第 3 步  逐条抄录原文，不改写、不概括（概括会丢限定词）
第 4 步  标出每条里的限定词：时间、次数、金额、医院范围、诊断标准
第 5 步  归类到七类框架中
第 6 步  交叉核对保险责任条款，看同一事项在两处的表述是否一致
```

**必须说明**：**抄原文，不改写**。免责条款里的每个限定词（多少天内、几家医院、什么诊断标准、什么金额以下）都直接决定结论，**概括会丢掉关键信息**。

### 4.3 格式条款的不利解释原则

```
对格式条款存在两种以上解释的，人民法院应当作出不利于提供格式条款一方的解释。
```

**必须写清的三点**：

1. **适用前提是「存在两种以上解释」**。条款含义清楚、没有争议的，不适用这一原则
2. **前提是「格式条款」**。双方协商起草的条款与保险公司单方拟定的格式条款，适用路径可能不同
3. **最终由司法机关认定**，**不是投保人自行认定，也不是保险公司自行认定**

**绝对禁止**：

- 「条款对我不利，所以这条无效」——**结论绝对化**
- 「保险公司的条款都是无效的」——**一刀切是错的**
- 「按对我有利的解释就行」——**不是投保人单方决定的**

**正确表述**：「该条款存在两种以上解释的可能，按现行法律规定与司法实践，格式条款争议由人民法院作出不利于提供格式条款一方的解释；**具体适用以司法认定为准**。」

### 4.4 与如实告知义务的关联（必须讲清两者的区别）

| 项目 | 如实告知义务 | 责任免除条款 |
|---|---|---|
| 性质 | 投保人的**法定义务** | 合同约定的**不赔情形** |
| 触发时点 | **投保时** | **保险期间内出险时** |
| 后果 | 可能导致保险人不承担给付责任并解除合同 | 该情形不属保险责任范围 |
| 依据 | **法律规定 + 合同约定** | **合同条款** |
| 判定主体 | 保险公司核定，争议可诉 | 保险公司核定，争议可诉 |

**必须说明**：**这两条是不同的机制，不能混为一谈**。一个是「投保时没说」，一个是「合同说不赔」。**都可能导致拿不到赔款，但依据和时点完全不同**。

**表述纪律**：**「未如实告知」不能写成「已如实告知」**；**「属免责情形」不能写成「必然拒赔」**（免责条款本身仍可能有争议）。

### 4.5 量化约定（不能只看文字，还要看数字）

| 项目 | 核查点 |
|---|---|
| 免赔额 | 多少、是否按次、按年、按项 |
| 免赔率 | 百分之多少、是否与免赔额叠加 |
| 给付比例 | 赔多少比例、是否分档 |
| 给付限额 | 上限多少、是否分组限额 |
| 等待期 | 多少天、起算点、期满前出险的处理口径**以条款约定为准** |
| 医院范围 | 限公立二级及以上还是不限、是否含私立与境外 |
| 药品与器材范围 | 医保目录内还是含目录外、是否限指定药品 |
| 诊断标准 | 是临床诊断还是病理确诊、是否要求达到特定分级 |

**必须说明**：**赔付金额 = 按责任范围计算后的金额 × 给付比例 − 免赔额 − 免赔额对应部分**，具体计算顺序**以合同条款约定为准**。**不看这些数字，等于不知道自己能拿多少。**

### 4.6 特别约定与批单

| 文件 | 效力关系 |
|---|---|
| 特别约定 | **通常优先于一般条款约定** |
| 批单 | 对原保单的修改，**以批单载明的内容为准** |
| 附加险条款 | 与主险条款**一并构成完整责任范围** |
| 投保单与告知问卷 | 构成合同组成部分，**告知内容影响理赔判定** |

**必须说明**：**不能只看主险条款就下结论**。**附加险、特别约定、批单都可能改变责任范围**。

## 五、核心规则与要件库

出结论前，**必须先读**：

- `rules/insurance-exemption-rules.md`：责任免除定位方法、七类免责归类框架、量化约定清单、不利解释原则口径与适用前提、如实告知义务与免责条款的区别、投保前重点核对十二项、防误伤（否定词）清单、争议处理路径与材料留存清单。

**不得凭印象编造条款号或疾病定义编号**；**不得对具体情形下「赔/不赔」的结论**；**不得把「存在两种解释」写成「条款无效」**。

## 六、脚本用法

```bash
python scripts/exemption_scan.py --file case.json --out 免责条款核查清单.md
python scripts/exemption_scan.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：免责条款条目列表（每条含原文与章节页码）、保险责任条目、量化约定（免赔额、免赔率、给付比例、限额、等待期）、附加与特别约定清单 |
| `--text` | 直接给 JSON 字符串 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检 |

输入 JSON 示例：

```json
{
  "clauses": [
    {"text": "投保前已患有的疾病或症状，本公司不承担给付责任", "page": 12},
    {"text": "先天性、遗传性疾病不在保障范围内", "page": 12},
    {"text": "被保险人在合同生效之日起 90 日内确诊的，本公司不承担给付责任", "page": 12},
    {"text": "被保险人故意犯罪或抗拒依法采取的强制措施致死的，本公司不承担给付责任", "page": 13}
  ],
  "quantitative": {"deductible": 10000, "deductible_rate": 0.0,
                   "payout_ratio": 1.0, "payout_cap": 500000,
                   "waiting_days": 90},
  "riders": ["附加意外伤害保险条款"],
  "endorsements": ["特别约定：限公立二级及以上医院住院"],
  "profile": {"has_preexisting": true, "family_history": false,
              "age": 52, "job_risk": "low"}
}
```

脚本输出：免责条目归类结果、量化约定汇总与粗略赔付上限测算、与投保人情况相关的重点提示、附加与特别约定清单核对结果、必须向保险公司确认的问题，以及争议处理路径提示。

> 脚本按你提供的条款文本做**结构化归类与提示**。**责任免除以保险合同条款为准**；**赔付认定由保险公司依条款与事实核定**；**格式条款解释适用以现行法律规定与司法实践为准，由司法机关认定**。脚本不对具体情形下赔或不赔下结论，**不承诺理赔结果**。

## 七、人工确认清单（这步不能省）

- [ ] 合同是**完整文本**（含附加条款、特别约定、批单），不是只有首页
- [ ] 「责任免除」章节已**逐页定位**，页码已记录
- [ ] 每条免责**已抄录原文**，没有被概括或改写
- [ ] 每条中的**限定词**（时间窗口、次数、金额、医院范围、诊断标准）已标出
- [ ] 七类归类已完成，重点标出**与自身既往病史、职业、爱好、就医习惯相关**的条目
- [ ] **保险责任条款**已与责任免除条款**交叉核对**，无表述冲突未处理
- [ ] **免赔额、免赔率、给付比例、给付限额、等待期**已抄下具体数字
- [ ] **医院范围、药品范围、诊断标准**已核对
- [ ] **附加险、特别约定、批单**已一并核对，未只看主险
- [ ] **健康告知问卷**已逐问比对，确认无漏填错填
- [ ] 合同全文已**留存**（纸质扫描件或电子件），投保过程沟通记录已留存
- [ ] 结论中**没有出现「一定赔」「一定不赔」**这类表述

## 八、最常见的坑

1. **整节翻过责任免除。** 这一节格式和正文一样正式，很容易被跳过。**不读这一节，等于不知道自己买了什么，也买了什么。**
2. **只看主险条款。** **附加险、特别约定、批单都可能改变责任范围**。只看主险就下结论，风险很大。
3. **读的是概括版，不是原文。** 免责条款里的限定词——多少天内、几家医院、什么诊断标准、什么金额——**直接决定结论**。概括会丢掉关键信息。
4. **把免责和「没如实告知」当成一回事。** 一个是**投保时没说**，一个是**合同说不赔**。都可能拿不到赔款，但**依据和时点完全不同**。
5. **以为「条款对我不利所以无效」。** 不利解释原则的**前提是「存在两种以上解释」**，而且**最终由司法机关认定**，不是投保人自己说了算，也不能一刀切说所有条款都无效。
6. **不核对量化约定。** 免赔额、免赔率、给付比例、给付限额、等待期，这些数字直接决定**到手多少钱**。只看文字不看数字，等于不知道自己能拿多少。
7. **不核对医院范围。** 限公立二级及以上医院、是否含私立与境外、药品是否限医保目录内——**这些都可能让本来该赔的变成不赔**。
8. **把「确诊」当成「达到诊断标准」。** 有些条款要求病理确诊、有些要求达到特定分级。**确诊 ≠ 达到合同约定的诊断标准。**
9. **投保时不读，出险后才读。** 出险后再看条款，看到的就是自己当时没读的那一节。**投保时读，才有意义。**
10. **不留合同与沟通记录。** 争议时没有合同原文、没有投保过程记录，**说什么都缺依据**。
11. **拿销售的口头解释当依据。** 口头说明不构成合同内容，**理赔时看的是合同条款原文**。
12. **把免责当成「一定拒赔」。** 条款是否落入免责、条款本身是否有解释争议，**由保险公司认定、有争议由司法机关认定**，不是当事人自己下结论。

## 九、边界与免责

- 本技能用于条款结构化定位与投保前自查，**不构成保险代理、保险经纪或法律意见**，不替代保险合同的约定与保险公司的理赔核定
- **责任免除、免赔、给付比例、限额与等待期均以保险合同条款为准**；不同产品差异很大，不得互相套用
- **本技能不对具体情形下赔或不赔下结论**，不承诺理赔结果，不代替保险公司作理赔认定
- **格式条款的不利解释原则以现行法律规定与司法实践为准**，由司法机关认定；本技能只说明其**适用前提与口径**，不代替司法判断
