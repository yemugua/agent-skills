# 安全生产费用提取使用（safety-cost）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《企业安全生产费用提取和使用管理办法》，生成安全生产费用清单：提取依据与比例、使用范围（安全/培训/应急/隐患治理）、专账管理、使用记录与监督。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 安全生产费用
- 安措费
- 安全费用提取
- 安全投入
- 安全费用台账

## 三、工作流
1. 按行业确定提取依据与比例/额度
2. 明确使用范围（完善/改造/培训/应急/隐患治理）
3. 设立专账、专款专用
4. 建立使用记录与凭证
5. 内部监督与年度核算

## 四、核心内容（检查清单与判定）
财政部、应急部《企业安全生产费用提取和使用管理办法》规定不同行业提取标准（如矿山、危化、建筑施工）与专用范围，须专款专用、单独核算。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含提取依据与比例/额度 | 依据 |
| Q2 | FAIL | 未明使用范围（安全/培训/应急/隐患） | 范围 |
| Q3 | WARN | 未含专账管理与专款专用 | 专账 |
| Q4 | FAIL | 未含使用记录与凭证 | 记录 |
| Q5 | WARN | 未含监督与核算 | 监督 |

> 脚本 `safety-cost_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python safety-cost_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python safety-cost_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
