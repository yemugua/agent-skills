# 手机套餐资费与降套携号转网核查

话费越交越多，往往不是套餐月费涨了，而是超额、增值业务、副卡和宽带绑定叠加出来的。这个技能先按账单核算真实月均和年度支出，再逐项排查降套与携号转网的障碍，最后比较保号、低月租、融合套餐和携转的一年总成本。

## 你会得到什么

- 月度、年度真实支出核算和单位流量成本
- 套餐利用率判断：是否买多了或买少了
- 降套与携号转网的障碍清单和解除顺序
- 违约金、赠款返还、宽带解绑和终端处理提示
- 办理话术、留痕清单与运营商投诉、行业申诉路径

## 典型用法

适合话费逐年上涨、想降最低套餐、携号转网被拒、校园或合约套餐到期、被开通增值业务等场景。技能自带 Python 脚本，可按 JSON 档案核算支出并做内置自检。

## 边界

脚本只做算数与清单匹配，不查询运营商系统，不承诺办理成功。资费、合约、携转条件和申诉流程以现行规定和运营商、行业主管部门要求为准。
