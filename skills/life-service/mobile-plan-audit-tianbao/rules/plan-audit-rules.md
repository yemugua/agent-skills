# 手机套餐资费、降套与携号转网规则

> 资费、合约、携号转网条件与申诉流程以现行规定和运营商、行业主管部门要求为准。

## 一、真实支出口径

| 分项 | 计入方式 |
|---|---|
| 套餐月费 | 逐月实收，注意优惠期结束后恢复原价 |
| 语音超额 | 超出套餐的通话费 |
| 流量超额 | 超出套餐的流量费或提速包 |
| 增值业务 | 彩铃、云盘、会员、游戏、保险等 |
| 副卡与附加卡 | 每张卡的月费与共享资源 |
| 宽带与 IPTV | 融合套餐中的绑定费用 |
| 国际漫游与短信 | 单独统计 |
| 违约金与一次性费用 | 计入一次性成本，不摊进常规月均 |

月均支出 = 各月实付合计 ÷ 月数；年度支出 = 月均 × 12 + 已知一次性费用。套餐利用率按实际使用量与套餐内资源比较。

## 二、降套常见障碍

| 障碍 | 表现 | 处理方向 |
|---|---|---|
| 合约未到期 | 承诺在网、购机补贴、返费活动 | 核算违约金与已享优惠后选择等待或解约 |
| 宽带绑定 | 融合套餐含宽带、IPTV | 先确认能否解绑、移机或设备返还 |
| 副卡与亲情网 | 主号降套导致关联号码失效 | 先迁移或注销关联号码 |
| 集团或校园套餐 | 集团折扣、政企合约 | 向集团经办人或营业厅确认退出规则 |
| 增值业务 | 连续扣费的附加业务 | 退订并主张未经确认开通部分的退费 |
| 欠费或停机 | 号码状态异常 | 先结清欠费恢复正常状态 |
| 实名问题 | 证件过期或信息不符 | 先完成实名核验 |

## 三、携号转网障碍与顺序

常见核查项：号码为实名登记、处于正常使用状态、无欠费或已结清、无在网约定期限限制或已处理、无影响携出的绑定业务、距上次携转满足间隔要求。

建议顺序：

1. 通过官方查询方式确认携出资格，并保存查询结果与拒绝原因。
2. 先解绑宽带、副卡、亲情网、集团网等附加关系。
3. 处理合约、返费、终端补贴与违约金，取得书面或系统记录。
4. 结清欠费，确认号码状态、证件有效期和实名信息。
5. 再申请携出授权码并办理转入，保留授权码获取时间和有效期。
6. 转入后核对生效时间、余额、绑定业务和次月账单。

「未到期合约」「未解绑宽带」「未结清欠费」不能按关键词判为已满足，必须逐项有记录。

## 四、替代方案比较

| 方案 | 适合 | 一年成本关注点 |
|---|---|---|
| 保号低月租 | 极少通话和流量 | 月租、来电显示、最低消费 |
| 纯流量或互联网套餐 | 主要用流量 | 超额资费、速率限制、优惠期 |
| 家庭融合套餐 | 多人多终端 | 宽带、副卡、设备押金与返还 |
| 携号转网 | 长期资费偏高 | 转入优惠期、违约金、号码绑定迁移 |
| 双卡组合 | 工作号与生活号分离 | 两张卡总支出是否真的更低 |

比较口径应为一年总成本：月费 × 12 + 一次性费用 + 可能的违约金 − 可确认的返费。

## 五、办理时限、留痕与救济

- 营业厅或线上办理应取得办理回执、生效时间、工单编号和客服工号。
- 套餐变更通常在次月或约定时间生效，未收到生效短信前不要停止核对账单。
- 增值业务争议：先要求提供开通时间、开通方式和确认凭证，再主张退订与退费。
- 对运营商处理不满意：先向运营商投诉渠道反映并保存工单；仍未解决，可向通信行业申诉渠道反映，必要时向消费者组织或市场监管部门咨询。
- 所有沟通用文字留痕，电话沟通后补充确认短信或在线记录。
