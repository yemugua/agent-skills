# 手机套餐资费与降套、携号转网障碍核查

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 按你提供的账单核算月度与年度实际支出 | 查询运营商系统里的真实套餐、合约或账单 |
| 识别降套、解绑、携号转网的常见障碍和顺序 | 代你向运营商提交办理、解约或退订申请 |
| 输出替代套餐对比表和办理话术 | 承诺一定降到某个价格或一定携转成功 |
| 整理未经确认开通业务的退费与投诉路径 | 指导绕过实名、冒办、代客携转或违规操作 |
| 提示违约金、设备返还、宽带绑定等成本 | 代替运营商解释具体资费政策 |

涉及企业集团号、物联网卡、校园或政企合约、欠费停机、实名争议、号码被他人绑定、涉嫌诈骗停机或司法协查时，应直接通过运营商营业厅、客服或行业主管部门渠道处理。

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「每月话费一百多，能不能降到十几块」 | 用，先算真实支出与合约成本 |
| 「携号转网被拒，说有合约」 | 用，做障碍清单和解除顺序 |
| 「宽带和手机绑一起，想只留手机」 | 用，提示解绑与设备处理 |
| 「莫名其妙多了个增值业务」 | 用，整理退订、退费和投诉路径 |
| 「合约机提前解约要赔多少」 | 用，按你提供的合同条款估算 |
| 「帮我把别人的号转到我名下」 | 不用，明确拒绝 |

## 三、完整工作流

1. **建号码档案**：号码、运营商、套餐名称与月费、合约起止、终端补贴、宽带绑定、副卡数量、增值业务清单。
2. **取真实支出**：导入近 6 至 12 个月账单或手工录入月费、语音超出资费、流量超出资费、增值业务、违约金和一次性费用。
3. **算真实月均**：用脚本核算月均支出、年度支出、套餐利用率和单位流量成本，避免只看套餐月费。
4. **查障碍**：按 `rules/plan-audit-rules.md` 逐项核查合约、赠款返还、宽带绑定、亲情网、集团、欠费、实名和终端限制。
5. **做替代方案**：列出保号、低月租、互联网套餐、家庭融合套餐、携号转网等选项并比较一年总成本。
6. **排办理顺序**：先解次要障碍、再处理主障碍，最后办理降套或携转，避免同一天多点冲突。
7. **留痕与投诉**：所有办理请求记录时间、工号、渠道和答复；争议时按运营商投诉与行业申诉渠道逐级处理。

## 四、核心规则与要件库

生成资费对比或办理话术前，**必须先读**：

- `rules/plan-audit-rules.md`：资费口径、降套障碍、携号转网条件、违约金估算、被拒原因、办理时限与救济。
- `templates/audit-report.md`：账单调阅清单、替代方案对比表和投诉记录模板。

不得把「未到期合约」识别为「无合约」，不得把「已申请但未生效」当成「已办理成功」。

## 五、脚本用法

```powershell
& "C:\Users\Ti'an'bao\.workbuddy\binaries\python\versions\3.13.12\python.exe" "scripts\plan_calc.py" --selftest
& "C:\Users\Ti'an'bao\.workbuddy\binaries\python\versions\3.13.12\python.exe" "scripts\plan_calc.py" --file case.json --out out
```

| 参数 | 说明 |
|---|---|
| `--file` | 号码档案 JSON，字段见规则文件与脚本头部注释 |
| `--out` | 输出目录，默认 `out`，生成 `资费核查报告.md` |
| `--selftest` | 运行内置样例自检，结果写入 `scripts/_selftest_result.txt` |

脚本只做算数与清单匹配，不查询运营商系统，不判断你是否一定能办理成功。

## 六、人工确认清单

- [ ] 账单月份连续，没有漏月或跨月重复计入
- [ ] 套餐月费、超额、增值业务、违约金分别归类
- [ ] 合约起止月、赠款返还、终端补贴金额已核实
- [ ] 宽带、副卡、亲情网、集团网等绑定关系已列全
- [ ] 实名信息与证件有效期满足办理要求
- [ ] 携号转网资格查询结果与障碍原因已保存
- [ ] 替代方案按一年总成本比较，不只看月费
- [ ] 客服工号、办理时间、答复与工单编号已留痕

## 七、最常见的坑

1. **只看套餐月费**：超额流量、语音、增值业务和违约金才是大头。
2. **忽略合约赠款返还**：提前解约可能要返还已享优惠，实际成本高于表面违约金。
3. **宽带绑定没解**：融合套餐里的宽带、IPTV、副卡常是携转和降套的主障碍。
4. **副卡和亲情号没清理**：主号办理时，关联号码可能一起失效或继续计费。
5. **把「已申请」当「已生效」**：必须确认生效时间、生效短信和次月账单。
6. **号码状态异常**：欠费、停机、实名不全、挂失或司法限制都会阻塞办理。
7. **增值业务只退订不退费**：未经确认开通的业务，退订之外还应主张退费并保留证据。
8. **口头承诺不留痕**：营业厅口头同意降套，最后没办理成功时没有凭证，必须记录工号和工单。
