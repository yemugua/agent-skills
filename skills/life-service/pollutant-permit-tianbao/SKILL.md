# 排污许可管理（pollutant-permit）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《排污许可管理条例》与HJ 608，生成排污许可管理清单：许可证执行、自行监测、台账、执行报告（月/季/年）与合规自查。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 排污许可
- 排污证
- 自行监测
- 排污台账
- 执行报告
- 环保合规

## 三、工作流
1. 核对许可证载明事项与有效期
2. 制定自行监测方案（因子/频次）
3. 建立环境管理台账
4. 按期提交执行报告（月/季/年）
5. 合规自查与整改

## 四、核心内容（检查清单与判定）
《排污许可管理条例》要求按证排污、自行监测、建立台账、定期提交执行报告；台账保存≥5年，执行报告依许可证要求月/季/年提交。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未核许可证与有效期 | 条例 |
| Q2 | FAIL | 自行监测计划缺失（因子/频次） | 自行监测 |
| Q3 | FAIL | 未建环境管理台账 | 台账 |
| Q4 | WARN | 执行报告未按期提交 | 执行报告 |
| Q5 | WARN | 无合规自查/整改闭环 | 合规 |

> 脚本 `pollutant-permit_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python pollutant-permit_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python pollutant-permit_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
