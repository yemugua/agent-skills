# 计量确认（metrology-confirmation）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据 ISO 10012 与 JJF 1112《计量检测体系确认规范》，生成计量确认清单：确认依据（计量要求/校准规范）、确认间隔、状态标识、封缄保护、偏离处置。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 计量确认
- 测量设备确认
- 计量要求
- 校准状态
- 测量管理体系

## 三、工作流
1. 确定计量要求（准确度/范围/环境）
2. 选择校准规范并确认间隔
3. 实施校准并评定结果
4. 状态标识与封缄保护
5. 异常/偏离的处置与追溯

## 四、核心内容（检查清单与判定）
计量确认是确保测量设备符合预期使用要求的一组操作；包括校准、标识与封缄，偏离预期时应采取纠正措施并记录。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含确认依据（计量要求/校准规范） | 依据 |
| Q2 | WARN | 未明确确认间隔 | 间隔 |
| Q3 | FAIL | 未含状态标识（合格/限用/停用） | 标识 |
| Q4 | WARN | 未含封缄保护 | 封缄 |
| Q5 | FAIL | 未含偏离/异常处置 | 处置 |

> 脚本 `metrology-confirmation_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python metrology-confirmation_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python metrology-confirmation_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
