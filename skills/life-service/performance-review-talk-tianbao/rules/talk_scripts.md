# 绩效面谈话术脚本库

> 背熟三类。面谈时不要即兴组织语言。

---

## 一、面谈开场三句（固定用，不要自由发挥）

| # | 话术 | 目的 |
|---|---|---|
| 1 | 「谢谢您安排时间。我想先听一下您对这一周期的整体判断，我再讲我这边的情况。」 | 先取信息，避免先入为主 |
| 2 | 「这次的判定依据主要来自哪几个维度？各项的具体得分和扣分原因，方便的话请给我一份。」 | 取依据，后面一切的前提 |
| 3 | 「我先不解释，等您说完我再补充。这样效率更高。」 | 防止对话一开始就变成辩论 |

---

## 二、认可类话术（结果高于预期）

| # | 话术 | 意图 |
|---|---|---|
| 1 | 「谢谢。我自己复盘，超出预期的地方在 XX——我把 XX 环节前移了，单均耗时从 A 降到 B。」 | 让认可有具体锚点 |
| 2 | 「这条方法我在 XX 场景又用了一次，效果是 X。可以推广到 Y 场景。」 | 把一次好评变成方法论 |
| 3 | 「如果下周期要冲更高目标，我建议从 XX 入手，因为它同时影响 X 和 Y。需要您确认优先级。」 | 用好评换资源与授权 |
| 4 | 「有一点我想确认：这个结果的评定里，我 XX 方面的贡献计入了哪些？」 | 顺势核对口径，不显攻击性 |

**不要说**：「我本来就是干这个的」「主要靠我带着 A 做的」——把一次好结果变成个人英雄叙事，反而降低可信度。

---

## 三、改进类话术（结果低于预期）

### 五步结构

```
第1 步  接住结论
   「这个结果我接受。」（停两秒）

第2 步  定位差距到一个动作
   「从数据看，问题主要在 XX 环节：目标 A，实际 B，差距 C。
    根因是我在 XX 时间点才介入，错过了 XX 窗口。」

第3 步  把根因落在可控项
   「这部分是我能改的。下一阶段我改成 XX 机制，具体是……」

第4 步  给可验收的改进计划
   「下周期目标：X 指标达到 Y（当前 B）。三项动作：1.… 2.… 3.…
    希望 X 月中旬做一次中途对齐。」

第5 步  当场复述共识
   「我理解的改进项是这三个，有遗漏您指出来；下次对齐定在 X 月中旬对吗？」
```

### 根因句改写对照

| 禁止 | 改为 |
|---|---|
| 「因为产品需求变更频繁」 | 「需求变更 3 次，我在第 2 次后引入评审机制，后续变更导致的影响下降 X%」 |
| 「团队人不够」 | 「本月计划 5 项完成 3 项，剩余需 1 人 2 周或延至下月，您倾向哪个方案」 |
| 「我时间不够用」 | 「我的问题是没有区分优先级，按到达顺序处理。改为按影响面排序」 |
| 「我能力不够」 | 「我在 XX 环节缺少经验，计划用 X 方式补：跟做 X 项目 + 每周复盘一次」 |

## 四、申诉类话术（对结果有异议）

### 六步顺序（不可颠倒）

| 步 | 话术 | 目的 |
|---|---|---|
| 1 请对方给依据 | 「我想先理解判定依据。这个分数由哪几个维度构成？每项的具体得分和扣分原因能给我一份吗？」 | 很多异议在拿到依据后自然消失 |
| 2 摆事实 | 「关于 XX 维度，我有三条记录：X 月完成 A（工单 T123）、X 月完成 B（文档 D456，已评审）、X 月处理 C 共 N 件。这些是否被计入？未计入的原因是什么？」 | 只问「是否计入」「为什么」，不评价对方 |
| 3 收敛成口径差异 | 「我理解的口径是 X，贵方口径是 Y。差异导致我得分 A 而非 B。若以贵方口径为准我认可；若以我方口径，我请求重新核算。」 | 把争议从「谁错了」变成「口径不同」 |
| 4 提一个明确诉求 | 「我的诉求是：请复核 XX 维度的计分依据，并把复核结论书面反馈给我。」 | 诉求越具体越可能被执行 |
| 5 问下一步与时限 | 「如果本轮无法调整，我按制度在 X 日前提交书面申诉，受理人按制度是 XX。我会在 X 日前收到回复吗？」 | 记住制度里的回复时限 |
| 6 结束确认 | 「我理解今天达成的共识是：XX、XX、待办是 XX。我会后发纪要邮件，不准确的地方请您指正。」 | 当场留痕 |

### 四句禁语对照

| 禁语 | 为什么禁 | 替换 |
|---|---|---|
| 「你这是故意针对我」 | 动机指控，无法举证，对话终止 | 「我想理解这个判定的口径」 |
| 「凭什么他就有我没有」 | 变成人比人，偏离评价体系 | 「关于这个维度，我的记录是……」 |
| 「我不服，我要告你们」 | 把沟通变成对抗，对方只剩防御选项 | 「我按公司制度提交书面申诉」 |
| 「我在公司干了 X 年」 | 资历不等于绩效，强化印象偏差 | 「过去三个周期，我的 X 指标分别是 A、B、C」 |

## 五、僵局破法话术库

| 僵局表现 | 破法话术 |
|---|---|
| 对方开始讲个人情绪或旧账 | 「我理解。我们先把这次考核的 XX 维度对齐，其他的我另找时间单独聊。」 |
| 对方拒绝给依据 | 「我理解现在不方便给。那我按流程提交书面申诉，并在其中列明我的依据请求，可以吗？」 |
| 被问到完全没准备的点 | 「这个我需要回去确认，不现场给不确定的答案。我 X 日前书面回复您。」 |
| 自己情绪上来了 | 「我需要十分钟。」（然后离开现场，情绪在场内无法沟通） |
| 对方提出无法承受的改进项 | 「方向我认同，具体目标值我需要核算后 X 日回复，先记录下来。」 |
| 事实无分歧只对结论有分歧 | 「我们对事实没分歧，分歧在评价结论。结论以公司制度为准，我按申诉流程走。」 |
| 对方要求当场认错 | 「我可以承认结果，但我需要先拿到依据。这两件事我希望分开处理。」 |
| 谈崩无法继续 | 「今天先到这里。我会在 X 日前发纪要邮件，把我们的共识和不同意见写清楚。」 |

---

## 六、通用收尾句（任何场合都适用）

> 「今天的信息我记下来了。我会在 X 日前发一封纪要邮件，写明我们的共识和我的不同意见。如果有不准确的地方，请您指正。」

同时完成三件事：留痕、保留异议权、给对方一个低成本的回应通道。

## 七、不能说与能说对照总表

| 场景 | ❌ 不能说 | ✅ 能说 |
|---|---|---|
| 谈未达标 | 「这个也不是我能控制的」 | 「我复盘过，可控的部分是 X，我改的方式是 Y」 |
| 谈同事 | 「A 做得比我好太多了」 | 「按评价维度，我在 X 上的结果是 Y」 |
| 谈加班 | 「我加班最多」 | 「我在 X 环节的投入使单均耗时从 A 降到 B」 |
| 谈待遇 | 「所以是不是该给我加薪」 | 绩效面谈不谈薪酬，薪酬沟通另开一场 |
| 谈未来 | 「我以后会努力的」 | 「下周期 X 指标达到 Y，三项动作是……」 |
| 谈异议 | 「这明显不公」 | 「我请求复核 XX 维度的计分依据」 |
| 谈归因 | 「都是他们部门的问题」 | 「我需要改进的是我在 XX 环节的介入时机」 |
| 谈自己 | 「我可能不太适合这份工作」 | 「我想搞清楚标准差在哪，再决定怎么补」 |
