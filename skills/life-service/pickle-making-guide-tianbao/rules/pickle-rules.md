# 腌菜制作规则库

本文件是腌菜配比与安全判断的核心资产，先读再做判断。

## 一、盐与菜重量比

| 类型 | 盐占菜重 | 说明 |
|---|---|---|
| 泡菜/酸菜 | 2%–5% | 低盐发酵，靠乳酸 |
| 辣白菜 | 2%–3% | 短时发酵 |
| 咸菜/酱菜 | 10%–15% | 高盐保藏 |
| 糖醋腌 | 1%–2% + 糖醋 | 靠酸糖防腐 |

低于 2% 的盐量难以抑制杂菌，易臭坛软烂。

## 二、水盐浓度

- 泡菜盐水浓度建议 3%–6%（每升水 30–60g 盐）。
- 必须完全没过菜体，液面下用重物压实。
- 水需用凉开水或纯净水，忌生水。

## 三、发酵温度与天数

| 温度 | 表现 |
|---|---|
| 15–22℃ | 理想，缓慢发酵风味好 |
| <10℃ | 过慢，易生花 |
| >25℃ | 过快产酸、菜易软 |

食用建议：腌制 ≥20 天再食用，避开亚硝酸盐峰值。

## 四、亚硝酸盐峰值

- 一般第 3–8 天为峰值期，之后下降。
- 峰值期食用风险较高，建议避开。
- 本提示非绝对，受原料与温度影响，以久腌为稳妥。

## 五、变质信号判定

| 信号 | 处理 |
|---|---|
| 表面白膜（产膜酵母） | 可捞除，补盐并滴少许白酒，观察 |
| 变黏拉丝 | 整坛废弃 |
| 发臭/发酸异常 | 整坛废弃 |
| 菜体腐烂软糜 | 整坛废弃 |

## 六、常见不合格项与原因

| 现象 | 为什么不合格 | 处理 |
|---|---|---|
| 盐 <2% | 杂菌抑制不足，易臭坛 | 补盐至区间 |
| 菜露液面 | 接触空气发霉长白毛 | 压实没过 |
| 容器带油水 | 整坛污染 | 换无油生水容器 |
| 第 5 天食用 | 正值亚硝酸盐峰值 | 延至 20 天后 |
| 金属容器 | 腐蚀且影响安全 | 换玻璃/陶坛 |
| 发臭变黏 | 已腐败 | 整坛废弃 |
