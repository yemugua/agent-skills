# 腌菜制作

## 1. 硬边界表

| 能做 | 不能做 |
|---|---|
| 给盐与菜重量比、水盐浓度 | 替代你对原料新鲜度的判断 |
| 给发酵温度与天数区间 | 承诺「绝对无亚硝酸盐」 |
| 给亚硝酸盐峰值天数的安全提示 | 判断商业腌制品合规 |
| 给变质信号判定（白花/黏/臭） | 处理食物中毒事件 |

必须转交专业人士：出现食物中毒症状立即就医；对腌制品合规咨询市场监管部门。

## 2. 什么时候用

| 用户说法 | 用本技能 |
|---|---|
| 「腌菜盐放多少」 | 用 |
| 「泡菜几天能吃」 | 用 |
| 「腌菜长白膜了」 | 用（给判定口径） |
| 「亚硝酸盐高不高」 | 用（给峰值天数提示） |
| 「怎么卖腌菜赚钱」 | 不用，属商业 |

## 3. 完整工作流

1. 选新鲜蔬菜，洗净晾干表面水。
2. 按 `rules/pickle-rules.md` 称盐：泡菜盐比 2%–5%，咸菜可达 10%–15%。
3. 配盐水，保证完全没过菜。
4. 容器开水烫洗或无水无油，压实排气。
5. 控温发酵（15–22℃ 为宜）。
6. 记录天数，避开亚硝酸盐峰值期食用。
7. 对照人工确认清单核对后再食用。

## 4. 核心规则

先读 `rules/pickle-rules.md`：含盐量配比、水盐浓度、发酵温度、亚硝酸盐峰值天数（一般第 3–8 天为高）、以及变质硬性信号。

## 5. 脚本用法

```
python scripts/check.py --file 腌菜记录.json
python scripts/check.py --selftest
```

`--file` 含 salt_percent（盐占菜重百分比）、water_salt_percent、ferment_days、temp_c、signs（异常信号列表）。

## 6. 人工确认清单

- [ ] 盐占菜重是否 ≥2%（泡菜）或达标（咸菜）
- [ ] 盐水是否完全没过菜
- [ ] 容器是否无油无生水
- [ ] 发酵温度是否在 15–22℃
- [ ] 食用天数是否避开亚硝酸盐峰值（建议 >20 天）
- [ ] 有无白花/变黏/发臭信号

## 7. 最常见的坑

1. 盐太少（<2%）抑制不了杂菌，易臭坛、软烂。
2. 菜露在液面外，接触空气发霉长白毛。
3. 容器带生油生水，整坛污染。
4. 高温（>25℃）发酵过快产酸、易软。
5. 腌后第 3–8 天就吃，正值亚硝酸盐峰值。
6. 长白膜（产膜酵母）舍不得捞，扩散污染。
7. 用金属容器腌，腐蚀且影响风味安全。

## 8. 边界与免责

本技能为家常参考，不保证无亚硝酸盐。家庭腌制建议腌制 20 天以上再食用以避开峰值。出现白花可捞除并补盐白酒；变黏发臭则整坛废弃。
