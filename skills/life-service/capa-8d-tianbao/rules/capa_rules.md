# CAPA 规则库（capa_rules）

> 本文件是 capa-8d 技能的规则支撑。条款以 ISO 9001 现行版本为准。

## 一、法规依据速查

| 文件 | 关键要求 | 关联 |
|---|---|---|
| ISO 9001 | 10.2 不符合和纠正措施：评价、消除根因、防止再发 | CAPA 义务来源 |
| 单位体系文件 | 不合格品控制、纠正措施程序 | 执行口径 |

## 二、围堵/纠正/预防区分

| 类型 | 目的 | 判定口径 |
|---|---|---|
| 围堵 | 防流出 | 须临时、有退出机制 |
| 纠正 | 消除已发生根因 | 须更新文件 |
| 预防 | 防同类 | 须有横向展开记录 |

## 三、根因分析判定口径

- 5Why 至少 3 层，触系统层面（流程/设计/标准）
- 根因写"员工疏忽/意识不足"判深度不足
- 区分发生原因与流出原因
- 多因问题用鱼骨/树图

## 四、8D 九步检查口径

| 步骤 | 判定 |
|---|---|
| D0-D1 | 组队跨部门 |
| D2 | 问题描述 5W2H + IS/IS NOT |
| D3 | 围堵 + 验证 + 库存处置 |
| D4 | 根因（发生+流出） |
| D5 | 纠正 + 文件更新 |
| D6 | 预防 + 横向展开 |
| D7 | 标准化 + 培训 |
| D8 | 结案 + 经验沉淀 |

## 五、有效性验证口径

- 窗口 ≥3 个批次或 ≥1 个月
- 证据：后续数据、审核记录
- 未通过 → 重新分析、升级小组

## 六、常见不合规情形

- 围堵变长期全检
- 根因到人不到系统
- 措施不改文件
- 实施即结案
- 无横向展开
