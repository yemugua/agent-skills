# 西瓜视频下载与本地保存：途径、限制与合规边界

## 一、先判定：能不能下

| 归属类别 | 能否下载 | 允许的用途 |
| --- | --- | --- |
| 自有作品 | 可以，优先用原始导出文件 | 任意 |
| 已授权素材 | 可以 | 仅限授权范围内 |
| 作者开放了保存 | 可以，走官方途径 | 个人留存，**不得二次分发** |
| 第三方作品（未授权） | **不建议下载** | 不应用于任何对外场景 |

技术上能不能下载，和法律上能不能用，是两回事。

## 二、途径，按稳定性排序

| 途径 | 操作要点 |
| --- | --- |
| 原文件 | 优先。找发布时的原始导出成品（剪辑软件导出/本地素材库），画质无损无水印；若仍在，后面几条都不必尝试。 |
| 西瓜创作平台 | 登录**自己的账号**进入西瓜侧创作平台，在内容管理里管理已发布作品。仅限自有作品，入口以当前实际页面为准。 |
| 官方保存与App缓存 | 分享面板 → 保存到本地相册（作者开启时）；或在 App 内缓存后离线观看。缓存为加密分片，不可导出为通用文件。 |
| 通用命令行工具 | 本机需 Python + ffmpeg：`pip install -U yt-dlp`。常用形态：`yt-dlp -f "bv*+ba/b" <链接>`。对站点改版敏感，失效先升级。 |

## 三、本平台的真实限制

- 西瓜与抖音同属字节系，但**创作入口与后台并不通用**，账号体系、作品管理各自独立（具体入口以当前实际页面为准）。
- 西瓜以横屏中长视频为主，单个文件动辄数百 MB 到数 GB，批量下载要先算磁盘空间与耗时。
- 部分内容设置了「仅 App 可看」，网页端打开会提示在 App 内观看，这类内容无法用网页途径下载。
- 西瓜与今日头条的内容池互通，同一稿件在两头都能检索到，取网页端可正常打开的那个地址更稳。

## 四、画质与水印

- 西瓜支持较高码率上传，下载上限取决于作者上传的版本；中长视频建议选 720p 以平衡体积与清晰度。
- 水印为平台叠加的作者昵称与西瓜标识。自有作品请改用发布前的原始导出文件。

## 五、合规红线

1. 不得去除作者署名后二次分发
2. 不得将他人作品搬运至自己的账号（含剪辑、配音后发布）
3. 不得下载或传播私密账号、付费内容
4. 受版权或 DRM 保护的内容不支持下载，也不提供任何破解方法
5. 商用前必须取得书面授权
6. 批量高频抓取可能违反平台服务协议，导致账号受限
