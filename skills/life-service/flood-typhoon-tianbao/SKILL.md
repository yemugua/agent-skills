# 防汛防台应急（flood-typhoon）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据防汛防台应急管理要求，生成防汛防台清单：风险点排查（低洼/屋顶/门窗/广告牌）、应急物资与队伍准备、预警响应分级、值班巡查与信息报送、灾后恢复与复盘。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 防汛
- 防台
- 防汛防台
- 台风应急
- 汛期值班

## 三、工作流
1. 排查风险点（低洼/屋顶/门窗/广告牌）
2. 准备应急物资与队伍
3. 明确预警响应分级
4. 落实值班巡查与信息报送
5. 灾后恢复与复盘

## 四、核心内容（检查清单与判定）
防汛防台应汛前排查低洼积水、屋顶门窗与悬挂物等风险点，备好物资队伍，按预警分级响应并值班巡查，灾后及时恢复复盘。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含风险点排查 | 排查 |
| Q2 | FAIL | 未含应急物资与队伍 | 物资 |
| Q3 | WARN | 未含预警响应分级 | 预警 |
| Q4 | FAIL | 未含值班巡查与信息报送 | 值班 |
| Q5 | WARN | 未含灾后恢复与复盘 | 复盘 |

> 脚本 `flood-typhoon_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python flood-typhoon_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python flood-typhoon_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
