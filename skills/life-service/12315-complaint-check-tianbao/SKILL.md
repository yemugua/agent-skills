# 12315 投诉正确用法与维权路径

输入一份消费纠纷采集表，本 Skill 会告诉你：

- **12315 到底管不管**：劳资、婚姻、刑事诈骗、借贷、二手房、医疗、物业这几类不归 12315，会直接指错渠道（比如被诈骗立刻走 110）。
- **走「投诉」还是「举报」**：一般纠纷走投诉入口调解；涉嫌虚假宣传、价格违法、无照经营走举报入口立案查处，力度完全不同。
- **诉求站不站得住**：退款、退一赔三（欺诈）、退一赔十或 1000 元保底（食品安全）各有法定依据。
- **证据齐不齐**：订单号、支付凭证、聊天记录、商品照片、发票，缺哪样一清二楚。
- **怎么填、找谁办**：全国 12315 平台 / 热线 / 微信小程序的用法，材料清单与投诉话术三要素，调解不成怎么升级到法院。

## 适用场景
- 网购不发货、虚假宣传、七天无理由被拒
- 实体店买到假货、质量缺陷、商家跑路
- 预付卡（健身/美容/教育）余额不退
- 价格违法、宰客、食品安全问题

## 不适用
- 被电信诈骗转账 → 立刻 110 报案
- 劳资、婚姻、借贷、二手房、医疗纠纷 → 对应主管部门
- 本 Skill 不替代律师，最终以市场监管 / 司法认定为准

## 用法
把 `templates/12315投诉信息采集表.md` 填好，交给本 Skill 生成核查报告。字段未填一律按「待补正 / 有风险」处理，绝不判通过。
