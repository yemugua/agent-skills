## 提交前准备
- [ ] 商家准确全称 + 所在地（决定向哪个地区 12315 投诉）
- [ ] 订单号 / 合同号
- [ ] 支付凭证（转账 / 支付截图）
- [ ] 聊天记录（承诺、拒绝截图）
- [ ] 商品照片 / 视频
- [ ] 发票 / 收据（如有）
- [ ] 宣传页面 / 直播回放（如有虚假宣传）

## 渠道选择
- [ ] 一般纠纷 → 全国 12315 平台（网站/APP/微信小程序）「投诉」
- [ ] 涉嫌违法（虚假宣传/价格违法/无照）→ 同平台「举报」入口
- [ ] 不擅长手机 → 加区号拨 12315 热线
- [ ] 要曝光施压 → 黑猫投诉 / 消费保

## 话术三要素（写进投诉内容）
- [ ] ① 事实：何时何地买了什么、出了什么问题
- [ ] ② 依据：对应法条 / 平台规则
- [ ] ③ 请求：具体退款 / 赔偿金额

## 提交后
