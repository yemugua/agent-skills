# 维权路径与投诉话术

## 一、标准路径（七步）
1. 固定证据：合同、转账、聊天、商品图全部备份。
2. 先书面协商一次并留痕（部分平台要求先协商）。
3. 在全国 12315 平台（网站/APP/小程序）注册并提交投诉，填准商家名称与所在地。
4. 涉嫌违法经营 → 同步走「举报」入口要求立案。
5. 记下受理编号，7 个工作日后查进度。
6. 调解不成 → 准备向法院起诉（小额诉讼）。
7. 把本报告与所有材料存一个文件夹备用。

## 二、投诉话术三要素（照抄结构）
- **① 事实**：何时、何地、买了什么、出了什么问题（附证据编号）。
  > 例：2026-03 在抖音「型动健身」旗舰店购私教包，付 6800 元，一节未上商家失联。
- **② 依据**：对应法条或平台规则。
  > 例：依据《消法》第 53 条，经营者歇业应退还预付款。
- **③ 请求**：具体金额或动作。
  > 例：请求调解全额退款 6800 元。

避免情绪化描述（「骗子」「太气了」），事实清楚、请求具体才易被受理。

## 三、升级
调解不成或对结果不服，不影响另寻法律途径；就行政行为（如市场监管不作为）可申请复议。
