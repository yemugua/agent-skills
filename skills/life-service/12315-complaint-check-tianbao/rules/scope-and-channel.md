# 受理范围与渠道选择

## 一、12315 受理什么
消费争议：买商品 / 接受服务过程中发生的质量、虚假宣传、不发货、不退款、价格违法、食品安全等问题。

## 二、12315 不受理（本 Skill 会直接指错渠道）
| 情形 | 正确渠道 |
|---|---|
| 被电信诈骗 / 杀猪盘转账 | **立刻 110 报案**，12315 追不回赃款 |
| 工资、社保、劳动合同、工伤 | 劳动监察 12333 / 劳动仲裁 |
| 离婚、抚养、继承、家暴 | 法院民事诉讼 |
| 借钱不还、网贷 | 凭借条向法院起诉 |
| 二手房买卖、房东违约 | 住建部门 / 法院 |
| 医疗事故、误诊 | 卫健委 / 医疗纠纷调解委 |
| 物业费、停车费争议 | 业委会 / 法院 |

## 三、投诉 vs 举报（力度不同）
- **投诉**：针对你和商家之间的具体纠纷，由属地市场监管组织调解，目标是退钱赔钱。
- **举报**：针对商家违法经营行为（虚假宣传、价格违法、无照经营、假冒），由监管部门立案查处，可罚款吊销。**涉嫌违法时优先走举报**，比单纯调解更狠。

## 四、提交渠道
1. 全国 12315 平台：网站 ss12315.org / APP / 微信小程序「12315」，在线提交，自动分转商家所在地。
2. 12315 热线：加商家所在地区号（如上海 021-12315），适合不擅长手机操作的人。
3. 黑猫投诉 / 消费保：公开曝光施压。
4. 调解不成：向法院起诉（小额诉讼 50 元起步）或就行政行为申请复议。
