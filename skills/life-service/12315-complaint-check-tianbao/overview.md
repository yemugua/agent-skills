# 12315 投诉正确用法与维权路径

消费者最常用的维权入口是 12315，但绝大多数人用错了：把不归它管的事（诈骗、劳资、医疗）往里塞，或者只走「投诉」不知道还有「举报」入口，或者诉求写「讨个说法」而不是法定金额。

本 Skill 把《消费者权益保护法》《食品安全法》《市场监督管理投诉举报处理暂行办法》里和 12315 相关的通用规则，整理成一份「先判断受理范围 → 再选渠道 → 再定诉求 → 再备证据 → 再写话术」的结构化核查报告。

核心交付：
- 受理范围判定（含不受理情形的正确分流）
- 投诉 vs 举报的选择
- 法定诉求依据（退一赔三 / 退一赔十或千元保底）
- 证据清单与缺口
- 全国 12315 平台 / 热线 / 小程序用法
- 投诉话术三要素与升级路径

输入越具体，报告越准；未填项一律提示补正，不假判通过。
