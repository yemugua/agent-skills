# 网约车乱扣费 / 绕路 / 空驶费 维权

## 一、取证三件套（发现异常先做，别删行程）
1. **行程详情页截图**：起终点、时间、车型、司机。
2. **费用明细截图**：里程费、时长费、远途/夜间/动态溢价各项。
3. **地图轨迹截图**：规划路线 vs 实际行驶轨迹对比（绕路关键证据）。

## 二、止损顺序（按优先级）
1. **立即在 App 内申诉**：「我的 → 订单 → 该行程 → 客服 / 费用疑问」，勾选对应项：
   - 未乘车却扣费 → 选"未乘车"
   - 绕路多收 → 选"实际路线与规划不符"，上传轨迹对比
   - 空驶/取消费争议 → 选"不合理取消费"
2. **转人工**：机器人答非所问，反复发"人工客服"或打官方 95xxx 电话（滴滴 400-000-0999）。
3. **平台 24h 不处理或拒赔 → 升级**：
   - **12328**：交通运输服务监督电话（网约车属出租客运，最对口）
   - **12315**：属消费纠纷，微信/支付宝搜"12315"小程序投诉
   - **黑猫投诉**：新浪旗下，舆论压力倒逼，适合金额较大或平台推诿
4. **报警**：仅当涉及**人身安全、司机敲诈、恐吓**才打 110；普通费用纠纷不报警。

## 三、投诉话术模板（12315/黑猫用）
"本人于 X 月 X 日 X 时在 XX 平台（订单号 XXX）乘坐网约车，实际里程 X 公里，平台按 X 公里多收 X 元，且实际行驶轨迹明显绕路（附轨迹截图）。已联系平台客服 X 次未解决，现要求退还多收费用 X 元并道歉。"

## 四、常见结果
- 未乘车扣费：平台通常 100% 全额退。
- 轻微溢价争议：退差价或部分补偿券。
- 绕路多收：核实后退还多收里程费。

## 五、边界
- 不帮写虚假投诉、不伪造证据。
- 不接受"教用户故意绕路再投诉讹平台"类请求。
