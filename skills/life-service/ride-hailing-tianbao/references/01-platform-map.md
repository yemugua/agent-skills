# 主流网约车平台地图与入口

## 一、聚合平台（不直接派车，整合运力）
- **高德打车**：高德地图 App 内「打车」入口；整合滴滴/曹操/T3/首汽/阳光等数十家。投诉顺序：先找高德客服，再找实际承运商。
- **美团打车**：美团 App「打车」；同聚合逻辑，券与美团会员体系打通。
- **腾讯出行服务**：微信「我 → 服务 → 出行服务」或 QQ 内；聚合多家。

## 二、自营平台（自有/加盟运力，责任更集中）
- **滴滴出行**：运力最全，含快车/专车/豪华车/出租车。客服 400-000-0999，App「客服」在线。
- **曹操出行**：吉利系，新能源专车为主，车况统一。
- **T3 出行**：一汽/东风/长安背景，直营司机，安全标签重。
- **首汽约车 / 神州专车**：偏商务合规，发票规范。

## 三、低价拼车
- **花小猪**：滴滴旗下，便宜但规则更严，发票与客服走滴滴体系。
- **滴滴拼车 / 特惠快车**：同 App 内低价选项。

## 四、稳定入口索引（通用，版本差异以实际客户端为准）
- 客服/帮助：每个 App「我的 → 客服 / 帮助中心」
- 订单/行程：App「我的 → 订单 / 行程」
- 钱包/券：App「我的 → 钱包 / 优惠券 / 会员」
- 发票/报销：App「我的 → 发票 / 报销」
- 安全中心：App「我的 → 设置 → 安全中心 / 紧急求助」

## 五、搜索兜底
App 内搜索框输入「发票 | 投诉 | 优惠券 | 费用 | 行程」比翻菜单快得多。

## 六、校验方式
找到入口后看页面标题与实际诉求是否一致（如点"发票"进去是"开票记录"而非申请页，就回上一级重找）。不要凭记忆点旧路径——各 App 改版频繁。
