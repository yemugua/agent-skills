# 网约车使用与维权指南

> **5 句口诀**（3 秒判断要不要用我）：
> 1. 问题出在**滴滴 / 高德打车 / 花小猪 / 曹操 / 美团打车 / 腾讯出行 / T3** 等网约车平台 → 用我
> 2. 用户要**比价省钱、找优惠券、开发票报销、处理乱扣费/绕路、保障行程安全** → 用我
> 3. 用户要**刷单、扰乱平台定价、绕过平台私下交易、虚假投诉** → 拒绝，并说明原因
> 4. 涉及**钱（多扣费）**的先给"止损顺序"，再给"取证清单"，最后给"投诉路径"
> 5. 界面路径**只给层级方向 + 校验方法**，不假装知道用户手机上的确切按钮

## 一、这个技能解决什么

网约车不是一家，而是三类：**聚合平台**（高德/美团/腾讯出行，本身不派车，整合多家运力）、**自营平台**（滴滴/曹操/T3，自有或加盟运力）、**低价拼车**（花小猪、滴滴拼车）。同一个诉求（比如"被多扣钱"）在不同平台里的**入口、责任方、处理时效**完全不同，用户最常见的痛苦不是"不会点"，而是**不知道该找谁、证据怎么留**。

本技能用「稳定官方入口 + 通用定位法 + 止损顺序」帮你找到功能位置、理清投诉路径、明确合规边界。

## 二、平台地图（先分清你用的是哪类）

| 类型 | 代表 | 特点 | 出问题先找谁 |
|---|---|---|---|
| 聚合平台 | 高德打车、美团打车、腾讯出行 | 不直接派车，整合多家运力 | 先找聚合平台客服，再找实际承运商 |
| 自营平台 | 滴滴、曹操出行、T3 | 自有或加盟运力 | 平台客服 + 司机双线 |
| 低价拼车 | 花小猪、滴滴拼车 | 便宜但规则更严 | 滴滴体系客服 |

## 三、通用三步定位法（所有"找不到功能在哪"通用）

1. **打开对应 App → 我的 / 个人中心 → 客服 / 帮助中心**：90% 的"账单、优惠券、发票、投诉"入口都在这。
2. **搜关键词**：在 App 内搜索框输入"发票""投诉""优惠券""行程"，比翻菜单快。
3. **校验**：找到的入口看页面标题与你要办的事是否一致；不一致就回"我的"重找，别在三级页乱点。

## 四、高频场景处理路径

### 场景 A：叫车省钱（比价 + 优惠券）
- 比价：聚合平台（高德/美团）能一次比多家，优先用聚合叫车看总价。
- 优惠券：各 App「我的 → 钱包 / 优惠券 / 会员」；新人、通勤卡、企业版常更便宜。
- 拼车/特惠：非急就选"拼车""特惠快车"，价格低 20%–40%。
- **边界**：不引导刷券、不教绕过区域定价。

### 场景 B：乱扣费 / 绕路 / 空驶费（维权，按止损顺序）
1. **止损**：发现多扣先别删行程，截图「行程详情 + 费用明细 + 地图轨迹」三件套。
2. **定位**：在 App「我的 → 订单 / 客服 → 费用疑问」提交，勾选"实际路线与规划不符""未乘车却扣费"。
3. **找平台**：客服机器人答非所问就转**人工**（反复发"人工客服"或打官方 95xxx 电话）。
4. **升级**：平台 24h 内不处理或拒赔 → 12328 交通运输服务监督电话 / 12315（消费纠纷）/ 黑猫投诉。
5. **报警**：涉及**人身安全或敲诈**才报警，普通费用纠纷走上面。

### 场景 C：发票报销
- 入口：App「我的 → 发票 / 报销 → 开票」，选行程批量开**电子发票**，抬头填公司。
- 企业版：滴滴企业版、高德企业版可开**增值税专用发票**，需先认证企业。
- 校验：发票抬头、税号、金额与行程一致，报销前核对。

### 场景 D：行程安全
- 上车前：核对车牌、司机头像，分享行程给家人（App 内"共享行程"）。
- 途中：偏航/异常一键报警（App 内"安全中心/紧急求助"）。
- 下车：确认支付完成、车门锁好，贵重物品带齐。

## 五、司机侧（如果你是被咨询的司机）
- 抽成/派单规则：App「司机端 → 收入 / 规则中心」看抽成比例与奖惩。
- 封号申诉：违规封禁在「司机端 → 帮助 → 申诉」，按提示上传证据。
- 权益：社保/合同问题属劳动关系，平台只是信息中介，争议走劳动监察（12333）。

## 六、明确拒绝的
- 刷单、虚构行程套取平台补贴
- 教用户绕过平台私下交易、扰乱区域定价
- 帮写虚假投诉、伪造证据
- 破解/窥探他人行程数据
