# 标准化作业与 SOP（work-instruction）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据标准化作业要求，生成清单：作业步骤与节拍、关键控制点与参数、质量与安全要点、可视化与现场可得、版本更新与培训。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 标准化作业
- SOP
- 作业指导书
- 标准作业
- 作业标准

## 三、工作流
1. 梳理作业步骤与节拍
2. 明确关键控制点与参数
3. 纳入质量与安全要点
4. 实现可视化并现场可得
5. 版本更新并培训到人

## 四、核心内容（检查清单与判定）
标准化作业把最佳实践固化为可执行的步骤与参数；关键是关键控制点清晰、现场可视化可得，并随变更及时更新培训。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含作业步骤与节拍 | 步骤 |
| Q2 | FAIL | 未含关键控制点与参数 | 控制点 |
| Q3 | WARN | 未含质量与安全要点 | 要点 |
| Q4 | FAIL | 未含可视化与现场可得 | 可视化 |
| Q5 | WARN | 未含版本更新与培训 | 更新 |

> 脚本 `work-instruction_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python work-instruction_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python work-instruction_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
