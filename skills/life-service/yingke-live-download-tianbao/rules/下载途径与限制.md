# 映客直播回放留存与访问边界：途径、限制与合规边界

## 一、先判定：能不能下

| 归属类别 | 能否下载 | 允许的用途 |
| --- | --- | --- |
| 自有作品 | 可以，优先用原始导出文件 | 任意 |
| 已授权素材 | 可以 | 仅限授权范围内 |
| 作者开放了保存 | 可以，走官方途径 | 个人留存，**不得二次分发** |
| 第三方作品（未授权） | **不建议下载** | 不应用于任何对外场景 |

技术上能不能下载，和法律上能不能用，是两回事。

## 二、途径，按稳定性排序

| 途径 | 操作要点 |
| --- | --- |
| 原文件 | 优先。主播开播时的本地录制文件最完整清晰，若有本地录制，后面几条都不必尝试。 |
| 主播后台留存 | 登录自己的主播账号在直播管理里查看回放与数据，可下载或延长保留，这是主播最稳的做法。 |
| 官方回放入口 | 观众端在直播间或个人主页查看回放，取决于主播是否开启回放生成以及是否仍在保留期内。 |
| 通用命令行工具 | 需 Python + ffmpeg：pip install -U yt-dlp。仅对公开且未关闭保存的免费内容可能有效。 |

## 三、本平台的真实限制

- 回放不是必然生成：主播关闭回放功能或直播中断，就可能没有回放。
- 回放有保留期，过期会被清理，任何工具都拿不回来，只能靠提前本地录制。
- 付费直播、仅粉丝可见回放受访问限制，不支持下载或导出。
- 观众端回放画质受转码影响，低于主播本地录制原画质。

## 四、画质与水印

- 回放是平台转码版本，画质低于主播本地录制；主播应优先保留开播时的本地录制文件。
- 回放含主播署名与平台标识，转载需取得主播同意，不得去除署名后发布。

## 五、合规红线

1. 不得去除作者署名后二次分发
2. 不得将他人作品搬运至自己的账号（含剪辑、配音后发布）
3. 不得下载或传播私密账号、付费内容
4. 受版权或 DRM 保护的内容不支持下载，也不提供任何破解方法
5. 商用前必须取得书面授权
6. 批量高频抓取可能违反平台服务协议，导致账号受限
