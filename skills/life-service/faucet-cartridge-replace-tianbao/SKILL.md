# 水龙头漏水与阀芯更换（faucet-cartridge-replace）

水龙头漏水，**先看漏水的位置**。出水口滴、把手下方渗、底座一圈渗，是三种完全不同的故障，换阀芯只能解决其中一部分。不看位置就买阀芯，是最常见的白换。

这个技能做四件事：**看位置** → **判原因** → **认型号** → **规范换**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 按漏水位置判断故障部件 | ❌ 认定"漏水就是阀芯坏了" |
| 识别阀芯规格并指导选购 | ❌ 保证某型号一定通用（同尺寸也有孔位差异） |
| 给出拆装顺序与验收方法 | ❌ 处理墙内接头、角阀断丝、管路改造 |
| 提示什么情况必须停用并报修 | ❌ 建议用蛮力拧动锈死件 |
| 区分正常残水与真实滴漏 | ❌ 判断热水器、恒温阀等专用设备内部故障 |

**遇到以下情况，立即停止自行操作，转交专业维修人员：**

- 关闭角阀后**仍然出水**（角阀已失效，需先换角阀）
- 角阀、软管螺母锈死，或已经出现**滑丝、断裂**
- 墙面内的接头、预埋管件渗水（涉及破坏墙面，且可能扩大漏水）
- 需要拆台盆、拆橱柜、拆水槽才能施工
- 恒温龙头、感应龙头、抽拉式龙头的内部结构故障
- 阀体本体有裂纹、砂眼（只能整体换龙头，不是换芯）
- 热水侧施工前未关闭热水器电源 / 进水的情况

**永远不要在没关水、没泄压的情况下拆阀芯。** 带压拆卸会导致阀芯弹出、水喷到墙面与插座，存在触电与泡水风险。

## 二、完整工作流

```
第 1 步  关角阀（或总阀），打开龙头泄压，确认真的不出水
第 2 步  看漏水位置：出水口 / 把手下方 / 底座 / 软管接头
第 3 步  先读规则文件 rules/faucet_cartridge_rules.md（位置对照 + 型号识别 + 红线）
第 4 步  跑故障树脚本
    python scripts/faucet_leak_check.py --text "关紧后出水口一直滴，把手下面也湿"
第 5 步  拆下旧阀芯，带去比对买新件（不要凭目测尺寸网购）
第 6 步  按十步作业顺序更换
第 7 步  缓慢开阀，逐点验收：把手、压盖、底座、软管、出水口
```

## 三、漏水位置对照（决定换不换芯）

| 漏水位置 | 最可能原因 | 换阀芯有没有用 |
|---|---|---|
| 出水口关闭后持续滴 | 阀芯陶瓷片磨损、密封垫老化 | ✅ 有效 |
| 把手下方 / 阀体周围渗 | 阀芯外壳 O 圈老化 | ✅ 有效（O 圈随芯带） |
| 底座与台面接缝渗水 | 底座胶圈老化、台下锁紧螺母松 | ❌ 无效，紧螺母或换胶圈 |
| 进水软管接头滴水 | 垫片老化、螺母未到位 | ❌ 无效，换垫片或软管 |
| 出水小、水流分叉 | 起泡器结垢堵塞 | ❌ 无效，除垢即可 |
| 关水后滴几滴就停 | 起泡器与管内残水 | ❌ 正常现象，不用修 |
| 关不严且水压很高 | 进水压力过高 | ❌ 无效，需装减压阀 |

**判断要点**：擦干所有表面，用干纸巾逐个位置贴 5 分钟，看哪一张先湿。这是定位漏水点最可靠的方法。

## 四、阀芯规格识别（最容易买错的一步）

| 要素 | 怎么看 | 常见值 |
|---|---|---|
| 直径 | 卡尺或直尺量阀芯柱体 | 35mm 最常见，另有 40mm、25mm |
| 总高 | 量从底座到顶杆顶端 | 差异大，短了压不住，长了压盖装不回 |
| 齿数 | 数顶杆花键齿数 | 常见 20 齿、24 齿、28 齿 |
| 定位脚 | 看底部两个定位脚的间距与方向 | 不对位装不进去 |
| 进出水孔位 | 看底部孔的位置与形状 | 冷热反了会出冷水变热水 |
| 冷热标识 | 阀芯上的红蓝标记 | 装反会导致冷热水对调 |

**最可靠的办法：拆下旧阀芯，带着实物去比对。** 网购只看"35mm 阀芯"极易买错——同直径不同高度、不同孔位的产品非常多。

## 五、更换作业顺序（严格照做）

**工具与材料**：活动扳手（或小开口扳手）、内六角扳手、一字与十字螺丝刀、尖嘴钳、生料带、抹布、手电、白醋或除垢剂、旧牙刷、新阀芯、可选松动除锈剂。

1. **关水**：顺时针关紧角阀（没有角阀就关总阀）
2. **泄压**：打开龙头到冷热混合位，放尽余水，确认完全不出水
3. **断电**（热水侧）：热水器关电源、关进水，避免干烧
4. **取装饰盖**：用一字螺丝刀轻撬把手上的红蓝标识盖，露出固定螺丝
5. **卸螺丝**：十字或内六角，螺丝掉进下水口要先捞出来
6. **取把手**：垂直向上拔；锈住时用松动剂喷后等 10 分钟，**不要左右硬掰**（会把阀芯顶杆掰弯）
7. **拆压盖**：扳手卡住压盖六角面，**先用布包住**再拧，避免留下牙印；逆时针旋出
8. **取旧阀芯**：垂直拔出，记住定位脚方向；断在里面用阀芯拔取器，**不要用蛮力撬**
9. **清阀体**：旧牙刷清理阀体内水垢与沙粒，手电照看阀座面有没有划痕
10. **装新芯与回装**：对准定位脚压到底 → 装压盖（手感紧即可，**不要死拧**）→ 装把手 → **缓慢**开角阀 → 逐点验收

> **压盖过紧**会把新芯压裂，表现是装完立刻漏水或把手卡滞。拧紧到位后回退四分之一圈是稳妥做法。

## 六、脚本用法

```bash
python scripts/faucet_leak_check.py --text "关紧后出水口一直滴，把手下面也湿"
python scripts/faucet_leak_check.py --file 描述.txt --out 结果.md
```

| 参数 | 说明 |
|---|---|
| `--text` | 直接给现象描述 |
| `--file` | 从文件读描述（`.txt` / `.md`） |
| `--out` | 结果落盘路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本按漏水位置匹配故障树，输出**处理顺序**、每条的验证动作、是否值得换阀芯，以及命中红线时的停用提示。

> 脚本只做关键词匹配，**不代表现场判断**。定位漏水点必须用纸巾贴敷实测。

## 七、人工确认清单（这步不能省）

- [ ] 角阀关闭后龙头确实完全不出水
- [ ] 漏水位置用纸巾贴敷法确认过，不是猜的
- [ ] 旧阀芯已拆下并带去比对（直径、总高、齿数、定位脚、孔位）
- [ ] 阀体内水垢与沙粒清理干净
- [ ] 新阀芯定位脚对准、压到底
- [ ] 压盖拧紧但没死拧
- [ ] 开阀后把手、压盖、底座、软管接头、出水口逐点检查
- [ ] 冷热水方向正确（没有被装反）

## 八、最常见的坑

**坑一：不看位置直接买阀芯。**
底座一圈漏水、软管接头滴水，换阀芯完全没用。这两类占了漏水报修的相当比例。

**坑二：只看"35mm"就下单。**
同直径但总高、齿数、孔位不同的阀芯非常多。带旧件比对是唯一可靠的办法。

**坑三：把正常残水当滴漏。**
关水后从起泡器滴几滴，是管内与起泡器里的残水，属正常。持续不断的滴才是故障。

**坑四：硬掰锈住的把手。**
左右硬掰会把阀芯顶杆掰弯，本来只换芯变成要换整套。先喷松动剂等 10 分钟。

**坑五：压盖死拧。**
过紧压裂新芯，装完立刻漏。拧到位后回退四分之一圈。

**坑六：带压拆卸。**
没关角阀就拆压盖，阀芯会被水压顶出，水喷到墙面与插座。

**坑七：角阀锈死还硬拧。**
角阀拧断在墙内接头里，会从"换阀芯"变成"砸墙换接头"。锈死就停手报修。

**坑八：换了新芯还漏就认为是芯的问题。**
更常见的是阀体阀座面被沙粒划伤、型号不完全匹配、或压盖没压紧。

**坑九：忽略水压。**
水压长期超过 0.6MPa，新阀芯寿命会大幅缩短。反复漏水要想到加装减压阀。

## 九、边界与免责

- 本技能**不替代**给水管改造、角阀更换、墙内接头修复等专业作业
- 龙头结构、阀芯规格因品牌型号差异极大，**以实物比对与产品说明书为准**
- 涉及墙内管道、需要破坏墙面或台面的操作，应交给专业人员
- 任何出现断裂、滑丝、无法关闭水源的情况，应立即停止并报修
- 操作前务必确认水源已关闭并泄压，热水侧需先切断热水器电源与进水
