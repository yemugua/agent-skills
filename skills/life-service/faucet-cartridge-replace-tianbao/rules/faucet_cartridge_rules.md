# 水龙头漏水判定与阀芯更换规则

## 一、判定总原则

1. **位置优先于猜测。** 漏水位置直接决定故障部件，没定位就换件是最大浪费。
2. **先关水泄压，后动手。** 带压拆卸有喷水、触电与泡水风险。
3. **旧件比对优先于型号推断。** 同直径阀芯的高度、齿数、孔位差异极大。
4. **压盖宁松勿过紧。** 过紧会压裂新芯。
5. **锈死件不硬拧。** 拧断在墙内会把小修变成砸墙。

---

## 二、漏水位置对照表

| 漏水位置 | 最可能原因 | 换阀芯有效性 | 处置 |
|---|---|---|---|
| 出水口关闭后持续滴 | 阀芯陶瓷片磨损、密封垫老化 | 有效 | 换阀芯 |
| 把手下方 / 阀体周围渗 | 阀芯外壳 O 圈老化 | 有效 | 换阀芯（O 圈随芯带） |
| 底座与台面接缝渗水 | 底座胶圈老化、台下锁紧螺母松 | 无效 | 紧台下螺母或更换底座胶圈 |
| 进水软管接头滴水 | 垫片老化、螺母未到位 | 无效 | 换垫片或换软管，缠生料带 |
| 出水小、水流分叉 | 起泡器结垢堵塞 | 无效 | 拆下起泡器泡白醋除垢 |
| 关水后滴几滴即停 | 起泡器与管内残水 | 无需修 | 属正常现象 |
| 关不严且水压很高 | 进水压力过高 | 无效 | 加装减压阀 |
| 角阀本体或墙面接口渗 | 角阀失效、墙内接头渗漏 | 无效 | 停用报专业人员 |

### 定位方法：纸巾贴敷法

1. 擦干龙头全部表面与台面
2. 在把手根部、压盖、底座一圈、软管接头、出水口各贴一张干纸巾
3. 静置 5 分钟（滴漏慢的可延长到 15 分钟）
4. 哪一张先湿，漏点就在哪里

## 三、故障树（按处理顺序）

| 顺序 | 原因 | 判定 | 验证动作 | 处置 | 需停用报修 |
|---|---|---|---|---|---|
| 1 | 正常残水 | 关水后滴几滴即停 | 观察 10 分钟是否停止 | 不处理 | 否 |
| 2 | 起泡器结垢 | 出水小、水流分叉 | 拆下起泡器看网面水垢 | 白醋浸泡除垢 | 否 |
| 3 | 阀芯陶瓷片磨损 | 关紧后持续滴 | 纸巾贴敷确认漏点为出水口 | 换阀芯 | 否 |
| 4 | 阀芯外壳 O 圈老化 | 把手下方湿 | 纸巾贴敷确认漏点 | 换阀芯 | 否 |
| 5 | 底座胶圈 / 螺母松 | 底座一圈渗 | 手晃龙头看是否松动 | 紧螺母或换胶圈 | 否 |
| 6 | 软管接头垫片老化 | 接头处滴 | 纸巾贴敷确认 | 换垫片或软管 | 否 |
| 7 | 进水压力过高 | 关不严、多处同时漏 | 压力表测静压 | 装减压阀 | 否 |
| 8 | 角阀失效或锈死 | 关角阀仍出水、拧不动 | 关阀后开龙头看出水 | **停用报专业人员** | **是** |
| 9 | 阀体裂纹 / 墙内渗漏 | 阀体本体渗水、墙面渗 | 擦干后看渗水来源 | **停用报专业人员** | **是** |

## 四、阀芯规格识别六要素

| 要素 | 识别方法 | 常见值 / 注意 |
|---|---|---|
| 直径 | 卡尺量柱体 | 35mm 最常见，另有 40mm、25mm |
| 总高 | 底座到顶杆顶端 | 短了压不住，长了压盖装不回 |
| 齿数 | 数顶杆花键齿 | 常见 20 / 24 / 28 齿 |
| 定位脚 | 底部两脚间距与方向 | 不对位装不进去 |
| 进出水孔位 | 底部孔位置与形状 | 装错会冷热对调 |
| 冷热标识 | 阀芯红蓝标记 | 装反导致冷热水方向反了 |

**唯一可靠的选购方式：拆下旧阀芯带实物比对。** 网购只写"35mm 阀芯"极易买错。

## 五、更换作业顺序（十步）

1. **关水**：顺时针关紧角阀；无角阀关总阀
2. **泄压**：龙头开到冷热混合位放尽余水，确认完全不出水
3. **断电**：热水侧先关热水器电源与进水，避免干烧
4. **取装饰盖**：一字螺丝刀轻撬红蓝标识盖
5. **卸螺丝**：十字或内六角，掉进下水口先捞出
6. **取把手**：垂直向上拔；锈住先喷松动剂等 10 分钟，禁止左右硬掰
7. **拆压盖**：布包住再扳，逆时针旋出，避免留下牙印
8. **取旧阀芯**：垂直拔出并记住定位脚方向；断在里面用阀芯拔取器
9. **清阀体**：旧牙刷清阀体内水垢沙粒，手电照看阀座面有无划痕
10. **回装验收**：定位脚对准压到底 → 压盖拧紧后回退四分之一圈 → 装把手 → 缓慢开角阀 → 逐点验收

## 七、安全红线（必须停用并报专业人员）

| 情形 | 处置 |
|---|---|
| 关闭角阀后仍然出水 | 角阀已失效，先换角阀，不得带水作业 |
| 角阀或软管螺母锈死、滑丝、断裂 | 停止拧动，避免断在墙内接头 |
| 墙面内接头或预埋管件渗水 | 涉及破坏墙面，转专业人员 |
| 需拆台盆、橱柜、水槽才能施工 | 转专业人员 |
| 恒温龙头、感应龙头、抽拉龙头内部故障 | 转专业人员或厂家售后 |
| 阀体本体有裂纹或砂眼 | 整体更换龙头，不是换芯 |
| 热水侧未切断热水器电源与进水 | 先断电断水，避免干烧与烫伤 |

**禁止事项：**

- 禁止带压拆卸（阀芯被水压顶出，水喷到墙面与插座）
- 禁止左右硬掰锈住的把手（会掰弯阀芯顶杆）
- 禁止压盖死拧（压裂新芯）
- 禁止用管钳直接夹持镀层表面（必须垫布）

## 八、常见误判清单（反向判断）

| 现象 | 常见误判 | 正确判断 |
|---|---|---|
| 关水后滴几滴 | 阀芯坏了 | 起泡器与管内残水，属正常 |
| 底座一圈渗水 | 阀芯坏了 | 底座胶圈老化或台下螺母松，换芯无效 |
| 把手下方渗水 | 龙头要整体换 | 阀芯外壳 O 圈老化，换芯即可 |
| 出水小、水流分叉 | 水压不足 | 起泡器结垢，除垢即可 |
| 换了新芯还漏 | 新芯质量差 | 阀座面被沙粒划伤、型号不完全匹配、压盖未压紧 |
| 冷热水都漏 | 两颗阀芯都坏了 | 单把混合龙头只有一颗阀芯，两侧都漏多是底座胶圈 |
| 反复漏水 | 阀芯寿命短 | 可能水压长期过高，需装减压阀 |
| 网购阀芯装不上 | 尺寸不对 | 同直径也有总高、齿数、孔位差异 |
| 龙头关不严 | 阀芯磨损 | 也可能水压过高或阀体内有杂质 |

## 九、验收标准

| 项目 | 合格标准 |
|---|---|
| 关闭状态 | 手柄关闭后出水口 5 分钟内无新水滴 |
| 把手根部 | 纸巾贴敷 5 分钟不湿 |
| 底座 | 台面接缝干燥，龙头无晃动 |
| 软管接头 | 纸巾贴敷 5 分钟不湿 |
| 冷热水 | 方向正确，无冷热对调 |
| 压盖手感 | 把手转动顺滑无卡滞 |

任一项不合格，按故障树重新定位，不要重复换芯。
