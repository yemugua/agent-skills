# 发票报销合规自查与真伪识别

面向个人报销、企业财务初审、 freelancer 对账等场景，帮助快速判断一张发票能不能安心报销、有没有明显的假票或重复报销风险。

## 它能做什么

- 核查**抬头与税号**：购买方名称/税号是否与报销人（或本单位）一致
- 标记**重复报销**风险：同一张票是否已经报过
- 提示**真伪查验**：是否已在全国增值税发票查验平台完成官方查验（本技能不联网，只指引官方途径）
- 识别**虚假发票 / 骗局信号**：个人抬头开公司发票、无明细大额、税率异常、销售方税号异常等
- 区分**虚开风险**：是否基于真实交易（非真实交易 = 高风险）
- 给出**待办补正动作**与**风险提示**

## 使用方式

把 `templates/发票信息采集表.md` 填好交给本技能，未填项一律按「待补正 / 有风险」处理，绝不判通过。

## 边界

本结果依通用财务合规规则整理，不替代专业财税意见，最终以税务机关、本单位财务制度及司法认定为准。
**本技能不提供任何避税、虚开发票或财务造假的方法与指导**，只做合规自查与官方查验指引。
