# B站视频下载与离线缓存：途径、限制与合规边界

## 一、先判定：能不能下

| 归属类别 | 能否下载 | 允许的用途 |
| --- | --- | --- |
| 自有作品 | 可以，优先用原始导出文件 | 任意 |
| 已授权素材 | 可以 | 仅限授权范围内 |
| 作者开放了保存 | 可以，走官方途径 | 个人留存，**不得二次分发** |
| 第三方作品（未授权） | **不建议下载** | 不应用于任何对外场景 |

技术上能不能下载，和法律上能不能用，是两回事。

## 二、途径，按稳定性排序

| 途径 | 操作要点 |
| --- | --- |
| App 内离线缓存 | 官方途径。App 打开稿件→缓存。注意：离线缓存为加密格式，**无法直接导出为通用视频文件**，仅能在App内观看。 |
| 创作者稿件管理 | 登录**自己的账号**进入创作中心稿件管理，可下载自己投稿的原始稿件与统计数据。仅限自有投稿。 |
| 通用命令行工具 | 需 Python + ffmpeg：`pip install -U yt-dlp`。常用形态：`yt-dlp -f "bv*+ba/b" <BV链接>`。仅适用于非版权、非付费的公开内容。 |
| 弹幕与字幕 | 弹幕为 XML 格式，字幕多为 json/ass，需单独指定下载。这类属于附加资源，非视频本体。 |

## 三、本平台的真实限制

- **付费与会员专享内容不得下载后分发**。这是B站版权保护的重点区域，破解或录屏传播可能承担法律责任。
- 番剧、影视、付费课程普遍有版权保护（部分含 DRM），通用工具通常取不到或只能取到试看片段，这是设计如此，不是工具坏了。
- 1080P 及以上画质需要登录态，4K、杜比视界需要大会员权限。未登录时只能取到较低清晰度。
- BV 号与 av 号指向同一稿件，BV 是现行格式；分P稿件需在链接后加 `?p=N` 指定第N个分区。

## 四、画质与水印

- 画质上限受登录态与会员等级约束：未登录通常最高 720P，登录后 1080P，4K/杜比需大会员。下载无法突破账号本身的权限。
- B站水印策略随稿件类型变化，部分稿件叠加UP主昵称。自有稿件请在创作中心取原始投稿文件。

## 五、合规红线

1. 不得去除作者署名后二次分发
2. 不得将他人作品搬运至自己的账号（含剪辑、配音后发布）
3. 不得下载或传播私密账号、付费内容
4. 受版权或 DRM 保护的内容不支持下载，也不提供任何破解方法
5. 商用前必须取得书面授权
6. 批量高频抓取可能违反平台服务协议，导致账号受限
