# B站视频下载与离线缓存：常见失败与排查

报错信息请**粘贴原文**再对照。写成「下载失败了」没有排查价值，
写成 `HTTP Error 403` 或 `ffmpeg not found` 才能定位。

## 现象 → 原因 → 处理

| 现象关键词 | 原因与处理 |
| --- | --- |
| drm / 加密 / 版权保护 / 付费 | 该内容受版权保护，**不支持也不应下载**。请通过官方会员渠道观看。 |
| 会员专享 / 需要大会员 | 需大会员权限内容，不属于可下载范围。 |
| 需要登录 / 1080p / 清晰度不够 | 高画质需要登录态：`yt-dlp --cookies-from-browser chrome <链接>`，4K还需大会员。 |
| 找不到缓存文件 / dat / m4s | App 离线缓存为分片加密格式，不能当普通视频文件拷出来用，这是平台设计。 |
| 试看 / 只有前几分钟 | 这是付费内容的试看限制，不是下载失败。 |

## 通用故障（各平台都可能遇到）

| 现象 | 处理 |
| --- | --- |
| 403 / 需要登录 / 机器人验证 | 触发反自动化校验：携带登录态或减少请求频率，不要高频重试 |
| 429 / 频繁 / 限流 | 降低请求频率、分批间隔重试 |
| 404 / 失效 / 不存在 | 链接失效或已删除：让对方重新生成分享 |
| 没有声音 / 无音轨 | ffmpeg 未安装或未合并轨：安装后用 `-f "bv*+ba/b"` 合并 |
| 解析失败 / 格式不支持 | 站点接口变动：把工具升级到最新版，而不是换工具 |
| 超时 / 连接失败 | 检查网络可达性后重试 |

## 排查顺序

1. 先确认网络能访问目标平台
2. 再确认目标内容是否属于可下载范围（回到归属判定）
3. 然后确认工具是最新版
4. 最后才怀疑链接本身

九成的「下载失败」卡在第 1 步和第 2 步，而不是工具坏了。
