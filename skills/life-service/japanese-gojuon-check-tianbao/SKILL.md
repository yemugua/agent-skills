# 日语五十音图记忆与发音核查（japanese-gojuon-check）

五十音记不住，通常不是记性问题，而是**一次背完整个表**：今天背あ行到わ行，明天全忘。按行推进、当天默写、隔天复习才有效。

这个技能做三件事：**按行给对照表** → **出默写题并批改** → **统计薄弱行定向复习**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出清音/浊音/半浊音/拗音的对照表 | ❌ 保证"X 天背完五十音" |
| 标出发音要点与易混音 | ❌ 代替发音教师纠正口型 |
| 生成默写题并批改统计正确率 | ❌ 代替正式课程与等级考试评分 |
| 给出按行推进的记忆计划与验收标准 | ❌ 提供具体考试时间、报名时间与费用 |
| 指出薄弱行与复习顺序 | ❌ 判断某个假名的"标准口型"是否绝对正确 |

**出现以下情况先停下来，别照着表硬背：**
- 「し=shi」「つ=tsu」「ふ=fu」只是**罗马音转写方案**的一种，口型以教材音频为准
- ら行的发音（弹音）用文字很难描述准，**以教材或教师的音频示范为准**
- 涉及日语能力考试（JLPT）的等级、时间、报名 —— 以**当年官方公告为准**
- 自学超过两周仍分不清易混音 —— 建议找教师带一遍发音，不要靠罗马音硬记

## 二、完整工作流

```
第 1 步  确认起点：零基础 / 背过但忘了 / 只会平假名
第 2 步  先读 rules/gojuon_table.md，按行过一遍对照表（不要一次看完整个表）
第 3 步  读 rules/learning_plan.md，抄下按行推进的计划与验收标准
第 4 步  生成当天那一行的默写题并作答
         python scripts/japanese_gojuon_quiz.py --mode quiz --rows a,ka --out quiz.md
         python scripts/japanese_gojuon_quiz.py --mode grade --rows a,ka --file answers.txt
第 5 步  看脚本给出的正确率与薄弱行，薄弱行第二天重默写
第 6 步  平假名某一行稳定 90% 以上后，再补该行的片假名
第 7 步  清音全部达标后，进浊音与半浊音，最后进拗音
```

## 三、五十音构成

| 类别 | 数量 | 说明 |
|---|---|---|
| 清音 | 46 个（含拨音 ん） | あ行到わ行 + ん |
| 浊音 | 20 个 | が行、ざ行、だ行、ば行各 5 个 |
| 半浊音 | 5 个 | ぱ行 |
| 拗音 | 常用 33 个 | きゃ、しゃ、ちゃ 等 11 组 × 3 |

> 浊音 20 + 半浊音 5：本技能按「浊音与半浊音合计 25 个」处理，脚本 `--set dakuon` 覆盖浊音 20 个与半浊音 5 个。

**行的顺序**（记忆顺序）：あ → か → さ → た → な → は → ま → や → ら → わ → ん

---

## 四、发音要点（最容易读错的几个）

| 假名 | 罗马音 | 要点 |
|---|---|---|
| し | shi | 不是 "si" |
| ち | chi | 不是 "ti" |
| つ | tsu | 不是 "tu" |
| ふ | fu | 不是 "hu"，是双唇音 |
| ら行 | ra/ri/ru/re/ro | 弹音，不是汉语的"拉" |
| を | o (wo) | 作助词时读 o |
| ん | n | 拨音，单独占一拍 |

---

## 五、12 组易混音

| 组别 | 混淆点 | 区分办法 |
|---|---|---|
| シ / ツ | 片假名，两点位置与笔画方向不同 | シ 两点在右上左下行；ツ 两点在左上右下行 |
| ソ / ン | 片假名 | ソ 两笔向左下；ン 第二笔向上提起 |
| ク / ケ | 片假名 | ケ 多一竖 |
| ワ / ウ | 片假名 | ワ 是两笔折；ウ 是三笔 |
| あ / お | 平假名 | お 右上角多一小竖 |
| る / ろ | 平假名 | る 下方有个小圈折；ろ 是一笔绕 |
| れ / ね | 平假名 | ね 起笔是竖后折 |
| は / ほ | 平假名 | ほ 右上多一横 |
| ぬ / ね | 平假名 | ぬ 收尾是大圈 |
| み / む | 平假名 | む 收尾有小撇 |
| て / に | 平假名 | て 是一笔折；に 上面多一横 |
| す / せ | 片假名 ス / セ | セ 中间多一横 |

## 六、脚本用法

```bash
python scripts/japanese_gojuon_quiz.py --mode quiz --rows a,ka --out quiz.md
python scripts/japanese_gojuon_quiz.py --mode grade --rows a,ka --file answers.txt
python scripts/japanese_gojuon_quiz.py --mode quiz --set dakuon --direction roma2kana --out quiz2.md
python scripts/japanese_gojuon_quiz.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--mode` | `quiz` 出题 / `grade` 批改 |
| `--set` | `seion` 清音（默认）/ `dakuon` 浊音与半浊音 / `all` |
| `--rows` | 指定行，逗号分隔，如 `a,ka,sa`；不填则出题全部 |
| `--direction` | `kana2roma` 给假名写罗马音（默认）/ `roma2kana` 给罗马音写假名 |
| `--file` | 批改模式的答案文件，每行一个答案 |
| `--out` | 输出文件路径（不填则写到 `scripts/_gojuon_result.md`） |
| `--selftest` | 跑内置自检 |

脚本做四件事：① 按行生成默写题（含平假名与片假名两栏）；② 批改并算正确率；③ 按行统计正确率，标出薄弱行；④ 给出下一行该复习哪一行。

> 罗马音转写方案有多种，本技能采用常见方案（し=shi、つ=tsu、ふ=fu），**实际口型以教材音频与教师示范为准**。

## 七、人工确认清单（这步不能省）

- [ ] 是否按行推进，而不是一次背完整个表
- [ ] 当天背的行是否当天默写过
- [ ] 薄弱行是否第二天重默写
- [ ] 平假名稳定后再补片假名，还是同步推进（建议先平后片，但同一行内间隔不超过两天）
- [ ] 「し / つ / ふ / ら行」是否听过音频，而不是只看罗马音
- [ ] 易混音是否单独抄了一遍
- [ ] 涉及等级考试的安排是否查过**当年**官方公告

## 八、最常见的坑

**坑一：一次背完整个表。**
错误做法：第一天把 46 个假名全看一遍；正确做法：一天 1~2 行，当天默写，第二天复习前一天的行。

**坑二：只看不写。**
错误做法：盯着表看，觉得"认识了"；正确做法：默写，写不出来的才算没记住。

**坑三：先背片假名。**
错误做法：觉得片假名"像英文"更好记，先背片假名；正确做法：先平假名（课文里出现最多），再补片假名。

**坑四：用罗马音当发音。**
错误做法：按 "ra ri ru re ro" 念成汉语的"拉里路勒罗"；正确做法：ら行是弹音，以教材音频为准。

**坑五：不区分 し 与 つ 的罗马音。**
错误做法：把 し 写成 si、つ 写成 tu；正确做法：し=shi、つ=tsu（本技能采用常见转写方案）。

**坑六：忽略拨音 ん。**
错误做法：把 ん 当成"n 结尾"一带而过；正确做法：ん 单独占一拍，要单独练。

**坑七：浊音与清音一起背。**
错误做法：清音还没稳就进浊音；正确做法：清音按行达标 90% 再进浊音。

**坑八：拗音提前学。**
错误做法：五十音没背完就练 きゃきゅきょ；正确做法：拗音放在最后，它是"き + ゃ"的组合。

**坑九：不统计薄弱行。**
错误做法：每次都从あ行开始默；正确做法：看批改结果，只默薄弱行。

**坑十：把 を 读成 wo。**
错误做法：所有场景都读 wo；正确做法：作助词时读 o。

**坑十一：混淆 は 的助词读音。**
错误做法：助词「は」也读 ha；正确做法：作助词时读 wa（这是单词与助词的差异，以教材为准）。

**坑十二：忽视长音与促音。**
错误做法：五十音背完就觉得发音没问题；正确做法：长音、促音、拨音都要单独占一拍。
