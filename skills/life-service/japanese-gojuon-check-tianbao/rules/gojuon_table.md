# 日语五十音图对照表与发音要点

> 罗马音转写采用常见方案（し=shi、つ=tsu、ふ=fu），不同教材方案可能不同，**实际口型以教材音频与教师示范为准**。

| さ | さ サ sa | し シ shi | す ス su | せ セ se | そ ソ so |
| た | た タ ta | ち チ chi | つ ツ tsu | て テ te | と ト to |
| な | な ナ na | に ニ ni | ぬ ヌ nu | ね ネ ne | の ノ no |
| は | は ハ ha | ひ ヒ hi | ふ フ fu | へ ヘ he | ほ ホ ho |
| ま | ま マ ma | み ミ mi | む ム mu | め メ me | も モ mo |
| や | や ヤ ya | — | ゆ ユ yu | — | よ ヨ yo |

## 四、拗音（常用 33 个）

拗音 = い段假名 + 小写 ゃ / ゅ / ょ

| 组 | ゃ | ゅ | ょ |
|---|---|---|---|
| き | きゃ kya | きゅ kyu | きょ kyo |
| し | しゃ sha | しゅ shu | しょ sho |
| ち | ちゃ cha | ちゅ chu | ちょ cho |
| に | にゃ nya | にゅ nyu | にょ nyo |
| ひ | ひゃ hya | ひゅ hyu | ひょ hyo |
| み | みゃ mya | みゅ myu | みょ myo |
| り | りゃ rya | りゅ ryu | りょ ryo |
| ぎ | ぎゃ gya | ぎゅ gyu | ぎょ gyo |
| じ | じゃ ja | じゅ ju | じょ jo |
| び | びゃ bya | びゅ byu | びょ byo |
| ぴ | ぴゃ pya | ぴゅ pyu | ぴょ pyo |

**关键**：ゃ / ゅ / ょ 是**小写**，写大了就变成两个假名。

## 五、发音要点（最容易读错的几个）

| 假名 | 罗马音 | 要点 |
|---|---|---|
| し | shi | 不是 si |
| ち | chi | 不是 ti |
| つ | tsu | 不是 tu |
| ふ | fu | 不是 hu，是双唇摩擦音 |
| ら行 | ra ri ru re ro | 弹音，舌尖轻弹上齿龈，不是汉语的"拉" |
| を | o | 作助词时读 o |
| ん | n | 拨音，**单独占一拍** |
| は（助词） | wa | 作助词时读 wa，作单词时读 ha |

## 六、12 组易混音

| 组别 | 类型 | 区分办法 |
|---|---|---|
| シ / ツ | 片假名 | シ 两点在右上→左下；ツ 两点在左上→右下 |
| ソ / ン | 片假名 | ソ 两笔向左下；ン 第二笔向上提起 |
| ク / ケ | 片假名 | ケ 多一竖 |
| ワ / ウ | 片假名 | ワ 两笔折；ウ 三笔 |
| あ / お | 平假名 | お 右上角多一小竖 |
| る / ろ | 平假名 | る 下方有小圈折；ろ 一笔绕 |
| れ / ね | 平假名 | ね 起笔是竖后折 |
| は / ほ | 平假名 | ほ 右上多一横 |
| ぬ / ね | 平假名 | ぬ 收尾是大圈 |
| み / む | 平假名 | む 收尾有小撇 |
| て / に | 平假名 | て 一笔折；に 上面多一横 |
| ス / セ | 片假名 | セ 中间多一横 |

## 七、拍的概念（发音容易漏掉的三个）

| 项目 | 说明 | 例 |
|---|---|---|
| 长音 | 元音拖长一拍 | おかあさん（ka 后多加一拍） |
| 促音 | 小写 っ，停顿一拍 | がっこう（ga 后停顿一拍） |
| 拨音 | ん 单独一拍 | でんわ（denwa 三拍+一拍） |

> 长音、促音、拨音都**各占一拍**，漏掉会改变词义，五十音背完后要单独练。
