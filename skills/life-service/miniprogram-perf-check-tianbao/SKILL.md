# 小程序启动与渲染性能核查

面向小程序开发者与技术负责人：启动慢、首屏白屏久、列表卡顿、包体积逼近上限、体验评分偏低的场景。

## 它能做什么

- 诊断**包体积**：主包与总包是否超限，是否需要分包与按需注入
- 诊断**启动性能**：冷启动与首屏渲染耗时分级，定位启动链路瓶颈
- 诊断**渲染与交互**：setData 数据量与调用频率、长列表是否虚拟化
- 诊断**网络与资源**：首页请求数、接口响应、图片体积与格式、CDN 与缓存
- 给出**分级结论**：优秀 / 达标 / 需优化 / 严重超标，并标出优先处理项
- 给出**可执行优化清单**：按投入产出排序的具体改造动作与复测建议

## 使用方式

把 `templates/性能信息采集表.md` 填好（两列表或「字段：值」），交给本技能生成报告。
未填项一律按「待补正 / 有风险」处理，绝不判通过。

## 边界

本结果依通用规则与公开参考值整理，不替代平台官方结论、真机实测与官方计费账单，最终以微信公众平台、微信云开发控制台与官方文档为准。
