# 规则表二：两种鉴定路径、赔偿项目核算口径、参与度与和解审查

> 依据医疗损害责任与人身损害赔偿的通行规则整理。**计算标准（人均可支配收入、职工平均工资、伙食补助标准等）各地每年更新，以受诉法院所在地现行公布数据为准**；本表不编造条款号。

## 第 1 节 两种鉴定路径对比（选错了会白花钱）

| 对比项 | 医疗损害鉴定 | 医疗事故技术鉴定 |
|---|---|---|
| 实施主体 | 具备资质的司法鉴定机构 | 医学会（设区的市级/省级） |
| 启动主体 | 当事人申请（法院委托）或双方共同委托 | 卫生行政部门移交，或医患双方共同委托 |
| 鉴定内容 | 医疗过错、因果关系、**原因力（参与度）**、伤残等级、护理期/营养期等 | 是否属于医疗事故、事故等级、责任程度 |
| 结论用途 | **民事赔偿**的主要依据 | **行政处理**的主要依据 |
| 与赔偿的关系 | 直接支撑赔偿主张 | 不构成事故**不免除**民事赔偿责任 |

**重要区分**：医疗事故技术鉴定结论"不构成医疗事故"，**不等于**医疗机构不承担医疗损害赔偿责任。两条路径并行，不要把行政结论当成民事责任结论。

**鉴定事项清单（申请时写清楚）**：
1. 医疗行为是否存在过错（违反诊疗规范、未尽告知义务、未尽与当时医疗水平相应的诊疗义务）；
2. 过错与损害后果之间是否存在因果关系；
3. 过错在损害后果中的**原因力（参与度）大小**；
4. 伤残等级（如构成残疾）；
5. 护理期、营养期、误工期（如需）；
6. 后续治疗费的必要性（如需）。

## 第 2 节 赔偿项目与计算口径

| 项目 | 计算口径 | 依据材料 |
|---|---|---|
| 医疗费 | 按**票据**据实计算，含已发生与**确定必然发生**的后续治疗费 | 医疗费票据、费用清单、后续治疗证明 |
| 误工费 | 误工时间 × 收入；有固定收入的按实际减少的收入；无固定收入的按最近三年平均收入，不能举证的参照当地同行业上一年度职工平均工资 | 误工证明、收入证明、银行流水、鉴定意见 |
| 护理费 | 护理天数 × 每日护理费 × 护理人数；护理人员有收入的参照误工费，无收入或雇护工的参照当地护工报酬标准 | 护理证明、护理人员收入、护理期鉴定 |
| 交通费 | 凭票据据实，需与就医时间、地点、次数相符 | 交通票据 |
| 住院伙食补助费 | 住院天数 × 当地国家机关一般工作人员出差伙食补助标准 | 住院记录 |
| 营养费 | 营养期天数 × 每日标准，参照医疗机构意见 | 医嘱、营养期鉴定 |
| 残疾赔偿金 | 城镇居民人均可支配收入（年） × 赔偿年限 × 伤残系数 | 伤残鉴定意见 |
| 残疾辅助器具费 | 按普通适用器具的合理费用，含更换周期与维修费 | 配置机构意见、票据 |
| 丧葬费 | 受诉法院所在地上一年度**职工月平均工资 × 6 个月** | 死亡证明 |
| 死亡赔偿金 | 城镇居民人均可支配收入（年） × 赔偿年限 | 死亡证明 |
| 被扶养人生活费 | 年生活费标准 × 扶养年限 ÷ 共同扶养人数 | 扶养关系证明 |
| 精神损害抚慰金 | 依伤残等级、过错程度、当地经济水平酌定 | 伤残/死亡后果、过错程度 |
| 鉴定费 | 凭票据 | 鉴定费发票 |

### 2.1 赔偿年限

```
60 周岁以下：20 年
60 周岁以上：年龄每增加 1 岁减少 1 年（即 20 - (年龄 - 60)）
75 周岁以上：按 5 年
```

### 2.2 伤残系数

| 等级 | 系数 | 等级 | 系数 |
|---|---|---|---|
| 一级 | 100% | 六级 | 50% |
| 二级 | 90% | 七级 | 40% |
| 三级 | 80% | 八级 | 30% |
| 四级 | 70% | 九级 | 20% |
| 五级 | 60% | 十级 | 10% |

## 第 3 节 过错参与度（原因力）折算

```
物质损失合计 = 医疗费 + 误工费 + 护理费 + 交通费 + 住院伙食补助费
              + 营养费 + 残疾赔偿金（或死亡赔偿金）+ 残疾辅助器具费
              + 丧葬费 + 被扶养人生活费 + 鉴定费

应赔金额 = 物质损失合计 × 过错参与度
```

| 参与度常见表述 | 系数 |
|---|---|
| 全部原因 | 1.0 |
| 主要原因 | 0.6 ~ 0.9 |
| 同等原因 | 0.4 ~ 0.6 |
| 次要原因 | 0.2 ~ 0.4 |
| 轻微原因 | 0.1 以下 |

**关于精神损害抚慰金是否再乘参与度**：各地裁判口径存在差异，有的直接酌定、有的再按参与度折算。核算时应**两种都算**，并说明差异。

**参与度不是"打几折"的简单算术**：它由鉴定意见给出，协商时可浮动，诉讼中由法院结合全案确定。

## 第 4 节 处理路径排序与材料

| 顺序 | 路径 | 材料 | 特点 |
|---|---|---|---|
| 1 | 院内投诉/医患沟通 | 书面投诉、诉求清单、病历复印件 | 留痕，为后续证明"医疗机构知情" |
| 2 | **医疗纠纷人民调解委员会** | 申请书、病历、票据、身份证明 | **免费、专业，多数纠纷的首选** |
| 3 | 行政处理（卫生健康行政部门） | 投诉书、病历复印件、违规线索 | 针对违规执业行为 |
| 4 | 司法鉴定 + 诉讼 | 起诉状、鉴定申请、全部证据 | 执行力最强，周期最长 |

**调解协议的司法确认**：医疗纠纷人民调解达成的协议，可依法向**人民法院申请司法确认**，确认后具有强制执行力。**未经司法确认的调解协议，一方反悔时需另行起诉**——这是最常被忽略的一步。

## 第 5 节 和解协议签署前审查清单（重大损害不要在鉴定前签）

| 审查项 | 风险 |
|---|---|
| 是否写明"一次性了结、不得再主张" | 签后通常不能再主张后续费用 |
| 是否覆盖**后续治疗费** | 遗漏则后续自担 |
| 是否覆盖**后遗症/并发症** | 鉴定前签署，后遗症风险极高 |
| 伤残等级是否已确定 | 未鉴定即签约，金额可能被严重低估 |
| 金额是否明显低于核算结果 | 显失公平的可请求撤销（以现行规定为准） |
| 是否约定了违约责任与履行期限 | 无期限约定则难以主张迟延责任 |
| 是否有"不得向监管部门投诉"条款 | 此类条款效力存疑，且不影响投诉权利 |

**原则**：损害后果已经稳定、伤残等级已明确、后续治疗费可预估之后再谈一次性了结。

## 第 6 节 常见误判对照表（否定词防误伤）

| 文本/情形 | 不要判成 | 正确判法 |
|---|---|---|
| 不构成医疗事故 | 无需赔偿 | 行政结论不等于民事责任结论 |
| 属于并发症 | 医院必然无责 | 关键看诊疗义务、告知义务与处置是否到位 |
| 已复印病历 | 证据已固定 | **主观性病历必须封存**，复印不覆盖 |
| 已封存纸质病历 | 电子数据已固定 | 电子病历需另行明确固化与操作日志 |
| 已签署知情同意书 | 医院必然免责 | 知情同意不等于免除过错责任 |
| 病历有事后补记 | 一定是篡改 | 抢救等紧急情形下依法补记与违规改写不同 |
| 已达成调解 | 款项已到手 | 未经司法确认的协议执行力有限 |
| 未做尸检 | 一定由医院承担不利后果 | 需看是**哪一方**拒绝或拖延 |
| 只找当事医生 | 被告适格 | 责任主体是**医疗机构**（非法行医除外） |
| 损害轻微 | 不值得主张 | 仍应封存证据并保留主张权利的记录 |

## 第 7 节 时效

医疗损害责任纠纷的诉讼时效一般为 **三年**，自知道或者应当知道权利受到损害以及义务人之日起算（以现行规定为准）。**自权利受到损害之日起超过二十年的，人民法院一般不予保护**（以现行规定为准）。久拖不决的，应通过书面函件、调解申请、投诉等方式**主张权利并留痕**。
