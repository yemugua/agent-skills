# 规则表一：病历分类、封存步骤、复印权利、尸检时间窗与举证责任

> 依据医疗纠纷预防与处理、病历管理、医疗损害责任的通行规则整理。**具体期限、范围与程序以现行规定和当地卫生健康行政部门要求为准**，本表不编造条款号。

## 第 1 节 病历分两类：可复印的与需封存的

| 类别 | 内容 | 患者权利 |
|---|---|---|
| **客观性病历** | 门诊病历、住院志（入院记录）、体温单、医嘱单、化验单（检验报告）、医学影像检查资料、特殊检查（治疗）同意书、手术同意书、手术记录、麻醉记录、病理资料、护理记录、出院记录（出院小结）、医疗费用清单 | 患者**有权复印/复制**，医疗机构应当提供并加盖证明印记 |
| **主观性病历** | 病程记录（含首次病程、日常病程）、上级医师查房记录、疑难病例讨论记录、会诊意见、死亡病例讨论记录、术前讨论记录 | **应当在医患双方在场的情况下封存**，不单独提供给患者 |

**为什么必须分清楚**：
- 复印拿不到主观性病历 → 只复印不封存，等于把最重要的部分留给了对方单方面掌控。
- 封存是**保全**，不是调取；封存后材料仍在医疗机构保管，后续鉴定时再启封。

## 第 2 节 病历封存操作步骤（当天完成）

1. **书面提出**：向医疗机构医务科/医患关系办公室提交书面封存申请，**索取收件回执**（不要只口头说）。
2. **共同在场**：医患双方共同在场，共同确认病历的页数、份数与完整性。
3. **制作封存清单**：一式两份，载明——患者姓名、住院号、封存日期时间、封存材料名称与页数、在场人员、双方签字盖章。
4. **当场封装**：装入袋/箱后封口，双方在封口处签字或加盖骑缝章。
5. **留存保管**：一般由医疗机构保管；双方另有约定的从约定。**清单必须拍照留存**。
6. **疑似实物同时封存**：输液器、注射器、药品及残液、血液制品、植入物、器械等；需检验的由双方共同指定检验机构。

**易漏点**：只封纸质病历，忘了**电子病历**。应一并明确电子病历数据的封存/固化（要求出具电子病历的复制件并加盖证明印记，同时保存系统操作日志线索）。

## 第 3 节 复印病历的权利与流程

| 项目 | 要点 |
|---|---|
| 申请人 | 患者本人；患者死亡的，其**近亲属**；不能到场的，可委托代理人（需授权委托书与身份证明） |
| 范围 | 全部客观性病历资料 |
| 形式 | 医疗机构应当提供复制服务，并在复制件上**加盖证明印记** |
| 费用 | 医疗机构可收取工本费（以现行规定为准） |
| 拒绝提供 | 属违规，可向卫生健康行政部门投诉并留痕 |

## 第 4 节 电子病历修改留痕核查

电子病历系统应当具备**修改留痕**功能（保留修改人、修改时间、修改内容）。怀疑病历被事后补记或改写的：

1. **立即封存**（先封存，再谈其他）；
2. 书面要求医疗机构提供该病历的**操作日志/修改记录**；
3. 比对：护理记录与医嘱的时间一致性、检验报告出具时间与病程记录引用时间、知情同意书签署时间与手术时间；
4. 鉴定时可申请对电子病历数据真实性进行**鉴定/勘验**；
5. 注意：抢救等紧急情形下**依法补记**的病历与违规改写不同，**不要一律认定为篡改**（防误伤）。

## 第 5 节 尸检时间窗（死亡情形，小时级）

| 项目 | 口径 |
|---|---|
| 启动条件 | 患者死亡，**死因不明或对死因有异议** |
| 时间窗口 | 一般应在患者死亡后 **48 小时内**进行；具备尸体冻存条件的，可延长至 **7 日**（以现行规定为准） |
| 告知义务 | 医疗机构应当**告知**近亲属尸检的必要性与时间限制，并**留有告知记录** |
| 拒绝/拖延后果 | 拒绝或者拖延尸检，**超过规定时间**影响死因判定的，由拒绝或拖延的一方承担**不利后果**（以现行规定为准） |
| 实施主体 | 具备资质的病理解剖机构/鉴定机构 |

**实操要点**：
- 收到尸检告知后**不要口头拒绝且不签字**。
- 若不同意尸检，应**书面**说明理由并保留一份副本，避免被认定为"拒绝一方"。
- 若同意，应书面明确尸检机构的选择方式与费用承担。
- 尸体未经家属同意不得擅自处理，医疗机构负妥善保管义务。

## 第 6 节 实物封存清单

| 类别 | 举例 | 处理 |
|---|---|---|
| 药品类 | 输液瓶（袋）及残液、口服药、麻醉药品 | 双方封存，必要时共同送检 |
| 器械类 | 输液器、注射器、导管、植入物、骨科内固定 | 双方封存，保留包装与批号 |
| 血液类 | 血袋、输血器 | 双方封存 |
| 检材类 | 组织标本、病理切片、涂片 | 可申请调取/会诊 |
| 其他 | 疑似污染的物品 | 拍照 + 封存 |

**要点**：实物封存同样需要**共同在场**与**封存清单**；需检验的应由**双方共同指定**检验机构，单方送检的检材证明力会被削弱。

## 第 7 节 举证责任分配

| 待证事实 | 举证方 | 说明 |
|---|---|---|
| 就诊事实（医患关系存在） | 患者 | 挂号单、病历、费用票据 |
| 损害后果 | 患者 | 诊断证明、伤残鉴定、死亡证明 |
| 医疗行为存在过错、与损害有因果关系 | **医疗机构**（举证责任有特别规定） | 由医疗机构证明其无过错、无因果关系 |
| 病历的完整性与真实性 | 医疗机构 | 保管方负有保证义务 |
| 免责/减责事由（如不可抗力、患者不配合） | 医疗机构 | 依具体情形 |

**因此患者的核心工作是**：证明**来看过病** + **有损害** + **把病历和实物先锁住**。剩下的过错与因果关系由鉴定解决，举证责任不在患者一方。

## 第 8 节 就诊时间线模板（一周内整理完成）

```
____年__月__日  首次就诊（科室、主诉、诊断）
____年__月__日  检查（项目、结果、出具时间）
____年__月__日  入院 / 手术 / 麻醉（名称、术者、知情同意书签署时间）
____年__月__日  用药（名称、剂量、时间）／输血
____年__月__日  出现异常情况（症状、发现人、通知时间）
____年__月__日  处置措施（会诊、转科、抢救）
____年__月__日  转院（转入医院、诊断）
____年__月__日  出院 / 死亡
```

时间线的价值在于暴露**时间上的矛盾**（如知情同意书签署晚于手术时间、检验报告晚于病程引用），这是发现病历问题的关键。
