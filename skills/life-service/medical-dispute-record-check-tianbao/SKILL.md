# 医疗纠纷病历封存与鉴定路径核查

医疗纠纷的处理有个铁律：**证据先于主张，鉴定先于金额**。病历没封、尸检没做、鉴定没出，任何金额主张都是空中楼阁，而且一旦错过时间窗，证据就永久灭失。本技能按"**当天 → 一周 → 一个月 → 长期**"的时间轴组织动作。

## 一、硬边界（能做 / 不能做）

| 能做 | 不能做 |
|---|---|
| 给出病历封存、实物封存、复印的具体步骤与清单 | 替代医疗机构实施封存 |
| 说明两种鉴定路径的适用与差异 | 判断医院是否有过错（需鉴定意见） |
| 按人身损害赔偿项目逐项核算并按参与度折算 | 给出"必然能赔多少"的结论 |
| 梳理协商、调解、行政投诉、诉讼的顺序与材料 | 认定医疗事故（由医学会/行政部门依法认定） |
| 提示尸检时间窗与告知义务 | 决定是否需要尸检（需结合病情与家属意愿） |
| 输出和解协议签署前的审查要点 | 代签和解协议或放弃权利 |

**必须转交专业人士的情形：**
- 已经发生或可能发生死亡、重度残疾等严重后果——**必须委托专业医疗纠纷律师**。
- 需要判断医疗行为是否存在过错、因果关系与原因力——必须由鉴定机构出具意见。
- 涉及刑事（非法行医、医疗事故罪）嫌疑——向公安机关或检察机关反映。
- 进入诉讼的——举证、质证、鉴定申请均需专业人士办理。

## 二、什么时候用

| 用户说法 | 用不用 | 说明 |
|---|---|---|
| 我要封存病历，怎么封 | 用 | 当天就要做，走时间轴第一步 |
| 医院不给我复印病历 | 用 | 客观病历依法可复印，走权利清单 |
| 病历是不是被改了 | 用 | 走电子病历修改留痕核查路径 |
| 人死了，要尸检吗 | 用 | 时间极敏感，走尸检时间窗 |
| 做哪种鉴定 | 用 | 走两种鉴定路径对比 |
| 能赔多少钱 | 用 | 走赔偿项目核算（需先有鉴定） |
| 和解协议能不能签 | 用 | 走协议审查要点 |
| 帮我打这个官司 | 部分用 | 本技能给路径与材料，诉讼请委托律师 |

## 三、完整工作流

### 时间轴第一步：当天（或发现损害后立即）

1. **申请封存病历**：向医疗机构医务部门提出，**书面**提出并索取回执。封存范围包括主观性病历与客观性病历。
2. **共同在场、共同封存**：医患双方共同在场，对病历共同确认后封存，制作**封存清单**（一式两份，双方签字），注明封存日期、页数、份数。
3. **封存疑似实物**：输液器、注射器、药品、血液制品、医疗器械等；需要检验的，双方共同指定检验机构。
4. **复印客观病历**：患者有权复印客观性病历资料（清单见规则表），医疗机构应当提供并加盖证明印记。
5. **不要签署任何"免责/了结"文件**。

### 时间轴第二步：死亡情形（小时级，最紧急）

- 患者死亡且死因不明或对死因有异议的，**应当在规定时间内进行尸检**；常见口径为患者死亡后 **48 小时内**进行，具备尸体冻存条件的可延长至 **7 日**（以现行规定为准）。
- **医疗机构负有告知义务**：应当告知家属尸检的必要性与时间限制，并留有告知记录。
- **拒绝或拖延尸检，导致死因无法判定的**，由拒绝或拖延的一方承担不利后果（以现行规定为准）。
- 因此：收到尸检告知后，**不要拖延、不要口头拒绝**，如不同意应书面说明理由并保留副本。

### 时间轴第三步：一周内

- 整理就诊时间线（挂号、门诊、检查、入院、手术、用药、转科、出院）。
- 收集全部票据（医疗费、交通费、护理用品、辅助器具）。
- 复印、拍照固定所有书面材料（知情同意书、检查报告、出院小结、费用清单）。
- 必要时申请**电子病历修改记录**（电子病历系统应留痕）。

### 时间轴第四步：选择处理路径

| 路径 | 特点 | 适用 |
|---|---|---|
| 院内协商 | 快、成本低，但金额通常偏低 | 损害轻、责任清晰 |
| **医疗纠纷人民调解委员会** | 免费、专业、**性价比最高的常规选择** | 多数纠纷 |
| 行政处理（卫生健康行政部门） | 行政机关依法处理 | 涉及违规执业、医疗事故争议 |
| 司法鉴定 + 诉讼 | 周期长、成本高，但结论执行力强 | 损害重、争议大 |

**建议顺序**：先封存证据 → 院内投诉留痕 → 医调委调解 → 调解不成则鉴定 + 诉讼。

### 时间轴第五步：鉴定
见 `rules/02-鉴定路径与赔偿核算.md` 第 1 节（两种鉴定对比、鉴定事项、费用与周期）。

### 时间轴第六步：核算与主张
按赔偿项目逐项核算，再按**过错参与度（原因力比例）**折算（第五节脚本）。

## 四、核心规则（动手前必读）

**先读这两个文件，不要凭印象做：**
- `rules/01-病历封存与证据固定.md` —— 主观/客观病历分类、封存步骤与清单、复印权利清单、电子病历修改留痕、尸检时间窗与告知义务、实物封存、举证责任分配。
- `rules/02-鉴定路径与赔偿核算.md` —— 两种鉴定对比、鉴定事项、赔偿项目与计算口径、过错参与度、和解协议审查要点、时效。

**赔偿核算骨架：**

```
单项合计 = 医疗费 + 误工费 + 护理费 + 交通费 + 住院伙食补助费
         + 营养费 + 残疾赔偿金 + 残疾辅助器具费 + 丧葬费
         + 死亡赔偿金 + 被扶养人生活费 + 精神损害抚慰金 + 鉴定费

可主张金额 = 物质损失项目合计 × 过错参与度
```

**关键口径**：赔偿年限（60 周岁以下一般按 20 年，60 周岁以上年龄每增加一岁减少一年，75 周岁以上按 5 年）、伤残系数（一级 100% 至十级 10%）、精神损害抚慰金是否再乘参与度（各地口径不同）。**以上均以现行人身损害赔偿规定为准。**

## 五、脚本用法

脚本：`scripts/medical_compensation_calc.py`（Python 3 标准库）

```bash
python scripts/medical_compensation_calc.py --file 案件.json
python scripts/medical_compensation_calc.py --file 案件.json --json
python scripts/medical_compensation_calc.py --selftest
```

| 字段 | 说明 |
|---|---|
| `medical_expense` | 医疗费票据合计（元，含已发生与确定必然发生的后续治疗费） |
| `lost_days` / `monthly_income` | 误工天数 / 月收入（无固定收入的填当地行业标准） |
| `nursing_days` / `nursing_rate` / `nursing_count` | 护理天数 / 每日护理费 / 护理人数 |
| `hospital_days` / `meal_rate` | 住院天数 / 每日住院伙食补助标准 |
| `nutrition_days` / `nutrition_rate` | 营养期天数 / 每日营养费标准 |
| `transport` | 交通费（凭票据） |
| `disability_level` | 伤残等级 1~10，无伤残填 0 |
| `death` | 是否死亡（true/false） |
| `age` | 受害人定残/死亡时的年龄 |
| `urban_income` | 受诉法院所在地上一年度城镇居民人均可支配收入（元/年） |
| `wage_monthly` | 上一年度职工月平均工资（元/月，用于丧葬费） |
| `aid_device` | 残疾辅助器具费 |
| `spiritual` | 精神损害抚慰金主张金额 |
| `spiritual_with_ratio` | 精神损害抚慰金是否也乘参与度（false 为不乘，各地口径不同） |
| `fault_ratio` | 过错参与度（0~1），由鉴定意见或协商确定 |
| `dependent_annual` / `dependent_years` / `supporters` | 被扶养人年生活费标准 / 扶养年限 / 共同扶养人数 |

输出：逐项明细、物质损失合计、参与度折算后金额、精神损害抚慰金处理方式、可主张金额合计。

## 六、人工确认清单（不能省）

- [ ] 病历已**封存**并取得封存清单（不是只复印）？
- [ ] 封存时**医患双方共同在场**，清单上有双方签字与日期？
- [ ] 客观性病历已**全部**复印并加盖医疗机构证明印记？
- [ ] 死亡情形的**尸检时间窗**已确认，告知记录已留存？
- [ ] 疑似实物（药品、器械、血液）已封存？
- [ ] 所有票据已收集并分类整理（医疗费、交通费、辅助器具）？
- [ ] 已申请核查电子病历的**修改留痕**？
- [ ] 鉴定的类型、机构、费用、周期已明确？
- [ ] **未**在任何"一次性了结"文件上签字？
- [ ] 诉讼时效（一般三年）未经过，或已书面主张权利留痕？

## 七、最常见的坑

1. **只复印不封存**。复印只能拿到客观病历，**主观性病历（病程记录、会诊意见、讨论记录）必须封存**，否则后续被修改无从查证。
2. **错过尸检时间窗**。死后 48 小时（可冻存延长至 7 日）是硬时间窗，错过即死因无法查明，会直接导致举证不能。
3. **收到尸检告知后口头拒绝且不签字**。可能被认定为拒绝一方，承担死因无法判定的不利后果；应当书面回应并保留副本。
4. **过早签署"一次性了结"和解协议**。后续治疗费、后遗症往往在签约后才显现，签了通常不能再主张。重大损害**不要**在鉴定前签。
5. **把"并发症""医疗意外"当免责理由**。并发症不等于无过错，关键看是否尽到诊疗义务、是否充分告知、是否及时处置。
6. **未做鉴定就主张金额**。没有过错与因果关系的鉴定意见，金额主张缺乏支撑，也容易错过调解窗口。
7. **把"不构成医疗事故"当"不用赔"**。医疗事故技术鉴定是行政路径，不构成事故**不影响**依医疗损害责任主张民事赔偿。
8. **忽略电子病历修改留痕**。电子病历修改应留痕，可申请调取修改记录，这是识别事后补记的关键。
9. **调解协议未经司法确认**。医调委调解协议可依法申请司法确认，未经确认的强制执行力有限。
10. **只找当事医生**。医疗损害责任的承担主体是**医疗机构**，不是医生个人（非法行医等情形除外）。
11. **超过诉讼时效**。一般为三年，自知道或应当知道损害及义务人之日起算；久拖不决应书面主张权利留痕。

## 八、边界与免责

本技能输出的是**证据固定流程、路径选择与金额核算方法**，不是医疗过错认定、鉴定意见或法律意见。医疗行为是否存在过错、因果关系及原因力大小，由具备资质的鉴定机构出具意见；是否构成医疗事故由医学会或卫生健康行政部门依法认定；赔偿数额最终由医患双方协商、调解协议或人民法院裁判确定。涉及死亡、重度残疾、诉讼的，请务必委托专业医疗纠纷律师。人身损害赔偿的计算标准各地每年更新，请以受诉法院所在地现行公布的数据为准。
