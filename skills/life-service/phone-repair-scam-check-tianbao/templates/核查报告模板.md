# 手机维修核查报告（模板）

> 脚本会自动生成下列九段结构。本模板供人工复核与手工补写时参照，**不要手工编造数据**。

## 1. 结论摘要
- 维修方 / 报修问题 / 是否官方售后 / 已付金额
- 骗局手法命中数 / 风险项数 / 维修结果
- **总体结论：通过 / 有风险 / 不通过 / 待补正**

## 2. 故障诊断与报价核查
- 报修问题、对方诊断、是否官方、是否事前报价、是否有单据
- 诊断与报修是否吻合（是否小病大修）

## 3. 骗局手法与维修方核查
- 维修方主体、资质、渠道
- 命中的骗局手法（偷换 / 小病大修 / 坐地起价 / 以次充好 / 无资质）
- 风险项（旧件未归还、无单据、非官方且资质不明）

## 4. 费用与收款核查
- 报价 / 已付 / 已退 / 未退
- 是否超报价、收款主体是否与维修方一致、是否个人账户或现金

## 5. 维修结果与质保
- 原故障是否解决、是否出现新故障、保修承诺范围

## 6. 法律后果、合规取证路径与举报入口
- 三包规定时限、消法第五十五条退一赔三、价格法
- 举报入口：12315、市场监管部门、公安

## 7. 证据清单与固定要点
- 已具备 / 仍缺失（分类列出）
- 固定要点：拆机前后照、旧件照、聊天上下文导出、付款备注

## 8. 待办补正动作
- 编号列出，每条都是**可执行动作**

## 9. 边界与纪律
- 不替代法律意见与官方核验
- 维修合理性以实物检测与官方售后复核为准
- **不提供任何维修、代修或介绍维修渠道服务**

---

## 复核要点（人工看报告时对照）

| 检查项 | 合格标准 |
| --- | --- |
| 结论是否四态之一 | 通过/有风险/不通过/待补正，勿出现其他词 |
| 是否杜撰数据 | 所有数字、日期、主体名均来自采集表 |
| 未填项处理 | 一律不得判「通过」 |
| 是否含维修服务 | 不得出现推荐商家、代修、报价引流 |
| 待办是否可执行 | 每条都能落到具体动作 |
