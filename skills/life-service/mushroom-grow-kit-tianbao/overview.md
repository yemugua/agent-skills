# 食用菌菌棒家庭种植与杂菌污染识别

## 你会得到什么

一套**控温湿通风、每天查污染、按成熟度采收**的家庭菌棒口径。家庭种菌棒失败绝大多数不是不会种，是杂菌污染没及时发现——等到整袋发绿、有酒味才发现，挽救基本无望；发现得早（只冒一小片绿斑）还有可能靠加强通风和降温压住。

- **六类菌棒参数表**：平菇、香菇、金针菇、木耳、杏鲍菇、茶树菇的发菌期温度、出菇期温度、相对湿度、开袋或划口时机与采收周期。
- **明确温度是第一变量**：发菌期温度不达标，菌丝生长慢或不整齐，后面湿度怎么控都补不回来；家庭最容易出问题的就是夏天室温过高。
- **湿度维持方式**：地面洒水、覆盖湿布、周围放水盆，**不靠天天往菌棒上喷水**——表面长期潮湿正是杂菌孢子萌发最有利的环境。
- **十类污染征兆表**：绿色绒毛、深绿斑点、红色紫色绒毛、白色絮状物、黑色绒毛、酒味、酸味酸败味、渗液黏性、局部生长大片空袋、菌丝发黄变褐，每条配污染源、紧急程度与处置方式。
- **白色菌丝与白色霉菌四条区分**：生长速度、气味、分布、手感；并给一条判定原则——**判断不确定时按污染处理并移出**，因为污染棒留在原处会污染整批。
- **污染率五级分级**：0%、1%-5%、6%-15%、16%-30%、30% 以上，各配处置动作。
- **处置六步顺序**：停止喷水 → 移出隔离 → 加强通风降温 → 单独密封 → 记录 → 复查。
- **采收成熟度判据**：菌盖由卷曲变为平展但尚未完全摊开、边缘仍内卷时采收，孢子量最少；含采收手法与采后管理。
- **不出菇的五步排查**：温度、光照、湿度、开袋时机、是否已污染。
- **安全红线七条**：野生菌一律不采不食、污染菌棒不当厨余、**不喷药救菌棒**、开袋与出菇期避开儿童宠物、孢子防护、采后尽快食用。

## 典型用法

- 买了一盒菌棒，不知道温度湿度怎么控
- 菌棒表面冒了一小片绿毛，还能不能救
- 袋口有酒味，是怎么回事
- 什么时候开袋、划多深
- 平菇长到多大可以摘
- 菌棒养了一个月还没出菇

## 边界

不替代菌种供应方与农技部门的技术指导。不提供菌种品系名称与供种渠道，品种选择以供种方说明和当地农技部门为准。**不推荐任何杀菌剂、消毒剂或农药，家庭条件下不使用药剂处理菌棒**，污染处置靠移出、隔离与废弃。污染源的微生物种类鉴定以专业检测结论为准。不承诺出菇率与产量。**野生菌一律不采不食**，误食不明菌菇立即就医。废弃菌棒处理应符合当地环保与农业废弃物管理要求。
