# 食用菌菌棒家庭种植与杂菌污染识别（mushroom-grow-kit）

家庭种菌棒失败，**绝大多数不是"不会种"，是杂菌污染没及时发现**。等到整袋发绿、有酒味才发现，挽救基本无望；发现得早（只冒一小片绿斑）还有可能靠加强通风和降温压住。

这个技能做三件事：**控温湿通风 → 认污染 → 判采收**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出菌棒类型的温湿度与通风口径 | ❌ 提供具体菌种品系的名称与供种渠道 |
| 列出杂菌污染征兆与处置顺序 | ❌ 推荐杀菌剂、消毒剂品牌与浓度 |
| 给出污染率分级与废弃处置口径 | ❌ 判断污染的具体微生物种类 |
| 给出出菇期管理与采收成熟度判据 | ❌ 承诺出菇率与产量 |
| 给出家庭场所的安全边界 | ❌ 指导使用高毒农药处理污染菌棒 |

**遇到以下情况，停止自行处理，转交菌种供应方或当地农技部门：**

- 整袋大面积污染且已出现明显霉味、酒味与渗液
- 疑似野生毒菇误采误食风险的情形
- 需要鉴定污染源的微生物种类
- 需要确定菌种来源与检疫状态
- 计划在生产场所或大规模场地种植

**安全红线（必须遵守）：**

1. **野生菌一律不采不食**：野外采回或不认识的菌菇**不加工、不试味**。**野生毒菇中毒没有低剂量安全线**，误食请立即就医，不要观察等待。
2. **污染菌棒不当厨余**：污染菌棒**不得丢弃在河边、树林、菜地或垃圾桶外**，须集中无害化处理。杂菌孢子扩散会污染周围环境与下一批菌种。
3. **不喷药救菌棒**：家庭条件下**不使用任何杀菌剂或农药处理菌棒**——菌丝与杂菌同处一袋，药剂会同时伤到菌丝，且残留影响食用安全。污染的处置是**移出、隔离、废弃**。
4. **开封与出菇期通风**：菌棒开袋与出菇期会产生孢子粉尘，**在通风处操作，避开儿童与宠物**，操作后洗手；孢子对呼吸道敏感者（哮喘、过敏体质）尤其要注意。
5. **孢子扩散防护**：出菇期菌盖完全展开前是孢子量最少的时候，**采收要在菌盖尚未完全摊开时进行**，这是减少粉尘扩散的关键动作。
6. **食用安全**：家庭种植的菌菇**采收后尽快食用**，不采收已经发黄、变软、有异味的菇体。

## 二、完整工作流

```
第 1 步  认菌棒类型：不同类型参数差别很大，先确认
第 2 步  控温：发菌期温度是决定成败的第一变量
第 3 步  控湿与通风：湿度靠地面与覆盖，不靠天天喷水
第 4 步  每天查污染：绿斑、酒味、渗液、酸败味
第 5 步  判污染率并分级处置：小面积加强通风，大面积废弃
第 6 步  按类型开袋或划口，进入出菇期
第 7 步  出菇期管理与喷水口径
第 8 步  按成熟度采收，菌盖未完全摊开即采
```

**顺序不能颠倒**：不控温度就谈湿度，是菌棒失败最常见的起点。

## 三、菌棒类型与参数

| 类型 | 发菌期温度 | 出菇期温度 | 相对湿度 | 开袋或划口时机 | 采收周期 |
|---|---|---|---|---|---|
| 平菇类 | 20-25℃ | 15-25℃ | 85-95% | 菌丝基本长满、袋口出现原基后划口 | 每天或隔天 |
| 香菇类 | 20-25℃ | 15-22℃ | 85-90% | 菌丝长满后按供种方要求处理 | 数天一批 |
| 金针菇类 | 18-22℃ | 8-15℃ | 80-90% | 按供种方要求套袋或不套袋 | 整批一次采 |
| 木耳类 | 22-28℃ | 18-26℃ | 85-95% | 菌丝长满后划口 | 每天或隔天 |
| 杏鲍菇类 | 20-25℃ | 15-20℃ | 85-90% | 菌丝长满后开袋 | 隔天采 |
| 茶树菇类 | 22-26℃ | 18-24℃ | 85-95% | 菌丝长满后划口 | 隔天采 |

**温度是第一变量**：发菌期温度不达标，菌丝生长慢或不整齐，后面无论湿度怎么控都补不回来。**家庭环境最容易出问题的就是夏天室温过高**。

**温度超标时的处置**：移至阴凉处、加遮阳、地面洒水降温、通风。**不要往菌棒上直接浇大量冷水降温**，温度骤变与积水都会引发污染。

## 四、湿度与通风

| 项目 | 口径 |
|---|---|
| 湿度维持方式 | 地面洒水、覆盖湿布、周围放水盆；**不靠天天往菌棒上喷水** |
| 喷水要点 | 少量多次，**喷到菌棒表面湿润但不滴水**；水珠挂在菇体上易引发软腐 |
| 喷水时机 | 避开菇体采收前与菇体含水量最高时 |
| 通风 | 出菇期必须有通风，否则菇体畸形、黏连、变黄 |
| 通风与湿度矛盾 | 用**时间错开**解决：白天通风，夜间覆盖保湿 |
| 光照 | 散射光即可；**完全黑暗会导致菇体苍白、菇柄过长** |

**为什么不能天天喷**：菌棒表面长期潮湿，是杂菌孢子萌发最有利的环境。**越喷越湿，越容易污染**，形成恶性循环。

## 五、杂菌污染征兆对照表

| 征兆 | 出现位置 | 可能污染源 | 紧急程度 | 处置顺序 |
|---|---|---|---|---|
| 绿色或黄绿色绒毛状霉层 | 菌棒表面或划口 | 绿霉类 | 高 | 见处置流程第 1 步 |
| 深绿色斑点、边界清晰 | 菌棒表面 | 绿霉类早期 | 中 | 早期可加强通风与降温观察 |
| 红色或紫色绒毛 | 菌棒表面 | 红色霉菌类 | 高 | 立即移出隔离 |
| 白色絮状物快速扩展 | 菌棒表面 | 棉状霉菌 | 中 | 移出，注意与正常菌丝区分 |
| 黑色斑点或黑色绒毛 | 菌棒表面 | 黑色霉菌类 | 高 | 立即移出 |
| 明显酒味或发酵味 | 袋内或袋口 | 细菌污染 | **最高** | 立即移出，不再尝试挽救 |
| 酸味、酸败味、刺鼻味 | 袋内或渗液 | 细菌污染 | **最高** | 立即移出 |
| 渗液、带颜色、有黏性 | 袋体 | 细菌污染并已变质 | **最高** | 立即移出，整袋废弃 |
| 菌丝只在局部生长、大片空袋 | 袋内 | 接种不均或已污染 | 中 | 属废棒，需分开 |
| 菌丝发黄、变褐、停止生长 | 袋内 | 温度不达标或污染 | 中 | 先查温度记录 |

**白色菌丝与白色霉菌的区分**：

| 对比 | 正常菌丝 | 白色霉菌 |
|---|---|---|
| 生长速度 | 相对规律，按日推进 | 常在 1-2 天内大片扩展 |
| 气味 | 无异味 | 可能有土腥味或发酵味 |
| 分布 | 从接种点向外均匀推进 | 常从一处突然扩展、有明确边界 |
| 手感 | 细腻、均匀 | 常呈絮状或绒毛状 |

**判断不确定时，按污染处理并移出**——污染棒的代价是一棒，正常棒被误判移出的代价是一棒，**但污染棒留在原处会污染整批**。

## 六、污染率分级与处置

```
污染率 = 污染棒数 / 总棒数
```

| 污染率 | 等级 | 处置 |
|---|---|---|
| 0% | 无污染 | 正常管理 |
| 1%-5% | 轻度 | 加强通风、降温降湿，单独隔离放置，每日复查 |
| 6%-15% | 中度 | 污染棒移出，单独密封后再处理；健康棒分区管理 |
| 16%-30% | 重度 | 污染棒全部移出并密封处理；检查环境湿度与通风是否失效 |
| 30% 以上 | 严重 | 整批停止后续种植，环境彻底清洁与通风改造后再开始 |

**处置顺序（不能跳步）**：

1. **停止喷水**：污染扩散最快的条件是高湿
2. **移出隔离**：污染棒单独移出并密封，不要在原环境内处理
3. **加强通风降温**：降低环境湿度，抑制孢子萌发
4. **单独密封**：污染棒密封后再按当地要求处置
5. **记录**：记录污染率与位置，判断是环境问题还是批次问题
6. **复查**：轻度的每日复查，观察是否扩散

## 七、出菇期管理与采收

| 项目 | 口径 |
|---|---|
| 原基识别 | 划口处出现白色或灰色小疙瘩状原基，是出菇的前兆 |
| 幼菇期 | 小而紧实，喷水要避开菇体 |
| 膨大期 | 菇体快速长大，此时保持湿度与通风 |
| 成熟期特征 | **菌盖由卷曲变为平展但尚未完全摊开**；边缘仍内卷 |
| 采收时机 | **菌盖未完全摊开时采收**，此时孢子量最少、品质最好 |
| 采收手法 | 整丛从基部拧下或用刀沿基部切下，**不从菇体中段硬拽** |
| 采收后 | 清除残茬，清理袋口，补充水分恢复出菇 |
| 停喷水 | 采收当天不喷水，减少菇体含水量 |
| 采后处理 | 尽快食用；发黄、变软、有异味的菇体不采不食 |

**为什么要在菌盖未完全摊开时采**：菌盖完全摊开后开始大量弹孢子，**孢子粉尘对呼吸道敏感者（尤其儿童、老人、哮喘与过敏体质）有影响**，同时菇体品质下降。

**不出菇的原因排查顺序**：

1. 温度是否在出菇期范围（很多是温度太高）
2. 光照是否为零（长期完全黑暗会导致菇体畸形或不形成）
3. 湿度是否不足（尤其花期与幼菇期）
4. 是否已充分成熟才开袋（菌丝未长满就开袋会导致不出菇）
5. 是否已因污染失去产菇能力

## 八、脚本用法

```
python scripts/mushroom_check.py --file kit.json
python scripts/mushroom_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`kind`（菌棒类型）、`stage`（发菌期/出菇期）、`temp_c`、`humidity`、`total`、`contaminated`、`signs`、`cap_open`、`days_since_open` |
| `--json` | 以 JSON 输出 |
| `--out` | 结果写入指定文件，默认 `scripts/_last_result.txt` |
| `--selftest` | 运行自检 |

脚本做四件事：**按类型与阶段给出温度湿度区间并判定是否达标 → 按征兆定位污染类型与紧急程度 → 算污染率并给出分级处置 → 判采收时机**。脚本**不提供菌种品系、药剂与消毒剂**。

## 十、最常见的坑

**坑一：发菌期温度不达标还硬等。**
错误做法：夏天室温 30℃ 以为"菌丝会自己适应"。正确做法：移阴凉处、加遮阳、地面洒水、通风降温。**发菌期温度是决定成败的第一变量**，不达标后面无法补救。

**坑二：天天喷水保湿。**
错误做法：为了保湿每天往菌棒上喷一遍。正确做法：地面洒水、覆盖湿布、周围放水盆。**菌棒表面长期潮湿正是杂菌孢子萌发最有利的环境**，越喷越湿越容易污染。

**坑三：发现小绿斑再观察几天。**
错误做法：看到一小片绿斑想着"再看看能不能控制住"。正确做法：**污染按小时扩散**，发现当天就停止喷水、移出隔离、加强通风。轻度的还有可能压住，等扩散就晚了。

**坑四：有酒味还想着焐一焐。**
错误做法：袋口有酒味，认为"闷一闷就好了"。正确做法：**酒味是细菌污染的最高优先级信号，立即移出，不再尝试挽救**。细菌污染一旦出现，袋内已经变质，任何处理都救不回来。

**坑五：用消毒剂泡菌棒救污染。**
错误做法：把污染的菌棒泡消毒液 hoping 杀菌。正确做法：**家庭条件下不使用任何杀菌剂或农药处理菌棒**。菌丝与杂菌同处一袋，药剂会同时伤到菌丝，且残留影响食用安全。**污染的处置是移出、隔离、废弃**。

**坑六：菌盖完全摊开才采。**
错误做法：等菌盖完全平展、边缘完全外翻才采。正确做法：**菌盖未完全摊开、边缘仍内卷时就采**。完全摊开后才大量弹孢子，粉尘对呼吸道敏感者有影响，品质也下降。

**坑七：采收时硬拽菇体。**
错误做法：抓住菇体中段往上拽。正确做法：整丛从基部拧下或用刀沿基部切下。**从中段硬拽会拉伤菌丝和基部**，影响后续出菇。

**坑八：污染棒随手丢。**
错误做法：污染的菌棒扔到楼下垃圾桶、河边或菜地。正确做法：单独密封后按当地要求处置。**杂菌孢子扩散会污染周围环境与下一批菌种**，这是很多人第二批也失败的原因。

## 十一、边界与免责

- 本技能提供家庭菌棒种植的温湿度通风口径、杂菌污染征兆对照与采收判据，**不替代菌种供应方与农技部门的技术指导**
- 不提供菌种品系名称与供种渠道；**品种选择以供种方说明和当地农技部门为准**
- 不推荐任何杀菌剂、消毒剂或农药；**家庭条件下不使用药剂处理菌棒**，污染处置靠移出、隔离与废弃
- 污染源的微生物种类鉴定**须以专业检测结论为准**，本技能只给风险分级与处置顺序
- 不承诺出菇率与产量；产量受菌种质量、温度、湿度与通风条件影响很大
- **野生菌一律不采不食**；误食不明菌菇立即就医，不要观察等待
- 废弃菌棒的处理**应符合当地环保与农业废弃物管理要求**
