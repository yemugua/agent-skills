# 菌棒类型参数与污染征兆

> 本文件不含任何药剂名称、品牌与浓度。家庭条件下不使用药剂处理菌棒。

## 一、菌棒类型参数表

| 类型 | 发菌期温度 | 出菇期温度 | 相对湿度 | 开袋或划口时机 | 采收周期 |
|---|---|---|---|---|---|
| 平菇类 | 20-25℃ | 15-25℃ | 85-95% | 菌丝基本长满、袋口出现原基后划口 | 每天或隔天 |
| 香菇类 | 20-25℃ | 15-22℃ | 85-90% | 菌丝长满后按供种方要求处理 | 数天一批 |
| 金针菇类 | 18-22℃ | 8-15℃ | 80-90% | 按供种方要求套袋或不套袋 | 整批一次采 |
| 木耳类 | 22-28℃ | 18-26℃ | 85-95% | 菌丝长满后划口 | 每天或隔天 |
| 杏鲍菇类 | 20-25℃ | 15-20℃ | 85-90% | 菌丝长满后开袋 | 隔天采 |
| 茶树菇类 | 22-26℃ | 18-24℃ | 85-95% | 菌丝长满后划口 | 隔天采 |

**温度是第一变量**：发菌期温度不达标，菌丝生长慢或不整齐，后面无论湿度怎么控都补不回来。家庭环境最容易出问题的就是夏天室温过高。

**温度超标处置**：移至阴凉处、加遮阳、地面洒水降温、通风。不要往菌棒上直接浇大量冷水降温，温度骤变与积水都会引发污染。

## 二、湿度与通风

| 项目 | 口径 |
|---|---|
| 湿度维持 | 地面洒水、覆盖湿布、周围放水盆；不靠天天往菌棒上喷水 |
| 喷水要点 | 少量多次，喷到表面湿润但不滴水；水珠挂在菇体上易引发软腐 |
| 喷水时机 | 避开菇体采收前与菇体含水量最高时 |
| 通风 | 出菇期必须有通风，否则菇体畸形、黏连、变黄 |
| 通风与湿度矛盾 | 用时间错开：白天通风，夜间覆盖保湿 |
| 光照 | 散射光即可；完全黑暗会导致菇体苍白、菇柄过长 |

## 三、杂菌污染征兆表

| 征兆 | 出现位置 | 可能污染源 | 紧急程度 | 处置 |
|---|---|---|---|---|
| 绿色或黄绿色绒毛状霉层 | 表面或划口 | 绿霉类 | 高 | 立即执行处置流程 |
| 深绿色斑点、边界清晰 | 表面 | 绿霉类早期 | 中 | 早期可加强通风降温观察 |
| 红色或紫色绒毛 | 表面 | 红色霉菌类 | 高 | 立即移出隔离 |
| 白色絮状物快速扩展 | 表面 | 棉状霉菌 | 中 | 移出，注意与正常菌丝区分 |
| 黑色斑点或黑色绒毛 | 表面 | 黑色霉菌类 | 高 | 立即移出 |
| 明显酒味或发酵味 | 袋内或袋口 | 细菌污染 | 最高 | 立即移出，不再尝试挽救 |
| 酸味、酸败味、刺鼻味 | 袋内或渗液 | 细菌污染 | 最高 | 立即移出 |
| 渗液、带颜色、有黏性 | 袋体 | 细菌污染并已变质 | 最高 | 立即移出，整袋废弃 |
| 菌丝只在局部生长、大片空袋 | 袋内 | 接种不均或已污染 | 中 | 属废棒，需分开 |
| 菌丝发黄、变褐、停止生长 | 袋内 | 温度不达标或污染 | 中 | 先查温度记录 |

## 四、白色菌丝与白色霉菌的区分

| 对比 | 正常菌丝 | 白色霉菌 |
|---|---|---|
| 生长速度 | 相对规律，按日推进 | 常在 1-2 天内大片扩展 |
| 气味 | 无异味 | 可能有土腥味或发酵味 |
| 分布 | 从接种点向外均匀推进 | 常从一处突然扩展、有明确边界 |
| 手感 | 细腻、均匀 | 常呈絮状或绒毛状 |

**判断不确定时按污染处理并移出**：污染棒的代价是一棒，误判移出的代价也是一棒，但**污染棒留在原处会污染整批**。

## 五、污染率分级与处置

```
污染率 = 污染棒数 / 总棒数
```

| 污染率 | 等级 | 处置 |
|---|---|---|
| 0% | 无污染 | 正常管理 |
| 1%-5% | 轻度 | 加强通风、降温降湿，单独隔离放置，每日复查 |
| 6%-15% | 中度 | 污染棒移出并单独密封处理；健康棒分区管理 |
| 16%-30% | 重度 | 污染棒全部移出并密封处理；检查环境湿度与通风是否失效 |
| 30% 以上 | 严重 | 整批停止后续种植，环境彻底清洁与通风改造后再开始 |

## 六、处置顺序（不能跳步）

1. **停止喷水**：污染扩散最快的条件是高湿
2. **移出隔离**：污染棒单独移出并密封，不在原环境内处理
3. **加强通风降温**：降低环境湿度，抑制孢子萌发
4. **单独密封**：密封后再按当地要求处置
5. **记录**：记录污染率与位置，判断是环境问题还是批次问题
6. **复查**：轻度每日复查，观察是否扩散

## 七、出菇期管理与采收

| 项目 | 口径 |
|---|---|
| 原基识别 | 划口处出现白色或灰色小疙瘩状原基 |
| 幼菇期 | 小而紧实，喷水避开菇体 |
| 膨大期 | 菇体快速长大，保持湿度与通风 |
| 成熟期特征 | 菌盖由卷曲变为平展但尚未完全摊开，边缘仍内卷 |
| 采收时机 | **菌盖未完全摊开时采收**，此时孢子量最少、品质最好 |
| 采收手法 | 整丛从基部拧下或用刀沿基部切下，不从菇体中段硬拽 |
| 采收后 | 清除残茬，清理袋口，补充水分恢复出菇 |
| 停喷水 | 采收当天不喷水 |
| 采后处理 | 尽快食用；发黄、变软、有异味的菇体不采不食 |

**为什么要早采**：菌盖完全摊开后大量弹孢子，粉尘对呼吸道敏感者（儿童、老人、哮喘与过敏体质）有影响，同时品质下降。

## 八、不出菇的原因排查顺序

1. 温度是否在出菇期范围（很多是温度太高）
2. 光照是否为零（长期完全黑暗导致菇体畸形或不形成）
3. 湿度是否不足（尤其花期与幼菇期）
4. 是否充分成熟才开袋（菌丝未长满就开袋会导致不出菇）
5. 是否已因污染失去产菇能力

## 九、安全红线

| 项目 | 口径 |
|---|---|
| 野生菌 | 一律不采不食；误食不明菌菇立即就医，不观察等待 |
| 污染菌棒处置 | 不丢弃在河边、树林、菜地或垃圾桶外；单独密封后按当地要求处置 |
| 药剂 | 家庭条件下不使用杀菌剂或农药处理菌棒 |
| 开袋与出菇 | 在通风处操作，避开儿童与宠物，操作后洗手 |
| 孢子防护 | 菌盖完全展开前采收，采收是减少粉尘扩散的关键动作 |
| 呼吸道敏感者 | 哮喘、过敏体质者尤其注意孢子粉尘 |
| 食用安全 | 采后尽快食用；发黄、变软、有异味的菇体不采不食 |

## 十、必须转供种方或农技部门的情形

- 整袋大面积污染且已出现明显霉味、酒味与渗液
- 疑似野生毒菇误采误食风险的情形
- 需要鉴定污染源的微生物种类
- 需要确定菌种来源与检疫状态
- 计划在生产场所或大规模场地种植
