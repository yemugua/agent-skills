# 校园霸凌识别与应对处置核查

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 用重复性、故意性、力量不对等、伤害后果、排除合理争辩五个维度区分霸凌与冲突 | 断言「这就是霸凌」或「这不算霸凌」，定性结论交由学校与专业人员 |
| 输出取证路径、材料类型与时间线整理方式 | 组织或指导孩子偷拍、跟踪、设套取证 |
| 给出学生 → 家长 → 班主任与学校 → 必要时报警与妇联的处置顺序 | 建议私自报复、围堵、约架、以暴制暴或找校外人员 |
| 提供受欺凌方、施暴方、围观同学、家长四方话术 | 代替家长与学校沟通，或代写威胁性内容 |
| 说明必须报警的情形（伤害、威胁、拍摄传播、性相关、索要财物） | 对人身安全风险作担保或淡化处理 |
| 提示情绪观察与求助资源（心理热线等） | 做心理诊断、评估创伤严重程度并给治疗方案 |
| 说明信息保护与学校信息公开的边界 | 承诺调查结果或处理时限（学校内部程序不由本技能决定） |

**必须立即报警或就医的红线（出现任一条，先保证人身安全再谈其他）**

- 已发生或即将发生的人身伤害（击打、推搡致伤、器械伤害、勒颈、按压胸腹）
- 涉及性相关的内容、言语、影像、胁迫或接触 —— 立即报警，同时保留证据，不与对方私下协商
- 被索要财物、财物被抢、被拍裸照或隐私部位照片、收到威胁「带多少钱来」「不准告诉家长」
- 长期、反复的暴力导致受伤，或出现头部撞击后呕吐、意识模糊、剧烈头痛、抽搐
- 出现呼吸困难、胸痛、腹部损伤、骨折可疑、四肢畸形
- 孩子表达明确的自杀念头、说「不想活了」，或出现自伤行为 —— 立即报警并同步心理危机干预
- 出现群体性围殴、社交软件上组织性的排挤与威胁
- 出现传播受欺凌者隐私照片、视频并伴随要挟

**绝对禁止**：教唆以暴制暴、私自报复、组织围堵或找人「谈一谈」；教唆孩子偷录他人隐私、传播施暴者照片「曝光」；让孩子独自去找施暴者「说清楚」。

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「怎么判断是霸凌还是普通吵架」 | 用，五维判定 |
| 「孩子被欺负了家长该怎么办」 | 用，处置顺序 |
| 「要不要收集证据」 | 用，取证路径与安全边界 |
| 「被欺负了要不要打回去」 | 用，明确禁止并给替代做法 |
| 「孩子不肯说怎么办」 | 用，沟通话术 |
| 「围观的同学该做什么」 | 用，围观者正确做法 |
| 「要不要转学」 | 用，先看学校处置与安全整改，不作为第一手段 |
| 「老师不管怎么办」 | 用，升级路径与外部渠道 |
| 「孩子被打后怎么处理伤口」 | 只作就医提示，伤口处理与诊断由医护人员负责 |

## 三、完整工作流

1. **先保安全**：确认孩子当下是否处于危险中，是否已受伤。命中红线先报警或就医。
2. **听孩子说，不做结论**：用 `rules/识别判定维度.md` 的提问顺序记录事实，不打断、不追问细节、不下结论。
3. **五维判定**：逐维打分，输出「倾向霸凌 / 倾向冲突 / 信息不足」三档，并写明依据与缺口。
4. **取证整理**：按 `rules/取证路径与安全边界.md` 整理时间地点、在校时间线、聊天记录、伤情照片、证人与时间，**不组织任何私自取证**。
5. **按级处置**：学生 → 家长 → 班主任与学校 → 必要时报警与妇联（妇联、公安、教育部门为对应渠道名称，具体入口以当地主管部门公布为准）。
6. **准备沟通材料**：用 `templates/事件记录与沟通材料表.md`，一页纸写清时间线、诉求与已采取措施。
7. **给出四方话术**：受欺凌方、家长对老师、家长对施暴方家长、围观同学。
8. **安排情绪观察与复盘**：4 周内每周问一次安全感受，明确需要专业心理支持的信号。

## 四、核心规则与要件库

生成任何判定或处置建议前，**必须先读**：

- `rules/识别判定维度.md`：五维判定口径、霸凌与冲突对照、常见误判、心理支持边界。
- `rules/取证路径与安全边界.md`：材料类型、时间线整理、四级处置顺序、各方话术、禁止行为。

不得输出定性结论（这不是霸凌）；不得给出以暴制暴、私自报复、偷拍曝光类建议；不得承诺学校处理时限与结果。

## 五、脚本用法

```
python scripts/bullying_assess.py --file case.json
python scripts/bullying_assess.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`dimensions` 五维标记（`repeated` `intentional` `power_imbalance` `harm` `not_provable`），`red_flags` 红线标记，`evidence` 已有证据类型列表，`weeks` 已持续周数 |
| `--json` | 以 JSON 输出 |
| `--out` | 结果写入指定文件，默认 `scripts/_last_result.txt` |
| `--selftest` | 运行自检 |

脚本输出判定档位与依据、处置顺序、取证缺口与红旗提示。**脚本不下定性结论、不提供药物与心理治疗方案。**

## 六、人工确认清单

- [ ] 已先确认孩子当下是否安全、是否受伤
- [ ] 红线已逐条核对，命中即报警或就医
- [ ] 已用五维逐条记录，未凭印象或单方转述下结论
- [ ] 已明确告知「冲突不等于霸凌」，也未轻率否定
- [ ] 未组织偷拍、跟踪、设套等私自取证
- [ ] 未建议以暴制暴、私自报复或找校外人员
- [ ] 未建议传播施暴者照片「曝光」
- [ ] 已告知学校内部程序与时限不由家长或本技能决定
- [ ] 已安排情绪观察并写明需要专业心理支持的信号
- [ ] 已说明信息保护边界，避免二次传播伤害孩子隐私

## 七、最常见的坑

1. **把所有冲突都当霸凌**：一次争执、一次抢东西、一次言语不中，都不构成霸凌。误判会让家长被学校认为不客观，也可能让真正的霸凌被稀释。
2. **把所有霸凌都当「小孩之间的事」**：有伤害、有传播、有要挟的已经不是小事，需要按红线处理。
3. **只让孩子「别理他」「强大一点」**：无效且可能让孩子觉得是自己的错。
4. **以暴制暴**：教唆孩子打回去，短期解气，实际会把孩子推向被排除、受伤、被退学的风险更高位置。
5. **私自取证**：带孩子去施暴者家、偷拍视频、找人对质，会把安全风险全部转给孩子。
6. **扩散施暴者照片「曝光」**：可能构成侵权与二次伤害，且往往引发新一轮报复循环。
7. **一次谈话就结案**：处理后不观察是否复发。霸凌往往是重复发生的，只处理单次事件等于没处理。
8. **让孩子当小侦探**：反复追问细节、要求复述经过，会造成二次创伤。孩子拒绝说不等于不发生。
9. **先转学后处理**：转学把风险带给孩子下一所学校，学校的问题没被整改，也可能遭遇新环境同样问题。
10. **忽略围观者**：多数霸凌场景里有旁观者，围观者不作为会让施暴行为被强化。

## 八、边界与免责

本技能提供霸凌与冲突的判定维度、取证路径与处置顺序参考，**不作定性结论、不提供心理诊断与治疗方案、不提供任何药物建议**。事件的性质认定与处理由学校及教育、公安等主管部门依职权认定，**以学校正式处理结果和当地主管部门要求为准**。涉及人身伤害、性相关伤害、索要财物、威胁恐吓或自伤风险的，必须立即报警。本技能不替代学校、公安机关、妇联或未成年人保护相关机构的正式处理程序。
