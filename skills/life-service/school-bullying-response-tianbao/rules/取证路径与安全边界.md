# 取证路径、安全边界、处置顺序与四方话术

## 一、材料类型（只整理已有与合法可获得的材料）

| 类型 | 具体形式 | 注意 |
|---|---|---|
| 时间线 | 每次事件的时间、地点、在场人、目击者 | 一行一次，不合并 |
| 聊天与信息记录 | 群聊、社交软件信息、威胁文字 | **保留原始设备与原始记录，不剪辑、不转发扩散** |
| 伤情记录 | 就医记录、诊断结果、伤情照片 | 拍照时保留整体与局部，注意隐私部位不拍不传 |
| 校内在场证据 | 在校时间线、活动参加情况、座位与活动安排变化 | 从学校已有的记录中获取，不私自调取监控 |
| 第三方证言 | 目击同学、家长、老师听到的 | 记录为陈述，不要求出具书面材料 |
| 行为变化记录 | 出勤、成绩、睡眠、食欲、情绪 | 用观察表，不用推测 |

**取证的绝对边界（不可越过）**：

- 不带孩子去施暴者家或校外场所
- 不组织偷拍、录音、设套、引诱
- 不私下调取或拷贝学校监控
- 不让被欺凌者独自去找施暴者「说清楚」
- 不找人「谈一谈」或「摆平」
- 不在社交平台曝光施暴者照片、姓名或个人信息
- 不组织孩子之间「和解见面」作为取证手段

## 二、四级处置顺序（不得跳级）

### 第 1 级：学生（立即，安全优先）

- 离开现场到可看见成人的地方
- 明确告知至少一位可信任的成年人
- 不独自对峙、不追赶、不还手、不捡起地上的物品对抗
- 记住可记录的时间与在场人，不强行取证

### 第 2 级：家长（24-72 小时内启动）

- 用 `templates/事件记录与沟通材料表.md` 整理一页纸
- 先与孩子共同确认事实与诉求，不代替孩子决定
- 与班主任或年级教师单独沟通，避开孩子在场时讨论细节

### 第 3 级：学校（书面提出，跟踪闭环）

- 书面提出诉求：查明事实、明确处理、防止复发、后续跟踪
- 要求说明处理依据与后续跟踪安排，**但接受学校内部程序时限不由家长决定**
- 保留沟通记录（时间、在场人、答复要点）
- 处理后 4 周内每两周确认一次是否复发

### 第 4 级：外部渠道（视情形）

- 报警：人身伤害、性相关伤害、索要财物、威胁恐吓、拍摄传播、自伤风险 —— **立即报警，不先走学校流程**
- 未成年人保护相关渠道（妇联设有相关职能、各地设有未成年人保护热线）
- 教育行政部门：学校长期不处理或处理明显不当，可向主管部门反映
- 心理支持：需要时联系学校心理老师、当地心理援助热线或儿童青少年心理专业机构

**渠道名称与入口以当地主管部门公布为准**，本技能不编写具体条款号与网址。

## 三、四方话术（可直接改写使用）

### 对被欺凌的孩子

- 「我相信你，这不是你的错。」
- 「谢谢你告诉我。你不需要一个人扛。」
- 「你想怎么处理？我陪你一起想办法。」
- 「不需要你现在把细节讲清楚，等你准备好了再说。」

### 家长对班主任或年级教师

- 「我想先说明事实，再谈怎么处理。时间线我整理了一页纸在这里。」
- 「这件事已经发生过几次（说次数），我希望学校能查明并防止复发。」
- 「除了处理这次，我希望有后续的跟踪安排。」
- 「我不需要承诺具体结果，但需要知道学校的处理依据和跟进方式。」

### 家长对施暴方家长

- 「我今天联系你不是来吵架的，孩子的事需要一个处理方式。」
- 「我们希望双方孩子都能安全上学。」
- 「具体请通过学校或相关部门沟通，我不在现场冲突。」

### 对围观同学（家长转达或学校倡导）

- 「看到有人在被欺负，你可以：大声说『住手』、陪被欺负的同学一起离开、告诉老师、记下时间地点在场人。」
- 「不要起哄、不要拍摄传播、不要跟着一起笑。」
- 「你不需要一个人去对抗，只要其中一件事做到就有效。」

## 四、明确的禁止行为清单

- 教唆孩子还手、报复、围堵
- 教唆去找校外人员「解决」
- 教唆偷拍或曝光施暴者隐私
- 组织孩子之间「和解见面」作为压力手段
- 让孩子重复讲述被欺负的细节
- 在社交平台公开事件、点名当事人
- 把孩子转学当作第一手段
- 对「我不管他就好了」这类无效建议表示认同

## 五、事后 4 周跟踪表要点

| 周次 | 检查项 | 记录方式 |
|---|---|---|
| 第 1 周 | 是否复发、出勤、睡眠、情绪 | 每项一句具体观察 |
| 第 2 周 | 孩子是否仍害怕、是否回避特定场所 | 具体到场所 |
| 第 3 周 | 与学校沟通一次，确认跟进安排 | 沟通时间与答复要点 |
| 第 4 周 | 是否需要转介专业心理支持 | 给出明确结论：需要 / 暂不需要 |
