# 霸凌与冲突的判定维度（五维）

**前置声明**：本表只提供判定维度与依据整理，**不作定性结论**。事件的性质认定由学校及教育、公安等主管部门依职权认定，以学校正式处理结果和当地主管部门要求为准。

## 一、五个判定维度

每维记「是 / 否 / 不确定」，并写一句依据。**不要凭印象打勾。**

| 维度 | 判定口径 | 记录方式 |
|---|---|---|
| D1 重复发生 | 发生过 2 次及以上，或有明确的长期持续性（持续 2 周以上） | 写清第 1 次与最近 1 次的时间 |
| D2 故意为之 | 有预谋或蓄意，包括挑选时机避开老师、结伙、言语挑衅后动手 | 写清预谋迹象 |
| D3 力量不对等 | 存在人数、体格、地位、性别、是否有成年人介入等不对称 | 写清不对等的具体形式 |
| D4 造成伤害 | 身体伤害、心理伤害、财物损失、名誉与隐私受损（含拍摄与传播） | 写清伤害形式与可观察表现 |
| D5 排除合理争辩 | 已排除「一次争执」「双方都有推挤」「玩耍打闹」「误会后已澄清」等情形 | 写清排除过程与仍存疑点 |

**说明**：D5 是最容易被跳过的一维，也是误判的主要来源。「是不是在玩」需要具体证据支撑，不是猜。

## 二、判定档位（不是结论，是下一步动作的依据）

| 档位 | 口径 | 下一步 |
|---|---|---|
| 倾向霸凌 | D1、D2、D4 中至少 2 项为「是」，且 D3 或 D5 有依据 | 进入完整处置顺序，保留材料，同步情绪观察 |
| 倾向冲突 | D1 不成立（单次），D2 无依据，D3 不明显 | 引导双方沟通与和解，不升级为霸凌处理 |
| 信息不足 | 多维为「不确定」，或孩子表述零散 | 补齐信息后再判，暂不采取强处置动作 |

**否定词防误伤**：「倾向冲突」不等于「不该管」；「信息不足」不等于「不严重」，只表示证据还不足以定性，此时仍要做安全安排与情绪观察。

## 三、常见误判对照

| 情形 | 是否属霸凌判定范畴 | 说明 |
|---|---|---|
| 一次争执，双方都有推挤 | 通常不属于 | 无重复、无预谋、力量大体对等，可按冲突处理 |
| 同学间打闹，未造成伤害 | 通常不属于 | 若被欺负一方明显害怕或拒绝参与，则需重新看 D2、D3 |
| 同学间打闹，一方持续处于劣势且不敢反抗 | 需要五维完整核查 | 玩耍与霸凌的差别要看弱势方的感受与反应 |
| 长期被嘲笑孤立、无人一起吃饭 | 可能是霸凌 | 社交排斥型霸凌不易被看见，需重点记录时间线 |
| 一次性言语冒犯后已澄清道歉 | 通常不属于 | 但要记录并观察是否重复 |
| 索要财物、威胁「不准告诉家长」 | 属于霸凌且命中红线 | 立即报警 |
| 拍摄隐私部位照片并传播或要挟 | 属于霸凌且命中红线 | 立即报警，保留原始设备与信息，不与对方私下协商 |
| 被同学孤立、群聊里被排挤 | 可能是霸凌 | 记录群聊时间线，注意是否伴随要挟 |

## 四、提问顺序（照着问，不打断）

1. 「今天发生了什么？」——让孩子叙述，不打断
2. 「当时有几个人？」——人数是力量不对等的重要信息
3. 「之前有过吗？第一次是什么时候？」——判断重复性
4. 「他们是故意的还是你觉得不是？」——不引导孩子下结论
5. 「他们说了什么、做了什么？」——记录原话，不评价
6. 「你有没有告诉过谁？老师还是别的同学？」——判断学校是否知情
7. 「现在你希望我做什么？」——把主动权部分交给孩子

**禁止**：反复要求复述细节、「他是不是欺负你」这类引导性提问、让孩子录一段说明、发朋友圈寻求支持。

## 五、情绪观察（每周一次，4 周）

需要专业心理支持（建议联系学校心理老师、当地未成年人保护热线或儿童青少年心理专业机构）的信号：

- 连续两周以上睡眠障碍、噩梦、拒绝上学
- 明显食欲下降、体重变化
- 反复腹痛头痛但查不出原因（躯体化表现）
- 情绪低落、易怒、情绪爆发明显增多
- 自伤行为，或说出不想活了、活着没意思
- 拒学、装病、成绩突然大幅下滑

**边界**：以上仅为识别信号，**不做心理诊断、不评估创伤严重程度、不给治疗方案**。任何自伤或自杀相关表达，立即联系心理危机干预与警方。

## 六、对受影响孩子的六条支持原则

1. 先相信再了解，不先质疑
2. 不追问细节，不要求「再讲一遍」
3. 不说「你要坚强」「别理他」「你也有问题」
4. 不承诺「我一定让老师惩罚他」，也不承诺「这事就过去了」
5. 保持日常节奏：睡眠、三餐、运动、朋友，这些是防恶化的底盘
6. 每周固定一次 10 分钟单独时间，只问安全感受，不问细节
