# 抓具选型与摆放口径

## 一、数量口径

| 项目 | 口径 | 说明 |
|---|---|---|
| 抓具总数 | 猫数加一，且不少于 2 | 一处不够，两处才勉强够：猫必须有得选，它才会选我们提供的那个 |
| 小猫（不到半岁） | 按猫数加一，且每处都要有小猫能上的 | 小猫够不到成猫尺寸的抓柱 |
| 多猫家庭 | 每一处都分散在不同房间 | 全堆在一处等于一处；被强势猫占住就没人敢靠近 |
| 分布要求 | 至少有一处在猫常驻的房间 | 放在杂物间、阳台角落基本等于没有 |

> **否定口径**：「总共有两个，其中一个在阳台」不算满足数量，因为它不在生活动线上。**数量达标要同时满足「总数够」与「分布在动线上」两条。**

## 二、形态配置

| 被抓对象 | 形态判定 | 需要的抓具 |
|---|---|---|
| 沙发扶手、桌腿、门框 | 立面 | 立式抓柱或立式抓板，高度要够 |
| 窗帘、墙面、书柜边 | 高立面 | 高立式抓柱，紧跟窗帘旁 |
| 地毯、地垫 | 平面 | 平放抓板，直接压在被抓的那块上 |
| 床沿、沙发坐面 | 平面偏软 | 平放厚抓板，靠近这一侧 |
| 纸箱、被子 | 平面加柔软 | 平放瓦楞纸抓板 |
| 同时抓沙发扶手和地毯 | 立面加平面 | 两种形态都要有，缺一种就会有另一处继续被抓 |

## 三、尺寸口径

| 项目 | 口径 | 不足的后果 |
|---|---|---|
| 立式抓柱高度 | 多数成猫 60 厘米以上，小猫可用 40 厘米 | 高度不够，猫无法完成站立抓伸，会绕过抓柱继续抓家具 |
| 抓面宽度 | 不小于猫站立时的肩宽 | 太窄猫会滑下来 |
| 底座 | 四点着地，底座重量足够 | 站上去会晃就禁止投入使用 |
| 猫树综合型 | 抓面不能少于 40 厘米的可抓高度 | 只有顶端一小截等于没有 |

**身高换算**：想知道你家猫要多少高度，让它站着抓一次，测量前爪最高点到地面的距离，加 10 厘米即为所需抓柱高度下限。不要凭外部平均值硬套。

## 四、四种抓面材质对比

| 材质 | 手感 | 掉屑 | 耐用度 | 适合哪类猫 |
|---|---|---|---|---|
| 剑麻绳 | 粗、适中有回弹 | 少量麻屑 | 高 | 爱抓粗布、麻织家具的猫，多数猫的通用首选 |
| 瓦楞纸 | 松脆、抓时有明显声响 | 较多纸屑 | 低到中 | 爱抓纸箱、纸袋的猫，也适合小猫 |
| 地毯面 | 柔软、密 | 无 | 中到高 | 已经在抓地毯、地垫的猫，先用它做过渡 |
| 麻布包面 | 密实、偏软 | 少量 | 中 | 爱抓布艺沙发但尚不夸张的阶段 |

**选型原则**：按它**现在咬什么、抓什么**来反推，而不是按销量或外观。已经在抓地毯的猫，第一块就给地毯面；已经坐实了抓麻织扶手的猫，第一根就给剑麻。

## 五、摆放位置（最重要的一项）

| 原则 | 做法 |
|---|---|
| 紧贴被抓点 | 新抓具放在被抓处 30 到 50 厘米内，同一视线范围内 |
| 睡醒处优先 | 猫睡醒第一个动作就是伸懒腰加抓挠，卧榻旁必放一处 |
| 进门处可选 | 部分猫进门后会做标记行为，可在玄关加一处 |
| 避免餐盆与猫砂盆旁 | 挨着排泄与进食点会降低使用意愿 |
| 避开过道死角 | 太窄处的抓具猫站不开，用两次就放弃 |

> **转移距离口径**：新抓具到原抓点的距离超过 50 厘米，转移基本失败。这是这一整套里最容易做错、也最容易被误判成「猫就是不喜欢」的一项。

## 六、稳定性检查清单

- [ ] 用力推抓柱顶端，位移不超过 2 厘米
- [ ] 猫全身重量压上去不会倾倒
- [ ] 放在光滑地面上时底下有防滑垫
- [ ] 立面板与底座的连接螺丝无松动
- [ ] 平放抓板不会被猫一把推走

> 第一次被晃倒或吓一次的抓具，猫通常永久不再使用，**这一项没有「再试试」的机会**。

## 七、损耗更换口径

| 观察项 | 处理 |
|---|---|
| 平放瓦楞纸被抓出超过表面积一半的碎沟 | 更换。变得太松软的板，抓感消失，猫会嫌弃 |
| 剑麻绳整段松脱、垂下来 | 重绕或更换，松垂的绳抓上去没有回弹 |
| 抓面上积了毛和碎屑 | 每周吸一次，脏的抓面使用率会下降 |
| 抓具被移到别的位置 | 移回原位。位置一变，前面积累的使用习惯作废 |

## 八、指甲修剪口径

| 项目 | 口径 |
|---|---|
| 修剪周期 | 14 到 21 天一次 |
| 每次修剪部位 | 只剪前端透明的弯钩部分，粉红色血线要留 2 毫米 |
| 室内猫是否需要 | 需要。室内打磨不足，指甲会自然长到扎进肉垫 |
| 一次剪几只 | 不必一次全剪，受不了就分两天，每次配合零食 |
| 新手是否会剪错 | 会。宁可少剪一点点，也不要贪多。剪到血线请按兽医建议处理 |
