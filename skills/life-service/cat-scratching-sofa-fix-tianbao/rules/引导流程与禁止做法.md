# 引导流程与禁止做法

## 一、四步转移流程

| 步骤 | 做什么 | 判据 |
|---|---|---|
| 第一步 气味引导 | 把虫瘿草或猫草轻擦在新抓面上，每天一次，持续一周 | 猫会主动凑上去闻、蹭脸 |
| 第二步 临时遮挡原抓点 | 用双面胶带、铝箔、加厚罩盖住被抓的那块，让它不好抓 | 猫到原抓点试探后放弃，转向别处徘徊 |
| 第三步 奖励正确位置 | 只要它在新抓具上抓，立刻给零食或轻声夸奖，**当场给**，不要等它抓完走开再给 | 一天内有两三次在新抓具上出现抓挠 |
| 第四步 渐进撤除保护 | 稳定使用两周后，逐块撤下遮挡物，撤到最后一块时观察一周 | 撤完遮挡后一周内没有出现回到原抓点的情况 |

**顺序不得颠倒**：先遮挡后引导是最常见的错误顺序。没有先做气味引导就遮挡，猫只会去找下一个没遮的地方——通常是隔壁那张沙发。

## 二、转移期的时间预期

| 阶段 | 预期 | 处理 |
|---|---|---|
| 第 1 到 2 周 | 开始在新抓具上尝试，但仍有少量抓原处 | 正常，不要撤保护 |
| 第 3 到 4 周 | 新抓具使用明显增多，原处偶发 | 保持现状，继续奖励 |
| 第 5 到 8 周 | 基本完成转移 | 可开始渐进撤除保护 |
| 满 4 周零改善 | 异常，需要复盘 | 检查数量、形态、位置、稳定性四项 |
| 满 8 周零转移 | 说明方案有一项根本没做对 | 重新走一遍工作流，不要只加一个抓板 |

## 三、禁止做法清单（出现即不合格）

| 禁止做法 | 为什么不行 | 替代做法 |
|---|---|---|
| 打、追打、拎后颈教训 | 猫不理解「为何被打」，只学到躲着人抓，频率不降 | 用第三步的当场奖励建立正确位置的联结 |
| 喷水、喷雾、摇罐吓 | 只在人在时才有效，且制造对人的恐惧；一出门照抓 | 临时遮挡加转移期保护，物理隔断比恐吓可靠 |
| 长期戴防抓套 | 影响爪的正常伸缩与旧爪鞘脱落，且抓挠动作照做家具照损 | 定期修剪加提供充足抓具；如确有使用必要请咨询兽医 |
| 除爪手术 | 属手术性处置，涉及疼痛、行走改变与行为恶化风险，且多地已限制，需向兽医充分咨询 | 引导加防护加定期修剪的组合方案 |
| 单纯把猫抱到抓具上捏爪做动作 | 猫不理解被动动作的意义，可能形成抗拒被抱 | 让它自主发现，用气味引导加当场奖励 |
| 一次性把家里所有抓具全换掉 | 习惯与气味标记全部清零，前功尽弃 | 一次只换一个，旧的先留着 |
| 惩罚后立刻给零食安抚 | 形成「被骂等于有零食」的混乱联结 | 取消惩罚，只保留正确行为的奖励 |

> **否定口径**：以惩罚为目的的任何装置，都不算替代方案。判定以是否在禁止清单内为准，不以是否被描述为「只是轻轻一下」而降低等级。

## 四、家具临时保护的可用做法

| 做法 | 适用 | 注意事项 |
|---|---|---|
| 双面胶带贴在被抓处 | 沙发扶手、桌腿 | 猫讨厌黏感，但长期使用会留胶痕，属于过渡期手段 |
| 铝箔包裹 | 立面 | 有响声也有效果，个别猫会去啃铝箔，应避免误食 |
| 加厚罩、专用防抓垫 | 大面积防护 | 罩子要固定牢，松垮的罩子本身会变成新玩具 |
| 把家具暂时转个方向 | 短期应急 | 转移期结束后需恢复正常摆放并维持抓具配置 |
| 喷柑橘类气味（不使用任何刺激化学品） | 辅助 | 效果个体差异大，且需避开猫直接接触口鼻的浓度；有疑虑请咨询兽医 |

> **转移期保护的前提**：保护只用于购买时间。没有同时提供足够数量和正确位置的抓具，单纯遮挡等于把猫逼去抓别的地方。

## 五、多猫家庭的分流要点

| 情形 | 处理 |
|---|---|
| 强势猫占住唯一一处抓具 | 按猫数加一配置，并把抓具分散到不同房间，避免只有一条通路 |
| 弱势猫不敢走到客厅去抓 | 在弱势猫的常驻房间单独配置一处，它不必经过强势猫的地盘 |
| 只有一只在抓，其他不参与 | 大多属于模仿学习，把抓具放在它抓的位置即可，不需要隔离任何猫 |
| 突然开始争抢抓具 | 可能是压力信号，需同步检查资源点数量是否足够，并留意是否出现其他冲突迹象 |

## 六、就医与转介判断清单（只做判断不下诊断）

出现下列任一情形，请带它去看兽医，**本技能不给出任何处置结论**：

- 抓挠行为突然出现或突然加剧，尤其集中在身体某一侧、某一只爪
- 抓的同时频繁舔同一处，出现局部脱毛、红肿、皮屑、结痂
- 同时伴发精神食欲下降、躲藏时间增加、攻击性上升、乱排泄
- 老龄猫突然大量抓挠并伴随叫唤、定向异常、明显睡眠结构改变

就诊前请整理这四条信息给兽医：

1. 行为改变从哪天开始，前后有没有搬家、新成员加入、装修、换砂换粮
2. 一天出现几次，每次持续多久，集中在哪些家具和哪个时间段
3. 拍到了没有——抓挠行为和皮肤状况的视频对判断很有帮助
4. 食欲、饮水、排便、体重有没有同步变化

## 七、结论分类口径

| 档位 | 判定条件 |
|---|---|
| 先处理 | 抓具总数不足猫数加一、缺必需形态、立式高度不足、转移距离超过 50 厘米、使用了禁止做法、修剪间隔超过 21 天 |
| 待确认 | 无上述缺陷，但必填字段缺失或取值无法识别 |
| 可照此执行 | 无上述两类问题 |

> 顺序不可颠倒：存在真实缺陷时，即使信息也不完整，仍判先处理。
