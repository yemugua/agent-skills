# 猫抓沙发（cat-scratching-sofa-fix）

猫抓沙发不是报复，也不是学坏，是**它在做两件必须做的事**：磨掉旧爪鞘、以及在最显眼的地方留下气味爪痕与视觉标记。买的抓板不吃这套组合需求，它就继续挑沙发。

这个技能做三件事：**配够 → 放对 → 转移**。

> 注意：常见说法「给猫换个抓板就好了」基本无效。**只加一样东西几乎必然失败**，必须数量、形态、材质、位置四项同时对。

---

## 一、硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出抓具数量、形态、材质与摆放口径 | ❌ 判断过度抓挠是否由皮肤病或疼痛引起 |
| 给出从旧抓点向新抓具转移的引导流程 | ❌ 建议使用惩罚、体罚、喷水、恐吓装置 |
| 给出家具保护与指甲修剪的可执行做法 | ❌ 建议防抓套长期佩戴或除爪手术 |
| 给出多猫场景下的分流配置思路 | ❌ 保证猫完全不碰任何家具 |
| 给出多久未见改善就该复盘的判据 | ❌ 提供任何药物或镇静类处置建议 |

**必须先去兽医处排查的情况**

- 抓挠行为突然出现或突然加剧，尤其集中在身体某一侧或某只爪
- 抓的同时伴有频繁舔同一处、局部脱毛、皮肤红肿或有皮屑
- 同时出现精神食欲下降、躲藏、攻击性上升
- 老龄猫突然开始大量抓挠且伴随叫唤、定向异常

## 二、什么时候用

| 用户说法 | 用不用 | 说明 |
|---|---|---|
| 「猫总抓沙发扶手」 | ✅ 用 | 按具体的被抓位置反推所需形态，扶手多为立面加易抓面 |
| 「买的抓板它不用」 | ✅ 用 | 九成是位置不对或形态不对，不是猫的毛病 |
| 「猫开始抓地毯了」 | ✅ 用 | 地毯属平面抓，要配平放抓板，不是配抓柱 |
| 「猫抓窗帘」 | ✅ 用 | 高立面，需要够高的抓柱放在窗帘旁 |
| 「猫一直舔爪子还抓得厉害」 | ⚠️ 部分 | 只给就医判断清单，不下诊断结论 |
| 「能不能给它做除爪手术」 | ❌ 不建议 | 见禁止做法，需先了解后果，务必咨询兽医 |

## 三、完整工作流

1. **数猫**：抓具总数按「猫数加一」配置，至少两处。**这一条多数家庭都不达标。**
2. **记录被抓点**：连续观察三到五天，把被抓的确切位置、高度、次数记下来。**不要凭印象写「它爱抓沙发」，要写「抓沙发左扶手外侧，站立高度约四十五厘米」。**
3. **判断形态**：立面（站起抓，常见沙发扶手、窗帘、桌腿）与平面（伏身抓，常见地毯、床沿）要分别配。
4. **选材质**：目前它能接触的家具材质反推它偏爱什么——爱抓地毯就先用带织纹的，爱抓粗布就试剑麻。
5. **定位置**：新抓具必须落在被抓点的三十到五十厘米范围内，超出这个距离转移基本失败。
6. **固定与稳定**：抓柱四点着地、不摇晃；一晃就倒过一次的抓柱，猫会永久放弃。
7. **做保护**：在转移期把原抓点用贴纸、铝箔、加厚罩暂时盖住，同时把猫草、虫瘿草擦在新抓具上做气味引导。
8. **修指甲**：按十四到二十一天一次的小量修剪，别等指甲劈了再管。
9. **复盘**：四周未见减少、八周未见明显转移，回头检查数量、形态、位置、稳定性四项。

## 四、核心规则说明

**动手买东西之前，必须先读这两个文件，不要凭印象写：**

- `rules/抓具选型与摆放口径.md` —— 数量、高度、尺寸、四种材质的匹配表，摆放位置与稳定性要求
- `rules/引导流程与禁止做法.md` —— 四步转移流程、地形期保护做法、指甲修剪口径、禁止做法清单与复盘判据

要点三条：

1. **数量不够是第一位原因**。一处不够，两处才勉强，猫数加一是底线。
2. **位置比抓具本身重要**。放在阳台角落的顶级抓柱，效果远不如放在沙发扶手旁的普通剑麻板。
3. **稳定是隐形的生死线**。猫站立抓伸时重心前移，抓柱一晃就再也不用第二次。

## 五、脚本用法

```
python scripts/scratching_fix.py --selftest
python scripts/scratching_fix.py --file plan.json
```

输入字段：

| 字段 | 说明 | 示例 |
|---|---|---|
| cat_count | 猫的数量 | 2 |
| total_posts | 已有抓具总数 | 3 |
| vertical_exists | 是否有立式抓具 | true |
| vertical_height_cm | 立式抓具高度厘米 | 70 |
| flat_exists | 是否有平放抓具 | false |
| damage_targets | 被抓家具列表 | 「沙发扶手」「地毯」 |
| distance_cm | 新抓具到被抓点的距离厘米 | 40 |
| material | 新抓具材质 | 「剑麻」「瓦楞纸」 |
| stable | 抓具是否稳固 | true |
| nail_trim_days | 指甲修剪间隔天 | 14 |
| methods | 采用的纠正手段列表 | 「气味引导」「贴纸保护」 |
| move_target | 转移目标 | 「立式抓柱」 |

结论分三档：**先处理**（数量不足、缺形态、距离过远、用了禁止手段）、**待确认**（信息不足）、**可照此执行**。存在真实缺陷时即使信息也不完整仍判先处理。

结果写入 `scripts/_last_result.txt`，每条不合格带原因。

## 六、人工确认清单（这步不能省）

- [ ] 抓具总数不少于猫数加一
- [ ] 立式与平放两种形态都配齐（按被抓对象判断）
- [ ] 立式高度足够，猫站起能完整拉伸
- [ ] 新抓具就在被抓点三十到五十厘米内
- [ ] 材质与猫当前偏好的家具质感一致或接近
- [ ] 抓具站得稳，推一下不会晃
- [ ] 修剪间隔在十四到二十一天之间
- [ ] 纠正手段里没有任何禁止项
- [ ] 转移期已用贴纸或罩子盖住原抓点

## 七、最常见的坑

1. **只买一个还很便宜**。数量不够时，猫的任何选择权都没有，它不抓沙发抓什么。
2. **放在猫不去的房间**。抓具要放在猫的生活动线上，尤其常驻的沙发边和睡醒的地方，不是放在杂物间。
3. **买来就有空却不教**。新抓具要先做气味引导，把猫草或虫瘿草擦在抓面上，它才知道这是用来抓的。
4. **抓柱一晃**。摇一下就倒或者会滑动的抓柱，猫第二次就不碰了，这个损失不可逆。
5. **偏偏用水喷**。喷水教不会它去抓别处，只教出「主人在时不抓」，你一出门它照抓，还多了怕你的副作用。
6. **看到抓就大喊追打**。这属于体罚，只能让猫学会躲着你抓，抓的频率一般不降。
7. **戴防抓套长期不取**。长期佩戴会影响爪的正常伸缩与旧爪鞘脱落，而且猫依然会做挠这个动作，家具照样损伤。这类做法需先咨询兽医。
8. **等四周就说没用**。转移期通常需要四到八周，过早放弃等于把刚起的作用白费掉。
