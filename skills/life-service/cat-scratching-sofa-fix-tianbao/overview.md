# 猫抓沙发

你会得到一份**照着买、照着放、照着转移就能执行的家具引导方案**，而不是「买个猫抓板试试」。

## 你会得到什么

1. **数量口径**：抓具总数按「猫数加一」配，至少两处。多数家庭只买了一处，这是失败率第一位的原因，猫没有任何别的选项。
2. **形态配置**：区分立面和平面。猫站起来抓沙发扶手、窗帘，需要够高的立式抓柱；趴着抓地毯、床沿，需要平放抓板。两种形态配错，等于没配。
3. **材质匹配**：剑麻、瓦楞纸、地毯面、麻绳四种抓面的手感差異与适用偏好。挑哪种，取决于它**现在**在抓的家具是什么质感，不是取决于哪个好看。
4. **位置口径**：新抓具必须落在被抓点的三十到五十厘米范围内，且要在猫的生活动线上。放在阳台角落的顶级抓柱，效果远不如贴着沙发扶手边放一块普通剑麻板。
5. **稳定性要求**：推一下不晃。猫站在上面拉伸时重心前移，晃一次的抓柱基本就被永久放弃了。
6. **四步转移流程**：气味引导 → 临时遮挡原抓点 → 奖励在正确位置抓 → 渐进撤除保护。每一步都有可执行的做法和判据。
7. **禁止做法清单**：体罚、追打、喷水、恐吓装置、长期佩戴防抓套、除爪手术，逐条写清为什么不行。
8. **复盘判据**：四周未见减少、八周未见明显转移，就回头检查数量、形态、位置、稳定性四项，而不是再加一个抓板。

## 典型用法

- 「猫总抓沙发扶手」：扶手是立面加偏粗质感，要配立式、带一定粗糙度、贴着扶手放的抓具。
- 「买的抓板它不用」：九成是位置不对或形态不对。把它挪到被抓点旁边，再做一次气味引导。
- 「猫开始抓地毯了」：这是平面抓，加立式抓柱完全无效，要配平放抓板并直接放在被抓处。
- 「几只猫要几个抓板」：按猫数加一，并且要分散在不同房间，不能全堆在一处。

## 边界

不判断是否由皮肤病、过敏、疼痛或焦虑引起。抓挠突然加剧、集中在某一侧、伴随舔同一处至脱毛或精神食欲下降，先去兽医处排查，本技能只给就医判断清单。不建议任何药物或手术性处置，涉及除爪手术请先向兽医充分了解。
