# 地下空间与人防工程消防（underground-space-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《建筑设计防火规范》GB 50016 与人防工程防火要求，生成地下空间消防清单：防火分区与防烟分区、疏散距离与安全出口、机械排烟与补风、消防救援口与标识、应急照明与广播。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 地下空间消防
- 地下室消防
- 人防工程消防
- 地下车库消防
- 地下商业消防

## 三、工作流
1. 核查防火分区与防烟分区
2. 核对疏散距离与安全出口
3. 检查机械排烟与补风
4. 确认消防救援口与标识
5. 核实应急照明与广播

## 四、核心内容（检查清单与判定）
地下空间疏散与排烟困难，GB 50016 对其防火分区、疏散距离与机械排烟有严格要求；应确保安全出口数量与排烟补风可靠。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含防火分区与防烟分区 | 分区 |
| Q2 | FAIL | 未含疏散距离与安全出口 | 疏散 |
| Q3 | WARN | 未含机械排烟与补风 | 排烟 |
| Q4 | FAIL | 未含消防救援口与标识 | 救援口 |
| Q5 | WARN | 未含应急照明与广播 | 照明 |

> 脚本 `underground-space-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python underground-space-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python underground-space-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
