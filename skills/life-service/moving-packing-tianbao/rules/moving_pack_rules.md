# 搬家打包规则表

生成搬家方案前先读本文件，不要凭印象写。

---

## 一、分类打包法

**核心原则：按类别打包，不按房间打包。** 找东西的效率差别很大。

| 类别 | 推荐箱型 | 打包要点 | 注意 |
|---|---|---|---|
| 书籍 | 小号箱，每箱不超过 10 至 15 公斤 | 填满空隙防止变形 | 大部头书单独放，重的不压轻的 |
| 被褥床品 | 编织袋或大号箱 | 直接装，不压缩 | 见真空压缩一节 |
| 衣物 | 中号箱，按人分箱 | 卷叠装，填满空隙 | 每人单独一箱并贴标签 |
| 厨房餐具 | 中号箱，箱外贴易碎标签 | 每件独立包裹，之间加填充 | 碗口相扣更省空间且不易碎 |
| 玻璃器皿 | 小号箱单独 | 报纸或气泡膜包裹，中间加填充 | 装箱后箱体不晃动 |
| 电器 | 原包装优先 | 用原泡棉与防震材料 | 无原包装必须单独包裹 |
| 清洁与卫浴 | 单独箱，不与其他物品混装 | 液体密封双层袋装 | 见第四节 |
| 药品 | 随身 | 原包装 | 处方药与说明书一并带上 |
| 证件合同 | 随身，不装箱 | 文件袋按类别分装 | 见第四节 |
| 贵重物品 | 随身 | 相机、电脑、珠宝单独 | 见第四节 |
| 杂物零碎 | 大号收纳箱 | 用袋子分装并写内容 | 不要散装 |

## 二、装箱顺序

**原则：不常用物品先装箱，最后装箱的先取。**

| 阶段 | 装什么 |
|---|---|
| 第一批 | 不常用物品（换季衣物、旧书、纪念品） |
| 第二批 | 不常用但不重的（装饰品、备用餐具） |
| 第三批 | 常用但不急的（大部分衣物、书籍） |
| 第四批 | 常用且急用的（厨房基本用品、卫浴用品、毛巾），装小箱并标先开 |
| 不进箱 | 证件、贵重、药品、液体、易碎高价、工具，全部随身 |

**新家开箱顺序**：先卫生间与厨房，再卧室，最后其他。

## 三、真空压缩袋适用与禁忌

| 物品 | 能否长期真空压缩 | 原因 |
|---|---|---|
| 羽绒被 | 不建议长期 | 长期压缩破坏绒簇结构，回弹变差 |
| 厚被褥、棉被 | 可以 | 棉纤维受压变形影响较小 |
| 羽绒服 | 不建议长期 | 与羽绒被同理，影响蓬松度 |
| 羊毛被、羊毛衫 | 不建议 | 羊毛纤维受压易产生折痕，恢复困难 |
| 蚕丝被 | 不建议 | 长期压缩可能造成结构变形 |
| 枕头 | 可短期 | 到家后立即取出摊开 |
| 床品、被套 | 可以 | 纯棉织物短期压缩无碍 |
| 毛毯 | 可以 | 无填充结构，短期压缩无碍 |

**使用注意：**

- 短期运输压缩与长期存储是两回事，超过一两个月的压缩不要用于羽绒与羊毛
- 到家后立即取出并彻底摊开，让填充物回弹
- 不要抽到完全真空，留一点余量更稳妥
- 压缩袋要防漏，破损后物品会缓慢回弹变潮

## 四、必须单独处理的物品

### 液体与清洁用品

| 物品 | 处理方式 |
|---|---|
| 液体清洁剂 | 拧紧瓶盖，密封袋双层装，直立放置不倒置 |
| 喷雾类 | 确认阀门锁紧，装入密封袋防渗漏 |
| 洗手液、洗发水 | 同上，瓶口用保鲜膜再缠一圈 |
| 毛巾、浴巾 | 洗净彻底晾干后单独装，潮湿会发霉 |
| 牙刷、牙膏 | 洗净晾干，牙膏直立放置 |
| 卷纸、抽纸 | 压实后装袋避免散落 |
| 拖把、水桶 | 晾干后装袋 |

**原因**：液体泄漏会污染同箱物品；潮湿织物到新家会发霉；厨房液体与卧室衣物同箱，漏一箱全废。

### 证件、贵重、药品（全部随身）

| 物品 | 专门做法 |
|---|---|
| 瓷器、餐具 | 每件独立包裹，碗口相扣，装箱后晃动无物感 |
| 玻璃制品 | 报纸或气泡膜双层包裹，单独装箱，箱外贴标签 |
| 水晶 | 软布包裹后放入硬盒，盒内填充固定 |
| 相机 | 用原包装或气泡膜包裹，放随身包 |
| 笔记本电脑 | 原包装包裹，随身携带不托运 |
| 珠宝与现金 | 全程随身不离身 |
| 相框与镜面 | 玻璃面贴交叉胶带固定，背面加硬板 |
| 绿植 | 单独装箱，箱体留通气孔避免挤压 |

## 五、丢件高发环节与应对

| 环节 | 为什么会丢 | 应对 |
|---|---|---|
| 装箱时未贴标签 | 到新家不知箱内是什么，容易弃置 | 每箱外部两面贴标签，写类别与箱号 |
| 拆箱后未登记 | 拆开没收起来，最后找不到 | 拆箱当场登记已开箱与箱内物品 |
| 证件与贵重混装 | 途中丢失或被水浸 | 全程随身 |
| 液体未密封 | 泄漏后整箱被弃 | 双层密封，直立放置 |
| 大小箱混装超重 | 底部箱子搬不动被落在原地 | 大件重物单独小箱 |
| 相同标签多箱 | 记不清哪箱是哪箱 | 编号箱号 |
| 搬运途中散落 | 编织袋破损、纸箱底受潮破裂 | 编织袋底部加一层，纸箱底加胶带 |
| 到新家边拆边找 | 拆一半就乱 | 按开箱顺序，先归位再拆下一箱 |

## 六、清单 A：搬家前准备

- [ ] 物业报备（搬运时间、电梯使用、货车停靠）
- [ ] 断电、断水、断燃气
- [ ] 清理冰箱与洗衣机（断电静置，处理残留水）
- [ ] 空调与家用电器按说明书关机及移机安排
- [ ] 门窗、抽屉、柜门固定到位
- [ ] 易碎与贵重物品已单独处理
- [ ] 证件、合同、药品、现金已随身
- [ ] 每个纸箱外部两面贴好标签并编号
- [ ] 当天必用物品已单独装先开箱

## 七、清单 B：地址与业务迁移

- [ ] 水电燃气开户或过户
- [ ] 宽带与网络迁移申请
- [ ] 固定电话迁移（如使用）
- [ ] 快递与邮件地址变更
- [ ] 各类会员与订阅地址更新
- [ ] 银行与保险联系地址更新
- [ ] 车辆年检与驾驶证地址（如适用）
- [ ] 宠物安置（携带证明、疫苗记录、托运或寄养）
- [ ] 学校与接送点变更（如适用）
- [ ] 医院与社区服务中心登记变更

具体办理要求与时限以当地相关单位与服务商的规定为准。

## 九、纸箱数量估算参考

| 房间类型 | 参考箱量 | 影响因素 |
|---|---|---|
| 客厅 | 3 至 6 箱 | 有无电视、音响、装饰品 |
| 卧室 | 3 至 6 箱 | 衣物与书籍量 |
| 厨房 | 2 至 4 箱 | 餐具数量与锅具 |
| 卫生间 | 1 至 2 箱 | 洗漱与清洁用品 |
| 阳台 | 1 至 3 箱 | 是否含大件与杂物 |
| 书房 | 4 至 10 箱 | 书籍是主要变量，书籍越重越需要小箱 |

**估算只作参考**。书籍超过 10 箱时应改用更小的箱子分装，而不是加大单个箱子的装载量。

## 十、宠物安置

| 方式 | 注意事项 |
|---|---|
| 自行随车携带 | 专用航空箱或携带笼，提前准备饮水与熟悉气味的物品 |
| 寄养 | 提前预约并确认环境与照护安排 |
| 托运 | 使用有资质的托运服务，随身携带证明文件 |

**共同要求**：出发前按医嘱控制饮食与饮水，准备好笼具、饮水、证明文件与应急联系方式。

## 十一、必须转专业搬家的情形

1. 大型家具（钢琴、保险柜、大理石台面）需拆装或搬运
2. 易碎高价物品（瓷器、水晶、玻璃制品）需特殊包装与运输
3. 需要恒温的物品（部分药品与电子设备）
4. 必须全程随身的重要文件与证件数量较多
5. 跨省长途运输
6. 楼层较高且无电梯，需人工搬运上楼下

---

## 十二、常见误判清单

1. 按房间打包——厨房物品分散多个箱子
2. 羽毛服装进真空袋存三个月——后期蓬松度不可恢复
3. 液体清洁剂与衣物同箱——漏一次整箱废
4. 证件随手放进箱子——途中易丢
5. 纸箱不贴标签——到新家当垃圾处理
6. 一箱塞太满太重——箱子被落在原地
7. 只装箱子不列清单——当天无法照着核对
8. 断电断水断气没提前办——当天办不了
9. 新家当天不先解决厨房卫生间——晚上连饭都做不了
10. 搬家当终点——地址未变更，两周后开始收错寄包裹与旧账单
