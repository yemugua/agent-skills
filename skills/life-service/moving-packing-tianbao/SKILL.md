# 搬家打包与物品清单核查（moving-packing）

搬家最怕两件事：**该带的东西没带**，和**打包方式不对导致东西到不了就坏**。前者靠清单，后者靠方法。这两件事都可以提前解决。

这个技能做四件事：**按类别分箱** → **按顺序装箱取箱** → **用清单核查** → **防丢件**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出分类打包方法与装箱顺序 | ❌ 代替搬运、抬运、车辆调度 |
| 生成可打印的物品与迁移核查清单 | ❌ 代替物业办理报备与各项迁移手续 |
| 判断哪些物品不能真空压缩 | ❌ 判断物品在运输途中的实际损坏责任 |
| 提示证件、贵重、易碎的专门处理 | ❌ 代办宽带、快递、燃气等业务变更 |
| 列出丢件高发环节与应对 | ❌ 承诺运输方责任认定结果 |

**遇到以下情况，建议改用专业搬家公司或单独处理：**

- 有大型家具（钢琴、保险柜、大理石台面）需拆装或搬运
- 有易碎高价物品（瓷器、水晶、玻璃制品）需要特殊包装与运输
- 有需要恒温的物品（部分药品、部分电子设备）
- 有必须全程随身的重要文件与证件
- 涉及跨省长途运输
- 楼层较高、无电梯，需人工搬运上楼下

## 二、完整工作流

```
第1 步  读规则文件 rules/moving_pack_rules.md（打包方法表 + 清单 + 高发环节）
第 2 步  按类别与使用频率分箱，不要一个房间一箱了事
第 3 步  按装箱顺序封箱：不常用先装，最后装箱的先取
第 4 步  生成物品清单与迁移核查清单
    python scripts/moving_checklist.py --rooms "客厅2,卧室2,厨房1,卫生间1" --out 搬家清单.md
第 5 步  证件、贵重、清洁与卫浴用品单独处理，不进大箱
第 6 步  搬家当天按当天清单逐项打勾
第 7 步  到新家先按优先级开箱：先厨房与卫生间，再卧室，最后其他
```

## 三、第 2 步：分类打包法

**核心原则：按类别打包，不按房间打包。**

按房间打包的问题是"厨房的东西分散在三四个箱子里"，找到一个箱子不知道里面还有没有相关物品；按类别打包则是"所有厨房用品在 A 组箱子里"，找东西效率高得多。

| 类别 | 推荐箱型 | 打包要点 | 注意 |
|---|---|---|---|
| 书籍 | 小号箱，**每箱不超过 10-15 公斤** | 立放或平放均可，但要填满空隙防止变形 | 大部头书单独放，重的不压轻的 |
| 被褥床品 | 编织袋或大号箱 | 直接装，不压缩 | 见第五节 |
| 衣物 | 中号箱，按人分箱 | 卷叠装，填满空隙 | 每个人的衣物单独一箱，贴标签 |
| 厨房餐具 | 中号箱，**在外部贴"易碎"标签** | 每件独立包裹，碗碟之间加填充 | 碗口与碗口相扣更省空间且不易碎 |
| 玻璃器皿 | 小号箱，单独 | 报纸或气泡膜包裹，中间加填充 | 装箱后箱体不晃动 |
| 电器 | 原包装优先 | 用原泡棉与防震材料 | 无原包装的必须单独包裹 |
| 清洁与卫浴用品 | **单独箱，不与其他物品混装** | 液体密封双层袋装 | 详见第六节 |
| 药品 | 随身，不托运 | 原包装 | 处方药与说明书一并带上 |
| 证件合同 | **随身，不装箱** | 文件袋按类别分装 | 见第四节 |
| 贵重物品 | **随身** | 相机、电脑、珠宝单独 | 见第四节 |
| 书籍类重物 | 小箱分装 | 每箱限重 | 超过限重会拖慢搬运且易损箱 |
| 杂物零碎 | 大号收纳箱 | 用袋子分装并写内容 | 不要散装 |

## 四、第 3 步：装箱顺序（这条决定到了新家顺不顺）

**原则：不常用物品先装箱，最后装箱的先取。**

| 阶段 | 装什么 | 说明 |
|---|---|---|
| 第一批装 | 不常用物品（换季衣物、旧书、纪念品） | 搬家过程中基本不动 |
| 第二批装 | 不常用但不重的（装饰品、备用餐具） | 装在大箱里 |
| 第三批装 | 常用但不急的（大部分衣物、书籍） | 装在中间 |
| 第四批装 | 常用且急用的（厨房基本用品、卫浴用品、毛巾） | 装在小箱并标"先开" |
| **不进箱** | 证件、贵重、药品、液体、易碎高价、工具 | 全部随身 |

**到新家的开箱顺序：新家先解决卫生间与厨房 → 再卧室 → 最后其他。** 这条能让你在搬完当天不至于连毛巾都找不到。

## 五、真空压缩袋：适用与禁忌

这一条最容易出事，因为很多人以为"能压缩就更省空间"。

| 物品 | 能否长期真空压缩 | 原因 |
|---|---|---|
| 羽绒被 | ⚠️ **不建议长期** | 长期压缩会破坏羽绒的绒簇结构，回弹变差，短期看不出问题 |
| 厚被褥、棉被 | ✅ 可以 | 棉纤维受压变形影响较小，短期压缩无碍 |
| 羽绒服 | ⚠️ **不建议长期** | 与羽绒被同理，长期压缩影响蓬松度 |
| 羊毛被、羊毛衫 | ❌ **不建议** | 羊毛纤维受压易产生折痕，恢复困难 |
| 蚕丝被 | ❌ **不建议** | 长期压缩可能造成结构变形 |
| 枕头 | ⚠️ 可短期 | 短期运输压缩无碍，到家后立即取出摊开 |
| 床品、被套 | ✅ 可以 | 纯棉织物短期压缩无碍 |
| 毛毯 | ✅ 可以 | 无填充结构，短期压缩无碍 |

**使用注意：**

- 短期运输压缩与长期存储是两回事，**超过一两个月的压缩不要用于羽绒与羊毛**
- 到家后**立即取出并彻底摊开**，让填充物回弹
- 不要抽到完全真空，留一点余量更稳妥
- 压缩袋本身要防漏，破损后物品会缓慢回弹变潮

## 六、清洁与卫浴用品：必须单独处理

| 物品 | 处理方式 |
|---|---|
| 液体清洁剂 | 拧紧瓶盖，密封袋双层装，直立放置不倒置 |
| 喷雾类 | 确认阀门锁紧，装入密封袋防止渗漏 |
| 洗手液、洗发水 | 同上，瓶口用保鲜膜再缠一圈 |
| 毛巾、浴巾 | 洗净彻底晾干后单独装，潮湿会发霉 |
| 牙刷、牙膏 | 洗净晾干，牙膏直立放置 |
| 卷纸、抽纸 | 压实后装袋，避免散落 |
| 拖把、水桶 | 晾干后装袋 |

**为什么要单独处理**：液体泄漏会污染同箱的其他物品；潮湿的织物到新家会发霉；而厨房的液体与卧室的衣物同箱，漏一箱全废。

## 七、易碎与贵重物品的专门处理

| 物品 | 专门做法 |
|---|---|
| 瓷器、餐具 | 每件独立包裹，碗口相扣；装箱后晃动无物感 |
| 玻璃制品 | 报纸或气泡膜双层包裹；单独装箱；箱外贴标签 |
| 水晶 | 软布包裹后放入硬盒，盒内填充固定 |
| 相机 | 用原包装或气泡膜包裹，放在随身包而非箱内 |
| 笔记本电脑 | 原包装包裹，随身携带，不托运 |
| 珠宝与现金 | 全程随身，不离身 |
| 相框与镜面 | 玻璃面贴交叉胶带固定，背面加硬板 |
| 绿植 | 单独装箱，箱体留通气孔，避免挤压 |

**通用原则**：易碎品"包裹三层 + 填充到不晃动 + 箱外贴标签"，标签正面写"易碎"，侧面也写一份。

## 八、丢件高发环节与应对

| 环节 | 为什么会丢 | 应对 |
|---|---|---|
| 装箱时未贴标签 | 到新家不知道箱子里是什么，容易弃置 | 每箱外部两面都贴标签，写明类别与箱号 |
| 拆箱后未及时登记 | 拆开就没收起来，最后找不到 | 拆箱当场登记已开箱与箱内物品 |
| 证件与贵重混装 | 途中丢失或被水浸 | 全程随身，不装箱 |
| 液体未密封 | 泄漏后整箱物品被弃 | 双层密封袋，直立放置 |
| 大小箱混装超重 | 底部箱子搬不动，被落在原地 | 大件重物单独小箱，不超重 |
| 相同标签多箱 | 记不清哪箱是哪箱 | 编号箱号，如 A01 到 A20 |
| 搬运途中散落 | 编织袋破损、纸箱底部受潮破裂 | 编织袋底部加一层，纸箱底加胶带 |
| 到新家直接开箱找东西 | 边拆边找，拆一半就乱 | 按开箱顺序，先归位再拆下一箱 |

## 九、可打印核查清单（分两份）

### 清单 A：搬家前准备

- [ ] 物业报备（搬运时间、电梯使用、货车停靠）
- [ ] 断电、断水、断燃气（按物业与燃气公司要求办理）

- [ ] 空调、家用电器按说明书关机与移机安排
- [ ] 门窗、抽屉、柜门固定到位

- [ ] 证件、合同、药品、现金已随身
- [ ] 每个纸箱外部两面贴好标签并编号
- [ ] 当天必用物品已单独装"先开"箱

### 清单 B：地址与业务迁移

- [ ] 水电燃气开户或过户
- [ ] 宽带与网络迁移申请
- [ ] 固定电话迁移（如使用）
- [ ] 快递与邮件地址变更
- [ ] 各类会员与订阅地址更新
- [ ] 银行与保险联系地址更新
- [ ] 车辆年检与驾驶证地址（如适用）
- [ ] 宠物安置（携带证明、疫苗记录、托运或寄养）
- [ ] 学校与接送点变更（如适用）

> 具体办理要求与时限以当地相关单位与服务商的规定为准，建议提前咨询。

### 清单 C：丢件高发的四件随身物

- [ ] 身份证与相关证件
- [ ] 房屋相关文件与合同
- [ ] 处方药与病历
- [ ] 现金与贵重物品

## 十一、脚本用法

```bash
python scripts/moving_checklist.py --rooms "客厅2,卧室2,厨房1,卫生间1,阳台1"
python scripts/moving_checklist.py --file 房间清单.json --out 搬家清单.md
python scripts/moving_checklist.py --format json --rooms "客厅2"
```

| 参数 | 说明 |
|---|---|
| `--rooms` | 逗号分隔的「房间名+数量」，如 `客厅2,卧室2` |
| `--file` | 从文件读，支持 `.txt` / `.json`（JSON 用 `{"rooms": ["客厅2", ...]}` 或 `{"rooms": "..."}`） |
| `--out` | 清单输出路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本按输入的箱数与房间生成：纸箱分配建议、装箱顺序、当天必用清单、清单 A/B 的完整条目，以及丢件高发提醒。还会校验箱数是否够用、是否缺项。

> 脚本按房间数估算箱量，仅作规划参考。实际箱量取决于物品多少与规格。

## 十三、最常见的坑

**坑一：按房间打包。**
"厨房的东西分散在四个箱子里"是找东西最难受的根源。按类别分箱，找东西效率差很多。

**坑二：把羽毛服装进真空袋存三个月。**
短期运输压缩没问题，长期压缩会影响蓬松度，而且这个问题要过几个月才显现，到时已经没法补救。

**坑三：把液体清洁剂和衣物放同一箱。**
漏一次整箱都废。双层密封、直立放置是基本要求。

**坑四：证件随手放进箱子。**
路上丢失、淋水、被搬运时压在最底下。证件合同必须随身。

**坑五：纸箱不贴标签。**
到新家拆开不知道是什么，一部分会被当垃圾处理。箱号 + 类别，两面都贴。

**坑六：一箱塞太满太重。**
超过搬运舒适重量后，箱子会被留在原地，或者搬起来伤腰。大件重物单独小箱。

**坑七：只装箱子不列清单。**
清单的价值在于搬家当天照着打勾，而不是事后回忆。清单 A 和清单 B 分开做。

**坑八：断电断水断气没提前办。**
当天才想起来，物业不受理，整个流程乱掉。提前按物业与燃气公司要求办理。

**坑九：新家当天不先解决厨房和卫生间。**
搬完连毛巾和餐具都找不到，晚上连饭都做不了。开箱顺序要提前定好。

**坑十：把搬家当终点。**
地址、宽带、快递、会员、车辆的变更不做，两周后开始收到寄错地方的包裹、旧地址的水电账单和骚扰电话。

## 十四、边界与免责

- 本技能**不替代**搬运、运输、家具拆装与专业搬家公司服务
- 物品在运输途中的损坏责任划分，按**运输合同约定与相关主管部门要求**办理
