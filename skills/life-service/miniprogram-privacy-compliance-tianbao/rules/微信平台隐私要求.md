# 微信小程序平台隐私要求（核查口径）

## 一、用户隐私保护指引（硬性要求）

- 小程序管理后台：**设置 → 基本设置 → 服务内容声明 → 用户隐私保护指引**。
- 指引中应填写：收集的信息类型、用途、第三方共享情况（含 SDK 列表）。
- 未配置将导致隐私接口调用被拦截，影响登录/支付等核心链路，严重的将被下架处理。

## 二、隐私授权机制（2023 起）

- 调用隐私接口（如 `getPhoneNumber`、`getLocation`、`chooseImage`、`chooseMedia`、`onAccelerometerChange` 等）前，必须通过隐私授权弹窗取得用户同意。
- 相关能力：`wx.getPrivacySetting`（查询隐私授权状态）、`requirePrivacyAuthorize`（订阅隐私授权事件）。
- 顺序纪律：**先弹窗同意 → 后调用接口**；未经同意调用将被平台拦截。
- 用户拒绝后：不得强制退出小程序，基础功能应保持可用（信息为业务必需的除外，且应说明原因）。

## 三、第三方 SDK / 插件申报

- 管理后台：**设置 → 第三方设置 → 插件管理 / SDK 管理**。
- 接入了统计、推送、地图、支付、登录等第三方 SDK，必须申报，并维护**信息共享清单**（含第三方名称、用途、隐私协议链接）。
- 未申报的 SDK 调用隐私接口会被拦截，属平台违规行为。

## 四、账号注销

- 平台运营规范要求小程序提供**账号注销**入口。
- 注销流程应：验证身份 → 提示注销后果（数据清除不可恢复）→ 冷静期（如 7 天可撤销）→ 完成注销并清除/匿名化数据。

## 五、常见被拦截/被通报场景

| 场景 | 后果 | 处理 |
|------|------|------|
| 未配置隐私指引 | 隐私接口调用失败 | 后台配置后发布生效 |
| 未弹窗直接调隐私接口 | 接口报错、接口被禁用 | 接入授权弹窗 |
| SDK 未申报 | 接口被拦截 | 后台申报并更新共享清单 |
| 一揽子授权敏感信息 | 通报/下架 | 改为单独同意弹窗 |
| 无注销入口 | 审核驳回/处罚 | 增加注销功能 |
| 过度收集 | 监管通报 | 按最小必要删减字段 |

## 六、审核与自查建议

- 每次涉及信息收集、SDK 变更的新版本，发布前过一次本核查。
- 保留自查与整改记录，应对平台复查与监管抽查。
- 平台规则会更新，以小程序官方《隐私开发指南》最新版本为准。
