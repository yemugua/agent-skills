# 碳管理与双碳（carbon-management）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据碳排放核算与双碳工作要求，生成清单：排放边界与源识别（范围一二三）、核算方法与活动数据、减排措施与项目、数据质量与核查、披露报告与持续改进。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 碳管理
- 碳排放核算
- 双碳
- 碳达峰
- 碳核查

## 三、工作流
1. 界定排放边界与识别排放源
2. 确定核算方法与活动数据
3. 策划减排措施与项目
4. 保障数据质量并接受核查
5. 编制披露报告并持续改进

## 四、核心内容（检查清单与判定）
碳管理先界定边界（范围一直接、范围二能源间接、范围三价值链），以活动数据核算，减排项目与核查披露构成闭环。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含排放边界与源识别 | 边界 |
| Q2 | FAIL | 未含核算方法与活动数据 | 核算 |
| Q3 | WARN | 未含减排措施与项目 | 减排 |
| Q4 | FAIL | 未含数据质量与核查 | 核查 |
| Q5 | WARN | 未含披露报告与改进 | 披露 |

> 脚本 `carbon-management_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python carbon-management_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python carbon-management_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
