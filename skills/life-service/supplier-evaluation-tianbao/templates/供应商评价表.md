# 供应商评价表

> 供应商评价实行**准入评价 + 绩效评价**双轨。准入看"能不能用"，绩效看"好不好用"；分级结果直接挂钩份额与淘汰。

## 一、准入评价（新供方/新物料）

| # | 评价项 | 权重 | 评分要点 | 得分 |
|---|---|---|---|---|
| 1 | 资质与合法性 | 15% | 营业执照、生产许可、行业强制认证是否有效 | |
| 2 | 体系认证 | 15% | ISO 9001/行业体系证书及覆盖范围 | |
| 3 | 样品确认 | 20% | 样品检验/试用结论，合格率 | |
| 4 | 过程能力 | 15% | 设备、关键工序控制、检测能力 | |
| 5 | 交付能力 | 10% | 产能、地理位置、物流方式 | |
| 6 | 财务与风险 | 10% | 经营年限、涉诉、同业口碑 | |
| 7 | 价格与商务 | 15% | 报价水平、付款条件、服务承诺 | |
| | **准入总分** | 100% | ≥70 分列入候选，≥85 优先 | |

## 二、绩效评价（年度/季度）

| 维度 | 权重 | 指标定义 | 数据来源 | 得分 |
|---|---|---|---|---|
| 质量 | 40% | 来料批次合格率、PPM、客户投诉归因 | IQC 记录/客诉台账 | |
| 交付 | 25% | 准时交付率、订单满足率 | ERP 收货记录 | |
| 服务 | 15% | 异常响应时效、整改配合度、8D 质量 | 采购/SQE 记录 | |
| 价格 | 10% | 价格竞争力、降价配合度 | 商务记录 | |
| 体系维持 | 10% | 二方审核结果、证书有效性 | 审核报告 | |
| | **绩效总分** | 100% | | |

## 三、分级判定

| 等级 | 判定标准 | 管理动作 |
|---|---|---|
| A（战略） | 绩效≥85 且准入≥85 | 优先份额、签框架协议、高层互访 |
| B（合格） | 70≤绩效<85 | 维持份额、季度回顾 |
| C（观察） | 60≤绩效<70 | 限期改进、冻结新份额、现场辅导 |
| D（淘汰） | 绩效<60 或重大违规 | 启动淘汰与替代 |

## 四、再评价与淘汰

- 再评价周期：A 级 __ 年；B/C 级 __ 季度
- 淘汰触发：□连续 __ 次 C 级 □重大质量事故 □资质失效 □停业风险
- 淘汰执行：停止新订单 → 在途/库存处置 → 替代供方切换 → 名录注销（审批人：）

**归档**：评价表、等级变更记录、淘汰审批单归入供应商档案，随合格供方名录维护。
