# 供应商评价与分级管理（supplier-evaluation）

供应商是质量链条的延伸：**准入不评价、绩效不统计、分级不落地**，来料问题就会月月复发。

这个技能做四件事：**准入评** → **绩效算** → **分级管** → **动态调**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 讲解评价方法与分级口径 | ❌ 替代组织采购决策 |
| 生成评价表与评分计算 | ❌ 保证供方绩效 |
| 整理淘汰与再评价机制 | ❌ 出具认证结论 |

**不得以评价替代对供方的现场审核与验证**；关键供方应开展现场审核。

**永远不要**让"关系分"进评分表——维度、权重、数据口径要事先定死，事后不改。

---

|---|---|

## 二、完整工作流

```
第 1 步  明确场景：准入评价 / 季度年度绩效评价 / 分级调整 / 淘汰
第 2 步  读规则文件 rules/supplier_rules.md
第 3 步  按场景取用：
    - 准入评 → 准入维度（第三节）
    - 绩效算 → 维度与权重（第四节）
    - 分级管 → 分级规则（第五节）
    - 动态调 → 再评价与淘汰（第六节）
    - 跑评分 → python scripts/supplier_score.py --selftest
第 4 步  按 templates/供应商评价表.md 输出
第 5 步  人工确认：数据口径、现场审核、商务隔离
```

## 三、准入评价（新供方）

| 维度 | 内容 |
|---|---|
| 资质 | 营业执照、行业许可、特殊资质 |
| 体系 | 认证证书及范围、必要时二方审核 |
| 产能与交付 | 产能、交期历史、物流方式 |
| 样品/首件 | 样品确认、小批量试做 |
| 财务与合规 | 经营稳定性、重大诉讼 |
| 商务 | 价格、付款、服务响应 |

**准入红线**：资质缺失、体系范围不覆盖、样品不合格——一票否决，不进入评分。

---

## 四、绩效评价维度与权重（示例）

| 维度 | 权重 | 数据来源 |
|---|---|---|
| 质量 | 50% | 来料合格率(PPM)、退货、让步 |
| 交付 | 30% | 准时交付率、短缺次数 |
| 服务/响应 | 20% | 问题响应速度、配合度 |

> 权重由采购、质量、使用部门共同确定，**一个年度内不变**；不同品类可设不同权重（如设备类加大服务权重）。

---

## 五、分级管理

| 等级 | 分数 | 管理策略 |
|---|---|---|
| A（优秀） | ≥ 90 | 优先付款、加大份额、减少进货检验 |
| B（合格） | 75~89 | 维持份额、正常管理 |
| C（观察） | 60~74 | 限制新订单、要求改进计划、加密检验 |
| D（不合格） | < 60 或触红线 | 停用淘汰、启动替代 |

**红线项（一票降级/淘汰）**：掺杂使假、擅自变更材料/工艺、伪造报告、重大质量事故隐瞒。

---

## 六、再评价与淘汰

- **周期**：A 级年度、B 级半年度、C 级季度；新供方前 3 批加密评价
- **降级**：连续两期下降或触发红线，降一级并约谈
- **淘汰**：D 级或红线，走替代流程，**旧库存与在途按风险处置**，保留记录备查

---

## 七、脚本用法（评分计算器）

```bash
python scripts/supplier_score.py --quality 98 --delivery 92 --service 85
python scripts/supplier_score.py --selftest
```

输出：加权总分、等级、管理建议。

> ⚠️ 计算器只按权重口径计算，**不替代评价决策**。

---

## 八、人工确认（这步不能省）

- [ ] 数据来源是否可追溯（来料记录、交付记录）
- [ ] 权重是否年度内未动
- [ ] 样品/首件确认是否留存
- [ ] 现场审核是否按计划开展
- [ ] 降级淘汰是否履行告知与替代流程
- [ ] 评分与商务隔离，无利益输送

---

## 九、输出结构（固定三段）

1. **供方状态**——结论先行：健康 / 有风险 / 有红线
2. **评分明细**——维度、数据、加权分
3. **处置建议**——份额调整、改进要求、淘汰流程

## 十、最常见的坑

**坑一：准入走过场。** 资质复印件一收就算评完，现场都没去过。

**坑二：绩效凭印象。** 年底评分全靠"感觉还行"，没有数据。

**坑三：权重看订单改。** 份额大的供方权重就调松，评分失去公信力。

**坑四：C 级不处置。** 观察级供方订单照下，问题照犯。

**坑五：淘汰不留痕。** 说不清为什么淘汰，涉诉时举证不能。
