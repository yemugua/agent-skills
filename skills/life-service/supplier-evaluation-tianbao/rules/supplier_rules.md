# 供应商评价规则库（supplier_rules）

> 本文件是 supplier-evaluation 技能的规则支撑。维度与权重以本单位制度为准。

## 一、法规依据速查

| 文件 | 关键要求 | 关联 |
|---|---|---|
| ISO 9001 | 8.4 外部提供过程控制：评价、选择、绩效监视 | 供方管理来源 |
| 单位采购制度 | 准入流程、权限、审批 | 执行口径 |

## 二、准入评价判定口径

| 维度 | 红线项（一票否决） |
|---|---|
| 资质 | 证照缺失、超范围经营 |
| 体系 | 范围不覆盖且拒不改进 |
| 样品 | 连续两次不合格 |
| 交付 | 交期严重失信且无说明 |
| 合规 | 重大处罚隐瞒、涉诉未披露 |

## 三、绩效评分口径

| 维度 | 权重 | 数据来源 |
|---|---|---|
| 质量 | 50% | 来料合格率/PPM、退货 |
| 交付 | 30% | 准时交付率、短缺 |
| 服务 | 20% | 响应速度、配合度 |

公式：总分 = 质量×0.5 + 交付×0.3 + 服务×0.2

## 四、分级判定口径

| 等级 | 分数 | 策略 |
|---|---|---|
| A | ≥90 | 优先付款、加份额、减检验 |
| B | 75~89 | 维持 |
| C | 60~74 | 限单、改进计划、加密检 |
| D | <60 或触红线 | 停用淘汰 |

## 五、再评价与淘汰口径

- 周期：A 年度 / B 半年度 / C 季度 / 新供方前 3 批加密
- 降级：连续两期下降或触红线
- 淘汰：D 级或红线，走替代流程，旧库存按风险处置

## 六、常见不合规情形

- 准入无现场审核
- 评分无数据凭印象
- 权重随订单调整
- C 级不处置
- 淘汰不留痕
