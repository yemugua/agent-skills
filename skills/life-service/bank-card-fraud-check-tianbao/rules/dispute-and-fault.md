# 争议类型与银行担责

## 一、五类争议类型（脚本 `DISPUTE_TYPES`）

| 类型 | 常见表述 | 处理路径 |
|---|---|---|
| **伪卡盗刷** | 伪卡、假卡、伪造、复制卡、卡片被复制 | 复制卡在商户或取现环节产生 → 找**收单机构与发卡行**，重点是让银行举证其核验义务 |
| **网络盗刷** | 网络、线上、手机银行、网银、支付平台、第三方支付 | 找**发卡行**主张安全义务，重点是银行有没有做异常识别与拦截 |
| **短信诈骗转账** | 诈骗、冒充、客服、公检法、刷单、退款、杀猪盘、被骗转账 | **主要对手是骗子和公安机关**，银行通常以"你自愿转账"抗辩，重点在报案追赃 |
| **他人代刷或误输账号** | 输错、代刷、误转、错转、认错、他人操作 | 找银行核实收款人身份与操作渠道，多数可协商退回 |
| **涉毒涉赌资金** | 赌博、博彩、毒品、洗钱、非法平台、跑分 | 走刑事程序，同时向银行申请冻结与止付 |

**为什么必须先定性**：同样是钱被刷走，银行该不该赔、找谁赔、拿什么证据，完全不同。填采集表时把**钱是怎么被刷走的、在哪里发生、什么时间**写清楚。

## 二、银行担责的前提与例外

银行对客户负有**安全保障义务**，主要包括：

- 核验义务：核验身份、验证交易要素
- 风控义务：识别异常交易、拦截可疑操作
- 安全提示义务：更换卡片、提醒用卡安全
- 信息保密义务：不泄露客户信息给第三方（不刷或转授权导致的盗刷）

**但以下情形银行可能不承担赔偿责任**（需由银行举证）：

1. 你把密码、验证码、卡片交给了他人，或授权他人操作
2. 你在公用设备、不明链接页面上登录了网银
3. 你开通并**实际使用**了小额免密、代扣等快捷支付
4. 你收到银行或支付机构的**安全提示后仍按提示操作**
5. 你在发现异常后**未及时采取措施**（未挂失、未改密），导致损失扩大

**关键点**：即使是"你授权过"，**银行仍需说明它是否履行了监测与拦截义务**。要求其书面提供核验记录与风控记录。

## 三、常见银行说法与应对

| 银行说 | 你要回什么 |
|---|---|
| "可能是你本人授权的" | 要求提供**具体授权凭证**（哪笔、代扣协议编号、开通时间），并说明是否验证了动态口令 |
| "你已开通免密支付" | 问清**是否在你不知情时开通的**、开通渠道与验证方式；不明渠道开通的属银行未尽审查 |
| "系统已识别为异常" | 问**识别后为什么没拦截**；有风控记录不等于履责 |
| "你去公安报案，我们配合" | 报案是**义务而非前置条件**，不得以"未报案"为由拒受理争议 |
| "你等通知吧" | 要求**书面受理回执**与**答复时限**，否则视为未受理 |
| "已经过了诉讼时效" | 银行不得以格式条款排除主要权利；时效问题需具体协商 |

## 四、追偿顺序

1. **发卡行**：主张未尽安全保障义务（伪卡、网络盗刷场景）
2. **收单机构 / 支付平台**：商户侧收银系统或平台风控问题
3. **公安机关**：涉刑的追赃挽损
4. **金融监管部门投诉**：12378 银行服务热线、金融监管总局派出机构
5. **支付结算投诉**：12363
6. **法院起诉**：向发卡行或收单机构主张返还损失

## 五、责任判断的常见误区

- **"我卡没离开我手"就一定能赔**？不一定。若开通了免密、验证码被套取，银行可能抗辩成立。
- **"银行有免责条款"就一定不用赔**？不一定。**排除对方主要权利、免除己方主要义务的格式条款可能无效**。
- **"金额小不值得报案"**？**一定要报**。报案记录会成为后续所有维权的基础材料。
- **"钱不多就算了"**？多数情况下**银行会全额赔付符合条件的盗刷**，主动放弃不划算。
