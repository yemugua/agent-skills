# 盗刷止损与维权操作卡

> 发现盗刷时按顺序做，**越靠前越紧急**。别跳步。

## 【第一优先】发现后 1 小时内

- [ ] 通过**银行官方渠道**（App / 卡背电话 / 柜台）**挂失或冻结账户**
- [ ] 拿到**挂失回执**，确认上面有办理时间
- [ ] **更换**取款密码、网银密码、支付密码（不与其他服务复用）
- [ ] **关闭**所有小额免密支付、代扣协议、快捷支付授权
- [ ] 更换邮箱、支付类 App 密码
- [ ] 剪断或销毁旧卡（如已补卡）

> ⚠️ **绝不拨打搜索结果里的"客服电话"，绝不点击自称银行发来的短信链接。**

## 【第二优先】发现后 24 小时内

- [ ] 到银行网点打印**近 6 个月完整流水**（要纸质章，不要 App 截图）
- [ ] **逐笔标注**可疑交易：日期、金额、商户、渠道、订单号
- [ ] 到公安机关**报案**，取得**受案回执**，记下警号与办案民警
- [ ] 排查账号安全：是否点过不明链接、是否装过不明 App、是否被借用过
- [ ] 保存排查结论的截图或书面说明

## 【第三优先】发现后 3 日内

- [ ] 提交**书面**盗刷异议（模板见下），**不要只打电话**
- [ ] 索取**书面受理回执**与答复时限
- [ ] 书面要求银行提供：核验记录、风控记录、免密开通渠道与时间
- [ ] 用 **EMS 寄一份**给开户行合规部门，保留寄件单与签收记录

## 书面异议必写要素

- [ ] 姓名、身份证号、卡号后四位、联系方式
- [ ] 发现时间、挂失时间、涉及的可疑交易清单
- [ ] 明确主张：**请求不承担上述交易责任并予以返还**
- [ ] 要求银行书面提供核验方式、风控处理情况
- [ ] 若拒赔，要求**书面写明依据**
- [ ] 附件：流水、挂失回执、报警回执、身份证明

## 【升级】银行不给结果时

- [ ] 银行客服与上级行投诉，**留存工单号**
- [ ] 拨 **12378** 银行服务热线投诉，索取**投诉编号**
- [ ] 涉第三方支付平台或收单机构 → 拨 **12363** 支付结算服务热线
- [ ] 向**金融监管总局及其派出机构**提交投诉书与全套证据
- [ ] 必要时向法院起诉发卡行或收单机构

## 征信同步处理

- [ ] 查询个人信用报告
- [ ] 有盗刷记录 → 提**征信异议申请**，附流水与报案回执
- [ ] 一般 20 日内应得到核查答复

## 涉刑就并行推进

- [ ] 确认是伪卡、网络盗刷或诈骗转账的，**书面要求银行移送公安机关**
- [ ] 提供**收款账户、交易时间、订单号**协助追赃
- [ ] 银行不予移送的，向公安机关说明并留存记录

---

**记住**：报案回执、完整流水、挂失回执——**这三样是全部维权动作的地基**。
