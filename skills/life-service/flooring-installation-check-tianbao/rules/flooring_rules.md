# 地板铺装验收规则表

生成验收方案或沟通材料前先读本文件，不要凭印象写。

---

## 一、七项验收必查表

| 序号 | 验收项 | 检测方法 | 合格表现 |
|---|---|---|---|
| 1 | 空鼓 | 用专用空鼓锤或硬币逐块轻敲，听空音；边角与接缝处重点查 | 以产品说明书与施工规范约定的口径为准；无明确约定时应书面确认判定标准后再判定 |
| 2 | 拼缝高低差 | 用直尺跨接缝测量，或用硬币侧面沿缝滑动 | 无可感知的台阶；具体允许值以说明书与规范为准 |
| 3 | 表面平整度 | 用靠尺或直尺贴地检查，间隙情况用塞尺测 | 无明显起伏；允许值以说明书与规范为准 |
| 4 | 含水率 | 按产品说明书规定的方法检测，必要时用相应仪器 | 以产品说明书与施工规范要求为准，不同材质要求不同 |
| 5 | 封边与踢脚线 | 目视与手触：封边是否牢固、踢脚线是否平顺、缝隙是否均匀 | 平顺牢固，无明显缝隙与翘起 |
| 6 | 异响 | 逐区走动，重点在拼缝处与墙边、门口过渡处 | 正常走动无异响；轻微响声需判断是否为材料正常现象 |
| 7 | 缝隙直线度 | 顺缝方向目视，必要时拉线检查 | 缝隙走向基本顺直，无明显弯曲错位 |

**关于具体数值**：不同材质、不同产品、不同施工做法允许值差别很大。不要套用别家的数值，一律以本产品说明书与现行施工规范为准。

## 二、验收时点

| 时点 | 是否适合 |
|---|---|
| 铺装当天 | 不适合，材料未稳定，判断易误判 |
| 说明书规定的养护期结束后 | 适合 |
| 入住数月后 | 过晚，现场状态已改变，缺少依据 |

---

## 三、空鼓责任判定参考

| 空鼓分布特征 | 常见归属参考 | 说明 |
|---|---|---|
| 集中在地面积水区、门口、墙边等特定位置 | 铺装方 | 属施工工艺问题 |
| 零散分布且比例较高 | 铺装方为主 | 属整体铺装工艺问题 |
| 铺装后被人为踩踏、搬重物、水浸造成 | 使用方 | 属后期损坏 |
| 基层问题导致 | 需区分 | 应先确认基层状况 |
| 出现在未踩踏区域且随时间扩大 | 铺装方为主 | 属材料或工艺稳定性问题 |

归属的最终认定以施工合同约定、现场记录、材料检测报告与专业检测结论为准。

**关键点**：区分铺装方责任与后期损坏的界线是**踩踏与浸水**。验收时逐块敲完并留记录，是唯一有效的分界依据。

## 四、含水率与地板类型的关系

| 地板类型 | 含水率要求的方向性说明 |
|---|---|
| 强化复合地板 | 有较明确的要求范围，需按说明书检测 |
| 多层实木复合地板 | 要求通常与实木接近，需注意平衡层与面层差异 |
| 实木地板 | 对含水率较敏感，含水率与环境湿度不匹配是开裂与变形的常见原因 |
| 软木地板 | 需按产品说明书要求检测 |
| PVC 与弹性地材 | 与木地板的要求逻辑不同，需按对应产品说明书 |

**三条通用原则：**

1. 具体数值以产品说明书与施工规范为准，不要用别家的数值
2. 检测方法按说明书规定，不同方法结果可能不同
3. 含水率要与使用环境湿度条件匹配，南方与北方、不同季节的合理区间不同

含水率不匹配造成的开裂与变形，往往在铺装后数月甚至跨年后才显现，那时已很难追溯。

## 五、三种铺装方式对照

| 方式 | 做法 | 适用 | 优点 | 限制 |
|---|---|---|---|---|
| 直铺 | 直接铺在基层上，按产品要求处理 | 基层平整干燥状况良好 | 工期短、层高低 | 基层要求高，平整度差不行 |
| 锁扣拼装 | 锁扣卡接，多为悬浮式 | 多数强化与多层地板 | 快、无需胶、便于更换 | 基层仍需平整，空鼓拼缝问题多与基层相关 |
| 悬浮铺装 | 锁扣拼装且不固定在基层，靠板与板之间行走 | 常见强化与多层地板 | 对基层要求相对宽松、可拆卸 | 基层潮气仍会影响，潮湿基层不可直接铺 |
| 龙骨铺装 | 先装龙骨找平再铺地板 | 地面高差大、基层状况差、地暖需架空 | 可大幅改善平整、架空层可通风 | 成本高、层高增加、需专业施工 |

---

## 六、龙骨铺装要点

| 要点 | 说明 |
|---|---|
| 龙骨间距与固定 | 按产品说明书与施工规范，不可随意放大间距 |
| 找平与标高 | 龙骨安装时同步找平，处理地面高差 |
| 通风与防潮 | 架空层需保持通风，检查基层干燥状况 |
| 与地暖配合 | 涉及地暖时按地暖系统的具体要求处理 |
| 防虫与防潮处理 | 按产品说明书要求处理 |
| 成品保护 | 龙骨安装后铺板前应做保护，避免踩踏扰动 |

龙骨铺装属于专业施工范围，本节仅供了解与沟通。

---

## 七、必须提前确认的六件事

| 事项 | 为什么必须提前 |
|---|---|
| 地面找平状况 | 决定采用哪种铺装方式 |
| 门槛与门洞高度差 | 铺装后层高增加，可能导致门装不上或需要改门 |
| 踢脚线尺寸与固定方式 | 涉及地板与墙面的收口 |
| 伸缩缝位置 | 长度与宽度方向需留出伸缩余量，不能随意取消 |
| 基层干燥状况 | 潮湿基层铺装会导致起拱、开裂 |
| 家具与柜体安装顺序 | 重物位置、地脚线是否与踢脚线冲突 |

---

## 八、必须转铺装方或专业检测的情形

1. 大面积铺装（整户或多房间）
2. 需龙骨铺装
3. 地面高差大，需大量找平或局部处理
4. 旧地板拆除
5. 基层有明显裂缝、空鼓、渗水痕迹
6. 需要动地暖系统或地面基层
7. 出现贯穿性结构问题的争议

## 九、常见推诿与应对

| 对方说法 | 问题在哪 | 应对方式 |
|---|---|---|
| 这是正常现象 | 正常需要口径，不是靠说 | 要求书面明确判定标准，以说明书与规范为准 |
| 空鼓一点点不影响使用 | 影响长期稳定与后续责任划分 | 按约定口径逐块敲并记录，不接受口头结论 |
| 当时你验收过了 | 需要验收时点与记录 | 展示验收记录与照片，说明记录之外的部分 |
| 是你后来泡水造成的 | 归属界线是踩踏与浸水 | 用验收记录对照，区分铺装时缺陷与后期损坏 |
| 含水率当时测过合格 | 需要检测方法与数值 | 请提供检测记录与方法，按说明书要求的方法核对 |
| 这不是我的施工范围 | 范围应写在合同里 | 以合同约定范围为准 |

**通用建议**：验收时逐项检查、逐项拍照、逐项记录，并请铺装方共同确认。口头结论在纠纷时没有作用。

## 十、常见误判清单

1. 铺完当天就验收——材料未稳定，易误判
2. 只看表面不看空鼓——空鼓是后期起拱异响的根源
3. 不敲边角——空鼓常集中在墙边、门口与拼缝边缘
4. 拿别家数值当标准——允许值因材质与产品而异
5. 含水率不测——跨年后开裂变形已无证据
6. 忽略门槛高度差——铺装后门可能装不上
7. 伸缩缝被填掉——容易起拱
8. 验收不留照片和记录——三个月后无法追溯
9. 分不清铺装缺陷与后期泡水——界线是踩踏与浸水
10. 把这是正常现象当结论——正常需要口径
