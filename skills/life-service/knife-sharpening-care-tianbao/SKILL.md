# 刀具保养与磨刀核查（knife-sharpening-care）

磨刀这件事只有一个关键动作：**逆刃单向推磨**。做对了刀会越来越利，做错了会把刃口磨成锯齿和凹口，之后要修回来非常困难。

这个技能做三件事：**选刀型参数 → 按口径磨 → 查状态**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 按刀型给出刃角、磨料与磨法口径 | ❌ 修复崩口、断裂或严重变形 |
| 说明磨刀器、磨刀石、磨刀棒的差异 | ❌ 指导电磨、砂轮机高速磨削 |
| 给出清洗、收纳与生熟分离要求 | ❌ 判定刀具材质与是否达到食品接触标准 |
| 输出九项状态检查与三级判定 | ❌ 指导自制或改造磨刀器具 |

**遇到以下情况，交由专业磨刀与维修处理：**

- 刃口**崩口、缺角或出现明显跳刃**
- 刀身**弯曲变形**，或与柄部连接处松动
- **刀柄开裂、脱胶**（尤其是木柄与竹柄）
- **刀口有裂纹、材质变色**等疑似疲劳或材质问题
- **特殊材质刀具**（陶瓷、钛、粉末钢等）的高精度复原
- 需要**电磨或砂轮机**高速磨削

> **木柄与竹柄刀具不可进洗碗机，也不可长时间泡水。** 这是本技能最需要强调的一条，见下文。

## 二、磨刀的方向与力度（最重要）

```
磨刀的核心是逆刃推磨，不是来回拉锯。
```

| 要点 | 正确做法 | 错误后果 |
|---|---|---|
| **方向** | 刀刃放磨料上，**由刀跟向刀尖单向推动** | 来回拉锯会磨出**高低不平的波浪线**，形成锯齿状缺陷 |
| **力度** | **均匀而轻**，靠磨料自身磨削去除金属 | 用力过猛单侧下压会**磨出凹口**，刃线不再平直 |
| **频率** | 每磨几下**观察一次**刃口线是否平直 | 盲磨到「感觉够了」，往往已经磨过头 |

**为什么不能来回拉锯**：每一次回程都会在刃口上产生**方向相反的磨削**，两次磨削的起始点不同，于是刃线被磨成波浪状。波浪形的刃口切割时会产生额外摩擦，既不锋利又加速钝化。

**为什么不能用力压**：磨料的作用是**引导**金属去除，不是靠压力硬磨。压力大只会让磨料嵌入刀面，造成不均匀磨损。

## 三、按刀型的磨刀参数

| 刀型 | 刃口角度 | 刃角档位 | 推荐工具 | 磨料 | 注意事项 |
|---|---|---|---|---|---|
| **中式片刀** | 15° | 薄刃 | 磨刀石 | 细目与粗目配合 | 刃口薄，平推轻磨；**忌用磨刀棒硬刮** |
| **日式主厨刀** | 15° | 薄刃 | 磨刀石 | 细目 1000–3000 | 单刃结构，**只磨主刃**，凹刃侧不要磨出斜面 |
| **中式片刀（厚背型）** | 20° | 标准刃 | 磨刀石 | 粗细目配合 | 刃角较厚，先粗磨定型再细磨，握持靠近刀跟 |
| **剔骨刀** | 20° | 标准刃 | 磨刀石 | 细目为主 | 刃薄需轻磨，握持靠近刀尖便于精细控制 |
| **西式厨刀** | 20° | 标准刃 | 磨刀器或磨刀石 | 中细目 | 适用磨刀器，注意磨料槽与刀身角度贴合 |
| **厨房剪刀** | 20° | 标准刃 | **专用剪刀位** | 专用细目 | **剪刀不可整体压上磨刀器**，用专用位逐刃磨 |
| **面包刀（锯齿）** | 20° | 标准刃 | 专用锯齿磨具 | 专用细目 | **锯齿刃不可磨成平刃**，会失去锯切能力 |
| **削皮刀与餐刀** | 20° | 标准刃 | 磨刀石 | 细目 1000 以上 | 小刀刃短，握持靠近刀尖控制力度 |
| **中式斩切刀** | 20° | 标准刃 | 磨刀石 | 粗目为主 | 刃角较厚，磨除量较大，**分多次进行避免过热** |

**刃角档位含义**：

| 档位 | 角度 | 特点 |
|---|---|---|
| **薄刃** | 15° | 适合精细切割，锋利但**易崩需谨慎** |
| **标准刃** | 20° | 兼顾锋利与耐用，家庭最常用 |
| **厚刃** | 20° 以上 | 耐用，适合劈砍与重活 |

**按原角度磨，不要随意改变刃角几何**：改动刃角会改变刀的重心与切割特性，且很难恢复。

## 四、磨刀器、磨刀石、磨刀棒怎么选

| 工具 | 优点 | 缺点 | 适用 |
|---|---|---|---|
| **磨刀器** | 日常快速修整，效率高，对操作要求低 | 控制力度不当时**极易磨出 V 形凹口**，且明显消耗刃口 | 不追求刃口精细度时首选 |
| **磨刀石** | 刃口可控性好，可磨出理想的平直刃线与弧度 | 需要一定手法与练习，学习成本较高 | 追求锋利度与刃口几何时 |
| **磨刀棒**（陶瓷或钢） | 快速恢复刃口锋利，延缓钝化 | **只能修整不能真正磨出锋利刃口**，且会改变刃角 | 日常维护，**不作为主要磨刀方式** |

**关于磨刀棒的常见误解**：很多人以为磨刀棒能把刀磨快。它实际做的是**把卷起的刃口重新「捋」直**，属于临时恢复，不去除金属。真正变钝后仍需磨刀石或磨刀器。

## 五、去毛刺（磨完必做）

```
用一根细麻绳或皮革条，顺着与刃口垂直的方向轻轻拉过整个刃口，
把向一侧倒伏的毛边扳倒回去，再顺着切削方向轻拉一次。
```

**为什么必须去毛刺**：

| 不去毛刺的后果 | 说明 |
|---|---|
| **挂毛、撕纤维** | 切肉、切水果时纤维被毛边勾住，断面不干净 |
| **加速再次钝化** | 毛边在切割中反复折叠断裂，钝化速度明显加快 |
| **手感割手** | 毛边向内侧倒伏时容易割到手指 |

**去毛刺的时机**：每次磨刀完成后，以及**每次使用前**发现刀口有毛刺时。

## 六、收纳四条

| # | 要求 | 原因 |
|---|---|---|
| 1 | **不可叠放** | 刃口互相碰撞会**瞬间崩刃** |
| 2 | **竖放或用刀架、刀块**，刃口朝下或插入槽位 | 避免刃口与其他物体接触 |
| 3 | **刃口不碰金属** | 木质或塑料刀架更安全 |
| 4 | 洗后**立刻擦干** | 潮湿会锈蚀并使刃口边缘发黑 |

**「不可叠放」是硬要求**：两把刀叠在抽屉里，刃口互相压着，稍微一动就是一次碰撞。崩口一旦形成，只能靠专业磨刀修复。

---

## 七、明确禁止的操作（8 类）

1. **木头柄与竹柄刀具不可进洗碗机**——高温与长时间浸水会使柄部开裂变形
2. **木头柄与竹柄刀具不可长时间泡水**——浸水后柄部会膨胀松动
3. **不可用洗碗机清洗任何优质刀具**——高温与洗涤剂会损伤刃口
4. **不可用磨刀棒当主要磨刀方式**——只能修整不能磨出锋利刃口
5. **不可用陶瓷刀磨玻璃或大理石台面**——会剧烈磨损刃口
6. **不可把刀丢进水槽底部**——容易缺口且难以发现
7. **不可用力过猛单侧下压**——会磨出凹口并使刃线不再平直
8. **剪刀不可整体压上磨刀器**——须用专用剪刀位逐刃修磨

**木柄竹柄为什么特别怕水**：木材与竹材吸水后**膨胀变形**，而金属刀身与刀柄的热胀冷缩系数不同，反复干湿交替会使**连接部位松动开裂**。洗碗机的高温蒸汽环境是最恶劣的情况。

## 八、生熟刀分离

```
红色或粉色标识刀 → 生肉
蓝色或绿色标识刀 → 蔬菜与熟食
黄色标识刀 → 一般用途
```

**为什么必须分离**：生肉表面可能带有**沙门氏菌、弯曲菌**等致病菌。用切过生肉的刀直接接触即食或即入口食品，会造成交叉污染。

**只有一把刀怎么办**：切完生肉后必须**彻底冲洗并用皂液清洁刀面**，且**不要只用擦刀布擦干表面就收起来**——那只是把污染转移到布上。

## 九、九项状态检查

| # | 检查项 | 怎么判断 | 不合格后果 |
|---|---|---|---|
| 1 | **锋利度** | 能轻松切开纸张或黄瓜片而不拖泥带水 | 钝刀需加大力度，更容易**滑刀割伤** |
| 2 | **刃线平直** | 刃口线平直无高低波浪，无 V 形凹口 | 切割不干净，且难以恢复 |
| 3 | **毛刺已清除** | 迎光观察无倒伏毛边，切割不挂毛 | 挂毛撕纤维，加速再次钝化 |
| 4 | **柄部完好** | 木柄竹柄无开裂松动，金属柄无松动锈蚀 | 柄部松动时受力异常，刃口易崩 |
| 5 | **无锈蚀** | 刃面无锈点，刃口边缘无发黑 | 消耗刃口材料，钝化加快 |
| 6 | **已完全擦干** | 刀身与柄部完全干燥无水渍 | 潮湿导致锈蚀与柄部开裂 |
| 7 | **收纳合规** | 未叠放，竖放或用刀架，刃口不碰金属 | 叠放碰撞会瞬间崩刃 |
| 8 | **清洁到位** | 刀面已用皂液清洁并冲净，无残留 | 残留物与潮湿共同导致异味与锈蚀 |
| 9 | **生熟分离** | 生肉刀与即食刀分用，分色管理 | 生肉交叉污染即食食品 |

**三级判定**：全部合格为**状态良好**；有未检查项为**待确认**；有任一不合格项为**需处理后使用**。

## 十、脚本用法

```bash
python scripts/knife_care_check.py --file knife.json --out 刀具核查.md
python scripts/knife_care_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`items` 刀具列表（`knife` 刀型键、可选 `angle` 当前刃角）、`checks` 九项检查结果 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检（47 条断言，含 BOM 输入两条） |

输入 JSON 示例：

```json
{
  "checks": {
    "sharpness": true,
    "edge_line": true,
    "burr": false,
    "handle": true,
    "corrosion": true,
    "dry": true,
    "storage": true,
    "clean": true,

    {"knife": "serrated_bread", "name": "锯齿面包刀"}

```

脚本输出：三级判定、按刀型的磨刀参数、磨刀工具三方对比、逆刃推磨口径、去毛刺、收纳四条、明确禁止的操作、生熟刀分离、九项检查逐项状态与提示。

## 十一、人工确认清单（这步不能省）

- [ ] 刃口线平直，无 V 形凹口与波浪线
- [ ] 已完成去毛刺，切割不挂毛
- [ ] 木柄竹柄刀具未进过洗碗机、未长时间泡水
- [ ] 刀具已完全擦干并合规收纳，未叠放
- [ ] 生熟刀分离，分色管理
- [ ] 磨刀为逆刃单向推磨，力度均匀而轻

## 十二、最常见的坑

**坑一：来回拉锯磨刀。**
错误做法：像锯东西一样来回推。正确做法：**由刀跟向刀尖单向推动**，每一下同一方向。来回拉锯会磨出**高低不平的波浪线**，形成锯齿状缺陷，之后要修回来非常困难。

**坑二：磨刀棒当主要磨刀方式。**
错误做法：刀钝了就用磨刀棒怼几下。正确做法：磨刀棒**只能修整不能真正磨出锋利刃口**，它做的是把卷起的刃口重新捋直。真正变钝后仍需磨刀石或磨刀器。

**坑三：木柄刀扔洗碗机。**
错误做法：中式片刀木柄，顺手放洗碗机。正确做法：**木柄竹柄不可进洗碗机、不可长时间泡水**。高温蒸汽与长时间浸水会使柄部开裂变形、与刀身连接松动，且刀身锈蚀。

**坑四：刀叠在抽屉里。**
错误做法：所有刀往抽屉里一扔，层层叠压。正确做法：**不可叠放**。刃口互相碰撞会瞬间崩刃。应竖放或用刀架、刀块，**刃口不碰金属**。

**坑五：磨完不处理毛刺。**
错误做法：磨完擦一擦就切肉。正确做法：**磨完必须去毛刺**，用细麻绳或皮革条顺着与刃口垂直的方向拉过整个刃口。不去毛刺会**挂毛撕纤维**，且加速再次钝化。

**坑六：锯齿面包刀磨成平刃。**
错误做法：面包刀钝了，拿磨刀石一路磨平。正确做法：**锯齿刃不可磨成平刃**，会彻底失去锯切功能。应按原有锯齿形态逐齿修整，或用专用锯齿磨具。

**坑七：剪刀整个压上磨刀器。**
错误做法：剪刀开合着往磨刀器槽里压。正确做法：**剪刀不可整体压上磨刀器**，须用**专用剪刀位**逐刃修磨。整体压会磨歪刃口且损坏磨刀器。

**坑八：用磨刀石很用力往下压。**
错误做法：觉得磨得慢就加力。正确做法：**力度要均匀而轻**，靠磨料自身的磨削作用去除金属。用力过猛单侧下压会**磨出凹口**，刃线不再平直。

**坑九：一把刀切完生肉直接切水果。**
错误做法：刚切过生排骨的刀，直接削苹果。正确做法：**生熟刀必须分离**，红色标识刀用于生肉，蓝色或绿色用于蔬菜与熟食。生肉表面可能带有**沙门氏菌、弯曲菌**。只有一把刀时必须用皂液彻底清洁刀面。

**坑十：只用擦刀布擦干就收。**
错误做法：刀上有点水，擦一下收进刀架。正确做法：**洗后立刻擦干**，潮湿会锈蚀并使刃口边缘发黑。擦刀布上的残留物也会造成异味。

**坑十一：刀钝了还加大力气切。**
错误做法：切不动就使劲压。正确做法：钝刀切菜需加大力度，**更容易滑刀割伤**。钝了就磨，顺带还能降低割伤风险。

**坑十二：崩口了自己想办法修。**
错误做法：崩了个口子，用磨刀石磨一磨接着用。正确做法：崩口、缺角、刀身弯曲、刀柄开裂应**交由专业磨刀与维修处理**，自行修磨往往会让损伤扩大。
