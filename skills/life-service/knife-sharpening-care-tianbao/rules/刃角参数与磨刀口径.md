# 刃角参数与磨刀口径

> 生成磨刀建议前先读这份文件。不要笼统说「在磨刀石上磨几下」。

## 一、按刀型的磨刀参数

| 键 | 刀型 | 刃角 | 档位 | 工具 | 磨料 | 注意 |
|---|---|---|---|---|---|---|
| `chinese_cleaver` | 中式片刀 | 15° | 薄刃 | 磨刀石 | 细目与粗目配合 | 刃口薄，平推轻磨；忌用磨刀棒硬刮 |
| `japanese_gyuto` | 日式主厨刀 | 15° | 薄刃 | 磨刀石 | 细目 1000–3000 | 单刃结构，只磨主刃，凹刃侧不要磨出斜面 |
| `gyuto_alt` | 日式主厨刀（15 度型） | 15° | 薄刃 | 磨刀石 | 细目 1000–3000 | 单刃结构，注意保持原有弧度 |
| `beef_knife` | 中式片刀（厚背型） | 20° | 标准刃 | 磨刀石 | 粗细目配合 | 先粗磨定型再细磨，握持靠近刀跟 |
| `boning_knife` | 剔骨刀 | 20° | 标准刃 | 磨刀石 | 细目为主 | 刃薄需轻磨，握持靠近刀尖 |
| `utility_knife` | 西式厨刀 | 20° | 标准刃 | 磨刀器或磨刀石 | 中细目 | 注意磨料槽与刀身角度贴合 |
| `kitchen_scissors` | 厨房剪刀 | 20° | 标准刃 | 专用剪刀位 | 专用细目 | 剪刀不可整体压上磨刀器 |
| `bread_knife` | 面包刀 | 20° | 标准刃 | 磨刀石 | 细目 400–600 | 锯齿刃，按原有形态逐齿修整 |
| `serrated_bread` | 锯齿面包刀 | 20° | 标准刃 | 专用锯齿磨具 | 专用细目 | 锯齿刀不可磨成平刃 |
| `paring_knife` | 削皮刀与餐刀 | 20° | 标准刃 | 磨刀石 | 细目 1000 以上 | 小刀刃短，握持靠近刀尖 |
| `chopping_hachet` | 中式斩切刀 | 20° | 标准刃 | 磨刀石 | 粗目为主 | 磨除量大，分多次避免过热 |

**刃角档位**

| 档位 | 角度 | 特点 |
|---|---|---|
| 薄刃 | 15° | 精细切割，锋利但易崩需谨慎 |
| 标准刃 | 20° | 兼顾锋利与耐用，家庭最常用 |
| 厚刃 | 20° 以上 | 耐用，适合劈砍与重活 |

## 二、磨的方向与力度

```
由刀跟向刀尖单向推动，每一下同一方向。
力度均匀而轻，靠磨料自身磨削去除金属。
每磨几下观察一次刃口线是否平直。
```

| 要点 | 正确 | 错误后果 |
|---|---|---|
| 方向 | 由刀跟向刀尖单向 | 来回拉锯磨出高低波浪线，形成锯齿状缺陷 |
| 力度 | 均匀而轻 | 用力过猛单侧下压磨出凹口，刃线不再平直 |
| 频率 | 每几下观察一次 | 盲磨到「感觉够了」往往已磨过头 |

**为什么不能来回拉锯**：每次回程产生方向相反的磨削，起始点不同，刃线被磨成波浪状。波浪刃切割时产生额外摩擦，既不锋利又加速钝化。

**为什么不能用力压**：磨料作用是**引导**金属去除，不是靠压力硬磨。

## 三、磨刀工具对比

| 工具 | 优点 | 缺点 | 适用 |
|---|---|---|---|
| 磨刀器 | 快速修整，效率高，要求低 | 易磨出 V 形凹口，明显消耗刃口 | 不追求精细度时首选 |
| 磨刀石 | 刃口可控性好，可磨出平直刃线与弧度 | 需手法与练习，学习成本高 | 追求锋利度与刃口几何时 |
| 磨刀棒（陶瓷或钢） | 快速恢复锋利，延缓钝化 | 只能修整不能真正磨出锋利刃口，且改变刃角 | 日常维护，不作主要磨法 |

**磨刀棒做的是把卷起的刃口重新捋直，属临时恢复，不去除金属。**

## 四、去毛刺

```
用细麻绳或皮革条，顺着与刃口垂直的方向轻轻拉过整个刃口，
把倒伏毛边扳倒回去，再顺着切削方向轻拉一次。
```

| 不去毛刺的后果 | 说明 |
|---|---|
| 挂毛、撕纤维 | 切肉切水果时纤维被毛边勾住 |
| 加速再次钝化 | 毛边反复折叠断裂 |
| 手感割手 | 毛边向内侧倒伏时易割手指 |

**时机**：每次磨刀完成后，以及每次使用前发现毛刺时。

## 五、收纳四条

1. **不可叠放**——刃口互碰会瞬间崩刃
2. **竖放或用刀架、刀块**，刃口朝下或插入槽位
3. **刃口不碰金属**——木质或塑料刀架更安全
4. 洗后**立刻擦干**——潮湿会锈蚀并使刃口发黑

## 六、明确禁止的操作

1. 木柄与竹柄刀具**不可进洗碗机**
2. 木柄与竹柄刀具**不可长时间泡水**
3. **不可用洗碗机清洗任何优质刀具**
4. **不可用磨刀棒当主要磨刀方式**
5. 陶瓷刀**不可磨玻璃或大理石台面**
6. **不可把刀丢进水槽底部**
7. **不可用力过猛单侧下压**
8. **剪刀不可整体压上磨刀器**，须用专用剪刀位逐刃修磨

**木柄竹柄为什么特别怕水**：木材与竹材吸水后**膨胀变形**，与金属刀身热胀冷缩系数不同，反复干湿交替使**连接部位松动开裂**。洗碗机高温蒸汽是最恶劣情况。

## 七、生熟刀分离

| 标识色 | 用途 |
|---|---|
| 红色或粉色 | 生肉 |
| 蓝色或绿色 | 蔬菜与熟食 |
| 黄色 | 一般用途 |

生肉表面可能带有**沙门氏菌、弯曲菌**等致病菌，切过生肉的刀不应直接接触即食或即入口食品。

**只有一把刀**：切完生肉后必须**彻底冲洗并用皂液清洁刀面**，不要只用擦刀布擦干就收起。

## 八、九项检查

| 键 | 检查项 | 怎么判断 | 不合格后果 |
|---|---|---|---|
| `sharpness` | 锋利度 | 能轻松切开纸张或黄瓜片 | 钝刀加大力度，更易滑刀割伤 |
| `edge_line` | 刃线平直 | 平直无波浪，无 V 形凹口 | 切割不干净且难恢复 |
| `burr` | 毛刺已清除 | 迎光无倒伏毛边，切割不挂毛 | 挂毛撕纤维，加速钝化 |
| `handle` | 柄部完好 | 木柄竹柄无开裂松动 | 柄部松动刃口易崩 |
| `corrosion` | 无锈蚀 | 刃面无锈点，刃口无发黑 | 消耗刃口材料，钝化加快 |
| `dry` | 已完全擦干 | 无残留水渍 | 潮湿导致锈蚀与柄部开裂 |
| `storage` | 收纳合规 | 未叠放，竖放或用刀架 | 叠放碰撞瞬间崩刃 |
| `clean` | 清洁到位 | 已用皂液清洁并冲净 | 残留与潮湿导致异味锈蚀 |
| `separation` | 生熟分离 | 分用与分色管理 | 生肉交叉污染即食食品 |

**三级判定**：全合格为**状态良好**；有未检查项为**待确认**；有任一不合格为**需处理后使用**。

## 九、转交专业处理的情形

- 刃口**崩口、缺角或明显跳刃**
- 刀身**弯曲变形**或与柄部连接松动
- **刀柄开裂、脱胶**（尤其木柄竹柄）
- 刀口**有裂纹、材质变色**等疑似疲劳
- **特殊材质刀具**（陶瓷、钛、粉末钢）的高精度复原
- 需要**电磨或砂轮机**高速磨削

## 十、否定词与防误伤

- 「**能切动**」**不等于**锋利，可能靠蛮力，切菜更易滑刀割伤
- 「**磨过了**」**不等于**磨好了，力度过猛已磨出凹口
- 「**看着挺平**」**不等于**刃线平直，需迎光斜视检查
- 「**用磨刀棒蹭两下**」**不等于**磨出锋利刃口
- 「**洗完晾干就行**」**不等于**安全，木柄竹柄需立即擦干

## 十一、处置决策树

```
1. 刀型是什么？
   ├─ 锯齿或剪刀类 → 不可磨成平刃，用专用磨具
   ├─ 日式单刃 → 只磨主刃，保持凹刃侧
   └─ 中式或西式 → 按刃角档位磨
2. 木柄或竹柄？
   ├─ 是 → 禁止进洗碗机、禁止长时间泡水，用后立即擦干
   └─ 否 → 仍建议手洗并立即擦干
3. 磨刀方式是逆刃单向推磨吗？
   ├─ 否 → 改为由刀跟向刀尖单向，力度均匀而轻
   └─ 是 → 继续
4. 磨完去毛刺了吗？
   ├─ 否 → 用麻绳或皮革条去毛刺
   └─ 是 → 继续
5. 收纳是否合规？
   ├─ 叠放 → 改为竖放或用刀架，刃口不碰金属
   └─ 合规 → 继续
6. 是否切过生肉？
   ├─ 是 → 与即食刀分离，或皂液彻底清洁刀面
   └─ 否 → 完成
```
