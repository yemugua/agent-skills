# 家具保养与使用维护（furniture-care-guide）

家具的损伤，大部分不是"用坏了"，而是**用错了**：拿同一种清洁剂对付八种材质、把红木和仿红木当同一类对待、长期暴晒和重压当成无所谓。**按材质分类保养，是这一块唯一有效的办法。**

这个技能做五件事：**先判材质** → **查禁忌** → **定手法** → **辨损伤成因** → **决定自己处理还是找师傅**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 按八类材质给出清洁手法与禁忌 | ❌ 承诺修复开裂、崩边、变形等结构损伤 |
| 判断损伤类型与可能成因 | ❌ 代替木工、沙发厂、皮具工做专业修复 |
| 给出日常使用的隐性伤害清单 | ❌ 对不确定材质的家具做化学处理 |
| 说明搬运移位与拆装注意 | ❌ 指导改造家具内部结构、加装受力件 |
| 列出必须找师傅的判定口径 | ❌ 判断家具的承载安全与结构寿命 |

**遇到以下情况，停止自行处理，转交家具厂或专业维修师傅：**

- 结构松动：摇晃、榫接处脱开、受力件开裂
- 五金失效：铰链滑牙、合页断裂、滑轨脱落、连接件松脱
- 大理石崩边或断裂：尤其是带角的位置崩掉、出现贯穿裂
- 皮革开裂：出现贯穿裂缝、表皮大面积起壳剥落
- 软包塌陷：弹簧失效、海绵老化塌陷，坐下去不回弹
- 涉及承重安全的柜体、书架、床架变形
- 价值较高、需要保值的老家具（尤其是木质与皮具）
- 破损涉及结构件而非表面件

## 二、完整工作流

```
第 1 步  判材质：翻到背面、看边角、看五金与断面，确认是哪一类
第 2 步  查禁忌：读 rules/material_care_rules.md 里对应材质的禁忌行
第 3 步  判损伤：看是划痕、开裂、变形、掉色、发霉、五金松动还是塌陷
第 4 步  辨成因：是日常隐性伤害，还是材质本身的先天缺陷，还是使用超载
第 5 步  决定处理方式：表面件可 DIY，结构件转师傅
第 6 步  走七步保养动作：断用、清灰、干擦、分区处理、控湿、复位、复检
第 7 步  建立周期：把容易出问题的部位列入定期检查清单
```

## 三、第 1 步：先判材质（判错就全错）

| 材质 | 识别特征 | 一句话定性 |
|---|---|---|
| 实木 | 断面有连续木纹，摸上去有木质纹理；背面常可见木蜡油或涂装 | 怕干怕潮，怕烫怕重压 |
| 板式（人造板） | 断面是均匀颗粒或层状；封边整齐；背面多为贴皮或素板 | 怕水泡，怕重压，防潮是第一位 |
| 软包（布艺） | 表层织物，能闻到织物味，接缝处有拉链或缝线 | 怕油污、怕潮、怕不晾干 |
| 皮革 | 表面有天然或人造皮纹，边角能看到断面层次 | 怕油、怕暴晒、怕干裂 |
| 金属 | 冷感、导热、可磁吸（钢制）或不导磁（铝制） | 怕潮腐蚀、怕酸碱、怕刮擦 |
| 玻璃 | 透明或有磨砂面；触碰冰凉；边角易崩 | 怕磕碰、怕骤冷骤热 |
| 藤编 | 编织纹理，可见编织走向与结点 | 怕断裂、怕干燥、怕重压 |
| 大理石（天然石） | 天然纹理，硬度较高，滴醋会缓慢起泡 | 怕酸、怕磕边、怕重物撞击 |

**判不出来的处理方式**：不要上化学清洁剂，先用**微湿拧干的软布**擦一次，观察有无变色与残留反应，再决定下一步。

## 四、八类材质的禁忌与手法对照

| 材质 | 主要禁忌 | 可以做 | 不可以做 |
|---|---|---|---|
| 实木 | 暴晒、水泡、暖气直吹、硬物刮擦、骤冷骤热 | 微湿软布顺纹擦拭，立刻擦干；按说明书周期上养护油 | 用水冲洗、酒精喷洒、砂纸打磨后不上油 |
| 板式 | 长期受潮、边缘泡水、超重堆压 | 干布擦拭；封边处单独检查；边角受潮立即擦干 | 湿布长时间覆盖、蒸汽拖把反复靠近、堆重物 |
| 软包 | 油污渗入、暴晒、沙发套不拆洗、坐塌后继续用力 | 定期吸尘；局部用中性清洁剂轻擦；拆洗布套 | 用力揉搓、暴晒直烤、不拆布套整体喷洗 |
| 皮革 | 油、酒精、强碱、暴晒、干裂后强行揉搓 | 干布除尘；按说明书用皮革护理剂小面积试用 | 皮油随意涂抹、酒精擦色斑、龟裂处大力按摩 |
| 金属 | 潮湿、酸碱、硬物刮擦、不同金属直接接触 | 干布擦拭；锈点轻者用中性除锈；补漆前先除锈 | 钢丝球大力擦、酸性清洁剂除锈、不同金属直接贴放 |
| 玻璃 | 磕碰、骤冷骤热、硬物刮擦 | 软布配中性清洁剂；使用固定频率减少水垢积累 | 用瓷砖清洁剂的强碱性配方、硬质刮水板 |
| 藤编 | 断裂、重压、长期干燥、沾水后暴晒 | 软毛刷除尘；微湿布后阴干；断裂处及时绑定 | 水洗、重压、局部受潮后暴晒 |
| 大理石 | **酸性液体**、重物磕边、油污渗入 | 中性清洁剂；渗油后用吸附材料敷在表面 | **滴醋或用酸性清洁剂**、钢丝球、案板直接放锅具 |

> 材质识别与损伤判定口径的完整版在 `rules/material_care_rules.md`。**大理石遇酸会永久失去光泽并被腐蚀**，这一条不能记错。

## 五、七类常见损伤：类型与成因

| 损伤 | 外观 | 最可能成因 | DIY 可能性 |
|---|---|---|---|
| 划痕 | 线性浅槽，木质常见于顺纹方向 | 硬物直接接触、金属家具表面粉尘摩擦 | 浅表可 DIY，深及底漆转师傅 |
| 开裂 | 线性裂缝，木质多顺纹；可能贯穿 | 木材干缩、长期暴晒或过度干燥 | 小面积非贯穿可处理，贯穿转师傅 |
| 变形 | 板面翘曲、门板不贴合、桌面不平 | 受潮后反复干湿、板件未留伸缩余量 | 已变形无法自己恢复，转师傅 |
| 掉色 | 表面颜色变浅或局部斑驳 | 紫外线老化、清洁剂腐蚀、涂层磨损 | 补色或翻新属专业作业 |
| 发霉 | 表面霉斑、织物霉点、底板霉味 | 长期潮湿、不通风、皮革或布套受潮 | 表层可处理，基材霉变转师傅 |
| 五金松动 | 铰链、合页、滑轨晃动或脱落 | 长期受力、螺丝滑牙、木材干缩 | 紧固螺丝可 DIY，滑牙需换件转师傅 |
| 塌陷 | 沙发坐下去不回弹、床垫凹陷 | 弹簧失效、海绵老化、结构疲劳 | 属结构件，转师傅更换 |

## 六、五类日常隐性伤害（这一节比清洁更重要）

**这些伤害都是慢慢发生的，出问题时已经不可逆。**

| 伤害 | 表现机制 | 摆放与使用建议 |
|---|---|---|
| 暴晒 | 涂层与木质加速老化、皮革干裂、布料褪色 | 避开南向与西向直射窗；用窗帘或百叶过滤直射光 |
| 潮湿 | 木质吸胀变形、板材起皮、金属锈蚀、布料起霉 | 离外墙至少留出距离；梅雨季与北方供暖季重点控湿 |
| 重压 | 板件下弯、抽屉导轨变形、沙发塌陷、藤编断裂 | 顶柜重物下移；沙发与床不要长期堆重物 |
| 锐物 | 划伤涂层、戳破皮革、崩玻璃边 | 台面上不放剪刀钥匙；玻璃与大理石面上不放硬边器物 |
| 热源 | 木质开裂、涂层起泡、玻璃炸裂、皮革收缩 | 不贴近暖气片、地暖出风口、灶台；不放过烫杯具 |

## 七、红木与仿红木：处理方式完全不同

这是最容易被搞混的一块，**给假红木上红木养护油是最常见的伤害**。

| 项目 | 红木（实木） | 仿红木（贴皮、染色、仿木纹板材） |
|---|---|---|
| 结构 | 整块实木，可见连续木纹与端面 | 板件或贴皮，断面可见胶层或基材 |
| 表面处理 | 已有漆面或蜡面，需按原有工艺养护 | 常为染色或覆膜，本身无漆可养 |
| 能不能上蜡 | 按原有工艺与说明书决定 | **不要直接上红木蜡或木蜡油**，会在贴皮膜层上发花、变色 |
| 日常处理 | 顺纹微湿擦拭后立刻擦干 | 干布擦拭；局部受损只能由厂家翻新 |
| 判断方法 | 背面、边角、抽屉底板能看到实木断面 | 封边处、端面能看到胶线或不同基材 |

**判断方法**：看**背板、抽屉底板、边角断面**。这三处最能暴露真实结构。只看门面板容易被贴皮骗过。

## 八、搬运与移位

| 情形 | 能不能自己搬 | 注意 |
|---|---|---|
| 单人可抬起的小件（凳子、小柜） | ✅ | 抬腿不拖地；先卸掉抽屉与层板 |
| 两人抬的普通衣柜 | ✅ | 先拍照记录拆装顺序；柜门拆下单独搬；底部加护角 |
| 实木大件、超过两人抬 | ⚠️ | 先评估楼梯转角与门洞尺寸，宁可多拆一次 |
| 挂墙柜、吊柜 | ❌ | 高处与承重作业，转师傅 |
| 带玻璃门的柜 | ⚠️ | 玻璃门单独包好竖立运输，平放易碎 |
| 整体过大的柜体需转 90 度过道 | ⚠️ | 先量通道最窄处，再决定是否拆装 |

**搬前的固定动作**：卸掉所有活动件（抽屉、层板、柜门、玻璃门），用气泡膜或旧毯包裹边角，螺丝装进袋并贴在柜体上标注位置，拍照留档。

> 脚本是关键词匹配，**不等于现场判断**。材质识别以翻看背面与断面为准。

## 十一、最常见的坑

**坑一：一种清洁剂刷全屋家具。**
布艺、皮革、木质、大理石对同一款清洁剂的反应完全不同。这一条是家具受损最主要的来源。

**坑二：给仿红木上红木蜡。**
贴皮或染色件表面是覆膜层，红木蜡或木蜡油上去会发花、变色，而且很难恢复。先看断面。

**坑三：给大理石滴醋测酸碱。**
网上常见的"鉴别大理石"方法会直接造成永久腐蚀。用**不显眼处**的中性擦拭观察替代滴液实验；确需鉴别请专业人员检测。

**坑四：沙发布套不拆洗，直接喷清洁剂。**
液体顺着布面渗进海绵，无法从内部烘干，结果是异味与霉菌更严重。必须拆洗布套。

**坑五：皮沙发起皮用凡士林或皮革油直接涂。**
起壳、龟裂属于材料老化，涂油脂封闭后更易发黑发霉。轻微表面干燥用护理剂，龟裂贯穿应转师傅。

**坑六：受潮的柜体立刻关严门。**
潮湿环境关门会闷住水汽，让变形与霉变加重。应开门通风、擦干、再逐步关闭。

**坑七：把"隐性伤害"当小事。**
暴晒、潮湿、重压、锐物、热源五项，单独看都不严重，累积起来就是不可逆的老化。

**坑八：抽屉滑轨卡住就猛拽。**
多数是导轨与滑块磨损或杂物阻挡。清理归位后再判断，滑牙或脱落需换件转师傅。

**坑九：藤编断裂后用胶粘。**
编织结构受力已断，粘上只是短暂。应停止使用并绑定固定，转专业修复。

**坑十：搬柜子不卸抽屉。**
抽屉与层板是搬运中最先飞出、最先造成家具或人受伤的部件。搬前必卸。

## 十二、边界与免责

- 本技能**不替代**木工、沙发厂、皮具工、石材养护等专业作业
- 家具材质、结构与工艺差异很大，**以现场实际情况与厂家说明书为准**
- 涉及承载安全、结构件、老家具保值的判断，请交由专业人员
- 清洁剂与护理用品的适用范围以产品说明书为准，不同产品不可混用
- 涉及家具消费纠纷与售后责任的，按**商家售后约定与相关主管部门要求**办理
