# 家具材质保养规则表

生成保养方案或处理建议前先读本文件，不要凭印象写。

---

## 一、八类材质识别特征

| 材质 | 识别特征 | 判定要点 |
|---|---|---|
| 实木 | 断面有连续木纹；摸上去有木质纹理；背面常见涂装 | 以背板、抽屉底板、边角断面为准 |
| 板式（人造板） | 断面均匀颗粒或层状；封边整齐；背面贴皮或素板 | 封边处能看到基材与胶线 |
| 软包（布艺） | 表层织物；接缝有拉链或缝线；有织物气味 | 看是否能拆洗布套 |
| 皮革 | 表面有天然或人造皮纹；边角可见断面层次 | 人造革与真皮护理方式不同 |
| 金属 | 冷感、导热；钢制可磁吸，铝制不导磁 | 区分钢、铝、不锈钢、有色金属 |
| 玻璃 | 透明或磨砂面；触碰冰凉；边角易崩 | 磨砂玻璃与光面玻璃清洁方式不同 |
| 藤编 | 编织纹理；可见编织走向与结点 | 真藤与仿藤材质不同 |
| 大理石（天然石） | 天然纹理；硬度较高；边角可能有崩缺 | 与人造石、岩板区分对待 |

**判不出来时的处理**：不要上化学清洁剂。先用微湿拧干的软布擦一次，观察有无变色与残留反应，再决定下一步。

## 二、禁忌与手法对照

| 材质 | 主要禁忌 | 可以做 | 不可以做 |
|---|---|---|---|
| 实木 | 暴晒、水泡、暖气直吹、硬物刮擦、骤冷骤热 | 微湿软布顺纹擦拭后立刻擦干；按说明书周期使用养护油 | 用水冲洗、酒精喷洒、打磨后不上油 |
| 板式 | 长期受潮、边缘泡水、超重堆压 | 干布擦拭；检查封边；边角受潮立即擦干 | 湿布长时间覆盖、蒸汽拖把反复靠近、堆重物 |
| 软包 | 油污渗入、暴晒、不拆洗、坐塌后用力 | 定期吸尘；局部中性清洁剂轻擦；拆洗布套 | 用力揉搓、暴晒直烤、整体喷洗不拆套 |
| 皮革 | 油、酒精、强碱、暴晒、干裂后揉搓 | 干布除尘；护理剂小面积试用 | 皮油随意涂抹、酒精擦色斑、龟裂处按摩 |
| 金属 | 潮湿、酸碱、硬物刮擦、不同金属直接接触 | 干布擦拭；轻锈点用中性除锈；补漆前除锈 | 钢丝球大力擦、酸性除锈、不同金属贴放 |
| 玻璃 | 磕碰、骤冷骤热、硬物刮擦 | 软布配中性清洁剂；固定频率减少水垢 | 强碱性配方、硬质刮水板 |
| 藤编 | 断裂、重压、干燥、沾水后暴晒 | 软毛刷除尘；微湿布后阴干；断裂处及时绑定 | 水洗、重压、局部受潮后暴晒 |
| 大理石 | 酸性液体、重物磕边、油污渗入 | 中性清洁剂；渗油后用吸附材料敷表面 | **酸性清洁剂**、钢丝球、锅具直接放置 |

## 三、七类损伤：类型、成因与归属

| 损伤 | 外观 | 最可能成因 | DIY 归属 |
|---|---|---|---|
| 划痕 | 线性浅槽，木质顺纹 | 硬物直接接触、金属表面粉尘摩擦 | 浅表可DIY；深及底漆转师傅 |
| 开裂 | 线性裂缝；可能贯穿 | 木材干缩、长期暴晒、过度干燥 | 非贯穿小面积可处理；贯穿转师傅 |
| 变形 | 板面翘曲、门板不贴合 | 受潮反复干湿、板件未留伸缩余量 | 已变形无法自行恢复，转师傅 |
| 掉色 | 颜色变浅或局部斑驳 | 紫外线老化、清洁剂腐蚀、涂层磨损 | 补色与翻新属专业作业 |
| 发霉 | 表面霉斑、织物霉点、底板霉味 | 长期潮湿、不通风、布套或皮革受潮 | 表层可处理；基材霉变转师傅 |
| 五金松动 | 铰链、合页、滑轨晃动脱落 | 长期受力、螺丝滑牙、木材干缩 | 紧固可DIY；滑牙需换件转师傅 |
| 塌陷 | 坐下去不回弹、床垫凹陷 | 弹簧失效、海绵老化、结构疲劳 | 结构件，转师傅更换 |

## 四、五类日常隐性伤害

| 伤害 | 表现机制 | 摆放与使用建议 |
|---|---|---|
| 暴晒 | 涂层与木质加速老化、皮革干裂、布料褪色 | 避开南向与西向直射窗；用窗帘或百叶过滤 |
| 潮湿 | 木质吸胀变形、板材起皮、金属锈蚀、布料起霉 | 离外墙留出距离；梅雨季与供暖季重点控湿 |
| 重压 | 板件下弯、导轨变形、沙发塌陷、藤编断裂 | 顶柜重物下移；床与沙发不长期堆重物 |
| 锐物 | 划伤涂层、戳破皮革、崩玻璃边 | 台面不放剪刀钥匙；玻璃与石面不放硬边器物 |
| 热源 | 木质开裂、涂层起泡、玻璃炸裂、皮革收缩 | 不贴近暖气、地暖出风口、灶台；不放烫杯具 |

## 五、红木与仿红木处理差异

| 项目 | 红木（实木） | 仿红木（贴皮、染色、仿木纹板材） |
|---|---|---|
| 结构 | 整块实木，连续木纹，端面可见实木 | 板件或贴皮，端面可见胶层或基材 |
| 表面处理 | 已有漆面或蜡面，按原工艺养护 | 常为染色或覆膜，本身无漆可养 |
| 能否上蜡 | 按原有工艺与说明书决定 | **不要直接上红木蜡或木蜡油**，会在膜层发花变色 |
| 日常处理 | 顺纹微湿擦拭后立刻擦干 | 干布擦拭；局部受损由厂家翻新 |
| 判断方法 | 背面、边角、抽屉底板可见实木断面 | 封边处、端面可见胶线或不同基材 |

**判断口诀**：看背板、抽屉底板、边角断面。这三处最能暴露真实结构，只看门面板容易被贴皮骗过。

## 六、必须转师傅的六种情况

1. 结构松动：摇晃、榫接脱开、受力件开裂
2. 五金失效：铰链滑牙、合页断裂、滑轨脱落
3. 大理石崩边或断裂，特别是带角位置崩掉或贯穿裂
4. 皮革开裂：贯穿裂缝、表皮大面积起壳剥落
5. 软包塌陷：弹簧失效、海绵老化，坐下不回弹
6. 承重安全的柜体、书架、床架变形

另加一条：**价值较高、需要保值的老家具**，尤其是木质与皮具。

## 七、搬运与移位

| 情形 | 能否自行搬运 | 注意 |
|---|---|---|
| 单人可抬起的小件 | 可以 | 抬腿不拖地；先卸抽屉与层板 |
| 两人抬的普通衣柜 | 可以 | 拍照记录拆装顺序；柜门拆下单独搬；底部加护角 |
| 实木大件 | 谨慎 | 先评估楼梯转角与门洞尺寸 |
| 挂墙柜、吊柜 | 不可以 | 高处与承重作业，转师傅 |
| 带玻璃门的柜 | 谨慎 | 玻璃门单独包好竖立运输 |
| 需转 90 度过道的大柜体 | 谨慎 | 先量通道最窄处再决定是否拆装 |

**搬前固定动作**：卸掉所有活动件；边角用气泡膜或旧毯包裹；螺丝装袋并贴在柜体上标注位置；拍照留档。

## 八、日常保养周期建议

| 周期 | 动作 |
|---|---|
| 每周 | 软包、金属件干布除尘 |
| 每月 | 检查板件封边与柜体受潮情况；检查五金是否松动 |
| 每季 | 检查靠窗家具的暴晒情况；藤编家具除尘；玻璃与石面台面清理水垢 |
| 梅雨季前 | 重点检查靠外墙、靠地面的家具受潮情况；提前准备除湿 |
| 供暖季 | 检查暖气附近的木质家具是否开裂；保持适度通风 |
| 每年 | 实木家具按说明书使用养护油；全面检查五金与结构 |

## 九、常见误判清单

1. 一种清洁剂刷全屋家具——材质反应完全不同
2. 给仿红木上红木蜡——覆膜层发花变色
3. 给大理石滴液测酸碱——造成永久腐蚀
4. 沙发布套不拆洗直接喷清洁剂——渗入海绵无法烘干
5. 皮沙发起皮涂油脂——封闭后更易发黑发霉
6. 受潮柜体立刻关门——水汽闷住，加重变形与霉变
7. 忽视暴晒潮湿重压锐物热源五项隐性伤害
8. 抽屉卡住猛拽——多为导轨磨损或杂物阻挡
9. 藤编断裂用胶粘——受力已断，只是短暂
10. 搬柜子不卸抽屉——最先飞出且最易造成伤害
