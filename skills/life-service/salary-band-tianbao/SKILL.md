# 薪酬带宽设计（salary-band）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据薪酬体系设计方法，生成薪酬带宽清单：职级序列、带宽宽度（中位值±%）、级差、市场分位对标、重叠度、晋升路径。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 薪酬带宽
- 薪酬体系
- 职级薪酬
- 宽带薪酬
- 薪酬中位值

## 三、工作流
1. 搭建职级序列与薪等
2. 设定带宽宽度（中位值±%）
3. 确定相邻级差与重叠度
4. 对接市场分位（P50/P75）
5. 明确晋升调薪规则

## 四、核心内容（检查清单与判定）
薪酬带宽是职级薪酬的区间范围，通常以中位值为基准设±宽度；合理级差与适度重叠可兼顾激励与成本控制，并支撑晋升调薪。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含职级序列与薪等 | 职级 |
| Q2 | FAIL | 未含带宽宽度（中位值±%） | 带宽 |
| Q3 | WARN | 未含级差与重叠度 | 级差 |
| Q4 | FAIL | 未含市场分位对标（P50/P75） | 对标 |
| Q5 | WARN | 未含晋升调薪路径 | 晋升 |

> 脚本 `salary-band_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python salary-band_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python salary-band_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项

- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
