# 银行理财净值与风险等级规则库

> 本规则库按理财产品常见披露结构整理。**业绩比较基准不是承诺收益**；净值型理财**不承诺保本**；风险等级与适当性要求**以现行规定和金融监管部门口径为准**；产品信息以产品说明书与销售机构披露为准。本库不预测净值走势，不推荐产品。

---

## 一、类型与口径区分

### 1.1 核心概念对照

| 概念 | 定义 | 是否承诺 |
|---|---|---|
| **净值型理财** | 净值随所投资产价格波动，投资者按净值申购赎回 | **不承诺保本** |
| **业绩比较基准** | 用于展示业绩的**参照标准**，通常是区间或数值 | **不是承诺收益** |
| **预期收益 / 业绩比较基准区间** | 通常标注「非业绩承诺」「不代表实际收益」 | **不是承诺** |
| **实际收益** | 按实际净值涨跌计算的结果 | 事后结果，非事先承诺 |
| **收益率（年化）** | 按持有期收益折算的年化值 | 区间值，随净值变化 |

### 1.2 表述纪律

**必须写清的两句话**：

1. **业绩比较基准不是承诺收益，只是比较对象。**
2. **净值型理财的净值会波动，波动方向和幅度都不预先确定。**

**禁止写法**：

| 禁止 | 正确替代 |
|---|---|
| 「业绩比较基准 3%，所以能赚 3%」 | 「业绩比较基准 3% 是参照标准，不是承诺收益」 |
| 「预期收益率 3%」 | 「业绩比较基准 3%，非业绩承诺」 |
| 「这是保本理财」 | 「净值型理财不承诺保本」 |
| 「历史净值很稳」 | 「历史区间波动较小，但不代表未来不会跌破」 |

### 1.3 常见产品类型

| 类型 | 净值特征 | 核查重点 |
|---|---|---|
| 固定收益类 | 净值波动较小，但仍会随市场变化 | 是否净值化、是否承诺型、赎回规则 |
| 权益类 | 净值波动明显，与权益市场相关 | 风险等级、回撤幅度、持有期要求 |
| 混合类 | 波动介于两者之间 | 资产配置比例、风险等级 |
| 结构性理财 | 含衍生品条款，收益与观察挂钩 | 是否保本、收益条件是否写进合同 |

**不得因为类型名含「稳」「固收」「安心」就判断为保本**。名称不是条款。

## 二、R1 到 R5 风险等级

### 2.1 逐级定义与适配人群

| 等级 | 风险属性定位 | 波动特征 | 可承受风险人群（描述口径） |
|---|---|---|---|
| **R1** | 低风险 | 本金损失概率极低、波动很小 | **能接受本金基本不受影响、对短期净值小幅波动不敏感**的人 |
| **R2** | 中低风险 | 本金损失概率较低、波动较小 | **能接受本金有小幅波动、整体期望为正**的人 |
| **R3** | 中风险 | 本金损失与波动均不可忽视 | **能接受净值阶段性下跌、也可能在持有期内承受账面亏损**的人 |
| **R4** | 中高风险 | 本金损失概率与波动幅度明显 | **能接受较大净值回撤、且短期不一定会回到成本**的人 |
| **R5** | 高风险 | 本金损失与大幅波动均属常见 | **能接受本金大幅损失甚至可能损失全部本金**的人 |

### 2.2 三条必读说明

1. **风险等级不是收益高低排序**。R5 不等于收益更高，只等于风险更高。
2. **「适合」描述的是风险承受能力，不是收益期望**。能承受低风险的人，不会因为高等级产品收益高而更适合。
3. **能否购买取决于适当性匹配**：投资者风险承受能力需与产品风险等级匹配，**以销售机构实际测评结果与现行监管口径为准**。

### 2.3 适当性管理要点

| 项目 | 口径 |
|---|---|
| 风险测评 | 由销售机构按**现行规定和金融监管部门口径**进行，**以销售机构实际测评结果为准** |
| 匹配规则 | 投资者等级需与产品等级匹配才可购买 |
| 重新测评 | 收入、家庭状况、负债变化后可申请重新测评 |
| 严禁误导 | **不得建议编造测评答案以获得更高等级**，不得虚构测评结果 |

## 三、净值与回撤测算口径

### 3.1 公式

```
单期收益率     r_t = NAV_t / NAV_{t-1} − 1
持有期收益率   R   = NAV_末 / NAV_初 − 1
最大回撤       MDD = max over t of ( peak_t − NAV_t ) / peak_t
                其中 peak_t 为截至 t 的历史最高净值
周期波动率     σ_p = std(r_1, r_2, ..., r_N)
年化波动率     σ_a = σ_p × sqrt(每年周期数)
```

| 项目 | 口径 |
|---|---|
| 净值来源 | **必须取自已披露的历史净值**；**不得用业绩比较基准倒推净值** |
| 周期数 | 波动率必须说明**取了多少个周期、周期是什么**（日/周/月），否则数字无意义 |
| 回撤区间 | 必须用**峰值到谷值**，不得随意挑选区间 |
| 年化因子 | 日频常用 252，周频 52，月频 12；须在结论中写明所用因子 |

### 3.2 结果表述纪律

| 可以写 | 不能写 |
|---|---|
| 「历史区间最大回撤为 X%」 | 「最大回撤就是 X%」 |
| 「历史区间年化波动率为 X%」 | 「年化波动率 X%，所以安全」 |
| 「按已披露净值测算」 | 「该产品收益率为 X%」（未来口径） |

**必写一句**：「历史区间波动**不代表未来波动上限**。」

## 四、赎回与到账规则

| 规则 | 含义 | 必须核对 |
|---|---|---|
| **T+0** | 当日申请赎回，当日到账 | 具体到账时点、单日限额 |
| **T+1** | 当日申请赎回，次一工作日到账 | 是否遇节假日顺延 |
| **T+n** | n 个工作日后到账 | 封闭期产品常见 |
| 巨额赎回 | 超过约定比例的申购/赎回可暂停或延期 | 触发比例与处理方式 |
| 封闭期 | 约定期限内不可赎回 | 到期开放日 |
| 申购起点 | 单笔最低金额、是否可追加 | 说明书载明 |
| 费用 | 申购费、赎回费、管理费、超额业绩报酬 | 说明书与合同载明 |

**关键提醒**：**T+0 不等于当天实时无风险**。当日赎回按**当日净值**确认，而当日净值可能已经下跌。**资金到账快不代表净值不跌。**

## 五、破净定性

```
净值 < 初始净值（通常 1.0000）  →  处于破净状态
破净幅度 = (初始净值 − 当前净值) / 初始净值 × 100%
```

| 必须写清 | 必须避免 |
|---|---|
| 破净表示**单位净值低于初始净值**，即账面处于浮亏 | 破净表示**本金已确定损失** |
| 破净幅度是**比例**，不是**金额** | 破净幅度等于实际亏损金额 |
| 破净可能源于市场波动，也可能源于**估值调整** | 破净必然是市场下跌造成的 |
| 损失以**赎回时实际确认的净值为准** | 未来一定能涨回初始净值 |
| 破净不改变产品风险等级 | 破净后产品会自动升级为低风险 |

**四类绝对禁止表述**：

- 「破净＝本金没了」
- 「破净＝一定会亏」
- 「破净＝银行不认了」
- 「不破净＝绝对安全」

## 六、防误伤（否定词）清单

| 见到这些情况 | 必须这样判 | 严禁这样写 |
|---|---|---|
| 业绩比较基准 3% | 判为**参照标准，非承诺收益** | 「收益 3%」 |
| 产品净值当前 < 1 | 判为**处于破净状态，账面浮亏** | 「本金已损失」 |
| 产品净值当前 ≥ 1 | 判为**未破净，但不等于安全** | 「本金安全」 |
| 历史最大回撤 X% | 判为**历史区间值，非未来上限** | 「最多跌 X%」 |
| 未赎回、账面浮亏 | 判为**浮亏，未实现** | 「已经亏了这么多」 |
| 已赎回确认亏损 | 判为**已实现损失，以确认净值为准** | 写成「浮亏」 |
| 风险等级 R4 | 判为**中高风险，非收益排序** | 「收益更高」 |
| 未做风险测评 | 判为**适当性未核，不得代为判断** | 建议编造答案 |
| 「保本」「稳赚」「一定不亏」 | 判为**违规表述，不采用** | 照抄进结论 |
| 「T+0 赎回很安全」 | 判为**到账快但按当日净值确认，仍有波动** | 「当天赎回就锁定收益」 |
| 数据非官方披露 | 判为**数据来源待核实** | 直接用于最终结论 |

## 七、免责

本规则库为投资实践整理，**不构成投资建议、金融代理或法律意见**。**业绩比较基准不是承诺收益**；净值型理财**不承诺保本**；风险等级与适当性要求**以现行规定和金融监管部门口径为准**；产品类型、风险等级、赎回规则与费用**以产品说明书与销售机构披露为准**；净值与回撤测算基于**已披露的历史数据**，**不代表未来波动上限**。不预测净值走势，不推荐具体产品，**以现行规定和金融监管部门口径为准**。
