# 银行理财净值波动与风险等级核查

买银行理财最容易搞混的两件事：**「业绩比较基准」不是承诺收益**，**「破净」不等于本金没了**。这两条搞反，决策就会整个反过来。

这个技能做五件事：**分类型 → 认等级 → 算波动 → 核赎回 → 破净定性**。

---

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 区分净值型与业绩比较基准的口径 | 承诺收益、承诺保本、承诺「不会跌」 |
| 逐级说明 R1 到 R5 风险等级与适配人群 | 推荐具体银行、具体产品、具体经理 |
| 按历史净值测算最大回撤、波动区间、持有期收益 | 预测未来收益率或未来净值走势 |
| 核对赎回规则与到账时间口径 | 代替销售机构作风险测评或适当性判断 |
| 提示破净不等于本金安全的口径 | 断言「已经本金损失」或「绝对安全」 |
| 提示业绩比较基准不是承诺收益 | 把业绩比较基准说成收益承诺或收益率 |

涉及以下情形，应停下来交由销售机构、理财顾问或金融监管渠道处理：**产品已发生兑付风险提示、投资者适当性评估争议、产品说明书与实际披露不一致的投诉、金融消费者权益争议处理**。

**绝对不做**：**不承诺收益、不承诺保本**。业绩比较基准**不是承诺收益**；风险等级与适当性要求**以现行规定和金融监管部门口径为准**。

## 四、核心口径（必须分清）

### 4.1 净值型 vs 业绩比较基准（最核心的一条）

| 概念 | 定义 | 是不是承诺 |
|---|---|---|
| **净值型理财** | 产品净值随所投资产价格波动而变动，**不承诺本金不变**，投资者按净值申购赎回 | **不承诺保本** |
| **业绩比较基准** | 产品说明书或销售页面用于展示业绩的**参照标准**，通常是一个区间或数值 | **不是承诺收益**，只是比较对象 |
| **预期收益率 / 业绩比较基准区间** | 通常标注为「非业绩承诺」「不代表实际收益」 | **不是承诺** |
| **实际收益率** | 按实际净值涨跌计算的结果 | 事后结果，不是事先承诺 |

**必须写清的两句话**：

1. **业绩比较基准不是承诺收益，只是比较对象。**
2. **净值型理财的净值会波动，波动方向和幅度都不预先确定。**

**绝对禁止**：把业绩比较基准写成「预期收益」「保本收益」「收益率 X%」。

### 4.2 R1 到 R5 风险等级（逐级说明）

风险等级由产品本身的风险属性决定；投资者能否购买，取决于**风险测评结果与等级是否匹配**，**以现行规定和金融监管部门口径为准**。

| 等级 | 风险属性定位 | 大致对应 | 对应的可承受风险人群（描述口径） |
|---|---|---|---|
| **R1** | 低风险 | 本金损失概率极低、波动很小 | **能接受本金基本不受影响、对短期净值小幅波动不敏感**的人 |
| **R2** | 中低风险 | 本金损失概率较低、波动较小 | **能接受本金有小幅波动、但整体期望为正**的人 |
| **R3** | 中风险 | 本金损失与波动均不可忽视 | **能接受净值阶段性下跌、也可能在持有期内承受账面亏损**的人 |
| **R4** | 中高风险 | 本金损失概率与波动幅度明显 | **能接受较大净值回撤、且短期不一定会回到成本**的人 |
| **R5** | 高风险 | 本金损失与大幅波动均属常见 | **能接受本金大幅损失甚至可能损失全部本金**的人 |

**必须说明的三点**：

- 风险等级**不是收益高低排序**，高等级不等于收益更高，只等于风险更高
- 「适合」描述的是**风险承受能力**，不是「收益期望」；能承受低风险的人不会因为 R5 收益高而更适合
- 等级与投资者是否匹配，**以销售机构的适当性管理要求为准**；**不得建议通过虚假测评获得更高等级**

### 4.3 净值与回撤测算口径

```
单期收益率 r_t = NAV_t / NAV_{t-1} − 1

持有期收益率 R = NAV_末 / NAV_初 − 1

最大回撤 MDD = max_t [ (峰值 NAV 截至 t 的峰值) − NAV_t ] / 该峰值
更易算的等价式：MDD = max over t of ( peak_t − NAV_t ) / peak_t

年化波动率（按 N 个周期）：
  周期收益率标准差 σ_p = std(r_1, r_2, ..., r_N)
  年化波动率 = σ_p × sqrt(每年周期数)
```

| 项目 | 口径 |
|---|---|
| 净值口径 | 申购赎回按**披露净值**计算，**不是**按业绩比较基准计算 |
| 回撤 | 用**峰值到谷值**的最长一段计算，不是随便挑一段 |
| 波动率 | 必须说明**取了多少个周期、周期是什么**（日/周/月），否则数字没有意义 |
| 数据来源 | **必须使用已披露的历史净值数据**；**不得用业绩比较基准倒推净值**；**不得预测未来净值** |

**表述纪律**：历史回撤与波动率**只描述已发生的区间**，**不是未来上限**。必须写「历史区间最大回撤为 X%，**不代表未来最大回撤不超过 X%**」。

### 4.4 赎回与到账规则（T+0 / T+1）

| 规则 | 含义 | 必须核对 |
|---|---|---|
| **T+0** | 当日申请赎回，当日到账 | 具体到账时点、是否有单日限额 |
| **T+1** | 当日申请赎回，次一工作日到账 | 是否遇节假日顺延 |
| **T+n** | n 个工作日后到账 | 封闭期产品常见 |
| 巨额赎回 | 超过产品约定比例的申购或赎回可暂停或延期 | 触发比例与处理方式 |
| 封闭期 | 约定期限内不可赎回 | 到期后才开放 |
| 申购起点与追加 | 单笔最低金额、是否可追加 | 产品说明书载明 |
| 费用 | 申购费、赎回费、管理费、超额业绩报酬 | 以说明书与合同为准 |

**必须说明**：**T+0 不等于当天实时无风险**。当天的赎回申请按**当日净值**确认，而当日净值可能已经下跌。资金到账快，不代表净值不跌。

### 4.5 破净的含义（最容易讲错的一条）

```
净值 < 1.0000  → 处于破净状态
```

| 必须写清 | 必须避免 |
|---|---|
| 破净表示**单位净值低于初始净值 1**，即账面处于浮亏 | 破净表示**本金已确定损失** |
| 破净幅度 = (1 − 当前净值) × 100% | 破净幅度 = 实际已亏金额 |
| 破净可能源于市场波动，也可能源于**估值调整** | 破净必然是市场下跌造成的 |
| 净值型产品的**损失以赎回时实际确认的净值为准** | 未来一定能涨回 1 |
| 破净后**风险等级不因此改变**，也不会自动升级 | 破-net 之后产品会自动升级为低风险 |

**绝对禁止**：「破净＝本金没了」「破净＝一定会亏」「破净＝银行不认了」「不破净＝绝对安全」这四类表述。

### 4.6 适当性与风险测评

| 项目 | 口径 |
|---|---|
| 风险测评 | 由销售机构按**现行规定和金融监管部门口径**进行，**以销售机构实际测评结果为准** |
| 匹配规则 | 投资者风险承受能力需与产品风险等级**匹配**才可购买 |
| 风险承受能力会变 | 收入、家庭状况、负债变化后**可以重新测评** |
| 不得误导 | **不得建议编造答案以获得更高等级**；**不得虚构测评结果** |

出结论前，**必须先读**：

- `rules/bank-wealth-rules.md`：净值型与业绩比较基准的口径区分、R1 到 R5 逐级定义与适配人群描述、净值与回撤计算公式、T+0/T+1 赎回规则、破净定性口径、适当性与防误伤清单。

## 六、脚本用法

```bash
python scripts/nav_risk_check.py --file case.json --out 理财风险核查.md
python scripts/nav_risk_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：净值序列（按日期升序）、初始净值、产品风险等级、赎回规则、持有天数等 |
| `--text` | 直接给 JSON 字符串 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检 |

输入 JSON 示例：

```json
{
  "navs": [1.0, 1.012, 0.998, 0.985, 1.005, 0.992, 0.978, 1.001],
  "initial_nav": 1.0,
  "risk_level": "R3",
  "redemption_rule": "T+1",
  "periods_per_year": 252
}
```

脚本输出：当前净值与破净幅度、持有期收益率、历史最大回撤、周期波动率与年化波动率、R1 到 R5 等级定位与适配人群提示、赎回规则要点、以及必须向销售机构确认的事项清单。

> 脚本按**你提供的历史净值数据**做**静态回溯测算**。历史波动**不代表未来波动上限**；业绩比较基准**不是承诺收益**；产品信息、风险等级与赎回规则**以产品说明书与销售机构披露为准**。脚本不预测未来净值，不给买卖指令，不推荐具体产品。

## 七、人工确认清单（这步不能省）

- [ ] 产品**类型**（净值型 / 固收类 / 混合类）已从说明书确认，不是听销售口述
- [ ] **业绩比较基准**已确认是参照标准，且已知悉它**不是承诺收益**
- [ ] **风险等级**已从产品页面确认（R1 到 R5），不是听销售说「这个挺稳」
- [ ] 本人**风险测评结果**已确认，且与产品等级匹配（**以销售机构测评结果为准**）
- [ ] 历史净值数据取自**官方披露渠道**，覆盖足够长的时间区间
- [ ] 算回撤时用的是**峰值到谷值**，不是随手挑一段
- [ ] 波动率说明了**取了多少个周期、周期是什么**
- [ ] **赎回规则与到账时间**已从说明书核对（T+0 / T+1 / 封闭期）
- [ ] 巨额赎回条款与暂停赎回情形已读
- [ ] 费用项（申购费、赎回费、管理费）已核对
- [ ] 结论中**没有出现「保证」「保本」「一定」**这类表述
- [ ] 若已破净，已确认破净的净值来源（市场波动 / 估值调整），**未直接等同于本金已损失**

## 八、最常见的坑

1. **把业绩比较基准当收益预期。** 业绩比较基准**只是比较对象，不是承诺收益**。看业绩比较基准选产品，等于拿一个参照尺去当尺子量自己有多高。
2. **把「不破净」当成本金安全。** 净值型产品**不承诺保本**。今天不破净，明天下跌就破净。**不破净≠安全，破净≠本金已确定损失。**
3. **风险等级看成收益排序。** R5 不是「收益更高」，只是「风险更高」。为了买 R5 去把测评做高，是把适当性管理当成障碍。
4. **用业绩比较基准倒推净值做回测。** 业绩比较基准是产品自己定的参照，不是净值历史。**用它倒推出来的回撤是假的**，会让你以为这只产品很稳。
5. **忽略赎回规则与到账时间。** 急用钱时才发现是 T+1 或封闭期，钱拿不出来，**只能被动持有**。**T+0 也不等于当天不跌**——当日赎回按当日净值确认，当日净值可能已经跌了。
6. **只用很短的一段净值算回撤。** 半年数据算出的最大回撤，往往远小于产品真实的风险区间。**回撤必须用峰值到谷值、覆盖完整周期**。
7. **把浮亏当成已实现损失，或反过来。** 净值型产品**以赎回时实际确认的净值为准**。浮亏数字天天变，但只有赎回确认后才最终落地。
8. **忽略巨额赎回与暂停赎回条款。** 某些产品在特定情形下可暂停赎回，这是流动性风险的一部分，**不在「风险等级」三个字里体现**。
9. **忽略费用项。** 申购费、赎回费、管理费会直接吃掉净值表现，**短持有期尤其明显**。
10. **拿历史最大回撤当未来上限。** 「历史最大回撤 3%」不等于「未来最多跌 3%」。**历史区间只描述已发生的区间。**
11. **资产新规后还用旧评级思维看所有产品。** 理财产品的分类、风险等级与适当性要求**以现行规定和金融监管部门口径为准**，凭几年前的记忆判断很容易错。

## 九、边界与免责

- 本技能用于理财产品条款与风险口径核查，**不构成投资建议、金融代理或法律意见**，不替代产品说明书、销售机构披露与适当性管理要求
- **业绩比较基准不是承诺收益**；净值型理财**不承诺保本**；实际收益以赎回时确认的净值为准
- **风险等级与适当性要求以现行规定和金融监管部门口径为准**；投资者风险测评结果**以销售机构实际测评为准**

- **破净不等于本金已确定损失**，浮亏以赎回确认的净值为准；本技能**不断言本金安全，也不断言本金已损失**
