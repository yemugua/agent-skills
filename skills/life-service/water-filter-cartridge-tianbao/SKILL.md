# 净水器滤芯选型与更换周期核查（water-filter-cartridge）

滤芯该不该换，**不能只看用了几个月**。同样的 PP 棉，一家三口和一家六口，寿命能差一倍。判断要同时看两个指标：**时间**和**累计净水量**，哪个先到算哪个。

这个技能做五件事：**选型号 → 算周期 → 定更换顺序 → 规范冲洗 → 查异常**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 按水质与用水量给出滤芯与通量选型口径 | ❌ 认定「换了滤芯一定安全」（还要看管路与储水） |
| 按时间与水量的双指标核算更换进度 | ❌ 检测微生物、重金属、农药残留等水质指标 |
| 给出更换、冲洗与验收的作业顺序 | ❌ 指导改动给水管路、打孔、改动电路 |
| 给出出水异常的排查顺序与停用标准 | ❌ 判断水质是否达到直饮标准（需专业检测） |

**遇到以下情况，立即停用并转交专业人员：**

- 机身、接头、储水桶渗水、漏水，或地柜内积水（**先断电再关水**）
- 漏水影响到楼下、地板、柜体，或可能接触到插座、电源线
- 需要改动给水管路、新增角阀、在台面或墙体打孔
- 需要新增或改动插座、线路，或机器内部有烧焦味、冒烟、跳闸
- 储水桶压力异常、桶体变形、接头崩开
- 进水压力异常（过高或过低）、有水锤声、管路震动
- 进水为自备井水、山泉水、不明水源，未做过水质检测

**饮用水卫生红线（这条最重要）：**

- 出水出现**浑浊、可见杂质、异味、异色** → **立即停止直饮，改煮沸后饮用**，并排查滤芯与管路
- 滤芯**超过额定周期或额定总净水量** → 视为失效，不要「再撑一阵」
- 长期不用（超过 3 天）后重新使用 → **放水 3-5 分钟**再取用；超过 7 天建议整箱换水或按说明书处理
- 更换滤芯后必须**充分冲洗**（RO 膜冲洗 20-30 分钟，活性炭滤芯冲洗 5-10 分钟），前几箱水不要直接喝
- 储水桶、滤芯外壳、接头等涉水部件，必须是**食品级材料**，不使用来历不明的替代品

**涉水作业前：先断电，再关进水阀。** 净水器通常带增压泵与电控板，带电操作湿区设备有触电风险。

## 二、完整工作流

```
第 1 步  过安全红线：出水是否浑浊异味、是否漏水漏电、是否超期
第 2 步  读规则文件 rules/filter_rules.md（类型对照 + 周期表 + 排查表）
第 3 步  算原水条件：TDS、硬度、余氯味、浑浊度、人数与日均用水量
第 4 步  选滤芯与通量：按水质选类型，按人数与用水量选通量
第 5 步  算更换进度：跑脚本，按时间与累计净水量双指标算寿命百分比
第 6 步  定更换顺序：按寿命百分比从高到低换，超期的先换
第 7 步  规范更换：断电 → 关进水阀 → 泄压 → 换芯 → 检查密封圈
第 8 步  冲洗与验收：充分冲洗 → 查漏 → 测 TDS → 前几箱水不直饮
第 9 步  记录：记下更换日期与净水量读数，作为下一次的基准
```

**顺序不能颠倒**：第 1 步的停用判断没做，后面算得再准也没意义。

## 三、滤芯类型对照（先搞清每级干什么）

| 级别 | 类型 | 作用 | 不能干什么 | 常规周期 |
|---|---|---|---|---|
| 一级 | PP 棉（5μm / 1μm） | 拦泥沙、铁锈、悬浮物 | 不能除余氯、不能除溶解性物质 | 3-6 个月 |
| 二级 | 颗粒活性炭 GAC | 吸附余氯、异味、部分有机物 | 不能除重金属、不能除菌 | 6-12 个月 |
| 三级 | 活性炭棒 CTO / 烧结炭 | 进一步吸附余氯、改善口感，兼过滤 | 同上 | 6-12 个月 |
| 四级 | RO 反渗透膜 | 去除溶解性盐类、重金属、大部分污染物 | 产水慢、有废水 | 24-36 个月 |
| 五级 | 后置活性炭 T33 | 改善口感、去除储水桶异味 | 只是口感 | 12 个月 |
| 同级 | 超滤 UF | 除浑浊、细菌、胶体，**保留矿物质** | **不能除重金属与水垢** | 12-24 个月 |
| 同级 | 软化树脂 | 降硬度、防水垢 | 不能直饮、需加盐再生 | 按说明 |

**关键认知**：超滤机**不能**降低 TDS，也不能除重金属和硝酸盐水垢；想除溶解性污染物，要看 RO 膜。

**RO 机的废水比**是正常的（一般 1:1 到 1:3，视机型与水温），不是故障；但废水比突然明显变大，通常是膜或泵的问题。

## 四、通量与桶的选型

| 家庭人数 | 建议通量 | 说明 |
|---|---|---|
| 1-2 人 | 400G | 日常饮用与做饭够用 |
| 3-4 人 | 600G | 接水等待时间可接受 |
| 5 人以上 / 用水量大 | 800G 及以上 | 多人连续取水不等待 |
| 有泡茶、煮汤、大量直饮需求 | 在上表基础上加一档 | 峰值流量更重要 |

| 有桶 vs 无桶 | 优点 | 缺点 | 适用 |
|---|---|---|---|
| 有桶（压力桶） | 出水快、停电能放水、泵负荷小 | 占空间、桶内需清洁、口感可能有桶味 | 空间够、追求稳定流量 |
| 无桶（大通量） | 省空间、即滤即饮 | 首杯水 TDS 可能偏高、对泵要求高 | 厨下空间紧张 |

**冬季水温低时 RO 产水量会明显下降**（水温每降 1℃，产水量约下降 2-3%），这是正常现象，不是膜坏了。

## 五、双指标核算（时间 + 水量）

更换周期按两个指标算，**取先到者**：

```
时间进度 = 已用天数 ÷ (额定月数 × 30) × 100%
水量进度 = 累计净水量 ÷ 额定总净水量 × 100%
寿命百分比 = max(时间进度, 水量进度)
```

**判定：**

| 寿命百分比 | 状态 | 处置 |
|---|---|---|
| < 70% | 正常 | 继续用，记录读数 |
| 70% - 100% | 关注 | 备好新滤芯，安排更换 |
| ≥ 100% | 超期 | **视为失效**，及时更换；超期期间不直饮 |

**为什么必须双指标**：一家六口用额定 12 个月的活性炭，可能 7 个月就把额定总净水量用完了；反过来，一人独居的 PP 棉可能水量远远没到，但时间到了也会滋生细菌。只按时间换、或只看出水流量，都会判断错。

---

## 六、RO 脱盐率（判断膜状态最实用的指标）

```
脱盐率 = (1 - 出水 TDS ÷ 进水 TDS) × 100%
```

| 脱盐率 | 判断 |
|---|---|
| ≥ 90% | 膜状态良好 |
| 85% - 90% | 开始衰减，关注 |
| < 85% | 建议更换 RO 膜（需先排除进水 TDS 变化与储水桶因素） |

**测 TDS 的正确姿势**：放水 1-2 分钟后再测（首杯水 TDS 偏高是正常现象）；同时测进水与出水，只看出水值没有意义。进水 TDS 本身会随季节与水源变化。

**TDS 低 ≠ 水安全**：TDS 只反映溶解性固体总量，不能反映微生物、有机物、农药残留等。**TDS 正常不代表可以直饮**，这是最常见的误解。

## 七、更换作业顺序（严格照做）

**工具与材料**：新滤芯（型号核对）、滤芯扳手、干净毛巾、水盆、食品级润滑硅脂（可选）、记号笔、TDS 笔。

1. **断电**：拔掉电源或断开机器供电（涉水作业必须先断电）
2. **关进水阀**：关闭进水球阀，打开龙头泄压
3. **铺毛巾、备水盆**：滤瓶内会残留水
4. **拆滤瓶**：用扳手逆时针旋开，注意别把密封圈弄丢
5. **倒掉残水、清洗滤瓶内壁**（换 PP 棉和活性炭时）
6. **装新滤芯**：注意方向（有胶圈的一端朝向按说明书），密封圈抹少量食品级硅脂并确认没有翻边、没有漏装
7. **旋回滤瓶**：手拧到位后再用扳手轻紧，**不要死拧**（拧裂滤瓶是常见事故）
8. **开阀、通电**：先开进水阀，检查接头是否渗漏，再通电
9. **冲洗**：RO 膜冲洗 20-30 分钟，活性炭滤芯冲洗 5-10 分钟；有桶机型第一桶水放掉不要喝
10. **验收**：查漏 30 分钟、测 TDS、确认出水无异味无杂质
11. **记录**：在滤瓶或机身上贴标签，记下更换日期与净水量读数

**旧滤芯处理**：PP 棉与活性炭按生活垃圾处理；RO 膜按当地垃圾分类要求处理，不要自行拆解。

## 八、脚本用法

```bash
python scripts/filter_change_calc.py --file filter.json --out 滤芯核查.md
python scripts/filter_change_calc.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：安装日期、今日日期、日均用水量、每级滤芯的额定周期与额定总净水量、上次更换日期、进水与出水 TDS |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检 |

输入 JSON 示例：

```json
{
  "install_date": "2024-03-01",
  "today": "2026-03-01",
  "people": 4,
  "daily_liters": 12,
  "tds_in": 260,
  "tds_out": 18,
  "cartridges": [
    {"name": "PP棉", "last_change": "2025-12-01", "rated_months": 6, "rated_liters": 3000},
    {"name": "前置活性炭", "last_change": "2025-09-01", "rated_months": 12, "rated_liters": 6000},
    {"name": "RO膜", "last_change": "2024-03-01", "rated_months": 24, "rated_liters": 12000},
    {"name": "后置活性炭", "last_change": "2025-09-01", "rated_months": 12, "rated_liters": 6000}
  ]
}
```

脚本输出：每级滤芯的已用天数、时间进度、水量进度、寿命百分比、剩余天数、状态与建议，按寿命百分比从高到低排出更换顺序；同时给出 RO 脱盐率与通量建议；命中超期或脱盐率过低时输出**停止直饮**提示。

> 脚本按你填的额定值计算，**额定周期与额定总净水量以产品说明书为准**；不同品牌差异很大，不要凭印象填。

## 九、人工确认清单（这步不能省）

- [ ] 出水是否浑浊、有异味、有可见杂质（有则停止直饮）
- [ ] 更换前已断电、已关进水阀、已泄压
- [ ] 新滤芯型号与原机规格核对过
- [ ] 密封圈已检查（未漏装、未翻边、未老化）
- [ ] 滤瓶未死拧，接头无渗漏（已观察 30 分钟）
- [ ] 已充分冲洗（RO 膜 20-30 分钟，活性炭 5-10 分钟）
- [ ] 前几箱水未直接饮用
- [ ] TDS 已测（进水与出水同时测，放水 1-2 分钟后测）
- [ ] 更换日期与净水量读数已记录

## 十、最常见的坑

**坑一：只看时间，不看水量。**
错误做法：说明书写 12 个月，就一年一换。正确做法：同时算时间进度与水量进度，取先到者。六口之家可能 7 个月就把额定总净水量用完了，此时活性炭已经失效。

**坑二：只看 TDS 判断能不能喝。**
错误做法：TDS 显示 15，就认为水很安全。正确做法：TDS 只反映溶解性固体总量，**不能反映微生物、有机物与农药残留**。TDS 正常不等于可以直饮。

**坑三：看到废水就以为机器坏了。**
错误做法：RO 机有废水，以为漏了或坏了。正确做法：RO 机排废水是原理决定的（一般 1:1 到 1:3），属正常；但废水比突然明显变大，才需要查膜或泵。

**坑四：换完滤芯直接接来喝。**
错误做法：换完立刻接一杯喝了。正确做法：RO 膜冲洗 20-30 分钟、活性炭冲洗 5-10 分钟，有桶机型第一桶水放掉。新炭有炭粉，不冲就喝会有黑水和异味。

**坑五：死拧滤瓶。**
错误做法：怕漏水，扳手使劲拧。正确做法：手拧到位后轻微加力即可，密封圈完好就不会漏；拧裂滤瓶是更换作业最常见的事故，一旦裂了只能整瓶更换。

**坑六：超期了觉得「出水还清亮就没事」。**
错误做法：滤芯超期半年，看水挺清就继续直饮。正确做法：活性炭失效后**肉眼不可见**，但吸附饱和后会成为细菌滋生的载体；超期即视为失效，及时更换，期间改煮沸饮用。

**坑七：长期不用，回来直接喝。**
错误做法：出差半个月回来，接一杯就喝。正确做法：超过 3 天未用，放水 3-5 分钟；超过 7 天按说明书处理或更换滤芯。静置水中的细菌增殖肉眼看不出来。

**坑八：漏电漏水了还先去擦水。**
错误做法：地柜积水，先拿抹布擦。正确做法：**先断电，再关进水阀**，然后才处理积水。净水器带泵与电控板，带电接触积水有触电风险。

**坑九：用超滤机指望除水垢和重金属。**
错误做法：以为装了净水器就什么都能滤。正确做法：超滤不能除溶解性盐类、不能降 TDS、不能除重金属与水垢；要除这些需要 RO 膜。买之前先搞清楚需求。

## 十一、边界与免责

- 本技能提供滤芯选型、周期核算与更换作业口径，**不检测水质，也不判定水质是否达到直饮标准**
- 水质是否安全，**以具备资质的检测机构按现行生活饮用水卫生标准的检测结果为准**
- 额定周期与额定总净水量**以产品说明书为准**，不同品牌差异很大
- 涉及管路改造、打孔、电路改动、桶体与泵的问题，**应交由专业人员处理**
- 出水浑浊、异味、异色或滤芯超期期间，**应停止直饮并改用煮沸水**
- 本技能不构成任何健康或医疗建议
