# 助听器选配与适应期核查

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 说明必须先做听力检查的必要性 | 判断听力损失类型、程度与病因并下结论 |
| 列出选型前应评估的六个维度 | 给出具体品牌、型号、价格区间推荐 |
| 给出验配五步流程框架 | 代替听力师或耳鼻喉科医生做验配 |
| 解释适应期常见现象与应对 | 承诺「用了就能听清」或给出改善幅度 |
| 列出必须先就医排查的警示信号 | 判断突发性耳聋、听神经病变等疾病 |
| 给出随访与复查安排建议 | 给出药物、治疗或鼓膜修补等医疗建议 |

**必须先就医排查、暂不讨论选配的警示信号（出现任一条，先去耳鼻喉科）**

- **突发听力下降**：一侧或双侧听力在数小时至数天内明显下降 —— 突发性听力下降有时间窗，必须立即就医
- **伴眩晕**：听力变化同时出现天旋地转、站立不稳、恶心呕吐 —— 可能涉及内耳或前庭系统
- **单侧听力骤降**：一侧突然听不清而另一侧正常 —— 需排除突发性聋与占位性病变
- **耳痛、流液、流血、外耳道畸形**：可能有中耳炎、外伤或先天异常
- **耳鸣突然加重并伴听力变化**、耳鸣与听力下降同步出现
- **面部麻木、口角歪斜、说话含糊、吞咽困难**：可能涉及面神经或中枢，需急诊评估
- **儿童、青少年出现听力下降**：病因与干预路径与成人不同，需专科评估
- **长期未治疗的听力下降伴随言语识别明显差**：需先评估言语识别能力，再谈选配
- **单侧传导性听力下降伴反复中耳炎史**：需先处理中耳问题
- **持续耳鸣伴眩晕与听力下降**：需专科排查后再谈选配

**必须立即就医的红线**：听力骤降伴突发剧烈头痛、意识改变、单侧肢体无力、言语含糊 —— **急诊**，排除急性脑血管事件。

**绝对禁止的做法**：不查听力就凭症状买助听器；代购、代选未经专业验配的产品；把助听器当作「治疗」手段。

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「助听器怎么选」 | 用，先说明须先做听力检查 |
| 「多少钱合适」 | 用，说明价格不能只按预算选，须先评估 |
| 「老人耳背什么时候配」 | 用，说明评估维度 |
| 「戴了还是听不清」 | 用，区分调试问题与言语识别能力差异 |
| 「耳朵突然听不见了」 | 不用，直接转诊，这是紧急信号 |
| 「戴着头晕耳朵胀」 | 用，常见适应现象 + 何时必须回诊 |
| 「取不下来」 | 用，手指灵活性与取戴训练 |
| 「老人不肯戴」 | 用，家庭沟通与适应期安排 |

## 三、完整工作流

1. **先排警示**：逐条核对就医警示信号，命中即转诊，暂不谈选配。
2. **确认已完成听力检查**：按 `rules/选型前评估维度.md` 核对是否具备听力检查结果；没有就先做检查。
3. **评估六维**：听力损失情况、言语识别能力、生活场景与噪音环境、预算与支付方式、佩戴意愿、手指灵活性与认知配合能力。
4. **走完验配五步**：听力检查 → 选型 → 调试 → 适应期随访 → 定期复测，按专业机构安排执行。
5. **准备适应期方案**：用 `templates/选配与适应期记录表.md` 记录佩戴时长、场景反馈与调试要求。
6. **给适应期应对**：堵耳感、耳鸣、取戴困难、语言识别未立即改善等问题的处理方向。
7. **排复查与随访**：适应期内多次复查，稳定后定期复测。
8. **给家庭配合要点**：沟通方式、环境调整、佩戴时间安排。

## 四、核心规则与要件库

生成任何建议前，**必须先读**：

- `rules/选型前评估维度.md`：就医警示、六维评估、五步验配流程、复查安排。
- `rules/适应期问题与家庭配合.md`：五类适应期常见问题、沟通要点、佩戴时间安排、必须回诊的情形。

不得给品牌、型号与价格推荐；不得判断听力损失类型与程度；不得承诺使用效果；不得给药物与治疗建议。各环节以专业验配机构的安排与**最新版相关指南、耳鼻喉科医师与听力师的判断为准**。

## 五、脚本用法

```
python scripts/hearing_aid_check.py --file case.json
python scripts/hearing_aid_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`warnings` 就医警示标记，`checked` 评估维度是否已完成，`stage` 当前所处验配阶段（`1` 到 `5`），`issues` 适应期问题标记，`red_flags` 急诊红线标记 |
| `--stage` | 只输出该阶段的动作要点 |
| `--json` | 以 JSON 输出 |
| `--out` | 结果写入指定文件，默认 `scripts/_last_result.txt` |
| `--selftest` | 运行自检 |

脚本输出警示拦截、维度缺口、所处阶段与适应期应对。**脚本不判断听力损失程度、不推荐品牌型号价格、不给药物建议。**

## 七、最常见的坑

1. **不查听力就买**：这是最普遍也最贵的错误。听力损失类型与程度不同，选型思路完全不同。
2. **只看听力曲线不看言语识别**：两个老人听力曲线相似，但一个能听清、一个听不清，后者可能需要更长适应期与不同方案。
3. **按预算选而不是按评估选**：预算重要，但不是唯一变量。评估清楚了才知道钱该花在哪。
4. **指望戴上就听清**：戴上就能恢复正常听力是不现实的，需要适应期与调试。
5. **两周没效果就放弃**：适应期需要时间与多次调整，放弃得越早越难戴上。
6. **只在安静环境测**：真正困难的是嘈杂环境，不在噪音场景验证就不知道实际效果。
7. **每天戴的时间太少**：每天佩戴时长不足是最常见的失败原因，宁可缩短外出也要保证日常佩戴。
8. **老人不愿意戴就放弃**：老人觉得「别人看不见」「我不需要」时，需要家里调整沟通方式而不是降低要求。
9. **取戴困难就放弃**：取戴困难可以训练，也可以在选型时考虑更易操作的款式。
10. **耳鸣与听力下降混为一谈**：耳鸣可能是症状也可能是伴随表现，需要专业评估。
11. **自行调整或改装设备**：不当改装会造成听力进一步受损与设备损坏。
12. **不复查**：听力与设备状态会变化，定期复测是保证效果的前提。

## 八、边界与免责

本技能提供助听器选配前的评估维度、验配流程框架与适应期应对参考，**不判断听力损失类型与程度、不诊断病因、不推荐具体品牌型号与价格、不提供药物与治疗建议**。突发听力下降、伴眩晕、单侧听力骤降、耳痛流液等情况**必须先就医排查**，不能直接进入选配流程。听力检查、选型、调试、随访与复测各环节**以专业验配机构的安排和最新版相关指南为准**，最终以耳鼻喉科医师与听力师的判断为准。本技能不替代诊疗。
