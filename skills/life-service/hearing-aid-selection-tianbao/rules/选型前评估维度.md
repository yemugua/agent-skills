# 选型前评估维度与验配流程

## 一、必须先就医排查的警示信号（命中即暂不谈选配）

| 信号 | 为什么要先排查 |
|---|---|
| 突发听力下降（数小时至数天内明显下降） | 突发性听力下降有时间窗，越早处理越好 |
| 伴眩晕：天旋地转、站立不稳、恶心呕吐 | 可能涉及内耳或前庭系统 |
| 单侧听力骤降 | 需排除突发性聋与占位性病变 |
| 耳痛、流液、流血、外耳道畸形 | 可能有中耳炎、外伤或先天异常 |
| 耳鸣突然加重并伴听力变化 | 耳鸣与听力下降需一并评估 |
| 面部麻木、口角歪斜、说话含糊、吞咽困难 | 可能涉及面神经或中枢，需急诊评估 |
| 儿童、青少年出现听力下降 | 病因与干预路径与成人不同，需专科评估 |
| 长期未治疗听力下降伴言语识别明显差 | 需先评估言语识别能力，再谈选配 |
| 单侧传导性听力下降伴反复中耳炎史 | 需先处理中耳问题 |
| 持续耳鸣伴眩晕与听力下降 | 需专科排查后再谈选配 |

**立即急诊的红线**：听力骤降伴突发剧烈头痛、意识改变、单侧肢体无力、言语含糊 —— 排除急性脑血管事件。

## 二、选型前六维评估（缺哪维都要补齐）

### D1 听力损失的情况

- 是否已完成正规听力检查，检查日期
- 听力损失是单侧还是双侧
- 是否存在传导性问题需要先处理中耳
- 检查结果是否在有效期内（有效期由检查机构说明）

**口径**：本维度只记录「检查做没做、结果是什么」，**不判断损失类型与程度**，这由耳鼻喉科医生与听力师判断。

### D2 言语识别能力

- 是否做了言语识别测试
- 在安静环境下能听懂多少
- 在噪音环境下能听懂多少（这一项常被忽略）

**为什么重要**：两个老人听力曲线可能相似，但言语识别能力差别很大。识别差的人需要更长适应期与更精细的调试。

### D3 生活场景与噪音环境

| 场景 | 描述要点 |
|---|---|
| 居家 | 家人说话音量、是否需要开电视很大声 |
| 电视 | 能否听清、有没有开字幕的习惯 |
| 外出 | 菜市场、公交、餐厅等嘈杂场所 |
| 工作或社区 | 是否需要开会、是否有集体活动 |
| 宗教或集体场合 | 是否有集体活动需求 |

**为什么重要**：日常最困难的往往是嘈杂环境，不是安静环境。场景决定了选型时更看重哪些指标。

### D4 预算与支付方式

- 可承受的支出范围
- 是否有医保、商业保险或其他支付渠道
- 后续维护（电池、耗材、维修、复查）是否算在预算内

**口径**：预算重要但不是唯一变量。**评估清楚之后才知道钱该花在哪**，而不是先定价格再倒推方案。

### D5 佩戴意愿

- 本人是否主动愿意戴
- 是否担心「别人看出我耳背」「显得老」
- 是否担心别人议论

**为什么重要**：意愿是适应期能否坚持的前提。家里人的沟通方式会直接影响意愿。

### D6 手指灵活性与认知配合能力

- 能否自己取戴
- 能否自己更换电池或充电
- 能否记住充电与保养步骤
- 认知功能能否配合定期复查与调试

**口径**：这一维会直接影响款式选择（操作复杂度）与是否需要家人协助，**建议在选型时就和验配师说明**。

## 三、验配五步流程（各环节以专业验配机构安排为准）

| 步骤 | 内容 | 关键提醒 |
|---|---|---|
| 第 1 步 听力检查 | 专业的听力检查与评估 | 没有这一步不进入选配 |
| 第 2 步 选型 | 根据评估结果选择方案 | 不按预算单方面决定 |
| 第 3 步 调试 | 由专业人员进行初次调试 | 把日常生活场景告诉调试人员 |
| 第 4 步 适应期随访 | 佩戴过程中多次复查调整 | 适应期内不要一次调整后就定案 |
| 第 5 步 定期复测 | 稳定后定期复测 | 听力与设备状态会变化 |

**口径**：以上五步的顺序与具体安排**由专业验配机构决定**，本表只是流程框架，不代替验配方案。

## 四、复查与随访安排

| 阶段 | 安排 | 关注点 |
|---|---|---|
| 初次验配后 | 按机构安排回访 | 佩戴是否舒适、有无明显不适 |
| 适应期内 | 多次复查（不宜过少） | 场景反馈、语言识别变化、调试需求 |
| 稳定后 | 定期复测 | 听力变化、设备状态、保养 |
| 出现异常时 | 立即联系验配机构或就医 | 见适应期文件中的「必须回诊」清单 |

**口径提醒**：复查时点以验配机构安排为准。出现「耳朵痛、流液、突然听不清」等情况，不等复查时间，直接就医。

## 五、价格与选型的一条硬口径

- **不得只按预算选**：先完成评估，再根据评估结果确定方案，最后再看预算能否覆盖
- **维护成本要算进去**：电池、充电仓、耳模、干燥剂、维修、定期复查都属于长期成本
- **不推荐具体品牌与型号**：不同品牌与型号差异需由验配师根据评估结果判断
