# 适应期常见问题与家庭配合

**前置声明**：适应期出现的现象多数是常见的，但**具体是哪一种、有没有危险信号，需要由耳鼻喉科医师与听力师判断**。本表提供应对方向，不做诊断与效果承诺。

## 一、五类常见适应期问题

### P1 堵耳感（觉得耳朵像塞住了）

| 项 | 内容 |
|---|---|
| 表现 | 戴上后觉得耳闷、耳内发胀、有压迫感 |
| 为什么 | 耳模或定制外壳的密闭度较高，属常见现象 |
| 应对方向 | 联系验配机构反馈，评估是否需要调整外壳或耳模类型 |
| 不能做 | 不要自行拆改，不要因为不适应就长时间不戴后突然大音量 |
| 必须回诊 | 耳痛明显、耳道内发红破损、流液或流血 |

### P2 耳鸣变化

| 项 | 内容 |
|---|---|
| 表现 | 戴上后耳鸣暂时减弱，停戴后又出现；或耳鸣感觉变化 |
| 为什么 | 耳鸣本身可能随环境与注意力变化 |
| 应对方向 | 记录耳鸣出现的时间、环境与变化，作为复查时的信息 |
| 不能做 | 不要因为耳鸣自行加音量 |
| 必须回诊 | 耳鸣突然明显加重并伴听力变化、伴眩晕 |

### P3 取戴困难

| 项 | 内容 |
|---|---|
| 表现 | 戴不上、取不下、戴的位置不对 |
| 为什么 | 手部精细动作能力不足、方向不熟、听力与视力配合困难 |
| 应对方向 | 在验配时就说明手指灵活性，请验配师考虑更易操作的款式；做取戴训练（先在镜子前练，用有标记的一只先练） |
| 不能做 | 不要硬掰、不要用手强推耳道 |
| 必须回诊 | 取戴时耳朵明显疼痛、耳道皮肤破损 |

### P4 语言识别未立即改善

| 项 | 内容 |
|---|---|
| 表现 | 戴上后觉得「还是听不清」，尤其在嘈杂环境 |
| 为什么 | 长期听力损失后听觉系统需要重新适应；噪音环境下识别本就困难 |
| 应对方向 | 继续按适应期佩戴时长要求佩戴，按时复查，把具体困难的场景告诉调试人员 |
| 不能做 | 不要因为几天没听清就判定无效并放弃 |
| 必须回诊 | 完全听不到声音、或突发听力下降 |

### P5 佩戴时长不足

| 项 | 内容 |
|---|---|
| 表现 | 每天戴的时间断断续续，几天才戴一次 |
| 为什么 | 不习惯、怕被人看见、觉得不需要 |
| 应对方向 | 固定场景佩戴（起床、上厕所、吃饭、看电视、与人交谈），把佩戴绑定在日常事件上；家里人先调整沟通方式 |
| 不能做 | 不要「等准备好了再戴」，适应期靠时间不靠准备 |
| 必须回诊 | 出现耳痛、流液、听力下降 |

## 二、家庭沟通要点（直接影响佩戴意愿）

| 要做 | 不要做 |
|---|---|
| 面对面说话，光线照到说话人脸上 | 背对着说话、从另一个房间喊 |
| 语速放慢，句子短一些 | 快速连说长句 |
| 一次说一件事 | 连续输出多条信息 |
| 叫名字或轻拍后再开始说 | 直接开口说 |
| 电视开字幕、调大音量（适度） | 长时间把音量开到很大 |
| 重要的事单独找安静地方说 | 在嘈杂场合说重要的事 |

## 三、佩戴时间安排

| 阶段 | 安排 |
|---|---|
| 开始阶段 | 从每天固定场景开始，固定场景优先于长时间 |
| 逐步阶段 | 逐步延长佩戴时间，尽量在清醒时持续佩戴 |
| 稳定阶段 | 白天清醒时间基本持续佩戴 |

**核心口径**：每天佩戴时长不足是最常见的失败原因。**宁可缩短外出时间，也要保证日常佩戴。**

## 四、必须立即就医或回诊的情形

| 情形 | 处置 |
|---|---|
| 听力骤降（数小时至数天内） | 立即就医，不要等复查时间 |
| 听力骤降伴突发剧烈头痛、意识改变、单侧无力、言语含糊 | **急诊** |
| 伴眩晕、站立不稳、恶心呕吐 | 就医 |
| 耳痛、流液、流血、外耳道破损 | 就医 |
| 耳鸣突然明显加重并伴听力变化 | 就医 |
| 戴后耳内持续剧烈疼痛 | 立即联系验配机构并就医 |
| 完全听不到声音 | 联系验配机构，若伴随其他症状则就医 |

## 五、适应期记录的必填内容

- 每日佩戴时长（小时）
- 佩戴场景（晨间、看电视、外出、社交等）
- 有困难的具体场景（不要只写「听不清」，要写「在菜市场听不清」）
- 有无耳鸣变化
- 有无耳闷、耳痛、流液
- 皮肤有无异常（耳道、耳廓）
- 需要复查的诉求（具体到场景，不要只写「没效果」）

**记录的意义**：复查时把这些具体场景告诉调试人员，调试才有针对性。

## 六、必须避免的做法

- 自行拆改、自行调整设备参数
- 因为不适应就长时间完全不戴，然后又突然大音量长时间戴
- 自行购买未经验配的设备
- 用助听器替代就医（突发听力下降必须先就医）
- 在嘈杂环境下长时间硬撑而不做调整反馈
- 只在安静环境测试就认为效果够用
