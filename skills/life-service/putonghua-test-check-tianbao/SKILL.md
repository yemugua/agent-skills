# 普通话水平测试报名与备考核查（putonghua-test-check）

普通话这件事，考之前要搞清楚**目标等级**，考之后要搞清楚**够不够用**。

很多人为了"更好看"反复考，其实认定公告写的是二级甲等，考到就够了；也有人被"证书 5 年有效"的误传骗去重考，其实 2003 年 6 月之后的证长期有效。

这个技能做五件事：**判等级** → **核达标** → **查有效期** → **算间隔** → **定备考**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 按分数判定三级六等等级 | ❌ 代替测试站的评分与等级评定 |
| 核查是否达到用途的等级要求 | ❌ 代替教师资格认定公告、招录公告的官方要求 |
| 判断证书是否长期有效 | ❌ 代替用人单位对证书年限的自主判断 |
| 测算复测间隔是否够 | ❌ 代替属地测试站的报名资格审查 |
| 给出备考优先级与训练方法 | ❌ 代替系统的语音训练与专业辅导 |

**遇到以下情况，务必以属地测试站与主管部门的公告为准：**
- 报名时间、场次、名额、收费标准与照片规格
- 成绩公布时间与复查期限
- 复测间隔的具体天数（各地不同）
- 教师资格认定、导游、播音主持等用途的等级要求（查认定公告或招录公告）
- 证书补办、信息更正的具体流程

**永远不要把"常见要求"说成"一定要求"。** 用途的等级要求以认定公告或招录公告为准，本技能给的是常见口径。

## 二、完整工作流

```
第 1 步  先确认用途所需等级（查认定公告/招录公告，不靠猜）
第 2 步  先读规则文件 rules/test_content.md 与 rules/registration_cert.md
第 3 步  跑核查脚本
    python scripts/putonghua_check.py --score 86.5 --purpose teacher-chinese
    python scripts/putonghua_check.py --score 88 --last-test 2026-08-01 --as-of 2026-10-08
第 4 步  按 70 分原则排备考：命题说话 40 + 朗读短文 30
第 5 步  报名前按清单自检（照片、身份证、缴费、五个时间节点）
第 6 步  成绩公布后核对复查期限，证书信息有误尽早更正
```

## 三、三级六等（分数是硬指标）

| 等级 | 分数区间 |
|---|---|
| **一级甲等** | 97 分及以上 |
| **一级乙等** | 92 分及以上，不足 97 分 |
| **二级甲等** | 87 分及以上，不足 92 分 |
| **二级乙等** | 80 分及以上，不足 87 分 |
| **三级甲等** | 70 分及以上，不足 80 分 |
| **三级乙等** | 60 分及以上，不足 70 分 |

**60 分以下不发证。差 0.1 分就是差一个等级**，不要指望"差不多"。

## 四、四题分值（70 分原则）

| 题号 | 内容 | 分值 |
|---|---|---|
| 一 | 读单音节字词 100 个 | 10 分 |
| 二 | 读多音节词语约 50 个 | 20 分 |
| 三 | 朗读短文约 400 音节 | **30 分** |
| 四 | 命题说话 3 分钟 | **40 分** |

**命题说话 + 朗读短文 = 70 分。** 前两题全省的人都差不多，真正决定等级的是这两题。朗读短文的篇目是公开的，不练是最大的浪费。

---

## 五、按用途查等级（不是越高越好）

| 用途 | 常见等级要求 |
|---|---|
| 语文教师 | **二级甲等**及以上 |
| 其他学科教师 | **二级乙等**及以上 |
| 幼儿园教师 | 各省不同，多为二级甲等或二级乙等 |
| 播音员、主持人 | 一级甲等或一级乙等（国家级与省级要求不同） |
| 导游 | 二级乙等及以上 |
| 公务员与事业单位 | 岗位不同，**以招录公告为准**，无统一要求 |

**先确认目标等级，再决定要不要复测。** 达标即可，多考几次通常没必要。

## 六、证书有效期（最常被误传的一条）

| 情形 | 口径 |
|---|---|
| **2003 年 6 月之后取得**的证书 | **长期有效** |
| 2003 年 6 月之前取得的证书 | 按当时规定执行有效期（常见为 5 年），一般已不被认可 |

**"普通话证书有效期 5 年"是流传最广的误传**，针对的是早期证书。但用人单位是否认可多年以前的证书，属于单位自主判断。

## 七、脚本用法

```bash
# 等级与用途达标核查
python scripts/putonghua_check.py --score 86.5 --purpose teacher-chinese

# 顺带查证书有效期与复测间隔
python scripts/putonghua_check.py --score 90.2 --purpose teacher-other \
    --cert-date 2019-05-20 --last-test 2026-05-01
```

| 参数 | 说明 |
|---|---|
| `--score` | 测试总分（0~100） |
| `--purpose` | `teacher-chinese` / `teacher-other` / `broadcaster` / `tour-guide` / `civil-service` / `other` |
| `--cert-date` | 已有证书取得日期，用于有效期判断 |
| `--last-test` | 上次测试日期，用于复测间隔测算 |
| `--interval` | 复测间隔天数，默认 90（各地不同） |
| `--as-of` | 核查基准日，默认今天 |
| `--out` / `--format` | 输出路径 / `md` 或 `json` |
| `--selftest` | 跑内置自检（21 条断言） |

脚本输出四类结论：**等级判定**（含距上一等级还差多少分）、**用途达标**（含常见要求与差多少分）、**证书有效期**（按 2003 年 6 月分界）、**复测间隔**（距上次测试天数 vs 要求天数）。

> ⚠️ 等级要求以认定公告或招录公告为准，复测间隔以属地测试站规定为准，脚本给的是常见口径。

## 八、人工确认清单（这步不能省）

**报名前：**

- [ ] 已确认用途所需等级（查认定公告或招录公告）
- [ ] 已确认报名渠道（学校集体报名 / 属地测试站社会报名）
- [ ] 身份证在有效期内，信息与报名一致
- [ ] 电子照片符合测试站规格（背景、尺寸、格式）
- [ ] 已记下报名、确认、缴费、测试、查分五个时间节点
- [ ] 已核对与前次测试的间隔是否满足属地要求

**备考：**

- [ ] 朗读短文篇目已逐篇练三遍（30 分）
- [ ] 命题说话已按随机话题计时练，能说满 3 分钟不停（40 分）
- [ ] 已找出自己的系统性发音缺陷并集中突破
- [ ] 已用录音回听过自己的发音

**考后：**

- [ ] 成绩公布后已核对复查期限（逾期一般不再受理）
- [ ] 证书信息（姓名、身份证号）已核对，有误尽早更正
- [ ] 纸质证书与电子证书均已留存

## 九、最常见的坑

**坑一：把"证书 5 年有效"当真。**
2003 年 6 月之后取得的证书长期有效。这个误传让很多人白重考。

**坑二：照片规格不对导致报名失败。**
背景、尺寸、格式都要按测试站要求，不合格会被退回，名额可能就没了。

**坑三：报名了没缴费。**
未缴费视为报名无效，这一步每年都有人栽。

**坑四：没确认目标等级就反复考。**
先查清楚用途要求几级，达标就行。

**坑五：错过成绩复查期限。**
复查有明确窗口，逾期一般不再受理。

**坑六：证书信息错了拖着不改。**
等到认定时才发现，流程直接卡住。

**坑七：复测间隔没算够。**
间隔不足报名会被驳回，赶不上认定时间。

**坑八：缺考后以为能免费重考。**
缺考一般视为放弃，需重新报名缴费。

**坑九：命题说话背稿。**
会被扣分，不是背得越熟越好。

**坑十：不练朗读短文。**
篇目公开，这 30 分不拿是最大的浪费。

**坑十一：只练前两题。**
前两题合计 30 分，后两题合计 70 分，精力分配反了。

**坑十二：说不满 3 分钟。**
命题说话缺时扣分明显，宁可慢也不要停。

## 十、输出结构（固定五段）

1. **结论先行** —— 等级、是否达标、卡在哪一项
2. **等级判定** —— 分数、等级、距上一等级还差多少分
3. **用途达标** —— 常见要求等级、当前是否达标、差多少分
4. **证书与间隔** —— 是否长期有效、距上次测试天数与间隔要求
5. **备考优先级** —— 四题分值表与 70 分原则
