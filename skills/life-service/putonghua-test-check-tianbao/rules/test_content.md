# 普通话水平测试等级标准、测试内容与备考

> 普通话水平测试的等级标准、测试内容与评分办法由**国家语言文字工作部门制定的现行测试大纲与相关规定**确定，各省测试站在具体安排上存在差异。**以现行大纲与属地测试站公告为准**，本文件只给通行口径。

## 一、三级六等（分数是硬指标）

| 等级 | 分数区间 | 水平描述 |
|---|---|---|
| **一级甲等** | **97 分及以上** | 朗读和自由交谈时，语音标准，词汇、语法正确无误，语调自然，表达流畅 |
| **一级乙等** | **92 分及以上，不足 97 分** | 朗读和自由交谈时，语音标准，词汇、语法正确无误，语调自然，表达流畅；偶有字音、字调失误 |
| **二级甲等** | **87 分及以上，不足 92 分** | 朗读和自由交谈时，声韵调发音基本标准，语调自然，表达流畅；少数难点音偶有失误 |
| **二级乙等** | **80 分及以上，不足 87 分** | 朗读和自由交谈时，个别调值不准，声韵母发音有不到位现象；难点音较多，方言语调不明显 |
| **三级甲等** | **70 分及以上，不足 80 分** | 朗读和自由交谈时，声韵母发音失误较多，难点音超出常见范围，方言语调较明显 |
| **三级乙等** | **60 分及以上，不足 70 分** | 朗读和自由交谈时，声韵母发音失误多，方音特征突出，方言语调明显 |

**60 分以下不发证。** 分数区间是硬指标，差 0.1 分就是差一个等级，这就是为什么复查与复测需求这么常见。

## 二、测试内容（四题，总分 100）

| 题号 | 内容 | 分值 | 限时 | 考什么 |
|---|---|---|---|---|
| 一 | 读单音节字词 **100 个** | **10 分** | 3.5 分钟 | 声母、韵母、声调的发音 |
| 二 | 读多音节词语（**约 50 个词**） | **20 分** | 2.5 分钟 | 声韵调、变调、轻声、儿化 |
| 三 | 朗读短文（**约 400 个音节**） | **30 分** | 4 分钟 | 流利度、语调、停连 |
| 四 | 命题说话 | **40 分** | 3 分钟 | 语音标准程度、词汇语法规范、自然流畅 |

**第四题占 40 分，是拉开差距的地方。** 前两题全省的人都差不多，真正决定等级的是朗读和说话。

## 三、第四题（命题说话）评分要点

| 评分维度 | 常见失分 |
|---|---|
| **语音标准程度** | 声韵调错误、系统性缺陷（如前后鼻音不分、平翘舌不分） |
| **词汇语法规范程度** | 方言词汇、不规范表达 |
| **自然流畅程度** | 背稿痕迹明显、长时间停顿、重复、口头禅 |
| **时间不足** | 说不满 3 分钟会按缺时扣分，**这是最容易白丢的分** |

**"背稿"会被识别。** 测试大纲明确命题说话是即兴表达，背现成文章或明显离题会被扣分。

## 四、常见发音难点（按方言区分）

| 方言区 | 典型难点 |
|---|---|
| 北方方言区 | 声调调值不到位、轻声与儿化不规范 |
| 吴语区（江浙沪） | 浊声母、入声字、前后鼻音 |
| 粤语区 | 无翘舌音、声调调类与普通话差异大 |
| 闽语区 | 无唇齿音 f、无翘舌音、文白异读 |
| 客家话区 | 送气与不送气、声调调值 |
| 西南官话区 | n/l 不分、平翘舌不分、前后鼻音不分 |
| 湘语区 | n/l 不分、f/h 不分、无翘舌音 |

**先判断自己是"系统性缺陷"还是"偶发失误"。** 系统性缺陷（如所有 zh/ch/sh 都读成 z/c/s）扣分远重于偶发失误，这是二乙上不去二甲的根本原因。

## 五、备考优先级（时间不多时的取舍）

| 优先级 | 内容 | 为什么 |
|---|---|---|
| 1 | **命题说话（40 分）** | 分值最高，且拿到模板就能练 |
| 2 | **朗读短文（30 分）** | 可提前练熟指定篇目，见效最快 |
| 3 | **多音节词语（20 分）** | 变调、轻声、儿化是固定规则，可突击 |
| 4 | **单音节字词（10 分）** | 分值最低，但错一个扣得也实在 |

**朗读短文的篇目是公开的**，考前逐篇读三遍，这 30 分基本能拿稳。

## 六、训练方法

| 方法 | 做法 |
|---|---|
| **录音回听** | 用手机录自己读，对照标准音频找差异，比"感觉"可靠 |
| **难点集中突破** | 找出自己的系统性缺陷（如平翘舌），集中练两周 |
| **计时说话** | 随机抽话题，说满 3 分钟不停，**练的是"不停"这件事** |
| **朗读按音节计时** | 400 音节 4 分钟，提前练到 3 分半内读完且不出错 |
| **模拟测试** | 找测试站或 App 做全真模拟，熟悉流程与限时压力 |

## 七、考场要点

| 事项 | 提示 |
|---|---|
| 第一题、第二题 | 可回读一次，**以最后一次为准**；横向朗读，不要竖着读 |
| 第三题 | 读到 400 个音节即可，不必读完整篇；不要回读 |
| 第四题 | 必须说满 3 分钟；缺时扣分明显 |
| 音量与语速 | 音量适中，语速略慢于日常说话，把每个音节发完整 |
| 设备 | 保持与话筒的固定距离，避免喷麦与爆音 |

## 八、防误伤清单

1. **差 0.1 分就是差一个等级**，不要指望"差不多"
2. **命题说话背稿会被扣分**，不是背得越熟越好
3. **说不满 3 分钟会缺时扣分**，宁可慢也不要停
4. **系统性缺陷比偶发失误扣得多**，先解决系统性问题
5. **朗读短文篇目公开**，不练是最大的浪费
6. **60 分以下不发证**
7. **等级要求按用途查**，不是越高越好，达标即可
8. **证书信息错误要尽早更正**，用到时才发现会耽误事
