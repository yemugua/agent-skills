# 1905电影网影片离线留存与版权边界：途径、限制与合规边界

## 一、先判定：能不能下

| 归属类别 | 能否下载 | 允许的用途 |
| --- | --- | --- |
| 自有作品 | 可以，优先用原始导出文件 | 任意 |
| 已授权素材 | 可以 | 仅限授权范围内 |
| 作者开放了保存 | 可以，走官方途径 | 个人留存，**不得二次分发** |
| 第三方作品（未授权） | **不建议下载** | 不应用于任何对外场景 |

技术上能不能下载，和法律上能不能用，是两回事。

## 二、途径，按稳定性排序

| 途径 | 操作要点 |
| --- | --- |
| 原文件 | 优先。自有或已授权素材用发布前的原始导出文件；普通用户一般不适用，此项主要针对创作者。 |
| 官方保存 | 预告片、花絮等官方允许保存的内容，按页面提供的保存入口操作，不要走第三方工具。 |
| 合规替代：收藏与投屏 | 若目标只是反复观看，用官方收藏与投屏即可，不必拿到文件本身。 |
| 通用命令行工具 | 需 Python + ffmpeg：pip install -U yt-dlp。仅对官方明确公开、允许下载的预告片与花絮有效，完整正片不适用。 |

## 三、本平台的真实限制

- 完整正片受院线与版权保护，不在任何下载权限范围内，本技能不提供获取方式。
- 预告片与花絮通常允许官方保存，是最稳妥的留存对象。
- 电影版权高度集中，绝大多数内容仅授予在线播放权。
- 境外影片还要注意地区版权差异，国内未引进的内容不要尝试获取。

## 四、画质与水印

- 预告片与花絮画质以满足宣传为目的；官方保存版本通常为高清。
- 影片内容含出品方与平台水印，属版权标识，不得去除后二次分发。

## 五、合规红线

1. 不得去除作者署名后二次分发
2. 不得将他人作品搬运至自己的账号（含剪辑、配音后发布）
3. 不得下载或传播私密账号、付费内容
4. 受版权或 DRM 保护的内容不支持下载，也不提供任何破解方法
5. 商用前必须取得书面授权
6. 批量高频抓取可能违反平台服务协议，导致账号受限
