# 烧烤腌制

## 1. 硬边界表

| 能做 | 不能做 |
|---|---|
| 给分食材腌料配比 | 替代你对肉源质量的判断 |
| 给腌制时间区间（下限/上限） | 承诺腌越久越嫩 |
| 给嫩肉粉（木瓜蛋白酶）安全用量 | 指导工业级添加剂使用 |
| 提示冷藏腌制与串味风险 | 处理食物中毒事件 |

必须转交专业人士：出现食物中毒症状立即就医；商业腌制合规问题咨询市场监管部门。

## 2. 什么时候用

| 用户说法 | 用本技能 |
|---|---|
| 「牛肉怎么腌才嫩」 | 用 |
| 「鸡肉腌多久」 | 用 |
| 「嫩肉粉放多少」 | 用 |
| 「腌料配方」 | 用 |
| 「哪种烧烤酱最好卖」 | 不用，属商业 |

## 3. 完整工作流

1. 按食材选腌料类型（干腌/湿腌/酱腌）。
2. 按 `rules/bbq-rules.md` 配比调腌料。
3. 控制嫩肉粉用量（如用）。
4. 冷藏腌制，控制在时间区间内。
5. 烤前沥干表面水分，避免烤架起火。
6. 对照人工确认清单核对后再烤。

## 4. 核心规则

先读 `rules/bbq-rules.md`：含肉类/海鲜/蔬菜腌料配比、腌制时间区间表、嫩肉粉用量上限、以及超时与过量的不合格判定。

## 5. 脚本用法

```
python scripts/check.py --file 腌制方案.json
python scripts/check.py --selftest
```

`--file` 含 meat_type、marinade_minutes、tenderizer_g_per_kg、refrigerated 等字段。

## 6. 人工确认清单

- [ ] 嫩肉粉是否 ≤3g/公斤肉
- [ ] 腌制时间是否在区间内（牛羊肉 2–24h，鸡肉 0.5–4h）
- [ ] 是否冷藏腌制（非常温）
- [ ] 腌料盐分是否过高（尝味不齁）
- [ ] 烤前是否沥干防起火

## 7. 最常见的坑

1. 嫩肉粉过量，肉腌成「豆腐渣」、口感粉烂。
2. 鸡肉常温腌制超 2 小时，夏季细菌快速繁殖。
3. 腌越久越嫩误区：超时肉反而散、出水、异味。
4. 腌料太咸，烤后无法下口。
5. 海鲜腌制过久，蛋白质变性发柴。
6. 烤前带水下烤架，油火苗窜起焦糊。
7. 不同生熟食材共用腌料汁不加热直接蘸，交叉污染。

## 8. 边界与免责

本技能为家常参考，不保证风味与安全。肉源新鲜度与冷藏温度是核心变量。腌料汁若接触过生肉，再使用时须煮沸。
