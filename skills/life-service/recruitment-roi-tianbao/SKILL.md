# 招聘 ROI 分析（recruitment-roi）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据人力资源管理 ROI 方法，生成招聘 ROI 分析清单：招聘成本（渠道/猎头/内推）、到岗质量、留存表现、投产比（价值/成本）、渠道效能对比。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 招聘ROI
- 招聘投产比
- 招聘成本分析
- 渠道效能
- 招聘价值

## 三、工作流
1. 归集招聘成本（渠道费/猎头/内推/人力）
2. 量化到岗质量（匹配度/绩效）
3. 跟踪留存与产出贡献
4. 计算ROI（价值/成本）
5. 对比渠道效能并优化投入

## 四、核心内容（检查清单与判定）
招聘ROI=招聘带来的价值/招聘投入成本；衡量不应只看到岗数，应结合质量、留存与业务贡献，用于渠道优选与预算优化。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含招聘成本归集（渠道/猎头/内推） | 成本 |
| Q2 | WARN | 未含到岗质量量化 | 质量 |
| Q3 | WARN | 未含留存/产出贡献 | 留存 |
| Q4 | FAIL | 未含ROI计算（价值/成本） | ROI |
| Q5 | WARN | 未含渠道效能对比 | 渠道 |

> 脚本 `recruitment-roi_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python recruitment-roi_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python recruitment-roi_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
