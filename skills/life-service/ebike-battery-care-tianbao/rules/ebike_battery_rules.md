# 电动车电池保养与充电安全规则

## 一、判定总原则

1. **续航下降先排除非电池原因。** 胎压与刹车是最高频也最便宜的两个因素。
2. **铅酸与锂电分开对待。** 用铅酸习惯养锂电会缩短寿命。
3. **充电环境优先于充电技巧。** 位置不对，习惯再好也抵消不了风险。
4. **鼓包不将就。** 鼓包是热失控前兆，不是"还能骑一阵"。
5. **人身安全优先。** 冒烟起火先撤离，财物次之。

---

## 二、非电池原因排查表

| 非电池原因 | 检查方法 | 影响 |
|---|---|---|
| 胎压不足 | 胎压表测量或拇指按压感受 | 续航明显下降，最常见 |
| 刹车拖滞 | 抬起车轮转动听摩擦声 | 持续耗电 |
| 轴承缺油 | 转动车轮感受阻力 | 阻力增大 |
| 载重与逆风 | 记录载重与路况 | 影响显著 |
| 低温 | 冬季与夏季续航对比 | 铅酸尤其明显 |
| 控制器或电机异常 | 需专业设备检测 | 转专业人员 |

---

## 三、铅酸与锂电保养对照表

| 项目 | 铅酸电池 | 锂电池 |
|---|---|---|
| 充电时机 | 剩余 30%-40% 时充 | 尽量在 20%-80% 区间循环 |
| 充电时长 | 通常 6-8 小时，变灯后浮充 1-2 小时 | 充满即停，不要长期整夜插着 |
| 能否天天充 | 可以，避免每次深度放电 | 可以，避免每次都充到满格 |
| 亏电危害 | 硫化，容量永久损失 | 过放损伤电芯与保护板 |
| 久放处理 | 每 1-2 个月补电一次 | 存放保持 50%-60% 电量，定期检查 |
| 低温 | 容量明显下降，回暖恢复 | 0℃ 以下不要充电，析锂风险 |
| 高温 | 避免暴晒后立即充电 | 避免高温环境充电 |
| 循环寿命 | 约 300-500 次 | 约 800-1200 次，磷酸铁锂更长 |
| 充电器 | 规格必须匹配 | 必须原装匹配，不同体系不能通用 |

**关键认知**：铅酸怕亏电，锂电怕过充过放与高温。

---

## 四、电池状态故障树（按处理顺序）

| 顺序 | 原因 | 判定 | 验证动作 | 处置 |
|---|---|---|---|---|
| 1 | 胎压不足 | 轮胎偏软 | 胎压表测量 | 补气，最便宜的解法 |
| 2 | 刹车拖滞或轴承阻力 | 抬轮转动有阻力或异响 | 抬起车轮转动检查 | 调整刹车、保养轴承 |
| 3 | 低温影响 | 冬季续航下降 | 冬夏续航对比 | 属正常，回暖恢复 |
| 4 | 载重、路况、逆风 | 续航与使用条件相关 | 记录载重与路况 | 调整预期 |
| 5 | 铅酸硫化 | 一充就满一骑就没电，用了两年以上 | 需专业设备测容量 | 检测后决定是否更换 |
| 6 | 锂电单体压差大 | 一充就满一骑就没电 | 需专业检测单体电压 | 做均衡或更换 |
| 7 | 充电器故障或接触不良 | 不变绿灯、充不进 | 换同规格充电器对比 | 更换充电器 |
| 8 | 电池老化到寿命末期 | 续航持续下降且排除以上 | 连续三次续航记录 | 更换电池 |
| 9 | 鼓包、发热、异味、漏液 | 外壳变形、温度异常 | 目视与手背试温 | **立即停用更换** |

## 五、充电环境要求

| 要求 | 说明 |
|---|---|
| 位置 | 室外或专用充电场所，不在室内、楼道、疏散通道 |
| 通风 | 干燥、通风、远离可燃物 |
| 时间 | 尽量白天或有人看护时，避免整夜无人看管 |
| 距离 | 与可燃物保持距离，下方不堆放杂物 |
| 线路 | 固定插座与合规线缆，不飞线、不私拉乱接 |
| 顺序 | 先接电池端再接电源；充满后先断电源再拔电池端 |

## 六、热失控处置流程

| 阶段 | 处置 |
|---|---|
| 鼓包、发烫、异味、漏液 | 立即停用，在确保安全前提下断电，移到空旷处，联系售后或专业回收 |
| 出现冒烟 | 人员立即撤离，关闭房门，拨 119，不要自行搬动冒烟电池 |
| 已起火 | 立即撤离并拨 119，锂电火势猛、会复燃、有有毒烟气，注意防烟 |
| 灭火后 | 持续警戒，锂电可能复燃，交由专业人员处理 |

**不要做的事**：不刺破挤压拆解鼓包电池；不用水少量浇泼后离开；不把冒烟电池搬进电梯或室内；不把废电池丢进普通垃圾桶。

---

## 七、严禁清单

- 严禁在室内、楼道、疏散通道、安全出口停放或充电
- 严禁飞线充电（从楼上拉接线板到楼下）
- 严禁把电池带入电梯或住宅室内
- 严禁私自改装、并联不同容量电池、拆除保护板
- 严禁使用非原装或参数不匹配的充电器
- 严禁三元锂与磷酸铁锂充电器混用

---

## 八、安全红线（立即停用并求助）

| 情形 | 处置 |
|---|---|
| 电池鼓包、发烫、异味、漏液、冒烟 | 立即停用断电，人员撤离，冒烟起火拨 119 |
| 充电器或充电口烧熔、有焦味、外壳变形 | 停止使用该充电器，转专业人员 |
| 电池进水、泡水、跌落破损 | 停用并转专业人员，不要充电 |
| 电池仓与接插件有烧蚀痕迹 | 停用并转专业人员 |
| 充电中异常高温、异响、冒烟 | 断电撤离，必要时拨 119 |

---

## 九、常见误判清单（反向判断）

| 现象 | 常见误判 | 正确判断 |
|---|---|---|
| 续航变短 | 电池老化 | 先查胎压与刹车拖滞，是最常见原因 |
| 冬天跑不远 | 电池报废 | 低温容量下降属正常，回暖会恢复 |
| 一充就满一骑就没电 | 电池容量满 | 铅酸硫化或锂电单体压差大，需检测 |
| 充电器不变绿灯 | 电池坏了 | 可能是充电器故障或充电口接触不良 |
| 换新电池后仍跑不远 | 新电池有问题 | 可能是胎压、刹车、控制器或充电器不匹配 |
| 电池鼓包 | 还能凑合用 | 热失控前兆，必须停用更换 |
| 铅酸加修复液 | 能复活 | 硫化严重不可逆，效果有限 |
| 锂电充满要 12 小时 | 充得越久越满 | 锂电充满即停，久充伤电池 |
| 快充更快更方便 | 只是快 | 大电流显著缩短寿命并有安全隐患 |
| 电池带回家充更安心 | 方便 | 把热失控风险搬进居住空间，严禁 |

---

## 十、验收与记录标准

| 项目 | 合格标准 |
|---|---|
| 胎压 | 达到车辆标称值 |
| 空转 | 抬起车轮转动顺畅无摩擦声 |
| 续航记录 | 同样路线连续记录三次取平均 |
| 充电时长 | 铅酸变灯后浮充 1-2 小时；锂电充满即停 |
| 电池外观 | 无鼓包、无变形、无漏液 |
| 温度 | 充电结束时电池与充电器无异常高温 |

任一项不合格，按故障树重新定位；出现危险征兆立即停用。
