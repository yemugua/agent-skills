# 电动车电池保养与充电安全（ebike-battery-care）

续航变短，**先别急着换电池**。胎压、刹车拖滞、载重、低温都能让续航掉一大截，这些和电池老化无关，换了电池也不会好转。而电池本身的问题里，充电习惯的影响远大于电池本身的质量差异。

这个技能做四件事：**判真伪** → **分类型** → **改习惯** → **识危险**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 区分铅酸与锂电的保养差异 | ❌ 认定"续航短就是电池坏了" |
| 给出充电时机与环境要求 | ❌ 建议拆解电池包、短接或改装 |
| 判断续航下降的非电池原因 | ❌ 指导修复鼓包或受损电池 |
| 识别热失控前兆并给出处置流程 | ❌ 替代电池检测与更换服务 |
| 说明充电器匹配要求 | ❌ 建议混用不同体系的充电器 |

**遇到以下情况，立即停止使用并按危险处置：**

- 电池**鼓包、发烫、有异味、漏液、冒烟**——这是热失控前兆，**立即停用、断电、人员撤离**，冒烟起火时拨 119
- 充电器或充电口**烧熔、有焦味、外壳变形**
- 电池**进水、泡水、跌落后外壳破损**
- 电池仓与接插件有**烧蚀痕迹**
- 充电过程中**异常高温、异响、冒烟**

**严禁事项（涉及人身与公共安全）：**

- 严禁在**室内、楼道、疏散通道、安全出口**停放或充电
- 严禁**飞线充电**（从楼上拉接线板到楼下）
- 严禁把电池**带入电梯或住宅室内**
- 严禁**私自改装**、并联不同容量电池、拆除保护板
- 严禁使用**非原装或参数不匹配**的充电器（三元锂与磷酸铁锂的充电器**不能通用**）

## 二、完整工作流

```
第 1 步  判断续航下降是不是电池问题（先查胎压、刹车、载重、气温）
第 2 步  确认电池类型：铅酸 / 三元锂 / 磷酸铁锂（看铭牌）
第 3 步  先读规则文件 rules/ebike_battery_rules.md（保养对照 + 红线 + 处置流程）
第 4 步  跑故障树脚本
    python scripts/ebike_battery_check.py --text "冬天续航短了一半，电池用了两年"
第 5 步  调整充电习惯与环境，连续记录三次续航做对比
第 6 步  出现危险征兆立即停用并按处置流程处理
```

## 三、先排除非电池原因（这步跳过就白换电池）

| 非电池原因 | 检查方法 | 影响 |
|---|---|---|
| 胎压不足 | 用胎压表测，或拇指按压感受 | 续航明显下降，最常见 |
| 刹车拖滞 | 抬起车轮转动，听有没有摩擦声 | 持续耗电 |
| 轴承缺油 | 转动车轮感受阻力 | 阻力增大 |
| 载重与逆风 | 记录载重与路况 | 影响显著 |
| 低温 | 冬季对比夏季续航 | 铅酸尤其明显 |
| 控制器或电机异常 | 需专业检测 | 需专业人员判断 |

**判定口径**：胎压与刹车是续航下降里最高频也最便宜的两个因素，先查这两项，再怀疑电池。

## 四、铅酸与锂电保养对照

| 项目 | 铅酸电池 | 锂电池 |
|---|---|---|
| 充电时机 | 剩余 30%-40% 时充 | 尽量在 20%-80% 区间循环 |
| 充电时长 | 通常 6-8 小时，变灯后浮充 1-2 小时 | 充满即停，不要长期整夜插着 |
| 能否天天充 | 可以，但避免每次都深度放电 | 可以，避免每次都充到满格 |
| 亏电危害 | 硫化，容量永久损失 | 过放损伤电芯与保护板 |
| 久放处理 | 每 1-2 个月补电一次 | 存放保持 50%-60% 电量，定期检查 |
| 低温 | 容量明显下降，回暖恢复 | **0℃ 以下不要充电**（析锂风险） |
| 高温 | 避免暴晒后立即充电 | 避免高温环境充电 |
| 循环寿命 | 约 300-500 次 | 约 800-1200 次（磷酸铁锂更长） |
| 充电器 | 必须用匹配规格 | **必须用原装匹配款，不同体系不能通用** |

**关键认知**：铅酸怕亏电，锂电怕过充过放与高温。用铅酸的习惯养锂电（比如"充满再浮充两小时"）会缩短锂电寿命。

---

## 五、充电环境要求

| 要求 | 说明 |
|---|---|
| 位置 | 室外或专用充电场所，**不在室内、楼道、疏散通道** |
| 通风 | 干燥、通风、远离可燃物 |
| 时间 | 尽量白天或有人看护时充电，避免整夜无人看管 |
| 距离 | 与可燃物保持距离，下方不堆放杂物 |
| 线路 | 使用固定插座与合规线缆，**不飞线、不私拉乱接** |
| 顺序 | 先接电池端再接电源；充满后先断电源再拔电池端 |

## 六、热失控处置流程（电池起火风险）

| 阶段 | 处置 |
|---|---|
| 发现鼓包、发烫、异味、漏液 | 立即停止充电与使用，**在确保安全前提下断开电源**，把电池移到空旷处，联系售后或专业回收 |
| 出现冒烟 | 人员立即撤离，关闭房门，拨 **119**，不要自行搬动冒烟电池 |
| 已起火 | 立即撤离并拨 119；锂电池火势猛、会复燃、有有毒烟气，注意防烟 |
| 灭火后 | 即使表面扑灭也要持续警戒，锂电可能复燃，交由专业人员处理 |

**不要做的事**：不要刺破、挤压、拆解鼓包电池；不要用水少量浇泼后离开；不要把冒烟电池搬进电梯或室内；不要把废电池丢进普通垃圾桶。

## 七、脚本用法

```bash
python scripts/ebike_battery_check.py --text "冬天续航短了一半，电池用了两年铅酸"
python scripts/ebike_battery_check.py --file 描述.txt --out 结果.md
```

| 参数 | 说明 |
|---|---|
| `--text` | 直接给现象描述 |
| `--file` | 从文件读描述 |
| `--out` | 结果落盘路径 |
| `--format` | `md`（默认）或 `json` |
| `--battery` | 电池类型：`lead`（铅酸）或 `lithium`（锂电） |
| `--selftest` | 跑内置样例自检 |

脚本按现象匹配故障树，输出排查顺序、对应电池类型的保养要点，命中鼓包、发烫、冒烟等情形时输出**停用与撤离**提示。

> 脚本只做关键词匹配，**不代表电池检测结论**。续航判断要连续记录三次做对比。

## 八、人工确认清单（这步不能省）

- [ ] 胎压测过，不是靠目测
- [ ] 抬起车轮转过，确认无刹车拖滞
- [ ] 电池类型确认过（看铭牌，不要猜）
- [ ] 充电器是原装匹配款，参数对得上
- [ ] 充电位置不在室内、楼道、疏散通道
- [ ] 没有飞线、没有私拉乱接
- [ ] 电池无鼓包、无发热、无异味、无漏液
- [ ] 连续记录三次续航，有对比数据

## 九、最常见的坑

**坑一：续航短就换电池。**
胎压不足是最常见也最便宜的原因。先测胎压、查刹车拖滞，再考虑电池。

**坑二：用铅酸的习惯养锂电。**
"充满再浮充两小时""用到没电再充"对锂电都是伤害。

**坑三：冬天充电。**
0℃ 以下给锂电充电会析锂，严重损伤电芯并有安全风险。低温环境下先回温到室温再充。

**坑四：室内或楼道充电。**
这是电动车火灾伤亡的主要场景。电池热失控火势猛、有有毒烟气，疏散通道被堵的后果不堪设想。

**坑五：飞线充电。**
线缆长期摩擦、日晒雨淋，绝缘破损后短路风险极高，且违规。

**坑六：混用充电器。**
三元锂与磷酸铁锂的充电器参数不同，**不能通用**。电压电流不匹配会损伤电池甚至引发危险。

**坑七：电池鼓包还凑合用。**
鼓包是热失控前兆，不是"还能骑一阵"。立即停用更换。

**坑八：久放不管。**
铅酸久放会硫化，锂电久放会过放。长期不用也要定期补电。

**坑九：把电池带回家充。**
等于把热失控风险搬进居住空间，严禁。

## 十、边界与免责

- 本技能**不替代**电池检测、维修与更换服务，续航是否真的衰减需专业设备检测
- 电池类型、容量、充电参数差异大，**以车辆与电池铭牌、产品说明书为准**
- 涉及电池拆解、改装、并联、更换电芯的操作，应由专业人员处理
- 出现鼓包、发热、异味、冒烟时，人身安全优先，立即撤离并求助专业力量
- 充电与停放的合规要求**以当地消防与物业的具体规定为准**
