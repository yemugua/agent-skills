# 视频号小店带货合规核查

## 用途

对视频号小店带货经营做逐项合规核查，定位阻断项与风险项，给出可落地的整改清单。适合：

- 开通视频号小店/橱窗前的准入自查
- 不确定带货类目要不要报白、要什么资质
- 商品被下架/扣分/限流后的整改定位
- 直播话术与「站外交易」红线确认

## 输入

一份 Markdown 采集表（表格 `| 字段 | 值 |` 或 `字段：值` 冒号行均可），字段见
`templates/带货合规采集表.md`。核心字段：

| 字段 | 说明 |
|------|------|
| 账号主体类型 | 企业 / 个体工商户 / 个人 |
| 是否开通视频号小店 | 是 / 否 |
| 是否缴纳足额保证金 | 是 / 否（不同类目标准不同） |
| 带货类目 | 如「食品、美妆」；命中定向准入类目会触发资质核查 |
| 类目资质是否已报备 | 定向准入类目报白/上传资质 |
| 是否持有对应经营资质 | 许可证/备案凭证 |
| 商品标题主图是否夸大或虚假 | 绝对化用语/功效夸大 |
| 是否存在价格违规 | 虚构原价/先涨后降/虚假折扣 |
| 是否销售禁售商品 | 假货/处方药/野生动物制品/公民信息等 |
| 是否执行7天无理由退货 / 发货时效是否达标 / 客服响应是否及时 | 履约与体验分 |
| 是否直播带货 / 直播话术是否违规 / 是否引导站外或私下交易 | 直播红线 |
| 是否收到过违规扣分或处罚 / 品质退款率或投诉率是否偏高 / 商品是否经过质检或资质备案 | 记录与品质 |

## 输出

多段 Markdown 报告：

1. **结论摘要**：总体结论（通过 / 有风险 / 不通过）+ 阻断/风险计数 + 处置建议
2. **分项核查**：店铺与保证金 / 类目准入与资质 / 商品信息（标题主图价格禁售）/ 售后与物流 / 直播话术与场外交易 / 违规与品质记录
3. **阻断项与风险/待办**：逐条列出，阻断项注明平台后果（下架/扣分/清退）
4. **整改操作指引**：标准 8 步带货合规清单
5. **边界与纪律**：依据《广告法》《价格法》《电子商务法》与平台公开规则，不替代官方规则与法律意见

## 使用

```bash
python3 scripts/channels_shop_compliance_check.py <采集表.md>
```

退出码：`0` 正常；`2` 未读取到有效字段（打印待补正提示）。

## 判定口径

- **不通过（阻断）**：未开通小店/未缴保证金带货、定向准入类目无资质报备、无对应经营资质、商品文案夸大虚假、价格违规、销售禁售商品、直播话术违规、引导站外/私下交易。
- **有风险**：未执行 7 天无理由、发货时效不达标、客服不及时、有违规扣分记录、品质退款率偏高、商品无质检备案。
- **通过**：全部核查项满足。

## 红线（本技能不会做的）

- 不教唆规避报白、虚假标注类目或绕开平台交易。
- 不替代平台官方规则与审核结论，不构成法律意见。
