# 视频号小店类目准入与资质清单

## 一、两类类目

| 类型 | 说明 | 操作 |
|------|------|------|
| 普通类目 | 平台开放经营，满足基础资质即可 | 入驻时选择类目，缴纳保证金后上架 |
| 定向准入类目 | 平台限定经营主体与资质，须审核 | 提交资质报白（准入申请），通过后才能带货 |

## 二、常见定向准入/需资质类目

| 类目 | 核心资质/要求 | 常见坑 |
|------|---------------|--------|
| 预包装/散装食品 | 食品经营许可证或预包装食品备案 | 无证卖自制食品、超范围经营 |
| 保健食品 | 食品经营资质 + 保健食品注册/备案凭证 | 宣称疾病预防治疗功效（违法） |
| 医疗器械 | 二类经营备案 / 三类经营许可 | 个人带货、无广告审查 |
| 药品 | 严禁带货推广（处方药禁止） | 任何形式的变相药品推广 |
| 化妆品 | 普通化妆品备案 / 特殊化妆品注册证 | 功效宣称无依据、销售“三无”产品 |
| 图书 | 出版物经营许可证 | 无证售书、售卖盗版 |
| 母婴/儿童用品 | 配方食品须配方注册；儿童用品注意 3C | 忽略强制认证 |
| 珠宝玉石文玩 | 定向准入，质检/来源证明 | 假货、二次溢价炒作 |
| 宠物食品/药品 | 饲料经营资质；兽药经营许可 | 宠物药当人药卖 |

## 三、保证金口径

- 视频号小店按经营类目缴纳保证金，不同类目金额不同（常见从数千到数万元）。
- 未缴足保证金：无法上架商品、无法使用部分带货能力，严重将被清退。
- 违规扣罚可能动用保证金；关店时符合条件的可申请退还。

## 四、准入流程（标准顺序）

1. 完成小店主体认证（企业/个体工商户）。
2. 选择经营类目，确认是否定向准入。
3. 定向准入类目：上传资质 → 报白审核 → 通过。
4. 缴纳足额保证金。
5. 上架商品，进入运营。

## 五、禁售商品（部分，以平台禁售清单为准）

假货仿品、处方药、野生动物及其制品、管制刀具/枪支弹药、公民个人信息、
走私与非法代购、作弊器材、赌博/洗钱服务、伪造变造证件等。

> 本清单依据视频号小店公开规则整理，**以平台最新类目表与禁售清单为准**。
