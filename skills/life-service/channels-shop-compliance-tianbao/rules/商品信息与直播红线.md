# 视频号带货商品信息与直播红线

## 一、商品信息合规（标题/主图/详情）

### 1. 绝对化与夸大用语（禁用）

- 「最好 / 第一 / 最强 / 顶级 / 国家级 / 绝对 / 100% / 永久」等绝对化用语。
- 「根治 / 包治 / 特效 / 无副作用 / 零风险 / 稳赚」等虚假或无法证实的宣称。
- 化妆品功效宣称须有依据，食品不得宣称疾病预防治疗功能。

### 2. 价格合规

- 不得虚构原价：标称“原价”须真实成交过。
- 不得先涨后降、虚假折扣：促销价须真实让利。
- 明码标价，标注清晰的计价单位与规格。

### 3. 类目与属性

- 商品须放入正确类目，不得错放类目规避资质审核。
- 关键属性（规格、成分、产地、保质期）如实填写。

## 二、售后与履约

| 项 | 要求 | 违规后果 |
|----|------|----------|
| 7 天无理由 | 适用商品应支持（法定例外除外：定制、鲜活、在线下载等） | 处罚 + 体验分下降 |
| 发货时效 | 现货承诺时效内发货（通常现货 48 小时内） | 赔付/扣分 |
| 客服响应 | 及时响应售后与咨询 | 纠纷率上升、体验分下降 |

- 体验分/带货口碑分直接影响流量分发与功能使用，须当作生命线维护。

## 三、直播带货红线

| 红线 | 说明 |
|------|------|
| 虚假宣传 | 夸大功效、虚构销量、演戏炒作、“亏本福利”话术造假 |
| 承诺收益/疗效 | 不得承诺投资回报、治疗效果 |
| 诱导场外交易 | 严禁“加微信下单”“扫码转账”“线下交易”绕开小店 |
| 诋毁同行 | 不得贬低其他主播/商家/商品 |
| 违规演示 | 危险演示、违规使用平台标识 |

## 四、违规后果阶梯（平台口径）

- 轻微：警告、下架商品、扣分。
- 中度：限制带货功能、冻结部分能力、扣罚保证金。
- 严重：清退店铺、扣除全部保证金、封禁账号，涉嫌违法的移交监管。

## 五、主要依据

《中华人民共和国广告法》《中华人民共和国价格法》《中华人民共和国电子商务法》
《中华人民共和国消费者权益保护法》《网络直播营销管理办法（试行）》及微信视频号小店
《商品信息发布规范》《违规管理规则》《直播带货规范》。
