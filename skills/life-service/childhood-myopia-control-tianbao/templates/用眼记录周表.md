## 四、环境核对表

- [ ] 读写距离约一尺（33 厘米）
- [ ] 胸口离桌沿约一拳
- [ ] 握笔处到笔尖约一寸
- [ ] 双脚平放地面，桌椅高度匹配
- [ ] 房间顶灯与台灯同时开启，光从左前方来
- [ ] 不在全黑环境看屏幕
- [ ] 屏幕观看距离为对角线的 3 倍以上
- [ ] 不在晃动的车内看书或看屏幕

## 五、需要尽快就诊的信号（出现即填并就医）

- [ ] 视力突然下降
- [ ] 经常眯眼、歪头、凑得很近看
- [ ] 遮盖单眼时明显抗拒或哭闹
- [ ] 眼位偏斜或眼球抖动
- [ ] 瞳孔区发白、发黄或有异常反光
- [ ] 眼红眼痛畏光伴视力下降
- [ ] 眼前闪光感、黑影突然增多
- [ ] 戴镜后仍看不清

## 六、复诊提问清单

- 孩子目前的屈光状态和眼轴增长情况如何？
- 需要配镜吗？什么情况下必须戴、什么情况下可以不戴？
- 角膜塑形镜或药物干预是否适合我家孩子？风险与随访要求是什么？
- 复查间隔按多久安排？
- 度数控制在什么范围内算进展慢？
- 户外和用眼安排上还有哪些需要调整的？
