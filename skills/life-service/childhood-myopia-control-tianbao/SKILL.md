# 儿童近视防控与户外用眼管理

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 给出户外时长、读写姿势、休息间隔的管理口径 | 判断是否需要配镜、配多少度、是否需要散瞳 |
| 按年龄分段给出屏幕时间上限 | 推荐角膜塑形镜、低浓度阿托品等具体医疗手段与用法 |
| 提示需要尽快就诊的眼部异常信号 | 承诺某种方法能让度数下降或「治好近视」 |
| 整理周记录表与复诊提问清单 | 解读验光单、眼轴、角膜地形图并下结论 |
| 说明常见防控措施的作用与局限 | 建议自行停用或更改医生开具的眼镜与用药 |

**就医红线（出现任一条，尽快到眼科就诊；标注急诊的直接去急诊）**

- 视力突然下降、视物模糊明显加重
- 经常眯眼、歪头、凑得很近看东西、单眼遮盖时哭闹（提示单眼视力差）
- 眼位偏斜、眼球不自主抖动（眼球震颤）、歪头视物
- 瞳孔区发白、发黄或有反光（白瞳征）—— 尽快就诊，不可拖延
- 眼红、眼痛、畏光、流泪伴视力下降
- 眼前闪光感、黑影突然增多、视野缺损
- 眼部外伤、化学物入眼、异物入眼 —— 急诊
- 戴镜后仍然看不清，或短期内度数快速加深
- 3 岁以下婴幼儿家长明显怀疑视力异常，或早产儿、有家族眼病史 —— 按医嘱做筛查
- 伴头痛、恶心呕吐、眼球突出

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「孩子每天要户外多久」 | 用 |
| 「近视了要不要一直戴眼镜」 | 用，说明由医生决定并解释常见误区 |
| 「写作业坐姿怎么纠正」 | 用 |
| 「孩子总揉眼睛、眯眼看电视」 | 只作就医提示 |
| 「角膜塑形镜好不好」 | 用，只说明需专业验配与随访，不推荐具体产品 |
| 「护眼灯、防蓝光眼镜有用吗」 | 用，说明证据局限 |
| 「度数能不能降下来」 | 用，说明近视不可逆、防控目标是延缓进展 |

## 三、完整工作流

1. **先排红线**：逐条核对就医红线，命中则停止管理建议，转为就诊提示。
2. **确认年龄分段**：0-3 岁、3-6 岁、6-18 岁三段的户外、屏幕与休息口径不同，先定段。
3. **盘户外时长**：按 `rules/户外时长与用眼规则.md` 统计每日与每周户外累计时长，判断是否达标。
4. **盘近距离用眼**：记录读写、乐器、绘画、屏幕等所有近距离项目，不只是手机。
5. **定休息规则**：按年龄设定单次近距离用眼时长与休息时长，用定时器执行。
6. **改环境**：读写距离、照明、桌椅高度逐项核对。
7. **建立屈光档案**：按医嘱定期验光，记录度数、眼轴与随访时间。

## 四、核心规则与要件库

生成建议前，**必须先读**：

- `rules/户外时长与用眼规则.md`：年龄分段口径、户外时长、读写距离、屏幕时间、照明与桌椅。
- `templates/用眼记录周表.md`：每日户外、近距用眼、屏幕、症状记录表与复诊提问清单。

不得把「护眼模式」「防蓝光」「眼贴按摩」说成可以防控近视；不得因度数低就建议不戴镜（是否戴镜由医生判断）。近视不可逆，防控目标是延缓进展。

## 五、脚本用法

```
python scripts/outdoor_vision_calc.py --file week.json
python scripts/outdoor_vision_calc.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`age` 年龄，`days` 为 7 天记录，含户外分钟、近距离用眼分钟、屏幕分钟 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--json` | 以 JSON 输出 |
| `--selftest` | 运行自检 |

脚本输出周户外达标天数、日均缺口、屏幕时间是否超限及按年龄的近距离用眼上限。**仅作记录与达标判定，不涉及任何医疗处置。**

## 六、人工确认清单

- [ ] 就医红线已排除，尤其眯眼歪头、眼位偏斜与瞳孔发白
- [ ] 年龄分段已确认，口径按对应年龄段执行
- [ ] 户外时长为「户外光照下」时长，不包括室内体育课与车内时间
- [ ] 近距离用眼包含写作业、练琴、画画、拼搭与屏幕，未只统计手机
- [ ] 读写距离与照明已现场核对，不是口头要求
- [ ] 桌椅高度与孩子身高匹配
- [ ] 眼镜、角膜塑形镜、药物的使用严格遵医嘱
- [ ] 定期验光随访时间已记录

## 七、最常见的坑

1. **把室内活动当户外**：防控相关的关键是户外自然光照，体育馆、家里阳台隔着玻璃算不上同等效果。
2. **晚上出去也算数**：夜间的光照强度远低于白天，达不到同样的作用，应优先安排在白天。
3. **只盯手机不管作业**：写作业、练琴、拼搭同样是近距离用眼，往往时间更长。
4. **度数低就不戴镜**：是否戴镜由医生结合视力、眼位和用眼需求决定，不是按度数高低自行判断。
5. **相信戴镜会加深近视**：不规范配镜和随访才是问题，规范矫正本身不是加深的原因。
6. **买护眼灯、防蓝光眼镜当防控**：照明要足够且不刺眼，但这类产品不能替代户外和用眼习惯管理。
7. **用眼贴、按摩仪治近视**：真性近视不可逆，这类手段不能降低度数。
8. **一天猛补户外**：户外时长应分散到每天，累积效应比周末一次性补更重要。

## 八、边界与免责

本技能提供儿童近视防控的日常管理口径与记录工具，不构成诊断或治疗方案。户外时长、屏幕时间、休息间隔的具体数值因年龄、屈光状态、地区指南版本而异，**以最新版儿童青少年近视防控相关指南和眼科医师的判断为准**。是否配镜、是否使用角膜塑形镜或药物干预，必须由眼科医师面诊后决定。出现就医红线中的任一情况，请尽快就诊。
