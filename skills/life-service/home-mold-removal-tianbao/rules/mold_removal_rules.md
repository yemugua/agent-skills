# 除霉判定与处理规则表

生成处理方案前先读本文件，不要凭印象写。

---

## 一、霉变 / 返碱 / 污渍 三分判定

| 判据 | 霉变 | 返碱 | 普通污渍 |
|---|---|---|---|
| 颜色 | 黑、绿、灰黑斑 | 白色或灰白色粉状结晶 | 黄褐、灰褐均匀附着 |
| 遇水行为 | 不化开，会散开成孢子样 | **遇水化开，干燥后重新析出** | 可擦掉，不留粉状残留 |
| 气味 | 有明显霉味或土腥味 | 无味或轻微 | 视来源而定 |
| 触感 | 表面有绒毛感或颗粒感 | 干燥粉状 | 滑腻或黏着 |
| 范围 | 成片，有扩散趋势 | 沿墙根、砖缝、水痕路径 | 集中在接触面或上方 |

### 三个快速验证动作

1. **干擦测试**：用白色纸巾干擦，看是否留下黑色或绿灰色痕迹。
2. **湿擦测试**：微湿布擦一小块，观察白色粉状物遇水是否化开。
3. **闻味测试**：靠近墙面闻霉味是否明显。返碱没有霉味。

## 二、表面浮霉与深层霉变判定

| 判据 | 表面浮霉 | 深层霉变 |
|---|---|---|
| 轻擦表现 | 表面霉层能擦掉，露出底色 | 擦掉表层后底下仍发黑 |
| 铲除试判 | 铲掉浮层后基层干净 | 基层本身发黑、发软、有霉丝 |
| 气味 | 通风后可减轻 | 通风后霉味不减 |
| 湿擦后 | 无异常 | 擦拭后很快重新出现 |
| 处理范围 | 可自行处理 | **必须转专业机构** |

**判定动作**：选一小块不显眼位置轻铲表层。露出干净基层为浮霉；底下仍黑为深层霉变。

## 三、位置与湿源对应表

| 位置 | 典型湿源 | 先做什么 |
|---|---|---|
| 墙角、外墙侧墙角 | 冷凝水、外墙渗水、保温层缺陷 | 查外墙、控湿度，不要先刷漆 |
| 天花板与墙面交接处 | 上层渗漏、管线渗漏 | 下楼看对应位置天花，按渗漏排查流程走 |
| 墙纸背面、墙布下 | 墙纸透气性差，湿气被困 | 局部起拱处开小口排湿，不整面撕除 |
| 踢脚线后、柜体背面靠墙处 | 墙面渗水、冷凝、缝隙进湿 | 移开柜体或踢脚线，检查背面水渍 |
| 衣柜、鞋柜内部 | 衣物未干放入、柜内不通风、地面返潮 | 清空通风、彻底晾干衣物后再放回 |
| 卫生间瓷砖缝、缝隙 | 长期潮湿、清洁不彻底 | 保持干燥、清理缝隙、改善排风 |
| 冰箱、洗衣机周边 | 设备冷凝或渗漏 | 排查设备本身 |

**规律**：霉变分布位置会告诉你湿源在哪。先找湿源，再处理霉斑。

## 四、四步处理流程

### 第一步：断湿源

- 找到并处理造成潮湿的原因（渗漏、冷凝、排水、堆放过密）
- 无法立刻解决时先做物理隔离：移开柜体、垫高物品、留通风缝

### 第二步：通风干燥

- 打开门窗形成对流通风；单向开窗不换气效果有限
- 阴雨天与湿度高的时段不宜长时间开窗
- 必要时使用除湿设备

### 第三步：清洁除霉

- 佩戴手套与口罩，作业期间保持通风
- 小面积表层：按说明书使用专用除霉剂，先小面积试用，静置后按说明擦除
- 处理后必须彻底干燥
- **墙面大面积不建议使用含氯消毒剂**（见第五节）

### 第四步：防霉收尾

- 基面完全干燥后按说明书做防霉涂层或防水涂层
- 改善通风条件，减少湿气滞留
- 定期复查原位置

## 五、安全红线

**不得直接用含氯消毒剂或强酸强碱处理大面积霉菌。**

原因：霉菌孢子受强刺激后会大量释放到空气中；含氯消毒剂遇酸性物质或与其他清洁剂混合会产生刺激性气体，加重呼吸道敏感者症状，对婴幼儿、老人、哮喘患者尤其危险。

| 情形 | 正确做法 |
|---|---|
| 小面积表层霉斑 | 按说明书用专用除霉产品，先小面积试用，保持通风，佩戴手套口罩 |
| 大面积霉变 | 转专业除霉机构，不要自行喷洒化学药剂 |
| 儿童、老人、孕妇居住房间 | 优先物理方式：断湿源、干燥、拆除受影响的表层材料；必须用药时先咨询专业人员 |
| 有呼吸道疾病的人 | 不参与作业；作业期间不进入房间；完工后充分通风再进入 |
| 想喷含氯消毒液"杀得更彻底" | 不建议，刺激性气体与过敏加重是真实风险 |

**其他安全要求：**

- 任何除霉药剂都不要与含氯消毒剂混用，也不要与酸性清洁剂混用
- 按产品说明书使用，不同产品不混用
- 作业时开窗通风，人不要长时间待在喷洒空间内
- 处理过的织物与刷具单独清洗，不接触食物与餐具

## 六、必须转专业机构的情形

1. 霉变面积大（单面墙超过一平方米，或多个房间同时出现）
2. 深层霉变：霉斑渗入底层、铲除表层后底层仍发黑、通风后霉味不减
3. 霉变伴随墙体渗水、水渍、返潮痕迹
4. 墙体有裂缝、空鼓、脱落等结构问题
5. 同一位置反复处理两次以上仍在复发
6. 家庭成员有呼吸道敏感、哮喘、婴幼儿或孕妇居住在该房间

---

## 七、防复发要点

| 措施 | 具体做法 |
|---|---|
| 湿度控制 | 梅雨季与回南天使用除湿设备；密闭空间尤其重要 |
| 通风 | 每天定时开窗形成对流；卫生间与衣柜干燥后再关门 |
| 物品干燥 | 衣物、被褥、地毯完全晾干再放入柜内或铺用 |
| 间距 | 家具与墙面留空隙，不要紧贴；柜内不要塞满 |
| 定期检查 | 每月看墙角、踢脚线后、柜内、卫生间缝隙 |
| 渗漏优先 | 渗水导致的霉变必须先修漏源 |

## 八、常见误判清单

1. 不判是霉还是返碱就买除霉剂——白色返碱用除霉剂是无效覆盖
2. 直接喷含氯消毒液处理大面积霉菌——强刺激释放孢子，混合会产生刺激性气体
3. 只清洁不断湿源——每三个月长一次
4. 擦掉表层就以为处理完——底层仍黑说明是深层霉变
5. 衣物没干就塞进衣柜——衣柜长霉最常见的直接原因
6. 柜子紧贴墙面——背后形成不通风的湿袋
7. 卫生间除霉后不做干燥就关门——下次长霉更快
8. 把返碱当墙面脏了使劲擦——破坏表层，问题来自干燥与防水侧
9. 儿童房间用强力化学药剂——优先物理方式
10. 处理完不复查——两周后目视复查一次最省事
