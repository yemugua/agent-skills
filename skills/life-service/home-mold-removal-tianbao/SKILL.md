# 家居除霉与防霉核查（home-mold-removal）

长霉这件事，**第一步不是买除霉剂，而是判断这是不是霉**。白色粉状结晶遇水就化开，那是返碱；黑绿斑带霉味才是霉变。判错了，用错产品，墙面就白处理一次。

第二步是**判断是表面浮霉还是深层霉变**——这一条直接决定能不能自己处理。

这个技能做五件事：**判性质** → **定深浅** → **定位置** → **按四步处理** → **防复发**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 区分霉变、返碱与普通污渍 | ❌ 承诺大面积霉变的清除效果 |
| 区分表面浮霉与深层霉变 | ❌ 代替专业除霉机构处理大面积霉变 |
| 给出断湿源、通风、清洁、防霉四步流程 | ❌ 判断墙体渗水、结构裂缝等根源问题 |
| 列出安全红线与人群禁忌 | ❌ 指导在儿童与老人房间大面积使用化学药剂 |
| 说明防复发的湿度与通风要点 | ❌ 判断室内空气指标的合格与否 |

**遇到以下情况，停止自行处理，转交专业除霉机构或先解决根源问题：**

- 霉变面积大（单面墙超过一平方米，或多个房间同时出现）
- 深层霉变：霉斑已渗入底层、铲除表层后底层仍发黑、有明显霉味且通风不改善
- 霉变伴随墙体渗水、水渍、返潮痕迹
- 墙体有裂缝、空鼓、脱落等结构问题
- 反复处理两次以上仍在同一位置复发
- 家庭成员有呼吸道敏感、哮喘、婴幼儿或孕妇居住在该房间

## 二、完整工作流

```
第 1 步  判性质：霉 / 返碱 / 污渍（看颜色、遇水行为、有无霉味）
第 2 步  判深浅：表面浮霉 vs 深层霉变（轻擦、湿擦、铲除试判）
第 3 步  定位置与湿源：墙角 / 墙纸后 / 踢脚线后 / 柜内 / 卫生间缝隙
第 4 步  先读规则文件 rules/mold_removal_rules.md（判定表 + 四步流程 + 红线）
第 5 步  跑判定脚本
    python scripts/mold_check.py --text "墙角发黑有霉味，擦掉一层还是黑"
第 6 步  按四步处理：断湿源 → 通风 → 清洁 → 防霉
第 7 步  建立湿度与通风的日常机制，观察是否复发
```

**顺序不能颠倒**：不先断湿源就清洁，等于每三个月重做一次。

## 三、第 1 步：霉、返碱、污渍三分判定

| 判据 | 霉变 | 返碱 | 普通污渍 |
|---|---|---|---|
| 颜色 | 黑、绿、灰黑斑 | 白色或灰白色粉状结晶 | 黄褐色、灰褐色均匀附着 |
| 遇水行为 | 不化开，会散开成孢子样 | **遇水化开，干燥后重新析出** | 可擦掉，擦后不留粉状残留 |
| 气味 | 有明显霉味或土腥味 | 无味或轻微 | 视来源而定 |
| 触感 | 表面有绒毛感或颗粒感 | 干燥粉状 | 滑腻或黏着 |
| 范围 | 成片、有扩散趋势 | 沿墙根、砖缝、水痕路径 | 集中在接触面或上方 |
| 一句话判据 | 黑绿斑且有霉味 | 白霜遇水化开 | 能擦掉且不留结晶 |

**快速验证三步：**

1. **干擦测试**：用白色纸巾干擦，看纸上是否留下黑色或绿灰色痕迹。
2. **湿擦测试**：微湿布擦一小块，观察白色粉状物遇水是否化开。
3. **闻味测试**：靠近墙面闻霉味是否明显。返碱没有霉味。

> 判定口径完整版在 `rules/mold_removal_rules.md`。**误判成霉变而用杀菌类产品处理返碱，等于在墙面上加一层没用的东西。**

## 四、第 2 步：表面浮霉 vs 深层霉变

| 判据 | 表面浮霉 | 深层霉变 |
|---|---|---|
| 轻擦表现 | 表面霉层能被擦掉，露出底色 | 擦掉表层后底下仍发黑 |
| 铲除试判 | 铲掉浮层后基层干净 | 基层本身发黑、发软、有霉丝 |
| 气味 | 通风后可减轻 | 通风后霉味不减 |
| 湿擦后 | 无异常 | 擦拭后很快重新出现 |
| 处理范围 | 可自行处理 | **必须转专业机构** |

**判断动作**：选一小块不显眼的位置，轻轻铲一下表层。**露出干净基层 = 表面浮霉；底下仍黑 = 深层霉变。**

---

## 五、第 3 步：位置与湿源对应表

| 位置 | 典型湿源 | 先做什么 |
|---|---|---|
| 墙角、外墙侧墙角 | 冷凝水、外墙渗水、保温层缺陷 | 查外墙、控湿度，**不要先刷漆** |
| 天花板与墙面交接处 | 上层渗漏、管线渗漏 | 下楼看对应位置天花，走上一节渗漏排查 |
| 墙纸背面、墙布下 | 墙纸本身透气性差，湿气被困在后面 | 局部起拱处开小口排湿，不要整面撕除 |
| 踢脚线后、柜体背面靠墙处 | 墙面渗水、冷凝、缝隙进湿 | 移开柜体或踢脚线，检查背面是否有水渍 |
| 衣柜、鞋柜内部 | 衣物未干就放入、柜内不通风、地面返潮 | 清空通风、彻底晾干衣物、再放回 |
| 卫生间瓷砖缝、缝隙 | 长期潮湿、清洁不彻底 | 保持干燥、清理缝隙、改善排风 |
| 冰箱、洗衣机周边 | 设备冷凝或渗漏 | 排查设备本身 |

**规律**：霉变的分布位置会告诉你湿源在哪。**先找湿源，再处理霉斑。**

---

## 六、第 4 步：四步处理流程

```
断湿源  →  通风干燥  →  清洁除霉  →  防霉收尾
```

**第一步：断湿源**

- 找到并处理造成潮湿的原因（渗漏、冷凝、排水、堆放过于紧密）
- 无法立刻解决时，先做物理隔离：移开柜体、垫高物品、留出通风缝

**第二步：通风干燥**

- 打开门窗形成对流通风；单向开窗不换气，效果有限
- 阴雨天与湿度高的时段不宜长时间开窗
- 必要时使用除湿设备，把湿度控制在舒适区间

**第三步：清洁除霉**

- 佩戴手套与口罩，作业期间保持通风
- 小面积表层：按产品说明书使用专用除霉剂，**先小面积试用**，静置后按说明擦除
- 处理后必须彻底干燥，否则残留水分会再次长霉
- **墙面大面积不建议使用含氯消毒剂**（原因见第七节）

**第四步：防霉收尾**

- 待基面完全干燥后按说明书做防霉涂层或防水涂层
- 改善通风条件，减少湿气滞留
- 定期复查原位置

## 七、安全红线（这一节最重要）

**不得直接用含氯消毒剂（漂白水类）或强酸强碱处理大面积霉菌。**

原因很实在：霉菌孢子受强刺激后会大量释放到空气中，同时含氯消毒剂遇酸性物质或与其他清洁剂混合会产生刺激性气体。这会**加重呼吸道敏感者的症状**，对婴幼儿、老人、哮喘患者尤其危险。

| 情形 | 正确做法 |
|---|---|
| 小面积表层霉斑 | 按说明书用专用除霉产品，先小面积试用，保持通风，佩戴手套口罩 |
| 大面积霉变 | 转专业除霉机构，不要自行喷洒化学药剂 |
| 儿童、老人、孕妇居住的房间 | 优先物理方式：断湿源、干燥、拆除受影响的表层材料；必须用药时先咨询专业人员 |
| 有呼吸道疾病的人 | 不参与作业；作业期间不进入房间；完工后充分通风再进入 |
| 打算喷含氯消毒液"杀得更彻底" | **不建议**，刺激性气体与过敏加重是真实风险 |

**其他安全要求：**

- 任何除霉药剂都**不要与含氯消毒剂混用**，也不要与酸性清洁剂混用
- 除霉剂按产品说明书使用，不同产品不混用
- 作业时开窗通风，人不要长时间待在喷洒空间内
- 处理过的织物、刷具单独清洗，不要接触食物与餐具

## 八、防复发要点

| 措施 | 具体做法 |
|---|---|
| 湿度控制 | 梅雨季与回南天使用除湿设备；密闭空间尤其重要 |
| 通风 | 每天定时开窗形成对流；卫生间与衣柜做到干燥后再关门 |
| 物品干燥 | 衣物、被褥、地毯必须完全晾干再放入柜内或铺用 |
| 间距 | 家具与墙面留出空隙，不要紧贴；柜内不要塞满 |
| 定期检查 | 每月看一眼墙角、踢脚线后、柜内、卫生间缝隙 |
| 渗漏优先 | 渗水导致的霉变必须先修漏源，否则清洁只是暂时 |

## 九、脚本用法

```bash
python scripts/mold_check.py --text "墙角发黑有霉味，擦掉一层还是黑"
python scripts/mold_check.py --file 情况.json --out 结果.md
```

| 参数 | 说明 |
|---|---|
| `--text` | 直接描述霉变情况 |
| `--file` | 从文件读，支持 `.txt` / `.md` / `.json`（JSON 用 `{"desc": "..."}`） |
| `--out` | 结果落盘路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本做三件事：判定是霉变还是返碱或污渍、判定是表层还是深层、按位置给出对应湿源与先做什么；命中安全红线时直接输出"转专业机构"的结论。

> 脚本是关键词匹配，**不等于现场判断**。判定表只给你一个起点，最终要靠干擦、湿擦、铲除三个实测。

## 十一、最常见的坑

**坑一：不判是霉还是返碱就买除霉剂。**
白色返碱用除霉剂处理，等于在墙面上加一层无效覆盖，还多花钱。先做三个测试再决定。

**坑二：直接喷含氯消毒液处理大面积霉菌。**
强刺激会让孢子大量释放，含氯遇酸或与其他清洁剂混用会产生刺激性气体，加重过敏。这是本技能明确的安全红线。

**坑三：只清洁不断湿源。**
每三个月长一次，第四次就会放弃。除霉是收尾动作，断湿源才是主动作。

**坑四：擦掉表层就以为处理完了。**
底下仍然发黑说明是深层霉变，自行处理只会反复。深层霉变要转专业机构。

**坑五：衣物没干就塞进衣柜。**
这是衣柜长霉最常见的直接原因。衣物完全晾干再放入，是最便宜的防霉措施。

**坑六：柜子紧贴墙面。**
背后形成"不通风的湿袋"，一旦墙面渗水或冷凝就直接长霉。留出空隙。

**坑七：卫生间除霉后不做干燥。**
刚处理完就关门，湿气闷在里面，下一次长霉更快。必须彻底干燥后再关门。

**坑八：把返碱当成墙面脏了使劲擦。**
返碱是水分带着盐分上泛，反复擦只会破坏表层。要从干燥和防水侧解决。

**坑九：儿童房间用强力化学药剂。**
优先物理方式：断湿源、干燥、必要时拆除受影响的表层材料。

**坑十：处理完不复查。**
处理后两周目视复查一次，有残留及时补做，比三个月后再全面返工省得多。

## 十二、边界与免责

- 本技能**不替代**专业除霉机构、渗漏处理、结构修复
- 霉菌种类与污染物限值涉及检测，**是否达标以有资质的检测结论为准**
- 药剂适用范围与使用浓度以**产品说明书**为准，不同产品不可混用
- 有基础疾病者、婴幼儿、孕妇居住空间的处理方式，建议咨询专业人员
- 涉及房屋渗漏导致霉变的责任划分，按**物业管理与相关主管部门要求**办理
