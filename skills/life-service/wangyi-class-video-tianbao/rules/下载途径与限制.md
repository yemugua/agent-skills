# 网易云课堂课程视频离线留存：途径、限制与合规边界

## 一、先判定：能不能下

| 归属类别 | 能否下载 | 允许的用途 |
| --- | --- | --- |
| 自有作品 | 可以，优先用原始导出文件 | 任意 |
| 已授权素材 | 可以 | 仅限授权范围内 |
| 作者开放了保存 | 可以，走官方途径 | 个人留存，**不得二次分发** |
| 第三方作品（未授权） | **不建议下载** | 不应用于任何对外场景 |

技术上能不能下载，和法律上能不能用，是两回事。

## 二、途径，按稳定性排序

| 途径 | 操作要点 |
| --- | --- |
| 原文件 | 优先。若是机构或主讲方，向课程运营索取原始文件最直接完整。 |
| 官方离线缓存 | 网易云课堂 App 支持课程视频离线缓存，只能在官方客户端内观看，不能导出成通用文件。 |
| 课件与字幕单独保存 | 课件 PDF、讲义与字幕通常可单独下载，这部分对学习帮助往往比视频更大。 |
| 联系机构获取 | 机构内部培训等场景，向主办方申请授权后的原始文件是最稳妥的方式。 |

## 三、本平台的真实限制

- 先分清免费公开课与付费课程，授权范围完全不同。
- 付费课程视频明确不允许下载与分发，本技能不提供任何绕过方式。
- 官方离线缓存只能在客户端内观看，不能导出成通用视频文件。
- 课件与字幕往往比视频更值得保存：PPT 与讲义知识密度高、体积小，且多数平台明确允许下载。
- 结课后访问权可能收回，重要内容应在学期内保存课件与笔记。

## 四、画质与水印

- 课程视频多为录制转码，画质以满足教学为目的；课件 PDF 通常更清晰也更便于检索。
- 课程视频含机构与教师署名，学习自用可以，去除署名后分发存在侵权风险。

## 五、合规红线

1. 不得去除作者署名后二次分发
2. 不得将他人作品搬运至自己的账号（含剪辑、配音后发布）
3. 不得下载或传播私密账号、付费内容
4. 受版权或 DRM 保护的内容不支持下载，也不提供任何破解方法
5. 商用前必须取得书面授权
6. 批量高频抓取可能违反平台服务协议，导致账号受限
