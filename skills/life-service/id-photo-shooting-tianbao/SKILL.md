# 证件照拍摄（id-photo-shooting）

自己拍证件照，**八成的退回原因不是拍得不好看，而是规格不对**。

尺寸差几十像素、分辨率只有 72 dpi、背景有影子、刘海遮了眉毛——这四件事任何一件都足以让系统拒收。

这个技能做三件事：**定规格 → 核指标 → 排退回风险**。

> **最重要的一句话**：不同用途、不同地区、不同受理系统的要求差异很大。本技能给的是**常见值**，**最终以受理机构公布的要求为准**。报名页面、办事指南或窗口说明写了具体像素与背景色的，一律以那个为准。

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出常见规格尺寸与硬指标的核查口径 | ❌ 代办、代审或保证通过受理机构审核 |
| 说明五官、着装、表情的通用要求 | ❌ 提供伪造、变造、篡改证件照的方法 |
| 给出在家自拍的操作流程 | ❌ 解答证件本身的申领条件与办理流程 |
| 按严重度排出退回风险 | ❌ 替代受理机构的审核结论 |

**遇到以下情况，按各自渠道处理：**

- 受理机构**公布了具体像素、底色、文件大小** → 一律以那个为准，本表只作参考
- 身份证、护照等**法定证件**的照片要求 → 以公安机关与受理机关的现行规定为准
- 需要**抠图换底、修图** → 本技能不涉及具体后期操作
- 对审核结果有异议 → 联系受理机构

**本技能不提供任何伪造、变造证件照的方法，也不协助规避审核。**

## 二、完整工作流

### 第一步：先查受理机构的要求（这步不能跳）

打开报名页面或办事指南，确认四件事：**像素尺寸、底色、文件大小上限、是否要求近期拍摄**。

**这四项如果机构有明确要求，一律以机构为准**，跳过本技能的默认值。

### 第二步：选规格

| 规格 | 毫米 | 像素（300 dpi） | 常见用途 |
|---|---|---|---|
| 一寸 | 25 × 35 | 295 × 413 | 社保、资格报名、档案表 |
| 二寸 | 35 × 49 | 413 × 579 | 简历、资格证书、部分签证 |
| 小二寸 | 35 × 45 | 413 × 531 | 部分考试报名 |
| 护照 / 签证常用 | 33 × 48 | 390 × 567 | 出入境证件、多数国家签证 |

### 第三步：布置背景与光

找一面干净的白墙（或按要求挂蓝布/红布），**人离墙至少 0.5 米**，否则影子会投到墙上。左右前方 45 度各放一盏灯，避免单侧光造成阴阳脸。

### 第四步：架手机自拍

1. 手机架稳，**镜头高度与眼睛齐平**
2. **用 2 倍镜**——主摄是广角，近距离会把脸拍变形
3. 开网格线，**脸部中轴对准竖中线**
4. **关掉美颜与滤镜**——美颜会改变五官特征，审核可能不通过
5. 设定时快门，避免手抖
6. **连拍 5 到 10 张**，挑表情最自然、眼睛睁得最开的一张
7. 拍完立刻放大检查：瞳孔清晰、无红眼、头发没遮眉

### 第五步：填 JSON 跑自查

把像素、dpi、底色、各项比例填进去，脚本一次给出逐项判定与退回风险。

## 三、核心规则（生成结论前先读规则文件）

**必须先读 `rules/证件照规格与自查表.md`，不要凭印象写。** 规则文件里有：

- 四种常见规格的毫米尺寸与 300 dpi 像素值
- 构图比例三项（头部占比、头顶留白、眼睛位置）
- 五官与着装七项要求（眉毛、耳朵、帽子、眼镜、表情、红眼、服装对比）
- 背景与光线的四条要求
- 自拍七步流程
- 判定顺序说明与八条高频坑

**判定顺序不能颠倒**：先看严重项（分辨率、尺寸、底色、遮眉、超期、文件超限、红眼、服装无对比），再看可改进项，最后才看信息是否完整。

**为什么这条重要**：若先判信息完整度，会出现「分辨率只有 72 dpi 肯定被退回，却因为没填头部占比而被判成待确认」——把问题说轻了，比漏判更糟。

## 四、指标速查

| 项目 | 合格口径 | 严重度 |
|---|---|---|
| 分辨率 | 不低于 300 dpi | 严重 |
| 像素尺寸 | 与所选规格一致（容差 3 像素） | 严重 |
| 底色 | 符合用途与受理机构要求 | 严重 |
| 眉毛 / 耳朵 | 必须露出 | 严重 |
| 帽子头饰 | 不得佩戴（宗教与医疗原因按机构要求） | 严重 |
| 拍摄时间 | 近 6 个月内 | 严重 |
| 文件大小 | 10 到 300 KB | 严重 |
| 红眼 | 不得有 | 严重 |
| 服装配色 | 与底色有明确保持对比 | 严重 |
| 头部占比 | 70% 到 80% | 可改进 |
| 头顶留白 | 3% 到 10% | 可改进 |
| 眼睛水平位置 | 45% 到 65% | 可改进 |
| 背景 | 均匀、无阴影褶皱杂物 | 可改进 |
| 眼镜 / 表情 / 肩膀 | 建议不戴眼镜；表情中性不露齿；肩膀拍全且对称 | 可改进 |

## 五、脚本用法

```bash
python scripts/id_photo_check.py --file photo.json --out 证件照自查.md
python scripts/id_photo_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`photos` 为照片列表，每张填 `spec` / `px_w` / `px_h` / `dpi` / `bg` 等 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检（59 条断言，含 BOM 两条路径） |

输入 JSON 示例：

```json
{
  "photos": [
    {
      "name": "社保一寸",
      "spec": "one_inch",
      "px_w": 295,
      "px_h": 413,
      "dpi": 300,
      "bg": "white",
      "face_height_ratio": 0.75,
      "head_top_margin": 0.06,
      "eye_line_ratio": 0.55,
      "file_kb": 45,
      "months_since": 2,
      "hair_cover_brow": false,
      "ears_visible": true,
      "headwear": false,
      "red_eye": false,
      "clothes_contrast": true,
      "bg_even": true,
      "shadow_on_bg": false,
      "glasses": false,
      "expression": "neutral",
      "shoulders_visible": true
    }
  ]
}
```

可选枚举：`spec` 取 `one_inch` / `two_inch` / `small_two` / `passport`；
`bg` 取 `white` / `blue` / `red`；`expression` 取 `neutral` / `slight` / `teeth`。
数值字段：`px_w`、`px_h`、`dpi`、`face_height_ratio`、`head_top_margin`、`eye_line_ratio`、`file_kb`、`months_since`。
布尔字段：`hair_cover_brow`、`ears_visible`、`headwear`、`red_eye`、`clothes_contrast`、`bg_even`、`shadow_on_bg`、`glasses`、`shoulders_visible`。

脚本输出：总体判定、逐张判定表（含不合格原因的 why）、整改顺序、常见规格表、阈值表、人工确认清单，并在开头标注「以受理机构公布的要求为准」。

## 六、人工确认清单（这步不能省）

- [ ] 已核对受理机构公布的具体像素、底色与文件大小要求
- [ ] 关掉了美颜与滤镜
- [ ] 镜头高度与眼睛齐平，脸部中轴对准网格竖中线
- [ ] 眉毛耳朵露出，没戴帽子头饰，没戴眼镜
- [ ] 背景纯净均匀、无阴影，人离墙至少 0.5 米
- [ ] 连拍了 5 到 10 张，放大检查瞳孔清晰、无红眼
- [ ] 服装颜色与底色有明确保持对比

## 七、最常见的坑

**坑一：从相册截图当证件照。**
错误做法：把照片放大截一块就上传。正确做法：**截图通常只有 72 dpi**，远低于 300 dpi 要求，会被系统直接退回。按规格重新导出或拍摄。

**坑二：用手机主摄近距离自拍。**
错误做法：举着手机凑近拍大头照。正确做法：**用 2 倍镜（约 50mm）或退远再放大**。主摄是广角，近距离会把鼻子额头放大、脸变形。

**坑三：人贴着墙站。**
错误做法：背贴墙面拍，觉得背景干净。正确做法：**离墙至少 0.5 米**。贴着站头影会投在墙上，背景有阴影就退回。

**坑四：白底穿白衬衫。**
错误做法：白底照片穿白衬衫。正确做法：**服装要与底色有明确保持对比**。白底穿浅色衣服，肩膀会和背景糊在一起。

**坑五：刘海遮眉毛、长发盖耳朵。**
错误做法：日常发型直接拍。正确做法：**眉毛和耳朵必须完整露出**，刘海梳上去，长发别到耳后。

**坑六：觉得笑一下好看。**
错误做法：露齿微笑自认为精神。正确做法：**表情中性，双唇自然闭合**。多数证件照用途不接受露齿笑。

**坑七：开着美颜拍。**
错误做法：开美颜磨皮瘦脸，觉得更像自己。正确做法：**关掉美颜与滤镜**。美颜会改变五官特征，人工审核时可能被判与本人不符。

**坑八：只拍一张就上传。**
错误做法：拍一张觉得差不多。正确做法：**连拍 5 到 10 张再挑**。红眼、闭眼、头发乱这些只有放大才看得见。
