## 一、结论摘要

| 项 | 结论 |

| 主体一致性 | 待填 |

| 参考应退 | 待填 |
| 有效期状态 | 待填 |
| 高危项 | 待填（n 项） |
| **总体结论** | **通过 / 有风险 / 不通过 / 待补正** |

四态含义：

- **通过**：主体一致、条款合规、无未告知限制
- **有风险**：存在需交涉或需补正的问题
- **不通过**：命中高危项（概不退费条款、门店停业失联、主体不一致、教练离职不可退等）
- **待补正**：核心金额或课时未填，不下实质结论
