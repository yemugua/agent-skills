# 健身房退费谈判与投诉操作卡

## 卡片 A：办卡前必须写进合同的六条

1. 总共多少节？单节价格多少？
2. 有效期多久？到期未上完的怎么办（顺延还是退）？
3. 中途不想上了怎么退？退多少？多久到账？
4. 教练是谁？教练离职怎么办？
5. 门店转让或停业怎么办？由谁承接？
6. 能不能转让给别人？手续费多少？

**要求**：六条全部写进书面合同，口头承诺不作数。

## 卡片 B：销售口头承诺怎么留证（最低成本）

事后用微信发一句给销售：

> 「确认一下：你刚才说的 50 节私教课 29800，随时可以申请退未上的部分，没有有效期限制，对吧？」

对方回「对」「是的」即完成留证。不回或者含糊，本身就是信号。

## 卡片 C：门店拒绝退费时的三步

```
第 1 步  书面申请
  EMS 寄到合同主体注册地址（不是门店地址）
  内容：购买事实 + 剩余节数 + 计算式 + 7 个工作日答复要求
  拿：EMS 面单 + 签收记录

第 2 步  12315 投诉
  全国 12315 平台提交：合同、付款凭证、宣传截图、EMS 面单
  重点写：不公平格式条款 + 拒不履行退款义务

第 3 步  选路径
  储值卡/年卡 → 商务主管部门（单用途预付卡）
  私教课服务合同 → 市场监管 + 消协调解
  门店失联且人数多 → 联合报案
```

## 卡片 D：谈判时怎么说

- 「合同第 × 条写『概不退费』，这个条款排除了我的主要权利，属于不公平格式条款，我可以主张它无效。」
- 「我只主张未消费的 42 节，已上的 8 节按原价扣除，我没有要求额外赔偿。」
- 「请出具书面的拒绝退费说明，并加盖公章——我需要它去投诉。」

**最后一句最关键**：要求书面答复，多数机构到这一步会松口。

## 卡片 E：教练离职时怎么说

> 「我买的是 ×× 教练的课，指定教练是我签约的核心条件。教练离职属于合同主要内容变更，
> 我不同意更换教练，申请解除并退还剩余 ×× 节的费用。」

**要点**：不同意的要在**第一时间书面提出**；已经接受新教练上了几节课的，会被视为默认变更。

## 卡片 F：门店转让/停业时怎么说

- 转让：「请新店出具书面承接承诺；不出具的，我向原签约主体主张。请在 7 日内书面答复。」
- 停业：「请出具停业说明与退款方案；不答复的，我同步投诉 12315 与商务部门，并保留报案权利。」
- 失联：联合其他会员统计人数与金额，一起报案；不要单人反复上门。

## 卡片 G：硬性时间纪律

- 诉讼时效三年，不要拖
- 门店出现转让、欠薪、装修停业传闻时**立刻**书面主张
- 已失联的不要等，直接投诉 + 报案
