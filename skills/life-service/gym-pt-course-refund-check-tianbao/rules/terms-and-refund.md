# 健身房退费的条款效力与计算口径

## 一、哪些条款站不住

| 条款 | 为什么站不住 | 怎么说 |
| --- | --- | --- |
| 「一经售出概不退费」 | 不合理免除自身责任、排除消费者主要权利 | 属不公平格式条款，可主张无效 |
| 「过期作废，余额清零」 | 未消费的不因期限届满而当然消灭 | 有效期条款须显著提示，且不得排除退款请求权 |
| 「最终解释权归本店」 | 排除消费者权利 | 典型无效表述 |
| 「本店有权单方更换教练」 | 私教课高度依赖教练人选，单方换人显失公平 | 更换教练应征得同意，否则可主张解除 |
| 「只能转让不能退」 | 限制消费者法定权利 | 转让是选项之一，不能替代退款请求权 |
| 「转让需支付 30% 手续费」 | 手续费应与实际成本相当 | 过高可请求调整 |
| 「会员卡遗失不补」 | 排除消费者财产权 | 可主张无效 |

依据：《中华人民共和国消费者权益保护法》及其实施条例、《中华人民共和国民法典》关于格式条款、
显失公平与情势变更的相关规定。条文号以官方文本为准。

## 二、应退金额怎么算

```
未消费金额 = 已付总额 − 已上节数 × 单节价格
应退金额   = 未消费金额 − 已退金额 − 合理成本（如已交付的实体物品）

若合同未写单节价格：
单节价格 = 合同总金额 ÷ 购课总节数
```

**可扣除的部分**：已实际交付的器材、服装等实物；已实际提供的服务对价。

**不应扣除的部分**：
- 「违约金」高于机构实际损失的，可请求调整（违约金以补偿实际损失为原则）
- 已支付的销售提成、管理费——属机构内部成本，不应转嫁
- 尚未发生的「场地费」「系统费」等名义扣款

**机构原因导致的解除**（门店停业、无法安排教练、擅自更换教练）：
未消费部分应**全额退还**，且可主张赔偿合理损失。

## 三、有效期条款的处理

1. 有效期条款必须**显著提示**（加粗、签字确认），未尽提示义务的可主张不成为合同内容。
2. 有效期届满不等于余额消灭：未消费的预付款仍可主张返还。
3. 因机构原因（装修停业、无法预约、教练缺失）导致无法在有效期内消费的，
   有效期应当相应顺延。
4. 因消费者自身原因（出国、伤病）长期未消费的，可主张情势变更协商解除，
   但退费比例会低于机构原因的情形。

## 四、教练离职怎么办

- 私教课的核心是人。指定教练离职的，属于**合同目的无法实现或主要内容变更**，
  消费者可主张解除并要求退还未消费部分。
- 机构提出换教练的，消费者有权**同意或拒绝**；拒绝的，应退费而不是强制换人。
- 合同写「有权单方更换教练」的，该条款显失公平，可主张无效。
- 若只是换了教练但课程照常提供、消费者已实际接受新教练上课的，
  视为默认变更，再主张全额退费的难度会上升——**不接受的要在第一时间书面提出**。

## 五、门店转让与停业

| 情形 | 谁负责 | 怎么做 |
| --- | --- | --- |
| 门店转让（换老板、换招牌） | 受让方承接原会员债务；原主体仍有连带责任 | 要求新店书面确认承接，不确认的向原主体主张 |
| 门店停业（关闭） | 原经营主体 | 立即书面主张退费，同步投诉与报案 |
| 门店失联（跑路） | 原经营主体及其股东 | 人数众多的，联合报案；涉预付卡的同时反映至商务部门 |
| 只是装修/搬迁 | 原经营主体 | 可要求顺延有效期，不接受的可协商退费 |

**关键**：通过**国家企业信用信息公示系统**查清签约主体是否存续、是否有经营异常；
转让的要拿到转让协议或承接承诺的书面证据。

## 六、预付费资金监管

《消费者权益保护法实施条例》对预付费经营者的书面合同、退款规则与资金管理有明确要求。
消费者可要求经营者提供**书面合同**并载明：服务内容、价格、退款方式、违约责任。
未签订书面合同或合同未载明退款规则的，本身就是投诉的抓手。

## 七、纪律边界

- 本技能只做信息核查与路径指引，不代办投诉、不代写诉状。
- 退费比例为依填写信息推算的**参考值**，最终以协商、调解或裁判结果为准。
- 金额较大或涉人数众多的，建议联合其他消费者并咨询执业律师。
