# 私教课退费的路径、取证与时间纪律

## 一、逐级推进的路径

| 层级 | 找谁 | 适用 | 要准备什么 |
| --- | --- | --- | --- |
| 1 | 门店/机构书面申请退费 | 全部情形 | 书面退费申请（EMS 寄送留面单）、合同、付款凭证 |
| 2 | 平台介入 | 经第三方平台（如团购/健身平台）下单的 | 订单号、聊天记录 |
| 3 | 12315 投诉（全国 12315 平台） | 拒退、格式条款、虚假承诺 | 合同、付款凭证、宣传截图、书面申请材料 |
| 4 | 当地商务主管部门 | 单用途商业预付卡（储值卡、年卡） | 卡片、合同、预付凭证 |
| 5 | 消费者协会调解 | 双方仍有协商空间 | 全套材料复印件 |
| 6 | 人民法院起诉 / 小额诉讼 | 金额明确、协商不成 | 起诉状、证据清单、主体信息 |

**关键区分**：`私教课服务合同`走 12315 与市场监管；`储值年卡/预付卡`同时可走商务部门；
`经营者失联且人数众多`可联合报案。三条可并行，不要只走一条。

## 二、证据清单

必留材料：

1. **书面合同或协议原件**（含签字页与附件）
2. **付款凭证**：POS 单、转账记录、发票或收据；**重点看收款方名称**
3. 会员卡/课程包的系统截图（剩余节数、有效期、购买时间）
4. 教练安排与上课记录（约课记录、签到记录）
5. 销售承诺的**原始载体**：宣传页、微信聊天、录音、海报
6. 教练离职或门店变更的公告、通知截图
7. 书面退费申请与 EMS 面单、签收记录
8. 机构答复（书面或录音）

## 三、取证要点

- **收款方名称**最关键：合同主体与收款主体不一致时，两家都要列入主张对象。
- **剩余节数**要截图固定：在系统里截，注明截图时间；门店不给查的，书面要求提供。
- 销售口头承诺要转化为书面：事后用微信文字复述一遍请对方确认，是最低成本的留证。
- 与门店的谈话可以录音，但要当场录制、保留原始文件。

## 四、退费申请书要点

```
致：××健身（合同主体全称）
本人于 ×年×月×日购买 ×× 私教课 ×× 节，支付 ¥××××，已上 ×× 节，剩余 ×× 节未消费。
现因 ××（教练离职 / 门店停业 / 个人原因无法继续），依据《消费者权益保护法》
相关规定，申请解除服务合同并退还剩余费用 ¥××××（计算方式：已付 − 已上×单节价）。
请于 7 个工作日内书面答复并办理退款。
                                              申请人：    日期：
```

**务必**：用 EMS 寄到合同主体注册地址，保留面单与签收记录——这决定后续能否主张逾期利息。

## 五、时间纪律

- 主张退费的**诉讼时效为三年**，自知道权利受损之日起算，不要无限期拖延。
- 门店一旦出现转让、装修停业、欠薪传闻，**立刻**书面主张，越早越有主动权。
- 经营者已失联的，不要等待，直接投诉 + 报案（涉人数众多的涉嫌集资或诈骗）。

## 六、常见误区

| 误区 | 正确做法 |
| --- | --- |
| 「合同写了概不退费就没办法」 | 该条款可主张无效，退费请求权不因条款而消灭 |
| 「过期了就不能退」 | 有效期条款须显著提示，未消费余额不当然消灭 |
| 「只能转让不能退」 | 转让不能替代退款请求权 |
| 「教练走了只能自认倒霉」 | 指定教练离职可主张解除，机构原因应全额退未消费部分 |
| 「门店换了老板就找不到了」 | 受让方承接债务，原主体仍有责任；用公示系统查主体存续 |
| 「金额小不值得折腾」 | 可走小额诉讼，成本远低于想象；且多人投诉会被优先处理 |

## 七、纪律边界

不替代专业法律意见，最终以主管部门及司法机关认定为准。
