# 违法处理与撤销操作卡

> 记住两个时限：**复议 7 日**（对罚款有异议）、**逾期缴款按日加罚**（不论有无异议）。
> 顺序不能反：**先确认事实 → 再决定认还是争 → 争就 7 日内书面提 → 无论结果都先缴款**。

## 【第一步：确认事实】

- [ ] 登录**交管 12123**，导出全部违法记录
- [ ] **逐条比对**：时间、地点、行为、扣分、罚款
- [ ] 特别看**扣分明显偏高**的（普通违停扣 6 分、超速档位对不上）
- [ ] 到窗口打印**违法决定书**（纸质、带章）
- [ ] 记录**收到决定书的日期**（决定复议时限的起算点）

## 【第二步：决定是认还是争】

判断能不能争，看这三条：

- [ ] **违法时开车的是不是你？** 不是 → 可主张撤销
- [ ] **标志标线设备有没有客观问题？** 有 → 可主张撤销
- [ ] **车有没有转让、被盗、被套牌？** 有 → 可主张撤销

**三条都没有** → 认了更划算，**争议的成本通常高于罚款本身**。

## 【第三步：现场取证（主张客观异常的必做）】

- [ ] 标志：**全貌 + 近景**两张，能看出被什么遮挡
- [ ] 标线：**清晰度对比**，说明当时无法辨认
- [ ] 信号灯：**工作状态**，说明故障或不显示
- [ ] 摄像头：**位置与视角**，说明被遮挡或角度不合理
- [ ] 施工路段：**施工公示牌与现场**
- [ ] ⚠️ **照片必须保留原始拍摄时间信息**，PS 过的会被否

## 【第四步：固定"不是本车驾驶人"的证据】

- [ ] **车库监控**（覆盖违法时段）
- [ ] **车位照片**（带时间信息）
- [ ] **行车记录仪**录像
- [ ] 违法时段的**不在场证明**（出差、住院、另一辆车）
- [ ] 借用协议 / 借车记录
- [ ] 车辆被盗的**报案回执**

## 【第五步：7 日内提交书面申请】

- [ ] 写**书面**撤销申请（不要只在窗口口头说）
- [ ] 内容包含：违法事实 + **具体异议理由** + 证据清单 + 请求
- [ ] 现场递交并**索取受理回执**，或**EMS 邮寄并保留单号**
- [ ] 保留一份原件自留

## 【第六步：无论结果如何，按期缴款】

- [ ] 在复议/撤销处理期间**先把罚款缴了**
- [ ] 逾期不缴会**按日加处罚款**，还影响**年检和保险**
- [ ] 保存**缴费凭证与处理回执**
- [ ] 若撤销成功，**再申请退费**

## 【营运车 / 单位车额外必做】

- [ ] 要求单位出**书面处理说明**（费用由谁承担）
- [ ] 明确问一句：**记分是记在我驾驶证上还是公司车辆上？**
- [ ] 处理完在 12123 **自己核对记分归属**
- [ ] 若记分有误 → 向省级交管部门申请**复核更正**
- [ ] 查劳动合同与员工手册中关于费用承担的条款，**拍照留存**
- [ ] 若工资被扣：算一下**是否低于当地最低工资标准**

---

## 撤销理由清单（对照勾选）

- [ ] 违法行为已被确认无效（标志遮挡、标线不清、信号灯故障、设备故障）
- [ ] 机动车号牌被他人套用
- [ ] 记录录入后机动车已转让
- [ ] 已被简易程序处罚，本人可到指定场所提出撤销申请
- [ ] 交通技术监控设备检测或录入有错误
- [ ] **根本不是本车驾驶人**（被盗、被借、套牌）

## 处理渠道

- [ ] 交管 12123 App（多数情形线上办）
- [ ] 交警队 / 车管所窗口（需现场核实时）
- [ ] 邮局代收（部分地区支持邮寄）
- [ ] 复议：对**罚款**有异议，**7 日内**向上一级交警部门
- [ ] 复核：对**记分**有异议，向省级交管部门
