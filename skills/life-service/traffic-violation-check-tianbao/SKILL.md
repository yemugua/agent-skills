# 交通违法扣分与撤销核查

交通违法的处理有两条完全不同的路：**认了交罚款**，或者**争到底争取撤销**。多数人一开始就走错了——要么稀里糊涂认了本不是自己开的车，要么和窗口吵了一架却在复议时限上过期。

## 什么时候用

- 12123 或短信通知你有违法记录，不知道扣几分、罚多少
- 记分扣得比实际多，或者出现了自己没做过的违法
- 车停着却被拍了（套牌、被盗、被借出）
- 现场标志被遮挡、标线不清、信号灯故障，觉得"这不能算我违章"
- 营运车/公司车，单位说罚款自己出还要扣绩效
- 12 分快扣满了，怕吊销驾照
- 收到决定书了，想知道还能不能申请撤销

## 怎么做

**第 1 步**：复制 `templates/交通违法处理信息采集表.md` 填写（违法类型、扣分、**违法时驾驶人是谁**、收到决定书时间是最关键的四项）。

**第 2 步**：跑脚本

```bash
python scripts/traffic_violation_check.py 采集表.md --base 2026-10-05 --out 核查报告.md
```

**第 3 步**：照第八段七步路径走——**先在 12123 确认事实 → 判断是不是本人车 → 符合条件就申请撤销 → 先处理再申诉 → 主动缴款避免加罚**。

## 三条最容易错过的规则

1. **7 日复议时限**。对**罚款**有异议的，要在**收到处罚决定书 7 日内**向上一级交警部门申请行政复议。**过了就基本走不通了**，只剩复核记分和更正两条路。
2. **逾期不处理要加处罚款**。不缴罚款会**按日加处罚款**，还影响**年检和保险续保**。所以即使有异议，**也要先处理、再申诉**——拖着不处理是最不划算的做法。
3. **扣满 12 分会暂扣驾驶证**。一个记分周期内累积扣满 12 分的，**暂扣驾驶证并参加学习考试**；再次累积还会被**吊销**。9 分以上就已接近危险线，要逐条核对有没有错误记录。

## 边界与纪律

- 依**通用规则**整理，**不替代律师意见**；记分与罚款标准、撤销条件、电动自行车与事故处理规定，**以交管部门与现行《道路交通安全违法行为记分管理办法》口径为准**
- **本报告的推算分值仅供参考**，实际以 12123 与处罚决定书为准
- 不预测交管部门是否批准撤销或复核
- **未填的一律不算通过**，只按已填内容判断
- 车牌号、驾驶证号等敏感信息**本地处理，不要外发**
- **醉驾、事故致人伤亡、肇事逃逸的，先咨询律师，不要自行处理**
