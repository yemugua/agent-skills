# 医美退费口径与证据规则

## 一、过错责任与退费口径
- **机构全责**（无资质行医 / 超范围执业 / 事故 / 欺诈）：可主张**全额退款**，造成人身损害的另可要求赔偿损失（医疗费、护理费、误工费、精神损害等）。
- **部分责任**（合同未写明项目明细 / 中途增项加价 / 效果未达承诺）：按已消费比例协商退还未消费部分。
- **一般情形**：按《消费者权益保护法》与合同约定，协商退还未消费、未服务部分。

## 二、典型陷阱
- **格式条款**：合同写「一经付款概不退款」「最终解释权归本机构」属无效格式条款。
- **增项加价**：未事前明示并征得同意的加收费用可拒付，属价格违法线索（可向市场监管举报）。
- **诱导医美贷**：机构诱导贷款不等于债务转移，与机构的服务纠纷不影响还款义务，但可就欺诈主张撤销合同；警惕「套路贷」。

## 三、证据清单（固定优先级）
1. 合同 / 知情同意书（最重要）
2. 付款凭证（发票、收据、转账、分期/贷款记录）
3. 术前术后照片 / 影像（带时间水印）
4. 聊天记录（微信、顾问沟通，原话留痕）
5. 病历与诊疗记录（事故发生后）

## 四、维权路径表
| 情形 | 向谁投诉 | 说明什么 |
| --- | --- | --- |
| 无执业许可证 / 超范围执业 | 卫生健康行政部门 | 机构名、地址、项目、时间 |
| 虚假宣传、效果未达、增项加价 | 12315 / 市场监管 | 合同、付款、承诺原话 |
| 并发症 / 医疗事故 | 卫健部门 + 医疗纠纷调解 | 病历、伤情、剩余产品 |
| 诱导贷款 / 套路贷 | 金融监管部门 + 公安 | 聊天、办贷记录 |
| 协商无果 | 法院（小额诉讼） | 全套证据链 |

## 五、时间纪律
- 先补齐资质查询截图与合同/付款证据，再一次性提交投诉，效率最高。
- 出现并发症：**先就医固定伤情**，再谈退费与赔偿。
