# 医美退费维权 · 概述

## 适用场景
- 在医美机构消费后想退费（效果未达、被加价、不想做了）
- 怀疑机构无《医疗机构执业许可证》或无资质人员操作
- 被诱导办理医美分期/贷款后反悔
- 出现感染、并发症、事故，要求赔偿

## 核查逻辑
1. **资质先查**：机构是否持《医疗机构执业许可证》且诊疗科目含所选项目；操作医师是否注册执业、执业范围相符。无证或超范围即非法行医。
2. **合同与承诺**：是否签合同、合同是否写明项目/次数/单价；是否承诺效果、实际是否达标。
3. **风险点**：中途增项加价、诱导医美贷、出现并发症事故。
4. **退款测算**：机构全责（无资质/事故/欺诈）→ 全额退+赔偿；部分责任（合同不明/增项/效果未达）→ 退未消费部分；一般情形协商。
5. **证据与路径**：合同、付款、术前术后照片、聊天、病历；卫健部门、12315、医疗纠纷调解、法院。

## 结论四态
通过 / 有风险 / 不通过 / 待补正（关键信息未填绝不判通过）。

## 边界
本技能为信息核查与路径指引，不替代律师意见与医学诊断，最终以主管部门及司法机关认定为准。
