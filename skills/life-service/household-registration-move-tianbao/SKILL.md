# 户口迁移办理与材料核查（household-registration-move）

迁户口这件事，绝大多数人卡在四个点：**不知道自己属于哪类迁移、要不要先办准迁证、三段流程搞混了、迁入地的准入门槛没摸清就去排队**。

这个技能做五件事：**定类型** → **查门槛** → **核三段材料** → **算时限** → **找救济**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 判断属于哪类户口迁移 | ❌ 承诺一定准予迁入、一定落户 |
| 列出三段流程的材料清单并标缺失 | ❌ 代填申请表、代签承诺 |
| 提示迁入地准入门槛与需核实事项 | ❌ 编造"不用准迁证也能办"的操作口径 |
| 提示办理时限与被卡原因 | ❌ 提供虚假婚姻、虚假房产、虚假劳动关系的办法 |
| 说明不予受理后的救济途径 | ❌ 代理行政复议或行政诉讼 |

**遇到以下情况，直接问迁入地与迁出地公安机关户籍窗口，不要靠猜：**
- 迁入地的落户政策与本人条件是否匹配（社保年限、学历、年龄、房产性质）
- 房产性质存疑（小产权、商住两用、查封、抵押、共有产权）
- 集体户口、人才市场集体户、单位集体户的迁出与接收
- 离婚、再婚、非婚生育涉及的子女随迁
- 户口迁移证已过期或遗失
- 涉及征地冻结、拆迁冻结、限购等特殊管控区域

**永远不要伪造婚姻关系、房产证明或劳动关系材料去凑落户条件。** 一经查实，除不予办理外还可能依法追究责任并影响后续申请。

## 二、完整工作流

```
第 1 步  定类型：八类迁移情形中命中哪一类
第 2 步  查门槛：迁入地对该类迁移的准入条件是什么（先问，别先排队）
第 3 步  先读规则文件 rules/migration_rules.md（类型表 + 三段流程 + 材料 + 被卡原因）
第 4 步  跑核查脚本
    python scripts/hukou_material_check.py --file 情况.txt --type 购房落户 --as-of 2026-10-08
第 5 步  逐项人工确认（脚本只做关键词匹配，不做户籍口径判断）
第 6 步  按 templates/户口迁移材料清单表.md 输出核查表
```

---

## 三、八类迁移情形

| 类型 | 典型情形 | 常见准入要点 |
|---|---|---|
| **购房落户** | 在迁入地购买合法稳定住所 | 房产性质、面积或总价、是否取得不动产权证 |
| **夫妻投靠** | 配偶一方在迁入地有常住户口 | 婚姻关系存续年限、结婚登记年限 |
| **父母子女投靠** | 未成年子女随迁、年老父母投靠子女 | 亲属关系证明、年龄与抚养关系 |
| **人才引进/学历落户** | 凭学历、职称、技能等级迁入 | 学历认证、社保缴纳、年龄区间 |
| **务工经商落户** | 凭合法稳定就业或经营迁入 | 劳动合同、社保年限、营业执照 |
| **大中专学生** | 入学迁入学校集体户、毕业迁出 | 录取通知书、毕业去向、档案关系 |
| **工作调动** | 因组织人事调动迁入 | 调动函、接收单位证明 |
| **集体户转家庭户** | 从单位或人才集体户迁出 | 迁入地是否有合法稳定住所或接收单位 |

> 具体准入条件由迁入地按现行规定设定，**同一省内不同城市的口径也可能不同**。先确认门槛，再准备材料。

---

## 四、三段流程（最容易搞混的地方）

| 段 | 在哪办 | 拿什么 | 注意 |
|---|---|---|---|
| **第一段：申请准迁** | 迁入地公安机关户籍窗口 | 准予迁入证明（准迁证） | 门槛核验主要在这一段，不过就没有第二段 |
| **第二段：办理迁出** | 迁出地公安机关户籍窗口 | 户口迁移证 + 原户口簿注销 | 须持准迁证办理，迁移证有有效期 |
| **第三段：办理落户** | 迁入地公安机关户籍窗口 | 新户口簿、办理身份证换发 | 须在迁移证有效期内办理，逾期需重新申请 |

> 三段**不能跳、不能并**。很多人直接去迁出地问"我要迁走"，被告知要先拿准迁证，白跑一趟。

---

## 五、材料清单

完整清单、替代材料与常见替代口径见 `rules/migration_rules.md`。核心八项：

| # | 材料 | 要点 | 缺了会怎样 |
|---|---|---|---|
| 1 | 居民身份证 | 原件及复印件 | 不予受理 |
| 2 | 居民户口簿 | 原件，迁出时需交回注销 | 不予受理 |
| 3 | 准予迁入证明 | 迁入地出具，是第二段的前置 | 迁出地不予办理 |
| 4 | 户口迁移证 | 迁出地出具，是第三段的前置 | 无法落户 |
| 5 | 准入条件证明材料 | 房产证、结婚证、学历证书、社保记录等 | 第一段即被卡 |
| 6 | 亲属关系证明 | 投靠类迁移需要 | 退回补材料 |
| 7 | 迁入地接收证明 | 集体户、单位接收时需要 | 退回补材料 |
| 8 | 申请表与承诺书 | 窗口现场填写或网上预填 | 无法受理 |

## 六、办理时限

- 各段法定办理时限按现行规定执行，实际时长受申请量、是否需核查、是否需发函核实影响。
- **准迁证、户口迁移证均有有效期**，须在有效期内办理下一段。逾期通常需要重新申请，不要拿着过期的证去窗口。
- **整体时间 = 第一段 + 第二段 + 第三段 + 材料准备时间**。跨省迁移还要算上往返与邮寄时间。
- 涉及社保、学历、房产信息核验的，核验时间不计入受理时限的可能性存在，要提前问清。

## 七、脚本用法

```bash
python scripts/hukou_material_check.py --file "D:\材料\情况说明.txt" \
    --type 购房落户 --as-of 2026-10-08 --out 核查结果.md
```

| 参数 | 说明 |
|---|---|
| `--file` | 必填。情况说明、材料清单或聊天记录导出文本（`.txt` / `.md`） |
| `--type` | 迁移类型：购房 / 夫妻投靠 / 人才引进 / 学生 / 随迁 / 集体户等，缺省自动判定 |
| `--as-of` | 核查基准日，默认今天 |
| `--permit-date` | 准迁证开具日期，用于算准迁证有效期剩余天数 |
| `--move-date` | 户口迁移证开具日期，用于算迁移证有效期剩余天数 |
| `--out` | 输出路径，默认打到屏幕 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本做五件事：
1. **类型判定**：八类迁移情形命中哪一类
2. **三段流程核查**：当前处在哪一段、下一段缺什么
3. **材料核查**：八项清单逐项标齐备/缺失/不涉及
4. **证件有效期**：准迁证与户口迁移证剩余有效期与逾期提示
5. **被卡风险**：七类高频被卡原因是否命中

> ⚠️ 脚本只做关键词匹配，**不代表受理结论**。标"齐备"不等于窗口认可这份材料。

## 八、人工确认（这步不能省）

- [ ] 迁入地的准入条件是否已通过官方渠道确认，不是看帖子或问朋友
- [ ] 房产是否已取得不动产权证，性质是否符合迁入地要求
- [ ] 社保缴纳是否连续、是否已到要求的年限、缴纳单位是否与劳动合同一致
- [ ] 结婚证、出生医学证明上的姓名与身份证是否完全一致
- [ ] 集体户口迁出是否已取得保管方同意
- [ ] 准迁证、户口迁移证是否在有效期内
- [ ] 拟落户地址是否有对应的门牌与社区，能否实际落户
- [ ] 涉及未成年人的，另一方监护人是否知情并同意

---

## 九、输出结构（固定六段）

1. **迁移类型** —— 命中哪一类、准入要点是否清楚
2. **当前所处段位** —— 第一段/第二段/第三段，下一段要做什么
3. **材料清单核查表** —— 八项逐项标齐备/缺失/不涉及
4. **证件有效期** —— 准迁证、迁移证剩余天数与逾期提示
5. **被卡风险** —— 命中的高频被卡原因
6. **救济途径** —— 不予受理时可以走什么路径

## 十、最常见的坑

**坑一：直接去迁出地办迁出。**
没拿准迁证，迁出地不予办理。顺序是**先迁入地、后迁出地、再回迁入地落户**。

**坑二：以为买了房就一定能落户。**
房产性质、是否取得不动产权证、面积或总价、是否限购区域，都是迁入地的准入门槛。先确认门槛再买房，或买房前确认这套房能不能落。

**坑三：拿着过期的准迁证或迁移证去窗口。**
两证都有有效期。逾期通常要重新申请，前面的时间白花。

**坑四：社保断缴或缴纳单位与合同不一致。**
人才引进、务工经商类迁移核验社保时，断缴、补缴是否计入、缴纳主体是否一致，都是常见的被卡点。以迁入地答复为准。

**坑五：集体户口迁出没取得保管方同意。**
人才市场集体户、单位集体户迁出通常需要保管方配合。先沟通，再去窗口。

**坑六：只备一套材料。**
三段流程各自要的材料不同，且部分材料要交原件、部分收复印件。只带一套复印件会在第二段或第三段被退回。

**坑七：用"朋友说他这么办成了"当依据。**
不同城市、不同区、不同迁移类型的口径都不一样，且政策会调整。以迁入地公安机关户籍窗口的现行答复为准。

**坑八：被退回后反复重复提交。**
不予受理应当要求说明理由。属于材料问题的补齐后再报；属于条件不符的，重复提交不会有不同结果，应先问清依据与救济途径。

## 十一、边界与免责

- 本技能**不代替**公安机关户籍窗口的受理、审查与登记
- 迁移类型、准入条件、材料清单、办理时限与证件有效期各地口径不同，**以现行规定和迁入地、迁出地公安机关户籍窗口要求为准**
- 本技能**不计算**落户排队位次、**不预测**审批结果、**不提供**虚假婚姻、房产、劳动关系材料的制作办法
- 涉及行政复议、行政诉讼的，应咨询专业法律人士并依法定程序办理
