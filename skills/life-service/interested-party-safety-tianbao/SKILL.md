# 相关方安全管理（interested-party-safety）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据 ISO 45001 与相关方管理实践，生成相关方安全清单：承包商/供应商/访客/实习生的安全准入、交底、现场监督与绩效评价。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 相关方安全
- 承包商安全
- 外包安全
- 供应商安全
- 访客管理
- 入场交底

## 三、工作流
1. 识别相关方类型（承包/供应/访客/实习）
2. 安全准入与资质审查
3. 安全交底与风险告知
4. 现场监督与违章处置
5. 绩效评价与黑名单管理

## 四、核心内容（检查清单与判定）
ISO 45001 要求对承包商等工作人员实施安全控制；相关方须通过准入审查、交底告知与现场监督纳入统一安全管理。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未识别相关方类型（承包/供应/访客/实习） | 识别 |
| Q2 | FAIL | 未含安全准入/资质审查 | 准入 |
| Q3 | WARN | 未含安全交底与告知 | 交底 |
| Q4 | FAIL | 未含现场监督与违章处置 | 监督 |
| Q5 | WARN | 未含绩效评价与黑名单 | 评价 |

> 脚本 `interested-party-safety_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python interested-party-safety_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python interested-party-safety_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。

## 九、免责声明
本技能为辅助参考工具，输出不构成法律/行政意见。最终合规责任由使用单位与责任人承担。引用标准以官方发布为准。
