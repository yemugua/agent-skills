# 二手交易维权路径（按止损顺序）

## 1. 止损（第一时间）
- 平台内**举报卖家/订单**：选欺诈类型，提交聊天与订单证据。
- 申请**披露卖家信息**（平台可依法提供实名），为后续投诉/报警准备。
- 保留：订单截图、聊天记录、转账记录、商品照片/视频、开箱录像。

## 2. 平台介入
- 闲鱼：「订单 → 客服 / 小法庭」，买卖双方举证，评审团裁定。
- 转转/拍拍：「我的 → 客服 / 官方验机复检」。
- 平台内担保交易才介入；**脱离平台的私转平台无法追回**。

## 3. 12315 / 黑猫（商家主体明确时）
- 按经营者所在地投诉（闲鱼/转转主体在杭州/北京，可在 12315 选对应企业）。
- 黑猫投诉曝光施压。

## 4. 报警（已转账/诈骗）
- 脱离平台被骗、金额较大 → 打 **96110（反诈）或 110**。
- 提供：转账记录、对方账号、聊天记录、对方诱导脱离平台的证据。
- 越快报警，冻结对方账户挽回可能越大。

## 关键提醒
- **最有效的防线是"不脱离平台"**。一旦微信直转，基本只能靠报警。
- 到付件**先验后签**，不符当场拒收，别签收再投诉。
- 维权材料参考「消费维权投诉材料生成」技能整理。
