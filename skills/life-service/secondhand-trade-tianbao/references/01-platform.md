# 二手交易平台地图与入口

## 一、主流平台对比
- **闲鱼**（阿里）：C2C 最活跃，担保交易，社区氛围强。入口「我的 → 我买到的/我卖出的 → 客服」。
- **转转**（腾讯/58）：有官方验机服务，数码类较靠谱。入口「我的 → 客服 / 官方验机」。
- **拍拍**（京东）：二手数码自营验机，售后规范。
- **找靓机**：二手手机垂类，官方质检分级，看清"充新/95新/9成新"定义差异。
- **闲转**：转转旗下社区化二手。

## 二、稳定入口索引（通用）
- 订单/客服：「我的 → 我买到的 / 订单 → 客服 / 小法庭 / 举报」
- 举报骗子：「订单/聊天 → 举报 → 选择欺诈类型」
- 验机服务：转转/拍拍/找靓机的「官方验机 / 质检」入口（商品页或下单页）
- 纠纷仲裁：闲鱼「小法庭」（买卖家举证，评审团裁定）

## 三、搜索兜底
平台内搜索"客服""举报""验机""被骗"比翻菜单快。

## 四、校验
- 付款前确认订单在**平台内有记录**且款项走**平台担保**，而非直接转给卖家个人。
- 任何要求"加微信/QQ/支付宝直转"的，一律视为高风险，停止交易。
