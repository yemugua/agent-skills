# 二手交易防骗与维权指南

> **5 句口诀**（3 秒判断要不要用我）：
> 1. 交易发生在**闲鱼 / 转转 / 拍拍 / 找靓机 / 闲转**等二手平台 → 用我
> 2. 用户要**验货、识别骗局、处理到付/假货/脱离平台交易被骗、退款维权** → 用我
> 3. 用户要**绕过平台私下交易、洗钱、销赃、伪造鉴定报告** → 拒绝，并说明原因
> 4. 涉及**钱**的先给"止损顺序"，再给"取证清单"，最后给"投诉/报警路径"
> 5. 界面路径**只给层级方向 + 校验方法**，不假装知道用户手机上的确切按钮

## 一、这个技能解决什么

二手交易最大的坑不是"不会买"，而是**脱离平台**和**信任陷阱**：到付骗局、假货调包、钓鱼链接、以"保证金/手续费"为由先转账、被诱导加微信/QQ 私下交易后拉黑。一旦发生，平台无法介入，追回极难。

本技能用「平台内闭环交易 + 通用识别法 + 止损顺序」帮你避坑、验货、理清维权路径。

## 二、平台地图（先分清你在哪）
| 平台 | 特点 | 注意 |
|---|---|---|
| 闲鱼 | 阿里系，C2C 最活跃，担保交易 | 私下加微信交易风险极高 |
| 转转 | 腾讯/58 系，有官方验机 | 官方验机服务可优先用 |
| 拍拍 | 京东系，二手数码为主 | 自营验机较规范 |
| 找靓机 | 二手手机垂类，官方质检 | 看清"充新/95新"定义 |
| 闲转 | 转转旗下，社区化 | 同转转体系 |

## 三、通用三步定位法
1. **只在平台内沟通与付款**：任何"加微信/QQ/支付宝直转"都是红线。
2. **搜关键词**：平台内搜"验货""被骗""举报"找官方入口。
3. **校验**：付款前确认订单在平台内有记录、款项走平台担保，而非直接到账卖家。

## 四、高频骗局识别（核心）
- **到付骗局**：货到付款签收后发现是砖头/模型，签收即视为认可，极难退。先验货再签收。
- **假货/调包**：低价"全新"名牌、手机，到手真假混发。用官方验机/鉴定。
- **钓鱼链接**：仿冒平台登录页盗号。只从官方 App 内操作，不点短信/聊天里的链接。
- **保证金/手续费诈骗**：以"交易需保证金/开通诚信通"为由先让你转账——平台从不收这类前置费。
- **脱离平台交易**：以"平台手续费高/私下更便宜"诱导微信直转，转完拉黑。

## 五、验货要点（分品类）
- **数码/手机**：查序列号/IMEI、爱思助手验机、外观与功能全测、核对型号配置。
- **奢侈品/包表**：专柜/中检鉴定、核对五金/编码/证书。
- **家具/家电**：实物视频、通电测试、运输损伤当场验。
- **票务/虚拟**：警惕"代充/内部票"，优先官方渠道。

## 六、维权路径（按止损顺序）
1. **止损**：发现被骗立即冻结（平台内举报+申请披露卖家信息），保留所有聊天/订单。
2. **平台介入**：闲鱼/转转「我的 → 客服/小法庭/举报」，提交证据。
3. **12315/黑猫**：涉及金额、商家主体明确时投诉（按经营者所在地）。
4. **报警**：已转账/脱离平台被骗、金额较大 → 110 或反诈中心 96110。

## 七、明确拒绝的
- 绕过平台私下交易、洗钱、销赃、伪造鉴定报告
- 教"反杀/套卖家"等恶意操作
- 提供他人隐私信息
