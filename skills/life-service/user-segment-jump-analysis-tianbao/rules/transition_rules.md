# 用户分层跃迁口径与计算规则库

> 生成跃迁报告、解读跃迁矩阵、或核对他人给的跃迁数前，先读这份规则。

---

## 一、跃迁矩阵定义

设层序为 `L1 > L2 > ... > Lk`（从高到低），`M[i][j]` 为**上期在层 Li、本期在层 Lj 的用户数**。

```
M[i][j]  上期层 i  →  本期层 j
```

**三条恒等式（任何一条对不上都是口径问题，不要先怀疑业务）：**

| 恒等式 | 公式 | 不成立说明 |
|---|---|---|
| 恒等式 1（行和） | `Σ_j M[i][j] = 上期层 i 人数` | 上期分层未按层聚合，或有用户未归层 |
| 恒等式 2（列和） | `Σ_i M[i][j] = 本期层 j 人数` | 本期分层未按层聚合，或有用户未归层 |
| 恒等式 3（留存+迁出） | `层内留存率(i) + 跨层迁出率(i) = 1` | 分子分母用了不同集合 |

**行和 + 列和的总校验：**

```
Σ_i Σ_j M[i][j] = 上期总人数（若无新进用户）
Σ_i Σ_j M[i][j] = 本期总人数（若无流失用户）
两者不等 → 存在新进/流失用户，必须单列「新增层」与「流失层」
```

## 二、四类跃迁率

```
升层率(i)     = (Σ_{j<i} M[i][j]) / Σ_j M[i][j]
降层率(i)     = (Σ_{j>i} M[i][j]) / Σ_j M[i][j]
层内留存率(i) = M[i][i] / Σ_j M[i][j]
整体升层率    = (Σ_{i<j} M[i][j]) / (Σ_{i,j} M[i][j])
净升层率      = 整体升层率 − 整体降层率
```

> 注意层序约定：此处 `L1` 为最高层，故「`j<i`」表示 `j` 层更高，即升层。

| 指标 | 分母 | 用于 | 不能用于 |
|---|---|---|---|
| 升层率/降层率 | 上期层 i 人数 | 单层分析 | 跨层比较（分母不同） |
| 层内留存率 | 上期层 i 人数 | 层的稳定性 | 等同留存分析的 D7/D30 |
| 整体升层率 | 全部用户 | 总体汇报 | 定位问题层 |
| 净升层率 | 全部用户 | 两期对比 | 判断分层健康度 |

## 三、漏损通道排序

```
通道迁出人数(i→j)   = M[i][j]            (j 低于 i)
通道占该层比(i→j)    = M[i][j] / Σ_j M[i][j]
通道占总降层比(i→j)  = M[i][j] / (Σ_{i,j 降层} M[i][j])
```

### 判定阈值（需按实际规模校准）

| 判据 | 优先处理 | 次优先 | 暂不处理 |
|---|---|---|---|
| 通道占总降层比 | **≥ 20%** | 8%–20% | < 8% |
| 通道迁出人数 | ≥ 100 | 30–100 | < 30 |

**排序必须同时看两个指标。** 只看率会选中「高率小层」，只看人数会忽略「低率高率」的结构性问题。

**判定矩阵：**

| 占总降层比 | 迁出人数 | 判定 |
|---|---|---|
| 高（≥20%） | 高（≥100） | 重点排查，优先立项 |
| 高 | 低（<30） | 小层波动，看趋势不看单期 |
| 低 | 高 | 广谱下沉，查整体原因（版本/活动） |
| 低 | 低 | 正常波动 |

## 四、层内留存率 vs 留存分析

| 项 | 层内留存率（跃迁） | N 日留存率（留存分析） |
|---|---|---|
| 分母 | 上期层 i 人数 | 注册/活跃队列人数 |
| 分子 | 本期仍在层 i 的人数 | 第 N 天活跃的人数 |
| 分层依据 | 任意（RFM、活跃、GMV 等） | 无分层概念 |
| 关系 | 当分层依据=「本期是否活跃」时二者近似 | — |

**报告书写规范**：写「层内留存率（跃迁口径）」，不写「留存率」。

## 五、口径漂移四信号与检测

| # | 信号 | 检测方法 | 处置 |
|---|---|---|---|
| 1 | 阈值改版 | 对比 `--threshold-version`；某层人数剧烈变化但无对应业务事件 | 全部历史按新阈值重算；无法重算则标断点，两侧不可比 |
| 2 | 未分层用户被丢 | `Σ层人数 ≠ 总用户数`（应 ≤ 总数，差额为 U 层） | 未分层者单列 U 层，出现在矩阵中 |
| 3 | 窗口不等长 | `--prev-window` ≠ `--cur-window` | 统一窗口重算 |
| 4 | 去重口径变化 | 跨端归并规则变更记录 | 同口径重算或标断点 |

### 阈值变更后的正确处理

```
情形 A：可重算 → 用同一套新阈值重算全部历史期，重算后再比较
情形 B：不可重算 → 在图中标注断点线，断点两侧不可直接比较
情形 C：只改层名未改阈值 → 可直接比较，但需核对层序方向是否变化
```

**禁止**：阈值改了但历史用旧规则，且报告中不标断点。

## 六、新进用户与流失用户的处理

跃迁矩阵的行列和未必相等，因为存在：
- **新进用户**：上期不在任何层（本期才首次出现）→ 单列「新进」列
- **流失用户**：上期在层内，本期不活跃/不再被识别 → 单列「流失」列

```
完整矩阵 = (原层 × 原层) + 新进列 + 流失列 + U 层行
```

不单列的后果：新进用户全部算作「升层」，流失用户全部算作「降层」，整体升层率被系统性高估。

## 八、小样本警戒

| 迁出人数 | 判定 | 建议 |
|---|---|---|
| < 30 | 不可作为优化依据 | 看 3 期趋势 |
| 30–100 | 参考 | 需下钻维度确认 |
| > 100 | 可作为依据 | 直接进入排查 |

二项比例标准误近似 `SE ≈ √(p(1-p)/n)`。n=40、p=0.2 时 SE ≈ 6.3pp，即 ±12pp 波动属正常。
