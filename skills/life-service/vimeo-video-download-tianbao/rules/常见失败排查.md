# Vimeo 视频下载与权限核查：常见失败与排查

报错信息请**粘贴原文**再对照。写成「下载失败了」没有排查价值，
写成 `HTTP Error 403` 或 `ffmpeg not found` 才能定位。

## 现象 → 原因 → 处理

| 现象关键词 | 原因与处理 |
| --- | --- |
| 密码 / password / 需要密码 | 密码保护内容不支持也不应下载，请联系作者索取文件或授权。 |
| 域名 / 白名单 / 嵌入 / embed | 白名单嵌入只授权在特定站点播放，无法作为下载源，请向作者索取。 |
| 付费 / ondemand / 购买 | 付费点播内容受版权保护，不支持下载后导出，请通过官方渠道观看。 |
| 没有下载按钮 / 下载不了 | 作者未开启「允许下载」。技术上或可解析，但未经授权的下载存在侵权风险，建议先联系作者。 |
| 字幕没有 / subnotfound | 字幕需单独指定语言轨道下载，且取决于作者是否上传了字幕文件。 |

## 通用故障（各平台都可能遇到）

| 现象 | 处理 |
| --- | --- |
| 403 / 需要登录 / 机器人验证 | 触发反自动化校验：携带登录态或减少请求频率，不要高频重试 |
| 429 / 频繁 / 限流 | 降低请求频率、分批间隔重试 |
| 404 / 失效 / 不存在 | 链接失效或已删除：让对方重新生成分享 |
| 没有声音 / 无音轨 | ffmpeg 未安装或未合并轨：安装后用 `-f "bv*+ba/b"` 合并 |
| 解析失败 / 格式不支持 | 站点接口变动：把工具升级到最新版，而不是换工具 |
| 超时 / 连接失败 | 检查网络可达性后重试 |

## 排查顺序

1. 先确认网络能访问目标平台
2. 再确认目标内容是否属于可下载范围（回到归属判定）
3. 然后确认工具是最新版
4. 最后才怀疑链接本身

九成的「下载失败」卡在第 1 步和第 2 步，而不是工具坏了。
