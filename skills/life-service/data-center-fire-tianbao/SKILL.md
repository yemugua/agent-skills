# 数据中心与机房消防（data-center-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《数据中心设计规范》GB 50174 与机房消防要求，生成数据中心与机房消防清单：机房分级与防火分隔、火灾早期探测（吸气式/极早期）、线缆与阻燃封堵、灭火设施配置、运维巡检与应急。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 数据中心消防
- 机房消防
- IDC消防
- 极早期烟雾探测
- 机房防火封堵

## 三、工作流
1. 明确机房分级与防火分隔
2. 配置火灾早期探测（吸气式）
3. 做好线缆选型与阻燃封堵
4. 配置灭火设施
5. 落实运维巡检与应急

## 四、核心内容（检查清单与判定）
GB 50174 对数据中心分级与消防提出要求；机房宜采用极早期（吸气式）探测以便尽早发现，线缆应阻燃并做防火封堵，防止沿缆蔓延。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含机房分级与防火分隔 | 分隔 |
| Q2 | FAIL | 未含火灾早期探测（吸气式） | 探测 |
| Q3 | WARN | 未含线缆选型与阻燃封堵 | 线缆 |
| Q4 | FAIL | 未含灭火设施配置 | 灭火 |
| Q5 | WARN | 未含运维巡检与应急 | 运维 |

> 脚本 `data-center-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python data-center-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python data-center-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
