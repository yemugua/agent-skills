# 电缆隧道与竖井防火（cable-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《电力工程电缆设计标准》GB 50217 与建筑防火封堵要求，生成清单：阻燃耐火电缆选型、电缆桥架与穿墙封堵、隧道通风与火灾探测、防火分隔与灭火设施、巡检与负荷监测。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 电缆隧道防火
- 电缆竖井封堵
- 阻燃电缆选型
- 电缆桥架防火
- 电缆测温

## 三、工作流
1. 核查阻燃耐火电缆选型
2. 核查桥架与穿墙封堵
3. 落实隧道通风与火灾探测
4. 配置防火分隔与灭火设施
5. 开展巡检与负荷监测

## 四、核心内容（检查清单与判定）
GB 50217 对电缆阻燃与阻火分隔有明确规定；电缆隧道竖井一旦起火蔓延迅速，穿墙封堵必须严密，配合火灾探测与负荷监测可显著降低风险。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含阻燃耐火电缆选型 | 电缆选型 |
| Q2 | FAIL | 未含桥架与穿墙封堵 | 封堵 |
| Q3 | WARN | 未含隧道通风与火灾探测 | 探测 |
| Q4 | WARN | 未含防火分隔与灭火设施 | 分隔 |
| Q5 | WARN | 未含巡检与负荷监测 | 巡检 |

> 脚本 `cable-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python cable-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python cable-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
