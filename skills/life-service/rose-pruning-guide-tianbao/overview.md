# 月季修剪（月季修剪 / rose-pruning-guide）

你会得到什么：一份按品种（灌木 / 微型 / 藤本 / 老桩）和本地气候落地的月季修剪方案——冬季、花后、夏季各自的时机窗口与修剪强度，剪口斜 45 度、留饱满外芽的操作口径，工具消毒与病枝销毁要求，以及五步标准操作顺序（先清病枝枯枝，再疏删、短截、抹砧木芽、伤口处理）。技能内置 `rose_prune_plan.py`，把你的方案写成 JSON 跑一遍，自动标出强度错配（藤本冬季重剪、微型重剪）、漏消毒、剪口角度错、留内芽、顺序颠倒、病枝未销毁等不合格项并附原因。

典型用法：月季冬天该重剪还是轻剪；花谢了从哪剪；剪刀要不要消毒；剪口留几个芽、朝哪边；藤本剪秃了为什么不开花。写成字段交給脚本，立刻拿到「先处理 / 待确认 / 可照此执行」的结论。

边界：本技能只做家庭月季修剪的时机与方法口径，**不诊断病害、不开药、不给农药稀释浓度**。整株黑斑白粉持续扩散、枝干溃疡等请直接联系专业园艺或植保人员。
