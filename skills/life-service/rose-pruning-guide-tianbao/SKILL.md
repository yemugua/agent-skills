# 月季修剪（rose-pruning-guide）

月季「七分靠养，三分靠剪」。剪对了，通风好、病害少、花量大；剪错了，要么剪秃了不开花，要么枝条乱窜闷出病。核心记住三件事：**先剪病枯、留外芽、剪口斜 45 度、刀要消毒**。

这个技能做三件事：**定时机 → 定强度 → 走步骤**。

---

## 一、硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出按品种与气候的修剪时机、强度 | ❌ 给出任何农药的名称、稀释浓度与喷施方案 |
| 给出剪口角度、留芽方向、工具消毒口径 | ❌ 判断月季患的是什么病害并开药 |
| 给出病枝、花后、冬季三类操作步骤 | ❌ 指导大规模苗圃或商业生产的修剪排期 |
| 给出常见错误与转交专业园艺的判断线 | ❌ 承诺任何开花量或株型结果 |

**转交专业园艺/植保人员的情况**

- 整株大面积黑斑、白粉、霜霉且持续扩散
- 枝干流胶、溃疡、枯萎病明显
- 根系或嫁接口严重腐烂
- 不确定品种，无法判断应在新枝还是老枝下剪

## 三、完整工作流

1. **认品种**：灌木、微型、藤本、老桩，强度完全不同。
2. **定时机**：冬季休眠期重/中剪，花后轻剪，夏季只疏不截。
3. **消毒工具**：剪前剪后都用酒精擦刀，病枝单独处理。
4. **清病枝枯枝**：第一步永远是先去掉病、枯、细弱、交叉枝。
5. **疏删过密**：从基部去掉向内、过密、细弱枝，打开冠内通风。
6. **短截壮枝**：留饱满外芽，剪口斜 45 度，距芽 0.5 厘米。
7. **抹砧木芽**：嫁接苗的砧木萌蘖及时抹掉。
8. **伤口处理**：粗枝剪口可涂愈合剂，病枝销毁不堆肥。
9. **核对**：用 `--file` 跑一遍，把错强度、错角度、错顺序、漏消毒先排掉。

## 四、核心规则说明

**动手之前必须先读这两个文件，不要凭印象写：**

- `rules/修剪时机与强度.md` —— 按品种的时机窗口与修剪强度，藤本/老桩的特殊处理
- `rules/工具与操作步骤.md` —— 工具消毒、剪口角度、留芽方向、五步操作顺序

要点三条：

1. **先清病枯再整形**。带着病枝直接整形，刀一过就传播，是月季修剪头号错误。
2. **剪口留外芽、斜 45 度**。留内芽新枝向内交叉，平剪积水烂芽。
3. **藤本月季冬天别重剪**。它靠老枝开花，重剪等于把花剪没了。

## 五、脚本用法

```
python scripts/rose_prune_plan.py --selftest
python scripts/rose_prune_plan.py --file rose.json
```

输入字段：

| 字段 | 说明 | 示例 |
|---|---|---|
| plant_type | 品种 | 「灌木月季」「微型月季」「藤本月季」「老桩月季」 |
| pruning_time | 修剪时机 | 「冬季休眠期」「花后」「夏季」 |
| prune_strength | 修剪强度 | 「重剪」「中剪」「轻剪」 |
| tool_sanitized | 工具是否消毒 | true |
| cut_angle | 剪口角度度 | 45 |
| bud_direction | 留芽方向 | 「外芽」「内芽」 |
| has_disease | 是否有病枝 | false |
| dispose_diseased | 病枝是否销毁 | true |
| steps | 操作顺序列表 | 见规则文件 |

结论分三档：**先处理**（强度错配、漏消毒、角度错、留内芽、顺序错、病枝未销毁）、**待确认**（信息不足）、**可照此执行**。存在真实缺陷时即使信息也不完整仍判先处理。

结果写入 `scripts/_last_result.txt`，每条不合格带原因。

## 六、人工确认清单（这步不能省）

- [ ] 已确认品种，强度是按这个品种取的
- [ ] 修剪时机与本地气候、植株状态对得上
- [ ] 剪刀剪前剪后都消毒，病枝用单独工具/单独擦
- [ ] 第一步是清病枝枯枝，不是直接整形
- [ ] 剪口斜 45 度，距饱满外芽约 0.5 厘米
- [ ] 留的是外芽，没有留内芽
- [ ] 病枝已销毁，没有丢进堆肥
- [ ] 嫁接苗砧木萌蘖已抹掉
- [ ] 粗剪口做了防护，植株无持续病害

## 七、最常见的坑

1. **带着病枝直接整形**。刀把孢子带得到处都是，黑斑白粉爆发。
2. **藤本冬天重剪**。老枝是花芽所在，剪光了夏天没花。
3. **平剪或留内芽**。平剪积水烂芽，内芽让枝条互相穿插、冠内闷湿。
4. **剪口离芽太远或太近**。远了枝枯一段，近了芽干死。
5. **不消毒反复用一把刀**。一株染病全园传染。
6. **夏季重剪**。高温期重剪应激大，夏季只疏不截。
7. **盲枝不处理**。顶端无芽的盲枝白占养分，应从基部疏掉。
8. **砧木芽留着长**。抢养分还改变株型，嫁接苗必须抹。
