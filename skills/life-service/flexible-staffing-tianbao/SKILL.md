# 灵活用工与劳务派遣（flexible-staffing）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据劳务派遣与灵活用工规定，生成清单：用工形式选择（派遣/外包/兼职/实习）、派遣三性岗位与比例限制、供应商资质与协议、同工同酬与工伤责任、合规风险排查。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 灵活用工
- 劳务派遣
- 劳务外包
- 派遣比例
- 同工同酬

## 三、工作流
1. 选择用工形式与适用场景
2. 核查派遣三性岗位与比例
3. 审查供应商资质与协议
4. 落实同工同酬与工伤责任
5. 排查合规风险并整改

## 四、核心内容（检查清单与判定）
劳务派遣只能在临时性、辅助性、替代性岗位使用并受比例限制，须由具备资质单位派遣；用工单位对同工同酬与工伤承担相应责任。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含用工形式与适用场景 | 形式 |
| Q2 | FAIL | 未含派遣三性岗位与比例 | 比例 |
| Q3 | WARN | 未含供应商资质与协议 | 资质 |
| Q4 | FAIL | 未含同工同酬与工伤责任 | 同工同酬 |
| Q5 | WARN | 未含合规风险排查 | 排查 |

> 脚本 `flexible-staffing_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python flexible-staffing_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python flexible-staffing_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
