# 加油加气站消防安全（gas-station-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《汽车加油加气加氢站技术标准》GB 50156，生成加油加气站消防安全清单：站址与站内防火间距、储罐与储气瓶组、卸油加气作业区、防雷防静电与接地、消防器材与动火管理。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 加油站消防
- 加气站
- 加油加气站
- 卸油区
- 储气瓶组

## 三、工作流
1. 核查站址与站内防火间距
2. 检查储罐与储气瓶组布置
3. 管控卸油加气作业区
4. 落实防雷防静电与接地
5. 配置消防器材并管理动火

## 四、核心内容（检查清单与判定）
GB 50156 规定加油加气加氢站的站址、间距、储罐与工艺设施安全要求；卸油加气区须防雷防静电，消防器材按需配置并严格动火管理。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含站址与站内防火间距 | 间距 |
| Q2 | FAIL | 未含储罐与储气瓶组布置 | 储罐 |
| Q3 | WARN | 未含卸油加气作业区管控 | 作业区 |
| Q4 | FAIL | 未含防雷防静电与接地 | 防静电 |
| Q5 | WARN | 未含消防器材与动火管理 | 器材 |

> 脚本 `gas-station-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python gas-station-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python gas-station-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
