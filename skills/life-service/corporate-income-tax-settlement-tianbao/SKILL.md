# 企业所得税汇算清缴纳税调整核查

汇算清缴的本质是：**会计利润不是应纳税所得额**。中间隔着一大堆限额扣除、不得扣除、加计扣除与弥补亏损的调整项。调错一项，税额就差一截。

这个技能做五件事：**取会计利润 → 逐项算调整 → 算应纳税所得额 → 套税率 → 核汇算期**。

---

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 按给定数据核算调整项与应纳税额 | 代替企业登录电子税务局提交年度申报 |
| 逐项核对限额扣除类费用的调整口径 | 编造成本费用、收入或亏损数据 |
| 提示优惠税率的适用条件与判断维度 | 保证一定享受某项优惠、一定能通过备案或核查 |
| 输出调整依据清单与复核要点 | 提供转移利润、虚列成本、隐瞒收入的避税方案 |
| 提示汇算期与逾期后果 | 代替税务机关作认定或核定 |

涉及以下情形，应停下来交由税务机关、会计师、税务师或律师处理：**重大资产重组与特殊性税务处理、跨境关联交易与转让定价、境外所得抵免、税务稽查或纳税评估、优惠政策适用存在争议、以前年度重大差错更正**。

**绝对不做**：不虚列成本费用、不隐瞒收入、不虚构交易转移利润、不提供任何以少缴税为目的的虚假安排。

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「汇算清缴纳税调整怎么调」 | 用，逐项核调整项 |
| 「业务招待费能扣多少」 | 用，按 60% 与收入 5‰ 孰低核 |
| 「广告费超了怎么办」 | 用，核限额与结转 |
| 「研发费用加计扣除怎么算」 | 用，按现行比例核 |
| 「亏损能弥补几年」 | 用，按结转年限核 |
| 「小型微利企业税率多少」 | 用，按现行优惠口径核，并核条件 |
| 「汇算什么时候截止」 | 用，按年度终了起 5 个月核（5 月 31 日） |
| 「怎么把利润做低少交税」 | 不用，拒绝提供避税筹划方案 |

## 三、完整工作流

```
第 1 步  取会计利润：以年度利润表的利润总额为准，与总账、明细账核对
第 2 步  读规则文件 rules/cit-adjust-rules.md（调整项、限额比例、不得扣除项、优惠税率）
第 3 步  核收入类调整：免税收入、减计收入、不征税收入、视同销售
第 4 步  核扣除类调整：限额扣除（招待费、广告费、福利费、工会经费、职工教育经费、捐赠等）
第 5 步  核不得扣除项目：税收滞纳金、罚金罚款、赞助支出、未经核定的准备金等
第 6 步  核加计扣除：研发费用加计扣除等，按现行比例与条件
第 7 步  跑脚本核算：scripts/cit_adjust_calc.py --file case.json
第 8 步  核亏损弥补：以前年度可弥补亏损额与结转年限
第 9 步  套税率与优惠：一般税率 / 小型微利 / 高新技术等，核条件是否满足
第 10 步 申报与归档：在汇算期内完成年度申报，保存申报表、调整计算表与依据材料
```

## 四、核心计算口径

### 4.1 应纳税所得额

```
应纳税所得额 = 会计利润总额
             + 纳税调整增加额
             − 纳税调整减少额
             − 免税、减计收入及加计扣除
             ± 境外应税所得抵减
             − 抵扣应纳税所得额
             − 弥补以前年度亏损

应纳税额 = 应纳税所得额 × 适用税率 − 减免税额 − 抵免税额
```

**结果可以为负**：为负时当年不缴企业所得税，亏损按政策规定结转以后年度弥补。

### 4.2 常见限额扣除口径

| 项目 | 限额口径 | 超出部分 |
|---|---|---|
| 业务招待费 | 按发生额的 **60%** 扣除，且不超过当年销售（营业）收入的 **5‰**，**两者取低** | 不得扣除，也不得结转 |
| 广告费和业务宣传费 | 不超过当年销售（营业）收入 **15%** 的部分准予扣除（特定行业按现行规定比例更高） | 准予结转以后年度扣除 |
| 职工福利费 | 不超过工资薪金总额 **14%** | 不得扣除 |
| 工会经费 | 不超过工资薪金总额 **2%**（凭工会组织开具的专用收据） | 不得扣除 |
| 职工教育经费 | 不超过工资薪金总额 **8%** | 准予结转以后年度扣除 |
| 公益性捐赠 | 不超过年度利润总额 **12%** 的部分准予扣除 | 准予结转以后三年内扣除 |
| 研发费用加计扣除 | 按现行政策规定的比例加计扣除 | 以公布口径为准 |

> 以上比例为现行常见口径，**具体比例与适用条件以现行税法及税务机关公布口径为准**。

### 4.3 不得扣除项目（全额调增）

- 税收滞纳金
- 罚金、罚款和被没收财物的损失
- 非广告性质的赞助支出
- 未经核定的准备金支出
- 与取得收入无关的其他支出
- 直接向受赠人的捐赠（非公益性捐赠）

### 4.4 税率与优惠口径

| 类型 | 口径 |
|---|---|
| 一般企业 | 法定税率按现行规定执行（**以现行税法为准**） |
| 小型微利企业 | 按现行政策享受优惠税率（常见口径为应纳税所得额减按一定比例计入后按较低税率计算，实际税负较低），**须同时满足从业人数、资产总额、应纳税所得额等条件** |
| 高新技术企业 | 按现行政策享受优惠税率，**须取得有效资格并在规定期限内** |
| 其他区域性、行业性优惠 | 按现行政策规定执行 |

**优惠不是自动享受的**：条件、备案或申报方式、留存备查资料都要核。**以现行规定和税务机关口径为准。**

### 4.5 亏损弥补

| 项目 | 口径 |
|---|---|
| 一般企业 | 当年亏损准予向以后年度结转，结转年限按现行规定（常见为 **5 年**） |
| 特定类型企业 | 部分类型企业结转年限更长（按现行规定，**以公布口径为准**） |
| 弥补顺序 | 先到期先弥补，逐年在可弥补额度内扣除 |

### 4.6 汇算期与逾期

| 项目 | 口径 |
|---|---|
| 汇算期限 | 自年度终了之日起 **5 个月内**（次年 5 月 31 日前），以税务机关公告为准 |
| 季度/月度预缴 | 按规定的期限预缴，年度终了后汇算清缴，多退少补 |
| 逾期未申报或少缴 | 税务机关责令限期改正，可并处罚款；**从滞纳税款之日起按日加收滞纳金**，以税务机关核定为准 |

## 五、防误伤（否定词清单）

- 「会计利润为正」≠「应纳税所得额为正」。调整后可能为负，不得直接用会计利润乘税率。
- 「不征税收入」≠「免税收入」。两者对应的支出处理不同，不得混用。
- 「限额扣除」≠「全额扣除」。超出限额必须调增，不得遗漏。
- 「广告费超限额」≠「永久不能扣」。超限额部分可结转以后年度，调增的同时要登记结转台账。
- 「亏损已弥补」需核对**剩余可弥补额度**，不得把已过结转年限的亏损继续弥补。
- 「优惠资格在申请中」→ 判为**未取得**，不得按优惠税率计算。
- 「已申报未缴款」→ 判为**未完成**，不得写成「已办结」。
- 「研发费用归集未分摊」→ 判为**口径未定**，不得直接按全额加计扣除。

## 六、核心规则与要件库

出结论或填申报表前，**必须先读**：

- `rules/cit-adjust-rules.md`：调整项清单与比例、不得扣除项、加计扣除条件、亏损弥补、税率与优惠适用条件、汇算期与逾期、常见差错与复核要点、留存备查资料清单。

不得凭上年数据直接套用本年，不得按优惠税率计算而忽略资格条件。

## 七、脚本用法

```bash
python scripts/cit_adjust_calc.py --file case.json --out 纳税调整测算.md
python scripts/cit_adjust_calc.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：会计利润、销售收入、工资薪金总额、各项费用发生额、研发费用与加计比例、不得扣除项目、以前年度可弥补亏损、税率与优惠标志 |
| `--text` | 直接给 JSON 字符串 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检 |

输入 JSON 示例：

```json
{
  "accounting_profit": 1200000,
  "revenue": 20000000,
  "wage_total": 3000000,
  "entertainment": 120000,
  "advertising": 4000000,
  "welfare": 500000,
  "union_fee": 70000,
  "education_fee": 300000,
  "donation": 200000,
  "rd_expense": 1000000,
  "rd_add_rate": 1.0,
  "penalty": 20000,
  "sponsorship": 30000,
  "prior_loss": 200000,
  "tax_rate": 0.25,
  "small_low_profit": false,
  "high_tech": false
}
```

脚本输出：每项费用的限额、可扣除额与调增/调减额、调整合计、弥补亏损后的应纳税所得额、适用税率、应纳税额、实际税负、广告费结转台账提示与汇算期提示。

> 脚本按你填的数据做静态测算，**未含境外所得抵免、资产与递延所得税、特殊性税务处理、区域性优惠等**；比例、条件与税率以现行税法及税务机关口径为准。

## 八、人工确认清单（这步不能省）

- [ ] 会计利润与年度利润表、总账一致，不是估算
- [ ] 销售收入口径与招待费、广告费的限额计算基数一致
- [ ] 工资薪金总额为**实际发放且合理的**工资薪金，含范围已核实
- [ ] 限额扣除项逐项算过，超出部分已调增
- [ ] 不得扣除项目已全额调增（滞纳金、罚款、赞助、准备金等）
- [ ] 研发费用已按口径归集与分摊，加计比例按现行规定
- [ ] 以前年度亏损余额与剩余结转年限已核实
- [ ] 优惠税率的资格条件、有效期与留存备查资料已核
- [ ] 调整计算表与依据材料已归档
- [ ] 在汇算期内完成申报，并保存申报回执

## 九、最常见的坑

1. **直接用会计利润乘税率。** 会计利润与应纳税所得额之间隔着限额扣除、不得扣除、加计扣除与弥补亏损，直接相乘必然算错。
2. **业务招待费只按 60% 算，忘了收入 5‰ 的封顶。** 正确口径是**两者取低**：发生额的 60% 与销售收入的 5‰ 中较小的那个才是可扣除额。
3. **广告费超限额就直接放弃。** 广告费和业务宣传费超限额部分**准予结转以后年度扣除**，调增的同时必须登记结转台账，否则以后年度白白损失扣除额。
4. **职工教育经费按旧比例算。** 比例已调整为工资薪金总额的 8%，且超限额部分可结转。用旧比例会调增过多。
5. **捐赠全额扣除。** 公益性捐赠在年度利润总额 12% 以内扣除，超出部分结转以后三年；**直接向受赠人的捐赠不属于可扣除的公益性捐赠**。
6. **把不征税收入当免税收入。** 两者对应的支出处理不同：不征税收入对应的支出通常也不得扣除，混用会导致调整方向错误。
7. **亏损无限期弥补。** 结转年限按现行规定（一般企业常见为 5 年），超过年限的亏损不能再弥补，要核对剩余额度。
8. **优惠税率直接套用。** 小型微利、高新技术都有明确的条件与期限，资格在申请中或已过期的，不得按优惠税率计算。
9. **研发费用未按口径归集。** 研发费用需与其他费用合理划分、分别核算，混在一起直接全额加计扣除，容易在后续核查中被调整。
10. **拖到 5 月 31 日之后才申报。** 逾期按日加收滞纳金并可能被责令改正、处以罚款。**汇算工作应在年度结账后尽早启动。**

## 十、边界与免责

- 本技能用于汇算前核查与材料整理，**不构成税务代理、审计或法律意见**，不替代企业申报与税务机关认定
- 扣除比例、加计扣除条件、亏损结转年限、税率与优惠适用条件、汇算期限，**均以现行税法及税务机关公布口径为准**
- 本测算为**静态口径**，未含境外所得抵免、递延所得税、特殊性税务处理、区域性优惠等特殊情形
- **不承诺一定享受某项优惠、一定按某个金额缴纳**
- 不提供虚列成本、隐瞒收入、虚构交易转移利润的任何方案；涉及稽查、纳税评估或争议，应及时咨询税务师或律师
