# 糖尿病饮食搭配与主食升糖控制

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 给出主食定量、配餐结构和进餐顺序的通用口径 | 制定个人化治疗方案、调整降糖药或胰岛素剂量 |
| 按食物成分表口径估算碳水克数与交换份 | 承诺某种食物能降糖、根治或替代药物 |
| 解释升糖指数、升糖负荷的读法与局限 | 推荐具体药品、保健品或品牌 |
| 提示哪些情况需要尽快就医 | 解读化验单并下诊断结论 |
| 输出配餐记录表与就诊提问清单 | 给妊娠糖尿病、1 型糖尿病儿童单独定方案（需专科营养师） |

**就医红线（出现任一条，尽快就医；标注急诊的直接去急诊）**

- 血糖明显偏低（常见低血糖阈值按 3.9 mmol/L 口径，以医生给的个人目标为准）并出现心慌、手抖、出汗、饥饿、头晕、行为异常
- 低血糖且进食后 15 分钟不缓解、意识模糊、抽搐、昏迷 —— 急诊
- 血糖持续明显偏高（常见口径 ≥16.7 mmol/L）伴口渴、多尿、乏力、视物模糊
- 恶心呕吐、腹痛、呼吸深快、呼气有烂苹果味、嗜睡 —— 疑似酮症，急诊
- 胸痛、胸闷、一侧肢体无力、说话不清、口角歪斜 —— 急诊
- 视力骤降、眼前黑影飘动、视物变形
- 足部破溃、红肿、发黑、流脓，或足部感觉明显减退伴外伤
- 严重腹泻呕吐导致进食进水困难、明显脱水
- 发热伴血糖失控、反复低血糖

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「一顿吃多少米饭合适」 | 用，给出定量口径与个体化由营养师确认 |
| 「水果能不能吃、吃多少」 | 用 |
| 「无糖饼干可以多吃吗」 | 用，说明无糖不等于无碳水 |
| 「粥升糖快是不是不能喝」 | 用，说明糊化程度的影响 |
| 「帮我算今天吃了多少碳水」 | 用，脚本核算 |
| 「我该打多少胰岛素」 | 不用，必须由医生调整 |
| 「血糖 20 了怎么办」 | 只作就医提示 |

## 三、完整工作流

1. **先排红线**：逐条核对就医红线，命中则停止配餐建议，转为就医提示。
2. **收集基础信息**：身高体重、活动量、当前用药类型（是否用胰岛素或促泌剂）、医生给的血糖目标、肾功能与并发症情况。
3. **定主食总量**：按 `rules/主食与配餐规则.md` 的交换份口径给出每日与每餐份数区间，标注需营养师个体化确认。
4. **配一餐结构**：按「蔬菜—蛋白—主食」的进餐顺序和盘子比例搭一餐。
5. **核算碳水**：用脚本按食物成分表口径计算该餐碳水总量与交换份数，与设定目标对比。
6. **标注 GI 与做法**：对高 GI 或糊化程度高的做法给出替换方案。
7. **记录与反馈**：填入 `templates/配餐记录表.md`，记录餐后 2 小时血糖与主观饥饿感，复诊时带给医生。

## 四、核心规则与要件库

生成配餐建议前，**必须先读**：

- `rules/主食与配餐规则.md`：主食定量、交换份、进餐顺序、做法影响、无糖食品陷阱。
- `templates/配餐记录表.md`：每日配餐登记、碳水核算和餐后血糖记录表。

不得把「无糖」「不甜」「粗粮」等同于「不升糖」；不得因食物 GI 低就建议不限量。所有数值为通用食物成分表口径，品种、产地、做法差异很大。

## 五、脚本用法

```
python scripts/carb_exchange_calc.py --file meal.json
python scripts/carb_exchange_calc.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`items` 为食物名与重量列表，`target_carb` 为该餐碳水目标克数 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--json` | 以 JSON 输出 |
| `--selftest` | 运行自检 |

脚本按内置食物成分表口径输出每项的碳水克数、交换份数、合计与是否超目标，并标出高升糖指数食物。**未收录的食物不会凭空估算，会列为待确认项。**

## 六、人工确认清单

- [ ] 就医红线已排除
- [ ] 身高体重、活动量、用药类型（尤其是否用胰岛素或促泌剂）已确认
- [ ] 医生给出的个体化血糖目标已记录
- [ ] 主食份数按营养师或医生意见确认，不是自行套用
- [ ] 肾功能、并发症、食物过敏与不耐受已告知
- [ ] 食物重量按可食部生重或熟重区分，未混用
- [ ] 餐后 2 小时血糖记录口径与医生要求一致
- [ ] 出现反复低血糖已及时就医，不是自行减药

## 七、最常见的坑

1. **「无糖」就放开吃**：无糖食品只是不加蔗糖，淀粉和油脂照样升糖、升热量。
2. **只盯主食不管油**：坚果、花生、肥肉、油炸食品不含多少碳水，但热量高、影响体重和胰岛素敏感性。
3. **粗粮无限量**：粗粮也是碳水，量大同样升糖，且部分人胃肠不耐受。
4. **喝粥当养胃**：熬煮时间越长糊化程度越高，升糖越快；改成整粒、干饭更好。
5. **水果只看甜不甜**：不甜的水果（如火龙果）也有碳水，甜的水果（如西瓜）单位重量碳水反而较低，关键在量。
6. **果汁代替水果**：榨汁破坏膳食纤维，升糖明显加快。
7. **不吃主食控糖**：长期极低碳水有酮症和低血糖风险，尤其用胰岛素或促泌剂者。
8. **把「餐后 2 小时」记错起点**：从第一口饭开始计时，不是吃完才计时。

## 八、边界与免责

本技能提供糖尿病饮食搭配的通用口径和碳水核算工具，不构成医疗建议、营养处方或治疗方案。食物成分数值来自通用食物成分表口径，品种与做法差异较大；热量与碳水目标、血糖控制目标、妊娠糖尿病与儿童糖尿病的营养方案差异很大，**以最新版临床营养指南和内分泌科医师、注册营养师的判断为准**。出现就医红线中的任一情况，请立即就医。
