# 物业费争议与拒缴抗辩核查（property-fee-dispute-check）

物业费争议的核心不是「要不要交」，而是**三个数**：该由谁交、交多少、其中多少已经过了三年。

这个技能做三件事：**算账** → **分级** → **出抗辩意见**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 按面积单价月数逐期核算欠费 | ❌ 判定物业服务是否达标 |
| 拆分哪部分是本金、哪部分是违约金 | ❌ 代替业主作出是否拒缴的决定 |
| 核查逐期诉讼时效是否届满 | ❌ 代理应诉或代签法律文书 |
| 给抗辩事由做 A/B/C 分级 | ❌ 承诺法院一定支持某项减免 |
| 生成书面质询与沟通留痕要点 | ❌ 建议删改签名、伪造签收或催缴记录 |

**遇到以下情况，务必咨询当地专业律师或主管部门：**

- 已被物业公司起诉或收到法院传票
- 涉及业主大会决议、业委会选举等集体程序争议
- 争议金额较大或已累计多年
- 物业公司已进入清算、更换频繁，账目混乱

**不要因为物业服务有瑕疵就建议用户全额拒缴并停止一切沟通。**全额拒缴通常只会扩大违约金与诉讼风险。

## 二、完整工作流

```
第 1 步  拿到三样东西：物业服务合同、不动产权面积、欠费明细单

第 6 步  输出「无争议金额」与「争议金额」分列的意见材料
```

## 三、金额核算（三层，缺一层都不算数）

规则全文在 `rules/fee_calculation.md`。

### 第一层：本金

```
期数金额 = 计费建筑面积 × 单价(元/㎡·月) × 月数
欠费本金 = Σ 各期欠缴金额
```

| 必须核对的输入项 | 以什么为准 |
|---|---|
| 计费面积 | 不动产权证书记载的建筑面积 |
| 单价 | 物业服务合同、业主大会决议或当地政府指导价 |
| 起算时间 | **交房之日**起，不是买房、不是装修之日 |
| 缴费主体 | 交房前由建设单位承担，交房后由业主承担 |

### 第二层：滞纳金

```
滞纳金 = 该期欠缴本金 × 约定日利率 × 逾期天数
```

| 约定日利率 | 年化 | 判定 |
|---|---|---|
| 万分之三 | 约 10.95% | 常见，一般可接受度较高 |
| 万分之五 | 约 18.25% | 偏高，可争取调减 |
| 千分之一 | 约 36.5% | 明显偏高，建议主张调整 |
| 千分之三 | 约 109.5% | 畸高，极可能被调减，重点抗辩对象 |

### 第三层：诉讼时效

```
普通诉讼时效 3 年，物业费债权逐期分别起算
```

- 口头催缴**一般不认定**为有效中断
- EMS 催缴函 + 业主签收 → 中断成立，从签收日**重新计算**三年
- 时效届满不等于债务消灭，只是产生抗辩权；主动清偿后不能再要求返还

> 收费标准、空置房减免与滞纳金上限口径各地不同，**以现行规定和当地主管部门要求为准**。

## 四、抗辩事由三级分级

`rules/defense_grounds.md` 里有完整清单，这里给判定口径：

| 级别 | 含义 | 典型事由 |
|---|---|---|
| **A 级｜可主张免除** | 缴费义务本身不成立或主体错误 | 未交付、无进驻依据、已过时效、收费无约定、重复计费 |
| **B 级｜可主张减免** | 履约有瑕疵但不导致义务消灭 | 服务不到位、维修拖延、安保缺位、收费未公示、空置（有地规） |
| **C 级｜不成立** | 法律或实践不支持 | 长期不住、不用电梯、服务态度、他人未缴、租客承担、开发商遗留问题 |

**B 级事由的共同局限：物业服务面向全体业主整体给付，个别瑕疵通常不支持全额免除。**

## 五、脚本用法

```bash
python scripts/fee_check.py --file 催缴单.txt --area 89.6 --unit 2.5 --from 2019-01 --to 2025-12 --rate-daily 0.0005
```

| 参数 | 说明 |
|---|---|
| `--file` | 催缴单或起诉状文本（`.txt` / `.md`） |
| `--area` | 计费建筑面积（㎡），必填 |
| `--unit` | 单价（元/㎡·月），必填 |
| `--from` | 欠费起始月份，格式 `2021-03` |
| `--to` | 欠费截止月份，格式 `2025-12` |
| `--paid-months` | 已缴纳的月份数（从台账中扣除） |
| `--rate-daily` | 合同约定的滞纳金日利率，如 `0.003` 表示千分之三 |
| `--as-of` | 核算基准日，默认今天，用于时效计算 |
| `--delivery-date` | 交房日期，用于判定缴费主体起算点 |
| `--out` | 输出路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本做五件事：
1. **逐期本金核算** —— 按月生成台账
2. **滞纳金风险分级** —— 把日利率换算年化并对照风险表
3. **诉讼时效核查** —— 逐期三年，标出已过期数
4. **主体起算核查** —— 交房日之前的期数标为「建设单位承担待核实」
5. **否定词防误伤** —— 检出「未交房」「未收到催缴」等表述，强制进「待核实」栏

> ⚠️ 脚本只做算术与关键词匹配，**不代表司法机关对时效中断或违约金调整的认定**。

## 六、人工确认（这步不能省）

- [ ] 计费面积与不动产权证书是否一致（非套内、非开发商单方口径）
- [ ] 单价是否为**现行有效**标准，有无业主大会调价决议
- [ ] 交房日是否已有书面交付文件支撑
- [ ] 每一条抗辩事由有没有**带日期**的证据（事后补拍证明力弱）
- [ ] 时效结论是否逐期核查过中断事由
- [ ] 金额表有没有分「无争议」与「争议」两栏
- [ ] 是否存在 C 级事由被误当成 A 级写进结论

**三类高频错误，见到就退回：**

| 错误 | 表现 | 后果 |
|---|---|---|
| 理由不成立却全额拒缴 | 「我不用电梯所以不交」 | 违约金滚大，败诉风险高 |
| 滞纳金当主要战场 | 本金没核就去谈滞纳金 | 抓错了重点 |
| 缺乏当时证据 | 只有事后补拍照片 | 减免主张难获支持 |

## 七、输出结构（固定六段）

1. **结论先行** —— 哪些期间应当缴纳、哪些存在实质争议、建议如何处置
2. **欠费台账** —— 逐期列出期间、金额、是否在时效内
3. **滞纳金核算与合理性意见** —— 日利率、年化换算、风险级别、建议主张区间
4. **抗辩事由分级表** —— 事由、级别、证据情况、是否需要补充
5. **书面主张要点** —— 只写三点：不认可的期间、理由、要求的处理
6. **边界与口径** —— 以现行规定和当地主管部门要求为准

## 八、最常见的坑

**坑一：用「我没享受到服务」当主要理由。**
物业服务是对整个物业区域的给付，不以个别业主是否使用为前提。这个理由几乎必然落到 C 级。

**坑二：先拒缴再谈判。**
争议期间照常缴纳无争议部分，是控制违约金成本的关键动作。全额拒缴往往让原本几百块的争议变成几千块的违约金。

**坑三：把开发商的问题装进物业账单。**
房屋质量、延期交房是买卖合同关系，与物业服务不是同一法律关系，混在一起主张会被驳回。

**坑四：催缴函随手签收或不收。**
签收会构成诉讼时效中断，拒收同样可能被认定送达。碰到有争议的催收，先核实时效再决定是否签收，并留存函件原件。

**坑五：以为时效三年是整单倒推。**
物业费逐期分别起算，不是从最后一期往前数三年。必须拆到期。

**坑六：日利率小数位看错。** `日万分之五` 与 `日千分之五` 差十倍，年化差出上百个百分点，务必逐位确认小数表记。

**坑七：抗辩意见里混着谴责语句。**
「物业态度恶劣」「管理混乱」这类表述对结果没有帮助，只会让材料看起来情绪化。要写期间、金额、证据编号。

## 九、边界与免责

- 本技能**不代替**律师意见，也不代理应诉
- 是否主张时效抗辩、是否减免属于当事人自主决定，本技能不替代决策
- 收费标准、空置房减免、滞纳金调整口径**以现行规定和当地主管部门要求为准**
- **严禁**用于伪造交付文件、催缴签收记录或缴费凭证
