# 物业费核算规则（本金／滞纳金／时效）

> 全部金额与时间口径以**现行规定、物业服务合同约定和当地主管部门要求为准**。
> 各地空置房减免、收费标准、资金监管规则不同，本文件只给**算式与核查顺序**。

---

## 一、本金怎么算

```
期数金额 = 计费建筑面积(㎡) × 单价(元/㎡·月) × 月数
欠费本金 = Σ 各期欠缴金额
```

### 四个必须核对的输入项

| 输入项 | 以什么为准 | 常见错误 |
|---|---|---|
| **计费面积** | 不动产权证书记载的建筑面积｜经房产测绘确认的面积 | 按套内面积算、按开发商单方口径算 |
| **单价** | 物业服务合同、业主大会决议、当地政府指导价 | 沿用入住时的老标准，忽略已变更的调价文件 |
| **起算时间** | **交房之日起**，不是买房之日、不是装修之日 | 未交付房屋却从买卖合同签订日起算 |
| **缴费主体** | 已交房后由业主承担，未交房由建设单位承担 | 把开发商应承担的期间算到业主头上 |

> **记忆点：未交付房屋的物业费由建设单位承担。**业主从完成交付之日起才开始承担缴费义务。

---

## 二、四档缴费主体归属

| 阶段 | 承担人 | 依据方向 |
|---|---|---|
| 房屋未交付给买受人 | 建设单位（开发商） | 买卖合同与前期物业服务合同另有约定的从其约定 |
| 已交付但未装修入住（空置） | 业主 | 是否可减免按当地规定，无特别规定一般全额缴纳 |
| 已装修出租 | 业主，可与承租人约定转嫁 | 约定不得对抗物业公司 |
| 房屋已转让 | 交付前的欠费由原业主结清 | 需核查是否有约定，公示核实后再主张 |

**物业费是业主对整个物业管理区域的共同义务，不能因为个人未使用某一项服务而免除。**

---

## 三、滞纳金／违约金的核算口径

```
滞纳金额期 = 该期欠缴本金 × 约定日利率 × 逾期天数
```

### 三条核查线

1. **约定优先但有上限** —— 合同约定的滞纳金不得畸高；约定过高的，可请求调整为合理数额
2. **司法审查口径** —— 一般以「实际损失」为基础衡量，明显超过实际损失的部分难以获得支持；实践中常参照**同期贷款市场报价利率（LPR）的一定倍数**作为合理性参照
3. **本息合计的软上限** —— 滞纳金滚过本金数倍时，被整体调减的可能性极高

| 约定日利率 | 年化换算 | 风险判定 |
|---|---|---|
| 万分之三（0.03%/日） | 约 10.95%/年 | 常见，一般可接受度较高 |
| 万分之五（0.05%/日） | 约 18.25%/年 | 偏高，可争取调减 |
| 千分之一（0.1%/日） | 约 36.5%/年 | 明显偏高，建议主张调整 |
| 千分之三（0.3%/日） | 约 109.5%/年 | 畸高，极可能被调减，重点抗辩对象 |

> 约定违约金过分高于造成的损失时，可以请求人民法院或者仲裁机构适当减少，这是合同领域的一般规则。具体倍数以现行规定和当地口径为准。

## 四、诉讼时效（最容易漏的抗辩）

```
普通诉讼时效 = 3 年，自权利人知道或应当知道权利受损害及义务人之日起算
物业费债权  = 逐期分别起算（每期期满之日各算一次起算点）
```

### 核查步骤

1. 把欠费拆到**每一年、每一期**
2. 对每一期单独计算：今天 − 该期起算日 是否 > 3 年
3. 检查期间有没有**催缴函、律师函、部分还款、诉讼材料签收**等中断事由
4. 有中断的，从中断之日起**重新计算 3 年**

| 情形 | 判定 |
|---|---|
| 物业公司口头催过，但没有书面凭证 | 一般不认定为有效中断 |
| 有 EMS 催缴函 + 邮寄凭证 + 业主签收 | 中断成立，须从签收日重新算三年 |
| 业主曾经缴纳过其中一期 | 就该期而言履行完毕，其余期不受影响 |
| 长期无任何催收动作 | 超期部分丧失胜诉权，可在诉讼中提出抗辩 |

> **重要区分：诉讼时效届满不等于债务消灭**，只是债务人获得抗辩权。主动清偿后不能再要求返还。是否主张时效抗辩由业主自己决定。

## 五、核价顺序（照这个顺序走）

```
第 1 步  先算该不该由你承担  —— 交房前？开发商责任？
第 2 步  再算面积单价对不对  —— 证载面积 vs 计费面积
第 3 步  再算起算时间对不对  —— 交房日 vs 其他口径
第 4 步  再拆分 outsourcing  —— 哪些是合同内，哪些是未经业主大会同意的加收项
第 5 步  再核时效            —— 逐期三年，把超期部分单列
第 6 步  最后才看滞纳金      —— 本金定不下来，滞纳金不可能算对
```

## 六、常见算错的六个点

| 错在哪 | 正确做法 |
|---|---|
| 用一个总数跟物业对峙 | 拆到每一年、每一期、每一笔 |
| 把滞纳金当成主要争议 | 本金才是主战场，滞纳金是附带项 |
| 用服务瑕疵抵销全部物业费 | 服务瑕疵一般只支持部分减免，不支持全额免除 |
| 以为空置房一定半价 | 各地口径不同，无明确规定即全额 |
| 以为时效三年整单一刀切 | 逐期分别起算，不是从最后一期倒推三年 |
| 拒缴所有费用导致违约扩大 | 有争议的部分另行主张，**无争议部分照缴**，避免滚雪球 |

## 七、否定词防误伤表

| 材料里这样写 | 不能理解成 | 应判为 |
|---|---|---|
| 未交房、尚未交付 | 应由业主缴纳 | 缴费主体存疑，须核交付日 |
| 未提供物业服务的同时 | 服务完全达标 | 服务存疑，但不等同于可全免 |
| 未缴纳、欠缴 | 已缴清 | 状态：欠缴，需核算金额 |
| 未收到催缴函 | 已催缴 | 未中断，时效可能已过 |
| 未提供某项服务、服务不到位 | 可以拒缴全部 | 属履约瑕疵，按瑕疵程度争取部分减免 |
| 不能证明已交付 | 已交付 | 交付事实待核实 |

**输出规则：凡带否定词的描述，一律不转换为肯定结论；存疑项进"待核实"栏，不进"欠费确认"栏。**
