# 物业费拒缴抗辩事由分级库

> 分级目的：告诉用户「这个理由能用、力度多大」，不是劝说用户一律拒缴。
> 是否成立以**现行规定、合同约定、当地主管部门要求和具体证据**为准。

---

## 一、三级分级总表

| 级别 | 含义 | 典型效果 |
|---|---|---|
| **A 级｜可主张免除** | 缴费义务本身不成立或主体错误 | 该部分不予支持 |
| **B 级｜可主张减免** | 履约有瑕疵，但不导致义务消灭 | 按瑕疵程度酌减，一般远低于全额 |
| **C 级｜不成立** | 法律或实践上不支持 | 说了没用，还可能扩大违约 |

**输出时先给级别，再给理由，不要笼统写「可以不交」。**

---

## 二、A 级事由（义务本身有问题）

| 事由 | 核查要点 | 需要的材料 |
|---|---|---|
| 房屋**尚未交付**给买受人 | 核对交房日期、交付通知书、验收单 | 买卖合同、交付文件或未交付证明 |
| 物业公司**未取得**合法进驻依据 | 前期物业服务合同或业主大会选聘文件是否存在 | 业委会决议、合同、备案信息 |
| 物业费已**超过诉讼时效**的那几期 | 逐期起算三年，检查有无中断 | 催缴函、签收凭证、缴费记录 |
| **从未约定**的收费项目 | 是否有业主大会决议或合同依据 | 合同、业主大会决议、收费公示 |
| 同一期间**重复计费** | 前后物业交接期的重复 | 交接记录、两家物业的账单 |
| 已出售／已转让后的期间 | 交付前的欠费应由原业主结清 | 买卖合同约定、交付确认 |

---

## 三、B 级事由（可以谈减免，但不能全免）

| 事由 | 力度 | 关键证据 |
|---|---|---|
| 保洁、绿化、秩序维护明显不到位 | 弱至中 | 带日期照片、视频、连续记录 |
| 公共部位维修长期拖延不修 | 弱至中 | 报修单、工单、回访记录 |
| 安保缺位导致失窃且有因果关系 | 中 | 报案回执、监控缺失证明 |
| 消防、电梯等设施带病运行 | 中 | 检验报告、整改通知、部门查勘 |
| 收费未经公示或与公示不符 | 中 | 公示照片与实际账单对比 |
| 业主共有部分收益未公开 | 弱 | 请求公开的材料记录 |
| 空置房（当地有减免规定） | 依当地规定 | 水电零用量记录、当地规定文件 |

**B 级事由的共同局限：物业服务是面向全体业主的整体给付，个别瑕疵通常不支持全额免除。**

---

## 四、C 级事由（说了没用，别写进意见书）

| 常见说法 | 为什么不成立 |
|---|---|
| 我长期不住／空置，没享受到服务 | 物业服务对象是物业整体，不以个别业主使用为前提 |
| 我不用电梯／不去花园／没有车 | 同上，共有设施维护义务不因不使用而免除 |
| 服务态度不好、和物业有矛盾 | 属一般摩擦，不构成减免费用的法定事由 |
| 我不认可物业公司，我自己管 | 物业公司合法性未否定前，个体无权替代 |
| 别人也没交 | 他人欠缴不能成为自己的抗辩 |
| 我房子租出去了，找租客要去 | 业主是合同相对方，内部约定不对抗物业公司 |
| 开发商遗留的质量问题没解决 | 属买卖合同关系，与物业服务不是同一法律关系 |
| 我没签过物业服务合同 | 前期物业服务合同与业主大会议决对全体业主有约束力 |

---

## 五、举证要求（A/B 级事由没有证据就等于没有事由）

| 事由类别 | 最低证据要求 |
|---|---|
| 未交付 | 书面交付文件或开发商书面确认 |
| 服务瑕疵 | **带日期、带地点**的连续照片或视频，不能只有一次 |
| 收费无依据 | 物业服务合同全文 + 当地收费公示 |
| 已超诉讼时效 | 完整欠费明细 + 三年内无催收或无签收的证明 |
| 重复计费 | 两家物业的账单 + 交接时间证明 |

**证据必须是「当时的」，事后补拍的照片证明力很弱。**

---

## 六、主张顺序建议

```
1. 先区分有无争议：无争议的期间照常缴纳，降低违约金风险
2. 有争议的部分另行书面主张，注意留痕（EMS 或当面签收）
3. 书面主张的内容只有三点：不认可的期间、不认可的理由、要求的处理
4. 不要以拒收、拉黑、贴大字报代替书面主张
5. 诉讼阶段提出时效抗辩、主体抗辩、金额抗辩，按此顺序写
```

## 七、否定词防误伤表（输出前必扫）

| 材料里的表述 | 不能判成 | 应判为 |
|---|---|---|
| 未交房、尚未交付 | 业主应承担 | 主体待定，须核交付日 |
| 未提供某项服务、服务不到位 | 服务完整无瑕疵 | 履约存疑，按程度争取减免，不等于全免 |
| 未收到催缴、未签收催缴函 | 时效已中断 | 未有效中断，时效可能已过 |
| 未公示、未经业主大会同意 | 收费合法 | 收费依据不足，可主张剔除 |
| 已缴纳其中某期 | 全部缴清 | 仅该期履行完毕，其余期继续核算 |
| 尚未解决问题、未回应投诉 | 已整改 | 整改未完成，作为协商筹码记录 |

**写作守则：**
- 任何「未／没有／尚未／未收到」的表述不得改写为肯定事实
- 凡是可能无法成立的事由，标注为「争取项」，不写进「可以确定」的结论里
- 金额表分「无争议金额」与「争议金额」两栏，不要合并成一个总数
