# 四类邻里纠纷要件库

> 适用范围：相邻不动产权利人之间因漏水、噪音、违建、采光通风通行产生的纠纷。
> 具体认定、救济方式、查处权限**以现行规定和当地主管部门、受诉法院口径为准**。

---

## 一、漏水渗漏

| 项目 | 内容 |
|---|---|
| **三个必备要件** | 漏水点或漏水原因、损失范围与金额、与楼上或相邻方的关系 |
| **可能的责任主体** | 楼上业主（自有部分防水、自有管线）、物业（公共立管、公共屋顶）、开发商（保修期内质量缺陷）、承租人（使用不当） |
| **核心争议** | 漏水原因——这是绝大多数案件的胜负手 |
| **关键证据** | 第三方鉴定机构出具的漏水原因鉴定意见、物业加盖公章的在场情况说明、修复前照片、维修发票 |
| **常见抗辩** | 「我不知道漏水」「是房子老了自然老化」「可能是公共管道」「你自己也没及时止损」 |
| **救济方式** | 维修 + 恢复原状 + 赔偿损失；协商不成可诉。**已支出的必要维修费用可一并主张** |
| **取证顺序** | 拍照录像 → 通知到场 → 鉴定原因 → **先留证据后维修** |

> **别急着修。** 修复前状态一旦被覆盖，损失范围就再也无法还原，赔偿数额会被大幅压缩。

---

## 二、噪音扰民

| 项目 | 内容 |
|---|---|
| **三个必备要件** | 噪声发生的具体时段、持续时间与频次、干扰程度的客观佐证 |
| **分类与主管部门** | **社会生活噪声**（邻里音响、乐器、宠物、家庭活动）由公安机关依法处理；**工业噪声、建筑施工噪声**由生态环境主管部门监管 |
| **时段敏感点** | 夜间（通常为 22 时至次日 6 时）与午休时段是认定的高敏感区间，具体时段标准以当地规定为准 |
| **关键证据** | 带有时间标记的分贝测量记录、多次报警记录与出警反馈、物业管理处登记台账、第三方检测报告 |
| **常见抗辩** | 「已经很注意了」「孩子小没办法」「我没超过标准」 |
| **救济方式** | 协商 → 物业/社区调解 → 报警 → 主管部门处理 → 民事诉讼（停止侵害、损害赔偿） |

> **光靠主观描述不够。** 「我觉得很吵」在庭审中最容易被攻破，必须有分贝记录或反复报警的客观佐证。

## 三、违建加建

| 项目 | 内容 |
|---|---|
| **三个必备要件** | 建设行为的位置与形态、有无审批手续、主管部门查处进展 |
| **典型行为** | 封阳台、搭阳光房、占用公共通道、屋顶加盖、挖地下室、拆改承重结构 |
| **主管部门** | 城市管理综合行政执法部门、自然资源主管部门；部分地区由街道或镇政府承担相关工作 |
| **关键证据** | 建设前的原状照片或卫星影像、施工过程的连续影像、向主管部门反映的受理凭证、规划核实材料 |
| **查处路径** | 向主管部门举报 → 受理立案 → 现场勘验 → 责令停止/限期改正 → 强制程序 |
| **民事 vs 行政** | 违建处置在行政部门，**业主不能自行拆除他人建筑**；因违建造成损害的，可另行主张民事赔偿 |

> **先走行政程序。** 拿到行政认定为违法建设的认定文书，后面的民事谈判或诉讼会主动得多。

---

## 四、采光通风通行

| 项目 | 内容 |
|---|---|
| **三个必备要件** | 遮挡事实与建成时间先后、实际影响程度、是否符合规划与间距要求 |
| **判断核心** | 是否违反国家有关工程建设标准中的**日照、间距、通风**要求 |
| **关键证据** | 规划核实意见书、建设工程规划许可证及附图、日照分析报告、遮挡前后对比照片 |
| **建成先后很重要** | 合法建筑在先、受害房屋在后，一般不当然构成侵权；反之则需要具体分析 |
| **救济方式** | 主张排除妨害、损害赔偿；属违法建设的，同步走违建查处 |
| **常见误区** | 「只要挡住一点光就能要求拆」——不构成违反标准的，一般不支持拆除请求 |

> **三分论断七分勘验。** 这类纠纷高度依赖专业机构的日照分析，自行拍几张照片通常不够。

## 五、三条路径对照

| 路径 | 适用情形 | 优点 | 局限 |
|---|---|---|---|
| **物业/社区调解** | 争议小、双方仍愿沟通 | 快、不伤和气、零成本 | 无强制力 |
| **行政投诉举报** | 违建、噪声、规划问题 | 有查处力量，可形成官方认定 | 不处理民事赔偿 |
| **民事诉讼** | 需要赔偿、需要排除妨害 | 有强制执行力 | 周期长、成本高、需举证 |

**选择的判断口径：**
1. 存在人身威胁或肢体冲突风险的，先报警保安全
2. 有明确行政违法的（违建、噪声超标），先走行政程序拿认定
3. 纯赔偿争议的，先固定证据再协商，协商不成再起诉
4. 持续侵害且对方完全否认的，诉讼+行为保全/先予执行一并考虑

## 六、防误伤：否定词清单

出现以下表述，**不能认定为对方已认可责任或已完成处置**：

- 「他说会处理」——没有时间、没有责任人，等于没说
- 「物业说会协调」——协调不等于协调成功
- 「准备做防水」——未完成施工
- 「已经投诉了」——没有受理编号与回复期限，不好推定
- 「邻居态度还行」——与法律责任无关
- 「应该不影响吧」——未经专业勘验
