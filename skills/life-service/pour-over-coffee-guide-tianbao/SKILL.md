# 手冲咖啡

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 给出粉水比、研磨度、水温、时长等参数口径 | 判断咖啡豆的产地真假、等级或品质优劣 |
| 说明分段注水流程与风味问题的归因方向 | 承诺按参数冲就一定好喝（豆子本身是前提） |
| 给单变量调整的顺序与方法 | 建议用极端参数（沸水直冲、超细粉长时间）掩盖豆子问题 |
| 输出参数不合格项与原因、调整顺序 | 给出与健康、医疗相关的功效结论 |

**不属于本技能处理范围的情况**

- 咖啡豆已经明显陈旧、走味或有异味 —— 先换豆，参数救不了
- 磨豆机刀盘磨损严重、磨出粉粗细极不均匀 —— 先解决设备
- 水质极硬或有明显异味 —— 先换过滤水
- 需要评价具体品牌、具体豆子的好坏 —— 不做品牌与产品评价

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「手冲咖啡怎么冲」 | 用，给完整流程与参数 |
| 「粉水比多少合适」 | 用 |
| 「手冲水温多少」 | 用，按烘焙度区分 |
| 「冲出来太酸怎么办」 | 用，判萃取不足并给调整 |
| 「冲出来太苦太涩」 | 用，判萃取过度并给调整 |
| 「闷蒸要多久、加多少水」 | 用 |
| 「一杯要冲多久」 | 用，按粉量给区间 |
| 「一次能改几个变量」 | 用，明确一次只改一个 |
| 「这包豆子好不好」 | 不做产品评价 |

## 三、完整工作流

1. **先确认豆子状态**：烘焙日期在 3-30 天内、无异味、无油耗味。豆子不行，参数怎么调都没用。
2. **定粉量与粉水比**：按杯数定粉量（每人 15 克左右），粉水比先取 1:16。
3. **定研磨度**：按 `rules/参数口径与注水流程.md` 选与烘焙度匹配的中细研磨。
4. **定水温**：浅烘高、深烘低，按烘焙度取区间。
5. **温壶与润纸**：预热分享壶与滤杯，滤纸用热水冲一遍去纸味。
6. **按流程注水**：闷蒸 → 分段注水 → 总时长控制在目标区间。
7. **尝并归因**：酸薄判萃取不足，苦干判萃取过度，按 `rules/风味诊断与单变量调整.md` 调整。
8. **一次只改一个变量**：改完连续冲两杯确认，再改下一个。

## 四、核心规则与要件库

生成冲煮参数或调整建议前，**必须先读**：

- `rules/参数口径与注水流程.md`：粉水比、研磨度、水温、闷蒸、分段注水与总时长的具体口径。
- `rules/风味诊断与单变量调整.md`：酸薄与苦干的归因表、单变量调整顺序、常见操作错误。

**调整必须一次只改一个变量**，同时改研磨和水温，出了问题无法归因。

## 五、脚本用法

```
python scripts/pour_over_check.py --file case.json
python scripts/pour_over_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：粉量、水量、水温、研磨度、烘焙度、总时长、闷蒸水量与时长、分段数、是否预热、风味描述 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--json` | 以 JSON 输出 |
| `--selftest` | 运行自检 |

脚本输出粉水比、水温、研磨度、时长、闷蒸的逐项判定，以及风味归因与调整顺序。**判定顺序是先查真实缺陷（粉水比越界、水温严重偏离、时长严重偏离、研磨度严重偏离、闷蒸不足），再看信息是否完整**；只填了水温却严重超标时，会直接判不合格而不是待确认。

## 六、人工确认清单

- [ ] 豆子在新鲜期内，无异味、无油耗味
- [ ] 粉量按杯数定好，粉水比先取 1:16
- [ ] 研磨度与烘焙度匹配，磨出的粉粗细均匀
- [ ] 水温按烘焙度选，且手冲壶有实际测温而不是只看设定
- [ ] 分享壶与滤杯已预热，滤纸已润洗
- [ ] 闷蒸水量为粉量 2-3 倍，闷蒸 25-45 秒
- [ ] 总时长在按粉量推算的区间内
- [ ] 风味归因后一次只改一个变量，连冲两杯确认

## 七、最常见的坑

1. **只看壶上设定温度不看实际水温**：手冲壶显示的温度与出水温度常有差距，倒水过程还会再降几度。
2. **同时改研磨和水温**：两个变量一起改，冲出来好喝也不知道是哪个改对了，下次照样出问题。
3. **闷蒸水太少或干脆跳过**：闷蒸不足会让后续萃取不均匀，粉层里残留干粉，风味又薄又杂。
4. **注水冲穿粉壁**：沿滤杯边缘猛冲，水直接从滤纸边流走，粉根本没被萃取，冲出来必然水薄。
5. **总时长凭感觉**：时长是最容易量化也最容易失控的变量，必须用计时器。
6. **粉水比先动**：一上来就改粉水比，会把浓度问题和萃取问题混在一起，先改研磨或水温。
7. **用沸水冲深烘**：深烘本身就容易萃取，再加沸水，苦涩是必然结果。
8. **不预热器具**：冷分享壶与冷滤杯会让水温在最初几十秒里掉一大截。

## 八、边界与免责

本技能提供手冲咖啡的参数口径、流程与风味归因方法，不构成对任何咖啡豆、器具或品牌的评价，也不涉及健康与医疗结论。风味判断存在主观差异，参数区间因豆种、处理法、烘焙度、磨豆机与水质而异，请以自己的口感为准。豆子本身不新鲜或设备有明显问题时，参数调整无法解决。
