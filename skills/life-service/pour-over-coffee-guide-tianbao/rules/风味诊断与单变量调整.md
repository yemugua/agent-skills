# 风味诊断与单变量调整

## 一、风味归因表

| 风味表现 | 判定 | 可能原因 |
|---|---|---|
| 尖酸、咸、水感薄、喝完很快没味 | 萃取不足 | 研磨过粗、水温偏低、总时长过短、粉水比过高（水太多） |
| 苦、干涩、喉干、杂味重 | 萃取过度 | 研磨过细、水温偏高、总时长过长、粉水比过低（水太少） |
| 又酸又苦、风味混乱 | 萃取不均 | 闷蒸不足、注水冲穿粉壁、粉层塌陷、磨出的粉粗细不均 |
| 水薄但颜色深 | 注水方式问题 | 水沿滤纸边流走，粉未被充分萃取 |
| 干净但平淡 | 参数基本合理 | 可微调粉水比或豆子本身风味较平 |

## 二、单变量调整顺序

**一次只改一个变量**，改完连冲两杯确认，再改下一个。

| 问题 | 第一改 | 第二改 | 第三改 |
|---|---|---|---|
| 萃取不足（酸薄） | 研磨调细一档 | 水温提高 2 摄氏度 | 延长总时长 15-20 秒 |
| 萃取过度（苦干） | 研磨调粗一档 | 水温降低 2 摄氏度 | 缩短总时长 15-20 秒 |
| 萃取不均（又酸又苦） | 规范注水与闷蒸 | 检查磨豆机出粉均匀度 | 检查粉层是否塌陷 |

**粉水比放在最后改**。粉水比改的是浓度，不是萃取程度，先动它会把两类问题混在一起。

## 三、调整幅度

| 变量 | 单次调整幅度 |
|---|---|
| 研磨度 | 一档（不要一次跳两档） |
| 水温 | 2 摄氏度 |
| 总时长 | 15-20 秒 |
| 粉水比 | 1 个档位（如 1:16 改 1:15） |

调过头再往回调，等于把变量又改了一遍，反而更难收敛。

## 四、常见操作错误

| 错误 | 表现 | 修法 |
|---|---|---|
| 只看壶上设定温度 | 实际出水温度低好几度 | 用温度计实测出水温度 |
| 注水冲穿粉壁 | 水薄、颜色深但没味 | 中心向外画圈，避开滤纸边缘 |
| 一次加满到滤杯口 | 水位过高，萃取不均 | 分段注水，控制水位 |
| 粉层完全干掉再注水 | 萃取中断，风味断层 | 水位降到粉层一半时续注 |
| 不预热器具 | 最初几十秒水温骤降 | 预热分享壶与滤杯 |
| 跳过闷蒸 | 粉层残留干粉，风味薄杂 | 闷蒸 25-45 秒，水量为粉量 2-3 倍 |
| 不撤滤杯等滴完 | 尾段过度萃取发苦 | 水快滴完即撤走滤杯 |
| 凭感觉计时 | 时长忽长忽短 | 用计时器，每次记录 |

## 五、排查顺序

冲出问题时的检查顺序：

1. 豆子是否新鲜（烘焙日期 3-30 天，无异味）
2. 磨出的粉粗细是否均匀
3. 实际出水温度是多少
4. 粉量与水量是否称准
5. 总时长是否计时
6. 注水方式是否冲穿粉壁
7. 最后才考虑调整参数

前五项里任意一项有问题，调参数都白费。

## 七、参数救不了的情况

- 豆子明显陈旧、走味、有油耗味
- 磨豆机刀盘磨损，出粉粗细极不均匀
- 水质极硬或有明显异味
- 器具未清洗干净，有残留旧咖啡油

这些属于前提条件问题，先解决前提，再谈参数。
