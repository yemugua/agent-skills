# 参数口径与注水流程

## 一、粉量与粉水比

| 项目 | 口径 |
|---|---|
| 粉量 | 每人约 15 克；单人 15-18 克，双人 30-36 克 |
| 粉水比 | 常用 1:16；偏好浓 1:14-1:15，偏好淡 1:17-1:18 |
| 越界判定 | 低于 1:13 过浓，高于 1:19 过淡，均需调整 |
| 举例 | 15 克粉配 240 克水为 1:16；配 225 克水为 1:15 |

**粉水比先取 1:16，不要一开始就动它。** 粉水比改的是浓度，不是萃取程度，把两者混在一起会让问题更难定位。

## 二、研磨度

| 研磨度 | 手感参考 | 适用 |
|---|---|---|
| 细 | 接近细砂，易结块 | 意式，不适合手冲 |
| 中细 | 比白砂糖略细 | 浅烘手冲常用 |
| 中 | 接近白砂糖 | 中烘手冲常用 |
| 中粗 | 比白砂糖略粗 | 深烘手冲常用 |
| 粗 | 接近粗砂 | 冷萃、法压 |

| 烘焙度 | 建议研磨 |
|---|---|
| 浅烘 | 中细 |
| 中烘 | 中 |
| 深烘 | 中粗 |

浅烘豆结构紧密不易萃取，用稍细的研磨；深烘豆结构疏松易萃取，用稍粗的研磨。偏离建议档位一档属可调整范围，偏离两档以上会明显影响风味。

## 三、水温

| 烘焙度 | 水温区间 |
|---|---|
| 浅烘 | 90-94 摄氏度 |
| 中烘 | 88-92 摄氏度 |
| 深烘 | 85-90 摄氏度 |

**要看实际出水温度，不是只看壶上设定值。** 手冲壶显示温度与出水温度常有差距，倒水过程还会再降几度。没有测温条件时，水沸后开盖静置 1-2 分钟大致落在 90 摄氏度上下。

## 四、闷蒸

| 项目 | 口径 |
|---|---|
| 闷蒸水量 | 粉量的 2-3 倍（15 克粉用 30-45 克水） |
| 闷蒸时长 | 25-45 秒 |
| 目的 | 让粉层排气、均匀吸水，避免后续萃取不均 |
| 新鲜豆 | 排气旺盛，闷蒸时可见明显鼓包，可延长到 40-45 秒 |
| 不新鲜豆 | 几乎不鼓包，闷蒸 20-25 秒即可 |

闷蒸水过少或跳过闷蒸，粉层里会残留干粉，风味又薄又杂。

## 五、分段注水

| 项目 | 口径 |
|---|---|
| 分段数 | 闷蒸后分 2-4 段注水 |
| 每段水量 | 尽量均匀，最后一段补水到目标总水量 |
| 注水方式 | 中心向外画圈，避开滤纸边缘，不要冲穿粉壁 |
| 水位 | 不要一次加满到滤杯口，也不要让粉层完全干掉 |
| 结束 | 水快滴完时撤走滤杯，避免尾段过度萃取 |

**注水冲穿粉壁是最常见的操作错误**：水沿滤纸边直接流走，粉根本没被萃取，冲出来必然水薄。

## 六、总时长

| 粉量 | 目标总时长 |
|---|---|
| 15 克 | 130-180 秒 |
| 20 克 | 170-240 秒 |
| 30 克 | 260-360 秒 |

| 判定 | 阈值 |
|---|---|
| 偏短（萃取不足） | 低于目标下限的 75% |
| 偏长（萃取过度） | 高于目标上限的 130% |
| 可接受 | 目标区间上下浮动 25% 以内 |

时长是最容易量化也最容易失控的变量，必须用计时器。

## 七、器具与水质

| 项目 | 口径 |
|---|---|
| 预热 | 分享壶与滤杯用热水预热，避免最初几十秒水温骤降 |
| 滤纸 | 用热水冲一遍去纸味，冲完倒掉润纸水 |
| 水质 | 用过滤水；极硬水或有异味的水会明显影响风味 |
| 秤 | 精确到 0.1 克，注水量按重量控制而非体积 |

## 八、标准流程（15 克粉 / 240 克水为例）

| 步骤 | 操作 |
|---|---|
| 1 | 烧水到 92 摄氏度，预热分享壶与滤杯，润洗滤纸并倒掉润纸水 |
| 2 | 倒入 15 克中细研磨的咖啡粉，轻拍使粉层平整 |
| 3 | 注入 30-45 克水闷蒸，计 30 秒 |
| 4 | 第一段注水到约 140 克，中心向外画圈 |
| 5 | 水位下降到粉层一半时注第二段到约 200 克 |
| 6 | 末段补到 240 克，总时长控制在 130-180 秒 |
| 7 | 水快滴完撤走滤杯，轻晃分享壶后倒出 |
