# 衣物熨烫规则

生成方案前先读此表。

## 一、温度点对照

| 标签 | 约温度 | 适用 |
|---|---|---|
| 无熨斗 / 叉 | 不可熨 | 忌熨面料 |
| 1 点 | 110℃ | 真丝、化纤、腈纶 |
| 2 点 | 150℃ | 涤棉、羊毛混纺 |
| 3 点 | 200℃ | 纯棉、亚麻 |

## 二、标准流程（强制，温度升序）

| 序 | 步骤 | 不合格原因 |
|---|---|---|
| 1 | 看标签 | 不看温度点，易烫焦 |
| 2 | 分材质 | 不分温，低温料被烫坏 |
| 3 | 低温试烫 | 不试直接烫，掉色熔洞 |
| 4 | 中温 | 中温料高温会伤 |
| 5 | 高温 | 高温料可蒸汽，需移动 |
| 6 | 收尾 | 不断电，安全隐患 |

## 三、材质手法

| 材质 | 手法 |
|---|---|
| 真丝 | 低温、垫薄布、反面熨 |
| 化纤 | 低温、移动快、不喷冷水 |
| 羊毛 | 中温、垫湿布、顺纹 |
| 棉麻 | 高温、可蒸汽、保持移动 |

## 四、禁用（任一即不合格）

- 高温直接烫真丝 / 化纤（熔融焦化）
- 熨斗停留不动烫同一处（亮光 / 焦痕）
- 带水通电拆机

> 不合格带原因：「高温直接烫真丝：丝蛋白熔融焦化，必须低温垫布」。
