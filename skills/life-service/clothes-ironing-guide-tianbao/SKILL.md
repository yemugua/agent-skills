# 衣物熨烫

## 1. 硬边界（能做什么 / 不能做什么）

| 能做 | 不能做（转专业人士） |
|---|---|
| 按标签温度点调温熨烫 | 改电路、修熨斗 |
| 分材质、垫布、喷雾熨 | 高温硬烫娇贵面料 |
| 蒸汽 / 干烫手法选择 | 带水通电时拆机 |

熨斗漏电、冒烟、漏水严重，转维修。

## 2. 什么时候用

| 用户说法 | 用不用 |
|---|---|
| 真丝衬衫怎么熨 | 用（低温垫布） |
| 熨斗温度点看不懂 | 用（读标签） |
| 熨完有亮光 / 焦痕 | 用（降温垫布） |
| 熨斗冒烟漏电 | 不用（转维修） |

## 3. 完整工作流

1. **看标签**：数熨斗温度点（1 点≈110℃、2 点≈150℃、3 点≈200℃），无点不可熨。
2. 按材质分堆：化纤 / 真丝低温，棉麻高温。
3. **低温试烫**：先在边角低温试，确认不掉色不熔再正式。
4. 中温面料（如涤棉）正常熨，顺纹推进。
5. 高温面料（纯棉麻）可蒸汽，保持移动不停留。
6. 收尾：挂起晾凉定型，关熨斗断电。

温度对照见 `rules/ironing-rules.md`。

## 4. 核心规则 / 要件说明

生成熨烫方案前**先读 `rules/ironing-rules.md`**：温度点对照、材质手法、垫布要求。不合格带原因，如「高温直接烫真丝：丝蛋白熔融焦化，必须低温垫布」。

## 5. 脚本用法

`scripts/iron_check.py` 自检「熨烫操作清单」：

```
python scripts/iron_check.py --file steps.json
python scripts/iron_check.py --selftest
```

## 6. 人工确认清单

- [ ] 已看标签温度点
- [ ] 已按材质分温
- [ ] 已低温试烫
- [ ] 娇贵料垫布
- [ ] 结束断电

## 7. 最常见的坑

1. 不看标签直接高温：真丝 / 化纤熔融焦洞，先数温度点。
2. 高温硬烫不留移动：停留烫出亮光印、甚至焦。
3. 真丝不垫布：直接接触发亮损伤，垫薄布。
4. 湿衣直接熨：水渍印，半干或蒸汽熨。
5. 熨斗平放不归位：烫坏台面，立放 / 断电。
6. 先高温后低温同批：低温料被前序高温烫坏，先低后高。

## 8. 边界与免责

覆盖家用熨斗日常熨烫。熨斗电路维修不在范围。蒸汽熨注意防烫，儿童远离。
