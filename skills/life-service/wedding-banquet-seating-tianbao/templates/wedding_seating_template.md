# 婚宴桌次与席位排布模板（可直接复制使用）

生成桌次方案前，**先读本文件的核算口径**，并用 `scripts/seating_plan.py` 核对数量。

## 一、人数到桌数核算卡

| 项 | 口径 | 本次数值 |
|---|---|---|
| 宾客总人数 | 名单实测 | ____ |
| 3 岁以上儿童 | 占座 | ____ |
| 抱婴（不占座） | 需与酒店确认是否提供宝宝椅 | ____ |
| 占座人数 | 总人数 - 抱婴数 | ____ |
| 每桌座数 | 常规 10 人；主桌 10-12 人 | ____ |
| 基础桌数 | ceil(占座人数 ÷ 每桌座数) | ____ |
| 备用桌 | 基础的 5%-8%；≤10 桌加 1，10-25 桌加 1-2，>25 桌不超 2 | ____ |
| 建议报酒店桌数 | 基础 + 备用 | ____ |
| 工作人员 | 摄影/摄像/主持/督导，按工作餐另计 | ____ |

**备用桌上限**：总桌数 25 桌以上时，备用桌不超过 2 桌。备用桌通常计入最低消费，加多了既浪费又空桌难看。

## 三、主桌座次表（10-12 人圆桌）

```
              [舞台方向]
                 ○ ○        ← 长辈 / 证婚人
            ○         ○     ← 双方父母
         ○               ○
      （新郎）         （新娘）
         ○               ○
            ○         ○     ← 伴郎伴娘（若在主桌）
                 ○ ○
              [上菜位 / 通道]
```

**填写顺序**：

1. 新人居中、面向舞台与宾客
2. 双方父母分坐新人两侧（男左女右或按当地习俗）
3. 祖辈、证婚人安排在父母旁边
4. **上菜位（桌端、靠近通道一侧）不安排长辈与证婚人**

## 五、禁忌核对清单（排座前先列，排完再核）

- [ ] 不能同桌的组合已列出（离异父母、有过节的亲属、前任同事等）——**由新人及双方家庭确认**
- [ ] 长辈、领导未安排在最后一桌、门口、上菜口、音响旁
- [ ] 不同圈子的人未混在同一桌
- [ ] 主桌未超员（不超酒店桌型上限）
- [ ] 备用桌不占用消防通道
- [ ] 儿童随父母同区安排，且有成人照看
- [ ] 素食、过敏、忌口人员已标注并提前通知酒店
- [ ] 需要轮椅/无障碍通道的宾客安排在靠近出入口且不挡通道的位置

## 六、当天引导与变更处理

| 事项 | 做法 |
|---|---|
| 签到台 | 放总桌次图（含分区色块与桌号），配 1-2 名引导人员 |
| 桌号牌 | 每桌立牌，字号要大，从通道方向可见 |
| 席位卡 | 主桌、亲属桌、领导桌必做；其余桌可只做桌牌 |
| 临时加人 | 启用机动桌，由指定负责人（伴郎/婚庆督导）统一处理，不要现场临时拼桌 |
| 空桌处理 | 备用桌未启用时，撤掉桌号牌或改为摆放区，**不要留明显的空桌** |
| 变更 | 提前 3 天二次确认人数；当天变更由负责人记录并同步酒店 |

---

## 七、时间节点表

| 时间 | 事项 |
|---|---|
| 提前 4 周 | 初拟宾客名单，估桌数，与酒店确认桌型与最低消费 |
| 提前 2 周 | 定名单，算出占座人数与基础桌数，报酒店 |
| 提前 1 周 | 完成分区与逐桌排座，列出禁忌组合 |
| 提前 3 天 | 二次确认人数，确定最终桌数，制作桌号牌与席位卡 |
| 提前 1 天 | 与酒店、婚庆、伴郎伴娘同步最终桌次图 |
| 当天 | 签到台放桌次图，指定负责人处理临时变更 |
