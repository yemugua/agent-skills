# 婚宴桌次安排与席位排布

## 你会得到什么

一套把「多少人 → 多少桌 → 怎么坐」算清楚并排明白的口径，解决婚宴排桌最常见的两类翻车：人来了没座，和一桌人互相不认识。

- **数量核算**：占座人数口径（3 岁以上占座、抱婴需确认）、基础桌数 = ceil(占座人数 ÷ 每桌座数)、备用桌按 5%-8% 且 25 桌以上不超 2 桌的核算规则。
- **六区分区**：主桌 / 男方亲属 / 女方亲属 / 同事 / 同学 / 朋友，各自的位置原则与桌数算法，含「两侧都要靠前、长辈不坐最后一排」的排布原则。
- **主桌座次**：10-12 人主桌的人员构成与填写顺序，伴郎伴娘另设桌并紧邻主桌的处理方式。
- **可复制模板**：人数核算卡、分区桌号分配表、主桌座次示意、逐桌席位卡清单、禁忌核对清单、时间节点表。
- **脚本核算**：`scripts/seating_plan.py` 按人数自动生成桌数、分区桌号区间与清单，并在人数与分区不匹配时报警。

## 典型用法

- 定了 168 人的名单，算出该报酒店多少桌
- 双方亲戚加起来 88 人，怎么左右分区、各占几桌
- 主桌到底坐谁，伴郎伴娘要不要挤进去
- 领导和长辈安排在哪几桌才不失礼
- 提前 3 天人数变了，判断要不要加桌、加几桌

## 边界

不替代酒店宴会厅的现场摆台、容纳人数核定与消防疏散要求——场地能放多少桌、能不能加桌，以酒店现场条件与消防要求为准。涉及家庭关系的敏感安排（离异父母、亲戚不和）由新人及双方家庭确认，本技能只给处理原则。各地婚俗差异大，主桌座次与左右分区以当地习俗与双方家庭意见为准。
