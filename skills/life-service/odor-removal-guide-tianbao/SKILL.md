# 异味处理与来源排查（odor-removal-guide）

家里有味道，**第一步永远是定位来源，不是买香薰**。用香掩盖是错误做法：它不解决源头，还会让人忽略真正的污染源，等到问题扩大才发现。

这个技能做四件事：**分类定位** → **判结构性原因** → **对应处理** → **判断是否要报物业或找专业人员**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 区分十二类异味来源并给定位方法 | ❌ 认定"通风就能解决" |
| 判断下水道返味的结构性原因 | ❌ 代替管道疏通机处理主管堵塞 |
| 给出每类来源的处理动作 | ❌ 拆改管道、通气管、地漏结构 |
| 列出清洁剂混用的安全红线 | ❌ 建议混合含氯消毒剂与酸性清洁剂 |
| 说明何时报物业或找专业人员 | ❌ 替代室内空气检测 |

**遇到以下情况，停止自行处理，报物业或转专业人员：**

- 同一楼层多个住户同时反映异味（公共立管或化粪池问题）
- 污水从地漏或洗手盆反涌
- 需要拆地板、拆吊顶或动管道才能处理
- 通气管疑似被封死（部分装修把通气管当成预留孔封堵）
- 异味伴随管道异响、渗漏或楼下返水
- 装修味持续不散且找不到明确来源（可能涉及结构内材料）
- 需要做室内空气检测才能判断是否达标

```

```

## 三、为什么"用香掩盖"是错误做法

这一点必须先说清楚，因为它是最常见的处理方式，也是最耽误事的。

| 问题 | 说明 |
|---|---|
| 不解决源头 | 香氛只作用于鼻腔，污染源仍在 |
| 掩盖真实信号 | 掩盖后人会忽略源头，可能错过需要立刻处理的渗漏或堵塞 |
| 造成二次污染 | 香味成分本身在密闭空间累积，与原有气味混合成更难处理的味道 |
| 掩盖后复发更隐蔽 | 香味变淡的那天，往往是问题已经扩大的那天 |

**正确顺序永远是：定位 → 清源头 → 通风 → 必要时用吸附或中和类产品 → 验证。**

**通风的局限也要说清楚**：通风对"源头在空气里"的情况有效（比如新家具散味），对**源头在管道、墙体或柜体内**的情况几乎无效。往地漏里灌热水、通一晚上窗，对通气管堵塞型返味毫无作用。

## 四、十二类异味来源分诊表

| 编号 | 来源 | 定位方法 | 处理动作 |
|---|---|---|---|
| 1 | 下水道返味 | 逐个封堵地漏、洗手盆、马桶，每次停留观察 | 按结构性原因分别处理（见第五节） |
| 2 | 下水道干涸 | 长期不用（出差、空置、客卫） | 补清水维持水封；长期不用定期补水 |
| 3 | 装修遗留味 | 集中在特定区域或材料，通风后减轻但不完全消失 | 充分通风、移除或隔离主要来源、必要时咨询检测 |
| 4 | 霉味 | 有霉味且在潮湿位置 | 先除湿通风，再做霉变处理 |
| 5 | 油烟味 | 厨房为主，或衣物沾染 | 清理油烟机与滤网，清洗沾染织物 |
| 6 | 宠物味 | 与宠物活动区、笼子、猫砂盆相关 | 彻底清理源头、彻底干燥、勤换垫料 |
| 7 | 织物味 | 布艺、窗帘、地毯、床品 | 拆洗并彻底晾干；不晾干会加重 |
| 8 | 电器味 | 新机胶味或长期未清洁 | 新机充分通风散味；老机清洁与停机除味 |
| 9 | 洗衣机残留 | 只在洗衣机运行或洗后出现 | 清洁滚筒与排水口，跑空程序 |
| 10 | 冰箱残留 | 开冰箱门时明显 | 清理变质食物、擦净内壁、门封清洁 |
| 11 | 鞋柜柜体味 | 集中在鞋柜、储物柜 | 清空通风、清理鞋底、保持干燥 |
| 12 | 洗衣机与阳台排水 | 集中在阳台或洗衣机位 | 查排水口与地漏 |

## 五、下水道返味的四种结构性原因

这一节是本包的重点。返味反复出现，往往是结构原因，不是清洁问题。

| 原因 | 判断方法 | 处理 |
|---|---|---|
| 地漏芯失效 | 芯体松动、翻盖不复位、密封圈老化 | 更换对应类型地漏芯 |
| 存水弯干涸 | 长期不用区域；补水后气味明显减轻 | 补清水；长期不用定期补水 |
| 通气管堵塞 | 多个排水点同时返味；换气效果差 | **必须由专业处理**，需拆动吊顶或管道 |
| 装修时未做水封或水封被破坏 | 老房直排；或改造时破坏了存水结构 | 加装存水弯或改用带水封的地漏 |

**关键提醒**：如果**同一层多个排水点同时返味**，优先怀疑通气管问题。通气管的作用是把排水系统内的气味排到室外，它被堵住或被封死后，室内排水点的返味会同时变重。这种情况**不要自己拆吊顶找管子**，交给物业或专业人员。

## 六、安全红线

**严禁把含氯消毒剂与酸性清洁剂混合使用。**

两者混合会产生有毒气体，对呼吸道有明显刺激。同一条也适用于：含氯消毒剂与洁厕灵、含氯消毒剂与醋、含氯消毒剂与柠檬酸类清洁剂。

| 危险配对 | 说明 |
|---|---|
| 含氯消毒剂 + 酸性清洁剂（洁厕灵、白醋、柠檬酸、部分除垢剂） | 产生有毒气体，刺激呼吸道 |
| 含氯消毒剂 + 碱性清洁剂 | 同样不属于安全配对 |
| 任意两种含氯产品混合 | 有效成分叠加，不可控 |
| 清洁剂 + 酸性除垢剂用于大理石 | 腐蚀石材表面 |

**其他要求：**

- 管道疏通剂按说明书使用，不与其他清洁剂混用，不确定管道材质时先咨询
- 清洁剂使用后及时开窗通风
- 不用香味产品覆盖需要排查的异味
- 存放的清洁剂保持原包装、原标签，不分装到不明容器

## 七、通风为什么经常不管用

| 场景 | 通风是否有效 |
|---|---|
| 新家具、新装修材料散味 | ✅ 有效 |
| 衣物窗帘带出的外部气味 | ✅ 有效 |
| 密闭空间积聚的人体味与食物味 | ✅ 有效 |
| 地漏或存水弯干涸返味 | ⚠️ 有限，水封不补就持续 |
| 通气管堵塞型返味 | ❌ 基本无效 |
| 管道内部污垢 | ❌ 无效 |
| 墙体或柜体内部污染 | ❌ 无效 |

**判断方法**：封堵某个排水点后气味明显减轻，说明来源就在那里；封堵所有排水点后气味仍在，说明来源在其他地方，继续做封堵测试。

## 八、脚本用法

```bash
python scripts/odor_triage.py --text "卫生间早上起来最臭，下水有咕噜声"
python scripts/odor_triage.py --file 情况.json --out 结果.md
```

| 参数 | 说明 |
|---|---|
| `--text` | 直接描述异味情况 |
| `--file` | 从文件读，支持 `.txt` / `.md` / `.json`（JSON 用 `{"desc": "..."}`） |
| `--out` | 结果落盘路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置安全配对检查：`--pair "含氯 酸性"` 可单独检查两种清洁剂配对 |
| `--selftest` | 跑内置样例自检 |

脚本做四件事：按分诊顺序匹配最可能的来源、给出定位动作、判断是否命中结构性原因、检查是否触发清洁剂混用红线。

> 脚本是关键词匹配，**不等于现场判断**。封堵测试必须自己实际做一次。

## 十、最常见的坑

**坑一：用香薰、空气清新剂盖味道。**
不解决源头，还会掩盖需要立刻处理的渗漏或堵塞信号。

**坑二：以为通风能解决所有异味。**
通气管堵塞、管道污垢、墙体内部污染，通风完全无效。

**坑三：多个排水点同时返味，还在一个个换地漏芯。**
这多半是通气管问题，换芯解决不了，需要找物业或专业人员。

**坑四：把含氯消毒剂和洁厕灵一起倒进马桶。**
会产生有毒气体。这是明确的安全红线，记住：**含氯和酸性，永远不混。**

**坑五：清理了但没干燥。**
湿地毯、湿床品、潮湿的柜内，都会重新长霉味。清理后必须彻底干燥。

**坑六：宠物味只做表面清洁。**
猫砂盆、笼子、尿垫的底部才是源头，只擦表面等于没做。

**坑七：洗衣机有味只擦门封。**
滚筒与排水口的残留是主要来源，需要跑一次空程序清洗。

**坑八：冰箱有味只擦一层。**
变质食物与内壁残留要一起处理，门封条本身也会藏污纳垢。

**坑九：装修味"忍一忍就过去了"。**
来源不明的持续异味应先排查具体来源，必要时咨询检测，而不是被动等待。

**坑十：把清洁剂分装到小瓶里。**
失去原标签，误用与混用的风险显著上升。

## 十一、边界与免责

- 本技能**不替代**管道疏通、通气管检修、专业除味施工与室内空气检测
- 异味是否达标涉及检测，**结论以有资质的检测为准**
- 清洁剂适用范围与配对禁忌以**产品说明书**为准，不同产品不可混用
- 公共立管、通气管、化粪池相关问题通过物业处理
- 涉及房屋质量与装修责任争议的，按**物业管理与相关主管部门要求**办理
