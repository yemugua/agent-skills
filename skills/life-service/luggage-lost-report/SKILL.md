# 行李丢失申报

## 何时使用
需要完成「行李丢失申报」相关的具体任务时使用本技能。

## 执行原则
1. 先确认目标与现状，再按步骤执行，不跳步。
2. 每一步做完做对应自查，出错时回退上一步重试。
3. 涉及安全、金额或不可逆操作时，先停下来向用户确认。

## 标准流程
1. **准备阶段**：列出所需工具/材料/信息，检查前置条件是否满足。
2. **执行阶段**：按顺序完成核心步骤，每步记录关键结果。
3. **验证阶段**：对照自查清单逐项确认，发现问题立即修正。

## 常见坑
- 跳过准备直接动手，导致中途返工。
- 忽略边界情况（数值异常、环境差异、时间限制）。
- 完成后不做验证，问题被推迟暴露。

## 自查清单
- [ ] 目标明确且可衡量
- [ ] 准备项全部就绪
- [ ] 每个步骤有执行记录
- [ ] 自查清单全部通过
- [ ] 结果符合预期，异常已处理
