# 剩菜处理与变质识别（leftover-handling）

剩菜能不能留，关键不在「放了几小时」，而在**它是哪一类菜**。同样冷藏 24 小时，红烧肉没问题，绿叶菜和米饭已经不适合吃了。

这个技能做四件事：**分类 → 定时 → 定温 → 定去留**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 按菜品分类给出冷藏保存期与隔夜适宜度 | ❌ 检测剩菜的微生物指标 |
| 给出复热中心温度要求与操作要点 | ❌ 承诺「复热后一定安全」 |
| 说明绿叶菜亚硝酸盐与米饭耐热毒素的限制 | ❌ 提供任何「挽救」已变质食物的方法 |
| 给出变质三条硬指标与高风险人群提示 | ❌ 判定餐饮门店的合规状态 |

**遇到以下情况，按最坏情况处理，不要给「复热一下应该就行」的结论：**

- 剩菜**已出现异味、黏液、变色、霉斑中任一条** —— **复热无法挽救**
- 米饭**在室温放置超过两小时以上**才冷藏 —— 耐热毒素可能已产生
- 凉拌菜**室温放置超过两小时** —— 未经加热，风险最高，直接弃用
- 用户出现**腹泻、呕吐、发热**并怀疑某顿剩菜 —— 属健康问题，转医疗建议
- 剩菜要供**婴幼儿、孕妇、65 岁以上老人、免疫力低下者、正在服药或化疗者**食用 —— 门槛应更严，保存时间减半

> **核心认知**：复热的意义是**杀灭冷藏期间增殖的致病菌**，不是**消除已产生的毒素**。部分毒素加热不被破坏，所以「多热一会儿就安全了」是错的。

## 二、完整工作流

```
第 1 步  过红线：是否已命中三条硬指标、是否高风险人群食用
第 2 步  分类：判定菜品属于哪一类（这一步决定后面全部结论）
第 3 步  读规则文件 rules/剩菜分类保存期与复热要求.md
第 4 步  查台面停留时长：烹饪后多久进的冰箱，这一项常被忽略
第 5 步  确认冷藏时长（小时，不是「昨天中午」这种模糊描述）
第 6 步  跑脚本核查状态与复热要求
第 7 步  感官三项核对：异味、质地、外观
第 8 步  复热到中心温度并保持
第 9 步  当次吃完，不留到第二天
```

**第 4 步最容易被忽略**：很多「剩菜放不久」的真实原因是**烹饪后在台面上凉了太久**，这段时间根本不在冷藏的保护范围内。

## 三、按菜品分类的冷藏保存期

| 菜品分类 | 冷藏上限 | 时长档位 | 隔夜适宜度 | 复热中心温度 |
|---|---|---|---|---|
| **绿叶菜类** | 12 小时 | 短（当日内） | ❌ **不适合** | 75℃ |
| **凉拌菜与即食** | 4 小时 | 极短（两小时内） | ❌ **不适合** | 不需复热 |
| **米饭与面食** | 12 小时 | 短（当日内） | ❌ **不适合** | 75℃ |
| **汤类** | 48 小时 | 中（两天内） | ✅ 适合 | 75℃ |
| **瓜类与芹菜** | 24 小时 | 短 | ⚠️ 谨慎 | 75℃ |
| **花菜类与菌菇** | 24 小时 | 短 | ⚠️ 谨慎 | 75℃ |
| **海鲜类菜肴** | 24 小时 | 短 | ⚠️ 谨慎 | 75℃ |
| **蛋类菜肴** | 48 小时 | 中（两天内） | ✅ 适合 | 75℃ |
| **油炸与煎制** | 48 小时 | 中 | ✅ 适合 | 70℃ |
| **肉类菜肴** | 72 小时 | 较长（三天内） | ✅ 适合 | 75℃ |
| **炖煮类与卤味** | 72 小时 | 较长 | ✅ 适合 | 75℃ |

**保存期是冷藏上限，不是「到点必坏」**：温度未达标、有异味、有二次污染时，实际安全期更短。

## 四、绿叶菜与米饭：两个硬限制

### 绿叶菜：亚硝酸盐与现炒现吃优先

绿叶菜存放后会发生两个不利变化：

- **叶绿素分解**，颜色发黄发黑，营养同时下降
- **亚硝酸盐累积**，随存放时间延长而增加

因此**绿叶菜现炒现吃优先**。需要保存时应：
- **焯水后快速沥干**，缩短后续存放时间
- 冷藏上限按 **12 小时**掌握
- 剩绿叶菜不建议隔夜，尤其不用于高风险人群

### 米饭：耐热毒素是复热也解决不了的

米饭在室温放置时，蜡样芽孢杆菌可繁殖并产生**加热不被破坏的毒素**。这意味着：

- **一旦产生，复热无法去除**，再多热一会儿也没用
- 关键在**缩短室温时间**：做好的米饭要尽快降温冷藏
- **不要长时间摊在台面上晾**
- 米饭冷藏上限 **12 小时**，且不适合隔夜

**这两条的共同点**：都指向「**缩短在危险温度区停留的时间**」，而不是「加热更久」。

## 五、复热要求

```
复热有效判据 = 中心温度达到 75℃ 并保持一段时间
```

| 要点 | 说明 |
|---|---|
| **中心温度** | 达 75℃ 并保持，确保杀灭冷藏期间增殖的致病菌 |
| **均匀受热** | 整锅复热比分份复热更均匀；大块肉要切开判断 |
| **只热一次** | 反复加热加剧油脂氧化与口感劣化 |
| **汤类** | 加热到彻底冒热气 |
| **海鲜** | 少量喷水避免干硬，但仍要彻底加热 |
| **凉拌菜** | **不需复热，也不可复热**，室温超 4 小时即弃用 |

**复热解决什么、不解决什么：**

| 复热能解决 | 复热解决不了 |
|---|---|
| 冷藏期间增殖的致病菌 | 已产生的耐热毒素（如蜡样芽孢杆菌毒素） |
| 表面与浅层的污染 | 已经变质食物中的代谢产物 |
| — | 感官已异常食物的安全性 |

**所以顺序永远是：先判断是否变质，再考虑复热。变质的东西复热后照样不能吃。**

## 六、变质三条硬指标

| 指标 | 具体口径 | 命中后 |
|---|---|---|
| **异味** | 酸馊味、腐败味、氨味、哈喇味（油脂氧化） | **立即弃用，复热无用** |
| **质地变化** | 发黏、变滑、结块分层、汤汁变稠发浑 | **立即弃用，复热无用** |
| **外观霉变** | 白色或彩色绒毛状霉菌、绿斑、发臭水泡 | **立即弃用，复热无用** |

## 七、剩菜与新菜混装的风险

**不建议混装**，原因有三：

1. **交叉污染**：新菜是生的或即食的，混入剩菜会被二次污染
2. **温区冲突**：新菜温度高，会让整盒温度升高，加速变质
3. **去留冲突**：一盒里既有能留的也有不能留的，倒掉可惜、留下不放心

**正确做法**：熟食用**带盖分格容器**分开存放，生熟分开；剩菜**浅容器分装**，加速散热；容器标上**制作时间**。

## 八、感官不可靠场景

| 菜品 | 机制 |
|---|---|
| 肉类菜肴 | 李斯特菌可在冷藏温度下增殖，外观与气味完全正常 |
| 米饭 | 蜡样芽孢杆菌毒素加热不被破坏，无异味也可能不安全 |
| 凉拌菜 | 沙门氏菌与李斯特菌污染可无任何感官变化 |
| 海鲜 | 组胺等降解产物不产生异味，但可引起不适 |
| 蛋类菜肴 | 沙门氏菌污染可无异味，加热不充分风险高 |

**结论**：感官正常 ≠ 安全。感官只能排除明显变质，不能确认安全。

## 九、脚本用法

```bash
python scripts/leftover_check.py --file left.json --out 剩菜核查.md
python scripts/leftover_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`items` 剩菜列表、`fridge_temp_ok` 冷藏温度达标标记 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检（36 条断言，含 BOM 输入两条） |

输入 JSON 示例：

```json
{
  "fridge_temp_ok": true,
  "items": [
    {"name": "炒青菜", "category": "leafy", "hours_in_fridge": 14, "reheat_done": true},
    {"name": "剩米饭", "category": "rice", "hours_in_fridge": 6, "reheat_done": true},
    {"name": "红烧肉", "category": "meat_dish", "hours_in_fridge": 60, "reheat_done": true},
    {"name": "凉拌黄瓜", "category": "cold_dish", "hours_in_fridge": 5}
  ]
}
```

可选分类键：`leafy` `cauliflower` `celery_cucumber` `meat_dish` `egg_dish` `seafood` `rice` `soup` `cold_dish` `fried` `stew`。

脚本输出：逐项冷藏状态与隔夜适宜度（不适合隔夜的排最前）、复热要求、感官不可靠提示、变质三条硬指标、高风险人群提示与处置建议。**脚本不做感官判断，也不给「可以吃」的结论。**

## 十一、最常见的坑

**坑一：把剩菜统一冷藏三天。**
错误做法：所有剩菜一律冷藏三天再吃。正确做法：绿叶菜 12 小时、米饭 12 小时、凉拌菜 4 小时，而肉类可到 72 小时。**统一对待必然要么浪费要么冒险。**

**坑二：绿叶菜隔夜第二天再炒。**
错误做法：晚上炒的青菜留到明天中午。正确做法：绿叶菜存放后叶绿素分解、**亚硝酸盐累积**，冷藏上限 12 小时且不适合隔夜。现炒现吃是唯一稳妥做法。

**坑三：米饭摊在台面上晾到凉透再收。**
错误做法：米饭盛一大盆放桌上，等凉透了再进冰箱。正确做法：米饭室温放置可产生**加热不被破坏的毒素**，复热无法去除。要么分装到浅容器快速降温，要么尽快吃完。

**坑四：以为复热就能挽救一切。**
错误做法：剩菜有点味了，热透就能吃。正确做法：复热杀灭的是**增殖的致病菌**，消除不了**已产生的毒素**，也救不了已变质的食物。**先判断是否变质，再考虑复热**，顺序不能颠倒。

**坑五：凉拌菜留到第二天。**
错误做法：凉拌的黄瓜、木耳留到明天。正确做法：凉拌菜**未经加热**，冷藏上限只有 4 小时，且不适合隔夜。室温放置超过两小时就直接弃用。

**坑六：剩菜和新菜装一盒。**
错误做法：中午的剩菜和晚上的新菜放一起。正确做法：新菜温度高会升高整盒温度，新菜是生的或即食的会被剩菜污染。**熟食用带盖分格容器分开存放**。

**坑七：用超大深盆装剩菜。**
错误做法：一大锅汤放一个大盆里晾着。正确做法：**分装到浅容器**才能加速散热降温。深盆中心降温慢，等于在危险温度区多待了几个小时。

**坑八：反复加热剩菜。**
错误做法：中午热一次，晚上再热一次。正确做法：**只热一次**。反复加热会加剧油脂氧化（产生哈喇味）与口感劣化。

**坑九：给老人孩子吃隔夜菜。**
错误做法：剩菜闻着没味，给孙子吃。正确做法：婴幼儿、孕妇、65 岁以上老人、免疫力低下者、正在服药或化疗者，**保存时间减半，感官可疑即弃用**。

**坑十：用「反正还会再热」放松判断。**
错误做法：想着待会儿还要加热，所以现在常温放着没关系。正确做法：**室温停留的那段时间不在冷藏保护范围内**，而且这段时间恰恰是细菌增长最快的阶段。要么尽快冷藏，要么尽快吃完。

## 十二、边界与免责

- 本技能提供家庭条件下的**剩菜分类保存期与复热口径**，**不做微生物检测，也不判定食品是否安全**
- 食品是否安全，**以具备资质的检测机构结果、现行规定和相应产品标签为准**
- 保存期上限基于家庭冷藏条件（不高于 4℃），温度未达标时实际安全期更短
- 本技能**不提供任何挽救已变质食物的方法**，命中硬指标一律按弃用处理
- 涉及餐饮门店、食品生产经营的合规判定不属于本技能范围
- 已出现消化道症状者应及时就医，本技能不作任何健康或医疗建议
- 本技能不构成任何食品安全担保
