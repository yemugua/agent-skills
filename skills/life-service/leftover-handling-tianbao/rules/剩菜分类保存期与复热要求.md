# 剩菜分类保存期与复热要求

> 生成剩菜建议前先读这份文件，不要统一按「冷藏三天」处理。

## 一、按菜品分类的冷藏保存期

| 分类键 | 菜品 | 冷藏上限（小时） | 时长档位 | 隔夜适宜度 | 复热中心温度 |
|---|---|---|---|---|---|
| `cold_dish` | 凉拌菜与即食 | 4 | 极短 | 不适合 | 不需复热 |
| `leafy` | 绿叶菜类 | 12 | 短 | 不适合 | 75℃ |
| `rice` | 米饭与面食 | 12 | 短 | 不适合 | 75℃ |
| `celery_cucumber` | 瓜类与芹菜 | 24 | 短 | 谨慎 | 75℃ |
| `cauliflower` | 花菜类与菌菇 | 24 | 短 | 谨慎 | 75℃ |
| `seafood` | 海鲜类菜肴 | 24 | 短 | 谨慎 | 75℃ |
| `soup` | 汤类 | 48 | 中 | 适合 | 75℃ |
| `egg_dish` | 蛋类菜肴 | 48 | 中 | 适合 | 75℃ |
| `fried` | 油炸与煎制 | 48 | 中 | 适合 | 70℃ |
| `meat_dish` | 肉类菜肴 | 72 | 较长 | 适合 | 75℃ |
| `stew` | 炖煮类与卤味 | 72 | 较长 | 适合 | 75℃ |

**状态判定**：占用时长 ÷ 上限，<70% 正常、70–100% 临近期限、≥100% 已超期。

## 二、不适合隔夜的菜品及原因

| 菜品 | 原因 |
|---|---|
| 绿叶菜 | 叶绿素分解发黑，**亚硝酸盐累积**，现炒现吃优先 |
| 米饭 | 室温放置可产生**加热不被破坏的毒素**，复热无法去除 |
| 凉拌菜 | 未经加热，微生物风险最高，室温超两小时风险显著上升 |

## 三、绿叶菜专项

- 存放后：**叶绿素分解**（发黄发黑）、**亚硝酸盐累积**
- 冷藏上限 **12 小时**，不适合隔夜
- 需要保存时：**焯水后快速沥干**，缩短后续存放时间
- 不用于**婴幼儿、孕妇、老人、免疫力低下者**

## 四、米饭专项

- 室温放置时蜡样芽孢杆菌可繁殖，产生**加热不被破坏的毒素**
- **一旦产生，复热无法去除**，热多久都没用
- 关键在**缩短室温时间**：尽快降温冷藏
- **不要长时间摊在台面上晾**
- 冷藏上限 **12 小时**，不适合隔夜

## 五、复热要求

```
复热有效判据 = 中心温度达到 75℃ 并保持一段时间
```

| 要点 | 说明 |
|---|---|
| 中心温度 | 75℃ 并保持 |
| 均匀受热 | 整锅复热比大盆分份更均匀 |
| 只热一次 | 反复加热加剧油脂氧化与口感劣化 |
| 大块肉 | 切开判断中心温度 |
| 汤类 | 加热到彻底冒热气 |
| 海鲜 | 少量喷水避免干硬，仍须彻底加热 |
| 凉拌菜 | **不需复热，也不可复热**，超 4 小时即弃用 |

### 复热能解决与解决不了的

| 复热能解决 | 复热解决不了 |
|---|---|
| 冷藏期间增殖的致病菌 | 已产生的耐热毒素 |
| 表面与浅层污染 | 已变质食物的代谢产物 |
| — | 感官已异常食物的安全性 |

**顺序永远是：先判断是否变质，再考虑复热。**

## 六、变质三条硬指标

| 指标 | 口径 | 命中后 |
|---|---|---|
| 异味 | 酸馊味、腐败味、氨味、哈喇味 | 立即弃用，复热无用 |
| 质地变化 | 发黏、变滑、结块分层、汤汁变稠发浑 | 立即弃用，复热无用 |
| 外观霉变 | 白色或彩色绒毛状霉菌、绿斑、发臭水泡 | 立即弃用，复热无用 |

## 七、感官不可靠场景

| 菜品 | 机制 |
|---|---|
| 肉类菜肴 | 李斯特菌冷藏下增殖，感官正常 |
| 米饭 | 蜡样芽孢杆菌毒素耐热，无异味也可能不安全 |
| 凉拌菜 | 沙门氏菌与李斯特菌污染可无感官变化 |
| 海鲜 | 组胺不产生异味但可致不适 |
| 蛋类菜肴 | 沙门氏菌污染可无异味 |

**感官正常 ≠ 安全**，感官只能排除明显变质。

## 八、存放操作要点

- **浅容器分装**：加速散热降温；深盆中心降温慢，等于多待在危险温度区
- **带盖分格**：生熟分开、新菜与剩菜分开
- **标注时间**：容器上写制作时间
- **不混装**：新菜温度高会升高整盒温度，且新菜会被剩菜污染
- **不长时间晾**：减少室温停留

## 九、高风险人群

重点人群：**婴幼儿、孕妇、65 岁以上老人、免疫力低下者、正在服药或化疗者**。

对其供餐时：**保存时间减半，感官有任何可疑即弃用。**

## 十、否定词与防误伤

- 「**复热过了**」**不等于**安全，消除不了耐热毒素
- 「**闻着没味**」**不等于**可以吃
- 「**放凉再收**」**不等于**已经冷藏，室温时间不在保护范围内
- 「**加热到冒热气**」**不等于**中心温度达标，大块需切开判断
- 「**冷藏三天**」**不等于**所有剩菜都能放三天

## 十一、处置决策树

```
1. 是否命中三条硬指标任一条？
   ├─ 是 → 弃用，复热无用
   └─ 否 → 继续
2. 烹饪后在台面停留多久？
   ├─ 超过两小时（米饭、凉拌菜尤其）→ 按最坏情况处理
   └─ 较短 → 继续
3. 菜品属于哪一类？
   └─ 查表得冷藏上限与隔夜适宜度
4. 冷藏时长 ÷ 上限？
   ├─ <70% → 正常
   ├─ 70-100% → 立即食用
   └─ ≥100% → 已超期，弃用
5. 是否供高风险人群？
   ├─ 是 → 每档门槛再降一档
   └─ 否 → 按表执行
```
