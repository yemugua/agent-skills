# 护照首次申领与换发补发核查（passport-application-check）

护照办不下来，绝大多数卡在四个点：**走错了办理情形、照片不合格、登记备案人员没拿到单位审批意见、以为随便哪个城市都能办**。

这个技能做五件事：**定情形** → **核材料** → **查特殊身份** → **算时限** → **找救济**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 判断应走首次申领、换发还是补发 | ❌ 承诺一定受理、一定签发 |
| 列出材料清单并标出缺失 | ❌ 代填申请表、代签承诺 |
| 提示登记备案人员需提交单位审批意见 | ❌ 提供规避登记备案审批的办法 |
| 提示照片规格与常见不合格原因 | ❌ 修图造假、PS 回执 |
| 说明不予签发的法定情形 | ❌ 教人隐瞒真实出境目的或伪造证明材料 |
| 提示不予受理/不予签发的救济途径 | ❌ 代理行政复议或行政诉讼 |

**遇到以下情况，直接问所在地公安机关出入境管理部门，不要靠猜：**
- 登记备案人员的单位审批意见拿不到，或单位与本人对备案状态有争议
- 户籍信息与身份证、户口簿记载不一致
- 涉外婚姻、境外出生、定居国外的中国公民申请
- 曾持用护照被吊销、宣布作废，或有不准出境的记录
- 护照在国外遗失、被盗，需向驻外使领馆申请旅行证
- 未满 16 周岁未成年人单独申领

**永远不要伪造、变造证明材料，不要隐瞒真实出境目的。** 一经查实，除不予签发出入境证件外，还可能被依法追究责任并影响后续申请。

## 二、完整工作流

```
第 1 步  定情形：首次申领 / 换发 / 补发（三者材料不同，不能混）
第 2 步  先读规则文件 rules/application_rules.md（情形判定 + 材料 + 不予签发情形）
第 3 步  跑核查脚本
    python scripts/passport_material_check.py --file 情况.txt --category 换发 --as-of 2026-10-08
第 4 步  查特殊身份：是否登记备案人员、是否未成年人、是否异地办理
第 5 步  逐项人工确认（脚本只做关键词匹配，不做受理判断）
第 6 步  按 templates/材料清单与办理时限表.md 输出核查表
```

## 三、三类办理情形

| 情形 | 适用条件 | 关键差异 |
|---|---|---|
| **首次申领** | 从未持有过护照，或曾持有但已注销且无有效记录 | 需完整提交身份与户籍材料，一般需现场采集指纹与签名 |
| **换发** | 护照有效期即将届满、签证页即将用完、护照被损坏不能继续使用、护照有效期不足但仍有出国需求 | 须交回原护照，原护照上的有效签证需办理转移或保留 |
| **补发** | 护照遗失、被盗、损毁 | 须说明遗失/被盗情况，原护照同时作废，不能再使用 |

> **换发与补发不要选错。** 护照还在只是过期了，走换发；护照找不到了，走补发。把"找不到"报成"过期换发"，一旦原护照被他人冒用，责任在本人。

## 四、材料清单

完整清单、替代材料与常见替代口径见 `rules/application_rules.md`。核心六项：

| # | 材料 | 要点 | 缺了会怎样 |
|---|---|---|---|
| 1 | 居民身份证 | 原件，部分情形需复印件 | 不予受理 |
| 2 | 户口簿 | 异地办理、未成年人、集体户口等情形常需核验 | 退回补材料 |
| 3 | 符合标准的照片及回执 | 多数受理点现场采集，自带回执须符合规格且在有效期 | 照片不合格被退回 |
| 4 | 申请表 | 一般在受理点现场填写或网上预填后打印 | 无法受理 |
| 5 | 原护照 | 换发、补发时需要；补发须说明遗失情况 | 换发无法交回原证 |
| 6 | 登记备案人员单位审批意见 | 仅登记备案人员需要 | 不予受理 |

## 五、登记备案人员（最容易踩的坑）

- **哪些人**：一般指在国家机关、国有企业、事业单位等任职，且按规定被列入登记备案的人员。具体备案范围与审批层级由所在单位与主管部门规定。
- **怎么办**：向所在单位组织人事部门提出，取得同意办理出入境证件的审批意见后，再提交申请。
- **能不能绕**：不能。**任何规避登记备案审批的操作都不在本技能范围内**。
- **备案状态有争议**：以单位人事部门与出入境管理部门的答复为准，不要按"朋友说他不用交"来判断。

---

## 六、办理时限

- 法定办理时限由所在地公安机关出入境管理部门按现行规定执行，一般为**受理之日起若干个工作日**。
- 实际取证时间受申请量、是否需核查、是否异地办理、是否需发函核实等因素影响。
- **加急**：符合条件的可申请加急办理，具体情形与时限以当地答复为准。常见加急事由包括奔丧、探病、紧急商务、开学临近等，须提供相应证明材料。
- **规划口径**：出票前先算好"受理 + 办理时限 + 取证 + 签证办理"四段时间，**不要用别人的经验值倒推自己的时间**。

## 七、脚本用法

```bash
python scripts/passport_material_check.py --file "D:\材料\情况说明.txt" \
    --category 换发 --as-of 2026-10-08 --out 核查结果.md
```

| 参数 | 说明 |
|---|---|
| `--file` | 必填。情况说明、材料清单或聊天记录导出文本（`.txt` / `.md`） |
| `--category` | 办理情形：`首次` / `换发` / `补发`，缺省由文本自动判定 |
| `--as-of` | 核查基准日，默认今天 |
| `--expiry` | 现持护照有效期截止日，用于算剩余有效期与换发窗口 |
| `--out` | 输出路径，默认打到屏幕 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本做五件事：
1. **情形判定**：首次申领 / 换发 / 补发命中哪一类
2. **材料核查**：六项清单逐项标齐备/缺失/不涉及
3. **特殊身份**：登记备案人员、未成年人、异地办理是否命中
4. **有效期换算**：剩余有效期是否进入换发窗口（不足 6 个月提示）
5. **不予签发风险**：六类高频情形是否命中

> ⚠️ 脚本只做关键词匹配，**不代表受理结论**。标"齐备"不等于窗口认可这份材料。

## 八、人工确认（这步不能省）

- [ ] 是否为登记备案人员，以单位人事部门答复为准，不要凭印象
- [ ] 身份证是否在有效期内，姓名、出生日期与户口簿是否一致
- [ ] 照片是否为近期、是否符合规格、回执是否在有效期
- [ ] 换发时原护照上的有效签证是否需办理转移
- [ ] 补发时能否清楚说明遗失/被盗的时间、地点与经过
- [ ] 异地办理是否符合当地现行条件，是否需要居住证明材料
- [ ] 未成年人是否由监护人陪同，是否带监护关系证明材料
- [ ] 预留的办理时间是否覆盖办理时限与后续签证办理时间

---

## 九、输出结构（固定六段）

1. **走哪类办理** —— 首次申领 / 换发 / 补发，结论先行
2. **材料清单核查表** —— 六项逐项标齐备/缺失/不涉及
3. **特殊身份提示** —— 登记备案、未成年人、异地办理
4. **有效期与时间节点** —— 剩余有效期、换发窗口、建议申请日期
5. **不予签发风险** —— 命中的高频情形
6. **救济途径** —— 不予受理或不予签发时可以走什么路径

## 十、最常见的坑

**坑一：护照过期了还去办"补发"。**
补发适用于遗失、被盗、损毁。护照还在只是过期，是换发。情形选错会被退回重填，也影响原证的处理方式。

**坑二：以为异地一定能办。**
异地办理有适用条件与材料要求，且各地执行口径不同。先在拟办理城市的出入境管理部门渠道确认，再安排时间请假跑窗口。

**坑三：登记备案人员自己直接去窗口。**
没带单位审批意见，窗口不予受理。先走单位流程，再预约。

**坑四：照片自己拍、自己修。**
照片背景、尺寸、头部比例、佩戴物、修图痕迹都有要求。受理点现场采集是最省事的做法，自带回执务必确认符合规格且在有效期。

**坑五：只看护照有效期，不算签证办理时间。**
护照下来还有签证要办。按"受理 + 办理时限 + 取证 + 签证"四段一起排，别卡着出发日期申请。

**坑六：原护照上的有效签证没处理就换发。**
换发须交回原护照。原证上有仍在有效期内的签证，要提前问清是否需要办理签证转移或保留原证。

**坑七：护照丢了不当回事。**
护照遗失应及时办理补发并说明情况，原证作废。拖延不报，一旦被冒用，责任难以撇清。

**坑八：被拒绝后不知道可以问理由。**
对不予受理或不予签发的决定，可以要求说明理由，并按法定途径申请救济。具体途径与期限见 `rules/application_rules.md`，以现行规定和当地主管部门要求为准。

- 本技能**不代替**公安机关出入境管理部门的受理、审查与签发
- 材料清单、办理时限、收费标准、是否支持网上预约与异地办理，各地口径不同，**以现行规定和所在地公安机关出入境管理部门要求为准**
- 本技能**不提供**规避登记备案审批、隐瞒真实出境目的、伪造或变造证明材料的方法
- 涉及行政复议、行政诉讼的，应咨询专业法律人士并依法定程序办理
