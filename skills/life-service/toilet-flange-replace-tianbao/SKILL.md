# 马桶底座漏水与法兰圈更换（toilet-flange-replace）

马桶底座渗水，**先分清是水从哪来的**。法兰圈老化只是其中一种，水箱螺栓垫片、进水软管接头、甚至水箱外壁结露，表现都像"底座漏水"。没分清就抬马桶，是最累也最容易白干的一件事。

这个技能做四件事：**找来源** → **判法兰** → **选类型** → **规范装**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 判断渗水是否来自法兰圈 | ❌ 认定"底座有水就是法兰坏了" |
| 按管口高度选法兰类型 | ❌ 用叠两个蜡圈的方式凑厚度 |
| 给出拆装顺序与验收标准 | ❌ 处理排污管改造、楼板渗漏、防水修复 |
| 提示搬运与陶瓷安全红线 | ❌ 判断结构层、防水层问题 |
| 区分结露水与真实渗漏 | ❌ 建议重复使用一个已压过的蜡圈 |

**遇到以下情况，立即停止自行操作，转交专业维修人员：**

- 楼下天花板已出现渗水、水印、滴水（可能已影响楼板）
- 地面排污管需要切割、移位、改造
- 马桶底座或水箱本体有裂纹
- 地面明显不平、瓷砖松动、需找平
- 智能一体马桶拆装（涉及电路与进水连接）
- 冲水时污水从排污口**反涌**出来（先疏通，装法兰解决不了）
- 抬不动、没有帮手、或家中有无法搬重物的情况

**永远不要在排污管堵塞的情况下装新法兰。** 装完第一次冲水就会返水，新法兰随即报废，还可能泡坏地面。

## 二、完整工作流

```
第 1 步  关角阀、断电（智能马桶盖必须拔插头并关进水）
第 2 步  干燥排查：擦干所有表面，用纸巾贴敷定位渗水来源
第 3 步  先读规则文件 rules/toilet_flange_rules.md（来源对照 + 选型 + 红线）
第 4 步  跑故障树脚本
    python scripts/toilet_flange_check.py --text "冲水时底座边缘冒水，马桶有点晃"
第 5 步  确认是法兰问题后，量管口高度、选法兰类型、备材料、找帮手
第 6 步  按十五步作业顺序拆装
第 7 步  冲水 5-8 次验收，24 小时后打外侧密封胶
```

## 三、先找来源（跳过这步最容易白干）

| 渗水表现 | 真实来源 | 是不是法兰问题 |
|---|---|---|
| 冲水时底座边缘有水渗出 | 法兰密封失效 | ✅ 是 |
| 马桶长期晃动后有味 | 法兰被压偏、移位 | ✅ 是 |
| 马桶后侧靠墙处滴水 | 水箱与便器连接螺栓垫片老化 | ❌ 换垫片 |
| 底座一侧持续有水渍 | 进水软管接头或角阀渗水 | ❌ 换软管垫片 |
| 黄梅天水箱外壁有水珠 | 水箱结露（冷凝水） | ❌ 属物理现象 |
| 冲水后水面下降、异味重 | 存水弯水位异常或马桶本体 | ❌ 另查 |

**干燥排查法**：擦干地面与马桶所有外表面，静置 1 小时不冲水、不用水，再检查是否出现新水渍。没有新水渍却"一直有水"，多半是结露或别处流过来的。

---

## 四、法兰选型（选错类型等于白装）

| 类型 | 特点 | 适合 | 不适合 |
|---|---|---|---|
| 蜡圈 | 一次成型，密封性好，便宜 | 管口与地面基本齐平 | 装后不能挪动，挪过就报废 |
| 橡胶 / 泡沫法兰 | 可重复调整，带导向套 | 管口略低于地面、需要微调 | 对管口平整度要求高 |
| 加厚法兰 | 厚度更大 | 管口低于地面 1-2cm | 管口明显低于地面时仍不够 |
| 法兰延伸器 | 加长接管 | 管口低于地面 2cm 以上 | 需要足够安装深度 |

**两个关键尺寸：**

1. **管口高度**：地面排污管口是齐平、略低还是明显低于地面。低于地面 2cm 以上必须用延伸器
2. **管口内径**：常见 100mm，也有 110mm，法兰导向套外径要匹配

**禁止用叠两个蜡圈凑厚度。** 叠装极易在上层马桶压下时错位，是最常见的返工原因。

---

## 五、拆装作业顺序（十五步，严格照做）

**工具与材料**：橡胶手套、海绵与旧毛巾、活动扳手、一字与十字螺丝刀、塑料铲刀、除胶剂或酒精、美工刀、中性硅酮密封胶与胶枪、水平尺、记号笔、新法兰（蜡圈或橡胶）、可选新马桶螺栓、纸板或旧毛毯。

**拆除：**

1. 关角阀，**智能马桶盖拔插头并关进水**
2. 冲水排空水箱，再用海绵吸干水箱与便器内余水
3. 拆进水软管（下方垫毛巾接残水）
4. 撬开底座螺母装饰盖，卸下两侧螺母（锈死喷松动剂，别硬拧）
5. 一体式跳过水箱连接螺栓；分体式需拆水箱与便器之间的连接螺栓
6. **两人配合**，双手抱住马桶**垂直向上抬起**，严禁倾斜扭转
7. 放到纸板或旧毛毯上，立即用抹布堵住排污口（防臭气与杂物掉入）

**清理与安装：**

8. 塑料铲刀铲除旧蜡与旧胶，除胶剂辅助，**禁止用金属铲刀刮瓷砖**
9. 检查地面管口高度、管口是否破损、地面是否平整
10. 试放新法兰，确认导向套能坐入管口且高度合适
11. 在底座内侧打一圈中性硅酮胶（**两侧或后侧留出观察口**，不要全封死）
12. 两人配合对准螺栓孔，**一次性垂直落下**，落下后不得挪动
13. 坐上去或用身体均匀施压，把法兰压实
14. 装螺母，**对角交替、分两次拧紧**，手感紧即可（过紧会压裂陶瓷）
15. 接回软管，缓慢开角阀，静置 30 分钟后冲水 5-8 次逐次观察

> **落下即定位**：马桶一旦坐下，蜡圈就被压成型。再挪一次，密封就废了，必须换新圈。

## 六、脚本用法

```bash
python scripts/toilet_flange_check.py --text "冲水时底座边缘冒水，马桶有点晃"
python scripts/toilet_flange_check.py --file 描述.txt --out 结果.md
```

| 参数 | 说明 |
|---|---|
| `--text` | 直接给现象描述 |
| `--file` | 从文件读描述 |
| `--out` | 结果落盘路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本按渗水表现匹配故障树，输出处理顺序、验证动作、是否需要抬马桶，以及命中红线时的停用提示。

> 脚本只做关键词匹配，**不代表现场判断**。渗水来源必须用干燥排查法实测。

## 七、人工确认清单（这步不能省）

- [ ] 干燥排查法确认过渗水来源，不是结露或软管
- [ ] 冲水时排污顺畅，没有反涌（堵的问题先解决）
- [ ] 角阀已关、智能马桶盖已断电断水
- [ ] 管口高度与内径实测过，法兰类型选对
- [ ] 有帮手配合，马桶重量与搬运路径确认过
- [ ] 旧蜡与旧胶清除干净，地面平整
- [ ] 马桶一次性垂直落下，没有挪动
- [ ] 螺母对角交替拧紧，没有过紧
- [ ] 冲水 5-8 次，底座四周无渗水
- [ ] 24 小时后复检，再打外侧密封胶

## 八、最常见的坑

**坑一：底座有水就抬马桶。**
水箱螺栓垫片、进水软管接头、水箱结露，表现都像底座漏水。先做干燥排查，能省掉一次抬马桶。

**坑二：堵着就装新法兰。**
排污不畅时第一次冲水就返水，新法兰当场报废。先疏通再装。

**坑三：用两个蜡圈叠起来凑厚度。**
压下时上层错位，密封失效。管口低于地面就用法兰延伸器或加厚法兰。

**坑四：马桶落下后又挪位置。**
蜡圈压过一次就成型，挪动后必须换新圈。对准是一次性动作。

**坑五：螺母拧到死紧。**
陶瓷被压裂，轻则渗水，重则整只马桶报废。手感紧即可，对角交替。

**坑六：抬起时倾斜扭转。**
排污口断裂、陶瓷碎裂割伤。必须两人配合垂直抬起。

**坑七：打胶把四周全封死。**
全封死会导致漏水无法被发现，等发现时地面已经泡坏。要留观察口。

**坑八：异味就换法兰。**
马桶异味也可能来自地漏水封干涸、洗手盆下水管无 S 弯、马桶内部存水弯裂缝。

**坑九：旧蜡圈舍不得换。**
拆下来的蜡圈已经变形，重复使用必然渗漏。蜡圈是一次性耗材。

## 九、边界与免责

- 本技能**不替代**排污管改造、防水修复、楼板结构处理等专业作业
- 马桶型号、排污口位置、管口尺寸差异大，**以现场实测与产品说明书为准**
- 涉及楼下渗水、楼板、需要切割管道的操作，应交给专业人员并通知物业
- 搬运重物存在腰伤与砸伤风险，不具备条件时应请专业人员
- 智能马桶拆装涉及电路与进水连接，应由专业人员或厂家售后处理
