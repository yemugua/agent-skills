# 马桶底座渗水判定与法兰圈更换规则

## 一、判定总原则

1. **来源先于施工。** 抬马桶成本极高，未确认来源不得动工。
2. **堵塞先于密封。** 排污不畅时装法兰必然返水报废。
3. **法兰是一次性耗材。** 拆下的蜡圈不得重复使用。
4. **落下即定位。** 马桶坐下后不得挪动，挪过必须换圈。
5. **宁松勿过紧。** 螺母过紧压裂陶瓷。

---

## 二、漏水来源对照表

| 渗水表现 | 真实来源 | 是否法兰问题 | 处置 |
|---|---|---|---|
| 冲水时底座边缘冒水 | 法兰密封失效 | 是 | 更换法兰 |
| 马桶晃动后出现异味 | 法兰被压偏移位 | 是 | 更换法兰并重新固定 |
| 马桶后侧靠墙处滴水 | 水箱与便器连接螺栓垫片老化 | 否 | 换垫片 |
| 底座一侧持续水渍 | 进水软管接头或角阀渗水 | 否 | 换软管垫片 |
| 黄梅天水箱外壁有水珠 | 水箱结露 | 否 | 属物理现象，加强通风 |
| 冲水后水面下降、异味重 | 存水弯水位异常或马桶本体问题 | 否 | 另查存水弯与本体 |
| 污水从排污口反涌 | 排污管堵塞 | 否 | 先疏通，装法兰解决不了 |

### 干燥排查法（动手前必做）

1. 擦干地面与马桶全部外表面
2. 静置 1 小时：不冲水、不用水、不洗澡
3. 检查是否出现新水渍
4. 无新水渍却长期有湿感 → 多为结露或别处流来
5. 有新水渍 → 按位置对照表定位

---

## 三、故障树（按处理顺序）

| 顺序 | 原因 | 判定 | 验证动作 | 处置 | 需停用报修 |
|---|---|---|---|---|---|
| 1 | 水箱结露 | 潮湿季节、水箱外壁水珠 | 干燥排查法 | 通风除湿，不维修 | 否 |
| 2 | 进水软管或角阀渗 | 底座一侧持续水渍 | 纸巾贴敷软管接头与角阀 | 换垫片或软管 | 否 |
| 3 | 水箱连接螺栓垫片老化 | 后侧靠墙滴水 | 纸巾贴敷水箱底部 | 换垫片 | 否 |
| 4 | 排污管堵塞 | 冲水返水、排污慢 | 冲水观察水位 | 先疏通再装法兰 | 严重返涌 → 是 |
| 5 | 法兰圈老化或移位 | 冲水时底座冒水、马桶晃 | 干燥排查 + 手晃测试 | 更换法兰 | 否 |
| 6 | 法兰选型错误 | 管口低于地面仍用普通圈 | 量管口高度 | 改用加厚法兰或延伸器 | 否 |
| 7 | 马桶本体裂纹 | 底座或水箱有可见裂缝 | 擦干后手电照检 | **停用报专业人员** | **是** |
| 8 | 地面不平或管口破损 | 瓷砖松动、管口缺角 | 水平尺测地面 | **停用报专业人员** | **是** |
| 9 | 楼板或防水层问题 | 楼下渗水、水印 | 询问楼下、看天花 | **停用报专业人员** | **是** |

## 四、法兰选型表

| 类型 | 特点 | 适用 | 不适用 |
|---|---|---|---|
| 蜡圈 | 一次成型、密封好、便宜 | 管口与地面基本齐平 | 装后不可挪动 |
| 橡胶 / 泡沫法兰 | 可重复调整、带导向套 | 管口略低于地面、需微调 | 管口不平整时密封差 |
| 加厚法兰 | 厚度更大 | 管口低于地面 1-2cm | 低于 2cm 以上仍不够 |
| 法兰延伸器 | 加长接管 | 管口低于地面 2cm 以上 | 安装深度不足的场合 |

### 两个关键尺寸

1. **管口高度**：齐平 / 略低 / 明显低于地面。低于 2cm 以上必须用延伸器
2. **管口内径**：常见 100mm，也有 110mm，导向套外径要匹配

**禁止叠装两个蜡圈凑厚度。** 压下时上层错位，是最常见的返工原因。

## 五、拆装作业顺序（十五步）

### 拆除（1-7）

1. 关角阀；智能马桶盖拔插头并关进水
2. 冲水排空水箱，海绵吸干水箱与便器内余水
3. 拆进水软管，下方垫毛巾接残水
4. 撬开底座螺母装饰盖，卸两侧螺母（锈死喷松动剂，禁止硬拧）
5. 一体式跳过；分体式拆水箱与便器连接螺栓
6. 两人配合，双手抱住马桶**垂直向上抬起**，严禁倾斜扭转
7. 放到纸板或旧毛毯上，立即用抹布堵住排污口

### 清理与安装（8-15）

8. 塑料铲刀铲除旧蜡与旧胶，除胶剂辅助，禁止金属铲刀刮瓷砖
9. 检查管口高度、管口是否破损、地面是否平整
10. 试放新法兰，确认导向套能坐入管口且高度合适
11. 底座内侧打一圈中性硅酮胶，两侧或后侧留观察口
12. 两人对准螺栓孔，**一次性垂直落下**，落下后不得挪动
13. 坐压或用身体均匀施压，把法兰压实
14. 装螺母，对角交替分两次拧紧，手感紧即可
15. 接回软管，缓慢开角阀，静置 30 分钟后冲水 5-8 次逐次观察

## 七、安全红线（必须停用并报专业人员）

| 情形 | 处置 |
|---|---|
| 楼下天花板渗水、水印、滴水 | 停止拆装，报物业与专业维修 |
| 地面排污管需切割、移位、改造 | 转专业人员 |
| 马桶底座或水箱本体有裂纹 | 整体更换，转专业人员 |
| 地面明显不平、瓷砖松动需找平 | 转专业人员 |
| 智能一体马桶拆装 | 涉及电路与进水，转专业人员或厂家售后 |
| 排污不畅、冲水反涌 | 先疏通，不得在堵塞状态下装法兰 |
| 无人协助、无法安全搬运 | 请专业人员，避免腰伤与砸伤 |

**禁止事项：**

- 禁止用叠装蜡圈凑厚度
- 禁止抬起时倾斜扭转（排污口断裂、陶瓷碎裂割伤）
- 禁止螺母拧到死紧（压裂陶瓷）
- 禁止重复使用已压过的旧蜡圈
- 禁止打胶把四周全封死（漏水无法被发现）
- 禁止用金属铲刀刮瓷砖表面

## 八、常见误判清单（反向判断）

| 现象 | 常见误判 | 正确判断 |
|---|---|---|
| 底座周围有水 | 法兰坏了 | 可能是软管接头、水箱螺栓垫片或水箱结露 |
| 卫生间有异味 | 法兰漏气 | 也可能来自地漏水封干涸、洗手盆下水管无 S 弯 |
| 装完还漏 | 新法兰质量差 | 多为没压实、落下后挪动过、螺栓过紧导致陶瓷裂 |
| 管口低一截 | 用两个蜡圈叠起来 | 必须用法兰延伸器或加厚法兰 |
| 马桶轻微晃动 | 螺栓松了 | 螺栓松会带动法兰移位，需抬开检查法兰 |
| 黄梅天地面湿 | 渗水 | 多为水箱结露，干燥排查可区分 |
| 冲水慢 | 法兰不合适 | 是排污不畅，先疏通 |
| 后侧滴水 | 法兰问题 | 水箱与便器连接螺栓垫片老化 |

## 九、验收标准

| 项目 | 合格标准 |
|---|---|
| 冲水 | 连续冲水 5-8 次，底座四周无渗水 |
| 稳固 | 手晃马桶无明显位移与异响 |
| 密封 | 静置 24 小时后地面无新水渍 |
| 排污 | 冲水顺畅，无返水、无咕噜声 |
| 打胶 | 24 小时复检合格后，再打外侧密封胶并留观察口 |

任一项不合格，按故障树重新定位，不要重复抬马桶。
