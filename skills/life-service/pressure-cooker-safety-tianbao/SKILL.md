# 高压锅使用与安全核查（pressure-cooker-safety）

高压锅的全部安全，都建立在一个前提上：**锅内压力必须能被可靠地释放。** 所有严重事故的根源都是「压力释放不了」或「带压开盖」。

这个技能做三件事：**过红线 → 配档位 → 定停用**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 输出十项安全红线自检与三级判定 | ❌ 检测锅具耐压强度与安全性能 |
| 按食材给出压力档位匹配建议 | ❌ 指导改装、拆卸或更换安全阀与限压阀 |
| 列出必须立即停用的情形与禁止操作 | ❌ 给出「压力多大算正常」的仪器判据 |
| 说明停火后自然冷却要求 | ❌ 替代产品说明书与专业维修 |

**出现以下任一情况，立即停用并转交专业维修，不要自行处理：**

- 听到**异常噪音、尖锐啸叫或锅体剧烈震动**
- **压力表指针不归零、不摆动或明显抖动**
- **限压阀或安全阀堵塞、锈死、卡滞**
- **密封圈老化开裂、变形或缺失**
- **锅体变形、底部凹陷、焊点渗漏**
- **排气口堵塞**，或蒸汽从**非排气口位置**喷出
- 锅盖**无法锁紧**或有明显缝隙

> **本技能不提供任何改装指导。** 擅自更换或改装安全阀会直接破坏整台锅的安全机制，属严重隐患，必须由专业人员按产品说明处理。

## 二、十项安全红线自检

**这十项在使用前逐项确认，任一项不合格即禁止使用。**

| # | 自检项 | 为什么重要 |
|---|---|---|
| 1 | **限压阀通畅** | 堵塞是高压锅最危险的故障之一，会导致锅内压力无法释放 |
| 2 | **安全阀通畅且未改动** | 被替换、拆除或改动会导致压力无法释放 |
| 3 | **密封圈完好无老化** | 老化变形或裂纹导致封口不严，压力泄漏或蒸汽外溢烫伤 |
| 4 | **配重块齐全且未变形** | 缺失或变形导致压力档位不准，蒸汽泄漏或压力失控 |
| 5 | **排气口无遮挡** | 被毛巾、锅具或残渣堵塞会导致压力无法释放 |
| 6 | **装量未超过上限线** | 超量会在沸腾时产生泡沫顶起限压阀，压力失控 |
| 7 | **锅盖与锅口已清洁** | 锅口残渣导致密封不严，蒸汽从缝隙喷出烫伤 |
| 8 | **限压阀与安全阀已定期清洗** | 阀孔积垢导致压力释放不畅，是压力表异常的常见原因 |
| 9 | **使用年限在产品说明范围内** | 超期服役部件可能失效 |
| 10 | **锅体底座与灶面贴合稳定** | 底座变形或悬空导致受热不均，压力波动异常 |

**三级判定：**

| 判定 | 条件 | 处置 |
|---|---|---|
| **可正常使用** | 十项全部合格 | 按压力档位匹配表使用 |
| **待确认** | 存在未检查项 | 未确认前不要开始加热 |
| **禁止使用** | 存在任一不合格项 | 先处理再使用，不要开始加热 |

## 三、按食材的压力档位匹配

| 食材 | 建议档位 | 易堵口 | 需完全泄压 | 关键禁忌 |
|---|---|---|---|---|
| **肉类** | 高压 | 否 | **是** | 需完全去除压力后才能开盖 |
| **排骨与带骨肉** | 高压 | 否 | **是** | 骨渣可能堵塞排气口，勿超量 |
| **带壳鸡蛋** | 高压 | 否 | **是** | 带壳鸡蛋需完全泄压，骤然开盖会爆裂 |
| **豆类与豆制品** | 中压 | **是** | 否 | 易产生泡沫顶起限压阀，需留足空间并分批 |
| **海鲜与贝类** | 中压 | **是** | **是** | 易起泡顶阀，升温阶段须盯着限压阀 |
| **整鱼** | 中压 | **是** | **是** | 易堵塞，升温时须全程看管 |
| **土豆与根茎** | 中压 | **是** | 否 | 淀粉类易糊底堵塞，排气口须畅通 |
| **玉米与根茎类** | 中压 | 否 | 否 | 易膨胀顶阀，装量不宜过多 |
| **绿叶蔬菜** | 低压 | **是** | 否 | 体积大易堵限压阀，勿装满 |
| **面条与米线** | 低压 | **是** | 否 | 易糊底，升温快需小火 |
| **米饭与粥** | 低压 | 否 | 否 | 易溢锅，勿超过内锅容积上限线 |
| **速冻水饺** | 低压 | **是** | 否 | 易堵口，且速食本身无需高压 |

**档位说明**：

- **低压**（约 80 千帕）：叶菜、面条、米饭粥类等易熟或易糊食材
- **中压**（约 100 千帕）：根茎、豆类、海鲜等需要适中压力的食材
- **高压**（约 120 千帕）：肉类、带骨肉、带壳蛋等需要快速熟透的食材

**不同品牌与型号的压力值与档位定义可能不同，以产品说明书为准。**

## 四、易堵口食材的特别要求

豆类、海鲜、整鱼、叶菜、面条这五类**极易堵塞排气口或顶起限压阀**：

1. **留足空间**：装量明显低于上限线
2. **分批处理**：豆类一次不要煮太多
3. **升温阶段全程看管**：这是最关键的窗口期，泡沫顶阀就发生在这个阶段
4. **排气口方向避开面部与身体**
5. **淀粉类食材易糊底**：糊住阀孔会导致压力释放不畅

## 五、必须立即停用并转专业维修（7 条）

1. 听到**异常噪音、尖锐啸叫或锅体剧烈震动**
2. **压力表指针不归零、不摆动或明显抖动**
3. **限压阀或安全阀堵塞、锈死、卡滞**
4. **密封圈老化开裂、变形或缺失**
5. **锅体变形、底部凹陷、焊点渗漏**
6. **排气口堵塞**，或蒸汽从**非排气口位置**喷出
7. 锅盖**无法锁紧**或有明显缝隙

**这七条没有「凑合用一下」的选项。** 压力释放机制一旦失效，下一次开盖可能就是事故。

---

## 六、明确禁止的操作（8 条）

1. **严禁在压力未完全释放时强行开盖**
2. **严禁带压开盖**，或用工具强行扳动锅盖
3. **严禁堵塞排气口**，或在其上覆盖任何物品
4. **严禁改装、拆除或替换安全阀与限压阀**
5. **严禁超过红线装量**，或超过内锅上限线
6. **严禁使用超过产品说明年限的锅具**继续作业
7. **严禁在无人看管状态下加热**
8. **严禁用高压锅烹煮易产生大量泡沫**而不留排气的食材

---

## 七、停火后冷却要求（最重要的一条）

```
听到异常噪音或出现压力异常
    ↓
立即停火，自然冷却
    ↓
严禁强行开盖　　严禁用冷水浇淋锅体加速冷却
    ↓
自然冷却过程中限压阀仍可能喷出蒸汽
    ↓
保持人员在场，避开排气口方向
    ↓
压力表指针完全归零、限压阀不再喷气
    ↓
方可按说明书开盖
```

**为什么严禁冷水浇淋**：锅体骤然降温会使内腔产生负压，反而增加开盖难度；同时剧烈温差可能导致锅体变形或内胆开裂。

**为什么必须避开排气口方向**：自然冷却过程中限压阀仍会喷出高温蒸汽，站在正前方极易烫伤。

```bash
python scripts/pressure_cooker_check.py --file cooker.json --out 安全核查.md
python scripts/pressure_cooker_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`checks` 十项自检结果（true/false，省略视为未检查）、`items` 食材列表 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检（31 条断言，含 BOM 输入两条） |

输入 JSON 示例：

```json
{
  "checks": {
    "limit_valve": true,
    "safety_valve": true,
    "gasket": false,
    "weight": true,
    "vent_clear": true,
    "fill_level": true,
    "seal_clean": true,
```

脚本输出：三级判定（可正常使用／待确认／禁止使用）、十项红线逐项状态与原因、食材压力档位匹配（不匹配项排最前）、必须停用的 7 条情形、明确禁止的 8 条操作、停火后冷却要求与提示。**脚本不做耐压检测，也不替代产品说明书。**

## 十、最常见的坑

**坑一：压力还在就开盖。**
错误做法：锅不冒气了、火关了，随手就开盖。正确做法：**必须等压力表指针完全归零、限压阀不再喷气**才能开盖。判断依据是压力表，不是「看着不冒气」——蒸汽可能仍在压力下。

**坑二：为了赶时间用冷水浇锅身。**
错误做法：想快点降温，把锅放水池冲。正确做法：**严禁冷水浇淋加速冷却**。骤冷会产生负压，反而更难开盖，还可能导致锅体变形或内胆开裂。自然冷却即可。

**坑三：排气口上盖块布防溅。**
错误做法：怕蒸汽喷出来，在排气口盖块毛巾。正确做法：**严禁堵塞排气口**。这会让压力完全无法释放，是最危险的错误做法之一。防溅应调整排气方向，而不是堵住出口。

**坑四：安全阀坏了换一个「一样的」。**
错误做法：安全阀不灵了，自己换个看着差不多的。正确做法：**严禁改装、拆除或替换安全阀与限压阀**。不同阀体的开启压力不同，替换后整台锅的安全机制就失效了，必须由专业人员按产品说明处理。

**坑五：豆子装满一锅。**
错误做法：红豆装到上限线，煮两个小时。正确做法：豆类**易产生泡沫顶起限压阀**，需留足空间并分批，升温阶段全程看管。

**坑六：装量越多越划算。**
错误做法：反正锅大，一次做一周的量。正确做法：**装量超过内锅上限线会在沸腾时产生泡沫顶起限压阀**，导致压力失控。高压锅不是「装得越多越省时间」。

**坑七：密封圈该换就换，不看状态。**
错误做法：密封圈看着还行就用。正确做法：密封圈**老化、变形、开裂**会导致封口不严，蒸汽从缝隙喷出烫伤。这是需要立即停用转专业维修的七条之一。

**坑八：带壳鸡蛋煮完立刻开盖。**
错误做法：鸡蛋煮好了，马上开盖拿。正确做法：带壳鸡蛋**必须完全释放压力后**才能开盖。骤然开盖时壳内压力未释放，会爆裂。

**坑九：锅盖没扣到位也照样用。**
错误做法：赶时间，锅盖随手一扣就开火。正确做法：**锅盖无法锁紧或有明显缝隙**属于必须停用情形。密封不严时蒸汽会从缝隙喷出，直接烫伤，且压力无法达到设定值。

**坑十：锅一直在用，年头不记得了。**
错误做法：一口锅用了十几年，家里一直用着。正确做法：**使用年限应按产品说明核对**。超期服役的老化部件可能失效，密封圈、阀体等都会随时间劣化。

**坑十一：无人看管，「就十分钟」。**
错误做法：定时器设好，去做别的事。正确做法：**严禁在无人看管状态下加热**。压力异常、泡沫顶阀都需要当场处置，离开就失去了处置窗口。

**坑十二：压力表不动就再等等。**
错误做法：压力表指针好像没归零，再等一会儿。正确做法：**压力表指针不归零、不摆动或明显抖动**属于必须立即停用情形。这可能是阀孔堵塞或卡表，等下去只会延误处置。
