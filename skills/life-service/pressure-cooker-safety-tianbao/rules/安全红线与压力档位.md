# 高压锅安全红线与压力档位

> 生成安全建议前先读这份文件。任何一条红线不合格，都不要开始加热。

## 一、十项安全红线自检

| 键 | 自检项 | 为什么重要 |
|---|---|---|
| `limit_valve` | 限压阀通畅 | 堵塞会导致锅内压力无法释放，是最危险的故障之一 |
| `safety_valve` | 安全阀通畅且未改动 | 被替换拆除或改动会导致压力无法释放 |
| `gasket` | 密封圈完好无老化 | 老化变形开裂导致封口不严，蒸汽外溢烫伤 |
| `weight` | 配重块齐全且未变形 | 缺失变形导致压力档位不准 |
| `vent_clear` | 排气口无遮挡 | 堵塞导致压力无法释放 |
| `fill_level` | 装量未超过上限线 | 超量会在沸腾时产生泡沫顶起限压阀 |
| `seal_clean` | 锅盖与锅口已清洁 | 锅口残渣导致密封不严 |
| `valve_clean` | 限压阀与安全阀已定期清洗 | 阀孔积垢导致释放不畅 |
| `age` | 使用年限在产品说明范围内 | 超期服役部件可能失效 |
| `base_flat` | 锅体底座与灶面贴合稳定 | 悬空导致受热不均、压力波动 |

**三级判定**

| 判定 | 条件 | 处置 |
|---|---|---|
| 可正常使用 | 十项全部合格 | 按档位表使用 |
| 待确认 | 存在未检查项 | 未确认前不要开始加热 |
| 禁止使用 | 存在任一不合格项 | 先处理再使用 |

## 二、按食材的压力档位

| 键 | 食材 | 档位 | 易堵口 | 需完全泄压 | 关键禁忌 |
|---|---|---|---|---|---|
| `meat` | 肉类 | 高压 | 否 | 是 | 完全去压后才能开盖 |
| `bones` | 排骨与带骨肉 | 高压 | 否 | 是 | 骨渣可能堵排气口，勿超量 |
| `egg` | 带壳鸡蛋 | 高压 | 否 | 是 | 骤然开盖会爆裂 |
| `beans` | 豆类与豆制品 | 中压 | 是 | 否 | 易起泡顶阀，留空间分批 |
| `seafood` | 海鲜与贝类 | 中压 | 是 | 是 | 升温须盯着限压阀 |
| `whole_fish` | 整鱼 | 中压 | 是 | 是 | 升温全程看管 |
| `potato` | 土豆与根茎 | 中压 | 是 | 否 | 淀粉易糊底堵阀 |
| `corn` | 玉米与根茎类 | 中压 | 否 | 否 | 易膨胀顶阀 |
| `leafy_veg` | 绿叶蔬菜 | 低压 | 是 | 否 | 体积大易堵，勿装满 |
| `noodle` | 面条与米线 | 低压 | 是 | 否 | 易糊底，升温快需小火 |
| `rice_water` | 米饭与粥 | 低压 | 否 | 否 | 易溢锅，勿超上限线 |
| `noodle_dumpling` | 速冻水饺 | 低压 | 是 | 否 | 易堵口，速食无需高压 |

**档位定义**（不同品牌型号不同，以说明书为准）

| 档位 | 约压 | 适用 |
|---|---|---|
| 低压 | 80 千帕 | 叶菜、面条、米饭粥 |
| 中压 | 100 千帕 | 根茎、豆类、海鲜 |
| 高压 | 120 千帕 | 肉类、带骨肉、带壳蛋 |

## 三、易堵口食材五条要求

豆类、海鲜、整鱼、叶菜、面条五类极易堵塞排气口或顶起限压阀：

1. **留足空间**，装量明显低于上限线
2. **分批处理**，豆类一次不宜太多
3. **升温阶段全程看管**（最关键窗口期，泡沫顶阀就发生在此阶段）
4. **排气口方向避开面部与身体**
5. 淀粉类**易糊底**，糊住阀孔会导致释放不畅

## 四、必须立即停用转专业维修（7 条）

1. 异常噪音、尖锐啸叫或锅体剧烈震动
2. 压力表指针不归零、不摆动或明显抖动
3. 限压阀或安全阀堵塞、锈死、卡滞
4. 密封圈老化开裂、变形或缺失
5. 锅体变形、底部凹陷、焊点渗漏
6. 排气口堵塞，或蒸汽从非排气口位置喷出
7. 锅盖无法锁紧或有明显缝隙

**这七条没有「凑合用一下」的选项。**

## 五、明确禁止的操作（8 条）

1. 严禁在压力未完全释放时**强行开盖**
2. 严禁**带压开盖**或用工具强行扳动锅盖
3. 严禁**堵塞排气口**或在其上覆盖任何物品
4. 严禁**改装、拆除或替换安全阀与限压阀**
5. 严禁**超过红线装量**或超过内锅上限线
6. 严禁使用**超过产品说明年限**的锅具继续作业
7. 严禁在**无人看管**状态下加热
8. 严禁烹煮易产生大量泡沫而不留排气的食材

## 六、停火后冷却流程

```
听到异常噪音或出现压力异常
    ↓
立即停火，自然冷却
    ↓
严禁强行开盖　严禁用冷水浇淋锅体加速冷却
    ↓
冷却过程中限压阀仍可能喷出蒸汽，保持在场并避开排气口方向
    ↓
压力表指针完全归零、限压阀不再喷气
    ↓
方可按说明书开盖
```

**为什么严禁冷水浇淋**：骤冷产生负压，反而增加开盖难度；剧烈温差可能导致锅体变形或内胆开裂。

**为什么必须避开排气口方向**：自然冷却中限压阀仍会喷出高温蒸汽，站在正前方极易烫伤。

## 七、开盖判据

- **压力表指针完全归零**（不是「看着不冒气」）
- **限压阀不再喷气**
- 两者都满足才可开盖

蒸汽可能仍在压力下，所以**判断依据是压力表，不是肉眼观察**。

## 八、否定词与防误伤

- 「**不冒气了**」**不等于**压力已释放，看压力表
- 「**盖得挺紧**」**不等于**锁紧到位，可能是残渣垫起缝隙
- 「**阀还能用**」**不等于**安全，积垢会导致释放不畅
- 「**用了这么多年没事**」**不等于**还在安全年限内
- 「**换个一样的阀**」**是错的**，不同阀体开启压力不同

## 九、处置决策树

```
1. 十项红线是否全部合格？
   ├─ 有不合格 → 禁止使用，先处理
   ├─ 有未检查 → 待确认，不开始加热
   └─ 全合格 → 继续
2. 食材是否属易堵口五类？
   ├─ 是 → 留足空间、分批、升温全程看管
   └─ 否 → 继续
3. 压力档位是否匹配食材？
   ├─ 否 → 调整到建议档位
   └─ 是 → 继续
4. 加热中出现异常噪音或压力异常？
   ├─ 是 → 立即停火，自然冷却，严禁开盖
   └─ 否 → 继续加热，全程有人看管
5. 开盖前两项是否都满足？
   ├─ 压力表归零 + 限压阀不喷气 → 方可开盖
   └─ 否 → 继续等待，绝不强行开盖
```
