# 消费者投诉维权路径核查

消费纠纷真正卡住的通常不是"有没有理"，而是**找错了部门、说错了话、算错了钱、错过了期限**。本技能把路径、定性、证据、金额、期限五件事一次算清。

## 什么时候用

- 买的东西坏了 / 与宣传不符，商家不认
- 网店退货被拒，不知道该找平台还是 12315
- 直播间下单，主播和店铺互相推
- 充值办卡后门店关门跑路
- 食品吃出问题，不知道能主张多少
- 想写投诉信，但不知道该写什么、写给谁

## 怎么做

**第 1 步**：复制 `templates/消费者投诉信息采集表.md` 填写（不知道的留空，别瞎填）。

**第 2 步**：跑脚本

```bash
python scripts/complaint_check.py 采集表.md --base 2026-10-05 --out 核查报告.md
```

**第 3 步**：按第九段"待办补正动作"执行，投诉信直接抄第八段骨架。

## 五步维权阶梯（先找谁）

| 第几步 | 找谁 | 什么情况下升级 |
|---|---|---|
| 1 | 商家 / 客服（**书面留痕**） | 首次沟通后 3~7 日无实质方案 |
| 2 | 电商平台介入（有平台时） | 平台超时未处理或处理明显不公 |
| 3 | 12315 / 消协（市场监管） | 平台无结果，或直接向经营者所在地投诉 |
| 4 | 行政投诉举报（违法线索） | 涉及虚假宣传、无证经营、食品安全等违法行为 |
| 5 | 小额诉讼 / 仲裁 | 金额明确、证据成形、前面几步都走了 |

→ **投诉与举报不是一回事**，选错了会白等：见 `rules/complaint-path.md`。

## 三条最容易被忽略的规则

1. **投诉要具体诉求**，举报不管个人退赔。想拿回钱走投诉，想让对方被查走举报，可以两条并行。
2. **"概不退费""最终解释权归本店"这类格式条款无效**，不能拿它挡你。
3. **欺诈才赔三**。普通质量问题只能退换修，主张三倍赔偿要先证明对方有欺诈行为。

## 输入 / 输出

| | 内容 |
|---|---|
| 输入 | 采集表 Markdown（交易 / 争议 / 已走步骤 / 证据 / 诉求 / 时限） |
| 输出 | 九段报告：结论摘要 / 路径排序 / 投诉与举报定性 / 管辖 / 证据缺口 / 诉求测算 / 时效 / 话术 / 待办 |
| 退出码 | 0 正常；2 关键信息缺失（给提示串，不崩） |

## 边界与纪律

- 依《消费者权益保护法》《消费者权益保护法实施条例》等**通用规则**整理，**不替代律师意见**
- 不代写诉状、不代发投诉、不预测处理结果
- 12315 受理范围、各地消协流程、平台规则以**当地主管部门与平台最新口径为准**
- 跨境购、金融理财、医疗纠纷、商品房买卖等特殊领域不适用本通用路径
- **未填的一律不算通过**，只按填了的判断

- `templates/投诉话术卡.md` — 书面投诉信骨架、电话沟通留痕要点
