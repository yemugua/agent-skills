# 投诉话术卡

## 一、书面投诉信骨架（可直接复制填）

```
【关于××的投诉】

一、事实
本人于 {交易日期} 通过 {平台/门店} 向 {经营者全称} 购买 {商品或服务名称}，
订单号 {订单号}，实付金额 ¥{金额}，{支付方式}支付，于 {签收日期} 收到。
收货后发现：{客观描述，不写情绪，不写形容词}。
本人于 {首次沟通日期} 通过 {渠道} 向商家提出 {诉求}，对方 {回复或拒不回复}。

二、依据
1. 经营者提供的商品与宣传/约定不符，属于未按约定提供商品；
2. 经营者以格式条款作出"概不退费""最终解释权归本店"等排除消费者权利的规定，该条款无效；
3. 经营者存在虚假宣传/欺诈行为的，消费者有权要求退还价款并增加赔偿损失。

三、诉求
1. 退还货款 ¥{退款金额}；
2. 支付增加赔偿金 ¥{赔偿金额}；
3. 合计 ¥{合计金额}。
（如为食品不符合安全标准：按价款十倍或损失三倍主张，不足 1000 元按 1000 元。）

四、期限
请于收到本函之日起 7 日内，将款项支付至本人原支付账户，
或通过上述联系方式给出书面解决方案。逾期未答复的，
本人将向 12315 及经营者所在地市场监管部门投诉，并依法提起诉讼，
由此产生的维权成本一并由经营者承担。

五、证据清单（共 {N} 项，随附）
1. 订单截图（含订单号、时间、金额）
2. 支付凭证（含收款商户全称）
3. 商品照片 / 开箱视频
4. 聊天记录（连续、未删减）
5. 检测报告 / 签收记录
```

## 二、电话沟通留痕要点

1. 通话开场先说："请问您是 {经营者名称} 的哪位？工号多少？"——**把主体和对方身份钉死**。
2. 说完事实后补一句："麻烦您把刚才说的方案在订单里用文字发我一遍。"——把口头变书面。
3. 挂电话后**立刻**发一条文字消息复述："今天 {时间} 与您通话，您的答复是 ×××，如理解有误请更正。"——对方不否认即视为确认。
4. 全程录音，保存原始文件，不要剪辑、不要转码后再删原文件。

## 三、跟客服说这三句就够了

- **不带情绪**："订单号 ×××，商品 ×××，问题是 ×××，我的诉求是 ×××。"（事实 + 诉求，一次说清）
- **不给台阶**："请您给一个明确的书面方案和答复期限。"（不要接受"我帮你反馈一下"）
- **不留模糊**："请在今天下班前用文字回复到本对话，我以此为准。"（拒绝口头承诺）

## 四、三种对方话术的破解

| 对方说 | 回应 |
|---|---|
| "过了 7 天不能退" | 7 天是**无理由**退货期；质量问题、与约定不符按法定责任处理，不受 7 日限制 |
| "最终解释权归本店" | 排除或限制消费者权利的格式条款**无效** |
| "你去告吧" | "我会向 12315 投诉并提起诉讼，本次通话已录音，您的答复将作为证据" |

## 五、12315 提交时怎么填

- **被投诉人**：写营业执照全称 + 实际经营地址，不写店招。
- **诉求**：写具体金额与项目，"要求退款 3280 元并赔偿 9840 元"，不写"要求合理处理"。
- **事实**：按时间轴写，一段一句，每句对应一项证据。
- **附件**：一次传齐，别分次补——分次补会重新排队。
