# 证据清单、取证要点与六类特殊场景

## 一、八项基础证据（缺一项就可能被退回）

| # | 证据 | 叫什么名字 | 怎么取 |
|---|---|---|---|
| 1 | **订单 / 合同** | 订单截图、电子合同、会籍协议、购货凭证 | 平台订单详情页整屏截图，含订单号、时间、金额 |
| 2 | **支付凭证** | 微信/支付宝账单、银行卡流水、POS 单、收据 | 账单页点「申请转账电子凭证」，要带商户全称 |
| 3 | **发票** | 增值税发票 / 电子发票 | 没有发票的，向商家索要；拒开可另行举报 |
| 4 | **商品照片 / 视频** | 开箱视频、瑕疵特写、整体照 | 拍摄时把**快递面单和商品同框**，证明是这一件 |
| 5 | **快递外包装** | 外箱六面照、面单、破损处 | 拆之前先拍，拆完就没了 |
| 6 | **聊天记录** | 平台站内、微信、短信 | **不要截局部**，从头到尾连续导出；微信可用「收藏→导出」 |
| 7 | **通话录音** | 与客服/商家的通话 | 通话开始时说明对方身份与时间，保存原始文件别剪辑 |
| 8 | **检测报告 / 签收记录** | 第三方检测报告、快递单号轨迹 | 检测要找有资质的机构；签收记录从快递官网导出 |

补充：**宣传页面截图**（含 URL 与时间）、**同一商品他人评价**、**同类商品官方参数页**——证明虚假宣传时这几样最关键，也最容易丢。

## 二、取证三条纪律

1. **先留痕再交涉**：打电话之前先发一条文字消息，把争议事实写清楚，让对方在文字里确认。
2. **保留原始载体**：截图用原图，录音留原始文件，别只留转发过的二手记录。
3. **时间轴成链**：下单 → 付款 → 收货 → 发现问题 → 第一次沟通 → 平台介入 → 投诉，每一环都要有对应材料，断一环就补一环。

## 三、六类特殊场景分支

### 1. 预付式消费跑路（健身卡、美容卡、培训课）
- 定性：单用途商业预付卡，受**商务主管部门**的单用途商业预付卡管理规定规范（实名、资金存管、退卡规则）。
- 路径：门店书面交涉 → 品牌总部 → **12315 + 商务主管部门** → 市场监管 → 小额诉讼 / 集体维权。
- 关键证据：会籍协议、付款凭证、余额记录、门店停业照片、迁址通知。
- 分支：如果门店转让且新主体不承接原卡，原经营者仍应承担责任。

### 2. 虚假宣传
- 定性：既可作**投诉**（要求退赔），又可作**举报**（违法线索查处），建议两条并行。
- 关键证据：宣传页截图（带 URL 与时间戳）、实物或检测结果、官方参数页。
- 分支：宣称"医用级""国家级""第一"等无依据用语，且影响购买决策的，主张欺诈更有抓手。

### 3. 质量问题
- 定性：先走**修理 / 更换 / 退货**；造成损失的另计实际损失。
- 分支：7 天无理由过期不影响质量问题的退换修主张。
- 分支：多次修理仍不能正常使用的，可要求更换或退货。

### 4. 食品安全
- 定性：不符合食品安全标准的，可主张**价款十倍或损失三倍**（不足 1000 元按 1000 元）。
- 关键证据：实物留存（**别吃完扔掉**）、检测报告、就医记录与票据。
- 分支：只是"不好吃""口味不符"不构成不符合安全标准，不适用十倍赔偿。

### 5. 网购平台责任
- 定性：向平台内经营者主张；平台不能提供经营者真实名称、地址和有效联系方式的，消费者也可以向**平台**要求赔偿。
- 分支：平台明知或应知商家侵害消费者权益而未采取必要措施的，依法承担**连带责任**。
- 操作：先用平台投诉入口留痕，同时保存平台的处理回复，作为后续投诉的证据。

### 6. 直播带货
- 定性：看清**实际销售主体**——直播间挂的店铺是谁、收款方是谁、发票谁开具。
- 分支：主播是经营者本人 → 向主播主张；主播只是推广 → 向店铺经营者主张，主播依其角色承担相应责任。
- 操作：**录屏**保存直播回放（含商品链接、价格、话术），回放下架后无法补取。

## 四、四类最容易吃哑巴亏的情形

1. **只打电话不落字**——没有文字记录，等于没沟通过。
2. **付款走"朋友转账"**——支付凭证上的收款方不是经营者，钱款去向说不清。
3. **被诱导办理分期贷**——消费贷与消费合同是两层关系，商家跑路后贷款仍要还，需单独处理。
4. **宣传页没截图**——下架即灭失，虚假宣传最难补的就是这一项。
