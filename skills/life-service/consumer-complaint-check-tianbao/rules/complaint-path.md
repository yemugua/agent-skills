# 维权路径：先找谁、什么时候升级

## 一、五步阶梯

| 第几步 | 找谁 | 怎么提 | 什么时候升级 |
|---|---|---|---|
| **第 1 步** | 商家 / 客服 | **书面**（平台站内文字、微信、短信、邮件），别只打电话 | 首次提出后 **3~7 个自然日**无实质方案，或直接被拒 |
| **第 2 步** | 电商平台（有平台时） | 订单页「申请售后 / 投诉商家 / 平台介入」，提交图片与聊天截图 | 平台超时未处理、处理明显偏袒、或平台本身就是经营者 |
| **第 3 步** | 12315 / 消费者协会 | 拨打 12315，或用全国 12315 平台网站 / 小程序 / App 提交 | 平台无结果；线下消费可直接进入本步 |
| **第 4 步** | 行政投诉举报 | 向市场监管部门提交举报线索（违法行为查处） | 涉及虚假宣传、无证经营、食品安全、假冒伪劣等违法行为 |
| **第 5 步** | 小额诉讼 / 仲裁 | 被告住所地或合同履行地基层法院，走小额诉讼程序 | 诉求金额明确、证据成形、前几步均已走完 |

**升级判据一句话**：对方「不回应 / 明确拒绝 / 超时未办结 / 给出的方案低于法定标准」→ 立刻升一级，不要在同一级反复拉扯。

## 二、投诉与举报不是一回事（选错白等）

| | **投诉** | **举报** |
|---|---|---|
| 性质 | 消费**争议**，要求解决我和商家之间的事 | 提供**违法线索**，要求查处违法行为 |
| 要件 | 有明确的被投诉人、**具体的诉求和理由**、属于消费争议 | 有违法线索即可，不需要与个人有争议 |
| 结果 | **组织调解**，促成退赔、修理、更换 | **立案查处**，作出行政处罚 |
| 能不能拿回钱 | 能，调解成功即可拿到退赔 | **不能**，举报不解决个人退赔问题 |
| 期限 | 7 日内决定是否受理；**60 日内办结**，情况复杂可延长 **30 日** | 按行政执法程序办理，期限不必然一致 |
| 奖励 | 无 | 部分领域查处后可能有举报奖励，以当地规定为准 |

→ **实务做法**：两条并行。投诉书里写诉求与金额，举报信里写违法事实与证据；不要指望举报能把钱要回来。

## 三、管辖：向哪儿提

- **一般**：向**经营者实际经营地**或者**平台经营者住所地**县级以上市场监管部门提出。
- **网络交易**：可以向**平台住所地**或者**经营者所在地**提出；平台通常设有在线投诉入口，优先用平台入口留痕。
- **线下门店**：向门店**实际经营地**（不是注册地）的区县市场监管局提出；12315 会自动分流转办。
- **预付卡跑路**：除市场监管外，可同时向**商务主管部门**（单用途商业预付卡主管部门）反映。
- **食品安全**：向市场监管部门投诉举报，涉事的还可同步向卫生健康部门反映。
- **虚假宣传 / 广告**：市场监管部门（广告监管条线）。

→ 各省市 12315 平台的分流规则略有差异，**以当地市场监管部门口径为准**；查询入口：全国 12315 平台网站、12315 微信小程序、当地市场监管局官网 / 公众号。

## 四、办结期限与受理口径

| 环节 | 期限 |
|---|---|
| 12315 决定是否受理 | 收到投诉之日起 **7 日内** |
| 12315 办结 | **60 日内**；情况复杂的经批准可延长 **30 日** |
| 不予受理的常见情形 | 不是消费争议、被投诉人不明确、没有具体诉求和事实依据、已超过诉讼时效、已进入司法或仲裁程序、其他部门已受理 |
| 平台售后 | 以平台公示规则为准，**7 天无理由退货**（网购，自签收次日起 7 日）是最低线，质量问题不受此限 |
| 诉讼时效 | **3 年**，自知道或应当知道权利受到损害及义务人之日起算 |

## 五、走上一步之前必须先做的三件事

1. **固定证据**：下单页、宣传页、聊天记录、支付凭证、商品现状，全部截图或拍照留原图。
2. **算清金额**：把诉求写成"退货退款 3280 元 + 三倍赔偿 9840 元 = 13120 元"这种可执行的数字，不写"要求合理赔偿"。
3. **给期限**：书面材料里必须写"请于收到本函之日起 X 日内答复"，不写期限等于没催。
