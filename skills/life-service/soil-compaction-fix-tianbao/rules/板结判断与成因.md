# 板结判断与成因口径

本文件是「土壤板结」技能的核心资产。**改良前先读这里确认是不是板结、成因是什么。** 农业类只给判断流程与记录，不代开方、不给农药浓度。

## 1. 判断口径（四项，命中两条以上判为板结）

| 判断项 | 板结表现 | 怎么测 |
|---|---|---|
| 浇水下渗 | 水浮在表面、长时间渗不下去 | 浇一杯水，记渗完时间，明显慢于正常 |
| 土表结皮 | 表面发白、结硬壳 | 肉眼/手摸，干后成壳 |
| 硬度 | 铲/手指难插入 | 用木棍或手测阻力 |
| 根系形态 | 根盘在表层、扎不深 | 拔起或观察，根横向铺开 |

> 只「浇水渗不下去」一项，也可能是暂时缺水或坡度问题，需结合其他项判断。

## 2. 不是板结的情况（避免误判）

- 单纯长期干旱，浇透后恢复疏松
- 盐碱地表层泛白结晶（需专业检测，不在此范围）
- 新换的纯泥炭未沉实（会自然沉降）

## 3. 成因排查表（先判断再动手）

| 成因 | 表现线索 | 对应改良 |
|---|---|---|
| 长期踩踏/压实 | 小径、常走处更硬 | 停践踏 |
| 黏重土 | 黏土比例高、易结块 | 增施有机质+覆盖 |
| 有机肥长期偏少 | 连年种不补肥 | 增施腐熟有机质 |
| 浇水方式错 | 大水猛冲、表土结皮 | 改小水勤浇+覆盖 |
| 连作不倒茬 | 同一作物连年种 | 轮作绿肥 |

## 4. 禁忌（硬红线，碰到即判不合格）

- 使用未腐熟有机肥（生粪、生堆肥）
- 花盆深翻伤根
- 不排查成因直接猛加单一物料
- 涉及农药稀释浓度的强指令（不在本技能范围）
