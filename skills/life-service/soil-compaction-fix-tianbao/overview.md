# 土壤板结（土壤板结 / soil-compaction-fix）

你会得到什么：一份家庭园艺/菜地的土壤板结改良方案——先对照判断口径确认是不是板结（浇水下渗慢、土表结皮、硬度高、根系浅命中两条以上），再排查成因（踩踏/黏重/缺有机质/浇水方式/连作），然后走「停践踏 → 浅松土 → 增施腐熟有机质 → 覆盖 → 轮作绿肥」五步并锁住顺序，最后用改良前后的下渗与硬度记录核对效果。技能内置 `soil_fix_plan.py`，把方案写成 JSON 跑一遍，自动标出生肥、花盆深翻、顺序颠倒、未增施有机质等不合格项并附原因。

典型用法：花盆土板结、菜地土硬邦邦、浇水渗不下去、土表起白霜；想确认是不是板结、先做什么后做什么、能不能用生粪、花盆能不能深翻。写成字段交給脚本，立刻拿到「先处理 / 待确认 / 可照此执行」的结论。

边界：本技能只做板结的判断流程、改良步骤与记录核对，**不替代专业土肥检测，也不提供任何农药稀释浓度与喷施强指令**。涉及农药、除草剂使用请咨询农技或植保人员。
