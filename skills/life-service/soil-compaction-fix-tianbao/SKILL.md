# 土壤板结（soil-compaction-fix）

土板结不是「土不好」，多半是**被压实的 + 缺有机质**。浇水浮在表面渗不下去、铲子戳进去硬邦邦、植物根系盘在表层——这三样凑齐基本就是板结。改良的核心是「先判断成因、再按顺序改良、最后靠记录核对」，**不是往里猛加某样东西**。

这个技能做三件事：**判板结 → 排成因 → 走五步**。

---

## 一、硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出板结的判断口径与成因排查 | ❌ 给出任何农药的稀释浓度与喷施强指令 |
| 给出停践踏、松土、增施有机质的改良步骤 | ❌ 判断土壤缺哪种元素并开方施肥 |
| 给出覆盖与轮作绿肥的建议 | ❌ 指导大规模农田的机械化作业排期 |
| 给出改良前后的记录与核对清单 | ❌ 承诺任何改良周期或增产结果 |

**转交专业土肥/农技人员的情况**

- 大范围连片板结且成因不明
- 疑似盐碱化、酸化或重金属污染
- 需要专业土样检测与配方建议
- 涉及农药、除草剂的使用选择

## 三、完整工作流

1. **看症状**：浇水下渗慢、土表结皮、硬度高、根系浅——对照判断口径确认是不是板结。
2. **排成因**：长期踩踏/压实、黏重土、有机肥长期偏少、浇水方式错、连作不倒茬。先判断再动手。
3. **停践踏**：人畜不进、不堆重物，这是最容易忽略的一步。
4. **浅松土**：盆土用小耙浅松、不伤根；菜地浅耕，避免反复深翻把底层翻上来。
5. **增施腐熟有机质**：腐熟堆肥/厩肥/腐叶土混入，是根本。
6. **覆盖**：秸秆、碎草、树皮覆盖保墒抑草，减缓结皮。
7. **轮作绿肥**：空闲季种绿肥翻压，持续改善结构。
8. **做记录**：改良前后各测一次下渗与硬度，核对有没有变好。
9. **核对**：用 `--file` 跑一遍，把顺序错、生肥、花盆深翻先排掉。

## 四、核心规则说明

**动手之前必须先读这两个文件，不要凭印象写：**

- `rules/板结判断与成因.md` —— 判断口径、成因排查表、哪些表现不算板结
- `rules/改良步骤与记录.md` —— 五步操作顺序、有机质腐熟要求、覆盖与绿肥、记录核对

要点三条：

1. **先判断再改良**。没排查成因就猛加料，往往加错方向，白费功夫。
2. **有机质必须腐熟**。生粪、未腐熟有机物下地会烧根、二次发热，反而加重问题。
3. **花盆别深翻**。盆土浅松即可，深翻伤根，板结靠换土混有机质解决。

## 五、脚本用法

```
python scripts/soil_fix_plan.py --selftest
python scripts/soil_fix_plan.py --file soil.json
```

输入字段：

| 字段 | 说明 | 示例 |
|---|---|---|
| area_type | 地块类型 | 「花盆」「菜地」「庭院」 |
| symptoms | 板结症状列表 | 「浇水下渗慢」「土表结皮」 |
| cause_checked | 是否排查成因 | true |
| steps | 改良操作顺序列表 | 见规则文件 |
| organic_added | 是否增施有机质 | true |
| organic_type | 有机质种类 | 「腐熟堆肥」 |
| till_depth_cm | 松土深度厘米 | 8 |
| cover_used | 是否覆盖 | true |
| record_kept | 是否做改良前后记录 | true |

结论分三档：**先处理**（顺序错、用生肥、花盆深翻、未增施有机质）、**待确认**（信息不足）、**可照此执行**。存在真实缺陷时即使信息也不完整仍判先处理。

结果写入 `scripts/_last_result.txt`，每条不合格带原因。

## 六、人工确认清单（这步不能省）

- [ ] 已对照判断口径确认是板结，而不是单纯缺水或盐碱
- [ ] 已排查成因（踩踏/黏重/缺有机质/浇水方式/连作）
- [ ] 已停止人畜踩踏与堆放重物
- [ ] 松土只浅松，花盆未深翻伤根
- [ ] 用的有机质是腐熟的，不是生粪
- [ ] 已混入有机质而非只表面撒
- [ ] 有覆盖保墒抑草
- [ ] 空闲季安排了绿肥或轮作
- [ ] 改良前后测过下渗与硬度，有记录可核对

## 七、最常见的坑

1. **没判断就猛加料**。先看成因，不然加错方向。
2. **用生粪未腐熟**。烧根、发热、加重板结，是高频错误。
3. **花盆深翻**。伤根不说，板结靠换土混有机质才对。
4. **只表面撒不混入**。有机质要拌进土层才起作用。
5. **反复深翻**。把生土翻上来、把底土压实，越翻越板。
6. **不停践踏**。人在地里来回走，前脚松后脚压，白干。
7. **不覆盖**。裸露土面一干就结皮，浇水更渗不下去。
8. **不记录**。改没改好全凭感觉，无法核对、无法复盘。
