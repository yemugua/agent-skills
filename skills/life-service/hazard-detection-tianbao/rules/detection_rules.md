# 危害检测规则库（detection_rules）

> 本文件是 hazard-detection 技能的规则支撑。周期以现行规定为准。

## 一、法规依据速查

| 文件 | 关键要求 | 关联 |
|---|---|---|
| 《工作场所职业卫生管理规定》（国家卫健委令第5号） | 定期检测每年至少一次；结果告知 | 检测义务来源 |
| 《职业病防治法》 | 危害因素检测、结果利用 | 法源 |
| GBZ 159 | 采样规范 | 布点方法 |
| GBZ 2.1/2.2 | 职业接触限值 | 判读依据 |

## 二、检测类型与周期口径

| 类型 | 周期/触发 | 脚本判定 |
|---|---|---|
| 定期检测 | 每年 ≥1 次 | >365 天 FAIL |
| 评价检测 | 建设项目阶段 | 缺 WARN |
| 应急检测 | 事故触发 | 缺记录 WARN |

## 三、机构能力核验口径

- 职业卫生技术服务资质，范围覆盖检测项目
- 检测方法在能力表内
- 人员培训考核记录
- 报告要素：机构章/依据/布点图/数据/结论/签发人

## 四、布点原则

- 覆盖所有危害岗位
- 呼吸带高度
- 重点岗位加密
- 工种/班次分别布点
- 记录生产状态

## 五、结果运用闭环

判读（对限值）→ 超标：工程优先整改 + 复查 → 告知劳动者 → 公示/归档 → 纳入下次计划。

## 六、常见不合规情形

- 只测不改
- 布点漏岗位
- 机构资质不覆盖
- 结果不告知
- 检测时降负荷数据失真
