# 蚯蚓堆肥碳氮比与腐熟度判断（vermicompost-making）

堆肥失败最常见的两件事：**配比错了碳氮比失衡**，以及**水加多了闷成一坨**。氨味刺鼻说明氮多了还缺氧；酸味明显说明水太多、通风不足。这两种味道是判断方向最直接的信号。

这个技能做三件事：**配碳氮比 → 控温控湿 → 判腐熟**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出原料碳氮比与配比口径 | ❌ 指导处理医疗废物、宠物粪便以外的动物源危险废弃物 |
| 给出含水率、堆温、蚯蚓状态判断口径 | ❌ 处理有害生物、腐败肉类与含病原的废弃物 |
| 给出腐熟度判断与使用前的安全间隔口径 | ❌ 判断堆肥的病原灭活是否达标 |
| 给出氨味发酸的成因与处置顺序 | ❌ 推荐杀虫剂、消毒剂与除臭剂产品 |
| 给出家庭场地与操作卫生要求 | ❌ 处理工业污泥、建筑垃圾与含重金属的土壤 |

**遇到以下情况，停止自行处理，按当地环卫与农业废弃物管理要求处置：**

- 堆料中混入了医疗废物、宠物粪便、腐败肉类或带病禽畜粪便
- 堆体出现疑似传染性或人畜共患病源
- 堆肥用于食用农产品种植且对卫生指标有疑问
- 需要处理工业污泥、含重金属土壤或建筑垃圾
- 场地为阳台以外且影响邻里与环境卫生

**安全红线（必须遵守）：**

1. **禁入物料**：医疗废物（含用过的绷带、棉签、针具、药品包装）、宠物粪便（可能带寄生虫与病原）、腐败肉类、含重金属土壤、工业污泥、**含樟脑丸与杀虫剂包装的物品**——**樟脑丸对蚯蚓是强毒物，一颗就可能毁掉整箱**。
2. **场地卫生**：家庭堆肥建议在室外、避开餐饮与饮水区；**不得在阳台、封闭空间进行堆肥发酵**，发酵产热与气味会影响居住环境。
3. **洗手**：接触堆肥原料与成品后**必须洗手**；成品堆肥可能含有未完全分解的植物碎屑，接触后不要直接揉眼。
4. **不用药剂**：**不向堆肥中添加杀虫剂、消毒剂、除臭剂或氨水**。杀虫剂会毒死蚯蚓，消毒剂会杀死堆体微生物从而终止分解，氨水会瞬间提高 pH 与氮浓度。
5. **与食品分开**：堆肥原料容器与食品、餐具分开存放；**不使用盛过清洁剂或消毒液的容器**盛堆肥原料。
6. **儿童与宠物**：成品堆肥可能含未灭活的虫卵与生物性物质，操作后洗手；成品不用于直接入口。
7. **厨余前提**：带油、带盐、带酱汁的厨余**必须先沥油去盐并切碎**，否则会招虫、招鼠并产生酸腐。

## 二、完整工作流

```
第 1 步  清点原料：按碳氮比表分类，剔除禁入物料
第 2 步  算配比：按目标碳氮比 20-30:1 配干料，湿料按含水率折算
第 3 步  控水：手握成团、松开即散；偏干加少量水、偏湿加干料
第 4 步  装箱：分层铺料，每层加蚯蚓，厚度不超过箱高 2/3
第 5 步  控温：发酵升温期注意防烫伤，产热期每日测温
第 6 步  控味：每天闻一次，氨味查氮与通气，酸味查水与孔隙
第 7 步  转箱与补料：温度回落后转箱一次，补充成熟料
第 8 步  判腐熟：四项判据全通过再停用
第 9 步  熟化与使用：静置熟化后再用于盆栽与菜地
```

**顺序不能颠倒**：不测水分就装箱，后面基本是闷坏的结局。

## 三、碳氮比与配比

### 3.1 目标碳氮比

| 阶段 | 目标碳氮比 | 说明 |
|---|---|---|
| 起始发酵期 | **25:1 - 30:1** | 蚯蚓堆肥的常用起点 |
| 蚯蚓繁殖期 | 20:1 - 25:1 | 碳略降，氮略升 |
| 腐熟期 | 15:1 - 20:1 | 以氮为主，促分解 |

**碳氮比的意义**：碳过剩（干料太多）分解慢、堆体温度上不去；氮过剩（湿料太多）会氨挥发、pH 上升、烧死蚯蚓。**起始阶段取 25:1 - 30:1 是平衡两者的通用区间。**

### 3.2 常见原料碳氮比参考

| 原料 | 碳氮比 | 类别 | 处理要求 |
|---|---|---|---|
| 落叶、干树叶 | 40-80 | 高碳（干料） | 剪碎至 3-5 cm |
| 干草、秸秆 | 60-100 | 高碳（干料） | 剪碎至 3-5 cm |
| 纸板、牛皮纸 | 60-100 | 高碳（干料） | 撕碎、泡软、**去掉印刷与胶粘部分** |
| 咖啡渣 | 15-20 | 偏氮 | 用后滤纸去掉，含水率高需晾 |
| 茶叶渣 | 15-25 | 偏氮 | 用后滤纸去掉 |
| 水果皮（苹果、梨） | 25-40 | 中性偏碳 | 切碎、沥水 |
| 瓜皮（西瓜、甜瓜） | 20-30 | 中性 | 切碎、沥水 |
| 蔬菜叶、菜帮 | 15-25 | 偏氮 | 切碎 |
| 剩米饭、馒头 | 20-30 | 中性偏氮 | 需彻底沥干或晒干 |
| 豆渣 | 10-15 | 高氮 | 需与干料配比使用 |
| 新鲜草坪草 | 15-25 | 偏氮 | 剪短、切碎 |
| 纸箱瓦楞纸 | 60-90 | 高碳 | 撕碎泡软 |

**以上为通用参考值，实际碳氮比随原料批次变化**；精确配比需要检测，**以本地农业废弃物处理的技术口径为准**。

### 3.3 配比算法

```
干料份数 = (湿料份数 × 湿料碳氮比) / 目标碳氮比
```

例：目标 25:1，用湿料 2 份（碳氮比 20），则干料 = (2 × 20) / 25 = 1.6 份。

**湿料必须先沥水**：含水率高于目标区间时先晾晒或沥干，否则称出来的重量里大部分是水，配比全错。

## 四、含水率判断

**判定法（手握法）**：

| 手感 | 判定 | 处置 |
|---|---|---|
| 手握能成团，**松手即散开** | **合适** | 维持 |
| 手握成团，松手**成团不散、柔软可捏出少量水** | 偏湿 | 加干料并翻松、增加通气孔 |
| 手握不出水但料松散、一捏即碎 | 偏干 | 分次少量加水，边加边拌 |
| 手握出水、料滴水 | 过湿 | 加干料比例较大，充分翻松；必要时重新配料 |

**目标区间**：家庭蚯蚓堆肥常用手感判断，经验区间约 **50%-60%**（手握成团、松开即散）。

**为什么要这么严**：蚯蚓靠体表呼吸，**水太多会堵塞体表气孔导致窒息**；水太少则体表失水死亡。这是蚯蚓死亡的两个最常见原因。

**浇水方式**：**少量多次、喷洒在料面后翻拌均匀**，不要一次性大量浇在蚯蚓密集处。

## 五、三阶段温度曲线

| 阶段 | 时间（起始后） | 堆体温度 | 关键动作 |
|---|---|---|---|
| 升温期 | 0-3 天 | 20℃ → 40-50℃ | 不干预，记录温度 |
| 高温期 | 3-15 天 | 45-65℃ | **蚯蚓已下沉或钻入底层，属正常** |
| 降温期 | 15-30 天 | 40℃ → 30℃ | 可转箱一次 |
| 腐熟期 | 30-60 天 | 25-30℃ | 补料、判腐熟 |

**高温期的正常现象**：堆体中心温度超过 40℃ 后，**蚯蚓会主动下沉或转移到箱底与边缘**，表面看不到蚯蚓是正常的，不是"跑光了"。**不要因为表面看不到蚯蚓就翻动或加水**。

**温度异常的处置**：

| 现象 | 可能原因 | 处置 |
|---|---|---|
| 温度上不去，一直 20℃ 左右 | 碳氮比过高（干料太多）或水分不足 | 加少量湿料，翻松通气 |
| 温度过高超过 70℃ 且持续 | 碳氮比过低（湿料太多）或堆体过厚 | 加干料、摊薄、增加通风 |
| 温度正常但氨味刺鼻 | 氮过剩、pH 上升、通气不足 | 见第七节处置顺序 |

**测温口径**：用长杆温度计插入堆体中心，**避开边缘与表面**；同一位置每日同一时间测，便于比较。

## 六、蚯蚓状态判断

| 状态 | 判据 | 说明 |
|---|---|---|
| 活跃 | 蚯蚓钻动明显、体表湿润有光泽、蚓粪多 | 状态良好 |
| 受阻 | 蚯蚓活动变慢、集中在料面 | 水分偏干或温度偏低 |
| 下沉 | 高温期钻入底层或箱底 | **正常现象，不是异常** |
| 逃逸 | 从箱缝或表面大量爬出 | 强光刺激、缺水、氨味过重或 pH 异常 |
| 减少 | 连续观察数量明显下降 | 需逐项排查温度、水分、pH、气味与物料 |
| 死亡 | 见蜷缩、发黑、腐烂 | 逐项排查，不要只怪蚯蚓品种 |

**计数口径**：**固定时间、固定位置观察并记录条数**（如每周一次，箱角 10 cm × 10 cm 范围内），比"感觉变少了"可靠得多。

## 七、氨味与发酸的成因与处置

**氨味（刺鼻、挥发性强、伴随 pH 上升）**：

| 环节 | 内容 |
|---|---|
| 成因 1 | 碳氮比过低，湿料（尤其豆渣、剩饭、咖啡渣）比例过大 |
| 成因 2 | 堆体过厚、压实过紧，**内部缺氧** |
| 成因 3 | 通气孔堵塞或箱体密闭，氨气排不出去 |
| 处置 1 | 立即加干料（剪碎的落叶、秸秆、纸板），比例按感觉补，不刻意称量 |
| 处置 2 | 翻松堆体、增加通气孔 |
| 处置 3 | 降低堆体厚度、摊开扩大表面积 |
| 处置 4 | 移出上部料层，检查底层是否已经糊化 |
| 禁止 | **不喷水、不加氨水、不加消毒剂、不喷除臭剂** |

**酸味或酸腐味（发酸、渗液、有酒味）**：

| 环节 | 内容 |
|---|---|
| 成因 1 | **水分过高**，堆体压实，氧气不足后进入厌氧发酵 |
| 成因 2 | 含水率高的厨余（水果、剩饭）比例过大且未沥干 |
| 成因 3 | 翻堆频率太低，长期不扰动 |
| 处置 1 | 加干料并**充分翻松**，让空气进入堆体内部 |
| 处置 2 | 减少后续湿料投放，特别是高含水厨余 |
| 处置 3 | 检查排水孔是否堵塞，必要时在底部加透气层 |
| 处置 4 | 严重发酸且已渗液的料**整批取出重新配料**，不要试图"补救" |
| 禁止 | **不喷水、不加石灰中和**（石灰改变 pH 且不利蚯蚓） |

**判断口诀**：**氨味查氮和氧，酸味查水和氧。**

## 八、腐熟度判断

**四项判据，全部通过才算腐熟**：

| 判据 | 腐熟特征 | 未熟特征 |
|---|---|---|
| **气味** | 无氨味、无酸味、无酒味；有淡淡的泥土味或腐殖质气味 | 刺鼻氨味、酸腐味或酒味 |
| **颜色** | 均匀褐色或深褐色 | 仍能看到明显的浅色原料碎片 |
| **质地** | 松软、有腐殖质感、捏之即散 | 黏、结块、有生硬原料感 |
| **温度** | 与环境温度接近（25-30℃） | 仍明显高于环境温度 |

**辅助判据**：

- 蚯蚓数量明显减少甚至消失（**不是判断腐熟的标准**，只是伴随现象）
- 原料形态基本消失，看不出原始叶片、纸板的形态
- 体积明显缩小

**停用后仍需熟化**：达到腐熟判据后**静置 2-4 周**再使用。熟化过程让未完全分解的部分继续降解，也降低刺激性。

**用于食用农作物时的口径**：家庭堆肥用于蔬菜等可食部位时，**卫生指标无法在家确认**，建议先用于盆栽花卉与观叶植物，积累经验后再用于可食作物；用于可食作物时应遵循当地对有机肥料的管理要求。**未充分腐熟的堆肥不得直接接触可食部位。**

## 九、脚本用法

```
python scripts/vermi_calc.py --file compost.json
python scripts/vermi_calc.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`dry_parts`（干料份数）、`wet_parts`（湿料份数）、`wet_cn`（湿料碳氮比）、`target_cn`、`days`、`temp_c`、`moisture`（手感代号）、`smell`、`total_materials` |
| `--json` | 以 JSON 输出 |
| `--out` | 结果写入指定文件，默认 `scripts/_last_result.txt` |
| `--selftest` | 运行自检 |

脚本做四件事：**按目标碳氮比算干料份数 → 按手感代号判含水率并给处置 → 按天数与堆温定位阶段并给温控口径 → 按气味定位成因与处置顺序 → 判腐熟四项**。脚本**不推荐任何药剂与消毒产品**。

## 十、人工确认清单（这步不能省）

- [ ] 原料已按禁入物料清单逐项剔除（含樟脑丸的包装已单独丢弃）
- [ ] 已按碳氮比表分类，目标碳氮比取 25:1 - 30:1
- [ ] 湿料已沥水，含水率降到合适范围后再称重
- [ ] 手握法确认含水率：能成团、松开即散
- [ ] 堆体厚度不超过箱高 2/3，留有通气空间
- [ ] 有通气孔或透气孔隙，不完全密闭
- [ ] 每日同一时间同一位置测温并记录
- [ ] **高温期表面看不到蚯蚓时未盲目翻动**
- [ ] 每日闻一次气味，氨味与酸味分开判断
- [ ] 出现氨味时**未喷水、未加氨水、未加消毒剂**
- [ ] 出现酸味时**未喷水、未加石灰**，而是加干料并翻松
- [ ] 堆肥场地在室外，未在阳台或封闭空间进行
- [ ] 接触原料与成品后已洗手
- [ ] 腐熟四项判据全部通过后才停用，并静置熟化 2-4 周
- [ ] 未充分腐熟的堆肥未直接接触可食部位

## 十一、最常见的坑

**坑一：一股脑全倒厨余。**
错误做法：把一桶厨余全倒进箱里。正确做法：厨余必须**沥油去盐、切碎到 1-2 cm**，并与干料按碳氮比配比。带油带盐的厨余招虫招鼠，还会酸腐。

**坑二：把樟脑丸一起扔进去。**
错误做法：看到包装袋上有防虫片就一起堆。正确做法：**樟脑丸对蚯蚓是强毒物，一颗就可能毁掉整箱**。含樟脑丸、杀虫剂包装的物品必须单独丢弃。

**坑三：水加得越多越好。**
错误做法：为了"湿润"天天浇水。正确做法：**手握成团、松开即散**。水太多堵塞蚯蚓体表气孔导致窒息，这是蚯蚓死亡的头号原因。

**坑四：温度上不去还在加干料。**
错误做法：堆温一直 20℃，以为是"时间不够"，继续加落叶。正确做法：温度上不去通常是**碳氮比过高或水分不足**，应加少量湿料并翻松通气。继续加干料只会更慢。

**坑五：高温期看不到蚯蚓就以为死了。**
错误做法：第二天看不到蚯蚓就翻箱找。正确做法：**堆温超过 40℃ 后蚯蚓会主动下沉或转移到边缘**，表面看不到是正常现象。翻动反而干扰产热与菌群。

**坑六：氨味了就喷水。**
错误做法：氨味刺鼻，浇水"压一压"。正确做法：氨味查氮过剩与缺氧，**加干料 + 翻松通气**，绝不喷水。喷水会让缺氧更严重、氨味更重。

**坑七：酸味了就加石灰中和。**
错误做法：发酸了撒点石灰调 pH。正确做法：酸味查水分过高与缺氧，**加干料并充分翻松**，不喷水、不加石灰。石灰改变 pH 且不利蚯蚓。

**坑八：看着像黑了就用。**
错误做法：颜色变深就当腐熟，直接用来种菜。正确做法：**气味、颜色、质地、温度四项全部通过才算腐熟**，并且停用后还要静置熟化 2-4 周。**未充分腐熟的堆肥不得直接接触可食部位。**

**坑九：在阳台做堆肥。**
错误做法：怕麻烦，在阳台找个箱子发酵。正确做法：**家庭堆肥在室外进行**。发酵产热与气味会影响居住环境，密闭阳台还可能招虫。**在阳台堆肥是应当避免的做法。**

## 十二、边界与免责

- 本技能提供蚯蚓堆肥的碳氮比配比、含水率与堆温判断、腐熟度判定与氨味发酸处置口径，**不替代环卫与农业废弃物管理要求**

- **不向堆肥中添加任何杀虫剂、消毒剂、除臭剂或氨水**
- 原料碳氮比为通用参考值，实际值随批次变化；**精确配比与卫生指标检测须以专业检测结论为准**
