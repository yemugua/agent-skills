# 碳氮比、含水率与腐熟度判据

> 禁入物料与不得添加药剂的口径见本文末尾。原料碳氮比为通用参考值，实际值随批次变化。

## 一、目标碳氮比

| 阶段 | 目标碳氮比 | 说明 |
|---|---|---|
| 起始发酵期 | 25:1 - 30:1 | 常用起点 |
| 蚯蚓繁殖期 | 20:1 - 25:1 | 碳略降、氮略升 |
| 腐熟期 | 15:1 - 20:1 | 以氮为主，促分解 |

**碳氮比的意义**：碳过剩（干料太多）分解慢、温度上不去；氮过剩（湿料太多）氨挥发、pH 上升、烧死蚯蚓。

## 二、常见原料碳氮比参考

| 原料 | 碳氮比 | 类别 | 处理要求 |
|---|---|---|---|
| 落叶、干树叶 | 40-80 | 高碳（干料） | 剪碎至 3-5 cm |
| 干草、秸秆 | 60-100 | 高碳（干料） | 剪碎至 3-5 cm |
| 纸板、牛皮纸 | 60-100 | 高碳（干料） | 撕碎泡软，去掉印刷与胶粘部分 |
| 咖啡渣 | 15-20 | 偏氮 | 滤纸去掉，含水率高需晾 |
| 茶叶渣 | 15-25 | 偏氮 | 滤纸去掉 |
| 水果皮（苹果、梨） | 25-40 | 中性偏碳 | 切碎、沥水 |
| 瓜皮（西瓜、甜瓜） | 20-30 | 中性 | 切碎、沥水 |
| 蔬菜叶、菜帮 | 15-25 | 偏氮 | 切碎 |
| 剩米饭、馒头 | 20-30 | 中性偏氮 | 彻底沥干或晒干 |
| 豆渣 | 10-15 | 高氮 | 需与干料配比使用 |
| 新鲜草坪草 | 15-25 | 偏氮 | 剪短、切碎 |
| 纸箱瓦楞纸 | 60-90 | 高碳 | 撕碎泡软 |

## 三、配比算法

```
干料份数 = (湿料份数 × 湿料碳氮比) / 目标碳氮比
```

例：目标 25:1，湿料 2 份（碳氮比 20），则干料 = (2 × 20) / 25 = 1.6 份。

**湿料必须先沥水**：含水率高于目标区间时先晾晒或沥干，否则称出的重量里大部分是水，配比全错。

## 四、含水率手感判定法

| 手感 | 判定 | 处置 |
|---|---|---|
| 手握能成团，松手即散开 | 合适 | 维持 |
| 手握成团，松手成团不散、柔软可捏出少量水 | 偏湿 | 加干料并翻松、增加通气孔 |
| 手握不出水但料松散、一捏即碎 | 偏干 | 分次少量加水，边加边拌 |
| 手握出水、料滴水 | 过湿 | 加干料比例较大，充分翻松；必要时重新配料 |

**目标区间**：经验区间约 50%-60%（手握成团、松开即散）。

**为什么这么严**：蚯蚓靠体表呼吸，水太多堵塞体表气孔导致窒息，水太少体表失水死亡。

**浇水方式**：少量多次、喷洒在料面后翻拌均匀，不要一次性大量浇在蚯蚓密集处。

## 五、三阶段温度曲线

| 阶段 | 时间（起始后） | 堆体温度 | 关键动作 |
|---|---|---|---|
| 升温期 | 0-3 天 | 20℃ → 40-50℃ | 不干预，记录温度 |
| 高温期 | 3-15 天 | 45-65℃ | 蚯蚓已下沉或钻入底层，属正常 |
| 降温期 | 15-30 天 | 40℃ → 30℃ | 可转箱一次 |
| 腐熟期 | 30-60 天 | 25-30℃ | 补料、判腐熟 |

**高温期正常现象**：堆体中心超过 40℃ 后蚯蚓主动下沉或转移到箱底与边缘，表面看不到不是"跑光了"。不要因为表面看不到蚯蚓就翻动或加水。

**温度异常处置**：

| 现象 | 可能原因 | 处置 |
|---|---|---|
| 温度上不去，一直 20℃ 左右 | 碳氮比过高或水分不足 | 加少量湿料，翻松通气 |
| 温度超过 70℃ 且持续 | 碳氮比过低或堆体过厚 | 加干料、摊薄、增加通风 |
| 温度正常但氨味刺鼻 | 氮过剩、pH 上升、通气不足 | 见下节处置顺序 |

**测温口径**：长杆温度计插入堆体中心，避开边缘与表面；同一位置每日同一时间测。

## 六、蚯蚓状态判断

| 状态 | 判据 | 说明 |
|---|---|---|
| 活跃 | 钻动明显、体表湿润有光泽、蚓粪多 | 状态良好 |
| 受阻 | 活动变慢、集中在料面 | 水分偏干或温度偏低 |
| 下沉 | 高温期钻入底层或箱底 | 正常现象 |
| 逃逸 | 从箱缝或表面大量爬出 | 强光刺激、缺水、氨味过重或 pH 异常 |
| 减少 | 连续观察数量明显下降 | 逐项排查温度、水分、pH、气味与物料 |
| 死亡 | 见蜷缩、发黑、腐烂 | 逐项排查 |

**计数口径**：固定时间、固定位置观察并记录条数（如每周一次，箱角 10 cm × 10 cm 范围内）。

## 七、氨味处置（氮过剩 + 缺氧）

| 环节 | 内容 |
|---|---|
| 成因 1 | 碳氮比过低，湿料（豆渣、剩饭、咖啡渣）比例过大 |
| 成因 2 | 堆体过厚、压实过紧，内部缺氧 |
| 成因 3 | 通气孔堵塞或箱体密闭，氨气排不出去 |
| 处置 1 | 立即加干料（剪碎的落叶、秸秆、纸板） |
| 处置 2 | 翻松堆体、增加通气孔 |
| 处置 3 | 降低堆体厚度、摊开扩大表面积 |
| 处置 4 | 移出上部料层，检查底层是否已糊化 |
| 禁止 | 不喷水、不加氨水、不加消毒剂、不喷除臭剂 |

## 八、发酸处置（水分过高 + 缺氧）

| 环节 | 内容 |
|---|---|
| 成因 1 | 水分过高，堆体压实，氧气不足后进入厌氧发酵 |
| 成因 2 | 含水率高的厨余比例过大且未沥干 |
| 成因 3 | 翻堆频率太低，长期不扰动 |
| 处置 1 | 加干料并充分翻松，让空气进入堆体内部 |
| 处置 2 | 减少后续湿料投放，特别是高含水厨余 |
| 处置 3 | 检查排水孔是否堵塞，必要时底部加透气层 |
| 处置 4 | 严重发酸且已渗液的料整批取出重新配料 |
| 禁止 | 不喷水、不加石灰中和 |

**判断口诀**：氨味查氮和氧，酸味查水和氧。

## 九、腐熟度四项判据

| 判据 | 腐熟特征 | 未熟特征 |
|---|---|---|
| 气味 | 无氨味、无酸味、无酒味；淡泥土味或腐殖质气味 | 刺鼻氨味、酸腐味或酒味 |
| 颜色 | 均匀褐色或深褐色 | 仍能看到明显的浅色原料碎片 |
| 质地 | 松软、有腐殖质感、捏之即散 | 黏、结块、有生硬原料感 |
| 温度 | 与环境温度接近（25-30℃） | 仍明显高于环境温度 |

**四项全部通过才算腐熟。**

**辅助判据**：蚯蚓数量明显减少甚至消失（不是判断腐熟的标准，只是伴随现象）；原料形态基本消失；体积明显缩小。

**停用后熟化**：达到腐熟判据后静置 2-4 周再使用。

**用于可食作物**：家庭堆肥卫生指标无法在家确认，建议先用于盆栽花卉与观叶植物；用于可食作物时遵循当地对有机肥料的管理要求。未充分腐熟的堆肥不得直接接触可食部位。

## 十、禁入物料

| 物料 | 原因 |
|---|---|
| 医疗废物（绷带、棉签、针具、药品包装） | 病原风险 |
| 宠物粪便 | 可能带寄生虫与病原 |
| 腐败肉类 | 病原与招虫 |
| **含樟脑丸与杀虫剂包装的物品** | **樟脑丸对蚯蚓是强毒物，一颗就可能毁掉整箱** |
| 含重金属土壤、工业污泥 | 重金属富集 |
| 建筑垃圾 | 非有机物 |

## 十一、不得添加的药剂

| 药剂 | 原因 |
|---|---|
| 杀虫剂 | 毒死蚯蚓 |
| 消毒剂 | 杀死堆体微生物，终止分解 |
| 除臭剂 | 干扰菌群 |
| 氨水 | 瞬间提高 pH 与氮浓度 |
| 石灰 | 改变 pH 且不利蚯蚓（尤其在发酸时） |

## 十二、安全与卫生

| 项目 | 口径 |
|---|---|
| 场地 | 家庭堆肥在室外进行；不在阳台或封闭空间发酵 |
| 距离 | 避开餐饮与饮水区 |
| 洗手 | 接触原料与成品后必须洗手 |
| 容器 | 不使用盛过清洁剂或消毒液的容器 |
| 分开存放 | 堆肥原料容器与食品、餐具分开 |
| 儿童与宠物 | 成品可能含未灭活的虫卵与生物性物质；成品不用于直接入口 |
