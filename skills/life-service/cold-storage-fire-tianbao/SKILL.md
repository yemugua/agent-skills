# 冷库与冷链消防（cold-storage-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《冷库设计规范》GB 50072 与冷库安全要求，生成冷库消防清单：保温材料燃烧性能、防火分隔与穿堂、制冷机房与氨泄漏防护、电气与融霜防火、疏散与低温作业防护。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 冷库消防
- 冷库防火
- 冷链仓储消防
- 冷库保温材料
- 氨制冷消防

## 三、工作流
1. 核查保温材料燃烧性能
2. 落实防火分隔与穿堂要求
3. 检查制冷机房与泄漏防护
4. 管控电气与融霜防火
5. 明确疏散与低温作业防护

## 四、核心内容（检查清单与判定）
GB 50072 对冷库保温材料与防火分隔提出要求；氨制冷机房须防泄漏并配探测报警，低温环境电气与融霜作业须防火防爆。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含保温材料燃烧性能 | 保温材料 |
| Q2 | FAIL | 未含防火分隔与穿堂要求 | 分隔 |
| Q3 | WARN | 未含制冷机房与泄漏防护 | 机房 |
| Q4 | FAIL | 未含电气与融霜防火 | 电气 |
| Q5 | WARN | 未含疏散与低温作业防护 | 疏散 |

> 脚本 `cold-storage-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python cold-storage-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python cold-storage-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

- 重大隐患/高风险判定需由具备资质人员签字确认。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
