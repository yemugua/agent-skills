# 月龄readiness信号、添加顺序与食物质地

> 本文是口径参考，不替代儿科医生或临床营养师的个体化建议。月龄界限随指南版本更新而调整，**以最新版儿科相关指南与孩子的儿科医生的判断为准**。所有反应怀疑严重时要先排这篇最后的红线清单。

## 一、Readiness 五项信号（齐备才谈添加）

| 信号 | 具体表现 |
|---|---|
| 坐位稳定 | 能在婴儿椅里或在少量支撑下坐稳，头不后仰、身体不塌 |
| 头部控制稳定 | 头部能自主保持中线，不会被自己的动作带得乱晃 |
| 挺舌反射消失 | 勺子碰到嘴唇时不再用舌头顶出，能闭唇、用舌头把食物送到咽部咽下 |
| 手口协调 | 会伸手抓感兴趣的东西并送进嘴里 |
| 进食兴趣 | 看到大人吃饭会盯着看、伸手够、张嘴或身体前倾 |

**年龄口径**：通常在**满 6 月龄左右**出现上述信号并开始尝试。**过早（不足 4 月龄）添加**没有益处且增加负担；**过晚（明显超过 7-8 月龄）**会让铁储备消耗、错过口腔运动学习窗口。**早产儿按矫正月龄计算：矫正月龄 = 出生后月龄 −（40 周 − 出生胎龄周）÷ 4.3。**

## 二、引入原则（一次一种、小量起步、留观察窗）

1. **一次只引入一种新食物**，同种食物连续尝试后观察 **2-3 天**（也常用 3-5 天口径），期间不加入其他新食物。
2. **安排在上午或中午**，便于当天剩余时间观察；不要睡前或夜里试新食物。
3. **起始量**：从 1-2 勺（约几克到十几克）开始，孩子接受后逐步增加，**具体摄入量以孩子的食欲信号和儿保医生建议为准，不与别人家孩子比**。
4. **高铁优先**：首批重视含铁丰富的食物，如铁强化婴儿米粉类、肉泥、禽肉泥、肝泥（频率与量由医生/营养师指导）、后续逐步加入红肉、深绿色蔬菜泥。
5. **顺序不是军规**：现行口径不强调按「米粉→菜→果→肉」的固定先后，强调**质地由稀到稠、由细到粗、尽早保证铁的摄入**。
6. **不要替代奶**：1 岁前奶仍是主要营养来源，辅食是逐步叠加的，不以辅食量压奶量。
7. **不强迫、看信号喂食**：孩子扭头、闭嘴、用手推开即为停止信号；由大人决定喂什么和什么时候喂，由孩子决定吃不吃和吃多少，同一食物允许多次、多种做法后再尝试。

## 三、质地进阶（按月龄区间，个体差异大）

| 月龄区间 | 质地 | 频次参考 | 说明 |
|---|---|---|---|
| 6-8 月龄 | 稀泥糊 → 稠泥糊，可有小软颗粒 | 每日 1-2 次正餐尝试 | 以铁强化泥糊为基础，逐步引入菜泥、果泥、肉泥 |
| 8-10 月龄 | 细末状、软烂小块（能用牙龈压碎） | 每日 2-3 次 + 少量加餐 | 开始提供手指食物，练习自主抓握送入口 |
| 10-12 月龄 | 碎块状、条状、片状软食 | 每日 3 次 + 1-2 次加餐 | 鼓励自主进食，允许弄脏，餐具由大人掌握节奏 |
| 12-24 月龄 | 接近家庭餐的小块，少盐少油版本 | 每日 3 餐 + 2 次加餐 | 家庭成员同桌吃饭是最好的示范 |

**指夹食物的安全形状**：条状（成人小指粗细）、片状（能被牙龈压碎）、半球形（大于宝宝拳头，防止整吞）。

## 四、1 岁内明确禁忌

| 项目 | 口径 |
|---|---|
| 盐与含钠调味品 | 1 岁内不额外加盐，避免酱油、味精、鸡精、豆瓣酱、咸菜、加工肉制品中的隐形钠 |
| 添加糖 | 1 岁内不加糖，避免含糖饮料、甜点、炼乳；不要为了让孩子吃饭而加糖 |
| 蜂蜜 | **1 岁内禁食蜂蜜及含蜂蜜的食品**（婴儿肉毒中毒风险，食蜂蜜制品同理） |
| 普通牛奶替代母乳/配方奶 | 1 岁前不用普通牛奶作为主要饮品替代；少量用于辅食制作的口径以医生意见为准 |
| 米汤、蔬菜水、果汁替代奶/水 | 营养价值低、占胃容量，1 岁内不推荐果汁；不以这些替代奶或正常饮水 |
| 酒精、含咖啡因饮品、浓茶 | 任何年龄段儿童都不应摄入 |
| 补品、中药材、保健类饮品 | 不自行给婴幼儿服用 |

## 五、高窒息风险食物处理（5 岁以下都适用）

| 食物 | 正确处理 |
|---|---|
| 整颗坚果、花生、瓜子 | 磨成粉或做成坚果酱薄涂，5 岁前不给整粒 |
| 葡萄、小番茄、龙眼、樱桃 | 纵向切成四分之一或更碎；龙眼去核去整颗 |
| 爆米花、硬糖、软糖、果冻块 | 5 岁前不给；果冻类一律不推荐给幼儿 |
| 大块肉、带骨带刺、带筋的肉段 | 去骨去刺去筋，顺纹撕成细丝或切碎 |
| 生胡萝卜、生苹果硬块 | 蒸煮软化后切成条或薄片，不直接给生硬块 |
| 糯米类、大团状食物（汤圆、年糕、糍粑） | 幼儿不推荐 |

**喂食姿势**：必须坐直（头略前倾），不在哭闹、大笑、奔跑、乘车颠簸、躺卧位时喂食，全程有成人在旁，成人掌握节奏，孩子自己决定吃不吃。

## 六、过敏/不良反应观察口径

| 反应类型 | 常见表现 | 处理 |
|---|---|---|
| 局部接触性红 | 口周接触食物后发红，洗掉后消退 | 多为刺激而非过敏，记录并复观察；反复或扩散要咨询医生 |
| 轻度皮肤反应 | 少量散在红疹、轻微口周肿 | 停该食物、记录时间戳、**联系儿科医生评估后再决定是否再引入** |
| 消化道反应 | 呕吐（尤其喷射性）、腹泻、腹痛哭闹、便血 | 停食并就医 |
| 呼吸道/全身反应 | 喘息、声嘶、喉头发紧感、眼睑口唇面部肿胀、全身荨麻疹、面色苍白肢冷、意识改变 | **停食、立即急救**，详见红线清单 |

**观察窗口**：重点在进食后 **2 小时内**；迟发型反应可见于 **24-48 小时**（甚至更晚），这段时间仍要保持记录。

**不要自行给孩子贴「过敏」标签并长期禁食。** 正确做法是：停食、记录时间点与表现、联系儿科医生或过敏专科医生判断是否需要检测与管理方案。
