# 引入记录与过敏观察表

> 用途：把「吃过什么、什么时候、什么反应」变成可复查的记录，就诊时直接给医生。**本表不构成诊断，也不能用来判断是否可以自行再次尝试已致敏食物。**

## 一、每日食物日记（每引入一种新食物填一行）

| 日期 | 食物名称 | 首次/第几次 | 性状（泥糊/末/碎/条） | 大约摄入量（勺或克） | 同餐其他食物 | 进食起止时间 | 是否大人喂食/自主进食 | 备注 |
|---|---|---|---|---|---|---|---|---|
|  |  | 首次 |  |  |  |  |  |  |
|  |  | 第 2 次 |  |  |  |  |  |  |
|  |  | 第 3 次 |  |  |  |  |  |  |

**填写要点**

- 保留食物**包装与配料表**，就诊时带上；记录加工方式（蒸、煮、炒）与是否加了调味。
- 症状出现的**时间点**比严重程度更重要：记录「进食结束 → 出现症状」的间隔分钟数。
- 同一行不要混填多种新食物，否则无法归因。
- 如果当日接种疫苗、生病、换了新环境，在备注栏注明（可能干扰判断）。

## 二、不良反应记录（出现任何一种都填）

| 日期时间 | 可疑食物 | 皮肤：口周红/散在疹/荨麻疹/肿胀 | 消化道：吐/泻/腹痛/便血 | 呼吸道：咳/喘/声嘶 | 全身：面色/精神/肢冷 | 距进食间隔 | 处理（停食/清洗/就医） | 转归 |
|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |

## 三、观察窗口

- **重点窗口：进食后 2 小时内**，这段时间不要让孩子离开成人视线入睡或独处。
- **迟发反应：可延至 24-48 小时**，这段时间的皮疹、腹泻、嗜睡也要记录。
- 出现疑似反应即**停掉该食物**，直到医生评估结论明确为止，不要自行再次挑战。

> 这一栏**只填经医生确认的**，不要因为一次嘴角红或一次拒吃就自行列入长期回避。

## 六、每次儿保/随访携带清单

- [ ] 近两周食物日记与此次可疑反应的完整记录
- [ ] 可疑食物的包装与配料表（或拍照）
- [ ] 症状照片（带时间水印更佳）与短视频（咳嗽、喘息、异常动作）
- [ ] 生长曲线记录（体重、身长、头围）
- [ ] 目前的回避清单与开始回避的日期
- [ ] 想问医生的问题清单（先写好，避免临场遗漏）
