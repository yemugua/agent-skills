# 婴儿辅食添加顺序与过敏观察

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 按月龄说明 readiness 信号、引入顺序与质地进阶 | 诊断食物过敏、判读化验单、替代过敏原检测 |
| 给「一次引入一种食物、间隔观察」的记录口径 | **给任何药物的名称、剂量与服用方案（含抗过敏药、肾上腺素笔用法）** |
| 列出过敏急性反应的识别与就医/急救红线 | 判断某次皮疹到底是不是过敏，或建议自行判断后继续喂 |
| 给出添加顺序、禁忌食物与防窒息处理口径 | 建议用米汤、果汁、蔬菜水替代奶或辅食 |
| 输出引入计划表与食物日记 | 承诺某种添加顺序能保证孩子不过敏 |

**就医红线（出现任一条，立即停止喂食该食物并就医；标注急诊的立即打急救电话）**

- **呼吸困难、喘息、声音嘶哑或犬吠样咳嗽、喉咙发紧、流口水不能吞咽** —— 急诊
- **口唇/眼睑/面部肿胀、全身荨麻疹、皮肤潮红伴烦躁或萎靡** —— 急诊
- **面色苍白或发灰发绀、四肢冰凉、脉搏快而弱、意识改变、叫不应、瘫软** —— 急诊（过敏性休克征象，不要先喂水或观察）
- **呛咳后无法哭出声、无法咳嗽、发不出声音、口唇发绀、双手抓喉咙** —— 立即气道异物急救并呼叫急救电话
- 进食后反复喷射性呕吐、呕血、大便带血或呈黑色柏油样
- 腹泻伴明显尿量减少、口唇干、眼窝或囟门凹陷、精神差（脱水征象）
- 体重不增或下降、生长曲线跨两条主要百分位线向下
- 拒食持续、进食时哭闹弓背（需排查反流、食管炎等，由医生判断）
- 误吸后新出现持续咳嗽、喘息、发热（警惕吸入性肺炎）
- 添加辅食后出现明显湿疹加重伴睡眠与进食受影响 —— 由儿科医生评估是否需要过敏原检测，**不要自行长期盲目禁食**
- 1 岁以下食用蜂蜜后出现嗜睡、吸吮无力、哭声弱、便秘（警惕婴儿肉毒中毒）—— 急诊
- 早产、低出生体重、有严重湿疹、既往严重过敏反应、有基础疾病或喂养困难的婴儿 —— 引入时机与种类**必须**由儿科医生或临床营养师评估

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「几个月开始加辅食」「第一口吃什么」 | 用 |
| 「新食物一次加一种，要隔几天」 | 用 |
| 「吃了新食物嘴周红了是不是过敏」 | 用，先作区分并提示红线 |
| 「过敏了多久能再吃」 | 只说停食并转儿科/过敏专科评估，不自行再次尝试致敏食物 |
| 「1岁能吃盐吗」「蜂蜜几个月能吃」 | 用，明确给出年龄界限 |
| 「坚果、葡萄会不会噎到」 | 用，给出防窒息处理口径 |
| 「孩子大便变稀、发绿是不是辅食问题」 | 只作观察口径，持续或加重就医 |
| 「要不要先吃蛋黄」「迟点加鸡蛋能防过敏」 | 用，说明现行引入口径并注明以儿科医嘱为准 |
| 「缺铁吃什么、铁剂吃多少」 | 铁剂剂量不用，由医生按体重与化验结果决定 |

## 三、完整工作流

1. **先看 readiness，不看日历**：核对五项信号是否齐备（能独坐或在支撑下坐稳、头部控制稳定、挺舌反射消失能用勺咽、会伸手抓物送入口、看到大人吃饭表现出兴趣并张嘴），同时确认满 6 月龄左右。**早产儿按矫正月龄计算，具体时机以儿科医生评估为准。**
2. **排除就医红线**：先看是否命中红线清单，命中任何一条即停止添加、保留食物包装并记录，转就医或急救，**不给下一种食物的引入建议**。
3. **确认的高铁优先原则**：首批引入含铁丰富的泥糊状食物（铁强化婴儿米粉类、肉泥、肝泥等），具体搭配与配比由儿科医生或临床营养师确定。
4. **排引入顺序与间隔**：按 `rules/月龄添加顺序与食物质地.md` 排新食物清单，每次引入一种，同一种新食物先少量尝试，期间观察 2-3 天（也常用 3-5 天口径），期间不加其他新食物。
5. **安排观察窗口与时间**：安排在上午或中午喂养，便于当日观察；重点观察窗口是喂食后 2 小时内，迟发反应可延至 24-48 小时。
6. **记食物日记**：按 `templates/引入记录与过敏观察表.md` 记录食物名称、首餐日期、性状、摄入反应（口周红/呕吐/腹泻/皮疹/呼吸）、症状起止时间、是否就医。
7. **推进质地进阶**：6-8 月龄泥糊为主，8-10 月龄过渡到细末/指夹软烂小块，10-12 月龄碎块状并鼓励自主进食，1 岁后过渡接近家庭餐的小块状 —— 每个孩子节奏不同，不强行跳过。
8. **排窒息风险物品**：5 岁以下不给整颗坚果、整颗葡萄、爆米花、硬糖、果冻块等；所有高险食物必须加工成安全形状，进食时必须坐直、有大人在旁看护。

## 四、核心规则与要件库

生成引入计划或观察建议前，**必须先读**：

- `rules/月龄添加顺序与食物质地.md`：readiness 信号清单、按月的引入顺序、每餐频次、质地进阶口径、1 岁内明确禁忌、高窒息风险食物处理。
- `templates/引入记录与过敏观察表.md`：每日食物日记模板、过敏反应分级记录栏与随访要点。

不得出现任何药物名称、剂量与服用方案。不得建议用奶瓶兜米粉、不得建议米汤或果汁替代奶、不得承诺某种顺序能让孩子不过敏、不得因为一次拒吃就判定为过敏。

## 五、脚本用法

```
python scripts/infant_food_plan.py --file case.json
python scripts/infant_food_plan.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`birth_date` 出生日期、`gestational_weeks` 胎龄周（早产折算用）、`today` 当前日期、`correction_by_doctor` 是否由医生确认、`readiness` 五项信号布尔、`tried` 已尝试食物列表（含 `name`/`date`/`reaction`）、`allergy` 已明确过敏食物、`interval_days` 引入间隔天 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--json` | 以 JSON 输出 |
| `--selftest` | 运行自检 |

脚本输出：矫正月龄、readiness 判定、质地阶段、每日餐次、下一个可引入新食物的最早日期、月龄禁忌提醒、高窒息风险提醒。**命中早产、禁忌信号不足或明确过敏的情况，脚本只输出「以儿科医生评估为准」的结论，不输出推进计划。**

## 六、人工确认清单

- [ ] 已核对是否为早产并按矫正月龄折算，时机经儿科医生确认
- [ ] readiness 五项信号逐条核对，未强行提前添加
- [ ] 每次只引入一种新食物，观察间隔不少于 2-3 天
- [ ] 安排在上午或中午喂养，便于当日观察
- [ ] 喂食后 2 小时内有人在旁，知道迟发反应可到 24-48 小时
- [ ] 明确 1 岁内不加盐、不加糖、不吃蜂蜜、不用普通牛奶替代母乳或配方奶
- [ ] 高危窒息食物已加工处理，进食时坐直且有成人看护
- [ ] 食物日记已记录首餐日期与反应，保留包装与成分表
- [ ] 生长曲线由儿童保健定期测量，不自行判断「长得慢」
- [ ] 知道什么情况要停食并立即就医，家人与带养人口径一致

## 七、最常见的坑

1. **辅食越晚越好**：过了 6-7 月龄还不引入，容易错过口腔运动学习窗口，铁储备也会逐渐消耗，反而增加缺铁风险，引入时机以 readiness 和医生评估为准。
2. **为了防过敏长期回避鸡蛋、鱼、花生等**：是否需要回避、回避多久、如何再引入由儿科医生或过敏专科医生判断，自行长期禁食会造成营养缺口并增加后续焦虑。
3. **一次混好几种新食物一起给**：出现反应时无法归因，只能全部停掉。
4. **用米汤、果汁、蔬菜水代替**：热量与营养密度低，占胃容量又影响奶量，1 岁内不推荐果汁。
5. **1 岁内加盐加糖**：肾脏负担与口味偏好问题，且家长常低估成品辅食里的隐形钠。
6. **整颗坚果、整颗葡萄、果冻块直接喂**：这是婴幼儿窒息的常见原因，必须磨粉、切碎、去核对半切或四分切，且进食时不能边走边吃、不能躺着吃。
7. **在孩子哭闹、逗笑或被追喂时喂食**：哭闹时吸气状态下喂食容易误吸。
8. **一拒吃就认定「不喜欢/过敏」**：同一食物可能需要多次、不同做法尝试，真正的过敏反应不等同于拒吃或嘴角红。
9. **把奶量压到很低**：1 岁前奶仍是主要营养来源，辅食过量替代奶会影响能量与钙摄入。
10. **用奶瓶兜米粉**：不利于学习吞咽和口腔运动，也容易导致过喂。
11. **大人嚼碎喂食**：不卫生，还可能传播致龋菌与幽门螺杆菌。

## 八、边界与免责

本技能提供辅食引入的顺序、质地进阶与观察记录口径，**不提供任何药物名称、剂量与治疗方案，不构成过敏的诊断依据**。月龄界限、引入顺序与禁忌会因指南版本更新、孩子早产情况、基础疾病与家族过敏史而调整，**以最新版儿科营养与过敏相关指南、以及孩子的儿科医生的判断为准**。任何疑似过敏急性反应、呼吸困难、意识改变、严重呕吐腹泻、生长迟缓或误吸后症状，请立即停食并就医或呼叫急救电话。本技能不替代诊疗。
