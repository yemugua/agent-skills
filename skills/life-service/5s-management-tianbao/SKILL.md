# 5S 现场管理推行（5s-management）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：生成5S（整理/整顿/清扫/清洁/素养）现场管理推行方案与检查表：区域责任、红牌作战、目视化、评分与持续改善。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 5S
- 现场管理
- 整理整顿
- 车间5S
- 目视化
- 定置

## 三、工作流
1. 成立推行组织与责任区
2. 整理（要与不要）红牌作战
3. 整顿定置与标识
4. 清扫清洁标准
5. 素养养成与定期评分

## 四、核心内容（检查清单与判定）
5S源自精益：整理(SEIRI)区分要与不要、整顿(SEITON)定置标识、清扫(SEISO)清除脏污、清洁(SEIKETSU)标准化、素养(SHITSUKE)习惯。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未划责任区/推行组织 | 推行 |
| Q2 | WARN | 缺整理红牌/要与不要标准 | 整理 |
| Q3 | FAIL | 整顿未含定置与标识 | 整顿 |
| Q4 | WARN | 清扫清洁无标准/频次 | 清扫 |
| Q5 | FAIL | 未含评分与持续改善 | 素养 |

> 脚本 `5s-management_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python 5s-management_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python 5s-management_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
