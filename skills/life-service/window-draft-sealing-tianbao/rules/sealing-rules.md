# 窗户漏风封堵规则

生成方案前先读此表。

## 一、漏点定位

| 方法 | 操作 |
|---|---|
| 纸条法 | 点燃纸片 / 薄纸条靠近窗缝，被吸偏即漏风 |
| 手背法 | 手背沿框四周缓慢移动，凉处即漏点 |
| 强光法 | 白天关灯用手电照外侧，内侧见光即缝 |

必须四周（上、下、左、右、合页侧、锁侧）全部探到，漏点逐一标记。

## 二、材料选型（缝型 → 材料）

| 缝型 | 材料 | 注意 |
|---|---|---|
| 平面均匀缝（平开窗压合处） | D 型 / E 型背胶胶条 | 选与缝宽匹配的型号 |
| 推拉轨道缝 | 硅胶条 / 毛条 | 毛条用于滑动接触面，否则卡窗 |
| 宽缝 / 固定缝 | 中性硅酮密封胶 | 选中性，不腐蚀铝材 |
| 锁点松动 | 防风块 / 调节铰链 | 先调再封 |

## 三、施工顺序（强制）

| 序 | 步骤 | 不合格原因 |
|---|---|---|
| 1 | 检查缝隙 | 漏点未标全，后续遗漏 |
| 2 | 清洁基面 | 有油灰，胶条 3 天脱落 |
| 3 | 选材料 | 推拉缝用胶条会卡死 |
| 4 | 粘贴 / 打胶 | 未压实起泡留缝 |
| 5 | 按压固定 | 胶条起皱，风仍进 |
| 6 | 通风固化 | 未固化关窗会粘脱 |

> 不合格须带原因：「北窗上缝未处理：手测明显进风，需补贴」。

## 四、安全

高层外侧作业系安全带或请专业人员；密封胶通风处使用，避免密闭吸入。
