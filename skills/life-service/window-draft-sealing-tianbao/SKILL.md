# 窗户漏风

## 1. 硬边界（能做什么 / 不能做什么）

| 能做 | 不能做（转专业人士） |
|---|---|
| 窗缝贴密封条、打密封胶 | 更换整窗、动窗框结构 |
| 调窗扇铰链、加防风块 | 窗框变形严重、漏雨进水的结构性维修 |
| 清洁基面、粘贴毛条 | 双层中空玻璃漏气（需换玻璃） |

出现窗框明显变形、玻璃与框脱胶、整窗下沉关不上，转门窗师傅。

## 2. 什么时候用

| 用户说法 | 用不用 |
|---|---|
| 窗缝用手能感到进风 | 用（贴密封条/打胶） |
| 推拉窗两扇之间有缝 | 用（加毛条或防风块） |
| 窗边冬天冰凉结露 | 用（先封缝再考虑保温） |
| 玻璃中间起雾 | 不用（中空层漏气，换玻璃） |
| 整窗关不严、框变形 | 不用（转师傅） |

## 3. 完整工作流

1. 用点燃的纸条 / 手背沿窗框四周探风，标出所有漏点。
2. 清洁漏点基面：用酒精棉去油去灰，晾干。
3. 按缝型选材料：平面缝用 D 型 / E 型胶条，推拉轨道用毛条，宽缝用中性硅酮密封胶。
4. 撕背胶、对准粘贴，边贴边用滚轮 / 拇指压实，避免起皱气泡。
5. 宽缝打胶：打胶枪匀速走线，手指蘸肥皂水抹平。
6. 开窗通风 24 小时让胶固化，期间别碰。

详细选型与施工口径见 `rules/sealing-rules.md`。

## 4. 核心规则 / 要件说明

生成封堵方案前**先读 `rules/sealing-rules.md`**：材料选型表、基面处理要求、固化时间都有强制口径。不合格项带原因，如「北窗未处理：该缝手测明显进风，需补贴胶条」。

## 5. 脚本用法

`scripts/seal_check.py` 自检「封窗操作清单」顺序与完整性：

```
python scripts/seal_check.py --file steps.json
python scripts/seal_check.py --selftest
```

## 6. 人工确认清单

- [ ] 已标出全部漏点
- [ ] 基面已去油去灰并晾干
- [ ] 材料与缝型匹配
- [ ] 胶条压实无气泡
- [ ] 打胶后通风固化 ≥24h

## 7. 最常见的坑

1. 只贴一眼看到的缝：窗扇上方、合页侧常被漏，要四周探一遍。
2. 基面有灰就贴：三天就脱，必须酒精擦净晾干。
3. 推拉窗用错材料：轨道该用毛条，用胶条会卡住推不动。
4. 胶条起皱留缝：边贴边压实，接缝处重叠切 45 度斜口。
5. 打胶没抹平：胶线凹凸藏灰积水，用肥皂水手指抹平。
6. 没等固化就关窗：胶没干就粘住，撕开重打。

## 8. 边界与免责

覆盖常见塑钢 / 铝合金窗缝漏风的自封堵。结构变形、玻璃漏气、整窗更换不在范围内。高层外侧施工注意安全，必要时请专业人员。
