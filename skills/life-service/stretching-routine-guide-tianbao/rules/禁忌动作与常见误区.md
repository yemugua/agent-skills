# 禁忌动作与常见误区

## 一、禁止的做法

| 做法 | 风险 | 替代 |
|---|---|---|
| 弹震式拉伸（靠惯性一弹一弹） | 触发牵张反射，肌肉对抗性收缩，反而更容易拉伤 | 缓慢到位后保持不动的静态拉伸 |
| 让他人强行加压或扳拉 | 无法感知对方的实际耐受，容易超过组织承受范围 | 自己控制幅度，或由专业人员在沟通下进行 |
| 憋气拉伸 | 升高腹压、降低拉伸效果 | 全程缓慢呼吸 |
| 疼痛下坚持 | 造成微损伤与保护性收缩 | 降到轻微紧绷的强度 |
| 急性损伤期拉伸 | 加重出血与肿胀 | 先按急性期处理原则，不做拉伸 |
| 麻木放射痛部位拉伸 | 可能涉及神经，拉伸会加重 | 停止拉伸并就医评估 |

## 二、急性损伤期（48 小时内）的处理原则

| 项目 | 做法 |
|---|---|
| 是否拉伸 | 不拉伸 |
| 是否热敷 | 不热敷 |
| 是否按摩揉搓 | 不揉搓 |
| 是否继续运动 | 停止该项运动 |
| 活动度 | 在无痛范围内做极轻微的主动活动即可，不做牵拉 |
| 何时就医 | 肿胀明显、不能负重、疼痛剧烈、怀疑撕裂时尽快就医 |

48 小时后是否开始轻量活动，取决于疼痛与肿胀的消退情况，以专业人员的判断为准。

## 三、拉伸后异常反应的处理

| 反应 | 判断 | 处理 |
|---|---|---|
| 轻微酸胀，24 小时内消退 | 正常 | 下次降低一点强度 |
| 疼痛持续超过 24 小时 | 拉过头 | 停做该动作 2-3 天，恢复后降强度 |
| 出现淤青 | 组织损伤 | 停止拉伸并就医评估 |
| 麻木、刺痛向远端串 | 涉及神经 | 立即停止并就医 |

## 四、常见误区

| 误区 | 事实 |
|---|---|
| 越疼越有效 | 疼痛是停止信号，不是有效信号 |
| 运动前必须压腿拉伸 | 运动前该做的是动态热身 |
| 拉伸能替代热身 | 静态拉伸不提高体温，不能替代 |
| 拉伸能替代力量训练 | 拉伸改善活动度，不产生力量与稳定性 |
| 柔韧性越好越好 | 过度活动度会降低关节稳定性，按需就好 |
| 拉一次就有效果 | 活动度的改变需要数周持续，不是一次见效 |
| 只拉最酸的地方 | 只处理局部会掩盖整体活动度不足 |
| 拉伸能矫正体态 | 体态问题多与力量分布有关，拉伸只是配角 |

## 五、需要就医的信号

- 拉伸部位突发剧痛，有「砰」的感觉
- 局部出现凹陷、明显无力、不能发力
- 关节肿胀、交锁、活动明显受限
- 麻木或刺痛向肢体远端放射
- 疼痛在休息时也不缓解，或夜间痛
- 拉伸后出现淤青且范围扩大

## 六、特殊人群的注意

| 人群 | 注意 |
|---|---|
| 青少年 | 生长痛期避免高强度被动拉伸，以动态活动为主 |
| 中老年 | 有关节退变者避免极限幅度，控制在无痛范围 |
| 孕中晚期 | 避免仰卧位长时间拉伸与过度拉伸腹部相关肌群，遵医嘱 |
| 术后恢复期 | 严格按康复方案执行，不要自行加拉伸 |
| 有骨质疏松者 | 避免脊柱大幅度前屈与旋转类拉伸 |
