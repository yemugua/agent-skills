# 拉伸放松

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 给出运动前后拉伸的顺序规则与剂量 | 诊断肌肉拉伤等级、韧带损伤或关节病变 |
| 说明保持时长、组数、强度的判定口径 | 给急性损伤的处理方案、康复计划或用药建议 |
| 整理主要肌群的常规拉伸动作与流程 | 推荐弹震式拉伸、被动强行加压或他人暴力扳拉 |
| 提示拉伸禁忌与需要就医的信号 | 承诺拉伸能治疗疼痛、矫正体态或替代力量训练 |
| 输出顺序核对结果与拉伸流程表 | 说「越疼越有效」这类话 |

**必须停止拉伸并转交专业人士的情况**

- 急性损伤后 48 小时内：红肿热痛明显，此时拉伸会加重损伤
- 拉伸部位有麻木、刺痛、放射痛，或疼痛向肢体远端串
- 关节肿胀、活动明显受限、负重时剧痛
- 拉伸后出现持续超过 24 小时的疼痛，或出现淤青
- 疑似肌肉撕裂：突发剧痛、有「砰」的感觉、局部凹陷或明显无力

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「运动前要不要拉伸，先拉还是后拉」 | 用，明确顺序与类型 |
| 「运动完怎么拉伸，每个动作几秒」 | 用，给剂量 |
| 「静态拉伸和动态拉伸有什么区别」 | 用 |
| 「拉伸要拉到疼才有效吗」 | 用，明确不是 |
| 「弹震式拉伸（一弹一弹）能做吗」 | 用，说明风险 |
| 「跑完腿酸怎么放松」 | 用 |
| 「久坐肩颈僵硬怎么拉伸」 | 用 |
| 「刚拉伤了能不能拉伸」 | 只作停止拉伸与就医提示 |
| 「帮我看看我拉伸动作对不对」 | 不提供视频判读，只给动作要点清单 |

## 三、完整工作流

1. **先确定阶段**：运动前还是运动后，两者的拉伸类型完全不同，用错等于白做甚至有害。
2. **先排禁忌**：过一遍禁忌清单，急性损伤、麻木放射痛、关节肿胀等情况一律不拉伸。
3. **核顺序**：按 `rules/拉伸顺序与剂量规则.md` 核对「动态热身 → 主运动 → 静态拉伸」的相对顺序。**这一步用输入原序核对，不能按正确顺序重新排列后比对，否则顺序错误会被判成正确。**
4. **定剂量**：运动后静态拉伸每个动作保持 15-30 秒，2-3 组；运动前动态热身 5-10 分钟。
5. **定强度**：拉伸感到轻微紧绷或轻微不适即可，按 0-10 分不超过 5-6 分，出现刺痛立即停止。
6. **选肌群**：按当天主运动的发力部位选 4-6 个肌群，不要只拉最酸的那一个。
7. **记录与复评**：记录每个动作的时长与强度评分，两周后看活动度是否改善。

## 四、核心规则与要件库

生成拉伸流程或纠正建议前，**必须先读**：

- `rules/拉伸顺序与剂量规则.md`：前后阶段的类型差异、顺序规则、保持时长与组数、强度判定、主要肌群清单。
- `rules/禁忌动作与常见误区.md`：弹震式拉伸风险、急性损伤与麻木的处理、常见误区与就医信号。

不得建议弹震式拉伸或他人强行加压扳拉。不得把「拉到疼」说成有效，疼痛是停止信号。

## 五、脚本用法

```
python scripts/stretching_routine_check.py --file case.json
python scripts/stretching_routine_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：阶段、用户实际填写的流程顺序、保持秒数、组数、疼痛评分、是否弹震、热身时长、拉伸肌群、是否有急性损伤 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--json` | 以 JSON 输出 |
| `--selftest` | 运行自检 |

脚本按**输入原序**核对流程顺序，输出顺序判定、剂量判定、强度判定、不合格项与原因。**判定顺序是先查真实缺陷（顺序错误、运动前长时间静态拉伸、弹震式、强度过痛、急性损伤期拉伸），再看信息是否完整**，只填了阶段却填了弹震式时，会直接判不合格而不是待确认。

## 六、人工确认清单

- [ ] 阶段已分清：运动前做动态，运动后做静态
- [ ] 顺序已按原填写顺序核对，不是按理想顺序复述
- [ ] 禁忌清单逐条确认，急性损伤与麻木放射痛已排除
- [ ] 运动后每个动作保持 15-30 秒，2-3 组
- [ ] 强度在轻微紧绷范围，0-10 分不超过 5-6 分，无刺痛
- [ ] 未使用弹震式拉伸，未让他人强行加压
- [ ] 覆盖 4-6 个主要肌群，不只拉最酸的一处
- [ ] 拉伸过程中正常呼吸，没有憋气

## 七、最常见的坑

1. **运动前做长时间静态拉伸**：运动前静态拉伸超过 30 秒会暂时降低力量与爆发输出，运动前该做的是动态热身。
2. **顺序反了还自我感觉良好**：先静态拉伸再主运动，等于让肌肉在没预热的状态下直接发力，是最常见的顺序错误。
3. **弹震式拉伸**：靠惯性一弹一弹地拉，容易触发牵张反射导致肌肉对抗性收缩，反而更容易拉伤。
4. **拉到疼才算数**：疼痛是停止信号。出现刺痛说明已经拉过头，第二天会更疼。
5. **憋气拉伸**：憋气会升高腹压、降低拉伸效果，全程保持缓慢呼吸。
6. **只拉最酸的地方**：只处理局部会掩盖整体的活动度不足，至少覆盖当天主运动涉及的主要肌群。
7. **急性损伤马上拉伸**：拉伤后 48 小时内拉伸会加重出血与肿胀，这阶段不该拉伸。
8. **用拉伸替代热身**：静态拉伸不提高体温，不能替代慢跑、动态活动这类热身。

## 八、边界与免责

本技能提供拉伸的顺序规则、剂量参考和动作要点，不构成医学诊断、损伤分级或康复方案。拉伸的具体选择因年龄、关节活动度、既往损伤和合并疾病而异，以最新版运动医学共识和专业人员的现场评估为准。急性损伤、麻木放射痛、关节肿胀、疑似肌肉撕裂等情况，请停止拉伸并就医。
