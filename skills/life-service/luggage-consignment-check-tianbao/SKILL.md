# 行李托运与禁限带核查（luggage-consignment-check）

「这个到底能不能带」之所以难答，是因为它不是能不能带的问题，而是**能不能带、随身还是托运、带几个**三层问题。

这个技能做四件事：**先分类** → **再判携带方式** → **算额度** → **留凭证**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 说明禁运、限量、自营三类的判定逻辑 | ❌ 给出具体能量上限与额度数字 |
| 说明锂电池的特殊规定 | ❌ 承诺某个具体物品一定能通过 |
| 给出常见品类的判定要点 | ❌ 代替承运方安检做最终判定 |
| 说明额度口径与超重计费思路 | ❌ 编造条款号或标准号 |
| 说明理赔流程与凭证要求 | ❌ 代用户办理理赔 |

**具体品类范围、能量上限、额度与计费规则以承运方现行规定和现行规定为准。** 本技能只讲**判定逻辑与核对方法**，不写死具体数值，也不引用条款号。出行前请以承运方官方渠道公布的现行规则为准。

**最终判定权在安检环节**：即使按本技能判断可行，**安检仍有权根据现场情况决定是否放行**。有疑问时提前向承运方官方渠道确认，不要到了现场才赌。

## 二、三类判定逻辑

**这是本技能的第一根骨架，所有物品都先归到这三类。**

| 类别 | 判定逻辑 | 携带方式 |
|---|---|---|
| **禁运物品** | 本身被禁止运输，不因数量或包装改变 | **都不能带** |
| **限量物品** | 允许携带但有数量、容量、能量等限制 | 随身或托运各有限制，须按规则 |
| **自营物品** | 承运方自营的物品（如机上餐饮、纪念品） | 按承运方规则 |

**关键提醒**：**同一物品在不同承运方、不同运输方式（航空、铁路、水运）规则可能不同。** 一次旅行如果涉及多种运输方式，**每段都要单独核对**。

## 三、锂电池的特殊规定（最需要单独讲的一块）

**锂电池是最常被拦、也最容易被误带的品类。**

| 要点 | 说明 |
|---|---|
| **额定能量标识** | 锂电池与充电宝必须看清标称额定能量，这是判断的核心依据 |
| **必须随身的类别** | 便携式电子设备用锂电池（充电宝等）通常要求随身携带，**不得托运** |
| **易燃易爆电池禁止托运** | 存在起火风险的电池类型禁止托运 |
| **保护要求** | 端子有保护措施、避免短路、避免挤压 |
| **数量限制** | 数量与能量上限均有限制，**具体数值以承运方现行规定为准** |

**核对步骤**：

```
第 1 步  看清是电池还是充电宝，标称额定能量是多少
第 2 步  确认是否必须随身（多数便携式电池须随身，不可托运）
第 3 步  确认端子有保护措施，不会短路
第 4 步  确认数量与能量未超出承运方规定
第 5 步  打包时避免挤压与碰撞
```

**最常见的两类错误**：把充电宝放进托运行李，以及没看额定能量只带了容量百分比。

## 四、常见品类判定要点

**以下是常见品类的判定思路，具体以承运方现行规定为准。**

| 品类 | 判定要点 |
|---|---|
| 打火机、打火石 | 通常属限量类，随身与托运限制不同，**须按规则** |
| 火柴 | 通常有数量限制，属限量类 |
| 各类喷雾（含防晒喷雾、头发喷雾） | 通常有容量限制，且部分种类要求随身 |
| 气体罐、 pressurized 容器 | 通常限量，按规则 |
| 易燃液体（酒精、汽油等） | 通常限量或禁运，**须按规则确认** |
| 刀具（含折叠刀、工具刀） | 通常禁运，工具类另有限制 |
| 打火机油、有毒有害物品 | 通常禁运 |
| 酒类 | 通常有包装与容量要求，属限量类 |
| 液体（洗发水、饮料等） | 通常有单件容量限制，需密封防漏 |
| 药品 | 普通药品通常可带，**特殊药品与需冷藏药品另行确认** |
| 喷雾类化妆品与指甲油等 | 部分属限量，需按规则确认 |
| 动物与植物及其制品 | 通常有严格限制，**活体与多数动植物制品受限** |
| 种子、土壤 | 通常受限或禁运，须按规则确认 |
| 折叠自行车、工具 | 通常限量或需托运，按规则 |
| 充电宝、移动电源 | **必须随身，不可托运**，见上节 |
| 备用锂电池 | 同样须随身，不可托运 |

**否定项提醒**：**「别人带过」不是判断依据。** 规则会调整，物品属性也可能因包装形式不同而改变判定结果。

## 五、随身与托运额度口径

| 项目 | 说明 |
|---|---|
| 随身额度 | 按件重、件尺寸、件数等维度综合，**具体以承运方现行规定为准** |
| 托运额度 | 按重量与尺寸，**具体以承运方现行规定为准** |
| 计数口径 | 多件小件是否合并计算，看承运方规则 |
| 多段行程 | 每段可能单独计算，混装要注意 |

**超重计费的思路**：

- **先减重**：把不急用的物品转到随身或拿出来，通常比超重付费更划算
- **注意合并计数**：多件行李可能合并计算总重
- **分件可能更优**：具体如何分件最省要看承运方规则
- **费用标准以承运方现行规定为准**，本技能不给出费率数字

---

## 六、行李箱本身的限制

| 限制维度 | 说明 |
|---|---|
| 尺寸 | 各承运方有不同规格限制，超尺寸可能无法托运 |
| 重量 | 单件有上限，超重要另行处理 |
| 材质 | 部分材质或结构可能受限 |
| 打包 | 建议留出余量并做好防漏与防挤压 |

**建议**：出行前量一次行李箱外部尺寸并称重，**留出余量**，比到了值机柜台才发现超限要省事得多。

## 七、丢失与破损的理赔

**理赔流程的结构**：

```
第 1 步  发现问题立即在机场或车站的行李服务处办理登记
第 2 步  保留好行李牌与相关凭证
第 3 步  按承运方要求提交申报材料
第 4 步  必要时提供物品价值证明
第 5 步  跟进处理结果
```

**必须保留的凭证**：

| 凭证 | 作用 |
|---|---|
| 行李牌 | 证明确实办理过托运 |
| 购买凭证 | 证明物品价值 |
| 物品的电子照片 | 辅助证明物品状态 |
| 异常登记单 | 证明问题已被登记 |

**关于随身物品**：**随身物品通常不在托运行李的申报范围内**。所以贵重物品、易碎物品、证件、药品等**尽量随身携带，不要托运**。

**赔付范围与标准以承运方现行规定为准**，本技能不给出赔付金额或计算方式。

## 八、最常见的坑

**坑一：把充电宝放进托运行李。**
便携式电池通常要求随身携带、不得托运。放到行李里托运是常见的违规行为。

**坑二：只看容量不看额定能量。**
锂电池的判断依据是标称额定能量，不是容量百分比。两者不能直接换算。

**坑三：以为「别人带过」就行。**
规则会调整，包装形式变化也可能改变判定结果。**以承运方现行规定为准。**

**坑四：多种运输方式只按一段核对。**
航空、铁路、水运规则可能不同，每段都要单独核对。

**坑五：喷雾类一律按自用认定。**
喷雾通常有容量限制，且部分种类要求随身，**须按规则确认**。

**坑六：贵重物品和证件一起托运。**
随身物品通常不在托运行李的申报范围内，丢了很难追回。

**坑七：超重了才想办法。**
提前称重、超重先减重，通常比付费更省事。

**坑八：行李箱超尺寸没提前量。**
各承运方规格限制不同，超尺寸可能直接无法托运。出行前量一次留余量。

**坑九：托运出问题没保留凭证。**
行李牌、购买凭证、电子照片、异常登记单，缺一样都会影响后续处理。

**坑十：液体密封不好。**
液体类需密封防漏，托运途中渗漏会影响整件行李。

## 九、脚本用法

```bash
python scripts/luggage_check.py --items "充电宝,喷雾,折叠刀,打火机,酒"
python scripts/luggage_check.py --battery 20000 --file trip.json --out 核查结果.md
python scripts/luggage_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--items` | 逗号分隔的物品名称 |
| `--battery` | 电池额定能量（瓦时），用于锂电池判定 |
| `--powerbank` | 是否为充电宝（`yes`/`no`） |
| `--file` | 从 JSON 读（自动兼容带 BOM 的文件） |
| `--out` | 结果落盘路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本按三类判定逻辑给每件物品输出**类别判定、携带方式、判定要点提示**，锂电池单独输出专项提示。

> 脚本只做逻辑归类与核对提示，**不给出具体能量上限与额度数字**。最终判定以承运方与安检为准。

## 十、人工确认清单（这步不能省）

- [ ] 每件物品都归到了禁运、限量、自营三类中的一类

- [ ] 液体类做了密封防漏
- [ ] 刀具、易燃液体、动植物制品单独确认过
- [ ] 涉及多种运输方式时每段都核对了
- [ ] 贵重物品、证件、药品、易碎品放在随身没有托运
- [ ] 行李箱尺寸与重量提前量过并留了余量
- [ ] 知道最终判定权在安检，并保留了行李牌与凭证
