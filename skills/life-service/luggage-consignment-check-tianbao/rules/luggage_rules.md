# 行李托运与禁限带核查规则库

> 生成核查结论之前，先读这份文件，不要凭印象写。
> 具体品类范围、能量上限与额度以承运方现行规定为准。

---

## 一、三类判定逻辑

| 类别 | 判定逻辑 | 携带方式 |
|---|---|---|
| 禁运物品 | 本身被禁止运输，不因数量或包装改变 | 都不能带 |
| 限量物品 | 允许携带但有数量、容量、能量等限制 | 随身与托运各有限制 |
| 自营物品 | 承运方自营的物品 | 按承运方规则 |

**关键提醒**：**同一物品在不同承运方、不同运输方式规则可能不同。** 一趟行程涉及多种运输方式时，**每段都要单独核对**。

---

## 二、锂电池专项

| 要点 | 说明 |
|---|---|
| 额定能量标识 | 锂电池与充电宝必须看清标称额定能量 |
| 必须随身的类别 | 便携式电子设备用锂电池通常要求随身携带，不得托运 |
| 易燃易爆电池 | 禁止托运 |
| 保护要求 | 端子有保护措施、避免短路、避免挤压 |
| 数量与能量限制 | 具体数值以承运方现行规定为准 |

**核对步骤**：

1. 看清是电池还是充电宝，标称额定能量是多少
2. 确认是否必须随身（多数便携式电池须随身）
3. 确认端子有保护措施，不会短路
4. 确认数量与能量未超出承运方规定
5. 打包时避免挤压与碰撞

**两类最常见错误**：把充电宝放进托运行李；只看容量不看额定能量。

---

## 三、常见品类判定要点

| 品类 | 判定要点 |
|---|---|
| 打火机、打火石 | 通常限量，随身与托运限制不同 |
| 火柴 | 通常有数量限制 |
| 各类喷雾 | 通常有容量限制，部分种类要求随身 |
| 气体罐 | 通常限量 |
| 易燃液体 | 通常限量或禁运 |
| 刀具 | 通常禁运，工具类另有限制 |
| 有毒有害物品 | 通常禁运 |
| 酒类 | 通常有包装与容量要求 |
| 液体 | 通常有单件容量限制，需密封防漏 |
| 普通药品 | 通常可带，特殊与需冷藏药品另行确认 |
| 指甲油等化学品 | 部分属限量 |
| 动物与植物及其制品 | 限制严格，活体与多数制品受限 |
| 种子、土壤 | 通常受限或禁运 |
| 折叠自行车、工具 | 通常限量或需托运 |
| 充电宝、移动电源 | 必须随身，不可托运 |
| 备用锂电池 | 同样须随身，不可托运 |

**否定项提醒**：「别人带过」不是判断依据。规则会调整，包装形式变化也可能改变判定。

---

## 四、额度口径与超重处理

| 项目 | 说明 |
|---|---|
| 随身额度 | 按件重、尺寸、件数综合，具体以承运方现行规定为准 |
| 托运额度 | 按重量与尺寸，具体以承运方现行规定为准 |
| 计数口径 | 多件是否合并计算，看承运方规则 |
| 多段行程 | 每段可能单独计算 |

**超重处理思路**：

1. 先减重，把不急用的物品转到随身或拿出来
2. 注意多件行李可能合并计算总重
3. 分件方式是否更省要看承运方规则
4. 费用标准以承运方现行规定为准

---

## 五、行李箱限制

| 维度 | 说明 |
|---|---|
| 尺寸 | 各承运方规格不同，超尺寸可能无法托运 |
| 重量 | 单件有上限 |
| 材质 | 部分材质或结构可能受限 |
| 打包 | 留余量，做好防漏与防挤压 |

**建议**：出行前量一次外部尺寸并称重，留出余量。

---

## 六、理赔流程与凭证

| 顺序 | 动作 |
|---|---|
| 1 | 发现问题立即在服务处办理登记 |
| 2 | 保留好行李牌与相关凭证 |
| 3 | 按承运方要求提交申报材料 |
| 4 | 必要时提供物品价值证明 |
| 5 | 跟进处理结果 |

**必须保留的凭证**：

| 凭证 | 作用 |
|---|---|
| 行李牌 | 证明办理过托运 |
| 购买凭证 | 证明物品价值 |
| 电子照片 | 辅助证明物品状态 |
| 异常登记单 | 证明问题已被登记 |

**随身物品通常不在托运行李的申报范围内**，贵重物品、证件、药品、易碎品尽量随身携带。

---

## 七、常见误区对照

| 说法 | 是否成立 |
|---|---|
| 充电宝可以托运 | 不成立，通常要求随身携带 |
| 看容量就知道能不能带 | 不成立，判断依据是额定能量 |
| 别人带过就能带 | 不成立，规则会调整 |
| 一趟行程核对一次就够 | 不成立，多种运输方式要分别核对 |
| 喷雾都是自用随便带 | 不成立，有容量限制且部分要求随身 |
| 贵重物品托运也能赔 | 不成立，随身物品通常不在申报范围内 |
| 超重了再说 | 不成立，提前减重通常更划算 |
| 没保留凭证也能理赔 | 不成立，凭证是处理依据 |
