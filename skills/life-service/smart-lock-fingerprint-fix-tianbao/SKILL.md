# 智能门锁指纹失灵排查与应急开锁（smart-lock-fingerprint-fix）

指纹锁开不了门，**第一件事不是修锁，是先进门**。门锁问题里真正属于"指纹模块坏了"的比例很低，绝大多数是手指状态、录入质量、电池电压或机械阻力。

这个技能做三件事：**先进门** → **再定位** → **后处置**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出应急开锁的优先级顺序 | ❌ 提供撬锁、破锁、技术开启的具体手法 |
| 判断是手指、录入、电池还是机械问题 | ❌ 认定"识别不了就是模块坏了" |
| 指导指纹重录与日常维护 | ❌ 指导拆解锁体内部电路 |
| 提示电池鼓包与起火的处置 | ❌ 建议把应急钥匙藏在门外 |
| 说明开锁公司的核验要点 | ❌ 承诺一定能无损开门 |

**遇到以下情况，立即停止自行处置，转交专业人员或求助公共服务：**

- **有人被困室内、有老人儿童或宠物独处、有火情或燃气泄漏** → 拨打 119 / 110，不要自行拆锁
- 电池出现**鼓包、发烫、异味、漏液、冒烟** → 立即停用，人员撤离，按锂电起火处置
- 机械钥匙丢失、断在锁孔里、锁芯被堵
- 识别模块与主板故障、锁体电机或离合故障（需换件）
- 门体严重变形、方轴卡死、锁舌与门框扣板错位
- 无任何可用应急通道且情况紧急

**永远不要把应急机械钥匙藏在门外。** 消防栓、门垫、电表箱、门框上方是第一顺位被翻找的位置，藏在那里等于没有钥匙。

## 二、应急开锁顺序（被锁在外面时，按这个顺序来）

| 优先级 | 方式 | 适用条件 | 关键提醒 |
|---|---|---|---|
| 1 | **机械钥匙** | 钥匙随身或存放在门外可信处 | 平时就要确认钥匙能顺畅转动，别等到用时才发现 |
| 2 | **应急供电** | 电池耗尽 | 先确认接口类型：Type-C 应急口用充电宝；9V 电池触点用方块电池贴住正负极 |
| 3 | **密码 / 卡片 / NFC** | 主板仍有电 | 电池完全耗尽时多数不可用 |
| 4 | **APP 蓝牙 / 临时密码** | 手机在身边且锁在线 | 需提前绑定过 |
| 5 | **正规备案开锁公司** | 以上都不可用 | 必须核验备案与身份，详见第五节 |
| 6 | **破坏性拆除** | 最后手段 | 需物业或警方见证，破坏后锁具报废且门可能受损 |

> **先试机械钥匙**：它同时验证"机械部分是否正常"。钥匙能转但开不了，说明问题在锁体或门体，不是电子部分。

## 三、失灵故障树（按处理顺序）

完整判定口径在 `rules/smart_lock_rules.md`，顺序如下：

| 顺序 | 可能原因 | 判断方法 | 处置 |
|---|---|---|---|
| 1 | 电池电压不足 | 屏幕变暗、提示低电、或识别正常但电机无力 | 换电池或应急供电 |
| 2 | 指纹头脏污 | 识别慢、偶尔成功 | 干软布擦拭，少量酒精，禁用研磨剂 |
| 3 | 手指状态不佳 | 湿手、脱皮、油污、冬天干冷 | 擦干回暖再试，换手指 |
| 4 | 指纹录入质量差 | 某一位用户总失败 | 删除旧模板重新多角度录入 |
| 5 | 电池触点接触不良 | 黑屏、偶尔重启 | 擦触点、检查弹簧是否锈蚀 |
| 6 | 机械阻力过大 | 识别成功但开不了、耗电快 | 检查门下垂、锁舌卡滞、方轴，需调门 |
| 7 | 门框扣板错位 | 关门后自动上锁失败 | 调整扣板位置 |
| 8 | 模块或主板故障 | 以上全排除后仍失灵 | 报售后或专业人员 |

## 四、指纹重录规范（多数"失灵"在这里解决）

1. **删除旧模板**：先删掉要重录的那枚手指的所有旧记录
2. **保持手指清洁干燥**：油污与湿气是识别失败主因
3. **多角度多次录入**：同一枚手指分 3-5 次录入，覆盖指腹中心、偏左、偏右、指尖
4. **按压力度适中**：太轻采集不全，太重指纹变形
5. **覆盖常用手**：左右手各录至少一枚，主力手录两枚
6. **录完立刻实测**：连续开关 5 次，不成功就重录

**冬天失灵的处理**：先搓手回暖、哈气湿润再擦干，半导体指纹头受低温与静电影响明显。

## 五、找开锁公司时的核验清单

- 要求对方出示**公安机关备案**的相关证明或行业协会备案信息
- 上门后核对**从业人员身份信息**并留存
- 通过物业确认到场人员，最好有物业人员在场
- 提前准备**身份证明与居住证明**（身份证、房产证或租赁合同）
- 明确价格与是否无损开启，再让其动手
- 开完后**立即更换锁芯或重置全部指纹与密码**

```bash
python scripts/smart_lock_check.py --text "指纹识别成功但门打不开，电池刚换过"
python scripts/smart_lock_check.py --file 描述.txt --out 结果.md
```

| 参数 | 说明 |

| `--text` | 直接给现象描述 |
| `--file` | 从文件读描述 |

脚本按现象匹配故障树，输出排查顺序、验证动作、应急开锁优先级，以及命中红线时的停用与求助提示。

> 脚本只做关键词匹配，**不代表现场判断**。涉及被困人员与燃气泄漏的，直接求助公共服务。

## 七、人工确认清单（这步不能省）

- [ ] 机械钥匙在哪里、能不能顺畅转动，平时验证过
- [ ] 应急供电接口类型确认过（Type-C 还是 9V 触点）
- [ ] 电池是不是最近刚换过（换过还低电 → 查机械阻力）
- [ ] 指纹头有没有擦拭过
- [ ] 手指状态（湿、干、脱皮）排除过
- [ ] 指纹模板有没有重新录过
- [ ] 门有没有下垂、锁舌有没有卡滞
- [ ] 电池有没有鼓包、发烫、异味

## 八、最常见的坑

**坑一：一失灵就认定模块坏了。**
手指脏、干、录入质量差、电池电压低，这四类占了绝大多数。

**坑二：识别成功却开不了，第一反应是换锁。**
多是电池电压不足以驱动电机，或门下垂导致锁舌阻力大。先用机械钥匙验证机械部分。

**坑三：黑屏就以为主板报废。**
先查电池接触：弹簧锈蚀、电池松动、触点氧化都会导致间歇断电。

**坑四：电池换了新的还是很快没电。**
这是机械阻力过大的信号——门下垂、锁舌卡滞会让电机耗电剧增。换电池治标不治本。

**坑五：把应急钥匙藏在门外。**
门垫下、消防栓、电表箱、门框上方，是专业翻找的第一顺位。

**坑六：恢复出厂设置当常规操作。**
会清空全部指纹与密码，且可能丢失与 APP 的绑定。有机械钥匙在手时才考虑。

**坑七：电池鼓包还继续用。**
鼓包是热失控的前兆，不是"还能凑合"。立即停用更换。

**坑八：找开锁公司不核验身份。**
要求备案信息与身份证明，最好有物业在场，开完后立即换芯。

**坑九：冬天失灵就换锁。**
低温与静电导致半导体指纹头采集变差，回暖后多数恢复。

## 九、电池与用电安全（重点）

| 现象 | 处置 |
|---|---|
| 电池鼓包、发烫、异味、漏液 | 立即停用并断电，戴手套取出，放空旷处，勿挤压刺破，联系售后 |
| 电池冒烟或起火 | 人员立即撤离并拨 119；锂电火势猛且会复燃，不得用水少量浇泼后离开 |
| 充电口有烧蚀痕迹 | 停止使用该充电口，报售后 |
| 使用非原装充电器 | 电压电流不匹配会损伤电池与控制板，立即停用 |
| 电池仓弹簧锈蚀 | 擦拭干净再装新电池，接触不良会反复断电 |

**禁止事项：**

- 禁止拆解锁体内部电路与电池包（短路起火风险）
- 禁止把不同类型、不同电量的电池混装
- 禁止在电池鼓包状态下继续充电或使用
- 禁止把应急钥匙存放在门外任何位置
- 禁止用蛮力强行扳动把手（会损坏离合与方轴，反而更难开）

- 本技能**不提供**撬锁、破锁、技术开启的具体操作方法
