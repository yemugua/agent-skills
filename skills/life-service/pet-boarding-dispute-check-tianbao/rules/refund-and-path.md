# 宠物寄养退费与维权路径规则

## 一、退费计算顺序

```
应退金额 = 已付总额 − 已退金额 − 有合同依据的扣除
```

**扣除项的三个检验**：
1. 合同里有没有写这一项？（没写 → 不成立）
2. 有没有事前告知并取得同意？（事后补收 → 不成立）
3. 计算方式是否合理？（按天结算还是按次，单价是否与同类服务一致）

**常见不成立的扣除**：
- 「护理费」——未事先约定，或无实际护理事实凭证
- 「笼具清洁费」——笼具损耗属经营者成本，无约定不得转嫁
- 「应激损耗费」——宠物正常应激属生理现象，非主人过错
- 「违约金」——消费者一方通常不适用违约金条款

## 二、超期费用

- 合同约定了超期日单价的 → 按约定主张，但明显高于市场价的可主张酌减
- 未约定的 → 属**未约定事项**，应按当地同类寄养市场价协商，不支持商家单方定价

## 三、逐级维权路径

| 层级 | 动作 | 受理方 | 期限 |
| --- | --- | --- | --- |
| 1 | 书面协商 | 寄养商家 | 发出后 7 日无回复进下一级 |
| 2 | 平台投诉+ 申请介入 | 下单平台客服 | 平台一般 3~7 个工作日处理 |
| 3 | 12315 投诉 | 全国 12315 平台 / 当地市场监管 | 受理后 45 日内答复（可催办） |
| 4 | 消协调解 | 各级消费者协会 / 12315 站 | 调解不成可转诉讼 |
| 5 | 公安报案 | 公安机关 | 商家失联、涉嫌诈骗、涉动物检疫违法 |
| 6 | 民事诉讼 | 人民法院 | 立案后按简易程序 3 个月内审结 |

## 四、投诉材料清单（一次备齐，避免来回补）

1. 投诉人身份证明、联系方式
2. 寄养协议 / 订单截图 / 付款凭证（微信、支付宝账单截图需含交易单号）
3. 宠物入托前照片、视频
4. 寄养期间沟通记录截图（连续对话，不要截断）
5. 就诊记录、诊断证明、医疗费票据
6. 死亡证明或宠物火化证明（如有）
7. 商家营业执照信息（可通过国家企业信用信息公示系统查询，输入店名即可）
8. 要求商家书面答复的函件及其送达凭证

## 五、投诉话术要点

- **先讲事实，再讲诉求，最后给期限**。不要一开始就指责。
- 明确写出：「本人要求退还寄养费 ¥3200、赔偿医疗费 ¥1860，请在收到本函 7 日内书面答复。」
- 保留 12315 受理编号，用于后续催办和行政诉讼。
- 涉及格式条款无效的，可同时向**市场监管部门举报**（违法使用格式条款），这是行政处罚线索，与消费索赔并行不悖。

## 六、常见商家抗辩与应对

| 商家抗辩 | 应对 |
| --- | --- |
| 「宠物本就可能生病」 | 要求其举证入托前健康记录；强调寄养期间看管义务 |
| 「合同写了概不负责」 | 主张该条款属不合理免除自身责任，无效 |
| 「你没监控就没证据」 | 主张举证责任在商家（其持有监控与喂养记录）；同时立即书面申请调取 |
| 「这个价格是行业惯例」 | 要求出示当地同类服务明码标价或公示文件 |
| 「超过寄养期就要加钱」 | 主张无约定事项按市场价协商 |

## 七、注意事项

- 严禁以「宠物死了」相威胁或到店冲突，可能反过来构成治安问题。
- 涉及多只宠物、金额较大（万元级）或涉及刑事的，建议委托执业律师。
- 平台投诉与12315 投诉可并行，但同一事实重复投诉时以先受理方为主，避免被认为重复诉求影响处理。
