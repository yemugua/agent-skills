# 宠物寄养纠纷责任划分与退费维权

面向把宠物交给门店、家庭寄养点或平台托管宠物，事后出现宠物受伤、生病、死亡、走失、擅自加价、押金不退、超期费用争议的宠物主人。

## 与其他工具的区别

- 不只做"能不能退钱"，先做**过错归因**——宠物出事时主人最容易被一句"动物本就可能生病"带偏，先把责任框定清楚。
- 覆盖宠物寄养特有的法律空白：宠物没有独立民事权利，损害赔偿只能按**财产损失**主张，且需证明寄养方存在过错或违约。
- 把"举证责任"落到具体动作：疫苗本、就诊记录、寄养前照片、每日视频、笼舍监控调取申请。

## 典型适用场景

1. 寄养期间宠物发病或死亡，商家称"与寄养无关"
2. 商家单方面加价、延长寄养期未提前告知
3. 押金退还拖延、扣除"护理费""清洁费"无依据
4. 宠物走失，商家推诿或拒绝配合查找
5. 平台与商家互相推责，订单在谁手上说不清

## 使用流程

1. 抄录 `templates/宠物寄养纠纷信息采集表.md` 并如实填写（未知的留空或写"不清楚"）
2. 运行脚本生成核查报告
3. 按报告里的"待办补正动作"先补齐证据，再走对应维权路径

## 边界

本结果依通用规则整理，不替代专业法律意见。最终以主管部门或司法机关认定为准；涉及金额较大或宠物死亡的，建议同时咨询执业律师。
