# 重点单位消防档案建立

## 适用场景
重点单位消防档案建立指引，含三类备案与动态记录管理。

## 输入
按 `templates/场景表单.md` 填写场景、程度、可用工具与约束。

## 操作步骤
1. 打开 `templates/场景表单.md`，填写本次场景信息。
2. 运行：`python scripts/fire_keyunit_file.py <你填写后的表单路径>`
3. 按输出的分阶段清单逐项执行并打勾。
4. 每阶段完成后做阶段验收，禁止跳步。

## 输出说明
- 分阶段操作清单：每阶段含全部步骤、阶段验收与阶段禁忌
- 总体验收：步骤完成数核对 + 结果确认
