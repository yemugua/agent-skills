# 动火作业票管理与审批（hot-work-permit）

动火是单位火灾的**第一引火源**：电焊火星引燃油漆桶、气割熔渣掉进管道井——这类事故十有八九都输在"没办票、没测气、没看火"上。

这个技能做四件事：**定等级** → **办对票** → **控过程** → **收好尾**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 讲解动火分级与票证管理方法 | ❌ 替代现场安全监管与法定审批 |
| 生成动火票模板与体检报告 | ❌ 保证作业安全 |
| 整理检测与监护要点 | ❌ 出具执法结论 |

**遇到以下情况一律不得动火，先消除再干：**
- 未办票先动火、票证过期或越级审批
- 可燃气体检测不合格或未检测
- 盛装可燃物料的设备、管道未清洗置换
- 监护人不在现场

**永远不要**先干后补票。动火票是事故追责的核心证据，补票等于伪造证据。

## 二、完整工作流

```
第 1 步  定等级：按作业地点与危害判定特级/一级/二级
第 2 步  读规则文件 rules/permit_rules.md
第 3 步  办票：八要素填写 + 审批权限匹配 + 安全措施逐项确认
第 4 步  过程管控：气体检测 → 监护 → 作业 → 完工留守
第 5 步  体检表 → python scripts/permit_check.py --file 动火票.json
第 6 步  按 templates/动火作业票.md 出票或补全
```

## 三、动火三级分级

| 级别 | 典型场景（通行口径） | 审批权限 |
|---|---|---|
| 特级动火 | 运行状态的易燃易爆生产装置、罐区、油库、可燃气体管道上作业 | 单位主要负责人（或授权分管负责人） |
| 一级动火 | 易燃易爆场所内的禁火区作业 | 安全管理部门 + 单位分管负责人 |
| 二级动火 | 固定动火区以外的一般场所作业 | 作业部门 + 安全管理部门 |

> 分级标准**以本单位制度和现行规范为准**；施工现场动火分级按 GB 50720 等执行。拿不准就按高一级办。

---

## 四、动火票八要素

1. **作业部位**——具体到设备编号、楼层、管段
2. **动火方式**——电焊、气焊（割）、打磨、喷灯等
3. **作业人员**——姓名 + 特种作业证编号（**焊工必须持证**）
4. **监护人**——姓名 + 是否经过培训
5. **气体检测**——时间、部位、数值、检测人
6. **安全措施**——清理可燃物、灭火器材、隔离遮挡、通风、消防车/水源准备
7. **审批**——各级审批人签字与时间
8. **时间窗**——作业起止时间（一般一个班次内有效，跨班重新办）

---

## 五、过程管控三条线

**气体检测**：动火前 30 分钟内检测可燃气体浓度，**合格判据为体积分数 < 0.5%（或 LEL 10% 以下，按本单位标准从严执行）**；超过 30 分钟未动火或中断后重新动火，必须复测。

**监护**：监护人不得兼做其他工作，不得离开现场；备好灭火器材，发现异常有权叫停；特级动火应有消防车/微型消防站到场值守。

**完工**：作业结束后**留守观察不少于 30 分钟**，确认无阴燃、无火星飞溅隐患后，监护人签字闭环，票证归档。

## 六、脚本用法（票证体检）

```bash
python scripts/permit_check.py --file "D:\安全\动火票.json"
```

| 参数 | 说明 |
|---|---|
| `--file` | 必填。动火票 JSON（单张或数组） |
| `--today` | 核查基准日，默认今天 |
| `--selftest` | 跑内置样例自检 |

脚本检查五类问题：**要素缺失、分级与审批不匹配、气体检测数值超标或缺失、时间逻辑错误（审批晚于作业/超时间窗）、完工留守不足 30 分钟**。

> ⚠️ 脚本只做结构与逻辑检查，**不替代现场监管**；标"正常"不等于真做到。

---

## 七、人工确认（这步不能省）

- [ ] 作业人员特种作业证在有效期内、作业项目匹配
- [ ] 作业面可燃物是否清理、隔离是否到位
- [ ] 气体检测仪器是否在校验有效期内
- [ ] 监护人是否经过培训、是否清楚叫停权
- [ ] 下方楼层、竖井、电缆沟是否有火星坠落风险
- [ ] 应急预案与附近消防水源是否明确

---

## 八、输出结构（固定三段）

1. **能不能动**——结论先行：票证齐全 / 有缺口 / 有红线问题
2. **核对清单**——逐项标合规/缺失/存疑
3. **整改与补办建议**——先后顺序、责任岗位、留存材料

## 九、最常见的坑

**坑一：先干后补票。** 追责时补的票时间对不上监控，直接变伪造证据。

**坑二：气体检测一测了之。** 作业中通风变化、物料挥发会让浓度反弹，中断超 30 分钟必须复测。

**坑三：监护人变围观。** 监护人跑去递料、聊天，火星引燃油漆没人发现。

**坑四：等级就低不就高。** 罐区动火按二级办，审批层级不够，出了事层层失守。

**坑五：完工就走人。** 阴燃的保温层、火星落的电缆沟，半小时后才冒烟。
