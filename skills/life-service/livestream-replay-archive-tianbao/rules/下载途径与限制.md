# 直播回放留存与导出：途径、限制与合规边界

## 一、先判定：能不能下

| 归属类别 | 能否下载 | 允许的用途 |
| --- | --- | --- |
| 自有作品 | 可以，优先用原始导出文件 | 任意 |
| 已授权素材 | 可以 | 仅限授权范围内 |
| 作者开放了保存 | 可以，走官方途径 | 个人留存，**不得二次分发** |
| 第三方作品（未授权） | **不建议下载** | 不应用于任何对外场景 |

技术上能不能下载，和法律上能不能用，是两回事。

## 二、途径，按稳定性排序

| 途径 | 操作要点 |
| --- | --- |
| 主播本地录制 | **最可靠的方式**：开播时用 OBS 或推流工具同步录制到本地，拿到的是原始推流画质，不依赖平台保留期限。 |
| 平台回放下载（创作者后台） | 登录**自己的账号**在创作者后台下载平台自动生成的回放。注意回放有保留期限，过期不可恢复。 |
| 回放切条二次发布 | 把回放剪成短视频发布，属二次利用。发布前裁剪掉弹幕、礼物与观众信息。 |
| 通用命令行工具 | 需回放页地址且平台未做限制，稳定性随平台而异，失效先升级工具。 |

## 三、本平台的真实限制

- **回放有保留期限**（多为 7~30 天，各平台不同），过期后平台侧不可恢复。想长期留存必须在有效期内导出，或开播时就本地录制。
- 平台自动回放是转码后的版本，**画质通常明显低于直播源**；主播本地录制的是原始推流画质，二者差距肉眼可见。
- 付费直播的回放一般只对已购用户开放，下载后分发属违约且可能侵权。
- 回放里常包含观众弹幕、礼物提示与连麦画面，二次发布前建议裁剪，避免泄露他人信息。

## 四、画质与水印

- 回放画质受平台转码限制。若要原始画质，唯一可靠方式是开播端本地录制，而不是等回放生成。
- 回放可能带平台角标与直播间信息；二次发布前需裁剪，并注意遮挡观众昵称与头像。

## 五、合规红线

1. 不得去除作者署名后二次分发
2. 不得将他人作品搬运至自己的账号（含剪辑、配音后发布）
3. 不得下载或传播私密账号、付费内容
4. 受版权或 DRM 保护的内容不支持下载，也不提供任何破解方法
5. 商用前必须取得书面授权
6. 批量高频抓取可能违反平台服务协议，导致账号受限
