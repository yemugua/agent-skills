# 直播回放留存与导出：常见失败与排查

报错信息请**粘贴原文**再对照。写成「下载失败了」没有排查价值，
写成 `HTTP Error 403` 或 `ffmpeg not found` 才能定位。

## 现象 → 原因 → 处理

| 现象关键词 | 原因与处理 |
| --- | --- |
| 回放过期 / 已过期 / 看不了了 | 回放有保留期限，过期不可恢复。日后请在有效期内导出，或开播时就本地录制。 |
| 回放画质差 / 模糊 / 不清晰 | 平台回放为转码版本，画质低于直播源；下次用本地录制可保住原始画质。 |
| 没有回放 / 没生成 / 找不到回放 | 需在开播设置里开启回放生成，未开启则不产生回放文件。 |
| 仅app / 下载受限 / 只能在app | 部分平台回放只允许在 App 内观看或下载，改用 App 内操作。 |
| 文件太大 / 磁盘 / 空间不足 | 直播动辄数小时，单文件可达数 GB，先确认磁盘剩余空间。 |

## 通用故障（各平台都可能遇到）

| 现象 | 处理 |
| --- | --- |
| 403 / 需要登录 / 机器人验证 | 触发反自动化校验：携带登录态或减少请求频率，不要高频重试 |
| 429 / 频繁 / 限流 | 降低请求频率、分批间隔重试 |
| 404 / 失效 / 不存在 | 链接失效或已删除：让对方重新生成分享 |
| 没有声音 / 无音轨 | ffmpeg 未安装或未合并轨：安装后用 `-f "bv*+ba/b"` 合并 |
| 解析失败 / 格式不支持 | 站点接口变动：把工具升级到最新版，而不是换工具 |
| 超时 / 连接失败 | 检查网络可达性后重试 |

## 排查顺序

1. 先确认网络能访问目标平台
2. 再确认目标内容是否属于可下载范围（回到归属判定）
3. 然后确认工具是最新版
4. 最后才怀疑链接本身

九成的「下载失败」卡在第 1 步和第 2 步，而不是工具坏了。
