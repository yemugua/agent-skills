# 芒果TV视频离线与会员边界：途径、限制与合规边界

## 一、先判定：能不能下

| 归属类别 | 能否下载 | 允许的用途 |
| --- | --- | --- |
| 自有作品 | 可以，优先用原始导出文件 | 任意 |
| 已授权素材 | 可以 | 仅限授权范围内 |
| 作者开放了保存 | 可以，走官方途径 | 个人留存，**不得二次分发** |
| 第三方作品（未授权） | **不建议下载** | 不应用于任何对外场景 |

技术上能不能下载，和法律上能不能用，是两回事。

## 二、途径，按稳定性排序

| 途径 | 操作要点 |
| --- | --- |
| 原文件 | 优先。自有作品用发布前的原始导出文件；普通用户一般不适用，此项主要针对创作者。 |
| 官方离线缓存 | 在 App 内对支持的内容使用离线缓存，只能在**官方客户端内**观看，缓存文件加密，不能导出成通用视频文件。 |
| 合规替代：投屏观看 | 若目标只是在大屏上观看，用官方投屏即可，不必纠结拿到文件本身。 |
| 通用命令行工具 | 需 Python + ffmpeg：`pip install -U yt-dlp`。仅对**未加密的免费公开内容**可能有效，付费与会员内容不支持。 |

## 三、本平台的真实限制

- **离线缓存一律加密**：和爱优腾一样，缓存文件只能在官方客户端里播放，无法导出成 mp4，这是设计如此不是故障。
- 会员权益通常按端划分：手机端会员与电视端会员不互通，买了手机会员不代表能在电视上看。
- 综艺与剧集有排播与下架节奏，过了窗口期内容会下架，离线缓存也会随之失效。
- 超前点播、付费单片属额外付费内容，不支持下载或导出。
- 平台版权集中，相当比例内容仅取得网络播放权，不授予任何下载权。

## 四、画质与水印

- 在线播放的是转码流，画质受账号等级与网络自适应影响；缓存版本清晰度取决于下载时所选档位。
- 平台内容自带台标与水印，属版权标识，不得去除后二次分发。

## 五、合规红线

1. 不得去除作者署名后二次分发
2. 不得将他人作品搬运至自己的账号（含剪辑、配音后发布）
3. 不得下载或传播私密账号、付费内容
4. 受版权或 DRM 保护的内容不支持下载，也不提供任何破解方法
5. 商用前必须取得书面授权
6. 批量高频抓取可能违反平台服务协议，导致账号受限
