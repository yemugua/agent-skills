# 信用卡分期真实成本核算

「每月手续费只要 0.6%，听起来一年才 7%」，这句话几乎每年都有人信。

真相是：**0.6% 是单期费率，不是年化利率**。把它换算成真实年化，通常是单期费率的**将近两倍**。

这个技能做五件事：**认清计费方式 → 逐期算本金 → 换算真实年化 → 对比一次性还款 → 核提前还款**。

---

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 按每期费率与固定总手续费两种方式核算总成本 | 承诺资金用途合规、协助套现或违规转出 |
| 用近似公式与 IRR 两种口径换算真实年化 | 预测未来费率调整、承诺最低利率 |
| 逐期列出每期本金、利息与剩余本金 | 承诺提前还款一定免收剩余手续费 |
| 对比分期与一次性还款的差异 | 代替发卡行说明其内部计费规则 |
| 提示提前还款、展期、注销的口径 | 编造费率表、合同条款号与具体费率承诺 |
| 说明年化利率披露口径要求 | 提供任何编造用途、伪造凭证的方案 |

涉及以下情形，应停下来交由发卡行客服、合同载明渠道或金融消费者权益服务渠道处理：**费率争议、账单金额争议、账户异常与盗刷、涉诉或涉刑的信用卡纠纷**。

**绝对不做**：**不提供套现、虚假交易、资金违规转出或伪造用途的任何方案**。各行计费规则**以发卡行与合同载明为准**；年化利率的披露与计算口径**以现行规定和金融监管部门口径为准**。

## 三、完整工作流

```
第 1 步  取三项原始信息：分期本金、期数、费率或总手续费（从账单或申请页取得）
第 2 步  读规则文件 rules/credit-card-installment-rules.md（两种计费方式、
        换算公式、IRR 口径、提前还款、对比口径、防误伤清单）
第 3 步  判断计费方式：每期手续费率（按期收）还是固定总手续费（一次性收）
第 4 步  按逐期剩余本金 × 费率算每期成本，汇总总成本
第 5 步  跑脚本：scripts/installment_cost.py --file case.json
第 6 步  用近似公式换算年化，再算 IRR 精确口径，两者并列
第 7 步  对比一次性还款：总成本差额 + 资金占用期间的机会成本（不预设结论）
第 8 步  核提前还款与展期口径，确认剩余手续费是否继续收取
第 9 步  输出结论与必须向发卡行确认的问题，不替发卡行解释规则
```

## 四、核心口径（必须算得出来）

### 4.1 两种计费方式（先分清）

| 方式 | 收费规则 | 总成本算法 |
|---|---|---|
| **每期手续费率** | 每期按**剩余本金**（或按原始本金，**以合同载明为准**）× 费率收取 | **总手续费 = Σ 每期剩余本金 × 每期费率** |
| **固定总手续费** | 一开始就按一次性费率算出**总手续费**，此后每期不再重算 | **总手续费 = 原始本金 × 总费率** |
| 一次性收取手续费 | 首期或一次性收清，后续期数只还本金与（若有）利息 | 以合同载明为准 |

**必须说明**：**这三种方式的总额差别可能很大，必须先确认是哪一种，再算。** 同一句「费率 0.6%」，在不同计费方式下真实年化完全不同。

### 4.2 真实年化的近似换算公式

**每期手续费率（按剩余本金计）**：

```
真实年化成本 ≈ 每期手续费率 × 12 × 2
```

**固定总手续费（一次性收）**：

```
真实年化成本 ≈ 总手续费 ÷ 本金 × 12 ÷ 期数 × 2
```

> 这个「×2」是**近似处理**，来源于**平均占用资金约为总额的一半**。它给的是量级，不是精确值。

**必须写清**：

- **这是近似值，只能看量级**
- **精确口径要用 IRR**
- **不得把近似值当成合同约定的年化利率**

### 4.3 算例：每月 0.6% 到底是多少

**条件**：本金 12000 元，分 12 期，**每期按剩余本金收取 0.6% 手续费**。

| 期数 | 期初剩余本金 | 本期本金 | 本期手续费 |
|---|---|---|---|
| 1 | 12000 | 1000 | 72.00 |
| 2 | 11000 | 1000 | 66.00 |
| 3 | 10000 | 1000 | 60.00 |
| 4 | 9000 | 1000 | 54.00 |
| 5 | 8000 | 1000 | 48.00 |
| 6 | 7000 | 1000 | 42.00 |
| 7 | 6000 | 1000 | 36.00 |
| 8 | 5000 | 1000 | 30.00 |
| 9 | 4000 | 1000 | 24.00 |
| 10 | 3000 | 1000 | 18.00 |
| 11 | 2000 | 1000 | 12.00 |
| 12 | 1000 | 1000 | 6.00 |
| **合计** | | **12000** | **468.00** |

**三个结论**：

1. **每期手续费从 72 元一路降到 6 元**——因为按剩余本金收
2. **总手续费 468 元 ÷ 12000 元 = 3.9%**，这是 12 期的**总成本率**，不是年化
3. **近似公式**：0.6% × 12 × 2 = **14.4%**；**IRR 精确口径约 13.9%**

**对比固定总手续费方式**：如果同样 0.6% 是「一次性总费率」，总手续费 = 12000 × 0.6% = **72 元**，真实年化约 **1.5%**，与上面差了将近 10 倍。

> **同一个「0.6%」，按剩余本金逐期收和一次性收，结果差近十倍。这就是为什么第一件事是问清计费方式。**

### 4.4 IRR 精确口径

```
每期还款额 = 本金 ÷ 期数 + 当期手续费

IRR 求解：使 Σ [ 每期还款额 ÷ (1 + r)^t ] = 本金 的折现率 r
```

- **IRR 是把资金占用与还款节奏一并算进去的口径**，比近似公式准
- **必须说明现金流的时间点**：每期还款发生在期末还是期初，**口径不同结果不同**，需注明
- **IRR 与「合同约定的年化利率」不是一回事**，不得混用

### 4.5 提前还款与展期口径

| 情形 | 必须核对 |
|---|---|
| 提前一次性还清 | **剩余期数的手续费是否继续收取**、是否收违约金、是否有最低手续费 |
| 部分提前还款 | 手续费是否按剩余本金重算、是否按原始本金计 |
| 展期 / 延期 | 是否收费、费率是否上浮 |
| 分期手续费提前一次性收 | 中途还清能否退还已收未发生部分 |
| 最低还款额 | 未全额还款时是否按全额本金计息 |

**必须写清**：**这些规则各行差异很大，一律以发卡行与合同载明为准。不得凭「一般来说」下结论。**

### 4.6 分期与一次性还款的对比口径

```
资金占用期间的机会成本 = 占用金额 × 同期资金收益率 × 占用月数 ÷ 12

对比结论 = 分期总成本 − 一次性还款成本 − 机会成本
```

**必须说明**：

- **分期不等于「多花钱」也不等于「少花钱」**：取决于资金占用期间能不能拿到同等收益、能不能提前还
- **必须说明机会成本的口径**：本技能**不预设收益水平**，用你提供的收益率参数
- **不得给买卖建议**：只给两边的数字

## 六、脚本用法

```bash
python scripts/installment_cost.py --file case.json --out 分期真实成本核算.md
python scripts/installment_cost.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：分期本金、期数、每期费率或总费率、计费方式（按剩余本金 / 按原始本金 / 固定总手续费）、每期手续费固定额、是否期初还款、提前还款期数 |
| `--text` | 直接给 JSON 字符串 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检 |

输入 JSON 示例：

```json
{
  "principal": 12000,
  "months": 12,
  "method": "on_remaining",
  "monthly_rate": 0.006,
  "flat_total_rate": 0.006,
  "flat_monthly_fee": 0,
  "pay_at_beginning": false,
  "early_pay_month": 0
}
```

脚本输出：逐期本金与手续费明细表、总手续费与总成本率、近似换算年化、IRR 精确年化、两种计费方式的对比、提前还款情形下的成本、以及必须向发卡行确认的问题清单。

> 脚本按你填的数据做**静态测算**。各行计费规则**以发卡行与合同载明为准**；**年化利率的披露与计算口径以现行规定和金融监管部门口径为准**。脚本不预测费率调整、不承诺免收剩余手续费，也不提供任何资金违规转移方案。

## 七、人工确认清单（这步不能省）

- [ ] **分期本金**取自账单，不是申请额度
- [ ] **期数**确认是 3 / 6 / 12 / 24 期中的哪一档
- [ ] **计费方式**已从账单或申请页确认（按剩余本金 / 按原始本金 / 固定总手续费 / 一次性收取）
- [ ] **每期手续费金额**已从账单实际数值抄下，不是用费率反推
- [ ] 是否有**最低手续费**（如每期不低于 X 元）已确认
- [ ] **提前还款**是否继续收剩余手续费、是否收违约金，已从发卡行渠道确认
- [ ] **展期**是否收费、费率是否上浮，已确认
- [ ] 若做了「分期与一次性还款」的对比，**机会成本用的收益率口径已写明来源**
- [ ] 结论中**没有把每期费率直接写成年化**
- [ ] 结论中**没有承诺「提前还款一定免手续费」**

## 八、最常见的坑

1. **把每期手续费率当年化利率。** 0.6% 是**单期费率**，不是年化。**近似换算是 0.6% × 12 × 2 ≈ 14.4%，IRR 精确口径约 13.9%。**
2. **不确认计费方式就开始算。** 同样 0.6%，**按剩余本金逐期收**总手续费 468 元（本金 12000 / 12 期），**一次性总费率收**只有 72 元。**差近十倍。第一件事永远是问清怎么收。**
3. **用原始本金算每期手续费。** 有些规则是**按原始本金 × 费率**每期固定收，不随剩余本金递减。这样算出来的总成本与「按剩余本金收」完全不同。**以合同载明为准。**
4. **忽略「每期最低手续费」。** 很多产品每期手续费不低于某个金额。后期剩余本金变小后，最低值会顶上来，**实际成本比按费率算的高**。
5. **把近似换算值当成合同约定的年化利率。** 「×2」只是**近似处理**，用来判断量级。**精确值要用 IRR，而且 IRR 也不等于合同约定的年化利率。**
6. **忽略资金占用期间的机会成本。** 分期不是「多花钱」也不是「省了钱」，**取决于这期间的钱本来能不能拿到同等收益、能不能提前还**。不算机会成本，对比就是残缺的。
7. **以为提前还款能免掉剩余手续费。** **很多产品提前还清仍要收剩余期数的手续费，甚至有违约金。** 这条只能问发卡行，**不能凭「一般来说」**。
8. **用展期解决还款压力。** 展期通常收费且费率可能上浮，**只是把压力往后推**。**不要用展期掩盖资金缺口。**
9. **只还最低还款额。** 未全额还款时可能按**全额本金**计息，**成本远高于分期**。这一条要去合同里确认。
10. **不保留账单与沟通记录。** 费率与收费规则的争议，**靠账单和应用页截图说话**。
11. **被「免息」两个字带偏。** 「免息」不等于「免手续费」。**免的是利息，还有手续费**，这两件事要分开算。
