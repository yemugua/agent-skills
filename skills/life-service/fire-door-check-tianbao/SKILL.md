# 防火门与防火卷帘巡查核查

## 适用场景
面向消防维保人员的防火门与防火卷帘巡查核查，覆盖门体/卷帘/五金/维护四大域。

## 输入
按 `templates/采集表.md` 逐项核查并填写（填「是 / 否」或具体情况，留空视为待确认）。

## 操作步骤
1. 打开 `templates/采集表.md`，逐项核查现场、台账与记录。
2. 运行：`python scripts/fire_door_check.py.py <你填写后的采集表路径>`
3. 查看输出报告：总体结论 + 各域明细 + 整改建议。
4. 阻断项立即整改，风险项限期整改，待确认项补充后复跑。

## 输出说明
- 总体结论：**通过** / **有风险** / **不通过** / **待补正**
- 各域明细：每项标注（符合）/（风险）/（阻断）/（待确认）
- 整改建议：按【立即】【限期】【补充】分级列出

## 规则要点
### 防火门
- 闭门器顺序器完好：现场核查该事项，不符合即记录事实证据并整改
- 门缝封条无缺失：现场核查该事项，不符合即记录事实证据并整改
- 常闭防火门处于关闭状态：现场核查该事项，不符合即记录事实证据并整改
- 常开防火门信号正常：现场核查该事项，不符合即记录事实证据并整改

### 防火卷帘

- 温控释放装置完好：现场核查该事项，不符合即记录事实证据并整改
- 下方无堆物：现场核查该事项，不符合即记录事实证据并整改

### 五金与标识

- 标识标牌清晰完整：现场核查该事项，不符合即记录事实证据并整改

### 维护与记录
