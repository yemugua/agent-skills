## 二、姿势自查（每组都要过）

| 项目 | 是否合格 |
|---|---|
| 肘在肩正下方，前臂与肩同宽 | 是 / 否 |

| 无塌腰（腰部下沉） | 是 / 否 |
| 无撅臀（臀部抬高） | 是 / 否 |
| 核心收紧，腹部不往下坠 | 是 / 否 |
| 头颈中立，眼看地面 | 是 / 否 |
| 全程正常呼吸不憋气 | 是 / 否 |

塌腰、撅臀、憋气任一项为「否」：立即结束该组，该组时长不计入成绩。
