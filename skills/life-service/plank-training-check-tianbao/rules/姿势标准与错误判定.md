# 姿势标准与错误判定

## 一、五项姿势标准

| 项目 | 标准 | 自查方式 |
|---|---|---|
| 肘位 | 肘关节在肩关节正下方，前臂贴地与肩同宽 | 侧面看，肩与肘在同一条垂线上 |
| 身体直线 | 头、肩、髋、膝、踝基本在一条直线上 | 侧面录像或请人看，用一根杆贴背比对 |
| 核心收紧 | 肚脐向脊柱方向收，腹部不往下坠 | 感觉腹部有轻微绷紧，不是把腰往下压 |
| 头颈中立 | 眼看地面，颈椎自然延长 | 不低头看肚脐，也不抬头看前方 |
| 脚位 | 双脚与髋同宽，脚尖着地 | 脚跟向后蹬，脚踝保持紧张 |

## 二、错误判定表

| 错误 | 判定 | 后果 | 纠正 |
|---|---|---|---|
| 塌腰（腰部下沉） | 不合格 | 核心失守，负荷全由腰椎承担 | 立即结束该组；改跪姿或上斜版本重建核心张力 |
| 撅臀（臀部抬高） | 不合格 | 核心几乎不参与，等于白做 | 把臀降到与肩同高，缩短时长 |
| 肘部在肩前方 | 不合格 | 肩关节承担大部分负荷 | 肘回到肩正下方，必要时退阶 |
| 核心没收紧 | 不合格 | 动作失去意义 | 先练仰卧位的腹部收紧感，再回到平板 |
| 头颈下垂或抬起 | 需改进 | 改变躯干力线 | 眼看地面，颈椎自然延长 |
| 憋气 | 不合格 | 血压升高、疲劳加快 | 全程正常呼吸，用节奏呼吸配合 |
| 脚尖点地不稳 | 需改进 | 下肢支撑不充分 | 脚跟向后蹬，双脚与髋同宽 |

**塌腰与撅臀是最常见的两项，也最容易自我感觉良好。** 建议侧面录像 10 秒回看，肉眼在动作中很难发现自己的腰部下沉。

## 三、呼吸要求

| 环节 | 做法 |
|---|---|
| 摆好姿势前 | 吸一口气，把核心收紧 |
| 支撑过程 | 正常呼吸，不要憋气 |
| 节奏 | 可用 3-4 秒一吸、3-4 秒一呼的慢节奏 |
| 撑不住时 | 立即结束，不要靠憋气再多撑几秒 |

**憋气是撑不久的常见原因**：憋气会升高血压、加快疲劳，还会让核心更难维持。

## 四、结束一组的判定

出现以下任一项，立即结束该组，不要等到计时结束：

- 腰部开始下沉（塌腰）
- 臀部开始抬高（撅臀）
- 身体开始明显抖动且无法控制
- 出现憋气
- 出现疼痛或头晕

**姿势变形后继续计时，练的是代偿而不是核心。** 该组时长不计入成绩。

## 五、常见疑问

| 疑问 | 说明 |
|---|---|
| 膝盖着地算不算平板支撑 | 算退阶版本，是合法且推荐的做法 |
| 能不能减肚子 | 不能局部减脂，平板支撑练的是核心稳定性 |
| 每天做会不会更好 | 核心也需要恢复，每周 3-4 次即可 |
| 撑得越久越有效吗 | 不是，姿势变形后继续撑只会练到代偿肌群 |
| 腰疼还能做吗 | 不能，出现腰痛应停止并评估 |
