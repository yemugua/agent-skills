# 平板支撑

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 给出平板支撑的姿势标准与错误判定 | 诊断腰肌劳损、腰椎间盘突出或任何伤病 |
| 说明时长、组数、退阶与进阶的口径 | 给康复训练方案、伤后恢复计划或用药建议 |
| 提示呼吸要求与停练红线 | 承诺平板支撑能减肚子、瘦腰或替代有氧 |
| 输出姿势不合格项与原因、调整建议 | 建议追求单次时长纪录、憋气硬撑或带痛坚持 |

**必须停止练习并转交专业人士的情况**

- 支撑时或支撑后腰部出现疼痛，尤其疼痛向腿部放射
- 肩部疼痛、抬手受限、夜间痛
- 腹部出现牵拉痛、局部隆起或不适（尤其产后人群）
- 支撑中头晕、胸闷、眼前发黑
- 支撑后疼痛持续超过 24 小时不缓解

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「平板支撑标准动作是什么」 | 用 |
| 「做多久合适，是不是越久越好」 | 用，明确质量优先 |
| 「做的时候腰疼正常吗」 | 只作停止与就医提示，不做诊断 |
| 「塌腰算不算做错了」 | 用，明确属于不合格 |
| 「撑不了 30 秒怎么办」 | 用，给退阶方案 |
| 「平板支撑能减肚子吗」 | 用，说明不能局部减脂 |
| 「膝盖着地算不算」 | 用，说明跪姿是合法退阶 |
| 「要不要憋气」 | 用，明确不能憋气 |
| 「帮我看看我做得标不标准」 | 不提供视频判读，只给自查清单 |

## 三、完整工作流

1. **先排停练红线**：疼痛、头晕、肩腰不适先停，不要靠调整姿势硬撑。
2. **摆姿势**：肘在肩正下方，前臂贴地与肩同宽，双脚与髋同宽，身体从头到脚踝成一条直线。
3. **收紧核心**：肚脐向脊柱方向收，臀部与肩基本同高，不是把腰往下压也不是把屁股翘起来。
4. **查姿势**：按 `rules/姿势标准与错误判定.md` 逐项过，塌腰与撅臀任一项出现即判不合格。
5. **定剂量**：标准姿势下 3 组 × 20-40 秒，组间休息 30-60 秒；姿势变形就结束该组，不要硬撑。
6. **选退阶或进阶**：撑不到 20 秒就用跪姿或上斜版本；能标准撑满 60 秒再考虑进阶动作。
7. **记录与复评**：记录每组的实际时长与姿势评分；每周看标准姿势能撑多久，而不是看能不能撑 5 分钟。

## 四、核心规则与要件库

生成姿势纠正或训练建议前，**必须先读**：

- `rules/姿势标准与错误判定.md`：五项姿势标准、塌腰与撅臀等错误的判定与纠正、呼吸要求。
- `rules/剂量退阶与进阶.md`：时长与组数口径、跪姿与上斜退阶、进阶动作、停练红线与记录方式。

**姿势不合格时，单次时长再长也不计入成绩**。质量优先于时长是本技能的核心判定原则。

## 五、脚本用法

```
python scripts/plank_training_check.py --file case.json
python scripts/plank_training_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：组数、单次时长、组间休息、五项姿势自查、是否憋气、疼痛部位 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--json` | 以 JSON 输出 |
| `--selftest` | 运行自检 |

脚本输出姿势判定、不合格项与原因、时长与组数建议。**判定顺序是先查真实缺陷（塌腰、撅臀、肘位不对、核心没收紧、憋气、疼痛、单次超长），再看信息是否完整**；姿势不合格时脚本会明确写出「该组时长不计入」，不会用时长掩盖姿势问题。

## 六、人工确认清单

- [ ] 停练红线逐条确认，无疼痛、无头晕
- [ ] 肘在肩正下方，前臂与肩同宽
- [ ] 身体成一条直线，无塌腰、无撅臀
- [ ] 核心已收紧，肚脐向脊柱方向收
- [ ] 头颈部中立，既不低头也不抬头
- [ ] 全程正常呼吸，没有憋气
- [ ] 姿势变形就结束该组，没有硬撑到计时结束
- [ ] 记录了每组实际时长与姿势评分

## 七、最常见的坑

1. **追求单次时长纪录**：撑到 3 分钟、5 分钟，后半段全是塌腰代偿，练的是腰椎而不是核心。质量不合格的时长毫无意义。
2. **塌腰还继续计时**：腰部下沉说明核心已经失守，这时候每一秒都在用腰椎硬扛，应立即结束该组。
3. **撅臀当标准**：把屁股抬起来看着像一条直线，实际上核心完全没参与，等于白做。
4. **憋气硬撑**：憋气会升高血压、加快疲劳，还会让核心更难维持，是撑不久的常见原因。
5. **肘部跑到肩前面**：肘位靠前会让肩关节承担大部分负荷，肩痛的常见来源。
6. **低头或抬头看前方**：头颈位置改变会连带躯干力线，应保持中立看地面。
7. **以为能减肚子**：平板支撑是核心稳定性训练，不产生局部减脂效果。
8. **每天练不休息**：核心也需要恢复，每周 3-4 次即可，不必天天做。

## 八、边界与免责

本技能提供平板支撑的姿势标准、剂量参考和自查清单，不构成医学诊断、运动康复方案或体型改变承诺。支撑时长、组数和退阶方式因年龄、核心力量水平、腰肩状况和既往损伤而异，以最新版运动医学共识和专业人员的现场评估为准。产后人群、有腰肩病史者开始练习前应咨询医师或专业人员。出现腰腿放射痛、肩部夜间痛、腹部牵拉痛、头晕胸闷等情况，请停止练习并就医。
