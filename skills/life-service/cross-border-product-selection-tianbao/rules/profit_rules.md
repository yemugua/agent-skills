# 跨境电商选品：金额核算口径、参数区间与合规红线

生成利润测算或选品建议前，**必须先读本文件**，不要凭印象写「注意利润」。

---

## 一、七项成本：口径与易错点

| 编号 | 成本项 | 公式 | 易错点 |
|---|---|---|---|
| ① | 采购成本 | 含税到手价 | 漏算包装、贴标、质检、返工 |
| ② | 头程运费 | 计费重 × 单价 | **漏算体积重**、漏算旺季加价与偏远附加费 |
| ③ | FBA 配送费 | 平台费率(USD) × 汇率 | **尺寸段跳档**、包装改动后未复核 |
| ④ | 平台佣金 | 销售收入 × 佣金率 | 类目费率搞错、最低佣金未计入 |
| ⑤ | 广告费 | 销售收入 × ACOS | 用「目标 ACOS」而非实际 ACOS |
| ⑥ | 仓储费 | 按月体积与时长分摊 | 漏算长期仓储加价与旺季费率 |
| ⑦ | 退货损耗 | 退货率 × (货值成本 × 损耗率 + 处理费) | **完全不算**，或只算退款不算损耗 |
| ⑧ | 其他 | 包装、收款手续费、人工分摊 | 收款通道手续费常被忽略 |

**计费重口径**

```
体积重(kg) = 长(cm) × 宽(cm) × 高(cm) ÷ 除数
计费重(kg) = max(实重, 体积重)
```

- 除数：空运/快递常用 **6000**，部分渠道用 **5000**，以渠道规定为准
- 海运按立方米计费，泡货按体积吨

**为什么体积重必须算**：一个 30×30×30 cm、实重 0.5 kg 的产品，体积重是 4.5 kg，运费按 4.5 kg 算。泡货在选品阶段就该识别出来，否则定价时全盘皆错。

## 二、参数取值区间（用于估算，实际以报价为准）

| 参数 | 常见区间 | 取值建议 |
|---|---|---|
| 头程单价（海运） | 8-20 元/kg | 慢但便宜，适合重货与提前备货 |
| 头程单价（空运） | 25-45 元/kg | 平衡时效与成本 |
| 头程单价（快递） | 45-70 元/kg | 急件与小批量 |
| 平台佣金率 | 8%-15% | 按类目查平台费率表 |
| FBA 配送费 | 随尺寸段与重量段 | 以平台最新费率表为准 |
| ACOS（稳定期） | 10%-20% | 新品期可更高，但要看保本线 |
| 退货率（3C） | 5%-10% | |
| 退货率（家居） | 5%-8% | |
| 退货率（服装） | 15%-25% | 尺码问题是主因 |
| 退货损耗率 | 0.3-0.6 | 可翻新取低值，不可翻新取高值 |
| 汇率 | 随行就市 | 按结算周期实际汇率，留 1%-2% 波动余量 |

**保守原则**：估算阶段，头程取上限、退货率取上限、ACOS 取实际而非目标。**宁可算保守，不要算乐观。**

## 三、四个结果指标与判定档位

| 指标 | 公式 | 判读 |
|---|---|---|
| 毛利率 | 净利润 ÷ 销售收入 | 主判定指标 |
| 不含广告毛利率 | (销售收入 - 除广告外成本) ÷ 销售收入 | 等于**保本广告占比** |
| 保本 ROI | 1 ÷ 保本广告占比 | 广告 ROI 低于此值即亏损 |
| 保本售价 | 固定成本 ÷ (1 - 佣金率 - ACOS) ÷ 汇率 | 售价低于此值即亏损 |

| 毛利率 | 判定 | 动作 |
|---|---|---|
| ≥ 25% | 可做 | 按计划推进，先做合规排查 |
| 15% - 25% | 谨慎 | 压采购价或提价，或降 ACOS 后重算 |
| 0 - 15% | 不建议 | 抗风险能力差 |
| ≤ 0 | 亏损 | 不要上架 |

**附加红线**

- 实际 ROI < 保本 ROI → 广告正在吃掉利润，先优化转化率与客单价，不要加预算
- 保本 ROI > 4 → 毛利空间对广告过于敏感，放量要谨慎
- 保本售价接近当前售价 → 没有降价促销的空间

## 四、敏感分析（必做三步）

| 情景 | 变动 | 看什么 |
|---|---|---|
| 采购涨价 | 采购价 +10% | 毛利率还剩多少，是否跌破 15% |
| 运费上涨 | 头程 +30% | 泡货受影响最大 |
| 广告变差 | ACOS +5 个百分点 | 是否跌破保本广告占比 |
| 退货上升 | 退货率 +5 个百分点 | 服装类尤其敏感 |
| 汇率波动 | 汇率 -3% | 直接吃掉毛利 |
| 降价竞争 | 售价 -10% | 是否跌破保本售价 |

**判读**：如果任意一个情景就让毛利率跌破 0，说明这个产品的安全垫太薄，需要重新谈采购价或换品。

## 五、选品维度清单（利润之外的七项）

| 维度 | 判断口径 | 不宜做的信号 |
|---|---|---|
| 客单价 | 能否覆盖固定成本 | 客单价 < 15 美元且体积不小 |
| 体积重量 | 体积重 vs 实重 | 体积重 > 实重 2 倍以上 |
| 季节性 | 销售集中度 | 只有 1-2 个月能卖，且备货周期长 |
| 复购 | 复购率与关联销售 | 一次性消费且无配件 |
| 竞争度 | 头部集中度、评价数门槛 | 头部评价数上万且价格战激烈 |
| 合规 | 认证、专利、敏感属性 | 需认证未认证、有专利风险 |
| 供应链 | 供应稳定性与品质一致性 | 单一供应商、品质波动大 |

## 六、合规与侵权红线（上架前必查）

| 类别 | 必查项 |
|---|---|
| 专利 | 外观专利、实用新型、发明专利（**贴牌不等于免责**） |
| 商标 | 品牌名、Logo、图形商标是否已注册 |
| 版权 | 图案、插画、IP 形象是否有授权 |
| 认证 | 儿童用品、电器、无线产品、食品接触材料、化妆品、医疗器械、带电产品等类目的强制认证 |
| 敏感属性 | 带电池、磁性、液体、粉末、刀具、喷雾等是否可收 |
| 平台规则 | 是否在禁售或限制类目清单内 |
| 授权链 | 品牌代理需要完整授权文件 |

**绝对不做的事**：不刷单、不操纵评价、不低报货值、不拆分包裹规避监管、不销售侵权与假冒商品。这类操作的代价是封号与资金冻结。
