# 跨境电商选品与利润核算（cross-border-product-selection）

选品最贵的错误，是**上架之后才发现不赚钱**。售价看着挺高，扣完佣金、配送费、头程、广告、退货，剩下来的才是利润。

这个技能做三件事：**算清成本 → 算出保本线 → 过合规红线**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 按给定参数核算单品毛利、毛利率与保本线 | ❌ 提供平台实时费率、实时汇率、实时广告数据 |
| 给出各项成本的取值口径与常见区间 | ❌ 承诺某个产品一定能卖、一定能赚 |
| 给出选品的结构化判断维度与判定档位 | ❌ 判断专利是否侵权、商标是否可用（需专业检索与法律意见） |
| 提示必须做合规与侵权排查的情形 | ❌ 提供避税、低报货值、规避平台规则的方案 |

**必须停下来做专业核查的情形：**

- 产品外观、结构、图案可能涉及他人的**外观专利、实用新型、发明专利或商标**（需做专利与商标检索，必要时咨询知识产权律师）
- 产品属于需要认证的类目（儿童用品、电器、无线产品、食品接触材料、化妆品、医疗器械、带电产品等），**未取得相应认证不得上架**
- 产品带电池、磁性、液体、粉末、刀具、喷雾等敏感属性，需确认头程与平台可收
- 平台禁售或限制类目清单内的产品
- 涉及品牌授权、代理授权的，需有完整授权链

**绝对不做的事**：不刷单、不操纵评价、不低报货值、不拆分包裹规避监管、不销售侵权与假冒商品。**这类操作的代价是封号与资金冻结，远大于任何短期收益。**

## 二、完整工作流

```
第 1 步  过合规红线：侵权、认证、敏感属性、平台禁售四项先确认
第 2 步  读规则文件 rules/profit_rules.md（成本项口径 + 取值区间 + 判定档位）
第 3 步  收集参数：售价、采购价、重量尺寸、头程方式与单价、FBA 档位、佣金率、ACOS、退货率
第 4 步  跑脚本核算：python scripts/profit_calc.py --file product.json
第 5 步  看四个数：毛利率、保本广告占比、保本 ROI、保本售价
第 6 步  做判定：≥25% 可做，15%-25% 谨慎，<15% 不建议，≤0 亏损
第 7 步  做敏感分析：采购价 +10%、运费 +30%、ACOS +5 个点，分别还剩多少
第 8 步  再核一次参数：费率和汇率以最新数据为准
```

**顺序不能颠倒**：第 1 步的合规没过，后面算得再漂亮也不能上架。

## 三、金额核算：七项成本与四个结果

### 3.1 核算公式（单件，人民币口径）

```
销售收入   = 售价(USD) × 汇率

① 采购成本  = 含税到手价（含包装、贴标、质检）
② 头程运费  = 计费重(kg) × 头程单价(元/kg)
             计费重 = max(实重, 体积重)
             体积重 = 长(cm) × 宽(cm) × 高(cm) ÷ 体积重除数（空运/快递常用 6000，部分渠道 5000）
③ FBA 配送费 = 平台费率(USD) × 汇率      ← 按尺寸段与重量段跳档，以平台最新费率表为准
④ 平台佣金   = 销售收入 × 佣金率          ← 多数类目 8%-15%，部分类目更高
⑤ 广告费     = 销售收入 × 广告占比(ACOS)
⑥ 仓储费     = 月度仓储分摊（按体积与存放时长）
⑦ 退货损耗   = 退货率 × (货值成本 × 损耗率 + 单次退货处理费)
             货值成本 = 采购成本 + 头程运费 + FBA 配送费
其他        = 包装、收款手续费、人工分摊等

成本合计   = ① + ② + ③ + ④ + ⑤ + ⑥ + ⑦ + 其他
净利润     = 销售收入 - 成本合计
毛利率     = 净利润 ÷ 销售收入
```

### 3.2 四个结果指标

| 指标 | 公式 | 用途 |
|---|---|---|
| **毛利率** | 净利润 ÷ 销售收入 | 主判定指标 |
| **保本广告占比** | 剔除广告后的毛利额 ÷ 销售收入 | 广告占比超过这个值就开始亏 |
| **保本 ROI** | 1 ÷ 保本广告占比 | 广告 ROI 低于这个值即亏损 |
| **保本售价** | 固定成本 ÷ (1 - 佣金率 - 广告占比) ÷ 汇率 | 售价低于这个值即亏损 |

**保本 ROI 怎么用**：如果你的保本 ROI 是 2.5，实际广告 ROI 只有 2.0，说明**卖得越多亏得越多**——这时候该做的是优化转化率与客单价，而不是继续加预算。

### 3.3 判定档位

| 毛利率 | 判定 | 说明 |
|---|---|---|
| ≥ 25% | 可做 | 有空间应对广告与退货波动 |
| 15% - 25% | 谨慎 | 薄利，需压成本或提价 |
| 0 - 15% | 不建议 | 抗风险能力差，一波动就亏 |
| ≤ 0 | 亏损 | 不要上架 |

**附加红线**：实际广告 ROI 必须高于保本 ROI；保本 ROI 高于 4 说明毛利空间对广告过于敏感，放量要谨慎。

## 四、参数取值口径（这步填错，算出来就是假的）

| 参数 | 取值口径 | 常见区间 |
|---|---|---|
| 汇率 | 按结算周期的实际汇率，**不要长期用旧汇率** | 随行就市 |
| 头程单价 | 以货代实时报价为准 | 海运约 8-20 元/kg；空运约 25-45 元/kg；快递约 45-70 元/kg |
| 体积重除数 | 空运/快递常用 6000，部分渠道 5000 | 以渠道规定为准 |
| FBA 配送费 | **按平台最新费率表**，注意尺寸段跳档 | 随尺寸与重量段变化 |
| 平台佣金率 | 按类目查平台费率 | 多数 8%-15% |
| 广告占比 ACOS | 新品期可高于稳定期 | 稳定期 10%-20% 较为常见 |
| 退货率 | 按类目实际水平 | 3C 约 5%-10%；家居约 5%-8%；服装 15%-25% |
| 退货损耗率 | 退回件无法二次销售的比例 | 0.3-0.6（视品类与是否可翻新） |
| 仓储费 | 按月体积与存放时长分摊 | 旺季费率更高 |

**最容易漏掉的三项**：头程的体积重、退货损耗、长期仓储与旺季加价。只算采购价和售价的「毛利」，是新手最典型的算术错误。

## 五、选品判断维度（利润之外）

| 维度 | 看什么 | 不宜做的信号 |
|---|---|---|
| 客单价 | 太低覆盖不了固定成本，太高转化难 | 客单价低于 15 美元且体积不小 |
| 体积重量 | 泡货头程与仓储成本高 | 体积重远大于实重 |
| 季节性 | 是否只有一两个月能卖 | 季节性极强且备货周期长 |
| 复购 | 是否有复购与关联销售 | 一次性且无配件 |
| 竞争度 | 头部集中度、评价数门槛 | 头部评价数上万且价格战激烈 |
| 合规 | 认证、专利、敏感属性 | 需认证而未认证、有专利风险 |
| 供应链 | 是否有稳定供应与品质控制 | 单一供应商、品质波动大 |

**先算利润，再看维度。** 利润过不了线的产品，其他维度再好也不用继续看。

## 六、脚本用法

```bash
python scripts/profit_calc.py --file product.json --out 利润核算.md
python scripts/profit_calc.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：售价、汇率、采购价、重量尺寸、头程、FBA 费、佣金率、ACOS、退货率等 |
| `--text` | 直接给 JSON 字符串 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检 |

输入 JSON 示例：

```json
{
  "title": "厨房收纳架",
  "price_usd": 29.99,
  "fx": 7.15,
  "cost_cny": 38,
  "weight_kg": 0.45,
  "length_cm": 20,
  "width_cm": 15,
  "height_cm": 8,
  "freight_mode": "air",
  "freight_rate_cny_per_kg": 35,
  "vol_divisor": 6000,
  "fba_fee_usd": 5.75,
  "commission_rate": 0.15,
  "storage_cny": 3,
  "acos": 0.18,
  "return_rate": 0.08,
  "return_loss_rate": 0.5,
  "other_cny": 2
}
```

脚本输出：七项成本明细表、净利润、毛利率、不含广告毛利率、保本广告占比、保本 ROI、实际 ROI、保本售价、四档判定，以及泡货提醒、广告 ROI 低于保本线提醒、退货率偏高提醒。

> 脚本按你填的参数做静态单件核算，**未含退仓、销毁、长期仓储加价、促销折让与汇兑损失**；费率与汇率以最新数据为准。

## 七、人工确认清单（这步不能省）

- [ ] 头程单价以货代**实时报价**为准，不是三个月前的价
- [ ] FBA 配送费按**平台最新费率表**核对，尺寸段变化会跳档
- [ ] 退货率按**类目实际水平**取值，不是拍脑袋
- [ ] 已做侵权排查（外观专利、商标、版权）
- [ ] 已确认类目所需的认证与检测（儿童用品、电器、无线、食品接触等）
- [ ] 已确认产品不属于平台禁售或限制类目
- [ ] 已做敏感分析：采购价 +10%、运费 +30%、ACOS +5 个点，各还剩多少
- [ ] 汇率按结算周期复核过
- [ ] 长期仓储、旺季加价、退仓销毁的可能成本已考虑

## 八、最常见的坑

**坑一：只算采购价和售价，就以为有 60% 毛利。**
错误做法：(售价 - 采购价) ÷ 售价，算出「毛利很高」就上架。正确做法：必须把头程、FBA 配送费、平台佣金、广告、仓储、退货损耗全部计入。这几项加起来通常吃掉售价的 40%-60%。

**坑二：头程按实重算，不按体积重。**
错误做法：产品 0.45 kg，按 0.45 kg 算运费。正确做法：计费重 = max(实重, 体积重)，体积重 = 长×宽×高 ÷ 6000。一个 30×30×30 的箱子体积重就有 4.5 kg，运费差十倍。**泡货是选品阶段就该发现的，不是发货后才发现。**

**坑三：不知道自己的保本 ROI，广告一直加预算。**
错误做法：看广告 ROI 有 2.5 觉得还行，继续加预算。正确做法：先算保本 ROI。保本 ROI 是 3.0 而实际只有 2.5，说明广告投入正在吃掉利润，卖得越多亏得越多。

**坑四：退货率按 3% 算。**
错误做法：用「感觉不高」的退货率做测算。正确做法：按类目实际水平取，3C 约 5%-10%、家居约 5%-8%、服装 15%-25%。服装类按 3% 算，测算结果和实际情况会差出一整个毛利率档位。

**坑五：用旧汇率和旧费率做长期测算。**
错误做法：汇率和 FBA 费率还是去年填的。正确做法：汇率与平台费率都会变动，且 FBA 费率按尺寸段跳档——包装改一厘米，可能就跨档了。定期复核。

**坑六：没做合规排查就打样下单。**
错误做法：看到产品好卖，直接下单生产。正确做法：外观专利、商标、类目认证三项必须先查。侵权被投诉的代价是下架、资金冻结甚至封店，远大于省下的检索时间。**贴牌不等于免责。**

**坑七：只看毛利率，不看现金流。**
错误做法：毛利率 25% 觉得能做，就备三个月的货。正确做法：跨境的资金占用周期长（备货 + 头程 + 在仓 + 回款），毛利率要覆盖资金成本与滞销风险。新手备货宁少勿多。

**坑八：为了过利润线去压采购价，压掉了品质。**
错误做法：算出来毛利不够，就把采购价压 20%。正确做法：压价往往换来品质下降，退货率上升后利润反而更差。先算一下「退货率上升 5 个点，利润还剩多少」，再决定压不压价。

## 九、边界与免责

- 本技能提供利润核算的公式、取值口径与判定档位，**不提供平台实时费率、实时汇率与实时广告数据**
- FBA 配送费、平台佣金、仓储费率**以平台最新费率表为准**；头程单价**以货代实时报价为准**
- 本核算为**单件静态口径**，未含退仓、销毁、长期仓储加价、促销折让、汇兑损失与资金成本
- **不承诺任何产品一定能盈利**，市场表现受竞争、需求、季节、平台政策影响极大
- 专利、商标与认证问题**以专业检索结果与法律意见为准**，本技能只提示排查项，不构成法律意见
- 不提供任何规避平台规则、税务申报或监管要求的操作方案
