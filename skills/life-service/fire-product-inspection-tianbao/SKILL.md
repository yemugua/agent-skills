# 消防产品现场检查判定（fire-product-inspection）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《消防产品监督管理规定》（公安部令第122号）与 CCCF 认证要求，生成消防产品现场检查清单：灭火器/防火门/消防应急灯具/防火涂料等产品的市场准入、标识流向、现场判定与不合格处置。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 消防产品检查
- 消防产品现场判定
- 消防产品真实性
- CCCF核查
- 灭火器检查

## 三、工作流
1. 核对产品市场准入与强制性认证（CCCF）
2. 查验产品标识、合格证与流向信息
3. 按标准现场判定外观与功能
4. 记录不合格与假冒伪劣线索
5. 处置（停用/更换/上报）与留痕

## 四、核心内容（检查清单与判定）
《消防产品监督管理规定》要求消防产品须符合市场准入规则并具备强制性认证；现场检查应核对标志、证书与实物一致性，发现不合格或假冒产品须停用并上报。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含市场准入与强制性认证核查 | 准入 |
| Q2 | FAIL | 未含产品标识与流向查验 | 标识 |
| Q3 | WARN | 未含现场外观/功能判定 | 判定 |
| Q4 | FAIL | 未含不合格记录 | 记录 |
| Q5 | WARN | 未含处置与上报留痕 | 处置 |

> 脚本 `fire-product-inspection_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python fire-product-inspection_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python fire-product-inspection_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
