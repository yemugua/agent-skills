# 企业微信私域运营合规核查

## 用途

对企业微信私域运营做逐项合规核查，定位阻断项与风险项，给出可落地的整改清单。适合：

- 搭建或复盘私域加粉/群发/朋友圈运营流程前
- 不确定加粉方式、群发频次、诱导分享玩法是否踩线
- 配置会话存档、离职继承前确认合规要点
- 账号被限制功能/封号后的整改定位

## 输入

一份 Markdown 采集表（表格 `| 字段 | 值 |` 或 `字段：值` 冒号行均可），字段见
`templates/采集表.md`。核心字段：

| 字段 | 说明 |
|------|------|
| 企业主体类型 | 企业 / 个体工商户 / 其他 |
| 企业微信是否认证 | 已认证 / 未认证（未认证能力受限） |
| 是否配置客户联系功能 | 私域运营依赖外部联系人能力 |
| 主要加粉方式 | 活码/门店物料/广告 等合规渠道；或 爬虫/购买名单/自动加人 等违规特征 |
| 是否使用外挂或自动化工具 | 自动加人/自动群发/爬虫/机器人 |
| 是否购买或爬取客户名单 | 买卖、非法获取公民个人信息 |
| 是否做诱导分享或裂变活动 | 红包裂变/集赞/砍价/助力/分享解锁 |
| 是否高频群发 | 客户群发与客户朋友圈频次 |
| 是否推送金融医疗等需资质内容 | 荐股/荐基/保险/医疗健康 |
| 是否持有对应推送资质 | 持牌主体与对应资格 |
| 是否配置离职继承与客户分配 | 客户资产保护 |
| 是否使用会话存档功能 | 须事先告知员工与客户 |
| 会话存档是否告知员工与客户 | 存档前告知与同意 |
| 客户信息使用是否告知并取得同意 | 处理目的/方式/范围 + 退订 |
| 是否收到过投诉或账号限制 | 骚扰/欺诈/诱导分享投诉 |

## 输出

多段 Markdown 报告：

1. **结论摘要**：总体结论（通过 / 有风险 / 不通过）+ 阻断/风险计数 + 处置建议
2. **分项核查**：账号与客户联系功能 / 加粉合规 / 诱导分享与裂变 / 群发与朋友圈 / 推送内容资质 / 客户数据与会话存档 / 投诉与处罚记录
3. **阻断项与风险/待办**：逐条列出，阻断项注明后果（功能限制/封号/法律风险）
4. **整改操作指引**：标准 8 步私域合规清单
5. **边界与纪律**：依据公开规范整理，不替代官方规范与法律意见

## 使用

```bash
python3 scripts/wecom_private_compliance_check.py <采集表.md>
```

退出码：`0` 正常；`2` 未读取到有效字段（打印待补正提示）。

## 判定口径

- **不通过（阻断）**：使用外挂/自动化工具、购买或爬取客户名单、未配置客户联系功能、开展诱导分享/裂变、推送金融/医疗等需资质内容无资质、使用会话存档未告知员工与客户。
- **有风险**：企业微信未认证、高频群发、未配置离职继承、客户信息使用未告知、有过投诉或账号限制。
- **通过**：全部核查项满足。

## 红线（本技能不会做的）

- 不教唆使用外挂、购买/爬取名单或绕开平台做违规加粉。
- 不替代企业微信官方规范与审核结论，不构成法律意见。
