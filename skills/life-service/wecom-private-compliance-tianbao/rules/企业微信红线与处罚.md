# 企业微信红线与处罚映射

> 违规后果以企业微信官方规则为准；以下为常见情形与处置口径，用于核查报告的风险提示与整改优先级。

## 一、直接封号/限制功能（阻断级）

| 情形 | 后果 | 备注 |
|------|------|------|
| 使用外挂/自动化/爬虫工具 | 限制功能、封禁账号 | 情节严重连带主体下其他账号 |
| 购买或爬取客户名单 | 功能限制/封号 + 可能涉刑 | 侵犯公民个人信息罪 |
| 诱导分享/裂变（红包裂变/集赞/砍价/助力） | 链接拦截、功能限制、封号 | 违反外部链接管理规范 |
| 推送金融/医疗需资质内容无资质 | 内容下架、功能限制 | 持牌要求 |
| 会话存档未告知员工与客户 | 存档内容无效、合规风险 | 个人信息保护要求 |

## 二、风险/待办（建议级）

| 情形 | 后果 | 备注 |
|------|------|------|
| 企业微信未认证 | 成员/客户联系能力受限 | 先认证 |
| 高频群发 | 投诉上升、功能受限 | 控制频次 |
| 未配置离职继承 | 客户流失/纠纷 | 配继承规则 |
| 客户信息未告知 | 合规风险、投诉 | 告知+退订 |
| 有投诉/限制记录 | 影响账号信用 | 整改+响应机制 |

## 三、整改优先级

1. 停外挂、销毁违规名单（刑事与封号风险最高）。
2. 取消诱导分享玩法（封号风险）。
3. 确认内容资质与推送权限。
4. 会话存档告知与留存。
5. 认证、离职继承、群发频次、信息告知补全。
