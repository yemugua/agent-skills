# 雇主品牌（employer-branding）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：生成雇主品牌清单：雇主价值主张（EVP）、目标人才画像、传播渠道与内容、候选人体验、效果度量（投递量/认可度/留存）。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 雇主品牌
- ERB
- EVP
- 人才吸引
- 雇主价值主张
- 品牌传播
- 候选体验

## 三、工作流
1. 明确雇主价值主张（EVP）
2. 刻画目标人才画像
3. 选择传播渠道与内容（社媒/官网/员工故事）
4. 优化候选人体验（面试/拒信/入职）
5. 度量效果（投递量/认可度/留存）

## 四、核心内容（检查清单与判定）
雇主品牌以 EVP 为核心，向目标人才传递差异化价值；通过多渠道内容与良好候选体验提升吸引力与留存。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未明雇主价值主张（EVP） | 主张 |
| Q2 | WARN | 未含目标人才画像 | 画像 |
| Q3 | FAIL | 未含传播渠道与内容（社媒/官网/员工故事） | 传播 |
| Q4 | WARN | 未含候选人体验（面试/拒信/入职） | 体验 |
| Q5 | FAIL | 未含效果度量（投递量/认可度/留存） | 度量 |

> 脚本 `employer-branding_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python employer-branding_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python employer-branding_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
