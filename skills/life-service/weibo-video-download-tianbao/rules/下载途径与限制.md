# 微博视频下载与保存：途径、限制与合规边界

## 一、先判定：能不能下

| 归属类别 | 能否下载 | 允许的用途 |
| --- | --- | --- |
| 自有作品 | 可以，优先用原始导出文件 | 任意 |
| 已授权素材 | 可以 | 仅限授权范围内 |
| 作者开放了保存 | 可以，走官方途径 | 个人留存，**不得二次分发** |
| 第三方作品（未授权） | **不建议下载** | 不应用于任何对外场景 |

技术上能不能下载，和法律上能不能用，是两回事。

## 二、途径，按稳定性排序

| 途径 | 操作要点 |
| --- | --- |
| 官方保存 | 视频右下角更多 → 保存视频，取决于博主是否开放该权限。 |
| 微博创作中心 | 登录**自己的账号**管理已发布视频，仅限自有内容。 |
| 通用命令行工具 | 需 Python + ffmpeg。微博视频常来自外链源，工具需跟随源站适配更新，稳定性一般。 |

## 三、本平台的真实限制

- 微博视频**大量使用外部源**（历史上多为秒拍），实际播放地址常常指向第三方，这也是通用工具容易失效的原因。
- 微博视频普遍清晰度偏低，源本身压缩较重，下载无法提升画质。
- 微博故事的时效性短，过期后无法访问。
- 私密微博、付费内容不属于可下载范围。

## 四、画质与水印

- 微博视频源头清晰度普遍不高，且经过平台转码，下载得到的最好效果通常就是页面所见清晰度。
- 水印含博主昵称与微博标识，属平台自动叠加。

## 五、合规红线

1. 不得去除作者署名后二次分发
2. 不得将他人作品搬运至自己的账号（含剪辑、配音后发布）
3. 不得下载或传播私密账号、付费内容
4. 受版权或 DRM 保护的内容不支持下载，也不提供任何破解方法
5. 商用前必须取得书面授权
6. 批量高频抓取可能违反平台服务协议，导致账号受限
