# 水电验收

## 1. 硬边界表

| 能做 | 不能做 |
|---|---|
| 给打压测试压力/压降判定口径 | 替代持证水电工/监理 |
| 给绝缘电阻（摇表）合格线 | 出具安全合格法定结论 |
| 给回路、接地、线径检查清单 | 做电路带电作业指导 |
| 给必须转交专业的红线项 | 处理施工合同纠纷 |

本技能只做检查与判断清单，不做法律定性。带电检测必须由持证人员操作。

## 2. 什么时候用

| 用户说法 | 用本技能 |
|---|---|
| 「打压测试怎么看」 | 用 |
| 「电线摇表多少合格」 | 用 |
| 「回路怎么查」 | 用 |
| 「这合不合规」 | 不用，转专业 |

## 3. 完整工作流

1. 水路：关闭总阀，打压至 0.8MPa，稳压 30 分钟看压降。
2. 电路：断电后摇表测绝缘电阻，查回路标识与接地。
3. 查线径线管、接头、下水坡度。
4. 按 `rules/acceptance-rules.md` 逐项判定。
5. 标记「需专业确认」项。
6. 对照人工确认清单核对。

## 4. 核心规则

先读 `rules/acceptance-rules.md`：打压测试压力与压降合格线、绝缘电阻合格值、回路/接地/线径要求、红线项与判定口径。

## 5. 脚本用法

```
python scripts/check.py --file 水电验收.json
python scripts/check.py --selftest
```

`--file` 含 pressure_mpa、pressure_drop、insulation_mohm、grounded、circuits_ok 等字段。

## 6. 人工确认清单

- [ ] 打压 0.8MPa 稳压 30 分钟压降 ≤0.05MPa
- [ ] 绝缘电阻 ≥0.5MΩ（建议 ≥1MΩ）
- [ ] 各回路标识清晰、对应正确
- [ ] 接地可靠、漏保有效
- [ ] 线径符合回路负载（插座 2.5²、空调用 4²）
- [ ] 是否有「需专业确认」红线项

## 7. 最常见的坑

1. 打压只打不稳压，压降看不出。
2. 压降超 0.05MPa 仍签字，埋渗漏隐患。
3. 绝缘电阻不测，带电隐患未发现。
4. 回路标识错乱，日后维修抓瞎。
5. 线径不够（如空调用 2.5²），发热风险。
6. 接地虚接，漏保不跳。
7. 下水坡度不足，长期积水返味。

## 8. 边界与免责

本技能为自查清单，不替代持证水电工/监理。绝缘电阻、带电检测须由专业人员操作。本技能不做法律定性，施工权责请咨询专业人士。
