# 数据备份习惯与有效性核查

「我备份了」和「我能恢复回来」，中间隔着一次你从没做过的恢复演练。硬盘会坏、文件会损坏、账号会失效、格式可能不认——备份是一个没被验证过的承诺，只有真的取回来打开一次，才知道它值不值钱。

这个技能按 3-2-1 原则逐项核查备份现状：3 份副本、2 种介质、1 份异地。每一项都给出达标口径和不达标的典型形态，比如「同一台电脑上的两个文件夹只算一份」「全都在家里，失窃或火灾一起没」。脚本会读入你填的现状，按严重度排出缺口并给出补齐顺序建议。

真正拉开差距的是那份假备份坑清单：把同步当备份（云端删了本地一起没）、移动硬盘插上没跑完就拔、备份软件默认没开自动、历史版本被按天覆盖、备份目录被定期清理脚本当成垃圾一起扫掉。每一条都配了确认方法，你可以一条条对着查。还会给到一份最小可行恢复演练方案和备份检查表模板，按季度执行即可。

另外还准备了备份方式对比表（云盘、移动硬盘、NAS、电脑自动备份各自的自动性、异地性和多版本能力）、加密与口令管理规则，以及离职换机的数据交接清单——最后这份常被忽略，但工作衔接不上往往不是数据丢了，而是账号没交出去。

典型用法：把副本数、介质种类、异地、自动、演练过、加密这几项填进 JSON 跑一遍，看缺口排序；或者直接问「云盘算不算备份」「同步和备份差在哪」「怎么确认我的备份真的能用」。

边界要说清楚：本技能只做核查与方案设计，不代你访问、读取或传输任何数据，也不提供加密破解；不涉及他人隐私、公司核心资产或受监管约束的数据；介质选择和投入规模由你根据实际情况决定，本技能不做产品推荐和价格判断。
