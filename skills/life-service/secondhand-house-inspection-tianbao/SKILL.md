# 二手房验房

## 1. 硬边界表

| 能做 | 不能做 |
|---|---|
| 给分区检查清单 | 替代专业验房师/机构 |
| 给缺陷判定与严重程度口径 | 做法律效力定性（如「构成违约」） |
| 给必须转交专业人士的项 | 出具司法鉴定报告 |
| 给渗漏/空鼓等现场判断方法 | 处理产权/合同纠纷 |

本技能只做检查与判断清单，不做法律定性。涉及合同与权责，请咨询专业人士。

## 2. 什么时候用

| 用户说法 | 用本技能 |
|---|---|
| 「收房验房看什么」 | 用 |
| 「卫生间怎么查漏」 | 用 |
| 「墙面空鼓怎么看」 | 用 |
| 「这算不算违约」 | 不用，转专业 |

## 3. 完整工作流

1. 准备工具：手电、空鼓锤、试电笔、水桶、卷尺、纸笔。
2. 按 `rules/inspection-rules.md` 分区逐项查。
3. 记录每处缺陷位置与严重程度。
4. 对渗漏、电路、结构类问题标记「需专业确认」。
5. 汇总成验收单，区分「可收房小修」与「须整改后收」。
6. 对照人工确认清单核对。

## 4. 核心规则

先读 `rules/inspection-rules.md`：分区清单（门/墙地/门窗/厨卫/水电/管道）、缺陷判定口径、严重程度分级、必须转交专业的红线项。

## 5. 脚本用法

```
python scripts/check.py --file 验房记录.json
python scripts/check.py --selftest
```

`--file` 含各分区是否检查、缺陷项列表与严重程度。

## 6. 人工确认清单

- [ ] 入户门闭合、锁具、猫眼是否完好
- [ ] 墙面地面空鼓、裂缝、平整度
- [ ] 门窗开启顺畅、密封、玻璃完好
- [ ] 厨卫防水与楼下渗漏痕迹
- [ ] 强电弱电通电、回路、接地
- [ ] 给排水通畅、无渗漏
- [ ] 是否有「需专业确认」红线项

## 7. 最常见的坑

1. 只白天看房，漏掉夜间采光与漏水。
2. 不看顶楼/边户外墙渗水痕迹。
3. 忽略下水道堵塞，入住才发现问题。
4. 空鼓用敲代替，漏掉大面积空鼓。
5. 电路只试灯不试漏电保护。
6. 把结构性裂缝当普通裂缝，延误处理。
7. 不留存照片与记录，后续无凭证。

## 8. 边界与免责

本技能为自查参考清单，不替代专业验房。结构安全、电路隐蔽工程等建议由持证人员确认。本技能不做法律效力定性，合同权责请咨询专业人士。
