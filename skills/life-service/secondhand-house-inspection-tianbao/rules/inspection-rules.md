# 二手房验房规则库

本文件是验房判断的核心资产，先读再做判断。本技能只做检查与判断清单，不做法律定性。

## 一、分区检查清单

| 分区 | 检查项 | 方法 |
|---|---|---|
| 入户门 | 闭合顺畅、锁具、猫眼、门框缝隙 | 反复开合、钥匙试锁 |
| 墙面地面 | 空鼓、裂缝、平整、起砂 | 空鼓锤敲、目测、靠尺 |
| 门窗 | 开启、密封、玻璃裂纹、五金 | 开合、纸条测密封 |
| 厨卫 | 防水、瓷砖、吊顶、楼下渗漏痕迹 | 看水渍、问物业 |
| 电路 | 通电、回路、接地、漏保 | 试电笔、按漏保按钮 |
| 给排水 | 通畅、渗漏、水压 | 倒水试流、看接口 |

## 二、缺陷严重程度分级

| 等级 | 含义 | 处理建议 |
|---|---|---|
| 轻微 | 不影响使用，可收房后小修 | 记录，收房后处理 |
| 一般 | 需施工修复，但不危及安全 | 协商整改或折价 |
| 严重 | 影响安全/重大使用 | 须整改后再收房 |

## 三、红线项（须转交专业人士确认）

- 结构性裂缝（贯穿、斜向、随梁柱延伸）。
- 电路隐蔽工程无法现场判定者。
- 疑似渗漏至楼下且责任不清。
- 承重墙/梁柱损伤。
- 燃气管道改动不明。

以上不建议个人下结论，应请持证验房师或相关专业确认。

## 四、常见不合格项与判定

| 现象 | 判定 | 为什么 |
|---|---|---|
| 墙面空鼓率 >5% 单面 | 一般 | 易脱落需返工 |
| 顶棚水渍/起皮 | 严重（疑渗漏） | 须查水源与楼下 |
| 门窗无法闭合 | 一般 | 影响使用与安全 |
| 电路无接地/漏保失效 | 严重 | 触电风险 |
| 下水道堵塞 | 一般/严重 | 影响使用 |
| 结构性裂缝 | 红线 | 转专业确认 |

## 五、记录要求

- 每处缺陷拍照定位。
- 标注分区、位置、严重程度。
- 汇总成验收单，区分「可收房小修」与「须整改后收」。
