# 环境风险分级管控（env-risk-grading）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《企业突发环境事件风险分级方法》与环境影响评价要求，生成环境风险分级清单：风险源识别、分级标准（重大/较大/一般）、防控措施、应急预案、监测与预警。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 环境风险
- 风险分级管控
- 突发环境事件
- 环境风险源
- 环保风险

## 三、工作流
1. 识别环境风险源（危废/化学品/废水/废气）
2. 按物质量与影响划分等级（重大/较大/一般）
3. 制定分级防控措施
4. 配套突发环境事件应急预案
5. 建立监测与预警机制

## 四、核心内容（检查清单与判定）
《企业突发环境事件风险分级方法》依据涉险物质数量、敏感程度等划分风险等级；不同等级对应不同的防控措施与应急准备要求。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含环境风险源识别 | 辨识 |
| Q2 | FAIL | 未含分级标准（重大/较大/一般） | 分级 |
| Q3 | WARN | 未含分级防控措施 | 防控 |
| Q4 | FAIL | 未含突发环境事件应急预案 | 预案 |
| Q5 | WARN | 未含监测与预警 | 监测 |

> 脚本 `env-risk-grading_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python env-risk-grading_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python env-risk-grading_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
