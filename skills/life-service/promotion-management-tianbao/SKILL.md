# 晋升管理（promotion-management）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据晋升管理实践，生成清单：晋升通道与职级标准、晋升条件与年限、评审流程与评委构成、公示与申诉机制、晋升后跟踪与反馈。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 晋升管理
- 晋升机制
- 职级晋升
- 晋升评审
- 晋升标准

## 三、工作流
1. 明确晋升通道与职级标准
2. 设定晋升条件与年限
3. 设计评审流程与评委构成
4. 落实公示与申诉机制
5. 做好晋升后跟踪与反馈

## 四、核心内容（检查清单与判定）
晋升管理须标准清晰、流程公正并设申诉渠道；评审后应跟踪新岗位胜任情况并反馈，避免一升了之。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含晋升通道与职级标准 | 标准 |
| Q2 | FAIL | 未含晋升条件与年限 | 条件 |
| Q3 | WARN | 未含评审流程与评委构成 | 评审 |
| Q4 | FAIL | 未含公示与申诉机制 | 公示 |
| Q5 | WARN | 未含晋升后跟踪与反馈 | 跟踪 |

> 脚本 `promotion-management_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python promotion-management_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python promotion-management_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
