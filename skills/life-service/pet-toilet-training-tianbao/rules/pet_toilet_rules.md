# 宠物定点排便：疾病信号、如厕点配置与训练剂量

生成训练方案或排查建议前，**必须先读本文件**，不要凭印象写。

---

## 一、疾病信号与兽医红线（训练前逐条过）

### 1.1 立即就医（不要先训练）

| 信号 | 可能指向 | 紧迫度 |
|---|---|---|
| 蹲很久尿不出、腹部绷紧、频繁舔生殖器、叫唤 | 尿闭/尿路阻塞（公猫高发） | **急症，立即就医** |
| 尿中带血、尿色发深、尿味刺鼻 | 膀胱炎、结石、感染 | 24 小时内 |
| 尿频、每次只尿一点、在多个点位少量尿 | 膀胱炎、结石刺激 | 24 小时内 |
| 完全不在盆里尿，且尿量很大、饮水明显增多 | 肾病、糖尿病、甲亢、库欣 | 48 小时内 |
| 腹泻超过 24 小时、带血带黏液、腥臭 | 寄生虫、感染、食物不耐受 | 24 小时内 |
| 腹泻伴呕吐、精神沉郁、不吃 | 需排除细小、猫瘟等 | **当日就医** |
| 排便疼痛、弓背、肛周红肿、便里有虫体 | 肛囊炎、寄生虫、便秘 | 48 小时内 |
| 3 月龄内幼犬幼猫持续腹泻或呕吐 | 幼龄脱水风险高 | **当日就医** |
| 老年（7 岁以上）新出现的失禁、找不到盆、夜间叫唤 | 认知退化、慢性肾病 | 本周内 |
| 绝育后突然开始喷尿标记 | 泌尿问题优先于行为问题 | 48 小时内 |

### 1.2 可以先自查观察（无上述信号时）

- 排泄形态正常（成形、颜色正常、无血无黏液）
- 精神、食欲、饮水、体重无明显变化
- 乱拉位置相对固定，多发生在无人看管时
- 幼龄宠物（8 周 - 6 月龄）在学定点阶段

满足以上四条，才进入训练流程。

### 1.3 区分「行为性」与「病理性」的四问

1. **是突然发生的还是渐进的？** 突然 → 偏向病理；渐进 → 偏向环境/行为
2. **排泄形态有没有变？** 有变（稀、血、频）→ 病理优先
3. **是不是只在特定表面/位置？** 猫尿在软物（床、衣服、购物袋）→ 常见于膀胱炎或应激；狗在垂直面喷尿 → 标记行为
4. **有没有伴随环境变化？** 搬家、装修、新成员、换砂、主人出差 → 应激相关

## 二、如厕点配置标准

### 2.1 猫砂盆（猫数 = n）

| 项目 | 标准值 | 不达标后果 |
|---|---|---|
| 盆数 | n + 1，最少 2 个 | 守盆、拒绝使用 |
| 盆长 | ≥ 猫体长（不含尾）× 1.5 | 转身踩到排泄物 |
| 入口高度 | 幼猫/老猫/术后 ≤ 10 cm | 抬腿困难，就近解决 |
| 砂深 | 5-7 cm（结团砂） | 刨不动、埋不住 |
| 与食盆距离 | ≥ 1.5 m，且不在同一角落 | 拒绝靠近 |
| 位置 | 安静、2 个以上逃生方向、远离洗衣机与门铃 | 应激后永久弃用 |
| 清理频次 | 每天 1-2 次铲；整盆换砂按砂种 2-4 周 | 换地方拉 |
| 分布 | 多层楼每层至少 1 个 | 来不及跑 |

### 2.2 猫砂类型对照

| 砂种 | 脚感 | 优点 | 缺点 | 更换方式 |
|---|---|---|---|---|
| 膨润土结团砂 | 细沙，最接近自然 | 猫接受度最高 | 粉尘、重、不可冲厕 | 整盆 2-4 周 |
| 豆腐/玉米砂 | 颗粒偏粗 | 可冲厕、低粉尘 | 部分猫拒用、易发霉 | 整盆 2-3 周 |
| 混合砂（膨润土+豆腐） | 居中 | 接受度与可冲性折中 | 成本略高 | 整盆 3-4 周 |
| 水晶砂（硅胶） | 硬颗粒，脚感差 | 更换频次低 | **很多猫拒用**，尿液积底难判断尿量 | 按说明 3-4 周 |
| 松木砂 | 木屑颗粒 | 便宜、味道遮盖好 | 接受度差异大 | 按说明 |

**换砂必须渐进**：新砂按 25% → 50% → 75% → 100% 混兑，每档 7 天。一次性全换是猫「突然不用盆」的头号原因。

### 2.3 狗厕所 / 尿垫（室内方案）

| 项目 | 标准 | 说明 |
|---|---|---|
| 憋尿时长 | 月龄 ≈ 小时数（最多 +1 小时） | 3 月龄 ≈ 3 小时，6 月龄 ≈ 6 小时 |
| 如厕点面积 | 至少能让狗原地转两圈 | 太小会踩到边缘不肯用 |
| 与窝的距离 | 尽量隔开，不要贴边 | 狗天性不在窝边排泄 |
| 尿垫固定 | 用尿垫托盘或压边，避免被叼走撕碎 | 撕碎吞食有肠梗阻风险 |
| 过渡 | 室内定点 → 逐步移到门口 → 移向户外 | 一次性撤掉尿垫必然反弹 |

## 三、训练剂量与时机（狗）

### 3.1 必抓的四个时机

| 时机 | 间隔 | 动作 |
|---|---|---|
| 睡醒 | 立刻 | 抱/引到如厕点 |
| 饭后 | 15-30 分钟 | 引到如厕点，等 5 分钟 |
| 大量喝水后 | 20-40 分钟 | 引到如厕点 |
| 激烈玩耍后 | 立刻 | 引到如厕点 |

**5 分钟没拉**：平静带回围栏，不要在外面放风（放风后就忘了要拉），10-15 分钟后再来一次。

### 3.2 奖励口径

- **时间窗**：拉完 3 秒内给奖励，超过 5 秒狗关联不上
- **奖励物**：平时吃不到的高价值零食，一粒即可，不要喂饱
- **口令**：固定一个短口令（如「上厕所」），只在它正在拉的时候说一次，不要重复喊
- **退出机制**：连续 2 周稳定后，奖励从「每次给」过渡到「随机给」，不要突然全停

### 3.3 拉错时的处理（不打不骂）

1. **当场发现**：用一个中性声音打断（拍手、唤名），立刻引到如厕点，拉对了照样奖励
2. **事后发现**：安静收拾，不说话、不看它、不拖它过来看，清理完正常互动
3. **禁止动作**：打、骂、按鼻子蹭尿、关禁闭、拖到排泄物前训斥
4. **原因回溯**：是不是超过憋尿时长？是不是刚换环境？是不是没人在家？

## 四、除味口径（这步做错，训练全白费）

| 表面 | 处理 | 禁止 |
|---|---|---|
| 瓷砖、木地板（硬质） | 酶类/生物除味剂充分浸润，按说明停留 10-15 分钟，自然风干 | 84、氨水、漂白剂 |
| 地毯、床垫、沙发 | 先吸干表层，再浸润酶类除味剂，必要时拆洗或请专业清洗 | 蒸汽高温先烫（蛋白质固化） |
| 衣物、被褥 | 酶类预处理后常规洗涤，不要和别的衣物混洗 | 只用香水遮盖 |
| 猫抓板、纸箱 | 直接更换 | 反复清洗后留味 |

**验证方法**：处理完 24 小时后，用纸巾按压该处闻一下；人闻不到不代表宠物闻不到，猫的嗅觉阈值远低于人。反复在同一位置复发，基本就是除味没做干净。

**为什么不能用氨水**：尿液分解后产生氨味，氨水（及含氨清洁剂）的气味对宠物而言等同于「这里是可以拉的地方」，会主动强化错误点位。

## 五、特殊情形

| 情形 | 处理要点 |
|---|---|
| 多猫家庭 | 盆数 = 猫数 + 1，分散在不同房间；观察是否存在守盆，必要时加装猫门让弱势猫有专属盆 |
| 幼猫（8 周 - 4 月） | 浅盆、低入口、无香砂；饭后睡醒立刻放进盆里，让它自己出来 |
| 老年犬猫 | 低入口盆、就近增加点位；先排关节炎与认知退化 |
| 术后/病中 | 临时低边盆、勤清理；不要用带盖盆 |
| 寄养/搬家后 | 前 3 天先限制在小房间（含食盆水盆与砂盆），熟悉后再放开 |
| 新宠入户 | 新宠先隔离在小房间独立配置，7 天后再做气味交换与逐步接触 |
| 长期复发 | 回到排查顺序第 1 步，考虑转行为医师或做进一步检查 |

## 六、记录表模板（连续记 3 天）

| 日期 | 时间 | 宠物 | 地点 | 类型 | 形态 | 备注 |
|---|---|---|---|---|---|---|
| | | 猫/狗名 | 砂盆/客厅/床 | 尿/便 | 正常/稀/带血/量多 | 有无环境变化 |

**判读**：3 天内同一地点重复出现 → 除味或点位问题；地点分散且形态异常 → 疾病信号优先；只在无人时发生 → 训练与看管缺口。
