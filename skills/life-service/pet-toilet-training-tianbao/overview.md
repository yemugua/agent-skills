# 宠物定点排便训练与异常排查

## 你会得到什么

一套把「宠物乱拉乱尿」拆成两条线的处理口径：**先排除疾病，再谈训练**。

- **红线清单**：哪些症状必须立刻停训练去看兽医（公猫尿闭、血尿、持续腹泻、幼龄呕吐、老年失禁等），出现任一条，本技能不再输出训练方案。
- **七步训练流程**：定如厕点 → 定清理口径 → 抓时机 → 奖励 → 不惩罚 → 收窄空间 → 逐步放开，每步都给了判定标准。
- **配置标准**：猫砂盆数量（猫数+1）、尺寸（体长×1.5）、砂深（5-7cm）、位置禁忌；狗的憋尿时长（月龄≈小时数）与尿垫过渡顺序。
- **除味口径**：为什么不能用 84 和氨水，酶类除味剂怎么用，怎么做「人闻不到但宠物闻得到」的验证。
- **复发排查顺序**：先查病 → 查如厕点 → 查除味 → 查应激 → 查年龄 → 最后才加大训练强度。

## 典型用法

- 幼犬到家第一周，怎么安排围栏、尿垫和出门时机
- 猫突然不在盆里尿，判断该先看病还是先换砂
- 两只猫一个盆，谁在守盆、怎么加点位
- 狗在床上尿，解释「报复说」为什么不对，以及床垫该怎么除味
- 老猫乱拉，怎么区分关节疼、认知退化和单纯的行为问题

## 边界

不诊断疾病，不替代兽医检查与处方；不支持任何形式的打骂、按头蹭尿、关禁闭、长期禁水。训练效果因年龄、品种、既往经历与家庭环境差异很大，不承诺具体天数或成功率。血尿、尿闭、持续腹泻、呕吐、精神沉郁请立即就医。
