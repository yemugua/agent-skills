# 电商商品视频导出与竞品边界：常见失败与排查

报错信息请**粘贴原文**再对照。写成「下载失败了」没有排查价值，
写成 `HTTP Error 403` 或 `ffmpeg not found` 才能定位。

## 现象 → 原因 → 处理

| 现象关键词 | 原因与处理 |
| --- | --- |
| 防盗链 / 403 / referer | 商品视频多带防盗链，需携带来源信息，且限于自有商品使用。 |
| 体积超限 / 太大 / 上传失败 | 主图视频有时长与体积上限，超限需重新压缩后再上传。 |
| 竞品 / 同行 / 别人店铺 | 竞品视频不建议下载，用于模仿或搬运风险高，建议自行拍摄制作。 |
| 买家秀 / 评价视频 / 肖像 | 含他人肖像，二次商用前须取得书面授权，否则存在肖像权风险。 |
| 后台找不到 / 素材中心没有 | 确认登录的是该商品所属店铺账号，子账号可能无素材下载权限。 |

## 通用故障（各平台都可能遇到）

| 现象 | 处理 |
| --- | --- |
| 403 / 需要登录 / 机器人验证 | 触发反自动化校验：携带登录态或减少请求频率，不要高频重试 |
| 429 / 频繁 / 限流 | 降低请求频率、分批间隔重试 |
| 404 / 失效 / 不存在 | 链接失效或已删除：让对方重新生成分享 |
| 没有声音 / 无音轨 | ffmpeg 未安装或未合并轨：安装后用 `-f "bv*+ba/b"` 合并 |
| 解析失败 / 格式不支持 | 站点接口变动：把工具升级到最新版，而不是换工具 |
| 超时 / 连接失败 | 检查网络可达性后重试 |

## 排查顺序

1. 先确认网络能访问目标平台
2. 再确认目标内容是否属于可下载范围（回到归属判定）
3. 然后确认工具是最新版
4. 最后才怀疑链接本身

九成的「下载失败」卡在第 1 步和第 2 步，而不是工具坏了。
