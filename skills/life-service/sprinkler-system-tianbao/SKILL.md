# 自动喷水灭火系统核查（sprinkler-system）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《自动喷水灭火系统设计规范》GB 50084，生成自动喷水灭火系统核查清单：系统选型（湿式/干式/预作用）、喷头布置与间距、报警阀组、末端试水、水泵与供水、维护检测。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 自动喷水灭火系统
- 喷淋系统
- 喷淋头布置
- 报警阀组
- 末端试水

## 三、工作流
1. 确认系统选型与适用场所（湿式/干式/预作用）
2. 核查喷头布置、间距与障碍物净距
3. 检查报警阀组与水流指示器
4. 测试末端试水装置与联动
5. 核查水泵供水与定期维护检测

## 四、核心内容（检查清单与判定）
GB 50084 规定自动喷水灭火系统的选型、喷头布置、报警阀组与末端试水要求；系统应保持供水可靠并定期维保检测，确保火灾时有效动作。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含系统选型与适用场所 | 选型 |
| Q2 | FAIL | 未含喷头布置与间距核查 | 喷头 |
| Q3 | WARN | 未含报警阀组与水流指示 | 阀组 |
| Q4 | FAIL | 未含末端试水与联动测试 | 试水 |
| Q5 | WARN | 未含水泵供水与维保 | 维保 |

> 脚本 `sprinkler-system_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python sprinkler-system_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python sprinkler-system_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
