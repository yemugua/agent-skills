# 晕车处理与用药核查（motion-sickness-relief）

晕车不是「心慌」，是**前庭感受到的移动信息和眼睛看到的不一致**。理解这一点，就知道为什么有些办法只是缓解而不能解决。

这个技能做四件事：**讲机制** → **分方法真假** → **讲药物** → **划就医线**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 说明晕车的机制与成因 | ❌ 给出具体药物剂量 |
| 说明各类方法的实际局限 | ❌ 判断是否需要就医 |
| 说明药物类别与注意事项 | ❌ 替代医生或药师判断 |
| 说明儿童与孕妇的特别提示 | ❌ 给出适合所有人的用药建议 |
| 列出需要就医的情形 | ❌ 指导自行加减药量或延长疗程 |

**用量、频次与年龄限制一律以药品说明书和医嘱为准**，本技能只说明药物的类别与需要注意的事项，不写具体剂量数字。

**出现以下情况，停止自行处理并就医：**

- 晕车症状持续不缓解，或反复剧烈呕吐
- 伴随头痛、视物模糊、说话含糊、肢体麻木无力
- 出现胸闷、心悸、意识模糊
- 儿童高热伴随呕吐或精神状态差
- 孕妇晕车伴随出血、腹痛或胎动异常

## 二、机制说明（这一段决定后面所有判断）

**成因**：晕动症的基本原因是**前庭系统感受到的运动信息与视觉、本体感觉提供的信息不一致**。

| 场景 | 眼睛看到 | 前庭感受到 |
|---|---|---|
| 坐车看窗外 | 画面在移动 | 车在移动 |
| 坐车看手机 | 画面几乎静止 | 车在持续移动 |
| 坐船 | 随船晃动 | 持续晃动 |
| 骑车或跑步 | 自己控制的运动 | 同向运动 |

**关键结论**：**眼睛看到的和前庭感受到的越是「对不上」，越容易晕。** 这解释了为什么看手机比看窗外更容易晕。

## 三、方法有效性对照

**下面的对照要如实看，不要把「有点用」当成「有效」。**

| 方法 | 实际效果 | 局限说明 |
|---|---|---|
| **看窗外远处固定参照物** | 相对有效 | 让视觉与前庭信息趋于一致；只对轻中度有效，不能完全预防 |
| **座位靠前、面向行驶方向** | 相对有效 | 减少晃动方向与视野的不匹配 |
| **开窗通风** | 有限缓解 | 改善气味带来的不适感，但不解决信息不一致 |
| **清淡饮食、少食** | 有限缓解 | 减少胃部不适，**空腹反而可能更难受** |
| **分散注意力（看电影、聊天）** | **效果有限且可能更糟** | 把注意力固定在近距离静止目标上，**会加大视觉与前庭的不一致**，本身是加重因素 |
| **闻味道（香水、纸巾等）** | **基本无效** | 只是转移对恶心的注意力，不影响成因 |
| **嚼口香糖或吃东西** | 有限缓解 | 主要缓解恶心感，不解决成因 |
| **晕车贴** | 效果存在争议 | 成分与作用机制的说法较多，**实际效果因人而异，不能替代其他措施** |
| **提前服用晕车药** | 相对有效 | **需按说明书或医嘱提前服用**，是少数能作用于成因的手段之一 |
| **提前服药 + 选对座位 + 看窗外** | 相对有效 | 组合使用的效果通常优于任何单一手段 |

**核心口径**：**「转移注意力」这类方法本身可能就是加重因素，不是解法。** 把注意力放到近距离静止物体上，恰好放大了造成晕车的那种不一致。

## 四、常用药物的类别与注意事项

**按类别说明，不给剂量。剂量与频次以药品说明书和医嘱为准。**

| 类别 | 代表成分 | 需要注意 |
|---|---|---|
| **抗组胺类** | 常见为部分抗过敏药成分 | 可能出现嗜睡、口干；驾驶员是否可用需看说明书明确说明 |
| **抗胆碱类** | 常见为部分止吐药成分 | 可能出现口干、视物模糊、心率变化；部分人群不适用 |
| **其他止吐类** | 作用机制各异 | 各自注意事项不同，按说明书 |

**通用注意事项**：

- **驾驶员禁用与注意**：部分晕车药会影响判断力，**驾驶员是否能使用必须看说明书明确说明**，不能凭感觉
- **同乘人群注意**：服用后嗜睡、口干明显，同乘者自己开车或操作设备时要注意
- **提前服用**：多数需要提前服用才有效，临时发作时再吃往往来不及
- **不叠加使用**：同类药物不要同时服用
- **配伍注意**：正在服用其他药物时，先问医生或药师

**否定项提醒**：**「以前吃过没事」不是继续吃的理由。** 身体状况、正在服用的药物、年龄都会变化。

## 五、儿童与孕妇的特别提示

**儿童：**

- **不要直接用成人的剂量或成人的药**，儿童用药有专门的年龄限制与剂量
- 年龄越小越需要谨慎，**具体可用年龄以药品说明书为准**
- 儿童表达能力有限，晕车时往往表现为哭闹、脸色苍白、呕吐
- 儿童晕车常伴随出汗、乏力，呕吐后需要补充水分
- **孩子症状严重或持续不缓解要看医生**，不要自行反复用药

**孕妇：**

- **孕期用药必须先咨询医生**，这一点没有例外
- 晕车本身对孕妇的影响通常大于对普通乘客的影响
- 首选非药物措施：靠前座位、看窗外、清淡饮食、通风
- 伴随腹痛、出血、胎动异常时立即就医
- 不使用未曾与医生确认过的药物

## 六、出行前准备顺序

```
第 1 步  选座位：靠前、面向行驶方向、尽量靠中间少晃
第 2 步  出行前饮食清淡、别吃太饱也别空腹
第 3 步  需要时按说明书或医嘱提前服用晕车药
第 4 步  路上看窗外远处固定参照物，不看近距离屏幕
第 5 步  开窗通风，把注意力放在远处风景上
第 6 步  提前下车休息，不要硬撑到目的地
```

**顺序的意义**：前两步成本最低，第三步需要提前准备。**把注意力放到看窗外而不是聊天看电影，是最关键的一条。**

---

## 七、什么情况需要就医

| 情形 | 说明 |
|---|---|
| 症状持续不缓解 | 常规措施无效 |
| 反复剧烈呕吐 | 可能伴随脱水 |
| 伴随头痛、视物模糊、说话含糊 | 提示可能不只是晕车 |
| 伴随肢体麻木无力 | 需要排查其他原因 |
| 胸闷、心悸、意识模糊 | 需要立即就医 |
| 儿童高热伴随呕吐 | 可能是其他疾病 |
| 孕妇伴随腹痛或出血 | 需要立即就医 |

**以上任一情况出现时，不要按晕车继续处理，应尽快就医。**

## 八、脚本用法

```bash
python scripts/motion_sickness_check.py --symptoms "恶心,看手机更晕"
python scripts/motion_sickness_check.py --text "看手机,闻味道,提前服药" --out 建议.md
python scripts/motion_sickness_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--symptoms` | 逗号分隔的现象或已用方法 |
| `--group` | `child` / `pregnant` / `adult`，默认 `adult` |
| `--file` | 从 JSON 读（自动兼容带 BOM 的文件） |
| `--out` | 结果落盘路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本输出**方法的实际效果分级与局限说明、下一步建议、该人群的特别提示、就医信号**。命中「转移注意力」类方法时会明确提示其局限。

> 脚本只做方法有效性分级与提示，**不提供任何药物剂量**，用药判断须由医生或药师做出。

## 九、人工确认清单（这步不能省）

- [ ] 知道晕车是前庭与视觉信息不一致造成的
- [ ] 明确「分散注意力」是加重因素而不是解法
- [ ] 知道看窗外远处比看手机更不容易晕
- [ ] 药物的类别、注意事项、驾驶员能否使用都看过说明书
- [ ] 药物按说明书或医嘱提前服用，不是发作时才吃
- [ ] 没有同时服用两种同类晕车药
- [ ] 儿童用药按说明书的年龄限制，没有用成人药成人量
- [ ] 孕期任何用药都先咨询过医生
- [ ] 知道哪些情况不该按晕车处理，要就医

## 十、最常见的坑

**坑一：用分散注意力来防晕车。**
看电影、聊天、刷手机都会把注意力放到近距离静止目标上，**加大视觉与前庭的不一致，本身就是加重因素**。

**坑二：以为闻味道能防晕车。**
只是转移对恶心的注意力，不影响成因。

**坑三：发作时才吃晕车药。**
多数需要提前服用才有效，临发作吃往往来不及。

**坑四：给小孩吃成人药。**
儿童有专门的年龄限制与剂量，**具体可用年龄以药品说明书为准**。

**坑五：孕妇自行决定用药。**
孕期用药必须先咨询医生，这一点没有例外。

**坑六：驾驶员凭感觉决定能不能吃。**
部分晕车药影响判断力，**能否使用必须看说明书明确说明**。

**坑七：空腹上车。**
空腹反而可能更难受，出行前吃一点清淡的东西更稳。

**坑八：同类药物叠加服用。**
同时吃两种同类晕车药不是「加效果」，是增加风险。

**坑九：硬撑到目的地。**
提前下车休息比硬撑更好，也不至于把旅途全毁在一次上。

**坑十：把头痛、视物模糊也当成晕车。**
这些症状提示可能不只是晕车，应尽快就医。
