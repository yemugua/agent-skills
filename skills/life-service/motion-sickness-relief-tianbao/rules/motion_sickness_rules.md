# 晕车处理与用药核查规则库

> 生成出行方案、判断方法有效性之前，先读这份文件，不要凭印象写。
> 用量与年龄限制以药品说明书和医嘱为准。

---

## 一、机制说明

晕动症的基本原因：**前庭系统感受到的运动信息与视觉、本体感觉提供的信息不一致。**

| 场景 | 眼睛看到 | 前庭感受到 |
|---|---|---|
| 坐车看窗外 | 画面在移动 | 车在移动 |
| 坐车看手机 | 画面几乎静止 | 车在持续移动 |
| 坐船 | 随船晃动 | 持续晃动 |
| 骑车或跑步 | 自己控制的运动 | 同向运动 |

**关键结论**：**眼睛看到的和前庭感受到的越对不上，越容易晕。**

---

## 二、方法有效性对照表

| 方法 | 实际效果 | 局限说明 |
|---|---|---|
| 看窗外远处固定参照物 | 相对有效 | 让视觉与前庭趋于一致；只对轻中度有效 |
| 座位靠前面向行驶方向 | 相对有效 | 减少晃动方向与视野不匹配 |
| 开窗通风 | 有限缓解 | 改善气味带来的不适，不解决成因 |
| 清淡饮食、少量进食 | 有限缓解 | 减少胃部不适，空腹反而可能更难受 |
| 分散注意力（看电影、聊天） | 效果有限且可能更糟 | 固定注意力在近距离静止目标，加大不一致 |
| 闻味道 | 基本无效 | 只转移恶心注意力 |
| 嚼口香糖或吃东西 | 有限缓解 | 主要缓解恶心感 |
| 晕车贴 | 效果存在争议 | 成分与机制说法较多，效果因人而异 |
| 提前按说明书服用晕车药 | 相对有效 | 少数作用于成因的手段之一 |
| 组合使用 | 相对有效 | 通常优于任何单一手段 |

**核心口径**：**分散注意力这类方法本身可能就是加重因素，不是解法。**

## 三、药物类别与注意事项

| 类别 | 代表成分 | 需要注意 |
|---|---|---|
| 抗组胺类 | 常见为部分抗过敏药成分 | 可能嗜睡、口干；驾驶员能否使用看说明书 |
| 抗胆碱类 | 常见为部分止吐药成分 | 可能口干、视物模糊、心率变化 |
| 其他止吐类 | 机制各异 | 各自注意事项不同，按说明书 |

**通用注意事项**：

| 项目 | 说明 |
|---|---|
| 驾驶员 | 能否使用必须看说明书明确说明，不凭感觉 |
| 同乘人群 | 嗜睡口干明显时自己操作设备要注意 |
| 服用时机 | 多数需提前服用，临时发作时吃往往来不及 |
| 叠加使用 | 同类药物不要同时服用 |
| 配伍 | 正在服用其他药物时先问医生或药师 |

**否定项提醒**：「以前吃过没事」不是继续吃的理由。身体状况、正在服用的药物、年龄都会变化。

## 四、儿童特别提示

| 项目 | 说明 |
|---|---|
| 用药 | 不直接用成人剂量或成人的药 |
| 年龄限制 | 具体可用年龄以药品说明书为准 |
| 表现 | 哭闹、脸色苍白、呕吐，常伴随出汗与乏力 |
| 补水 | 呕吐后需要补充水分 |
| 就医 | 症状严重或持续不缓解要看医生 |

---

## 五、孕妇特别提示

| 项目 | 说明 |
|---|---|
| 用药 | 孕期用药必须先咨询医生，没有例外 |
| 影响 | 晕车对孕妇的影响通常大于普通乘客 |
| 首选 | 靠前座位、看窗外、清淡饮食、通风等非药物措施 |
| 就医 | 伴随腹痛、出血、胎动异常时立即就医 |

---

## 六、出行前准备顺序

1. 选座位：靠前、面向行驶方向、尽量靠中间少晃
2. 出行前饮食清淡，别吃太饱也别空腹
3. 需要时按说明书或医嘱提前服用晕车药
4. 路上看窗外远处固定参照物，不看近距离屏幕
5. 开窗通风，把注意力放在远处风景上
6. 提前下车休息，不要硬撑到目的地

---

## 七、就医信号清单

| 情形 | 说明 |
|---|---|
| 症状持续不缓解 | 常规措施无效 |
| 反复剧烈呕吐 | 可能伴随脱水 |
| 伴随头痛、视物模糊、说话含糊 | 提示可能不只是晕车 |
| 伴随肢体麻木无力 | 需要排查其他原因 |
| 胸闷、心悸、意识模糊 | 需要立即就医 |
| 儿童高热伴随呕吐 | 可能是其他疾病 |
| 孕妇伴随腹痛或出血 | 需要立即就医 |

**任一情况出现时，不要按晕车继续处理，应尽快就医。**

---

## 八、常见误区对照

| 说法 | 是否成立 |
|---|---|
| 分散注意力能防晕车 | 不成立，可能是加重因素 |
| 闻味道有用 | 基本不成立 |
| 发作时吃一片就有用 | 多数不成立，需提前服用 |
| 孩子可以用成人的药减半 | 不成立，有专门年龄限制 |
| 以前吃过没事就能继续吃 | 不成立，情况会变化 |
| 空腹上车更好 | 不成立，可能更难受 |
| 两种一起吃效果更好 | 不成立，是增加风险 |
| 硬撑过去就好了 | 不成立，提前休息更好 |
| 头痛也是晕车 | 不成立，需就医 |
