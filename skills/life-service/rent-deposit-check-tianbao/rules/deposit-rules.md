# 押金性质、可扣事由与退还期限

> 引用的《民法典》条文以**现行有效文本**为准；各地对押金上限、备案、押金专户的规定不同，
> 涉及具体数额与强制适用时以当地规定为准。本表只做判定与举证提示，**不构成法律意见**。

## 一、先分清：押金 ≠ 定金（这是最高频的误解）

| | 押金 / 保证金 | 定金 |
|---|---|---|
| 约定形式 | 通常写「押金」「保证金」「租房押金」 | 必须**书面约定**「定金」二字，口头叫「定金」一般不算 |
| 法律性质 | 担保 Crystall 性质的金钱质押/预付款，**违约金性质不成立** | 定金罚则：付定金方违约**不得要回**，收定金方违约**双倍返还** |
| 双倍返还 | **没有这条规则**（很多人以为押金能要双倍，错了） | 有，仅在收受方违约时适用 |
| 退还 | 租赁期满、承租人无违约且结清费用后**应退** | 按定金罚则处理，不是"退"的问题 |
| 上限 | 各地规定不一（有城市限定不超过 1–2 个月租金），以当地为准 | 不得超过主合同标的额的 **20%** |

**判定要点**：合同里写的是「押金/保证金/押一付三」→ 走押金规则，**不能主张双倍返还**；
只有白纸黑字写「定金」才适用定金罚则。这条写进报告第一页，能省掉最多次胜利幻想。

## 二、哪些扣款站得住（**举证责任在房东**）

主张扣款的一方是房东，得**自己证明**：损失真实存在、金额合理、与承租人过错有因果。
承租人只需证明"不是我造成的 / 属自然损耗"。

| 事由 | 判定 | 说明 |
|---|---|---|
| 欠租金 | 正当 | 从押金抵扣需**已履行催告**，且金额要对得上 |
| 欠水/电/燃气/物业/宽带费 | 正当 | 以**结算单据**为准，不含"大概欠多少" |
| 承租人**故意或重大过失**造成的损坏（砸坏家具、墙面乱涂、打孔改装、重度油污） | 正当 | 需照片/视频 + 交接时无此痕迹的对照 |
| 提前退租的违约金 | 正当（可请求调减） | 约定过高，可请求适当减少（司法实践常以**超过实际损失 30%** 为调减参考） |
| 转租/改变房屋用途/擅自拆改 | 按合同约定判定 | 看合同具体条款 |
| 门锁/钥匙丢失，房东换锁 | 存疑→有票据则正当 | 只认**实际换锁费用**，不认"人工费""加钱" |
| 保洁费 / 深度清洁费 | 存疑 | 除非合同明确约定且金额与市价相符；日常清洁是租客使用后的自然结果 |
| **墙面掉漆、墙纸起翘、地面轻微划痕、家电老化、管道老化、霉斑** | **不成立** | 属自然损耗，是房东收租时应承担的风险 |
| **空置期损失 / 租房空档没租出去** | **不成立** | 房源再出租是房东的经营风险，不能转嫁 |
| "房屋价值贬损""折旧费" | **不成立** | 无法律依据 |
| 要求"通下水道费""换灯泡费"这类零碎 | 存疑 | 属房东维修义务（见下） |
| 押金被抵作最后一个月房租却没重新签协议 | 存疑 | 要看双方后续意思表示，最好留确认记录 |

## 三、房东的维修义务（承租人不用背的锅）

- 出租人应当**按约定将租赁物交付承租人**，并在租赁期限内**保持租赁物符合约定用途**；
- 出租人负有**维修义务**（主体结构、管道、电气线路、门窗、防水等），当事人另有约定除外；
- 因维修影响居住的，承租人可要求相应**减免租金或延长租期**（具体看约定与协商）；
- 承租人**日常使用**造成的正常磨损、老化、自然损耗，维修责任在房东。

> 实践中：墙面重新刷、老化的水管电器、漏水霉斑、门锁老化 → 房东出钱。
> 承租人自己动手砸的、钉钉子装挂画、养宠物弄坏地板 → 承租人有责。

## 四、什么时候该退（期限怎么算）

顺序一定是：**约定优先 → 没有约定才看合理期限**。

1. 合同里写了退还时限（如"退租后 3 个工作日内""7 日内""结清费用后 15 天"）→ 按合同；
2. 合同没写 → 退租交接完成、费用结清后给**合理期限**（实践中常见 7–30 天，不同地区裁判口径有差异）；
3. 结算前提：水电燃气物业结清、房屋及钥匙交还、验收交接单签字。
   **注意**：房东不能以"还没找到下家"为由拖延，空置是房东风险。

逾期不退：可主张**资金占用损失**（有约定从约定；无约定可参照当时一年期 LPR 主张，
但以法院认定为准），并保留催告记录。

## 五、押金上限（各地不同，别一刀切）

部分城市/行政区对押金金额有上限要求（如不得超过 1–2 个月租金），
也有城市不作强制规定。**超出部分不一定无效**，但可以作为谈判/投诉的抓手。
→ 报告里只提示"查一下本城市是否有押金上限规定"，不替用户断言无效。

## 六、时效（最容易睡过去的一条）

- 普通诉讼时效 **3 年**，自**知道或应当知道权利被侵害**之日起算（通常是退租、押金该退的那天）；
- 期间通过**短信/微信催告、投诉、发函**会导致时效**中断**，重新计算 3 年——所以催告记录既是证据也是续命；
- 别躺平：3 年一过，胜诉权基本没了。

## 七、判定输出纪律

- 每一条扣款都要给出**判定 + 一句依据 + 下一步动作**，不许留空；
- 存疑项要写明**谁举证**：存疑且房东没票据 → 按不利于房东处理（报告提示"可争议"）；
- 不承诺胜诉、不写"一定拿得回"，只写"可以主张什么、证据缺什么"；
- 涉及具体条款，标「以现行有效法律文本与当地裁判口径为准」。
