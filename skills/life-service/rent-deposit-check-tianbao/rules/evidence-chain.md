# 退租交接证据链（断链是高败诉原因）

> 押金争议的战场不在法庭，在**退租那天拍的那组照片**。
> 本章讲：什么时候拍、拍什么、怎么拍才不能用，以及哪些常见拍法等于没拍。

## 一、两个时间点，缺一不可

| 时点 | 要固定什么 | 为什么 |
|---|---|---|
| **入住时**（进场） | 房屋现状 + 水电燃气表读数 + 已有瑕疵 + 家具家电状态 + 钥匙数量 | 证明"我接手时就是这样"，把自然损耗提前划走 |
| **退租时**（交还） | 同一视角、同一机位、同一批位置的现状 + 表读数 + 交还清单 | 证明"我还回去时没变差"，出事时候拿得出对照 |

**只有退租照、没有入住照 = 只能自证清白式地争论**，房东说"你入住就那样"你就哑火。
反过来只有入住照也不够——得证明退租时的状态。

## 二、必须拍到的清单（逐项打勾）

**通用六件**：
1. 合同**签字页** + 押金/租金支付页（拍到金额、日期、双方签名）；
2. 付款凭证（转账记录、微信账单含备注或聊天上下文，**不要只截余额**）；
3. 进门全景（ Door 全开，拍到门牌号）；
4. 客厅/卧室/厨房/卫生间**各一个固定机位全景**（站同一位置朝同一方向）；
5. 水/电/燃气**表盘读数**（拍清晰数字 + 表号）；
6. 钥匙/门禁卡/遥控 **数量与交接**。

**容易漏的四件**：
7. 墙面地面**细节近照**（尤其你入住时就有痕迹的地方，当天就拍）；
8. 家具家电**铭牌与状态**（冰箱、洗衣机、空调、热水器、灯具）；
9. 水电燃气**欠费结清凭证**（物业/_app 截图带时间）；
10. 交接时双方**在场确认的画面**（最好有对方在画面里，或至少聊天里确认"房已交还"）。

## 三、怎么拍才有效（形式比内容更容易出问题）

- **原始载体**：用手机原生相机/相册拍，别先发微信再存、别截图转发的二次图；
- **连续性与时间**：照片/视频里带**系统时间**；最好前后几分钟内连拍一组，形成时间序列；
- **别剪辑**：别 P、别裁只留有利部分，别删对话（聊天记录删了很难调取，平台也未必给）；
- **视频优于照片**：边走边说一句"今天是 X 月 X 日，房屋现状…"更稳（视听资料证明力更强）；
- **备份两处**：本地 + 云盘/另一个设备；仲裁/诉讼要交原始载体，只交复印件会被质疑。

## 四、聊天记录怎么留（最容易被认定"不完整"）

- 保留**完整对话**（上下上下文连贯），别只截"你该退我押金"那一条；
- 涉及金额/时间的，**要能看出是谁说的、什么时候说的**（头像、昵称、时间戳在截图里）；
- 关键承诺让对方**文字确认**："押金什么时候退""扣这个可以吗""房我已经交了"——让他打一遍字，比十句争辩有用；
- 电话/当面谈完，**立刻发一条文字复述**："刚才说的：X 月 X 日退押金 5000，扣 800，对吧？"→ 对方回"对"，你就锁死了；
- 对方已读不回**不构成承认**。

## 五、证据清单（打分用，八类）

| # | 证据 | 有/无 | 备注 |
|---|---|---|---|
| 1 | 租赁合同（含签字页、押金条款） | | |
| 2 | 押金与租金支付凭证 | | |
| 3 | 入住时现状照片/视频（含瑕疵） | | **最关键，缺它最致命** |
| 4 | 退租时现状照片/视频（同机位） | | |
| 5 | 水电燃气表读数与结清凭证 | | |
| 6 | 交接确认记录（交接单签字 / 聊天确认） | | |
| 7 | 催告记录（明确金额、期限、方式、时间） | | 既是证据也是**时效中断** |
| 8 | 房东扣款的**依据**（票据、报价、照片） | | **举证责任在房东**，他给不出就很难站住 |

缺 3 和 8 是**最常见、也最致命**的两项：3 是"我没造成损害"的起点，8 是"你扣得没道理"的落点。

## 六、常见断链现场（对照自查）

- 只拍了"坏的地方"，没拍全景 → 看不出是原来就坏还是你弄坏；
- 入住时只拍了客厅，卧室墙角、卫生间地砖、厨房柜体没拍；
- 表读数拍了但看不清数字；
- 照片是事后补拍（颜色/光线不同、无时间戳）→ 证明力弱；
- 只保留语音没保留文字；删了微信；只截了图没留原对话；
- 交接没有书面确认，只剩房东一句"你搬走就行"；
- 入住时口头说的"这面墙本来就有印子"，没留痕 → 等于没说过。

## 七、输出纪律

- 报告里的证据打分要写**缺哪一项、缺了会怎样、现在怎么补**；
- 补证建议必须**可执行**（"今天就去补拍哪几张"），不要泛泛说"注意保留证据"；
- 已删除的聊天记录要明确说"恢复困难，建议以后…"，别含糊带过；
- 一切以原始载体为准，输出中不替用户认定证据效力。
