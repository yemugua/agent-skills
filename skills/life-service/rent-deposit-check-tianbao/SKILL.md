# 租房押金争议核查与维权

## 一句话

回答四个问题：**这是押金还是定金（能不能拿双倍）、他扣的每一笔站不站得住、还能拖多久（时效）、现在该发哪句话**。

## 三步上手

1. 用 `templates/租赁信息采集表.md` 把租赁信息填进来（查不到就留空，脚本标【待现场填写】，不瞎猜）。
2. 跑一次核查：
   ```bash
   python scripts/deposit_check.py 租赁信息.md --json
   ```
   可选 `--base 2026-10-04` 固定基准日、`--lpr 3.0` 调整资金占用参考年利率。
3. 按报告第九节的「待办」执行；要实地补证的照 `templates/退租交接取证清单.md` 逐项打勾。

## 它算什么

- **扣款逐条判定**：欠租、欠水电、故意或重大过失损坏判「**正当**」；违约金、换锁、深度清洁、刷墙维修判「**存疑**」；
  空置期损失、折旧、自然磨损（掉漆/起翘/墙纸/老化/霉斑）、前租客损耗判「**不成立**」。
- **押金性质辨析**：合同写「押金/保证金」→ 结清后应退，**没有双倍返还**；写「定金」→ 才可能适用定金罚则（收受方违约才双倍），
  且一般不得超过主合同标的额 20%；写「订金」→ 一般按预付款处理。
- **时间与钱**：应退日（退租交接日 + 合同约定天数，未约定按 15 天）、逾期天数、诉讼时效届满日（+3 年还剩多少天）、
  可主张金额 = 押金 − 正当扣款 − 欠费 + 逾期资金占用（按 LPR 估算）。
- **证据完整度**：八类证据打分（合同签字页 / 付款凭证 / 入住现状 / 退租现状 / 表读数结清凭证 / 交接确认 / 催告记录 / 房东扣款依据），
  缺「入住时现状」与「房东扣款依据」最致命；每项都给可执行的补法。
- **催告话术**：三段式（亮事实 → 逐条反驳 → 期限与后果），自动只挑「存疑/不成立」的条目，正当的不争。

## 硬边界（必须遵守）

- **只做定性判定 + 金额测算 + 时效推算 + 路径建议**，不代拟正式法律文书、不承诺结果、不编造条款与判例。
- 各地受理口径与裁判尺度不同，一律写「以现行有效文本与当地为准」。
- **举证责任在房东**：他要扣款，就得拿出票据、报价、照片；报告只提示你「要求他给」，不替他早教你认下。
- 未填项标【待现场填写】，绝不杜撰金额、日期、对方全名（涉及身份证号/银行卡号请留空，用「房东 A」代称）。
- 风险提示写全：**别占房不走、别曝光对方隐私、别伪造证据**；该认栽的（确实欠租、确实故意损坏、已超时效）直说。

## 文件

- `rules/deposit-rules.md`：押金≠定金对照、可扣/存疑/不成立三档表、房东维修义务、退还期限、时效与中断。
- `rules/evidence-chain.md`：入住与退租两个时点、10 项必须拍内容、原始载体与连续性、八类证据打分、常见断链现场。
- `rules/claim-path.md`：协商→催告→12345/街道调解→小额诉讼四步路径、三段式话术、小额诉讼材料、时效续命、认栽情形。
- `templates/租赁信息采集表.md`：输入模板。
- `templates/押金争议核查报告.md`：输出骨架。
- `templates/退租交接取证清单.md`：现场取证执行清单（含交付前三问）。
- `scripts/deposit_check.py`：核查脚本（唯一可执行部分）。

## 三个容易踩的口径

- **押金没有双倍返还**——拿双倍的，多半是合同写成了「押金/保证金」，真正能主张双倍的是「定金」。
- **墙面掉漆、墙纸起翘、家电老化、管道老化属自然损耗，维修义务在房东**，不是你的账。
- **空置期/找不到下家是房东的经营风险**，不能转嫁成你的扣款；但你自己欠的房租、欠的水电，该结清。
