# 退租交接取证清单（拍照/录像前照着走）

> 打印或存手机备忘录。**入住当天拍一遍，退租当天再拍一遍**，两遍缺一不可。

## 一、入住当天（最容易被忽略，却最要命）

- [ ] 拍**门牌/门框全景**，证明是这一间
- [ ] 进门后**固定机位全景**：客厅 → 卧室 → 厨房 → 卫生间（站同一位置朝同一方向）
- [ ] 拍**水表、电表、燃气表**读数（数字拍清楚，最好连拍 3 张）
- [ ] 拍**入住时就有的瑕疵**：墙角、墙皮、地砖、吊顶、柜体、门框 —— 有就拍，没有也拍一遍空景做对照
- [ ] 拍**家具家电铭牌**（冰箱/洗衣机/空调/热水器/灯具）+ 开机状态（能亮/能转）
- [ ] 数**钥匙/门禁卡/遥控**数量，拍下来
- [ ] 拍**合同签字页**和你付款那笔（转账单 + 聊天里提到这笔钱的上下文）
- [ ] 口头说过的"这墙本来就有印子"，**当场发一条文字给房东确认**

## 二、退租当天（交还时）

- [ ] 同一机位、同一顺序再走一遍（拍法必须能对上）
- [ ] 再拍**表读数**（对比入住时，证明费用结清）
- [ ] 拍**清洁后的状态**——但也别过度清洁到"像新的一样"反而争议（按入住原状归还即可）
- [ ] 当着房东面**交接钥匙/门禁**，拍到对方接手的画面
- [ ] 交接完**立刻发文字确认**：「房已交还，表数 XX，钥匙 X 把已收到/交还，对吧？」等他回「对」
- [ ] 拿**物业/水电燃气结清凭证**（带时间的截图）
- [ ] 全程**用手机原生相机拍**，别先发微信再存；开云备份或拷到第二个设备

## 三、事后补充（已经过了这两天才想起来）

- [ ] 补拍：能补的尽快补（**但要说明拍摄时间**），不能补的就找替代证据：
  - 入住时的**物业/房东聊天记录**、搬入当天快递/搬家记录 → 佐证入住时间；
  - 水电网**缴费记录** → 佐证费用结清；
  - 之前**视频通话**里展示过房屋状态 → 视听资料；
- [ ] 补一份**书面《房屋状况说明》**发房东微信并要求回复确认（哪怕回个"嗯"也行）
- [ ] 已删的聊天记录：从**另一台设备/云备份**找；找不到就说明"记录仍在但被对方限制"，别伪造

## 四、催告怎么说才有效（每轮都留痕）

- [ ] 话里必须含**三个要素**：金额（__ 元）、期限（__ 个工作日前）、后果（投诉/诉讼）
- [ ] 走**至少两种渠道**：微信发一遍 + 短信/邮件再来一遍（互相印证送达）
- [ ] 电话谈完**立刻文字复述**，让他打字确认
- [ ] 每隔 3–6 个月催一次 —— 既逼对方，也算**时效中断**

## 五、交还房屋时的三条红线

- [ ] ❌ 别**换锁占房、留东西堵门**对抗押金 —— 你会从有理变违法
- [ ] ❌ 别**曝光对方身份证/住址/电话** —— 可能反手被诉侵权
- [ ] ❌ 别**修图/伪造证据** —— 识破就是全盘崩

## 六、交付前最后三问

1. **入住照有吗？**（没有的话，"不是我弄坏的"这句话基本没支撑）
2. **房东扣款的票据/照片有吗？**（举证责任在他，他给不出就很难站住）
3. **我催告过几次？最后一次是什么时候？**（3 年时效，别睡过去）
