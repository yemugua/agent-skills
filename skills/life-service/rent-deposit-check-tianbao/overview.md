# 租房押金争议核查与维权

退租那天最容易糊弄过去的，就是那笔押金。房东一条微信「墙面要重刷、卫生要开荒、房子空了两个月，
合计扣 3600」，你就稀里糊涂同意了——因为你说不清哪条该你出、哪条他纯属瞎要，也说不清还剩几天
诉讼时效。

这个技能把这件事拆成四件能落地的事：

| 你要的 | 它给的 |
|---|---|
| 这钱到底什么性质 | 押金 / 保证金 / 定金 / 订金对照表，**押金没有双倍返还** |
| 每一笔扣款合不合理 | 逐条判「正当 / 存疑 / 不成立」，给认定依据与下一步 |
| 我还有多少时间 | 应退日、逾期天数、诉讼时效届满日（+3 年）还剩几天 |
| 我该怎么开口 | 三段式催告话术，自动只挑能争的条目写 |

## 扣款怎么判

三档，不是二元的「该扣/不该扣」：

- **正当**：欠租、欠水电燃气物业、故意或重大过失造成的损坏——但有票据才有底。
- **存疑**：提前退租违约金（过高可请求调减）、换锁、深度清洁、刷墙/家电维修——要看合同有没有写、
  金额是不是市价、有没有交接单和票据。
- **不成立**：空置期损失、折旧贬值、正常磨损（掉漆/起翘/墙纸/老化/霉斑/管道老化）、前租客的损耗——
  自然损耗是出租方的维修义务与经营风险，不该你的账。

## 最要命的一份证据

**入住时的现状照片或视频**。没有它，「不是我弄坏的」这句话没有起点——房东随口说墙是你弄的，
你连反驳的现场都还原不出来。报告会把它列为第一项当务之急，并给出补法（找同期替代：搬家记录、
之前的视频通话）。

## 边界

只做定性判定、金额测算、时效推算与路径建议。不代拟正式法律文书、不承诺结果、不编造条款与判例，
各地口径以现行有效文本与当地为准。该认栽的（确实欠租、确实故意损坏、已过时效）直说，不硬撑。
