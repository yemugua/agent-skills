# 部门受理范围与流转路径

> 提交前必读。**按受理范围匹配渠道，不按情绪判断领域。**

## 一、主要渠道受理范围

> **以现行规定和各受理机构的实际口径为准**，本表为常见分工，不作扩张解释。

| 渠道 | 主要受理范围 | 注意 |
|---|---|---|
| **12315（市场监管）** | 消费交易纠纷、市场主体登记、价格违法、广告违法、部分假冒伪劣 | 消费者投诉举报主渠道 |
| **12345（政务便民热线）** | 政务咨询与投诉的**统一受理与转办入口** | 转办，非直接处理 |
| **消费者协会** | 消费纠纷第三方居中调解 | 调解非裁判，不强制 |
| **税务部门** | 税务征收、发票、税收违法行为 | 不处理消费纠纷 |
| **网信部门** | 网络违法有害信息、个人信息违规处理 | 针对网络领域 |
| **生态环境部门** | 污染排放、环评、环境违法行为 | 与消费纠纷无关 |
| **药监部门** | 药品、医疗器械质量与经营违法 | 涉药涉械专用 |
| **卫生健康部门** | 医疗纠纷、公共卫生违法行为 | 医疗纠纷专用路径 |
| **行业主管部门** | 特定行业经营规范 | 按行业归属 |
| **邮政业申诉** | 快递服务投诉的申诉渠道 | 快递类专用 |

## 二、渠道选择逻辑

```
1. 是不是消费纠纷？
├─ 是 → 12315
│├─ 解决个人纠纷 → 投诉
│└─ 促使查处违法 → 举报
└─ 否 → 2. 属于哪个领域？
├─ 税务 → 税务部门
         ├─ 网络违法 → 网信部门
         ├─ 环境污染 → 生态环境部门
         ├─ 药品器械 → 药监部门
         ├─ 医疗 → 卫生健康部门
         └─ 快递服务 → 邮政业申诉渠道
```

### 两条实用判断

**1. 12345 是转办入口，不是处理机构。** 投 12345 的材料会被转给对应部门，**转办不等于实质处理**。能直接投对部门时应直接投。

**2. 投诉与举报分开提交。** 投诉解决你的纠纷，举报促使查处违法。两者目的不同，混在一起会削弱效果。

## 三、四种去向的区别

| 形式 | 指向 | 你的目的 | 是否直接给你赔付 |
|---|---|---|---|
| **投诉** | 经营者 | 解决个人纠纷 | 可能 |
| **举报** | 违法行为 | 促使查处 | 不必然 |
| **调解** | 双方争议 | 第三方居中 | 取决于协议是否履行 |
| **诉讼** | 依法审判 | 获得裁判 | 判决后可申请强制执行 |

## 四、投诉无果的升级路径

**升级的前提是前序环节已走完且留痕。**

| 阶段 | 动作 | 留痕 |
|---|---|---|
| 1 | 找经营者协商 | 工单号、聊天记录 |
| 2 | 对应渠道提交 | 受理编号、提交回执 |
| 3 | 要求书面答复 | 答复文书或超期未答复记录 |
| 4 | 向上一级或专门机构反映 | 新受理编号 |
| 5 | 申请调解 | 调解申请与协议 |
| 6 | 走司法途径 | 受理通知 |

### 材料被退回要先分因

| 退回原因 | 处理方式 |
|---|---|
| **受理范围不对** | 改投正确渠道，不是补材料 |
| **材料不充分** | 补齐事实与证据后重新提交 |
| **诉求不明确** | 改写为明确可执行的诉求 |
| **不属该机关职责** | 按渠道分工表改投 |

## 五、投诉内容要聚焦事实

| 该写 | 不该写 |
|---|---|
| 「本人于某日在某平台购买某商品，实测与描述不符」 | 「这家店太过分了」 |
| 「诉求：退货退款」 | 「必须给个说法」 |
| 按时间顺序陈述可核查事实 | 夹杂情绪评价与主观猜测 |

**情绪化与威胁性表述的后果**：

1. 处理人员优先跳过实质诉求。
2. 威胁性表述可能使诉求被认定为不合理。
3. 夹杂无关内容拖慢流转。

**把不满转化为可核查的事实陈述，本身就是提高处理效率的技巧。**

## 六、常见错误对照

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 把 12345 当处理机构 | 它是转办入口 | 能直投就直投 |
| 投错部门不重投 | 会被退回 | 改渠道 |
| 投诉举报混投 | 目的不同 | 分开提交 |
| 内容全是情绪 | 实质诉求被跳过 | 只写事实 |
| 诉求笼统 | 无法执行 | 写明具体诉求 |
| 无前序留痕就升级 | 缺支撑 | 先留痕 |
| 被退回不分析原因 | 处理方向错 | 先分因再处理 |
| 先投信访再想正规渠道 | 定位不同易延误 | 选对路径 |
| 一次写几十页 | 关键信息被淹没 | 精简聚焦 |
| 提交后不跟踪 | 不知是否受理 | 主动查询 |
