# 固态硬盘寿命与健康度核查规则库

> 做核查、算剩余、定换盘计划之前，先读这份文件，不要凭印象写。

---

## 一、寿命指标口径表

| 指标 | 含义 | 读法 |
|---|---|---|
| 总写入量（标称） | 出厂标称可承受的累计写入量 | 作为分母看占比 |
| 总写入量百分比 | 已写入量占标称的比例 | 越低越好，看趋势 |
| 健康度百分比 | 厂商按综合指标折算的剩余寿命 | 看下降速度 |
| 通电时间 | 累计通电小时数 | 与写入量共同决定老化 |
| 每日写入量 | 近期写入强度 | 异常增长加速消耗 |
| 重映射单元数 | 无法使用而被替代的单元 | 持续增长要警惕 |

**核心口径**：健康度是厂商折算值，不是物理剩余寿命的精确测量。**跨品牌比较没有意义，同一块盘看趋势才有意义。**

---

## 二、健康度分级与建议动作

| 健康度区间 | 含义 | 建议动作 |
|---|---|---|
| 100% ~ 90% | 早期 | 正常使用，按周期记录 |
| 90% ~ 70% | 中期 | 确认备份完整，规划换盘时间 |
| 70% ~ 50% | 后期 | 尽快完成备份，不再放新数据 |
| 50% 以下 | 末期 | 备份后安排更换 |

**否定项提醒**：寿命末期风险是陡升的，不是线性下降。「还剩 50% 就放心」是误判，判断依据应是备份到不到位。

---

## 三、环境因素影响表

| 因素 | 影响方向 | 说明 |
|---|---|---|
| 长时间通电 | 加速老化 | 常年开机比间歇使用消耗更快 |
| 高温 | 明显加速 | 缩短写入单元的数据保持能力 |
| 频繁小量写入 | 影响相对小 | 分散写入比集中大量写入温和 |
| 一次性大量写入 | 瞬时压力较大 | 不适合长期高频 |
| 断电保存归档 | 有利 | 长期不用的盘应断电保存 |

**数据保留期口径**：**通电闲置比反复读写更容易保住数据。** 长期归档的数据，断电保存比一直挂着更稳妥。

---

## 四、掉盘但寿命富余时的排查方向

| 可能原因 | 判断线索 |
|---|---|
| 固件缺陷或更新问题 | 健康度仍高，突然开始掉盘 |
| 供电不稳 | 特定负载或时刻才掉 |
| 控制器或硬件故障 | 健康度正常，读写错误持续出现 |
| 接口、线缆或转接问题 | 换线换口后表现变化 |
| 文件系统损坏 | 盘能识别但分区异常 |
| 温度过高触发保护 | 高温时掉盘，降温后正常 |

**排查顺序建议**：先确认备份 → 换线换口验证 → 看温度 → 查固件 → 再考虑硬件问题。

**反向口径**：寿命末期也未必立刻掉盘，但**风险陡升**，不能用线性思维安排数据保留。

## 五、按用途分档要求

| 用途 | 关注重点 | 建议 |
|---|---|---|
| 系统盘 | 掉盘会导致整机不可用 | 备份最重要，健康度进入 70% 以下就规划更换 |
| 数据盘 | 读写频繁 | 看每日写入量与健康度趋势 |
| 归档盘 | 长期保存 | 断电保存，定期通电确认可读 |
| 写入密集用途 | 持续写入 | 优先高写入量型号或企业盘 |

## 六、企业盘与消费盘差异

| 维度 | 消费盘 | 企业盘 |
|---|---|---|
| 标称写入量 | 通常较低 | 通常较高 |
| 掉电保护 | 部分具备 | 通常具备 |
| 持续写入表现 | 易掉速 | 更稳定 |
| 保修与服务 | 面向消费场景 | 面向数据中心场景 |
| 适用位置 | 个人设备、读多写少 | 高频写入、长时间运行 |

## 八、常见误区对照

| 说法 | 是否成立 |
|---|---|
| 健康度还剩一半就安全 | 不成立，末期风险陡升 |
| 不同品牌健康度可以横向比 | 不成立，算法不同 |
| 掉盘就是寿命到了 | 不成立，寿命富余时更可能是固件或供电 |
| 寿命末期会立刻坏 | 不成立，但风险陡升，不能按线性安排 |
| 高温影响不大 | 不成立，对保持能力影响明显 |
| 归档盘挂着通电更保险 | 不成立，断电保存更稳妥 |
| 备份了就等于安全 | 不成立，没验证过的备份不算数 |
