# 机动车年检周期、材料与不合格项整改核查

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 按车型、使用性质和注册日期梳理检验周期 | 代替检验机构出具检验合格结论 |
| 核查免检标志申领与上线检测材料 | 承诺一定通过检测或包过 |
| 列出常见不合格项、整改方向和复检安排 | 指导拆除或规避法定安全、环保装置 |
| 提示逾期、事故、改装、查封等限制情形 | 处理拼装、盗抢、走私、报废车辆 |
| 输出上线前整备清单和材料清单 | 代替交警或检验机构的行政认定 |

涉及人员伤亡事故车、非法改装、达到强制报废标准、被盗抢或查封车辆、营运车辆和危险品运输车专项要求时，应直接咨询公安交管部门、检验机构或有资质的维修企业。

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「我的车多久检一次」 | 用，按车型和注册日期核算 |
| 「六年免检是不是不用管了」 | 用，提示仍需申领检验标志 |
| 「年检带什么材料」 | 用 |
| 「灯光和刹车不合格怎么办」 | 用，给整改与复检路径 |
| 「逾期两个月了还能补检吗」 | 用，提示尽快办理并核实处罚 |
| 「帮我找个能包过的地方」 | 不用，明确拒绝 |

## 三、完整工作流

1. **建车辆档案**：号牌、车型、使用性质、注册日期、行驶证、是否营运、燃料类型、核定载客或载质量、事故和改装记录、交强险状态。
2. **算周期**：按 `rules/inspection-cycle.md` 用注册日期与车型核算，区分免检申领标志与上线检验。
3. **查前置条件**：处理未处理的交通违法、事故状态、查封抵押提示、交强险有效期和车船税信息。
4. **备材料**：行驶证、车主身份证明、交强险凭证、车船税信息、代办与单位材料，异地或特殊情形另行核对。
5. **上线前整备**：灯光、制动、轮胎、外观、三角警示牌、反光背心、号牌、玻璃、雨刮、排气和故障灯。
6. **处理不合格项**：按不合格项整改后复检，保留维修单据与复检记录；同一问题反复出现要查根因。
7. **办结留痕**：确认检验有效期、标志状态、检测报告和缴费凭证，更新下次检验时间。

## 四、核心规则与要件库

输出周期表或整改建议前，**必须先读**：

- `rules/inspection-cycle.md`：周期口径、免检边界、材料清单、常见不合格项、逾期处理与救济。
- `templates/inspection-file.md`：整备清单、不合格项整改表和复检跟踪表。

不得把「免检」理解为「无需办理任何手续」；不得把「未检验」「检验不合格」「未复检」混为「已合格」。

## 五、人工确认清单

- [ ] 注册日期、使用性质、载客或载质量与行驶证一致
- [ ] 已区分「申领检验标志」与「上线检验」
- [ ] 交通违法和事故处理状态已核实
- [ ] 交强险在有效期且信息已同步
- [ ] 灯光、制动、轮胎、号牌、玻璃、警示牌等上线项已自查
- [ ] 改装部位是否影响安全和登记参数已评估
- [ ] 检验有效期、标志状态和检测报告已保存
- [ ] 异地检验、委托检验或单位车辆要求已确认

## 六、最常见的坑

1. **把六年免检当成不办**：免检通常指免于上线检验，仍需按规定申领或确认检验标志。
2. **按购车日期算**：检验周期按注册登记日期起算，不看提车或过户日期。
3. **违法未处理就上线**：未处理的违法和事故状态会阻塞检验或标志核发。
4. **交强险只看纸质保单**：保单信息未同步或过期会直接卡住。
5. **改装不留退路**：改变灯具、排气管、车身颜色、轮毂尺寸等可能影响检验和登记参数。
6. **只修不合格项表面**：尾气或制动反复不合格要查根因，如传感器、漏气、磨损或油品。
7. **逾期抱着侥幸上路**：逾期可能面临处罚、事故理赔风险和强制检验要求，应尽快补办。
8. **忽略否定词**：「未通过」「未复检」不能写成「已合格」；整改后必须复检确认。

## 七、边界与免责

本技能提供周期核算、材料整理和整改方向提示，不构成检验结论、行政处罚认定或维修技术方案。检验周期、免检政策、材料、检测项目和处罚标准会随车型、使用性质和地区时间变化，**以现行规定和当地公安交管部门、检验机构要求为准**。不得用于规避检测、伪造材料或驾驶依法不得上路的车辆。
