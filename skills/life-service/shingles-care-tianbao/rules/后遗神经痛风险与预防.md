# 后遗神经痛风险与预防

后遗神经痛指皮疹愈合后疼痛仍持续（常见定义为皮疹出现后持续超过 90 天，不同定义以 1 个月或 3 个月为界，以最新版指南为准）。它是带状疱疹最常见、最影响生活的并发症。

## 一、风险因素

| 因素 | 说明 |
|---|---|
| 年龄 | 年龄越大风险越高，50 岁以上明显升高，60 岁以上更高 |
| 急性期疼痛强度 | 发疹期疼痛越剧烈，后续持续疼痛的风险越高 |
| 前驱痛 | 皮疹出现前就有明显疼痛者风险更高 |
| 皮疹范围 | 皮疹面积大、水疱多、病程长者风险更高 |
| 受累部位 | 眼支、三叉神经区域受累者需更积极处理 |
| 免疫状态 | 免疫低下者病程更长、风险更高 |
| 就医时机 | 抗病毒启动越晚，风险相对越高 |

## 二、风险自查口径

| 评分项 | 计分 |
|---|---|
| 年龄 50-59 岁 | 1 分 |
| 年龄 60-69 岁 | 2 分 |
| 年龄 70 岁及以上 | 3 分 |
| 急性期疼痛评分 7 分及以上（0-10 分制） | 2 分 |
| 急性期疼痛评分 4-6 分 | 1 分 |
| 皮疹范围超过一个皮节或水疱密集融合 | 1 分 |
| 皮疹位于头面部（含眼周耳部） | 2 分 |
| 免疫低下状态 | 2 分 |
| 起疹超过 72 小时才就医 | 1 分 |

| 总分 | 分级 | 建议 |
|---|---|---|
| 0-2 分 | 低风险 | 规范护理与随访，愈合后仍痛需复诊 |
| 3-5 分 | 中风险 | 积极与医生沟通疼痛管理，按医嘱随访 |
| 6 分及以上 | 高风险 | 疼痛管理应更积极，考虑疼痛科评估，由医生决定方案 |

分级只用于提示随访强度，**不能用来替代医生判断，也不能预测个人结局**。

## 三、预防要点

| 项目 | 口径 |
|---|---|
| 早就医 | 出疹后尽快就诊，不要等「发透」 |
| 规范用药 | 抗病毒药物、外用与止痛治疗严格遵医嘱完成疗程 |
| 疼痛沟通 | 急性期疼痛控制不佳时主动复诊，不要硬扛 |
| 护理到位 | 避免继发感染，减少瘢痕与刺激 |
| 基础状态 | 控制血糖等基础疾病，保证睡眠与营养 |
| 疫苗 | 部分人群可考虑接种带状疱疹疫苗，是否适合、何时接种由医生评估，不推荐具体品牌 |

## 四、随访节点

| 时间点 | 做什么 |
|---|---|
| 就诊当日 | 记录疼痛起始日、皮疹出现日，确认用药与复诊时间 |
| 起疹后 3-7 天 | 观察皮疹是否停止新发、有无继发感染 |
| 起疹后 2-4 周 | 评估皮疹愈合情况与疼痛变化 |
| 皮疹愈合时 | 若疼痛仍明显，记录并复诊 |
| 疼痛持续超过 1 个月 | 复诊评估，按医嘱处理 |
| 疼痛持续超过 3 个月 | 属于后遗神经痛范畴，应由疼痛科或皮肤科系统评估 |

## 五、每日疼痛记录

| 日期 | 疼痛评分（0-10） | 性质（刺痛/烧灼/电击/瘙痒） | 是否影响睡眠 | 诱因（触碰、衣物摩擦、温度） | 用药与备注 |

## 六、常见误区

| 误区 | 事实 |
|---|---|
| 「蛇缠腰绕一圈会死人」 | 民间说法，无依据；真正危险的是眼支受累、播散、免疫低下与大范围受累 |
| 「等水疱发透了再看」 | 抗病毒越早越好，拖延增加后遗神经痛风险 |
| 「皮疹好了就没事了」 | 皮疹愈合后疼痛持续是需要复诊的信号 |
| 「把水疱挑破好得快」 | 增加继发感染与留疤风险 |
| 「抹点牙膏/香灰消炎」 | 刺激皮肤、增加感染，延误处理 |
| 「疼是排毒，忍忍就好」 | 急性期疼痛控制与后遗神经痛风险相关，应主动与医生沟通 |
| 「结痂了就不传染了」 | 完全结痂前仍建议覆盖并避免接触高危人群 |
| 「只有老人才会得」 | 年轻人在劳累、压力、免疫低下时同样可能发病 |

## 七、提问清单

- 我现在还在抗病毒窗口内吗？
- 我这个部位（眼周/耳部/头面）需要专科会诊吗？
- 疼痛管理方案是什么？疼痛加重时怎么联系您？
- 皮疹出现什么变化需要立刻复诊？
- 我这个年龄和风险，是否适合接种疫苗？什么时候接种？
- 疼痛超过多久需要转疼痛科？
