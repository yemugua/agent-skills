# 皮疹护理与分期

> 抗病毒药物、外用药与止痛方案均由医生面诊决定，本文件不涉及药物名称与剂量。

## 一、分期时间线

| 期 | 时间口径 | 表现 |
|---|---|---|
| 前驱期 | 皮疹出现前 2-5 天 | 单侧身体某条带状区域出现刺痛、烧灼、麻木、瘙痒，皮肤外观可正常 |
| 发疹期 | 起疹后约 3-5 天陆续出疹 | 红斑上出现簇集性丘疹与水疱，沿单侧神经分布，一般不越过身体中线 |
| 水疱期 | 起疹后约 3-7 天 | 水疱可浑浊、破溃、结痂 |
| 结痂期 | 起疹后约 7-14 天 | 开始结痂，传染性随结痂下降 |
| 恢复期 | 结痂脱落后 | 可能遗留色素沉着或瘢痕，部分人疼痛持续 |

时间线个体差异较大，免疫低下者病程更长。

## 二、抗病毒就医窗口

| 项目 | 口径 |
|---|---|
| 原则 | 越早启动越好，不要等「发出来」或「排毒」 |
| 常见窗口 | 多数指南以发疹后 72 小时内启动收益最明确；超过 72 小时是否用药由医生结合新疱出现、病程与受累部位判断 |
| 特殊情形 | 眼支受累、播散性、免疫低下、高龄、疼痛剧烈者就医应更积极，不受窗口限制 |
| 记录 | 记清疼痛起始日与皮疹出现日，就诊时直接告知医生 |

## 三、皮疹护理做法

| 项目 | 做法 |
|---|---|
| 清洁 | 用清水或医生建议的方式轻柔清洗，不用力搓擦 |
| 保持干燥 | 清洗后轻轻吸干，避免长时间潮湿 |
| 覆盖 | 用干净纱布或敷料松松覆盖，减少衣物摩擦与病毒扩散 |
| 防抓破 | 剪短指甲，夜间可戴棉手套；瘙痒明显时告知医生，不要自行乱用药 |
| 衣物 | 宽松、柔软、透气，避免化纤紧身摩擦 |
| 水疱 | 不自行挑破；大疱、血疱或破溃渗液增多需就医处理 |
| 洗澡 | 可淋浴，水温不宜过高，避免长时间浸泡与共用毛巾 |
| 用品 | 毛巾、衣物单独清洗，不与家人混用 |

## 四、明确禁止

- 不自行挑破、挤压水疱
- 不涂抹牙膏、酱油、香灰、蒜汁、酒精等刺激性物质
- 不自行长期使用含激素的外用药膏
- 不做热敷、拔罐、放血等刺激操作
- 不撕扯痂皮，让其自然脱落
- 不共用毛巾、浴巾与贴身衣物

## 五、传染管理

| 项目 | 口径 |
|---|---|
| 传染源 | 水疱液含病毒 |
| 传染期 | 从出疹到水疱完全结痂之前 |
| 传播方式 | 直接接触疱液；也可经飞沫传播（相对少见） |
| 易感者 | 未患过水痘且未接种水痘疫苗者，尤其孕妇、新生儿、早产儿、免疫低下者 |
| 隔离做法 | 覆盖皮疹；避免与上述人群接触；不共用物品；勤洗手 |
| 已患过水痘者 | 一般已有免疫，但仍应避免直接接触疱液 |
| 结痂后 | 传染性明显下降，结痂完全脱落前仍建议保持覆盖 |

**接触后处理**：孕妇、新生儿、免疫低下者若明确接触了疱液，应尽快联系医生咨询。

## 六、继发感染识别

| 信号 | 处置 |
|---|---|
| 皮疹周围红肿扩大、皮肤发烫 | 尽快就医 |
| 渗液化脓、出现黄色结痂增多 | 尽快就医 |
| 疼痛突然加重伴发热 | 尽快就医 |
| 痂下积脓、出血 | 尽快就医 |

## 七、就诊时带什么

- 疼痛起始日期、皮疹出现日期、水疱开始结痂的日期
- 皮疹部位照片（每天一张便于对比）
- 每日疼痛评分记录
- 既往疾病与用药清单，尤其是免疫抑制相关用药
- 是否妊娠、是否接触过孕妇或新生儿
