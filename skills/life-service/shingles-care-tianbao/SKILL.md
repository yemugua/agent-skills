# 带状疱疹护理与后遗神经痛预防

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 给出皮疹护理、衣物与清洁的口径 | 诊断带状疱疹、判断是否累及眼支或内脏 |
| 说明抗病毒治疗的就医时机窗口 | 提供任何抗病毒药物、止痛药的名称与剂量 |
| 提示疱液传染性与隔离注意事项 | 建议自行挑破水疱、涂抹偏方或自行停用药物 |
| 做后遗神经痛的风险自查分级 | 承诺某种方法能避免后遗神经痛 |
| 整理就诊提问与随访记录 | 推荐具体药品品牌或疫苗品牌 |

**就医红线（出现任一条，尽快就医；标注急诊的直接去急诊）**

- **皮疹出现在眼周、鼻尖、额头一侧** —— 提示眼支受累，眼科或皮肤科急诊评估，视力受损风险高
- **耳部皮疹伴面瘫、耳鸣、听力下降、眩晕** —— 需尽快耳鼻喉科与皮肤科评估
- 皮疹播散：超出相邻皮节的多个区域、或全身散在分布
- 免疫低下状态（肿瘤化疗、器官移植、长期激素或免疫抑制剂、HIV 感染）伴皮疹
- 妊娠期出现皮疹或密切接触者
- 皮疹伴高热、剧烈头痛、意识改变、颈项强直
- 会阴部或骶部皮疹伴排尿排便困难
- 疼痛剧烈难以忍受、或皮疹范围快速扩大、出现大疱血疱与皮肤坏死
- 皮疹继发感染：明显红肿化脓、渗液增多、周围皮肤发烫、发热
- 皮疹愈合后疼痛持续超过 1 个月且逐渐加重

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「带状疱疹水疱要不要挑破」 | 用，明确不建议自行挑破 |
| 「发疹第几天吃药还有效」 | 用，说明越早越好与常见窗口口径 |
| 「会不会传染给家人」 | 用，说明疱液传染与高危人群 |
| 「怎么预防后遗神经痛」 | 用，做风险分级与随访提示 |
| 「长在眼睛旁边严重吗」 | 只作急诊提示 |
| 「阿昔洛韦吃多少」 | 不用，药物由医生开具 |
| 「打疫苗有用吗」 | 用，说明可咨询医生，不推荐品牌 |

## 三、完整工作流

1. **先排红线**：逐条核对就医红线，命中即转就医，尤其是眼周鼻尖与耳部皮疹。
2. **记录时间线**：疼痛起始日、皮疹出现日、水疱结痂日三个时间点，用于判断就医窗口。
3. **评估抗病毒时机**：按 `rules/皮疹护理与分期.md` 说明越早越好、常见窗口口径，并强调由医生决定用药。
4. **皮疹护理**：清洁、覆盖、避免抓破、衣物选择，逐项执行。
5. **传染管理**：结痂前避免接触未患过水痘者、孕妇、新生儿与免疫低下者。
6. **疼痛记录与随访**：用 0-10 分每日记录，按 `rules/后遗神经痛风险与预防.md` 做风险分级。
7. **随访节点**：皮疹愈合后仍疼痛超过 1 个月应复诊评估后遗神经痛。

## 四、核心规则与要件库

生成护理建议前，**必须先读**：

- `rules/皮疹护理与分期.md`：分期时间线、护理做法、禁忌与传染隔离口径。
- `rules/后遗神经痛风险与预防.md`：风险因素、分级、随访节点与常见误区。

不得给出任何抗病毒药物或止痛药的名称与剂量。不得建议自行挑破水疱或涂抹偏方（牙膏、酱油、香灰等）。

## 五、脚本用法

```
python scripts/shingles_phn_risk.py --file case.json
python scripts/shingles_phn_risk.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：年龄、发疹天数、疼痛评分、皮疹范围、部位、免疫状态 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--json` | 以 JSON 输出 |
| `--selftest` | 运行自检 |

脚本输出抗病毒就医窗口提示、后遗神经痛风险分级与随访节点。**命中红线时只输出就医提示。脚本不提供任何药物剂量。**

## 六、人工确认清单

- [ ] 就医红线已排除，尤其眼周鼻尖、耳部伴面瘫、播散性皮疹
- [ ] 疼痛起始日与皮疹出现日已记录，未混淆
- [ ] 是否处于免疫低下状态已如实告知
- [ ] 皮疹部位、范围、是否出现大疱血疱已记录
- [ ] 每日疼痛评分已记录，用于随访对比
- [ ] 接触者中的孕妇、新生儿、免疫低下者已识别并隔离
- [ ] 用药严格遵医嘱，未自行停药或改量
- [ ] 愈合后疼痛是否超过 1 个月的随访节点已标注

## 七、最常见的坑

1. **等「排毒」再去看**：抗病毒治疗越早启动越好，拖延会错过最佳窗口并增加后遗神经痛风险。
2. **自行挑破水疱**：增加继发细菌感染与留疤风险。
3. **涂牙膏、酱油、香灰等偏方**：刺激皮肤、增加感染风险，延误正规处理。
4. **信「绕一圈会死人」**：这是民间说法，真正危险的是眼支受累、播散与免疫低下，不是「首尾相连」。
5. **以为不传染**：疱液含病毒，可传给未患过水痘的人并引起水痘，孕妇与新生儿风险更高。
6. **结痂就不管疼痛**：皮疹愈合后疼痛持续是后遗神经痛的信号，需复诊评估。
7. **自行长期用激素类药膏**：可能加重感染，需医生判断。
8. **硬扛疼痛**：急性期疼痛控制与后遗神经痛风险相关，应及时与医生沟通。

## 八、边界与免责

本技能提供带状疱疹的护理口径、传染管理要点与后遗神经痛风险自查，不构成诊断或治疗方案。**不提供任何药物名称与剂量**，抗病毒药物、止痛方案和疫苗是否适合均由医生面诊决定。抗病毒时机窗口、风险分级与随访节点因年龄、免疫状态、受累部位和指南版本而异，**以最新版临床指南和皮肤科或疼痛科医师的判断为准**。出现就医红线中的任一情况，请尽快就医。
