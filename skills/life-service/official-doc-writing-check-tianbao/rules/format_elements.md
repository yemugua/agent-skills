# 公文格式要素自查表与错误样例库

## 一、格式要素八项自查表

| # | 要素 | 自查问题 | 通过标准 |
|---|---|---|---|
| 1 | 标题 | 是否三要素齐全？事由能否一句话概括正文？ | 发文机关 + 事由 + 文种；末尾不加标点 |
| 2 | 主送机关 | 是否越级？是否多头？是否写「有关部门」？ | 层级正确、一个、具体名称 |
| 3 | 正文 | 是否有缘由、事项、执行要求？执行要求是否含时限？ | 三段齐全 |
| 4 | 附件说明 | 附件名称是否列明？正文引用是否一致？ | 附件说明存在且与实际一致 |
| 5 | 发文机关署名 | 署名机关与行文机关是否一致？名称是否规范？ | 一致且为全称或规范简称 |
| 6 | 成文日期 | 是否为会议通过或负责人签发日期？与落款是否一致？ | 一致 |
| 7 | 抄送机关 | 抄送范围是否必要？顺序是否规范？ | 必要且规范 |
| 8 | 印发机关与日期 | 需印发时是否齐全？ | 齐全 |

**版头、主体、版记的字体字号、字号编排、页码等格式要求以现行公文处理办法及本单位公文格式规定为准，本表只做要素层面自查。**

## 二、标题自查四条

| # | 规则 | ✗ 错误 | ✓ 正确 |
|---|---|---|---|
| 1 | 三要素齐全 | 《通知》 | 《XX 市水利局关于印发 XX 管理办法的通知》 |
| 2 | 事由具体 | 《关于有关事项的通知》 | 《关于调整 XX 标准的通知》 |
| 3 | 不写「加强」「做好」类空泛事由 | 《关于加强管理工作的通知》 | 《关于规范 XX 管理的通知》 |
| 4 | 末尾不加标点 | 《……的通知。》 | 《……的通知》 |

## 三、主送机关自查三条

| # | 规则 | ✗ 错误 | ✓ 正确 |
|---|---|---|---|
| 1 | 不越级 | 县政府发文给村民委员会 | 县政府发文给乡政府 |
| 2 | 不多头 | 主送：市发改委、市财政局、市住建局 | 主送：市发改委；抄送：市财政局、市住建局 |
| 3 | 写具体机关 | 主送：有关部门 | 主送：市发改委；抄送：各有关单位 |

## 四、结尾用语对照表（按文种）

| 文种 | 结尾用语 | ✗ 混用示例 |
|---|---|---|
| 报告 | 特此报告。 | ✗ 「以上情况，请批示。」（用在报告上） |
| 请示 | 妥否，请批示。/ 请予批复。 | ✗ 「特此报告。」（用在请示上） |
| 通知（要求执行） | 请遵照执行。/ 请认真贯彻执行。 | ✗ 「望周知。」（要求执行时用） |
| 通报 | 特此通报。 | — |
| 函（请求支持） | 请予支持。/ 专此函达，请予复函。 | ✗ 用「望周知」 |

**结尾用语是文种判断的最后一道验证。** 用错了说明前面的文种理解就有问题。

## 五、错误样例库（可直接用于培训）

### 样例 1：越级行文

```
原文：主送：XX 县 XX 乡 XX 村村民委员会
问题：县政府越过乡政府直接行文给村级组织
改法：改为逐级行文，主送改为 XX 乡人民政府
```

### 样例 2：多头主送

```
原文：主送：市发改委、市财政局、市住建局、市自然资源局
问题：上级对下级多头主送，对方无法确定责任主体
改法：主送保留一个，其余改为抄送
```

### 样例 3：请示与报告混用

```
原文：
  标题：《关于申请 XX 专项资金的报告》
  正文：……现将有关情况报告如下，同时申请资金 500 万元。
  结尾：以上情况，请批示。
问题：
  1. 标题用「报告」但内容含申请事项
  2. 报告夹带请示事项
  3. 结尾用了请示用语
改法：拆成两份文件
  文件一《XX 单位关于 XX 工作情况的报告》— 结尾「特此报告。」
  文件二《XX 单位关于申请 XX 专项资金的请示》— 结尾「妥否，请批示。」
```

### 样例 4：一文多事

```
原文：《关于申请三项资金支持的请示》
正文：分别列出一、二、三三项资金申请
问题：请示必须一文一事
改法：拆成三份请示文件
```

### 样例 5：口语化表述

```
原文：「差不多能覆盖全部需求，请尽快安排，我觉得挺紧要的。」
问题：模糊词 + 无时限要求 + 主观表述
改法：「约可覆盖全部需求，请于 2026 年 11 月 30 日前完成。」
```

### 样例 6：通知与通报混用

```
原文：《关于表彰 2026 年度先进个人的通知》
问题：表彰应使用通报
改法：改为《关于表彰 2026 年度先进个人的通报》，结尾「特此通报。」
```

### 样例 7：标题事由空泛

```
原文：《关于做好相关工作的通知》
问题：事由未说明具体做什么，执行时无从下手
改法：《关于开展 2026 年安全生产大检查的通知》
```

### 样例 8：附件缺失

```
原文：正文写「详见附件 1」，但文件无附件说明段
问题：附件说明缺失，正文引用与实际附件对不上
改法：补附件说明：「附件：1. XX 管理办法」；正文引用与名称一致
```

## 六、行文规则十条自查

- [ ] 1. 请示类一文一事
- [ ] 2. 行文关系明确
- [ ] 3. 不越级行文
- [ ] 4. 不多头主送
- [ ] 5. 请示与报告分开，报告不夹带请示事项
- [ ] 6. 需要执行的写明执行要求，不用「望周知」代替
- [ ] 7. 语言准确简洁，无错别字歧义
- [ ] 8. 不用生造词语与网络用语
- [ ] 9. 标点正确，书名号不误用，括号配对
- [ ] 10. 表述庄重平实，无口语、情绪、反问、感叹

## 七、涉密与法律效力提示

| 情形 | 处理 |
|---|---|
| 涉密文件 | 按现行保密规定和本单位保密管理制度办理，本技能不处理涉密内容 |
| 需加盖印章、特定审批流程的文件 | 按本单位发文办理流程执行 |
| 涉及法律效力的告知类文件 | 建议由法制或法务部门审核 |
| 引用已废止的旧文号或旧表述 | 以现行规定和本单位最新发布为准 |
| 字体字号、版式编排 | 以现行公文处理办法及本单位公文格式规定为准 |
