# 公文文种选型与格式要素规则库

> 起草任何公文前先读本文件。**文种选错，后面所有格式都对不上。**

---

## 一、六类文种完整对照表

| 文种 | 适用场景 | 是否需回复 | 一文几事 | 行文方向 | 典型结尾 |
|---|---|---|---|---|---|
| 通知 | 转发/批转上级公文；发布规章制度；传达要求下级办理的事项；任免人员 | 通常不需回复 | 可多事 | 上级→下级 | 请遵照执行 / 请认真贯彻执行 |
| 通报 | 表彰先进；批评错误；传达重要精神；告知重要情况 | 不需回复 | 可多事 | 上级→下级 | 特此通报 |
| 报告 | 汇报工作；反映情况；答复询问 | 不需回复 | 可多事 | 下级→上级 | 特此报告 |
| 请示 | 请求指示；请求批准 | **必须回复** | **必须一文一事** | 下级→上级 | 妥否，请批示 / 请予批复 |
| 函 | 不相隶属机关间商洽工作；询问答复问题；请求批准；商洽 | 视情况 | 可多事 | 平级/不相隶属 | 请予支持 / 请予复函 |
| 纪要 | 记载会议主要情况和议定事项 | 不需回复 | 只记会议 | 内部 | （通常无结尾语） |

**意见**：作为文种使用时，用于对重要问题提出见解和主张。**与「通知」的区别**：通知是要对方照办，意见是提出见解、由对方结合实际贯彻。混用会让文件执行口径不清。

## 二、通知 vs 通报判定树

```
问题：这份文件的核心诉求是什么？
├─ 要求对方做某事 → 通知
│   典型句式：请遵照执行 / 请认真贯彻执行 / 请抓好落实
└─ 告知对方发生了什么 → 通报
    典型句式：现将有关情况通报如下 / 特此通报

进一步区分通报：
├─ 表彰 → 表彰性通报
├─ 批评 → 批评性通报
├─ 传达重要精神 → 情况通报
└─ 告知重要情况 → 情况通报
```

| 维度 | 通知 | 通报 |
|---|---|---|
| 内容性质 | 要求办理、发布、传达 | 告知情况、表彰、批评 |
| 是否要求执行 | 通常要求 | 一般不要求 |
| 典型句式 | 「请遵照执行」 | 「现将有关情况通报如下」 |
| 用与表彰批评 | 不用 | 用 |

## 三、报告 vs 请示判定树

```
问题：这份文件想让上级做什么？
├─ 只是知道 → 报告（结尾：特此报告）
│   ├─ 汇报工作
│   ├─ 反映情况
│   └─ 答复询问
└─ 要指示或批准 → 请示（结尾：妥否，请批示）
    ├─ 必须一文一事
    └─ 必须有回复

【禁止】报告中夹带请示事项
【禁止】标题含「申请」却用「报告」
【禁止】报告结尾用「请批示」「请批复」
```

| 维度 | 报告 | 请示 |
|---|---|---|
| 行文目的 | 汇报、反映、答复 | 请求指示或批准 |
| 是否需要回复 | 不需要 | **必须回复** |
| 内容数量 | 可多事 | **必须一文一事** |
| 是否可带请求 | **不可** | 可 |
| 结尾用语 | 特此报告 | 妥否，请批示 |

**口诀**：报告只说事，请示要拿事。

## 四、八项格式要素细则

| # | 要素 | 内容要求 | 常见错误 |
|---|---|---|---|
| 1 | 标题 | 发文机关 + 事由 + 文种三要素；一般不用标点；末尾不加标点 | 缺发文机关；事由不清；末尾加标点 |
| 2 | 主送机关 | 行文对象机关名称；上级对下级一般只写一个 | 越级；多头；写「有关部门」 |
| 3 | 正文 | 开头缘由 + 主体事项 + 结尾要求 | 口语化；无缘由；无执行要求 |
| 4 | 附件说明 | 列明附件名称，正文中提及附件 | 缺失；与实际附件不一致 |
| 5 | 发文机关署名 | 行文机关全称或规范简称 | 与主送机关混用；非规范简称 |
| 6 | 成文日期 | 会议通过或负责人签发日期 | 与签发日不一致；与落款不一致 |
| 7 | 抄送机关 | 需了解该件的其他机关，按规范顺序 | 过多；顺序不规范 |
| 8 | 印发机关与印发日期 | 印发机关全称、印发日期 | 需印发时缺失 |

**版头、主体、版记的字体字号、字号编排、页码等具体要求以现行公文处理办法及本单位公文格式规定为准。**

### 标题拟定四条规则

```
1. 三要素齐全
   ✓ 《XX 市水利局关于印发 XX 管理办法的通知》
   ✗ 《通知》
   ✗ 《关于加强工作的通知》

2. 事由一句话概括正文全部内容
   ✓ 《关于调整 XX 标准的通知》
   ✗ 《关于有关事项的通知》

3. 一般不用标点符号，末尾不加标点
   ✓ 《XX 市关于开展安全生产大检查的通知》
   ✗ 《XX 市关于开展安全生产大检查的通知。》

4. 长标题可回行，回行时词意完整、排列对称
```

### 主送机关三条规则

| 规则 | 说明 |
|---|---|
| 不越级行文 | 行文不能越级。上级不能越级下发给下级的下一级 |
| 不多头主送 | 上级对下级一般只写一个主送机关；确需多个按规定处理 |
| 不写「有关部门」 | 写具体机关名称，或「各有关单位」并列明具体范围 |

## 五、行文规则十条判定表

| # | 规则 | 判定标准 | 违反后果 |
|---|---|---|---|
| 1 | 一文一事（请示） | 请示类每份只写一件事 | 退回重写 |
| 2 | 行文关系明确 | 按隶属关系和职权确定方向 | 越级 |
| 3 | 不越级行文 | 主送层级关系正确 | 退回 |
| 4 | 不多头主送 | 上级对下级只写一个 | 退回 |
| 5 | 请示与报告分开 | 报告不夹带请示事项 | 退回 |
| 6 | 不以「望周知」代替执行要求 | 需执行的写明执行要求 | 执行不力 |
| 7 | 语言准确简洁 | 无错别字、无歧义、无多余修饰 | 校对问题 |
| 8 | 不用生造词语 | 不用非公知外来词、网络用语 | 庄重性受损 |
| 9 | 标点正确 | 不用一逗到底；书名号不误用 | 格式问题 |
| 10 | 表述庄重平实 | 无口语、无情绪、无反问感叹 | 庄重性受损 |

## 六、口语化表述改写对照表（12 组）

| # | 错误写法 | 规范写法 | 问题类型 |
|---|---|---|---|
| 1 | 大概 / 差不多 | 约 / 近 / 明确数值 | 模糊 |
| 2 | 搞 / 弄 / 干 | 开展 / 办理 / 实施 | 口语 |
| 3 | 特别重要 / 非常重要 | 删除，用具体要求代替 | 形容词堆砌 |
| 4 | 大家都知道 | 删除 | 无信息量 |
| 5 | 尽快 / 抓紧 | 于 X 月 X 日前 | 无约束力 |
| 6 | 有关部门 / 有关方面 | 具体机关名称 | 指代不清 |
| 7 | 就这样 / 别的就不多说了 | 删除 | 不庄重 |
| 8 | 说实话 / 其实 | 删除 | 口语 |
| 9 | 必须 / 一定要 / 千万 | 应当 / 须 | 过度强调 |
| 10 | 不能不出问题 | 应杜绝…（肯定句） | 双重否定歧义 |
| 11 | 我认为 / 我个人觉得 | 删除，用客观表述 | 主观 |
| 12 | 差不多能覆盖全部需求 | 约可覆盖全部需求 | 模糊 |

**处理原则**：先删，再改。删不掉的词，用具体表述替换。

## 七、常见错误样例对照

### 越级行文

```
✗ 某县人民政府直接行文给该乡下属村民委员会
✓ 改为逐级行文：某县人民政府 → 某乡人民政府
```

### 多头主送

```
✗ 主送：市发改委、市财政局、市住建局
✓ 主送：市发改委；抄送：市财政局、市住建局
```

### 请示与报告混用

```
✗ 标题《关于申请 XX 资金并汇报工作情况的报告》
  结尾「以上情况，请批示。」
✓ 拆成两份：
  《XX 单位关于 XX 工作情况的报告》— 结尾「特此报告。」
  《XX 单位关于申请 XX 资金的请示》— 结尾「妥否，请批示。」
```

### 一文多事（请示）

```
✗ 一份请示里写三项资金申请
✓ 拆成三份，或改用其他文种
```

### 口语化

```
✗ 「差不多能覆盖全部需求，请尽快安排。」
✓ 「约可覆盖全部需求，请于 X 月 X 日前完成。」
```
