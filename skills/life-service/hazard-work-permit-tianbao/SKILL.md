# 危险作业许可管理（hazard-work-permit）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据 GB 30871《危险化学品企业特殊作业安全规范》，生成危险作业许可清单：作业票类型（动火/高处/有限空间/临时用电）、风险辨识、安全措施、监护人、审批与关闭。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 危险作业许可
- 特殊作业票
- 动火作业
- 高处作业
- 有限空间作业

## 三、工作流
1. 识别作业类型并开具对应作业票
2. 开展危险有害因素辨识
3. 落实安全措施与个体防护
4. 指定监护人并分级审批
5. 作业全过程监护与完工验收关闭

## 四、核心内容（检查清单与判定）
GB 30871 规定动火、高处、受限空间、临时用电等特殊作业须办理作业票，进行风险辨识、措施确认、监护与审批，作业结束应验收关闭。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含作业票类型（动火/高处/有限空间/临时用电） | 类型 |
| Q2 | FAIL | 未含危险有害因素辨识 | 辨识 |
| Q3 | WARN | 未含安全措施与个体防护 | 措施 |
| Q4 | FAIL | 未含监护人与审批 | 监护 |
| Q5 | WARN | 未含作业关闭/验收 | 关闭 |

> 脚本 `hazard-work-permit_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python hazard-work-permit_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python hazard-work-permit_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
