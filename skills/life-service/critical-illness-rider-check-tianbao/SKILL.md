# 重疾险犹豫期退保与条款核查

买重疾险最怕两件事：**该退的时候不知道能退多少**，以及**不该买的责任被一条免责吞掉**。

犹豫期退保能不能退钱、等待期内生病赔不赔、健康告知少答一个字会怎样——这三件事的答案全都在**合同本身**，不在销售的话里。

这个技能做五件事：**定犹豫期到期日 → 算退保损失 → 分清等待期 → 核告知义务 → 逐条比条款**。

---

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 按合同成立日与合同约定天数推算犹豫期到期日 | 承诺一定能退、一定能全额退、一定赔 |
| 按合同现金价值表口径测算退保损失金额 | 劝诱退保、劝诱加保、劝诱换产品 |
| 解释犹豫期与等待期的区别与各自后果 | 代替保险公司作核赔认定或理赔决定 |
| 逐条比对保险责任、责任免除、疾病定义 | 诊断疾病、给医学结论、替代体检 |
| 提示如实告知义务与常见核保结论类型 | 编造具体条款号、产品名、疾病定义编号 |
| 提示带病投保的核保结论类型与后续流程 | 承诺核保结果一定是标准体或一定通过 |

涉及以下情形，应停下来交由保险公司理赔部门、专业代理人或律师处理：**理赔申请与争议、拒赔申诉、二次手术与复发认定、等待期内出险的责任认定、职业类别与拒保通知、涉及诉讼的理赔纠纷**。

**绝对不做**：不承诺收益、不承诺理赔、不劝诱退保。**犹豫期天数以合同约定为准；犹豫期内退保的现金价值以合同载明的现金价值表为准；责任免除与疾病定义以保险合同条款为准。**

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「重疾险犹豫期是多久」 | 用，按合同约定天数核 |
| 「昨天刚买，今天能退吗」 | 用，算犹豫期是否届满 |
| 「犹豫期内退保能退多少」 | 用，按现金价值表口径算 |
| 「等待期和犹豫期有什么区别」 | 用，按两个不同概念分别说 |
| 「等待期内确诊了赔不赔」 | 用，按条款口径说明处理方式 |
| 「体检有结节没敢填健康告知」 | 用，讲如实告知义务与理赔影响 |
| 「没告知会不会拒赔」 | 用，说明后果口径，不下个案结论 |
| 「重疾险哪个病赔得多」 | 用，比对疾病定义与分组 |
| 「帮我推荐一款重疾险」 | 不用，拒绝推销具体产品 |
| 「先买后退，反正能退」 | 不用，说明退保损失口径与不劝诱退保 |

## 三、完整工作流

```
第 1 步  取三件原始材料：保险合同、投保单/电子投保单、现金价值表
第 2 步  确认合同成立日（以合同载明为准，不是以刷卡日或口头日为准）
第 3 步  读规则文件 rules/critical-illness-rules.md（犹豫期口径、等待期口径、
        告知义务、条款核查点、防误伤清单）
第 4 步  按合同约定天数推算犹豫期到期日，标注为「以合同约定为准」
第 5 步  跑脚本核算：scripts/cooling_off_calc.py --file case.json
第 6 步  按现金价值表口径列退保损失：已交保费 − 退保时可退金额
第 7 步  分情形核对等待期内出险的处理口径（以条款约定为准）
第 8 步  核对健康告知：问什么答什么，逐项比对投保单填写内容
第 9 步  逐条比对保险责任、责任免除、疾病定义、赔付比例、等待期
第 10 步 输出核查清单与人工确认项，不给理赔结论
```

## 四、核心口径（必须算得出来）

### 4.1 犹豫期天数与到期日

```
犹豫期到期日 = 合同成立日 + 合同约定的犹豫期天数
```

| 项目 | 口径 |
|---|---|
| 起算日 | **合同成立日**，以保险合同载明的成立日期为准 |
| 天数 | **以合同约定为准**。长期人身保险合同一般会约定一段犹豫期，常见为合同成立日起若干天，**具体天数以你的保险合同条款载明为准，不要凭印象套用某个数字** |
| 届满判断 | 到期日当天及之后已过犹豫期；**是否含当日、是否顺延，以合同约定与保险公司的口径为准** |
| 犹豫期长度 | **不能与等待期混为一谈**：犹豫期是给你「反悔」用的，等待期是给保险公司「防带病投保」用的 |

> **重要**：犹豫期天数因产品、渠道、投保方式而不同。**这里给的是计算方法，不是标准答案。天数以合同约定为准。**

### 4.2 犹豫期内退保与犹豫期外退保

| 情形 | 处理口径 |
|---|---|
| 犹豫期内退保 | **通常按合同约定的口径退还已交保费，可能扣除少量手续费用**；**具体退还范围、扣除项目与标准以合同约定为准** |
| 犹豫期届满后要求解除合同 | 通常按**现金价值表**载明的对应金额退还；**退保损失 = 已交保费 − 可退金额（现金价值）**，且现金价值通常随保单年度递增，前期可能**远低于**已交保费 |
| 保单年度初期退保 | 现金价值通常很低，**退保损失可能接近甚至超过全部已交保费** |
| 犹豫期已过但仍在缴费期内 | 退保通常只能拿现金价值，**不能拿回剩余未缴保费** |

**必须写清的口径**：

```
退保损失 = 已交保费 − 可退金额
可退金额 = 合同载明的现金价值表对应数值（犹豫期外退保口径）
         或 合同约定的退还范围（犹豫期内退保口径）
```

**不得写成**：现金价值 = 已交保费，或退保能拿回全部保费。**现金价值以合同载明的现金价值表为准。**

### 4.3 等待期 vs 犹豫期

| 维度 | 犹豫期 | 等待期 |
|---|---|---|
| 保护谁 | 保护**投保人**（给反悔机会） | 保护**保险公司**（防带病投保） |
| 起算 | 合同成立日起 | **以合同约定为准**，通常为合同成立日或约定起算日后若干天 |
| 长度 | **以合同约定为准** | **以合同约定为准**，可能按不同责任分别约定不同天数 |
| 期满后 | 可以自由选择是否退保（不再受此约束） | 出险按保险责任与疾病定义判定能否赔 |
| 期满前出险 | 与保障责任无关，属反悔期 | **处理方式以条款约定为准**，常见口径是退还已交保费或终止该责任，**具体以合同条款为准，不得断言一定赔或一定不赔** |

**最关键的结论**：等待期内确诊，**不要自己下结论说「一定赔」或「一定不赔」**，只写「处理方式以保险合同条款约定为准，需向保险公司确认」。

### 4.4 如实告知义务与理赔影响

| 项目 | 口径 |
|---|---|
| 告知范围 | **以保险合同约定的询问事项为准**，通常是投保时书面或电子问卷中列明的问题 |
| 回答原则 | **问什么答什么**：问卷问到的每一问都要按实际情况回答；问卷没问的项，按合同条款约定处理 |
| 常见错误 | ①凭感觉答，认为指标「问题不大」就不填；②把体检异常当成已确诊疾病填；③把医生口头说的「随访观察」当成确诊；④投保后才发现漏填，以为自己没说就不算 |
| 带病投保的核保结论类型 | **标准体承保 / 加费承保 / 责任除外承保 / 延期承保 / 拒保**（具体类型与判定标准由保险公司核保规则决定，**以保险公司实际核保结论为准**） |
| 核保结论的含义 | **加费**＝按更高费率缴费；**责任除外**＝对该项原因导致的疾病不赔，其他责任按约赔付；**延期**＝暂缓决定，需补充资料或观察后再定；**拒保**＝不承保 |
| 未如实告知的后果 | 保险公司可依保险合同约定与相关法律规则，**对未如实告知的相关事项作出不承担给付责任的处理，并可能解除合同**。**具体处理以合同约定、法律规定与保险公司的核定结论为准** |
| 时间点 | 核保结论会**同步影响犹豫期内的退还口径与后续保费**，投保后应主动核对核保结论是否与告知内容一致 |

**表述纪律**：只能说「未如实告知可能导致保险人不承担给付责任」，**不能说「隐瞒了必定拒赔」**，也不能把「未如实告知」说成「已如实告知」。

### 4.5 条款核查必看项（每条都要落到合同页码）

| 核查项 | 看什么 | 为什么重要 |
|---|---|---|
| 保险责任 | 赔哪些疾病/状态，分几档赔付 | 决定保额能不能覆盖实际损失 |
| 责任免除 | 不赔的情形清单 | 合同里最容易被跳过、也最关键的一节 |
| 等待期 | 起算日、天数、期满前出险的处理口径 | 决定生效时间 |
| 犹豫期 | 天数、退还口径、解除方式与通知期限 | 决定能不能反悔 |
| 健康告知 | 问了几问、问了什么、是否问了既往检查异常 | 决定告知义务范围 |
| 疾病定义 | 各项疾病的定义原文与诊断标准 | 「确诊」不等于「达到定义」 |
| 赔付方式 | 一次性给付比例、多次赔付、分组 | 决定同一疾病能赔几次 |
| 现金价值表 | 各保单年度对应现金价值 | 决定退保损失 |
| 保费与豁免 | 保费缴清年限、豁免触发条件 | 决定长期可维持性 |

## 五、核心规则与要件库

出结论前，**必须先读**：

- `rules/critical-illness-rules.md`：犹豫期与等待期口径对照、退保损失测算口径、健康告知问询项结构、带病投保核保结论类型、条款逐条核查清单、防误伤（否定词）清单、争议处理路径。

**不得凭印象套用犹豫期天数**；**不得用现金价值等于已交保费的算法**；**不得把等待期内出险写成一定赔或一定不赔**；**不得推荐具体产品或具体条款编号**。

## 六、脚本用法

```bash
python scripts/cooling_off_calc.py --file case.json --out 重疾险犹豫期与退保测算.md
python scripts/cooling_off_calc.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：合同成立日、合同约定犹豫期天数、已交保费、投保年度、现金价值（按对应保单年度取值）、是否在犹豫期内申请解除、等待期约定天数等 |
| `--text` | 直接给 JSON 字符串 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检 |

输入 JSON 示例：

```json
{
  "contract_date": "2026-03-01",
  "cooling_off_days": 20,
  "paid_premium": 3000,
  "policy_year": 1,
  "cash_value": 0,
  "in_cooling_off": true,
  "waiting_days": 90,
  "paid_months": 1
}
```

脚本输出：犹豫期起算日与到期日、是否仍在犹豫期、已过天数、犹豫期内退保与犹豫期外退保两种口径的测算、退保损失金额、等待期到期日提示、必须由合同与保险公司确认的事项清单。

> 脚本按你填的数据做**静态测算**。犹豫期天数、现金价值、等待期天数**均以保险合同约定与载明的现金价值表为准**；理赔结论由保险公司依合同与事实核定。脚本不判断该不该退，也不预测赔不赔。

## 七、人工确认清单（这步不能省）

- [ ] **合同成立日**取自保险合同载明的成立日期，不是刷卡日、不是销售口头说的日期
- [ ] **犹豫期天数**取自合同条款载明值，不是销售口头承诺
- [ ] 犹豫期是否届满，已向承保公司以书面/官方渠道确认
- [ ] **现金价值**取自合同载明的现金价值表对应保单年度，未用估算值
- [ ] 已交保费与缴费记录核对一致，未把「应交」当成「已交」
- [ ] 健康告知**逐问比对**投保单与实际体检/就诊记录，确认无漏填错填
- [ ] 已确认核保结论类型（标准体/加费/除外/延期/拒保），并与告知内容比对
- [ ] 等待期起算日与天数已按合同确认
- [ ] 疾病定义原文已读，而不是只看产品宣传页上的病种列表
- [ ] 责任免除逐条已读，特别是与自身既往病史相关的那几条
- [ ] 需要核赔结论的，已向保险公司书面咨询并留存记录

## 八、最常见的坑

1. **把犹豫期和等待期当成一回事。** 犹豫期是给你反悔的，等待期是给保险公司防带病投保的。两个期限可能起算不同、长短不同、处理方式完全不同，**混着算一定会算错**。
2. **用错起算日。** 犹豫期从**合同成立日**起算，不是从你付第一笔保费那天起算，也不是从签单那天起算。差三五天，可能就跨过了到期日。
3. **以为犹豫期内能全额拿回。** **犹豫期内的退还范围、扣除项目与标准以合同约定为准**；犹豫期外退保只能按现金价值表拿，**前期现金价值可能远低于已交保费**。用「退保＝拿回全部保费」去做决策，是最贵的误解。
4. **以为等待期内确诊「不赔就没损失」。** 等待期内出险的处理方式**以条款约定为准**，常见口径涉及退还已交保费或终止该责任。**不要自己下结论说一定赔，也不要说一定不赔。**
5. **把体检异常当成确诊填进健康告知，或者反过来瞒着不填。** 前者可能带来不必要的责任除外，后者是**未如实告知**。两种做法都会影响核保结论与后续理赔。
6. **投保后不核对核保结论。** 带病投保往往不是被拒保，而是**加费**或**责任除外**。不主动核对，到理赔时才发现某项责任早被除外。
7. **只看宣传页的病种列表，不看疾病定义原文。** 「确诊某病」不等于「达到合同约定的疾病定义」。分组、赔付比例、多次赔付条件全在条款里。
8. **跳过了「责任免除」这一节。** 免责条款往往写在条款中段，格式和正文一样，很容易被翻过去。既往症、先天性疾病、特定行为、特定时间段内的情形，是常见的除外类别。
9. **在犹豫期届满后才开始问「能不能退」。** 犹豫期是**有期限的程序权利**，错过就是错过。**犹豫期天数以合同约定为准**，不要按听说来的天数安排时间。
10. **把「销售说能赔」当结论。** 销售的口头说明不构成理赔依据。理赔结论只看保险合同条款与事实认定。

## 九、边界与免责

- 本技能用于投保前后条款核查与口径梳理，**不构成保险代理、保险经纪或法律意见**，不替代保险合同的约定与保险公司的理赔核定
- **犹豫期天数以合同约定为准；犹豫期内退保的退还范围以合同约定为准；现金价值以合同载明的现金价值表为准；等待期天数与期满前出险的处理方式以合同条款为准**
- 疾病定义、赔付比例、分组与多次赔付条件**均以保险合同条款为准**，不同产品差异很大，不得互相套用
- 如实告知义务的判定、拒赔与解除合同的效力，**以法律规定、保险合同约定与保险公司的核定结论为准**
- 本测算为**静态口径**，未含保单贷款、减额交清、加保、续保、宽限期与复效等情形
- **不承诺一定能赔、一定能退、能退多少、能拿多少**；**不劝诱退保，也不劝诱加保或换产品**；不推荐具体保险公司与具体产品
- 不作任何医学诊断、不给医学结论、不替代体检与就医
