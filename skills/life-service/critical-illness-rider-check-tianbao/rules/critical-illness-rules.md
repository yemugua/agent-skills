# 重疾险犹豫期、等待期与条款核查规则库

> 本规则库按长期人身保险合同的常见结构整理。**犹豫期天数、等待期天数、现金价值、疾病定义、责任免除一律以保险合同条款与载明的现金价值表为准**。本库不预测理赔结果，不得据此对外承诺赔付或退还金额。

---

## 一、犹豫期口径

### 1.1 定义与作用

犹豫期是长期人身保险合同成立后，投保人可以**反悔、解除合同**的一段时间。犹豫期内解除合同与犹豫期届满后解除合同，**退还口径完全不同**。

| 项目 | 口径 |
|---|---|
| 起算日 | **合同成立日**，以保险合同载明的成立日期为准 |
| 天数 | **以合同约定为准**。不同产品、渠道、投保方式的约定天数可能不同 |
| 作用 | 保护投保人，给一段不承担长期成本的反悔窗口 |
| 是否可以延长 | 以合同约定为准；**不得默认延长，也不得默认缩短** |

### 1.2 到期日推算

```
犹豫期到期日 = 合同成立日 + 合同约定的犹豫期天数
是否仍在犹豫期 = 申请解除之日 ≤ 犹豫期到期日
已过天数 = 申请解除之日 − 合同成立日
```

**边界情形处理**：

- 申请解除之日**恰好等于**到期日：按合同约定的「含当日 / 不含当日」口径判断，**不确定时必须向承保公司确认，不得自行推定**
- 申请解除之日**早于**到期日：仍在犹豫期，按犹豫期口径处理
- 申请解除之日**晚于**到期日：犹豫期已届满，按现金价值口径处理

### 1.3 解除合同的时限与通知方式

- **犹豫期内解除合同的申请期限，以合同约定与法律规定的口径为准**
- 通知方式（书面、线上申请、柜面）以合同约定与承保公司的实际操作口径为准
- **不得假设「口头说一声就算解除」**；应以合同约定的通知方式与留痕方式办理

## 二、等待期口径

### 2.1 定义

等待期是合同生效后、**保险责任开始承担前**的一段限制期，目的是防止带病投保。等待期**不是犹豫期**，两者起算日、长度、期满后后果都不同。

| 维度 | 犹豫期 | 等待期 |
|---|---|---|
| 保护对象 | 投保人 | 保险人 |
| 起算日 | 合同成立日 | **以合同约定为准**，可能与合同成立日相同，也可能另有约定起算点 |
| 长度 | **以合同约定为准** | **以合同约定为准**，且不同责任可能分别约定不同天数 |
| 期满前出险 | 与保障责任无关，属反悔期 | **处理方式以条款约定为准**，不得自行判定赔或不赔 |
| 期满后 | 不再受犹豫期约束，可继续持有或按现金价值解除 | 按保险责任与疾病定义判定是否属于保险事故 |
| 轻症/ 中症 / 重疾责任 | 各自可能有独立等待期约定 | **必须逐项核对，不要只看主险的等待期** |

### 2.2 等待期内出险的处理口径

**正确写法**：「等待期内确诊或发生保险事故的处理方式，以保险合同条款约定为准，需向承保公司确认，常见口径涉及退还已交保费或终止对应责任。」

**错误写法**（一律禁止）：

- 「等待期内确诊一定不赔」——把条款口径说成绝对结论
- 「等待期内确诊也赔」——同上
- 「等待期内确诊退本金」——没看到合同就下退还结论

## 三、退保损失测算口径

### 3.1 基本公式

```
退保损失 = 已交保费 − 可退金额
```

| 情形 | 可退金额口径 |
|---|---|
| 犹豫期内解除合同 | **合同约定的退还范围**（可能扣除合同约定的手续费用），**以合同约定为准** |
| 犹豫期届满后解除合同 | **合同载明的现金价值表**中对应保单年度的金额 |

### 3.2 现金价值的三个要点

1. **现金价值 ≠ 已交保费**。长期人身险前期现金价值通常明显低于已交保费
2. **现金价值随保单年度递增**。退保时按**对应保单年度**的表值，不按已交保费比例折算
3. **现金价值以合同载明的现金价值表为准**。销售口头说的「退多少」不构成依据

### 3.3 防误伤清单（退保相关）

| 见到这些表述 | 必须这样判 | 严禁这样写 |
|---|---|---|
| 「犹豫期内退保能全额拿回」 | 判为**按合同约定的退还范围处理，可能有约定扣除** | 「一定全额退还」 |
| 「现金价值等于已交保费」 | 判为**现金价值以现金价值表为准，通常低于已交保费** | 等式写法 |
| 「已退保」 | 只有**已完成解除并收到款项**才算已退保 | 提交申请即写已退保 |
| 「未退保」 | 未提交申请或未完成款项到账，判为**未退保** | 「反正也退不了」 |
| 「还在犹豫期」 | 只在申请日 ≤ 到期日时成立 | 用「刚买没多久」推定 |
| 销售口头说的天数 | 判为**待以合同条款核实** | 直接写入结论 |

**表述纪律**：**不劝诱退保，也不劝诱加保**。只做口径测算与条款核查。

## 四、健康告知与如实告知义务

### 4.1 告知义务的基本结构

| 项目 | 口径 |
|---|---|
| 询问来源 | **保险合同约定的投保告知问卷**（纸质投保单或电子投保单） |
| 回答原则 | **问什么答什么**。问卷列明的每一问，按实际情况回答 |
| 未问到的情况 | 按保险合同条款的约定处理；**不因「没问」而当然免除，也不因「没说」而当然需要主动申报**，**具体以条款约定与法律规则为准** |
| 回答口径 | 有确诊记录按确诊回答；仅体检异常、仅指标偏高、医生建议随访观察的，**如实说明「曾检查发现异常、尚在随访、未确诊」**，不擅自升格为「已确诊」，也不擅自降格为「无异常」 |
| 修改方式 | 投保后发现填错的，**应尽快按承保公司规定的渠道主动补充更正**，不要沉默 |

### 4.2 常见回答错误

| 错误 | 后果 |
|---|---|
| 凭感觉答，认为指标「问题不大」就填「否」 | 构成未如实告知的典型情形 |
| 把体检异常填成「已确诊」 | 可能导致不必要的责任除外或加费 |
| 把医生口头「随访观察」当成「无异常」不填 | 该项未如实回答 |
| 只答「是/否」不写具体项目名称与时间 | 后续核保与理赔时无法自证 |
| 投保后再补填，认为「没说就不算」 | 补充说明的时点与内容同样重要，**以承保公司核定为准** |
| 替家人统一填「都是健康的」 | 每个人的告知问卷各自独立，不能相互代替 |

### 4.3 带病投保的核保结论类型

| 结论类型 | 含义 |
|---|---|
| **标准体承保** | 按标准费率承保，无附加条件 |
| **加费承保** | 按高于标准的费率缴费后承保 |
| **责任除外承保** | 承保，但将某项原因导致的疾病或责任排除在赔付范围外，其余责任按约赔付 |
| **延期承保** | 暂不作出结论，需补充资料或经观察期后再定 |
| **拒保** | 不予承保 |

**这五类是核保结论的常见类型，具体的判定标准由保险公司的核保规则决定，实际结论以保险公司出具的核保结论通知为准。**

### 4.4 责任免除与理赔影响的表述纪律

- 可以说：**「未如实告知可能导致保险人依合同约定与法律规定不承担给付责任，并可能解除合同」**
- 可以说：**「如实告知后可能出现加费、责任除外、延期或拒保等核保结论」**
- 不可以说：「隐瞒了就一定拒赔」（结论绝对化）
- 不可以说：「没告知不算问题」（淡化义务）
- **不得把「未如实告知」写成「已如实告知」**，也不得把「已如实告知」写成「未如实告知」
- 个案是否构成未如实告知、如何处理，**由保险公司依事实与合同约定核定，涉及争议应咨询律师**

## 五、条款核查清单（逐条落到合同页码）

### 5.1 必看十项

| 序号 | 核查项 | 记录什么 | 常见问题 |
|---|---|---|---|
| 1 | 合同成立日与生效日 | 两个日期是否相同 | 混为一谈 |
| 2 | 犹豫期天数与退还口径 | 天数、起算、退还范围、解除通知方式 | 用销售口头天数 |
| 3 | 等待期 | 起算日、天数、是否分轻症/中症/重疾分别约定 | 只看主险等待期 |
| 4 | 保险责任 | 赔哪些疾病或状态、分几组、赔付比例 | 只看宣传页病种列表 |
| 5 | 责任免除 | 不赔情形清单、是否分项列明 | 整节翻过去 |
| 6 | 健康告知 | 问了几问、问了什么、是否涉及检查异常 | 没拿到问卷原件 |
| 7 | 疾病定义 | 定义原文与诊断标准、是否要求达到特定状态 | 认为确诊即赔 |
| 8 | 赔付方式与次数 | 一次性/多次、间隔期、分组赔付规则 | 以为同一疾病能无限赔 |
| 9 | 现金价值表 | 各保单年度对应数值 | 用已交保费代替 |
| 10 | 保费与豁免 | 缴清年限、豁免触发条件、宽限期与复效 | 长期持有能力未评估 |

### 5.2 责任免除常见类别（用于定位，不用于认定个案）

| 类别 | 典型表述方向 |
|---|---|
| 既往症类 | 投保前已存在的疾病或症状 |
| 先天与遗传类 | 先天性、遗传性疾病 |
| 特定疾病类 | 条款单独列明的特定疾病或特定状态 |
| 特定行为类 | 特定时间段内的特定行为、危险活动、酗酒等 |
| 非约定原因类 | 非保险合同约定的疾病、非约定的诊疗方式 |
| 主观行为类 | 故意行为、欺诈行为 |
| 未按约就医类 | 未按约定期限就医、擅自中断治疗等 |

**免责条款的定位方式**：在合同中检索「责任免除」「不承担」「除外」等关键词所在章节，逐条读原文。

**条款解释原则**：对格式条款存在争议时，按**不利于提供格式条款一方**的解释原则处理，**具体适用以法律规定与司法实践为准**。投保时的重点是把免责条款**读懂并留存**。

## 六、争议处理路径

| 情形 | 建议路径 |
|---|---|
| 犹豫期是否届满有争议 | 向承保公司书面/官方渠道确认并留存记录 |
| 现金价值金额有争议 | 调取合同载明的现金价值表与保单年度对应行 |
| 等待期内出险处理有争议 | 书面咨询承保公司，取得书面答复 |
| 核保结论有异议 | 按承保公司渠道申请复核 |
| 拒赔或解除有争议 | 收集投保单、告知问卷、条款文本、病历，走投诉与调解渠道，必要时咨询律师 |

**不建议**：在争议未解决前继续缴费或贸然退保，以免影响自身权益主张；也不建议通过社交媒体施压等非正规方式处理。

## 七、防误伤（否定词）总清单

| 见到这些情况 | 必须这样判 | 严禁这样写 |
|---|---|---|
| 犹豫期内申请解除 | 判为**仍在犹豫期**，退还范围以合同约定为准 | 「一定能全额退」 |
| 犹豫期已届满 | 判为**按现金价值表口径** | 「按已交保费退」 |
| 现金价值低于已交保费 | 判为**正常现象**，退保损失为正 | 「亏了，公司坑人」 |
| 等待期内出险 | 判为**处理方式以条款约定为准** | 「一定赔」/「一定不赔」 |
| 未如实告知 | 判为**可能导致不承担给付责任** | 「必定拒赔」 |
| 已如实告知 | 判为**需核保结论确认** | 「肯定能保」 |
| 非保证收益 | 判为**非保证** | 「保证收益」 |
| 未退保 | 判为**未退保** | 「已退保」 |
| 已退保 | 仅在解除完成且款项到账时成立 | 「已提交申请」 |
| 演示/建议数据 | 判为**非合同载明值，待以合同核实** | 直接当结论写 |

## 八、免责

本规则库为投保实践整理，**不构成保险代理、保险经纪或法律意见**。犹豫期天数、等待期天数、现金价值、疾病定义、责任免除、赔付比例**均以保险合同条款与载明的现金价值表为准**；如实告知义务的判定与理赔结论**以法律规定、合同约定与保险公司的核定为准**。**以现行规定和金融监管部门口径为准。** 不劝诱退保，不推荐具体产品，不作医学结论。
