# 述职量化规则库

## 一、指标选取规则

| 规则 | 口径 | 违反后果 |
|---|---|---|
| 指标数量 | **5-8 项**；少于 3 项显得工作量薄，多于 12 项每项都讲不深 | 评委抓不住重点 |
| 权重合计 | = 1.0，单项权重不超过 0.5 | 加权达成率失真 |
| 指标构成 | 业务结果类 ≥ 2 项 + 质量/效率类 ≥ 1 项 + 协同/成长类 ≥ 1 项 | 只写业绩不写质量，容易被质疑透支 |
| 每项必备四数 | 本期值、上年同期值、上一周期值、目标值 | 缺基线 = 无法证明增长 |
| 单位必填 | 万元 / 次 / 天 / 分 / % / 件 / 人 | 无单位口径不清，会被追问 |
| 目标来源 | 注明「年初定」或「年中调整为」 | 隐去调整属口径操纵 |

## 二、三个口径的计算公式

```
同比       =（本期值 - 上年同期值）÷ 上年同期值 × 100%
环比       =（本期值 - 上一周期值）÷ 上一周期值 × 100%
达成率(up) = 本期值 ÷ 目标值 × 100%
达成率(down)= 目标值 ÷ 本期值 × 100%
加权达成率 = Σ(单项达成率 × 权重) ÷ Σ权重      单项按 120% 封顶
量化覆盖率 = 有数值且基线完整的指标数 ÷ 指标总数
```

**单项封顶 120% 的原因**：不封顶的话，一项超额 300% 的指标会把整体达成率抬上去，掩盖其他未达项。

## 三、单项等级判定

| 方向 | 达成 | 基本达成 | 未达成 |
|---|---|---|---|
| up（越大越好） | ≥ 100% | 90% - 100% | < 90% |
| down（越小越好） | ≤ 100%（实际 ≤ 目标） | 100% - 110%（超出目标 10% 以内） | > 110% |

## 四、整体判定档位

| 加权达成率 | 判定 | 述职怎么写 |
|---|---|---|
| ≥ 100% | 达成 | 正常陈述，重点讲关键动作 |
| 90% - 100% | 基本达成 | 说明未达项与止损动作 |
| 70% - 90% | 部分达成 | 必须给根因与下期改进计划 |
| < 70% | 未达成 | 如实陈述，重心放在下期计划 |

**量化覆盖率红线**：低于 80% 不建议提交——说明述职还停留在定性描述阶段。

## 五、四象限交叉核查（最关键的一栏）

| 同比 | 达成率 | 真实情况 | 处理 |
|---|---|---|---|
| ↑ | ≥100% | 真增长真达成 | 重点写，给关键动作 |
| ↑ | <100% | 有增长但没够到目标 | 说明目标高度与增长节奏 |
| ↓ | ≥100% | **目标定低了** | 必须主动说明，避免被追问 |
| ↓ | <100% | 真实下滑 | 给根因与止损动作 |

## 六、定性转定量对照表

| 定性词 | 替换口径 | 数据来源 |
|---|---|---|
| 大幅提升 | 数值 + 变化幅度 + 起止时间 | 系统日志 / 台账 |
| 明显改善 | 改善前后的具体数值与百分比 | 前后对比记录 |
| 积极参与 | 参与次数、负责模块、交付件 | 项目清单 |
| 优化流程 | 环节数变化、单均耗时变化 | 流程图 + 计时 |
| 保障稳定 | 可用率、故障次数、MTTR | 监控平台 |
| 获得好评 | 满意度分值、投诉件数、样本量 | 问卷 / 工单 |
| 完成日常 | 处理量、响应时长、一次解决率 | 工单系统 |
| 能力成长 | 新增技能、认证、承担的新职责 | 培训与项目记录 |

**禁用词清单**：显著提升、大幅提升、明显改善、圆满完成、积极、努力、认真、高度重视、稳步推进、成效显著。出现即替换为数值。

## 七、禁用表述与替代表述

| 禁用 | 替代 |
|---|---|
| 我主导了整个项目 | 我负责 XX 模块，交付 XX |
| 因为别的部门导致延期 | 协同链路长，我在 XX 环节提前介入后改善 |
| 在资源不足的情况下 | 我用 XX 方式补齐缺口，结果是 XX |
| 基本完成 | 8 项达成 6 项，加权 96%，未达项为 C、D |
| 得到了领导认可 | 在 XX 评审中通过，结论为 XX |
| 明年继续努力 | 下期目标 XX，关键动作三项，需 XX 支持 |

## 八、问题段写法（3 段式）

```
① 事实：XX 指标为 XX，目标 XX，缺口 XX（先给数，不解释）
② 根因：根因是 XX（落到自己能改的环节，不归因他人）
③ 动作：已启动 XX，预计 XX 见效，下期目标 XX
```

问题段写 **2-3 个**即可。写 0 个显得不反思，写 5 个以上说明这一年失控。

## 九、计划段写法（必须含三项）

```
目标值    ：下期 XX 指标达到 XX（具体数值）
关键动作  ：三项，每项写清「做什么 + 什么时候做完」
所需资源  ：人力 / 预算 / 协同支持，明确到量级
```

缺「所需资源」的计划段最容易被判定为空话。

## 十、时间轴与篇幅参考

| 述职类型 | 篇幅 | 数据段指标数 | 建议准备时间 |
|---|---|---|---|
| 季度述职 | 800-1200 字 / 5 页 PPT | 3-5 项 | 提前 3 天 |
| 年度述职 | 1500-2500 字 / 10-15 页 PPT | 5-8 项 | 提前 1-2 周 |
| 转正述职 | 800-1500 字 / 6-8 页 PPT | 3-5 项 | 提前 5 天 |
| 晋升答辩 | 2000-3000 字 / 15-20 页 PPT | 5-8 项 + 能力项 | 提前 2-3 周 |

**数据准备要提前**：述职前一周才去拉数，通常拉不全；建议按月留存台账。
