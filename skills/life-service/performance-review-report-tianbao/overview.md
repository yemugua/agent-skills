# 述职汇报撰写与业绩量化核查

## 你会得到什么

一套把「这一年干了什么」说清楚的述职写法，避免通篇形容词、评委听完不知道你到底把什么从多少变成了多少。

- **四段结构与字数配比**：结论 10% / 数据 50% / 问题 20% / 计划 20%，每段给一句话模板。
- **三个量化口径**：同比、环比、目标达成率的公式，其中越小越好类（故障、成本、耗时）达成率 = 目标 ÷ 实际，很多人算反。
- **四象限交叉核查**：同比涨 / 跌 × 达成率达标 / 未达，四种组合各自的真实情况与写法，其中「同比下滑却达成 104%」是最容易被追问的一栏。
- **指标选取规则**：5-8 项、权重合计为 1、业务结果类 ≥2 项 + 质量效率类 ≥1 项 + 协同成长类 ≥1 项。
- **定性转定量对照表**：显著提升、积极参与、保障稳定、获得好评等八类定性说法各自换成什么数、从哪儿取数。
- **禁用词与替代表述**：十九条禁用表述对照，含自夸边界与甩锅边界。
- **脚本核算**：`scripts/perf_metric_calc.py` 一次算出加权达成率、量化覆盖率、逐指标等级，并给出基线缺失、口径不清、达成超标但同比下滑、权重不为 1 等提醒。

## 典型用法

- 年底述职，先算加权达成率再动笔
- 只有一堆事、没有数字，按定性转定量表换成数值口径
- 故障率、成本、耗时这类指标，核对达成率有没有算反
- 目标年中调过，核查述职里有没有隐去调整
- 晋升答辩，按四段配比搭 PPT 页序

## 边界

不代替公司绩效考核制度与人力部门口径，考核维度、权重与评级规则以公司制度为准。不替你编造没有发生过的数字，所有数据须本人核实，未上线、未验收、未确认的项目不得按已达成口径写。不保证评级结果或晋升通过。脚本只做算术与结构核查，不判断目标合理性与数据真实性。
