# 职业健康监护档案与体检合规管理（occupational-health-archive）

职业健康这块，**档案是证据链，体检是防火墙**：没档案等于没监护，没岗前体检就安排上岗是硬伤，体检异常不处置比不做体检更危险。

这个技能做四件事：**建档案** → **排体检** → **跟异常** → **管周期**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 讲解监护档案与体检合规要求 | ❌ 替代职业健康检查机构的检查与结论 |
| 生成档案目录表与体检台账 | ❌ 出具职业病诊断 |
| 整理周期与异常处置流程 | ❌ 保证体检结果 |
| 输出档案体检报告 | ❌ 判定个体健康状况 |

**以下情况立即送医并按应急职业健康检查流程处置，不走常规周期：**
- 作业中或作业后出现急性中毒症状
- 发生职业病危害事故（泄漏、爆燃等）
- 劳动者自述明显职业禁忌相关症状

**永远不要**把员工个人健康信息拍照发群、公开排名、随意放置。职业健康监护档案属**个人隐私健康信息**，专人专柜、查阅审批、离职可复制。

## 三、监护档案内容清单（一人一档）

依据《用人单位职业健康监护监督管理办法》等规定，为**每名接触职业病危害作业的劳动者**建立职业健康监护档案，内容包括：

1. **个人基本信息**：姓名、性别、年龄、工种、接触职业病危害因素、入职/离岗日期
2. **职业史**：既往工作单位、工种、接触危害因素及年限
3. **职业病危害接触史**：现岗位危害因素种类、接触水平（检测结果对应）
4. **既往病史**：与职业禁忌相关的既往疾病
5. **家族病史**：法定要求问询的家族遗传类情况
6. **个人生活史**：吸烟、用药等检查机构要求采集的项目
7. **职业健康检查结果及处理情况**：各次检查的结论、复查安排、处理意见
8. **职业病诊疗资料**：如进入诊断治疗流程的相关资料
9. **其他资料**：应急职业健康检查记录、离岗时检查记录等

> 具体名目**以现行规定和职业健康检查机构要求为准**；档案应动态更新，劳动者**有权复制本人档案复印件**。

## 四、体检四类型与周期表

| 类型 | 什么时候做 | 要点 |
|---|---|---|
| **上岗前** | 安排从事接触职业病危害作业**之前** | 发现职业禁忌证的不得安排上岗；未经岗前检查不得安排接触危害作业 |
| **在岗期间** | 按危害因素周期定期做 | 早发现早调离，周期见下表 |
| **离岗时** | 脱离危害作业时 | 明确脱离时的健康状况，分清责任 |
| **应急** | 事故或出现急性症状后 | 立即启动，不走常规周期 |

**在岗期间体检周期简表**（依据 GBZ 188-2014，简化口径，具体以标准文本为准）：

| 危害因素 | 周期 |
|---|---|
| 噪声作业（≥85dB） | 1 年 |
| 矽尘等无机粉尘 | 1 年 |
| 煤尘、其他粉尘 | 2 年 |
| 化学毒物 | 按毒物种类与接触水平 1～2 年 |
| 高温作业 | 1 年 |
| 其他因素 | 按 GBZ 188 对应条款 |

> **离岗检查简化规则**：离岗前 90 日内的在岗期间职业健康检查，可视同离岗时职业健康检查（GBZ 188 口径）；没有的必须补做离岗时检查。

## 五、异常处置闭环

```
检出异常/疑似职业病 → 安排复查（90日内按机构意见）→ 必要时申请职业病诊断
→ 诊断成立：调离原岗位、落实治疗与待遇 → 归档随访记录 → 更新档案
```

- 检查机构给出"复查""疑似职业病"意见的，**按意见期限复查，不得拖过年检周期**
- 有职业禁忌证的，**调离禁忌作业岗位**，不是"注意点就行"
- 处置的每个动作（复查单、诊断书、调岗单）都要进档案

## 六、脚本用法（档案体检）

```bash
python scripts/health_archive_check.py --file "D:\EHS\监护档案.json"
```

| 参数 | 说明 |
|---|---|
| `--file` | 必填。监护档案 JSON |
| `--today` | 核查基准日，默认今天 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本检查六类问题：**档案内容缺口、未做上岗前体检、在岗体检超期、离岗无体检、异常无随访、检查结果无签章**。

> ⚠️ 脚本只做结构与逻辑检查，**不判定健康状况、不替代检查机构与诊断机构结论**。

## 七、人工确认（这步不能省）

- [ ] 危害因素辨识与检测是否覆盖所有岗位
- [ ] 体检机构是否具备职业健康检查资质（备案可查）
- [ ] 体检项目是否与危害因素对应（接噪声的不查听力等于白查）
- [ ] 异常人员是否按意见复查、职业禁忌是否调岗
- [ ] 档案是否专人专柜、查阅是否有审批记录
- [ ] 离职人员档案是否留存、是否提供复印件

---

## 八、输出结构（固定三段）

1. **能不能过关**——结论先行：档案齐全 / 有缺口 / 有红线问题
2. **核对清单**——逐项标合规/缺失/存疑
3. **整改与补资料建议**——先后顺序、责任岗位、留存材料

---

## 九、最常见的坑

**坑一：先上岗后体检。** 入职三个月才补岗前体检，这三个月就是违法窗口期。

**坑二：档案在人手一叠纸。** 检查来了才发现半数员工没有档案，或档案在离职时被当废纸处理。

**坑三：体检周期一刀切。** 全员一年一次，噪声和粉尘混同，漏检错检一起发生。

**坑四：异常不复查。** 报告写"建议复查"没人跟，拖成疑似职业病，企业全责。

**坑五：禁忌不调岗。** 有职业禁忌证继续上岗，出事就是"未按规定调离"。

**坑六：档案公开化。** 体检结果全员公示、拍照发群，侵犯隐私反吃投诉。

## 十、边界与免责

- 本技能**不替代**职业健康检查、职业病诊断法定程序；周期与名目**以现行规定和检查机构要求为准**

- 不得依据本技能出具任何医学结论
- 规程要点为管理实践方法论整理，**不构成执法或诊断结论**
