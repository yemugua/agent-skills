# 热水器除垢

## 1. 硬边界（能做什么 / 不能做什么）

| 能做 | 不能做（转专业人士） |
|---|---|
| 断电断水、排空、拆排污口清垢 | 拆加热管、动内胆焊接 |
| 检查 / 更换镁棒 | 内胆漏水、锈穿的更换 |
| 冲洗内胆、复位 | 电路 / 温控器维修 |

内胆漏水、加热管烧断、漏电保护跳，转维修。

## 2. 什么时候用

| 用户说法 | 用不用 |
|---|---|
| 加热变慢、电费涨 | 用（结垢隔热） |
| 出水忽大忽小、有杂质 | 用（清排污口） |
| 用了 1–2 年没保养 | 用（查镁棒除垢） |
| 内胆漏水 / 漏电 | 不用（转维修） |

## 3. 完整工作流

1. **断电断水**：拔插头、关进水阀，安全第一。
2. 开热水龙头泄压，接软管到排污口排冷水。
3. 拧开排污口（多数兼镁棒固定），放空余水，掏出水垢。
4. 检查镁棒：损耗过半（剩 <50% 原径）即换。
5. 从进水口灌水冲洗内胆至清，必要时专用除垢剂循环。
6. 装回镁棒 / 排污口、关严，开进水排空气，确认无漏再通电。

口径见 `rules/descale-rules.md`。

## 4. 核心规则 / 要件说明

生成方案前**先读 `rules/descale-rules.md`**：断电断水顺序、镁棒更换标准、复位检漏。不合格带原因，如「未断电断水：带电带压拆卸有触电 / 喷烫风险」。

## 5. 脚本用法

`scripts/wh_check.py` 自检「除垢操作清单」：

```
python scripts/wh_check.py --file steps.json
python scripts/wh_check.py --selftest
```

## 6. 人工确认清单

- [ ] 已断电、关进水阀
- [ ] 已开龙头泄压、排冷水
- [ ] 镁棒损耗已检查（<50% 径即换）
- [ ] 内胆已冲洗至清水
- [ ] 复位后无漏再通电

## 7. 最常见的坑

1. 不断电断水就拆：喷烫水 + 触电，必须先断。
2. 忘开热水龙头泄压：排污口打不开、内胆憋压。
3. 镁棒不换只清垢：消耗完内胆被腐蚀，一年一查。
4. 装回没排空气就通电：干烧坏加热管，先开进水排尽气。
5. 密封圈不换：装回渗水，旧圈老化必换。
6. 除垢剂留内胆：没冲净，会污染用水，必须冲到清。

## 8. 边界与免责

覆盖储水式电热水器日常除垢与镁棒保养。即热式、燃气热水器、内胆焊接维修不在范围。操作涉及水电，无把握请转持证人员。
