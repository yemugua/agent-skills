# 律师函撰写与回复核查（lawyer-letter-check）

律师函最大的价值往往不是"让对方害怕"，而是**三年后的法庭上，你能证明你主张过**。

写函看三件事：要素齐不齐、有没有违规表述、期限合不合理。
收到函也看三件事：函是真的吗、事实对不对、怎么回才不自认。

这个技能做五件事：**核要素** → **扫违规** → **判期限** → **算时效** → **定应对**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 核查函件要素是否齐全 | ❌ 出具具有法律效力的律师函 |
| 扫描禁止性表述并给修改方向 | ❌ 代替执业律师的签发与盖章 |
| 测算诉讼时效与提示中断方式 | ❌ 认定时效是否真的中断（取决于送达与证据） |
| 给出收到函后的应对思路 | ❌ 代理诉讼、代写诉状、代出庭 |
| 提供模板骨架 | ❌ 套用模板后不经核实直接发出 |

**遇到以下情况，务必转交执业律师：**
- 需要以律师名义正式签发并加盖律所印章的函件
- 争议金额较大，或已临近诉讼时效届满
- 涉及刑事风险、知识产权、涉外、金融等特殊领域
- 需要采取诉讼、仲裁、保全等后续法律行动
- 收到对方函件后判断是否构成自认、是否需反制

**永远不要为了"吓住对方"而加入威胁、侮辱、虚构或曝光隐私的内容。** 这类内容违反执业规范，会削弱函件可信度，甚至反被主张侵权。

## 二、完整工作流

```
第 1 步  分清是"我要发函"还是"我收到函"：--mode send 或 --mode reply
第 2 步  先读规则文件 rules/letter_review.md 与模板 templates/lawyer_letter_template.md
第 3 步  跑核查脚本
    python scripts/lawyer_letter_check.py --mode send --file 律师函.txt --debt-due 2024-05-01
    python scripts/lawyer_letter_check.py --mode reply --file 收到的律师函.txt
第 4 步  逐项人工通读复核（脚本只做关键词检索，不做法律判断）
第 5 步  发函的：修改后交执业律师审核 → EMS 寄送 → 保留签收回执
第 6 步  收函的：六步应对 → 期限内书面回函 → 保留送达凭证
```

## 三、九项必备要素（缺一项就不像正式函件）

| # | 要素 | 缺了会怎样 |
|---|---|---|
| 1 | 标题「律师函」 | 性质不明 |
| 2 | 受函人名称 | 主体不明，送达无效 |
| 3 | 委托关系说明（律所、委托人、承办律师） | 来源不明，对方可质疑发函主体 |
| 4 | 事实陈述（时间线、金额、行为） | 主张无从判断 |
| 5 | 证据指向 | 可信度打折 |
| 6 | 法律依据 | 主张缺乏支撑 |
| 7 | 具体要求（做什么、多少、何时、付到哪） | 不可执行，等于白写 |
| 8 | 履行期限与后果提示 | 催告效力打折扣 |
| 9 | 落款（律所、承办律师、联系方式、日期、盖章） | 形式不完备 |

## 四、六类绝对不能出现的内容（详见 `rules/letter_review.md`）

| 禁止项 | 典型表述 | 处理 |
|---|---|---|
| **威胁恐吓** | 「后果自负」「让你好看」 | 改为「将依法提起诉讼/申请仲裁」 |
| **侮辱诽谤** | 「骗子」「老赖」 | 删除，只陈述客观事实 |
| **绝对化断言** | 「必将承担刑事责任」「100% 胜诉」 | 改为「可能承担相应法律责任」 |
| **冒充公权力** | 「本院」「判处」「已立案」 | 删除或据实表述 |
| **隐私曝光威胁** | 「通知你的家人」「公开曝光」 | 删除 |
| **不当承诺结果** | 「包赢」「一定胜诉」 | 删除 |

**后果提示只能写己方将采取的合法措施**：提起诉讼、申请仲裁、申请财产保全、向主管部门反映。不能写对方"会受到什么惩罚"。

---

## 五、合理期限与送达留痕

| 事项 | 通行做法 |
|---|---|
| 付款催告 | 收到函后 **7~15 日** |
| 停止侵权 | **3~7 日**（视紧急程度） |
| 复杂事项 | **15~30 日** |
| 过短期限 | 1~2 日可能被认为未给予合理期限，削弱催告效力 |
| 发送方式 | **EMS 或挂号信**，内件品名写明「×× 关于 ×× 事宜的律师函」 |
| 凭证 | 寄件单、物流轨迹、**签收回执** |

**发得出不算数，能证明对方收到了才算数。**

---

## 六、诉讼时效（发函最实际的作用之一）

| 事项 | 通行口径 |
|---|---|
| 普通诉讼时效 | 一般为 **3 年**，自权利人知道或应当知道权利受到损害以及义务人之日起计算 |
| 中断事由 | 权利人向义务人提出履行请求、提起诉讼或申请仲裁等 |
| 中断效果 | 从中断时起，诉讼时效期间**重新计算** |
| 最长保护期 | 自权利受到损害之日起超过 **20 年**的，人民法院不予保护 |

**函发了、凭证没了，等于没发。** 时效中断要靠送达凭证来证明。

## 七、脚本用法

```bash
# 发函前核查
python scripts/lawyer_letter_check.py --mode send --file "D:\函件\律师函.txt" --debt-due 2024-05-01

# 收到函后核查
python scripts/lawyer_letter_check.py --mode reply --file "D:\函件\收到的律师函.txt"
```

| 参数 | 说明 |
|---|---|
| `--mode` | `send` 发函前核查 / `reply` 收到函后核查 |
| `--file` | 函件文本（`.txt` / `.md`） |
| `--debt-due` | 债务到期日或知道权利受损日，用于诉讼时效测算 |
| `--as-of` | 核查基准日，默认今天 |
| `--out` / `--format` | 输出路径 / `md` 或 `json` |
| `--selftest` | 跑内置自检（13 条断言） |

脚本做四件事：
1. **九项要素扫描**——逐项查有没有
2. **六类禁止性表述扫描**——命中即给修改方向
3. **履行期限合理性判断**——短于 7 日标存疑
4. **诉讼时效测算**——3 年届满日、剩余天数、未届满/临近届满/已届满三段判定

> ⚠️ 脚本只做关键词检索，**命中不等于一定违规，缺项也不等于函件无效**。必须人工通读复核。

## 八、人工确认清单（这步不能省）

**发函前：**

- [ ] 委托关系清楚，将以执业律师名义出具并加盖律所印章
- [ ] 受函人名称与合同主体/登记信息一致
- [ ] 事实按时间线陈述，每个关键事实都有证据支撑
- [ ] 金额、日期、履行情况核对无误
- [ ] 法律依据具体，不写「根据相关规定」
- [ ] 要求可执行：履行方式、金额、期限、账户齐全
- [ ] 期限合理，未过短
- [ ] 后果表述限于合法措施
- [ ] 无威胁、侮辱、虚构、泄露隐私、冒充公权力内容
- [ ] 发送方式可留痕，已规划签收回执保存

**收函后：**

- [ ] 已核实律所与承办律师真实存在
- [ ] 函中每一句事实已逐条对账，标出属实/不属实/需核实
- [ ] 本金、违约金、利息的算法已单独核对
- [ ] 期限合理性与诉求可执行性已判断
- [ ] 已决定应对方式（全部接受/部分接受/协商/拒绝）
- [ ] 回函已加免责句
- [ ] 回函同样用 EMS 并保留回执

## 九、最常见的坑

**坑一：把律师函当判决书。**
它没有强制执行力，对方不理你，还得走诉讼或仲裁。发函只是第一步。

**坑二：为了吓人写威胁、侮辱的话。**
不仅违反执业规范，还会让函件整体可信度下降，甚至反被主张名誉侵权。

**坑三：事实陈述带情绪、带评价。**
「恶意拖欠」「蓄意欺诈」在函里是负担。写「截至某日尚欠某元未付」就够了。

**坑四：法律依据写「根据相关规定」。**
等于没写。要写清楚是什么法律关系、对方应承担什么责任。

**坑五：要求写得不可执行。**
「请尽快付款」「请妥善处理」没有期限、金额、账户，等于白写。

**坑六：期限写得过短。**
1~2 日会被认为不合理，催告效力打折扣。

**坑七：发出去不留凭证。**
微信发张图片就完事，将来无法证明送达。EMS + 签收回执才是可靠做法。

**坑八：收到函后沉默。**
失去表达立场和保存抗辩记录的机会，也让对方误判形势。不回复不等于事实不成立。

**坑九：回函里笼统认错。**
「我方确实存在一定问题」可能被当作自认。表述要精确到具体事项。

**坑十：发函给无关第三方。**
向对方家人、单位、合作伙伴散发函件内容，可能构成侵犯隐私或名誉权。

**坑十一：忘了算诉讼时效。**
发函的重要作用就是中断时效，函发了、凭证没了，等于没发。

**坑十二：非律师以律师名义发函。**
冒充律师名义出具律师函属于严重违规。本技能提供的是**撰写与核查辅助**，最终应以执业律师名义出具并盖章。

## 十、输出结构（固定五段）

1. **结论先行** —— 要素是否齐全 / 有无禁止性表述 / 期限是否合理
2. **要素核查表** —— 九项逐项标有/缺
3. **禁止性表述清单** —— 类型、命中表述、修改方向
4. **期限与时效** —— 最短履行期限、3 年时效届满日、剩余天数
5. **应对建议** —— 发函的四条提醒，或收函的四步应对与回函铁律

## 十一、边界与免责

- 本技能**不出具具有法律效力的律师函**，不代替执业律师的签发与盖章
- 时效中断的认定、函件的法律效力**以现行法律规定与争议处理机构的认定为准**，本技能不引用具体条款号
- **不代理诉讼、不代写诉状、不承诺任何法律结果**
- 涉及重大金额、临近时效届满或已进入程序的争议，应咨询执业律师
- 不得用于威胁、恐吓、侮辱、诽谤或侵犯他人隐私
