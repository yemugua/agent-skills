# 律师函撰写规范、禁止内容与收到函后的应对

> 律师函的性质、效力与执业规范由**现行法律规定与律师执业行为规范**确定。**以现行规定与承办律师的专业判断为准**，本文件只给撰写与应对方法论，不引用具体条款号。

## 一、律师函是什么，不是什么

| 是 | 不是 |
|---|---|
| **催告与主张**的正式书面方式 | ❌ 判决书、裁定书，没有强制执行力 |
| **固定事实与证据**的手段 | ❌ 认定的事实，事实最终由法院或仲裁机构认定 |
| **中断诉讼时效**的合法事由之一 | ❌ 万能的"吓退"手段 |
| **表明立场、开启协商**的渠道 | ❌ 威胁、恐吓、施压的工具 |
| 律师依法执业的文书 | ❌ 任何人都可以随便署名发出的东西 |

**律师函最大的价值往往不是"让对方害怕"，而是"三年后的法庭上，你能证明你主张过"。**

## 二、律师函的四项真实作用

| 作用 | 说明 |
|---|---|
| **中断诉讼时效** | 权利人向义务人提出履行请求的，诉讼时效中断，从中断时起重新计算 |
| **固定事实与证据** | 函中对事实的陈述与附随证据，构成后续程序中的书证 |
| **催告履行** | 为迟延履行情形下主张解除合同创造前提（经催告后在合理期限内仍未履行） |
| **表明立场与留痕** | 证明己方已尽通知、协商、减损义务 |

## 三、撰写规范：九段结构

| # | 段落 | 要求 |
|---|---|---|
| 1 | 标题 | 「律师函」，不加夸张修饰 |
| 2 | 受函人 | 名称与合同主体/登记信息一致 |
| 3 | 委托关系 | 律所、委托人、承办律师指名 |
| 4 | 事实陈述 | 按时间线客观陈述，含日期、金额、行为；**只陈述，不评价** |
| 5 | 证据指向 | 写明支撑材料名称，不夸大也不虚构 |
| 6 | 法律依据 | 指向具体法律关系，不写「根据相关规定」 |
| 7 | 具体要求 | 可执行：做什么、给多少、何时、付到哪 |
| 8 | 期限与后果 | 合理期限 + **合法**后果（提起诉讼、申请仲裁） |
| 9 | 落款 | 律所名称、承办律师签名、联系方式、日期、盖章 |

## 四、绝对不能出现的内容（红线）

| 禁止项 | 典型表述 | 为什么 |
|---|---|---|
| **威胁恐吓** | 「后果自负」「让你好看」「等着瞧」 | 违反执业规范，可能被投诉，并削弱函件可信度 |
| **侮辱诽谤** | 「骗子」「老赖」「无耻」 | 可能构成名誉侵权，反被对方主张权利 |
| **虚构事实** | 编造合同、金额、日期 | 严重违反执业规范，可能导致执业责任 |
| **伪造证据** | 拼接、篡改单据 | 明确的违法违规行为 |
| **泄露隐私** | 公开对方身份证号、家庭住址、家人信息 | 可能构成侵犯个人信息 |
| **曝光威胁** | 「将通知你的单位/家人」「公开曝光」 | 属于不当施压 |
| **冒充公权力** | 「本院」「判处」「已立案」等暗示已由司法机关处理 | 严重违规 |
| **绝对化断言** | 「必将承担刑事责任」「一定败诉」「100% 胜诉」 | 超越律师身份的判断，不专业且不可靠 |
| **不当承诺** | 「保证能要回钱」「包赢」 | 违规承诺结果 |

**后果提示只能写己方将采取的合法行动**：提起诉讼、申请仲裁、申请财产保全、向主管部门反映。不能写对方"会受到什么惩罚"。

## 五、合理期限（重要但常被写错）

| 事项 | 通行做法 |
|---|---|
| 付款催告 | 收到函后 **7~15 日**较为常见 |
| 停止侵权 | 视紧急程度，**3~7 日** |
| 复杂事项 | 可给 **15~30 日** |
| 过短期限 | 明显不合理的短期限（如 1~2 日）可能被视为未给予合理期限，削弱催告效力 |
| 约定期限优先 | 合同已约定履行期限的，以合同为准 |

## 六、发送与送达留痕

| 事项 | 做法 |
|---|---|
| 方式 | 优先 EMS 或挂号信，**内件品名写明「×× 关于 ×× 事宜的律师函」** |
| 地址 | 合同约定的送达地址；无约定的用注册地址或实际经营地 |
| 凭证 | 寄件单、物流轨迹、**签收回执**（必要时加盖邮政查询章） |
| 拒收 | 保留退件凭证与轨迹，证明已送达约定地址 |
| 电子送达 | 合同约定的邮箱或账号，保留发送与已读记录 |

**发得出不算数，能证明对方收到了才算数。**

## 七、收到律师函后怎么办（六步）

```
第 1 步  核实真伪：查律所与律师是否真实存在，核对函件落款与联系方式
第 2 步  核对事实：函中每一句话逐条对账，标出"属实/不属实/需核实"
第 3 步  核对金额：本金、违约金、利息的算法与依据是否成立
第 4 步  判断诉求合理性：期限是否合理、要求是否可执行、是否有法律依据
第 5 步  决定应对：全部接受 / 部分接受 / 全部拒绝 / 提出反制
第 6 步  书面回复：在期限内回函，保留不构成自认的表述，并留送达凭证
```

## 八、收到函后的四种应对

| 应对 | 适用 | 要点 |
|---|---|---|
| **全部接受** | 事实与金额均无争议 | 按指定方式履行并保留凭证，最好签书面了结协议 |
| **部分接受** | 本金无争议但违约金过高 | 明确写明接受部分、异议部分及理由，避免沉默被推定认可 |
| **协商解决** | 有履行意愿但需分期或调整 | 主动约谈，谈成后签书面协议，不要只靠口头 |
| **全部拒绝** | 事实不成立或已过时效等 | 逐条书面反驳并附证据，保留抗辩记录 |

**沉默是最差的选择。** 不回复不等于事实不成立，反而会失去表达立场和保存抗辩记录的机会。

## 九、回函的三条铁律

| 铁律 | 说明 |
|---|---|
| **不随意承认** | 对无争议部分可以明确认可，对有异议部分必须明确否认并说明理由 |
| **加免责句** | 「本回函不构成对任何责任的承认，亦不放弃我方依法享有的任何权利与抗辩」 |
| **留送达凭证** | 回函同样用 EMS 并保留回执 |

**特别注意自认风险**：协商过程中为表示诚意写的「我方确实存在一定问题」，可能在后续程序中被当作对事实的自认。表述要精确到具体事项，不要笼统认错。

## 十、否定词意识（防误伤）

| 表述 | 正确理解 |
|---|---|
| 「已发出律师函」 | ≠ 对方已收到；≠ 义务已履行；≠ 时效当然中断 |
| 「对方未回复」 | ≠ 对方默认认可 |
| 「对方部分履行」 | ≠ 认可全部债务 |
| 「函中陈述的事实」 | ≠ 已被认定的事实 |
| 「逾期将提起诉讼」 | ≠ 已经起诉 |
| 「愿意协商解决」 | ≠ 承认责任 |

## 十一、常见坑

**坑一：把律师函当判决书。**
它没有强制执行力，对方不理你，还得走诉讼或仲裁。发函只是第一步。

**坑二：为了吓人写威胁、侮辱的话。**
不仅违规，还会让函件整体可信度下降，甚至反被主张名誉侵权。

**坑三：事实陈述带情绪、带评价。**
「恶意拖欠」「蓄意欺诈」这类词在函里是负担。写「截至某日尚欠某元未付」就够了。

**坑四：法律依据写「根据相关规定」。**
等于没写。要写清楚是什么法律关系、对方应承担什么责任。

**坑五：要求写得不可执行。**
「请尽快付款」「请妥善处理」没有期限、没有金额、没有账户，等于白写。

**坑六：期限写得过短。**
1~2 日的期限会被认为不合理，催告效力打折扣。

**坑七：发出去不留凭证。**
微信发个图片就完事，将来无法证明送达。EMS + 签收回执才是可靠做法。

**坑八：收到函后沉默。**
失去表达立场和保存抗辩记录的机会，也让对方误判形势。

**坑九：回函里笼统认错。**
「我方确实存在一定问题」可能被当作自认。表述要精确到具体事项。

**坑十：发函给无关第三方。**
向对方家人、单位、合作伙伴散发函件内容，可能构成侵犯隐私或名誉权。

**坑十一：忘了算诉讼时效。**
发函的一个重要作用就是中断时效。函发了、凭证没了，等于没发。

**坑十二：非律师以律师名义发函。**
冒充律师名义出具律师函属于严重违规行为。本技能提供的是**撰写与核查辅助**，最终应以执业律师名义出具并盖章。

## 十二、发函前自检清单

- [ ] 委托关系清楚，函件将以执业律师名义出具并加盖律所印章
- [ ] 受函人名称与合同主体一致
- [ ] 事实按时间线陈述，每句关键事实都有证据支撑
- [ ] 金额、日期、履行情况核对无误
- [ ] 法律依据具体，不写「根据相关规定」
- [ ] 要求可执行，含履行方式、金额、期限、账户
- [ ] 期限合理，未过短
- [ ] 后果表述限于合法措施
- [ ] 无威胁、侮辱、虚构、泄露隐私、冒充公权力内容
- [ ] 落款要素齐全
- [ ] 发送方式可留痕，已规划签收回执保存
