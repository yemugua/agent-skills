# 律师函通用模板与要素说明

> 模板只解决"结构完整"，不解决"内容成立"。**事实、证据与法律依据必须逐案核实**，不得套用后直接发出。涉及具体权利义务的，应由承办律师审核。

## 一、律师函的标准结构（九段）

| # | 段落 | 写什么 |
|---|---|---|
| 1 | **标题** | 「律师函」三字即可，不加夸张修饰 |
| 2 | **受函人信息** | 名称/姓名、地址，与合同主体一致 |
| 3 | **委托关系说明** | 某律所接受某人（委托人）委托，指派某律师就某事致函 |
| 4 | **事实陈述** | 时间、地点、合同、行为、金额，按时间线客观陈述，**不评价、不辱骂** |
| 5 | **证据指向** | 指出支持事实的材料名称（合同、对账单、送货单等），不附全部证据也可写明"相关证据我方已保全" |
| 6 | **法律依据** | 指明法律关系的性质与对方应承担的责任，不写空泛的"根据相关法律规定" |
| 7 | **具体要求** | 做什么、给多少、什么时候前完成、**付到哪里**，要可执行 |
| 8 | **期限与后果** | 合理期限；逾期将采取的措施（提起诉讼、申请仲裁等） |
| 9 | **落款** | 律所名称、承办律师签名、联系方式、日期、盖章 |

## 二、催告付款类模板骨架

```
律 师 函

致：________（受函人全称/姓名）

________律师事务所（以下简称"本所"）接受________（以下简称"委托人"）的委托，
指派本所________律师，就贵方与委托人之间________一事，特向贵方致函如下：

一、基本事实
    1. ______年__月__日，贵方与委托人签订《________》，约定________。
    2. 委托人已依约于______年__月__日完成________，贵方已于______年__月__日签收/验收。
    3. 依据合同约定，贵方应于______年__月__日前支付款项人民币________元。
    4. 截至本函发出之日，贵方尚有人民币________元未支付，逾期已达____日。
    上述事实有《________》、送货单、对账单、验收记录等证据为证，委托人已妥善保全。

二、法律意见
    贵方未按约定支付款项，已构成违约，应当依约并依法承担继续履行、赔偿损失等违约责任。

三、具体要求
    请贵方于收到本函之日起____日内，将人民币________元支付至以下账户：
        户名：________    开户行：________    账号：________
    并同步支付截至实际付款日的逾期违约金/利息人民币________元。

四、逾期后果
    如贵方在上述期限内未履行，委托人将依法采取包括向人民法院提起诉讼（或依约申请仲裁）
    在内的一切必要措施，届时贵方除应支付上述款项外，还可能承担诉讼费、保全费、
    律师费及其他相关费用。望贵方慎重考虑，避免损失扩大。

特此函告。

________律师事务所
承办律师：________（执业证号：________）
联系电话：________
联系地址：________
______年____月____日
```

## 三、要求停止侵权类模板骨架

```
律 师 函

致：________

本所接受________的委托，指派________律师，就贵方________行为一事致函如下：

一、基本事实
    1. 委托人对________享有________权利，权利凭证为________。
    2. 贵方自______年__月__日起，未经许可实施了________行为，具体表现为________。
    3. 上述行为已对委托人造成________影响/损失。

二、法律意见
    贵方的上述行为已构成对委托人________权的侵害，依法应当承担停止侵害、
    消除影响、赔偿损失等责任。

三、具体要求
    1. 请贵方于收到本函之日起____日内，立即停止________行为；
    2. 于____日内删除/下架/撤回________；
    3. 于____日内以书面方式向委托人赔礼道歉并赔偿经济损失人民币________元。

四、逾期后果
    逾期未履行的，委托人将依法提起诉讼并申请行为保全/财产保全，
    由此产生的一切法律后果由贵方承担。

特此函告。
（落款同上）
```

## 四、回函（受函人回复）模板骨架

```
关于《律师函》的回函

致：________律师事务所  ________律师

贵所于______年__月__日发出的《律师函》已收悉，现就函中所涉事项回复如下：

一、对事实部分的意见
    1. 函中称________一事，与事实不符。实际情况为________。
    2. 函中称________，我方不予认可，依据是________。
    （对无异议的部分，可以明确写明"对________一项我方不持异议"。）

二、对法律意见的意见
    我方认为________，故不构成违约/侵权。

三、我方立场
    1. 我方不同意函中第____项要求；
    2. 我方愿意就________问题在________前提下协商解决；
    3. 请贵所转告委托人于____日内提供________材料，以便进一步核实。

四、其他
    本回函不构成对任何责任的承认，亦不放弃我方依法享有的任何权利与抗辩。

________（回函人）
联系电话：________
______年____月____日
```

> **回函关键句**：「本回函不构成对任何责任的承认，亦不放弃我方依法享有的任何权利与抗辩。」这一句能避免协商过程中的表述被当作自认。

## 五、要素核查清单（发函前逐项打勾）

- [ ] 标题为「律师函」，无夸张修饰
- [ ] 受函人名称与合同主体/登记信息一致
- [ ] 委托关系说明清楚（律所、委托人、承办律师）
- [ ] 事实按时间线客观陈述，含具体日期与金额
- [ ] 每个关键事实都有对应的证据名称
- [ ] 法律依据指向具体的法律关系，不写"根据相关规定"
- [ ] 具体要求可执行：做什么、给多少、什么时间、付到哪
- [ ] 期限合理（一般为收到后 7~15 日，过短会被认为不合理）
- [ ] 后果表述为"将提起诉讼/申请仲裁"等**合法措施**，不含威胁恐吓
- [ ] 无侮辱、诽谤、泄露隐私、曝光威胁的内容
- [ ] 未冒充司法机关或行政机关
- [ ] 落款含律所名称、承办律师、联系方式、日期，并盖章
- [ ] 发送方式可留痕（EMS 并写明内件品名，保留寄件单与签收回执）

## 六、发送与留痕（决定了以后能不能用得上）

| 事项 | 做法 |
|---|---|
| 发送方式 | 优先 **EMS 或挂号信**，内件品名写明「×× 关于 ×× 事宜的律师函」 |
| 收件地址 | 合同约定的送达地址；无约定的用注册地址或实际经营地 |
| 凭证留存 | 寄件单、邮寄费发票、物流轨迹截图、**签收回执**（必要时到邮政查询并加盖查询章） |
| 电子送达 | 合同约定的邮箱或即时通讯账号，保留发送记录与已读状态 |
| 多地址 | 受函人为公司的，可同时寄注册地址与实际经营地 |
| 拒收处理 | 受函人拒收的，保留退件凭证，配合物流轨迹证明已送达约定地址 |

**发得出不算数，能证明对方收到了才算数。** 签收回执是最低成本的可靠凭证。
