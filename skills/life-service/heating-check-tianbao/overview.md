供暖不达标退费核算——先把"这房子是哪种供暖、该找谁"定性，再判达标，最后算能退多少。

北方冬天室温不达标的人很多，但绝大多数不知道三件事：室温法定标准通常是不低于 18℃；**该找的是供热企业不是物业**；不达标是有**法定测温程序**和**退费比例规则**的，不是只能自认倒霉。

本技能补的是"出了室温问题以后怎么判断和算账"：

- 供暖方式定性：集中供暖 / 小区自供暖 / 燃气壁挂炉 / 电采暖，四种的责任主体完全不同
- 达标判定：集中供暖看当地供热条例规定的室温标准（普遍不低于 18℃，部分地区 16~18℃），必须在供热期内、室内正常用热条件下测温
- 测温程序核查：提前报备、供热单位到场、经检定合格的仪器、同时测室外温度、多点多时次、双方签字——缺一项都会让测温记录站不住
- 退费双轨测算：有当地规则或合同约定按规则比例退，无约定按室温缺口对应的实际损失退，并给出可退金额区间
- 处理阶梯：供热企业（首问负责与索赔主体）→ 属地供热主管部门与 12345 → 12315 → 诉讼

输出九段报告：结论摘要 / 供热方式与责任主体 / 是否达标与测温程序 / 退费测算 / 证据缺口 / 处理阶梯 / 时限 / 待办 / 边界与纪律。不替代律师意见，具体标准与退费比例以当地供热条例与主管部门口径为准。
