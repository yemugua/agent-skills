# 退费口径与算式、投诉阶梯、材料与时限

## 一、退费的双轨口径（核心）

**口径一（优先）：当地规则 / 合同约定退费比例**
凡当地供热条例、供热服务细则、供用热合同、供热企业公示的《供热服务承诺》中**写明退费比例或退费公式**的，一律优先按它算。常见形态：

- 按不达标天数 × 日热费 × 固定比例（如"室温每低于标准 1℃ 退 X%"、"不达标按日退还部分热费"）；
- 按档位比例表（如低于标准不超过 2℃ 退 20%、2~4℃ 退 40%、4℃ 以上退 60%~100%，各地下限不同）；
- 供热单位在合同中**书面承诺**的温度未达标的，直接按承诺条款退。

**口径二（兜底）：无约定时按实际损失**
既无地方规则也无合同约定的，按供热企业**实际提供的热量与约定应提供热量之间的差额**折算退还，实务中简化为**室温缺口比例**：

```
室温缺口比例 = (标准室温 − 实测平均室温) / 标准室温
应退金额     = 该供热期已缴热费 × 室温缺口比例（上限为已缴热费）
```

**为什么这样算**：用户支付的热费对应的是"把房间维持在标准温度"这一给付；实际室温低于标准，说明给付不足，理应按不足的比例返还对价——这是《民法典》合同编关于**按约履行与违约救济**的一般逻辑。

**区间而非单一数字**：口径一和口径二得出的数往往不同，报告给的是**区间 [较小值, 较大值]**，并把两个算式都展开，便于你按当地规则挑更有利的那一条主张。

## 二、算式的固定结构（脚本按这个结构输出）

```
输入：已缴热费 F、标准室温 S、实测平均室温 A、供热期天数 D、不达标天数 N、约定/规定退费比例 p
① 室温缺口 Δ = max(0, S − A)            缺口比例 ρ = min(1, Δ / S)
② 口径一：应退₁ = F × p                  （有 p 时）
③ 口径二：应退₂ = F × ρ                  （A、S 都填了时）
④ 可退区间 = [min(口径一, 口径二), max(口径一, 口径二)]，且以 F 为上限
⑤ 参考·按日退还 = (F ÷ D) × N × ρ        （用于当地规则是"按日退还"形态时换算，不得大于 F）
⑥ 尚需追回 = ④ − 已退金额（如已获部分退费）
```

**注意口径一的比例写法**：脚本同时接受 `30`（=30%）和 `0.3`（=30%）。

## 三、自供暖例外：这三种情形没有"热费退费"

| 情形 | 能做什么 |
|---|---|
| 燃气壁挂炉 | 查设备保修与安装合同；不热多为设备/安装/循环/排气问题；燃气供应不足找燃气公司；有人身财产损失的走保险 |
| 电采暖（电热膜、电暖气、热泵） | 设备质量或安装问题走三包/消协；电费与室温不作退费对价 |
| 房屋保温、自家遮挡、长期空置 | 属用户自担部分，可与供热企业协商分担，但不能据此要求全额退费 |

## 四、处理阶梯（按顺序走，别跳步）

**第 1 步 — 向供热企业书面反映，要求测温与退费**
- 对象：**供热企业**（不是物业）。发给客服工单/营业厅/APP，同时抄送物业知悉。
- 内容：哪几天不达标、实测温度、要求按其公示的退费规则在几日内测温并退费。
- 形式：**书面 + 留痕**，索要工单号；对方口头推托的，回一条"请贵单位在 X 日内书面答复"。

**第 2 步 — 属地供热主管部门 / 12345**
- 拨打 **12345**，明确要求派单给**住建（城管/公用事业）部门的供热主管科室**，要求出具处理意见。
- 供热主管部门对供热企业有监督检查职责，其督办函的效力远高于物业的回应。

**第 3 步 — 消协 12315 / 市场监管**
- 供用热合同争议、供热企业公示承诺与实际不符的，可向 **12315** 投诉消费争议；
- 价格、公示、垄断性服务行为问题向**市场监管（价格监督检查）**反映。

**第 4 步 — 诉讼 / 仲裁**
- 依供热合同约定的争议解决方式；没有约定可提起民事诉讼，**诉讼时效 3 年**，自知道或应当知道权利被侵害之日起算。
- 集体案件（同一小区同症状）联合业主举证，效果显著更好。

## 五、材料清单

| 类别 | 具体材料 |
|---|---|
| 主体与合同 | 供用热合同、供热服务承诺书/温度承诺、缴费凭证（发票、收据、银行/微信支付记录）、房产证或租赁合同（证明是该房屋居民） |
| 温度证据 | 双方签字的测温记录（多次）、单方测温的录像与照片、温湿度计自动记录（带时间戳曲线）、同期室外温度（气象台数据截图） |
| 程序证据 | 测温前的书面报备记录（短信/微信/工单号）、供热单位到场人员的工号与照片 |
| 沟通证据 | 与供热企业的通话录音、工单截图、书面回复、客服承诺截图 |
| 自担部分 | 房屋保温照片（单层玻璃、无保温）、暖气片被包死/遮挡的照片（证明装修影响）、改动暖气设施的记录 |
| 金额证据 | 缴费金额与所属供热期、已获退费的金额与凭证 |

## 六、时限清单

| 事项 | 期限 |
|---|---|
| 供热期内主张 | 供热期内（当地条例规定起止）就应书面提出，别拖到供热期结束 |
| 供热期结束后结算 | 多数地区要求供热期结束后一定期限内申请结算退费，以当地规定为准 |
| 民事诉讼时效 | 3 年，自知道或应当知道权利被侵害之日起算 |
| 供热投诉 12345 | 无严格时限，但越晚证据越难固定 |
| 证据固定 | 测温记录 7~30 天内基本会被覆盖/重测，越快越好 |

## 七、纪律

- 不预测诉讼、复议与行政处罚结果。
- 不编造当地退费比例表；各地比例差异极大，**未查到当地规则的，按口径二（实际损失）兜底主张**。
- 数值均为核算参考，最终以供热单位与主管部门核定、司法机关认定为准。
