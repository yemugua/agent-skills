# 供暖信息采集表

> 复制填写。**带斜杠的选项是提示，填写时请删掉不要的部分**，留着斜杠会被判为"未填"。
> 不知道的就写"不清楚"，不要留空。留空会被当成"未填"，不按通过处理。

## 一、基本情况

| 字段 | 值 |
|---|---|
| 所在城市 | （如：石家庄） |
| 供暖方式 | （集中供暖/小区自供暖/燃气壁挂炉/电采暖/不清楚） |
| 供热企业 | （热力公司名称，集中供暖填这个） |
| 物业/管理方 | （小区自供暖或代收代缴填这个） |
| 供热期 | （如：2025-11-05 至 2026-03-31） |
| 供热期天数 | （天数，只填数字） |
| 房屋类型 | （住宅/公寓/商铺/办公） |
| 房屋保温与遮挡 | （正常/单层玻璃无保温/边户顶楼/暖气被包死或遮挡/长期空置） |

## 二、缴费情况

| 字段 | 值 |
|---|---|
| 已缴热费金额 | （元，本供热期实缴，只填数字） |
| 缴费日期 | （如：2025-10-20） |
| 缴费方式 | （热费发票/银行代扣/物业代收/微信支付） |
| 供热合同中是否承诺温度 | （有/无/不清楚） |
| 合同承诺温度 | （如：18℃） |

| 字段 | 值 |
|---|---|

| 实测平均室温 | （℃，多次测温的平均，只填数字） |
| 最低室温 | （℃，只填数字） |
| 最高室温 | （℃，只填数字） |
| 不达标天数 | （天，只填数字） |
| 是否达标 | （是/否/不清楚） |
| 室外温度 | （℃，测温当天的室外温度，只填数字） |

| 报备日期 | （如：2026-01-08） |

| 测温仪器是否检定合格 | （是/否/不清楚） |
