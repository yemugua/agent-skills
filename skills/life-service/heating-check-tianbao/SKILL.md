# 供暖不达标退费核算

室温不达标的人很多，但多数人不知道**室温有法定下限**、**该找的是供热企业不是物业**、**不达标是有法定测温程序和退费比例规则的**。

## 什么时候用

- 屋里白天晚上都是十几度，供热公司说"鼻子不冷就不算不达标"
- 交了全额取暖费，但整个供热期只热了十几天
- 供热单位来测温，一个人拿个仪器量了 30 秒就走，记录没你签字
- 想退费，热线让你找物业、物业让你找供热公司，互相踢皮球
- 是小区自供暖（小锅炉房/壁挂炉），不知道能不能退、该找谁
- 供热期已经结束了，想把这一年或多年的热费要回来

## 怎么做

**第 1 步**：复制 `templates/供暖信息采集表.md` 填写。

**第 2 步**：跑脚本

```bash
python scripts/heating_check.py 采集表.md --base 2026-10-05 --out 核查报告.md
```

**第 3 步**：按第八段"待办补正动作"执行，先补测温记录再谈退费。

## 三句话定性的核心规则

1. **先定性供暖方式**：集中供暖（市政/区域热网）的责任主体是**供热企业**；小区自供暖是**产权单位或物业公司**；燃气壁挂炉、电采暖是**你自己和设备供应商**——**热力企业是首问负责和索赔主体，不是物业**，找错人是最常见的原因。
2. **达标看当地供热条例，普遍口径是室温不低于 18℃**（部分地区 16~18℃），且必须在**供热期内**、**室内正常用热条件**下测温：没有提前报备、没有供热单位到场、仪器未经检定、没测室外温度、没多点多时次取值、没有双方签字的，记录很难被采信。
3. **退费双轨**：有当地规则或合同约定的按规则比例退（各地退费比例表不同）；没有约定就按**室温缺口对应的实际损失**退，脚本给出可退金额**区间**，不是拍一个数。

## 输入 / 输出

| | 内容 |
|---|---|
| 输入 | 采集表 Markdown（供暖方式 / 供热期 / 缴费 / 室温记录 / 测温程序 / 退费约定 / 交涉 / 证据） |
| 输出 | 九段报告：结论摘要 / 供热方式与责任主体 / 是否达标与测温程序 / 退费测算 / 证据缺口 / 处理阶梯 / 时限 / 待办 / 边界与纪律 |
| 退出码 | 0 正常；2 关键信息缺失（给提示串，不崩） |

## 边界与纪律

- 依**通用规则**整理，**不替代律师意见**
- 室温标准、退费比例、测温程序的地方差异极大，**一律以当地供热条例与供热主管部门口径为准**；各地条例可在当地住建（城市管理/公用事业）部门官网、当地政府门户查询
- 不预测行政处罚、复议与诉讼结果
- **自供暖/壁挂炉/电采暖不适用热费退费**，走设备维修、保修与保险路径
- **未填的一律不算通过**，只按填了的判断
