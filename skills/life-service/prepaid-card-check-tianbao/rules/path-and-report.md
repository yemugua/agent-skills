# 维权路径与报案要点

## 1. 七步路径（按紧迫度）
1. **立刻固定证据**：合同、转账记录、聊天截图、会员卡全部拍照备份，原件不删。
2. 确认是否属单用途预付卡未备案，查营业执照与备案。
3. 向 **12315**（热线 / 全国 12315 平台）投诉，写清金额、卡种、商家现状。
4. 向商务主管部门举报未备案 / 违规发卡。
5. 向市场监管举报「虚假宣传 / 格式条款无效」。
6. 商家失联卷款且金额较大：带证据到**公安机关报案**，争取按合同诈骗或非法集资立案。
7. 联合其他消费者集体维权，人数与金额越大越易立案。

## 2. 何时该报警而非只投诉
- 商家**失联 / 人去楼空 / 卷款跑路** → 普通退款通道失效，立即报警。
- 涉案**人数多、金额大**（几十人、十几万以上）→ 达到合同诈骗/非法集资立案门槛概率高。
- 仅凭「拖延退款」一般先走 12315 + 行政举报，不构成刑事立即立案。

## 3. 报案材料清单
- 本人身份证
- 合同 / 会员协议（或电子会员页截图）
- 所有转账记录（微信/支付宝/银行流水）
- 与销售的聊天记录（含退款承诺）
- 商家营业执照信息、门店照片
- 其他受害者名单与联系方式（如有）

## 4. 话术要点
向警方说明：① 明确是「预付消费后商家失联」而非普通纠纷；② 强调涉及**不特定多数消费者**；③ 提供已固定的资金流水证据。
