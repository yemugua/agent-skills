# 退款条款与格式条款效力

## 1. 「概不退款 / 一经售出不退」依法无效
经营者以格式条款（会员协议、办卡须知里的小字）作出「概不退款、一经售出概不退换、最终解释权归本店」等规定，属于**加重消费者责任、排除消费者主要权利**的条款，依《民法典》格式条款规则**无效**。消费者仍可主张退还未消费部分。

## 2. 退款条款的三种情形
- **明确可退**（随时退 / 未消费全额退）：直接据此要求退款，截图留存。
- **按比例 / 扣手续费**：需核算扣留是否合理；明显高于实际损失的扣留可主张无效，按「未消费余额应退」主张。
- **只写不退**：结合宣传承诺、聊天记录证明对方虚假宣传，向市场监管举报该条款并主张退款。

## 3. 口头承诺同样可作证据
销售当时说「随时退」「不行就退」，即便合同写不退，**聊天截图、录音**可证明当初约定，作为有利证据。

## 4. 关键动作
把合同/会员页里退款条款整段截图，与销售承诺聊天记录一并保存——这是后续投诉与诉讼的核心材料。
