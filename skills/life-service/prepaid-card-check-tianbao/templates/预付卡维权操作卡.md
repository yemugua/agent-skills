# 预付卡维权操作卡（逐项打勾）

## 第一步：固定证据（24 小时内做完）
- [ ] 合同 / 会员协议拍照或截图
- [ ] 所有转账记录导出（微信/支付宝/银行流水）
- [ ] 与销售关于「可退」的聊天记录截图
- [ ] 会员卡 / 实体卡拍照
- [ ] 商家门店照片、营业执照信息
- [ ] 宣传单 / 朋友圈承诺截图

## 第二步：判断商家状态
- [ ] 正常营业 → 走协商 + 12315
- [ ] 转让 / 停业 → 书面要求退款并留痕
- [ ] 失联 / 跑路 → 直接报警 + 集体维权

## 第三步：发起投诉
- [ ] 打 12315 / 上全国 12315 平台，写明金额与商家现状
- [ ] 向商务部门举报单用途卡未备案（如适用）
- [ ] 向市场监管举报「概不退款」格式条款无效

## 第四步：报案（仅失联/跑路/大额）
- [ ] 整理报案材料清单
- [ ] 到属地公安机关经侦 / 派出所报案
- [ ] 拉群统计其他受害者人数与总金额

## 第五步：跟进
- [ ] 记录每次投诉/报案的受理编号
- [ ] 每周跟进一次进度
- [ ] 材料统一存一个文件夹备用
