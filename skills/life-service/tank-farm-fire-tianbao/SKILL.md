# 储罐区消防安全（tank-farm-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《石油化工企业设计防火标准》GB 50160 与储罐区要求，生成清单：罐区布置与防火堤、储罐间距与分组、消防冷却水系统、防雷防静电与接地、围堰容积与应急收集。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 储罐区消防
- 罐区防火
- 防火堤
- 储罐间距
- 消防冷却水

## 三、工作流
1. 核查罐区布置与防火堤
2. 核对储罐间距与分组
3. 检查消防冷却水系统
4. 落实防雷防静电与接地
5. 核实围堰容积与应急收集

## 四、核心内容（检查清单与判定）
GB 50160 规定储罐区的布置、防火堤与间距要求；防火堤与围堰须能容纳泄漏量，消防冷却水与防雷防静电是罐区防护关键。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含罐区布置与防火堤 | 布置 |
| Q2 | FAIL | 未含储罐间距与分组 | 间距 |
| Q3 | WARN | 未含消防冷却水系统 | 冷却水 |
| Q4 | FAIL | 未含防雷防静电与接地 | 防静电 |
| Q5 | WARN | 未含围堰容积与应急收集 | 围堰 |

> 脚本 `tank-farm-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python tank-farm-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python tank-farm-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
