# 绿色工厂评价（green-factory）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《绿色工厂评价导则》GB/T 36132，生成清单：基本要求与合规性、基础设施与能源资源投入、产品生态设计、环境排放与绩效、管理体系与自评价报告。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 绿色工厂
- 绿色工厂评价
- 绿色制造
- 绿色工厂申报
- 生态设计

## 三、工作流
1. 核对基本要求与合规性
2. 完善基础设施与能源资源投入
3. 推进产品生态设计
4. 管控环境排放与绩效指标
5. 建立管理体系并做自评价

## 四、核心内容（检查清单与判定）
GB/T 36132 从基础设施、能源资源投入、产品、环境排放与绩效等维度评价绿色工厂；须先合规，再做自评价与申报。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含基本要求与合规性 | 合规 |
| Q2 | FAIL | 未含基础设施与能源资源投入 | 基础设施 |
| Q3 | WARN | 未含产品生态设计 | 生态设计 |
| Q4 | FAIL | 未含环境排放与绩效指标 | 排放 |
| Q5 | WARN | 未含自评价报告 | 自评价 |

> 脚本 `green-factory_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python green-factory_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python green-factory_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
