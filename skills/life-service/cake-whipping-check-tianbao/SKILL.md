# 蛋糕打发

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 给出各类打发的状态判定与温度器具要求 | 判断某个配方是否好吃、是否成功（口感主观） |
| 说明打发失败的成因排查顺序与补救方法 | 承诺补救一定能恢复到理想状态 |
| 整理蛋白、淡奶油、全蛋、黄油的操作要点 | 给出与健康、医疗相关的饮食结论 |
| 输出状态核对、不合格项与原因、补救步骤 | 建议把已经变质的材料继续使用 |

**不属于本技能处理范围的情况**

- 奶油或蛋白已经出现酸味、异味、变色 —— 属于变质，不要使用，也不存在补救
- 需要评价具体品牌、具体配方的优劣 —— 不做产品评价
- 食品安全相关的保存期限判断 —— 以产品包装标示和食品安全常识为准

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「蛋白打不发是什么原因」 | 用，按排查顺序查 |
| 「淡奶油打不发」 | 用，重点查温度与乳脂含量 |
| 「湿性发泡干性发泡怎么区分」 | 用，给状态描述 |
| 「蛋白打过头了还能救吗」 | 用，给分级补救 |
| 「淡奶油打成豆腐渣怎么办」 | 用，给分级补救 |
| 「打蛋白为什么要分次加糖」 | 用 |
| 「蛋白里混了蛋黄还能用吗」 | 用，说明油脂会阻止打发 |
| 「蛋糕出炉塌陷是不是蛋白问题」 | 用，给可能原因清单 |
| 「这个配方好不好吃」 | 不做配方与产品评价 |

## 三、完整工作流

1. **先确认打发对象**：蛋白、淡奶油、全蛋、黄油，四者的温度与操作要求完全不同，先分清再动手。
2. **查器具**：盆与打蛋头必须无水无油，蛋白里不能混入蛋黄。这是蛋白打发最常见的失败原因。
3. **查温度**：按 `rules/打发状态判定与操作要点.md` 核对该类打发的温度区间。温度不对，其他都白做。
4. **按时机加糖**：蛋白分三次加糖，分别在粗泡、细泡、出现纹路时。
5. **判状态**：按状态表判断到了哪一档，到目标状态就停，不要「再打一会儿保险」。
6. **识别打过头**：出现粗糙、无光泽、析水、豆腐渣、油水分离，立即停止并分级补救。
7. **记录**：记录温度、加糖时机、用时、最终状态，下次对比。

## 四、核心规则与要件库

生成打发建议或补救方案前，**必须先读**：

- `rules/打发状态判定与操作要点.md`：四类打发的温度、器具、加糖时机、状态描述与判定。
- `rules/失败排查与补救.md`：打不发与打过头的成因排查顺序、分级补救方法、常见操作错误。

不得建议把已经变质的材料继续使用。补救方案必须写明「可能部分挽回」，不能承诺恢复如初。

## 五、脚本用法

```
python scripts/cake_whipping_check.py --file case.json
python scripts/cake_whipping_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：打发类型、器具是否无水无油、是否混入蛋黄、温度、加糖次数、打发速度方式、目标状态与观察到状态、是否打过头或油水分离、淡奶油乳脂含量与糖比例 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--json` | 以 JSON 输出 |
| `--selftest` | 运行自检 |

脚本输出逐项判定、不合格项与原因、状态与目标的对档结果、分级补救步骤。**判定顺序是先查真实缺陷（器具带油带水、混入蛋黄、温度越界、乳脂不足、打过头、油水分离），再看信息是否完整**；只填了「已油水分离」这一个字段时，会直接判不合格并给出补救，而不是待确认。

## 六、人工确认清单

- [ ] 打发对象已分清，用的是对应的温度与操作口径
- [ ] 盆与打蛋头无水无油，蛋白里没有混入蛋黄
- [ ] 温度已核对该类打发的区间，淡奶油连同盆与打蛋头都够冷
- [ ] 蛋白分三次加糖，分别在粗泡、细泡、出现纹路时
- [ ] 到目标状态就停，没有「再打一会儿保险」
- [ ] 打蛋速度最后用低速整理，不是高速一打到底
- [ ] 出现粗糙、析水、豆腐渣时立即停止并分级补救
- [ ] 材料无酸味异味变色，变质的不使用也不补救

## 七、最常见的坑

1. **盆或打蛋头有一点油**：哪怕一点点油脂，蛋白也基本打不起来。这不是技术问题，是清洁问题。
2. **蛋白里混了蛋黄**：蛋黄含脂肪，混进去的蛋白只能改做其他用途，别指望打发。
3. **淡奶油温度不够低**：奶油本身、盆、打蛋头都要冷。温度超过 15 摄氏度，怎么打都是稀的。
4. **糖一次全加进去**：一次性加糖会拖慢打发并降低稳定性，分三次加是硬性要求。
5. **高速一打到底**：全程高速打出的气泡粗大不稳定，烤完容易塌陷，最后要转低速整理。
6. **「再打一会儿保险」**：打过头比打不够更难救，到状态就停。
7. **用乳脂含量低的奶油**：乳脂低于 30% 的淡奶油基本打不发，先看包装标示。
8. **补救期待过高**：轻微过头可以部分挽回，严重油水分离只能改做其他用途。

## 八、边界与免责

本技能提供蛋糕打发的状态判定、操作要点与补救方法，不构成对任何配方、原料或品牌的评价，也不涉及健康与医疗结论。实际结果受原料、温度、设备与操作手法影响，补救只能部分挽回，不能保证恢复如初。出现酸味、异味、变色等变质迹象时，请不要食用。
