# 打发状态判定与操作要点

## 一、蛋白打发

| 项目 | 口径 |
|---|---|
| 器具 | 盆与打蛋头必须无水无油，一点点油脂都会打不起来 |
| 分离 | 蛋白里不能混入蛋黄，蛋黄含脂肪会阻止打发 |
| 温度 | 17-22 摄氏度最易打发且稳定；冷藏蛋白更稳定但打发更慢 |
| 糖 | 分三次加：粗泡时第一次、细泡时第二次、出现纹路时第三次 |
| 稳定剂 | 可加几滴柠檬汁或白醋，或少量塔塔粉 |
| 速度 | 中速打发，最后转低速整理 30 秒至 1 分钟 |

### 蛋白状态表

| 状态 | 描述 | 适用 |
|---|---|---|
| 湿性发泡 | 提起打蛋头有大弯钩，蛋白有光泽 | 轻乳酪、部分慕斯 |
| 中性发泡 | 提起有小弯钩，纹路清晰不消失 | 戚风蛋糕常用 |
| 干性发泡 | 提起是直立尖角，倒盆不流动 | 蛋白霜、马卡龙 |

**戚风常用中性到干性之间**，打过头会让蛋糕开裂、口感粗糙。

## 二、淡奶油打发

| 项目 | 口径 |
|---|---|
| 乳脂含量 | 需 30% 以上，低于 30% 基本打不发 |
| 温度 | 奶油本身、盆、打蛋头都要冷，建议 10 摄氏度以下 |
| 糖量 | 一般为奶油重量的 8-10%，依口味调整 |
| 速度 | 中低速打发，全程盯着状态，不要离开 |
| 环境 | 夏天建议垫冰水打，或在空调房操作 |

### 淡奶油状态表

| 状态 | 描述 | 适用 |
|---|---|---|
| 六七发 | 浓稠可缓慢流动，纹路易消失 | 慕斯、冰淇淋 |
| 八发 | 纹路清晰，提起有弯钩尖峰 | 抹面、夹馅（最常用） |
| 九十发 | 硬挺，纹路很深，尖峰直立 | 裱花、造型 |

**淡奶油从八发到油水分离往往只有十几秒**，全程不能离开。

## 三、全蛋打发（海绵蛋糕）

| 项目 | 口径 |
|---|---|
| 温度 | 隔水加热到约 40 摄氏度（手摸温热不烫）再打发，更易起泡 |
| 糖 | 一次性加入或分两次，全蛋打发对加糖时机不如蛋白敏感 |
| 状态 | 提起打蛋头，蛋糊画「8」字能保持几秒不消失 |
| 速度 | 先高速起泡，转中低速整理到细腻 |

## 四、黄油打发

| 项目 | 口径 |
|---|---|
| 软化温度 | 20-22 摄氏度，手指能轻松压出凹痕 |
| 状态警示 | 软化过头成油状或化成液体，无法打发，需重新冷藏回硬再软化 |
| 糖 | 与糖打至颜色变浅、体积膨大 |
| 加蛋液 | 分次少量加，每次完全吸收再加下一次，避免水油分离 |

## 五、通用操作要点

| 要点 | 说明 |
|---|---|
| 到状态就停 | 打过头比打不够更难救 |
| 最后低速整理 | 高速打出的气泡粗大不稳定，低速整理让气泡细腻 |
| 不要离开 | 尤其淡奶油，状态变化极快 |
| 用不锈钢或玻璃盆 | 塑料盆易残留油脂且难彻底清洁 |
| 同一方向打 | 减少气泡破裂 |

## 六、状态判定的自查方法

| 方法 | 做法 |
|---|---|
| 提起看尖峰 | 直立尖角、小弯钩还是大弯钩 |
| 倒盆看流动 | 完全不流动说明已到干性 |
| 看光泽 | 有光泽为正常，粗糙无光说明开始过头 |
| 插牙签 | 牙签能立住说明已偏干 |
| 摸手感 | 用刮刀挑起感受阻力与细腻度 |
