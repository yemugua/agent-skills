# 防烟排烟系统核查（smoke-control）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《建筑防烟排烟系统技术标准》GB 51251，生成防烟排烟系统核查清单：防烟分区、机械加压送风、机械排烟、自然排烟、补风、联动控制与维护。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 防排烟系统
- 防烟排烟
- 排烟风机
- 加压送风
- 自然排烟

## 三、工作流
1. 划分防烟分区并明确控制方式
2. 核查机械加压送风（楼梯间/前室）
3. 核查机械排烟量与排烟口布置
4. 检查自然排烟条件与补风
5. 验证联动控制与定期维护

## 四、核心内容（检查清单与判定）
GB 51251 规定建筑防烟排烟系统的分区、送风/排烟量、风口布置与联动要求；系统须保证火灾时有效防烟排烟并定期维护检测。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含防烟分区与控制方式 | 分区 |
| Q2 | FAIL | 未含机械加压送风核查 | 送风 |
| Q3 | FAIL | 未含机械排烟量与风口 | 排烟 |
| Q4 | WARN | 未含自然排烟/补风条件 | 补风 |
| Q5 | WARN | 未含联动控制与维保 | 维保 |

> 脚本 `smoke-control_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python smoke-control_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python smoke-control_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
