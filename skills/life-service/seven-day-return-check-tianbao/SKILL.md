# 七日无理由退货与例外核查

七日无理由**不是无条件**：它同时受**商品类别例外**与**商品完好**两个门槛约束，而且**这通常是商家最常用的两个拒绝理由**。本技能把这两道门槛拆开逐项核查。

## 一、硬边界（能做 / 不能做）

| 能做 | 不能做 |
|---|---|
| 按例外清单逐项判定是否属于例外 | 断言例外情形「以现行规定列举为准」之外的扩张解释 |
| 给出商品完好的判断标准与留证方法 | 认定某件商品「法律上完好」（由经营者与争议处理方判断） |
| 给出起算时点的口径与实操确认方法 | 写死具体天数、金额或条款编号 |
| 说明运费承担与举证责任的一般规则 | 承诺「一定能退成」或保证退款到账 |
| 区分退货与换货 | 代替经营者受理退货申请 |

**必须转交专业人士或走争议解决：** 涉及金额较大、已过申请时限、商家拒绝且沟通无果，或需要认定商品实际价值是否因使用而显著降低的，应通过平台、监管部门或司法途径解决。

## 二、什么时候用

| 用户说法 | 用不用 | 说明 |
|---|---|---|
| 七天无理由怎么用 | 用 | 走两道门槛判定 |
| 七天从哪天开始算 | 用 | 走起算时点口径 |
| 拆封了还能退吗 | 用 | 走例外情形中的拆封类 |
| 定制的能退吗 | 用 | 走定制品例外 |
| 商品完好怎么认定 | 用 | 走完好判断标准 |
| 退货运费谁出 | 用 | 走运费承担口径 |
| 退货运费险和商家包退区别 | 用 | 走两者差异对照 |
| 换货算不算退货 | 用 | 走换货与退货差异 |
| 赠品必须一起退吗 | 用 | 走完好与完整性判定 |

## 三、完整工作流

### 步骤 1：先排除例外（第一道门槛）

先查是不是例外，是则本路径可能直接不通。用 `scripts/seven_day_judge.py` 逐项核查。

### 步骤 2：再判商品完好（第二道门槛）

不是例外也不必然能退——**完好**是独立要求，见第五节。

### 步骤 3：确认起算时点

第七天怎么算，取决于起算点。见第四节。

### 步骤 4：确认运费与举证责任

**谁主张谁举证**是核心，见第六节。

### 步骤 5：申请并留痕（留好完好证据）

**完好证据在申请时就必须已经存在**，事后无法补做。

## 四、核心规则（申请前必读）

**先读 `rules/例外情形与完好判定.md`，不要凭印象争论。**

**所有时限、运费标准与列举范围，一律以现行规定和受理机构口径为准**，本技能不写死具体天数与金额。

### 例外情形清单（以现行规定列举为准）

以下为常见的例外类型，**具体列举范围以现行规定为准**，各地与不同商品类别的执行口径可能存在差异：

| 例外类型 | 说明 | 判定要点 |
|---|---|---|
| **定制品** | 依消费者要求专门制作 | 是否为「专门制作」，非标品即适用 |
| **鲜活易腐** | 易变质、鲜活 | 商品性质决定 |
| **拆封的音像制品与计算机软件** | 拆封后影响完好 | **是否已拆封**，未拆封不适用 |
| **交付的报纸期刊** | 已交付的订阅物 | 交付性质 |
| **消费者已确认的与商品性能不符的瑕疵** | 消费者自己已确认 | 是否有消费者的确认记录 |
| **定制礼物** | 特定赠送场景 | 商家能否证明属于此类 |
| **网络下载或已拆封的数字化商品** | 数字化交付 | 交付方式 |

**关键判定原则**：例外情形的适用**由经营者举证**（见第六节），不是消费者自己证明自己属于例外。

**最容易搞错的一条**：拆封类例外针对的是**特定品类**（音像制品、计算机软件、数字化商品），**不是所有商品**。拆封了一双鞋不构成退货例外。

### 起算时点口径

| 口径 | 说明 |
|---|---|
| 通常口径 | 自消费者**收到商品**之日起计算（而非下单日、付款日、发货日） |
| 分批交付 | 分批交付的，可能按每批分别起算 |
| 预售、定制、鲜活 | 特殊交付方式的起算点可能不同 |

**实操确认方法**：不要与商家争「从哪天算」，直接要求商家在订单系统中出示**该笔订单的退货截止日期**——系统数据对双方都有约束力，比口头争论有效。

### 商品完好的判断标准

判断标准是：**商品是否因查验或使用而影响二次销售**。

| 要素 | 影响完好的情形 | 通常不影响 |
|---|---|---|
| **包装** | 包装破损、封条已破坏且无法复原 | 快递外箱轻微压痕 |
| **配件** | 配件缺失、赠品未随附 | 说明书、合格证齐全 |
| **吊牌与标识** | 吊牌已剪、序列号被破坏 | 吊牌未剪 |
| **使用痕迹** | 已使用、有明显使用痕迹、影响再次销售 | 仅查验拆封但未使用 |
| **商品本体** | 污渍、磨损、划痕 | 仅开封查看 |

**注意区分「查验」与「使用」**：为确认商品质量而进行的合理查验（如试穿、试听），与实际使用（如穿着出门）性质不同，**后者可能影响完好认定**。

### 退货 vs 换货

| 维度 | 退货 | 换货 |
|---|---|---|
| 法律性质 | 解除买卖合同 | 变更标的 |
| 货币返还 | 有 | 无 |
| 运费方向 | 通常由消费者寄回 | 视情况 |
| 适用七日无理由 | 适用 | **不当然适用**（换货通常按商品质量问题处理） |

**关键区别**：七日无理由对应的是**退货（解除合同）**，换货是另一回事。若是商品本身有质量问题，走的是质量问题处理路径，通常不要求承担运费。

### 运费承担口径

**一般规则：谁主张谁承担。**

| 情形 | 运费方向 |
|---|---|
| 你无理由退货 | 通常由你承担退货运费 |
| 商家存在商品问题 | 通常由商家承担 |
| 平台提供运费险 | 按保险条款约定处理 |
| 商家承诺包退 | 按承诺执行 |

**退货运费险 vs 商家包退的区别**：

| 对比项 | 退货运费险 | 商家包退 |
|---|---|---|
| 性质 | 保险产品，需投保 | 商家单方承诺 |
| 赔付方式 | 按保险条款理赔 | 商家直接承担 |
| 前提 | 已投保且在保障期内 | 以商家承诺为准 |
| 覆盖范围 | 看条款（部分为限额赔付） | 看承诺范围 |
| 理赔耗时 | 可能需提交理赔 | 通常与退货同步 |

**两者不冲突**：运费险是兜底，商家包退是承诺，先看商家承诺能否覆盖。

### 举证责任

| 待证明事项 | 举证方 |
|---|---|
| 商品属于例外情形 | **经营者** |
| 商品不完好 | **经营者** |
| 商品已交付并处于完好状态 | **消费者** |
| 在申请期限内提出 | **消费者** |

**这是最关键的一条**：**例外的适用由商家举证**。商家说「这是定制品」「已拆封」，要商家拿出依据。

## 五、脚本用法

脚本：`scripts/seven_day_judge.py`

```bash
python scripts/seven_day_judge.py --file 商品.json
python scripts/seven_day_judge.py --selftest
```

| 字段 | 说明 |
|---|---|
| `category` | 商品类别（如定制/鲜活/音像/普通） |
| `opened` | 是否已拆封 |
| `condition` | 完好要素（packaging/accessories/tags/used/body） |
| `days_since_receipt` | 距签收天数（仅用于相对判断，不写死阈值） |
| `merchant_proved_exception` | 商家是否已举证例外 |

输出：例外命中情况、完好判定、举证责任归属提示、运费方向提示、下一步动作建议。

## 六、人工确认清单（不能省）

- [ ] 商品类别是否属于例外的**具体列举范围**（以现行规定为准）？
- [ ] 若商家称属例外，**是否要求其举证**？
- [ ] 拆封类例外是否只针对特定品类，而非所有商品？
- [ ] 完好状态是否在申请前就已固定证据（照片/视频）？
- [ ] 使用的查验行为是否可能被主张为「使用」？
- [ ] 起算时点是否已通过订单系统的退货截止日期确认？
- [ ] 运费由谁承担是否已明确（谁主张谁承担）？
- [ ] 换货诉求是否被误当作退货处理？
- [ ] 商家承诺包退与运费险是否已核对，避免重复主张？

## 七、最常见的坑

1. **把「拆封」当成万能拒绝理由**。拆封类例外只针对特定品类（音像制品、计算机软件、数字化商品），拆封鞋子不构成例外。
2. **没有在申请时固定完好证据**。事后无法补做，商家可主张已使用。
3. **把查验行为做成使用行为**。试穿出门与试穿查看，性质不同。
4. **在系统退货截止日期已过后仍在扯皮**。应先让商家出示系统截止日期。
5. **默认例外由自己举证**。**例外与不完好均由经营者举证**，这是最有力的一条。
6. **把换货当退货走七日无理由**。两者法律性质不同，换货通常走质量问题路径。
7. **以为买了运费险就一定全赔**。运费险可能限额赔付且需按条款理赔。
8. **同时主张运费险和商家包退却不说明**。应先明确商家承诺能否覆盖。
9. **赠品不随货退回**。赠品缺失可能影响完好认定，应随主商品一并退回。
10. **只看外箱压痕就担心**。快递外箱轻微压痕通常不影响商品完好。
11. **口头交涉不留痕**。所有主张与答复都要书面留痕。

## 八、边界与免责

本技能提供例外核查、完好判断标准与运费举证的一般规则，**不写死具体天数、金额与条款编号，不承诺退成与否**。例外情形的**具体列举范围、商品完好的最终认定、运费标准均以现行规定和受理机构口径为准**，各地执行口径存在差异。商品实际价值是否因使用而显著降低等实质问题，需由经营者与争议处理方认定；争议请通过平台、监管部门或司法途径解决。
