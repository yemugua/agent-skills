# 例外情形与完好判定

> 申请前必读。**两道门槛：例外 + 完好。例外与不完好均由经营者举证。**

## 一、例外情形清单

> **具体列举范围以现行规定为准。** 各地与不同商品类别的执行口径可能存在差异，本表为常见类型，不作扩张解释。

| 例外类型 | 说明 | 判定要点 | 常见误判 |
|---|---|---|---|
| **定制品** | 依消费者要求专门制作 | 是否为「专门制作」，非标品即适用 | 普通现货也被告定制品 |
| **鲜活易腐** | 易变质、鲜活商品 | 商品性质决定 | 争议鲜活类商品是否已变质 |
| **拆封的音像制品与计算机软件** | 拆封影响完好 | **是否已拆封**，未拆封不适用 | 用来拒绝一切拆封商品 |
| **交付的报纸期刊** | 已交付的订阅物 | 交付性质 | 误用于纸质图书 |
| **消费者已确认的与商品性能不符的瑕疵** | 消费者自己已确认 | 有无消费者的确认记录 | 无确认记录也主张 |
| **定制礼物** | 特定赠送场景 | 商家能否证明属于此类 | 笼统称「属定制」 |
| **网络下载或已拆封的数字化商品** | 数字化交付 | 交付方式 | 混淆物理商品与数字商品 |

### 最容易搞错的一条

**拆封类例外针对的是特定品类**（音像制品、计算机软件、数字化商品），**不是所有商品**。

拆封一双鞋、拆开食品包装、拆开日用品包装，**不因为「拆封了」就构成退货例外**。商家用「已拆封」拒绝一切退换，是需要驳斥的。

### 举证归属

**例外情形的适用由经营者举证。** 商家主张「这是定制品」「这是易腐品」，须由其证明。

## 二、商品完好判断标准

**核心判据：商品是否因查验或使用而影响二次销售。**

| 要素 | 影响完好 | 通常不影响 |
|---|---|---|
| **包装** | 包装破损、封条破坏且无法复原 | 快递外箱轻微压痕 |
| **配件** | 配件缺失、赠品未随附 | 说明书、合格证齐全 |
| **吊牌与标识** | 吊牌已剪、序列号破坏 | 吊牌未剪 |
| **使用痕迹** | 已使用、影响再次销售 | 仅查验拆封未使用 |
| **商品本体** | 污渍、磨损、划痕 | 仅开封查看 |

### 查验 vs 使用

| 行为 | 性质 |
|---|---|
| 拆封查看、必要试穿试听（为确认质量） | **查验** |
| 穿着出门、日常使用、洗涤 | **使用** |

**这条界线在争议中很关键**：为确认商品质量而进行的合理查验，与实际使用性质不同，后者可能影响完好认定。

**实操建议**：拆封后立即拍摄涵盖包装、吊牌、商品本体的完整照片与一段连续视频，作为查验而非使用的证据。

## 三、起算时点口径

| 情形 | 口径 |
|---|---|
| 一般情形 | 自**收到商品**之日起计算（非下单日、付款日、发货日） |
| 分批交付 | 可能按每批分别起算 |
| 预售、定制、鲜活 | 起算点可能与常规不同 |

**具体天数以现行规定和受理机构口径为准**，本文件不写死。

### 实操确认方法（重要）

**不要与商家争「从哪天算」**——直接要求商家在订单系统中出示该笔订单的**退货截止日期**。系统数据对双方都有约束力，比口头争论有效得多。

## 四、退货 vs 换货

| 维度 | 退货 | 换货 |
|---|---|---|
| 法律性质 | 解除买卖合同 | 变更标的 |
| 货币返还 | 有 | 无 |
| 运费方向 | 通常消费者承担 | 视情况 |
| 适用七日无理由 | **适用** | **不当然适用** |
| 常见错误 | — | 把换货当退货主张 |

**换货通常按商品质量问题处理**，此时通常不要求消费者承担运费。

## 五、运费承担口径

**一般规则：谁主张谁承担。**

| 情形 | 运费方向 |
|---|---|
| 消费者无理由退货 | 通常消费者承担 |
| 商家存在商品问题 | 通常商家承担 |
| 平台提供运费险 | 按保险条款约定 |
| 商家承诺包退 | 按承诺执行 |

### 退货运费险 vs 商家包退

| 对比项 | 退货运费险 | 商家包退 |
|---|---|---|
| 性质 | 保险产品，需投保 | 商家单方承诺 |
| 赔付方式 | 按保险条款理赔 | 商家直接承担 |
| 前提 | 已投保且在保障期内 | 以商家承诺为准 |
| 覆盖范围 | 看条款（部分为限额赔付） | 看承诺范围 |
| 耗时 | 可能需提交理赔资料 | 通常与退货同步 |

**两者不冲突**：运费险是兜底，商家包退是承诺。**先看商家承诺能否覆盖**，避免重复主张与来回扯皮。

## 六、举证责任分配（核心）

| 待证明事项 | 举证方 |
|---|---|
| 商品属于例外情形 | **经营者** |
| 商品不完好 | **经营者** |
| 商品已交付且处于完好状态 | **消费者** |
| 在申请期限内提出 | **消费者** |

**这是最有力的一条**：例外的适用与不完好的主张都由商家举证。消费者只需证明「我收到了商品且商品完好」。

## 七、留证清单（申请前完成）

| 证据 | 用途 | 时机 |
|---|---|---|
| 订单截图（含订单号） | 证明交易关系 | 申请前 |
| 物流签收记录 | 证明签收时间（起算点） | 签收后 |
| 开箱视频（连续） | 证明商品到货时完好 | **开箱当时** |
| 商品全貌照片 | 证明包装、吊牌、配件齐全 | 开箱当时 |
| 配件与赠品照片 | 证明齐全 | 开箱当时 |
| 与商家沟通记录 | 证明协商过程与答复 | 全程 |

**开箱当时没拍，事后无法补做**。这是完好举证失败的最主要原因。

## 八、常见错误对照

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 接受「已拆封」拒绝一切退换 | 拆封例外只针对特定品类 | 举商品类别，要求其举证 |
| 事后补拍完好照片 | 无法证明到货时状态 | 开箱当时拍连续视频 |
| 把试穿出门当查验 | 属使用行为 | 查验限于确认质量 |
| 口头争论起算日 | 无约束力 | 让商家出示系统截止日期 |
| 默认例外自己举证 | 举证责任在经营者 | 明确要求商家举证 |
| 把换货当退货主张 | 法律性质不同 | 质量问题走换货路径 |
| 以为运费险全赔 | 可能限额且需理赔 | 看条款理赔并核对商家包退 |
| 赠品不随货退 | 可能影响完好认定 | 赠品一并退回 |
| 只交涉不留痕 | 无法证明协商过程 | 全部书面留痕 |
