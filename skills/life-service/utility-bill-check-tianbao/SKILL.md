# 水电费异常核查与退补

水电费争议的核心不是"感觉多了"，而是**找出差额来自哪一段**：抄表段、计量段（表具）、计费段（档位/倍率/类别）、还是管线段（漏水）。四段的责任主体、退补口径和举证责任完全不同，判错了就会投诉错对象、算错金额。

## 一、硬边界（能做 / 不能做）

| 能做 | 不能做 |
|---|---|
| 用历年账单做环比同比，标出异常月份 | 认定"表一定坏了"（需法定计量检定机构检定） |
| 按阶梯/分档规则重算应缴金额并与实收比对 | 直接给出当地现行电价水价数值（以当地公布的价目表为准） |
| 按表计相对误差折算应退补电量 | 认定漏水点在表前还是表后（需现场查勘） |
| 梳理转供电/转供水加价的合规口径与退还路径 | 断言"加价违法"（需核对当地转供政策与合同约定） |
| 输出退补申请书、投诉路径与证据清单 | 承诺退费金额、免除违约金或胜诉结果 |
| 计算违约金是否超过约定与本金的合理上限 | 代替供电/供水企业作出账务调整 |

**必须转交专业人士的情形：**
- 争议金额较大或跨年度累计的账务纠纷——建议律师介入。
- 涉及表计强制检定结论异议——申请法定计量检定机构（市场监管部门）检定/仲裁检定。
- 怀疑窃电、违规接线——不要自行拆表，应由供电企业依程序处理，涉及行政处罚的请咨询专业人士。
- 漏水造成邻里/物业损失赔偿——涉及责任划分与损失的，转交调解或诉讼。

## 二、什么时候用

| 用户说法 | 用不用 | 说明 |
|---|---|---|
| 这个月电费突然翻倍 | 用 | 走环比异常 → 分段排查 |
| 家里没人水表还在转 | 用 | 走空转/自转 → 关阀试验 → 申请校表 |
| 抄表员是不是抄错了 | 用 | 走串户/估抄/倍率核对 |
| 房东收我 1.5 元一度电 | 用 | 走转供电加价核查 |
| 漏水的水费谁出 | 用 | 走表前表后责任分界 |
| 帮我改电表 | 不用 | 计量装置不得自行拆改，需报供电企业处理 |
| 这个官司能赢吗 | 部分用 | 可给路径与证据框架，结论请咨询律师 |

## 三、完整工作流

### 步骤 1：取齐数据（不齐就别下结论）
至少取**连续 12 个月**的：账单金额、抄表读数、抄表日期、抄表方式（实抄/估抄/远抄）、用量（度数/吨数）、户号、表号、倍率。缺抄表读数的账单，先向营业厅或线上渠道申请补打明细。

### 步骤 2：做环比同比，锁定异常月份
- 与上月比、与去年同期比、与近 12 个月中位数比。
- 剔除季节性（夏季空调、冬季采暖）后再判断。
- 标出涨幅超过阈值（建议 50%）且无对应生活变化的月份。

### 步骤 3：分段归因（四段排查法）

| 段 | 检查点 | 责任方 | 典型证据 |
|---|---|---|---|
| **抄表段** | 表号与户号是否对应、是否估抄、是否串户、倍率是否录入正确 | 供电/供水企业 | 表具铭牌照片、户号对照、抄表记录 |
| **计量段** | 表具是否超差、是否空转/自转 | 需**检定机构**结论 | 检定证书、关阀观察记录 |
| **计费段** | 阶梯档位、用电类别（居民/商业/合表）、峰谷时段、附加费（污水处理费、水资源税、基金附加） | 供电/供水企业 | 价目表、账单明细、类别核定单 |
| **管线段** | 漏水点在表前还是表后、是否在保修范围 | 按分界与保修约定 | 关阀试验、漏水点照片、维修记录 |

### 步骤 4：现场核表（在申请校表前先做）
1. 拍表具铭牌（表号、出厂编号、准确度等级、倍率）。
2. 记录当前读数，隔固定时间（如 2 小时）再读一次，算实际走量。
3. **关阀试验（水）**：关闭户内所有用水器具与总阀，观察水表是否转动；转动说明存在暗漏或表具空转。
4. **断电试验（电）**：断开户内总开关，观察电表脉冲/读数是否变化；仍在变化说明表后有旁路、串户或表具故障。

### 步骤 5：申请表具校验
- 向供水/供电企业提出校验申请，**书面留痕**（线上工单号、书面回执）。
- 对检定结论有异议的，可申请**仲裁检定**（法定计量检定机构/市场监督管理部门）。
- 校验期间的费用争议：先"有争议暂按争议前方式结算"或按当地规则处理，不要据此拒缴全部费用导致违约金扩大。

### 步骤 6：核算应退应补（见第四节口径）
### 步骤 7：书面提出退补申请，固定工单号
### 步骤 8：未达成一致 → 逐级投诉（第六节）

## 四、核心规则（核算前必读）

**先读这两个文件，不要凭印象算：**
- `rules/01-异常归因与退补核算规则.md` —— 四段排查表、表计误差退补公式、漏水责任分界与分摊、估抄与追补规则、违约金上限、阶梯电价核算口径、转供加价核查。
- `rules/02-取证清单与投诉路径.md` —— 取证清单、申请书模板、投诉路径顺序、常见误判对照表。

**核算口径要点（详见规则表，此处只列骨架）：**
- 表计超差退补：按相对误差折算，**应退补电量 = 抄见电量 × r / (1 + r)**（r 为表快时的相对误差）；表慢时同理反向补收。退补期间一般自上次校验合格之日起至发现之日止，以当地供用电/供用水规则为准。
- 漏水：以**水表为界**，表前（含水表）一般属供水企业，表后属用户；但保修期内、物业维护范围内或第三方施工造成的，责任另行划分，**不是一律由用户承担**。
- 违约金：按日加收的违约金通常设有**本金比例上限**，且不得重复计收；超过合理上限部分可主张调整。
- 阶梯核算：先确认当地执行的是**按月**还是**按年**分档，再按档累加；一户多人口可申请增加第一档基数（以当地政策为准）。

## 五、脚本用法

脚本：`scripts/utility_bill_check.py`（Python 3 标准库）

```bash
python scripts/utility_bill_check.py --file 账单.json
python scripts/utility_bill_check.py --file 账单.json --json
python scripts/utility_bill_check.py --selftest
```

输入 JSON 结构：

```json
{
  "cycle": "month",
  "spike_threshold": 0.5,
  "tiers": [
    {"limit": 180, "price": 0.5469},
    {"limit": 400, "price": 0.5969},
    {"limit": null, "price": 0.8469}
  ],
  "months": [
    {"label": "2025-01", "usage": 120, "amount": 65.63},
    {"label": "2025-02", "usage": 430, "amount": 300.0}
  ]
}
```

| 字段 | 说明 |
|---|---|
| `cycle` | `month` 按月分档、`year` 按年累计分档（不填默认 month） |
| `tiers` | 阶梯表，`limit` 为该档上限（最后一档填 `null`），`price` 为该档单价 |
| `months` | 月度记录，`usage` 用量、`amount` 实收金额（可留空仅算应缴） |
| `spike_threshold` | 环比涨幅阈值，默认 0.5（即 50%） |

输出：每月应缴与实收差额、环比异常月份、阶梯档位明细、差额合计；`--file` 缺失 `amount` 时只算应缴。

另有三个可单独调用的核算函数（脚本内）：
- `meter_error_refund(抄见电量, 相对误差)` → 应退补电量
- `late_fee(本金, 天数, 日费率, 上限比例)` → 违约金（含上限截断）
- `tier_amount(用量, 档位表)` → 阶梯金额

## 六、人工确认清单（不能省）

- [ ] 已取得连续 12 个月账单与抄表读数，不是只凭一两个月判断？
- [ ] 表具铭牌上的**表号、户号、倍率**已与账单核对一致？
- [ ] 抄表方式已确认（实抄 / 估抄 / 远抄），估抄是否连续超过一个周期？
- [ ] 关阀/断电试验已做并留有照片或视频？
- [ ] 表具校验结论来自**法定计量检定机构**？
- [ ] 漏水点位置已明确在**表前还是表后**，并有照片或查勘记录？
- [ ] 阶梯是按月还是按年执行，已按当地口径确认？
- [ ] 用电/用水类别（居民、合表、商业）已核定正确？
- [ ] 违约金计算没有重复计收，且未超过本金合理比例？
- [ ] 退补申请已书面提出并保留工单号？

## 七、最常见的坑

1. **只凭一个月账单下结论**。水电有明显季节性，单月对比必然误判，必须做同比与 12 个月中位对比。
2. **把"账单金额变了"当成"表坏了"**。金额变化绝大多数来自档位、季节、类别或抄表周期，表具超差是少数情形，需检定证明。
3. **自行拆表或请非授权人员改表**。计量装置不得擅自拆改，可能引发更严重后果（含违规用电认定）。
4. **拒缴全部费用等待处理**。争议期间拒缴会累积违约金，正确做法是**先缴无争议部分、书面保留争议部分**。
5. **漏水一律自己认**。表前漏水、保修期内、物业维护范围内的漏水不应由用户承担，需先划分责任再谈金额。
6. **把"未过户"当成"欠费清零"**。过户不改变既有账务，旧账可能随户号留存，过户前必须做账务结清确认。
7. **把"已缴当期"当成"历史已结清"**。缴费只覆盖当期，需核对账户是否仍有往期挂账。
8. **把"表具校验合格"当成"计费一定正确"**。倍率录入错误、串户、档位错误与表具准确度无关，校表合格不代表账务无误。
9. **转供加价直接按"违法"投诉**。转供场景存在公摊、线路损耗与物业服务对价，需先核对当地转供政策与合同约定，再判断加价是否合理。
10. **把"未退费"写成"已退费"**。退费必须核对**到账金额**与**应退金额**是否一致，仅收到"受理通知"不等于已完成退补。

## 八、边界与免责

本技能提供的是**核查路径与核算方法**，不是账务认定或检定结论。电价、水价、阶梯基数、附加费标准以当地价格主管部门与供水供电企业公布的现行价目表为准；表计是否超差以法定计量检定机构的检定结论为准；漏水责任、转供加价与违约金争议的最终认定，由供水供电企业、市场监督管理部门、价格主管部门或人民法院作出。涉及金额较大、跨年度或拟进入诉讼的，请委托律师等专业人士。
