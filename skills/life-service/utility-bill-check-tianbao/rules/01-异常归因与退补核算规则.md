# 规则表一：水电费异常四段归因与退补核算口径

> 依据供用电、供用水与计量管理的通行规则整理。**电价、水价、阶梯基数、附加费、退补期间与违约金标准，一律以当地价格主管部门、供水供电企业现行公布的规则与合同约定为准**，本表不内置任何地区的具体价格数值。

## 第 1 节 四段归因法（先归因，再谈金额）

| 段 | 检查点 | 典型症状 | 责任/处理方 | 关键证据 |
|---|---|---|---|---|
| 抄表段 | 表号与户号对应、估抄、串户、倍率录入 | 用量突然跳变但生活无变化；账单户号与自家表号不符 | 供水供电企业 | 表具铭牌照、户号对照、抄表记录、历月读数 |
| 计量段 | 表具超差、空转/自转、停走 | 关阀后仍在走表；断电后读数仍变化 | 需法定计量检定机构检定 | 检定证书、关阀/断电试验记录 |
| 计费段 | 阶梯档位、用电类别、峰谷时段、附加费 | 金额涨幅远高于用量涨幅；类别被核定为商业 | 供水供电企业 | 价目表、账单明细、类别核定单 |
| 管线段 | 漏水点位置、保修范围、物业维护范围 | 用水量持续偏高且无新增用水 | 按分界与保修约定 | 漏水点照片、维修记录、查勘单 |

**归因顺序**：先排除抄表段和计费段（成本低、证据易得），再进入计量段（需检定），最后处理管线段（需查勘）。反过来做会浪费大量时间。

## 第 2 节 表计超差的退补核算

### 2.1 折算公式（不要用"差额 × 月份"粗算）

设抄见电量为 `W`，表计相对误差为 `r`（表快时 `r > 0`，表慢时 `r < 0`）：

```
实际用量 = W / (1 + r)
应退补量 = W - W / (1 + r) = W × r / (1 + r)
```

- `r > 0`（表快）：应退给用户（退费方向）
- `r < 0`（表慢）：应向用户补收（补收方向）

**示例**：抄见 3000 度，检定相对误差 +5%（r = 0.05）：
实际用量 = 3000 / 1.05 ≈ 2857.14 度；多计 ≈ 142.86 度。
注意不是 3000 × 5% = 150 度，两种算法差 7 度，**按折算公式算才对**。

### 2.2 退补期间的确定

- 一般以**上一次校验合格之日**起至**发现超差之日**止为退补期间；无法确定的，按当地供用电/供用水规则处理（常见为退补半年或按可查证期间）。
- 期间长短直接决定金额，**必须书面确认起止日期**，不要接受口头口径。

### 2.3 检定路径

1. 向供水/供电企业提出校验申请（留工单号）。
2. 由具备资质的计量检定机构检定，取得检定证书。
3. 对结论有异议 → 申请**仲裁检定**（向市场监督管理部门或法定计量检定机构提出）。
4. 检定期间**不宜拒缴全部费用**，建议缴无争议部分、书面保留争议部分，避免违约金扩大。

## 第 3 节 漏水责任分界与分摊

### 3.1 基本分界

| 位置 | 一般责任方 |
|---|---|
| 水表及表前管道 | 供水企业 |
| 水表后（户内及户外墙内支管，以当地与物业约定为准） | 用户 |
| 公共立管、共用下水 | 物业/产权单位（依物业管理与维修资金规则） |

### 3.2 不应一律由用户承担的情形（防误伤重点）

| 情形 | 责任方向 |
|---|---|
| 房屋仍在**开发建设单位保修期内** | 建设单位承担维修与相应损失 |
| 漏水点在**物业服务/维护范围**（公共管道、共用设施） | 物业或维修资金承担 |
| **第三方施工**（装修、开挖、邻居改造）造成 | 第三方承担 |
| 漏水点位于**表前** | 供水企业 |
| 出租房中因**房屋固有缺陷**导致 | 出租人（依租赁关系与合同约定） |

### 3.3 漏水期间水费的处理口径

- 修复前的超高水量仍需结算，但可就**责任方**主张赔偿/分摊，缴费义务与赔偿责任是两件事，不要混为一谈。
- 部分供水企业对**表后暗漏**有减免或按前三年同期平均核定的处理口径，**以当地规则为准**，需在申请中明确提出。
- 申请减免的，需提供：漏水点证明、维修凭证、修复前后读数、用水人口与同期对比数据。

## 第 4 节 估抄、追补与长期未结算

- 抄表应**实抄**；确需估抄的，一般**不得连续两个抄表周期估抄**，连续估抄属违规。
- 估抄后应补抄并按实际用量**结清**，多退少补；追补不应跨无限期累积。
- 长期估抄后一次性大额追补的，可就**追补期间过长**与**未及时抄表**提出异议，主张分期或减免违约金。
- 抄表周期不一致（如双月抄表与单月混用）会导致环比失真，比对前先**对齐周期**。

## 第 5 节 违约金上限

```
违约金 = 本金 × 日费率 × 逾期天数
封顶值 = 本金 × 上限比例
计收额 = min(违约金, 封顶值)
```

- 日费率与上限比例以**合同约定与当地现行规则为准**，不同企业、不同时期口径不同，不要套用他人经验值。
- **不得重复计收**：已计收违约金的部分不再滚入本金继续计息（利滚利），发现此类计算应书面异议。
- 违约金明显高于实际损失的，可依法请求适当调整（以现行规定为准）。
- **争议未决期间的违约金**：建议先缴无争议部分、对争议部分书面提出异议，可降低后续违约金争议风险。

## 第 6 节 阶梯计价核算口径

### 6.1 先确认分档周期

- **按月分档**：每月独立按档位计算，每月重置基数。
- **按年分档**：年度累计用量落到哪一档，该档内全部用量按该档价计算（各地口径不同，有的按累计分段，有的是年度内分段累加）。

**这一步弄错，整张账单全错。** 必须先向供水供电企业确认执行方式。

### 6.2 累加算法（分段累进）

```
第 1 档金额 = min(用量, 档1上限) × 档1价
第 2 档金额 = clamp(用量 - 档1上限, 0, 档2上限) × 档2价
第 3 档金额 = max(用量 - 档1上限 - 档2上限, 0) × 档3价
应缴 = 各档金额之和 + 附加费
```

### 6.3 常见核算差错点

- 一户多人口未申请**增加第一档基数**（多数地区对 5 人及以上家庭有增加基数的政策，以当地为准）。
- 用电类别被核定为**商业/非居民**，实际应为居民生活用电。
- 合表用户（多户共用一表）未执行合表电价。
- 峰谷分时**未申请却按峰价计收**，或申请后未实际切换。
- 附加费（污水处理费、水资源税、可再生能源附加、基金）**重复计收**或计收基数错误。

## 第 7 节 转供电 / 转供水加价核查

场景：租房、写字楼、园区、市场档口由房东或物业转供。

| 检查点 | 口径 |
|---|---|
| 终端电价是否超过当地**目录电价**（居民/一般工商业） | 超出部分需有明确依据（公摊、线损、服务对价） |
| 公摊与线损是否**公示**并按实际发生计算 | 未公示的固定比例加价可要求说明 |
| 租赁合同是否约定了单价 | 有约定从约定，但显失公平的可请求调整 |
| 是否提供了**分表读数与分摊明细** | 无明细的按户平均分摊可提出异议 |
| 加价部分是否开具了凭证 | 无凭证的收款难以主张合法性 |

**处理顺序**：先要明细（分表读数、分摊公式、加价构成）→ 比对目录价 → 书面协商退还差价 → 12345 / 价格主管部门 → 消协 → 诉讼。

**注意**：不要把"转供加价"一律判定为违法。公摊、损耗、服务对价在一定范围内属合理，需结合当地转供政策与合同约定判断。

## 第 8 节 过户与账务结清

- 过户**不产生欠费豁免**，既有账务随户号留存。
- 过户前必须取得**账务结清证明**（书面或在营业厅确认并留痕），否则前业主欠费可能影响到新户主。
- 二手房/租房交接时，应现场共同抄表并签字确认**交接读数**，这是后续争议的关键分界点。
