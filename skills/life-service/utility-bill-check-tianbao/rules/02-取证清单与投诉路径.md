# 规则表二：取证清单、申请书模板、投诉路径与误判对照

## 第 1 节 取证清单（按顺序固化）

| # | 证据 | 固化要点 |
|---|---|---|
| 1 | 连续 12 个月账单 | 含金额、用量、抄表日期、抄表方式；缺明细的先申请补打 |
| 2 | 表具铭牌照 | 拍清表号、出厂编号、准确度等级、倍率、制造厂 |
| 3 | 户号与表号对照 | 营业厅或线上渠道查询的户号信息截图 |
| 4 | 读数序列 | 同一角度、同一时间规律拍摄的读数照片，形成时间序列 |
| 5 | 关阀/断电试验 | **视频**记录：关闭总阀（或断开总开关）→ 拍表 → 等待 30 分钟以上 → 再拍表 |
| 6 | 漏水现场 | 漏水点近景远景视频、渗水位置、维修前后对比、维修凭证与费用票据 |
| 7 | 校验申请与结论 | 线上工单号截图、书面回执、检定证书 |
| 8 | 缴费凭证 | 缴费记录、发票，证明已缴部分与争议部分 |
| 9 | 沟通记录 | 客服工单号、通话录音（依法取得）、营业厅办理回执 |
| 10 | 用水/用电人口与设备清单 | 用于佐证用量的合理性（人数、是否新增大功率设备） |

## 第 3 节 投诉路径顺序（不要跳步）

| 顺序 | 路径 | 适用 | 说明 |
|---|---|---|---|
| 1 | 供水/供电企业营业厅与客服 | 全部类型 | 先取得书面核查答复，这是后续所有投诉的基础材料 |
| 2 | 企业上级投诉/服务监督热线 | 对答复不满 | 要上一级工单号 |
| 3 | **12345** 政务服务便民热线 | 供水服务、物业转供 | 会转办至主管部门并回访问效 |
| 4 | **12398** 能源监管热线 | 供电服务、电价执行 | 电力领域的专门监管渠道 |
| 5 | 市场监督管理部门（12315） | 计量器具、消费纠纷 | 表具检定争议、仲裁检定 |
| 6 | 价格主管部门 | 价格与加价行为 | 转供加价、超标准收费 |
| 7 | 消费者协会调解 | 消费纠纷 | 需双方同意调解 |
| 8 | 人民法院诉讼 | 金额较大、久拖不决 | 小额诉讼程序效率较高 |

**跳步的代价**：没有企业书面答复，主管部门往往要求先向企业申请核查，会拉长周期；同时缺少"企业知情且拒绝整改"的证据，对后续主张不利。

## 第 4 节 现场核查动作清单（按顺序做）

1. 拍铭牌照（表号、倍率、准确度等级）。
2. 记录读数 T0，等待固定时间（≥30 分钟），记录读数 T1。
3. **关阀试验（水）**：关闭户内总阀与所有器具 → 观察水表是否转动 → 转动则为暗漏或空转。
4. **断电试验（电）**：断开户内总开关 → 观察电表读数/脉冲 → 仍变化则为旁路、串户或表具故障。
5. 核对户号：拨打客服或在营业厅查询户号对应的表号。
6. 抄表方式确认：查询历次抄表是实抄/估抄/远抄，连续估抄要提出异议。
7. 比对类别：确认居民/合表/商业类别与实际情况一致。
8. 提出申请：书面提交，取得工单号。

## 第 5 节 常见误判对照表（否定词防误伤）

| 文本/情形 | 不要判成 | 正确判法 |
|---|---|---|
| 账单金额上涨 | 表具超差 | 先查抄表段与计费段，表超差需检定证明 |
| 表具校验合格 | 计费一定正确 | 倍率、串户、档位错误与表具准确度无关 |
| 已缴当期费用 | 历史账务已结清 | 需核对账户是否有往期挂账 |
| 房屋已过户 | 欠费已清零 | 过户不豁免既有账务 |
| 已收到受理通知 | 退补已完成 | 需核对**到账金额**与应退金额是否一致 |
| 漏水未修复 | 责任已划分 | 需先确定漏水点位置与保修/维护范围 |
| 关阀后水表仍转 | 一定是暗漏 | 也可能是表具空转，需检定区分 |
| 转供加价 | 一律违法 | 需核对当地转供政策与合同约定，公摊线损可能属合理 |
| 未缴争议费用 | 无任何风险 | 会累积违约金，应缴无争议部分并对争议部分书面异议 |
| 连续估抄 | 正常抄表 | 连续估抄属违规，可提出异议 |
| 用水量偏高 | 一定是表后漏水 | 也可能是表前漏水、串户、或实际用水变化 |

## 第 6 节 争议期间的自我保护动作

1. **不要自行拆改计量装置**，可能引发更严重后果。
2. **缴无争议部分**，对争议部分书面提出异议并保留凭证。
3. **所有沟通留痕**：工单号、回执、录音、截图。
4. **不要签署"自愿放弃追索"类文件**，签署前请仔细阅读，必要时咨询专业人士。
5. **关注时效**：账务与费用争议的诉讼时效一般为三年，自知道或应当知道权利受损之日起算（以现行规定为准），久拖不决应及时主张权利。
