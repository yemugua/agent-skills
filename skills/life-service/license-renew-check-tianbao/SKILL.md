# 驾驶证换证办理核查

驾驶证换证真正要命的不是"材料没带齐"，是**过期了还在开车**和**过期太久要重考**。本技能按日期帮你算出卡在哪一档。

## 什么时候用

- 驾驶证快到期了，想知道能提前多久办、能换几年
- 驾驶证**已经过期**了，想知道还能不能正常换、要不要重考科目一
- 长期在外地，想知道能不能不回核发地办
- A/B 类（大车）或满 70 周岁，想知道有没有额外义务
- 驾驶证丢了/信息变了，不确定该办"补证"还是"换证"
- 有人跟你说"过期一天就得重考"，想核实是不是真的

## 怎么做

**第 1 步**：复制 `templates/驾驶证换证信息采集表.md` 填写。

**第 2 步**：跑脚本

```bash
python scripts/license_check.py 采集表.md --base 2026-10-05 --out 核查报告.md
```

**第 3 步**：按第八段"待办补正动作"执行。

## 有效期三档（核心）

| 当前情况 | 换发后有效期 |
|---|---|
| 初次取得 | **6 年** |
| 6 年有效期内，**每个**记分周期均未记满 12 分 | **10 年** |
| 10 年有效期内，**每个**记分周期均未记满 12 分 | **长期有效** |

→ 只要在某一个记分周期被记满 12 分，本次换证就**升不了档**，只能换回同档（6 年）。

## 逾期三档（最核心）

| 逾期时长 | 后果 | 怎么办 |
|---|---|---|
| 未满 1 年 | 可正常换证 | 尽快换，**期间不得驾车** |
| 1 年以上不满 3 年 | 注销但未完全失效 | 重考**科目一**合格后恢复 |
| 3 年以上 | 注销 | **重新报考全部科目** |

→ 起算点是**有效期截止日**，不是你发现的那天。**逾期期间一律不得驾驶机动车。**

## 两个高频误解

1. **"提前 90 日"是最早能办的日子**，不是必须办的日子。提前办不会缩短新证有效期起点（按各地口径，多数自原证有效期满次日起算，以 12123 显示为准）。
2. **异地可以办**。期满换证已全国通办，可在居住地/暂住地直接申请，不用回核发地；想顺便把证转到现居住地的，办"转入换证"。

## 输入 / 输出

| | 内容 |
|---|---|
| 输入 | 采集表 Markdown（驾驶人 / 证件与有效期 / 记分 / 办理地 / 身体条件 / 材料 / 特殊情形） |
| 输出 | 九段报告：结论摘要 / 有效期档位 / 逾期判定 / 下次能换几年 / 材料清单 / 办理路径 / 特殊分支 / 待办 / 纪律 |
| 退出码 | 0 正常；2 关键信息缺失（给提示串，不崩） |

## 边界与纪律

- 依《机动车驾驶证申领和使用规定》等**通用规则**整理，**以当地公安交管部门与交管 12123 显示为准**
- **不代办、不承诺**具体办结时限与能否免体检/免照片（各地自助体检机、联网照片采集差异大）
- 记分、违法状态以 12123 实时数据为准，本技能只用你填的
- **未填的一律不算通过**，只按填了的判断
- 军警驾驶证、境外驾驶证换领、校车驾驶资格等另有规定，需另行查证
