# 规则三：特殊分支——70 周岁、A/B 类、补证与降级、不予换证

## 一、年满 70 周岁

| 义务 | 内容 |
|---|---|
| **每年提交身体条件证明** | 年龄在 **70 周岁以上**的机动车驾驶人，应当**每年进行一次身体检查**，在记分周期结束后**提交**医疗机构出具的身体条件证明 |
| **准驾车型受限** | 年满 70 周岁后，不得驾驶普通三轮摩托车、普通二轮摩托车等；原持有 **D、E** 准驾车型的，应当**降级为 F**（轻便摩托车） |
| **未提交的后果** | 未按规定提交身体条件证明的，驾驶证可能被注销或停止使用，需按规定恢复 |

**要点**

- 这个义务是**每年一次**，不是"换证时才有"。跟 6 年/10 年换证是两件事，不要混为一谈。
- 提交时间：一般在**记分周期结束后**的一定期限内提交，具体期限以当地与 12123 提示为准。
- 办理降级换证时，可同时办理"自愿降低准驾车型"换证。

## 二、A/B 类（大型客车、牵引车、城市公交车、中型客车、大型货车）

准驾车型代号：**A1**（大型客车）、**A2**（牵引车）、**A3**（城市公交车）、**B1**（中型客车）、**B2**（大型货车）。

| 情形 | 规则 |
|---|---|
| **有记分的要审验** | 一个记分周期内有记分的，应当在**记分周期结束后 30 日内**接受**审验** |
| **无记分可免审** | 一个记分周期内**没有记分**的，**免予**本记分周期的审验 |
| **连续三个周期不审验** | **连续三个记分周期**不参加审验的，注销其**最高准驾车型**驾驶资格，并通知在规定期限内办理降级换证 |
| **记满 12 分** | 记满 12 分的，注销其最高准驾车型驾驶资格，并按规定办理**降级换证** |
| **审验内容** | 包括道路交通安全违法行为、交通事故处理情况，以及身体条件情况；审验时按规定参加学习与警示教育（不少于规定时长） |

**要点**

- 审验 ≠ 换证。审验是**每年/每周期**的义务，换证是**有效期满**才办。两件事都要盯。
- "记分周期结束后 30 日内"是硬期限，超期不审会被累积计入"连续三个周期"。
- A/B 类驾驶人发生交通事故造成人员死亡、承担同等以上责任未被吊销驾驶证的，也要在记分周期结束后 30 日内接受审验。

## 三、别办错了：换证 vs 补证 vs 变更 vs 降级

| 你的情况 | 该办什么 |
|---|---|
| 有效期满（或即将满） | **期满换证** |
| 驾驶证**丢失**或**损毁** | **补证**（补领机动车驾驶证），不是换证 |
| 姓名、身份证号、住址等**信息变更** | **变更换证**（信息变更换证） |
| 自愿降低准驾车型 | **降级换证** |
| 长期在异地居住，想把证迁过来 | **转入换证**（可并入期满换证一起办） |
| 身体条件发生变化不适合原准驾车型 | 按规定的**降低准驾车型换证**或注销 |

## 四、不予换证的情形（办之前先排除）

有下列情形之一的，不予换发机动车驾驶证：

1. 有**未处理完毕**的道路交通安全违法行为（违法未处理）；
2. 有**未处理完毕**的道路交通事故（事故未结案）；
3. 机动车驾驶证被**扣押、扣留、暂扣**期间；
4. 驾驶证被**吊销、撤销**期间；
5. 身体条件不符合驾驶许可条件的（如体检不合格、存在影响安全驾驶的疾病）；
6. 其他依法不应换发的情形（如被依法采取强制措施、涉及案件限制等）。

**怎么办**：先到 12123 查清违法与事故状态，把罚款缴清、事故处理完结，再申请换证。

## 五、其他常见分支

| 情形 | 处理 |
|---|---|
| **驾驶证被扣 12 分未处理** | 先按规定参加学习并考试合格后清除记分，再办换证 |
| **实习期** | 实习期内的驾驶证换证按一般规定办理；实习期的特殊限制（如不得独自上高速）另行遵守 |
| **军警驾驶证换领地方证** | 另有专门规定与材料要求，需另行查证 |
| **境外驾驶证换领** | 需提交境外驾驶证及翻译文本、按规定参加相应科目考试，需另行查证 |
| **校车驾驶资格** | 另有资格审查与年度审验要求，需另行查证 |
| **驾驶证被冒用/信息被盗用** | 立即向车管所与 12123 反映，按指引处理 |

## 六、给 A/B 类与 70 周岁以上驾驶人的一句话建议

- **A/B 类**：把"记分周期结束后 30 日内审验"设成日历提醒；连续三个周期漏审 = 最高准驾车型被注销，这是最贵的失误。
- **70 周岁以上**：把"每年提交身体条件证明"设成日历提醒；同时确认准驾车型是否需要降级（D、E → F）。
