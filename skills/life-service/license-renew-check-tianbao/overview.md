# 概览：驾驶证换证办理核查

## 解决什么问题

驾驶证换证这件事，绝大多数人只在两个字上翻车：**过期**。

- 以为"过期几天没事"，结果**过期期间开车被按无证驾驶性质处理**，出了事故还要加重责任
- 以为"过期就得全部重考"，其实**1 年到 3 年之间只需要重考科目一**
- 以为"必须回发证地办"，其实**早已全国通办**，居住地在异地就能直接申请
- 以为"6 年满了自然换 10 年"，结果中间有个记分周期被记满 12 分，**升不了档**

本技能把"日期 + 记分 + 办理地 + 特殊身份"四个变量算成一句话结论：你现在在哪一档、下次能换几年、要跑哪一步。

## 输入 → 输出

```
采集表（证件与有效期 / 记分 / 办理地 / 身体条件 / 材料 / 特殊情形）
        │
        ▼
  ┌────────────────────┐
  │ 有效期档位判定      │  6 年 / 10 年 / 长期，按历史记分推算
  ├────────────────────┤
  │ 逾期三档判定        │  正常 / 1 年内 / 1-3 年 / 3 年以上
  ├────────────────────┤
  │ 下次能换几年        │  给出推算依据与"卡在哪"
  ├────────────────────┤
  │ 材料清单           │  逐项标已备 / 缺失
  ├────────────────────┤
  │ 办理路径           │  12123 线上 / 车管所 / 异地通办
  ├────────────────────┤
  │ 特殊分支           │  70 周岁 / A·B 类 / 补证 / 不予换证
  └────────────────────┘
```

## 三条硬规则（本技能最值钱的部分）

**① 逾期不是一刀切**
不满 1 年可正常换；1 年以上不满 3 年，重考**科目一**即可恢复；**满 3 年**才要重新报考全部科目。日期差一天，工作量差一个量级。

**② 升档看的是"每个记分周期"**
6 年换 10 年、10 年换长期，条件都是"**每个**记分周期均未记满 12 分"。一个周期满 12 分，本次就升不上去。

**③ 逾期期间一律不得驾车**
这不是"小心点开"的问题。逾期驾车属无证驾驶性质，处罚之外，一旦发生交通事故，责任认定与理赔都会往不利方向走。

## 和其他工具的区别

| 现有工具 | 本技能 |
|---|---|
| 交管业务办事指南 | 只讲流程，不按**你的日期**算档位 |
| 驾驶证有效期计算器 | 只算到期日，不算**逾期档位与重考科目** |
| 12123 APP 本身 | 能办，但不告诉你**为什么卡住、下一步补什么** |

## 不做的事

- 不代办、不承诺办结时限
- 不替代公安交管部门认定，最终以 12123 与车管所窗口口径为准
- 未填的一律标"未填"，不算通过
- 军警、境外驾驶证换领、校车资格等另有规定，需另行查证

## 适用人群

驾驶证临期或已过期的驾驶人、长期异地居住的驾驶人、A/B 类大车司机与运输企业安全管理人员、年满 70 周岁驾驶人及其家属。
