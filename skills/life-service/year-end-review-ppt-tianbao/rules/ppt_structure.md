# 述职 PPT 结构与页序规则库

> 排页前先读本文件。**结论必须在第 1 页。**

---

## 一、五段页序结构

| 段 | 位置 | 页数占比 | 每页必须回答 | 一句话模板 |
|---|---|---|---|---|
| 结论 | 第 1 页 | 1 页 | 干成了什么、达成多少 | 「本期 X 项核心指标加权达成 XX%，A、B 超额，C 未达」 |
| 数据 | 中段前部 | 40% | 各指标目标/实际/达成率/同比/环比 | 「销售额 1200 万，同比 +26%，目标达成 104%」 |
| 亮点 | 中段中部 | 20% | 哪 2-3 件事最值得说 | 「把 X 环节从 A 天压到 B 天，关键动作是……」 |
| 问题 | 中段后部 | 20% | 1-2 个真问题 + 根因 + 已做动作 | 「C 未达，根因是 X，已启动 Y，预计 Z 见效」 |
| 计划 | 最后一页 | 1 页起 | 下期目标值 + 关键动作 + 需要的资源 | 「下期目标 X，三项动作，需要 XX 支持」 |

## 二、页数与时长配比

| 汇报形式 | 页数 | 时长 | 每页平均 |
|---|---|---|---|
| 短述职 | 8-12 页 | 5-10 分钟 | 30-50 秒 |
| 标准述职 | 12-18 页 | 10-15 分钟 | 40-60 秒 |
| 答辩 | 18-25 页 | 20 分钟 | 50 秒 |

**一页讲了超过 90 秒还讲不完，就是内容太多。** 拆成两页或删掉。

## 三、每页一句话结论的四种写法

### 写法一：数字型

```
「[指标] 从 [基线] 到 [结果]，同比 [±X%]，目标达成 [XX%]」
```

### 写法二：对比型

```
「[原做法] 单均 [X]，改为 [新做法] 后降到 [Y]」
```

### 写法三：动作—结果型

```
「把 [环节] 前移到 [时点]，返工率从 [X%] 降到 [Y%]」
```

### 写法四：结论—动作型（问题页用）

```
「[问题] 未达成，根因是 [可控原因]，已启动 [动作]，预计 [时间] 见效」
```

**每页标题就是这句话，不要另写标题。**

## 四、四个量化口径与公式

```
同比     =（本期值 - 上年同期值）÷ 上年同期值 × 100%
环比     =（本期值 - 上一周期值）÷ 上一周期值 × 100%

目标达成率（越大越好类）= 本期值 ÷ 目标值 × 100%
目标达成率（越小越好类）= 目标值 ÷ 本期值 × 100%

人均效能 = 本期产出 ÷ 本期平均在岗人数
本期平均在岗人数 =（期初在岗人数 + 期末在岗人数）÷ 2

加权达成率 = Σ(单项达成率 × 权重) ÷ Σ权重
量化覆盖率 = 有数值且基线完整的指标数 ÷ 指标总数
```

### 同比与达成率的四象限

| 同比 | 达成率 | 真实情况 | 述职怎么写 |
|---|---|---|---|
| ↑ | ≥100% | 真增长真达成 | 重点写，给关键动作 |
| ↑ | <100% | 增长但没够到目标 | 说明目标定得高，或增长集中在后半段 |
| ↓ | ≥100% | **目标定低了** | **必须主动说明** |
| ↓ | <100% | 下滑 | 写根因与止损动作 |

> 「同比下降但达成率 104%」是最容易被抓的一栏。**自己先说出来，比被问出来好。**

### 越小越好类指标别算反

```
故障次数 25 → 18，目标 20
✗ 错误：18 ÷ 20 = 90%（或写成 72%）
✓ 正确：目标 ÷ 实际 = 20 ÷ 18 = 111%
```

适用：故障次数、成本、耗时、缺陷数、离职人数。

### 人均效能分母口径

- 期初期末各记一次在岗人数，取平均
- 中途入职按实际在岗月数折算
- **口径必须写明**，不写明这个数没有意义

## 五、指标选取规则

| 项 | 建议 | 说明 |
|---|---|---|
| 指标数 | 5-8 项 | 评委记忆容量有限，宁深不宽 |
| 权重 | 合计为 1 | 不为 1 说明权重口径没定 |
| 基线 | 每项都要有上年同期值 | 无基线则无法算同比 |
| 来源 | 系统 / 台账 / 抽样 | 抽样须注明样本量与区间 |
| 方向 | 标明越大越好还是越小越好 | 决定达成率公式 |

### 定性变定量对照

| 定性说法 | 换成什么数 | 数据来源 |
|---|---|---|
| 大幅提升效率 | 处理时长从 X 降到 Y，降幅 Z% | 系统日志 / 工单 |
| 积极参与协作 | 跨部门协同 N 次，推动 M 项落地 | 会议纪要 / 项目清单 |
| 优化了流程 | 环节从 N 步减到 M 步，单均省 T 分钟 | 流程图 + 计时 |
| 保障了稳定性 | 可用率 X%，故障 N 次，同比 -Y% | 监控平台 |
| 获得好评 | 满意度 X 分，投诉 N 件同比 -M | 问卷 / 工单 |

## 六、五类忌讳与改写

### 忌讳一：堆工作量

```
✗ 本年度参与各类项目 15 项，承担 XX 工作 300 余天，完成会议纪要 120 份。
✓ 项目 A：负责 XX 模块，交付 XX，联调一次通过，节省人工 Y 人日
   项目 B：主导 XX 改造，耗时从 X 天降到 Y 天
   项目 C：协同 3 个部门，落地 Z 项流程
```

### 忌讳二：只讲过程不讲结果

```
✗ 「积极参与项目建设」「认真负责」「加班加点完成任务」
✓ 「把 X 环节从 A 压到 B，单次节省 C 小时」
```

### 忌讳三：每页没有结论句

```
✗ 标题写「项目进展」，正文列 8 条内容
✓ 标题写「项目 A 按期交付，返工率下降 12%」
```

### 忌讳四：数据无来源

```
✗ 「满意度提升 12%」（说不清怎么统计的）
✓ 「按季度问卷，样本 428 份，2026 年 11 月采集」
```

### 忌讳五：问题页甩锅

```
✗ 「因产品需求频繁变更，导致上线延期」
✓ 「需求变更 3 次，我在第 2 次后引入评审机制，后续变更影响下降 XX%」
```

## 七、逐页质检表

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 标题是否就是结论句 | 是，不另写标题 |
| 2 | 结论句里是否有一个数 | 是 |
| 3 | 数据是否有来源 | 系统 / 台账 / 抽样注明样本量 |
| 4 | 是否区分个人贡献与团队成果 | 写清人数、分工与自己承担的那段 |
| 5 | 同比与环比是否与结论方向一致 | 不一致时主动解释 |
| 6 | 越小越好类达成率是否算反 | 故障/成本/耗时用「目标÷实际」 |
| 7 | 图表数字与正文数字是否一致 | 一致 |
| 8 | 是否存在无结果的表述 | 删除「积极参与」「认真负责」 |
| 9 | 问题页是否甩锅 | 结论句主语是自己的动作 |
| 10 | 本页讲述是否 ≤90 秒 | 超时拆页 |
