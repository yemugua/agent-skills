# 墙面开裂

## 1. 硬边界表

| 能做 | 不能做 |
|---|---|
| 按形态/位置判断裂缝成因 | 替代结构工程师鉴定 |
| 给严重程度分级 | 做结构安全法定结论 |
| 给对应修补工艺清单 | 处理施工/质量纠纷 |
| 标出须转交专业的红线 | 指导承重构件拆改 |

本技能只做检查与判断清单，不做法律定性。结构性裂缝须由持证结构工程师确认。

## 2. 什么时候用

| 用户说法 | 用本技能 |
|---|---|
| 「墙面裂缝要不要紧」 | 用 |
| 「裂缝怎么补」 | 用 |
| 「承重墙有裂缝」 | 用（给红线，转专业） |
| 「这算质量问题吗」 | 不用，转专业 |

## 3. 完整工作流

1. 观察裂缝位置（顶层/山墙/梁下/承重墙/非承重）。
2. 量宽度、长度，看是否贯通、是否随结构延伸。
3. 按 `rules/wall-crack-rules.md` 判断成因与分级。
4. 非结构裂缝按工艺修补。
5. 红线项标注「须转交结构工程师」。
6. 对照人工确认清单核对。

## 4. 核心规则

先读 `rules/wall-crack-rules.md`：裂缝分类（发丝/温度/沉降/结构）、成因对照、严重程度分级、修补工艺、红线项。

## 5. 脚本用法

```
python scripts/check.py --file 裂缝记录.json
python scripts/check.py --selftest
```

`--file` 含 location、width_mm、through（是否贯通）、extends_structure（是否随结构延伸）、growing（是否在发展）等字段。

## 6. 人工确认清单

- [ ] 裂缝位置是否在承重墙/梁柱
- [ ] 宽度是否 >0.3mm
- [ ] 是否贯通、是否随结构延伸
- [ ] 是否在持续变长变宽（发展）
- [ ] 是否为温度/收缩类非结构性裂缝
- [ ] 是否有「须转交结构工程师」红线项

## 7. 最常见的坑

1. 把结构性斜裂缝当温度裂缝，延误处理。
2. 只补表面不查成因，补完又裂。
3. 沉降裂缝未等沉降稳定就补，反复开裂。
4. 忽略裂缝持续发展（变长变宽），错过预警。
5. 承重墙裂缝自行处理，掩盖隐患。
6. 用普通腻子补结构性缝，无效。
7. 顶层/山墙温度缝未做伸缩处理，反复出现。

## 8. 边界与免责

本技能为自查判断清单，不替代结构工程师。结构性、贯通、随结构延伸或持续发展的裂缝，须由持证人员确认。本技能不做法律定性。
