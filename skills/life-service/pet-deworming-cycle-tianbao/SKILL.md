# 宠物驱虫周期与给药间隔核查（pet-deworming-cycle）

驱虫这件事，**最常见的两个错误方向正好相反**：一个是"看不到虫就不用驱"，一个是"每月固定吃一片图省事"。前者会让体外寄生虫反复引入，后者会让给药间隔失真——**体内外药的作用对象不同，间隔口径也不同，混着算就会算错**。

这个技能做三件事：**分体内外 → 排间隔 → 核记录**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出体内外寄生虫的作用对象差异 | ❌ 提供具体驱虫药名称、品牌与成分 |
| 给出周期核查口径与记录方法 | ❌ 提供剂量、给药量与按体重换算 |
| 给出与疫苗间隔的执行口径 | ❌ 判断具体某只宠物的给药方案 |
| 给出异常反应与延误风险的红线 | ❌ 判断体内寄生虫种类与感染程度 |
| 给出环境卫生与防再引入口径 | ❌ 判断驱虫药是否对该个体安全 |

**本技能的核心限制：体内驱虫药与体外驱虫药的品种、剂量、给药间隔与安全间隔期，全部由执业兽医确定。** 本技能只提供**核查口径、作用对象差异、间隔计算方式与记录方法**。

**就医红线（出现任一条，尽快联系兽医）**

- **服药后出现抽搐、意识障碍、呼吸困难、面部肿胀** —— 提示急性过敏反应，需立即急诊
- **服药后持续呕吐、腹泻超过 24 小时，伴精神沉郁** —— 需就诊评估
- **粪便中持续可见大量虫体或虫卵** —— 提示感染负荷高，需做粪检确定种类
- **肛周有异动但粪便中找不到虫** —— 需排查绦虫、滴虫等，需要粪检
- **皮肤出现大面积脱毛、红斑、结痂并伴脱毛** —— 需排查真菌与螨虫，不限于驱虫能解决
- **耳道内有黑褐色分泌物、剧烈甩头** —— 需排查耳螨与耳炎，驱虫药未必覆盖
- **幼宠在驱虫后出现持续不吃不喝、血糖偏低表现（幼犬幼猫尤需注意）**
- **怀疑误服过量或多宠共用剂量导致过量**
- **母宠处于妊娠期或哺乳期**
- **有肝肾基础疾病或正在服用其他药物**

**绝对禁止**：

- **不给人用药给宠物驱虫**。部分人用驱虫药对猫有严重毒性，猫禁用。
- **不自行加大剂量或缩短间隔**。
- **不把体外驱虫药按体内驱虫用，或反之**。
- **不在多种驱虫药之间自行叠加**。
- **不用"驱虫药当保健品每月一片"的思路**。给药方案应由兽医确定。

## 二、完整工作流

```
第 1 步  分清体内外：先判断需要处理的是哪一类（或两类都有）
第 2 步  查暴露因素：外出、季节、接触其他动物、居家环境
第 3 步  排周期：按体内、体外分别排，间隔不混算
第 4 步  排与疫苗的间隔：确认两者不同日、同日是否会互相影响
第 5 步  核记录：拿出上一次驱虫与疫苗日期，逐项对齐
第 6 步  确认方案：品种、剂量、间隔由兽医确定并写进记录
第 7 步  执行与观察：给药后观察精神、食欲、粪便
第 8 步  环境处理：防止再引入，体外驱虫不做环境等于白做
```

**顺序不能颠倒**：不先分体内外就排周期，是间隔算错的头号原因。

## 三、体内外作用对象对照

**这是本技能最核心的一张表——分不清体内外，周期就没法排。**

### 3.1 体内寄生虫与作用对象

| 类别 | 常见代表 | 表现线索 | 说明 |
|---|---|---|---|
| 蛔虫 | 蛔虫 | 幼宠多见；粪便中可见；可能有腹痛、消瘦 | 属常见地面传播寄生虫 |
| 绦虫 | 绦虫 | 粪便中可见白色或米粒状节片；肛周瘙痒 | 常与跳蚤中间宿主相关 |
| 钩虫 | 钩虫 | 便血、贫血、消瘦 | 可经皮肤侵入 |
| 鞭虫 | 鞭虫 | 大量黏液便、腹泻、消瘦 | 幼犬猫多见 |
| 蛲虫（犬） | 蛲虫 | 肛周异动、夜间瘙痒 | 主要在犬 |
| 球虫类 | 等孢子虫等 | 幼宠腹泻、便中带血 | 幼年发病较多 |
| 弓形虫 | 弓形虫 | 多数无症状；免疫低下时发病 | **属人畜共患病，管理上要重视卫生** |

### 3.2 体外寄生虫与作用对象

| 类别 | 常见代表 | 表现线索 | 说明 |
|---|---|---|---|
| 跳蚤 | 跳蚤 | 剧烈瘙痒；黑色颗粒状粪便（血便）；腰臀部与尾根多见 | **会叮咬人**；家中有跳蚤是常见反复来源 |
| 蜱虫 | 蜱虫 | 发现肉眼可见的虫体附着；叮咬处红肿、结痂 | **可传播疾病**；草地与户外是高暴露环境 |
| 耳螨 | 耳螨 | 剧烈甩头、耳道内黑褐色分泌物、结痂 | **位置在耳道内，普通体外滴剂未必覆盖耳道** |
| 疥螨 | 疥螨 | 剧烈瘙痒、脱毛、结痂，多从边缘开始 | 传染性强，**人也可被感染** |
| 蠕形螨 | 蠕形螨 | 脱毛、红斑、皮肤增厚 | 需皮肤镜检确认 |
| 虱子 | 虱子 | 可见蠕动的虫体、结痂 | 多见于环境差或免疫低下个体 |
| 恙螨 | 恙螨 | 趾间、腹部等部位红斑、剧烈瘙痒 | 潮湿季节高发 |

### 3.3 两类驱虫的区别要点

| 对比项 | 体内驱虫 | 体外驱虫 |
|---|---|---|
| 作用对象 | 肠道与体内器官的寄生虫 | 体表与皮毛上的寄生虫 |
| 常见表现 | 粪便异常、消瘦、腹泻、血便 | 瘙痒、脱毛、结痂、可见虫体 |
| 粪检意义 | 需要粪检才能确定 | 一般靠外观与皮肤检查 |
| 环境处理 | 主要是粪便清理与消毒 | **必须同步处理环境，否则复发** |
| 人是否受影响 | 弓形虫等属人畜共患病 | **跳蚤、蜱虫、疥螨可影响人** |

**体外驱虫不做环境，等于白做**：宠物身上的跳蚤和蜱虫大部分卵、幼虫、蛹在环境里，只给宠物驱虫而环境不处理，很快会再次感染。

## 四、周期核查口径

**具体周期由兽医根据宠物的暴露风险确定。以下是核查时的分类维度，不给固定天数。**

| 维度 | 情况 | 对周期的影响 |
|---|---|---|
| 暴露类型 | 完全室内、几乎不外出 | 体外风险低；体内仍需按兽医意见 |
| 暴露类型 | 每天外出、接触草地与公共区域 | 体外暴露持续，风险高 |
| 暴露类型 | 季节性外出（春秋、夏季） | 需按季节调整 |
| 接触其他动物 | 猫狗混养、常去宠物店或寄养 | 交叉感染风险上升 |
| 年龄 | 幼宠 | 体内寄生虫更常见；**首次驱虫时机由兽医确定** |
| 年龄 | 老年 | 需评估免疫状态与基础疾病 |
| 免疫与健康 | 免疫状态良好或不佳 | 影响方案，**由兽医评估** |
| 既往感染史 | 曾有寄生虫感染 | 需医生确认是否需要连续方案 |
| 环境 | 家中有其他未驱虫动物 | 相互交叉感染 |
| 环境 | 潮湿、动物密集 | 体外寄生虫与中间宿主风险上升 |

**为什么要按维度而不是按固定天数**：同样一只猫，室内散养与每天放养的体外驱虫需求完全不同；同样一只幼犬，第一次驱虫的时机取决于它吃了什么、什么时候接触地面。**把这些因素摊开给兽医，是拿到合理方案的前提。**

## 五、间隔计算口径

### 5.1 需要区分的三种间隔

| 间隔类型 | 含义 | 谁确定 |
|---|---|---|
| 体内驱虫的给药间隔 | 两次体内驱虫之间隔多久 | 兽医 |
| 体外驱虫的给药间隔 | 两次体外驱虫之间隔多久 | 兽医 |
| 与疫苗的间隔 | 驱虫与免疫之间是否需要分开 | 兽医 |

**三条间隔不能混算**：体内与体外的给药间隔本身可能不同，再加上与疫苗的间隔，**混在一起算必然出错**。

### 5.2 与疫苗的间隔口径

| 口径 | 说明 |
|---|---|
| 是否必须分开 | **由兽医确认**，不同方案与不同个体情况不同 |
| 安排方式 | 常见做法是**错开日期**而不是同日进行，方便观察反应、判断来源 |
| 同日进行的风险 | 若同日进行，**出现不良反应时难以区分是驱虫还是疫苗引起** |
| 观察重点 | 每次后观察 24-48 小时的精神、食欲、粪便、体温 |
| 记录要求 | **两次都记日期**，便于对齐与复盘 |
| 幼宠 | 首次驱虫与首次免疫的时间顺序**由兽医安排** |

**为什么要错开而不是同日**：不是为了"安全间隔"这种笼统说法，**实际价值在于出现了不良反应时能判断来源**。这是排查问题的基础。

### 5.3 给药口径的确认要求

| 项目 | 要求 |
|---|---|
| 药品品种 | **由兽医确定并写明**，不用"通用型"这种模糊说法 |
| 给药方式 | 口服、外滴、佩戴项圈或注射，**由兽医确定** |
| 剂量 | **按体重由兽医确定并记录当时的体重**；不同体重的剂量不同 |
| 体重记录 | **每次给药时记录当时体重**，体重变化直接影响后续方案 |
| 给药间隔 | 由兽医确定并写入记录 |
| 疗程 | 有些情况需要连续给药，疗程由兽医确定，**不自行停药** |
| 体内外是否同期 | 由兽医确认是否需要分开或同期 |

## 六、执行与观察

| 环节 | 口径 |
|---|---|
| 给药时间 | 选宠物相对放松的时间，便于观察反应 |
| 给药后 | 观察 24-48 小时精神、食欲、呕吐、腹泻、粪便 |
| 粪便观察 | 记录有无虫体排出，但**"看不到虫"不等于"没打中"** |
| 是否有效 | **不能只靠有没有排出虫来判断**；是否有效由兽医结合检查判断 |
| 重复给药 | 按医嘱完成疗程，不自行停也不自行加 |
| 多宠家庭 | 每只分别记录，**不共用一份记录** |
| 环境同步 | 体外驱虫**必须同步处理环境** |

**关于"吃了药没看到虫"**：虫体排出与否受感染负荷、给药时间、个体差异影响，**看不到虫不等于药无效**。是否需要调整方案由兽医判断，不要自行加量或缩短间隔。

---

## 七、环境处理方向

**体外驱虫必须与环境处理同步，否则复发几乎必然。**

| 环节 | 方向 |
|---|---|
| 宠物本身 | 按兽医方案定期驱虫 |
| 寝具与织物 | 清洗并高温处理；无法高温的可按产品说明处理 |
| 宠物窝与垫子 | 清洗、暴晒 |
| 吸尘 | 重点清理地毯、沙发缝、墙角；**吸尘袋立即扎紧丢弃** |
| 蚤蛹 | 蛹对药剂耐受，**吸尘器拍打 carpets 有助于刺激蛹羽化**，从而暴露在残留药剂下 |
| 潮湿处 | 保持干燥，减少潮气 |
| 其他动物 | 同住动物**同时处理** |
| 体外环境（犬） | 避开已知高发草地与草丛区域，尤其是蜱虫高发期 |

**关于灭蚤产品**：可使用正规登记的宠物专用产品或环境处理产品；**品种选择、使用方式与对幼宠、鱼类的安全性须确认**。有鱼缸与鸟笼的家庭需特别注意——**鱼缸与鸟笼附近不要使用宠物体外驱虫环境产品**。

## 八、脚本用法

```
python scripts/deworm_calc.py --file plan.json
python scripts/deworm_calc.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`species`、`age_months`、`indoor_only`、`outdoor_freq`、`multi_pet`、`last_internal_deworm`、`last_external_deworm`、`last_vaccine`、`next_vaccine`、`weight_kg`、`symptoms`、`red_flags` |
| `--json` | 以 JSON 输出 |
| `--out` | 结果写入指定文件，默认 `scripts/_last_result.txt` |
| `--selftest` | 运行自检 |

脚本做四件事：**按暴露维度给风险分层（不替兽医定周期）→ 分别算体内、体外与疫苗三条间隔并算出距上次天数 → 排就医红线 → 列出需向兽医确认的方案项**。脚本**不给药名、不给剂量、不给固定驱虫天数**。

## 十、最常见的坑

**坑一：体内外驱虫混着算间隔。**
错误做法：体内药三个月一次、体外药一个月一次，但都记在同一个本子上，算的时候按同一条线排。正确做法：**体内、体外、与疫苗三条间隔分开排、分开记**。三条间隔本身可能不同，混着算必然出错。

**坑二：看不到虫就认为药没用。**
错误做法：吃了驱虫药，粪便里没看到虫，认为买错了，下次不吃了。正确做法：**"看不到虫"不等于"没打中"**。虫体是否排出受感染负荷、给药时间、个体差异影响。是否需要调整方案由兽医判断，**不要自行加量或缩短间隔**。

**坑三：每月固定一片当保健品。**
错误做法：不管暴露情况如何，每月喂一片驱虫药图省事。正确做法：**给药方案由兽医确定**。完全室内的猫与每天放养的猫，体外驱虫需求完全不同。定期把暴露情况讲清楚给兽医，才是拿到合理方案的前提。

**坑四：同日做驱虫和疫苗。**
错误做法：为了省事约在同一天。正确做法：**错开日期**。实际价值不在于某种"安全间隔"，而在于**出现不良反应时能判断来源**——同日进行，出了问题根本分不清是驱虫还是疫苗引起的。

**坑五：体外驱虫只给宠物做，环境不管。**
错误做法：给猫滴了一滴驱虫药，认为任务完成。正确做法：**体外驱虫必须同步处理环境**。跳蚤和蜱虫的大部分卵、幼虫、蛹在环境里，只给宠物驱虫很快会再次感染。织物清洗、吸尘、吸尘袋立即扎紧丢弃，这些步骤不能省。

**坑六：用人用药给猫驱虫。**
错误做法：家里有人的驱虫药，顺手给猫吃。正确做法：**部分人用驱虫药对猫有严重毒性**。猫用药必须由兽医开具，**这是硬红线，不是"注意一下就行"的事**。

**坑七：耳螨当成体外驱虫一定能解决。**
错误做法：猫甩头、耳朵有黑褐色分泌物，买体外驱虫药滴。正确做法：**耳螨位置在耳道内，普通体外滴剂未必覆盖耳道**；耳道分泌物也可能是耳炎。需要医生检查确认，不是自己判断。

**坑八：多宠共用一份驱虫记录。**
错误做法：一只猫驱完，在本子上写"猫狗都驱了"。正确做法：**每只分别记录**，包括各自的体重、给药日期与品种。体重不同剂量就不同，记录混在一起无法核对，也容易重复或漏做。

## 十一、边界与免责

- **体内驱虫药与体外驱虫药的品种、剂量、给药方式、给药间隔与疗程，全部由执业兽医确定。** 本技能只提供核查口径、作用对象差异、间隔计算方式与记录方法
- **不提供任何驱虫药名称、品牌、成分、剂量与按体重换算**
- 不判断体内寄生虫种类与感染程度，**确认需做粪检并由兽医解读**
- 与疫苗的间隔是否需要分开、分开多久，**由兽医确认**
- 幼宠首次驱虫时机、母宠妊娠与哺乳期用药、有基础疾病者的方案，**均须兽医评估**
- **绝对禁止给人用药给宠物驱虫**；部分人用驱虫药对猫有严重毒性
- 环境驱虫产品的选择与使用须确认对同住幼宠、鱼类、鸟类的安全性
- 驱虫药与兽用制剂的使用**以兽医医嘱和产品标签说明为准**
