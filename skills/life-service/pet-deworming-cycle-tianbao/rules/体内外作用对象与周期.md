# 体内外作用对象与周期核查

> **驱虫药的品种、剂量、给药方式、给药间隔与疗程全部由执业兽医确定。** 本文件只提供作用对象差异与核查口径。

## 一、体内寄生虫与表现线索

| 类别 | 常见代表 | 表现线索 | 说明 |
|---|---|---|---|
| 蛔虫 | 蛔虫 | 幼宠多见；粪便中可见；可能有腹痛、消瘦 | 常见地面传播寄生虫 |
| 绦虫 | 绦虫 | 粪便中可见白色或米粒状节片；肛周瘙痒 | 常与跳蚤中间宿主相关 |
| 钩虫 | 钩虫 | 便血、贫血、消瘦 | 可经皮肤侵入 |
| 鞭虫 | 鞭虫 | 大量黏液便、腹泻、消瘦 | 幼犬猫多见 |
| 蛲虫（犬） | 蛲虫 | 肛周异动、夜间瘙痒 | 主要在犬 |
| 球虫类 | 等孢子虫等 | 幼宠腹泻、便中带血 | 幼年发病较多 |
| 弓形虫 | 弓形虫 | 多数无症状；免疫低下时发病 | 人畜共患病，管理上要重视卫生 |

## 二、体外寄生虫与表现线索

| 类别 | 常见代表 | 表现线索 | 说明 |
|---|---|---|---|
| 跳蚤 | 跳蚤 | 剧烈瘙痒；黑色颗粒状粪便；腰臀部与尾根多见 | 会叮咬人；家中有跳蚤是常见反复来源 |
| 蜱虫 | 蜱虫 | 肉眼可见虫体附着；叮咬处红肿、结痂 | 可传播疾病；草地与户外是高暴露环境 |
| 耳螨 | 耳螨 | 剧烈甩头、耳道内黑褐色分泌物、结痂 | 位置在耳道内，普通体外滴剂未必覆盖耳道 |
| 疥螨 | 疥螨 | 剧烈瘙痒、脱毛、结痂，多从边缘开始 | 传染性强，人也可被感染 |
| 蠕形螨 | 蠕形螨 | 脱毛、红斑、皮肤增厚 | 需皮肤镜检确认 |
| 虱子 | 虱子 | 可见蠕动的虫体、结痂 | 多见于环境差或免疫低下个体 |
| 恙螨 | 恙螨 | 趾间、腹部红斑、剧烈瘙痒 | 潮湿季节高发 |

## 三、体内外驱虫的区别要点

| 对比项 | 体内驱虫 | 体外驱虫 |
|---|---|---|
| 作用对象 | 肠道与体内器官的寄生虫 | 体表与皮毛上的寄生虫 |
| 常见表现 | 粪便异常、消瘦、腹泻、血便 | 瘙痒、脱毛、结痂、可见虫体 |
| 确认方式 | 需要粪检才能确定 | 一般靠外观与皮肤检查 |
| 环境处理 | 主要是粪便清理与消毒 | 必须同步处理环境，否则复发 |
| 人是否受影响 | 弓形虫等属人畜共患病 | 跳蚤、蜱虫、疥螨可影响人 |

**体外驱虫不做环境等于白做**：宠物身上的跳蚤和蜱虫大部分卵、幼虫、蛹在环境里，只给宠物驱虫而环境不处理，很快会再次感染。

## 四、周期核查维度

**具体周期由兽医根据暴露风险确定。本表是核查时的分类维度，不给固定天数。**

| 维度 | 情况 | 对周期的影响 |
|---|---|---|
| 暴露类型 | 完全室内、几乎不外出 | 体外风险低；体内仍需按兽医意见 |
| 暴露类型 | 每天外出、接触草地与公共区域 | 体外暴露持续，风险高 |
| 暴露类型 | 季节性外出（春秋、夏季） | 需按季节调整 |
| 接触其他动物 | 猫狗混养、常去宠物店或寄养 | 交叉感染风险上升 |
| 年龄 | 幼宠 | 体内寄生虫更常见；首次驱虫时机由兽医确定 |
| 年龄 | 老年 | 需评估免疫状态与基础疾病 |
| 免疫与健康 | 免疫状态良好或不佳 | 影响方案，由兽医评估 |
| 既往感染史 | 曾有寄生虫感染 | 需医生确认是否需要连续方案 |
| 环境 | 家中有其他未驱虫动物 | 相互交叉感染 |
| 环境 | 潮湿、动物密集 | 体外寄生虫与中间宿主风险上升 |

**为什么按维度而不是按固定天数**：室内散养与每天放养的猫，体外驱虫需求完全不同；幼犬首次驱虫时机取决于它吃了什么、什么时候接触地面。**把因素摊开给兽医，是拿到合理方案的前提。**

## 五、三种间隔不能混算

| 间隔类型 | 含义 | 谁确定 |
|---|---|---|
| 体内驱虫的给药间隔 | 两次体内驱虫之间隔多久 | 兽医 |
| 体外驱虫的给药间隔 | 两次体外驱虫之间隔多久 | 兽医 |
| 与疫苗的间隔 | 驱虫与免疫之间是否需要分开 | 兽医 |

### 与疫苗的间隔口径

| 口径 | 说明 |
|---|---|
| 是否必须分开 | 由兽医确认，不同方案与个体情况不同 |
| 安排方式 | 常见做法是错开日期而不是同日进行 |
| 同日进行的风险 | 出现不良反应时难以区分是驱虫还是疫苗引起 |
| 观察重点 | 每次后观察 24-48 小时的精神、食欲、粪便、体温 |
| 记录要求 | 两次都记日期，便于对齐与复盘 |
| 幼宠 | 首次驱虫与首次免疫的时间顺序由兽医安排 |

**为什么错开而不是同日**：实际价值在于**出现不良反应时能判断来源**，这是排查问题的基础。

## 六、给药口径的确认要求

| 项目 | 要求 |
|---|---|
| 药品品种 | 由兽医确定并写明，不用通用型这种模糊说法 |
| 给药方式 | 口服、外滴、佩戴项圈或注射，由兽医确定 |
| 剂量 | 按体重由兽医确定并记录当时的体重 |
| 体重记录 | 每次给药时记录当时体重 |
| 给药间隔 | 由兽医确定并写入记录 |
| 疗程 | 有些情况需连续给药，疗程由兽医确定，不自行停药 |
| 体内外是否同期 | 由兽医确认是否需要分开或同期 |

## 七、执行与观察

| 环节 | 口径 |
|---|---|
| 给药时间 | 选宠物相对放松的时间，便于观察反应 |
| 给药后 | 观察 24-48 小时精神、食欲、呕吐、腹泻、粪便 |
| 粪便观察 | 记录有无虫体排出，但看不到虫不等于没打中 |
| 是否有效 | 不能只靠有无排出虫判断；是否有效由兽医结合检查判断 |
| 重复给药 | 按医嘱完成疗程，不自行停也不自行加 |
| 多宠家庭 | 每只分别记录，不共用一份记录 |
| 环境同步 | 体外驱虫必须同步处理环境 |

## 八、环境处理方向

| 环节 | 方向 |
|---|---|
| 宠物本身 | 按兽医方案定期驱虫 |
| 寝具与织物 | 清洗并高温处理；无法高温的可按产品说明处理 |
| 宠物窝与垫子 | 清洗、暴晒 |
| 吸尘 | 重点清理地毯、沙发缝、墙角；吸尘袋立即扎紧丢弃 |
| 蚤蛹 | 蛹对药剂耐受；吸尘器拍打地毯有助于刺激蛹羽化，从而暴露在残留药剂下 |
| 潮湿处 | 保持干燥，减少潮气 |
| 其他动物 | 同住动物同时处理 |
| 体外环境（犬） | 避开已知高发草地与草丛区域，尤其蜱虫高发期 |

**灭蚤产品**：可使用正规登记的宠物专用或环境处理产品；品种选择、使用方式与对幼宠、鱼类的安全性须确认。**鱼缸与鸟笼附近不要使用宠物体外驱虫环境产品。**

## 九、绝对禁止

- 不给人用药给宠物驱虫（部分人用驱虫药对猫有严重毒性，猫禁用）
- 不自行加大剂量或缩短间隔
- 不把体外驱虫药按体内驱虫用，或反之
- 不在多种驱虫药之间自行叠加
- 不用驱虫药当保健品每月一片的思路

## 十、就医红线

| 情况 | 说明 |
|---|---|
| 服药后抽搐、意识障碍、呼吸困难、面部肿胀 | 急性过敏反应，立即急诊 |
| 服药后持续呕吐腹泻超过 24 小时，伴精神沉郁 | 就诊评估 |
| 粪便中持续可见大量虫体或虫卵 | 感染负荷高，需粪检确定种类 |
| 肛周有异动但粪便中找不到虫 | 需排查绦虫、滴虫，需要粪检 |
| 大面积脱毛、红斑、结痂 | 需排查真菌与螨虫，不限于驱虫能解决 |
| 耳道内黑褐色分泌物、剧烈甩头 | 需排查耳螨与耳炎，驱虫药未必覆盖 |
| 幼宠驱虫后持续不吃不喝 | 幼犬幼猫需注意血糖偏低 |
| 怀疑误服过量或多宠共用剂量导致过量 | 立即联系兽医 |
| 母宠妊娠期或哺乳期 | 方案须兽医确定 |
| 有肝肾基础疾病或正在服用其他药物 | 方案须兽医确定 |
