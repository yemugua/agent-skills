# 家庭组网规则库

> 生成方案、写采购建议、做验收表之前，先读这份文件，不要凭印象写。

---

## 一、拓扑选型决策表（按顺序判，命中即停）

| 顺序 | 判据 | 命中后的结论 |
|---|---|---|
| 1 | 有线直连也慢 | 宽带或线路问题，**回到运营商**，不是组网问题 |
| 2 | 能布网线，且面积大或跨层 | **路由 + 有线 AP**，最稳，漫游可控 |
| 3 | 不能布线，面积 ≤ 90 ㎡，承重墙 ≤ 4 | 单台高规格无线路由器，先试再决定加节点 |
| 4 | 不能布线，面积 > 90 ㎡，或承重墙多，或跨层 | **Mesh 多节点**，5G 优先留作回程 |
| 5 | 无线设备很多（25 台以上）且不能布线 | Mesh 多节点，单独考虑 5G 专用回程 |
| 6 | 弱电箱位置极偏且无法外放线 | 主节点必须移出弱电箱，否则一切白做 |
| 7 | 商铺、办公、公寓多 AP 需求 | **转专业网规**，不在本表内解决 |

**否定项提醒**：「家里信号不好」不等于「要买 Mesh」。满格还慢是干扰问题，换设备无效。

## 二、节点数估算口径

估算起点：每 40-60 ㎡ 一个覆盖单元；每道承重墙额外削减一档穿透能力；每多一层至少加一个节点。

**必须说明**：以上只是估算起点，**最终数量以逐点实测为准**。厂商标称覆盖面积是在理想空旷环境测的，承重墙、金属柜、异形户型都会让实际覆盖缩水。

## 三、回程带宽换算表

| 入户实测速率 | 有线回程下限 | 无线回程可行性 |
|---|---|---|
| ≤ 300Mbps | 100Mbps | 可用，注意实测折损 |
| 500Mbps | 200Mbps | 可用但折损明显，多节点慎用 |
| 1000Mbps | 500Mbps | **不建议无线回程**，多节点优先有线 |
| > 1000Mbps | 全千兆有线 | 无线回程撑不住 |

**无线回程折损口径**：同频段回程占用本机收发能力的一半左右，实测通常只有直连速率的一半左右；跨楼层、隔承重墙还要再打折。这条经验值**只作估算，须实测**。

## 四、2.4G 与 5G 分工表

| 项目 | 2.4GHz | 5GHz |
|---|---|---|
| 穿透 | 强 | 弱 |
| 速率 | 低 | 高 |
| 干扰 | 大 | 小 |
| 设备类型 | 智能家居、摄像头、门锁、老设备 | 手机、平板、电脑、电视 |
| 是否做回程 | 可，不推荐 | 推荐专用 |

**SSID 策略**：默认建议 2.4G 与 5G 分开命名，方便按设备类型绑定，也便于分频段测速对比。双频合一只在设备不支持手动选频、且没有智能家居设备时才考虑。

## 五、漫游机制对比

| 机制 | 是否需要客户端支持 | 常见问题 |
|---|---|---|
| 双频合一 | 否 | 智能家居找不到网；手机反复跳频 |
| 各节点发同名 SSID | 部分 | 老设备黏在弱节点不切 |
| 802.11r | 是 | 老设备不兼容 |
| 802.11k/v | 是 | 需要 AP 端同时开启 |

**验收方法**：拿手机从弱节点走到强节点，确认连接真的切换了。只有信号格数变化不算漫游。

## 六、摆放禁忌与要点

| 位置 | 判定 | 说明 |
|---|---|---|
| 弱电箱内 | ❌ 禁止 | 金属封闭空间包住天线，覆盖明显变差 |
| 紧邻金属柜 / 鱼缸 / 镜面 | ❌ 禁止 | 反射与遮挡造成信号空洞 |
| 紧邻微波炉 | ❌ 禁止 | 工作时 2.4G 明显受干扰 |
| 天花板夹层 / 吊顶内 | ❌ 禁止 | 散热差且信号被压制 |
| 居中开阔、离地 1-1.5 米 | ✅ 推荐 | 覆盖利用率最高 |
| 跟着网线走的有线 AP | ✅ 推荐 | 不受插座位置限制 |

## 八、光猫模式对照（只讲判断，不代改）

| 模式 | 特点 | 更适合的情况 |
|---|---|---|
| 路由模式 | 光猫直接拨号上网 | 只想上网、不做端口映射或远程访问 |
| 桥接模式 | 光猫只转光，拨号交给自己的路由器 | 需要端口映射、内网穿透、访客网络等高级功能 |

**改动前必须确认三件事**：当前是哪种模式、是否有端口映射或远程访问在用、改回去的方法是否清楚。**不要盲目改。**

## 九、常见组网错误清单（逐条排查）

| 错误 | 表现 | 正确做法 |
|---|---|---|
| 主节点塞在弱电箱 | 全屋信号都一般 | 移出弱电箱，或用线引到箱外 |
| 光猫与路由都分配地址 | 有时连不上网 | 只保留一处分配 |
| 多节点全无线回程 | 节点越多越慢 | 优先有线，或 5G 专用做回程 |
| 双频合一 | 智能家居连不上 | 分开 SSID，按设备绑定 |
| 把 AP 塞进弱电箱当分线器 | 供电不稳或只能无线回程 | AP 放箱外，保证供电与网线 |
| 只按标称面积买节点 | 死角照样有 | 逐点实测后补节点 |
| 光猫与路由贴太近 | 5G 互相干扰 | 拉开距离，网线各自归位 |
| 改光猫参数不记录原状 | 出问题无法回退 | 改前记录，改后立即验证 |
