# AB 实验样本量与显著性规则库

> 生成任何实验方案、样本量测算或显著性结论前，先读这份规则，不要凭印象写。

---

## 一、参数定义（先把四个词定死）

| 参数 | 符号 | 含义 | 谁定 |
|---|---|---|---|
| 基线率 | p1 | 实验开始前、对照组的指标取值 | 历史同口径数据 |
| 目标率 | p2 | 实验组期望达到的指标取值 | p1 × (1 + 相对提升) |
| 绝对提升 | δ | p2 − p1 | 相对提升 × p1 |
| 相对提升 | e | δ / p1 | 业务方定，必须换算成绝对值再进公式 |
| 显著性水平 | α | 拒绝原假设的概率上界（假阳性） | 默认 0.05 双侧 |
| 统计功效 | 1−β | 真的有效时能测出来的概率（1−β 是漏检率） | 默认 0.8 |
| 最小可检测提升 MDE | — | 在选定样本量下能可靠检出的最小提升 | 反解得出 |

**防误伤提醒**：`p` 值（p-value）与 `p1`（基线率）完全是两回事。写文档时用 `p_value` 与 `baseline_rate` 区分，不要都写成 `p`。

## 三、样本量公式

### 比例型指标（转化率、点击率、成功率）

```
n = 7.849 × [ p1(1-p1) + p2(1-p2) ] / (p2 - p1)²      （α=0.05 双侧, power=0.8）
```

### 连续型指标（金额、时长、人均次数，标准差 σ）

```
n = 2 × 7.849 × σ² / δ²
```

### 比率型指标（分子分母都是随机的，如「点击率 = 点击 / 曝光」）

方差比简单比例大得多，需用 delta 方法单独估算；粗略做法是把有效样本量打 0.7~0.8 折，或直接改用「分子绝对量」+「分母均值」做区间估计。

### 效应量 Cohen's h（比例型）——用于事后功效分析

```
h = 2 × arcsin(√p1) − 2 × arcsin(√p2)
判定：|h| < 0.2 小，0.2~0.5 中，0.5~0.8 大，> 0.8 很大
```

## 四、样本量速查表（α=0.05 双侧 / power=0.8 / 相对提升 10%）

| 基线率 | 目标率 | 方差项 `[p1(1-p1)+p2(1-p2)]` | 每组样本量 | 总样本量（两组） |
|---|---|---|---|---|
| 1% | 1.1% | 0.020779 | 163,092 | 326,184 |
| 2% | 2.2% | 0.041116 | 80,679 | 161,358 |
| 5% | 5.5% | 0.099475 | 31,231 | 62,462 |
| 10% | 11% | 0.187900 | 14,748 | 29,496 |
| 20% | 22% | 0.331600 | 6,507 | 13,014 |
| 30% | 33% | 0.431100 | 3,760 | 7,520 |
| 50% | 55% | 0.497500 | 1,562 | 3,124 |
| 80% | 88% | 0.265600 | 326 | 652 |

> 全部数字可用 `python scripts/ab_sample_size.py --p1 X --mde 10 --relative` 逐行复算验证。
>
> - **1% 基线每组要 16 万人**——这就是低转化率实验必须先改指标或改分流的原因。
> - **10% 行高于 5% 行**：相对提升同为 10%，绝对差却从 0.5pp 变1pp，样本量随之上涨。
> - **80% 行最小**：因为 80%→88% 是 +8pp 的巨大绝对提升。高基线下的「小相对提升」依然昂贵。
> - 方差项在 p=50% 时最大（0.4975），因此 p1=50%、绝对提升 5pp 的 1,562 人并不算小。
> - 同为 +2pp 时，20%→22% 与 78%→80% 样本量完全相同（方差关于 50% 对称），可用作口径校验。

## 五、天数与流量

```
每日有效入组 = 日流量 × 实验流量比例
每组每日入组 = 每日有效入组 ÷ 实验组数
所需天数     = ⌈ 每组样本量 ÷ 每组每日入组 ⌉
最终天数     = max(所需天数, 7)，并向上取整到 7 的倍数
```

**流量可行性判断表：**

| 日有效入组（每组） | 达成 14,730 所需天数 | 是否可行 |
|---|---|---|
| 5,000 | 约 3 天 | ✅ 但必须延到 7 天以上 |
| 1,000 | 约 15 天 | ⚠️ 周期太长，考虑放宽 MDE 或合并变体 |
| 200 | 约 74 天 | ❌ 不可行，放弃或改做前后对比 |
| 20 | 约 736 天 | ❌ 完全不可行 |

**一条铁律：同一个变体不能同时承载两个改动。** 实验组和对照组必须只差一个变量，否则效应无法归因。

## 六、分流规则

| 规则项 | 硬要求 | 违反后果 |
|---|---|---|
| 分流单元 | 明确到用户/设备/会话/门店之一，与统计单元一致 | 同一单元跨组，效应趋零 |
| 哈希稳定性 | 同一分流标识恒定落在同一组，跨端一致 | 用户漂移组，污染指标 |
| 比例固定 | 对照组是固定比例而非「剩下的」 | 无法保证组间可比 |
| 分层 | 需按地域/机型等分层时，必须在层内随机，层间比例一致 | 辛普森悖论 |
| 排查顺序 | 分流哈希 → 重定向（是否被中途改组）→ 去重逻辑 → 埋点丢失 | — |

## 七、剔除规则（必须上线前定稿）

允许剔除的四类，且**两组同规则**：

1. 内部账号与机器人账号
2. 脏数据：设备 ID 异常、时间戳非法、UA 为空
3. 无有效曝光：分到组但目标界面未渲染
4. 实验期间被其他实验互斥覆盖的单元

**明令禁止**：
- 事后剔除「指标特别差」的单元
- 两组用不同剔除规则
- 把剔除率高于对照组的那部分人单独拿出来看

剔除率两组差值超过 0.5pp 时，要作为 SRM 之外的独立问题排查。

## 八、SRM 卡方检验阈值表

| 自由度 df | p=0.05 | p=0.01 | **p=0.001** |
|---|---|---|---|
| 1（两组） | 3.841 | 6.635 | **10.828** |
| 2（三组） | 5.991 | 9.210 | **13.816** |
| 3（四组） | 7.815 | 11.345 | **16.266** |
| 4（五组） | 9.488 | 13.277 | **18.467** |
| 5（六组） | 11.070 | 15.086 | **20.515** |

判定：卡方统计量 > 对应阈值即拒绝「实际人数按设定比例分配」。

**为什么用 p<0.001 而不是 p<0.05**：分流错误在正常实验中极罕见，正常实验出现 p<0.05 的概率不小（每 20 个实验就会有 1 个），用 0.05 会大量误杀；用 0.001 把误杀率压到千分之一，同时真正的分流 bug 几乎必然被抓住。

期望人数小于 5 时卡方近似失效，应改用精确检验或先把天数拉长。

## 九、停止规则

| 规则 | 是否安全 | 说明 |
|---|---|---|
| 固定样本量（跑够 n 才停） | ✅ | 唯一能保证名义 α 的做法 |
| 固定天数（跑满 D 天才停） | ✅ | 天数由样本量反推得出 |
| 固定天数 + 看 CI 宽度 | ✅ | 更好：结束时若 CI 跨过 0 且宽度仍大于业务 MME，报「数据不足」并给出所需样本量 |
| 逐日 peek，显著就停 | ❌ | 假阳性率从 5% 膨胀到 20%–30% |
| 中途改停止条件 | ❌ | 等价于事后挑时间点 |

**护栏指标**：崩溃率、错误率、客诉量、核心功能成功率。预设阈值（如崩溃率环比 +0.2pp），触发即**立即停并回滚**，不读正向指标。

## 十、结论写法（必须按此模板）

```
指标名称：            （口径见指标字典）
基线值 / 实验值：     p1 → p2
绝对提升 / 相对提升： δ pp / e%
95% 置信区间：        [下界, 上界] pp
p 值：                0.0xx
实际样本量：          对照组 x 人，实验组 y 人（计划 z 人）
实际运行时长：        x 天
SRM 检验：            p = 0.xx
结论：                显著正向 / 显著负向 / 无显著差异 / 数据不足
业务判断：            效应量是否达到最小有意义提升 MME
```

**四选一的结论措辞必须严格区分：**
- 「显著正向」——效应量达 MME
- 「显著负向」——回滚
- 「无显著差异」——**仅当样本量已达计划值且 CI 已排除 MME 时才可写**
- 「数据不足」——CI 仍包含 ±MME，**不得写成「无显著差异」或「有正向趋势」**

## 十一、多重比较校正

| 场景 | 校正方式 | 校正后 α |
|---|---|---|
| 1 个主指标 + 若干辅助指标 | 主指标用 0.05，辅助指标仅描述 | 主 0.05 / 辅 不做结论 |
| k 个指标同为决策依据 | Bonferroni | 0.05 / k |
| k 个变体对同一对照 | Bonferroni | 0.05 / k |
| 长期连续实验平台 | FDR（BH）控制错误发现率 | 视 q 值 |

不做校正的实际假阳性：看 5 个指标，至少一个「显著」纯属偶然的概率约 **23%**；看 10 个约 **40%**。
