# 投诉信（投诉书）必备要素与写法规范

## 一、十二项必备要素（缺一项就可能被退回或石沉大海）

| # | 要素 | 判定标准 | 缺了会怎样 |
|---|---|---|---|
| 1 | 受理单位名称 | 写全称或规范简称，如"XX 区市场监督管理局""XX 平台客服中心" | 无法确定受理主体，材料被转来转去 |
| 2 | 投诉人姓名 | 与身份证件、账号实名一致 | 无法核实身份，不予受理 |
| 3 | 联系方式 | 手机号（必填）+ 邮箱或通讯地址 | 无法回访，直接搁置 |
| 4 | 被投诉方全称 | 营业执照上的全称或平台店铺全称，不要写"那家店" | 无法锁定主体，无法查处 |
| 5 | 事实时间线 | 至少 3 个时间节点：交易/签约日、问题发现日、协商日 | 看不出经过，无法认定 |
| 6 | 问题描述 | 客观描述，不带情绪词，说明具体哪里不符合约定/规定 | 被认定为情绪化诉求，降低优先级 |
| 7 | 具体诉求 | 可执行、可验证：退款 XX 元 / 换货 / 修复 / 书面道歉 / 查处并反馈 | 诉求模糊导致无法办理 |
| 8 | 金额与计算 | 争议金额 + 计算过程 + 已付/已退金额 | 涉及退费的，金额不明确无法调解 |
| 9 | 凭证编号 | 订单号、合同编号、发票号、运单号、保单号 | 无法调取记录 |
| 10 | 已协商情况 | 沟通过几次、对方答复是什么、有无拒绝记录 | 未体现"先协商"，被要求先自行协商 |
| 11 | 证据清单 | 逐项列明：合同/发票/聊天截图/照片/录音/检测报告，编号对应 | 证据未列明容易被忽略 |
| 12 | 签名与日期 | 手写签名或实名账号提交，落款日期 | 形式要件缺失 |

**加分项（能显著提高处理效率）**：
- 附一页"事实时间线表"（日期 - 事件 - 证据编号）
- 诉求按优先级排序，标出"最低可接受方案"
- 明确回复方式与期限期望（如"请在 15 个工作日内书面答复"）

## 二、写法规范

### 结构（一页纸原则，正文控制在 800 字内）

```
标题：关于 XXX 的投诉书 / 投诉信
抬头：受理单位全称
第一段：我是谁 + 我要投诉谁 + 我要什么（三句话讲完）
第二段：事实经过（按时间顺序，一段一节点）
第三段：为什么对方应当负责（约定条款 / 承诺内容 / 通行规则）
第四段：我已经做了什么（协商过程与对方答复）
诉求清单：1. 2. 3.（可执行、可验证）
附件清单：1. 2. 3.（与正文证据编号对应）
落款：签名 + 日期 + 联系方式
```

### 语气要求

| 要这样写 | 不要这样写 |
|---|---|
| "2026 年 3 月 5 日交付的商品，3 月 8 日出现 XX 故障，与商品页面承诺的 XX 不符" | "这破东西三天就坏了，明显是垃圾货" |
| "商家于 4 月 2 日明确表示不予退换" | "商家态度极其恶劣，拒不处理" |
| "请求协调退还货款 1,280 元" | "必须给我一个说法，否则没完" |
| "据我了解，该类商品应提供不少于 XX 的售后" | "你们肯定收了好处费" |

**原则**：
1. **只写事实和证据，不写推测和动机**。"我认为他们故意欺诈"要改成"商品页面标注 XX，实际收到 XX，二者不一致"
2. **每一句事实后面跟一个证据编号**
3. **不写没有证据支撑的定性词**（"诈骗""黑心""故意"），这类词不仅不会加分，还会让受理方质疑材料可信度
4. **不写威胁性表述**（曝光个人信息、上门、网络曝光要挟），可能被认定为不当诉求
5. **诉求要留协商余地**，写"请求协调退还 XX 元"比"要求赔偿十倍并公开道歉"更容易达成

## 三、诉求类型与可执行表述对照

| 诉求类型 | 可执行表述 | 不可执行表述 |
|---|---|---|
| 退款 | "退还已支付货款 1,280 元，退货运费由商家承担" | "把钱退给我" |
| 换货/维修 | "更换同型号全新商品一台，或免费维修至正常使用" | "处理好这件事" |
| 赔偿 | "按实际损失赔偿检测费 300 元（附检测报告）" | "赔偿我的一切损失" |
| 继续履行 | "按合同约定于 X 月 X 日前完成安装调试" | "尽快完工" |
| 查处 | "对被投诉方涉嫌虚假宣传的行为依法查处，并将处理结果告知投诉人" | "严惩这家黑店" |
| 道歉 | "由被投诉方出具书面道歉" | "必须当面向我跪歉" |
| 整改 | "限期拆除/整改 XX，并公示整改结果" | "让他们别再这样了" |

## 四、不同渠道的格式差异

| 渠道 | 格式要求 | 特别注意 |
|---|---|---|
| 12345 / 12315 热线 | 口述即可，话务员记录生成工单 | 说清"被投诉方全称 + 具体诉求 + 订单号"三件事，记下工单号 |
| 12315 平台（网站/小程序） | 在线表单，字段固定，附件限图片/PDF | 企业名称要与营业执照一致，可先在企业信用信息公示系统核对 |
| 电商平台投诉 | 平台内提交，多数要求先与商家协商 | 保留聊天记录，平台只看站内聊天记录，站外微信记录要截图转存 |
| 书面投诉书（寄送/现场） | 纸质，签名+身份证复印件+证据复印件 | 寄送用 EMS 并保留内件详情单与妥投查询记录 |
| 信访 | 书面或网上信访，需实名 | 已经或应当通过诉讼、仲裁、行政复议解决的，信访不予受理 |
| 行业主管部门举报 | 多用专用表格，需勾选违法行为类别 | 举报与投诉不同：举报是要求查处，投诉是要求解决自身权益争议 |
| 法院起诉/小额诉讼 | 起诉状有法定格式要求 | 不是投诉信，需另行准备 |

## 五、跟进与升级路径

```
提交 → 拿到受理编号/工单号 → 记录受理时间 → 在承诺时限内等待
  → 超期未回复：凭编号催办（同一渠道 + 12345 督办）
  → 处理结果不满意：要求书面答复 → 向上一级主管部门反映
  → 仍不满意：仲裁（有仲裁条款）/ 法院起诉 / 小额诉讼
```

**处理时限口径**（各渠道不同，**以当地主管部门公示为准**）：
- 12345 热线工单：一般有明确的受理告知与办结时限，可在平台查询进度
- 12315 投诉：市场监管部门应在收到投诉之日起**七个工作日内**作出是否受理的决定并告知投诉人（以现行规定为准）
- 信访事项：一般自受理之日起 **60 日内**办结，情况复杂可延长，延长期限不超过 **30 日**
- 电商平台：各平台规则不同，通常 3~15 个工作日

**防误伤提醒**：
- 提交后**没有拿到编号**就等于没提交。任何渠道都要当场索取受理编号/工单号/回执
- "已提交"不等于"已受理"，要确认受理状态
- 同一事项**重复多渠道提交**会被合并处理，反而拖慢；建议先走一个渠道拿编号，超期不处理再升级
- 投诉与举报、信访、诉讼是四条不同的路，混用会导致材料被退回或不予受理

## 六、投诉前的自检清单

- [ ] 被投诉方全称核对过（企业信用信息公示系统 / 营业执照 / 平台店铺信息）
- [ ] 事实时间线至少 3 个节点，每节点有证据
- [ ] 诉求具体、可执行、金额明确
- [ ] 已先与对方协商，并有协商记录
- [ ] 无情绪化、侮辱性、威胁性表述
- [ ] 附件与正文证据编号一一对应
- [ ] 签名、日期、联系方式齐全
- [ ] 已确认渠道选择正确（不是该渠道管的事就换渠道）
- [ ] 涉及金额较大或法律关系复杂的，已考虑咨询律师
