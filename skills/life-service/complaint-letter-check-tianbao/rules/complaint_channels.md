# 投诉路径与受理单位对照表

> 以下为常见投诉事项的受理渠道口径。**具体受理范围、管辖层级与办理时限以当地主管部门公示为准**，跨区域、大额或涉及多个部门的，先打 12345 咨询转派。

## 一、热线速查表

| 热线 | 受理范围 | 典型事项 |
|---|---|---|
| 12345 | 政务服务便民热线，统一转派属地部门 | 不知道找谁时的首选；跨部门事项；承办单位不作为的督办 |
| 12315 | 市场监管（原工商、质检、食药、物价、知识产权整合） | 商品服务质量、虚假宣传、价格欺诈、预付卡跑路、食品安全、消费纠纷调解 |
| 12328 | 交通运输服务监督 | 驾校退费、出租车拒载、网约车、汽车维修、道路客运 |
| 12333 | 人力资源和社会保障 | 欠薪、不签劳动合同、社保缴纳、工伤、劳务派遣 |
| 12378 | 金融监管（银行保险） | 银行乱收费、保险拒赔、销售误导、信用卡纠纷 |
| 12386 | 证券期货 | 证券期货违法违规、投资者诉求 |
| 12393 | 医疗保障 | 医保报销、定点医药机构、医保基金 |

| 12369 | 生态环境 | 噪声、油烟、排污、扬尘 |
| 12316 | 农业农村 | 农资质量、兽医兽药、农机 |

| 事项 | 第一选择 | 备选/升级 |

## 三、四条路径的区别（选错会白跑）

| 路径 | 干什么 | 谁发起 | 结果 | 是否解决自身损失 |
|---|---|---|---|---|
| **投诉** | 解决自己的消费/服务权益争议，要求调解 | 权益受损的当事人 | 组织调解，促成退款赔偿 | ✅ 直接 |
| **举报** | 要求主管部门查处违法行为 | 任何人 | 立案查处、行政处罚 | ❌ 不直接给你赔钱 |
| **信访** | 向政府反映情况、提出建议或投诉请求 | 公民/组织 | 转送有权处理机关并答复 | ❌ 一般不处理民事纠纷 |
| **诉讼/仲裁** | 通过司法或准司法程序主张权利 | 当事人 | 判决/裁决，可强制执行 | ✅ 有强制力 |

**关键区分**：想要回钱走**投诉或诉讼**；想让对方被罚走**举报**。两者可以同时进行，但要分开提交，不要混在一份材料里。

**信访不受理的情形**（常见）：已经或者依法应当通过诉讼、仲裁、行政复议等法定途径解决的；属于各级党委政法委、法院、检察院职权范围的。

## 四、管辖层级怎么定

| 情形 | 找哪一级 |
|---|---|
| 个体工商户、线下门店 | 经营场所所在地的区/县主管部门 |
| 电商平台内商家 | 平台内投诉优先；12315 可投诉商家（属地）或平台（平台注册地） |
| 连锁品牌 | 消费发生地的门店主管机关，或品牌总部所在地 |
| 跨省网购 | 经营者所在地或平台所在地；消费者也可先走平台 |
| 央企、金融机构分支机构 | 分支机构所在地的主管派出机构 |
| 行政机关不作为 | 该机关的本级政府或上一级主管部门（12345 可督办） |

## 五、书面投诉材料的送达与留痕

| 方式 | 留痕要点 |
|---|---|
| 现场提交 | 要求出具**受理回执**或材料接收凭证；没有回执就在材料上盖"收讫"章并拍照 |
| 邮寄 | 用 **EMS**，内件详情单写明"关于 XX 的投诉书"，保留详情单与妥投查询记录 |
| 网上平台 | 截图提交成功页与**受理编号** |
| 热线电话 | 记下**工单号**与通话时间 |
| 电子邮件 | 保留发送成功记录，重要事项仍建议补寄纸质件 |

## 六、提交后的时间管理

- 提交当天：拿到编号，记录提交时间与承诺办结时限
- 受理告知期内：关注是否受理，未收到告知的主动查询
- 办结时限届满前 3~5 天：主动查询进度
- 超期未办结：凭编号催办，必要时通过 12345 反映承办单位不作为
- 结果不满意：索取**书面答复**，作为后续复议、诉讼、仲裁的材料

> 涉及金额较大、法律关系复杂或即将超过诉讼时效的，**不要只靠投诉拖时间**，投诉不产生诉讼时效中断的确定效力，应以起诉、仲裁或取得对方书面确认等更稳妥的方式处理。
