# 企业微信应用与配置排查

面向企业微信开发者与 IT 管理员：自建应用配置报错（redirect_uri 不一致、IP 不在白名单、无权限）、消息回调不通、客户联系/会话存档开通异常的场景。

## 它能做什么

- 核查 **可信域名与网页授权**：可信域名是否配置校验、OAuth2 回调域名与 redirect_uri 是否一致
- 核查 **消息回调**：回调 URL 可达性、Token/AESKey 配置、加解密模式、公网可访问
- 核查 **通讯录与权限**：应用可见范围、通讯录读取权限、secret 权限范围、IP 白名单
- 核查 **客户联系与存档**：客户联系权限、客户群、会话内容存档、离职继承
- 映射 **常见报错码**：40093/60020/81013/48002 等含义与处置
- 给出 **整改清单**：按报错与缺失项排序的配置修复动作

## 使用方式

把 `templates/应用配置采集表.md` 填好（两列表或「字段：值」），交给本技能生成报告。
未填项一律按「待补正 / 有风险」处理，绝不判通过。

## 边界

本结果依通用规则与公开参考值整理，不替代平台/管局/企业微信官方结论，最终以微信公众平台、管局备案系统与企业微信管理后台与官方文档为准。
