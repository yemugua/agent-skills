# 企业微信常见报错码与处置

| errcode | 含义 | 处置 |
| --- | --- | --- |
| 40093 | redirect_uri 与可信域名不一致 | 在「应用管理 → 网页授权及JS-SDK → 可信域名」配置并校验与 redirect_uri 完全一致的域名 |
| 60020 | 调用接口 IP 不在白名单 | 在「企业可信 IP」或应用白名单加入服务器出口 IP；本地调试用内网穿透映射到白名单 IP |
| 81013 | 无权限调用该接口 | 在「应用 → 权限配置」勾选所需接口权限，或检查 secret 对应应用是否正确 |
| 48002 | API 接口无权限 | 确认应用已开通对应接口权限，部分接口需企业微信认证 |
| 45009 / 45011 | 接口调用超限/频率超限 | 降低频率、批量接口、缓存、退避重试 |
| 40089 | 不合法的 secret | 检查 secret 是否复制完整、是否被重置，重新获取 |
| 41001 | 缺少 access_token | 先获取 access_token 再调用业务接口，注意缓存与刷新 |
| 40014 | 不合法的 access_token | access_token 过期或错误，重新获取 |
| 60011 | 不允许跨应用调用 | 确认调用方与应用 secret 匹配 |

## 可信域名与网页授权要点
- 网页授权、JS-SDK、分享依赖可信域名，须配置并校验通过。
- OAuth2 回调地址的域名必须与可信域名完全一致（协议、域名、路径前缀）。
- 回调 URL 必须公网可达，localhost/内网不通。

## secret 安全
- secret 是应用最高凭证，禁止硬编码、明文落库、放前端/客户端、提交到代码仓库。
- 存服务端安全配置，限制可读权限，定期轮换；建议开启操作审计日志。
