# 人身安全保护令：怎么申请、拿到了之后怎么办

> 人身安全保护令由**人民法院**作出。受理条件、管辖法院、材料清单、有效期，
> **一律以受理法院与当地现行规定为准**；本文件写的是通行口径与准备方法。

## 一、它是什么、能干什么

- **作出机关**：人民法院（不是派出所，也不是妇联——妇联和社区只能帮你代写、转介、陪同）。
- **性质**：法院作出的裁定，是最直接、最快的自我保护工具，
  **不需要先打离婚官司，也不要求你已经做了伤情鉴定**。
- **常见可请求事项**：
  1. **禁止实施家庭暴力**；
  2. **禁止骚扰、跟踪、接触**申请人及其近亲属；
  3. **责令迁出住所**；
  4. 其他合理必要的保护措施（例如变更子女探望方式等，视案情与法院口径）。
- **执行**：裁定作出后**可由公安机关协助执行**；
  对方违反裁定的，可就其行为请求**拘留、罚款**，构成犯罪的**依法追究刑事责任**。
- **有效期**：**以裁定书载明为准**，实践中常见为数个月；届满仍面临危险的，
  可以及时重新申请/申请延长。
- **申请费**：一般不收取诉讼费用（具体以受理法院口径为准）。

## 二、谁能申请、去哪申请

| 项 | 说明 |
|---|---|
| 申请人 | **你自己**（受害者本人） |
| 也可以由谁申请 | **居民委员会、村民委员会、妇女联合会、学校、幼儿园、医疗机构**等；
  无民事行为能力人、限制民事行为能力人因年龄或精神状况无法自行申请的，
  其**近亲属**可以代为申请 |
| 去哪申请 | 向**人民法院**直接申请；部分地方可向**居住地**或**家庭暴力发生地**的
  **基层人民法院**申请（各地有细则，**以受理法院口径与当地规定为准**） |
| 能不能委托 | 可以委托律师、基层法律服务工作者、其他愿意帮忙的人；符合条件的可申请法律援助 |

> 常见误区：**"要先报警才有保护令"** —— 报警不是硬性前置条件，但报警记录会让申请顺很多。
> **"没受伤就不能申请"** —— 不要求达到轻伤或见血，重点是"遭受家庭暴力或面临现实危险"。

## 三、材料清单（照这个准备）

| 材料 | 要什么 | 注意 |
|---|---|---|
| 人身安全保护令申请书 | 写明申请人与被申请人身份、关系、请求事项、事实与理由 | 见下方模板 |
| 申请人身份证明 | 身份证原件与复印件 | 未成年人由监护人代为提交时附监护人身份证明 |
| **关系证明** | 结婚证、户口本、居住证、共同生活的证据（同住照片、租房合同、水电缴费、物业记录） | **证明力取决于"关系"，别漏** |
| 证据清单 | 每份证据的名称、来源、证明目的 | 见 rules/evidence-playbook.md |
| 证据复印件 | 报警回执/接警编号、询问笔录、病历、诊断证明、伤情照片、录音、聊天记录、证人证言、社区/妇联记录 | 按时间顺序编号 |
| 送达地址与联系方式 | 法院用来送达对方 | 准确的地址非常关键，决定裁定能否生效执行 |

## 四、申请书写法（可直接照抄改）

```
人身安全保护令申请书

申请人：张三，女，19XX 年 X 月 X 生，身份证号 XXX，
        住址 XXX，联系电话 XXX。
被申请人：李四，男，19XX 年 X 月 X 生，身份证号 XXX，
        住址 XXX，联系电话 XXX。
        申请人与被申请人系夫妻关系（或：共同生活关系）。

请求事项：
1. 禁止被申请人对申请人实施家庭暴力；
2. 禁止被申请人以任何方式骚扰、跟踪、接触申请人及其近亲属；
3. 责令被申请人迁出住所。

事实与理由：
申请人与被申请人自 XXXX 年共同生活（或结婚）。自 20XX 年 X 月起，
被申请人多次对申请人实施暴力：XXXX 年 X 月 X 日，在 XXX 处，
被申请人因 XXX 争执对申请人殴打，致申请人 XX 处受伤（附：医院诊断证明、
伤情照片、报警回执编号 XXX）；XXXX 年 X 月 X 日又发生……

上述行为已持续多次，申请人现仍面临被继续施暴的现实危险。
根据相关规定，特申请人民法院作出人身安全保护令，予以禁止与保护。

此致
XX 区人民法院

附件证据清单：
1. 报警回执（编号 XXX）及询问笔录      —— 证明事发时间与公安机关介入
2. 门诊病历、诊断证明                  —— 证明伤情与致伤成因
3. 伤情照片 X 张                       —— 证明受伤情况
4. 微信威胁记录截图 X 页               —— 证明威胁与经常性
5. 邻居 XXX 证言                       —— 证明亲眼所见
6. 居委会/妇联介入记录                 —— 证明社区已介入

                                        申请人：张三
                                        20XX 年 X 月 X 日
```

写请求事项时的三个提醒：
- 能写具体就别写笼统（"禁止在 XX 地址对申请人实施殴打"比"禁止暴力"更好）；
- 要**迁出住所**的，得说明你目前住哪里、对方还会回来；
- 涉及共同未成年子女的，可一并说明需要保护的部分。

## 五、提交之后

| 环节 | 会发生什么 | 你能做什么 |
|---|---|---|
| 立案审查 | 法院接收材料后审查 | 留好提交回执/网上立案截图 |
| 作出裁定 | 符合条件即作出 | 关注送达，及时签收 |
| 送达对方 | 法院将裁定送达被申请人 | 留意对方是否出现新的骚扰 |
| 执行 | **可由公安机关协助执行** | 再被打/被骚扰时，出示裁定并报警 |
| 违反裁定 | 可请求**拘留、罚款**；构成犯罪的**追究刑事责任** | 保存违反的证据（新报警记录、新照片） |

## 六、拿到裁定还不够：同时做这几件事

1. **把裁定书复印件给家人、单位、物业、居委会**——让周围人知道真实情况，
   也便于出事时有人帮。
2. **报一次备案性质的警**——裁定生效后若再发生任何接触或暴力，**立刻报警**，
   并出示裁定，这次的报警记录就是"违反裁定"的证据。
3. **别撤诉式地彻底沉默**——如果对方在回访、短信骚扰，保留记录，
   这些可以作为后续变更、执行程序的材料。
4. **民事赔偿另算**——保护令止暴不等同于赔钱；受伤造成的医疗费、误工费等损失，
   另行通过离婚诉讼或人身损害赔偿程序主张。

## 七、和其他路径的关系

| 路径 | 与保护令的关系 |
|---|---|
| 报警 | 保护令**不以报警为前置**；但已报警的材料能大幅提升成功率 |
| 离婚诉讼 | 保护令**不需要先离婚**；离婚诉讼中可以同时主张损害赔偿 |
| 妇联/社区 | 帮你**代写申请书、出情况说明、陪同去法院**，是前哨不是终局 |
| 伤情鉴定 | 不是必须；但如果达到了法定伤人程度，可做伤情鉴定，为治安/刑事程序与赔偿服务 |
| 法律援助 | 符合条件的可申请，由法律援助机构指派律师代书与代理 |

## 八、时限

| 事项 | 期限 |
|---|---|
| 申请人身安全保护令 | **无严格时效**，面临现实危险即可申请，越早越好 |
| 违反裁定后请求拘留/罚款 | 按《治安管理处罚法》相关规定办理，实务中应尽快并保留新证据 |
| 后续民事损害赔偿诉讼时效 | 一般 3 年，自知道权利受损及义务人之日起算 |
| 裁定有效期 | 以裁定书载明为准，届满可重新申请/延长 |
