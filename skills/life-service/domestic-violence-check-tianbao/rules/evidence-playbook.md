# 证据清单与取证流程

## 一、核心三件套（缺一就弱一截）

| 件 | 是什么 | 为什么关键 |
|---|---|---|
| **1. 报警笔录 + 回执** | 公安机关形成的询问笔录、接处警记录、报警回执/接警编号 | 公权力机关当场制作，证明力最高；证明"发生过、什么时候、什么性质" |
| **2. 伤情照片 + 就医病历** | 带时间地点水印的多角度照片，病历/诊断证明/检查报告 | 证明"受了伤、伤成什么样、什么成因" |
| **3. 对方的威胁/暴力固定记录** | 录音录像、微信短信、被砸物品、证人 | 证明"是他做的、他承认/惯犯" |

**这三者互相补强**：只有照片没报警 → 难以证明是谁打的；
只有笔录没照片 → 难以证明伤情程度；有照片、有记录但没报警 → 仍缺一个权威时间锚点。

## 二、逐项取证动作（按紧急度排序）

| 顺序 | 动作 | 关键细节 | 紧急度 |
|---|---|---|---|
| 1 | **拍伤情照片** | 伤口特写 + 全身 + 环境；开原生相机水印与位置信息；**留原图** | 最急（伤会愈合） |
| 2 | **拨打 110 + 要回执 + 要笔录** | 到场主动说"我需要做笔录"；签字前核对 | 最急 |
| 3 | **去正规医院就诊并说明成因** | 说清"被谁、用什么方式打伤"；病历里的致伤原因表述极关键 | 最急 |
| 4 | **固定手机里的文字威胁** | **别删**；截图 + 录屏（带完整界面与时间）+ 导出原始记录 | 高（随时可能被删） |
| 5 | **录音录像** | 先开录音再对话；保留原始文件；场景音里带身份信息 | 高（覆盖可能被覆盖） |
| 6 | **物证拍照** | 被砸的家具、撕坏的衣服、碎掉的杯子，原地拍、标时间地点，别急着清理 | 中高 |
| 7 | **找证人** | 邻居、物业、亲友；记姓名电话，必要时书面证言 | 中 |
| 8 | **社区/妇联介入** | 到居委会反映并要求**记入台账**；妇联出情况说明 | 中 |
| 9 | 心理/精神科就诊 | 证明精神损害 | 低但有用 |

## 三、八类证据的具体清单

| 类别 | 具体材料 | 证明什么 |
|---|---|---|
| **报警类** | 报警回执、接警编号、受案回执、**询问笔录**、接处警登记表 | 事发时间地点经过、公权力机关已介入 |
| **伤情类** | 伤情照片、门诊/急诊病历、诊断证明、验伤单、法医鉴定意见 | 受伤程度与成因 |
| **影像类** | 争吵录音、监控录像、自拍视频 | 对方自认、暴力过程 |
| **文字类** | 微信威胁/辱骂、短信、邮件、社交平台发帖 | 经常性侮辱恐吓、威胁内容 |
| **物证类** | 损坏的家具家电、被撕坏的衣物、打碎的器具 | 暴力发生的现场痕迹 |
| **人证类** | 邻居、物业、亲友、同事的证言 | 亲眼所见（私密空间里往往只有他们） |
| **记录类** | 妇联介入记录、社区调解记录、社工记录、心理咨询/精神科记录 | 反复发生、持续性、精神损害 |
| **法律类** | 人身安全保护令申请书与受理回执、裁定书、送达回证；离婚起诉状 | 已有法律程序的进展 |

## 四、整理证据册的做法（法院喜欢看的样子）

1. 做一份**证据清单表**，列四列：`序号 | 证据名称 | 来源/持有人 | 页码`，
   另附一列"证明目的"（这一份证明什么事实）。
2. 每份材料**复印件 + 原件照片**各一套，装订成册，加封面写明当事人与案由。
3. **按时间顺序**排：最早的一次在最前，能看出"经常性"这个特征。
4. 时间线做一张表：日期 / 地点 / 什么行为 / 有没有报警 / 有没有就医 / 证人。
5. 照片打印出来，背面**手写**注明：拍摄时间、地点、拍的是什么。
6. 录音录像要**刻盘或存原始手机**，并附文字整理稿（把威胁原话抄下来）。

**别做这几件事**：
- 别删任何原始记录（删了就再也补不回来）；
- 别剪辑录音（剪辑过的证明力大打折扣）；
- 别伪造、拼凑（一旦被查出，整份材料的诚信度崩塌，风险远大于收益）；
- 别在取证过程中与对方发生新的正面冲突（安全第一）。

## 五、取证时的安全纪律

- **先安全后取证**——冲突正当时不要举着手机对拍、不要正面硬刚，先脱离。
- 录音录像也要在**不激化**的前提下进行；对方若情绪失控，优先离开。
- 带孩子/老人的，先把他们带到安全处，再处理自己的取证。
- 任何情况下**不要以暴制暴**，这不仅会让你陷入被动，还可能触发反过来的责任。

## 六、证据缺了怎么办

| 缺的是 | 补法 |
|---|---|
| 没报警 | **现在就去报警**，之前的事也能报，警方的接处警记录仍然有效 |
| 没照片（伤口已愈合） | 回原就诊科室补一份伤情说明；找当时目击的人；调取事发地监控 |
| 没有录音 | 用报警笔录 + 病历 + 证人证言组合替代 |
| 没有文字记录 | 报警记录 + 社区调解记录 + 妇联记录可以替代，证明力稍弱但能成立 |
| 只有一次、没有"经常性" | 补时间线：往前翻找历次报警、就医、聊天记录，把"反复发生"串起来 |
| 什么都没有 | 立刻做三件事：报警（拿回执）、就医（拿病历）、拍现状照；同时找妇联 12338 出记录 |
