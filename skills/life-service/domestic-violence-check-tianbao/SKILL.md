# 家庭暴力取证与人身安全保护令核查

最难受的不是那一巴掌，是**没人告诉你这算不算"事"**、**该找谁**、**报警有没有用**——很多人卡在"我们不是夫妻""只是家务事""没打到见血就不算"这三句话上，一步没走出去。

## 什么时候用

- 被推搡、扇耳光、掐脖子、拽头发、踢打，想固定证据但不知道从哪开始
- 没打到伤，但长期辱骂、威胁、恐吓、贬低人格、当众羞辱
- 被限制出门、没收手机、查岗、跟踪尾随、不许和某个人往来
- 被切断经济来源、掌握工资卡、巨额负债强加自己
- 已经报过警但没做笔录、没拿回执，现在想重新来一遍
- 想申请人身安全保护令，但不知道去哪个法院、要什么材料、能要求什么
- 关系已经结束了（分手/离婚），想把过去的事实变成证据

## 怎么做

**第 1 步**：复制 `templates/家庭暴力信息采集表.md` 填写——**先填"是否与对方仍在同一现场"，这是安全第一项**。

**第 2 步**：跑脚本

```bash
python scripts/domestic_violence_check.py 采集表.md --base 2026-10-05 --out 核查报告.md
```

**第 3 步**：按第十一段"待办补正动作"执行——顺序是**先脱离现场、再报警、再就医、最后补其他证据**。

> **安全优先**：如果按你填的内容看暴力可能还在进行，**先离开现场或拨打 110，别为了留证据继续待在危险环境里**。证据可以事后补，人受伤补不回来。

## 三句话定性的核心规则

1. **家暴不只是"打人"**：殴打、捆绑、残害、限制人身自由，以及**经常性的侮辱、恐吓**，都在定义内。精神暴力、控制跟踪、经济控制同样算，**不需要打到见血**。
2. **适用范围比很多人以为的宽**：夫妻、共同生活的亲属当然在；**同居、前男女友等共同生活关系同样可走保护令路径**（是否受理以受理法院口径为准），而**报警、就医、妇联求助这三条路不受关系限制**。关系早已结束，过去的暴力事实照样能主张。
3. **顺序是"先制止、再留痕、最后追责"**：一上来就谈赔偿赔不到；报警记录是后面所有路径的底座。人身安全保护令**由人民法院作出**，可请求禁止暴力、禁止骚扰跟踪接触、责令迁出住所，作出后**可由公安机关协助执行**，对方违反的可请求拘留、罚款。

## 输入 / 输出

| | 内容 |
|---|---|
| 输入 | 采集表 Markdown（关系 / 最近一次时间 / 事情经过 / 是否脱离现场 / 报警与笔录 / 伤情照片与就医 / 录音录像与聊天 / 证人 / 已有证据 / 保护令进展 / 离婚打算） |
| 输出 | 十一段报告：结论摘要 / 形态与适用范围定性 / 安全优先级 / 证据清单与缺口 / 报警与就医要点 / 保护令申请路径与材料 / 其他求助渠道 / 时限倒计时 / 离婚与赔偿 / 申请路径排序 / 证据缺口速查 / 待办补正动作（另附边界与纪律） |
| 退出码 | 0 正常；2 关键信息缺失（给提示串，不崩） |

## 边界与纪律

- 依**通用规则**整理，**不替代律师意见**；保护令的**受理条件、管辖法院、可请求事项、有效期与执行方式一律以受理法院与当地现行规定为准**
- 不预测法院是否会签发保护令，也不预测离婚与损害赔偿的结果
- **未填的一律不算通过**，只按已填内容判断
- 采集表涉及的高度私人信息，本地处理，不要外发
