# 家庭暴力取证与人身安全保护令核查

被打、被骂、被威胁、被控制住走不掉的时候，最缺的不是勇气，是**一份能看懂的下一步**。

这个技能不劝和、不评判，只做三件事：**定性**（这算不算、你能不能主张）、**排顺序**（先做什么后做什么）、**找缺口**（还差哪几样证据）。

## 它管什么

| 常被问 | 它给的结论 |
|---|---|
| "他只是骂我，这算家暴吗" | 经常性的侮辱、恐吓、威胁属精神暴力，在定义内 |
| "我们已经分手了，还能申请吗" | 同居/前伴侣等共同生活关系同样可走保护令；报警、就医、妇联不受关系限制 |
| "没打到见血，要不要报警" | 不需要见血；报警>笔录>回执是证据链起点 |
| "保护令去哪申请、要什么" | 人民法院，可请求禁止暴力/禁止接触/责令迁出，可在立案窗口或网上提交 |
| "过了两年还能不能要说法" | 给时效倒计时（一般民事诉讼时效 3 年） |

## 它不管什么

- 不替代律师意见，不预测法院会不会签发保护令
- 不处理刑事故意伤害的侦查结果与量刑
- 保护令的管辖、材料清单、有效期以受理法院与当地现行规定为准

## 怎么用

1. 填 `templates/家庭暴力信息采集表.md`（**第一项永远是"现在还安全吗"**）
2. 跑 `scripts/domestic_violence_check.py`，输出十一段核查报告
3. 照第十一段待办补正动作执行：脱离现场 → 报警要回执 → 就医留痕 → 补其他证据 → 申请保护令

> 安全优先。证据可以事后补，人受伤补不回来。
