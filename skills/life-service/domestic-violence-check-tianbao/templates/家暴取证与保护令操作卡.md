# 家暴取证与保护令操作卡

## 一、第一步永远是安全（顺序不能反）

| 优先级 | 动作 | 说明 |
|---|---|---|
| 1 | **离开现场** | 去公共场所（商场、便利店、派出所）、亲友家、单位宿舍。不要留在冲突环境里硬扛 |
| 2 | **拨打 110** | 说清三件事：我在哪、我被谁打了、现在是否安全。请求出警 |
| 3 | **去公共场所或亲友家暂住** | 换环境本身能降低再次发生的概率，也便于冷静后取证 |
| 4 | **告诉可信任的人** | 亲友、同事、邻居、物业。有人知道你的处境，出事才有人帮得上 |
| 5 | **再处理证据** | 证据可以事后补，人受伤补不回来 |

> 别硬扛、也别以暴制暴。保持冷静、先保人再保证。

## 二、报警环节：三样东西必须拿到

1. **报警回执 / 接警编号**——现场会给单据；没给就回拨报办（或到派出所查询）要编号。
2. **询问笔录**——**这是最有力的证据**。到场后主动说："我需要做笔录。"
   笔录会记载时间、地点、经过、伤情。**签字前先核对内容，与事实不符要求更正或补充陈述**。
3. **伤情初步意见**——情节需要时，可请公安机关出具或指引去做伤情鉴定。

报警时说这些话更有效：

> 我在 XX 地址，被我配偶（或同居的 XX）打伤了，现在需要报警出警，请派民警来做笔录，
> 我需要报警回执和接警编号。

## 三、就医环节：最关键的一句是"致伤原因"

- 去**正规医院急诊或外科**，带上身份证。
- 向医生**如实说明致伤成因**（例如"被丈夫打伤""被人推倒磕到桌角"），
  **医院记录里的致伤原因表述非常关键**——医生怎么写，直接决定这份材料的证明力。
- 留存：门诊/急诊病历、诊断证明、检查报告、费用发票、挂号记录。
- 没有明显外伤也要就诊留痕；"没伤"不等于不能认定家暴。

## 四、伤情照片：怎么拍才有用

| 要拍什么 | 要求 |
|---|---|
| 伤口特写 | 近景、清晰、能看出伤情部位与程度 |
| 全身照 | 远景，照出人整体状态 |
| 环境照 | 所在房间、家具摆放、翻倒的物品 |
| 与参照物合影 | 手里拿一张当天的报纸/手机（证明拍摄时间） |
| 原图务必保留 | **不要只发微信后删原图**；开启手机"位置信息"保存 |
| 时间地点水印 | 用原生相机自带的水印功能，别用后期加的 |

## 五、其他证据

| 类型 | 具体怎么留 |
|---|---|
| 录音录像 | 争吵时先开录音再对话，内容含对方自报身份与威胁语句最有用。**留手机原始文件** |
| 微信/短信 | 威胁、辱骂、**别删**。截图 + 录屏保全（录屏有完整界面与时间），再导出原始记录 |
| 物证 | 被砸坏的家具、撕碎的衣服、打碎的杯子 —— 原地拍照，注明时间地点，别急着扔 |
| 证人 | 邻居、物业、亲友。记下姓名电话，请其出具书面证言；答复时别引导他们 |
| 妇联/社区 | 到居委会反映并**要求记入台账**；妇联（12338）可协助代写材料、出情况说明 |
| 心理记录 | 心理咨询、精神科就诊记录可证明精神损害 |

## 六、人身安全保护令怎么办

**谁作出**：**人民法院**。

**三条申请路径**：
1. 申请人**自己**向法院直接申请；
2. 部分地方可向**居住地**或**家庭暴力发生地**的**基层人民法院**申请（以受理法院口径为准）；
3. **居委会/村委会、妇联、学校、幼儿园、医疗机构等可以代为申请**。

**可请求的事项**（常见）：
- 禁止实施家庭暴力；
- 禁止骚扰、跟踪、接触；
- 责令迁出住所；
- 其他合理必要的保护措施。

**材料清单**：
- 人身安全保护令申请书（写明请求事项、事实与理由）；
- 申请人身份证明；
- 能够证明双方关系的材料（结婚证、户口本、居住证明、共同生活证据等）；
- 证据清单及证据复印件（报警回执、笔录、病历、照片、录音、聊天记录、证人证言等）；
- 具体的请求与所依据的事实理由。

**拿到裁定之后**：
- 裁定由**人民法院作出**，**可由公安机关协助执行**；
- 对方违反裁定，可就其行为请求**拘留、罚款**，构成犯罪的**依法追究刑事责任**；
- 有效期**以裁定书载明为准**（实践中常见为数个月），到期需要延续的及时重新申请；
- 保管好裁定书原件与送达回证。

## 七、其他求助入口速查

| 你遇到的是 | 找谁 |
|---|---|
| 不知道怎么办、想要人帮 | **妇联 12338**（维权热线，咨询+调解+转介） |
| 需要人出面、要记录 | 居委会/村委会/社区综治窗口，要求记入台账 |
| 家里暂时住不了 | 问当地**民政部门**是否有反家暴庇护中心（或打 12345 转接） |
| 打不起官司 | **法律援助机构**（符合条件的可申请，资助与否由当地法律援助机构认定） |
| 正在被打、情况紧急 | **110** |
| 离婚与赔偿 | 律师/法律援助；在离婚协议或诉讼中一并主张损害赔偿 |

## 八、五条别踩的坑

1. **别删威胁记录**——微信、短信里那些气话恰恰是最直接的证据。
2. **别为了留证据而留在危险里**——先安全，再取证。
3. **别信"两口子吵架别人别管"**——家庭暴力不是家务事，报警、求助都不丢人，也有明确规定支持。
4. **别以为没打伤就没证据**——精神暴力、经常性侮辱恐吓、控制与限制人身自由同样属于家庭暴力。
5. **别拿"没同居就不算家暴"劝退自己**——同居、前男女友等共同生活关系同样适用；
   就算已经分开，之前的暴力事实依然可以主张。
