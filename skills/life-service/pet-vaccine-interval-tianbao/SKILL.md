# 宠物疫苗接种间隔与反应观察（pet-vaccine-interval）

疫苗这件事，**最常见的两个问题都出在"记录"上**：一是靠记忆记不清上次什么时候打的，二是漏打之后不知道怎么处理、干脆就当没这回事。**接种记录不是记给自己看的，是漏打时唯一能算清楚间隔的依据**。

这个技能做三件事：**分核心 → 排程序 → 盯反应**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出核心与非核心疫苗的区分口径 | ❌ 提供具体疫苗名称、品牌与毒株 |
| 给出接种程序表的核查与记录方法 | ❌ 给出具体针数与间隔天数作为自家方案 |
| 给出接种后反应观察项与时限 | ❌ 判断反应是过敏还是正常免疫反应 |
| 给出免疫失败迹象与复诊口径 | ❌ 判断免疫是否已建立 |
| 给出漏打与既往接种记录的处理流程 | ❌ 推荐具体疫苗产品 |

**本技能的核心限制：疫苗的品种、程序、针数、间隔与接种时间由执业兽医根据宠物的年龄、既往接种史、健康状况与当地流行情况确定。** 本技能只提供**区分口径、程序核查方法、记录要求与反应观察口径**。

**就医红线（出现任一条，尽快联系兽医；标注急诊的直接去急诊）**

- **接种后出现呼吸困难、面部或咽喉肿胀、呕吐、站立不稳、倒地** —— 提示急性过敏反应，**立即急诊**
- **接种后持续高热超过 24 小时不退，或体温明显偏低**
- **接种后精神沉郁、不吃不喝超过 24 小时**（幼宠尤其危险）
- **接种部位出现大面积红肿、脓性分泌物、皮肤破溃或坏死**
- **接种部位肿块持续增大、质地变硬、超过数周不消退**
- **接种后出现抽搐、意识障碍**
- **幼宠接种后出现低血糖表现**（幼犬幼猫风险较高，需密切观察）
- **接种后出现持续呕吐、腹泻**
- **已按程序接种但仍发病** —— 提示可能是免疫失败或疾病本身特点，**须由兽医评估**
- **免疫功能异常、免疫抑制、正在使用免疫抑制药物、患有自身免疫病或肿瘤**
- **妊娠期母宠**
- **接种前宠物处于病中、发热、腹泻或正在使用其他药物**

**绝对禁止**：

- **不在宠物生病期间接种**，也不在病愈后立即接种，须由兽医判断时机。
- **不跳过规定的针次图省事**，也不自行延长或缩短间隔。
- **不在不同疫苗之间自行切换或混用**，须由兽医确认兼容性。
- **不在接种前刚洗完澡就接种**（部分情况下不建议同日进行）。
- **不为了"看着精神好"就推迟必要的加强免疫**。

## 二、完整工作流

```
第 1 步  拿记录：找出既往接种记录（纸质本、芯片档案、机构记录）
第 2 步  分核心与非核心：先确认哪些是必要的
第 3 步  排程序：按记录算出已完成针数与下一针时点
第 4 步  排与驱虫的间隔：错开日期，便于区分不良反应来源
第 5 步  确认方案：品种、针数、间隔由兽医确定并写入记录
第 6 步  接种当天与之后 24-72 小时：按观察项逐项记录
第 7 步  异常处置：命中红线即就医，不自行处理
第 8 步  漏打处理：按记录推算并由兽医确认重启方案
```

**顺序不能颠倒**：没有记录就排程序，是漏打后最麻烦的处境。

## 三、核心与非核心疫苗的区分

**这是本技能最核心的一张表——不分清，就会被推销一堆不必要的针。**

| 类别 | 含义 | 判断口径 | 常见内容举例 |
|---|---|---|---|
| **核心疫苗** | 几乎所有宠物都应接种 | 依据是**该病一旦发生后果严重、且本地流行** | 犬：狂犬病、犬瘟热、犬细小病毒、犬腺病毒等；猫：狂犬病、猫泛白细胞减少症（猫瘟）、猫疱疹病毒、猫杯状病毒等 |
| **非核心疫苗** | 取决于个体暴露风险 | 依据是**这只宠物是否会接触到该病原** | 犬：钩端螺旋体病、莱姆病、犬副流感等；猫：猫白血病病毒（主要针对有外出风险的猫） |
| **不推荐/已停用** | 效果有限或不推荐常规使用 | 依据是**保护价值不足或有替代方案** | 部分覆盖不全的疫苗、不推荐常规使用的减毒活疫苗等 |

**非核心疫苗的判断逻辑**：**这只宠物是否会接触到该病原**。从来不外出的室内犬、从不接触其他猫的室内猫，很多非核心疫苗**不需要**。反过来，接触野生动物、经常去户外、有接触其他动物历史的，风险明显更高。

**三个必须问清楚的问题**：

1. 这一针是核心还是非核心？**依据是什么？**
2. **如果是非核心，依据我这只宠物的哪些情况？**
3. 如果我暂不打，会带来什么风险？

**问不清楚这三问，就容易被动接受不必要的针。**

## 四、接种程序核查

**具体针数与间隔由执业兽医确定。本节只给核查方法，不给自家方案。**

### 4.1 记录必须包含的字段

| 字段 | 说明 | 为什么必须有 |
|---|---|---|
| 接种日期 | 精确到日 | 算间隔的唯一依据 |
| 疫苗名称或类别 | 至少记清类别与是第几针 | 不同类别程序不同 |
| 针次序号 | 首免第几针、第几次加强 | 判断程序完成度 |
| 接种机构 | 便于后续查询与补种 | 机构通常保留记录 |
| 不良反应记录 | 有无发热、精神差、局部肿块 | 后续接种的参考 |
| 批次或有效期 | 部分记录会有 | 便于追溯 |

### 4.2 排查顺序

```
第 1 步  拿出全部既往接种记录（纸质本、宠物芯片档案、就诊机构记录）
第 2 步  按日期排序，确认已完成针数与末次日期
第 3 步  核对哪些是核心、哪些是非核心
第 4 步  末次日期距今多久，是否已到加强时点（时点由兽医确定）
第 5 步  若记录缺失或对不上，带宠物到机构查询或做抗体检测评估
第 6 步  由兽医确定后续程序并写入记录
```

### 4.3 幼宠首免的几个原则

| 原则 | 说明 |
|---|---|
| 首免起点 | 由兽医按年龄与母源抗体情况确定 |
| 母源抗体影响 | 母源抗体可能干扰首免效果，**首免起点由兽医判断** |
| 针次间隔 | 由兽医确定；**不自行缩短间隔"提前完成"** |
| 完成前保护有限 | 未完成程序前，**避免接触未接种的同种动物、宠物店、寄养与高密度场所** |
| 幼宠免疫未成熟 | 幼宠在完成程序前属于易感，**外出与社交要控制** |
| 记录每一针 | 每打一针立刻记录，不要事后补记 |

**"完成前保护有限"是最容易被忽略的一条**：很多人在幼宠还没打完全部针次时就去宠物店、去公园，免疫还没建立，风险最高的时候反而在最高暴露环境。

### 4.4 漏打与记录缺失的处理

| 情形 | 处理口径 |
|---|---|
| 漏了一针，但有记录 | 带记录就诊，由兽医计算补种时点 |
| 记录不清或完全没有记录 | 带宠物到机构查询；部分机构可做抗体检测评估 |
| 超过加强时点较久 | **不要直接"从现在开始按新程序打"**，须由兽医判断是否需要重启程序 |
| 幼宠未完成程序且已超期 | **须由兽医确定方案**，不自行决定 |
| 不确定是否打过 | 视为记录缺失处理，交由兽医判断 |

**关键原则**：漏打后**不要自行"重新开始一套"**。是否需要重启程序、重启几针、间隔多久，**必须由兽医判断**，因为不同疫苗、不同年龄段的处理方式不同。

## 五、与驱虫的间隔

| 口径 | 说明 |
|---|---|
| 是否需要分开 | **由兽医确认**，不同方案与个体情况不同 |
| 常见做法 | **错开日期**，而不是同日进行 |
| 同日进行的实际风险 | 出现不良反应时**难以区分是疫苗还是驱虫引起** |
| 观察重点 | 每次后观察 24-72 小时 |
| 记录要求 | **两次都记日期**，便于对齐与复盘 |
| 幼宠 | 首免与首次驱虫的时间顺序**由兽医安排** |

**错开的价值在于排查**：不是"同日做就不安全"这种笼统说法，而是**出了问题能查出来源**。

## 六、接种后反应观察

### 6.1 观察时限与项目

| 时段 | 观察什么 | 什么算异常 |
|---|---|---|
| 接种当天 | 精神、食欲、呕吐、排便、体温、注射部位 | 呼吸困难、面部肿胀、抽搐、站立不稳 |
| 接种后 24 小时 | 精神、进食、体温、注射部位 | 持续高热、精神沉郁、不吃不喝 |
| 接种后 24-48 小时 | 同上，加观察肿胀范围变化 | 肿胀扩大、脓性分泌物、皮肤破溃 |
| 接种后 72 小时 | 局部硬结是否开始消退 | 肿块持续增大、质地变硬 |
| 接种后数周 | 局部肿块是否消退 | 超过数周不消退 |

**记录方式**：每次接种后**逐项记录**（时间、症状、是否用药、处理），而不是"好像有点蔫"这种模糊记忆。**不良反应复诊时，这份记录是医生判断的核心依据。**

### 6.2 反应的性质区分（不自行判断）

| 表现 | 可能属于 | 口径 |
|---|---|---|
| 接种当天精神略差、食欲下降 | 常见轻度反应 | 记录并观察；若持续加重按红线就医 |
| 接种部位轻微红肿、硬结 | 常见局部反应 | 记录范围变化；**不自行按摩、不自行涂抹** |
| 发热 | 可能属免疫反应 | **是否异常由兽医判断**；持续不退按红线 |
| 呕吐、腹泻 | 需要重视 | 持续超过 24 小时按红线 |
| 呼吸困难、面部肿胀、抽搐、倒地 | **急性过敏反应** | **立即急诊** |
| 大面积红肿、脓性分泌物、皮肤坏死 | 感染或组织损伤 | 尽快就医 |

**关键原则**：**轻度反应与过敏反应的区别由兽医判断，不要自己下结论**。同样表现，在不同个体上性质可能完全不同。判断错了要么延误急救，要么把正常反应当事故。

**部位处理的红线**：**不自行按摩、不自行涂抹任何药膏、不自行热敷或冰敷**。这些处置可能改变局部表现，反而影响医生判断。

### 6.3 与免疫失败的区分

| 情况 | 说明 | 处置 |
|---|---|---|
| 接种后仍发病 | **不等于疫苗没用** | 需兽医评估：可能是疾病本身特点、暴露量过大、免疫未建立、或该疫苗的保护范围 |
| 免疫未建立 | 程序未完成、间隔过短、母源抗体干扰 | 由兽医评估是否需重启程序 |
| 母源抗体干扰 | 幼宠首免时可能影响效果 | 由兽医评估处理方式 |
| 免疫抑制个体 | 用药、疾病、年龄因素 | 须兽医评估方案 |
| 保护范围有限 | 疫苗针对特定病原，**不是万能的** | 防护仍靠卫生与隔离 |

**要说清的一句话**：**疫苗不是保险，是降低特定疾病的重症与死亡风险**。接种后仍可能感染或发病，原因多样，需要兽医评估，**不能简单归为"疫苗没用"**。

## 七、特殊情况

| 情况 | 口径 |
|---|---|
| 妊娠期母宠 | **须兽医评估**，不自行安排接种 |
| 正在使用免疫抑制药物 | 须兽医评估 |
| 免疫缺陷、自身免疫病、肿瘤治疗中 | 须兽医评估 |
| 幼宠接种后精神差 | **幼宠风险较高，需密切观察；幼犬幼猫注意低血糖表现** |
| 老年宠 | **是否继续加强、是否调整程序由兽医评估**，不自行停 |
| 既往有严重不良反应史 | **必须主动告知医生**，影响后续方案 |
| 多宠家庭 | **每只分别记录**，不共用一份记录 |
| 短期内多次接种 | 需确认间隔是否合理，由兽医判断 |
| 接种前刚洗澡 | 部分情况下不建议同日进行 |
| 宠物正在生病、发热、腹泻 | **不接种**；病愈后时机由兽医判断 |

## 八、脚本用法

```
python scripts/vaccine_gap.py --file record.json
python scripts/vaccine_gap.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`species`、`age_months`、`records`（既往接种记录数组，含 `date`、`category`、`seq`）、`core_done`、`noncore_risk`（非核心暴露风险）、`last_deworm`、`last_vaccine`、`red_flags`、`reactions` |
| `--json` | 以 JSON 输出 |
| `--out` | 结果写入指定文件，默认 `scripts/_last_result.txt` |
| `--selftest` | 运行自检 |

脚本做四件事：**按记录排序并算已完成的针数与距末次天数 → 区分核心与非核心并标出需问清的三个问题 → 核对与驱虫的间隔是否同日 → 排反应观察时限与就医红线**。脚本**不给疫苗名称、品牌、针数与间隔天数作为自家方案**。

## 九、人工确认清单（这步不能省）

- [ ] 已拿出全部既往接种记录（纸质本、芯片档案、机构记录）
- [ ] 记录包含日期、类别、针次序号、机构、不良反应
- [ ] 已核对哪些是核心、哪些是非核心
- [ ] 非核心疫苗已问清"依据我这只宠物的哪些情况"
- [ ] **具体针数与间隔由兽医确定并写入记录**
- [ ] 未完成程序前**避免接触未接种同种动物、宠物店、寄养与高密度场所**
- [ ] 与驱虫是否分开已向兽医确认，非同日安排已留出观察窗口
- [ ] 接种后 24 小时、48 小时、72 小时已逐项记录
- [ ] 局部反应**未自行按摩、未涂抹、未热敷或冰敷**
- [ ] 出现急性过敏反应信号立即急诊，未自行判断为"正常反应"
- [ ] 既往严重不良反应史已主动告知医生
- [ ] 漏打情形**未自行重新开始一套**，已交由兽医判断
- [ ] 妊娠、免疫抑制、基础疾病情况已如实告知
- [ ] 多宠家庭每只分别记录
- [ ] 疫苗品种与程序以执业兽医确定为准

## 十、最常见的坑

**坑一：靠记忆记接种时间。**
错误做法：记不清上次什么时候打的，凭印象算。正确做法：**接种记录不是记给自己看的，是漏打时唯一能算清楚间隔的依据**。每打一针立刻记，不要事后补记。

**坑二：分不清核心与非核心，被推销一堆针。**
错误做法：接种时机构说什么打什么。正确做法：**核心依据是后果严重与本地流行；非核心依据是这只宠物是否会接触到该病原**。从来不外出的室内犬、从不接触其他猫的室内猫，很多非核心疫苗不需要。**问不清楚"依据我这只宠物的哪些情况"，就容易被动接受不必要的针。**

**坑三：为了"提前完成"而缩短间隔。**
错误做法：想早点打完全部针次，把间隔缩短。正确做法：**针次间隔由兽医确定**。间隔过短会影响免疫效果，缩短间隔不等于提前获得保护。

**坑四：程序没打完就带去宠物店、公园、寄养。**
错误做法：幼宠才打了两针，觉得差不多了就带出门社交。正确做法：**未完成程序前保护有限**，避免接触未接种的同种动物、宠物店、寄养与高密度场所。**免疫还没建立的时候反而在高暴露环境，是风险最高的组合。**

**坑五：疫苗和驱虫约在同一天。**
错误做法：为了省事约同一天。正确做法：**错开日期**。实际价值不在于某种"安全间隔"，而在于**出现不良反应时能判断来源**。同日进行，出了问题根本分不清是疫苗还是驱虫引起的。

**坑六：接种后打疫苗部位一有硬结就按摩。**
错误做法：摸到硬结就揉开。正确做法：**不自行按摩、不自行涂抹任何药膏、不自行热敷或冰敷**。这些处置可能改变局部表现，反而影响医生判断。记录范围变化，按时限观察。

**坑七：接种后精神差就自己判断"是正常反应"。**
错误做法：宠物蔫了一天，认为正常。正确做法：**轻度反应与过敏反应的区别由兽医判断，不要自己下结论**。出现呼吸困难、面部肿胀、抽搐、站立不稳——**立即急诊**，不要观察等待。

**坑八：漏打了就自己"重新开始一套"。**
错误做法：漏了一针，干脆从头打起。正确做法：**是否需要重启程序、重启几针、间隔多久，必须由兽医判断**。不同疫苗、不同年龄段的处理方式不同。

**坑九：打了疫苗就认为万事大吉。**
错误做法：接种后就完全放松防护。正确做法：**疫苗不是保险，是降低特定疾病的重症与死亡风险**。已按程序接种仍发病，原因多样需兽医评估，**不能简单归为"疫苗没用"**。卫生与隔离防护仍要继续。

## 十一、边界与免责

- **疫苗的品种、程序、针数、间隔与接种时间由执业兽医根据年龄、既往接种史、健康状况与当地流行情况确定。** 本技能只提供区分口径、程序核查方法、记录要求与反应观察口径
- **不提供具体疫苗名称、品牌、毒株，也不给出自家适用的针数与间隔天数**
- **不判断反应是过敏还是正常免疫反应**；是否异常由兽医判断
- **不判断免疫是否已建立**；抗体水平评估须通过检测并由兽医解读
- 妊娠期、免疫抑制、自身免疫病、肿瘤治疗中、正在使用免疫抑制药物的个体，**方案须兽医评估**
- 宠物生病、发热、腹泻期间不接种；病愈后时机由兽医判断
- **不建议在未完成免疫程序前接触未接种同种动物、宠物店、寄养与高密度场所**
- 已按程序接种仍发病的情况，须由兽医评估，不作"疫苗无效"的结论
