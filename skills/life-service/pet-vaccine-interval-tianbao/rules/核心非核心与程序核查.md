# 核心非核心区分与程序核查

> 疫苗的品种、程序、针数、间隔与接种时间由执业兽医确定。本文件只提供区分口径、核查方法、记录要求与反应观察口径。

## 一、核心与非核心疫苗的区分

| 类别 | 含义 | 判断口径 | 常见内容举例 |
|---|---|---|---|
| 核心疫苗 | 几乎所有宠物都应接种 | 该病一旦发生后果严重，且本地流行 | 犬：狂犬病、犬瘟热、犬细小病毒、犬腺病毒等；猫：狂犬病、猫泛白细胞减少症（猫瘟）、猫疱疹病毒、猫杯状病毒等 |
| 非核心疫苗 | 取决于个体暴露风险 | 这只宠物是否会接触到该病原 | 犬：钩端螺旋体病、莱姆病、犬副流感等；猫：猫白血病病毒（主要针对有外出风险的猫） |
| 不推荐或已停用 | 效果有限或不推荐常规使用 | 保护价值不足或有替代方案 | 部分覆盖不全的疫苗、不推荐常规使用的减毒活疫苗等 |

**非核心疫苗的判断逻辑**：这只宠物是否会接触到该病原。从来不外出的室内犬、从不接触其他猫的室内猫，很多非核心疫苗不需要。接触野生动物、经常去户外、有接触其他动物历史的，风险明显更高。

## 二、三个必须问清楚的问题

1. 这一针是核心还是非核心？**依据是什么？**
2. **如果是非核心，依据我这只宠物的哪些情况？**
3. 如果我暂不打，会带来什么风险？

**问不清楚这三问，就容易被动接受不必要的针。**

## 三、接种记录必须包含的字段

| 字段 | 说明 | 为什么必须有 |
|---|---|---|
| 接种日期 | 精确到日 | 算间隔的唯一依据 |
| 疫苗名称或类别 | 至少记清类别与是第几针 | 不同类别程序不同 |
| 针次序号 | 首免第几针、第几次加强 | 判断程序完成度 |
| 接种机构 | 便于后续查询与补种 | 机构通常保留记录 |
| 不良反应记录 | 有无发热、精神差、局部肿块 | 后续接种的参考 |
| 批次或有效期 | 部分记录会有 | 便于追溯 |

## 四、程序排查顺序

```
第 1 步  拿出全部既往接种记录(纸质本、宠物芯片档案、就诊机构记录)
第 2 步  按日期排序, 确认已完成针数与末次日期
第 3 步  核对哪些是核心、哪些是非核心
第 4 步  末次日期距今多久, 是否已到加强时点(时点由兽医确定)
第 5 步  若记录缺失或对不上, 带宠物到机构查询或做抗体检测评估
第 6 步  由兽医确定后续程序并写入记录
```

## 五、幼宠首免的几条原则

| 原则 | 说明 |
|---|---|
| 首免起点 | 由兽医按年龄与母源抗体情况确定 |
| 母源抗体影响 | 母源抗体可能干扰首免效果，首免起点由兽医判断 |
| 针次间隔 | 由兽医确定；不自行缩短间隔提前完成 |
| 完成前保护有限 | 未完成程序前，避免接触未接种的同种动物、宠物店、寄养与高密度场所 |
| 幼宠免疫未成熟 | 幼宠在完成程序前属于易感，外出与社交要控制 |
| 记录每一针 | 每打一针立刻记录，不要事后补记 |

**"完成前保护有限"最容易被忽略**：很多人在幼宠还没打完全部针次时就去宠物店、去公园，免疫还没建立，风险最高的时候反而在最高暴露环境。

## 六、漏打与记录缺失的处理

| 情形 | 处理口径 |
|---|---|
| 漏了一针，但有记录 | 带记录就诊，由兽医计算补种时点 |
| 记录不清或完全没有记录 | 带宠物到机构查询；部分机构可做抗体检测评估 |
| 超过加强时点较久 | 不直接"从现在开始按新程序打"，须由兽医判断是否需要重启程序 |
| 幼宠未完成程序且已超期 | 须由兽医确定方案，不自行决定 |
| 不确定是否打过 | 视为记录缺失处理，交由兽医判断 |

**关键原则**：漏打后不要自行"重新开始一套"。是否需要重启程序、重启几针、间隔多久，**必须由兽医判断**。

## 七、与驱虫的间隔

| 口径 | 说明 |
|---|---|
| 是否需要分开 | 由兽医确认，不同方案与个体情况不同 |
| 常见做法 | 错开日期，而不是同日进行 |
| 同日进行的实际风险 | 出现不良反应时难以区分是疫苗还是驱虫引起 |
| 观察重点 | 每次后观察 24-72 小时 |
| 记录要求 | 两次都记日期，便于对齐与复盘 |
| 幼宠 | 首免与首次驱虫的时间顺序由兽医安排 |

**错开的价值在于排查**：不是"同日做就不安全"，而是出了问题能查出来源。

## 八、接种后反应观察时限

| 时段 | 观察什么 | 什么算异常 |
|---|---|---|
| 接种当天 | 精神、食欲、呕吐、排便、体温、注射部位 | 呼吸困难、面部肿胀、抽搐、站立不稳 |
| 接种后 24 小时 | 精神、进食、体温、注射部位 | 持续高热、精神沉郁、不吃不喝 |
| 接种后 24-48 小时 | 同上，加观察肿胀范围变化 | 肿胀扩大、脓性分泌物、皮肤破溃 |
| 接种后 72 小时 | 局部硬结是否开始消退 | 肿块持续增大、质地变硬 |
| 接种后数周 | 局部肿块是否消退 | 超过数周不消退 |

**记录方式**：逐项记录（时间、症状、是否用药、处理），而不是"好像有点蔫"这种模糊记忆。

## 九、反应性质的区分（不自行判断）

| 表现 | 可能属于 | 口径 |
|---|---|---|
| 接种当天精神略差、食欲下降 | 常见轻度反应 | 记录并观察；若持续加重按红线就医 |
| 接种部位轻微红肿、硬结 | 常见局部反应 | 记录范围变化；不自行按摩、不自行涂抹 |
| 发热 | 可能属免疫反应 | 是否异常由兽医判断；持续不退按红线 |
| 呕吐、腹泻 | 需要重视 | 持续超过 24 小时按红线 |
| 呼吸困难、面部肿胀、抽搐、倒地 | 急性过敏反应 | 立即急诊 |
| 大面积红肿、脓性分泌物、皮肤坏死 | 感染或组织损伤 | 尽快就医 |

**关键原则**：轻度反应与过敏反应的区别由兽医判断，不要自己下结论。判断错了要么延误急救，要么把正常反应当事故。

**部位处理红线**：不自行按摩、不自行涂抹任何药膏、不自行热敷或冰敷。

## 十、与免疫失败的区分

| 情况 | 说明 | 处置 |
|---|---|---|
| 接种后仍发病 | 不等于疫苗没用 | 需兽医评估：可能是疾病本身特点、暴露量过大、免疫未建立、或该疫苗的保护范围 |
| 免疫未建立 | 程序未完成、间隔过短、母源抗体干扰 | 由兽医评估是否需重启程序 |
| 母源抗体干扰 | 幼宠首免时可能影响效果 | 由兽医评估处理方式 |
| 免疫抑制个体 | 用药、疾病、年龄因素 | 须兽医评估方案 |
| 保护范围有限 | 疫苗针对特定病原，不是万能的 | 防护仍靠卫生与隔离 |

**要说清的一句话**：疫苗不是保险，是降低特定疾病的重症与死亡风险。

## 十一、特殊情况

| 情况 | 口径 |
|---|---|
| 妊娠期母宠 | 须兽医评估，不自行安排接种 |
| 正在使用免疫抑制药物 | 须兽医评估 |
| 免疫缺陷、自身免疫病、肿瘤治疗中 | 须兽医评估 |
| 幼宠接种后精神差 | 幼宠风险较高；幼犬幼猫注意低血糖表现 |
| 老年宠 | 是否继续加强、是否调整程序由兽医评估，不自行停 |
| 既往有严重不良反应史 | 必须主动告知医生，影响后续方案 |
| 多宠家庭 | 每只分别记录，不共用一份记录 |
| 短期内多次接种 | 需确认间隔是否合理，由兽医判断 |
| 接种前刚洗澡 | 部分情况下不建议同日进行 |
| 宠物正在生病、发热、腹泻 | 不接种；病愈后时机由兽医判断 |

## 十二、就医红线

| 情况 | 紧急程度 |
|---|---|
| 呼吸困难、面部或咽喉肿胀、呕吐、站立不稳、倒地 | 立即急诊 |
| 接种后抽搐、意识障碍 | 立即急诊 |
| 持续高热超过 24 小时不退，或体温明显偏低 | 尽快联系兽医 |
| 精神沉郁、不吃不喝超过 24 小时 | 尽快联系兽医 |
| 幼宠接种后出现低血糖表现 | 尽快联系兽医 |
| 接种部位大面积红肿、脓性分泌物、皮肤破溃或坏死 | 尽快就医 |
| 接种部位肿块持续增大、质地变硬、超过数周不消退 | 就医评估 |
| 接种后持续呕吐、腹泻 | 尽快就医 |
| 已按程序接种但仍发病 | 须由兽医评估 |
| 免疫功能异常、免疫抑制、正在使用免疫抑制药物 | 须兽医评估方案 |
| 妊娠期母宠 | 须兽医评估方案 |
| 接种前宠物处于病中、发热、腹泻或正在使用其他药物 | 不接种 |

## 十三、绝对禁止

- 不在宠物生病期间接种；病愈后时机由兽医判断
- 不跳过规定的针次图省事；不自行延长或缩短间隔
- 不在不同疫苗之间自行切换或混用
- 不为了"看着精神好"就推迟必要的加强免疫
