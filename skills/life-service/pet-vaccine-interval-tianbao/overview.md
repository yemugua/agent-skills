# 宠物疫苗接种间隔与反应观察

## 你会得到什么

一套**分核心、排程序、盯反应**的疫苗核查口径。疫苗最常见的两个问题都出在记录上——靠记忆记不清上次什么时候打的，漏打之后不知道怎么处理干脆当没这回事。**接种记录是漏打时唯一能算清楚间隔的依据。**

- **核心与非核心疫苗的区分表**：核心依据是「该病一旦发生后果严重且本地流行」，非核心依据是「这只宠物是否会接触到该病原」；含犬猫常见举例。
- **三个必须问清楚的问题**：这一针是核心还是非核心、依据是什么；**如果是非核心，依据我这只宠物的哪些情况**；暂不打会带来什么风险。问不清楚这三问就容易被动接受不必要的针。
- **记录六个必填字段**：接种日期（精确到日）、疫苗名称或类别、针次序号、接种机构、不良反应记录、批次或有效期；每条都写明为什么必须有。
- **程序排查六步**：拿全部记录 → 按日期排序 → 核对核心与非核心 → 看末次日期 → 记录缺失时查询或做抗体检测 → 由兽医确定后续程序。
- **幼宠首免六条原则**：首免起点由兽医按母源抗体情况确定、不自行缩短间隔"提前完成"、**未完成程序前保护有限**（避免接触未接种同种动物、宠物店、寄养与高密度场所）、每打一针立刻记录。
- **漏打与记录缺失的处理**：明确**不要自行"重新开始一套"**，是否重启程序、重启几针、间隔多久必须由兽医判断。
- **与驱虫的间隔**：错开日期的实际价值在于**出现不良反应时能判断来源**，而不是笼统的"安全间隔"。
- **反应观察五个时段**：当天、24 小时、24-48 小时、72 小时、数周，每段写明观察什么与什么算异常。
- **反应性质区分表**：从"接种当天精神略差"到"呼吸困难抽搐倒地是急性过敏反应立即急诊"，并明确**轻度反应与过敏反应的区别由兽医判断，不要自己下结论**。
- **部位处理红线**：**不自行按摩、不涂抹、不热敷或冰敷**——这些处置会改变局部表现，反而影响医生判断。
- **与免疫失败的区分**：说明"疫苗不是保险，是降低特定疾病的重症与死亡风险"，已按程序接种仍发病需兽医评估，不简单归为疫苗没用。
- **特殊情况十一条**与**就医红线十二条**。

## 典型用法

- 幼犬什么时候打第一针、打几针
- 上次打疫苗记不清了，怎么算间隔
- 疫苗和驱虫能不能约同一天
- 打完全程没打完就被推荐非核心疫苗，要不要打
- 接种后发烧、部位有硬结
- 漏了一针怎么办
- 疫苗打了怎么还会生病

## 边界

**疫苗的品种、程序、针数、间隔与接种时间由执业兽医根据年龄、既往接种史、健康状况与当地流行情况确定。** 本技能只提供区分口径、程序核查方法、记录要求与反应观察口径，**不提供具体疫苗名称、品牌、毒株，也不给出自家适用的针数与间隔天数**。**不判断反应是过敏还是正常免疫反应**，是否异常由兽医判断。**不判断免疫是否已建立**，抗体水平评估须通过检测并由兽医解读。妊娠期、免疫抑制、自身免疫病、肿瘤治疗中、正在使用免疫抑制药物的个体方案须兽医评估。宠物生病、发热、腹泻期间不接种。**不建议在未完成免疫程序前接触未接种同种动物、宠物店、寄养与高密度场所**。已按程序接种仍发病须由兽医评估，不作"疫苗无效"的结论。
