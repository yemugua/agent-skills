# 七类套路话术与信息造假取证

## 一、七类常见套路

### 1. 承诺成功 / 包结婚

| 机构常说 | 为什么是套路 |
|---|---|
| 「包成功」「保证成功」「不结婚全退」 | **婚姻自主决定，任何机构都无权保证结果** |
| 「一年内必结婚」 | 婚姻是人身事项，不能作为服务对价 |
| 「我们的成功率九成」 | 婚恋没有官方成功率统计，这个数字来源不明 |

**关键动作**：
- **口头承诺与合同不一致时，以合同为准**——但这个不一致本身就是证据
- 保留**宣传物料**：门店海报、易拉宝、宣传单页、小程序页面截图
- 录下**当场承诺的音频**（在公共场合录音取证，不违反法律）
- 若对方在合同签字前承诺「包成功」而合同写「一经付款概不退款」，**这构成宣传与合同重大不一致**，是可主张解除与退费的理由

---

### 2. 虚假资源与成功率

| 机构常说 | 为什么是套路 |
|---|---|
| 「优质资源多」「内部名额」 | 资源数量无法核实，「优质」无标准 |
| 「成功案例上千」 | 案例无编号、无当事人确认，多为营销素材 |
| 「今天下单锁定名额」「仅限今日」 | **制造紧迫感**逼你当场决策 |

**关键动作**：
- 要求**看资源库**（哪怕只看规模和地区分布），并**当场记录**
- 「名额有限」如果是真的，应该写进合同并写明**名额数量**
- **绝不在被催当场付款**。回家冷静一天再决定，第二天热情通常会减半

---

### 3. 诱导签约与分期

| 机构常说 | 为什么是套路 |
|---|---|
| 「先签合同，细节后面补」 | 先签后补，空白栏永远不补 |
| 「App 上分 12 期，比一次性便宜」 | **让你在没看清条款时就背上长期负债** |
| 「贷款额度下来了，先刷出来」 | 服务没开始就负债 |
| 「限时优惠今天到期」 | 逼单 |

**关键动作**：
- **合同空白栏一律不签**。介绍次数、服务期限、退费规则**当场填满**或写「无」
- 遇到**分期 / 贷款 / 刷流水**当场办：这是本案里最危险的一步，**服务没开始你已经在还钱**
- 想清楚**要不要承担这个负债**再签字，不要被「办理流程快」推着走
- 签字前拍照留档（每一页，包括空白页）

---

### 4. 信息不实与隐瞒

| 表现 | 说明 |
|---|---|
| 照片与本人对不上 | 用网图或他人照片充数，**可能构成欺诈** |
| 年龄、职业、学历造假 | 资料「包装美化」是行业常见操作 |
| 已婚、有子女情况隐瞒 | **最要命的一条**——隐瞒已婚涉及重大误导 |
| 对方联系方式给的是中介号 | 介绍的人根本不存在，或本人不愿联系 |

**关键动作**：
- 每介绍一个人，**要求书面提供**：年龄、学历/职业、婚姻状况、是否有子女
- **要求机构书面确认这些信息真实**，写进合同或微信文字
- 照片**先看视频**，视频比静态照片难造假
- 对方联系不上时，**立即书面催机构核实并给出说明**
- 发现造假 → **构成欺诈，可主张解除合同、退还费用并赔偿损失**

---

### 5. 限制人身与社交

| 条款表述 | 问题 |
|---|---|
| 「服务期内不准与其他人相亲」 | **限制人身自由，显失公平** |
| 「不得中途退出」 | 同上 |
| 「必须配合介绍安排，否则不退费」 | 把机构义务变成你的义务 |
| 「不准见别人」「不能离婚」 | 严重越界，**绝对无效** |

**关键动作**：
- **人身自由是底线**。你有权随时终止与任何人的接触
- 看到这类条款**直接要求删除**，对方拒绝就别签
- 已签的，**可主张该条款无效**，并作为后续解除合同的正当理由
- 机构以「不准见别人」施压时，**保留施压的聊天记录**

---

### 6. 拖延与换人

| 机构常说 | 为什么是套路 |
|---|---|
| 「缘分没到，再等等」 | 无期限拖延，**服务期自动延长** |
| 「这个不合适，换下一个」 | 无限换人，永远不主张「已服务完」 |
| 「下一个更好」 | 没有次数约定 = 没有终点 |

**关键动作**：
- **关键在合同**：合同里写了「安排 N 次介绍」，到期就结束；**没写次数就永远说不清**
- 自己**记录每一次介绍**的日期、对象、结果
- 每次介绍后**书面问一次**「这是第几次安排」，让机构确认计数
- 时间节点一到（服务期届满 / 次数用完）**主动发函要求结算或退费**

---

### 7. 冒用资质与格式合同

| 风险 | 说明 |
|---|---|
| 门店与合同主体不一致 | 门店是加盟的，合同方是另一家公司 |
| 收款方是个人微信 | **钱不进公司**，出问题极难追回 |
| 合同是「技术服务协议」 | 标题规避「婚介服务」，换个名目换个规则 |
| 合同全是「最终解释权归本公司」 | 典型的加重对方责任、减轻己方责任的格式条款 |
| 无盖章、无授权 | 可能不是公司真实意思 |

**关键动作**：
- 把机构名称在 **国家企业信用信息公示系统** 查一遍
- **核对三处一致**：门店招牌名 = 合同甲方 = 收款方
- **不要向个人账户付款**。确实要付个人，必须有公司出具的收款委托书
- 格式条款中**加重你责任、减轻机构责任的部分，可主张不成为合同内容**
