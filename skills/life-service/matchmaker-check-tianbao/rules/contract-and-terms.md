# 合同必备条款与条款效力

## 一、婚介服务合同的六项必备内容

**缺少任何一项，你都很难约束机构**：

| 必备内容 | 为什么必须有 | 缺失的后果 |
|---|---|---|
| **服务期限** | 明确服务到什么时候 | 无法主张「期限已到未达成」 |
| **服务期限起算日** | 明确从哪天开始算 | 机构可能说「从首次介绍算起」，无限拖延 |
| **介绍次数 / 安排次数** | 明确提供几次服务 | **介绍一个就算履约完毕** |
| **介绍对象的信息来源** | 明确信息来源与核实程度 | 无法追究信息造假 |
| **解除与退费规则** | 明确怎么退出、退多少 | 只能被动接受对方的规则 |
| **费用与付款方式** | 明确金额、支付对象、发票 | 钱转给了谁都说不清 |

**特别强调「介绍次数」**：这是婚介合同里**最容易被留空、也最关键的一栏**。留空意味着机构介绍一个人就可以主张「已提供服务」。

## 二、三组必须写死的条款

### 1. 服务期限

```
服务期限：自 2026 年 3 月 15 日起至 2026 年 9 月 15 日止（共 6 个月）
```

**不接受**：「服务期限为一年」「长期服务」「直到结婚为止」

- 没有**起算日**的期限，机构可以从「第一次介绍」开始算，拖很久
- 「直到结婚为止」= **无期限**，等于没有约束

### 2. 介绍次数

```
服务期内应安排不少于 10 次介绍，其中不少于 3 次双方见面
```

**不接受**：「协助介绍」「提供资源」「推荐合适对象」这类模糊表述

**次数要可考核**：写清是「提供联系方式」还是「安排见面」——差别很大。

### 3. 解除与退费

```
（1）双方均可书面通知解除
（2）机构已安排介绍 X 次、服务期已过 Y 天，应按未服务比例退还费用
（3）退款于解除之日起 15 个工作日内完成
```

**不接受**：「一经付款概不退款」「介绍不满不适用任何退款」

## 三、限制人身自由的条款：无效

### 常见违法条款

| 条款内容 | 问题 |
|---|---|
| 「服务期间不得与机构安排的以外对象恋爱」 | 干涉人身自由 |
| 「不准离婚」「不得中途退出」 | 干涉婚姻自主 |
| 「禁止接触其他相亲对象」 | 限制社交自由 |
| 「必须配合机构安排的一切活动」 | 加重对方责任 |
| 「未达服务期不得解除合同」 | 排除对方主要权利 |

### 为什么无效

**婚姻自由与恋爱自由是人身权利的一部分**，不属于合同可以约定的财产性义务。

这类条款通常被认定为：
- **不合理限制对方主要权利**
- **不合理加重对方责任**
- 属于**显失公平**的条款

**可主张该条款无效**，但要注意：**主张无效 ≠ 合同整体无效**。合同其他部分仍有效，只是不受该条款约束。

### 实务建议

**签约前**：看到这类条款直接要求删除，或明确写「本条不构成对乙方人身自由的限制」。

**已经签了**：
- 保存条款原文的照片
- 如果机构真的以「不许接触其他人」为由限制你，**保留证据**
- 必要时向公安机关反映（若涉及实际限制人身自由）

## 四、格式条款的问题

婚介合同通常是机构事先拟好的**格式条款**，你只能选择接受或拒绝。

### 可能无效的格式条款

- **不合理免除机构自身责任**：「介绍不成功概不负责」「不对信息真实性负责」
- **不合理加重你的责任**：「因个人原因未成功，全额不退」
- **排除你的主要权利**：「一经付款概不退款」
- **不合理限制你**：「不得与他人接触」

### 但要注意

**主张格式条款无效需要走程序**（协商、投诉、诉讼），**耗时较长**。

**更实际的策略是签约前谈清楚**——这也是本技能把「合同要素核查」放在第二节的原因。

## 五、合同里这几句话要特别警惕

| 表述 | 问题 |
|---|---|
| 「介绍次数按实际进度安排」 | 次数不固定 = 无约束 |
| 「服务期内介绍对象不保证符合期望」 | 免责过宽 |
| 「因不可抗力或本人原因导致失败不予退款」 | 「本人原因」范围无限大 |
| 「服务费一经支付不退」 | 直接排除你的主要权利 |
| 「本公司保留最终解释权」 | 排除对方解释义务 |

## 六、签约时的必做动作

- [ ] **逐条读完**整个合同，不只看法务费那页
- [ ] 拍下**每一页**，包括附件、补充协议
- [ ] 「介绍次数」「服务期限起算日」「退费规则」三处**必须写死**
- [ ] 机构口头承诺的每一句，**要求写进合同或补充协议**
- [ ] 问清「不合适」由**谁认定**（这一条最容易扯皮）
- [ ] 拿到**自己那份原件**，不只留机构那份
- [ ] 确认收款账户是**对公账户**，收款方与合同甲方一致
