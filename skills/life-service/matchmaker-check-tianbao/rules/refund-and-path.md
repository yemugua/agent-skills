# 退费规则解读、七步路径与投诉渠道

## 一、退费规则怎么读

婚介合同里最容易吃亏的，是「一经付款概不退款」这类条款。**这类条款不是绝对无效，但也不是你必须接受的**——关键看机构**实际提供了多少服务**。

### 四类常见退费条款与应对

| 条款写法 | 实际含义 | 应对思路 |
|---|---|---|
| **一经付款概不退款** | 无论服务做没做都不退 | **显失公平**。机构提供服务是合同义务，权利义务不对等；未提供服务即不支持不退 |
| **服务期内一律不退** | 只要没到期就不退 | 结合**实际服务进度**主张按未提供部分结算 |
| **介绍 N 次后不退款** | 完成次数就不退 | 核对**实际介绍次数**与合同约定是否一致，是否有效联系、是否信息真实 |
| **退费扣除已发生费用** | 扣掉已服务部分后退 | **最合理的条款**。应核算「已提供服务对应的合理费用」 |

### 退费金额怎么算

**按已提供服务的合理比例扣减**是通行思路：

```
可主张退还的金额 = 已付总费用 − 已提供服务对应的合理费用
```

计算时要看三个点：

1. **已介绍了几次，其中几次真实有效**（对方联系不上、信息造假的应扣除）
2. **服务期过了多久**（服务期过半仍未达约定目标的，服务方应担主要责任）
3. **机构有无明显违约**（介绍次数未写、明知信息造假仍提供、承诺与合同不符——这些都会让机构处于不利地位）

**举例**：付 28800 元，约定两年服务、安排 10 次介绍；实际介绍 4 人、仅 1 人可正常联系、2 人信息造假、1 人失联。服务期刚过四分之一。机构若主张「已服务」要求不退，可主张按实际有效服务折算后**退还大部分费用**，而非一分不退。

> 实际退费金额以协商或认定结果为准。本技能只做规则解读与金额核算思路，不预测对方是否同意。

## 二、七步维权路径

### 第 1 步：先核资质，别急着付全款
- 机构名称查 **国家企业信用信息公示系统**，确认注册信息、经营范围、存续状态
- 线下门店尤其要查，很多是加盟或纯营销壳
- **先付小额、保留退路**，不要一次性交清全程费用

### 第 2 步：把服务内容写进合同
合同必须写明：服务期限、**推荐次数或安排几次**、介绍人的基本信息来源、未达约定次数怎么办、**双方如何解除与退费**。

**只写「介绍对象」不写次数的合同，等于没有约束。**

### 第 3 步：核对方信息真实性
- 每介绍一人，要求提供年龄、学历、职业、婚姻状况、是否有子女，**并要求书面确认真实**
- 发现明显造假（照片与本人不符、年龄职业造假），**构成欺诈，可主张解除与赔偿**

### 第 4 步：保护自己的社交自由
**人身自由是底线**。任何机构要求「不许离婚」「不准接触其他人」「不得中途退出」的条款，**显失公平可主张无效**。你有权随时终止与任何人的接触，也有权随时结束服务。

### 第 5 步：留痕
微信沟通不要口头说。**要求机构在微信上书面答复**，每次介绍后确认计数，每次催办后留存记录。口头承诺全部要落到文字。

### 第 6 步：书面协商退费
发**书面催办函**（微信/邮件/函件均可），写明：签约时间、金额、约定服务内容、实际提供情况、**具体退费诉求与理由**。留好送达凭证。

要求对方在明确期限内书面答复。协商不成再往下走。

### 第 7 步：投诉或诉讼
按金额与性质选渠道，见下节。金额较大（数万元）且对方明确拒赔的，**建议咨询律师**。

## 三、投诉渠道怎么选

| 渠道 | 适用场景 | 说明 |
|---|---|---|
| **12315**（全国 12315 平台 / 市场监管） | 服务合同纠纷、虚假宣传、退费争议、格式条款 | **最常用、成本最低**。提交合同、付款凭证、沟通记录、诉求 |
| **民政部门** | 婚姻介绍服务机构违规、非法经营 | 婚介行业有主管部门；机构无资质经营、超范围经营可向民政反映 |
| **市场监管部门** | 虚假宣传、虚假信息、格式条款、违规收费 | 重点是**宣传与合同不符**、**信息造假**两类 |
| **公安机关** | 对方信息造假涉嫌诈骗、伪造身份 | 达到立案标准的走刑事，**不建议自行曝光对方个人信息** |
| **法院诉讼** | 协商与投诉均无果、金额较大 | 注意**时效**，并评估成本 |

### 投诉材料清单

1. 机构名称与查询到的注册信息
2. 服务合同 / 协议原件或复印件
3. 付款凭证（发票、收据、转账记录、分期记录）
4. 介绍对象的资料记录（每次介绍的时间、对象、结果）
5. 沟通记录（微信、短信、通话录音）
6. 退费诉求与机构答复

### 投诉话术要点

- **只讲事实与合同**，不掺杂情绪评价
- **金额与诉求写明确**（退多少、什么时间前）
- 一次只向一个渠道提交，避免多头反复
- 保留**受理编号或回执**
