# 婚介服务合同与退费核查报告 模板

> 报告由 `scripts/matchmaker_check.py` 自动生成，共**十一段**。本文件说明每段的用途与判读方式。

## 段落结构

| 段 | 标题 | 内容 | 判读要点 |
|---|---|---|---|
| 一 | 结论摘要 | 整体风险等级 + 不通过/有风险项数量 + 最该先做的三件事 | **先看这一段**。三件事通常是补材料、发书面催办、核算可退金额 |
| 二 | 婚介服务类型与合同核查 | 服务形式识别 + 合同六项必备内容核查 + 限制人身自由条款判定 | 「**介绍次数**」缺失 = 最关键的坑 |
| 三 | 机构承诺与套路识别 | 命中的七类套路话术（承诺成功/虚假资源/诱导分期/信息不实/限制人身/拖延换人/冒用资质） | 命中的每一类都对应一项可主张的权利 |
| 四 | 介绍服务与信息核实 | 已介绍人数、有效次数、对方信息真实性 | 失联与造假的人次**不计入有效服务** |
| 五 | 费用与退费规则 | 已付金额、是否分期、退费条款类型与应对思路 | 「一经付款概不退款」是**显失公平**条款，不是必须接受 |
| 六 | 服务期限与时效风险 | 服务期长短是否合理、有无节点、退费是否按月不退 | 「直到结婚为止」= 无期限 = 无约束 |
| 七 | 证据清单与缺口 | 八类证据是否齐全 + 缺什么 | **未填的一律不算通过** |
| 八 | 路径与维权流程 | 七步路径（核资质 → 写进合同 → 核信息 → 保自由 → 留痕 → 书面协商 → 投诉诉讼） | 按顺序走，别跳步 |
| 九 | 投诉渠道 | 12315 / 民政 / 市场监管 / 公安 / 法院各自适用场景 | 一次只向一个渠道提交 |
| 十 | 证据缺口速查 | 缺哪一类材料会导致哪一项主张站不住 | 补材料的优先级清单 |
| 十一 | 待办补正动作 | 可直接照做的补正动作清单 | 照着做即可 |

---

## 四态判定

报告里每项核查有四种结论：

| 判定 | 含义 | 你该做什么 |
|---|---|---|
| **通过** | 已填内容中该项没问题 | 不用动。**注意：未填不判通过** |
| **有风险** | 有隐患但不一定致命 | 优先补材料、补条款，必要时作为协商依据 |
| **不通过** | 明确存在问题 | 这是主张解除与退费的核心理由 |
| **待补正** | 关键信息没填，无法判断 | **先补采集表再重跑**，不要凭感觉下结论 |

---

## 使用建议

1. **先补齐采集表再跑脚本**。字段填「不清楚」比乱填好——脚本会把不清楚的判为「待补正」，不会给你假结论。
2. **金额较大（数万元）且对方明确拒赔的，咨询律师**。本报告是规则梳理与核算思路，不替代律师意见。
3. **实际退费金额以协商或认定结果为准**。报告不给对方会不会同意的预测。
4. **隐私本地处理**。采集表含双方姓名、照片、联系方式，不要发到公开平台，也不要用来曝光对方。
