## 签约前（还没交钱时逐项打勾）

- [ ] 机构名称已在**国家企业信用信息公示系统**查到，确认存续状态与经营范围
- [ ] 门店招牌名 = 合同甲方 = 收款方，**三处一致**
- [ ] **没有向个人账户付款**（若有，需公司出具收款委托书）
- [ ] 合同写明**服务期限**（含起算日，不是「直到结婚为止」）
- [ ] 合同写明**介绍次数 / 安排几次**
- [ ] 合同写明**介绍对象信息的核实程度**
- [ ] 合同写明**解除与退费规则**
- [ ] 合同**没有任何空白栏**（介绍次数、服务期限、金额都不能空）
- [ ] 合同**没有限制人身自由的条款**（不准见别人 / 不得中途退出 / 不许离婚）
- [ ] 「包成功」「不结婚全退」这类口头承诺**已写进合同**
- [ ] **没有当场办分期、贷款、刷流水**
- [ ] 没有被「今天下单锁定名额」催着当场付款
- [ ] 合同**每一页都拍照留档**（含空白页）

**任一项没打勾就别签。**

## 服务中（每次介绍后立刻做）

- [ ] 记录本次介绍：日期 / 第几次 / 对方基本情况
- [ ] 核对对方信息：年龄、学历、职业、婚姻状况、是否有子女
- [ ] **看过视频**，不只是静态照片
- [ ] 已要求机构在微信上**书面确认**对方信息真实
- [ ] 微信问过「**这是第几次安排**」，让机构确认计数
- [ ] 对方联系不上 → 已**书面催机构核实并说明**
- [ ] 发现信息造假 → 已拍照留证，书面提出

---

## 想退费时（按顺序做）

- [ ] 1. 先核机构资质（注册信息、经营范围、存续状态）
- [ ] 2. 核算已提供服务的**有效介绍次数**（失联的、信息造假的应扣除）
- [ ] 3. 书面催办（微信/邮件/函件）：签约时间、金额、约定内容、实际提供情况、**具体退费金额与理由**
- [ ] 4. 给对方**明确答复期限**，并保存送达凭证
- [ ] 5. 对方拒退 → 按性质选渠道：**12315 / 民政 / 市场监管 / 公安 / 法院**
- [ ] 6. 提交材料：合同、付款凭证、介绍记录、沟通记录、投诉回执
- [ ] 7. 金额数万元且对方明确拒赔 → **咨询律师**

---

## 三条底线

1. **人身自由是底线**。任何限制你社交自由的要求都可以拒绝，条款可主张无效。
2. **未提供的信息不视为已提供**。介绍一个人不等于履约完毕，除非合同写清了次数。
3. **未写进合同的口头承诺不算数**。所以要么写进合同，要么留好书面证据。
