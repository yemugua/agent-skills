# 婚介服务合同与退费核查

婚介这门生意，**承诺在付款之前，服务在付款之后**。签的时候说得天花乱坠，交完钱才发现合同里「介绍次数」那一栏是空的。

## 什么时候用

- 被婚介门店或线上平台签了服务协议，交了钱
- 对方说「包成功」「不结婚全退」，结果介绍的人没一个能联系上
- 介绍对象照片和本人对不上、年龄学历疑似造假
- 合同写「一经付款概不退款」，但服务根本没提供
- 对方让你分期或办贷款付服务费
- 想知道服务没做到位能不能退、能退多少

## 怎么做

**第 1 步**：复制 `templates/婚介服务信息采集表.md` 填写（**机构名称、机构承诺原话、已介绍人数、退费规则**是关键项）。

**第 2 步**：跑脚本

```bash
python scripts/matchmaker_check.py 采集表.md --base 2026-10-05 --out 核查报告.md
```

**第 3 步**：照第八段七步走——**先核资质 → 把服务内容写进合同 → 核对方信息真实性 → 保护社交自由 → 留痕 → 书面协商退费 → 投诉诉讼**。

## 三条最该记住的规则

1. **「包成功」「不结婚全退」几乎是话术**。婚姻自主决定，**没有任何机构能保证结果**。如果对方在宣传里这样承诺，而合同里写的是「一经付款概不退款」——**两者矛盾时以合同为准**，这本身就是重要的证据。
2. **合同里必须写「介绍次数」或「服务期限 + 起算日」**。只写「协助介绍对象」不写次数的合同，**几乎无法约束机构**——介绍一个也算履约完毕。
3. **任何限制人身自由的条款都无效**。「不准见别人」「不能中途退出」这类条款**显失公平，可主张无效**。你有权随时终止与任何人的接触，也有权随时结束服务。

## 输入 / 输出

| | 内容 |
|---|---|
| 输入 | 采集表 Markdown（服务类型 / 机构 / 服务经过 / 合同内容 / 机构承诺 / 资质核实 / 服务期限 / 已介绍人数 / 信息是否核实 / 已付费用 / 是否分期 / 退费规则 / 服务状态 / 已有材料） |
| 输出 | 十一段报告：结论摘要 / 服务类型与合同核查 / 机构承诺与套路识别 / 介绍服务与信息核实 / 费用与退费规则 / 服务期限与时效风险 / 证据清单与缺口 / 路径与维权流程 / 投诉渠道 / 证据缺口速查 / 待办补正动作（另附边界与纪律） |
| 退出码 | 0 正常；2 关键信息缺失（给提示串，不崩） |

## 边界与纪律

- 依**通用规则**整理，**不替代律师意见**；婚介服务合同的效力与退费规则，**以合同约定、监管规定与司法机关认定为准**
- 报告金额按已填凭证汇总，**实际退费金额以协商或认定结果为准**
- 不预测机构是否同意退费，也不预测投诉与诉讼结果
- **未填的一律不算通过**，只按已填内容判断
- 涉及**双方姓名、照片、联系方式等个人信息**，**本地处理，不要外发**；婚介纠纷常涉隐私与人际矛盾，**不建议在公开平台曝光对方信息**
- 金额较大（数万元）且对方明确拒赔的，**建议咨询律师**
