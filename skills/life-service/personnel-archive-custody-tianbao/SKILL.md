# 人事档案托管与转递核查（personnel-archive-custody）

档案这件事，绝大多数人卡在四个点：**不知道档案在哪、不知道该由谁保管、想自己拿去办、拆了封还不知道后果**。

这个技能做五件事：**找档案** → **定托管机构** → **核转递通道** → **查材料缺口** → **判死档**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 判断档案应由哪类机构托管 | ❌ 承诺一定接收、一定能激活死档 |
| 说明转递应走的合规渠道 | ❌ 教人自带档案、拆封后再自行封装 |
| 列出归档材料清单并标缺失 | ❌ 补制、伪造学历、工龄、党团材料 |
| 提示死档成因与处置路径 | ❌ 提供"重新建档"等规避口径 |
| 说明调档流程与所需材料 | ❌ 代开调档函、代签承诺 |

**遇到以下情况，直接问档案管理服务机构或原单位人事部门，不要靠猜：**
- 档案去向不明，多方查询都没有结果
- 档案已在个人手中，或封条已被拆开
- 涉及学历、工龄、党团关系等关键材料缺失
- 出国（境）定居、死亡人员的档案处置
- 涉密单位、特殊行业人员的档案转递
- 跨省流动且两地机构对接不畅

**永远不要把档案拿在自己手里，不要拆封，不要自行封装。** 档案一旦脱离机要渠道进入个人手中，或封条被拆，接收方通常不予接收。

| "档案里缺材料怎么补" | ✅ |
| "帮我重新做一份档案" | ❌ 不在本技能范围内 |

## 二、完整工作流

```
第 1 步  找档案：从毕业院校、原单位、人才中心、人社部门倒着查
第 2 步  定托管机构：四类机构中应由谁保管
第 3 步  先读规则文件 rules/custody_rules.md（机构表 + 转递渠道 + 材料 + 死档）
第 4 步  跑核查脚本
    python scripts/archive_transfer_check.py --file 情况.txt --as-of 2026-10-08
第 5 步  核转递通道：必须机要或派专人，不得个人自带
第 6 步  逐项人工确认，按 templates/档案托管与转递核查表.md 输出
```

---

## 三、托管机构（四类）

| 机构 | 适用人群 | 常见情形 |
|---|---|---|
| **公共就业和人才服务机构** | 流动人员、非公单位就业人员、未就业毕业生 | 最常见的一类托管机构 |
| **有人事档案管理权的用人单位** | 机关、国企、事业单位在编人员 | 由单位人事部门直接管理 |
| **户籍地或居住地人社部门所属机构** | 未就业、灵活就业、返乡人员 | 具体受理以当地规定为准 |
| **教育系统与学校** | 在校生、毕业后暂未转出的学生档案 | 有存放期限，应及时转出 |

> 无档案管理服务权限的一般企业**不得保管员工档案**。这类人员通常由单位委托公共就业和人才服务机构管理，或个人按规定办理托管。

---

## 四、转递渠道（红线所在）

| 渠道 | 是否合规 | 说明 |
|---|---|---|
| **机要通信渠道** | ✅ | 档案转递的主要合规渠道 |
| **派专人送达（两人以上、密封、签收）** | ✅ | 部分机构接受，须事先确认 |
| **邮政快递、普通快递、物流** | ❌ | 绝大多数机构不接收 |
| **个人自带、托人捎带** | ❌ | **不允许**，会导致接收方拒收 |
| **拆封后自行封装再送** | ❌ | 封条一旦破损，档案真实性无法保证 |

> **这条不是"建议"，是接收方的基本核验条件。** 档案在个人手中或封条破损，接收机构通常直接退回。

---

## 五、常见归档材料（八类）

完整清单与补充口径见 `rules/custody_rules.md`。核心八类：

| # | 材料类别 | 典型内容 | 缺了会怎样 |
|---|---|---|---|
| 1 | 履历材料 | 履历表、简历类材料 | 影响工龄认定 |
| 2 | 学历学位材料 | 毕业生登记表、成绩单、学位材料 | 影响学历认定与政审 |
| 3 | 政治面貌材料 | 入党入团志愿书、党员材料 | 影响政审与组织关系 |
| 4 | 工资与任免材料 | 工资审批表、任免文件 | 影响退休待遇核算 |
| 5 | 考核与奖惩材料 | 考核表、奖惩决定 | 影响考核连续性 |
| 6 | 劳动合同与就业材料 | 劳动合同、就业登记材料 | 影响工作经历连续性 |
| 7 | 职称与技能材料 | 职称评审表、技能等级材料 | 影响职称认定 |
| 8 | 转递与接收手续 | 转递单、回执、托管协议 | 造成档案去向不明 |

## 六、死档（最麻烦的情况）

| 成因 | 表现 | 处置方向 |
|---|---|---|
| 长期滞留在个人手中 | 档案在自己家里，没有机构接收 | 联系拟托管机构问清接收条件，不要自行封装 |
| 封条破损或被拆开 | 封条断裂、有拆封痕迹 | 由原保管机构或转出机构核实并重新密封 |
| 长期未办理托管手续 | 毕业后多年未转递，去向不明 | 从毕业院校与原单位倒查转递记录 |
| 关键材料缺失 | 缺学历、工龄、党团材料 | 向原形成单位申请补制，不要自行制作 |

> **"死档"不是法律术语，是经办中的俗称。** 具体能否接收、如何补救，一律以拟托管机构的答复为准。

---

## 七、办理时限

- 转递、托管、调档的具体办理时限由各地档案管理服务机构按现行规定执行，实际时长受转递方式、跨省协调、材料核查影响。
- **机要通道有在途时间**，跨省转递通常需要数周，不要按快递时效估算。
- **调档函有有效期**，应在有效期内完成调档；逾期通常需要重新开具。
- 涉及退休、政审、落户等事项的，应**提前数月**核实档案去向与材料完整性，不要临到截止日期才查。

## 八、脚本用法

```bash
python scripts/archive_transfer_check.py --file "D:\材料\情况说明.txt" \
    --as-of 2026-10-08 --out 核查结果.md
```

| 参数 | 说明 |
|---|---|
| `--file` | 必填。情况说明、材料清单或聊天记录导出文本（`.txt` / `.md`） |
| `--text` | 直接给一段情况描述 |
| `--as-of` | 核查基准日，默认今天 |
| `--letter-date` | 调档函开具日期，用于算有效期剩余天数 |
| `--out` | 输出路径，默认打到屏幕 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本做五件事：
1. **托管机构判定**：四类机构中应由谁保管
2. **转递渠道核查**：是否命中个人自带、快递、拆封等违规方式
3. **材料核查**：八类归档材料逐项标齐备/缺失/不涉及
4. **死档识别**：五类成因是否命中并给出处置方向
5. **调档函有效期**：剩余天数与逾期提示

> ⚠️ 脚本只做关键词匹配，**不代表接收结论**。标"齐备"不等于机构认可这份材料。

---

## 九、人工确认（这步不能省）

- [ ] 档案当前去向是否已通过原单位、毕业院校或人才中心核实，不是靠推测
- [ ] 档案是否曾在自己手中，封条是否完好
- [ ] 转递是否走机要或派专人，没有通过快递或自带
- [ ] 调档函是否在有效期内，是否已取得回执
- [ ] 学历、工龄、党团材料是否齐全，缺失的应向原形成单位申请补制
- [ ] 是否属于涉密单位或特殊行业，转递是否有额外要求
- [ ] 涉及退休、政审、落户的，是否已提前足够时间核实

---

## 十、输出结构（固定六段）

1. **档案去向** —— 已知/未知，该向谁核实
2. **托管机构** —— 应由哪类机构保管
3. **材料核查表** —— 八类逐项标齐备/缺失/不涉及
4. **转递渠道** —— 是否合规，命中了哪些违规方式
5. **死档风险** —— 命中的成因与处置方向
6. **时间节点** —— 调档函有效期、建议核实时点

---

## 十一、最常见的坑

**坑一：自己拿着档案去办托管。**
档案在个人手中，接收机构通常直接拒收。转递必须走机要通信或派专人送达。

**坑二：拆开看看里面有什么。**
封条一旦破损，档案的真实性无法保证，接收方不予接收。好奇一次，补救很久。

**坑三：用快递寄档案。**
机要通信是档案转递的主要合规渠道。快递寄送绝大多数机构不接收，且途中损毁无从追责。

**坑四：毕业多年不管档案。**
档案滞留在学校或原单位超过存放期限，再想转出时往往已联系不上经办人。毕业后应及时办理转递。

**坑五：把档案当成"学历证明复印件"。**
档案是成套的原始材料，不是复印件集合。学历、工龄、党团材料缺一项，都可能影响退休核算、政审与落户。

**坑六：缺材料就自己做一份。**
缺失材料应向原形成单位申请补制。自行制作属于弄虚作假，一经发现后果严重。

**坑七：临到政审或退休才查档案。**
档案去向核查、跨省转递、材料补制都需要时间。提前数月核实才来得及。

**坑八：以为调档函开了就万事大吉。**
调档函有有效期，且必须确认对方机构已实际收到并出具回执。开完函不跟进，档案可能一直在途。

## 十二、边界与免责

- 本技能**不代替**公共就业和人才服务机构、人社部门及用人单位人事部门的受理与管理
- 托管条件、转递要求、材料清单、办理时限各地口径不同，**以现行规定和档案管理服务机构要求为准**
- 本技能**不提供**自行封装、重新建档、补制伪造材料等规避办法
- 涉及涉密单位、出国（境）定居人员、死亡人员档案的，按专门规定办理
