# 停车收费：定价性质与明码标价

## 一、定价性质三分类（决定"能不能随便涨"）

| 类型 | 常见场景 | 谁定价 | 能不能随便涨 |
|---|---|---|---|
| **政府定价 / 政府指导价** | 城市道路临时停车泊位、部分公立医院、公办学校、政府投资的交通枢纽与公共场馆配套停车场 | 价格主管部门制定或在指导价范围内确定 | **不能**，必须按公布的标准执行 |
| **市场调节价** | 商场、写字楼、住宅小区、社会停车场 | 经营者（小区为业主共同决定或合同约定）自主确定 | 经营者可调整，但须**明码标价并公示**，不得价格欺诈、不得串通涨价 |
| **业主共同决定** | 住宅小区利用共有部分设置的车位 | 业主大会 / 业主共同决定 | 物业或业委会**不能单方面决定** |

> 各地具体分类目录不同（有的城市把道路泊位以外的公共停车场也纳入政府指导价），**务必以当地价格主管部门公布的最新目录为准**。

## 二、明码标价（最容易被忽略、最容易赢的一条）

经营者收取停车费应当**明码标价**，公示内容一般包括：

1. 收费单位名称
2. 收费项目与计费方式（按次 / 按小时 / 按天 / 月租）
3. 收费标准（含不同车型、不同时段、免费时长）
4. 收费依据（定价文件文号或业主决定）
5. 价格投诉电话（12315 / 12345）

**明码标价的三个硬点**：

- 标价要**在收费场所显著位置**（出入口、收费岗亭、缴费处），不是"扫码后才知道"
- 实际收取金额**不得超过标价**
- 调整价格的，**应当提前公示**（各地对提前公示天数有不同规定，以当地为准）

→ 未明码标价、标价之外加价、虚假优惠（假原价）均属价格违法行为，可向**市场监督管理部门**举报，也可通过 **12345 / 12315** 反映。

## 三、超标准收费怎么主张退

1. 固定证据：拍下**公示牌全景**（含文字与立牌位置）、缴费页面截图、支付凭证、发票、入场与出场记录。
2. 计算差额：实缴金额 − 公示标准应缴金额 = 可主张退还的差额。
3. 主张路径：现场要求退还 → 收费主体上级（物业总部 / 商场管理方 / 停车运营公司）→ 12345 与市场监管（价格违法）→ 消协 12315 → 小额诉讼。
4. 多人被超收的，可集中投诉，效果明显好于单人。

## 四、免费时长与"不足一个计费单元"的争议

- 各地对道路泊位普遍设有**免费停放时长**（常见 15 分钟或 20 分钟，以当地规定为准）。
- 计费单元："不足 X 分钟按 X 分钟计"属于计费规则，**必须事先公示**；未公示的事后解释一般不能作为收费依据。
- 重复计费、出场后仍继续计时、系统故障多扣费：凭支付凭证要求退还，平台/运营方拒不处理的可投诉至市场监管与 12345。

## 五、常见误区

| 误区 | 正解 |
|---|---|
| 小区是市场调节价，物业想涨就涨 | 共有部分车位涨价属**业主共同决定事项**，程序不合规不当然有效 |
| 停车时没看到标价，事后补个牌子就行 | 收费时未明码标价即构成价格违法，事后补正不影响已发生的违规 |
| 取车时才发现被多收，钱少就算了 | 可主张退还差额并可举报，多人集中投诉时处理力度大 |
| 收费员说"不交不让走"只能交 | 可先缴纳并**注明异议**留存凭证，事后主张退还，不要发生肢体冲突 |
