# 车辆受损、违停处罚与争议处理

## 一、车在停车场受损 / 被盗，谁赔

### 责任性质

- 收费停车场与车主之间通常形成**有偿的停车服务关系**，经营者对停放车辆负有**合理的安全保障义务**（场地设施安全、出入管理、监控与巡查、必要的看管）。
- **"本车场仅提供场地、不承担保管责任""车辆受损概不负责"** 这类告示，属于免除自身责任的格式条款，不能当然免除其依法应尽的安全保障义务。
- 免费停车场（如开放式场地、消费附赠停车）的义务相对更低，但**因管理瑕疵直接造成损害**的仍可能承担相应责任。

### 责任判断要点（逐项自查）

| 要点 | 有利情形 | 不利情形 |
|---|---|---|
| 停车凭证 | 有入场记录、支付凭证、发票、月租卡 | 无凭证，无法证明车辆停放在该场 |
| 监控 | 已及时调取并保全 | 超过保存期（通常 7~30 天）被覆盖 |
| 场方管理 | 出入口无人值守、道闸损坏、照明缺失、无巡查 | 设施完好、有定期巡查记录 |
| 损害情形 | 刮擦、砸窗、被盗整车 | 车主自述但无证据、无法排除他处发生 |
| 报警 | 当场报警并取得回执 | 事后补报或无记录 |

### 步骤（顺序不能乱）

1. **先拍照**：车辆受损部位全景与细节、停放位置、周边设施（有无监控头、照明、道闸）、地面标线。
2. **当场要求调取并保全监控**——这是最紧急的一步，监控留存期很短，超过期限基本无法补救。
3. **报警**并取得回执或报案记录（无论场方是否愿意赔）。
4. 向场方**书面提出索赔**并索要回执，写明时间、地点、损害、诉求。
5. 取得维修估价单或 4S 店定损单、维修发票。
6. 协商不成：向消协 12315 / 12345 反映，或就赔偿争议提起民事诉讼（诉讼时效 3 年）。
7. 车有车损险的，可先走保险理赔，由保险公司取得代位求偿权后再向责任方追偿——**别因为报了保险就放弃向场方主张**。

## 二、被贴违停罚单 / 车被拖走

### 关键判断

- 处罚主体应当是**公安机关交通管理部门**；商场、小区、物业公司**没有行政处罚权**，其张贴的"罚款通知""锁车费"不当然具有法律效力。
- 城市道路范围内的违法停车由交管部门处理；小区、商场内部道路一般不属交管管辖（**消防通道除外**，由消防救援机构或公安机关处理）。
- 驾驶人在场的，一般应口头警告并令其立即驶离；不在场或虽在场但拒绝立即驶离、妨碍其他车辆行人通行的，可处罚款并可将机动车拖移至不妨碍交通的地点。

### 拖车费（很多人被坑在这里）

- 因违法停车被拖移的，**不得向当事人收取拖车费**，并应当及时告知当事人停放地点。
- 若被要求缴纳拖车费、停车费才能取车，可要求出具收费依据并向 **12345 / 市场监管 / 公安督察渠道**反映。

### 对处罚不服怎么办

- 收到处罚决定后，可在法定期限内申请**行政复议**（一般为知道该行政行为之日起 60 日内），或在法定期限内提起**行政诉讼**（一般为 6 个月内）。
- 有利证据：禁停标志缺失或被遮挡、标线不清或施划不规范、现场照片显示无禁停标识、车辆因故障或紧急情况临时停放并已设置警示标志、驾驶人当时在场。
- 通过"交管 12123"可在线查询违法记录、陈述申辩与处理。

## 三、其他高频争议

| 情形 | 判断 |
|---|---|
| 收费停车场出口道闸砸车 | 场方设施致损，一般由场方承担相应责任，保留监控与维修单据 |
| 新能源汽车充电车位被燃油车占用 | 属场内管理问题，向场方反映；道路泊位按当地规定处理 |
| 机械车位故障导致车辆受损 | 场方未尽维护义务，责任较明确，注意保全检修记录 |
| 小区内被他人车辆剐蹭后逃逸 | 报警调取监控，可主张侵权赔偿；物业未尽管理义务的承担相应责任 |
| 车辆在洗车、维修期间受损 | 属承揽/服务合同关系，由经营者承担，与停车责任不同 |

## 四、时限清单

| 事项 | 期限 |
|---|---|
| 申请行政复议 | 一般为知道行政行为之日起 60 日内 |
| 提起行政诉讼 | 一般为知道作出行政行为之日起 6 个月内 |
| 民事损害赔偿诉讼时效 | 3 年，自知道权利受损及义务人之日起算 |
| 监控保全 | 越快越好，通常 7~30 天即被覆盖 |
| 价格违法举报 | 无严格时限，但越早证据越完整 |

## 五、纪律

- 涉具体收费标准、是否属于政府定价目录，一律以当地价格主管部门公布为准。
- 不预测复议与诉讼结果；是否处罚、是否赔偿以主管部门认定与司法机关裁判为准。
