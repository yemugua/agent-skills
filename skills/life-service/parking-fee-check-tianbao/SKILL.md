# 停车收费纠纷核查

停车纠纷几乎人人遇到，但 90% 的人不知道**这笔钱属于什么定价**、**涨价要不要经业主同意**、**车在收费场受损谁赔**。

## 什么时候用

- 小区物业单方面涨停车费，想知道涨得算不算数
- 路边停车被收了钱但没看到公示牌，怀疑超标准
- 车停在收费停车场被刮/被盗，场方说"只租场地不负责"
- 被贴违停罚单，或车被拖走还要交拖车费
- 买了/租了车位，才发现是人防车位或公共区域车位
- 小区公共区域停车的收益去向，想弄清楚归谁

## 怎么做

**第 1 步**：复制 `templates/停车收费信息采集表.md` 填写。

**第 2 步**：跑脚本

```bash
python scripts/parking_check.py 采集表.md --base 2026-10-05 --out 核查报告.md
```

**第 3 步**：按第九段"待办补正动作"执行。

## 三句话定性的核心规则

1. **先看定价性质**：城市道路临时停车泊位、部分公立医院/交通枢纽等多属**政府定价或政府指导价**，必须按公示标准收；商场、写字楼、住宅小区一般属**市场调节价**，但仍必须**明码标价**。
2. **小区公共区域车位属业主共有**：占用业主共有的道路或者其他场地停放汽车的车位属于业主共有，收益归业主共有；涨价属业主共同决定事项，物业或业委会单方面涨价不当然有效。
3. **车在收费场受损不等于自认倒霉**：收费停车场对车辆负有合理的安全保障义务，"只提供场地不负责保管"的告示不能当然免责；关键是**有没有停车凭证、监控是否被及时保全**。

| 退出码 | 0 正常；2 关键信息缺失（给提示串，不崩） |

## 边界与纪律

- 依**通用规则**整理，**不替代律师意见**
- 停车收费的地方差异极大，涉及具体标准的**一律以当地价格主管部门、住建（物业）主管部门、公安交管部门口径为准**
- 不预测行政处罚复议结果、不预测诉讼结果
- **未填的一律不算通过**，只按填了的判断
- 涉人防车位产权归属、小区车位历史遗留确权的，需另行查证
