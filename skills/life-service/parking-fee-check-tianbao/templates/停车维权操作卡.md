# 停车维权操作卡

## 一、取证清单（按顺序，越早越好）

| 顺序 | 取证动作 | 为什么急 |
|---|---|---|
| 1 | 拍公示牌**全景**（能看出立在出入口）+ 特写（能看清收费标准与投诉电话） | 证明有没有明码标价，事后补牌不影响已发生的违规 |
| 2 | 缴费页面截图 + 支付凭证 + 发票 | 证明实缴金额 |
| 3 | 入场与出场记录、道闸照片、月租合同 | 证明车辆停放在该场 |
| 4 | **书面要求保全监控**（当场提出并留存提出记录） | 留存期通常仅 7~30 天，过期无法补救 |
| 5 | 报警回执（刮擦/砸窗/被盗） | 保险理赔与索赔都要 |
| 6 | 受损部位全景 + 细节照片、停放位置、周边设施 | 责任认定 |
| 7 | 维修估价单 / 定损单 / 维修发票 | 损失金额 |
| 8 | 业主大会决议、表决统计、公示照片（小区） | 涨价程序是否合规 |

## 二、场景化话术

### 向物业/业委会索要依据

> 请提供本次停车收费调整的全部依据：业主大会会议决议、表决票统计结果、公示记录（含公示时间与位置），
> 以及共有部分停车收益的收支明细。在收到上述材料前，我对调整后的标准有异议，暂按原标准缴纳，
> 请予书面确认。

### 向场方索赔（车损）

> 本人车辆于 X 月 X 日 X 时停放于贵场（凭证号 XXX），取车时发现 XX 受损。
> 请于 3 日内：① 保全并提供该时段监控录像；② 书面回复处理方案。
> 贵场公示的"不负责保管"属免除自身责任的格式条款，不能免除依法应尽的安全保障义务。
> 逾期未回复的，本人将向消协、12345 反映并依法主张赔偿。

### 要求退还超收部分

> 本人于 X 月 X 日在贵处停车被收取 X 元，贵处公示标准为 X 元，超出 X 元。
> 请于 X 日内退还至本人账户（附支付凭证）。未明码标价与超标准收费属价格违法行为，
> 本人已向市场监督管理部门举报（受理号 XXX）。

### 被收取拖车费

> 因违法停车被拖移车辆的，不得向当事人收取拖车费。请出具本次收费的法律依据与文件文号，
> 并退还已收取的 X 元。

## 三、投诉入口速查

| 问题类型 | 找谁 |
|---|---|
| 未明码标价、超标准收费、价格欺诈 | 市场监督管理部门 / 12315 / 12345 |
| 小区停车涨价程序、物业拒不公开收益 | 街道（乡镇）/ 住建（物业管理）主管部门 / 12345 |
| 违停处罚争议 | 公安交管部门；不服可申请行政复议或提起行政诉讼 |
| 占用消防通道 | 消防救援机构 / 公安派出所 |
| 车损赔偿争议 | 消协 12315 / 12345 / 民事诉讼 |
| 共有部分收益返还 | 业主共同决定后依法主张 |

## 四、四条别踩的坑

1. **别为了不交钱发生冲突**——先缴纳并注明异议留存凭证，事后主张退还更稳。
2. **别拖着不保全监控**——这是唯一一条过期就没了的证据。
3. **别认为"免费停车就完全没人管"**——因管理瑕疵直接造成损害的仍可能担责。
4. **别把物业费和停车费混为一谈**——两个法律关系，以拒交物业费对抗停车争议不可取。
