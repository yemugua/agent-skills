# 恋爱避坑与关系健康核查

面向在相亲、交友软件、线下活动或网友交往中确认关系前后的用户，帮助快速判断「这段关系有没有危险信号」「对方有没有骗财或操控倾向」「我该保留哪些证据、做哪些自我保护」，生成一份红旗核查与理智行动清单。

## 它能做什么

- 识别**骗财红旗（杀猪盘 / 情感投资诈骗）**：未见面就借钱、诱导充值/投资/理财/博彩平台、以"系统故障/保证金/解冻费"等话术要钱
- 识别**情感操控红旗（PUA / 控制）**：系统性贬低打压、制造依赖、冷热交替制造焦虑、限制社交圈、要求交出隐私或查岗控制行踪
- 识别**闪恋索财风险**：极短时间确认关系后随即索要财物或投资
- 识别**身份不透明红旗**：拒绝视频/线下见面、人设完美却无法第三方验证
- 给出**关系健康度结论**：健康 / 需警惕 / 高风险
- 提示**安全与自我保护动作**：保留聊天记录、核实身份、勿轻信转账、向亲友同步、必要时报警
- 给出**待办补正清单**：未填项一律按「存疑 / 有风险」处理，绝不判无风险

## 使用方式

把 `templates/关系信息采集表.md` 填好交给本技能，未填项一律按「待补正 / 有风险」处理。

## 边界

本结果依公开的反诈与心理健康常识整理，不替代专业心理咨询、公安机关或司法机关意见，最终以官方认定为准。
**本技能不提供任何心理咨询诊断，不提供约会撮合或情感代理服务**，只做识别指引与自我保护提示。
