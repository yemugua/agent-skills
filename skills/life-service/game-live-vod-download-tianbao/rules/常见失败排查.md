# 游戏直播回放留存与保留期：常见失败与排查

报错信息请**粘贴原文**再对照。写成「下载失败了」没有排查价值，
写成 `HTTP Error 403` 或 `ffmpeg not found` 才能定位。

## 现象 → 原因 → 处理

| 现象关键词 | 原因与处理 |
| --- | --- |
| 回放过期 / 已清理 / 找不到了 | 超过保留期不可恢复，任何工具都无法找回，以后应开播即本地录制。 |
| 没有回放 / 未生成 / 主播关闭 | 主播可能未开启回放生成，或直播异常中断，此时不存在回放文件。 |
| 付费 / 仅粉丝 / 权限不足 | 受限回放不支持下载，需取得主播授权或购买相应服务。 |
| 画质差 / 转码 / 不如直播清晰 | 回放是转码版本，想要原画质需主播提供本地录制文件。 |
| 保留期多久 / 各家一样吗 | 各平台保留期与规则不同，以当期平台规则为准，不要套用别家的天数。 |

## 通用故障（各平台都可能遇到）

| 现象 | 处理 |
| --- | --- |
| 403 / 需要登录 / 机器人验证 | 触发反自动化校验：携带登录态或减少请求频率，不要高频重试 |
| 429 / 频繁 / 限流 | 降低请求频率、分批间隔重试 |
| 404 / 失效 / 不存在 | 链接失效或已删除：让对方重新生成分享 |
| 没有声音 / 无音轨 | ffmpeg 未安装或未合并轨：安装后用 `-f "bv*+ba/b"` 合并 |
| 解析失败 / 格式不支持 | 站点接口变动：把工具升级到最新版，而不是换工具 |
| 超时 / 连接失败 | 检查网络可达性后重试 |

## 排查顺序

1. 先确认网络能访问目标平台
2. 再确认目标内容是否属于可下载范围（回到归属判定）
3. 然后确认工具是最新版
4. 最后才怀疑链接本身

九成的「下载失败」卡在第 1 步和第 2 步，而不是工具坏了。
