# 游戏直播回放留存与保留期：途径、限制与合规边界

## 一、先判定：能不能下

| 归属类别 | 能否下载 | 允许的用途 |
| --- | --- | --- |
| 自有作品 | 可以，优先用原始导出文件 | 任意 |
| 已授权素材 | 可以 | 仅限授权范围内 |
| 作者开放了保存 | 可以，走官方途径 | 个人留存，**不得二次分发** |
| 第三方作品（未授权） | **不建议下载** | 不应用于任何对外场景 |

技术上能不能下载，和法律上能不能用，是两回事。

## 二、途径，按稳定性排序

| 途径 | 操作要点 |
| --- | --- |
| 原文件 | 优先。主播自己开播时的本地录制文件是最完整清晰的来源，若有本地录制，后面几条都不必尝试。 |
| 主播后台留存 | 登录**自己的主播账号**在直播管理里查看回放、录播与数据，可下载或延长保留，这是主播最稳的做法。 |
| 官方回放入口 | 观众端在直播间或个人主页查看回放，取决于主播是否开启回放生成以及是否仍在保留期内。 |
| 本地录制兜底 | 回放未生成或已过期时，唯一补救是以后开播时同步本地录制；已过期的回放无法恢复。 |

## 三、本平台的真实限制

- **三家的保留期与规则不一样**：常见情况是 B站直播回放由主播设置、虎牙与斗鱼各有自己的录播保留窗口，具体天数以平台当期规则为准，不要套用别家经验。
- 回放不是必然生成：主播关闭了回放功能、或直播被中断，就可能根本没有回放。
- **过期不可恢复**：回放超过保留期会被清理，此时任何工具都拿不回来，只能靠提前本地录制。
- 付费直播、仅粉丝可见的回放受访问限制，不支持下载或导出。
- 观众观看的回放画质受转码影响，低于主播本地录制的原始画质。

## 四、画质与水印

- 回放是平台转码版本，画质低于主播本地录制；主播应优先保留开播时的本地录制文件。
- 回放含主播署名与平台标识，转载需取得主播同意，不得去除署名后发布到自己的账号。

## 五、合规红线

1. 不得去除作者署名后二次分发
2. 不得将他人作品搬运至自己的账号（含剪辑、配音后发布）
3. 不得下载或传播私密账号、付费内容
4. 受版权或 DRM 保护的内容不支持下载，也不提供任何破解方法
5. 商用前必须取得书面授权
6. 批量高频抓取可能违反平台服务协议，导致账号受限
