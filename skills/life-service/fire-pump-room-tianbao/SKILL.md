# 消防水泵房与稳压设施（fire-pump-room）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《消防给水及消火栓系统技术规范》GB 50974，生成清单：水泵性能与备用泵、泵房布置与通道、供电与自动启动、稳压装置与压力、巡检测试与记录。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 消防水泵房
- 消防泵
- 稳压泵
- 水泵接合器
- 消防泵房布置

## 三、工作流
1. 核查水泵性能与备用泵配置
2. 核查泵房布置与通道
3. 检查供电与自动启动
4. 校核稳压装置与压力
5. 开展巡检测试并留记录

## 四、核心内容（检查清单与判定）
GB 50974 要求消防水泵应设备用泵、具备自动启动能力并保证可靠供电；泵房布置应便于检修，稳压装置须维持系统压力，巡检与年度检测须留痕。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含水泵性能与备用泵 | 备用泵 |
| Q2 | FAIL | 未含泵房布置与通道 | 布置 |
| Q3 | FAIL | 未含供电与自动启动 | 启动 |
| Q4 | WARN | 未含稳压装置与压力 | 稳压 |
| Q5 | WARN | 未含巡检测试与记录 | 记录 |

> 脚本 `fire-pump-room_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python fire-pump-room_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python fire-pump-room_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
