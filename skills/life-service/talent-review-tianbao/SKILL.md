# 人才盘点（talent-review）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据人才盘点方法论，生成人才盘点清单：盘点范围与标准、绩效-潜力九宫格、校准会、关键岗位风险、个人发展计划(IDP)与梯队建设。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 人才盘点
- 人才校准
- 九宫格
- 人才地图
- 关键岗位风险

## 三、工作流
1. 明确盘点范围与能力/潜力标准
2. 开展绩效-潜力评估与九宫格
3. 组织校准会统一尺度
4. 识别关键岗位风险与高潜
5. 制定IDP与梯队建设举措

## 四、核心内容（检查清单与判定）
人才盘点以绩效与潜力双维度（九宫格）识别人才与风险；经校准会统一评价尺度，并衔接 IDP 与继任/梯队建设。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含盘点范围与标准 | 范围 |
| Q2 | FAIL | 未含绩效-潜力九宫格 | 九宫格 |
| Q3 | WARN | 未含校准会统一尺度 | 校准 |
| Q4 | FAIL | 未含关键岗位风险识别 | 风险 |
| Q5 | WARN | 未含IDP与梯队建设 | 梯队 |

> 脚本 `talent-review_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python talent-review_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python talent-review_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
