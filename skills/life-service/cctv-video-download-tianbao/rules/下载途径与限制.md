# 央视频与央视节目离线留存：途径、限制与合规边界

## 一、先判定：能不能下

| 归属类别 | 能否下载 | 允许的用途 |
| --- | --- | --- |
| 自有作品 | 可以，优先用原始导出文件 | 任意 |
| 已授权素材 | 可以 | 仅限授权范围内 |
| 作者开放了保存 | 可以，走官方途径 | 个人留存，**不得二次分发** |
| 第三方作品（未授权） | **不建议下载** | 不应用于任何对外场景 |

技术上能不能下载，和法律上能不能用，是两回事。

## 二、途径，按稳定性排序

| 途径 | 操作要点 |
| --- | --- |
| 原文件 | 优先。自有或已授权素材用发布前的原始导出文件；普通用户一般不适用，此项主要针对创作者。 |
| 官方离线缓存 | 在央视频 App 内对支持的内容使用离线缓存，只能在官方客户端内观看，缓存文件加密，不能导出成通用视频文件。 |
| 合规替代：投屏观看 | 若目标只是大屏观看，用官方投屏即可，不必纠结拿到文件本身。 |
| 通用命令行工具 | 需 Python + ffmpeg：pip install -U yt-dlp。仅对官方明确公开、允许下载的新闻与纪录片片段有效，付费与会员内容不适用。 |

## 三、本平台的真实限制

- 新闻与大量纪录片具有公共传播属性，官方通常提供保存入口，是最稳妥的留存对象。
- 离线缓存文件加密，只能在官方客户端内观看，无法导出成 mp4。
- 电视剧综艺与体育赛事有版权与回看窗口，过期入口会关闭。
- 央视版权集中，相当比例内容仅取得网络播放权，不授予任何下载权。

## 四、画质与水印

- 新闻与纪录片多为高清源；电视剧综艺画质受转码与网络影响。
- 节目内容含台标与水印，属版权标识，不得去除后二次分发。

## 五、合规红线

1. 不得去除作者署名后二次分发
2. 不得将他人作品搬运至自己的账号（含剪辑、配音后发布）
3. 不得下载或传播私密账号、付费内容
4. 受版权或 DRM 保护的内容不支持下载，也不提供任何破解方法
5. 商用前必须取得书面授权
6. 批量高频抓取可能违反平台服务协议，导致账号受限
