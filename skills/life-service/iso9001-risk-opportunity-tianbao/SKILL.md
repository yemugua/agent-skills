# ISO 9001 风险与机遇应对（iso9001-risk-opportunity）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据 GB/T 19001-2016 / ISO 9001:2015 条款 6.1，生成清单：内外部议题识别、相关方需求识别、风险与机遇清单、应对措施策划、评价有效性。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- ISO 9001 风险管理
- 风险与机遇
- 条款6.1
- 相关方需求识别
- 风险应对措施

## 三、工作流
1. 识别内外部议题
2. 识别相关方及其需求
3. 形成风险与机遇清单
4. 策划应对措施并融入过程
5. 评价措施有效性

## 四、核心内容（检查清单与判定）
条款 6.1 要求组织策划应对风险和机遇的措施，并在体系过程中整合实施；仅有一份风险清单而未落实到过程控制、未评价有效性，是常见不符合原因。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含内外部议题识别 | 议题 |
| Q2 | FAIL | 未含相关方需求识别 | 相关方 |
| Q3 | FAIL | 未含风险与机遇清单 | 清单 |
| Q4 | WARN | 未含应对措施策划 | 措施 |
| Q5 | WARN | 未含有效性评价 | 有效性 |

> 脚本 `iso9001-risk-opportunity_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python iso9001-risk-opportunity_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python iso9001-risk-opportunity_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
