# 知乎视频保存与外链识别：途径、限制与合规边界

## 一、先判定：能不能下

| 归属类别 | 能否下载 | 允许的用途 |
| --- | --- | --- |
| 自有作品 | 可以，优先用原始导出文件 | 任意 |
| 已授权素材 | 可以 | 仅限授权范围内 |
| 作者开放了保存 | 可以，走官方途径 | 个人留存，**不得二次分发** |
| 第三方作品（未授权） | **不建议下载** | 不应用于任何对外场景 |

技术上能不能下载，和法律上能不能用，是两回事。

## 二、途径，按稳定性排序

| 途径 | 操作要点 |
| --- | --- |
| 原文件 | 优先。自有作品用发布前的原始导出文件，画质与音轨完整；若仍在，后面几条都不必尝试。 |
| 创作者中心 | 登录**自己的账号**在创作中心查看自有视频的数据与素材，仅限自己的内容。 |
| App 长按保存 | 知乎 App 内对部分视频长按可保存，取决于作者设置与客户端版本，入口不稳定。 |
| 通用命令行工具 | 需 Python + ffmpeg：`pip install -U yt-dlp`。**外链视频要按源站处理**，直接把知乎链接丢进去常取不到。 |

## 三、本平台的真实限制

- **知乎的视频大量是外链**：回答里嵌入的往往是 B站、腾讯视频、优酷的播放器，所以真正要解析的是源站，不是知乎本体。先确认视频来源再选工具。
- 盐选专栏、付费 Live、私家课等付费内容**不支持下载**，本技能不提供任何绕过方式。
- 回答里的视频常需展开全文或点击播放后才会加载真实地址，直接抓页面源码容易拿到空地址。
- 知乎自己的视频与外链视频的画质上限不同：外链视频的上限由源站决定。
- 视频回答的封面与视频是两回事，封面图可以直接存，视频要另行处理。

## 四、画质与水印

- 外链视频画质由源站决定，知乎自传视频上限取决于作者上传时的码率，下载无法凭空提升。
- 知乎一般不强制叠加水印，但转载他人回答视频须保留作者署名，盐选内容不得外传。

## 五、合规红线

1. 不得去除作者署名后二次分发
2. 不得将他人作品搬运至自己的账号（含剪辑、配音后发布）
3. 不得下载或传播私密账号、付费内容
4. 受版权或 DRM 保护的内容不支持下载，也不提供任何破解方法
5. 商用前必须取得书面授权
6. 批量高频抓取可能违反平台服务协议，导致账号受限
