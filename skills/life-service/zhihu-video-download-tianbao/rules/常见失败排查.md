# 知乎视频保存与外链识别：常见失败与排查

报错信息请**粘贴原文**再对照。写成「下载失败了」没有排查价值，
写成 `HTTP Error 403` 或 `ffmpeg not found` 才能定位。

## 现象 → 原因 → 处理

| 现象关键词 | 原因与处理 |
| --- | --- |
| 外链 / 第三方 / 源站 / bilibili嵌入 | 这是外链视频，请把源站地址取出后按源站的规则处理，不要直接解析知乎链接。 |
| 盐选 / 付费 / 会员 / 充值 | 付费内容受版权与服务协议约束，不支持下载，请通过官方渠道观看。 |
| 地址为空 / 取不到 / 没地址 | 需先播放或展开全文让页面加载真实媒体地址，再重新抓取。 |
| 只有封面 / 封面图 | 拿到的是封面图不是视频，需定位真正的媒体地址。 |
| 登录 / 需要登录态 / 验证 | 部分内容需登录态：`yt-dlp --cookies-from-browser chrome <链接>`，仅限自己的账号。 |

## 通用故障（各平台都可能遇到）

| 现象 | 处理 |
| --- | --- |
| 403 / 需要登录 / 机器人验证 | 触发反自动化校验：携带登录态或减少请求频率，不要高频重试 |
| 429 / 频繁 / 限流 | 降低请求频率、分批间隔重试 |
| 404 / 失效 / 不存在 | 链接失效或已删除：让对方重新生成分享 |
| 没有声音 / 无音轨 | ffmpeg 未安装或未合并轨：安装后用 `-f "bv*+ba/b"` 合并 |
| 解析失败 / 格式不支持 | 站点接口变动：把工具升级到最新版，而不是换工具 |
| 超时 / 连接失败 | 检查网络可达性后重试 |

## 排查顺序

1. 先确认网络能访问目标平台
2. 再确认目标内容是否属于可下载范围（回到归属判定）
3. 然后确认工具是最新版
4. 最后才怀疑链接本身

九成的「下载失败」卡在第 1 步和第 2 步，而不是工具坏了。
