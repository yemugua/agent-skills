# 机构类型与适配

**前置声明**：本表用于理解类型差异与自查适配，**不推荐、不评价任何具体机构**。机构的资质、备案范围与服务能力**以民政部门等主管部门的备案信息、公示信息和当地要求为准**。

## 一、四类机构定位差异

| 类型 | 定位 | 主要收住谁 | 常见要求 |
|---|---|---|---|
| 护理型（护理院、护理中心） | 以医疗护理与长期照护为主 | 重度失能、卧床、压疮风险高、需持续护理者 | 通常要求有相应医疗支持能力，资质与许可范围需核实 |
| 照料型 | 以生活照料与日常照护为主 | 能自理或轻度失能、需要有人帮着起居者 | 重点看起居照护能力与活动安排 |
| 综合型（兼具照料与护理） | 两者兼具，分区或分层提供 | 需求跨度较大、需要后续可能转护理者 | 需确认各分区实际能否提供对应服务 |
| 居家社区养老 | 老人仍住在家里，上门或社区提供支持 | 多数老人首选，能自理或轻度失能 | 重点看上门频次、服务项目与应急响应 |

**判断口径**：很多机构在宣传上会同时使用多个名称，**以主管部门登记与备案的类别和范围为准**，不要以机构自述为准。

## 二、入住前需求清单（先写清楚再选）

| 项 | 要写清什么 |
|---|---|
| 自理程度 | 完全自理 / 部分自理 / 卧床失能 |
| 认知状况 | 认知正常 / 有记忆或识别困难 / 有走失风险 |
| 医疗需求 | 是否需持续医疗支持、是否需定期就医、是否需用药管理 |
| 护理需求 | 翻身拍背、喂饭、擦洗、导管护理等具体项目 |
| 饮食需求 | 普通饮食 / 低盐低糖 / 吞咽困难需特殊处理 / 过敏 |
| 排泄需求 | 是否需导尿管、是否失禁、是否需协助如厕 |
| 预算 | 可承受的月支出与总支出，含一次性费用 |
| 探视距离 | 家属探视的频率与交通成本 |
| 老人意愿 | 是否愿意入住（能表达时必须听取） |

**否定词防误伤**：老人不愿意住不等于不能住，但**必须记录意愿并向机构说明**，否则容易出现抗拒、隐瞒需求、照护配合度差的问题。

## 三、类型适配判断

```
需持续医疗护理、卧床、压疮风险高 → 优先护理型
起居需协助、能基本自理 → 优先照料型
需求跨度大且后续可能转护理 → 优先综合型，但需确认分区实际能力
多数老人希望留在家里 → 优先考虑居家社区养老
```

**注意**：上表是**优先考虑顺序**，不是「只有这一类能收」。实际能否接收、接收条件如何，需向机构与主管部门确认。

## 四、老人意愿的处理

| 情形 | 处理 |
|---|---|
| 老人明确反对 | 不宜强行送入。倾听原因，是怕被抛弃、怕花钱、怕不认得人、还是怕被欺负；针对原因沟通 |
| 老人犹豫 | 增加探访频次、让老人参与选择，带去看环境 |
| 老人同意 | 记录口头同意，入住后持续关注其状态变化 |
| 老人无法表达 | 由家属决定，但要考虑其既往意愿与生活习惯 |

**重要**：住进去之后老人说不舒服、不适应、想回家，这些反应要认真对待，及时与机构沟通调整。

## 五、居家社区养老与机构入住的对比维度

| 维度 | 居家社区养老 | 机构入住 |
|---|---|---|
| 环境熟悉度 | 高 | 需要适应期 |
| 家属参与 | 直接参与照护 | 靠探视与沟通 |
| 应急响应 | 取决于服务方响应能力 | 机构内部处理 |
| 社交 | 取决于社区环境 | 机构安排 |
| 费用结构 | 需逐项确认上门项目与频次 | 需逐项确认床位费与各类附加费 |
| 适合谁 | 能自理或轻度失能、家属能陪伴 | 需要持续照护、家属无法承担照护 |

## 六、需要向民政部门核实的事项（核实前不签约）

1. 机构是否具备相应资质（营业执照、备案信息）
2. 许可与登记范围是否覆盖拟提供的服务类型
3. 收费项目与标准是否在备案或公示范围内
4. 消防与建筑是否符合要求（消防验收或备案、疏散通道）

**核对口径**：以上以主管部门的备案信息、公示信息和当地要求为准。本技能不提供具体机构名单，不编写具体条款号。
