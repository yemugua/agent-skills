# 养老机构十维核查表

每维都要**问出来、记下来、看到证据**，不用印象代替证据。合格与否写「合格 / 待澄清 / 不合格」，待澄清的必须写清由谁在什么时间前答复。

## D1 资质与备案

| 问什么 | 怎么问 |
|---|---|
| 营业执照与备案信息 | 要求出示，或请家属代为向主管部门核实 |
| 登记与备案的服务类型 | 确认是否覆盖拟购买的服务 |
| 是否超范围经营 | 若登记类型不含所购服务，属于重大问题 |

**不合格信号**：拒绝出示、登记范围与所售服务不符、说不清备案情况。

## D2 消防与疏散

| 问什么 | 怎么看 |
|---|---|
| 消防验收或备案情况 | 要求出示相关材料 |
| 疏散通道是否畅通 | **实地看**：杂物堆放、门被堵、锁闭、标识不清 |
| 疏散门与楼梯是否可用 | **实地走一遍** |
| 是否有应急照明与疏散指示 | 看是否有、是否亮 |

**不合格信号**：疏散通道堆物、锁闭、灯不亮、说不清消防情况。

## D3 护理配比与在岗人数

| 问什么 | 怎么看 |
|---|---|
| 承诺的护理员与老人比例 | 要求给出具体数字 |
| 夜班在岗人数 | 问夜班几个人 |
| 实际在岗而非编制 | **实地数**：在岗几个人、分别在照顾谁 |
| 护理员资质与培训 | 问是否持证、是否定期培训 |

**不合格信号**：只说编制不谈在岗、说不出具体数字、夜班无人在岗。

## D4 床位与房间条件

| 问什么 | 怎么看 |
|---|---|
| 登记床位数与实际入住数 | **实地看房间与加床情况** |
| 房间人数 | 数一数实际住了几个人 |
| 床间距与过道宽度 | 看轮椅能否通过、能否翻身 |
| 床的高度、有无护栏 | 看是否符合失能老人使用 |
| 有无独立卫生间 | 影响如厕安全与失禁管理 |
| 通风、采光、室温 | 实地感受 |

**不合格信号**：加床严重、超员、床间距过窄、无护栏、房间拥挤。

## D5 医疗支持

| 问什么 |
|---|
| 是否有医生定期巡诊、巡诊频次 |
| 突发情况的处理流程与转诊渠道 |
| 用药管理方式（谁发药、谁记录、有无台账） |
| 是否能对接家属指定的医院 |
| 有无急救设备与人员 |

**不合格信号**：说不清转诊流程、用药无台账、无任何急救设备。

## D6 膳食

| 问什么 |
|---|
| 供餐次数、能否满足个别需求 |
| 低盐低糖、素食、吞咽困难餐能否安排 |
| 过敏与非整吞咽情况如何处理 |
| 营养配餐的依据 |
| 每天的菜单能否提前看到 |

**不合格信号**：说不清特殊饮食如何安排、无菜单、无法提供低盐低糖。

## D7 收费结构与隐性收费

| 问什么 |
|---|
| 月费包含哪些项目（逐项问清） |
| 不包含哪些项目（最关键） |
| 护理费、餐费、耗材费、药费、特殊护理费如何计 |
| 押金金额与退还条件 |
| 一次性费用（床位费、押金、服务费） |
| 费用调整的条件与幅度 |

**不合格信号**：只报一个月费总数、不愿逐项说明、口头说「都包含」但不写进合同。

## D8 退住与退费条款

| 问什么 |
|---|
| 老人或家属可主动退住的条件 |
| 是否需要提前申请、提前多久 |
| 退费期限与计算方式 |
| 可扣项目有哪些 |
| 押金退还的时间与流程 |
| 生病、去世等特殊情形的处理 |

**不合格信号**：拒绝写入合同、只说「按规定退」、退费时间模糊。

## D9 探视与投诉渠道

| 问什么 |
|---|
| 探视时间与方式 |
| 家属能否随时到院 |
| 投诉受理人与流程 |
| 是否有书面投诉记录 |
| 紧急情况如何第一时间联系家属 |

**不合格信号**：限制探视、不说明投诉渠道、无紧急联系方式。

## D10 老人意愿与家属参与

| 问什么 |
|---|
| 入住前是否安排家属考察与老人参观 |
| 老人可否参与选择房间与床位 |
| 入住后多久有一次家属沟通 |
| 家属能否参与照护方案制定 |

**不合格信号**：拒绝家属参与、强制入住、沟通无固定安排。

## 十维汇总口径

| 结论 | 条件 |
|---|---|
| 可进入签约环节 | D1 资质已核实、D2 消防合格、D7 收费清晰、D8 退住条款明确，其余无「不合格」 |
| 需继续澄清 | 存在「待澄清」项且已明确责任人与答复时间 |
| 不建议签约 | 存在任一「不合格」项，尤其是 D1、D2、D3、D8 |

**否定词防误伤**：单项「待澄清」不等于机构不行，但**未澄清前不得签约**；「机构宣传与备案不一致」属于 D1 不合格，不能用其他维度的优点抵消。
