# 探访实查、资质核实与合同必看条款

## 一、探访实查五看（用眼睛和鼻子，不只听介绍）

### 一看：闻气味

- 走廊、房间、卫生间、洗衣区分别闻
- 有没有霉味、尿味、汗味久不散、消毒水刺鼻味
- 房间闷不通风时气味会更明显

**异常信号**：整栋都是尿味或霉味；卫生间味道特别大而排风不畅；进入房间即有明显异味。

### 二看：看皮肤

看老人**手背、脚背、骶尾部（腰下面）、足跟、肛周**：

| 观察部位 | 正常与异常 |
|---|---|
| 手背、脚背 | 有无红斑、破损、瘀斑、水疱 |
| 骶尾部 | 有无压疮红斑、破溃、已愈合的瘢痕 |
| 足跟 | 长期卧床者最易出问题，是否有红斑或已破 |
| 肛周 | 有无红肿、破损（提示失禁管理不到位） |
| 指甲 | 是否过长、有无嵌甲（提示基础照护不足） |
| 衣被 | 是否潮湿、脏、有无尿渍 |

**口径说明**：皮肤状况是最直接的照护质量证据。有压疮和反复失禁痕迹，说明减压与失禁管理没做到位。

### 三看：看翻身痕迹

| 看什么 | 怎么判断 |
|---|---|
| 卧床老人的受压部位 | 有无压疮、有无定时变换体位的痕迹 |
| 床单是否干燥平整 | 是否尿湿未换、是否皱褶堆叠 |
| 体位是否摆放到位 | 侧卧是否两腿夹枕、足跟是否悬空、上侧肢体是否置于胸前 |
| 有无翻身记录 | 问记录在哪、能否看到 |

**异常信号**：卧床老人皮肤完好但说不清翻身安排；床单长期潮湿；看不到任何记录。

### 四看：看消防通道

- 从入口一路走到最里面，看疏散通道、楼梯口、消防栓
- 有没有杂物堆放、临时搬来的桌椅、床垫、纸箱
- 门有没有被锁闭或用东西挡住
- 疏散指示灯与应急照明是否亮
- 消防通道标识是否清楚

**这是最容易被忽略也最致命的一项**。平时看不出问题，着火时是致命的。

### 五看：看是否超员

| 看什么 | 怎么判断 |
|---|---|
| 登记床位数与实际入住数 | 两相对照 |
| 房间实际住几个人 | 实地数 |
| 有无加床 | 看房间与走廊 |
| 护理员与老人比例 | 数在岗人数、推算比例 |

**异常信号**：明显加床；护理员明显少于承诺；一个护理员同时照顾人数远超承诺。

## 二、资质核实清单（向民政部门等有关部门核实，未核实不签约）

| 项 | 核实方式 |
|---|---|
| 营业执照与备案信息 | 请家属代为核实或要求出示 |
| 登记与备案的服务类型 | 确认覆盖拟购服务 |
| 是否超范围经营 | 对照登记类型与所售服务 |
| 收费项目与标准是否在备案或公示范围内 | 索取公示信息 |
| 消防与建筑是否符合要求 | 核实消防验收或备案、疏散通道 |

**口径**：以主管部门的备案信息、公示信息和当地要求为准。本技能不提供具体机构名单，不编写具体条款号。

## 三、隐性收费识别方法

**核心方法：问「不包含哪些」，比问「包含哪些」更有效。**

### 逐项追问清单

| 追问项 | 为什么必须问 |
|---|---|
| 护理费按什么标准收（分级、分项目） | 分级标准差异大 |
| 餐费是否包含在月费里 | 常见独立计费 |
| 耗材费（尿垫、护理垫、纸巾等） | 常被说成「另算」 |
| 药费由谁买、能否代买 | 代买有服务费 |
| 特殊护理费（翻身、拍背、导管护理） | 按次或按月 |
| 洗护费、理发费 | 小额但持续 |
| 陪同就医、接送费 | 按次计 |
| 水电费 | 有时全包，有时另算 |
| 床位费、押金、服务费 | 一次性费用 |
| 退住时的清洁费、损耗费 | 退住时最容易起争议 |

### 识别四个信号

1. **只报一个月费总数，不愿逐项说明** —— 直接要求书面明细
2. **口头说「都包含」但不写进合同** —— 一律按不含处理
3. **收费标准说「按规定」但不说明具体文件** —— 要求写明具体内容并留存
4. **报价与其他机构不可比** —— 按同一口径逐项对比后再比

## 四、合同七项必看条款

| 序 | 条款 | 必须写清什么 | 含糊表述的风险 |
|---|---|---|---|
| 1 | 收费项目与标准 | 逐项列出、单价或计算方式、是否包含 | 只写一个总数，出现分歧时无法主张 |
| 2 | 费用调整 | 调整的条件、幅度、是否需提前通知 | 机构可随时涨价 |
| 3 | 退住条件 | 老人或家属可主动退住的条件、是否需提前申请及提前多久 | 口头「随时可退」但合同要求提前三个月 |
| 4 | 退费规则 | 退费期限、计算方式、可扣项目 | 只写「按规定退」，无法执行 |
| 5 | 护理等级变更 | 等级如何划分、变更的条件、变更后费用调整、变更由谁提出 | 需要升级护理时费用争议 |
| 6 | 意外责任划分 | 跌倒、烫伤、误吸、丢失等情形的责任划分与处理 | 出事后责任不清 |
| 7 | 解除与终止 | 双方均可解除的条件、通知方式、后果 | 机构单方解除无依据 |

### 合同签订前的补充动作

- [ ] 所有口头承诺已写入合同或补充约定
- [ ] 未澄清的问题已写明责任人与答复时间
- [ ] 附件齐全：收费明细表、服务协议、护理等级标准
- [ ] 双方签字或盖章，**一式多份，家属持一份**
- [ ] 重要变更须书面形式，不接受只口头通知
- [ ] 重大合同建议由律师审阅

**口径**：合同效力与法律后果**以现行法律规定和合同约定为准**，重大合同建议由律师审阅。本技能不代替律师出具法律意见。

## 五、入住后复查节奏

| 时点 | 复查内容 |
|---|---|
| 入住第 1 周 | 适应情况、有无明显情绪问题、皮肤状况、进食与睡眠 |
| 每月 | 皮肤状况、翻身记录、用药台账、体重与进食、体重变化趋势 |
| 每季度 | 收费核对（有无额外收费）、护理等级是否需调整、探视沟通 |

**记录要求**：每次复查留书面或可查的记录，发现问题及时沟通。

## 六、出现问题的处理顺序

1. 先与机构沟通并留记录
2. 涉及照护失当、安全事故、虐待的，同步向当地主管部门反映
3. 需要时咨询律师
4. 需要时联系媒体或相关社会组织（视情形）

**口径**：本技能不代替主管部门认定，也不代替法律程序。
