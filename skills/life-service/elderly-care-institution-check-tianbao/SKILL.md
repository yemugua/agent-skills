# 养老机构选择与合同核查

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 按类型、维度、条款、探访四层给出核查清单 | 推荐或评价具体养老机构的资质、口碑 |
| 说明各类机构的定位差异与适合人群 | 代替民政部门确认备案状态与许可范围 |
| 列出收费结构与隐性收费的识别方法 | 给出具体价格标准、补贴金额或机构报价 |
| 给出合同必看条款与谈判要点 | 代替律师审合同或出具法律意见 |
| 给出探访实查的具体观察方法 | 组织或代替家属突击检查、代为投诉 |
| 说明退住与退费条款应如何核对 | 判定退费金额、退费条件是否合法合规 |

**必须向民政部门或有关部门核实、核实前不签约的事项**

- **机构是否具备相应资质**：营业执照、备案信息、许可范围是否覆盖拟提供的服务类型
- **拟委托的护理服务是否超出该机构的登记与备案范围**
- **收费项目与标准是否在备案或公示范围内**
- **消防与建筑是否符合要求**：消防验收或备案情况、疏散通道是否合规

**核对口径**：以上事项**以民政部门等主管部门的备案信息、公示信息和当地要求为准**。本技能不提供具体机构名单、不对任何机构做评价，也不编写具体条款号。

| 用户说法 | 用不用 |

| 「这家养老院靠不靠谱」 | 用，探访实查五看 + 资质核实 |
| 「养老院收费怎么算」 | 用，收费结构与隐性收费识别 |
| 「合同里要注意什么」 | 用，合同七项必看条款 |
| 「退住能退钱吗」 | 用，退住与退费条款核对口径 |

| 「补贴怎么申请」 | 只说明需向有关部门咨询，不给金额与流程承诺 |

## 三、完整工作流

1. **先定需求**：老人的身体状况、自理程度、认知状况、饮食与医疗需求、预算、家属探视距离。
2. **定类型**：按 `rules/机构类型与适配.md` 匹配护理型、照料型、综合型、居家社区养老四类。
3. **资质核实**：把需向民政部门核实的事项列成清单，未核实不进入签约环节。
4. **十维核查**：按 `rules/十维核查表.md` 逐项问、逐项记，不用印象代替证据。
5. **探访实查**：按 `rules/探访实查与资质核实.md` 的五看清单实地观察，不做突击式检查。
6. **收费结构测算**：用 `templates/费用与合同核查表.md` 算清月支出与总支出，识别隐性收费。
7. **合同必看**：七项必看条款逐条核对，未澄清的写进补充约定。
8. **定复查节奏**：入住后按周、按月复查并记录。

## 四、核心规则与要件库

生成任何核查建议前，**必须先读**：

- `rules/机构类型与适配.md`：四类机构差异、需求清单、适配判断、老人意愿优先口径。
- `rules/十维核查表.md`：十个核查维度、每维的提问口径与不合格信号。
- `rules/探访实查与资质核实.md`：五看清单、资质核实清单、隐性收费识别、合同必看条款。

不得推荐或评价具体机构；不得给出价格标准、补贴金额与退费金额；不得代替律师审合同。所有资质与政策口径**以民政部门等主管部门的备案信息、公示信息和当地要求为准**。

## 五、脚本用法

```
python scripts/institution_cost_calc.py --file case.json
python scripts/institution_cost_calc.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`type` 机构类型（`nursing` `care` `integrated` `community`），`base_fee` 月基础费用，`extra` 附加项数组（`name` `monthly` `onetime`），`deposit` 押金，`months` 入住月数，`rates` 未来费用涨幅（可选），`red_flags` 核查发现的问题标记 |
| `--contract` | 只输出合同必看条款与退住核对清单 |
| `--json` | 以 JSON 输出 |
| `--out` | 结果写入指定文件，默认 `scripts/_last_result.txt` |
| `--selftest` | 运行自检 |

脚本输出月支出与总支出测算、隐性收费提示、合同核对清单。**脚本不给机构评价、不给价格标准、不给退费金额结论。**

## 六、人工确认清单

- [ ] 资质已向民政部门核实，未核实不签约
- [ ] 服务类型未超出机构登记与备案范围
- [ ] 十维核查已逐项记录，不用印象代替证据
- [ ] 已实地探访并按五看清单记录（用鼻子闻、用眼睛看，不只看口头介绍）
- [ ] 已核查护理配比是否与承诺一致
- [ ] 已核查消防通道是否畅通、是否被堵
- [ ] 已确认是否存在超员与临时加床
- [ ] 月支出与总支出已测算，含一次性费用
- [ ] 隐性收费项目已逐项问清并写进合同
- [ ] 合同七项条款已逐条核对，未澄清项写进补充约定
- [ ] 退住与退费条件已明确写明，不是口头承诺
- [ ] 老人本人意愿已听取（能表达时）
- [ ] 家属已约定入住后的复查节奏

## 七、最常见的坑

1. **只看装修和宣传**：装修新不代表管理好。实看要看皮肤状况、看消防通道、看是否超员。
2. **信口头承诺不写进合同**：口头说「随时可以退」，合同里写「需提前三个月申请」或不提，就是坑。口头承诺一律落纸。
3. **忽略隐性收费**：床位费之外的护理费、餐费、耗材费、药费、特殊护理费往往才是大头，入住前必须逐项问清并写明。
4. **不查消防通道**：很多机构把杂物堆在疏散通道。平时看不出问题，着火时是致命的。探访时必看。
5. **不数人头算护理配比**：承诺的护理员与实际在岗人数往往不同。探访时看在岗的有几个人、分别在照顾谁。
6. **不看皮肤状况**：探访时看老人手背、脚背、骶尾部有没有红斑、压疮、有没有破皮。皮肤状况是最直接的照护质量证据。
7. **签了不看退费条款**：退住条件、退费期限、可扣项目、退费比例必须写清。含糊表述最容易在退住时出问题。
8. **不核实备案就签约**：机构登记范围不覆盖所购服务，或资质不合规。
9. **超员**：床位已满还继续收，护理质量必然下降。问清楚实际入住人数与登记床位数。
10. **老人本人不同意就送进去**：能表达意愿的老人应听取本人意见，否则容易抗拒，照护反而更困难。
11. **比价格不比对价口径**：不同机构报的「月费」包含的项目可能完全不同，必须按同一口径逐项对比。
12. **入住后不复查**：合同签完不代表结束。入住后按周、按月观察，发现问题及时沟通并留记录。

## 八、边界与免责

本技能提供养老机构选择、核查与合同条款参考，**不推荐或评价任何具体机构，不给出价格标准、补贴金额、机构报价，也不判定退费金额是否合法合规**。机构的资质、备案范围、消防与建筑合规性、收费项目与标准**以民政部门等主管部门的备案信息、公示信息和当地要求为准**；合同效力与法律后果**以现行法律规定和合同约定为准**，重大合同建议由律师审阅。入住后出现安全事故、虐待或严重照护失当等情况，应及时向机构、当地主管部门反映。本技能不替代法律意见与主管部门认定。
