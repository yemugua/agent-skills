# 压力容器定期检验周期与到期判定规则

> 以下为通行实务口径。**具体检验周期以现行安全技术监察规程和检验机构出具的检验报告载明周期为准**，本文件不引用具体条款号。任何情况下，使用单位不得自行延长检验周期。

## 一、三类"检查/检验"不要混淆

| 名称 | 谁来做 | 周期 | 能不能替代定期检验 |
|---|---|---|---|
| 年度检查 | 使用单位自行组织实施，也可委托检验机构 | 每年至少一次 | ❌ 绝对不能替代 |
| 定期检验（全面检验） | 具备核准资质的特种设备检验机构 | 按安全状况等级确定（3~6 年） | — |
| 耐压试验 | 检验机构 | 一般在两次全面检验期间内至少一次，长期未做的按规程与检验机构要求 | ❌ 不能替代全面检验 |

**防误伤**：台账上写着"今年做了年度检查"不等于"定期检验已做"。监督检查时这两项分别查。

## 二、定期检验周期判定表（按安全状况等级）

| 安全状况等级 | 含义 | 一般检验周期 | 使用限制 |
|---|---|---|---|
| 1 级 | 无缺陷或缺陷轻微 | 一般 6 年 | 正常使用 |
| 2 级 | 存在一般缺陷，不影响安全使用 | 一般 6 年 | 正常使用 |
| 3 级 | 存在较严重缺陷，需监控或修理 | 一般 3~6 年（**保守按 3 年**） | 可监控使用，需缩短周期复查 |
| 4 级 | 存在严重缺陷，不能保证安全使用 | 由检验机构确定，且**累计监控使用时间不得超过 3 年** | 必须监控使用，限期处理缺陷 |
| 5 级 | 存在危及安全的缺陷 | 不得继续使用 | 必须处理缺陷（修理/改造/报废），处理后重新检验定级 |

**判定顺序**：先取上次检验报告载明的安全状况等级 → 按表定周期 → 若检验报告明确写了下次检验日期，**以报告写明的日期为准**（优先于按等级推算）。

## 三、首次检验与后续检验

| 环节 | 口径 |
|---|---|
| 首次全面检验 | 一般在新压力容器投入使用后 **3 年内**进行 |
| 投用未满 3 年 | 按投用日期 + 3 年推算首次到期日 |
| 投用满 3 年及以上未检 | 已超期，应立即停用并申报检验 |
| 移装/过户后 | 应重新确认检验有效期，通常需在使用登记变更后按原周期执行 |
| 停用超过 1 年重新启用 | 重新启用前应进行定期检验（按现行要求执行） |
| 改造、重大修理后 | 应进行检验，必要时进行耐压试验 |

## 四、安全附件与仪表的校验周期

| 附件/仪表 | 周期 | 谁来做 | 超期后果 |
|---|---|---|---|
| 安全阀 | **每年至少校验一次**（整定压力、密封性） | 有资质的校验机构/使用单位具备条件的校验站 | 超期未校验的，整台设备不得投入使用 |
| 压力表 | **每半年至少检定一次**（强制检定计量器具） | 法定计量检定机构或授权机构 | 超期未检定不得使用 |
| 爆破片装置 | 按制造单位规定或使用工况定期更换，通常 2~3 年 | 使用单位 | 超期未更换视为安全附件失效 |
| 液位计、温度计 | 按使用工况与制造单位要求定期校验 | 使用单位或校验机构 | 影响参数监控 |
| 紧急切断装置 | 按制造单位要求定期功能试验 | 使用单位 | 应急功能失效 |

**注意**：安全附件超期未校验是现场检查中最常见、也最容易整改的问题，但它会导致整台设备被判定为不具备使用条件，不能当作小事。

## 五、到期预警分级（按剩余天数）

| 剩余天数 | 等级 | 动作 |
|---|---|---|
| > 180 天 | 正常 | 纳入年度计划 |
| 91 ~ 180 天 | 关注 | 开始准备停机、清洗、置换方案 |
| 31 ~ 90 天 | 预警 | 联系检验机构申报，安排停机窗口 |
| 1 ~ 30 天 | 紧急 | 立即申报并确定检验日期 |
| ≤ 0 天 | **已超期** | **立即停止使用**，停用挂牌，申报检验 |

**超期未检的处理**：不得继续使用。停用 → 挂牌标识 → 向检验机构申报 → 检验合格后方可恢复使用。监管部门发现使用未经定期检验或检验不合格的压力容器，可责令停止使用并依法处理。

## 六、检验前准备工作清单

| 项目 | 要求 |
|---|---|
| 停机与隔离 | 切断与系统连接，加装盲板，挂牌上锁 |
| 置换与清洗 | 按介质性质置换、吹扫、清洗，必要时蒸煮 |
| 取样分析 | 可燃气体、氧含量、有毒气体分析合格（受限空间作业要求） |
| 通风与照明 | 强制通风，安全电压照明 |
| 监护 | 设专人监护，配备防护用品与应急救援器材 |
| 资料准备 | 产品合格证、制造监督检验证书、使用登记证、上次检验报告、运行与检修记录、修理改造资料、安全附件校验报告 |
| 拆除保温与搭脚手架 | 按检验要求拆除局部保温层，搭设检验用脚手架 |

## 七、检验结论的三种表述（不要一律当成"合格"）

| 结论 | 含义 | 能不能用 |
|---|---|---|
| 符合要求 | 可继续使用 | ✅ |
| 基本符合要求 | 有缺陷但可在限制条件下监控使用，**必须执行报告载明的限制条件与缩短的周期** | ⚠️ 有限制条件 |
| 不符合要求 | 不得继续使用 | ❌ |

**防误伤**：把"基本符合要求"当成"合格"，忽略报告里"降压至 X MPa 使用""监控使用期限不超过 X 个月"的限制条件，是典型的事故前兆。

## 八、一台一档（台账必备字段）

| 字段 | 说明 |
|---|---|
| 设备名称、编号、位号 | 与铭牌一致 |
| 产品编号、制造单位、制造日期 | 与产品合格证一致 |
| 使用登记证编号 | 与登记证一致 |
| 投用日期 | 首次投入使用日期 |
| 设计压力/温度、介质、容积 | 与设计文件或铭牌一致 |
| 上次全面检验日期、安全状况等级、下次检验日期 | **以报告为准** |
| 上次年度检查日期 | 每年一次 |
| 上次耐压试验日期 | 按周期 |
| 安全阀校验日期、压力表检定日期 | 1 年 / 半年 |
| 停用、启用、改造、过户、报废记录 | 全生命周期 |

## 九、高频问题速查

| 现象 | 常见原因 | 处置方向 |
|---|---|---|
| 检验到期但生产不能停 | 未提前纳入计划 | 提前 90 天排产，备机或系统切换 |
| 检验机构说要先处理缺陷才能出报告 | 存在 4 级缺陷 | 按报告要求修理后复检 |
| 台账周期与报告不一致 | 安全状况等级变更后未更新台账 | 以最近一次报告为准更新 |
| 安全阀校验了但整台还是被判不合格 | 本体存在缺陷 | 安全附件不是全部，本体检验单独判定 |
| 停用设备要不要检 | 停用期间可不检 | 重新启用前应检验并办理启用手续 |
| 翻新/二手设备无资料 | 资料缺失 | 补齐资料并进行检验、必要时重新登记 |
