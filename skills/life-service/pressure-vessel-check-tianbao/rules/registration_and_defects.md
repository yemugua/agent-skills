# 压力容器使用登记、变更手续与常见缺陷处置

> 登记机关为特种设备使用登记部门（市场监管部门）。**办理时限、材料清单以当地登记机关公示为准**，本文件只给通行口径，不引用具体条款号。

## 一、使用登记

| 环节 | 口径 |
|---|---|
| 登记时点 | 在压力容器投入使用**前**或投入使用后 **30 日内**办理使用登记 |
| 登记结果 | 取得使用登记证（或电子证照）与使用登记编号 |
| 标志张贴 | 使用登记标志应置于该设备的显著位置 |
| 未登记后果 | 不得投入使用；监管部门可责令限期改正、停止使用并依法处理 |

登记材料常见清单（以当地要求为准）：

| # | 材料 |
|---|---|
| 1 | 使用登记表（加盖使用单位公章） |
| 2 | 使用单位统一社会信用代码证明（营业执照等） |
| 3 | 产品合格证、产品数据表 |
| 4 | 制造监督检验证书 |
| 5 | 安装/改造/重大修理监督检验证书（如适用） |
| 6 | 特种设备作业人员证（安全管理人员与操作人员） |
| 7 | 安全管理制度、操作规程、应急预案 |
| 8 | 进口设备的进口批准文件（如适用） |

## 二、变更手续对照表

| 情形 | 手续 | 时限口径 | 特别注意 |
|---|---|---|---|
| 移装（本单位内部改变使用地点） | 办理使用登记变更 | 按当地要求及时办理 | 移装后应确认检验有效期 |
| 过户（转移给其他单位） | 原使用单位办理注销，新使用单位办理登记 | 变更后 30 日内（以当地要求为准） | 必须把全部技术档案随设备移交，档案缺失会导致无法登记 |
| 改造、重大修理 | 施工前告知，施工后经监督检验，办理变更 | 按当地要求 | 改变主要受压元件的需重新核验参数 |
| 停用 | 办理停用手续，设备挂牌、切断电源/介质 | 停用超过 1 年应办理 | 停用期间不安排定期检验 |
| 重新启用 | 办理启用手续，**启用前应进行定期检验** | 启用前 | 停用期间超过检验周期的，必须检验合格后方可启用 |
| 报废 | 办理使用登记注销，去功能化处理 | 报废后及时办理 | 不得转让、不得继续使用、不得拆除后私自转卖 |
| 单位名称/地址变更 | 办理登记信息变更 | 变更后 30 日内 | 与营业执照同步 |

## 三、常见缺陷与处置方向

| 缺陷类型 | 典型表现 | 检验机构常见处置 | 使用单位动作 |
|---|---|---|---|
| 均匀腐蚀减薄 | 壁厚实测值低于设计壁厚 | 强度校核；可降压使用或缩短周期；严重的判 4/5 级 | 做壁厚监测点，控制介质腐蚀性 |
| 局部腐蚀、点蚀 | 局部深坑 | 打磨圆滑过渡后复测；超标补焊或挖补 | 排查积水部位、保温层下腐蚀 |
| 裂纹 | 表面/埋藏裂纹 | 打磨消除（深度受限）、补焊、局部挖补；严重判 5 级 | 排查应力集中、疲劳、湿硫化氢环境 |
| 鼓包、变形 | 局部凸起、椭圆度超标 | 强度校核；一般判 4 级或 5 级 | 排查超压、超温、液位失控 |
| 泄漏 | 法兰、接管、密封面渗漏 | 紧固、换垫、补焊 | 排查预紧力、垫片选型、热应力 |
| 焊缝缺陷 | 未熔合、未焊透、气孔超标 | 按规程评定，超标需返修 | 返修方案须经技术负责人批准 |
| 绝热层/防腐层损坏 | 保温脱落、外腐蚀 | 修复绝热与防腐层，检查本体 | 建立保温层下腐蚀检查计划 |
| 安全附件失效 | 安全阀超期、压力表损坏 | 整台设备判定为不具备使用条件 | 立即校验或更换，不得带病运行 |
| 支座、基础问题 | 下沉、倾斜、螺栓松动 | 修整基础，紧固 | 纳入日常巡检 |

**判定原则**：缺陷处置方案由检验机构与原制造单位或有资质的修理单位确定；**任何修理、改造都必须在施工前履行告知手续，施工后经监督检验**，不得私自焊接补焊后继续投入使用。

## 四、日常巡检与年度检查要点

| 项目 | 检查内容 |
|---|---|
| 本体 | 有无变形、泄漏、异常振动、异常声响、外腐蚀 |
| 绝热层/防腐层 | 完好性、有无脱落、有无积水 |
| 安全附件 | 安全阀铅封完好、在校验有效期内；压力表在检定有效期内、指示正常 |
| 参数 | 压力、温度、液位是否在规定范围内，有无超压超温记录 |
| 连接部位 | 法兰、螺栓、阀门有无渗漏 |
| 基础与支座 | 有无下沉、倾斜、松动 |
| 运行记录 | 压力温度记录完整、异常工况有记录与处置 |
| 人员 | 作业人员持证上岗，证书在有效期内 |

## 五、常见违规情形（监督检查高频处罚项）

| 违规 | 表现 |
|---|---|
| 使用未取得使用登记的压力容器 | 无登记证、登记标志未张贴 |
| 使用未经定期检验或检验不合格的设备 | 检验报告超期、结论"不符合要求"仍在使用 |
| 安全附件超期未校验 | 安全阀超过 1 年未校验、压力表超过半年未检定 |
| 作业人员无证上岗 | 操作人员、安全管理人员未持证 |
| 私自修理改造 | 未告知、未监督检验即焊接修补 |
| 停用设备未办理手续 | 长期停用无记录，重新启用未检验 |
| 报废设备未注销 | 仍挂在台账上或已拆除未注销 |
| 台账与实物不符 | 设备位号、编号、数量对不上 |

## 六、防误伤清单

1. **"做了年度检查"≠"做了定期检验"**，两者分别考核
2. **"检验合格"≠"无限制使用"**，"基本符合要求"有监控条件与缩短周期，必须执行
3. **"安全附件合格"≠"本体合格"**，本体有缺陷时附件再好也不能用
4. **"停用"≠"免检"**，重新启用前必须检验
5. **"未到期"≠"可以延"**，检验周期只能由检验机构确定，使用单位不得自行延长
6. **"过户了"≠"档案可以不交"**，技术档案缺失会导致新使用单位无法登记
7. **"修好了"≠"能用了"**，重大修理后须经监督检验合格
