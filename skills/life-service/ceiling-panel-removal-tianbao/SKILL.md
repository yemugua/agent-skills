# 集成吊顶扣板拆卸与检修口开设（ceiling-panel-removal）

集成吊顶最大的优势就是**每一块扣板都能单独拆下来**，所以大多数情况下根本不需要"开检修口"——拆下需要检修位置的那几块板就够了。而在动手之前，第一件事永远是**断电验电**，因为吊顶里最常出事的不是扣板，是浴霸和照明的接线。

这个技能做四件事：**断电** → **拆板** → **检修** → **回装**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 指导扣板与电器模块的拆装顺序 | ❌ 认定"吊顶有问题就要整片拆掉" |
| 说明检修口的位置选择 | ❌ 在龙骨、扣板上悬挂重物或站人 |
| 提示断电验电与燃气处置 | ❌ 指导带电接线或改动配电回路 |
| 判断什么情况必须停用报修 | ❌ 替代水管维修、燃气作业与防水施工 |
| 给出回装与验收清单 | ❌ 保证拆装后一定恢复如初 |

**遇到以下情况，立即停止自行操作，转交专业人员：**

- 需要**新增回路、改动接线、更换配电箱内器件**（属电工作业）
- 吊顶上方有**燃气管道、燃气热水器排烟管**，或**闻到燃气味**
- 吊顶上方漏水来源不明，或涉及楼上住户与公共管道
- 需要大面积拆装、龙骨锈蚀变形、扣板大面积损坏
- 作业高度超过 2 米，或需要站在人字梯最高两档
- 浴霸、换气扇的接线端子有**烧蚀、熔化、焦味**

**闻到燃气味时**：立即开窗通风、关闭燃气阀门、**不触碰任何电器开关**（包括门铃与手机除外，拨打燃气公司电话要到户外）。

## 二、完整工作流

```
第 1 步  断开浴霸与照明回路的空开，验电笔确认无电
第 2 步  确认吊顶上方有没有燃气管、水管、电线，规划要拆的板块
第 3 步  先读规则文件 rules/ceiling_panel_rules.md（拆装顺序 + 红线 + 检修口）
第 4 步  跑故障树脚本
    python scripts/ceiling_panel_check.py --text "吊顶上有水渍，想拆开看看是不是楼上的问题"
第 5 步  用吸盘或撬片拆板，拆下的板平放，边缘锋利戴手套
第 6 步  检修或拆换电器模块（先拍照记接线，再拆线）
第 7 步  回装扣板，确认卡紧，恢复供电后逐项验收
```

## 三、扣板拆卸手法（不要用蛮力）

| 方法 | 操作 | 适用 |
|---|---|---|
| 吸盘法 | 玻璃吸盘或吸盘挂钩吸住板面中部，垂直向下轻拉 | 首选，最不容易变形 |
| 撬片法 | 薄撬片从板缝插入，轻轻撬动一角，手指扣住边缘下拉 | 板缝较紧时 |
| 胶带法 | 宽胶带粘住板面中部，向下拉 | 临时没有吸盘时 |
| 划缝法 | 用薄刀片沿板缝划一圈 | 被油漆或胶粘连时先划开再吸 |

**关键提醒**：扣板大多是卡在三角龙骨上的，**垂直向下轻拉**即可脱开。硬撬会让扣板永久变形，装回去后卡不紧、会掉。

**拆不下来最常见的原因**：卡扣紧、板缝被油漆或密封胶粘住。先用薄片沿缝划开，再用吸盘拉，不要直接撬角。

---

## 四、电器模块拆装顺序（浴霸、换气扇、灯具）

1. **断电**：断开对应回路空开，**验电笔确认无电**（不能只靠关开关）
2. **拆面板**：照明与换气扇面板多为卡扣或螺丝固定，先取下面板
3. **拍照**：接线方式拍照留存，**标注火线、零线、地线**
4. **拆线**：松开接线端子取线，不要硬拽电线
5. **取模块**：拆弹簧卡或固定螺丝，双手托住模块缓慢取下
6. **装新模块**：按相反顺序回装，**先接好线再固定**
7. **绝缘**：线头压接牢固并用绝缘胶带包好，不留裸露铜线
8. **恢复供电**：合上空开，逐项测试照明、取暖、换气

> **接线端子有烧蚀、熔化、焦味时不要继续使用**，这是接触不良过热的痕迹，应请电工处理。

---

## 五、检修口：多数情况不需要专门开

| 情形 | 做法 |
|---|---|
| 只是临时查看或检修一次 | **拆下对应位置的 1-2 块扣板即可**，无需专门开检修口 |
| 需要经常检修某个阀门或接头 | 把该处扣板换成带框的**活动检修板**（磁吸或卡扣式） |
| 吊顶是石膏板等不可拆材质 | 需开孔锯开孔并加装成品检修口边框，请专业人员 |
| 需要长期预留检修通道 | 安装成品铝合金检修口边框并加固周边龙骨 |

**关键认知**：集成吊顶本身就是"每块都能拆"的结构，**为了检修而专门开一个口是没必要的**。需要反复检修时，把那块板换成活动检修板即可。

---

## 六、检修口位置选择（确实要开时）

1. 先确认上方要检修的**具体设备位置**（水管接头、阀门、电线接头、排烟管接口）
2. 选择该设备**正下方或侧下方**的扣板位置
3. 一般拆 1-2 块（约 30-60cm 见方）就够伸手操作
4. 避开浴霸、灯具等电器模块的正上方主龙骨位置
5. 确认该位置上方没有电线与燃气管再动手

## 七、脚本用法

```bash
python scripts/ceiling_panel_check.py --text "吊顶上有水渍，想拆开看看是不是楼上的问题"
python scripts/ceiling_panel_check.py --file 描述.txt --out 结果.md
```

| 参数 | 说明 |
|---|---|
| `--text` | 直接给现象描述 |
| `--file` | 从文件读描述 |
| `--out` | 结果落盘路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本按现象匹配故障树，输出排查顺序、验证动作与处置，命中燃气、带电接线、大面积拆装、登高作业等情形时输出停用并报专业人员提示。

> 脚本只做关键词匹配，**不代表现场判断**。断电必须用验电笔确认。

## 八、人工确认清单（这步不能省）

- [ ] 对应回路空开已断开，**验电笔确认无电**
- [ ] 上方有没有电线、水管、燃气管确认过
- [ ] 拆板用的是吸盘或撬片，没有硬撬变形
- [ ] 拆下的扣板平放，没有踩踏
- [ ] 电器模块拆线前拍照并标注了火零地
- [ ] 接线端子没有烧蚀、熔化、焦味
- [ ] 线头压接牢固并做了绝缘处理
- [ ] 回装后扣板卡紧、无松动、无异响
- [ ] 恢复供电后照明、取暖、换气逐项测试过

## 九、最常见的坑

**坑一：只关开关不断空开。**
浴霸与照明回路可能仍带电，必须用验电笔确认，不能只信开关。

**坑二：扣板拆不下来就硬撬。**
扣板一旦变形，装回去就卡不紧，之后会掉。先划缝再用吸盘拉。

**坑三：在龙骨上挂重物。**
龙骨与扣板不承重，挂晾衣杆、重型灯具、吊扇会直接把吊顶拉坏。

**坑四：吊顶有水渍就认定自家水管漏。**
楼上防水、公共排水管、浴霸排风管冷凝或未排到室外，都会造成吊顶内湿气与水渍。先找水源再回装，否则装回去还会霉。

**坑五：拆电器模块不拍照就拆线。**
线序记错会导致接回去后开关控制混乱，甚至短路。

**坑六：闻到燃气味还去动电器开关。**
开关火花可能引燃燃气。开窗、关阀、不动电器，到户外打电话。

**坑七：为了检修专门开一个口。**
集成吊顶每块都能拆，临时检修拆对应板块即可，不必破坏性开孔。

**坑八：站在人字梯最高两档作业。**
吊顶作业高度本就高，站在最高两档极易失去平衡，且上方可能有管线。

**坑九：接线端子烧蚀还继续用。**
烧蚀说明接触不良过热，继续使用有起火风险，应请电工处理。
