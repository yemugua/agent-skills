# 集成吊顶扣板拆装与检修口规则

## 一、判定总原则

1. **断电验电先于一切。** 只关开关不算断电，必须验电笔确认。
2. **能拆板块就不开孔。** 集成吊顶本身就是可拆卸结构。
3. **不硬撬。** 扣板变形后卡不紧，之后会掉。
4. **拆线先拍照。** 线序记错会导致控制混乱甚至短路。
5. **龙骨不承重。** 严禁站人、踩踏或悬挂重物。

---

## 二、扣板拆卸手法

| 方法 | 操作 | 适用 |
|---|---|---|
| 吸盘法 | 玻璃吸盘或吸盘挂钩吸住板面中部，垂直向下轻拉 | 首选，最不易变形 |
| 撬片法 | 薄撬片从板缝插入，轻撬一角，手指扣住边缘下拉 | 板缝较紧时 |
| 胶带法 | 宽胶带粘住板面中部向下拉 | 临时没有吸盘时 |
| 划缝法 | 薄刀片沿板缝划一圈 | 被油漆或胶粘连时先划开再吸 |

**拆不下来的常见原因**：卡扣紧、板缝被油漆或密封胶粘住。先划缝再用吸盘，不要直接撬角。

---

## 三、电器模块拆装顺序（浴霸、换气扇、灯具）

1. 断对应回路空开，验电笔确认无电
2. 取下面板（卡扣或螺丝固定）
3. 拍照记录接线并标注火线、零线、地线
4. 松开接线端子取线，不硬拽电线
5. 拆弹簧卡或固定螺丝，双手托住模块缓慢取下
6. 回装时先接好线再固定
7. 线头压接牢固并做绝缘处理，不留裸露铜线
8. 合上空开，逐项测试照明、取暖、换气

**接线端子有烧蚀、熔化、焦味时不得继续使用**，应请电工处理。

---

## 四、故障树（按处理顺序）

| 顺序 | 原因 | 判定 | 验证动作 | 处置 |
|---|---|---|---|---|
| 1 | 空开跳闸或遥控电池没电 | 浴霸不热、换气扇不转、灯不亮 | 查配电箱空开与遥控器电池 | 合空开或换电池 |
| 2 | 接线端子松动 | 时好时坏、有轻微异响 | 断电后检查端子 | 断电后紧固，异常请电工 |
| 3 | 排风管未接到室外或止逆阀失效 | 吊顶内潮气重、有异味 | 看排风管走向与止逆阀 | 接管到室外或更换止逆阀 |
| 4 | 模块本身故障 | 通电后不工作且有异响或焦味 | 排除前几项后判断 | 更换模块或报修 |
| 5 | 扣板变形或卡不紧 | 板面松动、有异响 | 看扣板边缘是否变形 | 更换单块扣板 |
| 6 | 上方水管或接头渗漏 | 吊顶内有水渍、滴水 | 断电后拆板查看 | 关水阀，请水管维修 |
| 7 | 楼上或公共管道渗漏 | 水渍位置与自家管线不符 | 询问楼上、联系物业 | 报物业协调 |
| 8 | 燃气管道或排烟管问题 | 有燃气味或排烟管脱落 | **不动电器开关** | 关阀开窗，到户外报燃气公司 |

## 五、检修口规则

| 情形 | 做法 |
|---|---|
| 临时查看或检修一次 | 拆下对应位置 1-2 块扣板即可，无需专门开孔 |
| 需要经常检修某个阀门或接头 | 把该处扣板换成带框的活动检修板 |
| 石膏板等不可拆材质 | 需开孔锯开孔并加装成品检修口边框，请专业人员 |
| 需要长期预留检修通道 | 安装成品铝合金检修口边框并加固周边龙骨 |

**关键认知**：集成吊顶每块都能拆，为检修专门破坏性开孔通常没有必要。

### 检修口位置选择

1. 先确认上方要检修的具体设备位置
2. 选择该设备正下方或侧下方的扣板
3. 一般拆 1-2 块（约 30-60cm 见方）即可操作
4. 避开浴霸、灯具等电器模块正上方的主龙骨
5. 确认该位置上方没有电线与燃气管再动手

## 七、安全红线（必须停用并请专业人员）

| 情形 | 处置 |
|---|---|
| 需新增回路、改动接线、更换配电箱内器件 | 请持证电工 |
| 接线端子有烧蚀、熔化、焦味 | 立即停用，请电工 |
| 闻到燃气味 | 开窗、关阀、不碰电器开关，到户外报燃气公司 |
| 上方有燃气管道或燃气热水器排烟管 | 不碰撞，作业前确认位置 |
| 漏水来源不明或涉及楼上与公共管道 | 关水阀并报物业协调 |
| 需大面积拆装、龙骨锈蚀变形 | 请专业人员 |
| 作业高度超 2 米或需站人字梯最高两档 | 请专业人员 |

**禁止事项：**

- 禁止只关开关就动手（必须断空开并验电）
- 禁止在龙骨与扣板上站人、踩踏或悬挂重物
- 禁止硬撬扣板导致变形
- 禁止单人登高作业（需有人扶梯）
- 禁止在吊顶内使用明火照明

## 八、常见误判清单（反向判断）

| 现象 | 常见误判 | 正确判断 |
|---|---|---|
| 浴霸不热 | 浴霸坏了 | 先查空开是否跳闸、遥控是否有电 |
| 吊顶有水渍 | 自家水管漏 | 可能是楼上防水、公共管道或排风管冷凝，先找水源 |
| 扣板拆不下来 | 用了胶 | 多为卡扣紧或油漆粘连，先划缝再吸盘拉 |
| 扣板变形 | 要整片换吊顶 | 单块可换 |
| 吊顶有异味 | 扣板密封不好 | 多为排风管未排到室外或止逆阀失效 |
| 吊顶内有响声 | 扣板松动 | 多为换气扇管道共振或风叶碰线 |
| 为了检修要开孔 | 必须破坏性开孔 | 集成吊顶拆对应板块即可 |
| 换气扇不转 | 电机坏了 | 先查空开与接线端子是否松动 |
| 吊顶发霉 | 装回去就好 | 不先解决水源，装回去还会霉 |

---

## 九、回装与验收标准

| 项目 | 合格标准 |
|---|---|
| 扣板 | 卡紧到位，无松动、无变形、无异响 |
| 平整 | 板面与相邻板齐平，缝隙均匀 |
| 供电 | 合上空开后照明、取暖、换气均正常工作 |
| 接线 | 端子紧固、线头绝缘良好、无裸露铜线 |
| 排风 | 换气扇运转正常，排风管连接到位无脱落 |
| 安全 | 作业区域无遗留工具与螺丝，梯具收好 |

任一项不合格，按故障树重新定位；涉及电气与燃气的立即停用并请专业人员。
