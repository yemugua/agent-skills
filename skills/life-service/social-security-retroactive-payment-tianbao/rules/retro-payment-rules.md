# 社保补缴与年限认定规则库

> 本规则库为办理实践整理，**各地口径差异很大**，所有结论以参保地现行规定和社保经办机构核定为准。不得据此对外承诺办理结果。

---

## 一、参保类型与断缴原因矩阵

| 参保类型 | 典型断缴原因 | 一般可补性判断 | 关键提示 |
|---|---|---|---|
| 单位职工 | 单位漏缴、欠缴、少缴 | 通常**可补**，由单位申请补缴，一般加收滞纳金 | 责任主体是单位，个人先与单位协商并由单位申报 |
| 单位职工 | 已离职、劳动关系已终止 | 需按当地口径判断，多数地区不允许个人就离职后期间自行补缴 | 不要自行推断，先问经办机构 |
| 单位职工 | 试用期未缴、未签合同 | 可补，但需先确认劳动关系（合同、工资流水、考勤） | 劳动关系未确认的，先走确认程序 |
| 灵活就业 | 个人中断缴费 | **多数地区不允许事后追补断缴期间**，只能续缴往后算 | 这是最常见的误解点，务必先核实 |
| 灵活就业 | 制度衔接空档 | 按当地衔接政策判断 | 需提供衔接材料 |
| 城乡居民 | 按年缴费漏缴 | 一般可在当年补缴，跨年度补缴是否计入年限按当地口径 | 居民养老与职工养老年限不直接等同 |
| 跨省流动 | 转移接续在途 | 先办结转移再算累计 | 未办结前不得认定为本参保地年限 |

**先定类型，再谈补缴。** 类型错了，后面全错。

---

## 二、可补与不可补清单（核查用）

### 2.1 通常属于可补的情形（仍需当地核定）

1. 用人单位存续期间应缴未缴、少缴，劳动关系明确的
2. 劳动关系经仲裁或诉讼确认后，对应期间的社保补缴
3. 单位申报错误（基数、起止月）导致的漏缴更正
4. 社保经办机构系统原因导致的错录、漏录，经核实的
5. 退役军人、特殊群体按政策应计入的年限衔接

### 2.2 通常属于不可补或需特别审批的情形

1. **灵活就业人员自行中断的期间**，多数地区不允许事后追补
2. 无劳动关系证明的期间（需先确认劳动关系）
3. 已超过当地规定追溯期限的期间（各地规定不同，务必核实）
4. 已在其他统筹地区参保且未办转移的重复期间（重复缴费不重复计算年限）
5. 虚构劳动关系、挂靠代缴的期间 —— **违规，一律不得办**
6. 已按月领取基本养老金后再补缴以提高待遇的期间

### 2.3 一律拒绝提供的方案

- 虚构劳动合同、工资表、考勤记录以制造参保事实
- 挂靠无实际用工关系的公司代缴代补
- 拆分工资、少报缴费基数以降低补缴金额
- 任何以「内部渠道」「包过」为名的代办承诺

## 三、缴费年限认定口径

| 项目 | 口径 | 易错点 |
|---|---|---|
| 实际缴费年限 | 按经办系统记录的**实际缴费月数**累计，满 12 个月为 1 年 | 已申报未到账不算 |
| 视同缴费年限 | 未实行个人缴费制度前的连续工龄等，需**档案认定** | 认定前按 0 计入 |
| 养老最低累计年限 | 累计满 **15 年**（180 个月） | 差 1 个月即为未缴满 |
| 医保累计年限 | **各地不同**，常见男 25 年/女 20 年，**以参保地口径为准** | 不得套用外地口径 |
| 重复缴费期间 | 不重复计算年限 | 跨省转移必须办结后合并 |
| 军龄 | 按政策计入，需提供服役证明 | 需认定后计入 |
| 城乡居民养老转入职工养老 | 按衔接政策折算或合并，**不直接等同** | 缴费档次不同不可简单相加 |

### 3.1 养老年限不足的处理路径（口径）

| 情形 | 一般路径 | 提示 |
|---|---|---|
| 达到退休年龄但累计不足 15 年 | 延长缴费至满 15 年，或按政策一次性补缴 | **是否允许一次性补缴以当地现行政策为准** |
| 制度实施前参保、延长缴费后仍不足 | 按当地过渡政策处理 | 属于过渡期衔接，需经办核定 |
| 未达退休年龄且缴费正常 | 继续缴费即可，无需补缴 | 不要为了凑年限而补缴不必要的期间 |
| 跨省多地参保 | 先办转移接续，归集到待遇领取地再算累计 | 在途期间不认定为已归集 |

## 四、金额测算口径

```
补缴月数   = max(0, 目标累计月数 − 已有累计月数)
           已有累计月数 = 实际缴费月数 + 已认定的视同缴费月数
补缴本金   = 补缴月数 × 月补缴基数 × 补缴费率
滞纳金     = 欠缴金额 × 日加收比例 × 欠缴天数
           日加收比例：社会保险费滞纳金通行口径为按日万分之五（0.0005），以当地核定为准
合计       = 补缴本金 + 滞纳金
```

| 参数 | 取值口径 |
|---|---|
| 月补缴基数 | 按欠缴期间本人工资或当地规定的基数上下限核定，**以经办核定为准**，通常不能随意选最低 |
| 补缴费率 | 养老、医疗、失业等各险种费率不同；单位补缴含单位部分与个人部分，个人部分由个人承担 |
| 欠缴天数 | 自欠缴之日起算至补缴申报或实际缴纳之日，**不是从今天往前估** |
| 灵活就业费率 | 各地有单独的灵活就业缴费比例与基数档次，以当地公布口径为准 |

**测算时标清四件事**：本金、滞纳金、合计、以及「以上为静态测算，实际以经办核定为准」。

## 五、材料清单（按情形取用）

### 5.1 单位补缴

- 补缴申请书（说明欠缴期间、原因、人数、金额）
- 劳动合同或劳动关系证明（未签合同的需先确认劳动关系）
- 欠缴期间的工资发放凭证（工资表、银行代发流水、个税申报记录）
- 单位营业执照、经办人身份证件与授权
- 补缴人员名单及身份信息
- 劳动仲裁裁决书或法院文书（劳动关系经确认的）

### 5.2 个人相关

- 本人身份证件
- 参保缴费记录（经办系统打印或线上导出）
- 人事档案或视同缴费年限认定材料（涉及视同年限的）
- 退役证明（涉及军龄的）
- 跨省转移接续材料（涉及多地参保的）
- 代办的需授权委托书与代办人身份证件

## 六、办理路径

```
① 线上或窗口查询缴费明细，导出逐月记录
② 与档案/合同/工资凭证比对，标出疑问期间
③ 就疑问期间向经办机构咨询：能否补、按什么基数、滞纳金怎么算
④ 准备材料（单位补缴由单位主导申报）
⑤ 提交申请，索取受理回执
⑥ 缴费到账后回查：月数是否增加、年限是否更新、险种是否正确
⑦ 结果不符的，按告知渠道申请复核或依法救济
```

**第 ③ 步不能跳。** 各地能否补、按什么基数补，只有经办机构能定；跳过去按网上的经验值算，误差可能很大。

---

## 七、复核要点

- [ ] 疑问期间的起止月是否与实际用工期间一致
- [ ] 补缴的险种是否正确（养老、医疗、失业、工伤、生育各自独立）
- [ ] 单位部分与个人部分是否已分别承担，个人部分是否被漏收
- [ ] 缴费到账后月数是否真的增加（不是只看扣款成功）
- [ ] 医保年限是否同步更新（有时养老更新了医保没更新）
- [ ] 是否存在重复缴费（跨省未办结转移时常见）
- [ ] 回执、受理单、缴费凭证是否归档

---

## 八、常见拒办原因（提前自查）

1. 劳动关系无法证明，或证明材料相互矛盾
2. 断缴期间属于个人灵活就业中断，当地不允许追补
3. 诉求期间已超过当地规定的追溯期限
4. 缴费基数材料缺失，无法核定基数
5. 已在其他统筹地区参保，重复期间不能补
6. 材料信息与系统登记信息不一致（姓名、证件号、曾用名）
7. 单位已注销、破产或无实际经营，责任主体缺失

## 九、否定词防误伤清单（输出前逐条比对）

| 见到这些词 | 必须这样判 | 严禁这样写 |
|---|---|---|
| 未缴满 / 不足 / 尚差 / 差 X 个月 | 判定为**未满足** | 「已缴满」「满足领取条件」 |
| 视同缴费年限待认定 | 按 **0** 计入测算 | 「已计入视同年限」 |
| 已申报未到账 | 判定为**未上账** | 「缴费成功」 |
| 中断缴费 | 判定为**中断**，不等于免缴也不等于已补 | 「已补缴」「无需处理」 |
| 暂不征缴 / 不征收 | 不等同于**免缴义务**，不等同于免税 | 「不用交了」 |
| 转移接续在途 | 判定为**未归集** | 「年限已合并」 |
| 城乡居民养老缴费 | 不直接等同职工养老年限 | 「年限可折算为 X 年」 |
| 补缴申请已受理 | 判定为**受理中**，非已办结 | 「补缴已完成」 |

## 十、免责

本规则库为办理实践整理，**不构成法律意见或行政认定意见**。补缴的适用范围、基数、费率、滞纳金、一次性补缴政策、医保累计年限与转移接续规则，均**以参保地现行规定和社保经办机构核定为准**。不得用于虚构劳动关系、挂靠代缴、伪造材料或少报基数。
