# 社保补缴办理与年限认定核查

社保补缴的核心不是「想补就能补」——**能不能补、补哪一段、按什么基数补、要不要加收滞纳金，四件事必须分开判断**。混在一起谈，最容易得出错误结论。

这个技能做四件事：**判能不能补 → 算清年限缺口 → 测算本金与滞纳金 → 列出材料与路径**。

---

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 按参保类型与断缴原因判断可补/不可补清单 | 登录社保账号、代替本人申报或代缴 |
| 计算累计缴费年限、年限缺口与补缴月数 | 承诺一定能补、一定能补成功、一定能按最低基数补 |
| 按给定基数与费率测算补缴本金和滞纳金估算 | 提供虚构劳动关系、伪造工资表、挂靠代缴等方案 |
| 输出材料清单、办理路径与复核要点 | 代替社保经办机构作年限认定或行政核定 |
| 提示医保、养老、失业工伤生育的口径差异 | 把「补缴」等同于「连续缴费」或「视同连续」 |

涉及以下情形，应停下来交给社保经办机构、单位人事、律师或专业社保代理人员处理：**跨省转移接续存在争议、视同缴费年限需调档认定、存在劳动争议或劳动关系未确认、单位已注销或破产、涉及一次性补缴政策的过渡期衔接、涉嫌虚构参保关系**。

**绝对不做**：不虚构劳动关系补缴，不通过挂靠公司代缴，不伪造工资凭证、劳动合同或用工记录。这类操作的后果是补缴被撤销、费用不退、并被记入失信记录。

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「社保断了两年，现在还能补吗」 | 用，先分参保类型和断缴原因 |
| 「退休时养老差 8 个月，怎么办」 | 用，算缺口并比对延长缴费与一次性补缴 |
| 「医保年限不够，要补几个月、多少钱」 | 用，按当地医保累计年限口径测算 |
| 「单位那几年没给我交，能补吗」 | 用，可补但要走单位补缴并加收滞纳金 |
| 「我自己那几年没交，现在想补上」 | 用，但要先确认当地是否允许个人事后追补 |
| 「视同缴费年限算不算 15 年里面」 | 用，算入累计年限但需档案认定 |
| 「挂靠个公司把前几年补上」 | 不用，拒绝提供虚构劳动关系方案 |
| 「怎么少交滞纳金、少报基数」 | 不用，不提供规避方案 |

## 三、完整工作流

```
第 1 步  确认参保身份：单位职工 / 灵活就业 / 城乡居民，三类规则不同
第 2 步  确认断缴原因：单位漏缴欠缴 / 个人中断 / 制度衔接 / 跨省转移空档
第 3 步  读规则文件 rules/retro-payment-rules.md（可补与不可补清单、年限口径、滞纳金口径）
第 4 步  调取缴费记录：逐险种、逐年度的实际缴费月数，与档案核对视同缴费年限
第 5 步  算年限缺口：养老 15 年、医保按当地累计年限，分别算，不要合并
第 6 步  跑脚本测算：scripts/contribution_years.py --file case.json
第 7 步  测算本金与滞纳金：补缴本金 = 补缴月数 × 月基数 × 费率；滞纳金按日加收
第 8 步  备材料与提交：按清单准备，提交后索取受理回执
第 9 步  复核结果：缴费记录是否上账、月数是否变更、年限认定与预期是否一致
```

**顺序不能颠倒**：第 1、2 步没定清楚，第 5 步的年限缺口算出来也没有意义。

## 四、年限与金额口径

### 4.1 累计缴费年限口径

```
养老累计缴费年限 = 实际缴费年限 + 视同缴费年限      （按月累计，满 12 个月为 1 年）
养老按月领取条件 = 达到法定退休年龄 且 累计缴费满 15 年
医保累计年限     = 按参保地规定的累计缴费年限        （各地不同，常见男 25 年/女 20 年，以当地为准）
```

**三条容易错的口径**：

1. **累计 ≠ 连续**。养老看的是累计满 15 年，中断不影响累计月数；医保待遇享受与连续缴费相关的地方规定另行核对，不要把「累计够」当成「待遇立即恢复」。
2. **不足整年按月算**。差几个月就是差几个月，**「缴满 15 年差 1 个月」是未缴满，不是已缴满**。
3. **养老和医保分开算**。养老满 15 年只解决养老，医保年限要单独核，两者缺口月数通常不同。

### 4.2 补缴金额口径

```
补缴月数   = 目标累计月数 − 已有累计月数（实际 + 视同）
补缴本金   = 补缴月数 × 补缴月基数 × 补缴费率
滞纳金估算 = 欠缴金额 × 日加收比例 × 欠缴天数        （日加收比例按当地口径，社会保险费滞纳金通行口径为按日万分之五）
合计       = 补缴本金 + 滞纳金
```

补缴基数、单位与个人分担比例、**是否允许按最低基数补**，各地口径不一，**以参保地社保经办机构核定为准**。不要按网上流传的单一费率直接对外报数。

### 4.3 判定表

| 项目 | 判定 | 动作 |
|---|---|---|
| 养老累计 ≥ 15 年 且 达退休年龄 | 可申请按月领取 | 走退休办理 |
| 养老累计 < 15 年 | 未缴满，不能按月领取 | 延长缴费或按规定一次性补缴，以当地政策为准 |
| 医保累计 ≥ 当地规定年限 | 退休后医保待遇按当地规则 | 核对是否还需补足连续缴费要求 |
| 医保累计 < 当地规定年限 | 年限不足 | 按规定补缴或继续缴费，以当地政策为准 |

**防误伤（否定词清单）**：输出结论前逐条比对——

- 「未缴满」「不足」「尚差」→ 一律判为**未满足**，不得写成「已缴满」
- 「视同缴费年限待认定」→ 判为**未计入**，不得当作已计入的累计年限
- 「中断缴费」→ 不等同于「免缴」，也不等同于「已补缴」
- 「已申报未到账」→ 判为**未上账**，不得当成缴费成功
- 「不征收」「暂不征缴」→ 不等同于「免缴义务」，不等同于「免税」

## 五、核心规则与要件库

生成材料或给结论前，**必须先读**：

- `rules/retro-payment-rules.md`：参保类型与断缴原因矩阵、可补与不可补情形、年限认定口径、滞纳金口径、材料清单、办理路径、复核要点与常见拒办原因。

不得根据口头描述认定缴费年限，不得把档案未认定的年限直接计入，不得用其他城市口径套本地。

## 六、脚本用法

```bash
python scripts/contribution_years.py --file case.json --out 补缴测算.md
python scripts/contribution_years.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：性别、实际缴费月数、视同缴费月数、医保月数、当地医保年限、拟补缴区间、补缴基数、费率、日加收比例、欠缴天数 |
| `--text` | 直接给 JSON 字符串 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检 |

输入 JSON 示例：

```json
{
  "name": "示例",
  "gender": "male",
  "pension_actual_months": 168,
  "pension_deemed_months": 12,
  "medical_actual_months": 170,
  "medical_required_years": 25,
  "retro_months": 8,
  "monthly_base": 4500,
  "total_rate": 0.20,
  "late_daily_rate": 0.0005,
  "late_days": 900
}
```

脚本输出：养老累计年限与是否缴满（严格按月判断）、医保累计年限与缺口月数、补缴本金、滞纳金估算、合计金额、是否仍需延长缴费的提示，以及「未缴满不得判为已缴满」的防误伤标注。

> 脚本按你填的参数做静态测算，**未含利息、政策性减免、单位与个人分担差异、跨省转移在途月数**；基数、费率与滞纳金口径以参保地社保经办机构核定为准。

## 七、人工确认清单（这步不能省）

- [ ] 参保身份已确认（单位职工 / 灵活就业 / 城乡居民），不是凭印象猜的
- [ ] 断缴原因已确认，且有对应证明材料（劳动合同、工资发放记录、离职证明等）
- [ ] 视同缴费年限已由档案或有权部门认定，不是自己估算的
- [ ] 缴费记录的月数与本人记忆不一致时，以经办系统记录为准并申请复核
- [ ] 补缴基数与费率已按参保地现行口径核对，不是网上抄的
- [ ] 养老与医保缺口分别列出，没有合并成一个数
- [ ] 滞纳金起算日与天数已核实（不是从今天往前随便估）
- [ ] 已索取受理回执，且缴费到账后重新核对月数
- [ ] 跨省参保的，转移接续已办结再算累计，避免重复或漏算

## 八、最常见的坑

1. **把「累计」当「连续」，以为断了就白交**。养老看累计月数，中断不清零；但医保待遇享受的地方规定关连续缴费，两者不要混为一谈，也不要反过来用「累计够」推断「待遇马上恢复」。
2. **差一个月也算没缴满**。14 年 11 个月 ≠ 15 年。脚本按月判断，输出里会明确标注「未缴满」。
3. **把「视同缴费年限待认定」当成已计入**。视同年限必须有档案依据并经认定，口头说的军龄、知青年限、未参保前的工龄，在认定完成前一律按 0 计入测算。
4. **只算养老不算医保**。养老满 15 年只解决一个问题，医保累计年限通常更长，退休前不核对，往往到办退休时才发现差好几年。
5. **用外地口径套本地**。医保累计年限、补缴基数上下限、是否允许个人事后追补，各地差异很大，跨城市套用会得出完全错误的结论。
6. **以为补缴一定按最低基数**。补缴基数通常按欠缴期间本人工资或当地规定的基数口径核定，加上滞纳金后可能远高于预期；先问经办机构再决定补不补。
7. **把「已申报」当「已到账」**。申报成功不等于缴费上账，上账不等于年限已更新，每一步都要回查记录。
8. **听信「挂靠公司补缴」**。虚构劳动关系补缴属于违规，后果包括补缴被撤销、费用难以追回、影响个人信用。**没有捷径。**

## 九、边界与免责

- 本技能用于补缴前核查与材料整理，**不构成法律、社保代理或行政认定意见**，不替代本人办理与经办机构核定
- 补缴的适用范围、基数、费率、滞纳金、是否允许一次性补缴、医保累计年限，**均以参保地现行规定和社保经办机构核定为准**
- 本测算为**静态口径**，未含利息、政策性减免、单位与个人分担差异、跨省转移在途月数
- **不承诺一定能补、一定能按某个基数补、一定能补成功**
- 不提供虚构劳动关系、挂靠代缴、伪造材料、少报基数、规避滞纳金的任何方案
