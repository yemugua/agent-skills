# 尤克里里入门（ukulele-starter-guide）

尤克里里上手快，但「快」也容易让人跳过基础：弦没调准就练和弦、和弦按品错了还以为是手小、一上来就弹唱结果扫弦糊成一片。

这个技能做三件事：**定标准音 → 核指法 → 排练习顺序**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出 gCEA 四弦标准音与音分判定 | ❌ 评判演奏水平或音色好坏 |
| 核对九个入门和弦的按品指法 | ❌ 讲解具体品牌琴的选购与配置 |
| 核查练习路径的阶段顺序是否合理 | ❌ 替代专业老师的现场纠正 |
| 指出常见错误指法与练习误区 | ❌ 指导特殊调弦法（如 Low G、D 调夹法）的音高设定 |

**遇到以下情况，按各自渠道处理：**

- 琴颈弯曲、打品、弦距过高、品丝刮手 → 属维修调整范围，找专业琴行
- 需要选购琴、琴弦、调音器 → **本技能不推荐具体品牌型号**
- 需要系统考级或舞台演出训练 → 找具备资质的老师

## 二、完整工作流

### 第一步：先把四根弦调到标准音

标准调弦为 **gCEA**（从四弦到一弦）。用调音 App 或电子调音器，把每根弦调到对应频率（见 `rules/尤克里里入门练习路径.md` 频率表）。调音时**从粗到细、从低往高拧**，不要一下拧过。

### 第二步：对照指法表练单和弦

打开 `rules/尤克里里入门练习路径.md` 的和弦指法表，每个和弦按「四弦 / 三弦 / 二弦 / 一弦」四个位置逐一核对品数。手指垂直按在品丝**后方一格**，不要压在品丝上。

### 第三步：填 JSON 跑指法核查

把要练的和弦与每弦按品填进去，脚本一次性告诉你哪个弦按错了、正确品数是多少。

### 第四步：按四阶段路径推进

不要一上来就弹唱。先单音、再单和弦、再和弦转换、最后上一首只有两三个和弦的慢歌。脚本能核对你的练习计划是否跳过了基础阶段。

### 第五步：每天短时高频

入门阶段每天 **15 到 25 分钟、隔天练** 比一次练两小时更稳，手指起茧前别硬撑。

---

## 三、核心规则（生成结论前先读规则文件）

**必须先读 `rules/尤克里里入门练习路径.md`，不要凭印象写。** 规则文件里有：

- gCEA 四弦的标准音名与频率、音分公式与四级判定
- 九个入门和弦（C / C7 / Am / A / F / G / G7 / D / Dm / Em）的标准按品指法，按「四弦 三弦 二弦 一弦」顺序
- 练习路径四阶段与每阶段该达成什么
- 八条高频坑

**判定顺序不能颠倒**：先看真实缺陷（弦音严重跑调、和弦按品错），再看练习路径是否缺基础阶段，最后才看信息是否完整。

**为什么这条重要**：如果先判信息完整度，会出现「F 和弦按品全错，却因为没填练习计划而被判成待确认」——把明显错误说轻了，比漏判更糟。

---

## 四、和弦指法速查（节选）

按品顺序固定为「四弦 / 三弦 / 二弦 / 一弦」，数字为品格数，0 表示空弦：

| 和弦 | 四弦(g) | 三弦(C) | 二弦(E) | 一弦(A) |
|---|---|---|---|---|
| C | 0 | 0 | 0 | 3 |
| Am | 2 | 0 | 0 | 0 |
| F | 2 | 0 | 1 | 0 |
| G | 0 | 2 | 3 | 2 |
| Em | 0 | 4 | 3 | 2 |

完整十个和弦见规则文件。

**反例**：把 C 和弦按成一弦 0 品（忘了按 3 品），声音会变成 open A 主导的怪和弦——脚本会逐弦点名「一弦应为 3 品，实为 0」。

## 五、脚本用法

```bash
python scripts/ukulele_practice_check.py --file plan.json --out 自查.md
python scripts/ukulele_practice_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`tuning` 为四弦频率、`chords` 为和弦指法列表、`plan` 为练习阶段列表 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检（≥8 条断言，含 BOM 两条路径与反例） |

输入 JSON 示例：

```json
{
  "tuning": {"g": 392.0, "C": 261.6, "E": 329.6, "A": 440.0},
  "chords": [{"name": "C", "frets": [0, 0, 0, 3]}],
  "plan": ["tuning", "single_chord", "transition", "first_song"]
}
```

脚本输出：调音判定、和弦逐弦正误、练习路径阶段核查、整改顺序、人工确认清单。

## 六、人工确认清单（这步不能省）

- [ ] 四根弦已用调音器调到 gCEA 标准音
- [ ] 按和弦时手指落在品丝**后方一格**，不是压在品丝上
- [ ] 每个按品手指的第一指节垂直，没有碰到邻弦
- [ ] 换和弦时先练「共同指不动、只动变化的指」
- [ ] 扫弦用手腕带动，不是抡整条胳膊
- [ ] 每天练 15 到 25 分钟，手指疼就停

## 七、最常见的坑

**坑一：弦没调准就练和弦。**
错误做法：新琴拿出来凭耳朵拧两下就开始练 C。正确做法：尤克里里四弦是 re-entrant（G 比 C 高），不调准则和弦永远「差点意思」。**先调准再练。**

**坑二：把 C 和弦按成空弦。**
错误做法：一弦忘了按 3 品，以为是手指够不着。正确做法：C 和弦只有一弦按 3 品，其余全空弦，是最简单的和弦之一；按错说明没看指法表。

**坑三：手指压在品丝上。**
错误做法：指尖落在品丝正上方，出来的音发闷或打品。正确做法：按在**品丝后方约一格**的位置，用力更省、音更干净。

**坑四：一上来就练弹唱。**
错误做法：第一天就选一首四个和弦的快歌。正确做法：先单和弦按稳，再练两个和弦之间的转换（如 C→Am、C→G），最后才上慢歌。

**坑五：F 和弦用手腕硬压。**
错误做法：小横按把食指整个压在一弦和二弦上，结果三弦四弦被闷住。正确做法：F 只压一弦 2 品、二弦 1 品，用食指侧边点压，三弦四弦保持空弦。

**坑六：扫弦用胳膊抡。**
错误做法：整条小臂大幅摆动，节奏一快就糊。正确做法：以手腕为轴小幅转动，下扫上扫均匀，先练慢速四分音符。

**坑七：连续练到手指起泡。**
错误做法：一次练一小时，指尖磨破。正确做法：每天短时（15–25 分钟）、隔天练，给指尖长茧的时间。

**坑八：换和弦时所有手指全抬再落。**
错误做法：每个和弦都「全部松开再重新按」，转换慢且易错。正确做法：找出两个和弦的**共同指**，让它留在原位，只移动变化的手指。

## 八、边界与免责

- 本技能提供的是**入门练习路径与指法自查口径**，**不评判演奏水平与音色**，也不构成教学水平评价
- 和弦指法为 gCEA 主流弹法的通用整理；不同体型手型可有细微差别，以自身舒适与发声干净为准
- **不涉及特殊调弦法**（如 Low G、变调夹改调）的具体音高设定
- **不涉及琴颈弯曲、弦距、品丝维修**；此类问题应找专业琴行
- **不推荐具体品牌型号**的琴、琴弦与调音器
- 练习强度因人而异，手指疼痛应停止，避免劳损
- 本技能不构成任何演奏效果或学习进度的担保
