# 幼儿园与学校消防安全管理（kindergarten-school-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《中小学幼儿园消防安全管理规定》《托育机构消防安全指南（试行）》，生成学段化消防清单：儿童疏散、厨房/宿舍/实验室、用电管控与安全教育课时。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 幼儿园消防
- 学校消防
- 校园消防
- 托育消防
- 学生疏散
- 中小学消防

## 三、工作流
1. 明确学段与机构类型（幼儿园/中小学/高校）
2. 制定儿童/学生疏散预案（含失能协助）
3. 厨房/宿舍/实验室用火用电专项
4. 规定疏散演练频次（每学期≥1次）
5. 安排消防安全教育课时

## 四、核心内容（检查清单与判定）
《中小学幼儿园消防安全管理规定》要求学校将消防安全教育列入教学计划并定期组织疏散演练；托育机构须落实消防专人管理与夜间巡查。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未明确适用学段/机构类型 | 管理规定 |
| Q2 | FAIL | 未含儿童/学生疏散预案（含失能协助） | 疏散要求 |
| Q3 | WARN | 未含厨房/宿舍/实验室用火用电专项 | 重点部位 |
| Q4 | FAIL | 未规定疏散演练频次（每学期≥1次） | 演练要求 |
| Q5 | WARN | 未含消防安全教育课时 | 教育 |

> 脚本 `kindergarten-school-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python kindergarten-school-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python kindergarten-school-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
