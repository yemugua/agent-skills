# 脚手架安全（scaffold-safety）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《建筑施工脚手架安全技术统一标准》GB 51210，生成清单：方案编制与审批、材质与构配件检查、立杆基础与扫地杆、连墙件与剪刀撑、验收挂牌与拆除。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 脚手架安全
- 脚手架验收
- 连墙件
- 剪刀撑
- 脚手架搭设

## 三、工作流
1. 编制方案并审批
2. 检查材质与构配件
3. 落实立杆基础与扫地杆
4. 设置连墙件与剪刀撑
5. 验收挂牌并规范拆除

## 四、核心内容（检查清单与判定）
GB 51210 对脚手架的构配件、基础、连墙件与剪刀撑提出要求；搭设完须验收挂牌方可使用，拆除应按方案顺序进行。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含方案编制与审批 | 方案 |
| Q2 | FAIL | 未含材质与构配件检查 | 材质 |
| Q3 | WARN | 未含立杆基础与扫地杆 | 基础 |
| Q4 | FAIL | 未含连墙件与剪刀撑 | 连墙件 |
| Q5 | WARN | 未含验收挂牌与拆除 | 验收 |

> 脚本 `scaffold-safety_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python scaffold-safety_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python scaffold-safety_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
