# 流量主接入与平台规则（微信小程序）

## 开通条件（概览，具体以平台公示为准）
- 主体：已完成微信认证的企业或个体工商户；个人主体不可开通。
- 门槛：累计独立访问用户达到一定量级（历史为 1000 UV，平台可能调整），无严重违规记录。
- 类目：部分特殊类目限制或禁止接入广告，须以平台当前类目规则为准。

## 广告形式与限制
| 形式 | 说明与注意 |
|------|-----------|
| Banner 广告 | 页面底部/顶部条幅，须标识「广告」、不得遮挡关键功能 |
| 插屏广告 | 页面切换时弹出，须控制频次，不得误触 |
| 激励视频 | 用户主动观看换奖励；**只能用于可选功能**，不得作为核心功能前提 |
| 视频贴片 | 视频前后贴片，须标识 |
| 原生模板/文中广告 | 融入内容流，须明确标注「广告」 |

## 违规与处罚梯度
| 行为 | 平台处置 |
|------|---------|
| 诱导/误导点击、虚假按钮 | 清退广告位、限制广告能力 |
| 虚假点击/刷量/机器点击 | 封禁流量主权限、清零/追回收益、追究责任 |
| 功能捆绑（强制看广告才能用核心功能） | 限制广告能力乃至下架 |
| 广告含极限词/违禁类目无资质 | 拒登、下架广告、处罚 |
| 个性化广告未告知同意 | 与隐私违规联动，限流/处罚 |
| 诱导分享换广告收益 | 封禁分享接口与广告能力 |

## 结算
- 收益按平台规则结算至绑定账户，企业须依法纳税。
- 提现须主体一致，异常结算/税务不合规会引发风控与合规风险。
