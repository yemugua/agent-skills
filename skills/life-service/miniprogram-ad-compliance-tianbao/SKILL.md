# 小程序广告与流量主合规核查

## 适用场景

- 你正在做或已上线一个小程序，准备接入**广告变现 / 微信流量主**（banner、插屏、激励视频、视频贴片、原生模板、文中广告等）。
- 典型对象：**落叶涧日记**这类已含 xpay 会员、可能进一步接入广告变现的内容/工具产品。
- 已做过隐私合规、ICP 备案、内容安全、虚拟支付的，本技能补齐"广告变现"这一层合规。

## 何时调用

- 小程序准备开通流量主、接入广告、被平台提示广告违规/限流、或收益结算异常时。
- 需要一份可交付的《小程序广告与流量主合规核查报告》作为整改清单与留存证据。

## 工作流程

1. **采集信息**：用 `templates/采集表.md` 让用户填写主体类型、是否接广告、广告形式、是否有诱导/虚假点击、是否功能捆绑、广告内容审核、极限词、需资质类目、个性化广告告知、未成年人保护、结算税务、违规历史。
2. **运行核查**：`python scripts/miniprogram_ad_compliance.py <采集表.md>` 输出报告。
3. **解读结论**：报告含结论摘要（通过/有风险/不通过）、分项核查、阻断项与风险待办、标准整改清单、边界声明。
4. **整改闭环**：按"阻断项（必须处理）→ 风险待办（建议处理）→ 历史违规闭环"推进，整改后重跑核查。

## 核查维度（6 大域）

1. **流量主接入资质**：主体须企业/个体工商户（个人不可），须完成认证并满足开通门槛。
2. **广告位与形式合规**：禁止诱导/误导点击、虚假点击/刷量；广告须标识「广告」；不得强制观看广告才能用核心功能。
3. **广告内容合规（广告法/平台规则）**：建立广告主资质与内容审核；禁用极限词/绝对化用语；医疗/药品/保健/金融/烟酒等类目须持资质。
4. **个性化广告与数据合规**：精准投放须告知并取得同意、提供关闭选项（与隐私合规衔接）。
5. **未成年人与诱导营销**：不向未成年人推送不适宜/诱导消费广告；不得以「分享/拉新换广告收益」诱导分享。
6. **结算税务与平台规则**：绑定与主体一致结算账户、依法申报纳税；违规历史须闭环。

## 关键判断规则

- **个人主体接广告/流量主** → **阻断**（流量主仅对企业/个体户开放）。
- **诱导点击 / 虚假点击刷量 / 强制捆绑核心功能** → **阻断**。
- **广告含极限词 / 需资质类目无资质** → **阻断**。
- **个性化广告未告知同意** → **阻断**（衔接 PIPL）。
- **用分享/拉新换广告收益并诱导** → **阻断**（衔接诱导分享红线）。
- **未审核广告主资质 / 未达开通门槛 / 广告未标识 / 无关闭个性化选项 / 未成年人广告无限制 / 结算税务不合规 / 有违规历史** → **风险**。

## 边界

- 依据《广告法》《个人信息保护法》、微信小程序流量主相关规则与平台运营规范公开规则整理。
- **不替代监管规定、平台规则与正式法律意见**，重大场景请咨询律师。
- 流量主仅向完成认证的企业/个体工商户开放，个人主体不可开通；虚假点击/刷量将清退权限并追回收益。
