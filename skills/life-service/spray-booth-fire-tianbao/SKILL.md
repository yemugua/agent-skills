# 喷漆房防火防爆（spray-booth-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据涂装作业安全规程与爆炸危险环境电气要求，生成清单：爆炸危险区域划分与防爆电气、通风与可燃气体浓度报警、漆雾与积漆清理、动火作业与静电接地、消防器材与应急。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 喷漆房防火
- 涂装作业防爆
- 喷漆房通风
- 可燃气体报警
- 静电喷涂接地

## 三、工作流
1. 划分爆炸危险区域并配防爆电气
2. 组织通风与设置可燃气体报警
3. 清理漆雾与积漆
4. 管控动火作业与静电接地
5. 配置消防器材与应急设施

## 四、核心内容（检查清单与判定）
涂装作业场所存在大量可燃蒸气与漆雾，须按爆炸危险区域配置防爆电气并保持有效通风；积漆自燃风险高，静电接地与动火管控缺一不可。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含危险区域划分与防爆电气 | 防爆 |
| Q2 | FAIL | 未含通风与可燃气体报警 | 报警 |
| Q3 | WARN | 未含漆雾与积漆清理 | 清理 |
| Q4 | FAIL | 未含动火作业与静电接地 | 接地 |
| Q5 | WARN | 未含消防器材与应急设施 | 应急 |

> 脚本 `spray-booth-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python spray-booth-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python spray-booth-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
