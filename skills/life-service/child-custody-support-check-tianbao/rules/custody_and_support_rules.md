# 子女抚养权归属与抚养费核算规则

> 依据现行《民法典》及相关司法解释的通行口径。**具体条文序号以现行有效文本为准**，本文件只给判定口径与计算方法，不引用具体条款号。个案结果由双方协商或人民法院认定。

## 一、抚养权归属判定口径

### 年龄分层

| 年龄 | 判定原则 |
|---|---|
| 不满 2 周岁 | 一般由**母亲**直接抚养；母亲有不宜抚养情形的除外 |
| 2 周岁以上、8 周岁以下 | 协商不成时，由法院按**最有利于未成年子女**原则综合判定 |
| 8 周岁以上 | 应当尊重子女的**真实意愿**（法院通常单独询问，不当庭对质） |

### 母亲不宜直接抚养不满 2 周岁子女的情形

- 患有久治不愈的传染性疾病或其他严重疾病，子女不宜与其共同生活
- 有抚养条件不尽抚养义务，而父亲要求子女随其生活
- 因其他原因（如吸毒、赌博、严重精神疾病、服刑）子女确不宜随其生活

### 2 周岁以上综合考量的因素

| 类别 | 具体因素 |
|---|---|
| 抚养能力 | 收入与稳定性、住房条件、工作时间与陪伴可能、健康状况 |
| 生活连续性 | 子女目前的生活环境、就学情况、主要照料人（不宜轻易改变） |
| 抚育意愿与投入 | 既往实际照顾情况、与子女的感情基础 |
| 优先情形 | 已做绝育手术或因其他原因丧失生育能力的；子女随其生活时间较长，改变生活环境对子女健康成长明显不利的；一方无其他子女而另一方有其他子女的 |
| 协助力量 | 祖父母、外祖父母愿意且有能力协助照顾的 |
| **不利情形（减分）** | 家庭暴力、虐待遗弃、吸毒赌博等恶习、长期不尽抚养义务、严重传染病或精神疾病、服刑 |
| 子女意愿 | 8 周岁以上应听取并尊重其真实意愿 |

### 两个孩子的常见处理方式

实务中并非一律"一人一个"。若两个孩子一直共同生活、感情深厚，法院可能判归一方更有利于其成长；也可能结合年龄、性别、各自照料安排判定分别抚养。**不要默认一定是一人一个。**

## 二、抚养费核算

### 比例口径

| 情形 | 比例 |
|---|---|
| 有固定收入，1 个子女 | 一般按月总收入的 **20% ~ 30%** 给付 |
| 有固定收入，2 个及以上子女 | 比例可适当提高，但一般**不得超过月总收入的 50%**（实务常按 30%~50% 测算） |
| 无固定收入 | 依据**当年总收入**或**同行业平均收入**折算月收入后，参照上述比例 |
| 特殊情况 | 子女患重大疾病、有特殊教育需求、当地生活水平特别高的，可适当调整；给付方确有困难的，可适当降低 |

**月总收入**一般指工资、奖金、津贴、补贴等全部劳动收入；部分口径还包含经营性收益、租金等稳定收益。认定口径存在差异，**以双方举证和法院认定为准**。

### 三档测算口径

| 档位 | 取值 | 用途 |
|---|---|---|
| 保守档 | 比例下限 | 对方收入举证不足、需要快速达成时的预期下限 |
| 合理档 | 上下限中值 | 协商谈判的主报价 |
| 争取档 | 比例上限 | 有多个子女、实际支出明显偏高时的争取目标 |

### 抚养费的范围

| 包含 | 通常不含（需另行协商或单独主张） |
|---|---|
| 生活费 | 大额择校费、私立学校学费（**需协商一致或法院认定必要性**） |
| 日常教育费（义务教育阶段学杂费、常规学习用品） | 出国留学、高额兴趣班（非必需） |
| 常规医疗费（医保报销后的自付部分） | 重大疾病的巨额自费部分（可另行主张增加） |

### 给付方式与期限

| 事项 | 口径 |
|---|---|
| 给付方式 | 定期给付（按月/季/年）；有条件的可一次性给付；一方无经济收入或下落不明的，可用其财物折抵 |
| 给付期限 | 一般至子女 **18 周岁**为止 |
| 提前停止 | 16 周岁以上不满 18 周岁，以劳动收入为主要生活来源且能维持当地一般生活水平的，可停止给付 |
| 延长给付 | 尚在校接受高中及其以下学历教育，或丧失/部分丧失劳动能力等非因主观原因无法维持正常生活的，可继续给付 |

### 数额调整

**可以增加的情形**：原定数额不足以维持当地实际生活水平；因子女患病、上学，实际需要已超过原定数额；有其他正当理由（如给付方收入显著增加）。

**可以减少或免除的情形**：给付方长期患病或丧失劳动能力确有困难；服刑期间确无给付能力；直接抚养方再婚、继父母愿意承担部分抚养费的（实务有争议，以个案认定为准）。

## 三、探望权

| 事项 | 口径 |
|---|---|
| 权利主体 | 不直接抚养子女的父或母 |
| 义务主体 | 直接抚养方有**协助义务**，不得阻碍 |
| 方式时间 | 由双方协商；协商不成由法院判决 |
| 中止 | 探望不利于子女身心健康的，可依法中止；中止事由消失后应当恢复 |
| 执行 | 强制执行的对象是**拒不协助的一方**（可罚款、拘留等），**不能强制执行子女的人身**，不能强行带走孩子 |
| 常见约定 | 每周/隔周的周末、寒暑假分段、节假日轮换，接送地点与时间明确 |

## 四、变更抚养关系

可以请求变更的情形：

1. 与子女共同生活的一方患严重疾病或因伤残无力继续抚养
2. 与子女共同生活的一方不尽抚养义务、有虐待行为，或对子女身心健康确有不利影响
3. 8 周岁以上子女愿随另一方生活，且该方有抚养能力
4. 有其他正当理由需要变更

**注意**：变更需要证明"出现了新的重大事由"或"现有安排已不利于子女"，单纯"我现在条件更好了"通常不足以支持变更。

## 五、证据清单

| 主张 | 证据 |
|---|---|
| 收入水平（对方） | 工资流水、个税申报记录、社保缴费基数、单位收入证明、公积金缴存额、经营性收入凭证、微信/支付宝流水 |
| 收入水平（自己） | 同上，用于主张自己的抚养能力与给付能力 |
| 子女实际开支 | 学费单、校服餐费、补习班合同与票据、医疗票据、保险单、日常生活支出记录 |
| 抚养条件 | 住房证明（房产证或租赁合同）、就近学校、作息时间表、家人协助照顾的书面说明 |
| 既往照料事实 | 家长群沟通记录、接送记录、就医陪同记录、老师证言、邻居证言 |
| 对方不利因素 | 报警记录、伤情鉴定、人身安全保护令、行政处罚决定书、戒毒/戒赌记录、刑事判决书、悔过书 |
| 子女意愿 | 8 周岁以上子女的书面或当庭陈述（**不得诱导、不得让孩子当众站队**） |
| 特殊需求 | 疾病诊断证明、康复训练方案与费用、特殊教育安排 |

## 六、防误伤清单（最重要）

1. **不要抢孩子、藏孩子。** 抢夺、藏匿子女会被认定为不利于子女身心健康的行为，直接影响抚养权判定，严重的会被罚款、拘留，甚至构成拒不执行判决裁定罪。
2. **不要教孩子说假话、不要让孩子当众站队。** 一旦被发现，性质比"不表态"严重得多。
3. **不要把"对方收入高"当成决定因素。** 抚养权看的是最有利于子女，收入只是其中一个因素，既往照料事实与生活连续性往往更关键。
4. **不要把"对方不给抚养费"当成"可以拒绝探望"。** 两者是不同法律关系，拒绝协助探望会被强制执行。
5. **不要把"对方拒绝探望"当成"对方放弃抚养"。** 不能据此自行变更抚养安排。
6. **不要以为抚养费一成不变。** 物价上涨、子女患病上学、收入显著变化都可以请求调整。
7. **不要把大额择校费、私立学费默认算进抚养费。** 这类支出通常需协商一致或经法院认定必要性。
8. **非婚生子女享有与婚生子女同等权利**，不直接抚养的一方同样应负担抚养费。
9. **不要伪造收入证明或开支票据。** 一旦查实，直接影响全案可信度。

## 七、常见误判对照

| 常见说法 | 正确口径 |
|---|---|
| "孩子不满两岁一定归妈妈" | 原则上由母亲直接抚养，母亲有不宜抚养情形的除外 |
| "两个孩子一定一人一个" | 不一定，看是否有利于子女共同成长 |
| "孩子说跟谁就跟谁" | 8 周岁以上的真实意愿应当尊重，但不是唯一依据 |
| "不给抚养费就别想看孩子" | 两回事，都不能互相抵消 |
| "抚养费按基本工资算" | 按**月总收入**（含奖金津贴等）测算 |
| "孩子上大学了还得给抚养费" | 一般至 18 周岁；高中及以下在读等特殊情形可继续 |
| "对方再婚了就能少给" | 不当然减免，需个案认定 |
| "改了姓就可以不给" | 不得因子女姓氏变更拒付抚养费 |
