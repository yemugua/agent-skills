# 子女抚养权归属与抚养费核算（child-custody-support-check）

抚养这件事拆成两块：**孩子跟谁生活**、**另一方给多少钱**。判定逻辑完全不同，不要混着谈。

这个技能做四件事：**判归属** → **算金额** → **定期限** → **理探望**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 按年龄分层与综合因素给出归属判定口径 | ❌ 预测法院会怎么判 |
| 按收入比例测算抚养费三档区间 | ❌ 认定某一方"一定能拿到抚养权" |
| 折算给付期限与合计区间 | ❌ 代你起诉、代签协议、代收抚养费 |
| 给出探望权约定与变更抚养关系的情形清单 | ❌ 出具律师执业意见 |
| 整理证据清单与防误伤提示 | ❌ 建议任何抢夺、藏匿子女的行为 |

**遇到以下情况，务必转交执业律师或法律援助机构：**
- 涉及家庭暴力、虐待、遗弃，需要申请人身安全保护令
- 一方下落不明、服刑、有严重精神疾病或吸毒赌博等情形
- 涉及涉外婚姻、境外子女、收养关系
- 已进入诉讼程序，需要举证与出庭策略
- 涉及大额财产分割、公司股权、隐匿转移财产

**永远不要建议"先把孩子抢过来/藏起来"。** 这类行为会被认定为不利于子女身心健康，直接影响抚养权判定，严重的会被罚款、拘留。

## 二、抚养权归属：年龄分层

| 年龄 | 判定原则 |
|---|---|
| 不满 2 周岁 | 一般由**母亲**直接抚养；母亲有不宜抚养情形的除外 |
| 2 ~ 8 周岁 | 协商不成时按**最有利于未成年子女**原则综合判定 |
| 8 周岁以上 | 应当尊重子女的**真实意愿**（法院通常单独询问） |

**母亲不宜直接抚养的情形**：久治不愈的传染性疾病或其他严重疾病；有抚养条件不尽抚养义务而父亲要求随其生活；吸毒、赌博、严重精神疾病、服刑等确不宜共同生活的情形。

### 综合考量的因素（完整表见 `rules/custody_and_support_rules.md`）

| 加分因素 | 减分因素 |
|---|---|
| 已做绝育手术或丧失生育能力 | 家庭暴力、虐待、遗弃 |
| 子女随其生活时间较长，改变环境明显不利 | 吸毒、赌博等恶习 |
| 无其他子女，而另一方有其他子女 | 长期不尽抚养义务 |
| 祖父母/外祖父母愿意且有能力协助照顾 | 严重传染病或精神疾病、服刑 |
| 既往实际照料多、感情基础好 | 抢夺、藏匿子女 |

**两个孩子不一定一人一个。** 若两个孩子一直共同生活、感情深厚，判归一方更有利于成长的安排同样常见。

## 三、抚养费：比例口径

| 情形 | 比例 |
|---|---|
| 有固定收入，1 个子女 | 月总收入的 **20% ~ 30%** |
| 有固定收入，2 个及以上子女 | 比例可适当提高，一般**不超过月总收入的 50%**（实务按 30%~50% 测算） |
| 无固定收入 | 按当年总收入或同行业平均收入折算月收入后参照上述比例 |

**月总收入**一般指工资、奖金、津贴、补贴等全部劳动收入，不是基本工资。

三档用法：

| 档位 | 取值 | 用途 |
|---|---|---|
| 保守档 | 比例下限 | 对方收入举证不足时的预期下限 |
| 合理档 | 上下限中值 | 协商谈判的主报价 |
| 争取档 | 比例上限 | 多子女或实际支出明显偏高时的目标 |

**抚养费范围**：含生活费、日常教育费、常规医疗费；**通常不含**大额择校费、私立学校学费、出国留学、高额兴趣班、重大疾病巨额自费部分——这些需另行协商或单独主张。

## 四、给付期限

| 事项 | 口径 |
|---|---|
| 一般期限 | 至子女 **18 周岁** |
| 提前停止 | 16 周岁以上不满 18 周岁，以劳动收入为主要生活来源且能维持当地一般生活水平 |
| 延长给付 | 尚在校接受高中及以下学历教育，或丧失/部分丧失劳动能力等非主观原因无法维持正常生活 |
| 数额调整 | 物价上涨、子女患病上学、给付方收入显著变化，可请求增加；给付方确有困难的，可适当降低 |

## 五、探望权与变更

| 事项 | 口径 |
|---|---|
| 探望权主体 | 不直接抚养子女的父或母 |
| 协助义务 | 直接抚养方不得阻碍 |
| 中止与恢复 | 探望不利于子女身心健康的依法中止；事由消失后恢复 |
| 执行边界 | 强制执行对象是**拒不协助的一方**，**不能强制执行子女的人身**，不能强行带走孩子 |
| 变更抚养关系 | 需出现新的重大事由：与子女共同生活方患严重疾病/伤残无力继续抚养、不尽义务或虐待、8 周岁以上子女愿随另一方且该方有抚养能力等 |

**"不给抚养费"不能抵消探望权，"不让探望"也不等于放弃抚养。**

## 六、脚本用法

```bash
python scripts/support_calc.py --income 10000 --children 1
python scripts/support_calc.py --income-type none --income-year 180000 --children 2
python scripts/support_calc.py --income 12000 --children 1 --child-birth 2015-06-01 --as-of 2026-10-08 --out 结果.md
python scripts/support_calc.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--income` | 月总收入（元），有固定收入时填 |
| `--income-type` | `fixed`（默认）/ `none` |
| `--income-year` | 当年总收入（元），无固定收入时填 |
| `--industry-avg` | 同行业平均月收入（元） |
| `--children` | 子女人数，默认 1 |
| `--child-birth` | 子女出生日期，用于折算给付期限 |
| `--as-of` | 测算基准日，默认今天 |
| `--out` / `--format` | 输出文件与格式（`md` / `json`） |
| `--selftest` | 跑内置自检（12 条断言） |

脚本做三件事：按收入与子女人数算三档月付金额与年付金额 → 按子女人数摊到每人 → 用出生日期折算至 18 周岁的剩余月数与合计区间。

> ⚠️ 输出是**测算区间**，不是判决金额。具体数额以双方协商或人民法院认定为准。

## 七、人工确认（这步不能省）

- [ ] 收入是按"月总收入"还是"基本工资"认定的，是否有奖金津贴未计入
- [ ] 子女实际支出是否明显偏高（重大疾病、特殊教育），是否需要另行主张
- [ ] 是否存在大额择校费、私立学费等需单独协商的项目
- [ ] 8 周岁以上子女的真实意愿如何表达，**有没有被诱导**
- [ ] 证据是否覆盖：收入凭证、子女开支凭证、既往照料事实、对方不利因素
- [ ] 探望安排是否具体（时间、地点、接送方式、寒暑假与节假日）
- [ ] 是否涉及家庭暴力等需要申请人身安全保护令的情形

## 八、最常见的坑

**坑一：以为抢到孩子就能拿到抚养权。**
抢夺、藏匿子女会被认定为不利于子女身心健康，直接影响判定，还可能被罚款、拘留。

**坑二：抚养费按基本工资算。**
应按**月总收入**测算，奖金、津贴、补贴都要计入。对方拿基本工资说事时，要调取流水与个税记录。

**坑三：以为抚养费一成不变。**
物价上涨、子女患病上学、给付方收入显著变化，都可以请求调整。

**坑四：把大额择校费、私立学费默认算进去。**
这类支出通常要另行协商一致或经法院认定必要性，直接按抚养费主张可能不被支持。

**坑五：拿"不给抚养费"卡探望权。**
两个法律关系，不能互相抵消。拒绝协助探望会被强制执行。

**坑六：让孩子当众站队、教孩子说假话。**
一旦被发现，性质比不表态严重得多，还伤害孩子。

**坑七：以为两个孩子一定一人一个。**
法院看的是最有利于子女，两个孩子长期共同生活的，判归一方也很常见。

**坑八：以为非婚生子女没有抚养费。**
非婚生子女享有与婚生子女同等权利，不直接抚养的一方同样应负担。

## 九、边界与免责

- 本技能只做**规则整理与金额测算**，不构成法律意见，不代理案件，不承诺判决或调解结果
- 判定口径与比例标准**以现行《民法典》及司法解释和受诉法院认定为准**，本技能不引用具体条款号
- 涉及家庭暴力、虐待、遗弃的，应第一时间报警并申请人身安全保护令，不以本技能替代紧急处置
- 本技能不得用于伪造收入证明、开支票据，或策划抢夺、藏匿子女
