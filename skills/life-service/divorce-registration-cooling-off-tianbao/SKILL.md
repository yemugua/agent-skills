# 离婚登记冷静期与协议离婚流程核查（divorce-registration-cooling-off）

协议离婚最常见的三个坑：**冷静期从哪天算没搞清、届满后三十日内没去领证、离婚协议要素写漏导致被退回**。

这个技能做四件事：**算日期** → **定管辖** → **核协议要素** → **查不适用情形**。

> **本技能不做感情建议，不判断该不该离婚。** 只做流程、日期与材料的核查。

---

## 硬边界（先看这条）

| 能做 | 能做（续） | 不能做 |
|---|---|---|
| 按申请受理日算冷静期起算与届满 | 列出离婚协议必备要素 | ❌ 判断该不该离婚、劝和或劝离 |
| 算届满后三十日的领证窗口 | 提示哪些情形不适用协议离婚 | ❌ 代写离婚协议的具体条款内容 |
| 提示管辖机关的判定方向 | 说明逾期视为撤回的后果 | ❌ 承诺一定能办成离婚登记 |
| 提示常见被卡原因 | 提示财产分割与债务的注意点 | ❌ 提供转移财产、逃避债务的办法 |

**遇到以下情况，直接问婚姻登记机关或咨询专业法律人士：**
- 一方不同意离婚，或对子女抚养、财产分割无法达成一致
- 涉及家庭暴力、虐待、遗弃等情形
- 一方为无民事行为能力人或限制民事行为能力人
- 涉及境外婚姻、涉外因素、涉港澳台
- 结婚证遗失、信息不一致，或婚姻登记档案查不到
- 财产涉及公司股权、境外资产、未办证房产、共有产权
- 涉及未成年子女抚养权、探视权的具体安排

**永远不要为转移财产、逃避债务而设计离婚方案。** 这类安排可能被依法撤销，并可能承担相应法律后果。

## 三、冷静期的日期口径（本技能最核心的部分）

协议离婚的冷静期规则是：**自婚姻登记机关收到离婚登记申请之日起三十日内，任何一方可以撤回申请；前述期限届满后三十日内，双方应当亲自到婚姻登记机关申请发给离婚证；未申请的，视为撤回离婚登记申请。**

| 节点 | 口径 | 说明 |
|---|---|---|
| **起算日** | 婚姻登记机关**收到离婚登记申请之日** | 不是双方商量好的那天，不是递交材料的那天（若材料不齐未受理） |
| **冷静期长度** | **三十日** | 期间任何一方可撤回 |
| **冷静期届满日** | 起算日 + 30 日 | 届满后才进入领证阶段 |
| **领证窗口** | 届满日起 **三十日内** | 双方**必须共同到场**申请发证 |
| **逾期后果** | **视为撤回离婚登记申请** | 想继续办理需重新申请，冷静期重新计算 |

> **以上为现行规定的通用口径，具体日期计算与受理流程以现行规定和办理地婚姻登记机关要求为准。** 部分环节是否含法定节假日、是否按工作日计算，各地执行可能不同，务必以登记机关答复为准。

> ⚠️ **最容易错的一点**：冷静期届满**不等于**自动离婚。必须在届满后的三十日内**双方共同到场**申请发证，否则视为撤回。

## 四、协议离婚五段流程

| 段 | 做什么 | 谁要到场 | 关键注意 |
|---|---|---|---|
| 1 | 提交离婚登记申请与材料 | **双方共同** | 材料不齐可能不予受理，起算日以受理日为准 |
| 2 | 登记机关受理 | — | 拿到受理凭证，记下起算日 |
| 3 | 冷静期三十日 | — | 任何一方可撤回 |
| 4 | 冷静期届满后三十日内申请发证 | **双方共同** | 逾期视为撤回 |
| 5 | 审查、登记、发证 | **双方共同** | 审查通过才发给离婚证 |

> **两次到场都不能少**：提交申请一次，领取离婚证一次。只去第一次，等于白走一趟。

---

## 五、离婚协议七项要素

完整要素与常见遗漏见 `rules/cooling_off_rules.md`。核心七项：

| # | 要素 | 要点 | 写漏会怎样 |
|---|---|---|---|
| 1 | 双方自愿离婚的意思表示 | 明确、无条件 | 不予受理 |
| 2 | 子女抚养安排 | 由谁直接抚养、抚养费数额与支付方式 | 退回补正 |
| 3 | 探视权安排 | 时间、方式、交接 | 后续纠纷高发 |
| 4 | 夫妻共同财产分割 | 列明财产并写明归属 | 后续执行困难 |
| 5 | 共同债务处理 | 列明债务并写明承担 | 容易遗漏、后患大 |
| 6 | 隐匿转移财产的处理约定 | 写明违约责任 | 事后维权困难 |
| 7 | 其他需要约定的事项 | 户口迁出、姓名变更、协助义务 | 视情形 |

## 六、不适用协议离婚的情形（部分列举）

| 情形 | 说明 | 方向 |
|---|---|---|
| 一方不同意离婚 | 协议离婚需双方自愿 | 走诉讼途径 |
| 对子女抚养、财产分割无法达成一致 | 协议不成 | 走诉讼途径 |
| 一方为无民事或限制民事行为能力人 | 协议离婚要求双方具有完全民事行为能力 | 走诉讼途径 |
| 未办理结婚登记 | 不存在婚姻关系，无需离婚 | 按同居关系处理 |
| 涉外、涉港澳台婚姻 | 有特殊规定 | 咨询登记机关或专业人士 |

> **诉讼离婚不适用离婚冷静期规定。** 具体程序与期间以现行规定和人民法院要求为准。

## 七、办理时限

- 冷静期为**三十日**，自婚姻登记机关收到离婚登记申请之日起算。
- 冷静期届满后**三十日内**双方应共同申请发证。
- **整体最短周期 = 30 日冷静期 + 领证申请日**，实际还受材料补正、审查、登记机关工作安排影响。
- 逾期未申请发证的，**视为撤回**，需重新申请，冷静期重新起算。
- 具体日期计算是否含节假日、是否按工作日计，以办理地婚姻登记机关答复为准。

## 八、脚本用法

```bash
python scripts/divorce_cooling_check.py --apply-date 2026-10-08 --as-of 2026-10-08 --out 结果.md
python scripts/divorce_cooling_check.py --file 情况.txt --apply-date 2026-09-20
```

| 参数 | 说明 |
|---|---|
| `--apply-date` | 离婚登记申请受理日（冷静期起算日） |
| `--as-of` | 核查基准日，默认今天 |
| `--file` / `--text` | 情况说明文本，用于扫描协议要素与被卡原因 |
| `--out` | 输出路径，默认打到屏幕 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本做五件事：
1. **冷静期换算**：起算日、届满日、剩余天数
2. **领证窗口**：届满后三十日的窗口起止与剩余天数
3. **状态判定**：冷静期内 / 已届满待领证 / 已逾期视为撤回
4. **协议要素核查**：七项要素是否提到
5. **被卡风险**：六类高频被卡原因是否命中

> ⚠️ 脚本只算日期与做关键词匹配，**不构成法律意见**，也不代表登记机关的受理结论。

## 九、人工确认（这步不能省）

- [ ] 起算日以**登记机关实际受理**的日期为准，不是自行商定的日期
- [ ] 冷静期届满后的**三十日**内双方是否都能到场，是否已排好时间
- [ ] 离婚协议七项要素是否都写到了，尤其是**共同债务**与**隐匿财产的处理**
- [ ] 财产清单是否完整：房产、车辆、存款、理财、股权、公积金、保险、债务
- [ ] 子女抚养与探视的安排是否具体到可执行
- [ ] 管辖机关是否已确认，异地办理是否符合当地现行条件
- [ ] 结婚证是否完好，信息与身份证是否一致
- [ ] 涉及股权、境外资产、公司财产的，是否已咨询专业人士

## 十、输出结构（固定六段）

1. **适用路径** —— 协议离婚 / 诉讼离婚 / 不明确
2. **日期节点** —— 起算日、冷静期届满日、领证窗口起止、剩余天数
3. **当前状态** —— 冷静期内 / 届满待领证 / 已逾期视为撤回

5. **被卡风险** —— 命中的高频被卡原因
6. **不适用情形提示** —— 命中的情形与应走的方向

## 十一、最常见的坑

**坑一：以为冷静期一过就自动离婚了。**
冷静期届满只是进入领证阶段。**必须在届满后的三十日内双方共同到场申请发证**，否则视为撤回，前面的等待白等。

**坑二：起算日算错。**
起算日是**登记机关收到离婚登记申请之日**。材料不齐被退回补正的，以实际受理日为准，不是第一次跑腿的那天。

**坑三：只去了一次。**
协议离婚要**两次共同到场**：提交申请一次，领证一次。只去第一次，等于没办完。

**坑四：离婚协议只写"财产已分割完毕"。**
不列明具体财产与归属，事后执行困难，也容易被登记机关退回补正。要列清单、写明归属。

**坑五：漏写共同债务。**
只分财产不写债务，是最常见的遗漏，也是事后纠纷最多的地方。债务要列明并写明由谁承担。

**坑六：拿诉讼离婚的经验套协议离婚。**
诉讼离婚不适用三十日冷静期的规定，但协议离婚适用。两条路的流程、期间、结果完全不同。

**坑七：用离婚来转移财产、逃避债务。**
这类安排可能被依法撤销，并可能承担相应法律后果。本技能不提供此类方案。

**坑八：异地办离婚没先确认管辖。**
异地办理有适用条件，且各地执行口径不同。先向拟办理地婚姻登记机关确认，再安排时间。

## 十二、边界与免责

- 本技能**不做感情建议**，**不判断该不该离婚**，不劝和也不劝离
- 本技能**不代替**婚姻登记机关的受理与审查，**不构成**法律意见
