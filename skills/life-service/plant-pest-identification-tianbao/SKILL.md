# 植物病虫害识别特征与防治类别（plant-pest-identification）

植物出问题的第一件事是**认对人**。白粉病当蚜虫治、白粉病当霜霉病治，方向错了，投入再多也白搭；而看到虫子就喷药，往往把天敌也一起灭掉，第二年虫子更凶。

这个技能做三件事：**按特征认 → 分清类别 → 选防治方式**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 按症状形态与分布给出识别特征对照 | ❌ 诊断病原种类并给出病原学结论 |
| 给出可能病因的多个候选并说明如何区分 | ❌ 推荐任何农药品牌、成分与商品 |
| 给出生物、物理、化学三类防治方式的适用情形 | ❌ 给出具体药剂名称、浓度、剂量与配比 |
| 给出观察、记录与上报口径 | ❌ 判断是否需要检疫处理或上报 |
| 给出家庭与开放环境下的安全边界 | ❌ 判断施药对传粉昆虫与水生生物的影响 |

**遇到以下情况，停止自行处理，转交当地植保机构或农技推广部门：**

- 疑似检疫性病虫害（按当地规定的检疫对象清单核对）
- 疑似病毒类病害（花叶、斑驳、条纹症状）
- 大棚、农田等生产场所的病虫疫情
- 需要鉴定害虫种类以确定防治方案
- 需要确定用药品种、剂量、次数与安全间隔期
- 家庭以外公共空间的绿化养护用药

**安全红线（必须遵守）：**

1. **不推荐具体农药商品**：本技能的「化学防治」只写**方式类别与适用情形**，不写商品名、成分名、浓度与配比。**药剂的品种、用量、次数与安全间隔期以产品登记标签和当地植保部门要求为准。**
2. **禁限用农药一律不使用**：包括国家明令禁止在蔬菜、果树、茶叶上使用的品种。
3. **家庭与阳台环境优先不用化学杀虫剂**：室内、半封闭阳台、通风不良处原则上只用物理与生物方式；确需化学防治时，应在傍晚施用并充分通风。
4. **食用农产品安全间隔期**：任何用于可食部位的药剂，必须严格执行标签规定的**安全间隔期**，**安全间隔期内不采收**。这是自我约束，也是硬要求。
5. **防护**：施药时戴手套、口罩、长袖；不逆风施药；不与家人共用同一套喷雾器具而不清洗。
6. **养宠与养鱼家庭**：拟除虫菊酯、有机磷类等对猫、犬、观赏鱼毒性较大，家中有这些动物时**不使用此类药剂**，并把植物与水体隔离；**鱼缸水面上方不得施药**。
7. **废弃物**：药剂包装与剩余药液按规定回收处置，**不得倒入下水道、池塘或菜地**。

## 二、完整工作流

```
第 1 步  先看部位：叶面、叶背、茎、果实、根，各部位对应不同类群
第 2 步  再看形态：粉层、霉层、网、点、斑、瘤、丝、蛀孔
第 3 步  看分布：只在一株、在一片、蔓延快、集中在新叶还是老叶
第 4 步  用摇动/放大/白纸法确认有无活体
第 5 步  按特征表给出 2-3 个候选与区分方法
第 6 步  选防治方式类别：物理、生物、化学，按环境与规模选
第 7 步  记录与复看：3-7 天后回看，验证方向对不对
第 8 步  复发则升级：范围扩大或出现检疫嫌疑，转植保机构
```

**顺序不能颠倒**：不确认有没有活体就下药，是最常见的白花钱。

## 三、常见病害识别特征表

| 病害 | 部位 | 形态特征 | 分布特点 | 可能混淆 |
|---|---|---|---|---|
| 白粉病 | 叶面为主 | 白色或灰白色粉状霉层，像撒了层面粉，擦得掉 | 叶片正面，扩展快，常连片 | 霜霉病、灰尘 |
| 霜霉病 | 叶面 | 叶片出现水浸状黄斑，叶背对应位置有灰紫色霉层 | 叶背有霉是判据，位置与正面斑一一对应 | 白粉病 |
| 锈病 | 叶面 | 淡黄小斑后长出黄褐色或锈褐色粉状小疱 | 常有褪绿小斑在前、锈粉在后两个阶段 | 白粉病、蚜虫分泌物 |
| 炭疽病 | 果实、茎、叶 | 圆形或不规则褐色或黑褐斑，中心凹陷并有黑色小点 | 果实上凹陷明显 | 疫病、日灼 |
| 疫病 | 果实、茎基 | 水浸状暗绿斑，迅速扩大变褐腐烂 | 果实上呈油浸状软腐 | 炭疽、软腐 |
| 软腐病 | 茎基、果 | 组织软烂、有腥臭，渗出黏液 | 常从伤口或虫害处开始 | 疫病 |
| 青枯病 | 茎、根 | 茎基部变褐，纵切可见维管束变褐 | 植株中午萎蔫、夜间恢复，数日全株枯死 | 枯萎病、缺水 |
| 病毒类 | 全株 | 花叶、斑驳、条纹、叶片皱缩畸形、植株矮化 | **系统性病害，新叶症状更明显** | 缺素、药害 |
| 缺素（非病害） | 全株 | 均匀黄化或叶脉间黄化，按叶龄分布有规律 | 与施肥记录吻合 | 白粉病初期、病毒 |
| 药害（非病害） | 叶面 | 灼斑、药斑、畸形，常在施药后 1-3 天出现 | 与施药时间高度重合 | 病害、红蜘蛛 |

**最关键的一条区分**：**病害与缺素、药害的区别看分布规律**。病害通常从局部开始逐渐扩散，边界不规则；缺素与药害通常整株或整片同时出现，且与施肥或施药记录对得上。

## 四、常见虫害识别特征表

| 虫害 | 部位 | 形态特征 | 确认方法 | 易混淆 |
|---|---|---|---|---|
| 蚜虫 | 嫩叶、茎、花 | 小型软虫，成群聚在叶背与嫩梢，蜜露发亮，叶片黏 | 摇动枝条，白纸下方有虫落下 | 蓟马、粉虱 |
| 红蜘蛛（叶螨） | 叶背 | 极小，肉眼难辨；叶面出现密集针尖状白点，叶背有细网 | 放大镜看叶背有移动小点；手摸叶面发涩 | 蓟马、白粉病早期 |
| 蓟马 | 花、叶、幼果 | 细长小虫，1-2 mm，受惊快速逃走；花期与幼果期为害重 | 摇动或拍打，看掉落与飞走的小虫 | 蚜虫、小飞虫 |
| 白粉虱（小飞蛾） | 叶背 | 成虫白色小蛾善飞，幼虫与卵在叶背，覆白色蜡粉 | 叶背轻拍，成虫成团飞起 | 蓟马、蚜虫 |
| 蚧壳虫 | 茎、叶、果实 | 固定不动的硬壳状小隆起，褐色或白色，刮掉壳内有虫体 | 硬壳刮不动，用针挑出白色虫体 | 芽鳞、介壳 |
| 青虫（鳞翅目幼虫） | 叶、花、果实 | 粗壮肉质幼虫，体表光滑或具刚毛，**排出明显虫粪** | 见大颗粒深色虫粪即判断 | 蜗牛、蛞蝓 |
| 斑潜蝇 | 叶 | 叶片上白色弯曲潜道隧道 | 叶面出现蛇形白线 | 蓟马危害、叶斑 |
| 蓟马所致花器危害 | 花、幼果 | 花瓣出现褐色斑点，幼果留疤 | 花期加强检查 | 生理落花 |
| 蛞蝓与蜗牛 | 全株尤其夜间 | 留下银白色黏液痕迹与啃食孔 | 夜间用手电检查，黏液是判据 | 啃食孔型虫害 |

**三个快速确认法**：

1. **白纸法**：白纸垫在枝叶下方，轻拍或摇动，纸上掉下小虫即确认有活体。
2. **放大法**：10 倍放大镜看叶背，区分红蜘蛛（移动的点）与白粉病（擦得掉的粉层）。
3. **夜间法**：蛞蝓、蜗牛、某些夜行性虫害白天藏起来，夜间检查更准。

## 五、易混淆对照表

| 对比项 | A | B | 区分要点 |
|---|---|---|---|
| 白粉病 vs 霜霉病 | 正面白色粉层，**擦得掉** | 叶背灰紫霉层，**擦不掉** | 看霉层位置与能否擦掉 |
| 白粉病 vs 灰尘 | 有扩展蔓延、有新叶发病 | 分布均匀、无扩展 | 灰擦掉后叶面是否留痕 |
| 红蜘蛛 vs 蚜虫 | 极小点状，需放大；叶面针尖白点 | 可见成群小虫、蜜露 | 蜜露是蚜虫独有 |
| 红蜘蛛 vs 白粉病早期 | 叶面发涩、有细网 | 有粉层 | 手摸发涩是叶螨 |
| 蓟马 vs 蚜虫 | 受惊快速逃走、不聚团 | 聚团不动、分泌蜜露 | 行为特征 |
| 蚧壳虫 vs 芽鳞 | 刮不动、挑得出虫体 | 属于芽本身的结构 | 能否挑出虫体 |
| 青虫 vs 蛞蝓 | 干颗粒状虫粪 | 银白色黏液痕迹 | 粪便与黏液 |
| 缺素 vs 病毒 | 全株规律、与施肥吻合 | 新叶症状更重、无规律 | 分布规律 |
| 药害 vs 病害 | 与施药时间重合（1-3 天内） | 渐进扩散 | 时间关系 |
| 青枯病 vs 缺水 | 茎基维管束变褐 | 根系正常或干缩 | 纵切茎看维管束 |

## 六、三类防治方式的适用情形

| 方式 | 适用情形 | 具体做法方向 | 局限 |
|---|---|---|---|
| 物理防治 | 虫量少、发生初期、家庭与开放环境 | 手捕、剪除病枝叶、冲水冲洗、黄蓝粘板诱杀、防虫网、调整栽培期避开高峰期 | 虫量大时收效慢 |
| 生物防治 | 虫量已成规模、环境较封闭、需要持续控制 | 保护或释放天敌、使用微生物制剂、诱捕装置 | 见效慢，需提前布置 |
| 化学防治 | 物理与生物手段已不足以控制、虫害扩散迅速、生产场景 | 按当地植保部门指导选择登记药剂，**严格按标签的用量、次数与安全间隔期** | 见效快但风险高，**不推荐具体商品** |

**选择顺序**：**物理 → 生物 → 化学**。能不用化学就不用；必须用时，优先选用**对天敌与传粉昆虫影响小、选择性高**的类别，并严格按标签执行。

**家庭与阳台的特殊边界**：室内与半封闭阳台**原则上不使用化学杀虫剂**；拟除虫菊酯、有机磷类对猫、犬、观赏鱼毒性较大，家中有这些动物时直接排除该类。

## 七、记录与复看

| 时间 | 动作 |
|---|---|
| 发现当天 | 拍照（整体一张 + 局部一张），记录部位、形态、分布 |
| 发现当天 | 做一次确认法（白纸法/放大法/夜间法），确认有无活体 |
| 发现当天 | 记录近期施肥与施药记录，用于排除药害 |
| 处理后 3 天 | 看是否有新病斑、新虫口 |
| 处理后 7 天 | 复看：若范围扩大或出现检疫嫌疑，转植保机构 |

**判断方向对不对**：**有效的处理，新症状出现的速度会明显放缓**。7 天后仍在快速扩散，通常是认错了类群，或只处理了症状没处理根源（如施药后虫转移到未处理的邻株）。

## 八、脚本用法

```
python scripts/pest_id.py --file pest.json
python scripts/pest_id.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`part`（部位）、`sign`（形态特征代号）、`distribution`（分布）、`has_live`（是否有活体）、`env`（环境：indoor/balcony/garden/field）、`has_pets`（家有无猫犬观赏鱼）、`signs`（症状列表） |
| `--json` | 以 JSON 输出 |
| `--out` | 结果写入指定文件，默认 `scripts/_last_result.txt` |
| `--selftest` | 运行自检 |

脚本做四件事：**按部位与形态给候选清单与区分方法 → 判断有无活体并分流 → 按环境与是否有宠物推荐防治方式类别 → 给出必须转专业机构的提示**。脚本**不输出任何药剂名称、品牌、浓度与配比**。

## 九、人工确认清单（这步不能省）

- [ ] 先记了部位（叶面/叶背/茎/果/根）

## 十、最常见的坑

**坑一：看到白粉就喷药，把霜霉病当白粉病治。**
错误做法：叶子上有白的东西就当白粉病。正确做法：**白粉病在叶面且擦得掉，霜霉病的霉层在叶背且擦不掉**。认错了，打再多药也是白打，两种病的防治方向完全不同。

**坑二：没确认有没有活体就下药。**
错误做法：看到叶面异常就喷。正确做法：先用白纸法或放大法确认有无活体。**没有活体就不是虫害**，那是病害、缺素或药害，三类处理方式完全不同。

**坑三：见虫就用药，把天敌也灭掉。**
错误做法：蚜虫一出现就喷。正确做法：先上黄板、冲水、剪除受害枝叶；**瓢虫、草蛉、蚜小蜂这些天敌被一起灭掉后，第二年虫子往往更凶**。

**坑四：把药害当病害治。**
错误做法：叶子有斑就按病害处理。正确做法：查最近 1-3 天有没有施药。**药害的特征是与施药时间高度重合**，先排除它，否则会连续误判。

**坑五：把缺素当病害，反复用药。**
错误做法：叶黄就是有病。正确做法：查施肥记录。**缺素通常全株或整片同时出现且分布规律，病害往往从局部开始、边界不规则**。这一条能省掉大量误判。

**坑六：家里有猫还拟除虫菊酯。**
错误做法：宠物在场也照喷。正确做法：家中有猫、犬或观赏鱼时，**直接排除对它们毒性大的类别**，把植物移到隔离位置处理。鱼缸水面上方不得施药。

**坑七：可食部位不看安全间隔期。**
错误做法：打了药第二天就摘来吃。正确做法：**严格执行标签规定的安全间隔期，期内不采收**。这不是"最好做到"，是硬要求。

**坑八：施药后不复看，方向错了还继续加量。**
错误做法：喷了没好转就加量再喷。正确做法：处理后 3 天、7 天各复看一次。**7 天后仍在快速扩散，通常是认错了类群**，继续加量只会加重药害与抗性风险。
