# 石棉与高危粉尘管控（asbestos-management）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《石棉作业场所有害因素职业接触限值》与职业病防治要求，生成清单：含石棉材料排查与台账、拆除作业审批与专业队伍、湿式作业与负压防护、废弃物包装与处置、职业健康检查与告知。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 石棉拆除
- 石棉危害告知
- 石棉废弃物处置
- 含石棉材料排查
- 保温层职业危害

## 三、工作流
1. 排查含石棉材料并建立台账
2. 办理拆除审批并选专业队伍
3. 采取湿式作业与负压防护
4. 规范废弃物包装与处置
5. 落实健康检查与危害告知

## 四、核心内容（检查清单与判定）
石棉纤维肉眼不可见且潜伏期长达数十年，拆除时一旦扬尘影响极大。必须由具备资质队伍实施，严禁干式敲打与普通工具切割。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含含石棉材料排查与台账 | 台账 |
| Q2 | FAIL | 未含拆除审批与专业队伍 | 资质 |
| Q3 | FAIL | 未含湿式作业与负压防护 | 防护 |
| Q4 | FAIL | 未含废弃物包装与处置 | 处置 |
| Q5 | WARN | 未含健康检查与危害告知 | 告知 |

> 脚本 `asbestos-management_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python asbestos-management_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python asbestos-management_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
