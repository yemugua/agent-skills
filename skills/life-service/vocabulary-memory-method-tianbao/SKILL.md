# 单词记忆方法与复习计划

单词记不住，**绝大多数不是记性差，而是方法用错了**：反复重读带来的「熟悉感」被误认成「记住了」。本技能只解决这一件事——把「看」换成「回忆」，把「集中突击」换成「间隔重复」，并给出可排期的每日复习量。

## 一、硬边界（能做 / 不能做）

| 能做 | 不能做 |
|---|---|
| 判定用户的记忆失败原因（重读型/无复习型/无提取型） | 断言某个词「一定记得住」 |
| 生成间隔复习日程与每日复习量 | 承诺词汇量提升的具体达标时间（个体差异大） |
| 给出词根词缀/例句/联想法的选用规则 | 提供针对特定考纲的官方词表（以官方现行大纲为准） |
| 判断记忆工具该怎么用、用什么节奏 | 判定用户的记忆障碍或给出医学结论 |
| 估算复习负荷是否超出可用时间 | 承诺「不遗忘」或给出精确留存率承诺 |

**必须转交专业人士：** 怀疑存在记忆障碍、读写障碍、注意力缺陷，或出现因学习压力引发的持续失眠、情绪崩溃、躯体症状——应转教育心理或医疗机构评估，不要靠调整背单词方法解决。

## 二、什么时候用

| 用户说法 | 用不用 | 说明 |
|---|---|---|
| 单词总记不住 | 用 | 先判失败原因，多数是重读型 |
| 看了三遍还是想不起来 | 用 | 典型「熟悉感误认为记忆」 |
| 背单词书有用吗 | 用 | 给出「只看不回忆」的具体修正法 |
| 艾宾浩斯怎么安排 | 用 | 给节点表与跳过规则 |
| 每天背多少词合适 | 用 | 按可用时间反推每日新增量 |
| 词汇量多久能到某个水平 | 用 | 给区间估算与达成条件，不给承诺 |
| 背单词 App 怎么用 | 用 | 给节奏建议，不做产品推荐 |
| 失眠/焦虑到学不下去 | 部分用 | 先转介，不给学习计划 |

## 三、完整工作流

### 步骤 1：先判失败原因（不判就开方，一定开错）

| 症状 | 类型 | 对策方向 |
|---|---|---|
| 眼熟但说不出意思 | **重读型** | 全部改成遮盖自测 |
| 说得出但拼写/听写错 | **提取通道单一** | 增加拼写与听辨通道 |
| 当天都会、隔天全忘 | **无复习型** | 建立间隔复习表 |
| 一直很努力却没长进 | **负荷超限** | 降低每日新增量，先补复习 |
| 只会认识、不会用在句子里 | **孤立型** | 加例句与输出 |

### 步骤 2：选记忆技术（每个词只选一到两种，别叠满）

详见 `rules/记忆技术对照表.md`。核心原则：**一个词配一个「提取线索」**，而不是记五个知识点。

### 步骤 3：排间隔复习日程

详见 `rules/艾宾浩斯节点与复习量.md`，用 `scripts/ebbinghaus_schedule.py` 生成。

### 步骤 4：设完成标准（这一步决定成败）

「记住了」的判定必须写成可执行动作，例如：看到英文能说出中文大意 + 能拼写 + 能放进一个自造句子里。三项中至少两项达标才算过。

### 步骤 5：每周用留存表现校准

连续两轮仍有大量遗忘，说明**间隔拉长得太快或每日新增量过大**，按规则文件里的校准表往回调，不要靠意志硬扛。

## 四、核心规则（生成计划前必读）

**先读 `rules/记忆技术对照表.md` 与 `rules/艾宾浩斯节点与复习量.md`，不要凭印象排计划。**

**主动回忆为什么优于重复阅读：**

重读时你处在「被提示」状态——眼睛看到答案的瞬间大脑不费力，所以有轻松感；而回忆时你必须**主动从记忆中提取**，提取过程本身才 strengthen 记忆连接。实验上二者同等时间的保持率差别显著，而且重读带来的轻松感会让人**高估自己的掌握程度**，于是复习量越来越少，最后崩塌。

一句话：**重读的舒适感是学习最大的陷阱。**

## 五、脚本用法

脚本：`scripts/ebbinghaus_schedule.py`

```bash
python scripts/ebbinghaus_schedule.py --file 词汇计划.json
python scripts/ebbinghaus_schedule.py --file 词汇计划.json --json
python scripts/ebbinghaus_schedule.py --selftest
```

| 字段 | 说明 |
|---|---|
| `start_date` | 起始日期（YYYY-MM-DD） |
| `daily_new` | 每日新增词数 |
| `intervals` | 复习间隔天数列表，缺省用默认节点 |
| `review_cap` | 每日复习上限，缺省不限 |

输出：逐日复习清单、每日复习负荷峰值、负荷超限预警与调参建议。

## 六、人工确认清单（不能省）

- [ ] 用户的可用学习时间是多少（不是「有多少学多久」）？
- [ ] 每日新增量是否已按复习负荷反推过，而不是拍脑袋定的？
- [ ] 每个词是否都配了提取线索，而不是只读了释义？
- [ ] 完成标准是否写成可执行动作（能说出/能拼写/能造句）？
- [ ] 是否已有至少两轮间隔复习，而不是学完当天就结束？
- [ ] 单词书是否被当作「查词工具」而非「从头顺读的材料」？
- [ ] 是否有每日固定时段（同一时间同一地点）？

## 七、最常见的坑

1. **把单词书从第一页顺读到最后一页**。这是最普遍的错误用法，产出的是「认识感」不是「记忆」。正确做法：只用来查词与核对，学习走自己的复习队列。
2. **只看不遮盖**。遮盖自测的那几秒不适感，正是记忆强化的环节；跳过它等于取消了复习。
3. **复习间隔一开始就拉很长**。前几次间隔拉太开，前面建立的连接还没稳住就断了。正确做法：前几个节点保持密集，答对再逐步拉长。
4. **一次背太多**。每日新增量必须为复习负荷留出空间，否则复习队列永远追不上，最终放弃。
5. **追求「全认识」而不是「能回忆」**。认识是提示下的识别，回想是独立提取，二者不能互相替代。
6. **用抄写代替提取**。抄写三遍的机械动作几乎不产生提取训练，属于低效重复。
7. **只在整块时间背**。间隔复习本身只需要几分钟，塞在通勤、课间就能完成；整块时间反而难坚持。
8. **把「没记住」当成需要更用力**。多数情况是间隔设置问题或新增量过大，换个更狠的惩罚只会更快放弃。
9. **一个词记五个意思还嫌不够**。提取线索越多越互相干扰，单词应先锁定一个核心义与其搭配。
10. **从不检查是否真的会用**。只会认不会用，在真题和口语里等于不会。

## 八、边界与免责

本技能提供记忆方法、复习日程与负荷计算，**不提供诊断、不替代专业教学**。学习效果受睡眠、情绪、基础与学习时长等多因素影响，脚本给出的节奏是起点不是终点，请按实际表现校准。各类考试的词汇要求与大纲请以官方现行规定为准，不要以本技能的数字为准。
