# 单词记忆方法与复习计划

## 你会得到什么

把「背单词记不住」拆成一个可诊断、可排期、可校准的问题，而不是一句「要多背」。

**一、先判失败原因。** 眼熟但说不出意思，是重读型；当天都会隔天全忘，是无复习型；说得清但拼写错，是提取通道单一；很努力却没长进，是负荷超限。判错类型就开错方。

**二、主动回忆为什么比反复阅读有效。** 重读时你处在「被提示」的状态，看见答案毫不费力，因此产生轻松感；回忆时必须主动从记忆里提取，而**提取过程本身才强化记忆连接**。更麻烦的是重读带来的轻松感会让人高估掌握程度，于是复习量越来越少，最后整体崩塌。一句话：重读的舒适感是学习最大的陷阱。

**三、具体到能照做的记忆技术。** 词根词缀法（记一个词根带整族）、例句法（记真实句子而非孤立释义）、联想法（画面感优先，平常联想无效）、拼写分块法、对比法、图像法。每词只配**一个**提取线索，叠满反而互相干扰。

**四、复习间隔与每日复习量的算法。** 默认节点是当天、1 天、3 天、7 天、15 天、30 天、60 天。答对拉长间隔，答错缩回上一节点（**不是重头开始**）。复习负荷决定每日新增量上限：负荷算出来超出可用时间，先降新增量，再减节点，最后才延长周期——绝不在复习堆积时继续加新词。

**五、词汇量达成节奏的条件式估算。** 给的是「在复习队列不掉队的前提下需要多久」，同时提醒：主动词汇远少于被动词汇，达到数字后的维持成本远高于积累成本。

## 典型用法

- 「看了三遍还是想不起来」：判定为重读型，全部改成遮盖自测。
- 「每天背多少词合适」：按可用时间反推，而不是拍脑袋。
- 「艾宾浩斯怎么安排」：给节点表 + 跳过规则 + 答错缩间隔规则。
- 「单词书从头读有用吗」：指出这是最普遍的误用，单词书只应作查词工具。
- 「App 到期复习堆成山」：新增量过大，按校准表下调。

## 脚本

`scripts/ebbinghaus_schedule.py` 读入计划 JSON，输出逐日复习清单、每日负荷峰值、负荷超限预警与调参建议，带 `--selftest`。

## 边界

不提供诊断，不替代专业教学，不承诺词汇量达标日期。学习效果受睡眠、情绪与基础影响，脚本给出的节奏是起点不是终点。各类考试的词汇要求以官方现行大纲为准。
