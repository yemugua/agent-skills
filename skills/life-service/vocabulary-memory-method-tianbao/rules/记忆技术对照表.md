# 单词记忆技术对照表

> 生成学习计划前先读本文件，不要凭印象给建议。**一个词只选一到两种技术**，叠满是反效果。

## 一、技术总览

| 技术 | 适用词类 | 具体做法 | 成本 | 主要弱点 |
|---|---|---|---|---|
| **词根词缀法** | 有明显词根的学术词、派生词族 | 记住一个词根，连带认出整族词 | 前期高、后期极低 | 对完全无规律的外来词无效 |
| **例句法** | 抽象名词、一词多义 | 记一个真实句子，不记孤立释义 | 中 | 句子本身不熟时会卡住 |
| **联想法** | 抽象概念、术语 | 造一个夸张、荒谬、有画面感的联想 | 中 | 联想不平凡才有效，平常联想无用 |
| **拼写分块法** | 长单词、易拼错词 | 按音节/词块分段拼，而非逐字母 | 低 | 需要先会读 |
| **对比法** | 易混形近词 | 成对记忆差异点（如 adapt/adopt） | 低 | 只对易混组有效 |
| **图像法** | 名词、空间概念 | 在脑中放一张清晰画面 | 低 | 抽象动词不适用 |
| **重复朗读法** | 发音、听力辨音 | 读出声，重点在听辨而非朗读 | 低 | **不产生提取训练，单独用无效** |

## 二、选用决策树

```
这个词有可识别的词根或前缀吗？
├─ 有 → 词根词缀法（记词根，带整族）
│        └─ 同族还有 2 个以上词没一起记 → 一次记一整族
└─ 无 → 释义本身抽象吗？
         ├─ 抽象 → 例句法（真实句子 + 自己的例句各一个）
         └─ 具体 → 能画出来吗？
                  ├─ 能 → 图像法 + 联想法
                  └─ 不能 → 联想法（画面感优先）
```

**任何情况下，长单词额外配拼写分块法。**

## 三、每词最小学习卡（模板）

不要写「意思 + 例句 + 词根 + 联想」四栏全满。一张卡只放**一个提取线索**加**一个验证动作**：

```
单词：__________
核心义（只写 1 个）：__________
提取线索（词根 / 画面 / 例句，任选 1）：__________
验证动作：□ 遮盖说中文  □ 听写拼写  □ 填进自己造的句子
下次复习日期：__________
```

**验证动作三选一即可，跨词轮换**，用于打通不同提取通道。

## 四、主动回忆的执行方式

| 环节 | 正确做法 | 错误做法 |
|---|---|---|
| 呈现 | 只看单词面，遮住释义 | 单词和释义同时看 |
| 提取 | 说出/写出中文大意（凭记忆） | 眼睛在释义上滑一遍 |
| 核对 | 说完再翻开对照 | 边看边确认 |
| 判定 | 全对 → 拉长间隔；错/想不起 → 缩回上一节点 | 想不起就跳过这词 |
| 记录 | 只记「对/错」与下次日期 | 抄写释义三遍 |

**时间分配原则**：单张卡在**提取阶段耗时越短越好**，因为提取快说明线索好；卡住超过约定时间应判定为失败并缩间隔，不要硬磨。

## 五、记忆软件的使用节奏

| 场景 | 建议节奏 |
|---|---|
| 每日新词 | 固定时段一次性完成，或拆成早晚两次 |
| 复习队列 | 每天固定次数（如早一次、晚一次），**不要只在睡前** |
| 每日总时长 | 与可用时间匹配；宁可缩短新增量也要保住复习队列 |
| 长期停用后 | 先只做复习队列，不新增词，把欠账补完再学新词 |

**判断软件用对没有**：连续两周「到期复习数」稳定、没有堆积到看不完，说明节奏合适；到期堆积说明每日新增量过大，应下调。

## 六、常见误用对照

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 单词书从第一页读到最后一页 | 顺序阅读产生的是顺序熟悉感，不是记忆 | 单词书只作查词与核对用 |
| 抄写三遍 | 机械动作不触发提取 | 遮盖自测 |
| 一个词背五个释义 | 线索互相干扰 | 先锁一个核心义 |
| 只用 App 的「新词」按钮 | 忽略到期复习队列才是主体工作 | 先清复习队列再学新词 |
| 靠意志硬撑到期复习 | 负荷超出时间后会整体崩盘 | 按规则文件调低新增量 |
| 追求一天背五百词 | 复习负荷失控 | 按脚本算出的上限反推 |
