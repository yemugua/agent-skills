# 艾宾浩斯节点与复习量

> 排复习日程前先读本文件。所有数字都是**起点**，必须按实际表现校准。

## 一、默认复习节点（天）

默认节点按「学完当天 → 逐步拉长」设计：

```
第 0 天（当天）→ 第 1 天 → 第 3 天 → 第 7 天 → 第 15 天 → 第 30 天 → 第 60 天
```

**为什么前期密集后期稀疏**：前期记忆还脆弱，连接容易断；后期连接已稳定，拉长间隔的边际收益高而单位时间成本上升。

**为什么要有第 0 天**：学完当天遮盖自测一次，成本最低，收益最高。这一步漏掉，后面所有节点的通过率都会下降。

## 二、间隔调整规则

| 本次回忆结果 | 下次间隔 | 说明 |
|---|---|---|
| 完全想不起 / 空白 | **退到上一个节点或当天再来一次** | 不是重头开始 |
| 想起但很慢、有明显犹豫 | **保持当前间隔，不拉长** | 慢说明连接弱 |
| 快速准确 | 拉长到下一个节点 | |
| 连续两次快速准确 | 可额外拉长一档 | 只在长期稳定时用 |

**核心规则：答错时缩间隔，不是重置进度。** 重置会让整个计划变得不可能完成。

## 三、复习负荷计算（脚本做的就是这个）

设：

```
每日新增 = N
节点个数 = K（含当天）
稳定期时，第 d 天到期复习量 ≈ N × (当天到期的节点数)
```

粗略估算稳定负荷：

```
稳定期每日复习量 ≈ N × K / 2
每日总负荷 ≈ N（学新词）+ 稳定期每日复习量
```

**举例**：N = 20、K = 6 → 稳定期每日复习约 60，总负荷约 80 词次/天。

**负荷是否超限的判据**：每日总负荷 ÷ 单词平均处理时间 > 可用学习时间，就是超限。超限时的调整顺序：

1. **先降每日新增量**（最有效）
2. 再减少节点（去掉最长那一档）
3. 最后才考虑延长整体周期

**不要**在复习量堆积时继续加新词——那只会让欠账滚雪球。

## 四、按可用时间反推每日新增量

```
每日新增量 ≈ 可用时间 ÷ (单次处理时间 + 复习摊销时间)
```

粗略经验值（可按个人实际校准）：

| 每日可用时间 | 建议每日新增量区间 |
|---|---|
| 20 分钟以内 | 5—10 词 |
| 30—45 分钟 | 10—20 词 |
| 1 小时以上 | 20—30 词 |

> 超过 30 词/天时，多数人会跳过复习队列；**宁少勿多**是可用的原则。

## 五、词汇量达成节奏（估算，不是承诺）

给出估算时必须同时说明以下条件，否则就是误导：

```
达成天数 ≈ 目标词汇量 ÷ (每日新增量 × 有效复习达成率)
```

其中有效复习达成率指「真正完成全部复习节点的词数 ÷ 计划新增词数」。**若复习队列长期堆积，这个达成率会显著低于 1**，实际耗时会成倍增加。

**必须同时告知用户的三个现实：**

1. **主动词汇（能写出、能用）远少于被动词汇（能认出）**，两者不要混为一谈。
2. 词汇量的「记住」不等于「会用」，考试中真正起作用的是主动词汇。
3. 达到某个数字后，**维持成本远高于积累成本**——不复习照样掉。

**不给精确达标日期**。只给「在复习队列不掉队的前提下，按当前节奏需要大致多久」的条件式表述。

## 六、每周校准表

每周固定做一次，看这五个指标：

| 指标 | 正常 | 异常信号 | 调整方向 |
|---|---|---|---|
| 到期复习堆积量 | 稳定 | 逐周增长 | 降新增量 |
| 单次自测正确率 | 稳定或缓升 | 下降 | 缩间隔 / 降新增量 |
| 完成计划的天数占比 | 大部分 | 经常中断 | 缩小单次时长 |
| 单张卡平均耗时 | 稳定 | 越来越长 | 提取线索设计有问题 |
| 主动可用比例 | 上升 | 长期不上升 | 增加例句与造句练习 |

**校准的原则是提前调，而不是等到崩盘再调。**

## 七、常见误区

1. **节点间隔照抄但从不跳过**——答对了也照样下次再来，负荷浪费在已经稳固的词上。
2. **答错就重头背**——正确做法是缩回上一节点。
3. **只做当天复习，不做隔日复习**——第 0 天的巩固无法替代第 1 天及之后的间隔提取。
4. **把复习队列当成负担**——复习才是主体工作，新增只是输入。
5. **每日新增量按「今天还有多少时间」定**——应按「稳定期复习量已经能消化」定。
6. **考前突击的间隔还照常排**——考前时间短，应加密而不是按长间隔。
7. **用「已学词数」当成绩**——真正该看的是主动可用量与到期复习清零情况。
