# 月子中心/产后康复退费维权核查

## 适用范围
- 月子中心（住家/集中式）、产后康复（产康）机构的消费纠纷
- 典型场景：预付费套餐不退、入住前退订扣高额违约金、服务缩水与虚假宣传、护理不当致产妇/新生儿健康损害、合同主体与收款方不一致、机构停业跑路、月子餐食品安全

## 不适用
- 纯医疗行为纠纷（产科诊疗、手术事故）→ 走医疗纠纷/卫健渠道
- 月子中心劳动用工（月嫂雇佣关系劳动争议）→ 劳动仲裁

## 使用方式
把陈述或聊天记录整理成采集表（见 `templates/月子中心信息采集表.md`），交给主脚本：

```
python scripts/postpartum_refund_check.py 采集表.md --out 报告.md
python scripts/postpartum_refund_check.py 采集表.md --json
```

## 输出
9 段结构化报告，含结论摘要（通过/有风险/不通过/待补正）、合同与主体一致性、付款与预付费口径、母婴健康损害识别、证据清单、维权路径、待办补正动作、边界与纪律。

## 核查要点
1. 有无书面合同/协议、合同主体与收款主体是否一致
2. 是否预付费、剩余入住天数、退费基数测算
3. 付款至个人/现金/微信直转的风险
4. 产妇/新生儿健康损害（黄疸、感染、呛奶、护理不当）的识别与处置优先级
5. 证据清单：合同、付款凭证、沟通记录、服务过程记录、损害病历票据

## 纪律
- 仅做信息核查与维权路径指引，不构成法律意见
- 不提供任何中介、代办投诉或代制证据服务
- 地域差异以当地市场监管与卫健部门公布为准
