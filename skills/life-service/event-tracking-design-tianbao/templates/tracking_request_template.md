## 特殊场景处理

| 场景 | 是否需要额外处理 | 方案 |
|---|---|---|
| 列表曝光 | □ 是 □ 否 | 视口 ≥50% + 停留 ≥500ms + item_id+session_id 去重 |
| 结果类（接口） | □ 是 □ 否 | 在**成功回调**中上报，禁止请求发出即报 |
| 弱网 | □ 是 □ 否 | 队列 + 重试策略 |
| 提前退出 | □ 是 □ 否 | 关键节点立即上报，不攒到结束时 |
| 重复触发 | □ 是 □ 否 | 去重键 ______ |

## 验收标准

- [ ] 抓包确认请求已发出（差异 ≤0.5%）
- [ ] 端上报量与服务端入库量一致（差异 ≤1%）
- [ ] 服务端落库与数仓分区一致（差异 ≤1%）
- [ ] 量级与业务预期一致（差异 ≤20%）
- [ ] 枚举值与设计一致
- [ ] 去重规则生效（重复操作只上报一次）
- [ ] 弱网/提前退出/闪退场景已验证
- [ ] 属性中无个人敏感信息
- [ ] 老版本无此埋点的情况已单独标注
