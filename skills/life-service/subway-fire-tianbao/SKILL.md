# 地铁与轨道交通消防（subway-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《地铁设计规范》GB 50157 与轨道交通消防要求，生成清单：车站防火分区与疏散、区间排烟与联络通道、消防给水与报警、车辆基地消防、运营值守与演练。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 地铁消防
- 轨道交通消防
- 地铁车站消防
- 区间隧道排烟
- 车辆基地消防

## 三、工作流
1. 核查车站防火分区与疏散
2. 检查区间排烟与联络通道
3. 确认消防给水与报警系统
4. 落实车辆基地消防
5. 做好运营值守与演练

## 四、核心内容（检查清单与判定）
GB 50157 规定地铁车站与区间的防火、疏散、排烟与给水要求；地下区间疏散救援困难，联络通道与排烟尤为关键。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含车站防火分区与疏散 | 分区 |
| Q2 | FAIL | 未含区间排烟与联络通道 | 排烟 |
| Q3 | WARN | 未含消防给水与报警 | 给水 |
| Q4 | FAIL | 未含车辆基地消防 | 基地 |
| Q5 | WARN | 未含运营值守与演练 | 值守 |

> 脚本 `subway-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python subway-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python subway-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
