# 员工关系管理（employee-relations）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据员工关系管理实践，生成清单：沟通渠道与诉求受理、劳动争议预防与调解、员工关怀与活动、纪律处分与申诉机制、群体事件与舆情应对。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 员工关系
- 员工沟通
- 劳动争议调解
- 员工关怀
- 员工申诉

## 三、工作流
1. 建立沟通渠道并受理诉求
2. 预防与调解劳动争议
3. 开展员工关怀与活动
4. 规范纪律处分与申诉
5. 应对群体事件与舆情

## 四、核心内容（检查清单与判定）
员工关系重在沟通与预防：畅通诉求渠道、规范处分申诉、做好关怀，把劳动争议化解在早期并防范群体性风险。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含沟通渠道与诉求受理 | 沟通 |
| Q2 | FAIL | 未含劳动争议预防与调解 | 争议 |
| Q3 | WARN | 未含员工关怀与活动 | 关怀 |
| Q4 | FAIL | 未含纪律处分与申诉机制 | 申诉 |
| Q5 | WARN | 未含群体事件与舆情应对 | 应对 |

> 脚本 `employee-relations_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python employee-relations_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python employee-relations_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
