# 消防安全标识标准化（fire-sign-standard）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据 GB 13495《消防安全标志》与 GB 15630《消防安全标志设置要求》，生成消防标识标准化清单：安全出口/疏散/禁火/灭火器材等标识分类、设置位置、完好保持、应急照明与疏散图。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 消防标识
- 消防安全标志
- 疏散指示标志
- 禁火标识
- 灭火器标识

## 三、工作流
1. 按功能分类（安全出口/疏散方向/禁止/警告/灭火器材）
2. 明确设置位置与高度（疏散走道/门口/设施处）
3. 保持完好清晰、不被遮挡
4. 配置应急照明与楼层疏散图
5. 定期巡检与维护

## 四、核心内容（检查清单与判定）
GB 13495/15630 规定消防安全标志的图形、颜色与设置要求；疏散指示标志应设在疏散走道及转角处，应急照明应保证疏散时清晰可辨。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含标识分类（安全出口/疏散/禁火/灭火器材） | 分类 |
| Q2 | FAIL | 未明确设置位置与高度要求 | 位置 |
| Q3 | WARN | 未含完好保持/不被遮挡 | 维护 |
| Q4 | FAIL | 未含应急照明与疏散图 | 照明 |
| Q5 | WARN | 未含定期巡检 | 巡检 |

> 脚本 `fire-sign-standard_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python fire-sign-standard_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python fire-sign-standard_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
