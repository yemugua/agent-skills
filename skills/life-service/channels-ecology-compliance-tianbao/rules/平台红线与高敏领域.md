# 视频号平台红线与高敏领域参考

> 以下为通用合规要点，最终以微信公众平台/视频号官方规则与审核结论为准。

## 一、高敏领域（无资质高风险）

| 领域 | 合规要点 |
| --- | --- |
| 医疗健康 | 个人/无资质不得发布医疗美容、药品疗效、诊疗建议；带货医疗器械、保健食品须对应经营/备案资质；医疗广告须经审查 |
| 药品/医疗器械 | 推广受严格限制，须持牌医药主体与广告审查，个人不得随意推广 |
| 保健食品 | 带货须食品经营资质，不得宣称疾病预防治疗功效 |
| 财经/证券/基金 | 荐股、基金推荐须持牌（证券投资咨询/基金销售资格），不得承诺收益、不得公开招揽、不得代客理财 |
| 时政新闻 | 采编发布须《互联网新闻信息服务许可》，个人账号不得采编时政新闻 |
| 食品/美妆 | 带货须对应商品资质，功效宣称须有依据，不得虚假夸大 |

## 二、平台通用红线

- 低俗、色情、暴力、血腥、惊悚内容
- 标题党、封面党、诱导点赞/关注/转发
- 虚假宣传、夸大功效、绝对化用语（如「第一」「根治」）
- 侵权：搬运未授权影视、音乐、他人原创内容
- 违规站外引流：直接留微信/外链/二维码引导私域
- 诈骗、赌博、违禁品交易等违法内容

## 三、限流常见信号

- 收到平台违规通知（累计多次触发封号）
- 播放量/推荐量异常下跌
- 被用户举报、投诉增多
- 非原创搬运、互动数据异常（刷量）
