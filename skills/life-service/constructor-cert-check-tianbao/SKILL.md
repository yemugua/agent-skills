# 建造师报考注册与继续教育核查（constructor-cert-check）

建造师这条路上有两个坎：**考得过**和**注得上**。

考得过看三件事：学历层次、专业类别、**从事建设工程项目施工管理工作年限**。
注得上也看三件事：受聘单位合规、**继续教育达标**、没有不予注册情形。

这个技能做五件事：**核报考条件** → **算年限缺口** → **查免试资格** → **测注册与继续教育到期** → **排不予注册情形**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 按通行口径核查报考条件与年限 | ❌ 代替各省考务公告与住建主管部门规定 |
| 列出报名与注册材料清单 | ❌ 代为网上报名、代为提交注册申请 |
| 测算注册有效期与延续申请窗口 | ❌ 承诺注册一定会批下来 |
| 计算继续教育学时缺口 | ❌ 代替主管部门认可的继续教育培训 |
| 列出不予注册情形并提示风险 | ❌ 为"挂靠""多单位注册"出主意 |

**遇到以下情况，务必以属地住建主管部门与省级人事考试机构的现行规定为准：**
- 二级建造师的报名条件、合格标准、免试口径与执业地域范围（各省自定）
- 一级建造师的报名时间与资格审核方式（各省不同）
- 继续教育的具体学时构成、认可机构与网络教育平台
- 注册受理部门、材料格式与办理时限
- 境外学历、军校学历、职称证书是否可认

**永远不要把"未缴费"说成"已报名"，也不要把"考试通过"说成"可以执业"。** 资格证书与注册证书是两回事。

## 二、完整工作流

```
第 1 步  分清是"报考前"还是"注册后"：--mode exam 或 --mode reg
第 2 步  先读规则文件 rules/exam_conditions.md 与 rules/registration_and_ce.md
第 3 步  跑核查脚本
    python scripts/constructor_cert_check.py --mode exam --level yiji --education zhuanke \
        --major relevant --work-years 8 --manage-years 5
    python scripts/constructor_cert_check.py --mode reg --level yiji --reg-date 2024-06-01 \
        --ce-hours 80 --age 42
第 4 步  逐项人工确认（脚本按通行口径匹配，不做政策判断）
第 5 步  输出结论表 + 材料补充清单 + 到期时间轴
第 6 步  明确提示：报名入口为省人事考试网，注册由属地住建主管部门受理
```

## 三、一级建造师报考条件（通行口径，详见 `rules/exam_conditions.md`）

| 学历 | 从事施工管理工作年限 | 工作年限（通行表述） |
|---|---|---|
| 大学专科 | 满 **4 年** | 满 6 年 |
| 大学本科 | 满 **3 年** | 满 4 年 |
| 硕士 / 双学士 / 研究生班 | 满 **2 年** | 满 3 年 |
| 博士 | 满 **1 年** | 满 1 年 |

**两个年限口径都要看，卡的是"从事建设工程项目施工管理工作年限"。**

学历越高，施工管理年限要求越低，但**博士也要满 1 年**——学历高的人最容易栽在这一条上。

## 四、二级建造师的三个省级差异

| 差异点 | 说明 |
|---|---|
| 命题与合格标准 | 全国统一大纲，**各省自行命题并组织**，合格线各省自定 |
| 专业口径 | 部分省份允许"相近专业"，部分要求严格对口 |
| 执业地域 | 一般**仅在本省（自治区、直辖市）范围内执业**，跨省通常不能直接通用 |

**在哪儿执业就在哪儿考**，这是最省事也最稳妥的选择。

## 五、九类不予注册情形（详见 `rules/registration_and_ce.md`）

| # | 情形 |
|---|---|
| 1 | 不具有完全民事行为能力 |
| 2 | 申请在**两个或者两个以上单位**注册 |
| 3 | 未达到**继续教育**要求 |
| 4 | 受到刑事处罚尚未执行完毕或执行完毕未满规定年限 |
| 5 | 因执业活动受刑事处罚，自处罚决定之日起**未满 5 年** |
| 6 | 被吊销注册证书，自处罚决定之日起**未满 2 年** |
| 7 | 申请之日前 **3 年**内担任项目负责人期间项目发生**重大质量安全事故** |
| 8 | 年龄超过 **65 周岁** |
| 9 | 法律、法规规定不予注册的其他情形 |

**否定词意识（防误伤）：**

| 表述 | 正确理解 |
|---|---|
| 「已取得资格证书」 | ≠ 可以执业，未注册不得以注册建造师名义执业 |
| 「未达到继续教育要求」 | 是**不予注册**的独立事由，不是"以后补上就行" |
| 「申请在两个单位注册」 | 是**不予注册**情形，不是操作技巧 |
| 「注册有效期届满」 | ≠ 自动续期，未延续的注册证书失效 |
| 「延续注册申请已提交」 | ≠ 已批准 |

## 六、注册与继续教育时间轴

| 事项 | 通行口径 |
|---|---|
| 初始注册时限 | 取得资格证书后一般应在 **3 年内**提出申请 |
| 注册有效期 | **3 年** |
| 延续注册申请 | 有效期**届满 30 日前**提出 |
| 继续教育学时 | 每一注册有效期一般不少于 **120 学时**（二级以本省规定为准） |
| 逾期后果 | 有效期届满未延续的，注册证书失效 |

**提前 30 日是申请窗口的最晚点，不是开始准备的时间。** 继续教育要上课、单位材料要盖章，实际要提前 3~6 个月动手。

## 七、脚本用法

```bash
# 报考条件核查
python scripts/constructor_cert_check.py --mode exam --level yiji --education zhuanke \
    --major relevant --work-years 8 --manage-years 5

# 注册与继续教育核查
python scripts/constructor_cert_check.py --mode reg --level yiji --reg-date 2024-06-01 \
    --ce-hours 80 --age 42
```

| 参数 | 说明 |
|---|---|
| `--mode` | `exam` 报考条件核查 / `reg` 注册与继续教育核查 |
| `--level` | `yiji` 一级 / `erji` 二级 |
| `--education` | `chuzhong` / `zhongzhuan` / `zhuanke` / `benke` / `shuoshi` / `boshi` |
| `--major` | `relevant` 工程类或工程经济类 / `near` 相近专业 / `other` 其他 |
| `--work-years` | 参加工作总年限 |
| `--manage-years` | 从事建设工程项目施工管理工作年限 |
| `--senior-title` | 是否受聘担任高级专业技术职务（免试判断） |
| `--manage-20` | 大专以上学历且施工管理是否满 20 年（一级免试判断） |
| `--reg-date` | 注册起始日或上次延续注册日 |
| `--ce-hours` | 本注册有效期内已完成继续教育学时 |
| `--age` | 申请人年龄 |
| `--units` | 同时受聘（申请注册）的单位数 |
| `--accident` | 近 3 年担任项目负责人期间是否发生质量安全事故 |
| `--criminal` | 因执业活动受刑事处罚是否未满 5 年 |
| `--revoked` | 被吊销注册证书是否未满 2 年 |
| `--as-of` | 核查基准日，默认今天 |
| `--out` / `--format` | 输出文件路径 / `md` 或 `json` |
| `--selftest` | 跑内置自检（16 条断言） |

脚本输出三类结论：**符合 / 需补充材料或核实 / 不符合（存在不予注册情形）**，并区分「不符合项」与「需补充项」。

> ⚠️ 脚本按通行口径计算，**不等于所在省份当年考务公告与属地住建部门要求**。所有结论都要回到官方渠道复核。

## 八、人工确认清单（这步不能省）

**报考前：**

- [ ] 学历证书学信网可查，查不到的先做学历认证
- [ ] 年限证明由聘用单位出具并盖章，**写明从事建设工程项目施工管理工作岗位与起止时间**
- [ ] 区分清楚工作年限与施工管理年限，按后者卡
- [ ] 专业是否属于工程类或工程经济类，相近专业是否被本省认可
- [ ] 免试要主动申请并提交职称证书等证明材料
- [ ] 报名、审核、缴费三个时间节点已记下
- [ ] 报名入口为省人事考试网或住建部门官网

**注册与延续：**

- [ ] 注册有效期届满日与建议延续申请截止日已算出
- [ ] 继续教育学时达到要求，且是主管部门认可的机构出具
- [ ] 受聘单位具备相应资质，劳动合同有效
- [ ] 未在两个及以上单位注册
- [ ] 年龄未超过 65 周岁
- [ ] 近 3 年担任项目负责人期间无重大质量安全事故
- [ ] 变更单位时同步办理变更注册，避免"人证分离"

## 九、最常见的坑

**坑一：把工作年限当施工管理年限。**
两个年限不一致时卡的是后者。年限证明只写"在本单位工作 X 年"不够，必须写明从事施工管理工作。

**坑二：博士学历也要满 1 年施工管理年限。**
学历高只降低年限要求，不取消要求。

**坑三：考过了就以为能执业。**
资格证书不等于注册证书。不注册、不继续教育，就不能以注册建造师名义执业。

**坑四：注册到期忘了延续。**
有效期 3 年，届满未延续的注册证书失效，失效后继续执业属于违规。

**坑五：继续教育攒到最后一年。**
学时要在注册有效期内完成，而且要求达到规定学时，临时集中补往往来不及。

**坑六：同时挂两个单位。**
申请在两个单位注册是明确的不予注册情形，社保与聘用关系可查。

**坑七：年龄超 65 周岁还去申请。**
硬性条件，超龄不予注册。

**坑八：相信"挂靠包注册""不用来上班"。**
出借证书、允许他人以自己名义执业属于明确的违规执业行为，项目一旦出质量安全事故会被追责，并可能进入不予注册情形。这不是"行业惯例"，是风险。

**坑九：二级建造师跨省直接拿去用。**
各省自行命题并组织，执业地域一般限于本省，跨省使用通常不能直接通用。

**坑十：滚动周期算错导致科目作废。**
一级建造师成绩一般在连续 2 个考试年度内滚动，第二年只过一科、第一年成绩可能作废。报考前先算清楚还剩几科有效。

## 十、输出结构（固定五段）

1. **结论先行** —— 符合 / 需补充材料或核实 / 不符合，并说明卡在哪一项
2. **核查表** —— 逐项标符合 / 需核实 / 不符合，附判定依据与缺口数字
3. **材料补充清单** —— 缺什么、由谁出具、有没有时间周期
4. **时间轴** —— 注册有效期届满日、建议延续申请截止日、继续教育学时缺口
5. **风险提示** —— 不予注册情形核对、跨省与挂靠风险、官方渠道说明

## 十一、边界与免责

- 本技能**不代替**住房和城乡建设主管部门的现行规定与各省人事考试机构当年考务公告
- 报考条件、免试口径、合格标准、继续教育学时与注册要求**以属地住建主管部门与当年公告为准**
- **不代报名、不代办注册、不承诺注册审批结果**
- 涉及时限与学时的具体数值均为通行口径，**不引用具体条款号**，使用前须核对现行规定
- 任何"挂靠""多单位注册""出借证书"的做法都存在执业与法律风险，本技能不予协助
