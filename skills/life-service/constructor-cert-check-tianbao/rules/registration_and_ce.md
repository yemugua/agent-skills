# 建造师注册、继续教育、执业与注销

> 注册条件、注册有效期、继续教育学时、不予注册情形由**住房和城乡建设主管部门的现行规定与各省实施细则**确定。**以属地住建主管部门的现行要求为准**，本文件只给通行口径，不引用具体条款号。

## 一、注册是两回事：考试通过 ≠ 可以执业

| 阶段 | 状态 | 能做什么 |
|---|---|---|
| 考试合格 | 取得**资格证书** | 只是有资格，**不能以注册建造师名义执业** |
| 初始注册 | 取得**注册证书与执业印章** | 可以在执业范围内以注册建造师名义执业 |
| 延续注册 | 注册有效期届满前办理 | 继续保持执业资格 |
| 变更注册 | 变更聘用单位 | 在新单位执业 |

**资格证书长期有效，注册证书有有效期。** 很多人考过了就放着，几年后想用才发现还要补继续教育、还要重新走注册流程。

## 二、初始注册

| 事项 | 通行口径 |
|---|---|
| 申请时限 | 取得资格证书后一般应在 **3 年内**提出初始注册申请（逾期申请的，通常需提供达到继续教育要求的证明） |
| 受理部门 | 聘用单位所在地省级住建主管部门（一级建造师按有关规定受理） |
| 注册有效期 | **3 年** |
| 必备条件 | 受聘于一个具有建设工程施工或勘察、设计、监理、招标代理、造价咨询资质的单位；与聘用单位签订劳动合同；达到继续教育要求 |

**"受聘于一个单位"是硬条件**：同时在两个单位注册、或者证书挂靠在不实际工作的单位，都不符合注册要求，且存在执业与法律风险。

## 三、不予注册的情形（见到就停）

| 情形 | 说明 |
|---|---|
| 不具有完全民事行为能力 | |
| 申请在**两个或者两个以上单位**注册 | |
| 未达到**继续教育**要求 | |
| 受到**刑事处罚**，刑事处罚尚未执行完毕或执行完毕未满规定年限 | |
| 因执业活动受到刑事处罚，自处罚决定之日起至申请注册之日止**未满 5 年** | |
| 被吊销注册证书，自处罚决定之日起至申请注册之日止**未满 2 年** | |
| 在申请注册之日前 **3 年**内担任项目负责人期间，所负责项目发生过**重大质量和安全事故** | |
| 年龄超过 **65 周岁** | |
| 法律、法规规定不予注册的其他情形 | |

**否定词意识**：「未达到继续教育要求」「申请在两个单位注册」是**不予注册**的独立事由，不是"补一下就行"的小问题。材料里出现这两项，注册申请会被直接驳回。

## 四、继续教育

| 事项 | 通行口径 |
|---|---|
| 周期 | 每一**注册有效期（3 年）**内应完成继续教育 |
| 一级建造师学时 | 一般不少于 **120 学时**（其中必修课与选修课各 60 学时，以当年规定为准） |
| 二级建造师学时 | 由各省规定，一般不少于 120 学时，**以本省住建主管部门要求为准** |
| 形式 | 面授、网络教育等，须在主管部门认可的机构完成 |
| 证明 | 完成继续教育后取得证明，**是延续注册与逾期初始注册的必备材料** |
| 增项注册 | 增报专业的人员，增报专业也需完成相应继续教育 |

**继续教育是延续注册的前置条件，不是可选项。** 学时不够，延续注册办不下来，注册证书失效后就不得以注册建造师名义执业。

## 五、延续注册

| 事项 | 通行口径 |
|---|---|
| 申请时间 | 注册有效期**届满 30 日前**提出申请（各省表述可能不同，以属地要求为准） |
| 有效期 | 续期后仍为 **3 年** |
| 必备材料 | 延续注册申请表、注册证书、与聘用单位的劳动合同、继续教育证明等 |
| 逾期后果 | 注册有效期届满未延续的，注册证书失效 |

**提前 30 日不是"提前一个月想起来就行"**：继续教育要上课、单位材料要盖章，实际要提前 3~6 个月开始准备。

## 六、变更注册与增项注册

| 类型 | 触发情形 | 要点 |
|---|---|---|
| **变更注册** | 变更聘用单位、单位名称变更等 | 需原单位解聘证明与新单位劳动合同；**变更期间不得执业** |
| **增项注册** | 已取得某一专业注册证书，需增加其他专业 | 需取得相应专业的资格证书，并满足继续教育要求 |
| **注销注册** | 与聘用单位解除劳动关系、丧失注册条件等 | 应主动办理注销；不办理会构成"人证分离"风险 |

## 七、执业范围与禁止行为

| 能做 | 不能做 |
|---|---|
| 在执业范围内以注册建造师名义执业 | ❌ 同时受聘于两个及以上单位 |
| 担任建设工程项目施工负责人 | ❌ 允许他人以自己的名义执业（出借证书） |
| 在本人执业活动形成的文件上签字盖章 | ❌ 超出执业范围执业 |
| | ❌ 涂改、倒卖、出租、出借或以其他形式非法转让注册证书与执业印章 |

**"挂靠"是明确的风险行为**，不是"行业惯例"。一旦项目出现质量安全事故，挂靠的注册人员可能被追责，且会进入不予注册的情形。

## 八、常见坑

**坑一：考过了就以为能执业。**
资格证书不等于注册证书。不注册、不继续教育，证书就是一张纸。

**坑二：注册到期忘了延续。**
有效期 3 年，届满未延续的注册证书失效。失效后继续以注册建造师名义执业，属于违规执业。

**坑三：继续教育攒到最后一年。**
学时要在注册有效期内完成，临时集中补往往来不及，而且要求达到规定学时，不是随便听两节课。

**坑四：同时挂两个单位。**
申请在两个单位注册是明确的不予注册情形，且现有系统可查社保与聘用关系。

**坑五：年龄超 65 周岁还去申请。**
超过 65 周岁不予注册，这是硬性条件。

**坑六：项目负责人期间出过重大质量安全事故。**
3 年内担任项目负责人期间项目发生上述事故的，不予注册。不是"事故处理完就没事"。

**坑七：变更单位不办变更注册。**
人走了证没跟着走，原单位还在用你的名义投标执业，出了事算你的。

**坑八：相信"挂靠包注册""不用来上班"。**
资格考试与注册都有明确的审核与监管要求，这类承诺伴随执业风险与法律风险。

## 九、注册前自检清单

- [ ] 资格证书已取得，且在有效期内（逾期初始注册的需继续教育证明）
- [ ] 受聘于一个符合资质要求的单位，且有劳动合同
- [ ] 继续教育达到规定学时，有证明
- [ ] 年龄未超过 65 周岁
- [ ] 不在两个及以上单位注册
- [ ] 无刑事处罚执行未满规定年限等不予注册情形
- [ ] 近 3 年担任项目负责人期间未发生重大质量安全事故
- [ ] 若为延续注册，已在有效期届满 30 日前提出申请
- [ ] 注册证书执业范围与本人实际执业范围一致
