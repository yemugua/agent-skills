# 建造师报考条件、免试科目与考试安排

> 一级建造师、二级建造师的报考条件、免试科目、报名时间、合格标准由**住房和城乡建设部与各省（自治区、直辖市）人事考试机构当年发布的考务文件**确定，各省在学历、专业、年限与免试口径上存在差异。**以考生所在省份当年考务公告为准**，本文件只给通行口径，不引用具体条款号。

## 一、两个等级，别报错

| 等级 | 执业范围（通行口径） | 组织方式 |
|---|---|---|
| **一级建造师** | 全国范围内执业，可担任大、中、小型工程项目负责人 | 全国统一大纲、统一命题、统一组织；合格标准全国统一 |
| **二级建造师** | 一般在**本省（自治区、直辖市）范围内**执业，可担任中、小型工程项目负责人 | 全国统一大纲，**各省自行命题并组织**；合格标准各省自定 |

**关键差异**：二级建造师的合格线、报名条件免试口径、注册后的执业地域范围都由各省定，**跨省使用往往不能直接通用**。在哪儿执业就在哪儿考，是最省事的选择。

## 二、一级建造师报考条件（通行口径）

| 学历 | 从事建设工程项目施工管理工作年限 | 备注 |
|---|---|---|
| 工程类或工程经济类**大学专科** | 满 **4 年**（工作满 6 年） | 两个年限口径各省表述不同，以公告为准 |
| 工程类或工程经济类**大学本科** | 满 **3 年**（工作满 4 年） | |
| 工程类或工程经济类**硕士学位 / 双学士学位 / 研究生班毕业** | 满 **2 年**（工作满 3 年） | |
| 工程类或工程经济类**博士学位** | 满 **1 年** | |

**两个年限要分清：**

- **工作年限**：从毕业后实际参加工作起算，一般截至报名当年年底
- **施工管理工作年限**：在建设工程项目施工管理岗位上的年限，是**硬指标**

两个年限不一致时，**以"从事建设工程项目施工管理工作年限"为准**去卡。学历高的人常常栽在这个年限上——博士学历好拿，一年的施工管理年限不好凑。

## 三、二级建造师报考条件（通行口径，各省差异大）

| 条件 | 口径 |
|---|---|
| 学历与专业 | 工程类或工程经济类**中等专科及以上学历**（部分省份放宽专业限制，或允许相近专业） |
| 工作年限 | 从事建设工程项目施工管理工作满 **2 年** |
| 放宽情形 | 部分省份对取得**中级及以上专业技术职称**、或**从事施工管理工作满 15 年**的人员另有免试或放宽规定，以本省公告为准 |

**二级建造师的省级差异最明显**：有的省份要求专业严格对口，有的省份允许"相近专业"，有的省份对年限计算方式不同。跨省报名前一定要读本省当年公告，不要拿外省经验套。

## 四、免试科目（通行口径，务必核对当年公告）

| 等级 | 免试情形 | 可免科目 |
|---|---|---|
| 一级建造师 | 受聘担任工程或工程经济类高级专业技术职务，或具有工程类或工程经济类大专以上学历并从事建设项目施工管理工作满 **20 年** | 可免考《建设工程经济》与《建设工程项目管理》两个科目 |
| 二级建造师 | 具有中级及以上专业技术职称，且从事建设项目施工管理工作满 **15 年**（部分省份口径） | 可免考部分科目，各省规定不同 |

**免试也要报名、也要审核、也要缴费。** "符合免试条件"不等于"自动免试"，必须按规定提交证明材料并通过审核。

## 五、考试科目

| 等级 | 科目 | 说明 |
|---|---|---|
| 一级建造师 | 《建设工程经济》《建设工程法规及相关知识》《建设工程项目管理》《专业工程管理与实务》 | 前三科为客观题，《实务》含主观题 |
| 二级建造师 | 《建设工程法规及相关知识》《建设工程施工管理》《专业工程管理与实务》 | 三科 |

《专业工程管理与实务》分专业类别，需按实际从事方向选报（如建筑工程、公路工程、水利水电工程、市政公用工程、矿业工程、机电工程等，具体专业设置以当年公告为准）。

## 六、成绩管理与滚动周期

| 事项 | 通行口径 |
|---|---|
| 一级建造师 | 考试成绩实行**滚动管理**，参加全部 4 个科目考试的须在**连续 2 个考试年度**内通过全部科目 |
| 免试部分科目 | 须在**1 个考试年度**内通过应试科目 |
| 二级建造师 | 各省不同，多为连续 2 个考试年度滚动（部分省份按当年一次通过） |

**滚动周期是最容易被算错的**：第二年只过了一科，第一年过的科目可能作废。报考前把"我还有几科有效"算清楚。

## 七、报名与考试流程（时间以当年公告为准）

| 环节 | 通行时间 | 要点 |
|---|---|---|
| 考务文件发布 | 一般为上半年 | 先读本省文件，再决定报不报 |
| 网上报名 | 各省不同，多在 **2~7 月** | 一级与二级时间不同 |
| 资格审核 | 网报后 | 网上核查或现场审核，**学历与工作年限是核查重点** |
| 网上缴费 | 审核通过后 | **未缴费视为报名无效** |
| 打印准考证 | 考前一周左右 | |
| 考试 | 一级多在 **9 月**，二级多在 **5~6 月**（各省不同） | |
| 成绩查询 | 考后 2~3 个月 | |
| 证书领取 | 成绩公布后 | 现多为电子证书，可自行下载打印 |

## 八、报名材料清单（通用）

| # | 材料 | 说明 |
|---|---|---|
| 1 | 身份证 | 有效期内 |
| 2 | 学历证书 | 学信网可查，查不到的先做学历认证 |
| 3 | 从事建设工程项目施工管理工作年限证明 | 由聘用单位出具并盖章，写明岗位与起止时间 |
| 4 | 专业技术职务证书（免试人员） | 高级职称证书等 |
| 5 | 照片 | 按省要求规格 |
| 6 | 社保证明或工作单位证明（部分省份） | 用于核实工作单位与年限 |
| 7 | 增报专业人员的已有资格证书 | 已取得某一专业资格证书的，增报其他专业可免考部分科目 |

## 九、防误伤清单

1. **工作年限 ≠ 施工管理年限**，卡的是后者
2. **未缴费 = 未报名**，审核通过不等于报名成功
3. **滚动周期会作废**，跨年度报考前先算还剩几科有效
4. **二级建造师跨省不通用**，在哪执业就在哪儿考
5. **免试要主动申请并提交证明**，不自动生效
6. **"代报名""包过""挂靠包注册"都是风险项**，资格考试不存在包过，"挂靠"存在执业与法律风险
7. **学历必须学信网可查**，查不到先认证
8. **年限证明要写岗位**，只写"在本单位工作 X 年"不够，要写明从事施工管理工作
9. 认准**省人事考试网 / 住建部门官网**为唯一报名入口
