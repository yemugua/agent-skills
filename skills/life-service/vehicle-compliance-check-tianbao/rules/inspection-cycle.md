# 机动车检验周期、逾期风险与改装备案

> 适用：非营运小微型载客汽车（9 座及以下，含私家轿车、SUV、MPV）。
> **营运车、货车、大型客车、挂车、摩托车另按专门规定**，本表不适用于它们。
> 法规会调整，输出里必须带一句「以当地车管所与 12123 显示为准」。

## 一、现行检验周期（2022-10-01 起优化调整后的口径）

以**注册登记日期**为起算点（不是买车日，不是发证日）：

| 车龄节点 | 干什么 |
|---|---|
| 第 2 年 | 免检，通过 12123 / 交管窗口**申领检验合格标志** |
| 第 4 年 | 免检，同上，申领标志 |
| 第 6 年 | **上线检验**（到检测站，需处理完违章） |
| 第 8 年 | 免检，申领检验标志 |
| 第 10 年 | **上线检验** |
| 10 年以上 | **每年上线检验 1 次** |

简化记法：**6 年内两年一领标（第 2、4、8 年）＋ 第 6 年、第 10 年上线，10 年后年年检。**

## 二、上线检验要带什么、要查什么

必备：行驶证、有效期内的交强险保单（电子版可查）、处理完的**全部违章**、
在有效期内的身份证（代办带代办人身份证 + 委托书）、三角警示牌与反光背心（部分省市要求）。

检测项：外观（车身、号牌、灯光、改装）、制动、尾气/OBD（环保检测）、底盘。
免检车不用上线，但要**按时申领标志**，没标志等于没检。

## 三、逾期后果（分级写进报告）

| 状态 | 后果 |
|---|---|
| 逾期 ≤ 30 天 | 尽快补检；路上被查可能警告 |
| 逾期 31–90 天 | 罚款（一般 200 元以下）、记 1 分；补检时可能要填写说明 |
| 逾期 > 90 天 | 罚款、记分叠加；发生**保险事故商业险可拒赔** |
| **连续 3 个检验周期未检验** | **强制报废**（这是最容易忽略的一条） |

补充：逾期未检期间上路，被查可**扣留机动车**；连续 3 个周期不检的车，即使后来补检也可能被引导报废。

## 四、上线前最容易卡住的五件事（写报告时逐条核）

1. **还有没处理的违章** —— 有未处理违章根本上不了线，必须先交清。
2. **改装没备案** —— 改色、换轮毂/轮毂样式、加尾翼、改变车身结构、贴大面积深色膜（透光率不满足）、改灯。
3. **交强险过期** —— 检车先要有效交强险，脱保 = 先补罚再补检。
4. **证书不在手 / 登记证书遗失** —— 先补办（12123 可申请补领登记证书）。
5. **车里有改装或故障灯亮** —— 故障灯（发动机、ABS）亮通常直接判定不合格。

## 五、改装备案规则（常被误判为"多管闲事"，其实是硬要求）

| 项目 | 要求 |
|---|---|
| 改变车身颜色 | 变更后 **10 日内**到车管所备案、换行驶证照片；大面积改色需备案 |
| 换发动机 / 车身 / 车架 | 需具备资质厂家修复 + 鉴定，方可办理变更登记 |
| 改变使用性质（非营运 → 营运） | 必须先变更登记，再按营运周期年检 |
| 加装尾翼、踏板和改变外形 | 未备案即改装，年检外观项不合格 |
| 贴膜 | 前挡风玻璃透光率需达标（一般 ≥70%），深色膜是常见不合格点 |

## 六、强制报废与引导报废（自查时判"该不该继续用"）

| 情形 | 处理 |
|---|---|
| **连续 3 个检验周期未检验** | 强制报废 |
| 经修理调整仍不符合机动车安全技术标准 | 强制报废 |
| 达到规定行驶里程 / 年限（营运类、大型车按专门规定） | 引导报废 |
| 排放或噪声经整治仍不达标 | 强制报废 |
| 因事故致车辆无法修复 | 强制报废 |

非营运小微型载客汽车目前**没有强制使用年限**，但状态不达标一样要报废；
车辆达到报废标准后继续上路，罚款 + 可扣车。

## 七、输出纪律

- 只按「注册日期 + 车龄」推算**下一步该做什么、什么时候做**；
- 具体办理地点、费用、是否需预约，**写【以当地车管所/12123 为准】**，不编造；
- 逾期天数一律用**今天或用户指定基准日**算，写清基准日；
- 免检车也要提醒「申领检验标志」，不能因为"免检"就判没问题。
