# 过户（含外迁）、保险与车船税自查

> **各地车管所材料清单存在差异**，本表给的是通用主干，输出必须标注「以双方所在地车管所为准」。

## 一、过户前必须先解决的四件事（顺序不能反）

1. **处理完所有违章与交通事故** —— 有未处理违章，车管所不受理转移登记；
2. **解除抵押 / 查封** —— 有抵押（车贷没还完）或司法查封，**不能过户**；
3. **交强险在有效期内** —— 过户前后都要有效，脱保期间过户会有空窗；
4. **车辆到场查验** —— 车管所要验车（外观、车架号、发动机号、改装情况），人能不去、车必须到（部分地区可委托）。

## 二、本地过户材料（主干）

| 类别 | 材料 |
|---|---|
| 卖方（现车主） | 身份证原件、机动车登记证书（大绿本）、行驶证、交强险保单（在有效期内） |
| 买方 | 个人身份证（外地户籍各地要求不同；**限牌城市还需指标证明**） |
| 单位之间 | 营业执照、公章、单位代码证、委托书、经办人身份证 |
| 车辆本身 | 车（到场）、车船税完税或免税证明、有效期内的检验合格标志 |
| 其他 | 二手车销售统一发票（二手车交易市场开具或平台代开）、买卖合同 |

办理后：换发**新行驶证**与**新号牌**（车牌归原车主，可保留原号需符合条件）；
登记证书变更；**保险需批改投保人**（或直接退保重新投保）。

## 三、外迁（跨省/跨市过户）额外注意

- 先在**转出地**提档（开具转移联系函/档案），再到**转入地**落户；
- 转入地有**排放门槛**（国五/国六，各地不同）和**年限要求**（部分城市对旧车迁入有年限限制）；
- 提档后档案有**有效期**（一般 30 日内办理落户，逾期需回转出地重新提档）—— 这条很多人踩；
- 外迁途中**不要上路行驶**（未落户车辆无正式牌照），需要托运；
- 提档前先确认无抵押、无查封、违章清零。

## 四、限牌城市（先查自己城市有没有指标）

上海、北京、广州、深圳、杭州、天津、海南等实行小客车增量调控。
**过户/上牌前必须先有指标**，无指标即使材料齐全也办不了。
→ 自查时先问一句"是否在限牌城市"，有则把指标列为**第 0 项前置条件**。

## 五、保险自查（脱保是最高频雷）

| 险种 | 要点 |
|---|---|
| **交强险** | 强制、按时续保；脱保上路被查 → 扣车 + 罚应缴保费 **2 倍**；**过户时只要在保，别断档** |
| 商业三者险 | 建议 ≥ 200 万（一线/高速多）；与事故赔付直接挂钩 |
| 车损险 | 含盗抢、涉水、自燃（2020 年车险综合改革后并入主险） |
| 座位险 / 驾乘险 | 车上人员保障，跑高速、载人多的必看 |
| 新能源车险 | 三电（电池电机电控）专属条款，与传统车险不完全通用 |
| 续保时点 | 到期前续；**脱保后重新投保可能有等待/计费调整**，别拖到最后一天（系统延迟会裸奔） |

出过的案子对保费影响大（交强险与商业险的费率与出险次数挂钩），
自查表里要提醒：**续保前先看去年出险次数**。

## 六、车船税

- 按排量（燃油车）或核定载客人数（部分新能源免征）**按年计征**；
- 一般与**交强险同时缴纳**，交强险代收；
- 过户时该年度车船税需结清（由原车主承担至过户当月，各地口径略有差异）。

## 七、高频坑清单（逐条核对）

1. 违章没交清就过户 → 车管所不受理。
2. 车贷没还完（有抵押）→ 不能过户，先解押。
3. 外迁提档后拖着落户 → 超出档案有效期（30 日）要回原地重办。
4. 买的"过户二手险"没批改 → 出险时原投保人已变更，理赔扯皮。
5. 交强险脱保一天上路 → 扣车 + 双倍保费罚款。
6. 限牌城市无指标 → 材料齐全也办不成。
7. 改装（贴膜、轮毂、尾翼）没改回/没备案 → 过户查验不过。
8. 车辆有未到期商业险，过户后没退保也没批改 → 空窗或重复投保。
9. .convert 别人的"背户车"（原车主不配合）→ 无法过户到名下，风险极高，不要用。
10. 判"该不该现在卖"时忽略**年检与保险到期日** → 买家不要一个快到期的车。

## 八、输出纪律

- 材料清单写**主干 + 需向车管所确认的项**，不虚构网点、费用、办理时长；
- 时间敏感项（档案 30 日、指标有效期、保险到期）一律给**具体天数/日期**；
- 不代办公证、不代办过户、不承诺"能办"；
- 未填项标【待现场填写】，绝不编造车架号、发动机号、保单号。
