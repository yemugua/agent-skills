# 车辆信息采集表（输入模板）

> 能填多少填多少，**查不到的留空**，脚本会标成【待现场填写】，不会瞎猜。
> 车架号/VIN、发动机号只填后 6 位即可（自选保留），完整号不需要。

## 一、车辆 basics

| 项 | 填什么 |
|---|---|
| 车辆性质 | 非营运小微型载客汽车 / 营运车 / 货车 / 大型车 |
| 注册登记日期 | YYYY-MM-DD（行驶证 registration date，不是买车日） |
| 表显里程 | 万公里（可选） |
| 所在城市 | 如：上海 |
| 是否限牌城市 | 是 / 否（上海、北京、广州、深圳、杭州、天津、海南等） |
| 车辆现状 | 自用 / 计划过户 / 已外迁 / 待报废 |

## 二、年检与检验标志

| 项 | 填什么 |
|---|---|
| 上次上线检验日期 | YYYY-MM-DD（没上线过就写「未上线」） |
| 上次领取检验标志日期 | YYYY-MM-DD / 未领 |
| 是否有未处理违章 | 有（__ 条）/ 无 |
| 车辆改装 | 无 / 已备案（__）/ 有改装未备案 |

## 三、保险与税费

| 项 | 填什么 |
|---|---|
| 交强险到期日 | YYYY-MM-DD |
| 商业险到期日 | YYYY-MM-DD |
| 车船税是否已缴 | 是 / 否 |
| 去年出险次数 | 数字（影响续保） |
| 新能源车 | 是 / 否 |

## 四、记分（驾驶人，不是车）

| 项 | 填什么 |
|---|---|
| 驾驶证初次领证日 | YYYY-MM-DD（记分周期从这里算） |
| 本周期已累计记分 | 数字（12123 上能看到） |
| 待处理违章 | 逐条写（日期 + 地点 + 行为），例如：2026-03-11 环城东路 闯红灯 |
| 已缴清未处理的旧账 | 有 / 无 |

## 五、过户（如不涉及可写「不涉及」）

| 项 | 填什么 |
|---|---|
| 是否计划过户 | 是 / 否 |
| 过户类型 | 本地过户 / 跨省外迁 / 二手车经销入库 |
| 车辆是否有抵押 | 是 / 否（车贷未结清） |
| 是否被查封 | 是 / 否 |
| 买方是否已有机动车指标 | 是 / 否 / 不涉及 |
| 提档日期（外迁） | YYYY-MM-DD（档案 30 日内要落户） |
