# 过户 / 保险 办理清单（执行用）

> 带 ✅ 项在去之前自己勾一遍，别到窗口才发现漏带。

## 一、去之前（按顺序）

- [ ] <!-- 0 --> 限牌城市：确认买方**已有机动车指标**（无指标材料再全也办不了）
- [ ] 违章与交通事故**全部处理完毕**（窗口不受理有违章的转移登记）
- [ ] 车贷结清、**抵押解除**（登记证书上解除抵押登记）
- [ ] 无司法查封、无盗抢/套牌记录
- [ ] 交强险在有效期内（脱保先补，不然要先罚后办）
- [ ] 车身改装**已改回或已备案**（贴膜透光率、轮毂、尾翼是高频卡点）
- [ ] 证件带齐：身份证、登记证书、行驶证、保单（纸质或电子）

## 二、窗口办理

- [ ] 验车（车到、人可不到，部分城市需委托）
- [ ] 提交材料 → 二手车发票（市场/平台代开）
- [ ] 选号（是否保留原号：原号需满足使用年限与车主条件）
- [ ] 换发新行驶证 + 新号牌
- [ ] 登记证书变更登记

## 三、外迁专用（跨省/跨市）

- [ ] 转出地**提档**（开具转移联系函/档案）
- [ ] 记录**提档日期**：档案一般 **30 日内**须到转入地落户（逾期回转出地重提）
- [ ] 确认转入地**排放门槛**（国五/国六，各市不同）和年限限制
- [ ] 提档后**不要上路**（无正式牌照）→ 走托运
- [ ] 转入地查验 → 落户 → 新牌新证

## 四、保险衔接（最容易断档的地方）

- [ ] 交强险：过户前后**不能空窗**；原保单在保的，及时做**投保人批改**或退保重投
- [ ] 商业险：批改或退保重投，避免"原投保人已变更"导致理赔扯皮
- [ ] 车船税：结清至过户当月（一般随交强险代收）
- [ ] 拿到新牌后更新 12123 绑定与导航/ETC 信息（ETC 需到发行方变更）

## 五、过户后 72 小时内要做的四件小事

1. 更新 **12123 绑定**（换绑本人核验）；
2. **ETC 变更**（不变更会卡口扣款到原账户）；
3. 更新 insurance contacts（保险公司留的新联系方式）；
4. 拍全车 + 车架号 + 保单 + 新证，**存档**（后续维权与二次交易用）。

## 六、卖方视角（卖之前也要自检）

- [ ] 违章清零后再交车（不然买家替你背单）
- [ ] 收齐买方款项与**过户完成凭证**再交车
- [ ] 交车同时**移交钥匙、登记证书、行驶证、保单原件**
- [ ] 如有商业险且不想随车 → 及时退保退费（未到期通常可退）
- [ ] 在 12123/交警 APP 上确认**违章已全部处理、车辆状态正常**再离开

## 七、别碰的三件事

1. **背户车**（原车主不配合、无法过户到名下）——再便宜也别要。
2. **代扣分 / 买分卖分**——违法，且分还会落回实际驾驶人。
3. **"包过""包提档""内部渠道"的中介**——外迁档案过期、二次抵押是常见骗局。
