# 机动车违章年检车务合规自查

## 定位

市面上的车务工具大多在「帮你查违章」，本技能多做一层：**算时间、排顺序、把坑提前标出来**。

- 从注册登记日期推出未来每个年检/领标节点，**已过期的会提醒"办没办"**（最常见的漏领标）；
- 保险到期、外迁档案 30 日窗口都按基准日算剩余天数，逾期分三档；
- 记分做加法：已累计 + 疑似违章常见档位，≥12 直接给满分处理流程；
- 过户给「前置四件事 + 第 0 项指标 + 材料主干」，顺序错一件就白跑一趟窗口。

## 报告七段

| 段 | 内容 |
|---|---|
| 一 | 结论摘要（最近要办 + 记分判定） |
| 二 | 到期倒计时（交强险 / 商业险 / 年检节点 / 外迁档案） |
| 三 | 年检周期推算（含已过期节点） |
| 四 | 记分核验（逐条常见档位 + 合计 + 满分处理 + 消分红线） |
| 五 | 过户 / 保险自查（前置四件事、限牌指标、外迁、保险衔接） |
| 六 | 风险与待办（带时间节点） |
| 七 | 数据质量提示（未填项 + 法规口径） |

## 适用与不适用

**适用**：私家轿车/SUV/MPV 的年检与领标、保险续保提醒、违章记分估算、二手车过户前自查、外迁提档窗口。

**不适用**：营运车/货车/大型客车的专门周期、摩托车、驾驶证业务（换证、审验）、
事故定责与理赔、违章罚款金额计算——这些必须走交管窗口或 12123。

## 数据与法规边界

- 输入的车辆信息只在本机脚本内解析，不联网、不上传。
- 检验周期口径为 2022-10-01 起优化调整后的非营运小微型载客汽车规定；
  记分档位为 2022-04-01 起施行的《道路交通安全违法行为记分管理办法》。
- 各地材料清单、排放迁入门槛、保费与处罚幅度**有差异且会调整**，
  报告里一律标注以当地车管所、12123 与最新规章为准。
- 不代办、不承诺、不代缴、不构成法律意见。
