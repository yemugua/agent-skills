# 机动车违章年检车务合规自查

## 一句话

回答四个问题：**检什么时候该办、分够不够 12、保险断没断、过户能不能立刻办**。

## 三步上手

1. 用 `templates/车辆信息采集表.md` 把车辆信息填进来（查不到就留空，脚本标【待现场填写】，不瞎猜）。
2. 跑一次自查：
   ```bash
   python scripts/vehicle_check.py 车辆信息.md --json
   ```
   可选 `--base 2026-10-04` 固定基准日（回归与复算用）。
3. 按报告第六节的「待办」执行；要办过户的再照 `templates/过户与保险办理清单.md` 逐条打勾。

## 它算什么

- **年检节点**：从注册登记日期推出第 2/4/8 年领标、第 6/10 年上线，10 年以上每年一检；
  **已过期的节点不会静默跳过**——没办就是逾期，会标成「已过期，先确认办没办」。
- **到期倒计时**：交强险、商业险、外迁档案（30 日落户窗口），按基准日算还剩多少天，
  逾期分三档（≤30 天 / 31–90 天 / >90 天）。
- **记分核验**：本周期已累计分 + 疑似违章常见档位（12/9/6/3/1）合计，
  ≥12 直接提示满分学习 + 科目一 + 期间禁驾；并明确写出**买卖记分、代扣分属违法**。
- **过户前置**：违章清零 → 解押 → 交强险在有效期 → 车辆到场，外加限牌城市指标（第 0 项）、
  外迁 30 日档案窗口、排量/排放门槛。

## 硬边界（必须遵守）

- **只做时间推算 + 常见档位核对**，不代办、不承诺"能办"、不写网点地址、不报费用。
- 法规口径一律写「以当地车管所、12123 与最新规章为准」——各地材料清单与执行有差异。
- 记分只做**算术**：不替用户断言"这条该扣几分"，只说常见档位、最终以决定书为准。
- 未填项标【待现场填写】，**绝不编造车架号、发动机号、保单号、办理时长**。
- 代扣分、买分卖分只提示违法风险，**不提供任何消分方案**。
- 只覆盖**非营运小微型载客汽车**；营运车、货车、大型客车、摩托车另有规定，脚本会提示不适用。

## 文件

- `rules/inspection-cycle.md`：检验周期（2022-10-01 口径）、逾期后果分级、上线前五件事、
  改装备案规则、强制报废情形。
- `rules/penalty-points.md`：记分周期算法、12/9/6/3/1 常见档位、满分处理流程、消分红线。
- `rules/transfer-and-insurance.md`：过户前置四件事、材料主干、外迁 30 日窗口、限牌城市、
  保险衔接与脱保后果、高频坑十条。
- `templates/车辆信息采集表.md`：输入模板。
- `templates/车务合规自查报告.md`：输出骨架。
- `templates/过户与保险办理清单.md`：办理执行清单（含卖方视角）。
- `scripts/vehicle_check.py`：自查脚本（唯一可执行部分）。

## 两个容易踩的口径

- **注册登记日期 ≠ 买车日**，也不是发证日；周期从这里算，填错会整体错位一年。
- **记分记在驾驶人头上，不是车上**；本周期看的是初次领证日起 12 个月，不是自然年。
