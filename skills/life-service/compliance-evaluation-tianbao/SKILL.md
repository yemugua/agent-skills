# 合规性评价与法规识别（compliance-evaluation）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据 ISO 14001/45001 合规义务要求，生成清单：法律法规与其他要求识别、合规义务清单与动态更新、合规性评价策划与实施、不符合纠正、评价报告与记录留存。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 合规性评价
- 法规识别
- 合规义务
- 法律法规清单
- 合规评价报告

## 三、工作流
1. 识别适用的法律法规与其他要求
2. 建立合规义务清单并动态更新
3. 策划并实施合规性评价
4. 纠正不符合并采取措施
5. 形成评价报告并留存记录

## 四、核心内容（检查清单与判定）
ISO 14001/45001 要求识别合规义务并定期评价遵循情况；清单须随法规更新，评价发现的不符合须纠正并留报告。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含法律法规与其他要求识别 | 识别 |
| Q2 | FAIL | 未含合规义务清单与更新 | 清单 |
| Q3 | WARN | 未含合规性评价策划与实施 | 评价 |
| Q4 | FAIL | 未含不符合纠正与措施 | 纠正 |
| Q5 | WARN | 未含评价报告与记录留存 | 报告 |

> 脚本 `compliance-evaluation_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python compliance-evaluation_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python compliance-evaluation_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。

## 九、免责声明
本技能为辅助参考工具，输出不构成法律/行政意见。最终合规责任由使用单位与责任人承担。引用标准以官方发布为准。
