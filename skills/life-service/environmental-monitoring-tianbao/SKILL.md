# 环境监测管理（environmental-monitoring）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据排污许可与自行监测要求，生成清单：监测因子与点位确定、监测频次与方法、委托监测与自测能力、数据记录与信息公开、超标处置与报告。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 环境监测
- 自行监测
- 排污监测
- 监测方案
- 监测数据公开

## 三、工作流
1. 确定监测因子与点位
2. 明确监测频次与方法
3. 落实委托监测与自测能力
4. 做好数据记录与信息公开
5. 规范超标处置与报告

## 四、核心内容（检查清单与判定）
排污单位须按排污许可开展自行监测，明确因子、点位与频次；数据应记录保存并按规定公开，超标须及时处置并报告。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含监测因子与点位 | 因子 |
| Q2 | FAIL | 未含监测频次与方法 | 频次 |
| Q3 | WARN | 未含委托监测与自测能力 | 能力 |
| Q4 | FAIL | 未含数据记录与信息公开 | 记录 |
| Q5 | WARN | 未含超标处置与报告 | 超标 |

> 脚本 `environmental-monitoring_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python environmental-monitoring_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python environmental-monitoring_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
