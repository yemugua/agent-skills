# 产品安全与产品责任（product-safety-liability）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《产品质量法》与产品责任要求，生成清单：安全特性识别与警示说明、合规标准与认证、缺陷追溯与召回、责任风险与产品保险、投诉与事故处置。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 产品安全
- 产品责任
- 产品警示说明
- 产品认证
- 产品责任险

## 三、工作流
1. 识别安全特性并标注警示说明
2. 确认合规标准与认证要求
3. 建立缺陷追溯与召回机制
4. 评估责任风险并配置保险
5. 规范投诉与事故处置

## 四、核心内容（检查清单与判定）
《产品质量法》要求产品不存在危及人身财产安全的不合理危险；应识别安全特性、合规认证、警示说明完备，并以追溯召回与保险降低责任风险。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含安全特性识别与警示 | 警示 |
| Q2 | FAIL | 未含合规标准与认证 | 认证 |
| Q3 | WARN | 未含缺陷追溯与召回 | 召回 |
| Q4 | FAIL | 未含责任风险与保险 | 保险 |
| Q5 | WARN | 未含投诉与事故处置 | 处置 |

> 脚本 `product-safety-liability_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python product-safety-liability_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python product-safety-liability_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。

## 九、免责声明
本技能为辅助参考工具，输出不构成法律/行政意见。最终合规责任由使用单位与责任人承担。引用标准以官方发布为准。
