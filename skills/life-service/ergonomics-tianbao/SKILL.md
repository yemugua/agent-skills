# 人机工程与肌肉骨骼防护（ergonomics）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据人机工程学与职业危害防护要求，生成清单：作业姿势与负荷评估、工位与工具设计、搬运与重复动作风险、工间休息与轮岗、损伤监测与改善。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 人机工程
- 工效学
- 肌肉骨骼损伤
- 作业姿势
- 搬运负荷

## 三、工作流
1. 评估作业姿势与负荷
2. 优化工位与工具设计
3. 管控搬运与重复动作风险
4. 安排工间休息与轮岗
5. 监测损伤并持续改善

## 四、核心内容（检查清单与判定）
人机工程通过工位、工具与作业设计降低肌肉骨骼损伤风险；重点是不良姿势、重复动作与超负荷搬运，配合休息轮岗与监测。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含作业姿势与负荷评估 | 评估 |
| Q2 | FAIL | 未含工位与工具设计 | 工位 |
| Q3 | WARN | 未含搬运与重复动作风险 | 搬运 |
| Q4 | FAIL | 未含工间休息与轮岗 | 休息 |
| Q5 | WARN | 未含损伤监测与改善 | 监测 |

> 脚本 `ergonomics_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python ergonomics_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python ergonomics_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
