# 网盘视频存本地与在线播放流辨析：常见失败与排查

报错信息请**粘贴原文**再对照。写成「下载失败了」没有排查价值，
写成 `HTTP Error 403` 或 `ffmpeg not found` 才能定位。

## 现象 → 原因 → 处理

| 现象关键词 | 原因与处理 |
| --- | --- |
| 限速 / 很慢 / 几十kb | 非会员限速属平台策略，建议用客户端在闲时同步，或改用官方离线缓存。 |
| 链接失效 / 已取消 / 不存在 | 分享链接可能已被取消或过期，需联系分享者重新分享，无法凭链接恢复。 |
| 版权 / 违规 / 无法显示 | 涉嫌版权的内容会被替换或屏蔽，无法通过技术手段取回，应通过正规渠道获取。 |
| 画质变差 / 不是原画质 / 转码 | 在线播放的是转码流，想要原画质需下载原始文件而非录制播放画面。 |
| 需要客户端 / 网页下不了 | 大文件通常要求用官方客户端下载，网页端有限制。 |

## 通用故障（各平台都可能遇到）

| 现象 | 处理 |
| --- | --- |
| 403 / 需要登录 / 机器人验证 | 触发反自动化校验：携带登录态或减少请求频率，不要高频重试 |
| 429 / 频繁 / 限流 | 降低请求频率、分批间隔重试 |
| 404 / 失效 / 不存在 | 链接失效或已删除：让对方重新生成分享 |
| 没有声音 / 无音轨 | ffmpeg 未安装或未合并轨：安装后用 `-f "bv*+ba/b"` 合并 |
| 解析失败 / 格式不支持 | 站点接口变动：把工具升级到最新版，而不是换工具 |
| 超时 / 连接失败 | 检查网络可达性后重试 |

## 排查顺序

1. 先确认网络能访问目标平台
2. 再确认目标内容是否属于可下载范围（回到归属判定）
3. 然后确认工具是最新版
4. 最后才怀疑链接本身

九成的「下载失败」卡在第 1 步和第 2 步，而不是工具坏了。
