# 飞书直播与会议录制留存边界：途径、限制与合规边界

## 一、先判定：能不能下

| 归属类别 | 能否下载 | 允许的用途 |
| --- | --- | --- |
| 自有作品 | 可以，优先用原始导出文件 | 任意 |
| 已授权素材 | 可以 | 仅限授权范围内 |
| 作者开放了保存 | 可以，走官方途径 | 个人留存，**不得二次分发** |
| 第三方作品（未授权） | **不建议下载** | 不应用于任何对外场景 |

技术上能不能下载，和法律上能不能用，是两回事。

## 二、途径，按稳定性排序

| 途径 | 操作要点 |
| --- | --- |
| 原文件 | 优先。主持人或录制者的本地录制文件最完整清晰，若本地录制仍在，后面几条都不必尝试。 |
| 官方导出 | 登录自己的主播/管理员账号在直播与会议管理里导出自己有权限的录制，这是最合规的做法。 |
| 向管理员索取 | 普通成员如需留存，向管理员申请授权后的回放或原始文件，不要自行抓取。 |
| 本地录制兜底 | 会议或直播中开启本地录制，得到本机可直接播放的文件，不受云端保留期限制。 |

## 三、本平台的真实限制

- 云端录制默认仅主持人/管理员可见，普通成员无权访问他人未授权的会议内容。
- 企业私密会议与加密录制不支持任何抓取或导出。
- 会议录制涉及所有参会者肖像与发言，对外分发需取得相关方同意。
- 云端录制有保留期，过期会被清理，重要会议应提前导出或本地录制。

## 四、画质与水印

- 本地录制文件画质取决于录制时设置；云端回放为转码版本，低于本地原始画质。
- 会议录制含平台与会议标识，对外分发需取得相关方授权，不得去除标识后发布。

## 五、合规红线

1. 不得去除作者署名后二次分发
2. 不得将他人作品搬运至自己的账号（含剪辑、配音后发布）
3. 不得下载或传播私密账号、付费内容
4. 受版权或 DRM 保护的内容不支持下载，也不提供任何破解方法
5. 商用前必须取得书面授权
6. 批量高频抓取可能违反平台服务协议，导致账号受限
