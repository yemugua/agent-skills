# 食品经营许可申办条件、材料清单与办理流程

> 食品经营许可的申请条件、材料要求、核查程序与办理时限由**县级以上地方市场监督管理部门按现行规定执行**，各地在材料细项、办理系统与承诺时限上有差异。**以属地市场监督管理部门现行要求为准**，本文件只给通行口径，不引用具体条款号。

## 一、先判断：要不要办这个证

| 情形 | 是否需办理食品经营许可 |
|---|---|
| 从事食品销售（预包装食品、散装食品、特殊食品等） | **需要** |
| 从事餐饮服务（餐馆、饮品店、小吃店、网络餐饮等） | **需要** |
| 单位食堂（学校、托幼、养老、建筑工地、机关等） | **需要** |
| 仅销售**预包装食品**的 | 按现行规定**可能只需备案**，具体要求以属地监管部门口径为准 |
| 食品生产加工（取得食品生产许可的） | 属于**食品生产许可**范畴，不是经营许可 |
| 仅销售食用农产品 | 一般**不需要**食品经营许可 |
| 食品摊贩 | 按**地方规定**管理，各地不同 |

**先分清"销售"和"生产"**：自己加工制作后销售的（如自制饮品、现制现售），通常按餐饮服务或相应业态纳入经营许可管理。

## 二、一地一证原则

| 规则 | 说明 |
|---|---|
| 一地一证 | 同一经营场所只能取得**一个**食品经营许可证 |
| 一址多主体 | 同一地址存在两个经营主体的，一般不能分别办证 |
| 跨地址经营 | 在不同地址经营应分别申请；连锁门店需**逐店办证** |
| 网络经营 | 通过第三方平台或自建网站销售的，应在许可事项中体现或按规定报告，入网时向平台提供真实许可信息 |

**连锁不等于一张证通用。** 每个门店地址都要单独申请，这是连锁扩张时最容易低估的工作量。

## 三、申请条件（通行口径）

| 条件 | 具体要求 |
|---|---|
| 场所 | 具有与经营的食品品种、数量相适应的**食品原料处理和食品加工、包装、贮存**等场所，保持环境整洁，并与有毒有害场所以及其他污染源保持规定距离 |
| 设备设施 | 具有相应的**消毒、更衣、盥洗、采光、照明、通风、防腐、防尘、防蝇、防鼠、防虫、洗涤以及处理废水、存放垃圾和废弃物**的设备或者设施 |
| 人员与制度 | 有**食品安全管理人员**和保证食品安全的规章制度 |
| 布局与流程 | 具有合理的设备布局和工艺流程，防止**待加工食品与直接入口食品、原料与成品交叉污染**，避免食品接触有毒物、不洁物 |
| 健康证明 | 从事接触直接入口食品工作的人员应取得**健康证明**（一般每年体检一次） |
| 主体资格 | 先行取得**营业执照**等主体资格证明（各地"先照后证"办理顺序以属地要求为准） |

## 四、主体业态与经营项目（按现行分类体系填写）

| 主体业态 | 说明 |
|---|---|
| 食品销售经营者 | 商场超市、便利店、食杂店、网络食品销售商、食品批发商等 |
| 餐饮服务经营者 | 特大型/大型/中型/小型餐馆、快餐店、小吃店、饮品店、中央厨房、集体用餐配送单位等 |
| 单位食堂 | 学校食堂、托幼机构食堂、养老机构食堂、建筑工地食堂、机关企事业单位食堂等 |

| 常见经营项目 | 说明 |
|---|---|
| 预包装食品销售 | 含冷藏冷冻食品或不包含，需分别勾选 |
| 散装食品销售 | 含冷藏冷冻食品或不包含，需分别勾选 |
| 特殊食品销售 | 保健食品、特殊医学用途配方食品、婴幼儿配方乳粉等，**类别对应要求更严** |
| 餐饮服务 | 热食类、冷食类、生食类、糕点类、自制饮品等**按制售项目分别核发** |
| 食品经营管理 | 连锁管理、餐饮管理等 |

**经营项目要按实际勾全**：漏了一项，实际做了就是超范围经营，属于违规。

## 五、申请材料清单

| # | 材料 | 说明 |
|---|---|---|
| 1 | 食品经营许可申请书 | 按属地系统在线填报或纸质提交 |
| 2 | 营业执照或者其他主体资格证明文件 | 名称、地址须与申请一致 |
| 3 | 法定代表人（负责人）及食品安全管理人员身份证明 | |
| 4 | 经营场所合法使用证明 | 房产证或租赁协议，**地址须与营业执照一致** |
| 5 | 经营场所布局图与操作流程文件 | 标注各功能区、设备位置与流向 |
| 6 | 食品安全自查、从业人员健康管理、进货查验记录、食品安全事故处置等规章制度 | 小微型经营者可按属地简化要求提供 |
| 7 | 食品安全管理人员的培训合格证明或相关资质证明（按属地要求） | |
| 8 | 从业人员健康证明 | 接触直接入口食品的岗位必须 |
| 9 | 设施设备清单 | 冷藏冷冻、消毒、三防等 |
| 10 | 委托他人办理的授权委托书与身份证明 | |
| 11 | 网络经营的相关说明（按属地要求） | 自建网站还需提供网址与备案信息 |

## 六、办理流程与时限（时间以属地承诺时限为准）

| 环节 | 通行口径 |
|---|---|
| 提交申请 | 线上政务平台或窗口提交 |
| 受理 | 材料齐全的予以受理；需补正的**一次性告知** |
| 资料审查 | 审核材料完整性与合规性 |
| **现场核查** | 监管部门派员核查场所与设施设备；**现场核查时间一般不计入办理时限** |
| 审批决定 | 符合条件的作出准予许可决定 |
| 发证 | 发放食品经营许可证（含电子证书） |
| **办理时限** | 一般自受理之日起 **20 个工作日**内作出决定，情况复杂的经批准可延长（各地承诺时限可能更短） |

**现场核查是整个流程里最容易被卡的一环**，材料再齐，场所不达标一样过不了。要先按核查要点自查再提交。

## 七、不予许可情形

| 情形 | 说明 |
|---|---|
| 经营场所不符合要求 | 与污染源距离不足、面积与经营规模不匹配、无独立操作空间 |
| 设备设施不符合要求 | 缺少消毒、冷藏、三防、排水等必要设施 |
| 布局流程不合理 | 存在生熟交叉污染风险、原料与成品混放 |
| 无食品安全管理人员 | 未配备或未通过培训考核（按属地要求） |
| 从业人员无健康证明 | 接触直接入口食品岗位人员缺失健康证明 |
| 申请人隐瞒真实情况或提供虚假材料 | 情形严重的，一定期限内不得再次申请 |
| 被吊销食品经营许可证未满规定年限 | 以及法定代表人、直接责任人等有相应限制 |
| 法律法规规定的其他情形 | |

**否定词意识**：「已提交材料」≠「已受理」；「已受理」≠「已许可」。只有拿到许可证才能开展经营。

## 八、先照后证与"一件事"办理

| 事项 | 说明 |
|---|---|
| 办理顺序 | 一般先取得营业执照，再申请食品经营许可（各地已推行"证照联办""一件事一次办"，顺序与流程以属地为准） |
| 名称与地址一致性 | 营业执照、申请书、场所使用证明三者地址必须一致，不一致会被退回 |
| 经营范围 | 营业执照经营范围应与拟经营的食品业态基本对应 |

## 九、常见退回原因

1. **地址不一致**：营业执照地址、租赁协议地址、申请书地址三处对不上
2. **布局图不规范**：没标功能区、没画流向、与实际场地不符
3. **缺健康证**：只提供了部分人员的，或已过期
4. **设备清单缺失**：没写冷藏冷冻或消毒设施
5. **制度照抄模板**：与实际经营业态不符（如饮品店写了热食加工制度）
6. **现场核查不通过**：三防设施、冷藏设施、消毒设施缺失或不达标
7. **超范围申报项目与实际不符**：申报了冷食类制售但无专间
8. **经营范围与营业执照不匹配**

## 十、申办前自检清单

- [ ] 已确定主体业态与全部经营项目，且与实际经营一致
- [ ] 已取得营业执照，名称地址与申请一致
- [ ] 场所使用证明齐全，地址三处一致
- [ ] 布局图与流程图已绘制，标明功能区与流向
- [ ] 消毒、冷藏冷冻、三防、排水等设施已到位
- [ ] 接触直接入口食品人员健康证齐全且在有效期内
- [ ] 食品安全管理人员已配备并有培训证明
- [ ] 食品安全规章制度已按实际业态制定
- [ ] 网络经营的已按属地要求填报
- [ ] 已按现场核查要点自行预检一遍
