# 现场核查要点、有效期延续与日常合规

> 现场核查标准、有效期与延续要求、变更与注销规定由**县级以上地方市场监督管理部门按现行规定执行**。**以属地监管部门现行要求为准**，本文件只给通行口径，不引用具体条款号。

## 一、现场核查看什么（按重要性排序）

| 序号 | 核查项 | 常见不合格表现 |
|---|---|---|
| 1 | **场所环境与选址** | 与有毒有害场所、污染源距离不足；场所内有生活区混用 |
| 2 | **功能分区与布局** | 无独立的粗加工、切配、烹饪、备餐区域；流向倒流 |
| 3 | **生熟分开** | 生熟食品容器、刀具、砧板未分开标识；冰箱内生熟混放 |
| 4 | **冷藏冷冻设施** | 无冷藏设施或数量不足；无温度显示或记录；实际温度超标 |
| 5 | **清洗消毒设施** | 无专用消毒柜或消毒液配比不规范；餐具未按规定消毒保洁 |
| 6 | **三防设施** | 无纱窗纱门、防鼠板、灭蝇灯，或安装了但未正常使用 |
| 7 | **更衣与洗手设施** | 无更衣场所；洗手池非感应或脚踏式；无洗手液与消毒用品 |
| 8 | **排水与废弃物** | 排水沟无防鼠网、无隔渣；垃圾桶无盖、未及时清运 |
| 9 | **专间要求** | 冷食类、生食类制售无独立专间、无空气消毒与专用工具容器 |
| 10 | **食品贮存** | 未离墙离地存放；无标识或过期食品未清理 |
| 11 | **从业人员健康与卫生** | 无健康证或已过期；操作时未佩戴口罩手套、穿戴不洁工作衣帽 |
| 12 | **进货查验与台账** | 无进货查验记录；无法提供供货者资质与合格证明文件 |
| 13 | **添加剂管理** | 无专人专柜、无使用记录、超范围超限量使用 |
| 14 | **留样管理** | 集体用餐配送单位、学校食堂等未按品种留样并保存规定时间 |

**三防设施（防蝇、防鼠、防虫）是最常见的不合格项**，装了但没正常使用的，同样判定不达标。

## 二、按业态的重点差异

| 业态 | 核查重点 |
|---|---|
| 预包装食品销售 | 贮存条件、离墙离地、货架、温湿度（含冷藏冷冻的） |
| 散装食品销售 | 防尘防蝇遮盖、容器标识、销售人员卫生、不得裸售无防护 |
| 特殊食品销售 | **专区或专柜**销售、显著标识提示、不得与普通食品混放 |
| 餐饮服务（热食） | 粗加工→切配→烹饪→备餐流向、油烟排放、餐具消毒 |
| 冷食类/生食类制售 | **独立专间**、空气消毒、专用工具容器、温度控制 |
| 自制饮品 | 净水设备、制冰用水、容器清洁、水果清洗区 |
| 单位食堂 | 留样、进货查验、从业人员健康管理、就餐人数与场所面积匹配 |
| 集体用餐配送 | 分装专间、运输车辆与温度控制、留样与追溯 |
| 网络餐饮 | 实体店许可真实有效、送餐容器卫生、加工场所与订单量匹配 |

**特殊食品（保健食品等）必须专区或专柜销售并做显著提示**，与普通食品混放是高频处罚点。

## 三、有效期、延续与变更

| 事项 | 通行口径 |
|---|---|
| **有效期** | 一般为 **5 年** |
| **延续申请** | 需要延续的，应在有效期**届满 30 个工作日前**向原发证部门提出申请 |
| **逾期后果** | 有效期届满未延续仍继续经营的，属于无证经营 |
| **变更事项** | 经营场所、主体业态、经营项目、名称、法定代表人等发生变化应申请变更 |
| **迁址** | 经营场所发生变化的，一般应**重新申请**（新址按新办处理） |
| **补办** | 许可证遗失或损坏的可申请补办 |
| **注销** | 终止食品经营的应主动申请注销 |

**"30 个工作日"不是 30 个自然日**，中间要扣掉周末和法定节假日，实际约提前 6 周动手。这是延续过期最常见的原因。

## 四、日常合规要点（拿到证之后）

| 事项 | 要求 |
|---|---|
| **亮证经营** | 在经营场所显著位置悬挂或摆放许可证正本 |
| **按许可范围经营** | 不得超范围、超项目经营（如未取得冷食类制售不得制售冷食） |
| **健康管理** | 接触直接入口食品人员每年体检，健康证在有效期内 |
| **进货查验** | 查验供货者资质与合格证明，建立进货查验记录并按规定保存 |
| **台账与追溯** | 建立食品安全追溯体系，票据与记录按规定期限保存 |
| **贮存与陈列** | 离墙离地、分类分架、标识清晰、定期检查清理 |
| **添加剂管理** | 专人采购、专柜存放、专人添加、专册记录 |
| **留样** | 按规定品种与数量留样，冷藏保存规定时间，记录完整 |
| **自查** | 定期开展食品安全自查并记录，发现问题及时整改 |
| **网络经营** | 公示真实许可信息，入网信息变更及时更新 |

## 五、常见违规与后果（提级意识）

| 违规 | 说明 |
|---|---|
| 无证经营 | 未取得许可从事食品经营活动，属于严重违规 |
| 超范围经营 | 超出许可的经营项目经营，如只批了热食却做冷食 |
| 许可证过期仍经营 | 届满未延续继续经营的，按无证处理 |
| 转让、涂改、出租出借许可证 | 明确禁止 |
| 健康证过期仍在岗 | 接触直接入口食品岗位人员健康证失效 |
| 虚假材料骗取许可 | 会被撤销许可，且一定期限内不得再次申请 |

## 六、否定词意识（防误伤）

| 表述 | 正确理解 |
|---|---|
| 「已提交申请」 | ≠ 已受理，更 ≠ 已取得许可 |
| 「已受理」 | ≠ 准予许可，还要过资料审查与现场核查 |
| 「现场核查已安排」 | ≠ 核查通过 |
| 「许可证在有效期内」 | ≠ 可以超范围经营 |
| 「有营业执照」 | ≠ 可以经营食品，许可与执照是两回事 |
| 「连锁总部有证」 | ≠ 门店可以不用办证，一地一证、逐店办理 |
| 「已申请延续」 | ≠ 延续已批准，批准前继续经营仍有风险 |

## 七、常见坑

**坑一：地址三处不一致。**
营业执照、租赁协议、申请书三处地址对不上，材料被直接退回。

**坑二：布局图照抄模板。**
与实际场地不符或没标流向，现场核查时立刻暴露。

**坑三：三防设施装了不用。**
纱窗卷着、灭蝇灯没开、防鼠板没插上，等同于没有。

**坑四：特殊食品没有专区专柜。**
保健食品与普通食品混放，是高频处罚点。

**坑五：冷食类无专间却申报了冷食制售。**
申报项目与实际条件不匹配，核查必挂。

**坑六：健康证只办了一部分人。**
接触直接入口食品的岗位全部要有，缺一个就过不了。

**坑七：把 30 个工作日当成 30 天算延续时间。**
差了两周，一忙就过期，过期后继续经营按无证处理。

**坑八：连锁新店沿用总部的证。**
一地一证，每个门店地址都要单独申请。

**坑九：迁址后只做变更。**
经营场所变化一般要重新申请，按新办走，别走变更流程。

**坑十：制度照抄模板。**
饮品店写热食加工制度、小食杂店写食堂留样制度，核查人员一眼看出，反而显得不认真。

## 八、现场核查前自检清单

- [ ] 场所环境整洁，与污染源保持距离，无生活区混用
- [ ] 功能分区清晰，流向合理，无倒流与交叉污染
- [ ] 生熟容器、刀具、砧板分开并有明显标识
- [ ] 冷藏冷冻设施运行正常，有温度显示与记录
- [ ] 消毒设施齐备并正常使用，餐具按规定消毒保洁
- [ ] 三防设施安装到位**且处于正常使用状态**
- [ ] 更衣与洗手设施可用，有洗手液与消毒用品
- [ ] 排水沟有防鼠网与隔渣，垃圾桶有盖
- [ ] 冷食、生食制售有独立专间与专用工具容器
- [ ] 食品贮存离墙离地，标识清晰，无过期食品
- [ ] 从业人员健康证齐全有效，操作着装规范
- [ ] 进货查验记录与供货者资质文件可现场提供
- [ ] 特殊食品专区或专柜销售并有显著提示
- [ ] 许可证正本在显著位置公示
