# 食品经营许可证申办与核查（food-business-permit）

食品经营许可这件事，材料部分不难，**难在两处**：一是现场核查，二是延续时点。

材料照着清单备就行；现场核查会把所有"装了但没用"的东西照出来；延续则是每年都有人因为把"30 个工作日"当成"30 天"而过期。

这个技能做五件事：**定业态** → **核材料** → **预检现场** → **测有效期** → **排不予许可情形**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 列出申办材料清单与准备顺序 | ❌ 代替属地市场监管部门受理或作出许可决定 |
| 按业态核对场所与设施要求 | ❌ 认定某场所"一定能通过核查" |
| 测算有效期与延续申请时点 | ❌ 保证延续申请一定获批 |
| 提示不予许可情形与整改方向 | ❌ 代为提交申请、代为承诺材料真实 |
| 梳理迁址、变更、注销的处理口径 | ❌ 为无证经营或超范围经营出主意 |

**遇到以下情况，务必以属地市场监督管理部门的现行要求为准：**
- 是否需要办证（如仅销售预包装食品可能只需备案，各地口径不同）
- 材料细项、办理系统、承诺时限与是否需现场核查
- 现场核查的具体判定标准与整改要求
- 特殊食品、集体用餐配送、中央厨房等特殊业态的附加条件
- 食品摊贩的管理方式（由地方规定）

**永远不要把"已提交申请"说成"已取得许可"。** 只有拿到许可证才能开展经营，此前经营属于无证经营。

| 用户这样说 | 就用 |
|---|---|
| "开个小餐饮店要办什么证" | ✅ |

| "保健食品要专区专柜吗" | ✅ |
| "健康证要几个人的" | ✅ |

| "30 个工作日前到底是提前多久" | ✅ |

## 二、完整工作流

```
第 1 步  确定主体业态与全部经营项目（按实际做勾全，不能漏）
第 2 步  先读规则文件 rules/application_materials.md 与 rules/onsite_inspection.md
第 3 步  跑核查脚本
    python scripts/food_permit_check.py --mode apply --business-type catering \
        --staff 8 --health-certs 8 --manager yes --license-biz yes --address-match yes \
        --layout yes --rules yes --facility pest,cold,disinfection,handwash,separate
第 4 步  按 rules/onsite_inspection.md 的十四项要点自行预检一遍
第 5 步  提交申请 → 配合现场核查 → 取证后按日常合规要点执行
第 6 步  记下有效期，按测算出的延续时点提前动手
```

## 三、先判断要不要办这个证

| 情形 | 是否需办理 |
|---|---|
| 食品销售（预包装、散装、特殊食品） | **需要** |
| 餐饮服务（餐馆、饮品店、小吃店、网络餐饮） | **需要** |
| 单位食堂（学校、托幼、养老、工地、机关） | **需要** |
| 仅销售预包装食品 | 按现行规定**可能只需备案**，以属地口径为准 |
| 食品生产加工 | 属于**食品生产许可**范畴 |
| 仅销售食用农产品 | 一般**不需要** |
| 食品摊贩 | 按**地方规定**管理 |

**先分清"销售"和"生产"**：自己加工制作后销售的（自制饮品、现制现售），通常按餐饮服务或相应业态纳入经营许可管理。

## 四、一地一证，连锁不等于一张证

| 规则 | 说明 |
|---|---|
| 一地一证 | 同一经营场所只能取得**一个**食品经营许可证 |
| 一址多主体 | 同一地址存在两个经营主体的，一般不能分别办证 |
| 跨地址经营 | 不同地址应分别申请，**连锁门店逐店办证** |
| 网络经营 | 应在许可事项中体现或按规定报告，入网时向平台提供真实许可信息 |

## 五、申请条件与材料（详见 `rules/application_materials.md`）

| 条件 | 要求 |
|---|---|
| 场所 | 与经营的食品品种、数量相适应，与有毒有害场所及污染源保持规定距离 |
| 设备设施 | 消毒、更衣、盥洗、通风、防腐、防尘、防蝇、防鼠、防虫、洗涤、排水、废弃物存放等 |
| 人员与制度 | 有**食品安全管理人员**和保证食品安全的规章制度 |
| 布局与流程 | 防止待加工食品与直接入口食品、原料与成品**交叉污染** |
| 健康证明 | 接触直接入口食品的人员应取得健康证明，一般每年体检一次 |
| 主体资格 | 先行取得营业执照 |

**材料清单十一条**（申请书、营业执照、身份证明、场所使用证明、布局图与流程文件、规章制度、管理人员证明、健康证明、设施设备清单、委托书、网络经营说明）见规则文件。

## 六、现场核查十四项（详见 `rules/onsite_inspection.md`）

| 高频不合格项 | 表现 |
|---|---|
| **三防设施** | 无纱窗纱门、防鼠板、灭蝇灯，**或装了没正常使用** |
| **生熟不分** | 容器、刀具、砧板未分开标识，冰箱内生熟混放 |
| **冷藏冷冻** | 设施不足、无温度显示或记录、实际温度超标 |
| **清洗消毒** | 无专用消毒设施、配比不规范、餐具未消毒保洁 |
| **专间缺失** | 冷食类、生食类制售无独立专间与专用工具容器 |
| **特殊食品未专区专柜** | 与普通食品混放，无显著提示 |
| **健康证不全** | 部分人员缺失或已过期 |
| **进货查验无记录** | 现场无法提供供货者资质与合格证明 |

**三防设施装了但没用，等同于没有。** 纱窗卷着、灭蝇灯没开、防鼠板没插上，核查人员一眼就看出来。

---

## 七、有效期与延续（最容易被算错的一段）

| 事项 | 通行口径 |
|---|---|
| 有效期 | 一般 **5 年** |
| 延续申请 | 应在有效期**届满 30 个工作日前**向原发证部门提出 |
| **30 个工作日 ≈ 42 个自然日** | 中间要扣掉周末，实际要提前约 **6 周**动手 |
| 逾期后果 | 届满未延续仍继续经营的，按无证经营处理 |
| 迁址 | 经营场所变化的一般应**重新申请**，不能按变更或延续办理 |
| 变更 | 名称、法定代表人、经营项目等变化应申请变更 |
| 注销 | 终止食品经营的应主动申请注销 |

## 八、脚本用法

```bash
# 申办核查
python scripts/food_permit_check.py --mode apply --business-type catering \
    --staff 8 --health-certs 8 --manager yes --license-biz yes --address-match yes \
    --layout yes --rules yes --facility pest,cold,disinfection,handwash,separate

# 延续与变更核查
python scripts/food_permit_check.py --mode renew --permit-date 2022-03-01 --as-of 2026-10-08
```

| 参数 | 说明 |
|---|---|
| `--mode` | `apply` 申办核查 / `renew` 延续与变更核查 |
| `--business-type` | `prepackaged` / `bulk` / `special` / `catering` / `canteen` / `online` |
| `--staff` / `--health-certs` | 从业人员数 / 已取得健康证人数 |
| `--manager` | 是否配备食品安全管理人员 |
| `--license-biz` | 是否已取得营业执照 |
| `--address-match` | 三处地址是否一致 |
| `--layout` / `--rules` | 是否有布局图与流程文件 / 规章制度 |
| `--facility` | 已具备设施：`pest` `cold` `disinfection` `handwash` `separate` `counter` |
| `--cold-food` | 是否经营冷藏冷冻食品 |
| `--online` | 是否网络经营 |
| `--permit-date` | 许可证发证日期（延续模式） |
| `--relocated` / `--changed` | 是否迁址 / 是否许可事项变化 |
| `--as-of` | 核查基准日，默认今天 |
| `--out` / `--format` | 输出路径 / `md` 或 `json` |
| `--selftest` | 跑内置自检（16 条断言） |

脚本按业态自动匹配必需设施：餐饮、食堂、网络餐饮需**三防 + 冷藏 + 消毒 + 洗手 + 生熟分开**；特殊食品需**三防 + 专区专柜**；预包装仅需**三防**（含冷藏冷冻的另加冷藏）。

> ⚠️ 脚本按通行口径匹配，**不等于属地监管部门的具体要求**。所有结论都要回属地确认。

## 九、人工确认清单（这步不能省）

**申办前：**

- [ ] 主体业态与经营项目按实际勾全，不漏项
- [ ] 营业执照、场所使用证明、申请书**三处地址完全一致**
- [ ] 布局图与流程文件**按实际场地**绘制，标明功能区与流向
- [ ] 规章制度按实际业态制定，不照抄模板
- [ ] 食品安全管理人员已配备并有培训证明
- [ ] 接触直接入口食品人员健康证**全员**齐备且在有效期内
- [ ] 三防、冷藏、消毒、洗手、生熟分开设施到位**且处于可用状态**
- [ ] 特殊食品已设专区或专柜并有显著提示
- [ ] 网络经营已按属地要求填报

**延续前：**

- [ ] 有效期届满日与延续申请最迟时点已算出（按 30 个工作日，非自然日）
- [ ] 经营场所未搬迁（搬迁的按重新申请办）
- [ ] 名称、法定代表人、经营项目等变化已同步申请变更
- [ ] 期间无超范围经营记录

## 十、最常见的坑

**坑一：地址三处不一致。**
营业执照、租赁协议、申请书三处地址对不上，材料被直接退回。

**坑二：布局图照抄模板。**
与实际场地不符或没标流向，现场核查时立刻暴露。

**坑三：三防设施装了不用。**
纱窗卷着、灭蝇灯没开、防鼠板没插上，等同于没有。

**坑四：特殊食品没有专区专柜。**
保健食品与普通食品混放，是高频处罚点。

**坑五：冷食类无专间却申报了冷食制售。**
申报项目与实际条件不匹配，核查必挂。

**坑六：健康证只办了一部分人。**
接触直接入口食品的岗位全部要有，缺一个就过不了。

**坑七：把 30 个工作日当成 30 天算延续时间。**
差了约两周，一忙就过期，过期后继续经营按无证处理。

**坑八：连锁新店沿用总部的证。**
一地一证，每个门店地址都要单独申请。

**坑九：迁址后只做变更。**
经营场所变化一般要重新申请，按新办走。

**坑十：制度照抄模板。**
饮品店写热食加工制度、小食杂店写食堂留样制度，核查人员一眼看出，反而显得不认真。

## 十一、输出结构（固定五段）

1. **结论先行** —— 能不能提交 / 需补充哪些 / 卡在哪一项
2. **核查表** —— 主体业态、营业执照、场所、布局图、制度、管理人员、健康证、设施逐项标结果
3. **现场核查预检清单** —— 十四项要点按业态挑重点，标注当前缺失
4. **时间轴** —— 有效期届满日、延续申请最迟时点、剩余天数
5. **风险提示** —— 一地一证、迁址重办、超范围经营、亮证与台账要求

## 十二、边界与免责

- 本技能**不代替**属地市场监督管理部门的受理、核查与许可决定
- 申办条件、材料细项、核查标准与办理时限**以属地监管部门现行要求为准**，本技能只提供通行口径，不引用具体条款号
- **不代提交申请、不代承诺材料真实性、不保证核查通过或延续获批**
- 食品经营关系公众健康，涉及具体经营场所的合规性判断应直接咨询属地监管部门
- 不得用于规避无证经营、超范围经营的监管要求
