# 请求类型与证据矩阵

> 准备前必读。**先定请求类型，再按矩阵备证据。**
> 各请求的计算口径、时效与金额**以现行规定和受理机构口径为准**。

## 一、请求类型与核心证据

| 请求类型 | 核心证据 | 备注 |
|---|---|---|
| **确认劳动关系** | 工资流水、社保记录、工作证、考勤、聊天记录、工作安排 | 无合同时的主要路径 |
| **追讨工资** | 工资流水、劳动合同、考勤、银行记录、工资条 | 区分已付与未付部分 |
| **未签劳动合同二倍工资** | 实际用工起止时间证据、工资记录、考勤 | 证据基础与一般工资不同 |
| **加班费** | 考勤、加班审批、工资条、工作成果时间、通讯记录 | 加班事实举证难度较高 |
| **经济补偿** | 工作年限证据、离职原因证据、工资水平证据 | 按年限与月工资口径 |
| **赔偿金** | 违法解除或违法事实的证据 | 针对用人单位违法情形 |
| **未休年假** | 工作年限、年休假记录、未休证明 | 可与其他请求一并主张 |

**经济补偿与赔偿金的区别**（最常混淆）：

| 对比项 | 经济补偿 | 赔偿金 |
|---|---|---|
| 触发情形 | 法定情形下解除或终止 | 用人单位**违法**情形 |
| 性质 | 劳动者可依法主张 | 需用人单位存在违法事实 |
| 混写后果 | **部分请求可能不被支持** | 同左 |

## 二、证据强弱排序（核心）

```
劳动合同  >  社保记录  >  工资流水  >  考勤记录  >  员工陈述
```

| 证据 | 强度 | 说明 |
|---|---|---|
| **劳动合同** | **最强** | 双方合意，内容明确 |
| **社保记录** | 强 | 官方记录，证明劳动关系与工作地 |
| **工资流水** | 较强 | 银行记录客观，证明工资标准与发放 |
| **考勤记录** | 中 | 常由企业掌握 |
| **员工陈述** | 较弱 | 需其他证据印证 |

### 关键认知：企业掌握的证据

**考勤记录、工资台账、规章制度等通常由用人单位掌握管理。**

劳动者无法自行取得时，**应在仲裁中明确请求调取**，不能仅口头提及。用 `scripts/arbitration_checklist.py` 的 `employer_docs` 字段列出。

## 三、材料清单

```
1. 仲裁申请书
   - 申请人信息
   - 被申请人（用人单位名称，与营业执照一致）
   - 请求事项（分项列明，不要笼统）
   - 事实与理由
2. 身份证明
3. 劳动关系证据（劳动合同或事实劳动关系证据链）
4. 工资流水（银行记录）
5. 社保记录
6. 考勤记录（无则列明并主张调取）
7. 证据目录
   - 证据名称
   - 证据来源
   - 证明事项
   - 页码
```

**证据目录是核心文件**——它决定仲裁员能否快速找到你要证明的事实。

## 四、时效口径

| 项 | 说明 |
|---|---|
| 起算 | 通常自知道或应当知道权利被侵害之日起算 |
| 中断情形 | 主张权利、被要求履行、对方同意履行等（以现行规定为准） |
| 前置程序 | 一般需先申请仲裁 |

**两条关键提醒**：

1. **时效可能因主张权利等行为而中断**，但**中断需要证据**（微信、邮件、函件、录音等）。
2. **拖一拖再准备往往已接近甚至超过时效**，这是最常见也最可惜的失误。

**具体时效天数以现行规定和受理机构口径为准**，本文件不写死。

## 五、管辖

- 由**劳动争议仲裁委员会**管辖。
- 通常按**劳动合同履行地**或**用人单位所在地**的属地原则确定。
- 具体以受理机构口径为准。

## 六、企业常见抗辩与应对

| 企业抗辩 | 应对方向 |
|---|---|
| 「不存在劳动关系」 | 社保、工资流水、考勤、聊天记录形成链条 |
| 「已结清工资」 | 要求提供工资台账；口头称已付证明力有限 |
| 「自愿加班无审批」 | 工作成果提交时间、通讯记录、工作安排佐证 |
| 「工资超过最低标准故无加班费」 | 加班费与最低工资是两个口径 |
| 「已达成调解协议」 | 核对协议内容、是否自愿、是否履行 |
| 「超过仲裁时效」 | 核对起算点与中断情形，提交主张权利证据 |
| 「员工是外包而非员工」 | 核对用工管理主体与实际用工情况 |

**通用原则**：企业主张的每一项事实，都要求其提供**书面的、形成于当时的**材料；单方陈述证明力有限。

## 七、调解与裁决的衔接

| 阶段 | 要点 |
|---|---|
| **调解** | 双方协商；调解协议达成后可**申请司法确认** |
| **调解不成** | 转入仲裁审理；调解非强制前置 |
| **裁决** | 不服裁决的，按现行规定依法向人民法院起诉 |
| **裁决后不履行** | 依法申请强制执行，**有法定期限** |

## 八、常见错误对照

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 拖很久才准备 | 时效可能已过 | 尽早核算时效并主张权利 |
| 没写证据目录 | 难以定位事实 | 制作名称来源证明事项页码 |
| 拿不到考勤就放弃 | 企业掌握该证据 | 明确请求调取 |
| 只用零散聊天记录 | 证明力不足 | 与其他证据形成链条 |
| 请求写笼统 | 无法支持 | 分项列明 |
| 混淆补偿与赔偿 | 适用情形不同 | 分别列明 |
| 口头约定工资 | 难被采信 | 找流水等客观记录 |
| 不知调解可司法确认 | 错过强制执行路径 | 调解后申请确认 |
| 裁决不履行不申请执行 | 申请有期限 | 及时申请 |
