# 劳动仲裁流程与材料准备

劳动争议的核心是**两件事**：**时效有没有过**，**证据够不够硬**。本技能给的是这两条的判断口径，以及材料怎么组织才能让请求被支持。

## 一、硬边界（能做 / 不能做）

| 能做 | 不能做 |
|---|---|
| 给出时效、管辖、材料准备的判断口径 | 写死具体时效天数、赔偿倍数或条款编号 |
| 按请求类型列出对应证据 | 承诺仲裁结果或胜诉率 |
| 给出证据强弱排序与补证方向 | 代替劳动者本人签署或提交申请书 |
| 说明企业常见抗辩与应对思路 | 出具法律意见书或代理仲裁 |
| 提示调解与裁决的衔接 | 认定用人单位是否违法（由仲裁机构认定） |

**必须转交执业律师的情形：** 争议金额较大；涉及群体性争议；用人单位已注销或失联；需要主张惩罚性赔偿或涉及复杂股权、竞业限制条款；已进入诉讼或执行阶段。

**所有时效、费用与裁决效力一律以现行规定和受理机构口径为准**，本技能不写死具体天数与金额。

## 二、什么时候用

| 用户说法 | 用不用 | 说明 |
|---|---|---|
| 欠薪怎么办 | 用 | 走请求类型与证据 |
| 没合同能仲裁吗 | 用 | 走事实劳动关系证据 |
| 加班费怎么要 | 用 | 走证据排序 |
| 经济补偿还是赔偿金 | 用 | 走请求类型区分 |
| 仲裁要哪些材料 | 用 | 走材料清单 |
| 时效多久 | 用 | 走时效口径与中断情形 |
| 公司抵赖怎么办 | 用 | 走抗辩与应对 |

## 三、完整工作流

### 步骤 1：先定请求类型（决定要什么证据）

不同请求对应不同证据，**先定类型再备材料**。见第四节。

### 步骤 2：查时效

**时效是最容易被忽视、也最难挽回的一项。** 见第五节。

### 步骤 3：固定证据（越早越好）

与劳动者个人相关的材料（工资记录、考勤）**由用人单位掌握**的，要及时主张调取。

### 步骤 4：匹配材料并核对管辖

用 `scripts/arbitration_checklist.py` 逐项核对。

### 步骤 5：调解与裁决的衔接

**调解不是必须前置，但多数争议在调解阶段能更快解决。**

## 四、核心规则（准备前必读）

**先读 `rules/请求类型与证据矩阵.md`，不要凭印象准备材料。**

### 时效与管辖口径

| 项 | 口径 |
|---|---|
| **申请时效** | 劳动争议申请仲裁的时效**以现行规定为准**；特别注意存在「仲裁前置」与特殊情形的中断规则 |
| **管辖机构** | 由**劳动争议仲裁委员会**管辖，通常按劳动合同履行地或用人单位所在地的属地原则确定 |
| **前置程序** | 一般需先申请仲裁，对仲裁裁决不服的再依法向人民法院起诉 |
| **举证责任** | 与争议事项有关的证据属于用人单位掌握管理的，用人单位应当提供 |

**关于时效的两个关键提醒**：

1. **时效可能因主张权利、被要求履行、对方同意履行等行为而中断**，具体认定以现行规定与仲裁机构口径为准。
2. **知道被侵害之日起算**，拖一拖再准备往往已经接近甚至超过时效，这是最常见也最可惜的失误。

### 七类常见请求类型与对应证据

| 请求类型 | 需要的核心证据 | 备注 |
|---|---|---|
| **确认劳动关系** | 工资流水、社保记录、工作证、考勤、聊天记录、工作安排 | 无合同时的主要路径 |
| **追讨工资** | 工资流水、劳动合同、考勤、银行记录、工资条 | 区分已付与未付部分 |
| **未签劳动合同二倍工资** | 实际用工起止时间证据、工资记录、考勤 | 该项与一般工资的证据基础不同 |
| **加班费** | 考勤、加班审批、工资条中是否体现、工作成果时间 | 加班事实的举证难度较高 |
| **经济补偿** | 工作年限证据、离职原因证据、工资水平证据 | 按年限与月工资口径计算 |
| **赔偿金** | 违法解除或违法事实的证据 | 通常针对用人单位违法情形 |
| **未休年假** | 工作年限、年休假记录、未休证明 | 与其他请求可一并主张 |

**注意**：各请求的计算口径（年限、月工资基数、倍数）**以现行规定为准**，本技能不写死倍数与金额。

### 证据强弱排序（核心）

```
劳动合同  >  社保记录  >  工资流水  >  考勤记录  >  员工陈述
```

| 证据 | 强度 | 说明 |
|---|---|---|
| **劳动合同** | **最强** | 双方合意，内容明确 |
| **社保记录** | 强 | 官方记录，证明劳动关系与工作地 |
| **工资流水** | 较强 | 银行记录客观，证明工资标准与发放情况 |
| **考勤记录** | 中 | 常由用人单位掌握，**应及时主张调取** |
| **员工陈述** | 较弱 | 需其他证据印证 |

**关键认知**：考勤、工资台账等材料**由用人单位掌握**。劳动者无法自行取得时，**应在仲裁中明确请求调取**，而不是仅口头提及。

### 材料清单

```
1. 仲裁申请书（写明请求事项、事实与理由）
2. 身份证明
3. 劳动关系证据（劳动合同或事实劳动关系证据）
4. 工资流水（银行记录）
5. 社保记录
6. 考勤记录（无则列明并主张调取）
7. 证据目录（列明证据名称、来源、证明事项、页码）
```

**证据目录是核心文件**——它决定仲裁员能否快速找到你要证明的事实。

## 五、常见企业抗辩与应对

| 企业抗辩 | 应对方向 |
|---|---|
| 「不存在劳动关系」 | 用社保、工资流水、考勤、聊天记录形成链条 |
| 「已结清工资」 | 要求提供工资台账；仅凭口头称已付不足 |
| 「自愿加班无审批」 | 用工作成果提交时间、通讯记录、工作安排佐证 |
| 「工资已超过最低标准故无加班费」 | 加班费与最低工资是两个口径 |
| 「已达成调解协议」 | 核对协议内容与是否自愿、是否履行 |
| 「超过仲裁时效」 | 核对起算点与中断情形，提交主张权利的证据 |
| 「员工是外包而非员工」 | 核对用工管理主体与实际用工情况 |

**通用应对原则**：企业主张的每一项事实，都要求其提供**书面的、形成于当时的**材料；单方陈述证明力有限。

## 六、调解与裁决的衔接

| 阶段 | 能做 | 要点 |
|---|---|---|
| **调解** | 双方在第三方主持下协商 | 调解协议达成后可申请司法确认 |
| **调解不成** | 转入仲裁审理 | 调解不是强制的必经前置 |
| **裁决** | 仲裁机构作出裁决 | 对裁决不服的，按现行规定依法向人民法院起诉 |
| **裁决后不履行** | 可依法申请强制执行 | 需在法定期限内提出 |

**注意**：申请执行有法定期限，裁决生效后应及时处理，不要拖延。

## 七、脚本用法

脚本：`scripts/arbitration_checklist.py`

```bash
python scripts/arbitration_checklist.py --file 仲裁.json
python scripts/arbitration_checklist.py --selftest
```

| 字段 | 说明 |
|---|---|
| `claims` | 请求类型列表 |
| `evidence` | 已持有证据列表 |
| `months_since_known` | 距知道被侵害的月数（用于时效相对提醒，不写死阈值） |
| `employer_docs` | 需主张调取的企业掌握的证据 |
| `stage` | 当前阶段（准备/仲裁/裁决/执行） |

输出：请求类型与证据匹配矩阵、缺失证据、证据强弱排序、时效相对提醒、需主张调取的证据、下一阶段动作。

## 八、人工确认清单（不能省）

- [ ] 请求类型是否已明确？（不同类型对应不同证据）
- [ ] 证据是否已按**强弱排序**评估（合同 > 社保 > 工资流水 > 考勤 > 陈述）？
- [ ] 企业掌握的证据（考勤、工资台账）是否**已明确主张调取**？
- [ ] 证据目录是否已制作（名称、来源、证明事项、页码）？
- [ ] 时效是否已核算，是否存在中断情形？
- [ ] 是否有主张权利的书面记录（微信、邮件、函件）？
- [ ] 管辖机构是否已按属地原则确认？
- [ ] 是否已了解调解与裁决的衔接关系？
- [ ] 是否已考虑申请执行的法定期限？

## 九、最常见的坑

1. **拖到很久才准备**。时效可能已接近甚至经过，且中断需要证据支撑。
2. **没写证据目录**。仲裁员难以快速定位你要证明的事实。
3. **考勤拿不到就放弃**。考勤由企业掌握，**必须在仲裁中明确请求调取**。
4. **只用聊天记录且内容零散**。聊天记录需与其他证据形成链条。
5. **把请求类型写笼统**。「要求赔偿」无法支持，应分项列明。
6. **混淆经济补偿与赔偿金**。两者适用情形不同，混写会导致部分请求不被支持。
7. **口头承诺工资标准**。无书面或流水支持的约定难被采信。
8. **不知道调解可以司法确认**。调解协议可申请司法确认，具有强制执行力。
9. **裁决后不履行也不申请执行**。申请执行有法定期限，拖延会失权。
10. **误以为必须先劳动监察才能仲裁**。两条路径的关系需按现行规定确认，不要凭印象操作。

## 十、边界与免责

本技能提供仲裁流程、请求类型、证据矩阵与时效口径，**不写死具体时效天数、赔偿倍数、费用金额与条款编号，不承诺仲裁结果**。时效计算、各请求的金额口径、管辖与程序细节**以现行规定和受理机构口径为准**，各地执行口径存在差异。争议金额较大、涉及群体性争议、用人单位失联注销或需主张惩罚性赔偿的，请及时委托执业律师。本技能不代替仲裁机构受理与认定。
