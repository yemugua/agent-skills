# 公司注销流程与清算核查

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 判断简易注销、一般注销或其他退出路径 | 隐匿资产、虚构无债权债务承诺 |
| 核查税务清缴、公告、清算与登记材料 | 代替清算组、股东或董事承担法定义务 |
| 输出时间线、缺件和阻塞项 | 承诺一次通过或精确完成日期 |
| 提示分支机构、许可、账户和档案收尾 | 把吊销、歇业、税务注销当成主体已注销 |
| 整理异议、补正和救济材料 | 处理破产、资不抵债或重大税务争议的最终方案 |

发现资不抵债、账册严重缺失、股东或董事失联、财产混同、未决诉讼、股权冻结、重大欠税、职工安置争议或涉嫌逃废债时，应转交律师、税务专业人员、清算或破产专业机构。

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「公司一直零申报，能走简易注销吗」 | 用，先查债务和限制情形 |
| 「注销公告要挂多少天」 | 用，区分简易公告与一般清算公告 |
| 「税务注销后工商为什么办不了」 | 用，检查是否还有清算和登记步骤 |
| 「营业执照被吊销了，还需要注销吗」 | 用，吊销不等于注销 |
| 「有债务但想承诺无债务快速注销」 | 不用，拒绝虚假承诺 |
| 「公司已无力清偿全部债务」 | 仅做风险提示，转专业破产评估 |

## 三、完整工作流

1. **建退出档案**：主体、股东和董事、分支机构、对外投资、许可、税务、社保、员工、资产负债、诉讼执行、印章账户。
2. **选路径**：按 `rules/deregistration-path.md` 判断是否满足简易注销；有债权债务、清算事项或限制情形时走一般注销或专业程序。
3. **作出解散决定**：按章程与现行规定形成有效决议，明确清算责任、成员和联系人。
4. **完成清算通知与公告**：一般清算需依法通知已知债权人并公告；简易注销按公示系统规定发布承诺与公告。
5. **税费和用工收尾**：核对申报、发票、欠税、社保、公积金、工资补偿、个人所得税及资产处置税务影响。
6. **清理资产负债**：催收债权、清偿费用与债务，编制财产清单、清算报告；未清偿前不得违规分配剩余财产。
7. **提交登记注销**：按路径提交申请、决议、清算报告或全体投资人承诺等材料，逐条回应补正。
8. **注销后收尾**：处理银行账户、印章、许可证、海关、域名店铺、档案保管和股东资料，不擅自销毁会计档案。

## 四、核心规则与要件库

生成注销时间线或承诺文本前，**必须先读**：

- `rules/deregistration-path.md`：简易与一般注销条件、公告期、清算顺序、税务清缴、材料、常见被卡原因和救济。
- `templates/liquidation-workbook.md`：清算底稿、债权人通知记录、注销进度表和补正清单。

所有「无债权债务」「债务已清偿」「税费已结清」必须有账簿、凭证与查询结果支持。出现「未结清」不得被关键词误判为「已结清」。

## 五、人工确认清单

- [ ] 解散事由、决议程序与签署人员有效
- [ ] 简易注销全体投资人承诺真实，且不存在限制情形
- [ ] 所有已知债权人已通知，公告平台和期间正确
- [ ] 税种、发票、欠税、社保、公积金、员工工资补偿已核清
- [ ] 分支机构、对外投资、许可证、海关和网店状态已处理
- [ ] 未决诉讼、执行、担保、质押、冻结和行政处罚已排查
- [ ] 清算报告与账簿、银行余额、资产处置记录相符
- [ ] 注销回执、清算档案和会计档案已按要求保管

## 六、最常见的坑

1. **把「吊销」当「注销」**：吊销只是经营资格受限，主体通常仍存在，清算与注销义务不会自动消失。
2. **零申报就承诺无债务**：租金、工资、社保、股东借款、未开发票收入和担保都可能是未清事项。
3. **简易公告与清算公告混用**：两者路径、平台、期限和法律效果不同，不能拿一张截图互相替代。
4. **只做税务注销**：清税完成不等于市场主体已注销，还需登记注销和其他账户收尾。
5. **漏分支机构或对外投资**：未注销分支、股权冻结、质押等可能阻塞主体验证。
6. **先分剩余财产再还债**：清算费用、职工权益、税费和债务清偿有顺序，违规分配会产生责任风险。
7. **公告期间算错**：从公示系统显示的起止日期核对，不凭提交草稿日期起算。
8. **为注销销毁账册**：账册缺失会放大税务与清算风险，注销后仍有档案保管义务。
