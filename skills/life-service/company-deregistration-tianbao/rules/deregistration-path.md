# 公司注销路径与清算规则

## 一、路径判断

| 核查项 | 简易注销倾向 | 应转一般注销或专业处理 |
|---|---|---|
| 债权债务 | 未发生或已全部清偿，可据实承诺 | 尚有债务、担保、争议或债权人不明 |
| 税费与发票 | 已核清，符合便捷清税条件 | 欠税、风险事项、发票或申报未处理 |
| 员工权益 | 无员工欠款，社保公积金已处理 | 欠工资、补偿、社保或劳动争议 |
| 企业状态 | 不存在系统限制情形 | 股权冻结、质押、未决处罚、被立案调查等 |
| 分支与投资 | 已清理或不存在 | 尚有分支机构、对外投资待处置 |
| 全体投资人 | 能作真实一致承诺 | 有人失联、拒签或对债务有异议 |
| 偿债能力 | 足以清偿全部债务 | 明显资不抵债，需评估破产程序 |

简易注销并不是「材料少就能用」，核心是全体投资人对无未了债权债务等事项作真实承诺。被提出异议、承诺不实或出现限制情形时，不得硬走简易路径。

## 二、常见时间轴

### 简易注销

1. 完成税务、员工、债务和限制情形自查。
2. 全体投资人形成真实承诺，通过规定公示渠道发布简易注销公告。
3. 常见公告期为 **20 日**；期间有关部门、债权人及利害关系人可提出异议。
4. 公告期满无有效异议后，在系统提示的申请期限内提交注销登记。
5. 登记机关审查和补正时间以受理回执为准。

### 一般注销

1. 有效形成解散决定并依法组织清算。
2. 清算组织成立后，通常应在 **10 日内**通知已知债权人，并在 **60 日内**依法公告。
3. 债权人通常自收到通知之日起 **30 日内**申报；未收到通知的，通常自公告之日起 **45 日内**申报。
4. 编制资产负债表与财产清单，处理合同、职工、税费、债权债务、诉讼与资产。
5. 形成清算报告并按公司治理要求确认，完成税务与登记注销。

不同主体、地区与系统可能有衔接差异，所有期间以现行规定和公示平台提示为准。

## 三、清算顺序与禁止动作

- 先确认清算财产和清算费用。
- 依法处理职工工资、社会保险、法定补偿等权益。
- 结清税费。
- 清偿公司债务。
- 全部清偿后，才可按法定或章程规则分配剩余财产。

不得隐匿、转移、低价处置给关联方，不得抢先向股东分配，不得把未到期、附条件或有争议的债务直接写成不存在。发现财产不足清偿全部债务时，应停止无序个别清偿并尽快获得破产法律意见。

## 四、材料清单

| 阶段 | 常见材料 | 高频被卡原因 |
|---|---|---|
| 解散 | 决议、章程、主体与签署人材料 | 表决比例或签署人员不符 |
| 清算 | 清算成员信息、财产清单、债权债务台账 | 账册、银行余额和清单不一致 |
| 通知公告 | 已知债权人送达凭证、公示截图 | 只公告未通知已知债权人 |
| 税务 | 申报、发票、清缴或系统办结证明 | 漏税种、漏申报、非正常户未解除 |
| 员工 | 工资、补偿、社保公积金结清资料 | 员工名单和申报人数不一致 |
| 登记注销 | 申请书、决议、清算报告或承诺书、执照 | 简易与一般路径材料混交 |
| 收尾 | 银行、印章、许可、海关、档案记录 | 先注销账户导致款项无法收付 |

## 五、常见限制与排查

- 尚有未结案诉讼、执行、仲裁或行政调查。
- 股权被质押、冻结，或公司财产被查封。
- 仍有分支机构、对外投资、许可资质未处置。
- 被列入异常或严重失信后，尚未满足处理要求。
- 法定代表人、股东或董事身份签署无法核验。
- 企业名称、统一社会信用代码或迁移登记信息不一致。
- 简易注销公告期间收到异议。
- 「未清税」「未结清工资」被错误当成已完成。

## 六、办理时限、补正与救济

- **计划时间**：简易注销至少预留 20 日公告期与后续申请审查；一般注销至少覆盖通知、60 日内公告及债权申报、税务和资产清理时间，复杂案件会显著延长。
- **补正**：要求受理机关列明缺件、路径冲突和期限，逐项形成补正对照表。
- **异议**：先确认异议主体、依据与未了事项，解决后选择重新申请、转一般注销或专业程序，不伪造承诺绕过。
- **登记争议**：对不予受理、不予登记等正式决定，按文书载明渠道申请复核、行政复议或行政诉讼。
- **股东失联**：保留通知与送达记录，核对章程和治理程序；不得冒签，必要时通过诉讼或司法解散、清算路径处理。

所有材料、期限、简易注销条件、清税和救济，**以现行规定和当地市场监管、税务等主管部门要求为准**。
