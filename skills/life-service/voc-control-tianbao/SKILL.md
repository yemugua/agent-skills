# VOCs 治理（voc-control）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据挥发性有机物治理与排放标准要求，生成清单：VOCs 源头识别与排放台账、收集与治理设施（吸附/燃烧/冷凝）、治理效率与排放监测、运行维护与耗材更换、排放合规性自查。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- VOCs治理
- 挥发性有机物
- 废气治理
- 活性炭吸附
- 废气排放监测

## 三、工作流
1. 识别源头并建立排放台账
2. 配置收集与治理设施
3. 监测治理效率与排放浓度
4. 做好运行维护与耗材更换
5. 开展排放合规性自查

## 四、核心内容（检查清单与判定）
VOCs 治理应源头控制、应收尽收，治理设施（吸附/燃烧/冷凝等）须正常运行并定期更换耗材，排放须达标并留监测记录。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含源头识别与排放台账 | 台账 |
| Q2 | FAIL | 未含收集与治理设施 | 设施 |
| Q3 | WARN | 未含治理效率与排放监测 | 监测 |
| Q4 | FAIL | 未含运行维护与耗材更换 | 维护 |
| Q5 | WARN | 未含排放合规性自查 | 合规 |

> 脚本 `voc-control_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python voc-control_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python voc-control_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
