# 轮胎更换时机与磨损判断规则库

> 生成判断结论、给检查清单之前，先读这份文件，不要凭印象写。
> 胎纹下限等安全数值以现行规定和车辆说明书要求为准。

---

## 一、磨损判断三维度

| 维度 | 怎么看 | 说明 |
|---|---|---|
| 胎纹深度 | 胎面花纹沟深度，胎侧通常有刻度标记 | 低于现行规定下限必须更换 |
| 使用年限 | 胎侧周数编码 | 超过厂家标注年限建议更换 |
| 磨损均匀度 | 对比四条轮胎与左右两侧 | 单侧偏磨往往有别的原因 |

**核心口径**：里程和年限要一起看，**先到者为准**。里程少但年份久的轮胎同样需要更换。

---

## 二、生产日期周数编码读取法

```
四位数字：前两位是周数（01 到 52 或 53），后两位是年份（20xx）
示例：2219 表示第 22 周、生产于 2022 年
```

**注意**：部分品牌的第三四位不是年份而是生产日期，**编码规则不完全一致，拿不准时以厂家说明为准**。

**用法**：算出生产日期到现在过了多少个月，与厂家标注的使用年限对比，超过即考虑更换。

---

## 三、偏磨原因对照表

| 磨损形态 | 常见原因 | 应做什么 |
|---|---|---|
| 单侧偏磨 | 胎压长期偏高或偏低 | 检查胎压并按标准充气 |
| 单侧偏磨加方向盘偏 | 定位偏差 | 做四轮定位 |
| 前后磨损差异大 | 驱动形式与轴荷分配 | 确认是否为该车正常表现 |
| 胎面边缘磨损 | 胎压长期偏低 | 按标准充气 |
| 中间磨损两侧浅 | 胎压长期偏高 | 按标准充气 |
| 单个轮胎不规则锯齿状 | 轮辋变形或轴承异常 | 检查轮辋与轴承 |
| 胎侧异常磨损 | 定位偏差、载重异常 | 检查定位与使用方式 |

**核心口径**：**换胎前先找出偏磨的原因**，否则新胎很快重复同样的磨损。

---

## 四、更换周期的影响因素

| 因素 | 说明 |
|---|---|
| 里程 | 主要消耗因素之一 |
| 年限 | 与里程独立，少开也会到期 |
| 载荷 | 长期满载加快磨损 |
| 路面状况 | 颠簸碎石路段加速磨损 |
| 气候 | 高温地区老化更快 |
| 驾驶习惯 | 急加速急刹车增加磨损 |

**判定原则**：里程与年限先到者为准，**最终看实际磨损状态**。

---

## 五、安全红线（立即停车）

| 情形 | 判定 |
|---|---|
| 鼓包 | 立即停车 |
| 胎侧割伤或裂口 | 立即停车检查 |
| 帘线暴露 | 立即更换 |
| 胎纹低于现行规定下限 | 必须更换 |
| 异常发热 | 立即停车 |
| 行驶中异常震动且方向不稳 | 立即停车 |

**这些不是注意观察，是立即停车。**

---

## 六、更换后必做项

| 顺序 | 项目 | 原因 |
|---|---|---|
| 1 | 做动平衡 | 不平衡会导致高速振动、加剧磨损、影响操控 |
| 2 | 按说明书标准检查胎压 | 胎压直接影响磨损形态与油耗 |
| 3 | 做四轮定位 | 有偏磨或原车有定位记录时 |
| 4 | 确认方向盘居中、不跑偏 | 检查安装结果 |
| 5 | 里程上来后复测一次 | 确认磨损是否均匀 |

---

## 七、补胎适用边界

| 情况 | 是否可补 |
|---|---|
| 胎面扎钉孔且不在胎肩胎侧 | 通常可补 |
| 胎侧扎伤 | 通常不建议 |
| 胎肩附近扎伤 | 通常不建议 |
| 孔洞较大 | 通常不建议 |
| 多次修补 | 风险上升，需评估 |
| 帘线暴露 | 不可补，必须换 |

**原则**：补胎是应急与延长使用的手段，不是无限延寿的办法。

---

## 八、备胎适用边界

| 项目 | 说明 |
|---|---|
| 限速 | 通常限速使用，数值看胎壁标注 |
| 长途 | 通常不适合长距离高速行驶 |
| 尺寸 | 部分车型为折叠式或非全尺寸 |
| 使用后 | 补好胎尽快到正规点检查，必要时更换 |
| 使用后检查 | 检查气压，对全轮做动平衡与定位 |

## 十、常见误区对照

| 说法 | 是否成立 |
|---|---|
| 里程没到就不用换 | 不成立，年限到了也要换 |
| 胎纹还深就一定没问题 | 不成立，老化与偏磨也要看 |
| 偏磨换胎就行 | 不成立，胎压与定位问题不解决会重复 |
| 换了胎不用做动平衡 | 不成立，会振动并加剧磨损 |
| 鼓包可以先开回家 | 不成立，立即停车 |
| 胎侧扎伤也能补 | 通常不成立 |
| 备胎可以当正常胎用 | 不成立，限速且不适合长途 |
| 周数编码第三位都是年份 | 不成立，品牌规则不一致 |
