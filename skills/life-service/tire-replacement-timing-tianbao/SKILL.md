# 轮胎更换时机与磨损判断（tire-replacement-timing）

轮胎该不该换，**不是看里程到了没有，是看磨损状态和使用年限到了没有**。开了两万公里的新胎可能已经偏磨严重，三万公里的胎可能还很新。

这个技能做四件事：**读磨损** → **读日期** → **找偏磨原因** → **定更换动作**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 说明胎纹深度与年限的判断口径 | ❌ 给出具体的法定胎纹下限数值 |
| 说明生产日期编码的读取方法 | ❌ 编造法规条款号或标准号 |
| 解释偏磨的常见原因 | ❌ 代用户操作车辆或拆装轮胎 |
| 说明更换后必须做的项目 | ❌ 判断轮胎是否还能继续使用 |
| 说明补胎与备胎的适用边界 | ❌ 指导不规范的补胎或轮胎改装 |

**涉及法规与安全要求的部分，一律以现行规定和车辆说明书要求为准。** 具体的胎纹深度下限、磨损限值等数值要求以现行规定和车辆说明书为准，本技能只讲判断方法，不写死数字。

**出现以下情况，立即停车检查，不要继续行驶：**

- 轮胎鼓包
- 胎侧有割伤、裂口或异常磨损
- 胎面出现帘线暴露
- 明显异常震动且伴随方向不稳
- 轮胎在行驶中异常发热

## 二、磨损判断的口径

**看三个维度，缺一不可：**

| 维度 | 怎么看 | 说明 |
|---|---|---|
| **胎纹深度** | 胎面花纹沟的深度，胎侧通常有刻度标记 | 低于法定下限必须更换 |
| **使用年限** | 胎侧的周数编码 | 超过厂家标注的使用年限建议更换 |
| **磨损均匀度** | 对比四条轮胎与左右两侧的磨损 | 单侧偏磨往往是有别的问题 |

**关于胎纹深度刻度**：胎侧通常有标记沟深的小刻度。**低于现行规定要求的下限就必须更换，不存在「还能凑合」。** 具体数值以现行规定和车辆说明书为准。

**关于使用年限**：轮胎是橡胶制品，**即使里程很少但放了很多年也会老化**。反过来里程很长但轮胎很新，状态可能仍然好。所以**年限和里程要一起看，先到者为准**。

---

## 三、生产日期周数编码读取法

**轮胎胎侧通常有一串编码，其中包含生产日期。读取方法：**

```
四位数字，前两位是周数，后两位是年份
周数从 01 到 52（或 53），年份取 20xx
```

**举例说明**：看到 `2219` 表示第 22 周、生产于 2022 年。

**注意区分**：有些编码的第三、第四位不是年份而是生产日期（某日某月），**不同品牌的编码规则不完全一致**。拿不准时看胎侧其他标注或以厂家说明为准。

**用法**：算出生产日期到现在过了多少个月，与厂家标注的使用年限对比。**超过就要考虑更换，哪怕胎纹还很深。**

## 四、前后轮差异与偏磨

**轮胎磨损不均匀通常不是轮胎本身的问题，而是有别的原因。** 偏磨是症状，要找原因。

| 磨损形态 | 常见原因 | 应做什么 |
|---|---|---|
| 单侧偏磨（左右不一致） | 胎压长期偏高或偏低 | 检查胎压并按标准充气 |
| 单侧偏磨 + 方向盘偏 | 定位偏差 | 做四轮定位 |
| 前后磨损差异大 | 驱动形式与轴荷分配 | 确认是否为该车正常表现 |
| 胎面边缘磨损 | 胎压长期偏低 | 按标准充气 |
| 中间磨损、两侧浅 | 胎压长期偏高 | 按标准充气 |
| 单个轮胎不规则锯齿状磨损 | 轮辋变形或轴承异常 | 检查轮辋与轴承 |
| 胎侧异常磨损 | 定位偏差、载重异常 | 检查定位与使用方式 |

**核心口径**：**换胎前先找出偏磨的原因，否则新胎换上很快会重复同样的磨损。** 只换胎不做定位或胎压纠正，是在重复花钱。

## 五、更换周期与里程

| 影响因素 | 说明 |
|---|---|
| 里程 | 常规使用里程是主要消耗因素之一 |
| 年限 | 橡胶老化与里程独立，即使少开也会到期 |
| 载荷 | 长期满载会加快磨损 |
| 路面状况 | 颠簸、碎石路段加速磨损 |
| 气候 | 高温地区老化更快 |
| 驾驶习惯 | 急加速急刹车会增加磨损 |

**判定原则**：**里程与年限，先到者为准。** 不要因为里程没到就一直用，也不要因为里程到了就认定必须换——**最终看的是实际磨损状态**。

---

## 六、安全红线（立刻停车的情形）

| 情形 | 判定 |
|---|---|
| **鼓包** | 立即停车，不要继续行驶 |
| **胎侧割伤或裂口** | 立即停车检查 |
| **帘线暴露** | 立即更换 |
| **胎纹低于现行规定下限** | 必须更换 |
| **异常发热** | 立即停车 |
| **行驶中异常震动且方向不稳** | 立即停车 |

**这些不是「注意观察」，是立即停车。** 尤其是鼓包，鼓包意味着内部结构已经受损，继续行驶有爆胎风险。

---

## 七、更换后必做项

```
第 1 步  做动平衡：新胎装上后必须做动平衡
第 2 步  检查胎压：按车辆说明书规定的冷胎胎压
第 3 步  做四轮定位：尤其是有偏磨或原车有定位数据记录的
第 4 步  复测方向：确认方向盘是否居中，车辆是否跑偏
第 5 步  观察一周：里程上来后复测一次胎压与磨损是否均匀
```

**为什么必须做动平衡**：不平衡会让轮胎在高速下振动，加剧磨损并影响操控。**新胎不做动平衡是常见且不必要的省略。**

**为什么必须检查胎压**：胎压直接影响磨损形态与油耗，充气不足和过量都会造成偏磨。

## 八、补胎与备胎的适用边界

**补胎适用边界**：

| 情况 | 是否可补 |
|---|---|
| 胎面扎钉孔，且位置不在胎肩、胎侧 | 通常可补 |
| 胎侧扎伤 | 通常不建议，胎侧薄且受力复杂 |
| 胎肩附近扎伤 | 通常不建议 |
| 孔洞较大 | 通常不建议 |
| 多次修补 | 需评估，风险上升 |
| 帘线暴露 | 不可补，必须换 |

**原则**：能否补要看损伤位置、大小与次数，**补胎是应急与延长使用的手段，不是无限延寿的办法**。

**备胎的适用边界**：

- 备胎通常限速使用，限速数值看轮胎侧壁标注
- 备胎通常不适合长距离高速行驶
- 部分车型的备胎为折叠式或非全尺寸，尺寸与用途不同
- 补好胎后仍应尽快到正规点做检查，必要时更换
- 备胎使用后要检查气压，并对全轮做动平衡与定位

**安全要求以现行规定和车辆说明书要求为准。**

## 九、脚本用法

```bash
python scripts/tire_wear_check.py --week 22 --year 2022 --depth 2.5 --skew 3
python scripts/tire_wear_check.py --file tire.json --out 判断结果.md
python scripts/tire_wear_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--week` | 生产日期的周数编码（01-53） |
| `--year` | 生产日期的年份 |
| `--depth` | 测得的胎纹深度（毫米） |
| `--skew` | 左右磨损差异（毫米），用于偏磨判断 |
| `--file` | 从 JSON 读（自动兼容带 BOM 的文件） |
| `--out` | 结果落盘路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本输出**生产日期解析结果、距今月数、与常见年限的对照、偏磨原因提示、必做项清单**。

> 脚本只做算术与规则判定，**不代表现场测量**。胎纹下限等安全数值以现行规定和车辆说明书为准。

## 十一、最常见的坑

**坑一：只看里程不看年限。**
橡胶会老化，里程少但年份久的轮胎同样需要更换。

**坑二：只看胎纹深度就放心。**
胎纹还深不代表没老化，四条轮胎的磨损均匀度也要看。

**坑三：偏磨了直接换胎不查原因。**
胎压或定位问题不解决，新胎换上很快重复同样的磨损，等于重复花钱。

**坑四：胎压偏高偏低不管。**
胎压是偏磨最常见的原因，长期不管会持续损坏新胎。

**坑五：换了胎不做动平衡。**
不平衡会导致高速振动、加剧磨损并影响操控。

**坑六：鼓包了继续开。**
鼓包意味着内部结构已受损，有爆胎风险，**立即停车**。

**坑七：胎侧扎伤也去补。**
胎侧薄且受力复杂，通常不建议补。

**坑八：反复补同一条胎一直用。**
补胎是应急与延长使用的手段，不是无限延寿的办法。

**坑九：拿备胎当正常胎上高速跑长途。**
备胎通常限速使用且不适合长途，补好胎后仍应尽快到正规点检查。

**坑十：把周数编码第三位当年份。**
不同品牌编码规则不完全一致，拿不准时以厂家说明为准。

## 十二、边界与免责

- 本技能**只讲判断方法与操作指引**，不代用户操作车辆或拆装轮胎
- 胎纹深度下限、磨损限值等**以现行规定和车辆说明书要求为准**，本技能不写死具体数值
- 周数编码的规则**以轮胎厂家说明为准**
- 是否还能继续使用、能否修补的最终判定应由专业人员做出
- 不指导不规范的补胎、不指导轮胎改装与不符合规定的替换
