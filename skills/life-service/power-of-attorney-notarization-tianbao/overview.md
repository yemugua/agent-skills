# 委托书公证办理与要素核查 · 能力概览

## 你会得到什么

一套把「委托书写得像不像那么回事」变成**可逐项核对**的清单——委托书被退件，绝大多数不是格式问题，而是要素缺失或权限写得没法执行。

**六项必备要素**：委托人（姓名+身份证号+住址+电话）、受托人（同上）、代理事项（具体到标的与环节）、权限范围（分项列举）、有效期限（起止日期）、签名与捺印（本人完成不得代签）。每项都写清「缺失或含糊的后果」。

**权限范围四种写法对照**：概括式 / 分项式 / 权限清单式 / 排除式，各自的优点、风险与适用场景，并给出「分项式 + 排除式」的推荐写法全文。四条硬规则：代理事项具体到标的、权限与事项匹配、「全权代理」不是万能、排除式条款写进正文不做口头约定。

**材料清单**：通用材料五项，加上不动产、股权、户籍、医疗、涉外、诉讼、继承、监护、劳动、社保、税务、银行、证券、合同等十七类事项的追加材料，以及办理条件与退件原因改正方法。

**三个最容易混的概念**：委托书是授权的依据、公证是对授权行为的证明、代理行为是受托人实际做的事——**不是所有委托都需要公证**；涉外事项要走「公证 → 领事认证 → 目标国当地手续」三步，且必须先问目标国受理机构。

**脚本**：`scripts/poa_check.py` 读取委托书文本，逐项核六要素、识别「全权代理一切事务」这类笼统表述、核对有效期限的起止日期与逻辑、识别代签代捺，并按代理事项输出追加材料清单。

## 典型用法

1. 委托书写完先自查：脚本跑一遍，缺什么一目了然。
2. 被退件了想知道原因：对照五类常见退件原因，通常只差一两项，不必整份重抄。
3. 权限不会写：直接用推荐的分项式 + 排除式模板改写。
4. 拿不准要不要公证：先看 §7 的三个判断维度，再问受理方。
5. 涉外委托：先问目标国受理机构，再决定是公证 + 认证还是其他形式。

## 边界

- 只做**要素核查、材料清单与流程说明**，**不代替公证机构的受理与出具**，也不能保证一定办成
- 材料清单、办理时限、收费标准**以受理机构实际答复为准**，不同机构与区县要求可能不同
- **以现行规定和当地主管部门要求为准**，本技能不引用具体法条条款号
- 涉外要求**以目标国受理机构的具体规定为准**，不得凭经验套用他国流程
- 脚本只做文本检查，**无法判断内容是否真实**，也不能替代公证员的面询，最终能否受理由公证机构决定
- 涉及诉讼、重大财产、婚姻家庭事项，**应先咨询执业律师**；本技能仅作材料与流程准备，不构成法律意见
- 不提供任何规避真实意思表示核验的做法，也不建议伪造或借用身份办理
