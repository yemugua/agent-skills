# 授权委托书模板（要素框架）

> **使用说明**
> - 本模板只提供**要素框架与写法示例**，不代填、不代签。
> - 方括号 `[ ]` 内为待填写内容，**必须按实际情况填写**。
> - 建议**现场手写**，多数公证处不接受提前打印好的文书。
> - **是否需要公证，请先向受理机构确认**——多数事项凭委托书原件加身份证明即可办理。
> - 涉及诉讼、重大财产、婚姻家庭事项，请先咨询执业律师。

### 三、代理事项（必须具体到标的与环节）

```
受权人 [委托人姓名] 现委托 [受托人姓名] 作为我的合法代理人，
代为办理以下事项：

[具体事项描述，例如：办理位于 ×× 市 ×× 区 ×× 路 ×× 号
不动产的转移登记手续]

委托原因：[例如：本人无法亲自到场办理]
```

> ❌ 反例：「代为办理房产相关手续」——不知道是哪个房产、办什么手续、办到哪一步。
> ✅ 正例：「代为办理位于 ×× 市 ×× 区 ×× 路 ×× 号不动产的转移登记手续」。

### 四、代理权限（推荐分项式 + 排除式）

```
代理权限：
1. 代为签署与本次事项相关的合同、协议及文件；
2. 代为办理本次事项涉及的手续、材料提交与领取；
3. 代为接收与本次事项相关的款项（仅限 [金额] 元）；
4. 代为办理本次事项涉及的其他必要手续。

以下事项不在授权范围内（本委托书不授予）：
1. 转让、出租、出售上述标的；
2. 设定抵押、质押；
3. 办理与本事项无关的登记或变更；
4. 再委托第三人（除非另有书面约定）。
```

> ❌ 反例：「全权代理委托人办理一切事务」——授权范围不可执行，
> 可能被受理机构或相对方以显失公平为由拒收，事后也难主张已获授权。
> 📌 权限必须与事项匹配：办过户需要签字权，就不能只给「代为提交材料」的权限。

### 五、有效期限

```
本委托书自 [    ] 年 [  ] 月 [  ] 日 起 至 [    ] 年 [  ] 月 [  ] 日 止。
```

> ❌ 反例：「长期有效」「永久有效」——实务中常被视为约定不明。
> ⚠️ 期限到期前应重新委托，不要等到用的时候才发现已过期。

## 办理前自查

- [ ] 已确认是否真的需要公证（问受理方，不要默认需要）
- [ ] 已向受理机构确认材料清单
- [ ] 委托人具备完全民事行为能力
- [ ] 代理事项具体到标的与环节
- [ ] 权限范围用分项式写清，不是「全权代理」一句
- [ ] 有效期限写明起止日期
- [ ] 受托人已确认接受委托，身份证信息与本委托书完全一致
- [ ] 事项证明材料已备齐
- [ ] 特殊事项（涉外、上门见证、视频见证）已确认额外要求

## 办理中自查

- [ ] 出示身份证**原件**
- [ ] 委托书**现场手写**
- [ ] **本人签名**，无他人代签
- [ ] **本人按捺指印**
- [ ] 面询时如实、明确回答
- [ ] 有不适配的代理事项时**主动取消**，不要硬写

## 领取后自查

- [ ] 逐字核对公证书内容（姓名、身份证号、标的、期限）
- [ ] 确认**份数**足够
- [ ] 登记有效期到期提醒
- [ ] 受托人已收到公证书与委托书
- [ ] 办理受托事项时带齐全部原件
