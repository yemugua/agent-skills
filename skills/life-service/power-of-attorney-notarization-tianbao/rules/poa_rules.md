# 委托书要素、权限写法与办理材料规则表

本文件是 `power-of-attorney-notarization` 的核心资产。**起草、改稿或核对材料之前，先读本文件，不要凭印象写。**

---

## 一、六项必备要素对照表

| # | 要素 | 必填字段 | 缺失/含糊的后果 |
|---|---|---|---|
| 1 | 委托人 | 姓名、性别、出生日期、身份证号、住址、联系电话 | 与产权/工商登记对不上，无法核验身份 |
| 2 | 受托人 | 姓名、性别、出生日期、身份证号、住址、联系电话 | 无法定位责任主体，代办机构拒收 |
| 3 | 代理事项 | 做什么 + 哪个标的 + 哪个环节 | 授权范围不可执行，事后主张困难 |
| 4 | 权限范围 | 具体到动作的分项列举 | 笼统授权易被以显失公平为由拒收 |
| 5 | 有效期限 | 起止日期（YYYY 年 MM 月 DD 日） | 过期未重签等于无授权；「长期有效」被视为约定不明 |
| 6 | 签名捺印 | 委托人本人签名 + 按捺指印 | 代签无效，且属于违规办理 |

**补充要素（有则更稳）：**

- 委托原因/说明
- 是否允许转委托
- 争议解决方式
- 委托书份数与签收方式
- 附件清单

## 二、权限范围四种写法对照

| 写法 | 示例 | 优点 | 风险 | 适用 |
|---|---|---|---|---|
| 概括式 | 「全权代理委托人办理上述事项」 | 简洁 | 笼统、易被拒收、事后难主张已授权 | 不推荐单独使用 |
| 分项式 | 「① 签署合同；② 办理过户；③ 领取证件」 | 边界清楚 | 事项多时易漏项 | ✅ 推荐 |
| 权限清单式 | 附清单逐项勾选，未勾选视为未授权 | 最严谨 | 手续繁琐 | 涉重大财产 |
| 排除式 | 「授权…但不包括转让、抵押、变更登记」 | 明确禁区 | 需双方认可 | 有明确禁区时补充 |

**推荐组合：分项式 + 排除式**

```
委托权限：
1. 代为签署与本次事项相关的合同、协议及文件；
2. 代为办理本次事项涉及的手续、材料提交与领取；
3. 代为接收与本次事项相关的款项（仅限 ______ 元）；
4. 代为办理本次事项涉及的其他必要手续。

以下事项不在授权范围内（本委托书不授予）：
1. 转让、出租、出售上述标的；
2. 设定抵押、质押；
3. 办理与本事项无关的登记或变更；
4. 再委托第三人（除非另有书面约定）。
```

**必须遵守的四条：**

1. 代理事项**具体到标的**（地址、证号、标的名称）。
2. 权限与事项**匹配**（办过户需签字权，不能只给提交材料的权限）。
3. **「全权代理」不是万能**，多数机构与相对方有权拒绝接收权限不明的文件。
4. 排除式条款**写进正文**，不做口头约定。

## 三、材料清单

### 通用材料

| # | 材料 | 必需性 | 备注 |
|---|---|---|---|
| 1 | 委托人身份证原件 | 必需 | 核验原件并留存复印件 |
| 2 | 受托人身份证件 | 一般必需 | 原件或复印件视机构要求 |
| 3 | 委托书正文 | 必需 | 一般现场手写 |
| 4 | 事项证明材料 | 按事项定 | 见下表 |
| 5 | 本人签名与指印 | 必需 | 现场完成 |

### 特殊事项追加材料

| 事项 | 追加材料 |
|---|---|
| 不动产转移登记 | 不动产权证/购房合同、身份证、户口本、结婚证（如共有） |
| 股权转让 | 营业执照、公司章程、股东会决议、股权证 |
| 诉讼 | 一般走律师代理，不走委托公证；先问律师或立案庭 |
| 户籍迁移 | 户口本、迁移事由证明 |
| 医疗住院事务 | 住院证明、病情证明 |
| 房产交易 | 购房合同、定金收据、资金监管协议 |
| 涉外/港澳台 | 护照或通行证、目标地区机构特殊要求 |
| 涉未成年或老人 | 监护证明、亲属关系证明、必要见证材料 |

> **以受理机构实际要求为准。** 同一事项在不同机构、不同区县要求可能不同，办之前先电话或线上确认。

## 四、办理条件

| 条件 | 要求 | 不满足时 |
|---|---|---|
| 主体资格 | 完全民事行为能力人 | 由法定代理人办理 |
| 意思表示真实 | 自愿、明确、无胁迫欺诈 | 拒绝办理 |
| 内容合法 | 不违反强制性规定 | 拒绝办理 |
| 材料齐全 | 身份证明 + 事项证明 | 退件补正 |
| 本人到场 | 一般需本人签署，不得代签 | 需问上门/视频见证 |
| 现场询问 | 公证员会问关键要素 | 答不上来可能拒绝 |

## 五、办理流程与时限参照

| 步骤 | 内容 |
|---|---|
| 1 | 确认是否需要公证（多数事项不需要） |
| 2 | 联系受理机构确认材料清单与特殊要求 |
| 3 | 准备材料，重点是事项证明材料 |
| 4 | 委托人本人到场出示身份证原件 |
| 5 | 现场书写委托书（建议手写，不提前打印） |
| 6 | 签名 + 按捺指印 |
| 7 | 公证员询问关键要素 |
| 8 | 受理审核 |
| 9 | 出具公证书 |
| 10 | 领取并逐字核对 |

**时限参照：**

| 环节 | 一般耗时 |
|---|---|
| 简单事项（材料齐全） | 当日或数个工作日 |
| 需核实事项 | 若干个工作日 |
| 需上门/视频见证 | 按预约安排，需提前预约 |
| 涉外公证 | 通常更长，后续还可能需认证 |

> **以受理机构答复为准**，本表仅为流程预期，不构成承诺。重要事项建议预留 1–2 周，并准备无公证版本备选。

## 六、退件原因与改正

| # | 退件原因 | 表现 | 改正 |
|---|---|---|---|
| 1 | 要素缺失 | 缺身份证号/联系方式/期限 | 按六要素逐条补齐 |
| 2 | 权限笼统 | 「全权办理一切事务」 | 改分项式，必要时加排除式 |
| 3 | 主体资格不符 | 限制行为能力人、失能、代签 | 由法定代理人办理；先咨询上门见证 |
| 4 | 证明材料不足 | 权属或关系证明缺失 | 补齐产权证/营业执照等 |
| 5 | 意思表示存疑 | 面询问答非所问、表述矛盾 | 如实明确回答；不适配的事项主动取消 |

**次常见原因：**

- 笔误划改未写「作废」重写
- 签名与身份证姓名不一致（含曾用名未说明）
- 日期格式混乱（统一「YYYY 年 MM 月 DD 日」）
- 模板未删干净（房产模板用在车辆事项上）
- 分页未处理骑缝
- 多事项只给一份委托书

**退件后正确做法：先问清具体原因，再改对应项，不要盲目整份重抄。**

## 七、公证与代理的边界

| 维度 | 授权委托 | 公证 | 代理行为 |
|---|---|---|---|
| 是什么 | 授权文书 | 对文书的效力核验背书 | 受托人实际做的事 |
| 谁做 | 委托人签署 | 公证机构 | 受托人执行 |
| 作用 | 证明「我授权他做这件事」 | 增强证明力 | 产生实际法律效果 |
| 是否必须 | 多数事项必须 | **多数事项不是必须** | 接受委托后应做 |

**是否需要公证，看三点：**

1. 受理机构的具体要求（不动产、法院、涉外通常更严）
2. 相对方的要求（银行、券商、大型企业合同相对方常要求）
3. 事项的重要程度与潜在争议风险

> **先问受理方是否需要。** 很多事项凭委托书原件加身份证明即可办理。

## 八、涉外三步流程与概念区分

```
1. 中国公证处办理公证        （证明签名印章真实）
2. 驻华使领馆办理领事认证    （证明中国公证处效力）
3. 目标国当地追加手续        （翻译、海牙认证、公证等）
```

| 概念 | 由谁做 | 做什么 | 性质 |
|---|---|---|---|
| 公证 | 中国公证机构 | 核验签名、印章、事实真实性 | 中国境内行为 |
| 领事认证 | 驻华使领馆 | 证明中国公证书有效 | 中国境内行为 |
| 海牙认证 | 缔约国之间 | 公文跨境流通的形式认证 | 需确认目标国是否适用 |

**四条必须注意：**

1. **必须先确认目标国的具体要求**（不同国家、不同部门可能不同）。
2. **文件语言**：通常不接受中文文书，需按要求翻译并签署声明或公证。
3. **部分国家不接受中国公证 + 领事认证**，而要求其他形式。
4. **使馆认证时间不可控**，重要事项不要把时间压到最低。

> **以目标国受理机构的具体要求为准。**

## 九、三阶段自查清单

### 办理前
- [ ] 已确认是否真的需要公证（问受理方）
- [ ] 已确认材料清单
- [ ] 委托人具备完全民事行为能力
- [ ] 代理事项具体到标的和范围
- [ ] 权限范围用分项式写清
- [ ] 有效期限明确
- [ ] 受托人已确认接受委托且信息一致
- [ ] 事项证明材料已备齐
- [ ] 特殊事项已确认额外要求

### 办理中
- [ ] 出示身份证原件
- [ ] 委托书现场手写
- [ ] 本人签名，无代签
- [ ] 本人按捺指印
- [ ] 面询时如实明确回答
- [ ] 不适配的事项主动取消

### 领取后
- [ ] 逐字核对姓名、身份证号、标的、期限
- [ ] 份数足够
- [ ] 有效期已登记提醒
- [ ] 受托人已收到文书
- [ ] 办理受托事项时带齐原件

## 十、反误判清单

| 现象 | 常见误判 | 真实情况 | 正确做法 |
|---|---|---|---|
| 要办委托 | 必须公证 | 多数事项不需要 | 先问受理方 |
| 写了全权代理 | 权限充分 | 笼统且可能被拒收 | 改分项式 |
| 写了长期有效 | 无期限问题 | 约定不明 | 写明起止日期 |
| 带了委托书 | 材料齐了 | 缺身份证原件与事项证明 | 按清单核对 |
| 被退件 | 全部重写 | 通常只差一两项 | 先问原因再改 |
| 办理公证 | 文书被背书全部内容 | 只证明签名印章与意思表示真实 | 不能替代权属证明与法律意见 |
| 涉外委托 | 走国内流程即可 | 还需认证与翻译 | 问目标国受理机构 |
| 涉诉委托 | 去办公证 | 有专门格式与要求 | 先问律师或立案庭 |
