# 委托书公证办理与要素核查（power-of-attorney-notarization）

委托书被退件，绝大多数不是文书格式问题，而是**要素缺失或权限写得没法执行**。

这个技能做三件事：**核六项要素** → **对材料清单** → **避开退件原因**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 逐项核查委托书要素是否齐全 | ❌ 代替公证机构受理或出具公证书 |
| 给出要素写法对照与修改建议 | ❌ 承诺「一定能办下来」「几天一定出证」 |
| 列出材料清单与办理流程 | ❌ 编造具体法条条款号与收费标准 |
| 说明公证与代理、涉外公证与认证的区别 | ❌ 提供规避公证的手段 |
| 提示常见退件原因与改正方法 | ❌ 代写需要本人签署意思表示的文件内容 |
| 给出要素参照 | ❌ 代替律师提供法律意见 |

**出现以下情况，先去咨询公证处或律师，不要照着模板改：**

- 涉及**诉讼代理**：诉讼委托书的格式与要求由法律规定并有专门格式，公证不是必经程序，先问律师或法院立案庭
- 涉及**涉外**：需要确认是「公证 + 认证」还是「仅公证」，以及目标国的具体要求，**必须问受理机构**
- 涉及**不动产权属、股权、婚姻家庭重大事项**：属地、主体资格、见证要求差异很大
- **委托人或受托人不能亲自到场**：可能需要公证员上门、公证处之间协助或视频见证，各机构做法不同
- 受托人是**境外人员或港澳台人员**：身份核验方式不同
- 涉及**遗产、监护、收养**：多数需要额外的见证或评估环节

**不要做的事：** 不要伪造签章、不要借用他人身份办理、不要在未告知的情况下代写本人意思表示的内容。公证的核心是**核验本人真实意思表示**，任何绕过本人真实意思的做法都可能导致公证书被撤销并带来更大麻烦。

## 二、委托书六项必备要素（核心）

**任何一份授权委托书，缺任何一项都可能被退件，或在后续争议中让受托人的行为失去授权依据。**

| # | 要素 | 必须写清什么 | 常见错误 |
|---|---|---|---|
| 1 | **委托人** | 姓名、性别、出生日期、身份证号、住址、联系电话 | 只写姓名不写身份证号，与产权/工商登记对不上 |
| 2 | **受托人** | 姓名、性别、出生日期、身份证号、住址、联系电话 | 只写「委托我公司」，无法定位责任主体 |
| 3 | **代理事项** | 做什么、在哪个范围、代表哪个标的 | 写成「办理一切事务」，过于笼统，可能不被采信 |
| 4 | **权限范围** | 具体授权到哪一步（见 §4 四种写法） | 笼统一句「全权代理」，对方以显失公平为由拒绝接收 |
| 5 | **有效期限** | 起止日期（YYYY 年 MM 月 DD 日） | 写「长期有效」，被视为约定不明；或过期未重委托 |
| 6 | **签名与捺印** | 委托人本人签名（不能代签）、按捺指印 | 由他人代签，或只有打印名 |

**补充要素（有则更稳）：**

- 委托原因/说明
- 受托人的权限转委托权（是否允许再委托）
- 争议解决方式
- 委托书份数与是否需要对方签收
- 附件清单（身份证复印件、产权证复印件等）

## 三、办理条件与材料清单

### 3.1 办理条件（一般情形）

| 条件 | 要求 |
|---|---|
| 主体资格 | 委托人具有完全民事行为能力；限制或无民事行为能力人需法定代理人办理 |
| 意思表示真实 | 委托人自愿、明确、无受胁迫或欺诈 |
| 内容合法 | 代理事项不违反法律法规强制性规定，不涉及国家禁止事项 |
| 材料齐全 | 身份证明与事项证明齐备 |
| 亲自到场 | 一般需委托人本人到场签署，无法代签 |
| 现场询问 | 公证员会就关键要素询问委托人，答不上来可能被拒绝 |

### 3.2 通用材料清单

| # | 材料 | 说明 | 是否必需 |
|---|---|---|---|
| 1 | 委托人身份证原件 | 公证处核验原件并留存复印件 | 必需 |
| 2 | 受托人身份证件 | 原件或复印件，视机构要求 | 一般必需 |
| 3 | 委托书正文 | 本人签署并捺印，一般现场书写 | 必需 |
| 4 | 代理事项的证明材料 | 产权证、营业执照、合同、诊断证明等 | **按事项定** |
| 5 | 委托人手写签名与指印 | 现场完成 | 必需 |
| 6 | 如委托他人代为提交 | 需额外的授权（代为送件授权） | 视情况 |

### 3.3 特殊事项追加材料

| 事项 | 追加材料 |
|---|---|
| 不动产相关 | 不动产权证或购房合同、身份证、户口本、结婚证（如涉及共有） |
| 股权/转让 | 营业执照、公司章程、股东会决议、股权证 |
| 诉讼 | 立案材料（一般走律师代理，不走公证） |
| 户籍/迁移 | 户口本、迁移事由证明 |
| 医疗/住院事务 | 住院证明、病情证明 |
| 房产交易 | 购房合同、定金收据、部分需要资金监管协议 |
| 涉外/港澳台 | 护照或通行证、目标国或港澳台地区的机构特殊要求 |
| 涉未成年或老人 | 监护证明、亲属关系证明、必要的见证材料 |

> 材料清单**以受理机构实际要求为准**。同一事项在不同机构、不同区县的要求可能有差异，**办之前先电话或线上确认清单**。

## 四、权限范围：四种写法对照（最容易被退的一环）

| 写法 | 示例 | 优点 | 风险 | 适用 |
|---|---|---|---|---|
| **概括式** | 「全权代理委托人办理上述事项」 | 简洁 | **过于笼统，易被对方以显失公平为由拒收；事后难主张已授权** | 不推荐单独使用 |
| **分项式** | 「代理权限：① 签署合同；② 办理过户；③ 领取证件」 | 边界清楚 | 事项多时容易漏项 | ✅ **推荐** |
| **权限清单式** | 附权限清单，逐项打勾，未勾选视为未授权 | 最严谨 | 手续繁琐 | 涉重大财产时推荐 |
| **排除式** | 「授权…，但不包括转让、设定抵押、变更登记」 | 明确禁区 | 需双方认可 | 有明确禁区时补充使用 |

**推荐写法结构（分项式 + 排除式组合）：**

```
委托权限：
1. 代为签署与本次事项相关的合同、协议及文件；
2. 代为办理本次事项涉及的手续、材料提交与领取；
3. 代为接收与本次事项相关的款项（仅限 ______ 元）；
4. 代为办理本次事项涉及的其他必要手续。

以下事项不在授权范围内（本委托书不授予）：
1. 转让、出租、出售上述标的；
2. 设定抵押、质押；
3. 办理与本事项无关的登记或变更；
4. 再委托第三人（除非另有书面约定）。
```

**关键要点：**

1. **代理事项必须具体到标的**。「代为办理房屋相关手续」不如「代为办理位于 ×× 路 ×× 号不动产的转移登记」。
2. **权限要与事项匹配**。办过户需要签字权，就不能只给「代为提交材料」的权限。
3. **「全权代理」不是万能的**。多数机构和相对方有权拒绝接收权限不明的文件。
4. **排除式条款要写进正文**，不要口头约定。

## 五、办理流程与时限

```
第 1 步  确认是否需要公证（多数事项不需要，见 §7）
第 2 步  联系受理机构，确认材料清单与特殊要求（可线上咨询）
第 3 步  准备材料，重点是代理事项的证明材料
第 4 步  委托人本人到场，出示身份证原件
第 5 步  现场书写或确认委托书内容（**建议现场手写，不要提前打印**）
第 6 步  签名 + 按捺指印
第 7 步  公证员询问关键要素（回答应与材料一致）
第 8 步  受理审核（形式审查 + 必要时的实质核实）
第 9 步  （如需）出具公证书或办理其他公证事项
第 10 步  领取公证书，核对内容与份数
```

**时限参照：**

| 环节 | 一般耗时 | 说明 |
|---|---|---|
| 材料齐全的简单事项 | 当日或数个工作日 | 各机构差异大 |
| 需核实的事项 | 若干个工作日 | 涉及权属核验、函证等 |
| 需见证/上门/视频见证 | 按预约安排 | 需提前预约，资源紧张 |
| 涉外公证 | 通常比国内事项更长 | 后续还可能需要认证 |

> 具体时限**以受理机构答复为准**，本表仅为流程预期参考，不构成承诺。

**建议：重要事项（如产权、股权、涉诉）至少预留 1–2 周**，并同时准备「无公证版本」作为备选，避免因时限耽误正事。

## 六、五类最常见退件原因与改正

| # | 退件原因 | 具体表现 | 改正办法 |
|---|---|---|---|
| 1 | **要素缺失** | 缺身份证号、缺联系方式、缺期限 | 按 §2 六项要素逐条补齐 |
| 2 | **权限笼统** | 「全权办理一切事务」 | 改成分项式，必要时加排除式条款 |
| 3 | **主体资格不符** | 限制行为能力人、已失能、代签 | 由法定代理人办理；本人确有困难先咨询上门见证 |
| 4 | **证明材料不足** | 委托事项对应的权属或关系证明缺失 | 先补齐事项证明（产权证、营业执照等） |
| 5 | **意思表示存疑** | 公证员询问时答非所问、表述矛盾 | 本人如实、明确回答；确有不适配的代理事项应取消 |

**次常见退件原因：**

- 笔误未涂改（应写「作废」重新写，而不是划改）
- 签名与身份证姓名不一致（含繁体/曾用名未说明）
- 日期格式混乱（统一用「YYYY 年 MM 月 DD 日」）
- 使用了模板但未删除不相关条款（如模板里的房产条款用在车辆事项上）
- 一页纸写不下却未分页，导致骑缝未处理
- 同时办理多个事项但只给了一份委托书（应分别出具或明确覆盖）

**被退件后的正确做法：** 先问清退件的具体原因，再改对应项，**不要重新抄一份完整的**——因为退件原因通常只在一两项上，全部重写可能引入新错误。

## 七、公证与代理的区别（最常混淆的一点）

| 维度 | 授权委托 | 公证 | 代理行为 |
|---|---|---|---|
| 是什么 | 一份**授权文书** | 对文书的**法律效力背书/核验** | 受托人**实际去做事** |
| 谁做 | 委托人签署 | 公证机构 | 受托人执行 |
| 作用 | 证明「我授权他做这件事」 | 增强文书可信度与证明力 | 产生实际法律效果 |
| 是否必须 | 多数事项必须 | **多数事项不是必须** | 受托人接受委托后应做 |
| 缺了会怎样 | 受托人无权代理 | 文书效力可能受影响 | 无法完成事项 |

**关键认知：** 委托书是**授权的依据**，公证是**对授权行为的证明**。**不是所有委托都需要公证**——是否必须，取决于：

1. 受理机构的具体要求（不动产登记、法院、涉外场景通常更严）
2. 相对方的要求（银行、券商、大型企业合同相对方常要求公证）
3. 事项的重要程度与潜在争议风险

> 不要把「要不要公证」当成默认前提。**先问受理方是否需要**，很多事项凭委托书原件加身份证明即可办理，公证只增加成本与时间。

## 八、涉外公证与领事认证的区别（最容易搞混的流程）

**三步流程：**

```
第 1 步  在中国公证处办理公证         （证明文书签名/印章真实）
第 2 步  到该国驻华使领馆办理认证     （证明中国公证处的效力）
第 3 步  在目标国使用时，可能还需当地追加手续（如海牙认证、翻译、公证）
```

**三个概念必须分清：**

| 概念 | 由谁做 | 做什么 | 说明 |
|---|---|---|---|
| **公证** | 中国公证机构 | 核验并证明签名、印章、事实的真实性 | 中国境内行为 |
| **领事认证** | 驻华使领馆 | 证明中国公证处的公证书有效 | 中国境内行为 |
| **海牙认证（附加证明书）** | 缔约国之间 | 公文跨境流通的形式认证 | 已在部分国家间实施，需确认目标国是否适用 |

**必须注意：**

1. **必须先确认目标国的具体要求**。不同国家、同一国家不同部门的要求可能不同，**必须向受理机构（目标国的单位）确认**。
2. **文件语言**：目标国通常不接受中文文书，需按要求翻译并由翻译机构签署声明或公证。
3. **部分国家不接受中国公证 + 领事认证**，而要求其他形式（如海牙认证）。
4. **使馆认证的办理时间不可控**，需预留充分时间，重要事项不建议把时间压到最低。

> **以目标国受理机构的具体要求为准**，不要凭经验套用他国流程。

## 九、办理前后的自查清单

### 9.1 办理前自查

- [ ] 已确认**是否真的需要公证**（问受理方，不要默认需要）
- [ ] 已确认**材料清单**（电话或线上咨询，不要凭经验）
- [ ] 委托人具备完全民事行为能力
- [ ] 代理事项**具体到标的和范围**
- [ ] 权限范围用**分项式**写清，不是「全权代理」一句
- [ ] 有效期限明确（起止日期）
- [ ] 代理人已确认**接受委托**（避免到场时被拒）
- [ ] 涉及事项的证明材料已备齐
- [ ] 特殊事项已确认额外要求（涉外、上门见证、视频见证）

### 9.2 办理中自查

- [ ] 出示的是**身份证原件**
- [ ] 委托书**现场手写**（不提前打印）
- [ ] **本人签名**，无他人代签
- [ ] **本人按捺指印**
- [ ] 公证员询问时**如实、明确**回答
- [ ] 有不适配的代理事项时**主动取消**，不要硬写

### 9.3 领取后自查

- [ ] 逐字核对公证书内容（姓名、身份证号、标的、期限）
- [ ] 确认**份数**足够（各方各一份）
- [ ] 确认**有效期**并登记到期提醒
- [ ] 受托人已收到公证书与委托书
- [ ] 办理**受托事项**时带上全部原件

## 十、脚本用法

```bash
python scripts/poa_check.py --file poa.txt --purpose 不动产转移登记
```

| 参数 | 说明 |
|---|---|
| `--file` | 委托书文本（草稿或已填内容） |
| `--purpose` | 代理事项关键词，如「不动产转移登记」「股权转让」「涉外」 |
| `--json` / `--out` | JSON 输出 / 写入指定报告文件 |
| `--selftest` | 跑内置自检（≥ 8 条断言） |

脚本做四件事：① 核六项必备要素是否齐全（委托人 / 受托人 / 代理事项 / 权限范围 / 有效期限 / 签名捺印）；② 识别「全权代理」「办理一切事务」这类笼统权限并给出改写建议；③ 核是否写明有效期限的具体日期；④ 按代理事项提示追加材料与额外注意事项。

> 脚本做的是**文本要素检查**，它无法判断内容是否真实、是否与实际相符，也不能替代公证员的面询。**最终能否受理由公证机构决定。**

## 十一、最常见的坑

**坑一：以为所有委托都要公证。**
多数事项凭委托书原件加身份证明即可。公证只在受理方明确要求时才需要。先问再办，能省时间与费用。

**坑二：权限写成「全权代理一切事务」。**
这既可能被受理机构拒收，也可能在后续争议中因「授权不明」而无法主张。**分项式写法才是可执行的授权。**

**坑三：代理事项写得太笼统。**
「代为办理房产相关手续」——办哪个房产、什么手续、办到哪一步，全都不明确。**必须具体到标的和环节。**

**坑四：没写有效期，或写「长期有效」。**
「长期有效」在实务中常被视为约定不明。一份过期未重签的委托书，等于没有委托。

**坑五：提前打印好委托书带去。**
多数公证处要求现场手写、现场签署。提前打印的容易被要求重写，白跑一趟。

**坑六：代理人没确认接受委托就去了公证处。**
公证完成后受托人拒不接受、或身份证信息不符，当场无法补，容易卡住。**先跟受托人对好。**

**坑七：被退件后整份重抄。**
退件原因通常只有一两项，盲目重写反而容易引入新的笔误与矛盾。**先问清具体原因，再改对应项。**

**坑八：把公证当成「万能背书」。**
公证证明的是**签名印章真实、意思表示真实**，不是证明事项本身的合法性或真实性。它不能替代权属证明，也不能替代法律意见。

**坑九：涉外委托书直接套国内流程。**
涉外场景除了公证，通常还需要领事认证或海牙认证，还可能需要翻译。**必须先问目标国的受理机构。**

**坑十：时间压得太紧。**
需要认证、核实、上门见证的事项耗时不可控，而正事的截止日期是硬的。**重要事项至少预留 1–2 周，并准备无公证版本的备选。**

**坑十一：涉及诉讼还去办公证。**
诉讼委托书有专门的法律要求和格式，通常由律师持律师证执业，不需要也一般不办委托公证。先问律师或立案窗口。

**坑十二：复印件当作原件提交。**
身份证、产权证等一般需核验原件。只带复印件是最常见的白跑一趟原因。
