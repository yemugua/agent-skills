# 泡沫灭火系统（foam-system）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据 GB 50151《泡沫灭火系统设计规范》，生成清单：系统选型（低/中/高倍数）、泡沫液类型与储量、比例混合器与管网、喷洒覆盖与供给强度、维护与定期检测。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 泡沫灭火
- 泡沫灭火系统
- 泡沫液
- 比例混合器
- 泡沫喷淋

## 三、工作流
1. 确定系统选型（低/中/高倍数）
2. 核对泡沫液类型与储量
3. 检查比例混合器与管网
4. 核实喷洒覆盖与供给强度
5. 做好维护与定期检测

## 四、核心内容（检查清单与判定）
GB 50151 规定泡沫灭火系统的选型、泡沫液储量、比例混合与供给强度；应确保覆盖可靠且泡沫液在有效期内。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含系统选型（低/中/高倍数） | 选型 |
| Q2 | FAIL | 未含泡沫液类型与储量 | 泡沫液 |
| Q3 | WARN | 未含比例混合器与管网 | 混合器 |
| Q4 | FAIL | 未含喷洒覆盖与供给强度 | 覆盖 |
| Q5 | WARN | 未含维护与定期检测 | 维护 |

> 脚本 `foam-system_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python foam-system_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python foam-system_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
