# 鱼塘增氧（鱼塘增氧 / fish-pond-aeration）

你会得到什么：一套家庭与小型鱼塘的增氧时机与设备配置方案——缺氧判断信号（浮头、水面聚集、吃食差）、溶氧阈值、按场景的增氧时机表（凌晨必开、高温午后开、投喂后开、阴雨提前开），增氧机类型（叶轮式/水车式/微孔/射流）与按面积密度配台数的口径、摆放覆盖死角与备电应急要求。技能内置 `pond_aeration_plan.py`，把方案写成 JSON 跑一遍，自动标出溶氧过低、有缺氧信号、无增氧机、类型非法、未覆盖凌晨、高密度台数不够等不合格项并附原因。

典型用法：鱼浮头了怎么办、增氧机什么时候开、叶轮式还是微孔、一天开多久、密度大了怎么配、阴雨天要不要提前开。写成字段交給脚本，立刻拿到「先处理 / 待确认 / 可照此执行」的结论。

边界：本技能只做增氧时机与设备配置口径，**不是水产兽医诊疗意见，也不提供任何鱼药或消毒剂剂量**。鱼翻肚皮、泛塘前兆、伴随病害请直接联系专业水产技术人员。
