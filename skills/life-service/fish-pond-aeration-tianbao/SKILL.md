# 鱼塘增氧（fish-pond-aeration）

鱼塘缺氧往往发生在**凌晨太阳出来前**——夜里植物不产氧反而耗氧，溶氧降到最低。鱼浮头就是最直接的警报。**增氧的关键是「提前开、重点时段开、高密度多配」**，等鱼翻肚皮再救往往来不及。

这个技能做三件事：**判缺氧 → 定时机 → 配设备**。

---

## 一、硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出缺氧信号与增氧时机口径 | ❌ 给出任何鱼药/消毒剂名称、剂量与疗程 |
| 给出增氧机类型与配置口径 | ❌ 判断鱼患什么病并开药 |
| 给出运行时长与摆放要求 | ❌ 指导大规模工业化养殖的工程排期 |
| 给出紧急应对与转交线 | ❌ 承诺任何成活或产量结果 |

**必须停止自行处理，联系水产技术人员/兽医的情况**

- 鱼已翻肚皮、侧浮、大量死亡
- 大面积浮头且开增氧机后不缓解
- 水质突变黑、发臭、泛塘前兆
- 伴随明显病害（烂鳃、出血、离群）

## 三、完整工作流

1. **看信号**：浮头、水面聚集、吃食差、游边张口——对照缺氧判断。
2. **测/估溶氧**：有溶氧仪看数值，无仪器看信号与时段。
3. **定时机**：凌晨必开、高温午后开、投喂后开、阴雨提前开。
4. **配设备**：按面积与密度选类型与台数，高密度多配。
5. **摆位置**：覆盖死角，不留静水区。
6. **排运行**：连续低氧时段不停机，备电源/备用水。
7. **做记录**：开机时段、天气、信号、鱼状态。
8. **核对**：用 `--file` 跑一遍，把漏开机、类型错、台数不够、未覆盖凌晨先排掉。
9. **应急**：出现翻肚皮/泛塘前兆，停手联系水产技术。

## 四、核心规则说明

**动手之前必须先读这两个文件，不要凭印象写：**

- `rules/缺氧判断与增氧时机.md` —— 缺氧信号、溶氧阈值、按场景的增氧时机表
- `rules/设备配置与运行.md` —— 设备类型、功率与台数口径、摆放与运行要求

要点三条：

1. **凌晨是生死线**。太阳出来前溶氧最低，这一时段必须保障增氧。
2. **高密度要加台数**。密度上去了还一台机，死角永远缺氧。
3. **阴雨提前开**。光照不足产氧少，等浮头再开就晚了。

## 五、脚本用法

```
python scripts/pond_aeration_plan.py --selftest
python scripts/pond_aeration_plan.py --file pond.json
```

输入字段：

| 字段 | 说明 | 示例 |
|---|---|---|
| pond_area_m2 | 塘面积平方米 | 200 |
| density_level | 放养密度 | 「高」「中」「低」 |
| do_value_mg | 溶氧毫克每升（可空） | 4 |
| symptoms | 缺氧信号列表 | 「鱼浮头」「水面聚集」 |
| aerator_type | 增氧机类型 | 「叶轮式」「微孔」「水车式」「射流式」 |
| aerator_count | 增氧机台数 | 2 |
| run_windows | 开机时段列表 | 「凌晨」「高温午后」「投喂后」 |
| placement_ok | 摆放是否覆盖死角 | true |
| emergency_ready | 是否有应急(备电/备水) | true |

结论分三档：**先处理**（溶氧过低、有缺氧信号、无增氧机、类型非法）、**待确认**（信息不足/配置偏弱）、**可照此执行**。存在真实缺陷时即使信息也不完整仍判先处理。

结果写入 `scripts/_last_result.txt`，每条不合格带原因。

## 六、人工确认清单（这步不能省）

- [ ] 已对照缺氧信号确认是不是缺氧，不是单纯水温不适
- [ ] 有溶氧仪最好，无仪器也按信号与时段判断
- [ ] 凌晨时段保障增氧，不靠白天补
- [ ] 阴雨、高温、投喂后这些重点时段都排了开机
- [ ] 增氧机类型与台数按面积密度配够，高密度多加
- [ ] 摆放覆盖死角，没有静水缺氧区
- [ ] 连续低氧时段不停机，有备用电源/备用水
- [ ] 出现翻肚皮/泛塘前兆已停手联系水产技术

## 七、最常见的坑

1. **只在白天开**。夜里凌晨才最缺氧，白天开没用。
2. **等浮头再开**。浮头已是缺氧中后段，再开常来不及。
3. **高密度一台机**。死角永远缺氧，鱼聚边上。
4. **阴雨不开**。光照不足产氧少，最该提前开。
5. **投喂后不增氧**。吃食耗氧大，饭后易缺氧。
6. **摆放留死角**。机器附近有浪、远处静水照样缺氧。
7. **没备用电源**。半夜跳闸，全塘缺氧。
8. **用错药当增氧**。缺氧先增氧，乱下药反而加重。
