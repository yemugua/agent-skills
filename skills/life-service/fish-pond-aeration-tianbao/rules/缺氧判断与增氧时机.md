# 缺氧判断与增氧时机口径

本文件是「鱼塘增氧」技能的核心资产。**开机器前先读这里确认是不是缺氧、什么时候开。** 数值为家庭与小型鱼塘通用参考，具体以品种、季节与本地条件为准。

## 1. 缺氧信号（命中即按缺氧处理）

- 鱼浮头：鱼群聚水面张口吞空气
- 水面聚集、游边、反应迟钝
- 吃食明显变差、抢食无力
- 清晨集中浮头、太阳出来才散

> 出现浮头即视为缺氧信号，先增氧再排查，不自行用药。

## 2. 溶氧阈值（参考）

| 溶氧 mg/L | 判断 |
|---|---|
| < 2 | 严重缺氧，立即增氧 |
| 2 - 3 | 偏低，需增氧 |
| 3 - 5 | 偏紧，重点时段开 |
| > 5 | 一般充足 |

无溶氧仪时以信号与时段判断，不唯数值。

## 3. 增氧时机表（按场景）

| 场景 | 时机 | 说明 |
|---|---|---|
| 凌晨 | 太阳出来前 1-2 小时开 | 一夜耗氧、溶氧最低，生死线 |
| 高温午后 | 14-16 点开 | 水温高、饱和低，易缺 |
| 投喂后 | 喂后 1-2 小时开 | 吃食耗氧大 |
| 阴雨/降温 | 提前开、连续开 | 光照不足产氧少 |
| 高密度 | 延长连续开机 | 负荷大，死角多 |
| 换水/用药前后 | 加强增氧 | 扰动与药应激耗氧 |

## 4. 禁忌（硬红线，碰到即判不合格）

- 鱼已浮头却不增氧、靠下药
- 增氧机类型不在已知类型内
- 未配置任何增氧机
- 涉及鱼药/消毒剂剂量（不在本技能范围）
