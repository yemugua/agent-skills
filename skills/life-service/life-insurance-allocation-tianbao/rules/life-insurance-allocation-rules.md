# 人身险家庭配置规则库

> 本规则库按家庭保障规划的常见实践整理。**各险种责任范围、免赔、等待期、给付条件与保额以保险合同条款为准**；**社保待遇以现行规定和社保部门口径为准**；保费预算占比为**参考区间，不是监管标准**。本库不推荐产品，不承诺理赔与收益，不劝诱退保。

---

## 一、四条顺序原则

### 1.1 原则一：先大人后小孩

| 顺序 | 对象 | 理由 |
|---|---|---|
| 第 1 顺位 | **家庭经济支柱**（收入占比最高者） | 出事后收入与负债同时受影响 |
| 第 2 顺位 | 其他收入来源成员 | 同样有收入中断风险 |
| 第 3 顺位 | 子女 | 保费低，但不承担家庭收入责任 |

**理由链**：大人是家庭收入的主要来源 → 大人没有保障，小孩的保障出了问题也无人承担费用 → 儿童保费低保额高，但优先级在家庭经济支柱之后。

**禁止**：因为孩子保费便宜就把它排到大人前面。

### 1.2 原则二：先保障后理财

| 类型 | 解决的问题 | 出险时 | 未出险时 |
|---|---|---|---|
| **保障型** | 出事后的**损失补偿** | 按约定给付保险金 | 通常退保损失较大（现金价值以合同载明的现金价值表为准） |
| **储蓄/理财型** | 现金流的长期安排 | 未必有高额保障 | 相对更接近本金累积 |

**必须说明**：**「理财型」不等于「高收益」，也不等于「一定更好」**。储蓄型产品同样有约定的给付口径与风险边界，**以合同条款为准**，**不得承诺收益**。

### 1.3 原则三：先足额保额后高额保额

```
总预算固定时：
  优先把保额补到「够用」的水平，而不是把保额加到「很高」但缺口仍在。
```

| 情形 | 判断 |
|---|---|
| 保额明显不足且年保费未到预算上限 | **先补保额** |
| 保额已达测算口径且仍有余钱 | 提高保额或补齐其他缺口 |
| 保额缺口与保费预算都到顶 | 接受当前水平，**不勉强加保** |

**保额不是越高越好，而是够不够**。给数字必须写明依据（收入、负债、支出、抚养年限）。

### 1.4 原则四：先核心成员后其他成员

按**收入贡献与责任占比**排序，不按年龄、性别或感情排序。**收入低但负债高的成员（如承担大量房贷者），可能排在收入更高的成员之前。**

## 二、四大险种分工

| 险种 | 解决的具体损失 | 给付方式 | 保额测算口径 |
|---|---|---|---|
| **重疾险** | 因合同约定疾病导致的**治疗费用损失 + 收入中断损失** | 确诊符合疾病定义后按约定给付一笔钱，**用途不限** | **3 到 5 年的家庭年收入**，或治疗自费部分 + 康复期收入损失 |
| **医疗险** | **超过医保报销范围的医疗费用** | 凭票据在免赔额以上按约定比例报销，**不是给一笔钱** | 关注**续保条件、免赔额、报销比例、医保外费用是否覆盖** |
| **意外险** | **意外事故导致的身故、伤残，以及意外医疗费用** | 身故/伤残按保额给付；意外医疗按约定报销 | 按**家庭负债与生活费延续需求**测算；意外医疗关注医保外费用 |
| **定期寿险** | **身故或全残导致家庭收入中断与负债无人偿还** | 身故或全残给付约定保额 | 见第五节公式 |
| **年金/储蓄型** | 长周期现金流的安排 | 按约定给付 | **不是「保额越高越保障」**，重点看现金流条款与约定口径 |

### 2.1 三大高频混淆

| 混淆 | 澄清 |
|---|---|
| 「医疗险能赔重疾的钱」 | **不能**。医疗险**报销型**，凭票据在免赔额以上按比例报；重疾险**给付型**，确诊符合定义即给付，**不凭票据** |
| 「有百万医疗就不用重疾险」 | 两者解决的不是同一个问题。医疗险解决**医疗费报销**，重疾险解决**收入中断与康复期支出**。断了收入，医疗费报再多也顶不上 |
| 「意外险便宜，买了就行」 | 意外险**只保意外导致的**。疾病导致的损失不在范围内，**必须有重疾险和医疗险配合** |

## 三、保额测算口径

```
重疾险保额参考 = 3 ~ 5 年家庭年收入
                或：合同约定疾病的治疗自费部分 + 康复期收入损失

意外险身故保额 = 家庭负债余额 + 家庭年支出 × 剩余抚养年限

定期寿险保额   = 家庭负债余额
             + 家庭年支出 × 剩余抚养年限
             − 已有寿险保额
             − 可变现资产
```

**必须说明**：保额测算结果是**参考口径，不是必须达到的门槛**。不得按「别人买多少我也买多少」给数字。

---

## 四、家庭年保费预算占比参考

```
年保费预算占比 = 家庭年保费合计 ÷ 家庭年收入
```

| 家庭状态 | 常见参考区间（口径参考，非承诺） |
|---|---|
| 单收入有房贷家庭 | 约 5% 到 10% |
| 双职工有子女家庭 | 约 8% 到 12% |
| 收入较低、负债较重家庭 | 应更低，**优先保额不优先全面覆盖** |
| 无社保或社保待遇不足 | 需额外考虑医疗与身故缺口 |

**三条必读**：

1. 这些是**常见参考区间，不是监管标准，也不是必须达到的比例**
2. **超过区间不代表更负责任，低于区间也不代表有缺口**——要结合保额缺口看
3. **判断标准是「缺口补齐了没有」，不是「保费花够了没有」**

## 五、定期寿险保额算例

| 项目 | 金额 |
|---|---|
| 房贷余额 | 120 万元 |
| 家庭年支出（房贷月供已含） | 24 万元/年 |
| 孩子剩余抚养年限 | 15 年 |
| 已有寿险保额（含单位团险折算） | 20 万元 |
| 可变现资产（存款、理财等） | 40 万元 |
| **测算结果** | 120 + 24 × 15 − 20 − 40 = **420 万元** |

**四条必读**：

1. **剩余抚养年限按最需要被抚养的人算**，通常取到子女经济独立
2. **已有寿险保额要包括单位团险与已购定期寿险**，避免重复计算
3. **可变现资产只算能较快变现的部分**，不能把长期锁定的资产全算进来
4. **测算结果是参考区间，不是销售目标**

## 六、社保与商业保险衔接

| 层次 | 谁报 | 说明 |
|---|---|---|
| 医保目录内费用 | 医保按目录与结算口径报销 | **报销比例、起付线、封顶线以现行规定和社保部门口径为准** |
| 医保目录外费用 | 医保不报或部分自付 | 由**商业医疗险**按合同约定报销，需确认合同是否覆盖医保外费用 |
| 大额住院与重疾后的收入中断 | 医保不覆盖 | 由**重疾险**给付一笔钱 |
| 意外身故与伤残 | 医保不覆盖 | 由**意外险**给付 |
| 身故后家庭负债与生活费 | 社保不覆盖 | 由**定期寿险**给付 |
| 身故保险金继承的税务处理 | 涉及税务事项 | **以现行规定和金融监管部门口径为准**，**不得包装成避税安排** |

**结论**：**「有社保就不用买商业险」是错的**。社保不解决收入中断，也不解决身故后的家庭经济问题。

## 七、已有保单重复与遗漏核查

| 核查项 | 说明 |
|---|---|
| 逐张清点 | 每个成员的重疾、医疗、意外、身故各有多少保额 |
| 单位团险 | **团体险的被保险人变更、离职即失效**，已有保额要算进去，但要知道它会消失 |
| 等待期衔接 | 上一张保单等待期未过、条款对某项责任有限制的，**已有保额不等于当下就生效** |
| 续保条件 | 医疗险的**续保条件**比年度免赔额更关键：不保证续保的产品可能需要时买不到 |
| 重复购 | 同一成员同险种多张保单时，核对各张的**责任范围与给付方式是否不同** |
| 缺口 | 保额为 0 的险种要单独列出，不因「有大人的了」而略过 |

## 八、优先级冲突时的取舍

| 冲突 | 取舍口径 |
|---|---|
| 预算只够买一张 | 先给**家庭经济支柱**买，优先**解决收入中断**的保障 |
| 大人保额与小孩保额二选一 | **先大人** |
| 保额不足与保费超预算 | **先保额**，可接受保额暂时偏薄，不勉强超预算 |
| 保障型与储蓄型二选一 | **先保障** |
| 某成员健康状况较差可能加费或除外 | 该成员优先级下调（**核保结论以保险公司实际结论为准**），预算转向其他成员 |

## 九、防误伤（否定词）清单

| 见到这些情况 | 必须这样判 | 严禁这样写 |
|---|---|---|
| 储蓄型产品 | 判为**有约定给付口径，非收益承诺** | 「理财型收益更高更划算」 |
| 医疗险 | 判为**报销型，凭票据，**有免赔门槛 | 「百万医疗能赔重疾的钱」 |
| 重疾险 | 判为**给付型，确诊符合定义给付，用途不限** | 「和医疗险一样要发票」 |
| 意外险 | 判为**只保意外导致的** | 「意外险什么都能赔」 |
| 单位团险 | 判为**已有保额，但离职可能失效** | 「有团险就不用买了」 |
| 等待期未过 | 判为**保障尚未生效** | 「已经生效了」 |
| 保费占比低于区间 | 判为**不等于有缺口，看保额缺口** | 「保费太低了不合格」 |
| 保费占比高于区间 | 判为**不等于更负责任** | 「保费花够了就达标」 |
| 未退保 | 判为**未退保** | 「已退保」 |
| 已退保 | 仅在解除完成且款项到账时成立 | 「已提交申请」 |
| 未如实告知 | 判为**可能导致不承担给付责任** | 「已如实告知」 |
| 社保待遇 | 判为**以现行规定和社保部门口径为准** | 凭记忆报报销比例 |

## 十、免责

本规则库为投保实践整理，**不构成保险代理、保险经纪、投资建议或法律意见**。**各险种责任、免赔、等待期、给付条件与保额以保险合同条款为准**；**社保待遇以现行规定和社保部门口径为准**；**保费预算占比为参考区间，不是监管标准**；保额测算基于用户填写的数据，**不承诺理赔、不承诺收益、不承诺回本**；不推荐具体产品，**不劝诱退保或更换产品**；涉及税务的问题**以现行规定和金融监管部门口径为准**。
