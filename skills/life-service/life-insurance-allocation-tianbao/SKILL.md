# 人身险配置顺序核查

家庭买保险最常见的两种错法：**给孩子买了一堆，大人没保额**；**先买了很多理财型的，保障额度还没补上**。

顺序错了，后面白花再多钱也补不回来。

这个技能做五件事：**定顺序 → 认分工 → 算缺口 → 定预算 → 核衔接**。

---

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 按四条顺序原则输出配置顺序与优先级 | 推荐具体保险公司、具体产品、具体计划书 |
| 说明各险种分别解决什么类型的损失 | 承诺理赔、承诺一定能赔多少 |
| 测算家庭保额缺口与年保费预算占比 | 替客户做最终投保决定 |
| 提示社保与商业保险的衔接关系 | 承诺社保报销比例或待遇金额 |
| 核对已有保单是否重复或遗漏 | 编造具体条款号、疾病定义编号与产品名 |
| 提示优先级冲突时的取舍原则 | 承诺收益、承诺回本、劝诱退保换产品 |

涉及以下情形，应停下来交由保险代理人、保险经纪或家庭法律顾问处理：**复杂家庭结构的保单重构、跨境保单、涉及税务的保险安排、已有纠纷或拒赔争议、明确拒保后的替代方案设计**。

**绝对不做**：不承诺收益、不承诺理赔、不劝诱退保。**各险种责任范围、免赔、等待期与保额以保险合同条款为准**；**社保待遇以现行规定和社保部门口径为准**。

| 用户说法 | 用不用 |

## 三、完整工作流

```
第 1 步  收集家庭结构：成员、年龄、收入、负债、已有保单、社保情况
第 2 步  读规则文件 rules/life-insurance-allocation-rules.md（顺序原则、
        险种分工、保额测算、预算占比、社保衔接、防误伤清单）
第 3 步  按四条顺序原则排优先级：先大人后小孩 → 先保障后理财 →
        先足额保额后高额保额 → 先家庭经济支柱后其他成员
第 4 步  逐人识别风险缺口：重疾（收入损失+治疗费）、医疗（超出自费部分）、
        意外（意外身故伤残+意外医疗）、身故（家庭负债与生活费延续）
第 5 步  跑脚本：scripts/allocation_budget.py --file case.json
第 6 步  算保额缺口：所需保额 − 已有保额 − 社保与单位可覆盖部分
第 7 步  算年保费预算：年保费 ÷ 家庭年收入，给出占比参考区间
第 8 步  核对社保与商业险衔接：哪些能报、哪些不报、哪些是自费
第 9 步  核对已有保单：是否重复、是否有缺口、是否有等待期未过
第 10 步 输出优先级清单与「这步不能省」的人工确认项，不给产品建议
```

## 四、四条顺序原则（必须写清）

### 4.1 原则一：先大人后小孩

```
原因：
  大人是家庭收入的主要来源。
  大人没有保障，小孩的保障出了问题也无人承担费用。
  儿童保费低、保额高，但优先级排在家庭经济支柱之后。
```

| 顺序 | 对象 | 理由 |
|---|---|---|
| 第 1 顺位 | **家庭经济支柱**（收入占比最高者） | 一旦出事，收入与负债同时受影响 |
| 第 2 顺位 | 其他收入来源成员 | 同样有收入中断风险 |
| 第 3 顺位 | 子女 | 保费低，但不承担家庭收入责任 |

**表述纪律**：**不能因为孩子保费便宜就把它排到大人前面**。预算有限时，**先保大人**。

### 4.2 原则二：先保障后理财

```
先买：解决「出事了钱从哪来」——重疾、医疗、意外、身故
后买：解决「钱怎么增值」——年金、增额终身寿等偏储蓄的形态
```

**关键区别**：

| 类型 | 解决的问题 | 出险时 | 未出险时 |
|---|---|---|---|
| **保障型** | 出事后的**损失补偿** | 按约定给付保险金 | 通常退保损失较大（现金价值以合同载明的现金价值表为准） |
| **储蓄/理财型** | 现金流的长期安排 | 未必有高额保障 | 相对更接近「本金累积」 |

**必须说明**：**「理财型」不等于「高收益」，也不等于「一定更好」**。储蓄型产品同样有约定的收益口径与风险边界，**以合同条款为准**，**不得承诺收益**。

### 4.3 原则三：先足额保额后高额保额

```
在总预算固定时：
  优先把保额补到「够用」的水平，而不是把保额加到「很高」但缺口仍在。
```

| 情形 | 判断 |
|---|---|
| 保额明显不足，年保费也没到预算上限 | **先补保额**，不要先追求保额倍数 |
| 保额已达到测算口径，仍有余钱 | 考虑提高保额或补齐其他缺口 |
| 保额缺口与保费预算都到顶 | 接受当前水平，**不勉强加保** |

**表述纪律**：**保额不是越高越好，而是够不够**。**必须说明保额测算口径与依据**（收入、负债、支出、抚养年限），不凭感觉报数字。

### 4.4 原则四：先核心成员后其他成员

在同一个家庭内，按**收入贡献与责任占比**排序，而不是按年龄、性别或感情排序。**收入低但负债高的人（如有大量房贷的家庭成员），也可能排在收入更高的人之前。**

## 五、四大险种各解决什么问题（必须分清）

| 险种 | 解决的具体损失 | 主要给付方式 | 保额测算口径 |
|---|---|---|---|
| **重疾险** | 因合同约定疾病导致的**治疗费用损失 + 收入中断损失** | 确诊符合疾病定义后按约定给付一笔钱，**用途不限** | 常用口径：**3 到 5 年的家庭年收入**，或覆盖治疗自费部分与康复期支出 |
| **医疗险** | **超过医保报销范围的医疗费用** | 凭票据在免赔额以上、按约定比例报销，**不是给一笔钱** | 关注**续保条件、免赔额、报销比例、医保外费用是否覆盖**；额度通常较高但有免赔门槛 |
| **意外险** | **意外事故导致的身故、伤残，以及意外医疗费用** | 意外身故/伤残按保额给付；意外医疗按约定报销 | 按**家庭负债与生活费延续需求**测算；意外医疗关注**意外导致的医保外费用** |
| **定期寿险** | **身故或全残导致家庭收入中断与负债无人偿还** | 身故或全残时给付约定保额 | 常用口径见第六节公式 |
| **年金/储蓄型** | 长周期现金流的安排 | 按约定给付 | **不是「保额越高越保障」，重点看现金流条款与约定口径** |

### 5.1 三大高频混淆（必须讲清）

| 混淆 | 澄清 |
|---|---|
| 「医疗险能赔重疾的钱」 | **不能**。医疗险是**报销型**，凭票据在免赔额以上按比例报；重疾险是**给付型**，确诊符合疾病定义即给付一笔钱，**不凭票据** |
| 「有百万医疗就不用重疾险」 | **两者解决的不是同一个问题**。百万医疗解决的是**医疗费报销**，重疾险解决的是**收入中断与康复期支出**。断了收入，医疗费报销再多也顶不上 |
| 「意外险便宜，买了就行」 | **意外险只保意外导致的**。疾病导致的损失不在意外险范围内，**必须有重疾险和医疗险配合** |

### 5.2 保额测算口径（必须写出依据）

```
重疾险保额参考 = 3 ~ 5 年家庭年收入
                或：合同约定疾病的治疗自费部分 + 康复期收入损失

医疗险        = 关注年度免赔额、报销比例、续保条件，而非「保额数字越大越好」

意外险身故保额 = 家庭负债余额 + 家庭年支出 × 剩余抚养年限

定期寿险保额   = 负债余额 + 家庭年支出 × 剩余抚养年限
                − 已有寿险保额 − 可变现资产
```

**必须说明**：**保额测算结果是参考口径，不是必须达到的门槛**。收入、负债、家庭责任不同，数字就不同。**不得凭「别人买多少我也买多少」给数字。**

### 5.3 家庭年保费预算占比参考

```
年保费预算占比 = 家庭年保费合计 ÷ 家庭年收入
```

| 家庭状态 | 常见参考区间（口径参考，非承诺） |
|---|---|
| 单收入有房贷家庭 | **约 5% 到 10%** |
| 双职工有子女家庭 | **约 8% 到 12%** |
| 收入较低、负债较重家庭 | **应更低**，优先保额不优先全面覆盖 |
| 无社保或社保待遇不足 | 需额外考虑医疗与身故缺口 |

**必须写清三条**：

1. **这些是常见参考区间，不是监管标准，也不是必须达到的比例**
2. **超过区间不代表更负责任，低于区间也不代表有缺口**——要结合保额缺口看
3. **判断标准是「缺口补齐了没有」，不是「保费花够了没有」**

## 六、定期寿险保额测算公式（可直接算）

```
定期寿险保额 = 家庭负债余额
             + 家庭年支出 × 剩余抚养年限
             − 已有寿险保额
             − 可变现资产
```

**算例**：

| 项目 | 金额 |
|---|---|
| 房贷余额 | 120 万元 |
| 家庭年支出（房贷月供已含） | 24 万元/年 |
| 孩子剩余抚养年限 | 15 年 |
| 已有寿险保额（含单位团险折算） | 20 万元 |
| 可变现资产（存款、理财等） | 40 万元 |
| **测算结果** | 120 + 24 × 15 − 20 − 40 = **420 万元** |

**必须写清的四条**：

1. **剩余抚养年限按最需要被抚养的人算，通常取到子女经济独立**
2. **已有寿险保额要包括单位团险与已购的定期寿险，避免重复计算**
3. **可变现资产只算能较快变现的部分**，不能把长期锁定的资产全算进来
4. **测算结果是参考区间，不是销售目标**；最终以家庭实际情况与合同条款为准

## 七、社保与商业保险的衔接

| 层次 | 谁报 | 说明 |
|---|---|---|
| 医保目录内费用 | 医保按目录与结算口径报销 | **报销比例、起付线、封顶线以现行规定和社保部门口径为准** |
| 医保目录外费用（部分药品、器材、特殊治疗） | 医保不报或部分自付 | **由商业医疗险按合同约定报销**，需确认合同是否覆盖医保外费用 |
| 大额住院与重疾后的收入中断 | 医保不覆盖 | **由重疾险给付一笔钱** |
| 意外身故与伤残 | 医保不覆盖 | **由意外险给付** |
| 身故后家庭负债与生活费 | 社保不覆盖 | **由定期寿险给付** |
| 身故保险金继承的税务处理 | 涉及税务事项 | **涉及税收的问题以现行规定和金融监管部门口径为准**，**不得包装成避税安排** |

**必须说明**：**「有社保就不用买商业险」是错的**。社保解决的是医疗费报销的一部分，不解决收入中断、也不解决身故后的家庭经济问题。

## 九、脚本用法

```bash
python scripts/allocation_budget.py --file case.json --out 家庭保险配置测算.md
python scripts/allocation_budget.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：家庭成员列表（年龄、收入、是否家庭支柱、已有各险种保额）、家庭负债、家庭年支出、剩余抚养年限、可变现资产 |
| `--text` | 直接给 JSON 字符串 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检 |

输入 JSON 示例：

```json
{
  "family_income": 400000,
  "debt": 1200000,
  "annual_expense": 240000,
  "support_years": 15,
  "liquid_assets": 400000,
  "members": [
    {"name": "A", "age": 38, "income": 280000, "breadwinner": true,
     "existing": {"critical": 300000, "medical": 0, "accident": 500000, "term_life": 200000}},
    {"name": "B", "age": 36, "income": 120000, "breadwinner": false,
     "existing": {"critical": 0, "medical": 0, "accident": 0, "term_life": 0}},
    {"name": "C", "age": 8, "income": 0, "breadwinner": false,
     "existing": {"critical": 0, "medical": 0, "accident": 0, "term_life": 0}}
  ],
  "annual_premium_plan": {"A": 9600, "B": 2400, "C": 1200}
}
```

脚本输出：按四条顺序原则排出的优先级、每位成员的保额缺口（重疾按 3 到 5 年收入、医疗按免赔与报销口径提示、意外与寿险按负债与支出口径）、家庭年保费合计与占年收入比、社保衔接提示、以及必须人工确认的事项清单。

## 十、人工确认清单（这步不能省）

- [ ] 家庭成员、年龄、收入**逐人核对**，没有漏人
- [ ] 已有保单**逐张清点**（含单位团险），确认每人的重疾、医疗、意外、身故各有多少保额
- [ ] 家庭负债**取当前余额**，不是原始贷款金额
- [ ] 家庭年支出口径明确（是否含房贷月供，是否含学费）
- [ ] 剩余抚养年限按**子女经济独立**估算，并写明依据
- [ ] 可变现资产只算了**能较快变现**的部分
- [ ] 优先顺序里**大人排在小孩前面**，没有因为保费便宜把小孩提前
- [ ] 保障型与储蓄型**分开记录**，没有把储蓄型当成高收益
- [ ] 医疗险已核对**续保条件、免赔额、报销比例、医保外费用是否覆盖**
- [ ] 社保待遇查询的是**现行**口径，不是几年前的记忆
- [ ] 结论里**没有出现「保证收益」「一定能赔」**这类表述

## 十一、最常见的坑

1. **给孩子买了一堆，大人裸奔。** 大人是家庭收入来源，大人出事，房贷、学费、日常开支全部断供，而孩子买再多保额也没人付保费。**顺序错了，后面补不回来。**
2. **先买理财型，保障额度没补。** 储蓄型产品解决不了「出事那天钱从哪来」。**先保障后理财**不是口号，是顺序问题。
3. **把百万医疗当重疾险用。** 医疗险是**报销型**，凭票据报；重疾险是**给付型**，确诊符合定义就给钱，**不凭票据**。断了收入，医疗费报销顶不上。
4. **保额缺口很大，却去追求高保额倍数。** 预算有限时，**先把保额补到够用**，再考虑加高。
5. **把储蓄型产品当成「理财收益更高所以更好」。** 储蓄型有约定的给付口径，**不是收益承诺**；而且它的退保损失与流动性同样存在。**以合同条款为准，不承诺收益。**
6. **单位有团险就以为不需要商业险。** 团险保额通常有限，且**团体险的被保险人变更、离职即失效**。已有保额要算进去，但要知道它是**会消失的**。
7. **保额数字凭感觉报。** 保额要按**收入、负债、支出、抚养年限**算出来，并写明依据。**不得按「别人买多少我也买多少」给数字。**
8. **以为有社保就不用买商业险。** 社保解决的是医保目录内费用报销的一部分，不解决收入中断，也不解决身故后的负债与生活费。**「有社保就不用买」是错的。**
9. **不核续保条件。** 医疗险的**续保条件**比年度免赔额更关键：不保证续保的产品，可能在需要的时候买不到。
10. **忽略等待期与既往症的衔接。** 上一张保单的等待期还没过、或者上一张保单的条款对某项责任有限制，**已有保额不等于当下就生效**。必须核对**当前是否已过等待期**。
11. **把「保费占比参考区间」当成达标线。** 区间是参考，不是标准。**判断标准是缺口补齐了没有，不是保费花够了没有。**
12. **算保额时把长期锁定的资产算进可变现资产。** 买了不能动的长期资产顶不了近期的房贷月供。

## 十二、边界与免责

- 本技能用于家庭保障缺口测算与配置顺序梳理，**不构成保险代理、保险经纪、投资建议或法律意见**
- **各险种责任范围、免赔、等待期、给付条件与保额以保险合同条款为准**；不同产品差异很大，不得互相套用
- **社保待遇以现行规定和社保部门口径为准**；不承诺报销比例与待遇金额
- 保额测算与保费预算占比为**参考口径，不是监管标准，也不是必须达到的门槛**；测算结果基于你填的数据，最终以家庭实际情况为准
- **不承诺理赔、不承诺收益、不承诺回本**；不推荐具体保险公司、具体产品与具体计划书
- **不劝诱退保，也不劝诱加保或更换产品**；涉及税务的问题**以现行规定和金融监管部门口径为准**，不提供避税安排
- 中途退保损失**以合同载明的现金价值表为准**；犹豫期天数**以合同约定为准**
