# 防护用品规则库（ppe_rules）

> 本文件是 ppe-management 技能的规则支撑。配备要求以现行规定为准。

## 一、法规依据速查

| 文件 | 关键要求 | 关联 |
|---|---|---|
| 《用人单位劳动防护用品管理规范》 | 选型、采购、发放、培训、更换、报废 | 管理义务来源 |
| GB/T 11651《个体防护装备选用规范》 | 按危害选型 | 选型依据 |
| 产品标准 + LA 标志 | 特种防护用品生产许可 | 采购依据 |

## 二、选型判定口径

| 危害 | 用品 | 匹配要点 |
|---|---|---|
| 粉尘 | 防尘口罩 | 按颗粒物等级 |
| 噪声 | 耳塞/耳罩 | 按降噪值 |
| 化学 | 防化手套/眼镜/服 | 按化学品类型 |
| 冲击 | 安全帽/眼镜/鞋 | 按冲击等级 |
| 高处 | 安全带 | 挂点合规 |
| 触电 | 绝缘手套/鞋 | 耐压等级 |

## 三、采购验收口径

- 查验生产许可证、合格证、LA 标志
- 核对规格型号数量
- 必要时抽检
- 入库建账、离地离墙、先进先出

## 四、发放与培训口径

| 项目 | 判定 |
|---|---|
| 岗位-用品对应表 | 缺 FAIL |
| 发放记录签字 | 缺 WARN |
| 佩戴培训 | 缺 WARN |
| 使用检查记录 | 缺 WARN |

## 五、更换报废口径

- 按周期强制更换（按使用强度）
- 损坏即换、旧品回收
| 岗位调整重新选型 |
| 污染/失效集中处置、禁止回流 |

## 六、常见不合规情形

- 补贴代替配备
- 等级不匹配
- 无培训无检查
- 报废品回流
- 账物不符
