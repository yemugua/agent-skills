# 劳动防护用品配备与管理（ppe-management）

防护用品是**最后一道防线**：工程控制能上的都上了，剩下的风险靠它兜底。管不好就是"配了不戴、戴了不对、换了不记"。

这个技能做四件事：**按岗选型** → **采购验收** → **发放记录** → **更换报废**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 讲解选型配备与管理方法 | ❌ 替代法定配备要求 |
| 生成配备标准表与台账 | ❌ 保证防护效果 |
| 整理更换与报废口径 | ❌ 替代产品标准符合性判定 |

**不得以发放防护用品替代工程控制措施**——能通风、能隔离、能降噪的，先做工程手段。

**永远不要**用实物、补贴替代应有的防护配备；也不得采购无生产许可、无合格证明的产品。

## 二、完整工作流

```
第 1 步  明确场景：建立配备标准 / 采购验收 / 发放台账 / 更换报废
第 2 步  读规则文件 rules/ppe_rules.md
第 3 步  按场景取用：
    - 按岗选型 → 选型原则（第三节）
    - 采购验收 → 验收要点（第四节）
    - 发放记录 → 台账要素（第五节）
    - 更换报废 → 周期与处置（第六节）
    - 体检表 → python scripts/ppe_check.py --file 防护台账.json
第 4 步  按 templates/防护用品台账.md 输出
第 5 步  人工确认：岗位危害辨识、使用合规、账物一致
```

## 三、按岗位选型原则

| 危害类型 | 常见防护用品 |
|---|---|
| 粉尘 | 防尘口罩（按颗粒物等级选择） |
| 噪声 | 耳塞/耳罩（按降噪值匹配场所） |
| 化学飞溅/毒物 | 防化眼镜、面罩、防化手套、防护服 |
| 冲击/飞屑 | 安全帽、防护眼镜、防砸鞋 |
| 高处作业 | 安全带（挂点合规）、安全绳 |
| 触电 | 绝缘手套（耐压等级匹配）、绝缘鞋 |
| 焊接 | 焊接面罩、阻燃手套、围裙 |
| 高温/辐射 | 隔热服、防辐射用品 |

> 选型依据 GB/T 11651《个体防护装备选用规范》及产品标准；**防护等级必须匹配岗位危害水平**（不是越贵越好）。

---

## 四、采购与验收

- **采购**：查验生产许可证、产品合格证、LA 标志（特种防护用品）
- **验收**：核对规格型号、数量、质量证明；必要时抽检
- **入库**：建账登记，离地离墙存放，先进先出
- **台账**：入库日期、数量、单价、供方、验收人

---

## 五、发放与台账

| 台账要素 | 说明 |
|---|---|
| 岗位-用品对应表 | 每个岗位配什么、配多少、什么周期 |
| 发放记录 | 领用人、日期、数量、型号、发放人签字 |
| 培训记录 | 佩戴方法、检查方法、更换信号 |
| 检查记录 | 定期检查使用情况（戴没戴、戴得对不对） |

> **发放不是终点**：没有培训和检查的发放，等于没管。

---

## 六、更换与报废

| 情形 | 处置 |
|---|---|
| 到期更换 | 按周期强制更换（口罩、耳塞等按使用强度） |
| 损坏/失效 | 即坏即换，旧品回收 |
| 危害变化 | 岗位调整时重新选型 |
| 报废 | 污染/失效品集中处置，不得回流使用 |

---

## 七、脚本用法（台账体检）

```bash
python scripts/ppe_check.py --file "D:\EHS\防护台账.json"
```

脚本检查四类问题：**岗位-用品不匹配、发放超期、无培训检查记录、报废品未处置**。

> ⚠️ 脚本只做结构与逻辑检查，**不判定防护效果**。

---

## 八、人工确认（这步不能省）

- [ ] 岗位危害辨识是否覆盖全部作业（含仓管、维修、清洁）
- [ ] 防护等级是否匹配危害水平
- [ ] 特种防护用品 LA 标志是否可查
- [ ] 培训是否覆盖正确佩戴与更换信号
- [ ] 现场检查是否发现"配了不戴"
- [ ] 账物是否一致

---

## 九、输出结构（固定三段）

1. **配备状态**——结论先行：标准齐全 / 有缺口 / 有红线问题
2. **核对清单**——选型、采购、发放、培训、更换逐项
3. **整改与补资料建议**——先后顺序、责任岗位、留存材料

---

## 十、最常见的坑

**坑一：拿补贴代替配备。** 发了钱没买品，检查时两头不占理。

**坑二：等级不匹配。** 噪声 100dB 的岗位配普通耳塞，降噪值根本不够。

**坑三：口罩当"形象工程"。** 工人戴海绵口罩防粉尘，等于没防。

**坑四：发了不教。** 滤毒盒到期没人知道，员工戴着失活的防护具。

**坑五：报废品回流。** 破安全绳剪断又接上用，事故就差这一根。

---

## 十一、边界与免责

- 本技能**不替代**法定配备要求；配备标准**以现行法规和 GB/T 11651 等标准为准**
- 不得以发放防护用品替代工程控制措施
- 规程要点为管理实践方法论整理，**不构成执法结论**
