# 消防技术服务机构从业条件核查（fire-tech-agency-check）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《消防技术服务机构从业条件》（应急〔2019〕88号）与《社会消防技术服务管理规定》（应急管理部7号令），核对机构/人员资质与执业合规。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 消防技术服务机构
- 从业条件
- 维保公司资质
- 检测机构条件
- 注册消防工程师人数

## 三、工作流
1. 核对企业法人与营业执照范围
2. 注册消防工程师人数（≥2，一级≥？）与社保
3. 职业技术负责人资格
4. 执业需签署盖章并公示系统
5. 服务项目与合同一致性

## 四、核心内容（检查清单与判定）
应急〔2019〕88号：从事消防设施维护保养检测的机构需取得资质，注册消防工程师不少于2人（其中一级不少于？视服务范围）；7号令要求服务合同、过程、结论在系统录入。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未核营业执照与执业范围 | 88号文 |
| Q2 | FAIL | 注册消防工程师人数不足 | 88号文 |
| Q3 | WARN | 技术负责人资格未列明 | 人员 |
| Q4 | FAIL | 维保/检测报告未系统录入与签章 | 7号令 |
| Q5 | WARN | 未核对人员社保（防止挂靠） | 挂靠 |

> 脚本 `fire-tech-agency-check_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python fire-tech-agency-check_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python fire-tech-agency-check_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
