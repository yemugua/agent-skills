# 消防演练评估（fire-drill-evaluation）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《消防法》与《机关团体企业事业单位消防安全管理规定》（公安部61号令），生成消防演练评估清单：演练计划/方案、演练类型（综合/专项/桌面）、参与与记录、评估复盘、问题整改闭环。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 消防演练评估
- 演练效果评估
- 应急演练总结
- 演练复盘
- 消防演练方案

## 三、工作流
1. 制定演练计划与方案（目标/情景/脚本）
2. 明确演练类型（综合/专项/桌面推演）
3. 组织参演与过程记录
4. 演练后评估（目标达成度/不足）
5. 问题整改与闭环验证

## 四、核心内容（检查清单与判定）
公安部61号令要求消防安全重点单位每半年进行一次灭火和应急疏散演练；演练应评估效果并针对问题整改，形成闭环记录。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含演练计划/方案（目标/情景/脚本） | 计划方案 |
| Q2 | WARN | 未明确演练类型（综合/专项/桌面推演） | 类型 |
| Q3 | FAIL | 未含参演组织与过程记录 | 记录 |
| Q4 | FAIL | 未含演练后评估复盘报告 | 评估 |
| Q5 | WARN | 未含问题整改闭环 | 闭环 |

> 脚本 `fire-drill-evaluation_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python fire-drill-evaluation_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python fire-drill-evaluation_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
