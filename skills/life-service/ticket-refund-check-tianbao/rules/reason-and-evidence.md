# 退改原因定性、证明材料与到账追踪

## 一、原因分类（决定能不能全退）

### 不可归责于旅客 —— 应全额退或不由你承担退票费

| 类型 | 典型表述 | 依据 |
|---|---|---|
| 承运人取消 | 航班取消、停飞、车次停运 | 承运人自身原因 |
| 天气与流控 | 台风、暴雨、冰雪、雷雨、大面积流控 | 不可抗力 |
| 机型/座位调整 | 换机型、舱位调整、座位减少 | 承运人调整 |
| 航班合并/中转调整 | 代码共享、合并航班、航线调整 | 承运人调整 |
| 票务差错 | 出票错误、重复出票、系统出票有误 | 承运人差错 |

> 沟通时的表述很重要：**说清"是谁的原因导致我无法成行"**，而不是"我有事去不了"。

### 可能按非旅客原因处理 —— 要靠证明

| 类型 | 需要准备的材料 |
|---|---|
| 生病、受伤、住院 | 医院诊断证明、住院病历、出院小结 |
| 直系亲属丧事 | 死亡证明、户口簿等亲属关系证明 |
| 单位原因 | 单位开具的证明（写明因公无法成行） |
| 学校学业 | 学校开具的证明或统一安排通知 |
| 不可抗力 | 官方公告、气象预警、承运人通知截图 |

> **是否减免由承运方/车站认定**，不是交了材料就一定免。但有材料总比空口主张强。

### 旅客个人原因 —— 按阶梯扣费

行程冲突、买错票、单纯不想去、临时有事但无证明。这类没有"讲情面"的空间，唯一优化是**改签而不是退票**。

## 二、证据清单（六类）

| 类别 | 具体材料 | 怎么取得 |
|---|---|---|
| **购票凭证** | 电子客票、行程单、订单 PDF、支付记录 | App 或邮箱导出，截图含订单号 |
| **退改申请记录** | 申请页面截图、工单号、受理编号 | 提交后立即截图 |
| **费用凭证** | 手续费扣费短信、账单明细、退款流水 | 银行/支付账单 |
| **承运方答复** | 客服答复截图、通话录音（合法留存、仅用于本人主张） | 提交工单后保存 |
| **原因证明** | 病历、诊断证明、死亡证明、单位/学校证明 | 就医时同步开好 |
| **不可抗力证明** | 官方取消公告、延误通知、天气预警 | 官方渠道截图 |

## 三、到账追踪

| 环节 | 正常周期 | 超期怎么办 |
|---|---|---|
| 提交申请 | 即时 | 自助渠道无工单号时改走人工 |
| 受理处理 | 铁路/民航常见 1~7 个工作日 | 用工单号催办 |
| **退款到账** | **原路退回，3~7 个工作日** | 超期未到账 → 工单号催办 → 12315/12345 |
| 保险与附加费 | 通常不随票退 | 需单独向承运方或保险公司主张 |

**追踪要点**：
- 记录每一笔扣款与退款的日期与金额，截图留证。
- 超过承诺周期没到账，**先用工单号催办并保留催办记录**，再去投诉渠道。
- 投诉时把"订单号 + 工单号 + 扣费记录 + 答复截图"一次备齐，避免因材料不全被退回。

## 四、话术

**开场（先定性）**
> "我要退票。我的情况是【承运人取消/天气原因/本人因病】，请确认这属于哪一类原因，以及对应的手续费是多少。"

**被按个人原因扣费时**
> "我提交了【病历/单位证明】，请按非旅客原因重新核对我这单。如果确实不能免，请给我一份书面说明，写明依据的具体条款。"

**催办到账**
> "我在【日期】提交的退票，工单号【XXX】，约定【日期】前到账，现在还没收到。麻烦查一下处理进度并给我明确到账时间。"

**投诉材料开头**
> "本人于【日期】通过【渠道】办理退票，工单号【XXX】，承运方于【日期】以【理由】扣收手续费【金额】。本人提交的【证明材料名称】未被采纳。现要求：①说明该扣费的具体依据条款；②重新按非旅客原因核办；③退还多收的手续费。"
