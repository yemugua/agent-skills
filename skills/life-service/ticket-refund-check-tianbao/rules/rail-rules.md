# 铁路退改签规则

> 通用口径，**具体以 12306 现行规定与车站实际执行为准**。规则会调整，办理前建议在 12306 App 或官网核对当班规则。

## 一、退票费阶梯（按距票面发车时间）

| 距发车时间 | 退票费 | 说明 |
|---|---|---|
| 开车前 **8 天以上（含 8 天）** | **不收** | 此时退票最划算 |
| 开车前 **48 小时 ~ 8 天** | 票面 **5%** | |
| 开车前 **24 小时 ~ 48 小时** | 票面 **10%** | |
| 开车前 **不足 24 小时** | 票面 **20%** | 最贵的一档 |
| **开车后（含已发车）** | 不退票 | 只能按规定改签 |

- 手续费以**票面金额**为基数计算，不是以实付金额。
- 预售期通常为 15 天，**超出预售期的车次无法办理**。

## 二、哪些情形一律不退

| 情形 | 说明 |
|---|---|
| **开车后** | 已发车不再受理退票 |
| **已检票** | 一般不予退票；当日可在车站按规定办理改签 |
| **站台票 / 购票凭证** | 已办理的站台票不办理退票 |
| **其他证件生成的临时车票** | 需按车站规定处理 |
| **误火车**（错开车次） | 开车前可按退票处理；开车后只能改签当日其他车次 |

## 三、改签规则

- **开车前**：可通过 12306 办理改签，**通常不收手续费**（差价多退少补）。
- **开车后**：可改签至**当日其他列车**（，具体以系统提示为准）。
- **限次**：改签次数有上限，超出后只能退票。
- **预售期外**：无法改签。
- **卧铺/，动卧席位等特殊铺别**：改签规则可能不同，以系统为准。

## 四、什么情况可以不算自己责任

- **不可抗力**（台风、暴雨、冰雪等导致停运）：可全额退，不收手续费。
- **列车停运 / 开车前无法成行**：按铁路部门公告办理全额退。
- **生病、直系亲属丧事**：可尝试提交**医院证明、死亡证明**等材料，按非旅客原因申请处理；**是否减免由车站认定**，先问清楚需要什么材料。

## 五、办理渠道与到账

| 渠道 | 适用 | 注意 |
|---|---|---|
| **12306 App 自助** | 绝大多数情况 | 最快，**先试自助** |
| **12306 客服 / 车站窗口** | 特殊情形、需提交证明 | 带身份证与购票凭证，**要工单号或受理编号** |
| **铁路 12306 客服中心** | 投诉与争议 | 附工单号与书面答复 |

- 退款**原路退回**，常见到账周期 **3~7 个工作日**。
- 已取纸质票的，需按要求交回或留存票根。

## 六、争议处理顺序

1. 12306 App 自助 → 2. 12306 人工客服（要工单号）→ 3. **12345 政务热线** → 4. **12315 消费投诉** → 5. 铁路主管部门渠道

每一级都附上：工单号、书面答复、订单与扣费凭证。
