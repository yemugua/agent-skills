# 民航退票与航班异常规则

> 通用口径，**具体以承运人公布的现行规则为准**。同一航司不同票价产品（特价、灵活、经济舱等）规则差别很大，买票时的"退改签条件"栏就是最准的依据。

## 一、退票费阶梯（国内客票常见口径）

| 距起飞时间 | 退票费 | 说明 |
|---|---|---|
| 起飞前 **7 天以上（含 7 天）** | **不收** | 此时退票最划算 |
| 起飞前 **48 小时 ~ 7 天** | 票面 **10%** | |
| 起飞前 **24 小时 ~ 48 小时** | 票面 **20%** | |
| 起飞前 **不足 24 小时** | 票面 **30%** | 最贵的一档 |

- 部分航司按**票价档**分级收取（如按 8000 元以上、5000~8000 元等档位对应不同比例），**买票时的退改签条款优先**。
- 退票费通常以**票面金额**为基数；实付含服务费/保险时，口径可能不同。
- **已值机/已打印登机牌**可能影响办理，**越早处理越有利**。

## 二、航班异常时的正确做法（最关键）

| 情形 | 你应该拿到的 |
|---|---|
| **航班取消** | **全额退款**或**免费改签**到承运人安排的其他航班 |
| **航班延误** | 延误/free改签按承运人规则；**非承运人原因（如天气、流控）导致的取消通常必须全额退** |
| **机型/座位调整** | 可要求免费改签或退票 |
| **合并航班 / 代码共享调整** | 要求免费改签或退票 |
| **出票错误、系统重复出票** | 属于承运人差错，应全额退 |

**关键动作**：
1. **先看航班状态**（App 或短信通知），截图保存官方取消/延误公告。
2. **第一时间联系承运人**，明确主张"这是非旅客原因，要求全额退款或免费改签"。
3. **不要先在 App 上点退票**——一旦按个人原因退掉，手续费就扣掉了，再争取原价很难。

## 三、航班延误能不能要赔偿

- **单纯的延误本身**通常不产生赔偿义务（没有约定时）。
- 但**因承运人原因取消**导致的损失、以及合同或会员权益中承诺的补偿，可依合同与承运人规则主张。
- 常见可主张的项目：退票费、错程住宿与交通（有票据时）、里程/优惠券补偿（按会员或活动规则）。
- **具体标准以承运人规则与合同约定为准**，不要按"延误就该赔钱"的直觉索赔。

## 四、办理渠道与到账

| 渠道 | 适用 |
|---|---|
| **航司 App / 小程序自助** | 绝大多数情况，最快 |
| **航司客服热线** | 特殊情形、需人工处理，**要工单号** |
| **票台/柜台** | 需提交证明材料的情形 |

- 退款**原路退回**，常见到账周期 **3~7 个工作日**。
- 通过第三方平台购票的，**先找平台还是先找航司**要看平台规则；平台与航司互相推诿时，用订单号同时向两边要工单号。

## 五、争议处理顺序

1. 航司自助渠道 → 2. 航司人工客服（要工单号）→ 3. **12315 消费投诉** → 4. 民航主管部门渠道（**以当地主管部门公布的渠道为准**）→ 5. 12345 政务热线

材料清单：订单与支付记录、航班状态截图或官方公告、申请记录、工单号、退款流水、航司答复。
