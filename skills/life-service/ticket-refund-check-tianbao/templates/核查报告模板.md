# 交通票务退改签核查报告模板

> 报告由 `scripts/rail_air_refund_check.py` 自动生成。此模板供人工复核时对照。

## 报告结构（10 段）

| 段 | 标题 | 回答什么问题 |
|---|---|---|
| 一 | 结论摘要 | 能退多少、扣多少、该退还是该改 |
| 二 | 票种与可退性定性 | 铁路还是民航、距发车多久、能不能退 |
| 三 | 退改原因定性 | 是承运方原因还是个人原因、要不要举证 |
| 四 | 退票手续费测算 | 落在哪一档、手续费多少、可退多少、算式 |
| 五 | 办理流程与到账 | 申请了没、有工单号没、钱到账没 |
| 六 | 投诉与申诉阶梯 | 四级渠道走了哪几级 |
| 七 | 证据清单与缺口 | 六类证据齐不齐 |
| 八 | 退改路径排序 | 第 1 步到第 6 步怎么走 |
| 九 | 证据缺口速查 | 每个缺口怎么补 |
| 十 | 待办补正动作 | 可直接照着做的动作 |
| — | 边界与纪律 | 免责与口径说明 |

## 四态判定口径

| 状态 | 含义 | 处理方式 |
|---|---|---|
| **通过** | 条件满足、无隐患 | 无需动作 |
| **有风险** | 可办但有代价或隐患 | 按说明提前处理 |
| **不通过** | 已过时间点、已检票、未提交等硬障碍 | 必须先解决 |
| **待补正** | 信息未填或填了无法判断 | **未填一律不算通过** |

## 复核要点

1. **出发/起飞日期**是否准确（直接决定退费档位）
2. **距出发时长**是否落在正确区间（8 天/48 小时/24 小时三道线）
3. **手续费基数**用的是票面金额还是实付金额（保险会让两者不同）
4. **退改原因**是否属于可主张非旅客原因的情形
5. 报告里所有"不通过"项在第八段路径里是否都有对应动作
6. 金额是否标注为**预估**（必须以承运方实际计算为准）
