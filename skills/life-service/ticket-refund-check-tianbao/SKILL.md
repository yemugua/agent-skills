# 火车票机票退改签核查

退票这件事最容易亏钱的地方，是**你没算档位就点了退票**——同样是退票，提前 9 天和提前 10 小时，扣的钱能差好几倍。

## 什么时候用

- 火车票买错了日期/车次，临近开车才发现退不掉
- 临时有事去不了，不知道退票还是改签划算
- 航班取消、延误、台风停飞，想全额退但被扣手续费
- 生病、家中直系亲属出事、单位或学校原因，能不能不算自己责任
- 已提交退票，钱一直没到账
- 值机了、纸质票拿了还能不能退
- 12306 或航司客服只说"系统不支持"，想要个说法

## 怎么做

**第 1 步**：复制 `templates/交通票务退改签信息采集表.md` 填写（票种、出发时间、票面金额、退改原因、是否已取票是五个关键项）。

**第 2 步**：跑脚本

```bash
python scripts/rail_air_refund_check.py 采集表.md --base 2026-10-05 --out 核查报告.md
```

**第 3 步**：按第八段路径走——**先算账、再比改签、最后才提交**。

## 三句话定性的核心规则

1. **票种先分清**：铁路按距开车的时长阶梯收退票费（8 天以上免、8~48 小时 5%、24~48 小时 10%、不足 24 小时 20%、开车后不退），民航按票价与起飞时长阶梯——**两套规则不能套用**。
2. **原因决定能不能全退**：航班取消/延误、天气、机型调整、承运人出票差错这类**不可归责于你的原因，应全额退或不由你承担退票费**；生病、直系亲属丧事、单位学校证明有机会按非旅客原因处理；单纯行程冲突、买错票则按阶梯扣费。
3. **算完账再决定退还是改**：**改签在开车/起飞前通常不收手续费**，同价或差价改签往往比"退票再买"划算；临近时刻退票最贵。

| | 内容 |

| 退出码 | 0 正常；2 关键信息缺失（给提示串，不崩） |

## 边界与纪律

- 依**通用规则**整理，**不替代律师意见**
- 铁路退改规则以 **12306 现行规定**为准；民航退改规则与票价档以**承运人公布的现行规则**为准（不同航司、不同票价产品差异很大）
- 报告里的金额是按通用阶梯测算的**预估**，最终以承运方实际计算与答复为准
- 不预测承运方、主管部门与法院的处理结果
- **未填的一律不算通过**，只按已填内容判断
- 涉及订单号、身份证、行程信息，本地处理，不要外发
