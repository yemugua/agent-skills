# 成因分类与对策表

> 改造前必读。**先判成因，再给对策。对策与成因不匹配等于无效。**

## 一、六类成因

| 成因 | 典型表现 | 该用的对策 | 不该用 |
|---|---|---|---|
| **怕失败** | 反复准备、不敢开始、怕做不好 | 拆到极小颗粒，让「做一点」就有完成感；降低标准先做完 | 逼自己面对完整任务 |
| **怕完美** | 反复改细节、不肯交付 | 设「先完成再改」硬规则；限制修改次数 | 追求一次做好 |
| **对抗控制** | 一被要求就反抗、越催越拖 | 保留自主权：自己选顺序与时间；把「必须」改成「我打算」 | 用外部压力施压 |
| **即时奖励偏好不足** | 讨厌的事更拖、有趣的事不拖 | 加即时奖励；固定启动；两分钟法则 | 空谈自律 |
| **目标不清** | 「该做的事」说不清具体是什么 | 先写清产出物；模糊任务变具体交付 | 直接排时间表 |
| **情绪回避** | 一想到就烦、涉及某人就拖 | 先处理情绪（记录并命名），把任务与情绪分开 | 硬压着做 |

### 判别要点

- **怕失败 vs 怕完美**：怕失败是「不敢开始」，怕完美是「不肯结束」。前者怕开头，后者怕交付。
- **对抗控制**：越催越拖是标志。此时施加外部压力会加剧。
- **即时奖励偏好不足**：拖延集中在枯燥任务，有趣任务不拖。
- **目标不清**：说不出交付物是什么。
- **情绪回避**：拖延集中于特定人或特定话题，且伴随明显不适。

## 二、可执行方法表（不是「自律」）

| 方法 | 具体做法 | 针对成因 |
|---|---|---|
| **任务拆分** | 拆到 **5—15 分钟**颗粒，每条有明确产出 | 全部 |
| **最小启动动作** | 「打开文档写一行」「打开书翻到那一页」 | 怕失败、任务太大 |
| **两分钟法则** | 能在两分钟内做完的立刻做 | 即时奖励偏好不足 |
| **固定启动时间地点** | 同一时间同一地点，只启动不要求完成 | 全部 |
| **即时奖励** | 做完即给一个小奖励（做完就刷十分钟） | 即时奖励偏好不足 |
| **环境准备** | 手机放远、桌面清空、只留当前材料 | 全部 |
| **自我承诺** | 写下来并告诉他人 | 目标不清 |
| **进度可视化** | 打卡、清单、看到连续完成 | 即时奖励偏好不足 |
| **先完成再改** | 明确「第一版允许粗糙」 | 怕完美 |
| **保留自主权** | 自己定顺序与时间 | 对抗控制 |

## 三、任务颗粒度判据

| 判据 | 标准 |
|---|---|
| 上限 | 15 分钟（超过则启动阻力上升） |
| 下限 | 5 分钟（再小则失去意义） |
| 验证 | 当场能判定是否完成 |

| 任务写法 | 是否合格 |
|---|---|
| 「写论文」 | 不合格（无法启动、无法判定） |
| 「写完论文提纲」 | 可能仍太大 |
| 「列出提纲的三个一级标题」 | 合格（5—15 分钟，可判定） |
| 「打开文档写一行」 | 合格（最小启动动作） |

## 四、延迟满足训练不适合所有人

延迟满足训练（靠意志抵抗即时诱惑）：

| 适用 | 不适用 |
|---|---|
| 即时奖励偏好强度一般 | 即时奖励偏好极强（长期依赖意志会耗尽） |
| 睡眠与注意力状况良好 | 有注意力困难、睡眠问题 |
| 同时配合即时奖励设计 | 只用意志硬扛 |

**三条提醒**：

1. 对即时奖励偏好极强的人，**长期依赖意志会耗尽**，反而加重拖延。
2. 有情绪障碍倾向、注意力困难或睡眠问题的人，**不宜用意志力硬扛**。
3. 它的前提是**同时提供即时奖励**，否则只是压抑而非解决。

**结论：延迟满足训练不是通用方案，更不能作为唯一方法。**

## 五、失败后的应对

**「下不为例」是最无效的失败应对**：它假设了强大的意志力，而拖延常常正是意志力不足的表现。

**正确做法**：

```
1. 不追加惩罚（不打手心、不骂自己）
2. 找出这次的具体阻力在哪一步
3. 把那一步的任务颗粒再缩小一半
4. 重新固定下次的启动时间与地点
```

**原则：失败说明方法与阻力不匹配，应调整方法而不是加大惩罚。**

## 六、常见错误对照

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 「你要自律」 | 忽略成因 | 先判成因 |
| 一套方法通用所有人 | 与成因不匹配 | 按成因选对策 |
| 「写完论文」当任务 | 颗粒太大 | 拆到 5—15 分钟 |
| 「等状态好了」 | 状态不会自己来 | 做最小启动动作 |
| 只靠延迟满足训练 | 意志会耗尽 | 加即时奖励 |
| 失败后下不为例 | 假设强大意志 | 缩小颗粒重来 |
| 环境不配合 | 启动成本高 | 手机放远、桌面清空 |
| 无即时奖励 | 枯燥任务难持续 | 设计小奖励 |
| 任务与情绪混一起 | 一想就烦 | 先处理情绪 |
| 伴随症状仍硬扛 | 可能需专业支持 | 主动求助 |
