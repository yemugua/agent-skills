# 拖延症克服方法核查

拖延**不是懒，也不是意志力问题，而是任务与当下之间的阻力问题**。本技能给的是把阻力降下来的具体方法，并按成因分类给不同对策——**不同成因必须用不同方法**，笼统地「加油」没有用。

## 一、硬边界（能做 / 不能做）

| 能做 | 不能做 |
|---|---|
| 按成因分类给不同对策 | 判定用户「有拖延症」或做心理诊断 |
| 给出任务拆分与环境准备方法 | 替代专业心理治疗 |
| 说明延迟满足训练**不适合所有人** | 承诺「按方法做一定不再拖延」 |
| 给出失败后的应对方式 | 保证特定方法对特定人有效 |
| 提示何时求助 | 评价用户「懒」或「不上进」 |

**本技能不提供诊断，不替代专业心理治疗。严重或持续的症状请寻求专业评估。**

## 二、求助红线（先看）

**出现以下情况，请立刻寻求专业帮助或拨打当地心理援助热线 / 急救：**

| 红线信号 | 说明 |
|---|---|
| **自伤或自杀的念头、计划，或工具已在手** | 危机状态，需即时人工支持 |
| 持续两周以上情绪低落、兴趣丧失 | 已达专业评估时长 |
| 失眠或嗜睡、食欲骤变、体重明显变化 | 躯体症状明显 |
| 无法正常工作生活、社会功能明显受损 | 需专业干预 |
| 出现幻觉或妄想 | 需立即评估 |
| 躁狂表现：少睡却不困、异常兴奋、思维奔逸 | 需立即评估 |
| 严重焦虑伴惊恐反复发作 | 需专业治疗 |
| 进食障碍倾向：体重骤降、催吐、过度运动 | 需专业干预 |
| 物质滥用失控 | 需专业干预 |

**拖延本身通常不属于心理疾病范畴**，但**长期拖延伴随上述任何症状时，应主动求助**——尤其当拖延已经是因为「不想面对」某种情绪时。

## 三、什么时候用

| 用户说法 | 用不用 | 说明 |
|---|---|---|
| 总是启动不了 | 用 | 走最小启动动作 |
| 任务太大做不动 | 用 | 走任务拆分 |
| 等状态好了再做 | 用 | 走成因为即时奖励偏好不足 |
| 拖延是不是懒 | 用 | 说明成因不是意志力 |
| 延迟满足训练有用吗 | 用 | 说明其**不适合所有人** |
| 拖延久了很焦虑 | 用 | 走最小动作与失败应对 |

## 四、完整工作流

### 步骤 1：先判成因（不判就开方，一定开错）

见第五节。**不同成因必须用不同对策。**

### 步骤 2：把任务拆到可启动颗粒

5—15 分钟颗粒，见第六节。

### 步骤 3：把「开始」缩到最小动作

**「打开文档写一行」就是合法的开始。**

### 步骤 4：固定启动条件与环境

见第六节。

### 步骤 5：失败后不用「下不为例」

见第七节。

## 五、核心规则（改造前必读）

**先读 `rules/成因分类与对策表.md`，不要凭印象给建议。**

### 拖延的六类成因与不同对策

| 成因 | 典型表现 | **该用的对策** | 不该用 |
|---|---|---|---|
| **怕失败** | 反复准备、不敢开始、怕做不好 | 拆到极小颗粒，让「做一点」就有完成感；降低标准先做完 | 逼自己面对完整任务 |
| **怕完美** | 反复修改细节、不肯交付 | 设「先完成再改」的硬规则；限制修改次数 | 追求一次做好 |
| **对抗控制** | 一被要求就反抗、越催越拖 | 保留自主权：自己选顺序与时间；把「必须」改成「我打算」 | 用外部压力施压 |
| **即时奖励偏好不足** | 讨厌的事更拖、有趣的事不拖 | 加即时奖励；固定启动；两分钟法则 | 空谈自律 |
| **目标不清** | 「该做的事」说不清具体是什么 | 先写清产出物；把模糊任务变成具体交付 | 直接排时间表 |
| **情绪回避** | 一想到就烦、涉及某人就拖 | 先处理情绪（记录并命名），把任务与情绪分开 | 硬压着做 |

**必须先判成因**：怕完美的人需要「允许粗糙」，怕失败的人需要「降低任务体量」，对抗控制的人需要「保留选择权」——三者方法完全不同。

### 可执行方法（不是「自律」）

| 方法 | 具体做法 | 针对 |
|---|---|---|
| **任务拆分** | 拆到 **5—15 分钟**颗粒，每条有明确产出 | 全部成因 |
| **最小启动动作** | 把开始缩到最小：「打开文档写一行」「打开书翻到那一页」 | 怕失败、任务太大 |
| **两分钟法则** | 能在两分钟内做完的立刻做 | 即时奖励偏好不足 |
| **固定启动时间与地点** | 同一时间、同一地点，只启动不要求完成 | 全部成因 |
| **即时奖励** | 完成即给一个小奖励（做完就刷十分钟） | 即时奖励偏好不足 |
| **环境准备** | 手机放远、桌面清空、只留当前任务材料 | 全部成因 |
| **自我承诺** | 写下来并告诉他人，公开承诺 | 目标不清 |
| **进度可视化** | 打卡、清单、看到连续完成 | 即时奖励偏好不足 |
| **先完成再改** | 明确「第一版允许粗糙」 | 怕完美 |
| **保留自主权** | 自己定顺序与时间 | 对抗控制 |

### 延迟满足训练不适合所有人（必须说明）

延迟满足训练（靠意志抵抗即时诱惑）在**部分人身上有效**，但：

- 对即时奖励偏好极强的人，**长期依赖意志会耗尽**，反而加重拖延；
- 有情绪障碍倾向、注意力困难或睡眠问题的人，**不宜用意志力硬扛**；
- 它的前提是**同时提供即时奖励**，否则只是压抑而非解决。

**结论：延迟满足训练不是通用方案，更不能作为唯一方法。**

## 六、失败后的应对（不用「下不为例」

**「下不为例」是最无效的失败应对**——它假设了强大的意志力，而拖延本身常常就是意志力不足的表现。

**正确做法**：

```
1. 不追加惩罚（不打手心、不骂自己）
2. 找出这次的具体阻力在哪一步
3. 把那一步的任务颗粒再缩小一半
4. 重新固定下次的启动时间与地点
```

**原则：失败说明方法与阻力不匹配，应调整方法，而不是加大惩罚。**

## 七、脚本用法

脚本：`scripts/procrastination_check.py`

```bash
python scripts/procrastination_check.py --file 情况.json
python scripts/procrastination_check.py --selftest
```

| 字段 | 说明 |
|---|---|
| `cause_signals` | 成因信号 |
| `task_minutes` | 当前任务预计耗时 |
| `avoided_thought` | 回避性想法 |
| `red_line_flags` | 求助红线相关信号 |
| `previous_failures` | 既往失败次数 |

输出：成因判定与对应对策、任务颗粒度检查、最小启动动作建议、延迟满足训练适用性提醒、失败应对提示、红线提示。

## 八、人工确认清单（不能省）

- [ ] 是否已判成因（而不是笼统说「要自律」）？
- [ ] 对策是否**与成因匹配**（怕完美给粗糙许可，对抗控制给选择权）？
- [ ] 任务是否已拆到 **5—15 分钟**颗粒？
- [ ] 是否已定义**最小启动动作**？
- [ ] 是否有固定的时间与地点？
- [ ] 环境是否已准备（手机放远、桌面清空）？
- [ ] 是否有即时奖励设计？
- [ ] 是否避免了「下不为例」式惩罚？
- [ ] 是否出现过求助红线中的症状？

## 九、最常见的坑

1. **把拖延当意志力问题，用「你要自律」回应**。成因判断错误，对策全部无效。
2. **不看成因就用同一套方法**。怕完美和怕失败需要的方法相反。
3. **任务颗粒太大**。「写完论文」无法启动，必须拆到 5—15 分钟。
4. **把「等状态好了」当理由**。状态不会自己来，先做最小动作。
5. **只靠延迟满足训练**。对部分人长期依赖意志会耗尽并加重拖延。
6. **失败后用「下不为例」惩罚**。假设了强大的意志力，而拖延恰恰是意志力不足。
7. **环境不配合**。手机在手边、桌面堆满，启动成本天然更高。
8. **没有即时奖励**。枯燥任务缺少回报就更难持续。
9. **把任务与情绪混在一起**。一想到就烦时，先处理情绪再动任务。
10. **长期拖延伴随情绪症状仍硬扛**。出现求助红线应主动求助。

## 十、边界与免责

本技能提供拖延的成因分类与可执行方法，**不提供诊断，不判定用户是否患有心理疾病，不替代专业心理治疗，不保证方法对特定人有效**。拖延本身通常不属于心理疾病范畴，但长期拖延伴随持续情绪低落、社会功能受损或躯体症状时，请寻求专业评估；出现自伤或自杀念头请立即联系身边可信任的人并拨打当地心理援助热线与急救电话。本技能不替代医疗诊断与治疗。
