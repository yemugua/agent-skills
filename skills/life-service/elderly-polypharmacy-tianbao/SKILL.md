# 老年人多重用药管理与相互作用核查

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 输出用药清单整理模板与整理步骤 | 开具处方、给出任何药物的剂量、频次或加减方案 |
| 列出通用名与商品名的对应整理方法 | 推荐具体药品品牌、具体药物组合方案或替代药物 |
| 识别重复成分（如两种感冒药都含同一种退热成分） | 判断某个具体药对「能不能一起吃」并给结论 |
| 列出六类相互作用**风险类别**（出血、镇静、降糖、电解质、肾毒性、QT 间期延长） | 指出具体的药名组合并说「这两味药会出事」 |
| 给出分药盒使用、双人核对、家庭药箱管理方法 | 建议停药、换药或调整剂量 |
| 给出必须立刻找医生的具体情形 | 给出诊断结论或替代诊疗方案 |
| 提示就诊时带上完整清单 | 代替医生或药师做处方审核 |

**必须立刻联系医生或就医的红线（出现任一条，当天联系医生；出现「立即就医」标注的直接急诊）**

- **立即就医**：跌倒后头部着地、意识改变、呕吐不止、剧烈头痛、言语不清、单侧肢体无力、抽搐
- **立即就医**：呕血、黑便、柏油样便、便血、尿血、皮下大片瘀斑或出血不止
- **立即就医**：呼吸困难、喉头水肿感、口唇发绀、严重皮疹伴呼吸困难
- **立即就医**：意识突然混乱、嗜睡叫不醒、说话含糊、瞳孔异常
- **立即就医**：心悸、胸痛、心律明显不齐、血压异常升高伴头痛胸闷
- **当天联系医生**：新出现的不适（头晕、乏力、恶心、腹泻、口干、视物模糊、便秘）
- **当天联系医生**：漏服、错服、重复服药后出现任何异常
- **当天联系医生**：自行减量、停药或换药后症状变化
- **当天联系医生**：导尿管堵塞伴发热、尿痛、尿液浑浊有异味
- **当天联系医生**：食欲明显下降、体重快速下降、持续呕吐、腹泻
- **当天联系医生**：出现皮疹、瘙痒、面部或口唇肿胀（哪怕不严重也要当天说）

**绝对禁止的「安全做法」**：擅自停用慢性病基础用药（降压、降糖、抗凝、抗心律失常等）、自行减量「感觉好转就停」、用保健品替代处方药、一次买多种药「哪个管用吃哪个」、凭广告用药。任何用药调整都必须由开处方的医生或药师决定。

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「老人吃十几种药怎么管」 | 用，清单整理 + 分药盒 |
| 「两种感冒药能一起吃吗」 | 用，指出重复成分识别方法；结论交医生药师 |
| 「哪些药不能一起吃」 | 用，只列六类风险类别，不点名具体组合 |
| 「药名记不清」 | 用，通用名商品名对应整理 |
| 「老人自己吃会吃乱」 | 用，双人核对与分药盒 |
| 「要不要买分药盒」 | 用，给选择维度 |
| 「能不能停掉降压药」 | 不用，结论交医生，明确禁止自行停药 |
| 「中药西药冲突吗」 | 用，只提示需要药师核对，不给结论 |
| 「老人漏服了怎么办」 | 不用，处置由医生或药师决定；只提示「当天联系医生」 |

## 三、完整工作流

1. **先排红线**：逐条核对上述就医红线，命中即当天联系医生或急诊，不给整理建议。
2. **收齐所有药**：把所有来源的药一次收齐，包括处方药、非处方药、保健品、中药、别人推荐的药、各医院各科室开的药。用 `templates/用药清单整理表.md` 一行一药填齐。
3. **统一名称**：每种药补上「通用名」，用通用名做后续所有判断的依据，商品名只作对照。
4. **查重复成分**：按 `rules/清单整理与重复成分识别.md` 的方法，找同一种成分出现在两种药里的情况。
5. **按六类风险分类**：把清单按出血、镇静叠加、降糖叠加、电解质、肾毒性、QT 间期延长六类风险归档，标记需要问医生的组合。
6. **建分药盒与核对机制**：按周分装、双人核对、保留原包装、写好急救联络卡。
7. **输出就诊材料**：完整清单随身带，就诊时逐条念给医生或药师，请其核对。
8. **设定复查节奏**：多科室就诊后重新整理一次。

## 四、核心规则与要件库

生成任何整理结果前，**必须先读**：

- `rules/清单整理与重复成分识别.md`：清单字段、名称对应方法、重复成分识别口径、六类风险类别说明。
- `rules/分药盒依从性与必须找医生.md`：分药盒使用、依从性管理、必须立刻找医生的完整情形、明确禁止做法。

不得输出任何药物剂量、具体药名组合的风险结论、加药或减药方案。所有「这两味药一起行不行」的结论，一律转给开处方的医生或药师。

## 五、脚本用法

```
python scripts/polypharmacy_audit.py --file case.json
python scripts/polypharmacy_audit.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`meds` 药物数组（每项含 `brand` `generic` `class` `dose` `freq` `indication` `prescriber`），`red_flags` 红线标记，`pillbox_days` 分药盒天数 |
| `--dup` | 只跑重复成分与类别查重 |
| `--json` | 以 JSON 输出 |
| `--out` | 结果写入指定文件，默认 `scripts/_last_result.txt` |
| `--selftest` | 运行自检 |

脚本输出重复成分命中、风险类别归档、清单缺口与红旗提示。**脚本不输出任何药物名称组合的风险结论，不含剂量与加减药建议。**

## 六、人工确认清单

- [ ] 就医红线已逐条核对，命中即已联系医生
- [ ] 所有来源的药物已一次收齐（含保健品、中药、他人推荐药）
- [ ] 每种药已补上通用名，后续判断以通用名为准
- [ ] 已做重复成分检查（同类药叠加是最常见也最容易漏的问题）
- [ ] 已按六类风险类别归档并标注需问医生的组合
- [ ] 未擅自停用任何慢性病基础用药
- [ ] 分药盒已按周分装并经双人核对
- [ ] 原包装与说明书已保留，药品未散装丢弃
- [ ] 已带完整清单就诊，请医生或药师逐条核对
- [ ] 已明确所有用药调整由医生或药师决定

## 七、最常见的坑

1. **以为「不同名字就是不同药」**：同一个通用名可能有多个商品名，同时吃两种就等于双倍剂量。
2. **感冒药叠加**：复方感冒药里常含退热、镇咳、抗过敏成分，再加单独服用的同类药就是重复成分。
3. **凭感觉停药**：血压正常了就停降压药、血糖降了就停降糖药，是老年人最常见也最危险的做法。
4. **用保健品替代药物**：宣传「根治」「无副作用」的产品不能替代慢病基础用药。
5. **一次看多个科室不做整合**：每个科室各开各的，没人看全清单，重复和相互作用就是这样产生的。
6. **药名记不清就凭药盒颜色认**：换一次包装就认错，清单必须写通用名。
7. **把分药盒当作唯一保障**：分药盒装错没人发现，所以双人核对不能省。
8. **出现新不适认为是「正常反应」**：头晕、乏力、恶心、腹泻、视物模糊都可能是药物相关，要当天说。
9. **自行减量「感觉好转」**：剂量调整必须由医生决定。
10. **漏服后加倍补服**：具体如何处理由医生或药师指导，不要自行加倍。

## 八、边界与免责

本技能提供老年人多重用药的清单整理方法、重复成分识别口径与风险类别清单，**不提供任何药物名称组合的风险结论、剂量、频次、疗程与加减药方案**。是否需要调整用药、是否可合并或停用某药，**必须由开处方的医生或药师判断，以最新版相关指南和主治医生意见为准**。任何出现跌倒后意识改变、呕血黑便、呼吸困难、意识突然混乱、导尿管堵塞伴发热尿痛的情况，必须立即就医。本技能不替代处方审核与临床药学服务。
