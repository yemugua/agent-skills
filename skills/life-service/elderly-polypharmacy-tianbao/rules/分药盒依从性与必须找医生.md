# 分药盒依从性管理与必须立刻找医生的情形

## 一、分药盒使用

### 选择维度

| 维度 | 说明 |
|---|---|
| 分区形式 | 一周七格可旋转的适合固定服药的老人；四格（早中晚夜）适合服药种类少 |
| 标识方式 | 优先选能贴标签的格子，标签写「早 1」「晚 1」并可用不同颜色区分 |
| 开启难度 | 手抖或视力差者选需要轻按或旋开即可的，避免需要较大力气的小盖 |
| 可视性 | 能否一眼看出今天是否已服（透明格子更好） |
| 密封性 | 防潮，药品不宜长期暴露在空气中 |

### 装盒规则

1. **按周分装**：每周固定同一天装盒，装好后双人核对
2. **保留原包装与说明书**：不散装丢弃，药品盒、说明书、处方一起另存
3. **标签写最小信息**：「早 1」「晚 2」这类，不在分药盒上写药名以外的信息
4. **不混格**：外观相似的白色药片不要装在同一格，避免误服
5. **外用药单独放**：不进入口服分药盒，另用单独收纳盒并标明「外用」
6. **保健品单独放**：与处方药分开放，避免混淆

## 二、双人核对机制

- 每周装盒时由两人一起核对，核对者签字或签名确认
- 家庭药箱由一人负责，钥匙或密码由两人共同知晓
- 每次就诊带回新药后，立即重新整理并双人核对
- 出现「药盒里剩余数量与消耗量对不上」时，立即核对，不猜测

## 三、依从性管理（提高规律服药的现实做法）

| 做法 | 具体口径 |
|---|---|
| 绑定日常事件 | 把服药绑定在早餐后、刷牙后等固定事件上，不依赖记忆 |
| 减少同时服用的种类数 | 种类越多依从性越差；可与医生讨论能否简化方案（由医生决定） |
| 一次只发一周 | 避免一次摆出几个月用量，防止漏服与混乱 |
| 闹钟与提醒 | 老人独处时用闹钟；有条件可用带语音的提醒设备 |
| 记录而非监督 | 家属核对记录，不指责、不训斥；漏服一次就当作数据，不当作过错 |
| 处理漏服 | 统一口径：发现漏服当天联系医生或药师，不自行加倍补服 |

## 四、必须立刻找医生的完整情形

### 立即就医（急诊）

1. 跌倒后头部着地，伴意识改变、呕吐、剧烈头痛、言语不清、单侧无力、抽搐
2. 呕血、黑便、柏油样便、便血、尿血
3. 皮下大片瘀斑、出血不止
4. 呼吸困难、喉头水肿感、口唇发绀
5. 严重皮疹伴呼吸困难
6. 意识突然混乱、嗜睡叫不醒、瞳孔异常
7. 心悸、胸痛、脉搏明显不齐
8. 导尿管堵塞伴发热、尿痛、尿液浑浊有异味

### 当天联系医生

1. 新出现的不适：头晕、乏力、恶心、腹泻、口干、视物模糊、便秘、震颤
2. 漏服、错服、重复服药后出现任何异常
3. 自行减量、停药或换药后症状变化
4. 皮疹、瘙痒、面部或口唇肿胀（哪怕不严重也要当天说）
5. 食欲明显下降、体重快速下降、持续呕吐或腹泻
6. 尿量明显减少、下肢水肿
7. 情绪明显改变、突然话少或情绪低落
8. 同一种药连续几天没吃或连续几天重复吃

## 五、明确的禁止做法（本技能不采用）

- 擅自停用慢性病基础用药（降压、降糖、抗凝、抗心律失常、镇痛、精神类等）
- 凭「感觉好转」自行减量或停药
- 用保健品、保健品类「调理品」替代处方药
- 一次买多种药「哪个管用吃哪个」
- 凭广告或他人经验用药
- 漏服后自行加倍补服
- 把药分到无标签的小盒子里
- 自行判断两药能否同服并据此停掉其中一种
- 复诊时不带清单，让医生凭印象判断
