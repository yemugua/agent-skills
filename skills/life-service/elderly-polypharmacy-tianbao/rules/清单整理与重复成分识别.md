# 用药清单整理与重复成分识别

## 一、清单必备字段（缺一项就补，补齐前不进入风险判断）

| 字段 | 说明 | 为什么必须有 |
|---|---|---|
| 通用名 | 药品的通用名称，国际通用且各地一致 | 所有后续判断的唯一依据 |
| 商品名 | 包装上的品牌名 | 只作对照，不能用于判断 |
| 剂型 | 片剂、胶囊、颗粒、软膏、滴剂、贴剂 | 同一成分不同剂型可能重复（如口服与外用） |
| 单次剂量 | 包装标注或处方标注 | 复核用，本技能不据此给建议 |
| 用药时间 | 每日几次、分别什么时间 | 识别叠加与间隔问题 |
| 用途 | 治什么 | 发现用途重叠 |
| 开处方医生 | 科室与医生 | 就诊时按科室核对 |
| 开始时间 | 何时开始 | 判断是否长期用药、是否有近期加药 |
| 是否可自行停 | 「否」的项目要特别标注 | 明确禁止擅自停药 |

**必须包含的来源**：三甲与社区医院、专科门诊、中医门诊、药店自行购买、家人从外地带回、他人推荐、保健品与「调理品」。

## 二、通用名与商品名的对应方法

1. 拿出药盒，找到成分栏（不是宣传栏）
2. 抄下成分栏里**第一个**药理成分的中文通用名
3. 复方制剂要把**全部**成分抄下来——重复成分往往藏在复方里
4. 同一通用名的不同商品名在清单里合并为一行，商品名用括号并列
5. 中药与保健品也要写：写清楚主要成分或药材名，不写「补品」两个字

**否定词防误伤**：「商品名不一样」不等于「成分不一样」；「包装换了」不等于「药换了」。清单核对时看成分，不看包装。

## 三、重复成分识别口径

### 识别步骤

1. 把清单里每一行的**全部成分**摊平到一张纸上
2. 按成分名逐个归拢
3. 出现 2 次及以上的成分，标记为「重复成分」
4. 对每一处重复记录：出现在哪几种药、每次剂量、每日总次数

### 常见的重复成分来源（举例说明识别思路，不构成用药建议）

| 成分类别 | 常见藏身处 | 叠加后的表现 |
|---|---|---|
| 退热镇痛成分 | 复方感冒药、复方退热药、单独退热药 | 服用过量风险，肝肾负担增加 |
| 抗过敏成分 | 复方感冒药、部分止咳药 | 嗜睡、口干、排尿困难、意识模糊 |
| 镇咳成分 | 复方感冒药、单独镇咳药 | 嗜睡、便秘 |
| 抗凝类成分 | 抗凝药、部分止痛药、部分抗炎药 | 出血风险升高 |
| 抗炎止痛成分 | 止痛药、外用贴剂、口服止痛药 | 消化道出血、肾功能负担 |
| 降糖成分 | 降糖药、部分复方制剂 | 低血糖表现 |
| 局部麻醉或血管扩张成分 | 部分滴剂、外用制剂 | 心血管反应叠加 |

**明确口径**：上表只说明「重复成分可能藏在哪里」，**不判定任何具体组合能否同服，也不给停用建议**。是否需要调整由医生或药师判断。

### 三类典型重复场景

1. **感冒药叠加**：吃了复方感冒药，又另外吃了单独的退热药或止咳药
2. **中西药叠加**：复方感冒药里的西药成分 + 单独的中药制剂中含同类西药成分
3. **多科室叠加**：不同科室开了作用相似的同类药，无人做整合

## 四、六类相互作用风险类别（只列类别，不点名具体组合）

| 类别 | 风险表现 | 家属要观察的信号 |
|---|---|---|
| R1 出血风险增加 | 容易出血、淤血不止 | 牙龈出血、鼻出血、皮下瘀斑、黑便、呕血、尿血 |
| R2 镇静叠加 | 过度困倦、反应变慢 | 白天嗜睡叫不醒、说话含糊、走路不稳、跌倒 |
| R3 降糖作用叠加 | 血糖过低 | 心慌、出冷汗、手抖、意识模糊、严重时昏迷 |
| R4 影响电解质 | 电解质紊乱 | 乏力、手足麻木、心律不齐、食欲极差 |
| R5 肾毒性叠加 | 肾功能负担 | 尿量减少、尿色加深、下肢水肿、食欲差、恶心 |
| R6 QT 间期延长 | 心律问题 | 心悸、胸闷、脉搏明显不齐、晕厥 |

**使用口径**：把清单中每一对药物按这六类做人工标记，标记为「需要问医生」而不是「有风险」。具体是否存在相互作用、是否需要调整，**必须由医生或药师核对**。

## 五、清单缺口自查

- [ ] 是否包含了保健品与中药
- [ ] 是否包含了家人带回与他人推荐的药
- [ ] 每一行是否都写了通用名
- [ ] 复方制剂是否抄全了全部成分
- [ ] 是否记录了开始时间
- [ ] 是否标注了「不可自行停药」的项目
- [ ] 是否记录了开处方科室
