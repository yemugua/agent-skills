# 火灾自动报警主机巡查

## 适用场景
火灾自动报警主机日常巡查核查，含主机状态、探测器、联动广播与记录整改。

## 输入
按 `templates/采集表.md` 逐项核查并填写（填「是 / 否」或具体情况，留空视为待确认）。

## 操作步骤
1. 打开 `templates/采集表.md`，逐项核查现场、台账与记录。
2. 运行：`python scripts/fire_alarm_host_check.py <你填写后的采集表路径>`
3. 查看输出报告：总体结论 + 各域明细 + 整改建议。
4. 阻断项立即整改，风险项限期整改，待确认项补充后复跑。

## 输出说明
- 总体结论：**通过** / **有风险** / **不通过** / **待补正**
- 各域明细：每项标注（符合）/（风险）/（阻断）/（待确认）
- 整改建议：按【立即】【限期】【补充】分级列出

## 规则要点
### 主机状态
- 控制器运行状态正常：现场核查该事项，不符合即记录事实证据并整改
- 火警/故障/监管信息分区显示：现场核查该事项，不符合即记录事实证据并整改
- 历史记录完整可查：现场核查该事项，不符合即记录事实证据并整改

### 探测器
- 点型感烟/感温外观完好：现场核查该事项，不符合即记录事实证据并整改
- 报修或屏蔽有记录：现场核查该事项，不符合即记录事实证据并整改
- 巡检周期符合要求：现场核查该事项，不符合即记录事实证据并整改

### 联动与广播
- 声光警报器与广播模块正常：现场核查该事项，不符合即记录事实证据并整改
- 多线制盘标识清晰：现场核查该事项，不符合即记录事实证据并整改
- 总线盘具备远程启动条件：现场核查该事项，不符合即记录事实证据并整改

### 记录与整改
- 值班记录与主机记录一致：现场核查该事项，不符合即记录事实证据并整改

- 屏蔽设备按期恢复：现场核查该事项，不符合即记录事实证据并整改
