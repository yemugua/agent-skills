# 厨房收纳规则表

生成收纳方案前先读本文件，不要凭印象写。

---

## 一、洗切炒动线

**厨房基本动线：洗 → 切 → 炒**

```
[冰箱/储物区] → [清洗区水槽] → [备餐区台面] → [灶台区] → [出菜/餐桌]
```

### 三条判断标准

| 标准 | 含义 | 不达标的表现 |
|---|---|---|
| 单向不折返 | 主要流程不回头 | 洗完菜要跑回冰箱拿东西 |
| 动线短 | 相邻步骤间距小 | 切完端到灶台要走半个厨房 |
| 取放顺手 | 常用的伸手就够到 | 常用调料在最高层吊柜里 |

### 三类典型动线问题

1. **冰箱与水槽距离过远**：食材取出后要走很久才到水槽，增加洒漏与疲劳
2. **备餐区被占**：台面堆满东西，切菜没有操作空间
3. **调料不在灶台附近**：炒菜时临时找调料是最常见的动线失败

## 二、四个功能区配置建议

### 灶台区（炒）

| 位置 | 适合放 | 不适合放 |
|---|---|---|
| 灶台侧前方 | 常用调料、油盐、锅铲（伸手可及） | 重物、玻璃器皿、液体 |
| 灶台下方 | 与灶具类型匹配的锅具、平底锅 | 尖锐刀具、易碎品、塑料制品 |
| 灶台后方挡板区 | 耐热抹布、油壶（稳固不倒） | 布艺、纸质、塑料 |

**两条硬规则**：

- 灶台附近不放重物（锅具、米袋、饮料箱放在灶台边或正上方，火灾时风险显著上升）
- 灶台附近不放液体（油、醋、酒类放灶台附近，一旦起火或溅洒后果更严重）

### 备餐区（切）

- 台面留出连续操作面，不被杂物占据
- 常用刀具与砧板就近，不放高处或深层抽屉
- 砧板竖放或立架存放，平放占台面且不易干
- 只放当次要用的容器，减少重复搬动

### 清洗区（洗）

- 洗洁精与洗碗布就近，单手可取，不弯腰不踮脚
- 沥水篮与清洁用品分层，湿区与干区分开
- 抹布与海绵分开存放，避免交叉污染
- 下水口周边保持通畅，不堆放杂物

### 储存区（冰箱、干柜）

- 高频物品放在腰到肩的高度，这段最省力也最常用
- 重物放下层，下层承重好，取放更安全
- 轻物放上层，上层取放需抬手，轻物更合适
- 密封容器按类别归置，避免开封后交叉污染与气味互串

## 三、容器选择四条原则

| 原则 | 说明 | 不达标的后果 |
|---|---|---|
| 尺寸与灶具匹配 | 锅具容器与灶具口径、深度匹配 | 锅放不稳、灶台留一圈油 |
| 可叠放 | 同类容器能叠放节省纵向空间 | 纵向空间浪费，同类散乱 |
| 材质耐热 | 灶台区与洗碗区容器需耐热 | 变形、开裂、老化 |
| 密封性足够 | 液体类、干货类必须有密封 | 渗漏、受潮、气味互串 |

### 材质方向参考

| 使用位置 | 材质方向 |
|---|---|
| 灶台区 | 耐热、稳固、不易倾倒 |
| 备餐区 | 无异味、易清洁 |
| 清洗区 | 耐水、耐热、可沥水 |
| 储存区 | 密封性优先；干货类注意透气需求 |

**不建议**：把**所有东西**做成同一款密封盒。干货需要透气，叶菜需要透气，液体需要密封。用同一种容器装所有东西，是形式整齐但功能错误。

## 四、冰箱内部分区与层高利用

| 层位 | 适合放 | 说明 |
|---|---|---|
| 最下层 | 重的、瓶子类、剩菜 | 承重好，重物放下层取放更安全 |
| 中下层 | 熟食、奶制品 | 温度稳定区域 |
| 中上层 | 蔬菜、水果、蛋类 | 果蔬层，注意分隔避免气味互串 |
| 最上层 | 剩菜、需密封的液体 | 温度略高，减少交叉污染风险 |
| 抽屉层 | 果蔬（按品种分开） | 保持湿度，不同品种分开存放 |
| 门架层 | 调味品、饮料 | 温度波动最大，不宜放易变质物品 |

### 层高利用三条要点

1. **容器高度要匹配层高**：过高取放时容易碰倒其他物品
2. **同类叠放而非前后排列**：叠放更省纵向空间，也更容易看清存量
3. **抽屉层用分隔**：不同品种果蔬分开，避免乙烯催熟与水分浸染

## 五、垂直空间利用的前提

| 前提 | 要求 |
|---|---|
| 墙体类型 | 明确墙体材质，不确定时不要自行打孔 |
| 承重能力 | 以产品说明书标注的承重要求为准，不清楚则不打孔 |
| 物品重量 | 高处只放轻的：海绵、抹布、铲子、量勺、常用小件 |
| 固定可靠性 | 打孔深度与位置需避开墙内管线，按产品说明与施工规范 |
| 碰撞风险 | 头部高度范围不装挂件，避免碰头 |

**明确禁止**：在**燃气管道与燃气表附近**加装挂件。这一条没有例外。

**高处绝对不放**：锅具、大米、饮料箱、玻璃器皿、液体容器。

## 六、五种不推荐的做法

| 不推荐做法 | 为什么 | 更好的做法 |
|---|---|---|
| 把重物放在高处 | 取放费力，掉落风险高 | 重物放下层，重心低 |
| 把所有东西做成同款密封盒 | 干货与叶菜需要透气 | 按功能选容器，分开处理 |
| 单件收纳导致拿取不便 | 取一件要拆一堆 | 同类归组，组内再分装 |
| 为收纳而买更多收纳工具 | 物品量没减少，只是换地方堆 | 先减量，再配置工具 |
| 灶台附近放重物与液体 | 火灾与溅洒风险显著上升 | 重物下移，液体远离热源 |

**补充误区**：断舍离变成囤积收纳工具。买了很多盒子箱子之后，物品总量没变，反而更占地方、更难找。先减量，再配置。

## 七、必须转装修方或专业人员的情形

1. 需要改动燃气管道、燃气表位置、电路
2. 墙面挂件涉及承重判断（墙体类型、基层情况不明）
3. 需要拆改橱柜、吊顶、水路
4. 吊柜或隔板安装位置在头部易碰撞区
5. 涉及改造灶具位置或加装电器
6. 需要打孔深度不明（不清楚墙内是否有管线或钢筋）

---

## 八、常见误判清单

1. 先买收纳盒再想怎么放——买了用不上的尺寸
2. 所有东西做成同款密封盒——干货叶菜需要透气
3. 重物放高处——费力且掉落风险高
4. 灶台附近放油壶和重锅——火灾与溅洒风险上升
5. 常用调料放最高层吊柜——炒菜时临时找调料
6. 备餐区台面被杂物占满——没有连续操作面
7. 冰箱里前后排列不叠放——纵向空间浪费
8. 果蔬混放一个抽屉——乙烯催熟与水分浸染
9. 在燃气表附近装挂件——没有例外
10. 单件收纳导致拿取不便——取一件要拆一堆包装
