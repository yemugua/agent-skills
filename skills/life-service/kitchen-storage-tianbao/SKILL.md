# 厨房收纳规划与核查（kitchen-storage）

厨房收纳好不好，**第一决定因素不是买多少收纳工具，是动线**。洗、切、炒的顺序决定了物品该放在哪，拿取路径是否顺畅决定了做饭时会不会来回跑。

第二个决定因素是**容器选择**：尺寸与灶具是否匹配、能不能叠放、材质耐不耐热、密封性够不够。这四条决定收纳是"看起来整齐"还是"真的好用"。

这个技能做四件事：**按动线规划** → **分四区配置** → **选对容器** → **守住安全前提**。

| 能做 | 不能做 |
|---|---|
| 按动线给出收纳规划建议 | ❌ 指导改动燃气管道与电路 |
| 分区给出配置建议 | ❌ 判断墙体承重能力（需专业检测） |
| 说明容器选择原则 | ❌ 承诺具体承重数值（以产品说明为准） |
| 指出不推荐做法 | ❌ 代替装修设计与施工 |
| 列出安全前提 | ❌ 指导在燃气设施附近加装挂件 |

**遇到以下情况，转交装修方或专业人员：**

- **需要改动燃气管道、燃气表位置、电路**
- **墙面挂件涉及承重判断**（墙体类型、基层情况不明）
- **需要拆改橱柜、吊顶、水路**
- **吊柜或隔板安装位置在头部易碰撞区**
- **涉及改造灶具位置或加装电器**
- **需要打孔深度不明**（不清楚墙内是否有管线或钢筋）

## 三、洗切炒动线（布局的第一决定因素）

**厨房的基本动线是：洗 → 切 → 炒。**

```
[冰箱/储物区]  →  [清洗区水槽]  →  [备餐区台面]  →  [灶台区]  →  [出菜/餐桌]
```

**动线的三条判断标准：**

| 标准 | 含义 | 不达标的表现 |
|---|---|---|
| 单向不折返 | 主要流程不回头 | 洗完菜要跑回冰箱拿东西 |
| 动线短 | 相邻步骤间距小 | 切完端到灶台要走半个厨房 |
| 取放顺手 | 常用的伸手就够到 | 常用调料在最高层吊柜里 |

**三类典型的动线问题：**

1. **冰箱与水槽距离过远**：食材从冰箱取出后要走很久才到水槽，增加洒漏与疲劳
2. **备餐区被占**：台面上堆满东西，切菜没有操作空间
3. **调料不在灶台附近**：炒菜时临时找调料，是做饭时最常见的动线失败

## 四、四个功能区的配置建议

### 1. 灶台区（炒）

| 位置 | 适合放 | 不适合放 |
|---|---|---|
| 灶台侧前方 | 常用调料、油盐、锅铲（伸手可及） | 重物、玻璃器皿、液体 |
| 灶台下方 | 与灶具类型匹配的锅具、平底锅 | 尖锐刀具、易碎品、塑料制品 |
| 灶台后方挡板区 | 耐热抹布、油壶（稳固不倒） | 布艺、纸质、塑料 |

**灶台区的两条硬规则：**

- **灶台附近不放重物**：锅具、米袋、饮料箱放在灶台边或正上方，火灾时风险显著上升
- **灶台附近不放液体**：油、醋、酒类放灶台附近，一旦起火或溅洒后果更严重

### 2. 备餐区（切）

| 配置 | 说明 |
|---|---|
| 台面留出连续操作面 | 不被杂物占据，锅碗瓢盆有固定位置 |
| 常用刀具与砧板就近 | 不放在高处或深层抽屉 |
| 砧板竖放或立架存放 | 平放占台面且不易干 |
| 备餐区的容器只放当次要用的 | 减少重复搬动 |

### 3. 清洗区（洗）

| 配置 | 说明 |
|---|---|
| 洗洁精与洗碗布就近 | 单手可取，不弯腰不踮脚 |
| 沥水篮与清洁用品分层 | 湿区与干区分开，避免二次污染 |
| 抹布与海绵分开存放 | 用途不同，混放会交叉污染 |
| 下水口周边保持通畅 | 不堆放杂物 |

### 4. 储存区（冰箱、干柜）

| 配置 | 说明 |
|---|---|
| 高频物品放在腰到肩的高度 | 这段最省力也最常用 |
| 重物放下层 | 下层承重好，取放也更安全 |
| 轻物放上层 | 上层取放需要抬手，轻物更合适 |
| 密封容器按类别归置 | 避免开封后交叉污染与气味互串 |

## 五、容器选择四条原则

| 原则 | 说明 | 不达标的后果 |
|---|---|---|
| **尺寸与灶具匹配** | 锅具容器与灶具口径、深度匹配 | 锅放不稳、灶台留一圈油 |
| **可叠放** | 同类容器能叠放节省纵向空间 | 纵向空间浪费，同类物品散乱 |
| **材质耐热** | 灶台区与洗碗区的容器需耐热 | 变形、开裂、老化 |
| **密封性足够** | 液体类、干货类必须有密封 | 渗漏、受潮、气味互串 |

**材质选择的参考：**

| 使用位置 | 材质方向 |
|---|---|
| 灶台区 | 耐热、稳固、不易倾倒 |
| 备餐区 | 无异味、易清洁 |
| 清洗区 | 耐水、耐热、可沥水 |
| 储存区 | 密封性优先；干货类注意透气需求 |

**不建议的做法**：把**所有东西**做成同一款密封盒。干货需要透气，叶菜需要透气，液体需要密封——**用同一种容器装所有东西，是形式整齐但功能错误**。

## 六、冰箱内部分区与层高利用

| 层位 | 适合放 | 说明 |
|---|---|---|
| 最下层 | 重的、瓶子类、剩菜 | 承重好，重物放下层取放更安全 |
| 中下层 | 熟食、奶制品 | 温度稳定区域 |
| 中上层 | 蔬菜、水果、蛋类 | 果蔬层，注意分隔避免气味互串 |
| 最上层 | 剩菜、需密封的液体 | 温度略高，减少交叉污染风险 |
| 抽屉层 | 果蔬（按品种分开） | 保持湿度，不同品种分开存放 |
| 门架层 | 调味品、饮料 | 温度波动最大，不宜放易变质物品 |

**层高利用的三条要点：**

1. **容器高度要匹配层高**：过高取放时容易碰倒其他物品
2. **同类叠放而非前后排列**：叠放比排开更省纵向空间，也更容易看清存量
3. **抽屉层用分隔**：不同品种果蔬分开，避免乙烯催熟与水分浸染

## 七、垂直空间利用的前提（安全部分）

**墙面挂杆、搁板、挂架确实能省很多台面空间，但前提条件必须先确认：**

| 前提 | 要求 |
|---|---|
| 墙体类型 | 明确墙体材质，不确定时不要自行打孔 |
| 承重能力 | 以产品说明书标注的承重要求为准，不清楚则不打孔 |
| 物品重量 | **高处只放轻的**：海绵、抹布、铲子、量勺、常用小件 |
| 固定可靠性 | 打孔深度与位置需避开墙内管线，具体按产品说明与施工规范 |
| 碰撞风险 | 头部高度范围不装挂件，避免碰头 |

**明确禁止**：**在燃气管道与燃气表附近加装挂件**。这一条没有例外。

**高处绝对不放**：锅具、大米、饮料箱、玻璃器皿、液体容器。

## 八、五种不推荐的做法

| 不推荐做法 | 为什么 | 更好的做法 |
|---|---|---|
| 把重物放在高处 | 取放费力，且掉落风险高 | 重物放下层，重心低 |
| 把所有东西做成同款密封盒 | 干货与叶菜需要透气，同款密封盒会导致受闷 | 按功能选容器，分开处理 |
| 单件收纳导致拿取不便 | 每件单独包装，取一件要拆一堆 | 同类归组，组内再分装 |
| 为收纳而买更多收纳工具 | 物品量没减少，只是换了个地方堆着 | 先减量，再配置工具 |
| 灶台附近放重物与液体 | 火灾与溅洒风险显著上升 | 重物下移，液体远离热源 |

**补充一条最常见的误区**：**断舍离变成囤积收纳工具**。买了很多盒子、箱子、隔板之后，物品总量没变，反而更占地方、更难找。**先减量，再配置**。

- [ ] 已按洗切炒动线确认冰箱、水槽、备餐区、灶台的顺序与间距
- [ ] 动线是单向不折返的
- [ ] 备餐区台面有连续操作面
- [ ] 常用调料在灶台侧前方伸手可及处

## 十、脚本用法

```bash
python scripts/kitchen_storage_check.py --text "灶台上方吊柜放锅具安全吗"
python scripts/kitchen_storage_check.py --file 情况.json --out 结果.md
```

| 参数 | 说明 |
|---|---|
| `--text` | 描述厨房现状与收纳困惑 |
| `--file` | 从文件读，支持 `.txt` / `.md` / `.json`（JSON 用 `{"desc": "..."}`） |
| `--out` | 结果落盘路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本做三件事：匹配动线问题、指出不推荐做法、检查是否命中安全红线（高处重物、灶台附近液体、燃气设施附近挂件）。

> 脚本是关键词匹配，**不等于现场判断**。承重与墙体条件必须实际确认。

## 十一、最常见的坑

**坑一：先买收纳盒再想怎么放。**
物品量没减少，只是换了个地方堆着，而且往往买了用不上的尺寸。

**坑二：把所有东西做成同款密封盒。**
干货与叶菜需要透气，同款密封盒会导致受闷变质。形式整齐但功能错误。

**坑三：重物放高处。**
取放费力、掉落风险高，还可能砸到人。重物放下层。

**坑四：灶台附近放油壶和重锅。**
火灾与溅洒风险显著上升。液体远离热源，重物下移。

**坑五：常用调料放最高层吊柜。**
炒菜时临时找调料是做饭时最常见的动线失败。常用的放伸手可及处。

**坑六：备餐区台面被杂物占满。**
没有连续操作面，切菜会很不顺手，还要频繁挪东西。

**坑七：冰箱里前后排列不叠放。**
纵向空间浪费。同类叠放更省空间，也更容易看清存量。

**坑八：不同品种果蔬混放一个抽屉。**
乙烯催熟与水分浸染互相影响，保存期缩短。

**坑九：在燃气表附近装挂件。**
这一条没有例外。

**坑十：单件收纳导致拿取不便。**
取一件要拆一堆包装。按类别归组，组内再分装。
