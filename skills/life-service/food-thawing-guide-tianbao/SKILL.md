# 食物解冻方式与安全核查（food-thawing-guide）

解冻这一步只有一句话原则：**在低温下慢慢解冻，让中心温度同步上来。** 任何让表层先熟、先化而中心还冻着的方式，都在给细菌开绿灯。

这个技能做四件事：**定方式 → 估耗时 → 排时点 → 管污染**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 按食材给出可用与禁止的解冻方式 | ❌ 检测解冻后食品的微生物指标 |
| 估算冷藏解冻耗时并给出转移时点 | ❌ 给出「解冻后保证安全」的结论 |
| 判定解冻后能否复冻 | ❌ 指导改造冰箱制冷系统或电路 |
| 列出解冻环节的交叉污染防控动作 | ❌ 判定食品生产经营的合规状态 |

**遇到以下情况，不要给家庭解冻方案，直接按最坏情况处理：**

- 解冻后**中心仍结冰但表层已发黏、有异味** —— 已属变质，按弃用处理
- **解冻液呈粉红色、浑浊、有明显黏液**（肉类解冻后特征）—— 弃用
- 冷冻室**断电数小时以上**期间的食材 —— 不确定解冻历史，按弃用处理
- **反复解冻复冻过**的食材 —— 微生物已多次繁殖，不建议食用
- 用户要给**婴幼儿、孕妇、老人、免疫力低下者**食用 —— 门槛应更严，改用冷藏慢解且当次吃完

> **本技能不提供任何消毒方法。** 解冻后若疑似变质，正确做法是弃用，不是想办法「挽救」。

## 二、完整工作流

```
第 1 步  确认食材与状态：种类、厚度、是否已部分解冻
第 2 步  确认解冻目的：什么时候要用（决定方式与时点）
第 3 步  读规则文件 rules/解冻方式对照与风险红线.md
第 4 步  选方式：按食材取推荐方式，避开禁止方式
第 5 步  估耗时：按厚度算冷藏解冻耗时，倒推转移时点
第 6 步  跑脚本逐项核查方式是否允许、耗时与转移安排
第 7 步  布置解冻环境：专用解冻盘、置于下层、避免滴液
第 8 步  完成后清洗：解冻盘、台面、手
第 9 步  当次吃完，不复冻
```

## 三、四类解冻方式对照

| 方式 | 适用 | 不适用 | 风险 |
|---|---|---|---|
| **冷藏慢解** | 一切肉类、整鱼、虾、速食 | 冰淇淋（需更快回温） | 耗时；但安全边际最大 |
| **室温** | 面包、饼干、黄油、土豆 | **整块肉、整鸡、整鱼、虾、肉馅** | 表层先进入危险温度区而中心仍冻，细菌反而长得快 |
| **微波** | 薄肉片、鸡翅鸡腿、鱼片 | **整块肉、整鸡、带骨大件** | 受热极不均匀，边缘已熟中心仍冰 |
| **热水** | 速食、部分汤类（直接下锅） | **整条鱼、虾、整鸡、整块猪肉与牛肉、速食、冰淇淋** | 表层瞬间熟化，汁液流失，且污染水槽 |

**核心判断**：室温解冻的问题不是「细菌立刻暴增」，而是**表面细菌增长速度远超中心解冻速度**——细菌跑得比冰融化快，所以解冻时间越长风险越大。

---

## 四、绝对禁止热水解冻的品类

**这不是「不推荐」，是「会毁掉食材并增加风险」。**

| 品类 | 为什么绝对不行 |
|---|---|
| **整条鱼** | 表层瞬间熟化而中心仍冰冻，细胞破裂后**汁液大量流失、肉质发柴** |
| **虾类** | 外壳粘连、虾肉变面，风味与口感不可接受 |
| **整鸡（带骨）** | 局部受热熟化而中心仍冻，解冻后极易滋生细菌 |
| **整块猪肉** | 表面渗出大量汁液，营养流失且污染台面与水槽 |
| **整块牛肉** | 同上，汁液流失严重，表面残留生熟不均 |
| **速冻水饺包子** | 外皮泡烂破口；速食本身**无需解冻** |
| **冰淇淋** | 大量融化后不可再冻成原质地 |

## 五、耗时估算与提前转移时点

```
冷藏解冻耗时 ≈ 厚度（厘米）÷ 2.5 × 12 小时
```

| 厚度 | 估算耗时 | 转移安排 |
|---|---|---|
| 2 厘米（肉片） | 约 10 小时 | 当天尽早转入 |
| 4 厘米（鸡翅） | 约 19 小时 | 提前一天转入 |
| 6 厘米（整鱼） | 约 29 小时 | 提前一天转入 |
| 8 厘米（整块牛肉） | 约 38 小时 | 提前一天转入 |
| 10 厘米（整鸡） | 约 48 小时 | 提前两天或夜间转入 |

**一般原则**：耗时 12 小时以内的，当天尽早转入冷藏室；超过 12 小时的，**必须提前一天转入**，夜间入睡前是最佳时点。

**如果今天才想起来，明天就要吃** —— 冷藏来不及，应改用微波（薄件）或直接下锅烹调，不要用热水。

## 六、能否复冻

**大多数肉类、鱼类解冻后不可复冻。**

| 品类 | 可否复冻 | 原因 |
|---|---|---|
| 各类生肉、生禽、鱼、虾 | **不可复冻** | 解冻后细菌大量繁殖，回冻不能逆转 |
| 肉馅 | **不可复冻** | 表面积大，污染与繁殖都更快 |
| 冷冻面包 | 可复冻 | 烘焙类水分少，品质损失可控 |
| 黄油 | 可复冻 | 油性脂肪，稳定性好 |
| 速冻饺子 | 不建议 | 反复冻裂后皮破易煮烂 |

**「解冻后再冻回去」的常见误解**：很多人以为低温能杀死细菌。**冻结只是让代谢暂停，不是杀死**。解冻期间已经增殖的细菌，回冻后只是暂停，恢复解冻又继续增殖，且代次更多、风险更高。

---

## 七、解冻环节交叉污染防控（五条）

1. **解冻盘必须单独使用**，不与直接入口或即食食品接触
2. **生禽与生肉的解冻液必须倒掉**，绝不用于其他食材
3. **解冻完成后立即清洗**解冻盘与操作台面，再处理即食食品
4. **解冻水不得倒入水槽**污染其他物品；有下层食材时要防止滴液
5. **处理完生肉后必须洗手**，再接触熟食与即食食品

**放置位置也很关键**：解冻中的生肉应放在冰箱**下层或专用密闭盒内**，让滴液不会落到下层的熟食或即食食品上。

## 八、脚本用法

```bash
python scripts/food_thaw_guide.py --file thaw.json --out 解冻核查.md
python scripts/food_thaw_guide.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`plan_from` 起始日（今天/明天/后天）、`items` 待解冻食材列表 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检（28 条断言，含 BOM 输入两条） |

输入 JSON 示例：

```json
{
  "plan_from": "今天",
  "items": [
    {"food": "whole_fish", "name": "整条带鱼", "method": "热水"},
    {"food": "chicken_whole", "name": "整鸡", "method": "冷藏慢解"},
    {"food": "beef_slice", "name": "牛肉片", "method": "微波"}
  ]
}
```

可选食材键：`whole_fish` `fish_fillet` `shrimp` `beef_roast` `beef_slice` `pork_roast` `chicken_whole` `chicken_part` `ground_meat` `frozen_dumpling` `frozen_bread` `ice_cream` `butter` `frozen_vegetable` `frozen_rice` `potato` `whole_egg` `butter_cookie`；`method` 只接受 `冷藏慢解` / `室温` / `微波` / `热水`。

脚本输出：逐项方式判定（禁止项排最前）、预计耗时、能否复冻、转移时点、交叉污染防控五条与提示。**脚本只判方式与耗时，不判食品是否变质。**

## 九、人工确认清单（这步不能省）

- [ ] 已在冷藏室内完成解冻，未用热水、未在室温长时间放置
- [ ] 解冻盘单独使用，解冻液已倒掉并清洗
- [ ] 处理完生肉生禽后已洗手，再接触熟食与即食食品
- [ ] 解冻后当次吃完，未复冻放回
- [ ] 中心已彻底解冻，未按「外面化了就是化了」判断
- [ ] 冷藏解冻期间未与生鲜即食食品同层交叉污染

## 十、最常见的坑

**坑一：用热水泡冻肉「快点解冻」。**
错误做法：整块牛肉丢进热水里泡十分钟。正确做法：这是明确禁止的做法。表层瞬间熟化、中心仍冰，汁液大量流失，且泡过的水污染水槽。正确路径是冷藏慢解，或薄件用微波。

**坑二：室温放一夜「反正天凉」。**
错误做法：冻肉放在厨房台面一整晚。正确做法：室温解冻的问题是**表面细菌增长快于内部解冻速度**，时间越长越危险。整块肉必须冷藏解冻，提前一天转移。

**坑三：微波解冻大件肉。**
错误做法：整鸡扔微波炉转十分钟。正确做法：微波从边缘开始受热，边缘已熟中心仍冰，解冻后极易滋生细菌。微波只适合 2 厘米左右的薄肉片。

**坑四：解冻后看看没坏就放回去冻。**
错误做法：化开一半，剩下的塞回冷冻。正确做法：**解冻即已复温**，细菌已开始繁殖，回冻只是暂停代谢不是杀死。要么一次解冻吃完，要么不解冻。

**坑五：冻饺子先泡水再煮。**
错误做法：水饺拿出来泡软了再下锅。正确做法：速食**不解冻，直接下锅**。先泡水外皮吸饱水，煮时容易破。

**坑六：解冻水顺手冲进水槽。**
错误做法：解冻盘的水倒掉就完事。正确做法：解冻盘必须单独使用，解冻液倒掉后立即清洗盘与台面；处理完生肉先洗手再碰熟食。

**坑七：只看外面化了就下锅。**
错误做法：整块肉表面软了，中间还硬着，直接切。正确做法：中心硬的部分仍是有效冷冻状态，细菌主要在已复温的部分。要么彻底解冻，要么不解冻直接整块烹调。

**坑八：整鱼用微波「加速解冻」。**
错误做法：整条鱼微波五分钟。正确做法：整条鱼必须冷藏慢解。微波与热水都会让表层熟化、鱼肉崩散、汁液流失。

**坑九：解冻的肉和即食食品放在同一层。**
错误做法：解冻盘和酸奶、熟食放同一层。正确做法：生鲜解冻必须放下层或专用密闭盒，滴液不能落到即食食品上。

**坑十：解冻后有异味，试着洗洗再做。**
错误做法：肉有点味道，冲一下再炒。正确做法：解冻后出现异味、黏液、解冻液浑浊粉色，**直接弃用**。解冻环节无法通过清洗挽救，正确做法是下次冷藏慢解。

## 十一、边界与免责

- 本技能提供家庭条件下的**解冻方式选择、耗时估算与污染防控口径**，**不做微生物检测，也不判定食品是否安全**
- 食品是否安全，**以具备资质的检测机构结果、现行规定和相应产品标签为准**
- 耗时为按厚度估算的参考值，实际受冰箱温度、食材初始温度与摆放位置影响，**以中心是否彻底解冻为最终判据**
- 本技能**不提供任何消毒或挽救方法**；疑似变质一律按弃用处理
- 涉及冰箱制冷系统、电路或结构异常的问题，应交由专业人员处理
- 本技能不构成任何食品安全担保
