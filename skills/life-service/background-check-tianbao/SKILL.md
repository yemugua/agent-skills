# 员工背景调查（background-check）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：生成员工背景调查方案与授权文书：身份信息、学历、工作经历、犯罪记录（合规范围内）、竞业限制与前雇主核实，含《个人信息保护法》边界。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 背景调查
- 背调
- 入职核实
- 候选人核实
- PIPL合规

## 三、工作流
1. 取得候选人书面授权（PIPL前提）
2. 核验身份与学历证书
3. 工作经历与前雇主核实
4. 涉敏岗位犯罪/失信核查（合规）
5. 竞业限制与利益冲突排查
6. 形成背调结论与风险

## 四、核心内容（检查清单与判定）
《个人信息保护法》要求处理敏感个人信息须有单独同意；背景调查应在授权范围内、最小必要原则进行，避免就业歧视。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 无候选人书面授权 | PIPL |
| Q2 | FAIL | 未核身份/学历 | 基础 |
| Q3 | WARN | 工作经历未核查 | 经历 |
| Q4 | WARN | 涉敏岗位未做合规核查 | 合规 |
| Q5 | FAIL | 未排查竞业限制/利益冲突 | 风险 |

> 脚本 `background-check_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python background-check_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python background-check_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
