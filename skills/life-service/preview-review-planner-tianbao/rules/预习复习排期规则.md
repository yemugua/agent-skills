# 预习复习排期规则

> 排计划前必读。**四栏字段缺一不可，失败归类不要混判。**

## 一、预习三步法

预习的目的**不是提前学会**，而是让正式学习时有个挂钩点、暴露不懂的地方。

| 步骤 | 动作 | 产出 | 时长占比 |
|---|---|---|---|
| **一、扫** | 通读一遍标题、小标题、目录、图表，不求懂 | 一份「大概讲什么」的印象 | 短 |
| **二、标** | 标出不认识的词、看不懂的段落、没解决的问题 | 问题清单 | 中 |
| **三、问** | 把问题清单带到正式学习时解决 | 问题清单 | 不占预习时间 |

**预习不该做的事**：提前做课后习题（会形成虚假熟悉感）、逐字精读全部内容（时间成本过高）、试图提前全部学懂（超出预习定位）。

**问题清单必须带到课堂**，否则预习等于没做——这是预习最常见的失效方式。

## 二、复习间隔安排

### 学科学习里的间隔节点

学科复习与单词复习的差别在于：**学科遗忘不是线性的，且复习单位是章节而非单词**。可用节点：

```
当天（课后当日过一遍）→ 第 2 天 → 第 7 天 → 第 21 天 → 考前
```

**与单词复习的关键差别**：学科复习每次耗时更长，所以节点数应更少，否则单日复习负荷会失控。**不要把单词的 7 节点直接套到学科上。**

### 每种复习的内容不同

| 节点 | 该做什么 | 不该做什么 |
|---|---|---|
| 当天 | 过一遍笔记与例题，标出没懂的 | 从头重读教材 |
| 第 2 天 | 做对应练习，错题当场整理 | 只看不做 |
| 第 7 天 | 闭卷回忆章节结构与关键点 | 照着笔记念 |
| 第 21 天 | 综合题 + 错题重做 | 只看错题不看新内容 |
| 考前 | 按题型集中训练 | 换新资料 |

**闭卷回忆优于照着重读**，理由与单词记忆一致：主动提取才强化连接。

## 三、各科复习配比思路

不给固定比例，给**决定配比的三个变量**：

```
配比权重 = 考试权重 × (1 − 当前掌握程度) × 遗忘风险系数
```

| 变量 | 含义 | 怎么估 |
|---|---|---|
| 考试权重 | 该科在评价中的分值比重 | 以现行评价方案为准 |
| 当前掌握程度 | 自评已完成的比例 | 做一套题看正确率，别凭感觉 |
| 遗忘风险 | 不复习会掉得多快 | 学过的旧章节风险更高 |

**两个实操原则**：

1. **复习时间要向「掌握程度低 + 遗忘风险高」倾斜**，而不是向「喜欢的科目」倾斜。
2. **任何一科连续多天为零即为失衡**，说明配比在实际执行中已经跑偏。

**不给通用百分比**：不同评价体系的权重结构不同，套用他人比例必然错位。

## 四、任务颗粒度判据

| 判据 | 标准 |
|---|---|
| 上限 | 单条任务预计耗时不超过单次专注时长 |
| 下限 | 单条任务预计耗时不低于 5 分钟（再小就失去意义） |
| 验证 | 任务能**当场判定**是否完成 |

**「复习第三章」不合格**（无法判定完成）；「做完第三章课后题 1—10 并标出错题」合格（可判定）。

## 五、完成标准的写法

| 写法 | 是否合格 | 说明 |
|---|---|---|
| 「掌握第三章」 | 否 | 无法判定 |
| 「看完第三章」 | 否 | 看没看完无法自检 |
| 「合上笔记写出第三章的 5 个关键概念及因果关系」 | 是 | 可当场判定 |
| 「做完课后题 1—10，错题数写出」 | 是 | 有可数产出 |

**判断标准**：合上所有资料后，你能不能立刻说出「做到了」或「没做到」。

## 六、每周失败归类表

| 现象 | 归类 | 修正动作（按此顺序试） |
|---|---|---|
| 排得很满，一周后放弃 | **计划过满** | 按上周实际完成率打折，留 20% 缓冲 |
| 排了但总不开始 | **只排不执行** | 首任务缩到 5—15 分钟；固定时间与地点；减少同时进行的计划数 |
| 做完不知算不算完成 | **没有完成标准** | 每条补可判定标准 |
| 任务太大，启动不了 | **任务粒度太大** | 拆到单次专注可完成 |
| 一直在做新内容，复习被挤掉 | **复习未独立排期** | 复习固定独立时段 |

**归类纪律**：一次只改一个变量。同时改计划量、时间、任务粒度，就无法知道哪个动作有效。

## 七、错题整理（24 小时规则）

**硬规则：错题在 24 小时内整理。**

| 时间点 | 价值 |
|---|---|
| 24 小时内 | 还记得当时的思路，错误原因可追溯 |
| 3 天后 | 需要重新推导，多数只剩「做错了」 |
| 1 周后 | 只剩结果，无信息量 |

**错题卡四字段**（不抄整题）：

```
题目定位：
我当时错在哪：（具体到步骤或知识点）
正确的关键一步：（只写关键那步）
下次遇到什么信号要警觉：
```

**重做时机**：在第 2 天与第 7 天各重做一次，只重做不看答案。

## 八、常见误操作

1. **预习做成提前学习**，产生虚假熟悉感。
2. **问题清单不带进课堂**，预习失效。
3. **把单词的密集节点套到学科上**，复习负荷失控。
4. **按喜好分配时间**，高分值低掌握科目被跳过。
5. **一科连续多天为零**仍不调整。
6. **一次改多个变量**，无法归因哪个动作有效。
7. **错题隔夜以后再整理**，错因丢失。
8. **只抄题不做错因分析**，下次照错。
9. **照笔记念当复习**，缺提取训练。
10. **计划不留缓冲**，一次意外即整体放弃。
