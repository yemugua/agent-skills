# 预习复习计划安排

学习计划失败，**极少是因为不够努力，而是因为计划表本身有结构缺陷**：任务粒度太大、没有完成标准、每天排太满、只排不执行。本技能给的是可排期的结构，以及**计划失败时的归类诊断**。

## 一、硬边界（能做 / 不能做）

| 能做 | 不能做 |
|---|---|
| 给出预习三步法与复习间隔安排 | 承诺按计划执行后的成绩提升 |
| 设计计划表字段与配比思路 | 断言某科目「必须每天两小时」 |
| 诊断计划失败原因并给修正动作 | 代替学校或老师制定教学计划 |
| 给出任务粒度与完成标准的写法 | 承诺考纲覆盖率或押题命中 |
| 输出可执行的排期表 | 提供官方教学大纲内容（以现行教材与大纲为准） |

**必须转交专业人士：** 计划长期无法执行且伴随持续情绪低落、失眠、注意力严重受损、躯体症状——这不是排期问题，应转教育心理或医疗机构评估。

## 二、什么时候用

| 用户说法 | 用不用 | 说明 |
|---|---|---|
| 怎么安排复习计划 | 用 | 走间隔安排 + 配比 + 排期 |
| 预习怎么做 | 用 | 走预习三步法 |
| 计划总是完不成 | 用 | 走失败原因归类诊断 |
| 错题本怎么做 | 用 | 走 24 小时整理规则 |
| 每天复习多久 | 用 | 按可用时间与任务量反推 |
| 各科时间怎么分 | 用 | 给配比思路而非固定比例 |
| 任务拆多大合适 | 用 | 给颗粒度判据 |
| 我就是学不进去 | 部分用 | 若伴随情绪症状应先转介 |

## 三、完整工作流

### 步骤 1：先查每日真实可用时间

计划基于**可用时间**而不是「有多少学多久」。可用时间 = 总时间 − 通勤、吃饭、休息等固定占用。

### 步骤 2：拆任务（粒度判据见规则文件）

任务粒度判据：**预计耗时超过单次专注时长就必须再拆**。一条任务的预计耗时应当是明确的数字，不是「大抵」。

### 步骤 3：写完成标准（最容易漏的一步）

没有完成标准的任务无法判断是否完成，也无法在中断后接上。写法见规则文件。

### 步骤 4：定优先级与顺序

按「考试权重 × 当前掌握程度 × 遗忘风险」排，不是按学科喜好排。

### 步骤 5：按间隔安排复习

详见 `rules/预习复习排期规则.md`，用 `scripts/study_plan_builder.py` 排期。

### 步骤 6：错题在 24 小时内整理

这条是硬规则，见第五节。

### 步骤 7：每周按失败原因归类校准

见第三节诊断表。

## 四、核心规则（排计划前必读）

**先读 `rules/预习复习排期规则.md`，不要凭印象排。**

### 计划表四栏字段（缺一不可）

| 字段 | 说明 | 反例 |
|---|---|---|
| **任务** | 动词开头的具体动作 | 「复习数学」（太粗） |
| **预计耗时** | 具体数字（分钟） | 「一会儿」（无法判断） |
| **完成标准** | 可判定真假的动作或产出 | 「掌握」（无法判定） |
| **优先级** | 高/中/低或排序 | 不填（等于按心情做） |

**没有「完成标准」的计划表无法执行**，因为中断后你不知道从哪接上。

### 计划失败的四个归类（对号入座）

| 现象 | 归类 | 修正动作 |
|---|---|---|
| 每天都排满，一周后放弃 | **计划过满** | 按实际完成率打折，留出缓冲 |
| 排了但从不开始 | **只排不执行** | 把任务缩到 5—15 分钟，并固定时间地点 |
| 做完不知道算不算完成 | **没有完成标准** | 每条补可判定标准 |
| 任务太大，启动不了 | **任务粒度太大** | 拆到能在一节课内完成 |

**这四类不要互相混判**，混判会导致加码时间而不是修正结构。

## 五、错题整理规则（硬规则）

**错题必须在 24 小时内整理。** 原因：超过 24 小时后，回忆当时为什么错已经需要重新推导，错误原因会丢失，只剩下「这题我做错了」这个无效信息。

错题卡只记四项，不抄整题：

```
题目定位（页码/题号）
我当时错在哪（具体到步骤或知识点）
正确思路的关键一步（只写关键那步）
下次遇到什么信号要警觉
```

**只抄不做错因归类的错题本，等于把题再做一遍，收益很低。**

## 六、脚本用法

脚本：`scripts/study_plan_builder.py`

```bash
python scripts/study_plan_builder.py --file 计划.json
python scripts/study_plan_builder.py --selftest
```

| 字段 | 说明 |
|---|---|
| `daily_minutes` | 每日可用分钟数 |
| `tasks` | 任务列表，含 title/minutes/priority/field |
| `review_nodes` | 复习间隔节点，缺省用默认 |

输出：按优先级排定的日计划、每日负荷是否超限、字段完整性检查（缺完成标准等）、失败原因提示。

## 七、人工确认清单（不能省）

- [ ] 每日可用时间是否按**实际**估算而不是理想值？
- [ ] 每条任务是否有**具体数字**的预计耗时？
- [ ] 每条任务是否有**可判定**的完成标准？
- [ ] 任务粒度是否已拆到单次专注能完成？
- [ ] 优先级是否按考试权重与掌握程度排，而非喜好？
- [ ] 错题是否在 24 小时内整理并写了错因？
- [ ] 计划是否留有缓冲（不是每天排满）？
- [ ] 每周是否按四类失败原因做过归类校准？

## 八、最常见的坑

1. **任务写成「复习数学」**。粒度太大，无法启动也无法判定完成。正确做法是拆到具体动作。
2. **没有完成标准**。中断后接不上，长期看会误以为一直没做。
3. **每天排满不留缓冲**。任何意外都会打乱，而打乱一次就容易整体放弃。
4. **只排不执行**。原因是任务启动成本高或没有固定时间地点，应缩小首任务并固定触发点。
5. **按学科喜好排序**。应按权重、掌握程度与遗忘风险排。
6. **错题隔几天才整理**。错因丢失，只剩无效信息。
7. **错题本只抄不做归因**。抄题不产生分析，下次同类错误照错。
8. **复习与新学混在一起无区分**。两者应分时段，否则复习时间被新学挤掉。
9. **间隔一开始就拉很长**。前期记忆未稳就拉长间隔等于白复习。
10. **计划失败就加码时间**。多数是结构问题，加码只会更快崩。

## 九、边界与免责

本技能提供排期方法、字段设计与失败归类，**不提供教学大纲内容、不承诺成绩提升、不替代学校教学计划**。各科目的考查范围与要求以任课教师与官方现行大纲为准。计划长期无法执行且伴随情绪或躯体症状的，请优先寻求专业评估。
