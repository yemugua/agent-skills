# 居家氧疗护理与吸痰操作核查

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 说明制氧设备类型差异与选购关注点 | 给出氧疗适应证判断或推荐数值标准 |
| 输出管路清洁、耗材更换周期与计算方法 | 给出具体的氧气流量数值或流量调整方案 |
| 说明湿化与鼻部护理要点 | 给出药物、雾化药物或任何用药方案 |
| 输出氧气安全红线（禁火源、防倾倒、静电等） | 判断能否离院、能否做手术、能否乘飞机 |
| 给出感染预防与手卫生要求 | 自行实施吸痰操作或给出吸痰深度、负压、时间参数 |
| 说明何时必须就医 | 诊断感染、判断是否需要住院 |
| 给出耗材周期的估算方法 | 推荐具体品牌、型号与商家 |

**必须立即就医或呼叫急救的红线（出现任一条）**

- **呼吸困难加重**：安静状态下也气促、说话不能成句 —— 急诊
- **口唇甲床发绀**（发紫）—— 急诊
- **意识改变**：嗜睡叫不醒、烦躁、意识模糊、反应迟钝 —— 急诊
- **二氧化碳潴留表现**：晨起头痛、嗜睡、扑翼样震颤、皮肤湿冷 —— 立即就医
- **突发剧烈胸痛**、胸闷伴大汗 —— 急诊
- **呼吸频率明显增快或减慢**、呼吸节律不规则 —— 急诊
- **意识丧失后仍有呼吸但出现呼吸暂停** —— 急诊，必要时呼叫急救
- **咳大量粉红色泡沫痰** —— 急诊
- **咳血或痰中带血** —— 急诊
- **发热伴痰量突然增多、变黄变稠、出现臭味** —— 当天就医（可能为感染加重）
- **吸痰时出现剧烈呛咳、血氧下降、心率明显增快** —— 停止操作并就医
- **吸痰管插入时遇到明显阻力** —— 不强行插入，停止并就医

**绝对禁止的做法**：自行加大氧气流量、靠近明火取暖做饭、在氧气旁抽烟、使用电热毯等易发热电器时长时间在氧疗中、在氧气附近使用打火机或燃气灶、氧气瓶不固定、把制氧机放在通风不良的狭小空间、堵塞排风口、用食用油润滑氧气管路。

## 三、完整工作流

1. **先排红线**：逐条核对就医红线，命中即就医或呼叫急救。
2. **确认医嘱前提**：确认医嘱已明确是否需要长期家庭氧疗、流量与每日使用时长。**未取得医嘱不做设备与流量安排。**
3. **选设备**：按 `rules/设备类型与管路耗材.md` 的四类设备对照，关注噪音、耗电、流量范围与维护成本。
4. **算耗材周期**：用脚本或表格算出滤芯、鼻氧管、湿化瓶、过滤棉的更换周期与年耗材成本。
5. **定清洁流程**：管路、湿化瓶、制氧机外部的清洁与消毒步骤，写进家庭护理流程表。
6. **落实安全红线**：按 `rules/氧气安全红线.md` 的十条逐项落实并张贴。
7. **做感染预防**：手卫生、口腔护理、管路不共用、每日通风。
8. **设监测与复评**：每日症状与流量记录，出现红线立即就医。

## 四、核心规则与要件库

生成任何建议前，**必须先读**：

- `rules/设备类型与管路耗材.md`：四类设备对照、选购关注点、管路清洁、耗材周期计算、感染预防。
- `rules/氧气安全红线.md`：十条安全红线、流量调整口径、雾化与吸氧同时进行注意、必须立即就医的情形。

**必须写明的边界**：氧疗适应证与氧气流量**由医生评估确定**，本技能不自行给适应证数字、不给流量数值。所有医学口径**以最新版指南和主治医生判断为准**。**吸痰操作必须由医护指导**——吸痰是侵入性操作，存在低氧、心律失常、气道黏膜损伤和感染风险，家庭不得在无人指导的情况下自行实施。

## 五、脚本用法

```
python scripts/oxygen_therapy_plan.py --file case.json
python scripts/oxygen_therapy_plan.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`device` 设备类型（`molecular` `concentrator` `liquid` `piston`），`hours_per_day` 每日使用小时数，`days_per_month` 每月使用天数，`nasal_days` 鼻氧管更换天数，`filter_days` 滤芯更换天数，`bottle_days` 湿化瓶更换天数，`red_flags` 就医红线标记 |
| `--cost` | 只输出耗材周期与年耗材成本估算 |
| `--json` | 以 JSON 输出 |
| `--out` | 结果写入指定文件，默认 `scripts/_last_result.txt` |
| `--selftest` | 运行自检 |

脚本输出耗材周期、年耗材估算、设备对照与安全清单。**脚本不给适应证数字、不给氧流量数值、不给吸痰参数。**

## 七、最常见的坑

1. **氧流量越大越好**：这是最危险也最常见的误解。流量必须遵医嘱，自行加大可能加重二氧化碳潴留。
2. **在氧气旁抽烟或用明火做饭**：氧气助燃，这是绝对禁止的红线，不是「小心点就行」。
3. **氧气瓶不固定**：容易倾倒，瓶阀受损可能造成危险。必须固定或使用带轮底座。
4. **滤芯超期不换**：滤芯饱和后出气量下降、纯度下降，家中还以为是病情变化。
5. **湿化瓶长期不清洗**：细菌繁殖，直接影响气道，这是家庭氧疗最常见的感染来源之一。
6. **管路弯折或压折**：管路打折会使实际进入量远低于设定值。
7. **用食用油润滑氧气管路**：油脂与高浓度氧接触有燃爆风险，明确禁止。
8. **制氧机放在狭小不通风的角落**：散热不良与氧浓度积聚风险。
9. **在氧疗中长时间使用电热毯等易发热电器**：需氧环境温度升高风险高。
10. **把制氧机当加湿器或净化器**：功能不同，不能替代其他用途。
11. **自行在家吸痰**：吸痰是侵入性操作，无人指导易造成低氧、心律失常、气道黏膜损伤。
12. **只在安静时监测**：需氧状况变化常常先在活动后或夜间出现。
13. **把氧疗当成治疗慢病的药物**：氧疗是缓解缺氧的手段，不是降压、降糖的药，不能替代基础用药。

## 八、边界与免责

本技能提供居家氧疗的设备选择参考、管路耗材管理与安全核查，**不提供氧疗适应证判断、不给氧气流量数值、不给药物与雾化方案，也不提供吸痰操作参数**。**氧疗适应证与氧气流量必须由医生评估确定**；**吸痰属侵入性操作，必须由医护指导，家庭不得在无人指导的情况下自行实施**。流量调整、能否离院、能否进行手术或长途出行等，均须向医生确认。设备与管路选择、清洁消毒与感染预防的具体执行**以最新版相关指南和医护人员的指导为准**。出现呼吸困难加重、发绀、意识改变、咳血或痰量突然增多等情况，必须立即就医。
