# 氧气安全红线、流量口径与必须立即就医的情形

## 一、十条氧气安全红线（逐条落实并张贴在制氧机旁）

| 序 | 红线 | 具体要求 |
|---|---|---|
| 1 | **严禁明火与油烟** | 严禁靠近明火取暖、做饭、使用燃气灶；厨房油烟环境禁止使用 |
| 2 | **严禁吸烟** | 氧疗期间严禁吸烟，氧浓度高的环境会助燃 |
| 3 | **严禁使用打火机与明火物品** | 打火机、香烛、烟花、明火取暖设备一律远离 |
| 4 | **氧气瓶固定防倾倒** | 使用瓶装氧须固定或使用带轮底座，转运时保持直立 |
| 5 | **制氧机放在通风处** | 不放在狭小不通风的空间，保持排风口通畅不遮挡 |
| 6 | **禁止油脂润滑管路** | 不得用食用油、润滑脂处理氧气管路与接头 |
| 7 | **谨慎使用易发热电器** | 电热毯、取暖器等需氧环境下长时间使用风险高，谨慎使用 |
| 8 | **注意静电** | 干燥季节注意静电积聚，触及设备前可先触摸接地金属 |
| 9 | **远离火源物品** | 打火机、酒精灯、烟花爆烛、蚊香等一律远离 |
| 10 | **管路不弯折不压折** | 管路打折会使实际进入量远低于设定值，睡觉时尤其注意 |

**核实口径**：以上十条中的具体要求需结合设备说明与当地要求执行。**红线本身不可协商**——「小心一点」不是可接受的执行方式。

## 二、氧气流量调整口径

**硬口径：氧气流量必须遵医嘱，任何人不得自行调整，包括家属。**

| 情形 | 处理 |
|---|---|
| 觉得气不够、想调大流量 | **不自行调整**，记录症状与实际使用情况，联系医生 |
| 觉得流量太大、不舒服 | **不自行调整**，记录后联系医生 |
| 设备显示与设定不符 | 停止使用并联系维修，不自行校准 |
| 换用其他设备后感觉不同 | **不自行改为旧流量**，联系医生重新评估 |
| 医生调整了流量 | 按新医嘱执行，并更新记录表 |

**为什么不能自行调整**：氧流量与是否需要氧疗、目标氧合水平相关，**部分患者在流量过大时可能出现二氧化碳潴留加重**。是否需要吸氧、需要多少，属于医疗判断，**以最新版指南和主治医生判断为准**。本技能**不提供任何流量数值**。

## 三、雾化与吸氧同时进行时的注意

| 项 | 要求 |
|---|---|
| 同时使用的前提 | 是否可以同时进行、装置如何连接，**必须由医护指导与确认** |
| 连接方式 | 不按厂商说明之外的方式自行改装连接 |
| 使用中的观察 | 使用中持续观察呼吸与面色，出现异常立即停止并联系医护 |
| 时间安排 | 按医嘱安排雾化与吸氧的时间，不自行叠加时长 |
| 禁忌 | 严禁在氧气附近进行任何产生火花的操作 |

**口径**：**本技能不提供雾化药物、雾化剂量与连接方案**。雾化与吸氧同时进行的可行性由医生判断。

## 四、必须立即就医或呼叫急救的情形

### 立即急诊

| 情形 | 观察点 |
|---|---|
| **呼吸困难加重** | 安静状态下也气促、说话不能成句 |
| **口唇甲床发绀** | 发紫 |
| **意识改变** | 嗜睡叫不醒、烦躁、意识模糊、反应迟钝 |
| **二氧化碳潴留表现** | 晨起头痛、嗜睡、扑翼样震颤、皮肤湿冷 |
| **突发剧烈胸痛、胸闷伴大汗** | |
| **呼吸频率明显增快或减慢、节律不规则** | |
| **意识丧失后仍有呼吸但出现呼吸暂停** | 必要时呼叫急救 |
| **咳大量粉红色泡沫痰** | |
| **咳血或痰中带血** | |

### 当天就医

| 情形 | 观察点 |
|---|---|
| **发热伴痰量突然增多、变黄变稠、出现臭味** | 可能为感染加重 |
| 发热 | 明确感染征象 |
| 新出现的不适 | 头晕、乏力、心悸、明显嗜睡 |
| 实际使用量与医嘱不符 | 记录后联系医生 |
| 设备故障影响吸氧 | 先用备用设备并联系维修与医生 |

## 五、吸痰的安全边界（本技能不提供操作指导）

**硬口径：吸痰是侵入性操作，必须由医护指导，家庭不得在无人指导的情况下自行实施。**

| 风险 | 说明 |
|---|---|
| 低氧 | 吸痰过程中可能引起血氧下降 |
| 心律失常 | 迷走反射可能引起心率变化 |
| 气道黏膜损伤 | 反复或粗暴操作可损伤气道黏膜 |
| 感染 | 无菌操作不到位可带入感染 |
| 气道痉挛 | 敏感气道者可能发生痉挛 |

**家庭可做的准备工作（在医护指导下进行）**：

- 确认需要吸痰的指征由医生判断，不自行判断痰多就该吸
- 学习判断痰的性状并记录，供医生参考
- 保持呼吸道湿化与体位摆放得当，减少痰液积聚
- 备好吸引装置与无菌用品（由医护指导型号与准备方式）
- 出现红线情形立即停止并就医

**必须立即就医的吸痰相关情形**：

- 吸痰时出现剧烈呛咳
- 出现血氧下降表现
- 心率明显增快
- 吸痰管插入时遇到明显阻力（**不强行插入**）

**绝对禁止**：自行动作规范、给出吸痰深度、给出负压数值、给出单次吸痰时间上限、给出每日吸痰次数上限——这些参数必须由医护根据患者情况设定。

## 六、其他必须向医生确认的事项

| 事项 | 为什么不能自行决定 |
|---|---|
| 能否离院、外出、长途出行 | 需要评估氧需与应急能力 |
| 能否乘坐飞机 | 需按航空与医疗要求评估 |
| 能否进行手术、有无特殊情况 | 术前需氧管理方案 |
| 流量与每日使用时长调整 | 属医疗决策 |
| 雾化与吸氧能否同时进行 | 属医疗决策 |
| 是否需要增加其他监护或设备 | 属医疗决策 |

## 七、消防与应急准备

| 项 | 要求 |
|---|---|
| 灭火器 | 家中备有灭火器并知道使用方法，定期检查有效期 |
| 消防通道 | 保持疏散通道畅通 |
| 应急联系人 | 写明医生、家属、紧急联系方式并贴在制氧机旁 |
| 停电应对 | 备有备用电源或了解停电时如何联系医护；**制氧机停电后重启按说明操作** |
| 设备故障 | 事先了解维修渠道与备机安排 |

**口径**：停电时长超过设备连续供电能力、或老人依赖程度高的，**应事先与医生讨论备用氧源的必要性**，这属于医疗决策。
