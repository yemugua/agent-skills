# 设备类型、管路耗材与感染预防

**前置声明**：本表用于理解设备差异与估算耗材周期，**不提供氧疗适应证判断，不给氧气流量数值**。适应证与流量必须由医生评估确定，以最新版指南和主治医生判断为准。

## 一、四类设备对照

| 类型 | 工作方式 | 噪音 | 耗电 | 主要特点 | 选型关注点 |
|---|---|---|---|---|---|
| 分子筛制氧机 | 物理分子筛吸附分离 | 相对较高 | 较低 | 供氧量随时间衰减，需定期更换滤芯 | 出气量是否满足医嘱、衰减后如何处理、维修成本 |
| 浓缩式制氧机 | 膜分离 | 相对较低 | 中等 | 体积小、噪音低、便于移动 | 实际供氧量是否满足、连续工作时间 |
| 液氧 | 低温液态气源 | 无 | 无 | 需定期换罐或配送，罐体搬运有安全要求 | 配送稳定性、罐体存放与固定 |
| 活塞式压缩机 | 压缩后分离 | 相对较高 | 较高 | 结构较简单 | 持续供氧能力、噪音、能耗 |

**口径提醒**：**不推荐具体品牌、型号与商家**。选型应基于医嘱要求的供氧量与使用时长，与医护和专业机构确认后选择。

## 二、选购时必须确认的六项

1. 实际供氧量是否满足医嘱要求（问清在何档位下的数据）
2. 连续工作时间是否覆盖每日使用时长
3. 噪音水平是否影响老人休息与家属作息
4. 耗电与散热是否适合放置位置
5. 滤芯与常用配件的更换周期与成本
6. 维修渠道与响应速度

## 三、管路清洁与耗材周期

### 耗材与周期估算

| 耗材 | 影响周期的因素 | 周期由谁定 |
|---|---|---|
| 鼻氧管（鼻氧ifold） | 使用频率、皮肤状况、是否变形堵塞 | 产品说明与医护建议 |
| 湿化瓶 | 清洗与消毒频次、水垢情况 | 清洗规范 |
| 制氧机滤芯 | 设备累计运行时间、粉尘环境 | 产品说明 |
| 过滤棉 | 同上 | 产品说明 |
| 电源线、接头 | 使用中是否破损 | 随时检查 |

**估算方法**：

```
年更换次数 = 365 ÷ 更换周期（天）
年耗材成本 = 每件单价 × 年更换次数 × 365 天使用率的对应天数
```

**周期口径**：本表给出的是**估算方法与计算方式**，**具体更换周期以产品说明与医护建议为准**，不同产品差异很大。鼻氧管与湿化瓶属高频接触气道的耗材，务必按说明与医护建议执行，不要为了省钱延长使用。

### 湿化瓶清洁要点

| 步骤 | 要求 |
|---|---|
| 每日 | 清洗，倒掉余水，不长时间存放积水 |
| 定期 | 按说明与医护建议的频次清洗消毒 |
| 水质 | 按说明要求的水；不使用含杂质或污染的水 |
| 干燥 | 清洗后晾干再装回，避免积水 |
| 更换 | 出现变色、异味、破损立即更换 |

**禁止**：使用食用油或润滑脂处理管路；用自来水直接长时间存放而不清洗；多人共用同一湿化瓶。

### 鼻氧管护理要点

| 要点 | 说明 |
|---|---|
| 清洁 | 按说明与医护建议的频次清洁 |
| 更换 | 按周期更换，变形、堵塞、破损立即更换 |
| 佩戴 | 不压迫耳廓与鼻翼过久，避免同一点长时间受压 |
| 检查 | 每日检查是否通畅（堵塞是氧量下降的常见原因） |
| 存放 | 干燥、清洁、无弯折折角 |

## 四、感染预防要点

| 项 | 要求 |
|---|---|
| 手卫生 | 接触管路、湿化瓶、鼻氧管前后洗手；老年人协助者同样执行 |
| 口腔护理 | 每日口腔清洁，减少口咽部定植菌进入气道 |
| 管路管理 | 不多人共用；不随意改装；不共用湿化瓶 |
| 环境 | 每日通风，室内避免粉尘、烟雾、香薰与清洁剂喷雾 |
| 存放 | 管路与耗材干燥清洁保存，避免放在潮湿或阳光直射处 |
| 设备外部 | 制氧机外部定期擦拭，滤网清洁按说明执行 |
| 感染征象 | 痰量突然增多、变黄变稠、出现臭味、发热 —— 当天就医 |

**判断口径**：以上是预防要点，**是否已发生感染需要医生判断**，本技能不做感染诊断。

## 五、必须记录的内容

| 项 | 频次 | 用途 |
|---|---|---|
| 每日实际使用小时数 | 每日 | 与医嘱比对 |
| 流量设定值（按医嘱，不自行调整） | 每日 | 与医嘱比对 |
| 症状：气促程度、能说话的长短 | 每日 | 发现变化趋势 |
| 痰量与性状 | 每日 | 发现感染征象 |
| 体温 | 每日 | 发现感染 |
| 设备运行是否正常、有无异响 | 每日 | 及时报修 |
| 耗材更换日期 | 每次更换 | 避免超期 |
| 清洁与消毒执行情况 | 每日 | 确认流程落实 |
| 安全红线逐项检查 | 每月 | 防止新增火源 |

**记录口径**：流量只记录**按医嘱设定并实际使用**的值，**不自行调整**。发现实际使用量与医嘱不符时，记录并联系医生，不自行修改设定。

## 六、明确禁止的居家操作

- 自行加大氧气流量
- 靠近明火取暖或做饭
- 在氧气旁吸烟或使用打火机
- 用食用油润滑氧气管路
- 氧气瓶不固定
- 把制氧机放在通风不良的狭小空间
- 堵塞制氧机排风口
- 在氧疗中长时间使用电热毯等易发热电器
- 自行在家实施吸痰
- 自行改装管路或设备参数
