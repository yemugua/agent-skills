## 六、必须立即就医或呼叫急救（出现任一项立即执行，不等记录）

### 立即急诊

- [ ] 呼吸困难加重：安静状态下也气促、说话不能成句
- [ ] 口唇甲床发绀（发紫）
- [ ] 意识改变：嗜睡叫不醒、烦躁、意识模糊、反应迟钝
- [ ] 二氧化碳潴留表现：晨起头痛、嗜睡、扑翼样震颤、皮肤湿冷
- [ ] 突发剧烈胸痛、胸闷伴大汗
- [ ] 呼吸频率明显增快或减慢、节律不规则
- [ ] 意识丧失后仍有呼吸但出现呼吸暂停
- [ ] 咳大量粉红色泡沫痰
- [ ] 咳血或痰中带血

### 当天就医

- [ ] 发热伴痰量突然增多、变黄变稠、出现臭味
- [ ] 发热
- [ ] 新出现的不适：头晕、乏力、心悸、明显嗜睡
- [ ] 实际使用量与医嘱不符
- [ ] 设备故障影响吸氧

## 八、明确禁止的居家操作（每周回顾）

- [ ] 没有自行加大氧气流量
- [ ] 没有靠近明火取暖或做饭
- [ ] 没有在氧气旁吸烟或使用打火机
- [ ] 没有用食用油润滑管路
- [ ] 氧气瓶已固定防倾倒
- [ ] 制氧机放在通风处，排风口未堵塞
- [ ] 未在氧疗中长时间使用易发热电器
- [ ] 没有自行在家实施吸痰
- [ ] 没有自行改装管路或设备参数

**填写须知**：本表用于家庭护理流程与记录，**不提供氧疗适应证判断、不给氧气流量数值、不给吸痰操作参数**。适应证与流量必须由医生评估确定；吸痰属侵入性操作，必须由医护指导。全部医学口径以最新版相关指南和主治医生判断为准。
