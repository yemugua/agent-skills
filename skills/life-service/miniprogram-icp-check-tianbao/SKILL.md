# 小程序备案与类目资质核查

面向小程序开发者与运营：上线前自查、上架被拦要求补资质、不确定要哪些证、备案主体对不上的场景。

## 它能做什么

- 核查 **ICP 备案**：是否已完成备案、备案号格式、备案主体与小程序主体是否一致、备案状态是否正常
- 映射 **特殊类目资质**：医疗/食品/金融/直播/出版等类目需要哪些主管部门许可或证照
- 核查 **类目与页面一致性**：所选服务类目是否与实际页面内容一致
- 核查 **隐私合规**：是否配置隐私保护指引、收集个人信息是否最小必要
- 给出 **缺失项清单**：按必办/建议分级逐项列出待补材料与整改动作
- 提示 **边界**：备案与资质最终以管局与企业微信公众平台审核为准

## 使用方式

把 `templates/备案与资质采集表.md` 填好（两列表或「字段：值」），交给本技能生成报告。
未填项一律按「待补正 / 有风险」处理，绝不判通过。

## 边界

本结果依通用规则与公开参考值整理，不替代平台/管局/企业微信官方结论，最终以微信公众平台、管局备案系统与企业微信管理后台与官方文档为准。
