# 备案与隐私合规要点

## ICP 备案（强制）

- 自 2023 年起，小程序须完成 ICP 备案方可对外提供服务（未备案不能上线）。
- 备案号格式示例：`沪ICP备12345678号-1`（省份简称 + ICP备 + 编号 + 号 + 序号）。
- 备案主体须与小程序注册主体一致，不一致需变更备案或重新注册主体。
- 备案状态须为正常（已接入）；注销 / 未接入 / 未备案状态下不可用。

## 隐私保护指引（收集个人信息时强制）

- 凡收集用户个人信息（手机号、位置、相册、通讯录、昵称头像等），必须配置《隐私保护指引》。
- 仅在必要场景申请授权，不得强制授权才能使用基础功能。
- 须说明收集类型、用途、保存期限、第三方共享情况。
- 指引须同步到小程序代码（调用相关接口前弹窗告知并获同意）。

## 类目一致性

- 所选服务类目须覆盖全部页面功能；类目与页面内容不一致会被驳回。
- 类目变更后一般需重新提审。

## 边界

- 以上为通用要点，最终以管局备案系统与微信公众平台规则为准。
- 本技能不承诺备案或资质一定通过。
