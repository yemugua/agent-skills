# 质量数据统计分析（quality-data-analysis）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据质量数据统计实践，生成清单：数据类型与采集（计量/计数）、分层与帕累托分析、趋势与控制图判异、相关与回归分析、结论与改进指向。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 质量数据分析
- 质量统计
- 帕累托图
- 控制图判异
- 相关回归分析

## 三、工作流
1. 明确数据类型与采集方法
2. 做分层与帕累托找主要问题
3. 看趋势并用控制图判异
4. 用相关与回归找关系
5. 给出结论与改进指向

## 四、核心内容（检查清单与判定）
质量数据分析先用帕累托锁定少数关键问题，再用控制图判异、回归找因果；结论必须落到具体改进指向才有价值。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含数据类型与采集 | 数据 |
| Q2 | FAIL | 未含分层与帕累托分析 | 分层 |
| Q3 | WARN | 未含趋势与控制图判异 | 控制图 |
| Q4 | FAIL | 未含相关与回归分析 | 回归 |
| Q5 | WARN | 未含结论与改进指向 | 结论 |

> 脚本 `quality-data-analysis_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python quality-data-analysis_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python quality-data-analysis_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
