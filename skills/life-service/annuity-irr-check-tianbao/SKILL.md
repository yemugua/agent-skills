# 年金险挑选与内部收益率IRR核算

年金险销售页上写的是**演示利率**，你真正买的是**合同保证利益 + 一段不确定的分红**。这两者之间可以差出两三个百分点，二十年下来差一半。

这个技能做五件事：**列现金流 → 算IRR → 压测 → 拆保证与浮动 → 出结论口径**。

---

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 按给定现金流结构计算内部收益率 IRR | 承诺收益率、承诺回本、承诺「肯定不亏」 |
| 对比不同缴费期、领取期、领取额下的 IRR | 推荐具体产品、具体公司、具体计划书 |
| 拆分保证利益部分与浮动（演示）部分并分别测算 | 把演示利率说成保证收益 |
| 做领取额下调、领取年限缩短的压力测试 | 预测分红水平、分红实现率、结算利率 |
| 说明 IRR 口径与计算步骤 | 代替用户做投资决策或给个性化理财建议 |
| 提示监管口径与合同载明事项 | 提供避税筹划或把年金包装成「免税高收益」 |

涉及以下情形，应停下来交由保险公司、持牌理财顾问或律师处理：**养老年金与企业年金的具体领取方案设计、跨境保单税务处理、大额资金一次性配置的合规问题、涉及诉讼的保险合同争议**。

**绝对不做**：**不承诺收益、不把演示利率说成保证收益、不提供避税筹划**。演示利率是**假设投资收益率**，不是保证收益；保证利益以**保险合同条款载明**为准。

## 三、完整工作流

```
第 1 步  收集三样材料：保险合同/计划书、现金价值表、产品说明书
第 2 步  确认可保证利益：保证领取金额、保证领取年限、领取方式
第 3 步  读规则文件 rules/annuity-rules.md（现金流结构、IRR 口径、
        保证与演示的区分、压力测试口径、防误伤清单）
第 4 步  构造现金流：缴费期每年缴费（负值），领取期每年领取（正值）
第 5 步  取演示数字算一版 IRR（口径：演示情形下的回报率）
第 6 步  取合同保证数字算一版 IRR（口径：只按保证利益能拿到的回报率）
第 7 步  跑脚本：scripts/annuity_irr_calc.py --file case.json
第 8 步  压力测试：领取额下调、领取年限缩短、缴费期延长，各算一遍
第 9 步  与其他投资对比时，统一到同一 IRR 口径与同一期限
第 10 步 出结论与风险提示，不给「买/不买」的绝对建议
```

## 四、核心口径（必须算得出来）

### 4.1 现金流结构（算 IRR 的前提）

IRR 的输入不是一句话，是**一条完整的现金流序列**。缺任何一段，IRR 就没有意义。

```
时点定义：
  t = 1 .. N      缴费期，每年缴费 premium（现金流为负）
  t = N+1 .. N+M  领取期，每年领取 payout（现金流为正）

若为趸缴：t = 0 时一次性投入 −premium，N = 0
若期末领取（先领后退）：领取起点前移一年
若保证给付 + 非保证分红：分两条现金流分别算
```

**必须先确认的四件事**：

| 项目 | 说明 |
|---|---|
| 缴费期长度与方式 | 年缴 / 季缴 / 月缴 / 趸缴；期缴要折算到年度口径 |
| 缴费金额 | 每年实际从你账户扣走多少（不是「保费」这个抽象词） |
| 领取期长度与起点 | 从第几年开始领、一共领多少年，还是终身领取 |
| 每年领取金额 | 分「合同保证领取额」与「演示中的非保证部分」 |

### 4.2 IRR 口径（必须写清）

**内部收益率 IRR = 使未来现金流现值等于当前投入的折现率。**

```
NPV(r) = Σ [ C_t / (1 + r)^t ] = 0
其中 C_t 为第 t 年的现金流（缴费为负、领取为正）
求解使 NPV(r) = 0 的 r，即为该现金流结构的 IRR
```

| 要点 | 说明 |
|---|---|
| 符号约定 | 缴费为负、领取为正；符号写反会算出无意义的数 |
| 时点约定 | 第 t 年末现金流折现 t 年；若缴费在年初，应统一口径并注明 |
| 多解问题 | 现金流符号只变一次时通常有唯一解；符号多次变化（多次存取）时可能有多个 IRR，**必须说明并给出取舍口径** |
| 无解情况 | 全部现金流同号（只交不领）时 NPV 无法归零，**判为「无 IRR」，不得编造一个数** |
| 结果含义 | IRR 是**该现金流结构自身的年化内部回报率**，不等于你实际拿到的年化收益率，也不等于任何产品的承诺 |

### 4.3 演示利率 ≠ 保证收益（最容易出事的一节）

| 概念 | 定义 | 是不是保证的 |
|---|---|---|
| **演示利率** | 计划书用来演示不同情形下假设的投资收益率 | **不是保证的**，是**假设** |
| **合同保证利益** | 保险合同条款载明的保证给付部分 | **是保证的**，以合同载明为准 |
| **非保证利益（演示部分）** | 实际投资结果与演示假设的差额部分 | **不是保证的**，可能低于演示 |
| **实际结算** | 保险公司按实际投资情况核算并公布的结算结果 | 不是承诺，实际结果可能低于演示 |

**必须写清的三句话**：

1. **演示利率是假设的投资收益率，不是承诺，也不是保证收益。**
2. **保证领取部分以保险合同条款载明的金额与年限为准。**
3. **实际分配（结算）结果由保险公司依实际投资情况核算，可能低于演示假设。**

**绝对禁止**：把演示利率写成「收益」「回报」「保证」「承诺」，或写成「这款产品年化 3.5%」。

### 4.4 具体数字反例（演示 3.5% vs 实际 2%）

用一条固定的现金流结构做对照。**结构**：30 岁投保，缴费 10 年、每年 2 万元（合计投入 20 万元），第 11 年起每年领取、领取 20 年。

| 假设 | 每年领取额（求解得出） | 对应 IRR |
|---|---|---|
| 演示口径 3.5% | 约 16509 元 | 3.50% |
| 演示口径 2.0% | 约 13393 元 | 2.00% |

**同一套缴费，只因每年领取额从 16509 元降到 13393 元，IRR 就从 3.5% 掉到 2.0%，年化差 1.5 个百分点，二十年累计领取差约 6.2 万元。**

再看一个更极端的对照：**如果只按合同保证利益领取、领取年限从 20 年缩短到 10 年，同一条现金流的 IRR 会直接变成负数（约 −1.9%）**——因为 10 年领取总额只有约 16.5 万元，低于 20 万元投入。

**这个例子说明两件事**：

- **演示数字与保证数字的差距，可以大到让 IRR 变号**
- **只按保证利益算，IRR 可能远低于演示口径，甚至为负**

### 4.5 压力测试三档（必须做）

| 档位 | 假设 | 目的 |
|---|---|---|
| 基准档 | 按合同保证利益算 | 看最坏情况下自己的钱是什么结果 |
| 中档 | 保证利益 + 演示假设 | 看计划书口径 |
| 压力档 | 演示部分按明显低于假设的水平下调（如演示 3.5% 按 2% 甚至更低试算） | 看假设落空时的影响 |

**必须同时输出**：每档的 IRR、累计领取总额、相对累计投入的差额。

**不得只给中档**。只给演示口径的 IRR，等于替保险公司背书假设。

### 4.6 与其他投资对比的统一口径

年金险 IRR 要和存款、国债、基金比，必须先统一：

| 统一项 | 要求 |
|---|---|
| 期限 | 同一段现金流期限，不能拿 10 年期年金比 1 年期存款 |
| 流动性 | 年金中途退保会损失本金（**退保损失以合同载明的现金价值表为准**），其他投资可以随时取 |
| 税收 | **不把年金包装成免税高收益**；涉及税负问题，**以现行规定和金融监管部门口径为准** |
| 风险等级 | 年金有约定的保证给付部分，其他投资的净值会波动 |
| 通胀 | 长期现金流要考虑购买力变化，**不得用名义 IRR 直接宣称划算** |

## 五、核心规则与要件库

出结论前，**必须先读**：

- `rules/annuity-rules.md`：现金流结构构造、IRR 口径与多解处理、演示与保证的区分、领取方式（保证领取 / 终身领取 / 一次性领取）差异、压力测试口径、跨产品对比统一口径、防误伤（否定词）清单。

**不得凭计划书演示数字直接下收益结论**；**不得把演示利率写成保证收益**；**不得在现金流不全时硬算 IRR**；**不得推荐具体产品或公司**。

## 六、脚本用法

```bash
python scripts/annuity_irr_calc.py --file case.json --out 年金险IRR核算.md
python scripts/annuity_irr_calc.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：缴费期、每年缴费额、领取起始年、领取年限、每年领取额（保证）、演示部分的年度增量列表等 |
| `--text` | 直接给 JSON 字符串 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检 |

输入 JSON 示例：

```json
{
  "pay_years": 10,
  "annual_premium": 20000,
  "payout_start_year": 11,
  "payout_years": 20,
  "guaranteed_annual_payout": 13000,
  "illustrated_annual_payout": 16509,
  "stress_annual_payout": 12000,
  "single_premium": 0
}
```

脚本输出：累计投入、保证口径 IRR、演示口径 IRR、压力口径 IRR、三档累计领取总额与差额、领取额每下调 10% 对 IRR 的影响、IRR 多解或无解的判定、以及必须以合同载明为准的事项清单。

> 脚本按你填的现金流做**静态测算**。演示利率是**假设投资收益率，不是保证收益**；保证利益以保险合同条款载明为准；实际结算以保险公司公布为准。脚本不预测分红、不判断产品好坏、不给投资建议。

## 七、人工确认清单（这步不能省）

- [ ] **缴费期长度与缴费方式**取自合同，不是听销售说的
- [ ] 缴费金额是**实际扣款额**，含首期与续期，不是「保费」的估值
- [ ] **领取起始年与领取年限**取自合同条款（保证领取年限与演示领取年限要分开看）
- [ ] **保证领取额**取自合同载明的数字，不是计划书上的演示数字
- [ ] 演示数字与保证数字**已经分开记录**，没有被混在一个「每年领多少」里
- [ ] 已确认领取方式：保证领取期结束后如何处理（继续领取 / 转为满期给付 / 终止）
- [ ] 缴费期内退保的**现金价值**已查（**以合同载明的现金价值表为准**）
- [ ] 至少做了一档**低于演示假设**的压力测试
- [ ] 与其他投资对比时，**期限、流动性、税收口径已统一**
- [ ] 结论里没有出现「保证收益」「承诺收益」这类表述
- [ ] 涉及税务的问题，已确认**以现行规定和金融监管部门口径为准**，未被当作免税安排

## 八、最常见的坑

1. **把演示利率当成收益率来比较。** 演示利率是**假设投资收益率**，不是保证收益。拿它去和存款或国债比，比的其实是「一个假设」对「一个确定的数字」。
2. **现金流结构没说清就报 IRR。** 只给「每年领 2 万、领 20 年」就开始算，**不问缴了多少、交了几年**，算出来的数没有意义。IRR 的输入必须是一条完整的现金流。
3. **漏掉缴费期。** 只把领取当收益、不把缴费当投入，IRR 会被算成极高的假数。
4. **只给中档，不给保证档。** 只按演示假设算 IRR，等于替保险公司的假设背书。**必须同时给出只按合同保证利益算的那一版**。
5. **忽略领取年限。** 同样每年领 13393 元，领 20 年和领 10 年是两种完全不同的产品。**本例中领 10 年的 IRR 直接变成负数**。
6. **把趸缴和期缴混着比。** 趸缴是一笔大额现金流，期缴是每年小额流出，IRR 的口径完全不同。要比就必须统一期限和现金流形态。
7. **忽略中途退保的损失。** 缴费期内退保只能拿现金价值，**现金价值以合同载明的现金价值表为准**，前期可能远低于已交保费。IRR 再高，中途退保拿不回本金。
8. **看到「保证领取」四个字就以为终身有收益。** 保证领取通常有**年限上限**；保证期结束后怎么办，要看条款约定。
9. **把非保证部分当成本金安全垫。** 演示与实际结算的差额部分**没有任何下限承诺**，可能为零。
10. **用名义 IRR 直接宣称「划算」。** 三十年后的 2 万元和今天的两万元不是一回事。长期现金流必须考虑通胀，**不得用名义 IRR 直接下划算与否的结论**。
11. **忘记现金流符号只变一次这条前提。** 中途有多次存取时，IRR 可能出现多个解。**遇到多解要说明并给出口径，不能随便挑一个报出去。**

## 九、边界与免责

- 本技能用于年金险现金流测算与口径梳理，**不构成投资建议、保险代理或法律意见**，不替代保险合同的约定
- **演示利率是假设的投资收益率，不是保证收益**；**保证利益以保险合同条款载明为准**；**实际结算以保险公司公布为准**
- 缴费期、领取期、领取金额、领取方式、保证领取年限，**均以保险合同条款与产品说明书载明为准**，不同产品差异很大，不得互相套用
- 本测算为**静态口径**，未含身故给付、满期给付、保单贷款、加保、减保、缴费宽限期、红利再投资方式选择等情形
- **不承诺收益、不承诺回本、不承诺不亏**；不预测分红实现率与结算利率；不推荐具体保险公司与具体产品
- 不提供避税筹划；涉及税收的问题**以现行规定和金融监管部门口径为准**
- 中途退保损失**以合同载明的现金价值表为准**；犹豫期天数**以合同约定为准**
