# 年金险现金流与 IRR 规则库

> 本规则库按长期人身保险年金类产品的常见结构整理。**演示利率是假设投资收益率，不是保证收益**；保证利益以保险合同条款载明为准；实际结算以保险公司公布为准。本库不预测分红、不推荐产品、不承诺收益。

---

## 一、现金流结构构造

### 1.1 基本形态

```
期缴年金：
  t = 1 .. N          C_t = −premium        （每年缴费，负值）
  t = N+1 .. N+M      C_t = +payout         （每年领取，正值）

趸缴年金：
  t = 0               C_0 = −single_premium
  t = 1 .. M          C_t = +payout
```

| 项目 | 必须确认 |
|---|---|
| 缴费期长度 N | 以合同载明为准 |
| 缴费方式 | 年缴 / 季缴 / 月缴 / 趸缴；**非年度缴费须折算到年度口径后再计算** |
| 缴费金额 | **实际扣款额**，不是保单上「保费」这个标签 |
| 领取起始时点 | 第几年开始领；先领后退时起点前移 |
| 领取年限 M | 保证领取年限与演示领取年限**必须分开记录** |
| 领取方式 | 保证领取期结束后如何处理（继续领取 / 转为满期给付 / 终止） |

### 1.2 常见领取方式

| 方式 | 现金流特征 | 核查重点 |
|---|---|---|
| 保证领取 + 可继续领取 | 保证期内固定领取额，保证期后按合同约定 | 保证期结束后怎么办，条款怎么写 |
| 终身领取 | 领取年限不确定，用生命周期或固定年限近似 | 演示假设对长期领取的影响极大 |
| 一次性/满期给付 | 到期一次性给付 | 现金流时点与折现年份 |
| 固定年金 | 每年固定领取额、领取年限固定 | 结构最简单，也最容易被演示数字放大 |

**口径要求**：终身领取类的现金流必须说明近似方式（按合同约定的保证期、或按某一假设年限），**不得直接把演示领取额当成终身确定金额**。

### 1.3 保证与演示的拆分

```
每年领取额 = 合同保证领取额 + 非保证（演示）部分

保证口径现金流：C_t = +guaranteed_payout
演示口径现金流：C_t = +guaranteed_payout + illustrated_extra
压力口径现金流：C_t = +stress_payout（低于演示假设）
```

**两版 IRR 必须分别输出**：只按保证利益算的那一版，是判断「最坏情况下会怎样」的唯一依据。

## 二、IRR 口径

### 2.1 定义

**内部收益率 IRR = 使未来现金流现值等于当前投入的折现率。**

```
NPV(r) = Σ [ C_t / (1 + r)^t ]
求解 NPV(r) = 0 的 r
```

| 要点 | 口径 |
|---|---|
| 符号 | 缴费为负、领取为正。**符号写反会算出无意义的数** |
| 时点 | 第 t 年末现金流折现 t 年。缴费在年初的，须统一口径并在结论中注明 |
| 唯一解 | 现金流符号只变一次时通常有唯一解 |
| 多解 | 符号多次变化（多次存取）时可能有多个 IRR。**必须说明存在多解并给出取舍口径，不能随便挑一个报出去** |
| 无解 | 全部现金流同号（只交不领）时 NPV 无法归零，**判为「无 IRR」，不得编造一个数** |
| 含义 | IRR 是**该现金流结构自身的年化内部回报率**，不等于承诺收益，也不等于实际到手年化收益率 |

### 2.2 求解方法

用二分法在合理区间内求解：先在低利率与高利率两端算 NPV，若两端同号则无解；异号则在区间内二分，逐次收窄。

**数值安全**：高利率下长时间折现可能溢出，计算时须对分母做上限保护，越界按无解处理。

### 2.3 结果解读纪律

| 可以写 | 不能写 |
|---|---|
| 「该现金流结构的 IRR 约为 X%」 | 「这款产品年化收益 X%」 |
| 「保证口径下 IRR 约为 X%」 | 「保证收益 X%」 |
| 「演示假设成立时 IRR 约为 X%」 | 「收益率 X%，稳赚」 |
| 「压力情形下 IRR 约为 X%」 | 「最差也有 X%」 |
| 「IRR 为负，说明该现金流结构下投入大于领取」 | 「买了就亏」 |

## 三、演示利率与保证收益

### 3.1 概念对照

| 概念 | 定义 | 是否保证 |
|---|---|---|
| **演示利率** | 计划书用来演示不同情形下**假设**的投资收益率 | **不保证**，是假设 |
| **合同保证利益** | 保险合同条款载明的保证给付部分 | **保证**，以合同载明为准 |
| **非保证利益** | 实际投资结果与演示假设的差额部分 | **不保证**，可能低于演示 |
| **实际结算** | 保险公司按实际投资情况核算并公布的结果 | 非承诺，可能低于演示 |

### 3.2 表述纪律

**必须写清的三句话**：

1. 演示利率是**假设的投资收益率**，不是承诺，也不是保证收益。
2. 保证领取部分以**保险合同条款载明的金额与年限**为准。
3. 实际分配（结算）结果由保险公司依实际投资情况核算，**可能低于演示假设**。

**绝对禁止的写法**：

- 把演示利率写成「收益」「回报」「保证」「承诺」
- 写「这款产品年化 3.5%」
- 写「保底 3.5%」除非合同条款明确载明该保证
- 把非保证部分说成本金安全垫

### 3.3 具体反例（同一现金流结构的三档结果）

**结构**：30 岁投保，缴费 10 年、每年 2 万元（累计投入 20 万元），第 11 年起每年领取、领取 20 年。

| 假设 | 每年领取额 | 对应 IRR | 20 年累计领取 |
|---|---|---|---|
| 演示口径 3.5% | 约 16509 元 | 3.50% | 约 330173 元 |
| 演示口径 2.0% | 约 13393 元 | 2.00% | 约 267860 元 |

**演示 3.5% 与实际 2% 的差距**：年化差 **1.5 个百分点**，20 年累计领取差约 **6.2 万元**。

**更极端的一档**：若只按保证利益领取、且保证领取年限只有 10 年（每年 13393 元），累计领取约 16.5 万元 < 投入 20 万元，**IRR 变为负数（约 −1.9%）**。

**这个反例证明两件事**：

1. 演示数字与保证数字的差距，可以大到让 IRR 变号
2. 只按保证利益算，**IRR 可能远低于演示口径，甚至为负**

## 四、压力测试

| 档位 | 假设 | 用途 |
|---|---|---|
| 基准档 | 只按合同保证利益算 | 看最坏情况下自己的钱是什么结果 |
| 中档 | 保证利益 + 演示假设 | 对应计划书口径 |
| 压力档 | 演示部分按明显低于假设的水平下调 | 看假设落空时的影响 |

**每档必须输出**：IRR、累计领取总额、相对累计投入的差额。

**弹性测度**：领取额每下调 10%，IRR 变化多少个百分点。弹性越大，说明该结构对假设越敏感。

**不得只给中档。** 只给演示口径的 IRR，等于替保险公司的假设背书。

## 五、与其他投资对比的统一口径

| 统一项 | 要求 |
|---|---|
| 期限 | 同一段现金流期限。**不得拿 10 年期年金比 1 年期存款** |
| 流动性 | 年金中途退保有损失（**退保损失以合同载明的现金价值表为准**），其他投资可能随时可取 |
| 税收 | **不把年金包装成免税高收益**。涉及税负问题**以现行规定和金融监管部门口径为准** |
| 风险等级 | 年金有合同保证给付部分，其他投资的净值会波动 |
| 通胀 | **不得用名义 IRR 直接宣称划算**。长期现金流要考虑购买力变化 |

## 六、现金价值与退保口径

| 项目 | 口径 |
|---|---|
| 缴费期内退保 | 只能拿**合同载明的现金价值表**对应保单年度的金额，**前期可能远低于已交保费** |
| 犹豫期内退保 | 退还范围**以合同约定为准**，可能扣除合同约定的费用 |
| 犹豫期外退保 | 按现金价值表，**退保损失 = 已交保费 − 现金价值** |
| 保证给付与现金价值的关系 | **保证给付 ≠ 现金价值**，两者是不同口径，不能互相替代 |
| 犹豫期天数 | **以合同约定为准** |

## 七、防误伤（否定词）清单

| 见到这些情况 | 必须这样判 | 严禁这样写 |
|---|---|---|
| 演示利率 3.5% | 判为**假设投资收益率，非保证** | 「收益 3.5%」「保证 3.5%」 |
| 合同载明的保证利益 | 判为**保证，口径以合同载明为准** | 「演示说的那些也保证」 |
| 非保证部分 | 判为**非保证，可能低于演示** | 「至少也能拿到演示数」 |
| 现金流符号只变一次 | 可求唯一解 | 不检查就报数 |
| 现金流符号多次变化 | 判为**可能多解，须说明取舍口径** | 随便挑一个解 |
| 只交不领 | 判为**无 IRR** | 硬编一个数 |
| 中途退保 | 判为**按现金价值表，损失以合同载明为准** | 「退保能拿回全部」 |
| 未退保 | 判为**未退保** | 「已退保」 |
| 未如实告知 | 判为**可能导致不承担给付责任** | 「已如实告知」 |
| 「保本」「稳赚」「一定不亏」 | 判为**违规表述，不采用** | 照抄进结论 |
| 「免税」 | 判为**不得包装成免税安排**，涉税以现行规定与监管口径为准 | 「这是免税的」 |

---

## 八、免责

本规则库为投保实践整理，**不构成投资建议、保险代理或法律意见**。演示利率是**假设的投资收益率，不是保证收益**；保证利益**以保险合同条款载明为准**；实际结算**以保险公司公布为准**；缴费期、领取期、领取金额、领取方式与保证领取年限**均以合同条款与产品说明书为准**；现金价值**以合同载明的现金价值表为准**；犹豫期天数**以合同约定为准**。不预测分红，不推荐具体产品，不承诺收益，涉及税收与监管的事项**以现行规定和金融监管部门口径为准**。
