# 员工敬业度调研（employee-engagement）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据敬业度调研方法论，生成清单：调研维度与问卷设计（薪酬/发展/管理/文化）、量表与样本代表性、匿名与保密机制、数据分析与驱动因素识别、改进行动计划与跟踪。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 员工敬业度
- 敬业度调研
- 员工满意度调研
- 组织氛围
- 敬业度问卷

## 三、工作流
1. 设计调研维度与问卷
2. 确定量表与样本代表性
3. 落实匿名与保密机制
4. 分析数据识别驱动因素
5. 制定改进行动并跟踪

## 四、核心内容（检查清单与判定）
敬业度调研应维度清晰、样本有代表性并保障匿名；关键在于识别驱动因素并转化为可跟踪的改进行动，而非只看分数。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含调研维度与问卷设计 | 维度 |
| Q2 | FAIL | 未含量表与样本代表性 | 样本 |
| Q3 | WARN | 未含匿名与保密机制 | 匿名 |
| Q4 | FAIL | 未含数据分析与驱动因素 | 分析 |
| Q5 | WARN | 未含改进行动与跟踪 | 行动 |

> 脚本 `employee-engagement_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python employee-engagement_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python employee-engagement_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
