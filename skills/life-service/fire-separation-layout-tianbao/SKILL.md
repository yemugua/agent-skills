# 防火间距与总平面布局（fire-separation-layout）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《建筑设计防火规范》GB 50016，生成防火间距与总平面布局核查清单：建筑之间防火间距、与储罐堆场及明火地点间距、总平面功能分区、防火间距不足的补偿措施、核查留痕。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 防火间距
- 总平面布局
- 建筑间距
- 防火间距不足
- 厂区总平面

## 三、工作流
1. 核实建筑之间的防火间距
2. 核查与储罐堆场及明火地点间距
3. 梳理总平面功能分区
4. 确定间距不足的补偿措施
5. 形成核查记录与留痕

## 四、核心内容（检查清单与判定）
GB 50016 按建筑耐火等级与用途规定防火间距；间距不足时可采用防火墙、不开门窗洞口等措施补偿，须有依据并留痕。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含建筑之间防火间距 | 间距 |
| Q2 | FAIL | 未含与储罐堆场及明火地点间距 | 危险间距 |
| Q3 | WARN | 未含总平面功能分区 | 布局 |
| Q4 | FAIL | 未含间距不足的补偿措施 | 补偿 |
| Q5 | WARN | 未含核查记录与留痕 | 留痕 |

> 脚本 `fire-separation-layout_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python fire-separation-layout_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python fire-separation-layout_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
