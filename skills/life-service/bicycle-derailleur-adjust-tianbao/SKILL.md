# 自行车变速调整与跳链处理（bicycle-derailleur-adjust）

跳链，**绝大多数不是变速没调好，是链条和飞轮磨损了**。这两类问题的解法完全不同：磨损要换件，调校要动手。混在一起调限位螺丝，怎么调都调不好。

这个技能做四件事：**量磨损** → **分类型** → **按序调** → **试骑验**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 判断是磨损还是调校问题 | ❌ 认定"跳链就是变速没调好" |
| 给出限位螺丝与张力的调整顺序 | ❌ 判断尾钩变形、后拨本体损坏的修复方案 |
| 说明链条磨损的判定方法 | ❌ 建议用蛮力扳动碳纤维部件 |
| 提示碳纤维扭力与刹车污染红线 | ❌ 替代车店的轮组校正与中轴维修 |
| 给出试骑验收清单 | ❌ 保证调完一定能解决所有异响 |

**遇到以下情况，立即停止自行操作，转交车店或专业技师：**

- 链条伸长超限（需换链条，**且可能要同时换飞轮**）
- 后拨或尾钩明显变形、曾摔车或后拨被撞过
- 内走线车架需要重新穿线
- 碳纤维车架与零部件（**必须按厂商标称扭力值**，凭手感极易拧裂）
- 液压刹车相关工作、中轴异响、轮组偏摆与辐条问题
- 电变系统（电子变速）故障，先查电量与连接，不要当机械问题拆

**永远不要让链条油沾到刹车盘、来令片或轮胎胎面。** 刹车一旦被油污染，制动力会大幅下降，属严重安全隐患。

## 二、完整工作流

```
第 1 步  清洁并润滑链条，先看链条有没有死节与锈蚀
第 2 步  量链条磨损（链条尺或 12 节拉长量），超限就换链
第 3 步  先读规则文件 rules/bicycle_derailleur_rules.md（磨损判定 + 调整顺序 + 红线）
第 4 步  跑故障树脚本
    python scripts/bicycle_derailleur_check.py --text "换了新链条还是跳齿，踩重了就打滑"
第 5 步  按"限位 → 张力 → B 张力"的顺序调后拨，再调前拨
第 6 步  低速空旷处试骑，逐档验证，注意后方安全
```

## 三、先量磨损（这步决定要不要调）

**链条伸长判定**：用链条尺最准；没有链条尺时，量 12 节链条的长度：

| 12 节实测长度 | 状态 | 处置 |
|---|---|---|
| 约 304.8mm（12 英寸） | 正常 | 继续用 |
| 超过约 307mm | 磨损超限 | 换链条，并检查飞轮 |
| 明显超过 307mm | 严重磨损 | 换链条 + 大概率要换飞轮 |

> 磨损的链条会**加速磨损飞轮与牙盘**。拖着不换，最后要换的是整套传动。

**关键认知**：**换了新链条仍然跳齿，说明飞轮已经被旧链条磨出形状了**。这是最常见的"换了链条没解决问题"的原因，需要同时换飞轮。

---

## 四、后拨调整顺序（顺序不能乱）

| 步骤 | 调整项 | 作用 | 调错的表现 |
|---|---|---|---|
| 1 | H 限位螺丝 | 限制链条不能掉到最小飞轮外侧 | 掉链到飞轮与车架之间 |
| 2 | L 限位螺丝 | 限制链条不能掉到最大飞轮内侧 | 后拨碰辐条 |
| 3 | 拉线张力（微调筒） | 决定换档是否到位 | 上不去或下不来 |
| 4 | B 张力螺丝 | 导轮与飞轮的间距 | 大飞轮时导轮顶齿有异响 |

**判别口诀**：
- 上不去大飞轮（踩着费力那侧）→ 张力不足，微调筒逆时针旋出增加张力
- 下不来小飞轮（轻的那侧）→ 张力过大，微调筒顺时针旋入减少张力
- 掉链到外侧 → H 限位；掉到内侧碰辐条 → L 限位

**限位螺丝不解决换档精度**，精度靠拉线张力。这是最容易搞混的一点。

---

## 五、前拨调整要点

| 调整项 | 标准 |
|---|---|
| 高度 | 导板底边距牙盘齿尖约 1-3mm |
| 角度 | 导板与牙盘平面平行 |
| L 限位 | 链条在最小牙盘时，内侧导板不蹭链 |
| H 限位 | 链条在最大牙盘时，外侧导板不蹭链 |
| 拉线张力 | 上不去大盘加张力，下不来小盘减张力 |

**掉链判断**：链条掉到牙盘**外侧**（脚踩那侧）→ H 限位问题；掉到**内侧**（车架五通处）→ L 限位问题。

## 六、跳链与蹭链原因对照

| 现象 | 最可能原因 | 处置 |
|---|---|---|
| 踩重时跳齿打滑 | 链条与飞轮磨损 | 换链条，必要时同时换飞轮 |
| 换了新链条仍跳 | 飞轮已磨损 | 同时换飞轮 |
| 只在某一档跳 | 该飞轮片磨损 | 换飞轮 |
| 链条死节（关节僵硬） | 链条缺油或锈蚀 | 除锈润滑，严重则换链 |
| 变速后持续异响 | 蹭前拨导板 | 调前拨角度与限位 |
| 后拨碰辐条 | L 限位或尾钩变形 | 调限位，变形送车店 |
| 上不去大飞轮 | 张力不足或 L 限位过紧 | 加张力 |
| 下不来小飞轮 | 张力过大 | 减张力 |

## 七、脚本用法

```bash
python scripts/bicycle_derailleur_check.py --text "换了新链条还是跳齿，踩重了就打滑"
python scripts/bicycle_derailleur_check.py --file 描述.txt --out 结果.md
```

| 参数 | 说明 |
|---|---|
| `--text` | 直接给现象描述 |
| `--file` | 从文件读描述 |
| `--out` | 结果落盘路径 |
| `--format` | `md`（默认）或 `json` |
| `--chain` | 12 节链条实测长度（毫米），用于判断磨损 |
| `--selftest` | 跑内置样例自检 |

给了 `--chain` 时会直接给出磨损判定。**脚本只做关键词匹配与简单换算，不代表现场判断。**

## 八、人工确认清单（这步不能省）

- [ ] 链条磨损量过，不是目测
- [ ] 换过链条的话，确认飞轮有没有同时检查
- [ ] 限位螺丝先调、张力后调，顺序没乱
- [ ] 各档位逐档试过，没有只在某一档跳
- [ ] 链条油没有沾到刹车盘、来令片与胎面
- [ ] 碳纤维件按扭力值拧过，没有凭手感
- [ ] 试骑在低速空旷处进行，注意后方

---

## 九、最常见的坑

**坑一：跳链就调限位螺丝。**
限位螺丝只管掉不掉链，不管跳不跳齿。踩重时跳齿基本都是磨损。

**坑二：换了新链条还跳，就以为新链条有问题。**
是飞轮被旧链条磨出了形状，要同时换飞轮。这是最常见的二次返工。

**坑三：拖着磨损链条不换。**
磨损链条会加速磨损飞轮与牙盘，最后从"换链条"变成"换整套传动"。

**坑四：链条油加太多。**
多余油会吸灰变成研磨膏，加速磨损。上油后要擦掉表面多余的油。

**坑五：链条油沾到刹车。**
刹车盘与来令片被油污染后制动力大幅下降，属严重安全隐患。

**坑六：碳纤维件凭手感拧紧。**
碳纤维过紧会开裂，必须按厂商标称扭力值用扭力扳手。

**坑七：尾钩变形当调校问题。**
摔过车或被撞过的后拨，调限位没用，需要校正或更换尾钩。

**坑八：电变没反应就拆机械部分。**
电子变速先看电池电量与连接状态，不要当机械故障处理。

**坑九：调完不试骑。**
必须在低速空旷处逐档验证，静态调得再准也要动态确认。

## 十、边界与免责

- 本技能**不替代**车店维修、部件更换与轮组校正
- 变速系统品牌与规格差异大，**以产品说明书与厂商标称值为准**
- 碳纤维零部件**必须按厂商标称扭力值**操作，凭手感有开裂风险
- 涉及液压刹车、内走线、尾钩校正、中轴与轮组的，应由车店处理
- **链条油不得污染刹车盘、来令片与轮胎胎面**，否则制动失效
