# 自行车变速调整与跳链处理规则

## 一、判定总原则

1. **先量磨损，后调螺丝。** 磨损与调校是两类问题，混在一起调不出结果。
2. **限位先于张力。** 限位管掉不掉链，张力管准不准。
3. **换新链条要同时检查飞轮。** 只换链不换磨损飞轮必然二次返工。
4. **碳纤维按扭力值，不凭手感。** 过紧会开裂。
5. **链条油不得污染刹车。** 制动失效属严重安全隐患。

---

## 二、链条磨损判定

| 12 节实测长度 | 状态 | 处置 |
|---|---|---|
| 约 304.8mm（12 英寸） | 正常 | 继续用 |
| 超过约 307mm | 磨损超限 | 换链条并检查飞轮 |
| 明显超过 307mm | 严重磨损 | 换链条 + 大概率换飞轮 |

- 用链条尺最准，没有链条尺时量 12 节长度
- 磨损链条会加速磨损飞轮与牙盘，拖延会从换链条变成换整套传动
- **换新链条仍跳齿，说明飞轮已被磨出形状，需同时换飞轮**

---

## 三、后拨调整顺序（不可乱）

| 步骤 | 调整项 | 作用 | 调错表现 |
|---|---|---|---|
| 1 | H 限位螺丝 | 限制链条不掉到最小飞轮外侧 | 掉链到飞轮与车架之间 |
| 2 | L 限位螺丝 | 限制链条不掉到最大飞轮内侧 | 后拨碰辐条 |
| 3 | 拉线张力（微调筒） | 决定换档是否到位 | 上不去或下不来 |
| 4 | B 张力螺丝 | 导轮与飞轮间距 | 大飞轮时导轮顶齿异响 |

### 判别口诀

- 上不去大飞轮（费力侧）→ 张力不足，微调筒逆时针旋出
- 下不来小飞轮（轻侧）→ 张力过大，微调筒顺时针旋入
- 掉链到外侧 → H 限位
- 掉到内侧碰辐条 → L 限位

**限位螺丝不解决换档精度**，精度靠拉线张力。

---

## 四、前拨调整要点

| 调整项 | 标准 |
|---|---|
| 高度 | 导板底边距牙盘齿尖约 1-3mm |
| 角度 | 导板与牙盘平面平行 |
| L 限位 | 最小牙盘时内侧导板不蹭链 |
| H 限位 | 最大牙盘时外侧导板不蹭链 |
| 拉线张力 | 上不去大盘加张力，下不来小盘减张力 |

**掉链判断**：掉到牙盘外侧（脚踩侧）→ H 限位；掉到内侧（五通处）→ L 限位。

## 五、跳链与蹭链原因对照表

| 现象 | 最可能原因 | 处置 |
|---|---|---|
| 踩重时跳齿打滑 | 链条与飞轮磨损 | 换链条，必要时同时换飞轮 |
| 换了新链条仍跳 | 飞轮已磨损 | 同时换飞轮 |
| 只在某一档跳 | 该飞轮片磨损 | 换飞轮 |
| 链条死节（关节僵硬） | 链条缺油或锈蚀 | 除锈润滑，严重则换链 |
| 变速后持续异响 | 蹭前拨导板 | 调前拨角度与限位 |
| 后拨碰辐条 | L 限位或尾钩变形 | 调限位，变形送车店 |
| 上不去大飞轮 | 张力不足或 L 限位过紧 | 加张力 |
| 下不来小飞轮 | 张力过大 | 减张力 |
| 电变无反应 | 电量或连接问题 | 先查电量与连接，不要当机械问题拆 |

## 六、故障树（按处理顺序）

| 顺序 | 原因 | 判定 | 验证动作 | 处置 |
|---|---|---|---|---|
| 1 | 链条磨损超限 | 12 节超 307mm | 链条尺或尺量 | 换链条并检查飞轮 |
| 2 | 飞轮磨损 | 换新链条后仍跳 | 观察飞轮齿形是否变尖 | 同时换飞轮 |
| 3 | 链条死节或锈蚀 | 转动时某节卡顿 | 逐节检查链条 | 除锈润滑或换链 |
| 4 | 限位螺丝不当 | 掉链或碰辐条 | 看掉链方向 | 调对应限位螺丝 |
| 5 | 拉线张力不当 | 换档不到位 | 逐档试换 | 调微调筒 |
| 6 | 线管阻力或内线断股 | 手感发涩、换档迟滞 | 检查线管与内线 | 换线管与内线 |
| 7 | 前拨位置或角度不当 | 蹭链 | 看导板与牙盘间距 | 调高度与角度 |
| 8 | 尾钩变形 | 摔过车、后拨歪 | 从后方看后拨是否垂直 | 送车店校正或更换 |
| 9 | 电变系统问题 | 电变无反应 | 查电量与连接 | 先查电，再谈机械 |

## 八、安全红线（必须停用并送车店）

| 情形 | 处置 |
|---|---|
| 链条伸长超限 | 换链条并检查飞轮，车店处理更稳妥 |
| 后拨或尾钩明显变形 | 送车店校正或更换尾钩 |
| 内走线车架需重新穿线 | 送车店 |
| 碳纤维车架与零部件 | 必须按厂商标称扭力值，建议车店操作 |
| 液压刹车相关 | 送车店 |
| 中轴异响、轮组偏摆、辐条问题 | 送车店 |
| 电变系统故障 | 先查电量与连接，仍异常送车店 |

**禁止事项：**

- 禁止让链条油沾到刹车盘、来令片与轮胎胎面（制动失效）
- 禁止凭手感拧紧碳纤维件（开裂风险）
- 禁止用蛮力扳动碳纤维前拨与座管
- 禁止在骑行途中低头调整变速
- 禁止在有人车通行的路段高速试骑

## 九、常见误判清单（反向判断）

| 现象 | 常见误判 | 正确判断 |
|---|---|---|
| 踩重跳齿 | 变速没调好 | 多为链条与飞轮磨损 |
| 换新链条仍跳 | 新链条有问题 | 飞轮已被旧链条磨出形状，需同时换 |
| 只在某一档跳 | 全局调校问题 | 该飞轮片磨损 |
| 上不去大飞 | 限位坏了 | 多为拉线张力不足 |
| 后拨碰辐条 | 后拨坏了 | 多为 L 限位未调好或尾钩变形 |
| 变速异响 | 限位问题 | 多为蹭前拨导板，查角度与高度 |
| 链条掉外侧 | 链条太长 | 查前拨 H 限位 |
| 电变无反应 | 机械故障 | 先查电量与蓝牙连接 |
| 上油越多越好 | 保养到位 | 多余油会吸灰加速磨损，应擦净 |

---

## 十、试骑验收标准

| 项目 | 合格标准 |
|---|---|
| 逐档换档 | 每一档都能到位，无迟滞无掉链 |
| 踩重测试 | 大力踩踏时不跳齿、不打滑 |
| 蹭链 | 任何档位都没有持续的金属摩擦声 |
| 限位 | 最大与最小飞轮均不掉链、不碰辐条 |
| 刹车 | 制动力正常（确认未被链条油污染） |

试骑必须在低速空旷处进行，注意后方来车与行人。
