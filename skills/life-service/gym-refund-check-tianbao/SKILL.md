# 健身房退卡退费核算

健身卡退费的核心争议只有一个：**已消耗的部分按什么价算**。门店一定主张按挂牌原价，你应当主张按**优惠后（会员）单价**。这一步差出来的往往是几千块。

## 什么时候用

- 办的健身卡不想用了，门店说"概不退费"
- 门店关门、跑路、转让后新老板不认旧卡
- 迁址到很远的地方，去不了了
- 承诺的私教换了人、课程永远约不上
- 身体原因不能再练，想退剩余费用
- 刚办卡几天就后悔，想走冷静期全额退

## 怎么做

**第 1 步**：复制 `templates/健身房退卡信息采集表.md` 填写。

**第 2 步**：跑脚本

```bash
python scripts/gym_refund_check.py 采集表.md --base 2026-10-05 --out 核查报告.md
```

**第 3 步**：按第九段"待办补正动作"执行，谈判时直接把第六段的算式甩过去。

## 能不能退：一句话结论

**能退。** 健身卡属于单用途商业预付卡，受商务主管部门的单用途商业预付卡管理规定规范（实名、资金存管、退卡规则），**不是"买了就不能退"**。合同里写"概不退费""最终解释权归本店"的，属于经营者以格式条款作出排除或者限制消费者权利、减轻或者免除经营者责任、加重消费者责任等对消费者不公平、不合理的规定，**该条款无效**。

## 退费怎么算

```
应退 = 实付总额 − 已消耗价值 − 合理违约金
```

- 已消耗价值按**优惠后（会员）单价**折算，**不按门店挂牌原价**
- 赠送课时、赠送期限一般不折算现金，但可按比例摊薄单价
- 违约金以**实际损失**为限，经营者须举证；司法实践常见上限参考为未履行部分的 20%~30%

## 四条最容易被忽略的规则

1. **"概不退费"无效**，但不能只凭这一句就要求全额退——已享受的服务要按会员价扣。
2. **冷静期看地方**：上海、北京等地对体育健身消费有 7 日内未消费可全额退款的规定或行业指引，**以当地规定为准**。
3. **门店跑路不是没辙**：预付卡资金存管与经营者清算义务仍在，可走商务主管部门 + 集体维权。
4. **分期贷是另一个坑**：商家跑路不当然免除你的还款义务，贷款要单独处理。

## 边界与纪律

- 依《消费者权益保护法》及商务主管部门单用途商业预付卡管理相关规定等**通用规则**整理，**不替代律师意见**
- 不代写诉状、不代发投诉、不预测判决金额
- 冷静期、退卡规则**地域差异大**，以当地商务主管部门与市场监管部门口径为准
- 会籍协议约定的违约金标准、各地司法裁判尺度存在差异，测算值为**谈判起点**而非最终金额
- **未填的一律不算通过**，只按填了的判断
