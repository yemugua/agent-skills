# 健身房退卡退费信息采集表

> 复制本表填到自己的文件里，填完保存为 Markdown，然后跑：
> `python scripts/gym_refund_check.py 我的采集表.md --base 2026-10-05 --out 核查报告.md`
>
> 标 `*` 的是决定结论的关键项，别空着。**不会填的写「待填」即可，脚本会把未填项标为待补正，不会瞎判。**

## 一、主体与卡品

| 字段 | 值 |
|---|---|
| 门店名称 / 经营者名称 * | 例：XX健身（望京店），营业执照全称后来查 |
| 门店所在地 * | 例：北京市朝阳区 |
| 卡种 * | 例：年卡 / 私教课包 / 次卡 |
| 会籍协议中的退卡条款 | 例：本卡一经售出概不退费；最终解释权归本店 |
| 协议是否约定违约金 | 是 / 否 |
| 协议约定的违约金比例 | 例：未约定 / 未履行部分的 20% |

## 二、钱与数量

| 字段 | 值 |
|---|---|
| 办卡日期 * | 例：2025-03-15 |
| 实付总额 * | 例：12800（含分期贷本金也算） |
| 赠送课时 / 赠送使用期限 | 例：赠送 12 节私教 / 赠送 30 天有效期 |
| 挂牌原价月单价 | 例：1280（门店对外标价，用来对照门店口径） |
| 是否为分期贷 / 培训贷付款 | 是 / 否 |

### 期限卡填这三行

| 字段 | 值 |
|---|---|
| 约定使用月数 | 24 |
| 约定使用天数 | 730 |
| 已使用月数 / 已使用天数 | 5 / 152 |

### 私教课包填这三行

| 字段 | 值 |
|---|---|
| 约定总课时 | 60 |
| 已消耗课时 | 18 |
| 赠送课时数 | 12 |

## 三、为什么退

| 字段 | 值 |
|---|---|
| 退卡触发情形 * | 例：门店关闭跑路 / 迁址很远 / 转让不承接 / 教练与承诺不符 / 课程长期约不上 / 健康原因 / 单纯不想用 |
| 是否有医院诊断证明 | 是 / 否（选「健康原因」的必填此项） |
| 购卡后是否已实际消费 | 是 / 否 |

## 四、冷静期

| 字段 | 值 |
|---|---|
| 所在地是否有健身消费冷静期规定 | 是 / 否 / 待填 |

> 上海、北京等地对体育健身类预付消费有相关规定（常见 7 日冷静期）。
> 是否适用、期限多长、**一律以当地商务主管部门、市场监管部门与体育主管部门口径为准**；
> 查询入口：当地商务局（单用途商业预付卡条线）、当地市场监管局官网/公众号、当地体育局、12345。
