# 退费规则：预付卡性质、格式条款效力、计算模型

## 一、健身卡是什么性质的钱

- 健身卡属于**单用途商业预付卡**：由商业企业发行，只在本企业或同一品牌连锁企业内兑付商品或服务。
- 受商务主管部门的**单用途商业预付卡管理办法（试行）**规范，核心制度有三条：**实名购卡、资金存管、退卡规则**。
- 因此它**不是"买了就不能退"**：经营者与消费者约定或经营者承诺的退卡情形出现时，应当按约定或承诺办理退卡。
- 卡内余额的所有权仍属于消费者，经营者停业、歇业、迁址的，应当依法处理预收资金。

## 二、格式条款：退卡的第一支点

会籍协议里这几句话，**写了也无效**：

| 典型条款 | 为什么无效 |
|---|---|
| "本卡一经售出，概不退费" | 排除消费者主要权利，免除经营者责任 |
| "最终解释权归本店所有" | 排除消费者权利、免除经营者责任 |
| "会员不得转让，转让需缴纳高额手续费" | 加重消费者责任 |
| "本公司有权单方变更服务内容，会员不得异议" | 排除消费者权利 |
| "余额过期作废，不予退还" | 加重消费者责任、免除经营者责任 |

依据：《中华人民共和国消费者权益保护法》关于**格式条款**的规定——经营者以格式条款、通知、声明、店堂告示等方式，作出排除或者限制消费者权利、减轻或者免除经营者责任、加重消费者责任等对消费者不公平、不合理的规定，**该条款无效**。

→ **重要边界**：格式条款无效 ≠ 全额退。条款无效只是拆掉"概不退费"这道墙，已实际享受的服务仍应按**合理价格**折抵。

## 三、退费计算模型

```
应退金额 = 实付总额 − 已消耗价值 − 合理违约金
```

### 1. 实付总额
实际支付的现金总额，含通过分期贷支付的金额（**贷款本金也算你付的钱**）。赠品、赠送金额不计入实付。

### 2. 已消耗价值——按**会员优惠单价**，不按挂牌原价

| 口径 | 算法 | 谁的立场 |
|---|---|---|
| **门店口径（不接受）** | 已用月数 × 挂牌原价月单价 | 门店 |
| **会员口径（应主张）** | 实付总额 ÷ 约定总天数 × 已用天数 | 消费者 |

**为什么按会员价**：你付的钱对应的是整个会员期，折扣已经体现在总价里。门店先打折收钱、退费时按原价扣，等于两头占便宜。

```
会员日单价 = 实付总额 ÷ 约定总天数
已消耗价值 = 会员日单价 × 已用天数
```

**私教课包**同理：
```
会员课时单价 = 实付总额 ÷ 约定总课时
已消耗价值 = 会员课时单价 × 已消耗课时
```

**赠送课时 / 赠送期限**：一般不折算成现金退给你，但可以**摊薄单价**——把赠送部分并入总服务量计算会员单价，从而压低已消耗价值。

### 3. 合理违约金——以实际损失为限

- 违约金的功能是弥补**实际损失**，不是惩罚。经营者主张违约金的，**须举证实际损失**。
- 约定违约金过高的，可请求予以适当减少；司法实践对健身类预付费纠纷常见的参考上限为**未履行部分的 20%~30%**，个案以实际损失与履约情况为准。
- 消费者因经营者违约（关门、迁址、服务缩水）而退卡的，**不应支付违约金**，反而可主张经营者承担违约责任。

### 4. 测算示例

办卡实付 ¥12800，约定 24 个月（730 天），已用 5 个月（152 天），无赠送，协议未约定违约金。

```
会员日单价    = 12800 ÷ 730 ≈ ¥17.53
已消耗价值    = 17.53 × 152 ≈ ¥2664.66
未履行部分    = 12800 − 2664.66 = ¥10135.34
违约金（20%） = 10135.34 × 20% ≈ ¥2027.07
应退         = 10135.34 − 2027.07 ≈ ¥8108.27
```

若门店按挂牌原价（月单价 ¥1280）扣：已消耗 = 1280 × 5 = ¥6400，应退仅 ¥6400 − 违约金。**两种口径差约 ¥1700**，这就是必须争的点。

## 四、四个常见误判

1. **"协议写了概不退费就没办法"** → 该条款无效，但已享受服务要折抵。
2. **"赠期也要折成钱退给我"** → 赠送部分一般不折算现金，但可用于摊薄单价。
3. **"违约金他说多少就是多少"** → 以实际损失为限，过高可请求减少，且由经营者举证。
4. **"门店跑路钱就打水漂了"** → 预付卡有资金存管与经营者清算义务，走商务主管部门 + 集体维权，另有可向品牌总部与出租方追索的路径。
