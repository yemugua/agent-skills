# 健身房退卡退费核算 · 概述

**什么场景用**：健身卡（年卡、季卡、私教课包、游泳卡、团课包）想退，门店拒退、跑路、迁址、转让不承接、服务缩水，或者刚办几天后悔了——想知道**能不能退、能退多少、先找谁**。

**和现有工具的区别**：

- 不是"能不能退"的问答——它输出**带完整算式的退费测算**：实付总额 − 已消耗价值（按会员优惠单价折算）− 合理违约金，每一步都能对账。
- 明确**单价口径**：门店按挂牌原价扣、你按会员价扣，差额往往是几千元，脚本把两种口径都算出来给你对比。
- 做**格式条款效力判定**：识别协议里的"概不退费""最终解释权""转卡费"等条款并给出无效结论。
- 带**冷静期分支**：按所在地是否有体育健身消费冷静期规定分叉判断，并注明以当地规定为准。
- 覆盖**跑路 / 迁址 / 转让 / 缩水 / 健康原因**五类高比例退费触发情形。
- 全程只按你填了的判断，**未填的一律不算通过**。

**不适用**：非预付式的一次性课程已全部消费完毕、企业团购卡、涉刑事案件的集资类预付。
