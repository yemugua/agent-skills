# 消防电梯与避难层（fire-elevator-refuge）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据 GB 50016 消防电梯与避难层（间）要求，生成清单：消防电梯设置与参数（载重/速度）、前室面积与防烟、井底排水与专用操作、避难层（间）面积与防火分隔、标识与维护。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 消防电梯
- 避难层
- 避难间
- 消防电梯前室
- 高层避难

## 三、工作流
1. 核查消防电梯设置与参数
2. 检查前室面积与防烟
3. 确认井底排水与专用操作
4. 核实避难层(间)面积与分隔
5. 完善标识并做好维护

## 四、核心内容（检查清单与判定）
GB 50016 规定消防电梯的载重、速度与前室要求，以及避难层（间）的面积、防火分隔与防烟；井底应排水并设专用操作装置。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含消防电梯设置与参数 | 电梯 |
| Q2 | FAIL | 未含前室面积与防烟 | 前室 |
| Q3 | WARN | 未含井底排水与专用操作 | 排水 |
| Q4 | FAIL | 未含避难层(间)面积与分隔 | 避难层 |
| Q5 | WARN | 未含标识与维护 | 标识 |

> 脚本 `fire-elevator-refuge_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python fire-elevator-refuge_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python fire-elevator-refuge_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
