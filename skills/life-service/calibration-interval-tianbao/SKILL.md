# 校准周期确定与调整（calibration-interval）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据 GB/T 19022 测量管理体系与 JJF 相关规范，生成清单：器具用途与风险分级、历次校准结果趋势、使用频次与环境条件、检定/校准方式区分、周期调整论证与审批。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 校准周期确定
- 校准间隔
- 检定周期
- 周期调整论证
- 强检与非强检

## 三、工作流
1. 按用途与风险对器具分级
2. 分析历次校准结果趋势
3. 评估使用频次与环境条件
4. 区分检定与校准方式
5. 论证周期调整并履行审批

## 四、核心内容（检查清单与判定）
强制检定器具周期由法规规定不得自行延长；非强检器具可基于历史数据调整，但必须论证并留审批记录，否则是外审常见不符合点。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含器具用途与风险分级 | 分级 |
| Q2 | WARN | 未含历次校准结果趋势分析 | 趋势 |
| Q3 | WARN | 未含使用频次与环境评估 | 环境 |
| Q4 | FAIL | 未含检定校准方式区分 | 方式 |
| Q5 | FAIL | 未含周期调整论证与审批 | 论证 |

> 脚本 `calibration-interval_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python calibration-interval_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python calibration-interval_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
