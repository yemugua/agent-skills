# 嫁接失败征兆与排查顺序

> 本表按「看到的现象 → 最可能原因 → 处置口径」排列，用于自家苗床自查，不替代实验室病原鉴定。

## 一、失败征兆对照表

| 征兆 | 最可能原因 | 处置口径 |
|---|---|---|
| 接口发黑、发软、有异味 | 接口沾水加高湿不通风，立即腐烂 | 立即停止喷雾与浇水，开小口通风；已腐烂整株移出销毁 |
| 接口发白或发霉、有菌丝 | 苗床高湿、消毒不彻底、通风不足 | 通风降湿，移出病株，刀具与台面重新消毒 |
| 接口干瘪、一碰就分离 | 愈合期湿度不足或成活后才失水 | 前期维持 90% 以上湿度，遮阴到位 |
| 接穗叶片萎蔫卷曲但不落 | 接穗失水过度，早期未及时入高湿室 | 立即转入高湿环境补失水 |
| 砧木长势猛、接穗被压 | 砧木芽未及时抹除 | 及时抹芽，接穗恢复生长后可追回 |
| 接口一头粗一头细 | 播期未控好，砧穗茎粗不匹配 | 砧木早播 5-10 天，粗细差控制在 1-2 mm |
| 成活后接口缢缩、勒痕深 | 绑扎过紧或未及时松绑 | 愈合后 7-10 天及时松绑或去除 |
| 成活后长到一定高度突然萎蔫 | 根系问题或砧穗不亲和 | 拔起查根，根系褐变需排查苗床病害 |
| 成活后一直不长新叶 | 接穗已死，砧木单独生长 | 拔除，用同级成活苗补位 |
| 定植后接口处腐烂 | 定植时嫁接口被埋入土中 | 调整定植深度，保持接口在土面之上 |

## 二、按时间顺序排查

| 时间点 | 先看什么 | 常见问题 |
|---|---|---|
| 嫁接后 0-1 天 | 接口是否保湿、苗是否失水萎蔫 | 未及时入高湿室 |
| 嫁接后 1-3 天 | 砧穗是否错位、砧木是否顶掉接穗 | 苗太嫩、切面不整齐、固定不牢 |
| 嫁接后 3-5 天 | 接口是否发黑、有异味 | 高湿不通风、结露 |
| 嫁接后 5-7 天 | 是否开始通风、砧木芽是否长出 | 未通风、未抹芽 |
| 嫁接后 7-15 天 | 新叶是否展开、接口是否硬实 | 接穗已死、绑扎过紧 |
| 定植后 | 是否深埋嫁接口、根系是否正常 | 定植过深、缓苗期大水大肥 |

## 三、失败原因的排除顺序（不能跳步）

1. **先排除操作因素**：切面是否平整、砧穗粗细是否匹配、固定是否牢、刀具是否消毒
2. **再排除环境因素**：愈合期湿度是否维持、温度是否骤变、第 5 天起是否通风
3. **再排除管理因素**：砧木芽是否及时抹除、是否大水大肥、通风口是否对接口结露
4. **最后才怀疑砧穗组合与种苗带毒**：需送检鉴定

**顺序不能跳**：一失败就换砧木，往往把可自己纠正的操作问题变成了不可逆的损失。

## 四、成批失活的处置口径

| 情形 | 处置 |
|---|---|
| 少量苗失败（5% 以内） | 移出销毁，用同级成活苗补位，单独记录 |
| 中量失败（5%-30%） | 停止扩大嫁接批次，先查操作与环境，保留失败苗样本送检 |
| 大量失败（30% 以上） | 全批报废，重新育苗；未查明原因前不要连续下一批 |
| 接口普遍发黑发软 | 优先查通风与结露，不是先换砧木 |
| 砧木芽普遍压过接穗 | 优先查抹芽流程，不是先换砧木 |

## 五、必须转农技部门或育苗基地的情形

- 需要鉴定病原菌、病毒或砧木种子带毒情况
- 需要确定某砧木对枯萎病、根腐病的抗性等级
- 需要采购砧木种子并核对检疫状态
- 同一组合连续两批成活率都偏低，需系统性排查
- 计划使用生根剂或生长调节剂，询问品种与浓度

## 六、明确禁止

- 不使用来历不明的砧木与接穗种子
- 不把带病症状的苗送进愈合室
- 不在同一把刀不消毒的情况下连续削苗
- 不用未腐熟有机肥或高浓度肥液给嫁接苗催长
- 不在嫁接口上覆盖不透气且长期不检查的覆盖物
