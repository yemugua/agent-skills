# 成人高考报考条件与志愿填报核查（adult-gaokao-application-check）

成人高考能不能报，**看四件事**：层次选对没有、学历够不够（专升本还要学信网可查）、有没有硬性禁报情形、异地报考材料齐不齐。

报上以后能不能被录取，**再看两件事**：志愿填得稳不稳、加分该拿的有没有拿到。

这个技能做五件事：**核条件** → **查材料** → **算加分** → **定志愿** → **排坑**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 按通行口径核查报考条件 | ❌ 代替省教育考试院发布报名公告 |
| 列出报名材料清单与办理顺序 | ❌ 代为网上报名、代缴费、代确认 |
| 按年龄/身份判断加分可能性 | ❌ 承诺具体加分分值或录取结果 |
| 给出志愿填报策略 | ❌ 替考生决定志愿并代填 |
| 提示常见骗局与风险 | ❌ 推荐、甄别具体培训机构 |

**遇到以下情况，务必以考生所在省份教育考试院（招生考试机构）当年公告为准，或直接咨询官方：**
- 报名时间、确认方式、缴费截止日等时间节点
- 志愿数量、录取批次、征集志愿的具体规则
- 加分与免试的申请流程、审核口径、证明材料格式
- 医学类、艺术类、体育类专业的特殊条件与加试安排
- 境外学历、军校学历、自考学历是否可查可认

**永远不要把"未缴费"说成"已报名"，也不要把"信息确认通过"说成"报名成功"。** 这两句话害人最多。

## 二、完整工作流

```
第 1 步  收集四项基础信息：报考层次、出生日期、现有学历、报考省份
第 2 步  先读规则文件 rules/application_conditions.md 与 rules/volunteer_and_policy.md
第 3 步  跑核查脚本
    python scripts/adult_gaokao_check.py --level zhuanben --birth 1990-05-01 \
        --education zhuanke --verified yes --exam-year 2026
第 4 步  逐项人工确认（脚本只做条件匹配，不做政策判断）
第 5 步  补材料清单 + 加分申请 + 志愿策略，一起输出给考生
第 6 步  明确提示：报名入口只能是省教育考试院官网
```

## 三、三个层次，选错就白报

| 层次 | 起点 | 学制（通行口径） | 总分 |
|---|---|---|---|
| 高中起点升专科（高起专） | 高中毕业文化程度 | 2.5 ~ 3 年 | 450 |
| 高中起点升本科（高起本） | 高中毕业文化程度 | 5 年 | 600 |
| 专科起点升本科（专升本） | 国民教育系列专科及以上 | 2.5 ~ 3 年 | 450 |

**三个层次不能混报。** 报了专升本就不能同时报高起专或高起本。这一条是硬规则，不是建议。

---

## 四、五类硬性条件（详见 `rules/application_conditions.md`）

| 条件 | 判定口径 |
|---|---|
| 学历层次 | 高起专/高起本需高中毕业文化程度；专升本需国民教育系列专科及以上 |
| 学信网核验 | **专升本的专科及以上学历必须学信网可查**，查不到先做学历认证 |
| 在校生限制 | 各类高、中等学校在校生不得报考 |
| 年龄 | 一般应年满 18 周岁（各省口径不同） |
| 医学类资格 | 临床类需执业助理医师及以上资格或相应专业学历；护理学需执业护士证书 |

**否定词意识（防误伤）：**

| 表述 | 正确理解 |
|---|---|
| 「信息确认通过」 | ≠ 报名成功，未缴费视为报名无效 |
| 「资料已提交」 | ≠ 审核通过 |
| 「拟录取」 | ≠ 已录取、≠ 有学籍 |
| 「成人医学学历」 | ≠ 可以报考执业医师/执业护士的依据 |
| 「函授」 | ≠ 不用上课，函授也有面授与考试 |

## 五、加分与免试（详见 `rules/volunteer_and_policy.md`）

- **符合多项加分条件的，只取最高一项，不累加。** 这是最常被误解的一条。
- 年龄加分通行口径：**截至报考当年 12 月 31 日年满 25 周岁，一般加 20 分**。
- 加分需要按规定提交证明材料并通过审核，不是自动生效。
- **免试入学也要履行报名手续**，不是不用报名。

## 六、脚本用法

```bash
python scripts/adult_gaokao_check.py --level zhuanben --birth 1990-05-01 --education zhuanke --verified yes --exam-year 2026
```

| 参数 | 说明 |
|---|---|
| `--level` | `gaoqi-zhuan` 高起专 / `gaoqi-ben` 高起本 / `zhuanben` 专升本 |
| `--birth` | 出生日期 `YYYY-MM-DD`，用于算年龄与 25 周岁加分节点 |
| `--education` | `chuzhong` / `gaozhong` / `zhongzhuan` / `zhuanke` / `benke` |
| `--verified` | 专升本学历是否学信网可查：`yes` / `no` |
| `--major-category` | `normal` / `clinical` 临床类 / `nursing` 护理学 / `medical-other` 医学其他 |
| `--license` | `none` / `assistant-doctor` / `nurse` / `rural-doctor` |
| `--residence` | `local` 户籍地 / `other` 异地 |
| `--permit` | 异地是否有居住证或社保材料：`yes` / `no` |
| `--student` | 是否为高、中等学校在校生 |
| `--exam-year` | 报考年份，默认基准日所在年份 |
| `--as-of` | 核查基准日，默认今天 |
| `--out` | 结果输出文件路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置自检（15 条断言） |

脚本输出三项结论：**符合 / 需补充或核实 / 不符合**，并区分「不符合项」与「需补充项」——前者是硬门槛，后者是材料问题，不要混为一谈。

> ⚠️ 脚本按通行口径判断，**不等于考生所在省份当年公告**。所有结论都要回到省教育考试院官网复核。

## 七、人工确认清单（这步不能省）

- [ ] 报考层次与本人学历起点是否匹配，且未跨层次混报
- [ ] 专升本学历是否已在学信网查到（本人登录查，不要听机构说）
- [ ] 是否属于各类高、中等学校在校生
- [ ] 医学类专业是否具备相应执业资格或专业学历，且专业对口
- [ ] 异地报考的居住证/社保材料是否已办下来（居住证办理需要时间）
- [ ] 身份证是否在有效期内
- [ ] 照片是否符合本省规格要求（背景、尺寸、格式）
- [ ] 加分证明材料是否齐备，是否符合多项时按最高一项申报
- [ ] 报名、确认、缴费三个时间节点是否已记下
- [ ] 报名入口是否为省教育考试院官网，而非第三方机构链接

## 八、最常见的坑

**坑一：错过报名，只能等下一年。**
一年只有一次，通常在 8 月底至 9 月上旬。把省教育考试院官网设为常用书签，报名期每周看一次公告。

**坑二：信息确认做了，忘了缴费。**
未缴费视为报名无效。这一步每年都有人栽，而且栽了没有补救。

**坑三：专升本学历学信网查不到。**
非国民教育系列、境外学历未认证、毕业证信息有误，都会卡在审核。先查再报，不要先报再查。

**坑四：医学类没资格硬报。**
临床类要执业助理医师资格或相应中专学历，护理学要执业护士证。资格不符即使考上也过不了新生资格复查，学费和时间全打水漂。

**坑五：异地报考没有居住证。**
居住证办理需要时间，报名前一个月才开始办就来不及。这是异地报考审核被驳回的第一原因。

**坑六：志愿只填一个且不服从调剂。**
分数够了却因为志愿策略落榜，最可惜。冲一冲 + 保底，是两个志愿的正确用法。

**坑七：相信"包过""全程托管""不用考试"。**
成人高考是国家教育考试，不存在包过。这类承诺往往伴随代报名、代考、假学籍等风险，一旦出事，损失的是钱和几年时间。

**坑八：报了非正规教学点。**
入学后学信网查不到学籍、毕业拿不到国家承认学历。认准省教育考试院公布的招生院校与官方教学点。

**坑九：以为成人学历能用来考执业医师/护士。**
相关资格考试对学历和专业另有要求，成人医学学历一般不作为报考依据。报之前先想清楚用途。

**坑十：不看学习形式就报。**
函授也有面授与考试，脱产需要全日制在校。选错了坚持不下来，中途退学什么都拿不到。

## 九、输出结构（固定五段）

1. **能不能报** —— 结论先行：符合 / 需补充材料 / 不符合，并说明卡在哪一项
2. **条件核查表** —— 逐项标符合 / 需核实 / 不符合，附判定依据
3. **材料补充清单** —— 缺什么、去哪办、要多久（居住证类标注办理周期）
4. **加分与免试核查** —— 可能符合的类别、是否叠加规则、需提交的证明
5. **志愿策略与风险提示** —— 冲稳搭配、是否服从调剂、报名入口与防骗提示

---

## 十、边界与免责

- 本技能**不代替**各省（自治区、直辖市）教育考试院当年发布的成人高校招生办法
- 报名时间、志愿数量、加分分值与录取规则**以考生所在省份当年公告为准**，本技能只提供通行口径
- **不代报名、不代缴费、不承诺录取、不承诺加分结果**
- 涉及学历认证、境外学历认定、军校学历认定等，应通过学信网与教育行政部门官方渠道办理
- 任何"包过""不用考试""全程托管"的承诺都应视为风险信号
