# 成人高考志愿填报、加分免试与避坑清单

> 志愿数量、录取规则、加分与免试政策由**各省（自治区、直辖市）当年成人高校招生办法**确定。**以考生所在省份当年公告为准**，本文件只给通行口径。

## 一、志愿填报通行规则

| 事项 | 口径 |
|---|---|
| 志愿数量 | 一般可填 1~2 个学校志愿，每个学校可填 1~2 个专业志愿（各省不同） |
| 层次限制 | 专升本、高起本、高起专**不能跨层次混报** |
| 科类限制 | 志愿须与报考科类一致（文史、理工、艺术、体育、西医、中医等） |
| 加试要求 | 艺术类、体育类专业一般需参加学校组织的**专业加试**，未加试或不合格不予录取 |
| 调剂 | 可选"是否服从调剂"，增加录取概率，但可能被调到同校其他专业 |
| 征集志愿 | 各批次录取后未完成的计划会进行征集志愿（补录），未录取的考生要及时关注 |
| 学习形式 | 函授、业余、脱产分别列计划，填报时看清上课地点与形式 |

## 二、填报策略

| 策略 | 说明 |
|---|---|
| 冲稳结合 | 第一志愿冲一冲，第二志愿选把握大的，**不要两个都冲** |
| 留一个保底 | 第二志愿选往年录取分数低于自己估分的院校专业 |
| 看清招生范围 | 有些院校只在省内招生，有些专业只在指定教学点开班 |
| 兼顾上课地点 | 函授也有面授，选离家或单位近的教学点，别只看学校名气 |
| 核对专业要求 | 医学类、艺术类、体育类有特殊条件与加试 |
| 关注计划数 | 招生计划少的专业，分数波动大 |
| 服从调剂 | 以拿到学籍为优先目标的，建议勾选 |

**只填一个志愿且不服从调剂，是落榜的高频原因。**

## 三、加分政策（通行口径，取最高一项，不累计）

| 类别 | 加分（通行口径） |
|---|---|
| **年满 25 周岁** | 一般加 **20 分** |
| 少数民族考生 | 各省不同，一般 10~20 分 |
| 少数民族聚居地区的少数民族考生 | 各省不同 |
| 烈士子女、烈士配偶 | 各省不同 |
| 归侨、归侨子女、华侨子女、台湾省籍考生 | 各省不同 |
| 自主就业的退役士兵 | 一般加 10 分（各省不同） |
| 荣立二等功以上的退役军人 | 各省不同 |
| 运动健将、武术项目武英级运动员 | 各省不同 |
| 边疆、山区、牧区的考生 | 各省不同 |

**关键**：符合多项的**只取最高一项，不累加**；年龄加分一般以报考当年 12 月 31 日为节点计算（以当年公告为准）。加分需要按规定提交证明并通过审核。

## 四、免试入学（通行口径，各省不同）

| 类别 | 说明 |
|---|---|
| 全国劳动模范、全国先进工作者、"全国五一劳动奖章"获得者 | 可申请免试入学 |
| 优秀运动员 | 符合规定运动成绩的可申请免试 |
| 普通高职（专科）毕业生服义务兵役退役、"下基层"服务期满并考核合格 | 按当年政策可申请免试或加分 |
| 参加"选聘高校毕业生到村任职""三支一扶""大学生志愿服务西部计划"等项目服务期满并考核合格 | 按当年政策执行 |

免试也要履行报名手续，不是不用报名。

## 五、录取分数线与录取规则

| 事项 | 口径 |
|---|---|
| 分数线 | 各省分层次、分科类划定最低录取控制分数线（各省各年不同） |
| 投档规则 | 一般在最低控制线上按志愿和分数投档 |
| 录取结果 | 以省招生机构与招生学校公布的录取结果为准 |
| 学籍 | 入学注册后可在学信网查询，查不到学籍要立即向学校核实 |
| 复查 | 新生入学后学校会进行资格复查，不符合报考条件的取消学籍 |

## 六、备考要点（时间不多时的取舍）

| 科目 | 策略 |
|---|---|
| 政治（专升本） | 性价比最高，重点看时政与基本概念，短期提分明显 |
| 语文 | 作文占分高，准备 2~3 个通用素材与结构模板 |
| 数学 | 抓基础题与公式题，放弃偏题 |
| 外语 | 背高频词汇与基础语法，重点拿选择题 |
| 专业课 | 对照考试大纲过一遍知识点，做近三年真题 |

**真题优先于模拟题。** 成人高考命题稳定，近三年真题覆盖大部分考点。

## 七、常见坑

**坑一：错过报名。**
一年一次，一般在 8 月底到 9 月上旬。把省教育考试院官网设成常用书签，报名期每周看一次公告。

**坑二：信息确认做了，忘了缴费。**
未缴费视为报名无效，这一步每年都有人栽。

**坑三：专升本学历学信网查不到。**
非国民教育系列、境外学历未认证、毕业证信息有误的，都会卡住。先查再报。

**坑四：医学类没资格硬报。**
临床类要有执业助理医师资格或相应中专学历，护理学要有执业护士证。资格不符即使考上也过不了复查。

**坑五：异地报考没有居住证。**
居住证办理要时间，报名前一个月才开始就来不及。

**坑六：志愿只填一个且不服从调剂。**
分数够了但因为志愿填报策略落榜，最可惜。

**坑七：相信"包过""全程托管""不用考试"。**
成人高考是国家教育考试，不存在包过。这类承诺往往伴随代报名、代考、假学籍等风险，一旦出问题，损失的是钱和时间。

**坑八：报了非正规教学点。**
入学后学信网查不到学籍、毕业拿不到国家承认学历。认准省教育考试院公布的招生院校与官方教学点。

**坑九：以为成人学历能用来考执业医师/护士。**
相关资格考试对学历和专业另有要求，成人医学学历一般不作为报考依据。

**坑十：不看学习形式就报。**
函授也有面授与考试，脱产需要全日制在校。选错了坚持不下来。

## 八、报名前自检清单

- [ ] 层次选对（高起专 / 高起本 / 专升本），且不混报
- [ ] 学历符合要求，专升本学历学信网可查
- [ ] 年满 18 周岁（按省要求）
- [ ] 非在校生
- [ ] 医学类具备相应执业资格或专业学历
- [ ] 异地报考的居住证/社保材料已备齐
- [ ] 身份证在有效期内
- [ ] 照片符合规格
- [ ] 加分证明材料已准备
- [ ] 已确认报名、确认、缴费三个时间节点
- [ ] 志愿策略已定（冲 + 稳 + 是否服从调剂）
- [ ] 报考入口是省教育考试院官网，不是第三方机构链接
