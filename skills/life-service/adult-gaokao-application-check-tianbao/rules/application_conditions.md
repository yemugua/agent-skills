# 成人高考报考层次、条件、科目与流程

> 成人高等学校招生全国统一考试的报名时间、流程、科目与分数线由**各省（自治区、直辖市）教育考试院（招生考试机构）当年发布的成人高校招生办法**确定，各省差异明显。**以考生所在省份当年公告为准**，本文件只给通行口径，不引用具体条款号。

## 一、三个报考层次

| 层次 | 起点 | 学制（通行口径） | 适合谁 |
|---|---|---|---|
| 高中起点升专科（高起专） | 高中毕业文化程度 | 2.5 ~ 3 年 | 想快速拿到专科学历 |
| 高中起点升本科（高起本） | 高中毕业文化程度 | 5 年 | 想一次性读到本科 |
| 专科起点升本科（专升本） | 已取得国民教育系列专科及以上 | 2.5 ~ 3 年 | 已有专科，想升本科 |

**三个层次不能混报。** 报了专升本就不能同时报高起专或高起本。

## 二、基本报考条件

| 条件 | 口径 |
|---|---|
| 国籍与身份 | 中国公民，遵守法律 |
| 身体健康 | 生活能自理，不影响所报专业学习 |
| 高起专 / 高起本 | 具有**高中毕业文化程度**（多数省份表述为高级中等教育学校毕业或具有同等学力） |
| 专升本 | 已取得经教育部审定核准的国民教育系列高等学校、高等教育自学考试机构颁发的**专科毕业证书、本科结业证书或以上证书** |
| 学历核验 | 专升本的专科及以上学历须在**学信网可查**，查不到的先做学历认证 |
| 年龄 | 一般应年满 18 周岁（各省口径不同，以当年公告为准） |
| 在校生限制 | 国家承认学历的各类高、中等学校**在校生不得报考** |

## 三、不得报考的情形

- 各类高、中等学校在校生（除国家另有规定的外）
- 因违反国家教育考试规定，被给予暂停参加成人高考处理且在停考期内的人员
- 因触犯刑法被有关部门采取强制措施或正在服刑者
- 不符合所报专业特殊要求的（如医学类无相应执业资格）

## 四、医学类专业的特殊条件（最容易被卡）

| 专业类别 | 条件 |
|---|---|
| 临床医学、口腔医学、预防医学、中医学等**临床类专业** | 取得省级卫生健康行政部门颁发的相应类别的**执业助理医师及以上资格证书**；或取得国家认可的普通中专及以上相应专业学历；或取得县级及以上卫生行政部门颁发的乡村医生执业证书并具有中专学历或中专水平证书 |
| **护理学专业** | 取得省级卫生健康行政部门颁发的**执业护士证书** |
| 医学门类**其他专业** | 应当是从事卫生、医药行业工作的**在职专业技术人员** |
| 通用原则 | **报考专业原则上应与所从事的专业对口** |

**防误伤**：成人高考医学类学历**不能作为报考执业医师、执业护士资格的依据**（相关资格考试另有学历与专业要求）。报之前先想清楚用途，别读了三年发现不能用来考证。

## 五、异地报考

| 情形 | 常见要求 |
|---|---|
| 户籍所在地报考 | 提供身份证、户口簿（按省要求） |
| 非户籍所在地报考 | 一般需提供**居住证**、或社保缴纳证明、或工作单位证明（各省口径不同） |
| 军人 | 按军队和省级招生机构的专门规定办理 |
| 港澳台及华侨 | 按专门规定办理 |

**异地报考材料是现场/网上审核的高频不通过项**，要提前半年办居住证的，别等到报名前一个月。

## 六、考试科目

| 层次 | 科目 | 总分 |
|---|---|---|
| 高起专（文） | 语文、数学（文）、外语 | 450 |
| 高起专（理） | 语文、数学（理）、外语 | 450 |
| 高起本（文） | 语文、数学（文）、外语、史地综合 | 600 |
| 高起本（理） | 语文、数学（理）、外语、物化综合 | 600 |
| 专升本 | 政治、外语 + 专业基础课 | 450 |

专升本专业基础课按学科门类：

| 门类 | 专业基础课 |
|---|---|
| 哲学、文学、历史学、中医中药学类 | 大学语文 |
| 艺术类 | 艺术概论 |
| 工学、理学（部分） | 高等数学（一） |
| 经济学、管理学、职业教育类、生物科学类、地理科学类、环境科学类、心理学类、药学类 | 高等数学（二） |
| 法学类 | 民法 |
| 教育学类 | 教育理论 |
| 农学类 | 生态学基础 |
| 医学类（除中医学类、药学类外） | 医学综合 |

各科满分通常为 150 分。外语一般可在英、日、俄中选一种（按省公告）。

## 七、报名与考试流程（时间以当年省公告为准）

| 环节 | 通行时间 | 要点 |
|---|---|---|
| 网上报名 | 通常为 **8 月底至 9 月上旬** | 每年只有一次，错过等一年 |
| 信息确认 | 网报后 | 网上审核或现场确认，二者都要按时完成 |
| 网上缴费 | 确认后 | **未缴费视为报名无效** |
| 打印准考证 | 考前一周左右 | 多打几份 |
| 考试 | 通常为 **10 月下旬的周末** | 带身份证、准考证 |
| 成绩查询 | 11 月 | 各省时间不同 |
| 录取 | 12 月前后 | 分批次进行 |
| 入学 | 次年春季（通常 3 月） | 按学校通知报到 |
| 学籍注册 | 入学后 | 之后可在学信网查学籍 |

## 八、报名材料清单（通用）

| # | 材料 | 说明 |
|---|---|---|
| 1 | 身份证 | 有效期内，正反两面 |
| 2 | 学历证明 | 专升本需专科及以上毕业证与学信网学历信息 |
| 3 | 照片 | 按省要求的规格（背景、尺寸、格式） |
| 4 | 户籍或居住证明 | 异地报考需居住证或社保材料 |
| 5 | 医学类资格证明 | 执业助理医师证、执业护士证等 |
| 6 | 加分证明材料 | 少数民族、退役军人、烈士子女等 |
| 7 | 联系方式 | 手机号必须能接收通知 |

## 九、学习形式

| 形式 | 特点 |
|---|---|
| 函授 | 以自学为主，集中面授为辅，适合在职 |
| 业余 | 安排在晚上或周末，适合本地在职 |
| 脱产 | 全日制在校学习（招生院校与计划较少） |

选择时重点看：**上课地点是否方便、面授比例、毕业要求、学费标准、学校是否正规（能否在学信网查到学籍）**。

## 十、防误伤清单

1. **一年只有一次报名机会**，错过只能等下一年
2. **未缴费 = 未报名**，信息确认通过不等于报名成功
3. **专升本学历必须学信网可查**，查不到要先做学历认证
4. **医学类有执业资格门槛**，不符合条件的报了也白报
5. **异地报考要提前办居住证**，临时来不及
6. **在校生不能报考**
7. **"包过""不用考试""全程托管"都是骗局**，成人高考是国家教育考试，不存在包过
8. **成人高考学历不能作为报考执业医师、执业护士的依据**（相关资格考试另有规定）
9. 认准**各省教育考试院官网**与学校官方教学点，不要通过非正规机构代报名
