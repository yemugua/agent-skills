# 交通建筑与航站楼防火（airport-terminal-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《民用机场航站楼消防设施配置》与交通建筑防火要求，生成清单：大空间防火分区与隔离、登机桥与行李系统防火、行李托运安检区消防设施、商业餐饮区防火分隔、应急通行疏散与大客流引导。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 航站楼消防
- 交通建筑防火
- 高铁站消防
- 客运站防火
- 大客流疏散

## 三、工作流
1. 划分大空间防火分区与隔离
2. 配置登机桥与行李系统防火
3. 保障安检托运区消防设施
4. 分隔商业餐饮防火单元
5. 组织应急通行疏散与客流引导

## 四、核心内容（检查清单与判定）
交通建筑空间高大、客流密集且不间断运行，行李系统与商业餐饮带来特殊火源。保持疏散通道不被商业占用是日常管理的最大难点。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含防火分区与隔离措施 | 分区 |
| Q2 | WARN | 未含登机桥与行李系统防火 | 行李系统 |
| Q3 | WARN | 未含安检托运区消防设施 | 设施 |
| Q4 | FAIL | 未含商业餐饮防火分隔 | 分隔 |
| Q5 | FAIL | 未含疏散通行与客流引导 | 疏散 |

> 脚本 `airport-terminal-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python airport-terminal-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python airport-terminal-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
