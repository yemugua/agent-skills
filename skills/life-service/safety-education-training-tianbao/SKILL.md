# 安全教育培训（safety-education-training）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《安全生产法》与《生产经营单位安全培训规定》，生成安全教育培训清单：培训对象（三级/特种/管理人/全员）、三级安全教育、内容与学时、一人一档与实操。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 安全教育
- 安全培训
- 三级教育
- 新员工培训
- 特种作业培训
- 培训档案

## 三、工作流
1. 覆盖培训对象（三级教育/特种/管理人/全员）
2. 落实三级安全教育（厂级/车间/班组）
3. 明确培训内容与学时（法定要求）
4. 建立培训档案与考核（一人一档）
5. 特种/实操培训

## 四、核心内容（检查清单与判定）
《安全培训规定》要求生产经营单位对新工人进行厂级、车间级、班组级三级安全教育并考核合格方可上岗；安全培训应建立档案。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未覆盖培训对象（三级教育/特种/管理人/全员） | 对象 |
| Q2 | FAIL | 未含三级安全教育（厂级/车间/班组） | 三级 |
| Q3 | WARN | 未含培训内容与学时（法定要求） | 学时 |
| Q4 | FAIL | 未含培训档案与考核（一人一档） | 档案 |
| Q5 | WARN | 未含特种/实操培训 | 实操 |

> 脚本 `safety-education-training_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python safety-education-training_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python safety-education-training_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
