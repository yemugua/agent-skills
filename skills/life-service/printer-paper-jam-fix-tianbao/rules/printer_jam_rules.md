# 打印机卡纸取纸与预防规则

## 一、判定总原则

1. **先断电，后动手。** 激光机还需冷却 10-15 分钟。
2. **看提示，不凭猜。** 屏幕给的卡纸位置是最准的线索。
3. **顺向取，不硬拽。** 有阻力就停手换位置。
4. **取净残片。** 残留一片，之后反复卡。
5. **反复卡纸查进纸机构**，不是换纸。

---

## 二、卡纸位置与取纸路径

| 位置 | 入口 | 取纸方向 | 注意 |
|---|---|---|---|
| 进纸盒 | 纸盒上方 | 顺进纸方向拉 | 先看纸张是否装太满 |
| 纸路中部 | 打开前盖或侧盖 | 顺纸路方向 | 双手匀速，不要斜拉 |
| 定影单元 | 后盖或上盖 | 顺出纸方向 | 激光机高温，先冷却 |
| 出纸口 | 出纸口 | 顺出纸方向 | 检查是否纸卷曲顶住 |
| 双面单元 | 抽出双面单元 | 按单元标示方向 | 单元要完全抽出再取 |
| 输稿器 | 掀开输稿器盖 | 顺走纸方向 | 别硬拽原稿 |

**通用原则**：顺纸张正常前进方向拉，双手同时匀速用力。有阻力立即停手，换盖板再找。

---

## 三、卡纸故障树（按处理顺序）

| 顺序 | 原因 | 判定 | 验证动作 | 处置 |
|---|---|---|---|---|
| 1 | 纸张受潮卷曲或夹带异物 | 纸卷曲、有订书钉、标签脱落 | 检查纸张状态 | 换干燥纸张，去除异物 |
| 2 | 纸盒装太满或导纸板不当 | 一次进多张、进纸歪斜 | 看纸量与导纸板 | 装七分满，导纸板贴合 |
| 3 | 搓纸轮脏污 | 不进纸、打滑 | 看轮面是否有纸灰发亮 | 无水酒精配无绒布擦拭 |
| 4 | 搓纸轮磨损 | 擦拭后仍打滑 | 看轮面是否磨平 | 更换搓纸轮 |
| 5 | 分离垫失效 | 一次进好几张 | 看分离垫是否磨光 | 更换分离垫 |
| 6 | 纸路残留纸片 | 取完仍报卡纸 | 手电逐段照纸路 | 镊子取出残片 |
| 7 | 传感器摆杆卡住 | 看不到纸却报卡纸 | 检查传感器摆杆能否回弹 | 复位摆杆或报修 |
| 8 | 定影组件故障 | 反复在同一位置卡纸 | 检查分离爪与定影膜 | **停用报修** |
| 9 | 输稿器齿轮断裂 | 有塑料碎屑、异响 | 看输稿器内有无碎屑 | **停用报修** |

---

## 四、反复卡纸的四个真因

| 原因 | 表现 | 处置 |
|---|---|---|
| 搓纸轮磨损或脏污 | 不进纸、打滑、一次进多张 | 无水酒精擦拭，磨平了就换 |
| 分离垫失效 | 一次进好几张 | 更换分离垫 |
| 纸张受潮卷曲 | 出纸口卡纸、打印歪斜 | 换干燥纸张，密封存放 |
| 纸路有残片 | 取完仍报卡纸 | 手电逐段照，镊子取出 |

**关键认知**：卡纸往往不是纸的问题，是进纸机构的问题。

---

## 五、安全要点（激光机尤其注意）

| 风险 | 防护 |
|---|---|
| 定影单元高温烫伤 | 关机后冷却 10-15 分钟再动手 |
| 定影辊夹手 | 不要用手指伸进狭窄纸路 |
| 碳粉吸入或沾染 | 轻拿轻放，勿拍打硒鼓，沾粉用干布处理 |
| 感光鼓强光损伤 | 取出硒鼓避免强光直射，不要用手摸鼓面 |
| 金属工具划伤部件 | 禁止用镊子与螺丝刀刮辊面 |

**碳粉处理**：不要用湿布擦感光鼓，不要用普通吸尘器吸碳粉（颗粒极细会泄漏且可能损坏电机）。

---

## 六、安全红线（必须停用并报修）

| 情形 | 处置 |
|---|---|
| 激光机刚工作过 | 冷却 10-15 分钟再动手，防高温烫伤 |
| 纸屑掉进机器深处看不见够不着 | 停用报修，不要盲目拆解 |
| 清洁搓纸轮后仍反复在同位置卡纸 | 可能是分离爪或定影膜破损，报修 |
| 报错代码持续、门盖传感器无法复位 | 报修 |
| 输稿器齿轮断裂、有塑料碎屑 | 报修 |
| 碳粉泄漏、硒鼓漏粉、焦味异响 | 立即停用并报修 |
| 仍在保修期内 | 走售后，自行拆机可能失去保修 |

**禁止事项：**

- 禁止逆向或斜向硬拽纸张（撕断后残片会导致反复卡纸）
- 禁止用金属工具刮感光鼓与定影辊
- 禁止用湿巾擦搓纸轮（残留会让轮子更滑）
- 禁止用普通吸尘器吸碳粉
- 禁止强光直射感光鼓

## 七、常见误判清单（反向判断）

| 现象 | 常见误判 | 正确判断 |
|---|---|---|
| 提示卡纸但看不到纸 | 没有卡纸 | 传感器摆杆卡住、纸屑压在传感器上、或搓纸轮打滑没进纸 |
| 反复在同一位置卡纸 | 这批纸不好 | 多为搓纸轮磨损或分离垫失效 |
| 取完纸仍报卡纸 | 传感器坏了 | 先查是否还有残片 |
| 一次进好几张 | 纸装多了 | 多为分离垫失效 |
| 打印歪斜 | 卡纸遗留 | 多为导纸板太松或纸张卷曲 |
| 打印有竖黑道 | 卡纸遗留碳粉 | 多为感光鼓划伤或刮板问题 |
| 喷墨机不进纸 | 卡纸 | 可能是墨盒或维护箱位置异常、进纸轮脏 |
| 擦拭搓纸轮后更滑 | 擦干净了 | 湿巾残留导致，应用无水酒精 |
| 刚开机就报卡纸 | 上次没取净 | 逐段照纸路找残片 |

## 八、预防维护表

| 周期 | 项目 |
|---|---|
| 每次换纸 | 纸盒装七分满，抖散纸张，导纸板调到贴合 |
| 每月 | 无水酒精擦拭搓纸轮，检查分离垫 |
| 每季度 | 清洁纸路，打测试页检查进纸稳定性 |
| 换季 | 检查纸张是否受潮，密封存放并放干燥剂 |
| 长期不用 | 取出纸盒里的纸，避免受潮卷曲 |

---

## 九、验收标准

| 项目 | 合格标准 |
|---|---|
| 报错 | 装回开机后卡纸提示消除 |
| 测试页 | 连续打印 5 张测试页无卡纸、无歪斜 |
| 进纸 | 每次只进一张，无多张进纸 |
| 走纸 | 纸路无异响、无纸灰堆积 |
| 输出 | 打印内容完整，无竖道与缺色 |

任一项不合格，按故障树重新定位，不要反复换纸。
