# 打印机卡纸处理与预防（printer-paper-jam-fix）

卡纸处理里，**最危险的动作是硬拽**。纸撕断留下的残片会导致反复卡纸，还可能损坏定影组件和分离爪。正确顺序是：**先断电，看提示，顺向取**。

这个技能做四件事：**断电** → **定位** → **取净** → **防复发**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 按提示位置顺向取纸 | ❌ 逆向或斜向硬拽纸张 |
| 判断反复卡纸的真实原因 | ❌ 拆机维修定影组件与齿轮组 |
| 指导搓纸轮清洁与更换 | ❌ 用金属工具刮感光鼓与定影辊 |
| 说明碳粉与高温的防护 | ❌ 让用户在保修期内自行拆机 |
| 给出验收与预防清单 | ❌ 判断主板与传感器电路故障 |

**遇到以下情况，立即停止自行操作，转交售后或维修人员：**

- **激光打印机**刚工作过（定影单元高温，有烫伤风险，需冷却 10-15 分钟）
- 纸屑掉进机器深处、看不见也够不着
- 反复在同一位置卡纸，且清洁搓纸轮后无改善（可能是分离爪或定影膜破损）
- 机器报错代码持续存在，或取纸后门盖传感器无法复位
- 输稿器齿轮断裂、有塑料碎屑掉落
- 碳粉泄漏、硒鼓漏粉、机器内有异响或焦味
- **仍在保修期内**（自行拆机可能失去保修）

**永远不要用蛮力把纸拽出来。** 纸撕断后残片留在纸路里，是"反复卡纸"最常见的成因。

## 二、完整工作流

```
第 1 步  关机断电（激光机需冷却 10-15 分钟）
第 2 步  看屏幕提示的卡纸位置，别凭猜
第 3 步  先读规则文件 rules/printer_jam_rules.md（分区取纸 + 红线 + 预防）
第 4 步  跑故障树脚本
    python scripts/printer_jam_check.py --text "取完纸还提示卡纸，一直进好几张"
第 5 步  按分区顺序顺向取纸，手电检查有没有残片
第 6 步  检查搓纸轮与分离垫，脏了用无水酒精擦，磨了就换
第 7 步  装回开机，打测试页验收，记录卡纸位置与频次
```

## 三、卡纸位置与取纸路径

| 位置 | 入口 | 取纸方向 | 注意 |
|---|---|---|---|
| 进纸盒 | 纸盒上方 | 顺进纸方向拉 | 先看纸张是否装太满 |
| 纸路中部 | 打开前盖 / 侧盖 | 顺纸路方向 | 双手匀速，不要斜拉 |
| 定影单元 | 后盖 / 上盖 | 顺出纸方向 | **激光机高温，先冷却** |
| 出纸口 | 出纸口 | 顺出纸方向 | 检查是否纸卷曲顶住 |
| 双面单元 | 抽出双面单元 | 按单元标示方向 | 单元要完全抽出再取 |
| 输稿器（ADF） | 掀开输稿器盖 | 顺走纸方向 | 别硬拽原稿 |

**通用原则**：顺着纸张正常前进的方向拉，双手同时用力、匀速。感觉有阻力就停，换个盖板再找。

## 四、为什么反复卡纸（换纸解决不了的四种）

| 原因 | 表现 | 处置 |
|---|---|---|
| 搓纸轮磨损或脏污 | 不进纸、打滑、一次进多张 | 无水酒精擦拭；磨平了就换 |
| 分离垫失效 | 一次进好几张 | 更换分离垫 |
| 纸张受潮卷曲 | 出纸口卡纸、打印歪斜 | 换干燥纸张，密封存放 |
| 纸路有残片 | 取完仍报卡纸 | 手电逐段照，镊子取出 |

**关键认知**：卡纸往往不是纸的问题，是**进纸机构**的问题。反复在同一位置卡纸，先查搓纸轮与分离垫，而不是换一包纸。

---

## 五、安全要点（激光机尤其注意）

| 风险 | 防护 |
|---|---|
| 定影单元高温烫伤 | 关机后冷却 10-15 分钟再动手 |
| 定影辊夹手 | 不要用手指伸进狭窄纸路 |
| 碳粉吸入或沾染 | 轻拿轻放，勿拍打硒鼓，沾粉用干布处理 |
| 感光鼓强光损伤 | 取出硒鼓避免强光直射，不要用手摸鼓面 |
| 金属工具划伤部件 | 禁止用镊子、螺丝刀刮辊面 |

**碳粉处理**：不要用湿布擦感光鼓，不要用吸尘器直接吸碳粉（碳粉颗粒细，普通吸尘器会泄漏并可能损坏电机）。

## 六、脚本用法

```bash
python scripts/printer_jam_check.py --text "取完纸还提示卡纸，一直一次进好几张"
python scripts/printer_jam_check.py --file 描述.txt --out 结果.md
```

| 参数 | 说明 |
|---|---|
| `--text` | 直接给现象描述 |
| `--file` | 从文件读描述 |
| `--out` | 结果落盘路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本按现象匹配故障树，输出排查顺序、验证动作与处置，命中高温、漏粉、保修期等情形时输出停用并报修提示。

> 脚本只做关键词匹配，**不代表现场判断**。取纸必须按屏幕提示的位置来。

## 七、人工确认清单（这步不能省）

- [ ] 已关机断电，激光机已冷却 10-15 分钟
- [ ] 按屏幕提示的位置找纸，不是凭猜
- [ ] 顺纸路方向取纸，没有硬拽
- [ ] 手电检查过纸路，确认没有残片
- [ ] 搓纸轮检查过（脏了擦、磨了换）
- [ ] 纸张干燥、没有卷曲、没有订书钉
- [ ] 纸盒没有装太满，导纸板松紧合适
- [ ] 装回后打了测试页，报错已消除

## 八、最常见的坑

**坑一：不看提示位置，直接掀盖找纸。**
屏幕给的位置代码是最准的线索，凭猜容易漏掉真正的卡点。

**坑二：硬拽把纸撕断。**
残片留在纸路里，之后反复卡纸，还可能损伤定影组件。有阻力就停手换位置。

**坑三：提示卡纸却看不到纸就以为好了。**
多是传感器摆杆卡住、纸屑压在传感器上、或搓纸轮打滑根本没进纸。

**坑四：反复卡纸就一直换纸。**
多数是搓纸轮磨损或分离垫失效，换一包纸不解决问题。

**坑五：用湿巾擦搓纸轮。**
湿巾残留会让轮子更滑，越擦越不进纸。要用无水酒精配无绒布。

**坑六：激光机刚打完就拆机。**
定影单元温度很高，立即动手会烫伤，还会碰到未定影的碳粉。

**坑七：纸盒装到最满。**
装太满会增加多张进纸的概率，一般装到七分满即可。

**坑八：保修期内自行拆机。**
拆过可能失去保修。先走售后，尤其涉及定影组件的部分。

**坑九：用吸尘器吸碳粉。**
碳粉颗粒极细，普通吸尘器会泄漏，还可能损坏电机。

## 九、预防维护表

| 周期 | 项目 |
|---|---|
| 每次换纸 | 纸盒装七分满，抖散纸张，导纸板调到贴合 |
| 每月 | 无水酒精擦拭搓纸轮，检查分离垫 |
| 每季度 | 清洁纸路，打测试页检查进纸稳定性 |
| 换季 | 检查纸张是否受潮，密封存放并放干燥剂 |
| 长期不用 | 取出纸盒里的纸，避免受潮卷曲 |

## 十、边界与免责

- 本技能**不替代**拆机维修与厂家售后
- 机型结构差异大，**取纸路径以产品说明书与屏幕提示为准**
- 涉及定影组件、齿轮组、主板与传感器的故障，应由专业人员处理
- 保修期内不建议自行拆机，以免影响保修
- 碳粉、硒鼓相关操作请注意防护，避免吸入与强光照射感光鼓
