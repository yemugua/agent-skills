# 唱歌跑调

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 给出音准偏差的分级口径与自查方法 | 诊断失歌症、听力障碍或任何疾病 |
| 拆分跑调成因并给出对应训练动作 | 承诺练多久一定能唱准、一定能过选秀 |
| 说明监听、伴奏音量、拾音设备的设置口径 | 推荐药物、喷雾、手术或任何医疗处置 |
| 给每日训练流程与进度记录方式 | 说「五音不全是天生的改不了」这种结论 |
| 提示需要就医评估的情况 | 用他人录音做评价或比较 |

**必须转交专业人士的情况**

- 自觉听不到自己声音、长期耳闷、听力下降，或一侧耳朵明显更差 —— 先做听力检查
- 声音嘶哑持续超过两周、说话费力、咽喉痛持续不缓解 —— 耳鼻咽喉科评估
- 儿童长期完全无法模仿任何音高，且语言发育也落后 —— 儿科或听力言语门诊评估
- 唱歌时胸闷、头晕、明显气短 —— 停止训练并就医

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「我一唱歌就跑调，怎么练」 | 用 |
| 「五音不全能改吗」 | 用，说明多数可通过训练改善，不承诺结果 |
| 「怎么判断自己唱得准不准」 | 用，给音分口径与录音回听法 |
| 「清唱还行，一跟伴奏就跑」 | 用，重点查监听与伴奏音量 |
| 「高音上不去还跑调」 | 用，查音域与换声区 |
| 「孩子唱歌跑调要不要管」 | 用，给年龄相关说明与红线 |
| 「声音哑了两周还没好」 | 只作就医提示 |
| 「帮我听听这段音频准不准」 | 不提供音频判读，只给自测方法 |

## 三、完整工作流

1. **先量偏差，不靠感觉**：用带音分显示的校音 App 或钢琴，逐音记录偏差（单位音分，半音 = 100 音分）。先把「跑调」变成可统计的数字，否则无法判断练了有没有用。
2. **拆分成因**：按 `rules/跑调成因与对应训练.md` 判断属于听不准（感知）、发不准（控制）、音域不够、气息支撑不足，还是监听设置问题。成因不同，练法完全不同。
3. **定音域与换声区**：测出自己能稳定唱的最低音与最高音，确认曲目是否超出音域。超出音域的跑调，练多少都解决不了，要先换调。
4. **排训练顺序**：单音模仿 → 二音模进 → 音阶 → 短句 → 整句带伴奏。跳步练是最常见的失败原因。
5. **设置监听**：伴奏音量压到人声之下，能清楚听到自己的声音。戴耳机时至少留一只耳朵不戴。
6. **录音回听**：每轮训练录音，回听时对照原曲，只标记「偏高 / 偏低 / 方向错」，不做情绪评价。
7. **定周期复评**：每两周复测一次同样的测试曲目，用同一套指标比较。

## 四、核心规则与要件库

生成训练方案或音准建议前，**必须先读**：

- `rules/音准判定与偏差分级.md`：音分口径、分级阈值、系统性偏移与音程方向错误的判定。
- `rules/跑调成因与对应训练.md`：五类成因的识别特征、逐日训练流程、监听与设备设置。

不得把「跑调」笼统归因为天赋，也不得反过来承诺一定能纠正。不得建议任何通过憋气、挤压喉部、加大音量喊唱来「顶上去」的做法。

## 五、脚本用法

```
python scripts/singing_pitch_check.py --file case.json
python scripts/singing_pitch_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：逐音的目标音高与偏差音分、气息支撑自评、能否听到自己、伴奏速度 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--json` | 以 JSON 输出 |
| `--selftest` | 运行自检 |

脚本输出平均绝对偏差、命中率、系统性偏移、音程方向错误数、跑调分级和对应处方。**判定顺序是先查真实缺陷（偏差超标、方向错误、系统性偏移、音域越界），再看信息是否完整**，只填了两个音但偏差巨大时，会被判成有风险而不是待确认。

## 六、人工确认清单

- [ ] 已用带音分显示的工具量过至少 10 个音，不是凭感觉判断
- [ ] 音域已测，曲目未超出可稳定演唱的范围
- [ ] 已确认属于听不准还是发不准，练法与成因对应
- [ ] 伴奏音量已压到能听清自己声音
- [ ] 戴耳机时至少留一只耳朵，或使用开放式监听
- [ ] 训练顺序未跳步，单音阶段不稳就不上整句
- [ ] 每轮训练都录音并回听，只记偏高偏低不评价好听与否
- [ ] 已定两周后的复评时间点与同一套测试曲目
- [ ] 声嘶、耳闷、气短等情况已排除或已就医

## 七、最常见的坑

1. **凭感觉判断跑调**：「我觉得挺准的」和实测偏差 60 音分经常同时出现，必须有数字才有进步。
2. **一上来就练整首歌**：单音都模仿不准时练整首，只会把错误固化，进度为零。
3. **伴奏开得比人声大**：听不到自己就没法自我修正，这是「清唱还行、跟伴奏就跑」的首要原因。
4. **用喊的方式找高音**：喉部用力顶出来的高音普遍偏高且刺耳，还会造成声带疲劳。
5. **下行一律偏低**：句尾掉音多半是气息支撑不足，练气息而不是练耳朵。
6. **跳过大跳音程**：四度以上的跳进最容易唱错方向，要先单独练跳进再连成句。
7. **只练不录**：不回听就等于没有反馈，练多久都不会自动变准。
8. **把音域问题当音准问题**：超出音域的高音怎么练都上不去，换调才是正解。

## 八、边界与免责

本技能提供唱歌音准的自查口径、训练流程和监听设置建议，不构成医学诊断、听力评估或声乐水平评价。训练强度、曲目难度和进度因人而异，儿童、嗓音疾病患者、正在变声期的青少年应降低强度或先咨询声乐教师与医师。出现声音嘶哑持续两周以上、听力下降、胸闷气短等情况，请停止训练并就医。
