# 结构化面试评估表设计（interview-evaluation）

面试最大的浪费是**聊得很嗨、评得很糊**：问了一小时，凭感觉下结论。结构化面试的意义就一条——**同一个岗位，问同一套问题，按同一把尺子打分**。

这个技能做四件事：**定维度** → **编问题** → **会追问** → **校准分**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 讲解结构化面试设计与评估方法 | ❌ 替代用人决策 |
| 生成评估表与评分汇总 | ❌ 保证录用准确 |
| 整理校准与偏见规避口径 | ❌ 出具背景调查结论 |

**不得问与岗位胜任无关的隐私问题**（婚育计划、健康、宗教、户籍等），合规红线。

**永远不要**面试中临时改题目、改标准——那是对先面试者的不公平。

## 二、完整工作流

```
第 1 步  明确岗位与核心胜任力维度（3~6 个）
第 2 步  读规则文件 rules/interview_rules.md
第 3 步  按步骤取用：
    - 定维度 → 维度定义（第三节）
    - 编问题 → 行为锚定问题（第四节）
    - 会追问 → STAR 追问（第五节）
    - 校准分 → 评分锚与校准会（第六节）
    - 汇总分 → python scripts/interview_score.py --file 评分.json
第 4 步  按 templates/结构化面试评估表.md 输出
第 5 步  人工确认：维度与岗位匹配、问题合规、证据记录
```

---

## 三、维度定义（示例）

| 维度 | 定义 |
|---|---|
| 专业能力 | 岗位所需知识、技能、经验的深度 |
| 问题解决 | 分析复杂问题、结构化拆解、闭环推进 |
| 沟通协作 | 表达清晰度、倾听、跨部门推动 |
| 执行力 | 结果导向、优先级管理、抗压 |
| 学习成长 | 复盘能力、新领域上手速度 |
| 文化匹配 | 价值观、工作方式与团队契合 |

> 维度从**岗位的真实成功因素**倒推，不是从网上模板抄；一岗一策。

---

## 四、行为锚定问题设计

**原则**：问过去的行为，不问未来的意愿（"你会..."换成"你曾经..."）。

| 维度 | 示例问题 |
|---|---|
| 问题解决 | "讲一个你处理过最复杂的质量问题，当时怎么定位根因？" |
| 沟通协作 | "描述一次你推动跨部门配合却遇到阻力的情况，你怎么处理的？" |
| 执行 | "说一个你同时面对多个紧急任务的经历，你怎么排优先级？" |
| 学习 | "最近一次你在陌生领域快速上手是什么时候？你是怎么做的？" |

每题标注：考察维度、追问点、优秀回答特征。

---

## 五、STAR 追问法

```
Situation 情境 → Task 任务 → Action 行动 → Result 结果
```

- **Action 是重点**：追问"具体你做了什么"，把"我们"拆回"我"
- **量化**：数字、时间、范围、角色
- **反套路**：候选人说"我们团队完成了 X"，追问"你在其中负责哪部分"
- **压力验证**：对关键经历换角度复述，验证真实性

---

## 六、评分锚与校准

| 分值 | 锚定描述 |
|---|---|
| 5 | 显著超越岗位要求，有可验证的标杆案例 |
| 4 | 稳定达到要求，案例具体完整 |
| 3 | 基本达到，案例完整但深度一般 |
| 2 | 部分达到，案例模糊或靠提示 |
| 1 | 明显低于要求，无有效案例 |

**流程**：面试官**独立打分后**再合议（避免锚定效应）；分歧 ≥ 2 分的维度上校准会，用证据说话；最后按加权总分 + 红线项出录用建议。

**偏见规避清单**：相似光环、首因效应、刻板印象、非语言偏好——用同一套题、同一把尺、独立先评来对冲。

---

## 七、脚本用法（评分汇总）

```bash
python scripts/interview_score.py --file "D:\招聘\评分.json"
```

输出：各维度均分、面试官间分歧提示（≥2 分维度标红）、加权总分、录用建议区间。

> ⚠️ 脚本只做汇总与分歧提示，**不替代用人决策**。

---

## 八、人工确认（这步不能省）

- [ ] 维度是否从岗位成功因素倒推
- [ ] 问题是否行为锚定、无隐私违规
- [ ] 追问是否落到候选人本人的行动
- [ ] 评分是否独立完成后再合议
- [ ] 分歧维度是否用证据校准
- [ ] 红线项（诚信、合规）是否单独核查

---

## 九、输出结构（固定三段）

1. **候选人画像**——结论先行：推荐 / 待定 / 不推荐
2. **评分明细**——维度分、证据、分歧
3. **决策建议**——定薪定级参考、待核实事项

## 十、最常见的坑

**坑一：问题凭现挂。** 每个候选人问的不一样，分数没法比。

**坑二：把"我们"当"我"。** 团队业绩算个人头上，入职后落差巨大。

**坑三：先合议后打分。** 第一个人说完，后面全跟着第一印象走。

**坑四：眼缘分。** "聊得舒服"成了最高权重，能力维度全忽略。

**坑五：红线不问。** 诚信、合规、履历断层没人核，offer 发了才发现。
