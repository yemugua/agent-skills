# 标准物质与期间核查（reference-material）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据 CNAS-CL01 与计量相关要求，生成清单：标准物质（有证/内部）台账与有效期、储存条件与标识、期间核查策划与频次、核查方法与判定、记录与异常处置。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 标准物质
- 有证标准物质
- 期间核查
- 核查频次
- 标准物质有效期

## 三、工作流
1. 建立标准物质台账并关注有效期
2. 落实储存条件与标识
3. 策划期间核查与频次
4. 确定核查方法与判定
5. 做好记录与异常处置

## 四、核心内容（检查清单与判定）
标准物质应在有效期内并按条件储存；两次校准之间须做期间核查以维持置信度，核查方法与判定应明确并留记录。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含标准物质台账与有效期 | 台账 |
| Q2 | FAIL | 未含储存条件与标识 | 储存 |
| Q3 | WARN | 未含期间核查策划与频次 | 核查 |
| Q4 | FAIL | 未含核查方法与判定 | 方法 |
| Q5 | WARN | 未含记录与异常处置 | 记录 |

> 脚本 `reference-material_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python reference-material_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python reference-material_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
