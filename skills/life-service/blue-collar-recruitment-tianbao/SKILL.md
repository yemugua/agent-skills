# 蓝领批量招聘（blue-collar-recruitment）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据批量招聘运营方法，生成清单：需求波峰测算与产能规划、渠道组合与到面转化、面试流程与极速入职、体检体检与岗前安全培训、到岗留存与流失预警。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 蓝领招聘
- 批量招聘
- 产线工人招聘
- 到岗率提升
- 批量入职

## 三、工作流
1. 测算需求波峰与产能缺口
2. 组合渠道并提升到面转化
3. 压缩面试流程实现极速入职
4. 安排体检与岗前安全培训
5. 建立到岗留存与流失预警

## 四、核心内容（检查清单与判定）
蓝领招聘比拼的是到岗率与首月留存，而非简历量。压缩等待时间、当天面当天定、入职首日有人接，往往比多发招聘广告更有效。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含需求测算与产能规划 | 测算 |
| Q2 | FAIL | 未含渠道组合与到面转化 | 渠道 |
| Q3 | WARN | 未含面试流程与入职时效 | 时效 |
| Q4 | FAIL | 未含体检与岗前安全培训 | 培训 |
| Q5 | WARN | 未含留存与流失预警 | 留存 |

> 脚本 `blue-collar-recruitment_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python blue-collar-recruitment_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python blue-collar-recruitment_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
