# 微型消防站运行管理（micro-fire-station-run）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《消防安全重点单位微型消防站建设标准》，生成微型消防站运行清单：站点设置（3分钟到场）、人员装备、值守训练、联勤联动、台账管理。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 微型消防站
- 微站运行
- 微站建设
- 义务消防队
- 3分钟到场

## 三、工作流
1. 明确建站范围（重点单位/社区）与3分钟到场要求
2. 配齐人员与装备（灭火器/水枪/防护服）
3. 落实值守与日常训练
4. 纳入消防救援机构联勤联动
5. 运行台账与拉动演练

## 四、核心内容（检查清单与判定）
微型消防站应做到「3分钟到场」初起处置；配备必要的灭火器材和防护装备，定期开展体能与技能训练，并纳入统一调度。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未明确建站范围与3分钟到场要求 | 建站 |
| Q2 | FAIL | 未含人员与装备配备 | 装备 |
| Q3 | WARN | 未含值守与日常训练 | 训练 |
| Q4 | WARN | 未含联勤联动 | 联动 |
| Q5 | FAIL | 未含运行台账/拉动演练 | 台账 |

> 脚本 `micro-fire-station-run_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python micro-fire-station-run_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python micro-fire-station-run_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
