# 离职面谈（exit-interview）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据离职管理实践，生成离职面谈清单：面谈对象与时机、结构化问题（真实原因/管理/薪酬/发展）、记录与保密、归因分析与组织改进、离职手续与知识交接。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 离职面谈
- 离职访谈
- 离职原因分析
- 离职手续
- 员工离职访谈

## 三、工作流
1. 确定面谈对象与时机
2. 设计结构化问题（原因/管理/薪酬/发展）
3. 规范记录与保密
4. 做归因分析并推动组织改进
5. 办理离职手续与知识交接

## 四、核心内容（检查清单与判定）
离职面谈的价值在于获取真实离职原因并推动组织改进；须结构化提问、注意保密，并同步做好知识交接与手续闭环。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含面谈对象与时机 | 对象 |
| Q2 | FAIL | 未含结构化问题设计 | 问题 |
| Q3 | WARN | 未含记录与保密 | 记录 |
| Q4 | FAIL | 未含归因分析与组织改进 | 归因 |
| Q5 | WARN | 未含离职手续与知识交接 | 交接 |

> 脚本 `exit-interview_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python exit-interview_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python exit-interview_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
