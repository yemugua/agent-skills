# 电动车上牌办理操作卡

## 第一步：先自己核三项（5 分钟，能省两趟）

1. **翻合格证**：拍照存档。看五项——有没有脚踏、车速多少、整车多重、电机多少 W、电池多少 V；
2. **看铭牌与钢印**：车架号（车辆识别代号）打刻在哪、清不清楚；铭牌在不在；
3. **问自己三句**：
   - 这车是不是我买的新车？发票在我手上吗？
   - 我有没有改过它（解限速、加电池、装后座、装伞）？
   - 我有 D/E 驾照吗？有交强险吗？

> 只要第 3 问里有一项是"没有"且车速/电压超标 → 直接走**机动车路径**（第 4 步），别按电动自行车去办，白跑。

## 第二步：按车种分两条路径

### 路径 A：五项全符合 → 非机动车（电动自行车）

1. 准备：身份证原件、购车发票（或销售证明）、合格证、车；
2. 检查车辆有没有改装：解限速、加电池、加后座/儿童座椅、装遮阳伞/雨棚 → **一律先拆回原状**；
3. 选办理渠道（三选一）：
   - **车管所窗口**：最稳，材料最全；
   - **"带牌销售"网点**：当场出牌，先确认网点有交管业务资质；
   - **线上（12123 / 当地交警小程序）**：申请邮寄号牌；
4. 现场：查验车辆、拓号（打号）、装牌、领行驶证；
5. 拿证后记住三件事：**戴头盔、走非机动车道、不要进楼入户充电**。

### 路径 B：任一项超标 → 机动车（电动轻便摩托车/电动摩托车）

1. 确认自己 **有 D 或 E 驾照**（没有就去考，别无证上路）；
2. 买 **交强险**；
3. 带身份证、发票、合格证、车辆、保单、驾驶证去车管所上**机动车号牌**；
4. **年龄门槛**：驾驶摩托车类需满 18 周岁，轻便摩托车一般需满 16 周岁，未满别骑；
5. 若当地给超标车发了**过渡期临时号牌**：记下截止日，到期前必须置换或转机动车牌。

## 第三步：卡点怎么办（按顺序试）

| 卡点 | 先做什么 | 还不行找谁 |
|---|---|---|
| 发票丢了 | 找销售补开销售证明/承诺书（盖章） | 12315 市场监管、12345 |
| 合格证没了 | 联系厂家/经销商按车架号补办 | 市场监管（三无产品） |
| 合格证型号与车不符 | **别拿去上牌**，属套牌合格证 | 12315 投诉 |
| 买过改装车 | 先恢复原状再去查验 | 销售方承担恢复责任 |
| 二手车原车主失联 | 12123 查车辆状态（抵押/查封/违法） | 车管所咨询、必要时民事诉讼 |
| 车架号磨没了 | 补打车架号/铭牌（指定企业） | 车管所窗口 |
| 异地户籍要居住证 | 先办居住证或暂住登记 | 当地公安户籍窗口 |

## 第四步：窗口话术（照着说）

- **问材料**："我这车合格证型号是 XXX，要办电动自行车注册登记，需要带哪些材料？能不能现场查验、当场出牌？"
- **问定性**："我这车合格证写着最高车速 28、整车 60 kg，按新国标算机动车对吧？那我要办机动车牌，是不是要交交强险和 D/E 证？"
- **问改装**："车我加装过后座，现在要恢复原状才能上牌是吧？恢复完能不能当场重查验？"
- **问过渡期**："我这辆超标车，咱们市过渡期临时号牌到哪一天？到期以后还能不能上路？到期不换会怎么处罚？"
- **问二手车**："原车主联系不上了，这车怎么过户上我名下？有没有抵押或查封？"

## 第五步：办完别忘

- [ ] 号牌按规定安装、不遮挡；
- [ ] 行驶证随身/随车（部分地区电子证即可）；
- [ ] 头盔买好，载人与充电遵守当地规定；
- [ ] 记下车架号、发票号、合格证编号，拍照存档；
- [ ] 过渡期临时牌的**截止日**写进日历提醒。

## 第六步：被查/被罚之后

- 现场被拦：配合查验，要求出具**处罚决定书**（上面会写依据和复议/诉讼期限，一般 60 日复议、6 个月诉讼）；
- 对认定不服：先 12123 与交警公众号查认定依据，再申请行政复议或提起行政诉讼；
- 与销售扯皮（承诺包上牌却办不成）：聊天记录 + 宣传页截图 + 转账凭证 = 证据，先 12315/12345，再考虑诉讼。

## 第七步：纪律

- 各地材料口径、工本费、过渡期、载人年龄**差异很大，一律以当地公安交管部门最新公告与现场要求为准**；
- 本卡只是**操作顺序与话术**，不是当地政策的承诺；
- 不代开证明、不代办虚假材料、不买代开发票。
