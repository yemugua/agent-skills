# 电动车上牌信息采集表

> 照着**产品合格证**和**车身铭牌**抄，抄不出来就留空。**留空 = 未填，脚本一律按"待补正"处理，不算通过。**
> 字段后带 `*` 的是关键项，缺了会直接卡住结论。

## 一、车主与所在地

| 字段 | 填什么 |
|---|---|
| 车主姓名* | 与身份证一致 |
| 常住城市* | 例如：杭州市（过渡期、限行、材料全按城市走） |
| 是否本人办理 | 是 / 否（委托代办） |
| 代办方式 | 本人办理 / 门店带牌销售代办 / 他人代办 |
| 是否已安装并登录交管12123 | 是 / 否 |
| 是否需要异地户籍材料（居住证/暂住登记） | 有 / 无 / 待确认 |

## 二、车辆指标（五项硬指标，缺一项即变机动车）

| 字段 | 填什么 |
|---|---|
| 车辆品牌型号* | 合格证上的型号，例如：TDT123Z |
| 是否有脚踏骑行能力* | 有 / 无 |
| 最高设计车速（km/h）* | 例如：25 |
| 装配完整的整车质量（kg）* | 例如：52 |
| 电动机额定连续输出功率（W）* | 例如：350 |
| 蓄电池标称电压（V）* | 例如：48 |
| 有无 CCC 认证标识 | 有 / 无 |
| 车辆类型（铭牌/合格证写法） | 电动自行车 / 电动轻便摩托车 / 电动摩托车 |

## 三、购车与车况

| 字段 | 填什么 |
|---|---|
| 购车日期* | YYYY-MM-DD |
| 购买渠道 | 品牌门店 / 电商 / 二手车 / 以旧换新 |
| 购车发票 | 有 / 无 / 丢失 |
| 发票品名 | 例如：电动自行车 |
| 产品合格证 | 有 / 无 / 缺失 |
| 合格证型号与实车是否一致 | 一致 / 不一致 |
| 是否改装过 | 是 / 否 |
| 改装项目 | 例如：解限速、加装后座、装遮阳伞、换电池 |
| 是否为二手车 | 是 / 否 |
| 二手车转让手续 | 双方到场 / 转让协议 / 无手续 |
| 车架号（车辆识别代号） | 打刻在立管/后叉上的钢印号 |
| 车架号是否清晰可辨 | 清晰 / 磨损 / 缺失 |
| 铭牌是否完整 | 完整 / 脱落缺失 |

## 四、资质与保险（判定为机动车时最关键）

| 字段 | 填什么 |
|---|---|
| 本人是否已取得摩托车类驾驶证（D/E/F） | 有 / 无 |
| 驾驶证准驾车型 | 例如：D / E / F / C1 / 无 |
| 是否已投保交强险 | 有 / 无 |
| 驾驶人是否已年满 16 周岁 | 是 / 否 |
| 是否已年满 18 周岁 | 是 / 否 |

## 五、办理情况

| 字段 | 填什么 |
|---|---|
| 拟办理渠道 | 车管所窗口 / 带牌销售网点 / 线上12123 / 未定 |
| 当地是否对超标车设过渡期（临时号牌） | 是 / 否 / 不清楚 |
| 过渡期截止日（若已知） | YYYY-MM-DD（不知道就留空） |
| 号牌是否已办 | 未办 / 已上非机动车牌 / 已上机动车牌 / 已上临时号牌 |
| 是否已被查处过 | 无 / 被警告 / 被罚款 / 被扣车 |
| 与销售的纠纷 | 无 / 商家拒绝上牌 / 商家失联 / 已向12315投诉 |
