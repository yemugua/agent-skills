# 二、上牌材料与卡点分支

> 材料口径**各地差异很大**，本文件给的是通用框架。凡标注"以当地口径为准"的，一律以当地公安交管部门、车管所现场要求为准。

## 1. 通用材料清单（电动自行车 / 非机动车上牌）

| 材料 | 要求 | 常见卡点 |
|---|---|---|
| 车主身份证明 | 居民身份证原件 | 代办需额外委托书与代办人身份证 |
| 购车发票或其他销售凭证 | 能证明合法来源与购车时间 | 发票丢失、发票抬头是他人、只给收据不给发票 |
| 产品合格证 | 与实车一致、带 CCC 认证标识 | 合格证缺失、型号与实车不符、无 CCC |
| 车辆本身 | 现场查验、打号（拓号） | 改装车不予登记，见第 3 节 |
| 居住证 / 暂住登记凭证 | 异地户籍或异地购车办理时，部分地区要求 | 以当地口径为准 |
| 委托书 | 委托销售门店、他人代办时 | 需本人签字，个别地区要求公证或现场核验 |

**办理渠道**：

1. **车管所（公安交管部门）窗口**——最通用的渠道，材料最全、口径最稳；
2. **"带牌销售"网点**——品牌门店/销售点驻场代办，多数只需带齐证件，当场出牌，但要确认网点有交管业务资质；
3. **线上办理**——部分城市可在交管 12123 APP 或当地交警小程序申请，快递寄牌；
4. **公安交管"流动车管所"/ 社区专场**——部分城市对新建小区、乡镇设专场。

**工本费**：电动自行车号牌与行驶证工本费各地不同（通常几十元以内），以窗口公示为准。

## 2. 卡点分支（按顺序判断）

### 2.1 发票丢失 / 只有收据

- 先找销售方**补开销售证明**（写明车辆品牌型号、车架号、销售日期、销售方盖章），或由销售方出具**购车情况说明 + 承诺书**；
- 票据已遗失且销售方不配合的，可携带身份证到**当地市场监管（12315）投诉补开**，或向市场监管部门反映"三无"销售；
- **不要买"代开发票"**，虚开、代开属于提供虚假材料，一旦被查登记可能被撤销，且涉及责任；
- Vendor 注销、门店跑路的，以当地口径为准，向 12345 与市场监管反映。

### 2.2 合格证缺失 / 合格证型号与车不符

- 联系**生产厂家或经销商补办合格证**（提供车架号、购货记录）；
- 合格证上是别的型号（"套牌合格证"）的，**不要拿去上牌**——型号与实车不符会被现场查验驳回，且涉嫌提供虚假材料；
- 完全无合格证的，属三无产品，向市场监管（12315）反映并要求处理，能否登记以当地交管认定为准。

### 2.3 改装车（最常见、最容易被拒）

以下情形**通常不予登记**，必须先恢复原状：

| 改装 | 为什么 |
|---|---|
| 解限速（刷控制器、改控制器参数） | 改变最高设计车速，直接改变车种定性 |
| 加装/更换电池（尤其加组、换 60 V/72 V） | 改变电池标称电压与整车质量 |
| 加装后座、儿童座椅、货箱 | 改变整车结构与质量 |
| 加装遮阳伞、雨棚、挡风被（加装类） | 改变外形，且上路本身违法、易被处罚 |
| 改变车架、更换电机 | 车辆识别代号与合格证不一致 |

**正确做法**：先到车管所/销售网点做**恢复原状（还原）**，再重新申请查验。改装过的车即使上了牌，上路被查仍可能因"擅自改变机动车/非机动车外形"被处罚，且事故后保险可能拒赔、商家与你之间的改装责任纠缠不清。

### 2.4 二手车（含"原车主联系不上"）

- 二手车转让需**双方共同到场**或**原车主签字转让协议/交易证明**；
- 车款付清、原车主要求先过户才放车款的，签好**转让协议并留存聊天记录与转账凭证**；
- 原车主失联的：先通过 12123 / 车管所查询车辆状态（是否有抵押、查封、未处理违法），再走当地二手自行车/电动车过户流程；仍办不了的，向 12345 与市场监管咨询，必要时走民事诉讼确认归属；
- 分期/以旧换新带回来的车，确认原车主是否已注销、是否仍有抵押登记。

### 2.5 车架号（车辆识别代号）问题

- 车架号(车辆识别代号)被打刻不清、磨损、被打磨过的，**不予登记**；
- 铭牌脱落缺失的，先补打铭牌/重打车架号（需到车管所或指定维修企业，按当地口径办）。

## 3. 机动车（超标车）上牌的额外材料

若第 `ebike-classify.md` 一步判定为机动车，除上表外还需：

- 机动车交通事故责任强制保险（交强险）保单；
- 对应驾驶证（D/E 证）；
- 机动车注册登记所需的其他材料（以车管所窗口为准）；
- **年龄门槛**：驾驶摩托车类需符合法定年龄（通常 18 周岁，轻便摩托车 16 周岁），未成年人不予发证。

## 4. 材料齐备度怎么判

判定三态：

- **已有**（有原件、与实车一致、在有效期内）；
- **缺失**（明确写了没有/丢失）；
- **待补正**（未填或填的是"待填""填什么""有/无"这类提示串——一律不算具备）。

**未填的一律不算通过**，必须提示补齐后再判。
