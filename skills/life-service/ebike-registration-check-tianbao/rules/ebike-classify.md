# 一、车种定性：非机动车还是机动车

## 1. 为什么这一步必须最先做

上错部门、跑错窗口，绝大多数"上不了牌"都是**车种定性错**导致的：

- 符合国标的电动自行车 → **非机动车**，上**电动自行车号牌**（各地样式不同，多为绿牌/白牌），**不需要驾驶证**，不需要买交强险；
- 不符合国标的车 → 按 **电动轻便摩托车 / 电动摩托车** 处理，属**机动车**，要：
  - **机动车号牌**（黄底黑字的摩托车号牌）；
  - **相应驾驶证**：电动轻便摩托车一般需 **D 或 E** 证，电动摩托车需 **D 或 E** 证（F 证只能驾驶轻便摩托车）；
  - **机动车交通事故责任强制保险（交强险）**；
  - 骑电动自行车需年满 16 周岁；驾驶轻便摩托车需年满 16 周岁，驾驶摩托车需年满 18 周岁。

**只要上路被认定"无证驾驶""驾驶无牌机动车"，罚款、扣车、扣证的后果远重于上牌本身。**

## 2. 新国标的五项硬指标（GB 17761《电动自行车安全技术规范》）

同时满足全部五项，才属于电动自行车（非机动车）：

| 指标 | 限值 |
|---|---|
| 具有脚踏骑行能力 | 必须有（脚踏结构） |
| 最高设计车速 | ≤ 25 km/h |
| 装配完整的整车质量 | ≤ 55 kg（2018 版为 55 kg；2024 版对部分指标作调整并设置过渡期，具体以合格证标注的产品执行标准与当地交管认定为准） |
| 电动机额定连续输出功率 | ≤ 400 W |
| 蓄电池标称电压 | ≤ 48 V |

**任何一项不满足 → 不属于电动自行车 → 按机动车（电动轻便摩托车 / 电动摩托车）管理。**

实务判定的优先证据顺序：

1. **产品合格证**（载明产品型号、执行标准、厂牌型号）——最直接；
2. 车辆铭牌 / CCC 认证标识；
3. 实际参数（车速、重量、电压）现场测量；
4. 购车发票（发票品名写"电动自行车"还是"电动车""摩托车"，可佐证来源）。

> 注意：车速可以在店里解限速后跑得更快，但**定性的依据是设计指标，不是你实际骑多快**。解了限速照样可能按原设计指标认定——而且改装本身会导致不予登记。

## 3. 四个最容易搞错的情形

- **"看着像自行车"**：有无脚踏不是唯一标准，还要看车速、质量、电压、功率。有脚踏但车速超标，仍是机动车。
- **"商家说是电动车"**：销售口头承诺、门店"包上牌"宣传，都不能替代产品标准和交管认定。**"包上牌"常常是超标车套路——帮你挂的可能是机动车牌或临时号牌，而你并没有驾驶证。**
- **"电池是后来换的"**：换成非原厂电池（尤其 60 V / 72 V）、加装电池仓，既改变电池标称电压的认定，也属改装。
- **"旧车买了没骑过"**：购车时间决定它属于旧国标存量车、新国标车还是超标车，直接影响能不能上牌，见 `ebike-compliance.md`。

## 4. 定性结论要怎么写

报告里必须同时给出三件事，缺一不可：

1. 定性结论（非机动车 / 机动车 + 具体车型）；
2. 依据（哪一项指标不符合、实测值与限值各是多少；或"五项全部符合"）；
3. **一个明确的口径**：最终以合格证标注与当地公安交管部门认定为准，不给"一定算机动车"的绝对承诺。

## 5. 常见误区速查

| 说法 | 真相 |
|---|---|
| "有脚踏就是非机动车" | 错，还要同时满足车速、整车质量、电压、功率 |
| "不上牌也能骑，我骑了没事" | 电动自行车号牌是上路前提，无牌上路会被处罚、扣车 |
| "超标车过渡期没到，随便骑" | 过渡期以当地公告的起止日为准，多数城市已到期或临近到期 |
| "我骑的是电动车不是机动车" | 超标车在交管系统里就是机动车，按机动车管理 |
| "交警不查就查不到我" | 一旦认定无牌无证，还可能被扣车、影响后续摩托类驾照申领 |
