# 三、过渡期、上路合规、无牌后果与当地规则查询

## 1. 超标车过渡期（各地最不一致的一块）

**不要指望任何通用答案**——过渡期是**省级/市级**设定的，期限从几个月到数年不等，且**多数城市已到期或即将到期**。

判定时要按 **"所在城市 + 购车时间 + 是否符合新国标"** 三要素分支：

| 情形 | 一般走向 | 结论口径 |
|---|---|---|
| 符合新国标 + 当地未限行 | 上电动自行车号牌（非机动车） | 可正常上路 |
| 符合新国标 + 当地对旧标车设限行 | 按当地限行区域/时段管理 | 以当地公告为准 |
| 超标（机动车）+ 当地有过渡期且未到期 | 挂**过渡期临时号牌**，限期内可上路 | 仍须戴头盔、按道行驶；临时牌到期即失效 |
| 超标 + 过渡期已到期 | 不得上路；继续上路按机动车无牌无证处理 | 尽快置换合规车或考 D/E 证上正规机动车牌 |
| 超标 + 当地从未设过渡期 | 直接按机动车管理 | 无机动车牌、无驾照不得上路 |

**必做的动作**：报告里必须给出**查询入口**，让用户自己核到截止日，而不是替他编一个日期。

### 当地规则查询入口（按顺位）

1. **交管 12123 APP** — 首页办事指南、附近网点查询、预约办理；
2. **当地交警微信公众号 / 小程序** — 发布过渡期公告、限行区域、临时号牌换发通知；
3. **当地公安交管部门（车管所）窗口电话** — 最可依赖，现场问一句最准；
4. **当地人民政府 / 公安交警官网** — 正式公告原文；
5. **12345 政务服务热线** — 以上渠道都查不到时的兜底，问到会形成工单回复。

> 若用户未填城市，**必须先提示补城市**，因为过渡期、限行、材料要求全是按城市走的。

## 2. 上牌后的上路合规（不论非机动车还是机动车）

- **戴头盔**：电动自行车驾驶人及乘坐人应当佩戴安全头盔（多地已强制，违者可处罚）。
- **按道行驶**：走非机动车道；没有分道规则的靠右侧通行，**不得逆行、不得闯红灯、不得占用机动车道**。
- **载人**：电动自行车载人按各地规定不同——多数城市允许搭载 1 名 12 周岁以上/以下儿童的规定不一，**以当地口径为准**；轻便摩托车、摩托车载人另有规则。
- **充电安全**：**禁止违规充电、禁止飞线充电、禁进楼入户充电、禁在楼梯间停放充电**；使用匹配的充电器。
- **不得擅自改装**：改装（解限速、加电池、加遮阳伞等）既是上牌障碍，也是上路违法、事故拒赔的高发原因。
- **牌证随身/随车**：号牌要按规定安装、不得遮挡；行驶证随车携带（部分地区电子证即可）。
- **未成年人**：不满 16 周岁不得驾驶电动自行车。

## 3. 无牌 / 不合规上路的后果

| 情形 | 常见后果 |
|---|---|
| 电动自行车无牌上路 | 警告或罚款、责令补办登记、扣留车辆 |
| 机动车（超标车）无牌上路 | 按上道路行驶的机动车未悬挂号牌处罚：罚款、扣留车辆 |
| 机动车无牌且驾驶人无驾驶证 | 按**无证驾驶**处罚；情节严重可处拘留 |
| 伪造/变造/套用号牌 | 处罚更重，可能扣证、拘留，并承担刑事责任风险 |
| 过渡期临时牌过期仍上路 | 视同无牌，按当地规定处罚；车辆可能被扣留 |
| 改装车上路 | 责令恢复原状并处罚，事故后保险可能拒赔 |

> 具体罚款金额、扣车期限、是否拘留，各地裁量不同，**以当地公安交管部门处罚决定为准**。本技能只给风险提示，不预测处罚结果。

## 4. 买车前的预防（比事后补牌省事得多）

1. 下单前**核对合格证**五项指标与 CCC 标识，拍照存档；
2. 问清销售"能不能上牌、上哪种牌、要不要驾照"——**要求书面/聊天记录留痕**，商家承诺可佐证；
3. **不要买解过速、加过电池、装过遮阳伞的展车/特价车**；
4. 发票抬头写自己；保留聊天记录、合同、转账凭证；
5. 优先选有 **"带牌销售"资质**的门店，当场把牌办了再提车；
6. 二手交易走正规过户，别私下"给钱就骑走"。

## 5. 与销售发生纠纷时

- 商家承诺"包上牌"却办不了的：以聊天记录、宣传页为证，向 **12315 / 市场监管**投诉其虚假宣传，主张退货退款；
- 买到超标"新国标"车却上不了牌：主张**欺诈/违约**，要求退车退款；
- 销售解限速、加装改装导致无法登记：责任在销售方，**要求恢复原状并赔偿补办损失**。
- 渠道顺位：销售方交涉 → 平台（OTA/电商）介入 → 12345 → 市场监管 12315 → 消费者仲裁/诉讼。

## 6. 纪律

- 本文件依**通用规则**整理，**不替代当地主管部门认定**；
- 不内置任何城市的过渡期截止日、罚款金额、载人年龄上限；
- **未填的一律不算通过**，只按填了的判断。
