# 电动车上牌资格核查

很多人不知道自己买的是**机动车**。超了新国标指标的电动车属于电动轻便摩托车 / 电动摩托车，要上机动车号牌、持 D/E/F 驾驶证、投保交强险——缺一样就是无证驾驶、无牌上路。

## 什么时候用

- 买了电动车，不知道能不能上牌、要带什么
- 不知道自己这辆车算非机动车还是机动车
- 发票丢了、合格证找不到了，还能不能办
- 改装过（解限速、加装电池、装遮阳伞），担心不给上牌
- 买的二手车，原车主联系不上
- 超标车、临时号牌快到期，不知道还能骑多久
- 已经无牌上路，想知道会有什么后果

## 怎么做

**第 1 步**：复制 `templates/电动车上牌信息采集表.md` 填写（照着合格证和铭牌抄，填不出来就空着）。

**第 2 步**：跑脚本

```bash
python scripts/ebike_check.py 采集表.md --base 2026-10-05 --out 核查报告.md
```

**第 3 步**：按第八段"待办补正动作"执行；第六段是当地规则的查询入口。

## 先分车种（最关键的一步）

符合 GB 17761《电动自行车安全技术规范》的电动自行车属**非机动车**，要同时满足：

| 指标 | 限值 |
|---|---|
| 具有脚踏骑行能力 | 必须有 |
| 最高设计车速 | 不超过 25 km/h |
| 装配完整的整车质量 | 小于或等于 55 kg |
| 电动机额定连续输出功率 | 小于或等于 400 W |
| 蓄电池标称电压 | 小于或等于 48 V |

→ **任何一项不满足，就不属于电动自行车**，按电动轻便摩托车 / 电动摩托车（**机动车**）管理：上机动车号牌、持 D/E/F 驾驶证、投保交强险，缺一项上路即可能被按无牌无证处理。

> 注：GB 17761 先后有 2018 版与 2024 版，现行版本对部分指标（如整车质量上限）有调整并设置过渡期。**具体以合格证标注的产品执行标准与当地公安交管部门认定为准**。

## 上牌材料（电动自行车，非机动车）

| 材料 | 说明 |
|---|---|
| 车主身份证明 | 居民身份证 |
| 购车发票或其他销售凭证 | 增值税发票、销售凭证均可，须能证明合法来源 |
| 产品合格证 | 带 CCC 认证 |
| 车辆本身 | 需现场查验、拓号 |
| 居住证或暂住登记 | 异地户籍办理的，部分地区要求，以当地口径为准 |
| 委托书 | 委托代办时需要 |

## 输入 / 输出

| | 内容 |
|---|---|
| 输入 | 采集表 Markdown（车主 / 车辆指标 / 材料 / 驾照保险 / 办理方式） |
| 输出 | 九段报告：结论摘要 / 车种定性 / 能不能上牌 / 卡点分支 / 超标车与过渡期 / 当地规则怎么查 / 后续合规 / 待办 / 纪律 |
| 退出码 | 0 正常；2 关键信息缺失（给提示串，不崩） |

## 边界与纪律

- 依 GB 17761《电动自行车安全技术规范》、机动车登记相关规定的**通用规则**整理，**不替代主管部门认定**
- **不承诺一定能上牌、不代办登记、不代开证明**
- 登记材料口径、过渡期期限、载人年龄限制、带牌销售网点、工本费等**各地差异很大**，一律以当地公安交管部门最新公告为准
- **未填的一律不算通过**，只按填了的判断
