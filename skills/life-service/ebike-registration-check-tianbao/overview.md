# 概览：电动车上牌资格核查

## 解决什么问题

买电动车的人，绝大多数卡在三件事上：

1. **不知道自己买的是机动车**——超了新国标指标的电动车属于电动轻便摩托车 / 电动摩托车，要驾照、要交强险、要机动车号牌，缺一样就是无牌无证；
2. **不知道差哪份材料**——跑一趟车管所才发现发票不合格、合格证没 CCC、异地户籍还要居住证，来回两三趟；
3. **不知道过渡期**——超标车的临时号牌各地期限不同，多数已到期或临近到期，过渡期满后不得上路，很多人是骑到被查才知道。

本技能先做**车种定性**，再查**材料齐不齐**，最后给**卡点分支与当地查询入口**。

## 输入 → 输出

```
采集表（车辆五项指标 / 铭牌类型 / 购车时间 / 材料 / 驾照保险 / 办理方式）
        │
        ▼
  ┌──────────────────┐
  │ 车种定性         │  脚踏 25km/h 55kg 400W 48V → 非机动车 or 机动车
  ├──────────────────┤
  │ 能不能上牌       │  身份证 / 发票 / 合格证 / 实车 / 居住证
  ├──────────────────┤
  │ 卡点分支         │  发票丢失 / 合格证缺失 / 改装 / 二手车
  ├──────────────────┤
  │ 超标车与过渡期   │  购车时间 × 是否符合新国标 × 当地公告
  ├──────────────────┤
  │ 当地规则怎么查   │  12123 / 交警公众号 / 车管所
  ├──────────────────┤
  │ 后续合规 + 待办  │  头盔、载人、充电、改装
  └──────────────────┘
```

## 和其他工具的区别

常见内容要么是"上牌需要什么材料"的清单，要么是"新国标是什么"的科普。本技能做的是**个案判定**：

- 给的是"你**这辆车**算什么、差哪几样、卡在哪一步"，不是通用清单；
- 五项指标、材料齐备度、卡点分支都是**可计算的判定逻辑**；
- 地域差异大的项一律输出**查询入口**，不编造当地政策。

## 不做的事

- 不内置任何城市的过渡期截止日、工本费、载人年龄上限
- 不承诺一定予以登记、不代办、不代开证明
- 不判断车辆质量与安全性、不做产品推荐

## 适用人群

刚买电动车的人、买了二手车的人、发票合格证有问题的车主、改装过的车主、超标车与临时号牌持有者、门店销售与带牌销售网点经办。
