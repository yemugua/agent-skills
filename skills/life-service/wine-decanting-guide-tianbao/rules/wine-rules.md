# 红酒醒酒规则库

本文件是醒酒判断的核心资产，先读再做判断。

## 一、是否需要醒酒

| 特征 | 建议 |
|---|---|
| 年轻（<5 年）、单宁重、封闭香气 | 需要，用醒酒器 |
| 中等酒体、果香略闷 | 需要，30–60 分钟 |
| 老酒（>15 年） | 谨慎，短时瓶醒或不过滤 |
| 清淡型（部分黑皮诺、起泡外的轻酒体） | 多不需醒 |
| 已有明显醋味/氧化味 | 不必醒，已过度 |

## 二、醒酒时长区间

| 类型 | 醒酒器时长 | 瓶醒时长 |
|---|---|---|
| 年轻重单宁（赤霞珠/西拉） | 60–120 分钟 | 2–3 小时 |
| 中等酒体 | 30–60 分钟 | 1–2 小时 |
| 老酒（>15 年） | 15–30 分钟且谨慎 | 30–60 分钟 |
| 清淡型 | 不建议 | 15–30 分钟 |

## 三、瓶醒 vs 醒酒器

- 醒酒器：加大接触面，促氧化，适合年轻封闭酒。
- 瓶醒：仅开瓶静置，氧化慢，适合老酒或不确定时。
- 过度氧化信号：果香消散、出现明显醋味/坚果氧化味，应立即停醒。

## 四、老酒沉淀处理

1. 饮用前直立静置 24 小时（或数小时）让沉淀沉底。
2. 开瓶后缓慢沿杯/醒酒器壁倒酒，避免扰动。
3. 末段见渣即停，弃去带渣部分。
4. 老酒尽量不过滤，过滤会损失香气与酒体。

## 五、不合格判定口径

| 现象 | 原因 | 处理 |
|---|---|---|
| 老酒醒酒器 >60 分钟 | 香气散尽变寡 | 缩短或改瓶醒 |
| 醒酒 >2 小时仍继续 | 氧化过头出醋味 | 立即停醒 |
| 有沉淀不直立直接倒 | 满口渣 | 先直立再慢倒 |
| 清淡酒猛醒 | 更淡寡 | 不醒或短时瓶醒 |
| 已氧化酒还醒 | 雪上加霜 | 不再醒 |
