# 红酒醒酒

## 1. 硬边界表

| 能做 | 不能做 |
|---|---|
| 判断酒是否需要醒 | 替代你对酒款真伪/年份价值的判断 |
| 给醒酒方式与时长区间 | 承诺醒酒后口感一定变好 |
| 给老酒沉淀处理步骤 | 做酒类鉴定或投资评估 |
| 提示过度氧化信号 | 处理酒精相关健康事件 |

## 2. 什么时候用

| 用户说法 | 用本技能 |
|---|---|
| 「这瓶酒要醒吗」 | 用 |
| 「醒多长时间」 | 用 |
| 「老酒有沉淀怎么办」 | 用 |
| 「这酒值多少钱」 | 不用，属鉴定 |

## 3. 完整工作流

1. 看酒的类型与年份（年轻单宁重/老年份）。
2. 按 `rules/wine-rules.md` 判断是否需醒、用瓶醒还是醒酒器。
3. 年轻酒用醒酒器促氧化；老酒谨慎、短时或不过滤。
4. 处理沉淀：直立静置后缓慢倒酒，末段弃去。
5. 计时，避免超时过度氧化。
6. 对照人工确认清单核对后再饮。

## 4. 核心规则

先读 `rules/wine-rules.md`：需醒酒特征、分类型醒酒时长区间、瓶醒与醒酒器选择、老酒沉淀处理、过度氧化信号。

## 5. 脚本用法

```
python scripts/check.py --file 醒酒方案.json
python scripts/check.py --selftest
```

`--file` 含 wine_age_years、tannin_level、decant_method、decant_minutes、has_sediment 等字段。

## 6. 人工确认清单

- [ ] 年轻单宁重酒是否用醒酒器
- [ ] 醒酒时长是否在类型区间内
- [ ] 老酒是否直立静置后再慢倒
- [ ] 末段沉淀是否弃去
- [ ] 有无氧化过头（果香散、醋味）信号

## 7. 最常见的坑

1. 老酒（>15 年）猛醒酒器大接触面，香气散尽变寡。
2. 本不需醒的清淡酒（如部分黑皮诺）醒后更淡。
3. 醒酒超时，年轻酒氧化过头出醋味。
4. 有沉淀不处理，倒杯里满口渣。
5. 不直立直接开瓶倒，沉淀全混。
6. 瓶醒与醒酒器搞反，需要促氧化却只瓶醒。
7. 冰镇过的酒直接醒，温度不对香气封闭。

## 8. 边界与免责

本技能为饮用参考，不保证口感与品质。酒款风格差异大，以实际闻香尝味为准。饮酒须适量，未成年人禁酒。
