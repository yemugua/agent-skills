# 蓝牙耳机排查规则库

> 生成排查方案、判断修还是换之前，先读这份文件，不要凭印象写。

---

## 一、原因概率排序表

| 顺序 | 原因 | 典型表现 | 处理动作 |
|---|---|---|---|
| 1 | 耳机电量不足 | 一只响、续航短、突然断 | 两只都充满，充电仓也充满 |
| 2 | 多设备连接抢占 | 手机连上又切到电脑 | 断开其他设备的连接 |
| 3 | 2.4G 与蓝牙抢占 | 插上接收器后蓝牙就连不上 | 一个接收器只保持一种连接 |
| 4 | 配对记录错乱 | 搜不到设备、配对反复失败 | 删除旧记录重新配对 |
| 5 | 驱动与协议不匹配 | 换台电脑就好、换口就好 | 换接口或换设备验证 |
| 6 | 蓝牙版本兼容性 | 老设备只能低版本功能 | 确认双方支持的版本 |
| 7 | USB 3.0 干扰 | 靠近移动硬盘就断 | 换接口或加延长避开干扰源 |
| 8 | 省电相关设置 | 闲置后连不上 | 关闭相关省电选项 |
| 9 | 音频编码设置 | 延迟大、音质差 | 调整编码设置 |

**为什么不先重装系统**：代价大、见效慢，且前几条原因的概率之和远高于它。**按顺序走，不要跳步。**

---

## 二、2.4G 与蓝牙的抢占关系

| 事实 | 说明 |
|---|---|
| 同一频段 | 2.4G 接收器与蓝牙都工作在 2.4GHz 频段 |
| 互斥 | 同一个接收器同一时间只能保持一种连接 |
| 典型表现 | 插上接收器后蓝牙频繁断连 |
| 正确做法 | 先断开蓝牙，再插上接收器 |

**关键口径**：这是「插上就断」最常见也最容易被忽略的原因。

---

## 三、配对重置顺序（先轻后重）

| 步骤 | 动作 |
|---|---|
| 1 | 关掉设备端蓝牙，重新打开 |
| 2 | 删除该耳机的配对记录 |
| 3 | 耳机放回充电仓，长按多功能键进入配对模式 |
| 4 | 设备端重新搜索并配对 |
| 5 | 只连一台设备，观察是否稳定 |

**重置的通用原则**：先轻后重——关蓝牙 → 删记录 → 重启设备 → 耳机恢复出厂设置。跳步会让问题定位不了。
**恢复出厂设置的入口因型号而异**，通常在充电仓里长按多功能键，以说明书为准。

---

## 四、2.4G 与蓝牙对比

| 维度 | 2.4G 接收器 | 蓝牙 |
|---|---|---|
| 连接方式 | 专用接收器，占一个 USB 接口 | 手机或电脑自带 |
| 延迟 | 通常更低，适合游戏 | 通常略高，视编码与版本而定 |
| 稳定性 | 稳定，干扰源少 | 受同频段设备影响 |
| 距离 | 受接收器位置限制 | 相对更远 |
| 抢占 | 与蓝牙互斥 | 与 2.4G 互斥 |
| 适用场景 | 固定电脑前、游戏 | 通勤、手机 |

**选择口径**：打游戏或固定电脑前使用优先 2.4G；通勤与手机使用蓝牙更方便。两者是场景分工，不是替代。

---

## 五、音频编码与延迟

| 目标 | 方向 |
|---|---|
| 稳定与低延迟 | 选编码支持低延迟模式的方案 |
| 音质优先 | 选高码率编码，代价是延迟与耗电增加 |
| 兼容性优先 | 保持默认设置 |

**口径**：延迟与编码、设备性能、传输距离都有关，**不是只由编码决定**。仍延迟明显时，优先换 2.4G 方案而不是反复调设置。

---

## 六、能修还是该换的判断线

| 情况 | 结论 |
|---|---|
| 只在一台设备上复现 | 该设备的问题，先换设备验证 |
| 换设备正常、原设备有问题 | 原设备的驱动、接口或系统问题 |
| 所有设备复现、耳机用过不久 | 耳机本体可能有问题，走售后 |
| 所有设备复现、已用较久且多处老化 | 该换耳机了 |
| 进液、接口松动、电池异常发热 | 立即停用，直接更换 |
| 延迟始终无法接受 | 换 2.4G 方案或换耳机 |

**判断原则**：先用一台正常的设备交叉验证，把责任分清。没分清就买新耳机容易白花钱。

---

## 七、干扰源清单

| 干扰源 | 影响 |
|---|---|
| USB 3.0 移动硬盘 | 同频段干扰，靠近就断 |
| USB 3.0 集线器 | 同上 |
| 无线路由器 2.4G | 同频段 |
| 其他蓝牙设备密集 | 同频段拥挤 |
| 无线鼠标键盘接收器 | 同频段 |

**处理**：换接口、加延长线、拉开距离，逐个排除。

---

## 八、常见误判对照

| 说法 | 是否成立 |
|---|---|
| 蓝牙耳机都要换新的了 | 不成立，先按顺序排查 |
| 重装系统就能修好 | 不成立，代价大且不是首选 |
| 插上接收器还能同时用蓝牙 | 不成立，同一接收器只能保持一种连接 |
| 调延迟设置能解决延迟 | 部分成立，编码只是因素之一 |
| 断连就是耳机坏了 | 不成立，多设备抢占也会导致 |
| 老设备一定连不上新耳机 | 不成立，需确认版本兼容性而非下结论 |
