# 人像摆姿（portrait-posing-guide）

摆姿的核心只有两句：**把身体转开一点，把手臂撑开一点。**

人一站直、两脚并拢、双手贴裤缝，画面里出现的就是一个正面朝向镜头的矩形——**最容易显宽、显僵、显胖的姿势**。

这个技能做三件事：**给动作 → 核十二项 → 分级整改**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出日常人像的摆姿动作与自查口径 | ❌ 评判被拍者的身材、长相或外形 |
| 说明镜头焦距、裁切、留白的取舍 | ❌ 提供后期修图、瘦身、磨皮的具体操作 |
| 按脸型体型给出先改哪一项 | ❌ 替代专业时装摄影与商业人像的造型设计 |
| 提供与被拍者沟通的口令 | ❌ 替代摄影师在现场的引导与判断 |

**遇到以下情况，按各自渠道处理：**

- 被拍者**明确表示不愿做某个动作或不想被拍** → 立即停止，不要勉强
- 被拍者是**未成年人** → 须取得监护人同意，不得拍摄或传播不适宜内容
- 照片要用于**商业宣传、出版、赛事投稿** → 涉及肖像权与著作权授权，走各自渠道
- 相机/手机的具体功能开关与菜单路径 → 以自己设备的官方说明为准

## 二、完整工作流

### 第一步：先定焦段与机位

人像用**等效 50 到 135mm**。手机主摄通常是等效 24 到 26mm，**贴脸拍半身会把鼻子放大**。

- 优先用 **2 倍镜**（多数手机接近等效 50mm）
- 没有 2 倍镜就**退远一点再放大**，不要走近
- 拍全身想显高 → **把机位降到腰部或膝盖高度**

### 第二步：给整体动作（脚和身体）

直接喊具体动作，不要说「自然一点」：

- 站姿：**「重心放后面那条腿，前面那只脚尖点地」**
- 坐姿：**「往前坐一点，腿往左边偏」**
- 倚靠：**「靠着别压着，一条腿弯起来」**

### 第三步：安排手

手必须有事做。五种安排任选：**叉腰 / 插兜露拇指 / 拿东西 / 抬手碰脸 / 扶墙**。

### 第四步：调头和下巴

**「下巴往前伸一点点，头略低」** —— 不是「收下巴」。收下巴会挤出双下巴、脖子消失。

### 第五步：按快门前喊「呼气」

憋气会让肩膀上提、脖子变短。呼气能一次卸掉肩膀的紧张。

### 第六步：回放再拍

每拍一组回放一次，**放大看眼睛有没有闭**、头发有没有乱、衣领有没有歪。

## 三、核心规则（生成结论前先读规则文件）

**必须先读 `rules/摆姿要点与自查表.md`，不要凭印象写。** 规则文件里有：

- 十二项自查的分级与不合格原因（严重项 4 条、可改进项 8 条）
- 三组万能摆姿的脚、手、肩、头处理办法与可直喊的口令
- 八种脸型体型的「先改哪一项」调整表
- 判定顺序说明
- 八条高频坑与拍照时的沟通顺序

**判定顺序不能颠倒**：先看严重项（焦段太广、裁在关节、手无处安放、下巴不前伸），再看可改进项，最后才看信息是否完整。

**为什么这条重要**：若先判信息完整度，会出现「已经用 24mm 把脸拍变形，却因为没填留白比例而被判成待确认」——把问题说轻了，比漏判更糟。

## 四、十二项自查速查

| 项目 | 合格口径 | 严重度 |
|---|---|---|
| 镜头等效焦距 | 不低于 35mm（低于即严重），推荐 50 到 135mm | 严重 / 可改进 |
| 裁切位置 | 裁大腿中段、上臂中段、腰部或全身；**不裁手腕手肘膝盖脚踝** | 严重 |
| 手的位置 | 叉腰、插兜露拇指、拿东西、抬手碰脸、扶墙 | 严重 |
| 下巴 | 微前伸并略低 5 到 10 度 | 严重 |
| 重心腿 | 站姿重心压一条腿，另一腿微屈或脚尖点地 | 可改进 |
| 手臂三角 | 手臂与躯干留出三角空隙 | 可改进 |
| 转体角度 | 20 到 45 度 | 可改进 |
| 肩线角度 | 与画面水平线成 5 到 30 度 | 可改进 |
| 眼神方向 | 看镜头或看向明确方向，不涣散 | 可改进 |
| 头顶留白 | 占画面高度 0.05 到 0.20 | 可改进 |
| 呼吸 | 按快门前呼气，不憋气 | 可改进 |

## 五、脚本用法

```bash
python scripts/pose_check.py --file poses.json --out 摆姿自查.md
python scripts/pose_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`shots` 为照片列表，每张填 `lens_mm` / `crop_at` / `hand_pose` 等 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检（61 条断言，含 BOM 两条路径） |

输入 JSON 示例：

```json
{
  "shots": [
    {
      "name": "站姿半身",
      "lens_mm": 50,
      "weight_leg": true,
      "arm_triangle": true,
      "body_turn_deg": 30,
      "shoulder_angle_deg": 15,
      "chin_forward": true,
      "eye_direction": "lens",
      "headroom": 0.12,
      "hand_pose": "waist",
      "crop_at": "waist",
      "exhaled": true
    }
  ]
}
```

可选枚举：`hand_pose` 取 `waist` / `pocket` / `hold` / `face` / `lean`；
`eye_direction` 取 `lens` / `off_axis` / `closed` / `down` / `wandering`；
`crop_at` 取 `thigh` / `upper_arm` / `waist` / `full` / `wrist` / `elbow` / `knee` / `ankle`。
其余为布尔或数值：`weight_leg`、`arm_triangle`、`chin_forward`、`exhaled`、`thumb_out`、`headroom`。

脚本输出：总体判定、逐张判定表（含不合格原因的 why）、整改顺序、手的五种安排、裁切位置表、阈值表、人工确认清单。

## 六、人工确认清单（这步不能省）

- [ ] 用的是 2 倍镜或退远拍摄，没用主摄贴脸拍
- [ ] 裁切位置不在手腕、手肘、膝盖、脚踝上
- [ ] 手有明确安排：叉腰、插兜露拇指、拿东西、抬手碰脸、扶墙
- [ ] 下巴微前伸并略低，没有双下巴
- [ ] 重心压在一条腿上，手臂与躯干有三角空隙
- [ ] 每拍一组回放一次，放大看眼睛有没有闭
- [ ] 涉及他人肖像的照片，发布前已取得本人同意

## 七、最常见的坑

**坑一：用手机主摄贴脸拍半身。**
错误做法：举着手机凑到对方面前拍，觉得这样人脸大。正确做法：主摄等效约 24 到 26mm，是广角，**离镜头近的鼻子额头会被放大**，脸变形、头显大。换 2 倍镜或退远一点。

**坑二：裁在膝盖或手腕上。**
错误做法：半身照裁到膝盖上方一点，全身照裁到脚踝上方。正确做法：**关节不能裁**，裁在手腕、手肘、膝盖、脚踝看起来像被截肢。改裁大腿中段、上臂中段或腰部，要么就全身入画。

**坑三：说「手自然放」。**
错误做法：「手自然放就好」，对方两只手贴着裤缝。正确做法：「自然」是最没用的指令，**直接给具体动作**：叉腰、插兜露拇指、拿杯子、撩头发、扶墙。

**坑四：让对方「收下巴」。**
错误做法：「下巴收一点」，结果挤出双下巴、脖子没了。正确做法：说**「下巴往前伸一点点，头略低」**。前伸能拉开颈部线条，回收只会挤出肉。

**坑五：让对方站军姿。**
错误做法：两脚并拢站直，身体僵、胯正、腿不显长。正确做法：**「重心放后面那条腿，前面那只脚尖点地」**，靠近镜头的那条腿承重更显腿长。

**坑六：拍全身站着不动。**
错误做法：站着用平视机位拍全身，人显得又矮又平。正确做法：**蹲下拍，机位降到腰部或膝盖高度**，重心腿靠近镜头、前脚尖点地。

**坑七：一直喊「笑一个」。**
错误做法：喊到第二十张，笑容已经僵在脸上。正确做法：**边聊边拍**，在对话间隙按快门。表情要从聊天里来，不从指令里来。

**坑八：拍完不看回放。**
错误做法：拍完就走，回家才发现闭眼、头发乱、衣领歪、手挡脸。正确做法：**每拍一组回放一次，放大看眼睛**。重拍三张的成本远低于回家后悔。
