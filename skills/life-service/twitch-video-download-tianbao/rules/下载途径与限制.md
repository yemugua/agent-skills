# Twitch 直播与切片留存边界：途径、限制与合规边界

## 一、先判定：能不能下

| 归属类别 | 能否下载 | 允许的用途 |
| --- | --- | --- |
| 自有作品 | 可以，优先用原始导出文件 | 任意 |
| 已授权素材 | 可以 | 仅限授权范围内 |
| 作者开放了保存 | 可以，走官方途径 | 个人留存，**不得二次分发** |
| 第三方作品（未授权） | **不建议下载** | 不应用于任何对外场景 |

技术上能不能下载，和法律上能不能用，是两回事。

## 二、途径，按稳定性排序

| 途径 | 操作要点 |
| --- | --- |
| 原文件 | 优先。主播开播时的本地录制文件最完整清晰，若有本地录制，后面几条都不必尝试。 |
| 主播后台留存 | 登录自己的主播账号在创作后台查看 VOD 与数据，可下载或延长保留，这是主播最稳的做法。 |
| 官方 VOD 入口 | 观众端在频道页查看公开 VOD，取决于主播是否开启与是否仍在保留期内。 |
| 通用命令行工具 | 需 Python + ffmpeg：pip install -U yt-dlp。仅对公开且未关闭保存的免费 VOD 可能有效，需保证网络对该站可达。 |

## 三、本平台的真实限制

- Twitch 属境外平台，境内访问可能存在网络可达性前置条件，本技能不提供任何翻墙或代理手段。
- VOD 有保留期，过期会被清理，任何工具都拿不回来，只能靠提前本地录制。
- 订阅专属 VOD 受访问限制，不支持下载或导出。
- 观众端 VOD 画质受转码影响，低于主播本地录制原画质。

## 四、画质与水印

- VOD 是平台转码版本，画质低于主播本地录制；主播应优先保留开播时的本地录制文件。
- VOD 含主播署名与平台标识，转载需取得主播同意，不得去除署名后发布。

## 五、合规红线

1. 不得去除作者署名后二次分发
2. 不得将他人作品搬运至自己的账号（含剪辑、配音后发布）
3. 不得下载或传播私密账号、付费内容
4. 受版权或 DRM 保护的内容不支持下载，也不提供任何破解方法
5. 商用前必须取得书面授权
6. 批量高频抓取可能违反平台服务协议，导致账号受限
