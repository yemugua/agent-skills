# 产品审核（product-audit）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据 IATF 16949 与 VDA 6.5 产品审核要求，生成产品审核清单：审核对象与抽样、检验特性（外观/尺寸/功能/包装）、缺陷分级（A/B/C）、审核报告与评分、纠正与再验证。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 产品审核
- VDA6.5
- 产品审核检查
- 缺陷分级
- 审核评分

## 三、工作流
1. 确定审核对象与抽样方案
2. 覆盖检验特性（外观/尺寸/功能/包装）
3. 按A/B/C分级判定缺陷
4. 形成审核报告与评分
5. 纠正不符合并再验证

## 四、核心内容（检查清单与判定）
产品审核从顾客视角评价已交付产品的质量水平，缺陷按严重程度分级（A致命/B严重/C一般），结果用于评分与持续改进。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含审核对象与抽样方案 | 抽样 |
| Q2 | FAIL | 未含检验特性覆盖 | 特性 |
| Q3 | WARN | 未含缺陷分级（A/B/C） | 分级 |
| Q4 | FAIL | 未含审核报告与评分 | 报告 |
| Q5 | WARN | 未含纠正与再验证 | 纠正 |

> 脚本 `product-audit_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python product-audit_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python product-audit_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
