# 冲洗液配制与浓度口径

## 一、水质安全（最重要）

| 水源 | 可否使用 |
|---|---|
| 无菌水、灭菌注射用水 | 可以 |
| 煮沸后冷却到适宜温度的水（煮沸时间按当地水质与海拔酌情延长） | 可以 |
| 经 0.2 微米级别过滤器过滤的水 | 可以 |
| 正规成品冲洗液或配套盐包配的液体 | 可以，优先推荐 |
| **未经处理的自来水** | **不可以**，存在微生物风险 |
| 井水、河水、湖水、未经消毒的储水 | 不可以 |

自来水中可能存在的微生物经鼻腔冲洗进入体内，虽然罕见但可引起严重感染。**不要图省事直接用自来水。**

## 二、浓度口径

| 类型 | 浓度 | 参考配比 | 适用 |
|---|---|---|---|
| 等渗盐水 | 0.9% | 每 1000 毫升水加约 9 克无碘盐 | 日常首选，长期维持 |
| 低渗 | 低于 0.9% | 一般不自行配制 | 少用 |
| 高渗 | 1.5%-3% | 需更高盐量，配比应由医生或产品说明给出 | 需医生指导，短期使用 |

**换算公式**：浓度（百分比）= 盐的克数 ÷ 水的毫升数 × 100。

例：9 克盐 + 1000 毫升水 = 0.9%；4.5 克盐 + 500 毫升水 = 0.9%。

## 三、盐的选择

| 项目 | 口径 |
|---|---|
| 盐种 | 使用无添加剂的纯盐（无碘、无抗结剂为佳），或产品配套盐包 |
| 不要用 | 加碘盐、低钠盐（含钾）、含抗结剂或其他添加剂的调味盐 |
| 优先 | 成品冲洗盐包或成品冲洗液，配比与纯度更有保障 |
| 容器 | 配制容器清洁，现配现用，不长时间存放 |

## 四、温度

| 项目 | 口径 |
|---|---|
| 目标 | 接近体温，约 35-37℃ |
| 加热 | 隔水加热或用安全的水调温，不要用微波炉直接加热不均 |
| 试温 | 滴手腕内侧，温热不烫 |
| 存放 | 现配现用，剩余液体不要留到第二天 |

## 五、鼻部用药注意（不涉及具体药物）

| 类别 | 注意 |
|---|---|
| 减充血剂类鼻喷剂 | 连续使用通常不宜超过 5-7 天；长期连用可致药物性鼻炎，越用越堵 |
| 鼻用激素类 | 需医生开具并说明用法与疗程，按医嘱使用与复查 |
| 抗组胺类 | 由医生判断是否适合 |
| 先后顺序 | 药物与冲洗的先后顺序按医生说明执行 |
| 通用原则 | 不自行加量、不自行延长疗程、不与他人共用鼻喷剂 |

**减充血剂依赖的自我识别**：不用喷剂就堵得完全不通、越用次数越多、用药间隔越来越短，出现这些情况应就诊。

## 六、常见误区

| 误区 | 事实 |
|---|---|
| 「自来水烧开过就够，直接用也行」 | 必须是煮沸后**冷却到适宜温度**的水，未经处理的自来水不能直接用 |
| 「浓度高一点效果好」 | 高渗需医生指导，长期自行高浓度会刺激黏膜 |
| 「洗得越勤越好」 | 过度冲洗破坏黏膜环境，按频次口径执行 |
| 「洗鼻可以代替喷剂」 | 冲洗是辅助手段，中重度症状仍需按医嘱用药 |
| 「瓶子不用每次洗」 | 器具污染等于往鼻腔灌污染液体 |
| 「堵得厉害就用力挤」 | 压力过大可致耳痛与耳闷 |
| 「减充血剂通气快，多用几天没事」 | 超过连用上限易形成药物性鼻炎 |
| 「孩子哭闹也要洗完」 | 无法配合的婴幼儿不应强行冲洗 |
