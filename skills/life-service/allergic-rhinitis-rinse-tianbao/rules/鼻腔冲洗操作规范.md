# 鼻腔冲洗操作规范

> 前提：就医红线已排除，水源符合安全口径，浓度已确认。
> 鼻部手术后的冲洗起始时间与方式以手术医生要求为准。

## 一、操作前准备

| 步骤 | 做法 |
|---|---|
| 洗手 | 用肥皂或洗手液彻底清洗双手 |
| 备液 | 按浓度口径配好，水温调到接近体温 |
| 试温 | 滴在手腕内侧，感觉温热不烫 |
| 体位 | 站在洗手台前，身体略前倾 |
| 器具 | 确认专用、已清洗晾干、未与他人共用 |

## 二、操作姿势与步骤

| 步骤 | 做法 |
|---|---|
| 1 | 头前倾约 45 度，下巴微收，头略转向待冲洗一侧的对侧 |
| 2 | 冲洗器出液口轻轻贴住上方一侧鼻孔，形成软密封，不要用力顶入 |
| 3 | **张口自然呼吸，可持续发「啊」的音**，让软腭关闭，避免液体进入咽部 |
| 4 | 让液体靠重力或轻微挤压流入，从下方鼻孔或口腔流出 |
| 5 | 全程不要吞咽、不要憋气、不要用大力挤压 |
| 6 | 一侧完成后换另一侧，方法相同 |
| 7 | 结束后轻轻擤鼻（单侧交替，不要两侧同时用力捏紧） |
| 8 | 清洗器具，甩干水分，开口朝下晾干 |

**关键要点**：头位前倾、张口呼吸、不吞咽、不用大力。出现耳痛、耳闷、剧烈咳嗽应立即停止。

## 三、水温与水量

| 项目 | 口径 |
|---|---|
| 水温 | 接近体温，约 35-37℃（以手腕试温不烫为准） |
| 成人每侧水量 | 常见口径约 120-250 毫升 |
| 儿童每侧水量 | 明显减量，按医生建议执行 |
| 水温过低 | 刺激鼻腔引起不适 |
| 水温过高 | 有黏膜烫伤风险 |

## 四、频次

| 情况 | 口径 |
|---|---|
| 日常维持 | 每日 1 次 |
| 症状明显期 | 每日 1-2 次 |
| 症状较重 | 可在医生指导下增加次数 |
| 长期高渗 | 需医生指导，不自行长期高浓度冲洗 |
| 不宜频繁 | 过度冲洗可能破坏黏膜正常环境，不是越多越好 |

## 五、器具清洁与更换

| 项目 | 口径 |
|---|---|
| 每次使用后 | 用安全的水冲洗器具内外，甩干，开口朝下自然晾干 |
| 定期消毒 | 按产品说明定期消毒或高温处理 |
| 更换周期 | 按产品说明定期更换，出现异味、变色、变形立即更换 |
| 共用 | 绝不与他人共用 |
| 存放 | 干燥通风处，不要密闭潮湿存放 |
| 电动脉冲式 | 按说明书清洁管路与水箱 |

## 六、停止冲洗的信号

| 信号 | 处置 |
|---|---|
| 冲洗时或冲洗后耳痛、耳闷、听力下降 | 立即停止，就诊 |
| 鼻出血 | 立即停止，按压处理；量大或反复需就诊 |
| 剧烈咳嗽、呛咳、胸闷 | 停止，调整姿势后仍出现则暂停 |
| 冲洗后鼻塞加重、头痛明显 | 停止并咨询医生 |
| 眩晕 | 立即停止，坐下休息 |

## 七、不宜自行冲洗的情况

| 情况 | 说明 |
|---|---|
| 鼻出血期间 | 暂停 |
| 急性中耳炎或耳痛 | 暂停并就诊 |
| 鼻部术后 | 以手术医生要求的时间与方式为准 |
| 无法配合的婴幼儿 | 需医生评估，不宜强行操作 |
| 吞咽协调差、易呛咳者 | 需医生评估 |
| 鼻腔完全堵塞无法流出 | 先就诊处理，不要强行加压 |
