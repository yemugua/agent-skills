# 过敏性鼻炎洗鼻与鼻腔冲洗操作

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 给出水质、水温、浓度与操作姿势的口径 | 诊断鼻炎类型、判断是否合并鼻窦炎或鼻息肉 |
| 说明冲洗频次、水量与器具清洁规范 | **提供鼻用激素、抗组胺药或减充血剂的名称与剂量** |
| 提示药物使用中的常见风险（如减充血剂连用上限） | 推荐具体药品与器械品牌 |
| 整理症状记录与诱发因素 | 承诺洗鼻能替代药物治疗或根治过敏 |
| 输出操作核对表与就医提示 | 建议自行长期高浓度冲洗 |

**就医红线（出现任一条，尽快就医；标注急诊的直接去急诊）**

- 单侧持续鼻塞、反复单侧流脓血涕或异味 —— 需排查鼻腔异物、肿瘤等，尽快就诊
- 鼻出血量大、按压 10 分钟不止、或反复频繁出血 —— 尽快就诊，量大者急诊
- 冲洗后出现剧烈耳痛、耳闷听力下降、眩晕 —— 停止冲洗并就诊
- 视力改变、复视、眼球突出、眼眶周围红肿 —— 急诊
- 剧烈头痛、额面部明显胀痛伴发热 —— 尽快就诊
- 喘息、呼吸困难、口唇发紫、全身皮疹伴鼻部症状 —— 急诊
- 鼻部外伤后鼻出血、鼻梁畸形 —— 急诊
- 鼻部手术后未满医嘱要求的冲洗起始时间 —— 先问手术医生
- 儿童长期张口呼吸、睡眠打鼾憋气、影响生长发育 —— 就诊评估腺样体与扁桃体
- 需要使用减充血剂超过 5-7 天才能通气 —— 就诊，不要继续自行延长

| 用户说法 | 用不用 |
|---|---|
| 「洗鼻的正确姿势是什么」 | 用 |
| 「生理盐水自己怎么配」 | 用，附水质安全前提 |
| 「洗鼻能用自来水吗」 | 用，明确不建议 |
| 「一天洗几次合适」 | 用 |
| 「洗完耳朵疼怎么办」 | 只作停止冲洗与就诊提示 |
| 「鼻喷剂能长期用吗」 | 用，说明不同类型差异，具体由医生定 |
| 「减充血剂用多久停」 | 用，说明常见连用上限口径 |

## 三、完整工作流

1. **先排红线**：逐条核对就医红线，命中即转就医，不输出冲洗方案。
2. **查水质**：确认使用的水达到安全口径，**不使用未经处理的自来水**。
3. **定浓度**：按 `rules/冲洗液配制与浓度口径.md` 确认等渗或高渗，高渗需医生指导。
4. **调水温与水量**：接近体温，按年龄确定每侧水量。
5. **摆姿势**：头前倾约 45 度、张口呼吸、不要吞咽，按步骤冲洗。
6. **清洁器具**：冲洗后清洗、晾干、定期更换，不与他人共用。
7. **记效果**：记录鼻塞评分、冲洗次数与不适，复诊时带给医生。

## 四、核心规则与要件库

生成冲洗建议前，**必须先读**：

- `rules/鼻腔冲洗操作规范.md`：姿势、水温水量、频次、器具清洁、停止信号。
- `rules/冲洗液配制与浓度口径.md`：水质安全、浓度换算、禁忌与常见误区。

不得给出鼻用药物（激素、抗组胺、减充血剂）的名称与剂量。不得建议用自来水、井水或未煮沸的水直接冲洗。

## 五、脚本用法

```
python scripts/saline_rinse_calc.py --file case.json
python scripts/saline_rinse_calc.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`salt_grams` 盐量、`water_ml` 水量、`water_source` 水源、`temp_c` 水温、`times_per_day` 频次 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--json` | 以 JSON 输出 |
| `--selftest` | 运行自检 |

脚本输出浓度百分比与等渗/高渗判定、水质与水温合规检查、频次提示。**水源不合规时脚本会阻断并只输出安全提示。脚本不输出任何药物剂量。**

## 六、人工确认清单

- [ ] 就医红线已排除，尤其单侧脓血涕与反复鼻出血
- [ ] 水源达到安全口径（非未经处理的自来水）
- [ ] 浓度已确认，高渗方案经医生同意
- [ ] 水温接近体温，未用冷水或热水
- [ ] 器具专用、每次清洗晾干、定期更换
- [ ] 操作者已掌握张口呼吸、不吞咽的姿势
- [ ] 鼻部用药严格遵医嘱，减充血剂未超过连用上限
- [ ] 出现耳痛、出血、剧烈头痛已停止冲洗并就诊

## 七、最常见的坑

1. **用自来水直接洗鼻**：未经处理的水可能含微生物，罕见但后果严重，必须使用符合安全口径的水。
2. **减充血剂长期连用**：这类鼻喷剂连续使用通常不宜超过 5-7 天，长期用会导致药物性鼻炎、越用越堵。
3. **水温过冷或过热**：冷水刺激引起不适，过热有烫伤风险，以接近体温为准。
4. **冲洗时用力过猛或捏紧双鼻孔**：压力过大可致耳痛、耳闷甚至中耳问题。
5. **浓度越浓越好**：高渗需医生指导，长期自行高浓度会刺激黏膜。
6. **洗鼻代替药物**：冲洗是辅助，症状明显时仍需按医嘱用药。
7. **器具长期不换不洗**：瓶内滋生细菌，等于往鼻腔里灌污染液体。
8. **出血时继续冲洗**：鼻出血、中耳炎急性期、鼻部术后未到时间都应暂停。

## 八、边界与免责

本技能提供鼻腔冲洗的操作口径与安全核对，不构成诊断或治疗方案。**不提供任何鼻用药物的名称与剂量**。浓度、水量与频次因年龄、鼻腔状态、术后情况与指南版本而异，**以最新版临床指南和耳鼻喉科医师的判断为准**。出现就医红线中的任一情况，请尽快就诊。
