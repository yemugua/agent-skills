# TikTok 与 Reels 视频保存：常见失败与排查

报错信息请**粘贴原文**再对照。写成「下载失败了」没有排查价值，
写成 `HTTP Error 403` 或 `ffmpeg not found` 才能定位。

## 现象 → 原因 → 处理

| 现象关键词 | 原因与处理 |
| --- | --- |
| 网络不通 / 无法访问 / 超时 / 连不上 | 先确认网络可达性，这是国内用户最常见的失败原因，与工具无关。 |
| 无水印 / nwatermark / 去水印 | 无水印需求通常指向搬运，且第三方去水印站点多为不可信服务，谨慎提交账号信息。 |
| 故事过期 / 24小时 / 不存在了 | Stories 有时效性，过期不可恢复，需要留存请在有效期内处理。 |
| 私密账号 / private / 仅粉丝 | 私密账号内容不属于可下载范围，应联系作者。 |
| 登录 / loginrequired / cookies | 需携带登录态：`yt-dlp --cookies-from-browser chrome <链接>`，仅限自己的账号。 |

## 通用故障（各平台都可能遇到）

| 现象 | 处理 |
| --- | --- |
| 403 / 需要登录 / 机器人验证 | 触发反自动化校验：携带登录态或减少请求频率，不要高频重试 |
| 429 / 频繁 / 限流 | 降低请求频率、分批间隔重试 |
| 404 / 失效 / 不存在 | 链接失效或已删除：让对方重新生成分享 |
| 没有声音 / 无音轨 | ffmpeg 未安装或未合并轨：安装后用 `-f "bv*+ba/b"` 合并 |
| 解析失败 / 格式不支持 | 站点接口变动：把工具升级到最新版，而不是换工具 |
| 超时 / 连接失败 | 检查网络可达性后重试 |

## 排查顺序

1. 先确认网络能访问目标平台
2. 再确认目标内容是否属于可下载范围（回到归属判定）
3. 然后确认工具是最新版
4. 最后才怀疑链接本身

九成的「下载失败」卡在第 1 步和第 2 步，而不是工具坏了。
