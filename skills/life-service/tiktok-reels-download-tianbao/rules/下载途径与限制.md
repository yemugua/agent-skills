# TikTok 与 Reels 视频保存：途径、限制与合规边界

## 一、先判定：能不能下

| 归属类别 | 能否下载 | 允许的用途 |
| --- | --- | --- |
| 自有作品 | 可以，优先用原始导出文件 | 任意 |
| 已授权素材 | 可以 | 仅限授权范围内 |
| 作者开放了保存 | 可以，走官方途径 | 个人留存，**不得二次分发** |
| 第三方作品（未授权） | **不建议下载** | 不应用于任何对外场景 |

技术上能不能下载，和法律上能不能用，是两回事。

## 二、途径，按稳定性排序

| 途径 | 操作要点 |
| --- | --- |
| 原文件 | 优先。自有作品用发布前的原始导出文件，画质无损且无平台水印；若仍在，后面几条都不必尝试。 |
| 官方保存 | TikTok：分享 → Save video，取决于作者是否开启下载开关。Instagram 对他人内容**没有**保存到相册的官方入口，只能收藏。 |
| 创作者后台 | TikTok 创作者工具与 Instagram 专业面板可查看自有内容的数据与素材，仅限自己的账号。 |
| 通用命令行工具 | 需 Python + ffmpeg：`pip install -U yt-dlp`。常用形态：`yt-dlp -f "bv*+ba/b" <链接>`。对两个平台支持度较好，站点改版后先升级。 |

## 三、本平台的真实限制

- **可访问性是前置条件**：在中国大陆内地通常无法直接访问 TikTok 与 Instagram，需先具备合规的网络条件，否则一切保存步骤无从谈起。
- Instagram 对他人内容没有官方「保存到相册」入口，只能收藏；TikTok 则取决于作者是否开启下载开关，两者策略不同。
- Stories 是 24 小时时效性内容，过期不可访问，需要留存应在有效期内处理。
- 两个平台的水印策略不同：TikTok 保存会带平台水印与作者名，Instagram 转载需保留署名。

## 四、画质与水印

- 画质取决于源上传码率。两个平台均为竖屏短视频，平台转码后码率有限，下载无法提升清晰度。
- 水印含作者账号，属署名性质。去除后二次发布风险高于保留。

## 五、合规红线

1. 不得去除作者署名后二次分发
2. 不得将他人作品搬运至自己的账号（含剪辑、配音后发布）
3. 不得下载或传播私密账号、付费内容
4. 受版权或 DRM 保护的内容不支持下载，也不提供任何破解方法
5. 商用前必须取得书面授权
6. 批量高频抓取可能违反平台服务协议，导致账号受限
