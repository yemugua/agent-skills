# 自驾游路线与里程规划规则库

> 生成行程方案、测算费用之前，先读这份文件，不要凭印象写。
> 路况、限行与通行条件以实时交通信息和当地主管部门公布为准。

---

## 一、里程口径

| 口径 | 说明 |
|---|---|
| 导航里程 | 按最优路线计算，不含绕行 |
| 实际里程 | 实际行驶距离，含绕行与找路 |
| 高速里程 | 走高速的部分 |
| 普通道路里程 | 走国道与省道的部分 |

**核心口径**：**实际里程通常大于导航里程。** 找路、绕行、等红灯都会增加，规划油费时留出余量更稳妥。

---

## 二、油耗影响因素

| 因素 | 影响 |
|---|---|
| 车速与路况 | 高速匀速巡航通常更省，市区走走停停更费 |
| 载重 | 载人多、行李多，油耗上升 |
| 空调与暖风 | 都增加油耗，冬天暖风影响更明显 |
| 海拔 | 高原空气稀薄，油耗通常上升 |
| 逆风与气温 | 都会影响 |

**核心口径**：**高速未必比国道更费油。** 匀速巡航时油耗往往接近甚至更优，真正费油的是市区走走停停与低速蠕行。但高速的过路费显著高于国道，**总费用要一起算**。

---

## 三、费用测算结构

| 项目 | 测算思路 |
|---|---|
| 油费 | 总里程 ÷ 实际百公里油耗 × 当地油价 |
| 过路费 | 按路段与车型，**以现行规定和实际公布为准** |
| 停车费 | 按目的地实际收费标准 |
| 餐饮与住宿 | 按行程安排估算 |
| 额外支出 | 租车费、门票、临时开销 |

**结构性差异**：高速需要过路费，普通道路通常没有。**这往往是高速与国道总费用差距的主要来源，比油耗差异更大。**

---

## 四、路线规划误区对照

| 误区 | 说明 |
|---|---|
| 只看公里数 | 同样里程，耗时、过路费、油耗都可能差很多 |
| 用理论时速算时间 | 要加红绿灯、服务区、堵车、找路的余量 |
| 假设不堵车 | 出行日、周末、节假日差别很大 |
| 只规划去程 | 返程高峰可能完全不同，要分别看 |
| 导航里程当实际里程 | 实际通常更长 |
| 不考虑海拔与气温 | 高原与冬季都影响油耗与驾驶状态 |
| 一天排太满 | 疲劳驾驶风险大于多住一晚的麻烦 |
| 不查限行与施工 | 可能到了才发现进不去或要绕行 |

**核心口径**：**时间比距离重要。**

## 五、出发前检查清单

**车辆方面**：

| 项目 | 判据 |
|---|---|
| 机油、冷却液、玻璃水 | 液位正常 |
| 胎压与胎纹 | 四条胎都看过 |
| 刹车 | 状态正常 |
| 灯光 | 含刹车灯与转向灯 |
| 雨刷 | 工作正常 |
| 备胎 | 可用，气压正常 |
| 随车工具与三角警示牌 | 齐全 |
| 燃油或电量 | 足够到达目的地 |

**证件与物资**：

| 项目 | 判据 |
|---|---|
| 驾驶证、行驶证、身份证件 | 齐全有效 |
| 常用药品、饮用水、食品 | 按人数与时长准备 |
| 手机、充电线、车充 | 齐全 |
| 导航或离线地图 | **信号不好的路段需要离线地图** |
| 应急联系方式 | 已保存 |

**行程文件**：

| 项目 | 判据 |
|---|---|
| 路线与备用路线 | 已规划 |
| 住宿预订信息 | 已确认 |
| 充电或加油点 | 新能源车需确认 |

## 六、休息安排

| 项目 | 说明 |
|---|---|
| 连续驾驶时长 | 每连续驾驶一段时间就安排休息 |
| 单次休息时长 | 真正离开驾驶位，活动一下 |
| 疲劳信号 | 打哈欠、注意力涣散、反应变慢、频繁眨眼 |
| 出现疲劳信号 | 立即停车休息 |
| 提神手段 | 咖啡与功能饮料只能短期提神，不能替代休息 |

**连续驾驶的具体时长限制以现行规定和当地主管部门要求为准**，本表只给安排原则。

---

## 七、路况与限行查询方法

| 要查什么 | 去哪里查 |
|---|---|
| 实时路况与拥堵 | 主流导航软件的实时路况功能 |
| 限行规定 | 当地主管部门官方发布渠道 |
| 施工与临时管制 | 当地交通管理部门发布 |
| 天气与预警 | 气象部门发布 |
| 道路通行条件 | 当地主管部门公布 |

**查询要点**：

- 限行要查到**适用车型与适用区域**，不是所有车都受限
- 施工信息有时效性，出发前查一次，路上再查一次
- 天气预警要提前看，恶劣天气要调整行程
- 导航推荐路线不等于最快或最安全，有多种选择时按实际情况判断

## 八、恶劣天气与夜间约束

| 场景 | 约束 |
|---|---|
| 大雨、暴雨 | 降低车速、加大车距、避免涉水路段 |
| 大雾 | 开启雾灯、降低车速、保持车距 |
| 冰雪路面 | 降低车速、避免急刹急打方向、延长车距 |
| 大风 | 注意侧风、握稳方向、避开临时设施 |
| 高温 | 关注水温、避免长时间怠速、备足饮水 |
| 夜间 | 注意疲劳、灯光使用、动物与行人 |
| 山路与高原 | 控制车速、下坡用低挡、避免连续制动 |

**遇到能见度极差或路面严重积水结冰，就近停车等待，不要勉强赶路。**

---

## 九、备胎与应急工具

| 必备 | 说明 |
|---|---|
| 备胎 | 检查气压是否正常 |
| 三角警示牌 | 停车后必须放置 |
| 随车工具 | 换胎需要 |
| 千斤顶 | 换胎使用 |
| 反光背心 | 夜间或能见度差时使用 |
| 应急联系方式 | 道路救援等 |

**应急处理基本原则**：

1. 保证人身安全，停车到安全位置
2. 开启危险报警闪光灯
3. 放置三角警示牌
4. 人员撤到安全区域，不要在车旁停留
5. 联系救援或按提示操作
