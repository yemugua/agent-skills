# 自驾游路线与里程规划（road-trip-planning）

自驾规划最容易犯的错，是**只盯着公里数**。400 公里高速和 400 公里国道，油钱、过路费、耗时可能差出一倍。

这个技能做四件事：**算里程** → **算费用** → **排节奏** → **列检查**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 说明里程、油耗、费用的测算口径 | ❌ 保证实际油耗与估算一致 |
| 说明高速与国道的差异 | ❌ 给出实时路况与限行信息 |
| 给出休息间隔与疲劳驾驶约束 | ❌ 判断某条路的实时通行状况 |
| 说明查询路况与限行的方法 | ❌ 承诺行程一定畅通 |
| 给出出发前检查与应急工具清单 | ❌ 代替驾驶员资质与车辆状况的实际检查 |

**路况、限行、施工与临时管制信息以实时交通信息和当地主管部门公布为准**，本技能只讲查询方法，不提供也不推测实时路况。涉及道路通行条件与车型限制的要求，以现行规定和当地主管部门公布为准。

**遇到以下情况，改用其他交通方式或调整行程：**

- 驾驶员连续驾驶时长已超出规定或自身疲劳
- 车辆存在影响安全的状况问题
- 恶劣天气导致道路通行条件明显恶化
- 山区路段、长隧道、高原路段超出驾驶经验

## 二、里程与油耗估算口径

**里程口径**：

| 口径 | 说明 |
|---|---|
| 导航里程 | 通常按最优路线计算，不含绕行 |
| 实际里程 | 实际行驶距离，含绕行与找路 |
| 高速里程 | 走高速的部分 |
| 国道与省道里程 | 走普通道路的部分 |

**实际里程通常大于导航里程**，因为找路、绕行、等红灯都会增加。规划油费时留出余量更稳妥。

**油耗口径（这是高速与国道差异的核心）**：

| 因素 | 影响 |
|---|---|
| 车速与路况 | 高速匀速巡航通常更省油，市区走走停停更费油 |
| 载重 | 载人多、行李多，油耗上升 |
| 空调与暖风 | 都会增加油耗，冬天暖风影响更明显 |
| 海拔 | 高原地区空气稀薄，油耗通常上升 |
| 逆风与气温 | 都会影响 |

**核心口径**：**高速未必比国道更费油**，匀速巡航时油耗往往接近甚至更优；**真正费油的是市区走走停停和低速蠕行**。但高速的过路费会显著高于国道，**总费用要一起算**。

**测算公式（思路）**：

```
总油费 = 总里程 ÷ 百公里油耗 × 油价
总费用 = 油费 + 过路费 + 停车费
```

**具体油耗数值以车辆实际表现为准**，不同车型、路况、载重差异很大，本技能不给出具体百公里油耗数字。

## 三、费用测算结构

| 项目 | 测算思路 |
|---|---|
| 油费 | 总里程 ÷ 实际百公里油耗 × 当地油价 |
| 过路费 | 按路段与车型计算，**以现行规定和实际收费站公布为准** |
| 停车费 | 按目的地停车场的实际收费标准 |
| 餐饮与住宿 | 按行程安排估算 |
| 可能的额外支出 | 租车费、景区门票、临时开销 |

**过路费的结构性差异**：**高速需要过路费，普通道路通常没有**。这是高速与国道总费用差距的主要来源，往往比油耗差异更大。

**过路费的具体标准以现行规定和实际收费站公布为准**，本技能不给出费率数字。

**建议**：出行前用导航工具的过路费估算功能先看个大概，再留出余量。**估算不等于实际收费。**

## 四、路线规划的常见误区

| 误区 | 说明 |
|---|---|
| **只看公里数** | 400 公里高速与 400 公里国道，耗时、过路费、油耗都可能差很多 |
| **只按理论时速算时间** | 实际时间要加上红绿灯、服务区、堵车、找路的余量 |
| **假设不堵车** | 出行日、周末、节假日的高峰时段差别很大 |
| **只规划去程不规划返程** | 返程高峰可能完全不同，要分别看 |
| **把导航里程当实际里程** | 实际通常更长，油费要留余量 |
| **不考虑海拔与气温** | 高原和冬季都会影响油耗与驾驶状态 |
| **一天排太满** | 疲劳驾驶的风险远大于多住一晚的麻烦 |
| **不查限行与施工** | 可能到了才发现进不去或要绕行 |

**核心口径**：**时间比距离重要。** 估算耗时时要把堵车、服务区、用餐、找停车位都算进去，而不是用距离除以理论时速。

## 五、出发前检查清单

**车辆方面**：

- 机油、冷却液、玻璃水液位正常
- 胎压正常，**四条胎的胎纹都看过**
- 刹车状态正常
- 灯光正常（含刹车灯、转向灯）
- 雨刷工作正常
- 备胎可用，气压正常
- 随车工具与三角警示牌齐全
- 燃油或电量足够到达目的地

**证件与物资**：

- 驾驶证、行驶证、身份证件
- 按人数准备的相应有效证件
- 常用药品、饮用水、少量食品
- 手机、充电线、车充
- 导航设备或离线地图（**信号不好的路段需要离线地图**）
- 应急联系方式

**行程文件**：

- 路线规划与备用路线
- 住宿预订信息
- 目的地充电或加油点（新能源车）

**每项都过一遍再出发，比路上出状况再想办法省事得多。**

## 六、疲劳驾驶与休息安排

**核心口径**：**疲劳驾驶的风险远大于多住一晚的麻烦。**

**休息安排**：

| 项目 | 建议 |
|---|---|
| 连续驾驶时长 | 每连续驾驶一段时间就安排休息，不要长时间不间断 |
| 单次休息时长 | 休息要真正离开驾驶位，活动一下 |
| 疲劳信号 | 打哈欠、注意力涣散、反应变慢、频繁眨眼 |
| 出现疲劳信号时 | 立即停车休息，不要靠喝咖啡硬撑 |
| 疲劳时的处置 | 停车休息比继续开安全得多 |

**连续驾驶的具体时长限制以现行规定和当地主管部门要求为准**，本技能只给出安排原则，不写死数字。

**关于咖啡、功能饮料**：可以短期提神，**但不能替代休息**，也不适合作为长期手段。

## 七、路况与限行查询方法

**查询方法（不代替实时信息）**：

| 要查什么 | 去哪里查 |
|---|---|
| 实时路况与拥堵 | 主流导航软件的实时路况功能 |
| 限行规定 | 当地主管部门的官方发布渠道 |
| 施工与临时管制 | 当地交通管理部门发布 |
| 天气与预警 | 气象部门发布 |
| 道路通行条件 | 当地主管部门公布 |

**查询要点**：

- **限行规定要查到「适用车型」和「适用区域」**，不是所有车都受限
- **施工信息有时效性**，出发前查一次，路上再查一次
- **天气预警要提前看**，恶劣天气要调整行程而不是硬上
- **导航的推荐路线不等于最快或最安全**，有多种选择时要按实际情况判断

**核心口径**：**路况与限行信息以实时交通信息和当地主管部门公布为准**，本技能不提供也不推测这些信息。

## 八、恶劣天气与夜间行车约束

| 场景 | 约束 |
|---|---|
| 大雨、暴雨 | 降低车速、加大车距、避免涉水路段 |
| 大雾 | 开启雾灯、降低车速、保持车距 |
| 冰雪路面 | 降低车速、避免急刹急打方向、延长车距 |
| 大风 | 注意侧风影响、握稳方向、避开临时设施 |
| 高温 | 关注车辆水温、避免长时间怠速、备足饮水 |
| 夜间 | 注意疲劳、灯光使用、动物与行人 |
| 山路与高原 | 控制车速、下坡用低挡、避免连续制动 |

**遇到能见度极差或路面严重积水结冰的情况，最安全的做法是就近停车等待，不要勉强赶路。**

**夜间与恶劣天气下的行车要求以现行规定和当地主管部门要求为准。**

## 九、备胎与应急工具

**必备**：

| 项目 | 说明 |
|---|---|
| 备胎 | 检查气压是否正常 |
| 三角警示牌 | 停车后必须放置 |
| 随车工具 | 换胎需要的工具 |
| 千斤顶 | 换胎使用 |
| 反光背心 | 夜间或能见度差时使用 |
| 应急联系方式 | 保險救援、道路救援 |

**应急处理的基本原则**：

1. 先保证人身安全，停车到安全位置
2. 开启危险报警闪光灯
3. **放置三角警示牌**
4. **人员撤到安全区域，不要在车旁停留**
5. 联系救援或按提示操作

**涉及道路救援与保险理赔的具体流程，以承保方与相关机构的规定为准。**

## 十、脚本用法

```bash
python scripts/road_trip_calc.py --km 520 --consumption 8.5 --price 7.8 --toll 240 --park 60
python scripts/road_trip_calc.py --file trip.json --out 测算结果.md
python scripts/road_trip_calc.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--km` | 总里程（公里） |
| `--consumption` | 百公里油耗（升） |
| `--price` | 油价（元/升） |
| `--toll` | 过路费（元） |
| `--park` | 停车费（元） |
| `--speed` | 规划的平均车速（公里/小时），含堵车与休息余量 |
| `--file` | 从 JSON 读（自动兼容带 BOM 的文件） |
| `--out` | 结果落盘路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本输出**油费、总费用、按规划车速估算的耗时**，以及高速与国道的结构差异说明和休息安排建议。

> 脚本只做算术估算，**油耗与耗时的实际值与车型、路况、载重、天气相关**，不代表实际测量。

## 十二、最常见的坑

**坑一：只看公里数不看时间。**
400 公里高速和 400 公里国道，耗时、过路费、油耗都可能差很多。

**坑二：用理论时速算耗时。**
实际要加上红绿灯、服务区、堵车、找路的余量。

**坑三：假设不堵车。**
出行日、周末、节假日的高峰时段差别很大，去程和返程要分别看。

**坑四：把导航里程当实际里程。**
实际通常更长，找路、绕行、等红灯都会增加。

**坑五：漏算过路费。**
高速的过路费往往是高速与国道总费用差距的主要来源，比油耗差异更大。

**坑六：不查限行就出发。**
可能到了才发现进不去或要绕行。查的时候要确认适用车型与区域。

**坑七：一天排太满。**
疲劳驾驶的风险远大于多住一晚的麻烦。

**坑八：疲劳了靠咖啡硬撑。**
只能短期提神，不能替代休息。

**坑九：没检查备胎和三角警示牌。**
备胎气压掉了、警示牌丢了，到用的时候才发现是最麻烦的。

**坑十：没下离线地图。**
信号不好的路段导航失效，没有离线地图就抓瞎。
