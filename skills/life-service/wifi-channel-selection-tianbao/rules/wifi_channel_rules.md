# WiFi 信道选择与干扰排查规则

## 一、判定总原则

1. **定性先于调参。** 未做有线测速就换信道，是最大的浪费。
2. **覆盖与干扰分开处理。** 覆盖靠 Mesh 或有线 AP，干扰靠信道与频段。
3. **2.4G 窄、5G 宽。** 2.4G 固定 20MHz，5G 用 80MHz。
4. **非 WiFi 干扰扫不出来。** 扫描软件看不到微波炉与无绳电话。
5. **改前改后都要测。** 各测三次取中位数，有数据才有结论。

---

## 二、四步定性法

| 检查 | 操作 | 判定 |
|---|---|---|
| 有线测速 | 网线直连光猫或路由器 LAN 口测速 | 有线也慢 → 宽带或线路问题，报装维 |
| 近场测速 | 站路由器 1 米内测速 | 近场快远处慢 → 覆盖问题 |
| 分时段测速 | 白天与晚高峰各测三次 | 晚高峰明显慢 → 拥塞或干扰 |
| 分频段测速 | 2.4G 与 5G 各测三次 | 5G 明显快 → 2.4G 拥塞 |

**判定口径**：信号满格但速率低 = 干扰或拥塞；信号格数少 = 覆盖不足。

---

## 三、信道规划表

| 频段 | 互不重叠信道 | 建议 |
|---|---|---|
| 2.4GHz | 1、6、11 | 三选一，选周边占用最少并固定 |
| 5GHz 低频 | 36、40、44、48 | 干扰较少，兼容性好 |
| 5GHz 高频 | 149、153、157、161、165 | 可用，设备支持差异较大 |
| 5GHz DFS 段 | 52-64、100-144 | 遇雷达会强制跳频，兼容性差时避开 |

- 2.4G 只有 1、6、11 三个互不重叠信道，邻居再多也只能三选一
- 5G 信道多、干扰少，优先使用
- 6GHz 频段以当地无线电管理规定与设备核准情况为准

---

## 四、信道宽度取舍

| 频段 | 建议宽度 | 原因 |
|---|---|---|
| 2.4GHz | 20MHz | 40MHz 几乎必然与邻居重叠，反而更慢 |
| 5GHz | 80MHz | 速率与抗干扰的平衡 |
| 5GHz 拥挤环境 | 40MHz | 牺牲峰值速率换稳定性 |

**自动信道的局限**：切换不及时是常态，可能半夜才调整或一直停在出厂信道。手动固定前先扫周边占用。

---

## 五、慢网故障树（按处理顺序）

| 顺序 | 原因 | 判定 | 验证动作 | 处置 |
|---|---|---|---|---|
| 1 | 宽带或线路问题 | 有线直连也慢 | 网线直连测速 | 报装维 |
| 2 | 覆盖不足 | 信号格数少、远处慢 | 近场与远场对比测速 | Mesh 或有线 AP |
| 3 | 2.4G 拥塞 | 5G 明显更快 | 分频段测速 | 迁到 5G |
| 4 | 信道重叠干扰 | 晚高峰明显变慢 | 扫描周边信道占用 | 换到最空闲信道并固定 |
| 5 | 信道宽度不当 | 2.4G 设了 40MHz | 查看无线设置 | 改回 20MHz |
| 6 | 非 WiFi 干扰源 | 特定时段或特定电器工作时断流 | 关掉可疑电器对比 | 远离干扰源或换频段 |
| 7 | 双频合一冲突 | 物联网设备掉线 | 分开 SSID 后观察 | 拆分 SSID |
| 8 | 终端能力老旧 | 只有个别设备慢 | 换设备对比 | 升级网卡或换设备 |
| 9 | 路由器摆放不当 | 位置差、有遮挡 | 挪位置对比测速 | 居中、离地、避金属 |
| 10 | 多AP或企业环境 | AP 数量多、需要漫游 | 统计 AP 与终端数量 | 请专业网规 |

---

## 六、非 WiFi 干扰源清单

| 干扰源 | 表现 | 处置 |
|---|---|---|
| 微波炉 | 工作时 2.4G 断流 | 远离厨房或改用 5G |
| 无绳电话、婴儿监视器 | 2.4G 间歇掉线 | 换新设备或改频段 |
| 无线摄像头 | 持续占用信道 | 独立划分或走有线 |
| 蓝牙设备密集 | 2.4G 抖动 | 减少同环境蓝牙数量 |
| Zigbee 物联网 | 与 2.4G 部分信道重叠 | 错开信道 |
| 金属柜、镜面、鱼缸 | 信号反射衰减 | 路由器避开这些物体 |

---

## 七、摆放与双频策略

- 位置：居中、离地 1-1.5 米、开阔无遮挡
- 远离：承重墙、金属柜、鱼缸、微波炉、镜面
- 双频合一：易导致物联网设备找不到网或频繁掉线，建议分开 SSID
- 物联网设备：多数只支持 2.4G，绑定 2.4G 的 SSID
- 大户型：靠 Mesh 或有线 AP
- Mesh 回程：优先有线回程，无线回程留专用频段

---

## 八、安全红线（必须停用并报装维或专业人员）

| 情形 | 处置 |
|---|---|
| 有线直连也慢 | 是宽带或线路问题，报运营商装维 |
| 光猫亮红灯、频繁掉注册、光衰异常 | 报装维，不要自行改参数 |
| 企业、商铺、多 AP 需统一规划与漫游 | 请专业网规 |
| 需新增网线、面板、POE 供电、室内分布 | 请专业人员 |
| 需改动光猫桥接、VLAN、认证参数 | 由装维操作 |
| 涉及强电改造、天花板内布线、登高安装 AP | 请专业人员 |

**禁止事项：**

- 禁止修改光猫注册与认证参数（改错直接断网，需装维重新下发数据）
- 禁止刷入第三方固件（变砖、失保、合规风险）
- 禁止超出设备销售地区核准的发射功率范围
- 禁止在弱电箱等封闭金属空间长期放置路由器

---

## 九、常见误判清单（反向判断）

| 现象 | 常见误判 | 正确判断 |
|---|---|---|
| 网速慢 | 信道不好 | 先做有线测速，可能是宽带本身慢 |
| 信号满格 | 网络没问题 | 满格只代表强度，不代表信道干净 |
| 2.4G 设 40MHz | 更快 | 必然与邻居重叠，实测通常更慢 |
| 换信道没效果 | 不是干扰 | 非 WiFi 干扰源扫不出来 |
| 晚高峰变慢 | 路由器不行 | 是拥塞证据，与邻居使用时段相关 |
| 双频合一 | 更方便 | 物联网与老设备会掉线，建议分开 |
| 大户型信号差 | 换信道解决 | 覆盖问题靠 Mesh 或有线 AP |
| 一个设备慢 | 网络整体慢 | 多为终端网卡老旧或后台占带宽 |
| 自动信道 | 一定最优 | 算法切换不及时是常态，手动固定常更稳 |

---

## 十、验收标准

| 项目 | 合格标准 |
|---|---|
| 有线基准 | 有线测速达到套餐标称的合理区间 |
| 近场无线 | 1 米处速率接近有线基准 |
| 远场无线 | 常用位置速率满足日常使用需求 |
| 晚高峰 | 与白天速率差距不显著 |
| 稳定性 | 连续 30 分钟无掉线与断流 |
| 物联网 | 智能设备持续在线，不频繁掉线 |

测试要求：改前改后各测三次，取中位数对比。
