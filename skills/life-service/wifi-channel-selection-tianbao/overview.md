# WiFi信道选择与干扰排查

家里 WiFi 一慢，第一反应往往是"换信道"。但慢的成因分两类：信号弱是覆盖问题，信号满格却慢是干扰或拥塞。这两类的解法完全不同，混在一起调信道是最常见的白忙。

这个技能把"WiFi 慢"变成"先定性、再扫描、后选信道、最后验效果"。

## 你会得到什么

- **四步定性法**——有线直连测速、近场测速、分时段测速、分频段测速，先确定是不是 WiFi 的问题
- **2.4G 与 5G 信道规划表**——互不重叠信道、DFS 段的取舍、为什么 2.4G 只能三选一
- **信道宽度取舍**——2.4G 固定 20MHz、5G 用 80MHz、拥挤时降 40MHz 的理由
- **非 WiFi 干扰源清单**——微波炉、无绳电话、无线摄像头、蓝牙、Zigbee，这些扫描软件看不见
- **安全红线**——不改光猫注册认证参数、不刷第三方固件、不超合规功率

## 典型用法

晚上七八点特别卡，是拥塞还是干扰；
智能摄像头总掉线，是不是双频合一的问题；
新路由器该设哪个信道，要不要开自动；
大户型一台不够，换信道能不能解决。

## 内置规则不是提示词

`rules/wifi_channel_rules.md` 给出定性方法、信道规划表、宽度取舍规则、干扰源清单、摆放要点与九条常见误判。
改设置之前先读这份文件，不凭印象下结论。

## 边界

只做排查与设置指导，**不改光猫注册与认证参数，不刷第三方固件，不替代运营商装维与企业级网规**。
有线直连也慢、光猫亮红灯、多 AP 环境，一律报装维或请专业人员。
