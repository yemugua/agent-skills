网购退货七天无理由核查——把"这个东西到底能不能退、运费谁出、还剩几天"一次算清楚。

现有工具多是电商平台的退款入口和物流查询，缺的是**退货前的法律判断**：七天无理由到底从哪天起算、哪些商品法定不能退、"拆封了不能退"是不是真的、"不支持七天无理由"是不是就排不掉。本技能补这一块：

- 四类法定除外（定作 / 鲜活易腐 / 拆封的数字化商品 / 报纸期刊）+ 第五类"购买时确认不宜退货"的成立要件
- **"拆封了不能退"是错的**：为检查、试用而拆封且商品完好的仍可退；区分"查验用拆封"与"超出查验使用"
- 运费归属：无理由退货消费者承担、质量问题经营者承担、运费险兜底，并给出算式
- 耐用商品与装饰装修服务六个月内瑕疵**举证责任倒置**由经营者承担
- 经营者收到退回商品后七日内返还价款的时间节点

输出九段报告，含七天窗口倒计时、证据缺口与平台介入路径。不替代律师意见，司法口径有分歧处如实标注，以主管部门 / 平台 / 司法机关认定为准。
