# 商品完好、拆封、激活与举证责任倒置

## 一、"商品完好"到底指什么

商品完好的标准：能够保持原有品质、功能，**商品本身、配件、商标标识齐全**；
并且**没有因使用导致价值贬损**。

判定分三档，从轻到重：

| 档 | 情形 | 是否完好 |
|---|---|---|
| A | 拆了外包装/塑封，但只是打开看、试按开机、试机运行，商品无划痕无污损 | **完好，可退** |
| B | 拆封后使用了超出查验范围的功能（如拆封后自用几天、穿出门、剪掉吊牌后使用） | 有风险，可能被视为不完好 |
| C | 已使用导致价值贬损较大（如服装上身、化妆品开封使用、鞋底穿着出门） | **不完好，一般不成立无理由退货** |

→ 关键是**"为查验和确认商品品质、功能需要"**这个限定语：它划出了 A 与 B 的分界线。

## 二、"拆封了不能退"是错的

消费者为**检查、试用**商品而拆封，且商品本身不污损的，属于商品完好，
商家不得以"已拆封"为由拒绝无理由退货。这条对**绝大多数实体商品**都成立。

例外只有一类：**在线下载或者消费者拆封的数字化商品**（音像制品、计算机软件等），
这类拆封本身即构成法定除外。

→ 所以商家说"你拆了封就不能退"，正确的回话是：
**"我是为检查商品品质拆的封，商品本体、配件、标识齐全，没有影响二次销售。"**

## 三、激活 / 联网绑定，不是法定除外

- 手机、电脑的**整机预装系统激活**，不等于"在线下载的数字化商品"——
  它仍然是实体商品，商家以"已激活"排除七天无理由缺少法律依据。
- 智能设备联网绑定账号、写入个人信息，同样不是法定除外；
  退回来时做**恢复出厂设置并解绑**即可消除这个理由。
- 真正的数字化商品是指：购买的就是**下载链接 / 卡密 / 激活码 / 已拆封的软件光盘与音像制品**。

→ 脚本在"是否已联网激活"填"是"且商家已拒退时，会明确点出这一层。

## 四、赠品与配件必须一并退回

- 随主商品赠送的赠品、随附的配件、说明书、包装、**商标标识**，退主商品时应**一并退回**；
- 赠品已消耗无法退回的，经营者可按赠品价值扣减，但**扣减应有依据**；
- 经营者若以"赠品未退回"为由拒绝全额退款，应先举证赠品价值。

→ 退之前把赠品和配件清点一遍，拍照留底；这是平台介入时最常被卡的一个点。

## 五、耐用商品的举证责任倒置

消费品（如计算机、电视机、电冰箱、空调器、洗衣机等）或**装饰装修服务**，
在**六个月内**发现瑕疵、发生争议的，由**经营者承担有关瑕疵的举证责任**；
六个月后才发现的，举证责任回到消费者。

- 起算点：自**接受商品之日**（一般即签收日）起算六个月。
- 意义重大：沙发、床垫、家电、装修服务这类**用久了才出问题**的，
  过期后才发现问题往往说不清是不是使用造成的，倒置规则把举证压力转给商家。
- 装饰装修服务同样适用，且通常是"服务完成之后六个月内"。

## 六、平台介入时的证据形态

| 争议点 | 需要的证据 | 备注 |
|---|---|---|
| 商品有问题 | 开箱视频（一条录完）、商品与外包装照片 | 视频必须连续，能看清面单、外包装、拆封、全景 |
| 短少 / 错发 / 少件 | 物流称重记录（重量差）+ 商品照片 | 重量差是硬证据 |
| 描述不符 / 货不对板 | 商品页面快照 + 实物照片对比 + 订单详情 | 页面截图要有 URL 与时间 |
| 商家拒退 | 聊天记录（文字，不要只留语音） | 让对方把"不能退"的说法留在文字里 |
| 已按期退货 | 寄回的物流单号与签收记录 | 证明你没拖 |

→ 开箱视频决定成败，且**必须在商家发货后、自己拆封前就录**，签收后再补录没用。
