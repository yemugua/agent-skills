# 运费、退款时限与投诉路径

## 一、退货运费谁承担

| 情形 | 运费承担方 | 依据 |
|---|---|---|
| 无理由退货（七天无理由、无质量问题） | **消费者** | 无理由退货的退回运费由消费者承担，另有约定的按约定 |
| 商品质量有问题 / 经营者违约（错发、少发、描述不符、货不对板、破损） | **经营者** | 经营者违约的，运费由其承担 |
| 商家另行承诺包退运费（页面承诺、聊天承诺） | **经营者** | 约定优先 |
| 有运费险的 | 先看保险赔付 | 运费险按保单额度赔付，不足部分再按上述规则由一方承担 |

**算式（脚本按这个算）**：

```
待承担运费 = 退回运费 − min(运费险赔付额度, 退回运费)
```

- 算出来为正且责任方是消费者的，你自付这个数；
- 责任方是经营者的，这数额由商家出，你先垫后凭票据报销；
- 运费险额度建议截图留存，赔付到账后仍有差额的要单独主张。

→ 实操提醒：**寄回不要选到付**（除非责任方明确是商家且你在系统里填了运费承担方），
到付件容易被退回；先垫付，凭快递单据 + 订单截图向商家或平台要。

## 二、退款什么时候到

| 节点 | 期限 |
|---|---|
| 消费者提交退货申请 | 七天窗口内提交，**以系统提交时间为准**，不是以你写好申请为准 |
| 商家收到退回商品 | 你寄出后盯物流签收；建议寄出当天在系统里回填单号 |
| **经营者返还价款** | 自**收到退回商品之日起七日内**返还 |
| 平台介入判定后退款 | 按平台赔付规则，通常快于法定七日，但不同平台不同 |
| 拒不退款的民事起诉时效 | 一般为 3 年 |

→ 商家说"收到货验货无误后退款"是正常的，但**"收到之日起七日"是上限不是可以无限拖**；
超过七日不退款的，直接走平台介入 / 12315。

## 三、阶梯路径（按顺序走，别跳步）

1. **订单页发起"退货退款"申请**，理由写清楚（无理由 / 质量问题），
   上传开箱视频、商品照片、称重记录（如有）、聊天截图；
2. 商家拒绝的，**立即申请平台介入**（订单详情页有入口），上传完整证据包并写清诉求金额；
3. 寄回时**在系统给出的地址寄回并回填物流单号**，保留快递单据；
4. 平台判退货但你仍不满意的，向 **12315（市场监管）** 投诉平台或商家；
5. 金额较大、平台判定明显的，可就争议提起民事诉讼（小额走小额诉讼程序）。

→ **跳步的代价**：跳过第 1 步直接寄回的，一旦商家说没收到，你无任何记录可查。
   先申请，再寄货，顺序不能反。

## 四、特殊交易分支

| 类型 | 额外要注意什么 |
|---|---|
| **二手闲置** | 平台多为"描述相符"争议，七天无理由的适用存在争议；重点是**描述不符**的证据与商品页面快照 |
| **海外购 / 跨境** | 适用跨境电商零售进口税收与平台规则，退货可能涉及已缴税款不退、退运成本；一般不适用境内七日内无理由，看平台规则 |
| **生鲜** | 命中法定"鲜活易腐"，无理由退货不成立；但在途损坏、变质、错发的可按质量 / 违约主张 |
| **直播带货** | 直播间口头承诺（"七天无理由""假一赔十"）要留录屏；主播承诺可能构成经营者的额外承诺 |
| **预售 / 定金** | 定金有定金罚则，订金、押金一般可退；**定金 ≠ 订金 ≠ 押金**，名字不同法律后果不同 |
| **定制 / 半定制** | 命中法定除外，但材质、尺寸与约定不符的仍可按质量 / 违约主张 |

→ 脚本按商品类别与渠道给出分支提示，具体以平台规则与当地监管口径为准。

## 五、地域与平台差异

- 七天无理由是**法定权利**，不因平台规则而被排除；平台规则只能**更宽松**。
- 平台以"不支持七天无理由"为由拒绝的，可要求其说明依据并保留记录，再走 12315。
- 各平台对"商品完好""影响二次销售"的自由裁量不同，平台判定不公的，12315 与诉讼是后手。
