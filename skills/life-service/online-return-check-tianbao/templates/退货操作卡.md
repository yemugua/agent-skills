# 退货操作卡（照着做，别跳步）

> 退货失败的九成原因不是法律，是**顺序错了**和**没留证**。
> 这张卡把顺序定死：先申请 → 再寄货 → 最后盯退款。

## 一、开箱取证（签收当天就能做，5 分钟）

收到货第一件事，**不要急着拆封先用**，先录像：

```
镜头从快递面单开始（看清收件人、单号）
→ 拍外包装六面（含快递柜/驿站取件凭证）
→ 拍封箱胶带原样
→ 当面/当镜头拆封
→ 拍商品本体（含所有瑕疵点、铭牌、序列号）
→ 拍配件、说明书、赠品
→ 最后一条：把商品和面单放一起拍一张全景
```

- **一条录完不要剪断、不要停**，断断续续的视频平台不认；
- 录像当天同步传到网盘/微信文件传输助手，**别只留本地**；
- 有重量差争议的（少件、短少），**当面称重并录像**，或要求驿站称重留证。

→ 这一步决定后面所有环节的成败，且**签收后再补录没用**。

## 二、申请话术（订单页文字里写，别只打电话）

无理由退货：

```
本人于 X 月 X 日签收该商品（订单号 ______），现依据消费者权益保护法
"消费者有权自收到商品之日起七日内退货"的规定，申请无理由退货。
商品已拆封用于检查/试用，本体、配件、商标标识齐全，保持原有品质与功能，
不影响二次销售。请在 ____ 前提供退货地址并承担/明确运费承担方式。
```

质量 / 描述不符：

```
本人签收该商品后发现 ________（具体瑕疵/不符点）。
已留存开箱视频与商品照片。该商品不属于法定四类除外商品，
页面亦未在购买时经本人单独确认不宜退货，故七天无理由/质量退货成立。
请于 3 日内：① 同意退货并出具退货地址；② 承担退回运费 ¥____。
逾期未答复的，本人将申请平台介入并向 12315 反映。
```

被"不支持七天无理由"挡回时的补一句：

> "该商品不属于法定四类除外情形；页面标注不能替代购买时的单独确认，
> 请贵方说明依据并出具购买时确认的痕迹，否则该排除对我不生效。"

## 三、寄回的三个坑

| 坑 | 正确做法 |
|---|---|
| 先寄回再申请 | **必须先申请、拿到退货地址再寄**，否则商家说没收到你全亏 |
| 寄到付 | 先垫付，费用按第六段算式向对方要；到付件容易被拒收 |
| 不回填单号 | 寄出当天在系统回填物流单号，这是"已按期退货"的唯一证明 |

- 寄出时再拍一组**商品 + 包装 + 快递单**的照片，记下重量；
- 用**可查轨迹的快递**（别用快递柜自提退回、别用同城跑腿）；
- 自己先垫付运费的，把快递单据 + 支付记录存好，平台介入时一并上传。

## 四、平台介入怎么打

1. 订单详情 → 找"申请售后 / 退款/退货" → 商家拒绝后点**"申请平台介入"**；
2. 上传证据包（一次传全，别分次）：开箱视频、商品照片、称重记录、
   商品页面快照、与商家的全部聊天记录、订单与支付截图；
3. 诉求写**具体金额**和**具体理由**，不要只写"要求退货"：
   例："要求退货退款 ¥2499，退回运费 ¥12 由商家承担（属描述不符）"；
4. 平台要求补充的，按要求补，**补的每一样都要重新传一遍链接**；
5. 判定不利的，**截图保存判定结果**，这是 12315 投诉的起点材料。

## 五、平台之后的三条后手

1. **12315 投诉**：在 12315 平台（网站/小程序）提交，选"网络购物"，
   被投诉方写**经营者主体**（营业执照名称），不是平台公司；
   投诉内容写清：订单号、日期、争议点、诉求金额、已走的平台介入过程与结果。
2. **向平台所在地市场监管部门反映**（平台规则以自己的限制为准，法定义务不能排除）。
3. **民事诉讼**：标的额小的走**小额诉讼**程序，流程快、成本低；
   注意诉讼时效一般为 3 年，别拖。

## 六、时间红线

| 红线 | 天数 |
|---|---|
| 收到商品之日起无理由退货窗口 | 7 日（**以系统提交申请的时间为准**） |
| 经营者收到退回商品之日起返还价款 | 7 日 |
| 12315 投诉受理 / 办结 | 7 日内决定是否受理，60 日内办结，可延长 30 日 |
| 民事诉讼时效 | 3 年 |
| 耐用商品举证责任倒置期 | 自接受商品之日起 6 个月 |
| 开箱视频 / 监控留存 | 越快越好，别等商家删了页面再截图 |

→ 只剩 1~2 天窗口时：**当天就提交申请**，不要等"想好了再写"。
   系统时间戳才是证据，不是你的草稿。

## 七、纪律

- 全程用平台内文字沟通，微信扯皮的话补一句"以上聊天内容确认如下"并截图；
- 不要签"放弃所有权利"的和解再拿钱；
- 大额商品（数码、家电、珠宝）建议先查一遍序列号与有无拆封保修贴，
  **有激活/保修痕迹的，退之前先解绑与恢复出厂设置**；
- **未填的一律不算通过**，采集表空着跑不出确定结论。
