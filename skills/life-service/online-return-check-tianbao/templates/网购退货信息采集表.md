# 网购退货信息采集表

> 复制本表填到自己的文件里，填完保存为 Markdown，然后跑：
> `python scripts/return_check.py 我的采集表.md --base 2026-10-05 --out 核查报告.md`
>
> 有 / 无 / 是 / 否 直接填字，别留空白；不会填的写「待填」。
> **未填项的判定一律是"待补正"，不算通过。**

## 一、商品与订单

| 字段 | 值 |
|---|---|
| 商品名称 | 例：某牌无线降噪耳机 |
| 商品类别 / 性质 | 例：普通实体商品 / 定制家具 / 生鲜 / 报刊 / 软件（照抄页面分类） |
| 购买渠道 | 例：某电商自营旗舰店 / 直播间 / 二手平台 / 海外购 |
| 订单实付金额 | 例：2499 |
| 商品页面是否标注不支持七天无理由 | 是 / 否 / 待填 |
| 购买时是否单独确认过不宜退货 | 是 / 否 / 待填 |

## 二、时间

| 字段 | 值 |
|---|---|
| 下单日期 | 例：2026-09-30 |
| 签收日期 * | 例：2026-10-04（快递柜/代收点取件日为准） |

## 三、法定除外逐条核对

| 字段 | 值 |
|---|---|
| 是否为定制 / 定作商品 | 是 / 否 |
| 是否为鲜活易腐商品 | 是 / 否 |
| 是否为在线下载或拆封的数字化商品 | 是 / 否 |
| 是否为报纸期刊 | 是 / 否 |

## 四、拆封与商品完好

| 字段 | 值 |
|---|---|
| 是否已拆封 | 是 / 否 |
| 拆封目的 | 例：检查外观 / 试机 / 试用 |
| 是否超出查验需要使用 | 是 / 否 |
| 商品是否完好 | 是 / 否 |
| 赠品与配件是否可一并退回 | 是 / 否 |
| 是否已联网激活或写入个人信息 | 是 / 否 |

## 五、质量与三包

| 字段 | 值 |
|---|---|
| 退货理由 | 例：收到就开不了机 / 与描述不符（说是 256G 实为 128G）/ 单纯不想要了 |
| 是否为耐用商品 | 是 / 否 |
| 发现瑕疵距签收天数 | 例：12 |
| 是否在三包有效期内 | 是 / 否 |
| 是否经两次修理仍不能正常使用 | 是 / 否 |

## 六、运费

| 字段 | 值 |
|---|---|
| 退货寄回运费金额 | 例：12 |
| 是否有运费险及赔付额度 | 例：运费险赔 10 |
| 商家是否另行承诺承担运费 | 是 / 否 |

## 七、进度与商家态度

| 字段 | 值 |
|---|---|
| 是否已发起退款申请 | 是 / 否 |
| 商家是否拒绝 | 是 / 否 |
| 商家拒绝理由原文 | 例：已拆封影响二次销售，不予退货 |
| 是否已申请平台介入 | 是 / 否 |
| 商家是否已收到退回商品 | 是 / 否 |
| 商家收到退回商品日期 | 例：2026-10-07 |
