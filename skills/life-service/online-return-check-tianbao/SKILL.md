# 网购退货七天无理由核查

退货被拒的时候，商家最爱说三句话：**"拆封了不能退""页面写着不支持七天无理由""超过七天了"**。
这三句里，只有第三句在绝大多数情况下是对的，前两句都有解。

## 什么时候用

- 收到货想退，商家以"已拆封""影响二次销售"拒绝
- 商品页面标了"不支持七天无理由"，你想知道这一条排不排得掉你
- 买了定制/生鲜/数码产品，纠结能不能退
- 退货被要求承担运费，不清楚该谁出、运费险够不够
- 用了几天发现瑕疵，商家要你证明是它的错
- 平台判定不公，或者商家收了货拖着不退钱

## 怎么做

**第 1 步**：复制 `templates/网购退货信息采集表.md` 填写。

**第 2 步**：跑脚本

```bash
python scripts/return_check.py 采集表.md --base 2026-10-05 --out 核查报告.md
```

**第 3 步**：按第九段"待办补正动作"执行；第七段的时间节点直接照着倒计时。

## 三条定性的核心规则

1. **七天无理由从收到商品起算**（脚本取对消费者有利的口径：自签收次日起算，7 个自然日），
   且**无需说明理由**；经营者应当自收到退回商品之日起**七日内**返还价款。
2. **"不支持七天无理由"不是免责金牌**。只有"根据商品性质并经**购买时确认**不宜退货"这一类
   才排除；购买时未经你单独确认的标注无效。法定明确除外的只有四类：定作、鲜活易腐、
   拆封的数字化商品、交付的报纸期刊。
3. **"拆封了不能退"是错的**。消费者为**检查、试用**商品而拆封，且商品本身不污损的，
   仍属于商品完好；只有**超出查验和确认品质、功能需要**使用商品、导致价值贬损较大的，
   才被视为不完好。

## 输入 / 输出

| | 内容 |
|---|---|
| 输入 | 采集表 Markdown（商品 / 签收 / 拆封 / 质量 / 运费 / 进度 / 证据） |
| 输出 | 九段报告：结论摘要 / 路径判定 / 七天无理由逐条核查 / 拆封与商品完好 / 质量与举证责任 / 运费谁出 / 时限与退款时限 / 证据缺口与平台介入 / 待办 |
| 退出码 | 0 正常；2 关键信息缺失（给提示串，不崩） |

## 边界与纪律

- 依《消费者权益保护法》《民法典》合同编等**通用规则**整理，**不替代律师意见**
- 部分问题在司法实践中存在**两种口径**（激活是否等同于数字化商品、耐用商品的举证范围），
  脚本如实标注，**不断言法院一定支持**
- 二手闲置、海外购、直播带货、预售定金等特殊交易，还要叠加平台规则与跨境规则另行判断
- 平台介入的判定尺度由平台掌握，本技能不预测平台结果
- **未填的一律不算通过**，只按填了的判断

- `templates/退货操作卡.md` — 开箱取证、申请话术、平台介入步骤
