# 翻身减压、体位摆放与营养失禁管理

## 一、受压风险六维评估（每项记「有/无」）

| 维度 | 判定口径 | 命中含义 |
|---|---|---|
| V1 活动受限 | 不能自主翻身或转移，需他人协助 | 高风险 |
| V2 意识障碍 | 意识不清、深度镇静、不能表达不适 | 高风险 |
| V3 皮肤已发红或破损 | 任一受压部位已达 L1 及以上 | 已发生风险 |
| V4 大小便失禁 | 有尿失禁、便失禁或尿垫长期潮湿 | 加剧因素 |
| V5 摄入不足 | 食欲差、进食量明显减少、体重下降 | 延缓愈合 |
| V6 低体重或水肿 | 体重明显偏低或全身、下肢水肿 | 加剧因素 |

**风险档位**：

| 档位 | 条件 |
|---|---|
| 高 | V1 或 V2 命中任一项，或 V3 命中 |
| 中 | V4、V5、V6 中命中 2 项及以上 |
| 低 | 以上均未命中 |

## 二、翻身间隔参考表

| 风险档位 | 翻身间隔参考 | 备注 |
|---|---|---|
| 高（含意识障碍或已发红破损） | 约 1-2 小时 | 需专人负责，按表执行并记录 |
| 中 | 约 2-3 小时 | 保证每次翻身确实改变受力点 |
| 低（可自主翻身） | 每 2-3 小时提醒，夜间同样不省略 | 自主翻身者以提醒与协助为主 |

**必须一并写明的口径**：

- 上表是**参考区间**，不是标准答案
- **具体翻身间隔以医护人员的评估和建议为准**
- 每次翻身都要看全部高发部位，不是只翻一次就算完成
- 夜间与睡眠时段最容易漏，必须纳入排班
- 睡眠超过 3 小时未翻身且属高风险，属执行不到位，应立即补翻并纠正排班

## 三、体位摆放要点

### 仰卧位

- 头部、骶尾部、足跟三处是重点，枕与床垫要保证头部不长时间压在同一点
- 床单平整无皱褶，床单与床垫不形成剪切
- 双足自然下垂，避免长期抵住床尾挡板造成足跟受压

### 侧卧位

- **必须使用支撑**：头与颈之间垫枕，避免颈部悬空
- **患侧与健侧的顺序有讲究**，有偏瘫或一侧感觉障碍者需按医护要求摆放
- **上侧肢体置于胸前**：上侧手臂放在身体前方，前臂与上臂之间放软枕承托，避免上臂悬空受压
- **两腿间夹枕**：防止上侧膝压迫下侧髋部、踝部互相叠压
- **足跟悬空**：足跟下垫软卷或让足跟离开床面，是最常被忽略的一步

### 坐位（轮椅或床椅）

- 每 30-60 分钟减压一次，起身或前倾改变受力点
- 坐骨结节处是主要受压点，避免长时间同一坐姿
- 悬垂足避免足跟与鞋后跟长时间顶压

## 四、搬运与移动的硬要求

- **抬起而非拖拽**：拖拽会造成剪切力，是压疮常见成因
- 使用中单或移位垫，两人或多人协同
- 移动后检查受压部位皮肤，特别是原受力点解除后的新受力点

## 五、营养与水分管理（原则层面）

| 方向 | 做法 | 不做什么 |
|---|---|---|
| 蛋白 | 保证每餐有蛋白来源，分次少量多次优于一次大量 | 不自行大剂量补充蛋白粉或营养剂 |
| 热量 | 三餐加 1-2 次加餐，减少因没胃口而整餐不吃 | 不用「喝汤」代替吃饭，汤水营养密度低 |
| 水分 | 白天分次饮水，按尿量与口唇情况观察 | 不因怕失禁而限制饮水 |
| 进食困难 | 记录进食量与体重趋势，交给医生或营养专业人员评估 | 不自行决定管饲或补充剂方案 |

**触发专业营养支持的条件**：连续 2 周体重下降、进食量明显低于日常一半、伴贫血或水肿。由医生或临床营养专业人员评估。

## 六、失禁管理

| 环节 | 做法 |
|---|---|
| 定时如厕 | 定时提醒并协助上厕所，减少长期使用尿垫 |
| 勤更换 | 尿垫湿或脏立即更换，不等下一次更换时间 |
| 清洁 | 每次失禁后用温水与温和清洁剂清洗，轻拍吸干，不用力擦 |
| 干燥 | 清洁后确保皮肤干燥，潮湿环境是压疮推手之一 |
| 隔离潮湿 | 使用隔离潮湿的护理垫或敷料，但保持透气，不能湿闷 |
| 皮肤保护 | 使用医护推荐的保护性产品，具体产品由医护选择 |
| 记录 | 记录失禁次数与每日尿量，作为评估依据 |

## 七、必须叠加使用的减压措施（不能只靠一项）

1. 定时翻身（执行到位才是第一位）
2. 合适的减压床垫或坐垫（不推荐具体品牌与参数）
3. 体位摆放与支撑（枕头、软卷、足跟悬空）
4. 避免牵拉拖拽（抬起移动）
5. 保持皮肤清洁干燥
6. 营养与水分支持
7. 失禁管理
8. 监测与记录（无记录等于没有执行）

## 八、记录与复评节奏

| 频次 | 内容 |
|---|---|
| 每次翻身 | 观察接触部位皮肤有无新发红 |
| 每日 | 各部位 L 级别、渗液、气味、体温、进食、饮水、失禁次数、翻身完成次数 |
| 每 2 天 | 创面长 × 宽测量 |
| 每周 | 体重 |
| 每 2 周 | 复评风险档位与翻身间隔是否需要调整（并与医护沟通） |
