# 压疮描述性分期与识别口径

**前置声明**：本表用**描述性口径**记录皮肤表现，便于家属与医护沟通。**正式的压疮分期诊断由医护人员判断**，分期以医护结论和最新版相关指南为准。

## 一、描述性表现分级（记录用，非诊断）

| 级别 | 名称 | 可观察表现 | 家庭处理定位 |
|---|---|---|---|
| L0 | 皮肤完好 | 受压部位皮肤完整，无颜色改变 | 预防为主，按风险档位执行翻身减压 |
| L1 | 压之褪色的红斑 | 局部发红，手指按压后变白，松手恢复红色 | 立即加强减压，停止该部位受压 |
| L2 | 压之不褪色的红斑 | 发红持续存在，按压不褪色 | 减压并通知医护，不按摩不揉搓 |
| L3 | 水疱 | 出现水疱或表皮破损渗液 | 停止受压，请医护评估，不自行挑破 |
| L4 | 浅表破溃 | 表皮缺失，创面浅，未见深层组织 | 转诊由医护处理 |
| L5 | 深部创面 | 创面较深，可能可见脂肪、筋膜、肌腱或可触及骨嵴 | **立即就医**，不做家庭处理 |

**使用口径**：分级只描述「看起来是什么样」，不描述病因、不给预后。记录时把「压之是否褪色」单独写清楚，这是变化最快的观察点。

## 二、必须记录的九项（每次观察都写）

1. **部位**：精确到解剖位置（如骶尾部、足跟、左侧髋部），并标明左右
2. **范围**：用可测量的方式描述（长 × 宽，单位厘米），不要只写「一块」
3. **颜色**：红、暗红、紫、暗紫、发黑、发黄
4. **压之是否褪色**：褪色 / 不褪色 / 未测（不要留空）
5. **是否完整**：完整 / 有水疱 / 已破溃
6. **渗液**：无 / 少量 / 中量 / 大量，并记录颜色
7. **气味**：无 / 有（有无恶臭）
8. **创缘与周围皮肤**：发黑发紫、肿胀、发红发热的范围
9. **患者反应**：有无疼痛；**注意「无痛」可能是神经受损的表现，不能当作好转**

## 四、必须立即就医或转诊的情形

1. 创面深达骨面、可见筋膜或肌腱、可触及骨嵴
2. 创面内有坏死组织、焦痂、脓液或明显恶臭
3. 创缘发黑、发紫、发亮，或周围红肿热痛迅速扩展
4. 两天内创面明显扩大，或 2 周完全不见收口迹象
5. 伴发热、寒战、意识改变、血压下降
6. 渗液量大并伴体温升高
7. 伴尿路感染表现（尿频尿痛发热、尿液浑浊异味）
8. 老人食欲极差、体重快速下降、严重贫血或水肿
9. 疼痛剧烈但对触碰无反应
10. 破溃位置在足跟、骶骨、髋部等承重骨突处

## 五、明确禁止的家庭处理

| 禁止 | 原因 |
|---|---|
| 按摩、揉搓发红的皮肤 | 加重微血管与组织损伤 |
| 用力按压骨突部位「测试」 | 造成新的损伤 |
| 自行挑破水疱 | 增加感染入口 |
| 自行切开引流 | 可能损伤深部结构与血管 |
| 用刀或剪刀剪除黑色组织 | 焦痂下可能是感染或更深层损伤 |
| 涂抹偏方、草药、牙膏、酱油等 | 污染创面并掩盖感染征象 |
| 自行使用抗生素软膏 | 耐药与菌群混乱，掩盖征象 |
| 拖拽搬动病人 | 剪切力是压疮的重要成因 |
| 不用药记录「好了」就不复诊 | 需医护评估是否真正收口 |

## 六、拍照记录的口径（可用于带去就医）

- 拍照用于自己对比与给医护看，**不发布到社交平台**
- 同一角度、同一光线、同一距离，保证可对比
- 拍照时遮挡非伤口的身体部位，**不拍不传隐私部位**
- 用直尺或硬币做尺寸参照放在画面边缘
- 每次拍照标注日期与体位

## 七、必须记录的可测量指标

| 指标 | 记录频次 | 用途 |
|---|---|---|
| 翻身次数与时间 | 每次 | 判断方案执行率 |
| 皮肤 L 级别（按部位分别记） | 每日 | 判断趋势 |
| 创面长 × 宽（厘米） | 每 2 天 | 判断是否收口 |
| 渗液量与气味变化 | 每日 | 判断有无感染 |
| 体重（公斤） | 每周 | 判断营养趋势 |
| 每日饮水量与进食量 | 每日 | 判断营养与水分 |
| 尿量与失禁次数 | 每日 | 判断失禁管理效果 |
| 体温 | 每日 | 早期发现感染 |
