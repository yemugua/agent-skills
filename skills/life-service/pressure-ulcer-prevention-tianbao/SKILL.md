# 褥疮分期与预防护理翻身核查

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 用描述性分期口径记录皮肤表现（红斑、水疱、破溃、深达骨面） | 给出压疮的正式分期诊断，分期以医护人员判断为准 |
| 按受压风险给出翻身间隔**参考**并说明以医护建议为准 | 承诺某个翻身间隔一定适合；不同患者差异很大 |
| 列出减压措施与体位摆放要点 | 推荐具体品牌、设备型号或床垫参数 |
| 输出营养与失禁管理的原则性要点 | 给出具体营养补充剂、蛋白粉用量或肠内营养方案 |
| 给出必须记录的可测量指标 | 给出药品名称、剂量、换药频次、敷料选择或清创方案 |
| 明确什么时候必须转诊、由医护处理 | 代替伤口专科或医师判断，做清创与治疗决策 |
| 说明伤口记录与拍照的隐私与合规口径 | 指导家属自行切开、挤压、清除坏死组织 |

**必须立即就医或转诊医护的红线（出现任一条，停止家庭处理并就医）**

- 伤口深达骨面、可见筋膜或肌腱、或可触及骨嵴
- 伤口内有坏死组织、焦痂、脓液、明显恶臭
- 创缘发黑、发紫、发亮，或周围红肿热痛迅速扩展
- 创面扩大：两天内明显扩大，或 2 周不见任何收口迹象
- 伴发热、寒战、意识改变、血压下降
- 渗液量大、有明显渗出并伴体温升高
- 出现尿路感染表现：尿频尿痛发热、尿液浑浊异味
- 老人出现食欲极差、体重快速下降、严重贫血或水肿
- 疼痛剧烈但神经可能受损（对触碰无反应而周围皮肤极痛）
- 伤口位于足跟、骶骨、髋部等承重骨突处且已破溃

**绝对禁止的处理方式**：自行切开引流、挤压清创、用刀或剪刀剪除坏死组织、涂抹不明偏方或草药于开放创面、自行使用抗生素软膏、用力按摩已发红的皮肤、用力揉搓骨突部位。

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「腰上有个红印子是不是褥疮」 | 用，描述性识别 + 是否需就医 |
| 「压疮怎么分期」 | 用，给描述性口径，正式分期以医护为准 |
| 「卧床多久翻一次身」 | 用，按风险给出参考间隔 |
| 「气垫床有没有用」 | 用，减压原则，不推荐品牌参数 |
| 「侧卧要垫枕头吗」 | 用，体位摆放要点 |
| 「大便失禁怎么办」 | 用，失禁管理原则 |
| 「创面抹点什么好得快」 | 不用，药品与敷料由医护决定 |
| 「要不要送医院」 | 用，红线判断 |
| 「多久能好」 | 用，只说明影响因素，不承诺时间 |

## 三、完整工作流

1. **先看有没有红线**：逐条核对就医红线，命中即转诊，不给家庭处理建议。
2. **描述现状**：按 `rules/分期描述与识别口径.md` 逐项记录皮肤表现、部位、范围、渗液、气味、周围皮肤；用 `templates/皮肤与翻身记录表.md`。
3. **判断受压风险等级**：按意识、活动能力、皮肤状况、大小便失禁、营养、体重六个维度给档位。
4. **给出翻身间隔参考**：按 `rules/翻身减压与体位摆放.md` 的风险档位表给参考值，并注明以医护建议为准。
5. **列减压叠加措施**：床垫、体位、支撑、避免牵拉、避免潮湿。
6. **列营养与失禁管理要点**：蛋白与热量摄入原则、大小便管理、皮肤清洁与干燥。
7. **设定记录与复评节奏**：每次翻身观察一次，每日记录一次，每 2 周复评一次。
8. **明确转诊触发条件**：把红线写进记录表首页，出现即执行。

## 四、核心规则与要件库

生成任何护理建议前，**必须先读**：

- `rules/分期描述与识别口径.md`：描述性分期表述、各期可观察表现、必须转诊情形、禁止的家庭处理。
- `rules/翻身减压与体位摆放.md`：受压风险六维评估、翻身间隔参考表、体位摆放要点、营养与失禁管理、记录指标。

不得给药品名称与剂量、换药频次、敷料选择与清创方案；不得给出压疮的正式分期诊断；不得承诺愈合时间。所有医学口径**以最新版指南和医护人员判断为准**。

## 五、脚本用法

```
python scripts/pressure_ulcer_plan.py --file case.json
python scripts/pressure_ulcer_plan.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`risk` 风险维度标记（`immobile` `unconscious` `red_skin` `incontinence` `poor_intake` `low_weight`），`stage` 观察到的表现等级 `blanchable` `nonblanchable` `blister` `erosion` `deep`，`red_flags` 红线标记，`hours_start` 起始观察小时数 |
| `--json` | 以 JSON 输出 |
| `--out` | 结果写入指定文件，默认 `scripts/_last_result.txt` |
| `--selftest` | 运行自检 |

脚本输出风险档位、翻身间隔参考、转诊触发与记录要求。**脚本不给药品、不给换药方案、不做正式分期诊断。**

## 七、最常见的坑

1. **以为只是红印子，揉一揉就好了**：揉搓已发红的皮肤会加重损伤，是明确禁止的做法。
2. **只靠床垫，不翻身**：再好的减压床垫也替代不了定时翻身与体位变换。
3. **翻身只抬身体不挪位置**：翻完还是压在同一点上，等于没翻。要确保受力点确实改变。
4. **侧卧不垫枕头**：侧卧时下肢交叉压迫、膝踝重叠会形成新的压迫点，必须摆放支撑。
5. **拉拽病人搬运**：拖拽会使皮肤承受剪切力，是压疮的重要成因，要抬而非拖。
6. **忽视失禁**：尿液与粪便的化学刺激和潮湿环境是压疮进展的常见推手，只清洁不够还要隔离潮湿。
7. **营养只靠「喝汤」**：汤水营养密度低，蛋白质与热量不足会直接延缓愈合。
8. **两周没好转就加大补品**：无效时首先考虑是否合并感染、营养不足或压力未解除，而不是加营养剂。
9. **自行用抗生素软膏**：可能造成耐药与菌群混乱，且掩盖感染征象。
10. **家属自行剪掉黑色组织**：焦痂下可能是感染或更深层损伤，自行处理极易造成不可逆后果。
11. **只看背面不看足跟**：足跟、尾骨、骶骨、髂前上棘、耳廓、肩胛都是高发部位，鞋袜里的足跟最容易漏。
12. **以为「不痛」就是没事**：神经受损或糖尿病周围神经病变者，痛觉减退，压疮可在无痛状态下进展。

## 八、边界与免责

本技能提供压疮的描述性识别口径、翻身与减压护理参考，**不提供药品名称与剂量、换药频次、敷料选择、清创方案，也不给出压疮的正式分期诊断**。翻身间隔与护理方案因受压风险、皮肤状况、基础疾病而差异很大，**以最新版相关指南和医护人员的判断为准**。出现深达骨面、坏死组织、脓液恶臭、创面快速扩大、发热或意识改变等情形，必须立即就医转诊。本技能不替代伤口专科诊疗与换药操作。
