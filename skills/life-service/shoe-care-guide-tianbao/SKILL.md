# 鞋子保养

## 1. 硬边界（能做什么 / 不能做什么）

| 能做 | 不能做（转专业人士） |
|---|---|
| 清灰、去污、上鞋油 / 护理喷雾 | 换底、粘胶结构修复 |
| 运动鞋浸泡刷洗（网面） | 皮鞋机洗、暴晒 |
| 塞纸定型、正确存放 | 烘干机烘鞋 |

鞋底断裂、开胶严重、鞋面破洞，转修鞋。

## 2. 什么时候用

| 用户说法 | 用不用 |
|---|---|
| 皮鞋发干开裂 | 用（上鞋油滋养） |
| 运动鞋洗后发黄 | 用（阴干 + 卫生纸） |
| 鞋有异味 | 用（除味通风） |
| 鞋底断了 / 开胶 | 不用（转修鞋） |

## 3. 完整工作流

1. **清灰**：解鞋带，干刷去浮灰泥。
2. **去污**：皮鞋用皮革清洁剂擦，运动鞋用中性洗剂软刷，帆布可水洗。
3. **护理**：皮鞋上鞋油 / 乳滋养并打亮，网面喷防水喷雾。
4. **晾干**：塞报纸定型，**阴干通风**，不暴晒不烘干。
5. **存放**：鞋撑 / 纸团保型，避潮避光，轮换穿。

鞋型对应口径见 `rules/shoe-rules.md`。

## 4. 核心规则 / 要件说明

生成保养方案前**先读 `rules/shoe-rules.md`**：鞋型 → 清洁剂 / 手法、禁用清单。不合格带原因，如「皮鞋机洗：脱胶变形开裂，必须手洗护理」。

## 5. 脚本用法

`scripts/shoe_check.py` 自检「保养操作清单」：

```
python scripts/shoe_check.py --file steps.json
python scripts/shoe_check.py --selftest
```

## 6. 人工确认清单

- [ ] 已清灰去污
- [ ] 清洁剂与鞋型匹配
- [ ] 已上护理
- [ ] 阴干未暴晒 / 烘干
- [ ] 塞纸定型存放

## 7. 最常见的坑

1. 皮鞋机洗：脱胶变形，必须手洗上油。
2. 洗后暴晒 / 烘干：开胶发黄变硬，阴干。
3. 运动鞋不塞纸：干后塌褶变形，塞报纸。
4. 白鞋洗后不包纸：氧化发黄，裹卫生纸阴干。
5. 长期不护理皮鞋：皮干裂，定期上油。
6. 一双穿到底：无休息回潮发霉，轮换。

## 8. 边界与免责

覆盖日常皮鞋 / 运动鞋 / 帆布清洁养护。换底、结构粘胶修复不在范围。贵重鞋建议专业养护。
