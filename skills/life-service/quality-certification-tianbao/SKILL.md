# 体系认证准备与迎审（quality-certification）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据 ISO 9001 等体系认证流程，生成清单：认证范围与机构选择、体系运行与内审管评、文件与记录准备、现场迎审与陪同、不符合项整改与获证维护。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 体系认证
- ISO认证
- 认证准备
- 外审迎审
- 认证不符合项

## 三、工作流
1. 确定认证范围并选择机构
2. 确保体系运行并完成内审管评
3. 准备文件与记录
4. 组织现场迎审与陪同
5. 整改不符合项并维护证书

## 四、核心内容（检查清单与判定）
体系认证前须完成内审与管理评审并备齐记录；现场迎审要安排熟悉过程的陪同人员，不符合项须按期整改并验证闭环。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含认证范围与机构选择 | 范围 |
| Q2 | FAIL | 未含体系运行与内审管评 | 内审 |
| Q3 | WARN | 未含文件与记录准备 | 文件 |
| Q4 | FAIL | 未含现场迎审与陪同 | 迎审 |
| Q5 | WARN | 未含不符合项整改与维护 | 整改 |

> 脚本 `quality-certification_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python quality-certification_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python quality-certification_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
