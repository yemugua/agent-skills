# 消防安全重点单位管理（fire-key-unit）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《消防法》第十七条与《机关团体企业事业单位消防安全管理规定》（公安部61号令），生成消防安全重点单位管理清单：列入界定、防火档案、每日防火巡查、定期培训演练、户籍化/标准化管理。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 消防重点单位
- 重点单位管理
- 消防安全重点
- 防火档案
- 户籍化管理

## 三、工作流
1. 按标准界定并申报消防安全重点单位
2. 建立消防安全档案与户籍化管理
3. 落实每日防火巡查与月度检查
4. 开展员工消防安全培训与演练
5. 明确管理人职责与履职记录

## 四、核心内容（检查清单与判定）
《消防法》第十七条明确消防安全重点单位须履行更严格的管理职责；61号令要求其建立防火档案、每日巡查、定期培训演练，实行标准化与户籍化管理。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含重点单位界定与备案 | 界定 |
| Q2 | FAIL | 未含消防安全档案/户籍化 | 档案 |
| Q3 | WARN | 未含每日防火巡查 | 巡查 |
| Q4 | FAIL | 未含培训与演练落实 | 培训 |
| Q5 | WARN | 未含管理人职责与履职 | 职责 |

> 脚本 `fire-key-unit_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python fire-key-unit_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python fire-key-unit_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
