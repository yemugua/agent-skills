# 烤箱温控与烘烤时间核查（oven-temperature-control）

烘烤失败只有两种：**外面焦了里面没熟**，或者**外面焦了里面还是没熟**。这两件事几乎都出在温度、时间与预热这三个变量上，而不是配方。

这个技能做四件事：**换算 → 定温 → 折算时间 → 判成因**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出温度换算、参数对照与时间折算 | ❌ 校准烤箱温控精度（需专业仪器） |
| 说明上下火、风扇模式、预热与开门的影响 | ❌ 判断食品是否达到安全温度（需探针实测） |
| 给出易焦与不熟的具体成因 | ❌ 替代产品说明书与烘焙配方 |
| 给出探针温度计使用要点 | ❌ 指导改装烤箱电路与温控元件 |

**遇到以下情况，转交专业人员：**

- 烤箱**实际温度与设定温度偏差明显**，且按建议空载预热后仍存在
- **温控器失灵、加热管局部不亮或异常发红**
- **有焦糊味、冒烟、异常声响**，或电源线、插座发热异常
- 烤箱**门封条破损、门玻璃碎裂**，或炉门关不严
- 需要**拆机、校准温控、更换加热管或改动电路**

> **本技能不提供校准与改装方法。** 温控精度只能靠专业仪器测量，家用条件下只能做「间接判断是否明显异常」。

## 二、温度换算表（华氏与摄氏）

| 华氏 | 摄氏 | 华氏 | 摄氏 |
|---|---|---|---|
| 100 | 38 | 220 | 104 |
| 120 | 49 | 230 | 110 |
| 140 | 60 | 240 | 116 |
| 150 | 66 | 250 | 121 |
| 160 | 71 | 260 | 127 |
| 170 | 77 | 280 | 138 |
| 180 | 82 | 300 | 149 |
| 190 | 88 | 320 | 160 |
| 200 | 93 | 350 | 177 |

**换算公式**：

```
摄氏 = (华氏 − 32) × 5 ÷ 9
华氏 = 摄氏 × 9 ÷ 5 + 32
```

**记忆锚点**：华氏 212 = 摄氏 100（水的沸点）；**烘烤常用区间是华氏 300 到 400，对应摄氏 149 到 204**。

## 三、按食材的温度与时间对照

| 食材 | 温度 | 时间 | 易焦成因 | 不熟成因 |
|---|---|---|---|---|
| **整鸡** | 190℃ | 70 分钟 | 表皮上色过快而中心未熟，需降温或加盖锡纸 | 中心温度不足，解冻不彻底或温度偏低 |
| **排骨** | 190℃ | 45 分钟 | 酱汁含糖易焦，中途翻面并降温 | 肋排贴近烤盘受热不足 |
| **鸡翅** | 200℃ | 25 分钟 | 糖分或酱料直接接触上火易焦，中途刷油翻面 | 翅根未熟透，摆放过密 |
| **牛排** | 200℃ | 8 分钟 | 高温长时间使表面碳化，内部仍偏生 | 厚度不够或预热不足 |
| **整条鱼** | 190℃ | 25 分钟 | 鱼皮直接暴露易焦，需垫锡纸或提前刷油 | 鱼肉厚薄不均，靠鱼尾处易生 |
| **烤蔬菜** | 200℃ | 30 分钟 | 水分多易出水后焦边，温度过高 | 块太大或铺满烤盘，间距不足 |
| **烤根茎** | 200℃ | 40 分钟 | 糖分表面易焦，中途翻面 | 块太厚或烤盘过密 |
| **烤红薯** | 200℃ | 45 分钟 | 糖分渗出易焦，中途翻面 | 红薯太大或温度不足 |
| **栗子** | 200℃ | 25 分钟 | 壳易焦，需开口后再烤 | 开口不足导致无法受热均匀 |
| **烤豆腐** | 200℃ | 25 分钟 | 表面水分多易焦边，需先煎或沥干 | 豆腐太嫩易碎，翻动过早 |
| **披萨** | 220℃ | 12 分钟 | 芝士与番茄酱易焦，上火过高时几分钟就上色 | 饼底太厚或水分过多 |
| **面包与吐司** | 180℃ | 30 分钟 | 糖浆与奶制品易焦，上火过高 | 发酵不足或烤箱温度偏低 |
| **蛋糕** | 170℃ | 40 分钟 | 表面糖分高易焦，需要垫烘焙纸 | 蛋白未打发或开裂导致未熟 |
| **曲奇饼干** | 170℃ | 15 分钟 | 糖浆易焦，需盯视颜色变化 | 面团过厚或炉温偏低 |

> 时间为参考值，实际受食材厚度、批量、初始温度与烤箱型号影响，**以产品说明书与实际观察为准**。

## 四、上下火与温场调整

| 温场状态 | 判断 | 调整 |
|---|---|---|
| **上火偏高** | 表面先焦、底部仍白 | 上火调低 20–30℃，或延长总时间 |
| **下火偏高** | 底部焦边、顶部不上色 | 下火调低 20–30℃，或垫空烤盘 |
| **上下火平衡** | 颜色均匀 | 维持当前设定 |
| **炉温不足** | 时间到了仍不上色 | 提高 10–20℃，或延长 20 分钟并提前 5 分钟复检 |
| **炉温过高** | 远不到时间就上色 | 降低 10–20℃，或加盖锡纸延缓上色 |

**两个容易忽略的点：**

- **靠近上管的食材总是先焦**，摆放时把易熟的放中层，易焦的放下层
- **不要铺满烤盘**，食材之间留间距，靠热空气循环才能均匀受热

## 五、风扇模式与非风扇模式

**风扇模式（热风循环）**：热量由风扇循环，受热更均匀，同温度下**通常比非风扇模式快约 20%**，需相应缩短时间。

**非风扇模式**：以上下发热管直接加热，**靠近上管的食材容易先焦**。

**风扇模式的特殊注意**：蛋糕与部分酥类点心在风扇模式下表面可能提前上色，**建议调低温度 10–20℃**。

---

## 六、预热的必要性

**预热不可省略。**

- 充分预热后，烤箱内**实际温度才达到设定值**
- 未充分预热时，投入食材会**吸收大量热量导致实际温度骤降**
- 结果是需要更长时间才能上色，**同时内部可能仍未熟透**

**家用烤箱建议预热 10–15 分钟**，可空箱或放空烤盘。预热期间不宜频繁开门。

---

## 七、开门对温场的影响

- 开门会导致烤箱内温度在**短时间内明显下降**
- **短时间开门取出检查**影响相对有限
- **长时间开门或连续多次开门**会显著延长烘烤时间并造成温场不均
- **建议一次开门完成观察与调整**，关门后按原时间继续
- 预热期间频繁开门会显著延长预热时间

---

## 八、易焦与不熟：具体成因对照

**「外面焦了里面还是生的」**——最常见也最容易被误判。成因通常同时存在多个：

| 成因 | 表现 | 处置 |
|---|---|---|
| 温度过高 | 远不到时间就上色发黑 | 降温 10–20℃ 或加盖锡纸 |
| 时间过长 | 到点后才想起，已焦 | 提前 5–10 分钟复视 |
| 食材太厚 | 表面已焦而中心仍冰 | 用探针测中心温度；延长时间并降温 |
| 摆放过密 | 局部上色不均 | 留间距，分批烤 |
| 紧贴上管 | 顶部明显比底部焦 | 调整烤盘层位 |
| 糖分或酱料 | 表面极易碳化 | 中途盖锡纸，降温 |
| 未充分预热 | 整体上色慢且不均 | 延长预热与总时间 |

**关键认知**：表面焦了**不代表**中心熟了。这两个状态可以同时存在，判断中心状态必须靠**探针温度计或可靠的切开观察**。

---

## 九、探针温度计使用要点

1. 探针插入**食物最厚处中心**，不能触到烤盘或烤架
2. 肉类禽类**中心温度达到 75℃ 并保持**，可靠性明显提高
3. **薄片与小块不适合探针测量**，应按时间与外观综合判断
4. 探针**每次用完要清洁消毒**，不同食材之间不要混用
5. 插拔探针时**先开门降温**，避免蒸汽烫伤

## 十、脚本用法

```bash
python scripts/oven_temp_check.py --file oven.json --out 温控核查.md
python scripts/oven_temp_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`temp_c` 摄氏温度、`fan_mode` 风扇模式、`preheat_done` 是否预热、`heat_state` 温场状态、`items` 食材列表 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检（34 条断言，含 BOM 输入两条） |

输入 JSON 示例：

```json
{
  "temp_c": 190,
  "fan_mode": false,
  "preheat_done": true,
  "heat_state": "top_heavy",
  "items": [
    {"food": "whole_chicken", "probe": true},
    {"food": "sweet_potato", "temp_c": 220}
  ]
}
```

可选食材键：`whole_chicken` `chicken_wing` `beef_steak` `pork_rib` `fish` `roast_vegetable` `bread` `cake` `cookie` `pizza` `roast_roots` `chestnut` `tofu` `sweet_potato`；`heat_state` 只接受 `top_heavy` / `bottom_heavy` / `even` / `too_low` / `too_high`。

**时间折算公式**：

```
实际时间 = 建议时间 × (建议温度 ÷ 实际温度)
风扇模式再乘 0.8
```

脚本输出：华氏摄氏换算表、逐项温度与折算时间（按时间变化幅度排序）、易焦与不熟成因、风扇模式说明、预热与开门影响、探针要点与提示。

## 十一、人工确认清单（这步不能省）

- [ ] 已充分预热 10–15 分钟
- [ ] 烤盘位置与食材摆放间距合适，未铺满
- [ ] 已在预计完成时间前复视颜色与状态
- [ ] 肉类禽类已用探针确认中心温度或按可靠时间执行
- [ ] 未频繁开门

## 十二、最常见的坑

**坑一：跳过预热。**
错误做法：设好温度直接放食材进去。正确做法：**预热不可省略**。未充分预热时投入食材会吸收大量热量导致实际温度骤降，结果是更长时间才上色，**同时内部可能仍未熟透**——这正是「外面焦了里面还是生的」的常见成因。

**坑二：把华氏当摄氏用。**
错误做法：食谱写 350 度，直接设 350℃。正确做法：华氏 350 = 摄氏 177。**烘烤常用区间是华氏 300–400，对应摄氏 149–204**。这是「温度设太高直接烤焦」的头号原因。

**坑三：风扇模式不缩短时间。**
错误做法：还是按原来的时间烤。正确做法：风扇模式同温度下**通常快约 20%**，需相应缩短时间。否则同样会烤焦。

**坑四：蛋糕用风扇模式还按原温度。**
错误做法：风扇模式烤蛋糕，温度不变。正确做法：蛋糕与部分酥类点心在风扇模式下**表面可能提前上色**，建议调低温度 10–20℃。

**坑五：全程不开门看。**
错误做法：怕热气跑掉，一直不开门。正确做法：**在预计完成时间前 5–10 分钟开门复视颜色**，一次开门完成观察与调整。看颜色是判断焦与不熟最直接的手段。

**坑六：频繁开门。**
错误做法：每隔十分钟开一次看看。正确做法：开门会导致温度**短时间内明显下降**，连续多次开门会显著延长烘烤时间并造成温场不均。**一次开门完成所有调整**。

**坑七：铺满烤盘。**
错误做法：把烤盘塞得满满当当。正确做法：食材之间**必须留间距**，靠热空气循环才能均匀受热。铺满是局部上色不均与内部不熟的重要成因。

**坑八：看到焦了就整盘端出来。**
错误做法：表面焦了，以为熟了就拿。正确做法：**表面焦不代表中心熟**，这两个状态可以同时存在。肉类禽类用探针测中心温度，或按可靠时间并切开确认。

**坑九：厚肉延长时间而不是降温。**
错误做法：牛排里面没熟，就多烤十分钟。正确做法：温度过高长时间会让表面碳化而内部仍偏生。正确做法是**降温 10–20℃ 并延长时间**，或中途加盖锡纸。

**坑十：紧贴上管烤。**
错误做法：把食材放在最上层。正确做法：**靠近上管的食材总是先焦**。摆放时把易熟的放中层，易焦的放下层。

**坑十一：酱汁含糖还不降温。**
错误做法：排骨刷了蜜糖还按 200℃ 烤到底。正确做法：**糖分与酱料极易碳化**，中途需盖锡纸并降温，否则外焦内生。

**坑十二：温度不准还在用。**
错误做法：设 190 烤半天不上色，怀疑配方。正确做法：先排除**温控偏差与未预热**两个变量。家用条件下无法精确校准，若偏差明显应转专业检测。
