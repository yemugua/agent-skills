# 消防验收常见不合格项库（12 类 + A/B/C 分级口径）

> 本表用于**把已经发现的问题排整改顺序**，不用于「认定某项目合格」。最终结论以住房和城乡建设主管部门的现场查验结果为依据。

## 一、分级口径

| 等级 | 定义 | 处置原则 | 常见整改期限（参考） |
|---|---|---|---|
| **A 类** | 违反强制性要求，或导致系统整体失效、疏散条件不成立 | 停用或禁止投入使用；整改后重新申请 | 立即 |
| **B 类** | 不导致整体失效，但明显降低可靠性或延长响应时间 | 限期整改并提交复查材料 | 通常 30 日内 |
| **C 类** | 形式性、标识性、台账类缺陷 | 随整改计划推进 | 通常 90 日内 |

**升级规则**：同一部位同时存在多个等级的问题，**按最高等级记一条**，不要拆成多条低等级项掩盖问题。
**降级禁止**：只有当有完整的复检记录、对比数据与责任人签字时，才可以把原 A 类项记为「已整改」；仅有口头说明或一句「已整改」的，仍按未整改处理。

## 二、12 类不合格项对照表

### 1. 擅自变更（常见 A 类）

| 表现 | 判定提示 |
|---|---|
| 平面分隔增加，疏散走道变窄 | 与审查通过图纸比对，逐层核对 |
| 防火分区合并或面积变化 | 核对防火分区图与防火分隔构件 |
| 减少安全出口或改变出口位置 | 数人头、数宽度，不以现场临时开启为准 |
| 增加夹层、使用人数增加 | 核对设计使用人数与实际容纳人数 |
| 取消或移位消防设施 | 核对设施点位图 |

**整改方式**：能恢复原状的先恢复；确需保留变更的，走设计变更技术复核乃至重新审查，再把图纸改一致。

### 2. 消防产品不符（常见 A 类）

| 表现 | 判定提示 |
|---|---|
| 目录内产品无强制性认证 | 查认证证书编号与有效期 |
| 产品型号与证书覆盖型号不一致 | 逐台核对铭牌 |
| 使用已被通报的不合格产品 | 查产品流向与进货凭证 |
| 型式检验报告替代强制认证 | 两者不可互相替代 |

### 3. 系统与联动（常见 A 类）

| 表现 | 判定提示 |
|---|---|
| 单系统能动作但联动逻辑未实现 | 最容易被放过的项：必须做联动试验，不是单机试一下 |
| 消防控制室手动/自动切换失效 | 现场实操验证 |
| 消防泵未在消防控制室手动直接启动 | 核对多线控制 |
| 未完工就申报 | 按申报范围核对实际完工内容 |

### 4. 疏散条件（常见 A 类）

| 表现 | 判定提示 |
|---|---|
| 安全出口数量不足 | 按楼层、防火分区分别计数 |
| 疏散宽度不足 | 按设计人数计算，含台阶、门扇有效宽度 |
| 疏散距离超限 | 量最近出口路径，含绕行 |
| 疏散通道被占用、锁闭 | 现场状态为准，临时打开不算整改 |

### 5. 防火分隔（常见 A 类）

| 表现 | 判定提示 |
|---|---|
| 防火分区面积超标 | 核对分区图与分隔构件完整性 |
| 防火门等级不符、缺闭门器或顺序器 | 逐樘核对 |
| 管线穿越防火分隔未封堵 | 看封堵材料与做法，不能只看表面 |
| 防火卷帘下降不到位、无两步降 | 现场实测到位信号 |

### 6. 装修材料（A 至 B 类）

| 部位 | 常见要求 | 常见问题 |
|---|---|---|
| 顶棚 | 燃烧性能等级要求最高 | 吊顶内使用可燃材料 |
| 墙面 | 次高等级要求 | 软包、木饰面无处理说明 |
| 地面 | 有相应等级要求 | 地毯、塑胶地板无检测依据 |
| 固定家具与装饰织物 | 有阻燃要求 | 窗帘幕布无阻燃处理证明 |

### 7. 总平面（A 至 B 类）

| 表现 | 判定提示 |
|---|---|
| 防火间距不足 | 含搭建、堆场、临时设施的占用 |
| 消防车道净宽净高不足 | 实测，含转弯半径与承载 |
| 登高操作场地被占 | 看是否被车位、绿化、构筑物侵占 |
| 消防车回车场缺失 | 尽头式车道必查 |

### 8. 水系统（常见 B 类）

| 表现 | 判定提示 |
|---|---|
| 消防水池、水箱水位不足 | 看实际有效容积，不是几何容积 |
| 消防泵组流量压力不达标 | 看实测曲线，出口压力不等于最不利点压力 |
| 末端试水压力或流量不足 | 在最不利点测 |
| 稳压装置频繁启停 | 看设定值与管网泄漏 |

### 9. 消防供配电（常见 B 类）

| 表现 | 判定提示 |
|---|---|
| 双电源未在末端配电箱切换 | 逐回路核末端切换 |
| 配电线路防火保护不到位 | 看敷设方式与保护措施 |
| 备用电源容量不足或切换超时 | 带载测试，不是空载切换 |
| 消防配电与非消防负荷混接 | 核回路图 |

### 10. 防排烟（常见 B 类）

| 表现 | 判定提示 |
|---|---|
| 风机风量不足 | 实测风量与设计值比对 |
| 正压送风余压不达标 | 测楼梯间与前室的压差 |
| 防火阀未联动关闭风机 | 查联动动作与信号反馈 |
| 排烟口位置或有效面积不符 | 核对图纸与被遮挡情况 |

### 11. 资料完整性（B 至 C 类）

| 表现 | 判定提示 |
|---|---|
| 隐蔽工程记录缺部位描述 | 必须写到部位与做法 |
| 检测报告过期或漏项 | 看有效期与系统覆盖完整性 |
| 施工记录几乎全写「正常」 | 无实测数据的记录等于没做 |
| 依据标准写代号不写年代号 | 退回的高频形式原因 |

### 12. 管理条件（常见 C 类）

| 表现 | 判定提示 |
|---|---|
| 消防安全管理制度照抄模板 | 缺本项目责任人、楼层、平面图 |
| 灭火和应急疏散预案无实际疏散路线 | 路线应与现场标识一致 |
| 未明确消防安全管理人与责任人 | 应有具体姓名与联系方式 |
| 标识、台账缺失 | 含消防设施标识与安全出口标识 |

## 三、整改排序原则

```
第 1 顺位  A 类中影响疏散与系统整体有效性的项（出口、分隔、联动）
第 2 顺位  A 类中涉及产品与材料的项（需要采购周期，早启动）
第 3 顺位  B 类技术性项（需调试与复测）
第 4 顺位  B 至 C 类资料项（可并行推进）
第 5 顺位  C 类形式项（最后一次核查前收口）
```

采购周期长的产品类问题要提前处理，否则会卡住最后期限。

## 四、闭环材料（每一项整改都要配齐）

| 要素 | 要求 |
|---|---|
| 问题描述 | 落到具体部位，不写「部分设施」这类模糊表述 |
| 整改措施 | 写清做法，不是写「加强管理」 |
| 整改日期 | 具体日期，且与后续复检日期有合理间隔 |
| 责任人 | 施工单位 + 建设单位双方签字 |
| 复查记录 | 复检人、复检日期、复检结论 |
| 佐证材料 | 照片、检测数据、产品证书等 |

**缺任何一项，都不能记为「已整改」。** 尤其是「未整改」「尚未整改」「待整改」这类表述，在核查表中必须保持其否定含义，不得按已整改统计。
