# 灭火器配置设计核算（fire-extinguisher-calc）

灭火器不是"差不多配几具"的事：**配少了烧起来没得用，配错了级别灭不了火，放远了远水救不了近火**。GB 50140 的算法，一个计算器就能搞定。

这个技能做四件事：**定危险级** → **算总量** → **分配置点** → **校距离**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 讲解配置核算方法与公式 | ❌ 替代设计文件、审查与验收结论 |
| 生成核算表与计算结果 | ❌ 保证实际灭火效果 |
| 整理危险级与保护距离规则 | ❌ 擅自变更已审查的设计 |

**计算结果仅作核算参考；正式工程配置以设计文件、审查意见和现行规范为准。**

**永远不要**把核算当形式——数量不足、级别不够、位置超距，检查时一项都跑不掉。

## 二、完整工作流

```
第 1 步  定危险级：工业/民用查表定严重/中/轻危险级
第 2 步  读规则文件 rules/extinguisher_rules.md
第 3 步  算总量：Q = K·S/U，再按场所修正 K
第 4 步  分配置点：Qe = Q/N，校每个点级别与保护距离
第 5 步  跑计算器 → python scripts/extinguisher_calc.py --selftest
第 6 步  按 templates/灭火器配置核算表.md 输出
```

## 三、危险级划分（节选示例）

| 类别 | 严重危险级 | 中危险级 | 轻危险级 |
|---|---|---|---|
| 厂房 | 闪点<60℃ 的液体等 | 闪点≥60℃ 的液体、可燃固体 | 一般固体原料 |
| 库房 | 化学危险品等 | 可燃固体 | 难燃材料 |
| 民用建筑 | 重要的电子/电信机房等 | 办公楼、旅馆、商场 | 普通办公、住宅配套 |

> 危险级查表**以 GB 50140 现行条文为准**；拿不准按高一级核算。

---

## 四、核算四步法

**第 1 步 划分计算单元**：按楼层、防火分区、使用功能划分。

**第 2 步 算总灭火级别**：

```
Q = K·S / U
```

- S：计算单元面积（㎡）
- U：单位灭火级别最大保护面积（㎡/A 或 ㎡/B，按危险级查表）
- K：修正系数（见下表）

**第 3 步 修正系数 K**：

| 已设设施 | K |
|---|---|
| 未设消火栓和灭火系统 | 1.0 |
| 设消火栓 | 0.9 |
| 设灭火系统 | 0.7 |
| 两者都设 | 0.5 |
| 歌舞娱乐放映游艺场所、网吧、商场、寺庙及地下建筑 | 另按 1.3 |

**第 4 步 分配置点**：`Qe = Q/N`，每个设置点灭火级别不得低于规范最低值（A 类严重 3A / 中 2A / 轻 1A；B 类对应 89B/55B/21B 量级，以规范表为准）。

---

## 五、保护距离（A 类火灾场所）

| 危险级 | 手提式灭火器最大保护距离 | 推车式 |
|---|---|---|
| 严重危险级 | 15 m | 30 m |
| 中危险级 | 20 m | 40 m |
| 轻危险级 | 25 m | 50 m |

> 设置在吊顶内的灭火器不计入保护距离；一个计算单元内任意点都应在保护范围内。

## 六、脚本用法（配置计算器）

```bash
python scripts/extinguisher_calc.py --area 1200 --level 中 --has-hydrant --has-system
python scripts/extinguisher_calc.py --selftest
```

输出：所需总灭火级别 Q、每个设置点级别建议、具数建议（按单具 2A 折算）、保护距离限值。

> ⚠️ 计算器只按简化口径核算，**正式配置以设计文件和规范为准**。

## 七、人工确认（这步不能省）

- [ ] 危险级划分是否与建筑实际用途一致
- [ ] 火灾类别是否不只是 A 类（有 B 类风险的需配 BC/ABC 对应级别）
- [ ] 每个点位置是否便于取用、无遮挡、无上锁
- [ ] 环境温度是否超出灭火器适用范围（严寒/高温场所）
- [ ] 配置图是否与实际摆放一致

## 八、输出结构（固定三段）

1. **够不够**——结论先行：核算达标 / 有缺口 / 有红线问题
2. **核算明细**——面积、危险级、K、U、Q、每点配置
3. **整改建议**——先补哪里、换什么级别、挪什么位置

## 九、最常见的坑

**坑一：只数个数不看级别。** 该配 3A 的点放了 1A 的，数量够级别不够。

**坑二：地下场所不乘 1.3。** 地下车库按普通场所算，直接少配三成。

**坑三：保护距离纸面达标。** 图上是 20 米，实际隔了三道门、一堆货架。

**坑四：B 类火灾配清水灭火器。** 油火用清水，越救越大。

**坑五：灭火器上锁/过期。** 配置达标，真用时打不开、喷不出。
