# 投诉书模板（三种口径，直接套用）

## 模板 A：12315 平台填写（简练、要素齐全）
```
被投诉方：____（企业全称，按营业执照）
经营地址：____（省/市/区）
投诉人：____ 电话：____
事实经过：
  本人于 X 年 X 月 X 日在【平台】购买【商品/服务】，订单号____，支付____元。
  收到后发现【问题描述，如：商品为假货/与宣传不符/商家拒绝退款】。
  已联系商家及平台客服（工单号____），对方【回复/未处理】。
投诉诉求：要求【退款____元 / 退货退款 / 赔偿____元 / 查处】。
附件：订单截图、问题照片、聊天记录、宣传页截图。
```

## 模板 B：黑猫投诉（叙事、带情绪但不失客观）
```
【事件】X 月 X 日，我在【平台】店铺【名】下单【商品】，花【金额】。
【问题】收到后【具体描述，附图】。与商家沟通，对方【态度/说辞】。
平台介入后【结果】。至今【未解决】。
【诉求】1. 退款/赔偿【金额】 2. 公开道歉 3. 请平台加强监管。
【证据】订单、支付、聊天、问题照片、宣传对比。
```

## 模板 C：平台工单（最快，先走内部）
```
问题描述：订单____出现【问题】，不符合【约定/宣传】。
已尝试：联系商家【结果】。
诉求：请平台依据规则【介入退款/退货/赔付】。
证据：见附件。
```

## 填写要点
- 金额、订单号、时间务必准确（与截图一致）。
- 诉求具体：写"退款 299 元"而非"退钱"。
- 不写辱骂、不夸大，"客观陈述"比"情绪宣泄"更容易被受理。
- 附件命名清晰：01订单、02问题图、03聊天。
