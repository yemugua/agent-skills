# 高频维权场景处理路径

## 场景 1：网购假货 / 货不对板
- 路径：平台工单（传鉴定/对比图）→ 12315（按商家所在地）→ 黑猫。
- 诉求：退货退款 + 依据消法主张赔偿（如构成欺诈退一赔三）。
- 证据：订单、正品对比、品牌鉴定、聊天记录。

## 场景 2：不发货 / 不退款
- 路径：平台介入（最管用）→ 12315 → 黑猫。
- 证据：下单支付、退款申请被拒截图、平台规则截图。

## 场景 3：预付费跑路（健身/培训/美容/月子）
- 路径：12315（按门店注册地）+ 当地商务主管部门（单用途预付卡归商务部门管）+ 黑猫 + 公安经侦（若涉集资/诈骗）。
- 证据：会员协议、充值记录、门店关闭公告、其他受害者群证。
- 提示：预付卡投诉常需联合其他受害者集体反映。

## 场景 4：旅游/月子/培训服务缩水
- 路径：合同 + 宣传页对比 → 平台/商家 → 12315 → 消协。
- 证据：合同、宣传页、实际服务记录、承诺聊天。

## 场景 5：外卖 / 到店食品安全
- 路径：平台投诉（附问题照片）→ 12315 / 当地市场监管（食品问题归市场监管）。
- 证据：订单、问题食品照片、就医记录（如不适）。

## 场景 6：虚假宣传 / 误导性广告
- 路径：留存广告页 → 12315（虚假宣传归市场监管）→ 黑猫。
- 证据：原广告截图（含违规词）、实际不符证明。

## 通用提示
- 所有场景先走"平台工单"，留工单号；平台不作为再升 12315/黑猫。
- 金额大、证据足、对方耍赖 → 互联网法院在线立案。
