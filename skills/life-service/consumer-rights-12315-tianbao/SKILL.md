# 消费维权投诉材料生成

> **4 句口诀**（3 秒判断要不要用我）：
> 1. 用户有**真实的消费纠纷**（买了假的/坏的/不退款/虚假宣传/跑路）想投诉 → 用我
> 2. 用户要**写投诉信、整理证据、找投诉渠道、知道适用哪条法律** → 用我
> 3. 用户要**虚构事实、伪造证据、恶意索赔、报复性投诉** → 拒绝，并说明原因
> 4. 我先要**事实要素**（谁、买了什么、花多少、出了什么问题、想要什么结果），再生成材料

## 一、这个技能是什么（工具型，不是指引型）

市场上已有"消费维权指引"类技能，本技能的定位是**代整理**：你口述一段真实经历，我把它变成一份**结构清晰、可直接复制投递**的投诉材料包，包含：
- 投诉书（事实经过 + 诉求，按 12315/黑猫/平台工单三种口径）
- 证据清单（你需要准备什么截图/凭证）
- 适用法条（消法/电商法/民法典关键条款，注明"以最新条文为准"）
- 投递渠道与优先级（先平台、再 12315、再黑猫/消协、最后法院）

## 二、收集事实要素的提问清单（必须问清再生成）

生成任何材料前，先确认以下 6 项，缺项就追问：
1. **对方是谁**：平台名（淘宝/京东/拼多多/抖音/美团…）、商家名/店铺名、订单号。
2. **买了什么/付了多少**：商品或服务名称、金额、支付时间、支付方式。
3. **出了什么问题**：假货/质量问题/不发货/不退款/虚假宣传/服务缩水/跑路。
4. **已做过什么**：是否联系过商家/平台客服、对方回复、是否留存记录。
5. **想要什么结果**：退款/赔偿/退货/道歉/查处。
6. **所在地/商家所在地**：影响 12315 管辖与投诉入口（微信/支付宝搜"12315"按经营者所在地选）。

## 三、生成材料的通用结构

```
【投诉书】
投诉人：___ 联系方式：___
被投诉方：平台___ / 商家___（统一社会信用代码如有）
事实经过：（时间线，按"何时—做了什么—对方如何回应"写）
投诉诉求：___（明确金额与诉求类型）
【证据清单】
1. 订单/支付截图  2. 商品问题照片/视频  3. 与商家/客服聊天记录
4. 宣传页面截图（证明虚假宣传） 5. 物流/签收记录
【适用法条】
《消费者权益保护法》第__条（注明以最新条文为准）
【投递渠道与优先级】
1. 平台工单（最快） 2. 12315（微信/支付宝小程序，7日内受理）
3. 黑猫投诉（舆论施压） 4. 消协 12315 同体系 5. 法院（金额大/拒不履行）
```

## 四、渠道优先级原则

1. **平台内工单/客服**最先（处理最快，留好工单号）。
2. **12315**（微信/支付宝小程序、web）——官方渠道，按经营者所在地投诉，7 日内决定是否受理。
3. **黑猫投诉**——新浪旗下，舆论压力倒逼，适合平台推诿。
4. **消协**（12315 同体系，或当地消保委）。
5. **法院/互联网法院**——金额大、证据足、对方拒不履行时最后手段（可在线立案）。

## 五、明确拒绝的
- 代写虚构事实的投诉、伪造/PS 证据
- 支持"职业索赔""恶意投诉""报复性举报"
- 承诺"百分百退款""包赢"——维权结果取决于事实与证据，不做保证
