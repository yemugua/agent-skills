# 卤味制作规则库

本文件是卤味配、卤、养的核心资产，判断前先读。

## 一、基础卤料配比（以 2 升清水为基准）

| 香料 | 用量 | 备注 |
|---|---|---|
| 八角 | 3–4 颗 | 主香 |
| 桂皮 | 1 小段约 5g | 不可过多，发苦 |
| 香叶 | 3–4 片 | |
| 草果 | 1 颗（拍裂） | 去腥增香 |
| 花椒 | 1 小勺约 3g | 可调 |
| 干辣椒 | 3–5 根 | 依口味 |
| 生姜 | 3–4 片 | |
| 葱 | 2 段 | |

调味料：生抽 4 汤匙、老抽 1 汤匙（上色）、盐 1–1.5 汤匙（依口味）、冰糖 1 小块（提鲜平衡）。糖色为可选项，炒至枣红立即下汤，过火则苦。

## 二、分食材焯水与卤制时间

| 食材 | 是否焯水 | 卤制时间 | 关火浸泡 |
|---|---|---|---|
| 鸡爪 | 是 | 12–15 分钟 | 10 分钟 |
| 鸭脖/鸭翅 | 是 | 25–30 分钟 | 15 分钟 |
| 鸡蛋（熟） | 否（先煮熟） | 8–10 分钟 | 30 分钟以上更入味 |
| 豆干 | 否 | 6–8 分钟 | 20 分钟 |
| 牛腱 | 是 | 50–70 分钟 | 30 分钟 |
| 五花肉 | 是 | 35–45 分钟 | 20 分钟 |

注：时间指小火微沸状态，非大火滚煮；浸泡是入味关键，不可省。

## 三、卤水养护三步法

1. 过滤：每次用完趁热用细筛滤除残渣。
2. 煮沸：滤后烧开 1–2 分钟杀菌，撇去浮油（留薄油可，厚油易酸）。
3. 冷藏：晾凉后密封冷藏，容器标注「使用次数」。建议同一锅卤水使用 ≤3 次，每次补适量水、盐、香料。

## 四、变质判定（出现任一即整锅废弃）

| 信号 | 说明 |
|---|---|
| 酸馊味 | 已产酸，不可再用 |
| 表面发黏拉丝 | 杂菌滋生 |
| 静置冒泡产气 | 已发酵腐败 |
| 颜色异常发灰绿 | 污染 |

## 五、常见不合格项与原因

| 现象 | 为什么不合格 | 处理 |
|---|---|---|
| 肉类未焯水直接卤 | 血沫腥味重、卤水易浑 | 先焯水去沫 |
| 卤水常温过夜 | 夏季数小时即酸败 | 必须煮沸后冷藏 |
| 使用超 3 次不补料 | 风味寡淡、杂菌积累 | 弃或补料限次 |
| 卤水发酸仍继续用 | 食品安全风险 | 整锅废弃 |
| 糖色炒过火 | 整锅发苦 | 重炒或减糖色 |
