# 卤味制作

## 1. 硬边界表

| 能做 | 不能做 |
|---|---|
| 给出基础卤料配比与用量 | 替代你对食材新鲜度的判断 |
| 给出分食材的卤制时间区间 | 判断商业卤味添加剂是否合规 |
| 给卤水过滤/煮沸/冷藏保存步骤 | 承诺长期反复使用绝对安全 |
| 提示卤水变质信号 | 处理食物中毒等医疗事件 |

必须转交专业人士：出现食物中毒症状（呕吐、腹泻、发热）立即就医；对食品合规有监管要求请咨询当地市场监管部门。

## 3. 完整工作流

1. 备料：食材焯水去血沫（肉类必做）。
2. 炒糖色或直接用酱油上色（可选）。
3. 卤料装袋，加水与调味料烧开成卤汤。
4. 下食材，按 `rules/braised-rules.md` 的时间卤制。
5. 关火浸泡入味（素菜短、荤菜长）。
6. 卤水过滤、煮沸、晾凉冷藏保存，记录使用次数。
7. 对照人工确认清单核对后再食用或保存。

## 4. 核心规则

生成任何配方或判断前先读 `rules/braised-rules.md`：含基础卤料配比表、分食材焯水与卤制时间、卤水养护三步法、以及变质判定的硬性信号。

## 5. 脚本用法

```
python scripts/check.py --file 你的卤制记录.json
python scripts/check.py --selftest
```

`--file` 传入 JSON（食材、卤制分钟、是否焯水、卤水已用次数、保存方式等）；`--selftest` 跑内置自检。

## 6. 人工确认清单

- [ ] 肉类是否先焯水去血沫
- [ ] 卤制时间是否在分食材区间内
- [ ] 卤水使用后是否过滤+煮沸
- [ ] 卤水冷藏且标注使用次数（建议 ≤3 次）
- [ ] 有无酸馊/发黏/产气等变质信号

## 7. 最常见的坑

1. 不焯水直接卤，血沫腥味重、卤水易浑。
2. 卤制时间一刀切：鸡爪 15 分钟、牛腱 60 分钟，错配导致夹生或过烂。
3. 卤水常温过夜，夏季几小时即产酸变质。
4. 反复使用不煮沸不过滤，杂菌积累、风味劣化。
5. 卤水发酸后舍不得扔，继续卤导致食品安全风险。
6. 糖色炒过头发苦，整锅报废。
7. 素菜与荤菜同锅久卤，串味且素菜过咸。

## 8. 边界与免责

本技能提供家常做法参考，不保证风味与绝对安全。食材新鲜度、环境温度是关键变量。卤水一旦出现酸馊、发黏、产气，应整锅废弃，切勿侥幸。
