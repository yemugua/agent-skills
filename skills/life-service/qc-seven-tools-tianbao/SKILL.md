# QC 七大手法（qc-seven-tools）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据质量管理老七种工具方法，生成 QC 七大手法应用清单：检查表、层别法、柏拉图、因果图、散布图、直方图、控制图的数据收集、分析与过程监控。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- QC七大手法
- 质量管理工具
- 柏拉图
- 鱼骨图
- 因果图
- 直方图
- 控制图

## 三、工作流
1. 覆盖七大手法（检查表/层别/柏拉图/因果图/散布图/直方图/控制图）
2. 数据收集（检查表/层别法）
3. 原因分析（因果图/柏拉图）
4. 过程监控（控制图/直方图）
5. 落到具体改进场景

## 四、核心内容（检查清单与判定）
QC 七大手法是现场质量改进的经典工具集；检查表与层别法用于收集数据，柏拉图与因果图用于分析原因，控制图与直方图用于过程监控。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未覆盖七大手法（检查表/层别/柏拉图/因果图/散布图/直方图/控制图） | 手法 |
| Q2 | WARN | 未含数据收集方法（检查表/层别法） | 数据 |
| Q3 | FAIL | 未含原因分析工具（因果图/柏拉图） | 分析 |
| Q4 | WARN | 未含过程监控工具（控制图/直方图） | 监控 |
| Q5 | FAIL | 未含应用场景（现场改进/课题） | 应用 |

> 脚本 `qc-seven-tools_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python qc-seven-tools_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python qc-seven-tools_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
