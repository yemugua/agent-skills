# 合同条款审查要点与高风险条款识别

> 合同的成立、效力、条款解释与违约责任由**现行民事法律规定与司法解释**确定，个案处理还取决于合同性质、交易背景与证据。**以现行法律规定和争议处理机构的认定为准**，本文件只给审查方法论与通行口径，不引用具体条款号。

## 一、审查顺序：先主体，后条款，最后才是措辞

| 顺序 | 审什么 | 为什么先审这个 |
|---|---|---|
| 1 | **主体资格** | 主体不适格，条款写得再漂亮也可能无效或无法执行 |
| 2 | **标的与权利义务** | 标的不确定，合同可能不成立 |
| 3 | **价款与支付** | 钱怎么算、什么时候付，是纠纷第一高发区 |
| 4 | **履行期限、地点、方式** | 判断谁违约的基准 |
| 5 | **违约责任与救济** | 出事了能不能拿到钱 |
| 6 | **争议解决与送达** | 打赢了能不能执行到位 |

**不要一上来就抠措辞。** 见过太多合同写了二十页违约责任，却没写清楚交付时间——违约根本无从判断。

## 二、必备条款清单（缺一项就留隐患）

| # | 条款 | 缺失后果 |
|---|---|---|
| 1 | 当事人的姓名或者名称、住所 | 主体不明，起诉时连被告都列不清 |
| 2 | 标的 | 合同可能不成立 |
| 3 | 数量 | 无法判断履行是否完全 |
| 4 | 质量 | 验收标准缺失，扯皮 |
| 5 | 价款或者报酬 | 计费依据缺失 |
| 6 | 履行期限、地点和方式 | 无法判断逾期与违约 |
| 7 | 违约责任 | 救济路径不清，维权成本高 |
| 8 | 解决争议的方法 | 管辖不明，增加诉讼成本 |

补充建议必备（不是法定必备，但强烈建议有）：

| 条款 | 作用 |
|---|---|
| 通知与送达条款 | 明确通知方式与送达地址，避免"没收到"抗辩 |
| 变更与解除条款 | 约定什么情形可以解除、怎么通知 |
| 不可抗力条款 | 明确范围、通知义务与后果 |
| 保密条款 | 保护商业秘密与交易信息 |
| 知识产权归属 | 委托开发、定制交付的成果归谁 |
| 验收条款 | 验收期限、验收标准、逾期未验收视为通过的约定 |
| 管辖与法律适用 | 选择对己方便利且有执行力的争议解决方式 |

## 三、主体资格审查

| 审查项 | 怎么做 |
|---|---|
| 自然人 | 姓名与身份证一致；是否具备相应民事行为能力；是否为限制行为能力人 |
| 法人 / 非法人组织 | 名称与登记一致；是否存续（未被注销或吊销）；是否超经营范围（一般不影响合同效力，但特许经营除外） |
| 签约人权限 | 法定代表人、负责人，或持有**授权委托书**的代理人；核对授权范围与期限 |
| 印章 | 公章 / 合同专用章；财务专用章、部门章一般不用于对外签约 |
| 特殊资质 | 建筑、医疗、食品、金融、教育等行业需相应许可或资质 |

## 四、高风险条款识别表（见到就标红）

| 风险条款 | 典型表述 | 风险 |
|---|---|---|
| **单方变更权** | 「甲方有权随时调整价格/服务内容，乙方不得异议」 | 对价失衡，己方履约成本不可控 |
| **无限免责** | 「因任何原因造成的损失，甲方概不负责」 | 可能被认定为不合理的免责条款而无效，但同时会诱导对方轻率履约 |
| **加重对方责任** | 「乙方违约应支付合同总额 200% 的违约金」 | 过分高于损失的，可被请求调减；不合理加重对方责任的格式条款可能无效 |
| **排除对方主要权利** | 「乙方不得就质量问题主张任何权利」 | 格式条款中此类约定可能无效 |
| **自动续约** | 「期满未提出异议的，自动续期一年」 | 被动续期，退出成本高 |
| **单方指定管辖** | 「由甲方所在地法院管辖」 | 增加己方诉讼成本；约定管辖须符合法定条件 |
| **模糊验收** | 「验收合格后付款」，但不写验收标准与期限 | 付款被无限期拖延 |
| **背靠背付款** | 「甲方收到第三方款项后再支付给乙方」 | 第三方不付款的风险被转嫁给己方 |
| **无限连带责任** | 「乙方对甲方的一切债务承担连带责任」 | 责任范围不可控 |
| **口头变更** | 变更一律口头，无书面确认 | 举证困难 |
| **违约金与定金并用** | 同时约定违约金与定金 | 一般只能择一适用 |

## 五、格式条款特别审查

| 要点 | 说明 |
|---|---|
| 什么是格式条款 | 预先拟定、未与对方协商、重复使用的条款 |
| 提示说明义务 | 提供格式条款的一方应采取合理方式提示对方注意免除或者减轻其责任等与对方有重大利害关系的条款 |
| 无效情形 | 不合理地免除或者减轻其责任、加重对方责任、限制对方主要权利；排除对方主要权利 |
| 解释规则 | 对格式条款的理解发生争议的，通常作出**不利于提供格式条款一方**的解释 |
| 非格式条款优先 | 格式条款与非格式条款不一致的，通常采用非格式条款 |

**实务提示**：如果己方是提供格式条款的一方，把免责与限责条款**加粗、单独列明并要求对方签字确认**，是最有效的合规动作。

## 六、价款与支付条款审查

| 要点 | 审什么 |
|---|---|
| 计价方式 | 固定总价 / 单价 / 成本加成，口径是否封闭 |
| 含税与否 | 是否含税、税率、发票类型与开具时间 |
| 支付节点 | 是否与可验证的交付/验收节点挂钩，而不是与主观评价挂钩 |
| 逾期付款后果 | 是否约定逾期利息或违约金，起算点是否明确 |
| 结算与对账 | 是否约定对账期限与确认方式 |
| 价格调整 | 原材料大幅波动时能否调整，调整机制是否可操作 |

## 七、违约条款审查

| 要点 | 审什么 |
|---|---|
| 违约情形是否列举 | 只写「任何一方违约应承担违约责任」太笼统 |
| 违约金是否可操作 | 是固定金额还是按比例计算，计算基数是什么 |
| 是否过高 | 约定的违约金过分高于造成的损失的，可被请求适当减少 |
| 是否过低 | 低于损失的，可请求增加 |
| 违约金与定金 | 一般只能择一适用，不要同时主张 |
| 解除权 | 约定解除条件是否明确、通知方式是否可举证 |
| 继续履行 | 是否保留要求继续履行的权利 |

## 八、争议解决条款审查

| 类型 | 要点 |
|---|---|
| 诉讼管辖 | 约定的管辖法院须符合法定条件，约定不明确的按法定管辖处理 |
| 仲裁 | 必须有**明确有效的仲裁协议**：请求仲裁的意思表示、仲裁事项、选定的仲裁委员会；三者缺一可能导致仲裁协议无效 |
| 二选一 | 同时约定「可以诉讼也可以仲裁」的，仲裁协议可能被认定无效 |
| 送达地址 | 约定送达地址与"地址变更应书面通知"，能大幅降低送达成本 |

**仲裁条款写错是最贵的错误**：写「提交当地仲裁委员会仲裁」而没有选定明确的仲裁委员会，可能导致仲裁协议无效，最后还是得回法院。

## 九、否定词意识（防误伤）

| 表述 | 正确理解 |
|---|---|
| 「未提出异议」 | ≠ 认可，除非合同明确约定逾期不提异议视为认可 |
| 「未验收」 | ≠ 验收合格，除非有明确的视为验收通过条款 |
| 「已付款」 | ≠ 履行完毕，还要看交付与验收 |
| 「合同未解除」 | ≠ 不能主张违约，违约救济与解除是两个路径 |
| 「未书面变更」 | 口头变更在履约事实清楚时也可能被认定，但举证困难 |
| 「不可抗力」 | ≠ 任何意外事件，需符合不能预见、不能避免且不能克服的法定内涵 |

## 十、审查输出清单

- [ ] 主体资格与签约权限已核验
- [ ] 八项必备条款齐全
- [ ] 标的、数量、质量标准可验证
- [ ] 价款、税率、支付节点明确
- [ ] 履行期限、地点、方式明确
- [ ] 验收标准与验收期限明确
- [ ] 违约情形列举清楚，违约金可计算
- [ ] 未同时约定违约金与定金
- [ ] 争议解决条款明确有效（仲裁三要素齐全）
- [ ] 通知与送达条款明确
- [ ] 高风险条款已逐条标注并给出修改建议
- [ ] 格式条款已履行提示说明义务
