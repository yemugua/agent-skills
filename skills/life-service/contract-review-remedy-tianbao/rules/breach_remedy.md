# 违约认定、救济路径与赔偿口径

> 违约责任的构成、救济方式与赔偿范围由**现行民事法律规定与司法解释**确定，个案还取决于合同约定、履约事实与证据。**以现行法律规定与争议处理机构的认定为准**，本文件只给通行口径与操作路径，不引用具体条款号。

## 一、先判断：到底有没有违约

| 判断步骤 | 内容 |
|---|---|
| 1. 义务是否存在 | 合同明确约定，或依法律规定、交易习惯、诚信原则产生 |
| 2. 义务是否到期 | 履行期限是否届至；有先履行抗辩、同时履行抗辩的另论 |
| 3. 是否未履行或履行不符 | 完全不履行、迟延履行、不完全履行（质量、数量、方式不符） |
| 4. 有无免责事由 | 不可抗力、债权人原因、约定的免责情形 |
| 5. 有无正当抗辩 | 同时履行抗辩、先履行抗辩、不安抗辩 |

**没有到期义务就没有违约。** 很多"对方违约了"的主张，其实是履行期限还没届至或付款条件未成就。

## 二、违约形态与对应救济

| 形态 | 表现 | 可用救济 |
|---|---|---|
| **拒绝履行** | 明确表示或以行为表明不履行 | 履行期届满前可主张预期违约的责任；要求继续履行、赔偿损失 |
| **迟延履行** | 逾期交付、逾期付款 | 要求履行 + 逾期违约金/利息；经催告后在合理期限内仍未履行的可解除 |
| **不完全履行** | 质量不符、数量不足、方式错误 | 要求修理、更换、重作、退货、减少价款或者报酬 |
| **履行不能** | 事实上或法律上无法履行 | 解除合同 + 赔偿损失 |
| **预期违约** | 履行期届满前明确表示不履行 | 可在履行期届满前主张违约责任 |

## 三、五种救济方式，别只会要钱

| 救济 | 适用 | 实务提示 |
|---|---|---|
| **继续履行** | 仍有履行可能且债权人要求 | 金钱债务一般可要求继续履行；非金钱债务有法定例外 |
| **采取补救措施** | 质量不符 | 修理、更换、重作、退货、减价 |
| **赔偿损失** | 有实际损失 | 需证明损失与因果关系 |
| **支付违约金** | 合同有约定 | 过高或过低可请求调整 |
| **定金罚则** | 合同有定金约定且已实际交付 | 与违约金一般择一适用 |

**选择救济方式前先想清楚自己要什么**：要货、要钱，还是要解除关系脱身。三种目标的举证重点完全不同。

## 四、违约金调整（高频争议点）

| 情形 | 通行口径 |
|---|---|
| 约定违约金**过分高于**造成的损失 | 可以请求人民法院或者仲裁机构予以**适当减少** |
| 约定违约金**低于**造成的损失 | 可以请求**予以增加** |
| "过分高于"的通行参照 | 司法实践中常以**超过造成损失的 30%** 作为判断过分高于的参考口径 |
| 迟延履行违约金 | 支付违约金后，仍应履行债务 |
| 调整程序 | 由当事人提出请求，一般不主动调整 |

**关键三点：**

1. **以"实际损失"为基准**，不是以合同金额或对方获利为基准
2. **30% 是通行参照口径，不是硬性公式**，个案会综合合同履行程度、过错程度、预期利益等因素
3. **要主动提出请求**，并举证证明实际损失，否则难以获得支持

## 五、定金规则

| 规则 | 口径 |
|---|---|
| 成立 | 定金合同自**实际交付定金**时成立（约定了不交不成立） |
| 数额上限 | 定金数额由当事人约定，但**不得超过主合同标的额的 20%**，超过部分不产生定金的效力 |
| 罚则 | 给付定金一方不履行债务的，**无权请求返还**；收受一方不履行债务的，应当**双倍返还** |
| 与违约金的关系 | 既约定违约金又约定定金的，一方违约时，对方**可以选择适用**违约金或者定金条款 |
| 与损失赔偿的关系 | 定金不足以弥补一方违约造成的损失的，对方可以请求赔偿超过定金数额的损失 |

**超过 20% 的部分不是"定金"，但可能作为预付款处理**，不适用定金罚则。这一点在起草和主张时都要分清。

## 六、损失赔偿范围

| 规则 | 说明 |
|---|---|
| 完全赔偿 | 损失赔偿额应当相当于因违约造成的损失，包括合同履行后可以获得的利益 |
| **可预见规则** | 不得超过违约一方订立合同时预见到或者应当预见到的因违约可能造成的损失 |
| **减损规则** | 一方违约后，对方应当采取适当措施防止损失扩大；未采取措施致使损失扩大的，不得就扩大的损失请求赔偿 |
| **与有过失** | 对方对损失的发生也有过错的，可以减轻相应的赔偿责任 |
| 举证责任 | 主张损失的一方需证明损失的存在、数额与因果关系 |

**减损规则是最容易被忽略的一条**：对方违约后自己放任损失扩大，扩大部分拿不到赔偿。

## 七、解除合同的路径

| 路径 | 条件 | 操作 |
|---|---|---|
| **约定解除** | 合同约定的解除条件成就 | 按约定方式通知，通知到达时解除 |
| **法定解除** | 因不可抗力致使不能实现合同目的；拒绝履行；迟延履行经催告后合理期限内仍未履行；迟延履行或其他违约行为致使不能实现合同目的等 | 通知解除，或起诉/仲裁主张解除 |
| **协议解除** | 双方协商一致 | 签解除协议，写清后续安排 |

**解除必须通知。** 以为"对方违约了合同就自动解除"是常见误解——不通知，合同还挂着，己方还可能反过来被主张违约。

## 八、证据清单（决定了能不能拿到钱）

| 类别 | 具体材料 |
|---|---|
| 合同本身 | 合同文本、附件、补充协议、订单、报价单 |
| 履行证据 | 交付凭证、物流单、验收单、对账单、付款凭证、发票 |
| 沟通记录 | 邮件、即时通讯记录、函件、会议纪要（**保留原始载体**） |
| 违约证据 | 催告函及送达凭证、照片视频、检测报告、第三方鉴定 |
| 损失证据 | 差价凭证、替代交易凭证、停工损失、仓储费用、维权费用 |
| 主体证据 | 营业执照、授权委托书、身份证明 |

**催告函要留送达凭证。** 口头催告在诉讼中很难证明，EMS 寄送 + 签收回执是最低成本的可靠做法。

## 九、时效与期间

| 事项 | 通行口径 |
|---|---|
| 普通诉讼时效 | 一般为 **3 年**，自权利人知道或者应当知道权利受到损害以及义务人之日起计算 |
| 最长保护期 | 自权利受到损害之日起超过 **20 年**的，人民法院不予保护（特殊情况可申请延长） |
| 时效中断 | 权利人向义务人提出履行请求、提起诉讼或者申请仲裁等，时效中断，重新计算 |
| 分期履行 | 同一债务分期履行的，诉讼时效期间自最后一期履行期限届满之日起计算 |
| 解除权行使期间 | 法律规定或者当事人约定解除权行使期限，期限届满当事人不行使的，该权利消灭 |

**时效不是"过期就没救了"，但会变成对方的抗辩。** 期间内主张一次权利并留痕，就能中断时效。

## 十、常见坑

**坑一：没写违约情形，只写"违约应承担责任"。**
无法判断什么叫违约，主张时对方一句"我没违约"就能拖很久。

**坑二：违约金写得越高越好。**
过分高于损失的部分会被调减，写了也拿不到，还可能被认定不合理加重责任。

**坑三：违约金和定金一起主张。**
一般只能择一适用，主张两项会被驳回一项。

**坑四：定金超过标的额 20% 还按定金罚则算。**
超过部分不产生定金效力，只能按预付款或损失处理。

**坑五：对方违约后自己放任损失扩大。**
扩大部分拿不到赔偿，因为违反了减损义务。

**坑六：以为对方违约合同就自动解除。**
不通知不解除，白白错过止损窗口，还可能反过来被主张违约。

**坑七：仲裁条款没选定明确的仲裁委员会。**
可能导致仲裁协议无效，最后还是回法院，白花时间。

**坑八：催告只打电话不留痕。**
无法证明催告过，迟延履行解除的条件就成就不了。

**坑九：只保存聊天截图不保存原始记录。**
截图证明力弱，原始载体与公证/时间戳才是可靠做法。

**坑十：拖过诉讼时效。**
3 年时间看着长，一忙起来就过了，且时效抗辩一旦提出，实体权利就无法通过法院强制实现。

## 十一、救济决策路径

```
确认义务到期 → 固定违约证据 → 发书面催告并留送达凭证
    → 判断己方目标：要履行 / 要赔偿 / 要解除
        → 要履行：催告 + 要求继续履行 + 主张逾期违约金
        → 要赔偿：固定损失证据 + 主张违约金或损失赔偿（择一或按约定）
        → 要解除：催告 → 合理期限届满仍未履行 → 发解除通知 → 主张恢复原状与赔偿
```
