# 内审规则库（audit_rules）

> 本文件是 qms-internal-audit 技能的规则支撑。条款以 ISO 9001 现行版本为准。

## 一、法规依据速查

| 文件 | 关键要求 | 关联 |
|---|---|---|
| ISO 9001 | 9.2 内部审核：按策划间隔开展，定义准则范围，审核员独立 | 内审义务来源 |
| 单位体系文件 | 内审程序、审核员任职条件 | 执行口径 |

## 二、审核方案覆盖判定口径

| 覆盖维度 | 要求 | 脚本判定 |
|---|---|---|
| 条款/过程 | 一个周期全覆盖 | 未覆盖条款 FAIL |
| 部门 | 每部门 ≥1 次 | 未覆盖部门 FAIL |
| 班次/场所 | 全部覆盖 | 未覆盖 WARN |
| 独立性 | 审核员不审本岗 | 违规 FAIL |
| 时间分布 | 按月/季度滚动 | 集中年底 WARN |

## 三、检查表设计要点

- 按过程组织，不按条款堆砌
- 每过程覆盖 PDCA 四问
- 记录抽样 ≥3~5 份，现场观察 ≥2 点
- 每题配"客观证据"栏
- 封闭确认 + 开放追问搭配

## 四、不符合分级口径

| 分级 | 情形 |
|---|---|
| 严重 | 体系性失效、区域性失效、后果严重 |
| 一般 | 单项未满足，未构成体系失效 |
| 观察项 | 有风险不构成不符合 |

描述四要素：条款 + 客观事实（时间/地点/文件编号/现象）+ 判定理由 + 类型。

## 五、报告与整改

报告要素：目的/范围/准则、审核组、发现汇总、有效性评价、不符合分布、结论建议。
整改验证：原因 → 措施 → 效果验证 → 标准化；管理者代表确认闭环。

## 六、常见不合规情形

- 审核员审自己工作
- 检查表照抄标准
- 不符合只写现象无条款
- 整改补记录不触根因
- 审核结论与管理评审输入脱节
