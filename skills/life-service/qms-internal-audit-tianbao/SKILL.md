# 质量管理体系内部审核（qms-internal-audit）

内审是体系的"自检程序"：**审核方案覆盖不全、检查表照抄标准、不符合开成现象描述**，内审就变成了编资料。

这个技能做四件事：**编方案** → **写检查表** → **开不符合** → **报结果**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 讲解内审流程与方法 | ❌ 替代认证机构审核结论 |
| 生成审核方案、检查表与报告模板 | ❌ 保证体系有效性 |
| 整理不符合分级与整改验证口径 | ❌ 出具认证决定 |

**内审员不得审核自己的工作**——审核独立性是底线。

**永远不要**为了让外审好看而"设计"不符合项的数量和措辞；内审的价值在暴露问题，不在表演合规。

## 二、完整工作流

```
第 1 步  明确场景：编年度方案 / 单次审核准备 / 开具不符合 / 写报告 / 迎外审
第 2 步  读规则文件 rules/audit_rules.md
第 3 步  按场景取用：
    - 编方案 → 覆盖原则（第三节）
    - 写检查表 → 设计方法（第四节）
    - 开不符合 → 分级与描述（第五节）
    - 报结果 → 报告要素（第六节）
    - 体检表 → python scripts/audit_plan_check.py --file 审核方案.json
第 4 步  按 templates/内审检查表.md 输出
第 5 步  人工确认：独立性、抽样代表性、证据链
```

## 三、年度审核方案覆盖原则

1. **全部过程覆盖**：一个审核周期内覆盖标准所有条款和单位所有过程
2. **全部部门覆盖**：每个部门至少被审一次
3. **全部班次/场所覆盖**：多班制、多场所的都要覆盖
4. **高风险优先**：上年外审问题、过程绩效差、重大变更的过程加密审核
5. **审核员独立性**：不得审自己工作；必要时聘请外部专家
6. **时间分布**：按月/季度滚动排期，不要年底一次性突击

## 四、检查表设计方法

| 设计要点 | 说明 |
|---|---|
| 按过程而非按条款编 | 一个过程一张表（如采购、设计开发），避免"一张表审所有部门" |
| 覆盖 PDCA | 每过程问：目标是什么（P）、怎么做（D）、做得怎样（C）、怎么改（A） |
| 抽样本 | 记录抽样 ≥ 3~5 份/过程；现场观察 ≥ 2 个作业点 |
| 问题类型搭配 | 封闭式确认 + 开放式追问（"给我看…""如果…怎么办"） |
| 留证据栏 | 每个问题对应"客观证据"栏，空着的问题等于没审 |

---

## 五、不符合开具与分级

**描述四要素**：标准条款 + 客观事实（时间、地点、文件编号、现象）+ 判定理由 + 不符合类型。

| 分级 | 情形 |
|---|---|
| 严重不符合 | 体系性失效（如过程缺失）、区域性失效、后果严重 |
| 一般不符合 | 单项要求未满足，未构成体系失效 |
| 观察项/改进建议 | 不构成不符合，但有风险 |

> 常见错法：只写"记录不完整"不写清哪份记录缺什么；把整改建议写进不符合描述；对人对事不对体系。

---

## 六、报告与整改验证

**报告要素**：审核目的/范围/准则、审核组、审核发现汇总（符合/不符合/观察项）、体系有效性评价、不符合分布分析、结论与建议。

**整改验证**：原因分析 → 纠正措施 → 效果验证（时间窗口）→ 标准化；内审员跟踪闭环，管理者代表确认。

---

## 七、脚本用法（审核方案体检）

```bash
python scripts/audit_plan_check.py --file "D:\质量\审核方案.json"
```

脚本检查四类问题：**条款/过程覆盖缺口、部门覆盖缺口、独立性违规、不符合无闭环**。

> ⚠️ 脚本只做结构与逻辑检查，**不判定审核质量**。

---

## 八、人工确认（这步不能省）

- [ ] 审核员是否具备能力且独立
- [ ] 抽样是否覆盖高风险过程与变更区域
- [ ] 客观证据是否充分（记录编号、现场照片）
- [ ] 不符合描述是否事实清楚、条款准确
- [ ] 整改措施是否触及根因而非就事论事
- [ ] 审核结论是否与管理评审输入衔接

---

## 九、输出结构（固定三段）

1. **体系什么状态**——结论先行：运行有效 / 有缺口 / 有系统性问题
2. **审核发现**——按条款/过程汇总
3. **改进优先级**——先系统、后局部；先高风险、后一般

## 十、最常见的坑

**坑一：方案年底突击。** 十二个月的内审压在两周做完，抽样全靠编。

**坑二：检查表抄标准。** 把 ISO 条款抄成问题，不结合本单位过程。

**坑三：不符合写现象。** "记录填写不完整"——哪份记录、缺什么、违反哪条，全没有。

**坑四：自己审自己。** 生产经理审生产过程，发现问题也轻轻放下。

**坑五：整改就事论事。** 补份记录结案，不分析为什么漏，明年照样漏。
