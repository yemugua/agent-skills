# 常见体检指标参考区间与分级

## 使用原则（三条，必须遵守）

1. **参考区间以报告为准**。报告每页都会印本单位参考区间，脚本优先取报告自带区间；报告没写的才回退到内置表，并在输出里显式标注「内置兜底区间，以报告/医院为准」。
2. **内置区间只做兜底**，不同实验室、年龄、性别会有差异，且存在「参考区间本身很宽、但你的值已经偏离趋势」的情况。
3. **不诊断**。本表只做「偏高/偏低/临界/正常」四档标记和「需就医」提示，不给出疾病结论。

## 四档分级定义

| 档位 | 判定规则 | 处理建议 |
|---|---|---|
| 正常 | 结果在区间内 | 保持；进入趋势跟踪 |
| 临界偏高/偏低 | 超出区间 ≤10%（对区间上限/下限算） | 3–6 个月后复查，先生活方式干预 |
| 偏高/偏低 | 超出 >10% 且 <2 倍 | 6 周–3 个月复查，带报告去门诊 |
| 明显异常 | 超出 ≥2 倍，或命中红旗项 | **尽快就医**（1–2 周内），不要等下次体检 |

## 红旗清单（命中任意一条，直接进「需尽快就医」，不参与普通复查节奏）

- 收缩压 ≥180 mmHg 或舒张压 ≥120 mmHg
- 空腹血糖 ≥11.1 mmol/L，或任意两次 ≥7.0
- LDL-C ≥4.9 mmol/L
- ALT 或 AST 超过上限 3 倍以上
- 肌酐超过上限 2 倍以上
- 尿蛋白阳性且合并尿糖阳性
- 血红蛋白低于下限 70%（重度贫血方向）
- 报告原页医生结论里明确写了「建议复查/建议专科就诊/建议进一步检查」

## 常见「假异常」（先排除，别自己吓自己）

| 现象 | 原因 |
|---|---|
| 转氨酶、CK、白细胞、血糖偏高 | 体检前熬夜、饮酒、剧烈运动、抽血前未空腹 |
| 血压偏高 | 诊室白大衣效应；连续三天同时段测更准 |
| 尿酸偏高 | 体检前海鲜/啤酒/火锅；也有先天代谢因素 |
| 血红蛋白偏低 | 女性生理期刚过、长期节食、缺铁 |
| 尿酮体阳性 | 空腹时间过长（很多人空腹 16 小时以上） |
| 参考区间看着「离谱」 | 不同医院单位不同（mmol/L vs mg/dL），务必按报告本页单位 |
| 单次数值异常 | 孤立异常常常复测即正常，看趋势不看单点 |
|  ALT 与 AST 都高 + GGT 高 | 脂肪肝常见组合，先做肝脏超声 |

## 年龄段常见漏检项（用于「建议补充检查」）

| 人群 | 常规项目之外建议补 |
|---|---|
| 30+ | 颈动脉超声、血脂细分、血糖（含糖化血红蛋白 HbA1c） |
| 40+ | 冠脉（体检或专科）、肺部 CT（吸烟/粉尘接触者）、肿瘤标志物（家族史相关）、骨密度 |
| 50+ | 胃肠镜（消化道筛查）、前列腺（男）、乳腺+甲状腺（女）、听力 |
| 60+ | 认知评估、跌倒风险评估、肌少症筛查、用药盘点 |

## 家庭档案要点

- 同一人跨年对比比单年更有意义：看主要指标年度变化方向。
- 家庭成员之间**不做直接对比**（性别、年龄、体重、用药差异大），只做同人纵向对比。
- 父母体检报告可为老人代做，注意：老人常多病共存、长期服药，异常项要看「比上次更差」还是「一直在」，长期服药者某些指标被药物影响（他汀降 LDL、降压药影响电解质等）。
