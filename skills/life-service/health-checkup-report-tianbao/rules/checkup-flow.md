# 体检全流程节点与高频坑

## 一、选套餐（体检前 1–2 周）

常见套餐三档，按需选，别默认买最贵的也别买最便宜的：

| 档 | 适合 | 关键项目 |
|---|---|---|
| 基础 | 20–30 岁、无明显家族史 | 血常规、肝肾功能、血糖、血脂、胸片、腹部超声 |
| 标准（多数人） | 30–50 岁 | + 甲状腺、心电图、幽门螺杆菌、颈动脉/脂肪肝相关 |
| 进阶 | 40+ / 有家族史 / 长期熬夜高压 | + 肺部 Ct、糖化血红蛋白、肿瘤标志物（按家族史选）、骨密度 |

**选前后必问四件事**（决定报告能不能用）：
1. 是否空腹几小时（一般 8–12 小时，前一晚 20:00 后禁食）；
2. 是否含女性专项（妇科、乳腺、甲状腺）与是否需避开经期；
3. 出报告要几天、能否拿纸质+电子两份（电子版便于长期建档）；
4. 异常项能否加做复查（有的机构送一次免费复检）。

## 二、体检当天（决定结果准不准）

- 前一晚别饮酒、别熬夜、别剧烈运动 —— 直接污染转氨酶、CK、白细胞、血糖。
- 空腹 8–12 小时即可，**别空腹超过 14 小时**，空腹太久尿酮体会阳性、血糖反而失真。
- 抽血前静坐 5–10 分钟再测血压。
- 女性避开经期（经期血红蛋白、尿常规不准）；经期已过 3 天以上更准。
- 长期服药者：降压药、降糖药、他汀一般不停（听医嘱），但提前问机构哪些药需停用。
- 有备孕/怀孕/哺乳：提前告知，很多项目（CT、部分超声、造影）需规避。

## 三、取报告后（本技能的主战场）

标准动作四步：

1. **先把参考区间对齐** —— 每页右上角/底部都有本页参考区间和单位，跨页可能不同（有的科室用 mmol/L、有的用 mg/dL）。
2. **逐项判四档**：正常 / 临界 / 偏高偏低 / 明显异常（见 indicators.md）。
3. **先找红旗** —— 有红旗项的先去医院，别排复查队。
4. **再排复查节奏**：临界 3–6 个月、轻度异常 6–8 周、稳定后并入年度。

**看报告的三个常见误读**：
- 「箭头↑就是有病」—— 单次 perturbation 常常是前一晚状态导致，看趋势不看单点。
- 「医院没写异常就没事」—— 有的机构只对超区间打印箭头，边缘值不标，需要自己比区间。
- 「去年的异常今年没了 = 好了」—— 可能只是今年没查同一项，或数值在临界晃动，要看项目是否一致。

## 四、拿结果去门诊（怎么问，效率差一倍）

挂号前先准备好四样：本次全套报告 + 往年报告（或至少异常项的往年值）+ 在服药品清单（含保健品）+ 症状时间线。

开口顺序（护士/医生都好接）：
「我这次体检 A、B 两项超了，去年也超了（值 X→Y），没有明显症状，想确认是复查还是用药。」

别问：「我这是啥病？」—— 问不出来的，医生需要检查。

## 五、年度节奏（可放进日程）

| 时点 | 事 |
|---|---|
| 每年 9–11 月 | 预约次年体检（套餐/机构有档期差） |
| 体检前 1 周 | 调整作息、停补品、问清空腹与经期避让 |
| 体检当天 | 空腹、先做需要空腹的项目、收好所有纸质单 |
| 出报告当天 | 建档（电子扫描/拍照存本地）+ 本技能跑一遍核验 |
| 有异常 | 按红旗/复查节奏排门诊；无异常则并入年度档案 |

## 六、高频坑清单（写进报告时注意）

- 只拍了异常页，没拍参考区间页 → 无法复核。
- 只有文字结论「轻度脂肪肝」，没有比值/分档 → ocols无法判定，需回机构要数据。
- 影像科结论（超声/CT）与检验科分开写，容易漏看影像里的「建议随访」。
- 体检机构与医院两个体系，体检异常一般指不出诊断，仍需医院复核。
- 电子报告上的「异常」标记可能只在 App 里显示，PDF 里没有，务必从 App 截图或导出。
- 老人代做：老人记忆里「去年体检没事」往往不准，尽量拿到去年纸质/电子件。
- 儿童参考区间与成人完全不同（儿童按年龄性别），别套成人表。
- 报告里的「建议」页常被忽略，那是体检机构法律意义上的记录，要留档。
