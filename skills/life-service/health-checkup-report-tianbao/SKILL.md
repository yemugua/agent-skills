# 体检报告解读与异常项自查

## 一句话

把体检报告从「一堆看不懂的箭头」变成「哪些要去医院、哪些 3 个月后再看、哪些不用管」，并且能跨年对比。

## 三步上手

1. 用 `templates/体检报告采集表.md` 把报告抄进来（贴原文也行，脚本自己抽；抄不准的留空即可）。
2. 跑一次核验：
   ```bash
   python scripts/checkup_review.py 我的体检报告.md --sex 男 --age 43 --json
   ```
   生成 `我的体检报告_核验报告.md`（与 JSON 结果同目录）。
3. 拿核验报告去门诊，同时把异常项填进 `templates/家庭健康档案年度跟踪表.md` 做跨年跟踪。

性别影响内置兜底区间（血红蛋白、肌酐、LDL、腰围男女不同），报告自带参考区间优先。

## 它做什么 / 不做什么

**做**：逐项比对参考区间 → 四档分级 → 标红旗 → 排复查时间 → 抽影像结论里的「建议」→ 建议补充检查 → 输出待办清单。

**不做**：不给疾病诊断；不替代医生；不联网、不上传任何原始报告；不缓存原文。所有判定都是「你这个值相对报告参考区间在哪一档」加上就医提示。

## 报告怎么读（四个要点）

1. **参考区间以报告为准**。每页区间可能不同（有的科室 mmol/L、有的 mg/dL），填不出区间时脚本用内置兜底表并显式标注「以医院为准」。
2. **四档**：正常 / 临界（超区间 ≤10%）/ 轻度偏高偏低（>10%–2 倍）/ 明显异常（≥2 倍）。
3. **红旗优先于档位**：命中红旗的一律进「需尽快就医」，不再按 3–6 个月排（血压 180+、血糖 7.0/11.1、LDL 4.9、转氨酶超上限 3 倍、肌酐超 2 倍、重度贫血、影像里写明「建议专科就诊」等）。
4. **一次异常别慌**：熬夜、饮酒、剧烈运动、空腹太久都会让转氨酶、CK、白细胞、血糖、尿酮体飘起来，看趋势不看单点。

## 隐私边界（必须遵守）

- 健康数据**只在本地脚本内解析**，不联网、不上传、不写外部服务。
- 输出默认落在本机；要给家人代做时用「父/母/儿/女」或 A1/A2 编号，**不写真实姓名、身份证号、手机号、病历号**。
- 涉及儿童和老人时**不套用成人参考区间**（儿童按年龄性别，常因慢性病或长期服药被放宽）。
- 脚本不留存原文，解析完即走。

## 文件

- `rules/indicators.md`：常见指标参考区间、四档定义、红清单、假异常清单、各年龄段漏检项。
- `rules/checkup-flow.md`：选套餐 → 体检当天 → 取报告 → 门诊怎么问 → 年度节奏 → 高频坑。
- `rules/privacy-and-quality.md`：隐私红线、报告质量六个坑、可信度分级、输出纪律。
- `templates/体检报告采集表.md`：输入模板。
- `templates/异常项复核表.md`：输出骨架。
- `templates/家庭健康档案年度跟踪表.md`：跨年跟踪（脱敏）。
- `scripts/checkup_review.py`：核验脚本（唯一可执行部分）。

## 硬边界

- 红旗提示是「尽快就医」，不是诊断结论。
- 未解析项进入「未解析项」列表，提示用户补全，**不猜值、不杜撰**。
- 单位存疑的项标「未参与判定」，交人工核对，不硬判。
- 缺失未做的项目只进「建议补充检查」，**不判异常**。
