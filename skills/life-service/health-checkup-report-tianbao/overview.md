# 体检报告解读与异常项自查

## 定位

同类工具大多停留在「把指标翻译成中文」，本技能多做一步：**核验**。

- 逐项比对报告自带参考区间，输出四档分级；
- 命中红旗的单独拎出来，明确「1–2 周内就医」；
- 复查建议必须带时间（3–6 个月 / 6–8 周 / 2 周内），不是「定期复查」这种废话；
- 抽影像结论里那句最容易被漏看的「建议复查/建议随访」；
- 跨年对比与家庭档案，让今年的报告能跟去年的比。

## 报告结构（脚本输出九段）

| 段 | 内容 |
|---|---|
| 一 | 结论摘要（一句话说清本次主要问题） |
| 二 | 红旗项（需尽快就医） |
| 三 | 明显异常（≥2 倍 / 需门诊） |
| 四 | 偏高 / 偏低（含可能原因、备注、复查时间） |
| 五 | 临界（≤10%） |
| 六 | 影像/检查结论里的「建议」 |
| 七 | 建议补充检查（按本次异常 + 年龄推导） |
| 八 | 下一步待办（带时间与状态） |
| 九 | 数据质量提示（未解析项、内置兜底区间、单位存疑） |

## 健康数据处理原则

1. 本地解析，不联网、不上传、不缓存原文；
2. 家庭档案脱敏（编号 / 称呼，不存身份号码）；
3. 儿童与老人不套成人区间；
4. 所有输出是「相对参考区间的档位 + 就医提示」，不是诊断。

## 适用与不适用

**适用**：年度体检报告、入职/入职前体检、父母代做的老人报告、入职体检超标需要复检、想搞懂报告上那些箭头。

**不适用**：疾病诊断、用药方案调整、影像学判读（CT/MRI 找病灶）、孕期检查、儿童专项生长评估——这些必须去医院。

## 与其他工具的分工

- 检验值**单位换算**、**趋势曲线**：医院 App 已有，本技能不重复做；
- 真正的诊断与治疗：门诊；
- 本技能只解决「报告拿回来看不懂、不知道先处理哪个、下次什么时候复查」这三件事。
