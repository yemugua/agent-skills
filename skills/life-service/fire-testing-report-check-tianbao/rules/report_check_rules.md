# 检测报告核查规则库（report_check_rules）

> 本文件是 fire-testing-report-check 技能的规则支撑。引用条款以现行有效文本为准。

## 一、法规依据速查

| 文件 | 关键要求 | 关联 |
|---|---|---|
| 《中华人民共和国消防法》 | 第十六条：按照国家标准、行业标准配置消防设施器材，定期组织检验、维修，确保完好有效 | 检测维保义务法源 |
| 《消防技术服务机构从业条件》（应急管理部，2019） | 机构从业条件：法人资格、场所设备、注册消防工程师与操作人员数量要求 | 机构核验依据 |
| 社会消防技术服务信息系统 | 机构基本信息公示与承诺 | 公示查询入口 |
| GB 25201-2010《建筑消防设施的维护管理》 | 建筑消防设施每年至少一次全面检测 | 周期红线依据 |
| XF 503《建筑消防设施检测技术规程》 | 检测项目与方法 | 项目覆盖参考 |

## 二、周期判定口径

| 事项 | 下限 | 脚本判定口径 |
|---|---|---|
| 建筑消防设施全面检测 | 每年至少一次 | 最近一次检测距今天数 ≤ 365 天 |
| 下次检测排期 | 间隔 ≤ 12 个月 | next_test_date − test_date ≤ 365 天 |
| 维护保养 | 合同约定 | monthly=true 视为月度维保 |

## 三、报告七要点检查口径

| # | 核查点 | 合格 | 不合格示例 |
|---|---|---|---|
| 1 | 机构名称与公示一致 | 系统可查 | 名称与公示不符、查不到 |
| 2 | 项目名称一致 | 楼宇楼层系统对得上 | 张冠李戴、范围不清 |
| 3 | 日期逻辑 | 报告日期 ≥ 检测日期 | 报告早于检测 |
| 4 | 项目覆盖 | 必备项全覆盖 | 缺消火栓/报警/喷淋等 |
| 5 | 结论一致 | 无未整改问题项 | "合格"但有问题未整改 |
| 6 | 整改闭环 | 问题有整改+复查 | 只列问题无整改 |
| 7 | 下次排期 | ≤ 12 个月 | 空置或超期 |

## 四、必备项目清单（按建筑类型）

- 高层公共建筑：消火栓系统、自动喷水灭火系统、火灾自动报警系统、防排烟系统、防火分隔设施、应急照明与疏散指示、消防电梯、消防电源、灭火器
- 人员密集场所：消火栓系统、自动喷水灭火系统（设自动设施的）、火灾自动报警系统、防排烟系统、防火分隔设施、应急照明与疏散指示、消防电源、灭火器
- 一般单位：消火栓系统、灭火器、应急照明与疏散指示；设自动消防设施的加火灾报警、喷淋
- 有燃气场所：以上 + 可燃气体报警装置

## 五、维保合同与记录核查口径

| 项目 | 核查点 |
|---|---|
| 合同主体 | 与报告机构一致，具备从业条件 |
| 维保频次 | 月度/季度写进合同，与记录对应 |
| 响应时限 | 故障响应时限写入合同（通行口径 ≤ 24 小时） |
| 报告义务 | 月报/季报约定，记录留存 |
| 人员 | 操作人员职业资格证书在有效期内 |

## 六、结论与问题项矛盾的处理

1. 结论为"合格"但存在未整改问题项 → 要求机构出具书面说明
2. 结论为"基本合格" → 按问题项逐条闭环，闭环前设施按"带病运行"管理
3. 结论为"不合格" → 立即制定整改计划，明确临时管控措施（加密巡查、限期停用风险部位）

## 七、现场抽查建议（验证报告可信度）

- 抽查 2-3 个"合格"项：消火栓静压/出水、应急灯放电、灭火器压力
- 核对问题项整改证据：更换记录、复测记录、影像
- 核对设施数量与台账一致（防止"账有实无"）
