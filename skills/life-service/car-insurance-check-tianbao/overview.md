# 概览：车险投保与理赔核查

## 解决什么问题

车主面临三个没人帮他算的问题：

1. **保单买得对不对**——只买交强险、三者买 50 万、漏了医保外用药，出事才知道；
2. **这次事故报不报保险**——报了明年涨价，不报自己掏钱，两边都怕吃亏；
3. **会不会被拒赔**——跑网约车按非营运投保、改装没告知、超 48 小时才报案，这些才是真正的拒赔根源。

本技能把三件事做成可计算的判断，而不是泛泛的科普。

## 输入 → 输出

```
采集表（车辆 / 保单 / 事故 / 拒赔自查 / 材料）
        │
        ▼
  ┌────────────────┐
  │ 保障缺口核查    │  交强险 / 车损 / 三者额度 / 座位 / 医保外用药
  ├────────────────┤
  │ 保费与 NCD      │  今年 vs 去年、过户与脱保的断点
  ├────────────────┤
  │ 报不报保险      │  维修费 vs 次年涨费估算（--ncd 可调）
  ├────────────────┤
  │ 拒赔风险扫描    │  酒驾 / 逃逸 / 营运 / 改装 / 超 48 小时
  ├────────────────┤
  │ 材料 + 步骤     │  先定损后修车、代位求偿、12378 投诉
  └────────────────┘
```

## 和其他工具的区别

| 现有工具 | 本技能 |
|---|---|
| 保费计算器 | 不算保费，算**缺口** |
| 车险科普文章 | 不做科普，做**个案判定** |
| 理赔流程说明 | 不做说明，给**这一步该干什么** |

## 三条硬规则

**2020 年 9 月车险综合改革后**，车损险已并入盗抢、涉水、自燃、玻璃、不计免赔、无法找到第三方——还在单卖这些的，是过时信息。

**NCD 三个断点**：过户不继承、脱保超 3 个月清零、出险一次回退。

**拒赔两个高发根源**：改变使用性质未告知（跑网约车）、超过 48 小时才报案。

## 不做的事

- 不推荐保险公司、不估算精确保费
- 不承诺理赔结果
- 不代拟法律文书、不代办理赔
- 用户没填的不猜

## 适用人群

私家车主、营运车主、刚出事故的人、续保前想核保单的人、二手车买家。
