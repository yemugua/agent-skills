# 出险处置卡（打印放车里）

## 一、现场 60 秒内

```
1. 熄火、开双闪、放三角牌（高速 150 米外）
2. 先看有没有人受伤 → 有人伤：120 + 122，不要搬动伤者
3. 拍照：全景（含标线）→ 相对位置 → 碰撞点特写 → 双方车牌
4. 保存行车记录仪视频（立刻，别被覆盖）
5. 交换：驾驶证、行驶证、联系方式、保单
```

## 二、要不要私了

| 条件 | 结论 |
|---|---|
| 有人伤（哪怕看起来轻微） | **不私了**，报 122 + 保险 |
| 无人员伤亡、责任清楚、损失小 | 可协商，但**必须留书面协议 + 转账凭证** |
| 对方酒驾 / 无证 / 逃逸嫌疑 | **不私了**，立即报警 |
| 对方态度好但说"别报保险，我赔你现金" | 谨慎：先拿到钱和书面凭证再挪车 |

**私了协议至少写清**：时间地点、双方车牌与证件号、事故经过、责任归属、赔偿金额、支付方式与时间、双方签字、注明"一次性了结"。

## 三、报案时限：48 小时

| 事项 | 时限 |
|---|---|
| 报保险公司 | **48 小时内**（多数公司要求） |
| 报交警 | 有人伤必须报 122；轻微事故可走快处快赔 |
| 提交材料 | 按保险公司通知，通常在修车与治疗结束后 |

超时报案可能被拒赔，**先打电话报案，材料后补**。

## 四、定损与修车顺序

```
报保险 → 查勘/定损 → 修车 → 交材料 → 领赔款
         ↑
    千万别先修后报：超出定损部分自己掏
```

## 五、对方全责却不赔

走**代位求偿**：向自己的保险公司申请先行赔付，由保险公司向对方追偿。

条件：己方车损险在保、己方非全责。是否计入出险次数，先问自己的保险公司。

## 六、材料速查

- [ ] 保险单（电子保单即可）
- [ ] 身份证、银行卡
- [ ] 行驶证、驾驶证
- [ ] 事故认定书
- [ ] 现场照片 / 记录仪视频
- [ ] 修车发票 + 维修清单
- [ ] 对方修车发票、物损凭证
- [ ] 人伤：病历、诊断证明、医疗费票据、误工证明
