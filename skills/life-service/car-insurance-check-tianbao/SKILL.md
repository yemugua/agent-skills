# 车险投保与理赔核查

保单买得对不对、这次事故该不该报、会不会被拒赔——三件事一次算清。

## 什么时候用

- 续保前想知道保单有没有缺口、三者险够不够
- 出了事故，纠结要不要报保险（怕明年涨价）
- 担心被拒赔（酒驾、逃逸、跑网约车、改装未告知）
- 对方全责却不赔，想知道怎么办
- 理赔被拖、定损有争议

## 怎么做

**第 1 步**：复制 `templates/车险信息采集表.md` 填写。没有事故就把第三节整节约掉。

**第 2 步**：跑脚本

```bash
python scripts/insurance_check.py 采集表.md --base 2026-10-04 --out 核查报告.md
```

`--ncd 25` 可调整"一次出险导致次年保费回退百分比"的假设（默认 25%），用于第四节的算账。

**第 3 步**：按第八段"待办动作"执行。

## 核心判定规则

### 保障缺口

| 险种 | 判断 |
|---|---|
| 交强险 | 没买 = 不能上路、不能年检，扣车并处 2 倍保费罚款 |
| 车损险 | 2020 年改革后已含盗抢、涉水、自燃、玻璃、不计免赔，不用单买 |
| 三者险 | **低于 100 万提示偏低**；撞人撞豪车远超想象 |
| 座位险 | 常载人建议投保 |
| 医保外用药责任险 | 三者险不赔医保外用药，人伤事故缺口大，保费很低 |

### 报不报保险（第四节的算账）

```
次年可能上涨额 ≈ 上年商业险保费 × NCD 回退幅度（默认 25%，可 --ncd 调）

维修费 > 上涨额 → 报保险
维修费 < 上涨额 → 自费（一次出险会打破多年折扣，恢复要好几年）
有人伤       → 一律报保险并报警，绝不私了
```

**注意**：上涨额是估算，报告里明确标注了假设。真要做决定，打电话问业务员"出险一次次年涨多少"。

### 常见拒赔根源

1. 酒驾 / 醉驾 / 毒驾
2. 无证驾驶、吊销暂扣期间
3. 肇事逃逸
4. **改变使用性质未告知**（跑网约车按非营运投保）—— 近年高发
5. 改装未告知且增加危险程度
6. 超过 48 小时才报案

### NCD 三个断点

- **过户**：NCD 不继承，过户后按新投保，折扣归零
- **脱保超 3 个月**：连续投保记录中断，折扣清零
- **出险一次**：折扣回退，恢复要好几年

## 输入 / 输出

| | 内容 |
|---|---|
| 输入 | 采集表 Markdown（车辆 / 保单 / 事故 / 拒赔自查 / 材料） |
| 输出 | 九段报告：结论摘要 / 保障缺口 / 保费与 NCD / 报不报保险 / 拒赔扫描 / 材料 / 处置步骤 / 待办 / 纪律 |
| 退出码 | 0 正常；2 关键信息缺失（给提示串，不崩） |

## 边界与纪律

- **不内置保费率、不估算精确保费、不推荐保险公司**
- 次年涨费只在填了"上年商业险保费"时才估算，且明确标注假设系数
- 不承诺理赔结果；责任划分以交警认定为准，是否赔付以保险公司核定为准
- 不代拟法律文书、不代办理赔
