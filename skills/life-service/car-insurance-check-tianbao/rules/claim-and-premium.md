# 车险：理赔流程、拒赔情形与出险算账

## 一、出险后七步（顺序别乱）

| 步 | 做什么 | 时限 / 要点 |
|---|---|---|
| 1 | 先救人、再报警 | 有人伤**必须**报 122；私了前先确认伤情 |
| 2 | 报保险 | 多数公司要求 **48 小时内**报案，超时可能被拒赔 |
| 3 | 现场取证 | 拍全景（含道路标线）、碰撞点特写、双方车牌、驾驶证行驶证 |
| 4 | 等交警定责 | 拿《道路交通事故认定书》，这是理赔核心依据 |
| 5 | 定损 | 到保险公司指定点定损，争议可申请第三方评估 |
| 6 | 修车 | 先定损后修车，**先修后报**会被砍 |
| 7 | 交材料、领赔款 | 见下方材料表 |

**不要**：私了后无凭证、擅自离开现场、先修车再定损、口头承诺不报保险。

## 二、典型拒赔 / 免赔情形

| 情形 | 常见处理 |
|---|---|
| 酒驾、醉驾、毒驾 | **商业险拒赔**；交强险在限额内垫付后可追偿 |
| 无证驾驶、驾驶证被吊销/暂扣期间 | 商业险拒赔 |
| 肇事逃逸 | 商业险拒赔 |
| 故意制造事故 | 拒赔，且可能涉保险诈骗 |
| 车辆未按规定年检 | 存在争议：改革后条款多数不再把"未年检"直接列为免责，但**因车辆本身故障导致的事故**仍可能拒赔——以条款与交警认定为准 |
| 改变使用性质未告知（跑网约车） | 商业险可拒赔，这是近年高发 |
| 改装未告知（且增加危险程度） | 可拒赔 |
| 在竞赛、测试期间 | 拒赔 |
| 战争、核、政府征用等 | 免责 |

**一句话**：违法驾驶 + 车辆用途/危险程度变更未告知，是最常见的两个拒赔根源。

## 三、理赔材料清单

| 材料 | 说明 |
|---|---|
| 保险单（电子保单即可） | 必备 |
| 被保险人身份证、银行卡 | 赔款打款用 |
| 行驶证、驾驶证（驾驶人） | 必备 |
| 《道路交通事故认定书》 | 有责/无责、责任比例的依据 |
| 修车发票、维修清单 | 先定损后修车，发票抬头要对 |
| 第三方损失凭证 | 对方修车发票、物损照片、评估报告 |
| 人伤材料 | 病历、诊断证明、医疗费票据、误工证明、伤残鉴定 |
| 施救费票据 | 拖车费等合理施救费用可赔 |

## 四、要不要报保险：算一笔账

出险一次，次年 NCD 折扣回退，保费上涨。**维修费低于上涨额时，自费更划算。**

估算方法（用自己保单上的真实数字，不要套别人的）：

```
次年可能上涨额 ≈ 本年商业险保费 × NCD 回退幅度
决策：维修费 > 上涨额 + 免赔额 → 报保险
      维修费 < 上涨额 + 免赔额 → 自费
```

**经验区间**（仅供判断，以保单为准）：

| 维修费 | 一般建议 |
|---|---|
| < 500 元 | 自费，别报 |
| 500–2000 元 | 先问业务员次年涨多少，再决定 |
| > 2000 元 | 通常报保险划算 |
| 有人伤 | **一律报**，不要私了 |

**注意**：连续多年不出险积累的折扣一旦打破，恢复需要好几年——**小额事故宁可自费**是常见理性选择。

## 五、代位求偿：对方全责却不赔怎么办

己方**无责或次责**，对方拖延/失联/无保险时，可以向**自己的保险公司**申请代位求偿：

1. 自己的车损险在保；
2. 己方对事故不负全责；
3. 向自己的保险公司申请先行赔付，由保险公司向责任方追偿。

**代位求偿一般不算作出险次数**（按现行规则多数公司不计入 NCD），但**仍要先向自己的保险公司确认口径**。

## 六、定损争议怎么办

| 争议 | 处理 |
|---|---|
| 保险公司定损价低于实际维修费 | 要求复勘；协商不成可委托**第三方评估机构** |
| 指定修理厂 vs 4S 店 | 看条款是否约定"指定专修厂"，没约定的可自行选择并要求按实际费用赔 |
| 配件用副厂件 | 要求明示，协商不一致可投诉或诉讼 |
| 理赔拖延 | 《保险法》规定核定期间一般不超 30 日（情形复杂的除外），超时可投诉 12378 |

## 七、投诉渠道

| 渠道 | 用途 |
|---|---|
| 保险公司客服 / 投诉专线 | 第一步 |
| **12378**（银保监会消费者投诉热线） | 保险公司不处理或对处理结果不满 |
| 12315 | 消费争议 |
| 人民法院 / 仲裁 | 金额大、争议实质的 |

## 八、输出纪律

- 不推荐具体保险公司、不估算精确保费、不承诺理赔结果；
- 保费、折扣、NCD 系数一律用用户填写的数字做比较；
- 涉及责任划分、拒赔认定的，只给规则与材料准备，最终以交警认定与保险公司核定为准；
- 不代拟法律文书。
