# 车险：交强险与商业险，各自保什么

## 一、交强险：强制、不买不能上路

| 项 | 内容 |
|---|---|
| 性质 | **强制投保**，不买不能上路、不能年检 |
| 保谁 | 只赔**第三方**（对方的人、车、物），**不赔自己和自己的车** |
| 赔付上限 | 2020 年 9 月 19 日车险综合改革后：死亡伤残 **18 万**、医疗费用 **1.8 万**、财产损失 **0.2 万**（以保单载明为准） |
| 无责也赔 | 无责任时亦有分项限额（更低），以保单为准 |
| 不买上路 | 扣留车辆 + 处应缴保费 **2 倍**罚款，补办后才放行 |
| 脱保 | 脱保期间发生事故，全部费用自担；重新投保时**连续投保折扣清零** |

**关键认知**：交强险额度极低。撞了人重伤、撞了豪车，18 万 / 0.2 万远远不够，**差额全靠商业三者险**。

## 二、商业险：三个主险，够不够看这个

| 险种 | 保什么 | 建议 |
|---|---|---|
| **机动车损失险（车损）** | 自己的车（碰撞、倾覆、火灾、爆炸、外界物体坠落、自然灾害等） | 新车、贷款车、价值高的车**必买** |
| **第三者责任险（三者）** | 超出交强险的部分，赔给第三方 | **必买，且额度要够**：一线城市建议 200 万起，300 万不贵多少 |
| **车上人员责任险（座位险）** | 本车司机与乘客 | 经常带人的建议买；也可以用意外险替代 |

### 2020 年综合改革后，车损险已经打包了这些

改革后**主险车损险已并入**以下责任，不用再单买、也没法单买：

- 盗抢险（全车盗抢）
- 玻璃单独破碎险
- 自燃损失险
- 发动机涉水损失险
- 不计免赔率险
- 无法找到第三方特约险
- 指定修理厂险（部分公司）

**含义**：只要买了车损险，上面这些都在里面。还有人单独推荐"涉水险""不计免赔"的，是过时信息。

### 附加险：按需

| 附加险 | 什么时候值得买 |
|---|---|
| 医保外医疗费用责任险（三者） | **强烈建议**：三者险不赔医保外用药，这个补上缺口 |
| 车身划痕损失险 | 新车、常停路边、豪车 |
| 修理期间费用补偿险 | 只有一辆车、修车期间必须用车 |
| 绝对免赔额特约 | 想降保费且愿意自担小额 |
| 增值服务特约（道路救援等） | 常跑长途 |

## 三、保额怎么定：三者险别买低了

三者险额度的选择逻辑：

| 场景 | 风险量级 |
|---|---|
| 撞伤行人/骑车人，重伤或死亡 | 死亡赔偿金 + 医疗费 + 抚养费，一线城市可达 **150–300 万** |
| 撞到豪车 | 维修费几十万到上百万不稀奇 |
| 多车连环 | 总额叠加 |

**50 万三者在今天已经不够用**，100 万是底线，200 万是主流，300 万与 200 万的保费差通常只有几十到一百多元。

**判断方法**：三者保费随额度上涨极缓，**往上加一级几乎总是划算的**。

## 四、NCD：不出险才便宜

保费主要受**无赔款优待（NCD）**影响：

| 情况 | 影响 |
|---|---|
| 连续多年不出险 | 逐年下降，商业险最低可至基准的很低折扣（按现行规则） |
| 出险一次 | 次年折扣回退，涨幅常达数百至上千元 |
| 出险两次及以上 | 涨幅明显，可能被列为高风险 |
| 过户 | **NCD 不继承**，过户后按新投保处理，折扣归零 |
| 脱保超 3 个月 | 连续投保记录中断，折扣清零 |

**实务推论**：小额维修要不要报保险，取决于**维修费 vs 次年保费上涨额**（见 `rules/claim-and-premium.md` 的算账方法）。

## 五、几个必须核对的保单信息

| 项 | 为什么 |
|---|---|
| 被保险人 / 行驶证车主是否一致 | 不一致可能影响理赔款支付 |
| 车辆使用性质 | **非营运 / 营运**，跑网约车按非营运投保，出险可能被拒赔 |
| 厂牌型号、车架号、发动机号 | 录错会导致理赔时核不上 |
| 初次登记日期 | 影响车损险保额（按折旧后实际价值） |
| 保险期间 | 起保时刻精确到时分，别出现空档 |
| 特别约定 | 常有限制条款，逐条看 |

## 六、判定输出纪律

- 交强险分项限额以**保单载明**为准，脚本只在用户填写时展示，不硬编数字；
- 保费、折扣、NCD 系数**不内置**，一律由用户填写"上年保费"与"今年报价"后做比较；
- 不推荐具体保险公司、不代算精确保费；
- 各地交强险费率浮动方案（与交通违法挂钩的地区）以当地现行规定为准。
