# 充电桩使用与续航估算（ev-charging-usage）

「表显还剩 120 公里，实际跑 80 就不敢开了」——这不是电池不行，是**估算口径不同**。搞清楚电表读数和表显里程的区别，焦虑就少一半。

这个技能做四件事：**选桩** → **算续航** → **算时长** → **排故障**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 说明交直流充电的特性差异 | ❌ 承诺具体续航里程 |
| 给出续航估算口径与折损区间 | ❌ 承诺充电时长精确值 |
| 给出充电时长的估算方法 | ❌ 指导拆改充电设备或私接线路 |
| 列出常见故障的处置顺序 | ❌ 判断电池或电控系统故障 |
| 给出安全注意与错峰建议 | ❌ 给出费率、电价的具体数字 |

**费用、电价、计费方式以运营方现行规则与公示为准**，本技能不引用具体费率标准。安全要求以现行规定与运营方说明为准。

**遇到以下情况，停止自行处理并联系运营方或专业人员：**

- 充电过程中出现异味、冒烟、异常发热
- 充电枪或枪口有变形、破损、电缆破损
- 车辆报警提示电池或高压系统异常
- 雨天涉水后桩体异常
- 私有桩需要新增线路或改动配电

## 二、桩类型与特性

| 类型 | 原理 | 速度 | 适用场景 |
|---|---|---|---|
| 交流慢充 | 车载充电机整流，桩提供交流电 | 慢，通常数小时 | 夜间居家、长时间停放 |
| 直流快充 | 桩内直接整流输出直流 | 快，通常几十分钟到两小时 | 途中补能、公共桩 |

**快慢充的核心差异**：**直流快充的功率由桩提供，充电速度快；交流慢充的功率受车载充电机限制**，所以同一辆车在不同慢充桩上速度可能差很多。

**关于伤电池**：快充确实比慢充对电池的负担大，**但真正的决定因素是长期的高电量停留与长期的高温**。日常能用慢充就用慢充，偶尔快充补能不必过度担心。

---

## 三、续航估算的两种口径

**这是最容易被搞混的地方。**

| 口径 | 怎么来的 | 特点 |
|---|---|---|
| **表显里程** | 车辆按最近一段时间的实际消耗估算 | 会根据驾驶习惯、空调、路况动态调整，看起来贴近实际 |
| **电表读数折算** | 充进去多少度电，除以标称能耗 | 更稳定，不受近期驾驶影响 |

**为什么两者会差**：

- 表显是**估算值**，不是精确剩余电量
- 高速行驶、开空调、开暖风都会明显增加消耗
- 低温环境下电池可用容量会下降
- 长期满电停放后，表显与实际会有偏差
- 剩余电量较低时，表显通常偏保守

**折损口径（经验值，会因车型与路况变化）**：

| 场景 | 相对表显的折损方向 |
|---|---|
| 城市道路 | 接近表显 |
| 高速行驶 | 明显增加消耗 |
| 低速开暖风 | 明显增加消耗 |
| 低速开空调 | 略有增加 |
| 低温环境 | 可用容量下降，实际跑不到表显里程 |

**规划口径**：**按电表读数折算，并留出安全余量。** 目的地充电桩位置不确定时，按表显里程再打七折左右做规划更稳妥。

## 四、充电时长估算

**估算方法**：

```
充电时长 ≈ 需要补充的电量 ÷ 实际充电功率 + 爬坡与收尾时间
```

**关键点**：

- **需要补充的电量 = 目标电量 - 当前电量**，不要拿满容量去算
- **实际充电功率**要区分：直流快充看桩的额定功率，交流慢充看车辆和桩的较小值
- **充电后期功率会下降**，所以从 20% 充到 80% 通常比线性估算更久
- **收尾时间**通常比想象中长，尤其是高电量区间

**常见误区**：用「电池容量 ÷ 桩功率」直接算，忽略了起始电量、功率曲线和收尾，结果往往乐观。

## 五、常见故障处理

| 现象 | 可能原因 | 处置顺序 |
|---|---|---|
| 跳枪（充电中途断开） | 车辆达到目标电量、过热、桩端异常、线路不稳 | 先确认是否已达目标电量；反复跳枪联系运营方 |
| 枪拔不下来 | 锁止机构未释放 | **不要硬拉**；先在车辆端结束充电，等待锁止释放后再拔 |
| 启动失败 | 充电时车辆处于通电状态、电池低压 | 结束充电后再尝试；仍失败则检查车辆状态 |
| 无法开始充电 | 枪未插到位、账号或支付问题、桩离线 | 重新插枪、检查支付方式、换桩试试 |
| 充电特别慢 | 桩功率低、车辆限功率、电池温度低或高 | 确认桩的功率与车辆的充电上限 |
| 中途停止并报错 | 电池温度保护、桩端故障、车辆异常 | 记录报错信息，联系运营方与售后 |

**关于枪拔不下来再强调一次**：**不要硬拉。** 正确顺序是车辆端结束充电 → 等待锁止释放 → 再拔。硬拉可能损坏锁止机构。

## 六、费用与错峰

**计费方式**（以运营方公示为准）：常见有按时段分档、按充电时长、按充电量计费等几种方式，具体规则看运营方现行公示。

**错峰建议**：

| 时段 | 特点 |
|---|---|
| 工作日白天 | 车辆少，通常较空闲 |
| 夜间（住宅桩） | 谷电时段费用通常更低 |
| 节假日前后 | 出行高峰，公共桩排队概率高 |
| 晚高峰时段 | 通勤聚集，热门区域容易排队 |

**口径**：具体费率与分时段规则以运营方公示为准，本技能不给出具体数字。

---

## 七、安全注意

| 场景 | 注意 |
|---|---|
| 雨天 | 使用正规运营的充电设施，避免在积水与破损桩体附近充电 |
| 高温 | 避免车辆与电池在长时间暴晒后立即大功率充电 |
| 低温 | 充电前若电池温度过低，充电速度可能受限 |
| 长时间停放 | 避免长期处于极低电量或满电状态 |
| 异常情况 | 异味、冒烟、异常发热立即停止并远离，同时联系相关方 |

**安全要求以现行规定与运营方说明为准。** 私自改线、改桩、改配置都不在可自行处理的范围内。

## 八、脚本用法

```bash
python scripts/ev_charge_calc.py --pack 75 --current 25 --target 80 --power 60 --type ac
python scripts/ev_charge_calc.py --file plan.json --out 测算结果.md
python scripts/ev_charge_calc.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--pack` | 电池容量（千瓦时） |
| `--current` | 当前电量（百分比） |
| `--target` | 目标电量（百分比） |
| `--power` | 充电功率（千瓦） |
| `--type` | `ac`（交流慢充）或 `dc`（直流快充） |
| `--loss` | 规划折损系数，默认按 0.75 |
| `--file` | 从 JSON 读（自动兼容带 BOM 的文件） |
| `--out` | 结果落盘路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本输出**需要补充的电量、充电时长估算（含收尾余量）、按折损后的规划里程**，并给出对应场景的估算口径说明。

> 脚本只做算术估算，**不代表实际测量值**。实际充电功率受车辆、桩体与电池状态共同影响。

## 十、最常见的坑

**坑一：拿满容量除以充电功率算时长。**
忽略了起始电量和功率曲线，结果往往乐观。正确算法是用需要补充的电量。

**坑二：把表显里程当准确值。**
表显是估算值，会因近期驾驶习惯变化。按电表读数折算并留余量更稳。

**坑三：高速和暖风场景不做折损。**
这两种情况消耗明显增加，不折损就规划容易在半路没电。

**坑四：枪拔不下来就硬拉。**
先在车辆端结束充电，等锁止释放，硬拉可能损坏锁止机构。

**坑五：把跳枪一律当故障。**
达到目标电量也会跳枪，先确认是不是正常结束。

**坑六：交流慢充按桩的额定功率算速度。**
交流慢充的速度受车辆端充电机限制，看车辆与桩两者中较小的那个值。

**坑七：长期满电或长期极低电量停放。**
这两种状态对电池都不友好，尽量避免。

**坑八：雨天在积水或破损桩体附近充电。**
使用正规运营的充电设施，并注意周边环境状况。

**坑九：以为快充次数多就必然伤电池。**
真正影响更大的是长期高电量停留与高温。日常以慢充为主，快充用于途中补能即可。

**坑十：目的地充电桩位置不确定还不留余量。**
按折损后的规划里程来定，到不了就很难处理。
