# 充电桩使用与续航估算规则库

> 生成测算、给排查建议之前，先读这份文件，不要凭印象写。
> 费用与安全要求以运营方现行规则、公示和现行规定为准。

---

## 一、桩类型对比表

| 类型 | 原理 | 速度 | 适用场景 | 决定速度的因素 |
|---|---|---|---|---|
| 交流慢充 | 车载充电机整流，桩供交流 | 慢，通常数小时 | 夜间居家、长时间停放 | 车辆端充电机功率与桩的较小值 |
| 直流快充 | 桩内直接整流输出直流 | 快，通常几十分钟到两小时 | 途中补能、公共桩 | 桩的输出功率与车辆接受上限 |

**关于伤电池**：快充对电池的负担确实比慢充大，**但更关键的因素是长期高电量停留与长期高温**。日常以慢充为主、偶尔快充补能属正常用法。

---

## 二、续航估算的两种口径

| 口径 | 来源 | 特点 |
|---|---|---|
| 表显里程 | 车辆按近期实际消耗动态估算 | 会随驾驶习惯、空调、路况调整 |
| 电表读数折算 | 充入电量除以标称能耗 | 更稳定，不受近期驾驶影响 |

**两者差异的来源**：

- 表显是估算值，不是精确剩余电量
- 高速、开暖风明显增加消耗
- 低温下电池可用容量下降
- 长期满电停放后表显与实际有偏差
- 低电量时表显通常偏保守

**规划口径**：**按电表读数折算并留安全余量。目的地充电桩位置不确定时，按表显里程再打折更稳妥。**

## 三、场景折损对照

| 场景 | 相对表显的方向 |
|---|---|
| 城市道路 | 接近表显 |
| 高速行驶 | 明显增加消耗 |
| 低速开暖风 | 明显增加消耗 |
| 低速开空调 | 略有增加 |
| 低温环境 | 可用容量下降，实际跑不到表显里程 |

## 四、充电时长估算公式

```
需要补充的电量 = (目标电量 - 当前电量) × 电池容量
充电时长 ≈ 需要补充的电量 ÷ 实际充电功率 + 爬坡与收尾时间
```

| 关键点 | 说明 |
|---|---|
| 起始电量 | 用需要补充的电量，不要拿满容量去算 |
| 功率取值 | 直流快充看桩额定功率；交流慢充看车辆与桩的较小值 |
| 功率曲线 | 充电后期功率下降，从低电量到高电量通常比线性估算更久 |
| 收尾时间 | 高电量区间的收尾常被低估 |

**常见误区**：用「电池容量 ÷ 桩功率」直接算，忽略起始电量、功率曲线与收尾，结果偏乐观。

## 五、常见故障处置表

| 现象 | 可能原因 | 处置顺序 |
|---|---|---|
| 跳枪 | 达到目标电量、过热、桩端异常、线路不稳 | 先确认是否已达目标电量；反复跳枪联系运营方 |
| 枪拔不下来 | 锁止机构未释放 | 不要硬拉；车辆端结束充电，等待锁止释放后再拔 |
| 启动失败 | 车辆处于通电状态、电池低压 | 结束充电后再试；仍失败检查车辆状态 |
| 无法开始充电 | 枪未插到位、支付问题、桩离线 | 重新插枪、检查支付方式、换桩试试 |
| 充电特别慢 | 桩功率低、车辆限功率、电池温度异常 | 确认桩功率与车辆充电上限 |
| 中途停止并报错 | 温度保护、桩端故障、车辆异常 | 记录报错信息，联系运营方与售后 |

**枪拔不下来的正确顺序**：车辆端结束充电 → 等待锁止释放 → 再拔。硬拉可能损坏锁止机构。

## 六、计费方式（以运营方公示为准）

| 常见计费方式 | 说明 |
|---|---|
| 按时段分档 | 不同时段费率不同 |
| 按充电时长 | 占用桩位时间计费 |
| 按充电量 | 按充入电量计费 |
| 服务费加电费 | 常见组合 |

**具体费率、分时段规则与优惠方式以运营方现行公示为准**，本表不给出任何具体数字。

## 七、错峰建议

| 时段 | 特点 |
|---|---|
| 工作日白天 | 车辆少，通常较空闲 |
| 夜间住宅桩 | 通常处于谷电时段 |
| 节假日前后 | 出行高峰，公共桩排队概率高 |
| 晚高峰 | 通勤聚集，热门区域容易排队 |

## 八、安全注意

| 场景 | 注意 |
|---|---|
| 雨天 | 使用正规运营设施，避免在积水与破损桩体附近充电 |
| 高温 | 避免长时间暴晒后立即大功率充电 |
| 低温 | 电池温度过低时充电速度可能受限 |
| 长时间停放 | 避免长期极低电量或满电状态 |
| 异常情况 | 异味、冒烟、异常发热立即停止并远离，同时联系相关方 |

**安全要求以现行规定与运营方说明为准。** 私自改线、改桩、改配置不在可自行处理的范围内。

## 九、常见误区对照

| 说法 | 是否成立 |
|---|---|
| 满容量除以功率就是充电时长 | 不成立，忽略起始电量与功率曲线 |
| 表显里程就是真实剩余里程 | 不成立，那是估算值 |
| 快充次数多必然伤电池 | 不成立，高电量停留与高温影响更大 |
| 跳枪都是故障 | 不成立，达到目标电量也会跳枪 |
| 枪拔不下来可以硬拉 | 不成立，会损坏锁止机构 |
| 交流慢充按桩的功率算速度 | 不成立，受车辆端充电机限制 |
| 长期满电停放没问题 | 不成立，应避免 |
| 雨天所有充电都危险 | 不成立，关键是使用正规设施并注意周边环境 |
