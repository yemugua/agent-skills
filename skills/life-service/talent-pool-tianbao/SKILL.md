# 人才库运营（talent-pool）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据人才库运营实践，生成清单：人才库结构与标签体系、候选人来源与录入、分级与定期激活维护、招聘匹配与转化跟踪、数据清理与效果评估。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 人才库
- 人才库运营
- 候选人库
- 人才储备
- 人才激活

## 三、工作流
1. 设计人才库结构与标签
2. 拓展来源并规范录入
3. 分级并定期激活维护
4. 做招聘匹配与转化跟踪
5. 清理数据并评估效果

## 四、核心内容（检查清单与判定）
人才库的价值不在存量而在激活与转化；应打好标签、分层维护、定期触达，并用转化率评估运营效果。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含人才库结构与标签 | 标签 |
| Q2 | FAIL | 未含候选人来源与录入 | 录入 |
| Q3 | WARN | 未含分级与激活维护 | 激活 |
| Q4 | FAIL | 未含招聘匹配与转化跟踪 | 转化 |
| Q5 | WARN | 未含数据清理与效果评估 | 评估 |

> 脚本 `talent-pool_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python talent-pool_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python talent-pool_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
