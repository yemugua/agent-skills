# 选购要点与袖带选择

> 不推荐具体品牌与型号，只给判断口径。产品是否符合标准以官方认证标识与说明书为准。

## 一、类型对比

| 类型 | 特点 | 建议 |
|---|---|---|
| 上臂式电子血压计 | 测量部位与诊室测量一致，受操作影响相对小，重复性好 | **首选**，家庭自测优先 |
| 腕式电子血压计 | 体积小便于携带，但对腕部位置极敏感 | 仅在无法使用上臂式时考虑，必须严格将腕部抬到心脏高度 |
| 手指式 | 受外周循环影响大，误差明显 | 不推荐用于家庭监测 |
| 水银柱式 | 需专业听诊技术，且汞有环境与健康风险 | 已逐步淘汰，家庭不推荐使用 |
| 带心律提示功能 | 可提示脉搏不规则 | 可作为附加功能，提示异常需就医，不用于自我诊断 |

## 二、袖带尺寸（最关键）

| 项目 | 口径 |
|---|---|
| 测量方法 | 上臂自然下垂，用软尺量肘窝上方约 2-3 厘米处的上臂周长 |
| 气囊宽度 | 约为上臂周长的 40% |
| 气囊长度 | 约为上臂周长的 80% 以上（或能覆盖上臂周长的八成） |
| 袖带过小 | 读数**偏高**，容易误判为血压高 |
| 袖带过大 | 读数**偏低**，容易漏掉真实升高 |
| 标准成人袖带 | 通常适配臂围 22-32 厘米，超出范围需选大号或专用袖带 |
| 臂围较大者 | 必须选大号袖带，强行使用标准袖带误差很大 |
| 儿童与细臂者 | 选相应小号袖带，用成人袖带误差明显 |

**买之前先量臂围**，这是最容易一步到位避免误差的动作。

## 三、功能与认证

| 项目 | 口径 |
|---|---|
| 认证 | 选择通过相关标准认证、有明确准确度验证的产品 |
| 售后与校准 | 有本地售后与校准渠道，便于与诊室测量对比 |
| 记忆与平均 | 能存储多组数据并自动计算平均值更实用 |
| 电源 | 电池与外接电源都支持更方便 |
| 袖带可更换 | 便于日后按臂围更换合适尺寸 |
| 显示 | 数字够大、读数清晰，方便老年人使用 |

## 四、常见选购陷阱

| 陷阱 | 说明 |
|---|---|
| 只看价格与赠品 | 准确度与袖带适配比赠品重要 |
| 买腕式图方便 | 位置要求严苛，家庭长期监测不推荐 |
| 忽略袖带尺寸 | 全家共用一台但臂围差异大时，应配不同袖带 |
| 买无认证无售后的产品 | 准确度无从验证，坏了无法校准 |
| 被「智能分析诊断」功能吸引 | 这类结论不能替代医生判断 |

## 五、测量规范

| 步骤 | 口径 |
|---|---|
| 测前 30 分钟 | 不吸烟、不饮酒、不喝咖啡浓茶、不做运动 |
| 排空膀胱 | 憋尿会使读数偏高 |
| 静坐休息 | 安静坐位休息 5 分钟 |
| 坐姿 | 背靠椅背，双脚平放不翘腿，上臂裸露或仅薄衣 |
| 袖带位置 | 气囊中心对准肱动脉，下缘距肘窝约 2-3 厘米，松紧以能插入 1-2 指为宜 |
| 高度 | 上臂中点与心脏保持同一水平，桌面支撑 |
| 测量中 | 不说话、不动、不看手机，自然呼吸 |
| 重复 | 间隔 1-2 分钟再测一次，两次取平均；两次相差较大时可测第三次 |
| 手腕式 | 腕部必须抬到与心脏同高，手背自然伸展 |

## 六、测量时间

| 时段 | 口径 |
|---|---|
| 清晨 | 起床后 1 小时内、排尿后、服药前、早餐前，坐位休息后测量 |
| 晚间 | 睡前，坐位休息后测量 |
| 次数 | 每个时段测 2 次取平均 |
| 连续天数 | 连续 7 天，至少 12 个有效测量值（早 + 晚）更有参考价值 |
| 特殊情况 | 需评估药效覆盖时由医生指定测量时间点 |

## 七、口径说明

| 项目 | 说明 |
|---|---|
| 家庭血压与诊室血压 | 参考阈值不同，不能套用同一套数值，记录时注明测量场景 |
| 目标值 | 达标目标因年龄、是否合并糖尿病肾病、妊娠状态等而异，由医生设定 |
| 单次波动 | 血压本身有昼夜与情绪波动，单次异常不必恐慌，看连续记录趋势 |
| 复诊 | 带血压计与记录表一起去复诊，必要时与诊室测量对比 |

## 八、明确不做的事

- 不根据单次家庭测量自行加减药物
- 不用腕式且不注意位置就下结论
- 不在运动后、饮酒后、情绪激动时测量并以此判断
- 不把不同时段、不同姿势的测量值混在一起平均
- 不因一次读数正常就停止规律监测
