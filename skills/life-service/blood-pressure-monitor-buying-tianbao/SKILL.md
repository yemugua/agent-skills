# 血压计选购与家庭血压测量

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 给出血压计类型、袖带尺寸与认证标识的选购口径 | 诊断高血压、判断是否需要用药 |
| 说明测量前准备、姿势、次数与取平均的规范 | **提供任何降压药的名称、剂量与调整方案** |
| 计算周均值并说明家庭血压的常用参考口径 | 推荐具体血压计品牌与型号 |
| 整理早晚测量时间与记录表 | 承诺家庭测量可以替代医生评估 |
| 提示需要尽快就医的血压极值 | 解读动态血压报告并下结论 |

**就医红线（出现任一条，尽快就医；标注急诊的直接去急诊）**

- **血压 ≥180/120 mmHg 并伴以下任一症状：胸痛胸闷、呼吸困难、视物模糊、一侧肢体无力或言语不清、剧烈头痛、意识改变** —— 急诊
- 血压反复达到 180/120 以上，即使暂无不适 —— 尽快就医
- 血压偏低（如低于 90/60）伴头晕、乏力、眼前发黑、晕厥
- 服药后出现明显低血压表现：起身头晕、乏力、跌倒
- 妊娠期血压升高伴头痛、视物模糊、上腹痛、明显水肿 —— 尽快就诊
- 脉搏明显不齐、心慌伴血压异常，或血压计反复提示心律异常
- 伴有胸痛、单侧肢体无力、说话不清、口角歪斜 —— 急诊，不要先在家复测耽误时间
- 家庭血压持续高于个人目标且多次复测无下降 —— 复诊调整方案

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「买上臂式还是腕式」 | 用，优先上臂式 |
| 「袖带买多大」 | 用，按臂围算 |
| 「测血压前要注意什么」 | 用 |
| 「早晚各测几次、记哪几个数」 | 用，脚本算均值 |
| 「家里测的数和医院不一样」 | 用，说明两者口径不同 |
| 「血压 180/110 要不要去医院」 | 只作就医提示 |
| 「降压药要不要加量」 | 不用，由医生决定 |

## 三、完整工作流

1. **先排红线**：逐条核对就医红线，命中则停止测量指导，转为就医提示。
2. **选型**：按 `rules/选购要点与袖带选择.md` 确定类型、袖带尺寸与认证要求。
3. **量臂围**：用软尺量上臂中段周长，据此选袖带，太大太小都会影响读数。
4. **定测量时间**：清晨与晚间两个时段，各自固定时间点。
5. **规范测量**：测前准备、坐姿、袖带位置、重复次数与间隔，逐项执行。
6. **记录与计算**：填入 `templates/家庭血压记录表.md`，用脚本算 7 天均值与早晚均值。
7. **复诊**：带着记录表与血压计一起复诊，必要时与诊室测量对比校准。

## 四、核心规则与要件库

生成选购或测量建议前，**必须先读**：

- `rules/选购要点与袖带选择.md`：类型对比、袖带尺寸算法、认证与淘汰说明、常见陷阱。
- `templates/家庭血压记录表.md`：早晚记录表、均值口径、有效测量次数与复诊提问清单。

家庭血压与诊室血压的参考口径不同，不能直接套用同一套数值；所有阈值以最新版指南和主治医师判断为准。

## 五、脚本用法

```
python scripts/bp_record_calc.py --file week.json
python scripts/bp_record_calc.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`readings` 为测量记录列表，含日期、时段、收缩压、舒张压、脉搏 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--json` | 以 JSON 输出 |
| `--selftest` | 运行自检 |

脚本输出总均值、清晨均值、晚间均值、有效测量次数是否达标、血压分级提示与脉搏不齐提醒。**命中极值红线时只输出就医提示。脚本不输出任何药物剂量。**

## 六、人工确认清单

- [ ] 就医红线已排除，尤其是否伴随胸痛、肢体无力、言语不清
- [ ] 血压计类型已选上臂式，臂围与袖带尺寸匹配
- [ ] 袖带气囊中心对准肱动脉，下缘距肘窝约 2-3 厘米
- [ ] 测量前 30 分钟未吸烟、未饮咖啡浓茶、未运动
- [ ] 已排空膀胱，静坐休息 5 分钟
- [ ] 坐姿正确：背靠椅背、脚平放、上臂与心脏同高、不翘腿、不说话
- [ ] 每次测 2 遍（间隔 1-2 分钟）并取平均，记录到表格
- [ ] 早晚各有测量，连续记录 7 天

## 七、最常见的坑

1. **袖带尺寸不对**：袖带偏小读数偏高、偏大读数偏低，是最常见也最容易被忽略的误差来源。
2. **袖带绑在厚衣服上**：应裸露上臂或只留薄衣，厚衣物会明显影响读数。
3. **测前刚运动、刚喝咖啡或憋尿**：都会让读数偏高。
4. **边测边说话、翘二郎腿、手臂悬空**：姿势不对直接影响结果。
5. **只测一次就下结论**：应间隔 1-2 分钟测 2 次取平均，单次数值波动大。
6. **只早上测**：部分人仅夜间或晚间升高，只看清晨会漏掉。
7. **用腕式但手腕位置没抬到心脏高度**：腕式对位置极敏感，这是它误差大的主因。
8. **买无认证、无售后渠道的产品**：准确度与校准都无从保障。

## 八、边界与免责

本技能提供血压计选购口径、家庭测量规范与记录均值计算，不构成诊断或治疗方案。**不提供任何降压药的名称与剂量**。家庭血压与诊室血压的参考阈值不同，分级与达标目标因年龄、合并糖尿病肾病、妊娠状态与指南版本而异，**以最新版高血压防治指南和主治医师的判断为准**。出现就医红线中的任一情况，请立即就医。
