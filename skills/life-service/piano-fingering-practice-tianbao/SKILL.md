# 钢琴指法

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 给出指法编号规则与常用音阶、琶音指法表 | 替代钢琴教师的逐人手型纠正与示范 |
| 说明手型自查项与常见错误的纠正方向 | 诊断腱鞘炎、关节炎或任何手部疾病 |
| 给练习剂量、慢练与提速的判定口径 | 承诺练多久能考到几级、能弹某首曲子 |
| 安排分手练习与变速练习的流程 | 建议用器械固定手型、绑手指或用外力压手腕 |
| 提示需要停手就医的手部信号 | 建议忍痛练习或加大练习量突破瓶颈 |

**必须停手并转交专业人士的情况**

- 练习中出现手指、手腕、前臂疼痛，尤其是指根部刺痛或夜间痛
- 手指关节肿胀、活动时弹响伴疼痛、晨起僵硬超过半小时
- 手麻、握力下降、前臂放射性酸痛
- 儿童持续拒绝练琴伴随明显手部不适 —— 先排除强度问题，再考虑心理因素

## 三、完整工作流

1. **先确认指法编号**：1 拇指、2 食指、3 中指、4 无名指、5 小指。左右手编号相同，不镜像。
2. **定手位与指法**：按 `rules/指法规则与音阶指法表.md` 选一套指法并固定下来，不要每次弹都不一样。
3. **查手型**：逐项过手型自查表，任一项不合格先纠正再练速度。
4. **分手慢练**：先单手，速度降到能不看谱也弹对为准，连续三遍无错再合手。
5. **定剂量**：每次 20-30 分钟，分 2-3 段，中间休息。
6. **按门槛提速**：准确率 100% 连续三遍后，速度提高 5-10 BPM，不要一次跳太多。
7. **记录与复评**：记录每日练习时长、速度、准确率；连续两周速度不涨且错误不降，说明指法或手型有问题，回到慢练。

## 四、核心规则与要件库

生成指法建议或练习计划前，**必须先读**：

- `rules/指法规则与音阶指法表.md`：指法编号、黑键与拇指规则、穿指跨指、同音换指、常用音阶与琶音指法序列。
- `rules/手型自查与练习剂量.md`：手型五项自查、慢练与提速门槛、分段剂量、常见错误纠正。

不得建议用器械固定手型、绑手指、压手腕或用外力强行纠正。不得把「手指塌陷」简单说成多练就好，塌指需要慢速断奏重建支撑。

## 五、脚本用法

```
python scripts/piano_fingering_check.py --file case.json
python scripts/piano_fingering_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：逐音的键名、是否黑键、所用指号，手型自查项，目标与实际速度，准确率，练习时长与天数 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--json` | 以 JSON 输出 |
| `--selftest` | 运行自检 |

脚本输出指法违规清单、音阶指法比对结果、手型不合格项、提速判定和练习剂量建议。**判定顺序是先查真实缺陷（指法违规、手型不合格、提速过早、准确率不达标），再看信息是否完整**，只填了手型但没填指法时，不会因此把手型问题判成待确认。

## 六、人工确认清单

- [ ] 指法已固定，每次弹同一段用同一套指法
- [ ] 黑键上没有使用 1 指（拇指）
- [ ] 手型五项逐项确认，无塌指、无手腕低于掌关节
- [ ] 已分手练习，单手准确率达标后才合手
- [ ] 慢练速度下连续三遍无错，才开始提速
- [ ] 每次提速幅度在 5-10 BPM 以内
- [ ] 单次练琴不超过 30 分钟，中间有休息
- [ ] 无手指手腕疼痛；有疼痛已停手

## 七、最常见的坑

1. **拇指上黑键**：拇指短且位置靠外，上黑键会把手掌扭歪，导致后面一串音都跟着错。基础阶段一律用 2、3、4 指弹黑键。
2. **提速太早**：准确率 90% 就提速，结果是错误被固化，越弹越快越错。必须 100% 连续三遍再提。
3. **只合手不分手**：左手弱就直接合手，两只手一起错，根本定位不到问题。
4. **塌指当小问题**：第一指节塌陷会让指尖失去支撑，长期会弹不快也弹不匀，要慢速断奏重建。
5. **手腕压得过低**：手腕低于掌关节会卡住，声音发死；抬高会僵硬。持平或略高于掌关节是安全区间。
6. **一次练一小时**：初学者注意力与手部耐力都撑不住，20-30 分钟分 2-3 段效果更好。
7. **指法每次都变**：即兴换指法等于每次都在学新东西，进度为零。
8. **疼了还练**：手指手腕疼痛时继续练，是把小问题拖成大问题。

## 八、边界与免责

本技能提供钢琴指法的通用规则、练习剂量与自查清单，不构成钢琴教学的全部内容，也不构成医学诊断。指法存在派别差异与曲目特殊性，进阶曲目以所用教材或教师的指定指法为准。出现手指、手腕、前臂疼痛或关节肿胀时，请停止练习并就医。
