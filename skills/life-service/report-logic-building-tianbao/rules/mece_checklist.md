# MECE 检查与图表选配规则库

> 排完结构后逐项检查。**分类不 MECE，后面写得再好也站不住。**

---

## 一、MECE 十条检查项

| # | 检查项 | 判定方法 |
|---|---|---|
| 1 | 分支是否互斥 | 任两个分支能否同时属于一类？ |
| 2 | 分支是否穷尽 | 说「除此之外不属于这类」，能否找到反例 |
| 3 | 分类标准是否单一 | 同一层有没有用两个不同标准 |
| 4 | 同层是否同粒度 | 有没有「A 小项」和「B 大类」并列 |
| 5 | 分支数量是否可控 | 是否超过 5 个 |
| 6 | 名称是否同一句式 | 有没有一个是动词短语、一个是名词短语 |
| 7 | 层级是否一致 | 每个分支下是不是同一级内容 |
| 8 | 是否与顶句同维度 | 分支是不是在论证顶句 |
| 9 | 顺序是否有逻辑 | 时间/程度/因果是否说得通 |
| 10 | 空分支是否存在 | 是否列了「其他」占位 |

## 二、最常见的 MECE 错误

| 错误 | 问题 | 改法 |
|---|---|---|
| 「线上渠道、线下渠道、社交媒体」 | 线上与社交媒体重叠 | 改成「自建渠道、投放渠道、代理渠道」 |
| 「成本、费用、管理费用」 | 费用包含成本 | 改成同层级的三项 |
| 「收入增长、成本下降、效率提升」 | 三个不同维度（结果/原因） | 归到「经营改善」下再往下分 |
| 「大客户、中小客户、其他」 | 「其他」是占位不是分类 | 找出第三类的实际特征 |
| 「线上增长、线下增长、其他增长」 | 「其他」不可核查 | 列出具体渠道名 |

## 三、MECE 修复三问

```
1. 这三个分支能用同一个问句回答吗？
   「渠道表现包含哪些方面」→ 渠道 B/渠道 C/其他渠道 ✓

2. 随便挑两个分支，它们会重叠吗？
   「线上渠道」和「社交媒体」→ 会 ✗

3. 有没有漏掉的一类？
   补一句「除此之外……」试填，能填出具体名字才算穷尽
```

## 四、图表选配规则

| 想表达的关系 | 用什么图 | 不要用 | 原因 |
|---|---|---|---|
| 随时间的趋势 | 折线图 | 柱状图 | 柱状图不体现连续趋势 |
| 类目之间的比较 | 柱状图 | 饼图 | 饼图超过 5 个扇区难比较 |
| 构成占比（≤4 项） | 饼图/环形图 | 多层饼图 | 多层无法判断面积 |
| 两个变量的关联 | 散点图 | 双轴柱状图 | 容易制造假相关 |
| 流程与阶段 | 流程图 | 表格 | 表格看不出流转 |
| 时间跨度对比 | 甘特图 | 柱状图 | 柱状图看不出依赖 |
| 分布 | 直方图 / 箱线图 | 饼图 | 饼图看不出离散程度 |

## 五、图表四条通则

```
1. 一个图只说一件事
2. 标题写结论，不写「XX 数据图」
3. 坐标轴从 0 开始（截断会夸大差异）
4. 数据点不超过 7 个，多了看不清
```

### 图表标题写法

```
✗ 「2026 年销售数据」
✓ 「销售连续两季度下滑，Q4 环比 -12%」
```

### 坐标轴原则

| 情况 | 处理 |
|---|---|
| 柱状图 | 必须从 0 开始 |
| 折线图 | 可用非零起点，但要明确标注 |
| 差异确实很小 | 诚实说差异小，或改用差值柱 |
| 截断轴会误导 | 不用 |

**截断坐标轴是误导，即使数据是真的。**

- [ ] 任两个分支不重叠
- [ ] 没有「其他」占位
- [ ] 同层粒度一致
- [ ] 图表类型与表达意图匹配
- [ ] 一个图只说一件事
- [ ] 图表标题写的是结论
- [ ] 坐标轴从 0 开始
- [ ] 数据点不超过 7 个
