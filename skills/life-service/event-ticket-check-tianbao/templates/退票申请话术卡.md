# 退改申请话术卡（直接抄，改人名金额）

## 一、平台自助入口怎么填

**申请理由一句话定生死，别写"不想去了"。**

| 你的真实情况 | 理由栏怎么写 |
|---|---|
| 主办方取消 / 延期 | 「主办方原因（演出延期），依据平台退改规则申请全额退款，票面 {{票面金额}} 元，实付 {{实付金额}} 元，请退至原支付账户」 |
| 生病 / 医嘱 | 「就诊证明附后，医嘱建议禁止出行/短期内避免人群聚集，申请退票」 |
| 行程 / 航班冲突 | 「已购不可逆机票 / 高铁票，出行时间不可调整，附行程截图」 |
| 误购（错场次） | 「操作失误误购 {{日期}} 场次，订单未使用未核销，申请改签至 {{目标场次}}」 |
| 涉疫 / 隔离 | 「属地管控要求，附社区或酒店证明」 |

**必填附件**：订单号、订单页截图、电子票截图、支付凭证、理由对应的证明材料。
**提交后立刻截图**：申请页面 + 提交时间 + 申请编号。

## 二、客服工单话术（微信/电话都可用）

```
您好，我是订单号 {{订单号}} 的购票人 {{姓名}}。
演出《{{演出名称}}》原定 {{原日期}}，主办方已于 {{公告日期}} 公告延期/取消。
本人要求按平台退改规则办理全额退款：
· 票面金额 ¥{{票面金额}}，实付 ¥{{实付金额}}（{{购票渠道}}）
· 请退至原支付账户，退款回执请回传工单号
· 请出具书面退改规则依据（截图时间：{{今天}}）
请在 3 个工作日内答复，逾期我将向 12345 与属地文旅主管部门反映。
我的联系方式：{{电话}}
```

**要点**：
- 加粗两句必须写全——**"主办方原因"** 和 **"请出具规则依据"** 是后面投诉的抓手。
- 每一次沟通都要**留痕**：文字优先，电话打完立刻补一条"刚与客服 {{工号}} 沟通，结论是……"的文字确认。
- 工单编号、客服工号、通话时间全部记下来。

## 三、升级投诉话术（12345 / 12315 / 文旅部门）

```
投诉事项：演出《{{名称}}》主办方 {{主办方}} 于 {{公告日期}} 公告延期/取消，
购票平台 {{平台}} 以"特价票不退不换"为由拒绝全额退款。
诉求：全额退款 ¥{{实付金额}}（票面 ¥{{票面金额}} + 手续费），并出具退改规则公示依据。
附件：订单截图、票面截图、官方公告、平台客服沟通记录、退改规则页面截图。
订单号：{{订单号}} 联系人：{{姓名}} {{电话}}
```

**向文旅主管部门举报倒票时改写诉求**（如涉及黄牛）：
```
举报事项：{{平台/个人}}加价倒卖本院演出门票，票面 ¥1280 加价至 ¥3800 出售。
诉求：请核查其是否具备倒票资质、是否违反票务管理规定，并提供处理结论。
```
注：是否构成违规、如何处罚，**以现行规定与主管部门认定为准**。

## 四、黄牛卖方沟通话术（退票面价）

```
你好，这张票我已通过 {{购票渠道}} 实名购票，票面价 ¥{{票面金额}}。
现在演出延期，我只能走官方渠道退票面部分，溢价 ¥{{溢价}} 我无法承担。
请你在 {{日期}} 前退还 ¥{{票面金额}}，我同步发起退款并撤回投诉；
否则我会把聊天记录、转账凭证一并提交平台与警方，按诈骗/不当得利处理。
```
- 只认 **平台担保交易**，脱离平台的直接转账基本追不回。
- 对方失联的，别闹事、别砸场，直接走报警程序。

## 五、别做的事

- 别在开场前 2 小时才申请退票（窗口基本关了）。
- 别把强实名票的二维码直接发给陌生人（人票不一致 = 进不去，且无法追回）。
- 别信"代退票""内部渠道退票"的广告（二次诈骗）。
- 别删订单页和规则页截图（它们会变，以截图为准）。
