# 取证、阶梯与时限

## 一、取证清单（按优先级）

1. **购票订单与票面**：订单号、订单页截图、电子票二维码、支付凭证。这是所有主张的地基。
2. **实名信息记录**：购票时绑定的观演人姓名与证件号、改绑记录。强实名票争议里这是关键。
3. **主办方公告**：取消 / 延期 / 变更演员或场馆的官方公告截图（含发布时间、来源账号）。
4. **平台退改规则页面**：规则截图并**记录截图时间**——规则是会改的，以你下单时公示和当前公示为准。
5. **与平台 / 主办方的聊天与工单记录**：客服回复、工单编号、处理时限承诺。
6. **黄牛交易记录**：转账凭证、聊天记录、对方账号信息、手写收条。有关系证明才有追索可能。
7. **现场证据**（如已被拒入场）：现场照片、与安保沟通录音、被拒入场的书面说明。

## 二、处理阶梯（从便宜到贵，逐个走）

### 主办方 / 场馆原因（取消、延期、变更）

1. 平台自助退改入口提交申请（通常最快，走"无理由全额退"通道）。
2. 平台客服工单（**要工单编号**），并明确写"主办方原因，要求全额退款"。
3. 主办方 / 场馆官方渠道（官网、公众号、客服电话）书面主张。
4. **12345** 反映，同时向**属地文旅主管部门**举报（涉演出审批与主办方履约）。
5. **12315** 消费者投诉（涉格式条款、退费争议）。
6. 合同有仲裁条款的走仲裁，没有的向被告住所地法院起诉（诉讼时效 3 年）。

### 观众自身原因（想退）

1. 平台自助退改 / 改签入口（优先试"改签"，免手续费）。
2. 平台客服工单，说明真实原因（病假、行程冲突、误购）。
3. 平台拒不处理的：12345 反映 + 12315 投诉，要求说明规则依据与提示方式。
4. 仍不成的，另行协商或诉讼（诉讼时效 3 年）。

### 黄牛 / 二手平台

1. 先向购票平台投诉该链接 / 该商家（售假、人票不一致、欺诈）。
2. 与卖方协商**退票面价**（你只能拿回票面部分）。
3. 线下交易转账后被拉黑的：向**公安机关报案**（涉诈骗）、12345 反映。
4. 加价倒票行为本身：向文旅主管部门 / 12345 举报。
5. 金额较大且证据完整的，可另行主张不当得利返还或诉讼。

## 三、时限

| 事项 | 时限 |
|---|---|
| **退票窗口期** | 多数平台为**演出前 24~72 小时**截止受理，越靠近开场越退不动（各平台不同，以平台公示为准） |
| 平台工单处理承诺 | 一般 3~15 个工作日；超期未回复要留痕升级 |
| 行政投诉（12345 / 12315） | 一般受理后 15 个工作日内回复 |
| 民事诉讼时效 | 3 年，自知道权利被侵害之日起算 |
| 退款到账 | 通常 7~15 个工作日退回原支付渠道 |

## 四、最紧急的三件事

- **临近开场的退票窗口**：先看第八段倒计时，别拖到开场前 2 小时才申请。
- **订单与规则页截图**：订单页和退改规则页随时会被改，先截下来。
- **主办方公告的发布时间**：取消 / 延期的责任认定与你的"合理时间"起算都靠它，务必存原图与链接。
