# 票种、实名与退改定性

## 一、第一步永远是先分票种

退改结论的方向由"票是不是强实名"决定，判错后面全错。

| 类型 | 特征 | 转手 | 退票 |
|---|---|---|---|
| **强实名票** | 购票时登记观演人证件，人票绑定、一场一证、入场核验证件与人一致 | 通常不可转赠，个别平台提供"转赠/改签"入口且名额有限 | 能否退完全看平台与主办方公布的退改规则，且常有窗口期 |
| **普通非实名票** | 只有二维码/条形码，入场不核验身份 | 转手相对可行，但二手交易不受购票平台保障 | 退票同样按平台规则走，与是否实名无必然关联 |

采集表里的"是否实名票"填：**强实名 / 非实名 / 不清楚**。填"不清楚"的按**待补正**处理，不要直接按"能退"或"不能退"下结论。

## 二、强实名票的四个常见卡点

1. **"不支持退票"不等于不能退**：还要看是**整单不可退**还是**在窗口期内可退**。多数平台设有"演出前 X 小时前可申请退款、之后不可"的规则。
2. **转赠被收口**：强实名票一旦核销或绑定，改绑他人往往要走平台特定入口；私下把二维码发给别人，到场可能被人票不一致拒入。
3. **"改签"与"退票"是两条路**：改签（改场次/改座位）通常免手续费且额度有限；退票按规则收费。能改签就别退，能退就别赌转手。
4. **实名信息的填写错误是自己的事**：填错证件号的，先走平台"修改观演人"或"退票重买"，别直接找黄牛。

## 三、主办方原因 vs 观众自身原因（这一项决定退不掉要不要)

### 主办方 / 场馆原因

- **演出取消**：观众有权要求**全额退款**；也可协商改到其他场次或保留至后续场次。
- **演出延期**：延期**不当然使门票作废**。主办方应就新的时间、地点另行通知并给出解决方案；观众对新的安排不满意的，通常可以退票。**不要默认延期后票就白扔了**。
- **变更演员 / 变更场馆**：属于演出合同内容的重大变更。变更场馆（尤其跨城）影响观演目的的，可主张退票；变更演员一般只能协商，是否构成根本违约要看合同与宣传承诺（如合同中明确"某主演"）。
- **场馆原因（停水停电、舞台事故、政策导致停演）**：归根到底还是主办方 / 场馆侧承担退改责任，与观众个人原因无关。

处理结论：**主办方原因 → 可退（全额退款为主），且可选择退票或改签 / 保留，观众不因个人原因被扣费**。

### 观众自身原因

- 时间冲突、行程变化、不可抗力（生病、交通管制、隔离等）→ 看平台退改规则。
- 常见规则形态：演出前若干天（如 7 天 / 48 小时）内可申请退款并按阶梯收手续费（例如按票面价 10%~30% 分档）；**临近开场（通常演出前 24~72 小时）普遍不再受理**。
- "特价票 / 预售票不退不换"这类声明：属于格式条款，是否对消费者发生效力，要看是否显著提示、是否合理排除消费者主要权利；**具体由购票平台规则与主管部门 / 司法机关认定，本表不直接下"当然无效"的结论**。
- 误购（买错场次/日期）：先试平台"改签/换票"入口，多数平台对未核销未入场订单支持自助改。
