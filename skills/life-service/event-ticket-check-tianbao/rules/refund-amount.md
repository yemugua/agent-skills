# 可退金额与手续费测算

## 一、先分清"退给你的基数"

| 情形 | 退的基数 | 收不收手续费 |
|---|---|---|
| 主办方原因取消 / 延期 / 变更 | **实付金额**（你为这张票实际掏的数） | 不收；退的是全额 |
| 观众自身原因 | **票面金额**（票上的面价）按平台阶梯扣手续费 | 按平台公布的阶梯收 |
| 黄牛 / 二手平台买入 | 只能退到**票面金额** | 平台按规则扣，溢价部分不退给你 |

**关键点**：黄牛票哪怕你原价 3800 买的、票面 1280，主办方 / 平台只按票面 1280 退，中间 2520 是溢价损失，只能自己扛（除非能证明对方诈骗或违约）。

## 二、手续费测算口径（给区间，不给单值）

脚本按下面的顺序取数：

1. **采到了"退票手续费率"** → 直接算：退票手续费 = 实付金额 × 比率；可退金额 = 实付金额 − 手续费。
2. **没填比率 → 给区间而非单值**：提示"常见区间（约 10%~30%，分档按平台公示），以购票平台公布的退改规则页面为准"，并列出"若无约定按实际损失、由双方举证"的兜底口径。
3. **临近开场（距演出 ≤ 24 小时）** → 提示"多数平台此时已停止受理退票，可退金额趋近于 0"，不要给一个虚假的确定值。
4. **主办方原因** → 直接按全额（实付金额）给可退金额。

## 三、金额结果的呈现方式

- 一律用 `¥` 前缀，整数不带 `.0`。
- 可退金额写**区间**而不是单值：如"¥1280 ~ ¥3800 / 或按平台实际扣费"，因为实际扣多少取决于平台规则与是否受理。
- 同时输出一条**"测算口径"**说明：上面的数是按什么规则推的，实际以平台结算为准。

## 四、黄牛票的三笔账

1. **溢价损失** = 实付金额 − 票面金额（买的时候就已经亏掉的部分）。
2. **退票后仍亏** = 实付金额 −（票面金额 − 退票手续费）。
3. **入场风险损失**：若人票绑定失败、根本进不去，票面金额拿不回来，还要另买。

**倒票本身可能违规**：加价倒卖有价票证、变相炒票的，可向文旅主管部门、12345 举报；是否构成违法、如何处罚，**以现行规定与主管部门认定为准**，本表不编造条号。

## 五、还有一笔容易被漏掉的钱

退票成功后，下列项目记得一起主张 / 核对：

- 票面外的**平台服务费、配送费、保险**是否一并退（很多平台只退票款不退服务费）。
- 同一订单**多张票**是否只退了其中一张。
- 退票款项**退回原支付账户**的时间（通常 7~15 个工作日）。
- 因主办方原因退票，是否还有**交通、住宿**等实际损失可另行协商（法律上要证明实际发生，别空口主张）。
