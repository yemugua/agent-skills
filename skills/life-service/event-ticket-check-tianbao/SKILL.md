# 演出门票退换核查

买错时间、临时有事、演出取消或延期、票想转手被拒——门票退改的第一件事不是算钱，是**先分清票种**。

## 什么时候用

- 演唱会 / 话剧 / 音乐节 / 球票买错了场次或座位，想退
- 演出官方取消、延期、换演员、换场馆，不知道该退还是该等
- 强实名票显示"不支持退票"，想知道是不是就没救了
- 在二手平台或黄牛手里买了票，进场时被拒（人票不一致）或溢价亏了
- 平台说"特价票不退不换"，不知道这个格式条款能不能站住
- 退票被扣了一笔手续费，想算一下扣得对不对

## 怎么做

**第 1 步**：复制 `templates/演出门票退换信息采集表.md` 填写。

**第 2 步**：跑脚本

```bash
python scripts/ticket_check.py 采集表.md --base 2026-10-05 --out 退换核查报告.md
```

**第 3 步**：按第九段"待办补正动作"执行，优先处理第八段时限倒计时里的紧急项。

## 三句话定性的核心规则

1. **强实名票与普通非实名票的退改逻辑完全相反**：强实名票人票绑定、一场一证、转赠收口，能不能退取决于平台与主办方公布的退改规则；普通非实名票转手相对容易，但退票仍按平台规则走。所以**第一步必须填"是否实名票"**，判错方向后面全错。
2. **主办方原因（取消、延期、变更演员或场馆）→ 你有权选退或选改**：取消通常全额退；延期不等于票作废，主办方应另行通知并给出退或改的方案；变更演出内容构成合同变更的，可协商退票。**不要把延期默认成作废**，也不要因为"已经延期"就放弃退票窗口。
3. **观众自身原因退票，看的是购票平台规则而非法律强制**：一般实名票在演出前若干时间（常见 24~72 小时的窗口期）内可申请退票并按阶梯收手续费，临近开场普遍不受理；"特价票不退不换"属于限制消费者主要权利的格式条款，是否当然有效要看是否显著提示、是否存在不合理排除，**具体以平台公示规则与主管部门认定为准**。黄牛票溢价部分基本只能自担，且倒票本身可能违规，可向文旅主管部门 / 12345 举报。

## 输入 / 输出

| | 内容 |
|---|---|
| 输入 | 采集表 Markdown（演出信息 / 票种与实名 / 主办方原因 / 购票与支付 / 退改动作 / 转手与黄牛 / 证据） |
| 输出 | 九段报告：结论摘要 / 票种与是否强实名 / 退改定性（谁的原因）/ 可退金额与手续费测算 / 转手与黄牛风险 / 证据缺口 / 处理阶梯 / 时限倒计时 / 待办 |
| 退出码 | 0 正常；2 关键信息缺失（给提示串，不崩） |

## 边界与纪律

- 依**通用规则**整理，**不替代律师意见**
- 退改规则、手续费阶梯、实名转赠政策**平台差异极大**，**一律以购票平台与主办方公布的现行规则、当地文旅主管部门口径为准**
- 不预测平台受理结果、不预测行政投诉与诉讼结果
- **未填的一律不算通过**，只按已填内容判断
- 涉及倒票是否违规、处罚认定的，以文旅主管部门与公安机关认定为准
