# 演出门票退换核查

## 解决什么

演唱会、话剧、音乐节、球票买错场次、演出取消延期、强实名票退不掉、黄牛溢价亏了——
绝大多数人在这几件事上**第一步就判错方向**：把"强实名票"当成"一定不能退"，或把"演出延期"当成"票自动作废"。
本技能的判断顺序是：**票种（强实名/非实名）→ 原因（主办方/个人）→ 金额 → 转手可行性 → 阶梯与时限**。

## 和通用法律问答的区别

- **不给法条号兜底**：法条号不确定的写"《XX法》相关规定"，不编造；退改细则一律指向"购票平台与主办方现行规则"。
- **算钱给区间不给单值**：手续费按平台公布的阶梯优先，没填就给"常见区间 + 举证口径"，临近开场直接说"趋近于 0"，不粉饰。
- **专门判黄牛票的三笔账**：溢价损失、退票后仍亏多少、人票绑定失败进不去，分开算。
- **时限按距演出天数实时算**：用 `--base` 指定当前日期，直接告诉你退票窗口还剩多少天。

## 输入 → 输出

填一份 Markdown 采集表（表格行或冒号行都认），跑一条命令：

```
python scripts/ticket_check.py 采集表.md --base 2026-10-05 --out 核查报告.md
```

输出九段报告：结论摘要 / 票种与是否强实名 / 退改定性 / 可退金额与手续费 / 转手与黄牛风险 / 证据缺口 / 处理阶梯 / 时限倒计时 / 待办。
附 `--json` 结构化输出；关键信息缺失时退出码 2 并提示，不崩。

## 使用纪律

依通用规则整理，不替代律师意见；退改规则与地域口径以购票平台、主办方、当地文旅主管部门为准。
