# 面包揉面

## 1. 硬边界表

| 能做 | 不能做 |
|---|---|
| 判断面团揉面阶段（拾起/扩展/完全） | 替代你对面粉蛋白质含量的判断 |
| 用窗户测试确认面筋状态 | 替代你对配方含水量的调整 |
| 给出揉面时长与温度区间 | 判断某种面粉是否变质 |
| 提示断筋或揉过头的信号 | 给出医疗或食品安全之外的承诺 |

必须转交专业人士的情况：配方涉及商用量产、特殊医用低蛋白/无麸质饮食、或对麸质过敏人群，请咨询专业烘焙师或营养师。

## 2. 什么时候用

| 用户说法 | 用本技能 |
|---|---|
| 「面团揉到什么程度算好」 | 用 |
| 「怎么看出膜」 | 用 |
| 「揉了20分钟还不光滑」 | 用 |
| 「哪种面粉最好吃」 | 不用，属选材偏好 |
| 「我有麸质过敏能吃吗」 | 不用，转专业 |

## 3. 完整工作流

1. 确认面粉类型（高筋/中筋）与含水量。
2. 分阶段观察：拾起阶段（粗糙黏手）→ 扩展阶段（光滑有弹性，能拉出厚膜易破）→ 完全阶段（薄膜透光、破口光滑）。
3. 做窗户测试：取一小块面团撑开成膜，观察透光与破口形状。
4. 记录揉面方式与总时长、面团中心温度。
5. 对照 `rules/bread-kneading-rules.md` 判定是否到位或过头。
6. 人工确认清单逐项核对后再决定下一步。

## 4. 核心规则

生成任何判断前，先读 `rules/bread-kneading-rules.md`，不要凭印象写。该文件给出各阶段的触感、薄膜标准、揉面时长区间与温度上限，以及断筋/揉过头的判定口径。

## 5. 脚本用法

本目录 `scripts/check.py` 可校验你填写的揉面自评：

```
python scripts/check.py --file 你的自评.json
python scripts/check.py --selftest
```

参数：`--file` 传入 JSON（含 stage、window_test、knead_minutes、dough_temp 等字段）；`--selftest` 跑内置自检。

## 6. 人工确认清单

- [ ] 面粉标称蛋白质 ≥11.5%（高筋）才追求完全阶段出膜
- [ ] 窗户测试破口是否光滑（光滑=完全阶段，锯齿=扩展阶段）
- [ ] 面团中心温度是否 ≤28℃
- [ ] 揉面总时长是否在区间内（手揉通常 20–40 分钟）
- [ ] 是否出现断筋信号（化水、稀软塌垮）

## 7. 最常见的坑

1. 误把扩展阶段当完全阶段：破口呈锯齿就上炉，组织粗糙。
2. 揉过头：完全阶段后继续揉，面筋断裂，面团化水塌陷。
3. 面团温度过高（>28℃）仍猛揉，发酵提前、成品扁塌。
4. 含水量高的面团前期必然黏手，新手误以为「没揉好」提前加粉，破坏配比。
5. 低筋面粉强行追求出膜，永远拉不出坚韧薄膜。
6. 机器揉面忽略升温，面包机/厨师机桶内温度累积超限。

## 8. 边界与免责

本技能只做家庭揉面的状态判断，不保证成品口感。面粉批次、环境温湿度差异会影响结果。以实际面团状态为准。
