# 外墙外保温防火（external-wall-insulation）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《建筑设计防火规范》GB 50016 与外墙外保温防火要求，生成清单：保温材料燃烧性能等级、防火隔离带与防护层、施工与动火管理、既有建筑排查整改、维护与警示标识。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 外墙保温防火
- 外保温材料
- 防火隔离带
- 保温层防火
- 外墙保温改造

## 三、工作流
1. 核查保温材料燃烧性能等级
2. 落实防火隔离带与防护层
3. 管控施工与动火作业
4. 排查既有建筑并整改
5. 做好维护与警示标识

## 四、核心内容（检查清单与判定）
外墙外保温应采用符合燃烧性能要求的材料并按层设防火隔离带与防护层；施工动火与既有建筑改造是火灾高发环节，须重点排查。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含保温材料燃烧性能等级 | 材料 |
| Q2 | FAIL | 未含防火隔离带与防护层 | 隔离带 |
| Q3 | WARN | 未含施工与动火管理 | 施工 |
| Q4 | FAIL | 未含既有建筑排查与整改 | 排查 |
| Q5 | WARN | 未含维护与警示标识 | 维护 |

> 脚本 `external-wall-insulation_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python external-wall-insulation_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python external-wall-insulation_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
