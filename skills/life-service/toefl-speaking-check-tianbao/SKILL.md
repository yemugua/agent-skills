# 托福口语答题结构与评分核查（toefl-speaking-check）

托福口语看两件事：**这道题该说的要点有没有说全**、**说出来的东西在三个维度上处于什么档位**。

三个评分维度各占一票：**Delivery**（表达清晰度）、**Language Use**（语言运用）、**Topic Development**（内容展开）。每道题 0~4 分，四道平均后换算成 0~30 分。

这个技能做三件事：**按题型核结构** → **按维度定档** → **核时长与要点覆盖**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出四类任务的答题结构与要点清单 | ❌ 代替官方评分给出确定分数 |
| 对照三维度描述定档 | ❌ 承诺"练完必过 23 分" |
| 核答题时长与要点覆盖是否达标 | ❌ 替你完成考试作答 |
| 估算 0~30 分并指出短板 | ❌ 判断某段录音是否会被判重复内容 |
| 输出针对性训练顺序 | ❌ 提供当年考位、报名时间与费用 |

**出现以下情况先停下来，别照着模板硬套：**
- 综合题听力完全没听懂 —— 先补听力，套模板拿不到内容分
- 三个维度里 Delivery 长期 ≤2 —— 属于发音与流利度问题，先做跟读而不是背模板
- 目标院校对口语小分有硬性要求 —— 以**当年招生简章与院校官网要求为准**
- 需要在短期内出分 —— 先确认报考场次与出分时间，**以官方报名公告为准**

## 二、完整工作流

```
第 1 步  确认题号（1 独立题 / 2 校园情景 / 3 学术概念 / 4 学术讲座）
第 2 步  先读 rules/task_structure.md，抄下这道题的要点清单（不要凭印象答）
第 3 步  读 rules/scoring_rubric.md，对三个维度各定一个 0~4 的档
第 4 步  计时录音，记录实际作答秒数与覆盖的要点数，跑体检脚本
         python scripts/toefl_speaking_check.py --task 3 --seconds 58 --points 3 \
             --delivery 3 --language 3 --topic 2
第 5 步  看脚本给出的"要点缺口"与"最短板维度"，按 §4 排训练
第 6 步  同一题号连续 3 套无变化时，换短板维度专项训练
第 7 步  填 templates/response_record.md，记录每题的要点覆盖与失分原因
```

## 三、四题任务速查

| 题号 | 类型 | 材料 | 准备 | 作答 | 必说要点 |
|---|---|---|---|---|---|
| Task 1 | 独立题 | 无 | 15 秒 | 45 秒 | 立场 + 2 个理由 + 各一个具体例子 |
| Task 2 | 校园情景 | 阅读公告 + 对话听力 | 30 秒 | 60 秒 | 阅读说了什么 + 说话人态度 + 2 个理由（来自听力） |
| Task 3 | 学术概念 | 阅读概念 + 讲座听力 | 30 秒 | 60 秒 | 概念是什么 + 教授举的例子 + 例子如何说明概念 |
| Task 4 | 学术讲座 | 只有讲座听力 | 20 秒 | 60 秒 | 总主题 + 2 个分点或例子（来自讲座） |

**综合题的核心原则**：阅读部分只占**一句**背景，重心在听力。把 60 秒花在复述阅读上，Topic Development 直接掉一档。

**时间硬指标**：作答时间低于规定时长的一半（如 60 秒题只说 25 秒），内容展开不足会被压档；说完之后剩下的空白时间不扣分。

## 四、三维度与提分顺序

| 维度 | 看什么 | 常见短板信号 |
|---|---|---|
| Delivery | 发音是否清楚、语流是否连贯、要不要听者费力 | 卡壳多、单词逐个蹦、语调平 |
| Language Use | 语法与用词是否自动且有效、错误是否挡理解 | 时态乱、主谓不一致、只会简单句 |
| Topic Development | 是否完整答题、要点是否展开、逻辑是否清楚 | 只给结论不给原因、例子不具体 |

| 你的状况 | 优先做什么 |
|---|---|
| 三项里 Topic Development 最低 | 先练要点清单与提纲，不是练发音 |
| Delivery 最低 | 先做跟读与复述，练语流 |
| Language Use 最低 | 先修时态与主谓一致，再练句型 |
| 三项都在 2~3 | 冲 Topic Development，举例具体化最容易抬一档 |
| 综合题听不懂 | 先补听力笔记，模板救不了内容分 |

## 五、脚本用法

```bash
python scripts/toefl_speaking_check.py --task 3 --seconds 58 --points 3 --delivery 3 --language 3 --topic 2
```

| 参数 | 说明 |
|---|---|
| `--task` | `1` / `2` / `3` / `4` |
| `--seconds` | 实际作答秒数 |
| `--points` | 实际覆盖的要点个数 |
| `--delivery` / `--language` / `--topic` | 三个维度自评 0~4 整数 |
| `--target` | 目标口语分数（0~30），默认 23 |
| `--out` / `--format` | 输出文件路径 / `md`（默认）或 `json` |
| `--selftest` | 跑内置自检 |

脚本做五件事：① 输出该题型的要点清单与实际覆盖数对比；② 核作答时长是否达到可用区间；③ 三维度各给档位描述；④ 按四题平均估算 0~30 分；⑤ 给短板维度与训练方向。

> 0~30 分是**按平均分线性估算**，官方采用评分量表与换算表，实际结果会有偏差，**以官方成绩报告为准**。

## 六、人工确认清单（这步不能省）

- [ ] 综合题有没有把 60 秒的大半花在复述阅读上（有就重录）
- [ ] Task 1 的两个理由是否各带了一个具体例子（不是抽象说理）
- [ ] 笔记是否记到听力里的两个理由/两个例子
- [ ] 录音是否真的计时，还是凭感觉说
- [ ] 三个维度是否分开打分，而不是只给一个总体印象分
- [ ] 是否有整段背诵的模板痕迹
- [ ] 目标院校的口语小分要求是否查过**当年**招生简章

## 七、最常见的坑

**坑一：综合题大段复述阅读。**
错误写法："The announcement says that the university will close the coffee shop, and it also mentions..."（60 秒里 30 秒在讲阅读）；正确写法：一句话交代背景 "The university plans to close the campus coffee shop."，其余时间讲听力里说话人的态度与两个理由。

**坑二：Task 1 只给立场不给理由。**
错误写法："I agree with this because it is good for students."（说完就停）；正确写法：立场 + 理由 1 + 具体例子（人名、场景、结果）+ 理由 2 + 收尾一句。

**坑三：例子太抽象。**
错误写法："For example, it can help people in many ways in their daily life."；正确写法："Last semester my roommate used the tutoring service before her statistics exam and raised her grade from a B to an A."

**坑四：整段背模板。**
错误写法：开头固定 "This is a very interesting question and I would like to share my opinion..."（模板句占 8 秒，还会压 Topic Development）；正确写法：直接进内容 "I agree that..."。

**坑五：追求语速忽视清晰度。**
错误写法：为塞进更多内容把语速提到听者费力的程度；正确写法：45 秒约 110~140 词、60 秒约 140~180 词，以清楚为准。

**坑六：听力没记笔记。**
错误写法：听完凭印象说，结果漏掉第二个理由；正确写法：笔记只记关键词与两个理由的标记，不写整句。

**坑七：说不完就停，或说完就慌。**
错误写法：说到一半发现忘了就停住沉默；正确写法：用 "Another reason is..." 争取 2 秒思考，把要点说完；说完提前结束不扣分。

**坑八：时态与主谓一致乱。**
错误写法："He say the student was agree with the plan."；正确写法："He says the student agrees with the plan."

**坑九：以为发音必须地道。**
错误写法：为纠正口音把每个词都咬得很重，语流断裂；正确写法：口音不扣分，Delivery 看的是是否清楚、是否需要听者费力。

**坑十：只练独立题不练综合题。**
四题里三题是综合题，且综合题的分数波动最大；错误写法：每天只练 Task 1；正确写法：综合题占训练量的三分之二。

## 八、边界与免责

- 本技能给出的是**答题结构核查与评分维度对照**，不构成官方评分，也不承诺达到某一分数
- 评分维度描述为公开评分标准（rubrics）的整理与简化表述，**完整口径以官方发布版本为准**
- 考试日期、报名时间、费用、出分时间与院校小分要求**以当年官方公告和报考院校要求为准**，本技能不提供具体日期与条款
- 本技能不代报名、不代考、不提供任何违背考试规则的做法
