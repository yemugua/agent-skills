# 托福口语四题任务结构与要点清单

> 题型与时间安排以官方最新考试说明为准，本表按当前常见结构整理。

---

## 一、四题总表

| 题号 | 类型 | 输入材料 | 准备时间 | 作答时间 | 目标词数 |
|---|---|---|---|---|---|
| Task 1 | 独立题 | 无（听题） | 15 秒 | 45 秒 | 110~140 词 |
| Task 2 | 校园情景 | 阅读公告（约 45 秒阅读）+ 对话听力 | 30 秒 | 60 秒 | 140~180 词 |
| Task 3 | 学术概念 | 阅读概念（约 45 秒阅读）+ 讲座听力 | 30 秒 | 60 秒 | 140~180 词 |
| Task 4 | 学术讲座 | 只有讲座听力 | 20 秒 | 60 秒 | 140~180 词 |

**时间分配的硬规则**：准备时间用来列要点，不用来写整句；作答时间低于规定时长一半，内容展开不足会被压档。

---

## 二、Task 1 独立题结构与要点清单

**结构**：立场句 → 理由 1 + 例子 → 理由 2 + 例子 → 收尾

| 要点 | 是否必说 | 说明 |
|---|---|---|
| 明确立场（agree / disagree / prefer A） | 必说 | 第一句就要说清，不要铺垫 |
| 理由 1 | 必说 | 一个完整的因果句 |
| 理由 1 的具体例子 | 必说 | 有人名、场景、结果，越具体越好 |
| 理由 2 | 建议说 | 与理由 1 不重复 |
| 理由 2 的具体例子 | 建议说 | 可以简短 |
| 收尾句 | 可省 | 时间不够时优先保理由 2 |

**必说要点数：2**（立场 + 至少 1 个理由带例子）；**满分要点数：4**（立场 + 2 理由 + 2 例子）。

**常见题型与立场句写法**：
- 二选一：I prefer A because...
- 同意与否：I agree that... / I disagree with the statement that...
- 现象描述：描述时按时间或重要性排序，不要列流水账

---

## 三、Task 2 校园情景结构与要点清单

**结构**：一句话交代阅读内容 → 说话人态度 → 理由 1（来自听力）→ 理由 2（来自听力）

| 要点 | 是否必说 | 说明 |
|---|---|---|
| 阅读公告/提议说了什么 | 必说 | **一句话**，不超过 10 秒 |
| 说话人态度（支持或反对） | 必说 | 明确说 agrees / disagrees |
| 理由 1 | 必说 | 来自听力，不是来自阅读 |
| 理由 2 | 必说 | 来自听力 |
| 收尾 | 可省 | |

**必说要点数：4**；阅读部分超时的判定：超过 15 秒即视为复述过多。

**笔记模板**：
```
Reading: 提议/变更 = 一句话
Speaker: agree / disagree
R1: ...
R2: ...
```

## 四、Task 3 学术概念结构与要点清单

**结构**：概念定义（来自阅读）→ 教授如何举例（来自听力）→ 例子与概念的对应

| 要点 | 是否必说 | 说明 |
|---|---|---|
| 阅读里的概念是什么 | 必说 | 一句话定义，不用复述整段 |
| 教授举的例子是什么 | 必说 | 具体场景与主体 |
| 例子的关键步骤或结果 | 必说 | 通常 2 个细节 |
| 例子如何说明概念 | 建议说 | 明确点出对应关系 |
| 收尾 | 可省 | |

**必说要点数：3**；**满分要点数：4**。

**笔记模板**：
```
Concept: 定义一句话
Example: 谁 + 做了什么
Detail A / Detail B
Link: 对应概念的哪一部分
```

---

## 五、Task 4 学术讲座结构与要点清单

**结构**：总主题 → 分点 1 + 例子 → 分点 2 + 例子

| 要点 | 是否必说 | 说明 |
|---|---|---|
| 讲座的总主题 | 必说 | 第一句给出 |
| 分点 1（或两个例子中的第一个） | 必说 | |
| 分点 2 | 必说 | |
| 各分点的支撑细节 | 建议说 | |
| 收尾 | 可省 | |

**必说要点数：3**；**满分要点数：4**。

**与 Task 3 的区别**：Task 4 没有阅读材料，全靠听力笔记；讲座结构通常是「总主题 + 两个分点/两个例子」，笔记要按 1-2 分层记。

---

## 六、准备时间怎么用

| 题号 | 准备时间 | 该做的事 | 不该做的事 |
|---|---|---|---|
| Task 1 | 15 秒 | 定立场 + 想两个理由的关键词 | 想例子细节（想不完） |
| Task 2 | 30 秒 | 确认态度 + 从笔记里圈出两个理由 | 重读阅读段落 |
| Task 3 | 30 秒 | 确认概念名 + 圈出例子两个细节 | 补写整句 |
| Task 4 | 20 秒 | 确认总主题 + 两个分点的关键词 | 回忆已过去的细节 |

---

## 七、要点缺失的扣分判定

| 缺失情况 | 判定 |
|---|---|
| 缺必说要点 1 个 | Topic Development 最多 3 分 |
| 缺必说要点 2 个及以上 | Topic Development 最多 2 分 |
| 综合题只讲阅读不讲听力 | Topic Development 最多 1 分 |
| 作答时长不足规定一半 | 直接压档，且要点无法展开 |
| 立场未给出（独立题） | Topic Development 最多 2 分 |
