# 托福口语答题结构与评分核查

托福口语最容易踩的坑是**把综合题答成了复述题**：60 秒里一半时间在念阅读段落，听力里的两个理由一句没说。Topic Development 看的是对内容的展开，复述阅读不算展开，所以很多人练了几十套还是 20 分。

这个技能把四道题各自该说的要点列成清单，把三个评分维度的 0~4 分档摆出来，再把时长和要点覆盖算清楚。

## 你会得到什么

- **四题任务结构与要点清单**——Task 1 独立题（15 秒准备 / 45 秒作答）、Task 2 校园情景与 Task 3 学术概念（30 秒 / 60 秒）、Task 4 学术讲座（20 秒 / 60 秒），每题标出必说要点数与满分要点数
- **三个评分维度分档描述**——Delivery、Language Use、Topic Development 从 0 到 4 档的具体表现
- **要点覆盖与时长核查**——必说要点缺 1 个则 Topic Development 最多 3 分，缺 2 个最多 2 分，作答不足规定时长一半直接压档
- **10 条失分点对照**——每条给出为什么扣分、错误写法、正确写法、自查动作
- **0~30 分估算与短板定位**——四题平均后线性折算，找出最短板维度
- **逐题自查记录表**——记录要点覆盖、三维度自评与下次训练重点

## 典型用法

练完一道 Task 3，想知道该说的要点有没有说全；
口语长期 20 分上不去，想定位是哪一个维度拖后腿；
不知道综合题要不要复述阅读、复述多久算过多；
45 秒或 60 秒到底说多少词合适；
分不清 Task 3 和 Task 4 的答题结构差异。

## 内置规则不是提示词

`rules/task_structure.md` 给出四题的时间硬指标、要点清单、笔记模板与要点缺失的扣分判定，
`rules/scoring_rubric.md` 给出三维度分档描述、0~30 分折算口径与 10 条失分点对照。

生成意见之前先读这两份文件，不凭印象作答。

## 边界

只做答题结构核查与评分维度对照，**不代替官方评分，不承诺达到某一分数，不代报名、不代考**。
完整评分标准以官方发布的 speaking rubrics 为准；题型与时间安排可能调整，以官方最新考试说明为准；考试日期、报名时间、费用与院校小分要求**以当年官方公告和报考院校要求为准**。
