# 二手房签约核查操作卡

签约当天打印，逐项打勾。**任何一项打不了勾，就先别付这一笔钱。**

## 付定金之前必须完成

- [ ] 到不动产登记机构**查档**，确认权利人姓名与身份证号
- [ ] 查档显示**有无共有人**，共有人是否全部到场签字
- [ ] 查档显示**有无抵押、查封、冻结**
- [ ] **房本原件**已现场核对，与查档信息一致
- [ ] 房屋性质（普通住宅 / 经适房 / 两限房 / 小产权）已确认
- [ ] 卖方**取得年限**已确认（影响增值税）
- [ ] 购房资格已核实（社保、个税、户籍、名下房产）
- [ ] 贷款预审通过（额度、月供能承受）

## 合同必须写进去的条款

- [ ] 明确写「**定金**」还是「**订金**」，不是"意向金""认购金"
- [ ] 定金金额、**退还条件**、**双倍返还**规则、违约责任
- [ ] 总价、付款节奏、每期付款时间与金额
- [ ] 卖方**如实披露**条款：漏水、违建、凶宅、欠费、租约、户口、权属争议
- [ ] 卖方户口**迁出时间** + **每日违约金** + 逾期处理
- [ ] 交房时间、物业水电燃气**结清**、钥匙门禁移交
- [ ] 税费与中介费**由谁承担**（兜底条款）
- [ ] **卖方违约**的救济：解约、赔偿、违约金标准
- [ ] 买卖不破租赁的**交房时间**与租客不搬的责任
- [ ] 房屋质量瑕疵的**处理方式与费用承担**

## 资金安全（重点）

- [ ] 走**银行资金监管**，监管协议已签
- [ ] 监管账户户名是**买卖双方或银行**，不是中介个人
- [ ] 解付条件写进合同与监管协议
- [ ] 付款只打到**合同相对方本人账户**或监管账户
- [ ] 每笔付款有**转账凭证 + 收据**，备注写"房款"
- [ ] 卖方有抵押的：解押资金来源、解押完成时间、过户时间都写明

## 顺序检查

- [ ] **先网签备案，再付款过户**
- [ ] 每一步都有书面凭证（受理回执、新证、监管记录）

## 材料清单

- [ ] 卖方身份证、产权证原件
- [ ] 共有权人身份证与签字
- [ ] 查档结果打印件
- [ ] 购房合同（各方签字捺印）
- [ ] 定金/首付收据 + 转账凭证
- [ ] 网签备案表、过户受理回执、新不动产权证
- [ ] 资金监管协议与解付记录
- [ ] 卖方书面告知书（房屋状况、户口、租约、欠费）
- [ ] 物业费、水电燃气、供暖费**结清证明**与抄表照片
- [ ] 钥匙、门禁、车位移交签收单

---

**提醒**：口头承诺一律无效。凡是没写进合同、没有违约责任的承诺，都当作没说过。
