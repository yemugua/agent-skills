# 权属瑕疵与合同条款风险

## 一、权属瑕疵八类（脚本内 `TITLE_RISKS`）

| 瑕疵类型 | 常见表述 | 风险后果 |
|---|---|---|
| 一房二卖 / 重复抵押 | 一房二卖、二卖、重复抵押、多头抵押、再次出售 | 房款付了过户不了，或房子被卖两次 |
| 产权证缺失或未办证 | 无证、未办证、房本未下、未取得产权证 | 无法办理转移登记，交易根本落不了地 |
| 抵押未解除 | 抵押、查封、冻结、抵押未解、未解押 | 查封状态下房屋不能交易；带押过户风险高 |
| 共有权人未签字 | 共有、共有人、夫妻共有、继承、析产、一人名下 | 可能被认定无权处分或合同无效 |
| 租赁未披露 | 租客、承租、租赁未告知 | 买卖不破租赁，承租人有权继续承租 |
| 户口未迁出 | 户口、户籍、迁户、户口未迁 | 不影响过户，但影响上学、居住证、后续处置 |
| 房屋性质受限 | 经济适用、限售、央产、军产、小产权、两限房 | 需补缴土地价款或无法上市交易 |
| 面积或格局不符 | 面积、户型、格局、公摊、赠送面积、缩水 | 房款与实物不符，事后难以弥补 |

**核心动作**：到不动产登记机构**查档**。房本原件必须现场核对，登记信息必须查档核实，两件事都不能省。

## 二、定金与订金：不是一回事

- **定金**：有罚则。给付方不履行，**可要求双倍返还**；收受方不履行，**双倍返还**。但定金数额不得超过主合同标的额的 20%，超出部分不产生定金效力。
- **订金**：一般视为预付款，**只能原数返还**，没有罚则。

**风险点**：卖方或中介口头说"这是定金"，但合同里写的是"订金"或"意向金"——一旦发生争议按订金处理，**拿不到双倍返还**。所以合同里必须白纸黑字写明是哪个、金额多少、什么条件退还、违约怎么赔。

## 三、共有权人签字

婚后购买的房屋通常属于**夫妻共同财产**，即便只登记在一方名下。**只与登记人签合同、未取得配偶或其他共有人书面同意的买卖，可能被认定无效或构成无权处分**。

动作：查档看共有情况 → 让每一位共有人在合同上签字 → 签字时留存身份证件与本人到场证据。

## 四、租赁：买卖不破租赁

房屋在租赁期内出售的，**承租人有权继续承租**。所以：

- 卖方必须如实披露租约（租期、租金、押金、承租人是否优先购买权）
- 合同中写明**实际交房时间**、空置期租金由谁承担、租客不搬的违约责任
- 有承租人优先购买权的，**须提前书面通知**，否则买卖可能不生效

## 五、户口迁出

- 户口迁不走**不影响过户**，房屋所有权仍归你
- 但会带来长期麻烦：孩子上学、居住证办理、后续再卖时的买方顾虑
- 动作：**保留部分尾款至迁户完成**，约定**每日违约金**（例如每日 500 元），并在合同中写明"逾期超过 X 日，买方有权解除合同并要求赔偿"

## 六、口头承诺一律无效

卖方说的每一句"你放心"——自己有钱赎楼、户口三年内迁、渗水已经修好了——**都必须变成合同条款 + 违约责任**。写不进去的风险，就是将来追不回来的风险。
