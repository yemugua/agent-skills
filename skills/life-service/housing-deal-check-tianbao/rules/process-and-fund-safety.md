# 交易流程与资金安全

## 一、七步流程（脚本 `path_steps`）

| 步骤 | 做什么 | 为什么不能省 |
|---|---|---|
| 第 1 步 先查产权再谈钱 | 到不动产登记机构**查档**：权利人、共有情况、抵押与查封。**房本原件现场核对** | 这一步不做，后面所有谈判都可能是空谈 |
| 第 2 步 核资格与贷款 | 核实限购资格（社保/个税/户籍/名下房产）与贷款审批可能性 | **资格和贷款是签约的前提**，先确认再付定金 |
| 第 3 步 把风险写进合同 | 房屋已知瑕疵、户口迁出时间、租客情况、税费与中介费承担方，全部写成条款并约定违约责任 | **口头承诺一律无效** |
| 第 4 步 定金与首付安全 | 写清「定金」还是「订金」、金额、退还与双倍返还规则；**大额款走银行资金监管** | 直接付给卖方或中介，钱追不回来 |
| 第 5 步 网签备案与过户 | **先网签备案，再付款过户**，顺序不能反。带押过户要明确解押资金与时间衔接 | 跳过网签易出一房二卖、被查封无法登记 |
| 第 6 步 交房与尾款 | 结清物业水电燃气供暖，抄表留档；**预留尾款至卖方户口迁出**，约定每日违约金 | 交房时的欠费与户口是最后一道口子 |
| 第 7 步 发现重大瑕疵 | 卖方刻意隐瞒漏水、结构、违建、凶宅或一房二卖的，**可主张解约、赔偿损失** | 协商不成走投诉与诉讼 |

## 二、资金监管：最大的防骗点

**二手房交易应由买卖双方共同通过银行做资金监管**：买方把房款打入监管账户，银行按合同约定的条件（通常是"过户完成"）解付给卖方。

| 情形 | 风险 | 判定 |
|---|---|---|
| 走银行资金监管 | 房款由银行托管，按条件解付 | 通过 |
| 未走监管 | 直接付给卖方或中介，一旦对方挪用或房子出问题，钱很难追回 | **不通过** |
| 付给中介个人账户 | 常见骗局，收款主体与合同主体不一致 | **不通过** |

**核对要点**：
1. 监管账户的**户名必须是买卖双方或银行**，不是中介
2. 解付**条件写进合同与监管协议**（例如"过户登记完成当日"）
3. 监管手续费谁承担，写明
4. **任何要求你"打到他个人账户方便"的中介，直接换一家**

若坚持不走监管，应大幅提高首付比例、缩短付款节奏，并把过户与付款严格绑定。

## 三、解押与过户的衔接

房子有抵押（常见：卖方还有贷款）时，**解押与过户必须衔接**：

| 填的状态 | 含义 | 判定 |
|---|---|---|
| 已解押 / 已解除 / 已赎楼 / 抵押已注销 | 可以正常过户 | 通过 |
| 卖方自己存款赎楼 / 解押后过户 / 带押过户 | 需要买方或卖方资金配合赎楼 | **有风险** |
| 未填 | 不知道能不能衔接 | 待补正 |

**带押过户必须写清四件事**：
1. 解押**资金来源**（谁的存款、是否用买方首付）
2. 解押**完成时间**
3. 过户**时间**
4. 任一环节**失败的违约责任**（尤其：解押后过户失败，赎楼的钱算谁的）

**解押资金同样建议走监管**，不要直接给卖方赎楼。

## 四、交易阶段风险对照

| 阶段 | 风险等级 | 主要风险 |
|---|---|---|
| 看房、议价 | 低 | 信息不实、定金条款不清 |
| 已付定金/意向金 | **最高** | 房屋再被卖、被查封、卖方反悔。**此时应尽快网签并办资金监管** |
| 首付款 | 高 | 无网签备案、无监管，钱款失控 |
| 网签备案后 | 中低 | 需盯紧解押、贷款、过户时间节点 |
| 过户后 | 低 | 户口迁出、欠费结清、尾款支付 |
| 交房 | 低 | 钥匙门禁、物业费、水电燃气抄表 |

**未网签就过户**属于高风险操作，脚本会单独输出「跳过网签风险」。

## 五、发现重大瑕疵怎么办

卖方刻意隐瞒以下事实，可主张**解约与赔偿损失**：
- 漏水、结构改动、违建
- 凶宅（曾有人命亡且未披露）
- 一房二卖、重复抵押
- 户口、租赁、欠费未披露
- 权属存在争议或司法查封

路径：书面提出异议 → 要求补充披露或解约 → 向当地住建/不动产登记部门投诉 → 协商不成走诉讼。
