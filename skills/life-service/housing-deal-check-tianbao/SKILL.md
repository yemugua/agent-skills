# 二手房买卖风险与费用核查

二手房交易的钱是一笔一笔付出去的，但**风险是最后一天才暴露的**。等过户不成、房款要不回来时，再去研究合同就晚了。这个技能的作用是**在付定金之前把坑找出来**。

## 什么时候用

- 看好了房、准备付定金或签合同，想知道有没有坑
- 中介说"放心没问题"，但你不确定该核什么
- 房子有抵押、有租客、卖方户口没迁、还在还贷
- 中介费、契税到底要花多少，没人给书面清单
- 中介让你把钱打到他的个人账户"走他的账户方便"
- 打算贷款，但不知道审批不通过怎么办
- 已经付了款发现不对，想知道还能补救什么

## 怎么做

**第 1 步**：复制 `templates/二手房买卖信息采集表.md` 填写（产权人、共有人、抵押查封、是否核验房本、付款对象、是否走资金监管是关键项）。

**第 2 步**：跑脚本

```bash
python scripts/housing_deal_check.py 采集表.md --base 2026-10-05 --out 核查报告.md
```

**第 3 步**：按第九段七步走——**先查档核产权 → 核资格与贷款 → 把风险写进合同 → 定金与大额款走监管 → 先网签再过户 → 交房与尾款 → 发现重大瑕疵主张解约**。

## 三条最容易踩的规则

1. **钱不要直接付给中介或卖方**。二手房交易应由买卖双方通过**银行资金监管**完成，银行按约定条件解付。付给中介个人账户，一旦对方挪用或房子出问题，钱很难追回——这一条本技能直接判「不通过」。
2. **顺序不能反：先网签备案，再付款过户**。跳过网签直接过户，容易出现一房二卖、卖方被查封无法登记等问题。
3. **口头承诺一律无效**。卖方说"他自己有钱赎楼""户口三年内迁"——**没有写进合同条款并约定违约责任的口头承诺，在纠纷中很难被采信**。

## 边界与纪律

- 依**通用规则**整理，**不替代律师意见**
- **契税、增值税等税费标准、限购政策、贷款条件以当地税务、住建、不动产登记与银行口径为准**；本技能的契税 3% 只是首套常见口径的**参考估算**
- 报告金额为参考口径的**估算**，实际以合同约定、税务核算与银行核定为准
- 不预测房屋市场价格涨跌，也不预测诉讼结果
- **未填的一律不算通过**，只按已填内容判断
- 涉及身份、房产证号、账号等隐私信息，本地处理，不要外发
