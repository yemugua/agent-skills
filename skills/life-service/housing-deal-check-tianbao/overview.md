# 二手房买卖风险与费用核查 · 概览

## 管什么

- **产权与标的瑕疵**：产权人是谁、有几位共有人、是否需共有人签字、有无抵押查封、产权证是否已现场核验、卖方披露过哪些房屋问题（渗水、违建、凶宅、欠费、租约、户口）
- **合同条款风险**：定金与订金的区别、退还与双倍返还规则、租赁未披露的后果、户口迁出安排
- **费用测算**：契税（参考口径）、增值税及附加、中介服务费、贷款评估与登记公证费，并列出尚未计入的缺口
- **贷款与购房资格**：是否需要按揭、是否符合当地限购条件
- **资金安全**：是否走银行资金监管、款项付给谁、解押与过户如何衔接
- **交易进度风险**：定金 / 首付 / 网签 / 贷款 / 监管 / 过户 / 交房各阶段的不同风险点
- **证据清单**：六类材料哪些有、哪些缺，并给出补法

## 不管什么

- **不查房价**。不预测市场涨跌，不判断房子贵不贵，不做投资建议
- **不做权属鉴定**。不代替不动产登记机构的查档结果，产权状态以登记机构查档为准
- **不出具法律意见**。不替代律师；重大瑕疵、权属争议、诉讼主张请找专业律师
- **不管贷款代办**。不评估具体银行的放款额度与利率
- **不代签合同**。不替你与卖方、中介谈判

## 怎么用

1. 复制 `templates/二手房买卖信息采集表.md`，把能问到的都问清楚填进去（问不到就写"不清楚"，别猜）
2. 跑 `python scripts/housing_deal_check.py 采集表.md --base 2026-10-05 --out 核查报告.md`
3. 看第一段结论摘要里的「不通过」项——**这几条不解决就不要继续付钱**
4. 按第十段证据缺口速查补材料，按第十一段待办逐项落地
5. 签约当天带 `templates/二手房买卖核查操作卡.md` 逐项打勾

> 铁律：**未填的一律不算通过**。采集表空着，报告里那一项就是"待补正"，不会因为没填而变成"通过"。
