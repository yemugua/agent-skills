# 工伤与事故管理（work-injury）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《工伤保险条例》与事故管理要求，生成清单：事故报告与应急响应、工伤认定申请与材料、医疗救治与劳动能力鉴定、待遇支付与理赔、事故调查与整改。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 工伤
- 工伤认定
- 工伤保险
- 工伤理赔
- 劳动能力鉴定

## 三、工作流
1. 及时报告事故并应急响应
2. 提交工伤认定申请与材料
3. 安排医疗救治与劳动能力鉴定
4. 办理待遇支付与理赔
5. 开展事故调查与整改

## 四、核心内容（检查清单与判定）
《工伤保险条例》规定工伤认定、劳动能力鉴定与待遇支付程序；单位应及时报告与申请，并同步调查整改防范再发。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含事故报告与应急响应 | 报告 |
| Q2 | FAIL | 未含工伤认定申请与材料 | 认定 |
| Q3 | WARN | 未含医疗救治与劳动能力鉴定 | 鉴定 |
| Q4 | FAIL | 未含待遇支付与理赔 | 待遇 |
| Q5 | WARN | 未含事故调查与整改 | 整改 |

> 脚本 `work-injury_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python work-injury_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python work-injury_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
