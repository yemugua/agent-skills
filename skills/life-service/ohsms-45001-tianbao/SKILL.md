# ISO 45001 职业健康安全管理体系（ohsms-45001）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据ISO 45001:2018，生成职业健康安全管理体系搭建/审核清单：方针、风险机遇、目标、运行控制、应急与绩效监测，覆盖条款4-10。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- ISO45001
- 职业健康安全体系
- OHSAS
- 体系搭建
- 体系审核

## 三、工作流
1. 确立范围与适用法律法规
2. 制定OH&S方针与目标
3. 辨识风险机遇与策划措施
4. 运行控制（采购/承包方/应急）
5. 绩效监测与管理评审

## 四、核心内容（检查清单与判定）
ISO 45001:2018 采用高阶结构（附录SL），核心条款6.1.2危险源辨识、6.1.4措施、8运行控制、9绩效评价、10改进。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 缺方针/目标或法律法规清单 | 45001 5/6 |
| Q2 | WARN | 缺风险机遇辨识输出 | 6.1 |
| Q3 | FAIL | 运行控制（承包方/应急）缺失 | 条款8 |
| Q4 | WARN | 绩效监测指标未设 | 条款9 |
| Q5 | FAIL | 未含管理评审输入 | 条款9.3 |

> 脚本 `ohsms-45001_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python ohsms-45001_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python ohsms-45001_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
