# 小程序内容安全合规核查

## 适用场景

- 你正在做或已上线一个**内容类 / UGC 小程序**（日记、社区、论坛、短视频、音频、相册等），想在上线前或整改前系统核查内容安全合规。
- 典型对象：**落叶涧日记**这类含用户文字/图片/音频/时光胶囊的内容产品。
- 已做过隐私合规、ICP 备案、虚拟支付接入的，本技能补齐"内容"这一层合规。

## 何时调用

- 内容/UGC 小程序准备上线、版本迭代、被平台提示内容风险、或被举报/下架整改时。
- 需要一份可交付的《内容安全合规核查报告》作为整改清单与留存证据。

## 工作流程

1. **采集信息**：用 `templates/采集表.md` 让用户填写主体、内容形态、是否 UGC、审核机制、版权授权、诱导行为、举报机制、未成年人保护、违规历史。
2. **运行核查**：`python scripts/miniprogram_content_safety.py <采集表.md>` 输出报告。
3. **解读结论**：报告含结论摘要（通过/有风险/不通过）、分项核查、阻断项与风险待办、标准整改清单、边界声明。
4. **整改闭环**：按"阻断项（必须处理）→ 风险待办（建议处理）→ 历史违规闭环"推进，整改后重跑核查。

## 核查维度（6 大域）

1. **内容审核机制**：先审后发 vs 先发后审、是否接入机器/人工审核、是否接入微信内容安全接口（msgSecCheck / imgSecCheck / mediaCheckAsync）、违规词库。
2. **版权与知识产权**：音频/音乐版权授权（高频侵权点）、图片/视频授权、字体与转载授权。
3. **诱导分享与诱导行为**：利诱分享、强制分享、诱导下载/添加（微信明确禁止，触发即可能封禁分享接口乃至下架）。
4. **未成年人内容保护**：青少年模式、内容过滤、防沉迷、监护人同意。
5. **UGC 平台责任**：举报入口与处置 SOP、违禁内容下架、留存记录。
6. **违规与下架历史**：既往违规是否整改闭环，避免主体连带处罚。

## 关键判断规则

- **UGC / 内容型小程序**：未接入内容审核机制、未接入微信内容安全接口、未建立举报处置机制 → **阻断（不通过）**。
- **含音频/音乐无版权授权** → **阻断**（侵权下架/赔偿高频）。
- **存在诱导分享/利诱** → **阻断**。
- **非先审后发、无违规词库、图片视频未授权、未成年人保护缺失、有违规历史** → **风险（建议处理）**。

## 资源

- `templates/采集表.md`：信息采集模板。

## 边界

- 依据《网络安全法》《网络信息内容生态治理规定》及微信小程序平台运营规范、《微信外部链接内容管理规范》公开规则整理。
- **不替代监管规定、平台规则与正式法律意见**，重大场景请咨询律师。
- 违禁内容（涉政、涉黄、暴恐、赌博、诈骗、谣言、侵权）一经发现应立即下架并留存记录。
