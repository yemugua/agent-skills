# 内推与试用期管理（referral-probation）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：生成内推与试用期管理清单：内推流程与激励、质量把控（筛选/背调），及试用期考核标准、转正与解除合规（劳动合同法）。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 内推
- 员工内推
- 内推激励
- 试用期管理
- 试用期考核
- 转正

## 三、工作流
1. 建立内推流程与激励规则
2. 内推质量把控（初筛/背调）
3. 设定试用期考核标准
4. 试用期评估与转正/解除
5. 合规留痕与归档

## 四、核心内容（检查清单与判定）
内推应设激励并严控质量；试用期管理须符合《劳动合同法》关于期限、工资与解除举证的规定，避免违法解除。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未设内推流程与激励 | 内推 |
| Q2 | WARN | 未含内推质量把控（筛选/背调） | 质量 |
| Q3 | FAIL | 未含试用期考核标准 | 考核 |
| Q4 | WARN | 未含转正/解除合规（提前通知/举证） | 合规 |

> 脚本 `referral-probation_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python referral-probation_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python referral-probation_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
