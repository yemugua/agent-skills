# 防坠落与高处作业防护（fall-protection）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据 GB 6095 安全带与 GB 30871 高处作业要求，生成清单：坠落危险源辨识、安全带与安全绳选型、生命线与挂点承载力、临边洞口防护、作业许可与监护。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 防坠落防护
- 安全带使用
- 高处作业防护
- 生命线设置
- 临边洞口防护

## 三、工作流
1. 开展坠落危险源辨识
2. 选定安全带与安全绳
3. 设置生命线并验算挂点承载力
4. 落实临边洞口防护
5. 执行作业许可与现场监护

## 四、核心内容（检查清单与判定）
高处坠落居事故首位。安全带须高挂低用并系在牢固构件上，生命线与挂点必须验算承载力；只发安全带而不做临边防护、不监护，等于没有防护。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含坠落危险源辨识 | 辨识 |
| Q2 | FAIL | 未含安全带与安全绳选型 | 安全带 |
| Q3 | FAIL | 未含生命线与挂点承载力 | 生命线 |
| Q4 | WARN | 未含临边洞口防护 | 临边 |
| Q5 | WARN | 未含作业许可与监护 | 监护 |

> 脚本 `fall-protection_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python fall-protection_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python fall-protection_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
