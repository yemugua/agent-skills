# 作业安全分析 JSA（job-safety-analysis）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据作业安全管理实践与GB 30871（特殊作业），生成JSA（作业安全分析）表：步骤分解、危害识别、控制措施与许可衔接。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- JSA
- 作业安全分析
- 工作安全分析
- 作业许可
- 危险作业
- 班前交底

## 三、工作流
1. 分解作业为连续步骤
2. 每步识别潜在危害
3. 评估风险与现有控制
4. 补充控制措施（消除-替代-工程-管理-PPE）
5. 与作业许可/监护衔接

## 四、核心内容（检查清单与判定）
GB 30871 规定动火、高处、受限空间等特殊作业需办理作业票并风险辨识；JSA将作业分解逐步分析，是许可前的风险预知工具。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 作业未分解为步骤 | JSA方法 |
| Q2 | FAIL | 步骤未识别危害 | 危害识别 |
| Q3 | WARN | 缺控制措施或层级 | 控制 |
| Q4 | FAIL | 特殊作业未衔接许可/监护 | GB 30871 |
| Q5 | WARN | 无人员资质/交底确认 | 人员 |

> 脚本 `job-safety-analysis_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python job-safety-analysis_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python job-safety-analysis_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
