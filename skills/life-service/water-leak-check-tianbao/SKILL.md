# 房屋漏水责任核查

漏水是家里最高发的邻里纠纷，但绝大多数人栽在同一件事上：**先找人修，忘了固定证据**——修完现场没了，责任立刻变成各说各话。

## 什么时候用

- 自己家天花板/墙面渗水，怀疑是楼上装修、忘关水或防水被破坏
- 新交房不久漏水，想搞清楚还能不能找开发商保修
- 公共管道、屋面、外墙漏水，物业说"要业主表决动维修资金"就一直拖
- 楼上推说是老管道老化、自然渗水，你不知道该不该做渗漏原因鉴定
- 租的房子漏水，房东拖延不修，怕扩大损失最后自己掏钱
- 已经修了，但修得比漏水贵得多，不知道超出的部分能不能要回来

## 怎么做

**第 1 步**：复制 `templates/房屋漏水信息采集表.md` 填写（漏填任何一项都会按"待补正"处理）。

**第 2 步**：跑脚本

```bash
python scripts/water_leak_check.py 采集表.md --base 2026-10-05 --out 核查报告.md
```

**第 3 步**：按第八段"待办补正动作"执行。

## 三句话定性的核心规则

1. **责任先分三支**：楼上住户有可归责行为（装修破坏防水层、管道改造、忘关水龙头、地漏堵塞等）→ 楼上业主承担**相邻关系/侵权责任**；漏水点在公共管道、屋面、外墙、下水立管等**公共部位** → **物业服务人 / 业主共有部分**的维修责任，大额可走**住宅专项维修资金**（需业主表决）；保修期内且属施工质量或防水缺陷 → **开发商**承担建设工程质量保修责任。三者混合的，靠鉴定划分比例。
2. **保修期自竣工验收合格之日起算**，其中屋面防水工程、有防水要求的卫生间/房间和外墙面防渗漏的最低保修期为 **5 年**；电气管线、给排水管道、设备安装、装修工程一般为 **2 年**（具体年限范围以现行规定及当地住建口径为准）。过了保修期不等于没得主张——能证明**原始施工缺陷**仍在的仍可依法主张。
3. **物业报修记录是全部动作的支点**：它同时证明漏水客观存在、发生时间、以及你已经尽到通知义务。没有书面到场记录（工单号、派单、现场照片、签到），后面谈赔偿和打官司都很被动。

## 输入 / 输出

| | 内容 |
|---|---|
| 输入 | 采集表 Markdown（部位 / 竣工日期 / 楼上原因 / 公共部位 / 报修与到场 / 鉴定 / 损失 / 维修范围 / 房屋性质） |
| 输出 | 九段报告：结论摘要 / 责任归属 / 保修期与开发商 / 取证与鉴定 / 损失核算 / 交涉路径与时效 / 租房与特殊情形 / 待办 / 边界 |
| 退出码 | 0 正常；2 关键信息缺失（给提示串，不崩） |

## 边界与纪律

- 依**通用规则**整理，**不替代律师意见**；责任比例与赔偿是否获支持**由司法机关认定**
- 保修年限范围、住宅专项维修资金的动用条件与表决比例**各地口径不同，以当地住建（房管）主管部门口径为准**
- 租金/住宿损失、误工费、精神损害通常**难以全额支持**，本表如实提示，不作结果承诺
- **未填的一律不算通过**，只按已填内容判断
- 擅自破坏现场导致无法鉴定的，主张会大幅削弱——查勘定损前不要动现场
- 不预测诉讼与鉴定结果
