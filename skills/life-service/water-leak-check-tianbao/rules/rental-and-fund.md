# 租房、维修资金与物业关系

## 一、租房场景

- **承租人义务**：发现漏水应**及时通知房东并留痕**（微信/短信均可），同时报物业查勘。未及时通知导致损失扩大的，**扩大部分可能由承租人自担**。
- **维修义务主体**：一般看租赁合同与当地规定——通常出租人负有出租房屋及附属设施的维修义务（当事人另有约定的从约定）；**承租人因使用不当造成损坏的，由承租人承担**。
- **第一步永远是固定**：先拍照、关水阀、断相关电源、报物业，再谈谁修谁赔。
- 房东拖着不修且损失持续的：书面催告并保留记录，必要时把损失清单与修复方案一并提交，作为后续主张的依据。

## 二、住宅专项维修资金（公共部位）

- 公共管道、屋面、外墙、下水立管等**公共部位**的维修，属物业服务人/业主共有部分的责任，金额较大的可依法申请使用**住宅专项维修资金**。
- 动用需经**业主表决程序**（表决比例与流程按当地规定及管理规约），物业未启动的，可提请业主委员会或向住建（房管）主管部门、街道反映。
- 维修顺序建议：先止损→物业编制方案与预算公示→业主表决→施工→验收结算。
- 别把"走维修资金"当成无限期拖延的理由：维修资金程序走完之前，物业的紧急止损义务不能免。

## 三、物业关系与常见坑

| 坑 | 说明 |
|---|---|
| 以拒交物业费对抗 | **两个独立的法律关系**。漏水赔偿与物业费不能互相抵扣或拒绝，拒交的物业可另行主张，还可能成为你违约的把柄。要赔偿就单独谈、单独诉 |
| 只打电话不取证 | 口头报修没有工单号、没有到场记录，等于没报 |
| 混同责任主体 | 向"物业"索赔本该由楼上或开发商承担的损失，主体错位 |
| 先修后谈 | 现场没了，责任与损失比例全靠猜 |
| 把租金/住宿当必得项 | 通常难全额支持，别写进主张书当筹码 |
| 忽视书面通知 | 没通知＝没尽减损义务，对方可以"你没叫我"为由砍掉扩大损失 |

## 四、阶梯路径（业主版）

1. 止损：关水阀、断相关电源、挡水擦干，防损失扩大。
2. 固定证据：拍漏水点与发展过程（带时间）、受损财产清单与照片、**向物业报修并索要到场记录/工单号**，同步书面通知楼上住户。
3. 书面要求责任方（开发商／楼上业主／物业）修复并赔偿，写明金额构成与期限，索要回执；楼上推诿的可请社区/居委会调解。
4. 向**社区/居委会**、人民调解委员会申请调解；公共部位可请物业启动住宅专项维修资金程序（业主表决）。
5. 向**住建（房管）主管部门**、**12345** 反映物业怠于履职；保修期内的同时投诉开发商不履行保修义务。
6. 调解不成的，按相邻关系/侵权主张**停止侵害、排除妨碍、恢复原状、赔偿损失**起诉；必要时申请诉前保全或先予执行（诉讼时效 3 年）。

（承租人的路径把第 2~3 步换成"向房东主张维修义务并索赔"，其余一致。）
