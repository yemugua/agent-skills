# 取证、鉴定与损失核算

## 一、证据清单（按重要性）

| 证据 | 为什么关键 |
|---|---|
| **物业报修与到场记录** | 最核心。工单号、派单截图、到场时间、现场照片、处理意见，能证明漏水客观存在、发生时间与已通知义务人 |
| 漏水点与发展过程影像 | 带时间水印；漏水点、渗水痕迹扩展方向、受损财产逐张拍，中途录一段连续视频 |
| 楼上/邻居沟通记录 | 微信、短信、通话录音（合法取得），证明对方知情、知情后不纠 |
| 渗漏原因鉴定报告 | 混合原因划分责任比例的核心证据 |
| 损失清单 | 修复报价（**至少两家书面报价**）、受损物品购买凭证、损失照片、维修记录与发票 |
| 房屋与竣工文件 | 竣工验收合格/交付日期，用于算保修期 |
| 租房相关 | 租赁合同、付款凭证、通知房东的记录（租房场景） |

## 二、渗漏原因鉴定要不要做

- **该做的情形**：楼上不认、原因不明、混合原因、损失较大（修复费＋财产损失明显超过鉴定费）。
- **先算这笔账**：鉴定费一般**先由申请方垫付**，最终由责任方按责任比例负担。若损失远小于鉴定费，先做止损与书面交涉更划算。
- **别做的情形**：现场已被修复或破坏、损失极小、对方已经书面承认全部责任。
- **红线**：擅自拆改、破坏现场导致无法鉴定的，主张会大幅削弱——查勘定损前不要动现场。

## 三、损失核算

| 项目 | 口径 |
|---|---|
| 修复费 | 只限漏水及直接受损部位的必要修复；**先拍照、再留报价、最后施工** |
| 财产损失 | 家具、电器、装修、物品——受损照片＋清单＋购买凭证或折旧估算 |
| 必要鉴定费 | 属于为确定损失与责任支出的合理费用，可一并主张 |
| 其他直接费用 | 搬运、临时接水、必要的紧急处理 |
| 租金/住宿 | **一般难以获得全额支持**，需证明必要性与实际发生（合同、付款、发票、时长对应）；有心理预期 |

**维修范围红线**：顺手翻新、换主材、美化项目属**自行扩大范围**，扩大部分通常不被支持。

## 四、赔偿请求怎么提

1. 主张内容：修复费、财产损失、必要的鉴定费（另可主张逾期不修导致的扩大损失）。
2. 租金/住宿、误工费、精神损害：如实提示风险，**不作结果承诺、不打包进必得金额**。
3. 金额按已发生＋必要待发生列，别把"心里舒服"的项目算进去，容易被整体质疑。

## 五、时效

- 民事诉讼时效 **3 年**，自知道或应当知道权利被侵害及义务人之日起算（实务中多以发现漏水之日确定）。
- **时效中断**：书面催告、投诉、调解申请、起诉均可中断，中断后重新起算 3 年。
- 报修与索赔要趁早：拖久了会造成证据灭失、现场被修复、责任无法划分——这比时效本身更容易翻车。
