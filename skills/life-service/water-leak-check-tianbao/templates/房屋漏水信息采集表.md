# 房屋漏水信息采集表（复制填写）

> 没填的项目一律按"待补正"处理，不会自动算通过。填完保存为 `采集表.md` 后运行脚本。

## 一、基本事实

| 字段 | 值 |
|---|---|
| 漏水部位 | 例如：卫生间及相邻客厅天花板 |
| 房屋性质 | 例如：自有商品住宅 / 承租房屋 |
| 发现漏水日期 | 例如：2025-06-18 |
| 竣工验收合格日期 | 例如：2016-08-25（算保修期用，不填无法判断开发商责任） |
| 漏水点是否属公共部位 | 是（下水立管、屋面、外墙、公共管道）/ 否（户内）/ 不清楚 |
| 楼上住户原因 | 例如：楼上装修破坏防水层、忘关水龙头、地漏堵塞、管道改造、无 |

## 二、原因与取证

| 字段 | 值 |
|---|---|
| 漏水原因是否明确 | 是 / 否 / 不清楚 |
| 漏水原因已经查明为 | 例如：楼上装修破坏防水层导致楼板渗水 |
| 是否已做渗漏原因鉴定 | 是 / 否 |
| 鉴定费金额 | 例如：8000 元 |
| 是否已向物业报修 | 是（工单号 ___）/ 否 |
| 物业是否到场并记录 | 是（有派单/照片）/ 否 / 不清楚 |
| 是否已书面通知物业与楼上 | 是 / 否（可写通知对象与时间） |
| 已通知对象 | 例如：物业张三、楼上李四 |
| 是否已经找社区居委会调解 | 是 / 否 |
| 证据清单 | 例如：漏水照片 12 张、连续视频 1 段、物业工单截图 |

## 三、损失与维修

| 字段 | 值 |
|---|---|
| 修复费用 | 例如：12000 元（已取两家书面报价） |
| 财产损失金额 | 例如：3200 元（衣柜背板、天花板涂料） |
| 其他损失金额 | 例如：500 元（临时接水与搬运） |
| 租金住宿损失金额 | 例如：6000 元（期间在外住宿） |
| 是否已维修 | 已修复 / 未修复 / 部分修复 |
| 是否扩大维修范围 | 否 / 是（说明顺手做了什么） |
| 是否可动用住宅专项维修资金 | 是 / 否 / 不清楚 |
| 维修资金业主表决情况 | 已表决通过 / 未表决 / 不涉及 |
| 是否以拒交物业费主张权利 | 是 / 否 |
| 是否已向责任方主张 | 是 / 否（说明对象与结果） |
