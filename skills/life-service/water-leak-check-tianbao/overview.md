# 房屋漏水责任核查（water-leak-check）

一句话：漏水先别吵架也别急着修，先弄清**漏的是谁的责、还过没过保修期、物业该不该管、能要回多少**。

## 解决的问题

- 自家天花板/墙面渗水，不知道是楼上、开发商还是物业的锅
- 新交房漏水，想确认还能不能找开发商保修
- 公共部位漏水，物业一直拿"要业主表决"拖着
- 楼上不认，到底要不要花几千块做渗漏原因鉴定
- 租房漏水房东拖延，怕扩大损失最后自己掏
- 修完发现修得比漏水贵得多，超出的部分能不能要回来

## 怎么用

```bash
python scripts/water_leak_check.py 采集表.md --base 2026-10-05 --out 核查报告.md
```

采集表复制 `templates/房屋漏水信息采集表.md` 填写；加 `--json` 直接拿结构化结果。

## 输出九段

结论摘要 / 责任归属判定 / 保修期与开发商责任 / 取证与鉴定 / 损失核算与赔偿范围 / 交涉路径与时效 / 租房与特殊情形 / 待办补正动作 / 边界与纪律。

## 三条核心规则

1. 责任三分支：楼上住户可归责→楼上业主相邻关系/侵权；公共部位→物业服务人/业主共有部分（可走住宅专项维修资金）；保修期内施工质量或防水缺陷→开发商。
2. 保修期自**竣工验收合格之日**起算，屋面防水、有防水要求的卫生间/房间和外墙面防渗漏最低 **5 年**，管线与装修一般 **2 年**；过保但能证明**原始施工缺陷**仍在的仍可主张。
3. **物业报修与到场书面记录**是全部动作的支点，同时证明漏水存在、发生时间、已尽通知义务。

## 纪律

不替代律师意见；保修年限、维修资金动用条件与表决比例各地不同，以当地住建（房管）主管部门口径为准；租金/住宿、误工、精神损害通常难全额支持，如实提示、不作结果承诺；未填一律不算通过。
