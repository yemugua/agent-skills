# 专职消防队建设（full-time-fire-brigade）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《消防法》与《企业专职消防队组织条例》，生成专职消防队清单：建队法定情形、人员编配与执勤、装备配备、训练演练与消防救援机构联勤联动。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 专职消防队
- 企业消防队
- 建队标准
- 专职队装备
- 消防队训练
- 联勤联动

## 三、工作流
1. 明确建队法定情形（大型危化/人员密集/重点单位）
2. 人员编配与24h执勤战备
3. 装备配备（车辆/器材/个人防护）
4. 训练与拉动演练（体能/技战术）
5. 与消防救援机构联勤联动

## 四、核心内容（检查清单与判定）
《消防法》第三十九条规定大型核设施、大型发电厂、生产储存易燃易爆危险品大型企业等应建立专职消防队；专职队应24h执勤并纳入统一调度。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未明确建队法定情形（大型危化/人员密集/重点单位） | 建队 |
| Q2 | FAIL | 未含人员编配与执勤（24h战备） | 人员 |
| Q3 | WARN | 未含装备配备（车辆/器材/个人防护） | 装备 |
| Q4 | FAIL | 未含训练与演练（体能/技战术/拉动） | 训练 |
| Q5 | WARN | 未含与消防救援机构联勤联动 | 联动 |

> 脚本 `full-time-fire-brigade_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python full-time-fire-brigade_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python full-time-fire-brigade_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
