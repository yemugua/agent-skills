# 体测达标

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 给出逐项差距测算与周期可行性判定 | 编造或保证某个具体的达标分数线 |
| 说明各项目的训练方法与提升节奏 | 诊断心脏病、哮喘或任何疾病，也不能做体检结论 |
| 给考前一周的安排与流程熟悉清单 | 建议服用药物、功能饮料、兴奋类物质或任何补剂 |
| 提示停练红线与就医信号 | 承诺练多久一定达标、一定拿优秀 |
| 输出分项差距排序与训练周计划 | 建议隐瞒病史参加测试或带病硬测 |

**必须停止训练并转交专业人士的情况**

- 运动中出现胸闷胸痛、心悸、头晕、眼前发黑
- 有心血管、呼吸系统疾病史，或医生曾限制运动强度
- 长跑中出现异常气短、喘息不止、口唇发紫
- 肌肉关节急性损伤、肿胀、活动受限
- 发热、感染期间，或身体明显不适时

**关于达标标准**：本技能不提供具体的达标分数线。各年级、各年龄段、各单位的标准不同，且会调整，请以学校或单位当年公布的《国家学生体质健康标准》执行文件为准，本技能只负责用你填进来的标准值做差距测算。

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「体测怎么练能及格」 | 用，先填当前成绩与目标值 |
| 「还有两周体测还来得及吗」 | 用，给周期可行性判定 |
| 「1000 米跑不下来怎么办」 | 用，给分阶段跑法 |
| 「引体向上一个都做不了」 | 用，给退阶训练法 |
| 「立定跳远怎么提高」 | 用 |
| 「体测标准是多少分」 | 不做标准查询，请查当年公布的执行文件 |
| 「体测前一周怎么安排」 | 用，给减量与流程熟悉 |
| 「跑完胸口难受」 | 只作就医提示 |
| 「帮我算一下我能拿多少分」 | 用，但需你提供标准值与成绩 |

## 三、完整工作流

1. **先确认标准值**：从学校或单位当年公布的执行文件里找到对应项目的达标值，填进来。不要用网上流传的旧版本。
2. **测当前成绩**：按体测的实际流程测一遍，记录真实成绩。用平时随意测的成绩会高估自己。
3. **算差距并排序**：按 `rules/分项训练方法.md` 的口径算每项差距百分比，差距最大的排最前。**顺序按差距从大到小排，不要按项目顺序排。**
4. **判周期可行性**：对照剩余周数与每项所需周数，明确哪些项目来不来得及。来不及的项目要调整预期，不能给乐观方案。
5. **定训练重点**：长跑是权重最高、提升最慢的项目，即使差距不是最大也要优先安排。
6. **排周计划**：每周 3-4 次，有氧 2 次、力量 2 次、专项 1 次，考前一周减量。
7. **考前流程熟悉**：考前 3 天熟悉场地与流程，考前一天不练强度。

## 四、核心规则与要件库

生成训练计划或可行性判断前，**必须先读**：

- `rules/分项训练方法.md`：各项目的训练方法、提升节奏、所需周期参考、常见错误。
- `rules/周期安排与考前一周.md`：周期可行性判定、每周安排、减量周、考前一周与当天流程。

不得承诺达标。差距过大而周期不足时，必须明确说明「来不及」并给出调整预期的建议，这是本技能最重要的判定原则。

## 五、脚本用法

```
python scripts/fitness_test_check.py --file case.json
python scripts/fitness_test_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：每个项目的名称、类型（越小越好或越大越好）、当前成绩、目标值、单位，以及距考试周数、每周训练次数 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--json` | 以 JSON 输出 |
| `--selftest` | 运行自检 |

脚本输出逐项差距百分比、**按差距从大到小排序**的项目清单、每项所需周期与可行性判定、训练周计划。**判定顺序是先查真实缺陷（周期不足的不达标项、差距过大项、训练频次不足），再看信息是否完整**；距考试只剩 3 天而某项差距 30% 时，会直接判为「来不及」而不是待确认。

## 六、人工确认清单

- [ ] 达标值取自当年公布的执行文件，没有用旧版本
- [ ] 当前成绩是按体测实际流程测的，不是随意测的
- [ ] 逐项差距已算出并按从大到小排序
- [ ] 每项所需周期与剩余周数已比对，来不及的项已调整预期
- [ ] 长跑已优先安排，即使差距不是最大
- [ ] 每周训练次数在 3-4 次，考前一周已安排减量
- [ ] 已核对自身健康情况，无胸闷心悸头晕等不适
- [ ] 考前一天不练强度，流程与场地已熟悉

## 七、最常见的坑

1. **拿旧标准当现行标准**：达标值每年可能调整，用网上流传的旧版本测算，结果会差一大截。
2. **用随意测的成绩当基线**：体测当天有流程、有紧张、有天气影响，平时随意测的成绩普遍偏高。
3. **考前两周才开始练**：长跑、引体向上这类项目需要 8 周以上的积累，两周只能熟悉流程，不能实质提升。
4. **只练最差那一项**：体测看总分或多项合格，把时间全砸在一项上会拉低其他项。
5. **考前一天还练强度**：考前减量比加练更重要，疲劳上场成绩必然打折。
6. **长跑一上来就冲**：1000/800 米最忌讳前 200 米冲太快，后半程崩掉反而更慢。
7. **引体向上只做引体**：一个都做不了时，直接做引体等于零刺激，要先做退阶动作。
8. **坐位体前屈猛压**：弹震式压腿会触发肌肉对抗，反而推不下去，要缓慢呼气渐进。

## 八、边界与免责

本技能提供体测项目的差距测算、周期可行性判断和训练方法参考，不构成医学诊断、体检结论或达标承诺。**具体达标标准、评分办法以免测与补测规定，以学校或单位当年公布的《国家学生体质健康标准》执行文件为准。** 训练强度因年龄、基础、健康状况而异，有心血管或呼吸系统疾病史者请先咨询医师。出现胸闷胸痛、心悸、头晕、异常气短等情况，请停止训练并就医。
