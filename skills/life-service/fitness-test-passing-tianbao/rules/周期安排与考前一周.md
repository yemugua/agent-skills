# 周期安排与考前一周

## 一、周期可行性判定

| 情形 | 判定 | 建议 |
|---|---|---|
| 剩余周数 ≥ 所需周期 | 可达标 | 按计划系统训练 |
| 剩余周数略少于所需周期（差 2 周内） | 需冲刺 | 提高频次到每周 4 次，优先长跑与权重高的项目 |
| 剩余周数不足所需周期一半 | 不乐观 | 调整预期，把时间投向差距小、见效快的项目 |
| 剩余不足 2 周且某项差距超 5% | 来不及 | 该项只做流程熟悉与稳定发挥，不做提升预期 |

**来不及的项目必须明确写出来，不粉饰。** 给一个两周内提升 30% 的方案，等于让用户带着错误预期上场。

## 二、每周安排模板

| 星期 | 内容 |
|---|---|
| 周一 | 有氧：轻松跑 25-35 分钟 |
| 周二 | 力量：下肢与核心，深蹲、平板、仰卧起坐或引体退阶 |
| 周三 | 休息或轻量活动 |
| 周四 | 专项：间歇跑或测项目模拟 |
| 周五 | 力量：上肢与背部，划船类、握力 |
| 周六 | 长距离轻松跑或综合模拟测试 |
| 周日 | 休息 |

每周 3-4 次是底线，低于 3 次时进步很慢。每 4 周安排一个减量周，训练量降到 60-70%。

## 三、考前一周

| 时间 | 安排 |
|---|---|
| 考前 7-5 天 | 训练量降到平时 50-60%，保持 2 次轻松活动 |
| 考前 4-3 天 | 熟悉场地与流程，做 1 次完整的流程模拟 |
| 考前 2 天 | 只做轻量活动 20 分钟，不做强度 |
| 考前 1 天 | 完全休息，检查装备与证件，早睡 |
| 当天 | 提前到场热身，按流程走，不临时改策略 |

**考前减量比加练更重要**，疲劳上场成绩必然打折。

## 四、当天流程

1. 提前 30-40 分钟到场。
2. 热身：慢跑 5-10 分钟 + 动态拉伸 5 分钟 + 1-2 次短距离加速跑。
3. 先做技术类项目（跳远、体前屈），把长跑放最后。
4. 长跑前再补一次简短热身，避免等待时间过长身体凉掉。
5. 每项结束后及时保暖，等待期间不要坐着不动。

## 五、停练红线

出现以下任一项，停止训练并就医评估：

- 运动中出现胸闷胸痛、心悸、头晕、眼前发黑
- 长跑中异常气短、喘息不止、口唇发紫
- 急性损伤、关节肿胀、活动受限
- 发热或感染期间
- 医生曾明确限制运动强度

## 六、常见误区

| 误区 | 事实 |
|---|---|
| 考前突击能大幅提升 | 长跑与引体需要 8 周以上积累 |
| 只练最差那一项 | 体测看多项，全砸一项会拉低其他项 |
| 考前一天加练 | 减量比加练重要 |
| 长跑前 200 米冲 | 后半程崩掉反而更慢 |
| 引体做不了就一直做引体 | 需要退阶动作建立力量 |
| 体前屈猛压 | 弹震式会触发肌肉对抗 |
| 靠功能饮料或药物提成绩 | 不推荐，且有健康风险 |

## 七、禁止的做法

- 为应付体测采取极端节食或脱水
- 服用药物、兴奋类物质或来源不明的补剂
- 隐瞒病史参加测试
- 带病或发热期间硬测
- 考前一周仍安排高强度间歇
