# 招聘评分规则库

> 维度与权重为通用基线，按岗位裁剪后写入评分表，一个招聘周期内不得中途改规则。

## 1. 七维度评分锚点（0-5 分）

| 维度 | 0 分 | 3 分 | 5 分 |
|---|---|---|---|
| 硬性资质 | 必需项缺失 | 必需项达标 | 达标且有岗位直接相关的加分资质 |
| 专业经验 | 无相关经验 | 同岗位 2 年+ | 同岗位 5 年+ 且经历过完整项目周期 |
| 能力证据 | 无任何成果描述 | 有成果但不可验证 | 有数据/作品/案例可追溯 |
| 稳定性 | 1 年内 3 次以上跳槽 | 平均 2-3 年 | 5 年+ 且每次跳槽有清晰逻辑 |
| 动机匹配 | 海投、职业规划混乱 | 方向基本一致 | 规划清晰且与岗位路径吻合 |
| 沟通协作 | 材料逻辑混乱 | 表达清楚 | 有跨部门协作/带人证据 |
| 成长潜力 | 无学习轨迹 | 有持续学习 | 主动习得与岗位相关的新技能并有产出 |

## 2. 权重方案

| 方案 | 适用 | 权重分布（1-7 维度） |
|---|---|---|
| default | 通用 | 15/25/20/10/10/10/10 |
| tech | 技术岗 | 10/25/30/10/5/10/10 |
| mgmt | 管理岗 | 10/25/15/15/15/10/10 |
| startup | 初创岗 | 10/20/20/10/15/5/20 |

## 3. 分档口径

| 档 | 总分 | 动作 |
|---|---|---|
| S | ≥90 | 48h 内首约 |
| A | 80-89 | 正常约，验证匹配 |
| B | 70-79 | 批量面，比价择优 |
| C | 60-69 | 备选，关键要素达标才约 |
| D | <60 | 归档人才库 |

## 4. 红线清单（发布 JD 前写明）

1. 法定必需证书缺失
2. 关键信息造假
3. 竞业限制无法规避
4. 到岗条件不满足（地点/班次/出差）
5. 利益冲突

## 5. 校准机制

- 两名以上评估人**独立打分**后再对分
- 分差 >10 分的维度必须复述证据对齐
- 面试后回填实际表现
- 每季度复盘：分档与试用期通过率是否匹配，不匹配就调维度/权重

## 6. 合规底线

- 评分维度不得包含性别、年龄、地域、婚育、宗教等与胜任无关因素
- 候选人个人信息仅用于本次招聘，按最小必要原则留存
- 背调须获候选人授权并走合规渠道
