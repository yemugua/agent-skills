# 洗衣机清洗规则

生成方案前先读此表。

## 一、清洗频率

| 项目 | 频率 |
|---|---|
| 绒毛滤网 | 每 2–4 周清一次 |
| 筒自洁（空转） | 每 1–2 个月 |
| 胶圈 / 分配盒擦拭 | 每周或见霉即擦 |
| 长期不用 | 断电、排空、敞开 |

## 二、标准清洗顺序（强制）

| 序 | 步骤 | 不合格原因 |
|---|---|---|
| 1 | 断电 | 带电清滤网误启动夹手 |
| 2 | 清滤网 | 不排残水清绒，异味源留 |
| 3 | 加清洗剂 | 不剂只水，去垢除菌不足 |
| 4 | 筒自洁 | 不跑程序，筒壁垢未除 |
| 5 | 擦胶圈 | 胶圈闷霉，下次又臭 |
| 6 | 通风 | 关舱门，霉斑复发 |

## 三、清洗剂用法

- 滚筒：粉 / 块按包装量倒入**筒内**（非衣物格），选高温筒自洁。
- 波轮：加水至高水位，化开清洗剂后浸泡再运转。
- 严禁用普通洗衣液替代槽清洗剂。

## 四、禁区

- 不拆内筒、不动电机 / 排水泵。
- 异响、漏水、不排水转维修。

> 不合格带原因：「未断电：带电清滤网有触电与误启动风险」。
