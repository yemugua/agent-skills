# 洗衣机清洗

## 1. 硬边界（能做什么 / 不能做什么）

| 能做 | 不能做（转专业人士） |
|---|---|
| 清绒毛滤网、加剂筒自洁 | 拆内筒、动电机 |
| 擦门封胶圈、分配盒 | 更换排水泵 / 电路维修 |
| 日常除味保养 | 漏水严重、异响的硬件故障 |

异响、漏水、不排水，转维修。

## 2. 什么时候用

| 用户说法 | 用不用 |
|---|---|
| 洗衣机有酸臭味 | 用（筒自洁除垢除菌） |
| 衣服洗完有毛屑黑渣 | 用（清滤网 + 筒洗） |
| 长期没洗过洗衣机 | 用（立即深度洗） |
| 洗衣机异响漏水 | 不用（硬件故障） |

## 3. 完整工作流

1. **断电**：拔插头，安全操作。
2. 拉开右下角 / 左下角滤网盖，拧开滤网排残水，清掉绒毛硬币。
3. 分配盒抽出冲洗，胶圈翻起擦净霉斑。
4. 筒内倒入洗衣机槽清洗剂（粉 / 块按说明），选「筒自洁 / 高温」程序空转。
5. 程序结束开盖通风，擦干胶圈，留缝晾干。
6. 每 1–2 个月重复；日常洗完敞开舱门。

口径见 `rules/wm-rules.md`。

## 4. 核心规则 / 要件说明

生成方案前**先读 `rules/wm-rules.md`**：清洗剂用量、程序选择、频率。不合格带原因，如「未断电：带电清滤网有触电 / 误启动风险」。

## 5. 脚本用法

`scripts/wm_check.py` 自检「清洗操作清单」：

```
python scripts/wm_check.py --file steps.json
python scripts/wm_check.py --selftest
```

## 6. 人工确认清单

- [ ] 已断电
- [ ] 滤网残水排净、绒毛清掉
- [ ] 胶圈霉斑擦净
- [ ] 已跑筒自洁空转
- [ ] 洗完敞开通风

## 7. 最常见的坑

1. 不断电清滤网：误启动夹手、触电，先拔插。
2. 只洗外面不洗筒：臭味在筒壁夹层，必须筒自洁。
3. 清洗剂放衣物格而非筒内：粉剂结块，按说明放筒。
4. 洗完立刻关舱门：胶圈闷出霉，敞开晾干。
5. 滤网半年不掏：绒毛堵排水，异味来源。
6. 用普通洗衣液当清洗剂：去垢除菌不够，用槽清洗剂。

## 8. 边界与免责

覆盖滚筒 / 波轮日常筒清洁。拆筒、电机、排水泵维修不在范围。清洗剂选专用，勿过量；高温程序注意机型支持。
