# 家政服务纠纷维权核查

## 适用范围
- 钟点工 / 保洁 / 保姆 / 月嫂 / 育儿嫂 / 养老陪护等家政服务消费纠纷
- 典型场景：中介或阿姨跑路、服务缩水与偷懒、预付费不退、财物损坏丢失、人员受伤、隐私泄露、合同主体与收款方不一致

## 不适用
- 家政公司劳动用工纠纷（雇主与阿姨之间的雇佣关系劳动争议 → 走劳动仲裁）
- 物业服务、搬家服务（属不同服务类目）

## 使用方式
把用户的陈述或聊天记录整理成采集表（见 `templates/家政服务信息采集表.md`），交给本技能主脚本：

```
python scripts/home_service_dispute_check.py 采集表.md --out 报告.md
python scripts/home_service_dispute_check.py 采集表.md --json
```

## 输出
9 段结构化报告，含结论摘要（通过/有风险/不通过/待补正）、合同与主体一致性、付款与预付费口径、人身财产损害识别、证据清单、维权路径、待办补正动作、边界与纪律。

## 核查要点
1. 有无书面合同、合同主体与收款主体是否一致
2. 是否预付费、剩余服务期、退费基数
3. 付款至个人/现金/微信直转的风险
4. 人身伤害、财物损坏、隐私侵权的识别与处置优先级
5. 证据清单：合同、付款凭证、沟通记录、服务过程记录、损害证明

## 纪律
- 仅做信息核查与维权路径指引，不构成法律意见
- 不提供任何中介、代办投诉或代制证据服务
- 地域差异以当地市场监管与商务部门公布为准
