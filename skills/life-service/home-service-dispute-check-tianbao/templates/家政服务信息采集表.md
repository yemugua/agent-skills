# 家政服务纠纷信息采集表

> 填写说明：能填的尽量填，拿不准写"待确认"，不要空着。带 * 为核心项。

| 字段 | 值 |
| --- | --- |
| 家政服务类型 * | 例如：钟点工/保洁/保姆/月嫂/育儿嫂/养老陪护 |
| 服务提供者 | 公司名/中介名/阿姨姓名 |
| 服务人员身份 | 例如：公司派单阿姨/中介介绍个人/直接雇佣 |
| 有无合同 | 是 / 否 |
| 合同主体 | 合同或订单上的签约方名称 |
| 付款方式 | 例如：微信转个人/对公转账/平台支付/现金 |
| 收款主体 | 实际收到钱的一方（个人微信名/公司账户） |
| 已付金额 * | 例如：6800（单位元） |
| 问题描述 * | 发生了什么纠纷，尽量具体 |
| 发生时间 | 例如：2026-09-20 |
| 服务起止日期 | 例如：2026-09-01 至 2026-12-01 |
| 有无平台 | 是 / 否 |
| 平台名称 | 例如：某家政APP |
| 损害情况 | 例如：财物损坏/人员受伤/隐私泄露/无 |
| 是否预付费 | 是 / 否 |
| 剩余服务期 | 例如：还剩 2 个月 |
| 证据留存 | 例如：有合同、有转账记录、有聊天记录、有照片 |
| 诉求 | 例如：退费/赔偿/道歉 |
