# 危险废弃物管理（hazardous-waste）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《固体废物污染环境防治法》与《国家危险废物名录》，生成危废管理清单：分类代码、贮存（危废间）、转移联单、台账与标识。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 危废管理
- 危险废物
- 危废台账
- 转移联单
- 危废暂存
- 危废标识

## 三、工作流
1. 对照《名录》识别危废与代码
2. 分类收集与专用容器标识
3. 危废暂存间（防渗/通风/泄漏）合规
4. 出入库台账与转移联单
5. 交由有资质单位处置

## 四、核心内容（检查清单与判定）
《固废法》要求危废实行名录管理、分类收集、专用贮存场所、转移联单制度；贮存不得超过1年，台账记录来源/种类/数量/流向。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未对照名录识别危废代码 | 固废法/名录 |
| Q2 | FAIL | 未分类收集与标识 | 分类标识 |
| Q3 | FAIL | 危废暂存间不合规（防渗/通风） | 贮存 |
| Q4 | WARN | 无出入库台账/转移联单 | 联单 |
| Q5 | WARN | 贮存超1年或无合规处置方 | 处置 |

> 脚本 `hazardous-waste_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python hazardous-waste_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python hazardous-waste_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
