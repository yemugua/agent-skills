# 商业三者险保额与责任结构规则库

> 本规则库按商业责任险的常见结构整理。**各责任限额、免赔与责任比例以保险合同条款为准**；**人身损害赔偿标准以现行法律规定与实际核定为准**；**社保待遇以现行规定和社保部门口径为准**。三条保额口径的倍数**只是参考区间，不是标准、不是监管要求、不是推荐**。本库不推荐产品，不承诺理赔。

---

## 一、三条保额估算口径

```
口径 A（按营业额）：所需保额参考 = 年营业额 × 参考倍数区间
口径 B（按场地财产）：所需保额参考 = 场地与设备价值 × 参考倍数区间
口径 C（按人员规模）：所需保额参考 = 人员数 × 人均责任估算

取三者最大值作为保额下限参考，再按可承受保费向上取档
```

| 口径 | 影响因素 | 常见倾向 |
|---|---|---|
| 按年营业额 | 高人流、高单价业务倍数更高 | 零售、餐饮、演出类偏紧 |
| 按场地与设备价值 | 场地越大、可接触财产越多倍数越高 | 仓储、大型场所偏紧 |
| 按人员规模 | 用工性质与作业风险 | 涉及作业风险的作业类偏紧 |

**必须说明**：

- **倍数只是估算区间，不是标准、不是监管要求**
- **具体倍数应结合行业风险、客流、历史赔付与当地赔偿水平确定**
- **最终保额以保险合同承保的限额与实际报价为准**
- **不得凭「别人买多少我也买多少」给数字**

---

## 二、责任限额结构拆解

| 项目 | 含义 | 必须核对 |
|---|---|---|
| **每次事故限额** | 单次事故下保险人最多赔多少 | 数值、人伤与财产是否分开设限 |
| **累计限额** | 一个保险期间内最多累计赔多少 | **累计限额可能远低于每次事故限额 × 次数** |
| **免赔额** | 损失超过多少的部分才进入赔付 | 数值、绝对免赔还是相对免赔 |
| **免赔率** | 每次事故扣掉的比例 | 比例、是否与免赔额叠加 |
| **责任比例** | 按过错或责任划分承担比例 | 划分方式以条款约定为准 |
| **分项限额** | 人身伤害与财产损失是否分别设限 | **两项限额往往不共用** |

**最常见误读**：**只看到「保额 100 万」，没看是每次事故限额还是累计限额，也没看人身伤害与财产损失是否分别设限。**

**必须写清**：`每次事故限额 ≠ 累计限额 ≠ 实际能赔到的金额`。

---

## 三、赔偿顺序

```
损失金额
 → 扣除合同约定的免赔额与免赔率对应部分
 → 剔除不属于保险责任的部分（非保险事故、属于免责情形）
 → 按责任比例划分
 → 受每次事故限额与累计限额约束
 → 剩余部分由被保险人自行承担（自付敞口）
```

**必须说明**：

- **顺序以保险合同条款约定为准**，不同产品可能不同
- **交强险与商业三者险的赔付关系**：一般先由交强险在责任限额内赔付，不足部分由商业险按约定赔付，**具体以现行规定与合同约定为准**
- **交强险有独立的责任限额与赔付结构**，**不得拿它的限额当商业险能赔的数**

---

## 四、社保、工伤与三者险的责任边界

| 损失类型 | 主要承担方 | 口径 |
|---|---|---|
| 员工在本单位工作原因受伤 | **工伤保险**（认定以人社部门为准） | 走工伤通道，**不是三者险** |
| 顾客/访客在场所内受伤 | **商业责任险（公众/场地责任）** | 按合同责任范围与限额 |
| 顾客财物在场所内受损 | **商业责任险的财产损失责任** | 注意是否分项限额 |
| 对第三方造成的人身伤亡 | **商业三者险** | 受每次事故限额与累计限额约束 |
| 交强险范围内的机动车事故 | **交强险先行，商业险补足** | 以现行规定与合同约定为准 |
| 场地、设备自身的损失 | **财产险，不是责任险** | **不要买错险种** |

**三条必读**：

1. **三者险不赔被保险人自己财产的损失**，那是财产险的事
2. **三者险不等于工伤保险**，工伤认定走人社部门
3. **社保报销比例、起付线、封顶线以现行规定和社保部门口径为准**，不凭记忆报数字

## 五、自付敞口测算

```
单次事故自付敞口 =
  max(0, 事故总损失
      − 社保或交强险可覆盖部分
      − 商业险赔付部分（已扣免赔、按责任比例、受限额约束）)
```

**三条必读**：

- **赔款不是「保额」**，中间还隔着免赔额、免赔率、责任比例与限额
- **实际赔付以保险公司核赔结论为准**，本测算只是口径演示
- **人身损害赔偿金额**涉及医疗费、误工费、护理费、残疾赔偿金、被扶养人生活费、精神损害抚慰金等多项，按**现行法律规定与实际核定**计算，**不是拍脑袋的数**

## 六、保额档次的性价比口径

```
加保增量成本 = 高档保费 − 低档保费
敞口降幅     = 低档自付敞口 − 高档自付敞口
每万元敞口降幅成本 = 加保增量成本 ÷ (敞口降幅 ÷ 10000)
```

**判断方法**：多花很少的钱就能把保额提高一档、显著降低敞口，通常值得加；增量成本已很高而敞口降幅有限，按自身承受能力决定。**不勉强加保，也不为省保费而压低保额。**

## 七、常见责任免除类别（用于定位）

| 类别 | 典型表述方向 |
|---|---|
| 未取得许可的经营 | 无相应资质或许可从事的业务 |
| 擅自改变用途 | 场所实际用途与申报用途不一致 |
| 场所不符合安全标准 | 消防、安全设施不符合要求 |
| 设施设备缺陷未整改 | 已发现隐患未整改仍继续营业 |
| 特定高风险活动 | 合同列明的高危作业或活动 |
| 合同约定外的财产损失 | 不属于保险标的的财产 |
| 战争、暴动等法定除外 | 战争、恐怖活动等特殊情形 |

**免责条款的定位方式**：在合同中检索「责任免除」「不承担」「除外」等关键词所在章节，逐条读原文。

**注意**：不读这一节，等于不知道自己买了什么、也买了什么。

## 八、防误伤（否定词）清单

| 见到这些情况 | 必须这样判 | 严禁这样写 |
|---|---|---|
| 看到「保额 100 万」 | 判为**需确认是每次事故限额还是累计限额** | 直接当能赔 100 万 |
| 有人伤与财产分项限额 | 判为**两项限额不共用，一项用满另一项就没了** | 「两项加起来有 X 万」 |
| 免赔额 5000 | 判为**已扣 5000** | 「没扣」 |
| 免赔率 10% | 判为**已扣 10%** | 「没扣比例」 |
| 责任比例 30% | 判为**按 30% 划分** | 「全赔」 |
| 累计限额已用满 | 判为**后续不再赔付** | 「还能继续赔」 |
| 员工工作原因受伤 | 判为**走工伤保险通道** | 「三者险赔」 |
| 自身设备受损 | 判为**属财产险范畴** | 「三者险赔」 |
| 交强险已赔部分 | 判为**先由交强险在限额内赔** | 「商业险从头赔」 |
| 人身损害赔偿金额 | 判为**按现行法律规定与实际核定** | 凭记忆报数字 |
| 事故责任认定 | 判为**由事故处理部门与法院认定** | 自行认定责任比例 |
| 未出险 | 判为**未赔付，未使用保额** | 「保额已用掉 X」 |
| 已赔付 | 仅在核赔完成且款项到账时成立 | 「已申请就算赔付」 |

## 九、争议处理路径

| 情形 | 建议路径 |
|---|---|
| 保额是否足够有争议 | 先按三条口径自算，再向保险公司与经纪人核保口径确认 |
| 每次事故限额与累计限额理解有争议 | 调取合同条款原文对应章节 |
| 赔偿顺序理解有争议 | 调取合同中赔偿处理章节原文 |
| 责任认定有争议 | 由交警等事故处理部门认定，必要时申请复核 |
| 伤残等级有争议 | 按法定程序申请鉴定 |
| 拒赔或定损争议 | 走投诉渠道，必要时咨询律师或申请公估 |

**不建议**：在争议未解决前签署任何放弃权利的文件。

---

## 十、免责

本规则库为投保实践整理，**不构成保险代理、保险经纪或法律意见**。**各责任限额、免赔额、免赔率与责任比例以保险合同条款为准**；**人身损害赔偿标准以现行法律规定与实际核定为准**；**社保待遇以现行规定和社保部门口径为准**；**赔偿顺序以合同约定为准**。三条保额口径的倍数**只是参考区间，不是标准、不是监管要求、不是推荐**。本库**不推荐具体产品、不预测赔偿金额、不承诺理赔结果**。事故责任认定、伤残鉴定与赔偿争议应及时交由事故处理部门、公估机构与律师处理。
