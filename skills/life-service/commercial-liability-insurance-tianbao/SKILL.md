# 商业三者险额度核查

商业险保额买多少，不是拍脑袋，而是**三条口径分别算一遍，再看哪条最紧**。

最常见的错是：**只看保费档位，不看自付敞口**。保额差一档，保费差几十块；但真出事，敞口差几十万。

这个技能做五件事：**三条口径估算 → 拆责任限额 → 排赔偿顺序 → 算自付敞口 → 比保额档次**。

---

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 按营业额、场地财产、人员规模分别估算所需保额 | 推荐具体保险公司、具体产品 |
| 拆解每次事故限额、累计限额、免赔额与责任比例 | 承诺一定能赔、一定能赔多少 |
| 说明赔偿顺序与社保衔接关系 | 代替保险公司作核赔认定 |
| 测算不同保额档次下的自付敞口 | 承诺人身损害赔偿的具体金额 |
| 输出必须向保险公司与律师确认的问题 | 编造条款号、费率表与具体赔偿标准 |
| 提示员工工伤与三者险的责任边界 | 把三者险当成工伤保险 |

涉及以下情形，应停下来交由保险公司、律师、公估机构或事故处理部门处理：**人伤事故的责任认定与赔偿协商、伤残等级鉴定、诉讼中的赔偿争议、拒赔或定损争议、涉及无证/酒驾/逃逸等法定免责情形、劳动部门认定的工伤处理**。

**绝对不做**：不承诺理赔、不编造赔偿标准与费率。**各责任限额、免赔与责任比例以保险合同条款为准**；**人身损害赔偿标准以现行法律规定与实际核定为准**。

## 三、完整工作流

```
第 1 步  取材料：保险合同、场所与经营信息（营业额、面积、客流、人员）、
        社保缴纳情况、以往事故与赔付记录
第 2 步  读规则文件 rules/commercial-liability-rules.md（三条保额口径、
        责任限额结构、赔偿顺序、社保衔接、防误伤清单）
第 3 步  按营业额口径估算：年营业额 × 参考倍数区间
第 4 步  按场地财产口径估算：场地与设备价值 × 参考倍数区间
第 5 步  按人员规模口径估算：人员数 × 人均责任估算口径
第 6 步  取三条口径中的最大值作为保额下限参考
第 7 步  跑脚本：scripts/liability_limit_calc.py --file case.json
第 8 步  拆解责任限额结构：每次事故限额 / 累计限额 / 免赔额 / 责任比例
第 9 步  按赔偿顺序测算自付敞口：损失 − 社保可赔部分 − 商业险赔付
第 10 步 比保额档次：增量保费 vs 敞口降幅，输出结论与必须确认的问题
```

## 四、核心口径

### 4.1 三条保额估算口径

```
口径 A（按营业额）：所需保额参考 = 年营业额 × 参考倍数区间
口径 B（按场地财产）：所需保额参考 = 场地与设备价值 × 参考倍数区间
口径 C（按人员规模）：所需保额参考 = 人员数 × 人均责任估算

取三者最大值作为保额下限参考，再按可承受保费向上取档
```

**必须说明**：

- **这三个倍数只是估算区间，不是标准、不是监管要求**
- **具体倍数应结合行业风险、客流、历史赔付与当地赔偿水平确定**
- **最终保额以保险合同承保的限额与实际报价为准**
- **不得凭「别人买多少我也买多少」给数字**

**参考区间（口径参考，不构成推荐）**：

| 口径 | 常见参考区间 | 说明 |
|---|---|---|
| 按年营业额 | 年保额约为**年营业额的一定倍数** | 高人流、高单价业务倍数更高 |
| 按场地与设备价值 | 年保额约为**场地与设备价值的一定倍数** | 场地越大、可接触财产越多，倍数越高 |
| 按人员规模 | 年保额约为**人员数 × 人均责任估算** | 人数本身不是唯一因素，还要看用工性质与作业风险 |

> **上表的倍数在不同行业、不同地区差异很大。本技能只给方法与区间口径，不给具体数字结论；具体倍数以实际风险评估与保险公司的核保结论为准。**

### 4.2 责任限额结构（必须拆开看）

| 项目 | 含义 | 必须核对 |
|---|---|---|
| **每次事故限额** | 单次事故下保险人最多赔多少 | 数值、人伤与财产是否分开设限 |
| **累计限额** | 一个保险期间内保险人最多累计赔多少 | **累计限额可能低于每次事故限额 × 次数** |
| **免赔额** | 损失超过多少的部分才进入赔付 | 数值、是绝对免赔还是相对免赔 |
| **免赔率** | 每次事故扣掉的比例 | 比例、是否与免赔额叠加 |
| **责任比例** | 按过错或责任划分承担比例 | 具体划分方式以条款约定为准 |
| **分项限额** | 人身伤害与财产损失是否分别设限 | **两项限额往往不共用** |

**最常见的误读**：**只看到「保额 100 万」，没看这是每次事故限额还是累计限额，也没看人身伤害与财产损失是不是分别设限。**

**必须写清**：`每次事故限额 ≠ 累计限额 ≠ 实际能赔到的金额`。三者要分开看。

### 4.3 赔偿顺序（先赔谁）

```
一般顺序（以合同约定为准）：
  损失金额
  → 先扣除合同约定的免赔额与免赔率对应部分
  → 再扣除不属于保险责任的部分（非保险事故、属于免责情形）
  → 再按责任比例划分
  → 最后受每次事故限额与累计限额约束
  → 剩余部分由被保险人自行承担（自付敞口）
```

**必须说明**：

- **顺序以保险合同条款约定为准**，不同产品可能不同
- **交强险与商业三者险的赔付关系**：一般先由交强险在责任限额内赔付，不足部分由商业险按约定赔付，**具体以现行规定与合同约定为准**
- **社保（工伤保险）与人身伤害赔偿的关系**：**工伤走工伤保险通道**，不当然由商业三者险承担，**具体以现行规定和社保部门口径为准**

### 4.4 社保与商业险的衔接

| 损失类型 | 主要承担方 | 口径 |
|---|---|---|
| 员工在本单位工作原因受伤 | **工伤保险**（认定以人社部门为准） | 走工伤通道，**不是三者险** |
| 顾客/访客在场所内受伤 | **商业责任险（公众/场地责任）** | 按合同责任范围与限额 |
| 顾客财物在场所内受损 | **商业责任险的财产损失责任** | 注意是否分项限额 |
| 对第三方造成的人身伤亡 | **商业三者险** | 受每次事故限额与累计限额约束 |
| 交强险范围内的机动车事故 | **交强险先行，商业险补足** | 以现行规定与合同约定为准 |
| 场地、设备自身的损失 | **财产险，不是责任险** | **不要买错险种** |

**必须说明**：

- **三者险不赔被保险人自己财产的损失**，那是财产险的事
- **三者险不等于工伤保险**，工伤认定走人社部门
- **社保报销比例、起付线、封顶线以现行规定和社保部门口径为准**，不凭记忆报数字

### 4.5 自付敞口测算口径

```
单次事故自付敞口 =
  max(0, 事故总损失
      − 社保或交强险可覆盖部分
      − 商业险赔付部分（已扣免赔、按责任比例、受限额约束）)
```

**必须说明**：

- **赔款不是「保额」**，中间还隔着免赔额、免赔率、责任比例与限额
- **实际赔付以保险公司核赔结论为准**，本测算只是口径演示
- **人身损害赔偿金额涉及医疗费、误工费、护理费、残疾赔偿金、被扶养人生活费、精神损害抚抚慰金等多项，按法律规定与实际核定计算，不是拍脑袋的数**

### 4.6 保额档次的性价比口径

```
加保增量成本 = 高档保费 − 低档保费
敞口降幅     = 低档自付敞口 − 高档自付敞口
每万元敞口降幅成本 = 加保增量成本 ÷ (敞口降幅 ÷ 10000)
```

**判断方法**：如果多花很少的钱就能把保额提高一档、显著降低敞口，通常值得加；如果增量成本已经很高、而敞口降幅有限，按自身承受能力决定。**不勉强加保，也不为省保费而压低保额。**

## 七、人工确认清单（这步不能省）

- [ ] **年营业额**取自实际经营数据，不是估算
- [ ] **场地与设备价值**取自资产清单，不是账面概数
- [ ] **人员数**与用工性质（全职/兼职/外包）已确认
- [ ] **每次事故限额**与**累计限额**已分别抄下，不是只看「保额」
- [ ] **人身伤害限额与财产损失限额**是否分项已确认
- [ ] **免赔额与免赔率**已抄下具体数字，并确认是叠加还是二选一
- [ ] **责任比例**的划分方式已从条款确认
- [ ] **赔偿顺序**已从合同条款确认，不是按常识假设
- [ ] **工伤保险**缴纳情况已确认，知道员工工伤走的是人社通道
- [ ] 社保待遇查询的是**现行**口径，不是几年前的记忆
- [ ] **责任免除**已逐条读，特别是与自身业务相关的情形
- [ ] 已知悉**三者险不赔自身财产损失**（那是财产险）
- [ ] 结论中**没有出现「一定能赔」「赔多少」**这类表述

## 八、最常见的坑

1. **只看「保额 100 万」，不看是每次事故限额还是累计限额。** 这两个数可能差几倍。**累计限额可能远低于每次事故限额 × 次数。**
2. **不看出身伤害限额与财产损失限额是分项的。** 很多产品两项限额不共用，**一项用满另一项就没了**。
3. **忽略免赔额与免赔率。** 免赔额小则赔款起扣点低；免赔率则直接扣比例。**这两个数字直接决定到手多少。**
4. **把三者险当工伤保险。** 员工在本单位工作原因受伤，**走工伤保险通道**，由人社部门认定，**不当然由商业三者险承担**。买错通道，赔的时候才发现。
5. **把三者险当财产险。** **三者险赔的是对第三方造成的人身伤亡与财产损失，不赔被保险人自己的设备和场地。** 自己的财产要买财产险。
6. **不按三条口径估算，只按营业额算。** 场地大、客流高、单价高的业务，**营业额口径会低估**；反过来，按场地口径估可能高估。**三条都算，取最大值。**
7. **以为保额等于能赔到的金额。** 中间隔着**免赔额、免赔率、责任比例、每次事故限额与累计限额**五道关口。**保额是天花板，不是结果。**
8. **不排赔偿顺序。** 一般是先扣免赔、再剔除非保险责任部分、再按责任比例划分、最后受限额约束，**具体以合同约定为准**。顺序错了，测算就错了。
9. **为省几十块保费压低保额。** 保额差一档，保费可能只差几百上千；但真出事，敞口差几十万。**加保通常是这类险里性价比最高的一笔钱。**
10. **不看责任免除。** 常见除外类别包括未取得许可的经营、擅自改变场所用途、场所不符合安全标准等。**不读这一节，等于不知道自己买了什么也买了什么。**
11. **凭记忆报人身损害赔偿标准。** 医疗费、误工费、护理费、残疾赔偿金、被扶养人生活费等按**现行法律规定与实际核定**计算，**不是拍脑袋的数**。
12. **拿交强险的责任限额当商业险能赔的数。** **交强险有独立的责任限额与赔付结构**，超出部分才由商业险接，**具体以现行规定与合同约定为准**。

## 九、边界与免责

- 本技能用于保额估算与责任结构梳理，**不构成保险代理、保险经纪或法律意见**，不替代保险合同的约定与保险公司的核赔
- **各责任限额（每次事故限额、累计限额、分项限额）、免赔额、免赔率与责任比例均以保险合同条款为准**；不同产品差异很大，不得互相套用
- **人身损害赔偿标准以现行法律规定与实际核定为准**；**社保待遇以现行规定和社保部门口径为准**；不承诺报销比例与赔偿金额
- 三条保额估算口径的**倍数只是参考区间，不是标准、不是监管要求、不是推荐**
- **不承诺理赔、不承诺赔多少**；不推荐具体保险公司与具体产品；不预测赔偿金额
- 事故责任认定、伤残鉴定与赔偿争议属专业与法律范畴，**应及时交由事故处理部门、公估机构与律师处理**
