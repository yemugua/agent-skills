# 汽车电瓶亏电与搭电核查规则库

> 生成排查顺序、给操作指引之前，先读这份文件，不要凭印象写。
> 容量与电压数值以车辆说明书和电瓶标识为准。

---

## 一、亏电原因排序

| 顺序 | 原因 | 典型表现 | 检查方向 |
|---|---|---|---|
| 1 | 长期停放未断电 | 停放几天就打不着 | 停放时长、是否有长期不断电的设备 |
| 2 | 频繁短途行驶 | 每天开一点，电量补不满 | 行驶时长与距离 |
| 3 | 空调、灯光未关 | 熄火后才发现 | 用车习惯 |
| 4 | 电瓶老化 | 用几年后突然更容易亏 | 使用年限与车况 |
| 5 | 加装设备耗电 | 加装后开始出现亏电 | 后装设备与加装情况 |
| 6 | 电路或用电异常 | 熄火后仍持续耗电 | 需专业检查 |
| 7 | 低温影响 | 冬季明显更容易没电 | 见低温一节 |

**说明**：

- 现代车辆熄火后仍有少量常电设备在工作，长期停放会慢慢消耗电量
- **熄火静置一夜后明显亏电，可能不是电瓶本身问题，而是有设备持续耗电**，需专业检查

## 二、搭电的正确顺序

| 顺序 | 连接到 | 说明 |
|---|---|---|
| 1 | 搭电车电瓶正极 | 先接正极 |
| 2 | 亏电车电瓶正极 | 再接正极 |
| 3 | 亏电车电瓶负极 | 接负极 |
| 4 | 搭电车电瓶负极 | **最后接负极** |

**原因**：最后接负极、完成搭电后再拆负极，让车辆在整个过程中有稳定电平参考，减少对车载电子设备的影响。**拆的顺序与接的相反**，先拆负极再拆正极。

**启动顺序**：搭电车**先点火并保持怠速**，再让亏电车尝试启动。**启动后不要立刻熄火**，让充电系统有时间充电。

---

## 三、搭电禁忌

| 禁忌 | 原因 |
|---|---|
| 正负极不可反接 | 反接可能损坏车载电子设备 |
| 不要在亏电车发动机运转时搭 | 电压不稳可能损坏双方车辆 |
| 不要用细导线 | 电流大易发热熔断，线径要够 |
| 不要同时触碰两个端子与金属 | 避免短路与电弧 |

**搭线选择**：**线径要足够，导线太细在大电流下会明显发热甚至熔断。** 选正规搭电线，不要用细铁丝或普通电线代替。

**操作环境**：通风、干燥、平整的场地，避免狭窄空间。**手不要同时接触两个端子。**

---

## 四、搭电后仍无法启动的排查

| 顺序 | 检查项 |
|---|---|
| 1 | 接线顺序正确、正负极没有接反 |
| 2 | 搭电车电量充足、已点火保持怠速 |
| 3 | 搭电线线径足够、连接牢固无松动 |
| 4 | 档位正确：自动挡在 P 挡，手动挡挂空挡 |
| 5 | 手刹拉起、方向盘解锁，钥匙转到启动位置 |
| 6 | 间隔十几秒再重试，不要连续长时间反复打 |

**连续长时间反复打火**会消耗电量还可能损伤电瓶。

---

## 五、必须换电池的判定

| 情况 | 判定 |
|---|---|
| 搭电后很快再次亏电 | 可能是容量衰减或存在持续耗电 |
| 使用年限已到 | 按电瓶标识与厂家说明为准 |
| 电瓶鼓包 | **立即停用，不要继续使用或搭电** |
| 电瓶漏液 | 立即停用，报修 |
| 端子腐蚀严重 | 需要检查，必要时更换 |
| 低温下频繁无法启动 | 容量可能已明显下降 |
| 车辆电气系统报警 | 应由专业人员判断 |

**核心口径**：**反复搭电不是长久之计。** 经常需要搭电说明电瓶或电路有问题。

## 六、冬季低温影响

| 因素 | 说明 |
|---|---|
| 电瓶容量在低温下下降 | 可用容量减少，同样的电启动不了 |
| 低温下机油黏度高 | 发动机阻力变大，启动电流需求更大 |
| 冬季使用频率可能下降 | 行驶时间不够，充电不足 |
| 雨雪天气电器使用多 | 除霜、后挡加热等增加耗电 |

**预防做法**：

- 长时间停放前确认电瓶状态
- 冬季适当延长行驶时间让充电更充分
- 极寒地区可考虑保温或维护装置
- 出发前先确认电瓶状况

**核心口径**：低温不增加电量消耗速度，但会降低电瓶可用容量，两者叠加更容易启动困难。

## 七、应急准备清单

| 项目 | 用途 |
|---|---|
| 搭电线（线径足够） | 搭电使用 |
| 三角警示牌 | 停车后必须放置 |
| 应急启动电源 | 不依赖第二台车的启动方式 |
| 反光背心 | 夜间或能见度差时 |
| 手机与充电线 | 求助与联系 |

**使用应急启动电源**：按设备说明书操作，**正负极连接同样不可反接**。

**应急处理原则**：保证人身安全、开启闪光灯、放置三角警示牌、人员撤到安全区域、联系救援。

## 八、常见误区对照

| 说法 | 是否成立 |
|---|---|
| 正负极接反没关系 | 不成立，可能损坏电子设备 |
| 引擎转着也能搭 | 不成立 |
| 细导线一样能用 | 不成立，会发热熔断 |
| 搭完立刻熄火走人 | 不成立，应让充电系统充电 |
| 反复打火总能打着 | 不成立，会耗电并损伤电瓶 |
| 自动挡挂着也能启动 | 不成立，必须在 P 挡 |
| 鼓包了还能用 | 不成立，立即停用 |
| 经常搭电没关系 | 不成立，该检查电瓶与电路 |
| 冬天亏电是正常的 | 部分成立，但反复出现仍需检查 |
