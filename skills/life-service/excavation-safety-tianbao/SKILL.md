# 动土与开挖作业安全（excavation-safety）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据建筑施工土石方安全规范与管线保护要求，生成清单：地下管线交底与探测、边坡放坡或支护、降水与基坑监测、临边围护与通道、作业票证与气体检测。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 动土作业
- 开挖作业票
- 基坑边坡
- 地下管线交底
- 土方坍塌

## 三、工作流
1. 完成地下管线交底与探测
2. 确定放坡或支护方案
3. 实施降水与基坑监测
4. 设置临边围护与通道
5. 办理作业票并检测气体

## 四、核心内容（检查清单与判定）
动土作业最常见事故是挖断管线与边坡坍塌。施工前必须完成管线交底与探测，基坑须按方案放坡或支护并持续监测，严禁在坑边堆土。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含地下管线交底与探测 | 交底 |
| Q2 | FAIL | 未含放坡或支护方案 | 支护 |
| Q3 | WARN | 未含降水与基坑监测 | 监测 |
| Q4 | WARN | 未含临边围护与通道 | 围护 |
| Q5 | FAIL | 未含作业票与气体检测 | 票证 |

> 脚本 `excavation-safety_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python excavation-safety_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python excavation-safety_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
