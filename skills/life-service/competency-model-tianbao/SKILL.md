# 胜任力模型搭建（competency-model）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据胜任力建模方法（BEI/冰山），生成胜任力模型清单：序列/层级划分、胜任力词典、行为锚定与应用场景（招聘/晋升/培养）。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 胜任力模型
- 素质模型
- 能力模型
- BEI
- 行为锚定
- 胜任力词典

## 三、工作流
1. 按序列/层级划分建模对象
2. 建立胜任力词典（名称/定义/层级）
3. 行为锚定（BEI证据）
4. 校准与评审
5. 应用于招聘/晋升/培养

## 四、核心内容（检查清单与判定）
胜任力模型以‘冰山’区分显性与隐性特质；通过 BEI 行为事件访谈提取关键行为并锚定等级，支撑招聘甄选与人才发展。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未分序列/层级建模 | 划分 |
| Q2 | FAIL | 未建胜任力词典（名称/定义/层级） | 词典 |
| Q3 | WARN | 未含行为锚定（BEI证据） | 锚定 |
| Q4 | WARN | 未含应用场景（招聘/晋升/培养） | 应用 |

> 脚本 `competency-model_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python competency-model_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python competency-model_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
