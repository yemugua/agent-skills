# 315维权途径与证据准备

维权失败，**多数不是因为找错了部门，而是因为证据链断了**或**路径顺序错了**（先跳过协商直接投诉，商家不配合且你没有固定证据）。

## 一、硬边界（能做 / 不能做）

| 能做 | 不能做 |
|---|---|
| 给出路径顺序与每步的成本口径 | 承诺「一定能退款」或承诺赔偿金额 |
| 用证据四要素检查材料完整性 | 认定对方「构成欺诈」「违法」（由认定机关认定） |
| 给出取证手段清单与合法性提示 | 教唆伪造证据、偷拍取证、诱导对方陈述 |
| 判断某事项应走投诉、举报还是报案 | 代替市场监管部门受理或作出处理决定 |
| 给出投诉文书要素清单 | 提供诉讼代理意见或代为投诉 |

**必须转交执业律师或走司法程序的：** 争议金额较大或法律关系复杂；对方已失联、注销、跑路或涉嫌诈骗；涉及人身伤害；需要财产保全或强制执行。

## 二、什么时候用

| 用户说法 | 用不用 | 说明 |
|---|---|---|
| 12315 怎么投诉 | 用 | 走路径顺序与材料准备 |
| 商家不处理怎么办 | 用 | 走升级路径 |
| 证据要准备哪些 | 用 | 走证据四要素与取证手段 |
| 投诉信怎么写 | 用 | 走文书要素（本技能给要素，文书模板另见规则文件） |
| 什么时候可以报警 | 用 | 走刑事移送线索的判定口径 |
| 投诉被踢皮球 | 用 | 走渠道选择与升级 |
| 要不要去法院 | 用 | 走路径末端条件 |

## 三、完整工作流

### 步骤 1：先定性质（投诉 / 举报 / 报案）

三者不是一回事，选错会浪费时间：

| 类型 | 指向 | 目的是 |
|---|---|---|
| **投诉** | 经营者（与你存在消费关系） | 解决你个人的消费纠纷 |
| **举报** | 违法行为（指向监管） | 促使查处，不以你获赔为目的 |
| **报案** | 涉嫌犯罪的行为 | 由公安机关认定是否立案 |

**关键区别**：举报的结果不必然让你拿到退款；投诉的结果不必然查处商家。

### 步骤 2：按顺序走（不要跳步）

详见第四节路径顺序。**跳步的代价**：跳过协商直接投诉，商家不会配合，且你没有协商记录作为后续依据。

### 步骤 3：按证据四要素准备材料

**发生了什么 / 谁造成的 / 什么时候 / 凭什么证明**——四项缺一即材料不完整。

### 步骤 4：写投诉文书（按要素，不写情绪）

**投诉文书是证据材料，不是情绪宣泄。** 这一点直接决定它能不能被采信，见第五节。

### 步骤 5：提交并留痕，按升级路径跟进

## 四、核心规则（维权前必读）

**先读 `rules/维权路径与证据要件.md`，不要凭印象写材料。**

### 路径顺序与成本口径

| 顺序 | 步骤 | 适用 | 成本口径 | 关键产出 |
|---|---|---|---|---|
| 1 | **商家协商** | 多数消费争议 | 时间成本低，无费用 | 协商记录、工单号 |
| 2 | **平台介入** | 平台内交易 | 无费用 | 平台处理结论 |
| 3 | **12315 投诉举报** | 经营者违法或双方争议 | 免费，无须缴费 | 受理编号、处理结果 |
| 4 | **消费协会调解** | 需要第三方居中 | 免费 | 调解协议 |
| 5 | **报案** | 涉嫌犯罪线索 | 免费 | 受案回执 |
| 6 | **诉讼** | 前述途径未解决、金额值得 | 存在诉讼费用与时间成本 | 裁判文书 |

**关于时效与费用**：各环节的申请时限、办理时限与费用标准**以现行规定和受理机构口径为准**，本技能不写死具体天数与金额。**但必须提醒**：多数争议存在申请时限，且**协商、投诉、向商家主张权利等行为可能影响时效的中断**，拖延本身有风险。

### 路径顺序的取舍逻辑

- **先协商**：成本最低，且协商记录本身是有用证据。
- **平台介入仅对平台内交易有效**，线下交易没有平台可介入。
- **12315 与投诉举报应分开考虑**：解决你的纠纷用投诉，促使查处用举报。
- **报案的前提是有涉嫌犯罪的线索**，不是「商家不退钱」本身。不予立案是常态，要有心理准备并保留受案回执。
- **诉讼是末端**，前序途径的记录都是你的证据。

### 证据四要素与取证手段

| 要素 | 含义 | 取证手段（合法方式） |
|---|---|---|
| **发生了什么** | 事实经过与损害后果 | 订单截图、商品页面公证、检测报告 |
| **谁造成的** | 被投诉方主体信息 | 营业执照信息、平台商家主页、收款方名称 |
| **什么时候** | 时间线 | 订单时间、聊天记录时间戳、物流轨迹 |
| **凭什么证明** | 支撑证据 | 聊天记录、购买小票、开箱视频、发票 |

**取证合法性红线**：不得偷拍他人隐私区域、不得伪造或篡改证据、不得以非法方式获取证据。**录音取证应在合法场所与合法场合下进行**，具体可采用性与证据效力由认定机关判断。

### 投诉文书五要素

```
1. 被投诉方：名称 + 统一社会信用代码（可在企业信用信息公示系统查）
2. 事实：按时间顺序写清经过，只写能证明的事实
3. 诉求：明确、可执行（如退货退款 / 赔偿差额 / 赔礼道歉）
4. 依据：法律依据写「以现行规定为准」+ 你主张的事实基础
5. 联系方式：姓名、电话、通信地址、电子邮箱
```

## 五、投诉文书是证据材料（关键）

**投诉文书的第一读者是处理人员与可能的裁判者，不是商家。**

| 该写 | 不该写 |
|---|---|
| 「本人于某日下单某商品，实测结果与页面描述不符」 | 「商家都是骗子」 |
| 「诉求：退货退款并赔偿差额」 | 「必须赔我十倍，不然曝光」 |
| 引用订单号、聊天记录具体位置 | 大段情绪宣泄与脏话 |
| 按时间顺序陈述 | 夹杂无关的抱怨 |

**为什么情绪化表述有害**：一是降低材料的专业性；二是让处理人员跳过你的实质诉求；三是威胁性表述可能使诉求被认定为不合理。**把愤怒转化为可核查的事实陈述，本身就是维权技巧。**

## 六、脚本用法

脚本：`scripts/claim_evidence_check.py`

```bash
python scripts/claim_evidence_check.py --file 材料.json
python scripts/claim_evidence_check.py --selftest
```

| 字段 | 说明 |
|---|---|
| `facts` | 事实时间线条目 |
| `evidence` | 已收集证据列表，含 type/obtained |
| `path_done` | 已完成的维权步骤 |
| `doc_sections` | 投诉文书已含要素 |
| `emotional_phrases` | 文书中的情绪化表述（脚本会判定风险） |

输出：证据四要素完整性、取证合法性风险提示、文书要素缺失、情绪化表述定位、建议的下一路径步骤。

## 七、人工确认清单（不能省）

- [ ] 是否已按顺序走过协商，而不是直接跳到投诉？
- [ ] 是否已核到被投诉方的**准确主体名称**（营业执照名称）？
- [ ] 证据四要素是否齐全（发生了什么/谁/什么时候/凭什么）？
- [ ] 所有证据是否为**合法取得**方式？
- [ ] 投诉文书是否只写事实、**无情绪化与威胁性表述**？
- [ ] 诉求是否明确可执行，而不是笼统的「给个说法」？
- [ ] 是否区分了投诉、举报、报案三者的不同目的？
- [ ] 是否已保留所有提交凭证与受理编号？
- [ ] 是否核查了相关申请时限，避免拖延？

## 八、最常见的坑

1. **跳过协商直接投诉**。少了成本最低的一步，也少了协商记录这条证据。
2. **被投诉方名称写错**。写成品牌名或店铺名而非营业执照主体名称，会导致处理对象不清。
3. **投诉文书全是情绪**。处理人员会跳过实质诉求，材料的专业性也下降。
4. **诉求笼统**。「给个说法」无法执行，应写明具体诉求。
5. **以为举报了就能退款**。举报的结果不必然带来你个人的赔付。
6. **把「商家不退钱」当犯罪去报案**。不付款是民事争议，报案多不予立案；要有涉嫌犯罪的线索。
7. **不固定被投诉方主体信息**。对方注销后，人都找不到了。
8. **用非法方式取证**。偷拍隐私、伪造证据会导致证据不被采信，甚至引发新问题。
9. **口头交涉不留痕**。协商结果无记录等于没协商。
10. **拖着不走流程**。各环节可能存在申请时限，拖延本身会削弱主张。
11. **把平台介入当万能入口**。仅对平台内交易有效。
12. **没有写明诉求依据**。只写事实不写依据，处理人员难以判断是否支持。

## 九、边界与免责

本技能提供维权路径、证据要件与文书要素，**不构成法律意见，不承诺退款或赔偿结果，不代替市场监管部门受理与认定**。是否构成欺诈、违法，由相应认定机关依法认定。各地在受理范围、办理流程与时限上存在差异，请以**现行规定和受理机构口径为准**，不要以本技能的表述为准。涉及金额较大、对方失联跑路或涉嫌犯罪的，请及时委托执业律师。
