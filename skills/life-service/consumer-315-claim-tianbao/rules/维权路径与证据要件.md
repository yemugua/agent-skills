# 维权路径与证据要件

> 维权前必读。**先定性质、按顺序走、按四要素备齐证据。**

## 一、投诉 / 举报 / 报案的区分

| 维度 | 投诉 | 举报 | 报案 |
|---|---|---|---|
| 指向对象 | 经营者 | 违法行为 | 涉嫌犯罪的行为 |
| 受理主体 | 市场监管部门等 | 市场监管部门等 | 公安机关 |
| 你的目的 | 解决自己的纠纷 | 促使查处 | 由公安认定是否属犯罪 |
| 结果是否给你赔付 | **可能** | **不必然** | **不必然** |
| 常见误区 | 以为举报等于投诉 | 以为举报了就能退款 | 以为商家不付款就是犯罪 |

**关键区分**：举报的结果与你的个人赔付之间没有必然联系；投诉也不必然导致对商家的查处。

## 二、路径顺序（六步）

### 步骤 1：商家协商

- 适用：绝大多数消费争议。
- 成本：时间成本，无费用。
- **必须留痕**：工单号、聊天记录、通话后书面确认。
- 产出：协商记录（后续维权的第一份材料）。

**跳步的代价**：没有协商记录，你在后续环节会缺少「已尽力解决」的证明；商家也少了一次配合机会。

### 步骤 2：平台介入

- 适用：**仅平台内交易**。线下交易无平台可介入。
- 成本：无费用。
- 产出：平台处理结论、平台先行赔付与否的结论。

### 步骤 3：12315 投诉举报

- 适用：经营者违法或双方争议。
- 成本：免费，无须缴费。
- 产出：受理编号、处理结果告知。
- **提示**：投诉与举报可分别提交，目的不同（见第一节）。

### 步骤 4：消费协会调解

- 适用：需要第三方居中，双方对立僵持。
- 成本：免费。
- 产出：调解协议（有约束力，可申请司法确认）。

### 步骤 5：报案

- 适用：**有涉嫌犯罪的线索**（如伪造凭证、诈骗、故意售假且情节严重）。
- 成本：免费。
- 产出：受案回执 / 不予立案的通知。
- **现实预期**：单纯「商家不退钱」属民事争议，报案多不予立案；保留受案回执是必要的留痕手段。

### 步骤 6：诉讼

- 适用：前序途径未解决、争议金额值得、时间成本可承受。
- 成本：存在诉讼费用与较长的周期。
- 产出：裁判文书（可申请强制执行）。

### 关于时效与费用（重要）

**所有环节的申请时限、办理时限与费用标准以现行规定和受理机构口径为准**，本文件不写死具体天数与金额。

必须提醒的两点：

1. **多数争议存在申请时限**，拖延本身有风险。
2. **协商、投诉、向商家主张权利等行为可能影响时效的中断**，不是「先拖一拖再说」。

## 三、证据四要素

| 要素 | 判定问法 | 缺失后果 |
|---|---|---|
| **发生了什么** | 事实经过与损害后果是什么 | 无法判断争议性质 |
| **谁造成的** | 被投诉方主体是谁 | 处理对象不清 |
| **什么时候** | 各环节时间点 | 无法核对是否超期 |
| **凭什么证明** | 支撑证据是什么 | 材料不被采信 |

**四要素缺一即材料不完整。** 先用 `scripts/claim_evidence_check.py` 检查。

### 取证手段（合法方式）

| 证据类型 | 用途 | 合法性提示 |
|---|---|---|
| 订单截图 | 证明交易关系与标的 | 注意页面完整性 |
| 平台商家主页截图 | 证明主体信息 | 配合公示系统查询 |
| 聊天记录 | 证明沟通过程与承诺 | 完整导出，不截取断章取义 |
| 购买小票 / 发票 | 证明付款 | 优先保留原件或电子凭证 |
| 页面公证 | 固定宣传内容 | 公证有费用，注意时效 |
| 检测报告 | 证明质量与描述不符 | 委托有资质的机构 |
| 开箱视频 | 证明商品状态与破损 | **越早越好**，事后无法补拍 |

### 取证合法性红线

**不得**偷拍他人隐私区域、伪造或篡改证据、以非法侵入方式获取证据。

**录音取证的提示**：应在合法场所与合法场合下进行，**不得采用窃听器材等违法手段**；其可采用性与证据效力由认定机关依法判断。

## 四、投诉文书五要素

```
1. 被投诉方：名称 + 统一社会信用代码
   （在国家企业信用信息公示系统查，不要凭店铺名）
2. 事实：按时间顺序，只写能证明的事实
3. 诉求：明确、可执行
4. 依据：法律依据写以现行规定为准 + 你主张的事实基础
5. 联系方式：姓名、电话、通信地址、电子邮箱
```

### 诉求写法对照

| 不合格 | 合格 |
|---|---|
| 给个说法 | 退货退款，金额按订单实付 |
| 赔偿我的损失 | 赔偿实付价款与实际支出的差额 |
| 必须赔十倍 | 按现行规定主张相应责任（不写死倍数） |

**不要写死赔偿倍数或引用具体条款号**，法律依据写「以现行规定为准」，由受理机关适用。

## 五、文书是证据材料，不是情绪宣泄

**第一读者是处理人员与可能的裁判者，不是商家。**

| 该写 | 不该写 |
|---|---|
| 「本人于某日下单某商品，实测结果与页面描述不符」 | 「商家都是骗子」 |
| 「诉求：退货退款并赔偿差额」 | 「必须赔我十倍，不然曝光」 |
| 引用订单号、聊天记录具体位置 | 大段情绪宣泄与脏话 |
| 按时间顺序陈述事实 | 夹杂无关抱怨 |

**为什么情绪化表述有害**：

1. 降低材料专业性，处理人员会优先跳过。
2. 威胁性表述会使诉求被认定为不合理。
3. 掩盖了本可以核查的事实陈述。

**把愤怒转化为可核查的事实陈述，本身就是维权技巧。**

## 六、跟进与留痕

| 环节 | 必须保留 |
|---|---|
| 协商 | 工单号、聊天记录、通话后书面确认 |
| 平台 | 平台工单号、处理结论 |
| 投诉举报 | 受理编号、提交回执、结果告知 |
| 调解 | 调解协议 |
| 报案 | 受案回执或不予立案通知 |
| 诉讼 | 受理通知、缴费凭证、裁判文书 |

**「已提交」不等于「已受理」，「已受理」不等于「已解决」。** 每一步都要拿到书面凭证。

## 七、常见错误对照

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 跳过协商直接投诉 | 缺协商记录，少一次低成本机会 | 按顺序走 |
| 主体名称写店铺名 | 处理对象不清 | 查营业执照主体 |
| 文书全是情绪 | 处理人员跳过实质诉求 | 只写事实与诉求 |
| 诉求笼统 | 无法执行 | 写明具体诉求与金额 |
| 以为举报能退款 | 举报与个人赔付无必然联系 | 投诉解决纠纷，举报促使查处 |
| 把不付款当犯罪 | 属民事争议 | 有涉嫌犯罪线索再报案 |
| 不固定主体信息 | 对方注销后找不到人 | 先查并存档 |
| 非法方式取证 | 不被采信甚至违法 | 用合法手段 |
| 口头交涉不留痕 | 等于没协商 | 全程留痕 |
| 拖着不走流程 | 可能已超时限 | 及时核查时限 |
| 平台介入当万能 | 仅平台内有效 | 线下走监管渠道 |
