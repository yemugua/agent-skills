# 企业工商年报填报与逾期核查

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 判断主体是否需报、对应哪个报告年度 | 登录企业账号、代替法定代表人确认并提交 |
| 逐字段核对数据来源和公示口径 | 编造营收、利润、出资、社保人数或联系方式 |
| 检查逾期、异常名录原因和补报材料 | 保证当天移出异常或恢复授信、招投标资格 |
| 输出填报底稿、缺数表和办理路径 | 把税务申报、审计报告等同于工商年报 |
| 提示更正、公示信息抽查和救济渠道 | 代替登记机关作行政认定 |

涉及被冒名登记、涉嫌虚假出资、股权争议、行政处罚、严重违法失信、注销与清算冲突，或收到正式调查通知时，应交由登记机关窗口、会计师、律师或企业合规人员处理。

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「今年工商年报最晚什么时候报」 | 用 |
| 「公司没经营、零收入还要年报吗」 | 用，不能把无经营等同于免报 |
| 「补报了，为什么还在异常名录」 | 用，核查是否另行申请移出 |
| 「社保人数、资产数据怎么填」 | 用，按同一年度底稿核对 |
| 「帮我把利润随便写小一点」 | 不用，拒绝虚假填报 |
| 「个人所得税怎么申报」 | 不用，属于税务申报 |

## 三、完整工作流

1. **确认主体与年度**：统一社会信用代码、登记机关、成立与注销状态、报告年度；不要把本年度经营数据填进上一年度报告。
2. **确认时限**：通常每年 1 月 1 日至 6 月 30 日报送上一年度年度报告；当年新设主体一般从下一年度开始报送，特殊主体和地区提示另行核对。
3. **建底稿**：按 `rules/annual-report-fields.md` 收集登记、股东出资、股权变更、网站网店、对外投资、资产、社保、海关等适用数据。
4. **逐项对账**：与营业执照、章程、股东名册、财务报表、银行凭证、社保申报、许可证和电商后台比对。
5. **标公示范围**：区分依法必须公示、企业可选择不公示和不适用字段；涉及个人联系方式时先核对平台展示规则。
6. **提交前复核**：法定代表人或授权人员确认报告年度、单位、人数、金额和出资日期，保存预览页与提交回执。
7. **逾期处理**：先补报缺失年度，再按当地登记机关要求申请移出经营异常名录；只补报不等于自动移出。
8. **争议救济**：对列入、拒绝移出或公示内容有异议，保留决定、回执和证明材料，按告知渠道申请复核或依法救济。

## 四、核心规则与要件库

填报或生成补报说明前，**必须先读**：

- `rules/annual-report-fields.md`：时限、字段来源、单位口径、异常名录、移出材料、被卡原因和救济。
- `templates/filing-workpaper.md`：内部填报底稿、差异处理与补报移出申请模板。

不得根据企业名称猜统一社会信用代码，不得用上一年度数字直接覆盖，不得把「未实际出资」误写成「已实缴」。

## 五、人工确认清单

- [ ] 主体名称、统一社会信用代码、登记机关与当前登记信息一致
- [ ] 报告年度正确，所有期末数和年度累计数使用同一会计期间
- [ ] 股东认缴与实缴分列，金额单位和日期无误
- [ ] 网站网店、对外投资、股权变更和许可信息没有漏项
- [ ] 资产、负债、营收、利润、纳税等数据与最终账表一致
- [ ] 社保参保人数、缴费基数和实际缴费金额口径已核对
- [ ] 「无」「0」「不适用」「未公示」没有混用
- [ ] 提交后状态确为已公示，回执和最终版已归档

## 六、最常见的坑

1. **把税务零申报当免报工商年报**：无收入、停业或零申报通常不当然免除年报义务。
2. **年度错位**：申报页面显示的是报告年度，不是点击提交的年份；期末数据应落在该报告年度末。
3. **认缴写成实缴**：章程约定出资不等于资金已到位，实缴必须有实际缴付依据。
4. **金额单位看错**：系统可能按万元或元显示，差一万倍会形成明显异常。
5. **只点保存没点公示**：草稿、预览或保存成功不等于完成报送，必须确认公示状态与时间。
6. **补报后等待自动移出**：多数情形还需提出移出申请并接受核查，先看当地流程。
7. **忽略否定词**：财务表中的「未分配利润」「未缴足」「无对外投资」不能按关键词当成正向事实。
8. **为避免公开而乱填零**：能否选择不公示与能否不填写是两回事，按页面字段规则处理。

## 七、边界与免责

本技能用于填报前核查和材料整理，不构成会计、审计或法律意见，不替代企业最终确认和登记机关审查。年度报告期间、字段、异常名录处理、信用修复和线上系统规则可能调整，**以现行规定和当地市场监督管理部门要求为准**。不得用于虚假公示、隐瞒实缴情况或冒用企业身份。
