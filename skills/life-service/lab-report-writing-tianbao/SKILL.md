# 实验报告书写规范核查

实验报告扣分**很少是因为结论错，而多数是因为「数据呈现不规范」与「结论超出数据支持」**。本技能给的是可逐条对照核查的清单，不是「认真写就好」。

## 一、硬边界（能做 / 不能做）

| 能做 | 不能做 |
|---|---|
| 按八要素逐条检查报告完整性 | 代写实验数据或编造测量值 |
| 判定误差类型并给出规范表述 | 判定某个实验「通过」或「不通过」（由指导教师认定） |
| 检查有效数字、单位、图表规范 | 预测实验结果或给出实验设计结论 |
| 指出结论是否超出数据支持范围 | 替代实验室或教师判定成绩 |
| 给出异常值的处理与标注方式 | 修改原始记录 |

**必须转交专业人士：** 涉及人身安全、有毒有害物质、辐射或需要专门资质才能操作的实验——必须由实验室与指导教师按现行规范管理，本技能只处理文书规范。

## 二、什么时候用

| 用户说法 | 用不用 | 说明 |
|---|---|---|
| 实验报告怎么写 | 用 | 走八要素清单 |
| 误差分析写什么 | 用 | 走三分类与表述方式 |
| 有效数字怎么取 | 用 | 走有效数字规则 |
| 原始数据能不能改 | 用 | 明确不可涂改，需更正规范 |
| 异常数据怎么处理 | 用 | 走标注与处理流程 |
| 结论写多了会扣分吗 | 用 | 走结论边界判定 |
| 图表有什么规范要求 | 用 | 走图表规范表 |
| 帮我把这实验结论写出来 | 部分用 | 可给结构与表述模板，数据必须本人测 |

## 三、完整工作流

### 步骤 1：先核原始记录（不是先核报告）

原始记录若已涂改且无更正痕迹，后面全部白查。**先确认原始记录本是否可追溯**。

### 步骤 2：按八要素逐条对照

目的、原理、器材、步骤、数据记录、误差分析、结论、注意事项。缺项即缺分，见规则文件。

### 步骤 3：查数据规范（有效数字、单位、可追溯性）

见第四节。

### 步骤 4：判误差类型并规范表述

**系统误差 / 随机误差 / 过失误差**三类的成因与处理方式完全不同，混写会被判为不理解。用 `scripts/lab_data_check.py` 检查。

### 步骤 5：核对结论边界（最容易失分的一步）

**结论不得超出数据支持范围。** 判定方法见规则文件。

### 步骤 6：查图表规范

坐标轴标注、图例、单位、分辨率都要对。

## 四、核心规则（写报告前必读）

**先读 `rules/报告要素与误差规范.md`，不要凭印象写。**

### 八要素清单

| 要素 | 必须写清 | 常见缺失 |
|---|---|---|
| **实验目的** | 要验证/测量什么，量或性质 | 写成「学习实验操作」这类空话 |
| **实验原理** | 依据的定律/公式及其说明 | 只写公式名不写关系 |
| **实验器材** | 名称 + 规格（量程/精度） | 不写精度，导致无法解释误差 |
| **实验步骤** | 可复现的操作顺序 | 步骤跳跃，他人无法复现 |
| **数据记录** | 原始数据、单位、有效数字 | 缺单位、无效数字随意 |
| **误差分析** | 三类误差的成因与减小办法 | 只写「误差较小」 |
| **实验结论** | 数据支持的结论 | **超出数据支持范围** |
| **注意事项** | 安全与操作关键点 | 完全缺失 |

### 数据记录四条硬规则

1. **原始记录不得涂改**。写错用单横线划掉、保留原值可辨认，另在旁边写正确值并签名/日期。
2. **有效数字按仪器精度取**，不是按计算方便取。多写的位数是虚假精度。
3. **每个数据必须带单位**，包括表格中的表头。
4. **异常值不得直接删除**。要么标注并说明处理方式，要么按规则处理后保留痕迹。

### 误差三分类与表述

| 类型 | 成因特征 | 可否通过重复测量消除 | 表述要点 |
|---|---|---|---|
| **系统误差** | 固定偏差，方向一致（仪器零偏、方法缺陷） | **不能**，重复反而稳定在错误值 | 指出偏差来源与改正办法（校准、改进方法） |
| **随机误差** | 无规则波动，正负不定 | 可通过多次测量取平均减小 | 用平均值与偏差描述，说明测量次数 |
| **过失误差** | 人为失误（读错、记错、违反操作） | 可通过规范操作避免 | 明确排除并说明已舍弃该数据及依据 |

**关键区别**：系统误差不会因为多测几次而消失。**把系统误差当随机误差用平均值处理，是本实验最典型的错误。**

### 结论边界判定

结论的强度必须与数据强度匹配：

| 数据支持程度 | 允许的结论强度 |
|---|---|
| 一次测量 | 只能写「本次测得…」 |
| 多次测量且偏差小 | 可写「在实验条件下，测得值约为…」 |
| 有对照、多次重复、偏差可估计 | 可讨论规律或适用范围 |
| 无对照或样本极少 | **不得**推广到普遍规律 |

**越界的典型写法**：单次测量就写「验证了某定律成立」；在有限范围内测得就写「普遍适用于」。

## 五、脚本用法

脚本：`scripts/lab_data_check.py`

```bash
python scripts/lab_data_check.py --file 实验数据.json
python scripts/lab_data_check.py --selftest
```

| 字段 | 说明 |
|---|---|
| `records` | 数据列表，含 value/unit/sig/overwritten/kept |
| `outliers` | 异常值索引列表 |
| `chart` | 图表要素，含 xlabel/ylabel/legend/unit |

输出：单位一致性检查、有效数字与仪器精度匹配检查、原始记录涂改标记、异常值处理提示、图表缺项、结论强度与数据强度的匹配提示。

## 六、人工确认清单（不能省）

- [ ] 原始记录本未被涂改，或涂改处有划线更正与签名？
- [ ] 每个数据都带单位，且表头也标了单位？
- [ ] 有效数字位数与仪器精度一致？
- [ ] 异常值已标注并说明处理方式，而非直接删除？
- [ ] 误差分析区分了系统误差与随机误差？
- [ ] 系统误差是否指出了具体来源，而不只是「误差较小」？
- [ ] 器材是否写了规格与精度？
- [ ] 步骤是否他人可复现？
- [ ] 结论强度是否与数据强度匹配，未作普遍化推广？
- [ ] 图表是否有坐标轴标注、图例、单位？

## 七、最常见的坑

1. **把原始数据直接涂改重写**。这是学术规范红线，正确做法是划线更正保留痕迹。
2. **有效数字按计算方便取**。多写位数等于虚报精度。
3. **数据不带单位**。表头不带单位是高频扣分点。
4. **把系统误差当随机误差取平均**。多测几次只会让错误值更稳定。
5. **误差分析只写「误差较小」**。没有成因分析与改进办法等于没写。
6. **直接删掉异常值**。必须标注、说明依据并保留处理痕迹。
7. **结论超出数据支持**。单次测量写「验证定律成立」是最典型的越界。
8. **器材不写精度**。不写精度就无法解释误差来源。
9. **步骤跳跃**。他人无法复现即视为步骤不完整。
10. **图表无坐标轴标注或图例**。数据无法解读。

## 八、边界与免责

本技能提供实验报告的要素清单与规范核查方法，**不代写数据、不判定实验成败、不替代实验室与指导教师的评定**。各校各课程的具体格式要求以任课教师与实验室现行规定为准。涉及安全、有毒有害或需资质的实验，一律按实验室与教师要求执行。
