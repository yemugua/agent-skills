# 报告要素与误差规范

> 写报告前逐条对照。**本文件是可核查的清单，不是参考建议。**

## 一、八要素完整清单

### 1. 实验目的

| 要求 | 反例 |
|---|---|
| 写清要测量的量或要验证的关系 | 「学习实验操作」 |
| 可写成「通过测量 X，探究 X 与 Y 的关系」 | 「熟悉仪器使用」 |

**检验法**：目的句里若没有变量名，通常不合格。

### 2. 实验原理

- 依据的定律或公式，并说明变量如何对应。
- 反例：只写「依据欧姆定律」而不写 I = U/R 中各量与本实验的对应关系。

### 3. 实验器材

**必须含规格与精度**，例如「电压表（量程 0—3 V，分度值 0.1 V）」。

**不写精度 → 无法解释误差来源 → 误差分析无从写起**，这是三处连带失分。

### 4. 实验步骤

- 步骤须可复现：他人照着能做出同样操作。
- 反例：「测出电阻值」——跳步过多。
- 正例：分步写接线、调节、读数，每步含动作与判断条件。

### 5. 数据记录

见第二节。

### 6. 误差分析

见第三节。三类误差必须分别处理。

### 7. 实验结论

见第四节强度匹配。

### 8. 注意事项

安全事项与关键操作要点（如同轴调节不可带电调）。

## 二、数据记录规范

### 有效数字

| 规则 | 说明 |
|---|---|
| 位数由仪器精度决定 | 分度值 0.1 的表读数末位应到 0.1 位 |
| 运算中多留一位 | 中间运算不提前舍入 |
| 最终结果与仪器精度匹配 | 末位不应超出仪器分辨能力 |
| 不确定度按需标注 | 有效数字多位时最好给出不确定度 |

**多写位数是虚假精度**，比写少更严重：它暗示了仪器没有的分辨能力。

### 单位

- 每个数据带单位；表格中**表头**也要标单位。
- 单位统一，不要同一表内混用不同单位。

### 原始记录的可追溯性（硬规则）

**原始记录不得涂改。**

| 做法 | 是否合规 |
|---|---|
| 直接涂黑重写 | ✗ 不合规 |
| 划单横线，原值仍可辨认，旁边写正确值 + 日期 + 签名 | ✓ 合规 |
| 撕页重抄 | ✗ 不合规 |
| 事后补记并注明补记 | ✗ 通常不合规 |

### 异常值处理

**异常值不得直接删除。** 正确流程：

```
1. 标记：先用符号标出可疑数据，不改动原值
2. 判断成因：区分是随机波动、仪器异常还是过失误差（读数/记录错误）
3. 若为过失误差：查原始记录确认读错或记错，按更正规范处理
4. 若为有效测量：保留数据，并说明其对结果的影响
5. 若保留：平均值计算是否含该值必须写明
```

**删除异常值会让报告失去可信度**，且若未说明，属于数据处理不当。

## 三、误差三分类（核心）

| 类型 | 成因 | 方向性 | 多次测量能否消除 | 正确处理 |
|---|---|---|---|---|
| **系统误差** | 仪器零偏、方法本身缺陷、刻度不准、环境固定偏差 | 有固定方向 | **不能** | 指出来源 + 改正办法（校准、换方法、修正公式） |
| **随机误差** | 温度波动、读数末位随机性、偶然因素 | 无规则 | 可通过平均减小 | 多次测量取平均 + 给出偏差/不确定度 |
| **过失误差** | 读错、记错、违反操作规程 | 无规律但有明确人为原因 | 可通过规范操作避免 | 查明并舍弃，说明舍弃依据 |

### 最典型的错误

**把系统误差当随机误差处理，用多次测量取平均。**

原因：随机误差经平均会减小，而**系统误差不会因重复测量而消失**——重复测量只会让结果稳定地偏在错误值上，越测越自信。

### 表述模板

- 系统误差：「本实验的系统误差主要来自 ___，表现为测量值始终 ___ 偏离真值，可通过 ___ 加以改正。」
- 随机误差：「随机误差由 ___ 引起，表现为读数的无规则波动。通过测量 ___ 次取平均值，可将其影响减小。」
- 过失误差：「第 ___ 组数据因 ___ 属过失误差，已舍弃，舍弃依据为 ___。」

## 四、结论强度与数据强度匹配

| 数据情况 | 允许的结论强度 | 禁止的写法 |
|---|---|---|
| 单次测量 | 「本次测得 ___」 | 「验证了…成立」 |
| 多次测量、偏差小 | 「在实验条件下测得 ___ 约为…」 | 「普遍规律为…」 |
| 有对照、重复充分、偏差可估计 | 可讨论规律与适用范围 | 无限制推广 |
| 无对照或样本极少 | 只能描述观察 | 任何规律性结论 |

### 越界的判据

**把结论改写成「在 ___ 条件下，___ 等于 ___」，如果填不出条件，就是越界。**

## 五、图表规范

| 项 | 要求 |
|---|---|
| 坐标轴标注 | 横轴与纵轴都须有名称与单位 |
| 图例 | 多条曲线必须有图例 |
| 单位 | 图中或轴标注中给出 |
| 数据点 | 标出数据点而非只有连线 |
| 误差棒 | 多次测量必须画误差棒 |
| 截断轴 | 纵轴不从零起时必须标注截断 |
| 分辨率 | 打印后数字仍清晰可读 |

**最常见缺项**：坐标轴无单位、多次测量无误差棒、纵轴截断未标注。

## 六、常见扣分点速查

| 扣分点 | 正确做法 |
|---|---|
| 涂改原始记录 | 划线更正 + 签名日期 |
| 数据无单位 | 每项带单位，表头也标 |
| 有效数字超位 | 按仪器精度取 |
| 直接删异常值 | 标注 + 说明处理方式 |
| 误差分析空泛 | 三类分开写成因与办法 |
| 系统误差当随机误差 | 单列并给改正办法 |
| 器材无精度 | 写量程与分度值 |
| 步骤跳跃 | 拆到可复现 |
| 结论过度推广 | 匹配数据强度 |
| 图表无轴标注/图例 | 补齐并标单位 |
