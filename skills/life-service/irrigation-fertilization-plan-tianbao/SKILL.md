# 灌溉施肥（irrigation-fertilization-plan）

灌溉和施肥是「看天看地看作物」的活，**没有一把通用的量**。本技能不替你拍脑袋定浓度，而是给你一套能照着排、能回头核对的框架：什么时段浇、用什么方式、频次怎么随生育期变，施肥怎么记才不会多施少施都靠猜。

这个技能做三件事：**排灌溉 → 排施肥 → 做记录**。

---

## 一、硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出灌溉频次、方式、时段口径 | ❌ 给出任何农药/叶面肥的稀释浓度与喷施强指令 |
| 给出按生育期的施肥记录框架 | ❌ 判断土壤缺哪种元素并开方配肥 |
| 给出 N-P-K 概念的通俗说明与核对清单 | ❌ 指导大规模农田的水肥一体化工程排期 |
| 给出干旱/涝害的观察判断与转交线 | ❌ 承诺任何产量或节水结果 |

**转交专业农技/植保人员的情况**

- 大范围连片缺水或积水成因不明
- 疑似盐碱、酸化需专业土样与配方
- 涉及农药、除草剂、叶面肥浓度的选择
- 需要专业水肥一体化设计

| 「打什么药防虫」 | ❌ 不可 | 转交植保 |

## 三、完整工作流

1. **定作物与地块**：叶菜/果菜/根菜差别大，花盆/菜地/大棚蒸发不同。
2. **排灌溉方式**：优先滴灌/沟灌节水，漫灌最费水且易板结。
3. **排时段**：清晨或上午浇，避开中午高温与傍晚闷湿。
4. **排频次**：随天气与生育期调整，见干见湿、不积水。
5. **排底肥**：整地时施足腐熟底肥，是根基。
6. **排追肥**：按苗期、生长期、花果期分次，少量多次。
7. **做记录**：每次灌溉与施肥记下日期、量、作物状态。
8. **核对**：对照记录看长势与问题，避免重复错误。
9. **用脚本核对**：用 `--file` 跑一遍，把错时段、错方式、漏记录先排掉。

## 四、核心规则说明

**动手之前必须先读这两个文件，不要凭印象写：**

- `rules/灌溉频次与方式.md` —— 频次区间、方式选择、时段与覆盖保墒
- `rules/施肥记录与核对.md` —— 底肥追肥框架、N-P-K 通俗说明、记录模板

要点三条：

1. **时段比次数更要紧**。中午浇水蒸发大、还容易灼叶；傍晚浇水叶心积水易生病。清晨/上午最好。
2. **记录是施肥的灵魂**。不记就不知道上次施了多少，容易累加过量。
3. **底肥打底、追肥少量多次**。一次猛施烧苗，分次才稳。

## 五、脚本用法

```
python scripts/irrig_fert_plan.py --selftest
python scripts/irrig_fert_plan.py --file plan.json
```

输入字段：

| 字段 | 说明 | 示例 |
|---|---|---|
| crop_type | 作物类型 | 「叶菜」「果菜」「根菜」 |
| area_type | 地块类型 | 「花盆」「菜地」「大棚」 |
| irrigation_method | 灌溉方式 | 「滴灌」「漫灌」「喷灌」「人工」 |
| frequency_per_week | 每周灌溉次数 | 4 |
| time_of_day | 浇水时段 | 「清晨」「上午」「傍晚」「中午」 |
| mulch | 是否覆盖保墒 | true |
| fert_stages | 已安排施肥的生育期列表 | 「底肥」「苗期」「花果期」 |
| npk_recorded | 是否记录 N-P-K 类型 | true |
| records_kept | 是否做灌溉施肥记录 | true |

结论分三档：**先处理**（时段错、方式非法、频次越界）、**待确认**（信息不足/漏记录）、**可照此执行**。存在真实缺陷时即使信息也不完整仍判先处理。

结果写入 `scripts/_last_result.txt`，每条不合格带原因。

## 六、人工确认清单（这步不能省）

- [ ] 已按作物与地块类型排灌溉方式（优先滴灌/沟灌）
- [ ] 浇水时段是清晨或上午，不是中午、不是傍晚积水
- [ ] 频次随天气与生育期调整，地面不长期积水
- [ ] 已安排腐熟底肥
- [ ] 追肥按生育期分次、少量多次
- [ ] 每次施肥记下了日期、种类、量
- [ ] N-P-K 类型有记录，不是凭感觉混
- [ ] 有覆盖保墒，减少无效蒸腾
- [ ] 干旱/涝害观察项有对照，异常已停手转农技

## 七、最常见的坑

1. **中午浇水**。蒸发快、易灼叶，等于白浇还伤苗。
2. **只记次数不记量**。施肥不记量，累加起来超了都不知道。
3. **一次猛施肥**。烧苗、徒长、落花落果都来。
4. **底肥忘了**。根基不牢，后面追再多也补不回来。
5. **漫灌当习惯**。费水、板结、涝根，能滴灌就滴灌。
6. **傍晚大水**。叶心积水一晚，病害爆发。
7. **不覆盖**。表土干得快，浇水更频繁。
8. **凭感觉配肥配药**。浓度拿不准就问农技，别自己估。
