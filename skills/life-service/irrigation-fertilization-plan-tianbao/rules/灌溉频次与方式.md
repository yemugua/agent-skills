# 灌溉频次与方式口径

本文件是「灌溉施肥」技能的核心资产。**排灌溉前先读这里。** 数值为家庭菜园/小型地块通用参考，具体以作物、天气与本地条件为准。

## 1. 灌溉方式选择（按节水与安全性排序）

| 方式 | 评价 | 适用 |
|---|---|---|
| 滴灌 | 最节水、不烂叶 | 菜地、大棚、盆均宜 |
| 沟灌 | 较节水 | 菜地垄作 |
| 喷灌 | 中等 | 大面叶菜，但叶心易湿 |
| 人工浇 | 灵活但费工 | 花盆、小面积 |
| 漫灌 | 最费水、易板结涝根 | 尽量避免 |

## 2. 浇水时段（重要）

- **首选清晨或上午**：温度回升前浇完，叶片能尽快干，病害少。
- **避免中午**：蒸发大、水温与土温差易灼叶。
- **避免傍晚大水**：叶心积水一晚，病害高发。

## 3. 频次区间（通用参考，随天气与生育期调整）

| 作物/地块 | 每周参考频次 | 原则 |
|---|---|---|
| 花盆叶菜 | 4-7 次 | 盆土浅易干，见干见湿 |
| 菜地叶菜 | 2-4 次 | 保水力好于盆 |
| 果菜/根菜 | 1-3 次 | 花果期需水稳，忌忽干忽湿 |
| 大棚 | 视温湿度 | 覆膜后显著减少 |

- 频次不在 1-21 次/周区间判为不合理。
- 核心原则：**见干见湿、不积水、不长期干旱**。

## 4. 覆盖保墒

- 秸秆/碎草/地布覆盖，减少无效蒸腾，降低浇水频次。
- 菜地、大棚建议覆盖；花盆可铺陶粒/松针。

## 5. 干旱与涝害观察（只观察，不诊断）

| 观察 | 可能问题 |
|---|---|
| 午后萎蔫、傍晚恢复 | 短期缺水 |
| 持续萎蔫、土干裂 | 严重干旱 |
| 叶黄、根褐、土长期湿臭 | 涝害/烂根 |

涝害或干旱成因不明、连片发生，停手联系农技。

## 6. 禁忌（硬红线，碰到即判不合格）

- 中午高温时段浇水
- 灌溉方式非法（不在已知方式内）
- 每周频次不在 1-21 区间
- 涉及农药/叶面肥稀释浓度的强指令（不在本技能范围）
