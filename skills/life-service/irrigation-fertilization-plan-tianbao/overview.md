# 灌溉施肥（灌溉施肥 / irrigation-fertilization-plan）

你会得到什么：一套家庭菜园与小型地块的灌溉施肥计划框架——按作物与地块（花盆/菜地/大棚）排灌溉方式（优先滴灌/沟灌）、浇水时段（清晨或上午，避开中午与傍晚积水）、频次区间（见干见湿、不积水），以及按生育期（底肥→苗期→生长期→花果期）的施肥记录模板与 N-P-K 通俗说明。技能内置 `irrig_fert_plan.py`，把计划写成 JSON 跑一遍，自动标出中午浇水、方式非法、频次越界、漏底肥、无记录等不合格项并附原因。

典型用法：菜地几天浇一次、早上浇还是晚上浇、滴灌怎么选、施肥怎么记才不会多施、底肥追肥怎么排。写成字段交給脚本，立刻拿到「先处理 / 待确认 / 可照此执行」的结论。

边界：本技能只做灌溉时段/方式/频次的判断与施肥记录核对，**不替代专业农技配方，也不提供任何农药或叶面肥的稀释浓度与喷施强指令**。涉及农药、除草剂使用请咨询农技或植保人员。
