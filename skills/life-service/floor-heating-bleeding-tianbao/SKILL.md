# 地暖排气

## 1. 硬边界（能做什么 / 不能做什么）

| 能做 | 不能做（必须转交专业人士） |
|---|---|
| 分水器排气阀排气、逐路排空气 | 拆改分水器主体、切割埋地管 |
| 清洗过滤器滤网、排气后观察升温 | 怀疑埋地管漏水时自行打压 |
| 判断气堵 / 脏堵 / 水力失衡 | 壁挂炉报故障码、燃烧相关异常 |
| 调节各回路阀门开度平衡室温 | 改动主管道、私自加泵 |

出现以下任一情况，停止操作并联系供热公司或持证暖通工：分水器或管道明显渗水、地面阴湿起鼓、壁挂炉显示故障代码、排气后整户仍完全不热且邻户同样。

## 2. 什么时候用

| 用户说法 | 用不用本技能 |
|---|---|
| 地暖一半热一半不热 | 用（典型气堵，逐路排气） |
| 分水器有哗啦流水声 | 用（管路有气，排气） |
| 刚供暖前两天不热 | 先用（先排气，再等系统循环） |
| 整户完全不热、邻户也冷 | 不用（先问供热公司是否外网问题） |
| 某房间一直不热且排气无效 | 不用（可能埋地管问题，转专业） |

## 3. 完整工作流

1. 确认壁挂炉 / 热源已正常运行、供水有温度。
2. 关闭分水器回水总阀（防止排气时回水倒灌喷溅）。
3. 准备接水容器、毛巾，套在排气阀下方。
4. 用一字螺丝刀或排气钥匙，缓慢拧松最上方回路的排气阀，听到「嘶」声即放气，见连续水流出再拧紧。
5. 按从「最不热」到「较热」的顺序逐路排气，每路见水即止。
6. 全部排完后，缓慢打开回水总阀。
7. 等待 30–60 分钟，用手摸各回路管道确认升温均匀。
8. 若仍不热，转第 4 节诊断表。

详细步骤与判定口径见 `rules/bleeding-steps.md`。

## 4. 核心规则 / 要件说明

生成任何排气方案或排查结论前，**先读 `rules/bleeding-steps.md`**，不要凭印象写：
- 排气顺序、阀门开关顺序有强制要求（先关回水总阀再开排气阀，否则喷溅）。
- 「气堵」与「脏堵」「水力失衡」判定口径不同，处理方式不同。
- 不合格项必须带原因（如「第 3 路未排气：该路明显冰凉，说明仍有气堵」）。

## 5. 脚本用法

本包提供 `scripts/bleed_check.py`，用于自检「排气操作清单」的顺序与完整性：

```
python scripts/bleed_check.py --file steps.json
python scripts/bleed_check.py --selftest
```

参数：`--file` 指定 JSON（`{"steps":[...]}`）或每行一步的文本；`--selftest` 跑内置回归。脚本会写盘结果到同目录 `_last_result.txt`。

## 6. 人工确认清单（不可省略）

- [ ] 热源已开、供水有温度
- [ ] 回水总阀已先关闭再开排气阀
- [ ] 每路都见到连续水流出才拧紧
- [ ] 排气后等待 ≥30 分钟再判断
- [ ] 无渗水、无故障码

## 7. 最常见的坑

1. 只排一路就以为完成：多路系统必须逐路排，否则仍半热半冷。
2. 先开排气阀后关回水阀：水会喷溅，且排不干净。
3. 把「水力失衡」当气堵：邻路都热只有一路冷，可能是该路阀门没开或堵塞，排气无效。
4. 刚供暖就急：系统还没循环满，先排气再等半天，别反复拧。
5. 排气阀拧太紧再拧滑丝：见水即止，用手感拧紧即可，别用蛮力。
6. 忽略过滤器：分水器前过滤器堵了也会不热，排气前先看过滤器。

## 8. 边界与免责

本指南仅适用于常见水地暖气堵排查，不含电地暖、不含埋地管维修。操作前确认自家系统类型；老旧小区或集中供暖请联系物业 / 供热公司，避免影响整栋楼水力平衡。
