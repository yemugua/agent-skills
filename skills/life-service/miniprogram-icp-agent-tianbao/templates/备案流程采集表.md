# 小程序 ICP 代备案流程采集表

> 填写说明：把「值」列按实际情况填写；不确定的留空或填「待确认」。留空一律按「有风险/待补正」处理。

| 字段 | 值 |
| --- | --- |
| 主体类型 | 企业 / 个体工商户 / 个人 |
| 是否持有营业执照 | 是 / 否 / 待确认 |
| 统一社会信用代码 | 填执照上的 18 位代码 |
| 小程序是否已注册并认证 | 是 / 否 / 待确认 |
| 小程序名称 | 你的小程序名 |
| 服务类目 | 如：工具、电商、资讯、医疗、食品、金融… |
| 是否涉及特殊类目 | 是 / 否 / 待确认 |
| 特殊类目资质是否齐备 | 是 / 否 / 待确认 |
| 域名是否已注册并实名 | 是 / 否 / 待确认 |
| 域名是否已完成ICP备案 | 已备案 / 未备案（本次待办）/ 待确认 |
| 接入商/服务器 | 如：腾讯云、阿里云（大陆节点） |
| 当前备案状态 | 未备案 / 已提交待审 / 管局审核中 / 已备案 / 被驳回 |
| 是否委托第三方代备案 | 是 / 否 / 待确认 |
| 负责人/法人信息是否齐全 | 是 / 否 / 待确认 |
| 是否完成人脸核验 | 是 / 否 / 待办 |
| 是否完成管局短信核验 | 是 / 否 / 待办 |
| 是否需要前置审批文件 | 是 / 否 / 待确认 |
