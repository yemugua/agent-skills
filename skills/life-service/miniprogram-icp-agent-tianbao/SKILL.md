# 小程序 ICP 代备案流程与操作指引

面向小程序开发者与运营：准备上线要做 ICP 备案、备案被驳回要整改、想委托代备案但怕踩坑、不确定流程走到哪一步的场景。本技能在已发布的「小程序备案与类目资质核查」基础上，**补充完整备案操作流程与代备案注意事项**。

## 它能做什么

- 核查 **前置条件**：主体证件（企业/个体须营业执照、个人用身份证）、小程序注册认证、域名实名、接入商是否齐备
- 定位 **备案流程阶段与下一步**：准备 → 平台审核 → 人脸核验 → 管局审核 → 短信核验 → 完成/被驳回
- 映射 **特殊类目资质**：医疗/食品/金融/出版/新闻等类目所需主管部门许可
- 提示 **代备案风险**：主体真实性、不得买卖套用备案、警惕「包过」夸大承诺
- 预警 **常见驳回原因**：信息不符、类目与页面不符、资料模糊、短信核验超时、前置审批缺失
- 给出 **阻断项 + 待办清单**与标准 8 步操作指引

## 使用方式

把 `templates/备案流程采集表.md` 填好（两列表或「字段：值」），交给本技能生成报告。
未填项一律按「待补正 / 有风险」处理，绝不判通过。

## 边界

本结果依通用流程与公开参考值整理，不替代管局与微信公众平台官方审核结论，最终以工业和信息化部备案系统、省级通信管理局与微信公众平台及官方文档为准。不得买卖、套用备案主体或提交虚假材料。
