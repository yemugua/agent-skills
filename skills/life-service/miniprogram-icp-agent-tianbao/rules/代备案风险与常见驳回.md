# 代备案风险与常见驳回原因

## 委托第三方代备案的风险提示

1. 主体真实性：备案主体必须是你自己的企业/个体/个人，不得由代理买卖或套用他人主体。
2. 材料真实：提交虚假信息将被驳回乃至列入备案黑名单，影响后续所有备案。
3. 机构选择：选有资质的接入商/代理机构，警惕「包过」「免材料」「低价速过」等夸大承诺与隐形收费。
4. 控制权：备案成功后账号与域名控制权须归你，避免被代理机构绑定或截留。
5. 费用：备案本身由管局免费审核，代理仅收服务费；被驳回重新提交不重复缴费。

## 常见驳回原因

| 驳回原因 | 说明与整改 |
| --- | --- |
| 主体信息不符 | 营业执照/身份证信息与填写不一致，核对后重填 |
| 类目与页面不符 | 所选服务类目与实际页面内容不一致，调整类目或页面 |
| 资料模糊/不全 | 证件照片不清晰或缺失，重新上传清晰完整件 |
| 短信核验超时 | 管局短信 24 小时内未核验，订单退回，须重新提交 |
| 负责人信息错 | 负责人/法人信息填写错误或缺失，更正后重提 |
| 前置审批缺失 | 新闻/出版/药品等类目未提供前置审批文件，先取得再提交 |
| 域名未实名 | 域名未完成实名或实名不满规定天数，先完成实名 |

## 纪律红线

- 不得买卖、套用备案主体。
- 不得提交虚假材料。
- 备案结论以管局与平台为准，本指引不替代官方审核。
