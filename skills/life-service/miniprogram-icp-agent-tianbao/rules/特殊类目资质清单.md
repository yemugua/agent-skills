# 特殊类目与所需资质（核查映射表）

> 说明：以下为常见需主管部门许可或资质的服务类目示例，实际以微信公众平台「资质管理」要求与主管部门规定为准。
> 资质须在有效期内，主体须与小程序注册主体一致。

| 类目关键词 | 所需资质示例 |
| --- | --- |
| 医疗 / 医疗服务 | 医疗机构执业许可证；互联网诊疗须另行审批 |
| 药品 | 药品经营许可证（线上售药另有严格规定） |
| 医疗器械 | 医疗器械经营许可证或备案凭证（按类别区分） |
| 食品 / 餐饮 | 食品经营许可证或食品生产许可证（仅预包装食品需备案） |
| 金融 / 理财 / 借贷 | 金融业务许可或备案（须持牌，个人不得从事） |
| 证券 | 证券投资咨询 / 经营证券期货业务许可证 |
| 基金 | 基金销售业务资格 |
| 保险 | 经营保险业务许可证、保险中介许可证 |
| 支付 | 支付业务许可证（第三方支付牌照） |
| 直播 | 网络文化经营许可证、信息网络传播视听节目许可证 |
| 游戏 | 游戏版号、ISBN |
| 出版 / 网络出版 | 出版物经营许可证 |
| 新闻 | 互联网新闻信息服务许可（个人不得采编） |
| 教育培训 / 学科类 | 办学许可证（学科类培训另有规定，须谨慎） |
| 招聘 / 人力资源 | 人力资源服务许可证 |
| 婚恋 | 相关经营资质与实名认证机制 |
| 宗教 | 宗教活动场所 / 主管部门材料（限制严格） |
| 危化品 | 危险化学品经营 / 安全生产许可证 |
| 网约车 | 网络预约出租汽车经营许可 |
| 拍卖 | 拍卖经营批准证书 |

## 增值电信业务许可证提示

若小程序涉及以下场景，通常还需《增值电信业务经营许可证》（ICP 证 / EDI 证）：
- 电商平台、商家入驻、在线交易撮合
- 收费信息服务、会员付费、有偿信息发布
- SaaS 类对外收费服务

纯展示、企业自有官网类一般不强制；具体以主管部门与平台要求为准。
