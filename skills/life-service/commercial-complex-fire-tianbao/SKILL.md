# 大型商业综合体消防管理（commercial-complex-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《大型商业综合体消防安全管理规则》（XF/T 3019）生成综合体消防管理清单：多产权统一管理、餐饮动火、疏散救援、微型站联勤。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 商业综合体消防
- 商场消防
- 大型商业消防
- 多产权建筑
- 综合体应急

## 三、工作流
1. 确认建筑性质与多产权架构
2. 建立统一消防管理单位与协议
3. 餐饮/娱乐场所用火用电专项
4. 疏散路线与消防救援窗核查
5. 微型消防站联勤与应急联动

## 四、核心内容（检查清单与判定）
XF/T 3019 要求大型商业综合体实行消防安全统一管理，设置取得资格的消防安全管理人；餐饮场所排油烟管道每季度清洗。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未明确统一消防管理单位/协议 | XF/T 3019 |
| Q2 | FAIL | 餐饮商铺未含动火与油烟管道清洗要求 | 餐饮专项 |
| Q3 | WARN | 未核查疏散楼梯/救援窗独立性 | 疏散救援 |
| Q4 | FAIL | 未建微型消防站或联勤机制 | 微型站 |
| Q5 | WARN | 夜间/闭店后管理要求缺失 | 值班 |

> 脚本 `commercial-complex-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python commercial-complex-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python commercial-complex-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
