# 遗嘱订立操作卡（照着做，别自己发挥）

## 一、选形式

| 你的情况 | 建议 |
|---|---|
| 神志清楚、能写字、内容简单 | **自书**（最简单，不用见证人） |
| 不会写 / 手抖写不了 | **代书**或**打印**（要两个见证人） |
| 想留影像、怕日后被质疑神志 | **录音录像**（把姓名、日期、神志状态说清楚） |
| 希望程序最稳、争议最少 | **公证**（到公证机构办理） |
| 病危抢救中 | **口头**（危急消除后必须重立，否则无效） |

## 二、自书遗嘱：照这个模板写

```
遗嘱

立遗嘱人：______，身份证号：____________，
现住：____________。

本人神志清楚，具有完全民事行为能力，
自愿订立本遗嘱，内容如下：

一、本人名下的______（财产描述、权证号），
    由______（姓名、身份证号）个人继承。

二、本人名下的______，由______个人继承。

三、此前所立遗嘱与本遗嘱抵触的，以本遗嘱为准。

立遗嘱人（签名）：____________
年  月  日
```

**四条硬要求**：
1. **全文手写**，一个字都不能打印；
2. **签名**与身份证一致；
3. **年月日齐全**；
4. 改动的字旁**另行签名确认**，别涂黑。

## 三、需要见证人的三种形式：见证人怎么找

```
至少 2 人，且必须同时满足：
  ✅ 完全民事行为能力人
  ✅ 不是继承人、不是受遗赠人
  ✅ 与继承人、受遗赠人无利害关系（不是其配偶、子女、父母、
     兄弟姐妹、债权人、债务人、合伙人）
  ✅ 全程在场，中途不离开
  ✅ 具备见证能力（看得见、听得见、能理解）
```

**稳妥人选**：社区/村委会工作人员、无任何利益关联的邻居或同事、律师。
**千万别找**：子女、配偶、儿媳女婿、继承人的朋友或生意伙伴。

## 四、行为能力留证（强烈建议）

老人、有认知障碍风险的人立遗嘱时，同时留这些证据：

1. **录像**：立遗嘱全过程，开头说清姓名、日期、地点、"我神志清楚";
2. **见证人书面说明**：两位见证人各写一份《见证说明》，写明时间地点、遗嘱人神志状态、在场人员;
3. **近期的医疗记录**：如有可能，保留近期的认知评估或就诊记录;
4. **遗嘱人自述**：在录像里说明为什么这么分，避免事后被说"受胁迫"。

## 五、表述上的九个别写错

| 别这么写 | 应该这么写 |
|---|---|
| "把**我们家**的房子留给老大" | "把**本人名下**位于××的房产（权证号××）**中属于本人的份额**留给××" |
| "全部财产给某某" | 先查有没有需要保留必留份的继承人 |
| 只签名不写日期 | 年月日三项齐全 |
| 打印后只签最后一页 | **逐页签名**（打印遗嘱） |
| 让儿子做见证人 | 见证人不能是继承人 |
| 涂改后不签名 | 改动处另行签名确认 |
| "我死后房子归他，**生前不给他**" | 遗嘱是死后生效，生前给要走赠与 |
| 处分已卖掉的房 | 先盘点现有财产 |
| 用昵称/小名 | 用身份证上的姓名 + 身份证号 |

## 六、订立后的四件事

1. **保管**：交遗嘱执行人 / 公证处 / 律师 / 银行保管箱；
2. **告知**：至少让一个人知道遗嘱在哪；
3. **清单**：附一份财产清单（房产、存款、账户、股权），并注明权证号；
4. **复查**：家庭、财产、意愿重大变化后重立，写清"以本遗嘱为准"。

## 七、什么时候必须找律师 / 公证

| 情形 | 建议 |
|---|---|
| 财产种类多、金额大 | 找律师 |
| 家庭关系复杂（再婚、非婚生子女、继子女） | 找律师 |
| 有人可能主张必留份 / 行为能力 | 找律师 + 做行为能力留证 |
| 涉公司股权、宅基地、涉外财产 | 找律师 |
| 想程序最稳妥 | 办公证 |

**本技能的定位**：帮你把形式要件逐条核一遍、把坑列出来，**不替代律师**。
