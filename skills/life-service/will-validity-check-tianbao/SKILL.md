# 遗嘱效力自查与订立核查

大量遗嘱不是输在"写得不对"，是输在**形式要件缺一项**。本技能把六种形式的要件逐条拆开，一条一条核。

## 什么时候用

- 自己写了（或准备写）遗嘱，想知道有没有效
- 家里老人留了遗嘱，先自查一遍再决定要不要找律师
- 打印的遗嘱只在最后一页签了名，心里没底
- 让子女做了见证人，担心白写
- 立了好几份遗嘱，不知道以哪份为准
- 涉及夫妻共同房产，不确定能处分多少

## 怎么做

**第 1 步**：复制 `templates/遗嘱信息采集表.md` 填写。

**第 2 步**：跑脚本

```bash
python scripts/will_check.py 采集表.md --base 2026-10-04 --out 核查报告.md
```

**第 3 步**：按第八段"待办补正动作"执行。

## 六种形式的形式要件

| 形式 | 核心要件 |
|---|---|
| **自书** | 亲笔书写全文 + 签名 + 年月日（不需要见证人） |
| **代书** | 2 名以上见证人在场，其中一人代书，遗嘱人/代书人/其他见证人签名，注明年月日 |
| **打印** | 2 名以上见证人在场，**每一页**签名，注明年月日 |
| **录音录像** | 2 名以上见证人在场，录音录像中记录姓名或肖像 + 年月日 |
| **口头** | 危急情况下，2 名以上见证人在场；**危急消除后须重立**，否则无效 |
| **公证** | 经公证机构办理 |

## 见证人资格（第 1140 条）

**不能**做见证人：无/限制民事行为能力人、不具有见证能力的人、**继承人、受遗赠人**、**与继承人受遗赠人有利害关系的人**。

→ 让子女、配偶、继承人的朋友做见证人，代书 / 打印 / 录音录像遗嘱**可能无效**。

## 三条最容易被忽略的规则

1. **打印出来签名 ≠ 自书遗嘱**。要么全文手写，要么按打印遗嘱补全"逐页签名 + 2 名见证人"。
2. **公证遗嘱不再优先**。《民法典》取消了公证优先，数份抵触的**以最后的为准**。
3. **必留份**（第 1141 条）：应为缺乏劳动能力又没有生活来源的继承人保留必要份额，未保留的部分**无效**。

## 输入 / 输出

| | 内容 |
|---|---|
| 输入 | 采集表 Markdown（立遗嘱人 / 形式 / 见证人 / 内容与财产 / 必留份 / 保管） |
| 输出 | 九段报告：结论摘要 / 形式要件 / 见证人资格 / 无效与撤回 / 处分范围 / 必留份 / 保管与执行 / 待办 / 纪律 |
| 退出码 | 0 正常；2 关键信息缺失（给提示串，不崩） |

## 边界与纪律

- 依《民法典》继承编**通用条文**整理，**不替代律师意见**
- **不代拟遗嘱正文**、不代办公证、不预测诉讼结果
- 是否有效的最终认定，以司法机关为准
- 涉港澳台、涉外、遗嘱信托、宅基地与股权继承等，需另行查证
- **未填的一律不算通过**，只按填了的判断
