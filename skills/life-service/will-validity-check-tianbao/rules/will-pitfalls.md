# 遗嘱：十个高频坑与自检清单

## 一、十个高频坑

| # | 坑 | 后果 | 怎么避 |
|---|---|---|---|
| 1 | **打印出来只签名** | 不成立自书遗嘱；按打印遗嘱核又缺逐页签名与见证人 → 两头不靠 | 要么全文手写，要么按打印遗嘱补全要件 |
| 2 | **只签名不写日期** | 形式要件缺失，效力存疑 | 年月日三项齐全 |
| 3 | **打印遗嘱只在最后一页签名** | 要件不全（要求**每一页**签名） | 逐页签 |
| 4 | **让子女/配偶做见证人** | 见证人不合格 → 代书、打印、录音录像遗嘱**无效** | 找无利害关系的完全民事行为能力人，至少 2 人 |
| 5 | **只找一个见证人** | 要求"两个以上"，一个不够 | 至少 2 人，全程在场 |
| 6 | **夫妻共同房产处分整套** | 超出自己份额的部分**无效** | 写清"属于本人的份额"，并附权证号 |
| 7 | **以为公证遗嘱最优先** | 《民法典》已取消公证优先，**以最后的为准** | 看重立时间，重立时写明"以本遗嘱为准" |
| 8 | **口头遗嘱事后没重立** | 危急情况消除后**自动失效** | 情况稳定后立刻重立书面遗嘱 |
| 9 | **录像没说姓名与日期** | 录音录像遗嘱要件缺失 | 开头说清姓名、身份证号、年月日、神志状态 |
| 10 | **没给必留份继承人留份额** | 该部分**无效** | 先查有没有"缺乏劳动能力又无生活来源"的继承人 |

## 二、订立前自检清单

**主体**

- [ ] 立遗嘱人神志清楚、具有完全民事行为能力
- [ ] 意思表示真实，无人胁迫、欺骗
- [ ] 名字与身份证一致，最好写上身份证号

**形式**

- [ ] 选对了形式，且该形式的要件**逐条齐备**
- [ ] 签名、日期齐全
- [ ] 需要见证人的：人数 ≥ 2、资格合格、全程在场
- [ ] 打印遗嘱逐页签名
- [ ] 录音录像里说了姓名（或露出肖像）与日期

**内容**

- [ ] 列的财产都是**本人名下 / 本人份额**
- [ ] 财产描述具体到权证号、账号、坐落
- [ ] 没有处分已出售、已过户、已灭失的财产
- [ ] 受益人写全姓名 + 身份证号
- [ ] 查过有没有需要保留**必留份**的继承人

**后续**

- [ ] 指定遗嘱执行人（可选但建议）
- [ ] 保管到位，至少一个人知道在哪
- [ ] 家庭/财产/意愿变化后及时重立

## 三、订立后什么时候要重立

| 触发事件 | 动作 |
|---|---|
| 离婚、再婚 | 重立 |
| 子女出生 / 收养 / 家庭成员去世 | 重立 |
| 购置或出售大额财产 | 重立或补充说明 |
| 与受益人关系恶化 | 重立 |
| 遗嘱中处分的财产已卖出 | **必须**重立（该部分已落空） |
| 遗嘱人行为能力发生变化 | 在能力尚存时重立，并做留证 |

## 四、容易被忽略的三类财产

| 类型 | 注意 |
|---|---|
| **指定了受益人的人身保险金** | **不属于遗产**，按保险合同给付给受益人，遗嘱处分布了也没用 |
| **死亡赔偿金、抚恤金** | **不属于遗产**，遗嘱处分无效 |
| **公积金、养老金个人账户余额、股权** | 属于遗产，但提取/过户有专门程序，需另查 |

## 五、该找专业人的情形

| 情形 | 找谁 |
|---|---|
| 财产种类多、金额大 | 律师 |
| 再婚家庭、非婚生子女、继子女 | 律师 |
| 可能有人主张行为能力问题 | 律师 + 行为能力留证（录像、见证说明、医疗记录） |
| 涉股权、宅基地、涉外 | 律师 |
| 想要程序最稳 | 公证机构 |

## 六、输出纪律

- 依据《民法典》继承编通用条文整理，**不替代律师意见**；
- 不代拟遗嘱正文、不代办公证、不预测诉讼结果；
- 是否被认定有效，最终以司法机关认定为准；
- 涉港澳台、涉外、遗嘱信托等特殊情形需另行查证。
