# 遗嘱：六种形式与各自的形式要件

## 一、六种形式一览（《民法典》第 1134–1139 条）

| 形式 | 条文 | 核心要件 |
|---|---|---|
| **自书** | 1134 | 遗嘱人**亲笔书写全文**、签名、注明年月日 |
| **代书** | 1135 | 两个以上见证人在场见证；其中一人代书；遗嘱人、代书人、其他见证人**签名**；注明年月日 |
| **打印** | 1136 | 两个以上见证人在场见证；遗嘱人和见证人**在每一页签名**；注明年月日 |
| **录音录像** | 1137 | 两个以上见证人在场见证；遗嘱人和见证人在录音录像中**记录姓名或者肖像**，以及**年月日** |
| **口头** | 1138 | **危急情况**下；两个以上见证人在场见证；危急情况消除后能用其他形式立遗嘱的，口头遗嘱**无效** |
| **公证** | 1139 | 经**公证机构**办理 |

## 二、逐条拆开看（每条都不能少）

### 自书遗嘱

- [ ] **全文亲笔书写**——打印出来再签名，不成立自书遗嘱
- [ ] 签名（与身份证一致的姓名，不要只写昵称、小名）
- [ ] 注明**年、月、日**（三项齐全）
- 不需要见证人

### 代书遗嘱

- [ ] 两个以上见证人**全程在场**（中途离开的不算全程见证）
- [ ] 由其中一人代书
- [ ] **遗嘱人、代书人、其他见证人**都要签名
- [ ] 注明年月日

### 打印遗嘱

- [ ] 两个以上见证人在场见证
- [ ] 遗嘱人和见证人**在每一页**签名（只在最后一页签 = 要件不全）
- [ ] 注明年月日

### 录音录像遗嘱

- [ ] 两个以上见证人在场见证
- [ ] 遗嘱人和见证人在录音录像中**记录姓名或者肖像**
- [ ] 注明**年月日**（在录音录像里说出来）
- 建议：开头先说清姓名、身份证号、日期、地点、神志清楚

### 口头遗嘱

- [ ] 危急情况（生命垂危、突发灾害等）
- [ ] 两个以上见证人在场见证
- ⚠️ **危急情况消除后**，遗嘱人能用书面或录音录像形式立遗嘱的，口头遗嘱**无效**——这是最常见的失效点

### 公证遗嘱

- 到公证机构办理，由公证员按程序办理
- ⚠️ **民法典已取消公证遗嘱优先**：数份遗嘱内容相抵触的，**以最后的为准**，不再看哪份是公证的

## 三、见证人资格（第 1140 条）

**不能**作为遗嘱见证人：

| 不能做见证人的 | 说明 |
|---|---|
| 无民事行为能力人、限制民事行为能力人 | 未成年人、不能辨认自己行为的成年人等 |
| **其他不具有见证能力的人** | 盲人做见证人不能见证"看见"、聋人不能见证"听见"等 |
| **继承人、受遗赠人** | 本人就是受益人的，一律不行 |
| **与继承人、受遗赠人有利害关系的人** | 继承人/受遗赠人的配偶、子女、父母、兄弟姐妹、债权人债务人、合伙人等 |

**实务含义**：

- 让**子女、配偶**做见证人 → 代书、打印、录音录像遗嘱**无效**
- 让继承人的**朋友、同事**做见证人 → 可能被认定有利害关系，风险高
- 稳妥做法：找**与遗产毫无关系的完全民事行为能力人**（如社区工作人员、邻居、同事中无任何利益关联者），**两人以上**，且不是受益人

**见证人数**：两个以上，即**至少两人**，且都须具备资格、全程在场。

## 四、行为能力（第 1143 条）

- 无民事行为能力人、限制民事行为能力人所立遗嘱**无效**
- 判断时点：**立遗嘱时**的状态，不是平时
- 有认知障碍、老年痴呆等情形的，事后极易被质疑——**建议同时做行为能力留证**（见操作卡）

## 五、形式要件 vs 实质要件

| | 内容 |
|---|---|
| **形式要件** | 书写方式、签名、日期、见证人——缺一项就影响效力 |
| **实质要件** | 行为能力、真实意思、内容合法、不违反必留份 |

**两样都要过**。形式要件是硬门槛，实务中大量遗嘱栽在这一步。
