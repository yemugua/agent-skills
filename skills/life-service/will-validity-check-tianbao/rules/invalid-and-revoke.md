# 遗嘱：无效、撤回、必留份与处分范围

## 一、无效的情形（第 1143 条）

| 情形 | 后果 |
|---|---|
| 无 / 限制民事行为能力人所立 | **整份无效** |
| 受欺诈、胁迫所立 | **无效**（必须表示真实意思） |
| 伪造的遗嘱 | **无效** |
| 被篡改的遗嘱 | **篡改的内容无效**（其余部分仍有效） |

## 二、撤回与变更（第 1142 条）

```
遗嘱人可以撤回、变更自己所立的遗嘱。
```

三种撤回方式：

| 方式 | 说明 |
|---|---|
| **明示撤回** | 另立新遗嘱声明撤回前一份 |
| **默示撤回（内容抵触）** | 立有数份遗嘱，内容相抵触的，**以最后的为准** |
| **行为撤回** | 立遗嘱后实施了与遗嘱内容**相反的民事法律行为**，视为对相关内容的撤回 |

**行为撤回举例**：遗嘱把房子留给甲，后来又把这房子**卖掉/赠与他人/过户**——视为撤回该部分。房子不再是遗产，遗嘱那部分落空。

⚠️ **重大变化**：《民法典》**取消了"公证遗嘱优先"**。以前公证遗嘱效力最高，现在**只看哪份在最后**。很多人以为公证的最保险，其实时间先后才是关键。

## 三、必留份（第 1141 条）

> 遗嘱应当为**缺乏劳动能力又没有生活来源**的继承人保留必要的遗产份额。

| 要点 | 说明 |
|---|---|
| 保护对象 | 继承人中**同时**缺乏劳动能力**且**没有生活来源的人 |
| 违反后果 | 对应当保留的份额部分**无效**，不是整份无效 |
| 常见对象 | 未成年子女、重度残疾且无收入的子女、无收入无劳动能力的父母 |
| 与前配偶 | 已离婚的配偶不是法定继承人，不适用必留份 |

**判断**：遗嘱把全部财产给一个人，而某个法定继承人既没劳动能力又没生活来源 → 该部分可被主张无效。

## 四、胎儿预留份（第 1155 条）

遗产分割时，应当**保留胎儿的继承份额**。胎儿出生时为死体的，保留的份额按法定继承办理。

## 五、处分范围：只能处分自己的财产

| 情形 | 后果 |
|---|---|
| 遗嘱处分了**他人的财产** | 该部分**无效** |
| 夫妻共同财产，一方立遗嘱处分**整套房** | **超出自己份额的部分无效**（通常只有一半可处分） |
| 处分**已出售 / 已过户**的财产 | 该部分落空（属于行为撤回） |
| 处分**已灭失**的财产 | 该部分落空 |

**最常见的错误**：夫妻共有的房子，一方写"我把我们家的房子留给大儿子"——只能处分自己的那一半，另一半仍按法定继承走。

## 六、能处分什么

| 财产类型 | 可否遗嘱处分 |
|---|---|
| 个人所有的房产、存款、车辆 | ✅ 可以 |
| 夫妻共同财产中**自己的份额** | ✅ 可以（仅限份额） |
| 家庭共有财产中自己的份额 | ✅ 可以（仅限份额） |
| 公司股权 | ✅ 可以（但受公司章程与公司法限制，需另查） |
| 保险金（指定了受益人） | ❌ 不属于遗产，按保险合同走 |
| 死亡赔偿金、抚恤金 | ❌ 不属于遗产 |
| 农村宅基地使用权 | ⚠️ 房屋可以，宅基地使用权受身份限制，需另查当地政策 |
| 人身性质的权利（如抚养费请求权） | ❌ 不可 |

## 七、遗嘱执行与保管

| 事项 | 建议 |
|---|---|
| 指定遗嘱执行人 | 可以指定；执行人可以是继承人以外的人 |
| 保管 | 交给遗嘱执行人、公证处、律师或银行保管箱；**不要藏在只有自己知道的地方** |
| 告知 | 至少让一个可信的人知道遗嘱在哪里 |
| 更新 | 家庭、财产、意愿发生重大变化时及时重立；重立时在文中写明"此前所立遗嘱与本遗嘱抵触的，以本遗嘱为准" |

## 八、输出纪律

- 本规则依据《中华人民共和国民法典》继承编通用条文整理，**不替代律师意见**；
- 涉港澳台、涉外、遗嘱信托、特留份特殊情形、农村宅基地与股权继承等，需另行查证；
- 不代拟遗嘱正文、不代办公证、不预测诉讼结果；
- 是否被法院认定有效，最终以司法机关认定为准。
