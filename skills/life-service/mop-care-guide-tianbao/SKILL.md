# 拖把与清洁工具保养（mop-care-guide）

拖把是家里最脏的清洁工具，也是最容易被忽略的一件。**一个没晾透的拖把，会把异味、霉菌、甚至整屋子的味道都带起来**——而大多数人处理异味时完全不会想到拖把。

另一个必须记住的红线：**绝不要把含氯消毒剂与酸性清洁剂混合**，会产生有毒气体。

这个技能做四件事：**按材质分类** → **清洗与晾干** → **判断更换** → **守住安全红线**。

- **地面材质对消毒剂不明确**（不确定是否会损伤）

## 三、五类拖把材质对照

| 类型 | 适用场景 | 清洗要点 | 晾干要点 | 注意 |
|---|---|---|---|---|
| **棉拖把** | 传统拖地，吸水强 | 温水洗涤，可加中性清洁剂 | 悬挂晾干，摊开不叠 | 潮湿易有异味；不可用热水久泡 |
| **绒布拖把** | 吸尘与吸水兼顾 | 按产品说明清洗，避免强力搓拧 | 摊开阴干或低温烘干 | 绒面易结团，按说明书处理 |
| **平板拖把** | 瓷砖、大面积地面 | 拖布可拆洗，按说明书操作 | 拖布晾干，塑料底座擦干 | 底座与拖布分别处理 |
| **旋转 mop** | 桶边旋转甩水 | 定期清理桶内污垢，拖布单独洗 | 拆开分别晾干 | 桶内积水是异味来源；拆装按说明书 |
| **一次性拖把** | 局部快速清洁 | 用后按产品说明处理 | 用完妥善处置 | 一般不建议反复使用，按产品说明 |

**三条通用要点**：

1. **按说明书操作**：各类拖把的材料与结构不同，方法差别很大
2. **不混用清洁剂**：一次只用一种
3. **每次用完立即处理**：不要攒几天再洗

## 四、清洗与晾晒流程

**这一节是本技能的核心：必须彻底晾干。**

| 步骤 | 动作 | 说明 |
|---|---|---|
| 1 | 预处理 | 冲掉表面泥沙与毛发；不要在桶里泡一晚上 |
| 2 | 洗涤 | 温水配中性清洁剂，按说明书洗涤 |
| 3 | 冲洗 | 用流动清水冲净，不留洗涤剂残留 |
| 4 | **彻底晾干** | **悬挂或摊开晾干，不叠放** |
| 5 | 确认干燥 | 手摸确认无潮感、无异味后再收 |

**彻底晾干的判断标准**：

| 判据 | 合格表现 |
|---|---|
| 手感 | 手摸拖布各处，无潮感 |
| 异味 | 靠近闻，无异味 |
| 折叠处 | 折叠处最易残留水分，重点摸 |
| 时间参考 | 通风环境下通常数小时；**不要只看时间，看手感** |
| 收放时机 | 干透后收，不干透就塞进柜子 |

**"不叠放"很重要**：叠放会让内层永远接触不到空气，形成闷湿层。

## 五、更换周期与更换信号

**不要死按月数，看四个信号。**

| 信号 | 表现 | 说明 |
|---|---|---|
| **掉毛** | 拖地后地上有毛絮或残留纤维 | 纤维已松散，清洁效果与卫生性都下降 |
| **异味难去** | 洗后仍有异味，或晾干后复现 | 内部已积聚污垢或霉菌，普通清洗无法解决 |
| **清洁力下降** | 同样的地，拖不干净，残留水痕 | 纤维吸水性与结构已退化 |
| **拖布硬化** | 拖布发硬发脆，折叠处开裂 | 材料老化，继续使用会刮伤地面 |

**参考周期**：按使用频率与清洗状况判断。**四个信号出现任一项即应更换**，而不是等到"到了周期"。

**换下来的处理**：按当地垃圾分类要求处理，或清洗后用于非清洁用途（如擦窗、擦家具外侧）——但注意不要用于需要高洁净度的表面。

## 六、消毒与去味

**核心原则：洗涤为主，而不是堆消毒剂。**

| 做法 | 说明 |
|---|---|
| **先洗净再谈消毒** | 表面污垢与有机物会削弱消毒效果，脏的拖把泡再多消毒液也没用 |
| **按说明书使用消毒剂** | 浓度、接触时间、是否需要冲洗，以产品说明书为准 |
| **用洗涤代替消毒（多数场景足够）** | 日常拖地用中性清洁剂洗净并彻底晾干，多数场景已足够 |
| **去味靠洗涤与晾干** | 异味来源通常是潮湿与积垢，靠洗净并彻底晾干解决 |

**常见误区**：往拖把上喷大量消毒液"杀菌"。结果是**消毒液残留被带到每个房间的地面**，而且可能损伤部分材料。

## 七、安全红线

**1. 绝不要把含氯消毒剂与酸性清洁剂混合。**

两者混合会产生有毒气体。含氯消毒剂 + 洁厕灵、含氯消毒剂 + 白醋、含氯消毒剂 + 柠檬酸类除垢剂，都会出问题。

| 危险配对 | 后果 |
|---|---|
| 含氯消毒剂 + 酸性清洁剂 | 产生有毒气体，刺激呼吸道 |
| 含氯消毒剂 + 碱性清洁剂 | 同样不属于安全配对 |
| 两种含氯产品混合 | 有效成分叠加，不可控 |

**2. 消毒剂不可长时间滞留于有人活动的表面。**

地面刚拖完就有人在上面走、玩，是常见情形。按产品说明书说明的使用与冲洗要求处理，不确定时以清水冲净。

**3. 拖把甩干时避免水花飞溅污染周边。**

甩水时注意避开电器、插座、食品与清洁用品存放处。**同时避免自己被污水溅到**——拖把头本身就是污染源。

**4. 其他要求：**

- 洗涤时戴手套，避免长时间接触污水
- 清洁剂与消毒剂保持原包装，不分装到不明容器
- 一次只用一种清洁剂，用完冲净再换下一种
- 对消毒剂过敏者与呼吸道敏感者避免操作

## 八、存放方式

| 部位 | 存放方式 |
|---|---|
| **拖布** | 悬挂晾干；彻底干燥后收放，不叠放 |
| **杆体** | 与拖布分开存放；杆体擦干，避免长期潮湿 |
| **桶** | 洗净、擦干；桶内不留积水 |
| **房间** | 通风处或卫生间外；避免放在潮湿角落 |

**"桶内不留积水"很重要**：长期积水加污垢，是桶发味的直接原因。

## 九、常见误判

| 误判 | 问题 |
|---|---|
| 拖把用完泡在桶里过夜 | 泡出异味与细菌；用完立即清洗晾干 |
| 晾干了再叠起来收 | 叠放形成闷湿层，内层永远干不了 |
| 靠时间判断干没干 | 折叠处与内层最潮，必须手感确认 |
| 用消毒液代替清洗 | 脏拖把泡消毒液效果有限，且残留带到各处 |
| 到期才换 | 四个信号出现任一即应更换 |
| 甩水时水花乱溅 | 污染周边与电器，也可能溅到自己 |
| 桶里长期留水 | 桶发味的直接原因 |
| 消毒液和洁厕灵一起用 | 产生有毒气体 |

```bash
python scripts/mop_care_check.py --text "拖把有味道了，掉毛"
python scripts/mop_care_check.py --pair "含氯消毒液" "白醋"
python scripts/mop_care_check.py --file 情况.json --out 结果.md
```

| 参数 | 说明 |
|---|---|
| `--text` | 直接描述拖把与清洁工具状况 |
| `--file` | 从文件读，支持 `.txt` / `.md` / `.json`（JSON 用 `{"desc": "..."}`） |
| `--pair` | 检查两种清洁剂的配对，输出 danger / warn / ok |
| `--out` | 结果输出路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本做三件事：匹配材质类型与清洗要点、检查更换信号、检查清洁剂配对与安全红线。

> 脚本是关键词匹配，**不等于现场判断**。是否干透要靠手感，异味要靠闻。

## 十二、最常见的坑

**坑一：拖把用完泡在桶里过夜。**
这是异味与细菌的主要来源，也是"家里有味道但找不到源头"的高频答案之一。用完立即清洗晾干。

**坑二：晾干了就叠起来收。**
叠放形成闷湿层，内层永远接触不到空气。要挂起来，不要叠。

**坑三：靠时间判断干没干。**
折叠处与内层最容易残留水分。必须手感确认，手摸各处无潮感才算。

**坑四：用消毒液代替清洗。**
脏拖把泡再多消毒液效果也有限，因为污垢与有机物会削弱消毒效果。而且残留会被带到每个房间。

**坑五：消毒液和洁厕灵一起用。**
会产生有毒气体。**含氯和酸性，永远不混。**

**坑六：刚拖完地就有人在上面走。**
消毒剂在有人活动的表面长时间滞留可能造成刺激，按说明书处理，不确定时清水冲净。

**坑七：甩水时水花乱溅。**
污染周边、电器与清洁用品，也可能溅到自己身上。拖把头本身就是污染源。

**坑八：桶里长期留水。**
积水加污垢是桶发味的直接原因。洗净擦干，不留积水。

**坑九：到"周期"才换拖布。**
出现掉毛、异味难去、清洁力下降、拖布硬化任一信号就该换了，不需要等周期。

**坑十：一次性拖把反复用。**
按产品说明处理，不建议反复使用。
