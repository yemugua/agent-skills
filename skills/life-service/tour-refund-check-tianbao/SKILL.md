# 旅游消费退款维权核查

针对跟团游、自由行套餐、定制游、研学/老年旅游等场景，核查旅行社资质、行程履约、
强制购物、退款口径与证据链，给出四态结论与维权路径。

## 何时使用
- 旅行社行程缩水、擅自变更、降级服务
- 被强制购物、擅自增加自费项目
- 旅行社停业/跑路、卷款失联
- 未出行或已出行想退费，不清楚能退多少
- 付款给个人、无合同、无发票，追偿困难

## 输入输出
- 输入：Markdown 采集表（`| 字段 | 值 |` 或 `字段：值`，全角冒号均认）
- 输出：9 段核查报告；结论四态：通过 / 有风险 / 不通过 / 待补正
- 核心事实（旅游类型、问题描述、已付金额）任一缺失 → 退出码 2，锁「待补正」

## 核查维度
1. 资质与主体：旅行社业务经营许可证、合同主体与收款主体一致性
2. 行程履约：缩水/擅自变更、强制购物（高危）
3. 退款口径：已付−已发生、是否出行、对公付款凭证
4. 证据链：合同/订单、付款凭证、行程单、沟通记录、购物与损害凭证

## 边界
- 仅做信息核查与维权路径指引，不构成法律意见
- 不提供任何代办投诉或代制证据服务
- 法律依据：《旅游法》第三十五条、第六十五条
