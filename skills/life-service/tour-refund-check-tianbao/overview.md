# 旅游消费退款维权核查 · 概述

旅游消费纠纷高发于三类情形：**行程缩水/擅自变更**、**强制购物与自费项目**、**旅行社跑路卷款**。
本技能帮用户把一纸投诉材料需要的"事实+证据+法律依据+路径"一次性梳理清楚。

## 核心结论四态
- **通过**：资质齐全、有合同、行程无缩水、无强制购物、付款凭证完整
- **有风险**：无合同 / 主体不一致 / 付款给个人 / 行程有争议但未确认
- **不通过**：强制购物、旅行社跑路、声称无资质经营
- **待补正**：旅游类型 / 问题描述 / 已付金额 任一未填

## 退款口径（关键）
- **未出行**：通常可主张全额退（扣除已实际发生且不可退的订票/签证等）；旅行社原因取消应全额退并可能赔偿
- **已出行**：依《旅游法》第六十五条，解除合同时组团社扣除已支付且不可退还费用后，余款退还；扣除项须有凭证

## 投诉主入口
- 12345 市民热线 / 全国旅游监管服务平台（文旅投诉）
- 12315（消费类）
- 文化和旅游部门（资质、强制购物）
- 市场监管（虚假宣传、跑路）
- 公安（卷款跑路、合同诈骗）
