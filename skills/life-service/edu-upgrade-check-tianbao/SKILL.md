# 学历提升报考与退费核查

这类事的坑集中在**收费之后**。报名时说得天花乱坠，交完钱才发现协议里写着「一经报名不退不费」，而钱已经转给了某个私人微信。

## 什么时候用

- 想提升学历，被机构游说报班，还没决定要不要交钱
- 已经交了钱，想知道能不能退、怎么退
- 对方说「保过」「不过退款」「不用考试」「一年拿证」
- 机构让你贷款或分期，说「三期免息」
- 协议签了但没看清退费那几条
- 想报自考/成考/国开，不确定哪个更适合自己

## 怎么做

**第 1 步**：复制 `templates/学历提升信息采集表.md` 填写（提升途径、机构名称、**机构说过的承诺原话**、是否贷款、缴费情况最关键）。

**第 2 步**：跑脚本

```bash
python scripts/edu_upgrade_check.py 采集表.md --base 2026-10-05 --out 核查报告.md
```

**第 3 步**：**先照第八段第 1~2 步查资质**（教育部名单 + 学信网），资质查不到就不用往下走了。资质没问题再谈合同与退费。

## 三条最该记住的规则

1. **「包过」几乎可以确定是骗局**。考试由**省级教育考试院命题组织**，机构无法左右；「不用考试」同样不可能。凡是这两种说法，直接排除该机构。
2. **任何让你贷款或分期的，一律拒绝**。**贷款责任不能转移**——机构跑了你照样还贷，可能同时背债务和征信污点。学费可以直接付给学校或机构对公账户。
3. **学费由学校收，服务费才是机构收**。正规机构会分开收；「全部打包交给机构」往往意味着**打包费里含着无法退的部分**。钱打到个人账户时，一旦出问题极难追回。

| 退出码 | 0 正常；2 关键信息缺失（给提示串，不崩） |

## 边界与纪律

- 依**通用规则**整理，**不替代律师意见**；报考条件、学制、学费标准与退费规则，**以教育部、省级教育考试院与院校官方口径为准**
- 不预测能否通过考试，也不预测投诉或诉讼结果
- **未填的一律不算通过**，只按已填内容判断
- 涉及身份证号、学历证书号、账号等敏感信息，**本地处理，不要外发**
- 涉及**替考、代办证件、买卖学籍**的，属违法行为，**应向公安机关报案而非仅追讨退款**
