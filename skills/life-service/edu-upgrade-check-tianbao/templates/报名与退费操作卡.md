# 报名与退费操作卡

> 三条红线：**「包过」「不用考试」= 骗局**；**让你贷款 = 拒绝**；**钱打个人账户 = 停手**。

## 【报名前：先查资质，别急着交钱】

- [ ] 学校名称在**教育部全国高等学校名单**查到，**截图**
- [ ] 机构名称在**省教育厅学历教育名单**查到，**截图**
- [ ] 中外合作项目在**教育部监管平台**确认，**截图**
- [ ] 目标院校**当前是否还在招生**（网络教育尤其要确认）
- [ ] 报考条件**自己对照官方要求核对过**，不只听机构说
- [ ] 学费**和学校官网公布的标准**对得上

**四条红线命中任何一条，直接走人：**

- [ ] ❌ 说「包过」「保录取」「不过退款」
- [ ] ❌ 说「不用考试」「直接拿证」「一年拿证」
- [ ] ❌ 让签贷款或分期合同
- [ ] ❌ 钱要打到个人微信/个人银行卡

## 【签约前：把承诺写进合同】

- [ ] 问清四件事：**谁出题、谁录取、谁发证、谁注册学籍**
- [ ] 「学费」与「服务费」**分开列明金额**
- [ ] 收款账户是**学校或机构的对公账户**，户名与机构名一致
- [ ] 能开**发票**（不是收据）
- [ ] 承诺的每一句都写进合同或补充协议
- [ ] **退费规则**写清：退多少、多久退、扣哪些
- [ ] 拒绝「一经报名不退不费」这类条款，要求拆成「已发生」与「未发生」两部分
- [ ] 合同**当场看完**，尤其退费那几条
- [ ] **自己留一份合同原件**

**退费谈判话术**：
> "已开通的课程按课时扣可以，但没上的部分、没发的教材应该全额退。
> 我们把这两部分拆开写清，并写明退款金额、时限和方式。"

## 【缴费后：立刻做】

- [ ] 索要**收据或发票**（写明服务内容与金额）
- [ ] 截图保存**转账成功页面**，备注写"XX 培训费"
- [ ] 合同**原件自留一份**
- [ ] 记录**课程账号与开通情况**
- [ ] 保存机构的**宣传材料**（含承诺话术的海报、视频、朋友圈截图）

## 【要退费时：按节奏走】

- [ ] 第 1 天：**书面**提出退费要求（写明金额、理由、时限）
- [ ] **EMS 邮寄 + 现场递交**，双留痕，索取回执
- [ ] 7~15 日：**不主动催**，等对方答复（留证据）
- [ ] 15 日后无答复 → **12315** 或当地**教育局/文旅部门**投诉
- [ ] 附全套材料：合同、收据、转账记录、承诺截图、资质查询截图
- [ ] 必要时申请**调解或仲裁**
- [ ] 金额大且证据充分 → 咨询律师评估诉讼

**投诉时的说法**：
> "我已于 X 月 X 日向 [机构] 提出退费要求，对方以'一经报名不退费'为由拒绝。
> 该条款属不合理免除其自身责任的格式条款，且对方招生时承诺'不过退款'，承诺与协议不符。"

## 【涉诈骗、伪造证件时：直接报案】

- [ ] 承诺包过但收了钱失联
- [ ] 提出代考、替考、代做作业
- [ ] 提出买卖学籍、挂靠学籍
- [ ] 提出办证、买证
- [ ] 收了钱跑路、拉黑失联

→ **向公安机关报案**，索取**受案回执**，说明"已交 X 元、对方承诺包过后失联"。

## 【避坑清单】

- [ ] 别相信「能协调考试」「内部名额」——考试由省教育考试院命题，无人能左右
- [ ] 别相信「国家承认」就等于学历——**要确认学信网能查到学籍**
- [ ] 别把学费一次性打包交给机构——正规是学校收学费、机构收服务费
- [ ] 别信「正规途径没用」——成考自考都是国家承认学历
- [ ] 别为了「尽快拿证」接受挂靠学籍——影响征信、考公、职称
