# 中介套路与资质核查

## 一、八类套路话术（脚本 `FRAUD_PATTERNS`）

### 1. 承诺包过 / 保录取
**话术**：「包过」「保过」「包录取」「不过退款」「保过班」「百分百」「稳过」「内部名额」

**为什么一定是骗局**：考试由**省级教育考试院命题与组织**，机构既无权命题也无权录取。**「内部名额」纯属捏造。**

**注意**：「不过退款」听起来有保障，但配套的通常是**苛刻退费条件**（如"需在报名后 15 天内申请"、"扣除全部教材费"），**根本没退成过**。

**应对**：直接排除该机构，不要因为「不过退款」四个字就觉得有保障。

### 2. 伪造学历 / 证书
**话术**：「代办毕业证」「买证」「办证」「代做作业」「替考」「代考费」「挂名」

**法律性质**：这已经**不是消费纠纷，是违法行为**。可能涉及伪造、买卖国家机关证件，**也可能构成诈骗**。

**应对**：**立即停止付款并向公安机关报案**，不要只想着退费。

### 3. 假借学历名义招生
**话术**：「借考」「替考」「组织考试作弊」「空挂学籍」「挂靠学籍」「买卖学籍」

**风险**：一旦挂靠出证，**你的身份信息与真实学籍不一致**，影响征信、考公、职称评定，甚至被牵连。

**应对**：**不要同意挂靠**。若已发生，**要求解除并保留证据**。

### 4. 夸大证书效力
**话术**：「国家承认」（错误使用）、「包分配」「包就业」「高薪就业」「免考」「直接拿证」「不用考试」「速成」「快速拿证」

**辨析**：
- 「国家承认」本身**不假**，但**必须是学信网可查的学历**。「培训结业证」也说国家承认，但它**不是学历**
- 「包就业」= 简历包装，不是承诺岗位
- 「免考」「直接拿证」= 不可能

**应对**：要求机构明确回答三个问题——**谁出题、谁录取、谁发证、谁注册学籍**。答不上来就是骗局。

### 5. 诱导贷款 / 分期
**话术**：「贷款」「分期」「三期免息」「花呗」「借钱」

**为什么最危险**：**贷款责任不能转移**。机构跑路、倒闭、涉刑，**你照样要还贷**，可能同时背上债务与征信污点。「三期免息」的话，后面往往接「手续费」。

**应对**：**拒绝**。学费可以直接付给学校或机构对公账户；确实要分期，让机构直接对接**学校分期**，不经过个人贷款。

### 6. 不退费 / 拖延退款
**话术**：「不退不费」「过两个月再说」「等下学期」「再等等」「不能退」

**应对**：**签约前就把退费规则写清**。签了「一经报名不退」再想改就难了。见 `contract-and-refund.md`。

### 7. 冒用办学资质
**话术**：机构只说「我们和某大学合作」，却不给合作协议；收款打到**个人账户**；**收据**而不是发票；名字里带「咨询」「教育信息服务」却自称「学院」

**应对**：**机构名称、收款账户、开票主体必须一致**。不一致就是转移责任的手段。

### 8. 贬低正规途径
**话术**：「正规没用」「自己考太难」「考不过」「成人高考没用」「自考没用」「含金量低」

**目的**：制造焦虑，让你在**没有比较正规选项**的情况下冲动报名。

**应对**：**自己查官方信息**，不听任何机构的比较。成考、自考都是国家承认学历。

## 二、资质核查：四个必查位置

| 查什么 | 去哪查 | 怎么查 |
|---|---|---|
| **学校是不是正规高校** | 教育部全国高等学校名单 | 教育部官网查询，输入学校名称 |
| **机构/院校是否具备学历教育资质** | 省教育厅学历教育机构名单 | 省教育厅官网 |
| **中外合作项目** | 中外合作办学监管工作信息平台 | 教育部监管平台 |
| **最终证书能不能查** | 学信网 | 学信网查询，输入姓名与身份证 |

**必做动作**：把每一步查询结果**截图保存**，带查询日期。后续申请与投诉都要用。

**查不到就排除**。不要因为「他说有资质」就相信。

## 三、收款主体的核查

**正规的结构**：

```
学费 → 学校对公账户（或学校统一收取）
服务费 → 机构对公账户 + 发票
```

**可疑信号**（任意一条就要停）：

- [ ] 收款方是**个人微信 / 个人银行卡 / 个人支付宝**
- [ ] 收款账户名与**机构名称不一致**
- [ ] 只给**收据**不给发票，或说「开不了票」
- [ ] 要求**现金**支付
- [ ] 机构名称是「XX 教育咨询有限公司」但自称「XX 学院」
- [ ] 说「钱先给老师 personally，我们转给学校」

**为什么**：「先付给个人，再由机构转」这种安排，**钱一旦被挪走，追回的难度极大**。

## 四、话术证据怎么留

**这些截图比什么都重要**：

1. **朋友圈 / 短视频里的承诺话术**——「不过退款」「保过」
2. **聊天记录里说的每一句承诺**
3. **宣传海报**（含"国家承认""速成""包过"字样的）
4. **直播间录屏**（如果是在直播间报的）
5. **同学或朋友的推荐聊天**（证明信息来源）

⚠️ **截图要包含时间与账号信息**，必要时做**屏幕录像**比静态截图更有效。

## 五、报警与投诉的分界

| 情形 | 处理路径 |
|---|---|
| 只是不想学了，要退学费 | 12315、12345、教育局/文旅部门、民事诉讼 |
| 承诺包过但没兑现 | 先投诉，**保留证据**，必要时投诉到虚假宣传 |
| 伪造证件、买卖学籍 | **公安机关报案** |
| 诱导贷款后跑路 | **公安机关报案**（涉嫌诈骗） |
| 收了钱失联 | **公安机关报案** |

**先报案再维权**，因为一旦机构失联，民事途径的胜算就很低了。
