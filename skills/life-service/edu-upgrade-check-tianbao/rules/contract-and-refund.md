# 合同条款与退费

## 一、签约前必须写进合同的七件事

1. **明确是「学费」还是「服务费」**，金额分别是多少
2. **收钱主体**：学校还是机构？收款账户是哪一家？
3. **退费规则**（最重要，见下）
4. **承诺条款**：写明承诺什么，**未兑现怎么赔**
5. **服务清单**：课程多少节、题库多少、答疑几次
6. **有效期**：课程能用多久、错过能不能补
7. **发票**：能否开具、什么时候开

## 二、退费规则怎么看

### 危险条款（最常见）

> 「一经报名，费用不予退还」

> 「甲方缴纳后，乙方不接受任何形式的退费申请」

> 「已开通课程后概不退款」

**为什么要防**：这是**目前最常见的坑**。签了之后想反悔，几乎无路可走。

### 合理的退费结构

把费用拆成两部分：

| 部分 | 内容 | 退费处理 |
|---|---|---|
| **已实际发生** | 已开通课程、已发放教材、已考试 | 按课时/已发部分折算扣除 |
| **未发生部分** | 未开课、未发放、未考试 | **应全额退还** |

**谈判话术**：
> "我理解已开通的课程按课时算，可以扣。但还没上的部分、
> 没发的教材，应该全额退。我们把这两部分拆开写清楚，
> 并写明退款金额、时限和方式。"

**退费时限也要写**：如"受理退费申请后 15 个工作日内原路退回"。

### 格式条款的问题

某些条款属于**格式条款**（机构事先拟定、未与你协商）：

- 不合理地**免除机构自身责任**
- 不合理地**加重你的责任**
- 排除你的**主要权利**

这类条款**可能无效**，但主张无效要花时间、要证据、可能进程序。**签约前谈清楚，永远比事后维权省力**。

## 三、贷款分期的风险

### 为什么最危险

```
机构跑路/倒闭/涉刑
   ↓
你还欠着贷款
   ↓
机构消失，课程与学历都拿不到
   ↓
你同时背债务 + 征信污点
```

**「贷款」的责任**在你与贷款机构之间，**与机构是否提供服务无关**。机构不履约，**你仍要还**。

### 「三期免息」的话术拆解

常见套路：
1. 「零息」→ 但**收手续费**（手续费率往往不低）
2. 「随时可还」→ 但**提前还款要违约金**
3. 「这是我们合作的贷款产品」→ **利息可能不低**
4. 「用你的手机 App 绑定」→ **征信上直接记一笔**

### 正确做法

| 需求 | 正确解法 |
|---|---|
| 一次交不起学费 | **直接和学校谈分期**，多数院校支持按学期缴 |
| 资金紧张 | **攒钱、延迟报名**，不要借高息消费贷 |
| 已经签了贷款协议 | 立即联系贷款机构问清**总利息与提前还款规则**，必要时咨询律师 |

**一言以蔽之**：**学费可以慢一点还，贷款不能借。**

## 四、缴费环节的核对

### 缴费前 checklist

- [ ] 机构与学校资质都查过了，截图留存
- [ ] 学费金额与服务费金额**分开列明**
- [ ] 确认**收款账户是学校或机构的对公账户**
- [ ] 确认**能开票**（收款方名称与开票方一致）
- [ ] 合同**当场看完**，尤其是退费那几条
- [ ] 承诺的每一句都**写进合同或补充协议**
- [ ] 所有款项**留转账凭证**，备注写"XX 培训费"

### 缴费后立刻做

- [ ] 索要**收据或发票**（收据上要写明服务内容与金额）
- [ ] 截图保存**转账成功页面**
- [ ] 索取**合同原件**（自己留一份，不要只留机构那份）
- [ ] 把**课程与账号**信息记录下来

## 五、七步维权路径

### 第 1 步：查办学资质
教育部名单、省教育厅名单、学信网，截图留存。**查不到就别往下走。**

### 第 2 步：查是不是正规途径
自考、成考、国开、开放大学都是国家承认学历，考试由教育考试院组织。**正规机构的收费路径是「学校收学费 + 机构收服务费」。**

### 第 3 步：把承诺变成文字
「包过」「保录取」**一律写进合同或补充协议**，并写明**未兑现的退费金额与时限**。

### 第 4 步：算清总价
把所有费用一次列清：学费、教材费、试卷费、服务费、代缴费、住宿费。**问清哪些不可退。**

### 第 5 步：拒绝贷款
贷款与分期一律拒绝。改为直接付给学校或机构对公账户。

### 第 6 步：保留全部证据
合同、收据、转账记录、聊天记录、课程视频、**承诺截图**，按时间顺序编号保存。

### 第 7 步：退费与投诉
```
书面提出退费要求（明确金额与时限）
   ↓
协商 → 12315 → 当地教育局或文旅部门
   ↓
涉诈骗、伪造证件、替考 → 公安机关报案
   ↓
仍不成 → 民事诉讼或劳动仲裁
```

## 六、退费话术

**第一步：书面提出**
> "我于 X 月 X 日报名贵机构的 XX 课程，已缴纳 X 元。
> 现因【具体原因】要求退费。按协议第 X 条，未发生的部分应予退还 X 元。
> 请在 X 个工作日内答复并办理退款。"

**要求书面**（EMS 邮寄 + 保留签收记录，或现场递交索取回执）。

**第二步：协商不成时投诉时的说法**
> "我已于 X 月 X 日向 [机构名称] 提出退费要求，对方以
> '一经报名不退费'为由拒绝。该条款属于不合理免除其自身责任的格式条款，
> 且对方在招生时承诺'不过退款'，承诺与协议不符。
> 现要求退还未发生部分费用 X 元。"

**第三步：涉诈骗时报案时的说法**
> "该机构在招生时承诺包过、承诺不过退款，收取我 X 元后失联。
> 其宣传内容涉嫌虚假宣传，怀疑存在诈骗，请求立案调查。"

## 七、常见退费纠纷的处理节奏

| 阶段 | 时间 | 做什么 |
|---|---|---|
| 书面提出 | 第 1 天 | 明确金额与时限，EMS + 现场双留痕 |
| 等回复 | 7~15 日 | 不主动联系，等对方答复（留证据） |
| 投诉 | 15 日后 | 12315 或主管部门，附全套材料 |
| 调解/仲裁 | 30~60 日 | 视答复决定 |
| 诉讼 | 视情况 | 金额大、有证据时考虑 |

**不要在对方不回的时候反复催**，催多了反而给对方"你急你妥协"的口实。**按节奏走，留痕就好。**
