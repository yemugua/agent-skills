# GRE 填空解题逻辑与词汇核查（gre-text-completion）

GRE 填空的核心不是"认识多少词"，而是**先定方向再选词**：题干里的信号词决定空格该填正向、负向还是同义替换。方向判错了，认识所有选项也选不对。

这个技能做三件事：**扫信号词定方向** → **按空数定解题顺序** → **核词汇背诵进度**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出九类逻辑信号词表与方向判定规则 | ❌ 代替官方评分给出确定分数 |
| 按单空/双空/三空给出解题顺序 | ❌ 承诺"背完必上 160" |
| 扫描题干命中的信号词 | ❌ 保证某道题一定选某个选项 |
| 核算词汇覆盖率与每日新词量 | ❌ 替你完成考试作答 |
| 输出复习间隔与训练安排 | ❌ 提供当年考位、报名时间与费用 |

**出现以下情况先停下来，别硬套规则：**
- 题干里出现两个相反方向的信号词 —— 以**离空格最近**的那个为准，不要平均判断
- 选项里有两个词都符合方向 —— 看**搭配与程度**，不是看谁更生僻
- 目标院校对 Verbal 或总分有硬性要求 —— 以**当年招生简章与院校官网要求为准**
- 需要在短期内出分 —— 先确认报考场次与出分时间，**以官方报名公告为准**

## 二、完整工作流

```
第 1 步  读全句（不急着看选项），标出所有信号词
第 2 步  先读 rules/logic_signals.md，按九类信号词判定方向（不凭语感）
第 3 步  按空数定解题顺序：单空直接定 / 双空先定有信号的那空 / 三空先定最确定的一空
第 4 步  把题干文本存成文件，跑扫描脚本
         python scripts/gre_text_completion.py --file stem.txt --vocab vocab.txt --days 21
第 5 步  看脚本给出的信号词命中与方向提示，核对自己判的方向
第 6 步  看词汇覆盖率与每日新词量，按 §4 安排背诵
第 7 步  填 templates/填空自查表.md，记录每道题的方向判定与错因
```

## 三、九类信号词与方向

| 类别 | 代表词 | 方向判定 |
|---|---|---|
| 转折对比 | although, but, yet, however, despite, whereas, paradoxically | **反向** |
| 因果 | because, therefore, thus, hence, consequently, given that | **同向** |
| 递进强调 | moreover, indeed, even, furthermore, not only...but also | **同向且加深** |
| 解释重述 | that is, namely, i.e., specifically, 冒号、破折号 | **同义替换** |
| 并列 | and, as well as, both...and, likewise, similarly | **同向** |
| 举例 | for example, such as, including | **具体化** |
| 让步 | admittedly, granted, to be sure, while it is true that | **先让后转，看主句** |
| 时间对比 | previously, formerly, until recently, no longer, now | **前后反向** |
| 否定 | not, never, without, lack, fail to, far from, absent | **取反** |

**两条判定优先级**：
1. 两个相反方向的信号词同时出现时，**以离空格更近的那个为准**
2. 否定词（not / never / without / far from）会**翻转**方向，判方向前先圈出来

## 四、按空数定解题顺序

| 题型 | 顺序 | 说明 |
|---|---|---|
| 单空 | 定方向 → 定语义 → 选词 → 回读 | 最快，不要过度推断 |
| 双空 | 先做**有明确信号词**的那一空，再用它推另一空 | 两空都无信号时看并列/因果 |
| 三空 | 先做**最确定的一空**（通常是第一空或带解释信号的那空），再链式推进 | 三空全对等得分，做对两空不得分 |

> 三空题是**全对才得分**，所以先保住确定性最高的那一空，再链式推；不要平均用力。

## 五、脚本用法

```bash
python scripts/gre_text_completion.py --file stem.txt --vocab vocab.txt --days 21
```

| 参数 | 说明 |
|---|---|
| `--file` | 题干文本文件（UTF-8），空格可用连续下划线 `__` 标记 |
| `--text` | 直接传题干字符串，与 `--file` 二选一 |
| `--vocab` | 词汇文件，每行 `单词<Tab>状态`，状态为 `mastered` / `fuzzy` / `unknown` |
| `--days` | 距考试天数，用于算每日新词量 |
| `--daily-cap` | 每日新词上限，默认 60 |
| `--out` / `--format` | 输出文件路径 / `md`（默认）或 `json` |
| `--selftest` | 跑内置自检 |

脚本做四件事：① 扫描题干命中的信号词并按类别列出；② 统计空格数并给出解题顺序建议；③ 判方向并标注否定词；④ 核算词汇覆盖率和按剩余天数应背的新词量。

> 方向提示是**基于信号词的统计推断**，实际语义以整句理解为准，脚本不替代人工判断。

## 六、人工确认清单（这步不能省）

- [ ] 是否读完全句再看选项（先看选项容易被生僻词带偏）
- [ ] 否定词是否圈出来了
- [ ] 两个相反信号词是否按"离空格最近"处理
- [ ] 选完是否回读整句验证语义通顺
- [ ] 双空题是否已用确定的一空去推另一空
- [ ] 三空题是否确认了"全对才得分"的规则
- [ ] 词汇状态是否按 mastered / fuzzy / unknown 真实标注，而不是"眼熟就算会"

## 七、最常见的坑

**坑一：先看选项再读句子。**
错误解法：扫一眼选项，挑一个认识的词填进去；正确解法：先读完整句定方向与语义，再看哪个选项匹配。GRE 选项里常放"认识但方向错"的干扰项。

**坑二：忽略否定词。**
错误解法：看到 because 就判同向，没注意后面有 never；正确解法：先圈出 not / never / without / far from / fail to，再判方向，否定会翻转方向。

**坑三：两个信号词取平均。**
错误解法：句首 although、句尾 therefore，判定"又反又同"不了了之；正确解法：以**离空格更近**的信号词为准。

**坑四：三空题平均用力。**
错误解法：三个空都想一遍，结果每个都不确定；正确解法：先锁最确定的一空，再链式推进；三空全对才得分，做对两空不得分。

**坑五：把"生僻"当"正确"。**
错误解法：两个词都符合方向时选更生僻的那个；正确解法：看搭配与程度，GRE 常考"程度是否过重"，如 catastrophic 与 undesirable 的差别。

**坑六：只背词义不背搭配与正负向。**
错误解法：只记中文释义；正确解法：每个词记三件事——正负向、常见搭配、程度强弱。

**坑七：每天新词量过大。**
错误解法：考前一个月每天新词 150 个；正确解法：每日新词控制在 60 个以内，把更多时间给复习，未复习的新词等于没背。

**坑八：眼熟就算掌握。**
错误解法：词汇表里标 mastered 只因为"见过"；正确解法：能在句中判出正负向、能说出搭配才算 mastered，否则标 fuzzy。

**坑九：填空和等价混为一谈。**
错误解法：句子等价题也按"方向一致"选一个；正确解法：等价题要选**两个**使句子语义相同的词，只选一个不得分。

**坑十：不做错因归类。**
错误解法：错了就看下答案继续刷；正确解法：按"方向判错 / 词义不识 / 搭配不熟 / 程度误判"四类归因，哪类最多就补哪类。
