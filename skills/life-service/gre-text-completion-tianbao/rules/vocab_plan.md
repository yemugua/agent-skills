# GRE 词汇背诵核查与复习安排

> 背诵量与复习间隔为经验参数，不同考生基础差异较大，请结合自身实际调整。
> 考试安排与成绩要求以当年官方公告和报考院校要求为准。

---

## 一、词汇状态三分类

| 状态 | 判定标准 | 处理方式 |
|---|---|---|
| mastered | 能在句中判出正负向 + 说出常见搭配 + 说出程度强弱 | 进入复习间隔，不再算新词 |
| fuzzy | 眼熟，但说不出搭配或程度 | 重点复习对象，每天必过 |
| unknown | 完全没印象 | 每日新词配额内消化 |

**关键判定**："眼熟"不等于掌握。能在句中判出正负向、能说出搭配才算 mastered，否则一律标 fuzzy。

---

## 二、覆盖率口径

```
覆盖率 = mastered 词数 ÷ 词表总词数 × 100%
待攻克   = fuzzy + unknown
```

| 覆盖率 | 状态 | 建议 |
|---|---|---|
| < 50% | 词汇是主要瓶颈 | 优先补高频词，暂停刷难题 |
| 50%~75% | 词汇基本够用 | 边刷题边补，重点清 fuzzy |
| 75%~90% | 词汇不再是主要瓶颈 | 转攻长难句与逻辑 |
| > 90% | 词汇充分 | 只做错题归因与模考 |

---

## 三、每日新词量

| 剩余天数 | 每日新词建议 | 说明 |
|---|---|---|
| > 60 天 | 30~40 个 | 新词与复习并重 |
| 30~60 天 | 40~60 个 | 上限 60，超过则复习时间被挤占 |
| 15~30 天 | 40~60 个 | 优先清 fuzzy，新词让位给复习 |
| < 15 天 | 不再加新词 | 只复习已有词表与错题词 |

**每日新词上限 60 个**：超过这个量，复习时间被挤占，未复习的新词等于没背。

计算口径：
```
每日新词量 = 向上取整( 待攻克词数 ÷ 剩余天数 )
若 每日新词量 > 60，则按 60 执行，并提示「词量与天数不匹配，建议优先清 fuzzy」
```

---

## 四、复习间隔

| 轮次 | 间隔 | 说明 |
|---|---|---|
| 第 1 次复习 | 背诵后 1 天 | 遗忘最快的一段 |
| 第 2 次复习 | 再隔 2 天 | |
| 第 3 次复习 | 再隔 4 天 | |
| 第 4 次复习 | 再隔 7 天 | |
| 第 5 次复习 | 再隔 15 天 | 之后进入稳定期 |

标记 mastered 的词进入间隔序列；fuzzy 的词**退出序列、回到每日必过清单**，重新掌握后再从头进入序列。

---

## 五、背词三件事

每个词必须记三件事，只记中文释义不算掌握：

1. **正负向**（褒义 / 贬义 / 中性）
2. **常见搭配**（跟什么介词、跟什么宾语）
3. **程度强弱**（如 undesirable < harmful < catastrophic）

| 词 | 正负向 | 搭配 | 程度 |
|---|---|---|---|
| undermine | 贬义 | undermine confidence / authority | 中 |
| bolster | 褒义 | bolster support / an argument | 中 |
| catastrophic | 贬义 | catastrophic failure | 强 |
| cursory | 贬义 | a cursory glance | 弱 |

## 六、常见失分点（错误做法 vs 正确做法）

### 1. 只背词义不背正负向
- 错误做法：只记中文释义，做题时靠语感
- 正确做法：每个词标正负向，做题先判方向再选词
- 自查：随机抽 20 个词，能不能在 3 秒内说出正负向

### 2. 眼熟就算掌握
- 错误做法：词汇表里全标 mastered
- 正确做法：说不出搭配的标 fuzzy
- 自查：抽 10 个标记 mastered 的词，能不能说出搭配

### 3. 每日新词过量
- 错误做法：考前一个月每天 150 个新词
- 正确做法：每日新词 ≤60，剩余时间给复习
- 自查：算一下当日复习量是否达到新词量的 2 倍

### 4. 不做错因归因
- 错误做法：错了看答案继续刷
- 正确做法：按方向判错 / 词义不识 / 搭配不熟 / 程度误判四类归因
- 自查：最近 20 道错题里，哪一类最多

### 5. 生僻词优先
- 错误做法：先背低频生僻词
- 正确做法：按真题频次背，高频词优先
- 自查：词表前 500 个是否覆盖了真题高频词

### 6. 背词与做题脱节
- 错误做法：先背完 3000 词再做题
- 正确做法：背到 50% 覆盖率就开始做题，边做边补
- 自查：每周是否至少做 3 套填空

### 7. 复习间隔不执行
- 错误做法：背完一遍从头再背
- 正确做法：按 1/2/4/7/15 天间隔推进
- 自查：今天该复习的词有没有清单

### 8. 等价题按填空做法
- 错误做法：等价题只选一个词
- 正确做法：必须选两个使句子语义相同的词
- 自查：每次等价题是否都选了两个

### 9. 程度误判
- 错误做法：语气更强就选
- 正确做法：看程度是否与句子匹配
- 自查：错题里有没有"方向对但程度错"

### 10. 忽略题干否定词
- 错误做法：看到 because 就判同向
- 正确做法：先圈 not / never / without / far from
- 自查：做题时是否习惯性划否定词
