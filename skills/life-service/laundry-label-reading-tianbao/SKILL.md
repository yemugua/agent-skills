# 衣服洗涤标签

## 1. 硬边界（能做什么 / 不能做什么）

| 能做 | 不能做（转专业人士） |
|---|---|
| 识读五类符号并给洗护建议 | 改标签、伪造洗护说明 |
| 按符号选水温 / 程序 | 符号冲突时臆测处理 |
| 提示禁忌（不可熨 / 不可漂） | 无视符号强行处理贵重衣 |

符号冲突或看不清，先按最严一档处理或送专业洗护。

## 2. 什么时候用

| 用户说法 | 用不用 |
|---|---|
| 标签有桶加数字啥意思 | 用（水洗温度） |
| 一个叉一个圈啥意思 | 用（不可某动作） |
| 能不能漂白 / 熨 | 用（漂白 / 熨烫符号） |
| 标签磨没了 | 不用（按最严档或送洗） |

## 3. 完整工作流

1. **看水洗符号**：水桶（带手=手洗，加叉=不可水洗，数字=最高水温℃）。
2. **看漂白符号**：三角（空白=可氯漂，加叉=不可漂）。
3. **看熨烫符号**：熨斗（点数=温度，叉=不可熨）。
4. **看晾干符号**：方框（横线=阴干，圆点=烘干温度，叉=不可烘）。
5. **看专业护理**：圆圈（干洗 / 湿洗说明，叉=不可）。
6. 综合五类，按最严禁忌执行。

符号全集见 `rules/label-symbols.md`。

## 4. 核心规则 / 要件说明

生成洗护建议前**先读 `rules/label-symbols.md`**：五类符号图形与含义、冲突处理。不合格带原因，如「漏读漂白符号：若标不可漂却用氯漂会毁衣，必须五类全读」。

## 5. 脚本用法

`scripts/label_check.py` 自检「标签识读清单」：

```
python scripts/label_check.py --file steps.json
python scripts/label_check.py --selftest
```

## 6. 人工确认清单

- [ ] 已读水洗符号
- [ ] 已读漂白符号
- [ ] 已读熨烫符号
- [ ] 已读晾干符号
- [ ] 已读专业护理符号

## 7. 最常见的坑

1. 只看水洗忽略漂白：不可漂衣用氯漂褪色破损。
2. 数字当「必须水温」：是最高水温，低温可。
3. 桶下加叉当「可机洗」：是「不可水洗」，只能干洗。
4. 熨斗一点当「随便熨」：是真丝级低温，高温焦。
5. 相似符号混读：手洗（带手）与机洗（无手）不同。
6. 冲突时取松：应取最严一档，别赌。

## 8. 边界与免责

覆盖常见国际洗护符号识读。地区旧版符号、定制符号以实物标签为准。贵重衣物按最严档或送专业洗护。
