# 洗涤标签符号全集

生成建议前先读此表。

## 一、五类符号与含义

| 类 | 图形 | 含义要点 |
|---|---|---|
| 水洗 | 水桶 | 数字=最高水温℃；带手=手洗；加叉=不可水洗 |
| 漂白 | 三角 | 空白=可氯漂；加叉=不可漂 |
| 熨烫 | 熨斗 | 点数=温度（1≈110 / 2≈150 / 3≈200）；叉=不可熨 |
| 晾干 | 方框 | 横线=阴干；圆点=烘干温；叉=不可烘 |
| 专业 | 圆圈 | 干洗 / 湿洗说明；叉=不可专业洗 |

## 二、识读流程（强制，五类全读）

| 序 | 步骤 | 不合格原因 |
|---|---|---|
| 1 | 看水洗符号 | 漏读，水温错烫缩 |
| 2 | 看漂白符号 | 漏读，误漂褪色破 |
| 3 | 看熨烫符号 | 漏读，高温焦洞 |
| 4 | 看晾干符号 | 漏读，误烘变形 |
| 5 | 看专业护理符号 | 漏读，误机洗毁衣 |

## 三、冲突处理

- 任一项标「不可」：执行最严一档，不赌。
- 符号磨糊看不清：按最严档或送专业洗护。
- 禁止臆测相似符号（手洗桶≠机洗桶）。

> 不合格带原因：「漏读漂白符号：若标不可漂却用氯漂会毁衣，必须五类全读」。
