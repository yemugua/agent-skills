# 机械设备安全防护（machine-guarding）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据 GB/T 8196《机械安全 防护装置》与机械安全要求，生成机械设备防护清单：危险部位识别（转动/传动/剪切/挤压）、固定与联锁防护装置、安全距离、急停与警示、防护装置检查维护。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 机械防护
- 设备安全防护
- 防护罩
- 联锁防护
- 急停装置

## 三、工作流
1. 识别危险部位（转动/传动/剪切/挤压）
2. 配置固定或联锁防护装置
3. 保持安全距离
4. 设置急停与警示标识
5. 定期检查维护防护装置

## 四、核心内容（检查清单与判定）
GB/T 8196 规定防护装置的设计与选用；转动、传动、剪切等危险部位须设固定或联锁防护，并保持安全距离与急停可靠。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含危险部位识别 | 识别 |
| Q2 | FAIL | 未含固定与联锁防护装置 | 防护装置 |
| Q3 | WARN | 未含安全距离 | 安全距离 |
| Q4 | FAIL | 未含急停与警示标识 | 急停 |
| Q5 | WARN | 未含防护装置检查维护 | 维护 |

> 脚本 `machine-guarding_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python machine-guarding_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python machine-guarding_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
