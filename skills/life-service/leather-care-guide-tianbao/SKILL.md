# 皮具护理

## 1. 硬边界（能做什么 / 不能做什么）

| 能做 | 不能做（转专业人士） |
|---|---|
| 清灰、上皮革护理剂 | 皮面深度补伤 / 换皮 |
| 五金擦拭、边油小补 | 断裂 / 开线结构修复 |
| 塞填保型、防潮存放 | 暴晒、沾水不理 |

皮面大面积龟裂、五金脱落、结构开线，转皮具维修。

## 2. 什么时候用

| 用户说法 | 用不用 |
|---|---|
| 皮包发干、皮带开裂 | 用（上护理剂） |
| 皮具怎么存放不霉 | 用（防潮避光） |
| 皮面沾水 | 用（及时吸干阴干） |
| 皮面破洞 / 开线 | 不用（转维修） |

## 3. 完整工作流

1. **清灰**：软布 / 马毛刷去浮灰，纹路处仔细。
2. **上护理剂**：薄涂皮革护理乳，打圈吸收，余剂擦净，避光阴干。
3. **五金**：干布擦亮，轻微氧化用专用膏。
4. **保型存放**：包内塞纸 / 软物，皮带卷放或挂起，勿折。
5. **防潮避光**：放防潮剂，远离窗、暖气，定期通风。

存放与禁忌见 `rules/leather-rules.md`。

## 4. 核心规则 / 要件说明

生成护理方案前**先读 `rules/leather-rules.md`**：护理频率、存放、禁用。不合格带原因，如「皮具暴晒：皮面脱脂干裂褪色，必须避光存放」。

## 5. 脚本用法

`scripts/leather_check.py` 自检「护理操作清单」：

```
python scripts/leather_check.py --file steps.json
python scripts/leather_check.py --selftest
```

## 6. 人工确认清单

- [ ] 已清灰
- [ ] 已上护理剂
- [ ] 未沾水不擦
- [ ] 避光防潮存放
- [ ] 塞填保型

## 7. 最常见的坑

1. 长期不护理：皮干裂，每月薄涂一次。
2. 沾水不理：水渍斑、变硬，及时吸干阴干。
3. 暴晒 / 近暖气：脱脂龟裂褪色，避光。
4. 塞太满 / 折放皮带：变形折痕，卷放或挂。
5. 湿布猛擦真皮：脱脂，用护理剂。
6. 霉了不处理：扩散，先擦霉再防潮。

## 8. 边界与免责

覆盖日常皮包皮带护理存放。深度补伤、换皮、结构维修不在范围。贵重皮具建议专业养护。
