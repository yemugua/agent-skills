# 下水返味预防与地漏维护（drain-odor-prevention）

下水返味最难处理的一种，不是地漏坏了，而是**通气管被封死**。部分装修把通气管当成预留孔封堵了——这是根本原因，换多少个地漏芯都不会好。

另一个必须分清的问题是：**"慢排"和"返味"是两个不同的问题**。排水慢是机械问题，返味是密封问题，混在一起处理会两头都不解决。

这个技能做四件事：**先分诊** → **区分慢排与返味** → **按类型预防维护** → **判断何时必须叫师傅**。

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 区分七类返味来源与验证方法 | ❌ 拆改管道与通气管结构 |
| 区分慢排与返味两个问题 | ❌ 代替机械疏通处理主管堵塞 |
| 给出地漏芯类型与适用对照 | ❌ 承诺返味永不复发 |
| 给出预防维护周期 | ❌ 判断返味是否由楼下或物业造成 |
| 列出安全红线与转交条件 | ❌ 指导强酸强碱破坏性通堵 |

**遇到以下情况，停止自行处理，报物业或联系专业人员：**

- **主管道堵塞**：污水反涌、多处同时排水异常
- **返味来自楼下或整层**：可能是公共立管或化粪池问题
- **需要动土处理通气管**：涉及楼板、吊顶或结构
- **久治不愈**：多次处理后仍返味，可能是结构性问题
- **需要拆地板或大量破坏性操作**

**明确禁止**：用玻璃胶把地漏完全封死。这会堵住排水通道，下次排水从别处溢出，且检修时更难处理。

## 三、七类返味来源分诊表

**按"最容易验证"排序，不是按概率排序。**

| 顺序 | 来源 | 验证方法 | 处理 | 归属 |
|---|---|---|---|---|
| 1 | **地漏芯失效** | 取出芯体，看闭合件能否自由开合并完全闭合；看密封圈是否老化 | 按实测尺寸更换对应类型芯 | 可 DIY |
| 2 | **存水弯干涸** | 长期不用区域（出差、空置、客卫）；补水后气味明显减轻 | 补清水维持水封；长期不用定期补水 | 可 DIY |
| 3 | **通气管堵塞** | 多个排水点同时返味；换气效果差 | **必须由专业处理**，需拆动吊顶或管道 | 转专业人员 |
| 4 | **装修时未做水封** | 老房直排；改造破坏存水结构 | 加装存水弯或改用带水封的地漏 | 转专业人员 |
| 5 | **水封被破坏** | 原本有水封，后被拆改、移位或加装设备破坏 | 恢复存水结构 | 转专业人员 |
| 6 | **洗手盆下水返味** | 只有洗手盆下水处返味；检查存水弯与下水器 | 加装或更换带防臭芯的下水器 | 可 DIY |
| 7 | **无地漏区返味** | 卫生间某区域没有地漏，气味从该处出 | 该区域需有水封隔断；无地漏区属设计问题 | 转专业人员 |

**关键提醒**：**多条排水点同时返味，优先怀疑通气管。** 通气管的作用是把排水系统内的气味排到室外。它被堵住或被封死后，室内各排水点的返味会同时变重。

## 四、必须区分：慢排与返味

**这是两个不同的问题，混在一起处理会两头都不解决。**

| 判据 | 慢排（排水问题） | 返味（密封问题） |
|---|---|---|
| 主要表现 | 排水慢、水积在盆内或地面积水 | 没有异味 |
| 伴随现象 | 咕噜声、偶尔反涌、排水后水位下降慢 | 什么都没有 |
| 验证动作 | 倒一定量的水，记录排净时间 | 封堵排水点后观察气味变化 |
| 处理方向 | 疏通、清除堵塞物 | 修复或更换水封与地漏芯 |
| 错误处理后果 | 用除臭产品处理排水问题，完全无效 | 用疏通剂处理返味，同样无效 |

**验证动作举例**：

- **慢排验证**：倒固定量的水进地漏或洗手盆，记录排净所需时间，与平时的正常速度比较
- **返味验证**：用地漏专用堵头或塑料袋封住该排水点，静置后复闻；气味明显减轻说明来源就在那里

**两类问题可能同时存在**：所以判断时要分开做这两个验证，不要用一个动作代替另一个。

## 五、地漏芯类型与适用

| 类型 | 原理 | 适合 | 不适合 | 注意 |
|---|---|---|---|---|
| 硅胶嘴（V 型） | 硅胶开口重力闭合 | 湿区常用、排水量大 | 长期不用会粘连 | 定期清洁，定期检查弹性 |
| T 型弹簧 / 磁吸 | 弹簧或磁力顶住盖板 | 干湿区通用 | 弹簧锈蚀后失效 | 检查弹簧与磁力 |
| 重力翻盖 | 翻板自重回落 | 排水量大的淋浴区 | 杂物卡住翻板 | 清理杂物防止卡滞 |
| 深水封（U 型） | 存水隔绝气味 | 长期有水的湿区 | **干区必干涸失效** | 干区不要选纯水封 |

**选择的关键**：**干区与湿区要分开考虑**。阳台、厨房、长期不用的卫生间属于干区，干区不能选纯水封。

**安装时的通用要求**：

- 芯与管壁要匹配，避免留缝漏气
- 装回后面板要稳固，踩上去不晃动
- 装好后倒水测试排水是否顺畅、有无返水

## 六、通气管检查要点（本技能的重点）

**通气管是很多"反复返味"的根本原因。**

| 检查要点 | 说明 |
|---|---|
| **是否被封死** | 部分装修把通气管当成预留孔封堵了，这是根本原因 |
| **是否被占用** | 吊顶内、通风管、其他管线占用或错接 |
| **是否堵塞** | 内部积垢、杂物或被压扁 |
| **验证方法** | 多条排水点同时返味，且封堵单个点无效 → 高度怀疑通气管 |

**重要提醒**：**不要自己拆吊顶找通气管**。这需要动管道与结构，属于专业范围。发现多条排水点同时返味时，直接报物业。

---

## 七、洗手盆下水返味的处理

| 情况 | 检查 | 处理 |
|---|---|---|
| 存水弯干涸或缺失 | 看下水器是否有 U 型存水结构 | 加装存水弯或更换带存水的下水器 |
| 下水器无防臭芯 | 取下下水器看有无防臭结构 | 更换带防臭芯的下水器 |
| 下水管直排无存水弯 | 拆开看是否有弯 | 加装存水弯 |
| 接口处漏气 | 看接口是否密封、老化 | 更换密封件 |

**常见误区**：把洗手盆下水直接接入下水管不做任何处理。直排没有水封，气味会直接上行。

## 八、预防维护周期

| 周期 | 动作 |
|---|---|
| **每月** | 检查各排水点是否有异味；给长期不用的排水点补一次水 |
| **每季** | 取出地漏芯清洗，检查闭合件与密封圈 |
| **入冬前** | 一次性房屋（不供暖）特别检查存水弯，避免干裂 |
| **每年** | 检查全部地漏芯状况，按需更换；检查洗手盆下水器 |
| **搬入前/退租前** | 全面检查并记录 |

**一条核心原则**：**长期不用的排水点要定期补水**。水封蒸发后，返味会从无到有，这是最常见也最容易解决的一种。

## 九、安全红线

**1. 严禁混合使用含氯消毒剂与酸性疏通剂。**

两者混合会产生有毒气体。

| 危险配对 | 后果 |
|---|---|
| 含氯消毒剂 + 酸性疏通剂或酸性清洁剂 | 产生有毒气体，刺激呼吸道 |
| 含氯消毒剂 + 碱性清洁剂 | 同样不属于安全配对 |
| 两种含氯产品混合 | 有效成分叠加，不可控 |

**2. 管道疏通剂的使用注意：**

- 按说明书使用，不与其他清洁剂混用
- **管道材质不确定时先咨询**，部分材质不耐强腐蚀
- 老旧铸铁管、镀锌管可能被腐蚀，接口漏水后维修成本远高于疏通
- 用后彻底冲洗
- **保持通风**，避免长时间处于封闭空间

**3. 其他要求：**

- 清洁剂保持原包装，不分装到不明容器
- 一次只用一种清洁剂，用完冲净再换下一种
- 不用强酸强碱做破坏性通堵

## 十一、脚本用法

```bash
python scripts/drain_odor_prevent.py --text "多个下水口都返味，排水也变慢了"
python scripts/drain_odor_prevent.py --pair "含氯消毒液" "酸性疏通剂"
python scripts/drain_odor_prevent.py --file 情况.json --out 结果.md
```

| 参数 | 说明 |
|---|---|
| `--text` | 直接描述返味与排水情况 |
| `--file` | 从文件读，支持 `.txt` / `.md` / `.json`（JSON 用 `{"desc": "..."}`） |
| `--pair` | 检查两种清洁剂或疏通剂的配对，输出 danger / warn / ok |
| `--out` | 结果落盘路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本做三件事：按分诊顺序匹配来源、区分慢排与返味、检查配对与安全红线；命中多条排水点同时返味时直接给出"优先查通气管"的结论。

> 脚本是关键词匹配，**不等于现场判断**。封堵测试必须实际做一次。

- [ ] 已做过封堵测试，确认味道来源在哪个排水点

- [ ] 地漏芯类型与干湿区匹配（干区未选纯水封）

- [ ] 未把含氯消毒剂与酸性疏通剂混用
- [ ] 疏通剂使用前已确认管道材质适配
- [ ] 未用玻璃胶把地漏封死

## 十三、最常见的坑

**坑一：多条排水点同时返味，还在一个个换地漏芯。**
这多半是通气管问题，换芯解决不了，需要找物业或专业人员。

**坑二：把慢排当返味处理，或反过来。**
排水慢是机械问题，返味是密封问题。用除臭产品处理排水问题、用疏通剂处理返味，都完全无效。

**坑三：自己拆吊顶找通气管。**
需要动管道与结构，且拆完装不回会造成新问题。发现多条同时返味直接报物业。

**坑四：干区装纯水封。**
阳台、厨房、长期不用的卫生间，水封蒸发后和直排没区别。干区必须选硅胶或 T 型。

**坑五：长期不用的排水点不管。**
水封蒸发后返味会从无到有。这是最容易解决也最常被忽略的一种，定期补水即可。

**坑六：用玻璃胶把地漏封死。**
短期没味，长期排水不畅，且下次检修要破坏性拆除。

**坑七：疏通剂和含氯消毒液一起倒。**
会产生有毒气体。**含氯和酸性，永远不混。**

**坑八：不确认管道材质就用强疏通剂。**
老旧铸铁管与镀锌管可能被腐蚀，接口漏水后维修成本远高于疏通。

**坑九：换芯不量尺寸。**
芯外径小了留缝漏气，大了塞不进去或顶坏管壁。带旧芯去比对最稳。

**坑十：返味反复就继续自己试。**
多次处理仍返味，可能是结构性问题。久治不愈属于该叫师傅的信号。

## 十四、边界与免责

- 本技能**不替代**管道疏通、通气管检修与结构处理
- 公共立管、化粪池与楼内共用部位问题，通过物业处理
- 返味来源的最终判定需要现场验证，脚本与规则表只提供排查顺序
- 清洁剂与疏通剂的适用范围以**产品说明书**为准，不同产品不可混用
- 涉及邻里或物业管理争议的，按**物业管理规定与相关主管部门要求**办理
