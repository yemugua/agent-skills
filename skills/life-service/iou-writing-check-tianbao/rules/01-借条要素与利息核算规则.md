# 规则表一：三证对比、借条必备要素、利息核算与时担保

> 依据民法典及民间借贷相关现行司法解释整理。**利率上限、时效与保证规则以现行法律和司法解释为准**，本表不编造条款号，也不提供当期 LPR 数值（以官方公布为准）。

## 第 1 节 借条 / 欠条 / 收条 对比

| 凭证 | 证明内容 | 证明力 | 注意 |
|---|---|---|---|
| **借条** | 借款合意 + 款项交付 | 最强 | 写"今**借到**"可同时证明交付 |
| **欠条** | 欠款事实（原因可能是货款、劳务费、赔偿款等） | 中 | 需另行说明欠款的基础法律关系 |
| **收条** | 收到款项（仅交付事实） | 弱 | **不能证明合意**，不能单独证明借贷关系 |

## 第 2 节 借条必备要素清单（16 项，逐项打勾）

| # | 要素 | 要求 |
|---|---|---|
| 1 | **标题** | 写明"**借条**"二字 |
| 2 | 出借人 | 姓名 + **身份证号** |
| 3 | 借款人 | 姓名 + **身份证号** + 住址 + 联系方式 |
| 4 | **金额** | **大小写并列**（如"人民币壹拾万元整（¥100,000.00）"），只写小写易被篡改 |
| 5 | 币种 | 人民币/外币，外币应写明 |
| 6 | 借款用途 | 写明用途，且用途必须合法 |
| 7 | **交付方式** | 现金写明"收到现金"；转账写明**收款账户**（开户行、户名、账号），与凭证一致 |
| 8 | **措辞** | 用"今**借到**"（同时证明合意与交付），不要用"今借" |
| 9 | 借款日期 | 填**实际交付日** |
| 10 | 还款期限 | 明确到期日；不写则从催告宽限期届满起算时效 |
| 11 | **利息** | 有息写明年利率（如"年利率 12%"）；无息写明"**无息**"；**约定不明视为无息** |
| 12 | 逾期利息/违约责任 | 可约定，但受利率上限约束 |
| 13 | 实现债权费用 | 约定律师费、保全费、诉讼费由违约方承担 |
| 14 | 管辖 | 约定**出借人住所地**人民法院管辖，降低维权成本 |
| 15 | 签署 | 借款人**亲笔签名 + 按指印 + 日期**；不要只盖章不签字 |
| 16 | 担保/共同签字 | 有保证人的写明保证方式、保证期间、保证范围；需配偶共同承担的，配偶共同签字 |

### 2.1 金额书写规范

```
人民币壹拾万元整（¥100,000.00）
```

- 大写用**壹贰叁肆伍陆柒捌玖拾佰仟万亿**，不用"一二三"。
- 大写到"**元整**"为止，有角分的写到角分。
- 小写加**千位分隔符**并保留两位小数，前后不留空格（防加字）。

### 2.2 利息写法

| 写法 | 评价 |
|---|---|
| 年利率 12%（单利），按实际天数计息 | 推荐，无歧义 |
| 月息 2 分 | **不推荐**，"分""厘"在各地含义不同 |
| 到期还本付息，利息另议 | **约定不明，视为无息** |
| 不写利息 | 视为无息 |

## 第 3 节 本金认定：砍头息

```
认定本金 = 实际到手金额
```

预先在本金中扣除利息（砍头息）的，**按实际交付的金额认定本金**并据以计算利息。

**示例**：借条写 10 万元，实际转账 9.5 万元（预扣 5000 元利息）→ **本金为 9.5 万元**，不是 10 万元。

## 第 4 节 利率上限

```
利率上限 = 合同成立时一年期 LPR × 4
受保护利率 = min(约定利率, 利率上限)
```

| 规则 | 说明 |
|---|---|
| 上限基准 | 以**合同成立时**一年期贷款市场报价利率（LPR）的四倍为标准（以现行司法解释为准） |
| 超出部分 | **超出上限的部分不受保护**，不是整个借贷关系无效 |
| 已付超限利息 | 借款人可请求返还超出部分，或主张冲抵本金 |
| 约定不明 | 自然人之间借款**视为无息** |
| 无息但逾期 | 未约定利息但约定了还款期限的，逾期后可主张逾期还款违约责任（受上限约束） |
| 未约定期限 | 出借人可催告，宽限期届满后可主张逾期利息 |

## 第 5 节 复利（利滚利）

前期利率未超过上限的，可将前期利息计入后期本金重新计息，但受到总上限约束：

```
最终本息之和 ≤ 最初本金 + 最初本金 × 利率上限 × 整个借款期间
```

超过上述上限的部分不受保护。**核算时务必先算这个总上限，再判断复利约定是否有效。**

## 第 6 节 利息计算

```
合法利息 = 认定本金 × 受保护利率 × 实际天数 / 365
```

- 计息期间自**实际交付日**起算（不是借条落款日，若两者不同以交付日为准）。
- 部分还款的，已还本金从还款日起不再计息。
- 已付利息超过上限的部分，先冲抵利息，再冲抵本金。

## 第 7 节 诉讼时效

| 情形 | 起算点 |
|---|---|
| 约定还款期限 | 自**期限届满**之日起算 |
| 未约定还款期限 | 自出借人**主张权利、宽限期届满**之日起算 |
| 最长保护期 | 自权利受到损害之日起超过二十年的，一般不予保护（以现行规定为准） |
| 时效期间 | 一般 **三年**（以现行规定为准） |

**中断时效的方式**（要有证据）：书面催告函（EMS 留存寄单与签收）、短信/微信催款记录、对方**部分还款**、对方书面承认债务、提起诉讼或仲裁、申请调解等。

## 第 8 节 担保与夫妻共同债务

### 8.1 保证

| 项目 | 规则 |
|---|---|
| 保证方式 | **未约定或约定不明的，按一般保证**承担保证责任（与旧规则不同） |
| 一般保证 vs 连带保证 | 一般保证下，保证人享有先诉抗辩权，即债权人须先向债务人主张（经强制执行仍不能履行后才能要求保证人） |
| 保证期间 | 应明确约定；**未约定的依法定期间**，逾期未主张的保证人免责 |
| 保证范围 | 应写明是否及于利息、违约金、实现债权费用 |

**要点**：想要连带保证，**必须写明"连带责任保证"**，只写"担保人"不够。

### 8.2 夫妻共同债务

- 认定为夫妻共同债务的核心：**共同意思表示**（共同签字、事后追认）或**用于家庭日常生活需要**。
- 超出家庭日常生活需要的债务，一般不认定为共同债务，除非债权人能证明用于夫妻共同生活、共同生产经营或基于共同意思表示。
- **操作建议**：需要夫妻双方承担的，让配偶**在借条上共同签字**。

## 第 9 节 不受保护的情形

| 情形 | 后果 |
|---|---|
| 明知借款人用于**赌博等违法活动**仍出借 | 借贷关系不受保护 |
| 套取金融机构贷款**转贷** | 借贷关系无效（以现行规定为准） |
| 无资质的**经常性放贷**（职业放贷） | 可能认定无效 |
| 违背公序良俗的借贷 | 不受保护 |
| 涉及套路贷、诈骗 | 及时报案 |
