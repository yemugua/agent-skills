# 借条规范写法与补正核查

借条只证明两件事：**借款合意**和**款项交付**。写借条的全部技术都围绕这两点展开——少证明一件，主张就可能落空。补正瑕疵借条的全部工作，也是围绕这两点去补证据。

## 一、硬边界（能做 / 不能做）

| 能做 | 不能做 |
|---|---|
| 区分借条/欠条/收条的法律关系差异 | 认定某笔债务是否成立（由法院认定） |
| 逐项核对借条必备要素并指出缺失 | 代写具有法律效力的最终文本（需双方签署） |
| 按 LPR 四倍上限、砍头息、复利规则核算本息 | 给出当期 LPR 的具体数值（以官方公布为准） |
| 给出瑕疵借条的补正路径与证据组合 | 认定是否属于夫妻共同债务（需证据与司法认定） |
| 提示诉讼时效起算与中断做法 | 承诺胜诉或执行结果 |
| 输出催款函要点与起诉材料清单 | 提供诉讼代理意见 |

**必须转交专业人士的情形：**
- 金额较大、涉及担保、抵押、夫妻共同债务认定的——委托律师起草与审查。
- 已进入诉讼或需要申请财产保全的——由律师办理。
- 涉嫌套路贷、非法集资、赌博债务的——及时报案并咨询专业人士。

## 三、完整工作流

### 步骤 1：先分清楚是"借"还是"欠"

| 凭证 | 证明的法律关系 | 要点 |
|---|---|---|
| **借条** | **借款合意 + 款项交付** | 民间借贷关系；写明"今借到"可同时证明交付 |
| **欠条** | **欠款事实**（可能是货款、劳务费、赔偿款等） | 法律关系不限于借款，需另行说明欠款原因 |
| **收条** | **收到款项**（只证交付，不证合意） | 不能单独证明借贷关系 |

**为什么重要**：凭"欠条"主张借款，还需说明欠款的基础法律关系；凭"收条"主张借款，合意完全缺失。写错一个字，举证的难度完全不同。

### 步骤 2：逐项核对必备要素（缺失的补上）
见第四节规则表第 2 节，共 16 项。

### 步骤 3：核利息与本金（用脚本算）
- 本金：**按实际到手金额**（砍头息不计入本金）
- 利率上限：以**合同成立时**一年期 LPR 的**四倍**为标准（以现行司法解释为准）
- 超限部分不受保护；已付超限利息可主张冲抵本金

### 步骤 4：核时效
- 一般 **三年**。
- 约定了还款期限的：自**期限届满**之日起算。
- 未约定还款期限的：自出借人**主张权利、宽限期届满**之日起算；但自权利受到损害之日起超过二十年的，一般不予保护（以现行规定为准）。

### 步骤 5：瑕疵借条的补正
按"合意 + 交付"两条线补证据，见 `rules/02-补正路径与时效中断.md`。

### 步骤 6：催款与主张（同时完成时效中断）
书面催告 + 留痕，既是主张权利，也是中断时效。

## 四、核心规则（写或算之前必读）

**先读这两个文件，不要凭印象写：**
- `rules/01-借条要素与利息核算规则.md` —— 三证对比、16 项必备要素、金额书写规范、利息口径与上限、砍头息与复利、时效起算、担保与夫妻债务。
- `rules/02-补正路径与时效中断.md` —— 补正证据组合、催款函与律师函要点、时效中断方式、起诉材料清单、误判对照表。

**利息核算骨架：**

```
认定本金   = 实际到手金额（预先扣除的利息不计入本金）
利率上限   = 合同成立时一年期 LPR × 4
受保护利率 = min(约定利率, 利率上限)
合法利息   = 认定本金 × 受保护利率 × 实际天数 / 365
已付超限利息 → 冲抵本金
复利上限   = 最初本金 × 利率上限 × 整个期间  （本息之和不得突破）
```

## 五、脚本用法

脚本：`scripts/loan_interest_check.py`（Python 3 标准库）

```bash
python scripts/loan_interest_check.py --file 借款.json
python scripts/loan_interest_check.py --file 借款.json --json
python scripts/loan_interest_check.py --selftest
```

| 字段 | 说明 |
|---|---|
| `nominal_principal` | 借条载明的本金（元） |
| `amount_received` | **实际到手金额**（元），用于砍头息处理；无砍头息时与载明本金相同 |
| `lpr_annual` | 合同成立时**一年期 LPR**（年化小数，如 0.0345），以官方公布为准 |
| `agreed_annual_rate` | 约定年利率（年化小数，如 0.24）；无约定填 0 |
| `days` | 借款实际天数 |
| `paid_interest` | 已支付利息（元） |
| `paid_principal` | 已偿还本金（元） |

输出：认定本金、利率上限与受保护利率、合法利息、已付利息是否超限、超限部分冲抵本金后的剩余本息、复利提示。

## 六、人工确认清单（不能省）

- [ ] 标题写的是**"借条"**（不是欠条、收条）？
- [ ] 金额**大小写同时写明**且一致？
- [ ] 出借人与借款人的**姓名 + 身份证号**都在？
- [ ] 交付方式写明（转账的写清**收款账户**，与转账凭证一致）？
- [ ] 写明"**今借到**"（同时证明合意与交付）？
- [ ] 借款日期 = **实际交付日**？
- [ ] 利息约定明确（有息写明利率；无息写明"无息"）？
- [ ] 自然人之间借款**约定不明**的，已知道会"视为无息"？
- [ ] 借款人**亲笔签名 + 按指印 + 日期**？
- [ ] 有担保的，保证方式、保证期间、保证范围写明？
- [ ] 需配偶共同承担的，配偶**共同签字**？
- [ ] 借款用途合法（未用于违法活动）？
- [ ] 原件已妥善保管，还款后已取回原件或取得**结清证明**？

## 七、最常见的坑

1. **写"欠条"实际是借款**。欠条证明的是欠款事实而非借款合意，主张借款时还需另行举证基础法律关系。
2. **金额只写小写**。"100000"加一笔就变"700000"，必须大小写并列。
3. **写"今借"而非"今借到"**。"借到"同时证明交付，少两个字就少证明一件事。
4. **现金交付不留凭证**。大额借款务必**转账**并注明"借款"，现金交付的应现场拍照、录像或有见证人。
5. **砍头息**。预先扣利息的，本金按**实际到手金额**认定，写 10 万只给 9 万，本金是 9 万不是 10 万。
6. **利息写成"月息 2 分"**。口语化表述易生歧义（年化 24% 还是 20%），应直接写年利率百分比。
7. **不写身份证号**。同名同姓极多，没有身份证号会导致被告不明确、执行困难。
8. **未约定利息就以为能要利息**。自然人之间借款对利息**约定不明的，视为没有利息**；想要利息必须写明。
9. **不约定管辖**。未约定的通常需到被告住所地起诉，异地维权成本陡增；应约定出借人所在地法院管辖。
10. **超过诉讼时效**。三年。约定还款期的从期满起算；久拖不决应书面催告并留痕以中断时效。
11. **保证方式未约定**。现行规则下未约定或约定不明的，按**一般保证**处理（与旧规则不同），出借人应先向债务人主张。
12. **还款后不还原件**。还款后应取回借条原件，或要求出具**结清证明**并保留转账凭证，否则可能被再次主张。
13. **部分还款不打收条**。部分还款应在借条上批注或另出收条，否则已还部分难以证明。
14. **借款用于赌博等非法活动**。明知用于非法活动仍出借的，借贷关系不受保护。
15. **把"已转账"当"借贷关系成立"**。转账只能证明交付，还需证明合意，缺一不可。

## 八、边界与免责

本技能提供的是**要素清单、核算方法与路径建议**，不构成法律意见，也不承诺诉讼结果。利率上限以现行司法解释与合同成立时官方公布的 LPR 为准；借贷关系是否成立、是否属于夫妻共同债务、保证责任如何承担，由人民法院依法认定。大额借贷、涉及担保抵押、已进入诉讼的，请委托律师起草与代理。
