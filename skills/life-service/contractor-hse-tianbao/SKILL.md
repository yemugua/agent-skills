# 承包商 HSE 审计（contractor-hse）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据 ISO 45001 与相关方管理要求，生成承包商 HSE 审计清单：资质审查、HSE 协议、入场培训、现场监督、绩效评估与退出机制。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 承包商管理
- 承包商HSE
- 相关方安全
- 外包安全
- 承包商审计

## 三、工作流
1. 入场前资质与HSE能力审查
2. 签订HSE协议与明确责任
3. 开展入场培训与安全交底
4. 现场监督与违章管理
5. 绩效评估与不合格退出

## 四、核心内容（检查清单与判定）
ISO 45001 要求对承包商等相关方施加影响并管理其风险；应通过资质审查、协议、培训、监督与评估实现全周期管控。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含资质与HSE能力审查 | 资质 |
| Q2 | FAIL | 未含HSE协议与责任划分 | 协议 |
| Q3 | WARN | 未含入场培训与安全交底 | 培训 |
| Q4 | FAIL | 未含现场监督与违章管理 | 监督 |
| Q5 | WARN | 未含绩效评估与退出 | 评估 |

> 脚本 `contractor-hse_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python contractor-hse_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python contractor-hse_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
