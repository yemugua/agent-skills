# 汇报模板库

> 直接复制填空。方括号为待替换项。填不出来的项写「暂无」而不是删掉——「暂无」本身就是一条有效信息。

---

## 模板一：日档（阻塞优先，≤5 行）

```
[日期] [进展] 完成：[结果1]；[结果2]
[日期] [计划] 今日：[动作1]；[动作2]
[日期] [阻塞] 卡在：[具体环节]，已持续 [N] 天，需要 [XX方] [XX方角色] 在 [日期] 前 [具体动作]
[日期] [需决策] 请您在 [A/B 两个选项] 中确认一项
```

无阻塞的日子不发。若只是例行同步，用模板二。

---

## 模板二：周档三段式（≤1 页）

```
【结论】本周 [事项X] [达成/未达成]，核心原因是 [一句话]。

【进展】
1. [事项A]：原 [基线值] → 现 [结果值]（[单位]），关键动作 [做了哪一步]
2. [事项B]：原 [基线值] → 现 [结果值]，关键动作 [...]
3. [事项C]：卡在 [环节]，等 [方] 回复，预计 [日期] 可动

【需要】
- [事项A] 无需支持
- [事项C] 需要 [具体人/角色] 在 [日期] 前 [具体动作]
- 其他：暂无
```

**第三段不能省**。写「无需支持，本周仅同步」也是合格答案。

---

## 模板三：月档（指标 + 风险 + 资源）

```
【结论】本月 [N] 项关键指标，[X] 项达成、[Y] 项未达；最大风险是 [一句话]。

【指标】
| 指标 | 目标值 | 实际值 | 达成率 | 环比 | 说明 |
|---|---|---|---|---|---|
| [指标1] | [A] | [B] | [B/A] | [+X%] | [一句话] |
| [指标2] | [A] | [B] | [B/A] | [-X%] | [未达原因] |

【风险】
1. [风险描述]：影响 [范围]，预计 [时间点] 显现，已采取 [动作]
2. ...

【资源需求】
- [资源1]：[数量/人日]，[用途]，不需要则写「本月无资源缺口」

【上月复盘】
上月承诺的 [动作X]：已完成 / 未完成（原因 [X]）
```

## 模板四：季档四段式（评价与资源）

```
【结论】本季目标加权达成 [XX%]；[A][B] 超额，[C] 未达；下季主线是 [一句话]。

【数据】
指标1：目标 [A] → 实际 [B]（达成 [B/A]）｜指标2：...｜指标3：...
趋势：较上季 [上升/下降/持平]，主因 [X]

【问题】
C 未达根因：[事实层原因]；非本人可控部分为 [X]，本人可控部分为 [Y]，
已启动 [Z 动作]，预计 [日期] 见效。

【计划】
下季目标值：[具体数值]
关键动作：1. ... 2. ... 3. ...
需要的支持：[人/预算/决策]，若无写「无需额外支持」
```

## 模板五：坏消息上报（发现后按分级时限发出）

```
【事实】[时间] 发现 [具体发生了什么]，当前状态 [现状描述]。不涉及评价性表述。
【影响】影响 [谁/哪条链路]，预计影响 [范围/金额/工期]。
【归因】已确认原因：[X]；待确认：[Y]；非本人可控部分为 [Z]。
【方案】已启动 [动作1]（预计 [时间]见效）；需要你决定 [选项 A / 选项 B]。
```

**四步顺序不能改**：先事实、后影响、再归因、最后方案。反过来写会变成甩锅或辩解。

## 模板六：预期对齐记录（一页，双方确认）

```
【任务名称】[名称]    【对齐日期】[YYYY-MM-DD]    【对齐人】[本人] / [对方]

一、成功标准
   我的理解：[做到什么程度算完成]
   需你确认：[A 标准 / B 标准 / 其他]
   你的确认：[留白或 IM 回复截图引用]

二、优先级
   若 [事项1] 与 [事项2] 撞车，先保：[事项X]
   你的确认：[ ]

三、节奏
   汇报频率：[每周 X / 每月 X]
   需立刻上报的例外情形：[安全/合规/资金/客户/其他]
   你的确认：[ ]

四、决策边界
   我可直接决定：[事项清单]
   需报你定：[事项清单]
   你的确认：[ ]

【留痕方式】IM 文字确认 / 会议纪要第 X 段 / 共用文档回复「确认」
```

## 模板七：越级同步（合规路径）

```
【给隔级领导】同步一个进展（已与 [直属上级姓名] 沟通，抄送其）
- 事实：[时间线，3 条以内]
- 当前动作：[我在做什么]
- 需要隔级关注的信息：[仅事实，不含对人的评价]
- 不含：对任何同事或上级的评价、不含诉求资源、不含承诺
```

---

## 模板八：检查清单（发出前逐条过）

- [ ] 第一段是不是一句话结论，不是一堆背景
- [ ] 每个进展项都带了一个数（结果值、时长、数量、比例）
- [ ] 「需要」段不是空的
- [ ] 归因句的主语是「我」或某个动作，不是某个部门
- [ ] 没有情绪词、抱怨句、反问句
- [ ] 没有未脱敏的薪酬、人事、未披露财务信息
- [ ] 抄送有明确理由
- [ ] 结论句里的事，上级能在收到消息后 2 分钟内做出决定或行动
