# 特殊类目资质与备案要求

> 通用整理。各行业所需资质以主管部门规定与公众平台当前要求为准，本文不代办任何资质。

## 一、哪些属于特殊类目

医疗、金融、教育、直播、游戏、药品、食品、出版、宗教、招聘、婚恋、酒类等，
小程序涉及这些领域时，除服务类目外还需提交专门资质，否则提审基本会被拒。

## 二、常见类目与所需材料（通用指引）

| 类目 | 通常需要的材料 |
| --- | --- |
| 医疗 | 医疗机构执业许可证等医疗卫生相关资质 |
| 金融 | 金融业务相关许可或备案材料（借贷、理财、征信等须持牌） |
| 教育 | 办学许可或教育相关资质，学科类培训另有专门规定 |
| 直播 | 网络文化经营许可证、信息网络传播视听节目许可证等 |
| 游戏 | 游戏版号、ISBN 等游戏出版与运营材料 |
| 药品 | 药品经营许可证或医疗器械相关许可 |
| 食品 | 食品经营许可证或食品生产相关许可 |
| 出版 | 出版物经营相关许可 |
| 宗教 | 宗教活动场所或主管部门相关材料（内容限制严格） |
| 招聘 | 人力资源服务许可证 |
| 婚恋 | 相关经营资质与用户实名认证机制 |
| 酒类 | 酒类经营相关许可 |

## 三、资质的三个硬要求

1. **主体一致**：资质上的主体名称必须与小程序主体一致，否则不认可。
2. **在有效期内**：过期资质等同无效，需更新后重传。
3. **清晰完整**：原件照片需清晰可辨，信息页与盖章页齐全。

## 四、备案

- 小程序需按工信部与平台要求完成备案，未备案的小程序无法上架发布。
- 备案在公众平台按指引提交主体信息、负责人信息并核验。
- 本技能只提示备案状态这一核查项，不代办备案。

## 五、不确定的处理原则

- 拿不准是否属于特殊类目时，按"是"处理并准备材料，宁可多备不可遗漏。
- 同一小程序涉及多个特殊类目的，每个类目分别准备对应资质。
- 资质办理请走主管部门正规渠道。
