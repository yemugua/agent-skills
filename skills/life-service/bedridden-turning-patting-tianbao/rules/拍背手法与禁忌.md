# 拍背手法、节奏与禁忌

**前置声明**：拍背属于有风险的操作，存在**肋骨骨折、气胸加重、误吸与窒息**风险。能否实施、实施方式必须由医护人员评估与指导，以最新版相关指南为准。本表不提供药物、雾化、吸痰操作指导，也不判断痰量与感染。

## 一、手法（空心掌）

| 项 | 正确做法 | 错误做法 |
|---|---|---|
| 手型 | **空心掌**：手掌弯成碗状，指尖并拢微屈 | 实心掌拍、握拳捶、指尖戳 |
| 力度 | 以皮肤不红、不痛、不出现瘀斑为限 | 用力过猛、越拍越重 |
| 接触面 | 掌根与掌外侧着力 | 掌中心硬拍 |
| 检查 | 拍 5-6 下后停下看皮肤有无红痕 | 一口气拍很久不看皮肤 |

## 二、方向

**由下向上、由外向内**，从肺底（低位）向肺尖方向，帮助松动分泌物。

## 三、节奏

- 每次约 3-5 分钟，或以老人耐受为限
- 有节律，不忽快忽慢
- 每拍几下短暂停顿，让老人可以呼吸与咳嗽
- **拍不出来就不加力不加时**，可能本来就没有可咳出的痰

## 四、避让区域（禁拍）

| 区域 | 原因 |
|---|---|
| **脊柱** | 震荡可能造成损伤 |
| **肾区**（腰部两侧后下方） | 冲击可造成肾脏损伤 |
| 髂骨、肩胛骨、骶骨突起处 | 骨突处受冲击易损伤 |
| 手术切口、骨折部位 | 直接损伤 |
| 皮肤破损、压疮创面、瘀斑处 | 加重损伤 |
| 孕妇的腹部（若照护对象涉及） | 禁拍腹部 |

## 五、时间窗（不可越过）

| 相对进食时间 | 是否可拍 |
|---|---|
| 餐前 1 小时内 | **不拍**（饱腹易呕吐误吸） |
| 餐后 1-2 小时内 | **不拍** |
| 餐后 2 小时以上或餐前 1 小时以上 | 可拍 |

**判断口径**：距上次进食不足 1 小时，或距上次进食不足 2 小时，都不拍。进食时间不明时，本轮不拍。

## 六、八项拍背禁忌（命中即停止并就医）

1. **咯血或痰中带血**
2. **已知或疑似的肋骨骨折、胸骨骨折、脊柱病变**
3. **骨质疏松程度明显，有拍背致骨折风险**
4. **气胸、气胸倾向或近期气胸病史**
5. **剧烈咳嗽导致的胸痛、呼吸困难**
6. **呼吸窘迫表现**：呼吸急促、发绀、鼻翼扇动、表情痛苦
7. **咳嗽反射消失或明显减弱、吞咽功能差、误吸史频繁**
8. **生命体征不稳定**：血压下降、心率异常、意识改变

**另加一条**：咯痰后突发呼吸困难或疑似异物梗阻 —— 这是**窒息，不是排痰**，立即停止并急救。

## 七、窒息风险预警与处置

### 预警信号

- 突然不能说话或声音发不出
- 双手抓喉、表情惊恐
- 面色青紫、口唇发绀
- **咳嗽无声**（这是与普通咳嗽最重要的区别）
- 呼吸急促、喘鸣、呻吟
- 身体软瘫、意识丧失

### 处置口径

1. **立即呼叫急救**
2. **立即停止一切拍背与拍打动作**
3. 按急救人员指导处置
4. 保持气道通畅的体位，解开领口

### 绝对禁止的窒息处置动作

- 继续拍背
- 抠挖口腔、用手掏喉咙
- 给水、喂药、喂饭
- 把人倒提、抖动

## 八、拍背全过程观察清单

拍背前确认：

- [ ] 八项禁忌已逐条核对，无一命中
- [ ] 意识状态可支持拍背
- [ ] 呼吸平稳，无发绀与鼻翼扇动
- [ ] 距进食时间符合时间窗要求
- [ ] 皮肤破损与压疮部位已标记并避开

拍背中观察：

- [ ] 面色是否发白或发青
- [ ] 呼吸是否变浅变快
- [ ] 是否出现胸痛
- [ ] 老人是否表达不适（能表达时）
- [ ] 是否出现抓喉、不能发声等窒息信号

拍背后确认：

- [ ] 呼吸是否恢复到拍背前状态
- [ ] 皮肤有无新发红痕或瘀斑
- [ ] 痰的性状与量（只作记录，不作判断）
- [ ] 是否出现呕吐
- [ ] 是否需要在记录表中标注异常

## 九、必须记录的内容

- 拍背时间、时长、手法（是否空心掌）
- 拍背前后呼吸与面色对比
- 痰的量与性状（只记录，不判断）
- 是否出现异常反应
- 皮肤有无红痕或瘀斑
- 是否因禁忌或时间窗未实施，未实施时写明原因

**记录口径**：「未实施」要写清原因（禁忌、时间窗、老人拒绝、医嘱禁止），不能留空——留空会让下次照护者误以为漏做。
