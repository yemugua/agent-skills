# 失能老人翻身拍背与压疮预防

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 给出翻身间隔参考与执行核查表 | 给出压疮正式分期诊断 |
| 给出仰卧侧卧的体位摆放要点与患侧上肢摆放 | 决定偏瘫侧摆放顺序（须按医护要求） |
| 给出拍背的手法、方向、节奏与时间窗参考 | 判断痰液量、判断感染、判断是否需要吸痰 |
| 列出拍背禁忌与立即停止就医的情形 | 给出化痰药、雾化药、抗生素或任何药物建议 |
| 给出压疮预防的叠加措施清单 | 推荐具体器械品牌与参数 |
| 说明窒息与误吸的预警信号 | 自行实施吸痰操作或给出吸痰深度与负压 |
| 给出护理交接与记录要求 | 承诺翻身与拍背一定能防止并发症 |

**必须立即停止拍背并就医的红线（出现任一条，停止操作并就医）**

- 咯血或痰中带血
- 已知或疑似的肋骨骨折、胸骨骨折、脊柱病变
- 骨质疏松程度明显，有拍背致骨折风险
- 气胸、气胸倾向或近期气胸病史
- 剧烈咳嗽导致的胸痛、呼吸困难
- 呼吸窘迫：呼吸急促、发绀、鼻翼扇动、表情痛苦
- 咳嗽反射消失或明显减弱、吞咽功能差、误吸史频繁
- 生命体征不稳定：血压下降、心率异常、意识改变
- 咯痰后突发呼吸困难或疑似异物梗阻 —— 这是**窒息**，不是排痰

**必须立即就医的窒息处置口径**：老人突然不能说话、双手抓喉、面色青紫、咳嗽无声——立即呼叫急救，同时按急救指导处理。**不要继续拍背、不要抠挖口腔、不要给水喂药。**

**绝对禁止的操作**：用力捶打胸背、拍打脊柱与肾区、在饱餐后或餐前 1 小时内拍背、对胸腹部加压助排、在意识不清或呼吸不稳时拍背。

## 三、完整工作流

1. **先排禁忌**：逐条核对八项拍背禁忌与窒息预警，命中即停止拍背并就医。
2. **确认生命体征与意识状态**：意识不清、呼吸不稳、血压心率异常者不做拍背。
3. **定时间窗**：确认距离上次进食的时间，避开餐前 1 小时与餐后 1-2 小时。
4. **摆体位**：按 `rules/翻身间隔与体位轮换.md` 摆好，注意患侧上肢置于胸前、两腿夹枕、足跟悬空。
5. **拍背**：按 `rules/拍背手法与禁忌.md` 的手势、方向、节奏、时间执行。
6. **观察反应**：拍背全程观察呼吸、面色、意识，出现异常立即停止。
7. **叠压疮措施**：把减压、营养、干燥、失禁管理、排便管理一起纳入，不只靠翻身。
8. **记录交接**：用 `templates/翻身拍背记录表.md` 记录，交给下一班与医护。

## 四、核心规则与要件库

生成任何护理方案前，**必须先读**：

- `rules/翻身间隔与体位轮换.md`：翻身间隔参考与执行核查、仰卧侧卧体位摆放、患侧肢体摆放、搬抬要求。
- `rules/拍背手法与禁忌.md`：空心掌手法、方向、节奏、时间窗、避让区域、八项禁忌、窒息预警与处置。

不得给药物与雾化建议；不得给吸痰操作指导；不得判断痰量与感染；不得决定偏瘫侧摆放顺序。所有医学口径**以最新版指南和医护人员判断为准**。

## 五、脚本用法

```
python scripts/bedridden_turning_plan.py --file case.json
python scripts/bedridden_turning_plan.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`risk` 风险标记（`immobile` `unconscious` `hemiplegia` `obesity` `edema` `incontinence`），`contraindication` 拍背禁忌标记，`hours_since_meal` 距上次进食小时数，`minutes_since_turn` 距上次翻身分钟数，`red_flags` 红线标记 |
| `--turn` | 只输出翻身与体位方案 |
| `--pat` | 只输出拍背方案与禁忌核对 |
| `--json` | 以 JSON 输出 |
| `--out` | 结果写入指定文件，默认 `scripts/_last_result.txt` |
| `--selftest` | 运行自检 |

脚本输出翻身间隔参考、时间窗判断、拍背禁忌核对与压疮叠加措施。**脚本不给药物、不给吸痰操作、不给痰量判断。**

- [ ] 八项拍背禁忌已逐条核对，命中即停止
- [ ] 意识状态与呼吸是否稳定已确认
- [ ] 距上次进食时间已确认，避开餐前 1 小时与餐后 1-2 小时

- [ ] 已避开脊柱、肾区、髂骨与肩胛

- [ ] 未判断痰量、未判断是否感染
- [ ] 未自行吸痰、未给药物建议
- [ ] 压疮预防措施是叠加执行而非只靠翻身
- [ ] 记录表已填，异常已写入并交接
- [ ] 搬抬用抬不用拖

## 七、最常见的坑

1. **拍背用力过猛**：像捶背一样拍，容易造成肋骨骨折、软组织损伤。正确的是空心掌、力度以皮肤不红不痛为限。
2. **拍脊柱和肾区**：这两处禁拍，脊柱受震荡、肾区受冲击都可能造成损伤。
3. **刚吃完就拍**：饱餐后立即拍背容易引起呕吐、误吸，甚至窒息。时间窗必须遵守。
4. **拍到「痰出来」为止**：拍不出痰不代表需要更用力或更久，可能本来就没有可咳出的痰。
5. **有骨折风险还拍**：骨质疏松、已知骨折、脊柱病变者拍背可能直接造成骨折。
6. **意识不清也拍**：意识不清者咳嗽反射弱，痰可能咳不出来反而误吸。
7. **以为翻身越勤越好而忽略其他措施**：压疮还受营养、失禁、潮湿、剪切力影响，只翻身不够。
8. **翻身不挪受力点**：翻完身体还是压在同一点，等于没翻。
9. **拖拽搬动**：剪切力是压疮的重要成因，要抬不要拖。
10. **夜间不翻身**：夜间与睡眠时段最容易漏，必须排班覆盖。
11. **侧卧不支撑**：下肢交叉压迫、膝踝重叠会形成新的压迫点。
12. **不记录**：没有记录就没有执行证据，两周后无法判断方案是否有效。

## 八、边界与免责

本技能提供失能老人的翻身、拍背与压疮预防护理参考，**不提供药物、雾化与化痰方案，不提供吸痰操作指导，不判断痰量与感染，也不给出压疮正式分期**。拍背属于有创风险的护理操作，存在**肋骨骨折、气胸加重、误吸与窒息**等风险，**能否实施、实施方式必须由医护人员评估与指导，以最新版相关指南为准**。出现咯血、骨折、气胸、呼吸困难、咳嗽反射消失或突发窒息迹象时，**必须立即停止拍背并就医**。翻身间隔为参考区间，具体以医护建议为准。
