# 痛风饮食禁忌与嘌呤控制

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 按嘌呤分级给出忌口与替换清单 | 诊断痛风、判断是否为感染性关节炎 |
| 说明急性期与缓解期的饮食差异 | 制定降尿酸用药方案或调整药物剂量 |
| 提示酒精、果糖、含糖饮料的风险 | 推荐具体药品、降尿酸茶或保健品 |
| 给出饮水、体重与运动的管理口径 | 承诺饮食控制能替代药物治疗 |
| 输出一餐嘌呤核算表和忌口清单 | 解读化验单并下结论 |

**就医红线（出现任一条，尽快就医；标注急诊的直接去急诊）**

- 单个关节突发红肿热痛并伴发热、寒战 —— 需排除感染性关节炎，尽快就诊
- 关节痛伴皮肤破溃流脓、明显红肿扩散
- 痛风石破溃、感染，或关节畸形影响活动
- 剧烈腰痛或腹痛伴血尿、排尿困难 —— 需排除尿路结石，尽快就诊
- 尿量明显减少、下肢或眼睑明显水肿 —— 提示肾功能受累
- 胸痛、胸闷、一侧肢体无力、说话不清 —— 急诊
- 尿酸极高伴恶心呕吐、乏力、意识改变
- 开始降尿酸治疗后出现皮疹、发热、肝功能异常表现 —— 立即联系医生

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「尿酸高哪些绝对不能吃」 | 用 |
| 「啤酒和白酒哪个更危险」 | 用，说明酒精影响排泄 |
| 「豆制品到底能不能吃」 | 用，说明现有观点与个体差异 |
| 「急性发作期怎么吃」 | 用，急性期从严 |
| 「火锅汤能不能喝」 | 用，说明汤中嘌呤溶出 |
| 「吃什么药降尿酸」 | 不用，由医生决定 |
| 「关节又红又肿还发烧」 | 只作就医提示 |

## 三、完整工作流

1. **先排红线**：逐条核对就医红线，命中则停止饮食建议，转为就医提示。
2. **分期**：判断是急性发作期（关节红肿热痛）还是缓解期（无症状、降尿酸阶段）。
3. **列忌口**：按 `rules/食物嘌呤分级表.md` 标出该期应避免、限量、可放心吃的三类。
4. **核一餐**：用脚本按食物成分表口径估算一餐嘌呤总量并分级。
5. **查酒精与果糖**：单独核对酒类、含糖饮料、蜂蜜、果汁的摄入，这两项常被漏掉。
6. **管饮水**：在心肺肾功能允许前提下增加饮水，记录每日尿量颜色。
7. **长期项**：体重管理、规律运动、避免快速减重与脱水，记录发作诱因。

## 四、核心规则与要件库

生成忌口清单前，**必须先读**：

- `rules/食物嘌呤分级表.md`：分级口径、常见食物归属、汤汁与酒类说明。
- `rules/急性期与缓解期饮食.md`：两期的具体口径、饮水与体重管理、高频误区。

不得把「不吃海鲜」当成唯一忌口；酒精和果糖饮料同等重要。不得因食物嘌呤低就建议不限量，总热量与体重同样影响尿酸。

## 五、脚本用法

```
python scripts/purine_calc.py --file meal.json
python scripts/purine_calc.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`items` 为食物名与重量列表，`stage` 为 `acute` 或 `chronic` |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--json` | 以 JSON 输出 |
| `--selftest` | 运行自检 |

脚本输出每项嘌呤毫克数、分级、合计、急性期上限对比与需删除的高危项。**未收录的食物不会凭空估算，会列为待确认项。**

## 六、人工确认清单

- [ ] 就医红线已排除，尤其发热伴单关节红肿
- [ ] 当前是急性发作期还是缓解期已确认
- [ ] 酒类（含啤酒、黄酒、白酒）与含糖饮料摄入已如实核对
- [ ] 每日饮水量与尿量情况已记录，心肺肾功能限制已考虑
- [ ] 正在使用的降尿酸药、利尿剂、阿司匹林等已告知
- [ ] 肾功能、尿路结石史、高血压糖尿病等合并症已告知
- [ ] 食物重量按可食部计算，汤汁类不按固体重量估算
- [ ] 近期是否有快速减重、脱水、剧烈运动等诱因已记录

## 七、最常见的坑

1. **只忌海鲜不忌酒**：酒精既含嘌呤又抑制尿酸排泄，啤酒和黄酒尤其明显，很多人漏掉这一项。
2. **只忌嘌呤不管果糖**：果糖代谢会升高尿酸，含糖饮料、奶茶、果汁、蜂蜜同样是风险项。
3. **喝火锅汤、老火汤「补」**：嘌呤易溶于水，汤里的嘌呤往往高于肉本身。
4. **不敢吃蔬菜**：蔬菜来源的嘌呤与痛风发作风险的关系和动物嘌呤不同，不必一概禁食。
5. **长期只吃少数几种「安全食物」**：营养不均衡，且总热量不足引起的酮体也会影响尿酸排泄。
6. **快速减重和断食**：体重骤降、饥饿性酮症会诱发急性发作。
7. **剧烈运动后不补水**：大量出汗脱水使尿酸浓度升高。
8. **发作期才忌口、缓解期放开**：缓解期才是降尿酸的关键窗口，需要长期维持。

## 八、边界与免责

本技能提供痛风饮食管理的通用口径与嘌呤核算工具，不构成医疗建议或治疗方案。食物嘌呤数值来自通用食物成分表口径，品种、部位、加工与烹饪方式差异很大；是否需要降尿酸药物、药物选择与剂量、尿酸控制目标因肾功能、结石史、心血管合并症而异，**以最新版临床指南和风湿免疫科或内分泌科医师的判断为准**。出现就医红线中的任一情况，请立即就医。
