# 急性期与缓解期饮食

痛风的饮食管理在发作期和缓解期目标不同：发作期求「不加重」，缓解期求「降下来」。

## 一、两期对比

| 项目 | 急性发作期 | 缓解期（降尿酸阶段） |
|---|---|---|
| 高嘌呤食物 | 严格避免 | 尽量避免 |
| 中嘌呤食物 | 明显减少，份量压到日常的一半以下 | 限量，控制频次与份量 |
| 低嘌呤食物 | 作为主要来源 | 作为主要来源 |
| 酒精 | 完全避免，包括啤酒、黄酒、白酒 | 是否可少量需医生判断，多数建议避免 |
| 含糖饮料与果汁 | 避免 | 避免 |
| 浓汤与火锅汤 | 避免 | 避免 |
| 饮水 | 在心肺肾功能允许下增加 | 长期保持充足饮水 |
| 重点 | 减少外源嘌呤、避免诱发因素 | 长期维持，配合药物治疗 |

## 二、每日饮食结构口径

| 组成 | 口径 |
|---|---|
| 蛋白质 | 优先蛋、奶、豆制品；动物肉控制份量 |
| 蔬菜 | 充足，不必因嘌呤一概限制 |
| 主食 | 按体重与活动量控制总量，避免超重 |
| 脂肪 | 控制烹调油，减少油炸与肥肉 |
| 水果 | 整果适量，不喝果汁 |

具体热量与蛋白质目标需结合体重、肾功能由医生或营养师确定，肾功能不全者蛋白质摄入需特别调整。

## 三、饮水口径

| 项目 | 口径 |
|---|---|
| 总量 | 在无心肺肾功能禁忌的前提下，常见建议为每日 2000 毫升以上 |
| 判断 | 尿色清淡、尿量充足说明基本够 |
| 禁忌 | 心衰、肾功能不全、需限水的患者按医生给的限额执行 |
| 时机 | 分次少量，不要一次大量 |
| 选择 | 白水为主，淡茶可计入；不用甜饮料代替 |

**限水患者必须遵医嘱，不要照搬 2000 毫升这个数字。**

## 四、体重与运动

| 项目 | 口径 |
|---|---|
| 减重速度 | 缓慢平稳，避免快速减重与断食（可诱发急性发作） |
| 运动类型 | 规律中等强度有氧为主，避免突然剧烈运动 |
| 运动补水 | 运动前后补足水分，避免脱水 |
| 关节状态 | 急性发作期受累关节休息，不强行活动 |

## 五、发作诱因记录

| 诱因 | 说明 |
|---|---|
| 饮酒 | 尤其啤酒与黄酒 |
| 大量高嘌呤饮食 | 内脏、海鲜大餐 |
| 脱水 | 出汗多、饮水少、腹泻 |
| 快速减重或长时间空腹 | 饥饿性酮症影响尿酸排泄 |
| 剧烈运动或外伤 | 局部关节受累 |
| 某些药物 | 利尿剂、小剂量阿司匹林等，是否调整由医生判断 |
| 感染、手术、熬夜 | 应激状态 |

## 六、高频误区

| 误区 | 事实 |
|---|---|
| 「只要不吃海鲜就行」 | 酒精、含糖饮料、动物内脏、浓汤同样重要 |
| 「蔬菜嘌呤高所以也要忌」 | 蔬菜来源嘌呤与动物嘌呤的影响不同，不必一概禁食 |
| 「豆制品绝对不能碰」 | 加工后嘌呤明显低于干豆，缓解期可适量，个体差异需观察 |
| 「喝汤最补，肉可以不吃」 | 嘌呤溶于水，汤往往是嘌呤最集中的部分 |
| 「发作期猛运动出汗排毒」 | 脱水反而升高尿酸浓度 |
| 「不痛了就可以放开吃」 | 缓解期是降尿酸的关键窗口，需要长期维持 |
| 「快速断食降尿酸」 | 饥饿性酮症会诱发发作 |
| 「靠饮食就能不吃药」 | 是否需要降尿酸药物由医生结合尿酸水平、发作频次与合并症判断 |

## 七、就诊与监测

| 项目 | 口径 |
|---|---|
| 监测指标 | 血尿酸、肾功能、尿常规、血压血糖血脂，按医嘱复查 |
| 复诊带什么 | 发作记录（日期、关节、诱因）、饮食记录、用药清单、近期化验单 |
| 何时联系医生 | 发作频次增加、出现痛风石、尿量减少、血尿、用药后不适 |

## 八、提问清单

- 我的血尿酸控制目标是多少？
- 我这个情况需要降尿酸药物吗？
- 有心肾功能问题时，每日饮水量按多少算？
- 我在用的利尿剂或阿司匹林是否需要调整？
- 缓解期哪些食物可以恢复到什么份量？
- 发作时应该先做什么、什么时候必须来医院？
