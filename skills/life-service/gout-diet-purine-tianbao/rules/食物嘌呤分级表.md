# 食物嘌呤分级表

> 嘌呤数值为通用食物成分表口径（每 100 克可食部，单位毫克），
> 品种、部位、产地、加工与烹饪方式差异很大，**以最新版临床营养指南和医师判断为准**。

## 一、分级口径

| 分级 | 每 100 克嘌呤 | 处置 |
|---|---|---|
| 低嘌呤 | 低于 50 毫克 | 一般可放心选择 |
| 中嘌呤 | 50-150 毫克 | 缓解期限量，急性期减少 |
| 高嘌呤 | 150 毫克以上 | 缓解期尽量避免，急性期严格避免 |

不同指南的分级切点略有差异，本表采用常见三档口径。

## 二、应避免类（高嘌呤）

| 类别 | 常见食物 | 说明 |
|---|---|---|
| 动物内脏 | 肝、肾、脑、胰、心 | 嘌呤最集中，急性期与缓解期都应避免 |
| 部分海产 | 沙丁鱼、凤尾鱼、小鱼干、鱼子、贝类、牡蛎、蛤蜊 | 单位重量嘌呤高，小鱼干尤其明显 |
| 浓汤类 | 火锅汤、老火靓汤、浓肉汤、炖煮久的鸡汤 | 嘌呤易溶于水，汤中含量常高于肉本身 |
| 干菌藻 | 干香菇、紫菜（干） | 干制品按干重计数值很高，泡发后按实际摄入折算 |
| 酵母类 | 酵母粉、酵母提取物调味品 | 常隐藏在酱料和调味品里 |

## 三、限量类（中嘌呤）

| 食物 | 说明 |
|---|---|
| 猪牛羊肉 | 瘦肉类普遍中嘌呤，缓解期控制份量与频次 |
| 禽肉 | 鸡、鸭，去皮可略减脂肪 |
| 多数鱼类 | 带鱼、鲳鱼、草鱼等 |
| 虾蟹 | 个体较大者单次摄入量容易超标 |
| 干豆类 | 黄豆、黑豆等干豆嘌呤不低，但加工后的豆制品明显降低 |
| 花生、部分坚果 | 嘌呤中等且热量高 |

## 四、一般可放心选择（低嘌呤）

| 食物 | 说明 |
|---|---|
| 蛋类 | 鸡蛋、鸭蛋，嘌呤很低 |
| 奶类 | 牛奶、无糖酸奶，部分研究显示与较低的尿酸水平相关 |
| 多数蔬菜 | 叶菜、瓜茄、根茎类，不必因「蔬菜也有嘌呤」而一概禁食 |
| 多数水果 | 注意含糖饮料与果汁另算，整果优于榨汁 |
| 精制谷物 | 米、面，注意总量与体重管理 |
| 豆腐、豆浆 | 加工后嘌呤明显低于干豆，缓解期可适量 |

## 五、酒类与饮料（单独查，最容易漏）

| 项目 | 风险点 |
|---|---|
| 啤酒 | 本身含嘌呤，且酒精代谢抑制尿酸排泄，双重影响 |
| 黄酒 | 同样兼具嘌呤与酒精影响 |
| 白酒、烈酒 | 嘌呤不高，但酒精抑制排泄且影响代谢 |
| 含糖饮料、奶茶 | 果糖代谢促进尿酸生成 |
| 果汁、蜂蜜 | 果糖集中，整果优于果汁 |
| 无糖饮料 | 相对好于含糖饮料，但仍不能代替水 |

急性期应完全避免酒精；缓解期是否可少量饮酒需医生结合尿酸控制、用药与肝功能判断。

## 六、烹饪与加工影响

| 做法 | 影响 |
|---|---|
| 水煮、焯水后弃汤 | 可溶出部分嘌呤，优于直接炖煮食用 |
| 炖煮、熬汤 | 嘌呤进入汤中，喝汤等于摄入溶出的嘌呤 |
| 烧烤、油炸 | 增加脂肪与热量，影响体重与代谢 |
| 打碎、打成浓浆 | 不改变嘌呤总量，但容易一次摄入过多 |

## 七、数值表使用提醒

- 干制品（干香菇、紫菜、小鱼干）按干重计，泡发后重量变化大，按实际摄入的生重或干重区分
- 汤汁类不适合用固体食物重量估算，按避免处理更稳妥
- 同一食物不同部位差异明显（如内脏与瘦肉）
- 数值只用于理解相对高低，不用于精确控制
