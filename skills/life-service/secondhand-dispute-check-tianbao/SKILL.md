# 闲鱼二手交易纠纷取证与维权

面向在闲鱼等二手平台买到与描述不符、假货、损坏、少件，或卖家收款不发货、收货后失联的买家。

## 它能做什么

- 核查**交易方式风险**：平台担保 vs 微信直转，决定钱还能不能追回
- 判断**七天无理由适不适用**：二手商品、定制品、个人闲置的边界一次说清
- 判断**描述不符 / 假货 / 损坏**分别怎么主张、举证责任在谁
- 给出**开箱视频与聊天记录的取证标准**：什么样的证据平台才会认
- 输出**退款测算**、平台介入话术与 12315、报警的升级路径

## 使用方式

把 `templates/二手交易纠纷采集表.md` 填好（两列表或「字段：值」），交给本技能生成核查报告。
未填项一律按「待补正 / 有风险」处理，绝不判通过。

## 边界

本结果依通用规则整理，不替代专业法律意见，最终以平台规则、市场监管部门及司法机关认定为准。
平台介入时限与判定标准以各平台现行规则为准。
