# 取证操作卡与平台介入话术

## 卡片 A：开箱视频怎么拍（二手交易第一证据）

```
第 1 步  快递外包装完整状态（不拆封）先拍一圈，拍到面单
第 2 步  一镜到底拆封，中途不剪辑、不转场
第 3 步  取出商品，拍全貌 + 序列号 + 所有细节
第 4 步  有问题的部位给特写，口播说明问题
第 5 步  保留原始文件（不要只存压缩截图），记下拍摄时间
```

**不采信的拍法**：拆完才想起来拍、只拍一张照片、拍完才发现问题又补拍。

## 卡片 B：收货前必做的三个动作

1. **先验货再签收**——贵重物品当着快递员的面开箱，有问题当场拒收并拍照
2. **不要点「确认收货」**——确认后货款才到卖家账，这是最关键的资金闸门
3. 有问题**当天**在平台内发起退款申请，聊天里同步说明，留下时间戳

## 卡片 C：描述不符的申诉话术（平台内）

> 商品描述为「99新无拆无修，快门数不到两千，原装电池两块，配件齐全」，
> 实际收到：底部螺丝有拧动痕迹、实测快门数一万三千多、电池仅一块且非原装、缺原装充电器。
> 已附商品描述截图、开箱视频、聊天记录与实物照片。
> 依据平台规则与《民法典》关于出卖人应按约定交付标的物的相关规定，申请退货退款，运费由卖家承担。

**要点**：先复述卖家原话，再列差异，最后给依据与诉求。不要写情绪化的话。

## 卡片 D：假货的申诉话术

> 经与品牌官方渠道比对（附比对图 / 鉴定结论），该商品非正品。
> 卖家以正品名义出售，构成根本违约。依据《消费者权益保护法》相关规定，
> 申请退款并主张相应赔偿。已附鉴定结论、商品细节图与聊天记录。

**要点**：假货必须附鉴定结论，只说「我觉得是假的」平台不会支持。

## 卡片 E：站外付款被骗后的三步

```
第 1 步  支付渠道投诉
  微信/支付宝内找到该笔转账 → 发起投诉 → 选择「被骗」→ 上传聊天与商品截图
  这一步有机会冻结对方账户，越早越好

第 2 步  平台举报
  在交易发生的平台举报该卖家 → 提交站外付款诱导的聊天证据
  即便款项不受理，也能让账号被处置，防止更多人受骗

第 3 步  报警
  携转账凭证（含收款方账号）、聊天记录、商品信息到派出所报案
  金额达到立案标准的，公安机关可依法侦查
```

## 卡片 F：卖家失联或注销时怎么说

- 对平台客服：「卖家账号已注销，申请平台披露卖家实名信息与收款账户，用于后续维权与报案。」
- 对 12315（卖家属经营性销售时）：「在 ×× 平台向卖家 ×× 购买 ××，付款后商品与描述严重不符，
  现卖家账号注销无法联系，请求协调平台提供经营者信息。」
- 对派出所：「我被以二手交易名义骗取 ¥××，有转账流水号与收款方账号，请求立案。」

## 卡片 G：与卖家沟通的三条纪律

1. **全部走平台聊天**，不转到微信——转到站外平台就管不了了
2. **不删任何记录**，包括不愉快的对话——完整记录才可信
3. **不威胁、不人身攻击**——申诉材料里的情绪化表述会降低你的可信度

## 卡片 H：升级路径（按顺序，每级留编号）

```
1. 平台内申请退款 + 平台介入      → 留工单号
2. 平台判定不利 → 申请平台二次复核
3. 12315 投诉（卖家属经营性销售）  → 留受理编号
4. 支付渠道投诉（站外付款）        → 留投诉编号
5. 报警（涉诈骗）                 → 留受案回执
6. 小额诉讼（金额明确、证据完整）  → 人民法院在线服务
```
