## 一、结论摘要

| 项 | 结论 |
| --- | --- |
| 交易方式风险 | 待填 |
| 问题类型 | 待填 |
| 七天无理由 | 待填（适用 / 不适用 / 有争议 / 已超期 / 待补正） |
| 举证充分度 | 待填 |
| 暂计应退 | 待填 |
| 高危项 | 待填（n 项） |
| **总体结论** | **通过 / 有风险 / 不通过 / 待补正** |

四态含义：

- **通过**：平台担保交易、证据完整、无实质争议
- **有风险**：存在需补正或需交涉的问题，但资金仍在可追回范围
- **不通过**：命中高危项（站外直转、卖家失联、假货、超期无证据）
- **待补正**：核心事实未填，不下实质结论
