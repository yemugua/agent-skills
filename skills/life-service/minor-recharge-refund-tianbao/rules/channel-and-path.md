# 七步路径与投诉渠道

## 七步路径（脚本 `PATHS`）

### 第 1 步：先固定证据（24 小时内）

**别急着找客服吵架**，先把四件事做完：

1. **保存订单号、充值流水、扣费记录**——游戏内或 App 内导出，截图带订单号
2. **保存孩子的游戏内聊天、留言、语音**——能证明是孩子操作，做成**录屏**（录屏比截图更难被质疑）
3. **申请账号所有权人变更或账号保护**——防止孩子继续消费，也表明你不是放任
4. **记录每一笔的时间、金额、渠道**——列成明细表，笔数与时间跨度本身就是主张材料

### 第 2 步：与平台书面协商（7 日内）

- 提交**书面**退款申请（网页工单、邮件、书面函件均可）
- 核心理由用「**未成年人限制民事行为能力人的行为需法定代理人追认**」
- **一次说清诉求与证据清单**，附上所有材料
- **要求书面答复**，留存工单号

### 第 3 步：申请未成年人退款通道

- 主流游戏平台均设有**未成年人充值退款申请入口**
- 按平台要求提交：身份证明、**监护关系证明**（户口本即可）、账号归属证明
- 平台会要求填写**孩子的情况说明**（孩子年龄、充值原因、是否受诱导）

### 第 4 步：找行业主管部门

| 消费类型 | 主管部门 |
|---|---|
| **网络游戏** | 所在地**文化和旅游部门**、**新闻出版署**相关渠道 |
| **直播打赏** | **网信办**及直播平台所在地**文化部门** |
| **短视频道具** | **广电总局**相关渠道 |
| **网络文学付费** | 出版主管部门、平台所在地监管部门 |

投诉材料：申请函 + 全套证据 + 平台答复截图（证明你已先找过平台）

### 第 5 步：12315 与 12345

- **12315**：消费者投诉举报平台（市场监管部门），处理率高、速度较快
- **12345**：政务服务便民热线，可作为补充与推动渠道
- 拨通后说明"已先找平台协商并被拒"，要求**登记编号**

### 第 6 步：公安报案

存在下列情形可报案：
- **被诱导消费**（主播诱导、抽奖骗局）
- **平台漏洞**（无实名可充值、限额可绕过）
- **疑似诈骗**（第三方骗取支付密码后充值）

报案主张诈骗；对恶意套取或诱导未成年人消费的，要求**移送**。

### 第 7 步：民事诉讼

- 被告：**游戏运营主体所属公司**（不是客服所在的分公司）
- 请求权基础：「**限制民事行为能力人实施的民事法律行为未经法定代理人追认**」
- 诉请：返还充值款及利息
- **起诉前建议先咨询律师**，特别是金额较大或已被平台多次拒绝的

## 各渠道话术要点

**平台客服 / 工单**
> "我要对未成年人充值申请退款。理由是：孩子 X 岁，属限制民事行为能力人，该笔消费明显超出其年龄智力水平，我作为监护人明确不予追认。请给我工单号与书面答复时限。"

**12315 / 主管部门**
> "我已于 X 月 X 日向 [平台名称] 提出退款申请并被拒，平台理由是'实名是成年人'。但实名信息是我提供的，平台从未核实实际使用人年龄，也未拦截异常消费。现附全套材料，请依法处理。"

**公安**
> "我的孩子在游戏内充值 X 元，未经我同意，疑被诱导或平台存在漏洞未拦截消费，我要求立案调查。"

## 一次说清的证据清单

提交时按下述顺序编号装订：

1. **监护人身份证明**（身份证）
2. **未成年人身份证明与监护关系证明**（户口本，含孩子页）
3. **孩子出生日期证明**（户口本或出生证）
4. **账号归属与实名信息截图**（游戏内或 App 内截图）
5. **充值消费记录**（订单流水，带订单号）
6. **孩子操作证据**（游戏内聊天、语音、动态录屏）
7. **孩子的情况说明**（手写或打印，监护人签字）
8. **已做的监护措施截图**（防沉迷、限额、支付密码设置界面）
9. **与平台沟通的记录**（工单号、答复截图、客服录音）

## 时限提醒

- 平台内部处理：通常 **7~15 日**
- 12315 / 主管部门：**15~30 日**
- **越早越好**。间隔越久，平台的"孩子已使用很久未被发现"抗辩越有说服力
- 民事诉讼：3 年诉讼时效

## 谈判的进退

- 平台第一次通常**不会全额退**，多是"申请 1~2 笔小额"
- **第一次不要接受小额处理**。可以先要求全额，再在后续协商中适度让步
- 若最终协商部分退款，**务必要求书面写明金额与条件**
- **收到款再撤诉/结案**，不要先撤后等
