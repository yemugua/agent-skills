# 未成年人充值退款申请与投诉操作卡

> 先止血，再取证，最后才谈钱。**顺序不能乱。**

## 【第一步：立刻止血】

- [ ] 申请**账号保护**或**账号所有权人变更**，防止孩子继续消费
- [ ] 修改支付密码、关闭免密支付
- [ ] 记录每一笔充值的**时间、金额、渠道、订单号**

## 【第二步：固定证据（24 小时内）】

- [ ] 导出**全部订单与充值流水**（带订单号，截图）
- [ ] 录制**游戏内聊天、语音、动态**的**录屏**（不是单张截图）
- [ ] 截图**账号实名信息**与账号 ID
- [ ] 截图**青少年模式、支付密码、消费限额**设置界面
- [ ] 保存**客服工单号、答复截图、通话录音**
- [ ] 写一份**孩子的情况说明**（为什么充、是否被诱导），监护人签字
- [ ] 准备**监护人身份证**与**孩子户口本**（含监护关系页）

> 沟通孩子时的提醒：**先问清为什么充，不要先指责**。攀比、想赢、被诱导——这些细节既是材料，也关系到孩子后面愿不愿意配合。

## 【第三步：书面申请（第 1 次，先要全额）】

- [ ] 通过平台的**未成年人退款通道**或客服工单提交
- [ ] 工单里写明：
  - 孩子年龄，属**限制民事行为能力人**
  - 金额**明显超出其年龄智力相适应的水平**
  - 作为监护人**明确不予追认**，该行为无效
  - 平台**从未核实实际使用人年龄**，**未拦截异常消费**
  - 请求**全额返还** X 元
- [ ] 附上全部证据（按清单编号）
- [ ] 索取**工单号**与**书面答复时限**

> ⚠️ **第一次不要接受小额处理**。平台第一次多半只肯退一两笔，**先按全额主张**，后续再谈让步。

## 【第四步：按答复分流】

| 平台答复 | 你的动作 |
|---|---|
| 拒绝退款 | 索取**书面**拒赔依据 → 第五步 |
| "核实中" | 记下**答复时限**，逾期未回 → 第五步 |
| "需补充材料" | 按清单**一次性补齐**，避免来回 |
| "可部分退款" | **不接受未写明金额的"综合考虑"**，要求书面写明 |
| "已全额退还" | 确认**到账**，保存凭证 |

## 【第五步：找主管部门】

- [ ] **游戏** → 所在地**文化和旅游部门**、**新闻出版署**相关渠道
- [ ] **直播打赏** → **网信办**、平台所在地**文化部门**
- [ ] **短视频道具** → **广电总局**相关渠道
- [ ] 拨 **12315**（消费者投诉举报）
- [ ] 拨 **12345**（政务便民热线）
- [ ] 投诉材料里写明"**已先找平台协商并被拒**"

## 【第六步：必要时报案】

- [ ] 存在**被诱导消费 / 平台漏洞 / 疑似诈骗** → 到公安机关报案
- [ ] 索取**受案回执**
- [ ] 对恶意套取或诱导未成年人消费的，要求**移送**

## 【第七步：诉讼（谨慎）】

- [ ] 被告是**游戏运营主体所属公司**（不是客服所在分公司）
- [ ] 请求权基础：**限制民事行为能力人的行为未经法定代理人追认**
- [ ] 诉请：返还充值款及利息
- [ ] **起诉前先咨询律师**
- [ ] **收到钱再撤诉**

## 平台抗辩应对速查

| 平台说 | 你回 |
|---|---|
| 实名是成年人 | **实名是我提供的，平台从未核实实际使用人的年龄** |
| 已尽审查义务 | **核验了什么？请提供核验记录与留存依据** |
| 有完整消费记录 | **记录完整不代表意思表示真实**，且 11 笔 4860 元为何未触发风控？ |
| 已发提醒 | **事后提示不能替代事前告知**，无法使待定行为变为有效 |
| 多次索要实名 | **索要实名 ≠ 核实实际使用人年龄**，这是两件事 |

## 一次性补齐清单

1. 监护人身份证
2. 孩子户口本（含监护关系页）
3. 账号归属与实名信息截图
4. 充值订单流水（带订单号）
5. 孩子操作证据（聊天、语音录屏）
6. 孩子的情况说明（签字）
7. 已做的监护措施截图
8. 与平台沟通记录（工单、答复截图、录音）
