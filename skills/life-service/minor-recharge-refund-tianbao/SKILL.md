# 未成年人游戏充值退款核查

这类争议的胜负不在"孩子确实充了钱"——这点平台也认，而在**「谁来承担这笔钱」**。平台的抗辩永远围绕"实名是成年人、已尽审查义务"，而你的破局点是把**孩子年龄、实际操作人、监护义务履行、平台监管责任**这四件事摆清楚。

## 什么时候用

- 孩子未经允许给游戏、直播、短视频、小说付费充值
- 平台客服说"实名是成年人账号""我们已尽审查义务"直接拒绝
- 不知道该找哪个部门投诉，反复找客服没有结果
- 孩子被同学攀比、想做网红、想赢游戏、被主播诱导打赏
- 金额不大但心里过不去，或者金额很大想追回来

## 怎么做

**第 1 步**：复制 `templates/未成年人充值退款信息采集表.md` 填写（孩子出生日期、消费平台、充值经过、笔数与时间跨度、监护措施、平台答复是关键项）。

**第 2 步**：跑脚本

```bash
python scripts/minor_recharge_refund.py 采集表.md --base 2026-10-05 --out 核查报告.md
```

**第 3 步**：照第八段七步路径走——**先固定证据 → 书面申请 → 找平台未成年人退款通道 → 找主管部门 → 12315/12345 → 必要时报案 → 诉讼**。

## 三条决定结果的核心规则

1. **年龄决定适用哪条法律**。不满八周岁是**无民事行为能力人**，其实施的民事法律行为**一律无效，平台必须全额返还**；八到十八周岁是**限制民事行为能力人**，充值行为处于"待追认"状态，**家长明确表示不追认的，行为无效、可要求返还**。这一句是所有书面申请的核心理由。
2. **争议的核心是"谁操作的"，不是"有没有这笔消费"**。所以证据要围绕**孩子的操作痕迹**组织：游戏内聊天、语音、动态、同学证言、录屏。只堆订单截图，平台一句"消费记录完整"就能挡回来。
3. **平台的抗辩要逐条拆**。实名是成年人？——**实名信息是谁提交的、平台有没有向监护人核实孩子年龄**？已尽审查义务？——**核实与提示的具体动作是什么、有没有留存记录**？消费记录完整？——**记录完整不代表意思表示真实**，限制民事行为能力人的行为效力待定。

## 边界与纪律

- 依**通用规则**整理，**不替代律师意见**；处理口径**以平台规则、行业主管部门与司法机关认定为准**
- 报告金额按已填订单与流水汇总，**实际退款金额以平台或法院认定为准**
- 不预测平台是否同意退款，也不预测投诉与诉讼结果
- **未填的一律不算通过**，只按已填内容判断
- 涉及孩子姓名、学校、身份证号等未成年人隐私信息，**本地处理，不要外发**
- 沟通孩子时注意方式：**先了解孩子为什么要充，不要一味指责**——孩子的攀比心理、被诱导情形，都是争取有利的材料
