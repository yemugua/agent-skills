# 儿童发热物理降温与家庭护理

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 按月龄给出体温口径与就医红线 | 判断发热原因、诊断疾病、处方用药 |
| 说明温水擦拭、减少衣物、补液的正确做法 | **提供任何退热药的剂量、频次或用药方案** |
| 列出明确禁忌（捂汗、酒精擦浴、冰水浴等） | 建议输液、抗生素或抗病毒药物 |
| 提示热性惊厥的现场处置与送医口径 | 承诺物理降温能把体温降到正常 |
| 输出护理记录与就诊分级 | 建议交替用药或联合用药 |

**就医红线（出现任一条，立即就医；标注急诊的直接去急诊）**

- **3 个月以下婴儿体温 ≥38.0℃（肛温）或腋温 ≥37.5℃** —— 急诊评估，不要自行在家观察
- **热性惊厥发作，尤其持续超过 5 分钟、或反复发作、或发作后意识未恢复** —— 急诊
- 意识改变：叫不醒、异常嗜睡、烦躁不安难以安抚、眼神发直
- 颈项强直、低头时脖子痛、剧烈头痛、反复呕吐
- 皮疹压之不褪色（瘀点样皮疹）、皮肤出现紫红色斑点 —— 急诊
- 呼吸困难、喘息、鼻翼扇动、锁骨上或肋间凹陷、口唇发紫 —— 急诊
- 明显脱水：8 小时以上无尿（婴儿 6 小时无尿）、口唇干裂、哭时无泪、眼窝或囟门凹陷、皮肤弹性差
- 持续拒绝饮水、无法进食进水、频繁呕吐腹泻
- 发热超过 3 天（任何年龄）或体温反复超过 40℃
- 免疫缺陷、正在化疗、长期使用激素或免疫抑制剂的患儿发热 —— 急诊
- 发热伴抽搐、肢体无力、行走异常、囟门明显膨隆
- 有基础心脏病、遗传代谢病、早产史的患儿发热，就医门槛应更低
- 家长直觉上觉得「孩子看起来很不对劲」—— 这条本身就是要就医的理由

## 三、完整工作流

1. **先定月龄**：3 个月以下、3-6 个月、6-24 个月、2 岁以上，四档就医门槛不同，先确认。
2. **测准体温**：记录测量部位（腋温、耳温、额温、肛温）与时间；不同部位正常值不同，必须注明。
3. **排红线**：逐条核对就医红线，命中即转就医，不给家庭护理方案。
4. **评估舒适度而非只看数字**：观察精神状态、饮水、尿量、呼吸、睡眠，比单纯看体温数字更重要。
5. **物理降温**：按 `rules/物理降温操作与误区.md` 执行温水擦拭与减少衣物，明确不做酒精擦浴与冰水浴。
6. **补液**：少量多次给水或口服补液盐，记录尿量与次数。
7. **记录与复评**：每 4 小时记录体温、饮水、尿量、精神状态；出现任何红线立即就医。

## 四、核心规则与要件库

生成护理建议前，**必须先读**：

- `rules/体温分级与月龄红线.md`：各月龄的体温口径、分级与就医门槛。
- `rules/物理降温操作与误区.md`：温水擦拭做法、明确禁忌、补液与观察要点、惊厥现场处置。

不得给出任何退热药的名称剂量与用药方案。不得以体温数字作为唯一就诊依据，精神状态和饮水情况同样重要。

## 五、脚本用法

```
python scripts/child_fever_triage.py --file case.json
python scripts/child_fever_triage.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`age_months` 月龄，`temp` 体温，`site` 测量部位，`duration_hours` 发热时长，症状标记 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--json` | 以 JSON 输出 |
| `--selftest` | 运行自检 |

脚本输出就诊分级（急诊 / 当日就诊 / 家庭护理观察 / 信息不足）与护理要点。**脚本不输出任何药物剂量。**

## 六、人工确认清单

- [ ] 月龄已确认，按对应档位执行（3 个月以下是最高警戒档）
- [ ] 体温已注明测量部位与时间，未跨部位直接比较
- [ ] 就医红线逐条核对完毕
- [ ] 精神状态、饮水意愿、尿量、呼吸已观察并记录
- [ ] 未使用酒精擦浴、冰水浴、捂汗等禁忌做法
- [ ] 退热药使用严格遵医嘱或药师说明，未自行加量与交替
- [ ] 家庭成员未吸烟、室内通风与温湿度合适
- [ ] 随访或复诊时间点已明确，知道什么情况要立刻返回医院

## 七、最常见的坑

1. **捂汗退烧**：婴幼儿体温调节能力弱，捂汗会导致散热障碍、脱水甚至高热，是明确的禁忌。
2. **酒精擦浴**：酒精经皮肤吸收可致中毒，婴幼儿风险更高，绝对禁止。
3. **冰水或冷水浴**：寒战反而使体温上升，且患儿极度不适。
4. **只看体温数字**：体温 38℃ 但精神好、能喝水，和体温 38℃ 但嗜睡拒饮，是完全不同的情况。
5. **一发热就用抗生素**：多数儿童发热为病毒感染，抗生素由医生判断后使用。
6. **交替或叠加用药**：退热药种类、剂量与间隔必须由医生或药师确定，自行交替风险高。
7. **睡着叫醒喂药**：睡眠本身是休息，是否用药看整体舒适度，按医嘱执行。
8. **忽略小婴儿**：3 个月以下婴儿发热可以是严重感染的唯一表现，必须就医评估。

## 八、边界与免责

本技能提供儿童发热的家庭护理口径与物理降温做法，**不提供任何药物剂量与用药方案**。体温分级与月龄门槛因测量部位、指南版本与个体基础疾病而异，**以最新版儿科相关指南和儿科医师的判断为准**。3 个月以下婴儿、热性惊厥、意识改变、脱水、皮疹压不褪色、呼吸困难等情况必须立即就医。本技能不替代诊疗，任何怀疑严重情况的场合请立即就诊。
