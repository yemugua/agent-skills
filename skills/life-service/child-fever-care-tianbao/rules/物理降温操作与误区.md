# 物理降温操作与误区

物理降温的目的是让孩子舒服，不是把体温数字压下去。

## 一、可以做的物理降温

| 做法 | 具体口径 |
|---|---|
| 减少衣物 | 不要捂，穿单层轻薄衣物，室温合适即可；手脚凉时可先保暖手脚，躯干不要捂 |
| 调节室温 | 保持通风，室温以孩子舒适为准，夏季可用空调，避免直吹 |
| 温水擦拭 | 水温约 32-34℃（手感温热不烫），用毛巾擦拭颈部两侧、腋下、肘窝、腹股沟、腘窝等大血管走行处 |
| 擦拭时长 | 每次 10-20 分钟，观察孩子反应；出现寒战、哭闹抗拒、皮肤发花立即停止 |
| 补充水分 | 少量多次给水或口服补液盐，不以一次大量灌水为目标 |
| 保证休息 | 睡眠本身有助于恢复，不必为测量频繁叫醒 |

**擦拭后要不要擦干**：擦完后用干毛巾轻轻吸干，避免着凉。

## 二、明确禁止的做法

| 禁忌 | 原因 |
|---|---|
| **捂汗、盖厚被子发汗** | 婴幼儿散热能力弱，捂汗可导致体温进一步升高、脱水，甚至发生捂热综合征 |
| **酒精或白酒擦浴** | 酒精经皮肤吸收可致中毒，婴幼儿风险更高 |
| **冰水浴、冷水擦浴** | 引起寒战与外周血管收缩，反而使核心体温上升，且极度不适 |
| **冰袋直接接触皮肤** | 可致局部冻伤，需包裹且时间很短，多数情况不推荐 |
| **自行交替或叠加退热药** | 种类、剂量与间隔必须由医生或药师确定 |
| **一发热就要求输液或抗生素** | 输液与抗生素都有明确指征，由医生判断 |
| **贴身退热贴当主要手段** | 局部降温范围有限，作用主要是舒适感，不能替代整体护理 |

## 三、补液口径

| 项目 | 口径 |
|---|---|
| 方式 | 少量多次，每次几口，频繁给予 |
| 选择 | 白水、母乳或配方奶（婴儿）、口服补液盐；大儿童可加清淡流食 |
| 目标 | 保持尿量正常、口唇湿润 |
| 警惕 | 持续呕吐无法进水、8 小时以上无尿、囟门凹陷、哭无泪，需就医 |
| 不推荐 | 含糖饮料、浓茶、咖啡；不强迫灌水 |

## 四、热性惊厥的现场处置

| 步骤 | 做法 |
|---|---|
| 1 | 保持冷静，让孩子侧卧，防止误吸呕吐物 |
| 2 | 移开周围硬物与尖锐物，不要按压肢体、不要撬开嘴、不要往嘴里塞东西 |
| 3 | 记录发作开始时间，观察持续多久 |
| 4 | **发作持续超过 5 分钟，或反复发作，或发作后意识未恢复 —— 立即拨打急救电话** |
| 5 | 首次发作、发作形式不典型、伴发热以外的症状，发作停止后也应就诊评估 |
| 6 | 不要在此期间强行喂水喂药 |

## 五、常见误区

| 误区 | 事实 |
|---|---|
| 「捂出一身汗就好了」 | 捂汗有害，是明确禁忌 |
| 「酒精擦得快」 | 有中毒风险，绝对禁止 |
| 「发烧要立马把温度压到正常」 | 目标是舒适，不是把数字压下来 |
| 「烧得越高病越重」 | 体温高低与病情严重程度不总是平行，精神状态更关键 |
| 「手脚凉说明要加被子」 | 体温上升期手脚凉常见，躯干不要捂，手脚可适当保暖 |
| 「发烧会烧坏脑子」 | 单纯发热不会；引起发热的原发病（如脑炎）才可能，需医生判断 |
| 「睡着了也要叫起来吃药」 | 睡眠是休息，是否用药看整体情况并遵医嘱 |
| 「退烧了就不用去医院了」 | 反复发热超过 3 天、精神差、脱水等仍需就诊 |

## 六、就诊时带什么

| 材料 | 说明 |
|---|---|
| 体温记录 | 时间、数值、测量部位 |
| 发作情况 | 惊厥起止时间、表现、次数（可用手机录像） |
| 饮水与尿量 | 最近 8-12 小时的饮水次数与尿量 |
| 用药记录 | 药名、时间、量（严格按医嘱），包括外院用药 |
| 基础疾病与过敏史 | 早产、心脏病、免疫缺陷、药物过敏 |
| 接触史 | 幼儿园或家庭成员有无类似症状 |
