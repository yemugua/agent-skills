# 体温分级与月龄红线

> 体温口径因测量部位不同而不同，记录时必须注明部位。
> 数值为常见儿科参考口径，**以最新版指南和儿科医师的判断为准**。

## 一、发热判定（按测量部位）

| 部位 | 发热判定 |
|---|---|
| 腋温 | ≥37.3℃ |
| 口温 | ≥37.5℃ |
| 耳温、额温 | ≥38.0℃（受环境与操作影响较大） |
| 肛温 | ≥38.0℃ |

不同部位数值不能直接横向比较，必须写明部位与时间。

## 二、体温分级（以腋温为例）

| 分级 | 范围 |
|---|---|
| 低热 | 37.3-38.0℃ |
| 中度发热 | 38.1-39.0℃ |
| 高热 | 39.1-41.0℃ |
| 超高热 | 超过 41.0℃ |

分级用于描述严重程度，**不用于单独决定是否用药**；是否用药看整体舒适度并遵医嘱。

## 三、月龄分档与就医门槛（最严格的部分）

| 月龄 | 门槛 | 说明 |
|---|---|---|
| **0-3 个月（不满 3 个月）** | 腋温 ≥37.5℃ 或肛温 ≥38.0℃ 即需急诊评估 | 小婴儿发热可能是严重感染的唯一表现，不自行在家观察，不用退热药自行处理 |
| **3-6 个月** | 体温 ≥38.5℃ 或精神状态差、拒奶、尿少，应尽快就诊 | 门槛明显高于大龄儿童 |
| **6-24 个月** | 体温 ≥39℃ 伴明显不适，或发热超过 24 小时无好转，应就诊 | 有热性惊厥史者门槛更低 |
| **2 岁以上** | 体温反复 ≥40℃、发热超过 3 天、精神差或拒绝饮水，应就诊 | 精神状态比体温数字重要 |

## 四、不看体温也要立即就医的情况

| 情况 | 处置 |
|---|---|
| 惊厥发作，尤其持续超过 5 分钟 | 急诊，拨打急救电话 |
| 意识改变：叫不醒、异常嗜睡、眼神发直 | 急诊 |
| 颈项强直、剧烈头痛、反复呕吐 | 急诊 |
| 皮疹压之不褪色、皮肤紫红斑点 | 急诊 |
| 呼吸困难、鼻翼扇动、肋间凹陷、口唇发紫 | 急诊 |
| 明显脱水：长时间无尿、哭无泪、口唇干裂、囟门凹陷 | 急诊 |
| 免疫缺陷、化疗中、长期用激素者发热 | 急诊 |
| 发热超过 3 天或反复超过 40℃ | 尽快就诊 |
| 家长直觉觉得孩子「很不对劲」 | 就诊，这条本身就是理由 |

## 五、观察要点（比体温更重要）

| 项目 | 看什么 |
|---|---|
| 精神状态 | 能否被逗笑、眼神是否有神、是否异常烦躁或嗜睡 |
| 饮水 | 是否愿意喝水、能否咽下 |
| 尿量 | 婴儿 6 小时、儿童 8 小时无尿需警惕 |
| 呼吸 | 是否急促、费力、有无凹陷与呻吟 |
| 皮肤 | 有无皮疹、颜色、压之是否褪色、有无发花发凉 |
| 睡眠 | 是否能安稳入睡，睡醒后状态是否恢复 |

每 4 小时记录一次，夜间若安稳睡眠可不叫醒测量，以观察呼吸与状态为主。

## 七、明确不做的事

- 不给 3 个月以下婴儿自行使用退热药
- 不自行决定药物种类、剂量、间隔与交替方案
- 不以体温数字作为唯一判断依据
- 不在孩子明显不适时坚持「扛一扛」
- 不因为退热后精神好转就忽略反复发热超过 3 天
