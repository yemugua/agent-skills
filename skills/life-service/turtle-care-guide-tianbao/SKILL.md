# 乌龟饲养（turtle-care-guide）

乌龟养不好，**很少是喂错一次，基本是环境没搭对**：没晒台、水太深或太浅、温度长期偏低、以及最致命的一条——**让本不该冬眠的龟去冬眠**。

这个技能做三件事：**搭环境 → 定喂养 → 判冬眠**。

---

## 一、硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出水龟、半水龟的环境参数与设备配置 | ❌ 给出任何药物的名称、剂量与疗程 |
| 给出按背甲长度换算的水深与晒台口径 | ❌ 判断龟患的是什么病，给出治疗方案 |
| 给出冬眠的条件筛查清单与控温区间 | ❌ 建议巴西龟等外来龟种放生到野外水体 |
| 给出投喂频次、单次量与禁忌食物表 | ❌ 承诺任何饲养结果，尤其冬眠存活率 |
| 给出必须停止自行处理联系专业人员的判断线 | ❌ 指导龟的繁殖、孵化与性别处理操作 |

**必须停止自行处理，联系爬行动物兽医或专业机构的情况**

- 张嘴呼吸、呼吸时有声、口鼻有分泌物、侧浮或沉不下水
- 眼肿、睁不开眼、壳出现软化、腐烂、出血或异味
- 拒食超过一周（非冬眠期），或冬眠中体重下降明显
- 四肢肿胀、行动失衡、长时间瘫软不动
- 误食异物、误接触清洁剂或其他化学品

> 另有一条硬红线：**巴西龟等外来龟种不得放生到野外水体**。民间放生的存活率极低，且会对本地物种造成影响。不想养时请联系专业机构接收。

## 三、完整工作流

1. **先定种类**：水龟、半水龟还是陆龟。**这一步错了，后面全错**——三类对水陆比例、水深、湿度的要求完全不同。最常见的情况是把半水龟当水龟深水养。
2. **测背甲长度**：这是后面所有尺寸的换算基准。
3. **配水体与晒台**：按背甲长度算水深与晒台大小，保证龟能完全离水晒背。
4. **配温控与光照**：水温、晒背区温度、是否配备 UVB 光源，灯具更换周期。
5. **定喂养方案**：按阶段定频次、单次量、食物种类。
6. **排换水与清理**：换水频次、晒水要求、清理周期。
7. **判冬眠必要性**：先做条件筛查，不达标就不要冬眠，直接加温过冬。**这一条是龟冬季死亡的最主要原因。**
8. **做记录**：体重、进食、排泄、活动状态，冬眠期更要定期称重。
9. **核对**：用 `--file` 跑一遍配置，把碰红线和不达标项先排掉。

## 四、核心规则说明

**动手之前必须先读这两个文件，不要凭印象写：**

- `rules/饲养环境与设备配置.md` —— 水龟与半水龟的环境参数、背甲长度到水深的换算、晒台与光照配置
- `rules/投喂冬眠与就医判断.md` —— 投喂频次与禁忌食物、冬眠条件筛查与控温区间、体重记录要求、就医判断线

要点三条：

1. **晒台是硬需求，不是装饰**。水龟必须能完全离开水、把背甲晒干。长期泡在水里又晒不到背，壳和皮肤问题会接连出现。
2. ** UVB 是多数家庭的缺失项**。只在窗边晒太阳往往不够——**玻璃会遮挡大部分有效波段**。不足会体现在壳的发育上。
3. **冬眠不是省事的选项**。要不要冬眠取决于龟的体重、健康状态与你能提供的控温条件，**不是取决于季节**。条件不够就不要冬眠。

## 五、脚本用法

```
python scripts/turtle_care_check.py --selftest
python scripts/turtle_care_check.py --file turtle.json
```

输入字段：

| 字段 | 说明 | 示例 |
|---|---|---|
| species_type | 种类 | 「水龟」「半水龟」「陆龟」 |
| carapace_cm | 背甲长度厘米 | 8 |
| water_depth_cm | 水深厘米 | 15 |
| basking_exists | 是否有完全离水的晒台 | true |
| basking_temp_c | 晒背区温度摄氏度 | 32 |
| water_temp_c | 水温摄氏度 | 26 |
| uvb_provided | 是否配备 UVB 光源 | true |
| uvb_age_months | 灯具已用月数数 | 8 |
| feed_times_per_week | 每周投喂次数 | 3 |
| food_items | 食物列表 | 「龟粮」「小鱼」 |
| hibernate | 是否计划冬眠 | false |
| hibernate_temp_c | 冬眠控温摄氏度 | 7 |
| weight_checked | 是否定期称重记录 | true |
| steps | 环境布置操作顺序列表 | 见规则文件 |

结论分三档：**先处理**（缺少硬需求、温度超标、食物禁忌、冬眠条件不满足）、**待确认**（信息不足）、**可照此执行**。存在真实缺陷时即使信息也不完整仍判先处理。

结果写入 `scripts/_last_result.txt`，每条不合格带原因。

## 六、人工确认清单（这步不能省）

- [ ] 已确认种类，环境的配置是按这个种类取的
- [ ] 龟能随时走到晒台上，**完全离开水**并把背甲晒干
- [ ] 晒台表面不会太烫（烫伤是常见事故），且有坡度方便攀爬
- [ ] 水温、晒背区温度在适用区间
- [ ] UVB 光源已配备，且没有超过更换周期
- [ ] 水深按背甲长度换算，且龟苗一定有浅水区
- [ ] 投喂频次与单次量符合该阶段口径
- [ ] 食物清单里没有任何禁忌项
- [ ] 若计划冬眠，条件筛查六项全部通过，且已明确控温手段
- [ ] 体重有记录，且知道自己的龟的正常体重范围

## 七、最常见的坑

1. **没有晒台，或晒台够不着**。龟长期泡水里，背甲晒不干，壳的问题很快就来。
2. **隔着玻璃晒太阳当补充光照**。玻璃会遮挡大部分有效波段，等于白晒。
3. **让龟苗冬眠**。龟苗体能储备不足，冬眠死亡率高，应当加温过冬。
4. **冬眠温度控制不住**。低于 2 摄氏度有冻伤与死亡风险，高于 15 摄氏度龟一直在消耗却吃不进东西，两头都危险。
5. **喂火腿肠、面包屑、咸味零食**。高盐高添加物的加工食品对龟是明显的负担，这是最常见的日常错误。
6. **一次喂一大把**。龟看起来一直在找吃的，很容易投多。单次量以头部体积为参照。
7. **换水全用刚接的自来水**。应晒过或做除氯处理。
8. **不想养了就放生**。外来龟种放生到野外基本活不了，还会影响本地物种，请联系机构接收。
9. **从不称重**。体重是判断龟健康趋势最直观的指标，尤其冬眠期间。**没有记录就看不出它在掉秤。**
