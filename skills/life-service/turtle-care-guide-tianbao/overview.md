# 乌龟饲养（乌龟饲养 / turtle-care-guide）

你会得到什么：一份按龟种（水龟 / 半水龟 / 陆龟）落地的饲养环境与管理方案——水深按背甲长度换算、晒台与 UVB 的硬性配置口径、投喂频次与禁忌食物表、冬眠前的六项条件筛查与控温区间，以及一份「什么时候必须停手联系爬行动物兽医」的就医判断清单。技能内置 `turtle_care_check.py`，把你的配置写成 JSON 跑一遍，自动标出缺晒台、水深越界、禁忌食物、龟苗冬眠、冬眠控温超标、操作顺序错误等不合格项并附原因。

典型用法：刚接回一只巴西龟不知道水深放多少；龟苗能不能冬眠拿不准；晒背灯用了一年多要不要换；喂了火腿肠要不要紧。把这些写成字段交給脚本，立刻拿到「先处理 / 待确认 / 可照此执行」的结论。

边界：本技能只做家庭饲养的环境与管理口径，**不诊断疾病、不开药、不给剂量**，也不指导繁殖与放生（外来龟种尤其禁止放生）。龟出现张嘴呼吸、拒食超一周、壳软化出血等情况，请直接联系专业爬行动物兽医。
