# 夜景拍摄（night-scene-photography）

夜景的三件事有先后顺序：**先解决糊，再解决噪，最后解决光。**

顺序不能倒。一张清晰但有噪点的照片还能看；一张噪点很少但糊掉的照片只能删。

这个技能做三件事：**算安全快门 → 定 ISO → 控曝光**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 算安全快门、核 ISO 上限与曝光补偿 | ❌ 检测或修复设备的硬件故障 |
| 给出手持与三脚架两套操作流程 | ❌ 提供后期降噪、堆栈、合成的具体操作 |
| 说明题材曝光时长参考 | ❌ 指导天文摄影的赤道仪、追踪等专业器材使用 |
| 判定闪光灯与曝光补偿是否用错 | ❌ 替代摄影师在现场的取景与判断 |

**遇到以下情况，按各自渠道处理：**

- 相机/手机出现**对焦失败、快门按不下、画面异常条纹** → 属设备故障，走售后或维修
- 需要**后期降噪、多张堆栈、曝光合成** → 不在本技能范围
- 涉及**他人肖像**的照片 → 发布前应取得本人同意
- 各机型可调参数、夜景模式算法、RAW 支持差异很大 → 以自己设备的官方说明为准

**安全提示**：夜间外出拍摄请注意人身与财物安全，**不要为了取景进入危险区域、禁止进入的场所或影响交通安全的位置**。

## 二、完整工作流

### 第一步：算安全快门（这一步先做）

**安全快门 = 1 ÷（等效焦距 × 裁切系数）**

| 等效焦距 | 全幅（系数 1.0） | 半幅（系数 1.5） |
|---|---|---|
| 24mm | 约 1/24 秒 | 约 1/36 秒 |
| 50mm | 约 1/50 秒 | 约 1/75 秒 |
| 85mm | 约 1/85 秒 | 约 1/128 秒 |

**手持时，快门时间必须不长于这个值。** 想要 1 秒、5 秒、30 秒的曝光，就必须上三脚架。

**防抖能救一两挡，救不了十倍。**

### 第二步：定 ISO（不越过上限）

| 设备 | 建议上限 |
|---|---|
| 手机 | 3200 |
| 相机（半幅） | 3200 |
| 相机（全幅） | 6400 |

**降噪的正确路径是「用三脚架换长曝光」，不是「把 ISO 降下来硬扛」。**

### 第三步：手持还是三脚架

**手持流程**（详见规则文件）：开夜景模式 → 定 ISO 上限 → 确认快门短于安全快门 → 找依托 → 对焦亮部边缘 → 连拍 3 到 5 张 → 用音量键或定时按快门。

**三脚架流程**：架稳 → 关光学防抖 → ISO 压到 100 到 400 → 光圈 f/8 到 f/11 → 手动对焦到亮部 → 曝光补偿负 0.7 → **用 2 秒定时或快门线** → 拍 RAW。

### 第四步：控制曝光

**曝光补偿压在负 1.0 到 0。** 夜景画面大部分是黑的，测光系统想把它提到中性灰，结果就是灯牌和天空溢出成死白。

**原则：宁可稍欠，不可过曝。** 高光溢出不可逆，暗部欠一挡在 RAW 里还有救。

### 第五步：填 JSON 跑自查

把每张的焦距、快门、ISO、支撑方式、曝光补偿填进去，脚本一次给出逐张判定与整改顺序。

## 三、核心规则（生成结论前先读规则文件）

**必须先读 `rules/夜景参数与拍摄步骤.md`，不要凭印象写。** 规则文件里有：

- 三阶段优先级（先不糊、再不噪、再有光）与理由
- 安全快门表（24/35/50/85mm × 全幅/半幅）
- ISO 上限表与超过之后的后果
- 曝光补偿三档后果对照
- 手持与三脚架两套完整流程
- 五种题材的曝光时长参考（城市夜景、车流光轨、水面倒影、星空、手持）
- 闪光灯为什么不能开（三个后果）
- 判定顺序说明与八条高频坑

**判定顺序不能颠倒**：先看严重项（快门超过手持极限、ISO 超上限、开了闪光灯），再看可改进项，最后才看信息是否完整。

**为什么这条重要**：若先判信息完整度，会出现「ISO 已经拉到 12800，却因为没填曝光补偿而被判成待确认」——把问题说轻了，比漏判更糟。

## 四、参数速查

| 项目 | 合格口径 | 严重度 |
|---|---|---|
| 安全快门 | 手持快门不长于 1 ÷（焦距 × 裁切系数） | 严重 |
| ISO | 手机/半幅不高于 3200，全幅不高于 6400 | 严重 |
| 闪光灯 | 必须关闭 | 严重 |
| 曝光补偿 | 负 1.0 到 0（低于负 2.0 欠曝，高于正 0.3 溢出） | 可改进 |
| 夜景模式 | 手机手持必须开 | 可改进 |
| RAW | 建议拍 RAW 给后期留空间 | 可改进 |
| 按快门方式 | 三脚架必须用定时或快门线 | 可改进 |
| 三脚架 ISO | 已上三脚架且长曝光时，ISO 应压到 400 以下 | 可改进 |

## 五、脚本用法

```bash
python scripts/night_shot_check.py --file night.json --out 夜景核查.md
python scripts/night_shot_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`shots` 为照片列表，每张填 `device` / `support` / `focal_mm` / `shutter_s` / `iso` 等 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检（53 条断言，含 BOM 两条路径） |

输入 JSON 示例：

```json
{
  "shots": [
    {
      "name": "江边夜景",
      "device": "full",
      "support": "tripod",
      "focal_mm": 24,
      "crop": 1.0,
      "shutter_s": 5.0,
      "iso": 200,
      "ev": -0.7,
      "flash": false,
      "raw": true,
      "timer_or_remote": true,
      "subject": "city"
    }
  ]
}
```

可选枚举：`device` 取 `phone` / `aps_c` / `full`；
`support` 取 `tripod` / `rest` / `handheld`；
`subject` 取 `city` / `trail` / `water` / `star` / `handheld`。
数值字段：`focal_mm`（等效焦距）、`crop`（裁切系数，默认 1.0）、`shutter_s`（快门秒数）、`iso`、`ev`（曝光补偿）；
布尔字段：`flash`、`night_mode`、`raw`、`timer_or_remote`。

脚本输出：总体判定、逐张判定表（含安全快门计算与不合格原因的 why）、整改顺序、ISO 上限表、题材曝光时长参考、阈值表、人工确认清单。

## 六、人工确认清单（这步不能省）

- [ ] 已算安全快门，手持曝光不长于该值
- [ ] ISO 未超过设备建议上限
- [ ] 闪光灯已关闭
- [ ] 曝光补偿压在负 1.0 到 0
- [ ] 三脚架时用了 2 秒定时或快门线

- [ ] 夜间拍摄地点安全，没有进入禁止区域或影响交通的位置

## 七、最常见的坑

**坑一：手持想拍 2 秒曝光。**
错误做法：手持举着手机，开了专业模式把快门调到 2 秒。正确做法：24mm 的手持安全快门只有约 1/24 秒，**差了几十倍**，怎么防抖都没用。要么上三脚架，要么提 ISO 把快门压回来。

**坑二：把 ISO 拉到手机最高。**
错误做法：ISO 拉到 6400 甚至 12800，觉得亮就行。正确做法：手机上限 3200。**超过之后降噪算法会强力涂抹**，建筑边缘发糊、细节变成色块、天空出现彩色噪点。正确路径是三脚架换长曝光。

**坑三：拍夜景开闪光灯。**
错误做法：觉得太黑，开闪光灯补光。正确做法：**关掉**。闪光只照亮 2 到 5 米，近处死白、远处依然黑、暖色氛围被冷白光压掉。需要照亮近处主体时用常亮光（路灯、店铺灯光），不要用闪光。

**坑四：夜景加曝光补偿想亮一点。**
错误做法：觉得画面太暗，加正 1 挡。正确做法：**压到负 1.0 到 0**。加曝光会让灯牌、霓虹、天空的高光溢出成死白，**且后期拉不回来**。宁可稍欠不可过曝。

**坑五：三脚架上用手直接按快门。**
错误做法：架好三脚架，伸手按下快门。正确做法：**用 2 秒定时或快门线**。按下那一下的抖动就够毁掉几秒的长曝光。

**坑六：三脚架上没关镜头防抖。**
错误做法：上了三脚架，防抖开关还开着。正确做法：**关掉**。防抖机构在无抖动时空转，反而制造抖动。

**坑七：自动对焦在纯黑区域拉风箱。**
错误做法：对着夜空对焦，对焦框来回跑对不上。正确做法：**点选灯牌边缘或建筑轮廓**，或者放大手动对焦，对好后锁焦。

**坑八：只拍一张就走。**
错误做法：拍一张觉得差不多就收工。正确做法：**连拍 3 到 5 张**。手持夜景总有抖的，多拍几张回家挑最清晰的那张，成本远低于重跑一趟。
