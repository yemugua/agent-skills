# 跑弦处置与练习校正

## 一、跑弦的原因判定顺序

| 现象 | 优先怀疑 | 处置 |
|---|---|---|
| 定完立刻就跑 | 新弦未拉伸到位 | 反复拉响并轻压弦身帮助延展，重定 2-3 天 |
| 拧了轴但音不动，或一松手就回 | 琴轴打滑 | 退弦取轴检查轴与孔配合，找琴师处理 |
| 拉几分钟整体走低 | 温度上升或琴体受力变化 | 等琴体稳定后重定，演出前提前 30 分钟定弦 |
| 只有一根弦跑 | 该弦起毛、缠弦松脱或轴孔磨损 | 换弦，仍跑则查轴 |
| 千斤位置缓慢下移 | 千斤绑扎不牢 | 重新绑扎，不要靠反复定弦掩盖 |
| 换季后整体音准漂移 | 温湿度影响蟒皮与弦 | 换季必做一次完整复校 |

**禁止的处置方式**：往轴孔滴胶水、缠胶带、垫纸片、用钳子硬扳。这些做法会扩大轴孔损伤，后续维修成本更高。

## 二、琴轴打滑的处置顺序

1. 先松弦，把弦从轴上完全退出，取下琴轴。
2. 看轴杆与轴孔的磨损情况：轴杆磨出亮痕、轴孔呈椭圆或有裂纹，属于需要琴师处理的情形。
3. 轻微打滑可尝试：把轴稍微往里推紧再边推边拧，增大配合面摩擦；涂抹少量专用的弦轴蜡或松香粉增加阻尼。
4. 上述方法无效，或轴孔已明显变大，停止自行处理，送修。
5. 不要靠「多缠几圈弦」临时解决，缠太多会改变有效弦长与受力，音准反而更差。

## 三、每日练习的音准校正流程（约 20 分钟）

| 环节 | 时长 | 做法 |
|---|---|---|
| 定弦与复检 | 3 分钟 | 定基准弦、纯五度定另一根、回校两轮、泛音校验一次 |
| 空弦长音 | 3 分钟 | 内外弦各拉 4 个长音，确认发音稳定、无沙音 |
| 逐指对照 | 6 分钟 | 按指距表逐指按弦，每音对一次校音器 |
| 音阶慢练 | 5 分钟 | D 调一个八度上下行，速度控制在能听清每个音 |
| 换把对照 | 3 分钟 | 换到第二把位，重做空弦与泛音对照 |

## 四、练习中的判断原则

- **宁慢勿快**：慢练时音不准，快练只会把错误固化。
- **先听后看**：先用耳朵判断偏高偏低，再看校音器验证，不要全程盯着数字。
- **偏差方向要记录**：同一个指头反复偏高或偏低，是手型问题不是耳朵问题，要改按弦角度而不是多听。
- **换把必复检**：换把后音准整体偏移是普遍现象，换完把先对空弦再继续。
- **连续两周无明显改善**：考虑找老师当面校正手型，不要自己硬练。

## 五、校音器使用的注意点

| 注意点 | 说明 |
|---|---|
| 用麦克风模式 | 拾音模式会混入琴体传导的杂音 |
| 避开环境噪声 | 空调、电视、人声都会干扰识别 |
| 拉长弓中速 | 太短促或太弱，识别会跳数 |
| 靠近琴码发音 | 音色集中，识别更稳 |
| 识别到的是「最近的音名」 | 偏差超过 50 音分时显示可能跳到相邻音名，要看音分数值不要只看音名 |
