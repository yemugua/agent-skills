# 二胡定弦

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 给出各调定弦的目标频率与五度校验口径 | 声称不看频率纯靠耳朵就能一次性定准 |
| 说明拧弦方向、千斤高度、琴码位置的检查口径 | 指导自行拆琴、换蟒皮、削琴码、改动琴筒结构 |
| 给出把位指距与音准校正的练习方法 | 承诺练几天就能解决所有音准问题 |
| 提示跑弦、琴轴打滑、弦老化的处置顺序 | 建议用胶水、502、缠胶带等方式固定琴轴 |
| 输出定弦步骤、偏差音分判定和自查表 | 把「音不准」简单归因于天赋或手小 |

**必须交给专业人士（琴师 / 制琴师 / 乐器维修）的情况**

- 琴轴严重打滑、开裂、轴孔磨大，拧了也定不住
- 琴杆弯曲、千斤断裂、琴筒脱胶、蟒皮破损或塌陷
- 琴码开裂、琴弦起毛或锈蚀严重
- 音准在反复校准后仍无法稳定，怀疑琴体本身问题

## 三、完整工作流

1. **先确认用的是哪套定弦**：标准 D/A（内 d1、外 a1）是最常用的一套；低五度 G/D 用于《二泉映月》一类曲目；C/G 用于部分现代作品与乐队配合。先确认再定，不要拿标准音去定低五度曲子。
2. **确定基准音**：先定外弦（上轴为内弦、下轴为外弦，不同琴有差异，先认清自己的琴）。外弦定到 a1 = 440 Hz（乐队合奏若用 442 Hz 则跟乐队走）。用长弓、中速、靠近琴码的弓段发音，校音器用麦克风模式、避开环境噪声。
3. **用纯五度定内弦**：内弦按纯五度关系降到 d1 = 293.66 Hz。纯五度频率比为 3:2，不是十二平均律的五度（2 的 7/12 次方）。听感校验用泛音法：轻触内弦弦长三分之一处得到的泛音，应与外弦空弦同高。
4. **回校与复检**：内弦定完后外弦会被牵动，必须回校外弦再复检五度，来回两到三轮。
5. **查硬件**：千斤高度、琴码是否居中、琴轴是否打滑、弦是否起毛。千斤或琴码不对，音准与音色都不可能稳定。
6. **音准校正训练**：按 `rules/定弦标准与音准校正.md` 的把位指距表，用空弦与泛音做对照音，逐指核对。
7. **稳定性测试**：定完弦拉满 10 分钟再测一次，偏差超过 15 音分说明弦或轴有问题，先处理硬件再谈音准。

## 四、核心规则与要件库

生成定弦步骤或音准建议前，**必须先读**：

- `rules/定弦标准与音准校正.md`：各调定弦频率表、五度校验口径、千斤琴码规格、把位指距与音准校正法。
- `rules/跑弦处置与练习校正.md`：琴轴打滑、新弦跑音、温湿度影响、每日练习校正流程。

不得把「纯五度」与「平均律五度」混为一谈：两者相差约 2 音分，单听差异小，但对二胡这种持续按弦的乐器，长期按平均律定会越听越别扭。不得建议用胶水或胶带固定琴轴，这类做法会毁掉轴孔。

## 五、脚本用法

```
python scripts/erhu_tuning_check.py --file case.json
python scripts/erhu_tuning_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：定弦方案、内外弦实测频率、是否跑弦、温度、千斤高度 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--json` | 以 JSON 输出 |
| `--selftest` | 运行自检 |

脚本输出内外弦各自的偏差音分、五度偏差音分、总判定（合格 / 需微调 / 不合格）、拧弦方向和待处理项。**判定顺序是先查真实缺陷（弦序颠倒、五度超差、跑弦、千斤越界），再看信息是否完整**，信息不全只会被记为「待确认」，不会因为缺字段就掩盖已查出的偏差。

## 六、人工确认清单

- [ ] 已确认本曲用的是哪套定弦，没有拿标准音去定低五度曲目
- [ ] 外弦定为基准，内弦按纯五度定，定完回校外弦至少两轮
- [ ] 泛音法校验过一次五度，不只看校音器数字
- [ ] 千斤高度在 38-42 厘米范围且与臂长匹配
- [ ] 琴码居中、无开裂，琴弦无起毛
- [ ] 定完拉满 10 分钟复测，偏差在 15 音分以内
- [ ] 琴轴不打滑；打滑已先处理，没有用胶水或胶带临时固定
- [ ] 温度骤变或换季时已重新校准

## 七、最常见的坑

1. **拿平均律五度当纯五度**：校音器上五度显示 0 音分并不代表纯五度，平均律五度比纯五度窄约 2 音分，长音持续时会听出闷和发紧。
2. **只定一遍不复检**：拧紧内弦会牵动琴杆与蟒皮受力，外弦必然被带偏，必须来回校两到三轮。
3. **新弦装上就上台**：新弦需要反复拉伸与重定 2-3 天才能稳定，上台前至少提前一天换弦。
4. **千斤位置凭手感**：千斤过高音域够但按弦吃力、偏低则音色发闷且把位挤，38-42 厘米是成人常用范围，儿童琴要相应缩短。
5. **琴轴打滑就拼命拧**：越拧轴孔磨损越快，正确做法是退弦检查轴与孔配合，找琴师处理。
6. **音不准只怪耳朵**：二指偏高、三指半音按宽是普遍问题，要用空弦与泛音做对照音逐个校准，不是靠多听就能改。
7. **低温环境直接演奏**：从冷环境进热房间，弦与蟒皮都会变，要等 15-30 分钟再定弦。
8. **把弓毛松紧当音准问题**：弓毛太松发音虚、音高感觉不稳，先确认弓压再怀疑音准。

## 八、边界与免责

本技能提供二胡定弦的频率参考、五度校验口径、硬件检查标准和音准练习方法，不构成乐器维修或演奏水平评价。不同琴、不同弦、不同演奏环境的实际取值存在差异，合奏时以乐队基准音为准，独奏曲目以该曲要求的定弦为准。涉及琴体、琴轴、蟒皮的实质性改动，请交给制琴师或乐器维修人员处理。
