# 简易注销进度查询

## 场景
处理"简易注销"事务中的"进度查询"环节，面向首次办理、被拒补正、异地/代办三类人群。

## 办理渠道
1. 线上：当地政务服务网/APP、交管12123（涉车驾事项）、电子营业执照小程序（涉市场主体事项）、12333（涉就业事项）。
2. 线下：对应主管部门窗口（运管/人社/市场监管/住建/燃气公司营业厅等）。
3. 热线：12345 总机（可转接各主管部门并投诉）。

## 通用材料清单
- 身份证原件及复印件
- 申请表（签名与证件一致）
- 佐证材料：按事项提供（权属/合同/票据/鉴定/认定书等）
- 委托办理：委托书+双方身份证复印件（部分事项需公证）

## 办理流程
1. 预约或线上提交 → 2. 窗口受理（缺件一次性告知，索要《补正通知书》）→ 3. 缴费（索取票据）→ 4. 领取结果（电子证照同效）。

## 时限与费用
- 以受理回执标注的法定时限为准；超期凭受理编号向 12345 催办。
- 行政服务类收费须有公开依据，"加急费"可拒付举报。

## 常见驳回原因
1. 材料过期（证明类多为 90 天有效）
2. 影像不清/复印件未签注"与原件一致"
3. 前置条件缺失（未年审/未备案/未缴清费用）
4. 信息不一致（曾用名、证件升位、户名不符）

## 申诉与维权
- 驳回有异议：索要书面凭证 → 行政复议（60日内）/行政诉讼（6个月内）。
- 乱收费、推诿：12345、12388 实名举报。
