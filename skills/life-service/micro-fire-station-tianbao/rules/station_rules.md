# 微型消防站规则库（station_rules）

> 本文件是 micro-fire-station 技能的规则支撑。引用条款以现行有效文本为准。

## 一、法规依据速查

| 文件 | 关键要求 | 关联 |
|---|---|---|
| 《中华人民共和国消防法》 | 单位消防组织、志愿消防队 | 建站法源 |
| 《消防安全重点单位微型消防站建设指导意见》 | 重点单位建站要求、人员装备值守训练口径 | 建设标准直接依据 |
| 当地消防救援机构规定 | 站点、值守、调度具体要求 | 属地口径 |

## 二、建设标准要点

1. 设置范围：消防安全重点单位应建；其他单位鼓励组建
2. 站点：便于出动，与消防控制室统筹；有条件的配消防车辆/消防摩托
3. 值守：分班次值守，火警即时响应（班次以当地要求为准）
4. 调度：与消防控制室联通，纳入区域联防联动

## 三、人员配置检查口径

| 项目 | 口径 | 脚本判定 |
|---|---|---|
| 人员数量 | ≥ 6 人 | 人数不足 FAIL |
| 持证 | 操作设施人员持消防设施操作员证 | 无证 WARN |
| 负责人 | 站长明确 | 未明确 WARN |
| 培训 | 上岗培训 + 复训记录 | 缺记录 WARN |

## 四、装备清单检查口径

| 类别 | 必配项 |
|---|---|
| 灭火器材 | 灭火器、灭火毯、水带水枪 |
| 破拆救生 | 消防斧、应急照明、逃生绳（高层） |
| 个人防护 | 防护服、头盔、腰带、手套 |
| 通信指挥 | 对讲机、预案卡、站点图 |
| 运输工具 | 消防车辆/摩托（有条件的） |

## 五、日常管理检查口径

| 事项 | 频次下限 | 脚本判定 |
|---|---|---|
| 值守排班 | 连续无断档 | 断档 FAIL |
| 技能训练 | 每月 ≥ 1 次 | 缺月 WARN |
| 演练 | 每季度 ≥ 1 次 | 缺季 WARN |
| 出动记录 | 每次留痕 | 缺记录 WARN |
| 装备维护 | 定期检查 | 无维护记录 WARN |

## 六、常见不达标情形

- 挂名人员、无证操作
- 装备配而不维护、过期失效
- 排班表与实到不符
- 训练只跑步不练器材
- 出动无记录、无总结
