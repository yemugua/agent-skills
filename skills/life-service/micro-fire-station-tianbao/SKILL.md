# 微型消防站建设与管理（micro-fire-station）

微型消防站是重点单位的**第一出动力量**：火警响起到场 3 分钟，靠的不是运气，是站里有人、有装备、练过。

这个技能做四件事：**定标准** → **配人员** → **配装备** → **管日常**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 讲解建设标准与管理方法 | ❌ 替代法定建设与监管要求 |
| 生成核对清单与台账模板 | ❌ 保证灭火救援效果 |
| 整理训练与值守制度要点 | ❌ 替代消防救援队伍职责 |

**遇到真实火警，微型消防站力量只承担初起火灾扑救与疏散引导；火势超出控制能力时，第一时间拨打 119 并撤离，不得盲目硬拼。**

**永远不要**为了应付检查把装备堆在库里不维护、训练记录全靠补——真出事时这些都是摆设。

## 二、完整工作流

```
第 1 步  明确场景：新建站 / 达标核对 / 台账补全 / 迎检
第 2 步  读规则文件 rules/station_rules.md
第 3 步  按场景取用：
    - 定标准 → 建设要点（第三节）
    - 配人员 → 人员与证书（第四节）
    - 配装备 → 装备清单（第五节）
    - 管日常 → 值守/训练/联动（第六节）
    - 体检表 → python scripts/micro_station_check.py --file 微型站.json
第 4 步  按 templates/微型消防站台账.md 输出
第 5 步  人工确认：人员排班真实性、装备维护状态
```

---

## 三、建设要点

1. **设置范围**：消防安全重点单位应建微型消防站；其他单位鼓励组建（通行口径，以现行规定为准）。
2. **站点设置**：值守点应便于出动，与消防控制室统筹设置；有条件的配备消防车辆或消防摩托。
3. **值守要求**：重点单位微型消防站一般实行分班次值守，确保火警时能第一时间响应；具体班次**以当地消防救援机构要求为准**。
4. **调度联动**：与消防控制室、本单位志愿消防队伍联通，纳入区域联防联动，接受消防救援机构调度。

---

## 四、人员与证书

| 项目 | 通行口径 |
|---|---|
| 人员数量 | 不少于 6 人（由单位员工组成，消防控制室值班人员可纳入） |
| 负责人 | 明确站长，一般由消防安全管理人兼任或指定 |
| 持证要求 | 操作消防设施的人员应持消防设施操作员职业资格证书 |
| 培训 | 上岗前培训 + 定期复训，内容含灭火器材、防护装备、疏散引导 |

---

## 五、装备配置清单（核对用）

| 类别 | 常见配置 |
|---|---|
| 灭火器材 | 灭火器（按配置设计另计）、灭火毯、消防水带水枪 |
| 破拆救生 | 消防斧、断线钳、应急照明、逃生绳、缓降器（高层） |
| 个人防护 | 灭火防护服、头盔、腰带、消防靴、手套、呼吸器（按能力配置） |
| 通信指挥 | 对讲机、电话、站点平面图、预案卡 |
| 运输工具 | 消防车辆/消防摩托（有条件的） |

> 装备**按本单位火灾风险配置**；配了就得上账、定期维护，过期失效及时更换。

---

## 六、日常管理四条线

1. **值守**：排班表上墙，交接班有记录，控制室与站点通讯畅通
2. **训练**：每月至少一次技能/体能训练，每季度至少一次实战或桌面演练
3. **巡查联动**：与防火巡查结合，发现隐患直报消防安全管理人
4. **出动记录**：每次出动、训练、维护都留记录，年底有总结

---

## 七、脚本用法（建设核对）

```bash
python scripts/micro_station_check.py --file "D:\消防\微型站.json"
```

脚本检查五类问题：**人员数量与持证缺口、装备清单覆盖缺口、值守排班断档、训练演练频次不足、出动/维护记录缺失**。

> ⚠️ 脚本只做结构与逻辑检查，**不判定实际作战能力**。

---

## 八、人工确认（这步不能省）

- [ ] 人员是否为真实在岗，不是挂名凑数
- [ ] 装备是否在有效期内、放置位置是否好取用
- [ ] 值守人员是否熟悉本单位预案与出动路线
- [ ] 与消防救援机构/区域联防的联动渠道是否畅通
- [ ] 训练内容是否覆盖本单位主要风险

---

## 九、输出结构（固定三段）

1. **能不能过关**——结论先行：达标 / 有缺口 / 有红线问题
2. **核对清单**——逐项标合规/缺失/存疑
3. **整改与补资料建议**——先后顺序、责任岗位、留存材料

---

## 十、最常见的坑

**坑一：挂名站。** 名单上 8 个人，实际 2 个还都是兼职。

**坑二：装备只配不管。** 灭火器过期、水带霉变、对讲机没电，比不配更危险。

**坑三：值守形同虚设。** 排班表漂亮，火警时站点没人。

**坑四：训练就是跑步。** 不练器材操作、不练出水、不练疏散引导，真警时抓瞎。

**坑五：出动不记录。** 干了什么都说不清，迎检时全项存疑。
