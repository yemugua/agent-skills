# 各平台直播规则要点（方向）

> 平台规则频繁更新，以各平台"规则中心 / 电商创作者管理规则 / 社区公约"**实时内容**为准。本节给找入口与共性雷区。

## 一、共性雷区（各平台都禁）
- **违禁词/虚假宣传**：极限词、夸大功效、虚构数据。
- **类目准入**：未开通类目不得带货（尤其食品/医疗/金融）。
- **诱导站外**：引导加微信/QQ/第三方，绕过平台交易。
- **数据造假**：刷单、刷人气、虚假互动。
- **侵权**：未经授权使用他人品牌、音乐、肖像、视频。

## 二、平台入口（通用定位）
- 抖音：「我 → 创作者服务中心 / 电商带货 → 规则中心」
- 快手：「快手小店 / 快手电商 → 规则」
- 视频号：「视频号小店 / 创作者中心 → 规则」
- 淘宝直播：「淘宝直播中控台 / 规则」
- 搜索兜底：平台内搜"规则中心""违规""创作者管理"。

## 三、违规后果梯度
- 轻度：警告、限流、下架商品。
- 中度：冻结佣金、暂停带货权限。
- 重度：清退、列入黑名单、移交执法。

## 四、申诉
- 路径：规则中心 → 违规记录 → 提交申诉材料（录屏、授权、资质）。
- 关键：证据齐全、表述客观，不情绪化。

## 五、校验
- 大促/新类目前必看平台当期限定规则（如特殊品类临时管控）。
- 以官方规则中心文字为准，不听"群消息/小道消息"。
