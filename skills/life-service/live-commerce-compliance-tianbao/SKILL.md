# 直播带货合规避坑指南

> **5 句口诀**（3 秒判断要不要用我）：
> 1. 问题涉及**直播带货 / 短视频带货 / 主播话术 / 带货资质 / 税务** → 用我
> 2. 用户要**查什么词不能说、要办什么证、怎么交税、话术怎么审、被平台扣分怎么办** → 用我
> 3. 用户要**刷单、数据造假、规避监管、卖违禁品** → 拒绝，并说明原因
> 4. 涉及法规：只列**方向 + 法条类别**，不编具体条文编号，提示"以最新有效法律为准"
> 5. 平台规则只给**层级方向**，以各平台"规则中心 / 创作者管理规则"实际内容为准

## 一、这个技能解决什么

直播带货是"内容 + 电商 + 广告"三线交汇、监管最严的赛道之一。主播、商家、MCN 最容易踩的坑：
- **说错一个词**（极限词 / 虚假功效）被市场监管罚几十万；
- **卖特殊品类没资质**被封店；
- **税务不合规**（长期个人微信收公款不申报、虚开发票）被查。

本技能用「红线清单 + 资质地图 + 平台规则 + 话术审查」帮你**提前避坑**，不事后救火。

## 二、广告法红线（最核心，详见 references/01-ad-law.md）
- **绝对化用语**："最/第一/顶级/国家级/唯一/极致"等禁用（除非有确凿证据且法定允许）。
- **虚假功效**：食品、化妆品、保健品不得宣称医疗功效；普通商品不夸大。
- **对比贬低**：不得贬低其他生产经营者的商品或服务。
- **虚构数据**：销量、好评率、奖项、销量排名不得编造。
- **代言责任**：不得为未使用过的商品或未接受的服务作推荐、证明。

## 三、资质地图（详见 references/02-qualification.md）
- 基础：**营业执照**（个体户或公司）。
- 食品：食品经营许可 / 预包装备案；保健食品需专门资质。
- 医疗/药品/医疗器械/农药等：广告审查批准文件，极严，多数平台禁播。
- 特殊品类：珠宝玉石、二手、图书、跨境、酒类等各有准入要求。
- 主播：平台实名 + 资质认证；特定品类需额外证书。

## 四、税务合规（详见 references/03-tax.md）
- 主播/商家收入应按"经营所得"或"劳务报酬"依法申报，**别用个人微信长期收公款不申报**。
- **虚开发票**风险极高，绝对避免。
- 平台交易数据可追溯，税务部门可核查。

## 五、平台规则（详见 references/04-platform-rules.md）
- 抖音 / 快手 / 视频号 / 淘宝直播各有"电商创作者管理规则 / 社区公约"。
- 重点雷区：违禁词、类目准入、虚假宣传、诱导站外交易。
- 违规后果：警告 → 限流 → 下架 → 冻结佣金 → 清退。
- 申诉：规则中心 → 违规记录 → 申诉，留好证据。

## 六、话术审查清单（详见 references/05-script-review.md）
- 上线前逐条过：极限词、功效词、对比词、价格误导、诱导词、绝对承诺。

## 七、明确拒绝的
- 刷单、虚假交易、数据造假
- 规避监管、教"怎么绕开平台审核"
- 销售违禁品、假冒伪劣
- 提供"包过审/包不被罚"承诺
