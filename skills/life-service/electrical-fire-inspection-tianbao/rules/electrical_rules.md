# 电气防火检测规则库（electrical_rules）

> 本文件是 electrical-fire-inspection 技能的规则支撑。引用条款以现行有效文本为准。

## 一、法规依据速查

| 文件 | 关键要求 | 关联 |
|---|---|---|
| 《中华人民共和国消防法》 | 第十六条：按标准配置电气线路、定期检验维修 | 检测义务法源 |

## 二、周期判定口径

| 事项 | 下限 | 脚本判定 |
|---|---|---|
| 电气防火检测 | 每年 ≥ 1 次 | 距今天数 > 365 FAIL |
| 防雷防静电检测 | 每年 ≥ 1 次 | 同上 |
| 配电箱巡查 | 每周/每月按制度 | 断档 WARN |

## 三、必测部位清单

| 区域 | 部位 |
|---|---|
| 变配电室 | 变压器、开关柜、母线/电缆接头、补偿柜 |
| 配电线路 | 楼层配电箱、桥架接头、穿墙封堵 |
| 用电设备 | 大功率设备、电加热、广告照明、机房配电 |
| 照明插座 | 密闭灯具、插座回路、开关 |
| 接地 | 接地干线、重复接地、防静电接地 |

## 四、红外测温判据（简化口径）

- 三相接头温差异常偏大 → 接触不良嫌疑
- 温升显著超环境温度 → 列隐患
- 较历史数据持续上升 → 劣化趋势
- 巡查"烫手/变色/异味" → 不等报告，立即按隐患处置

## 五、隐患分级与整改

| 级别 | 情形 | 处置 |
|---|---|---|
| 立即整改 | 过热打火、绝缘焦糊、严重过负荷 | 停电/降荷 + 当日整改 |
| 限期整改 | 温升超限、接头松动、私拉乱接 | 定人定期 |
| 观察监控 | 温升临界、轻微老化 | 加密巡查复测 |

## 六、巡查要点清单

1. 配电箱：门锁完好、无私拉乱接、无可燃物、标识清晰
2. 插座开关：无破损、无超负荷（插排串插排）
3. 线路：无老化破损、无重压、无私接
4. 临时线：到期拆除
5. 大负荷设备：温度、气味、声响
6. 闭店后：非必要电源切断（消防电源除外）
