# 电气防火检测与线路巡查（electrical-fire-inspection）

电气火灾占火灾起数的头把交椅，而电气隐患**藏在墙里、藏在配电箱里、藏在没人看的插座上**。检测不是走形式，是把"看不见的热"找出来。

这个技能做四件事：**定周期** → **列部位** → **判温度** → **闭闭环**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 讲解检测项目与巡查方法 | ❌ 替代法定检测与专业机构结论 |
| 生成检测记录表与巡查清单 | ❌ 出具检测报告 |
| 整理隐患分级与整改口径 | ❌ 带电作业 |

**红外测温等带电检测必须由具备相应能力的人员、使用合格仪器进行；非专业人员不得打开配电箱、不得带电操作。**

**永远不要**把"测温正常"当"线路没问题"——绝缘老化、谐波超标、接地不良，红外是照不出来的。

## 二、完整工作流

```
第 1 步  明确场景：排年度检测计划 / 日常巡查 / 隐患整改 / 报告核查
第 2 步  读规则文件 rules/electrical_rules.md
第 3 步  按场景取用：
    - 定周期 → 周期红线（第三节）
    - 列部位 → 检测部位清单（第四节）
    - 判温度 → 红外判据（第五节）
    - 巡线路 → 巡查要点（第六节）
    - 体检表 → python scripts/electrical_check.py --file 电气检测.json
第 4 步  按 templates/电气防火检测记录表.md 输出
第 5 步  人工确认：机构能力、仪器校验、整改证据
```

## 三、周期红线

| 事项 | 通行口径 |
|---|---|
| 电气防火检测 | 每年至少一次；人员密集场所、大型商业等应每年检测 |
| 配电箱/线路巡查 | 纳入日常防火巡查，每周/每月按制度执行 |
| 红外测温 | 检测时全数测量；日常可对重点部位（大负荷接头）加密 |
| 防雷防静电检测 | 每年一次（有相关设施的） |

> 检测应由具备从业条件的消防技术服务机构实施；周期**以现行标准和当地消防救援机构要求为准**。

---

## 四、检测部位清单（核对用）

| 区域 | 必测部位 |
|---|---|
| 变配电室 | 变压器、高低压开关柜、母线接头、电缆接头、无功补偿柜 |
| 配电线路 | 各楼层配电箱、分配电箱、电缆桥架内接头、穿墙封堵 |
| 用电设备 | 大功率设备、电加热器具、广告照明、机房配电 |
| 照明与插座 | 筒灯射灯（尤其密闭灯具）、插座回路、开关 |
| 接地 | 接地干线、重复接地、防静电接地 |

---

## 五、红外测温判据（简化口径）

| 现象 | 判读 |
|---|---|
| 同一回路三相接头温差异常 | 三相中温差明显偏大的一相，重点怀疑接触不良 |
| 接头温度显著高于环境温度 | 温升越大风险越高，超限即列隐患 |
| 与历史数据对比持续上升 | 劣化趋势，提前安排检修 |
| 元器件整体发热 | 可能过负荷或内部故障 |

> 具体判据以检测标准和检测机构结论为准；巡查发现的"烫手、变色、异味"一律按隐患处置，不等检测报告。

---

## 六、线路巡查要点（每周/每月）

1. **配电箱**：门完好上锁、无私拉乱接、无可燃物堆积、标识清晰
2. **插座开关**：无破损、无过负荷使用（一个插座带一排大功率设备就是信号）
3. **线路**：无老化发硬、无鼠咬破损、无重物压迫、无私接
4. **临时线**：到期拆除，不"临时"变"永久"
5. **大负荷设备**：运行时间、表面温度、异常气味声响
6. **节假日/闭店后**：非必要电源应切断（冷库、消防电源除外）

---

## 七、脚本用法（检测记录体检）

```bash
python scripts/electrical_check.py --file "D:\消防\电气检测.json"
```

脚本检查五类问题：**部位覆盖缺口、测温异常未处置、隐患整改无闭环、周期超期、巡查记录断档**。

> ⚠️ 脚本只做结构与逻辑检查，**不判定电气安全状态**。

---

## 八、人工确认（这步不能省）

- [ ] 检测机构是否具备从业条件、报告是否可查
- [ ] 红外仪器是否在校验有效期内
- [ ] 隐患整改是否有证据（紧固、更换、扩容记录）
- [ ] 大负荷回路是否核算过容量
- [ ] 装修施工临时用电是否有审批和巡查

---

## 九、输出结构（固定三段）

1. **能不能过关**——结论先行：覆盖齐全 / 有缺口 / 有红线问题
2. **核对清单**——逐项标合规/缺失/存疑
3. **整改与补资料建议**——先后顺序、责任岗位、留存材料

## 十、最常见的坑

**坑一：检测报告只测不变。** 年年测出同一批接头过热，没人紧固更换。

**坑二：一个插座带一圈设备。** 过负荷打火，插排连着插排。

**坑三：临时线不拆。** 施工结束半年，那根线还在墙外挂着。

**坑四：配电箱里堆杂物。** 纸箱、抹布、备用缆线，一起火就是助燃剂。

**坑五：只信红外。** 绝缘老化、谐波超标、接地不良，红外看不见。
