# 规则三：投诉阶梯、诉讼要点与时效

## 一、投诉阶梯（按顺序走，别跳级）

```
第 1 级  当面沟通 + 留痕          微信文字 / 录音 / 书面，留下"我说过了"
   ↓
第 2 级  物业 / 业委会           物业服务人负有劝阻、调解义务，要有记录
   ↓
第 3 级  社区居委会              基层群众性自治组织调解，调解记录很关键
   ↓
第 4 级  12345 市民热线           会派单到主管部门，务必拿工单编号
   ↓
第 5 级  主管部门执法            社会生活噪声→110 出警、可依法处罚
                                 建筑施工 / 工业噪声→生态环境部门查处
   ↓
第 6 级  人民法院诉讼             相邻关系 / 侵权责任，主张停止侵害、排除妨碍
```

**为什么不能跳级**：法院看的是"你有没有尽力主张过"。前几级的记录，既是证据，也是你"穷尽合理途径"的证明。

## 二、每一级怎么落地

| 级别 | 找谁 | 拿什么回来 |
|---|---|---|
| 1 | 噪声源一方（邻居 / 商户 / 装修业主） | 微信文字记录、当面沟通录音 |
| 2 | 物业服务人、业主委员会 | 报事记录、调解记录、回复截图 |
| 3 | 社区居委会、网格员 | 调解记录（能盖章最好） |
| 4 | 12345 热线（电话 / 小程序 / App） | **工单编号**、办结反馈 |
| 5 | 公安机关 / 生态环境主管部门 | 接处警记录、报警回执、责令改正文书 |
| 6 | 人民法院（被告住所地或侵权行为地） | 起诉状、证据清单、检测报告 |

## 三、报警时怎么说（要点）

- 明确报"**社会生活噪声**"，不是"邻居吵架"；
- 说清**地点（× 区 × 小区 × 栋 × 单元 × 室）**、**噪声类型**、**持续了多久**；
- 说清"**已经上门沟通过，没有效果**""**物业已调解无果**"；
- 说清"**我有录音和噪声记录**"；
- 出警后**索取接处警记录或报警回执**，记下警号与单位。

→ 社会生活噪声由公安机关依法处理，可以**警告、罚款**。

## 四、诉讼要点

1. **案由**：相邻关系纠纷，或者噪声污染责任纠纷（侵权责任）。
2. **诉讼请求**，按重要性排序：
   - **停止侵害**（禁止在 ×× 时段产生超过 ×× dB 的噪声）——这是**核心**；
   - **排除妨碍**（拆除加装设备、恢复原状）；
   - **赔偿损失**（检测费、医疗费、维权合理支出）；
   - 赔礼道歉；
   - 精神损害抚慰金——**一般难以支持**，不要把它当主要诉求。
3. **谁主张谁举证**：你得证明① 噪声存在 ② 超标或明显不合理 ③ 对方是噪声源 ④ 你受到了损害 ⑤ 因果关系。**检测报告是关键**。
4. **持续性侵害**：可以依法申请**行为保全**（诉前 / 诉中）与**先予执行**，要求先行停止噪声。
5. **诉讼时效**：普通诉讼时效期间为**三年**，自权利人知道或者应当知道权利受到损害以及义务人之日起计算（《民法典》关于诉讼时效的相关规定）。持续性侵权的起算有特殊性，**及早起诉，别拖**。
6. **调解**：相邻关系案件法院普遍先调解，调解不成再判；调解书同样可以申请强制执行。
7. **执行难**：判了不停的，可申请强制执行，并可请求对拒不履行者采取罚款、拘留等强制措施。

## 五、赔偿能要多少

- **检测费**、**公证费**、**合理维权支出**：有票据的，主张成功的可能性较高；
- **医疗费**：需要有就诊记录与医嘱，且与噪声的因果关系要能说明；
- **精神损害抚慰金**：仅在造成严重后果时才可能支持，一般噪声扰民案件**难以支持**；
- **房屋贬值损失、租房搬离费用**：需专门举证，法院自由裁量空间大。

→ 结论：**别盯着赔钱，重点是判"停止侵害"。**

## 六、纪律

- 本规则不预测诉讼胜负、不代写起诉状；
- 处罚幅度、执法流程、各地时限以当地主管部门口径为准；
- 是否构成侵权、是否支持赔偿，最终以司法机关认定为准。
