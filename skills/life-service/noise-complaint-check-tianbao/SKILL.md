# 噪音扰民取证与投诉

被噪声折磨的人，绝大多数卡在同一个地方：**投诉无果不是因为不管，是因为找错了部门、又没有证据**。本技能先判"这事归谁管"，再算"你的证据够不够"，最后给"下一步找谁、怎么说"。

## 什么时候用

- 楼上跑跳、拖家具、孩子蹦跳，沟通无效
- 邻居音响、K歌、宠物持续吠叫
- 小区外广场舞、商铺高音喇叭循环播放
- 住宅楼里周末/午间/夜间装修电钻敲打
- 工地夜间打桩浇筑、工厂风机冷却塔昼夜响
- 已经投诉过好几轮，没人管，想知道还能走哪一步
- 准备起诉，想知道证据够不够

## 怎么做

**第 1 步**：复制 `templates/噪音扰民信息采集表.md` 填写（填不出来就空着，不要编）。

**第 2 步**：跑脚本

```bash
python scripts/noise_check.py 采集表.md --base 2026-10-05 --out 核查报告.md
```

**第 3 步**：按第八段"待办补正动作"执行；第六段是可直接照读的话术。

## 先判归谁管（最关键的一步）

| 噪声类别 | 典型场景 | 主管部门 |
|---|---|---|
| **社会生活噪声** | 邻里生活、家庭音响乐器、宠物、广场舞、商铺喇叭、**住宅楼内室内装修** | **公安机关**（110 / 派出所） |
| **建筑施工噪声** | 工地打桩、浇筑、渣土车、夜间施工 | **生态环境主管部门** |
| **工业噪声** | 工厂车间、风机、冷却塔、生产设备 | **生态环境主管部门** |
| **交通运输噪声** | 道路车流、高架、铁路、地铁、飞机、"炸街" | 公安交管 / 铁路民航等按职责 |

→ 把"住宅楼里装修"当成工地施工去投诉环保部门，或者把"工地夜间施工"当成邻里纠纷打 110，都会被推回来。**先分对类，再投诉**。

## 三条最容易被忽略的规则

1. **夜间施工是禁的，但有例外**：噪声敏感建筑物集中区域，禁止夜间进行产生噪声的建筑施工作业；抢修、抢险作业和因生产工艺要求或特殊需要必须连续作业的除外，连续作业需取得证明并公告附近居民。
2. **手机分贝 APP 只能当初步证据**。执法与诉讼认的是有资质的检测机构按规范出具的检测报告，APP 读数的证明力有限，但它能支撑"我确实被吵到了"并推动出警与调解。
3. **"我投诉过"本身就是证据**。报警回执、12345 工单编号、物业调解记录，构成持续侵权的证据链——只打电话不留单，等于没投诉。

## 输入 / 输出

| | 内容 |
|---|---|
| 输入 | 采集表 Markdown（你的情况 / 噪声源 / 测量 / 证据 / 已采取措施 / 诉求） |
| 输出 | 九段报告：结论摘要 / 归哪个部门管 / 时段与限值对照 / 取证强度与缺口 / 投诉阶梯 / 话术卡 / 诉讼要点 / 待办 / 纪律 |
| 退出码 | 0 正常；2 关键信息缺失（给提示串，不崩） |

## 边界与纪律

- 依《中华人民共和国噪声污染防治法》、GB 3096《声环境质量标准》等**通用规则**整理，**不替代律师意见**
- **不认定违法、不预测处罚结果、不代写投诉与起诉文书**
- 声环境功能区类别、夜间时段起止、装修限时段、临时限额等**各地可另行划定并公告**，一律以当地主管部门口径为准
- **未填的一律不算通过**，只按填了的判断
