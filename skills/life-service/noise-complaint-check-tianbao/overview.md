# 概览：噪音扰民取证与投诉

## 解决什么问题

被噪声折磨的人，八成卡在三件事上：

1. **找错部门**——住宅楼里装修是社会生活噪声归公安，工地夜间施工归生态环境。打错电话，换来一句"不归我们管"；
2. **没有证据**——吵的时候没录，录了没有时间，有录音但没有连续记录，执法和法院都推不动；
3. **顺序错**——没沟通、没留痕就直接起诉，或者只打电话不留工单，事后证明不了"我投诉过"。

本技能把"归谁管 → 超没超标 → 证据缺什么 → 下一步找谁 → 怎么开口"一次算清楚。

## 输入 → 输出

```
采集表（噪声来源 / 时段 / 实测分贝 / 功能区类别 / 证据 / 已采取措施 / 诉求）
        │
        ▼
  ┌──────────────────┐
  │ 归口判定         │  社会生活→公安；施工/工业→生态环境；交通→交管
  ├──────────────────┤
  │ 时段 × 限值对照  │  GB 3096 昼/夜限值，夜间突发 +15 dB(A)
  ├──────────────────┤
  │ 取证强度评分     │  时间水印录音 / 噪声日记 / 检测报告 / 回执工单
  ├──────────────────┤
  │ 投诉阶梯排序     │  沟通→物业→社区→12345→110/环保→诉讼
  ├──────────────────┤
  │ 话术卡           │  对邻居 / 报警 / 12345 工单
  ├──────────────────┤
  │ 诉讼要点 + 待办  │  举证、行为保全、时效
  └──────────────────┘
```

## 和其他工具的区别

常见做法要么是"投诉电话列表"，要么是"噪声标准表格"。本技能做的是**个案判定**：

- 给的是"你这个噪声归谁管、证据差几项、下一步该找谁"，不是"噪声标准是多少"
- 归口、时段、限值、取证强度都是**可计算的判定逻辑**，不是查表
- 输出到"照着做、照着说"为止——话术段落可以直接念

## 不做的事

- 不认定对方违法、不预测会不会被处罚、不预测诉讼胜负
- 不内置任何城市的具体时段与限值时点，一律提示以当地公告为准
- 不代写投诉书、起诉状，不代办检测与公证

## 适用人群

被邻里或商铺噪声困扰的居民、被装修电钻折磨的业主、工地周边住户、物业与社区调解人员、准备起诉的当事人。
