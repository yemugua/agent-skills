# 入职引导（Onboarding）（onboarding）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：生成入职引导清单：入职前准备（offer确认/工位/账号）、首日首周计划、导师/伙伴（buddy）机制、30/60/90天里程碑与反馈、融入评估与转正衔接。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 三、工作流
1. 入职前准备（offer确认/工位/账号）
2. 入职首日/首周计划（欢迎/制度/文化）
3. 建立导师/伙伴（buddy）机制
4. 30/60/90天里程碑与反馈
5. 融入评估与转正衔接

## 四、核心内容（检查清单与判定）
入职引导（onboarding）覆盖从发offer到转正的全过程；以首周融入、buddy 陪伴与阶段里程碑反馈提升新员工留存。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含入职前准备（offer确认/工位/账号） | 准备 |
| Q2 | FAIL | 未含入职首日/首周计划（欢迎/制度/文化） | 首周 |
| Q3 | WARN | 未含导师/伙伴（buddy）机制 | 导师 |
| Q4 | FAIL | 未含30/60/90天里程碑与反馈 | 里程碑 |
| Q5 | WARN | 未含融入评估与转正衔接 | 评估 |

> 脚本 `onboarding_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python onboarding_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python onboarding_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
