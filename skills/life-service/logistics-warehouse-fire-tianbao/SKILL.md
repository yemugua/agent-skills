# 物流仓储消防管理（logistics-warehouse-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《仓储场所消防安全管理通则》（XF 1131）与GB 50016，生成仓库消防管理清单：货架防火间距、丙类/甲乙类分库、装卸动火、电动车禁入。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 仓库消防
- 仓储消防
- 物流消防
- 冷库消防
- 堆放间距
- 仓储安全

## 三、工作流
1. 确认储存物品火灾危险性分类
2. 甲乙类独立库/丙类分区
3. 校核堆距与墙距、主通道
4. 装卸与动火审批隔离
5. 电动车/叉车充电区独立设置

## 四、核心内容（检查清单与判定）
XF 1131 规定库存物品应分类分垛储存，垛与垛间距≥1m、垛与墙≥0.5m、主通道≥2m；甲乙类仓库严禁明火与电动车入内。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未明确储存物品火灾危险性分类 | GB 50016 |
| Q2 | FAIL | 堆距/墙距/主通道未达标 | XF 1131 |
| Q3 | WARN | 甲乙类未独立库或通风防爆缺失 | 甲乙类 |
| Q4 | FAIL | 电动车/充电区未独立隔离 | 电动车 |
| Q5 | WARN | 装卸与动火审批未单列 | 动火 |

> 脚本 `logistics-warehouse-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python logistics-warehouse-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python logistics-warehouse-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
