# 厨房排油烟管道防火（kitchen-hood-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据餐饮场所燃气与厨房防火要求，生成清单：油烟管道清洗与油脂积聚、灶台自动灭火装置、燃气报警与紧急切断、排油烟罩与防火阀、明火作业与用气管理。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 油烟管道清洗
- 厨房排油烟管道
- 灶台灭火装置
- 燃气报警切断
- 餐饮厨房消防

## 三、工作流
1. 核查油烟管道清洗与油脂积聚
2. 检查灶台自动灭火装置
3. 落实燃气报警与紧急切断
4. 核查排油烟罩与防火阀
5. 规范明火作业与用气管理

## 四、核心内容（检查清单与判定）
厨房油烟管道积油是餐饮场所典型火灾诱因，须定期清洗并留证；灶台应设自动灭火装置，燃气泄漏报警须联动紧急切断阀。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含油烟管道清洗与油脂积聚 | 清洗 |
| Q2 | FAIL | 未含灶台自动灭火装置 | 自动灭火 |
| Q3 | FAIL | 未含燃气报警与紧急切断 | 切断 |
| Q4 | WARN | 未含排油烟罩与防火阀 | 防火阀 |
| Q5 | WARN | 未含明火作业与用气管理 | 用气 |

> 脚本 `kitchen-hood-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python kitchen-hood-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python kitchen-hood-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
