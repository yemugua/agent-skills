# 哑铃训练

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 给出基础动作的标准要点与代偿信号清单 | 诊断肩袖损伤、腰椎间盘突出或任何伤病 |
| 说明重量选择、组次与组间休息的剂量口径 | 给康复训练方案、伤后恢复计划或用药建议 |
| 整理渐进超负荷的判定与调整方式 | 承诺练多久能长多少肌肉、减多少体重 |
| 给每周安排与停练红线 | 建议憋气发力、追求力竭或带伤硬扛 |
| 输出动作不合格项与原因、重量调整建议 | 推荐使用类固醇、激素类或任何药物与补剂 |

**必须停止训练并转交专业人士的情况**

- 动作中出现关节锐痛、刺痛，或疼痛向肢体远端放射
- 训练后关节肿胀、活动受限，或疼痛夜间加重、休息时不缓解
- 腰部出现放射到腿部的疼痛、麻木或无力
- 肩部出现抬不起来、夜间痛、特定角度的疼痛弧
- 训练中头晕、胸闷、心悸、眼前发黑 —— 立即停止并就医
- 任何急性损伤：突发剧痛、无力、局部明显肿胀

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「哑铃买多重合适」 | 用，给按动作区分的重量选择口径 |
| 「一组几个、一次几组」 | 用，给目标区间 |
| 「组间休息多久」 | 用，复合与孤立动作分开给 |
| 「哑铃卧推肩膀不舒服」 | 只作停练与就医提示，不做诊断 |
| 「练了两个月没进步」 | 用，查渐进超负荷与计划 |
| 「在家只有一副哑铃怎么练」 | 用，给全身动作组合 |
| 「要不要每组都做到力竭」 | 用，说明不是必须 |
| 「发力时要不要憋气」 | 用，明确不建议憋气 |
| 「帮我看看我动作标不标准」 | 不提供视频判读，只给自查清单 |

## 三、完整工作流

1. **先排停练红线**：逐条过停练清单，命中任一条先停练并就医，不要边疼边改动作。
2. **定目标**：增肌、力量还是耐力，三者的组次与休息完全不同。
3. **选动作**：按 `rules/动作标准与代偿信号.md` 选 5-7 个动作，覆盖推、拉、下肢、核心。
4. **定重量**：按「能标准完成目标次数且还剩 2-3 次余力」选重量，宁轻不重。
5. **查代偿**：每个动作逐项过代偿信号，任一项出现就降重量或退阶，而不是继续加。
6. **排计划**：按 `rules/剂量与渐进超负荷.md` 排每周频次与渐进方式。
7. **记录与复评**：记录每次的重量、次数、组数、RIR；连续 2-3 周三项都不涨，说明计划需要调整。

## 四、核心规则与要件库

生成训练计划或动作纠正建议前，**必须先读**：

- `rules/动作标准与代偿信号.md`：各动作的起始位、运动轨迹、呼吸、常见代偿与退阶方式。
- `rules/剂量与渐进超负荷.md`：重量选择、组次与休息区间、RIR 口径、渐进方式与停滞处理、每周安排。

不得建议每组做到力竭，也不得建议憋气发力。出现代偿信号时的第一动作是降重量或退阶，不是继续加重量。

## 五、脚本用法

```
python scripts/dumbbell_training_check.py --file case.json
python scripts/dumbbell_training_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：目标、每个动作的重量次数组数 RIR、代偿信号、组间休息、每周频次、同一肌群每周次数、停滞周数、是否憋气 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--json` | 以 JSON 输出 |
| `--selftest` | 运行自检 |

脚本输出逐动作判定、代偿不合格项与原因、剂量偏差、渐进超负荷判定和每周安排建议。**判定顺序是先查真实缺陷（代偿信号、休息严重不足、同一肌群过量、长期停滞、憋气），再看信息是否完整**，只填了代偿信号却没填重量时，会直接判不合格而不是待确认。

## 六、人工确认清单

- [ ] 停练红线逐条确认，未命中的才开始训练
- [ ] 目标已明确，组次与休息按目标选择
- [ ] 每个动作的重量满足「标准完成且余 2-3 次」
- [ ] 代偿信号逐项确认，出现任一项已降重量或退阶
- [ ] 每组未做到力竭，保留 2-3 次余力
- [ ] 全程不憋气，发力呼气还原吸气
- [ ] 同一肌群每周不超过 3 次，间隔至少 48 小时
- [ ] 每次训练都记录了重量、次数、组数、RIR

## 七、最常见的坑

1. **重量上得比动作快**：动作还没稳定就加重量，是代偿和不适的主要来源。重量的增长应该跟在动作质量后面。
2. **耸肩做肩推和侧平举**：斜方肌一参与，肩部训练就变味，而且颈肩会越来越紧。降重量、沉肩再做。
3. **腰部反弓做推举和划船**：腰椎代偿说明核心没收住或重量过大，先退阶到坐姿或减重。
4. **每组都做到力竭**：力竭会显著延长恢复时间，还会让后面几组动作变形，得不偿失。保留 2-3 次余力更稳。
5. **组间休息太短**：复合动作休息不足 90 秒，下一组必然动作变形，等于用错误姿势练。
6. **憋气发力**：大重量时憋气会明显升高血压，头晕眼黑就是信号。全程保持呼吸。
7. **练了不记录**：不记录重量次数，等于无法判断有没有渐进，练多久都是原地踏步。
8. **一周练同一部位四五次**：肌肉在休息时恢复，练得越勤不等于长得越快。

## 八、边界与免责

本技能提供哑铃基础动作的标准要点、剂量参考和计划安排思路，不构成医学诊断、运动康复方案或体测成绩承诺。重量、组次、频次因年龄、训练年限、关节状况和既往损伤而异，以最新版运动医学共识和专业教练的现场评估为准。出现关节锐痛、放射痛、肿胀、夜间痛、训练中头晕胸闷等情况，请停止训练并就医。
