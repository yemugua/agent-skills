# 临时用电安全（temporary-electricity）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《施工现场临时用电安全技术规范》JGJ 46，生成清单：临时用电方案与审批、三级配电两级保护、一机一闸一漏一箱、电缆敷设与防破损、巡检维护与拆除。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 临时用电
- 施工现场用电
- 三级配电
- 两级保护
- 一机一闸一漏

## 三、工作流
1. 编制临时用电方案并审批
2. 落实三级配电两级保护
3. 做到一机一闸一漏一箱
4. 规范电缆敷设并防破损
5. 定期巡检维护并规范拆除

## 四、核心内容（检查清单与判定）
JGJ 46 要求临时用电采用三级配电、两级保护与 TN-S 接零保护，并做到一机一闸一漏一箱；电缆敷设与巡检拆除同样关键。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含方案编制与审批 | 方案 |
| Q2 | FAIL | 未含三级配电两级保护 | 配电 |
| Q3 | WARN | 未含一机一闸一漏一箱 | 一机一闸 |
| Q4 | FAIL | 未含电缆敷设与防破损 | 电缆 |
| Q5 | WARN | 未含巡检维护与拆除 | 巡检 |

> 脚本 `temporary-electricity_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python temporary-electricity_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python temporary-electricity_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
