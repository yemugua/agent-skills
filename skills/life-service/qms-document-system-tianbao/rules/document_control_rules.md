# 质量管理体系文件受控规则速查

> 以现行标准（GB/T 19001/ISO 9001）、法规及认证机构要求为准。

## 1. 四层文件架构

| 层 | 文件 | 内容 | 编号段 |
|---|---|---|---|
| 一 | 质量手册 | 方针、目标、范围、过程相互作用、删减说明 | QM |
| 二 | 程序文件 | 跨部门过程的职责、流程、接口、监控要求 | QP |
| 三 | 作业指导书 | 岗位操作、技术规范、设备规程、检验规范 | WI |
| 四 | 记录表单 | 过程输出证据，与上层文件对应 | QR |

**必需程序（通用基线，按标准与行业裁剪）：**
文件控制、记录控制、内部审核、不合格品控制、纠正措施、预防措施；
按组织实际增设：采购、生产服务提供、设备管理、培训、应急准备等。

## 2. 编号规则

```
类型码-过程码-序号[-版本]
QM / QP / WI / QR + 两位过程码 + 两位序号
```

原则：唯一、可读、可扩展、版本分离。
**废止编号不得复用**；换版只升版本，不改编号。

## 3. 三级审批

```
编制（起草人，过程归口部门）
  ↓
审核（部门负责人/过程相关方）
  ↓
批准（管理者代表或授权人，手册须最高管理者批准）
```

授权审批人名单应形成文件并定期评审。

## 4. 受控管理要点

- 受控章内容：文件编号、版本号、总份数、受控编号、持有人
- 发放/回收双登记，签收人、日期齐全
- 更改申请单：更改原因、更改内容、影响评估、验证要求
- 换版：新版发布前完成旧版回收；留存样本加盖"作废留存"
- 外来文件（法规、标准、客户文件）：清单管理，定期查新
- 电子受控：明确主控形式、权限、备份与恢复机制

## 5. 记录管理

- 记录设计五要素：唯一标识、追溯字段、判定字段、更改规范、保存期限
- 更改：划改+签名+日期；禁用修正液/整页重抄
- 保存期限：满足法规、产品责任期与客户要求
- 存储：防潮、防火、防丢，电子记录有备份

## 6. 内审与管理评审输入

**内审准备：** 审核方案（年度计划）、检查表、不符合报告、纠正措施、审核报告
**管理评审输入至少包括：** 方针目标达成、审核结果、顾客反馈、过程绩效、不合格与纠正措施、变更需求、改进建议

## 7. 现场审核高频不符合项

- 文件未经审批发放或审批人不在授权名单
- 现场使用作废版本
- 记录涂改、后补、代签
- 记录与文件要求字段不一致
- 外来标准过期未更新
- 内审不符合项无纠正措施或未验证效果
