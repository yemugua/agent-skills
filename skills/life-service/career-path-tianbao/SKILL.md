# 职业发展通道设计（career-path）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据职业发展与任职资格实践，生成职业发展通道清单：通道划分（管理/专业/技能）、职级与晋升标准、任职资格与评审、轮岗与横向发展、发展计划与导师支持。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 职业发展通道
- 双通道
- 任职资格
- 晋升标准
- 员工发展

## 三、工作流
1. 划分发展通道（管理/专业/技能）
2. 设定职级与晋升标准
3. 建立任职资格与评审机制
4. 设计轮岗与横向发展
5. 配套发展计划与导师支持

## 四、核心内容（检查清单与判定）
职业发展通道让员工不必都挤管理独木桥；管理、专业、技能多通道并行，配套清晰晋升标准与任职资格评审。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含通道划分（管理/专业/技能） | 通道 |
| Q2 | FAIL | 未含职级与晋升标准 | 晋升 |
| Q3 | WARN | 未含任职资格与评审 | 资格 |
| Q4 | FAIL | 未含轮岗与横向发展 | 轮岗 |
| Q5 | WARN | 未含发展计划与导师支持 | 发展 |

> 脚本 `career-path_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python career-path_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python career-path_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
