# 毕业设计（论文）选题判断标准与常见毛病

> 各校的选题范围、审批流程、字数与格式要求不同。**以本校毕业设计（论文）工作管理办法和指导教师要求为准**。

## 一、选题六项判断标准

| # | 标准 | 具体问法 | 不合格表现 |
|---|---|---|---|
| 1 | 边界清晰 | 能不能用一句话说清"研究什么、不研究什么" | 题目包含多个并列问题，范围无限外延 |
| 2 | 规模适配 | 工作量与学制、周期、个人能力是否匹配 | 本科题做成了博士题，或一周能做完的题做了半年 |
| 3 | 可行性 | 数据、样本、设备、场地、经费能不能拿到 | 需要企业内部数据但拿不到，需要昂贵设备 |
| 4 | 有问题意识 | 有没有一个待解决的具体问题 | 只是描述现象，没有要回答的问题 |
| 5 | 有新材料或新方法 | 新数据、新场景、新角度、新方法，至少占一样 | 别人做过十遍的题目，用同样方法再做一遍 |
| 6 | 与专业匹配 | 是否落在专业培养方向与指导教师研究领域内 | 跨得太远，答辩时无法回应专业问题 |

## 二、题目大小的判断

| 过大（要收窄） | 适中 | 过小（要扩展） |
|---|---|---|
| 中国新能源汽车产业发展研究 | 某三线城市新能源汽车充电桩选址的影响因素研究——以 XX 区为例 | 某小区 1 号充电桩使用情况调查 |
| 人工智能在医疗中的应用 | 基于 XX 数据集的肺部影像分类方法比较研究 | 某模型在 10 张影像上的测试 |
| 企业财务管理问题研究 | XX 行业中小企业应收账款周转率对现金流的影响——以 A 公司为例 | A 公司 2023 年 3 月凭证抽查 |

**收窄三招**：加限定（时间、地域、行业、样本范围）、换对象（从"产业"换成"某类企业"）、定方法（从"研究"换成"基于 XX 方法的分析"）。

## 三、常见题目毛病清单

| 毛病 | 例子 | 怎么改 |
|---|---|---|
| 题目过大 | XX 行业发展问题研究 | 加地域、行业细分、时间范围限定 |
| 题目过空 | 浅析 XX / XX 的若干思考 | 补上具体问题与研究对象 |
| 题目即结论 | XX 方法的优越性研究 | 改成"XX 方法在 XX 场景下的适用性研究" |
| 无法获取数据 | 某企业内部风险控制研究 | 换可公开获取数据的对象，或改用案例公开资料 |
| 与专业不符 | 计算机专业写纯文学作品分析 | 换回专业相关方向 |
| 工作量不匹配 | 一周能完成的简单调研 | 增加对比维度、样本量或方法深度 |
| 多个并列问题 | XX 的现状、问题、成因与对策研究 | 聚焦其中一个，其余作为背景 |
| 题目含生僻缩写 | 基于 XX-YOLOv11 的 XX | 首次出现写全称，避免缩写堆砌 |

## 四、选题来源与可行路径

| 来源 | 优点 | 注意 |
|---|---|---|
| 指导教师课题的子课题 | 数据与方向有保障 | 明确自己的独立工作量边界 |
| 实习单位实际问题 | 数据真实，应用价值高 | 注意脱敏与授权，避免涉密 |
| 公开数据集 + 方法复现 | 数据可得，可复现 | 不能只做复现，要有自己的改进或比较 |
| 文献综述型（理论研究） | 不依赖实验条件 | 必须有明确的分析框架与自己的判断，不能只是罗列 |
| 工程设计/系统设计类 | 产出物明确 | 要有可运行的原型、测试与结果分析 |
| 社会调查类 | 素材丰富 | 样本量、抽样方法、问卷设计要经得起问 |

## 五、文献综述怎么写（不要按人罗列）

| 组织方式 | 适用 | 写法 |
|---|---|---|
| 主题脉络 | 研究问题有多个子议题 | 按子议题分节，每节综述进展与不足 |
| 方法脉络 | 方法演进是主线 | 按方法类别分节，比较适用条件与效果 |
| 争议脉络 | 已有结论存在分歧 | 按争议点分节，摆出各方证据与分歧原因 |
| 时间脉络 | 发展阶段清晰 | 按阶段分节，说明每阶段的突破与局限 |

**结尾必须落到**：已有研究解决了什么、**还没解决什么**、因此本文要做什么。没有这三层，综述就只是读书报告。

## 六、开题报告的核心要素

| 要素 | 要点 |
|---|---|
| 研究背景与意义 | 说清为什么值得做，现实意义与理论意义分开写 |
| 文献综述 | 按脉络组织，结尾落到研究空白 |
| 研究问题 | 1 个主问题 + 2~3 个子问题，可验证 |
| 研究内容 | 与研究问题对应，逐条可交付 |
| 研究方法 | 说清用什么方法、为什么用它、数据从哪来 |
| 技术路线 | 流程图 + 步骤说明 |
| 创新点 | 1~2 条，具体到"新在哪"，不要写"填补空白" |
| 进度安排 | 节点 + 产出物 + 时间 |
| 参考文献 | 数量与格式按学校要求，近五年文献占比要够 |

**防误伤**：开题报告里写的是"拟采用"的方法，不等于"已经采用"。中期和定稿阶段方法变了，要在正文中说明调整原因并体现在最终稿里，否则答辩时会被问住。

## 七、学术诚信红线

| 禁止 | 说明 |
|---|---|
| 抄袭他人论文、报告、代码 | 查重与抽检能发现，后果由学校规定 |
| 伪造、篡改实验数据与调研样本 | 属于学术不端，一经认定后果严重 |
| 购买、代写论文 | 涉及学术不端与欺诈 |
| 一稿多投、重复发表自己的成果 | 需按学校规定说明与处理 |
| 不当引用（引而不注、注而不实） | 引用必须真实可溯源 |
| 整篇由生成式人工智能产出后当作自己的作品 | 各校对 AI 使用有明确规定，须按学校要求披露与使用 |

**正确做法**：AI 可用于文献检索、语言润色、思路梳理、代码调试辅助，但研究设计、数据获取、分析结论与最终表述必须是自己的，并按学校要求如实说明使用情况。
