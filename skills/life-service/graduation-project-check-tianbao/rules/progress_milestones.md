# 毕业设计（论文）进度节点、产出物与倒排表

> 各校节点名称、时间与材料要求不同。**以本校毕业设计（论文）工作日程与指导教师要求为准**。

## 一、标准节点与产出物

| # | 节点 | 产出物 | 常见卡点 |
|---|---|---|---|
| 1 | 选题与任务书 | 选题审批表、任务书 | 题目范围过大；导师方向不匹配 |
| 2 | 文献调研 | 文献综述初稿、参考文献清单 | 只罗列不分析；文献太旧 |
| 3 | 开题 | 开题报告、开题答辩 PPT | 研究问题不清；方法说不清为什么用它 |
| 4 | 研究实施 | 实验/调研/开发记录、原始数据 | 数据拿不到；实验不可复现；无过程记录 |
| 5 | 中期检查 | 中期报告、已完成部分、问题与调整 | 进度落后却写成"按计划进行" |
| 6 | 初稿 | 全文初稿（含图表、参考文献） | 结构缺失；数据分析没做完 |
| 7 | 查重 | 查重报告 | 引用不规范导致重复率偏高；引而不注 |
| 8 | 修改定稿 | 修改说明、定稿 | 导师意见未逐条回应 |
| 9 | 答辩 | 答辩稿、PPT、演示/演示视频 | PPT 照搬全文；讲不清自己的贡献 |
| 10 | 归档 | 最终版论文、材料袋、源文件 | 格式不符合归档要求；源文件丢失 |

## 二、从答辩日倒排（默认口径，可按学校日程调整）

| 节点 | 距答辩日 | 说明 |
|---|---|---|
| 开题 | 提前约 10 周 | 早于它就要完成选题与文献调研 |
| 中期检查 | 提前约 8 周 | 此时完成度应在 50% 以上 |
| 初稿 | 提前约 6 周 | 全文成稿，可进入修改 |
| 查重 | 提前约 4 周 | 留出修改时间，不要卡在截止前一天 |
| 定稿 | 提前约 2 周 | 导师意见逐条改完 |
| 答辩 | 0 | 答辩稿与 PPT 就绪 |

**倒排原则**：以答辩日为锚向前推，**每个节点之间留出缓冲**。查重一定要留够修改时间——重复率不合格还有一轮修改，卡在最后几乎必然出问题。

## 三、进度状态判定

| 状态 | 判定 |
|---|---|
| 已完成 | 已标记完成 |
| 正常 | 未完成，剩余天数 > 14 天 |
| 关注 | 未完成，剩余 8 ~ 14 天 |
| 预警 | 未完成，剩余 3 ~ 7 天 |
| 紧急 | 未完成，剩余 1 ~ 2 天 |
| 已逾期 | 未完成，剩余 ≤ 0 天 |

## 四、完成度口径（不要自欺欺人）

| 阶段 | 真实完成度参考 |
|---|---|
| 只是定了题目 | 5% ~ 10% |
| 文献综述写完 | 20% ~ 25% |
| 开题通过 | 25% ~ 30% |
| 数据/实验做完 | 45% ~ 55% |
| 初稿成稿 | 60% ~ 70% |
| 查重通过 | 75% ~ 80% |
| 定稿完成 | 85% ~ 90% |
| 答辩通过并归档 | 100% |

**防误伤**：把"资料收集了"当成"写了一半"是最常见的进度误判。判断完成度的唯一标准是**有没有可交付的成稿**，不是"看了多少资料"。

## 五、与指导教师沟通的正确方式

| 要这样 | 不要这样 |
|---|---|
| 带着两个方案去问"哪个更合适，为什么" | "老师我下一步做什么" |
| 每次汇报有明确产出物 | 只说"我在做了" |
| 记录导师意见并逐条回应 | 意见收到后无反馈，下次还是老问题 |
| 提前预约、按约定时间交付 | 截止前一天才提交，压缩导师审阅时间 |
| 遇到卡点及时说，附自己的判断与备选方案 | 卡住了不说，等到中期才发现 |

## 六、答辩准备的要点

| 项目 | 要点 |
|---|---|
| PPT | 10~15 页为宜：问题、方法、数据、结果、结论、创新点 |
| 讲述 | 三分钟内说清"做了什么、怎么做的、得到什么结论" |
| 自述重点 | 自己的贡献与不足，不要通篇讲背景 |
| 常见问题 | 为什么选这个方法；数据怎么来的；样本量够不够；结论的适用范围；与已有研究的区别 |
| 演示 | 系统/原型要能现场跑通，准备录屏备份 |
| 材料 | 带齐论文、任务书、指导教师与评阅意见、原始数据或源码 |

## 七、格式与规范的高频扣分点

| 项目 | 常见问题 |
|---|---|
| 引用 | 正文引用与参考文献表不对应；引而不注；文献类型标识错误 |
| 图表 | 编号不连续；图表无标题或标题位置错；截图模糊；数据图未标单位 |
| 目录 | 自动生成未更新；页码与实际不符 |
| 摘要 | 写成引言；没有结论与关键词（或关键词不检索友好） |
| 章节 | 章节之间无过渡；某章只有一页；章节篇幅严重失衡 |
| 参考文献 | 数量不足；近五年占比低；格式不统一；引用二手来源未核原文 |
| 术语 | 同一概念多种叫法；首次出现未给定义 |

## 八、进度落后时的处理顺序

```
1. 如实盘点：哪些节点真的完成了，交付物在哪
2. 找出卡点：是数据、方法、设备，还是时间分配
3. 收缩范围：把题目边界收窄到能做完（先保住完整性）
4. 重排节点：按剩余时间倒排，砍掉非必要内容
5. 主动沟通：带着方案找导师，说明调整与理由
6. 保住底线：完成度 > 完美度，先交出完整稿再谈优化
```

**绝对不要**：把进度落后写成"按计划进行"、伪造数据、抄同学的阶段成果、或找人代写。这些一旦被发现，后果远重于延期。
