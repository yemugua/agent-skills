# 投影画面梯形校正与摆放（projector-keystone-correction）

投影画面一歪，绝大多数人的反应是打开梯形校正。**这是顺序错了。** 数码梯形校正是用像素裁剪和重采样换来的，代价是分辨率、亮度和清晰度。正确顺序是：**先摆位，后校正**。

这个技能做四件事：**算距离** → **摆正位** → **少校正** → **严验收**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 按投射比换算投射距离 | ❌ 保证某机型一定能投出某尺寸（以说明书为准） |
| 给出先摆位后校正的调校顺序 | ❌ 建议用大角度侧投长期观看 |
| 说明数码校正的画质代价 | ❌ 判断机器内部光路故障 |
| 提示吊装与高空作业安全红线 | ❌ 指导在吊顶扣板、龙骨上承重安装 |
| 列出画面验收清单 | ❌ 替代售后维修与吊装施工 |

**遇到以下情况，立即停止自行操作，转交专业人员：**

- 需要在吊顶内、承重结构上打孔吊装（吊顶扣板与轻钢龙骨**不能承重**）
- 需要走暗线、穿墙布 HDMI 或电源线（涉及电工作业）
- 作业高度超过 2 米，或需要站在梯子最高两档
- 机器内部有异响、异味、冒烟、画面出现固定黑点或色斑
- 需要新增或改造电源插座
- 重型幕布、电动幕布的安装

**永远不要在投影仪散热完成前断电。** 灯泡机型关机后风扇要继续转，直接拔电源会显著缩短灯泡寿命，严重时损坏机器。

## 二、完整工作流

```
第 1 步  确认幕布或墙面尺寸，定画幅宽度与安装高度
第 2 步  查机器的投射比，算投射距离（镜头到幕面）
第 3 步  先读规则文件 rules/projector_setup_rules.md（距离换算 + 校正代价 + 红线）
第 4 步  跑故障树脚本
    python scripts/projector_setup_check.py --text "画面上下不等宽，机器只能放侧面"
第 5 步  物理摆位：镜头正对画面中心、机身水平、考虑镜头位移
第 6 步  关闭自动校正看原始画面形状，先调机身再谈校正
第 7 步  对焦、变焦填满，按验收清单逐项核对
```

---

## 三、投射距离换算（先算再搬）

**投射比 = 投射距离 ÷ 画面宽度**，所以：

```
投射距离 = 投射比 × 画面宽度
```

| 投射比 | 投 100 英寸（宽约 2.21m）所需距离 |
|---|---|
| 0.47:1（超短焦） | 约 1.04m |
| 1.0:1 | 约 2.21m |
| 1.2:1（常见） | 约 2.65m |
| 1.5:1 | 约 3.32m |

> 变焦机型给的是一个范围（如 1.15-1.5:1），距离可以在这个区间内灵活调整。**以机器说明书标注的投射比为准**，不同型号差异很大。

**安装高度**：画面底边离地通常 60-90cm，画面中心与坐姿视线齐平或略高。吊装时先算好镜头中心到画面中心的垂直偏移。

## 四、先摆位后校正（核心原则）

| 手段 | 画质代价 | 优先级 |
|---|---|---|
| 挪机器位置，让镜头正对画面中心 | 无 | 最高 |
| 用光学镜头位移（Lens Shift） | 无 | 高 |
| 用光学变焦调画幅大小 | 基本无 | 高 |
| 数码垂直梯形校正 | 有，损失分辨率与亮度 | 中 |
| 数码水平梯形校正 | 明显，侧投时一侧失焦 | 低 |
| 数码四角校正 | 最大，重采样锯齿 | 最低 |

**关键认知**：侧投时画面与镜头平面不平行，**聚焦平面也是倾斜的**，所以一边清楚一边模糊是物理必然，不是机器坏了。校正角度越大，画质损失越明显，游戏与高速画面还会有额外延迟。

---

## 五、摆位与调校作业顺序

**工具**：卷尺、水平仪（手机 APP 即可）、梯子（需有人扶）、记号笔、抹布、对焦测试图。

1. **定画幅**：确认幕布尺寸或墙面上要投多大，量出画面宽度
2. **算距离**：投射比 × 画面宽度 = 镜头到幕面的距离
3. **定高度**：镜头中心尽量正对画面中心高度
4. **摆水平**：用水平仪确认机身左右水平，调节脚调俯仰
5. **关校正看原图**：**先关掉所有梯形校正**，看原始画面形状，判断差多少
6. **能挪就挪**：优先挪机器、挪幕布，把偏差物理上消掉
7. **用镜头位移**：有 Lens Shift 的机型用光学位移，别用数码校正
8. **最后开校正**：自动校正后手动微调四角，尽量小的校正量
9. **对焦变焦**：用对焦测试图对焦，变焦把画面填满幕布
10. **记录数值**：记下距离、高度、校正量，下次搬家不用重来

## 六、脚本用法

```bash
python scripts/projector_setup_check.py --text "画面上下不等宽，机器只能放侧面，一边模糊"
python scripts/projector_setup_check.py --file 描述.txt --out 结果.md
```

| 参数 | 说明 |
|---|---|
| `--text` | 直接给现象描述 |
| `--file` | 从文件读描述 |
| `--out` | 结果落盘路径 |
| `--format` | `md`（默认）或 `json` |
| `--throw-ratio` | 投射比，例如 1.2 |
| `--width` | 画面宽度（米），例如 2.21 |
| `--selftest` | 跑内置样例自检 |

给了 `--throw-ratio` 与 `--width` 时会直接算出投射距离。**脚本只做关键词匹配与简单换算，不代表现场判断。**

## 七、人工确认清单（这步不能省）

- [ ] 投射距离按投射比算过，不是目测
- [ ] 机身左右水平（水平仪验证过）
- [ ] 先关掉校正看过原始画面形状
- [ ] 优先挪过机器，而不是直接开校正
- [ ] 有 Lens Shift 的机型优先用了光学位移
- [ ] 对焦用的是测试图，不是随便一个画面
- [ ] 画面四角都落在幕布内，没有溢出
- [ ] 散热空间够（进出风口距墙 ≥20-30cm）

## 八、最常见的坑

**坑一：画面歪了就开梯形校正。**
校正是用像素换形状的，先挪机器能无损解决。校正量越大，分辨率与亮度损失越明显。

**坑二：侧投后一边模糊就以为是机器坏了。**
侧投时聚焦平面倾斜，一边失焦是物理必然。减少侧投角度才是解法。

**坑三：只看"能投多大"不看投射比。**
同一台机器投 100 寸和投 120 寸的距离差几十厘米，装之前不算是返工主因。

**坑四：把投影仪贴墙放。**
进出风口被挡，机器过热保护、自动降亮度，甚至关机。留出 20-30cm 散热空间。

**坑五：灯泡机型关机后立即拔电源。**
关机后风扇要继续散热，直接断电显著缩短灯泡寿命。

**坑六：在吊顶扣板或龙骨上装吊架。**
扣板与轻钢龙骨不能承重，必须固定在楼板或承重结构上，并加装防坠绳。

**坑七：自动校正完就不管了。**
自动校正常留黑边与锯齿，需要手动微调四角，且尽量减小校正量。

**坑八：亮度不够第一反应是灯泡老化。**
先算是不是画幅投太大、是不是开了大角度侧投校正、是不是环境光太强。

**坑九：吊装画面倒了以为装错了。**
设置里有吊装模式 / 投影方式，切换即可，不是硬件问题。

## 九、边界与免责

- 本技能**不替代**吊装安装、电路改造、暗线布设与售后维修
- 投射比、镜头位移范围、校正能力因机型差异极大，**以产品说明书为准**
- 涉及承重结构打孔、登高作业、强电改造的，应由专业人员施工
- 机器出现异响、异味、冒烟、固定黑点时，应立即停用并联系售后
- 激光光源机型**切勿直视镜头**，避免强光伤眼
