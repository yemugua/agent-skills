# 投影画面调校与摆放规则

## 一、判定总原则

1. **先摆位，后校正。** 数码校正是用画质换形状，能物理消除的偏差不要靠校正。
2. **先算距离，后搬机器。** 装之前不算投射距离是返工主因。
3. **光学位移优先于数码校正。** Lens Shift 无损，数码校正有损。
4. **校正量越小越好。** 校正量与画质损失正相关。
5. **散热优先于美观。** 进出风口被挡会触发过热保护与降亮。

---

## 二、投射距离换算

**投射比 = 投射距离 ÷ 画面宽度**，因此：

```
投射距离 = 投射比 × 画面宽度
```

| 投射比 | 机型特征 | 投 100 英寸（宽约 2.21m）所需距离 |
|---|---|---|
| 0.47:1 | 超短焦 / 激光电视 | 约 1.04m |
| 1.0:1 | 短焦 | 约 2.21m |
| 1.2:1 | 常见家用 | 约 2.65m |
| 1.5:1 | 长焦 | 约 3.32m |

- 变焦机型给的是范围（如 1.15-1.5:1），距离可在区间内调整
- **以机器说明书标注的投射比为准**，不同型号差异很大
- 画面宽度不等于对角线尺寸，换算时先查幕布规格

### 安装高度

- 画面底边离地通常 60-90cm
- 画面中心与坐姿视线齐平或略高
- 吊装时先算镜头中心到画面中心的垂直偏移

---

## 三、调校手段优先级

| 手段 | 画质代价 | 优先级 |
|---|---|---|
| 挪机器位置，让镜头正对画面中心 | 无 | 最高 |
| 光学镜头位移（Lens Shift） | 无 | 高 |
| 光学变焦调画幅 | 基本无 | 高 |
| 数码垂直梯形校正 | 有，损失分辨率与亮度 | 中 |
| 数码水平梯形校正 | 明显，侧投时一侧失焦 | 低 |
| 数码四角校正 | 最大，重采样锯齿 | 最低 |

**关键认知**：侧投时画面与镜头平面不平行，聚焦平面也是倾斜的，一边清楚一边模糊是物理必然。

## 四、画面异常故障树（按处理顺序）

| 顺序 | 现象 | 最可能原因 | 处置 |
|---|---|---|---|
| 1 | 上下不等宽（垂直梯形） | 机身俯仰角度不对 | 调调节脚或用光学位移，最后才用垂直校正 |
| 2 | 左右不等宽（水平梯形） | 机器没有正对幕布中心 | 挪机器位置，减少侧投角 |
| 3 | 一边清楚一边模糊 | 侧投导致聚焦平面倾斜 | 减小侧投角，重新对焦 |
| 4 | 四角都不是直角 | 幕布不平或墙面不平 | 检查幕面平整度 |
| 5 | 边缘发虚、有色边 | 镜头位移超出范围或镜头脏 | 回到位移中心，清洁镜头 |
| 6 | 画面有黑边或锯齿 | 数码校正的像素重采样 | 减小校正量 |
| 7 | 亮度不足、发灰 | 画幅过大、侧投校正、环境光强 | 缩小画幅、减少校正、遮光 |
| 8 | 画面上下颠倒 | 吊装模式未切换 | 设置里切换投影方式 |
| 9 | 固定黑点、色斑、异响 | 机器内部故障 | **停用并报售后** |

---

## 五、十步调校顺序

1. 定画幅：确认幕布尺寸或墙面投多大，量出画面宽度
2. 算距离：投射比 × 画面宽度
3. 定高度：镜头中心尽量正对画面中心
4. 摆水平：水平仪确认机身左右水平
5. 关校正看原图：**先关掉所有梯形校正**，判断差多少
6. 能挪就挪：优先挪机器或挪幕布，物理消除偏差
7. 用镜头位移：有 Lens Shift 的机型用光学位移
8. 最后开校正：自动校正后手动微调四角，尽量小
9. 对焦变焦：用对焦测试图对焦，变焦填满幕布
10. 记录数值：记下距离、高度、校正量

## 七、安全红线（必须停用并请专业人员）

| 情形 | 处置 |
|---|---|
| 需在吊顶内或承重结构上打孔吊装 | 吊顶扣板与轻钢龙骨不承重，转专业人员 |
| 需走暗线、穿墙布 HDMI 或电源线 | 涉及电工作业，转专业人员 |
| 作业高度超过 2 米或需站梯子最高两档 | 转专业人员 |
| 机器内部异响、异味、冒烟、固定黑点 | 立即停用并报售后 |
| 需新增或改造电源插座 | 转电工 |
| 重型幕布、电动幕布安装 | 转专业人员 |

**禁止事项：**

- 禁止把投影仪贴墙放置（进出风口距墙应 ≥20-30cm）
- 禁止灯泡机型关机后立即拔电源（风扇需继续散热）
- 禁止直视激光光源镜头（强光伤眼）
- 禁止在吊顶扣板或龙骨上悬挂投影吊架
- 禁止单人进行 2 米以上登高作业
- 吊装必须加装防坠绳并固定在承重结构

## 八、常见误判清单（反向判断）

| 现象 | 常见误判 | 正确判断 |
|---|---|---|
| 画面歪 | 开梯形校正就行 | 先挪机器，校正损画质 |
| 一边模糊 | 机器坏了 | 侧投聚焦平面倾斜，是物理必然 |
| 亮度不够 | 灯泡老化 | 先查画幅过大、侧投校正量、环境光 |
| 画面颠倒 | 装错了 | 切换吊装模式 / 投影方式 |
| 边缘发虚 | 机器没对好焦 | 镜头位移超范围或镜头脏 |
| 有黑边锯齿 | 幕布尺寸不对 | 数码校正的重采样，减小校正量可消除 |
| 自动校正后有偏差 | 校正功能不准 | 自动校正后需手动微调四角 |
| 投不满幕布 | 距离不对 | 用光学变焦调，不要用数码缩放 |
| 画面发灰 | 机器亮度虚标 | 环境光与墙面反射影响极大 |

## 九、验收标准

| 项目 | 合格标准 |
|---|---|
| 方正 | 四角为直角，用测试图网格线检查无变形 |
| 清晰 | 中心与四角均清晰，无明显单侧失焦 |
| 溢出 | 画面完整落在幕布内，无溢出无黑边 |
| 亮度 | 在正常观看光线下层次可辨 |
| 校正量 | 数码校正量尽可能小，必要时记录数值 |
| 散热 | 进出风口通畅，机器无过热告警 |

任一项不合格，按故障树重新调校，不要反复加大校正量。
