# 腰椎间盘突出康复锻炼与急性期处置

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 按分期给出休息、活动和训练的通用口径 | 诊断腰突节段、压迫程度或判断是否需要手术 |
| 列出各期可做的动作与明确禁忌动作 | 指导推拿复位、暴力扳腰、牵引器自行使用 |
| 提示马尾综合征等需要急诊的红旗症状 | 把「膨出/突出/脱出」直接对应到症状严重程度 |
| 整理坐姿、搬物、睡姿的负荷管理口径 | 推荐具体药品、剂量或贴膏品牌 |
| 输出分期康复清单与复评时间点 | 承诺锻炼能「把突出练回去」 |

**就医红线（出现任一条，立即就医；标注急诊的直接去急诊）**

- **会阴区（鞍区）麻木、大小便失禁或排不出、尿潴留** —— 疑似马尾综合征，急诊
- **双腿进行性无力、走路拖步、脚尖或脚跟抬不起来** —— 急诊
- 单侧下肢麻木无力快速加重，或范围持续扩大
- 腰痛伴发热、寒战，或有静脉吸毒史、近期感染、免疫抑制状态（需排除感染）
- 有恶性肿瘤病史，出现新发持续腰痛或夜间痛
- 外伤后（跌倒、车祸、举重受伤）急性腰痛，尤其高龄或骨质疏松者
- 腰痛伴明显腹痛、主动脉瘤病史者突发剧痛
- 保守处理 4-6 周仍持续加重，或跛行距离持续缩短

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「腰突了能做什么锻炼」 | 用，先分期再给动作 |
| 「急性期要躺几天」 | 用，说明卧床不宜超过 48 小时的通用口径 |
| 「小燕飞、仰卧起坐能不能做」 | 用，明确各期禁忌 |
| 「腿麻加重了是不是严重了」 | 只做就医提示 |
| 「要不要手术」 | 用，只说明常见手术指征口径，由专科医生判断 |
| 「按摩把突出推回去靠谱吗」 | 用，说明风险 |
| 「我现在大小便控制不住」 | 只作急诊提示，不给任何动作 |

## 三、完整工作流

1. **先排红旗**：逐条核对就医红线，命中任一立即停止康复建议，输出急诊或尽快就诊提示。
2. **判定分期**：按疼痛天数与疼痛强度分为急性期、亚急性期、缓解期；记录是否有下肢放射痛。
3. **定活动量**：急性期以短时多次步行为主，避免久坐久站；不推荐长时间绝对卧床。
4. **配动作**：按分期从 `rules/分期处置与动作许可.md` 选动作，遵守「疼痛向心化」原则。
5. **管负荷**：调整坐姿、搬物方式、睡姿和体重管理，对照规则表逐项落实。
6. **设复评点**：2 周、4-6 周各复评一次；加重或无改善及时转专科。
7. **记录**：每日疼痛评分、步行距离、能做与诱发疼痛的动作，形成记录表。

## 四、核心规则与要件库

生成康复建议前，**必须先读**：

- `rules/分期处置与动作许可.md`：急性期与缓解期的活动量、动作库和明确禁忌动作。
- `rules/红旗症筛查与就医判定.md`：马尾综合征与危险信号清单、急诊口径、常见误区。

不得把影像学上的「突出」直接等同于症状来源；影像学改变在无症状人群中同样常见。不得建议暴力手法、自行牵引或长期绝对卧床。

## 五、脚本用法

```
python scripts/lumbar_redflag_check.py --file case.json
python scripts/lumbar_redflag_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：症状天数、疼痛评分、是否放射到腿、红旗项、目前活动量 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--json` | 以 JSON 输出 |
| `--selftest` | 运行自检 |

脚本输出分期判定（急性期 / 亚急性期 / 缓解期）、动作许可与禁忌清单、每日步行目标。**命中红旗时只输出就医提示，不输出任何锻炼动作。**

## 六、人工确认清单

- [ ] 红旗症逐条核对，未命中才进入康复方案
- [ ] 分期已按疼痛天数和强度确认
- [ ] 禁忌动作清单已逐条确认不做
- [ ] 每日步行目标已按分期设定，且以不加重为度
- [ ] 久坐单次时长已控制在 30 分钟以内
- [ ] 搬物姿势已改为屈髋屈膝、物体贴近身体
- [ ] 基础疾病、肿瘤史、骨质疏松、既往腰部手术史已告知
- [ ] 2 周与 4-6 周复评时间点已记录

## 七、最常见的坑

1. **急性期猛练小燕飞**：腰部后伸过度在急性期常加重症状，应先用俯卧支撑等温和后伸或等长训练。
2. **练仰卧起坐和体前屈**：屈曲加压动作会增加椎间盘前负荷，腰突者普遍不推荐。
3. **长期绝对卧床**：卧床超过 48 小时反而延缓恢复，应在可耐受范围内尽早恢复日常活动。
4. **信「按摩推回去」**：突出是椎间盘组织移位，手法推不回去，暴力操作有加重风险。
5. **睡硬板床治腰突**：过硬床垫不改善预后，以睡醒不加重、支撑均匀为准。
6. **腿麻加重还硬撑**：进行性无力或麻木范围扩大是加重信号，不是「锻炼见效的反应」。
7. **久坐不动**：久坐（尤其前倾坐位）椎间盘内压较高，比站立负荷更大。
8. **只看核磁报告做决定**：治疗方案要症状、查体和影像三者结合，由专科医生判断。

## 八、边界与免责

本技能提供腰突康复的分期处置口径、动作许可与禁忌清单，不构成诊断、治疗方案或手术建议。所有活动量、训练剂量、手术指征因年龄、神经损害程度、病程和合并疾病而异，**以最新版临床指南和骨科或康复科医师的判断为准**。出现就医红线中的任一情况，请立即就医，勿依据本技能延误。
