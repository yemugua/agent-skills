# 红旗症筛查与就医判定

腰突绝大多数可以保守处理，但少数情况属于外科急症。筛查先于一切康复建议。

## 一、马尾综合征（急诊）

| 表现 | 说明 |
|---|---|
| 会阴区、肛门周围、大腿内侧麻木（鞍区麻木） | 最典型的早期信号 |
| 小便排不出、尿潴留，或失禁 | 膀胱功能受累 |
| 大便失禁或排不出 | 肠道功能受累 |
| 双腿无力、走路拖步、站不稳 | 多神经根受累 |
| 性功能突然改变 | 可伴随出现 |

处置口径：疑似马尾综合征属于**外科急症**，应立即到急诊就诊，不要等到第二天门诊，不要先做按摩或锻炼。部分患者以「尿不太顺畅 + 会阴有点麻」起病，容易被忽略。

## 二、其他危险信号

| 信号 | 提示方向 | 处置 |
|---|---|---|
| 腰痛伴发热、寒战 | 需排除脊柱感染 | 尽快就诊，查血与影像 |
| 有恶性肿瘤病史，新发持续腰痛 | 需排除转移 | 尽快就诊 |
| 不明原因体重下降、夜间痛为主、休息不缓解 | 需进一步评估 | 尽快就诊 |
| 外伤后急性腰痛（跌倒、车祸、举重） | 需排除骨折 | 就诊评估；高龄或骨质疏松者更谨慎 |
| 高龄、长期使用激素、骨质疏松者突发剧痛 | 需排除椎体压缩骨折 | 就诊评估 |
| 已知主动脉瘤或腹部血管病史突发剧痛 | 需排除血管急症 | 急诊 |
| 腰痛伴腹痛、血尿 | 需排除泌尿与腹部问题 | 就诊 |
| 下肢进行性无力、足下垂 | 神经损害进展 | 尽快就诊，常需专科评估手术指征 |

## 三、常见手术指征口径（只作说明，不由本技能判断）

- 疑似马尾综合征
- 进行性神经功能损害（肌力持续下降）
- 保守治疗 6-12 周无效且症状严重影响生活与工作
- 反复发作、生活质量严重受损

是否手术由骨科或神经外科医师结合症状、查体和影像综合判断。

## 四、明确不做的事

- 不做暴力推拿、扳腰、踩背
- 不自行购买使用腰椎牵引器
- 不在急性期做小燕飞、仰卧起坐、体前屈
- 不长期绝对卧床（超过 48 小时弊大于利）
- 不因为「片子突出很大」就恐慌，也不因为「只是膨出」就忽视神经症状

## 五、就诊时带什么

| 材料 | 说明 |
|---|---|
| 影像资料 | 原始影像（光盘或电子文件）比报告更有用 |
| 症状时间线 | 起病时间、诱因、加重缓解因素 |
| 神经症状记录 | 麻木部位、肌力变化、二便情况，写清出现日期 |
| 用药与过敏史 | 当前所有用药 |
| 问题清单 | 是否需手术、能做什么动作、什么时候复诊 |

## 六、高频误区

| 误区 | 事实 |
|---|---|
| 「腿麻加重是在通经络」 | 麻木范围扩大或出现无力是加重信号 |
| 「躺到完全不痛再起来」 | 长期卧床延缓恢复，应尽早恢复可耐受活动 |
| 「睡硬板床能把腰突睡好」 | 床垫以支撑均匀、睡醒不加重为准，过硬无额外收益 |
| 「按摩能把突出推回去」 | 手法不改变椎间盘位置，暴力操作有风险 |
| 「贴膏药/吃止痛药就能练」 | 疼痛被掩盖不等于负荷消失，动作剂量仍需以反应为准 |
| 「突出必须手术」 | 多数患者保守处理可恢复 |
