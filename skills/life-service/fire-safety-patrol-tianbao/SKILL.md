# 防火巡查检查（fire-safety-patrol）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：按《机关团体企业事业单位消防安全管理规定》（公安部61号令）生成防火巡查/检查计划与记录表，逐条对标隐患判定。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 防火巡查
- 防火检查
- 每日巡查
- 巡查记录
- 巡查表
- 61号令巡查

## 三、工作流
1. 明确巡查层级（日巡/月检/专项）与频次
2. 生成巡查路线与检查项（用火用电/疏散/设施/值班）
3. 现场记录+拍照留痕
4. 隐患分级（一般/重大）与闭环
5. 归档并更新下次巡查计划

## 四、核心内容（检查清单与判定）
依据公安部61号令：公众聚集场所营业期间每2h一次巡查；其他单位每日巡查、每月至少一次检查。重大隐患依GB 35181判定。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未明确巡查层级与频次 | 61号令第二十五条 |
| Q2 | FAIL | 用火用电/疏散通道/消防设施三类核心检查项缺失 | 61号令 |
| Q3 | WARN | 近30天巡查记录不足应巡次数 | 巡查闭环 |
| Q4 | FAIL | 发现隐患但未记录整改责任人与期限 | 隐患闭环 |
| Q5 | WARN | 未含消防控制室/值班人员在岗核查 | 值班管理 |
| Q6 | FAIL | 重大火灾隐患未按GB 35181直接判定或综合判定 | GB 35181-2025 |

> 脚本 `fire-safety-patrol_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python fire-safety-patrol_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python fire-safety-patrol_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
