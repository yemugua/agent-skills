# 颈椎锻炼动作与颈部劳损缓解

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 给出缓慢、可控的颈部与肩胛带训练动作与剂量 | 诊断是不是颈椎病、哪一节突出、是否需要手术 |
| 说明疼痛停止原则和动作退阶方式 | 推荐正骨、暴力推拿、颈椎扳法或任何「咔哒复位」操作 |
| 整理工位屏幕高度、坐姿、睡枕的选择口径 | 指导自行牵引、购买牵引器或长期佩戴颈托 |
| 提示需要尽快就医的红旗症状 | 把片子上的「退变」「膨出」直接解释成病因 |
| 输出每日锻炼清单与负荷自查打分 | 承诺锻炼一定能消除手麻、头晕或头痛 |

**就医红线（出现任一条，停止自行锻炼，尽快就诊；急诊情况直接去急诊）**

- 手或手指麻木、无力，握力下降、拿东西掉、扣扣子不灵活
- 走路发飘、踩棉花感、双腿发紧、容易绊倒
- 大小便障碍、会阴区麻木（提示脊髓受压可能，属于紧急情况）
- 上肢放射痛持续加重，夜间痛到睡不着，或咳嗽打喷嚏时明显加重
- 头晕伴视物旋转、复视、说话不清、吞咽困难、一侧肢体无力（先排除脑血管问题）
- 外伤后颈痛（车祸、跌倒、撞击），无论轻重都要先评估
- 颈痛伴发热、体重明显下降、夜间盗汗、既往肿瘤史
- 颈痛伴明显头痛、恶心呕吐、怕光或意识改变

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「久坐后脖子僵，做点什么动作」 | 用 |
| 「米字操能不能做」「转头咔咔响正常吗」 | 用，明确快速环绕不推荐 |
| 「肩膀酸，怎么拉伸」 | 用 |
| 「手麻是不是颈椎间盘突出」 | 只做就医提示，不做诊断 |
| 「帮我看看 CT 片子上写的是什么意思」 | 用，只解释术语，不下结论 |
| 「正骨把骨头推回去靠谱吗」 | 用，说明风险与禁忌 |
| 「脖子疼得转不了，还发烧」 | 只作急诊提示 |

## 三、完整工作流

1. **先排红线**：逐条过一遍就医红线清单，命中任一条立刻停止给锻炼方案，转为就医提示。这一步不能跳过。
2. **区分疼痛性质**：记录疼痛部位（颈后、肩胛内侧、上肢）、性质（酸胀、锐痛、放射）、诱因（久坐、低头、特定动作）和加重缓解因素。只有「久坐相关的酸胀僵硬」才适合本技能的动作方案。
3. **确定疼痛基线**：用 0-10 分给当前颈痛打分，作为后续动作是否可继续的判断基准。
4. **选动作并定剂量**：从 `rules/动作库与训练剂量.md` 选动作，按「缓慢、小幅度、可退阶」原则配 3-5 个动作。
5. **执行疼痛停止原则**：动作中疼痛比基线升高 2 分以上、出现放射痛或麻木、或次日症状加重，立即减量或停做。
6. **改工位，不只练肌肉**：对照 `rules/工位改造与误区.md` 调整屏幕高度、座椅支撑和手机使用姿势。
7. **记录与复评**：连续 2 周记录锻炼天数、疼痛评分和诱发时长；2 周无改善或加重则转康复科/骨科评估。

## 四、核心规则与要件库

生成锻炼清单或姿势建议前，**必须先读**：

- `rules/动作库与训练剂量.md`：动作分解、组次剂量、退阶与进阶、疼痛停止原则。
- `rules/工位改造与误区.md`：屏幕高度、座椅、睡枕、手机姿势口径与高频误区。

不得把「颈椎曲度变直」「骨质增生」「椎间盘膨出」写成必然引起症状的原因，影像退变在中年以上人群普遍存在。不得建议任何形式的快速甩头、暴力旋转、他人扳颈或自行牵引。

## 五、脚本用法

```
python scripts/cervical_load_check.py --file case.json
python scripts/cervical_load_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：每日低头时长、屏幕是否低于视线、锻炼天数、疼痛评分、是否命中红线项 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--json` | 以 JSON 输出 |
| `--selftest` | 运行自检 |

脚本输出负荷分级（低 / 中 / 高）、推荐动作数、每周锻炼频次缺口和命中红线的就医提示。**命中红线时脚本只会输出就医建议，不输出任何锻炼方案。**

## 六、人工确认清单

- [ ] 就医红线逐条确认，未命中的才开始动作方案
- [ ] 疼痛基线已记录，动作前后用同一把尺子打分
- [ ] 动作已确认缓慢可控，无快速甩头与暴力旋转
- [ ] 每个动作有退阶方案（幅度变小、次数减少、改为等长）
- [ ] 屏幕高度、座椅支撑、手机姿势至少各改一项
- [ ] 睡枕高度与睡姿已核对
- [ ] 已知的基础疾病、既往颈部手术或外伤史已告知
- [ ] 2 周后复评时间点已定

## 七、最常见的坑

1. **练米字操式快速环绕**：快速大幅度转头会刺激椎动脉与关节突，中老年人风险更高，应当用小幅度、缓慢、分段的方向性活动替代。
2. **把响声当「复位成功」**：关节弹响不等于问题解决了，反复刻意掰响反而加重关节松弛。
3. **去做正骨扳颈**：颈椎暴力手法有椎动脉夹层、脊髓损伤风险，尤其有手麻、头晕、骨质疏松者更不应尝试。
4. **长期戴颈托**：颈托连续佩戴超过 1-2 周会加重颈部肌肉萎缩，只在医生明确要求时使用。
5. **只练脖子不练肩胛**：肩胛带力量不足是「肩颈酸痛」的常见来源，只做颈部拉伸效果有限。
6. **疼着硬练**：疼痛加重说明剂量过大，不是「打通经络」。
7. **只看片子不看人**：影像退变与症状常常不对应，避免拿片子吓自己。
8. **改动作不改工位**：每天低头 6 小时，练 10 分钟不解决问题。

## 八、边界与免责

本技能提供颈部劳损的动作规范、训练剂量参考和姿势改造要点，不构成诊断、治疗方案或医学建议。所有动作剂量、适应证和禁忌因年龄、骨质疏松、既往手术、神经症状和合并疾病而异，**以最新版临床指南和康复科或骨科医师的判断为准**。出现就医红线中的任一情况，请立即停止自行锻炼并就医。
