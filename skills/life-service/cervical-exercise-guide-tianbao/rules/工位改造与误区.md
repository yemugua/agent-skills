# 工位改造与误区

锻炼只解决肌肉能力，姿势改造解决负荷来源。两者缺一不可。

## 一、工位改造口径

| 项目 | 口径 | 判定方法 |
|---|---|---|
| 屏幕高度 | 屏幕上 1/3 与眼睛大致同高，视线平视或略向下 10-15 度 | 平视时能看到屏幕上沿，不需要低头 |
| 屏幕距离 | 一臂距离（约 50-70 厘米） | 手伸直指尖能触到屏幕 |
| 笔记本 | 用支架抬高 + 外接键盘鼠标，不要直接低头看 | 键盘与屏幕分离 |
| 座椅 | 臀部坐满椅深，腰靠支撑第 3-4 腰椎，双脚平放地面 | 膝略低于髋 |
| 扶手 | 高度使肩自然下沉、肘约 90 度 | 肩不需要耸起 |
| 文档 | 用文档架放在屏幕旁，避免反复低头侧头看纸 | 视线平移即可 |
| 手机 | 抬到面部高度看，不要低头；长时间阅读改用平板支架 | 手肘有支撑 |
| 中断 | 每 30-60 分钟起身活动 2-3 分钟 | 用定时器提醒 |

## 二、睡枕与睡姿

| 睡姿 | 口径 |
|---|---|
| 仰卧 | 枕头高度约「侧躺时头颈与躯干保持中立」的厚度，通常压缩后一拳左右；颈后不悬空 |
| 侧卧 | 枕头高度应填满耳到肩的距离，使头颈与脊柱成一条直线 |
| 俯卧 | 不推荐，颈部长时间扭转 |
| 通用判定 | 起床后颈僵加重说明枕头不合适；以醒来无僵硬为准 |

枕头只给选择口径，不推荐具体品牌与型号。

## 三、高频误区

| 误区 | 事实 |
|---|---|
| 「米字操把脖子转一圈能缓解」 | 快速大幅度环绕风险大于收益，应改为分段、缓慢、小幅度的方向性活动 |
| 「脖子响一下就是复位了」 | 弹响是关节内气体或软组织滑动，不等于复位；刻意反复掰响会加重松弛 |
| 「按摩店正骨能把突出推回去」 | 椎间盘突出不会被手法推回；暴力手法有椎动脉夹层、脊髓损伤风险 |
| 「片子写了膨出/增生，所以脖子疼就是它」 | 影像退变在中年以上普遍存在，与症状常不对应，需结合查体 |
| 「戴颈托保护颈椎」 | 长期佩戴导致颈部肌肉萎缩，只在医师明确要求时使用 |
| 「疼就多拉一拉，拉开就好了」 | 疼痛是停止信号，忍痛拉伸会加重 |
| 「睡硬枕头或不睡枕头治颈椎」 | 无依据，以醒来无僵硬为唯一标准 |
| 「手麻就是缺钙/受凉」 | 手麻伴无力是神经受压信号，需专业评估 |

## 四、症状记录表（每日一行）

| 字段 | 填写口径 |
|---|---|
| 日期 | 年-月-日 |
| 疼痛评分 | 0-10 分，取当日最明显的一次 |
| 久坐低头时长 | 按小时记录，含手机 |
| 锻炼内容 | 动作名 + 组次 |
| 动作后反应 | 减轻 / 无变化 / 加重 |
| 备注 | 新出现的麻木、头晕、放射痛要单独记 |

连续 2 周后回看：若疼痛评分与久坐时长同步下降，方案有效；若无变化或加重，转康复科或骨科评估。
