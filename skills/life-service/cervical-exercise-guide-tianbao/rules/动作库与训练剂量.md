# 动作库与训练剂量

> 适用前提：就医红线全部未命中，且症状以久坐相关的颈部酸胀僵硬为主。
> 所有剂量为常见康复训练参考区间，**以最新版临床指南和康复科或骨科医师的判断为准**。

## 一、训练总原则

| 原则 | 具体口径 |
|---|---|
| 慢 | 动作全程 3-5 秒完成一个来回，不做甩动、不做爆发 |
| 小 | 活动到「有拉伸感但无明显疼痛」的 70% 幅度即止，不追求极限 |
| 可控 | 全程能随时停下；出现放射痛、麻木、头晕立即停止 |
| 退阶 | 任何动作都可退阶为「更小幅度 / 更少次数 / 改等长 / 改卧位」 |
| 复评 | 连续 2 周记录，2 周无改善或加重转康复科评估 |

## 二、核心动作（每日选 3-5 个）

### 1. 收下巴训练（颈深屈肌）

- **起始**：坐位或仰卧位，目视前方，下巴保持水平，**不要低头看地板**。
- **动作**：后脑勺向后平移（像把头「缩」向椅背），出现双下巴的感觉，不是低头。
- **剂量**：保持 5-10 秒，8-10 次/组，1-2 组/天。
- **退阶**：仰卧位做，或保持时间缩到 3 秒。
- **常见错误**：用低头代替后缩；肩膀跟着耸起。

### 2. 颈部等长抗阻（前 / 后 / 左 / 右）

- **动作**：手掌抵住额头（或后枕、侧颞），颈部发力顶住手掌，头**不发生位移**，纯静态对抗。
- **剂量**：每个方向保持 5-10 秒，3-5 次/方向，1 组/天。
- **退阶**：手掌压力减小到 30% 力度；或只做后侧与左右侧，跳过前屈。
- **常见错误**：手和头真的在动，变成了动态抗阻；憋气。

### 3. 肩胛后缩（中下斜方肌）

- **动作**：坐位，双臂自然下垂，两侧肩胛骨向脊柱靠拢并轻微下沉，保持肘部伸直。
- **剂量**：保持 5 秒，10-15 次/组，2 组/天。
- **退阶**：改为「耸肩—放松—下沉」循环，减少保持时间。
- **常见错误**：耸肩到耳朵；含胸驼背状态下做。

### 4. 胸肌拉伸（门框或墙角）

- **动作**：前臂贴门框，肘略低于肩，身体缓慢前移，感受胸前拉伸。
- **剂量**：每侧保持 20-30 秒，2-3 次/侧，1-2 组/天。
- **禁忌**：肩关节前方疼痛、脱位史者先问医生。
- **常见错误**：把身体猛地前倾做弹振式拉伸。

### 5. 上斜方肌拉伸

- **动作**：坐位，一手轻扶对侧耳上方（**不拉扯头部**），头向对侧缓慢侧屈并轻微旋转，同侧手向下轻压肩部固定。
- **剂量**：每侧保持 20-30 秒，2-3 次/侧，1 组/天。
- **常见错误**：用力拽头；两侧同时做。

### 6. 胸椎伸展（靠椅背）

- **动作**：坐位双手抱头，椅背顶在胸椎中段，缓慢后仰过椅背边缘，伸展胸椎而非折腰。
- **剂量**：保持 3-5 秒，8-10 次，1 组/天。
- **禁忌**：骨质疏松、椎体压缩骨折史不做。

## 三、疼痛停止原则（判定表）

| 情况 | 处置 |
|---|---|
| 动作中疼痛比基线升高 ≥2 分（0-10 分制） | 该动作减半次数，或换退阶版本 |
| 出现上肢放射痛、麻木、刺痛 | 立即停止该动作，本轮不再做 |
| 出现头晕、视物旋转、恶心 | 立即停止，坐下休息；反复出现需就医 |
| 锻炼后次日疼痛加重且 24 小时内不恢复 | 暂停 2 天，剂量回到上一档 |
| 疼痛持续下降、活动度改善 | 每 1-2 周按 10-20% 幅度小幅进阶 |

## 四、周频次基准

| 项目 | 参考区间（口径：一般久坐人群的康复训练） |
|---|---|
| 颈部专项训练 | 每周 5-7 天，每天 10-15 分钟 |
| 肩胛带力量训练 | 每周 3-5 天 |
| 中断休息 | 每坐 30-60 分钟起身活动 2-3 分钟 |
| 整体有氧活动 | 每周累计 150 分钟中等强度（成人一般推荐口径，以最新版指南为准） |

## 五、明确不做的事

- 不做快速、大幅度、连续环绕的颈部绕圈（俗称米字操式甩头）
- 不做他人施力的颈椎扳法、正骨、暴力推拿
- 不做自行颈椎牵引或使用家用牵引器（需医师评估后决定）
- 不做「痛着硬压」「忍痛拉开」类拉伸
- 不长期连续佩戴颈托（超过 1-2 周需医师确认）
