# 储能与锂电池消防安全（energy-storage-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《电化学储能电站设计规范》GB 51048 与锂电池储能消防要求，生成储能与锂电池消防安全清单：电池舱室布置与防火分隔、火灾探测与报警、灭火系统配置、热失控防控与隔离间距、应急处置。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 储能消防
- 锂电池消防
- 电化学储能
- 储能电站
- 热失控

## 三、工作流
1. 核查电池舱室布置与防火分隔
2. 配置火灾探测与报警
3. 确定灭火系统（气体/水）
4. 落实热失控防控与隔离间距
5. 明确禁水性确认与应急处置

## 四、核心内容（检查清单与判定）
电化学储能与锂电池存在热失控风险，应按 GB 51048 等做好防火分隔、探测报警与灭火配置；处置须先明确电池类型与禁水性，防止用水加剧。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含电池舱室布置与防火分隔 | 布置 |
| Q2 | FAIL | 未含火灾探测与报警 | 探测 |
| Q3 | WARN | 未含灭火系统配置 | 灭火 |
| Q4 | FAIL | 未含热失控防控与隔离间距 | 热失控 |
| Q5 | WARN | 未含应急处置与禁水性确认 | 应急 |

> 脚本 `energy-storage-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python energy-storage-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python energy-storage-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
