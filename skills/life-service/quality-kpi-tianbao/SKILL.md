# 质量目标分解与 KPI（quality-kpi）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据 ISO 9001 质量目标要求，生成清单：目标承接战略并可测量、逐层分解到部门与岗位、指标定义与计算口径、监测频次与看板、未达标改进与定期评审。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 质量目标
- 质量KPI
- 目标分解
- 质量指标
- 质量看板

## 三、工作流
1. 制定可测量并承接战略的目标
2. 逐层分解到部门与岗位
3. 统一指标定义与计算口径
4. 明确监测频次与看板
5. 未达标改进并定期评审

## 四、核心内容（检查清单与判定）
质量目标须可测量、与方针一致并逐层分解；关键是统一计算口径与监测频次，未达标要有改进闭环，避免目标挂墙无跟踪。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含目标可测量与承接战略 | 目标 |
| Q2 | FAIL | 未含逐层分解到部门岗位 | 分解 |
| Q3 | WARN | 未含指标定义与计算口径 | 口径 |
| Q4 | FAIL | 未含监测频次与看板 | 监测 |
| Q5 | WARN | 未含未达标改进与评审 | 评审 |

> 脚本 `quality-kpi_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python quality-kpi_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python quality-kpi_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
