# 消防宣传教育（fire-safety-education）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：按《消防法》第六条与应急管理部门要求，生成消防宣传计划、培训课件大纲、演练方案与考核题，覆盖重点岗位与全员。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 消防宣传
- 消防培训
- 消防安全教育
- 培训课件
- 119宣传月
- 演练方案

## 三、工作流
1. 识别培训对象（全员/重点岗位/新进）与频次
2. 编年度计划与课时
3. 生成课件大纲（四懂四会/四个能力）
4. 设计演练脚本与考核题库
5. 记录培训签到与考核结果

## 四、核心内容（检查清单与判定）
《消防法》第六条明确机关团体企业事业单位应加强对职工的消防宣传教育；消防安全重点单位对职工每年至少一次全员培训。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未区分培训对象与频次 | 消防法第六条 |
| Q2 | WARN | 课件未覆盖四懂四会/四个能力 | 四个能力 |
| Q3 | FAIL | 未含演练或考核环节 | 培训闭环 |
| Q4 | WARN | 无培训签到与考核记录留痕 | 可追溯 |
| Q5 | FAIL | 重点岗位未单独列明培训要求 | 重点岗位 |

> 脚本 `fire-safety-education_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python fire-safety-education_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python fire-safety-education_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
