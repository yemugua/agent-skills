# 课堂笔记速记与整理

## 你会得到什么

一套能立刻上手的速记方案，核心是一句话：**速记的目的是记住结构，不是写字好看。**

**一、可直接照用的关键词缩写表与符号约定表。** 三十多个缩写（cf. 定义、ex. 例如、imp. 重要、q. 问题、rm. 记住、↔ 双向关系等）与符号含义（`*` 老师强调、`?` 没听懂、`!` 易错点、`⇒` 强结论）。纪律是同一概念只保留一个写法，符号只用一套并长期固定——频繁改符号等于每次都要重新解码。颜色约定不超过三种，否则记的时候会犹豫该用哪个。

**二、该记什么与不该记什么。** 该记：概念定义（压缩成自己的话）、结构与层级、老师强调的考点、没听懂的问题、与上节的连接。不该记：板书原句逐字抄、例题完整演算、与本课无关的背景铺垫、已经会的已知内容。口诀是**记不懂的和不熟的，不记会的**。

**三、结构选择按内容形态，不按习惯。** 有时间或步骤顺序的内容用线性记录（顺序本身携带信息，分支会破坏它）；多个并列要点围绕一个核心用分支；递进结构用线性主干加分支挂补充。特别提醒：**不要把顺序内容画成思维导图**，思维导图是并列结构，用在顺序内容上会丢掉逻辑链条。

**四、改良康奈尔框架**：主体区约三分之二线性记录、右侧关键词栏课后再填、底部总结区课后写。关键词栏**必须在课后填**，课上填会打断记录，得不偿失。复习时先看关键词栏自问自答，再看主体区。

**五、事后整理比当场工整更重要**，给了课后十分钟内、当天、之后按复习节点的三段式流程。其中**合上笔记用自己的话写三个要点**是检验笔记质量的唯一可靠方法——写不出来说明记的是抄写不是理解。

## 典型用法

- 「记不过来怎么办」：抓结构而非全记，用符号替代文字。
- 「笔记太潦草」：当场求快课后求整，课后十分钟内整理。
- 「要不要全部记下来」：按取舍表，明确不该全记。
- 「线性还是分支」：按内容形态判据选择。
- 「考完发现没重点」：压缩一页摘要，闭卷回忆结构。

## 脚本

`shorthand_map.py` 读入笔记 JSON，做片段分类统计、该记不该记判定、符号覆盖率与冲突检测、结构匹配建议与个人符号表导出，带 `--selftest`。

## 边界

不承诺零遗漏，不替代听课本身。符号方案需按个人习惯调整，建议固定一套后长期使用。有书写障碍或手部功能受限者，请使用录音等替代方式并寻求专业建议。
