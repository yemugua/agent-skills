# 课堂笔记速记与整理

**速记的目的是记住结构，不是写字好看。** 这是本技能最重要的一句话：花三分钟把一个概念的定义用自己的符号记下来，比花三分钟把板书写得工整，复习价值高出很多。

## 一、硬边界（能做 / 不能做）

| 能做 | 不能做 |
|---|---|
| 给可直接照用的缩写与符号约定表 | 承诺「记全」或「零遗漏」 |
| 给结构化记录框架与取舍原则 | 断言某套记法适合所有人 |
| 给出事后整理的流程与字段 | 替代本人的听课理解 |
| 判断笔记该记什么不该记什么 | 提供他人课堂内容的臆造整理 |
| 给出复习与再加工方法 | 代替听课本身（听课是输入，笔记是辅助） |

**必须转交专业人士：** 出现书写障碍、严重手部震颤影响记录，或注意力严重受损导致无法跟上课堂——应使用录音等替代方案或寻求专业评估，不要硬练速记。

## 二、什么时候用

| 用户说法 | 用不用 | 说明 |
|---|---|---|
| 课堂笔记怎么记 | 用 | 走取舍原则与框架 |
| 记不过来怎么办 | 用 | 走缩写表与抓结构而非全记 |
| 速记符号有哪些 | 用 | 给符号约定表 |
| 笔记太潦草看不懂 | 用 | 走事后整理与个人符号表 |
| 康奈尔笔记怎么用 | 用 | 给改良版结构与用法 |
| 要不要全部记下来 | 用 | 明确「不该全记」 |
| 线性还是分支 | 用 | 给取舍判据 |
| 考完发现笔记没重点 | 用 | 走复习加工方法 |

## 三、完整工作流

### 步骤 1：先定记录目标（记什么）

**课堂笔记不是抄板书。** 只记四类内容，见第四节。

### 步骤 2：用约定符号替代文字

符号表**只用一套并长期固定**。频繁改符号等于每次都要重新解码。

### 步骤 3：选记录结构（线性 vs 分支）

按板书与讲解形态选，不是按习惯选。

### 步骤 4：课后立刻整理（比当场工整重要）

见第六节。**当场不完美是可接受的，当场完美是不可持续的。**

## 四、核心规则（记笔记前必读）

**先读 `rules/速记符号表与记录框架.md`，不要临时发明符号。**

### 该记什么 / 不该记什么

| 该记 | 不该记 |
|---|---|
| 概念定义（用自己的话压缩） | 板书原句逐字照抄 |
| 结构与层级关系 | 例题的完整演算过程 |
| 老师强调的重点（「这个要考」类提示） | 与本课无关的背景铺垫 |
| 没听懂的问题（明确标记） | 空着的页与只有页码的占位 |
| 章节间的连接（与上节的关系） | 已经会的已知铺垫 |

**核心取舍**：**记不懂的和不熟的，不记会的。**

### 线性 vs 分支的取舍判据

| 板书/讲解形态 | 用哪种 | 理由 |
|---|---|---|
| 有明确时间或步骤顺序（流程、推导） | **线性** | 顺序本身携带信息，分支会破坏顺序 |
| 多个并列要点围绕一个核心 | **分支** | 并列关系需要同层展示 |
| 内容层层递进（定义→性质→应用） | **线性 + 分支混合** | 先线性记主干，旁支挂分支 |

**不要为了「好看」把所有内容画成思维导图**：思维导图适合并列，不适合顺序。顺序被打乱后，逻辑链条就丢了。

## 五、脚本用法

脚本：`scripts/shorthand_map.py`

```bash
python scripts/shorthand_map.py --file 笔记.json
python scripts/shorthand_map.py --selftest
```

| 字段 | 说明 |
|---|---|
| `segments` | 片段列表，含 kind（定义/结构/强调/疑问）与 text |
| `symbols` | 个人符号约定表 |
| `structure` | linear / branch / hybrid |

输出：片段分类统计、该记不该记的判定、符号覆盖率与冲突检测、结构匹配建议、个人符号表导出。

## 六、事后整理（比当场工整更重要）

**当场追求工整是不可持续的**，因为工整需要额外时间，而额外时间会挤掉记录内容本身。

```
课后 10 分钟内完成（趁热）：
1. 补全来不及记的空缺（问同学或看资料）
2. 用红笔标出没听懂的地方
3. 删掉明显抄错的（保留痕迹，划线更正）

当天或次日完成：
4. 合上笔记，用自己的话在空白处写三个要点（检验是否真懂）
5. 把疑问整理成问题清单
6. 把笔记压缩成一页摘要（这一步是核心）

之后按复习节点用：
7. 闭卷只看摘要回忆结构 → 再展开细节
```

**第 4 步是检验笔记质量的唯一可靠方法**：写不出来说明记的是抄写不是理解。

## 七、人工确认清单（不能省）

- [ ] 笔记中是否标出了没听懂的地方？
- [ ] 是否用固定一套符号，而不是每堂课换符号？
- [ ] 结构选择是否与内容形态匹配（顺序用线性、并列用分支）？
- [ ] 是否在课后短时间内完成了整理，而不是放着不管？
- [ ] 是否尝试过合上笔记复述要点？
- [ ] 是否压缩过一页摘要？
- [ ] 有没有把「会的东西」也记了下来（应删）？
- [ ] 符号表是否长期未变（变动即需重新熟悉）？

## 八、最常见的坑

1. **追求字迹工整**。这是最常见也最贵的错误：工整耗掉时间，记录内容反而变少。正确做法是当场求快，课后求整。
2. **试图记全所有内容**。全部记下来等于没筛选，复核时无法定位重点。
3. **把会的也记下来**。已知内容占篇幅，真正要复习的内容被淹没。
4. **临时发明符号**。自己都认不出的符号等于没记。
5. **符号表频繁改动**。改动一次就要重新熟悉一次。
6. **当场不整理，事后也不整理**。三天后基本认不出自己写的字。
7. **只抄不加工**。抄写不产生理解，第 4 步的复述会立刻暴露这一点。
8. **结构选择与内容不匹配**。顺序内容用分支会丢掉逻辑链。
9. **从不压缩摘要**。笔记不做减法，考前无法快速过一遍。
10. **把笔记当唯一材料**。笔记是输入的辅助，不能替代听课和理解。

## 九、边界与免责

本技能提供速记方法、符号约定与笔记整理流程，**不承诺零遗漏、不替代听课本身**。符号方案需按个人习惯调整，建议固定一套后长期使用。有书写障碍或手部功能受限者，请使用录音等替代方式并寻求专业建议。
