# 速记符号表与记录框架

> 记笔记前必读。**符号只用一套并长期固定。**

## 一、核心原则

**速记的目的是记住结构，不是写字好看。**

当场工整需要额外时间，而额外时间会挤掉记录内容本身。取舍很清楚：**记下的内容比记下的字迹重要**。

| `!` | 易错点 | |

| `※` | 个人疑问或待查 | |
| `__` | 定义下划线 | 定义一律划线 |
| `()` | 举例或限定条件 | |
| `「」` | 原话引用 | 只用于老师确实说了的话 |

**符号颜色约定**（如用多色）：

| 颜色 | 含义 |
|---|---|
| 黑色 | 常规内容 |
| 红色 | 重点与考点 |
| 蓝色 | 疑问与未解决 |
| 绿色 | 个人补充与联想 |

**颜色不超过三种**，否则记的时候要犹豫「该用哪个」。

## 四、结构化记录框架

### 改良康奈尔（课堂用主推）

原始康奈尔把笔记区限制得太窄，课堂记不完。改良版：

```
┌─────────────────────────────┬──────────┐
│                             │  关键词  │
│      主体记录区（约 2/3）    │   栏     │
│      线性记录，右侧留白      │（课后再填）│
│                             │          │
│                             │          │
├─────────────────────────────┤          │
│  底部总结区（约 1/6，课后写） │          │
└─────────────────────────────┴──────────┘
```

**用法要点**：

| 时机 | 做什么 |
|---|---|
| 课堂中 | 只填主体区，线性记录，右侧关键词栏**留空** |
| 课后 10 分钟 | 在右侧栏用 3—5 个词概括该段主题 |
| 课后当天 | 在底部总结区写本页核心 |
| 复习时 | **先看关键词栏自问自答，再看主体区** |

**关键词栏必须在课后填**。课上填会打断记录，得不偿失。

### 线性 vs 分支

| 判据 | 选择 |
|---|---|
| 有时间/步骤顺序（流程、推导） | 线性 |
| 多个并列要点围绕一个核心 | 分支 |
| 递进结构（定义→性质→应用） | 线性主干 + 分支挂补充 |
| 对比两个对象 | 分支左右对照 |

**不要把顺序内容画成思维导图**：思维导图是并列结构，用在顺序内容上会丢掉逻辑链条。

## 五、什么该记什么不该记

| 该记 | 不该记 |
|---|---|
| 概念定义（压缩成自己的话） | 板书原句逐字抄 |
| 结构与层级关系 | 例题完整演算 |
| 老师强调的考点（标 `*`） | 与本课无关的背景铺垫 |
| 没听懂的问题（标 `?`） | 空页与只有页码的占位 |
| 与上节的连接 | 已经会的已知内容 |

**取舍口诀：记不懂的和不熟的，不记会的。**

## 六、事后整理流程（当场完美不可持续）

```
课后 10 分钟内（趁热）：
  1. 补全空缺（问同学或查资料）
  2. 红笔标出没听懂处
  3. 划线更正抄错处（保留痕迹）

当天或次日：
  4. 合上笔记，用自己的话写三个要点（检验是否真懂）
  5. 疑问整理成问题清单
  6. 压缩成一页摘要（核心步骤）

之后按复习节点：
  7. 闭卷只看摘要回忆结构 → 展开细节
```

**第 4 步是检验笔记质量的唯一可靠方法**：写不出来，说明记的是抄写不是理解。

## 七、常见误区

| 误区 | 后果 | 正确做法 |
|---|---|---|
| 追求字迹工整 | 时间被挤，内容变少 | 当场求快，课后求整 |
| 试图记全 | 无法定位重点 | 按取舍表筛选 |
| 把会的也记下 | 重点被淹没 | 删已知内容 |
| 临时发明符号 | 认不出等于没记 | 固定一套并长期用 |
| 符号频繁改动 | 反复重新熟悉 | 改动需同时重记该符号含义 |
| 事后不整理 | 三天后认不出 | 课后 10 分钟内整理 |
| 只抄不加工 | 无理解产出 | 执行第 4 步复述检验 |
| 结构与内容不匹配 | 逻辑链丢失 | 顺序用线性、并列用分支 |
| 不压缩摘要 | 考前无法速览 | 压缩成一页 |
