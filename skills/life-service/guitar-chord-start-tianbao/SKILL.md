# 吉他和弦入门

## 适用场景
吉他入门器材、基础和弦、节奏与练习计划指引。

## 输入
按 `templates/场景表单.md` 填写场景、程度、可用工具与约束。

## 操作步骤
1. 打开 `templates/场景表单.md`，填写本次场景信息。
2. 运行：`python scripts/guitar_chord_start.py <你填写后的表单路径>`
3. 按输出的分阶段清单逐项执行并打勾。
4. 每阶段完成后做阶段验收，禁止跳步。

- 总体验收：步骤完成数核对 + 结果确认
