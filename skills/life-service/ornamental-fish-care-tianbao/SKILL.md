# 观赏鱼饲养（ornamental-fish-care）

绝大多数观赏鱼的问题，**查到最后都是两件事：水和喂**。水是慢性问题，往往在鱼浮头、拒食、白点、烂鳍那一刻才暴露；喂是急性问题，一次过量能把一缸水毁掉。

这个技能做三件事：**把水养好 → 把鱼放对 → 把量控住**。

---

## 一、硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出开缸养水的流程与判据 | ❌ 给出任何药物的名称、剂量与疗程 |
| 给出四项核心水质指标的判断阈值 | ❌ 判断鱼患的是什么病、给出治疗方案 |
| 给出换水、困水、过温过水的操作口径 | ❌ 保证任何情况下鱼都不死 |
| 给出按水体与鱼种换算的密度与投喂量 | ❌ 建议未经困水的自来水直接入缸 |
| 给出必须停手联系专业人员的判断线 | ❌ 处理多种鱼混养的攻击性冲突处置结论 |

**必须停手并联系水族专业人员或水产兽医的情况**

- 短时间内多条鱼相继死亡，或同一症状在缸内快速扩散
- 鱼体出现白点、白毛、溃烂、立鳍、腹水、突眼等明显异常且持续加重
- 水质指标严重异常且常规换水后不见改善
- 整缸鱼集体浮头、趴底、急促呼吸，且不随换水缓解
- 疑似中毒（误加清洁剂、杀虫剂、消毒剂、金属污染）

## 三、完整工作流

1. **开缸**：洗缸 → 加水 → 开过滤 → 建立硝化系统。这一步最少七天，急不得。
2. **测水**：准备氨氮、亚硝酸盐、硝酸盐、酸碱度四项的基本测试能力。没有数据就调缸，等于闭眼开车。
3. **判读数据**：把测得的值对照阈值表，先判有没有急性危险。
4. **算密度**：把所有鱼的体长总和算出来，对照水体升数与鱼种系数。
5. **定喂食**：按「两到三分钟内吃完」确定单次量，按水温与鱼种定每日次数。
6. **排换水**：按硝酸盐上升速度与喂食量定换水频次，按口径定单次换水比例。
7. **入新鱼**：按购买地点到家的实际时间安排过温与过水，不着急把袋子打开。
8. **做记录**：每次测水、换水、死亡、异常都记一笔。**没有记录就无法判断趋势，绝大多数「突然死鱼」其实是有趋势的。**
9. **核对**：用 `--file` 跑一遍计划，把道理上的不合格项先排掉。

## 四、核心规则说明

**动手之前必须先读这两个文件，不要凭印象写：**

- `rules/水质指标与换水口径.md` —— 四项核心指标的判断阈值、兑水与困水要求、单次换水比例与频次
- `rules/开缸养水与喂食管理.md` —— 养水周期与判据、新鱼过温过水步骤、密度换算、投喂量与禁食情形

要点三条：

1. **氨氮和亚硝酸盐是两条命线**，这两项一超标，鱼是先伤鳃后伤器，等你看到行为异常往往已经晚了。
2. **换水的目的是稀释硝酸盐，不是把水换干净**。换得太多太勤，硝化系统永远不稳定。
3. **新鱼入缸头号死因是温差与水质突变的双重刺激**，不是运输。过温过水这两步省掉任何一步，等于让鱼自己耐过两重打击。

## 五、脚本用法

```
python scripts/fish_care_check.py --selftest
python scripts/fish_care_check.py --file tank.json
```

输入字段：

| 字段 | 说明 | 示例 |
|---|---|---|
| tank_liters | 水体升数 | 60 |
| fish_cm_total | 全部鱼体长之和（厘米） | 45 |
| fish_type | 鱼种类别 | 「小型热带鱼」「金鱼」「锦鲤」 |
| ammonia | 氨氮毫克每升 | 0.1 |
| nitrite | 亚硝酸盐毫克每升 | 0.05 |
| nitrate | 硝酸盐毫克每升 | 25 |
| ph | 酸碱度 | 7.2 |
| temp_c | 水温摄氏度 | 26 |
| temp_change_24h | 二十四小时水温变化摄氏度 | 0.5 |
| cycle_days | 开缸养水天数 | 14 |
| water_change_percent | 单次换水比例 | 30 |
| dechlorinated | 新水是否除氯处理 | true |
| feed_times_per_day | 每日投喂次数 | 2 |
| fed_in_minutes | 投饵吃完用时分钟 | 3 |
| steps | 新鱼入缸操作列表 | 见规则文件 |
| filter_stop_hours | 过滤停转小时数 | 0 |

结论分三档：**先处理**（指标超危险阈值、密度超标、操作触碰红线）、**待确认**（信息不足）、**可照此执行**。存在真实缺陷时即使信息也不完整仍判先处理。

结果写入 `scripts/_last_result.txt`，每条不合格带原因。

## 六、人工确认清单（这步不能省）

- [ ] 开缸养水天数已达周期，且氨氮与亚硝酸盐均归零才逐步下鱼
- [ ] 氨氮、亚硝酸盐在安全范围内
- [ ] 硝酸盐在可控范围，且已安排下一次换水
- [ ] 酸碱度在所选鱼种适生区间内
- [ ] 水温与二十四小时温差均符合要求
- [ ] 单次换水比例在口径内，且新水已做困水或除氯处理
- [ ] 密度换算结果不超标
- [ ] 投喂量与频次在口径内，且吃完用时在三分钟内
- [ ] 新鱼已完整执行过温与过水，未直接把袋子里的水倒进缸里
- [ ] 近期的测水与换水记录能连成趋势

## 七、最常见的坑

1. **开缸第二天就下鱼**。硝化菌还没建立，氨氮直接顶上来，鱼是被自己排泄物毒死的。至少七天，急就要等。
2. **自来水直接加**。余氯会直接损伤鳃组织，同时把好不容易建立的硝化菌一起干掉。
3. **一次换水换一半以上**。看似干净，实际是让鱼一次性承受水质与温度的双重突变，体质稍差当场就出问题。
4. **喂到鱼不再吃为止**。鱼没有饱腹感的节制，吃到撑甚至胀肚。两到三分钟吃完就够了，五分钟还在吃说明投多了。
5. **出差前猛喂一顿**。这是最典型的喂食过量加污染组合，正确做法是提前两天正常喂，临走前停喂，而不是补偿性投喂。
6. **新鱼不过水直接倒**。袋水与缸水的酸碱度和温差可能差出一大截，直接倒等于让鱼硬扛双重打击。
7. **只测酸碱度不测氨氮**。酸碱度看着挺好，氨氮早已超出可承受范围，这是最常见的误判。
8. **过滤一停就是一整天**。硝化菌是需氧菌，滤材干涸或断流超过四小时，整个系统的处理能力会明显倒退。
