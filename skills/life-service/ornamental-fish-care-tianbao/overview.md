# 观赏鱼饲养

你会得到一套**能照着执行的鱼缸水质与喂养管理方案**，包含具体数值和判断阈线。

## 你会得到什么

1. **开缸养水周期**：从空缸到能下鱼的最短天数、不同条件下的路径差异、以及「养水完成」的可执行判据——不是靠天数猜，而是靠氨氮与亚硝酸盐两项都归零来判断。
2. **四项核心水质阈值**：氨氮、亚硝酸盐、硝酸盐、酸碱度各自的正常区间、警戒区间与危险区间。要紧的是前两项：这两项一超标，鱼是先伤鳃后伤内部，等你发现行为异常往往已经晚了。
3. **困水与换水口径**：换水的目的是稀释硝酸盐，不是把水换干净。单次换多少、多久换一次、新水要怎么处理，都给到可执行数值，并说明为什么不能一次换一半以上。
4. **密度换算**：按水体升数乘以鱼种系数算上限，小型热带鱼与金鱼、锦鲤的系数不同——金鱼锦鲤排泄量大，同样体长要的水体明显更多。
5. **过温过水步骤**：袋子要不要开、泡多久、每隔几分钟加多少缸水、总时长多少分钟。这两步省一步，就等于让鱼硬扛温差与水质的双重打击。
6. **投喂口径**：单次以几分钟吃完为准、每天几次、什么情况下必须停喂，以及出差前那一顿到底该不该喂。
7. **记录格式**：测水、换水、异常、死亡四条线的记录模板。**没有记录就看不出趋势，绝大多数「突然死鱼」其实早有趋势。**
8. **校验脚本**：把缸的情况填进 json 跑一遍 `fish_care_check.py`，把超标项、密度超标、操作红线三类问题带原因列出来。

## 典型用法

- 「新缸要养水几天」：给周期和判据两条判据，最短七天，且必须以两项指标归零为准。
- 「自来水能不能直接加」：不能，要困水或做除氯处理，余氯会伤鳃也会杀硝化菌。
- 「我的缸能养几条鱼」：把所有鱼体长加起来乘以鱼种系数，对照水体升数。
- 「水发白发浑怎么办」：区分硝化系统未建立与水过营养两种成因，走不同的处理路径。

## 边界

不给任何药物的名称、剂量与疗程，涉及鱼病请咨询专业水族从业人员或水产兽医。不判断鱼患的是什么病，只给「先隔离、保水质、停喂、联系专业人员」的处置顺序与判断清单。不承诺养殖结果，活体损耗受运输、种源、季节与实际操作多重影响。
