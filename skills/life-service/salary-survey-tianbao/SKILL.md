# 薪酬调研分析（salary-survey）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：生成薪酬调研方案与数据分析：职位匹配、样本渠道、分位值（P25/P50/P90）、内外部公平性诊断与调薪建议，对接BOSS直聘等渠道行情。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 薪酬调研
- 薪资报告
- 薪酬对标
- 市场分位
- 调薪依据
- 薪酬带宽

## 三、工作流
1. 界定对标职位与层级
2. 确定样本渠道与样本量
3. 采集市场数据（P25/P50/P90）
4. 内部公平性（级差/重叠度）诊断
5. 形成调薪与带宽建议

## 四、核心内容（检查清单与判定）
薪酬调研应以同质职位对标；常用分位值描述市场分布，P50为中位值；内部需关注相邻职级级差与带宽重叠合理性。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未界定对标职位/层级 | 调研 |
| Q2 | WARN | 样本量/渠道不足 | 样本 |
| Q3 | FAIL | 未算市场分位值 | 分位 |
| Q4 | WARN | 缺内部公平性诊断 | 公平性 |
| Q5 | FAIL | 无调薪/带宽建议输出 | 结论 |

> 脚本 `salary-survey_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python salary-survey_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python salary-survey_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
