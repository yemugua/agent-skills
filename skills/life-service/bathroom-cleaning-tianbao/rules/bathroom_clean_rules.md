# 卫生间清洁规则表

生成清洁方案前先读本文件，不要凭印象写。

---

## 一、六类污渍识别与处理

| 污渍类型 | 外观与位置 | 主要成因 | 处理方向 |
|---|---|---|---|
| 水垢 | 白色或灰白色硬质沉积，集中在水龙头、淋浴玻璃、瓷砖缝 | 水中矿物质析出 | 需酸性或专用除垢剂，必须先查材质 |
| 皂垢 | 白色或淡黄滑腻沉积，集中在台面边缘、浴缸边、皂缸 | 脂肪酸与水中矿物质结合 | 中性清洁剂加温水软化；严重时用专用皂垢清洁剂 |
| 霉斑 | 黑色、绿色或灰黑斑，集中在瓷砖缝、墙角、密封胶处 | 长期潮湿与不通风 | 除霉处理并解决潮湿来源 |
| 锈渍 | 橙褐色或深褐色斑点，集中在金属件、水龙头、螺栓处 | 铁件氧化 | 轻者用中性除锈；严重时更换件 |
| 尿碱 | 黄色或黄褐色结晶，主要在马桶内壁与小便斗 | 尿液中的物质沉积 | 酸性清洁剂为主，必须避开铝合金与彩色金属件 |
| 油污 | 黏腻油膜，集中在洗手台周边、镜子边缘 | 洗手与烹饪带入 | 中性去油清洁剂 |

### 判断方法

- 白且硬、能刮下 → 多为水垢
- 白且滑腻、擦得掉 → 多为皂垢
- 黑绿且有霉味 → 霉斑
- 橙褐且在金属上 → 锈渍
- 黄色结晶且集中在马桶 → 尿碱
- 黏腻成膜 → 油污

## 二、按区域分频次

| 区域 | 建议频次 | 重点 |
|---|---|---|
| 台面 | 每日或每次使用后擦一次 | 水渍与皂垢，及时擦最省力 |
| 镜面 | 每周 | 水渍与手印 |
| 马桶 | 每周；内壁尿碱严重时增加 | 刷洗与除垢分开处理 |
| 浴缸 | 每周 | 皂垢与水垢 |
| 地漏 | 每周 | 毛发与污垢，避免堵塞与异味 |
| 瓷砖缝 | 每月；霉变后按需增加 | 发黑与霉斑 |
| 淋浴玻璃 | 每周 | 水垢，需专用除垢 |
| 排气扇 | 每季度 | 油污与灰尘 |

**通用原则**：水渍及时擦比定期除垢省力得多。台面每次用完擦干，能大幅减少后续水垢与皂垢的量。

## 三、材质禁忌清单

| 材质或部位 | 禁忌 | 原因 |
|---|---|---|
| 大理石、天然石 | 严禁酸性清洁剂 | 会被腐蚀，造成永久失去光泽与质感损伤 |
| 彩色金属件（烤漆、彩色电镀） | 强酸强碱 | 表面镀层会被腐蚀变色 |
| 亚克力、有机玻璃 | 钢丝球、硬质刷具 | 会划伤表面，产生永久划痕 |
| 铝制品 | 洁厕剂、强酸 | 会被腐蚀发白、起斑 |
| 彩色金属件与铝制品 | 洁厕剂 | 洁厕剂多为强酸，会腐蚀变色 |
| 任何表面 | 含氯消毒剂与酸性清洁剂混合 | 产生有毒气体，刺激呼吸道 |
| 含氯消毒剂 | 与碱性清洁剂混合 | 同样不属于安全配对 |
| 不锈钢 | 强酸使用后及时冲净 | 长时间接触会腐蚀产生锈斑 |
| 木质部件 | 长时间浸水 | 会膨胀变形、开裂 |

**通用要求**：

- 一次只用一种清洁剂，用完冲净再换下一种
- 清洁剂保持原包装，不分装到不明容器
- 含氯消毒剂与酸性清洁剂不混用
- 在不显眼处先试用，观察有无变色或损伤

## 四、除垢原理与等待时间

**原理**：除垢剂通过与水垢（碳酸盐类沉积）反应使其溶解，需要保持湿润接触才能有效。

**通用步骤**：

1. 按产品说明书喷洒或涂抹
2. 保持湿润接触，按说明书规定的时间等待
3. 等待期间不要擦掉
4. 用软布或刷具处理
5. 用清水彻底冲净

具体等待时间以产品说明书为准，不同产品配方差异很大，不要套用别家的数值。原则是按说明书时间等待，不要立即擦掉。

**处理顺序**：先冲水去掉表面浮层，让除垢剂能接触到水垢本体。

## 五、马桶黄渍处理

马桶黄渍通常是尿碱沉积，判断依据是黄色或黄褐色的结晶状附着。

1. 先用清水冲洗，去掉浮层
2. 用适合马桶材质的除垢剂，按说明书喷洒在黄渍处
3. 保持接触，按说明书时间等待
4. 用马桶刷轻刷；黄渍顽固处可重复
5. 彻底冲净

**注意事项**：

- 洁厕剂是强酸类，使用前确认洁具材质与颜色不受影响
- 铝合金、彩色金属件与亚克力附件不可用洁厕剂
- 马桶水箱内的水垢需打开水箱盖处理，处理后确认盖已盖紧
- 长时间未使用的马桶，水箱内可能有无生物，处理时注意开盖后的防护

## 六、淋浴玻璃水垢处理

| 步骤 | 动作 | 说明 |
|---|---|---|
| 1 | 冲水 | 去掉表面浮层 |
| 2 | 涂专用除垢剂 | 按说明书，用量以覆盖水垢为准 |
| 3 | 等待 | 按说明书时间，保持湿润接触 |
| 4 | 轻擦 | 用软布或专用海绵，不用钢丝球或硬质刮片 |
| 5 | 彻底冲净 | 防止残留形成新的沉积 |
| 6 | 保持干燥 | 擦干可减少后续水垢累积 |

**预防**：每次用完淋浴后刮掉表面水膜或开窗通风，能显著减少水垢累积量。

## 七、必须叫师傅的四种情形

1. 排水堵塞（排水慢、返水、需疏通主管）
2. 防水层问题（墙根渗水、楼下有水印、闭水试验异常）
3. 隐蔽管道渗漏（水从墙面或地面渗出、找不到明确来源）
4. 严重水垢导致排水慢需拆洁具

## 八、常见误判清单

1. 含氯消毒液和洁厕灵一起倒进马桶——产生有毒气体
2. 用酸性清洁剂擦大理石台面——永久失去光泽
3. 亚克力用钢丝球——永久划痕
4. 水垢当皂垢处理——选错方法白花时间
5. 喷上除垢剂立刻擦掉——需要接触时间
6. 洁厕剂用在铝合金或彩色件上——腐蚀发白起斑
7. 只擦表面不处理瓷砖缝——异味与发黑来源
8. 排水慢还继续倒清洁剂——机械问题清洁剂解决不了
9. 卫生间长期不通风——霉斑反复的根本原因
10. 以为卫生间味道是清洁问题——有渗水痕迹应先排查来源
