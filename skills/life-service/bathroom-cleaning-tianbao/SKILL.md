# 卫生间清洁与除垢核查（bathroom-cleaning）

卫生间清洁最贵的两类错误：**污渍类型判错导致用错方法损伤表面**，以及**清洁剂混用产生有害气体**。前者是长期累积的小损伤，后者是当下的真实危险。

所以这个技能的核心是两件事：**先判污渍类型，再查材质禁忌**。

这个技能做四件事：**按区域分频次** → **按污渍类型处理** → **守住材质禁忌** → **判断何时必须叫师傅**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 区分六类污渍并给出对应处理 | ❌ 用强酸强碱处理不明成分的污渍 |
| 给出按区域的清洁频次建议 | ❌ 使用与材质不匹配的清洁剂 |
| 列出材质禁忌清单 | ❌ 代替管道疏通与防水处理 |
| 说明除垢原理与等待时间 | ❌ 拆装洁具与拆洁具内部 |
| 说明何时必须叫师傅 | ❌ 判断隐蔽管道与防水层问题 |

**遇到以下情况，停止自行处理，联系专业人员：**

- **排水堵塞**：排水慢、返水、需要疏通主管
- **防水层问题**：墙根渗水、楼下有水印、闭水试验异常
- **隐蔽管道渗漏**：水从墙面或地面渗出、找不到明确来源
- **严重水垢导致排水慢需拆洁具**：需要拆装马桶或面盆才能处理

## 三、六类污渍的识别与处理

**这一步是全技能的关键。判错类型，用错方法，会损伤表面。**

| 污渍类型 | 外观与位置 | 主要成因 | 处理方向 |
|---|---|---|---|
| **水垢** | 白色或灰白色硬质沉积，集中在水龙头、淋浴玻璃、瓷砖缝 | 水中的矿物质析出 | 需要酸性或专用除垢剂，**必须先查材质** |
| **皂垢** | 白色或淡黄滑腻沉积，集中在台面边缘、浴缸边、皂缸 | 脂肪酸与水中矿物质结合 | 中性清洁剂加温水软化；严重时用专用皂垢清洁剂 |
| **霉斑** | 黑色、绿色或灰黑斑，集中在瓷砖缝、墙角、密封胶处 | 长期潮湿与不通风 | 除霉处理并解决潮湿来源 |
| **锈渍** | 橙褐色或深褐色斑点，集中在金属件、水龙头、螺栓处 | 铁件氧化 | 轻者用中性除锈；严重时更换件 |
| **尿碱** | 黄色或黄褐色结晶，主要在马桶内壁与 Urinal 小便斗 | 尿液中的物质沉积 | 酸性清洁剂为主，**必须避开铝合金与彩色金属件** |
| **油污** | 黏腻油膜，集中在洗手台周边、镜子边缘 | 洗手与烹饪带入 | 中性去油清洁剂 |

**判断方法：**

- **白且硬、能刮下** → 多为水垢
- **白且滑腻、擦得掉** → 多为皂垢
- **黑绿且有霉味** → 霉斑
- **橙褐且在金属上** → 锈渍
- **黄色结晶且集中在马桶** → 尿碱
- **黏腻成膜** → 油污

## 四、按区域分频次

| 区域 | 建议频次 | 重点 |
|---|---|---|
| 台面 | 每日或每次使用后擦一次 | 水渍与皂垢，及时擦最省力 |
| 镜面 | 每周 | 水渍与手印 |
| 马桶 | 每周；内壁尿碱严重时增加 | 刷洗与除垢分开处理 |
| 浴缸 | 每周 | 皂垢与水垢 |
| 地漏 | 每周 | 毛发与污垢，避免堵塞与异味 |
| 瓷砖缝 | 每月；霉变后按需增加 | 发黑与霉斑 |
| 淋浴玻璃 | 每周 | 水垢，需专用除垢 |
| 排气扇 | 每季度 | 油污与灰尘 |

**一条通用原则**：**水渍及时擦比定期除垢省力得多**。台面每次用完擦干，能大幅减少后续水垢与皂垢的量。

## 五、材质禁忌清单（这一节最重要）

| 材质或部位 | 禁忌 | 原因 |
|---|---|---|
| **大理石、天然石** | ❌ **严禁酸性清洁剂** | 酸性会腐蚀石材表面，造成永久失去光泽与质感损伤 |
| **彩色金属件**（烤漆、彩色电镀） | ❌ 强酸强碱 | 表面镀层会被腐蚀变色 |
| **亚克力、有机玻璃** | ❌ 钢丝球、硬质刷具 | 会划伤表面，产生永久划痕 |
| **铝制品** | ❌ 洁厕剂、强酸 | 会被腐蚀发白、起斑 |
| **彩色金属件与铝制品** | ❌ 洁厕剂 | 洁厕剂多为强酸，会腐蚀变色 |
| **任何表面** | ❌ **含氯消毒剂与酸性清洁剂混合** | 产生有毒气体，刺激呼吸道 |
| **含氯消毒剂** | ❌ 与碱性清洁剂混合 | 同样不属于安全配对 |
| **不锈钢** | ⚠️ 强酸使用后及时冲净 | 长时间接触会腐蚀产生锈斑 |
| **木质部件** | ❌ 长时间浸水 | 会膨胀变形、开裂 |

**通用要求**：

- 一次只用一种清洁剂，用完冲净再换下一种
- 清洁剂保持原包装，不分装到不明容器
- 任何含氯消毒剂与酸性清洁剂不混用
- 在不显眼处先试用，观察有无变色或损伤

## 六、除垢的原理与等待时间

**除垢产品需要接触时间才能起效，这是最容易被忽略的一点。**

**原理**：除垢剂通过与水垢（碳酸盐类沉积）反应使其溶解，需要保持湿润接触才能有效。喷上立刻擦掉，效果会大幅下降。

**通用原则**：

1. 按产品说明书喷洒或涂抹
2. **保持湿润接触，按说明书规定的时间等待**
3. 等待期间不要擦掉
4. 用软布或刷具处理
5. **用清水彻底冲净**

**时间说明**：具体等待时间以**产品说明书**为准。不同产品配方差异很大，不要套用别家的数值。原则是"**按说明书时间等待，不要立即擦掉**"。

**处理顺序**：先冲水 → 再上除垢剂 → 等待 → 轻擦 → 彻底冲净。先冲水是为了去掉表面浮层，让除垢剂能接触到水垢本体。

## 七、马桶黄渍的处理

马桶黄渍通常是尿碱沉积，判断依据是黄色或黄褐色的结晶状附着。

**处理步骤：**

1. 先用清水冲洗，去掉浮层
2. 用适合马桶材质的除垢剂，按说明书喷洒在黄渍处
3. 保持接触，按说明书时间等待
4. 用马桶刷轻刷；黄渍顽固处可重复
5. 彻底冲净

**注意事项**：

- **洁厕剂是强酸类**，使用前确认洁具材质与颜色不受影响
- **铝合金、彩色金属件与亚克力附件不可用洁厕剂**
- 马桶水箱内的水垢需打开水箱盖处理，处理后确认盖已盖紧
- 长时间未使用的马桶，水箱内可能有无生物，处理时注意开盖后的防护

## 八、淋浴玻璃水垢的处理

| 步骤 | 动作 | 说明 |
|---|---|---|
| 1 | 冲水 | 去掉表面浮层 |
| 2 | 涂专用除垢剂 | 按说明书，用量以覆盖水垢为准 |
| 3 | 等待 | 按说明书时间，让除垢剂保持湿润接触 |
| 4 | 轻擦 | 用软布或专用海绵，**不用钢丝球或硬质刮片** |
| 5 | 彻底冲净 | 防止残留形成新的沉积 |
| 6 | 保持干燥 | 擦干可减少后续水垢累积 |

**预防**：每次用完淋浴后刮掉表面水膜或开窗通风，能显著减少水垢累积量。

## 十、脚本用法

```bash
python scripts/bathroom_clean_check.py --text "马桶有黄渍，淋浴玻璃有水垢"
python scripts/bathroom_clean_check.py --pair "含氯消毒液" "洁厕灵"
python scripts/bathroom_clean_check.py --file 情况.json --out 结果.md
```

| 参数 | 说明 |
|---|---|
| `--text` | 直接描述卫生间污渍情况 |
| `--file` | 从文件读，支持 `.txt` / `.md` / `.json`（JSON 用 `{"desc": "..."}`） |
| `--pair` | 检查两种清洁剂的配对，输出 danger / warn / ok |
| `--out` | 结果输出路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本做三件事：匹配六类污渍类型、按涉及的材质给出禁忌提示、检查清洁剂配对与安全红线。

> 脚本是关键词匹配，**不等于现场判断**。污渍类型要靠看与摸确认，材质要靠查。

## 十一、人工确认清单（这步不能省）

- [ ] 已确认污渍类型（水垢、皂垢、霉斑、锈渍、尿碱、油污）
- [ ] 已确认涉及的材质（天然石、金属、亚克力、铝、彩色件）
- [ ] 已核对材质禁忌清单，确认所用清洁剂不冲突
- [ ] 含氯消毒剂未与酸性清洁剂混合
- [ ] 除垢剂已按说明书时间等待，未立即擦掉
- [ ] 除垢后已用清水彻底冲净
- [ ] 已确认未使用钢丝球处理亚克力与玻璃
- [ ] 已确认未使用酸性清洁剂处理大理石
- [ ] 地漏毛发已清理，排水正常
- [ ] 已确认不属于"必须叫师傅"的四种情形

## 十二、最常见的坑

**坑一：把含氯消毒液和洁厕灵一起倒进马桶。**
会产生有毒气体。这是明确的安全红线，**含氯和酸性，永远不混**。

**坑二：用酸性清洁剂擦大理石台面。**
石材会被腐蚀，造成永久失去光泽。这一条最常见，因为很多人不知道自己的台面是天然石。

**坑三：亚克力用钢丝球。**
会划伤表面留下永久划痕，亚克力盆与淋浴房挡水板尤其要注意。

**坑四：水垢当皂垢处理。**
白且硬能刮下是水垢，白且滑腻是皂垢。选错方法会白花时间。

**坑五：喷上除垢剂立刻擦掉。**
除垢剂需要接触时间才起效，立即擦掉效果大幅下降。

**坑六：洁厕剂用在铝合金或彩色件上。**
会被腐蚀发白起斑。

**坑七：只擦表面不处理瓷砖缝。**
缝里的霉斑与污垢是异味与发黑的来源，且擦完还会再长。

**坑八：排水慢还继续用清洁剂硬冲。**
排水堵塞是需要处理的机械问题，清洁剂解决不了，反复倒清洁剂只是污染。

**坑九：卫生间长期不通风。**
通风不足是霉斑反复的根本原因，不解决这个，清洁只是暂时的。

**坑十：以为卫生间味道是清洁问题。**
有渗水痕迹或楼下有水印时，应先按渗漏排查流程定位来源。
