# 副业时间预算与投入产出规则库

## 一、真实可用小时怎么算（不能用理想值）

```
每周可用小时 = 工作日每天可用小时 × 工作日数 + 周末每天可用小时 × 2
每周可用小时（保守）= 上式 × 0.7        ← 扣掉加班、应酬、家庭突发
每周交付小时 = 每周可用小时 - 每周运营小时
每周运营小时 = 获客 + 内容 + 沟通 + 改稿 + 售后
```

| 来源 | 取值口径 | 注意 |
|---|---|---|
| 工作日每天 | 按过去四周**实际**发生的空闲时间中位数 | 不是「我想每天做两小时」 |
| 周末每天 | 单日不超过 5 小时 | 周末全天做副业通常撑不过一个月 |
| 保守系数 | 0.7 | 有小孩、经常加班、通勤长的取 0.6 |
| 运营小时 | 技能交付型 3-5 小时/周；内容型 5-8 小时/周 | **获客时间最容易被漏算** |

**红线**：每周可用小时（保守后）低于 5 小时，不建议启动——产能太低，连获客都跑不通。
**上限**：每周超过 20 小时，主业与健康大概率先出问题。

## 二、产能与收入公式

```
每周产能单数 = 每周交付小时 ÷ 单均交付耗时
每周毛收入   = 产能 × 单价
每周变动成本 = 产能 × 单均成本
每周净收入   = 每周毛收入 - 每周变动成本 - (月固定成本 ÷ 4.33)
月净收入     = 每周净收入 × 4.33
单位时间收益 = 每周净收入 ÷ 每周可用小时
回本周期(月) = 累计已投成本 ÷ 月净收入      ← 月净收入 ≤ 0 时为无法回本
```

> 月固定成本按 4.33 周/月折算，不要用 4——会低估成本。

## 三、本职时薪（对比基准）

```
本职时薪 = 月到手收入 ÷ (月工作天数 × 日均实际投入小时)
```

日均实际投入小时一般按 **9-10 小时**算（含通勤、加班、待命），不是 8 小时。
按 8 小时算会高估本职时薪，导致副业被误判为不划算。

## 四、判定档位

| 单位时间收益 ÷ 本职时薪 | 判定 | 动作 |
|---|---|---|
| ≥ 1.5 | 可启动 | 按计划推进，先做 3 单验证 |
| 1.0 - 1.5 | 谨慎启动 | 先小步试，控制投入 |
| 0.6 - 1.0 | 不划算 | 除非有技能沉淀或转行价值，否则不做 |
| < 0.6 | 不启动 | 在贱卖时间 |
| 月净收入 ≤ 0 | 不启动 | 模型本身不成立 |

## 五、试错成本上限

```
试错成本上限 = 月可支配结余 × 试错月数 × 风险系数
```

| 参数 | 口径 | 常见值 |
|---|---|---|
| 月可支配结余 | 月收入 - 固定支出 - 应急金定投 | 先备 3-6 个月生活费 |
| 试错月数 | 愿意给的时间窗口 | 3-6 个月 |
| 风险系数 | 探索性支出不满仓 | 0.3；重资产最多 0.5 |

| 已投 ÷ 上限 | 处置 |
|---|---|
| < 50% | 正常推进 |
| 50% - 100% | 暂停新增投入，只看数据 |
| > 100% | 立即停手并复盘 |

**禁止**：动用应急金、借款、信用卡套现、抵押、挪用家庭刚性支出资金。

## 六、止损线（启动前写死，五项）

| 类型 | 触发条件 | 动作 |
|---|---|---|
| 时间止损 | 连续 4 周实际投入 < 计划 50% | 排不动就收缩或换赛道 |
| 收入止损 | 连续 3 个月月净收入 < 目标 30% | 停投，复盘获客 |
| 回本止损 | 实际回本周期 > 计划 1.5 倍 | 停投 |
| 主业止损 | 主业绩效下滑或被约谈 | 立刻停 |
| 健康止损 | 连续两周睡眠 < 6 小时 | 立刻降量 |

## 七、四类副业门槛表

| 类型 | 启动资金 | 见收益周期 | 产能天花板 | 主要风险 |
|---|---|---|---|---|
| 技能交付型 | 0-2000 元 | 1-4 周 | 受交付时间限制，明显 | 获客不稳、议价低、尾款难收 |
| 内容资产型 | 0-3000 元 | 3-12 个月 | 边际成本低，天花板高 | 长期无反馈、平台规则变化 |
| 商品交易型 | 3000-30000 元 | 1-3 个月 | 受备货与资金限制 | 库存、退货、资金占用 |
| 资源撮合型 | 低-中 | 2-6 个月 | 依赖人脉 | 合规风险最高 |

**上班族优先技能交付型**：可随时收缩、不用备货、见收益快。

## 八、合规红线（七项）

1. **竞业限制**：劳动合同有约定的，先确认范围、地域与期限
2. **资质许可**：食品、教育培训、医疗器械、金融中介、出版物等需取得资质
3. **公司资源**：不得使用公司设备、工作时间、客户名单、商业秘密
4. **税务申报**：达到申报规模的，按现行税法与税务机关要求办理
5. **主体登记**：持续经营的，按市场监管部门要求办理登记
6. **知识产权**：不使用未授权的字体、图片、音乐、课程内容
7. **宣传合规**：不做虚假宣传、不刷单、不虚构销量与评价

## 九、启动前最小验证（三步）

```
第 1 单：验证交付流程跑得通，记录实际耗时（对比预估，通常超 30%-50%）
第 2 单：验证获客渠道可复制，记录获客耗时与成本
第 3 单：验证能否按时交付且不影响主业，记录实际时间占用
三单跑完再决定是否追加投入。
```

**实际交付耗时通常比预估高 30%-50%**，第一次报价前务必先自测一遍。
