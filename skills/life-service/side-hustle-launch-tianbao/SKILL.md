# 副业启动规划与时间投入核算（side-hustle-launch）

副业最容易踩的坑不是选错项目，而是**时间算错**：每周能挤出 10 小时，扣掉获客、沟通、改稿，真正能交付的只有 4 小时，算下来单位时间收益还不如加班费。

这个技能做三件事：**算时间 → 算单位时间收益 → 定试错上限与止损线**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 按你给的参数核算产能、收益、回本周期 | ❌ 推荐「稳赚」的副业项目或承诺收益 |
| 给出试错成本上限与止损线的设定口径 | ❌ 提供绕过竞业限制、偷税漏税的操作方案 |
| 对比四类副业的启动门槛与周期特征 | ❌ 代替劳动合同、竞业协议的具体条款判断 |
| 指出主业冲突、资质、税务等风险点 | ❌ 代替税务、法务、人社部门的专业意见 |
| 输出启动前自查清单 | ❌ 建议挪用应急资金或举债投入 |

**必须停下来做专业确认的情形：**
- 劳动合同里有**竞业限制条款**，或副业与本行业务存在竞争关系 —— 先确认条款范围与期限，必要时咨询律师
- 副业涉及**需要许可或资质的经营**（食品、教育培训、医疗器械、金融中介、出版物等）—— 未取得资质不得经营
- 副业收入达到需要申报的规模 —— 按现行税法与当地税务机关要求办理
- 需要注册个体工商户或公司 —— 以市场监管部门与税务部门的要求为准
- 副业可能影响主业绩效或涉及公司资源使用 —— **不得使用公司设备、客户名单、工作时间做副业**

## 二、完整工作流

```
第 1 步  过合规红线：竞业限制、资质许可、税务申报、公司资源使用四项
第 2 步  先读 rules/time_budget_rules.md，再按 §1 算每周真实可用小时
第 3 步  选赛道：按 §3 四类副业门槛表，挑与「技能/时间/启动资金」匹配的
第 4 步  收集参数：单价、单均交付耗时、单均成本、每周运营小时、启动投入
第 5 步  跑脚本核算：python scripts/side_hustle_calc.py --file hustle.json
第 6 步  看四个数：单位时间收益、月净收入、回本周期、试错投入占比
第 7 步  定止损线：连续 3 个月月净收入低于目标 30% 即停（见 §5）
第 8 步  小步试：先做 3 单验证交付与获客，再决定是否加投入
```

**顺序不能颠倒**：第 1 步没过，后面算得再好也不能启动。

## 三、核算链（六个数，一个都不能跳）

```
① 每周可用小时   = 工作日每天小时 × 工作日数 + 周末每天小时 × 2
② 每周交付小时   = 每周可用小时 - 每周运营小时（获客/内容/沟通/售后）
③ 每周产能单数   = 每周交付小时 ÷ 单均交付耗时
④ 每周净收入     = 产能 × (单价 - 单均成本) - 月固定成本 ÷ 4.33
⑤ 单位时间收益   = 每周净收入 ÷ 每周可用小时          ← 最关键的一个数
⑥ 回本周期(月)   = 累计已投成本 ÷ 月净收入
```

**单位时间收益是这个核算链的答案。** 把它和本职时薪放一起比：

| 单位时间收益 vs 本职时薪 | 判定 | 说明 |
|---|---|---|
| ≥ 1.5 倍 | 可启动 | 明显划算，值得投入 |
| 1.0 - 1.5 倍 | 谨慎启动 | 略高于本职，但要考虑稳定性 |
| 0.6 - 1.0 倍 | 不划算 | 除非有技能沉淀或转行价值 |
| < 0.6 倍 或 ≤ 0 | 不启动 | 纯粹在贱卖时间 |

**本职时薪怎么算**：`月到手 ÷ (月工作天数 × 日均投入小时)`。很多人只拿月薪除以 21.75×8，忽略了每天实际投入 10 小时——按 10 小时算，本职时薪会低一大截，副业才有可比性。

## 四、试错成本上限（这步决定你会不会伤筋动骨）

```
试错成本上限 = 月可支配结余 × 试错月数 × 风险系数(0.3)
```

| 参数 | 口径 | 常见取值 |
|---|---|---|
| 月可支配结余 | 月收入 - 固定支出 - **应急金定投** | 先留 3-6 个月生活费再谈副业 |
| 试错月数 | 你愿意给这个副业的时间窗口 | 3-6 个月 |
| 风险系数 | 副业属于探索性支出，不宜满仓 | **0.3**，重资产可到 0.5 |

**硬规则**：试错投入**不得超过应急金**，不得借款、不得刷信用卡套现、不得挪用房贷与教育资金。

| 已投 ÷ 上限 | 处置 |
|---|---|
| < 50% | 正常，可继续小步试 |
| 50% - 100% | 收紧，暂停新增投入，只看数据 |
| > 100% | **立即停手**，进入复盘，不再追加 |

## 五、止损线（先定好，才不会越陷越深）

止损线要在**启动前**写下来，用数字而不是感觉：

| 止损触发条件 | 阈值 | 动作 |
|---|---|---|
| 时间止损 | 连续 4 周实际投入 < 计划投入的 50% | 说明排不动，收缩或换赛道 |
| 收入止损 | 连续 3 个月月净收入 < 目标月收入的 30% | 停投，复盘获客环节 |
| 回本止损 | 实际回本周期 > 计划回本周期的 1.5 倍 | 停投 |
| 主业止损 | 主业绩效下滑或被约谈 | **立刻停**，优先级永远在主业之上 |
| 健康止损 | 连续两周睡眠 < 6 小时 | 立刻降量 |

> 副业的第一目标不是赚钱，是**不要影响主业**。主业受影响的代价，远大于副业可能的收益。

## 六、四类副业的门槛对比

| 类型 | 代表 | 启动资金 | 见收益周期 | 时间特征 | 主要风险 |
|---|---|---|---|---|---|
| **技能交付型** | 设计、剪辑、翻译、代写、咨询 | 极低（0-2000 元） | 1-4 周（有渠道的话） | 交付耗时大，产能有天花板 | 获客不稳、议价低、尾款 |
| **内容资产型** | 公众号、短视频、小红书、专栏 | 低（0-3000 元） | 3-12 个月 | 前期投入大、后期边际成本低 | 长期无反馈、平台规则变化 |
| **商品交易型** | 电商、二手、代购、手作 | 中（3000-30000 元） | 1-3 个月 | 备货与客服占用大量时间 | 库存、退货、资金占用 |
| **资源撮合型** | 中介、代理、社群、渠道合作 | 低-中 | 2-6 个月 | 依赖人脉与信任积累 | 合规风险最高、依赖个人信用 |

**上班族首选技能交付型**：启动资金低、见收益快、不用备货、可随时收缩。缺点是产能有天花板——**这正好可以用核算链算清楚**。

## 七、脚本用法

```bash
python scripts/side_hustle_calc.py --file hustle.json --out 副业投入产出核算.md
python scripts/side_hustle_calc.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON，见下方结构 |
| `--text` | 直接给 JSON 字符串 |
| `--out` | 结果写入文件，默认 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检 |

输入 JSON：

```json
{
  "name": "周末约拍",
  "weekday_hours": 1.5,
  "workdays": 5,
  "weekend_hours": 4,
  "ops_hours_per_week": 3,
  "price": 300,
  "unit_cost": 40,
  "delivery_hours": 3,
  "monthly_fixed_cost": 200,
  "startup_cost": 1500,
  "monthly_surplus": 3000,
  "trial_months": 3,
  "day_job_hourly": 80,
  "target_monthly_income": 2000
}
```

| 字段 | 说明 |
|---|---|
| `weekday_hours` / `workdays` / `weekend_hours` | 工作日每天可用小时、工作日数、周末每天可用小时 |
| `ops_hours_per_week` | 每周获客、内容、沟通、售后时间 |
| `price` / `unit_cost` / `delivery_hours` | 单价、单均成本、单均交付耗时（小时） |
| `startup_cost` | 累计已投入成本 |
| `monthly_surplus` / `trial_months` | 月可支配结余、试错月数 |
| `day_job_hourly` | 本职时薪，用于对比 |

脚本输出：每周可用小时、产能、周净收入、月净收入、单位时间收益、与本职时薪的比值、回本周期、试错成本上限与投入占比、启动判定、止损触发检查，以及时间过载、获客时间过少、投入超上限、回本超期等提醒。

> 脚本按你填的参数做静态核算，**不预测市场、不承诺收益**。

## 八、人工确认清单（这步不能省）

- [ ] 劳动合同里的竞业限制条款已确认，副业不在限制范围内
- [ ] 副业不属于需要许可或资质的经营，或已取得相应资质
- [ ] 不使用公司设备、工作时间、客户名单与公司资源
- [ ] 每周可用小时按**实际能排进去**的时间算，不是理想值
- [ ] 已留足 3-6 个月生活费的应急金，试错资金不来自应急金
- [ ] 试错投入未超过月可支配结余 × 试错月数 × 0.3
- [ ] 止损线已写成数字并写下来（时间、收入、回本、主业、健康五项）
- [ ] 已先做 3 单验证交付流程与获客成本
- [ ] 收入达到申报规模的，已了解税务申报要求

## 九、最常见的坑

**坑一：只算交付时间，不算获客时间。**
错误做法：每单 3 小时，每周 10 小时，觉得能做 3 单。正确做法：扣掉获客、沟通、改稿、售后每周至少 3-5 小时，实际产能只有 1-2 单。**副业里最贵的是获客时间，不是交付时间。**

**坑二：用「感觉每周能挤出 10 小时」做规划。**
错误做法：按理想状态排 10 小时，两周后一天都排不进去。正确做法：按过去四周**实际发生**的空闲时间打七折，再减去不可控的加班与家庭事项。

**坑三：不跟本职时薪比，只看「一个月多赚两千」。**
错误做法：月入 2000 觉得挺好。正确做法：算单位时间收益。如果每月投入 40 小时赚 2000，单位时间收益 50 元，低于本职时薪 80 元——这是在贱卖时间。**除非这个项目有技能沉淀或转行价值，否则不划算。**

**坑四：没有止损线，做了一年还在投。**
错误做法：「再坚持一下就好了」，一直追加投入。正确做法：启动前写死止损线——连续 3 个月月净收入低于目标 30% 就停。**感觉会骗人，数字不会。**

**坑五：拿应急金去试错。**
错误做法：把 6 个月生活费拿出一半进货。正确做法：试错上限 = 月可支配结余 × 试错月数 × 0.3，且不得动用应急金、不得借款。副业亏光不影响生活，才叫试错。

**坑六：忽略竞业限制与资质要求。**
错误做法：在本行业接私活，觉得没人知道。正确做法：先确认劳动合同条款；涉及食品、教育培训、医疗器械、金融中介等需要资质的领域，未取得资质不得经营。**被追究的代价远大于副业收入。**

**坑七：用公司资源做副业。**
错误做法：用公司电脑、公司客户名单、上班时间接单。正确做法：设备、时间、客户资源全部自有。这类行为一旦被发现，后果不只是丢副业。

**坑八：一上来就备货、租场地、做品牌。**
错误做法：还没卖出第一单，先花两万装修工作室。正确做法：先做 3 单验证交付与获客，跑通再追加。副业的正确顺序是**先验证，再投入**。

**坑九：把所有空闲时间填满。**
错误做法：下班后 4 小时 + 周末全天都在做副业。正确做法：留出休息与家庭时间，副业是长跑。每周超过 20 小时的副业，通常撑不过三个月。
