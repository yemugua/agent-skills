# 咪咕视频离线留存与版权边界 信息采集表

> 不确定的项留空或写「不清楚」，不要猜。留空会被判「待补正」，不影响运行。
> **第一项「内容归属」最关键** —— 它决定能不能下载，也决定后面推荐哪些途径。

## 一、权属与授权（决定能不能下）

| 字段 | 值 |
| --- | --- |
| 内容归属 | 自己运营的账号 / 已授权素材 / 第三方作品 |
| 有无授权 | 是 |
| 授权范围 | 授权怎么写的，覆盖哪些用途 |
| 作者设置 | 对方是否开放了保存权限 |
| 账号类型 | 公开账号 / 私密账号 / 仅粉丝可见 |
| 是否登录可见 | 否 |

## 填写要点

- **报错信息一定要粘原文**。写成「下载失败了」没用，写 `HTTP Error 403` 或 `ffmpeg not found` 才有针对性。
- **ffmpeg 不确定就执行 `ffmpeg -version` 看一眼**。九成的「没声音」都是它没装。
- **本机环境写清操作系统**，不同系统的命令形态不一样。
