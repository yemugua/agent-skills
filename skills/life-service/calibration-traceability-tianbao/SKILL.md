# 计量校准与测量溯源管理（calibration-traceability）

测量是质量的"眼睛"：**证书收了一摞没人核、超期器具还在用、修正值没人看**——数据都是拿失准的器具量出来的。

这个技能做四件事：**建台账** → **核证书** → **判使用** → **控到期**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 讲解溯源管理与证书核查方法 | ❌ 替代法定计量检定结论 |
| 生成台账与到期预警报告 | ❌ 出具校准结论 |
| 整理判定使用与处置口径 | ❌ 保证测量结果准确 |

**涉及贸易结算、安全防护、医疗卫生、环境监测等强制检定目录内的器具，必须依法检定，不得以校准替代。**

**永远不要**用超期、失准的器具出数据——量出来的每个数字都是废品。

## 二、完整工作流

```
第 1 步  明确场景：建台账 / 收新证书 / 判证书 / 到期预警 / 不合格处置
第 2 步  读规则文件 rules/calibration_rules.md
第 3 步  按场景取用：
    - 建台账 → 台账要素（第三节）
    - 核证书 → 六要素核查（第四节）
    - 判使用 → 判定口径（第五节）
    - 控到期 → 预警与处置（第六节）
    - 体检表 → python scripts/calibration_due_check.py --file 器具台账.json
第 4 步  按 templates/计量器具台账.md 输出
第 5 步  人工确认：用途匹配、强制检定范围、修正值落地
```

---

## 三、台账要素（一件一档）

器具名称、型号规格、出厂编号、使用部门/地点、测量范围、用途（关键/一般）、上次校准日期、下次到期日、校准机构、证书编号、状态（合格/限用/停用/报废）、责任人。

---

## 四、证书六要素核查

1. **机构资质**——CNAS 认可标识或法定计量机构资质，校准能力范围覆盖被校器具
2. **器具信息**——名称、型号、编号与实物一致（**贴错证书是高频错误**）
3. **校准依据**——检定规程或校准规范编号
4. **校准结果**——各点示值误差/修正值/不确定度
5. **结论**——校准证书通常只给数据不给"合格"结论；**符合性判定由使用方按使用要求做**
6. **日期与签章**——校准日期、机构章、校准人签字

---

## 五、判定使用口径

| 情形 | 使用判定 |
|---|---|
| 误差 ≤ 使用要求允差 | 正常使用 |
| 误差超差但可修正 | 按修正值使用（在器具/系统内落地修正） |
| 误差超差不可修正 | 限用或停用 |
| 强制检定目录内 | 只认"检定合格"结论，校准数据不能替代 |

> **修正值不落地 = 白校准**：要把修正值写进记录模板、录入数据采集系统，不是锁在证书柜里。

---

## 六、到期预警与不合格处置

- **预警**：提前 30 天预警；关键测量设备提前 60 天
- **到期未校**：立即停用、贴标识、追溯上次合格以来测量的数据
- **不合格处置**：停用 → 追溯已测产品 → 评估影响 → 必要时通知顾客 → 重新校准或报废
- **备机策略**：关键工序设备配备机，避免停产倒逼超期使用

---

## 七、脚本用法（到期预警）

```bash
python scripts/calibration_due_check.py --file "D:\质量\器具台账.json" --warn-days 30
```

脚本输出：**即将到期（30/60 天）、已超期、停用状态、证书要素缺失**四类清单。

> ⚠️ 脚本只做台账结构与日期核算，**不判定器具实际状态**。

---

## 八、人工确认（这步不能省）

- [ ] 用途是否在强制检定目录内
- [ ] 证书与实物编号是否一一对应
- [ ] 修正值是否已在使用端落地
- [ ] 停用/限用标识是否到位
- [ ] 超期期间的数据追溯是否做了
- [ ] 校准机构能力范围是否覆盖

---

## 九、输出结构（固定三段）

1. **溯源状态**——结论先行：台账完整 / 有到期 / 有超期在用
2. **清单**——按到期日排序的预警表
3. **处置建议**——停用、送校、追溯、备机

---

## 十、最常见的坑

**坑一：证书对不上实物。** A 器具的证书贴给 B 器具，编号一查就穿帮。

**坑二：超期凑合用。** "就差两天"——量出来的数据全部存疑。

**坑三：修正值锁柜子里。** 证书显示 +0.02mm 偏差，记录表还在用原值。

**坑四：强制检定用校准顶替。** 贸易结算器具没检定合格证，一查一个准。

**坑五：停用不追溯。** 发现失准后只停用，不追查失准期间量过的产品。
