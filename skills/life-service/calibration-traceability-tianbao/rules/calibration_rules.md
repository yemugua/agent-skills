# 校准溯源规则库（calibration_rules）

> 本文件是 calibration-traceability 技能的规则支撑。强制检定以现行目录为准。

## 一、法规依据速查

| 文件 | 关键要求 | 关联 |
|---|---|---|
| 《中华人民共和国计量法》 | 强制检定目录内器具依法检定 | 法定义务 |
| 实施强制管理的计量器具目录 | 检定范围 | 强检判定 |
| ISO 9001 7.1.5 | 测量溯源、状态标识、失准处置 | 体系要求 |

## 二、台账判定口径

| 字段 | 判定 |
|---|---|
| 下次到期日 | 缺失 WARN |
| 状态 | 合格/限用/停用/报废 缺 WARN |
| 证书编号与实物 | 不一致 FAIL |

## 三、证书六要素

1. 机构资质（CNAS/法定机构，能力范围覆盖）
2. 器具信息与实物一致
3. 校准依据（规程/规范编号）
4. 结果（误差/修正值/不确定度）
5. 符合性判定由使用方做
6. 日期签章齐全

## 四、使用判定口径

| 情形 | 处置 |
|---|---|
| 误差 ≤ 允差 | 正常使用 |
| 超差可修正 | 按修正值使用（须落地） |
| 超差不可修正 | 限用/停用 |
| 强检目录内 | 只认检定合格结论 |

## 五、到期预警口径

| 阈值 | 动作 |
|---|---|
| 60 天 | 关键设备预警 |
| 30 天 | 一般设备预警 |
| 到期 | 停用 + 追溯 + 重新送校 |

## 六、不合格处置

停用 → 追溯失准期间数据 → 评估产品影响 → 必要时通知顾客 → 重新校准/报废。
