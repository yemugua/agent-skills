# 企业文化建设（corporate-culture）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据企业文化建设实践，生成清单：使命愿景价值观梳理、文化行为化与准则、宣贯活动与内部传播、管理者示范与践行、文化评估与迭代。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 企业文化
- 文化建设
- 价值观落地
- 企业文化宣贯
- 文化评估

## 三、工作流
1. 梳理使命愿景价值观
2. 将文化转化为行为准则
3. 开展宣贯活动与内部传播
4. 推动管理者示范践行
5. 定期评估并迭代文化

## 四、核心内容（检查清单与判定）
企业文化不止于口号，须转化为行为准则并由管理者示范；通过宣贯传播与定期评估实现文化落地与迭代。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含使命愿景价值观梳理 | 理念 |
| Q2 | FAIL | 未含文化行为化与准则 | 准则 |
| Q3 | WARN | 未含宣贯活动与内部传播 | 宣贯 |
| Q4 | FAIL | 未含管理者示范与践行 | 示范 |
| Q5 | WARN | 未含文化评估与迭代 | 评估 |

> 脚本 `corporate-culture_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python corporate-culture_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python corporate-culture_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。

## 九、免责声明
