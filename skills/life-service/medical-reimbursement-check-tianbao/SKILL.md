# 医保报销单据核查与拒报复核

## 一句话

回答四个问题：**这四层钱怎么拆的、10 项材料齐不齐、被拒是"政策上根本不该报"还是"手续没跟上"、接下来该找谁要哪句书面答复**。

## 三步上手

1. 用 `templates/费用报销采集表.md` 把这次费用填进来（查不到就留空，脚本标【待现场填写】，不瞎猜）。
2. 跑一次核查：
   ```bash
   python scripts/reimburse_check.py 费用报销采集表.md --json
   ```
   可选 `--base 2026-10-04` 固定基准日。
3. 按报告第九节「待办」执行；要真去窗口的，照 `templates/拒报复核与补正清单.md` 打勾带齐。

## 它算什么

- **费用四层拆解**：总费用 − 目录外自费 = 目录内；− 先行自付 − 起付线 = 可报基数；× 报销比例（再被年度封顶线截断）= 估算可报。
  每一步都把算式写出来，方便你拿结算单逐行对。
- **10 项材料核查**：发票、盖章费用清单、出院小结、诊断证明、病历首页、刷卡记录、转诊单、备案凭证、银行卡信息、已结算盖章复印件——
  每项给「缺了会怎样 + 现在去哪补」。**盖章费用清单是最常漏的一项**，只有发票没清单，医保判定不了哪些进目录，直接退回。
- **拒报归类**：先分「政策上多半不该报」（第三方责任 / 工伤走错险种 / 美容整形 / 体检 / 境外 / 非定点），
  再看「手续没跟上」（未备案 / 无转诊 / 清单没盖章 / 目录外未告知 / 卡状态异常 / 超时 / 重复报销）——
  前者争的是认定，后者多半能救，方向搞反就白跑。
- **复核与申诉路径**：要书面理由 → 复核申请 → 行政复议 / 医保稽核投诉 → 商保单位争议。全程只认**工号、工单号、受理回执**。

## 硬边界（必须遵守）

- **只做算式拆解 + 材料核查 + 路径建议**。不查政策、不编造任何城市的起付线/比例/封顶数字、
  不写材料清单的本地特殊要求，一律写「以参保地医保经办机构现行口径为准」。
- **不承诺能报、不承诺时间、不承诺金额**，只给"按你填的三要素算出来的估算"。
- 不提示任何倒票、代刷、挂床住院、伪造病历发票的做法（属骗保）。
- 涉及身份证号、银行卡号：**不填**，本表只记「有」。

## 文件

- `rules/reimbursement-basics.md`：四种身份、费用四层、三种结算方式（直结 / 手工报销 / 商保）、三个必须自己填的参数
- `rules/document-checklist.md`：出院必拿 10 项材料、门慢特认定、发票原件被收走的补救、最常见三个断链瞬间、断链了去哪补
- `rules/denied-reasons.md`：硬拒与软拒两张表、复核申诉五步、风险红线、该认栽的四种情况
- `templates/费用报销采集表.md`：输入模板
- `templates/报销单据核查报告.md`：输出骨架（九段）
- `templates/拒报复核与补正清单.md`：去窗口的执行清单（含红线与收手条件）
- `scripts/reimburse_check.py`：核查脚本（唯一可执行部分）

## 四个容易踩的口径

- **自费 ≠ 自付**：目录外自费永远不进基数；先行自付是先自己掏一点，剩下的**仍进基数**。
- **起付线多在一年内累计**，不是每次住院都从头算一次。
- **异地直接结算**：比例按参保地，目录与起付线按就医地，两个地方各管一段。
- **发票原件常被医保收走** → 报商保/单位前，先去复印并加盖「已医保结算」章，否则商保直接拒。
