# 拒报复核与补正清单（执行用）

> 打印或复制出来带去窗口。每完成一项打勾，写日期。

## 0. 进门前三件事

- [ ] 把**所有材料原件 + 复印件**各带一套（窗口常被退是因为只带了原件）
- [ ] 记下受理窗口的**工号/姓名**（后面找人要靠这个）
- [ ] 明确问一句：**「不予支付理由是政策认定，还是材料押金？能不能给我书面通知书？」**
  —— 没有书面理由，后面复核无从谈起。

## 1. 按「不予支付通知书」逐条对应

| 通知书写的理由 | 归到哪一类 | 这一步做什么 |
|---|---|---|
| 第三方责任 | 政策硬拒 | 等责任方保险结算；有补充条款再谈 |
| 工伤/职业病 | 走错险种 | 先做**工伤认定**，已报的医保款按要求退回 |
| 美容/体检/非治疗 | 政策硬拒 | 病理性修复的，改走"治疗性"材料重新申报 |
| 境外/非定点 | 政策硬拒 | 基本无解 |
| 未备案 / 无转诊 | **手续问题** | 补备案 + 补转诊单 → 再报（可救） |
| 清单未盖章 / 发票丢失 | **材料问题** | 回医院补打盖章清单、打印电子票据 |
| 目录外未告知 | 医院问题 | 找医院要自费告知签字；同时可投诉医院 |
| 卡状态异常 | 手续问题 | 补缴/解挂/换卡后再报 |
| 超时限 | 手续问题 | 问能否特批，不承诺 |
| 重复报销 | 手续问题 | 只保留一份发票原件，商保报差额 |

## 2. 复核申请要交的东西

- [ ] 不予支付通知书（或结算单原件）
- [ ] 出院小结 / 诊断证明 / 病历首页
- [ ] 盖章费用清单 + 发票（或电子票据）
- [ ] 自费项目事前告知凭证（如护士站/收费处有签字单，一定要）
- [ ] 本人身份证 + 社保卡
- [ ] 写一份一页纸的**时间线**：什么时候入院、谁建议去哪、为什么选这个医院、
      有没有告知过自费、当时窗口说了什么（口头答复要复述）

## 3. 复核结果不服怎么办

- [ ] 先要**复核结论的书面答复**
- [ ] 行政复议：向本级人民政府或上级医保主管部门提出（有法定时限，当场问清期限）
- [ ] 涉及医院违规收费/目录外未告知：同时向**卫健部门 + 医保稽核**投诉
- [ ] 商保/单位拒赔：按保险合同主张，不成再协商或诉讼

## 4. 不要做的事（红线）

- [ ] 不伪造病历、发票、诊断证明（骗保要担责，本技能绝不提示）
- [ ] 不参与挂床住院、倒票、代刷（医院被拒付会连带你退钱）
- [ ] 不在材料不齐时先签"放弃报销"的纸条
- [ ] 不把发票原件交给人代报（要本人授权或家属关系证明）

## 5. 该收手的情况（省得白跑）

- [ ] 第三方责任且对方保险已赔付到位
- [ ] 工伤已走工伤保险结报完成
- [ ] 居民医保当年断缴（多数地区当年不能补报）
- [ ] 当地经办机构明确表示超时且不再受理
