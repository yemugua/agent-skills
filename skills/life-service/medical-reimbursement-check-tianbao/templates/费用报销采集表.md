# 费用报销采集表（输入模板）

> 查不到就留空，脚本会标【待现场填写】，不瞎猜、不替你填当地政策数字。
> 涉及身份证号、银行卡号：**不填**，用「本人」代替即可。

| 项 | 填什么 |
|---|---|
| 就医类型 | 住院 / 门诊 / 门诊慢特病 / 急诊 |
| 身份 | 职工医保 / 城乡居民（含新农合）/ 商业医疗险 |
| 就医时间 | YYYY-MM-DD（入院日或就诊日） |
| 出院/结算日期 | YYYY-MM-DD |

| 医院是否参保地定点 | 是 / 否 |
| 医疗总费用（发票合计） | 数字（元） |
| 其中目录外自费 | 数字（元） |
| 其中先行自付比例 | 数字（%），如 10；乙类药常见 |
| 其中本次起付线 | 数字（元）；没有就填 0 |
| 报销比例（本次适用） | 数字（%） |
| 年度封顶线（还剩多少额度） | 数字（元） |
| 是否已直接结算（刷卡） | 是 / 否 |
