# 拒报/不予支付：常见事由与复核路径

> 判定逻辑：**先看是不是"政策上根本不该报"，再看"该报但材料/手续没跟上"**。
> 前者争的是"认定"，后者争的是"补手续"。搞错了方向，白跑。

## 一、根本不该报（先自己认掉，别硬扛）

| 事由 | 说明 | 能不能争取 |
|---|---|---|
| 第三方责任（车祸、打架、他人侵权） | 应由责任方/其保险承担，医保不予支付 | 只能等第三人保险结算后再走补充；**工伤走工伤保险，别走医保**（走错会要求退回） |
| 工伤/职业病 | 走工伤保险基金，不走基本医保 | 先做工伤认定；已按医保报的，认定后要退回 |
| 美容、整形、瘦脸、美白、牙科美容 | 属消费/非疾病治疗 | 基本无解；**病理性修复**（如烧伤后功能重建）可争取 |
| 健康体检、预防性检查 | 非治疗 | 无解（部分城市有体检券/公卫项目，另算） |
| 境外、港澳台就医 | 一般不符合 | 无解，回内地后手工报销通常也不受理工伤以外情形 |
| 自杀/自残（除外责任情形） | 视参保地条款与是否因病 | 复杂，直接问经办机构 |
| 应由公共卫生经费承担的（疫苗、婚前检查等） | 走公卫，不走医保 | 无解 |

## 二、该报但手续没跟上（**大多能救**）

| 事由 | 常见原因 | 怎么办 |
|---|---|---|
| 未备案异地就医 | 先后看病后备案 | 补备案（急诊可追溯）→ 再手工报销；比例可能下调 |
| 无转诊转院单 | 自己直接去上级医院 | 回原医院医保办补开（说明病情），或补办备案 |
| 费用清单没盖章 | 只拿了发票 | 回住院处补打盖章清单 |
| 发票丢失 | 出院没拿全 | 电子票据自助打印；或病案室复印收费票据存根 |
| 项目属目录外但未告知 |  violated知情同意 | 要求医院提供自费告知/签字；**多数地区现在要求事前告知**，可投诉医院 |
| 卡状态异常 | 断缴、冻结、挂失、居民未缴当年 | 居民断缴当年通常不能补报；先补缴/解挂再报 |
| 超过手工报销时限 | 拖太久 | 问经办机构能否特批，不承诺 |
| 重复报销（同笔费用报两次） | 医保+商保+单位都报同一笔 | 发票只能 receipt 一次，商保只能报差额 |
| 挂床/onical不住院 | 医保核查发现 | 医院会被拒付，患者连带被要求退钱，别参与 |
| 非定点机构（自驾游/外资医院/私立未接入） | 选错机构 | 一般不予；急诊就近可通融 |

## 三、复核与申诉路径（按顺序走，别跳步）

1. **先问窗口**：要书面/工单编号。口头答复不算，后面没处查。
2. **要《不予支付通知书》**（或结算单上写明理由）——**没有书面理由，就没法复核**。
3. **复核申请**：向参保地医保经办机构提交复核（多数地区可在窗口/线上提交），
   材料：通知书、出院小结、费用清单、发票、诊断证明、**自费告知凭证**（如有）。
4. **行政救济**：对复核结论不服 → 行政复议 / 向同级医保主管部门投诉；
   涉及医院违规（过度收费、目录外未告知）→ 同时向**卫健部门/医保局稽核**投诉。
5. **商保/单位报销被拒**：属民事争议，凭保险合同与结算单主张，不成再协商或诉讼。

## 四、风险红线（写在输出里）

- 别帮忙**倒票、代刷、挂床、伪造病历/发票**——属骗保，要承担法律责任，本技能绝不提示任何此类做法。
- 别让用户在"没拿全材料前先签字放弃报销"。
- 别替用户判断"这个病一定能/一定不能报"，只说常见口径 + 让他问经办机构。

## 五、该认栽的四种情况

1. 属于第三方责任且对方保险已赔（除非有补充条款）
2. 工伤误走了医保，且已完成结报
3. 居民医保当年断缴
4. 超过当地手工报销时限且经办机构明确不再受理
