# 医保报销单据核查与拒报复核 · 概览

## 它解决什么

医院窗口说「这笔报不了」，人通常只拿到一句话，然后就卡住了：不知道是**这笔费用政策上根本不该报**，
还是**就差一张单子没交**；不知道该找谁的工号要书面理由，也不知道复核申请递到哪一层才有人管。

这个技能把这件事拆成四件能干的事：

1. **把钱算清楚**——总费用 → 目录内 → 可报基数 → 估算可报，四层算式逐行列出，
   拿结算单能一行行对上（不编任何城市的起付线/比例/封顶数字）。
2. **把材料点清楚**——出院必拿的 10 项结算材料，逐项标「缺了会怎样 + 现在去哪补」。
   其中**盖章费用清单是最常漏的一项**：只有发票没有清单，医保判定不了哪些进目录，直接退回。
3. **把拒报定性**——先分「政策上多半不该报」（第三方责任 / 工伤走错险种 / 美容整形 / 体检 / 境外 / 非定点），
   再分「手续没跟上」（未备案 / 无转诊 / 清单没盖章 / 目录外未告知 / 卡状态异常 / 超时 / 重复报销）。
   方向搞反，跑多少趟都是白跑。
4. **把路走明白**——要书面理由 → 复核申请 → 行政复议 / 医保稽核投诉 → 商保单位争议，
   全程只认工号、工单号、受理回执；并明确「什么情况该认栽」而不是硬耗。

## 输入 / 输出

| | 内容 |
|---|---|
| 输入 | 一张 `templates/费用报销采集表.md`（费用四要素 + 结算方式 + 10 项材料勾选 + 已走动作） |
| 输出 | `templates/报销单据核查报告.md` 九段成品：摘要 / 费用四层拆解 / 10 项材料 / 拒报归类 / 异地与结算方式 / 复核路径 / 催办公文话术 / 风险红线 / 待办 |
| 可执行 | `scripts/reimburse_check.py`（唯一可执行部分，输出 Markdown） |

## 三个硬边界

- **不查政策数字**：所有比例、起付线、封顶线一律由你自己填三要素（技能不内置任何城市口径），
  报告里凡是本地特殊要求，都写「以参保地医保经办机构现行口径为准」。
- **不承诺**：不保证能报、不保证时间、不保证金额，只给「按你填的三要素算出来的估算」。
- **不碰红线**：不提示倒票、代刷、挂床住院、伪造病历发票（属骗保）；身份证号、银行卡号只记「有」，不落具体号码。

## 四个容易踩的口径

- **自费 ≠ 自付**：目录外自费永远不进基数；先行自付是先自己掏一点，剩下的**仍进基数**。
- **起付线多在一年内累计**，不是每次住院都从头算一遍。
- **异地直接结算**：比例按参保地，目录与起付线按就医地，两个地方各管一段。
- **发票原件常被医保收走**：报商保 / 单位前先复印并加盖「已医保结算」章，否则商保直接拒。

## 配套规则

- `rules/reimbursement-basics.md`：四种参保身份、费用四层、三种结算方式（直接结算 / 手工报销 / 商保）、三个必填参数
- `rules/document-checklist.md`：出院必拿 10 项材料、门慢特认定、发票原件被收走的补救、最常见三个断链瞬间
- `rules/denied-reasons.md`：硬拒与软拒两张表、复核申诉五步、风险红线、该认栽的四种情况
- `templates/拒报复核与补正清单.md`：去窗口的执行清单（打勾 + 红线 + 收手条件）
