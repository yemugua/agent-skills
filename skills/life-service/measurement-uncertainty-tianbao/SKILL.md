# 测量不确定度评定（measurement-uncertainty）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据 JJF 1059《测量不确定度评定与表示》，生成测量不确定度评定清单：不确定度来源识别（设备/环境/人员/方法）、A类与B类评定、合成与扩展（k=2）、与规范限的符合性判定、评定报告与保存。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 测量不确定度
- 不确定度评定
- JJF 1059
- 扩展不确定度
- 符合性判定

## 三、工作流
1. 识别不确定度来源（设备/环境/人员/方法）
2. 开展A类与B类评定
3. 合成并计算扩展不确定度（k=2）
4. 进行与规范限的符合性判定
5. 出具并保存评定报告

## 四、核心内容（检查清单与判定）
JJF 1059 规定不确定度的评定与表示方法；A类用统计方法、B类用其他信息，合成后取包含因子 k=2 得扩展不确定度，用于合格判定的边界分析。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含不确定度来源识别 | 来源 |
| Q2 | FAIL | 未含A类/B类评定 | 评定 |
| Q3 | WARN | 未含合成与扩展不确定度 | 扩展 |
| Q4 | FAIL | 未含与规范限的符合性判定 | 符合性 |
| Q5 | WARN | 未含评定报告与保存 | 报告 |

> 脚本 `measurement-uncertainty_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python measurement-uncertainty_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python measurement-uncertainty_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
