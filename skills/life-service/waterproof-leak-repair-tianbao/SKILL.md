# 防水补漏与渗水排查（waterproof-leak-repair）

漏水这件事，**动手之前必须先定位来源**。不定位就刷防水，是这一块最大的浪费：钱花了，问题没解决，下雨照样渗，还把责任搅得更说不清。

这个技能做四件事：**判是不是渗漏** → **定来源** → **按顺序验证** → **决定自己做还是叫师傅**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 区分渗漏与冷凝水、判断水的大致来向 | ❌ 认定"刷一层防水就能解决" |
| 按七类来源给出识别特征与排查顺序 | ❌ 拆楼板、凿开混凝土找漏点 |
| 判断 DIY 适用范围与不适用范围 | ❌ 高层外墙、外墙作业、屋面作业 |
| 列出闭水试验、观察记录的操作方法 | ❌ 改动燃气、电气、承重结构 |
| 说明什么情况必须立即转交专业人员 | ❌ 代替物业与物业之间做责任认定 |

**遇到以下情况，立即停止自行排查，转交物业或防水专业队伍：**

- 高层住宅的外墙渗水、窗框渗水（需要在外立面作业）
- 整层、或同一户多个房间同时出现渗漏痕迹
- 渗漏涉及承重结构、楼板、梁柱、外墙保温层
- 渗漏来自共用管道（立管、污水管、暖气管道）
- 连续多日降雨后渗漏仍在持续加重
- 怀疑涉及燃气管道、电气线路附近
- 楼上住户不配合入户检查
- 需要登高、爬出窗外、站在窗台或屋面作业

**这些情形不是"难做"，是"不该做"。** 高处与外墙作业的坠物、坠落风险应由有资质的人员承担；承重结构与共用管道的判断需要现场勘查条件。

## 二、完整工作流

```
第1 步  判性质：是渗漏，还是冷凝水、还是返碱
第 2 步  先读规则文件 rules/leak_source_rules.md（七类来源分诊表 + 判定口径）
第 3 步  跑分诊脚本，从最容易验证的来源开始排
    python scripts/leak_source_triage.py --text "顶棚水印，雨后加重，楼上卫生间位置正上方"
第 4 步  按脚本给出的顺序做低成本验证（下楼看顶 / 闭水试验 / 降雨时间比对 / 管线位置比对）
第 5 步  定位到来源后，判断是自己处理还是转交专业队伍
第 6 步  DIY 的先断水源、清理、干燥，再按材质做局部修补
第 7 步  复测：同条件再验一次，并留好记录
```

**顺序不能颠倒**：第 1、2 步不做，直接跳到刷防水，就是本技能开头说的最大浪费。

## 三、第 1 步：先判是不是渗漏

渗漏、冷凝水、返碱，三者处理方式完全不同，判错就是白干。

| 现象 | 渗漏 | 冷凝水 | 返碱 |
|---|---|---|---|
| 出现位置 | 天花板、墙角上方、窗台内侧、外墙内侧 | 窗玻璃、墙角北侧、外墙内侧、瓷砖表面 | 墙根、踢脚线附近、砖缝 |
| 时间规律 | 与降雨、楼上用水、上层管线相关 | 与温差、结露季节相关，不下雨也有 | 与水分上泛有关，干燥期减轻 |
| 触感 | 手感发潮、发软、局部鼓起，有渗出或滴水 | 表面均匀凝露，摸上去是水珠不是水渍 | 表面有白色粉状结晶 |
| 遇水行为 | 不明显 | 擦干后过几小时又在同一位置凝露 | 白霜遇水化开，干燥后重新析出 |
| 一句话判据 | 停掉可疑水源后改善 | 无水源变化规律，跟温度走 | 白霜遇水化开 |

**两个快速判别动作：**

1. **降雨时间比对法**：连续记录 3 次降雨的时间点与渗漏出现的时间点。降雨后 6-12 小时内出现 → 外墙或屋面来源；与降雨无关但与楼上用水时段重合 → 上层来源。
2. **温差观察法**：渗水位置长期在背阴侧、北侧墙角，且只出现在冬春降温期 → 更可能是冷凝水，先改通风与除湿，不是先刷防水。

> 判定口径的完整版在 `rules/leak_source_rules.md`。冷凝水被当成渗漏去刷防水，是这类返工里最贵的一种。

## 四、第 2 步：七类来源分诊表

按"最容易验证"排序，不是按概率排序。

| 顺序 | 来源 | 识别特征 | 最便宜的验证动作 |
|---|---|---|---|
| 1 | 自家给排水或暖气管道漏水 | 沿管道走向有水渍、阀门或三通处渗水、关闭该管路后现象消失 | 关掉分区阀，观察 30 分钟是否停止 |
| 2 | 楼上或上层单元渗漏 | 位置正好在上一层厨卫或水槽下方，雨天明显加重 | 下楼查看对应位置天花；与楼上用水时段比对 |
| 3 | 卫生间/淋浴区防水层失效 | 水从墙根、地漏周边、门槛处渗出，楼下顶棚对应位置发霉 | 闭水试验（见第六节） |
| 4 | 窗框或窗缝渗水 | 渗水在窗台内侧、窗框周边，雨水斜打时明显 | 关窗淋水测试（外侧可控时）；或看渗水位置是否与固定方向的风雨对应 |
| 5 | 外墙裂缝或女儿墙渗水 | 渗水出现在外墙内侧、楼层交界、顶棚与墙面交接处 | 对着外墙裂缝做淋水观察（自己能站在室内完成的） |
| 6 | 设备渗漏（空调冷凝水、热水器、洗衣机接口） | 紧贴设备下方或管道接口，且只在设备运行时出现 | 停用设备观察 |
| 7 | 楼板结构裂缝或上下层共用部位 | 裂缝斜向、有水泥析出、逐渐加长 | 停用该区域，转专业队伍 |

**判断顺序的意义**：从 1 到 7 逐个排除，前四类多数能自己定，第 5 类起就必须叫专业人员。所以不是"全都能自己查"，而是"能自己查到第 4 步就已经够用了"。

## 五、明确不适用的情况（这些别自己修）

| 情形 | 原因 | 应该怎么做 |
|---|---|---|
| 高层外墙渗水 | 需要外立面作业，有坠落与坠物风险 | 报物业，由物业安排专业队伍 |
| 涉及承重结构、梁柱、楼板裂缝 | 结构判断需要专业检测 | 转专业队伍，先检测再定方案 |
| 整层或多个房间同时渗漏 | 大概率是上层、立管或结构共性问题 | 报物业与相邻业主共同排查 |
| 渗漏来自共用管道 | 不属于单个住户的处置范围 | 报物业 |
| 连续多日降雨仍在加重 | 说明源头在上方或外墙，未定位 | 转专业队伍 |
| 燃气、电气管线附近渗漏 | 涉及安全专项 | 燃气问题先关阀开窗；电气问题先断电 |

## 六、DIY 适用范围（能自己处理的就这几类）

**可以做：**

- 卫生间局部渗水（墙根、地漏周边、门槛处），且面积小、来源已确认
- 阳台、窗框周边的渗水（能站在室内处理的部分）
- 地面小面积渗水（洗衣区、洗手台下方局部）
- 给排水管接口、阀门处的轻微渗漏（关阀后更换密封圈或接口件）
- 空调冷凝水盘溢流（清理排水口与滤网）

**DIY 的固定动作顺序：**

1. **断源**：关闭相关分区阀门或停用设备，让渗漏停止
2. **清理**：铲除起鼓、空鼓、脱落的旧涂层，露出基面
3. **干燥**：自然通风 + 除湿，让基面彻底干透；有渗水时禁止直接施工
4. **确认基面状态**：无空鼓、无松动、无油污；空鼓先返修
5. **按材质施工**：柔性材料用于有变形可能的部位，刚性材料用于无位移的部位
6. **养护**：按产品说明书给足养护时间，期间禁止踩踏、淋水
7. **复测**：回到第 3 步的验证动作，同条件再做一次

> 涉及湿作业与高处作业时，材料选择、养护时间、通风条件以产品说明书与现行施工规范为准，本技能不指定具体牌号与配比。

## 七、脚本用法

```bash
python scripts/leak_source_triage.py --text "顶棚水印，雨后加重"
python scripts/leak_source_triage.py --file 现象描述.txt --out 分诊结果.md
python scripts/leak_source_triage.py --format json --file 现象描述.json
```

| 参数 | 说明 |
|---|---|
| `--text` | 直接给现象描述 |
| `--file` | 从文件读，支持 `.txt` / `.md` / `.json`（JSON 可写 `{"desc": "..."}`） |
| `--out` | 结果落盘路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本做三件事：按排查顺序匹配最可能的来源、给出每类的验证动作与 DIY 归属、命中安全红线时直接输出"转交专业队伍"的结论。

> 脚本是关键词匹配，**不等于现场判断**。写了"雨后加重"要真的对过时间点，写了"楼上"要真的下过楼。

## 八、人工确认清单（这步不能省）

- [ ] 已经排除冷凝水与返碱（做过降雨比对或温差观察）

- [ ] 已按产品说明书留足养护时间
- [ ] 复测结果已记录，遗留问题已列入待观察清单

## 九、最常见的坑

**坑一：没定位就刷防水。**
全屋刷一遍，钱花了、味道大、问题没解决，还把责任搅浑。顺序永远是先定位后动手。

**坑二：把冷凝水当渗漏刷防水。**
北墙角、窗边冬天"渗水"，实际是凝露。刷多少层都不解决，该做的是通风与除湿。

**坑三：把返碱当霉点刷杀菌剂。**
墙根白色粉状结晶遇水化开，那是返碱；霉是黑绿斑且有霉味。两者处理方式不同，用错产品会加重墙面负担。

**坑四：闭水试验不做就直接刷。**
闭水试验是验证卫生间防水层是否失效的最便宜方法，不做就等于没诊断。

**坑五：只在下雨天看一次就下结论。**
一次降雨不足以判断来源。要连续记录 3 次降雨与渗漏出现的时间对应关系。

**坑六：卫生间局部渗水直接整体重做。**
来源已确认且面积小的时候，局部修补是更合理的选择。是否整体重做要看基面状态与范围，不是看心情。

**坑七：把楼上漏水当成自己家的事硬扛。**
楼上渗漏处理的主体是责任方，但你自己要先做的是：记录证据、固定时间点、通过物业沟通，而不是自己去敲人家的门。

**坑八：忽略了物业与相邻住户的沟通记录。**
漏水纠纷的核心往往不是技术，而是没有记录。没有时间点、没有照片、没有沟通纪要，最后谁都说不清。

**坑九：自己站在窗台或楼外侧作业。**
一处渗水不值得用坠落风险去换。窗台作业交给有相应防护与资质的人。

**坑十：渗漏期间继续在墙面刷漆、贴砖、装柜体。**
湿基层上做任何饰面都会空鼓脱落，等于把成本翻一倍。

## 十、边界与免责

- 本技能**不替代**防水专业施工、外墙作业、结构检测与物业协调
- 渗漏来源最终判定需要现场勘查条件，脚本与规则表只提供排查顺序
- 材料规格、养护时间、施工工艺以**产品说明书与现行施工规范**为准
- 涉及相邻住户责任、赔偿、报修流程的，按**当地物业管理与相关主管部门要求**办理
- 任何高处、外墙、承重结构、燃气、电气相关情形，一律转交专业人员
