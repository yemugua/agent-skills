# 产检时间安排与报告指标核查规则

> 说明：以下为常见安排口径，具体项目、次数、孕周窗口和报销政策因地区、医院、指南版本及个人情况而异，以就诊医疗机构的要求为准。

## 一、孕周口径

- 常用末次月经推算与早孕超声核对两种方法，两者不一致时以医生采用的口径为准。
- 月经不规律、辅助生殖、哺乳期妊娠或记不清末次月经时，应尽早通过超声核对。
- 记录模板里同时保留两种孕周，避免后续窗口计算错乱。

## 二、常见产检节奏

| 阶段 | 常见节奏 | 说明 |
|---|---|---|
| 确认妊娠至 12 周前 | 就诊建档，完善基础检查 | 尽早确认宫内妊娠和孕周 |
| 中孕期 | 一般每 4 周左右一次 | 高风险或医嘱会增加频率 |
| 晚孕期 | 频率逐步提高至每 2 周、每 1 周 | 以胎心监护、超声和母体评估为主 |
| 超过预产期 | 按医嘱加强监测 | 关注胎动、羊水和胎盘情况 |

## 三、常见项目与时间窗

| 项目 | 一般时间窗 | 目的与注意 |
|---|---|---|
| 早孕超声 | 孕早期 | 核对孕周、胎数、宫内位置 |
| NT 超声 | 通常 11 至 13 周+6 天区间内 | 有严格孕周窗口，错过难以补做 |
| 早期唐筛 | 常与 NT 同期 | 与血清指标联合评估 |
| 中期唐筛 | 常约 15 至 20 周 | 高龄或高风险者可能直接采用其他方案 |
| 无创 DNA 筛查 | 通常 12 周以后按医嘱 | 属筛查不是诊断，结果需医生解读 |
| 系统超声（大排畸） | 常约 20 至 24 周 | 需提前预约，受胎位和母体条件影响 |
| 口服葡萄糖耐量试验 | 常约 24 至 28 周 | 通常需空腹并按流程多次采血 |
| 贫血与血常规复查 | 按孕周和既往结果 | 关注血红蛋白动态变化 |
| 乙肝、梅毒、艾滋等筛查 | 建档期及医嘱复查 | 涉及母婴阻断，务必按医嘱 |
| 胎心监护 | 晚孕期按医嘱 | 结果需结合临床背景 |
| B 族链球菌等晚孕检查 | 按医院项目表 | 与分娩管理相关 |

## 四、报告阅读口径

| 指标 | 常见关注点 | 记录要求 |
|---|---|---|
| 血压 | 收缩压和舒张压，测量状态和体位 | 记录日期、数值和是否复测 |
| 体重 | 孕前体重和增长趋势 | 记录体重变化曲线 |
| 血常规 | 血红蛋白、血小板等 | 抄本院参考区间和单位 |
| 尿常规 | 蛋白、糖、酮体、白细胞 | 注意留取方式和污染 |
| 糖耐 | 空腹及各时点血糖 | 记录是否严格空腹和采血时间 |
| 甲功 | TSH、FT4 等 | 不自行调整药物 |
| 肝功能、胆汁酸 | 皮肤瘙痒或异常时按医嘱 | 记录症状发生时间 |
| 超声 | 胎儿生长、羊水、胎盘、脐血流 | 只抄报告文字，自行不判读图像 |
| 胎心监护 | 基线和变异等描述 | 由医生结合临床解释 |

## 五、异常三级提示

| 级别 | 表现 | 处理 |
|---|---|---|
| 立即联系医生或急诊 | 出血、流液、持续腹痛、头痛视物模糊、抽搐先兆、血压明显升高、发热、胎动明显减少或消失 | 不要等待下次产检 |
| 尽快联系医生 | 新发明显异常指标、既往异常持续加重、空腹血糖明显异常、血红蛋白持续下降 | 在医疗机构告知的时限内联系 |
| 随访时沟通 | 轻度异常且医生已说明、单项临界值、需复查确认 | 记录问题并在复诊时问清 |

## 六、否定词与防误伤

- 「未见明显异常」不等于保证一切正常，应在后续随访中继续观察。
- 「未提示」「未显示」「未见」是限定表述，不能删掉后写成完整结论。
- 「未复查」不能算作「已复查正常」。
- 「未空腹」「未完成全部时点采血」会影响糖耐类结果，应如实记录并告知医生。

## 七、就诊前准备

- 携带既往全部产检报告、用药清单、过敏史、手术史和基础疾病资料。
- 确认是否需空腹、憋尿、预约或家属陪同。
- 高风险情形（高龄、多胎、既往不良孕产史、慢性病、辅助生殖）按医嘱增加随访，不以通用表替代个体安排。
