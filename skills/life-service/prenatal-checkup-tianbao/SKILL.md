# 孕期产检项目时间表与报告指标核查

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 按孕周整理常见产检项目和时间窗 | 诊断是否妊娠、胎儿是否健康或畸形 |
| 解释报告常见指标和参考区间读法 | 代替医生调整药物、胰岛素或治疗方案 |
| 提示漏检、过期、需尽快联系医生的异常级别 | 解读超声影像、胎心监护图形并下结论 |
| 输出产检进度表和就诊提问清单 | 安排住院、分娩方式或紧急处置 |
| 提醒携带既往报告和基础疾病史 | 承诺任何妊娠结局 |

出现阴道出血或流液、持续腹痛、剧烈头痛或视物模糊、血压明显升高、明显水肿、发热、胎动明显减少或消失、外伤、意识改变、严重呕吐无法进食等情况，应立即就医或按当地急救渠道处理，不要等下一次产检。

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「孕几周该做什么检查」 | 用 |
| 「NT、唐筛、大排畸什么时候做」 | 用，说明具体孕周以医院安排为准 |
| 「糖耐没过是不是糖尿病」 | 用，只做说明和就诊提示 |
| 「血红蛋白 98 是不是严重贫血」 | 用，提示尽快咨询医生 |
| 「帮我判断胎儿有没有问题」 | 不用，需要产科和超声专业判断 |
| 「胎动少了要不要紧」 | 只作急诊提示，立即就医 |

## 三、完整工作流

1. **固定孕周口径**：记录末次月经、月经周期、早孕超声核对结果；机构常用末次月经或超声核对孕周，两者不一致时以医生采用的为准。
2. **建立产检档案**：孕周、日期、医院、项目、医生意见、下次预约日期、是否需空腹或憋尿。
3. **按时间表核对**：对照 `rules/checkup-timeline.md` 标出已做、漏做、错过窗口和即将到期项目。
4. **登记报告指标**：只抄检验单上的数值、单位和本院参考区间；不要自行换算或跨机构对比后下结论。
5. **分异常级别**：标注「需尽快联系医生」「下次随访时沟通」「已由医生说明并记录」三档，不把异常写成正常。
6. **生成提问清单**：把不确定项转成可执行问题，下次就诊时逐条问。
7. **留痕与复诊**：保存纸质或电子报告、用药和过敏史，复诊携带全部既往单。

## 四、核心规则与要件库

整理时间表或解读提示前，**必须先读**：

- `rules/checkup-timeline.md`：孕周时间窗、常见项目、指标读法、异常分级和禁忌提示。
- `templates/checkup-record.md`：产检进度表、报告登记表和提问清单模板。

不得改写检验数值，不得因报告出现「未见异常」字样就忽略其他异常描述；「未见」「未提示」「无明显异常」属限定表述，不能当成永续正常。

## 五、人工确认清单

- [ ] 孕周计算口径已和产检医院一致
- [ ] 每次产检的血压、体重、宫高、腹围、胎心等基础数据已记录
- [ ] 报告数值、单位和参考区间按本院单抄录
- [ ] 特殊项目是否需要空腹、憋尿、提前预约已确认
- [ ] 既往病史、手术史、用药、过敏、不良孕产史已告知
- [ ] 异常指标已按级别处理，未自行判断为不用管
- [ ] 已确认下次产检日期和紧急联系方式
- [ ] 多发妊娠、高龄、基础疾病等高风险情形已遵医嘱增加随访

## 六、最常见的坑

1. **孕周口径不统一**：末次月经孕周与超声核对孕周不同，按医生采用口径安排检查。
2. **错过时间窗**：部分筛查和超声有明确孕周窗口，错过后不能简单补做或延后。
3. **只看箭头不看区间**：不同医院方法、单位和参考区间不同，跨院对比需医生判断。
4. **空腹与憋尿搞反**：部分抽血需空腹，部分超声与尿检要求不同，按预约单执行。
5. **把「未见明显异常」当保证**：影像和筛查都有条件限制，随访仍有意义。
6. **忽略否定词**：「未见血流信号」「未及明显异常」不能简化为「异常」或「正常」任意一边。
7. **自行停药或减量**：铁剂、甲状腺素、胰岛素、降压药等调整必须遵医嘱。
8. **胎动异常拖延**：明显减少或消失属于需要尽快就医的信号，不要等预约日。

## 七、边界与免责

本技能提供产检流程整理和报告阅读提示，不构成医疗诊断、治疗方案或妊娠结局判断。项目安排、筛查策略、参考区间和随访频率因地区、医院、指南版本、年龄、既往史和多胎等因素差异很大，**以现行临床规范和就诊医疗机构的要求为准**。紧急情况请立即联系医生或急救渠道，不要依据本技能延误就医。
