# 消防电源与配电（fire-power-supply）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《建筑设计防火规范》GB 50016 与消防电源要求，生成清单：消防负荷等级与供电要求、双电源与末端自动切换、备用电源（柴油发电机/EPS/UPS）、配电线路耐火与敷设、巡检与切换试验。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 消防电源
- 消防配电
- 双电源切换
- 备用发电机
- 消防配电线路

## 三、工作流
1. 核定消防负荷等级与供电要求
2. 落实双电源与末端自动切换
3. 配置备用电源（发电机/EPS/UPS）
4. 检查配电线路耐火与敷设
5. 定期巡检并做切换试验

## 四、核心内容（检查清单与判定）
消防设备供电须按负荷等级保障可靠性，末端自动切换与备用电源是关键；配电线路应具备耐火能力并定期做切换试验。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含消防负荷等级与供电要求 | 负荷 |
| Q2 | FAIL | 未含双电源与末端自动切换 | 切换 |
| Q3 | WARN | 未含备用电源（发电机/EPS/UPS） | 备用 |
| Q4 | FAIL | 未含配电线路耐火与敷设 | 线路 |
| Q5 | WARN | 未含巡检与切换试验 | 试验 |

> 脚本 `fire-power-supply_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python fire-power-supply_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python fire-power-supply_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
