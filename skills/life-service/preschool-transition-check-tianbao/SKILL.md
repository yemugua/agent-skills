# 幼小衔接准备与能力清单核查

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 用八大维度逐项核查入学准备情况并给出档位判断 | 断言孩子「一定跟得上」或「一定跟不上」 |
| 给出入学前 3 个月倒排准备表 | 指定教材版本、课程体系、教材出版社 |
| 说明各地入学政策不同，以当地教育部门要求为准 | 代替当地教育部门解释招生政策、划片条件 |
| 提供各维度可观察的判定口径与家庭练习方法 | 诊断学习障碍、发育迟缓、注意力缺陷多动障碍 |
| 纠正「提前学一年级知识」的误区 | 推荐具体商业机构、幼小衔接班或网课品牌 |
| 提示需转交医生或专业教师评估的情形 | 给出 IQ 数值、学业预测分数或入学结果判断 |

**就医或专业评估红线（出现任一条，先做专业评估再谈衔接）**

- 已到入学年龄仍无法完成基本自理：不会自己穿衣吃饭喝水、无法表达如厕需求 —— 建议儿科或儿童保健科评估
- 语言表达明显落后：不能说完整短句、同龄孩子能说而孩子只能说单词、听不懂简单指令 —— 建议儿童保健科或言语治疗科评估
- 注意与冲动表现持续存在：多数场合无法安静听指令、多动影响基本生活、经常打断他人 —— 建议儿科或儿童心理专业评估
- 精细动作明显困难：不会用剪刀、握笔姿势异常、不会串珠、绘画涂鸦不成形 —— 建议作业治疗或儿科评估
- 视听问题：反复中耳炎史、疑似听弱、看东西眯眼或歪头 —— 先到耳鼻喉科和眼科排查
- 已确诊发育障碍、学习障碍、孤独症谱系 —— 衔接方案须由专业机构制定
- 听力、视力筛查未通过或学校体检异常 —— 先复查

**政策口径**：义务教育阶段入学年龄、免试就近入学、划片与户籍要求、放学后与周末托管政策**各地不同、年份间可能调整**，一律以**当地教育部门当年发布的招生入学工作通知为准**，本技能不提供具体政策条款。

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「幼小衔接要准备什么」 | 用，八维度清单 |
| 「上小学要会什么」 | 用，逐项判定口径 |
| 「入学前要不要学拼音和识字」 | 用，说明前阅读前书写是能力不是知识量 |
| 「孩子坐不住怎么办」 | 用，专注力维度给可练动作 |
| 「幼小衔接班有必要上吗」 | 用，明确说明能力准备优先 |
| 「几岁上一年级合适」 | 用，政策以当地教育部门为准，能力看清单 |
| 「孩子会被人跟班怎么办」 | 用，说明入学适应期的正常范围 |
| 「是不是要提前学一年级课本」 | 用，明确反对作为主要准备方式 |

## 三、完整工作流

1. **先确认孩子当前年级与目标入学时间**，确定倒排起点。
2. **确认政策口径**：明确告知以当地教育部门通知为准，不引用具体条款号。
3. **八维度逐项核查**：按 `rules/八大能力维度核查表.md` 逐条观察，不凭印象打勾。
4. **排红线**：命中评估红线即转诊或转专业机构，不给衔接方案。
5. **判定档位**：就绪 / 基本就绪 / 需集中补短板 / 需专业评估。
6. **输出 3 个月倒排表**：用 `templates/入学前三个月准备表.md`，短板维度优先排入每日时段。
7. **给出家庭练习动作**：每维度给 2-3 个可在家里做的动作，注明每日时长上限。
8. **设定 4 周复评**：用记录表回看趋势，调整而非加量。

## 四、核心规则与要件库

生成任何准备表或结论前，**必须先读**：

- `rules/八大能力维度核查表.md`：八维度判定口径、短板判定线、可练动作、误区。
- `rules/入学前三个月倒排与误区.md`：3 个月倒排逻辑、常见误区、入学适应期观察点。

不得以「提前学一年级知识」作为主要衔接方式；不得给出教材版本与商业机构推荐；不得对入学结果做预测。

## 五、脚本用法

```
python scripts/preschool_readiness_check.py --file case.json
python scripts/preschool_readiness_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`age_months` 当前月龄，`months_to_school` 距入学月数，`skills` 八维度成熟标记，`red_flags` 红线标记，`weak` 短板标记 |
| `--focus` | 只看某维度：`selfcare` `time` `focus` `rule` `reading` `writing` `express` `motor` |
| `--json` | 以 JSON 输出 |
| `--out` | 结果写入指定文件，默认 `scripts/_last_result.txt` |
| `--selftest` | 运行自检 |

脚本输出档位判断、短板排序、倒排建议与红线提示。**脚本不预测入学成绩、不给学习障碍结论。**

## 七、最常见的坑

1. **把提前学一年级课本当主要准备**：短期会让孩子开学显得轻松，但自理、专注、规则跟不上，二年级分化反而更明显。
2. **只练知识不练自理**：会认很多字却不会自己上厕所、不会整理书包、不会收拾桌面，这些才是入学第一周的真正卡点。
3. **用「写字量」衡量前书写**：前书写是握笔姿势、手部力量、专注时长，抄字量多了反而伤害兴趣。
4. **把坐不住当缺点**：幼儿的专注时长本就有限，用成人的 40 分钟标准衡量会得出错误结论；要看的是能否在短时段内保持专注并能被打断后回来。
5. **焦虑驱动加码**：一天安排三四个班，压缩睡眠和运动，反而损害注意力和情绪稳定性。
6. **只陪孩子写不让孩子自己做**：包办式陪伴让孩子失去练习机会，入学后仍依赖家长。
7. **忽略入学适应期的正常波动**：短期沉默、成绩波动、说想上厕所却不敢去，都可能是适应期反应，观察 4-6 周再判断。
8. **把语言落后当「说话晚一点没关系」**：语言表达落后会同时拖累课堂理解与同伴交往，越早评估越安全。
9. **盲目相信幼小衔接班**：能替代的是家庭陪伴与能力准备，替代不了孩子自己的适应过程。

## 八、边界与免责

本技能提供幼小衔接的能力核查口径与家庭准备排期参考，**不提供升学预测、不做发育或学习能力诊断、不指定教材与课程体系**。义务教育阶段入学年龄、划片、免试就近入学等政策**各地不同且会调整，以当地教育部门当年发布的招生入学工作通知为准**。怀疑存在发育迟缓、注意力问题、语言或视听障碍时，必须由儿科或相关专业科室评估。本技能不替代教育部门规定与专业教育评估。
