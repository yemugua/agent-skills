# 个税专项附加扣除填报与留存资料核查

专项附加扣除最容易出问题的地方，不是「填不填」，而是**填的量对不对、两个人有没有重复扣、资料有没有留**。这三类问题在事后核查时都要补税加滞纳金。

这个技能做四件事：**逐项核标准 → 查超额与重复 → 算年度影响 → 列留存资料**。

---

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 按现行标准核对每项扣除的额度与期间 | 代替本人登录个税 App 提交或确认 |
| 检查分摊方式是否合规、是否超额 | 编造扣除事实、虚构子女或被赡养人信息 |
| 计算年度扣除额与对应纳税所得额影响 | 提供拆分收入、虚增扣除、转换所得性质的避税方案 |
| 输出留存资料清单与更正路径 | 保证不被核查、不被要求补税 |
| 提示重复扣除、超额扣除的后果 | 代替税务机关作认定 |

涉及以下情形，应停下来交由税务机关、扣缴义务人、税务师或律师处理：**扣除事实存在争议、被税务机关要求说明或补正、涉及境外所得、涉及股权激励与一次性补偿、已收到核查或处罚通知**。

**绝对不做**：不虚构扣除信息，不重复申报同一子女或同一被赡养人，不提供任何以少缴税为目的的虚假安排。

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「子女教育一个月能扣多少」 | 用，按每个子女的标准与分摊方式核 |
| 「房贷利息和房租能同时扣吗」 | 用，同一纳税年度内一般不可同时享受 |
| 「非独生子女赡养老人怎么分」 | 用，核每人上限与分摊方式 |
| 「大病医疗怎么扣、限额多少」 | 用，按年度自付超额部分核 |
| 「换工作了专项附加扣除要重新填吗」 | 用，核扣缴义务人变更与信息更新 |
| 「要留什么资料、留多久」 | 用，按项目列清单 |
| 「怎么多填点扣除少交税」 | 不用，拒绝提供虚增扣除方案 |
| 「税后收入怎么算、社保怎么交」 | 看情形，属于汇算清缴的用对应技能 |

## 三、完整工作流

```
第 1 步  确认纳税年度与纳税人身份：是否为居民个人、有无配偶
第 2 步  读规则文件 rules/deduction-rules.md（七项标准、分摊口径、留存资料、不得同时享受情形）
第 3 步  逐项收集事实：子女人数与年龄、被赡养人年龄与兄弟姐妹数、房贷是否首套与已扣月数、
         租房城市与自有住房情况、继续教育类型与证书、大病自付金额
第 4 步  核分摊：父母之间、兄弟姐妹之间的分摊方式与每人上限
第 5 步  跑脚本核验：scripts/deduction_check.py --file case.json
第 6 步  算影响：年度扣除额合计 → 对综合所得应纳税所得额的影响
第 7 步  查重复与超额：同一子女、同一被赡养人、房贷与租金、夫妻双方是否撞车
第 8 步  备资料：按清单留存，跨年度的留存到规定期限
第 9 步  年度复核：次年汇算前重新核一遍事实是否变化（子女入学、老人年满 60、房贷还清等）
```

## 四、扣除标准口径

| 项目 | 标准 | 关键限定 |
|---|---|---|
| 3 岁以下婴幼儿照护 | 每婴幼儿每月 2000 元 | 父母可选择一方 100% 或双方各 50%，**合计不得超标准** |
| 子女教育 | 每子女每月 2000 元 | 学前教育＋学历教育；父母分摊方式同上；选择后一个纳税年度内一般不得变更 |
| 继续教育 | 学历学位每月 400 元（同一学历最长 48 个月）；职业资格取得证书当年 3600 元 | 学历与职业资格可分别享受；**未取得证书不得按 3600 扣** |
| 大病医疗 | 医保目录内个人自付累计**超过 15000 元的部分**，年度限额 **80000 元**据实扣除 | 汇算时办理；可选择本人或配偶扣除；未成年子女可由父母一方扣除 |
| 住房贷款利息 | 每月 1000 元，最长 **240 个月** | 限于**首套**住房贷款；夫妻双方约定由一方扣；与住房租金不可同时享受 |
| 住房租金 | 直辖市/省会/计划单列市等每月 1500 元；市辖区户籍人口超 100 万的城市每月 1100 元；不超 100 万的每月 800 元 | 本人及配偶在主要工作城市**无自有住房**；与房贷利息不可同时享受 |
| 赡养老人 | 独生子女每月 3000 元；非独生子女与兄弟姐妹分摊每月 3000 元额度，**每人不超过 1500 元** | 被赡养人**年满 60 岁**；指定分摊优先于约定分摊 |

> 以上为现行常见标准，**具体标准以现行税法及税务机关口径为准**，政策调整时以最新公布为准。

### 4.1 扣除额与税额影响口径

```
年度专项附加扣除合计 = Σ(各项目月标准 × 可扣月数 × 分摊比例)

综合所得应纳税所得额 = 年收入
                     − 60000（基本减除费用）
                     − 专项扣除（基本养老保险、基本医疗保险、失业保险等个人负担部分）
                     − 专项附加扣除
                     − 依法确定的其他扣除（如符合条件的个人养老金、商业健康险等，按各自限额）

应纳税额 = 应纳税所得额 × 适用税率 − 速算扣除数   （七级超额累进，见 rules/deduction-rules.md）
```

**扣除额不等于少交的税**：扣除 1 万元，少交的税是 1 万元 × 你所在的边际税率（3%–45%），不是 1 万元。这一点必须对用户讲清。

### 4.2 防误伤（否定词清单）

- 「已填报」→ 判为**待核验**，不得写成「已确认可扣」
- 「分摊协议未签署」→ 判为**分摊未成立**，不得按分摊后的金额计算
- 「老人未满 60 岁」→ 判为**不符合**，不得计入赡养老人扣除
- 「非首套住房贷款」→ 判为**不符合**房贷利息扣除
- 「主要工作城市有自有住房」→ 判为**不符合**住房租金扣除
- 「未取得职业资格证书」→ 判为**不符合** 3600 元扣除
- 「自付未超 15000 元」→ 判为**大病医疗可扣金额为 0**
- 「夫妻双方各扣 100%」→ 判为**重复扣除**，必须纠正

## 五、核心规则与要件库

生成填报说明或给结论前，**必须先读**：

- `rules/deduction-rules.md`：七项扣除的标准、期间、分摊方式、不得同时享受的情形、留存资料清单与留存期限、更正与核查应对。

不得按他人说法认定扣除事实，不得把「准备去办」当成「已符合」。

## 六、脚本用法

```bash
python scripts/deduction_check.py --file case.json --out 扣除核查.md
python scripts/deduction_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：纳税年度、纳税人情况与各扣除项明细（见下） |
| `--text` | 直接给 JSON 字符串 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检 |

输入 JSON 示例：

```json
{
  "year": 2026,
  "children": [{"type": "education", "months": 12, "share": 0.5}],
  "infants": [{"months": 12, "share": 1.0}],
  "elderly": {"parent_age": 65, "only_child": false, "share": 0.5, "months": 12},
  "housing_loan": {"first_home": true, "months": 12, "used_months": 36},
  "housing_rent": {"city_tier": 1, "months": 0, "own_house_in_city": false},
  "continuing_education": {"degree_months": 0, "certificate_obtained": true},
  "medical": {"self_pay_total": 30000},
  "marginal_rate": 0.10
}
```

脚本输出：每项标准额、可扣额、差异与判定、年度扣除合计、按边际税率估算的税额影响、重复与超额提示、留存资料缺失清单。

> 脚本按你填的事实做静态核验，**不代表税务机关认定**；标准与口径以现行税法及税务机关公布为准。

## 七、人工确认清单（这步不能省）

- [ ] 子女、婴幼儿、被赡养人的身份信息与实际情况一致，没有虚构
- [ ] 父母之间、兄弟姐妹之间的分摊方式已明确，且**合计不超标准**
- [ ] 房贷是否为首套已核实（不是凭开发商说法）
- [ ] 租房扣的，本人及配偶在主要工作城市确实无自有住房
- [ ] 大病医疗的自付金额取自医保系统或结算单，不是估算
- [ ] 分摊协议（约定分摊、指定分摊）已签订并留存
- [ ] 留存资料按清单备齐，跨年度的留存到规定期限
- [ ] 扣除额 ≠ 少交税额，已按边际税率向用户说明差异
- [ ] 次年事实变化（子女入学、老人年满 60、房贷还清、换城市）已更新

## 八、最常见的坑

1. **夫妻两人都按 100% 扣同一个孩子。** 子女教育与婴幼儿照护的父母合计不得超过标准，双方各扣 100% 就是重复扣除，事后要补税加滞纳金。必须先约定分摊方式。
2. **房贷利息和住房租金同时扣。** 同一纳税年度内一般不可同时享受，只能选其一。换城市工作、老家有房贷、工作地租房的情形尤其容易撞车。
3. **非独生子女赡养老人按 3000 元扣。** 非独生子女与兄弟姐妹分摊每月 3000 元额度，**每人不超过 1500 元**。按 3000 填就是超额。
4. **老人未满 60 岁就填赡养老人扣除。** 年龄是硬门槛，**差一个月都不符合**。
5. **把扣除额当成少交的税。** 扣除 12000 元，若适用 10% 税率，少交的税约 1200 元，不是 12000 元。宣传口径与实际感受的落差往往源于此。
6. **职业资格没拿证就按 3600 元扣。** 3600 元是在**取得证书的当年**扣除，报名了、在考不等于已取得。
7. **大病医疗按全额自付扣。** 只有医保目录内个人自付**累计超过 15000 元的部分**才可扣，且年度限额 80000 元；自付 14000 元的可扣金额是 0。
8. **换工作或信息变更后不更新。** 扣缴义务人变更、子女升学、老人年满 60、房贷还清，都会改变扣除事实，不更新就会导致申报不实。
9. **留存资料没留。** 扣除是「自行申报＋留存备查」，核查时拿不出资料，扣除照样要调整。境外学历、职业资格证书、分摊协议尤其容易丢。

## 九、边界与免责

- 本技能用于填报前核查与材料整理，**不构成税务代理或法律意见**，不替代纳税人自行申报与税务机关认定
- 扣除标准、分摊规则、期间与留存资料要求，**均**以现行税法及税务机关公布口径为准**；政策调整时以最新公布为准
- 本核验为**静态口径**，未含跨年度结转、境外所得、股权激励、一次性补偿等特殊情形
- **不承诺不被核查、不被要求补税**，不提供虚增扣除、重复扣除、拆分收入的任何方案
- 涉及补税、滞纳金、处罚或争议，以税务机关认定为准，并应及时咨询税务师或律师
