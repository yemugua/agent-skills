# 个税专项附加扣除规则库

> 本规则库按现行常见口径整理。**具体标准以现行税法及税务机关公布口径为准**，政策调整时以最新公布为准。不得据此对外承诺申报结果。

---

## 一、七项扣除速查表

| 项目 | 标准 | 期间/期限 | 分摊与限定 |
|---|---|---|---|
| 3 岁以下婴幼儿照护 | 每婴幼儿每月 2000 元 | 婴幼儿出生当月至年满 3 周岁前一个月 | 父母一方 100% 或双方各 50%；**合计不超标准** |
| 子女教育 | 每子女每月 2000 元 | 学前教育（满 3 周岁当月至小学前）＋学历教育（入学至毕业） | 父母一方 100% 或双方各 50%；选择后一个纳税年度内一般不得变更 |
| 继续教育-学历学位 | 每月 400 元 | 同一学历（学位）最长 **48 个月** | 本科及以下学历继续教育，可选择由父母或本人扣除 |
| 继续教育-职业资格 | 取得证书当年 **3600 元** | 一次性 | 技能人员与专业技术人员职业资格；**未取得证书不得扣** |
| 大病医疗 | 自付累计超 **15000 元**的部分，年度限额 **80000 元** | 汇算清缴时办理 | 本人或配偶扣除；未成年子女可由父母一方扣除 |
| 住房贷款利息 | 每月 1000 元 | 最长 **240 个月** | 限于**首套**住房贷款；夫妻约定由一方扣；与住房租金不可同时享受 |
| 住房租金 | 1500 / 1100 / 800 元每月（按城市） | 租赁合同约定的租赁期 | 本人及配偶在主要工作城市**无自有住房**；与房贷利息不可同时享受 |
| 赡养老人 | 独生子女每月 **3000 元**；非独生子女分摊每月 3000 元额度，每人**不超过 1500 元** | 被赡养人年满 60 周岁当月至义务终止 | 指定分摊优先于约定分摊；分摊方式和额度确定后一个纳税年度内一般不得变更 |

### 1.1 住房租金城市档位

| 城市 | 每月标准 |
|---|---|
| 直辖市、省会（首府）城市、计划单列市及国务院确定的其他城市 | 1500 元 |
| 市辖区户籍人口超过 100 万的城市 | 1100 元 |
| 市辖区户籍人口不超过 100 万的城市 | 800 元 |

## 二、综合所得计算口径

```
综合所得应纳税所得额 = 年收入
                     − 60000                 （基本减除费用）
                     − 专项扣除              （基本养老保险、基本医疗保险、失业保险等个人负担部分）
                     − 专项附加扣除           （本规则库七项）
                     − 依法确定的其他扣除     （个人养老金、商业健康险、税延养老保险等，按各自限额）

应纳税额 = 应纳税所得额 × 适用税率 − 速算扣除数
```

### 2.1 七级超额累进税率表（综合所得，年度）

| 级数 | 全年应纳税所得额 | 税率 | 速算扣除数 |
|---|---|---|---|
| 1 | 不超过 36000 元 | 3% | 0 |
| 2 | 36000 – 144000 元 | 10% | 2520 |
| 3 | 144000 – 300000 元 | 20% | 16920 |
| 4 | 300000 – 420000 元 | 25% | 31920 |
| 5 | 420000 – 660000 元 | 30% | 52920 |
| 6 | 660000 – 960000 元 | 35% | 85920 |
| 7 | 超过 960000 元 | 45% | 181920 |

> 以上税率表为现行综合所得适用表口径，**以现行税法及税务机关口径为准**。

### 2.2 扣除额 ≠ 少交的税

```
少交的税额 ≈ 增加的扣除额 × 本人适用的边际税率
```

若边际税率为 10%，增加 12000 元扣除，少交的税约 1200 元，而非 12000 元。
若应纳税所得额已为 0 或负数，再增加扣除**不会带来更多退税**。

## 三、不得同时享受与重复扣除清单

| 情形 | 处理 |
|---|---|
| 住房贷款利息 与 住房租金 | 同一纳税年度内一般**不可同时享受**，择一 |
| 同一子女：父母双方各扣 100% | **重复扣除**，合计不得超每月 2000 元 |
| 同一婴幼儿：父母双方各扣 100% | **重复扣除**，合计不得超每月 2000 元 |
| 同一被赡养人：兄弟姐妹合计超 3000 元/月 | **超额**，需调整分摊 |
| 同一住房贷款：夫妻双方同时扣 | **重复扣除**，约定由一方扣 |
| 同一学历继续教育：本人与父母同时扣 | **重复扣除**，选择其一 |
| 同一职业资格证书：多个扣除年度重复扣 | **不得重复**，仅在取得证书当年扣 3600 元 |

## 四、留存资料清单

| 项目 | 留存资料 |
|---|---|
| 3 岁以下婴幼儿照护 | 婴幼儿出生医学证明等子女信息材料 |
| 子女教育 | 子女教育阶段与就读信息；境外留学的留存录取通知书、留学签证等 |
| 继续教育-学历学位 | 学籍、学费缴纳或录取材料；境外教育留存录取通知书、留学签证等 |
| 继续教育-职业资格 | **职业资格证书**（技能人员/专业技术人员职业资格目录内的） |
| 大病医疗 | 医疗服务收费票据（医保系统可查询的自付金额记录）、医保报销结算单 |
| 住房贷款利息 | **住房贷款合同**、贷款还款支出凭证；首套住房贷款认定材料 |
| 住房租金 | **住房租赁合同**、租赁备案或支付凭证 |
| 赡养老人 | 被赡养人身份信息；非独生子女的**分摊协议**（约定分摊或指定分摊书面文件） |

**留存原则**：纳税人对报送信息的真实性、准确性、完整性负责，相关资料需按规定留存备查。**核查时拿不出资料，扣除照样会被调整。**

## 五、填报与更正路径

```
① 确认本年度事实（子女、老人年龄、房贷、租房、证书、大病自付）
② 与配偶/兄弟姐妹确定分摊方式，签署分摊协议（如需要）
③ 在个税 App 或向扣缴义务人填报/更新扣除信息
④ 留存资料归档（按项目，跨年度的留存到规定期限）
⑤ 次年汇算清缴前重新核对事实是否变化
⑥ 发现填报错误的，及时更正；涉及补税的，按规定办理补税
```

**关键时间点**：扣除信息一般在**每年 12 月**确认次年信息；年度中间事实变化的，应及时更新。具体确认时间与方式以税务机关公布为准。

## 六、事实变化触发清单（每年至少核一遍）

| 变化 | 影响 |
|---|---|
| 子女出生 / 满 3 周岁 / 入学 / 毕业 | 婴幼儿照护与子女教育的起止月变化 |
| 被赡养人年满 60 周岁 | 赡养老人扣除起始月 |
| 兄弟姐妹情况变化 | 分摊额度变化 |
| 房贷还清 / 贷款超过 240 个月 | 房贷利息扣除终止 |
| 换城市工作 / 在主要工作城市购房 | 住房租金扣除资格变化 |
| 取得职业资格证书 | 当年可扣 3600 元 |
| 大病自付累计超 15000 元 | 汇算时可扣超额部分 |
| 结婚 / 离婚 | 分摊方式与房贷、房租扣除安排需重新确定 |

## 七、否定词防误伤清单（输出前逐条比对）

| 见到这些情况 | 必须这样判 | 严禁这样写 |
|---|---|---|
| 仅显示「已填报」 | 判为**待核验** | 「已确认可扣除」 |
| 分摊协议未签署 | 判为**分摊未成立**，按法定或不可分摊处理 | 「已按约定分摊扣除」 |
| 被赡养人未满 60 周岁 | 判为**不符合** | 「可享受赡养老人扣除」 |
| 非首套住房贷款 | 判为**不符合**房贷利息扣除 | 「可享受房贷利息扣除」 |
| 主要工作城市有自有住房 | 判为**不符合**住房租金扣除 | 「可享受住房租金扣除」 |
| 未取得职业资格证书 | 判为**不符合** 3600 元扣除 | 「可扣 3600 元」 |
| 大病自付未超 15000 元 | 判为**可扣金额为 0** | 「可扣自付金额」 |
| 夫妻双方各扣 100% | 判为**重复扣除**，必须纠正 | 「双方均可全额扣除」 |
| 准备去办 / 打算办理 | 判为**未取得**，不计入 | 「已符合扣除条件」 |
| 超过 48 个月的学历继续教育 | 判为**超出期间**，超出月份不扣 | 「继续按月扣 400 元」 |

## 八、核查应对要点

- 被要求说明或补正的，**按税务机关要求的期限和方式提交资料**
- 确有填报错误的，**及时更正**；涉及补税的按规定办理，不要拖延
- 对处理结果有异议的，**按告知渠道申请复核或依法救济**，保留提交记录与回执
- 涉及金额较大、情形复杂或已收到处罚通知的，**及时咨询税务师或律师**

---

## 九、免责

本规则库为办税实践整理，**不构成税务代理或法律意见**。扣除标准、分摊规则、期间、留存资料与核查要求，**均以现行税法及税务机关公布口径为准**。不得用于虚增扣除、重复扣除、虚构扣除事实或任何以少缴税为目的的虚假安排。
