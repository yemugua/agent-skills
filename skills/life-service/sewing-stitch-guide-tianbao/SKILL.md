# 缝补针法（sewing-stitch-guide）

衣服破了，补不好往往不是手笨，是**针法选错了**：该锁毛边的地方用了缭针、该隐藏线迹的地方用了回针、该留伸缩的位置用了平针。选对针法，手缝的牢度可以接近机缝；选错，缝三遍还是散。

这个技能做三件事：**选针法 → 配针线 → 核顺序**。

---

## 一、硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出破损形态与针法的匹配口径 | ❌ 改动服装版型、结构与立体剪裁 |
| 给出布料对应的手缝针号与线材选型 | ❌ 保证贵重面料（真丝重绉、羊绒、皮草）缝补后无痕 |
| 给出针距、缝份、起针收针的可执行数值 | ❌ 替代专业织补，大面积织补是专门工种 |
| 给出缝前缝后操作顺序的核验清单 | ❌ 处理需要拆整件重做的结构破损（如整片袖窿磨穿） |
| 给出熨烫、缩水、色牢度的风险提示 | ❌ 推荐具体品牌商品 |

**必须交给专业裁缝的情况**

- 西装、大衣、礼服等带衬结构与驳头的部位破损失常
- 皮革、麂皮、涂层面料、冲锋衣压胶层破损
- 破损面积超过手掌，或布料本身已糟朽（一拉就裂，经纬脆化）
- 需要保持原样鉴定、涉及退换货争议的衣物

## 二、什么时候用

| 用户说法 | 用不用 | 说明 |
|---|---|---|
| 「裤脚脱线了怎么缝」 | ✅ 用 | 缭针或藏针，看是否要求正面无线迹 |
| 「衣服破了个洞怎么补」 | ✅ 用 | 按布纹是否缺失分补丁或织补 |
| 「手缝怎么缝才结实」 | ✅ 用 | 回针缝，线迹密度与回针半针距是核心 |
| 「腋下崩开一条缝」 | ✅ 用 | 回针缝加固，注意这是受力加活动部位 |
| 「针织衫勾丝破洞」 | ✅ 用 | 按脱圈处理，不能用直线定针法硬拉 |
| 「把我这件大衣改成收腰」 | ❌ 不用 | 属改制版，超出范围 |
| 「羽绒服划了个口子」 | ⚠️ 部分 | 只给防钻绒的贴补思路，压胶层修复需专业 |

## 三、完整工作流

1. **看布料**：判断是薄软、中厚、厚硬，还是针织带弹。这一步决定针号、线材、针距，跳过会把后面全搞错。
2. **看破损**：区分「只是缝线崩了」「纤维缺了（破洞）」「只是毛边」「针织脱圈勾丝」四类，四类补法完全不同。
3. **看受力**：腋下、袖口、裤裆、膝盖这些地方既要伸缩又要强度；下摆、贴边相对静态。
4. **选针法**：按 `rules/针法选型与线材搭配表.md` 的匹配表取，不要凭印象。
5. **配针线**：按布料取手缝针号、线材材质、线的粗细。
6. **定数值**：针距、缝份、回针半针距。
7. **缝前处理**：熨平归正，必要时先疏缝临时固定再正式缝。
8. **缝后处理**：起针收针回 2 到 3 针打牢，剪余线，熨烫定型。
9. **核对**：用 `--file` 跑一遍计划，确认没有选错项，再落针。

## 四、核心规则说明

**生成任何缝补方案前，必须先读这两个文件，不要凭印象写：**

- `rules/针法选型与线材搭配表.md` —— 五种基础针法的适用与禁用场景、布料到针号与线材的选型表、禁用组合清单
- `rules/缝补流程与尺寸口径.md` —— 针距、缝份、回针半针距、起收针、熨烫、顺序要求与结论分类

要点三条：

1. **回针缝是手缝的主力承重针法**，半回针牺牲一点强度换速度。承重部位不要只用平针。
2. **看不见线迹不等于结实**。藏针缝、缭针缝属于隐藏类，靠的是间距小、吃布浅，不适合承重。
3. **针织和弹力布的关键是缝完还能拉开**：用有弹的涤纶线、球头针、允许拉伸的针法，棉线配直线针法一拉就崩。

## 五、脚本用法

```
python scripts/stitch_plan.py --selftest
python scripts/stitch_plan.py --file plan.json
```

输入字段：

| 字段 | 说明 | 示例 |
|---|---|---|
| fabric | 布料类型 | 「真丝雪纺」「针织汗布」「牛仔」 |
| damage | 破损形态 | 「顺缝崩线」「勾丝脱圈」「破洞缺肉」 |
| position | 部位 | 「下摆」「腋下」「膝盖」 |
| stitch | 选用针法 | 「回针缝」「缭针缝」「锁边缝」 |
| thread | 线材 | 「涤纶线」「棉线」「弹力线」 |
| needle | 手缝针号 | 9、7、5 |
| stitch_length_mm | 针距毫米 | 2.0 |
| seam_allowance_mm | 缝份毫米 | 10 |
| steps | 操作顺序列表 | 见规则文件 |
| prewash | 是否预缩水处理 | true |

顺序检查按**填的实际顺序**判定，不会因为「凑齐了这几步」就判通过；顺序填错直接判不合格。

结论分三档：**先处理**（存在禁用组合或超出硬口径）、**待确认**（信息不足）、**可照此执行**。脚本先看真实缺陷，再看信息是否完整——不会因为漏填一项就掩盖已查出的选错。

结果写入 `scripts/_last_result.txt`。每条不合格都带原因，不是只甩一个结论。

## 六、人工确认清单（这步不能省）

- [ ] 针法与该布料、该破损形态、该部位的匹配已确认
- [ ] 手缝针号在布料允许区间内
- [ ] 线材材质兼容布料弹力需求
- [ ] 针距、缝份在推荐区间
- [ ] 已做熨烫归正，或已确认可免熨
- [ ] 需要伸缩的部位，所选针法允许伸缩
- [ ] 起针、收针都有回针打牢
- [ ] 贴布补丁的经纬方向与面料一致，且已剪圆角、留出缝份
- [ ] 面料能否承受熨斗温度已确认（不确定先在废布头试）

## 七、最常见的坑

1. **不该用棉线的地方用了棉线**。棉线几乎无弹，缝弹力布料一撑就崩线，且洗后缩率与布料不一致，缝口会抽皱。
2. **该锁毛边的地方直接缭边**。斜裁边和毛边不先锁边或包边，洗两次就从边缘秃一圈，补了等于没补。
3. **承重部位用藏针缝或缭针缝**。这两种是隐藏类针法，吃布浅、线迹松，受力后会被拉开。
4. **贴布补丁没有对齐布纹**。补丁经纬与面料方向不一致，洗完一边缩一边不缩，补丁直接鼓成硬包。
5. **跳过缝前熨烫和疏缝**。亲眼看到的裂口已经是歪的，直接缝，缝完起皱、错位、两边长短差一截。
6. **薄软面料用了粗针**。真丝上用粗针会留永久针孔，拆了都消不掉。
7. **起收针没回针**。缝了一大段，头尾却没有回针打牢，穿两次就从头崩。
8. **针织破洞用直线针法硬揪**。把破口拉成一字凸起，脱圈的线圈继续往下跑，洞越来越大。
