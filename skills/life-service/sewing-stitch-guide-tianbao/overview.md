# 缝补针法

你会得到一套**能照着落针的缝补方案**，而不是一句「用回针缝就好」。

## 你会得到什么

1. **针法匹配**：按布料的薄厚与是否带弹、破损形态（顺缝崩线、破洞缺肉、毛边、针织脱圈勾丝）、受力情况三个维度，选出他要用的那一种——回针缝、半回针缝、缭针缝、藏针缝、锁边缝、贴布补丁，并说清为什么是它、哪些是禁选。
2. **针线配置**：布料对应的手缝针号区间、线材该选涤纶线还是棉线还是弹力线、要不要换球头针。这一项选错，缝得再整齐也白费。
3. **可执行数值**：针距多少毫米、缝份留多少毫米、回针的半针距怎么取、起针收针怎样回针打牢。
4. **顺序核验**：熨烫归正 → 疏缝固定 → 正式缝合 → 收尾熨烫的顺序有没有走反，这里最容易省掉的是前两步。
5. **校验脚本**：把方案填进 json，跑一遍 `stitch_plan.py`，把「禁用组合」「超出硬口径」「信息不足」三类问题带原因列出来。

## 典型用法

- 裤脚脱线：问的是怎么缝，重点是正面要不要无线迹——要就选藏针缝，不在乎就选缭针缝，两者都先处理毛边。
- 衬衫腋下崩开：这是受力加活动的部位，要用回针缝加回针加固，用隐藏类针法一定返工。
- 针织衫勾丝：不是缝的问题，是线圈跑的问题，按脱圈处理，直线针法硬拉只会让洞变大。
- 裤子膝盖破洞：看缺不缺「肉」。缺了就用贴布，经纬方向必须跟面料一致，否则洗完鼓包。

## 边界

不做服装改制版、不做版型调整、不保证贵重面料无痕。西装大衣带衬部位、皮革麂皮、冲锋衣压胶层、糟朽面料（一拉就裂）一律转交专业裁缝。宠物意外伤害不在此范围。所有方案的最终外观与耐洗程度取决于实际操作，动手前请先在废布头试一遍。
