# 失智老人沟通技巧与走失预防

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 给出沟通原则与可直接照着说的句式 | 诊断失智类型、分期或病因 |
| 解释常见沟通障碍（黄昏症候群、认人困难、重复提问）的应对思路 | 给药物方案、镇静剂使用建议或剂量 |
| 输出居家环境改造与走失预防措施清单 | 承诺「这样就不会走失」或给走失概率数字 |
| 给出走失后立即处置流程与报警信息清单 | 组织家庭多人分头寻找而不报警 |
| 提示何时联系医生与专业机构 | 代替医生评估，断言病情进展 |
| 提供家属自我照顾与沟通节奏建议 | 建议限制老人活动范围、锁禁或约束措施作为常规手段 |

**必须立即就医或联系医生的红线（出现任一条，当天联系医生；标注急诊的直接急诊）**

- 突然的意识混乱、说不清话、单侧无力、言语含糊 —— **急诊**，排除急性脑血管事件
- 发热伴意识改变、尿液浑浊异味伴精神行为突变 —— 可能为感染诱发，需当天就医
- 突发剧烈头痛、呕吐、抽搐、跌倒后头部着地 —— **急诊**
- 出现幻觉妄想被害内容后极度恐惧、拒绝进食、长时间不睡
- 出现攻击行为、拒绝一切照护、有伤人或自伤风险
- 出现明确的自杀意念
- 走失后经报警仍无法定位，或本人出现迷路后过度行走、脱水、失温表现
- 出现新发吞咽困难、进食呛咳、反复肺部感染

**必须立即报警的情形**：老人走失且短时间内无法在附近找到。**走失后 6 小时是黄金期**，超过后找回难度显著上升。家属自行寻找不构成充分处置，必须报警并同步其他措施。

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「老人痴呆不认我是谁」 | 用，认人困难处理思路 |
| 「一直问同样的问题怎么答」 | 用，重复提问的回应方式 |
| 「老人走丢了怎么找」 | 用，走失后处置流程 |
| 「要不要把门锁上」 | 用，走失预防三级措施，说明锁禁不是首选 |
| 「傍晚就开始闹怎么办」 | 用，黄昏症候群处理 |
| 「跟他说什么都听不懂」 | 用，沟通原则与句式 |
| 「给他吃什么药能安静」 | 不用，用药由医生决定 |
| 「去哪个医院看」 | 只作就医提示，不指定医院与科室以外的内容 |
| 「老人是不是变严重了」 | 只提示需要医生评估，不做病情判断 |

## 三、完整工作流

1. **先排红线**：逐条核对就医与报警红线，命中即就医或报警。
2. **判断当前障碍类型**：按 `rules/沟通原则与障碍处理.md` 的四类障碍对照表，判断是重复提问、认人困难、黄昏症候群，还是理解与表达受损。
3. **给沟通方案**：按七条原则生成一句具体能用的说法，避免给「多沟通」这类空话。
4. **排查诱因**：疼痛、饥饿、口渴、困倦、便秘、尿憋、环境嘈杂、光线不足、昼夜节律颠倒。
5. **出环境改造清单**：按 `rules/走失预防与居家安全.md` 输出门、窗、楼梯、卫生间、厨房等具体做法。
6. **出走失预防三级措施**：随身识别卡、门禁与提醒、定位设备，逐级说明局限。
7. **出走失预案**：走失后立即处置流程、报警信息清单、6 小时黄金期口径。
8. **安排家属自我照顾**：沟通节奏与照护者休息安排。

## 四、核心规则与要件库

生成任何建议前，**必须先读**：

- `rules/沟通原则与障碍处理.md`：七条沟通原则、四类常见障碍对照、可照着说的句式、诱因排查表。
- `rules/走失预防与居家安全.md`：居家环境改造、三级预防措施、走失后处置流程、报警信息清单。

不得给药物与镇静方案；不得诊断与分期；不得承诺不会走失或给找回概率；不得把锁禁与约束作为常规手段推荐。

## 五、脚本用法

```
python scripts/dementia_safety_plan.py --file case.json
python scripts/dementia_safety_plan.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`obstacle` 障碍类型标记（`repeat_question` `not_recognize` `sundowning` `comprehension`），`risks` 环境风险标记（`front_door` `back_door` `window` `stair` `elevator` `alone_out`），`red_flags` 红线标记，`minutes_since_missing` 走失已过分钟数 |
| `--checklist` | 只输出走失预防与报警信息清单 |
| `--json` | 以 JSON 输出 |
| `--out` | 结果写入指定文件，默认 `scripts/_last_result.txt` |
| `--selftest` | 运行自检 |

脚本输出障碍处理要点、环境风险覆盖、走失处置与报警清单。**脚本不给药物、不做诊断、不给找回概率。**

## 六、人工确认清单

- [ ] 红线已逐条核对，命中即就医或报警
- [ ] 已区分「暂时没反应」与「急性的意识改变」
- [ ] 沟通方案已给出具体可照着说的句子，不只是原则
- [ ] 已排查诱因（疼痛、饥渴、困倦、便秘、尿憋、光线、噪音）
- [ ] 未使用药物或镇静手段让老人「安静」
- [ ] 未把锁禁、约束作为常规手段
- [ ] 随身识别卡已制作并**由老人随身携带**（不是放在家里）
- [ ] 门禁与提醒已按可执行的方式落实
- [ ] 定位设备已评估（含隐私与依从性，不强制）
- [ ] 走失预案已写明：立即报警、6 小时黄金期、报警要提供的信息
- [ ] 已安排照护者休息，不是全天单人硬扛

## 七、最常见的坑

1. **跟老人讲道理**：认知功能下降不是态度问题，讲道理没有作用只会换来对抗。
2. **纠正与争辩**：「你说什么都对」「你记错了」这类纠正会直接放大对抗与羞耻感。
3. **提早告诉坏消息**：说「你再也回不了家了」会引发强烈恐惧，用温和的转移更有效。
4. **黄昏时段硬扛**：傍晚症状加重时硬碰硬，往往两败俱伤。要提前准备环境与节奏。
5. **怕丢就用锁**：锁门可以临时防走失，但会加重无力感与冲突，掩盖真正的照护需求。
6. **把识别卡放家里**：卡必须随身且老人愿意带着，放抽屉里等于没做。
7. **走失后先自己找几小时再报警**：这恰恰浪费了最重要的 6 小时。报警不丢人，拖延才危险。
8. **报警时不带照片、不带特征**：信息不全会让查找效率大幅下降。
9. **给老人吃「安静药」**：镇静类药物由医生决定，且可能增加跌倒与意识混乱风险。
10. **只照顾老人不照顾照护者**：照护者耗竭后，沟通质量会一起崩掉。
11. **认为「忘了是正常的，不用管」**：突发的记忆骤降可能是感染、药物或急性事件的信号，要就医。
12. **反复换照顾者**：每次换人都会加重混乱，尽量固定主要照顾者。

## 八、边界与免责

本技能提供失智老人的沟通参考、走失预防措施与走失后处置流程，**不提供诊断、分期、病因判断、药物或镇静方案，也不给出找回概率承诺**。突然的意识改变、单侧无力、言语含糊、发热伴行为突变等情况必须立即就医排查急性病因。老人走失且短时间内无法找到时，**必须立即报警，走失后 6 小时是黄金期**。失智照护方案应结合医生与专业机构的评估，**以最新版相关指南和专业医护人员的判断为准**。
