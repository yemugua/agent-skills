## 四、必须立即联系医生的信号（出现任一项打勾）

- [ ] 突然的意识混乱、说不清话、单侧无力、言语含糊 —— **急诊**
- [ ] 发热伴意识改变、尿液浑浊异味伴精神行为突变 —— 当天就医
- [ ] 突发剧烈头痛、呕吐、抽搐、跌倒后头部着地 —— **急诊**
- [ ] 幻觉妄想后极度恐惧、拒绝进食、长时间不睡
- [ ] 出现攻击行为、拒绝一切照护、有伤人或自伤风险
- [ ] 出现明确的自杀意念
- [ ] 新发吞咽困难、进食呛咳、反复肺部感染

**口径提醒**：渐进性变化可能是病情进展，找医生评估；**1-2 天内突然明显改变，先排查感染、药物与急性事件**。

## 五、照护者自我检查（每周一次）

| 项目 | 本周情况 |
|---|---|
| 是否有过完整的半天休息 | |
| 睡眠平均是否低于 6 小时 | |
| 是否出现持续失眠或情绪低落 | |
| 是否曾出现对老人的排斥感 | |
| 是否已向家人或专业支持求助 | |

**口径提醒**：出现持续失眠、情绪低落、对老人产生排斥感，是正常的求助信号，不是失败。能持久照护就是好照护。
