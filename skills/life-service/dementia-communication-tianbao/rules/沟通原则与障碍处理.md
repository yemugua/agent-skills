# 沟通七原则与常见障碍处理

**边界前置**：本表提供沟通参考，**不做失智诊断与分期**。突然的、快速的记忆或行为改变是急性事件信号，必须就医，不属于本表处理范围。

## 一、七条沟通原则

| 原则 | 具体做法 | 反例（不要这样做） |
|---|---|---|
| P1 短句 | 一句话说一件事，控制在十个字以内 | 讲一大段道理 |
| P2 不否定情绪 | 先接住情绪，再处理事情 | 「你说什么都对」 |
| P3 用肯定句 | 说「现在我们吃饭好吗」 | 说「你别问了」 |
| P4 二选一而非开放问 | 给两个具体选项 | 「你想吃什么」（开放题无解） |
| P5 一次只提一件事 | 不叠加多个要求 | 同时催穿衣和洗脸 |
| P6 慢一点，留出反应时间 | 说完等 5-10 秒，不要重复追问 | 立刻追问「你听到没有」 |
| P7 不纠正、不羞辱 | 不说「你记错了」「你怎么这么笨」 | 当众纠正、拿别人比较 |

**通用句式模板**：

- 呼唤注意力：轻轻叫名字 + 停顿 + 再说一遍名字，不要连叫三声
- 转移注意：「我们先吃饭，吃完再看这个」+ 立刻执行（不给等待窗口）
- 结束话题：「这件事我们下次说」+ 岔开到一个熟悉的话题
- 确认理解：不说「你明白了吗」（答案永远是「不」），改说「我给你拿下衣服好不好」

## 二、四类常见沟通障碍

### 障碍一：重复提问（同一个问题问几十遍）

| 项 | 内容 |
|---|---|
| 表现 | 反复问「今天吃什么」「什么时候回家」，语气可能带焦虑 |
| 背后 | 短期记忆受损，记不住自己刚问过；不代表没听懂你的回答 |
| 处理 | 第一次回答时给具体信息（「现在是吃饭时间，我们吃面条」） |
| 处理 | 第二次不再重复解释，用转移代替（「好，我们先站起来」） |
| 处理 | 若因找东西反复问：把要找的东西放在固定位置并贴上标识 |
| 禁忌 | 责骂「我刚说过了」、反复解释、大声、表现无奈叹气 |

### 障碍二：认人困难（不认得家人，把家人当陌生人）

| 项 | 内容 |
|---|---|
| 表现 | 问「你是谁」、对家人表现出戒备、把家人当成闯入者 |
| 背后 | 与面孔识别功能受损有关，不是感情问题 |
| 处理 | 不争辩「我是你女儿」，改为「你饿了吧，我们吃点东西」 |
| 处理 | 保持距离、不突然从背后接近，先打招呼再接触 |
| 处理 | 出现攻击或极度恐惧时，退出房间，等情绪平复再接近 |
| 处理 | 把本人照片放在显眼处（客厅、饭桌旁），并在照片上写「这是你的女儿」 |
| 禁忌 | 强行拥抱、拍照指认（「你看这是谁」）、多人同时靠近 |

### 障碍三：黄昏症候群（傍晚与夜间症状加重）

| 项 | 内容 |
|---|---|
| 表现 | 傍晚后烦躁、喊叫、拒绝、想往外走、坐立不安 |
| 背后 | 昼夜节律颠倒、光线不足、环境嘈杂、疲劳、疼痛、憋尿 |
| 处理 | 白天增加光照与活动，避免下午长时间卧床 |
| 处理 | 傍晚前完成洗漱与穿衣，把容易引发冲突的事放在白天 |
| 处理 | 保持室内光线充足，避免昏暗与阴影造成的误认 |
| 处理 | 准备安静熟悉的环境，减少电视、人群与噪音 |
| 处理 | 排查诱因（见诱因排查表），能排除一项就少一项诱因 |
| 禁忌 | 傍晚硬碰硬、临时改变环境、直接约束 |

### 障碍四：理解与表达受损（听不懂、说不出）

| 项 | 内容 |
|---|---|
| 表现 | 答非所问、词不达意、找不到词、说话越来越短 |
| 处理 | 用手势和实物替代语言（「喝水」说 + 递杯子） |
| 处理 | 问封闭问题（是/不是）：「要不要喝水？」而不是「你想喝什么」 |
| 处理 | 一次只给一个选择，不要三选一 |
| 处理 | 保留老人原有的称呼与习惯用语，不纠正 |
| 禁忌 | 代他把话说完后当作他的意思执行、催促表达、笑话其表达不清 |

## 三、诱因排查表（行为突然变差时先查这些）

| 诱因 | 表现线索 | 处理方向 |
|---|---|---|
| 疼痛 | 皱眉、拒绝触碰、指着某部位 | 请医生评估疼痛，不自行给止痛药 |
| 饥饿 | 反复找食物、烦躁 | 给固定加餐时间，不在情绪爆发时谈吃饭 |
| 口渴 | 反复要水、嘴干 | 固定饮水量与温水的放置位置 |
| 困倦 | 打哈欠、注意力涣散 | 安排休息时段，不在疲劳时沟通 |
| 便秘或尿憋 | 躁动、反复起身 | 定时如厕，建立如厕习惯，异常时就医 |
| 光线不足 | 黄昏时加重 | 傍晚前开灯，保证室内明亮 |
| 环境嘈杂 | 多人、电视、施工时加重 | 减少噪音，移到安静房间 |
| 昼夜节律颠倒 | 白天睡晚上闹 | 白天增加光照与活动，限制白天长睡 |
| 人员变动 | 换了照顾者后加重 | 固定主要照顾者，变动要预告并有缓冲 |

**判断口径**：**渐进性变化 → 可能是病情进展，找医生评估；突然性变化（1-2 天内明显改变）→ 先排查感染、药物、急性事件，当天就医。**

## 四、家属自我照顾（同样重要）

- 每周至少安排半天完全离开照护角色，由他人接手
- 把「今天的困难」写下来而不是全部压在自己身上，4 周后回看会发现规律
- 不把自己的照护水平等同于孝顺标准，能持久地照护就是好照护
- 出现持续失眠、情绪低落、对老人产生排斥感时，向家人或专业支持寻求帮助，这是正常信号不是失败

## 五、什么情况必须联系医生

- 突然的意识混乱、说不清话、单侧无力、言语含糊 —— **急诊**
- 发热伴意识改变、尿液浑浊异味伴精神行为突变 —— 当天就医（感染诱发）
- 突发剧烈头痛、呕吐、抽搐、跌倒后头部着地 —— **急诊**
- 幻觉妄想后极度恐惧、拒绝进食、长时间不睡
- 出现攻击行为、拒绝一切照护、有伤人或自伤风险
- 出现明确的自杀意念
- 新发吞咽困难、进食呛咳、反复肺部感染
