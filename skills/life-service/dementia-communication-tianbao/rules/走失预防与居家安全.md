# 走失预防与居家安全

## 一、居家安全环境改造清单（逐项核对）

| 位置 | 具体做法 | 为什么 |
|---|---|---|
| 入户门 | 门链、门锁、内侧加装低位暗锁或门吸；门的颜色与墙面区分明显 | 降低开门便利性，同时不制造压迫感 |
| 阳台门 | 保持锁闭，窗台高度不作为落脚点 | 减少高坠与走失路径 |
| 窗户 | 锁闭，窗边不放可攀爬家具 | 防坠落 |
| 楼梯 | 上下楼口装门；夜间灯感应亮起 | 防跌倒与误入 |
| 电梯 | 轿厢与楼层按钮做明显区分；不单独带老人乘电梯下楼 | 防误操作 |
| 卫生间 | 装扶手、防滑垫；门能从外开或装可观察装置 | 防跌倒与被困 |
| 厨房 | 燃气自动关闭装置；锅具远离边缘；调料与刀具收起 | 防烫伤与误用 |
| 卧室 | 床头与地面留出活动空间；移除小桌与杂物 | 防跌倒撞伤 |
| 阳台与窗边 | 不放凳子、箱子等可踩物 | 防攀爬出走 |
| 楼道与小区 | 与邻居打个招呼，请留意异常 | 邻里是最快的观察者 |
| 光照 | 全程照明，夜间走廊留小夜灯，感应式更佳 | 减少夜间迷失方向 |
| 迷路风险动作 | 外出有陪同、外出前说明去哪里与多久回 | 行为层面的预防 |

## 二、走失预防三级措施（按强度递增）

| 级别 | 措施 | 局限与注意 |
|---|---|---|
| 第一级 | **随身识别卡**：姓名、年龄、家属电话、简单病史、照片、居住地信息 | 卡必须**由老人随身携带**，放在抽屉里等于没做；卡片要小、要固定、不要放钱包底层 |
| 第二级 | **门禁与出门提醒**：门链、暗锁、门吸、感应灯、门垫提示字 | 是延迟而非阻止；**锁禁不是长期方案**，会加重无力感与冲突，应与其他级同时推进 |
| 第三级 | **定位与随身设备**：定位手表、定位卡、防走失鞋 | 需考虑老人依从性、隐私意愿与电池续航；不强制、不强迫佩戴 |

**共同原则**：三级叠加使用更可靠。**任何一级都不能保证「不会走失」**，不得给出概率承诺。

## 三、识别卡内容模板（照着做一张）

```
┌──────────────────────────────┐
│  照片（近期、正面、清晰）        │
│                              │
│  姓名：                     │
│  性别 / 出生年月：            │
│  身高 / 体型特征：            │
│  衣着特征（常穿颜色）：        │
│  走失时的可能特征：            │
│                              │
│  家属姓名：                  │
│  电话：                      │
│  备用联系人与电话：            │
│                              │
│  居住地：                    │
│  常去场所（市场、公园等）：     │
│                              │
│  简单健康情况：               │
│  （听力 / 视力 / 说话 / 表达  │
│   困难 / 是否需要随身药物）    │
│                              │
│  发现走失请联系：____         │
└──────────────────────────────┘
```

**制作要点**：塑封防水、系在钥匙串或衣物内侧口袋、不放钱包底层。

## 四、走失后立即处置流程

**核心口径：走失后 6 小时是黄金期，超过后找回难度显著上升。家属自行寻找不构成充分处置，必须立即报警。**

| 步骤 | 动作 | 时间要求 |
|---|---|---|
| 第 1 步 | 立即报警，说明老人走失 | 发现后立即，不观察等待 |
| 第 2 步 | 报警时提供完整信息（见第五节清单） | 同一次通话内 |
| 第 3 步 | 报警同时安排家人分头在附近找（小区、周边路口、常去场所） | 与报警同步，不等报警结束 |
| 第 4 步 | 在明显位置留一张寻人信息（照片与电话） | 找到后收回 |
| 第 5 步 | 联系物业、保安、邻里、社区说明情况 | 同步进行 |
| 第 6 步 | 联系老人常去场所与熟悉的人 | 同上 |
| 第 7 步 | 若发现老人，立即确认身体状况与情绪，先保暖与补水 | 找到后 |
| 第 8 步 | 事后复盘：哪一步能提前（识别卡、定位、门禁） | 找到后 |

**绝对禁止**：先自己找几小时再报警；只在小区内找而不报警；不提供照片与特征；分头行动但不告知彼此去向。

## 五、报警时必须提供的信息清单

| 项 | 说明 |
|---|---|
| 走失时间 | 确切时间或「约 X 小时前」 |
| 最后出现地点 | 具体到小区、楼栋、楼层 |
| 走失时衣着 | 上下衣颜色、鞋、外套、有无戴帽 |
| 身体特征 | 身高、体型、发型、有无眼镜、走路姿态 |
| 健康情况 | 听力视力、说话是否清楚、能否独自行走 |
| 是否需要随身药物 | 是否有慢性病用药中断风险 |
| 认知与自理能力 | 能否自己找厕所、能否进食、会不会走错方向 |
| 家属姓名与电话 | 保持电话畅通 |
| 常去场所 | 市场、公园、老朋友家、庙会等 |
| 是否有定位设备 | 型号与是否开启 |
| 疾病与用药史 | 供救助时参考 |

## 六、走失后的身体风险预警

找到后若出现以下表现，立即送医：

- 过度行走后脱水：口唇干裂、皮肤弹性差、尿量少
- 低温暴露：手脚冰凉、反应迟钝、意识模糊
- 暴晒：中暑样表现、皮肤发烫、意识不清
- 跌倒或外伤：头部着地后呕吐、意识改变、肢体不能动
- 长时间未进食：低血糖样表现（心慌、出冷汗、意识模糊）
- 情绪极度惊恐或持续兴奋不睡

## 七、家属的日常预防习惯

- **固定外出路线与时间**，尽量规律
- **外出有陪同**，尤其去人多地方
- **每次外出前口头确认**：去哪、多久回、认路的关键词
- **邻里与物业知情**：说明情况、请协助留意
- **不在吵架或情绪激动时让老人独自在家**
- **不要在门口争执**，门口是走失高发场景
- **每月更新识别卡照片**（照片过旧会影响识别）
- **每月一次走失演练**：约定一个联系方式与集合点
