# 气瓶安全管理（gas-cylinder-safety）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据气瓶安全技术规程与常用气瓶要求，生成气瓶安全清单：气瓶检验周期与色标、直立固定与防倾倒、间距与防晒、减压器与软管、空实瓶分区与运输。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 气瓶安全
- 气瓶管理
- 氧气乙炔瓶
- 气瓶检验
- 气瓶存放

## 三、工作流
1. 核查气瓶检验周期与色标
2. 落实直立固定与防倾倒
3. 保持间距并防晒
4. 检查减压器与软管
5. 分区存放空实瓶并规范运输

## 四、核心内容（检查清单与判定）
气瓶须在检验周期内、色标清晰，直立固定防倾倒，与明火保持间距并防晒；氧气与乙炔等气瓶应分区，运输时戴瓶帽防震圈。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含检验周期与色标核查 | 检验 |
| Q2 | FAIL | 未含直立固定与防倾倒 | 防倾倒 |
| Q3 | WARN | 未含间距与防晒 | 间距 |
| Q4 | FAIL | 未含减压器与软管检查 | 减压器 |
| Q5 | WARN | 未含空实瓶分区与运输 | 分区 |

> 脚本 `gas-cylinder-safety_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python gas-cylinder-safety_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python gas-cylinder-safety_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
