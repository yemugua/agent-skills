# 建设项目三同时（three-simultaneous）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《安全生产法》与建设项目安全设施三同时要求，生成三同时清单：安全预评价/安全生产条件和设施综合分析、安全设施设计、安全设施施工与监理、试运行与竣工验收、留痕归档。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 三同时
- 安全设施三同时
- 建设项目安全
- 安全预评价
- 安全设施设计

## 三、工作流
1. 开展安全预评价或综合分析
2. 编制安全设施设计并审查
3. 按设计施工并监理
4. 组织试运行
5. 完成竣工验收并归档

## 四、核心内容（检查清单与判定）
《安全生产法》要求建设项目安全设施与主体工程同时设计、同时施工、同时投入生产和使用；各阶段须有评价、设计与验收留痕。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含安全预评价/综合分析 | 预评价 |
| Q2 | FAIL | 未含安全设施设计与审查 | 设计 |
| Q3 | WARN | 未含按设计施工与监理 | 施工 |
| Q4 | FAIL | 未含试运行与竣工验收 | 验收 |
| Q5 | WARN | 未含资料归档留痕 | 归档 |

> 脚本 `three-simultaneous_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python three-simultaneous_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python three-simultaneous_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
