# 医保关系转移接续规则与办理清单

> 各地经办口径、线上渠道和年限规则可能不同，以下为通用核查框架，最终以现行规定和当地医疗保障部门要求为准。

## 一、先判断要不要转

| 情形 | 建议 |
|---|---|
| 已在新参保地正常参保，且原参保地已停保 | 通常需办理转移接续，累计缴费年限并衔接个人账户 |
| 只是短期就医、出差、转诊 | 先确认是否只需异地就医备案或联网结算 |
| 两地同时参保缴费 | 先处理重复参保，不重复享受待遇 |
| 已确定退休地或待遇领取地 | 先向待遇地经办机构确认年限和办理顺序 |
| 跨制度：职工转居民、居民转职工 | 年限折算、账户处理和待遇衔接以转入地规则为准 |

## 二、常见流程

1. 在转入地正常参保或在转出地办理停保。
2. 通过国家统一医保信息平台、地方政务或医保应用提交转移接续申请，或到窗口办理。
3. 转出地核对参保记录、缴费年限和个人账户信息。
4. 转入地接收并核对，办理年限累计、账户资金划转或信息接续。
5. 参保人查询结果确认办结，并核对年限、账户和待遇起始月。

## 三、时限口径

- 线上提交后应即时取得申请编号或受理回执。
- 常见口径：转出地和转入地各自在规定工作日内完成核对与办理，整体通常在 **45 个工作日**左右；信息不全、欠费、重复参保、跨制度或单位欠缴情形会延长。
- 「已提交」「已受理」「已办结」是三个不同状态，只有办结才代表年限和账户已处理。
- 具体时限以经办机构告知和平台状态为准。

## 四、材料清单

| 材料 | 用途 | 高频被卡原因 |
|---|---|---|
| 身份证件 | 核验参保人身份 | 姓名、证件号与参保登记不一致 |
| 参保或缴费凭证 | 核对参保起止月 | 缺历史参保记录或单位未申报 |
| 转移接续申请信息 | 明确转出、转入地 | 选错统筹区或参保类型 |
| 单位或代办材料 | 委托办理情形 | 授权不全、印章不符 |
| 特殊情形证明 | 视同年限、安置、军人等政策情形 | 缺主管部门认定材料 |
| 重复参保处理申请 | 退费或保留一方 | 未提供重复期间缴费明细 |

## 五、年限与账户口径

| 项目 | 核查方式 | 注意 |
|---|---|---|
| 实际缴费月数 | 按月核对参保记录 | 断缴月份不当然计入连续缴费 |
| 视同缴费年限 | 依政策认定材料 | 不与实际缴费直接混算 |
| 跨制度年限 | 以转入地规则为准 | 职工与居民口径不同 |
| 个人账户余额 | 核对划转金额与时间 | 单独核对利息与到账 |
| 退休最低缴费年限 | 向待遇地经办机构确认 | 男女、参保类型和地区可能不同 |
| 补缴或延缴 | 由经办机构核定 | 不得自行判断金额和年限 |

## 六、中断与重复参保

- 中断缴费可能影响待遇享受起始、连续缴费认定和退休年限计算；具体等待期和补缴规则以当地政策为准。
- 重复参保期间通常不得重复享受待遇，重复的缴费处理需按经办机构要求选择保留、清退或合并口径。
- 单位原因导致漏缴或少缴的，应先与单位和经办机构核实补缴路径，保留劳动合同、工资和申报记录。

## 七、常见被卡原因

- 转出地仍有未办停保或未结清记录。
- 姓名、证件号、参保地或参保类型在系统不一致。
- 存在欠费、退费在途或重复参保。
- 单位代办材料缺失或授权不足。
- 跨制度转移缺少政策认定材料。
- 误把异地就医备案当成转移，导致年限未累计。

## 八、办理时限、补正与救济

- 提交后保存编号、回执和状态截图，按经办机构告知的期限跟踪。
- 被要求补正时，索取明确的缺件、格式和截止时间，形成补正对照表。
- 对不予受理、年限核定、退费或待遇认定有异议，先向经办机构申请复核；对正式行政决定不服的，按文书载明渠道依法申请行政复议或诉讼。
- 单位欠缴或拒不配合的，可保留劳动关系和工资凭证，向劳动保障监察、医保或税务缴费管理部门咨询反映。
