# 六西格玛 DMAIC（six-sigma）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据六西格玛管理方法论，生成 DMAIC 改进清单：定义（DCTQ/项目章程）、测量（Y 与 X 数据）、分析（根因/假设检验）、改进（DOE/方案）、控制（SPC/控制计划）。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 六西格玛
- DMAIC
- 6sigma
- 精益六西格玛
- 过程改进

## 三、工作流
1. 定义阶段：明确 CTQ 与项目章程
2. 测量阶段：收集 Y 与 X 数据并验证测量系统
3. 分析阶段：识别关键 X 与根因（假设检验）
4. 改进阶段：通过 DOE 优化方案
5. 控制阶段：SPC 与控制计划固化成果

## 四、核心内容（检查清单与判定）
六西格玛以 DMAIC 为主线，追求缺陷率降至 3.4ppm（六西格玛水平）；强调数据驱动与统计工具，改进成果须以控制计划与 SPC 长期保持。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含定义阶段（CTQ/章程） | 定义 |
| Q2 | FAIL | 未含测量阶段（Y/X 数据） | 测量 |
| Q3 | FAIL | 未含分析阶段（根因） | 分析 |
| Q4 | FAIL | 未含改进阶段（DOE/方案） | 改进 |
| Q5 | WARN | 未含控制阶段（SPC/控制计划） | 控制 |

> 脚本 `six-sigma_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python six-sigma_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python six-sigma_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 八、常见坑

- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
