# 胜任证据与岗位匹配度规则库

> 写胜任证据前先读本文件。**第三级台阶才决定评委记不记得住你。**

---

## 一、证据选取：2-3 段，不多不少

| # | 选取标准 |
|---|---|
| 1 | 与目标岗位的要求**同一能力维度** |
| 2 | 有一个**可核查的数字结果** |
| 3 | 能体现你的**角色**，不是团队成果 |
| 4 | 至少一段能讲到**第三级台阶** |
| 5 | 至少一段包含**失败或未达成**的复盘 |

**不要选的证据**：与岗位无关的大项目、只有荣誉没有过程的、你只做了很小一部分却硬说主导的。

---

## 二、STAR 三级台阶模板

```
一级  做过什么      —— 我负责过 X 项目的 A 模块
二级  怎么做得更好  —— 我改了 B 环节，结果从 C 变成 D
三级  为什么是我能做 —— 这形成了 E 方法，正对应本岗位的 F 要求
```

**第三级是整段证据的落点。** 没有第三级，评委听到的是履历；有第三级，评委听到的是岗位匹配度。

---

## 三、四类可迁移能力（对应多数通用岗位要求）

| 能力 | 三级台阶写法示例 |
|---|---|
| 定位根因 | 一级：处理过 X 类问题；二级：不是解症状而是找出根因，数据从 C 到 D；三：这套方法用于本岗位就是先摸清主要矛盾 |
| 流程改造 | 一级：改过某流程；二级：环节从 7 步减到 4 步，单次省 T 小时；三：改造前先量化，是本岗位推进落地的基础 |
| 跨部门协同 | 一级：协同过 3 个部门；二级：把 6 周的排期压到 3 周；三：用统一排期表解决优先级分歧，是本岗位的核心难点 |
| 带人培养 | 一级：带过 X 人；二级：其中 X 人后来能独立负责某模块；三：我的做法是先交后接，不是替代 |

## 四、失败复盘的写法（30 秒内讲完）

```
1. 目标是什么（5 秒）
2. 实际结果与差距（10 秒）
3. 我的判断哪里错了（10 秒）
4. 之后怎么改的（5 秒）
```

### 示例

> 「三年前我负责一个迁移项目，按计划应该在九月完成，最后拖了六周。
> 根因是我把排期按技术任务拆，而没有按业务上线场景拆，
> 导致每个环节都'按时完成'，整体却上不了线。
> 后来我改成按上线场景倒推排期，之后两个类似项目都在窗口内完成。」

**讲失败的重点不是失败本身，是你的复盘方法。**

## 五、团队成果与个人角色的写法

| 写法 | 判定 |
|---|---|
| 「我主导了整个项目」且无分工说明 | ❌ 高风险，追问必露 |
| 「项目共 4 人，分工为……我负责 XX 模块」 | ✅ |
| 「我们完成了 X」+ 人数 + 分工 | ✅ |
| 「我完成了 X」但 X 是集体成果 | ❌ |

## 六、没有直接经验的迁移三段

```
1. 我没有直接做过 X，但我做过 Y，两者在 A 维度上方法相同
2. 在 Y 中我取得的可核查结果是 Z
3. 对 X 中我没有把握的部分，我的做法是在前 30 天跟着做，快速补齐
```

**承认没有直接经验，比编一段假经历安全得多。**

## 七、八类扣分表述与改法

| # | 扣分点 | 错误写法 | 正确写法 |
|---|---|---|---|
| 1 | 表态式空话 | 「我将尽全力」「不辜负信任」 | 删掉，换成 30 天做什么 |
| 2 | 复述 JD | 「这个岗位要求有 X 能力」 | 「这个岗位当下最难的是 X」 |
| 3 | 只讲一级 | 「我做过 X 项目」 | 补二级 + 三级 |
| 4 | 没有数字 | 「提升了效率」 | 「从两天缩短到四小时」 |
| 5 | 全是「我们」 | 「我们完成了 X」 | 写清人数、分工与自己承担的那段 |
| 6 | 过度承诺 | 「一年内业绩翻三倍」 | 承诺可控的机制与流程改进 |
| 7 | 攻击竞聘者 | 「某些人做事不力」 | 删掉，只讲岗位与做法 |
| 8 | 否定前人 | 「原来那套方法不行」 | 「现有做法在 X 有效，在 Y 需补充」 |

## 八、证据自检

- [ ] 2-3 段，与岗位能力维度直接对应
- [ ] 每段 STAR 四要素齐全
- [ ] 每段结果都有可核查的数字
- [ ] 至少一段讲到第三级台阶
- [ ] 至少一段含失败复盘，控制在 30 秒内
- [ ] 团队成果已写清人数与分工
- [ ] 无编造经历
- [ ] 无过度承诺
- [ ] 无攻击竞聘者与否定前人的表述
