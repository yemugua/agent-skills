# 使用假证的后果、止损与举报路径

## 一、使用伪造特种作业操作证有什么后果

| 层面 | 后果 |
| --- | --- |
| **行政** | 持假证上岗属重大事故隐患，可依《安全生产法》《特种作业人员安全技术培训考核管理规定》相关规定对**人员与用工单位**予以处罚；无证上岗的，责令限期改正并处罚款 |
| **从业** | 证书被认定无效，上岗资格作废；已取得的岗位、收入、项目资质受影响 |
| **民事** | 因无资质作业造成事故的，用人单位与个人承担赔偿责任，保险理赔亦可能受影响 |
| **刑事** | 伪造、买卖、使用伪造的国家机关证件或事业单位印章，情节严重的可能触及《刑法》相关规定；涉及非法侵入计算机信息系统「改分」「补录」的，另有对应罪名 |

> 条文号以全国人大、国务院与主管部门发布的官方文本为准，本表仅作检索指引。

**重要**：即使是「别人帮你办的、你不知情」，一旦使用假证上岗，**本人与用人单位均需承担责任**。
知情后立即停止使用并主动说明，是最有利的处置。

## 二、已经付款了怎么止损

```
第 1 步  停止追加
  不再支付任何「加急费」「改分费」「补录费」「保证金」

第 2 步  固定证据
  保存聊天记录、转账凭证、对方联系方式、宣传页面、已收到的证书实物照片

第 3 步  官方核验
  到应急管理部特种作业操作证查询平台核对；查不到即不能上岗

第 4 步  书面要求退款
  微信或 EMS 书面提出，要求对方说明证书来源与官方查询路径

第 5 步  举报与报案
  应急管理部门举报（假证与非法培训）→ 市场监管部门（虚假宣传、无照经营）
  → 12315（消费纠纷）→ 金额较大或对方失联的，向公安机关报案
```

## 三、举报路径

| 对象 | 向谁举报 | 说明什么 |
| --- | --- | --- |
| 伪造证书、非法培训 | 当地应急管理部门 | 机构名称、地址、宣传内容、付款凭证、证书照片 |
| 虚假宣传、无照经营 | 市场监管部门 / 12315 | 广告截图、合同、收款方 |
| 诈骗（收钱失联） | 公安机关（110 或当地派出所） | 转账流水、聊天记录、对方账号 |
| 用工企业持假证 | 当地应急管理部门 | 企业名称、岗位、证书信息 |

**举报要点**：说清「谁、在哪个平台、以什么名义、收了多少钱、承诺了什么、证书编号是多少」，
并附上截图与流水。多人受骗的，联合举报会被优先处理。

## 四、正规取证的正确路

1. 找**具备资质的安全生产培训机构**（可向当地应急管理部门核实其备案情况）
2. 完成规定学时培训
3. **本人**参加理论与实操考试
4. 考核合格后取证并**当场核验官方平台能否查到**
5. 建立复审提醒：有效期 6 年、每 3 年复审一次，提前 2~3 个月申请

**费用判断**：正常培训考试有明确的收费标准区间，明显低于市场价且承诺免考的，一定是骗局。
具体收费以当地培训机构公示与应急管理部门口径为准。

## 五、常见误区

| 误区 | 正确做法 |
| --- | --- |
| 「证书能扫二维码就是真的」 | 二维码可伪造，唯一标准是官方平台查询结果 |
| 「对方给了查询网站链接」 | 只认应急管理部官方平台，不点对方给的链接 |
| 「先上岗，证慢慢补」 | 无证上岗属重大隐患，企业与个人都要担责 |
| 「别人都这么办的」 | 普遍性不构成合法性，查不到就是不能用 |
| 「企业让我办的，责任在企业」 | 使用假证的责任不能因他人指示而免除 |
| 「钱不多就算了」 | 举报能让后续的人不再受骗，且可追回损失 |

## 六、纪律边界

- 本技能只做信息核查与路径指引，**不提供任何办证、代考或制证服务**。
- 是否构成违法，最终以应急管理部门、市场监管部门与司法机关认定为准。
- 涉金额较大或对方涉嫌诈骗的，应立即报案。
