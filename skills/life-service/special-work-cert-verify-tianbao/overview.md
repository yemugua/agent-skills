# 特种作业操作证核验与防骗常识

面向需要考取或已经持有电工证、焊工证、高处作业证等特种作业操作证，想确认证书真伪、了解正规取证流程、识别招生与办证骗局的从业人员与用工企业。

## 与其他工具的区别

- **只做核验，不做办证**。市面上大量「免考速出」本身就是骗局或违法行为，本技能只告诉你怎么核、怎么举报。
- **给出可执行的官方核验路径**：不是笼统说「去官网查」，而是写清哪个平台、查什么字段、查不到意味着什么。
- **覆盖用工企业视角**：企业招到持证人员但未核验的，属于未履行安全生产管理义务，
  这是很多企业不知道的风险点。

## 典型适用场景

1. 报名机构承诺「包过，不用考试，一周出证」
2. 已付款拿到证书，但官方平台查不到编号
3. 证书能查到，但姓名、身份证号或作业类别对不上
4. 企业招聘时发现员工证书疑似造假
5. 被要求加钱「改分」「补录系统」
6. 证书快到期，不知道复审与换证怎么走

## 使用流程

1. 抄录 `templates/证书核验信息采集表.md` 填好（不知道写「未填写」，别猜）
2. 运行脚本生成核验报告
3. 先按报告去官方平台核验，**核完再决定是否付款或继续使用**
4. 查不到的按「举报路径」推进

## 边界

不替代专业法律意见，最终以应急管理部门、人社部门及司法机关认定为准。
本技能仅做证书核验、防骗科普与官方查询指引，不提供任何办证、代考或制证服务。
