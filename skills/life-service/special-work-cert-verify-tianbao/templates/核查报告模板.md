# 证书真伪核查报告（模板）

> 本模板为脚本输出结构示意，实际报告由 `scripts/cert_verify_check.py` 生成。

## 一、结论摘要

| 项 | 结论 |
| --- | --- |
| 官方核验 | 待填 |
| 骗局话术命中 | 待填（n 项） |
| 费用与收款 | 待填 |
| 证书可用性 | 待填 |
| 高危项 | 待填（n 项） |
| **总体结论** | **通过 / 有风险 / 不通过 / 待补正** |

四态含义：

- **通过**：官方平台核验为真、无骗局话术、本人参加考试
- **有风险**：存在需核验或需补正的问题
- **不通过**：命中骗局话术、官方查不到、或已付款后发现虚假
- **待补正**：核心信息未填，不下实质结论

## 二、证书真伪与官方核验

证书类型、编号、发证机构、核验平台与结果、不一致项。

## 三、骗局话术与办证机构核查

逐条命中「包过」「免考」「速出」等话术并说明为什么是骗局。

## 四、费用与收款核查

办证费用、已付、已退、收款主体与协议情况。

## 五、法律后果、合规取证路径与举报入口

使用假证的后果、正规流程、举报对象与渠道。

## 六、复审换证提醒

有效期、复审周期、复审到期提示。

## 七、证据清单与固定要点

已具备 / 仍缺失。

## 八、待办补正动作

按优先级编号。

## 九、边界与纪律

不替代法律意见与官方核验，最终以主管部门认定为准。

本结果依通用规则整理，不替代专业法律意见，最终以主管部门或司法机关认定为准。
