# 催吐禁忌与消化异常分层

> **不提供任何药物名称、剂量与用法。是否催吐由兽医决定。**

## 一、不能催吐的情形

| 情形 | 为什么不能催吐 | 处置方向 |
|---|---|---|
| 尖锐物（鱼钩、缝衣针、牙签） | 催吐会让尖锐物二次划伤食道与消化道 | 立即就医 |
| 腐蚀性物质（清洁剂、汽油、消毒剂、强酸碱） | 催吐会让腐蚀物再次灼伤 | 立即就医，不喂水 |
| 纽扣电池 | 催吐会加快电池在消化道推进，且有灼伤风险 | 立即就医 |
| 已进入症状期的宠物 | 反复呕吐可能提示已有损伤，催吐加重负担 | 立即就医 |
| 石油类、油漆类 | 吸入性肺炎风险 | 立即就医 |
| 已经发生剧烈呕吐或腹泻 | 脱水与电解质紊乱风险，催吐无意义 | 立即就医 |
| 意识模糊、反应迟钝 | 呛入气道风险极高 | 立即就医 |

## 二、关于催吐的明确立场

- **不推荐自行给狗或猫催吐**。是否需要催吐、用什么方式、剂量多少，**全部由兽医决定**
- **网络上流传的灌肥皂水、灌双氧水、按压腹部等方法，不要自行尝试**。这些方法可能造成呛入、加重损伤或延误正确处理
- **不确定能不能催吐时，正确做法是就医**，而不是试一个可能有害的方法

## 三、消化异常的分层排查

**前提：已排除误食异物与有毒物质。**

| 表现 | 分层 | 排查方向 | 就医口径 |
|---|---|---|---|
| 呕吐物中有食物残渣，未消化 | 轻度 | 近期换粮、进食过快、吃太多 | 观察并记录；持续或加重就医 |
| 呕吐物有黄色泡沫 | 中度 | 胃酸、可能空腹过久、胆汁 | 少量多次给水；持续呕吐就医 |
| 呕吐物带血丝或咖啡渣色 | 危险 | 消化道损伤或异物 | 尽快就医 |
| 稀便、未成形 | 轻度 | 换粮、轻微饮食不当 | 观察并记录 |
| 便中带血 | 危险 | 消化道损伤、寄生虫、感染 | 尽快就医 |
| 果酱样便 | 危险 | 出血量较大 | 立即就医 |
| 黑色柏油样便 | 危险 | 上消化道出血 | 立即就医 |
| 持续呕吐超过 4 小时 | 危险 | 脱水与电解质紊乱 | 尽快就医 |
| 呕吐伴腹胀、无法排便排气 | 危险 | 肠梗阻可能 | 立即就医 |
| 完全不进食超过 24 小时 | 危险 | 肝脂肪肝等风险，幼宠更早 | 尽快就医（幼犬幼猫更早） |
| 精神沉郁、蜷缩、痛叫 | 危险 | 疼痛或全身性状况 | 尽快就医 |
| 幼犬幼猫腹泻伴呕吐 | 危险 | 脱水进展快 | 尽快就医 |

**时限口径的方向性说明**：本文件不给"观察多少小时"的固定结论，因为幼犬幼猫与成年犬猫差别很大、有基础疾病的与健康的差别很大。判断时限由兽医给出。

## 四、就医红线

| 情况 | 紧急程度 |
|---|---|
| 误食纽扣电池 | 立即就医 |

| 误食清洁剂、汽油、消毒剂、强酸强碱 | 立即就医，不催吐不喂水 |
| 误食人用药物 | 立即就医 |
| 误食木糖醇 | 立即就医，猫尤其危险 |
| 误食巧克力、咖啡因 | 立即就医 |
| 误食洋葱、大蒜、大葱及含洋葱成分的汤汁与调味料 | 立即就医 |
| 误食葡萄、葡萄干、葡萄汁 | 立即就医 |
| 误食酒精 | 立即就医 |
| 误食高盐食物 | 立即就医 |
| 误食百草枯 | 立即就医，不催吐不喂水 |
| 误食大量骨头、坚硬异物 | 尽快就医 |
| 误食果核、枣核、桃子核等硬核 | 尽快就医 |
| 误食线、绳、袜子、塑料薄膜等可缠绕物 | 尽快就医，肠梗阻风险 |
| 毛发团呕吐排出且精神正常 | 可观察；排不出或精神差则尽快就医 |

| 误食后症状延迟出现 | 尽快就医 |

## 五、必须立刻做的三件事

1. **先确认吃进去的是什么**（包装、残留物、照片）
2. **再确认吃了多少、大概什么时候吃的**
3. **打急诊电话，把这两条信息说清楚**

**不要在没弄清是什么之前就动手处理。**

## 六、就诊时带什么

| 物品 | 为什么 |
|---|---|
| 食品包装或药品包装 | 判断物质成分的第一依据 |
| 残留物（呕吐物、食物残渣） | 可能含有未消化的毒物 |
| 误食时间记录 | 影响处理方式的选择 |
| 大致摄入量记录 | 影响风险判断 |
| 症状出现的时间与表现 | 帮助医生判断损伤进程 |
| 既往病史与用药史 | 影响处理方案 |
| 体重 | 影响处理方案 |

## 七、明确禁止

- 不自行给狗或猫催吐
- 不自行尝试灌肥皂水、双氧水、手抠喉、按压腹部等方法
- 腐蚀性物质或百草枯误食后不喂水
- 不自行给药或给"解毒"的东西
- 不以"吃一点点"或"现在没事"作为放弃就医的依据
- 不提供任何药物名称、剂量与用法
