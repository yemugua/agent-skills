# 有毒食物与异物分层

> **不提供任何药物名称、剂量与用法。误食处置由兽医决定。**

## 一、高风险物质（误食后立即就医）

| 物质 | 说明 | 需要注意 |
|---|---|---|
| 巧克力 | 含可可碱与咖啡因 | 黑巧与可可含量越高风险越大；包装上的可可含量是重要信息 |
| 咖啡与咖啡因 | 咖啡、浓茶、可乐、能量饮料 | 巧克力与咖啡因属同类风险 |
| 洋葱、大蒜、大葱 | 及其粉末与提取物 | 含洋葱成分的汤汁、调味汁、婴儿米粉同样有风险 |
| 葡萄、葡萄干、葡萄汁 | 大量摄入有风险 | 干燥后单位重量风险上升 |
| 木糖醇 | 无糖口香糖、无糖糖果、部分牙膏 | 猫尤其危险；包装上写"无糖"要留意外包装 |
| 酒精 | 酒、含酒调味品、发酵物 | 家中含酒精的饮料与酒酿类食品同样有风险 |
| 百草枯 | 除草剂 | 不催吐、不喂水，立即就医 |
| 人用药物 | 退热药、镇痛药、抗生素、安眠药等 | 任何剂量都应立即联系兽医 |
| 高盐食物 | 大量咸菜、腌制品、加工肉、薯片 | 大量摄入有风险 |

## 二、需要留意的类别

| 类别 | 说明 |
|---|---|
| 大量生豆芽 | 生豆芽与大剂量蔬菜可能有风险 |
| 大量生鱼 | 生鱼与熟鱼在营养与风险上不同；煮熟更稳妥 |
| 大量果核 | 桃、杏、樱桃、李、枣等的核，误吞有阻塞风险 |
| 大量坚果 | 尤其带壳坚果；有窒息与阻塞风险 |
| 咖啡渣与茶叶 | 咖啡因风险 |
| 烹调调味料 | 尤其含洋葱粉、蒜粉等的复合调味 |
| 发酵与变质食物 | 呕吐物本身也可能含危险物质 |

**通用原则**：带包装的食品要留好包装。急诊时能不能快速判断物质，取决于包装还在不在。

## 三、异物吞咽的识别

| 观察 | 提示 |
|---|---|
| 吞下后频繁干呕、伸颈、作呕状 | 可能有异物卡在咽喉或上消化道 |
| 能正常喝水与进食 | 异物可能较小或已进入更深处，不代表没有问题 |
| 精神食欲正常但排出干硬便 | 可能排出了较硬的异物 |
| 拒食、拒水 | 高度警惕，需就医 |
| 腹部触碰有疼痛反应 | 需就医 |
| 呕吐物中有异物残片 | 已排出部分，仍可能有残留 |

**关键**：能吃能喝不等于没问题。小型犬肠道细，部分异物能通过但仍可能造成局部损伤。

## 四、按类型的风险分层

| 异物类型 | 风险 | 处置方向 |
|---|---|---|
| 纽扣电池 | 极高 | 立即就医，不观察 |
| 硬币 | 较高 | 尽快就医 |
| 尖锐物（鱼钩、缝衣针、牙签、刀片） | 高 | 立即就医，不催吐 |
| 腐蚀性（清洁剂、消毒剂、汽油） | 高 | 立即就医，不催吐、不喂水 |
| 线、绳、袜子、塑料薄膜 | 高（肠梗阻风险） | 尽快就医 |
| 硬骨头、硬塑料 | 中到高（阻塞或碎裂损伤） | 尽快就医 |
| 果核、枣核、桃子核 | 中（阻塞风险） | 尽快就医 |
| 布球、毛发团 | 较低，但可能阻塞 | 呕吐排出且精神正常可观察 |
| 小石子 | 低 | 通常可排出，观察 |
| 纸、少量食物残渣 | 低 | 通常可排出 |

## 五、观察时限

| 情况 | 口径 |
|---|---|
| 尖锐物、腐蚀物、电池 | 不观察，立即就医 |
| 高风险食物 | 不观察，立即联系兽医 |
| 不明异物、能吃能喝 | 密切观察，发现任何异常立即就医 |
| 观察期内记录 | 精神、食欲、饮水、排便、呕吐，逐项记录 |
| 观察多久没症状才能放心 | **须由兽医判断**，不同异物差别很大 |
| 延迟症状 | 部分损伤是延迟出现的（数小时到数天），不能因现在没事就放心 |

**明确说明**：本文件不给"观察多少小时就安全"的具体结论。不同异物、不同体型、不同时间差别很大，该结论必须由兽医给。

## 六、环境整改

| 类别 | 方向 |
|---|---|
| 药品 | 全部收进抽屉或带锁柜，不放在台面、床头、沙发扶手 |
| 清洁剂与消毒剂 | 收到孩子与宠物接触不到的位置；用完立即盖紧 |
| 电池类 | 遥控器、玩具、饰品里的电池收好；纽扣电池尤其要收进带锁柜 |
| 食品 | 不在人吃饭时给狗猫顺口；剩菜尤其含洋葱味的不能给 |
| 包装 | 保留包装与残留物，便于急诊判断 |
| 垃圾桶 | 使用带盖垃圾桶；外出时注意翻倒的垃圾桶 |
| 线与绳 | 收好线团、纱线、绳结；玩线绳类玩具时全程看护 |
| 花与植物 | 百合类对猫有严重风险，家有猫时不摆放；其他植物也要确认毒性 |
| 药物保健品 | 复合保健品中的某些成分也可能有风险 |
| 外出 | 留意地面、垃圾堆、动物粪便与骨头 |

**关于百合**：百合类植物对猫有严重风险，且可能从花粉、叶片甚至花瓶水途径发生。有猫的家庭不摆放百合类。其他植物也应确认对猫的毒性后再养。
