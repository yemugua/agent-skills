# 狗狗误食与消化异常核查（dog-indigestion-check）

误食这件事，**最危险的两个误区是"先观察一下"和"赶紧催吐"**。前者会错过黄金处理窗口，后者遇到腐蚀物或异物时会造成二次伤害。**能不能催吐，取决于吃进去的是什么**——不是所有误食都能催吐，也不是所有误食都该观察。

这个技能做三件事：**认物质 → 定时限 → 判红线**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出常见有毒食物清单与风险分级 | ❌ 判断具体某次误食的剂量是否达到中毒量 |
| 给出异物吞咽的识别方法与观察时限 | ❌ 提供任何催吐、解毒或吸附类药物 |
| 给出不能催吐的具体情形 | ❌ 指导用手抠、按压或自行给药催吐 |
| 给出呕吐、腹泻、便血的分层排查 | ❌ 诊断消化道疾病并开治疗方案 |
| 给出就医前的信息整理口径 | ❌ 判断某项检验指标是否异常 |

**本技能不提供任何药物名称、剂量与用法。** 误食后的处理方式（催吐、洗胃、吸附、解毒、观察）**全部由兽医根据物质种类、剂量与时间决定**。

**就医红线（出现任一条，立即就医；标注尽快的当日就医）**

- **误食电池（尤其纽扣电池）** —— **立即就医，不观察**
- **误食鱼钩、缝衣针、牙签等尖锐物** —— **立即就医，不催吐**
- **误食清洁剂、汽油、消毒剂、强酸强碱等腐蚀性物质** —— **立即就医，不催吐、不催吐也不喂水**
- **误食人用药物** —— **立即就医**
- **误食木糖醇（口香糖、无糖糖果、部分牙膏）** —— **立即就医，猫尤其危险**
- **误食巧克力、咖啡因** —— **立即就医**
- **误食洋葱、大蒜、大葱及含洋葱成分的汤汁与调味料** —— **立即就医**
- **误食葡萄、葡萄干、葡萄汁** —— **立即就医**
- **误食酒精** —— **立即就医**
- **误食高盐食物（大量咸菜、腌制品、薯片）** —— **立即就医**
- **误食百草枯** —— **立即就医，不催吐、不喂水**
- **误食大量骨头、坚硬异物** —— **尽快就医**
- **误食果核、枣核、桃子核等硬核** —— **尽快就医**
- **误食线、绳、袜子、塑料薄膜等可缠绕物** —— **尽快就医，肠梗阻风险**
- **误食毛发团** —— 呕吐排出且精神正常可观察；**若排不出或精神差，尽快就医**
- **呕吐物或粪便带血** —— **尽快就医**
- **持续呕吐超过 4 小时** —— **尽快就医**
- **完全不进食超过 24 小时** —— **尽快就医**（幼犬幼猫更早）
- **精神沉郁、蜷缩不动、痛叫** —— **尽快就医**
- **腹部胀大、触碰疼痛、无法排便排气** —— **尽快就医**
- **误食后症状延迟出现（数小时到数天）** —— **尽快就医**

**必须立刻做的三件事**：

1. **先确认吃进去的是什么**（包装、残留物、照片）
2. **再确认吃了多少、大概什么时候吃的**
3. **打急诊电话，把这两条信息说清楚**

**不要在没弄清是什么之前就动手处理。**

## 二、完整工作流

```
第 1 步  立刻确认物质：吃了什么、多少、什么时候（保留包装与残留物）
第 2 步  排红线：对照有毒食物清单与不能催吐清单，命中即就医
第 3 步  不命中红线：按观察时限与症状做家庭观察，逐项记录
第 4 步  出现红线信号：立即停止观察，转急诊
第 5 步  记录与交接：把误食物质、时间、量、症状写成清单带去就诊
第 6 步  环境整改：找出可接触的同类物品并清理
```

**顺序不能颠倒**：不确认是什么就催吐，是最常见的二次伤害来源。

## 三、常见有毒食物清单

**以下为常见风险类别，**风险大小与个体差异有关，任何一项误食都应联系兽医，不自行判断"吃一点点没事"**。

### 3.1 高风险（误食后立即就医）

| 物质 | 说明 | 需要注意 |
|---|---|---|
| **巧克力** | 含可可碱与咖啡因 | **黑巧与可可含量越高风险越大**；包装上的可可含量是重要信息 |
| **咖啡与咖啡因** | 咖啡、浓茶、可乐、能量饮料 | 巧克力与咖啡因属同类风险 |
| **洋葱、大蒜、大葱** | 及其粉末与提取物 | **含洋葱成分的汤汁、调味汁、婴儿米粉同样有风险** |
| **葡萄、葡萄干、葡萄汁** | 大量摄入有风险 | 干燥后单位重量风险上升 |
| **木糖醇** | 无糖口香糖、无糖糖果、部分牙膏 | **猫尤其危险**；包装上写"无糖"要留意外包装 |
| **酒精** | 酒、含酒调味品、发酵物 | 家中含酒精的饮料与酒酿类食品同样有风险 |
| **百草枯** | 除草剂 | **不催吐、不喂水，立即就医** |
| **人用药物** | 退热药、镇痛药、抗生素、安眠药等 | **任何剂量都应立即联系兽医** |
| **高盐食物** | 大量咸菜、腌制品、加工肉、薯片 | 大量摄入有风险 |

### 3.2 需要留意的类别

| 类别 | 说明 |
|---|---|
| 大量生豆芽 | 生豆芽与大剂量蔬菜可能有风险 |
| 大量生鱼 | 生鱼与熟鱼在营养与风险上不同；**煮熟更稳妥** |
| 大量果核 | 桃、杏、樱桃、李、枣等的核，误吞有阻塞风险 |
| 大量坚果 | 尤其带壳坚果；有窒息与阻塞风险 |
| 咖啡渣与茶叶 | 咖啡因风险 |
| 烹调调味料 | 尤其含洋葱粉、蒜粉、孜然等的复合调味 |
| 发酵与变质食物 | 呕吐物本身也可能含危险物质 |

**一条通用原则**：**带包装的食品要留好包装**。急诊时能不能快速判断物质，取决于包装还在不在。

## 四、异物吞咽的识别

### 4.1 能不能排出来的判断

| 观察 | 提示 |
|---|---|
| 吞下后频繁干呕、伸颈、作呕状 | 可能有异物卡在咽喉或上消化道 |
| 能正常喝水与进食 | 异物可能较小或已进入更深处，**不代表没有问题** |
| 精神食欲正常但排出干硬便 | 可能排出了较硬的异物 |
| 拒食、拒水 | **高度警惕，需就医** |
| 腹部触碰有疼痛反应 | **需就医** |
| 呕吐物中有异物残片 | 已排出部分，仍可能有残留 |

**关键**：**能吃能喝不等于没问题**。小型犬肠道细，部分异物能通过但仍可能造成局部损伤。

### 4.2 按类型的风险分层

| 异物类型 | 风险 | 处置方向 |
|---|---|---|
| **纽扣电池** | **极高** | **立即就医，不观察** |
| 硬币 | 较高 | 尽快就医 |
| **尖锐物（鱼钩、缝衣针、牙签、刀片）** | **高** | **立即就医，不催吐** |
| **腐蚀性（清洁剂、消毒剂、汽油）** | **高** | **立即就医，不催吐、不喂水** |
| **线、绳、袜子、塑料薄膜** | 高（肠梗阻风险） | **尽快就医** |
| 硬骨头、硬塑料 | 中到高（阻塞或碎裂损伤） | 尽快就医 |
| 果核、枣核、桃子核 | 中（阻塞风险） | 尽快就医 |
| 布球、毛发团 | 较低，但可能阻塞 | 呕吐排出且精神正常可观察 |
| 小石子 | 低 | 通常可排出，观察 |
| 纸、少量食物残渣 | 低 | 通常可排出 |

### 4.3 观察时限

| 情况 | 观察口径 |
|---|---|
| 已知误食尖锐物、腐蚀物、电池 | **不观察，立即就医** |
| 已知误食高风险食物 | **不观察，立即联系兽医** |
| 不明异物、能吃能喝 | 密切观察，**发现任何异常立即就医** |
| 观察期内的表现 | 精神、食欲、饮水、排便、呕吐，全部逐项记录 |
| 观察多久没症状才能放心 | **须由兽医判断**，不同异物差别很大 |
| 出现延迟症状 | **部分损伤是延迟出现的**（数小时到数天），不能因为"现在没事"就彻底放心 |

**明确说明**：本技能**不给"观察多少小时就安全"的具体结论**——不同异物、不同体型、不同时间差别很大，**这个结论必须由兽医给**。

## 五、不能催吐的情形

**这是本技能最核心的一张表。**

| 情形 | 为什么不能催吐 | 处置方向 |
|---|---|---|
| **尖锐物**（鱼钩、缝衣针、牙签） | 催吐会让尖锐物二次划伤食道与消化道 | **立即就医** |
| **腐蚀性物质**（清洁剂、汽油、消毒剂、强酸碱） | 催吐会让腐蚀物再次灼伤 | **立即就医，不喂水** |
| **纽扣电池** | 催吐会加快电池在消化道推进，且有灼伤风险 | **立即就医** |
| **已进入症状期的宠物** | 反复呕吐可能提示已有损伤，催吐加重负担 | **立即就医** |
| **石油类、油漆类** | 吸入性肺炎风险 | **立即就医** |
| **已经发生剧烈呕吐或腹泻** | 脱水与电解质紊乱风险，催吐无意义 | **立即就医** |
| 意识模糊、反应迟钝 | 呛入气道风险极高 | **立即就医** |

**关于催吐的明确立场**：

- **不推荐自行给狗或猫催吐**。是否需要催吐、用什么方式、剂量多少，**全部由兽医决定**。
- **网络上流传的"灌肥皂水""灌双氧水""按压腹部"等方法，不要自行尝试**。这些方法可能造成呛入、加重损伤或延误正确处理。
- **不确定能不能催吐时，正确做法是就医**，而不是试一个可能有害的方法。

## 六、消化异常的分层排查

**前提：已排除误食异物与有毒物质。**

| 表现 | 分层 | 排查方向 | 就医口径 |
|---|---|---|---|
| 呕吐物中有食物残渣，未消化 | 轻度 | 近期换粮、进食过快、吃太多 | 观察并记录；持续或加重就医 |
| 呕吐物有黄色泡沫 | 中度 | 胃酸、可能空腹过久、胆汁 | 少量多次给水；持续呕吐就医 |
| 呕吐物带血丝或咖啡渣色 | **危险** | 消化道损伤或异物 | **尽快就医** |
| 稀便、未成形 | 轻度 | 换粮、轻微饮食不当 | 观察并记录 |
| 便中带血 | **危险** | 消化道损伤、寄生虫、感染 | **尽快就医** |
| 果酱样便 | **危险** | 出血量较大 | **立即就医** |
| 黑色柏油样便 | **危险** | 上消化道出血 | **立即就医** |
| 持续呕吐超过 4 小时 | **危险** | 脱水与电解质紊乱 | **尽快就医** |
| 呕吐伴腹胀、无法排便排气 | **危险** | 肠梗阻可能 | **立即就医** |
| 完全不进食超过 24 小时 | **危险** | 肝脂肪肝等风险，幼宠更早 | **尽快就医**（幼犬幼猫更早） |
| 精神沉郁、蜷缩、痛叫 | **危险** | 疼痛或全身性状况 | **尽快就医** |
| 幼犬幼猫腹泻伴呕吐 | **危险** | 脱水进展快 | **尽快就医** |

**时限口径的方向性说明**：本技能**不给"观察多少小时"的固定结论**，因为**幼犬幼猫与成年犬猫差别很大、有基础疾病的与健康的差别很大**。判断时限由兽医给出。

## 七、环境整改

| 类别 | 整改方向 |
|---|---|
| 药品 | 全部收进抽屉或带锁柜，**不放在台面、床头、沙发扶手** |
| 清洁剂与消毒剂 | 收到孩子与宠物接触不到的位置；**用完立即盖紧** |
| 电池类 | 遥控器、玩具、饰品里的电池收好；**纽扣电池尤其要收进带锁柜** |
| 食品 | 不在人吃饭时给狗猫"顺口"；剩菜尤其是含洋葱味的不能给 |
| 包装 | 保留包装与残留物，便于急诊判断 |
| 垃圾桶 | 使用带盖垃圾桶；**外出时注意翻倒的垃圾桶** |
| 线与绳 | 收好线团、纱线、绳结；玩线绳类玩具时**全程看护** |
| 花与植物 | **百合类对猫有严重风险，家有猫时不摆放**；其他植物也要确认毒性 |
| 药物保健品 | 复合保健品中的某些成分也可能有风险 |
| 外出 | 外出时留意地面、垃圾堆、动物粪便与骨头 |

**关于百合**：**百合类植物对猫有严重风险**，且风险可能从**花粉、叶片甚至花瓶水**途径发生。有猫的家庭**不摆放百合类**。其他植物也应确认对猫的毒性后再养。

## 八、脚本用法

```
python scripts/ingest_check.py --file case.json
python scripts/ingest_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`substance`（物质代号）、`amount`、`hours_since`、`symptoms`、`red_flags`、`no_vomit_here`（能否催吐）、`species`、`age_months` |
| `--json` | 以 JSON 输出 |
| `--out` | 结果写入指定文件，默认 `scripts/_last_result.txt` |
| `--selftest` | 运行自检 |

脚本做四件事：**按物质判定风险等级与是否需要立即就医 → 判断能否催吐并给出不能催吐的具体理由 → 按时间与症状分层 → 排就医红线并给出环境整改清单**。脚本**不提供任何药物名称、剂量与催吐方法**。

## 九、人工确认清单（这步不能省）

- [ ] **已第一时间确认误食的物质是什么**（保留包装、残留物、拍照）
- [ ] 已确认大概吃了多少、大概什么时候吃的
- [ ] **已对照有毒食物清单与不能催吐清单逐项核对**
- [ ] 命中红线时**立即就医，未先观察**
- [ ] **未自行尝试灌肥皂水、双氧水、抠喉、按压腹部等催吐方法**
- [ ] 腐蚀性物质或百草枯误食时**未喂水**
- [ ] 尖锐物、纽扣电池误食**未催吐**
- [ ] 观察期内记录了精神、食欲、饮水、排便、呕吐
- [ ] 未以"现在没事"就完全放心（**部分损伤是延迟出现的**）
- [ ] 未自行给药或给"解毒"的东西
- [ ] 就诊时带了包装、残留物与误食时间清单
- [ ] 已做环境整改：药品、带锁收电池、清洁剂、带盖垃圾桶、线绳、花草
- [ ] 家有猫时不摆放百合类植物

## 十、最常见的坑

**坑一：先观察一下再说。**
错误做法：狗吃了块巧克力，想着先看看有没有事。正确做法：**误食高风险食物不观察，立即联系兽医**。部分损伤是延迟出现的（数小时到数天），**"现在没事"不等于安全**。观察时限由兽医判断，不自己定。

**坑二：赶紧催吐。**
错误做法：不管吃了什么，先想办法弄吐出来再说。正确做法：**能不能催吐取决于吃进去的是什么**。尖锐物、腐蚀性物质、纽扣电池、石油类、已出现症状的宠物，**催吐会造成二次伤害**。是否催吐、用什么方式、剂量多少，全部由兽医决定。

**坑三：按网上的方法灌肥皂水或双氧水。**
错误做法：照着网上视频给狗灌肥皂水、双氧水、或者用手抠。正确做法：**不自行尝试任何催吐方法**。这些方法可能造成呛入、加重损伤或延误正确处理。**不确定能不能催吐时，正确做法是就医，而不是试一个可能有害的方法。**

**坑四：认为"吃一点点没事"。**
错误做法：巧克力只咬了一小口、洋葱汤只喝了一口，觉得量少没事。正确做法：**风险大小与剂量、物质种类、体重有关，但判断必须由兽医做**。含可可的黑巧、洋葱粉调味料、无糖口香糖里的木糖醇，**少量也可能有风险**。

**坑五：家里养猫还摆百合。**
错误做法：喜欢百合花，养猫也摆着。正确做法：**百合类植物对猫有严重风险**，且可能从花粉、叶片甚至花瓶水途径发生。**有猫的家庭不摆放百合类**。

**坑六：把剩菜喂狗，觉得有营养。**
错误做法：自己吃剩的菜给狗，认为不浪费。正确做法：**含洋葱、大蒜的调味汁、汤汁不能给**；剩菜还有高盐、油腻的问题。**人吃剩菜与宠物食物不是一回事**。

**坑七：给猫吃无糖口香糖提神。**
错误做法：给狗猫吃无糖口香糖当奖励。正确做法：**木糖醇对猫尤其危险**。无糖口香糖、无糖糖果、部分牙膏都含木糖醇。**包装上写"无糖"要格外留意**。

**坑八：误食后忘记保留包装。**
错误做法：把包装扔了，反正家里还有一样的。正确做法：**保留包装与残留物**。急诊时能不能快速判断物质，取决于包装还在不在。判断不了物质，就没法判断风险和处理方式。
