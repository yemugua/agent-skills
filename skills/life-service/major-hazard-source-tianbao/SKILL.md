# 重大危险源管理（major-hazard-source）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《危险化学品重大危险源辨识》GB 18218，生成重大危险源管理清单：辨识与分级（一~四级）、安全评估与备案、监测监控与报警、应急预案与演练、安全警示与告知。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 重大危险源
- 危险源辨识分级
- 重大危险源备案
- GB 18218
- 危险源监控

## 三、工作流
1. 按临界量辨识并划分等级
2. 开展安全评估并备案
3. 建立监测监控与报警
4. 编制应急预案并演练
5. 设置安全警示与告知

## 四、核心内容（检查清单与判定）
GB 18218 按危险化学品实际存在量与临界量的比值辨识重大危险源并分级；单位须评估备案、监控预警并配备应急准备。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含辨识与分级 | 辨识 |
| Q2 | FAIL | 未含安全评估与备案 | 评估 |
| Q3 | WARN | 未含监测监控与报警 | 监控 |
| Q4 | FAIL | 未含应急预案与演练 | 预案 |
| Q5 | WARN | 未含安全警示与告知 | 告知 |

> 脚本 `major-hazard-source_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python major-hazard-source_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python major-hazard-source_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
