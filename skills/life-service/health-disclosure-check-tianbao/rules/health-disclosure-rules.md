# 健康告知与核保结论规则库

> 本规则库按保险投保实务整理。**健康告知的范围以保险合同约定的询问事项为准**；**核保结论以保险公司实际出具的结论为准**；**未如实告知的后果以法律规定、合同约定与保险公司的核定为准**。本库**不诊断疾病、不给医学结论、不承诺核保与理赔结果**，不建议修改答案规避核保。

---

## 一、询问回答制

**原则**：**保险人问了什么，投保人就答什么；没有被问到的，按保险合同条款的约定处理。**

| 要点 | 口径 |
|---|---|
| 询问范围 | **以保险合同约定的询问事项为准**，通常就是投保时那份书面或电子问卷 |
| 回答范围 | 问卷列明的每一问，**都要按实际情况回答** |
| 未问到的项 | 按保险合同条款的约定处理；**不能简单理解为「不问就完全不用管」** |
| 不可隐瞒 | **问卷问到的不答、答错、答得比实际轻，都属于未如实告知的风险范围** |
| 告知时点 | 告知义务发生在**投保时**；出险环节的「如实告知义务」是另一回事 |

**禁止表述**：

- 「体检问题不大可以不填」
- 「很久以前的事不用写」
- 「没问就不用说」

---

## 二、常见问项类型清单

按人群与险种，问卷通常覆盖以下方向（**具体以问卷原文为准**）：

| 方向 | 常见问法方向 |
|---|---|
| 近期检查异常 | 近若干年体检是否有异常指标 |
| 既往疾病诊断 | 近若干年是否被诊断为某种疾病 |
| 住院与手术 | 是否有住院、手术记录 |
| 门诊与用药 | 是否长期服药、是否在治疗中 |
| 特定疾病列举 | 问卷点名列举的疾病类型 |
| 家族史 | 父母、兄弟姐妹是否有特定疾病 |
| 职业与工作环境 | 职业类别、工作环境风险 |
| 生活方式 | 吸烟、饮酒、高风险运动等 |
| 已投保情况 | 其他公司已持有的保额合计 |

**注意**：**问卷的实际问法与时间范围必须逐字读**，不能按上表的「常见方向」推断自己该答什么。

## 三、三类情况的填写口径

| 情况类型 | 特征 | 填写口径（结构化提示） |
|---|---|---|
| **体检异常** | 体检报告有异常指标或影像所见，但**尚未确诊** | **如实填写「曾检查发现异常」的事实**，含项目与时间；**不得填「无异常」，也不得擅自升格为「已确诊某病」** |
| **门诊记录** | 门诊就诊、开了药、有医嘱随访建议 | 按问卷问及的范围如实填写；**「医生说随访观察」不等于「已确诊」，也不是「无异常」** |
| **既往确诊** | 有明确的临床诊断、病理或检验确诊结论 | **如实填写确诊情况**，含疾病名称与确诊时间；**不得因为「已经好了」就填「无」** |

**三条必读**：

1. **身体上已经出现过的异常，填「无」就是把异常说成没有**
2. **「问题不大」不是医疗结论，只是判断。判断不能代替如实回答**
3. **「已经好了」也不改变曾经发生过的事实**；是否属于询问范围**以问卷原文为准**

---

## 四、八类常见错误

| 错误 | 说明 | 正确做法 |
|---|---|---|
| 凭感觉答 | 认为指标「问题不大」就填「否」 | 按实际情况填「是」，并在说明栏写清项目与时间 |
| 把体检异常当确诊 | 把「甲状腺结节」填成「甲状腺癌」 | 写「体检发现甲状腺结节，未确诊」 |
| 把确诊当体检异常 | 把确诊过的疾病写成「体检异常」 | 按实际确诊情况填写 |
| 把「随访观察」当「无异常」 | 医生说定期复查就不填 | 写明「曾就诊，医生建议随访观察」 |
| 只答「是/否」不写细节 | 问卷要求说明的项没写 | 补齐疾病名称、确诊时间、治疗情况 |
| 投保后才发现漏填 | 以为「没说就不算」 | **尽快按承保公司渠道主动补充更正** |
| 替家人统一填 | 认为「都是健康的」 | **每个人的问卷各自独立**，逐人填写 |
| 时间范围理解错 | 认为「几年前的事不用写」 | 按**问卷原文**的时间范围作答 |

## 五、五类核保结论

| 结论类型 | 含义 | 后续影响 |
|---|---|---|
| **标准体承保** | 按标准费率承保，无附加条件 | 保费与保障按标准执行 |
| **加费承保** | 按高于标准的费率缴费后承保 | **保费变高，保额与责任按合同** |
| **责任除外承保** | 承保，但将某项原因导致的疾病或责任排除在赔付范围外 | **该项不赔，其他责任按约赔付；必须主动核对除外的是哪一项** |
| **延期承保** | 暂不作出结论，需补充资料或经观察期后再定 | 需按承保公司要求配合，观察期长度与条件**以承保公司口径为准** |
| **拒保** | 不予承保 | 可换其他产品重新评估，**但不得试图通过改答案来规避** |

**必须说明**：

- 这五类是**核保结论的常见类型**，**具体的判定标准由保险公司的核保规则决定**，**实际结论以保险公司出具的核保结论通知为准**
- **责任除外不等于全部不赔**：只针对被除外的那一项；**但必须主动核对除外的是哪一项**
- **如实告知是义务，不是通行证**：如实之后结论仍可能是加费、除外、延期甚至拒保

## 六、未如实告知的后果口径

**可以写**：

- 「未如实告知可能导致保险人依保险合同约定与相关法律规则，对相关事项**不承担给付责任**，并可能**解除合同**」
- 「如实告知后可能出现加费、责任除外、延期或拒保等核保结论」
- 「是否构成未如实告知、如何处理，**由保险公司依事实与合同约定核定**」

**不能写**：

- 「隐瞒了必定拒赔」
- 「漏填一点没事」
- 「不填也没关系」

---

## 七、投保后自查与更正流程

```
第 1 步  拿到核保结论通知，逐项核对是否与告知内容一致
第 2 步  发现不一致的，按承保公司规定的渠道书面提出更正或复核
第 3 步  留存：投保单、告知问卷填写内容、提交记录、核保结论通知、沟通记录
第 4 步  若被拒保或有异议，走正规复核与投诉渠道
```

**三条必读**：

1. **更正要趁早**：越早主动更正，越能说明情况
2. **不要沉默**：漏填后不吭声，风险自己承担
3. **不得改答案规避核保**：一旦被发现，后果更严重

## 八、材料留存清单

| 材料 | 留存理由 |
|---|---|
| 投保单或电子投保单（含健康告知问卷） | 询问范围与作答内容的直接依据 |
| 告知问卷的完整页面（含问题原文） | 核对时间范围与问法 |
| 体检报告 | 用于比对是否属于体检异常 |
| 门诊病历与出院小结 | 用于比对是否有就诊与确诊记录 |
| 提交记录与时间戳 | 证明何时提交、何时告知 |
| 核保结论通知 | 证明最终承保条件（加费、除外、延期、拒保） |
| 与销售/代理人的沟通记录 | 了解投保时的说明情况 |

## 九、防误伤（否定词）清单

| 见到这些情况 | 必须这样判 | 严禁这样写 |
|---|---|---|
| 问卷问到、答「否」 | 判为**已回答为无**，须与实际核对是否构成未如实告知 | 直接写「已如实告知」 |
| 问卷问到、答「是」但缺细节 | 判为**信息不完整**，需补齐说明 | 「已如实告知，完整无误」 |
| 漏填后已主动更正 | 判为**已更正**，仍需核保部门确认 | 「从未漏填」 |
| 漏填且未更正 | 判为**未如实告知的风险存在** | 「漏填不算事」 |
| 体检异常未填 | 判为**未如实告知的风险存在** | 「体检异常不算病」 |
| 已如实告知但结论是除外 | 判为**如实 ≠ 必然标准体** | 「如实了就肯定能过」 |
| 责任除外 | 判为**该项不赔，其他责任按约赔付** | 「责任除外＝整张保单无效」 |
| 加费承保 | 判为**保费提高，保障按合同** | 「加费＝买不了」 |
| 延期承保 | 判为**暂未结论，需配合** | 「延期＝拒保」 |
| 拒保 | 判为**不予承保** | 「拒保＝以后也不能买」 |
| 等待期内出险 | 判为**处理方式以条款约定为准** | 「一定赔」/「一定不赔」 |

## 十、免责

本规则库为投保实务整理，**不构成医学诊断、医学建议、保险代理或法律意见**。**健康告知的范围以保险合同约定的询问事项为准**；**核保结论以保险公司实际出具的结论为准，五类结论的判定标准由保险公司的核保规则决定**；**未如实告知的后果以法律规定、合同约定与保险公司的核定为准**。本库**不诊断疾病、不解读检查结果、不给治疗建议、不承诺核保结果与理赔结果**，**不建议修改答案或编造信息规避核保**。疾病与病史的归类判断涉及医学专业性，涉及时应咨询医生；核保复核与理赔争议应走承保公司正规渠道，必要时咨询律师。
