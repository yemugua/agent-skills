# 健康告知填写与理赔影响核查

## 你会得到什么

一套把「问卷每一问该怎么答、哪些情况算异常、如实之后会是什么结论」逐项对清楚的核对口径，避免凭感觉答「问题不大」就填否。

- **询问回答制**：**保险人问了什么，投保人就答什么；没有被问到的，按保险合同条款的约定处理**。问卷问到的不答、答错、答得比实际轻，都属于未如实告知的风险范围。明确拒绝「体检问题不大可以不填」「很久以前的事不用写」「没问就不用说」三类错误结论。
- **常见问项类型清单**：近期检查异常、既往疾病诊断、住院手术、门诊用药、特定疾病列举、家族史、职业与工作环境、生活方式、已投保情况。**但必须逐字读问卷原文，不能按清单推断自己该答什么**，因为时间范围只能看原文。
- **三类情况填写口径表**：**体检异常**（如实写「曾检查发现异常」含项目与时间，**不得填无异常，也不得擅自升格为已确诊**）、**门诊记录**（「医生说随访观察」不等于已确诊，也不是无异常）、**既往确诊**（**已经好了也不改变曾经发生过的事实**）。
- **八类常见错误与正确做法**：凭感觉答、把体检异常当确诊、把确诊当体检异常、把随访观察当无异常、只答是非不写细节、投保后才发现漏填却以为没说就不算、替家人统一填、时间范围按自己理解。
- **五类核保结论**：**标准体承保 / 加费承保 / 责任除外承保 / 延期承保 / 拒保**，各自含义与后续影响。强调两点：**责任除外只针对被除外的那一项，不等于整张保单无效**，但**必须主动核对除外的是哪一项**；**如实告知是义务，不是通行证**——如实之后结论仍可能是加费、除外、延期甚至拒保。
- **未如实告知的后果口径**：只写「可能导致不承担给付责任并可能解除合同」，**不断言「隐瞒必定拒赔」**，也**不断言「没隐瞒就一定能赔」**。
- **投保后自查与更正流程**：拿到核保结论通知逐项核对 → 不一致按承保公司渠道书面更正 → 留存投保单、问卷、提交记录、核保通知、沟通记录 → 有异议走正规复核与投诉渠道。**不建议改答案规避核保。**
- **脚本核对**：`scripts/disclosure_check.py` 按问项逐条标出「已回答 / 答无但存在相关事实 / 已答是但缺细节」，输出需人工确认清单与需向核保部门确认的问题。

## 典型用法

- 拿到问卷不知道「体检有结节」这一项该怎么答
- 几年前看过门诊，时间范围不确定要不要写
- 已经如实填了，想知道核保结论可能是什么
- 责任除外和拒保到底差在哪
- 签完才想起漏填，问现在怎么办
- 想把两份保单的问卷一起填

## 边界

本技能只做**结构化核对与口径提示**，**不构成医学诊断、医学建议、保险代理或法律意见**。**健康告知的范围以保险合同约定的询问事项为准**，具体问卷以投保单或电子投保单载明为准；**核保结论以保险公司实际出具的结论为准**，五类结论的判定标准由保险公司的核保规则决定；**未如实告知的后果以法律规定、合同约定与保险公司的核定为准**。不诊断疾病、不解读检查结果、不给治疗建议、不替代体检与就医。**不承诺核保结果、不承诺理赔结果**，不推荐具体保险公司与产品，**不建议修改答案或编造信息规避核保**。疾病与病史的归类判断涉及医学专业性，涉及时应咨询医生；核保复核与理赔争议应走承保公司正规渠道，必要时咨询律师。
