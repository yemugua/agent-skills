# 健康告知填写与理赔影响核查

健康告知的核心原则只有一句：**问什么答什么**。

不问你不用说，但你**问到的不答、答错、或者凭感觉答「问题不大」，就构成了未如实告知。**

这个技能做五件事：**取问卷 → 逐项对 → 分三类口径 → 认核保结论 → 留更正路径**。

---

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 按询问回答制逐项核对问卷与实际情况 | 诊断疾病、判断指标是否「问题不大」 |
| 区分体检异常、门诊记录、既往确诊三类填写口径 | 给医学建议、建议做或不做某个检查 |
| 说明五类核保结论的含义与后续处理 | 承诺核保结果、承诺一定能标准体通过 |
| 说明未如实告知的可能后果口径 | 断言「隐瞒了必定拒赔」 |
| 输出投保后自查与更正流程 | 建议补填漏项以规避核保 |
| 提示材料留存与核对要点 | 代替保险公司作核保与理赔认定 |

涉及以下情形，应停下来交由承保公司核保部门、专业代理人或医生处理：**疾病诊断与治疗建议、检查结果的医学解读、复杂病历的归类判断、核保结论的复核申请、理赔争议、涉及诉讼的告知义务争议**。

**绝对不做**：**不给医学结论、不诊断疾病、不承诺核保结果与理赔结果**。**健康告知的范围以保险合同约定的询问事项为准**；**核保结论以保险公司实际出具的结论为准**；**未如实告知的后果以法律规定、合同约定与保险公司的核定为准**。

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「健康告知怎么填」 | 用，按询问回答制逐项讲 |
| 「体检有结节要不要填」 | 用，讲体检异常口径 |
| 「几年前看过病要写吗」 | 用，讲时间范围与门诊记录口径 |
| 「没告知会拒赔吗」 | 用，讲可能后果，不下绝对结论 |
| 「带病能不能买保险」 | 用，讲五类核保结论 |
| 「加费和责任除外什么意思」 | 用，逐类解释含义与影响 |
| 「告知问卷没看清就签了」 | 用，讲投保后自查与更正流程 |
| 「要不要为了通过核保去改答案」 | 不用，明确拒绝 |
| 「我指标偏高能不能买」 | 只做结构化提示，医学判断转医生 |

## 三、完整工作流

```
第 1 步  取原始问卷：投保单或电子投保单的健康告知部分（全部问项）
第 2 步  读规则文件 rules/health-disclosure-rules.md（询问回答制、三类填写
        口径、五类核保结论、更正流程、防误伤清单）
第 3 步  逐问抄录问卷问题，不改写、不省略
第 4 步  逐问对照实际情况：体检报告、门诊病历、出院小结、既往诊断
第 5 步  归类每个问项涉及的情况类型：体检异常 / 门诊记录 / 既往确诊 /
        住院手术 / 长期用药 / 家族史 / 其他
第 6 步  逐问给出填写口径，并标注「以问卷原文与实际情况为准」
第 7 步  跑脚本：scripts/disclosure_check.py --file case.json
第 8 步  输出待确认问项清单与需向核保部门确认的问题
第 9 步  说明五类核保结论（标准体 / 加费 / 责任除外 / 延期 / 拒保）各自含义
第 10 步 给出投保后自查与更正流程，以及材料留存清单
```

## 四、核心口径

### 4.1 询问回答制（必须讲清）

**原则**：**保险人问了什么，投保人就答什么；没有被问到的，按保险合同条款的约定处理。**

| 要点 | 口径 |
|---|---|
| 询问范围 | **以保险合同约定的询问事项为准**，通常就是投保时那份书面或电子问卷 |
| 回答范围 | 问卷列明的每一问，**都要按实际情况回答** |
| 未问到的项 | 按保险合同条款的约定处理；**不能简单理解为「不问就完全不用管」** |
| 不可隐瞒 | **问卷问到的不答、答错、答得比实际轻，都属于未如实告知的风险范围** |
| 时间点 | 告知义务发生在**投保时**；出险时的「如实告知义务」是另一回事 |

**必须写清**：

- **问什么答什么**：问卷里的每一问都要读懂、如实回答
- **不是「不问不说就一定没事」**：具体以合同条款约定与法律规则为准，**不得给出「不问就不用说」的绝对结论**

**绝对禁止**：

- 「体检问题不大可以不填」——这是典型的未如实告知
- 「很久以前的事不用写」——是否属于询问范围**以问卷原文的时间范围为准**
- 「没问就不用说」——**不成立**，要看合同条款怎么约定

### 4.2 三类情况的填写口径（最容易错的地方）

| 情况类型 | 特征 | 填写口径（结构化提示） |
|---|---|---|
| **体检异常** | 体检报告有异常指标或影像所见，但**尚未确诊** | **如实填写「曾检查发现异常」的事实**，包括项目与时间；**不得填「无异常」，也不得擅自升格为「已确诊某病」** |
| **门诊记录** | 门诊就诊、开了药、有医嘱随访建议 | 按问卷问及的范围如实填写；**「医生说随访观察」不等于「已确诊」，也不是「无异常」** |
| **既往确诊** | 有明确的临床诊断、病理或检验确诊结论 | **如实填写确诊情况**，包括疾病名称与确诊时间；**不得因为「已经好了」就填「无」** |

**必须说明**：

- **身体上已经出现过的异常，填「无」就是把异常说成没有**
- **「问题不大」不是医疗结论，只是判断。判断不能代替如实回答。**
- **「已经好了」也不改变曾经发生过的事实**；是否属于询问范围**以问卷原文为准**

### 4.3 常见错误（逐条列，必须写进输出）

| 错误 | 说明 | 正确做法 |
|---|---|---|
| 凭感觉答 | 认为指标「问题不大」就填「否」 | 按实际情况填「是」，并在说明栏写清项目与时间 |
| 把体检异常当确诊 | 把「甲状腺结节」填成「甲状腺癌」 | 写「体检发现甲状腺结节，未确诊」 |
| 把确诊当体检异常 | 把确诊过的疾病写成「体检异常」 | 按实际确诊情况填写 |
| 把「随访观察」当「无异常」 | 医生说定期复查就不填 | 写明「曾就诊，医生建议随访观察」 |
| 只答「是/否」不写细节 | 问卷要求说明的项没写 | 补齐疾病名称、确诊时间、治疗情况 |
| 投保后才发现漏填 | 以为「没说就不算」 | **尽快按承保公司渠道主动补充更正**，不要沉默 |
| 替家人统一填 | 认为「都是健康的」 | **每个人的问卷各自独立**，逐人填写 |
| 时间范围理解错 | 认为「几年前的事不用写」 | 按问卷原文的时间范围作答 |

### 4.4 未如实告知的后果口径

**可以写**：

- 「未如实告知可能导致保险人依保险合同约定与相关法律规则，对相关事项**不承担给付责任**，并可能**解除合同**」
- 「如实告知后可能出现加费、责任除外、延期或拒保等核保结论」
- 「是否构成未如实告知、如何处理，**由保险公司依事实与合同约定核定**」

**不能写**：

- 「隐瞒了必定拒赔」——结论绝对化
- 「漏填一点没事」——淡化义务
- 「不填也没关系」——错误结论

**表述纪律**：**「未如实告知」不能写成「已如实告知」**；**「已如实告知」也不能写成「未如实告知」**。

### 4.5 五类核保结论（必须区分）

| 结论类型 | 含义 | 后续影响 |
|---|---|---|
| **标准体承保** | 按标准费率承保，无附加条件 | 保费与保障按标准执行 |
| **加费承保** | 按高于标准的费率缴费后承保 | **保费变高，保额与责任按合同** |
| **责任除外承保** | 承保，但将某项原因导致的疾病或责任排除在赔付范围外 | **该项不赔，其他责任按约赔付；必须主动核对除外的是哪一项** |
| **延期承保** | 暂不作出结论，需补充资料或经观察期后再定 | 需按承保公司要求配合，观察期长度与条件**以承保公司口径为准** |
| **拒保** | 不予承保 | 可换其他产品重新评估，但**不得试图通过改答案来规避** |

**必须说明**：**这五类是核保结论的常见类型，具体的判定标准由保险公司的核保规则决定，实际结论以保险公司出具的核保结论通知为准。**

**最关键的一条**：**责任除外不等于全部不赔。** 责任除外只针对被除外的那一项；**必须主动核对除外的是哪一项，别把它理解成整张保单废了。**

### 4.6 投保后自查与更正流程

```
第 1 步  拿到核保结论通知，逐项核对是否与告知内容一致
第 2 步  发现不一致的，按承保公司规定的渠道书面提出更正或复核
第 3 步  留存：投保单、告知问卷填写内容、提交记录、核保结论通知、沟通记录
第 4 步  若被拒保或有异议，走正规复核与投诉渠道
```

**必须说明**：

- **更正要趁早**：越早主动更正，越能说明情况
- **不要沉默**：漏填后不吭声，风险是自己承担
- **不得建议改答案来规避核保**：这是错误做法，**一旦被发现后果更严重**

## 五、核心规则与要件库

出结论前，**必须先读**：

- `rules/health-disclosure-rules.md`：询问回答制口径、常见问项类型清单、三类情况填写口径表、八类常见错误、五类核保结论详解、投保后自查与更正流程、材料留存清单、防误伤（否定词）清单。

**不得凭感觉判断「问题不大」**；**不得把体检异常升格或降格为确诊**；**不得断言「隐瞒必定拒赔」**；**不得承诺核保结果**；**不得建议改答案规避核保**；**不给医学结论**。

## 六、脚本用法

```bash
python scripts/disclosure_check.py --file case.json --out 健康告知核查.md
python scripts/disclosure_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：问卷问项列表（每项含问题原文与作答）、实际情况条目（类型、时间、项目）、是否发现漏填项 |
| `--text` | 直接给 JSON 字符串 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检 |

输入 JSON 示例：

```json
{
  "questions": [
    {"id": "Q1", "text": "近五年内是否有过体检异常指标？", "answer": "否"},
    {"id": "Q2", "text": "近五年内是否有过医生诊断的疾病？", "answer": "是",
     "detail": ""}
  ],
  "facts": [
    {"type": "体检异常", "item": "甲状腺结节", "date": "2025-06"},
    {"type": "既往确诊", "item": "2型糖尿病", "date": "2021-03"}
  ]
}
```

脚本输出：问项逐条核对结果（已回答 / 答无但存在相关事实 / 已答是但缺细节）、需人工确认的问项清单、五类核保结论的含义说明、投保后更正流程提示、以及必须向承保公司核保部门确认的问题清单。

> 脚本按你提供的信息做**结构化核对**。**健康告知范围以保险合同约定的询问事项为准**；**核保结论以保险公司实际出具的结论为准**；**未如实告知的后果以法律规定、合同约定与保险公司的核定为准**。脚本**不给医学结论、不诊断疾病**，**不承诺核保结果与理赔结果**，**不建议改答案规避核保**。

## 七、人工确认清单（这步不能省）

- [ ] **健康告知问卷原件**已拿到（不是销售转述的口头说明）
- [ ] 每一问的**问题原文**已抄录，不看缩写、不看摘要
- [ ] 每一问的**作答内容**已与实际填写的核对
- [ ] 已准备**近年的体检报告**与**门诊病历**逐项对照，不是凭记忆
- [ ] 「体检异常」「门诊记录」「既往确诊」三类情况**已分别归类**，没有混填
- [ ] 答「是」但问卷要求填说明的，**说明栏已补齐**（疾病名称、时间、治疗情况）
- [ ] 时间范围按**问卷原文**执行，不是按自己理解
- [ ] **核保结论通知**已拿到，并与告知内容逐项核对
- [ ] 若为**责任除外**，已确认**除外的是哪一项**
- [ ] 若为**加费**，已知悉费率变化与其余保障内容
- [ ] 若为**延期**，已知悉需配合的补充资料与观察条件
- [ ] 材料已留存：投保单、问卷、提交记录、核保通知、沟通记录
- [ ] 结论中**没有出现「一定赔」「一定拒赔」「肯定能过」**这类表述

## 八、最常见的坑

1. **凭感觉答，认为「问题不大」就填否。** 这是最典型、也是后果最直接的错误。**「问题不大」是判断，不是医疗结论，判断不能代替如实回答。**
2. **把体检异常当成已确诊疾病填。** 甲状腺结节填成甲状腺癌，投保时看着谨慎，理赔时可能说不清楚。**如实写「体检发现某异常，未确诊」就够。**
3. **把已确诊的疾病写成「体检异常」。** 这是**往轻了填**，性质同样是不如实。**「已经好了」不改变曾经发生过的事实。**
4. **把「医生说随访观察」当成「无异常」。** 随访观察意味着有异常、有就诊、有医嘱，**不是没有**。
5. **只答「是/否」不写细节。** 问卷要求填说明的地方空着，等于信息不完整，核保时可能被直接追问或加费。
6. **认为「几年前的事不用写」。** 时间范围看的是**问卷原文**，不是自己划定的标准。**「几年前」在你和保险公司那里可能不是同一个起算点。**
7. **投保后才发现漏填，却以为「没说就不算」。** **漏填后不吭声，风险是自己承担。** 发现不一致要尽快按承保公司渠道主动更正。
8. **替家人统一填「都是健康的」。** 每个人的问卷各自独立，**不能相互代替**。家长替孩子填、配偶替对方填，都是把风险往自己身上搬。
9. **把「责任除外」理解成整张保单废了。** **责任除外只针对被除外的那一项，其他责任按约赔付。** 但反过来更要注意：**必须主动核对除外的是哪一项**，不去核对就默认「全都赔」，出险时才发现。
10. **以为「如实告知了就能过」。** 如实告知之后，核保结论可能是加费、除外、延期甚至拒保。**如实是义务，不是通行证。**
11. **为了通过核保去改答案。** 这是把一个可能的除外变成可能的解除合同甚至更严重的后果。**不要这么做。**
12. **把「未如实告知」和「免责条款」当成一回事。** 一个是**投保时没说**，一个是**合同说不赔**。都可能拿不到赔款，但**依据和时点完全不同**。

## 九、边界与免责

- 本技能用于健康告知问卷的**结构化核对与口径提示**，**不构成医学诊断、医学建议、保险代理或法律意见**
- **健康告知的范围以保险合同约定的询问事项为准**；**具体问卷以投保单或电子投保单载明为准**
- **核保结论以保险公司实际出具的结论为准**；五类结论的**判定标准由保险公司的核保规则决定**，本技能只说明其**含义与影响**
- **未如实告知的后果以法律规定、合同约定与保险公司的核定为准**；本技能**不断言「隐瞒必定拒赔」**，也**不断言「没隐瞒就一定能赔」**
- 本技能**不诊断疾病、不解读检查结果、不给治疗建议、不替代体检与就医**
- **不承诺核保结果、不承诺理赔结果**；不推荐具体保险公司与产品；**不建议修改答案或编造信息规避核保**
- 疾病与病史的归类判断涉及医学专业性，**涉及时应咨询医生**；核保结论的复核与理赔争议应走承保公司正规渠道，必要时咨询律师
