# 逆光拍照（backlit-photo-fix）

逆光只有两条路：**要么把脸补亮，要么干脆拍成剪影。**

最差的结果是中间状态——脸半黑不黑、背景也没亮起来。这种照片既不是人像也不是剪影，只能删。

这个技能做三件事：**选路线 → 定测光 → 控眩光**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 判定该走补光还是剪影路线 | ❌ 检测或修复设备的硬件故障 |
| 核查测光方式、曝光锁定、补光距离 | ❌ 提供后期局部提亮、蒙版、合成的具体操作 |
| 说明眩光控制与发丝光要点 | ❌ 替代摄影师在现场的取景与判断 |
| 给出四种补光方式的取舍 | ❌ 推荐具体品牌型号的补光器材 |

**遇到以下情况，按各自渠道处理：**

- 设备出现**对焦失败、测光异常、画面异常条纹** → 属设备故障，走售后或维修
- 需要**后期局部提亮、蒙版、合成** → 不在本技能范围
- 涉及**他人肖像**的照片 → 发布前应取得本人同意
- 各机型的测光模式名称、锁定操作方式差异很大 → 以自己设备的官方说明为准

**安全提示**：**不要为了逆光效果直视强光源取景，尤其不要用眼睛或镜头长时间对准太阳**，避免视力损伤与设备损坏。

## 二、完整工作流

### 第一步：先二选一（这步不能跳）

| 路线 | 什么时候选 | 关键动作 |
|---|---|---|
| **补光人像** | 背景本身漂亮（晚霞、水面反光、通透树叶） | 对人脸点测光 + 锁定 + 补光 |
| **剪影** | 背景杂乱、手上没补光工具、手机没 HDR | 压曝光到负 1 到负 2 + 轮廓清晰 + 背景有光 |

### 第二步：定测光（补光路线）

**对着人脸点测光，然后锁定曝光。**

为什么平均测光不行：测光系统想把整个画面平均到中性灰，逆光时明亮背景占大面积，系统为压住亮区会整体降曝光——**人脸就被拖黑了**。

**锁曝光不能省**：多数手机是「点哪里测哪里」，点完人脸不锁定，重新构图时测光点会漂移，脸又黑回去。

### 第三步：选补光方式

| 方式 | 有效距离 | 适用 |
|---|---|---|
| 反光板 | 1 到 2 米 | 有人帮忙举，光线最自然 |
| 闪光灯 / 补光灯 | 按器材标称值，常见 2 到 5 米 | 一个人拍；**超出有效距离等于没补** |
| 常亮补光 | 1 到 3 米 | 手机适用，强日光下压不过 |
| HDR / 提曝光补偿 | 不限 | 没带器材时的兜底 |

**补光量**：补到**人脸比背景暗 1 到 2 挡**就停。补过头脸比背景还亮，逆光氛围全丢。

### 第四步：控眩光

按有效性排序：**让光源被遮挡**（最有效）→ 装遮光罩或用手斜挡 → 偏 15 到 30 度 → 擦干净镜头。

### 第五步：填 JSON 跑自查

脚本一次给出逐张判定、路线选择与整改顺序。

## 三、核心规则（生成结论前先读规则文件）

**必须先读 `rules/逆光环境与补光处理.md`，不要凭印象写。** 规则文件里有：

- 两条路线的判断依据与最差结果说明
- 四种测光方式在逆光下的表现表
- 四种补光方式的有效距离、优点与注意点
- 眩光控制四招（按有效性排序）
- 发丝光四要点
- 剪影五要素
- 判定顺序说明与八条高频坑

**判定顺序不能颠倒**：先看严重项，再看可改进项，最后才看信息是否完整。

**为什么这条重要**：若先判信息完整度，会出现「已经用平均测光把脸拍全黑，却因为没填遮光罩而被判成待确认」——把问题说轻了，比漏判更糟。

**剪影路线不报「脸黑」**：剪影里脸黑是目标，不是缺陷。

| 路线 | 项目 | 合格口径 | 严重度 |
|---|---|---|---|
| 补光 | 测光方式 | 点测光对人脸；平均测光判不合格 | 严重 |

| 补光 | 补光距离 | 在器材有效距离之内 | 严重 |
| 补光 | 曝光锁定 | 点测后必须锁定 | 可改进 |
| 补光 | 眩光控制 | 有遮光罩或光源被遮挡 | 可改进 |
| 补光 | 机位 | 不正对光源 | 可改进 |
| 补光 | 补光量 | 人脸比背景暗 1 到 2 挡 | 可改进 |
| 剪影 | 曝光补偿 | 不高于负 0.5，不低于负 2.0 | 严重 / 可改进 |
| 剪影 | 轮廓 | 清晰，不重叠 | 严重 |
| 剪影 | 背景 | 必须有光 | 严重 |

## 五、脚本用法

```bash
python scripts/backlit_check.py --file backlit.json --out 逆光核查.md
python scripts/backlit_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`shots` 为照片列表，每张填 `mode` / `light` / `metering` / `fill` 等 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检（58 条断言，含 BOM 两条路径） |

输入 JSON 示例：

```json
{
  "shots": [
    {
      "name": "傍晚人像",
      "mode": "portrait",
      "light": "side_back",
      "metering": "spot_face",
      "exposure_lock": true,
      "fill": "reflector",
      "fill_distance_m": 1.5,
      "lens_hood": true,
      "angle_to_sun": "shielded",
      "face_vs_bg_stops": 1.5,
      "ev": 0.0
    }
  ]
}
```

可选枚举：`mode` 取 `portrait` / `silhouette`；
`light` 取 `back` / `side_back` / `side` / `front`（顺光与侧光返回「不适用逆光判定」）；
`metering` 取 `spot_face` / `evaluative` / `center` / `average` / `spot_bg`；
`fill` 取 `reflector` / `flash` / `continuous` / `hdr` / `none`；
`angle_to_sun` 取 `shielded` / `side` / `direct`。

数值字段：`fill_distance_m`（补光距离）、`flash_effective_m`（闪光器材标称有效距离，用于覆盖默认值）、
`face_vs_bg_stops`（人脸比背景暗的挡数）、`ev`（曝光补偿）。
布尔字段：`exposure_lock`、`lens_hood`、`hdr`、`bg_clipped`、`outline_clear`、`bg_has_light`。

脚本输出：总体判定、两条路线表、逐张判定表（含不合格原因的 why）、整改顺序、测光方式偏差表、补光方式与有效距离表、阈值表、人工确认清单。

## 六、人工确认清单（这步不能省）

- [ ] 已二选一：补光人像或剪影，不是中间状态
- [ ] 补光路线已对人脸点测光并锁定曝光
- [ ] 补光距离在器材有效距离之内
- [ ] 有遮光措施，或光源已被主体遮挡
- [ ] 剪影路线已压曝光到负 1 到负 2，轮廓清晰、背景有光
- [ ] 没有长时间用镜头或眼睛直对强光源
- [ ] 涉及他人肖像的照片，发布前已取得本人同意

## 七、最常见的坑

**坑一：用平均测光拍逆光人像。**
错误做法：举起来就拍，脸黑成剪影还不知道为什么。正确做法：**对人脸点测光并锁定**。测光系统想把整个画面平均到中性灰，而明亮背景占了大面积，它就会整体降曝光把脸拖黑。

**坑二：点完人脸没锁曝光。**
错误做法：点了人脸，然后移动手机重新构图。正确做法：**按下锁定再构图**。多数手机是点哪里测哪里，测光点会跟着漂移，脸又黑回去。

**坑三：闪光灯在 6 米外补光。**
错误做法：开了闪光灯，人在 6 米外，器材标称有效距离只有 3 米。正确做法：**超出有效距离等于没补**。走近补光、提高功率，或改用反光板近距离补。

**坑四：逆光正对太阳拍。**
错误做法：把太阳框进画面正中间。正确做法：**让主体的头、一棵树、一根柱子挡住太阳**，或者偏 15 到 30 度。正对光源画面会发灰起雾。

**坑五：补光补过头。**
错误做法：把脸补得比背景还亮。正确做法：**补到人脸比背景暗 1 到 2 挡就停**。补过头逆光氛围全丢，看着像棚拍。

**坑六：想拍剪影却没压曝光。**
错误做法：人是灰的，不是黑的。正确做法：**压到负 1 到负 2**。灰蒙蒙的人既不是人像也不是剪影。

**坑七：剪影选了纯黑背景。**
错误做法：对着一堵暗墙拍剪影，拍出来什么都没有。正确做法：**剪影的前提是背景有光**——晚霞、亮水面、亮天空。

**坑八：两个人轮廓叠在一起。**
错误做法：一家三口站成一团拍剪影，形状糊成一块。正确做法：**让人分开站，留出间隙**，动作要大（伸展、跳跃、牵手），剪影靠形状说话。
