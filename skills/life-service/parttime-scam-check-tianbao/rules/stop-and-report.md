# 紧急止付、报警要点与帮信罪风险

## 一、紧急动作：按这个顺序做

### 1. 立即停止一切转账

**这是第一位，也是最重要的一位。**

对方说的解冻、补单、申诉、交保证金，**全部是继续骗你的话术**。不存在「再充一次就放款」。

只要不再加钱，损失就不会扩大。**守住这一步比什么都重要。**

### 2. 拨 96110 或 110

- **96110**：全国反诈专线，可以咨询并**协助对涉诈账户止付**
- **110**：直接报警，走刑事

### 3. 申请紧急止付与冻结

第一时间联系银行、支付平台（支付宝/云闪付等）申请**紧急止付、账户冻结**。

**越快越能保住剩余资金**——资金在流转途中就有机会拦下，一旦被取现就很难追。

### 4. 保存全部证据，不要删除

- ❌ 不要删 App
- ❌ 不要删聊天记录
- ❌ 不要退出群
- ✅ 截图 + 录屏、打印账单、导出聊天

### 5. 不要受恐吓而沉默

对方说「不能报警」「会曝光隐私」**正是诈骗的典型施压话术**。

**报警是你的权利**。恐吓恰恰说明对方心虚。

### 6. 排查是否被牵连「帮信罪」

**如果你知情的情况下提供了银行卡、收款码、账户帮对方收款**，可能被认定为**帮助信息网络犯罪活动罪（帮信罪）**。

- **主动向公安机关说明，争取从宽处理**
- **隐瞒只会更被动**——现在技术手段已经能查到资金流向

### 7. 改密码、查征信

- 修改支付密码、网银密码，**关闭小额免密与代扣授权**
- 查询征信报告，看是否因延迟还款留下不良记录
- 确认名下无不明贷款与账户

## 二、报警要点

| 项 | 内容 |
|---|---|
| 报警电话 | 110（报警）、**96110**（全国反诈专线） |
| 主要罪名 | **诈骗罪**（以非法占有为目的，虚构事实骗取财物） |
| 关键证据 | 转账记录、聊天记录、对方账号信息、任务页面 |
| 必拿文书 | **受案回执**（没有就再去要） |
| 追回方式 | 刑事追赃为主，也可参与退赔退赃程序 |

### 报警时怎么说

按时间线讲清楚，每一步都要具体：

```
1. 什么时候、在哪看到的信息（快手/招聘平台/群）
2. 对方用什么话术（把原话复述一遍）
3. 第一笔垫了多少、返了多少
4. 后面怎么一步步加码到现在的金额
5. 什么时候开始说订单异常、要求解冻
6. 你一共转了多少钱、对方收款账号是什么
7. 现在对方还在联系吗
```

**一定要拿到受案回执**。这是后续所有维权的基础，没有它什么都做不了。

## 三、七步维权路径

| 步骤 | 时间 | 动作 |
|---|---|---|
| **1. 止付与报警** | 1 小时内 | 停止转账 → 拨 96110/110 → 申请紧急止付 |
| **2. 固定证据** | 24 小时内 | 导出聊天（截图+录屏）、转账记录、App 页面、对方账号、群聊，**按时间顺序编号成册** |
| **3. 提交材料** | 3 日内 | 到派出所提交，**取得受案回执**；金额大的**争取立为刑事案件** |
| **4. 配合调查** | 持续 | 提供资金流向线索。**已转出资金若能快速止付，可望部分挽回**；已被取走的，追赃周期较长 |
| **5. 平台投诉** | 同步 | 向涉事 App 平台投诉举报涉诈店铺与账号；涉未成年人同步联系监护人与学校 |
| **6. 刑事追赃** | 主线 | 通过律师申请追赃挽损，或参与法院审理阶段的**退赔退赃**程序 |
| **7. 民事兜底** | 备选 | 若平台未尽审核义务、支付机构风控不足，可另行主张相应责任。金额巨大建议咨询律师 |

## 四、几句必须记住的话

1. **正规兼职永远不会先收你钱**。培训费、押金、服装费、保证金——**全都是诈骗信号**。
2. **返利不是守信的表现**。前几十块的返利是买你信任的成本，不是对方讲信用。
3. **被威胁「不能报警」时，恰恰是最该报警的时候**。
4. **不要联系对方家属或在网上曝光**——这不但没用，还可能反被索赔。
