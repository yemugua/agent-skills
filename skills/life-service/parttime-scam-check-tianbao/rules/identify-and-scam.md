# 五阶段骗局结构与六类话术红旗

## 一、骗局是怎么推进的

标准刷单骗局有固定的五步。**每一步都在为下一步铺垫**，看懂结构就不会被「再充一次」骗到。

### 第 1 步：引流（广撒网）

| 渠道 | 话术 |
|---|---|
| 短视频 | 抖音/快手上「点赞关注做任务，日结 250」 |
| 招聘平台 | 「招线上兼职，手机就能做，零经验」 |
| 群聊 | 「进群接单，日结当天返」 |
| 陌生人私信 | 「姐妹在哪？有个兼职要不要看看」 |

**特征**：门槛极低、回报极高、不需要任何经验。**正常兼职不会这样**。

### 第 2 步：小额返利（建立信任）

让你做一个极小任务（垫 30~100 元），**完成后立刻返你几十块**。

**这一步是整个骗局的关键**：让你亲手验证「真的能返钱」。小额几十块，换的是你对后面几万块的信任。

### 第 3 步：垫资放大（提高赌注）

任务金额逐步加大：88 → 600 → 3000 → 50000。返利比例一直很诱人。

**你已经拿到过前几笔返利，所以不会怀疑。** 但钱越投越多，已经收不回来了。

### 第 4 步：冻结解冻（收割）

突然出现各种问题：

- 「订单异常，需要完成流水才能提现」
- 「系统判定为套利，需要充值解冻」
- 「提现名额已满，再做一单」
- 「缴纳保证金即可解冻」

**核心话术：「你的钱还在系统里，再充 X 就能一起退。」**

### 第 5 步：威胁拉黑（收割完毕）

你已经没钱可投了，对方换脸：

- 「不配合就取消资格，钱不退」
- 「拉黑你、曝光你找工作的信息」
- 「别报警，报了也没用」

**这时候的恐吓，目的就是让你不去报警。**

## 二、六类话术红旗

命中越多，诈骗可能性越高。

| 红旗 | 常见表述 | 为什么危险 |
|---|---|---|
| **以招聘兼职为名引流** | 招兼职、高薪、日结、门槛低、零经验、在家就能做 | 高薪零门槛 = 用不劳而获吸引人 |
| **要求垫资做任务** | 垫付、充值、本金、自己出钱、下单拍下 | **正常兼职不会要你先掏钱** |
| **以高额返利诱导** | 返利、佣金、提成、日息、回报率、千分之五 | 高回报必然对应高风险 |
| **宣称零风险稳赚** | 无风险、稳赚、保本、百分百、必返 | **没有人能保证赚钱**，说这话的就是想让你放松 |
| **制造时间紧迫感** | 名额有限、今天到期、马上、抓紧、先到先得 | 逼你当场决策，不给你冷静时间 |
| **拉群或转到隐蔽环境操作** | 让你下载专用 App、加私人微信、境外平台 | 正规公司不会要求你绕开公开渠道 |

## 三、五类平台形态

| 形态 | 特征 |
|---|---|
| **刷单返利类** | 「刷单」「垫付」「返利」，最典型的一种 |
| **点赞点赞类** | 以点赞关注为名，实际是刷单的前端包装 |
| **打字录入类** | 招打字员、数据标注，话术温和，**但要你先交押金/培训费** |
| **虚假投资类** | 「跟着导师炒股稳赚」「内部消息带单」，可能是刷单也可能是杀猪盘 |
| **仿冒客服类** | 假冒客服理赔、刷好评返现，目的是骗你转账 |

**注意：打字录入类变体最容易被忽视。** 「培训费」「服装费」「押金」本质都是**骗你交钱**，正规的兼职**永远不会先收费**。
