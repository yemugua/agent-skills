# 兼职刷单返利诈骗核查

刷单骗局的可怕之处不在于被骗走多少钱，而在于**它每一步都在教你「再充一次就能提现」**。

## 骗局是怎么推进的

标准刷单骗局有固定的五步。每一步都在为下一步铺垫。

## 什么时候用

- 有人说「点赞关注做任务，日结两三百」，你垫了第一单确实返了几十块
- 做到后面提示订单异常、流水不足，要求充值解冻
- 对方说「不配合就拉黑、曝光你找工作的事」「报警也没用」
- 已经转了好几笔，对方开始换名字、换账号
- 想知道自己该做什么、能追回多少

## 怎么用

复制 `templates/兼职刷单被骗信息采集表.md` 填写，跑脚本，按报告里的紧急动作清单处理。

**最要紧的三件事**：

1. **立刻停止一切转账**——解冻、补单、申诉都是继续骗钱
2. **拨 96110 或 110 报警**，申请紧急止付
3. **保存全部证据**——不要删 App、不要删聊天记录

## 报告的十一段

| 段 | 内容 |
|---|---|
| 一 | 结论摘要（含最该先做的三件事） |
| 二 | 事件性质与骗局阶段定位 |
| 三 | 话术红旗信号识别（六类） |
| 四 | 资金投入与损失核算 |
| 五 | 处置与报案核查（报警/停止/止付/证据/账户） |
| 六 | 证据清单与缺口 |
| 七 | 紧急止损动作（八条） |
| 八 | 路径与维权流程（七步） |
| 九 | 报警要点与法律提示 |
| 十 | 证据缺口速查 |
| 十一 | 待办补正动作 |

## 四条最该记住的规则

1. **停止转账是唯一的破局点**。「解冻」「补单」「申诉」「交保证金」全是话术，不存在「再充一次就放款」。
2. **只要要求你先垫资，就已经是诈骗**。没有正规兼职需要你先掏钱。
3. **这类钱主要靠刑事追赃**。报警是主线，越早越好。
4. **出借过银行卡或收款码的，主动说明**。可能涉帮信罪，隐瞒更被动。

## 边界

依通用规则整理，不替代律师意见。案件性质与追赃结果以公安机关与司法机关认定为准。不预测能否追回。不外发个人信息，不在公开平台曝光对方。
