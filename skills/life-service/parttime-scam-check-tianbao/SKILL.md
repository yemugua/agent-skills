# 兼职刷单被骗止损与报警追回

刷单骗局的可怕之处不在于被骗走多少钱，而在于**它每一步都在教你「再充一次就能提现」**。

## 什么时候用

- 有人说「点赞关注做任务，日结两三百」，你垫了第一单确实返了几十块
- 做到后面提示订单异常、流水不足，要求充值解冻
- 对方说「不配合就拉黑、曝光你找工作的事」「报警也没用」
- 已经转了好几笔，对方开始换名字、换账号
- 想知道自己该做什么、能追回多少

## 怎么做

**第 1 步**：复制 `templates/兼职刷单被骗信息采集表.md` 填写（**事件经过、对方承诺、任务流程、已投入金额、是否已报警、是否已停止转账**是关键项）。

**第 2 步**：跑脚本

```bash
python scripts/parttime_scam_check.py 采集表.md --base 2026-10-05 --out 核查报告.md
```

**第 3 步**：照第七段做紧急动作——**① 立即停止转账 ② 拨 96110 或 110 ③ 申请紧急止付**。

## 四条最该记住的规则

1. **停止转账是唯一的破局点**。对方说的「解冻」「补单」「申诉」「交保证金」，**全部是继续骗你的话术**，不存在「再充一次就放款」。
2. **只要要求你先垫资，就已经是诈骗**。**没有任何正规兼职需要你先掏钱**。所谓「返利」，是小额诱饵，不是守信的表现。
3. **这类钱主要靠刑事追赃**。民事协商、找平台投诉基本追不回来，**报警是主线**，而且**越早越好**——资金往下游走得越快，越难拦。
4. **如果出借过银行卡或收款码**，主动说明。你可能被认定为**帮助信息网络犯罪活动罪（帮信罪）**，**知情也要说，隐瞒只会更被动**。

## 边界与纪律

- 依**通用规则**整理，**不替代律师意见**；案件性质与追赃结果，**以公安机关与司法机关认定为准**
- 报告金额按已填凭证汇总，**实际追回金额以侦查与司法结果为准**；**不预测能否追回、能追回多少**
- **未填的一律不算通过**，只按已填内容判断
- 涉及**双方账号、身份证、银行卡等个人信息**，**本地处理，不要外发**
- **不要在公开平台曝光对方，也不要联系对方家属**——这不但解决不了问题，还可能反被索赔
- 金额巨大的，**建议咨询律师**
