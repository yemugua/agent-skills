# 兼职刷单返利诈骗核查报告 模板

> 报告由 `scripts/parttime_scam_check.py` 自动生成，共**十一段**。本文件说明每段的用途与判读方式。

## 段落结构

| 段 | 标题 | 内容 | 判读要点 |
|---|---|---|---|
| 一 | 结论摘要 | 整体判定 + 不通过/有风险数量 + **最该先做的三件事** | **先看这一段**。三件事固定是：停止转账、报警、止付 |
| 二 | 事件性质与骗局阶段 | 五类平台形态 + 你陷进五个阶段的哪一步 | 出现「冻结解冻阶段」「威胁拉黑阶段」= 已经收割完了 |
| 三 | 话术红旗信号识别 | 六类红旗（招聘引流/要求垫资/高额返利/零风险/紧迫感/隐蔽操作）+ 是否已被要求出资 | 命中越多越明确 |
| 四 | 资金投入与损失核算 | 已投入、已退回、**净损失**、损失是否达刑事报案量级 | ⚠️ **追加投入已含在总额里，不重复计入** |
| 五 | 处置与报案核查 | 报警 / 停止转账 / 止付 / 证据 / 出借账户 | 每一项独立判定 |
| 六 | 证据清单与缺口 | 七类证据是否齐全 | **未填的不算通过** |
| 七 | 紧急止损动作 | 八条（停止转账、96110、止付、留证、不沉默、改密码、帮信罪、征信） | **照着做** |
| 八 | 路径与维权流程 | 七步（止付报警 → 固证 → 报材料 → 配合调查 → 平台投诉 → 刑事追赃 → 民事兜底） | 按顺序走 |
| 九 | 报警要点与法律提示 | 报警电话、罪名、关键证据、必拿文书、追回方式 | **一定要拿到受案回执** |
| 十 | 证据缺口速查 | 缺哪一类会导致哪一项主张站不住 | 补材料优先级 |
| 十一 | 待办补正动作 | 可直接照做的补正动作清单 | 照着做即可 |

## 四态判定

| 判定 | 含义 | 你该做什么 |
|---|---|---|
| **通过** | 已填内容中该项没问题 | 不用动。**注意：未填不判通过** |
| **有风险** | 有隐患但不一定致命 | 优先补材料，必要时作为协商依据 |
| **不通过** | 明确存在问题 | 这是主张权利的核心理由 |
| **待补正** | 关键信息没填，无法判断 | **先补采集表再重跑**，不要凭感觉下结论 |

---

## 使用建议

1. **先补齐采集表再跑脚本**。填「不清楚」比乱填好——脚本会判「待补正」，不会给你假结论。
2. **净损失 = 已投入 − 已退回**。解冻追加的那笔钱通常**已经含在已投入总额里**，报告里会单独提示，不要重复计算。
3. **实际追回金额以侦查与司法结果为准**。报告不预测能否追回。
4. **隐私本地处理**。采集表含双方账号、身份证、银行卡，不要发到公开平台。
