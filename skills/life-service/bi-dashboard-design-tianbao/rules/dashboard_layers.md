# BI 看板分层、配额与可视化规则库

> 生成看板方案、评审看板、或审查指标清单前，先读这份规则，不要凭印象写。

---

## 一、三层指标分层定义

| 层 | 定义 | 判断标准 | 常见误放|
|---|---|---|---|
| **结果指标** | 业务最终要的东西，直接对应收入/用户/满意度 | 「这个数掉了，公司是不是受损」 | — |
| **过程指标** | 驱动结果的中间环节，可加和、有明确上下游 | 「这个环节改善会不会推高结果」 | 被误当结果指标汇报 |
| **健康度指标** | 反映做这件事付出的代价或潜在风险 | 「这件事是不是在透支未来」 | 被完全忽略 |

**归层实操法**：拿一个指标问自己两个问题——
1. 「它变了，老板会不会关心？」会 → 结果层。
2. 「它变了，说明结果会变（好或坏）？」是 → 过程层。
3. 「它变坏了，我们需要刹车吗？」是 → 健康度层。

一个指标可能同时符合多个。**按「老板第一眼要看哪个」来定层**。

## 二、每层数量配额（硬约束）

| 层 | 下限 | 上限 | 超出处置 |
|---|---|---|---|
| 结果指标 | 3 | **6** | 合并到总览页，其余下钻 |
| 过程指标 | 4 | **8** | 按业务链路分组，超出部分移入二级页 |
| 健康度指标 | 2 | **5** | 只保留有明确阈值与处置动作的 |
| **单屏总数** | — | **12** | **必须拆看板** |

**单块看板只回答一个问题**。一句话说不清，就拆。

### 两级看板结构（推荐）

```
一级总览页：结果层 4-6 + 健康度层 3-4      → 10 个以内，零交互可读
二级下钻页：按维度拆分的过程指标链路        → 可交互、可下钻、可导出
```

## 三、图型选型对照表（完整版）

| 数据形态 | 判定条件 | 首选图型 | 禁用图型 | 关键设置 |
|---|---|---|---|---|
| 时间序列 | 连续多期 | 折线图 | 柱状图、面积图（多序列时） | 纵轴可不从 0 起，需标断轴 |
| 时间序列对比 | 2–4 个序列 | 多折线 + 直接标注线尾 | 图例在远处 | 线尾直接标名称，去掉图例 |
| 类目对比 | 类目 ≤8 | 横向条形图（按值排序） | 饼图 | 按值降序，类目名用全称 |
| 类目对比 | 类目 >8 | 排序条形图 Top N + 「其他」 | 全部铺开 | N 取 10，其余归「其他」 |
| 构成占比 | 部分 ≤5 | 100% 堆叠条形 | 饼图、雷达图 | 标注百分比 |
| 构成占比 | 随时间变化 | 堆叠面积图 | 多饼轮播 | 层数 ≤5 |
| 分布 | 单连续变量 | 直方图、箱线图、小提琴图 | 柱状图 | 分箱数按样本量定 |
| 相关 | 两连续变量 | 散点图（含趋势线） | 折线图 | 标注相关系数与样本量 |
| 转化路径 | 有序阶段 | 漏斗图 / 横向递减条形 | 折线图、饼图 | 同时标绝对量与转化率 |
| 地理 | 有地理维度 | 分级设色地图 + 排序表 | 3D 地球、飞线图 | 地图必配排序表（精确比较靠表不靠色） |
| 单值 + 目标 | 1 个数对目标 | 指标数字卡（值 + 同比 + 进度条） | 仪表盘、3D 饼 | 数字卡优于仪表盘 |
| 时间 × 类别 | 双维交叉 | 热力图 | 分组柱状图（类目多时） | 类目按大小排序 |
| 明细 | 需要精确读数 | 表格 / 透视表 | 图表 | 数值右对齐、等宽字体 |

### 轴与刻度硬规则

| 规则 | 说明 |
|---|---|
| 柱状图纵轴**必须从 0 起** | 截断柱状图会歪曲比例关系，属于误导性可视化 |
| 折线图纵轴**可不从 0 起** | 小幅变化需要放大观察，但**必须在断轴处画折断符号并标注** |
| 类目图**必须按值排序** | 不按字母/编码顺序排，读者无法一眼找到极值 |
| 时间轴**必须等距** | 不等距日期（跳过周末、跳过空白期）会歪曲斜率 |
| 双轴图**慎用** | 两轴缩放可任意调整，会凭空造出「相关性」；确需使用时两轴均标单位且视觉上区分 |
| 网格线**减淡** | 网格应辅助读数，不应抢过数据 |

## 四、指标维度完备性七要素检查表

| # | 要素 | 判定问题 | 不合格示例 | 合格示例 |
|---|---|---|---|---|
| 1 | 时间窗 | 统计区间怎么定义？边界含不含？ | 「日活」 | 「自然日 00:00-24:00，Asia/Shanghai」 |
| 2 | 分母口径 | 比率类指标分母是什么？ | 「转化率」 | 「支付订单数 ÷ 到达结算页的 UV」 |
| 3 | 对比基准 | 同比还是环比？还是没有？ | 数字旁边无标注 | 「同比 +3.2%（vs 去年同期）」 |
| 4 | 维度 | 拆到哪些维度？ | 「DAU 100 万」 | 「DAU 100 万，可拆渠道/端/新老」 |
| 5 | 口径版本 | 与上期是否同口径？ | 历史数据口径变过未标注 | 口径 v3.1，断点已标注 |
| 6 | 数据延迟 | 什么时候出数？当前跑完没？ | 无说明 | 「T+1，每日 08:00 前更新」 |
| 7 | 负责人 | 数不对找谁？ | 无 | 数据owner + 业务 owner |

**任一项缺失 → 该指标不得上板。**

## 五、配色规范

### 语义色固定表（不得挪作他用）

| 语义 | 色相 | 说明 |
|---|---|---|
| 涨跌-正向 | 绿（或红，按地域习惯） | 全看板固定，注明习惯来源 |
| 涨跌-负向 | 红（或绿） | 与正向严格互补 |
| 状态-正常 | 绿 | 仅用于健康度层 |
| 状态-预警 | 黄/琥珀 | 仅用于健康度层 |
| 状态-异常 | 红 | 仅用于健康度层 |
| 中性 | 灰阶 | 背景、次要文字、对比组的一方 |

> **关键**：涨跌色与状态色在视觉上必须可区分（建议涨跌用蓝/橙，状态用绿/黄/红），否则红色的数字既可能是「跌」也可能是「异常」，语义冲突。

### 分类配色规则

| 类目性质 | 配色方式 | 禁止 |
|---|---|---|
| 无序类目 | 单色相按明度渐变（按值排序后取色阶） | 彩虹色（色相间距不均，读不出顺序） |
| 有序类目（时间/等级） | 单色相由浅到深 | 彩虹色 |
| 二元对比 | 对比色 + 中性灰 | 红绿（红绿是对立语义） |
| 连续数值（热力图） | 单色相明度渐变 | 发散双色（除非有明确中点含义） |

### 硬性禁止

- 3D 任何图表
- 面积渐变填充 + 白色描边「发光」效果
- 装饰性阴影、透视倾斜、旋转标签
- 超过 7 色的分类配色（超过 7 类人眼无法稳定区分）
- 仅用颜色传递信息（必须配符号或文字，考虑色觉障碍）
- 彩虹色用于**有序**数据

## 六、八大常见错误识别口径

| # | 错误 | 量化识别信号 | 处置 |
|---|---|---|---|
| 1 | 过程指标当结果 | 结果层出现「点击/曝光/访问/PV」等词 | 下移到过程层 |
| 2 | 指标无维度 | 指标只给总计值，无任何拆分视图 | 补至少一个维度拆分 |
| 3 | 口径不一致 | 与财务/业务报表差异无法解释到字段级 | 建立指标字典并对齐 |
| 4 | 同比对象错位 | 用相邻周期冒充同比；日历周错位 | 同比=去年同期；周同比需对齐自然周 |
| 5 | 图型错配 | 饼图>3 块；柱状图表时间序列；折线图表分布 | 按选型表改 |
| 6 | 指标过载 | 单屏数字块 >12 | 拆两级看板 |
| 7 | 无更新时间 | 页面无「数据截至」标注 | 顶部固定标注 |
| 8 | 配色无语义 | 同一颜色在不同区含义不同；涨跌与异常同色 | 按语义色固定表改 |

## 七、看板评审清单（逐条打勾，缺一不放行）

**问题与受众**
- [ ] 一句话写清本看板回答什么问题
- [ ] 受众明确（高管 / 一线 / 分析师），且按受众裁剪了细节

**分层与配额**
- [ ] 三层归类完成，每个指标都能说清归层理由
- [ ] 结果层 ≤6，过程层 ≤8，健康度层 ≤5
- [ ] 单屏总数 ≤12

**口径完备性**
- [ ] 七要素全部回答（时间窗/分母/基准/维度/版本/延迟/负责人）
- [ ] 每个指标有至少一个维度拆分
- [ ] 口径与指标字典一致；口径变更处已标断点

**可视化**
- [ ] 每个指标都按选型表核对了图型
- [ ] 柱状图纵轴从 0 起；折线图断轴已标注
- [ ] 类目图已按值排序；时间轴等距
- [ ] 图例靠近数据或线尾直接标注
- [ ] 无 3D、无彩虹色、分类色数 ≤7

**信息呈现**
- [ ] 顶部显示数据更新时间与延迟口径
- [ ] 同环比带箭头或文字，不只靠颜色
- [ ] 涨跌色与状态色可区分，全看板一致

**可用性**
- [ ] 空数据、极小值、大数值、断更时的降级显示已定义
- [ ] 2-3 名真实用户走查，能说出看板能回答什么问题

## 八、指标卡信息结构（模板）

```
┌─────────────────────────────────┐
│ 支付成功率                ⓘ      │  ← 指标名 + 口径说明入口（链接指标字典）
│                                 │
│  62.3%                          │  ← 主数值，字号最大
│  ↑ 1.8pp  同比 vs 2025Q1        │  ← 同比 + 箭头 + 基准期（不可省略任一项）
│  ━━━━━━━━━━░░░░  目标 65%        │  ← 进度条/目标对比（有目标时才画）
│  数据截至 2026-10-10 08:00 T+1   │  ← 更新时间与延迟
└─────────────────────────────────┘
```

**缺任一行都不合格**：没有「同比」的指标卡无法判断好坏，没有「更新时间」的指标卡会误导使用者。
