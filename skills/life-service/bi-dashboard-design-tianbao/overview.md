# BI看板设计与指标口径核查 · 能力概览

## 你会得到什么

**一层硬配额，看板不再无限膨胀。** 指标按「结果 / 过程 / 健康度」三层归类，每层有明确数量上限：结果 4–6、过程 6–8、健康度 3–5，**单屏总数不超过 12**。理由很实在：人眼能并行比较的数值块约 5–7 个，超过 9 个读者就退回逐个扫描，看板从「一眼看全局」变成「一张需要解释的图」。归不进去的指标，说明它本来就不属于这块看板。

**数据形态到图型的硬对照表。** 时间序列用折线不用柱状；类目超过 3 个别用饼图；单值对目标用数字卡不用仪表盘；地理分布必须配排序表。每条都写清「为什么」和「关键设置」，不只给结论。

**两条容易搞反的轴规则。** 柱状图纵轴**必须**从 0 起（截断会歪曲比例），折线图纵轴**可以不**从 0 起但**必须标断轴**（转化率 3.0%→3.1% 的真实波动会被压平）。这两条相反，弄混就是误导性可视化。

**维度完备性七要素。** 时间窗、分母口径、对比基准、维度拆分、口径版本、数据延迟、负责人——**任一项缺失，该指标不得上板**。维度不是可选项：只有一个总计的指标告诉你「今天降了」，但不告诉你「哪降了」，没有诊断价值。

**配色语义固定表。** 涨跌用一组色、健康度状态用另一组色，两组必须在视觉上可区分（否则红色的数字既可能表示「跌」也可能是「异常」）。无序类目用单色深浅渐变，禁止彩虹色（色相间距不均匀，读不出顺序）。

## 典型用法

1. 评审一块做了一屏数字的看板：先跑脚本看超配额与缺维度，再按三层重排。
2. 选图表类型拿不准：查选型对照表，每种都带禁用项。
3. 「这个数跟财务报表对不上」：查维度完备性与口径一致性条目，本质是缺指标字典。
4. 团队规范：把配额表、选型表、评审清单贴到 wiki，新看板按清单过一遍。

## 边界

- 给出的是通用设计规范与量化阈值，各行业的正常水位不同，阈值需结合业务校准
- 三个及以上变量的复杂归因不适合放看板，应下沉到分析工具或专项报告
- 大屏展示（给路过的人看）与内部看板不同：大屏通常只放 3–5 个结果指标，必须零交互
- 权限敏感数据的展示须遵守本单位数据合规要求，以现行规定和主管部门要求为准
- 指标口径的最终裁定权在指标字典与业务方
