# 灵活就业人员参保与退休办理规则库

> 本规则库为办理实践整理。**各地口径差异很大**，所有结论以参保地现行规定和社保经办机构核定为准。不得据此对外承诺待遇金额。

---

## 一、参保类型选择

| 类型 | 可参加险种 | 关键差异 |
|---|---|---|
| 以灵活就业身份参加**企业职工基本养老保险** | 职工养老保险（＋职工基本医疗保险，按参保地规定） | 缴费由个人全额承担；待遇按企业职工养老保险办法计发 |
| 参加**城乡居民基本养老保险** | 居民养老保险（按年缴费，分档） | 缴费档次低；待遇计发办法不同；与职工养老需按衔接政策处理 |
| 参加**城乡居民基本医疗保险** | 居民医保（按年缴费） | 与职工医保按年度衔接，不重复享受待遇 |

**职工养老与居民养老不得重复享受待遇**，重复参保期间不重复计算年限。选择前先算清长期缴费能力与预期年限。

---

## 二、缴费口径

```
月缴费基数 = 参保地公布的缴费基数档次
            （一般为当地全口径城镇单位就业人员平均工资的 60%–300%）
月缴费额   = 月缴费基数 × 养老费率 + 月缴费基数 × 医保费率（如参加职工医保）
年缴费额   = 月缴费额 × 12
```

| 参数 | 口径 |
|---|---|
| 缴费基数上下限 | 按参保地每年公布的口径，档次自选，**以公布值为准** |
| 养老费率 | 各地不同；**一部分进个人账户，一部分进统筹**，比例以参保地公布为准 |
| 医保费率 | 各地不同，含大病/互助等附加的按当地口径 |
| 失业保险 | 部分地区灵活就业人员可参加，**按当地规定** |
| 工伤、生育 | 灵活就业参保一般不适用，**按参保地口径核实** |
| 缴费渠道 | 一般通过税务部门提供的渠道按年/按月缴纳，**以当地公布为准** |

**缴费时间**：缴费截止与所属年度以参保地公布为准，逾期一般不能补缴当年。

---

## 三、年限口径

```
养老累计缴费年限 = 单位期间月数 + 灵活就业期间月数 + 已认定的视同缴费月数
养老按月领取条件 = 达到法定退休年龄 且 累计缴费满 15 年（180 个月）
医保累计年限     = 按参保地规定（常见男 25 年/女 20 年，以参保地口径为准）
```

| 情形 | 说明 |
|---|---|
| 单位期间与灵活就业期间 | 年限累计计算，但**平均缴费工资指数按各年基数与当年平均工资分段计算** |
| 断缴期间 | 不计入缴费年限；医保待遇按参保地规定处理 |
| 重复参保期间 | **不重复计算年限**，需清理 |
| 跨省参保 | 先办转移接续，归集到待遇领取地后合并计算 |
| 视同缴费年限 | 需档案认定，认定前按 0 计入 |

---

## 四、养老金计算口径（企业职工基本养老保险）

```
基本养老金 = 基础养老金 + 个人账户养老金（有视同缴费年限的还有过渡性养老金）

基础养老金 = （退休时当地上年度在岗职工月平均工资
             + 本人指数化月平均缴费工资）÷ 2 × 缴费年限 × 1%

本人指数化月平均缴费工资 = 退休时当地上年度在岗职工月平均工资 × 本人平均缴费工资指数
本人平均缴费工资指数     = 各年缴费基数 ÷ 当年当地平均工资 的平均值

个人账户养老金 = 个人账户储存额 ÷ 计发月数
```

### 4.1 计发月数（常见口径，以参保地公布为准）

| 退休年龄 | 计发月数 |
|---|---|
| 50 岁 | 195 |
| 55 岁 | 170 |
| 60 岁 | 139 |

### 4.2 影响因素（每一项都会改变结果）

1. **缴费年限**：越长，基础养老金越高
2. **缴费基数档次**：影响本人平均缴费工资指数与个人账户积累
3. **退休时当地上年度在岗职工月平均工资**：随社会平均工资变动
4. **个人账户记账利率**：由相关部门公布，逐年变动
5. **退休年龄**：影响计发月数与缴费年限
6. **是否有视同缴费年限**：涉及过渡性养老金
7. **待遇领取地**：按政策确定，跨省参保者尤其重要

**这是口径说明，不是待遇承诺。** 实际待遇以社保经办机构核定为准。

## 五、参保登记与退休办理路径

```
参保登记
① 确认参保类型与参保地
② 准备身份证件、居住/就业相关材料（按参保地要求）
③ 办理参保登记（线上或窗口）
④ 选定缴费基数档次
⑤ 按税务部门渠道按时缴费
⑥ 保存缴费凭证，定期核对到账月数

退休办理
① 提前 1–2 年核对：累计年限、视同年限、档案、待遇领取地
② 年限不足的，确定延长缴费或按政策补缴（以参保地为准）
③ 达到法定退休年龄前按参保地要求提出申请
④ 提交档案与身份材料，配合待遇核定
⑤ 领取核定结果，核对缴费年限与账户储存额
⑥ 结果不符的，按告知渠道申请复核
```

## 六、医保年限处理

| 情形 | 处理（以参保地为准） |
|---|---|
| 退休时医保累计已达参保地规定年限 | 按参保地规则享受退休人员医保待遇 |
| 退休时医保累计不足 | 按规定一次性补缴或继续缴费至规定年限 |
| 断缴期间 | 按参保地规定处理待遇享受与等待期 |
| 职工医保与居民医保衔接 | 按年度衔接政策处理，**不重复享受** |

---

## 七、常见拒办与卡点

1. 参保地与户籍地、居住地要求不符（按参保地规定）
2. 未办理参保登记就想直接缴费
3. 缴费基数档次选择超出公布范围
4. 已有单位参保关系未终止，重复登记
5. 跨省参保未办转移接续，年限无法合并
6. 档案缺失导致视同缴费年限无法认定
7. 缴费未到账即认为年限已更新

## 八、否定词防误伤清单（输出前逐条比对）

| 见到这些情况 | 必须这样判 | 严禁这样写 |
|---|---|---|
| 累计 14 年 11 个月 | 判为**未缴满** | 「已缴满 15 年」 |
| 视同缴费年限待认定 | 按 **0** 计入 | 「已计入视同年限」 |
| 断缴期间 | 判为**未缴费** | 「已缴费」「免缴」 |
| 重复参保期间 | 判为**不重复计算年限** | 「年限可叠加」 |
| 已申报未到账 | 判为**未上账** | 「缴费成功」 |
| 养老金估算值 | 必须标注**估算** | 「核定待遇」「保证领取 X 元」 |
| 暂不征缴 | 不等同于**免缴义务** | 「不用交了」 |
| 转移接续在途 | 判为**未归集** | 「年限已合并」 |
| 待办理/准备办理参保 | 判为**未参保** | 「已参保」 |

## 九、免责

本规则库为办理实践整理，**不构成法律、社保代理或行政认定意见**。缴费基数档次、费率、缴费渠道、累计年限、法定退休年龄、计发月数与待遇核定，**均以参保地现行规定和社保经办机构核定为准**。养老金为估算口径，**不构成任何待遇承诺**。不得用于虚构劳动关系挂靠代缴或重复参保套取待遇。
