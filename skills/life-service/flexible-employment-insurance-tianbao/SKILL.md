# 灵活就业人员参保与退休办理核查

灵活就业参保最容易算错的是两件事：**按哪个基数档交、到退休时年限够不够**。基数档决定现在每年掏多少，年限决定将来能不能领、领多久。

这个技能做五件事：**定参保类型 → 选基数档次 → 算年缴费额 → 核年限缺口 → 估养老金口径**。

---

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 说明可参加的险种与参保登记路径 | 代替本人办理登记、申报或代缴 |
| 按给定基数档与费率测算年缴费额 | 承诺具体养老金金额、承诺「交满就能领多少」 |
| 给出养老金的**计算口径**与影响因素 | 编造利率、工资增长、计发月数等参数 |
| 计算累计缴费年限与医保年限缺口 | 把「估算」当作「核定待遇」对外承诺 |
| 提示补缴、续缴、转移接续的办理路径 | 提供虚构劳动关系挂靠代缴的方案 |

涉及以下情形，应停下来交由社保经办机构、税务部门或专业社保人员处理：**跨省转移接续、视同缴费年限认定、特殊工种提前退休、病退或退职、待遇核定争议、已接近退休年限临界点**。

**绝对不做**：不虚构劳动关系挂靠代缴，不伪造用工材料，不重复参保以套取待遇。**重复参保不重复计算年限，也不重复享受待遇。**

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「自己交社保怎么交、交几档」 | 用，按当地公布的基数档次核 |
| 「按 60% 交一年多少钱」 | 用，按基数 × 费率测算 |
| 「自己交社保多少岁能退休」 | 用，按法定退休年龄与参保类型核 |
| 「养老金大概能领多少」 | 用，给计算口径与影响因素，**明确是估算** |
| 「医保年限不够怎么办」 | 用，按参保地累计年限口径核 |
| 「以前单位交过，现在自己交怎么算」 | 用，年限累计但缴费指数需分段 |
| 「能不能把前几年没交的补上」 | 用，先确认当地是否允许追补（多数地区不允许） |
| 「挂靠公司交是不是更划算」 | 不用，拒绝提供虚构劳动关系方案 |

## 三、完整工作流

```
第 1 步  确认参保类型：以灵活就业身份参加企业职工养老保险（＋职工医保），
         或参加城乡居民养老/医保 —— 两类规则不同，且不得重复享受待遇
第 2 步  读规则文件 rules/flexible-enrolment-rules.md（险种、基数档、费率、年限、退休条件）
第 3 步  取当地公布口径：缴费基数上下限、档次、各险种费率、医保累计年限
第 4 步  选档次并测算年缴费额：基数 × 费率 × 12
第 5 步  调取已有缴费记录：单位期间的月数 + 灵活就业期间的月数 + 已认定的视同年限
第 6 步  算年限缺口：养老 15 年；医保按参保地规定
第 7 步  跑脚本测算：scripts/flexible_insurance_calc.py --file case.json
第 8 步  算到退休的缴费计划：还差几年、每年交多少、合计多少
第 9 步  办参保与缴费：按税务部门的缴费渠道按时缴纳，避免断缴
第 10 步 退休前复核：提前 1–2 年核对年限、档案、待遇领取地
```

## 四、核心口径

### 4.1 缴费额口径

```
月缴费基数 = 参保地公布的缴费基数档次（一般为当地全口径城镇单位就业人员平均工资的 60%–300%）
月缴费额   = 月缴费基数 × 养老费率 + 月缴费基数 × 医保费率（如参加职工医保）
年缴费额   = 月缴费额 × 12
```

**要点**：养老保险费率的**一部分进入个人账户，一部分进入统筹**，各地比例不同，**以参保地公布口径为准**。灵活就业参保一般不参加工伤、生育保险（各地口径不同，需核实）；失业保险按当地规定。

### 4.2 年限口径

```
养老累计缴费年限 = 单位期间月数 + 灵活就业期间月数 + 已认定的视同缴费月数
养老按月领取条件 = 达到法定退休年龄 且 累计缴费满 15 年
医保累计年限     = 按参保地规定（常见男 25 年/女 20 年，以参保地口径为准）
```

**累计 ≠ 连续，但断缴影响医保待遇享受**：养老看累计，医保待遇享受常与连续缴费挂钩，**断缴期间的医保待遇按参保地规定处理，不要默认「补上就没事」**。

### 4.3 养老金计算口径（企业职工基本养老保险）

```
基本养老金 = 基础养老金 + 个人账户养老金

基础养老金 = （退休时当地上年度在岗职工月平均工资 + 本人指数化月平均缴费工资）
             ÷ 2 × 缴费年限 × 1%

本人指数化月平均缴费工资 = 退休时当地上年度在岗职工月平均工资 × 本人平均缴费工资指数
本人平均缴费工资指数     = 各年缴费基数 ÷ 当年当地平均工资 的平均值

个人账户养老金 = 个人账户储存额 ÷ 计发月数
计发月数（常见）：60 岁退休 139；55 岁退休 170；50 岁退休 195
```

**这只是一个口径说明，不是待遇承诺。** 实际待遇受缴费基数、缴费年限、退休时当地平均工资、个人账户记账利率、过渡性养老金等多重因素影响，**以社保经办机构核定为准**。

### 4.4 判定表

| 项目 | 判定 | 动作 |
|---|---|---|
| 累计 ≥ 15 年 且 达法定退休年龄 | 可申请按月领取基本养老金 | 走退休办理与待遇核定 |
| 累计 < 15 年 | 未缴满，不能按月领取 | 延长缴费或按政策一次性补缴，以参保地为准 |
| 医保累计 ≥ 参保地规定年限 | 退休后医保待遇按参保地规则 | 核对是否还需补足连续缴费要求 |
| 医保累计 < 参保地规定年限 | 年限不足 | 补缴或继续缴费，以参保地为准 |

### 4.5 防误伤（否定词清单）

- 「累计 14 年 11 个月」→ 判为**未缴满**，不得写成「已缴满 15 年」
- 「视同缴费年限待认定」→ 判为**未计入**，测算按 0 计
- 「断缴期间」→ 判为**未缴费**，不等同于免缴也不等同于已补缴
- 「重复参保期间」→ 判为**不重复计算年限**，也不重复享受待遇
- 「已申报未到账」→ 判为**未上账**，不得当成缴费成功
- 「养老金估算值」→ 必须标注**估算**，不得写成「核定待遇」「保证领取」
- 「暂不征缴」→ 不等同于免缴义务

## 五、核心规则与要件库

出结论或给测算前，**必须先读**：

- `rules/flexible-enrolment-rules.md`：险种与参保条件、缴费基数档次与费率、缴费渠道与时间、年限与退休条件、养老金计算口径与影响因素、转移接续、常见拒办原因。

不得用其他城市的基数与费率套本地，不得把「估算」当作「核定」。

## 六、脚本用法

```bash
python scripts/flexible_insurance_calc.py --file case.json --out 参保测算.md
python scripts/flexible_insurance_calc.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：性别、当前年龄、退休年龄、已缴年限、缴费档次、当地月平均工资、费率、是否参加医保、退休时平均工资假设 |
| `--text` | 直接给 JSON 字符串 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检 |

输入 JSON 示例：

```json
{
  "gender": "male",
  "current_age": 38,
  "retire_age": 60,
  "contributed_years": 6,
  "base_ratio": 0.6,
  "local_avg_wage": 8000,
  "pension_rate": 0.20,
  "account_rate": 0.08,
  "medical_enabled": true,
  "medical_rate": 0.09,
  "retire_avg_wage": 12000,
  "account_interest": 0.02
}
```

脚本输出：月缴费基数、月/年缴费额、个人账户年入账、到退休还需缴费年限、养老与医保年限缺口、退休时个人账户储存额估算、基础养老金与个人账户养老金估算、合计月养老金估算，以及「未缴满不得判为已缴满」和「本估算不构成待遇承诺」的标注。

> 脚本按你填的参数做静态测算，**未含过渡性养老金、政策调整、工资实际增长路径、个人账户记账利率变动**；基数、费率、计发月数与待遇核定以参保地现行口径和社保经办机构核定为准。

## 七、人工确认清单（这步不能省）

- [ ] 参保类型已确认（灵活就业职工养老 / 城乡居民养老），不是凭印象
- [ ] 缴费基数档次取**参保地本年度公布**的档次，不是网上抄的
- [ ] 各险种费率按**参保地现行口径**，养老与医保分开算
- [ ] 已有缴费月数以经办系统记录为准，视同年限需已认定
- [ ] 养老与医保缺口分别列出，没有合并
- [ ] 缴费渠道与截止时间已核实，避免断缴
- [ ] 退休前 1–2 年已复核年限、档案、待遇领取地
- [ ] 跨省参保的，转移接续已办结再算累计
- [ ] 已知悉：养老金为估算，实际以经办机构核定为准

## 八、最常见的坑

1. **用外地的基数和费率算本地。** 缴费基数上下限、档次、费率、医保累计年限，各地差异很大。套用外地数据得出的年缴费额可能相差数千元。
2. **把「累计满 15 年」当成「可以停了」。** 15 年只是按月领取的最低门槛，养老金与缴费年限、缴费基数正相关，交 15 年拿到的金额通常明显低于长期缴费。
3. **断缴不看医保影响。** 养老看累计，但医保待遇享受常与连续缴费挂钩，断缴期间的待遇按参保地规定处理。**不要默认「补上就没事」。**
4. **把估算的养老金当成承诺。** 脚本算出的金额依赖你填的工资增长与记息假设，**不是待遇核定**。对外表述必须写「估算」。
5. **同时参加职工养老和居民养老。** 重复参保不重复计算年限，也不重复享受待遇，还会带来退费与衔接麻烦。
6. **以为灵活就业能补缴以前断的年份。** 多数地区**不允许**灵活就业人员事后追补自行中断的期间，只能往后续缴。先问经办机构再决定。
7. **听信挂靠公司缴费。** 虚构劳动关系参保属于违规，后果包括缴费被清退、影响个人信用。**没有捷径。**
8. **退休前才核年限。** 到退休当月才发现差几年，往往只能延长缴费，晚领好几年。提前 1–2 年核对最省事。
9. **忽略待遇领取地问题。** 多地参保的，待遇领取地按政策确定，不是想在哪领就在哪领，跨省参保的尤其要提前核实。

## 九、边界与免责

- 本技能用于参保前核查与材料整理，**不构成法律、社保代理或行政认定意见**，不替代本人办理与经办机构核定
- 缴费基数档次、费率、缴费渠道、累计年限、法定退休年龄、计发月数与待遇核定，**均以参保地现行规定和社保经办机构核定为准**
- 养老金为**估算口径**，未含过渡性养老金、政策调整、工资实际增长路径与记账利率变动，**不构成任何待遇承诺**
- **不承诺具体养老金金额、不承诺「交满就能领多少」**
- 不提供虚构劳动关系、挂靠代缴、重复参保套取待遇的任何方案
