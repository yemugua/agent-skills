# 化妆品备案与标签合规自查

## 你会得到什么

把一个化妆品产品或一份标签文案，拆成三条线分别核查，最后合并成一份带优先级的整改清单：

1. **身份线**：判定它应当走"特殊化妆品注册"还是"普通化妆品备案"，并给出在国家药监局官方平台核验编号的具体核对点（编号、产品名、包装图三项一致，而不是只查编号存在不存在）。
2. **标签线**：按法定标注项逐项打勾——产品名称、注册/备案编号、注册人备案人与生产企业、执行标准、全成分（含 ≤0.1% 微量成分的引导语标注）、净含量、使用期限、使用方法与安全警示，以及儿童化妆品、进口产品、小规格包装的专门要求。
3. **宣称与成分线**：扫描文案里的医疗作用词、绝对化词、误导性表述、无依据的功效宣称，比对高风险禁用组分名单（糖皮质激素、性激素、抗生素、抗真菌药、氢醌、汞化合物等），并按一/二/三/四级划分违规后果。

同时给出消费者视角的完整处置路径：协商留痕 → 平台投诉 → 12315/12345 举报 → 药监部门 → 消协调解 → 诉讼，以及每一环要固定的证据（页面录屏、订单支付凭证、开箱视频、备案查询截图、检验报告、就医记录）。

## 典型用法

- 上架前自查："这个产品的标签还缺什么，能不能上架。"
- 遭平台下架：把下架原因对应到缺失项，判断属于改文案还是改包装。
- 消费者维权："商家宣称能治湿疹，我能不能退一赔三"——先区分钟点：这是**宣称违规**，是否构成欺诈要看是否足以诱使错误意思表示，本技能会明确给出"构成"与"不构成"的两种判定口径，不会一律主张三倍。
- 供应链审核：对代工厂提供的标签稿件做批量预扫。

## 脚本

`scripts/cosmetic_label_check.py` 支持 `--file` 输入标签/成分表文本，一次扫出「标注项缺失」「违禁宣称命中」「高风险成分命中」，支持 `--json` 输出，带 `--selftest`。脚本对否定语境（"不含激素""非药品"）做了降权处理，但命中项仍需人工复核。

## 边界

不出具检验报告，不作行政认定，不承诺处罚或胜诉结果。备案状态以官方平台实时数据为准，成分合规性以资质机构检验报告和现行《化妆品安全技术规范》目录为准。涉及人身损害、行政处罚听证、诉讼请求的，请转交律师等专业人士。
