# 规则表二：违禁宣称词库、高风险成分表、退一赔三判定与取证清单

> 依据《化妆品监督管理条例》《化妆品标签管理办法》《化妆品功效宣称评价规范》及《化妆品安全技术规范》现行目录整理。**具体条款号与目录以现行规定和官方发布为准。**

## 第 1 节 违禁宣称词库（扫描用）

### 1.1 医疗作用类（一级风险）

明示或暗示具有医疗作用，属于化妆品宣称中最严重的违规类型。

**命中即高危**：抗菌、消炎、杀菌、灭菌、抑菌、抗感染、抗病毒、药用、药效、处方、医师、医生、医院、治疗、治愈、根治、疗效、疗程、缓解疼痛、止痒药、皮炎、湿疹、痤疮治疗、激素、抗生素、麻醉、消肿、活血、解毒、排毒、生发、壮阳、病理、药理、临床验证。

**判定口径**：不是看字面是否出现"药"字，是看是否**明示或暗示医疗作用**。例如"缓解敏感不适"与"治疗过敏性皮炎"，前者可能合规、后者明显违规，需结合语境人工判断。

**否定语境降权**：出现在"不含激素""无抗生素""非药品""不能替代药品""化妆品不具有医疗作用"等否定或提示性表述中时，不构成违规，应判为**误命中**。这是本类扫描最常见的误伤来源。

### 1.2 绝对化与夸大宣传类（二级风险）

特效、奇效、神效、全效、超强、最强、极致、第一、国家级、顶级、极品、完美、万能、100% 有效、彻底、永久、立竿见影、瞬间、永不反弹、纯天然、纯植物、无添加、零添加、食品级、可食用、医用级。

**说明**："纯天然""无添加""食品级""可食用"属于典型的违法宣称方向（"食品级化妆品"本身即为不存在的合规概念）。绝对化用语同时可能违反广告相关规定。

### 1.3 误导与无依据宣称类（二级风险）

- 功效宣称**未公开功效宣称评价依据摘要**的（除依法可豁免的情形外）。
- 宣称"医学证明""临床证明""实验室认证""权威机构推荐"但无法提供出处。
- 利用国家机关、国家机关工作人员、医疗机构、医务人员、消费者组织等名义或形象作证明。
- 虚构或冒用注册证/备案编号、检验报告、认证标志。
- 宣称"已备案"但实际未备案，或宣称的功效与备案信息不符。

### 1.4 儿童化妆品超范围功效（一级风险）

祛斑美白、祛痘、抗皱、去屑、脱毛、除臭、染发、烫发 —— 出现在儿童化妆品宣称中即为高危。

## 第 2 节 高风险禁用组分名单（提示级，必须复核官方目录）

> 以下为高频风险名单，**不替代《化妆品安全技术规范》现行禁用组分目录**。是否违规以具备资质机构的检验报告为准。

| 类别 | 常见风险物质 |
|---|---|
| 糖皮质激素 | 氢化可的松、地塞米松、氯倍他索丙酸酯、曲安奈德、倍他米松、泼尼松、氟轻松 |
| 性激素 | 雌二醇、雌三醇、睾酮、黄体酮、己烯雌酚 |
| 抗生素类 | 氯霉素、甲硝唑、四环素、红霉素、林可霉素、磺胺类、诺氟沙星、氧氟沙星 |
| 抗真菌药 | 酮康唑、咪康唑、联苯苄唑、特比萘芬、克霉唑 |
| 美白祛斑违禁物 | 氢醌（对苯二酚）、汞及其化合物、苯酚、间苯二酚（超限量时） |
| 维 A 酸类 | 维 A 酸、异维 A 酸、他扎罗汀、阿达帕林 |
| 溶剂与杂质 | 二甘醇、甲醇、1,4-二噁烷（按杂质限量管控） |

**限用组分**：防腐剂、防晒剂、着色剂、染发剂、祛斑美白剂等须在**准用清单内且不超过最大使用浓度/使用条件**。例如染发剂中的对苯二胺类须符合准用清单与限值。超限量使用需检验数据支撑，不能凭标签推断。

## 第 3 节 退一赔三：适用条件与否定情形

### 3.1 适用条件（四个要件同时满足才成立）

1. 相对方是**经营者**（商家、平台内经营者），非个人二手交易；
2. 购买行为属于**生活消费**（不是用于经营/转售）；
3. 经营者存在**欺诈行为**：故意告知虚假情况，或故意隐瞒真实情况，诱使消费者作出错误意思表示；
4. 消费者因该欺诈行为作出了购买决定并受到损失。

满足时：可要求退货退款，并**增加赔偿购买商品价款的三倍**；增加赔偿金额不足五百元的，按**五百元**计算（以现行规定为准）。

### 3.2 化妆品场景中"通常构成欺诈"的情形

- 冒用、编造注册证/备案编号，或宣称"已备案"而实际未备案；
- 以普通化妆品冒充特殊化妆品功效（如宣称祛斑美白但产品并未注册）；
- 虚构、伪造检验报告、认证标志、专利号；
- 明知产品存在质量/安全问题仍销售并隐瞒；
- 以非化妆品（消毒产品、医疗器械）冒充化妆品，或反向冒充。

### 3.3 否定情形：这些**不能当然主张退一赔三**（防误伤重点）

| 情形 | 通常结论 | 说明 |
|---|---|---|
| 标签仅存在轻微瑕疵，不影响使用、不误导购买 | 一般**不构成欺诈** | 多按退货、更换、修理或行政责令改正处理 |
| 夸大宣传但未达"诱使错误意思表示"程度 | 可能是**广告违法**，不当然构成欺诈 | 走行政处罚路径，不等于三倍赔偿 |
| 消费者明知瑕疵仍购买（"职业打假"式知假买假的认定存在争议） | 结论不确定 | 各地裁判口径存在差异 |
| 产品本身合格，仅宣称用语不当 | 一般**不构成**对商品本身的欺诈 | 需区分"商品欺诈"与"宣传违法" |
| 用于转售经营的采购 | 不适用 | 非生活消费 |
| 造成人身损害但商家无欺诈 | 走**侵权赔偿**，不是退一赔三 | 依人身损害赔偿项目核算 |

**关键区分**：
- **欺诈 → 退一赔三**（以价款为基数）
- **人身损害 → 医疗费、护理费、误工费等实际损失赔偿**；造成死亡或健康严重损害的，可依法主张惩罚性赔偿（以现行规定为准）
- **标签瑕疵 → 退货/改正**
- **夸大宣传 → 行政处罚**

四条路径不能混用，混用会导致主张被驳回。

## 第 4 节 取证清单（按顺序固化，缺一环链条就断）

| # | 证据 | 固化要点 |
|---|---|---|
| 1 | 商品页面宣称 | **录屏**（从浏览器地址栏开始，滑动全页，显示 URL 与日期），截图需带完整页面与时间戳 |
| 2 | 订单与支付凭证 | 订单号、商品名、金额、店铺名、支付流水 |
| 3 | 收货与开箱 | **连续不剪辑**开箱视频，拍到快递面单、外包装、内包装、标签全貌 |
| 4 | 实物标签 | 正反面、成分表、限期使用日期、备案编号，微距清晰照 |
| 5 | 备案核验结果 | 官方平台查询页截图，含查询日期；查不到的要截图"无结果"页面 |
| 6 | 检验报告 | 委托具备 CMA/CNAS 资质的机构，明确检验项目（如糖皮质激素、重金属、抗生素） |
| 7 | 沟通记录 | 与客服/商家的完整聊天记录，不要只截片段 |
| 8 | 损害后果 | 就诊病历、诊断证明、医疗费票据、损容照片（前后对比）、误工证明 |
| 9 | 使用过程 | 使用日期、频次、部位记录，用于证明损害与使用之间的关联 |

## 第 5 节 投诉举报路径顺序（不要跳步）

| 顺序 | 路径 | 适用 |
|---|---|---|
| 1 | 与商家/平台协商 | 在订单内沟通，保存工单编号与聊天记录 |
| 2 | 平台投诉与电商争议处理 | 平台内投诉入口、信息披露申请 |
| 3 | **12315**（市场监督管理部门）或 **12345** | 欺诈、虚假宣传、消费纠纷 |
| 4 | 药品监督管理部门 | 备案/注册、质量安全、禁用组分 |
| 5 | 消费者协会调解 | 消费纠纷调解 |
| 6 | 人民法院诉讼 | 小额诉讼程序或普通程序 |

**注意**：先走协商与平台，可以固定"商家知情且拒绝整改"的证据，对后续主张欺诈有利。直接跳到监管部门，有时会因双方未先行沟通而更难认定故意。

## 第 6 节 常见误判对照表（否定词防误伤）

| 文本 | 不要判成 | 正确判法 |
|---|---|---|
| 未查询到公开备案信息 | 未备案 | 仅陈述"未查询到"，需进一步核实 |
| 不含抗生素、无激素 | 命中禁用成分违规 | 否定语境，属合规表述，判为误命中 |
| 本品不能替代药品 | 宣称医疗作用 | 合规提示语 |
| 敏感肌可用 | 治疗皮炎 | 需结合全文，多数为合规范畴宣称 |
| 绝对化词出现在转载的用户评价中 | 商家自身违规 | 需区分是商家自述还是用户评价转载 |
| 成分排序不规范 | 未备案 | 属标签瑕疵（四级），不是身份问题 |
| 页面已整改但包装未改 | 已整改完成 | **未整改**；整改需页面与实物同步 |
| 已知瑕疵仍购买 | 当然支持三倍赔偿 | 结论不确定，需个案判断 |
