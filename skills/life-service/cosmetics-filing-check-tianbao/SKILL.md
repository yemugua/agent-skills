# 化妆品备案与标签合规自查

把一份化妆品（或它的标签文案、成分表、详情页）拆成三类问题分别核：**有没有合法身份**（注册/备案）、**标签写没写全**、**宣称与成分有没有踩线**。三类问题的处理部门、整改成本和维权结果都不一样，不要混着判。

## 一、硬边界（能做 / 不能做）

| 能做 | 不能做 |
|---|---|
| 判定产品应走"注册"还是"备案"路径 | 代替药品监督管理部门作行政认定 |
| 逐项核对标签应当标注的法定项目是否缺失 | 认定某成分"一定超标/一定违法"（需检验报告） |
| 扫描宣称文案中的医疗作用词、绝对化词、违禁用语 | 出具检验报告、微生物/重金属检测结论 |
| 提示高风险禁用/限用组分清单（需官方目录复核） | 给出具体条款编号并宣称"必然适用" |
| 核验备案编号在国家药监局平台的查询方法 | 断言平台数据的实时状态（以查询时页面为准） |
| 输出整改优先级、投诉举报路径与证据清单 | 承诺罚款金额、处罚结果或胜诉结果 |

**必须转交专业人士的情形：**
- 涉及人身损害（过敏、灼伤、激素依赖性皮炎、汞中毒等）——先就医并保留病历，再走鉴定/诉讼。
- 需要出具具有证明力的检验报告——必须委托具备资质的检验机构。
- 企业面临立案调查、行政处罚听证的——交专业合规顾问或律师。
- 产品拟实际上市销售、跨境电商备案的——务必在上市前完成注册/备案，不要"边卖边补"。

## 二、什么时候用

| 用户说法 | 用不用 | 说明 |
|---|---|---|
| 这个化妆品在国家药监局查不到备案 | 用 | 先按"未备案/信息不符"路径固定证据，再决定投诉还是退货 |
| 帮我看看标签还缺什么 | 用 | 走标签要件逐项核对（rules/01） |
| 这句宣传语能不能写 | 用 | 走违禁宣称扫描（rules/02） |
| 这个成分是不是违禁添加 | 用（提示级） | 给出高风险名单比对结论，明确"以官方目录和检验报告为准" |
| 我用了烂脸了要赔多少 | 部分用 | 赔偿核算可做框架，但必须结合病历、鉴定意见，建议律师介入 |
| 帮我把备案做下来 | 不用 | 备案需在监管平台由备案人提交，本技能只做前置自查 |
| 检测一下这个产品含不含激素 | 不用 | 需要实验室检验，本技能无检测能力 |

## 三、完整工作流

### 步骤 1：确定产品身份路径
先分清是**特殊化妆品（注册制）**还是**普通化妆品（备案制）**，路径错了后面全错。判定见 `rules/01-备案与标签要件清单.md` 第 1 节。

### 步骤 2：核验备案/注册编号
- 在国家药品监督管理局官方网站的化妆品查询入口，输入产品名称或注册/备案编号核对：产品名称、注册人/备案人、生产企业、包装平面图是否与实物一致。
- **必须核对"三项一致"**：编号存在、编号对应的产品名与实物名一致、备案包装图与实物包装一致。只核"编号存在"是不够的，套用他人备案号是常见违规形态。
- 未见查询结果的，记为**"未查询到公开备案信息"**，不要直接写"未备案"——可能是数据同步延迟、名称变更、进口产品正在办理。结论措辞必须留余地。

### 步骤 3：逐项核对标签标注要件
按 `rules/01-备案与标签要件清单.md` 第 2 节的要件表逐项打勾，缺一项记一项。脚本可自动扫一遍（见第五节）。

### 步骤 4：扫描宣称与成分风险
按 `rules/02-违禁宣称与高风险成分表.md` 扫描：医疗作用词、绝对化词、虚假/误导词、无证功效宣称、高风险禁用组分。

### 步骤 5：判定后果等级并排序整改
| 等级 | 判定 | 处置 |
|---|---|---|
| 一级（最严重） | 未注册/未备案即上市，或检出禁用组分 | 立即停止销售，主动召回，准备应对调查 |
| 二级 | 标签缺法定标注项、备案信息与实物不符 | 停止上架，改版包装后重新核验 |
| 三级 | 宣称用语违规（绝对化、医疗暗示） | 改文案、下架页面、留存修改记录 |
| 四级 | 排版/顺序瑕疵（如成分排序不规范） | 列入下一批次改版 |

### 步骤 6：确定维权/投诉路径（消费者视角）
按顺序走，不要跳步（跳步会导致证据链断裂）：
1. 向商家/平台提出并留痕（订单内沟通、工单编号）；
2. 平台投诉与电商争议处理；
3. 12315（市场监督管理部门）或 12345 政务服务热线举报；
4. 药品监督管理部门（涉及备案、质量安全）；
5. 消费者协会调解；
6. 人民法院诉讼（小额诉讼程序）。

### 步骤 7：输出结论
必须包含：身份路径判定、编号核验结果（含查询时间与措辞留白）、缺失标注项清单、命中风险词清单、整改优先级、证据清单、下一步动作。

## 四、核心规则（生成任何材料前必读）

**先读这两个文件，不要凭印象写：**

- `rules/01-备案与标签要件清单.md` —— 注册/备案判定表、标签法定标注项表、全成分与微量成分标注规则、小规格简化标注、儿童化妆品专门要求、进口与境内责任人要求。
- `rules/02-违禁宣称与高风险成分表.md` —— 违禁宣称词库（医疗作用类/绝对化类/误导类）、高风险禁用组分名单、退一赔三的适用条件与"不构成欺诈"的否定情形、取证清单、投诉路径顺序。

规则表里的期限、比例、标注项均**以现行规定和当地主管部门要求为准**；本技能不编造条款号，凡涉及具体罚则与数额，一律提示"以现行规定为准"。

## 五、脚本用法

脚本：`scripts/cosmetic_label_check.py`（Python 3 标准库，无需第三方依赖）

功能：读取一份标签/成分表/详情页纯文本，自动扫描「法定标注项缺失」「违禁宣称词」「高风险禁用成分」三类问题，输出带等级的建议。

```bash
python scripts/cosmetic_label_check.py --file 产品标签文本.txt
python scripts/cosmetic_label_check.py --file 产品标签文本.txt --json
python scripts/cosmetic_label_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 待检文本路径（UTF-8），可为标签全文、成分表或详情页文案 |
| `--json` | 以 JSON 格式输出，便于二次处理 |
| `--out` | 结果写入指定文件（默认写 `scripts/_last_result.txt`） |
| `--selftest` | 运行自检，全过打印 `SELFTEST OK` |

脚本只是**提示器**：命中的词需要人工复核语境（例如"用于敏感肌"与"治疗皮炎"性质完全不同），未命中也不代表合规。

## 六、人工确认清单（这步不能省）

- [ ] 注册/备案编号已在国家药监局官方平台实际查询，且截图保留查询日期？
- [ ] 查询到的产品名称、包装图与实物**完全一致**（不是只查到编号）？
- [ ] 全成分表含量 >1% 部分按降序排列，≤0.1% 部分以"其他微量成分"引导语单独引出？
- [ ] 使用期限按"生产日期+保质期"或"生产批号+限期使用日期"两种方式之一完整标注？
- [ ] 儿童化妆品已标注儿童化妆品标志并标注警示语，且功效未超范围？
- [ ] 每宣称一项功效，都能对应到已公开的功效宣称评价摘要？
- [ ] 违禁宣称命中项中，是否只是语境误伤（如"抗生素"出现在"不含抗生素"的否定句中）？
- [ ] 结论措辞是否区分了"未查询到"与"未备案"？
- [ ] 涉及人身损害的，是否已建议就医并保留病历？

## 七、最常见的坑

1. **只查编号不看包装图**。套用他人备案编号、实物包装与备案图不一致，是最隐蔽也最常见的违规，只核"编号存在"必然漏掉。
2. **把"未查询到"写成"未备案"**。数据同步延迟、企业更名、进口在途都会导致查不到；写成确定性结论一旦出错，就是内容失实。
3. **否定句误伤**。扫描"不含激素""无抗生素""非药品"这类合规表述时，若直接按命中词判违规，会把合规文案判成违规——必须人工复核语境（脚本已内置否定语境降权，但仍需人工确认）。
4. **夸大宣传 ≠ 当然退一赔三**。"纯天然""第一"这类绝对化用语，多数情形是广告违法与行政处罚问题，是否构成欺诈还需看是否足以诱使错误意思表示，不能一律主张三倍赔偿。
5. **小样/赠品/分装被漏管**。小规格包装、赠品、分装产品同样受标签与备案约束，只是部分项目可依法简化；"赠品不用贴标签"是错误认知。
6. **"消字号""械字号"当化妆品卖**。消毒产品、医疗器械与化妆品是不同监管体系，把械字号产品按化妆品功效宣传，或把化妆品宣称医疗器械功效，都会踩线。
7. **功效宣称没留证据**。功效宣称需要评价依据并公布摘要，先上架后补评价属于典型违规。
8. **进口产品无中文标签、无境内责任人**。进口化妆品需有中文标签并标注境内责任人名称地址，"只有外文标签"不能直接上市。
9. **儿童化妆品超功效宣称**。清洁、保湿、爽身、防晒之外的功效（祛斑美白、祛痘、抗皱、去屑、脱毛等）不应在儿童化妆品上宣称。
10. **整改只改页面不改包装**。页面文案改了但实物包装未改，仍属标签违规。

## 八、边界与免责

本技能输出的是**自查提示与路径建议**，不是行政认定、检验结论或法律意见。备案与注册状态以国家药品监督管理部门官方平台的实时数据为准；成分是否违规以具备资质机构的检验报告和《化妆品安全技术规范》现行目录为准；是否构成欺诈、能否主张退一赔三，由市场监督管理部门或人民法院认定。涉及人身损害、行政处罚、诉讼请求的，请委托律师等专业人士处理。各地主管部门的执行口径存在差异，请以当地现行要求为准。
