# 质量成本分析（cost-of-quality）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据质量经济学与 ISO 9001，生成质量成本（COQ）分析清单：预防/鉴定/内部失败/外部失败四类比、数据采集口径、占营收比与改进。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 质量成本
- COQ
- 故障成本
- 预防成本
- 质量损失
- 质量核算

## 三、工作流
1. 划分四类质量成本（预防/鉴定/内损/外损）
2. 明确数据采集口径与财务映射
3. 计算质量成本占营收比
4. 分析结构并定位改进点
5. 制定降低失败成本计划

## 四、核心内容（检查清单与判定）
质量成本包括预防、鉴定、内部失败、外部失败四类；通过增加预防与鉴定投入降低失败成本，是质量经济性的核心逻辑。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未分四类质量成本（预防/鉴定/内损/外损） | COQ分类 |
| Q2 | WARN | 未含数据采集口径 | 口径 |
| Q3 | FAIL | 未计算质量成本占营收比 | 占比 |
| Q4 | WARN | 未含分析与改进计划 | 改进 |

> 脚本 `cost-of-quality_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python cost-of-quality_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python cost-of-quality_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
