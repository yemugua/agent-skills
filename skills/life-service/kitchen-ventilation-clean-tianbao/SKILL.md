# 油烟机清洗与保养（kitchen-ventilation-clean）

油烟机清洗，**不该按"几个月一次"来记，而该按三个信号来判断**：油垢厚度、吸力下降、噪音变化。这三个信号比日历可靠得多——高频烹饪的家庭和少做饭的家庭，清洗间隔可能差三倍。

但这个技能里**最重要的不是清洗方法，是安全**：油烟机的清洗涉及高处作业、带电部件、拆装复原。**清洗前不断电、拆装后漏装，都会出真实事故。**

这个技能做四件事：**判断该洗了没** → **按部位分层清洗** → **按类型区分** → **守住安全红线**。

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出清洗触发条件与分部位清洗要点 | ❌ 指导带电状态下的任何操作 |
| 说明顶吸、侧吸、集成灶的清洗差异 | ❌ 指导集成灶深度拆洗与电机拆解 |
| 列出清洁剂混用的安全红线 | ❌ 建议混合含氯消毒剂与酸性清洁剂 |
| 说明不清洁的五种后果 | ❌ 代替油烟机维修与电路检修 |
| 说明拆装后必须确认装回 | ❌ 判断电机与电路故障 |

**遇到以下情况，停止自行处理，转交油烟机维修或专业人员：**

- **集成灶的深度拆洗**：涉及灶体、蒸烤腔、油路结构
- **重油结垢已经硬化**：需要专业设备与清洗剂
- **有异响或电机异常**：可能是轴承、电机或安装问题
- **涉及电路**：任何带电部件的拆装
- **需要拆机或高处作业**：涉及受力和安全风险
- **油烟倒灌且伴随机器震动或位移**
- **安装位置需要调整或重新固定**

## 三、清洗触发条件（本技能的核心方法）

**三个信号，任一命中就说明该洗了：**

| 信号 | 怎么判断 | 说明 |
|---|---|---|
| 油垢厚度 | 取出油网目视，有明显油膜或油垢堆积 | 油网透光明显变差即需清洗 |
| 吸力下降 | 同样火力与锅具下，感觉吸力不如以前 | 吸力主观下降是可靠的信号 |
| 噪音变化 | 运行声音变高、变尖、出现摩擦声 | 噪音变化可能与油垢堆积导致的动平衡改变有关 |

**辅助判断**：油杯积油速度明显变快、玻璃面板油雾覆盖范围扩大、灶台附近油污增加。

**不推荐的做法**：死按"三个月一次"或"半年一次"。原因是**不同家庭的烹饪频次差异极大**，固定周期对高频家庭不够、对低频家庭过多。

## 四、安全红线（这一节必须先看）

**1. 清洗前必须断电。**

- 拔掉插头或关闭配电箱对应回路
- 确认断电后再动手，不要只关面板按钮
- 手部保持干燥，不在潮湿环境下操作电器

**2. 高处与拆机有触电与坠落风险。**

- 顶吸式通常在头顶高度，清洗时需要梯具或凳子
- **不要站在凳子或椅子上做不可控动作**，凳子不防滑、够身时重心易失衡
- 拆机前确认机器已稳固固定

**3. 清洗剂严禁混合使用。**

| 危险配对 | 后果 |
|---|---|
| 含氯消毒剂 + 酸性清洁剂（洁厕灵、白醋、柠檬酸类除垢剂） | 产生有毒气体，刺激呼吸道 |
| 含氯消毒剂 + 碱性清洁剂 | 同样不属于安全配对 |
| 两种含氯产品混合 | 有效成分叠加，不可控 |
| 酸性清洁剂用于不锈钢与铝制件 | 腐蚀表面，产生锈斑 |

**通用要求**：一次只用一种清洁剂；用完冲净再换下一种；清洁剂保持原包装不随意分装。

**4. 拆装后必须确认所有部件装回且无漏装。**

- 按拆卸的逆序装回
- 逐件核对：油杯、油网、长条形部件、盖板、螺丝
- 装回后确认机器稳固、无零件遗留在内部
- **有零件遗留在内部，通电后可能卡转或打火**

**5. 清洁剂不得喷入电机与电路部位。**

- 电机与电路区域只可用微湿软布擦拭，不能喷淋
- 喷淋后必须充分干燥再通电

## 五、分部位清洗要点

| 部位 | 清洗要点 | 注意 |
|---|---|---|
| 油杯 | 可取下直接清洗，用温水配中性清洁剂浸泡后刷洗 | 取下时可能有残油，容器接住 |
| 油网 | 可取下，用温水配中性清洁剂浸泡后刷洗 | 冲净后彻底晾干再装回 |
| 长条形挡板或滤板 | 取下清洗，动作轻，避免变形 | 装回时确认卡到位 |
| 风轮 | 需谨慎，一般只做表面擦拭 | **拆风轮属于维修范围**；重油结垢硬化时转专业 |
| 外壳与玻璃面板 | 微湿软布配中性清洁剂擦拭 | 避免液体流入缝隙与电路区 |
| 叶轮与电机表面 | 只做目视与轻微擦拭 | **不得喷淋、不得拆解**；油污多时转专业 |

**顺序建议**：油杯与油网（可取下的先洗）→ 挡板滤板 → 外壳面板 → 风轮表面目视。**先取下的先洗，干燥后最后装。**

---

## 六、不同类型的清洗差异

| 类型 | 清洗难点 | 建议 |
|---|---|---|
| 顶吸式 | 位置高，清洗需梯具 | 油网油杯可自行清洗；高处作业注意防坠落；外壳擦拭建议两人配合 |
| 侧吸式 | 位置低，清洗安全 | 自行清洗相对容易；玻璃面板油雾需重点清理 |
| 集成灶 | 结构紧凑，油路与灶体一体 | **深度拆洗属专业范围**；日常只做表面与可取下部件的清洁 |
| 欧式（内嵌式） | 部件多，拆装复杂 | 拆装复杂度高，建议交专业人员 |

---

## 七、不清洁的五种后果

| 后果 | 表现机制 |
|---|---|
| 吸力下降 | 风轮与风道被油垢占据，气流受阻 |
| 油烟倒灌 | 排风不畅，压力变化导致油烟回流 |
| 异响 | 油垢导致动平衡改变，或部件松动 |
| 耗电增加 | 风量下降时机器可能以更高功率运行 |
| 火灾隐患 | 长期油垢积聚遇高温存在起火风险 |

**这五条都是渐进的，等到明显出现时通常已经积了一段时间。**

## 八、必须叫师傅的情形

- 集成灶深度拆洗
- 重油结垢已经硬化，普通清洗方式无效
- 有异响或电机异常（可能是轴承或电机问题）
- 涉及电路的拆装
- 需要拆机或高处作业
- 油烟倒灌伴随机器震动或位移
- 安装位置需要调整或重新固定

## 九、脚本用法

```bash
python scripts/hood_clean_check.py --text "吸力变小了，还有异响"
python scripts/hood_clean_check.py --pair "含氯消毒液" "白醋"
python scripts/hood_clean_check.py --file 情况.json --out 结果.md
```

| 参数 | 说明 |
|---|---|
| `--text` | 直接描述油烟机状况 |
| `--file` | 从文件读，支持 `.txt` / `.md` / `.json`（JSON 用 `{"desc": "..."}`） |
| `--pair` | 检查两种清洁剂的配对，输出 danger / warn / ok |
| `--out` | 结果输出路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本做三件事：按三个信号判定是否该清洗、按部位给出清洗要点、检查清洁剂配对与安全红线。

> 脚本是关键词匹配，**不等于现场判断**。油垢厚度与吸力下降需要实际观察。

## 十、人工确认清单（这步不能省）

- [ ] 已断电（拔插头或关回路，不只是关面板按钮）
- [ ] 手部保持干燥，作业环境不潮湿
- [ ] 使用梯具时已确认稳固，凳子不作为高处作业平台
- [ ] 只用一种清洁剂，未与含氯或酸性清洁剂混合
- [ ] 清洁剂保持原包装，未分装到不明容器
- [ ] 未向电机与电路部位喷淋
- [ ] 所有可取下部件已彻底晾干
- [ ] 已按逆序装回并逐件核对，无漏装
- [ ] 确认内部无遗留零件
- [ ] 通电试运行后吸力与噪音正常
- [ ] 已确认不属于"必须叫师傅"的情形

## 十一、最常见的坑

**坑一：只关面板按钮就动手。**
面板关了但电路仍带电，这是触电风险的直接来源。必须拔插头或关回路。

**坑二：站在凳子上清洗顶部。**
凳子不防滑，够身时重心容易失衡。涉及高处与坠落风险，宁可找人来洗。

**坑三：含氯消毒液配白醋去油。**
会产生有毒气体。清洁一次比任何故障都危险，这是明确红线。

**坑四：拆完装不回去或漏装零件。**
有零件遗留在内部，通电后可能卡转或打火。装回后逐件核对。

**坑五：喷清洁剂到电机和电路区域。**
液体进入会导致短路或故障。电机区域只能微湿布擦。

**坑六：风轮拆下来自己洗。**
风轮属于拆机范围，装配不当会破坏动平衡。这属于维修，不是清洁。

**坑七：油网洗完没晾干就装回。**
潮湿装回会缩短部件寿命，也容易产生异味。

**坑八：集成灶自己深度拆洗。**
结构紧凑且涉及油路，深度拆洗属专业范围。

**坑九：等吸力明显下降才洗。**
吸力下降已经是积了一段时间的结果，而且此时油脂已经在电机与电路附近积聚。

**坑十：不同清洁剂混着用想提高效果。**
不但无效，还会腐蚀部件或产生有害气体。一次只用一种。

## 十二、边界与免责

- 本技能**不替代**油烟机维修、电机检修与电路检修
- 集成灶深度拆洗、拆风轮、涉及电路的拆装一律交专业人员
- 清洁剂适用范围以**产品说明书**为准，不同产品不可混用
- 电器安全相关要求以**产品说明书与相关主管部门要求**为准
- 涉及安装、移位与固定的问题，按**产品说明书与安装规范**处理
