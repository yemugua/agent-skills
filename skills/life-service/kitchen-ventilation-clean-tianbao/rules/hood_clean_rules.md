# 油烟机清洗规则表

生成清洗方案前先读本文件，不要凭印象写。

---

## 一、清洗触发条件（用三个信号代替固定周期）

| 信号 | 判断方法 | 说明 |
|---|---|---|
| 油垢厚度 | 取出油网目视，有明显油膜或油垢堆积 | 油网透光明显变差即需清洗 |
| 吸力下降 | 同样火力与锅具下，感觉吸力不如以前 | 主观下降是可靠信号 |
| 噪音变化 | 运行声音变高、变尖、出现摩擦声 | 可能与油垢堆积导致动平衡改变有关 |

**辅助判断**：油杯积油速度变快、玻璃面板油雾范围扩大、灶台附近油污增加。

**不推荐死按周期**：不同家庭烹饪频次差异极大，固定周期对高频家庭不够、对低频家庭过多。

## 二、安全红线

### 1. 清洗前必须断电

- 拔掉插头或关闭配电箱对应回路
- 确认断电后再动手，不要只关面板按钮
- 手部保持干燥，不在潮湿环境下操作电器

### 2. 高处与拆机的风险

- 顶吸式通常在头顶高度，清洗需梯具或凳子
- 不要站在凳子或椅子上做不可控动作，凳子不防滑、够身时重心易失衡
- 拆机前确认机器已稳固固定

### 3. 清洁剂严禁混合使用

| 危险配对 | 后果 |
|---|---|
| 含氯消毒剂 + 酸性清洁剂（洁厕灵、白醋、柠檬酸类除垢剂） | 产生有毒气体，刺激呼吸道 |
| 含氯消毒剂 + 碱性清洁剂 | 同样不属于安全配对 |
| 两种含氯产品混合 | 有效成分叠加，不可控 |
| 酸性清洁剂用于不锈钢与铝制件 | 腐蚀表面，产生锈斑 |

**通用要求**：一次只用一种清洁剂；用完冲净再换下一种；清洁剂保持原包装不随意分装。

### 4. 拆装后必须确认所有部件装回且无漏装

- 按拆卸的逆序装回
- 逐件核对：油杯、油网、长条形部件、盖板、螺丝
- 装回后确认机器稳固、无零件遗留在内部
- 有零件遗留在内部，通电后可能卡转或打火

### 5. 清洁剂不得喷入电机与电路部位

- 电机与电路区域只可用微湿软布擦拭，不能喷淋
- 喷淋后必须充分干燥再通电

## 三、分部位清洗要点

| 部位 | 清洗要点 | 注意 |
|---|---|---|
| 油杯 | 可取下直接清洗，温水配中性清洁剂浸泡后刷洗 | 取下时可能有残油，容器接住 |
| 油网 | 可取下，温水配中性清洁剂浸泡后刷洗 | 冲净后彻底晾干再装回 |
| 长条形挡板或滤板 | 取下清洗，动作轻，避免变形 | 装回时确认卡到位 |
| 风轮 | 需谨慎，一般只做表面擦拭 | 拆风轮属于维修范围；重油结垢硬化时转专业 |
| 外壳与玻璃面板 | 微湿软布配中性清洁剂擦拭 | 避免液体流入缝隙与电路区 |
| 叶轮与电机表面 | 只做目视与轻微擦拭 | 不得喷淋、不得拆解；油污多时转专业 |

**顺序**：油杯与油网（可取下的先洗）→ 挡板滤板 → 外壳面板 → 风轮表面目视。先取下的先洗，干燥后最后装。

---

## 四、不同类型的清洗差异

| 类型 | 清洗难点 | 建议 |
|---|---|---|
| 顶吸式 | 位置高，需梯具 | 油网油杯可自行清洗；高处作业注意防坠落；外壳擦拭建议两人配合 |
| 侧吸式 | 位置低，较安全 | 自行清洗相对容易；玻璃面板油雾需重点清理 |
| 集成灶 | 结构紧凑，油路与灶体一体 | 深度拆洗属专业范围；日常只做表面与可取下部件清洁 |
| 欧式内嵌式 | 部件多，拆装复杂 | 拆装复杂度高，建议交专业人员 |

---

## 五、不清洁的五种后果

| 后果 | 表现机制 |
|---|---|
| 吸力下降 | 风轮与风道被油垢占据，气流受阻 |
| 油烟倒灌 | 排风不畅，压力变化导致油烟回流 |
| 异响 | 油垢导致动平衡改变，或部件松动 |
| 耗电增加 | 风量下降时机器可能以更高功率运行 |
| 火灾隐患 | 长期油垢积聚遇高温存在起火风险 |

这五条都是渐进的，等到明显出现时通常已经积了一段时间。

---

## 六、必须叫师傅的情形

1. 集成灶深度拆洗
2. 重油结垢已经硬化，普通清洗方式无效
3. 有异响或电机异常（可能是轴承或电机问题）
4. 涉及电路的拆装
5. 需要拆机或高处作业
6. 油烟倒灌伴随机器震动或位移
7. 安装位置需要调整或重新固定

---

## 七、清洁剂配对判定

| 输入组合 | 等级 | 说明 |
|---|---|---|
| 含氯 + 酸性 | danger | 严禁，产生有毒气体 |
| 含氯 + 碱性 | danger | 不属于安全配对 |
| 含氯 + 含氯 | danger | 有效成分叠加，不可控 |
| 香味类产品 | warn | 只掩盖不解决来源 |
| 其他 | ok | 仍以产品说明书为准 |

---

## 八、常见误判清单

1. 只关面板按钮就动手——电路仍带电
2. 站在凳子上清洗顶部——凳子不防滑，重心易失衡
3. 含氯消毒液配白醋去油——产生有毒气体
4. 拆完装不回去或漏装零件——通电后可能卡转或打火
5. 喷清洁剂到电机和电路区域——短路或故障
6. 风轮拆下来自己洗——属维修范围，装配不当破坏动平衡
7. 油网洗完没晾干就装回——缩短部件寿命并产生异味
8. 集成灶自己深度拆洗——涉及油路，属专业范围
9. 等吸力明显下降才洗——积聚已持续一段时间
10. 不同清洁剂混着用想提高效果——腐蚀部件或产生有害气体
