# 皮皮虾短视频留存与授权边界：途径、限制与合规边界

## 一、先判定：能不能下

| 归属类别 | 能否下载 | 允许的用途 |
| --- | --- | --- |
| 自有作品 | 可以，优先用原始导出文件 | 任意 |
| 已授权素材 | 可以 | 仅限授权范围内 |
| 作者开放了保存 | 可以，走官方途径 | 个人留存，**不得二次分发** |
| 第三方作品（未授权） | **不建议下载** | 不应用于任何对外场景 |

技术上能不能下载，和法律上能不能用，是两回事。

## 二、途径，按稳定性排序

| 途径 | 操作要点 |
| --- | --- |
| 原文件 | 优先。自有作品用发布前的原始导出文件，最清晰完整，也最合规。 |
| 官方保存 | 在 App 内对开放了保存权限的内容使用官方保存，会带平台水印，不能去水印。 |
| 创作者后台 | 登录自己的创作者账号在后台查看与下载自己发布的内容。 |
| 通用命令行工具 | 需 Python + ffmpeg：pip install -U yt-dlp。仅对公开且未关闭保存的免费内容可能有效。 |

## 三、本平台的真实限制

- 皮皮虾短视频多为短时长、低码率，画质上限有限，追求高清应优先找回原文件。
- 他人作品未经授权不要下载与二次分发，影视剪辑还涉及原片版权。
- 音乐短视频含背景音乐版权，去水印后商用风险高。
- 官方保存会带平台水印且不可去除。

## 四、画质与水印

- 皮皮虾短视频画质上限有限，原文件优于平台保存版本。
- 平台保存带水印，属平台标识，不得去除后二次分发。

## 五、合规红线

1. 不得去除作者署名后二次分发
2. 不得将他人作品搬运至自己的账号（含剪辑、配音后发布）
3. 不得下载或传播私密账号、付费内容
4. 受版权或 DRM 保护的内容不支持下载，也不提供任何破解方法
5. 商用前必须取得书面授权
6. 批量高频抓取可能违反平台服务协议，导致账号受限
