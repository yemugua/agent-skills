# 儿童安全座椅安装与使用核查规则库

> 生成核查结论、写出行清单之前，先读这份文件，不要凭印象写。
> 涉及法规与标准的部分以现行规定、车辆说明书与产品说明书要求为准。

---

## 一、安装方式对比表

| 方式 | 原理 | 优点 | 常见问题 |
|---|---|---|---|
| ISOFIX 接口 | 车身固定点直接连接底座 | 稳定、误装概率低 | 接口位置不当会顶到前排座椅 |
| 安全带固定 | 靠安全带收紧固定 | 通用 | 装松是最常见问题 |
| 车载锚点（上拉带） | 配合其他方式限制倾角 | 增强稳定性 | 未按说明书使用会适得其反 |
| 内置座椅（部分车型） | 车辆自带 | 免安装 | 适配车型范围有限 |

**核心口径**：安装方式的差异不如安装是否到位重要。**安全带固定本身没问题，问题在于没按说明书规定的紧度收紧。**
**选型倾向**：能用 ISOFIX 就用 ISOFIX，误装概率明显更低。

## 二、阶段与安装方向对应表

| 阶段 | 典型身高体重范围 | 常见安装方向 | 说明 |
|---|---|---|---|
| 婴儿期 | 出生到约 1 岁 | 后向 | 后向对头颈保护最充分 |
| 幼儿期 | 约 1 到 4 岁 | 后向优先 | 后向能坐多久就坐多久 |
| 学龄前 | 约 4 到 7 岁 | 可转前向 | 仍需符合身高体重要求 |
| 学龄期 | 约 7 岁以上 | 前向 | 多数需用增高垫或安全带 |

**关于后向的口径**：

- 后向的保护优势主要来自对头颈的保护
- 后向能用到多大，**取决于身高体重是否仍落在说明书规定的后向适用范围内**，不取决于年龄
- **不要按年龄硬性切换**，孩子长得快慢差异很大

**转前向的三条确认**：身高达到规定值、体重达到规定值、后向安装已不适用。**三条都满足才能转。** 具体数值以说明书为准。

## 三、位置选择表

| 位置 | 判定 | 原因 |
|---|---|---|
| 后排 | 推荐 | 事故中相对约束更多，保护更充分 |
| 前排且有安全气囊 | 不可 | 前向座椅可能被气囊弹出直接撞击孩子 |
| 前排且能关闭气囊 | 不建议 | 关闭状态可能因故被误开或被系统自动启用 |

**核心口径**：有安全气囊的前排不能放儿童座椅。若因空间或座位安排只能放前排，**优先调整座位安排，而不是在前排凑合**。

## 四、安装后四项必检

| 检查项 | 怎么做 | 合格标准 |
|---|---|---|
| 松紧 | 在肩带或固定点处捏一下 | 捏起量不超过说明书规定厚度 |
| 倾角 | 看是否在说明书规定的倾角范围 | 落在规定范围内 |
| 锁止 | 晃动座椅与底座连接处 | 无松动、无位移 |
| 贴合 | 检查与车辆座椅间隙、孩子贴合 | 无明显空隙，背部贴合 |

**两个最常见的问题**：

- **装松**：安全带固定方式下尤其常见。要按说明书规定的紧度收紧，不是越紧越好，也不是差不多就行。
- **装错位置**：装在前排、后排中间、靠侧位置不合适、底座未按要求锁到位。

## 五、出行前检查清单

| 序号 | 检查项 |
|---|---|
| 1 | 座椅与底座连接牢固，按说明书指定的锁止指示确认到位 |
| 2 | 肩带或固定带松紧符合说明书要求 |
| 3 | 倾角与安装方向和孩子的身高体重匹配 |
| 4 | 孩子入座后贴合良好，肩带高度正确 |
| 5 | 车上没有松散物品能飞出或卡到孩子 |
| 6 | 孩子衣物没有卷入固定带 |
| 7 | 座椅未被长时间暴晒后变形 |
| 8 | 车钥匙未留在孩子可及范围内 |

## 六、更换与停用判定表

| 情况 | 建议 |
|---|---|
| 超出说明书规定的身高体重范围 | 更换到适用型号 |
| 经历过事故（即使外观看不出问题） | 停用并更换或送检 |
| 使用年限已到 | 停用更换 |
| 长期暴晒后外壳变形、织带磨损 | 停用更换 |
| 底座或连接件有裂纹、变形 | 立即停用 |
| 说明书规定的检查周期已过 | 按说明书送检或更换 |

**年限口径**：不同品牌与型号规定不同，**以产品说明书标注的使用年限为准**，不套用统一数字。

## 七、常见误区对照

| 说法 | 是否成立 |
|---|---|
| 有安全气囊的前排放一下没事 | 不成立，前向座椅会被气囊直接撞击 |
| 装紧了就行，不用看说明书 | 不成立，紧度要求以说明书为准 |
| 到年龄就转前向 | 不成立，看身高体重是否在后向适用范围内 |
| 装上了就等于锁到位 | 不成立，必须按指定方式确认锁止指示 |
| 出过事故但看着没事可以继续用 | 不成立，结构可能已受损 |
| 别人家孩子用这个没问题 | 不成立，依据是说明书不是经验 |
| 安全带固定不如 ISOFIX 安全 | 不成立，问题多在装松而不是方式本身 |
| 倾角看着差不多就行 | 不成立，须落在说明书规定范围内 |
