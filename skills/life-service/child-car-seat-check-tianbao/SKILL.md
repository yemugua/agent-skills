# 儿童安全座椅安装与使用核查（child-car-seat-check）

安全座椅的保护效果，一半来自产品，一半来自**装得对不对**。同样一款座椅，装对了和装松了，差别很大。

这个技能做四件事：**选安装方式** → **对阶段** → **装后必检** → **出行前查**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 说明安装方式对保护效果的影响 | ❌ 承诺任何安装方式都是安全的 |
| 说明后向安装的适用阶段与依据出处 | ❌ 编造法规条款号或标准号 |
| 给出安装后必须检查的项目 | ❌ 替代产品说明书的具体要求 |
| 给出出行前检查清单 | ❌ 修改车辆安全设置或改装座椅 |
| 说明更换与停用的判定条件 | ❌ 指导自制、加装或改装座椅 |

**涉及法规与安全要求的部分，一律以现行规定、车辆说明书与安全座椅产品说明书为准。** 本技能只讲通用原理与检查方法，具体数值要求看随座椅附带的说明书。

**遇到以下情况，咨询厂家或专业人员：**

- 座椅与车辆型号适配存疑
- 说明书要求的倾角无法调到规定范围
- 事故后座椅结构受损（即使外观看不出问题）
- 座椅使用年限已到或经历过高温暴晒后变形
- 孩子身高体重已超出说明书规定的适用范围

## 二、完整工作流

```
第 1 步  确认座椅适用范围：身高体重区间、适用年龄，对照产品说明书
第 2 步  选安装方式：ISOFIX 接口固定 / 安全带固定 / 车载锚点
第 3 步  选安装位置：优先后排，具体要求看车辆说明书
第 4 步  先读规则文件 rules/car_seat_rules.md（安装方式对比 + 阶段表 + 装后必检）
第 5 步  跑阶段与安装核查脚本
    python scripts/car_seat_check.py --age 3 --height 102 --weight 16 --position rear
第 6 步  执行安装后四项必检（松紧、倾角、锁止、贴合）
第 7 步  每次出行前过一遍出行前检查清单
```

## 三、安装方式对结果的影响

| 方式 | 原理 | 优点 | 常见问题 |
|---|---|---|---|
| ISOFIX 接口 | 车身固定点直接连接座椅底座 | 稳定、误装概率低 | 接口位置不当会顶到前排座椅 |
| 安全带固定 | 靠安全带收紧固定 | 通用 | **装松是最常见问题** |
| 车载锚点（上拉带） | 配合其他方式限制倾角 | 增强稳定性 | 未按说明书使用会适得其反 |
| 内置座椅（部分车型） | 车辆自带 | 免安装 | 适配车型范围有限 |

**核心口径**：**安装方式的差异不如安装是否到位重要。** 用安全带固定本身没问题，**问题在于没按说明书规定的紧度收紧**。

**能不用安全带固定就不要用**，不是因为安全带固定不安全，而是 ISOFIX 的误装概率明显更低。

---

## 四、儿童阶段与安装方式的对应

| 阶段 | 典型身高体重范围 | 常见安装方向 | 说明 |
|---|---|---|---|
| 婴儿期 | 出生到约 1 岁 | **后向** | 后向对头颈的保护最充分 |
| 幼儿期 | 约 1 到 4 岁 | 后向优先 | 后向能坐多久就坐多久 |
| 学龄前 | 约 4 到 7 岁 | 可转前向 | 仍需符合身高体重要求 |
| 学龄期 | 约 7 岁以上 | 前向 | 多数需用增高垫或安全带 |

**关于后向的通用口径**：

- **后向安装的保护优势主要来自对头颈的保护**，婴幼儿头颈相对身体比例更重更脆弱
- **后向能用到多大，取决于孩子的身高体重是否仍落在产品说明书规定的后向适用范围内**，而不是取决于年龄
- **不要按年龄硬性切换**，孩子长得快慢差异很大

**切换到前向前必须逐条确认**：身高达到说明书规定值、体重达到规定值、后向安装已不适用。**三条都满足才能转。** 具体数值以产品说明书为准。

## 五、位置选择：有安全气囊的前排不行

| 位置 | 是否建议 | 原因 |
|---|---|---|
| 后排 | ✅ 优先 | 事故中相对约束更多，保护更充分 |
| 前排且有安全气囊 | ❌ 不建议 | 前向座椅可能被安全气囊弹出直接撞击孩子 |
| 前排且能关闭气囊 | ⚠️ 不建议 | 气囊关闭状态可能因故被误开或被系统自动启用 |

**核心口径**：**有安全气囊的前排不能放儿童座椅。** 这一条不是「尽量避免」，是「不要这样装」。

**若因后排空间或座位安排只能放前排**：优先调整座位安排（换后排、加装座椅），而不是在前排凑合。

---

## 六、安装后四项必检

**这四项每次装完都要查，尤其在调整后。**

| 检查项 | 怎么做 | 合格标准 |
|---|---|---|
| **松紧** | 在肩带或固定点处捏一下 | 捏起量不超过说明书规定的厚度 |
| **倾角** | 看座椅是否达到说明书规定的倾角范围 | 落在线性碰撞测试时头部不前移的位置 |
| **锁止** | 晃动座椅与底座连接处 | 无松动、无位移 |
| **贴合** | 检查与车辆座椅间隙、与孩子贴合 | 无明显空隙，背部贴合 |

**最常见的两个问题：**

**装松**：安全带固定方式下尤其常见。固定后必须按说明书规定的紧度收紧，**不是越紧越好，也不是差不多就行，是按说明书来**。

**装错位置**：装在前排、后排中间、靠侧位置不合适、底座未按要求锁到位，都属于装错。

---

## 七、出行前检查清单

```
1. 座椅与底座连接牢固，按下说明书指定的锁止指示确认到位
2. 肩带或固定带松紧符合说明书要求（在锁骨处能捏起规定厚度）
3. 倾角与安装方向与孩子的身高体重匹配
4. 孩子入座后贴合良好，肩带高度正确
5. 车上没有其他松散物品能飞出或卡到孩子
6. 孩子的衣物没有卷入固定带
7. 座椅未被阳光长时间暴晒后变形
8. 车钥匙未留在孩子可及范围内（不用时取出）
```

**关于取下座椅的判断**：长时间不用时是否取下、按说明书要求操作，**以产品说明书为准**。不同座椅的取下与折叠方式不同。

---

## 八、更换与停用的判定

| 情况 | 建议 |
|---|---|
| 孩子超出说明书规定的身高体重范围 | 更换到适用型号 |
| 经历过事故（即使外观看不出问题） | 停用并更换或送检 |
| 使用年限已到 | 停用更换 |
| 长期暴晒后外壳变形、织带磨损 | 停用更换 |
| 底座或连接件有裂纹、变形 | 立即停用 |
| 说明书规定的清洁与检查周期已过 | 按说明书送检或更换 |

**年限口径**：不同品牌与型号的规定不同，**以产品说明书标注的使用年限为准**，不套用统一数字。

## 九、脚本用法

```bash
python scripts/car_seat_check.py --age 3 --height 102 --weight 16 --position rear
python scripts/car_seat_check.py --file child.json --out 核查结论.md
python scripts/car_seat_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--age` | 孩子年龄（岁） |
| `--height` | 身高（厘米） |
| `--weight` | 体重（千克） |
| `--position` | `rear` / `front` |
| `--method` | `isofix` / `belt` / `anchor` / `builtin` |
| `--direction` | `rearward` / `forward` |
| `--file` | 从 JSON 读（自动兼容带 BOM 的文件） |
| `--out` | 结果落盘路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本输出**阶段判定、安装方式建议、位置合规提示、安装后必检项与出行前清单**。

> 脚本只做通用阶段判断，**具体适用范围与安装要求以产品说明书和车辆说明书为准**。

## 十、人工确认清单（这步不能省）

- [ ] 核对了座椅说明书上的适用范围与孩子的身高体重
- [ ] 安装位置是后排，不是有安全气囊的前排
- [ ] 安装方向与孩子阶段匹配，没有按年龄硬切
- [ ] 优先用了 ISOFIX，安全带固定时按说明书紧度收紧
- [ ] 锁止指示已确认到位
- [ ] 松紧、倾角、锁止、贴合四项都检查过
- [ ] 出行前清单每次都过
- [ ] 座椅未经历过事故、暴晒变形或年限已到的情况仍被判定可用

## 十一、最常见的坑

**坑一：装在前排。**
有安全气囊的前排不能放儿童座椅，前向座椅可能被气囊弹出直接撞击孩子。

**坑二：安全带固定没按说明书紧度收紧。**
**装松是最常见的问题**，也是最容易自我说服「应该够了」的地方。按说明书来，不靠手感。

**坑三：按年龄切换前向。**
后向能用多久取决于身高体重是否还在说明书的后向适用范围内，不是看年龄。孩子长得快慢差别很大。

**坑四：锁止指示没确认。**
装上了不等于锁到位。装完必须按说明书指定的方式确认锁止。

**坑五：倾角凭感觉调。**
倾角有说明书规定的范围，落在规定范围内才有效，不能靠看着差不多。

**坑六：肩带高度不对。**
肩带过高过过低都会影响约束效果，每次入座后都要确认。

**坑七：孩子入座后有明显空隙。**
空隙意味着约束路径不对，要按说明书调整。

**坑八：出过事故的座椅继续用。**
事故后结构可能已受损，**即使外观看不出问题也要停用**。

**坑九：暴晒变形、织带磨损还继续用。**
这些是明确的停用信号，不要因为「还能用」就继续。

**坑十：把别人的经验当依据。**
「我家孩子用这个没问题」不是依据。**判断依据是产品说明书和车辆说明书。**

## 十二、边界与免责

- 本技能**只讲通用原理与检查方法**，不替代产品说明书与车辆说明书
- 涉及法规与安全标准的部分，**以现行规定、车辆说明书和安全座椅产品说明书要求为准**，本技能不引用具体条款号与标准号
- 具体的高度、体重、倾角范围与年限要求，**一律以随座椅附带的说明书为准**
- 不指导自制、加装或改装安全座椅，不指导修改车辆安全设置
- 事故后座椅的可用性判定应由厂家或专业人员做出
