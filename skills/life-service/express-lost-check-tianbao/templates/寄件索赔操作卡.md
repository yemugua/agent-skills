# 寄件索赔操作卡（一次做完不返工）

## 零、交寄当天就要做的四件事（预防）

1. **拍交寄照**：包裹合起来后拍一张整体照 + 一张内件与面单同框照（面单上要有重量字样更好）。
2. **称重留痕**：手机自带的秤或便利店称重，把重量记下来并拍照。
3. **贵重件必保价**：保价额写到接近实际价值就行，别为省几块钱保价费丢几百块。
4. **留存订单页**：寄件记录、资费、保价选项截屏。

> 上面四步做足了，后面每一步都轻松一半。

## 一、发现丢了，当天做

- [ ] 用运单号查轨迹：截图（**从下单第一条到最后一条，别只截结尾**）
- [ ] 轨迹停在「派送中 / 已到网点 / 代收点」的，当场截图网点名称
- [ ] 致电客服：只做一件事——**要工单号**，并记下通话时间、对方工号
- [ ] 疑似冒领的：立即报警，要**报案回执**；同时要企业给投递监控与签收影像
- [ ] 生鲜类：当场拍外箱霜冻、化冻、腐烂状态

## 二、价值证据怎么凑（决定最终赔多少）

| 顺序 | 材料 | 备注 |
|---|---|---|
| 1 | 发票 | 最硬 |
| 2 | 电商订单页 + 支付记录 + 商品快照 | 订单金额与成交时间要对得上 |
| 3 | 同类商品当时市场价（询价 / 比价截图） | 写清询价时间 |
| 4 | 二手平台同类成色成交价 | 只作参考，别当主证 |
| 5 | 称重 + 参数推算 | 最弱，兜底用 |

**每件都可能被问到的三个问题**（提前准备好答案）：
- 这件东西什么时候买的、多少钱？
- 为什么值这么多（有无发票、保修、型号）？
- 交寄时多重？你打算赔多少？

## 三、跟客服说的话（照着念）

> 「我是运单号 1234567890 的寄件人，内件是单反相机机身，实际价值 ¥2600，
> 交寄日 9 月 28 日，资费 ¥18。目前轨迹显示投递到代收点，我未收到也未被通知，
> 内件确已丢失。我主张按内件实际损失 ¥2900 赔偿（含我实际支出的附件费用 ¥300）。
> 请给我一个**受理工单号**，并书面告知赔偿处理进度与依据。
> 贵司运单背面『三倍资费封顶』条款如未尽提示说明义务，我不能认可其作为合同内容，
> 请以实际损失为准。」

## 四、二次申诉 / 12305 要提交什么

1. 运单号、企业全称、交寄日期、内件与价值
2. 第一次的**工单号** + 企业答复截图（证明你先投诉过）
3. 你的**诉求金额与算式**（企业口径 vs 可主张口径两个数一起写）
4. 全套价值凭证扫描件
5. 诉求一句话：「请求按内件实际损失 ¥X 赔偿，而非三倍资费 ¥Y」

## 五、时间红线

| 什么时候 | 做什么 |
|---|---|
| 当天 | 查轨迹截图、要工单号、生鲜拍照、冒领报警 |
| 3 个工作日内 | 收到企业答复；不服的立刻做二次申诉 |
| 30 天内 | 12305 申诉：对结果不服或企业逾期未答复的，请求邮政管理部门裁定 |
| 交寄起 1 年内 | 必须提出赔偿请求（越早越好） |
| 3 年内 | 诉讼时效，别拖到过期 |

## 六、常见坑

- **口头客服不作数**：没有工单号＝没有投诉记录，后面全断链。
- **别先寄新货再等结论**：换新件的钱先垫了，举证会乱。
- **别在电话里吵金额**：先留单，金额写在书面材料里。
- **别只盯末端网点**：投诉要打到总部 / 省级机构，加盟网点扛不住。
- **监控只有 7~30 天**：冒领和代收点场景，当天就要要求保全。
- **别忘运费本身**：没送到，运费也是损失，一并主张。
