# 快递丢失赔偿核算

丢一件东西最气人的不是东西本身，是客服那句"我们最多赔三倍运费"。
本技能把**企业口径**和**可主张口径**两个数同时摆出来，告诉你哪个更有利、证据怎么补、下一步该打哪个电话。

## 什么时候用

- 快递显示已签收，但东西根本没到（代收点/快递柜里没有、被别人拿走）
- 保价了，企业只肯按保价额的三分之一赔
- 没保价，企业说"最多赔三倍资费"，但你寄的是相机、金饰、合同原件
- 走的是平邮/挂号信/EMS 标准，听说只能赔三倍资费，想知道还有没有别的路
- 电商购物货没到，卖家和快递互相踢皮球
- 生鲜冷链烂在路上、国际件丢在中转场

## 怎么做

**第 1 步**：复制 `templates/快递丢失信息采集表.md` 填写。

**第 2 步**：跑脚本

```bash
python scripts/express_lost_check.py 采集表.md --base 2026-10-05 --out 核算报告.md
python scripts/express_lost_check.py 采集表.md --json
```

**第 3 步**：按第九段"待办补正动作"执行，重点是把**内件价值凭证**补齐。

## 四句话的核心规则

1. **永远有两套数**：企业只会按它的格式条款给（未保价常见是**资费三倍**封顶），
   但你按《民法典》运输合同主张的是**内件实际损失**。两个数一起摆上桌，
   哪个对你有利一目了然——差的那一截，靠**价值凭证**去够。
2. **"三倍封顶"是格式条款**：快递运单背面那行小字，如果企业没有加粗、没有单独提示说明、
   没有你签字确认，属于明显减轻其自身责任的条款，你可以主张它**不成为合同内容**。
   企业要援引它，得先证明自己尽到了提示说明义务。
3. **保价件按保价额，但不超过实际价值**：保价额填高了没用（超过实际价值的部分赔不了），
   填低了就等于自己给自己设了上限。
4. **电商件先找卖家**：货没到，直接在订单页点「未收到货」，让商家重新发货或退款——
   这条路通常最快，也不用你自己证明这包裹值多少钱。

## 输入 / 输出

| | 内容 |
|---|---|
| 输入 | 采集表 Markdown（企业 / 运单 / 内件 / 保价 / 资费 / 价值 / 情形 / 证据 / 已做动作） |
| 输出 | 十段报告：结论摘要 / 两套口径对比 / 赔偿测算 / 责任与举证 / 场景分支 / 阶梯路径 / 时限 / 证据缺口 / 待办 / 边界与纪律 |
| 退出码 | 0 正常；2 关键信息缺失（给提示串，不崩） |

## 边界与纪律

- 依**通用规则**整理，**不替代律师意见**
- 保价与未保价的赔偿上限、三倍资费口径的适用边界，在**邮政普遍服务**与**快递业务**之间存在两套口径，具体适用以主管部门认定与司法机关裁判为准
- 不预测诉讼结果、不承诺必定按实际价值获赔；**能不能按可主张口径拿到钱，取决于价值证据的充分程度**
- 违禁品、限寄品、超范围物品导致的损失，企业依法可不赔或只按约定处理，本报告会单独标注
- **未填的一律不算通过**，只按填了的判断
