# 责任与举证：先把事实钉死

## 一、举证四要件

主张赔偿，法院看的是四件事能不能证明：

| 要件 | 要证明什么 | 主要证据 |
|---|---|---|
| ① 合同成立 | 你确实交了一件货给这家企业 | 运单（底单 / 电子面单截图）、下单记录、支付记录 |
| ② 内件存在与价值 | 里面装了东西、值多少钱 | 发票、订单、付款记录、交寄称重照片、包装照片 |
| ③ 丢失事实 | 货没送到 / 交付前灭失 | 物流轨迹截图、企业书面答复、报警回执、签收记录 |
| ④ 损失与因果关系 | 这笔钱是因为丢件直接产生的 | 上述三组材料拼成的证据链 |

**顺序不能乱**：先证明「我寄了一个值 2600 的相机」，再证明「它没到」，最后才谈赔多少。
很多案子折在第②步——东西再贵，说不出它值多少，就只能拿到三倍资费。

## 二、八项证据清单

| # | 材料 | 为什么重要 | 缺失后果 |
|---|---|---|---|
| 1 | 快递运单（底单或电子面单截图） | 合同成立的根，没运单号什么都调不出来 | 无法调轨迹、无法立案 |
| 2 | 保价凭证 / 保价协议 | 保价件按保价额赔，凭证就是金额依据 | 保价白保 |
| 3 | 内件价值凭证（发票、订单、付款记录） | 可主张口径的唯一基数 | 退到三倍资费兜底 |
| 4 | 外包装与内件照片 | 反制「空包 / 你没真寄」的抗辩 | 企业抗辩难打掉 |
| 5 | 重量记录（交寄称重或物流称重） | 重量对不上＝内容物存疑 | 价值可信度大幅下降 |
| 6 | 物流轨迹 / 签收记录截图 | 固定「未送达」事实 | 丢失事实无法证明 |
| 7 | 与企业的投诉工单号 | 证明你主张过、企业拒赔 | 后续申诉缺前序记录 |
| 8 | 报警回执（疑似冒领时） | 冒领属于第三人侵权，报案是前置动作 | 分不清是自己没取还是被拿走 |

## 三、举证责任怎么分

- **一般规则**：谁主张谁举证，你先证明上面四要件。
- **格式条款的提示说明义务在企业**：企业若要用三倍 / 封顶条款减轻自己责任，
  要它自己证明已经加粗、提示、让你确认过。拿不出，你主张该条款不成为合同内容。
- **企业掌握的单方证据**：投递监控、签收影像、称重后台数据，都在企业手里，
  你有权要求提供；企业拒不提供的，可主张它承担不利后果。
- **监控有时限**：投递点监控通常只留 7~30 天，疑似冒领的**当天就要要求保全**。

## 四、责任主体到底是谁

| 情形 | 该找谁 | 说明 |
|---|---|---|
| 电商购物、货没到 | **卖家（商家）** | 在订单页点「未收到货」，让商家重新发货或退款 |
| 自己寄件给朋友/自用 | 快递企业 | 走运输合同索赔 |
| 代收点 / 快递柜丢了 | 快递企业（受托投递方） | 先核实是否征得收件人同意 |
| 被冒领 | 快递企业 + 报警 | 企业未安全送达仍有责任，第三人侵权另行追偿 |
| 加盟网点 | 总品牌企业 | 加盟经营中对外仍由品牌企业担责，投诉要打到总部 |
| 平台自营物流 | 平台 | 平台物流有独立的投诉与赔付通道 |

## 五、免责与减责情形（这些是真的会减钱）

1. **违禁品 / 限寄品**：内件属禁寄或超出寄递范围，企业依法可不赔或只按约定处理。
2. **未如实申报**：内件性质、重量、价值明显与运单不符的。
3. **收件人自身原因**：地址错误、长期未取导致遗失、自己告知代收后又没取。
4. **不可抗力**：自然灾害等不可抗力导致的灭失。
5. **有效格式条款**：三倍 / 封顶条款本身提示说明到位、且未明显减轻企业责任的。
6. **你自己签了保价限额**：签了就认，别反悔。

符合第 1、5、6 条的，可主张空间被压缩，报告会标红；符合第 2、3、4 条的，
要看你有没有尽到如实告知义务。

## 六、时效与成本的现实提醒

- 自**交寄之日起一年内**提出赔偿请求，越早越好；诉讼时效 3 年。
- 小额标的走**小额诉讼**，成本最低，但要预留时间。
- 全程留痕：每一次通话记工单号，每一次提交留截图，口头客服不作数。
