# 赔偿口径：保价与未保价，两套算法

> 法条号不确定的一律写「《XX法》相关规定」，本文件不编造条号。
> 具体适用以主管部门认定与司法机关裁判为准。

## 一、为什么永远有两套数

快递企业赔多少，取决于**它援引什么条款**；你该拿多少，取决于**你实际损失了多少**。
这两件事不是一回事，所以任何一次核算都要给出两个数：

| | 企业口径（它肯给的） | 可主张口径（你能要的） |
|---|---|---|
| 保价件 | 保价金额（超过实际价值的部分不赔） | 内件实际价值；已另行约定保价规则的从其约定 |
| 未保价·快递业务 | 运单格式条款封顶（常见**资费三倍**或固定上限） | 《民法典》运输合同项下**实际损失**赔偿 |
| 未保价·邮政普遍服务（平邮、挂号信、EMS 标准） | 《邮政法》的**三倍资费上限**口径 | 同样受限，可主张空间小于快递 |
| 价值算不出来时 | 三倍资费（兜底） | 三倍资费（兜底），补齐凭证后可主张更高 |

**关键动作**：主张时**两个数一起摆上桌**，附全套价值凭证。企业只会主动给它的那个数。

## 二、保价件怎么算

1. 保价额是**上限不是承诺**：赔的钱 = min(保价金额, 内件实际价值)。
   你把一件实际值 800 的东西保价 5000，超出部分拿不回来。
2. 保价凭证要留好：保价协议截图、付费记录、下单时的保价选项页面。
3. 保价了不等于一定按保价赔：如果保价条款本身存在无效情形（下面第三节），
   仍可主张实际损失。
4. 部分企业区分「保价」与「安心送/价值声明」：后者往往仍受三倍资费上限约束，
   要看条款原文，不要被名称误导。

## 三、「三倍 / 封顶」条款能不能用

快递运单背面的赔偿限制条款属于**格式条款**，不是你和小伙伴们商量出来的。

- 企业若援引它免除或减轻自身责任，须证明自己对该条款履行了**提示说明义务**
  （加粗、显著位置、单独签字或勾选确认等）。
- 未作提示说明、且明显减轻企业自身责任、排除你主要权利的，
  可以主张该条款**不成为合同内容**。
- 反过来，**你自己买了保价、勾选了赔偿条款、签字确认过的**，
  它对你就有约束力——别指望保价了还能按实际价值全额赔。

一句话：**小字不等于约定，签了字才算数。**

## 四、可主张口径里能算进「损失」的东西

| 项目 | 说明 |
|---|---|
| 内件本身价值 | 以交付或应当交付时该物品的市场价值为基准 |
| 已付运费 | 没送到，运费本身也是损失，可一并主张 |
| 包装费、保价费 | 交寄时实际支出的合理费用 |
| 其他直接损失 | 为这件货已经支出的、可直接对应的费用（如重新买的必要支出） |
| 可得利益 | 一般只在合同有约定或交易性质明确时才支持，别抱太高预期 |

**注意**："可得利益"是最容易被法院打折的一项，主张前先掂量证据。

## 五、价值证不出来怎么办

价值是整套核算的命门。举证顺序（能对应到**这一件**才有效）：

1. 发票 / 正规购买凭证（最硬）
2. 电商订单页 + 支付记录 + 商品快照（第二步）
3. 同类商品当时的市场价（询价记录、比价截图）
4. 二手平台同类成色成交价（作为参考，别当主证）
5. 称重 + 规格参数推算（最弱，只在其他都拿不出时用）

**重量记录很关键**：你的重量和企业系统重量对不上，企业会直接质疑内容物。
交寄前的称重照片、包装照片，比什么都管用。

## 六、企业常提的抗辩与应对

| 企业说法 | 怎么接 |
|---|---|
| 「最多赔三倍运费」 | 三倍是它援引的格式条款封顶；先问它有没有尽到提示说明义务，再摆可主张口径 |
| 「你没保价，自己承担」 | 未保价不等于免赔，按运输合同赔实际损失是默认规则 |
| 「已投递/已签收」 | 签收不等于交付有效：投递到代收点未经收件人同意的，不能以「已投递」免责 |
| 「重量与申报不符，疑似空包」 | 拿交寄称重照片、包装照片、价值凭证反打 |
| 「内件本身就不存在」 | 用价值凭证 + 重量 + 寄件前拍照形成闭环证据链 |
| 「已过期限，不受理」 | 自交寄之日起一年内提出；时效问题看第七段时限清单 |
