# 路径、时限与特殊场景

## 一、阶梯路径（从快到慢，别跳步）

**第 0 步（只要你是电商件就先走这条）**：在订单页点「未收到货」，由商家重新发货或退款。
理由很简单——卖家还没收到货、没责任，退起来最快，而且**不必你先证明内件值多少钱**。
卖家拖着或拒绝的，再往下走。

| 步 | 做什么 | 拿什么凭证 |
|---|---|---|
| 1 | 向快递企业客服**正式投诉并在系统里留单**，提供运单号、交寄时间、内件名称与价值、诉求金额 | **受理工单号**（没有工单号＝没投诉） |
| 2 | 一次申诉不成，向被投诉企业的省级机构 / 官方申诉入口做**二次申诉** | 申诉受理编号 |
| 3 | 拨打 **12305**（邮政业消费者申诉）：对企业处理结果不服或企业逾期未答复的，请求邮政管理部门裁定 | 申诉受理编号与裁定结果 |
| 4 | 涉及经营者违约、价值争议的，向 **12315（市场监管）** 或消协反映；物流服务消费纠纷也可打 12345 | 受理回执 |
| 5 | 仍不解决，提起民事诉讼，标的额小的走**小额诉讼** | 起诉状与全套证据 |

**顺序纪律**：先拿工单号，再谈金额；先企业后监管，别一上来就打 12305
（12305 通常要求先向企业投诉且对企业处理结果不服）。

## 二、时限清单

| 事项 | 期限 |
|---|---|
| 向企业提出赔偿请求 | 自交寄之日起**一年**内（越早越好） |
| 二次申诉 / 12305 申诉 | 对结果不服或企业逾期未答复的可请求裁定，一般 30 日内答复 |
| 民事诉讼时效 | **3 年**，自知道或应当知道权利受损及义务人之日起算 |
| 生鲜 / 易腐品 | 当场拍照 + 即时投诉，拖几天难度陡增 |
| 监控保全 | 投递点监控通常只有 7~30 天，疑似冒领**当天**要求 |
| 保价理赔申请 | 按企业规则在时限内提交，逾期会被拒 |

## 三、特殊场景分支

### 代收点 / 快递柜投递导致丢失
- 先核实：企业投递前是否**征得收件人同意**、有无投递通知（短信 / 电话 / 系统记录）。
- 未经同意放置到快递柜、驿站、门卫处的，企业不能以「已投递」为由免责——
  投递到代收点属于另一种交付方式，需用户同意。
- 你要的是：投递时间、柜号/点位、投递通知记录、监控。

### 被冒领 / 非本人签收
- 立即**报警**并索要报案回执；同时要求企业提供投递现场监控与签收影像。
- 代签、错领、重量不符的，都是关键线索。
- 冒领属第三人侵权，刑事上追责与民事上向企业索赔可以同时进行。

### 违禁品 / 限寄品
- 先核实内件是否真属禁寄范围（电池、液体、粉末、刀具、烟花、管制器具等）。
- 属实的话，企业依法可不赔或只按约定处理，别硬扛——先把事实搞清楚。

### 生鲜 / 冷链
- 当场拍照：外箱霜冻、化冻、变形、腐烂状态；有温度记录的（冷链车、保温箱温度计）一并留存。
- 价值随时间快速贬损，**当场固定**比事后回忆有用一百倍。

### 国际件 / 跨境件
- 先分清渠道：走**邮政渠道**（含邮政小包、国际挂号）的，未保价适用三倍资费口径；
  走**商业快递**的，按其国际运单条款与申报价值处理。
- 跨境件还可能涉及报关、保险、目的国清关责任，索赔主体与适用法都不同。
- 中转环节丢失的，多半要向起运地企业或邮政方主张，别只盯末端派送。

### 邮件/快件延误与部分损毁
- 内件部分损坏（外观完好、内件破损）也适用本流程，价值按**贬值后差额**主张：
  可主张口径 = 原价值 − 残值，别整件重买算一遍。

## 四、现实预期管理

- 打客服前一天：把运单号、价值凭证、轨迹截图整理成一个文件夹。
- 第一次电话只做一件事：**留工单号**。挂了再补材料，别在电话里吵金额。
- 二次申诉前：把第一次的工单号、答复内容、你的诉求金额写清楚再提交。
- 12305 之前：手上必须有「企业工单号 + 企业拒赔或不作为的证据」。
