# 快递丢失赔偿核算

寄出去的东西丢了，客服一句"最多赔三倍运费"就打发了？那三倍到底能不能不算、
该怎么往回要，是这套技能要解决的核心问题。

## 它算什么

- **企业口径**：企业按自家运单格式条款能给你的最大数（未保价常见 = 资费 × 3；
  保价件 = 保价金额，但不超过实际价值）
- **可主张口径**：按《民法典》运输合同下实际损失赔偿能主张的数（内件实际价值 +
  合理的其他直接损失）
- **两个数差多少**：同一个案子的两个答案，报告直接算出差额，并指出哪一套对你更有利

## 它管什么场景

| 场景 | 处理要点 |
|---|---|
| 代收点 / 快递柜投递导致丢失 | 先核实企业是否**未经同意放置**，未经同意的不能以「已投递」免责 |
| 被冒领 / 非本人签收 | 立即报警要回执，同时索要投递监控与签收影像（留存期 7~30 天） |
| 违禁品 / 限寄品 | 企业依法可不赔或只按约定处理，单独标注 |
| 生鲜 / 冷链腐烂变质 | 当场拍照、立即投诉，价值随时间快速贬损 |
| 国际件 / 跨境件 | 分清走的是邮政渠道（三倍资费口径）还是商业快递（国际条款） |
| 电商件 | 优先找卖家在订单页点「未收到货」，不必自己打快递官司 |

## 输出长什么样

十段 Markdown 报告：结论摘要 → 两套口径对比 → 赔偿测算（含算式）→ 责任与举证 →
场景分支 → 阶梯路径 → 时限 → 证据缺口 → 待办补正 → 边界与纪律。
支持 `--json` 输出，可被程序解析（`结论` / `风险项` / `待办`）。

## 一句话边界

依《邮政法》《民法典》运输合同及《快递市场管理办法》**通用规则**整理，
**不替代律师意见**，最终以主管部门认定与司法机关裁判为准。
