# 消防安全评估报告核查（fire-safety-assessment-check）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《消防安全评估规范》（XF/T 3005）与GB 35181，核查第三方消防安全评估报告的完整性与结论合规性：评估范围、方法、隐患分级与整改建议。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 消防安全评估
- 评估报告
- 风险评估
- 评估结论
- 评估机构产出

## 三、工作流
1. 确认评估依据（XF/T 3005等）与范围
2. 核对评估方法（检查表/模拟/专家）
3. 隐患分级与重大判定（GB 35181）
4. 整改建议时限与责任
5. 评估机构资质与签章

## 四、核心内容（检查清单与判定）
XF/T 3005 规定评估应包含单位消防安全基本情况、评估方法、火灾隐患认定、整改建议；重大火灾隐患直接/综合判定按GB 35181。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未列评估依据与范围 | XF/T 3005 |
| Q2 | FAIL | 无明确隐患分级或重大判定 | GB 35181 |
| Q3 | WARN | 整改建议缺时限与责任主体 | 整改 |
| Q4 | FAIL | 评估机构资质/签章缺失 | 合规 |
| Q5 | WARN | 缺现场核查/资料验证说明 | 方法 |

> 脚本 `fire-safety-assessment-check_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python fire-safety-assessment-check_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python fire-safety-assessment-check_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
