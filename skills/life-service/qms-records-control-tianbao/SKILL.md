# 质量记录归档与追溯（qms-records-control）

质量记录是体系的"黑匣子"：**该签的没签、该填的空着、该留的销毁了**——出了纠纷，空白的记录比没有记录更糟。

这个技能做四件事：**列清单** → **定规矩** → **管归档** → **控期限**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 讲解记录受控管理方法 | ❌ 替代法定记录义务 |
| 生成归档清单与填写规范 | ❌ 保证记录真实 |
| 整理保存期限与销毁口径 | ❌ 替代档案管理法规要求 |

**永远不要**补记录、代签字、撕页重写——记录的真实性是底线；缺了可以补执行，不能补记录。

---

## 一、什么时候用这个技能

| 用户这样说 | 就用 |
|---|---|
| "质量记录要管哪些" | ✅ |

| "电子记录怎么备份" | ✅ |
| "记录能划改吗" | ✅ |
| "这批记录能销毁吗" | ❌ 先查期限和审批 |

## 二、完整工作流

```
第 1 步  明确场景：建记录清单 / 填写规范培训 / 归档整理 / 期限到期 / 电子化
第 2 步  读规则文件 rules/records_rules.md
第 3 步  按场景取用：
    - 列清单 → 记录清单（第三节）
    - 定规矩 → 填写五不（第四节）
    - 管归档 → 归档与检索（第五节）
    - 控期限 → 保存与销毁（第六节）
    - 体检表 → python scripts/record_check.py --file 记录.json
第 4 步  按 templates/记录归档清单.md 输出
第 5 步  人工确认：必填项、笔迹、归档位置
```

## 三、记录清单（按过程建立）

| 过程 | 典型记录 |
|---|---|
| 市场/合同 | 合同评审记录、顾客沟通记录 |
| 设计开发 | 立项、评审、验证、确认、变更记录 |
| 采购 | 供方评价、采购单、进货检验 |
| 生产 | 作业指导书执行记录、过程参数、设备点检 |
| 检验 | 进货/过程/最终检验记录、试验报告 |
| 设备 | 台账、点检、维护、校准证书 |
| 不合格 | 不合格品处置单、围堵记录 |
| 改进 | 内审、管理评审、纠正措施 |
| 人员 | 培训、特殊岗位资质 |

> 每份记录要有：**编号、版本、保存期限、责任岗位**。

---

## 四、填写五不

1. **不空栏**——无内容填"无"或"/"，不空白
2. **不撕页**——作废页留存，标注"作废"
3. **不改写**——划改留痕：单线划掉、旁边重写、签改人名+日期
4. **不代签**——谁的责任谁签字
5. **不后补**——当时事当时记，不得倒填日期

---

## 五、归档与检索

- **标识**：编号 + 名称 + 版本，与文件受控清单对应
- **归档**：按月/按批次装订，目录清晰，专柜专人
- **检索**：能按产品批次/日期/编号任一维度查到
- **电子化**：扫描件与原件一致；电子记录定期备份、权限受控

---

## 六、保存期限与销毁

| 类型 | 期限口径 |
|---|---|
| 一般质量记录 | 按体系文件（常见 3 年） |
| 产品相关记录 | 产品保质期 + 法规要求（寿命长的按更长） |
| 涉及法规/顾客要求的 | 从其规定 |
| 电子记录 | 定期备份，迁移时保持可读 |

**销毁**：到期记录填写销毁清单，部门负责人 + 质量负责人审批后监销；未到期不得销毁。

---

## 七、脚本用法（记录体检）

```bash
python scripts/record_check.py --file "D:\质量\记录.json"
```

脚本检查四类问题：**必填项空缺、日期逻辑错误、签名缺失、归档要素不全**。

> ⚠️ 脚本只做结构与逻辑检查，**不判定记录内容真伪**。

---

## 八、人工确认（这步不能省）

- [ ] 必填项是否逐项落实（含"无"的规范填写）
- [ ] 划改是否规范留痕
- [ ] 签字是否本人、岗位是否匹配
- [ ] 归档位置与目录是否一致
- [ ] 电子记录备份周期与权限
- [ ] 到期销毁是否履行审批

---

## 九、输出结构（固定三段）

1. **记录什么状态**——结论先行：受控有效 / 有缺口 / 有红线问题
2. **核对清单**——逐项标合规/缺失/存疑
3. **整改与补资料建议**——先后顺序、责任岗位、留存材料

## 十、最常见的坑

**坑一：空白栏当默认。** 检验记录"检验结论"栏常年空白，出了事说不清。

**坑二：签字一笔签全组。** 一个人代签一个班组的记录。

**坑三：记录写完没人归。** 桌面堆半年，审计时现找。

**坑四：电子档只存一份。** 硬盘一坏，三年记录归零。

**坑五：到期一把火烧。** 没审批、没清单，涉诉时举证不能。

## 十一、边界与免责

- 本技能**不替代**法定记录义务；保存期限**以法规、顾客要求和本单位体系文件为准**
- 不得依据本技能伪造、补写、代签任何记录
- 规程要点为管理实践方法论整理，**不构成执法或认证结论**
