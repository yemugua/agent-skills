# 记录控制规则库（records_rules）

> 本文件是 qms-records-control 技能的规则支撑。条款以 ISO 9001 现行版本为准。

## 一、法规依据速查

| 文件 | 关键要求 | 关联 |
|---|---|---|
| ISO 9001 | 7.5 成文信息：标识、贮存、保护、检索、保留期限 | 记录控制来源 |
| 《档案法》 | 档案管理一般要求 | 法律口径 |
| 顾客/法规特殊要求 | 从优执行 | 特殊期限 |

## 二、填写五不判定口径

| 规则 | 判定 |
|---|---|
| 不空栏 | 必填项空 FAIL |
| 不撕页 | 缺页 WARN |
| 不改写 | 无留痕划改 FAIL |
| 不代签 | 签字人与岗位不符 FAIL |
| 不后补 | 日期逻辑错误 FAIL |

## 三、保存期限口径

| 类型 | 期限 |
|---|---|
| 一般质量记录 | 体系文件规定（常见 3 年） |
| 产品相关 | 保质期 + 法规 |
| 法规/顾客要求 | 从其规定 |

## 四、销毁口径

到期记录 → 销毁清单 → 部门负责人 + 质量负责人审批 → 监销；未到期不得销毁。

## 五、电子记录口径

- 扫描件与原件一致
- 定期备份（周期写入制度）
- 权限受控、迁移保持可读

## 六、常见不合规情形

- 关键栏空白
- 一人代签一组
- 记录堆积不归档
- 电子档单份无备份
- 到期无审批销毁
