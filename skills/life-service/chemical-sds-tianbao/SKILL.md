# 化学品 SDS 管理（chemical-sds）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据 GB/T 16483《化学品安全技术说明书 内容和项目顺序》与 GHS，生成化学品 SDS 管理清单：SDS 获取与合规、16 项内容核查、标签与分类、传递与培训、更新与应急。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 化学品SDS
- 安全技术说明书
- MSDS
- GHS标签
- 化学品分类

## 三、工作流
1. 收集并建立化学品台账与SDS
2. 核查SDS 16项内容完整性
3. 核对GHS分类与标签
4. 向使用岗位传递并培训
5. 跟踪版本更新与应急处置信息

## 四、核心内容（检查清单与判定）
GB/T 16483 规定 SDS 的 16 项内容结构，GHS 统一分类与标签；SDS 须随化学品传递至使用岗位并定期更新，支撑应急与防护。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含化学品台账与SDS获取 | 台账 |
| Q2 | FAIL | 未含SDS 16项内容核查 | 内容 |
| Q3 | WARN | 未含GHS分类与标签 | 标签 |
| Q4 | FAIL | 未含传递与培训 | 传递 |
| Q5 | WARN | 未含更新与应急信息 | 更新 |

> 脚本 `chemical-sds_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python chemical-sds_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python chemical-sds_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
