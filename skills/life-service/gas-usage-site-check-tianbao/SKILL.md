# 燃气使用场所消防安全检查（gas-usage-site-check）

燃气事故三件套：**漏气、聚集、遇火**。检查的意义就是让这三件事凑不到一起——早点发现漏、早点切断、早点通风。

这个技能做四件事：**查泄漏感知** → **查管路设备** → **查钢瓶存放** → **管日常巡查**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 讲解用气场所检查方法与要点 | ❌ 替代法定检验、维修与监管要求 |
| 生成检查表与体检报告 | ❌ 维修燃气设施 |
| 整理泄漏应急流程 | ❌ 保证处置结果 |

**闻到燃气味/怀疑泄漏，第一步：关阀、通风、禁火禁电（不开关任何电器、不在现场打电话）、撤人、到室外报警。不得在现场开关电器、使用明火或拨打电话。**

**永远不要**自行拆卸、改装燃气设施；钢瓶不得倾倒、加热、拆修阀件。

## 二、完整工作流

```
第 1 步  明确用气类型（管道气/瓶装气）与场所（餐饮/商业/工业）
第 2 步  读规则文件 rules/gas_rules.md
第 3 步  查感知：报警器+紧急切断（第三节）
第 4 步  查管路：软管/灶具/管道（第四节）
第 5 步  查钢瓶：数量/存放/检验（第五节）
第 6 步  跑体检 → python scripts/gas_site_check.py --file 燃气场所.json
第 7 步  按 templates/燃气场所检查表.md 输出
```

## 三、泄漏感知（报警 + 切断）

| 项目 | 要求（通行口径） |
|---|---|
| 报警器安装 | 用气场所（尤其地下室、半地下室、密闭空间）应设可燃气体报警装置 |
| 安装位置 | 靠近顶棚（气态燃气密度小于空气）或按气体密度确定 |
| 联动要求 | 报警信号联动**紧急切断阀**切断气源，联动信息传至有人值守处 |
| 定期检定 | 报警器按说明书周期检定/更换 |
| 通风 | 用气场所通风良好，不得设在地下室（瓶装气禁用地下） |

> 具体设置要求**以《城镇燃气管理条例》GB 50028 等现行规定为准**。

---

## 四、管路与设备

1. **连接管**：优先不锈钢波纹管或金属包覆软管；普通橡胶软管限期更换（通行口径 ≤ 18 个月）；不得穿墙、穿顶棚、超长。
2. **灶具**：带熄火保护装置；与可燃物保持距离；商用灶具按规范设防爆措施。
3. **管道**：无锈蚀、无私接；管道穿越部位按规范处理；不得作负重接地。
4. **阀门**：完好、可操作、标识清晰；用气完毕关阀。
5. **配电**：用气场所电气按爆炸危险环境选型（防爆要求场所）。

---

## 五、瓶装气管理

| 项目 | 要求 |
|---|---|
| 数量 | 按场所与规范控制（餐饮场所存量从严，通行口径如 50kg 钢瓶限量） |
| 存放 | 通风良好、防晒、防倾倒、直立固定；空瓶实瓶分区 |
| **禁用场所** | 地下室、半地下室、密闭空间、人员密集场所地上部分按规范限制 |
| 检验 | 钢瓶在检验有效期内 |
| 交接 | 实名登记、不超期存放 |

## 六、泄漏应急处置（人人要知道）

```
闻到味 → 关阀断气 → 开窗通风 → 禁火禁电禁开关 → 撤出人员 → 室外拨打抢修/119
```

- **不得**在现场开关任何电器（包括电灯、排风扇、门铃）
- **不得**使用明火查漏（用肥皂水涂接口看气泡）
- 大量泄漏时划定警戒区，防止气体低洼处聚集

---

## 七、脚本用法（检查表体检）

```bash
python scripts/gas_site_check.py --file "D:\消防\燃气场所.json"
```

脚本检查五类问题：**报警/切断缺失、软管超期或违规穿墙、钢瓶超量或违规存放、设备缺熄火保护、巡查记录断档**。

> ⚠️ 脚本只做结构与逻辑检查，**不判定现场实际安全状态**。

---

## 八、人工确认（这步不能省）

- [ ] 报警器是否真通电、探头是否被油污糊死（餐饮后厨通病）
- [ ] 紧急切断阀是否每月手动测试
- [ ] 钢瓶存量与存放间是否符合要求
- [ ] 软管有无老化、龟裂、鼠咬
- [ ] 员工是否都知道泄漏处置三步
- [ ] 与燃气公司、物业的联动电话是否上墙

---

## 九、输出结构（固定三段）

1. **能不能过**——结论先行：合规 / 有缺口 / 有红线问题
2. **核对清单**——逐项标合规/缺失/存疑
3. **整改与补资料建议**——先后顺序、责任岗位、留存材料

## 十、最常见的坑

**坑一：报警器被油泥封死。** 装是装了，探头糊满油垢，漏气不报警。

**坑二：切断阀装了不测试。** 报警响了阀不动，等于没有。

**坑三：软管穿墙走顶。** 方便了美观，漏了看不见。

**坑四：钢瓶堆在后厨角落。** 几瓶挤在热水器边上，遇火就是连环爆。

**坑五：泄漏时开排风扇。** 一个开关打出电火花，爆炸就在这一秒。
