# 情绪记录方法与复盘

情绪记录的价值**不在于记录当下，而在于回看时能看出模式**。写下来当天不会让你好受，但几周后回看能回答「我到底在什么情况下最容易难受」。

## 一、硬边界（能做 / 不能做）

| 能做 | 不能做 |
|---|---|
| 给出结构化记录模板与填写方法 | 提供心理诊断或判断是否患有心理疾病 |
| 说明频次安排与模式识别方法 | 替代专业心理治疗 |
| 帮助识别重复出现的触发模式 | 保证「记录能改善情绪」 |
| 提示什么时候该寻求专业帮助 | 处理危机状态或自伤风险（须转介） |
| 给出复盘方法 | 评价用户的情绪「想太多」或「不该有」 |

**本技能不提供诊断，不替代专业心理治疗。严重或持续的症状请寻求专业评估。**

## 二、求助红线（必须先看这一节）

**出现以下任何一项，请立刻寻求专业帮助或拨打当地心理援助热线 / 急救电话，不要仅靠自我记录处理：**

| # | 红线信号 | 为什么必须求助 |
|---|---|---|
| 1 | **自伤或自杀的念头、计划，或工具已在手** | 属危机状态，需即时人工支持 |
| 2 | 持续两周以上情绪低落、兴趣丧失 | 已达到需专业评估的时长 |
| 3 | 失眠或嗜睡、食欲骤变、体重明显变化 | 躯体症状已明显 |
| 4 | 无法正常工作生活、社会功能明显受损 | 需要专业干预 |
| 5 | 出现幻觉或妄想 | 需立即评估 |
| 6 | 躁狂表现：少睡却不困、异常兴奋、思维奔逸 | 需立即评估 |
| 7 | 严重焦虑伴惊恐反复发作 | 需专业治疗 |
| 8 | 进食障碍倾向：体重骤降、催吐、过度运动 | 需专业干预 |
| 9 | 物质滥用失控 | 需专业干预 |

**第 1 项是最高优先**：如果你正处在自伤或自杀念头中，请立即联系身边可信任的人，并拨打当地心理援助热线或急救电话。情绪记录工具**不能**用于处理这类状态。

## 三、什么时候用

| 用户说法 | 用不用 | 说明 |
|---|---|---|
| 情绪日记怎么写 | 用 | 走六栏模板 |
| 想找出情绪的规律 | 用 | 走模式识别方法 |
| 写完反而更焦虑 | 用 | 走防止反刍的设置 |
| 情绪反复但说不清 | 用 | 走触发事件—想法—结果链条 |
| 什么时候该看医生 | 用 | 走求助红线表 |
| 我是不是抑郁了 | **不做诊断** | 引导按红线自检并建议专业评估 |

## 四、完整工作流

### 步骤 1：先过一遍求助红线

**任何记录之前先做这一步。** 命中红线就直接转介，不进入记录流程。

### 步骤 2：用六栏模板记录

触发事件 → 身体反应 → 情绪与强度 → 想法 → 行为 → 结果。

### 步骤 3：设置「担忧时段」而非全天反刍

**记录不是反刍。** 每天固定一个时段处理情绪记录，其余时间遇到难受先记关键词，留到时段再展开。

### 步骤 4：每周回看，找模式

**回看比记录本身更有价值**，见第六节。

## 五、核心规则（记录前必读）

**先读 `rules/情绪记录模板与模式识别.md`，不要凭印象写。**

### 六栏记录模板

```
1. 触发事件：（具体到场景与行为，不写「今天很烦」）
2. 身体反应：（胸闷/心跳快/肩紧/胃部不适/脸发热）
3. 情绪与强度：（情绪名称 + 0 到 10 强度，10 为最难忍）
4. 想法：（当时脑子里的具体句子，原样记）
5. 行为：（我做了什么，说了什么）
6. 结果：（后来怎样，情绪是否变化）
```

**「想法」栏是最重要的一栏**——情绪的维持往往靠想法，而不是靠事件本身。**原样记下当时的句子**，不要改写成理性版本。

### 频次建议

| 方式 | 建议 | 说明 |
|---|---|---|
| 每日简记 | 每天 1—2 条 | 保持连续性，比事后补记有用 |
| 集中处理 | 每天固定 15 分钟 | 防止全天反刍 |
| 每周回看 | 每周 1 次 | **这一步才是产生价值的地方** |

**不建议的做法**：全天随时记录并反复回看当日情绪。

## 六、长期回看的价值（模式识别）

**单条记录没有价值，成组记录才有价值。** 常见可发现的模式：

| 模式 | 从记录中怎么看 |
|---|---|
| **特定人物触发** | 触发事件栏反复出现同一个人 |
| **特定时段触发** | 时间集中在某些时段 |
| **特定需求未被满足** | 想法栏反复出现同类句子 |
| **同一种身体反应** | 身体反应栏高度重复 |
| **行为模式固化** | 行为栏总是同一种反应（如总是回避） |
| **强度递增** | 同类事件强度逐周上升 |

**强度递增是重要信号**——说明压力在累积，应主动求助而非继续硬扛。

## 七、注意事项（防止记录变成伤害）

| 注意事项 | 说明 |
|---|---|
| **设置担忧时段** | 每天固定时段处理，其余时间只记关键词 |
| **不做自我审判** | 记录是观察，不是审判；不写「我怎么这么差」 |
| **不追求完整** | 漏记好过勉强填 |
| **不与他人比较** | 情绪没有优劣 |
| **记录后要有收尾动作** | 写完写一句「现在最需要的一件事」，避免停在痛苦里 |
| **正向事件也要记** | 只记负面会让记录变成痛苦清单 |

**如果记录让你更焦虑，说明用法有问题**：立即改为「只记关键词 + 固定时段展开」，或暂停记录并寻求专业支持。

## 八、脚本用法

脚本：`scripts/emotion_log_stats.py`

```bash
python scripts/emotion_log_stats.py --file 记录.json
python scripts/emotion_log_stats.py --selftest
```

| 字段 | 说明 |
|---|---|
| `entries` | 记录列表，含 trigger/body/emotion/intensity/thought/behavior/result |
| `self_critical` | 自我审判类表述标签 |
| `concern_window` | 是否已设置担忧时段 |

输出：强度趋势、重复触发人物、重复身体反应、常见想法、强度递增预警、求助红线命中提示。

## 九、人工确认清单（不能省）

- [ ] **是否已先过求助红线**（尤其是自伤念头与持续两周以上低落）？
- [ ] 记录是否写的是**具体场景与行为**，而不是笼统感受？
- [ ] 「想法」栏是否**原样记录**未做理性化改写？
- [ ] 身体反应是否记录（这是识别模式的锚点）？
- [ ] 是否设置了**固定担忧时段**避免全天反刍？
- [ ] 是否有每周回看（而不是只记不看）？
- [ ] 是否记录了正向事件（避免记录变成痛苦清单）？
- [ ] 写完后是否有收尾动作，避免停在痛苦里？
- [ ] 是否已识别出强度递增趋势？

## 十、最常见的坑

1. **只写「今天很烦」**。没有具体触发事件，模式无从识别。
2. **不记身体反应**。身体反应是识别模式最稳定的锚点。
3. **把想法改写成理性版本**。改写后就看不到当时真正驱动情绪的东西了。
4. **全天随时记录并反复回看**。这叫反刍，会让情绪更糟。
5. **把记录变成自我审判**。「我怎么这么差」不是记录，是攻击自己。
6. **只记负面不记正向**。会让记录越看越沉。
7. **从不回看**。记录本身不产生价值，回看才产生。
8. **追求记满不漏**。勉强填的内容没有信息量。
9. **强度递增仍继续硬扛**。这是应主动求助的信号。
10. **用记录工具处理危机状态**。自伤念头必须转介，记录工具无效。

## 十一、边界与免责

本技能提供情绪记录的模板与方法，**不提供诊断，不替代专业心理治疗，不保证记录能改善情绪**。情绪记录的效用因人而异，若记录后情绪加重，请暂停并寻求专业评估。出现求助红线中的任何情形，请立即联系专业机构或拨打当地心理援助热线与急救电话。本技能不替代医疗诊断与治疗。
