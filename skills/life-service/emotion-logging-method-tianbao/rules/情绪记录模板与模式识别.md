# 情绪记录模板与模式识别

> 记录前必读。**先过求助红线，再进记录流程。**

## 零、求助红线（先看）

**命中以下任一项，立刻寻求专业帮助或拨打当地心理援助热线 / 急救，不要仅靠自我记录处理。**

| # | 红线信号 | 性质 |
|---|---|---|
| 1 | 自伤或自杀的念头、计划，或工具已在手 | 危机，最高优先 |
| 2 | 持续两周以上情绪低落、兴趣丧失 | 时长已达专业评估门槛 |
| 3 | 失眠或嗜睡、食欲骤变、体重明显变化 | 躯体症状明显 |
| 4 | 无法正常工作生活、社会功能受损 | 需专业干预 |
| 5 | 出现幻觉或妄想 | 需立即评估 |
| 6 | 躁狂表现：少睡却不困、异常兴奋、思维奔逸 | 需立即评估 |
| 7 | 严重焦虑伴惊恐反复发作 | 需专业治疗 |

**第 1 项处理顺序**：立即联系身边可信任的人 → 拨打当地心理援助热线或急救电话 → 不要独处。

## 一、六栏记录模板

```
日期时间：
1. 触发事件：（具体到场景与行为，不写「今天很烦」）
2. 身体反应：（胸闷/心跳快/肩紧/胃部不适/脸发热/手抖）
3. 情绪与强度：（情绪名称 + 0 到 10，10 为最难忍）
4. 想法：（当时脑子里的具体句子，原样记）
5. 行为：（我做了什么，说了什么，逃开还是面对）
6. 结果：（后来怎样，情绪是否变化）
正向记录：（今天有什么好事，哪怕很小）
现在最需要的一件事：
```

### 各栏的填写要点

| 栏 | 要求 | 反例 |
|---|---|---|
| 触发事件 | 写**具体场景与行为** | 「今天很烦」 |
| 身体反应 | 写**身体感受**，不写情绪 | 「我很难过」（这是情绪不是身体） |
| 情绪与强度 | 情绪名 + 0—10 数字 | 只写情绪名无强度 |
| **想法** | **原样记当时的句子** | 改写成「我应该理性一点」 |
| 行为 | 写**做了什么** | 「我很难受」 |
| 结果 | 写后续实际发生什么 | 「以后会好」 |

**「想法」栏是最重要的一栏**：情绪的维持往往靠想法而不是事件本身，改写成理性版本就看不到驱动因素了。

## 二、频次安排

| 方式 | 建议 | 说明 |
|---|---|---|
| 每日简记 | 每天 1—2 条 | 保持连续性 |
| 集中处理 | 每天固定 15 分钟 | **防止全天反刍** |
| 每周回看 | 每周 1 次 | **产生价值的地方** |

**不建议**：全天随时记录并反复回看当日情绪（这是反刍）。

### 担忧时段设置（防反刍关键）

```
遇到难受时：先只记 1 个关键词（不展开）
固定时段（如晚 20:00）：用 15 分钟展开关键词为完整记录
其他时间：不回看、不反复想
```

## 三、模式识别（回看时重点看什么）

**单条记录没有价值，成组记录才有价值。**

| 模式 | 怎么看 |
|---|---|
| **特定人物触发** | 触发事件栏反复出现同一个人 |
| **特定时段触发** | 时间集中在某些时段 |
| **特定需求未被满足** | 想法栏反复出现同类句子 |
| **同一种身体反应** | 身体反应栏高度重复 |
| **行为模式固化** | 总是同一种反应（如总是回避、总是发火） |
| **强度递增** | 同类事件强度逐周上升 |

**强度递增是重要信号**：说明压力在累积，应主动求助而非继续硬扛。

## 四、防止记录变成伤害

| 注意事项 | 说明 |
|---|---|
| **设置担忧时段** | 固定时段处理，其余时间只记关键词 |
| **不做自我审判** | 记录是观察不是审判；不写「我怎么这么差」 |
| **不追求完整** | 漏记好过勉强填 |
| **不与他人比较** | 情绪没有优劣 |
| **写完有收尾动作** | 写一句「现在最需要的一件事」，避免停在痛苦里 |
| **正向事件也要记** | 只记负面会让记录变成痛苦清单 |

**如果记录让你更焦虑**：立即改为「只记关键词 + 固定时段展开」，或暂停记录并寻求专业支持。

## 五、常见错误对照

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 只写「今天很烦」 | 无具体触发点 | 写场景与行为 |
| 不记身体反应 | 失去模式锚点 | 记录身体感受 |
| 想法改写成理性版 | 看不到驱动因素 | 原样记录 |
| 全天随时记录反复回看 | 反刍，更糟 | 固定担忧时段 |
| 记录变成自我审判 | 攻击自己 | 记录是观察 |
| 只记负面 | 越看越沉 | 也记正向事件 |
| 从不回看 | 记录不产生价值 | 每周回看找模式 |
| 追求记满不漏 | 无信息量 | 允许漏记 |
| 强度递增仍硬扛 | 应主动求助 | 求助 |
| 用记录处理危机 | 工具无效 | 转介 |
