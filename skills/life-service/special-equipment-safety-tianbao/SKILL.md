# 特种设备安全（special-equipment-safety）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《特种设备安全法》与 TS.G 08，生成特种设备清单：设备类别（锅炉/压力容器/电梯/起重/厂内车）、使用登记与定期检验、作业人员持证、维护保养与应急。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 特种设备
- 电梯安全
- 压力容器
- 起重机械
- 锅炉
- 叉车
- 使用登记

## 三、工作流
1. 列出特种设备类别（锅炉/压力容器/电梯/起重/厂内车）
2. 使用登记与定期检验（检验合格标志）
3. 作业人员持证（司机/维保/管理）
4. 维护保养与自行检查
5. 应急预案与演练

## 四、核心内容（检查清单与判定）
《特种设备安全法》要求特种设备办理使用登记、定期检验并在检验有效期内使用；作业人员须持证上岗，使用单位应建立安全技术档案。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未列特种设备类别（锅炉/压力容器/电梯/起重/厂内车） | 类别 |
| Q2 | FAIL | 未含使用登记与定期检验（检验合格标志） | 登记 |
| Q3 | WARN | 未含作业人员持证（司机/维保/管理） | 持证 |
| Q4 | FAIL | 未含维护保养与自行检查 | 维保 |
| Q5 | WARN | 未含应急预案与演练 | 应急 |

> 脚本 `special-equipment-safety_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python special-equipment-safety_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python special-equipment-safety_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
