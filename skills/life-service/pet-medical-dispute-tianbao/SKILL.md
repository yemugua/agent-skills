# 宠物医疗纠纷与费用核查（pet-medical-dispute）

宠物医疗纠纷最难的不是吵赢，而是**证明**。

四个要件里，**诊疗过错**靠病历，**因果关系**靠尸检，**损害后果**靠票据。这三样少一样，主张就很难落地。

这个技能做五件事：**定类型** → **核证据** → **查收费** → **算赔偿** → **排路径**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 核查证据是否齐备、缺什么 | ❌ 判断诊疗行为是否有过错（需兽医专业意见） |
| 列出收费核查方法与争议项 | ❌ 认定机构一定乱收费 |
| 按参考口径测算赔偿范围 | ❌ 预测协商或裁判的具体赔偿数额 |
| 梳理维权路径与主管部门分工 | ❌ 代理投诉、代理诉讼 |
| 提示尸检与监控保全的紧迫性 | ❌ 代替兽医作出诊断或治疗方案 |

**遇到以下情况，务必寻求兽医专业意见或转交专业人士：**
- 需要判断诊疗行为是否符合诊疗规范（通常需要兽医专业意见或鉴定）
- 宠物仍在治疗中，需要立即的医疗决策
- 争议金额较大，或需要提起诉讼
- 涉及动物诊疗许可、执业兽医资格等专业监管问题

**永远不要在宠物刚死亡时就建议主人先火化或掩埋。** 尸体一处理，死因无法查明，因果关系基本断链。

## 二、完整工作流

```
第 1 步  分清是"证据问题"还是"收费问题"：--mode evidence 或 --mode fee
第 2 步  先读规则文件 rules/dispute_elements.md 与 rules/fee_check.md
第 3 步  跑核查脚本
    python scripts/pet_medical_check.py --mode evidence \
        --records medical_record,prescription,lab,detail,invoice,chat --death yes
    python scripts/pet_medical_check.py --mode fee --records detail,invoice \
        --itemized yes --price-posted no --charged 3800 --market 2200
第 4 步  逐项人工核对（脚本只做清单匹配，不做专业判断）
第 5 步  紧急动作：书面要求保存监控、死亡则尽快尸检
第 6 步  按协商 → 投诉 → 主管部门 → 诉讼的顺序推进
```

## 三、四个责任要件，最难过的是因果关系

| 要件 | 靠什么证明 |
|---|---|
| 诊疗行为存在 | 就诊记录、收费凭证、处方 |
| **存在过错** | 病历、化验与影像、知情同意书、兽医专业意见 |
| 有损害后果 | 死亡、伤残、额外支出、病情加重 |
| **因果关系** | **尸检或病理报告**（死亡情形）、连续诊疗记录 |

**宠物死亡后没有做尸检的，死因基本无法查明。** 这是这类纠纷主张落空的第一原因。死亡后应尽快尸检，勿先行火化或掩埋。

---

## 四、证据清单（详见 `rules/dispute_elements.md`）

| 类别 | 材料 | 紧迫性 |
|---|---|---|
| **病历资料** | 门诊/住院病历、手术记录、麻醉记录、护理记录 | 就诊时就索要，**事后补要可能被拒** |
| **化验与影像** | 化验单、影像片与报告 | 当场索取 |
| **处方与用药** | 处方笺、药品名称与剂量 | 当场索取 |
| **知情同意书** | 手术/麻醉/特殊检查同意书 | **签字前拍照** |
| **收费明细与发票** | 逐项明细 + 发票 | 要明细，不要只给总额 |
| **监控视频** | 诊疗区、寄养区监控 | **尽早书面要求保存**，会覆盖 |
| **尸检/病理** | 剖检报告、组织病理报告 | 死亡后尽快，勿先火化 |
| **机构资质** | 动物诊疗许可证、执业兽医资格 | 现场查看拍照 |
| **宠物价值** | 购买合同、付款凭证、血统证书 | 越早留存越好 |
| **沟通记录** | 微信、短信、录音**原始载体** | 不要只用截图 |

## 五、赔偿范围（通行口径）

| 项目 | 说明 |
|---|---|
| **已支出的医疗费** | 因过错导致的额外治疗、转院费用，凭票据 |
| **后续治疗费** | 必要后续治疗与康复费用，需医嘱或评估 |
| **宠物本身的价值** | 一般按购买价格并考虑饲养年限、品种、健康状况折减 |
| **必要的丧葬处理费** | 火化、无害化处理实际支出 |
| **鉴定费、尸检费** | 为查明事实支出的合理费用 |
| **精神损害** | 宠物一般作为物对待，**通常不予支持**；个别案例中法院可能就具有人身意义的特定物作出不同处理，以个案认定为准 |

**不要指望"宠物是家人"能直接换来精神损害赔偿。** 主张要落在财产损害与服务合同责任上。

## 六、十类常见乱收费（详见 `rules/fee_check.md`）

| 类型 | 核查方法 |
|---|---|
| **未做项目收费** | 逐项对账：收费项目 ↔ 报告单 |
| **重复收费** | 同一项目同一天收两次；耗材打包后单收 |
| **套餐式加项** | 对照主诉判断相关性 |
| **拆分收费** | 本属同一操作却拆成多项 |
| **耗材未告知** | 查是否有告知与确认 |
| **药品加成不透明** | 比对同类药品市场价 |
| **住院/寄养重复计费** | 查项目定义与是否告知 |
| **处置费虚无** | 「特殊处置费」无具体内容 |
| **加价未告知** | 手术中临时加项加价有无确认 |
| **不开发票** | 索要发票，支付记录也要留 |

**没有明细单，这些全都查不了。** 第一条动作永远是"要明细"。

## 七、维权路径与主管部门分工

```
第 1 步  固定证据 → 与机构协商，全程留痕
第 2 步  12315 / 消费者协会（价格、服务、虚假宣传）
第 3 步  农业农村主管部门（动物诊疗许可、执业兽医、病历处方管理、兽药使用）
第 4 步  市场监督管理部门（明码标价、价格欺诈、虚假宣传）
第 5 步  人民法院（服务合同纠纷 / 财产损害赔偿纠纷）
```

| 主管部门 | 管什么 |
|---|---|
| **农业农村主管部门** | 动物诊疗许可、执业兽医资格、病历与处方管理、兽药使用 |
| **市场监督管理部门 / 12315** | 明码标价、价格欺诈、虚假宣传、消费纠纷调解 |
| **人民法院** | 民事赔偿的最终裁判 |

## 八、脚本用法

```bash
# 证据完整性核查（宠物已死亡的会额外要求尸检与监控）
python scripts/pet_medical_check.py --mode evidence \
    --records medical_record,prescription,lab,detail,invoice,chat --death yes

# 费用核查
python scripts/pet_medical_check.py --mode fee --records detail,invoice \
    --itemized yes --price-posted no --charged 3800 --market 2200

# 顺带做赔偿参考测算
python scripts/pet_medical_check.py --mode evidence --pet-value 12000 --years 3 \
    --extra-cost 5000 --funeral 800
```

| 参数 | 说明 |
|---|---|
| `--mode` | `evidence` 证据核查 / `fee` 费用核查 |
| `--records` | 已取得材料：`medical_record` `prescription` `lab` `consent` `detail` `invoice` `chat` `video` `necropsy` `license` `value_proof` |
| `--death` | 宠物是否已死亡（为 `yes` 时额外要求尸检与监控） |
| `--itemized` / `--price-posted` | 是否有收费明细 / 是否明码标价 |
| `--charged` / `--market` | 实收总额 / 同类市场参考价 |
| `--pet-value` / `--years` | 宠物购买价 / 已饲养年限（赔偿折减） |
| `--extra-cost` / `--funeral` | 额外治疗费 / 丧葬或无害化处理费 |
| `--out` / `--format` | 输出路径 / `md` 或 `json` |
| `--selftest` | 跑内置自检（13 条断言） |

赔偿测算按 **10 年参考饲养年限**折减宠物价值（残值 = 购买价 ×（10 − 已饲养年限）/ 10），并加计额外治疗费与丧葬费。

> ⚠️ 脚本只做清单匹配与参考口径测算，**不判断诊疗是否有过错**。折减口径与赔偿项目以协商或争议处理机构的认定为准。

## 九、人工确认清单（这步不能省）

**就诊与事发后：**

- [ ] 病历、处方、化验与影像资料已全部索取并拍照
- [ ] 收费明细与发票已取得（不是只有总额）
- [ ] 知情同意书已留存（签字前有拍照）
- [ ] 已**书面**要求机构保存监控录像
- [ ] 死亡的已做尸检或病理检查，未先行火化或掩埋
- [ ] 沟通记录保留原始载体，不只截图
- [ ] 已核实机构《动物诊疗许可证》与执业兽医资格
- [ ] 宠物购买凭证、疫苗驱虫记录已找到

**主张前：**

- [ ] 已分清是收费争议还是诊疗过错争议，**分开主张**
- [ ] 争议金额已逐项列出并要求对方提供对应凭证
- [ ] 已按协商 → 投诉 → 主管部门 → 诉讼排序
- [ ] 时效未过（普通诉讼时效一般为 3 年）

## 十、最常见的坑

**坑一：就诊时不索要病历。**
事后机构补不出或不配合，诊疗过错根本无从判断。第一次就诊就要。

**坑二：宠物死了先火化、先埋了。**
尸检是查明死因唯一可靠手段，尸体一处理，因果关系就断链。

**坑三：不要求保存监控。**
监控一般几周到一个月就覆盖，晚一步就没了。

**坑四：只拿总额票据不要明细。**
没有明细就无法核查未做项目收费与重复收费。

**坑五：只截图不保留原始记录。**
微信截图证明力弱，原始手机与聊天记录才是可靠证据。

**坑六：在协商中笼统承认"我自己也有责任"。**
可能被对方引用。表述要具体到事实，不做责任判断。

**坑七：签知情同意书不看内容。**
签了不等于机构全免责，但确实增加了举证难度。签字前拍照。

**坑八：把希望寄托在精神损害赔偿上。**
宠物一般作为物对待，精神损害赔偿通常不予支持。

**坑九：把收费争议和诊疗过错混在一起谈。**
焦点模糊，两边都谈不下来。分开主张，各自举证。

**坑十：找了没有《动物诊疗许可证》的机构。**
违法诊疗，维权时连基本诊疗规范都无从对照。选机构时先查资质。

## 十一、输出结构（固定五段）

1. **结论先行** —— 证据是否齐备 / 费用凭证是否完整 / 卡在哪一项
2. **证据核查表** —— 逐项标符合 / 需核实 / 缺失，附紧迫性提示
3. **费用核查表** —— 明细、明码标价、发票、市场价对比与差异金额
4. **赔偿参考测算** —— 宠物价值折减、额外治疗费、丧葬费、合计
5. **维权路径** —— 五步顺序与主管部门分工

---

## 十二、边界与免责

- 本技能**不判断诊疗行为是否有过错**，这需要兽医专业意见或鉴定
- 赔偿范围与折减口径为通行做法，**以协商或争议处理机构的认定为准**，本技能不引用具体条款号
- **不代理投诉、不代理诉讼、不预测赔偿数额**
- 宠物在法律上一般作为物（财产）对待，精神损害赔偿通常不予支持
- 动物诊疗仍在进行的，应优先保障宠物得到及时救治
