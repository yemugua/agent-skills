# 宠物医疗费用核查与常见乱收费识别

> 动物诊疗收费实行市场调节价，经营者应当**明码标价**；价格欺诈、虚假宣传由市场监督管理部门监管。**以现行规定与属地主管部门要求为准**，本文件只给核查方法论，不引用具体条款号。

## 一、核查的四个层次

| 层次 | 核什么 | 常见发现 |
|---|---|---|
| 1. **有没有明细** | 是否提供逐项收费清单 | 只有总额、手写便条、加了微信发个数字 |
| 2. **做没做这项** | 项目是否实际实施 | 收了检查费但没有检查报告 |
| 3. **收得合不合理** | 是否明码标价、是否与公示价一致 | 现场报价与结算价不一致 |
| 4. **有没有必要** | 项目与主诉是否相关、是否重复 | 与主诉无关的"套餐"检查 |

**没有明细单，后面三层全都查不了。** 所以第一条动作永远是"要明细"。

## 二、明码标价要求

| 要点 | 说明 |
|---|---|
| 应当明码标价 | 诊疗服务项目、药品、耗材等应公示价格 |
| 公示形式 | 价目表、电子屏、公示栏等，置于经营场所显著位置 |
| 结算一致 | 实际结算价格应与公示价格一致，加价前应告知 |
| 价格欺诈 | 虚构原价、虚假优惠、低价诱导高价结算等属于价格违法行为 |
| 未标价的后果 | 可向市场监督管理部门反映 |

## 三、常见乱收费类型

| 类型 | 表现 | 核查方法 |
|---|---|---|
| **未做项目收费** | 收了某项检查费但无对应报告单 | 逐项对账：收费项目 ↔ 报告单 |
| **重复收费** | 同一项目同一天收两次；耗材打包再单收 | 看日期与项目名是否重复 |
| **套餐式加项** | 与主诉无关的"全面体检""必查套餐" | 对照主诉判断相关性 |
| **拆分收费** | 一个处置拆成多项分别计价 | 看项目是否本属同一操作 |
| **耗材不加告知** | 耗材、处置费未提前告知即收取 | 查是否有告知与确认 |
| **药品加成不透明** | 药品价格显著高于市场价且未告知 | 比对同类药品市场价 |
| **住院/寄养重复计费** | 已收住院费另收护理费、看护费且未说明 | 查项目定义与是否告知 |
| **处置费虚无** | "特殊处置费""专家费"无具体内容 | 要求说明具体处置内容 |
| **加价未告知** | 手术中临时加项目、加价，未取得确认 | 查是否有书面或可查的确认 |
| **不开发票** | 只给手写收据或什么都没有 | 索要发票，支付记录也要留 |

## 四、费用核查操作步骤

```
第 1 步  索要逐项收费明细清单（含项目名、单价、数量、日期）与发票
第 2 步  把明细与病历、化验报告、影像报告、处方逐项对账
第 3 步  标出三类问题：无对应报告的项目 / 重复项 / 与主诉无关项
第 4 步  比对明码标价公示价与实际结算价
第 5 步  汇总争议金额，先书面问询机构，再决定是否投诉或诉讼
```

## 五、争议金额的表达方式（决定了对方会不会理你）

| 写法 | 效果 |
|---|---|
| 「收费太贵了，不合理」 | 主观，机构可直接拒绝 |
| 「某月某日收取 CT 检查费 800 元，病历与影像系统内均无对应检查记录，请提供该次检查报告或退还该费用」 | 具体、可核查、可回应 |

**逐项列明 + 要求对方提供对应凭证**，是把争议从情绪拉回事实的最有效方式。

## 六、与诊疗过错的区分（别混在一起）

| 争议 | 走哪条路 | 举证重点 |
|---|---|---|
| **收费不合理** | 价格与消费纠纷 → 12315 / 市场监管 | 明细、公示价、支付凭证 |
| **诊疗有过错** | 服务合同 / 财产损害 → 协商 → 诉讼 | 病历、知情同意、尸检、因果关系 |
| **无资质行医** | 违法诊疗 → 农业农村主管部门 | 机构与人员资质证据 |

**收费问题和医疗过错是两件事。** 把两者混在一个诉求里，会让争议焦点模糊，反而都谈不成。分开主张，各自举证。

## 七、预防：就诊前就该做的六件事

| # | 动作 | 为什么 |
|---|---|---|
| 1 | 查看《动物诊疗许可证》与执业兽医资格公示 | 无资质的机构，出事连诊疗规范都无从对照 |
| 2 | 初诊时就索要并留存病历 | 事后补要可能被拒 |
| 3 | 检查项目要求先报价、后实施 | 避免结算时出现未告知项目 |
| 4 | 手术/麻醉前签知情同意书，**签字前拍照** | 明确告知内容与风险 |
| 5 | 每次付费都要明细清单与发票 | 日后核查的唯一依据 |
| 6 | 重大处置前用文字确认（微信即可） | 留下"同意了什么"的记录 |

## 八、常见坑

**坑一：只看总额不看明细。**
「一共 3800」里面可能包含没做的项目。

**坑二：结算时才第一次看到明细。**
项目已经做完了，争议就变成"你同意了没有"的口舌之争。检查前先报价。

**坑三：手写收据代替发票。**
发票是经营者义务，手写收据证明力弱。

**坑四：微信转账给个人。**
付给个人而非机构账户，日后连"向谁付的"都要另证。尽量付到机构账户并备注。

**坑五：不核对报告单。**
收了检查费却没有报告，是"未做项目收费"的典型特征。

**坑六：住院期间不加过问。**
住院费、护理费、耗材费最容易在无人核对时累加。

**坑七：被"套餐"带着走。**
与主诉无关的检查，即使做了也可以就必要性提出异议。

**坑八：把收费争议和医疗过错混在一起谈。**
焦点模糊，两边都谈不下来。分开主张。

**坑九：发现问题后直接吵，不留书面问询。**
口头争执没有记录。书面列出争议项并要求答复，才是能用的材料。

**坑十：忘了索要并保存支付凭证。**
支付记录是最基础的证据，删了就没了。

## 九、费用核查清单

- [ ] 已取得逐项收费明细（项目名、单价、数量、日期）
- [ ] 已取得发票或正规收据
- [ ] 明细项目与病历、报告、处方已逐项对账
- [ ] 已标出无对应报告的项目
- [ ] 已标出重复收费项目
- [ ] 已标出与主诉无关的项目
- [ ] 已比对公示价与结算价
- [ ] 已汇总争议金额并书面问询机构
- [ ] 支付凭证（含收款方）已留存
- [ ] 收费争议与诊疗过错争议已分开主张
