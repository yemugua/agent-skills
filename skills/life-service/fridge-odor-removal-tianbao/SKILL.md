# 冰箱除味与清洁核查（fridge-odor-removal）

冰箱有味道，**顺序错了等于白做**：直接放除味剂而不清理源头，除味剂吸满了味道还在，冰箱里的食物继续交叉污染。这是最常见的一种白花钱。

正确的顺序永远是：**先清理 → 再吸附或中和 → 最后改善门封与温度**。

这个技能做四件事：**分诊来源** → **按顺序清理** → **选除味方法** → **防复发**。

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 区分十类异味来源与定位方法 | ❌ 承诺除味效果与持续时间 |
| 判断是否必须先清理 | ❌ 代替冰箱维修与制冷系统检修 |
| 说明三类除味方法的区别与局限 | ❌ 判断食物是否已变质可食用 |
| 说明除味剂使用安全要求 | ❌ 判断是否达到食品安全标准 |
| 给出门封清洁与温度设置建议 | ❌ 拆修冰箱内部管路与电器部件 |

**遇到以下情况，转交冰箱维修或专业人员：**

- **制冷异常**：不制冷、制冷不足、冷冻室不结霜却仍结冰
- **异常结霜**：冷冻室后壁大量结霜、除霜系统异常
- **电气异常**：压缩机有异响、启动时跳闸、机身有漏电感
- **渗漏**：冰箱底部或后部有水渍
- **长期不用后通电**：需先静置检查再通电
- **疑似食物变质污染严重**：需整体清理消毒，涉及大量食物丢弃

## 三、十类异味来源分诊表

| 编号 | 来源 | 识别特征 | 处理 |
|---|---|---|---|
| 1 | 剩菜变质 | 有明确食物来源，取出后味道加重 | 清理变质食物，检查并密封其余食物 |
| 2 | 调料过期或渗漏 | 集中在调料区，有酸味或发酵味 | 清理过期调料，检查瓶盖密封 |
| 3 | 食物未密封 | 味道随食物种类变化，气味明显 | 改用密封容器，液体类尤其要密封 |
| 4 | 果蔬释放 | 集中在果蔬区，部分果蔬本身气味明显 | 果蔬分开放置，洋葱与大蒜类单独密封 |
| 5 | 塑料件吸味 | 抽屉、隔板、密封条长期使用后有味 | 清洁并彻底晾干；老化件按需更换 |
| 6 | 门封老化发霉 | 门封条表面发黑、变硬、有霉点或缝隙 | 清洁门封；老化或破损需更换 |
| 7 | 排水孔污垢 | 后壁下方或门上小孔有污垢或异味 | 清理排水孔，保持通畅 |
| 8 | 新机胶味 | 新机刚使用，随时间减轻 | 充分通风散味，按说明书空载运行一段时间 |
| 9 | 与冷冻室串味 | 味道主要来自冷冻室方向 | 排查冷冻室食物密封；检查门封 |
| 10 | 长期不用再启用 | 长期空置后启用 | 断电开门通风清理，再通电运行 |

## 四、必须先清理再除味（这一条是本技能的核心）

**顺序错了，除味剂就是白花钱。**

| 步骤 | 动作 | 说明 |
|---|---|---|
| 1 | 清空 | 全部取出，含隔板上的一切食物 |
| 2 | 分类丢弃 | 变质、渗漏、密封不完整的直接丢弃，不要再犹豫 |
| 3 | 擦净内壁与隔板 | 用温水配中性清洁剂擦洗，不用强碱或含氯产品 |
| 4 | 清理排水孔与门封 | 后壁下方小孔、门封条缝隙是污垢聚集处 |
| 5 | 彻底晾干 | 擦完后开门通风让内部彻底干燥，这一步不能省 |
| 6 | 再放除味产品 | 干燥后放入吸附类或中和类产品 |
| 7 | 分批回装 | 食物分批放回并密封存放，便于再次定位问题 |

**为什么要彻底晾干**：潮湿的内壁会让吸附类产品失效，也会给霉菌制造条件。

---

## 五、三类除味方法的区别与局限

| 类型 | 原理 | 优点 | 局限 | 关键提醒 |
|---|---|---|---|---|
| 吸附类（活性炭等） | 物理吸附气味分子 | 安全、无化学残留 | 容量有限，饱和后需更换 | 必须按说明书规定的更换周期，不更换会二次污染 |
| 中和类 | 与气味分子发生反应 | 对特定异味较有效 | 种类有限，可能有气味残留 | 按说明书使用，不可超量 |
| 遮蔽类（香氛类） | 用另一种气味覆盖 | 短期感受好 | 完全不解决来源，掩盖真实问题 | 不作为除味的主要手段 |
| 清洁类（处理源头） | 清理变质物与污垢 | 真正解决来源 | 需要动手、耗时 | 永远排在第一位 |

**排序永远是：清洁类 → 吸附类或中和类 → 遮蔽类（可选，不作为手段）。**

## 六、除味剂使用安全要求

| 要求 | 说明 |
|---|---|
| 不与食物直接接触 | 吸附类与中和类均应与食物分开，按产品说明书放置位置使用 |
| 不放入需密封加热的食物中 | 高温可能使产品失效或产生异味迁移 |
| 不放在儿童与宠物可触及处 | 避免误食 |
| 不混合清洁剂使用 | 任何情况下不与含氯消毒剂或酸性清洁剂混用 |
| 不在冰箱内壁直接涂抹 | 液体类除味剂直接涂内壁会污染食物接触面 |
| 按说明书放置与更换 | 活性炭等必须按说明书周期更换 |
| 保留原包装 | 不要分装到不明容器 |

---

## 七、门封检查与清洁

**门封是气味与湿气进入的主要通道，也是最容易被忽略的地方。**

| 检查项 | 方法 | 合格表现 |
|---|---|---|
| 表面清洁 | 目视与手触 | 无发黑、发霉、黏腻、硬化 |
| 密封性 | 关门后夹一张纸缓慢抽动 | 有明显阻力，纸条不易抽出 |
| 缝隙 | 沿四周目视 | 无明显变形、翘起、破损 |
| 清洁方法 | 中性清洁剂擦拭后清水擦净 | 擦净后彻底晾干再关闭冰箱门 |
| 老化判断 | 捏压看回弹 | 长期捏不弹或硬化开裂属老化，需更换 |

**注意**：清洁门封后不要立刻关门，要等门封彻底干燥。湿着关门容易残留水分与清洁剂。

---

## 八、温度设置对抑菌的影响

| 设置 | 说明 |
|---|---|
| 冷藏室温度 | 按产品说明书与食品保存要求设定，不宜过高 |
| 冷冻室温度 | 按产品说明书设定，保证食物冻结 |
| 温度波动大 | 会缩短抑菌效果，加快食物变质 |
| 门开合频繁 | 冷气流失明显，温度波动大 |
| 塞得太满 | 冷气循环受阻，实际温度不均匀 |

> 具体温度设定以**产品说明书**为准，不同型号差异较大，本技能不指定数值。

---

## 九、长期不用冰箱的处理

1. 清空全部食物，含抽屉与隔板
2. 断电，开门通风
3. 擦拭内部与门封，处理污垢与残留
4. 保持门体敞开或留缝，彻底干燥
5. 长期闲置后再启用时，先静置再通电观察；通电后如出现异常异响、跳闸或漏电感应，**立即断电并联系维修**

**长期不通电的冰箱重新启用前属于需要谨慎处理的情形。** 有制冷异常、异常结霜、渗漏、电气异常时，转专业维修。

## 十、脚本用法

```bash
python scripts/fridge_odor_check.py --text "新买的冰箱有塑料味，门封条发黑"
python scripts/fridge_odor_check.py --file 情况.json --out 结果.md
```

| 参数 | 说明 |
|---|---|
| `--text` | 直接描述冰箱异味情况 |
| `--file` | 从文件读，支持 `.txt` / `.md` / `.json`（JSON 用 `{"desc": "..."}`） |
| `--out` | 结果落盘路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本做三件事：按分诊顺序匹配最可能来源、给出清理顺序提醒、检查是否命中需转专业维修的红线。

> 脚本是关键词匹配，**不等于现场判断**。门封密封性与排水孔通畅需要实际检查。

## 十二、最常见的坑

**坑一：不清除直接放除味剂。**
除味剂吸满了味道还在，冰箱里继续交叉污染。而且吸附类饱和后不更换会二次污染。

**坑二：活性炭放到没味了就不换。**
吸附容量耗尽后会重新释放，必须按说明书周期更换。到没味为止不等于还有效。

**坑三：用香氛掩盖冰箱味。**
盖住的是鼻子，不是来源。变质食物还在继续污染。

**坑四：擦完立刻关门。**
湿着关门会让清洁剂和水分残留在门封与内壁，反而利发霉。

**坑五：门封发黑不处理。**
门封是气味进入的主通道，也是污垢聚集处。不清洁门封，其他处理都会被抵消。

**坑六：食物敞开存放。**
冰箱不是一个密封环境，一样敞开存放会互相串味。液体类尤其要密封。

**坑七：塞得满满当当。**
冷气循环受阻，实际温度不均匀，加速变质。

**坑八：温度设得偏高。**
省电设高温的代价是食物变质更快。

**坑九：用强碱或含氯产品擦内壁。**
内壁与食物直接接触，这类产品残留会影响食品安全，用中性清洁剂。

**坑十：长期不用的冰箱直接通电。**
应先清理、通风、静置，通电后有异常立即断电联系维修。

**坑十一：排水孔堵了不管。**
污垢在那里积存，是异味反复的来源之一。

## 十三、边界与免责

- 本技能**不替代**冰箱维修、制冷系统检修与电气检修

- 除味产品的适用范围与更换周期以**产品说明书**为准
- 涉及电器安全的注意事项，按**产品说明书与相关主管部门要求**执行
