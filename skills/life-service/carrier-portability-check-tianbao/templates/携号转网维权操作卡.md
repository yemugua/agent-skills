# 携号转网办理与拒绝申诉操作卡

## 一、打电话/去柜台时直接照着说

**开场（先确认自己有没有资格）**
> "我要办携号转网。先帮我查三件事：①我这个号码连续在网多久了？②有没有未到期的号码使用协议或套餐合约，到期日是哪天？③有没有未结清的合约赠品？麻烦给我一个工单号。"

**被拒时（要依据，不要解释）**
> "我理解可能有合约限制。请给我一份**书面《不予携出告知书》**，写明依据的是哪份协议、第几条。如果不方便出具，请记录我的工单号并告知书面答复时限。"

**对方说"系统不支持"**
> "系统不支持是操作层面的，还是政策层面的？如果是操作层面，请告诉我政策依据在哪一条。"

**涉及单位统一签约**
> "这个号码是我个人在用，携出不影响贵单位其他号码。请问需要单位管理员出具什么材料？我可以配合出具在职和授权证明。"

## 二、柜台办理清单

- [ ] 身份证原件（本人办理）
- [ ] SIM 卡
- [ ] 如委托他人：授权书 + 双方身份证
- [ ] 需求：**打印在网时长证明**、**查询协议到期日**、**索取书面答复**
- [ ] 离柜前：**核对工单号与答复时限**，记入手机

## 三、解除绑定操作顺序（别搞反）

1. 查清是哪份协议在约束（号码协议 / 融合套餐 / 靓号合约）
2. 先解需要单位配合的（政企、集团号）
3. 柜台解可当场办的（主副卡平移、宽带拆分）
4. **清服务绑定**：银行预留 → 免密支付/自动续费 → 会员/购物/云服务
5. 最后提交携出申请（**一旦提交，24 小时激活窗口开始倒计时**）

## 四、收到"已办理携出"短信后 24 小时内

- [ ] 当天到目标运营商营业厅，或提前在 App 上完成实名与开户
- [ ] 带身份证 + 原 SIM 卡（部分场景需插卡验证）
- [ ] 激活后核对：归属地、套餐内容、语音/流量是否按预期生效
- [ ] 原号停机前，确认银行代扣、免密支付已解绑

## 五、申诉材料打包清单

| 材料 | 从哪来 | 必需 |
|---|---|---|
| 在网时长证明 | 营业厅打印 | ✅ |
| 书面答复/告知书 | 营业厅或客服工单 | ✅ |
| 工单号记录 | 通话后自行记录 | ✅ |
| 身份证复印件 | 自备 | ✅ |
| 服务协议/号码使用协议 | 营业厅索取 | 建议 |
| 绑定关系截图（主副卡/宽带/靓号） | App 截图 | 建议 |
| 合约到期日证据 | 营业厅查询记录 | 建议 |

## 六、四个必须记住的数字

| 数字 | 含义 |
|---|---|
| **120 天** | 同一运营商连续使用满 120 天方可申请携出 |
| **24 小时** | 携出通知送达后须在此窗口内激活，逾期视为放弃 |
| **3 年** | 相关争议的民事诉讼时效一般口径 |
| **15~30 个工作日** | 申诉渠道的常见答复周期，超期可催办 |

## 七、什么时候该考虑诉讼

- 对方**书面拒绝**且理由不属于法定可携限制
- 走完工单 → 工信部 → 12345 → 12315 仍无果
- 有明确书面答复 + 充分证据证明自己符合条件

诉讼诉求通常是**确认对方受理条件成就、督促履行办理义务**。是否值得走，要评估时间与举证成本，**建议先咨询律师**。
