# 携号转网办理与拒绝核查

携号转网这事的坑不在"能不能转"，而在**你以为自己不能转，其实是对方在拖**——合约没到期是真的，宽带捆绑要拆也是真的，但**没人告诉你哪些能提前解除、解除之后多久能办**。

## 什么时候用

- 想换个运营商，但被告知"合约期未满不能办"
- 号码是主卡、下面挂着副卡，说"主卡不能携出"
- 办了融合套餐捆着宽带和电视，说"必须先退宽带"
- 号码是靓号/吉祥号，有低消合约，对方说"特殊号码不支持"
- 单位发的集团号/专线/总机，自己想带着号走
- 申请后突然收到"已办理携出"的短信，24 小时内没来得及激活
- 号要停用了，但绑着房贷代扣、银行卡、免密支付，怕收不到验证码
- 不知道该找客服、营业厅还是工信部，只知道被"踢皮球"

## 怎么做

**第 1 步**：复制 `templates/携号转网信息采集表.md` 填写（入网日期、合约状态、绑定情况、拒绝理由是四个关键项）。

**第 2 步**：跑脚本

```bash
python scripts/carrier_check.py 采集表.md --base 2026-10-05 --out 核查报告.md
```

**第 3 步**：按第九段路径走——**先解硬门槛（合约/宽带/主副卡），再清绑定（银行/免密），最后才是催办与申诉**。

## 三句话定性的核心规则

1. **资格是硬门槛**：同一运营商**连续使用满 120 天**、**处于正常在网状态**（无欠费无停机）、**无未到期合约与未结清赠品**。前两项不满足，申请提交了也会被驳回。
2. **不可携情形是有边界的**：政企专线与集团号（单位统一签约）、物联网与车规卡、宽带电视捆绑、主副卡绑定、靓号特殊合约——**这些不是"绝对不能转"，而是"要先解除绑定或变更业务类型"**，很多人卡在这里就放弃了。
3. **两个时限要盯死**：① 资格届满日 = 入网日 + 120 天；② **携出通知送达后 24 小时内必须在目标运营商激活，逾期视为放弃**。收到携出短信当天就要办，别等。

## 输入 / 输出

| | 内容 |
|---|---|
| 输入 | 采集表 Markdown（运营商 / 入网日期 / 在网状态 / 合约与赠品 / 政企与物联网 / 宽带电视 / 主副卡 / 靓号 / 银行与验证码 / 第三方绑定 / 申请与携出日期 / 拒绝理由 / 投诉渠道 / 证据） |
| 输出 | 十一段报告：结论摘要 / 资格条件逐项核查 / 不可携情形核查 / 号码与账户风险 / 时限倒计时 / 拒绝情形与申诉阶梯 / 投诉渠道与受理 / 证据清单与缺口 / 办理与申诉路径排序 / 证据缺口速查 / 待办补正动作（另附边界与纪律） |
| 退出码 | 0 正常；2 关键信息缺失（给提示串，不崩） |

## 边界与纪律

- 依**通用规则**整理，**不替代律师意见**
- 各运营商的**具体受理条件、合约条款、违约金与办理时限**差异很大，一律以**本人服务协议与运营商现行规则**为准；携号转网政策以工业和信息化部及运营商公告口径为准
- 不预测监管与法院的受理结果，也不承诺申诉一定通过
- **未填的一律不算通过**，只按已填内容判断
- 涉身份证号、账单等个人信息，本地处理，不要外发
