# 不可携情形：五类，以及逐个怎么解

> 关键认知：**"不可携"多数是"业务绑定"造成的，不是号码本身的属性。** 解开绑定就能转。

## 一、五类常见不可携情形

| 情形 | 为什么卡 | 怎么解 | 大概耗时 |
|---|---|---|---|
| **政企专线 / 集团号 / 企业总机** | 由单位统一签约，号码归属单位 | 联系单位信息化/人事管理员，由单位提出变更或销户 | 取决于单位流程 |
| **物联网卡 / 车规卡 / 定位卡** | 属于物联业务，不支持个人携出 | 换成普通手机卡（号码可保留的前提是业务可迁移，否则只能注销） | 数天~数周 |
| **宽带 / ITV / 电视捆绑** | 融合套餐期内不得单独拆分 | 问清"退宽带保号码"是否可行；部分需等到合约期满 | 合约期是硬约束 |
| **主副卡 / 亲情号 / 家庭套餐** | 主卡是合约主体，携出会导致副卡失效 | 先把主号在主副卡之间**平移**（转到副卡上），或解除主副卡关系 | 柜台当场可办 |
| **靓号 / 吉祥号 / 纪念号低消合约** | 特殊号码有最低消费合约 | 咨询能否变更套餐保住号码；或等合约期满 | 合约期是硬约束 |

## 二、解除绑定的操作顺序（很重要）

**顺序错了会白跑：**

1. **先查合约**：确认哪一份协议在约束（号码协议？融合套餐？靓号合约？）
2. **再解最难解的**：政企/集团号先找单位，其余的柜台当场办
3. **再清服务绑定**：银行预留、免密支付、自动续费、会员——**这一步最容易被忽略，号码停用后扣费失败、验证码收不到**
4. **最后才提交携出申请**：因为一旦发起携出，24 小时激活窗口就开始倒计时

## 三、这些不是"不可携"，别被话术带偏

- "靓号不支持携出" → 多数是**合约未到期**，不是号码类型限制
- "必须先注销宽带" → 部分地区允许只退宽带保号码，要问清
- "系统不支持" → 要求出具**书面告知并载明依据条款**
- "帮你升级了套餐" → 警惕**携出前被推销新合约**，先拒绝再办理
- "把你的业务都停了" → 携出后原业务终止是正常的，但**停机前应完成银行与免密换绑**

## 四、话术要点

- 第一次沟通就明确问三件事：**①我是否符合条件？②不符合的具体依据是哪份协议第几条？③能否出具书面告知？**
- 强调"**我要的是书面答复，不是口头解释**"——口头拒绝没有申诉价值。
- 若对方以"系统不支持"推脱，要求**记录工单号并告知处理时限**。
- 涉及单位统一签约的，直接说明"**号码是我个人在用，携出不影响贵单位其他号码**"，避免被误解为单位行为。
