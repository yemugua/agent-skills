# 隧道与地下交通消防（tunnel-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《建筑设计防火规范》GB 50016 与隧道消防要求，生成隧道消防清单：隧道分类与耐火、疏散通道与联络通道、排烟与通风、消防给水与灭火器、报警与应急广播。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 隧道消防
- 城市隧道
- 山岭隧道
- 隧道排烟
- 隧道疏散

## 三、工作流
1. 明确隧道分类与耐火要求
2. 核查疏散通道与联络通道
3. 检查排烟与通风系统
4. 确认消防给水与灭火器
5. 核实报警与应急广播

## 四、核心内容（检查清单与判定）
隧道空间封闭、排烟与疏散困难，须按分类设置疏散/联络通道、机械排烟与消防给水，并配报警与应急广播引导。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含隧道分类与耐火要求 | 分类 |
| Q2 | FAIL | 未含疏散通道与联络通道 | 疏散 |
| Q3 | WARN | 未含排烟与通风系统 | 排烟 |
| Q4 | FAIL | 未含消防给水与灭火器 | 给水 |
| Q5 | WARN | 未含报警与应急广播 | 报警 |

> 脚本 `tunnel-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python tunnel-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python tunnel-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
