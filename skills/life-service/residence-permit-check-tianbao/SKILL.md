# 居住证申办签注与积分核查（residence-permit-check）

居住证这件事，绝大多数人卡在四个点：**不知道走哪条路申领、材料带了不全、登记还没满半年、签注忘了办**。

这个技能做五件事：**选路径** → **核材料** → **算半年级门槛** → **算签注窗口** → **查积分覆盖度**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 判断符合哪条申办路径 | ❌ 承诺一定受理、一定出证 |
| 列出材料清单并标出缺失 | ❌ 代填申请表、代签承诺 |
| 按登记日期推算最早可申领日 | ❌ 编造"不用登记也能办"的操作口径 |
| 推算签注到期日并提示逾期后果 | ❌ 补办历史签注或撤销不良记录 |
| 核查积分材料覆盖度 | ❌ 计算具体分值、预测落户排队位次 |
| 提示换证、补领的情形 | ❌ 提供虚假住址、虚假劳动关系材料的办法 |

**遇到以下情况，直接去居住地公安派出所或受委托的社区服务机构问口径，不要靠猜：**
- 居住登记时间与社保、租赁合同时间对不上
- 属于集体户口、单位集体宿舍、借住亲友家等非典型住所
- 未成年人、老年人代办情形
- 涉及积分落户、子女入学、资格考试等对有效期有硬要求的场景
- 已在原户籍地享受的待遇与现居住地政策衔接

**永远不要建议用虚假租赁合同、虚假劳动关系证明去凑材料。** 造假一旦被查，除不予受理外还可能留下不良记录，影响后续申请。

## 二、完整工作流

```
第 1 步  问清三件事：来本地多久、靠什么立足（就业/住所/就读）、有没有办过居住登记
第 2 步  先读规则文件 rules/application_rules.md 与 rules/points_rules.md
第 3 步  跑核查脚本
    python scripts/residence_permit_check.py --file 情况.txt \
        --register-date 2026-01-15 --issue-date 2025-09-20 --as-of 2026-10-08
第 4 步  逐项人工确认（脚本只做关键词匹配，不做户籍口径判断）
第 5 步  按 templates/材料清单表.md 输出核查表
```

## 三、申办路径（三选一，符合其一即可）

| 路径 | 认定要点 | 典型证明材料 |
|---|---|---|
| **合法稳定就业** | 有实际任用、聘用关系且按规定缴纳社保 | 劳动合同/劳务合同、用人单位出具的劳动关系证明、工商营业执照 |
| **合法稳定住所** | 对居住房屋有合法使用权 | 房屋租赁合同、房屋产权证明、购房合同、出租人出具的住宿证明 |
| **连续就读** | 取得学籍并连续就读 | 学生证、就读学校出具的连续就读证明、学籍证明 |

> 三条路径**不需要同时满足**，符合其一即可申领。脚本会按关键词提示命中的路径，命中为空时不要假设"可以试着报"。

## 四、材料清单（六项）

完整清单与替代材料见 `rules/application_rules.md`，核心六项：

| # | 材料 | 常见替代/补充 | 缺了会怎样 |
|---|---|---|---|
| 1 | 本人居民身份证 | 原件+复印件 | 直接不予受理 |
| 2 | 近期免冠照片 | 多数受理点现场人像采集，不必自带 | 少数仍需收纸质照片 |
| 3 | 居住地住址证明 | 租赁合同/产权证/购房合同/住宿证明 | 退回补材料 |
| 4 | 就业或就读证明 | 三选一路径对应材料 | 退回补材料 |
| 5 | 居住登记凭证 | 部分地区系统可查，不必交纸质 | 无法起算半年门槛 |
| 6 | 委托书与代办人身份证件 | 只在代办时需要 | 代办被拒 |

## 五、居住登记与"半年"门槛

申领居住证的核心门槛是**在本市居住半年以上**。实际办理中，绝大多数城市以**居住登记满 6 个月**作为主要佐证。

- **起算日是登记日，不是来本市的那天。** 很多人拿火车票、租房合同日期当起算日，窗口不认。
- 脚本按 `--register-date` 加 6 个月算出最早可申领日；差一天提交都会被退。
- 未满半年但能证明**预期居住半年以上**（如 1 年期以上劳动合同、2 年期租赁合同）的，是否受理以当地答复为准，不要默认一定能办。
- **先把居住登记办好。** 登记本身比居住证简单，但它是后面一切的时间起点。

---

## 六、签注（最容易漏的一步）

居住证**每年签注 1 次**。应当在居住**每满 1 年之日前 1 个月内**办理签注。

| 状态 | 表现 | 后果 |
|---|---|---|
| 未到签注期 | 距到期还有 1 个月以上 | 正常，设提醒即可 |
| 签注窗口期 | 距到期 30 天内 | 尽快办理 |
| **已逾期** | 已过本次签注到期日 | **使用功能中止**，补办签注后恢复 |

> 中止不是作废，但中止期间持证人无法用居住证办理需要验证的事项（如报名、报考、子女入学审核），实际影响很大。

## 七、脚本用法

```bash
python scripts/residence_permit_check.py --file "D:\材料\情况说明.txt" \
    --register-date 2026-01-15 --issue-date 2025-09-20 --as-of 2026-10-08
```

| 参数 | 说明 |
|---|---|
| `--file` | 必填。情况说明书、材料清单或聊天记录导出文本（`.txt` / `.md`） |
| `--register-date` | 居住登记日期，用于算最早可申领日 |
| `--issue-date` | 发证日期或上次签注日期，用于算签注窗口 |
| `--as-of` | 核查基准日，默认今天 |
| `--out` | 输出路径，默认打到屏幕 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本做六件事：
1. **路径判定**：就业/住所/连续就读命中哪条
2. **材料核查**：六项清单逐项标齐备/缺失/不涉及
3. **退回风险**：五类高频退回情形是否命中
4. **半年门槛**：登记日期加 6 个月算出最早可申领日与剩余天数
5. **签注状态**：到期日、建议窗口、是否已逾期
6. **积分覆盖**：八个常见维度的材料有没有备齐

> ⚠️ 脚本只做关键词匹配，**不代表受理结论**。标"齐备"不等于窗口认可这份材料。

---

## 八、人工确认（这步不能省）

- [ ] 居住登记日期以**登记凭证或系统记录**为准，不要用租房合同签订日替代
- [ ] 租赁合同上的地址与实际居住地、出租屋登记信息是否一致
- [ ] 租赁合同的**剩余租期**是否覆盖申请日之后一段时间（临近到期的合同常被质疑）
- [ ] 就业路径的劳动合同是否**在有效期内**，社保是否已实际缴纳
- [ ] 代办时委托书是否写明委托事项、代办人是否带原件身份证
- [ ] 未满 16 周岁是否由监护人代办并带监护关系证明
- [ ] 上一次签注日期以**证件记载**为准，不要用"大概去年这个时候"

## 九、输出结构（固定六段）

1. **能不能办** —— 结论先行：可受理 / 需补材料 / 暂不受理（未达半年门槛）
2. **申办路径** —— 命中哪条、证据是否充分
3. **材料清单核查表** —— 六项逐项标齐备/缺失
4. **退回风险提示** —— 命中的高频退回情形
5. **时间节点** —— 最早可申领日、签注到期日、建议办理窗口
6. **积分材料覆盖度** —— 八个维度缺哪块

## 十、最常见的坑

**坑一：把"居住登记"和"居住证"当成一件事。**
登记只是登记，不发证、不算年限起点以外的东西。但没登记，居住证基本办不成。

**坑二：半年从"来本地那天"算。**
登记系统只认登记日。哪怕你已经住了两年，昨天才登记，窗口按昨天算。

**坑三：签注逾期后以为证还在用。**
使用功能中止期间，报名、报考、资格审核都可能卡住。很多人是到了报名网站才发现。

**坑四：搬家后不办变更。**
住址变更后不办理变更登记，新辖区无法提供相应服务，也会影响后续重新签注时的地址核验。

**坑五：租赁合同快到期还拿去办。**
租期只剩一个月，工作人员会质疑"合法稳定住所"是否成立。续租后再办更稳。

**坑六：拿当地城市的经验套另一个城市。**
"我这的朋友说他三天就下来了"——不同城市受理口径、是否与流动人口系统联网、照片是否现场采集都不一样。一律以拟申领地公安派出所答复为准。

## 十一、边界与免责

- 本技能**不代替**公安派出所及受委托社区服务机构的受理与审查
- 材料清单、办理时限、收费与否、是否支持网上办理，各地口径不同，**以现行规定和拟申领地公安派出所要求为准**
- 积分指标与分值由各地另行规定，本技能**只核查材料覆盖，不计算分值、不预测落户结果**
- **不得用于制作、使用虚假住址证明、虚假劳动关系证明或虚假就读证明**
