# 财务预测与单位经济模型规则库

> 写完财务模块先读本文件。**投资人不看利润表，先看单位经济模型。**

---

## 一、单位经济模型（UE）单客户账

```
客单价 ARPPU      = 元/单
变动成本          = 元/单   （履约、带宽、退款、按量成本）
毛利              = 客单价 - 变动成本
毛利率            = 毛利 ÷ 客单价

获客成本 CAC      = 元
单客户毛利贡献 LTV = 毛利 × 复购次数
LTV/CAC           = LTV ÷ CAC
回本周期(月)      = CAC ÷ 单客户月毛利
```

| 指标 | 判定 | 说明 |
|---|---|---|
| LTV / CAC | ≥ 3 才算基本跑通 | 不同行业标准不同，BP 中须写明所用标准 |
| 回本周期 | 越短越好 | 超过 12 个月现金压力显著 |
| 毛利率 | 按自己实际成本算 | 不抄行业平均 |

### CAC 完整算法（最常被漏算）

```
CAC =（渠道投放费用 + 销售人力成本 + 工具与佣金分摊）÷ 新增付费用户数
```

**只算投放费用的 CAC 会显著偏低**，回本周期算出来也不可信。

### 留存/复购曲线必须给

| 节点 | 要给的数 |
|---|---|
| 第 1 个月 | 次月留存率 |
| 第 6 个月 | 留存率 |
| 第 12 个月 | 留存率 |
| 复购次数 | 平均复购次数 |

**没有留存曲线，单位经济模型就是拍的。**

| 类别 | 科目 |

## 三、三条勾稽关系（必核）

```
1. 毛利 = 营业收入 - 营业成本
   毛利率 = 毛利 ÷ 营业收入

2. 经营利润 = 毛利 - 研发费用 - 销售费用 - 管理费用
   净利润 = 经营利润 - 所得税 ± 其他损益

3. 期末现金 = 期初现金 + 经营性现金流 + 投资活动现金流 + 筹资活动现金流
```

违反任意一条，财务表就是编的。**会计师一眼能看出勾稽不上。**

---

## 四、收入预测必须拆解

```
收入 = 用户数 × 付费率 × 客单价
```

**每一项都要有增长依据：**

| 乘数 | 增长依据 |
|---|---|
| 用户数 | 渠道投放预算 ÷ CAC，或渠道自然增长 |
| 付费率 | 试用转化流程数据，或行业参照（写明来源） |
| 客单价 | 定价方案与折扣政策的实际测算 |

**从 1000 万跳到 8000 万却不拆路径，是 BP 里最常见的致命伤。**

## 五、融资额推导

```
基础额 = 月度净消耗 × 达到下一个里程碑所需月数
建议融资额 = 基础额 × 安全系数（1.3-1.5）

例：月度净消耗 120 万，到下一里程碑需 18 个月
  基础额 = 120 × 18 = 2160 万
  建议融资 = 2160 × 1.3 ≈ 2800 万
```

**融资用途必须给比例**，例如：

| 用途 | 比例 | 金额 |
|---|---|---|
| 研发 | 55% | 1540 万 |
| 市场 | 30% | 840 万 |
| 运营 | 10% | 280 万 |
| 储备 | 5% | 140 万 |

**融资额与里程碑对不上，说明创始人没算清要多久。**
