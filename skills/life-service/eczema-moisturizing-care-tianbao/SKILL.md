# 湿疹保湿护理与润肤剂选择

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 给出润肤剂剂型选择、用量与涂抹频次口径 | 诊断湿疹类型、判断是否合并感染或过敏 |
| 说明成分选择原则与常见刺激成分 | **提供外用激素或任何药物的强度、剂量与使用方案** |
| 提示沐浴水温、时长与清洁产品选择 | 推荐具体药品与护肤品牌 |
| 整理衣物、环境、诱因的记录方法 | 建议忌口替代正规治疗或长期自行大面积用药 |
| 输出每周用量估算与护理记录表 | 承诺保湿能「根治」湿疹 |

**就医红线（出现任一条，尽快就医；标注急诊的直接去急诊）**

- 皮疹渗液化脓、黄色结痂增多、周围红肿发烫 —— 提示继发细菌感染，尽快就诊
- 原有湿疹部位突然出现密集水疱、脓疱，伴高热、精神差 —— 急诊（需排除疱疹样湿疹等急症）
- 皮疹在数小时到一两天内快速扩散、大面积皮肤发红脱皮
- 面部或眼睑严重肿胀、影响睁眼，或口唇肿胀伴呼吸不畅 —— 急诊
- 发热伴皮疹，尤其婴幼儿
- 剧烈瘙痒导致无法入睡、抓破出血明显、影响日常生活
- 婴幼儿皮疹伴生长发育迟缓、慢性腹泻、反复呕吐
- 长期大面积使用外用制剂后出现皮肤变薄、红血丝、色素改变
- 皮疹经规范护理 2 周无改善或持续加重

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「润肤霜一天涂几次、涂多少」 | 用，给出用量估算 |
| 「软膏和乳液选哪个」 | 用，按干燥程度与部位选 |
| 「湿疹能洗澡吗」 | 用，明确可以且要洗对 |
| 「激素药膏会不会依赖」 | 用，说明规范使用的口径，具体用药由医生定 |
| 「要不要查过敏原、忌口」 | 用，说明证据与局限 |
| 「氢化可的松怎么用」 | 不用，由医生开具并说明用法 |
| 「孩子湿疹渗水了」 | 只作就医提示 |

## 三、完整工作流

1. **先排红线**：逐条核对就医红线，命中即转就医，尤其渗液化脓与密集水疱伴高热。
2. **选剂型**：按干燥程度、部位、季节选软膏、霜剂或乳剂，对照 `rules/润肤剂选择与用量.md`。
3. **看成分**：优先无香精、无酒精、含保湿与屏障修复成分的产品，避开常见刺激成分。
4. **算用量**：用脚本按年龄与受累面积估算每周用量与单次指尖单位数。
5. **定频次**：每日至少 2 次，沐浴后 3 分钟内涂抹，干燥季节与部位增加次数。
6. **改沐浴**：水温 32-37℃，时长 5-10 分钟，减少碱性清洁产品。
7. **记诱因**：按 `rules/日常护理与诱因.md` 记录衣物、环境、食物与情绪因素，避免盲目忌口。

## 四、核心规则与要件库

生成护理建议前，**必须先读**：

- `rules/润肤剂选择与用量.md`：剂型对比、成分选择、每周用量口径、涂抹频次。
- `rules/日常护理与诱因.md`：沐浴、衣物、环境、诱因记录与常见误区。

不得给出外用激素的强度、浓度、部位与使用时长方案，具体用药由医生开具。不得建议用母乳、唾液、精油等涂抹皮疹。

## 五、脚本用法

```
python scripts/emollient_dose_calc.py --file case.json
python scripts/emollient_dose_calc.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`age_years` 年龄、`area_pct` 受累体表面积百分比、`times_per_day` 每日涂抹次数 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--json` | 以 JSON 输出 |
| `--selftest` | 运行自检 |

脚本输出每周润肤剂用量估算、单次用量与指尖单位数、按年龄的频次建议。**脚本不输出任何药物剂量。**

## 六、人工确认清单

- [ ] 就医红线已排除，重点确认渗液化脓与密集水疱伴高热
- [ ] 剂型已按干燥程度、部位与季节选定
- [ ] 产品成分已核对：无香精、无酒精、无明确过敏成分
- [ ] 每周用量已按面积估算，不是「想起来才涂」
- [ ] 沐浴后 3 分钟内涂抹已作为固定动作执行
- [ ] 水温与沐浴时长已核对
- [ ] 衣物材质、洗涤剂、环境温湿度已调整
- [ ] 用药（含外用激素）严格遵医嘱，未自行加减
- [ ] 诱因记录已连续记录 2 周以上

## 七、最常见的坑

1. **涂得太少**：多数人实际用量远低于需要量，这是保湿失败最常见的原因。
2. **只在发作时涂**：缓解期也要维持涂抹，皮肤屏障修复是长期工程。
3. **湿疹要保持干燥**：错，湿疹皮肤本就缺水缺脂，干燥会加重。
4. **热水烫洗止痒**：一时止痒，之后更干更痒，加重屏障损伤。
5. **盲目忌口**：忌口应有依据，长期盲目忌口影响营养与生活质量，尤其儿童。
6. **谈激素色变而完全不用**：规范、短期、按部位使用与长期滥用是两回事，具体方案由医生定。
7. **用纯天然精油、母乳、唾液涂抹**：增加刺激与感染风险。
8. **频繁更换产品**：皮肤适应需要时间，频繁更换反而难以判断哪种有效。

## 八、边界与免责

本技能提供湿疹保湿护理的通用口径与用量估算工具，不构成诊断或治疗方案。**不提供任何外用激素或药物的强度、浓度与用法**。用量数值为常见护理口径，因年龄、体表面积、季节与产品质地而异，**以最新版临床指南和皮肤科医师的判断为准**。出现就医红线中的任一情况，请尽快就诊。
