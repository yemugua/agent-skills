# 润肤剂选择与用量

> 用量数值为常见护理口径，因年龄、体表面积、季节与产品质地差异较大，
> **以最新版临床指南和皮肤科医师的判断为准**。本文件不涉及药物。

## 一、剂型对比

| 剂型 | 特点 | 适用场景 | 不适用 |
|---|---|---|---|
| 软膏（如凡士林类） | 油脂含量高、封闭性强、保湿持久 | 干燥明显的部位、冬季、夜间厚涂 | 夏季闷热、毛较多部位、有渗液时 |
| 霜剂（乳霜） | 油水混合，保湿与肤感较平衡 | 日常首选，多数季节与部位 | 极干燥时可能不够 |
| 乳剂 / 露 | 含水量高、清爽易推开 | 大面积涂抹、头皮、夏季、轻度干燥 | 干燥严重或冬季单用不够 |
| 油剂（沐浴油） | 加入洗澡水中减少脱脂 | 干性皮肤沐浴时使用 | 防滑倒需注意 |

**选择原则**：越干越厚，越热越薄；先试小面积，观察 2-3 天无刺激再扩大。

## 二、成分选择

| 优先选择 | 说明 |
|---|---|
| 含神经酰胺、胆固醇、脂肪酸 | 有助于屏障修复 |
| 含甘油、透明质酸、泛醇 | 常见保湿成分 |
| 含尿素 | 保湿兼软化角质；**浓度较高时有刺激性，儿童与破溃皮肤慎用** |
| 无香精、无色素、无酒精 | 降低刺激风险 |
| 包装密封、开口小 | 减少防腐需求与污染 |

| 尽量避开 | 说明 |
|---|---|
| 香精与芳香剂 | 常见刺激与致敏来源 |
| 酒精（乙醇）含量高 | 加重干燥与刺痛 |
| 精油、植物提取物 | 「天然」不等于温和，湿疹皮肤常不耐受 |
| 强效防腐成分（如甲基异噻唑啉酮类） | 接触性致敏风险 |
| 强力去角质、磨砂成分 | 破坏屏障 |

## 三、用量口径

| 人群 | 全身每周用量参考 |
|---|---|
| 婴幼儿（2 岁以下） | 约 100 克 |
| 儿童（2-12 岁） | 约 250 克 |
| 青少年与成人 | 约 250-500 克 |

按受累体表面积折算：每周用量 = 对应人群全身用量 × 受累面积百分比。

**指尖单位（FTU）**：从食指指尖到第一指间关节挤出的药膏或润肤剂约 0.5 克，可覆盖约 2 个手掌面积（约相当于 2% 体表面积）。单次用量可按此估算。

## 四、涂抹频次与时机

| 项目 | 口径 |
|---|---|
| 基础频次 | 每日至少 2 次 |
| 干燥季节或部位 | 每日 3-4 次或更多 |
| 关键时机 | 沐浴或洗手后 3 分钟内涂抹 |
| 方向 | 顺毛发生长方向轻柔涂抹，不要反复用力揉搓 |
| 顺序 | 药物与润肤剂同用时，先后顺序按医生说明执行 |
| 持续 | 皮疹缓解后仍应维持涂抹，不要一好转就停 |

## 五、涂抹操作要点

1. 洗手后再取用，避免把手伸进罐子里反复挖取
2. 用干净勺子或泵头取量，减少污染
3. 厚薄以「涂完看起来有一层薄薄光泽」为准，不是抹到看不见
4. 皱褶部位（肘窝、腘窝、颈部）薄涂，避免浸渍
5. 头皮可用乳剂或油剂，避免堵塞毛囊
6. 面部选择温和无香精产品，避开眼周

## 六、存储与更换

| 项目 | 口径 |
|---|---|
| 存储 | 阴凉避光，盖紧盖子，注意有效期 |
| 分装 | 不建议长期分装，容易污染 |
| 更换 | 不要频繁更换；若出现刺痛、红肿加重则停用并咨询医生 |
| 试用 | 新产品先在前臂内侧小面积试用 2-3 天 |

## 七、明确不做的事

- 不用母乳、唾液、米汤、茶叶水涂抹皮疹
- 不在渗液破溃处厚涂封闭性软膏（需医生处理）
- 不自行在面部、皱褶部位长期使用含激素的产品
- 不因为「怕依赖」而完全拒绝医生开具的规范治疗方案
- 不把润肤剂当药物替代急性期治疗
