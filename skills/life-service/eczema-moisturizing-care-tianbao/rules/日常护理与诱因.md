# 日常护理与诱因

## 一、沐浴口径

| 项目 | 口径 |
|---|---|
| 频率 | 可以每天洗，湿疹皮肤需要清洁，不洗澡反而增加感染风险 |
| 水温 | 32-37℃，以手肘试温不烫为宜 |
| 时长 | 5-10 分钟，不宜久泡 |
| 清洁产品 | 选温和、弱酸性或中性、无香精的产品；只用在必要部位，不必全身打泡 |
| 浴后 | 用毛巾轻拍吸干（不搓擦），**离开浴室 3 分钟内立即涂润肤剂** |
| 沐浴油 | 干性皮肤可加入洗澡水，注意浴盆防滑 |
| 不推荐 | 搓澡、磨砂、热水烫洗、碱性肥皂频繁使用、长时间泡澡 |

## 二、衣物与 bedding

| 项目 | 口径 |
|---|---|
| 材质 | 优先柔软透气的纯棉；羊毛、化纤直接接触常加重瘙痒 |
| 洗涤 | 用无香精、无柔顺剂的洗涤剂，漂洗干净，新衣先洗再穿 |
| 层数 | 避免过厚过热，以不出汗为宜 |
| 标签 | 剪掉衣物内侧标签，减少摩擦 |
| 床品 | 定期清洗更换，防螨除尘 |
| 婴幼儿 | 剪短指甲，夜间可戴棉手套，避免抓破 |

## 三、环境

| 项目 | 口径 |
|---|---|
| 温度 | 避免过热，出汗是常见加重因素 |
| 湿度 | 干燥季节使用加湿器，室内湿度维持在舒适范围 |
| 尘螨 | 定期清洁床品，减少毛绒玩具堆积（尤其卧室） |
| 宠物 | 明确过敏者需避免接触；未确认过敏不必盲目送走 |
| 吸烟 | 避免室内吸烟与二手烟暴露 |
| 日晒 | 适度日晒对部分人有帮助，但避免暴晒与晒伤 |

## 四、诱因记录方法

记录 2-4 周，找出规律，而不是凭印象下结论。

| 日期 | 瘙痒评分（0-10） | 皮疹范围与部位 | 当天饮食 | 接触物 | 环境（温湿度、出汗） | 睡眠 | 情绪事件 |
|---|---|---|---|---|---|---|---|

**判断原则**：同一因素多次、可重复地引起加重才有参考价值；单次巧合不足以忌口或规避。

## 五、饮食与过敏原

| 项目 | 口径 |
|---|---|
| 盲目忌口 | 不推荐；长期无依据忌口影响营养，儿童尤其影响生长 |
| 过敏原检测 | 结果需结合临床解读，阳性不等于致病；由医生判断是否需要检测 |
| 食物回避试验 | 应在医生指导下进行，并设明确的观察期与复引入时间 |
| 明确反应 | 进食后短时间内出现口唇肿胀、风团、呕吐、喘息者需就医评估 |
| 母乳喂养 | 母亲饮食调整应在医生指导下进行，不自行大幅忌口 |

## 六、常见误区

| 误区 | 事实 |
|---|---|
| 「湿疹要保持干燥」 | 湿疹皮肤缺水缺脂，干燥加重病情 |
| 「热水烫洗能止痒」 | 一时止痒，之后屏障损伤更重、更痒 |
| 「激素一用就依赖」 | 规范短期按医嘱使用与长期滥用不同，具体方案由医生定 |
| 「纯天然精油更安全」 | 精油是常见刺激与致敏来源 |
| 「涂母乳能治湿疹」 | 无依据，且增加刺激与感染风险 |
| 「忌口就能好」 | 食物只是部分人的诱因之一，多数需综合管理 |
| 「不洗澡减少刺激」 | 不清洁增加感染风险 |
| 「好了就不用涂了」 | 缓解期维持涂抹是减少复发的关键 |

## 七、就医与复诊提示

| 情况 | 处置 |
|---|---|
| 渗液化脓、黄色结痂增多 | 尽快就诊 |
| 密集水疱脓疱伴高热 | 急诊 |
| 皮疹快速扩散、大面积发红脱皮 | 尽快就诊 |
| 眼睑严重肿胀、口唇肿胀伴呼吸不畅 | 急诊 |
| 剧烈瘙痒无法入睡 | 就诊 |
| 规范护理 2 周无改善 | 就诊 |

## 八、提问清单

- 我这个部位和严重程度，润肤剂选软膏还是霜剂？每天涂几次？
- 药物和润肤剂的使用顺序与间隔怎么安排？
- 需要查过敏原吗？结果怎么解读？
- 哪些情况下需要立刻复诊？
- 缓解期维持治疗要持续多久？
- 孩子这个情况影响生长发育吗，饮食上要不要调整？
