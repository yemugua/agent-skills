# ISO 14001 环境因素识别与评价（ems-environmental-aspects）

> 领域：质量 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据ISO 14001:2015 条款6.1.2，生成环境因素识别与评价表：输入输出法、影响评价（定量/定性）、重要环境因素判定与管控。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 环境因素
- ISO14001
- 重要环境因素
- 环境评价
- 环保台账

## 三、工作流
1. 界定组织边界与活动/产品/服务
2. 用输入输出法识别环境因素
3. 评价环境影响（规模/频次/可控性）
4. 判定重要环境因素
5. 制定管控与监测方案

## 四、核心内容（检查清单与判定）
ISO 14001:2015 6.1.2 要求确定能够控制或能够施加影响的环境因素，确定重要环境因素并形成文件化信息。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未界定边界与识别对象 | 14001 6.1.2 |
| Q2 | FAIL | 未用输入输出法识别因素 | 方法 |
| Q3 | WARN | 缺评价准则（规模/频次/可控性） | 评价 |
| Q4 | FAIL | 未判定重要环境因素 | 重要因素 |
| Q5 | WARN | 重要因素无管控措施 | 管控 |

> 脚本 `ems-environmental-aspects_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python ems-environmental-aspects_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python ems-environmental-aspects_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
