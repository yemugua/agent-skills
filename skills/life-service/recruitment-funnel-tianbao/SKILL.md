# 招聘漏斗分析（recruitment-funnel）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：生成招聘漏斗分析清单：漏斗阶段定义（曝光/投递/筛选/面试/offer/入职）、各环节转化率、瓶颈识别、优化建议与数据周期口径。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 招聘漏斗
- 招聘转化
- 招聘漏斗分析
- 渠道转化
- 招聘效率
- 漏斗瓶颈

## 三、工作流
1. 定义漏斗各阶段（曝光/投递/筛选/面试/offer/入职）
2. 计算各环节转化率
3. 识别瓶颈（最低转化环节）
4. 提出优化建议（渠道/话术/流程）
5. 明确数据周期与口径

## 四、核心内容（检查清单与判定）
招聘漏斗将招募到入职拆解为多阶段，转化率揭示流失点；聚焦最低转化环节优化，可显著提升整体到岗效率。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未定义漏斗各阶段（曝光/投递/筛选/面试/offer/入职） | 阶段 |
| Q2 | FAIL | 未含各环节转化率计算 | 转化 |
| Q3 | WARN | 未含瓶颈识别（最低转化环节） | 瓶颈 |
| Q4 | FAIL | 未含优化建议（渠道/话术/流程） | 优化 |
| Q5 | WARN | 未含数据周期与口径 | 数据 |

> 脚本 `recruitment-funnel_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python recruitment-funnel_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python recruitment-funnel_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
