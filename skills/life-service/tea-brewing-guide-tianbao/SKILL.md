# 茶艺冲泡

## 1. 硬边界表

| 能做 | 不能做 |
|---|---|
| 按茶类给水温区间 | 替代你对茶叶品质的判断 |
| 给茶水比与出汤时间 | 承诺某种泡法包治百病 |
| 给器具选择建议 | 做茶叶真伪鉴定 |
| 提示烫熟/闷坏的信号 | 处理医疗健康事件 |

## 2. 什么时候用

| 用户说法 | 用本技能 |
|---|---|
| 「绿茶几度水」 | 用 |
| 「茶要泡几分钟」 | 用 |
| 「茶水比例多少」 | 用 |
| 「这茶是不是假的」 | 不用，属鉴定 |

## 3. 完整工作流

1. 确定茶类（绿/白/黄/青乌龙/红/黑）。
2. 按 `rules/tea-rules.md` 选水温。
3. 称茶、量水，确定茶水比。
4. 控制出汤时间（首泡与续泡递减）。
5. 选合适器具（盖碗/玻璃杯/紫砂）。
6. 对照人工确认清单核对后再泡。

## 4. 核心规则

先读 `rules/tea-rules.md`：六类茶的水温、茶水比、出汤时间表，以及烫熟、闷坏、过浓的判定口径。

## 5. 脚本用法

```
python scripts/check.py --file 冲泡参数.json
python scripts/check.py --selftest
```

`--file` 含 tea_type、water_temp、tea_g、water_ml、steep_seconds 等字段。

## 6. 人工确认清单

- [ ] 水温是否落在该茶类区间
- [ ] 茶水比是否合适（一般 1:15–1:50）
- [ ] 出汤时间是否在建议区间
- [ ] 绿茶是否用玻璃杯/盖碗而非闷泡
- [ ] 是否首泡短、续泡递增

## 7. 最常见的坑

1. 绿茶用 100℃ 沸水，烫熟变苦涩、失鲜爽。
2. 乌龙用 80℃ 低温，香气闷不出、泡不开。
3. 茶水比失调：茶多水少过浓，茶少水多寡淡。
4. 闷泡过久，尤其嫩绿茶，茶汤发暗发苦。
5. 出汤时间不分泡次，续泡仍按首泡，越泡越淡。
6. 用保温杯闷茶，持续高温闷坏。
7. 老白茶/黑茶不洗茶（润茶），杂味未去。

## 8. 边界与免责

本技能为冲泡参考，不保证风味与品质。水质、海拔（沸点变化）会影响水温实际值。以口感调整为准。
