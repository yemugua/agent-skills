# 食堂与饮用水卫生（canteen-hygiene）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《食品安全法》与生活饮用水卫生标准，生成清单：食品经营许可与健康证、原料采购索证与留样、加工过程生熟分开、餐具消毒与保洁、饮用水检测与二次供水管理。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 食堂卫生检查
- 食品经营许可证
- 健康证
- 食品留样
- 二次供水检测

## 三、工作流
1. 核验经营许可与健康证
2. 落实原料索证与留样
3. 执行加工过程生熟分开
4. 组织餐具消毒与保洁
5. 开展饮用水检测与水管理

## 四、核心内容（检查清单与判定）
集体食堂最怕群体性食源性疾病。许可证与健康证是底线，索证台账与每餐留样是溯源关键；二次供水水箱须定期清洗消毒并出具水质检测报告。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含经营许可与健康证 | 许可 |
| Q2 | FAIL | 未含原料索证与留样 | 留样 |
| Q3 | WARN | 未含生熟分开与加工规范 | 生熟 |
| Q4 | WARN | 未含餐具消毒与保洁 | 消毒 |
| Q5 | FAIL | 未含饮用水检测与水管理 | 水质 |

> 脚本 `canteen-hygiene_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python canteen-hygiene_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python canteen-hygiene_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
