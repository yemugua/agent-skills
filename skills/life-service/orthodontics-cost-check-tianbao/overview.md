# 牙齿矫正正畸花费与套路核查

面向正在做或准备做牙齿矫正、遇到报价不清、中途加项、医生换人、效果争议、想退费的当事人。

## 与其他工具的区别

- **聚焦正畸这一垂直场景**。通用消费维权工具不区分「医疗行为」与「消费服务」，而正畸恰恰两者交叉：
  退费走消费路径，效果争议走医疗损害路径，认错方向会白跑。
- **抓住正畸特有的收费结构**：矫治器费、拔牙、支抗钉、扩弓、片切、保持器、重启方案——
  这些是报价单上最常被拆出来二次收费的项目，本技能逐项核查是否事前告知。
- **核查隐形矫治器品牌授权**：宣传「进口隐形」实际用国产品牌、不给授权卡，是正畸最高发的争议点。

## 典型适用场景

1. 报价 2 万，做到一半说要拔牙、打支抗钉，每项再加钱
2. 宣传是隐适美，戴上的牙套包装上没有品牌标识，也没有授权卡
3. 被引导做「医美分期」「0 首付」，机构关门后仍被催收
4. 主治医生离职，换了个不熟悉的医生接手，方案被推翻重做
5. 做了一年多，效果与方案书承诺差距大，想停诊退费被拒
6. 合同写着「概不退费」「最终解释权归本机构」

## 使用流程

1. 抄录 `templates/正畸消费信息采集表.md` 填好（不知道的写「未填写」，别猜）
2. 运行脚本生成核查报告
3. 按「待办补正动作」补材料，再按「维权路径」逐级推进

## 边界

不替代专业法律意见与临床诊断，最终以主管部门及司法机关认定为准。
