# 牙齿矫正正畸花费与套路核查

面向正在做或准备做牙齿矫正（正畸）、遇到报价不清、中途加项、医生频繁更换、效果争议、想退费停诊的当事人。

## 它能做什么

- 核查**机构与医师资质**：口腔诊所执业许可、医师执业证书与执业范围
- 核查**方案与报价是否匹配**：报价单是否含全部必做项目，哪些项目常被拆出来二次收费
- 识别**隐形矫治器品牌套路**：宣传隐适美实际用其他品牌、未给授权卡
- 识别**分期与医美贷风险**：利率、提前终止条款、机构跑路后仍需还款
- 核查**增项是否事前告知**：拔牙、支抗钉、扩弓、保持器是否事先写进方案
- 识别**格式条款**：概不退费、最终解释权、单方变更医生
- 输出退费测算、证据清单与 12315 / 卫健部门 / 法院的维权路径

## 使用方式

把 `templates/正畸消费信息采集表.md` 填好（两列表或「字段：值」），交给本技能生成核查报告。
未填项一律按「待补正 / 有风险」处理，绝不判通过。

## 边界

本结果依通用规则整理，不替代专业法律意见与临床诊断，最终以卫生健康主管部门、市场监管部门及司法机关认定为准。
涉及医疗损害的，应同时申请医疗损害鉴定或咨询专业机构。
