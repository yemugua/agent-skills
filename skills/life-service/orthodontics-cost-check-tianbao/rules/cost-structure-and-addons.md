# 正畸收费结构与常见增项

## 一、正畸费用通常由哪几块组成

| 费用块 | 说明 | 是否应含在初始报价 |
| --- | --- | --- |
| 检查诊断费 | 全景片、头颅侧位片、CBCT、取模或口扫 | 多数机构打包，也有单独收取的，须事前写明 |
| 矫治器费 | 金属托槽 / 陶瓷托槽 / 隐形矫治器 | **核心费用**，必须写明品牌与型号 |
| 治疗处置费 | 拔牙、补牙、牙周治疗、片切 | 拔牙最常被单列，须事前评估并写明 |
| 辅助装置费 | 支抗钉（骨钉）、扩弓器、牵引、橡皮筋 | 高频增项，须事前告知 |
| 复诊调整费 | 每次复诊的调整操作 | 多数打包，部分机构按次收 |
| 结束后费用 | 保持器、复查、重启方案 | **保持器是否含在内是争议高发点** |

**判断标准**：签方案时医生已经能预见的项目（拔牙、支抗钉、保持器），就应当写进初始报价；
以「做着看」为由事后加收的，属于未履行事前告知义务。

## 二、六个高频增项与应对

| 增项 | 常见话术 | 是否合理 | 应对 |
| --- | --- | --- | --- |
| 拔牙 | 「要先拔四颗牙才能排齐」 | 若方案阶段即可预见，**应含在报价内** | 要求出示初始方案书，核对是否已写明拔牙及费用 |
| 支抗钉 | 「需要打骨钉加强支抗」 | 同上，属常见可预见项目 | 要求书面说明为什么初始方案没写 |
| 扩弓 / 片切 | 「牙弓太窄要扩一下」 | 视方案而定，须事前同意 | 未同意就实施的，可主张未经同意的处置 |
| 保持器 | 「结束后要另配保持器」 | 报价未写明的，可争议 | 签约时就问清「保持器含不含」并写进合同 |
| 重启方案 | 「效果不理想要重启，重新收费」 | 因机构原因重启的，**不应由患者买单** | 区分原因：患者不配合 vs 机构方案失误 |
| 治疗中断重启 | 「你没按时复诊，要重新交钱」 | 需在合同中约定 | 核对合同中关于中断的条款是否显失公平 |

## 三、隐形矫治器的品牌核查要点

1. **看包装与牙套本体**：正规隐形矫治器每副牙套袋上应有品牌标识与批次号。
2. **索要授权证明**：机构是否为该品牌的授权医疗机构，可要求出示授权文件或授权编号。
3. **索要官方账户/APP 权限**：主流品牌有患者端可查询方案与副数，拿不到查询权限的要警惕。
4. **核对副数与方案**：方案书应写明总副数与预计疗程，实际发放副数明显不符的要追问。
5. **警惕模糊表述**：宣传写「进口隐形矫正」「隐形矫正」而不写具体品牌的，签约时必须要求写明品牌与型号。

## 四、分期与「医美贷」风险

- 分期合同是**独立的金融合同**：机构关门、服务不到位，并不自动免除你的还款义务。
- 签约前必须看清：年化利率（不是「月费率」）、提前终止条款、逾期责任、放款方是谁。
- 被引导办理时若未充分告知利率与后果，可主张金融机构未尽提示说明义务。
- 机构跑路后：一边向金融监管部门与放款方申诉，一边向市场监管部门投诉机构，并保留报案权利。

## 五、常见的无效格式条款

| 条款 | 为什么无效或可争议 |
| --- | --- |
| 「概不退费」 | 不合理免除自身责任、排除消费者主要权利，属不公平格式条款 |
| 「最终解释权归本机构所有」 | 排除消费者权利的典型表述 |
| 「本机构有权单方更换主治医生」 | 正畸高度依赖医生连续性，单方换人条款显失公平 |
| 「逾期不复诊视为放弃，费用不退」 | 需与实际损失相当，全额不退显失公平 |
| 「效果以实际为准，不承担任何责任」 | 医疗行为不等于可以免除全部注意义务 |

> 依据：《中华人民共和国消费者权益保护法》及其实施条例、《中华人民共和国民法典》关于格式条款与显失公平的相关规定。条文号以官方文本为准。
