# 正畸谈判与投诉操作卡

## 卡片 A：签约前必须问清的八个问题（写进合同才算数）

1. 总费用包含哪些项目？**逐项列**，不要只写「全包」。
2. 拔牙、支抗钉、扩弓、片切是否需要？要的话含不含在总价里？
3. 保持器（含替换）含不含？
4. 用的是什么品牌什么型号？能不能给我授权卡和官方查询权限？
5. 总共多少副 / 预计多少个月？
6. 主治医生是谁？中途换医生怎么办？
7. 如果我中途因个人原因停止，怎么退费？
8. 如果机构原因（医生离职、停业）无法继续，怎么退费？

**要求**：以上八条的答案写进方案书或合同附件，口头承诺不作数。

## 卡片 B：遇到增项时的应对话术

> 「这个增项在我签的初始方案书里没有写明。请出示初始方案，说明为什么当时没有评估到。
> 在我书面确认之前，请不要实施，也不要收费。」

**要点**：不要当场签字付款。先要书面说明，再去核对初始方案。

## 卡片 C：退费协商书面申请（要点）

```
致：××口腔机构
本人于 ×年×月×日在贵机构接受正畸治疗，已付 ¥××××。
现因 ××（医生离职 / 机构停业 / 增项未告知 / 效果与方案严重不符），申请终止治疗并退费。
请求：
1. 退还尚未提供服务部分的费用 ¥××××（计算方式：已付 − 已完成疗程对应费用 − 已交付矫治器成本）
2. 提供完整病历、影像资料与矫治器品牌授权证明的复印件
请于 7 个工作日内书面答复。
                                        申请人：    日期：
```

**务必**：用 EMS 寄送并保留面单，或当面提交要求签收。

## 卡片 D：投诉时怎么说

- **12315（收费争议、虚假宣传、格式条款）**：
  「我在 ×× 机构做牙齿矫正，报价 ¥××，事后以增加 ×× 项目为由加收 ¥××，
  签约时未告知。合同写有『概不退费』。请求调解退费。」

- **卫健部门（资质问题）**：
  「我查询到 ×× 医师的执业地点不是该机构 / 该机构诊疗科目不含口腔科，
  请核查其执业资质。」（附查询结果截图）

- **金融监管部门（分期问题）**：
  「办理分期时未告知年化利率与提前终止条款，且服务机构已停业，请求核查放款方合规性与终止合同。」

## 卡片 E：效果争议时的取证顺序

1. 立即复印封存病历、方案书、影像资料（全景片、侧位片、CBCT）
2. 整理自己拍的牙齿照片时间线（正面、侧面、咬合）
3. 书面要求机构出具「实际治疗方案与初始方案的差异说明」
4. 必要时申请**医疗损害鉴定**——是否构成损害以鉴定意见为准，不要靠主观感受争论
5. 到当地**医疗纠纷人民调解委员会**申请调解，调解不成再起诉

## 卡片 F：硬性时间纪律

- 医疗损害责任纠纷诉讼时效三年，自知道或应当知道损害之日起算
- 病历影像资料越早复印越完整，机构停业后调取难度陡增
- 主张退费的，先书面提出并留送达凭证，这决定后续能否主张利息与违约责任
