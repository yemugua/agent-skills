# 衣物收纳与断舍离清单（wardrobe-audit-check）

断舍离最难的不是"想扔"，是**"不知道怎么判断该不该扔"**。所以这个技能把判断标准做成**可执行的量化判据**，而不是靠感觉。

另一个高频误区是**为了收纳而买更多收纳工具**。物品量没减少，只是换了个地方堆着，结果是衣柜更满了。

这个技能做三件事：**先定判据** → **再定收纳法** → **最后定周期**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出五条可执行的断舍离量化判据 | ❌ 代替使用者做价值判断与情感决策 |
| 说明收纳前提条件 | ❌ 承诺真空压缩后性能不受影响 |
| 给出按使用频率的分类收纳法 | ❌ 判断衣物是否达到可捐标准 |
| 说明压缩袋适用与禁忌 | ❌ 指导衣物染色修复与专业护理 |
| 给出通风与检查周期建议 | ❌ 判断室内湿度是否达标 |

**遇到以下情况，转交专业护理或处理：**

- **需要判断衣物是否达到捐赠或回收标准**：涉及接收方的要求，应向接收方确认
- **需要处理污渍渍洗不掉的衣物**：属专业洗涤与去渍范围
- **涉及真丝、羊绒等需专业护理的贵重衣物**
- **涉及染色、串色、变形的修复**
- **衣物出现大面积霉变或虫害**

## 二、完整工作流

```
第 1 步  读规则文件 rules/wardrobe_rules.md（五条判据 + 收纳法 + 压缩禁忌 + 周期）
第 2 步  先做收纳前提：洗净、晾干、除味
第 3 步  按五条量化判据逐件判断，不靠感觉
第 4 步  做减量之后再配置收纳工具（顺序不能反）
第 5 步  按使用频率而非类别分类收纳
第 6 步  压缩袋只用于适合的物品，并记录取出时间
第 7 步  建立除湿、通风与定期检查机制
```

## 三、第 2 步：收纳前提（四条）

**这一条比任何收纳技巧都重要——前提没做到位，后面全是白整理。**

| 前提 | 要求 | 不满足的后果 |
|---|---|---|
| **洗净** | 收纳前必须洗净，去除污渍与残留 | 污渍在密闭环境会固化发黄，且易招虫 |
| **晾干** | 必须完全晾干，含水率达标 | 潮湿衣物在柜内会发霉、长异味 |
| **除味** | 有异味需先处理再收纳 | 异味在密闭空间会渗透到其他衣物 |
| **理平** | 折痕已理平，出水已拧干 | 褶皱定型后更难处理 |

**验证方法**：取一件收纳好的衣物摸一下折痕处与领口袖口，**如果摸上去还有潮感或有明显气味，就是没干透或没洗净**。

---

## 四、第 3 步：五条量化断舍离判据

**这五条不是建议，是可以逐件对照执行的判据。**

| 编号 | 判据 | 具体判定方法 | 处理 |
|---|---|---|---|
| 1 | **一年未穿且场合无延伸可能** | 取出后回看最近一年是否有穿着记录；问自己"未来一年会不会穿"，且**不是"万一呢"的场合** | 处置或转赠 |
| 2 | **同功能重复且有明确短板** | 同一功能（如保暖外套）有多件，其中某件在保暖、耐穿、好搭配上明确更差 | 处置短板件 |
| 3 | **清洗后已变形** | 缩水、起球到无法接受程度、领口松垮、袖子变形 | 视情况处置，不抱期望修复 |
| 4 | **护理成本超过价值** | 需要专业护理或干洗的成本，已明显超过该物品的实际使用价值 | 处置 |
| 5 | **购买冲动未兑现** | 买时很想要，但至今没穿过或只穿过一两次，且**不是没机会而是没想穿** | 处置 |

**关于情感价值的处理方式**：

- 判据 1 里的"舍不得"可以单独处理：设一个**明确的最终期限**，到期仍未穿则处置
- **但不要用"有纪念意义"无限期豁免**——纪念品可以单独收进一个盒子，但那是"收藏"不是"衣物"，不应该占衣柜里的衣物位
- **实际占用是要算的**：一件"舍不得"占了半格空间，一年不穿一次，这个代价值得算清楚

**执行建议**：**一次处理一个类别**，不要试图一次清空整个衣柜。混着做会陷入"处理一件、后悔一件"的循环。

---

## 五、第 4 步：先减量，再配置工具（顺序不能反）

**这是断舍离最高频的失败模式。**

| 错误顺序 | 后果 |
|---|---|
| 先买收纳盒 → 再想怎么放 | 物品量没减少，换个地方堆着，还买了用不上的尺寸 |
| 先买真空压缩袋 → 再压缩所有衣服 | 不该压缩的被压缩，到家回弹变差，且箱子越换越多 |
| 先买挂钩 → 再挂所有衣服 | 衣服没减，挂钩堆满，看取用更难 |

**正确顺序**：判据逐件过 → 处置不需要的 → **盘点剩余量** → 根据剩余量选工具。

**处置方式的选择**：

| 方式 | 适用 | 注意 |
|---|---|---|
| 二手转赠 | 状况良好且仍可使用 | 转赠前清洁整理，转赠对象自己确认 |
| 捐赠 | 状况良好 | **是否达到接收方标准由接收方确认** |
| 回收 | 不适合再穿的纺织品 | 各地回收要求不同，先确认是否接收 |
| 丢弃 | 已破损无法使用 | 按当地分类要求处理 |

## 六、第 5 步：按使用频率分类收纳

**核心原则：按使用频率收纳，不按类别收纳。**

**按类别收纳**的问题是"要穿的时候要翻遍所有同类"；**按频率收纳**的逻辑是"常穿的放在一起，一眼看到就拿到"。

| 频率档 | 定义 | 收纳位置 | 收纳形式 |
|---|---|---|---|
| **高频** | 每周或每月穿 | 腰到肩的高度，伸手可及 | 悬挂或敞口折叠盒 |
| **中频** | 每季穿 | 上层或中上层 | 带盖收纳盒 |
| **低频** | 每年几次或更少 | 顶层或床底储物 | 密封收纳箱 |
| **季节性** | 只在特定季节穿 | 当季放外层，反季放深层 | 真空压缩或密封收纳 |

**三条实操要点**：

1. **高频物品按人或按场合分组**：一个人的高频衣物集中放，找起来最快
2. **容器高度匹配**：容器过高时，上层衣物难取且易倒落
3. **同类叠放**：同一容器内按类叠放，比一件一格更容易看清存量

---

## 七、真空压缩袋：适用与禁忌

**这一条最容易出事，因为它的问题往往在几个月后才显现。**

| 物品 | 能否长期压缩 | 原因 |
|---|---|---|
| 羽绒被、羽绒服 | ❌ **不建议长期** | 长期压缩破坏绒簇结构，蓬松度难以恢复 |
| 羊毛被、羊毛衫 | ❌ **不建议** | 羊毛纤维受压易产生折痕，恢复困难 |
| 蚕丝被 | ❌ **不建议** | 长期压缩可能造成结构变形 |
| 厚被褥、棉被 | ✅ 可以 | 棉纤维受压变形影响较小 |
| 床品、被套、枕套 | ✅ 可以 | 纯棉织物短期或长期压缩均无碍 |
| 毛毯 | ✅ 可以 | 无填充结构 |
| 羽绒外套 | ⚠️ **短期可以，长期不行** | 与羽绒服同理，问题显现滞后 |
| 呢料大衣 | ⚠️ 谨慎 | 长期压缩可能产生折痕 |

**使用要求**：

- **短期运输压缩与长期存储是两回事**：超过一两个月的压缩不要用于羽绒与羊毛
- **记录取出时间**：取出后立即摊开，让填充物回弹
- 不要抽到完全真空，留一点余量更稳妥
- 压缩袋要防漏，破损后物品会缓慢回弹变潮

**取出后的动作**：**立即取出并彻底摊开**。这一步不能省，也不能拖到第二天。

## 八、通风与定期检查

| 周期 | 动作 |
|---|---|
| 每月 | 打开衣柜通风一次；检查有无异味与潮气 |
| 每季 | 换季时整理一次，检查衣物有无受潮、霉变、虫害 |
| 梅雨季前 | 重点检查靠外墙、底层的衣物；准备除湿 |
| 供暖季 | 检查是否有干燥过度导致的静电与脆化 |
| 每年 | 全面清理：按五条判据再过一遍 |

**除湿方式**：

- **开门窗形成对流通风**：单向开窗不换气，效果有限
- **使用除湿设备**：梅雨季与回南天尤其重要
- **衣物完全干燥后再放入**：这是最基础也最有效的一条
- **柜内留出空隙**：塞满会形成不通风的闷袋

## 九、三种常见误区

| 误区 | 问题 | 正确做法 |
|---|---|---|
| **为了收纳而买更多收纳工具** | 物品量没减少，只是换地方堆着 | 先减量，再配置工具 |
| **断舍离变成囤积收纳工具** | 买了很多盒子箱子，物品总量没变，反而更占地方 | 工具按剩余量买，不预留 |
| **把"舍不得"当情感价值长期豁免** | 占着空间一年穿一次，实际占用代价值得算清 | 设明确期限；纪念品单独收进收藏盒，不占衣物位 |

## 十、脚本用法

```bash
python scripts/wardrobe_audit.py --text "一年没穿的衣服还留着，真空袋能装羽绒服吗"
python scripts/wardrobe_audit.py --file 情况.json --out 结果.md
```

| 参数 | 说明 |
|---|---|
| `--text` | 直接描述衣物与收纳困惑 |
| `--file` | 从文件读，支持 `.txt` / `.md` / `.json`（JSON 用 `{"desc": "..."}`） |
| `--out` | 结果落盘路径 |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 跑内置样例自检 |

脚本做三件事：匹配五条量化判据、检查真空压缩适用与禁忌、检查收纳前提是否满足。

> 脚本是关键词匹配，**不等于价值判断**。判据帮你把问题问清楚，最后的决定仍由你自己做。

## 十一、人工确认清单（这步不能省）

- [ ] 所有衣物已洗净
- [ ] 所有衣物已完全晾干（折痕处与领口袖口无潮感）
- [ ] 有异味的衣物已先处理
- [ ] 已按五条判据逐件过，而不是凭感觉
- [ ] "舍不得"的物品已设定明确期限
- [ ] 处置方式已确认（转赠、捐赠、回收、丢弃）
- [ ] 是先做完减量再买收纳工具
- [ ] 已按使用频率而非类别分类
- [ ] 压缩袋只用于适合的物品
- [ ] 已记录压缩袋的取出时间，到家后立即取出摊开
- [ ] 已建立每月通风与每季检查的机制

## 十二、最常见的坑

**坑一：没晾干就放进柜子。**
这是衣柜长霉与长异味最常见的原因。摸折痕处和领口，还有潮感就是没干透。

**坑二：先买收纳盒再断舍离。**
物品量没减少，只是换了个地方堆。而且往往买了用不上的尺寸。

**坑三：把羽绒服真空压缩半年。**
蓬松度难以恢复，而这个问题要过几个月才显现，到时已没法补救。

**坑四：按类别收纳。**
"要穿的时候要翻遍所有同类"。按频率收纳，常穿的放一起，找起来最快。

**坑五：柜子塞满。**
塞满会形成不通风的闷袋，潮湿与闷味都排不出去。

**坑六：用"有纪念意义"无限期豁免。**
纪念品可以单独收进收藏盒，但那是收藏不是衣物，不该占衣柜的衣物位。

**坑七：一次想清空整个衣柜。**
容易陷入"处理一件、后悔一件"的循环。一次处理一个类别更可持续。

**坑八：收纳前不检查有没有虫蛀。**
一件有虫的衣服放进柜里，可能影响整柜。收纳前抖一抖、检查一下。

**坑九：压缩袋取出后不立即摊开。**
填充物回弹需要时间，拖着不回弹会留下折痕。

**坑十：梅雨季不检查底层衣物。**
底层与靠外墙的位置最容易受潮，而这个位置的衣物最容易被忽略。

## 十三、边界与免责

- 本技能**不替代**衣物修复、专业洗涤与去渍
- 是否达到捐赠或回收标准**由接收方确认**，本技能不提供判断
- 压缩后的性能影响因产品而异，**以产品与护理标签说明为准**
- 室内湿度是否达标涉及检测，**结论以有资质的检测为准**
- 涉及真丝、羊绒等贵重衣物的护理，按**衣物洗涤标签与专业机构建议**处理
