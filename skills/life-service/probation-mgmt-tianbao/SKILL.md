# 试用期合规管理（probation-mgmt）

> 领域：招聘 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《劳动合同法》第十九条/二十一条，生成试用期合规清单：期限合法性、可举证录用条件、工资≥80%与考核解除程序。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 试用期
- 试用期期限
- 录用条件
- 试用期工资
- 试用期解除
- 劳动法合规

## 三、工作流
1. 核对试用期期限与合同期对应合法
2. 明确可举证的录用条件
3. 确认试用期工资≥转正80%
4. 建立考核与解除程序
5. 留痕与合规归档

## 四、核心内容（检查清单与判定）
《劳动合同法》第十九条按合同期限限定试用期上限；第二十一条规定试用期中不得无正当理由解除，须以录用条件不符并举证。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未明试用期期限合法（合同期对应） | 期限 |
| Q2 | FAIL | 未明确录用条件（可举证） | 录用条件 |
| Q3 | WARN | 未含试用期工资≥80% | 工资 |
| Q4 | FAIL | 未含考核与解除程序 | 程序 |

> 脚本 `probation-mgmt_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python probation-mgmt_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python probation-mgmt_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
