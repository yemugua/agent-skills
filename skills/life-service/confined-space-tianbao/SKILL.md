# 有限空间作业安全管理（confined-space）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《工贸企业有限空间作业安全管理与监督暂行规定》与 GB 30871，生成有限空间清单：辨识建账、审批（先通风后检测再作业）、监护与应急。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 有限空间
- 受限空间
- 有限空间作业
- 污水池作业
- 储罐作业
- 通风检测

## 三、工作流
1. 辨识有限空间并建立台账
2. 作业审批（先通风-再检测-后作业）
3. 通风与检测（氧含量/有毒有害）
4. 设置专职监护与通讯
5. 配备应急装备、严禁盲目施救

## 四、核心内容（检查清单与判定）
有限空间作业须执行‘先通风、再检测、后作业’；检测合格方可进入，设专职监护，配备呼吸器等应急装备，严禁盲目施救。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未辨识有限空间并建立台账 | 辨识 |
| Q2 | FAIL | 未含作业审批（先通风后检测再作业） | 审批 |
| Q3 | WARN | 未含通风/检测（氧含量/有毒有害） | 检测 |
| Q4 | FAIL | 未设专职监护 | 监护 |
| Q5 | WARN | 未含应急装备与严禁盲目施救 | 应急 |

> 脚本 `confined-space_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python confined-space_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python confined-space_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
