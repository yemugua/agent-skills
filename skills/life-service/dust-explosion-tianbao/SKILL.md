# 粉尘防爆管理（dust-explosion）

> 领域：EHS ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《工贸企业粉尘防爆安全规定》与 GB 15577《粉尘防爆安全规程》，生成粉尘防爆清单：涉粉作业辨识、爆炸危险区域划分、通风除尘、防静电、动火与清理、泄爆抑爆。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 粉尘防爆
- 涉爆粉尘
- 铝镁粉尘
- 粉尘清理
- 防爆区域

## 三、工作流
1. 辨识粉尘涉爆工艺与物质（铝镁/木屑/粮食）
2. 划分爆炸危险区域并设防爆电气
3. 设置通风除尘与防积尘清理
4. 采取防静电与禁火措施
5. 配置泄爆/抑爆/隔爆等防护

## 四、核心内容（检查清单与判定）
《工贸企业粉尘防爆安全规定》与 GB 15577 要求对涉爆粉尘进行辨识、分区、通风除尘、防静电与定期清理，并配置泄爆抑爆等安全装置。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含粉尘涉爆辨识（物质/工艺） | 辨识 |
| Q2 | FAIL | 未含爆炸危险区域划分 | 分区 |
| Q3 | WARN | 未含通风除尘与防积尘 | 通风 |
| Q4 | FAIL | 未含防静电与禁火措施 | 防静电 |
| Q5 | WARN | 未含泄爆/抑爆/隔爆防护 | 防护 |

> 脚本 `dust-explosion_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python dust-explosion_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python dust-explosion_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
