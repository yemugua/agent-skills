# 游泳换气动作与错误纠正

## 你会得到什么

一套把换气拆成「先练呼气、再定时机」的分阶练习口径，解决蛙泳抬头吸不到气、自由泳一换就沉、一换气腿就停这三类高频问题。

- **机制拆解**：吸气 0.5-1 秒用口、呼气占周期 70-80% 且脸一入水就开始，一句口诀「水下一直吐，上来只管吸」。
- **蛙泳换气**：六位置分解（滑行→划手→吸气→伸手→蹬夹→滑行），口诀「划手抬头吸，伸手低头呼，蹬腿滑一滑」，六个错误的纠正动作。
- **自由泳换气**：转头不抬头、一只泳镜在水下、看侧后方、手臂入水时脸同步转回；「呼吸口袋」与转头时机表；七个错误的纠正动作。
- **七阶练习表**：陆上呼气 → 池边扶边 → 蹬边漂浮 → 扶板打腿 → 单臂划手 → 完整配合 → 双侧换气，每阶都给了组数与达标标准。
- **按症状定位表**：呛水、下沉、吸不到气、脖子酸、练了很久没进步，各自先查什么、通常结论是什么。
- **溺水风险红线**：场所、同伴、水深、身体状态、闭气、儿童看护、耳部共七条，含浅水晕厥提示。

## 典型用法

- 已能在泳池游几下，但换气总呛水，想知道先练什么
- 自由泳换气时身体下沉，判断是抬头还是停腿
- 蛙泳抬头吸不到气，核对划手与抬头的先后
- 想自学换气，先确认场所与安全措施是否达标
- 练了一个月没进步，用症状表和分阶表定位卡在哪一阶

## 边界

不替代游泳教练的现场教学与保护，不替代救生员的看护职责。**完全不会游泳者请报正规游泳班，不要独自下水。** 有心肺疾病、高血压、癫痫、耳部疾病或孕期，下水前应取得医生许可。练习必须在有救生员值守的标准泳池浅水区进行，禁止野外水域、无值守场所和深水区练习，禁止闭气挑战与下水前过度换气。
