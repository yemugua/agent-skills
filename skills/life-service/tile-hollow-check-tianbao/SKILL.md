# 瓷砖空鼓

## 1. 硬边界表

| 能做 | 不能做 |
|---|---|
| 给空鼓敲击判断方法 | 替代专业监理 |
| 给空鼓率合格标准 | 做工程验收法定结论 |
| 给返工处理工艺清单 | 处理施工纠纷 |
| 标出须转交专业的项 | 指导拆改承重结构 |

本技能只做检查与判断清单，不做法律定性。大面积空鼓应请专业人员确认。

## 2. 什么时候用

| 用户说法 | 用本技能 |
|---|---|
| 「瓷砖空鼓怎么查」 | 用 |
| 「空鼓率多少合格」 | 用 |
| 「空鼓要返工吗」 | 用 |
| 「这算不算施工质量」 | 不用，转专业 |

## 3. 完整工作流

1. 用空鼓锤（或硬币）逐砖轻敲，听声辨空实。
2. 标记空鼓砖位置与范围（整块/边角/中心）。
3. 统计空鼓砖数与比例。
4. 按 `rules/tile-rules.md` 对照标准判定。
5. 边角/单砖超标标记返工；整体超标标记大面积整改。
6. 对照人工确认清单核对。

## 4. 核心规则

先读 `rules/tile-rules.md`：敲击声判别、单砖空鼓率、边角禁空鼓、整体空鼓率标准、返工工艺与红线项。

## 5. 脚本用法

```
python scripts/check.py --file 空鼓记录.json
python scripts/check.py --selftest
```

`--file` 含 total_tiles、hollow_tiles（整砖空鼓数）、edge_hollow（是否有边角空鼓）、hollow_ratio（整体空鼓率百分比）等字段。

## 6. 人工确认清单

- [ ] 是否逐砖敲击（非抽样）
- [ ] 边角是否有空鼓（边角禁空鼓）
- [ ] 单砖空鼓是否 >5%
- [ ] 整体空鼓率是否 ≤5%
- [ ] 空鼓砖位置（厨卫墙面/地面）
- [ ] 是否有「须转交专业」大面积项

## 7. 最常见的坑

1. 只敲几块抽样，漏掉大面积空鼓。
2. 分不清实声与空声，误判。
3. 边角空鼓忽视，后期掉砖。
4. 整体空鼓率超 5% 仍接收，隐患大。
5. 厨卫墙面空鼓未重点查，挂重物掉落。
6. 空鼓砖不返工，热胀冷缩后碎裂。
7. 返工只换砖不重做基层，再次空鼓。

## 8. 边界与免责

本技能为自查清单，不替代专业监理。大面积或厨卫关键位空鼓应请专业人员确认。本技能不做法律定性。
