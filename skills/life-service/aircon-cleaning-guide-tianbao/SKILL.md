# 空调清洗

## 1. 硬边界（能做什么 / 不能做什么）

| 能做 | 不能做（转专业人士） |
|---|---|
| 断电后拆洗滤网、外壳擦拭 | 拆开内机电路、动压缩机 |
| 喷洗蒸发器翅片（专用清洗剂） | 高压水冲电机 / 电路板 |
| 滤网每月除尘、换季深度洗 | 加氟、冷媒相关维修 |

内机漏水严重、异响、电路板烧糊味，转空调维修。

## 2. 什么时候用

| 用户说法 | 用不用 |
|---|---|
| 开空调有霉味 | 用（洗蒸发器） |
| 滤网发黑、出风变小 | 用（洗滤网） |
| 换季第一次开机 | 用（深度洗一次） |
| 制冷完全不行 | 不用（可能缺氟，转维修） |
| 内机滴水不止 | 不用（排水管 / 安装问题） |

## 3. 完整工作流

1. **断电**：拔插头或关空调专用空开，确认无电再动手。
2. 掀面板、取滤网，用软刷 + 中性洗剂水冲，阴干勿暴晒。
3. 套好防水罩，将空调清洗剂均匀喷在蒸发器翅片上，静置 15 分钟溶解污垢。
4. 用喷壶清水少量喷冲翅片（勿冲电机 / 电路板），污水从排水管流出。
5. 滤网装回、合面板，开机送风吹 30 分钟排残味。
6. 外机视情况用软毛刷清翅片灰尘（断电、低压水冲）。

周期与判定见 `rules/cleaning-rules.md`。

## 4. 核心规则 / 要件说明

生成清洗方案前**先读 `rules/cleaning-rules.md`**：周期、清洗剂用法、禁冲部位都有强制口径。不合格带原因，如「未断电：带电拆机有触电风险，必须先断电」。

## 5. 脚本用法

`scripts/ac_check.py` 自检「清洗操作清单」顺序与完整性：

```
python scripts/ac_check.py --file steps.json
python scripts/ac_check.py --selftest
```

## 6. 人工确认清单

- [ ] 已断电（拔插 / 关空开）
- [ ] 滤网已拆下清洗阴干
- [ ] 蒸发器喷剂静置 ≥15 分钟
- [ ] 未冲电机 / 电路板
- [ ] 开机通风 ≥30 分钟

## 7. 最常见的坑

1. 不断电就拆：触电风险，必须第一步断电。
2. 滤网暴晒：变形漏风，阴干即可。
3. 清洗剂喷到电路板：短路，先盖防水罩、避开电控盒。
4. 高压水直冲翅片：翅片倒伏影响换热，用低压雾状。
5. 只洗滤网不洗蒸发器：异味源在蒸发器，白洗。
6. 一年不洗：滤网每月除尘、换季深度洗，久积菌霉。

## 8. 边界与免责

覆盖家用壁挂 / 柜机日常清洗。中央空调、冷媒加注、电路维修不在范围。清洗剂选专用中性，避免腐蚀翅片；高空外机作业请专业人员。
