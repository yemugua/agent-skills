# 猫砂盆选择与清理排查

## 你会得到什么

一套**配盆、选砂、查原因**的猫砂配置口径。猫不进猫砂盆，绝大多数不是"盆不够大"，是盆型、位置、清洁度或猫本身状态这四项之一出了问题——而且**尿在盆外、憋着不进盆，和公猫尿闭是完全不同的两件事**。

- **猫数加一配置表**：1 只 2 个、2 只 3 个、3 只 4 个、n 只 n+1 个，并说明为什么是加一（分散需求 + 清洁时另一个盆还能用，**猫对正在被清理的盆接受度很低**）。
- **尺寸口径**：把猫放进去后能自然伸展身体、有多余空间；顶盖式盆开口要够猫进出；幼猫与老年猫用低边入口。
- **四种盆型与猫的偏好**：开放式、半封闭（顶盖）、全自动、极大号盆，各写猫的接受倾向，含「**没有哪种盆型最好，只有哪种你的猫愿意用**」与**换盆型必须新旧并排**的做法。
- **位置七项要求**：安静、不堵、有遮挡但不压抑、通风但不穿堂、分散摆放、靠近饮水与休息区、不在洗衣机旁；点明最常见的四个错误位置。
- **四类猫砂七维对比**：膨润土、豆腐砂、木砂、水晶砂，按粉尘、结团力、误食风险、清理方式与适用场景逐项对照。
- **误食风险**：**豆腐砂最容易被误食**（外观与气味接近食物），幼猫与好奇的猫风险更高；**发现误食后不要催吐，尽快联系兽医**。
- **能否冲厕**：取决于产品说明与自家管道状况，**不确定就不要冲**；膨润土与水晶砂通常不可冲。
- **换砂类型不要一次全换**：做新旧混合过渡。
- **清洁除味口径**：每天铲 1-2 次、猫排便后尽快铲、中性清洁剂不用香味、**除味的关键不是加香味**（织物、地面缝隙、墙角残留才是味道来源）。
- **十二类原因排查顺序**：尿闭急症 → 盆脏 → 盆太小 → 位置 → 盆型 → 猫砂类型 → 砂太厚 → 盆太干净或太脏 → 多猫抢占 → 意外 → 年龄或行动不便 → 环境变化。
- **乱尿两种情况的区分**：排尿姿势正常且能排出尿（多为行为或环境）vs 排不出尿或排尿疼痛（急症）。
- **十一条就医红线**与**记录要求七项**（行为排查靠排除法，只有记录才能排除）。

## 典型用法

- 家里两只猫要几个猫砂盆
- 猫砂盆该放哪，洗衣机旁边行不行
- 豆腐砂和膨润土砂选哪个，豆腐砂能冲马桶吗
- 猫突然不进猫砂盆了
- 猫砂盆味道太大，用香味产品盖住行不行
- 公猫在盆外蹲着但尿不出来

## 边界

不替代兽医对排尿异常的诊断。**不推荐任何猫砂、盆或除味产品的品牌**。**不诊断尿路疾病，也不提供任何药物名称与剂量**。**公猫尿闭等急症请立即就医，不做行为排查**。幼猫（尤其未满月）无法排尿属急症。**豆腐砂等误食后不要自行催吐**。能否冲入马桶取决于产品说明与自家管道状况，不确定就不要冲。**"突然乱尿"优先排查身体与环境因素，不作为行为问题处理**。
