# 拒绝使用猫砂盆的排查顺序与就医红线

> 排查必须按顺序，不能跳步。多数家庭只做了第一步和第二步就下结论了。

## 一、就医红线（出现任一条）

| 情况 | 紧急程度 |
|---|---|
| 公猫频繁进猫砂盆却尿不出、蹲坐时间异常长、频繁舔下体 | 立即就医 |
| 公猫龟头长时间露在包皮外 | 立即就医 |
| 猫砂盆中几乎没有尿、或只有几滴 | 立即就医 |
| 猫排尿时明显疼痛、叫声尖锐、血尿 | 尽快就医 |
| 公猫蹲在盆外做出排尿姿势但无尿 | 立即就医 |
| 超过 24 小时未见排尿记录（幼猫尤其危险） | 尽快就医 |
| 尿血、尿液浑浊带沉淀、有明显异味 | 尽快就医 |
| 排尿姿势正常但尿在盆外，且伴有舔下体频繁 | 尽快就医（可能是疼痛导致） |
| 猫在盆外排尿同时出现舔生殖器异常、阴茎红肿 | 尽快就医 |
| 幼猫（尤其未满月）无法排尿 | 立即就医 |
| 母猫持续舔外生殖器、外生殖器异常红肿或分泌物增多 | 尽快就医 |

## 二、关键区分

| 情况 | 特征 | 处理方向 |
|---|---|---|
| 尿在盆外但排尿姿势正常、能排出尿 | 多为盆型、位置、清洁、或情绪标记 | 按十二类顺序排查 |
| 排不出尿或排尿疼痛 | 尿闭或尿路问题，急症 | 立即就医，不做行为排查 |

**把前者当后者会延误救命。**

**另一个常被误判的情况**：猫**突然**开始乱尿，尤其是本来一直用盆的猫突然不用——**"一直很乖的猫突然乱尿"更可能是身体或环境出了问题，不是行为变坏**。

## 三、十二类原因排查顺序

| 顺序 | 原因 | 怎么查 | 处理方向 |
|---|---|---|---|
| 1 | 尿闭等泌尿问题（急症） | 是否频繁进盆却尿不出、蹲坐久、舔下体频繁 | 先排红线，是急症立即就医 |
| 2 | 盆脏 | 有没有超过 1 天没铲、盆底是否有积尿块 | 增加铲屎频率 |
| 3 | 盆太小 | 猫放进去能否转身、伸展 | 换大一号盆 |
| 4 | 位置不合适 | 是否在噪音源、走动频繁处、门口 | 移位 |
| 5 | 盆型不合适 | 猫是否害怕封闭、是否喜欢隐蔽 | 换盆型或并排放新旧盆 |
| 6 | 猫砂类型不喜欢 | 是否刚换过砂、是否刚倒上新砂 | 新旧砂混合过渡，逐步替换 |
| 7 | 猫砂太厚 | 砂层厚度是否过深 | 减薄到合适的厚度 |
| 8 | 盆太干净或太脏 | 是否刚洗过盆、有没有残留气味 | 恢复正常使用即可 |
| 9 | 多猫互相抢占 | 是否有猫被阻挡、是否都在用同一个盆 | 增加盆数、分散摆放 |
| 10 | 意外（惊吓、噪声） | 近期是否有搬家、装修、新成员 | 恢复安静环境，给适应时间 |
| 11 | 年龄或行动不便 | 幼猫、老年猫、行动不便的猫 | 改低边入口、更大更浅的盆 |
| 12 | 环境变化或压力 | 新成员、访客、作息变化、窗外变化 | 减少压力源，提供退避空间 |

**第 1 条必须先排**：把尿闭当成"行为问题"去调盆换砂，是可能延误的路径。

## 四、乱尿的两种情况

| 情况 | 特征 | 处理方向 |
|---|---|---|
| 排尿姿势正常、尿能排出、尿在盆外 | 多为盆型、位置、清洁、或情绪标记 | 按十二类顺序排查；也可能是领地标记行为 |
| 排不出尿或排尿疼痛 | 尿闭或尿路问题，急症 | 立即就医，不做行为排查 |

## 五、记录要求

| 记录什么 | 怎么记 |
|---|---|
| 排尿次数 | 按天记，异常增多或减少要能看出来 |
| 排尿地点 | 盆内还是盆外，具体位置 |
| 盆使用情况 | 有没有进去、停留多久、是否正常使用姿势 |
| 清洁记录 | 每次铲的时间、每次换砂的时间 |
| 猫砂更换 | 换的时间、类型、过渡方式 |
| 盆的位置调整 | 调整时间与前后对比 |
| 多猫情况 | 每只的排尿情况分别记 |

**为什么要逐项记**：行为问题的排查靠的是**排除法**，只有记录才能排除。凭记忆回想"好像上周开始的"，通常定位不到。

## 六、明确禁止

- 不推荐任何猫砂、盆或除味产品的品牌
- 不诊断尿路疾病，也不提供任何药物名称与剂量
- 不在尿闭急症上做行为排查
- 发现豆腐砂等误食后不自行催吐
- 不在不确定产品说明与管道状况时把猫砂冲入马桶
- 不把"突然乱尿"直接当作行为问题处理
- 不用强烈香味清洁剂或香味产品掩盖异味
