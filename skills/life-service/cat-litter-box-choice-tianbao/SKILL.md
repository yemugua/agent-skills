# 猫砂盆选择与清理排查（cat-litter-box-choice）

猫不进猫砂盆，**绝大多数不是"猫砂盆不够大"，是盆型、位置、清洁度或猫本身状态这四项之一出了问题**。而且尿在盆外、憋着不进盆，和**公猫尿闭**是完全不同的两件事——后者是急症。

这个技能做三件事：**配盆 → 选砂 → 查原因**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出数量、尺寸、位置与盆型配置口径 | ❌ 判断猫不进盆是否由泌尿系统疾病引起 |
| 给出四类猫砂的差异对比与适用场景 | ❌ 推荐具体品牌与商品 |
| 给出拒绝使用猫砂盆的原因排查顺序 | ❌ 诊断尿路疾病或给出治疗方案 |
| 给出清洁、除味与换砂的频率口径 | ❌ 处理公猫尿闭这类急症 |
| 给出乱尿的行为与排查区分口径 | ❌ 提供任何药物名称与剂量 |

**就医红线（出现任一条，尽快联系兽医；标注急诊的直接去急诊）**

- **公猫频繁进猫砂盆却尿不出、蹲坐时间异常长、频繁舔下体** —— 尿闭是急症，**立即就医**
- **公猫龟头长时间露在包皮外** —— 立即就医
- **猫砂盆中几乎没有尿、或只有几滴** —— 立即就医
- **猫排尿时明显疼痛、叫声尖锐、血尿** —— 尽快就医
- **公猫蹲在盆外做出排尿姿势但无尿** —— 尿闭信号，立即就医
- **超过 24 小时未见排尿记录**（幼猫尤其危险）—— 尽快就医
- **尿血、尿液浑浊带沉淀、有明显异味** —— 尽快就医
- **排尿姿势正常但尿在盆外，且伴有舔下体频繁** —— 尽快就医（可能是疼痛导致）
- **猫在盆外排尿同时出现舔生殖器异常、阴茎红肿** —— 尽快就医
- **幼猫（尤其未满月）无法排尿** —— 立即就医
- **母猫持续舔外生殖器、外生殖器异常红肿或分泌物增多** —— 尽快就医

**关键区分**：**尿在盆外但排尿姿势正常、能排出尿**，多半是行为或环境问题（盆型、位置、清洁）；**排不出尿、蹲很久尿不出**，是尿闭急症。**这两件事的处理完全不同，把前者当后者会延误救命。**

## 二、完整工作流

```
第 1 步  先排红线：先确认是不是尿闭，是就走急症流程，不往下走
第 2 步  数猫：按猫数加一原则算盆数
第 3 步  选盆型：按猫的偏好（有的猫要开放式、半封闭、全自动各有偏好）选
第 4 步  定位置：安静、不堵、通风、分散摆放
第 5 步  选猫砂：按粉尘敏感度、结团力、误食风险、清理频率选
第 6 步  设频率：铲屎与换砂频率按猫数与类型定
第 7 步  有问题再排查：按十二类原因逐项排，不跳步
第 8 步  记录：记录排尿、盆使用情况与清理记录，便于找规律
```

**顺序不能颠倒**：不排红线就开始调盆和换砂，遇到尿闭就白折腾，甚至延误。

## 三、配置口径

### 3.1 数量：猫数加一

| 猫数 | 建议盆数 | 说明 |
|---|---|---|
| 1 只 | 2 个 | 单猫也需要备选，避免与清洁时段冲突 |
| 2 只 | 3 个 | 猫之间可能互相抢占 |
| 3 只 | 4 个 | 同上 |
| n 只 | n+1 个 | 通用口径 |

**为什么是加一**：猫可能因为不喜欢当前盆而去找别的位置，**多备一个可以分散这种需求**；同时清洁一个盆时，另一个盆还能用——**猫对正在被清理的盆接受度很低**。

**如果是多猫且互相抢占位置**：需要考虑盆的**分布摆放**，而不是简单放在一个角落。

### 3.2 尺寸

| 判据 | 口径 |
|---|---|
| 基本要求 | 猫能完全进去并转身、能舒展趴下 |
| 更实用的判据 | **把猫放进去后，它能自然伸展身体、有多余空间** |
| 参考 | 猫的体长（鼻尖到尾根）加余量；**顶盖式的盆开口要够猫进出** |
| 深盆与浅盆 | 幼猫、行动不便的老猫更适合**低边入口**，进出不费力 |
| 太小是最常见问题之一 | 猫挤在盆里会直接关联到拒绝使用 |

### 3.3 盆型与猫的偏好

| 盆型 | 特点 | 猫的偏好倾向 |
|---|---|---|
| 开放式 | 无顶盖、侧壁低，视野好、进出自由、空气流通 | 多数猫更容易接受；顶盖聚味反而可能劝退 |
| 半封闭（顶盖） | 有顶盖，视觉遮蔽、聚味、减少气味扩散 | 部分猫偏好隐蔽感；部分猫不喜欢封闭 |
| 全自动猫砂盆 | 自动或半自动清理，卫生与频率上省事 | 取决于个体；**噪音、震动、滚筒转动可能吓到猫** |
| 极大号盆 | 空间充裕，常配合顶盖 | 跳跃力好的猫可能喜欢 |

**没有"哪种盆型最好"，只有"哪种你的猫愿意用"**。多猫家庭里，同一种猫对盆型的偏好也可能不同。

**换盆型的做法**：**并排放新旧两个盆**，让猫自己选择，不要一次只留新的。**直接把旧盆撤掉换新盆，猫可能因为不认识新盆而拒绝使用**。

### 3.4 位置

| 要求 | 原因 |
|---|---|
| 安静 | 噪音、震动、机器运转会劝退 |
| 不堵 | 人流经过、门口、洗衣机旁会让猫觉得不安全 |
| 有遮挡但不压抑 | 猫需要"能观察、也能退避"的空间 |
| 通风但无穿堂风 | 聚味太重会被嫌弃，直吹也会不适 |
| 分散摆放 | 多猫时集中摆放会互相抢占 |
| 靠近饮水与休息区 | 猫倾向在"自己的领地核心区"排泄 |
| **不放在洗衣机、烘干机旁** | 震动与噪音是常见干扰源 |

**最常见的错误位置**：马桶旁边、洗衣机旁边、门口走廊、封闭的卫生间角落。这些位置的问题不是"不能放"，而是**猫的主观感受不好**。

## 四、四类猫砂对比

| 类型 | 优点 | 缺点 | 粉尘 | 结团力 | 误食风险 | 清理 | 适用 |
|---|---|---|---|---|---|---|---|
| 膨润土（颗粒黏土） | 结团快、吸水好、易铲、价格低、猫咪接受度普遍较高 | 粉尘相对较多、部分猫 dislike、**不可冲入马桶** | 中等 | 好 | 相对低（颗粒大不易整粒吞） | 团好铲 | 大多数家庭，尤其有粉尘耐受的猫 |
| 豆腐砂 | 粉尘少、可结团、部分可冲厕（需确认产品说明）、轻 | 价格偏高、部分猫初始不接受、**有误食风险** | 低 | 中等 | **较高（外观像食物、有豆渣气味，猫可能误食）** | 团较软 | 粉尘敏感、铲屎官受不了粉尘的 |
| 木砂（刨花、木屑） | 粉尘少、可冲厕（需确认）、环保感强 | 吸水后易碎、清理略麻烦、部分猫不接受 | 低 | 中等 | 中等 | 需连碎屑一起清 | 粉尘敏感且希望可冲厕的 |
| 水晶砂（硅胶颗粒） | 吸水体积大、粉尘少、清理频率低 | 吸水后不结团、只能整盆换、**多数猫接受度一般**、不可冲厕 | 低 | 不结团 | 相对低（颗粒透明不似食物） | 整盆更换 | 懒得频繁清理且猫能接受的用户 |

**误食风险要说清**：**豆腐砂最容易被猫误食**，因为外观与气味接近食物。幼猫与好奇的猫风险更高。**发现误食后不要催吐，尽快联系兽医**。

**关于冲厕**：**能否冲入马桶取决于产品说明，不是所有"可冲厕"的产品都适合各家管道**。冲厕前先确认产品说明与自家管道状况；**不确定就不要冲**。膨润土砂与水晶砂通常不可冲厕。

**换砂的类型不要一次全换**：**新猫砂与旧猫砂按比例混合过渡**，让猫适应；一次全换容易导致拒绝使用。

## 五、清洁与除味

| 项目 | 口径 |
|---|---|
| 铲屎频率 | **每天至少 1-2 次**；多猫时按猫数增加 |
| 铲的时机 | 猫排便后尽快铲；**猫对正在使用的盆接受度低** |
| 换砂频率 | 按类型：结团砂盆面脏了换底砂；不结团砂按使用状况整盆更换 |
| 洗盆 | 按脏污程度；**洗净后完全晾干再放回** |
| 洗盆用品 | 中性清洁剂即可；**避免强烈香味清洁剂**，猫对气味敏感，强香味会劝退 |
| 盆的位置 | 潮湿与阳光直射处不利，**通风但不穿堂** |
| 除味来源排查 | 尿味多来自**盆本身、地面残留与织物**，不只是猫砂 |
| 织物处理 | 猫砂盆周围的垫子、拖把区域需一并处理 |
| 环境 | 通风；除味产品注意**对猫的呼吸道刺激与舔食风险** |

**除味的关键不是加香味**：**猫砂盆周围的织物、地面缝隙、墙角残留才是味道来源**。用香味产品盖住，猫反而更容易拒绝进盆。

## 六、拒绝使用猫砂盆的十二类原因

**排查必须按顺序，不能跳步。** 多数家庭只做了第一步和第二步就下结论了。

| 顺序 | 原因 | 怎么查 | 处理方向 |
|---|---|---|---|
| 1 | **尿闭等泌尿问题（急症）** | 是否频繁进盆却尿不出、蹲坐久、舔下体频繁 | **先排红线，是急症立即就医** |
| 2 | 盆脏 | 有没有超过 1 天没铲、盆底是否有积尿块 | 增加铲屎频率 |
| 3 | 盆太小 | 猫放进去能否转身、伸展 | 换大一号盆 |
| 4 | 位置不合适 | 是否在噪音源、走动频繁处、门口 | 移位 |
| 5 | 盆型不合适 | 猫是否害怕封闭、是否喜欢隐蔽 | 换盆型或并排放新旧盆 |
| 6 | 猫砂类型不喜欢 | 是否刚换过砂、是否刚倒上新砂 | **新旧砂混合过渡，逐步替换** |
| 7 | 猫砂太厚 | 砂层厚度是否过深 | 减薄到合适的厚度 |
| 8 | 盆太干净或太脏 | 是否刚洗过盆、有没有残留气味 | 恢复正常使用即可 |
| 9 | 多猫互相抢占 | 是否有猫被阻挡、是否都在用同一个盆 | 增加盆数、分散摆放 |
| 10 | 意外（惊吓、噪声） | 近期是否有搬家、装修、新成员 | 恢复安静环境，给适应时间 |
| 11 | 年龄或行动不便 | 幼猫、老年猫、行动不便的猫 | 改低边入口、更大更浅的盆 |
| 12 | 环境变化或压力 | 新成员、访客、作息变化、窗外变化 | 减少压力源，提供退避空间 |

**第 1 条必须先排**：把尿闭当成"行为问题"去调盆换砂，是可能延误的路径。

### 6.1 乱尿的两种情况要分开

| 情况 | 特征 | 处理方向 |
|---|---|---|
| 排尿姿势正常、尿能排出、尿在盆外 | 多为盆型、位置、清洁、或情绪标记 | 按上面十二类顺序排查；也可能是领地标记行为 |
| 排不出尿或排尿疼痛 | **尿闭或尿路问题，急症** | **立即就医，不做行为排查** |

**另一个常被误判的情况**：猫**突然**开始乱尿，尤其是本来一直用盆的猫突然不用——**"一直很乖的猫突然乱尿"更可能是身体或环境出了问题，不是行为变坏**。

## 七、记录要求

| 记录什么 | 怎么记 |
|---|---|
| 排尿次数 | 按天记，异常增多或减少要能看出来 |
| 排尿地点 | 盆内还是盆外，具体位置 |
| 盆使用情况 | 有没有进去、停留多久、是否正常使用姿势 |
| 清洁记录 | 每次铲的时间、每次换砂的时间 |
| 猫砂更换 | 换的时间、类型、过渡方式 |
| 盆的位置调整 | 调整时间与前后对比 |
| 多猫情况 | 每只的排尿情况分别记 |

**为什么要逐项记**：行为问题的排查靠的是**排除法**，只有记录才能排除。凭记忆回想"好像上周开始的"，通常定位不到。

## 八、脚本用法

```
python scripts/litter_setup.py --file cats.json
python scripts/litter_setup.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`cat_count`、`age`（幼猫/成猫/老年）、`has_kitten`、`litter_type`、`location_ok`、`scooped_today`、`boxes`、`refuse_reasons`、`symptoms`、`red_flags` |
| `--json` | 以 JSON 输出 |
| `--out` | 结果写入指定文件，默认 `scripts/_last_result.txt` |

脚本做四件事：**排就医红线并给出急症标识 → 按猫数加一算盆数并检查盆型位置与猫砂类型 → 按十二类原因输出排查顺序 → 给出清洁除味频率口径**。脚本**不推荐品牌、不给药物、不诊断尿路疾病**。

## 九、人工确认清单（这步不能省）

- [ ] **已先排除尿闭等急症**（能排出尿 vs 排不出尿已分清）
- [ ] 盆数按猫数加一配置，多猫时盆已分散摆放
- [ ] 盆尺寸足够猫转身伸展；顶盖式盆开口够猫进出
- [ ] 幼猫与老年猫用低边入口的盆
- [ ] 盆位在安静、不堵、通风但不穿堂、不在机器旁的位置
- [ ] 换盆型时**新旧盆并排放**，让猫自己选
- [ ] 猫砂类型按粉尘敏感、结团力、误食风险、清理需求选择
- [ ] **豆腐砂误食风险已注意**；发现误食未催吐，已联系兽医
- [ ] 冲厕与否**已确认产品说明与自家管道**，不确定就不冲
- [ ] 换猫砂类型时**做了新旧混合过渡**，未一次全换
- [ ] 每天铲屎至少 1-2 次，猫排便后尽快铲
- [ ] 清洁用品用中性，**未用强烈香味清洁剂**
- [ ] 异味来源已排查织物、地面缝隙、墙角，不只是加香味
- [ ] 排查按十二类顺序逐项走，**未跳步**，未直接归为行为问题
- [ ] 记录了排尿次数、地点、盆使用与清洁情况

## 十、最常见的坑

**坑一：公猫尿不出来，当成"不爱干净"去换砂盆。**
错误做法：猫不进盆、盆外有尿痕，以为是盆不好，换盆换砂。正确做法：**先分清是"尿在盆外但能排出来"还是"根本排不出来"**。公猫频繁进盆却尿不出、蹲很久、频繁舔下体——**尿闭是急症，立即就医**。把急症当行为问题调环境，可能延误救命。

**坑二：盆太小。**
错误做法：买了个漂亮的顶盖小盆，认为猫将就一下就行。正确做法：**把猫放进去后，它能自然伸展身体、有多余空间**。挤在盆里会直接关联到拒绝使用。**盆太小是最常见的配置问题之一。**

**坑三：盆放在洗衣机旁边或门口。**
错误做法：为了省地方放在洗衣机旁、走廊尽头。正确做法：**安静、不堵、有遮挡但不压抑、通风但不穿堂**。噪音、震动、走动频繁是常见干扰源——**猫不是嫌脏，是嫌不安全**。

**坑四：换盆型直接撤掉旧的。**
错误做法：换成新盆型后把旧盆扔了。正确做法：**新旧盆并排放，让猫自己选择**。猫对新物件需要适应期，直接撤旧换新很可能导致拒绝使用。

**坑五：换猫砂类型一次全换。**
错误做法：把旧砂清空，全换成新砂。正确做法：**新旧砂按比例混合过渡**，让猫适应。猫对气味的接受需要过程，一次全换容易导致拒绝。

**坑六：豆腐砂当猫粮被误食，还想着催吐。**
错误做法：发现猫吃了豆腐砂，给它催吐。正确做法：**豆腐砂外观与气味接近食物，误食风险相对较高**；**发现误食后不要催吐，尽快联系兽医**。喷洒催吐剂等产品对猫有风险，自行处理不合适。

**坑七：除味靠香味产品。**
错误做法：味道大就买香味猫砂、加香味除臭剂。正确做法：**猫砂盆周围的织物、地面缝隙、墙角残留才是味道来源**。用香味盖住，猫反而更容易拒绝进盆——**猫是靠嗅觉判断环境的**。

**坑八：一乱尿就断定是行为问题。**
错误做法：猫突然乱尿，认为是"发情标记"、"性格变坏"，开始训。正确做法：**"一直很乖的猫突然乱尿"更可能是身体或环境出了问题，不是行为变坏**。先排红线，再按十二类顺序排查，**不要跳步，更不要靠训斥解决问题**。
