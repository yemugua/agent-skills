# 不合格项 A/B/C 分级规则

## 一、分级口径

| 等级 | 判定口径 | 整改期限 | 说明 |
|---|---|---|---|
| **A 类** | 系统整体失效、关键功能丧失、直接影响人员疏散或灭火 | 立即 | 整改前该场所不具备消防安全条件 |
| **B 类** | 局部功能缺陷，系统仍可动作但可靠性下降 | 30 日内 | 需在期限内完成并复检 |
| **C 类** | 一般性缺陷，不影响主要功能 | 90 日内 | 可结合维保计划一并处理 |

## 二、典型 A 类项（见到即最高优先级）

| 缺陷 | 判定理由 |
|---|---|
| 火灾自动报警控制器故障、主备电无法切换 | 报警系统整体失效 |
| 喷淋泵/消火栓泵无法启动 | 灭火系统失去水源保障 |
| 消防水池无水或水位不足 | 系统无水源 |
| 防排烟风机无法启动 | 疏散与防烟失效 |
| 疏散通道、安全出口被封堵 | 直接影响人员疏散 |
| 防火卷帘无法下降或下降不到位 | 防火分隔失效 |
| 应急照明全部不亮 | 断电后无疏散照明 |
| 自动消防设施处于手动/停用状态 | 系统不能自动动作 |

## 三、典型 B 类项

| 缺陷 | 判定理由 |
|---|---|
| 个别探测器故障、误报 | 局部失效，系统仍可运行 |
| 个别喷头被遮挡、腐蚀 | 局部覆盖受影响 |
| 末端试水压力不足 | 局部可靠性下降 |
| 个别防火门闭门器失效 | 分隔局部失效 |
| 灭火器压力不足、超期 | 局部配置失效 |
| 应急照明个别灯不亮 | 局部缺陷 |
| 消防电话、插孔个别不通 | 局部通信失效 |
| 阀门被误关、无标识 | 存在误操作风险 |

## 四、典型 C 类项

| 缺陷 | 判定理由 |
|---|---|
| 标识缺失、模糊 | 不影响功能 |
| 设备表面积尘、锈蚀轻微 | 外观性缺陷 |
| 记录台账填写不规范 | 管理性缺陷 |
| 灭火器放置点不便取用 | 可用性轻微下降 |
| 线路敷设不整齐 | 不影响功能 |
| 资料档案不完整 | 管理性缺陷 |

## 五、分级判定三条原则

1. **就高不就低**：一句话里同时出现多个缺陷，按最高等级记一条，不要拆成多条低等级
2. **看系统不看单点**：单台设备故障通常 B 类；但该设备是整个系统的唯一保障（如唯一一台消防泵）时升为 A 类
3. **看场景**：人员密集场所、易燃易爆场所的同类缺陷，等级上调一级

## 六、否定词守卫（脚本与人工都要防）

「已整改」「已修复」不等于「无缺陷」——整改完成的项仍要列出，状态标「已闭环」，不能从报告里删掉。

| 表述 | 正确处理 |
|---|---|
| 「消音后未复位」 | 计为未处置，不是已处置 |
| 「已报维保，待更换」 | 计为整改中，不是已闭环 |
| 「已整改（无复检记录）」 | 计为闭环存疑 |
| 「已整改（复检日期 + 复检人）」 | 计为已闭环 |
