# 理赔流程与举证要件

> 申请前必读。**时限、限额、费用与条款内容一律以现行规定、承运合同约定与承运方口径为准。**

## 一、先分清丢件还是破损

| 对比项 | 丢件（未收到） | 破损（收到但损坏） |
|---|---|---|
| 事实形态 | 包裹未送达 | 已送达但内容物损坏 |
| 关键环节 | 轨迹中断、长时间无更新 | 签收时或签收后发现损坏 |
| 举证难点 | 需证明**寄出且应到达** | 需证明**送达时即为损坏** |
| 证据重点 | 面单、轨迹记录、寄件凭证 | **开箱视频、外包装状态、签收记录** |

**破损的举证核心：证明「送达时即已损坏」。** 签收后才发现且无开箱留证的，举证难度很大。

## 二、举证责任清单

| 证据 | 证明什么 | 重要性 |
|---|---|---|
| **快递面单** | 寄件人、收件人、物品、重量 | **最高**，无面单几乎无法主张 |
| **订单记录** | 交易关系与物品价值线索 | 高 |
| **物流轨迹** | 运输路径与当前状态 | **最高**，中断是关键证据 |
| **签收记录** | 是否送达、何时、谁签收 | 高 |
| **开箱视频** | 内容物与外包装状态 | **破损类最高** |
| **寄件时物品清单** | 内件明细 | 高 |
| **付款凭证** | 已付运费或保价费 | 中 |

**最容易缺的就是面单**——随手扔了，后续几乎无法主张。

## 三、先验后签（最重要的习惯）

**签收前开箱验货并留证**，能一次解决丢件与破损两类争议。

| 顺序 | 动作 | 留证要点 |
|---|---|---|
| 1 | 拍外包装 | **先拍面单**，再拍包装四个面 |
| 2 | 连续视频开箱 | **不中断**，从包装外拍到内件全部取出 |
| 3 | 核对内件 | 对照寄件清单逐项核对 |
| 4 | 有问题当场处理 | 拒收或先联系，保留通话与沟通记录 |

**注意点**：先验后签可能延长派送时间，但与事后无证可查相比，举证价值差距远大于时间成本。

**不要中断视频**：中断后无法证明内件与外包装的连续状态。

## 四、保价与未保价的规则差异

**本节只说明定性差异，不含任何金额与限额数字。**

| 对比项 | 已保价 | 未保价 |
|---|---|---|
| 赔付依据 | 按保价约定与实际损失 | 按承运方赔付规则与实际损失 |
| 限额 | 约定上限以内 | 依快递企业赔付标准，**通常有较高限额** |
| 举证重点 | 物品实际价值 | 物品实际价值 + 证明已交付承运方 |
| 价值证明 | 发票、订单、贵重凭证 | 同左 |

**两条通用提示**：

1. **未保价的赔付通常明显低于物品实际价值**，高价值物品务必考虑保价。
2. **保价条款的约定内容与效力可能存在争议**，应按承运合同与现行规定核对。

**赔付金额的具体测算不属于本技能范围**，请转向测算类技能或直接咨询承运方。

## 五、理赔时限口径

**理赔申请时限、承运方处理时限与赔付标准以现行规定与承运方口径为准**，本技能不写死具体天数。

两条必须提示的：

1. **不要因为「等调查结果」而拖延正式提交理赔申请**——拖延本身可能带来不利后果。
2. **系统轨迹与状态会变化**，越早固定证据越好。

## 六、拒赔理由与应对

| 拒赔理由 | 应对方向 |
|---|---|
| 无法证明内件价值 | 补订单、发票、付款凭证、寄件清单 |
| 无法证明已交付承运方 | 补面单与寄件凭证 |
| 已签收无破损记录 | **签收不等于完好，举证责任在承运方** |
| 超过时限 | 核对约定时限并说明已及时提交 |
| 未保价赔付有限 | 核对规则；需测算请转测算类技能 |

## 七、升级路径

| 顺序 | 渠道 | 说明 |
|---|---|---|
| 1 | 承运方官方客服与投诉 | 基础环节 |
| 2 | 承运方申诉与复核 | 企业内部层级 |
| 3 | **邮政业申诉渠道** | 快递服务投诉的专用申诉渠道 |
| 4 | 12345 政务便民热线 | 转办性质 |
| 5 | 市场监管 / 消协调解 | 第三方居中 |
| 6 | 司法途径 | 末端 |

**每一步留痕**：工单号、受理编号、书面答复。

## 八、常见错误对照

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 面单随手扔 | 后续几乎无法主张 | 保留或拍照存证 |
| 破损未先验后签 | 无送达时状态证据 | 连续视频开箱 |
| 视频不连续 | 无法证明状态连续 | 从外包装拍到内件全出 |
| 认为签收即完好 | 举证责任在承运方 | 要求承运方举证完好 |
| 拖延等调查结果 | 可能带来不利后果 | 及时正式提交 |
| 高价值物品未保价 | 赔付远低于价值 | 考虑保价 |
| 只在一处渠道交涉 | 层级不同 | 逐级申诉 |
| 口头交涉不留痕 | 无证明 | 留工单号与受理编号 |
