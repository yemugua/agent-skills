# 快递丢件理赔流程核查

理赔失败，**多数不是因为公司赖账，而是因为举证链断了**——没有面单、没有轨迹记录、没有开箱留证，事后无法证明包裹里是什么、到哪一步了。

## 一、硬边界（能做 / 不能做）

| 能做 | 不能做 |
|---|---|
| 给出理赔流程与材料准备清单 | 给出具体赔付金额或计算结果 |
| 说明保价与未保价的赔付规则差异 | 替代理赔测算类技能做金额核算 |
| 区分丢件与破损的处理路径 | 认定承运方「故意」丢失或认定法律责任 |
| 说明理赔时限口径与升级路径 | 写死具体天数、金额上限或保价条款编号 |
| 给出先验后签的留证操作建议 | 承诺一定赔付或承诺赔付比例 |

**与理赔测算的分工**：具体赔付金额的计算（如未保价时按什么标准、限额如何确定、保价约定被认定无效时如何处理）属于**测算类**范畴，本技能只写**流程与材料准备**，并指向测算类技能，不重复其内容。

**必须转交专业人士或走争议解决的：** 保价条款效力有争议、理赔金额争议较大、承运方已失联或拒不接受任何调查的。

## 二、什么时候用

| 用户说法 | 用不用 | 说明 |
|---|---|---|
| 快递丢了怎么赔 | 部分用 | 本包给流程与材料，金额指向测算类技能 |
| 理赔要什么材料 | 用 | 走举证责任清单 |
| 没保价和保价区别 | 用 | 走赔付规则差异（不给数字） |
| 快递公司不赔怎么办 | 用 | 走拒赔升级路径 |
| 包裹破损谁负责 | 用 | 走丢件与破损区分 |
| 签收后发现少东西 | 用 | 走先验后签与举证难点 |
| 快递12305怎么投诉 | 用 | 走升级路径 |

## 三、完整工作流

### 步骤 1：先分清丢件还是破损

两者的责任环节与举证难度不同，见第四节。

### 步骤 2：立即固定证据（越早越好）

**这是最关键的一步，且有时效性**——物流轨迹会更新、系统状态会改变。

### 步骤 3：按流程提出理赔

用 `scripts/express_claim_check.py` 核查材料完整性与时限口径。

### 步骤 4：核对赔付规则口径

保价与未保价走不同规则，见第五节。

### 步骤 5：拒赔时走升级路径

见第七节。

## 四、核心规则（申请前必读）

**先读 `rules/理赔流程与举证要件.md`，不要凭印象交材料。**

**所有时限、限额、费用标准与条款内容，一律以现行规定、承运合同的约定与承运方口径为准**，本技能不写死具体天数与金额。

### 丢件与破损的区分

| 对比项 | 丢件（未收到） | 破损（收到但损坏） |
|---|---|---|
| 事实形态 | 包裹未送达 | 已送达但内容物损坏 |
| 关键环节 | 物流轨迹中断、长时间无更新 | 签收时或签收后发现损坏 |
| 举证难度 | 需证明**寄出且应到达** | 需证明**送达时即为损坏** |
| 责任环节 | 运输与分拣环节 | 运输、分拣或末端派送环节 |
| 证据重点 | 面单、轨迹记录、寄件凭证 | **开箱视频、外包装状态、签收记录** |

**破损的举证关键在于证明「送达时即已损坏」**——签收后才发现且无开箱留证的，举证难度很大。

### 举证责任清单

| 证据 | 证明什么 | 重要性 |
|---|---|---|
| **快递面单** | 寄件人、收件人、物品、重量 | **最高**，无面单几乎无法主张 |
| **订单记录** | 交易关系与物品价值线索 | 高 |
| **物流轨迹** | 运输路径与当前状态 | **最高**，中断是关键证据 |
| **签收记录** | 是否送达、何时送达、谁签收 | 高 |
| **开箱视频** | 包裹内容物与外包装状态 | **破损类最高** |
| **寄件时的物品清单** | 内件明细 | 高，可辅以寄件时的照片或清单 |
| **付款凭证** | 已支付运费或保价费 | 中 |

### 先验后签（最重要的习惯）

**在签收前开箱验货并留证**，能一次性解决两类争议。

| 动作 | 留证方式 |
|---|---|
| 拍外包装（含面单） | 先拍面单，再拍包装四个面 |
| 连续视频开箱 | **不中断**，从包装外拍到内件全部取出 |
| 核对内件 | 对照寄件清单逐项核对 |
| 有问题当场拒收或先联系 | 保留通话与沟通记录 |

**注意**：先验后签可能延长派送时间，但相比事后无证可查，举证价值的差距远大于时间成本。

### 保价与未保价的赔付规则差异

**以下是规则差异的定性说明，不含具体金额与限额数字。**

| 对比项 | 已保价 | 未保价 |
|---|---|---|
| 赔付依据 | 按保价约定与实际损失 | 按承运方赔付规则与实际损失 |
| 限额 | 约定上限以内 | 依快递企业赔付标准，**通常有较高限额** |
| 举证重点 | 物品实际价值 | 物品实际价值 + 证明已交付承运方 |
| 价值证明 | 发票、订单、贵重凭证 | 同左 |

**两条通用提示**：

1. **未保价的赔付通常明显低于物品实际价值**，高价值物品务必考虑保价。
2. **保价条款的约定内容与效力可能存在争议**，应按承运合同与现行规定核对，具体以承运方口径与争议解决结果为准。

**赔付金额的具体测算不属于本技能范围**，请转向测算类技能或咨询承运方。

## 五、理赔时限口径

**理赔申请时限、承运方的处理时限与赔付标准，以现行规定与承运方口径为准**，本技能不写死具体天数。

**必须提示的两点**：

1. **不要因为「等调查结果」而拖延提交正式理赔申请**——拖延本身可能带来不利后果。
2. **系统轨迹与实际状态会变化**，越早固定证据越好。

## 六、拒赔的常见理由与应对

| 拒赔理由 | 应对方向 |
|---|---|
| 无法证明内件价值 | 补订单、发票、付款凭证、寄件清单 |
| 无法证明已交付承运方 | 补面单与寄件凭证 |
| 已签收无破损记录 | 指出签收不等于完好，**举证责任在承运方** |
| 超过时限 | 核对约定时限并说明已及时提交 |
| 未保价赔付有限 | 核对规则，必要时转向测算类技能 |

**关键认知**：签收仅证明「收到了」，**不证明「完好」**；承运方主张完好时，**相应举证责任在承运方**。

## 七、拒赔升级路径

| 顺序 | 渠道 |
|---|---|
| 1 | 承运方官方客服与投诉渠道 |
| 2 | 承运方的申诉与复核渠道 |
| 3 | **邮政业申诉渠道**（快递服务投诉的专用申诉渠道） |
| 4 | 12345 政务便民热线（转办性质） |
| 5 | 市场监管部门 / 消费者协会调解 |
| 6 | 司法途径 |

**每一步都要留痕**：工单号、受理编号、书面答复。

## 八、脚本用法

脚本：`scripts/express_claim_check.py`

```bash
python scripts/express_claim_check.py --file 理赔.json
python scripts/express_claim_check.py --selftest
```

| 字段 | 说明 |
|---|---|
| `case_type` | lost / damaged |
| `insured` | 是否已保价 |
| `evidence` | 已持有证据类型列表 |
| `signed` | 是否已签收 |
| `opened_before_sign` | 是否先验后签 |
| `days_since` | 距事发天数（仅用于相对提醒，不写死阈值） |

输出：材料完整性、举证难点提示、丢件/破损路径差异、先验后签建议、升级路径建议。

## 九、人工确认清单（不能省）

- [ ] 是否已分清是**丢件**还是**破损**（两者路径不同）？
- [ ] 面单是否保存？（**没有面单几乎无法主张**）
- [ ] 物流轨迹是否已截图留存？
- [ ] 破损情形是否有**连续开箱视频**？
- [ ] 是否有订单、发票等**价值证明**？
- [ ] 是否在签收前验货并留证？
- [ ] 是否已按承运方要求**书面提交**理赔申请？
- [ ] 每次主张是否都留了工单号或受理编号？
- [ ] 是否核对了理赔时限口径（以承运方与现行规定为准）？

## 十、最常见的坑

1. **没留面单**。面单是最基础也最常被忽略的证据，丢了几乎无法主张。
2. **破损没先验后签**。签收后才发现且无视频，举证难度极大。
3. **开箱视频不连续**。只拍内件不拍外包装，无法证明送达时状态。
4. **以为签收就等于完好**。签收仅证明收到了，完好与否的举证责任在承运方。
5. **拖延等调查结果而不正式申请**。拖延可能带来不利后果。
6. **高价值物品未保价**。未保价赔付通常明显低于实际价值。
7. **把「赔付金额」当成本技能能解决的问题**。金额测算属于测算类范畴。
8. **口头交涉不留痕**。每次都要工单号或受理编号。
9. **只在一处渠道交涉**。承运方内部复核与邮政业申诉是不同层级。
10. **没核对保价条款内容**。保价的约定与效力应以承运合同与现行规定为准。

## 十一、边界与免责

本技能提供理赔流程、材料准备与升级路径，**不给出赔付金额、不承诺赔付结果、不替代承运方处理与争议解决**。理赔时限、赔付标准、限额与保价条款内容，**以现行规定、承运合同的约定与承运方口径为准**，各地与各家执行口径存在差异。赔付金额的具体测算请转向测算类技能；涉及条款效力争议或金额争议较大的，建议咨询执业律师。
