# 定期寿险保额测算规则库

> **生成测算材料前先读本文件，不要凭印象写口径。**
> 保额算错是双向错误：算低了缺口自己扛，算高了保费确定支出而保障用不上。

---

## 一、公式与变量定义

```
保额缺口 = 负债余额 + 家庭年支出 × 剩余抚养年限 − 已有寿险保额 − 可变现资产
```

| 变量 | 单位 | 口径要点 |
|---|---|---|
| 负债余额 | 万元 | 各项**剩余本金**之和，非原始额度 |
| 家庭年支出 | 万元/年 | 近 12 个月**平均值**，含教育与赡养 |
| 剩余抚养年限 | 年 | 算到孩子经济独立（22–25 岁）或赡养责任终止 |
| 已有寿险保额 | 万元 | **仅含身故责任**的保额 |
| 可变现资产 | 万元 | **不含自住房与私家车** |

**结果含义：**

| 结果 | 含义 | 下一步 |
|---|---|---|
| > 0 | 存在风险缺口 | 结合长期缴付能力判断，不等于应买此数量 |
| = 0 | 理论刚好覆盖 | 建议留余量 |
| < 0 | 现有资源理论已覆盖 | **必须复核口径后再下结论** |

---

## 二、负债余额明细口径

| 项目 | 计入 | 说明 |
|---|---|---|
| 房贷剩余本金 | ✅ 必计 | 最大单项，通常占缺口 25%–40% |
| 车贷剩余本金 | ✅ 计入 | |
| 消费贷剩余本金 | ✅ 计入 | 含信用卡分期 |
| 经营贷剩余本金 | ✅ 计入 | 个体户家庭常见 |
| 助学贷款 | ⚠️ 视情况 | 多数家庭不构成抚养压力 |
| 已结清贷款 | ❌ | 不计 |
| 未签署的购房计划 | ❌ | 尚未形成负债 |

**核对动作**：逐项列出负债名称、原始额度、已还金额，用 `原始额度 − 已还 = 剩余本金` 验算。

---

## 三、家庭年支出明细口径

**取数规则**：最近 12 个月的**算术平均**。不足 12 个月取已有月份，并注明月数。

| 类别 | 计入 | 说明 |
|---|---|---|
| 房租房贷还款 | ✅ | 刚性 |
| 日常生活 | ✅ | |
| 育儿教育 | ✅ | 刚性且随年龄上升 |
| 赡养双方父母 | ✅ | 刚性，随年龄快速上升 |
| 商业保险保费 | ✅ | 家庭刚性支出 |
| 商业房贷（等额本息本金部分） | ✅ | 与房贷余额口径区分，不重复计 |
| 装修、买车、旅游 | ❌ | 可选项，非刚性 |
| 子女教育金专项储蓄 | ❌ | 是资产不是支出，避免与年金重复 |

> **低估最常见的方式**：只算吃饭穿衣。真实刚性支出里教育、赡养、商业保费常占三成以上。

---

## 四、剩余抚养年限口径

| 家庭结构 | 年限算法 | 常见区间 |
|---|---|---|
| 有孩子 | `经济独立年龄 − 当前年龄` | 15–22 年 |
| 需赡养父母（无收入来源） | 算到父母生活自理困难 | 15–25 年 |
| 单身无抚养责任 | 基本生活储备期 | 5–10 年 |
| 双职工有孩子 | 算到孩子经济独立 | 15–20 年 |
| **单收入家庭** | **算到孩子经济独立，且含配偶再就业过渡期** | 20–25 年 |
| 双职工、无抚养责任 | 父母赡养 + 基础储备 | 8–15 年 |

**经济独立年龄口径**：常见取 22–25 岁。已上大学的孩子可适当延长（学费与生活费延续）。

> **算低的最大单一来源**是把抚养年限算到孩子上幼儿园或上小学。

## 五、已有寿险保额合并口径

### 5.1 计入规则

| 保单类型 | 计入 | 说明 |
|---|---|---|
| 定期寿险 | ✅ 全额 | |
| 终身寿险 | ✅ 全额 | 含身故责任部分 |
| 团险含身故责任 | ⚠️ 条件计入 | **确认离职后是否失效** |
| 年金险有身故责任 | ⚠️ 按身故保额计入 | 纯生存领取型**不计** |
| 增额终身寿 | ❌ | 现金价值≠身故保障额度 |
| 重疾险 | ❌ | 消费型无身故赔付责任 |
| 医疗险 | ❌ | |
| 意外险 | ❌ | 身故责任已含在意外险中，但属另一险种维度，不抵扣寿险缺口 |
| 教育金、年金领取型 | ❌ | |

### 5.2 误判防护（防误伤）

| 说法 | 判定 |
|---|---|
| 「我买了 50 万重疾险就够了」 | **错**，重疾险无身故责任，不能抵扣 |
| 「年金险算有保额」 | **部分对**，仅身故责任部分可计 |
| 「增额终身寿有现金价值」 | **错**，现金价值是储蓄账户 |
| 「团险有 100 万身故」 | **条件对**，离职后可能失效 |
| 「车房很值钱能抵扣」 | **错**，默认不计入 |

### 5.3 去重规则

- 同一份保额**不得在夫妻双方重复计入**
- 「已有保额」是**家庭合计口径**，不是单个人口径
- 增额后保额上升的部分才计入变化量

## 六、可变现资产口径

| 资产 | 计入 | 说明 |
|---|---|---|
| 存款、活期理财、货币基金 | ✅ | |
| 股票、基金账户 | ✅ 折价后 | 考虑波动与变现时点 |
| 已到期定期存款 | ✅ | |
| 自住房 | ❌ 默认不计 | 居住刚需、变现周期长、有税费交易成本 |
| 私家车 | ❌ 默认不计 | 折价快、属消费资产 |
| 未上市股权、未变现厂房 | ⚠️ 折价 | 变现不确定 |
| 未来收入预期 | ❌ | |
| 自住房如计入 | ⚠️ 须同时计入**搬家成本与过渡租房成本** | 否则仍不可比 |

## 七、保额偏低判断线

| 判断线 | 阈值 | 等级 |
|---|---|---|
| 保额 < 负债余额 | 连债务都覆盖不了 | **严重不足** |
| 保额 < 家庭年支出 | 连一年开销都覆盖不了 | **明显不足** |
| 保额 < 家庭年支出 × 剩余年限 × 50% | 只能覆盖一半抚养期 | **不足** |
| 保额 < 家庭年支出 × 剩余年限 | 未覆盖全期 | **临界** |
| 保额 = 0 | 无任何身故保障 | **完全缺失** |

### 7.1 缺口规模经验参照

| 缺口占家庭年收入倍数 | 参照 |
|---|---|
| < 1 倍 | 小额缺口，需判断是否值得专门配置 |
| 1–3 倍 | 中等缺口 |
| 3–5 倍 | 较大缺口 |
| > 5 倍 | 很大缺口，须重点评估保障方案与缴费能力 |

> 该倍数仅用于**快速感知缺口量级**，不构成投保建议。

## 八、保额过高的识别与浪费点

| 浪费点 | 表现 | 识别方法 |
|---|---|---|
| 保费挤占现金流 | 加保费后家庭结余转负 | 算家庭年结余 = 年收入 − 年支出 − 保费 |
| 缴费能力不足 | 长期缴付影响教育金/养老金储备 | 检查缴费期内各年收入是否稳定 |
| 形态不匹配 | 用超长期限换短期需求 | 需求期与产品期限是否对齐 |
| 核保可行性 | 超额投保触发体检、加保、财务核保 | 既往病史、体检异常记录 |
| 资金机会成本 | 长期确定支出占用其他储备资金 | 不做收益预测，只提示此消彼长 |

### 8.1 缴费承受力检查（第二道闸）

```
加保费后家庭年结余 = 家庭年收入 − 家庭年支出 − 家庭年保费

结余 > 0              → 现金流可承受
结余 ≈ 0              → 临界，无缓冲
结余 < 0              → 不可承受，中途断缴风险高
```

**额外检查**：应急储备能否覆盖 **6–12 个月**家庭支出。覆盖不到时优先补应急金。

### 8.2 续期风险

- 定期寿险需长期缴费，**缴费期内恰是收入最不稳定的时期**
- 只看「现在能缴」而忽略「20 年都能缴」是典型低估
- 断缴后保障终止，已交保费不退（消费型）

## 九、三种形态对比（不推荐产品）

| 维度 | 定期寿险 | 终身寿险 | 年金险 |
|---|---|---|---|
| 保障期限 | 固定 | 终身 | 按合同约定 |
| 到期返还 | 无（消费型） | 现金价值累积 | 账户累积 |
| 主要解决 | 责任期收入中断 | 传承与资产安排 | 退休现金流 |
| 主要局限 | 续期风险、责任期外不覆盖 | 保费高、回本慢、长期占用 | 流动性弱、退保损失 |

### 9.1 判断顺序

```
1. 保障责任期在哪里？
2. 预算允许吗？
   ├─ 允许 → 按责任期配足
   └─ 不允许 → 先保「经济支柱 + 主要责任期」，不追求形态齐全
```

### 9.2 常见倒置

预算不足时优先购买形态复杂的产品，导致**基础保额严重不足**。保障不足时先解决「有没有」，再考虑「是哪一种」。

## 十、负数结果的复核清单

结果 < 0 时，**必须逐项复核**：

- [ ] 已有保额是否**逐张核对**，仅含身故责任
- [ ] 团险保额**离职后是否失效**
- [ ] 年金险是否为纯生存领取型
- [ ] 可变现资产**是否真能变现**（未上市股权、高比例单一持仓应折价）
- [ ] 是否**漏算房贷余额**
- [ ] 是否**漏算教育与赡养支出**
- [ ] 自住房与车**未被计入抵扣**

任一项复核后结果可能由负转正。**负数不是结论，是复核信号。**

## 十一、健康告知与核保（不属于测算范畴）

| 情形 | 处理 |
|---|---|
| 既往病史、住院记录 | 转保险公司核保，测算不等于可投保 |
| 近两年体检异常 | 同上 |
| 超额投保 | 可能触发体检、加保、财务核保 |
| 职业类别限制 | 转对应险种评估 |

**测算结果不构成承保承诺。** 实际投保以保险公司核保结论与合同约定为准。
