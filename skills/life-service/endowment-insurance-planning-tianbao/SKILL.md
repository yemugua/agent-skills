# 定期寿险保额计算核查（endowment-insurance-planning）

保额算错，代价是双向的：**算低了，真出事时赔付不够，缺口全靠家庭自己扛；算高了，多交的保费是确定支出，而保障用不上。**

这个技能做一件事：**把保额公式的每一项口径钉死，输出一个可复核的风险缺口数字**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 给出保额公式与逐项口径定义 | ❌ 推荐或比较具体保险产品 |
| 按录入数据算出风险缺口金额 | ❌ 预测收益、分红、现金价值 |
| 判断保额偏低还是偏高 | ❌ 劝诱投保或暗示「应该买」 |
| 给出已有保额的合并口径 | ❌ 代替保险公司给出承保承诺 |
| 输出需要人工确认的清单 | ❌ 代替核保判断能否买、买多少 |
| 说明定期/终身/年金的形态差异 | ❌ 给出投保建议或配置方案 |

**出现以下情况，先停下来人工处理，不要自行下结论：**

- 家庭有**既往病史、住院记录、近两年体检异常** → 健康告知与核保结论**只能由保险公司给出**，测算结果不等于可投保
- 测算缺口为**负数或接近零** → 可能是口径录入有误（尤其是漏算房贷余额、漏计年金/教育金已有保额），**先复核口径再下结论**
- 涉及**高保额投保（累计寿险保额较高）** → 可能触发体检、加保、财务核保等流程，须经保险公司核保
- 需要判断**具体产品是否值得买** → 不在本技能范围，属于产品与需求匹配的咨询
- 用户表达**明显的经济压力或投保焦虑** → 不劝诱投保，把缺口讲清楚后让用户自己决定
- 涉及**工伤、雇主责任、职业类别限制**的保障 → 属另一类险种，口径不同

> **最重要的前置声明**：保额测算仅供家庭风险缺口自查，**实际投保以保险公司核保结论与合同约定为准**。任何测算结果都不构成承保承诺，也不构成投保建议。

## 二、保额公式（核心，先记住这一行）

```
保额 = 负债余额 + 家庭年支出 × 剩余抚养年限 − 已有寿险保额 − 可变现资产
```

**这个数字是「缺口」，不是「建议购买量」。**

- 结果 **> 0**：存在风险缺口，具体买多少还要看家庭现金流承受能力、健康状况与产品形态
- 结果 **= 0**：理论上刚好覆盖，但**建议留出余量**（见 §7 保额偏低判断线）
- 结果 **< 0**：现有资源理论上已覆盖，但**必须先复核口径**，确认不是漏算了什么

**公式之外的两个必答问题（比公式本身更重要）：**

1. **给谁买？** 保额必须绑定**家庭经济支柱**（收入中断会直接影响家庭现金流的人），不是给孩子买、也不是谁危险给谁买。
2. **保额算出来后，家庭能长期缴多少年？** 算得出的缺口不等于缴得起。**长期缴付能力**是第二道闸。

## 三、五项口径定义（算错几乎都错在这里）

### 3.1 负债余额

| 是否计入 | 口径说明 |
|---|---|
| ✅ 房贷余额 | **必计**，且要用**当前剩余本金**，不是原贷款总额 |
| ✅ 车贷余额 | 计剩余本金 |
| ✅ 消费贷、经营贷 | 计剩余本金 |
| ✅ 信用卡分期、消费贷未结清 | 有还款义务即计 |
| ⚠️ 助学贷款 | 视家庭实际情况，多数家庭不构成抚养压力 |
| ❌ 已结清的贷款 | 不计 |
| ❌ 尚未签署的购房计划 | 不计（尚未形成负债） |

> **房贷是保额缺口的最大单项。** 房贷余额 200 万，等于家庭凭空多出 200 万的刚性支出——这是「收入中断」时最先崩的地方。

### 3.2 家庭年支出

| 口径要点 | 具体做法 |
|---|---|
| 取哪几个月 | **取最近 12 个月**，不足 12 个月取已有月份 |
| 是否平均 | **要平均**，避免用单月或旺季月份 |
| 含哪些 | 房租房贷还款、food、日常、育儿教育、交通、**赡养双方父母**、商业保险保费 |
| 是否含一次性支出 | 大额装修、买车等**不计入**（属可选项，不是刚性） |

> **只算「吃饭穿衣」的支出是严重低估。** 真实家庭刚性支出里，教育、赡养、商业保费往往占三成以上，而这些恰恰是收入中断后**不会自动消失**的支出。

### 3.3 剩余抚养年限

| 情形 | 算法 | 说明 |
|---|---|---|
| 有孩子 | 算到**孩子经济独立**（常见口径 22–25 岁），即 `目标年龄 − 当前年龄` | 高中、大学阶段仍需抚养 |
| 有需赡养老人 | 算到**父母生活自理困难或去世**，一般到 65–75 岁 | 无收入来源的赡养责任更重 |
| 单身无抚养责任 | 按 **5–10 年**的基本生活储备期 | 不要归零 |
| 双职工家庭 | 通常算到**孩子经济独立** | 双收入家庭抗风险能力更强，可略降 |
| 单收入家庭 | **必须算满**到孩子经济独立，且要算到配偶可重新就业的过渡期 | 单收入是保额缺口的典型来源 |

> **最常见的算低方式是把抚养年限算到孩子上幼儿园。** 教育阶段支出是持续且刚性的，用「孩子上小学前」做年限会显著低估缺口。

### 3.4 已有寿险保额

**合并口径（务必逐张核对）：**

| 计入类型 | 说明 |
|---|---|
| ✅ 定期寿险、终身寿险 | 全额计入 |
| ✅ 已有保额含豁免、附加重疾的身故责任 | 视其身故保额是否独立计入 |
| ✅ 单位团险中含身故责任的部分 | 计入（但要确认**离职后是否失效**） |
| ⚠️ 年金险 | **有身故责任的按保额计入；纯生存领取的不计入** |
| ⚠️ 增额终身寿 | **不等于身故保障**，不能按现金价值当保额抵扣 |
| ❌ 医疗险、意外险、重疾险 | **不计入**（无身故赔付责任，是不同保障维度） |

> **「我买了很多保险」不等于有相应保额。** 重疾险、医疗险解决的是费用补偿，**不能替代身故责任**。把「已买重疾险 50 万」当作已有寿险保额抵扣，会直接导致缺口算低 50 万。

### 3.5 可变现资产

| 是否计入 | 口径说明 |
|---|---|
| ✅ 存款、货币基金、活期理财 | 计入 |
| ✅ 股票、基金账户 | 计入，但要考虑**波动与变现时点** |
| ✅ 已到期的定期存款 | 计入 |
| ⚠️ 自住房 | **默认不计入**。变现周期长、有税费与交易成本、有居住刚需 |
| ⚠️ 私家车 | **默认不计入**。属于消费资产，且折价快 |
| ❌ 未上市股权、未变现厂房 | 变现不确定，谨慎计入 |
| ❌ 未来收入预期 | 不计入 |

> **自住房和车是「必需品」不是「可变现资产」。** 把自住房市值计入抵扣，等于假设家庭在悲剧发生时能卖掉房子住出去——这个假设通常不成立。**两者默认不计入，这是本技能的口径。**

## 四、四层核算顺序

```
第 1 层  确定投保对象：谁是家庭经济支柱？（不是孩子，不是老人）
第 2 层  录入五项参数：负债余额 / 家庭年支出 / 剩余抚养年限 / 已有寿险保额 / 可变现资产
第 3 层  代入公式，算出缺口
第 4 层  判断：缺口是多是少？是真缺口还是口径录错？
```

**铁律：先定人，再算钱。** 保额是「某个人挂了之后家庭损失多少钱」，主体不定，公式算出多少都没意义。

## 五、四个完整算例

### 算例一：标准双职工家庭（有房贷，有孩子）

**输入**

| 项 | 数值 | 口径 |
|---|---|---|
| 房贷余额 | 180 万 | 剩余本金 |
| 车贷余额 | 8 万 | 剩余本金 |
| 家庭年支出 | 30 万 | 近 12 个月平均，含教育与赡养 |
| 剩余抚养年限 | 18 年 | 孩子 6 岁 → 算到 24 岁 |
| 已有寿险保额 | 0 万 | 无 |
| 可变现资产 | 60 万 | 存款与理财，**不含自住房与车** |

**代入**

```
保额 = 负债余额 + 家庭年支出 × 剩余抚养年限 − 已有寿险保额 − 可变现资产
     = (180 + 8) 万 + 30 万 × 18 − 0 − 60 万
     = 188 万 + 540 万 − 60 万
     = 668 万
```

**结论**：风险缺口约 **668 万**，属于缺口较大。单靠家庭现有资源无法覆盖。

> **注意**：188 万的房贷占缺口的 28%。如果家庭同时有较高保额，这部分会很快被覆盖。

---

### 算例二：单收入家庭（有房贷，孩子还小）

**输入**

| 项 | 数值 | 口径 |
|---|---|---|
| 房贷余额 | 260 万 | 剩余本金 |
| 家庭年支出 | 24 万 | 近 12 个月平均，配偶无收入 |
| 剩余抚养年限 | 21 年 | 孩子 3 岁 → 算到 24 岁 |
| 已有寿险保额 | 50 万 | 配偶已投定期寿险 |
| 可变现资产 | 40 万 | 存款，**不含房与车** |

**代入**

```
保额 = (260 + 0) 万 + 24 万 × 21 − 50 万 − 40 万
     = 260 万 + 504 万 − 90 万
     = 674 万
```

**结论**：缺口约 **674 万**，但**实际应由夫妻双方共同覆盖**。

**这个算例的关键结论不是数字，而是「谁该被保」**：单收入家庭，收入中断方的责任远大于另一方。按 674 万全额投保一方通常超出可保范围，**更合理的做法是双方分工覆盖总额**。是否可行取决于核保结论。

---

### 算例三：缺口为负（必须复核口径）

**输入**

| 项 | 数值 | 口径 |
|---|---|---|
| 房贷余额 | 0 万 | 已结清 |
| 家庭年支出 | 36 万 | 含两个孩子教育 |
| 剩余抚养年限 | 15 年 | 长子 9 岁 → 算到 24 岁 |
| 已有寿险保额 | 300 万 | 一方定期寿险 200 万 + 单位团险身故 50 万 + 年金险身故责任 50 万 |
| 可变现资产 | 480 万 | 存款与理财，**不含房与车** |

**代入**

```
保额 = 0 万 + 36 万 × 15 − 300 万 − 480 万
     = 540 万 − 780 万
     = −240 万
```

**结论**：理论上覆盖充分（超出 240 万）。

**但必须先复核三件事：**

1. **300 万已有保额是否真的有效？** 单位团险的 50 万**离职后可能失效**——若投保人会离职，这 50 万应扣除。
2. **年金险那 50 万是否为身故责任？** 纯生存领取型年金险无独立身故保额，应扣除。
3. **480 万资产是否真能变现？** 未上市股权、高比例单一持仓的资产应折价。

**复核后若 300 万实际只有 250 万，缺口变为 +210 万。** 这就是「负数结果必须复核口径」的含义。

---

### 算例四：无负债无抚养责任（结果接近零）

**输入**

| 项 | 数值 | 口径 |
|---|---|---|
| 负债余额 | 0 万 | 无负债 |
| 家庭年支出 | 14 万 | 双退休，无教育支出 |
| 剩余抚养年限 | 8 年 | 算到父母生活自理困难 |
| 已有寿险保额 | 0 万 | 无 |
| 可变现资产 | 90 万 | 存款与理财，**自住房与车不计入** |

**代入**

```
保额 = 0 万 + 14 万 × 8 − 0 − 90 万
     = 112 万 − 90 万
     = 22 万
```

**结论**：缺口 **22 万**，属于**小额缺口**。

> 这种缺口未必需要用寿险解决——可能是「体检后一次性支出」「照护费用」等阶段性需求。**小额缺口是否值得专门配置寿险，是需要用户自己判断的决策，不是本技能能给结论的事。**

## 六、保额过低的判断线

| 判断线 | 阈值 | 含义 |
|---|---|---|
| 保额 < 负债余额 | 连债务都覆盖不了 | 收入中断即断供，属**严重不足** |
| 保额 < 家庭年支出 | 连一年开销都覆盖不了 | **明显不足** |
| 保额 < 家庭年支出 × 剩余年限（× 50%） | 只能覆盖一半抚养期开销 | **不足**，家庭将面临被迫借款或压缩教育 |
| 保额 < 家庭年支出 × 剩余年限 | 未覆盖全期抚养成本 | **临界**，需结合资产判断 |

**更高频的「其实保额不低」的信号：**

- 算出来的缺口为负 → 可能是口径录错，先复核
- 保额已覆盖负债但没覆盖抚养 → 需要区分「债务缺口」和「抚养缺口」

> **判断保额是否够，看的是「出事后家庭能撑几年」，不是「保额数字够不够大」。**

---

## 七、保额过高的浪费在哪

**保额算高不是「更安全」，而是确定支出。** 浪费体现在四处：

### 7.1 保费长期挤占现金流

| 项目 | 说明 |
|---|---|
| 缴费期 | 定期寿险常见 20 年、30 年，**保费是长期刚性支出** |
| 挤压点 | 教育金、养老金储备、应急金可能被挤压 |
| 判断方法 | 加上这笔保费后，**家庭年度结余是否仍为正**、应急储备能否覆盖 6–12 个月支出 |

> **保额再高，缴不起也是零。** 一个缴 20 年、每年影响家庭结余 30% 的方案，实际是「理论有保障、实际中途断缴」。

### 7.2 产品形态不匹配导致的沉没成本

| 形态 | 若保额严重超出实际需求 |
|---|---|
| 定期寿险 | 到期无返还，保费**纯消耗**（消费型） |
| 终身寿险 | 现金价值缓慢累积，**回本期长**，超配则长期锁定 |
| 年金险 | 若用**超长期限**换现金流，实际是被锁定的低流动性资产 |

### 7.3 核保可行性风险

- 高保额投保可能触发**体检、加保、财务核保**流程
- 有既往病史或体检异常记录时，超额投保**更容易被拒保或加费**
- 因此「算一个高保额」在**核保层面反而可能更难实现**

### 7.4 长期资金机会成本

- 保费是**确定支出**，保障是**或有收益**
- 长期缴付会占用本可用于其他储备的资金
- **不做收益预测**，只提示：资金用途之间存在此消彼长的关系

## 八、定期寿险 / 终身寿险 / 年金险的形态差异

| 维度 | 定期寿险 | 终身寿险 | 年金险 |
|---|---|---|---|
| 保障期限 | 固定（如至 60 岁 / 至 70 岁） | 终身 | 通常为养老/教育现金流设计 |
| 保障性质 | 消费型，**到期无返还** | 兼具保障与储蓄属性 | 以领取现金流为主 |
| 现金价值 | 到期归零或极低 | 缓慢累积 | 通常有账户累积 |
| 主要解决 | 收入中断期的家庭责任 | 传承 + 资产定向安排 | 退休后现金流 |
| 匹配场景 | 有抚养/赡养责任、预算有限、预算压力集中在责任期 | 有传承需求、预算充裕 | 养老现金流规划 |
| 主要局限 | 续期风险、责任期外的需求不覆盖 | 保费高、长期占用资金、回本慢 | 流动性弱、提前退保损失大 |

**形态选择的判断顺序（不推荐产品）：**

```
先问：保障责任期在哪里？
  ├─ 有抚养/赡养责任 → 责任期内定期寿险是成本效率较高的形态
  ├─ 有传承需求 → 终身寿险形态
  └─ 养老现金流 → 年金形态

再问：预算允许吗？
  ├─ 允许 → 按责任期配足
  └─ 不允许 → 先保「经济支柱 + 主要责任期」，不要为「全形态齐全」牺牲基础保额
```

> **常见的倒置做法：预算不足时优先买了形态更复杂的产品，导致基础保额严重不足。** 保障不足时，先解决「有没有」，再考虑「是哪一种」。

## 九、已有保额的常见误判（防误伤）

| 误判 | 正确口径 |
|---|---|
| 「我买了 50 万重疾险，寿险保额够了」 | ❌ 重疾险**无身故赔付责任**（消费型），不能抵扣寿险缺口 |
| 「我买了年金险，算有保额」 | ⚠️ 仅**有身故责任的部分**可计入；纯生存领取型不可计入 |
| 「增额终身寿有现金价值，能当保额」 | ❌ 现金价值是**储蓄账户**，不是身故保障额度 |
| 「单位团险有 100 万身故」 | ⚠️ 需确认**离职后是否失效**及续保条件 |
| 「车和房子值钱，可以抵扣」 | ❌ 默认不计入可变现资产 |
| 「我打算再买一份，加上现有的」 | ⚠️ **累计**保额才计入，不能重复计算同一份保额 |
| 「保额算出来是负数，所以不用买了」 | ⚠️ 先复核口径；复核后仍为负才说明现有资源已覆盖 |

## 十、脚本用法

```bash
python scripts/coverage_calc.py --file household.txt
python scripts/coverage_calc.py --file household.txt --json --out result.json
python scripts/coverage_calc.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 家庭参数文件，每行 `键\|值`，见下表 |
| `--json` / `--out` | JSON 输出 / 写入指定文件 |
| `--selftest` | 跑内置自检（≥ 8 条断言） |

**输入文件键名（单位一律用「万元」）：**

```
debt_mortgage|180        # 房贷剩余本金（万元）
debt_car|8               # 车贷剩余本金（万元）
debt_other|0             # 其他消费贷/经营贷余额（万元）
annual_expense|30        # 家庭年支出，近 12 个月平均（万元）
support_years|18         # 剩余抚养年限（年）
existing_coverage|0      # 已有寿险身故保额（万元）
liquid_assets|60         # 可变现资产，不含自住房与车（万元）
has_mortgage|1           # 是否有房贷
supporting_dependent|1   # 是否有需抚养/赡养对象
```

脚本做五件事：① 代入公式输出**逐步计算过程**；② 判定缺口方向（正/零/负）；③ 输出**保额偏低判断线**的逐条对照；④ 标注**口径需复核**的情形（负数结果、已有保额构成存疑）；⑤ 提示**保费承受力**这一第二道闸。

> 脚本**不推荐任何产品、不计算任何收益或保费**，只做缺口算术与口径校验。

## 十一、人工确认清单（这步不能省）

- [ ] **投保对象是家庭经济支柱**吗？（不是孩子，不是老人）
- [ ] 房贷余额用的是**剩余本金**还是原贷款总额
- [ ] 家庭年支出是**近 12 个月平均**，且含教育与赡养
- [ ] 剩余抚养年限算到**孩子经济独立**（22–25 岁），不是上幼儿园
- [ ] 已有保额是否**逐张核对**，且只计**身故责任**
- [ ] 重疾险、医疗险**没有被误当作已有寿险保额**
- [ ] 单位团险是否**离职后失效**
- [ ] 可变现资产**未含自住房与车**
- [ ] 结果为负数时，**已复核全部五项口径**
- [ ] 加这笔保费后，**家庭年度结余仍为正**吗
- [ ] 家庭是否有**既往病史或体检异常**（影响核保，不是测算问题）
- [ ] 结论是否已明确告知：**测算仅供自查，投保以核保结论与合同约定为准**

## 十二、最常见的坑

**坑一：把「我买了很多保险」当成「我有相应保额」。**
重疾险 50 万、医疗险、意外险**都不含身故赔付责任**，不能抵扣寿险缺口。买得多不等于保额高。**只有含身故责任的保单才能计入已有保额。**

**坑二：把自住房和车算进可变现资产。**
房子是居住刚需、变现周期长、有税费与交易成本；车是折价快且属于消费资产。**默认两者都不计入。** 计入后缺口会被大幅低估，得出「不用买了」的错误结论。

**坑三：抚养年限算到孩子上小学。**
教育阶段是持续且刚性的支出。**算到经济独立（22–25 岁）**才是通常口径。这一项是算低缺口的最大单一来源。

**坑四：房贷余额用原贷款总额。**
200 万的房贷还剩 60 万，缺口就差 140 万。**必须用当前剩余本金。**

**坑五：算出来的负数直接当结论。**
负数多半是口径录错的信号，最常见的是**漏算已有保额或漏算房贷**。复核口径后再下结论。

**坑六：只给「谁危险给谁买」。**
保额绑定的是**家庭经济支柱**——收入中断会摧毁家庭现金流的那个人。给老人或孩子高额保额而经济支柱保额不足，配置是错位的。

**坑七：算出缺口就当作「应该买这么多」。**
缺口是「需要多少保障」，不是「应该买多少保额」。**保费承受力是第二道闸**：缴 20 年每年吃掉家庭结余 30% 的方案，实际是中途断缴。

**坑八：保额越高越安心。**
保额过高的浪费是**确定的**（保费长期支出），保障是**或有的**。超配还会带来核保难度上升、长期资金占用、形态不匹配导致的沉没成本。

**坑九：忽略续期风险。**
定期寿险需要长期缴费。**缴费期内的收入中断或失业，反而是最需要保障的时候**——此时续期能力最弱。只看「现在能缴」而忽略「20 年都能缴」是典型低估风险。

**坑十：把团险的保额当成永久保障。**
单位团险的身故责任**通常在离职后失效**。把离职会失效的团险保额计入已有保额，等于高估了现有保障。

**坑十一：漏算赡养父母的开销。**
父母年老的医疗与护理支出是刚性的，且随年龄快速上升。**遗漏这一项会显著低估缺口**，尤其是独生子女家庭。

**坑十二：拿年金险的「保额」抵扣寿险缺口。**
纯生存领取型年金险**没有独立的身故保障额度**。有身故责任的才能按保额计入，不能按现金价值抵扣。

## 十三、边界与免责

- 本技能给出的**保额测算仅供家庭风险缺口自查**，**实际投保以保险公司核保结论与合同约定为准**
- 本技能**不推荐任何保险产品，不比较产品优劣，不预测分红、收益或现金价值**
- 本技能**不含任何投保劝诱**，测算结果不构成投保建议，是否投保由家庭自行判断
- 健康告知、核保结论、体检与加保要求**只能由保险公司给出**，测算结果不等于可投保
- 涉及**既往病史、职业类别、超额投保**的核保问题，应咨询保险公司与专业保险顾问
- 家庭财务状况复杂（个体经营、多套房产、跨境收入、公司担保）时，建议**咨询专业保险顾问或税务与法律专业人士**
- 保险产品的条款、责任免除、等待期与犹豫期规则**以保险合同约定为准**
- 涉及**社保养老、遗属待遇**等公共保障部分的衔接，**以现行规定和当地主管部门要求为准**
