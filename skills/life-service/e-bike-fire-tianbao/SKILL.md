# 电动自行车消防安全（e-bike-fire）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据国务院安委办电动自行车全链条整治与GB 17761，生成电动自行车停放充电消防管理清单：集中充电、禁入楼、电池安全、物业巡查。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 电动车消防
- 电动自行车
- 充电安全
- 充电棚
- 飞线充电
- 电瓶车进楼

## 三、工作流
1. 划定室外集中停放充电区（与建筑≥安全距离）
2. 严禁入楼入户与飞线充电
3. 充电设施具备自动断电/过载保护
4. 物业日巡与监控
5. 居民消防安全宣传

## 四、核心内容（检查清单与判定）
整治要求：电动自行车及电池不得进楼入户；集中充电场所应独立设置并具备定时充电、自动断电、故障报警功能。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未设室外集中停放充电区或距离不达标 | 整治要求 |
| Q2 | FAIL | 未明确禁入楼/禁飞线 | 红线 |
| Q3 | WARN | 充电设施无自动断电/过载保护 | 充电安全 |
| Q4 | FAIL | 无物业巡查与监控 | 巡查 |
| Q5 | WARN | 未含居民宣传告知 | 宣传 |

> 脚本 `e-bike-fire_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python e-bike-fire_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python e-bike-fire_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 六、人工确认事项
- 法规条款以最新发布版本为准，标准更新后须复核本清单依据。
- 重大隐患/高风险判定需由具备资质人员签字确认。
- 涉及行政处罚或争议时，以主管部门认定为准。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
