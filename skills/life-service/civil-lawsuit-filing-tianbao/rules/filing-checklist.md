# 民事起诉与立案核查规则表

## 一、先判能否走法院

| 核查项 | 通过口径 | 不能通过时 |
|---|---|---|
| 原告与争议有直接利害关系 | 权利主体、继受人或依法有权起诉者有证明 | 先补主体资格或授权材料 |
| 被告明确 | 名称可识别，并有足以启动送达的合法线索 | 依法查询，不得猜证件号和住址 |
| 请求与事实具体 | 能看出要求谁做什么、给多少钱、为何承担 | 拆分请求并补计算表 |
| 属民事受案范围 | 平等主体之间的人身或财产争议 | 行政、刑事或劳动前置程序另行判断 |
| 无有效仲裁排除 | 未约定仲裁，或仲裁条款经核验不排除诉讼 | 有效仲裁约定通常走仲裁 |
| 无重复起诉冲突 | 当事人、标的、请求等不构成重复 | 比对既有案件与生效文书 |

## 二、管辖四层判断

1. **级别管辖**：先按案件性质、影响与标的判断基层或上级法院；普通一审民事纠纷多由基层法院受理，但特殊案件须核对当地标准。
2. **地域管辖**：一般以被告住所地为起点；合同、侵权、保险、票据、运输等可能有特别连接点。
3. **专属管辖**：不动产、港口作业、遗产继承等特定争议按专属连接点办理，不能被普通协议随意改变。
4. **协议管辖**：书面选择须与争议有实际联系，且不得违反级别和专属管辖；条款含糊、法院无法确定时不要自行断言有效。

### 常见场景取证

| 场景 | 常见连接点 | 建议证据 |
|---|---|---|
| 买卖、服务合同 | 被告住所地、约定或实际履行地 | 合同、订单、收货或服务记录 |
| 民间借贷 | 被告住所地、履行地 | 借据、转账、催收、收款账户 |
| 网络购物 | 被告住所地及依法确定的合同履行地 | 订单页、收货地址、平台主体信息 |
| 一般侵权 | 被告住所地、侵权行为实施地或结果地 | 现场记录、就医、平台记录 |
| 不动产纠纷 | 不动产所在地 | 权属材料、坐落信息 |

## 三、立案材料清单

| 类别 | 必备内容 | 高频被卡原因 |
|---|---|---|
| 起诉状 | 当事人、请求、事实理由、签名日期 | 请求不具体、份数不足、未签名 |
| 原告主体 | 自然人身份证明；单位登记与负责人材料 | 名称过期、证件不清、负责人不一致 |
| 被告线索 | 准确名称及合法取得的地址、联系方式等 | 只有昵称、门店名，不足以确定主体 |
| 授权材料 | 授权委托书及代理人资格材料 | 权限未写清、特别授权缺失 |
| 证据目录 | 编号、名称、来源、页码、证明目的 | 目录与附件顺序、页码不一致 |
| 基础证据 | 支撑法律关系、履行、违约或损害 | 只有单方表述，没有原始载体 |
| 送达信息 | 当事人确认的送达地址或合法线索 | 地址陈旧、把户籍地当实际可收件地 |
| 费用申请 | 缓交、减交、免交的理由与证明 | 只口头申请，没有证明材料 |

线上提交通常需清晰、正向、完整扫描；同一证据多页合并，文件名含证据编号。敏感信息按平台要求处理，但给法院的必要身份信息不得擅自遮掉。

## 四、诉讼请求写法

- 给付金钱：本金、利息或违约金、损失分别编号；写基数、标准、起止日、暂计日。
- 履行行为：明确标的、数量、地点、期限和可识别状态，避免「恢复原状」却不说明恢复到何种状态。
- 确认请求：明确需要确认的权利、合同效力或关系，不与给付请求混成一句。
- 费用承担：案件受理费、保全费等按实际发生并依法裁判，不把尚未发生的律师费当然写成必然支持。

## 五、财产案件受理费速算

以下为常用分段速算口径，金额单位为元；最终以法院收费通知为准。

| 诉讼标的额 | 速算方式 |
|---|---|
| 不超过 10,000 | 50 |
| 10,000 至 100,000 | 标的额 × 2.5% − 200 |
| 100,000 至 200,000 | 标的额 × 2% + 300 |
| 200,000 至 500,000 | 标的额 × 1.5% + 1,300 |
| 500,000 至 1,000,000 | 标的额 × 1% + 3,800 |
| 1,000,000 至 2,000,000 | 标的额 × 0.9% + 4,800 |
| 2,000,000 至 5,000,000 | 标的额 × 0.8% + 6,800 |
| 5,000,000 至 10,000,000 | 标的额 × 0.7% + 11,800 |
| 10,000,000 至 20,000,000 | 标的额 × 0.6% + 21,800 |
| 超过 20,000,000 | 标的额 × 0.5% + 41,800 |

非财产案件、知识产权、劳动争议等另有收费口径。保全、鉴定、公告、评估、翻译和律师服务等费用不当然包含在案件受理费内。简易程序、调解、撤诉等可能涉及减半或退费，依实际程序决定。

## 六、办理时限、被卡原因与救济

- **审查口径**：材料齐全且符合条件的依法登记立案；通常民事立案决定按七日口径掌握。网上预审、补正、身份核验和跨域转交所用时间另行记录，以法院通知为准。
- **补正**：收到通知后按指定期限和项目补齐，提交逐条对照表；不要删除旧回执。
- **不予受理**：要求取得载明理由与救济方式的正式文书，并在文书载明期限内依法处理。
- **久拖无反馈**：保存提交时间、编号和沟通记录，可联系诉讼服务中心查询，或依现行机制向上级法院反映。
- **管辖异议或移送**：区分「材料预审建议改投」与正式裁定，必要时咨询律师。

所有期限、收费、管辖与救济方式，**以现行规定和当地法院要求为准**。
