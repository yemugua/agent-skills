# 民事起诉状与法院立案材料核查

## 一、硬边界

| 能做 | 不能做 |
|---|---|
| 梳理可能有管辖权的法院并提示冲突 | 代替法院决定立案或移送管辖 |
| 检查起诉状、主体材料、证据目录是否齐全 | 代签、代交材料或冒充律师代理 |
| 把诉讼请求改成明确、可计算、可执行的表达 | 编造当事人、金额、送达地址或证据 |
| 按现有材料估算案件受理费 | 承诺胜诉、执行回款或精确结案日期 |
| 输出补正清单与提交顺序 | 对需鉴定、涉外、群体性或重大疑难案件下最终意见 |

出现人身安全风险、诉讼时效将届满、财产可能转移、需行为禁令或保全、涉外送达、人数众多或金额重大时，应尽快交由律师、法律援助机构或受诉法院诉讼服务中心处理。

## 二、什么时候用

| 用户说法 | 用不用 |
|---|---|
| 「欠款不还，我该去哪个法院起诉」 | 用，先做管辖与被告信息核查 |
| 「网上立案退回，说请求不明确」 | 用，按退回理由逐项补正 |
| 「帮我做证据目录和起诉状清单」 | 用 |
| 「诉讼费大约多少」 | 用，只做估算 |
| 「帮我伪造一张借条」 | 不用，明确拒绝 |
| 「这案子一定能赢吗」 | 不用，不能预测裁判结果 |

## 三、完整工作流

1. **建案件卡**：案由事实、原被告身份、争议金额、合同履行地、侵权地、不动产所在地、约定管辖、仲裁条款、最早到期日。
2. **先判程序入口**：是否已有有效仲裁约定、是否重复起诉、是否属于民事受案范围；不满足就先处理入口问题。
3. **核管辖**：按 `rules/filing-checklist.md` 依次检查级别、地域、专属与协议管辖，列出首选法院和备选依据，不只凭原告所在地判断。
4. **写请求**：本金、利息或损失、履行行为、费用承担分开编号；金额请求写明计算基数、期间、标准和暂计日。
5. **组材料**：起诉状、身份或主体资格、授权手续、证据目录与证据、送达线索、费用或缓减免材料。
6. **做证据映射**：每项请求至少对应一组证据；证据目录只写可证明的事实，不先下「对方违法」等结论。
7. **估算费用**：按规则表分段计算财产案件受理费，另列保全、鉴定、公告等可能费用并标注未计入。
8. **人工复核后提交**：按法院在线平台或窗口提示上传，保留提交回执、退回理由与补正时间。

材料齐全且符合起诉条件的，法院通常依法登记立案；不能当场判断的，一般在法定审查期间内决定是否立案。常见民事案件通常以七日审查口径掌握，但网上预审、跨域提交、身份核验和补正耗时不等同于立案审查期，**以现行规定和受诉法院通知为准**。

## 四、核心规则与要件库

生成起诉状或补正意见前，**必须先读**：

- `rules/filing-checklist.md`：管辖四层判断、材料清单、诉讼费速算、退回原因、办理时限与救济路径。
- `templates/complaint-evidence-index.md`：起诉状与证据目录的可填写模板。

不要凭印象补法院名称、案号、身份证号、统一社会信用代码、利率或送达地址。无法确认的字段写「待当事人核实」，不得猜测。

## 五、人工确认清单

- [ ] 原被告名称与证件、登记信息逐字一致，法人分支机构主体适格已核验
- [ ] 无有效仲裁条款、重复起诉或已生效裁判冲突
- [ ] 管辖依据能落到具体事实和证据，协议管辖条款清晰有效
- [ ] 每项诉讼请求有编号、有金额或履行内容、有计算口径
- [ ] 事实时间线与证据日期不打架，复印件与原件一致
- [ ] 证据目录页码、份数、证明目的与附件一致
- [ ] 已核对诉讼时效、送达线索、保全必要性和费用承受能力
- [ ] 已按在线平台格式脱敏或分卷，并保存提交回执

## 六、最常见的坑

1. **只选离自己近的法院**：一般先看被告住所地，再结合合同履行地、侵权地和专属管辖；选错会退件或移送。
2. **把合同里的「争议解决」看漏**：有效仲裁约定可能使法院不受理；「可仲裁也可诉讼」等表述还需专业核验。
3. **请求写成口号**：只写「依法赔偿全部损失」而没有项目、金额和算法，常被要求补正。
4. **利息算到永远却不写标准**：应写基数、起止日、标准及暂计金额，后续金额以实际履行日计算。
5. **证据堆满但不对应请求**：截图、录音、转账各自证明什么要写明；聊天记录需保留账号信息、上下文和原始载体。
6. **把「未付款」误读成「已付款」**：核查否定词、撤回信息、冲正记录和仅部分履行，不能只做关键词命中。
7. **被告信息靠猜**：名称、证件号码或地址错误会影响送达和执行；先通过合法渠道核实。
8. **退回后反复原样提交**：逐条回应退回理由，制作「退回理由—已补材料—页码」对照表。
