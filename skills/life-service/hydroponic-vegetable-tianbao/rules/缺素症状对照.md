# 缺素症状对照与换液口径

> 不提供任何营养液商品配方与品牌。浓度区间为通用参考，以产品说明和当地农技部门口径为准。

## 一、判断第一步：老叶还是新叶

| 位置 | 指向 | 道理 |
|---|---|---|
| 老叶先出现 | 移动性元素不足（氮、磷、钾、镁） | 元素可在体内转运，供应不足时先从老叶搬到新叶 |
| 新叶先出现 | 不可移动元素不足（钙、铁、硫、硼等） | 元素不能转运，只能靠新吸收 |

## 二、缺素症状对照表

| 症状 | 可能病因 | 常见伴随表现 | 处置方向 |
|---|---|---|---|
| 老叶均匀发黄，从叶尖向内发展 | 缺氮 | 植株矮小、新叶偏淡、生长慢 | 提高氮素供给，复测 EC |
| 老叶紫红、叶背有暗色 | 缺磷 | 生长迟缓、茎细 | 提高磷素供给；低温时磷吸收差 |
| 老叶叶缘焦枯、叶尖先枯 | 缺钾 | 叶面斑点、果实着色差 | 提高钾素供给 |
| 老叶叶脉间发黄，叶脉仍绿 | 缺镁 | 严重时出现褐斑 | 补充镁；低温时镁吸收受影响 |
| 新叶发黄但叶脉清晰（网状绿脉） | 缺铁 | 新叶小、卷曲 | 调整 pH 并供铁；pH 过高时铁被固定 |
| 新叶顶端卷曲、生长点坏死 | 缺钙 | 果实脐腐、顶芽枯死 | 供钙；重点稳水分与根区温度 |
| 叶片整体褪绿发白、均匀 | 缺硫 | 新叶也偏黄 | 与缺氮区分：缺硫是新叶先黄 |
| 根褐变、黏滑、有异味 | 根腐（不是缺素） | 植株萎蔫、生长停滞 | 按根病处理，先查供氧与水温 |
| 根表褐色锈斑、白色附着物 | 根部沉积或藻类 | 生长缓慢 | 检查硬度与光照，降低表面藻类 |
| 叶片深色斑点或霉层 | 病害（非缺素） | 局部扩散 | 按病害处理，需专业判断 |

## 三、最有效的分流判断

```
根是白的，只是叶黄  ->  优先按缺素排查
根已褐变发臭        ->  先处理根区，无论叶子怎么黄
```

**先看根的状态，再看叶子**，这一步能省掉大量误判。

## 四、分阶段 EC 浓度与 pH 区间（mS/cm）

| 作物 | 苗期 | 生长期 | 成熟期 | pH 区间 |
|---|---|---|---|---|
| 生菜 | 0.4-0.8 | 0.8-1.2 | 1.0-1.6 | 5.5-6.5 |
| 小白菜 | 0.4-0.8 | 0.8-1.2 | 1.0-1.5 | 5.5-6.5 |
| 菠菜 | 0.5-0.9 | 0.9-1.4 | 1.2-1.8 | 5.5-6.8 |
| 番茄 | 0.6-1.0 | 1.2-2.0 | 1.8-2.5 | 5.5-6.5 |
| 辣椒 | 0.5-0.9 | 1.0-1.8 | 1.6-2.2 | 5.5-6.5 |
| 黄瓜 | 0.6-1.0 | 1.2-2.0 | 1.8-2.4 | 5.5-6.8 |
| 罗勒 | 0.4-0.8 | 0.8-1.4 | 1.0-1.6 | 5.5-6.5 |
| 草莓 | 0.5-0.9 | 0.9-1.5 | 1.2-1.8 | 5.5-6.5 |

**起步口径**：从区间中位偏下开始，观察 3-5 天无异常后再往上加。

## 五、pH 调节口径

| 方向 | 影响 | 调节做法 |
|---|---|---|
| pH 偏高（> 6.8） | 铁、锰等微量元素易被固定，根系发褐 | 少量多次下调 |
| pH 偏低（< 5.5） | 钙、镁吸收受阻，易出现缺钙表现 | 少量多次上调 |
| 每次调整幅度 | — | 1 个单位以内，调后静置 1-2 小时复测 |
| 测量 | — | 每次测同一支笔，避免仪器误差 |

**pH 每天会往下掉**：根系呼吸产酸，属正常现象。每天测一次、必要时补调即可。

## 六、换液与补液

| 项目 | 口径 |
|---|---|
| 换液周期（生长旺盛期） | 7-10 天一次 |
| 换液周期（苗期） | 可延长到 10-14 天 |
| 换液周期（高温期） | 缩短到 5-7 天 |
| 补液间隔 | 每 2-3 天补一次消耗的水 |
| 补液后动作 | **必须复测 EC** |
| 补液依据 | EC 偏高说明溶质已够，补水；EC 偏低说明被吸收，补营养液 |
| 换液要点 | 清洗容器与根系表面旧液；旧液不直接倒地下 |
| 换液时机 | 早晨或傍晚，避开高温；换后 1-2 小时内不强光暴晒 |
| 台账 | 记录日期、EC、pH、温度、换液或补液量 |

## 七、源水四项

| 项目 | 口径 | 不合格的处理 |
|---|---|---|
| EC | 越低越好，一般要求 0.5 mS/cm 以下 | 高 EC 需稀释或换水源 |
| pH | 6.5-7.5 之间较好调 | 酸碱异常先处理水而非加调节剂 |
| 硬度（钙镁） | 越高越容易在根表形成沉积 | 需软化或改用纯水 |
| 钠离子 | 越低越好 | 高钠会累积并造成生理性缺水 |

**自来水静置**：12-24 小时并充分曝气，让余氯挥发后再用。

## 八、体系与供氧

| 体系 | 液层深度 | 供氧要求 | 备注 |
|---|---|---|---|
| 深液流（DFT） | 5-10 cm | 水泵循环或定期换液 | 家庭最常见 |
| 营养液膜（NFT） | 薄层流过根面 | 必须有循环泵 | 停电 2 小时以上根系失水 |
| 浮板（浮筏） | 液层 3-6 cm | 液面不淹没根颈 | 叶菜最常用 |
| 雾培 | 喷雾 | 高压喷雾，根悬空 | 家庭不建议 |

## 九、光照与其它环境

| 项目 | 口径 |
|---|---|
| 光照时长（叶菜） | 每日 12-16 小时 |
| 光照时长（果菜） | 每日 14-16 小时 |
| 补光灯距叶面 | 20-30 cm，避免贴近烤伤 |
| 液温 | 理想 18-22℃；高于 25℃ 溶氧下降 |
| 水温波动 | 尽量稳定，骤变引发应激与根病 |
| 室内通风 | 保持空气流通，减少叶面结露 |

## 十、安全与卫生

| 项目 | 口径 |
|---|---|
| 原液存放 | 浓缩营养液开封后放到高处或上锁柜中 |
| 皮肤接触 | 溅到皮肤立即用大量清水冲洗 |
| 自配配液 | 每种盐单独称量溶解，逐一核对后再混合 |
| 混合顺序 | 先大量元素后微量元素，避免局部浓度过高 |
| 禁止混用 | 不混用两个品牌的营养液，不混用营养液与自配液 |
| 废液处置 | 不倒入下水道直排；按当地环保要求处置 |
| 儿童与宠物 | 容器、营养液、pH 调节剂放到接触不到的位置；水体不可饮用 |
| 用电 | 水泵、增氧泵使用带接地插座；湿区不带电操作 |
