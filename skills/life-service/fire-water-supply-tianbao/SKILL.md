# 消防给水与消火栓系统（fire-water-supply）

> 领域：消防 ｜ 作者：刘天宝｜墨燊 ｜ House Style 合规技能

## 一、硬边界（什么场合用 / 不碰）
**使用场景**：依据《消防给水及消火栓系统技术规范》GB 50974，生成消防给水与消火栓系统核查清单：水源与消防用水量、消防水池与水箱、消防水泵与稳压设施、室内外消火栓布置、系统维护与检测。
**不适用**：非本行的通用咨询、法律诉讼代理、与现行规范冲突的诉求。所有结论须以**现行有效**法规/标准为准，本技能不做最终合规裁定。

## 二、使用场景（触发词）
- 消防给水
- 消火栓系统
- 消防水池
- 消防水泵
- 消防用水量

## 三、工作流
1. 核实水源与消防用水量
2. 核查消防水池与水箱容积
3. 检查消防水泵与稳压设施
4. 核查室内外消火栓布置
5. 定期维护与检测

## 四、核心内容（检查清单与判定）
GB 50974 规定消防给水的水源、用水量、水池水箱、水泵与消火栓布置要求；系统应保证火灾时水量水压可靠，并定期维护检测。

| 编号 | 等级 | 检查项 | 依据 |
|---|---|---|---|
| Q1 | FAIL | 未含水源与消防用水量核实 | 水源 |
| Q2 | FAIL | 未含消防水池/水箱容积核查 | 水池 |
| Q3 | WARN | 未含消防水泵与稳压设施 | 水泵 |
| Q4 | FAIL | 未含室内外消火栓布置 | 消火栓 |
| Q5 | WARN | 未含维护与定期检测 | 维保 |

> 脚本 `fire-water-supply_check.py` 可对上述清单做自检：传入 JSON 记录，输出 FAIL/WARN 与命中条款。

## 五、脚本用法
```bash
# 对单条记录核查
python fire-water-supply_check.py --file record.json --today 2026-10-13
# 自检（内置 good/bad 样本断言）
python fire-water-supply_check.py --selftest
```
退出码 0=通过，1=存在 FAIL 或自检未过。

## 七、输出结构
- 核查结论（通过/存在不符合项）
- 不符合项明细（编号/等级/条款/说明）
- 整改建议与闭环时限
- 留痕记录（谁/何时/依据）

## 八、常见坑
- 把"建议"当"强制"，混淆规范性条文与推荐性条文。
- 漏查时效性：证书、检测报告、许可证均有时效，过期即不符。
- 只看有无、不看有效性（如制度上墙但从未演练）。
- 样本数据造假：自检用随机样本，不等于真实合规。
