# 操作顺序与防控做法

> 生成交叉污染防控建议前先读这份文件。不要泛泛说「注意卫生」。

## 一、操作顺序（核心）

**正确顺序：先洗菜 -> 再切生肉 -> 最后切熟食**

| 键 | 步骤 | 做法 | 常见错误 |
|---|---|---|---|
| `wash_veg` | 第一步：先洗菜切菜 | 先处理蔬菜与水果，洗净沥干后切分装盒 | 先切生肉再洗菜，生肉汁液沾到水龙头与菜上 |
| `cut_raw_meat` | 第二步：再切生肉生禽 | 生肉禽单独用刀与砧板，切完立即清洗器具与台面 | 用切过生肉的刀直接切熟食或直接入口食品 |
| `cut_cooked` | 第三步：最后切熟食 | 生熟彻底分开后，最后处理熟食、即食与水果 | 把生熟食放在同一块砧板上切 |

**为什么这个顺序**：蔬菜表面可能本来就带菌，生肉带来的污染是**新增且量更大的**。
先处理蔬菜并分装，再处理生肉，最后处理熟食——即使前面有轻微污染也不会传到即食环节。

## 二、砧板五色分区

| 颜色 | 用途 | 注意 |
|---|---|---|
| 红色 | 生肉与生禽 | 切生肉禽后的刀要专用，不切其他 |
| 蓝色 | 生海鲜与水产 | 水产易交叉污染，且易流失汁液 |
| 绿色 | 蔬菜与水果 | 蔬菜先洗后切；洗净即食的可不再加热 |
| 黄色 | 熟食与即食 | 切熟食即食的刀与砧板，不碰生食 |
| 棕色 | 生食非肉类 | 如生豆类、生熟前处理 |

**没有分色砧板**：用三块不同颜色的砧板，或在背面做永久标记。
关键是**有明确的物理区分，不靠记忆**。

## 三、八项具体做法

1. 砧板**按颜色分区**
2. 生肉专用刀与砧板，**不切熟食也不切直接入口的蔬果**
3. 切生肉后**立即用皂液洗手**，再接触熟食与即食食品
4. 生禽生肉放入**底部或专用密闭容器**，滴液不得污染下层即食食品
5. 解冻水与血水**必须倒掉**，容器用后立即清洗
6. 生熟食**分格存放，生食在下、即食在上**
7. 凉拌菜与即食食品**制作后尽快食用**，不与生食交叉接触
8. 只有一把刀时，切完生肉**彻底冲洗并用皂液清洁刀面**

**第 8 条展开**：生肉表面的致病菌需**流动水加皂液摩擦**才能去除，
只用擦刀布擦干等于没洗，还把污染转移到布上。

## 四、六种常见致病菌

| 致病菌 | 主要来源 | 易被忽视之处 |
|---|---|---|
| 沙门氏菌 | 生禽肉、生蛋、交叉污染的即食食品 | 污染的蛋与禽肉**外观与气味完全正常**，加热充分可杀灭，生食阶段无任何提示 |
| 李斯特菌 | 冷藏即食食品、软奶酪、熟肉制品 | 可在**冷藏温度下缓慢增殖**，感官均无异常 |
| 弯曲菌 | 生禽肉、未经巴氏杀菌的奶 | 生禽阶段无感官提示，加热可杀灭，但**仅冲洗不能杀灭** |
| 金黄色葡萄球菌 | 熟食、含奶油的点心、长时间室温食物 | 耐热毒素**加热不能破坏** |
| 蜡样芽孢杆菌 | 米饭、面条等含淀粉食物的室温存放 | 部分毒素**加热不被破坏**，凉饭剩饭风险更高 |
| 大肠杆菌 | 未洗净的生蔬、污染的即食食品 | 生菜沙拉风险常被低估，**不经过加热即被食用** |

**两条规律**

1. **感官正常 ≠ 安全**
2. **冲洗不能替代加热**

## 五、冷藏温度区间

| 部位 | 上限 | 说明 |
|---|---|---|
| 冷藏室 | 不高于 4℃ | 4 至 60℃ 是细菌快速繁殖的危险区间 |
| 冷冻室 | 不高于 −18℃ | 温度升高冷冻效果下降 |

冷藏的全部意义就是**把温度压到 4℃ 以下**，缩短危险区间停留时间。

## 六、高风险人群

| 人群 | 注意 |
|---|---|
| 婴幼儿 | 尤其 6 个月以下，肠道菌群尚未建立 |
| 孕妇 | 避免生食与未彻底加热的肉蛋水产 |
| 65 岁以上老人 | 免疫下降，且**味觉嗅觉减退导致感官判断本身不可靠** |
| 免疫力低下者 | 含长期使用激素、化疗、器官移植后服药人群 |
| 正在服药者 | 部分药物与免疫功能相关 |
| 慢性病患者 | 糖尿病等基础病会放大后果 |

**对高风险人群供餐**：生食一律避免，凉拌菜与即食制作环节清洁要求更高。

## 七、八项检查

| 键 | 检查项 | 说明 |
|---|---|---|
| `board_separated` | 砧板生熟分开 | 生肉砧板与熟食砧板分用，未混用 |
| `knife_dedicated` | 刀具专用 | 生肉刀不切熟食与即食食品 |
| `hand_washed` | 处理生肉后洗手 | 切完生肉已用皂液洗手，再接触熟食 |
| `store_order` | 冰箱生熟分格 | 生食放下层，即食放上层，有滴液隔离 |
| `juice_discarded` | 解冻水与血水已倒 | 未污染其他 |
| `veg_washed_first` | 蔬菜先洗后切 | 未先切生肉再洗菜 |
| `cold_food_protected` | 即食与凉菜隔离 | 未与生食交叉接触 |
| `equipment_cleaned` | 器具已清洗 | 砧板、刀、台面已清洗 |

## 八、明确禁止的操作

1. 同一块砧板先切生肉再切熟食
2. 用切过生肉的刀切熟食或即食食品，不清洗
3. 切完生肉不洗手就接触熟食与即食食品
4. 生蔬与即食凉菜放在同一容器或同一层冰箱
5. 切好的生肉与熟食混装在一个保鲜盒
6. 处理生肉后不倒掉解冻水与血水
7. 生禽与即食食品放在同一层且不做隔离
8. 只用擦刀布擦一下刀就当作清洗完成

## 九、否定词与防误伤

- 「**闻着没味**」**不等于**安全，感官正常 ≠ 安全
- 「**冲洗过了**」**不等于**杀灭，弯曲菌仅冲洗不能杀灭
- 「**擦干净了**」**不等于**洗干净，擦刀布只转移污染
- 「**就一个碗**」**不等于**可以混装，生熟必须分格
- 「**给家人吃没事**」**不等于**安全，高风险人群门槛更低

## 十、处置决策树

```
1. 操作顺序是否为「先洗菜 -> 再切生肉 -> 最后切熟食」？
   ├─ 否 → 调整顺序，蔬菜先处理并分装
   └─ 是 → 继续
2. 砧板与刀具是否生熟专用？
   ├─ 否 → 按五色分区，红色生肉、黄色熟食即食
   └─ 是 → 继续
3. 切完生肉是否用皂液洗手并清洗器具台面？
   ├─ 否 → 立即执行，擦刀布不算
   └─ 是 → 继续
4. 冰箱是否生食在下即食在上、有滴液隔离？
   ├─ 否 → 分格并使用专用密闭容器
   └─ 是 → 继续
5. 凉拌菜与即食食品是否避免与生食交叉接触？
   ├─ 否 → 立即隔离，已污染的弃用
   └─ 是 → 继续
6. 冷藏是否不高于 4 摄氏度、冷冻不高于负 18 摄氏度？
   ├─ 否 → 调低温度并缩短存放时间
   └─ 是 → 维持
7. 食用者是否高风险人群？
   ├─ 是 → 生食一律避免，门槛再降一档
   └─ 否 → 完成
```
