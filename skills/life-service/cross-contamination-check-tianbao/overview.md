# 食物交叉污染与生熟分开

## 你会得到什么

一套按「先洗菜 → 再切生肉 → 最后切熟食」顺序组织的交叉污染防控口径，解决「同一块砧板先切生肉再切黄瓜」和「切完生肉擦一下手就去拿菜」这两类最常见的做法。

- **核心操作顺序**：**先洗菜 → 再切生肉 → 最后切熟食**。原因是蔬菜表面可能本来就带菌，而生肉带来的污染是**新增且量更大的**——先处理蔬菜并分装，再处理生肉，最后处理熟食，即使前面有轻微污染也不会传到即食环节。
- **砧板五色分区**：红色生肉禽、蓝色水产、绿色蔬果、黄色熟食即食、棕色生食非肉类。没有分色砧板就用三块不同颜色的板或做永久标记，关键是**有明确的物理区分不靠记忆**。
- **八项具体做法**，其中最关键两条是「切生肉后**立即用皂液洗手**」和「只有一把刀时**彻底冲洗并用皂液清洁刀面**」——生肉表面的致病菌需**流动水加皂液摩擦**才能去除，只用擦刀布擦干等于没洗，还把污染转移到布上。
- **六种常见致病菌及易被忽视之处**：沙门氏菌（污染的蛋与禽肉**外观与气味完全正常**）、李斯特菌（可在**冷藏温度下缓慢增殖**）、弯曲菌（加热可杀灭但**仅冲洗不能杀灭**）、金黄色葡萄球菌（耐热毒素**加热不能破坏**）、蜡样芽孢杆菌（含淀粉食物室温存放，毒素加热不破坏）、大肠杆菌（生菜沙拉**不经过加热即被食用**）。两条规律：**感官正常 ≠ 安全**、**冲洗不能替代加热**。
- **冷藏温度区间**：冷藏不高于 4℃、冷冻不高于 −18℃。4 至 60℃ 是细菌快速繁殖的危险区间，冷藏的全部意义就是缩短这段停留时间。
- **六类高风险人群**：婴幼儿（尤其 6 个月以下）、孕妇、65 岁以上老人（**味觉嗅觉减退导致感官判断本身不可靠**）、免疫力低下者、正在服药者、慢性病患者。
- **八条明确禁止的操作**与**八项检查项**，脚本输出**四级判定**（存在交叉污染风险／存在薄弱环节／待确认／操作规范）。

## 典型用法

- 家里做菜，生熟到底怎么分开
- 砧板要不要买分色的，一块板够不够
- 切完生肉要做什么才算洗干净
- 生肉和冰淇淋能放冰箱同一层吗
- 凉拌菜有什么风险，能不能给小孩吃
- 沙门氏菌和李斯特菌分别怎么来的
- 冷藏温度多少度合适，怎么判断
- 只有一把刀怎么避免交叉污染

## 边界

不检测致病菌，也不判定食品是否已被污染——**食品是否安全以具备资质的检测机构结果、现行规定和相应产品标签为准**。**本技能不提供任何消毒剂使用或杀菌方案**：已发生交叉污染的食物（如生肉汁液溅到即食凉菜上）应弃用，不能靠冲洗或再加热挽救，因为凉拌菜、即食水果、熟食**不会再加热**，污染一旦发生就是直接入口。涉及餐饮门店与食品生产经营的合规判定不属于本技能范围；已出现消化道症状者应及时就医，本技能不作健康或医疗建议。
