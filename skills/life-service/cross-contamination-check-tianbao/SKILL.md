# 食物交叉污染与生熟分开（cross-contamination-check）

交叉污染的核心只有一句话：**生肉上的致病菌，会通过刀、砧板、台面、水槽和你的手，转移到本来可以直接入口的食物上。**

而那些食物——凉拌菜、即食水果、熟食——**不会再加热**，所以污染一旦发生就是直接入口。

这个技能做三件事：**定顺序 → 查执行 → 控温度**。

---

## 硬边界（先看这条）

| 能做 | 不能做 |
|---|---|
| 核查操作顺序与生熟分开执行情况 | ❌ 检测食品中的致病菌或判断是否已污染 |
| 给出砧板分区与具体操作做法 | ❌ 判定食品是否达到安全标准 |
| 说明常见致病菌与高风险人群风险 | ❌ 提供任何消毒剂使用或杀菌方案 |
| 核查冷藏与冷冻温度是否符合要求 | ❌ 指导冰箱制冷系统维修 |

**遇到以下情况，按最坏情况处理：**

- 已发生明确的交叉污染（如生肉汁液溅到即食凉菜上）→ **该食物弃用**，不能靠冲洗或再加热挽救
- 家庭成员出现**腹泻、呕吐、发热**并怀疑某次进食 → 属健康问题，转医疗建议
- 供**婴幼儿、孕妇、65 岁以上老人、免疫力低下者、正在服药或化疗者**食用 → 门槛应更严

> **本技能不提供消毒方案。** 交叉污染一旦发生，正确做法是弃用，不是想办法「杀菌挽救」。

## 二、核心：操作顺序不能乱

**正确顺序：先洗菜 → 再切生肉 → 最后切熟食**

| 步骤 | 做法 | 常见错误 |
|---|---|---|
| **第一步：先洗菜切菜** | 先处理蔬菜与水果，洗净沥干后切分装盒 | **先切生肉再洗菜**，生肉汁液沾到水龙头与菜上 |
| **第二步：再切生肉生禽** | 生肉禽单独用刀与砧板，切完立即清洗器具与台面 | **用切过生肉的刀直接切熟食**或直接入口食品 |
| **第三步：最后切熟食** | 生熟彻底分开后，最后处理熟食、即食与水果 | **把生熟食放在同一块砧板上切** |

**为什么这个顺序重要**：蔬菜表面可能本来就带菌（尤其是叶菜），而生肉带来的污染是**新增且量更大的**。先把蔬菜处理好并分装，再处理生肉，最后处理熟食——这样即使前面有轻微污染，也不会传到即食环节。

## 三、砧板五色分区

| 颜色 | 用途 | 注意 |
|---|---|---|
| **红色** | 生肉与生禽 | 切生肉禽后的刀要专用，**不切其他** |
| **蓝色** | 生海鲜与水产 | 水产易交叉污染，且易流失汁液 |
| **绿色** | 蔬菜与水果 | 蔬菜应**先洗后切**；洗净即食的可不再加热 |
| **黄色** | 熟食与即食 | 切熟食即食的刀与砧板，**不碰生食** |
| **棕色** | 生食非肉类 | 如生豆类、生熟前处理 |

**没有分色砧板怎么办**：用三块不同颜色的砧板分区，或在砧板背面做永久标记区分。**关键是要有明确的物理区分，不要靠记忆。**

## 四、生熟分开的八项具体做法

1. 砧板**按颜色分区**：红色生肉禽、蓝色水产、绿色蔬果、黄色熟食即食
2. 生肉专用刀与砧板，**不切熟食也不切直接入口的蔬果**
3. 切生肉后**立即用皂液洗手**，再接触熟食与即食食品
4. 生禽生肉放入**底部或专用密闭容器**，滴液不得污染下层即食食品
5. 解冻水与血水**必须倒掉**，容器用后立即清洗
6. 生熟食**分格存放**，**生食在下、即食在上**
7. 凉拌菜与即食食品**制作完成后尽快食用**，不与生食交叉接触
8. 只有一把刀时，切完生肉必须**彻底冲洗并用皂液清洁刀面**

**第 8 条要展开说**：很多人以为「用冲一下」就算清洗了。实际上生肉表面的致病菌需要**流动水加皂液摩擦**才能去除，只用擦刀布擦干表面等于没洗，还会把污染转移到布上。

## 五、六种常见致病菌

| 致病菌 | 主要来源 | 易被忽视之处 |
|---|---|---|
| **沙门氏菌** | 生禽肉、生蛋、交叉污染的即食食品 | 污染的蛋与禽肉**外观与气味完全正常**，加热充分可杀灭，但生食阶段无任何提示 |
| **李斯特菌** | 冷藏即食食品、软奶酪、熟肉制品、即食熟食 | 可在**冷藏温度下缓慢增殖**，室温与冷藏初期感官均无异常 |
| **弯曲菌** | 生禽肉、未经巴氏杀菌的奶 | 生禽阶段无感官提示，加热可杀灭，但**仅冲洗不能杀灭** |
| **金黄色葡萄球菌** | 熟食、含奶油的点心、长时间室温放置的食物 | 耐热毒素**加热不能破坏**，且可在食物中生长并产毒 |
| **蜡样芽孢杆菌** | 米饭、面条等含淀粉食物的室温存放 | 部分毒素**加热不被破坏**，凉饭剩饭风险高于其他食物 |
| **大肠杆菌** | 未洗净的生蔬、污染的即食食品 | 生菜沙拉风险常被低估，**不经过加热即被食用** |

**两条要记住的规律**：

1. **感官正常 ≠ 安全**：沙门氏菌污染的蛋与禽肉外观气味完全正常；李斯特菌可在冷藏下增殖而毫无感官变化。
2. **冲洗不能替代加热**：弯曲菌等**仅用流动水冲洗不能杀灭**，必须加热到足够温度。

## 六、冷藏温度区间

| 部位 | 上限 | 说明 |
|---|---|---|
| **冷藏室** | 不高于 **4℃** | 细菌在 4 至 60℃ 区间会快速繁殖 |
| **冷冻室** | 不高于 **−18℃** | 冷冻效果随温度升高而下降 |

**4 至 60℃ 是细菌快速繁殖的危险区间**，冷藏的全部意义就是**把温度压到 4℃ 以下**，让这段时间缩短到尽可能短。

**长期温度不达标**会让即食食品与凉拌菜的风险显著上升，因为它们**不经过加热**。

## 七、高风险人群警示

| 人群 | 注意 |
|---|---|
| **婴幼儿** | 尤其 6 个月以下，肠道菌群尚未建立，感染后风险最高 |
| **孕妇** | 避免生食与未彻底加热的肉蛋水产 |
| **65 岁以上老人** | 免疫功能下降，且**味觉嗅觉减退导致感官判断本身不可靠** |
| **免疫力低下者** | 包括长期使用激素、化疗、器官移植后服药人群 |
| **正在服药者** | 部分药物与免疫功能相关，需更严格 |
| **慢性病患者** | 糖尿病等基础病会放大食源性疾病后果 |

**对高风险人群供餐的额外要求**：供餐给上述人群时，**生食一律避免**，凉拌菜与即食食品要格外注意制作环节的清洁，且**不采用交叉接触风险高的做法**。

---

## 八、明确禁止的操作（8 条）

1. 同一块砧板**先切生肉再切熟食**
2. 用切过生肉的刀切熟食或即食食品，**不清洗**
3. 切完生肉**不洗手**就接触熟食与即食食品
4. 生蔬与即食凉菜放在**同一容器或同一层冰箱**
5. 把已经切好的生肉与熟食**混装在一个保鲜盒**
6. 处理生肉后**不倒掉解冻水与血水**
7. 生禽与即食食品放在冰箱**同一层且不做隔离**
8. **只用擦刀布擦一下刀**就当作清洗完成

## 九、脚本用法

```bash
python scripts/cross_contamination_check.py --file kitchen.json --out 交叉污染核查.md
python scripts/cross_contamination_check.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--file` | 输入 JSON：`steps` 实际操作顺序、`practices` 八项检查、`fridge_temp` / `freezer_temp` 温度 |
| `--out` | 结果写入指定文件，默认写 `scripts/_last_result.txt` |
| `--format` | `md`（默认）或 `json` |
| `--selftest` | 运行内置自检（49 条断言，含 BOM 两条路径） |

输入 JSON 示例：

```json
{
  "steps": ["cut_raw_meat", "wash_veg", "cut_cooked"],
  "practices": {
    "board_separated": true,
    "knife_dedicated": false,
    "hand_washed": true,
    "store_order": true,
    "juice_discarded": false,
    "veg_washed_first": false,
    "cold_food_protected": true,
    "equipment_cleaned": true
  },
  "fridge_temp": 5.5,
  "freezer_temp": -20
}
```

可选步骤：`wash_veg`（洗菜）、`cut_raw_meat`（切生肉）、`cut_cooked`（切熟食），**按实际执行顺序填写**；可选检查项见脚本内 `ORDER_CHECKS` 表。

脚本输出：四级判定（存在交叉污染风险／存在薄弱环节／待确认／操作规范）、顺序判定与实际执行顺序、砧板分区、检查项逐项状态、温度核查、致病菌表、高风险人群、具体做法建议与禁止操作。

## 十、人工确认清单（这步不能省）

- [ ] 操作顺序为先洗菜 → 再切生肉 → 最后切熟食
- [ ] 砧板按颜色分区，生肉砧板未切熟食
- [ ] 处理生肉后已用皂液洗手
- [ ] 生食放下层，即食放上层，有滴液隔离
- [ ] 解冻水与血水已倒掉，容器已清洗
- [ ] 凉拌菜与即食食品未与生食交叉接触
- [ ] 冷藏不高于 4℃，冷冻不高于 −18℃

## 十一、最常见的坑

**坑一：先切完生肉，再回来洗菜。**
错误做法：把肉切了放一边，转身去洗菜切菜。正确做法：**先洗菜切菜分装，再切生肉，最后切熟食**。先切生肉再洗菜，生肉汁液会沾到水龙头、菜和手上。

**坑二：同一块砧板先切生肉再切黄瓜。**
错误做法：一块板子，切完生肉直接切凉拌黄瓜。正确做法：**砧板按颜色分区**，红色生肉、绿色蔬菜、黄色熟食即食。黄瓜是即食的，不经过加热。

**坑三：切完生肉不洗手。**
错误做法：切完肉，手在围裙上擦一下就去拿黄瓜。正确做法：**立即用皂液洗手**。生肉表面的致病菌要靠流动水加皂液摩擦才能去除，擦一下不算。

**坑四：只用擦刀布擦刀就当洗干净。**
错误做法：切完生肉，擦刀布擦一下刀就收起来。正确做法：这只做到了**把污染转移到布上**。刀必须**用流动水和皂液彻底清洗**。

**坑五：冰箱里生熟同层。**
错误做法：冷冻室生肉和冰淇淋放在一起。正确做法：**生食放下层或专用密闭容器**，滴液不得污染下层即食食品。生肉放上层，滴到冰淇淋上是直接的污染。

**坑六：生肉和熟食装同一个保鲜盒。**
错误做法：切好的生肉和熟菜一起装。正确做法：**分格存放，生食在下、即食在上**。混装等于主动制造交叉污染。

**坑七：解冻水不清洗直接用。**
错误做法：解冻盘的水倒掉了，盘不清洗。正确做法：**解冻盘必须单独使用，解冻液倒掉后立即清洗盘与台面**。盘上残留的血水就是污染源。

**坑八：觉得闻着没味就没事。**
错误做法：凉拌菜闻着没问题就给小孩吃。正确做法：**感官正常 ≠ 安全**。沙门氏菌污染的蛋与禽肉外观气味完全正常；李斯特菌可在冷藏下增殖而毫无感官变化。

**坑九：凉菜冲洗一下就当消毒了。**
错误做法：生菜洗一洗就拌。正确做法：**冲洗不能替代加热**，弯曲菌等仅用流动水冲洗不能杀灭。凉拌菜的风险在于它**不经过加热**，所以重点在制作环节的清洁与生熟分开，而不是事后补救。

**坑十：给老人小孩吃同样的菜。**
错误做法：一大盘凉拌肉丝，全家一起吃。正确做法：**婴幼儿、孕妇、65 岁以上老人、免疫力低下者**的门槛应更低，生食一律避免，凉拌菜制作环节的清洁要求更高。

**坑十一：冷藏温度没测过。**
错误做法：感觉挺冷的。正确做法：**冷藏不高于 4℃、冷冻不高于 −18℃**。4 至 60℃ 是细菌快速繁殖区间，冷藏的全部意义就是压低这段危险时间。温度计比感觉可靠。

**坑十二：已经污染了，冲一冲继续吃。**
错误做法：生肉汁液溅到凉菜上，冲一冲继续吃。正确做法：**已发生交叉污染的食物直接弃用**。本技能不提供消毒方案，污染一旦发生就不能靠补救挽救。
