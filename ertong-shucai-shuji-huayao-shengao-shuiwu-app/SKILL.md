# 个税APP专项附加扣除填报

个税APP专项附加扣除填报：个税APP里7项专项附加扣除每项都能省税，漏报一项一年可能多缴数千元，填错分摊比例还可能被稽核。

| 项目 | 扣除标准 | 关键规则 |
|---|---|---|
| 住房贷款利息 | 每月1000元，最长240个月 | 首套房贷，夫妻可选一方扣或各扣50% |
| 住房租金 | 直辖市/省会1500/月，市辖区户籍人口>100万的城市1100/月，其余800/月 | 与房贷利息不能同时扣 |
| 子女教育 | 每个子女每月2000元 | 3岁到博士，父母各扣50%或一方全扣 |
| 赡养老人 | 独生子女每月3000元；非独生子女分摊，每人≤1500元 | 被赡养人须年满60岁 |
| 3岁以下婴幼儿照护 | 每个婴幼儿每月2000元 | 分摊方式同子女教育 |
| 继续教育 | 学历教育每月400元；证书取得当年定额3600元 | 同一年度多项不叠加学历项 |
| 大病医疗 | 自付超1.5万的部分限额8万/年 | 只能在汇算时扣，平时预扣不能扣 |

算例（赡养老人分摊）：兄妹三人赡养72岁母亲，总额3000元/月，约定哥哥1000、两个妹妹各1000，都在限额1500内合规；若哥哥想扣2000则违规，年度汇算会被要求更正补税。房贷各扣50% vs 一方全扣算例：妻子税率45%、丈夫3%时，由妻子全扣每月省税450元，各扣50%只省约225+15元——高收入方全扣更划算。

话术模板：「个税APP→办税→专项附加扣除填报→选年度→填对应项目。夫妻之间先商量好谁扣多少，同一项目不能重复扣。租房和房贷只能选一个，别都填。」

## 红线
> ⚠️ 提醒：个税APP专项附加扣除填报涉及官方流程与政策，以上金额与规则以办理当日官方口径为准；凡要求转账、验证码、屏幕共享的“代办加速”均为诈骗，一律只走官方APP与政务窗口。
