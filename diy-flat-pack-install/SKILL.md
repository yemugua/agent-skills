# 板式家具自装：说明书读法与常见翻车修复

一句话：板式家具自装省300-800元安装费，但80%的返工来自三个错：五金装反、先拧死再对位、板材正反面搞错——照这份顺序原则装，一次成。

## 一、开工前清单

- 工具：十字/一字螺丝刀、卷尺、橡皮锤（没有可用手+布）、电动螺丝刀低档（新手建议手动，电钻一滑丝板就废）。
- 核对包装清单：板材张数、五金包清点——**缺件当场拍照联系商家**，装到一半发现缺螺丝最抓狂。
- 铺垫：纸箱拆开铺地上，防刮地板也防刮板材面。

## 二、安装顺序四原则

1. **先辨正反面**：贴封边/光滑面朝外，有字贴纸的面多为背面。装错拆返工的时间是正确安装的两倍。
2. **先松后紧**：所有螺丝先拧到7成，整体对位无误后统一拧紧——一上来拧死必然孔位错位。
3. **先框架后板件**：底板+侧板立起框架→背板（背板歪=整个柜歪，先量对角线相等再钉）→层板最后。
4. **偏心轮连接件（三合一）**：预埋螺母拧到位（露出约5mm）→偏心轮箭头**对准孔位**插入→顺时针锁死。箭头没对准孔就硬拧=偏心轮报废，这是最高频翻车。

## 三、常见翻车修复表

| 翻车 | 修复 |
|---|---|
| 螺丝滑丝拧不紧 | 孔里塞牙签/火柴棍+一滴木工白胶再拧 |
| 偏心轮装废 | 单独买同规格三合一（几毛钱一颗，网购次日达） |
| 柜体歪斜 | 松开背板全部螺丝→量两条对角线相等→重新固定 |
| 板材面划伤 | 蜡笔补漆棒（5-10元）对应色号涂抹擦平 |

## 四、算钱

双人床+衣柜+书桌三件自装省安装费约400-700元；工时约3-5小时；最大成本=一次错装返工1小时——先松后紧原则直接消灭这个成本。

## 红线
> ⚠️ 提醒：高柜（>1.5m）装完必须上墙固定件（包装内标配防倾倒件），有儿童家庭这条不是可选项；电动工具低速档+对准再启动，滑丝损伤不可修复。
