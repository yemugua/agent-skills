# 年终奖个税测算器｜两种计税方式对比与到手核算

# 年终奖个税测算器

一句话：年终奖有**单独计税**和**并入综合所得**两种方式，选错的代价是几百到上万元。本技能给你完整测算公式 + 判断规则 + 3 个真实案例。

## 一、两种方式怎么算

### 方式A：单独计税（多数人更优）
年终奖 ÷ 12 → 查月度税率表 → 应纳税 = 年终奖 × 税率 − 速算扣除数

**月度税率表（2024 年起延续）：**

| 应纳税所得额（月） | 税率 | 速算扣除数 |
|---|---|---|
| ≤3,000 | 3% | 0 |
| 3,000-12,000 | 10% | 210 |
| 12,000-25,000 | 20% | 1,410 |
| 25,000-35,000 | 25% | 2,660 |
| 35,000-55,000 | 30% | 4,410 |
| 55,000-80,000 | 35% | 7,160 |
| >80,000 | 45% | 15,160 |

### 方式B：并入综合所得
年终奖 + 全年工资薪金合并 → 按年度综合所得税率表（3%-45%）计算。

## 二、避坑红线 ⚠️（重点）

### 1. 年终奖的「税收悬崖」
年终奖多发 1 元，到手可能少几千元！临界点必须避开：

| 年终奖临界点 | 超过后到手反而减少 |
|---|---|
| 36,000 | 发 36,001 → 多缴 231.9 元 |
| 144,000 | 发 144,001 → 多缴 1,320 元 |
| 300,000 | 发 300,001 → 多缴 1,000 元 |
| 420,000 | 发 420,001 → 多缴 1,920 元 |
| 660,000 | 发 660,001 → 多缴 7,020 元 |
| 960,000 | 发 960,001 → 多缴 18,280 元 |

**行动**：HR 给你的年终奖数字若刚好压线（如 36,001），主动要求调整为 36,000。

### 2. 政策有效期
单独计税政策延至 **2027 年 12 月 31 日**。此前每年年底财政部会发文延续——别信「今年最后一次」的营销话术，以财政部官方通知为准。

## 三、判断规则（直接套用）

- **工资低、年终奖高**（如月薪 5k + 年终 10 万）→ 几乎必然选**单独计税**
- **工资高、年终奖低**（如月薪 3 万 + 年终 2 万，且有专项附加扣除多）→ 试算**并入**，往往更省
- **有专项附加扣除没用满**（房贷/赡养/子女教育合计 > 年度收入−6 万的空档）→ 并入可能更优
- **两处以上拿工资** → 只能一处选单独计税，另一处必须并入

**精算方法**：个税 APP →「收入纳税明细」→ 年度汇算时两种方式都试算（APP 内可切换预览），取退税多/补税少的方案。**这是唯一 100% 准确的方法**，上面的规则只是初判。

## 四、3 个真实案例

### 案例1：月薪 8,000，年终奖 50,000
- 单独计税：50,000÷12≈4,167 → 税率 10% → 税 = 50,000×10%−210 = **4,790**，到手 45,210
- 并入：年综合所得 = 96,000+50,000−60,000（减除）−专项扣除约 20,000 ≈ 66,000 → 税率 10% → 税约 4,490
- **结论：并入略优（省 300 元）**——工资低且扣除足时并入常常反超，验证「年终奖必选单独计税」是误区。

### 案例2：月薪 25,000，年终奖 80,000
- 单独计税：80,000÷12≈6,667 → 10% → 税 = 7,790，到手 72,210
- 并入：年所得 300,000+80,000−扣除约 80,000 ≈ 300,000 → 税率 20% 速算扣除 16,920 → 稅 ≈ 43,080；单独计税时综合部分税 ≈ 28,680+7,790 = 36,470
- **结论：单独计税省约 6,600 元。**

### 案例3：年终奖 36,100（踩崖）
- 单独计税：36,100×3% = 1,083 → 到手 35,017
- 调整为 36,000：税 = 1,080 → 到手 34,920？——错！
- 重算：36,100 ÷12 = 3,008.3 → 刚过 3,000 → 税率跳档 10%：税 = 36,100×10%−210 = **3,400**，到手 32,700
- **36,000：税 1,080，到手 34,920。多发 100 元少拿 2,220 元。**
