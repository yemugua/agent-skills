# 一句话：车险到期前怎么比价不吃亏：交强+商业各险种基准价、NCD无赔款优待系数、小刮蹭报险还是私了的临界点，一页算清。

## NCD系数表（商业险折扣）
| 上年出险次数 | NCD系数 | 大致折扣 |
|---|---|---|
| 0次（连续3年） | 0.5 | 约5折 |
| 0次（2年） | 0.6 | 6折 |
| 0次（1年） | 0.7 | 7折 |
| 1次（无责赔付除外） | 1.0 | 无折扣 |
| 2次 | 1.25 | 上浮25% |

## 临界点算例：该不该报险
商业险基准保费4000元：不出险下年省 4000×(1-0.7)=1200元起（多年无赔差距更大）。自己责任的小事故维修费≤1500元（含来年保费上浮风险）→ 私了更划算；>2000元或涉人伤 → 报险。无责被撞：走对方保险，不影响自己NCD。
算例：剐蹭补漆一面4S店600元、修理厂300元——300元私了远优于报险（省1200+来年上浮）。

## 比价动作清单
1. 到期前30天，同一家公司APP+2家竞品报价单截图对比（同险种同保额才可比）
2. 报价核对三项：NCD系数、车型系数、驾驶人也系数（家人有记录会拉高）
3. 返现赠品折算进总价再比，不单看保费数字

## 红线
> 提醒：报价单不写NCD系数的多是虚报——要求书面注明；出险后48小时内不报案部分公司拒赔；“互碰自赔”仅适用于双方都有责且无人伤，别被对方忽悠私了后追偿无门。
