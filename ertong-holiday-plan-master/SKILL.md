# 儿童假期总规划：一张表管住作业/作息/屏幕时间

一句话：假期崩坏路径固定——前10天放纵、中间赶作业、最后熬夜补——用「三段式+倒排公式+契约」三件工具，一张表管住全程。

## 一、三段式框架（按假期长度等比缩放）

| 段 | 占比 | 目标 |
|---|---|---|
| 缓冲段（前10%） | 彻底放松2-3天+适应期 | 旅行/探亲放这段 |
| 主体段（中间70%） | 固定作息+每日作业块 | 见下方作息表 |
| 收心段（最后20%） | 作业查漏+调回上学作息 | 每天提前15分钟入睡 |

## 二、主体段每日作息表（可直接抄）

| 时段 | 内容 |
|---|---|
| 8:00-8:30 | 起床早餐（不睡懒觉是底线，比上学晚≤1小时） |
| 9:00-11:00 | 作业块①（最难科目放上午） |
| 11:00-12:00 | 自由活动/家务 |
| 午休+下午 | 兴趣班/运动/户外1小时（户外是防近视硬指标） |
| 19:30-20:30 | 阅读或作业块② |
| 21:30前 | 小学生入睡（假期不熬夜） |

## 三、作业倒排公式

**每日作业量 = 总量 ÷ 主体段天数 × 1.3**（×1.3是缓冲系数，留给生病/出游日）。
例：寒假作业本40页+3篇作文，主体段20天 → 每日2页+每4天1篇作文。前紧后松，收心段只查漏。

## 四、屏幕时间契约（直接抄）

> 本人承诺每天屏幕时间共___分钟（可分次），完成当日作业块后使用；连续违规1天，次日扣除双倍。家长同样遵守（陪伴时不刷手机）。
> 签名：孩子___ 家长___ 日期___

契约要点：数字写死（"少玩点"无效）、家长同步受限（否则立即失效）、写明扣除规则而非奖励规则（扣除比奖励更能约束）。

## 红线
> ⚠️ 提醒：作息落差是假期最大杀手——起床时间比上学晚不超过1小时；作业倒排要留×1.3缓冲，排满即崩；屏幕契约必须家长同签，单方约束的契约撑不过一周。
