# 秘匣 Mixia

只在本机运行的加密保险库。把图片、视频、文档拖进去，它们以密文存在一个普通文件夹里；
没有云、没有账号、不联网，忘记密码就永久打不开。

> 用之前请先读 [SECURITY.md](SECURITY.md)：**它防的是"文件离开这台电脑之后"，
> 不防"这台电脑正在被人用"。**

## 它是什么

一个保险库 = 一个普通文件夹。你可以整份复制、改名、放 U 盘、放移动硬盘。

```
我的保险库/
├── vault.json      # 明文：KDF 参数 + 被密码派生的密钥包装起来的主密钥
├── index.enc       # 加密索引：文件名、类型、大小（所以文件名也是密文）
├── blobs/<uuid>.bin  # 每个文件独立密钥、1 MiB 分块的 XChaCha20-Poly1305 密文
└── thumbs/<uuid>.bin # 图片缩略图密文（用于库内预览）
```

## 为什么做这个

- 桌面端能同时做到**中文、免安装、真零网络、库内直接看图看视频、不用挂载虚拟盘符**的开源工具，目前没有。
- VeraCrypt / Cryptomator 在密码学上更成熟，但要理解卷、挂载、盘符；对"只想把照片收起来"的人是门槛。
- 国产同类多是面向企业的"透明加密"，闭源、收费、装驱动。

秘匣走另一条路：**不接管你的文件系统，只做一层你能看懂的加密文件夹**，
并且把格式规范完整公开，保证你随时能走。

## 功能

- 新建 / 打开保险库，密码本地派生密钥（Argon2id 64 MiB × 3 轮 × 4 并行）
- 拖拽导入单个文件、多个文件、整个文件夹（递归，保留「所选文件夹名 + 相对路径」），带实时进度与取消
- 导入的文件夹在库里就是一个**黄色文件夹方块**，和文件卡片排在同一张网格里、文件夹排最前，
  方块上显示文件数与合计大小；**点方块走进这一层**，里面的子文件夹仍然是方块，不会被移出来，
  顶部一条面包屑点哪段回哪段（也有「上一级」按钮和 `Esc`）；
  方块上的「删除文件夹」把这一整枝（连子文件夹）一次删掉（只删库里的密文，磁盘上你自己的文件夹不动）；
  单个导入的文件直接是卡片；图片缩略图按需解密，可按文件名或目录名搜索（命中标出它在哪个文件夹）
- 打开（交给系统默认程序）、导出（选保存位置）、全部导出（一次解出一整个库，按原目录结构还原）、重命名、删除
- 批量删除：卡片和文件夹方块左上角勾选（勾方块 = 连子文件夹整批选中），工具栏「全选」按当前这一层算，
  底部选择条显示「已选 N 个 · 合计大小」，一次删完；`Esc` 或「取消选择」清空勾选
- 删除原件：导入完成会问一次；工具栏「清理原件」随时选个文件夹，把已经安全进库的原件一次挑出来删。
  两种都默认保留，勾选后仍逐个先验证库内密文能解开才删
- 修改密码：只重新包装主密钥，**不重新加密文件**，瞬间完成
- 无操作 10 分钟自动锁定；`Ctrl+L` 立即锁定；`Esc` 先取消勾选、没勾选时退回上一层文件夹；退出时删除解密临时目录
- 暖白浅色（默认，首次运行跟随系统）与深色两套配色，右上角一键切换，选择只记在本机
- 命令行工具 `mixia-cli`：`create` / `import` / `info` / `list` / `verify` / `export` / `extract` / `set-password`

## 快速开始

1. 到 [Releases](../../releases) 下载 zip，解压到任意目录，运行 `mixia.exe`
   （首次运行 Windows 可能提示"未知发布者"——这是个人开发的常态，见下文）
2. 点"新建保险库" → 选一个**干净的文件夹**（推荐单独建，例如 `D:\秘匣`；
   已经放着照片文档的文件夹也能用，那些文件照常可以加密进去）→
   设一个长口令（≥8 位，建议 15 位以上）→ 勾选风险确认 → 创建
3. 把文件拖进窗口。确认能正常打开之后，**再删除原始文件**
4. 定期做两件事：整份复制保险库文件夹（备份）、跑一次 `mixia-cli verify`（体检）

### 下载后请校验

```powershell
Get-FileHash .\mixia-v0.1.0-windows-x64.zip -Algorithm SHA256
# 与 Release 页面里 SHA256SUMS.txt 的对应行比对
```

### 关于"未知发布者"提示

本项目是个人开发、免费、GPL-3.0 开源，没有购买代码签名证书（约 ¥1.5k–3k/年），
所以 SmartScreen 会拦一次，部分杀毒软件也可能误报（加密 + 批量读写文件的特征像勒索软件）。
可以做的验证：

- 源码在本仓库，可自行构建比对
- Release 附 SHA256 校验和
- 用防火墙阻断该进程，功能完全正常 → 证明它不联网

## 构建

需要 Rust（MSVC 工具链）与 WebView2（Win10/11 一般自带）。

```bash
cd src-tauri
cargo build --release        # 产物：target/release/mixia.exe 与 mixia-cli.exe
cargo test                   # 18 项：分块往返、篡改/截断拒绝、改密、生命周期、verify、
                             # 目录树还原与越界路径清洗、保险库自身条目的识别（含 Windows
                             # canonical 路径），外加 2 项 mixia-cli 端到端契约测试
                             # （起真进程解整个库并逐字节比对）
```

中国大陆网络慢的话，把 `.cargo/config.toml.example` 复制成 `.cargo/config.toml`
即可改用 rsproxy 镜像（这份配置只在本机生效，不进仓库，CI 用官方 crates.io）。

界面是 `ui/` 下的原生 HTML/CSS/JS，无前端构建步骤、无 npm 依赖，
由 Tauri 在编译时嵌入。想改样式直接改这三个文件后重新 `cargo build`。

## 数据安全性从哪来

- 每种用途独立密钥：KEK（密码派生）→ MK（主密钥）→ 每个文件一把 FK
- 密钥层级与 AAD 绑定规则见 [docs/FORMAT.md](docs/FORMAT.md)
- 篡改、重排序、截断、跨文件搬块，全部在 AEAD 认证下失败
- 原子写 + 解锁时清理孤立密文，写入中断不会留下半截索引
- 密码不落盘；配置文件里只记最后一次打开的保险库路径

**未经第三方审计。** 密码学原语用的是广泛使用的 RustCrypto 实现，
格式与密钥层级是公开可审的，但"可审计"不等于"已验证"。

## 常见问题

**忘记密码？** 没有任何找回手段。Argon2 参数就是为了让离线爆破尽可能贵，
但足够强的密码 + 没有备份 = 数据永久丢失，这是设计目标而不是缺陷。

**能防住正在用我电脑的人吗？** 不能。解锁期间密钥在内存里。离开前 `Ctrl+L` 锁定，
或者用 BitLocker + 系统登录密码配合。

**能放多大文件？** 分块流式加解密，内存占用与文件大小无关（固定 1 MiB 一块）。
自动化测试覆盖了空文件、非整块长度（2 MiB + 123 B）与整块倍数（2 MiB）这些边界；
更大的文件只受磁盘速度限制，尚未做压力测试。

**支持 macOS / Linux 吗？** 目前没有。Tauri 本身跨平台，但只在 Windows 上构建和测试过。

**会不会以后收费 / 加云同步？** 不会加云同步——"不联网"是这个工具唯一的卖点，
破坏它就没有存在意义了。

**保险库文件夹能改名或移动吗？** 能。它不依赖路径，改名、换盘、换电脑都不影响。
