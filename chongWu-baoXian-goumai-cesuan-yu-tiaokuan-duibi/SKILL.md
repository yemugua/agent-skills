# 宠物保险购买测算与条款对比

一句话：宠物保险的账=「年保费 × 使用概率 vs 一次大病账单」——健康幼猫幼犬的性价比存疑，老年/纯种/易病体质是真正该买的人群。本技能给测算框架 + 条款避坑表 + 理赔要点。

## 一、先测算：你该不该买

**宠物医疗的真实风险账**（常见大病支出）：
| 疾病 | 典型费用 | 高发期 |
|---|---|---|
| 猫传腹 | 3,000-15,000 | 1-2 岁幼猫 |
| 犬细小/猫瘟 | 2,000-8,000 | 幼年疫苗前 |
| 骨折/内固定 | 3,000-10,000 | 全龄（意外） |
| 慢性肾衰（猫） | 年 1-3 万持续 | 8 岁+ |
| 尿闭（公猫） | 2,000-6,000 | 2-7 岁、饮水少 |
| 恶性肿瘤 | 1-5 万 | 7 岁+ |

**决策框架**：
| 你的情况 | 建议 |
|---|---|
| 幼猫/公猫（尿闭高危）/纯种（遗传病高发） | **值得买**——高发概率覆盖保费 |
| 健康田园猫/犬、2-5 岁、科学喂养 | 可不买——自留风险金（每月存 100）更灵活 |
| 7 岁+老年 | **买**——但注意投保年龄上限（多数 8-10 岁截止）与既往症除外 |
| 多宠家庭 | 每只单独测算；多宠折扣常见 |

**快速算例**：2 岁公猫，保费 480 元/年（报销 60%、单次免赔 200）
- 尿闭一次 4,000：报 (4,000−200)×60% = 2,280——**4.7 倍回本**
- 若三年平安：支出 1,440 vs 大病概率×费用——公猫尿闭终身发生率约 3-7%，期望值算下来勉强持平 → 看你对 4,000 元突发支出的承受力（买的其实是「安全感」）。

## 二、条款对比的六看（避坑表）

| 看什么 | 坑点 |
|---|---|
| 1. 既往症除外 | 投保前的病/疑似症状全除外——**健康时尽早买**（等病了买不到） |
| 2. 等待期 | 30 天（疾病）/10 天（意外）——等待期内生病不赔；续保无等待期 |
| 3. 免赔额与报销比例 | 单次免赔 200/300 + 60% 报销是主流；「0 免赔 90%」的保费翻倍——自己算 |
| 4. 定点医院限制 | 部分产品要求合作医院（外院打折报销）——先查你常去医院在不在名单 |
| 5. 单次/年度限额 | 单次限额（常见 5,000-10,000）与年度限额——大病覆盖能力看年度上限 |
| 6. 续保条款 | **理赔后是否拒保/单独涨价**——「保证续保」条款是长期价值的关键（多数产品不保证！） |

## 三、理赔实操要点

- 保留：病历/发票/费用清单（同医疗险标准件）——**就诊时说明走保险，让医院出完整明细**
- 部分产品支持直赔（合作医院出院即结）——直赔产品优先
- 理赔申请：APP 上传材料 → 3-15 日到账
- 病历主诉注意：写「呕吐待查」优于写「疑似传腹」（未确诊的猜测词可能触发既往症争议）

## 四、产品类型速览

- **医疗报销型**（主流）：门诊+住院按比例——大病主力
- **意外型**：骨折/创伤——年轻活泼狗值得
- **责任险**（咬人赔第三者）：遛大型犬的城市家庭小成本必备（年 100-300）
- 组合套（医疗+意外+责任）：多宠/家庭型选择

## 五、避坑红线 ⚠️

- ❌ 病了才想买——等待期+既往症除外会让你买了个寂寞
- ❌ 只看保费便宜——免赔 500+报销 50% 的「便宜」在大病时形同虚设
- ❌ 忽视「不保证续保」——理赔一次后被拒保的产品 = 一次性消耗品
- ❌ 把保险当替代疫苗驱虫——预防医学（疫苗/驱虫/绝育）是回报率最高的医疗支出

## 红线
> ⚠️ 提醒：宠物保险的公式——「高发体质才值得买、六看条款（等待期/免赔/续保/定点）、健康时早买、理赔留完整明细、保证续保是稀缺品、预防优于保险」。宠物保险买的是「大病突袭时的选择权」——算得清的人，花小钱拿回决定权；算不清的人，关键时刻只剩「治还是不治」的痛。
