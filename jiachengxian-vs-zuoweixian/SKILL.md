给"车里坐的人"上保障有两种东西：随车保的**车上人员责任险**（责任险）和**驾乘险**（意外险），名字像但赔付逻辑完全不同——买错形态，换车、开朋友车、坐别人车时都可能不赔。

## 一、两种产品核心差异表

| 维度 | 车上人员责任险（司机+乘客座位险） | 驾乘险（意外险形态） |
|---|---|---|
| 保险性质 | 车险三者之一，跟车 | 商业意外险，分"跟人"或"跟车"两种 |
| 保障对象 | 投保车辆上的座位人员 | 被保人本人（跟人版）或指定车上的所有人（跟车版） |
| 按责赔付 | **看事故责任比例**：你全责时按比例打折赔 | **不问责任**，符合意外定义即赔 |
| 保额参考 | 每座1万/5万/10万为主，常被销售人员压到1万 | 每座30万-100万常见 |
| 保费参考 | 每座10万档约100-300元/年（5座） | 跟车版每座50万档约100-200元/年 |
| 换车/借车 | 只保投保的这辆车 | 跟人版：坐任何车都保；跟车版：只保登记车辆 |
| 医疗责任 | 医疗费限额通常另计且低（如每座1万） | 意外医疗常含1-5万，可含自费药 |

## 二、算例：同样的钱，赔出来的差距

6座家用车，全家5人自驾出行出事故，全车人重伤，医疗费每人 8 万元，你全责：

- **只买座位险（每座保额1万、医疗1万）**：你是全责本应全赔，但限额封顶——每座最多赔1万，自担 7万×5人 = **35万元缺口**。
- **跟车驾乘险（每人50万+意外医疗2万含自费）**：不按责任比例，每人按伤残等级/医疗实付赔付，医疗 2 万内基本覆盖，伤残部分另按比例赔，**缺口收窄到几千元级**。
- 结论：座位险1万档基本是"安慰性保额"，年省的几十元保费换来的是致命缺口；要么拉到每座10万+，要么直接配跟车驾乘险，两者不是非此即彼，但至少要有一个高保额形态。

## 三、一分钟判定你该买哪种

1. 开自己的车、家人常坐 → **跟车驾乘险**（保整辆车，保费摊到每座最划算）。
2. 经常换车、坐网约车/朋友车/租车 → **跟人驾乘险**（综合交通意外险，人走到哪保到哪）。
3. 跑网约车/货运载客 → 座位险+单独职业意外险（营运状态商业意外险多免责，驾乘险条款要逐条查"营运车辆除外责任"）。
4. 老座位险已买1万档 → 不是退掉，是**补一份驾乘险把保额垫到50万档**。

## 四、投保必问三句话

- "这份驾乘险是跟人还是跟车？换车/坐别人车赔不赔？"
- "营运（网约车）状态下算不算除外责任？"
- "意外医疗是否含自费药、有没有免赔额和社保先报的前置要求？"

## 红线

> ⚠️ 提醒：① 座位险按事故责任比例赔付——对方全责时由对方交强险/三者险赔你车上的人，你自己的座位险根本不动用，别被"全险=人保了"误导；② 驾乘险跟车版一般按"核定座位数"承保，超员（5座车坐6人）第6人不赔，跟人版也存在"未开启营运平台记录才赔"的条款差异，投保时把保单条款第X页除外责任拍照留存；③ 意外险伤残按1-10级比例赔付（10级赔保额10%），不是"断了手指就赔全额"，理赔预期先对表。
