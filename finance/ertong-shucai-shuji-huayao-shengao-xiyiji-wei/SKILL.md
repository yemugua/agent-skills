# 洗衣机维修与换机决策：300块修还是2000块换，一次算清

一句话点题：洗衣机维修费超过新机价35%就该换，低于这个数先按报价表压价——本文给自查清单、报价区间和临界公式。

## 常见故障先自查（0成本排除30%的假故障）

| 现象 | 先自查 | 排除后再叫修 |
|---|---|---|
| 不脱水/甩干无力 | 盖开关未扣好、衣物偏载、排水管弯折 | 若仍不行→离合器/电机 |
| 不进水 | 水龙头未开、进水阀滤网堵（拧下冲洗） | 进水电磁阀，60-120元 |
| E1/E2报代码 | 排水超时：清排水泵过滤器（右下角小门，逆时针拧开） | 排水泵90-150元 |
| 剧烈撞桶 | 脚不平（调平脚）、单件大件失衡 | 减震吊杆/轴承 |
| 有异味发黑 | 90℃空转+槽清洁剂跑一遍 | 拆洗服务150-250元 |

## 维修合理报价区间（2025-2026主流滚筒/波轮）

| 项目 | 配件+人工合理价 | 虚高信号 |
|---|---|---|
| 排水泵更换 | 90-150元 | >250元 |
| 进水阀 | 60-120元 | >200元 |
| 皮带 | 50-90元 | >150元 |
| 水位传感器 | 80-130元 | >220元 |
| 减震器（一对） | 120-220元 | >350元 |
| 电脑板 | 200-400元 | 接近新机价 |
| 轴承拆装 | 300-500元 | 直接换机 |

上门费/开机费30-60元，修好后应折抵维修费；拒绝"检测费单独收100+且不修不退"。

## 修vs换临界公式

**维修费 ≤ 新机价×35% 且机龄<6年 → 修；否则换。**
算例：新一级能效10kg滚筒国补后到手约1600-2200元。师傅报"电脑板350+上门50=400元"，机龄5年：400/1800≈22% → 修。报"轴承+拆装480元"，机龄7年：480/1800≈27%但拆装伤箱体、二次故障率高 → 建议换。机龄>8年的任何>300元维修一律倾向换新（叠加以旧换新补贴，旧机折抵50-200元）。

## 比价话术（直接抄）

> "师傅，机型XX滚筒报代码E1。你们上门费多少、修不好退不退？换排水泵总价含配件人工不超150元能做吗？配件我要拍下旧件，包装修6个月。"
- 同城报2家（品牌售后400电话/平台服务/本地老店），原厂配件与通用件价差30%-50%，过保机器可要求报价两档。
- 保修必须留字据（微信文字确认即可）："换件保6个月，同故障免费上门"。

## 红线

> ⚠️ 提醒：①师傅说"主板烧了/要换电脑板"是最高频加价话术，先要求拍电脑板实物照片并报换板总价，多个报价对比再决定；②只报总价不肯拆分配件/人工的报价不可信；③修后旧件带走留存，防"以修代换"拿旧件充新；④机龄>8年、维修>300元的项目，算完临界公式再掏钱，别为老机器续命。
