体检的钱花在哪：基础套餐只需固定几项，加项按**年龄+家族史+已有异常**三条件决策；本条给出清单、加项决策表与费用算例，防两类错误——漏掉真正该查的、买一堆无效豪华项目。

## 一、基础套餐（成年人年度固定项，社区/公立医院约300-500元）

| 项目 | 针对什么 | 备注 |
|---|---|---|
| 血常规+肝肾功能+空腹血糖 | 贫血/肝肾功能/糖尿病筛查 | 必查 |
| 血脂四项 | 心血管风险 | 必查 |
| 尿常规 | 肾病/糖尿病线索 | 必查，最便宜的高性价比项 |
| 腹部超声（肝胆胰脾肾） | 脂肪肝/结石/占位 | 必查 |
| 心电图 | 心律失常/心肌缺血线索 | 必查 |
| 血压+身高体重腰围 | 代谢综合征 | 必查 |
| 胸部低剂量CT（LDCT） | 肺癌筛查 | 40岁以上或吸烟者年度；40岁以下非吸烟不必年年做 |
| 甲状腺超声 | 结节检出 | 高发且便宜（约100-150元），建议纳入 |

## 二、加项决策表（按三条件勾选）

| 你符合的条件 | 该加的项 | 自费参考价 |
|---|---|---|
| 年龄≥45岁（无论男女） | 胃肠镜（胃镜+肠镜）；首次肠镜正常可5-10年一次 | 无痛胃肠镜约1500-3000元 |
| 女性≥25岁 | 宫颈TCT+HPV（每3年一次联合筛查） | 约300-500元 |
| 女性≥40岁 | 乳腺超声（或钼靶）年度 | 超声约150元 |
| 直系亲属大肠癌/胃癌史 | 胃肠镜提前到40岁，或比亲属发病年龄早10年 | 同上 |
| 直系亲属乳腺癌史 | 乳腺检查提前到35岁 | 同上 |
| 三高/肥胖/BMI≥28 | 颈动脉超声+同型半胱氨酸 | 约200元 |
| 长期饮酒/乙肝携带 | 肝脏弹性检测+AFP | 约200-400元 |
| 长期熬夜用眼/高度近视 | 眼底照相+眼压 | 约100元 |

**费用算例**：35岁无家族史不吸烟者 = 基础套餐400元+甲状腺超声120元 ≈ **520元**。45岁吸烟+父亲肠癌史者 = 基础400+LDCT 300（部分套餐含）+无痛胃肠镜2000+甲状腺120 ≈ **2800元**——差价花在胃肠镜上完全值，大肠癌早筛的金标准是肠镜，不是肿瘤标志物。

**无效项目黑名单**（不推荐自费加）：肿瘤标志物全套（健康人体检阳性预测值低，异常徒增焦虑，且阴性不代表没事）；「全身PET-CT」筛查（数千元，健康人群筛查无证据支持）；基因检测「癌症风险套餐」；微量元素检测。这四类加起来常占套餐升级价的50%以上，砍掉它们就是最大的省钱点。

## 三、体检流程算例与省钱路径

- 公立医院体检中心 vs 商业机构：同项目公立更便宜且报告异常可直接转专科挂号；商业机构优势是预约灵活。预算3000元内建议公立。
- 单位体检已含基础项时，个人只补「决策表」里自己命中的加项——例：单位套餐已含腹部超声，你只需自费加甲状腺超声120元。
- 检查准备：肠镜前肠道准备、妇科避开经期、血脂血糖须空腹8小时——准备不合规会导致复测，一次复测=双倍费用。

## 四、报告红线（拿到报告必须做的事）

- 报告的「异常项」逐条处理：结节/息肉/囊肿按报告建议复查间隔回访，**过期不复查是体检最大浪费**——息肉3-5年可癌变，漏一次随访等于没查。
- 出现以下关键词立即专科就诊而非等年度复查：报告提示「可疑恶性/占位待查」、血便黑便、不明原因体重下降>5%、ECG提示明显缺血。
- 别用「指标比去年好一点」自我解释持续异常：同一异常连续2年存在，即使轻度也要专科确认一次。

## 红线

> ⚠️ 提醒：①45岁前完成一次胃肠镜（有家族史提前到40岁或比亲属发病年龄早10年），这是所有体检项里挽救生命证据最强的；②肿瘤标志物全套/PET-CT筛查/基因风险套餐对健康人群性价比极低，不建议自费；③报告异常必须按建议间隔复查随访，异常连续2年存在要专科确认，不要只等下一年体检。
