# 异地就医儿童备案与直结：先备案再住院，报销差一倍不是夸张

一句话点题：孩子跨市/跨省看病，是否提前在国家医保 App 备案，直接决定出院时是「刷卡直结」还是「全额垫付回跑报销」。

## 一、备案流程（30 分钟内可完成）

1. 「国家医保服务平台」App → 异地备案 → 为儿童做「亲情账户」绑定（需儿童参保地信息+户口页照片）。
2. 备案类型选「跨省异地就医直接结算备案」；就医地选实际城市，不指定具体医院（备案到城市，当地所有联网医院通用）。
3. 备案多数即时生效或 T+1 生效，急诊住院可在入院后补备案（但补备前的费用部分城市不直结）。
4. 住院时出示儿童医保码（家长手机里的亲情账户码）即可直结；门诊统筹直结覆盖范围各省不同，先问医院医保办。

## 二、直结 vs 自费垫付算例（住院 1 万元）

- 直结：出院当场按参保地政策结算。设医保内 9000 元、三级医院比例 60%、起付线 1000 元：(9000−1000)×60% = 5400 元报销，当场只付 4600 元。
- 未备案自费垫付：先付 1 万元，回参保地按「转外就医未备案」政策，报销比例通常下浮 10–20 个百分点甚至不予受理：(9000−1000)×45% = 4050 元，还多跑一趟报销窗口、等 1–3 个月到账——同样一次住院，多花 1350 元+来回跑。
- 垫付报销材料：发票原件、费用明细总清单、出院小结、备案表/急诊证明，缺一项退件重交。

## 三、常见坑（照抄避免）

1. 只备案到「医院级别」没选「就医地」→ 直结失败；备案就医地必须写孩子实际住院的城市。
2. 备案「住院」没勾「普通门诊」→ 门诊费用不能直结，需要门诊直结的在备案类型里同时勾选。
3. 自费药/丙类项目无论是否备案都不报，提前问医生哪些项目是自费的，可以选医保内替代。
4. 回参保地手工报销要在费用发生后规定时限内（多为当年或次年 3 月前）申请，过期作废。
