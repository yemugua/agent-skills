# 笔记本选型与内存硬盘升级

一句话点题：学习本优先买「可升级」机型，内存硬盘官方升配往往贵一倍以上，自己加条最划算。

## 工具表

| 用途 | 配置底线 | 参考价 |
|---|---|---|
| 网课+文档 | 核显 / 16G / 512G | 3499（锐龙 R5/酷睿 i5） |
| 编程/轻度剪辑 | 核显 / 16G / 1TB | 4499 |
| 游戏/重度剪辑 | 独显 RTX 4050 级 / 16G / 512G | 5999 |

升级成本算例（同机型对比）：
- 官方升 16G→32G：加价 800-1000 元；自购 DDR5 16G 内存条 + 拆机加装：约 **350 元**（含工具），省 450-650 元。
- 官方升 512G→1TB：加价 400-500 元；自购 1TB NVMe 固态约 **450 元**——官方与自购接近，但要迁系统，不如出厂 1TB。

## 精确算例

方案 A：出厂 16G/1TB = 4499 元。
方案 B：出厂 16G/512G = 4199 元，两年后加 450 元固态 = 4649 元。
结论：若两年内确实要 1TB 选 A；不确定就选 B，两年折现后 B 仍可能便宜 300 元左右。**买前必查：内存是否板载（板载不可升）**，商品页问客服一句："内存是插槽还是板载焊死？有几个插槽？"

## 可复制话术

> "这台内存板载还是插槽？二手拆封是否影响保修？我要确认能自己加装内存再下单。"

## 红线

| 红线 | 后果 |
|---|---|
| 板载内存机型规划"以后升级" | 无法升级 |
| 拆机不去售后报备贴标签 | 部分品牌拒保 |
| 只看"标压"不看散热 | 高负载降频 |

> ⚠️ 提醒：加装内存/硬盘前先确认品牌保修政策（部分品牌拆机不拒保，如联想/华为明确不拒保；杂牌渠道机慎拆）。
