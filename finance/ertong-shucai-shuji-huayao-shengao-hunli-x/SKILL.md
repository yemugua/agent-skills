# 婚宴烟酒糖采购：先算量再砍价，余量能退一半

婚宴烟酒糖是婚宴三大隐形支出之一，20桌酒水烟糖轻松花到2万+。采购逻辑只有三步：按桌型算量→渠道比价→余量可退渠道买。

## 用量公式（每桌）

- 白酒：每桌1瓶（500ml，8-10人分）；不喝白酒的年轻桌可减半，按实际宾客年龄结构调。
- 红酒/饮料：每桌2瓶（红酒1+饮料1），饮料备橙汁/雪碧各半。
- 啤酒：夏季户外宴每桌加4-6瓶，室内宴会厅可不备。
- 喜烟：每桌1包+签到台2条备用，抽烟率约30%-40%，20桌买12-14包+2条即可，别按桌数满配。
- 喜糖：宾客数×1.2盒（含未到席补发+伴手礼合用），每盒8-10颗约12-15元。

## 20桌算例（500元/桌预算线）

| 品项 | 数量 | 渠道 | 单价 | 小计 |
|---|---|---|---|---|
| 白酒（剑南春级） | 20瓶 | 京东自营大促/烟酒批发 | 420 | 8400 |
| 红酒（张裕级） | 20瓶 | 批发商整箱 | 68 | 1360 |
| 饮料 | 40瓶 | 山姆/批发市场整箱 | 5 | 200 |
| 喜烟（中华软级） | 14包+2条 | 烟草专卖店 | 65/包 | 2200 |
| 喜糖 | 240盒 | 1688定制糖盒 | 13 | 3120 |
| 合计 | | | | **15280** |

比价差价：同款白酒，烟酒店零售 vs 京东大促 vs 烟酒批发商整箱，差价可达8%-15%。20瓶×420元按批发价砍10%省840元。喜糖1688定制比线下婚庆公司代购便宜40%以上，但起订量通常100盒起。

## 余量退换策略

1. 下单前问死一句：**"未开封整箱能否退，退换截止日期是婚礼前还是后几天？"** 京东自营7天无理由+整箱白酒可退；批发商口头承诺不算，写在单据上。
2. 按预估到席率85%备货，多出的整箱酒退回=回收现金；散包烟糖退不了，宁少勿多。
3. 酒店禁带酒水的要提前确认开瓶费：有的酒店收50-100元/桌开瓶费，20桌就是1000-2000元，比自带省的差价还多，签约宴会厅时把"免开瓶费"写进合同。

## 红线

| 坑 | 表现 | 应对 |
|---|---|---|
| 假酒风险 | 名酒从非官方渠道低价购入 | 大牌白酒只走自营/专卖店，要发票 |
| 满配喜烟 | 按20桌满配买20包 | 按抽烟率×0.35配，省600-1000元 |
| 开瓶费盲区 | 宴会厅合同默认可收 | 签约前问清并写明"自带酒水免开瓶费" |
| 余量不退 | 批发商口头说能退 | 单据注明退换条款再付款 |

> ⚠️ 提醒：所有采购留发票和单据，假酒流出宴席是食品安全事故；按85%到席率备货+可退渠道，实际支出比满配省15%-20%。
