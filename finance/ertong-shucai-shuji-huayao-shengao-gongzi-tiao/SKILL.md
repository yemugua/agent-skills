# 工资条与个税专项核对：拿到手先对三笔账，错一个月追回一个月

多数人只看"到手多少"，不看扣得对不对。社保基数、专项附加扣除、累计预扣跳档是最常见的三处错。本篇给构成拆解、核对公式和算例，每月 5 分钟对完。

## 一、工资条构成拆解

```
应发工资 = 基本工资 + 岗位/绩效 + 加班费 + 补贴
扣款项 = 五险一金（个人部分）+ 个人所得税 + 其他（考勤扣款/借款等）
到手 = 应发 − 扣款项
```

## 二、核对公式与算例（月薪 15,000，一线城市参考）

**① 五险一金（个人缴纳比例参考：养老 8%、医疗 2%、失业 0.5%、公积金 5%-12%）**
- 按全额 15,000、公积金 12%：15,000 × (8% + 2% + 0.5% + 12%) = 15,000 × 22.5% = **3,375**。
- 常见错误：公司按最低基数（如 6,000）缴 → 月省 6,000 × 22.5% − 但你的公积金账户每月少 (15,000−6,000) × 12% = **1,080 元**，一年 12,960，且养老金待遇降低。工资条上"社保基数"一栏必须与应发工资一致（上限/下限封顶除外）。

**② 个税（累计预扣法）**
- 累计应纳税所得额 = 累计应发 − 累计五险一金（个人）− 5,000 × 月数 − 累计专项附加扣除
- 算例（3 月，专项附加扣除房租 1,500/月）：
  - 累计应发 45,000 − 五险一金 10,125 − 5,000 × 3 − 1,500 × 3 = 21,375
  - 税率 3% 档（≤36,000）→ 累计税 641.25，本月扣 = 641.25 − 前两月已扣。
- **跳档提示**：累计应纳税所得额超 36,000 后税率升 10%，某月工资条个税突然翻倍不是发错，是跳档——提前知道就不慌。

**③ 专项附加扣除自查清单（漏一项 = 每月白缴税）**
| 项目 | 额度/月 | 常漏情形 |
|---|---|---|
| 房贷利息/房租 | 1,000/1,500（城市分档） | 换城市没改 |
| 子女教育 | 2,000（父母各半可分摊） | 孩子下半年入学没填 |
| 赡养老人 | 3,000（分摊上限） | 独生子女没填满 |
| 继续教育 | 400 | 考证当年忘填 |
| 大病医疗 | 年度限额 80,000 | 年度汇算时才填 |

每漏 1,000 元/月额度，税率 10% 时每月多缴 100 元，一年 1,200。

## 三、发现错误的追回路径

1. 先找 HR/财务书面核对（邮件，附工资条截图）——基数错、漏扣时当月可补。
2. 个税多缴：「个人所得税」App → 综合所得年度汇算（每年 3-6 月）→ 退税直接到卡。
3. 社保基数长年压低：可向社保稽核部门投诉要求补缴（追溯有时效，越早越有利）。

## 四、红线段

## 红线
> ⚠️ 提醒：
> 1. 不要同意"把工资拆成报销款/补贴发放"避税——社保基数和离职补偿 N、经济补偿金都按真实工资算，拆低基数是你自己吃亏，且属违规。
> 2. 公司"现金发一部分"= 社保和个税双少缴，你的养老金、公积金贷款额度、购房资格证明全部受损。
> 3. 每年 3-6 月不做年度汇算，多缴的税不退、少缴的还可能被追缴滞纳金。
> 4. 核对发现少发/错扣，先书面留痕再口头沟通——工资争议的举证责任在主张方，工资条和银行流水至少保存 2 年。
