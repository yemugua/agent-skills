二手车贷款利率普遍 6%-15%，比房贷高、比信用贷不定——全款砍价+厂家金融贴息常常比贷款便宜 3000-8000 元。本条给贷款与全款的算账公式、隐藏费用清单和谈判话术。

## 贷款 vs 全款费用对比表
| 项目 | 贷款 | 全款 |
|---|---|---|
| 车价 | 可能「贷款优惠价」低 2000-5000（车商拿金融返佣） | 砍价空间照常 |
| 利息/手续费 | 贷 5 万 3 年，年化 8%≈利息 6000；或「手续费 3000」一次收 | 0 |
| GPS 费 | 500-1500（很多是强制搭售） | 0 |
| 上牌押金/续保押金 | 常被要求 2000-5000 押在车商 | 0 |
| 保险第一受益人 | 常被金融公司要求指定，出险理赔多一道手续 | 自己 |

## 算账公式
贷款总成本 = 利息（本金×年化×年限）+ 手续费 + GPS + 押金占用成本。
真实年化 = 用 IRR 算：月供×期数与到手本金差额反推，名义利率 4% 的等额本息真实年化约 7.4%。

## 算例
车价 8 万，贷款 5 万 3 年：
- 方案A 贷款：名义月费率 0.33%（宣传「月息3厘」），月供 50000/36+50000×0.0033≈1554 元，总利息 50000×0.0033×36=5940 元，另收 GPS 800+手续费 2000=8740 元总成本；真实年化约 7.8%。
- 方案B 全款：放弃「贷款优惠 2000」，但免 8740，净省 6740 元。
- 例外：厂家金融贴息（年化 2%-0%，如官方「3 年 0 息」）时，5 万 3 年利息仅 0-3000，且无手续费 GPS——此时贷款反而省。判断标准一句话：总附加成本（手续费+GPS+押金）+真实利息 > 全款优惠价差额，就全款。

## 可复制话术
「你把贷款方案写清楚：到手本金、月供、期数、总利息、手续费、GPS、押金，一共要付多少钱，我拿 IRR 算真实年化。超过 6% 年化或有 GPS 和押金，我全款，你把『贷款优惠价』改成全款价给我。」续保押金必须拒绝——收续保押金违反《汽车销售管理办法》第十四条，可打 12315 投诉。

## 红线
> ⚠️ 提醒：合同必须写明「无任何附加条件提前还款不收违约金」或违约金比例（超 3% 不签）；「月息3厘」是月费率不是年化，等额本息真实年化≈名义×1.8 倍；押金必须写进合同并注明退还条件与期限，口头承诺无效；贷款未结清前登记证书被抵押，卖车前要先结清解押。
