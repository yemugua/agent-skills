到手工资对不上账，九成是缴费基数被做手脚——学会一条公式+一张核对表，每月工资条2分钟查完，错一项追回一笔钱。

## 核心公式

**到手工资 = 税前工资 − 五险一金个人部分 − 个人所得税**

五险一金个人部分 = 缴费基数 × 个人比例：
| 险种 | 个人比例（全国主流） |
|---|---|
| 养老 | 8% |
| 医疗 | 2%（+大病几元） |
| 失业 | 0.5%（部分城市0.2%） |
| 工伤/生育 | 0%（单位全担） |
| 公积金 | 5%-12%（单位同比例） |

**缴费基数**：按上年月均工资申报，上下限=当地社平工资的60%~300%。新员工按首月全薪申报。

## 完整算例（月薪 15,000 元，公积金 12%，基数按全额）

| 项目 | 计算 | 金额 |
|---|---|---|
| 养老 | 15,000×8% | −1,200 |
| 医疗 | 15,000×2% | −300 |
| 失业 | 15,000×0.5% | −75 |
| 公积金 | 15,000×12% | −1,800 |
| 五险一金合计 | | −3,375 |
| 应税所得 | 15,000−3,375−5,000（起征） | 6,625 |
| 个税（月度简化，首档3%） | 6,625×3% | −198.75 |
| **到手** | | **≈11,426元** |

注意：个税实际按累计预扣，年初几个月税率3%，累计超36,000后跳档到10%，**后半年到手会变少属正常**，不是公司扣错。

## 工资条核对清单（每月2分钟）
1. **基数核对**：社保APP/公积金APP查"缴费基数"，应≈工资总额（≠基本工资，≠最低基数）。
2. **逐项核对**：个人养老=基数×8%，公积金=基数×你入职谈的比例。
3. **公积金双边**：公积金是单位+个人各缴一份，个人扣1,800则单位也进1,800，账户月入3,600——账户实入对不上=单位缴错。
4. **考勤扣款**：病假/事假扣款依据《工资支付暂行规定》，事假当日=月薪÷21.75，多扣即错。
5. **加班费基数**：加班费应按合同工资为基数（1.5/2/3倍），按"基本工资"做基数是常见克扣。

## 追钱算例
月薪15,000元，公司偷偷按最低基数（如5,000元）缴社保：
- 养老少缴 (15,000−5,000)×8% = **800元/月**，一年9,600元——这是你个人账户的钱，直接影响养老金。
- 追讨路径：先让社保稽核（12333）责令单位补缴，单位拒缴走仲裁；自己那部分补回时也需补扣，但账户本金和利息都归你。

## 可复制话术
- 质疑基数："我的社保基数应为上年月均工资___元，目前按___申报不符《社会保险法》第60条，请于本月调整，否则我向社保稽核部门投诉。"
- 质疑扣款："本月考勤扣款___元超过规定标准（月薪÷21.75×请假天数=___），请核对工资单并补发差额。"
- 问HR标准三句："我的缴费基数是多少？公积金比例是几个点？加班费按什么基数算？"

## 红线
> ⚠️ 提醒：① "按最低基数缴，你到手更多"是话术——个人部分进的是你自己的养老/公积金账户，低基数=偷你的钱；② 公积金比例谈成12%却按5%缴，差额可要求补缴，公积金投诉也有专门通道；③ 工资条/工资流水至少留3年（劳动争议仲裁时效1年，但养老金对账要看终身记录）；④ 月度算例个税为简化口径，实际累计预扣法后到手月度有波动，先查"个人所得税APP-收入纳税明细"再质疑公司，别把跳档当克扣闹错对象。
