家庭保单梳理的目的不是"清点"，而是算出缺口——一个人身故、大病、伤残、住院四类风险各差多少钱。

## 第一步：家庭保单四大件台账（可复制模板）

| 风险 | 对应险种 | 我家有/无 | 保额 | 年缴保费 | 缺口 |
|---|---|---|---|---|---|
| 身故责任 | 定期寿险 | | | | |
| 大病收入损失 | 重疾险 | | | | |
| 大额医疗费 | 百万医疗险 | | | | |
| 意外伤残/身故 | 综合意外险 | | | | |

把家里所有保单（含不知道给谁买的、人情单）按这张表归类：不属于四大件的（年金、增额终身寿、理财型）单列一行，标记"储蓄类"，不算保障。

## 第二步：保额缺口算例（三口之家，双职工年收入合计30万，房贷120万）

- 定期寿险：夫妻各按年收入5-10倍 + 分摊房贷。算例：丈夫年收入18万，买150万保额定寿（至60岁，30年缴），30岁男性年保费约1500-1800元；妻子12万收入买100万，年保费约800元。缺口=房贷120万÷2+收入损失，低于此额度即"人不倒钱不够"。
- 重疾险：保额≥3-5倍年收入。算例：收入18万→保额至少50万；30岁买50万保额终身重疾年缴约8000-12000元，买定期至70岁约4000-5000元。
- 百万医疗险：保额200万起，30岁年缴约300元，全家三人约800元/年。
- 意外险：成人50万保额一年约150元，儿童20万（监管限额）约60元。

全家保障四件套齐配参考总价：夫妻双方定寿+重疾+医疗+意外约1.2万-1.8万/年，占年收入30万的4%-6%为合理区间；超过10%优先砍储蓄型保单而不是砍保障型。

## 第三步：缺口分析话术（拒绝人情单推销用）

> "我按四大件算了缺口：寿险差80万、重疾差30万，你推荐这份年金险不解决任何一个缺口，我先补保障再说储蓄。请把这份产品的保额、现金价值表、免责条款发我书面版本，我对比后再回。"

## 第四步：已购保单自查三问

1. 保单受益人写的是谁？没写=法定继承，理赔时需全体继承人到场公证，改指定受益人免费且理赔快。
2. 缴费卡是哪张？换卡/断缴超60天进入中止期（2年内可复效，期间出险不赔）。
3. 有没有孤儿单？原推销员离职不影响理赔，打保险公司官方客服（合同首页）报案即可。

## 红线

> ⚠️ 提醒：不要因为"亲戚卖的"就不敢算缺口——人情单最大的损失是占用每年数千元预算却不补任何缺口；退保损失另见现金价值计算，先梳理再决策，不要在推销电话里当场承诺加保或退保。
