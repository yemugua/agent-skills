城市旅游五天四晚的花销不是玄学，把四大分项各算一遍加起来就是真实总价，预算超没超一目了然。

## 预算分项公式

总预算 = 交通费 + 住宿费 + 门票费 + 餐饮费 + 机动金（建议占总预算10%）

- 交通：往返大交通（高铁/机票）+ 市内交通（地铁/打车约30-50元/天）
- 住宿：每晚房价 × 4晚（四晚五天通常住4晚）
- 门票：热门景点门票按行程逐个加总
- 餐饮：早餐15-20 + 午餐40-60 + 晚餐60-100 ≈ 120-180元/人/天

## 算例：2大1小去成都五天四晚

| 分项 | 明细 | 金额 |
|---|---|---|
| 高铁往返 | 550×3人×2程 | 3300 |
| 市内交通 | 地铁+偶尔打车 40/天×5天 | 200 |
| 住宿 | 亲子酒店450/晚×4晚 | 1800 |
| 门票 | 大熊猫基地55×3+都江堰80×2+55（儿童半价）+武侯祠50×3 | 460 |
| 餐饮 | 150/人/天×3人×5天（儿童按0.5人算）≈ 1875，取1900 | 1900 |
| 机动金 | 总额10% | 770 |
| **合计** | | **8430（人均2810）** |

超支预警线：任意分项实际支出超预算20%即触发复盘——最常见的超支点是餐饮（景区内餐饮溢价50%-100%）和打车。

## 可复制模板

```
交通：往返___ + 市内___/天×___天 = ___

机动金 = 前四项之和 × 10%
```

## 红线

> ⚠️ 提醒：别用「人均2000够不够」这种模糊问法做决策——必须分项算。节假日酒店价格比平日高50%-150%，用平日价算节假日预算必超；机票价格浮动大，下单前用比价工具锁定，别按搜索页首屏价估算。
