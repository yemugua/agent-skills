# 进口宠物食品代购与海关：代购报价拆解与税额算例

进口粮代购的水都在报价单里：原价、运费、税、跑腿费混在一起。用下面的拆解公式和税额表核对，超预算立刻现形。

## 工具与公式
- 到手价 = 原价×汇率 + 国际运费分摊 + (行邮税或关税+增值税) + 代购费(通常10%-15%)
- 行邮税：宠物食品归「食品饮料」类，税率13%，免税额50元（税款≤50元免征）
- 个人自用合理数量：海关一般按自用判定，单次同款不宜过多；官方干粮进口需有输华准入与检疫审批，个人邮寄按行邮税
- 每斤到手成本 = 到手价 ÷ 净重(kg) × 0.5（元/斤）

## 算例（精确金额）
- 加拿大某品牌15kg装，原价70加元，汇率5.2 → 364元。
- 国际运费分摊（拼箱）：约90元；行邮税=(364+90)×13%≈59元>50元，需缴59元；代购费10%=45元。
- 到手价 = 364+90+59+45 = 558元 → 每斤18.6元。
- 对照国内行货同款约520元/15kg（每斤17.3元）：代购反而贵38元且无售后。临界点：只有「代购到手价 < 行货价×0.95」或国内无售时才值得，否则走国行。
- 税改临界：申报价≤385元时税款=385×13%=50元以内免征，个别代购拆单避税——拆单被查仍需补税且有退运风险（退运运费约100-200元自理）。

## 可直接抄的话术/模板
- 问代购：「报价是否含国际运费和行邮税？被税谁承担？批次日期和生产国？能否提供入境清关凭证？」
- 拆单比价表列头：原价｜汇率｜运费分摊｜税｜代购费｜到手价｜每斤价｜行货每斤价｜差价。

## 红线
> ⚠️ 提醒：无中文标签+无检疫准入的进口粮可能是不合规渠道（走私/分装），出问题无法索赔；分装粮（大袋拆小袋）氧化和掺假风险高；被税补缴是法定义务，逃税额大有限购与处罚风险；本条税率为常见参考，以海关总署现行行邮税表为准。
