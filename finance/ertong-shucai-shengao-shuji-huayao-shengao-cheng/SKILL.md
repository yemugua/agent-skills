# 成人高考报名与费用对比

成人高考总花费 = 报名费 + 学费×学制 + 教材费 + 论文费，差价主要出在学费档位，报名费是小头。

## 费用口径表

| 项目 | 标准区间（多数省份） | 说明 |
|---|---|---|
| 报名考务费 | 100–160元/人 | 各省教育考试院收取，如江苏120元（高起专4科）、北京84元 |
| 学费（函授/业余） | 2000–3200元/年（专科）、2400–3800元/年（专升本） | 官方备案价，艺术/医学类上浮 |
| 学制 | 专升本/专科 2.5年（学费通常按3年收） | 部分院校按2.5年收，报名前必须问清 |
| 教材费 | 300–800元/全程 | 有的打包进学费，有的另收 |
| 毕业信息采集/论文 | 100–300元 | 一次性的杂费 |
| 学位英语考试费 | 60–120元/次 | 需要学位证才考 |

## 精确算例：专升本 2.5年总花费

- A档（普通公办函授）：学费 2400×3=7200 + 报名费120 + 教材400 + 论文200 = **7920元**
- B档（普通民办/业余）：学费 3200×3=9600 + 同口径杂费720 = **10320元**
- C档（艺术类）：学费 3800×3=11400 + 杂费720 = **12120元**
- 结论：A 与 C 差价 **4200元**，C 比 A 贵 53%；同专业优先报公办函授档。

## 高起专 vs 专本套账

高起专（2.5年）+ 专升本（2.5年）分两次报，总学费约 5000+7920≈13000元级别；专本连读渠道（机构包装5年）常报价 18000–25000元，**溢价部分就是机构利润，不要为"一站式"多付**。

## 可复制话术

> "请问贵校 2027 级专升本 XX 专业学费备案价是多少？按 2.5 年还是 3 年收？教材费是否包含在学费内？除学费外还有哪些一次性费用？我需要看到学校继续教育学院官网公示页，请把链接发我。"

任何环节机构答不出官网公示链接的，直接换一家。

## 红线

> ⚠️ 提醒：①学费一律缴到对公账户或学校官方缴费平台，转到个人账户/微信即违规；②报名只在省教育考试院官网，任何"内部指标""不用考试"都是诈骗；③"一年拿证"不存在，成考最低学制2.5年，虚假承诺可向当地教育局举报（12391 教育督导热线）。
