寄宿还是走读，本质是一道「钱+时间+自理能力」的三元计算题：把通勤小时折成钱、住宿费加总、再对照孩子自理能力打分，答案比家庭争论客观得多。

## 一、三年总成本对照表（按当地价替换）

| 项目 | 寄宿 | 走读 |
|---|---|---|
| 住宿费 | 800-1500元/学期 → 3年约4800-9000元 | 0 |
| 生活用品/床品 | 首期800-1500元 | 0 |
| 校内伙食差价 | 略高（食堂+夜宵）约+200元/月 → 3年+5400元 | 0 |
| 通勤 | 0 | 公交/地铁月票或接送：150-600元/月 → 3年5400-21600元 |
| 家长接送时间成本 | 0 | 单程30分钟×2×240天/年×3年=720小时 |
| 课外陪读时间 | 周末集中 | 每晚可控 |

寄宿3年直接支出≈1.1万-1.6万；走读直接支出≈0.5万-2.2万，但多换来每天2-3小时亲子沟通与监督窗口。

## 二、通勤时间红线

- 单程通勤≤40分钟：走读无压力
- 40-60分钟：可走读，但睡眠压到7.5小时以下就改寄宿
- ＞60分钟：建议寄宿——初中生需8-9小时睡眠，每天2小时通勤一年吃掉约500小时学习/睡眠时间，等价于一整学期课时的三分之一。

## 三、自理能力评估（每项1分，8项打分）

自己起床（不用叫三遍）／整理书包床铺／按时吃饭不挑食／管理零花钱／洗小件衣物／主动写完作业／情绪不依赖每日安抚／愿意表达求助。
- ≥6分：寄宿可适应，开学首月每周通话2次即可。
- 4-5分：先走读一年观察，或寄宿但首月家长陪住过渡。
- ≤3分：寄宿风险高（不是成绩问题，是情绪与生活失控风险），优先走读+家政/家人补位。

## 四、决策算例

家庭A：对口校距家75分钟（地铁换乘），孩子打分5。寄宿3年成本≈1.3万；走读成本≈1万但孩子每天少睡50分钟+家长接送时间720小时。若家长误工按时薪50元折算=3.6万元隐性成本。结论：选寄宿，把周末用来集中陪伴，并为孩子先报一期独立生活夏令营（约600元）做过渡——这是花小钱降大风险。
家庭B：距家25分钟，孩子打分3。走读全年多支出≈5000元，但换到每日监管与睡眠，结论：走读。

## 五、真实案例

某家庭为「锻炼独立性」强行寄宿，孩子打分2（从未自己起床）；两个月后失眠、成绩下滑、每周五回家情绪爆发，转走读后一学期恢复。独立性的正确练法是小学高年级在家逐步放权，而不是用寄宿硬练——寄宿是通勤或家校条件倒逼的选择，不是教育目的本身。

## 红线

> ⚠️ 提醒：寄宿决定应在开学前2-4周确定并向学校申请床位，开学后中途转入常无床位；首月是适应关键期，家长若发现孩子持续失眠/拒学/体重下降超2kg，及时与班主任和校医沟通，勿硬扛「别人都能适应」；寄宿≠家长责任转移，周末高质量陪伴缺失会以青春期逆加重形式还回来。
