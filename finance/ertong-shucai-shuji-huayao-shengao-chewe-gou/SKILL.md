车位15万买还是800/月租？答案不固定，用租金回报率一算就知道——**年租金÷车位价>4% 租着划算，<3.5% 买着划算**，中间地带看持有年限。

**核心公式：**
- 租金回报率 = 年租金 ÷ 车位售价（车位健康区间 3.5%-5%，低于3%纯投资角度不值）
- 租N年总成本 = 月租×12×N×(1+年涨幅)^N；买=总价+契税(3%非住宅多数按3%)+管理费
- 买更划算的临界年限 ≈ (车位总价×1.03) ÷ (年租金 − 年管理费差)

**算例A：车位卖12万，月租500，管理费买车50/月、租房80/月（含在租金内单列）：**
- 买：12万×1.03（契税3%）= 12.36万 + 车位管理费50×12×10年=0.6万 → 10年约12.96万
- 租：500×12=6,000/年，年涨3% → 10年累计约 6.9万
- 租金回报率 = 6000/120000 = **5%** → 租金回报高，**租划算**，10年省约6万（省下的钱按3%理财还能再多1万+）。

**算例B：车位卖10万，月租700：**
- 回报率 = 8400/100000 = **8.4%**？——超过正常区间，说明要么车位卖得便宜（捡漏可买），要么租金包含其他服务，先核实再下结论。

**算例C：车位卖18万，月租450：**
- 回报率 = 5400/180000 = **3%** → 边界值，长期自住（>8年）买，短住或可能换城市租。买的核心价值是"使用权锁定+抗租金上涨"，不是增值。

**决策模板：**
```
车位售价____；契税____(×3%)；月管理费____
月租____；预计年涨幅____%；预计持有/居住年限____年
回报率=月租×12/售价 = ____%
回报率>4% → 租；<3.5% 且居住>5年 → 买；3.5-4% → 居住>8年买，否则租
```

**买前三个必查：**
1. 产权性质：要"产权车位"（能办不动产证），人防车位只能租不能买（合同写20年租期是规避手段，人防工程归国家，拆迁/征用无补偿）；机械车位确认维修责任方。
2. 是否能独立办证、能否单独转让——无独立产权的车位挂着"使用权转让"名义，转手难、维权难。
3. 开发商是否已大产权证办妥+车位是否抵押给银行（车位常被整批抵押，解押前不能过户）。

**砍价话术：** "同小区近三月成交X个，成交价X.X-X.X万，您报X万高出一截；如果是尾盘清售或者业主要快速回款，X.X万我现在签全款。"——报同小区成交案例+一口价。

## 红线
> ⚠️ 提醒：人防车位、"使用权转让"车位一律不当买卖处理，付款前查不动产登记簿确认车位独立产权+无抵押；购房时开发商"买房必须捆买车位"属违规捆绑，可向住建部门投诉；租车位一次付超过1年租金的"长租优惠"要谨慎，物管/开发商经营异常时预付款难追回；车位契税按非住宅税率（多数地区3%）计，别按住房1%预期；算账时把管理费差额和资金机会成本（总价×3%/年）都算进去，只比"总价vs月租"会系统性高估买车划算度。
