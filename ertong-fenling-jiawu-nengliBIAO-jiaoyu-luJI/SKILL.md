# 儿童分龄家务能力表

一句话：家务=儿童执行力+责任感+自理能力的三合一训练——「学习忙不用做家务」是最贵的教育误区（**做家务的孩子学业与独立性的相关性是研究反复验证的**）。本技能给分龄能力表 + 家务教学四步法 + 激励设计。

## 一、分龄家务能力表（3-18 岁）

| 年龄 | 能做的家务 | 教学重点 |
|---|---|---|
| 2-3 岁 | 收玩具/扔尿布进垃圾桶/把衣服放进篮子 | 「归位」概念启蒙 |
| 4-5 岁 | 铺床/浇花/擦桌子/摆餐具/叠简单衣物 | 完成感+具体示范 |
| 6-7 岁 | 收拾书包/**自己整理上学用品**/扫地/简单擦洗/给植物喂水 | 自我管理的开始 |
| 8-9 岁 | 洗碗/倒垃圾/叠自己的衣柜/简单做食（三明治/煮蛋）| 流程完整性 |
| 10-12 岁 | 洗自己的衣服（机器）/做 1-2 道简单菜/打扫房间全流程/照顾宠物 | 独立操作+质量标准 |
| 13-15 岁 | 全屋任一家务/做一顿饭/管理自己物品采购（洗衣液没了列清单）| 家庭成员角色 |
| 16-18 岁 | 独立生活全技能（做饭/洗衣/清洁/简单维修）/打零工 | **离家前的最后彩排** |

**原则**：家务责任「只增不减」——新家务加入，旧家务不收回（能力叠加制）。

## 二、家务教学四步法（教会而不是命令）

1. **你做我看着**（示范+讲解关键点）
2. **一起做**（扶手上手——错误允许）
3. **TA 做你看着**（只提醒不代劳——**忍住重做的手**）
4. **独立做+验收反馈**（具体表扬：「桌角也擦到了」——泛泛的「真棒」无效）

**失败处理**：做砸了（打碎碗/水洒了）→ 「没事，一起收拾」——**责骂=扼杀家务积极性**（孩子记住的是恐惧不是技能）。

## 三、激励设计（钱 vs 责任的边界）

- **日常家务=家庭义务，不付钱**（参考财商技能的原则——义务是家庭成员的身份责任）
- **额外商业行为可付钱**：洗车/擦全屋窗户/帮邻居收快递——「超出自己义务的劳动」才有市场定价
- 自然的后果代替惩罚：不收玩具→玩具被「暂时保管」；不洗校服→穿脏的（**后果教育的力度刚刚好**）
- 习惯养成期（前 3 周）：打卡表+完成感可视化（贴纸墙——低龄有效；大龄用「责任清单」替代贴纸）
- **避免的激励**：惩罚性家务（「罚你洗碗」=洗碗成为负面符号——家务永远不该当惩罚用）

## 四、家长纪律（家务教育的成败在家长）

1. **标准放低**：7 岁的洗碗有泡泡残留=合格（家长重洗=孩子学会「反正会被重做」）
2. **不抢救**：书包忘带了→ 让TA体验一次「没带的结果」（打电话送去=永远学不会自己检查）
3. **全家一致**：一方偷偷代劳=规则瓦解
4. **时间预期**：习惯养成 1-3 个月——「教了三次还不会」是正常节奏
5. 儿子女儿同标准：**家务无性别**（女孩不做家务/男孩不进厨房的双重标准都是坑）

## 五、与学业的平衡（「学习忙」的破解）

- 研究视角：做家务的时间与学业表现负相关是**误区**——轻度家务（30 分钟/天）与时间管理能力正相关
- 高中生的家务=「生活能力的必修课」（大学宿舍的生存技能是家庭教的）
- 考试周的弹性：家务可暂停但「自理部分」（房间/衣物）不豁免——**家务分两级：自理级（终身不豁免）+贡献级（可弹性）**

## 六、真实对照

> 案例 A：9 岁全程被代劳——15 岁住校第一月打包 8 公斤脏衣服回家（自理欠账的利息）。
> 案例 B：家务四步法教会 7 岁洗碗——三个月后孩子主动承包「周五洗碗日」（完成感一旦建立，积极性自己运转）。
> 家务教育的公式：**分龄能力表照单培养、四步法教会不命令、义务不付钱+超额可付、做砸不骂、标准放低不抢救、自理级终身不豁免、家务无性别**——家务教的不是劳动；是「我能照顾自己也能贡献家庭」的自我效能感——这个感觉，课本里没有。

## 红线
> ⚠️ 提醒：家务教育的公式——「能力随年龄只增不减、示范-同行-旁观-独立四步、义务不付费超额可付费、做砸了一起收拾、标准放低别重做、后果教育代替说教、自理级不豁免、家务不分性别」。会做家务的孩子赢的不是技能；是「离开父母也能把日子过好」的底气——这笔投资在 18 岁住校那天兑现。
