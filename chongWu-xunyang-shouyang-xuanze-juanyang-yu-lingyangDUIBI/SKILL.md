# 宠物领养与购买的选择：渠道决策与繁殖伦理

# 宠物来源决策：领养还是购买

一句话：来源决策=「你要什么+你能承担什么」——领养的优势在性格确定与健康性价比，购买（正规猫舍犬舍）的优势在品种可预期；**两者的红线都一样：远离后院繁殖**。本技能给决策矩阵 + 各渠道核验法 + 后院识别。

## 一、决策矩阵（先问自己三个问题）

1. **对品种外观有执念吗？**——有 → 正规猫舍犬舍（品种特征可预期）；没有/性格优先 → 领养（成年性格可见可挑）
2. **预算与风险偏好？**——领养低成本高性价比；购买=溢价买「可预期」（血统+性格倾向+健康筛查）
3. **投入时间与经验？**——新手 → 成年领养（性格定型+已训练已绝育）；有经验 → 幼崽（领养幼崽或购买）

**结论先行**：性格优先/新手/预算有限=领养；品种执念/参赛繁育计划/要幼犬幼猫=正规繁育者；**两条路都不选=后院/宠物店幼崽区（风险区）**。

## 二、正规繁育者（猫舍犬舍）的核验清单

- [ ] 看到母猫/母犬（**拒绝看母本的=幼崽来路存疑**——后院的典型话术「狗妈妈不在家」）
- [ ] 繁殖频率：母本一年一窝（**一年两窝以上=透支母本的商业繁殖**）
- [ ] 品种遗传病筛查：品种对应基因检测报告（折耳猫软骨基因/柯基髋关节评估等——**正规舍主动出示**）
- [ ] 疫苗驱虫记录+疫苗本
- [ ] 合同：健康协议（15-30 天重大疾病退换条款）+繁育限制条款（宠物级绝育协议）
- [ ] 环境实地看：家养环境 > 笼养车间（**笼位密布+幼崽走廊=流水线**）
- [ ] 价格锚点：正规舍比宠物店高 20-50%（**贵的是筛查与母本养护——不是智商税**）

## 三、后院繁殖与宠物店的识别（风险区特征）

**后院特征**：
- 母本不让看/「正好有一窝刚生」的多品种同时有货（**品种杂=以卖货为导向**）
- 价格明显低于市场（1/3 价位=压缩成本在某处：疫苗/母本健康/遗传筛查）
- 朋友圈式卖宠+快递发货（**活体快递=应激+健康风险+无售后**）
- 「包活包健康」口头承诺无合同

**宠物店幼崽区**：多为批发进货（后院供货链）——**星期宠物（买回一周发病）的高发区**；购物须当场查：疫苗本（注射记录可信度）/活体检测协议/店龄与口碑——**宠物店的可辩护性远低于正规舍**，买前想清楚。

## 四、领养渠道的进阶（比第一只更聪明的第二次）

- 领养适配度评估：救助站的领养问卷=双向筛选（**被「查户口」不是刁难是被负责**）
- 试养期 2-4 周写进协议（参考领养技能）
- 成年宠的二次适应：前史（遗弃原因/行为习惯）问清——救助团队的档案是信息金矿
- 品种救助站：想养特定品种的领养路线（品种专项救助——「领养代替购买」的进阶形态）

## 五、来源决策的健康底线（无论哪条路）

- 到家 3-7 天内基础体检（传染病/粪检/皮肤——**「带病进门」的隔离成本远高于体检费**）
- 与原住民隔离 2 周起步（传染病窗口期）
- 疫苗补全确认（记录核实——补针按未完成处理）
- **来源的合同与凭证永久保留**（维权/后续健康追溯的基础）

## 六、真实对照

> 案例 A：朋友圈 1,200 的「布偶」——到家 5 天猫瘟（治疗 5,000+且预后差）；母本从未见过、疫苗本笔迹存疑=典型后院链路。
> 案例 B：正规舍 4,500 布偶——父母基因检测报告+遗传病筛查+30 天健康合同——两年零疾病（溢价买的是「确定的健康起点」）。
> 来源决策的公式：**性格优先选领养、品种执念选正规舍、看母本是核验锚点、年一窝是繁殖伦理线、遗传筛查报告主动出、活体快递=风险区、到家体检+隔离两周、合同凭证永久留**——来源的差价背后是「谁承担了健康成本」——把成本压到看不见的地方，就会以医疗费的形式找回来。

## 红线
> ⚠️ 提醒：来源决策的公式——「领养=性格确定+性价比、正规舍=可预期+筛查背书、后院=风险区远离、不让看母本=红旗、一年两窝=透支、遗传筛查报告是入场券、星期宠物高发于批发链、到家必体检必隔离」。宠物的价格差从来不是「品牌溢价」；是「健康成本由谁付」——付在买前，还是付在病后。
