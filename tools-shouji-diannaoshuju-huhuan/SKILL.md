# 手机与电脑的数据互通工作流

跨设备传文件的六条通道对照（速度/限制）、文件传输助手与局域网方案、长图文与聊天记录的跨端、移动热点的办公组合。

## 操作路径
1. **六条通道对照（按场景选）**：①微信文件传输助手（0 门槛+通用——限制 1GB/文件+压缩画质）；②系统级互通（iPhone 隔空投送/AirDrop——近距离速度之王；华为荣耀小米的多屏协同/互传联盟）；③QQ 我的电脑（大文件不限速——比微信宽）；④局域网传输（LocalSend/SendAnywhere——同 WiFi 免登录全平台，速度快无压缩——隐私敏感与大批量的首选）；⑤网盘中转（异步传输——不着急的批量）；⑥数据线（最快最稳——大视频与全量备份）。
2. **场景化工作流**：手机拍素材→电脑剪辑——数据线或 LocalSend（原图不压缩）；电脑文档→手机查看——传输助手+收藏（同步多端）；聊天记录跨端——微信「聊天记录迁移」（设置-通用-迁移，同 WiFi 直传）；长图文批注——手机端标记后回传电脑（GoodNotes/WPS 的跨端同步）。
3. **局域网与免登录方案**：LocalSend（开源免费全平台——同 WiFi 秒传，2020s 后的默认答案）；SendAnywhere（跨网络也可——6 位码配对）；电脑开热点给手机（无路由器场景）；远程访问（向日葵/ToDesk——人在外面取电脑文件；注意账号安全与隐私习惯——用完断开）。
4. **备份与同步的边界**：照片——相册云同步为主、数据线月度归档为辅；聊天记录——电脑端微信的定期备份（手机换机前必做）；文件——传输 ≠ 同步（传输是一次性，同步是持续一致——长期工作文档用云盘同步而非反复传输）。
5. **速度与隐私的细节**：WiFi 5/6 的局域网速度差异（同路由下 LocalSend 可达 30-80MB/s）；微信传图勾「原图」（默认压缩画质——发素材必勾）；公共 WiFi 下不传敏感文件（明文网络的风险）；传输完成的清理习惯（传输助手的聊天记录定期清理——顺手但别误删素材）。

## 避坑红线 ⚠️
- 微信传大素材——压缩+1GB 限制+找不回的转发链；正经素材走数据线/LocalSend。
- AirDrop 常开「所有人」——公共场合的骚扰与文件投毒风险；用完切「仅联系人」。
- 只靠传输助手当存储——聊天记录清了就没了；「传输是搬运，备份才是保险」。

## 效率验收
日常传文件不掏数据线（LocalSend 常驻）；换机前知道「先迁移聊天记录再备份相册」的顺序。

## 真实价格
LocalSend/SendAnywhere 免费；数据线 20-50 元；向日葵免费档够用；整套 0-50 元，回报=每天几次的秒传。

## 红线
> ⚠️ 提醒：跨设备传输的选型口诀——「近距 AirDrop/LocalSend，大文件数据线，随手传传输助手，长期文档云盘同步」。原图勾选与聊天迁移是两个必知细节；AirDrop 平时关「所有人」。
