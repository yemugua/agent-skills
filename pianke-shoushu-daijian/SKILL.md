一句话点题：门诊小手术（皮脂腺囊肿、脂肪瘤、拆线、拔甲、痔疮简单处理等）多为局部麻醉、30-60分钟做完、当天回家——提前办好请假和陪护安排，比手术本身更影响恢复质量。

## 时间与安排基准表

| 环节 | 时长 | 陪护要求 |
|---|---|---|
| 门诊挂号+术前谈话 | 1-2小时 | 陪同（签字可本人） |
| 手术（局麻，含消毒准备） | 30-60分钟 | 可在外等候 |
| 术后留观 | 30-60分钟 | 需在场 |
| 当天回家 | 骑车/开车不可，打车需陪 | 1名陪护全程 |
| 拆线复诊 | 7-14天后，30分钟 | 可自理 |

请假公式：**请假天数 = 1天（手术日）+ 预估恢复缓冲**。表皮小肿物切1天够；伤口在关节/躯干受力处、或需久站久坐的职业（厨师/司机/教师站立岗）建议2-3天；涉及劳动强度岗位按病假条恢复期由医生填写为准。

## 请假条与病假证明要点

- 请假依据是医院开具的**病假条（诊断证明+休假建议）**，手术当天让医生一并开好，写明「术后休息__天」；术后补开要重新挂号，多花挂号费和时间。
- 门诊病历、手术记录单、缴费票据当天全部拍照留存——工伤或病假扣薪争议时这是证据链起点。
- 话术模板（对直属上级）：
```
__哥/姐，我约了__月__日上午在__医院做一个门诊小手术
（皮脂腺囊肿切除，局麻，约1小时），当天请假1天，
医生开的病假条我会拍照发您，术后如有需要按医嘱再请。
工作交接：__手头__事已同步给__，当天紧急事项可打我电话。
```

## 精确金额算例

- 门诊小手术自费区间：皮脂腺囊肿切除 300-800元（含局麻/敷料）；脂肪瘤 400-900元；拔甲 200-500元。医保门诊统筹报销后自付约 30-50%。
- 病假扣薪：企业按病假工资=本人工资×60-80%（各地下限不同，不低于当地最低工资80%）——月工资8000元、请2天病假约损失 8000÷21.75×2×(1-70%)≈110-220元。
- 陪护成本：打车往返 50-100元 vs 自己骑车伤口裂开二次缝合再花 500-800元+误工——**50元打车费是必须花的风险对冲**。

## 可复制术后照护清单

```
术后24小时：
□ 伤口压迫止血区按医嘱时间拆除，渗血渗透敷料→回院
□ 当天不沾水、不提重物（>2kg）、不做汗水大量运动
□ 口服止痛药（布洛芬）按时吃，不等痛了再吃
□ 抬高患处（手部悬吊/腿部垫枕）减少肿胀
术后2-14天：
□ 隔日换药或按医嘱；红肿加重、跳痛、发热>37.5℃→立即回院
□ 拆线日期：____（医生约定，别拖）
□ 疤痕护理：拆线后3天开始用硅酮凝胶，坚持2-3月
```

## 红线

> ⚠️ 提醒：
> 1. 局麻手术后禁止自己开车、骑车、操作机械——麻醉未完全代谢+应激反应，判断力和肢体力都打折，24小时内也不建议签署重要文件。
> 2. 病假条必须是看诊医生开具并盖医院诊断证明章，网购或代开的「病假条」属伪造证明，被查实可按旷工甚至解雇处理。
> 3. 伤口出现跳痛、渗液发黄、发热不是「正常恢复」，是感染信号——24小时内回原医院复诊，自行吃抗生素只会掩盖病情。
> 4. 有糖尿病、长期服用抗凝药（阿司匹林/华法林）者术前必须主动告知医生，自行停药或隐瞒都会显著提高出血风险。
> 5. 门诊小手术也可能出现病理异常结果——切除组织常规送病理，别因「小手术」拒绝送检，费用仅几十到百余元。
