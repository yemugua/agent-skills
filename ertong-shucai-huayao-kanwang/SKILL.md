# 春节走亲戚与拜年红包礼数

一句话点题：走亲戚最难的不是跑腿，是「叫不出称呼、包不出金额、收不出体面回礼」——三张表解决。

## 一、亲戚称呼速查表

| 关系 | 称呼 | 对方叫你 |
|---|---|---|
| 爸爸的哥哥 | 伯伯/大伯 | 侄子/侄女 |
| 爸爸的弟弟 | 叔叔 | 侄子/侄女 |
| 爸爸的姐妹 | 姑姑 | 内侄/内侄女 |
| 妈妈的兄弟 | 舅舅 | 外甥/外甥女 |
| 妈妈的姐妹 | 姨妈 | 外甥/外甥女 |
| 爸爸哥哥的孩子 | 堂哥/堂姐 | 兄/妹 |
| 妈妈姐妹的孩子 | 表哥/表姐 | 兄/妹 |
| 爸爸兄弟的配偶 | 伯母/婶婶 | 侄子 |
| 姑姑的丈夫 | 姑父 | 内侄 |
| 舅舅的妻子 | 舅妈 | 外甥 |
| 姨妈的丈夫 | 姨父 | 外甥 |
| 爸爸的爸爸的兄弟 | 堂爷爷/叔公 | 侄孙 |

记忆口诀：**父系「堂」，母系「表」；父之兄弟是伯叔，父之姐妹是姑；母之兄弟是舅，母之姐妹是姨。**

## 二、红包金额梯度表（2026 水位）

| 对象 | 一线/省会 | 地级市 | 县城/乡镇 |
|---|---|---|---|
| 亲侄/亲外甥（未成年） | 600–1000 | 400–600 | 200–400 |
| 表侄/表外甥 | 200–400 | 100–200 | 60–100 |
| 朋友同事小孩（拜年见面） | 100–200 | 60–100 | 20–60 |
| 给长辈的红包（孝敬） | 600–1000 | 400–600 | 200–400 |
| 自家孩子收到红包回礼 | ≥来礼 80% | ≥来礼 80% | ≥来礼 80% |

算例：你给表哥家两个孩子各 200，表哥回你家独生子一个——他包 400 才算「不亏」，包 200 属于「两清」，包 100 以下在亲戚圈里会被记住。原则：**回礼=来礼×80%起步，两家孩子数不等时按人均拉平**。

数字避讳：金额带 6/8（160/280/360/660），避开 4（40/400/440）；新客首次上门（订婚/头年新婚走亲）金额比常规水位上浮 50%–100%。

## 三、红包三话术

- 给出去：「拿着拿着，给孩子买点学习用品，别嫌少。」（递时双手，先孩子后大人）
- 推回来对方坚持：「那我就不推了，替孩子谢谢姑姑。」（推让超过 3 个回合就收，硬推不收反而失礼）
- 收到要回礼当场记：微信备忘录记「姑家 400、舅家 600」，年后汇总一次，避免明年包错。

## 四、走亲顺序与回礼规矩

1. 顺序：初一夫家父母→初二回娘家→初三姑姨→初四舅家→初五朋友（各地略有差异，以本地为准）。
2. 空手上门是红线：至少带水果/牛奶/烟酒一类（100–200 元档即可），礼轻不空手。
3. 回礼形式：对方带来的礼可原样转赠第三家（不回赠送礼人本人），或加一盒价值 50–80 元的茶叶/坚果凑双数回。

## 五、真实案例

某杭州家庭给亲侄包 200，嫂子年后在家族群里被追问；调整后亲侄 600、表侄 200，附一句「孩子大了，包个六百讨个顺」——争端即平。差额 400 元买断的是整年的亲戚口碑。

## 红线

> ⚠️ 提醒：金额忌 4 与单数；回礼低于来礼 50% 会被亲戚记账多年；称呼叫错（表/堂混用、姑父叫叔叔）当场道歉一句「叫岔了，叔叔别介意」即可，越遮掩越尴尬；红包当场不当面清点。
