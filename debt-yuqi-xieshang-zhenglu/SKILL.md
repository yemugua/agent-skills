# 信用卡/网贷逾期的协商路线

逾期后的应对顺序、停息挂账（个性化分期）的申请条件与话术、网贷平台的减免谈判与「催收承诺不落地」的防范。

## 操作路径
1. **逾期后 72 小时**：盘点全部债务（每家的本金/利率/逾期天数做成表）；按「利息增速+起诉风险」排序（信用卡和持牌消费金融先处理，年化 24%+ 的网贷优先止血）；立即止损——注销所有能借的渠道（防以贷养贷），删掉借款 App。
2. **信用卡协商（个性化分期还款协议）**：依据《商业银行信用卡监督管理办法》70 条——「特殊情况下无力偿还且仍有还款意愿」可与银行签个性化分期协议（最长 5 年/60 期，停止计息）；申请话术要点——说明逾期原因（失业/疾病——最好有证明）+收入与还款能力+明确方案（「每月可还 X 元，申请分 N 期」）；先打客服（录音），被拒再升级书面申请+银保监 12378 转办；注意——协商成功期间征信显示「止付/逾期」状态，协议履行完部分银行可申请修复。
3. **网贷协商**：持牌机构（借呗/微粒贷/京东金条）——官方客服申请延期/减免（政策时有窗口：提供困难证明可获 3-12 个月宽限或减免部分罚息）；非持牌高息平台——先算合法利率上限（LPR4 倍），超限部分可主张不付，协商「本金+合法利息」一次性结清（常有折扣空间）。
4. **催收应对**：合法催收边界——不得暴力/威胁/骚扰第三人/伪造公文；违规催收——录音+截图（保留号码与时间）→平台投诉→12378/互联网金融协会举报；「上门」的应对——开门前确认身份（工作证+委托书），全程录像，不签署任何现场文件。
5. **防「协商黑产」**：收费「征信修复/停息挂账代办」（收 10-30% 债务额）——全部操作本人免费可办；黑产常见操作「伪造病历/贫困证明」=涉嫌诈骗，反而加重责任；真协商自己打客服电话就能推进。

## 避坑红线 ⚠️
- 「失联躲催收」是最差策略——失联加速起诉+无法协商；每周主动联系一次（留通话记录=还款意愿证据）。
- 「等有钱一次结清」幻想——利息每天在涨，协商分期才是现实止损。
- 协商期间新逾期一笔=全线协议作废——协商前确保「月供总额<月收入 40%」的可持续方案。

## 维权阶梯
违规催收→互联网金融协会/12378/110（暴力催收）；协商被拒→12378 转办监管施压；利率超限→法院主张调整（司法保护上限）。

## 法律效力
《商业银行信用卡业务监督管理办法》70 条个性化分期；《个人信息保护法》对催收骚扰通讯录的限制；民间借贷利率司法保护上限（LPR4 倍）；暴力催收涉治安/刑事责任的情形。

## 真实价格
自己协商 0 元；「反催收黑产」收费 10-30% 债务额+法律风险；协商成功后的月供压力减半+停息；拖延的代价=利息滚存+起诉概率上升。

## 红线
> ⚠️ 提醒：逾期自救的顺序——「盘点排序→主动联系→书面方案→留证防骚扰」。所有协商本人免费可办，凡是先收费的「修复机构」都是第二刀。
