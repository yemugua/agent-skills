# 家具安装费陷阱：报价拆分与加价套路

一句话：「免费安装」=只免「标准安装」，螺丝加钱、上楼加钱、打孔加钱——把加价项目行情价记牢，师傅报高价当场就能对出来。

## 一、加价项目行情价表（2025-26 主流平台/线下）

| 项目 | 合理区间 | 套路价 |
|---|---|---|
| 打孔（混凝土墙） | 10-20元/个 | 50-80元/个 |
| 上楼无电梯 | 20-30元/层 | 50元/层起 |
| 加装五金件 | 配件费2-5元+安装10元 | 「专用螺丝」20-30元/颗 |
| 拆旧家具 | 50-100元/件 | 200元起 |
| 高层吊装（家具进不了电梯） | 200-400元 | 600元起 |

## 二、下单前把口说死（模板直接抄）

订单备注写：「免费安装范围：标准安装含常规打孔≤4个；上楼费___元封顶；不加价项目请提前电话确认，上门后加价项目一律拒付。」——平台订单备注是可以作为售后凭证的，客服口头承诺不算，**文字进订单备注才算**。

## 三、上门加价应对

1. 先问：「这些项目平台价格表是多少？」——多数师傅报价虚高就是赌你不知道。
2. 行情价对答：「打孔我们这边15一个，你报50我们不接受，要么按15装，我们好评+晒单。」
3. 师傅坚持加价：不装不付上门费（多数平台规则：未开始安装不收费），平台投诉「乱收费」，退款换人重约。
4. 线下店购：加价前要求出示价目表；没有价目表的「随手加价」可打12315。

## 四、算钱案例

双人床安装：标准免费；师傅到场加「加固件120+打孔4个×50=200」共320元。按行情价对答后：加固件实为可选（原包装有标准连接件）拒掉，4孔×15=60元成交——**省260元**。

## 红线
> ⚠️ 提醒：所有价格承诺落进订单备注，不接受口头；未开始施工前拒绝安装不构成违约；师傅私收现金无凭证=事后无维权基础，一律走平台支付。
