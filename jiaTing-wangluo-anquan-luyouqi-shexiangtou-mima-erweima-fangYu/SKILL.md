# 家庭网络安全：路由器与摄像头

# 家庭网络安全

一句话：家庭网络攻击的三大入口=**弱密码的路由器、裸奔的摄像头/智能设备、家庭成员的钓鱼点击**；家庭网安的性价比极高（三件事做完=风险降 80%+）。本技能给路由器加固 + 摄像头安全 + 家庭成员防线 + 智能设备清单。

## 一、路由器加固（第一道闸门）

- **管理密码 ≠ WiFi 密码**：路由器管理后台的 admin/admin 默认密码必须改（**默认密码=全世界的教科书都写着**）
- WiFi 加密：**WPA3 或 WPA2-AES**（WEP/开放网络=裸奔；「访客网络」给访客隔离主网）
- WiFi 密码强度：≥12 位混合（**8 位纯数字几分钟内被跑完**）
- 固件更新：路由器固件半年一查（**路由器是「永不关机的电脑」——固件漏洞=全家设备裸奔**）
- 远程管理（WAN 侧管理）关闭（不需要远程设置就关）
- UPnP 关闭（减少端口暴露——游戏设备需要时单独开）

## 二、摄像头/智能设备（隐私的重灾区）

- 摄像头三规则：
  1. **默认密码必改**（弱密码摄像头被「扫」的案例海量——观看你的生活的可能是陌生人）
  2. **摄像头账号独立密码+开启二次验证**
  3. 物理视角管理（**卧室/浴室不装**——「为了安全」装到隐私区=更大的不安全）
- 智能设备的通用规则：改默认密码/固件更新/不需要的功能（麦克风/远程）关闭/**闲置设备断电**（「智能插座联盟」的风险）
- 婴儿监视器：独立网络（访客网络隔离）+摄像头账号双重验证

## 三、家庭成员防线（人的漏洞最大）

- **钓鱼识别**：短信链接/「快递异常」/「ETC 失效」/「积分到期」——**不点链接，官方 App 核对**（参考反诈技能）
- 密码体系：**核心账户（支付/邮箱）独立强密码+两步验证；网站用密码管理器**（一码走天下=一个洞全家漏）
- 长辈防线：免密支付关闭+延迟到账（参考老人手机技能）+「转账前打电话给家人」的家庭暗号
- 儿童防线：游戏充值限额+「免费皮肤」诈骗教育（**未成年人受骗的重灾区**——参考财商防骗课）
- 家庭 WiFi 纪律：**不在家庭网络环境分享（网盘群发）身份证照片/合同照片不加密**——「内部泄露」是常被忽略的一环

## 四、家庭数字资产的备份与应急

- 照片 3-2-1 备份（参考备份技能）
- **账户清单+应急联系人制度**（参考紧急联系人技能——数字资产的「遗物管理」）
- 手机丢失的预案演练（SIM 卡挂失第一——参考手机丢失技能）

## 五、检查清单（一次 30 分钟的家庭网安体检）

- [ ] 路由器管理密码已改+固件半年内更新
- [ ] WiFi WPA2-AES 以上+≥12 位
- [ ] 访客网络隔离开启
- [ ] 摄像头/智能设备默认密码全改+固件更新
- [ ] 核心账户两步验证全开（支付/邮箱/云盘）
- [ ] 长辈手机免密支付关闭
- [ ] 儿童设备充值限额
- [ ] 照片备份 3-2-1 完好
- [ ] 卧室浴室无摄像头

## 六、真实对照

> 案例 A：家用摄像头默认密码——被陌生账号登录观看；改密+二次验证+独立账号后归零（**「弱密码摄像头」是被动的直播机**）。
> 案例 B：孩子「免费皮肤」链接——家长限额+防骗对话过的孩子识别出了；对照没讲过的：充值 2,000（**人的防线=对话教育出来的**）。
> 家庭网安的公式：**路由器双密码（管理+WiFi）全改+固件更新、摄像头默认密码改+视角管理、智能设备闲置断电、核心账户两步验证、钓鱼以「官方 App 核对」为纪律、长辈免密关闭、儿童充值限额、3-2-1 备份、半年一次家庭网安体检**——家庭网安的投入产出比惊人：30 分钟+零预算=风险降 80%——它不是技术活；是「把默认值全改掉」的纪律活。

## 红线
> ⚠️ 提醒：家庭网安的公式——「管理密码与 WiFi 密码分开改、WPA2-AES 起步、摄像头改密+两步验证+隐私区不装、智能设备固件更新+闲置断电、核心账户两步验证全开、钓鱼只信官方 App、长辈免密关儿童限额、家庭体检半年一次」。家庭网络的攻击面=所有带密码的设备×所有家庭成员的点击习惯——设备侧「改默认」是地板，人的侧「防钓鱼」是天花板——两个都要铺。
