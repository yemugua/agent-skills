# 微信记录作劳动仲裁证据的完整打法

一句话：没有劳动合同、工资打现金、老板口头辞退——微信记录就是唯一的证据链。仲裁认可电子数据，但要求「完整载体 + 可验证身份 + 未篡改」。本技能按三类纠纷给取证与组织证据的模板。

## 一、仲裁要证明什么（按纠纷类型）

| 纠纷 | 需证明 | 微信证据的角色 |
|---|---|---|
| 欠薪 | 劳动关系存在 + 工资标准 + 欠付金额 | 聊天里的工资约定 + 催薪对话 |
| 加班费 | 加班事实 + 安排者 | 排班/要求加班的聊天 + 工作交付记录 |
| 违法辞退 | 解雇事实 + 由谁提出 | 老板辞退的原话（最关键的一条） |

## 二、劳动关系认定的证据组合（没合同时的闭环）

1. **微信工作群记录**——老板派活的对话（「明天去 XX 工地」「把方案改一下」）
2. **工作成果交付**——你发文件/照片/报告给老板的记录（带时间戳）
3. **工资发放痕迹**——老板个人微信转账备注「工资」；**现金发放时**，每月领钱的微信确认对话（「这个月 8000 收到」）
4. **考勤类**——请假审批、定位打卡截图的聊天记录
5. **证人**——同事的证言 + 同事的微信记录（佐证）

**最强补强**：仲裁前给老板发一条确认消息——「我 X 年 X 月到 X 月在店里上班，月薪 8000 对吧？」老板回复「对」或默认不否认 = 关系自认。

## 三、取证操作（照做）

1. **完整录像**：另一台手机逐屏录工作群 + 私聊（从群名、群成员列表开始，展示老板的微信昵称与头像）
2. **关键对话的上下文完整保存**：不要跳截——仲裁员看到断章取义会减信
3. **原始手机带上庭**：当庭翻阅演示；庭前不清理、不换机、微信不退出重登（聊天记录迁移有风险）
4. **老板身份锁定**：转账实名验证截图（输入姓氏验证那页）+ 微信号、手机号（起诉时申请法院调取实名）
5. **语音转文字并刻录**：关键语音保留原始文件 + 整理成文字稿（标注对应时间点）

## 四、催欠薪的取证话术（边催边取证的模板）

> 「老板，我 X 月-X 月工资共 X 元一直没发，家里等着用钱，这周能结一下吗？」
> ——要点：写清**期间 + 金额**，让对方在回复中确认数字。他回「再等等」 = 欠薪事实确认；回「没有这么多」 = 争议焦点清晰。

**千万别发**：情绪辱骂长文（对方拉黑 = 记录中断，且仲裁庭观感差）。

## 五、辞退证据的抢救（被口头辞退的 24 小时内）

1. 立即发消息确认：「老板，您今天让我明天不用来了，是公司辞退我吗？」——等书面回复
2. 不发、不签任何「个人原因辞职」的东西——辞职申请 = 补偿金归零
3. 工作交接前把个人证据全部导出备份（群文件、交接记录）
4. 继续正常打卡出勤到书面通知到达——对方不让进门 = 拍视频留证（拒绝提供劳动条件的证据）

## 六、仲裁申请书要点（微信证据部分怎么写）

证据清单格式：
> 证据三：微信聊天记录打印件 X 页（证明被告安排原告工作及欠薪事实）；原始载体当庭出示；附被告微信实名验证截图。

仲裁请求写法（欠薪）：
> 1. 裁决被申请人支付 2025 年 X 月至 X 月工资 X 元；2. 支付解除劳动关系经济补偿 X 元。

## 七、真实案例

> 案例：奶茶店员工被口头辞退，无合同，工资现金+老板微信转一部分。
> 证据链：工作群派班记录 3 个月 + 老板转账备注「工资」+ 辞退确认消息回复 + 同事证言。
> 结果：确认劳动关系 + 违法辞退 2N 赔偿成立。成本：仲裁 0 元，耗时 45 天。

## 红线
> ⚠️ 提醒：劳动仲裁的公式——「派工+交付+转账备注+催薪确认=关系闭环、口头辞退 24h 内文字确认、辞职申请别签字、原始手机上庭、语音配文字稿」。没合同不怕；怕的是你平时没留痕、被辞退时急着签字——两条都避开，微信记录就能顶上劳动合同。
