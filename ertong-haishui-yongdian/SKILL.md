带孩子下海前先看这条：绝大多数海边儿童溺水不是"游不动"，而是被离岸流带出去后家长在岸上才反应过来。本条给出离岸流识别、潮汐时间表查法和看护动作清单，出发前10分钟能过完。

## 一、离岸流：识别与自救（背下来再下水）

离岸流是从岸边垂直向海里冲的强水流，不会把人往海底拽，只会带离岸边——恐慌挣扎才是死因。

**识别三特征（站在岸上选下水点时看）**
| 特征 | 长什么样 | 判断 |
|---|---|---|
| 颜色异常 | 两侧浪都是白色碎浪，中间一条颜色更深/更浑浊的"平静通道" | 高度疑似 |
| 泡沫带 | 一条向外海延伸的泥沙色/泡沫带，与岸边垂直 | 高度疑似 |
| 浪形缺口 | 白浪带中明显断开一段，缺口处没有浪花 | 疑似 |

**自救口诀（教给孩子和家长各一遍）：平行游，不硬顶**
1. 不呼救不挣扎，仰漂或踩水保持呼吸，离岸流只向外推不往下拖；
2. 沿与海岸线**平行**方向游（垂直于流的方向），游出流带（一般宽10-30米）再折返游回岸；
3. 游不动就顺流漂，挥手喊救生员，离岸流末端会自然减速散开。

**算例**：孩子在离岸流里以约0.5-0.8米/秒被带出，普通成人横游1米/秒游20米只需20秒——平行侧游1-2分钟内必能脱离，硬顶向岸边游则永远不会前进。这句话就是让孩子先平行游的物理依据。

## 二、涨退潮时间表：下水前必查

| 项目 | 查法 |
|---|---|
| 官方潮汐表 | 微信小程序搜"潮汐表"或全球潮汐App，选当天海区 |
| 涨潮危险 | 涨潮时浪力增强、滩涂淹没加速，退潮后1-2小时离岸流最活跃 |
| 最佳下水窗口 | 平潮前后约1小时（涨退潮转换期，流速最弱） |
| 每日两个低潮 | 多数海区一天两次低潮，间隔约12小时25分钟 |
| 现场核对 | 看沙滩湿沙线位置拍照，1小时后再拍，后退快=退潮快，离岸流风险高 |

**算例**：潮汐表显示低潮14:10，则平潮窗口约13:40-14:40最安全；涨潮开始后滩涂面积每小时可缩30-50米——下午16:00你铺的帐篷、水桶、小孩玩沙区可能已被淹。看海还要看"潮汐+日落"：日落前1小时必须上岸。

## 三、浮潜与下水禁区

- **禁区清单**：礁石区（脚被海胆/礁石割伤高发）、渔船航道与排污口附近、防鲨网外、无救生员值守的野滩（红/黄旗禁下水）、退潮后裸露的滩涂深坑。
- **浮潜底线**：儿童浮潜必须1对1成人陪同且成人会游泳；面镜进水练习先在浅水（水不过腰）做3次；救生衣选有裆带款（无裆带款孩子会从领口滑出）。
- **看护站位**：看护人站在水里齐腰深处、面朝海面、离孩子不超过2米——坐在遮阳伞下"时不时抬头看"不算看护，溺水是无声的（不会喊救命）。
- **10-20-10法则**：每10分钟抬头清点一次人数，下海孩子全程佩戴袖标式浮具。

## 四、可复制的出发前检查清单

```
□ 查当日潮汐表（低潮时刻＋日落时刻）→ 定下水窗口
□ 确认海滩有救生员＋当日旗帜颜色（绿=可游，红=禁）
□ 站高处观察：有无平静深色通道/泡沫带 → 圈出离岸流区，离它50米外下水
□ 孩子救生衣带裆带并扣紧（拉不起为合格）
□ 约定走散集合点＝救生员瞭望塔
□ 教孩子一句话："被水推走就平行游/仰漂挥手"
□ 大人手机装防水袋，急救包（生理盐水/创可贴/碘伏）带至沙滩
```

## 红线
- 红旗海滩、雷雨、无救生员野滩，任何情况下不下水——"孩子非要玩"不是理由。
- 不允许孩子独自或只与同龄同伴下水，哪怕水只到膝盖：离岸流在膝深水中也能拖倒人。
- 溺水救援第一选择永远是呼救救生员＋抛浮具，不提倡不会救援的家长徒手下水—— double 溺水是海滩死亡第二大原因。
- 涨潮期间禁止让孩子在礁石滩/防波堤上逗留，涨潮封路型礁石每年都有人员被困。

> ⚠️ 提醒：下海前两件事必须做完——查潮汐表、肉眼扫一遍离岸流特征。孩子溺水是无声的30秒事件，看护人必须站进水里距孩子2米以内，坐下玩手机即视为放弃看护。
