# 老人手机简易模式与防诈设置

给父母手机做一次30分钟的"安全出厂设置"，比事后追被骗的钱有效一百倍。照下面清单逐项打勾。

## 一、字体与简易模式（5分钟）
| 设置路径 | 动作 |
|---|---|
| 设置→显示→字体大小 | 调到最大档 |
| 设置→显示→字体 | 换粗体字型 |
| 设置→桌面/特色功能→简易模式 | 开启（图标变大、常用应用只留4-8个） |
| 微信→我→设置→通用→字体大小 | 拉到最大并重启微信 |

## 二、钱的安全（10分钟，最关键）
1. **微信**：我→服务→右上角钱包→支付设置→关闭「自动续费」；我→服务→钱包→消费者保护→安全保障→关闭「免密支付」里所有小额免密项。
2. **支付宝**：我的→设置→支付设置→免密支付/自动扣款→逐个解约；关闭「小额免密」。
3. 银行卡：手机银行APP→安全中心→关闭「快捷支付免密」，单日转账限额调到500元（可临时上调）。
4. 通话：把子女号码存成「儿子」「女儿」并设专属铃声——冒充子女的电话立刻露馅。

## 三、防诈白名单（10分钟）
1. 手机管家→骚扰拦截→开启「拦截陌生号码」+ 标记库拦截。
2. **白名单**：常用联系人（子女/社区医院/物业）加入白名单，不被拦截误伤。
3. 国家反诈中心APP装好并开启「来电预警」；微信→设置→账号与安全→开启「声音锁」防盗用。
4. 关闭非必要APP的通知推送（尤其贷款、彩票类）。

## 四、远程协助（5分钟）
- 双方手机都装同品牌帐号或「远程协助」工具（如小米家人服务/OPPO屏幕共享）；子女绑定后可远程看屏幕指导操作。
- 相册开启自动备份到子女可见的共享相册，手机丢失照片不丢。

## 可复制《给爸妈的手机说明书》
> 1. 凡是要你**转账、验证码、屏幕共享**的电话，一律挂断打给我确认。
> 2. 验证码=钱，谁要都不给。
> 3. 「安全账户」「清退」「点赞返现」都是骗。
> 4. 拿不准就先按我发的录音键，或者直接来问。

## 红线
- 别只装反诈APP不关免密——多数老人被骗是**自动扣款/免密**环节失守，APP拦不住已授权的扣款。
- 别替老人保管密码到失能程度都不留记录——写密封信封交家庭第三人，比"问不出口"强。
- 别把「拦截陌生号码」开成「仅白名单可呼入」后不告知医生/快递——误拦报警电话和重要通知。

> ⚠️ 提醒：免密支付和自动续费是老人账户流失的头两口子，配完字体先关它们。
