# 病历复印与报销材料准备指南

一句话：住院一次要跑三次医院的根源是「出院时没拿全套」——病历、发票、清单、证明各有各的窗口。本技能给「出院当天一站拿全」的清单 + 补办路径 + 各类用途（保险/仲裁/伤残鉴定）的材料组合。

## 一、出院当天一站拿全清单（打印带去照办）

- [ ] **出院小结/出院记录**——出院时主治医生打印（最重要：诊断+治疗经过+医嘱）
- [ ] **发票原件**——住院处结算窗口（医保分割的部分要「医保结算单」）
- [ ] **费用总清单**——一日清单的汇总版（收费处）
- [ ] **诊断证明书**——医生开+医院盖章（保险理赔/请假的核心件）
- [ ] 医保结算单（用了医保的）
- [ ] 检查报告：CT/MRI/病理报告（科室或自助机打印）
- [ ] 出院带药清单与医嘱说明

**一个窗口提示**：病案室（病历复印）通常出院后 **7-15 天**才能归档复印——出院当天拿不到全套病历是正常的，但**出院小结和发票当天必须拿**（后续一切的基础）。

## 二、病历复印（出院 1-2 周后回院一次）

**带**：患者身份证 + 代办人身份证 + 关系证明（户口本/委托书）
**地点**：病案室（多数医院在门诊楼）
**要什么**：
- 「复印病历全部」——含入院记录/手术记录/护理记录/检查报告/出院小结
- 每页加盖**病案管理专用章**（红色骑缝章——无章的复印件保险/法院不认）
- 费用：按页收费（0.3-1 元/页）+ 复印申请单

**用途选择复印内容**：
| 用途 | 必须包含 |
|---|---|
| 商业保险理赔 | 全部（重点：入院记录+出院小结+病理） |
| 医保手工报销 | 结算单+发票+清单（不用复印病历） |
| 劳动仲裁/伤残鉴定 | 手术记录+医嘱+休息建议（误工期依据） |
| 二诊 | 出院小结+关键检查报告（够用且省复印费） |

## 三、报销材料组合（按场景）

**医保手工报销（异地未直接结算）**：发票原件 + 费用清单 + 出院小结 + 医保卡/备案记录
**商业医疗险**：发票原件（或医保分割单）+ 费用清单 + 病历（盖章）+ 诊断证明 + 理赔申请书
**意外伤害（含第三方责任）**：上述全部 + 事故证明（公安/单位/物业出具）
**重疾给付**：病理报告/确诊证明（病种名称与条款比对）+ 病历

## 四、补办路径（出院后才发现缺件）

| 缺件 | 补办处 | 提示 |
|---|---|---|
| 发票原件丢失 | 收费处→发票存根复印件盖章（可报销但部分保险要原件——及时补申请「遗失证明」） | 最难补的是它——出院当天拿好 |
| 诊断证明 | 主治医生门诊/病案室 | 需复诊或凭病历补开 |
| 病历 | 病案室随时可补 | 患者本人永久可调 |
| 医保结算单 | 医保窗口/APP 下载电子版 | 电子版多数场景可用 |

## 五、家庭医疗档案制度（长期价值）

- 每次住院出院后归档：一个文件夹（按人）——发票原件、盖章病历、诊断证明、结算单
- 电子备份：全部扫描/拍照存云盘（原件丢失时有一手凭据）
- 慢性病/重疾的连续病历 = 保险投保告知、理赔因果链、伤残鉴定的基础——**病历是你医疗权益的原始股**

## 红线
> ⚠️ 提醒：病历的公式——「出院当天先拿小结+发票+诊断证明、病历归档后 7-15 天去病案室盖骑缝章、按用途选复印内容、发票原件是补办最难件、家庭医疗档案按人归档」。医院的材料不是「要的时候再回去拿」——是出院那一刻就该打包的资产；缺一张纸，理赔就多跑一趟。
