# 扫描件文字识别（OCR）实操路线

一句话：扫描件 = 图片型 PDF，复制不了文字；OCR 的选择标准 = 手写体识别率 + 表格还原能力。本技能按文件类型给最优免费路线。

## 一、文件类型 → 工具路线

| 文件类型 | 首选 | 识别要点 |
|---|---|---|
| 印刷体文档 | 微信小程序「传图识字」/白描 | 免费额度内基本全对 |
| 表格（报表/清单） | WPS「图片转表格」/白描表格模式 | 表格线还原是关键 |
| 手写体（签名/手写备注） | 白描/百度网盘 OCR | 手写识别率 70-90%，需人工校对 |
| 证件（身份证/银行卡） | 手机自带扫描或证件识别小程序 | **敏感信息，离线处理** |
| 合同盖章件 | WPS/福昕 OCR | 印章区域文字易漏，人工补 |

## 二、微信传图识字（最易上手）

1. 微信 → 搜索小程序「传图识字」→ 拍照/相册选图
2. 识别 → 选中文字 → 复制/导出 Word
3. **免费额度**：每日若干次，个人日常够用
4. 弱点：整页长文档分页麻烦 → 多页文档用 WPS 路线

## 三、白描 App（多页与表格最强免费）

1. 白描 → 批量识别 → 选多张扫描图
2. 输出可选：纯文本/Word/Excel（表格模式）
3. 表格模式对报表还原度显著高于通用 OCR
4. 免费额度：每日限制次数，重度使用看会员（约 60-100 元/年）

## 四、电脑端批量路线（大量文件）

WPS PDF 工具 → PDF 转 Word（OCR 模式）→ 批量转换。
免费额度有限时的替代：福昕 PDF 阅读器 OCR 插件（部分免费）。

## 五、校对铁律（OCR 不是 100% 准）

- **数字必须逐个核对**（金额/日期/号码——OCR 对 0/O、1/l、6/8 混淆率高）
- 身份证号/银行卡号/合同金额：OCR 结果与原图逐字比对
- 表格数值错位的连锁错误：错一格毁一整张报表
- 重要文件的双人校验：一人读原图、一人查识别稿

## 六、敏感文件的处理铁律

- 身份证/银行卡/病历 → **离线 OCR**（手机自带扫描、WPS 本地），不走在线小程序
- 确需在线时：先遮住关键号码段，识别完立即删除云端副本
- 识别后的电子稿含敏感信息：加密存储或仅存本机

## 七、真实案例

> 场景：50 页手写笔记转电子稿。
> 路线：白描批量识别（手写模式）→ 导出 Word → 人工校对数字与专有名词 → 2 小时完成。
> 对比：手工打字约 10 小时。成本：0-100 元。

## 红线
> ⚠️ 提醒：OCR 的公式——「印刷体用小程序、表格选专用模式、手写必须人工校、数字逐个核、证件离线处理」。OCR 省的是打字时间；省不掉的是校对——识别率 95% 的意思，是每 20 个字有 1 个要你自己抓出来。
