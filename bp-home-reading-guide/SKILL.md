一句话：家里量的血压不能直接套医院标准，先按规范测够7天，再用分级表决定是观察还是就诊。

## 一、测量规范自检（不达标读数作废）

| 检查项 | 合格标准 |
|---|---|
| 测前静坐 | 安静休息≥5分钟，30分钟内无咖啡/烟/运动 |
| 姿势 | 坐位，背有靠，双脚平放，袖带与心脏同高 |
| 袖带 | 下缘距肘窝2-3cm，能伸进1-2指 |
| 次数 | 早晚各1次×连续7天，每次间隔1分钟测2遍取均值 |
| 剔除 | 第1天读数不纳入统计 |

## 二、家庭自测分级表（≥135/85 即相当于医院140/90）

| 家庭均值 | 判定 | 动作 |
|---|---|---|
| <120/80 | 正常 | 每年复测1个周期 |
| 120-134/80-84 | 正常高值 | 3-6个月复测，限盐<5g/天 |
| 135-139/85-89 | 1级临界 | 连续复测2周，仍超标则就诊 |
| ≥140/90 或 任意一次≥180/110伴症状 | 高血压/急症 | 立即就诊；急症直接急诊 |

## 三、就医与随访费用测算（参考价，各地浮动±30%）

- 首诊：挂号25-60元 + 心电图20-40元 + 血常规/肾功能/电解质约80-150元。
- 动态血压监测（24h ABPM）：150-300元，医生怀疑"白大衣高血压"时必做，避免吃一辈子药。
- 首年服药随访：普通降压药（氨氯地平/缬沙坦集采价）约10-30元/月，按月复查挂号+部分化验约60-100元/次 → 全年药费+随访约600-1200元。
- 对比：不监测直接吃10年药，即使药免费，漏诊继发性高血压（肾性/原发性醛固酮增多症，检出率约5-15%）可能白吃药——首诊查全套餐是省钱的。

## 四、给医生看的7天记录模板（直接抄）

```
11/18  142/88  138/85    145/92  141/89    未服药; 夜班
...
7天均值：早 / ，晚 /
```

## 五、常见误判

- 腕式血压计未与心脏同高 → 读数偏差可达10mmHg；上臂式为准。
- 只在头晕时量 → 高血压多数无症状，读数不代表平时水平。
- 一次偏高就吃药/紧张 → 先按规范测满7天再定。
- 自行停药后复测"正常" → 停药后需观察4周以上才算真实血压。

## 红线

> ⚠️ 提醒：任意一次收缩压≥180或舒张压≥110并伴头痛、视物模糊、胸闷、肢体无力，立即急诊，不要在家观察；已服药者勿凭自测调药或停药，调整方案必须由医生做。
