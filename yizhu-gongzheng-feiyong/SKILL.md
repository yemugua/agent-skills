# 遗嘱公证 vs 自书遗嘱：效力与费用对照

一句话：公证遗嘱不再是效力优先（民法典已删掉公证优先条款，以最后一份有效遗嘱为准），选哪种形式的核心变量是「被挑战的概率」和「公证费/律师费差价」。

## 一、四种形式对照表

| 形式 | 成本 | 效力风险点 | 适合谁 |
|---|---|---|---|
| 公证遗嘱 | 公证费各地约200-600元（多份财产另加；70岁以上多数地方减免） | 程序最规范，被挑战概率最低 | 财产复杂/家庭关系紧张 |
| 自书遗嘱 | 0元 | 全文亲笔+签名+注明年月日，缺一项即可能无效 | 财产简单、字迹稳定 |
| 代书/打印遗嘱 | 0元 | 需两名以上无利害关系见证人全程在场签名注日期；打印遗嘱司法实践最易翻车 | 有可靠见证人 |
| 律师见证/遗嘱库 | 1000-5000元 | 见证程序留痕，介于两者之间 | 想低成本留证据 |

**算例**：一套自住房+存款50万的普通家庭——自书遗嘱0元 vs 公证约400元：自书若因见证瑕疵被判无效，按法定继承走，可能多出继承公证费（继承公证按受益额比例，50万标的约收费数千元）+诉讼费（遗产诉讼按标的额收取，50万约8800元受理费）+至少半年周期。400元公证费是全套流程里最便宜的保险。

## 二、自书遗嘱的最低合规模板（抄用）

```
遗嘱（全文手写，一气呵成，勿打印后签字）

立遗嘱人：___，身份证号___，立遗嘱时神志清醒。
我名下财产：①___房产（产权证号___）；②___银行存款。
本人自愿订立遗嘱如下：
一、上述房产由___（身份证号___）一人继承。
二、存款由___继承。
本遗嘱一式__份，由___保管。

立遗嘱人（亲笔签名）：
2026年__月__日
```

三个失效高发点：①打印后只签名（打印遗嘱必须两名见证人+每页签名注日期）；②日期不全（只写年不写月日有判例认定无效）；③处分了不属于自己的财产（如只有夫妻共同财产的一半份额）。

## 三、费用全景（身后被继承时才发生的对照）

| 环节 | 有公证/自书有效遗嘱 | 无法定有效遗嘱（法定继承） |
|---|---|---|
| 继承权公证/不动产登记 | 依遗嘱办理，费用低（多地不动产继承登记已免公证费） | 需全体继承人共同办理或公证，收费与摩擦成本高 |
| 诉讼费（若有争议） | 罕见 | 8万以下50-100元起、按标的额阶梯至1.5%+ |
| 周期 | 1-3个月 | 3个月-2年 |

**房产继承再加一笔**：法定继承或遗嘱继承取得均免契税，但转让时非法定继承情形（遗嘱继承视同受赠）再出售需按受赠路径计税（满五唯一等规则适用差异）——遗产房「先继承后出售」的税费规划应在立遗嘱阶段就问清楚。

## 四、可复制的沟通话术（说服老人立遗嘱）

> 「公证遗嘱约400元、当天办完，把房子和存款写清楚，将来不过户吵架、不打官司；不写的话按法律顺序分（配偶、子女、父母同为第一顺序），可能不是您想的那样。」

## 红线

| 红线 | 后果 |
|---|---|
| 打印遗嘱无两名见证人全程签名注日期 | 高概率被认定无效 |
| 遗嘱日期缺失或不完整 | 有判例直接判无效 |
| 处分配偶共有财产的全部 | 一半处分无效 |
| 以为公证遗嘱永远优先 | 民法典后以最后有效遗嘱为准，多份并存需逐份核日期 |
| 见证人由受益人或其亲属担任 | 见证无效，遗嘱形式要件不齐 |

> ⚠️ 提醒：多份遗嘱并存时按民法典第1142条以「最后的遗嘱」为准，但每份都要各自满足形式要件；涉及房产/家庭复杂的，花几百元公证费换程序确定性是性价比最高的选择，自书遗嘱务必全文手写+完整日期+妥善保管原件。
