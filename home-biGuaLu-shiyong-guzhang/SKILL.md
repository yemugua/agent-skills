# 壁挂炉的使用技巧与常见故障

壁挂炉的模式理解（采暖/热水/防冻）、温度与节能的设置、水压的监控与补水、常见故障码的处理、年度保养的项目、燃气安全、夏季模式的切换。

## 操作路径
1. **模式认知**：冬季档——采暖+热水双开（地暖/暖气片的联动）；「夏季档」——只供热水（采暖循环停——「夏天也烧地暖」的设置失误）；「防冻档」——长期出门的低温保护（5-10℃ 的循环防冻——关炉空房的冻裂风险）。
2. **节能设置**：采暖温度——地暖 40-50℃/暖气片 60-70℃ 的出水温（越高越费的锅炉逻辑）；「室温」——18-20℃ 的目标+分时段（白天低温+回家升温的编程）；「热水温」——45-50℃ 的舒适+节能（「调到最高」的烫伤与浪费）；「ECO 模式」——壁挂炉的节能档位。
3. **水压管理**：标准——1-1.5bar 的运行区间（<0.8 补水、>2.5 泄压）；「补水操作」——底部补水阀的缓慢开（压力到 1.2 即关——「补到爆表」的泄压狼狈）；「频繁掉压」——漏水/膨胀水箱失压的排查（月月补水的异常信号→报修）。
4. **故障码处理**：E1 类点火失败——查燃气阀/气量/表电池（见热水器代码条目的同源逻辑）；「E2 过热」——复位+散热（重复出现的清洗信号）；「水压故障」——补水复位；「复位原则」——一次复位无效即报修（反复重启的恶化避免）。
5. **保养与安全**：年度保养——燃烧室清洗+换热器除垢（供暖季前的 8-9 月最佳档期——200-400 元的保养比大修便宜）；「燃气安全」——软管年检+通风（见燃气条目）；「烟管」——排烟口的堵塞检查（鸟窝/积雪的冬季检查）；「寿命」——10-15 年的换新评估。

## 避坑红线 ⚠️
- 「出水温调最高」——能耗翻倍+干烫；按系统类型设定。
- 补水补到 2bar+——泄压阀喷水的现场；1.2bar 即停。
- 长期出门直接关炉——管道冻裂的风险；防冻档。

## 效果验收
三模式切换；节能温度表；补水标准操作；故障码的一次复位原则；年度保养档期。

补水 0 元；年度保养 200-400 元；壁挂炉的节能账——出水温从 75 降到 55℃，燃气费能降 15-25%；调温就是调钱。
