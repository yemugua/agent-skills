# 家庭急救箱配置清单

一句话：家庭急救箱的目标不是「治百病」，是「撑住去医院的路上」——止血/退热/抗过敏/外伤处理四类够用，多了反而乱。本技能给标准配置 + 效期管理 + 真正的急救动作清单。

## 一、标准配置清单（按功能四类）

### 1. 外伤处理
- [ ] 碘伏棉签（独立包装）——伤口消毒首选（酒精痛且伤组织）
- [ ] 无菌纱布/纱布块 + 医用胶带
- [ ] 创可贴（大小规格）
- [ ] 弹性绷带（扭伤加压）
- [ ] 三角巾（悬吊/固定）
- [ ] 一次性手套 ×2 副
- [ ] 剪刀/镊子（独立包装）
- [ ] 生理盐水（冲洗伤口/眼部）
- [ ] 烧伤凝胶/烫伤膏（磺胺嘧啶银类遵医嘱；家庭备凡士林纱布应急）

### 2. 常用药品（按说明书使用）
- [ ] 退热：布洛芬（成人+儿童混悬液两版）/ 对乙酰氨基酚
- [ ] 腹泻：口服补液盐（最重要且最被忽视！）+ 蒙脱石散
- [ ] 抗过敏：氯雷他定/西替利嗪（口服）；肾上腺素笔仅限有严重过敏史者（遵医嘱）
- [ ] 胃肠：铝碳酸镁（胃酸）/ 开塞露（应急）
- [ ] 外用：氢化可的松乳膏（轻度皮炎）/ 炉甘石（瘙痒）

### 3. 器械与工具
- [ ] 体温计（电子/额温）
- [ ] 血压计（家有老人的必配）
- [ ] 血糖仪（糖尿病家庭）
- [ ] 手电筒（瞳孔检查+停电）
- [ ] 急救卡（家庭成员过敏史/慢病/用药——写好放箱内）

### 4. 应急联络信息
- [ ] 120/110/119/燃气 96777
- [ ] 家庭医生/常就诊医院电话
- [ ] 邻居/紧急联系人

## 二、药品效期管理（一半的家庭药箱全是过期药）

- **每半年一次清点**：固定日期（如 6 月/12 月的第一个周日）——过效期的全部处理（药店回收点/社区回收，不乱扔）
- 眼药水开封后 **28 天**失效（瓶身写开封日期）
- 糖浆开封后按说明书（通常 1-3 月）
- 需冷藏的（胰岛素等）单独管理
- **清点动作清单**：看效期 → 看开封日期 → 看性状（变色/浑浊/结块=扔）→ 补缺（按上表）

## 三、真正的家庭急救动作（药箱救不了的靠这个）

| 场景 | 正确动作 | 红线 |
|---|---|---|
| 烫伤 | **冷水冲 15-30 分钟** → 剪开覆盖物 → 干净纱布盖 → 送医 | ❌牙膏酱油冰块；❌挑水泡 |
| 流鼻血 | 低头前倾+捏鼻翼 10 分钟 | ❌仰头（血咽下去）；持续 20 分钟不止就医 |
| 呛噎（成人/儿童） | 海姆立克（网购教学视频现在学） | 呛水呛奶婴儿的拍背压胸法不同——分龄学 |
| 扭伤 | 停止活动+冰敷 48h 内 | ❌立刻揉搓热敷（48h 后才热敷） |
| 癫痫发作 | 移开危险物+侧卧+计时 | ❌往嘴里塞东西；❌按住肢体；>5 分钟打 120 |
| 心梗疑信号（胸痛+冷汗+左臂放射） | 停止活动+半坐位+120+嚼阿司匹林（无禁忌时） | ❌自己开车去医院 |

**急救技能的性价比**：海姆立克 + 心肺复苏（CPR）——社区红十字会/急救中心有免费培训（半天拿证）；这两项技能的期望价值超过整个药箱。

## 四、存放原则

- 位置：全家知道+孩子够不到+阴凉干燥（**卫生间湿度大——别放卫生间**）
- 分层：外伤层/药品层/器械层（标签）
- 外出版：旅行小药包（退热+止泻+创可贴+晕车药+常用药 3 天量）

## 五、真实场景

> 案例：孩子深夜高热 39.2，家庭药箱有儿童布洛芬混悬液 → 按体重给足剂量（**按体重不是按年龄**——说明书查）→ 物理降温+补水 → 天亮退烧门诊。
> 反例：药箱只有成人药片，掰半喂错剂量——**儿童剂型是药箱的必配项**。

## 红线
> ⚠️ 提醒：急救箱的公式——「四类配置（外伤/退热/补液/抗过敏）+儿童剂型、半年清点效期、眼药水开封 28 天、烫伤冲 30 分钟不涂牙膏、补液盐是最被低估的救命药、海姆立克和 CPR 去学免费课、急救卡写过敏史」。急救箱的终极用途是「买时间」——配置对了+动作对了，120 到达前的每一分钟都是你挣来的。
