# 家务劳动补偿：民法典1088条，全职一方离婚时真能拿到钱

《民法典》第1088条（2021年生效）规定：一方因抚育子女、照料老人、协助另一方工作等负担**较多义务**的，离婚时有权请求补偿。这是对「隐形付出」第一次给出可执行请求权——全职主妇/主夫、承担大部分家务的一方，离婚时**必须主动提，法院不主动判**。

## 三个关键规则

| 问题 | 规则 |
|---|---|
| 谁能要 | 负担较多家务/育儿/赡养义务的一方，不限于全职（上班族承担主要育儿也可主张） |
| 何时提 | **离婚时（诉讼中或协议中）明确提出**；未登记结婚的同居关系不适用 |
| 和财产分割什么关系 | 1088补偿是**额外的**，不影响共同财产均分，也不以对方「有错」为前提 |
| 是否需要婚内AA | 旧婚姻法时代要求「分别财产制」才可主张，**民法典已删除该限制**——共同财产制下同样可要 |

## 判例金额对照（真实裁判尺度）

| 案件情形 | 判赔金额 |
|---|---|
| 北京全职太太，婚5年，2孩（2021年全国首案） | 5万元 |
| 婚龄10年+、全职育儿+照顾老人 | 8-15万元区间 |
| 双方均上班但一方承担绝大部分家务育儿 | 2-5万元 |
| 协议离婚中双方自行约定 | 无上限，谈多少给多少 |

现实尺度：法院判赔**远低于家务的市场替代成本**（一线城市育儿嫂月薪7000-10000元），但有总比没有强——10年全职婚龄主张10-15万是可达目标，主张50万不现实。

## 举证清单（离婚前就开始攒）

- 日常记录：微信家庭群聊天记录（谁排孩子的课、谁约疫苗、谁管老人就医）
- 消费记录：为孩子/老人/家庭的订单截图（奶粉、学费、药品、家政替代支出）
- 时间证据：辞职证明、简历断档说明、班主任/家长群聊天身份截图
- 对方加班出差记录（作为己方承担家务的对照）
- 证人：父母、邻居、老师的证言或出庭

## 可复制的诉讼主张模板

> 原告与被告婚姻关系存续__年，其间原告承担子女日常照护、接送就学、老人陪诊及家庭日常劳务，被告长期加班出差、未参与上述义务。依据《民法典》第1088条，请求被告支付家务劳动补偿人民币__元（参照本地家政劳务市场价格及原告投入年限酌定）。

协议离婚版：「双方确认，因__方婚姻存续期间承担较多家庭义务，__方自愿一次性支付家务劳动补偿__元，于离婚登记完成之日起__日内支付。」——写进离婚协议才有强制力。

## 红线

> ⚠️ 提醒：①**诉讼时效即离婚时**——离完婚再单独起诉1088补偿，法院一般不再受理，务必在离婚程序内提出；②金额预期要克制：判例集中在2-15万，按婚龄、子女数、当地收入合理主张，虚高会被法官直接往下压；③补偿与「离婚损害赔偿」（1091条，对方有重大过错）是两回事，可同时主张、分别举证；④全职期间也别放弃社保与个人账户资金安全，补偿款是补偿不是养老，长期保障要另行安排（个人养老金/自己续缴灵活就业社保）。
