一句话：肝功能报告的判读钥匙是"ALT升高倍数"——2倍以内多半可观察复查，5倍以上必须尽快就医，别被单项箭头吓到。

## 一、四组指标先分组

| 分组 | 指标 | 说明 |
|---|---|---|
| 肝细胞损伤 | ALT、AST | 最敏感；AST/ALT>2提示酒精性倾向 |
| 胆管淤积 | ALP、GGT | GGT单独高常见于饮酒/脂肪肝 |
| 排泄功能 | 总/直接胆红素 | 单独间接胆红素高=Gilbert体质，无碍 |
| 合成储备 | 白蛋白、PT | 低=长期/重症信号 |

## 二、按升高倍数分级（ULN=化验单参考上限）

| ALT/AST | 判定 | 动作 |
|---|---|---|
| <2×ULN | 轻度 | 排除诱因后4-8周复查，多数回落 |
| 2-5×ULN | 中度 | 2周内消化科/肝病科就诊，查病因 |
| >5×ULN 或 胆红素>2×ULN且上升 | 显著 | 尽快就诊（1-3天内） |

## 三、复查费用测算（参考价，±30%）

- 肝功能全套：40-80元/次。
- 轻度异常排查包：肝功能+乙肝两对半(60-100元)+腹部超声(100-150元) ≈ 200-330元。
- 加丙肝抗体约40元、血脂约50元——脂肪肝是国内ALT轻度升高第一原因。
- 诱因排查后再复查一次全套≈50元，轻度路径总成本约300元封顶。

## 四、居家排查清单（复查前先做，直接抄）

```
复查前4周自查：
□ 熬夜/剧烈运动(赛前查血常假性升高)
□ 新增保健品/中草药/抗生素/他汀
□ 每周饮酒量：____次×____ml
□ 体重/BMI：____（脂肪肝自查）
□ 甲减/肌病既往史(AST可来自肌肉)
```

## 五、易踩的坑

- 体检前一天健身：剧烈运动可使ALT假性升高数倍，先休息3天再复查。
- 见"升高"就吃"保肝药"：病因不明时乱吃反而增加肝负担。
- GGT单独高=肝癌：多为饮酒/药物/脂肪肝，超声无异常即可观察。
- 间接胆红素略高就查半天：Gilbert综合征人群约5-10%，属良性。

## 红线

> ⚠️ 提醒：ALT>5×ULN、胆红素持续上升、伴眼黄尿黄如浓茶/乏力明显/腹胀，按急性肝损伤处理1-3天内就诊；正在服用可能伤肝药物（他汀、抗结核、中草药）期间指标升高，先报开药医生再决定停不停，勿自行停药。
