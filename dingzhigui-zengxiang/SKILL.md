# 定制柜增项清单：报价单逐项审出隐形单

一句话：定制柜低价吸引下单、增项收回来20-30%是行业常态——报价单里「详见门店」「按实际结算」的字样就是增项埋伏点。

## 一、计价方式先分清（最大坑）

| 方式 | 算法 | 坑点 |
|---|---|---|
| 投影面积 | 柜宽×柜高，几百元/㎡ | 看着便宜；**层板/抽屉/五金全另算** |
| 展开面积 | 每块板展开算，单价低 | 报价低但总展开大，最终价反超；隔板越多越贵 |
| 按件计价 | 整柜一口价 | 最透明，适合标准柜体 |

谈价时要求商家**按你的实际图纸出整柜一口价**，写进合同「总价含以下全部配置清单」。

## 二、常见增项行情价表

| 增项 | 合理区间 | 套路价 |
|---|---|---|
| 抽屉 | 150-300元/个 | 400-600元/个 |
| 铰链/滑轨升级（阻尼） | 20-50元/个 | 100元/个起 |
| 见光板（柜体侧板） | 按板价100-200元/㎡ | 300-400元/㎡「必加」 |
| 顶柜延伸/包梁柱 | 按实际板材 | 一口价含进去本可谈 |
| 上门量尺 | 正规免费 | 收「定金抵量尺费」绑定下单 |

## 三、报价单审查清单（逐项打勾）

- [ ] 计价方式+总价封顶写明
- [ ] 板材品牌/等级（ENF/E0）/封边工艺三个字样齐全
- [ ] 五金品牌型号写明（百隆/海蒂诗 vs 杂牌差价3-5倍）
- [ ] 「见光板/抽屉/阻尼铰链」是否含在总价
- [ ] 安装费/上楼费/运输费=0 或写死金额
- [ ] 付款节奏：预付≤50%，验收合格再付尾款（全款预付=丧失所有谈判筹码）

## 四、算钱案例

25㎡衣柜：报价「投影699/㎡」=17,475，看着比同行899便宜2500——展开算完抽屉6个×400+见光板3㎡×350+阻尼铰链升级=+4,650元，实际22,125元。逐项审进一口价合同后实付18,900元。

## 红线
> ⚠️ 提醒：合同总价封顶+配置清单是唯一防线，口头「都包含」无效；预付不超过50%，尾款绑定安装验收；「按实际结算」四字出现必追问封顶价。
