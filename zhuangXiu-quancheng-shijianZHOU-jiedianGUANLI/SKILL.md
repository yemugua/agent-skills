# 装修全程时间轴与节点管理

一句话：装修拖期的根源是「工序串行错误」——别人等你、你等别人、材料迟到的三层等待。本技能给毛坯到入住的 4-6 个月标准时间轴 + 每阶段的主动动作清单。

## 一、总时间轴（100㎡ 半包/全包通用框架）

```
M0    定方案：量房→设计→报价对比→签合同（3-4 周，可与下阶段并行准备）
M1    拆改+水电：拆墙 3-5 天 → 水电 10-15 天（含验收）
M2    泥瓦：防水+闭水 5 天 → 贴砖 12-18 天
M3    木工+油漆：吊顶柜体 10-15 天 → 腻子乳胶漆 10-15 天
M4    安装期：橱柜/地板/门/卫浴/灯具/开关面板（15-20 天，多工种交叉）
M5    软装+保洁：家具家电进场 → 开荒保洁 → 通风散味
入住   检测达标后（通风建议 1-3 个月，急住可治理）
```

**关键路径**：水电→泥瓦→木工→油漆→安装——前一道不验收后一道不开工；「等」的最大浪费在「材料没订好等材料」。

## 二、每阶段的主动动作（业主别只等）

### M1 水电阶段（最容易出错的阶段）
- [ ] 点位图签字（见水电合同条目）
- [ ] 中央空调/新风/地暖的**进场顺序**在这阶段定——它们和水电是交叉施工，晚定=返工
- [ ] 水电验收+拍照存档+索要走向图

### M2 泥瓦阶段
- [ ] **瓷砖订货提前 15 天**（贴砖开始时到场——断货的等待最常见）
- [ ] 地漏/角阀/挡水条下单（泥工要埋）
- [ ] 防水闭水试验到场（楼下确认）
- [ ] 铺贴方案确认：瓷砖排版图（大砖对缝/波打线）——贴完不满意拆不了

### M3 木工油漆阶段
- [ ] **定制柜复尺**（贴砖完成后精确复尺——提前定是毛尺寸）
- [ ] 乳胶漆色号确认（小样上墙看光线下效果，别看色卡）
- [ ] **灯具/开关面板/洁具下单**（安装期要到货）

### M4 安装期（交叉与衔接的高发期）
- [ ] 安装顺序：橱柜→台面→卫浴→地板→门→灯具→开关→保洁
- [ ] 地板与门的先后之争：先门后地板（门压地板收口）或先地板后门（收口条）——问装门师傅要哪一种
- [ ] 每项安装验收（划痕/缝隙/功能）——安装完签字
- [ ] **尾款留到全验收后**（合同写明）

### M5 软装散味
- [ ] 开荒保洁在安装全部完成后
- [ ] 通风策略：高温高湿关窗闷放+开窗循环交替（甲醛释放加速法）；工业风扇对流通风
- [ ] 检测：CMA 机构检测（500-1,500 元）达标再入住——自测盒不作为依据
- [ ] 新家具（定制柜）是甲醛大头——空房通风重点是「关柜门」

## 三、材料下单时间表（等待即拖期）

| 材料 | 下单时点 | 原因 |
|---|---|---|
| 中央空调/新风/地暖 | M0 签合同后立即 | 水电前必须进场 |
| 定制柜 | M1 结束前 | 生产周期 30-45 天 |
| 瓷砖 | M1 中 | 到货 7-15 天 |
| 木地板/室内门 | M2 中 | 生产+到货 30 天+ |
| 洁具/灯具/开关 | M3 中 | 安装期要到货 |
| 窗帘/家具/家电 | M4 | 软装期 |

## 四、工期的合同保护

- 合同写明总工期+延期违约金（常见 100-300 元/天，封顶条款看清）
- 「甲方原因延期」：自己改主意/材料（自购部分）迟到——**自购材料按时间表下单就是保护自己**
- 每阶段验收单签字时注明日期（工期核算的凭据）
- 变更管理：任何改动书面确认+注明「工期影响天数」

## 五、真实拖期案例与教训

> 案例：贴砖完成等定制柜，柜子晚到 25 天 → 油漆工空档 → 整体延后 1 个月。
> 根因：定制柜 M2 才下单（应在 M1 结束前）。
> 教训：**装修拖期的主因从来不是工人慢；是业主下单慢**——材料时间表贴在冰箱上。

## 六、给不同人群的工期预期

- 精装房改造（局部）：1-2 个月
- 毛坯全包：4-5 个月施工+1-3 个月通风
- 二手房全拆重装：5-7 个月（拆除+老管线处理多一周级）
- 急住方案：简化定制（成品柜替代）+ 治理除醛（专业公司 3,000-8,000）压缩至 2-3 个月——预算换时间

## 红线
> ⚠️ 提醒：装修的公式——「四阶段串行验收不过不开工、材料按表提前订、定制柜 M1 下单是铁律、甲醛通风不能压缩、工期违约金写进合同、每阶段验收签字注日期」。装修管理的本质是「排队论」——你多管一天排期，工期少拖一周；你少下一次单，工期多拖十天。
