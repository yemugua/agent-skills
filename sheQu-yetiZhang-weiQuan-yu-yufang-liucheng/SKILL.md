# 小区电梯故障与物业维修基金的启用流程

# 小区电梯故障维权与维修基金启用

一句话：电梯坏了不动，根源九成是「维修基金动不了」——启用需要业主表决/公示/审计三道流程，物业嫌麻烦就拖。本技能给催修路径 + 维修基金启用流程 + 电梯安全的追责依据。

## 一、先分清：谁来修、谁出钱

| 情形 | 责任主体 | 资金来源 |
|---|---|---|
| 日常维保（15 日一次的法定维保） | 物业+维保公司 | 物业费 |
| 小修小换（千元内） | 物业 | 物业费/公共收益 |
| 大修/改造/换梯（万元+） | 全体业主 | **专项维修基金** |
| 质保期内 | 电梯厂商/安装方 | 质保金 |
| 人为损坏 | 责任人 | 责任人自付 |

**法定维保**：电梯每 15 日至少一次维保（《特种设备安全法》）——维保记录在轿厢内公示栏可查，**记录缺失=物业失职的直接证据**。

## 二、电梯故障的催修路径（按强度递进）

1. **书面报修**：物业客服书面（微信+纸质）报修——记录故障现象+时间，要求**答复处理时限**
2. **96333 电梯应急**：困人时先打救援（不是 110/119 的首选——电梯困人专业救援更快）
3. **12345 + 市场监管局特设科**：电梯归市场监管部门管（特种设备）——维保缺失/带故障运行的投诉直接到特设科，**这条最痛**（特设检查是企业的红线）
4. **业委会**：推动物业启动维修程序/约谈维保公司
5. **业主联名**：20% 业主签名可要求业委会/物业召开业主大会表决维修事项

## 三、维修基金启用流程（大修的关键）

```
物业/业委会提出使用方案（维修内容+预算+施工方报价）
 → 公示 7 日（征求意见）
 → 业主表决（双 2/3：专有面积 2/3 且人数 2/3 参与表决；同意数过参与数过半）
 → 报住建部门/维修基金管理中心审核
 → 施工 → 验收 → 结算公示
```

**常见卡点与解法**：
- 「表决凑不齐人」→ 线上表决（多数城市政务 APP 支持业主大会电子表决）+ 楼栋长逐户收权
- 「基金余额不足」→ 续筹（按面积分摊）或公共收益补充（电梯广告费本来就是干这个的——见物业费条目）
- 「物业说流程复杂不动」→ 12345 督办 + 住建部门咨询（管理中心有指导义务）

## 四、电梯安全的追责依据（事故/频繁故障时）

- **检验标志**：轿厢内《特种设备使用标志》——有效期过了还运行=违法运行，投诉必处理
- **维保记录**：15 日维保公示——缺失=物业+维保公司双失职
- 困人事故：救援时间（法定 30 分钟内抵达）、事后故障原因书面说明——业委会有权要求
- 伤害事故：取证（现场照片/监控调取/就医记录）→ 追责顺序：维保公司（维保不当）→ 物业（管理失职）→ 保险公司（特种设备责任险）

## 五、业委会缺位小区的替代打法

- 楼栋业主群共识 → 联名书面（20% 签名）→ 直接向街道/社区反映（社区对物业有协调权）
- 12345 连续工单：同一问题 3 次以上工单会被重点督办
- 「先易后难」策略：先推动千元内小修（物业费内可解决）建立合作，再推大修表决

## 六、真实案例

> 案例：某楼电梯频繁困人，物业以「基金审批慢」拖延 3 个月。
> 业主动作：调出轿厢维保记录（发现 2 个月未公示维保）→ 12345+市监特设科双投诉 → 特设科现场检查责令整改 → 物业一周内完成维修 + 限期补齐维保。
> 关键：**特设科是电梯维权的『核武器』**——特种设备的安全检查是企业不可承受之重。

## 红线
> ⚠️ 提醒：电梯的公式——「先分清谁修谁出钱、维保记录 15 日一公示是证据、困人打 96333、大修走维修基金表决流程、12345+特设科双管齐下、广告费本该补贴维修」。电梯的拖延不是技术问题；是「没人推流程」的问题——你推的那张工单，就是流程的启动键。
