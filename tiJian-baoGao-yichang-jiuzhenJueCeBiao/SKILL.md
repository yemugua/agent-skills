# 体检报告异常项就医决策表

一句话：体检报告的意义不在「异常」两个字，在「这个异常要不要管」。本技能把常见异常项做成**三级决策表**：立即就医 / 按期复查 / 生活调整即可——拿着报告直接对表。

## 一、三级决策表（常见异常项）

### 🔴 立即就医（一周内，别等）
| 异常项 | 可能提示 | 首诊科室 |
|---|---|---|
| 血压 ≥160/100 且有头晕心悸 | 高血压急症风险 | 心内科 |
| 空腹血糖 ≥7.0 + 尿酮体阳性 | 糖尿病急性风险 | 内分泌 |
| 血红蛋白 <70g/L（重度贫血） | 需查因 | 血液科 |
| 肌钙蛋白/转氨酶显著升高（>3 倍上限） | 心肌/肝脏损伤 | 心内/肝病科 |
| 影像报告「占位」「结节伴钙化/血流信号」 | 需进一步定性 | 对应专科（随访≠放任，问清复查间隔） |

### 🟡 按期复查（定了时间就来，别忘）
| 异常项 | 常见复查节奏 | 备注 |
|---|---|---|
| 甲状腺结节（TI-RADS 3 类） | 6-12 个月超声 | 3 类以下恶性率 <5% |
| 乳腺结节（BI-RADS 3 类） | 3-6 个月超声 | 4 类及以上尽快活检 |
| 肺小结节 <8mm | 6-12 个月 CT | 8mm+ 或增长快 → 胸外 |
| 幽门螺杆菌阳性 | 无症状也可考虑根除（胃癌家族史强烈建议） | 消化科开四联 |
| 血尿酸 >540 或伴痛风发作 | 药物+饮食管理 | 内分泌/风湿 |
| 转氨酶轻度升高（<2 倍） | 1-3 个月后复查（戒酒停药后） | 持续升高再查因 |

### 🟢 生活调整即可（报告的「软异常」）
- 轻度脂肪肝 → 减重 5-10% 可逆转，无需吃药
- 血脂边缘升高 → 先饮食运动 3 个月，复查再定
- 尿酸 420-540 无症状 → 管住嘴（内脏/啤酒/果糖）+ 多喝水
- 骨量减少 → 补钙+负重运动+晒太阳，一年后复查骨密度

## 二、读报告的三个通用规则

1. **看箭头更要看倍数**：↑1.1 倍 vs ↑5 倍是两回事——参考值上限的比例决定紧迫度
2. **异常项要「串」着看**：血糖↑+血压↑+血脂↑=代谢综合征的组合信号，单看一项会低估
3. **「建议随访」= 给你的医嘱**——不是免责套话；随访间隔写进日历（「6 个月后复查」的失访率超过 50%）

## 三、就诊时的报告用法（效率翻倍）

- 带原始报告+历史报告（趋势比单点重要：结节「较去年增大 2mm」是关键信息）
- 异常项提前列清单（超过 3 项时按 🔴 优先）
- 问医生三句话：「这个需要现在处理吗？」「多久复查一次？」「什么情况下要提前来？」

## 四、复查管理清单

- [ ] 报告出来 3 天内完成三级分类
- [ ] 🔴 项已挂号（手机挂号按科室+症状关键词）
- [ ] 🟡 项复查时间写进日历+设提醒
- [ ] 🟢 项的生活干预开始执行（有明确动作）
- [ ] 历年报告存一个相册文件夹（影像科调阅对比必备）

## 红线
> ⚠️ 提醒：体检的公式——「先分三级再行动、倍数比箭头重要、异常要串着看、随访间隔进日历、带历史报告就诊」。体检报告不是「看完就焦虑」或「扔进抽屉」的纸——它是你的健康 TODO list；分类完的下一件事是行动。
