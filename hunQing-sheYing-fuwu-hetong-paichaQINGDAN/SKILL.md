# 婚庆摄影服务合同排查与档期纠纷应对

# 婚庆摄影合同排查指南

一句话：婚庆摄影纠纷的三大雷 = 「档期跳单」「底片归属」「成片数量模糊」——婚礼不能重拍，合同就是唯一保险。本技能给签约前排查表 + 服务标准条款 + 纠纷应对。

## 一、签约前六大条款排查

| 条款 | 常见坑 | 应对 |
|---|---|---|
| 1. 档期锁定 | 「口头排期」未写进合同——旺季被跳单给价高者 | 合同写死日期+时间+地点+「档期唯一」条款；改期须经双方书面同意 |
| 2. 团队与人员 | 「专业团队」模糊——宣传的首席摄影师到场变助理 | 写明主摄影师姓名+「未经甲方同意不得更换；更换需同级或以上资质并提前 X 日告知」 |
| 3. 拍摄时长与机位 | 「全程跟拍」含不含接亲？超时费多少？ | 写明：服务起止时间（如 7:00-21:00）+机位数+超时单价 |
| 4. 成片交付 | 「精修 50 张」——精修标准？底片给不给？ | 写明：底片全部交付（数字原件）+精修张数+精修标准（祛痘/调色）+交付期限（如 30 天）+逾期违约金 |
| 5. 婚品与流程 | 抢亲道具/化妆/跟妆是否含？ | 服务清单逐项列明含与不含 |
| 6. 付款节点 | 全款预付 | 定金 ≤30%（法定上限）+ 尾款在成片交付合格后付——**全款预付的 pass** |

## 二、可直接抄的服务标准条款

> 「乙方于 X 年 X 月 X 日 X 时至 X 时在 XX 地点提供婚礼跟拍服务，主摄影师 XX（团队名单见附件），双机位。
> 交付标准：全部底片（数字文件）于拍摄后 30 日内交付；精修照片 XX 张（含调色与基础修瑕）于 45 日内交付；精修样片先交甲方确认风格后批量处理。
> 档期为本合同唯一档期，乙方因故不能履约的，应提前 X 日书面告知并退还全部款项，另按合同金额的 XX% 支付违约金；婚礼当日违约（未到场）的，退还全部款项并赔偿合同金额的 100%。
> 甲方逾期付款按日万分之五计违约金。」

## 三、档期纠纷与「婚礼当日违约」的特殊性

- 婚礼的不可重拍性 → 违约金可主张**超出一般合同的强度**（精神损害的酌定支持——同性质的服务违约，法院对婚礼档的判赔态度更严）
- 被跳单的证据链：合同+排期聊天记录+对方接了同日其他婚礼的痕迹（朋友圈/其他客户透露）
- 赔偿主张：已付款退还 + 同价位替代服务的差价 + 精神损害酌定——保留「临时找替代摄影师多花的钱」的凭证

## 四、成片纠纷的应对

| 纠纷 | 路径 |
|---|---|
| 精修逾期 | 书面催告+期限（合同写了交付日就是依据）→ 12315 → 起诉 |
| 精修质量差（美颜过头/漏拍关键环节） | 合同的「精修标准」条款+「关键环节清单」（交换戒指/敬酒/全家福——签约时列进附件！） |
| 底片不给/索要加钱 | 「底片全部交付」写进合同的直接执行；没写的按行业惯例+协商（数字文件的所有权争议倾向消费者） |
| 摄影师拍丢数据 | 存储卡管理是专业义务——合同写「因乙方原因导致素材丢失的，退还全部费用并赔偿损失」；真发生的可主张违约+精神损害 |

## 五、拍照当天的配合清单（保成片质量）

- [ ] 关键环节清单给摄影师+婚礼管家各一份（接亲时间线/必拍人物名单——长辈合影的漏拍最遗憾）
- [ ] 「必拍名单」模板：双方直系亲属合影组合清单（父母单独+双方全家+祖辈……提前列 10-15 个组合）
- [ ] 备用存储与双机位确认（到场时问一句「卡是双卡备份吗」）

## 六、真实案例

> 案例：婚期 10 月 2 日，工作室 9 月 28 日告知「摄影师阳了改助理」。
> 因合同写了主摄姓名+更换需同意条款 → 业主拒绝助理 → 要求退全款+赔偿 → 协商退全款+临时替代差价 2,000 由工作室承担。
> 关键：**合同里的「人员锁定条款」**——没有它，「换人也是我们团队」就是工作室的免死金牌。

## 红线
> ⚠️ 提醒：婚摄的公式——「档期唯一写进合同、主摄姓名锁定、底片全交+精修张数+交付期限、必拍名单当附件、定金不超三成尾款后付、当日违约全赔」。婚礼摄影买的是「不可重来的那一天」——合同多写一行，当天就少一分翻车。
