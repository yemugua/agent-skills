# PDF 打印排版：双面/缩放/页码处理实操

一句话：打印对话框里的「大小/适合页面/多页合一/双面」四个参数决定你打印出来是A4完整版、缺边残页、还是费纸一倍——参数表+省钱算例直接照抄。

## 一、打印参数对照表

| 场景 | 参数设置 | 效果 |
|---|---|---|
| 合同/正式材料 | 纸张A4、缩放「适合页面大小」、单面 | 内容完整不缺边 |
| 双面合同 | 双面「沿长边翻转」 | 翻页方向正确（选错=背面是倒的） |
| PPT讲义 | 多页合一「每张2页」竖版 | 省纸一倍仍可读 |
| 电子书草稿 | 每张4页+双面 | 最省，只适合粗读 |
| 照片式PDF | 「实际大小」勿选适合 | 避免拉伸变形 |

## 二、算钱：一年打印能省多少

- 双面打印：100张单面材料→50张双面，纸省50%；按A4约0.05元/张，年打印2000张省约50元+省一半携带体积。
- PPT「每张2页」：60页课件从30张纸变15张。
- 缺边残页修复：出现缺边=原PDF页面尺寸非A4（多为A3/自定义），缩放改「适合页面大小」即恢复完整。

## 三、常见翻车

| 翻车 | 后果 | 正确做法 |
|---|---|---|
| 双面选「沿短边翻转」 | 背面全倒过来 | 文字类一律沿长边翻转 |
| 直接打「大小100%」 | 非A4源文件缺边 | 先选「适合页面大小」预览 |
| 打印店按彩打收费 | 黑白文件被按彩色计价 | 打印前说清「黑白、单面/双面、几张」三要素 |

## 四、真实场景

打印店打一份42页双面合同：参数「A4+适合页面+双面长边翻转」，21张纸完成；同店另一客户没说参数默认单面彩打42张收双倍——打印前报「黑白/单双面/页数」三要素可避免计价纠纷。

## 红线
> ⚠️ 提醒：正式材料打印后核对首页与末页（双面漏页最高发在末页）；打印店计价前确认黑白/彩色与单双面；「适合页面大小」是修缺边的第一开关。
