床围防摔本身也会"杀孩子"——缝隙卡头、软垫捂口鼻是两类真实致命风险；床品越软越危险是新手爸妈最常反着来的认知。

## 一、床围安全检查清单（安装前后各过一遍）

| 检查项 | 合格标准 | 风险逻辑 |
|---|---|---|
| 床围与床垫间的水平缝隙 | **≤25mm（约两指并拢）**，塞不进成年人的两指 | 婴儿翻身卡入缝隙夹头/夹颈 |
| 床围上缘与床沿 | 竖直贴合床沿，无"外倾八字形"安装 | 外倾形成楔形缝，孩子下滑卡在床围与垫之间 |
| 高度 | 床围顶部高于床垫面≥16cm（会翻身后），且低于孩子站立时的胸口 | 太矮翻出去，太高垫脚翻越 |
| 卡扣与固定 | 每个支撑脚卡扣锁死，金属插管无松动；每天安装后手推测试不晃 | 单侧脱扣=整片床围倒向床内压住孩子 |
| 材质 | 网面透气款优先，直立网眼；无大块软包 | 软包床围=捂窒息风险 |
| 立柱/杆件间距 | **45-65mm之间**（《婴幼儿床安全要求》对围栏间距的规定同理） | 小于45卡手指，大于65卡头 |

## 二、软床垫与床品的窒息风险分级（1岁内尤其）

| 危险物 | 风险等级 | 处置 |
|---|---|---|
| 软床垫、记忆棉厚垫 | 高 | 婴儿床垫硬挺，按压后迅速回弹不留手印 |
| 被子、厚毯盖到胸口 | 高 | 1岁内用睡袋代替盖被 |
| 枕头（1岁内） | 高 | **1岁内不需要枕头**，颈椎平直才正常 |
| 床围软包、 bumper | 高 | 能不用就不用，用则选网面直立式 |
| 毛绒玩具、防撞床品堆 | 中 | 睡眠时清空婴儿床，玩具白天玩 |
| 防哭闹"床中床"/斜坡垫 | 中 | 无安全认证的网红产品，挤压窒息案例多发，不推荐 |

**婴儿床标准布置 = 硬床垫+ fitted 床笠+ 睡袋，其他全清空。**

## 三、买床围时的实体店检查法

1. 现场把两指伸进床围与床垫结合处——伸得进去就不合格。
2. 问执行标准：床围属儿童家具的应执行 **GB 28007《儿童家具通用技术要求》**，边缘倒圆、无危险锐利尖端；网购直接问客服要检测报告。
3. 拒绝"通用款"话术：床围与床体结构不匹配（欧式圆床、超厚床垫）是卡缝事故主因，量好床垫厚度和床沿形状再买。
4. 二手床围慎用：卡扣疲劳和缺件是隐性问题，说明书齐全才收。

## 四、错误用法纠正（对应话术）

- ❌ "垫个被子补缝" → 缝隙变大且引入软物窒息风险。正确做法：换匹配厚度的床围或塞专用填充条，使缝隙≤25mm。
- ❌ "床围拉高点更安全" → 高过孩子重心反而给攀爬支点，翻出去摔得更重。
- ❌ "孩子会翻身了加个枕头防偏头" → 1岁内枕头是窒息+偏头双误区，白天清醒时多趴卧才是纠正头型的方法。
- 孩子会站立攀爬（约18-24个月）后，床围的防摔意义下降、攀爬风险上升——此时降到最低床垫档或直接换落地矮床。

## 红线

> ⚠️ 提醒：两指能塞进床围与床垫之间就等于卡夹隐患成立，当晚就要处理；1岁内的婴儿床里除了硬床垫和床笠什么都不放——窒息事故几乎都发生在"多垫了一层软东西"的床上。
