# 儿童家务能力验证

一句话：家务教育的闭环=「**教→练→验→放**」——「会做」不等于「能稳定做」；验证的方法=「独立完成 + 质量达标 + 持续三周」三重标准（参考家务能力表与奖励制度技能的框架层，本篇讲验收与放权）。本技能给验证标准 + 常见退步的应对 + 放权的节奏。

## 一、验证的三重标准（「会」的客观定义）

1. **独立完成**：**无提示无陪同**完成全流程（家长「忍不住指点」=未通过——「旁观 5 分钟纪律」）
2. **质量达标**：对照「最低标准清单」（**洗碗=无残渣+台面擦净；晾衣=分类+挂平整**——「最低标准」优于「妈妈标准」，参考家务技能的标准放低）
3. **持续三周**：**单次成功≠能力**——连续三周的稳定执行才算「掌握」（三周=习惯的最低证据）

- 验证期的新任务不叠加（**一岗练稳再进下一岗**——「同时学三样=三样都不会」）

## 二、分龄的验证示例（能力表的验收版）

| 任务 | 独立完成标准 |
|---|---|
| 收玩具（3 岁+） | 归位+分类正确（验证 2 周） |
| 摆桌（4 岁+） | 餐具数量对+位置对（2 周） |
| 洗碗（7 岁+） | 无残渣+灶台擦+碗归位（3 周） |
| 洗衣机使用（9 岁+） | 分色+剂量对+晾晒分类（3 周） |
| 独立做饭一餐（12 岁+） | 安全用火电+一菜一汤+厨房复原（**「安全确认」是一票前置**） |

## 三、退步的应对（学过≠永远会）

- 退步的常见原因：**学业挤压/兴趣衰减/新 sibling 分走关注**（退步=信息不是叛逆）
- 应对：**降回上一阶段+重新验证**（不羞辱——「暂时降级」是机制不是惩罚——参考如厕技能的倒退宽容）
- 「故意搞砸逃岗」的识别与应对：**质量标准前置+复核制**（搞砸=重做，不做道德审判——参考奖励制度技能的刷分防范）
- 青春期的「罢工期」：**协商制替代积分制**（参考家务制度的年龄适配——自治感的给予）

## 四、放权的节奏（从「带做」到「归他」）

- **五步放权**：我做你看→一起做→你做我看→你做我查→归你（**每步 ≥1 周**——「直接跳到归你」=失败率最高的一步）
- 「你做我查」期的边界：**查结果不重做**（**「重做」=放权清零**——参考家务技能的返工禁忌）
- 「归你」的标准时刻：**三周稳定+孩子自认**（「这是我的活」的自我认同=放权的心理完成态）
- 长期保持的机制：**岗位轮换表/承包制**（参考奖励制度的运维层）

## 五、家长的自查（验证失败常是家长原因）

- [ ] 是否「忍不住重做/返工」（返工=动机清零——参考家务技能）
- [ ] 是否标准过高（**「最低标准」是否真低**——按孩子 8 岁的手臂高度看标准）
- [ ] 是否叠加太快（**上一岗是否真的稳了**）
- [ ] 是否只在失败时说话（**成功时零反馈=动力断电**——参考情绪技能的正反馈）
- [ ] 是否把家务变成了对抗场（**关系>家务**——持续的对抗说明要暂停或换法）

## 六、真实对照

> 案例 A：洗碗「教过就会」——一周后返工重洗；「三周验证+查结果不重做」后稳定上岗（**验证的耐心=能力的成活率**）。
> 案例 B：12 岁独立做饭——第一次糊锅后家长收权半年；「安全前置+一起做→旁观」重新放权成功（**安全事件后的回归路径**）。
> 家务验证的公式：**三重标准（独立+达标+三周）、五步放权不跳级、查结果不重做、降级是机制不是惩罚、一岗稳了再进岗、安全任务一票前置、青春期协商制、关系优先于家务**——家务教育的成品不是「干活的娃」；是「我有能力照顾自己」的自我认知——验证的每一步，都是在为这个认知攒证据。

## 红线
> ⚠️ 提醒：家务验证的公式——「独立无提示+最低标准+三周稳定才算会、五步放权渐进、家长查不重做、退步降级不羞辱、安全任务先认证、成功要反馈、青春期给协商、一岗成熟再叠新岗」。家务能力的成活率=家长的放权耐心——催熟的能力，会在你转身时枯萎。
