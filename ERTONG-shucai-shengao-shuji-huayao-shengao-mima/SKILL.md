# 账号密码管理与密码器选择

一个人平均有 80+ 个账号，全用同一个密码=一泄全泄。本条给出密码管理器选型对比表、两步验证配置路径、泄露自查入口和一份可直接抄的「密码应急卡」模板。

## 工具对比表（2026 年主流方案）

| 方案 | 免费版够用吗 | 优点 | 缺点 | 适合人群 |
|---|---|---|---|---|
| Bitwarden | 够用（无限密码+全平台同步） | 开源、可自建、支持通行密钥 | 中文界面一般 | 大多数人首选 |
| iCloud 钥匙串 | 全免费 | 苹果全家桶无缝 | 安卓/Windows 导出难 | 纯苹果设备用户 |
| 1Password | 不免费（约 $3/月） | 体验最好、家庭版共享强 | 年费约 ¥260 | 愿付费的家庭 |
| KeePassXC | 全免费开源 | 本地文件、绝对掌控 | 无自动云同步、手机端配置麻烦 | 极度重隐私者 |
| 浏览器自带（Chrome/Edge） | 免费 | 零门槛 | 加密强度依赖账号安全 | 过渡期方案 |

**密码器（实体/软件密码管理）选择原则**：优先「开源+端到端加密+可导出」三条件；任何要求上传明文密码表格的 App 直接淘汰。

## 公式：密码强度与改密优先级

改密优先级 = 资金损失风险 × 使用频率。排序：
1. 支付/银行类（支付宝、微信支付、银行 App）→ 独立密码 + 每个都开两步验证
2. 邮箱（邮箱是所有「找回密码」的钥匙）→ 最强密码 + 备份码离线打印
3. 购物/社交/云盘 → 密码管理器生成随机密码
4. 低风险论坛类 → 可共用一组随机密码

密码强度下限：长度 ≥14 位随机字符（管理器生成）＞「短语拼接+数字符号」（如 `蓝鲸#喝7杯咖啡!`）＞任何含生日/手机号的组合（一律弃用）。

## 精确算例：泄露代价

- 同一密码用在 20 个站点，其中 1 个冷门站点库被拖库：撞库后攻击者先试邮箱+密码登录支付宝/微信，若两步验证未开启，资金账户 0 门槛失守。
- 开启两步验证后：微软统计可拦截 99.9% 的自动化撞库；即使密码泄露，攻击者没有你的手机验证器/硬件钥匙也登不进。
- 1Password 家庭版 ¥260/年 ÷ 4 人 = 每人 ¥65/年，低于一次撞库后补办银行卡+挂失的时间成本（半天误工按日均 ¥300 算即亏 ¥300+）。

## 泄露自查三入口（每月一次）

1. `haveibeenpwned.com`：输入邮箱查历史泄露库（免费）；
2. Chrome/Edge → 设置 → 隐私 → 「检查密码」自动比对泄露库；
3. 支付宝/微信：设置 → 账号与安全 → 登录设备管理，清理陌生设备并改密。

## 可复制模板：密码应急卡（打印后放家里保险柜/告知家人）

```
【密码应急卡】填写后存放于____，请勿拍照上传
银行 App：______ 登录名线索：______ 备份码位置：______
支付宝/微信：登录名线索：______ 紧急冻结入口：95188 / 110 微信搜索「微信支付」冻结
邮箱：密码线索（不写明文）：______ 两步验证备用方式：______
密码管理器：主密码提示：______ 应急恢复码位置：______
两步验证备份码统一存放：______
```

注意：应急卡写「线索」不写明文；主密码可写在纸上但与卡片分开存放。

## 红线
> ⚠️ 提醒：① 任何客服/短信/邮件索要验证码或引导你「取消两步验证」的都是诈骗——真客服永远不需要你的验证码；② 两步验证务必保存离线备份码，换手机前先把验证器迁移（iCloud 钥匙串/Google Authenticator 导出），否则换机即自锁；③ 密码管理器主密码丢失无任何找回，先写应急卡再启用；④ 拒绝把密码表格存在微信收藏/网盘明文里——这是最常见的泄露源。
