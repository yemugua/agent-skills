# 驾校退费全套：核算+话术+投诉模板

# 驾校退费全套工具包

一句话：驾校退费的法律底牌是「未发生的课时按比例退」——驾校说的「报名费不退」没有法律依据。本技能给退费金额核算表 + 分阶段话术 + 12328 投诉信模板，一包到底。

## 一、退费金额核算表

**可退 = 已缴总额 − 实际发生的成本**：

| 扣除项 | 标准依据 | 常见乱扣 |
|---|---|---|
| 已上科目费用 | 按合同课时单价 × 已上次数 | 全额扣科目一费用（实际已考=合理；未考=乱扣） |
| 考试费/代缴费 | 实际已代缴给车管所的部分（有凭证） | 未考也全扣（乱扣） |
| 体检/照相 | 实际发生 | 抬价 |
| 合同约定违约金 | **不得超过法定合理范围**；未约定不得扣 | 扣 30-50%（多数乱扣） |

**核算示例**：缴 4,800，考完科目一（成本约 600+考试费 50），要求退：
→ 应退 ≈ 4,800 − 650 − 违约金（合同有约定按约定，一般 10% 内合理）≈ **3,600-3,900**
驾校报价「退 2,000」 → 差 1,600 = 谈判空间。

## 二、分阶段话术（先礼后兵）

**第 1 轮·电话/当面**：
> 「根据合同第 X 条和《机动车驾驶员培训管理规定》，未产生的培训费用应予退还。我已产生费用 X 元，请退我 X 元，本周内办理。」
（报价时用「根据」开头——对方能听出你懂规则）

**第 2 轮·书面催告**（微信+EMS）：
> 「本人于 X 月 X 日与贵校签订培训合同，已缴 X 元，完成科目一培训。现因个人原因申请退学，依规应退 X 元。请于 7 日内退款；逾期将向 12328 及交通运输管理部门投诉，并保留诉讼权利。」

**第 3 轮·投诉**（核心武器，驾校最怕这个）：
- **12328** 交通运输服务监督热线（驾校的行业主管投诉口，会转办并要求驾校限期答复）
- 当地「交通运输局官网」投诉入口 / 驾培管理平台
- 12315（合同纠纷）
- 投诉的作用：驾校有「投诉率考核」，被 12328 转办的投诉直接挂钩校评分——多数驾校在此步投降

**第 4 轮·起诉**：小额诉讼，合同+缴费凭证+聊天记录；一审终审 25-50 元。

## 三、12328 投诉信模板（直接抄）

> 投诉对象：XX 驾校（地址 XX）
> 事实：本人 X 年 X 月 X 日报名 C1 科目，缴纳 X 元。X 月 X 日因个人原因申请退学，已完成科目一培训（成本约 X 元）。依据培训合同与《机动车驾驶员培训管理规定》，申请退还剩余 X 元。该校先以「报名费不退」拒绝，后报价 X 元（低于应退金额），协商无果。
> 诉求：责令该校按未发生课时比例退还 X 元。
> 附件：合同、缴费凭证、沟通记录。

## 四、预防清单（还没报名的人看）

- [ ] 合同必须写「退费条款」——按课时比例退的写法；「一律不退」的合同可主张条款无效
- [ ] 缴费要发票/收据 + 对公账户（私人收款=风险信号）
- [ ] 「包过」「不限时长」话术的免责核实
- [ ] 保留与销售的聊天记录（承诺证据）

## 红线
> ⚠️ 提醒：退费的公式——「未发生课时按比例退是底牌、违约金不得畸高、书面催告 7 日期限、12328 是驾校的真痛点、合同缴费记录留全」。驾校赌的是你嫌麻烦——一套模板下来，从打电话到投诉不超过 3 小时；你多花的每 1 小时，都值回数百元退费。
