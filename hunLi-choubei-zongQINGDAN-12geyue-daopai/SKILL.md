# 婚礼筹备总清单（12 个月倒排）

一句话：婚礼筹备的失控来自「临期赶工」——酒店/四大金刚/婚纱照都有提前量窗口。本技能给 12 个月倒排的完整清单 + 各阶段的预算比例 + 拖期高发项预警。

## 一、预算框架（先定盘子）

**常见比例**（以 15 万总预算为例）：
| 项目 | 占比 | 金额参考 |
|---|---|---|
| 酒席（餐饮+酒水） | 40% | 6 万 |
| 婚庆布置（场布/花艺/司仪/灯光音响） | 20% | 3 万 |
| 四大金刚（摄影/摄像/化妆/司仪） | 12% | 1.8 万 |
| 婚纱礼服（租/买+西装） | 8% | 1.2 万 |
| 婚纱照 | 6% | 0.9 万 |
| 婚戒/三金 | 8% | 1.2 万 |
| 喜糖喜酒伴手礼 | 4% | 0.6 万 |
| 机动金 | 2% | 0.3 万 |

**机动金铁律**：留 5-10% 的机动——婚礼超支是常态，机动金是「不吵架基金」。

## 二、12 个月倒排清单

### T-12~10 月（定盘子阶段）
- [ ] 双方家庭预算沟通（**第一优先**——钱没谈拢后面全是雷）
- [ ] 定婚期（避开高峰档：5 月/10 月的周六价高 30% 且档期紧张——错峰=省钱+从容）
- [ ] 定婚礼规模（桌数）→ 决定一切后续
- [ ] 领证（按双方意愿的安排）

### T-10~8 月（大头锁定）
- [ ] **订酒店**（最早的稀缺资源——旺季提前 8-12 个月）：试菜+合同（菜单/服务费/最低桌数/场地费/超时费——见合同排查逻辑）
- [ ] 定婚庆公司（场布）——与酒店场地费的关系问清（进场费/电费谁出）
- [ ] 婚纱照拍摄启动（修片周期 2-3 个月）

### T-8~6 月
- [ ] **定四大金刚**（摄影/摄像/化妆/司仪——好档期比价格稀缺，见婚摄合同条目）
- [ ] 定婚纱（租赁 vs 定制：租赁 2,000-8,000 / 定制 1-3 万；出门纱+主纱+敬酒服三套的常见配置）
- [ ] 男方西装定制（提前 2 月，留修改时间）

### T-6~4 月
- [ ] 婚戒/三金
- [ ] 请柬设计与名单整理（双方家庭人数的核对是关键——漏请的得罪人，多请的超支）
- [ ] 伴郎伴娘确定

### T-3~2 月
- [ ] 试妆（不满意换化妆师还有时间）
- [ ] 婚庆场布方案定稿（效果图确认）
- [ ] 喜糖/喜酒/伴手礼采购（酒水量大可比价批发）
- [ ] 婚礼当天的流程脚本（司仪对接）

### T-1 月
- [ ] **人员确认**：四大金刚/婚车/接亲安排逐个电话确认
- [ ] 彩排（婚礼前一天场地走流程）
- [ ] 装备包：急救包/针线/备用丝袜/充电宝/补妆用品
- [ ] 收礼金人员+记账分工（双人记账防漏错）

### T-7 天
- [ ] 确认到场桌数微调（酒店最后桌数日期）
- [ ] 接亲路线踩点（堵车预案）
- [ ] 睡眠与皮肤管理（最后一周别熬夜试新护肤品）

## 三、拖期高发项预警（最容易来不及的事）

1. **酒店旺季档期**——晚订 1 个月=换日期或换城市
2. **四大金刚好档期**——性价比高的摄影师提前半年没档
3. **定制婚纱/西装**——修改周期被低估
4. **修片**——婚纱照精修拖到最后一周的常态；婚礼当天要用（迎宾区/大屏）的照片要提前单独催
5. **双方家长的意见统一**——礼数分歧（接亲环节/酒席标准）越早谈越不伤感情

## 四、省钱的正确姿势（哪里该省哪里不该省）

**该省**：场布的重复利用（仿真花混合鲜花）、喜糖包装（网购自制）、伴手礼（实用主义）、婚车（朋友车队 or 租车替代豪车租赁）
**不该省**：摄影摄像（唯一留下来的东西）、餐饮口味（宾客的直接体验）、化妆（全天妆面是你出镜的质量）

## 五、当天的分工表（提前写好）

| 岗位 | 职责 | 人选 |
|---|---|---|
| 总管 | 全天统筹决策 | 靠谱亲友（别选自己） |
| 礼金记账×2 | 收礼登记 | 家族长辈+年轻人配对 |
| 物资管理 | 装备包/换装衣物 | 伴娘伴郎 |
| 对接人 | 与酒店/婚庆/摄影对接 | 总管或专人 |
| 车辆调度 | 婚车路线时间 | 亲友 |

## 红线
> ⚠️ 提醒：婚礼的公式——「预算先谈拢再行动、酒店提前一年、四大金刚提前半年、机动金留 5-10%、必拍名单给摄影师、当天分工表提前写、摄影摄像的钱不能省」。婚礼是「一次性项目管理」——它考验的不是浪漫；是提前量的纪律。筹备越从容，当天越像在参加自己的婚礼而不是在干活。
