# 家庭旅行保险

一句话：旅行保险的决策=「**去哪/干啥/多久→选险种**」——境内游的基础医疗+意外；境外游的**医疗运送（最贵的一项目）+护照协助**；**滑雪/潜水等运动的「免责条款」=理赔翻车的第一大坑**（参考保险技能的条款意识）。本技能给险种选择 + 条款要点 + 理赔流程。

## 一、按场景选险种（决策树）

| 场景 | 核心险种 | 保费感 |
|---|---|---|
| 境内游（短途） | 一年期综合意外险（**常备比单次买划算**） | 百元级/年 |
| 境内长自驾 | +车上人员险/车辆保险确认（参考自驾技能） | |
| **境外游** | 旅行险（**医疗+医疗运送+行李延误**） | 50-200 元/程 |
| 高风险活动（滑雪/潜水/高原） | **必须选「含高风险运动」的专项**——普通旅行险免责 | |
| 携娃/老人 | 医疗额度优先+未成年人身故限额规定 | |

- **「一年期意外险常备」的逻辑**：日常+周末游全覆盖（**「出门才想起买」=漏买与赶买**——参考保险技能的常备思维）

## 二、境外险的关键条款（保费的差别都在这）

- **医疗运送与送返**（**保额要高：50 万+**——跨境医疗包机的真实成本百万级——**「医疗运送是境外险的灵魂」**）
- 医疗保额：境外就医的天价（欧美一次急诊=数万——**医疗 ≥30 万**）
- **紧急救援热线**（**保单上的救援电话=最值的一行**——出事先打救援公司不是先打客服）
- 行李延误/航班延误的定额赔付（**延误证明的收集**——参考理赔的材料意识）
- 旅行变更取消险（**不可退改的大额预订**——行程变动风险的转移）
- **免责清单的先读**：高风险运动/既往症/酒精相关的拒赔（**「玩着玩着出事不算」的条款雷**——参考保险升级技能的免责逻辑）

## 三、高原/潜水/滑雪的专项提醒

- **高原**：部分旅行险对海拔 >3,500m/5,000m 分档免责（**按目的地海拔选**——西藏/高原徒步的显式确认）
- 潜水：**持证 vs 体验潜的条款差异**（**无证深潜多数免责**——潜水证的「保险价值」）
- 滑雪：**「含滑雪」条款+雪道内事故**（**野雪/封闭区=免责**——雪场区域的条款边界）
- 自驾境外：**「含自驾」+国际驾照认证件**（参考行李证件技能的证件逻辑）

## 四、理赔流程（出事后的路径）

1. **立即联系救援热线/报案**（保单时效——**多数 24h 内报案要求**）
2. 保留全部票据：**医疗发票/诊断书/报警单/航班延误证明**（**原始票据=理赔的硬通货**——参考保险升级技能的材料清单）
3. 境外医疗的垫付问题（**部分救援公司可垫付——「先问垫付再掏卡」**）
4. 回国后索赔：材料齐全→线上/APP 提交（**旅行险理赔周期 2-4 周**）
- 拒赔的常见原因：**免责活动/未报案/材料缺失/既往症**——**90% 可在投保日预防**（参考保险技能的投保日决定论）

## 五、家庭投保的细节（携娃/老人）

- 儿童的身故限额（**法定未成年人身故赔付限额**——**儿童险重点是医疗与救援不是身故杠杆**）
- 老人：**年龄上限条款（多数旅行险 70-85 岁封顶）+既往症告知**
- 全家单 vs 分别投：**家庭计划单的性价比核算**（人数×单价 vs 家庭单）
- 「跟团游含保险」的核实：**旅行社保底≠足够**（**团费含的常是责任险不是个人医疗**——自行加买的标准动作）

## 六、真实对照

> 案例 A：境外骨折——医疗运送 40 万由险覆盖；对照「只买 30 元低保额」的：自付 20 万+（**医疗运送=境外险的灵魂条款**）。
> 案例 B：无证潜水受伤——条款免责拒赔；「持证+含潜水专项」的对照户正常赔付（**免责条款=投保日就该读的一页**）。
> 旅行保险的公式：**一年期意外险常备境内、境外险三要素（医疗 30 万+医疗运送 50 万+救援热线）、高风险活动买专项、免责先读、报案 24h+票据全留、垫付先问救援、儿童重医疗老人重年龄上限、团险必核实自行加买**——旅行保险是「几十元买百万级风险转移」的杠杆——杠杆的兑现条件=投保日读条款+出事日按流程。

## 红线
> ⚠️ 提醒：旅行保险的公式——「境内游常备一年期意外险、境外三要素（医疗/运送/救援热线）、滑雪潜水高原买专项且读免责、救援电话是保单最值一行、24h 报案+原始票据全留、垫付先问救援公司、儿童险重医疗、老人看年龄上限、跟团含险必核实」。旅行险的钱=最便宜的「出境底气」——买对险种+读懂免责，是出发前 10 分钟最值的动作。
