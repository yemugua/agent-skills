# 装修主材进场验收清单（瓷砖·板材·五金·乳胶漆的真假与型号核对）

# 装修主材进场验收清单

一句话：主材被调包/降级是装修纠纷的头名——合同写 A 牌特级，进场变 B 牌一级，外行根本看不出。本技能按品类给「看包装+查型号+试样品」三步验收法。

## 一、验收的总原则（进场当天做）

1. **对合同**：品牌+型号+规格逐字核对（合同写「XX 牌 YZ-800 瓷砖」——型号一个字母之差就是另一个档次）
2. **对报价单**：数量清点（瓷砖按箱×片数，损耗另计的部分写明）
3. **查真伪**：品牌官网/公众号扫码验真（瓷砖/乳胶漆/五金主流品牌都有溯源码）
4. **留样**：每批次留 1-2 片/一小罐样品+拍照（后续色差/调包争议的实物证据）

## 二、瓷砖验收

- [ ] 同一批次：箱体批号一致（不同批次有色差——铺出来「阴阳脸」）
- [ ] 平整度：两片面对面贴合看缝隙（四角对齐=平整）
- [ ] 尺寸：抽测对角线误差 ≤0.5mm
- [ ] 吸水率（厨卫釉面砖）：背面滴水渗得慢为好（渗太快=坯体疏松）
- [ ] 防滑性（卫生间）：踩湿砖感受
- [ ] 色差抽检：随机开 3-4 箱并排比色
- 常见调包：品牌专供款（工程降级款）冒零售款——看包装「优等品/一级品」等级标注

## 三、板材与定制柜体

- [ ] 环保等级：ENF/E0/E1 级看检测报告（合同写 E0 进场 E1 = 降级，环保报告要对批次）
- [ ] 基材辨认：颗粒板/多层实木/生态板的外观与合同一致
- [ ] 五金：铰链/滑轨品牌（百隆/海蒂诗 vs 杂牌）——柜子寿命 80% 看五金，定制公司最爱在这降本
- [ ] 封边：现场看加工样品的封边密实度（爆边/开胶的封边=设备差）
- [ ] 定制柜：进场前复尺签字（尺寸差错的责任分界）

## 四、乳胶漆与涂料

- [ ] 桶身防伪码扫码（立邦/多乐士官网验证）——**假漆重灾区**
- [ ] 型号核对：合同「五合一」进场变「净味基础款」= 常见降级
- [ ] 开桶检查：无分层结块、搅拌后细腻、气味正常（刺鼻=问题）
- [ ] 桶重核对（虚标容量的低端套路）
- [ ] 按房间用量倒推：合同约定几桶、进场几桶——「半桶差价」的偷料惯例

## 五、五金与水电材料

- [ ] 电线：国标铜芯（包装的 GB 标注+平方数实测——卡尺量铜芯直径，2.5㎡ 线径 ≥1.76mm）；非标线=火灾隐患
- [ ] 水管：PPR 品牌管件原配（伟星/金德等品牌管与杂牌管件的混用是常见坑）
- [ ] 开关面板：型号+功能（合同写带 USB/调光的核对功能件）
- [ ] 角阀/软管：全铜阀体 vs 锌合金（重量差异明显——手感越重越真）

## 六、进场验收的流程设计

```
材料到场 → 当天验收（对照本清单） → 不合格当场拒收
 → 合格签字《进场验收单》（双方+项目明细）
 → 隐蔽工程用前再次核对（水电封槽前对线管）
 → 每批主材进场重复一遍
```

**《进场验收单》模板**：
> X 月 X 日进场：XX 品牌 XX 型号瓷砖 N 箱（优等品，批号 XX）、XX 型乳胶漆 N 桶（扫码已验真）……
> 经核对与合同一致，双方确认施工。
> ——一句话的签字，是「进场就合格」的铁证；没有它，调包争议时你拿不出「进场时是对的」的证据。

## 七、避坑红线 ⚠️

- ❌ 「忙，到货直接让工人收」——进场验收是业主不可外包的责任
- ❌ 只看品牌不看型号——「同品牌」内部差价一倍是常态
- ❌ 环保等级不看检测报告批次——「报告是真的、砖不是那批」
- ❌ 样品不留——争议时的实物证据链断裂

## 红线
> ⚠️ 提醒：主材的公式——「品牌+型号+等级三要素逐字核、扫码验真+留样拍照、进场验收单双方签、电线卡尺量、五金掂重量、批次色差先比后铺」。装修公司的利润一半藏在材料差价里——你验一次进场，他少一分侥幸；每批都验，就是全屋真材实料。
