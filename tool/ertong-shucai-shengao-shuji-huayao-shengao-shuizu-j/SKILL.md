# 净水剂药剂安全使用

鱼药和净水剂用错剂量等于"下毒"——按水体算准剂量、避开禁忌组合，这一页给公式+算例+对照表，下药前算一遍。

## 按水体投药量公式

```
水体量(L) = 长(cm) × 宽(cm) × 水位高(cm) ÷ 1000
投药量 = 说明书剂量(每100L) × 实际水体 ÷ 100 × 水位折扣
安全首剂 = 说明书剂量 × 0.5   （先半量观察24h）
```

算例：60×45×45缸水位40cm → 60×45×40÷1000=**108L**。白点净说明书"每100L加10ml"→ 首剂=10×108÷100×0.5=**5.4ml**，用5ml针管量取；24小时无异常补足到10.8ml。

## 常见药剂对照表

| 药剂 | 用途 | 剂量基准（每100L） | 危险对象 |
|---|---|---|---|
| 白点净（亚甲蓝类） | 白点病 | 10ml | 虾/螺 |
| 黄粉（呋喃西林） | 烂鳍细菌 | 1g | 硝化菌 |
| 亚甲基蓝 | 水霉 | 2-3ml | 虾、水草 |
| 杀虫药（敌百虫类） | 体表虫 | **严格按说明** | 虾螺无鳞鱼 |
| 万能鱼药 | 混合感染 | 慎用，成分不明 | — |

## 禁忌组合表（直接查）

- **铜药 × 虾/螺缸 = 团灭**（无解药，换水稀释）
- 高锰酸钾 × 有机物多的高温缸 = 烧鳃（先换水再用）
- 两种药同时下 = 成分叠加过量（间隔48小时）
- 下药期间滤材里放活性炭 = 药被吸走等于白下
- 治疗结束必须：换水1/3+滤桶里放新活性炭24小时脱药

## 安全操作模板（下药当天抄）

```
1. 算水体→算首剂（半量）→针管量取
2. 药先溶在杯缸水里再倒入（不直接撒）
3. 关灯（部分药见光分解）+加强打氧（药耗氧）
4. 记录时间/药名/剂量在缸边便签
5. 24小时观察：浮头/狂游=立即换水50%
6. 疗程结束：换水1/3 + 活性炭脱药
```

**储存与废弃**：鱼药放儿童够不到的阴凉柜（和食品分开）；过期药不倒下水道，用药棉吸干+密封袋丢弃；高锰酸钾溶液染色用维生素C片擦掉。

## 红线

> ⚠️ 提醒：所有鱼药按人用药品标准存放——误食就医时带药瓶；下药首剂永远半量，"宁可无效不可过量"；虾螺缸用铜药是团灭级事故；药剂混用前查成分表，含铜+含甲醛（如部分"万能药"）叠加毒性翻倍；治疗中加强打氧是新手最常漏的一步。
