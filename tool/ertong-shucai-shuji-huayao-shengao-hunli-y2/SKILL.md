婚礼平均超支30%-50%，唯一解法是先定总额再分配，超支时按砍项优先级止损而不是事后记账。

## Excel预算总控表模板（直接建表）

| 列 | 说明 |
|---|---|
| A 项目 | 大类：宴席/摄影摄像/婚纱/戒指/婚庆/蜜月/红包 |
| B 预算额 | 定死，改预算需双方签字（口头改=超支根源） |
| C 已付定金 | 单独跟踪，防止重复计算 |
| D 实际报价 | 每签约一项即填 |
| E 偏差 | =D-B，>10%触发复盘 |
| F 是否可砍 | 事前标注高/中/低 |

总控公式：`剩余可签 = 总预算 - Σ已签约总价 - Σ已付定金`，剩余≤10%时停止新签可选项。

## 分配参考（总预算15万，二线城市）

宴席48%（72,000）/婚庆布置12%/摄影摄像7%/婚纱三金18%/蜜月10%/机动金5%。

## 超支预案（按砍项优先级）

| 优先级 | 砍什么 | 省多少 |
|---|---|---|
| 1 | 婚庆布置降级为半定制 | -8,000~-15,000 |
| 2 | 摄像双机改单机+快剪保留 | -2,000 |
| 3 | 桌数砍备桌、撤酒水升级 | -3,000~8,000 |
| 4 | 婚纱改租赁代定制 | -3,000 |
| 禁砍 | 摄影摄像质量、四大金刚 | 永久留存项不动 |

## 算例

预算15万，签约到12万时婚宴报价超预算1.5万。执行预案：砍婚庆降级1.2万+备桌2桌省0.7万 → 总支出回到15万内，且不动摄影摄像。

## 红线

> ⚠️ 提醒：①机动金低于5%的预算必然崩，宁可先砍项目；②「到时候再说」是超支唯一原因，每笔签约前查总控表；③份子钱不进预算——它是回款不是收入，按回款记账；④双方父母加项必须走「追加预算即等额砍别项」规则，否则总额失控。
