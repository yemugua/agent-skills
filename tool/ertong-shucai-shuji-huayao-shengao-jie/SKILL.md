# 节庆家宴备菜与时间表（模板）

一句话点题：家宴不慌的秘诀是T-3天倒推排程——只有"现炒类"留在当天，其余全部前置。

## 工具表：T-3天倒推时间表模板

| 时间节点 | 任务 | 类别 |
|---|---|---|
| T-3天 | 定菜单、下单网购类（干货/调料/进口锅具）、试购1份生鲜验品质 | 采购 |
| T-2天 | 肉类解冻腌制分装；炖菜（红烧肉/卤味）做完冷藏 | 备料 |
| T-1天 | 凉菜全部做完；高汤熬好；切配冻硬菜装保鲜盒 | 备料 |
| 当天上午 | 采购叶菜/活鲜；蒸制点心 | 采购+烹饪 |
| 开饭前2h | 炖菜回热；鱼虾处理 | 烹饪 |
| 开饭前40min | 全部现炒（按慢→快顺序） | 烹饪 |

## 精确算例（10人年夜饭）

T-2天晚7点开始：卤牛肉1.5kg炖90分钟 + 红烧肉2kg炖80分钟，同时灶台两锅并行，22:10收尾，实际耗时3h10min。当天现炒仅6道×平均8分钟 = 48分钟，开饭前压力全在40分钟窗口内消化。

## 可复制模板

```

责任人：__  灶眼数：__  开饭时刻：__
```

## 红线

> ⚠️ 提醒：熟食冷藏不得超过T-1天20:00（超过24h回热前必须彻底沸腾5分钟）；叶菜/活鲜严禁提前一天购买；冰箱冷藏室禁止生熟同层混放（生肉必须垫盘放下层）。
