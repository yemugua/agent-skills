把业主群和社区活动办好，靠的是规则先行+钱算清楚，不是热情。

## 一、业主群礼仪规则（可直接复制为群公告）

```
【本群公约】
1. 实名+楼栋号入群（如：3栋2单元502-张先生）
2. 禁广告、拉票、砍价链接；发一次撤回+移出
3. 报修/投诉直接@物业值班电话XXX，群里刷屏不解决问题
4. 争议话题（装修噪音等）私聊调解，不在群里指名互撕
5. 重要通知以群公告为准，不传未证实消息
```

群主责任红线：群内诽谤、谣言群主不制止可能被追责（两高关于网络诽谤司法解释精神），发现即提醒+移出并截图存证。

## 二、活动组织清单与预算算例

小区中秋活动预算表（200人规模）：

| 项目 | 数量 | 单价 | 小计 |
|---|---|---|---|
| 月饼DIY材料 | 50份 | 15元 | 750 |
| 灯谜奖品 | 40份 | 10元 | 400 |
| 茶水纸杯 | 1批 | 100 | 100 |
| 音响租借 | 1天 | 200 | 200 |
| 备用金(10%) | — | — | 145 |
| **合计** | | | **1595元** |

分摊公式：**人均 = 总预算 ÷ 预计到场家庭数**。1595 ÷ 80户 ≈ 20元/户。
算例：报名72户实收1440元，缺口155元 → 三个补法：①按实收缩减DIY份数至38份；②申请社区「公益金/惠民活动补贴」（多数街道有，单场500-2000元，提前1-2周找居委会报备）；③找周边商户赞助换摆摊位（奶茶店赞助300元换展位1个）。
结余处理：活动结束3日内在群公示收支截图，结余转入下次活动或按比例退，**不公示是业主群解散的最常见导火索**。

## 三、活动报名接龙模板

```
【中秋DIY活动报名】时间：9月X日15:00-17:00 地点：X栋架空层
费用：20元/户（多退少补，结束后群公示）
报名格式：楼栋号+户数+联系方式
报名截止：活动前3天，不足30户取消并全额退款
```

## 红线

> ⚠️ 提醒：收费活动必须事前公示预算、事后3日内公示收支，账目不清=信任崩塌；公共区域办活动提前向物业/居委会报备（涉及消防通道与噪音时段22:00-8:00禁高音）；不收「赞助换群发广告」类费用，易被认定为群主牟利引纠纷。
