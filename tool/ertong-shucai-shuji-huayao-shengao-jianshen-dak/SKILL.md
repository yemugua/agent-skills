健身放弃率高的根因不是懒，是**目标剂量太大**：计划每次练90分钟的人平均存活6周，把底线降到"到健身房门口就算赢"的人长期坚持率显著更高。一句话点题：先设计打不破的最小剂量，再用锚点固定时间，第21天前不谈效果。

## 习惯养成的三个设计原则

1. **最小剂量**：最低完成标准 = 换上运动鞋到场地，做1组就算打卡成功。超出是奖励，不是要求。
2. **锚点绑定**：把训练绑在已有习惯后——"下班进家门先换运动服"，而不是"今晚有空就练"（有空就练=永远没空）。
3. **连续性优先**：两周3次的最优计划输给"每周至少碰2次"的可持续计划，中断超过3天才算断。

## 21天打卡模板（直接抄）

```
打卡表（日期/完成/剂量/备注）
第1周目标：每周3次×最小剂量（到场+1组）
第2周目标：3次×30分钟完整训练
第3周目标：3次×45-60分钟
锚点句："我下班换鞋后就去健身房/客厅铺垫子"
奖励规则：连续7天打卡 → 买一件小装备；断签 → 不自责，次日做最小剂量续上
```

打卡方式：手机日历建每周一三五19:30重复事件，完成后改标题加✅；或用纸表贴冰箱。研究显示主动记录本身就能提升执行率约20%。

## 中断重启规则（防止"破罐破摔"）

- 断1-2天：照常继续，不做补偿性加倍训练
- 断3-7天（生病/出差）：回来第一周重量减20%
- 断>2周：回到第1周的最小剂量重新爬坡，心理上算"新一轮第1天"，而不是"我失败了"
- 节假日/出差预案：提前定好"酒店俯卧撑3组×15+深蹲3组×20"的最低替代方案，保持"不断签"的身份认同

## 常见失败点对照

| 症状 | 真实原因 | 修复 |
|---|---|---|
| 三分钟热度后彻底放弃 | 初始剂量过大 | 回到最小剂量 |
| 总说"没时间" | 无固定锚点 | 绑定下班/晨起，写进日历 |
| 练了一个月没效果想放弃 | 期望错误（21天≠变型） | 只看打卡连续性，拍照对比月度进行 |
| 天冷/下雨不去 | 依赖"去健身房" | 备好居家最小剂量方案 |

## 红线

> ⚠️ 提醒：打卡是工具不是目的，为保持连续性带病训练反而中断更久——生病优先休息；打卡App的"连续天数焦虑"不必理会，断签重启成本远低于放弃；目标写成"每周3次"而非"练出腹肌"，过程目标可控，结果目标交给时间。
