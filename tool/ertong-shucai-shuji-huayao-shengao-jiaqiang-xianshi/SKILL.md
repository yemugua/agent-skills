家里两台车"谁都能开"，账却记不清——一台油车一台电车的家庭，分工对了每年省8千-1.5万，保险也能省一档。

**一、两车分工算例（年2万公里，油车+电车各一台）：**

| 分工方案 | 油车费用 | 电车费用 | 合计/年 |
|---|---|---|---|
| 现状：随缘开，油车1.2万km+电车0.8万km | 油费7,000+保险4,000+保养1,200 | 电费900(家充)+保险4,800+保养200 | 18,100 |
| 优化：电车跑通勤1.8万km，油车只跑长途0.2万km | 油费1,200+保险4,000+保养800 | 电费1,500+保险4,800+保养200 | 12,500 |
| **年省** | | | **5,600** |

规律：**日常里程尽量压给电车，油车只干电车干不了的活**（长途、雨天拉货、低温远行）。反过来的家庭（图省事天天开油车）每年白扔5千+。

**二、保险分摊与减负：**
- 两车保险分开买，先比价：同一家多车通常有折扣（8-9.5折），分别报价再比单独渠道，取低者。
- 里程调节：年里程<1万公里的那台，投保时按实际里程申报+选按里程计价产品（部分公司有），保费再降10-20%。
- 驾驶人指定：商业险指定主驾驶人（如只限夫妻二人）比"不记名"便宜，但出险时非指定驾驶人驾驶可能加免赔——按真实驾驶分工指定，别为了省钱指定成从不开车的人。
- 电车保险高约20%：选车时把年保费差（约800-1,000元）计入总成本，别只看电费省。

**三、油电月账模板（每月1号记上月）：**
```
油车：加油____升×____元 = ____元；保养____；保险分摊____/12
电车：家充____度×0.3 = ____元；公共充电____元；保养____
本月合计____元；本月电车占比____%（目标>80%）
```
坚持记3个月就能看到分工错位，实际家庭案例：记账后发现问题不在油电，而是油车停在车位A、电车停在快充站附近——调换车位后充电次数降一半。

**四、谁开哪辆的三个判断：**
1. 里程大者优先开低成本车（通勤远的开电车）。
2. 新手开便宜/旧的那台（出险保费涨的是家庭账户，不是个人）——新手单独立项：前两年开旧车，省下的保费折旧差每年约3,000-5,000元。
3. 长途/带全家出行用油车（无续航焦虑+空间），日常单人通勤用电车。

**五、卖一留一的临界点：** 两台车年保险+车船税+折旧固定成本合计约1.2-1.8万。全家年里程合计<1.2万公里时，卖掉一台改"电车+打车/租车"通常更省：固定成本省8千+，租车按需3次/年×500元=1,500元，净省约6千/年。

## 红线
> ⚠️ 提醒：两车保险别想当然认为"一家买必有折扣"，逐家比价；指定驾驶人要与实际一致，否则出险有免赔争议；电车跑长途前查沿途充电桩实时状态（节假日高速排队1-3小时是常态）；家庭账本油电成本分开设账，混记一个月就失去分析价值；卖车前算清"固定成本节省vs用车不便"，家里确有每周多次多人出行的需求就别减配成一台车；新能源车保险出险一次涨幅明显（可达20-40%），小额剐蹭（<1,500元）自费修通常比走保险划算，出险前先报修车价再决定是否报案。
