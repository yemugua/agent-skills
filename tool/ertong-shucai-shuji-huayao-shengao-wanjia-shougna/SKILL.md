# 玩具收纳与轮换制

玩具乱、买不停的核心解法不是多买收纳箱，而是「轮换制」——一次只放出 1/3 的玩具，其余封存，每月轮换一次，旧玩具变新玩具，购买欲直接下降。

## 一、分类箱体系

| 箱体 | 内容 | 数量建议 | 参考价 |
|---|---|---|---|
| 当季开放箱（3-4个） | 现在玩的积木/车/娃娃 | 每箱≤10件 | 15-25元/个（带盖带轮） |
| 封存轮换箱（2-3个） | 轮换库存，贴目录标签 | 每箱 15-20件 | 10-18元/个 |
| 零件小盒（透明分格） | 拼图、磁力片、小颗粒 | 按套分格 | 5-10元/个 |
| 大件竖放架 | 滑板车、平衡车 | 立式卡位 | 30-60元/个 |

## 二、轮换制操作模板
```
1. 全部玩具摊开 → 坏的/缺件的直接淘汰
2. 分成 3 组（A/B/C），每组保证「动手类+建构类+角色扮演类」各一件
3. 只放出 A 组，B/C 装箱贴标签（写内容清单+放回日期）
4. 每 4 周轮换一次：收回 A、放出 B
5. 孩子点名要某件 → 当作「重新见面」，新鲜感恢复
```

## 三、收纳费用与省下的钱算例
- 起步投入：开放箱3个×20元 + 轮换箱3个×15元 + 分格盒4个×7元 ≈ **123元**。
- 收益侧：轮换后孩子对「消失又出现」的玩具重复投入注意时间显著变长，家长新增玩具购买从月均 150-300 元降到约 50-100 元（旧玩具重获新鲜感），**年省约 1200-2400 元**。
- 临界点：玩具总量超过 60 件时轮换收益最明显；少于 20 件的家庭直接分区即可，不必买轮换箱。

## 四、减少乱购的三条规则（直接抄）
1. 「一进一出」：买新玩具前必须淘汰一件同类旧玩具。
2. 生日/节日清单制：把想要记进清单，一个月后仍想要才买——多数冲动欲一个月内自然消退。
3. 不买带大量一次塑料包装的组合盲盒类，玩具数虚增最快的就是这一类。

## 五、避坑要点
- 小零件（磁力珠、弹珠、3cm以下部件）单独上锁收纳，3 岁以下误吞是急诊常客。
- 收纳箱不要堆超过孩子身高可及的两层，够不着的箱子等于不存在。
- 轮换标签必须写内容清单，否则 3 个月后大人自己都不记得箱里是什么，轮换制就断了。

## 红线
> ⚠️ 提醒：磁力珠（巴克球）、水弹枪、小颗粒积木严禁进入 3 岁以下儿童可及区域，误吞两颗磁力珠可致肠穿孔属外科急症；轮换箱封存前确认玩具无电池漏液（干电池漏液腐蚀玩具且有化学风险）；淘汰玩具送人前消毒并确认无缺件尖锐断口。
