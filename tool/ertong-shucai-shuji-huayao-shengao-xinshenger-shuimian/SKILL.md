# 新生儿睡眠安全：仰卧、空床、同屋不同床

1岁内（尤其4个月内）婴儿猝死综合征（SIDS）的主要可防因素是睡眠姿势与环境。一句话：每次睡眠都仰卧、婴儿床里只有宝宝没有杂物、同屋不同床、室温20-24℃——四条做到，SIDS风险大幅下降。

## 睡眠环境安全清单

| 项目 | 安全标准 | 常见错误 |
|---|---|---|
| 姿势 | 仰卧，每次都仰卧 | 侧卧/趴睡「头型好看」 |
| 床面 | 硬质床垫+ fitted床笠 | 床垫上加褥子、软垫 |
| 床内物品 | 无枕头、被子、毛绒玩具、防撞条 | 「怕着凉」盖被子 |
| 同睡 | 同屋不同床（婴儿床贴近大床） | 大人搂睡/沙发上睡着 |
| 保暖 | 睡袋或包裹代替盖被 | 厚被子捂住口鼻 |
| 室温 | 20-24℃，摸颈背温热不出汗 | 空调直吹或过捂 |
| 头位 | 每次放下换换头的朝向 | 固定一侧睡出偏头 |

## 襁褓包裹方法（算例）

菱形包裹法：毯子铺成菱形，顶角上折，宝宝肩部置于折线下；左角裹过身体压在背下，底角上折至胸前（留出髋部空间），右角裹紧掖好。判断合格的标准：
- 双腿能屈曲外展——包裹过直过紧增加髋关节发育不良风险（DDH），「蜡烛包」直腿绑裹是错误做法。
- 胸前能塞进2-3指，不影响呼吸。
- 会翻身后（约3-4个月，个体差异大）立即停止包裹，改用睡袋。

月龄算例：0-2月用襁褓毯包裹；2-3月过渡到无臂约束睡袋；4月起一律分腿睡袋，T0G 0.5-1.0对应20-24℃室温，夜里不用再盖任何东西。

## 夜间安排要点

- 白天小睡也在婴儿床仰卧，「白天抱着睡没事」是误区——SIDS发生在小睡与夜间一样多。
- 夜间喂养后重新放回婴儿床并恢复仰卧，不要喂着喂着大人睡着搂着宝宝。
- 使用安抚奶嘴入睡可降低SIDS风险（母乳喂养已建立后再引入，约3-4周后）；奶嘴掉出不塞回去。
- 婴儿床远离窗帘绳、暖气、电线；床栏间隙≤6cm。

## 家人沟通话术

「医生说了，一岁内每次睡觉都要仰卧，床里只放宝宝和床垫床笠，怕冷用睡袋解决。老人觉得趴睡侧睡「舒服」、盖厚被「保暖」，这些恰恰是窒息和过热的风险来源，咱们照儿保医生的清单来。」

## 红线

> ⚠️ 提醒：趴睡、侧卧、沙发或大人床上搂睡是SIDS三大高危行为，没有任何「宝宝喜欢」可以豁免；任何宣称防扁头的定型枕/侧睡枕对1岁内婴儿都是窒息物，禁用；包裹过紧过直伤髋关节，过松滑到脸上堵口鼻，每次包完检查胸前三指与髋部活动度；会翻身后包裹必须立即停止，否则翻成趴位无法自救。
