# 夜间出行安全清单

夜间 22 点后是出行风险高发时段，核心原则：**走亮处、走人处、让家人知道你在哪**。

## 出发前清单

- [ ] 手机满电或带充电宝，电量低于 20% 先充
- [ ] 把路线发给家人：「几点出发—走哪条路—预计几点到」
- [ ] 尽量结伴；独自一人时告知家人实时位置（微信位置共享）
- [ ] 穿便于走动的鞋，贵重物品收内袋不外露
- [ ] 提前查好末班车/打车预约，不在路边久等

## 路上怎么做

| 场景 | 做法 |
|---|---|
| 选路 | 走路灯亮、有监控、有店铺的主路，不抄近道穿小巷 |
| 走路 | 靠马路内侧走；耳机只戴一只或不戴，随时听身后动静 |
| 防尾随 | 怀疑被跟：过马路一次→再过一次→仍跟着，立刻进最近便利店/保安亭，假装买东西并打电话 |
| 楼道 | 进楼前看身后有无陌生人跟上；电梯里站靠按键一侧 |
| 到家 | 进门先反锁，再回消息 |

## 求助与防身话术模板

- 向店员求助：「麻烦帮我个忙，后面有人一直跟着我，让我在你店里待几分钟，假装结账就行。」
- 打电话报警造势（对可疑人）：大声说「喂爸，我到小区门口了，你在楼下等我吧，对，就在监控下面。」
- 被纠缠：「我朋友两分钟后到，监控都拍着，你别过来。」同时后退到人多处，不激怒不硬碰。
- 打车夜归：上车即说「师傅麻烦按导航走」+ 行程分享家人。

## 随身小工具

1. **钥匙**：手握在指间可撑开掌，主要作用是握感与击打面，不追求伤害。
2. **130 分贝个人报警器**（约 10-20 元）：拉环即响，可吓退并引人注意，比防身器械实用。
3. **手机快捷拨号**：设置一键拨 110 / 紧急联系人。

## 红线

> ⚠️ 提醒：财物的损失永远小于人身安全——被抢时交出财物，记住特征事后报警；不酒后独行、不搭陌生人便车；防身器械选择合规的报警器，管制类器械（甩棍、电击器）携带本身违法。
