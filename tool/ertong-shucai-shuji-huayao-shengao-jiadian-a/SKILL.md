# 家电漏电与跳闸排查：三步定位，一张清单保全家用电安全

一句话点题：反复跳闸不用干等电工——按"拔电器→关回路→测外壳"三步，90%的家庭漏电点20分钟内自己能定位，附全年安全检查清单。

## 跳闸三步定位法

**第一步·判断是漏电还是过载**：漏电保护器（带试验按钮T的开关）跳=漏电；空开（只跳不标T）跳=过载/短路。看跳的是哪个开关：总闸跳→短路或总线漏；单回路跳→该回路电器漏。

**第二步·拔电器排除法**：跳闸回路上的电器逐个拔，每拔一个合闸试一次。合得上=刚拔的那个漏；全拔了还跳=线路本身漏（墙内线/插座老化）→叫电工。

**第三步·验电笔测外壳**：不拔插头，验电笔碰金属外壳，氖泡亮/显示12V以上=外壳带电（火线碰壳，危险！），立即断电停用该电器。洗衣机、热水器、冰箱是漏电三大高发。

| 常见漏电源 | 特征 | 处置 |
|---|---|---|
| 电热水器 | 洗澡时跳、加热中跳 | 立即停用！镁棒腐蚀/加热管绝缘破损，专业更换80-200元 |
| 洗衣机 | 湿手触外壳有麻感 | 排查进水阀/电机进水，漏保必须装且定期按试验钮 |
| 冰箱 | 化霜加热管漏，定时跳闸 | 温控/化霜电路检修100-150元 |
| 老旧墙线 | 全拔电器仍跳 | 线路绝缘老化，电工换段200-500元 |

## 家庭用电安全年度清单（直接打印勾选）

- [ ] 每月按一次漏保"试验"按钮，能跳闸=漏保活着；不跳=漏保失效，立即换（漏保无测试跳闸=失效，成本30-80元换）
- [ ] 浴室/厨房插座确认带防溅盖；插排不带水拖线
- [ ] 大功率（空调/热水器/电磁炉）不共用一个插排，专线专插
- [ ] 插头插座无发黑发烫（发烫=接触电阻大，火灾前兆，及时换插座10-30元）
- [ ] 热水器用前断电或确认带防电墙+漏保
- [ ] 电线无破皮、无被家具压踩
- [ ] 电器超年限排查：电热毯/电热水器/老冰箱是年限高危品

## 应急处置模板

发现外壳带电或异味异响：
1. 拉总闸（记下位置，教会家中老人小孩）；
2. 拔下嫌疑电器插头（勿用手直接碰金属外壳，隔干木/塑料）；
3. 验电笔确认外壳不再带电再恢复其他回路；
4. 疑似电器挂"故障勿用"纸条，送修或报废。

## 红线

> ⚠️ 提醒：①外壳带电（麻手）的电器绝对不能再通电"试试"，触电致命；②墙内线路漏电、配电箱内作业属于持证电工范围，普通用户只做拔电器和验电笔两步；③验电笔每年自检一次（插正常插座验示值），坏验电笔会漏报带电；④漏保失效不换等于裸奔——它保护的正是你摸外壳的那一瞬间；⑤涉水电器（热水器/洗衣机）维修后必须先测外壳无电再使用。
