热门景点门票预约不上就找黄牛是最大的坑——先算清套票划不划算，再走正规预约渠道，钱和票都安全。

## 套票划算临界点公式

买联票划算的条件：**联票价 < 单票之和 - 你实际会去的不足景点的票价**

算例：某古城三景点联票150元，单票分别为60+60+60=180元。
- 计划三个都去：联票省30元，划算
- 只去两个（第三个60元不去）：单买120 < 联票150，**单买省30元**——为「可能去」的景点预付联票是伪省钱

家庭算例：2大1小，儿童半价。单票 (60+60+30)=150/人组，联票150（儿童联票75）：三人都去，联票省 (180-150)+(180-150)+(90-75)=45元。

## 官方渠道识别清单

| 渠道 | 特征 | 风险 |
|---|---|---|
| 景区官方公众号/官网小程序 | 名称含景区全称，无加价 | 无 |
| 官方授权OTA | 平台店铺有「官方旗舰」标 | 无 |
| 二手平台个人卖家 | 加价20%-100%，称「内部渠道」 | 强实名景点无法入园，票作废 |
| 门口拉客黄牛 | 无票面凭证，现金交易 | 100%风险，无维权凭据 |

强实名景点（身份证绑定）黄牛票=别人的身份证号，闸机刷证直接被拦，钱票两空且无法投诉。
