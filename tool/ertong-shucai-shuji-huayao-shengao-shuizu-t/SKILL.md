# 乌龟爬宠饲养与冬眠

龟过冬只有两条路：冬眠或加温——选错一步就可能损耗，这一页给判断表、设备算例和自查清单，入冬前照做。

## 冬眠 vs 加温判断表

| 条件 | 可以冬眠 | 必须加温 |
|---|---|---|
| 龟龄 | 3年以上成龟 | 幼龟/苗（壳径<5cm） |
| 体质 | 当年进食正常、无病 | 体弱、患过病、刚痊愈 |
| 品种 | 草龟、花龟、巴西等温带种 | 热带种（缘摄/安布闭壳等，5℃以下必死） |
| 环境温度 | 冬季稳定5-15℃ | 暖气不足或波动大的房间 |

**临界点算例**：加温过冬设备=加热棒80W（50元）+晒背灯UVB（60元）+温控器（40元）=**150元一次性**；电费：80W+25W共105W×24h×120天≈300度×0.55元=**165元/冬**。一条加温季总开销≈315元；冬眠成本≈0元但需接受损耗风险（体质差的龟冬眠死亡率可达10-20%，苗更高）。**一只能买150元以上的龟，加温更划算**——小于这个价位的常见草龟成龟可冬眠。

## 冬眠操作模板（直接抄）

```
11月中：停食2周排空肠胃（冬眠中食物烂在肠胃=致命）
12月初：浅水冬眠（水过背）或椰土/苔藓湿润垫材，放10-15℃阴凉处
每2周：查看一次，补水防干；不动龟不喂食
次年3月：气温回升20℃→浅水唤醒→2天后首次少量喂食
```

**禁止**：冬眠中中途加热唤醒再放回（反复折腾必病）；室内有暖气（20℃+）却让龟"半冬眠"——最危险的中间态，要么降温冬眠要么加热过冬。

## 日常器材清单与月账

| 器材 | 价格 | 月耗 |
|---|---|---|
| 龟箱/整理箱 | 30-80元 | — |
| 晒台 | 15元 | — |
| 加热棒+温控 | 90元 | 冬季电费14元 |
| UVB灯（室内无自然光必配） | 60元（灯管年换） | 5元 |
| 龟粮 | 30元/500g | 8元 |

常规月账（不加温季）≈**15元**；加温季≈**30元**。晒背关键：自然阳光透过玻璃无效（UVB被阻隔），室内必须UVB灯。

## 常见病速查

腐甲（烂壳发白）→干养+碘伏+红霉素膏，2周；白眼病→水温30℃+氯霉素眼药水，隔离；拒食→先查水温（低于20℃不吃是正常），再查流鼻涕（感冒/肺炎需加温28℃就医）。

## 红线

> ⚠️ 提醒：冬眠前停食排空是铁律，未排空直接冬眠=肠胃炎死亡率极高；加热棒必须全水浸没+温控双保险，龟咬电线需套管；巴西龟等外来种严禁放生（入侵物种，违法且破坏生态）；幼龟苗冬眠风险极大，第一年一律加温过冬。
