# 宝宝出行清单与应急（随身包 / 突发处理 / 算例）

一句话点题：带娃出门翻车90%源于"东西在车里、人在三公里外"——按"身上一层、包里一层、车上补货层"三层装，突发时永远有最近的一层兜底。

## 三层清单

**身上层（腰包/口袋，取物<10秒）**
- 2片纸尿裤、1包湿巾（小装）、独立装奶粉一次量、安抚奶嘴、手机+充电宝

**包里层（妈咪包，取物<1分钟）**
- 纸尿裤4-6片、隔尿垫、换洗衣物1套、围嘴、辅食/饼干、水杯、小毯子、塑料袋3个（装脏物）、宝宝常用药（退热用美林/泰诺林按医嘱剂量、生理盐水、创可贴、防蚊液）

**车上/ stroller 篮层（补货）**
- 纸尿裤整包、备用衣物2套、大瓶水、遮阳/雨具、一件厚外套

## 突发处理流程

1. 发热：先摸颈后判断，≥38.5℃或明显萎靡→按体重喂退热药（布洛芬5-10mg/kg、对乙酰氨基酚10-15mg/kg），记录时间剂量；持续高热>24小时、抽搐、囟门膨出→立即就医，不硬扛。
2. 摔碰头部：观察48小时——呕吐、嗜睡叫不醒、走路不稳、单侧无力，任一出现马上急诊；只哭不吐可先冷敷观察。
3. 误吞：异物卡喉不会哭叫→立即海姆立克（1岁以下5次拍背+5次压胸法，勿用成人腹部冲击法）；吞下光滑小物→可观察大便，电池/磁铁→立即急诊。
4. 走丢：提前教"站在原地不动+喊妈妈"；出门前给孩子口袋放一张写手机号的卡片。

## 补货成本算例

临时在景区便利店补买 vs 提前装包：便利店纸尿裤单片约3-5元（整包50-70元）、湿巾10元、瓶装水3元——一次忘带 = 多花 **60-100元**；按每周出行1次、每月忘带1次计，分层清单一年省 **约1000元**，省下的更是处理崩溃的时间。

## 红线

> ⚠️ 提醒：退热药剂量必须按体重算、按说明书浓度算，阿司匹林禁用于儿童（Reye综合征）；1岁以下婴儿禁用蜂蜜与整粒坚果；外出药包每次回来检查是否过期；任何"土方法"（烫伤抹牙膏、流鼻血仰头）都不用——冷水冲15分钟、低头捏鼻翼才是对的。
