家里文件找不到，九成是命名问题，不是存储问题。命名规范一条就够：**`日期_关键词_版本.扩展名`**。

## 一、命名公式与示例

```
YYYYMMDD_主题_版本号.扩展名
例：20261119_宝宝疫苗本_v2.pdf
    20261119_幼儿园报名材料_v1.docx
    20260601_旅行_三亚_行程表_v3.xlsx
```

| 要素 | 规则 | 反例 |
|---|---|---|
| 日期前缀 | 8位 YYYYMMDD，放最前 | 「新建文档3」 |
| 关键词 | 2-6个字，写「内容是什么」 | 「最终版」「确认版」 |
| 版本 | v1/v2/v3，发送前删中间版 | 「最终版2改」 |
| 分隔符 | 下划线 `_`，禁用空格和斜杠 | 「2026/11/19 报名」 |
| 排序 | 日期前缀天然按时间排序 | 靠文件属性排序易乱 |

## 二、归档目录（三层封顶）

```
家庭文件/
├─ 01_证件票据/（身份证、房产证、保单、发票——永不删）
├─ 02_孩子档案/（疫苗本、体检、奖状、照片）
├─ 03_家庭事务/（合同、装修、报修记录）
└─ 99_归档/（每年12月把当年完成的搬进来）
```

超过三层必乱：层级多了没人愿意点进去存。

## 三、搜索效率算例

- 命名混乱时找「去年的体检报告」：翻文件夹+按修改时间排序+逐个打开，平均 **5-10 分钟**，且靠记忆。
- 规范命名后：在 Everything（Windows）/聚焦搜索（Mac）/文件管理器搜索框输入 `体检`，日期前缀直接锁定年份，**10 秒内命中**。
- 一年找文件 100 次 × 每次省 8 分钟 = **每年省 13+ 小时**；全家 3 口人按各自找自己的算，省 40 小时以上。
- 版本号防事故：误发 v1 旧版给老师的概率从「经常」降到 0——只保留对外版，中间版打包进 `99_归档/2026_工作稿.zip`。

## 四、可复制话术/模板

- 给家人的规范说明（直接转发）：
> 「以后存文件都用这个名字格式：日期_是什么_版本号，比如 20261119_水电费缴费单_v1.pdf。存的地方只有三个：证件票据、孩子档案、家庭事务。找不到就搜关键词。」

- 每月 5 分钟归档提醒（设日历重复）：
> 「每月1号：把桌面和下载文件夹清空——有用改名的进对应目录，没用的删。」

## 五、避坑清单

| 坑 | 后果 | 解法 |
|---|---|---|
| 「最终版」当版本号 | 最多能到「最终版7」 | v2/v3 数字递增 |
| 微信文件直接另存 | 全是「 IMG_20261119 」 | 另存时立刻改名 |
| 日期放中间 | 排序乱 | 日期永远最前 |
| 目录超过三层 | 没人维护 | 三层封顶+搜索兜底 |

## 红线
> ⚠️ 提醒：身份证、房产证、银行卡照片务必存本机加密目录（压缩包加密码），不要裸放在网盘公共目录；云同步的「已删除」不等于删干净，敏感旧文件定期在网盘回收站二次清空。改命名习惯第一周最容易放弃——只坚持「下载文件夹当天清空」一条，其余自然养成。
