# 婚前体检与领证流程：免费的婚检别错过，材料带齐一次过

婚检是国家免费提供的公共卫生服务（含在基本公共卫生经费里），很多人自费300-800元做了本该免费的项目。领证现在已全国通办，但材料带错仍要跑两趟。

## 免费婚检申请流程

1. **时限**：领证前3个月内、或领证后1个月内均可做免费婚检（各地微调，以当地卫健部门为准）。
2. **路径**：领证时民政局现场领取《免费婚检服务卡》→ 到指定妇幼保健院检查；或直接到户籍地/居住地妇幼保健院，出示身份证+结婚证（领证后）即可免费。
3. **项目清单**：血常规、尿常规、胸透、肝功能、梅毒筛查、淋病筛查、妇科/男科检查、地中海贫血筛查（高发地区）、婚前卫生指导。自费可加：双方染色体、精液分析、HPV、ABO溶血（RH阴性者）。

## 领证材料清单（全国通办时代）

| 材料 | 要求 | 常见翻车点 |
|---|---|---|
| 双方身份证 | 有效期内 | 身份证消磁/过期当场被拒 |
| 双方户口簿 | 首页+本人页 | 集体户口需借页盖章；户口簿地址与实际不符可能被要求先更正 |
| 3张2寸合影 | 现场可拍，约30-50元 | 自己带的照片须红底近期 |
| 再婚者 | 离婚证/法院判决书生效证明 | 判决书须附生效证明，漏带白跑 |

## 算例：时间与费用

- 免费路径：领证当天民政局拿卡→妇幼保健院婚检，0元；自费加项染色体（约600元/对）+HPV（约300元）按需。
- 跨省领证：2023年起内地居民结婚登记"全国通办"，凭双方身份证+户口簿任一婚姻登记机关办理，无需回户籍地；但**补领结婚证**仍需原登记机关或一方户籍地办理。
- 时间算例：提前1个月预约（地方民政局周六号源紧张），婚检半天+领证半天，共1个工作日可完成；未预约高峰日排号2-4小时。

## 可复制准备清单

```
□ 身份证×2（查有效期）
□ 户口簿×2（集体户先借页）
□ 3张2寸红底合影
□ 离异再婚：离婚证+判决书生效证明
□ 免费婚检卡（领证当天现场领）
□ 提前30天在"民政通"小程序/当地民政局公众号预约
```

## 红线

| 坑 | 表现 | 应对 |
|---|---|---|
| 自费婚检 | 不知道有免费政策 | 先问当地妇幼保健院，别直接去民营体检机构 |
| 户口簿地址旧 | 与身份证不一致被拒 | 先去派出所更正再领证 |
| 婚检结果误解 | 指标异常恐慌 | 婚检是筛查不是诊断，异常按建议复诊 |
| 预约错通道 | 百度搜到中介网站 | 只用"民政通"小程序或政府官网 |

> ⚠️ 提醒：婚检发现重大传染性疾病有告知义务，隐瞒婚检重大病史可能构成婚姻撤销事由；免费婚检记得领结果报告，领证后一个月内有效期内尽快完成。
