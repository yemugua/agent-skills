4S店养车最贵的不是机油，是「推荐项目」——一次保养被推销发动机清洗、油路养护，多花500~1500元。按车厂手册保养，其余一概问清必要性。

## 一、周期表（以家用车为准，以车主手册为准绳）

| 项目 | 周期 | 参考价（含工时） |
|---|---|---|
| 机油+机滤 | 全合成1万km或12个月 | 400~700元 |
| 空调滤芯 | 1年或1万km | 4S店150~250元，自己换50元（十分钟自己可装） |
| 空气滤芯 | 2万km | 100~150元，自己换40元 |
| 火花塞 | 4~8万km（按材质） | 300~800元 |
| 刹车油 | 2年或4万km | 200~350元 |
| 防冻液 | 5~8年或按手册 | 300~500元 |
| 变速箱油 | 手册为准（多数6~8万km） | 600~1500元 |

## 二、过度保养识别表

| 被推销项目 | 是否必要 |
|---|---|
| 发动机内部清洗 | 全合成机油正常使用不需要，拒绝 |
| 油路/节气门免拆清洗 | 怠速抖动或油耗明显升高才做，否则拒绝 |
| 燃油宝/添加剂 | 直喷车按手册，普通车型基本无效 |
| 提前换防冻液/刹车油 | 按「时间或里程先到」执行，提前=浪费 |
| 保养套餐预存 | 按单次价比价，预存折扣<8折才考虑，警惕闭店跑路 |

## 三、算例：一年两次保养的差价

- 被「全套推荐」：小保养700+清洗项目600+空调滤4S价250=1550元。
- 按手册：小保养500+空调滤自己换50=550元。
- **每次省1000元，两年省约4000元**，足够覆盖一次四轮换位+刹车片。

## 四、工单核对清单（签字前过一遍）

1. 机油品牌/型号/粘度与报价单一致（0W-20还是5W-30，混用伤发动机）。
2. 旧件当场查看并带走（旧机滤、旧火花塞是你的凭证）。
3. 里程数记录在工单，防「多算公里数」。
4. 拒绝未确认的追加项目——工单手写添加必须你签字。

## 五、可复制话术

- 「先按车主手册的保养菜单做，推荐项目写个单子给我，我考虑。」
- 「机油桶当面拆封，旧件我要带走。」
- 「空调滤芯我自备，请只收工时费或免工时。」

## 红线

> ⚠️ 提醒：① 保养周期以车主手册为准，销售顾问的「提前保养建议」不可作为依据；② 出保前保养索要正规工单+发票并留档，出险/质保纠纷时是关键证据；③ 用假机油（低价套餐常见）伤发动机且可能影响质保——只接受当面拆封的正规品牌；④ 预存保养套餐先查门店经营状况，单店闭店不退余额的纠纷高发；⑤ 外部保养不影响质保（法规已明确），但必须保留凭证。
