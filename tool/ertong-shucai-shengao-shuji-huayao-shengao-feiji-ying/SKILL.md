# 带婴儿坐飞机实务（摇篮 / 婴儿票 / 算例）

一句话点题：带婴儿飞行的省钱省力全在"提前申请"——婴儿票、摇篮、第一排座位、优先登机，每一项都要在值机前锁定，机场现求基本没有。

## 票务规则与算例

- **婴儿票（未满2周岁）**：国内为全价票的 **10%**，不单独占座、无免费行李额（多数航司）+1件婴儿摇篮限额；需出生证明/户口本购票。
- **儿童票（2-12周岁）**：国内为全价票的 **50%**，占座、有行李额。
- 算例：成人经济舱全价1500元、实际折扣价700元——婴儿按全价10%=**150元**（注意：婴儿票比成人折扣票贵的情况不存在但比"占座儿童票"省）；儿童票=750元，若成人买到500元特价票，儿童票750元反而更贵，此时可尝试为儿童买成人特价（部分航司允许儿童购成人票，退差价凭政策）。
- 摇篮（Bassinet）：限体重≤10-12kg/身长≤70cm，挂在第一排舱壁，数量极少（每航班1-3个）——**购票后立即致电航司申请**，值机再要=没有。

## 出行流程

1. 证件：婴儿用出生证明或户口本；国际航线需护照+目的国签证。
2. 座位：不申请摇篮就选"可预约的安全出口以外的过道/靠走道位"，方便起身。
3. 耳压：起飞下降时喂奶/含水/吃奶嘴，吞咽动作平衡中耳压力；睡着了也别叫醒，醒着才有吞咽——起飞前算好喂奶时间。
4. 行李：婴儿车可推到登机口再托运（gate check，免费）；奶粉、辅食、水过安检可申请试喝，不必倒掉。
5. 申请优先登机：多数航司带婴儿乘客可提前登机，装车、放行李从容。

## 值机柜台话术

> "我们有X个月大的婴儿，已购票并提前申请了摇篮/第一排座位，麻烦确认一下；另外想申请带婴儿优先登机，谢谢。"（摇篮确认单/航司客服工号记下来，值机起争议时出示。）

## 红线

> ⚠️ 提醒：出生不满14天（部分航司7天）的婴儿多数航司拒绝承运，需医生证明；早产儿、心脏病婴儿先问医生能不能飞；感冒鼻塞严重时慎飞（耳压平衡差，易中耳炎）；摇篮里全程须系专用安全带，颠簸时大人自己也要系好——颠簸伤人主要伤的是没系安全带的大人抱不住孩子。
