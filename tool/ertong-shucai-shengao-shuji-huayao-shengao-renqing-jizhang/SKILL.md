一句话点题：人情账不记，三年后只剩"感觉亏了"——一张表记清每户的"我给TA"与"TA给我"，回礼金额用净额公式倒推，谁也不欠谁。

## 人情账表格列设计（Excel/手机备忘录照抄）

| 列 | 内容 | 示例 |
|---|---|---|
| A 日期 | 2026-01-15 | |
| B 关系户 | 王强（同事） | 每户一行累计 |
| C 事项 | 婚宴 | |
| D 我付 | 600 | |
| E 对方付（对我） | 800 | |
| F 净额 | =E-D 或 -D | 正=我还欠，负=对方欠 |

关键用法：**按关系户汇总净额**，不是按事件记流水——流水记完就散，净额才指导回礼。

## 回礼金额公式

回礼 = max(对方上次付我的金额 × 1.2, 当前关系档位下限)，且尾数取吉利数。

## 算例：三户对账

| 关系户 | TA给我 | 我给TA | 净额 | 下次回礼策略 |
|---|---|---|---|---|
| 王强 | 800（2023婚礼） | 600（当时随） | +200我欠 | 他满月酒随1000（800×1.2=960→1000） |
| 李芳 | 500（我婚礼） | 0 | +500我欠 | 她孩子满月随600，还差100记负，升学宴补 |
| 张伟 | 300 | 800（我随他婚宴） | -500他欠 | 他下次有事随300原额即可，不倒贴 |

## 收支平衡自检（年度）

- 年度人情支出 ÷ 月薪 > 20%：触发减档，只保留亲戚+挚友，普通同事降到100-200。
- 某户三年净额一直+且对方从无回礼迹象：止损，改随200档或礼到人不到。

## 可复制记账模板（文本版）

```
【人情账】王强
2023-05 我婚宴 他随 800
2026-01 他满月 我随 1000 → 净额 -200（他欠我200）
下次：升学宴随600即可拉平
```

## 红线

> ⚠️ 提醒：①净额只自己看，永远不要向对方摊牌"你欠我多少"——人情账的功能是心里有数不是讨债；②回礼宁多100不差100，差100记3年不如当场多随；③夫妻各自随礼要进同一张表，否则两边各记一份虚增一倍支出。
