# 复诊随访与病历整理：把散落的检查报告变成一套可查阅的档案

一句话点题：孩子反复看病最怕「医生问上次结果你翻不出来」——一个按时间归档的文件夹+一张随访表，能让每次复诊效率翻倍。

## 一、报告归档结构（手机相册+云盘双备份）

```
儿童病历/
├── 2026/
│   ├── 03-12_血常规_呼吸道感染.jpg
│   ├── 03-12_处方_阿奇霉素.jpg
│   └── 04-02_复查胸片_肺炎恢复.jpg
└── 出院小结/（单独放，永久保存）
```
规则：照片统一命名「日期_项目_结论」，关键数值（血象、体温曲线）在相册里额外加收藏；出院小结、诊断证明原件扫描存云盘，复印件办保险理赔/入园休学都用得上。

## 二、随访时间表（复制即用）

| 病种 | 复诊节点 | 复查内容 |
|---|---|---|
| 肺炎恢复期 | 出院后 1 周、4 周 | 听诊+必要时胸片 |
| 中耳炎 | 用药后 2 周 | 耳镜复查（确认积液吸收） |
| 泌尿系感染 | 治疗结束后 1–2 周 | 尿常规 |
| 儿童近视 | 每 3–6 个月 | 视力+眼轴 |
| 哮喘/过敏 | 每 1–3 个月 | 肺功能或症状评分 |

设手机日历重复提醒，提前 3 天提醒挂号——复诊号比首诊号更难临时挂上。

## 三、见医生前的「三句话清单」（直接说）

1. 「这次是 X 月 X 日之后第几次症状，最近一次用药是 …（药名+剂量+停药时间）。」
2. 「上次检查的关键结果是 …（只报数值，如白细胞 13.5、CRP 45）。」
3. 「我最担心的问题是 …，请帮我判断是否需要进一步检查。」
医生平均接诊 3–5 分钟，这三句话能把有效信息全部给到。

## 四、问医生清单模板（复诊时按顺序问）

1. 这个结果和上次比是好是坏？（要趋势不要单点）
2. 药是继续、停、还是减量？什么时候停？
3. 什么信号出现需要提前来？（如发热超 3 天、精神差）
4. 下次复查做什么项目、隔多久？

## 红线

> ⚠️ 提醒：报告照片只做备份，法律与理赔场景（商业保险、伤残鉴定、休学证明）一律用医院盖章原件或病案室打印的复印盖章件——手机截图保险公司和学校可拒收。不要凭上次处方自行延续用药，抗生素/激素类药物的复诊续方必须由医生当面判断。
