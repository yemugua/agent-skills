# 衣柜收纳与换季整理

衣柜乱的本质是「挂得太密+叠得太高+换季不分类」——用竖叠法提可视率、真空袋压体积、收纳盒做分区，一次整理能维持一整季。

## 一、竖叠法（文件折叠）操作要点
1. 衣服折成约 15×20cm 的长方块（T恤：两边袖子内折→下摆上折→对折）。
2. 按颜色/类别竖立排进抽屉或浅收纳盒，像文件一样一眼看到所有衣服。
3. 竖叠 vs 传统平叠对比：同格容量提升约 40%，取一件不乱一摞。

## 二、换季收纳工具表

| 工具 | 适用衣物 | 参考价 | 注意 |
|---|---|---|---|
| 真空压缩袋（80×100cm） | 羽绒服、厚被、毛毯 | 5-8元/个 | 羽绒服压缩≤70%，过度压缩损伤蓬松度 |
| 挂式真空袋 | 大衣、西装 | 12-18元/个 | 带挂孔，免折叠防褶皱 |
| 牛皮纸收纳箱 | 怕压的棉麻、真丝 | 10-15元/个 | 透气不回潮，优于塑料密封 |
| 布艺收纳盒（40×30×25cm） | 常穿叠放衣物 | 8-15元/个 | 选带透明视窗款 |
| 衣柜分层隔板 | 防叠堆过高 | 10-20元/片 | 单堆不超过 30cm 高 |

## 三、收纳用品费用算例
以 2 米衣柜 + 1 个 1.2 米五斗柜的换季为例：
- 6 个真空袋（羽绒服4件+两床被）×6元 = 36元
- 8 个布艺收纳盒 ×12元 = 96元
- 4 片分层隔板 ×15元 = 60元
- 干燥剂/樟脑替代品（雪松块10块）= 25元
- **合计约 217元**，替代定制内部改造（千元级）即可完成换季。

临界点判断：真空袋省钱的前提是衣物量≥8件厚冬装；少于这个量直接用收纳盒叠放即可，不必买抽气泵袋。

## 四、可直接复制的换季流程模板
```
第1步 全部清空 → 分四堆：留下 / 换季封存 / 送人(3年未穿) / 丢弃
第2步 封存件洗净晒干 → 真空袋+干燥剂 → 标签写「品类+数量+年份」
第3步 留下件竖叠进收纳盒 → 当季常穿挂前排、偶用放高处
第4步 拍照记录每盒内容，贴在盒外侧
```

## 五、避坑要点
- 樟脑丸对蚕丝、羊毛有腐蚀且需远离儿童，改用雪松块或密封袋本身防虫。
- 真空袋别装棉被超过半年不透气，每年取出来通风一次。
- 3年未穿的衣服按均价 100 元折算，10 件就是 1000 元的死资产——先清再买新收纳品，顺序不能反。

## 红线
> ⚠️ 提醒：真空袋不可压缩真丝、羽绒蓬松服长期存放、皮革制品（会永久压痕）；收纳用品先清空再购买，避免「为收纳乱买的衣服再买收纳」循环；含樟脑的箱包取用时先通风，儿童房衣柜禁用樟脑丸与萘制品。
