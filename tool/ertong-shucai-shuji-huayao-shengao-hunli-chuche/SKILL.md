接亲迟到在婚俗里是大忌，客人找不到停车位是投诉重灾区——车队路线和酒店停车各需要一张提前做好的执行表，不能靠当天临场发挥。

## 接亲路线规划原则

1. 提前一天用地图APP按出发时刻实测路线（当天早高峰与平时不同），选两条：主路线+备用路线。
2. 避开：限行路段（查当日尾号限行）、施工路段（地图施工标记）、大型市场/医院门口。
3. 尽量走「不走回头路」的大环线（婚俗讲究，也确实减少对向冲突），全程控制在30-45分钟内。
4. 主婚车头车坐熟悉路线的人（伴郎或司机队长），每车发一张路线截图+车牌清单+头车电话。
5. 车队保持：对讲机/微信群语音报点，过路口后头车等齐再走，跟丢就以「下一个地标汇合点」为准。

## 接亲时间表算例

| 时刻 | 事项 |
|---|---|
| 6:30 | 车队集合贴车头花（提前一晚贴好更稳） |
| 7:00 | 出发去新娘家 |
| 7:35 | 到达，堵门游戏限30分钟（闹钟提醒） |
| 8:15 | 出发去新房或酒店 |
| 9:00 | 到达酒店，新人休息补妆 |
| 10:58 | 婚礼仪式开始（吉时按两家商定） |

堵门超时10分钟，后面全部顺延——堵门红包设上限并告知伴娘「到点必开门」，比加钱有效。

## 酒店停车安排清单

1. 提前一周找酒店宴会销售：确认宴会客人是否有**免费/协议停车**（多数可谈：宴请满X桌免X小时），要书面确认（微信截图即可）。
2. 问清：车位总数、宴会高峰是否对外营业（对外营业的酒店高峰必爆）、有无地下车库入口位置、限高（婚车加高礼宾车注意）。
3. 安排：门口留2个「新人及长辈下车位」（用雪糕筒/安排保安），主婚车到位后直接停门口显眼处供拍照。
4. 客人指引：请柬/群通知里写清「导航至XX酒店P2入口，宴会厅在3楼，凭宴请桌数免停车费」；安排2名亲友在车库入口举牌引导1小时。
5. 备用：酒店满位时提前谈好隔壁写字楼/商场的停车协议（高峰时段约10-20元/小时，按30辆车2小时预算200-500元）。

## 备用方案表

| 风险 | 预案 |
|---|---|
| 早高峰堵车 | 启用备用路线；仍堵则新人先乘地铁/打车直奔，车队后到补拍 |
| 车辆抛锚 | 备用1辆车随队（租车队时可加1辆，费用约200-400元） |
| 雨天 | 备一次性雨伞20把+车内防湿座椅垫；拍照点位改室内 |
| 停车爆满 | 启用隔壁停车场协议+引导牌改址，群发更正消息 |

## 可复制话术

与酒店销售确认：

> 「我们是X月X日X厅的宴会客户，请书面确认：宾客凭宴会是否免停车费、免费几小时、车位总数、P区入口位置。另外我们能否在门口预留两个下车位？我们自备雪糕筒。」

群发客人的指引模板：

> 「各位亲友：X日婚礼导航请设『XX酒店-地下车库入口』，凭宴会免停车费X小时；宴会厅3楼。开车请12点前到，晚了车位紧张，可停隔壁XX大厦（步行3分钟）。」

## 红线

> ⚠️ 提醒：婚车租凭合同要写明超时费单价（常见超1小时加100-300元/车），路线规划失误产生的超时费别默认全由你承担，可协商；酒店口头免停车费不作数，拿截图；接亲路线提前一天实测，地图给的「最快路线」未算早高峰排队进门时间。
