# 旅行应急包与儿童药品清单：分场景配置、剂量、预算

带娃出行的应急包按场景配，不按"越多越好"配——本文给出三档清单、儿童常用药剂量速查表和一份精确到元的预算算例。

## 一、三档配置（按出行类型）

| 档位 | 适用 | 体积 |
|---|---|---|
| 基础档 | 1-3天短途/高铁游 | 一个化妆包 |
| 标准档 | 3-7天自由行 | 中号收纳袋 |
| 完整档 | 自驾长途/海岛山区 | 小背包 |

**基础档**：退热贴、体温计（耳温枪迷你款）、创可贴10片、酒精棉片、口服补液盐1袋、儿童常用药（见下表）。
**标准档** = 基础档 + 防晒霜（儿童SPF30+）、驱蚊液（避蚊胺≤10%）、晕车药、无菌纱布+医用胶带、镊子、生理盐水喷鼻。
**完整档** = 标准档 + 弹性绷带、烫伤膏、碘伏棉签、一次性冰袋、电解质水冲剂、防水袋（药品防潮）。

## 二、儿童常用药与剂量速查（体重为准，遵说明书）

| 症状 | 药 | 剂量规则 |
|---|---|---|
| 发热≥38.5℃不适 | 布洛芬混悬液 | 5-10mg/kg/次，间隔≥6小时，24h≤4次 |
| 发热（3-6月龄） | 对乙酰氨基酚 | 10-15mg/kg/次，间隔≥4小时 |
| 腹泻 | 口服补液盐III | 每次稀便后补50-100ml，防脱水重于止泻 |
| 晕车 | 茶苯海明 | 6岁以上按体重，上车前30分钟服 |
| 过敏/蚊虫叮咬 | 炉甘石洗剂（外用） | 局部涂抹；口服抗组胺药遵医嘱 |

> 3岁以下、首次用药、症状超48小时不缓解——就医优先于自行用药。

## 三、非药品清单（常被漏掉的高频项）

- 呕吐袋×3（晕车/船上）、密封袋（湿衣/药品分类）
- 儿童口罩、防晒帽、速干衣一件（出汗/落水替换）
- 保温杯（接热水冲奶冲药）、吸管杯
- 孩子的一张写有家长电话的卡片/手环（走失应急）
- 湿巾2包、免洗洗手液

## 四、预算算例（标准档，两大一小5天游）

| 项目 | 金额 |
|---|---|
| 布洛芬混悬液（100ml） | 18元 |
| 口服补液盐III（5袋） | 15元 |
| 炉甘石洗剂 | 12元 |
| 生理盐水喷鼻 | 25元 |
| 耳温枪（一次投入，可复用） | 79元 |
| 创可贴+棉片+纱布组合包 | 20元 |
| 驱蚊液+防晒霜 | 45元 |
| 收纳袋+杂项 | 30元 |
| **合计** | **约244元**（耳温枪为一次性投入，复用后单次出行实际约165元） |

对比：异地药店夜间买儿童退烧药常缺货且溢价20-50%，景区药店更贵——**出发前在家配齐是省钱也是保命**。

## 五、模板：出行前一晚核对口诀

```
一查证件（身份证/疫苗本），二查药（退烧/补液/驱蚊），三查电（充电宝/耳温枪电池），四查袋（呕吐袋/密封袋），五查卡（家长联系卡挂娃身上）。
```

## 红线

> ⚠️ 提醒：布洛芬6月龄以下禁用、对乙酰氨基酚3月龄以下禁用，剂量按体重不按年龄猜；阿司匹林儿童禁用（瑞氏综合征）；成人药掰半喂儿童是常见错误（缓释片掰开失效且过量）；药品过安检/海关需原包装+说明书，处方药带处方；孩子持续高热≥39.5℃不退、精神萎靡、尿量明显减少——放弃"扛一扛"，立即就医。
