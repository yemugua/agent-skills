挂错号=白排三小时队再重新挂号；检查资料没带齐=重复拍片重复花钱。本文给挂号前自查、资料清单和医生沟通模板。

## 挂号前自查表（先定位科室再挂号）

| 症状 | 正确首诊科室 | 常见挂错 |
|---|---|---|
| 头晕伴天旋地转、翻身加重 | 耳鼻喉科（耳石症） | 神经内科（排长队后转诊） |
| 心慌胸闷伴手麻、失眠 | 先查心内科排除器质病→无异常看心理/精神科 | 反复挂心内科重复心电图 |
| 腰腿痛伴腿麻放射痛 | 骨科/脊柱外科 | 肾内科（被腰部位置误导） |
| 胃痛+黑便 | 消化内科（急） | 按普通胃病慢号排期 |
| 头痛+眼胀视物模糊 | 眼科（先排除青光眼急症） | 神经内科 |
| 单纯体检报告某项↑↓无不适 | 按报告建议科室或全科/健康管理门诊 | 挂专家号问常规异常 |
| 皮肤起疹疑药疹/食物相关 | 皮肤科或变态反应科 | 挂内科 |

经验法则：**症状长在哪个器官首诊哪个科，伴发急症标志（黑便/胸痛/视物骤变）优先排除急症**；拿不准时挂"全科/普通内科"做初筛，比挂错专家号省一半时间。

## 避免重复检查：资料带齐清单

1. 影像资料原件：CT/MRI 的**胶片+光盘或电子影像**（不是只带报告单——医生要看原始图像），检查在6个月内的多数可沿用；
2. 化验单按时间排序装订，异常值画圈标注；
3. 用药清单：药名+剂量+吃了多久（拍照药盒即可），比口述"吃那个白色小药片"准确得多；
4. 以往诊断证明、出院小结、病理报告（有则必带）。

医生沟通模板（初诊3句话）："我这次主要是 X 症状，持续 X 天/月，加重条件是 X。之前在 X 医院做过 X 检查（结果X），今天带了胶片和报告。目前用药是 X，想解决的问题是 X。"——这三句话覆盖问诊80%的信息点，显著减少重复问诊与重复开单。

## 检查互认与省钱路径

- 检查结果互认：同级或上级医院对近期（一般影像3个月、部分化验3-7天）检查有互认要求，主动出示原片并说明检查时间，可减少重复开单；
- 算例：胸腹部CT在三甲约400-600元，带原片避免重做=直接省400元+免去再排队2小时；初诊挂普通号确诊路径走通后，复诊再挂专家号带齐资料，一次专家号解决，比连挂三次专家号省两笔挂号费与三次请假半天。
- 医保报销注意：门诊检查是否报销看当地门诊统筹政策，住院前后几日内的同项目门诊检查通常可并入住院结算，出院结算时主动向医保窗口问一句。

## 红线

> ⚠️ 提醒：① 急症标志（胸痛/黑便/意识改变/突发剧烈头痛/视物骤变）直接急诊，不要按普通门诊流程等号；② "检查结果互认"以医生结合病情判断为准，病情变化时医生重开检查是医疗规范不是乱收费，别机械拒绝；③ 自购药物也要告知医生（含保健品、中草药），漏报药物史是药物相互作用事故的主因；④ 网上问诊不能替代急症首诊，只能用于复诊续方与轻症咨询；⑤ 别人推荐"这个专家看这个好"先查该专家的执业方向，科室相近但亚专科不同（如骨科分脊柱/关节/创伤）挂错等于白排。
