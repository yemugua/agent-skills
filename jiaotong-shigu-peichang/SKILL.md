一句话：交通事故人伤赔偿有 12 项法定科目，每项都有公式和上下限，用这张表自己算出总账，理赔谈判不吃亏。

## 12 项科目与公式

| 科目 | 公式 | 关键点 |
|---|---|---|
| 医疗费 | 实际票据 | 含后续治疗费（需医嘱或鉴定） |
| 误工费 | 日收入×误工天数 | 见误工费条目 |
| 护理费 | 护理人员收入或当地护工劳务报酬×护理天数 | 无薪家属按护工价算 |
| 营养费 | 一般 30-50 元/天×医嘱天数 | 需医嘱「加强营养」 |
| 住院伙食补助 | 当地国家机关出差标准×天数（各地 50-100 元/天） | |
| 残疾赔偿金 | 城乡居民人均可支配收入×20 年×伤残系数（1-10级=100%-10%） | 60 岁以上每增 1 岁减 1 年 |
| 精神抚慰金 | 各地 10 级约 5000，每级递增约 5000 | 需构成伤残 |
| 被扶养人生活费 | 人均消费支出×年限÷扶养人数 | 未成年人算到 18 岁 |
| 交通费 | 实际票据 | 就医、转院合理开支 |
| 残疾辅助器具 | 普通适用型价格 | 假肢按更换周期 |
| 财产损失 | 维修票据 | 衣物手机损失也算 |
| 鉴定费 | 实际发票 | 由败诉方或全责方承担 |

## 精确算例（10 级伤残，全责方担责）
假设当地居民人均可支配收入 52000 元/年，伤者 40 岁，住院 30 天，月薪 8700 元：
- 残疾赔偿金 = 52000×20×10% = 104000 元
- 误工费 = 8700÷21.75×（30+90 医嘱休养）= 400×120 = 48000 元
- 护理费 = 120 元/天×30 = 3600 元；营养费 = 40×60 = 2400 元；伙食补助 = 100×30 = 3000 元
- 精神抚慰金 ≈ 5000 元
合计约 166000 元，其中交强险医疗限额 1.8 万、死亡伤残限额 18 万内优先赔付，超出部分按责任比例由商业三者险/个人承担。协商时低于此数 15% 以上即显著吃亏。

## 红线
| 坑 | 后果 | 正确做法 |
|---|---|---|
| 私了后才做伤残鉴定 | 保险公司拒赔或数额无法追溯 | 治疗终结 3 个月内先鉴定再谈 |
| 未经交警认定私下和解 | 责任比例吃亏 | 索要交通事故认定书 |
| 一次性协议漏写后续治疗 | 再治疗自费 | 协议保留「后续治疗费另行主张」条款 |
| 拿调解书前交原件 | 保险要原件核赔 | 谈判只给复印件 |

## 红线
> ⚠️ 提醒：伤残鉴定须在治疗终结后由有资质的司法鉴定机构作出，自行找医院开「伤残证明」无效；赔偿标准每年更新（各地人均可支配收入数据），起诉前查最新年度数据；诉讼时效 3 年。
