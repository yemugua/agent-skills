爸妈把体检单发过来时，你需要的不是科普，是一张「数值→分几档→多久内做什么」的对照表。本文给三大慢病核心指标（血压、血糖、尿酸）+ 肝肾功能与血脂的关键线，配复查时机阶梯和向医生提问的话术模板。

## 一、核心指标判读表（对照即用）

### 血压（家庭自测/诊室，mmHg）
| 收缩压 | 舒张压 | 档位 | 动作 |
|---|---|---|---|
| <120 且 <80 | | 正常 | 每年测 |
| 120-139 或 80-89 | | 正常高值 | 改生活方式，1-3个月内复测 |
| 140-159 或 90-99 | | 1级高血压 | 不同日2次复测确认，确认后就医评估是否用药 |
| ≥160 或 ≥100 | | 2级及以上 | 1-2周内挂号，大概率需药物 |
| ≥180 或 ≥110 | | 高血压急症边缘 | 当天就医；伴头痛/胸痛/视物模糊立即急诊 |

注意：家庭自测比诊室低5mmHg左右，135/85家庭值≈140/90诊室值。

### 空腹血糖 + 糖化血红蛋白（HbA1c）
| 空腹血糖 mmol/L | HbA1c % | 档位 | 动作 |
|---|---|---|---|
| <5.6 | <5.7 | 正常 | 每年查 |
| 5.6-6.9 | 5.7-6.4 | 糖尿病前期 | 控饮食+减重5%，3-6个月复查；此时干预可逆 |
| ≥7.0 或 HbA1c≥6.5 | | 达糖尿病诊断线 | 择期就医开始规范治疗，别拖 |
| 随机≥11.1 伴多饮多尿消瘦 | | 高度提示 | 尽快就医 |
| <3.9（服降糖药者） | | 低血糖 | 立即吃15g糖（3块方糖/半杯果汁），15分钟复测 |

### 尿酸（μmol/L）
| 数值 | 档位 | 动作 |
|---|---|---|
| <420（男）/<360（女） | 正常 | 每年查 |
| 420-540 无症状 | 无症状高尿酸 | 先饮食干预：戒啤酒/内脏/浓肉汤，多喝水2000ml/天，3个月复查 |
| >540 | 药物评估线 | 就医评估是否起始降尿酸药 |
| 关节突发红肿剧痛（大脚趾常见） | 痛风发作 | 发作期就医，不自行用降尿酸药 |

### 其他必看的四条线
- 低密度脂蛋白（LDL-C）：普通人<3.4；已有糖尿病/心血管病者<2.6甚至<1.8——看报告要对照「危险分层」，不是越低越好就够。
- 肌酐：男>133、女>115 μmol/L 提示肾功能可能受损，需结合 eGFR。
- 谷丙转氨酶（ALT）：>40 U/L 且非空腹/熬夜因素，2-4周复查仍高再查原因（脂肪肝最常见）。
- 同型半胱氨酸>15：补叶酸（0.4-0.8mg/天，几元钱）+ 限酒，H型高血压卒中风险叠加。

## 二、复查时机阶梯（一图决定「多急」）

```
当天急诊：胸痛/意识改变/血压≥180/110伴症状/血糖<3.9伴昏迷
1-2周门诊：2级高血压初诊、HbA1c≥6.5、肌酐超标
1-3个月：1级高血压复测、尿酸>540、ALT持续>40、LDL超标首诊
3-6个月：所有「前期」档（生活方式干预后复查）
每年：全部正常项
```

## 三、金额算例：一次「假性异常」复查要花多少钱

以最常见场景——尿酸520、ALT 48、血压146/92三项偏高为例：
- 保守做法：先生活方式干预，3个月后复查一次「肝功能+肾功能+血脂四项」套餐，社区医院约35-60元，二级医院约80-120元。
- 焦虑做法：立刻挂三甲专家号（诊查费30-100元）+ 复查全套（约150-250元）+ 加做腹部B超（约100元）≈350-450元，且医生大概率仍说「3个月后再看」。
- 结论：三项都只是轻中度异常、无症状时，先花50元复查比先花400元挂号更理性；真需要用药时再挂专科号不迟。一年四次社区复查≈240元，远低于一次急诊住院的自付额（数千元起）。

## 四、可直接复制的话术模板

**发给爸妈的微信**：
> 妈，你发的报告我看了：血糖6.3属于糖尿病前期，不用吃药，但接下来3个月米饭减1/3、晚饭后散步30分钟，2月底复查空腹血糖+糖化；尿酸520先把啤酒和动物内脏停了，每天喝够2升水。血压146/92，每天早晚各量一次记在手机备忘录里，连记7天发我。都是前期，来得及，不用慌。

**医生面诊/线上问诊开头（把关键信息前置，节省诊间时间）**：
> 医生您好，我父亲62岁，上周体检：血压146/92，空腹血糖6.3，糖化6.0，尿酸520，LDL 3.6，肌酐正常，无症状。既往无用药史。想请教三个问题：①这几项需要用药吗？②复查间隔多久？③饮食上最需要戒的是哪几样？

**家庭监测记录表（备忘录/表格照抄）**：
| 日期 | 早血压 | 晚血压 | 空腹血糖 | 备注 |
|---|---|---|---|---|
| 2/26 | 145/90 | 142/88 | 6.2 | 昨晚没喝酒 |

连续7天数据比单次数值有诊断价值，医生看到表格会直接采信。

## 五、避坑清单

| 坑 | 后果 | 正确做法 |
|---|---|---|
| 只看「↑↓」箭头不看参考区间性别年龄差异 | 尿酸女性按男性线误判 | 对照本文分档表 |
| 血糖偏高立刻自行买二甲双胍 | 前期用药无获益且可能低血糖 | 前期先生活方式，确诊线以上才由医生开药 |
| 尿酸高就猛喝苏打水 | 含糖苏打水反而升尿酸 | 白开水/淡茶，苏打水选无糖 |
| 体检报告放抽屉不看备注 | 备注栏常写「建议复查」是关键 | 先读每一项的备注 |
| 一次血压高就确诊高血压 | 白大衣高血压误判 | 不同日2次+家庭7天监测确认 |

## 红线
> ⚠️ 提醒：本表用于分档判断「多急该做什么」，不能替代医生诊断——达「当天急诊」线的任何一项，直接去医院别等复查。确诊和开药必须由执业医师决定，尤其降糖/降压/降尿酸药物不可凭体检单自行购买服用；老年人同一异常指标若伴随体重下降、黑便、持续疼痛等报警症状，优先排查器质性疾病而非先控饮食。
