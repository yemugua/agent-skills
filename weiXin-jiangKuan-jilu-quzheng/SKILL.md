# 微信转账记录取证的完整流程

一句话：微信转账记录是**法定电子数据证据**（《民事诉讼法》63 条），但「截图」的证明力最弱；完整的取证 = 转账凭证 + 聊天上下文 + 实名认证信息三件套。本技能给可直接照做的取证步骤。

## 一、证据三件套（缺一证明力减半）

1. **转账凭证**（证明钱付了）
2. **聊天上下文**（证明这笔钱为什么付——借款/工资/货款性质）
3. **对方实名信息**（证明「他」是谁）

## 二、取证步骤（照做）

### 1. 转账凭证的正规调取
- 转账记录页 → 选择该笔 → 「申请转账电子凭证」→ 输入姓名验证 → 生成**带腾讯电子章的 PDF**（可下载，法院认可度远高于截图）
- 路径：微信 → 我 → 服务 → 钱包 → 账单 → 对应交易 → 申请转账电子凭证
- 微信支付账单导出：钱包 → 账单 → 常见问题 → 下载账单（用于对账用途，个人账单 PDF 带章）

### 2. 聊天记录的固定
- **不要只截图**——截断的上下文易被质疑断章取义
- 完整录像：另一台手机拍摄逐屏翻阅（保留滚动过程），或电脑端微信备份
- 关键内容打印 + 本人签字「与原始载体一致」+ 注明日期（庭审当庭演示原始手机）
- **原始手机保留到案件结束**，不要清理微信缓存、不要换机

### 3. 对方实名信息的调取
- 聊天记录中对方的微信号绑定手机号/真实姓名（转账时输入过的姓名验证）
- 起诉时需对方身份证号：律师凭立案材料调取，或先以手机号向法院申请协助
- 微信转账页的「收款方实名验证」截图（输入姓氏验证成功的那页）本身也是证据

## 三、三种纠纷的证据强化

### 借款纠纷
- 转账凭证 + 含「借」「还」「利息」字样的聊天上下文
- 只有转账没有借条：补充微信确认——发「你借的 X 元何时还？」对方回复即成关键证据
- 补写电子借条：金额/期限/利息/身份信息四要素齐全

### 欠薪纠纷（个人雇主/工头）
- 转账记录（部分工资发放痕迹）+ 派工/考勤聊天记录 + 工作成果交付记录
- 注意：有「工资」字样的备注价值极高——转账时备注栏写「X 月工资」

### 买卖纠纷
- 订单聊天 + 转账 + 物流记录三链闭环
- 微信里的报价/承诺截图保留原始上下文位置

## 四、避坑红线 ⚠️

- ❌ 删除聊天记录「清理内存」——原始载体灭失 = 证据效力崩塌
- ❌ 只带打印件不带手机——法庭要求当庭出示原始设备
- ❌ 录音取证时诱导性提问（「你承认你欠我钱对吧」）——中性的事实确认问题才有效
- ❌ 用「恢复大师」第三方软件改写记录——篡改痕迹反而毁证据

## 五、真实案例

> 案例：借给同事 4.8 万，无借条，只有转账 + 微信聊天。
> 操作：调取带章转账凭证 + 完整录像聊天（含「下月发工资还你」）+ 转账实名验证截图。
> 结果：小额诉讼胜诉，对方在执行前和解归还。成本：诉讼费 50 元。

## 红线
> ⚠️ 提醒：取证的公式——「电子凭证带章调、聊天上下文留完整、原始手机别清理、实名验证要截图、催款确认发一条」。微信记录能打赢官司，但翻车也都在细节——截图不是证据，带章的凭证和完整的上下文才是。
