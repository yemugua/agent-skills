# 家用清洁剂安全使用

一句话：家用清洁剂的头号风险=「混用产生毒气」——84 消毒液+洁厕灵=氯气（致死级）、84+酒精=氯仿——「都用一点效果更好」的直觉=中毒事故的第一句遗言。本技能给混用禁忌表 + 分区使用原则 + 事故急救。

## 一、混用禁忌表（红线级，全家都要知道）

| 组合 | 产物 | 后果 |
|---|---|---|
| **84 消毒液+洁厕灵（盐酸）** | **氯气** | 黄绿色毒气，吸入即伤肺——密闭卫生间=致死级（每年都有真实死亡案例） |
| **84+酒精** | 氯仿等 | 刺激+潜在毒性——「消毒叠加」的常见翻车 |
| 84+双氧水 | 氧气剧烈反应 | 起泡飞溅+腐蚀 |
| 84+酸性清洁剂（任何） | 氯气 | 同洁厕灵原理 |
| 漂白水+氨水（玻璃水常含氨） | 氯胺 | 刺激伤肺 |
| 强酸+强碱叠加 | 中和放热 | 飞溅灼伤 |

**铁律**：84 消毒液（含氯漂白剂）**单独使用**——不与任何其他清洁剂/消毒剂混合；使用间隔 ≥30 分钟+中间充分冲净。

## 二、分区使用原则（卫生间的生死间隔）

- 洁厕灵刷马桶 → **冲净+通风 30 分钟** → 才可以用 84 或其他产品
- 卫生间消毒的推荐顺序：清水刷 → 洁厕剂（马桶内）→ 冲净 → 84 稀释液擦拭 → 冲净 → 通风——**一步一步来，不叠加**
- 84 的正确用法：稀释 1:100（500ml 水+5ml 84）擦拭表面——**原液直接用=腐蚀+气体浓度过高**；金属/织物慎用
- 使用时：戴手套+开窗/开排风——密闭空间+原液=最危险组合

## 三、常见清洁剂的正确场景速查

| 清洁剂 | 用对的地方 | 别用错 |
|---|---|---|
| 84 消毒液 | 地面/马桶/瓷砖白面 | 金属（生锈）/彩色织物（褪色）/大理石（腐蚀）|
| 洁厕灵 | 马桶内壁水垢 | 任何其他表面（强酸）+不与 84 混 |
| 厨房油污剂（碱性） | 油烟机/灶台 | 不锈钢面久留（腐蚀光面）+铝制品 |
| 玻璃清洁剂（含氨） | 玻璃镜面 | 不与漂白类先后叠加（氯胺风险） |
| 酒精消毒 | 小物件/手机 | 大面积喷洒（易燃——明火/静电）+84 混用 |
| 白醋/柠檬酸 | 水垢（电水壶/花洒） | 大理石（腐蚀）+与 84 混（产氯气！**「天然」不等于「可混」**——醋是酸，遇 84 同样产氯气） |

**「天然清洁剂也危险」的认知点**：白醋（酸）+84=氯气——**酸就是酸**，不管是不是厨房的。

## 四、储存与儿童安全

- 原瓶保存：**不换瓶不倒装**（装进饮料瓶=喝下去的儿童中毒事故第一名）——保留原标签与警示
- 高处/带锁收纳（清洁剂柜=儿童锁必装——参考儿童安全技能）
- 分区存放：酸类与氯类**分柜放**（打翻漏液相遇=气体）
- 过期处理：84 有效期 1 年（失效就换）；不乱倒下水道（大量腐蚀管道）
- 配制好的 84 液：当天用完（久放失效）+贴标签

## 五、事故急救（万一发生了）

**吸入氯气（闻到刺激味+咳嗽流泪）**：
1. **立即撤离到通风处**（别在密闭卫生间多留一秒）
2. 深呼吸新鲜空气+漱口；症状轻 → 观察 24h（肺水肿可能延迟发生——**不舒服别硬扛**）
3. 呼吸困难/持续咳嗽/胸闷 → **立即就医+告知医生「氯气吸入」**（120 报告毒物类型）
4. 现场处置：关闭源头+通风（戴防护再回去关）

**皮肤/眼睛接触**：大量清水冲洗 15 分钟+眼睛就医
**误服**：**不要催吐**（腐蚀物二次伤害）+立即就医带瓶子（医生看成分）
