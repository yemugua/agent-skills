# 装修增项黑名单与报价核查

一句话：装修报价单的低价是鱼饵，增项才是利润——行业常态「合同 12 万实付 16 万」。本技能给高频增项黑名单 + 报价单逐项核查法 + 合同防增项条款模板。

## 一、高频增项黑名单（报价单上没有的）

| 增项 | 典型加价 | 防范 |
|---|---|---|
| 水电改造按实结算 | +5,000-20,000 | 合同锁「按点位计价+总价上限」；要求出点位图再签 |
| 墙面找平/阴阳角 | +3,000-8,000 | 报价单写明「含基础找平 N ㎜」 |
| 砸墙/垃圾清运 | +2,000-5,000 | 合同含「拆除清运一口价」 |
| 卫生间防水加高 | +1,000-3,000 | 写明防水高度（墙面上翻 30cm/淋浴区 180cm） |
| 包立管/烟道处理 | +1,000-2,000/根 | 点位核对 |
| 瓷砖倒角/美缝 | +2,000-6,000 | 美缝单列或不做 |
| 五金/角阀辅材差价 | +1,000-3,000 | 「辅材明细表」附件进合同 |
| 窗台石/门槛石 | +1,000-2,000 | 石材单列 |

**防增项的核心条款模板**（写进合同）：
> 「本合同为固定总价合同。除甲方主动变更设计外，结算价不得超出合同总价 5%。乙方应在报价中列明全部施工项目与辅材明细；未列明项目视为已包含在总价内，不得另行收费。」

## 二、报价单核查五步（拿到报价当天做）

1. **横向对比**：3 家报价按同一项对齐（A 家「水电」B 家「改造」C 家分两条——口径统一再比价）
2. **拆单价**：人工+材料分开列的才透明；「综合单价」含糊的追问明细
3. **量核对**：面积/米数自己量（报价按 100㎡ 实测 85㎡ 的单价虚高问题）
4. **漏项排查**：对照黑名单逐项问「这个含吗？」——把口头「含」变成合同白纸
5. **低价项警惕**：明显低于市场价的单项（如瓷砖铺贴 35 元/㎡ 低于本地行情 45-60）= 增项伏笔

## 三、支付节奏的杠杆（钱在谁手里谁说了算）

**建议节奏**：开工 30% → 水电验收后 30% → 木工/瓦工完 30% → 竣工验收后 10%（留 5-10% 到入住 1 个月后无问题付清）
- 尾款 ≥10% 是你唯一的售后服务筹码
- 「开工付 50%」的报价单直接 pass

## 四、验收节点的核对（每笔尾款前）

- 水电：拍照存档管线走向图（后期打孔保命）+ 打压试验在场
- 防水：闭水试验 48h（楼下看顶板）
- 瓦工：空鼓率 <5%（响鼓锤逐块敲）
- 竣工：对照合同项目清单逐项打钩，未完成项写进「遗留问题单+完成期限」

## 五、发生增项争议时

1. 增项必须**书面确认**（微信文字确认也算）：「XX 增项，金额 X，双方确认后施工」——口头增项不认
2. 已施工未确认的：主张按合同价包含；投诉 12315/消协
3. 装修协会/住建部门投诉（有资质的装修公司怕行业投诉）
4. 合同防增项条款在手的：仲裁/诉讼主张超 5% 部分不付

## 红线
> ⚠️ 提醒：装修的公式——「固定总价+超 5% 不付写进合同、增项必须书面确认、尾款 10% 是筹码、报价单横向拆项比、低价单项是鱼饵、水电走向图必存」。装修战的胜负在签约日——那天你多问的每句「这个含吗」，都是竣工时不吵架的本钱。
