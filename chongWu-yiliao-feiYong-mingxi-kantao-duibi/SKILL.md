# 宠物医疗费用透明化对照表

一句话：宠物医疗是「无定价监管」的市场——同一个项目价差 3-5 倍是常态；懂行情的铲屎官能省下 30-50% 的医疗支出。本技能给常见项目合理价区间 + 检查砍单原则 + 二诊策略。

**价格差异的来源**：城市等级、器械新旧、进口药 vs 国产、门诊 vs 连锁溢价——**同一城市 3 家比价是基本功**。

## 二、检查砍单原则（哪些检查必要、哪些是套餐坑）

- **必要**：急症初诊的「血常规+生化」组合（判断感染/器官状况的基础盘）
- **可砍**：无症状宠物的「豪华体检套餐」（1,000-2,000 的全项）——年轻健康宠物基础项即可（血常规+粪检 ~200 元）
- **必问**：「这个检查的结果会改变治疗方案吗？」——答案模糊的检查先放一放
- **警惕**：一进店就推「套餐 + 疫苗 + 驱虫捆绑」的销售话术——先看病再谈预防
- **影像决策**：X 光能看的不必 CT；CT/核磁是疑难病工具（单次 1,500-4,000），普通病例被推 CT 要二诊

## 三、二诊策略（大额支出的必要动作）

**超过 1,500 元的治疗决定前，花 100 元换一家看同一份报告**：
- 带**原检查报告**（不用重复花钱重新检查）——只问「方案与报价」
- 对比三件事：诊断是否一致 / 治疗方案差异 / 价差
- 「立即手术/必须住院」的紧迫话术 + 拒绝提供报告原件 = 红色信号（正规医院报告随便拷）
- 线上问诊辅助（阿闻/瑞鹏线上/兽医约诊 30-100 元）——小问题线上先筛，省下跑医院的基础费

## 四、长期省钱的制度设计

1. **医院选定策略**：常规保健选社区医院（价低）；手术/疑难选有口碑的大型医院（成功率=省大钱）
2. **会员/储值警惕**：大额储值卡（3,000+）有跑路风险——储值 ≤1,000 且用于确定消耗的项目
3. **保险账**：宠物医保（年 300-800，报销 40-60%）——适合纯种/老年高发期；健康年轻猫犬的性价比自行测算
4. **驱虫/疫苗自主化**：体外驱虫滴剂自购（大宠/福来恩渠道价 vs 院内价差 30%）+ 按体重买大规格分装

## 五、真实案例

> 案例：猫呕吐，A 院开出「血检+B 超+X 光+住院 3 天」报价 3,800。
> 二诊：带 A 院血常规+B 超报告到 B 院——诊断为普通毛球炎，开药+饮食调整，花费 260 元。
> 关键动作：要走了报告原件（A 院未拒）+ 只比方案不重检查。

## 红线
> ⚠️ 提醒：宠物医疗的公式——「常见项目有行情价、检查先问『会改变方案吗』、大额决定必二诊带报告、紧迫话术是红灯、储值卡小额、驱虫自购渠道价」。宠物医疗没有物价局；但有你——带着对照表和报告原件走进第二家医院的那一刻，定价权就回到你手里。
