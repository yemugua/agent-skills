# 装修验收总表

一句话：验收的体系=「**四大节点（水电/防水/瓦木/竣工）×工具×清单**」——「想起来才验」=验收白做；「有表有工具有流程」=问题暴露在保修期内（参考各分项验收技能，本篇做集成总表）。本技能给节点清单 + 工具包 + 问题单的管理。

## 一、验收工具包（提前备好）

- **卷尺+2m 靠尺+塞尺**（平整度——参考瓷砖技能）
- **空鼓锤/硬币**（空鼓听诊）
- **验电器/相位检测仪**（插座接线——参考水电技能）
- **水桶+水平尺**（排水坡度——参考防水技能）
- **手电（侧光照墙）**（裂纹/平整——参考开荒技能）
- 手机（**拍照存档+问题单记录**）

## 二、四大节点的清单集成

**节点 1：水电验收**（参考水电技能全文）
- [ ] 闭水 48h+楼下签字
- [ ] 试压 0.8MPa 30min
- [ ] 摇表绝缘+活线+卡尺验线径
- [ ] 点位对图纸+配电箱标签
- [ ] **全墙拍照存档**

**节点 2：防水验收**（参考防水技能）
- [ ] 防水高度（淋浴 1.8m/门槛外延）
- [ ] 管根地漏附加层
- [ ] 保护层后才贴砖

**节点 3：瓦木验收**（参考瓷砖/木地板技能）
- [ ] 空鼓敲四角+中心（<15% 单砖）
- [ ] 平整 ≤2mm/缝宽均匀
- [ ] 卫生间泼水试坡
- [ ] 地板铺装伸缩缝/基层

**节点 4：竣工综合验收**（集成包）
- [ ] 墙面：侧光查裂纹/色差（参考裂缝技能）
- [ ] 全屋水电功能测试（**每个开关/插座/龙头/马桶**）
- [ ] 门窗：开关顺滑/密封条/五金（参考门窗技能）
- [ ] 灯具全亮+分控正确（参考灯带技能）
- [ ] 定制柜：门缝/五金/内部（参考定制技能）
- [ ] 美缝密实/打胶收口（参考美缝技能）
- [ ] 排水全通/地漏水封（参考防臭技能）

## 三、问题单的管理（发现的不是「说说」）

- **问题单三列**：位置/问题描述/整改标准与期限（**「口头反映」=无凭据**——参考水电技能的书面化）
- 整改的复验闭环：**改完→复验→签字→付款解锁**（参考尾款技能的杠杆）
- 「小问题保留意见」的分级：**接受类（色差轻微）/整改类（空鼓）/拒付类（返工）**（**「都改改」的模糊=扯皮的来源**）

## 四、验收的时机纪律（业主的责任面）

- **到场验收是业主义务**（**「拍照发我看」≠验收**——参考水电技能的到场原则）
- 节点验收不拖延（**业主拖延=工期顺延的合同风险**——参考工期技能）
- 完工的终验：**功能测试+资料交接（水电图/保修卡/钥匙）**（**竣工资料=十年检修的地图**——参考水电技能）

## 五、保修期的衔接（验收之后的系统）

- 保修清单：**各项目保修期（防水 5 年/其他 2 年法定）+报修方式**（参考保修技能）
- 保修的书面留痕（**微信报修+照片**——参考保修技能的证据链）
- 雨季/季节的主动检查（**保修期内免费修=别攒**）

## 六、真实对照

> 案例 A：竣工没做功能全测——入住发现两处插座不通电+一处冷热水接反；「逐点测试」的对照户一次交付（**「每个开关都按一下」=竣工的最低动作**）。
> 案例 B：问题口头说「回头改」——尾款付完失联；「问题单+复验签字+付款解锁」的对照户 5 天整改完（**流程=信用**）。
> 验收总表的公式：**工具包提前备、四大节点逐项打勾、功能全测是竣工底线、问题单三列+复验解锁付款、到场是义务、竣工资料交接、保修清单+季节主动查、分级处理不模糊**——验收的本质=「用清单对抗遗漏、用流程对抗扯皮」——有表的人验收 2 小时；没表的人，保修期里慢慢发现。

## 红线
> ⚠️ 提醒：验收总表的公式——「四节点（水电/防水/瓦木/竣工）各自清单一项不漏、工具包（靠尺/空鼓锤/验电器/侧光）常备、竣工=全屋功能逐点测试、问题单书面三列+复验签字解锁付款、业主到场不拖延、竣工资料（水电图/保修卡）必交接、保修期主动季检」。验收是「装修的最后防线」——防线的作用取决于清单的完整度与流程的执行度——表在手上，问题在保修期内。
