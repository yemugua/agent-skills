# 装修验收节点核对清单

一句话：装修验收不是竣工那一次——水电/防水/瓦工/木工/竣工五个节点各有一套「不过就别付款」的硬指标。本技能按节点给核对清单与工具用法。

## 一、节点验收流程（钱跟验收走）

```
开工 30% → [水电验收] → 30% → [防水验收] → 30% → [木瓦验收] → 竣工验收 → 10%（留 1 个月质保金）
```

## 二、节点 1：水电验收（最不能返工的隐藏工程）

- [ ] **拍照存档**：每面墙的管线走向图（横平竖直+标注尺寸）——**日后打孔不爆管的保命图**
- [ ] 打压试验：水管加压 0.8MPa 保压 30 分钟不掉压（要求当面做）
- [ ] 强弱电间距 ≥30cm / 交叉处锡箔屏蔽（网络干扰）
- [ ] 插座点位对照图纸逐一核对（数量+高度+位置，改点位按合同另算的核对确认单）
- [ ] 电线规格：照明 1.5㎡/普通插座 2.5㎡/空调厨卫 4㎡（线管内电线截面积 ≤40%）

## 三、节点 2：防水验收（楼下邻居的和平条约）

- [ ] 闭水试验：蓄水 2-3cm **48 小时**，楼下查看顶板无渗漏
- [ ] 防水高度：淋浴区墙上翻 ≥180cm、其余墙面 30cm（用量尺）
- [ ] 涂刷遍数与厚度（1.5mm+，可见膜厚）
- [ ] 管根/地漏/阴阳角加强层处理

## 四、节点 3：瓦工验收

- [ ] 空鼓率：响鼓锤逐块敲（单砖空鼓面积 <10%、总数 <5%）
- [ ] 平整度：2m 靠尺 ≤2mm 缝隙；十字缝对齐
- [ ] 坡度：地漏处泼水试排（积水即返工）
- [ ] 阳角碰角/海棠角工艺与报价一致

## 五、节点 4：木工与油漆

- [ ] 柜体：封边严密无爆边、柜门缝隙均匀（≤2mm）、抽屉顺滑
- [ ] 吊顶：无裂缝、转角 L 型整板防开裂（7 字板工艺）
- [ ] 墙面：灯光侧照看波浪（阴阳角直线）、无流坠色差
- [ ] 留缝：地板/门槛/家具缝的伸缩缝预留

## 六、竣工验收（付尾款前总对账）

- [ ] 对照合同项目清单逐项打钩——未完成项写《遗留问题单》（内容+责任人+完成期限）
- [ ] 门窗：启闭顺畅、密封条完好、打胶平整
- [ ] 全屋水电功能测试（每个插座验电器测、每个水龙头放水）
- [ ] 洁具/灯具/五金品牌型号对照合同（防调包）
- [ ] 索要：保修卡、材料质保书、水电图电子版、结清证明
- [ ] 质保金 5-10% 畦到入住 1 个月后无问题付清

## 七、验收工具包（百元级全套）

响鼓锤 15 元 / 2m 靠尺 40 元 / 验电器 15 元 / 卷尺+直角尺 30 元 / 水平仪（手机 App 可替代）
——**或者直接约第三方监理**（500-1,500 元/节点）：与施工方无利益关系的专业眼，最值的一次是水电验收。

## 红线
> ⚠️ 提醒：验收的公式——「五节点各过各的关、水电图必拍照、闭水 48h 必到场、空鼓逐块敲、遗留问题单+质保金、不合格不付款是唯一筹码」。验收省的每一步，都是返工时十倍的成本——脸皮厚一点，尺子勤一点，钱稳一点。
