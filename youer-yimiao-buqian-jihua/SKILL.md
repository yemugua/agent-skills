幼儿园/小学入托报名要交"预防接种查验单"，卡在漏针上的家庭往往临时手忙脚乱——补种有严格的间隔规则和顺序，提前4周规划就能一次打齐。本条给漏针排查表、补种间隔规则和查验单办理流程。

## 漏针自查表（入学查验必查项）

| 疫苗 | 入学要求的剂次 | 常见漏点 |
|---|---|---|
| 乙肝 | 3剂 | 第三针（出生1年内未及时补） |
| 脊灰 | 4剂（或IPV≥2剂） | 4岁加强剂 |
| 百白破 | 4剂基础+入学前需查加强 | 18月龄第4剂 |
| 麻腮风（麻腮风/麻风） | 2剂 | 第2剂18月龄 |
| 乙脑（减毒活） | 2剂 | 2岁第2剂 |
| A+C流脑 | 2剂 | 3岁、6岁各1剂 |
| 甲肝（减毒） | 1剂（灭活2剂） | 常被遗忘 |

**第一步**：打开"小豆苗"App/当地健康码疫苗页，或翻接种本逐行对照上表；也可直接带接种本去社区卫生服务中心打印"入托入学预防接种证查验单"，漏针会当场标红。

## 补种间隔规则（顺序错了白跑）

- **两种灭活疫苗**：可同天接种（左右臂），无需间隔。
- **两种减毒活疫苗**（麻腮风、乙脑减毒、甲肝减毒等）：要么同天打，要么间隔≥28天——这是最容易踩的坑，错开一周去打会被拒。
- **活疫苗与免疫球蛋白**：注射丙种球蛋白后需间隔≥3个月才能打活疫苗。
- **补种顺序原则**：多剂次疫苗从最早漏掉的剂次补起，剂次间隔不得短于该疫苗最短间隔（如百白破≥28天，乙肝第2-3针≥28天）。

## 精确算例：典型漏2针场景

- 3岁幼儿漏：麻腮风第2剂 + 乙脑减毒第2剂。9月1日入学，8月1日才查。
- 两者均为减毒活疫苗：8月2日同天双臂接种（合法）→ 8月2日当天完成，8月3日即可打印查验单，留有30天缓冲。
- 若已打乙脑第2剂于7月20日、麻腮风8月1日去打：间隔仅12天<28天被拒，需等到8月17日后——差3天错过报名截止日。**结论：活疫苗漏多针时，同天接种是最快方案。**
- 补种费用：免疫规划疫苗（表内全部）补种免费，仅收诊查费0-20元/针（各地不同）；自费替代苗（如灭活甲肝第二针）约150-200元/针。

## 查验单办理流程

1. 带接种本+户口本到现居地社区卫生服务中心预防接种门诊。
2. 找回异地/历史接种记录：全国接种记录已逐步联网，未联网省份凭纸质接种本人工补录到系统（当场可办）。
3. 接种完成后当场打印"预防接种证查验证明"（盖章版），幼儿园/学校只收这张。
4. 补录记录要核对学生姓名、出生日期与户口本一致——名字打错会导致学校系统比对失败。

## 红线

| 行为 | 后果 |
|---|---|
| 漏针拖到报名当天才去办 | 活疫苗28天间隔可能直接卡死入学 |
| 伪造/涂改接种本记录 | 查实后学校拒收，涉伪造证件文书 |
| 发热/腹泻当天仍坚持接种 | 接种单位应拒种，需痊愈后补 |
| 自费苗与免费苗重复打同一剂次 | 无必要支出，且多打剂次不增加保护 |

> ⚠️ 提醒：入学查验的截止日是死的，活疫苗28天间隔也是死的——两把锁之间留给你的操作窗口只有"提前1个月启动补种"这一个解；所有免疫规划疫苗补种本身免费，别被任何"补种收费套餐"收智商税。
