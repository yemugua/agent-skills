# 宠物老年体检深度

一句话：老年的体检=「**以 SDMA/血压/心脏影像为核心的早筛组合**」——老年病的三大隐匿（肾/心/肿瘤）都能被数据提前抓到（参考体检套餐技能的框架，本篇深度展开老年特有项与报告解读）。本技能给老年体检的深度清单 + 解读 + 慢病管理的联动。

## 一、老年体检的深度组合（半年一次的清单）

| 系统 | 项目 | 抓什么 |
|---|---|---|
| 肾 | **SDMA + 肌酐/BUN + 尿检（比重/蛋白）** | 猫肾病的 IRIS 分期（SDMA 比肌酐早抓 9-17 个月） |
| 心 | 听诊+**心超（猫 HCM/犬瓣膜病）+血压** | 心肌病/高血压（猫高血压=肾与眼的后台推手） |
| 内分泌 | 血糖/甲状腺（**猫甲亢/犬甲减**） | 老年高发内分泌病 |
| 肿瘤 | 体表触诊+影像（X 光/B 超）+血象异常 | 肿块的早发现（月度摸自查的医学版） |
| 口腔 | 口腔检查+牙片（必要时） | 牙结石/牙根脓肿（**牙病伤肾心的证据链**） |
| 关节/骨骼 | 步态评估+必要影像 | 关节炎（**「老了不动」一半是疼**） |
| 眼 | 眼压+眼底 | 白内障/高血压视网膜（猫） |

- **血压是老年体检的低估项**：猫高血压无声损伤肾与视网膜——**测一次 10 分钟**（参考老年照护技能）
- 老年体检的节律：**每 6 个月+月度家庭自查（体重/肿块/食欲）**之间形成筛查网

## 二、核心报告的深度解读

**肾指标的三层**：
- SDMA 升（>14μg/dl）=早期警报（肌酐还正常时）
- 肌酐+BUN 升+尿比重低=功能性下降→ IRIS 分期（一期到四期的管理方案差异巨大——**分期决定处方粮与复查节奏**）
- 尿蛋白持续 +=肾小球损伤信号→ 尿蛋白/肌酐比（UPC）量化

**甲状腺（猫甲亢高发）**：
- 老年猫「吃得多反而瘦+活跃亢奋」≠「身体好」——**甲亢的经典假象**（T4 确认； untreated=心脏负担）
- 犬「胖+迟钝+皮毛差」→ 甲减方向

**心脏影像**：
- 猫 HCM（心肌病）无症状期长——**心超是唯一早筛**（品种猫/老年猫的年度项）
- 犬 CVD 瓣膜病：听诊杂音→心超分级→治疗节点

## 三、慢病管理网（体检之后的系统）

- 每项确诊后的「管理档案」：用药/复查节奏/家庭观察点（**「数据-方案-观察」的闭环**——参考档案管理逻辑）
- 药物管理：老年多病的用药清单（**药物相互作用——「每种药都要告知所有医生」**）
- 饮食联动：肾病粮/心脏病低钠（**处方粮=医疗决策**——参考老年营养技能）
- 家庭监测的升级：体重（月）/食欲与饮水/呼吸频率（**睡眠呼吸 >30 次/分=心衰预警——猫的免费监测**）

## 四、麻醉与处置的老年特别考量（体检之外的深度）

- 老年麻醉前评估：血检+心超（**「要不要洗牙」的麻醉决策=老年体检的延伸议题**——不洗牙的牙病 vs 麻醉风险的权衡）
- 麻醉监护（心电/血氧/体温）=选医院的硬指标（参考医院技能）
- 洗牙的频次与风险平衡：**「小问题早处理」优于「大问题硬麻醉」**（口腔恶化到深部感染时的麻醉风险更高）

## 五、体检预算的分配（钱花在数据上）

- 必做核心：SDMA+尿检+血压+心超（**这四项是老年体检的灵魂**）
- 按个体加项：品种病/既往病史/症状指引
- 「豪华套餐」的拆解逻辑（参考体检套餐技能——**先定项目再对套餐**）
- 早筛的回报：肾病早期管理 vs 晚期透析的成本（**>10 倍的回报倍数**）

## 六、真实对照

> 案例 A：11 岁猫半年检 SDMA 16+尿比重低——IRIS 二期管理（处方粮+复查节奏）：3 年稳定；对照「体检只查肌酐」的漏诊→确诊即三期（**SDMA 的时间价值**）。
> 案例 B：老猫「精神好吃得多」主人欣慰——T4 高=甲亢；治疗一个月后体重回归（**「假象健康」的识别**）。
> 老年体检的公式：**半年一次+月度家庭自查、SDMA/血压/心超/尿检四核心、甲亢甲减的假象识别、IRIS 分期决定管理、睡眠呼吸 >30/分是猫心衰预警、麻醉前评估捆绑牙科决策、预算向核心数据倾斜**——老年体检的深度=「数据抓得早+解读读得懂+管理接得住」——三段都不缺席，老年病才抓得住窗口。
