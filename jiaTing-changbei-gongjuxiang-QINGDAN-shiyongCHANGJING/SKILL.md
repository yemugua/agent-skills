# 家庭工具箱配置清单

一句话：家庭的工具焦虑=「要拧个螺丝却翻不到一把螺丝刀」——30 件套的工具箱（预算 300-500 元）覆盖 95% 的家用场景；另外 5%（水电大活）本来也不该自己干。本技能给分类清单 + 场景对照 + 选购与安全。

## 一、30 件套清单（按功能分组）

### 拧的（螺丝与紧固）
- [ ] 多用螺丝刀套装（十字/一字/T 型——含小号眼镜螺丝刀）——**使用率第一**
- [ ] 内六角扳手套装（家具安装的命——网购家具全是内六角）
- [ ] 活动扳手 ×1（水暖/自行车通用）
- [ ] 尖嘴钳（夹/剪/掰小件）
- [ ] 老虎钳/斜口钳（剪铁丝/扎带）
- [ ] 电钻（家用冲击钻 200-300 元——**挂画/装架子从「求人」变「自理」的划时代工具**；配钻头套装：木头/混凝土/金属）

### 量的（测量与定位）
- [ ] 卷尺 5m（使用率第二）
- [ ] 水平尺小型/水平仪 App（挂画不歪的秘密）
- [ ] 电笔（测电——保命小工具）
- [ ] 铅笔+记号笔

### 粘的（胶带与胶）
- [ ] 免钉胶/结构胶（挂重物不钻孔——租房神器）
- [ ] 蓝丁胶（轻物贴墙）
- [ ] 双面胶（强力款）/透明胶带
- [ ] 502（小件快粘——注意飞溅别碰皮肤）
- [ ] 玻璃胶+胶枪（厨卫缝隙修补）

### 修的（水暖与电器小修）
- [ ] 生料带（水龙头缠接——漏水应急必备，3 元）
- [ ] 管钳/水槽扳手（水槽下拧接头的专用角度）
- [ ] 绝缘胶带
- [ ] 备用保险丝/电池套装（5 号/7 号/纽扣——**遥控器停电年检**）

### 救急的（安全与杂项）
- [ ] 强光手电+备用灯
- [ ] 应急锤（车用+家用）
- [ ] 小撬棒/一字撬刀（开罐/撬条）
- [ ] 砂纸（几张不同目数）
- [ ] 钢锯条/手锯（小型）
- [ ] 抹布/旧牙刷（清灰小件）
- [ ] 工具收纳箱（**分类收纳=找得到=会去用**——工具箱没用起来 80% 是收纳乱）

## 二、高频场景对照（这箱东西解决什么）

| 场景 | 用什么 |
|---|---|
| 网购家具安装 | 内六角+螺丝刀（全程 90% 是这两样） |
| 挂画/置物架 | 电钻+水平尺+膨胀管（打孔前**用电笔/探测仪查墙内电线水管**——打穿水管=大事故） |
| 水龙头滴水 | 活扳手+生料带（拆开缠生料带重装——视频教程 10 分钟） |

| 遥控器失灵 | 电池+棉签酒精擦触点 |
| 窗户异响/门框摩擦 | 砂纸+蜡（润滑） |

## 三、选购建议与预算分配

- **入门套装思路**：不买「99 件套」大礼包（80% 是凑数）——按上面 30 件单配（300-500 元）；电钻单买（品-treated 品牌入门款 200-300）
- 电钻选型：锂电充电式（便捷）> 有线；带「冲击」档=能打混凝土墙（挂画刚需）
- 质量分界：螺丝刀/钳子买品牌基础款（世达/钢拓/博世入门）——**手感差的工具会让你放弃使用工具**
- 每半年盘点一次：电池是否有电/胶是否干（免钉胶开盖后 6-12 月寿命）

## 四、安全纪律（家用工具的工伤都来自大意）

- 电：动电先断电（空开拉闸）+ 电笔验电——**「我以为没电」是维修事故的第一句话**
- 钻墙：先探测（电线/水管走位——新房可查水电照片档案！老房凭经验避开横竖走线的规律）；眼镜戴上
- 高处：不用摇椅垫脚（梯子 100 元该买就买——**垫凳摔伤率高**）
- 锯割：固定工件再锯（一手压一手锯=事故姿势）
- 502 胶：戴手套用（指尖粘连的急诊不罕见）

## 五、真实对照

> 案例：新居第一年——网购 6 件家具自装（内六角全程）+挂 8 幅画（电钻+水平尺）+修 2 次水龙头滴漏（生料带）+马桶水箱调整（扳手）——**省上门费与等待约 1,200 元**，且「修好东西的掌控感」是隐藏收益。
> 工具箱的公式：**30 件覆盖 95%、电钻是分水岭、内六角是家具的命、生料带 3 元修漏水、打孔前查电线、分类收纳才用得起来**——工具箱的本质不是「会修东西」；是「遇到小问题时的从容」——从容二字，值回所有票价。
