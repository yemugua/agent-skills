# 技术债务登记与排期

## 触发场景
当用户的需求涉及：识别登记；评分；排期；复核 时使用本技能。

### Step 1 · 识别登记
从 code review/事故/开发痛感收集债务项：分类（架构/测试/文档/依赖/监控）。

### Step 2 · 评分
影响（事故概率×范围）× 修复成本，得优先级分。

### Step 3 · 排期
每迭代固定 10~20% 容量偿还；P0 债务与 roadmap 功能绑定搭车修。

### Step 4 · 复核
季度复核台账：新增/偿还/失效，趋势报告给管理层。

## 红线
- 债务项必须有登记不修的理由记录
- 禁止用『没时间』替代优先级决策
