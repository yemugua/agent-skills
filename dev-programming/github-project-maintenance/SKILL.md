# 开源项目维护手册

## 触发场景
当用户的需求涉及：Issue 分诊；PR 审查；Release 流程；社区治理 时使用本技能。

### Step 1 · Issue 分诊
模板（bug/feature）、标签体系（类型/优先级/可贡献）、stale 自动处理与答复 SLA。

### Step 2 · PR 审查
贡献指南、CI 必过、review 检查清单、PR 大小引导（拆分）。

### Step 3 · Release 流程
SemVer、changelog 维护、发布 checklist（测试/文档/公告）。

### Step 4 · 社区治理
行为准则、Codeowners、维护者精力保护（拒答模板、good first issue 维护）。

## 红线
- 关闭 issue 必须给理由
- 不承诺无维护者支持的 feature
