# 出差电源：多口充电器与扩展选择

一句话：出差带一个 65W 三口氮化镓充电器可以替代三四个原装头，但「多口总功率怎么分」没人告诉你——电脑+手机同时充时电脑掉速的根因就在功率分配规则。

## 一、PD 功率分配规则（看懂再买）

| 器材 | 单口需求 | 关键规则 |
|---|---|---|
| 笔记本（PD协议） | 45-65W（游戏本100W+） | 单口输出才有满速；多口同用时C1口通常优先保大功率 |
| 手机（快充） | 18-33W | 与笔记本同充会被压到15W左右，慢是规则不是故障 |
| 平板 | 20-30W | 放C2口 |
| 无线耳机/充电宝 | 5-10W | 塞A口即可 |

**购买判断公式**：总价承受范围内，选「C口单口最大功率 ≥ 笔记本需求 + 5W」；两口全用时的标注功率（如 65W 充电器标注 C1+C2=45W+18W）才是同时充的真实体验，只看 65W 大数字会被误导。

**推荐配置**：65W 氮化镓 2C1A（约80-150元，覆盖电脑+手机+耳机）；若笔记本 100W 选 100W 版（150-250元）。再带一个带 2 个 AC 插孔+2 USB 的小插排（30-60元）解决酒店插座不够的问题。

## 二、酒店插座安全核查清单（1分钟）

1. 插座松旷/发黑/烧痕 → 不用，换位或用自带插排换到别的插座。
2. 用自带插排先插低功率设备（手机）1分钟摸温升，再接电脑。
3. 酒店床头 USB 口只给耳机/手环充电——功率低且与房间电路共享，充电脑极慢，个别老旧线路有发热风险。
4. 雨天行李落地：插座离地面/水渍位置，插排不放地毯上。
5. 每日退房前检查「电脑+充电器+插排」三件，充电器插排是酒店遗留物丢失重灾区。

## 三、算例：一晚出差电量怎么排

22:00 到店：C1 口充电脑（60W 约1.5小时满）；睡前插手机 C2（25W 半夜前满）；耳机 A 口。第二天开会携带：仅带 65W 充电器+1 根 C to C 线（100W 标称的线材，约30-50元，劣质线会让65W掉到20W）。

**线的坑**：标注「3A」的 C 线最大只跑 60W，笔记本 100W 必须选 5A 线（E-Marker），差价 15-25 元——这是「充电慢查不出原因」的第一大原因。

## 四、可复制的采购清单模板

```
出差电源包（总价约150-250元）：
□ 65W/100W 氮化镓 2C1A ×1
□ 5A C-to-C 线 1.5m ×2
□ AC插孔+USB 小插排 ×1
□ 摺叠转换头（英标/欧标，出境用）×1
```

## 红线

| 红线 | 后果 |
|---|---|
| 多口同充时以为设备坏了 | 是功率分配规则，换单口即满速 |
| 用 3A 线给 100W 本充电 | 只跑60W且发热大 |
| 买无品牌山寨高功率头 | 虚标+烧设备，保险拒赔 |
| 插排放地毯/潮湿台面 | 过热起火风险 |

> ⚠️ 提醒：充电器认准 3C 认证与品牌（Anker/绿联/倍思/小米等），虚标山寨头烧笔记本主板不在保修范围；笔记本边充边用高负载时优先插墙面插座，别串插排多级。
