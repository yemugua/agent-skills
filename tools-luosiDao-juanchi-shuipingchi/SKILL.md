# 螺丝刀、卷尺、水平尺的选购与使用

螺丝刀的规格体系（一字/十字/批头）、套装的选择（批头式 vs 一体）、卷尺的使用技巧（读数/回弹/挂钩钩边）、水平尺与水平仪、测量的小技巧（量角/找圆心）、工具的精度保持。

## 操作路径
1. **螺丝刀规格**：两大类——一字（一字槽）与十字（PH1/PH2/PH3 最常用）；「批头体系」——PH/PZ/T 星型（Torx）/内六角的识别（「都是十字随便拧」的滑丝事故——规格不对=螺丝报废）；「批头式套装」——一把手柄+N 批头（性价比+扩展）；「一体式」——耐用顺手（常用规格单买）。
2. **套装选择**：基础套装——PH1/PH2/PH3+一字 3-6mm+内六角常用号的组合；「材质」——S2 钢批头（劣质批头的软与滑）；「磁性」——磁化批头的单手操作（磁力过强的电子设备注意）；「精密批头」——眼镜/手机的小规格套装（见眼镜螺丝条目）。
3. **卷尺技巧**：读数——厘米/毫米的前缘精度（挂钩钩边的设计：内外测量的两种用法——钩住外沿推量内径）；「回弹控制」——慢放回收（「全自动飞速回弹」的打手）；「标记」——铅笔+卷尺的组合画线；「测量姿势」——尺带平贴不扭曲（歪斜的读数误差）。
4. **水平尺与水平仪**：水平尺——短款 30cm 的日常（气泡居中=平；「目测水平」的挂歪画）；「激光水平仪」——挂画排钉/贴砖的大工程（十字线投线的效率——几十元迷你款的够用性）；「用法」——地面找平/挂件预检（「打完孔才发现歪」的返工预防）。
5. **精度与技巧**：量角——量角器/角尺的使用（斜切件的放样）；「找圆心」——圆物直径的测量技巧；「精度保持」——卷尺不摔/水平尺不磕（气泡失准的静置校验——已知水平面的定期核对）；「二手测量」——卷尺挂牌测量长物的「配合测量法」。

## 避坑红线 ⚠️
- 「规格差不多就拧」——滑丝的螺丝报废；批头紧配合。
