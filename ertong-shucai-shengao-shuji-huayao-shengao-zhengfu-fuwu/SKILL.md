# 政务服务平台常用功能

政务服务平台常用功能：国家政务服务平台APP/小程序把社保、公积金、电子证件、跨省办事集中到一个入口，高频事项基本不用跑线下大厅。

| 功能 | 入口 | 说明 |
|---|---|---|
| 社保查询 | 首页『人社』/各地人社厅 | 缴费记录、参保状态、养老/医保累计年限 |
| 公积金查询 | 『公积金』服务 | 余额、缴存明细、异地转移接续申请 |
| 电子证件 | 『我的证照』添加 | 电子社保卡、电子结婚证（部分省）、电子驾驶证、电子身份证（试点省份） |
| 办事预约 | 各省分厅 | 政务大厅取号预约，减少现场排队 |
| 跨省通办 | 『跨省通办』专区 | 户籍类证明、社保转移、公积金异地转移等高频事项 |

话术模板（帮父母设置）：「下载国家政务服务平台APP→注册刷脸→我的证照里把电子社保卡、驾驶证都加上。以后查社保、办转移打开就行，不用再跑人社局。」

维权阶梯：线上办理超时未受理→服务专区查进度→12345热线投诉报办件编号；电子证照与实体证照效力等同，窗口拒认可要求其按国务院电子证照相关规定受理并记录工号投诉。

## 红线
> ⚠️ 提醒：政务服务平台常用功能涉及官方流程与政策，以上金额与规则以办理当日官方口径为准；凡要求转账、验证码、屏幕共享的“代办加速”均为诈骗，一律只走官方APP与政务窗口。
