# 离职收尾：工作群交接与退出标准流程

一句话：离职的体面收尾 = 交接有清单 + 退出有顺序 + 关系留后路——工作群退错顺序/交接没留痕，是背调与新工作的隐形雷。本技能给标准流程模板。

## 一、离职倒计时流程（提离职到走人的标准动作）

**提离职日（D0）**：
- 书面递交（邮件+纸质）辞职信——写「个人原因」即可（别写对公司的抱怨，背调会查）
- 同步整理个人文件：工作产出移交给接手人/公司盘，**个人文件清出公司设备**

**交接期（D0 至最后工作日）**：
- 编写《交接文档》模板：
```
交接清单
1. 在办事项：事项+进度+下一步+对接人（逐条）
2. 账号权限：系统账号清单（交回，不带走客户/内部数据）
3. 文档位置：共享盘路径说明
4. 常联系人：关键对接人+联系方式+沟通习惯
5. 注意事项：坑点提醒（显示职业度，也留人脉）
```
- 交接文档**邮件发送给直属上级并抄送 HR**——这就是「已尽交接义务」的书面证据（防扣押工资/离职证明的纠纷）

## 二、工作群的退出顺序与时机

**退出顺序（最后一天下午为佳）**：
1. 先退**纯项目群/临时群**（无声退，无存在感）
2. 同事内部闲聊群：退前发一条告别（可选）：
   > 「各位，今天是在职最后一天，感谢一路照顾！工作交接已与 XX 完成。以后微信常联系，江湖再见🙏」
3. **全员大群/部门群**：最后退（有的公司 HR 会统一移出——被移出比自退更常见且无妨）
4. **客户群**：原则上不主动退（交接到接手人后可退出）——先在群里完成交接公告：「后续由 XX 对接（@新人），感谢大家」

**细节**：
- 退群前**保存需要的群文件**（退群即失去访问）
- 别在群里抱怨/爆料——离职后的言论仍可能影响背调与行业口碑（圈子比你想的小）

## 三、离职证明与背调防线

- **离职证明必须拿到**（写明：入职/离职日期+岗位+协商解除/合同到期措辞）——入职新公司的硬材料
- 背调口径：交接文档里的对接人 = 会说你好话的背调名单（提前打招呼）
- 社保公积金：确认原公司减员日期 + 新公司增员衔接（断缴影响见五险一金条目）

## 四、关系资产留存（离职的隐性收益）

- 关键同事/客户加微信备注（「前司-名字-岗位」）
- 交接好的对接人 → 日后背调/行业合作的活口碑
- 领导层级：好领导是长期人脉——离职后第一条寒暄消息在离职 1 个月内发（淡了就真的淡了）

## 五、避坑红线 ⚠️

- ❌ 交接文档只发口头——书面+邮件留痕是「我交接完了」的唯一证据
- ❌ 带走客户名单/内部文件——侵犯商业秘密的法律风险；个人能力带走，公司数据留下
- ❌ 最后一天请催尾款/纠结小钱——离职当日只办：证明、交接确认、社保减员确认；钱的事按流程追
- ❌ 群里不发告别直接消失——熟人圈显得突兀；一条模板解决

## 红线
> ⚠️ 提醒：离职的公式——「书面辞职信、交接文档邮件留痕、先退小群后退大群、群文件先保存、离职证明必须拿到、社保减员增员衔接、告别一条不抱怨」。离职不是关系的终点；是口碑的结算日——交接单写得好的人，背调电话永远响得温柔。
