# Agent Skills 中文技能库

405 个中文 Agent Skills（SKILL.md 格式），覆盖生活服务、微信生态、数据分析等场景，
适用于 Claude Code、Codex、OpenCode、Cursor 等支持 Agent Skills 的工具。

## 安装

```bash
git clone https://github.com/<你的用户名>/agent-skills.git
cp -r agent-skills/skills/<分类>/<技能名> ~/.claude/skills/
```
