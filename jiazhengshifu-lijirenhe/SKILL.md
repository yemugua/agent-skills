# 家政阿姨离职交接清单

阿姨离职的纠纷九成出在"当时没清点"。按此清单当面逐项打勾，双方签字，尾款结清再送人。

## 交接顺序（关键：先清点、后结钱）
1. 约定离职日提前3天告知雇主；离职当天**先交接、双方签字后**再结清尾款——先给钱后清点=失去谈判筹码。
2. 中介派驻的：让中介到场或全程微信视频留证；私自直聘续约绕开中介的，注意原合同是否有「禁止私下签约」条款（违约金常见为1个月工资）。

## 物品盘点表（可复制）
| 类别 | 清点项 | 状态 | 双方签字 |
|---|---|---|---|
| 钥匙 | 大门__把/房间__把/车库__把 | 齐全/缺失 | |
| 门禁/车位卡 | 卡号 | | |
| 药品 | 老人常用药（药名/数量/服用时间） | | |
| 贵重小物 | 现金位置/首饰/存折（建议雇主预先收走） | | |
| 家电使用 | 燃气总阀/热水器开关习惯/常跳闸回路 | 已说明 | |
| 老人/孩子 | 饮食禁忌/作息/常去地点/联系人卡 | 已交接 | |
| 代收物品 | 快递/包裹未取件清单 | | |

## 药品交接红线
老人处方药**列出药名+剂量+服药时刻表**拍照发家庭群；漏交接漏服一次慢病药（降压/降糖）可能进医院——这一栏比钥匙更重要。

## 结算项目核算
- 工资尾款：按实际出勤日结算，法定节假日加班另计。
- 押金/垫付款：买菜垫付凭小票当次结清；雇主押金按合同条款退还。
- 中介费：已付服务费未消费部分按合同比例退（很多中介条款写"概不退还"，签约前就要看清）。
- 算例：月工资6000元、月休4天（计薪26天≈231元/天），本月工作18天=4154元，垫付菜款320元，应付4474元。

## 雇主收尾三件事
1. **当天换锁密码/重配指纹**——钥匙没交齐按配钥匙成本押尾款100-200元。
2. 改掉阿姨知道的支付密码、外卖地址备注、门禁临时码。
3. 留存交接单+结算转账记录至少1年，发生「财物失窃」指控时是关键证据。

## 红线
- 别当天情绪化"送人"后再发现东西少了——补追几乎不可能，交接单签字是唯一凭据。
- 别克扣工资抵"疑似损失"——无证据扣薪属违法克扣，阿姨可劳动仲裁反诉；疑似失窃走报警，不走私扣。
- 别口头承诺"介绍信/好评"换取无条件放弃结算争议——白纸黑字写在交接单备注栏才有效。

> ⚠️ 提醒：交接单双方签字+拍照存证+当天换密码，三件事做完再结尾款。
