# 行车记录仪与自驾安全

一句话：记录仪的核心价值=「**事故定责的证据+碰瓷的防御**」——但「装了」不等于「有用」（**画质/角度/存储/流量**四个细节决定证据效力）；自驾安全的另一半=出发前的车辆检查与疲劳管理。本技能给选购标准 + 证据效力要点 + 自驾检查清单。

## 一、记录仪选购（证据效力的标准）

- **分辨率：1080p 起步，1440p/4K 优先**（**车牌识别是证据效力的分水岭**——能看清车牌的画质才定得了责）
- 视角：**140-160°**（过广=边缘畸变看不清——「视角越大越好」是误区）
- 帧率 ≥30fps（高速场景 60fps 更稳）
- 夜视：星光级传感器（**夜间事故占比高——夜视画质是加分重头**）
- 存储：卡容量 64-256G+**写保护/事件锁定**（事故瞬间文件不被循环覆盖——「紧急锁定」键是刚需）
- 停车监控：碰撞唤醒拍摄（**停车场刮蹭的取证**——看供电方式：降压线接电=亏电风险；电瓶保护电压设定）
- 双镜头：后录（追尾定责——**「被追尾也有说不清的时候」**）

## 二、证据效力细节（装了≠能用）

- **时间校准**：时钟不准=证据链瑕疵（自动 GPS 校时优先）
- 格式化周期：存储卡每月格式化一次（**卡损=关键时刻没录像的常见原因**——监控循环写入的高损耗件）
- 视频导出：事故后**立即锁定导出原片**（手机 App/拔卡——别指望循环存储里的它还在）
- 隐私边界：车内录音合法性的认知（**公开道路拍摄合规；乘客隐私的度**）
- 提交格式：原文件+原始载体（**剪辑过的视频证据效力存疑**——原片直出）

## 三、自驾出发前检查清单（30 分钟的车况）

- [ ] 胎压（含备胎）+胎面磨损（**花纹深度 <1.6mm 换胎**——雨天性能的底线）
- [ ] 油液：机油/刹车油/冷却液/玻璃水
- [ ] 刹车手感与异响
- [ ] 灯光全检（转向/刹车/雾灯）
- [ ] 雨刮（长途雨区前必换老化条）
- [ ] 电瓶电压（3 年+电瓶长途前的检查）
- [ ] 应急包：三角牌/灭火器/破窗器/拖车绳/充电线（**三角牌 150m 摆放=高速事故的保命细节**）
- [ ] 证件：行驶证/驾驶证/保险单电子版
- [ ] 路线：充电桩/加油站规划（电车主）

## 四、长途驾驶的疲劳管理（人是最危险的部件）

- **连续驾驶 ≤4h 必休 20min+**（法规与生理共识——「再坚持一下」是事故的口头禅）
- 午后 1-3 点/凌晨 2-5 点=困倦高危时段（**避开或加倍警惕**）
- 副驾的陪伴与对话（**单人长驾=风险倍增**——参考出行成本技能的时间变量）
- 困意信号（眼皮沉/漏看指示/车道漂移）=**立即进服务区**（不是开窗听歌能解决的）

## 五、事故现场的流程（万一发生）

1. 停车+**三角牌（高速 150m）+人员撤离护栏外**
2. 拍照：全景/碰撞点/车牌/车道线/刹车痕（**6 张标准照片**）
3. 记录仪视频立即锁定导出
4. 轻微事故：快处快赔（**「人未伤车能动」先拍照挪车**——占道=二次事故源）
5. 有人伤：**先救人打 120+报警，不动伤者**（现场保护）
6. 保险报案时效（48h 内——参考保险技能）

## 六、真实对照

> 案例 A：碰瓷蹭车——记录仪 1440p 车牌清晰直接报警定责；对照「装了但 720p」的：车牌模糊定责拉锯（**画质=证据效力**）。
> 案例 B：连续驾驶 5h 车道漂移剐蹭——记录仪记录的「漂移轨迹」暴露疲劳驾驶；4h 一休的对照案例全程平顺（**疲劳的管理比技术重要**）。
> 自驾安全的公式：**1440p+夜视+事件锁定是选购底线、时间校准与月度格式化保证据、事故后立即导出原片、三角牌 150m+人员撤离、6 张照片标准作业、4h 必休 20min、困意信号立即服务区、出发前 30 分钟车况清单**——记录仪只负责「事后说清楚」；出发检查与疲劳管理负责「不发生」——两件事都做，才是完整的自驾安全。

## 红线
> ⚠️ 提醒：自驾安全的公式——「记录仪 1440p/夜视/紧急锁定三要素、存储卡月度格式化、事故视频立即导出、三角牌 150m 人先撤、拍照六张定责、疲劳 4h 一休困意即停、出发前胎压灯光油液清单、轻微事故快处快赔」。自驾的账有两本：证据账（记录仪）与安全账（检查+休息）——只装记录仪不休息的人，证据只能证明事故是怎么发生的。
