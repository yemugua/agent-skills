儿童改名最容易翻车的地方不是派出所，而是"学籍系统还是旧名"——学籍（全国学籍系统）与户籍是两条线，顺序错了会两头卡住。

## 正确顺序（先户籍后学籍）

1. **改姓名（户籍线）**：监护人带户口本、身份证、孩子出生证明、书面申请到户籍派出所办理；16 岁以上需孩子本人同意。一般 5-15 个工作日，户口簿换发，旧名作为"曾用名"保留。
2. **同步学籍（学校线）**：改完后**立即**找班主任/学籍管理员，学校在全国中小学生学籍信息管理系统提交"关键信息变更"（姓名），附新户口簿页作为证明材料，区县教育局审核。通常 1-4 周完成。
3. **验证闭环**：让孩子学校打印学籍卡/在系统查询确认新名已生效；同时核对身份证办理计划（16 岁前可不急，升学前必须一致）。

## 材料清单（直接照抄）

- 户籍线：户口簿原件、监护人身份证、出生医学证明、改名书面申请（模板见下）、（离异家庭）另一方监护人同意书或法院文书。
- 学籍线：新户口簿（曾用名页）、学校学籍信息变更申请表、有的区要家长手写情况说明。

**改名申请书模板**：
```
申请书
XX 派出所：本人 XXX 系学生 XXX（X 年 X 月生，现读 X 年级）之父/母，
因（重名率高/谐音不雅/随母姓变更等理由），申请将其姓名由 XXX 变更为 XXX，
变更后一切法律责任由监护人承担。申请人：XXX（签字）X 年 X 月 X 日
```

## 常见卡壳环节

| 卡点 | 处理 |
|---|---|
| 学校说"学籍改不了，等系统开放" | 学籍关键信息变更全年可提交（按区县审核节奏），让孩子学籍管理员在系统里发起，别等学期末 |
| 升学/转学窗口期改名 | 错开：先在新校注册稳定再改，或改完再转学——学籍变更和转学申请同时跑容易被驳回 |
| 两边名字不一致导致体检/考籍对不上 | 凭新户口簿（含曾用名）向学校说明，学校出证明过渡 |
| 离异家庭一方阻拦 | 改名需双方监护一致，协商不成由法院判；派出所无权单方受理 |

## 红线

> ⚠️ 提醒：曾用名一定要在户口簿上保留（派出所默认做法但要确认），这是后续各类证明的衔接凭据；改名后疫苗本、护照、银行卡等逐一手动更新，升学报名前 2-3 个月完成全部变更留缓冲；学籍系统姓名未生效前不要提交中考/高考报名信息，不一致会被退回。
