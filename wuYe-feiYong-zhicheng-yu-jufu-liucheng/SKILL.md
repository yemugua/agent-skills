# 物业费核查与拒付减付路径

一句话：物业费的对抗逻辑不是「不付」，是「服务不达标 → 合法抗辩 → 要求减付」——直接拒付会被起诉且必输，留证据走程序才能少付。本技能给服务标准对照 + 合法抗辩情形 + 程序模板。

## 一、先算明白：物业费包含什么、该值多少

**包含**：公共区域保洁、秩序维护、绿化、公共设施维护、客服——**不包含**：入户维修、户内保洁、水电燃气费
**政府指导价 vs 市场价**：多数城市有基准价+浮动（普通住宅 1-3 元/㎡/月常见）；超标需备案/业主大会同意
**核查动作**：要物业公示「收费依据+服务等级标准」（住建部门备案的合同附件）——等级标准就是打分的尺子。

## 二、可合法主张减付/抗辩的情形（留证据）

| 情形 | 抗辩方式 |
|---|---|
| 保洁/安保长期不达标 | 拍照/录像按月存档 → 书面要求整改 → 不改则要求按服务等级降费 |
| 公共收益不透明（电梯广告/停车费） | 要求公示收支——收益归全体业主，可主张抵扣物业费 |
| 未交付房屋 | 交付前的物业费由开发商承担（不是业主） |
| 房屋质量问题致无法入住 | 期间物业费可与开发商/物业协商减免（书面留痕） |
| 服务严重违约（合同依据） | 依《民法典》944 条：物业不得采取停水电催费；业主对服务不达标可主张违约责任 |

**不能作为拒付理由的**：个人没享受服务（「我一年没住」多数法院不支持全额免，可主张空置房折扣——各地 70-100% 政策不同）、对开发商不满（找错对象）。

## 三、程序路径（按步走）

1. **书面反映**：问题清单（照片+时间）交物业并留签收/微信记录，限期整改
2. **业委会路线**：有业委会的推动监督/谈判；无业委会的可联合业主（20% 联名）向街道申请成立
3. **投诉**：12345 + 住建局物业科（服务不达标是行业主管管的）
4. **协商减免**：证据在手后谈「按 X 折缴一年+物业整改承诺」——多数物业愿意折中（收 70% 好过诉讼收不回）
5. **被起诉时**：出庭抗辩服务不达标+提交证据——法院常见判法：按 80-90% 支持（服务确有瑕疵的酌减），**全额赖掉几乎不可能**

## 四、公共收益的暗账（最值钱的核查点）

- 电梯广告、外墙广告、公共车位、快递柜进场费——**归全体业主**
- 要求物业公示：年度收支明细（法定义务）
- 有结余的可主张：抵扣物业费 / 纳入维修资金 / 按户分红（业主大会决定）
- 拒不公示 → 住建投诉 + 起诉要求公开（有胜诉判例支撑）

## 五、避坑红线 ⚠️

- ❌ 直接拒缴 N 年——欠费事实清楚时必输+违约金；正确姿势是「照付但留证据主张减免」
- ❌ 用拒缴抗议开发商问题——对象错了；开发商的账找开发商
- ❌ 口头投诉无记录——所有沟通落文字（微信书面化）
- ❌ 空置房不打招呼——主动申请空置折扣（各地 70-90% 政策），不申请=默认全额

## 红线
> ⚠️ 提醒：物业费的公式——「先要服务等级标准当尺子、证据按月存档、书面整改限期、公共收益必须公示、拒缴必输而减付可赢、空置折扣主动申请」。物业战的正确姿势不是对抗是记账——你存的每一张照片，都是法庭上 10% 减免的依据。
