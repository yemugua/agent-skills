# 宠物医院就诊清单：带什么与问什么

# 宠物医院就诊指南

一句话：就诊效率=「信息完整度」——带上病历与视频、说清症状时间线、问对三个问题（什么病/为什么/有别的方案吗），一次就诊的价值翻倍。本技能给就诊准备清单 + 沟通话术 + 复诊管理。

## 一、就诊前准备清单（信息就是诊断效率）

- [ ] **症状视频**：抽搐/跛行/呼吸异常/呕吐——**当场录给医生看**（口头描述的信息量 <视频 10%）
- [ ] 时间线：何时开始/频率/有无诱因（换粮/外出/误食）——写在手机备忘录
- [ ] 病历档案：既往病历/用药记录/疫苗本（**首诊带全，复诊带上次报告**——避免重复检查）
- [ ] 用药史：最近用过什么药/保健品（药物相互作用+过敏排查）
- [ ] 误食物证：怀疑误食→带包装/残余（兽医按成分判断毒性）
- [ ] 排泄样本：腹泻/尿异常带新鲜样本（2h 内）——**粪检尿检是就诊的黄金配合**
- [ ] 保险信息：有宠物险的带保单（理赔材料当场问清——病历抬头要写全名）

## 二、就诊沟通的话术（把就诊价值最大化）

**说清这五点**：
1. 「症状是＿＿，从＿＿开始，频率＿＿」
2. 「有没有变化：食欲/精神/排泄/体重」
3. 「有没有可能接触过：毒物/异物/其他病宠」
4. 「在家做过什么处理」（喂过药？催吐过？——处理史影响判断）
5. 「我的预算范围与底线」（直说——医生能按预算排方案）

**必问三问**（参考二诊技能）：
- 「这个检查会改变治疗方案吗？」
- 「有没有保守替代方案？各自的优劣？」
- 「这个药用法用量——回家记在备忘录」（当场写下来）

## 三、检查与费用的现场管理

- 检查项目确认：医生开单时**问清每项的目的与价格**（「全套 800 元里每项查什么」）——模糊单=可砍的余地
- 分步策略：急症先做救命项；非急症可「基础项先行+结果决定后续」——**分步检查=费用可控且更精准**
- 报价超预期：可以叫停（「考虑一下」——回家比价/二诊参考）；住院押金问清退费规则
- 处方与用药：问「这个药的替代/人药等效是否可行」（**人药给宠物=红线**——剂量与毒性完全不同，只能医生评估）
- 复诊预约：当场约（复诊提醒写手机日历——宠物病的管理=日历管理）

## 四、住院与手术的管理

- 住院巡视：探视时段亲眼看（笼位/清洁/精神状态）——**住院≠全托不管**（每日视频/到场）
- 术前确认：麻醉方案/术前血检/风险告知书逐条读（签字=知情的记录）
- 术后护理要点当场问清：伤口护理/戴圈时长/饮食过渡/复诊拆线时间——**回家护理决定 50% 的恢复质量**
- 费用清单：出院时逐项对（**费用清单是理赔与纠纷的唯一凭证**）

## 五、复诊与慢病管理

- 病历归档：每次就诊后整理（日期/诊断/用药/费用）——自己的档案是第二诊疗意见的资本
- 慢病日历：用药时间/复查节点（肾病 3 个月一查/心脏病半年心超）
- 用药执行：分药盒+日历提醒（宠物用药漏服=疗程失败常见因）
- 疗效观察记录：症状变化日记（「吃了 3 天呕吐从 5 次/天减到 1 次」——**给复诊医生的信息**）

## 六、急诊的场景判断（参考二诊技能的急诊红线）

- 立即冲急诊：中毒/车祸/持续抽搐/胃扭转征（大型犬腹部胀+干呕）/公猫闭尿/难产/大量出血
- 可观察 12-24h：单次呕吐食欲尚可/轻微跛行——观察记录（次数/精神/食欲）当信息带去
- 夜间急诊费溢价 100-300——非致命情形天亮日诊（**判断「是不是今晚必须去」=就诊管理的第一技能**）

## 七、真实对照

> 案例 A：带呕吐视频+误食包装袋（多效唑类农药瓶）——医生直接按毒物定性洗胃，节省全套筛查 600 元+抢到黄金时间。
> 案例 B：复诊时自己整理的用药日记（3 天记录）——医生据此调整剂量，避免二次复诊（**信息的完整度=诊断的精度**）。
> 就诊的公式：**症状视频+时间线+病历随身、必问三问、检查分步控费、住院每日巡视、术后护理当场问清、费用清单留凭证、慢病用日历管**——宠物医院不是「送去就完事」；是「你作为信息管理者参与诊断」——你的准备度，就是治愈率的一部分。

## 红线
> ⚠️ 提醒：就诊的公式——「症状录视频、时间线写备忘录、复诊带上次报告、必问『改变方案吗』、检查可以分步、人药禁自行给、住院每天看、费用清单必留、观察期记录当信息」。就诊是「医生+你」的双人协作——你带的不是宠物，是一份待编辑的病历。
