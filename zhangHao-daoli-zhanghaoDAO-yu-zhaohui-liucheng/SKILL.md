# 账号被盗找回全流程

一句话：账号被盗的止损顺序 = 「保住关联资产（支付/邮箱）→ 找回主账号 → 排查泄露源」——很多人卡在「先找回账号」，结果支付账户先被掏。本技能给按资产优先级的止损清单。

## 一、发现被盗的信号

- 收到异地登录提醒 / 密码被改 / 踢出登录
- 朋友收到你「借钱」消息（被盗号诈骗）
- 绑定手机收到异常验证码（有人正在尝试——**立即改密的信号**）
- 支付账户出现非本人消费

## 二、止损顺序（资产优先，不是账号优先）

### 0-10 分钟：切断资金
- [ ] 支付宝/微信：改密+冻结（同手机丢失流程；被盗但手机在手：直接改密+解绑免密）
- [ ] 银行 App/快捷支付解绑
- [ ] 检查账单异常消费 → 平台申诉（被盗消费有赔付机制，要「非本人操作」的报案回执）

### 10-20 分钟：守住总闸（邮箱）
- [ ] **邮箱先改密**——所有账号的「找回密码」都发邮箱；邮箱丢了=全部沦陷
- [ ] 邮箱开两步验证

### 20-60 分钟：找回主账号
- 微信：110.qq.com 冻结 → 申诉找回（好友辅助验证）
- QQ/游戏账号：官方客服申诉（历史资料：注册时间/常用登录地/消费记录=申诉依据——**越详实的资料申诉越快**）
- 游戏账号装备被卖：联系客服回档/冻结交易（部分游戏支持）

### 24h 内：排查与加固
- [ ] 登录设备管理：踢掉所有陌生设备
- [ ] 密码全改 + 高危账号开两步验证
- [ ] 泄露源排查：最近在哪注册/扫码/连接了公共 WiFi（have i been pwned 查邮箱泄露记录）

## 三、被盗号诈骗他人（你的号骗了你朋友）

- 第一时间发朋友圈/让家人群通知：「账号被盗，任何人以我名义借钱都是诈骗」
- 被骗朋友的报案回执 → 提供给平台（你的申诉材料+免责说明）
- 配合平台冻结资金流（诈骗款若还在平台内有拦截可能）

## 四、账号买卖的特别风险（买号/卖号都看）

- **买号**：卖家找回是常态（申诉材料在他手里）——平台内交易（担保期后再确认）+ 要求卖家解绑全部信息（手机/邮箱/实名）+ 买号合同（无用但留证）
- **卖号**：账号被用于诈骗/洗钱 → **实名主体（你）被牵连**——卖号前想清楚：实名账号的法律责任跟着实名人走
- 游戏账号交易的平台仲裁靠「找回保险」（交易猫等有找回赔付险）——买贵号必选

## 五、预防设计（一次配置终身受益）

- [ ] 密码分级：资金类（银行/支付）独立强密码 + 两步验证；普通账号密码管理器
- [ ] 邮箱两步验证（总闸加锁）
- [ ] 微信/支付宝登录设备定期清理（季度一次）
- [ ] 不明链接不点（盗号的第一入口）；扫码授权看清范围
- [ ] 手机 SIM PIN 码（见手机丢失条目）

## 六、真实案例

> 场景：微信被盗，骗子向好友借「急用 5,000」，2 人转账。
> 处理：110.qq.com 冻结（15 分钟）→ 朋友圈+家人群预警（第 3 人未转账）→ 客服申诉找回（好友辅助，2 小时）→ 受骗朋友报案，平台拦截到未提现资金退回。
> 关键：冻结早于骗子的提现速度。

## 红线
> ⚠️ 提醒：找回的公式——「资产先于账号（支付→邮箱→主号）、邮箱是总闸先锁、申诉材料越详实越快、被盗号先通知亲友防二次诈骗、买号防找回卖号防牵连、密码分级+两步验证」。账号被盗的止损是和时间赛跑——排序错了（先找回账号再管钱），钱就没了；排序对了，除了手机号换绑的麻烦，几乎无损失。
