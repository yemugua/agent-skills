# 户口迁移全流程清单

一句话：户口迁移的难度不在流程在「材料清单」——不同情形（购房落户/婚迁/人才引进/投靠）材料组合不同，跑错一次窗口排一上午。本技能按情形给清单与办理顺序。

## 一、先确认迁入类型（材料完全不同）

| 类型 | 核心条件 | 难度 |
|---|---|---|
| 购房落户 | 有产权房（多数城市无面积/金额门槛；限购城市看社保年限） | ⭐ |
| 夫妻投靠 | 结婚登记（年限要求各城市 1-5 年不等） | ⭐⭐ |
| 人才引进 | 学历/职称/社保基数达标（本科+社保是多数城市门槛） | ⭐⭐ |
| 工作调动 | 单位有集体户/指标（国企/事业单位常见） | ⭐⭐ |
| 老人投靠子女 | 年龄+子女户籍条件 | ⭐⭐ |
| 未成年子女随迁 | 随父/母一方 | ⭐ |

**查询渠道**：迁入地公安分局户政窗口 / 当地政务服务网 / 「公安一网通办」APP——**先电话/线上确认材料清单再跑腿**（各城市差异极大，本文是通用框架）。

## 二、通用办理顺序（四步）

```
Step1 迁入地办《准予迁入证明》（准迁证）
  → 带齐材料到迁入地派出所户政窗口
Step2 原户籍地办《迁移证》
  → 准迁证 + 户口本 + 身份证 到原籍派出所（部分城市已免此步——电子流转）
Step3 迁入地落户
  → 迁移证 + 准迁证 + 照片 + 材料原件 → 办新户口本
Step4 关联事项更新
  → 身份证换发（地址变了）/ 社保公积金关联 / 驾照地址 / 银行信息 / 学籍档案
```

## 三、购房落户清单（最常见情形）

- [ ] 身份证+户口本原件
- [ ] 房产证/不动产权证（或购房合同+备案+发票——部分城市期房可迁）
- [ ] 结婚证（随迁配偶）/ 出生证明（随迁子女）
- [ ] 社保缴纳记录（限购城市的年限证明）
- [ ] 亲属关系证明（随迁时）
- [ ] 到房产所在地派出所申请准迁证

## 四、人才引进清单（换城市工作的年轻人必看）

- [ ] 学历证书+学信网备案表
- [ ] 劳动合同+社保记录（部分城市要求缴满 6-12 个月）
- [ ] 年龄红线核对（多数城市本科 ≤40 / 硕士 ≤45 / 博士不限）
- [ ] 单位营业执照/在职证明（部分城市需单位配合）
- [ ] 落户地址：自有房 > 单位集体户 > 人才市场集体户（影响孩子上学排位——尽量前两种）

## 五、办理中的高频卡点

| 卡点 | 解法 |
|---|---|
| 材料「差一张纸」跑三次 | 首次办理前打窗口电话逐项确认+线上预审（多数政务网支持） |
| 户口本找不到 | 原籍派出所补办户口本（当天出）或开户籍证明 |
| 集体户管理单位不配合 | 单位集体户迁出：先确定新地址（房产/人才市场）再办 |
| 子女上学时间紧迫 | 问清落户后学籍的「落户时长要求」（部分学区要求满 1-3 年——**买学区房前先查这个**） |
| 夫妻投靠年限 | 各城市 1-5 年婚龄要求——婚前问清（影响买房时间线） |

## 六、落户后的关联更新清单（漏一项麻烦一次）

- [ ] 身份证换发（30 日内）
- [ ] 社保/公积金：跨市迁移的转移接续（掌上 12333 + 公积金小程序）
- [ ] 驾驶证地址变更（车管所/交管 12123）
- [ ] 车辆登记信息（有车的）
- [ ] 银行卡预留地址/手机银行信息
- [ ] 护照/港澳通行证（签注办理地变化）
- [ ] 学籍/人事档案的迁移（毕业生报到证/档案调转）

## 七、真实提醒：落户与权益的联动账

- 落户决定：购房资格（限购城市户籍优先）、子女学区、医保养老待遇地、车牌摇号资格
- **迁户口前算三笔账**：购房资格账 / 学区账 / 摇号账——多数人为了学区迁，少数人为了购房资格迁；为了一时方便迁（挂集体户）最亏

## 红线
> ⚠️ 提醒：迁移的公式——「先定类型再备材料、电话预审防跑三趟、准迁证→迁移证→落户三步走、落户后七项关联更新、集体户能转房产户就转、学区落户年限前置查询」。户口是权益的开关——迁移本身不难；难的是你没在迁之前算清它能开哪些门。
