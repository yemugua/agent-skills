# 装修工期管理

一句话：装修超期的根源=「**工序排队无序+交叉作业混乱+主材到场不齐**」——「100㎡ 常规 3-4 个月」的基准上，工期管理的三工具=「排期表/节点验收/主材倒排」（参考预算总表的钱账，本篇管时间账）。本技能给工序标准工期 + 排期方法 + 延期防控。

## 一、标准工序与工期（100-140㎡ 的基准）

| 工序 | 工期 | 前置条件 |
|---|---|---|
| 拆改+清运 | 3-7 天 | |
| 水电改造 | 7-10 天 | 点位图确认 |
| 防水+闭水 | 5-7 天（含 48h 闭水） | 水电验收 |
| 瓦工（贴砖） | 10-15 天 | 砖到场 |
| 木工 | 5-10 天 | |
| 油漆 | 10-15 天（含干燥） | |
| 安装期（橱柜/门/洁具/灯具） | 7-10 天 | **主材全部到场** |
| 保洁+散味 | 5-10 天 | |
| **合计** | **60-90 天** | **主材准时是关键变量** |

- **工期延长的三主因**：主材迟到（50%+）/返工（10%+，参考验收技能）/施工方接单过多人手不足
- 旧房加成：+10-15 天（拆旧/隐蔽问题——参考旧房技能）

## 二、主材的倒排表（业主方的责任面）

- **「安装期倒排」法**：从安装期起点倒推各主材的下单期（**橱柜：量尺到安装 30-45 天=瓦工后立刻复尺下单**；门：30-45 天；定制柜：45 天+——参考定制技能）
- 倒排表的常见失误：**「瓦工贴完才想起橱柜」**（返工等待的典型）
- 业主的到货验收责任：**到场即验（破损/色号/规格）**——参考瓷砖技能的到货检验
- 「主材晚到=窝工索赔」的合同条款（**工期延误的责任划分双向写**——施工方窝工与业主供料延误的对称条款）

## 三、排期表的工具（管理的形态）

- 简版周计划表（**每周核对：本周完成/下周计划/风险项**——参考预算技能的周更同构）
- 节点验收的时点绑定：**水电后/防水后/瓦工后/竣工四大节点**（付款与进度绑定——参考付款节奏）
- 「并行工序」的管理：瓦木可并行/油漆与安装的部分并行（**并行=省时；乱并=返工**——「瓦木油」的顺序纪律）
- 沟通节律：**与工长固定日沟通**（每天微信=焦虑输出；每周碰头=效率输入）

## 四、延期防控清单（风险的预埋）

- [ ] 主材倒排表+下单提醒（最大变量）
- [ ] 合同工期条款+延误责任（日违约金）
- [ ] 节点验收不拖（**业主自己拖延验收=自我延期**——常见且自伤）
- [ ] 设计变更的截止点（**瓦工后的改设计=返工+顺延**——「装修期改主意」的成本课）
- [ ] 季节因素：雨季油漆干燥延长/冬季低温施工限制（参考涂料技能的施工条件）
- [ ] 施工方的人手确认（**「包工头同时开 3 个工地」=每个都慢**——开工前问清）

## 五、竣工期的事务（收尾的时间账）

- 开荒保洁→散味（参考甲醛技能的通风周期）→家具进场（**「散味期」与「家具提前买」的并行**——软装下单在油漆期启动）
- 入住时间表：**竣工+通风 ≥1-3 个月（甲醛线）+CMA 复测**（**「赶着入住」=健康预算的透支**——参考甲醛技能的红线）
- 尾款与保修凭证的收尾（参考保修技能）

## 六、真实对照

> 案例 A：90 天基准工程拖到 140 天——橱柜 60 天后才下单（倒排缺席）；对照倒排表的：90 天准点（**主材倒排=工期的一半**）。
> 案例 B：瓦工贴完要求改开关位置——砸砖返工+顺延 15 天；「点位图水电期终确认」的纪律案例零返工（**变更截止=返工防线**）。
> 工期管理的公式：**基准 60-90 天+旧房加成、主材倒排表是业主第一责任、周计划+节点验收绑定付款、并行工序守顺序、变更截止在瓦工前、双向延误责任写进合同、竣工散味按甲醛线不按急切、每周与工长固定沟通**——工期是「时间的预算」——钱账有总表，时间账也要有总表；两者的纪律一模一样。

## 红线
> ⚠️ 提醒：工期管理的公式——「工序基准 60-90 天、主材 45 天件（橱柜/门/定制）倒排下单、四大节点验收不拖延、设计变更截止瓦工前、双向延误条款、雨季冬季的工期折扣、竣工后按甲醛线决定入住不按急切」。装修延期的一半责任在业主侧（主材+验收+改主意）——工期管理=「管好自己的时间账，再管施工方的」。
