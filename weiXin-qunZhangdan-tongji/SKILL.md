# 微信群账单统计与分账

一句话：群聚餐/拼单/合租的水电分摊，靠「群收款」功能 3 步完成；复杂分账（不同人不同金额）用收款小账本。本技能覆盖全部场景的操作路径。

## 一、场景与工具对照

| 场景 | 用什么 | 操作难度 |
|---|---|---|
| 人人均摊（聚餐/拼单） | 微信群收款 | ⭐ |
| 不同人不同金额（AA 但有人没吃酒水） | 收款小账本/群收款自定义 | ⭐⭐ |
| 长期反复分摊（合租水电/月度拼车） | 收款小账本（记账） | ⭐⭐ |
| 已有人垫付、多人转账归还 | 各自转账 + 备注 | ⭐ |

## 二、群收款 3 步（人均均摊）

1. 群聊 → 「+」→ 群收款 → 填总额 + 参与人数 → 自动人均
2. 可设置「按人头/按金额」两种模式
3. 发起后群内成员点击付款，发起人可在「收款记录」追踪谁没付

**催付**：收款记录页 → 未付款成员 → 单独提醒（避免群里点名尴尬）

## 三、不同金额的自定义分账

群收款 → 「按人设置金额」→ 逐个填写（如 A 120、B 80、C 免单）→ 发起。

复杂场景（垫付交叉多笔）：
1. 每笔垫付单独记账（备注：谁付的、谁受益）
2. 合计每人应付 − 已付 = 净应收/应付
3. 最少转账次数原则：净付钱者只转给净收钱者（一笔清算，别来回转）

**手工核算模板：**
```
垫付记录：
- 午餐 600（A 付，全员5人）→ 每人 120
- 酒水 400（B 付，A/B/C/D 4人）→ 每人 100
每人应付 = 120+100(按受益)
A: 220 已付 0 → 转 B 或统一转垫付最多者
```

## 四、长期分摊（合租水电）

1. 每月账单出来 → 群收款发当月金额（固定模板，备注「X 月水电」）
2. 收款小账本（微信小程序）建「合租」账本 → 历史自动留痕
3. 年底导出对账（小账本支持明细导出）——避免「我记得我付过了」的扯皮

## 五、避坑红线 ⚠️

- ❌ 群里发转账码让人自己扫——漏付/重付无追踪；用群收款有记录
- ❌ 口头「下次一起算」——三个月后必扯皮；当场结清或当天发群收款
- ❌ 垫付人自掏大头又不好意思说——群收款的意义就是把「要钱」变成「系统通知」
- ❌ 微信转账给个人收大额拼单款无凭证——重要拼单走群收款或群公告留痕
