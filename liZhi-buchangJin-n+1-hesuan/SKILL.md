# 离职补偿金 N+1 核算器｜协商解除的法定标准与谈判底线

# 离职补偿金 N+1 核算器

一句话：N = 每工作满 1 年补 1 个月工资；「+1」只有**医疗期满/不能胜任/客观情况重大变化**三种法定情形才有，协商离职的「N+1」是谈判话术不是法定义务。本技能给你精确公式 + 常见克扣套路 + 谈判底线清单。

## 一、N 的法定算法（精确到分）

### 月工资基数 = 离职前 12 个月**应发工资的平均数**（不是基本工资！）

**应发工资包含：**
- 基本工资 + 岗位津贴 + 绩效奖金 + 提成 + 加班费
- 年终奖按月摊算（前 12 个月实际发放的奖金计入）
- **不含**：报销款、补贴中的实报实销部分

### N 的计算
- 每满 1 年 → 1 个月；满 6 个月不满 1 年 → 按 1 年（1 个月）；不满 6 个月 → 0.5 个月
- 例：工作 3 年 7 个月 → N = 4 个月工资

### 「+1」的法定情形（代通知金）
只有三种解除情形需提前 30 日书面通知，未通知的支付 1 个月：
1. 医疗期满不能从事原工作
2. 不能胜任工作经培训/调岗仍不能胜任
3. 客观情况重大变化（部门撤销/搬迁等）

**公司主动裁员的「N+1」是行业惯例筹码，不是法律强制**——谈判时心里有数。

## 二、计算示例

> 月均应发 18,500 元（含奖金提成），工作 4 年 3 个月，客观情况解除：
> N = 4.5 个月 → 18,500 × 4.5 = **83,250**
> +1（未提前 30 日通知）→ 83,250 + 18,500 = **101,750**

## 三、常见克扣套路与反制

| 套路 | 反制 |
|---|---|
| 「按基本工资算 N」 | 违法。仲裁口径 = 应发平均工资（《劳动合同法》47 条），工资条 + 银行流水为证 |
| 「你在试用期，没有补偿」 | 试用期解除同样可能需补偿（不胜任解除需证明+补偿） |
| 「主动辞职没补偿」 | 对——所以别在空白「辞职申请」上签字！协商解除要写「双方协商一致，由公司提出」 |
| 「补偿里含未休年假折算」 | 年假折算是单独的 300% 工资，不能混入 N |
| 「先签字后给补偿明细」 | 先要明细再签字。口头承诺一律写进协议 |
| 「2N 恐吓」 | 2N（违法解除赔偿）是公司违法解除时劳动者可主张的——谈判从 2N 起谈不亏 |

## 四、谈判底线清单（签协议前逐条核对）

- [ ] 补偿基数 = 前 12 个月应发平均（对照银行流水自己算一遍）
- [ ] N 的月数正确（不足半年按 0.5、满半年按 1）
- [ ] 「+1」是否存在（三种法定情形之一）
- [ ] 未休年假折算单独列明（应休未休天数 × 日工资 × 200%）
- [ ] 当月工资、报销款、奖金发放时间写明
- [ ] 社保公积金缴至离职当月
- [ ] 离职证明写「协商一致解除」（写「个人原因」影响领失业金）
- [ ] **失业金资格**：非本人意愿离职 + 缴满 1 年 → 别写成主动辞职
- [ ] 竞业限制条款：有补偿才有效（月补 ≥30% 工资），没补偿的可拒绝
- [ ] 保密/竞业条款阅读完再签，空白处划线

## 五、维权路径（谈不拢时）

1. 劳动仲裁：免费，时效 1 年，证据 = 劳动合同 + 工资流水 + 考勤 + 聊天记录
2. 微信聊天记录可作证据：导出完整对话（见微信证据条目），不要只截图
3. 仲裁请求可主张：违法解除 2N / 未签合同双倍工资 / 欠薪 + 经济补偿

## 真实价格
仲裁 0 元；律师咨询 200-500 元/次；N+1 与 N 差一个月工资——以月薪 1.5 万计，一次谈判差 1.5 万元。

## 红线
> ⚠️ 提醒：补偿金的公式——「基数=12 个月应发平均、N=年限折算、+1 只有三法定情形、年假 300% 单算、失业金别写主动辞职、空白文件不签字」。HR 的话术每多一个「行业惯例」，你的钱就少一截；自己按流水算一遍，比听十遍都管用。
