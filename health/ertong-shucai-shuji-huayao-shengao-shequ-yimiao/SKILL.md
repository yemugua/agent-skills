家门口的社区卫生服务中心藏着最省钱的一层医疗资源，多数人只去过打疫苗的窗口。

## 一、免费/低价服务清单（国家基本公共卫生服务项目，全国统一框架）

| 项目 | 对象 | 费用 |
|---|---|---|
| 居民健康档案+家庭医生签约 | 全体常住居民 | 免费 |
| 65岁以上老人年度体检 | 65岁+ | 免费（含血常规/血糖/血脂/心电图/B超等） |
| 高血压/糖尿病随访+免费测血压血糖 | 确诊患者 | 免费，每年≥4次随访 |
| 儿童体检与疫苗 | 0-6岁 | 免费程疫苗+体检 |
| 孕产妇产检5次+产后访视 | 辖区孕妇 | 免费 |
| 35岁以上首诊测血压 | 门诊首诊 | 免费 |
| 部分地区免费筛查 | 宫颈癌/乳腺癌（两癌）、肠癌FIT、肺结节LDCT | 免费/低价（限龄限户籍/常住） |

算例：65岁父亲在社区签约后做年度免费体检（同项目三甲自费约500-800元）+ 高血压随访免费用药指导 + 长处方（一次开4-12周慢病药，医院报销比例在社区通常更高，如职工医保社区90% vs 三甲80%）。年吃药3000元计：报销差10% = 省300元，加上体检省600元、少跑三甲挂号费与交通约300元，**一年省约1200元且少排队**。

## 二、家庭医生签约公式与算例

**签约收益 = 药品报销差价 + 长处方减少跑腿 + 优先转诊 + 免费随访**，签约本身免费且不绑定就诊限制。
算例：转诊路径——社区首诊开不出检查 → 家庭医生开「转诊单」至医联体上级医院 → 部分地区免二次挂号费、优先排检查。**直接去三甲 vs 经社区转诊**：后者在同城医联体内常见节省挂号费50元+缩短等待1-3天。

## 三、可复制模板

```
家庭医生签约服务申请（社区服务中心窗口/线上）
姓名：___ 身份证：___ 联系电话：___
常住地址：___（不限户籍，持居住证/居住登记亦可签约）
签约需求：□高血压随访 □糖尿病随访 □老人体检 □儿童保健 □孕产
家庭医生：___（可指定或分配）
```

慢病长处方申请话术：「医生，我在您这签约了，血压/血糖稳定，按长处方政策能不能给我开8周的量？我在外地工作，来回跑不方便。」

## 四、避坑表

| 坑 | 对策 |
|---|---|
| 以为社区只能打疫苗 | 体检/随访/长处方/转诊都在同一家办 |
| 65岁体检不知道要预约 | 每年名额分批，提前1个月问家庭医生 |
| 慢病药在三甲开 | 长处方+更高报销比例，改社区开 |
| 签约后不联系医生 | 签约留医生电话/微信，随访与转诊都靠它激活 |
| 两癌筛查错过年度窗口 | 名额按季度放，3-4月问当年批次 |

## 红线

> ⚠️ 提醒：国家基本公卫服务项目一律免费，遇到「签约收费」「体检收费」先问清是否为自费增项（如骨密度、肿瘤标志物套餐是自费可拒绝）；社区检查异常必须转上级医院复核，不要在社区反复复查拖延；家庭医生签约不改变急诊就近原则，急症直拨120或去急诊。
