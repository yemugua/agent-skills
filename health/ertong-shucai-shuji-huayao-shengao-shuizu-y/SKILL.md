# 观赏鱼选鱼与检疫

一条带病入缸的鱼能毁掉整缸——选鱼看三点、检疫花两周，用下面的判别表和算例算清楚"省检疫"到底亏多少。

## 选鱼现场判别表

| 部位 | 健康 | 病态（拒买） |
|---|---|---|
| 体表 | 鳞片平整有光泽 | 白点、白毛、红肿、掉鳞 |
| 鳍 | 舒展无破损 | 烂鳍、夹鳍收拢 |
| 眼 | 清亮对称 | 突出浑浊（凸眼病） |
| 肛门 | 不红肿 | 红肿拖便（肠炎） |
| 游姿 | 平稳主动 | 侧翻、擦缸、浮头 |
| 呼吸 | 缓慢均匀 | 急促、单鳃 |

** shop判别**：缸里有死鱼、水浑浊发臭、鱼密度过大挤压的店直接放弃——灯科鱼正常价2-5元/条，低于1元的多为淘汰病鱼。

## 检疫流程模板（两周，直接抄）

```
第1-3天：过水——鱼袋泡缸30分钟→每次加缸水1/4，共3次→捞入检疫缸（不带原店水）
第4-14天：隔离观察，水温28℃，每天观察体表/食欲/粪便
第7天：可用0.5%盐水浴10分钟驱虫（非必备）
第15天：无异常→合缸；有白点/烂鳍→继续治疗痊愈后再观察7天
```

检疫缸配置：30cm小缸+水妖精（35元）+加热棒（45元）=**一次性80元**，可反复使用。

## 算例：省检疫 vs 做检疫

带病鱼入缸场景：白点病传染，整缸20条感染→白点净+升温治疗，药40元+部分死亡（灯科鱼死亡10条损失30元）+水质崩坏翻缸重养硝化两周+人工；直接损失**70-150元+整缸折腾一个月**。做检疫成本：80元设备+14天等待，几乎零损失。**临界点：养鱼总投入超过300元的缸，检疫必做**。

常见病速查：白点病（升温30℃+白点净，3-7天）、烂鳍（黄粉药浴+换水）、肠炎（停食3天+升温）、水霉（升温+亚甲基蓝）。用药原则：**先升温换水再下药，下药减半量起步**。

## 与商家对话话术

> "这条鱼在你店里养了多久？最近有没有死鱼？"——当场问，商家含糊或答"今天刚到"的，鱼应激风险高。
> "我可以要求：鱼拿回家7天内无理由死亡包换一条吗？"——部分正规店支持，谈不下来就在便宜店买但必须检疫。

## 红线

> ⚠️ 提醒：原店水永远不倒进自家缸（带菌源头）；不同观赏鱼不能混用药（虾/螺对铜药极敏感）；人鱼共患病少见但接触鱼缸水后要洗手（尤其有伤口时，海缸分支杆菌感染皮肤有实际病例）；治疗期间停食比多喂更重要——鱼饿一周没事，坏水一晚就死整缸。
