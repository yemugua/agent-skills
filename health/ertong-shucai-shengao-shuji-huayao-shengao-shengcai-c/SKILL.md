# 剩菜保存与再加热安全（清单）

一句话点题：剩菜安全三原则——2小时内进冰箱、按类别定时限、回热必须彻底沸腾。

## 工具表：分类保存时限

| 类别 | 冷藏（4℃） | 冷冻（-18℃） | 再加热要求 |
|---|---|---|---|
| 绿叶蔬菜 | 当餐吃完，≤12h | 不建议冷冻 | 不再加热二次 |
| 肉类炖菜 | 2-3天 | 1-2个月 | 沸腾后继续煮5分钟 |
| 鱼虾海鲜 | 1天 | 1个月 | 蒸/煮彻底，勿微波半热 |
| 卤味凉菜 | 1天 | 2周 | 回热或改做热菜 |
| 米饭面食 | 1天 | 1个月 | 蒸透至中心≥74℃ |
| 蛋类（溏心） | 不保存 | 不保存 | 直接丢弃 |

## 精确算例

年夜饭剩6菜（2绿叶菜、1清蒸鱼、2炖肉、1凉拌）：2小时内分装——绿叶菜和凉拌当餐结束直接丢弃（占丢弃量50%）；鱼去骨装盒次日午吃掉；炖肉分2盒，1盒冷藏次日吃、1盒冷冻。结果：总剩菜约1.8kg，安全利用1.0kg（56%），丢弃0.8kg——不逞强吃完就是最大的省钱。

## 可复制清单

```
☐ 开餐前：每菜预留公筷公勺（减少口水菌污染）
☐ 餐后2h内：分类分装，凉透≤1h入冰箱
☐ 生熟分层：生肉放下层垫盘
☐ 再加热：中心温度≥74℃，沸腾后+5min
☐ 丢弃红线：绿叶凉菜隔夜即弃；异味/发黏/汤汁浑浊即弃
```

## 红线

> ⚠️ 提醒：室温存放超过2小时（夏季超过1小时）的剩菜一律丢弃，舍不得这点菜可能换来数天输液；剩菜重复加热不得超过1次；孕妇、婴幼儿、老人避免食用任何隔夜凉菜与绿叶剩菜（李斯特菌与亚硝酸盐高风险）。
