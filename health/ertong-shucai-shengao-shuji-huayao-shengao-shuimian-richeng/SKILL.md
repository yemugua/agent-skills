成年人睡眠不是「睡够8小时」一句口号，而是一套可以当天执行的方案：算清自己的睡眠窗口、改造睡前1小时、用作息表锁节奏、入睡失败有补救规则。

## 一、先算你的睡眠窗口（公式+算例）

**公式：起床时间 − 目标睡眠时长 = 上床时间（再加15-20分钟入睡时间）**

- 成年人推荐睡眠时长：7-9小时（美国睡眠基金会共识）。低于6小时连续3天以上，注意力与免疫力明显下降。
- 算例1：需7:00起床，睡8小时 → 上床 22:40（7:00 − 8h − 20min 入睡时间）。
- 算例2：需6:30起床，想睡9小时 → 上床 21:10；想睡7小时 → 上床 23:10。同一起床时间下，7小时与9小时的上床点相差2小时，先按7小时执行、白天不困再逐周提前15分钟，比一步跳到9小时更易坚持。
- 自检标准（比时长更重要）：白天不开咖啡因也能撑住、不在会议/地铁上秒睡 → 时长基本够；反之先加时长再加质量。

| 起床时间 | 睡7小时上床 | 睡8小时上床 | 睡9小时上床 |
|---|---|---|---|
| 6:00 | 22:40 | 21:40 | 20:40 |
| 6:30 | 23:10 | 22:10 | 21:10 |
| 7:00 | 23:40 | 22:40 | 21:40 |
| 7:30 | 00:10 | 23:10 | 22:10 |

## 二、睡前1小时远离屏幕：执行清单（不是建议，是清单）

蓝光抑制褪黑素分泌，但更关键的是内容唤醒度（短视频/工作消息让大脑兴奋）。执行四步：

1. 睡前60分钟：手机移出卧室或放床头柜2米外，闹钟用实体闹钟。
2. 睡前30分钟：灯光调到≤50%暖光，只做低刺激活动（纸质书、拉伸、洗漱）。
3. 睡前15分钟：写「明日三件事」清单到纸上——把未完成事项从大脑卸载，是对照实验里最有效的助眠动作。
4. 硬性例外规则：确需看屏幕时，开夜间模式+亮度≤30%+只看无剧情内容（文档/相册），每次≤10分钟。

**成本算例**：实体闹钟 15-25元，暖光小夜灯 20-40元，纸质便签本 10元——总投入约50-70元，远低于购买褪黑素软糖（约60-100元/月）且无依赖问题。褪黑素仅适用于跨时区倒时差，健康人长期服用不推荐。

## 三、可复制作息表模板

```
【我的睡眠作息表】（填好后打印贴床头）
固定起床时间（周末也±30分钟内）：____:____
目标上床时间：____:____（按上表公式算）
睡前60分钟：手机放____（位置），换成____活动
睡前30分钟：灯光调暗＋洗漱＋拉伸5分钟
睡前15分钟：写明日三件事：1.___ 2.___ 3.___
床只用于睡觉：不刷手机/不工作/不吃东西
白天：咖啡因14点后不碰（半衰期约5小时）；
     午睡≤20分钟、15点前结束
```

执行节奏：前3天最难（生物钟未动），第4-7天入睡时间自然前移；周末赖床超1小时，相当于每周一自动「倒时差」，直接毁掉整周节奏。

## 四、入睡失败的补救规则（20分钟法则）

- 上床20分钟没睡着 → 离开床，去昏暗处做无聊的事（翻纸质书），困了再回床。在床上翻滚越久，大脑越把「床=清醒焦虑」绑定，越躺越精神。
- 夜间醒来不看手机、不看钟（看钟产生时间焦虑）；超过30分钟醒着才起身。
- 连续3周每周≥3晚入睡超30分钟并影响白天状态 → 就医（睡眠门诊或神经内科），先排查焦虑、甲亢、睡眠呼吸暂停（打鼾+白天嗜睡是信号），不要自行长期服安眠药。

## 红线

> ⚠️ 提醒：①固定起床时间比固定上床时间更重要，周末赖床别超1小时；②不要用酒精助眠——它缩短入睡时间但破坏后半夜睡眠结构，且易形成依赖；③连续3周失眠或伴打鼾憋醒、白天严重嗜睡，必须就医排查睡眠呼吸暂停等疾病，勿自行长期服用褪黑素或安眠药。
