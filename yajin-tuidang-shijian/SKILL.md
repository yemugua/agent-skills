押金纠纷的核心不是「房东扣了」，而是**超过约定/合理时限不退+扣款拿不出凭证**——这两点就是你的法律抓手。

## 退还时限对照表

| 情形 | 时限依据 | 说明 |
|---|---|---|
| 合同有约定退还时间 | 按约定 | 「无正当理由扣押金」照样可主张 |
| 合同无约定 | 退房交接完成时即时结清；参照各地租房条例多为「退房后 3-7 个工作日内」 | 北京住房租赁条例：押金应当在退还之日 3 个工作日内退还（扣除部分需当面出示凭证） |
| 扣款必须出示凭证 | 收据/报价单/维修单 | 拿不出凭证=无依据扣款 |

## 扣押金抗辩清单（逐条对照）

| 房东常见扣款理由 | 你的抗辩 |
|---|---|
| 墙上钉孔/挂画痕迹 | 属**正常使用损耗**（折旧），不是损坏；小孔修补成本几十元且是房东翻新成本 |
| 墙面自然发黄、地板磨损 | 自然折旧，非人为损坏——入住照片+退房照片对比是关键证据 |
| 没打扫干净 | 打扫费 50-100 元内可接受，扣半个月押金不成比例；可主张实际清洁费 |
| 家具坏了 | 质证：坏在入住前？（入住照片）正常使用老化？（折旧）人为损坏才赔 |
| 「需要重新刷墙」 | 全屋重刷属房东翻新支出，不能转嫁租客 |

## 精确算例

月租 3000 元，押金 6000 元（两个月）。房东扣 3500 元：刷墙 2500 + 深度清洁 800 + 门锁 200。
- 抗辩结果：钉孔与发黄属折旧（刷墙 2500 全额驳回）；深度清洁按市场价 100-150 元计；门锁无损坏证据驳回。
- **合理应退：6000-150 ≈ 5850 元**，直接追回被多扣的 3350 元。
- 时间成本：微信函件 1 天 → 12345/住建部门投诉 3-7 天 → 小额诉讼（1 万内，一审终审）立案费约 25-50 元，1-2 个月审结。

## 可复制：催退话术模板

```
您好。本人已于X月X日交房并完成交接（有交接单/照片）。押金6000元至今未退，
已超过合同约定/《住房租赁条例》的X个工作日时限。
1. 请于X日内全额退还至原账户；
2. 如有扣款项目，请逐项提供凭证（维修单/报价单/收据）及对应损坏照片；
3. 逾期未处理，本人将向住建部门投诉并提起小额诉讼，产生的合理费用一并主张。
```

## 维权阶梯

①函件催告（留聊天记录）→ ②12345 政务热线/当地住建委投诉（中介机构最怕这个）→ ③人民调解免费 → ④小额诉讼程序（标的额各省上年度就业人员年平均工资 50% 以下，一审终审）。

## 真实案例

租客退房被扣 2000 元「墙面重刷费」，出具入住与退房对比照（入住时已有旧痕）+ 引用北京住房租赁条例 3 个工作日时限，投诉至住建部门后 5 天内房东全额退还 2000 元。

## 红线

> ⚠️ 提醒：①入住当天拍全屋照片/视频并带时间戳，这是押金纠纷第一证据，退房照同理；②别同意口头「押金抵扣最后一月房租」而不落纸面——条款要写进聊天记录或补充协议；③断水断电、换锁逼你搬走属违法，直接报警+投诉而非对峙；④超过 3 年不主张可能过诉讼时效，纠纷要当年处理。
