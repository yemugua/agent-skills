# 旅行行李清单与证件管理

一句话：旅行事故的一半是「证件没带对/药没备/行李丢」——出发前 24 小时的清单核对，值回整趟旅行。本技能给国内/出境两套清单 + 证件管理 + 行李丢失防御。

## 一、出发前 72 小时检查（按顺序）

### 证件层（最重要）
- [ ] 身份证（国内）——**拍照存云端+手机相册**（补办应急凭据）
- [ ] 儿童同行：户口本/出生证明（部分场景需要）
- [ ] 出境：护照有效期 **>6 个月**（许多国家硬门槛）、签证/ETA 打印+电子版、往返机票行程单（部分入境查验）
- [ ] 驾照（自驾）：国内驾照；出境自驾=**驾照国际翻译认证件（TID）**或当地要求（短期自驾：新西兰/美国部分州可用翻译件；欧洲多国需国际驾照——出发前查清，别信中介包过）

### 预订核对层
- [ ] 机票/火车票/酒店：订单截图+确认邮件——核对**姓名拼音/日期/航站楼**
- [ ] 酒店入住人姓名是否含所有人（双人入住用一人名字登记的另一人带身份证）
- [ ] 保险：旅游意外险（含医疗+延误+行李——日均 10-30 元；高危运动要专项附加）
- [ ] 外币/汇率：小额现钞（抵步交通+小费）+主卡（Visa/MC 出境；提前告知银行出境日期防风控冻结）

### 健康层
- [ ] 常用药 5-7 天量（慢性病必带+处方照片）
- [ ] 旅行药包：退热/止泻（补液盐）/晕车/抗过敏/创可贴
- [ ] 出境特定：目的地疫苗要求（黄热病等——国际旅行卫生中心办黄皮书）；高原行备红景天/乙酰唑胺遵医嘱

## 二、行李清单（三层法）

### 随身（不离身的 3 件套）
- 证件+现金+充电宝（**充电宝必须随身——托运禁止**；≤100Wh）
- 贵重与「丢不起」的都在身上

### 托运（原则：一半衣服都能在那边买到）
- 衣物按「天数+1」法（防延误）；一层压缩袋分天打包
- **液体托运规则**：单瓶 ≤100ml 限制只针对随身——托运随意；随身携带行李液体总量 ≤1L、单瓶 ≤100ml（出境安检）
- 锂电池/打火机禁托运

### 防丢防御（行李丢失的实战动作）
- 行李箱外挂牌（手机号）+箱内**行李清单与联系方式纸条**
- 行李照片（外观+内部）——理赔凭据
- 贵重/药/一晚换洗衣物放随身（行李延误=不裸奔）
- 直飞优先转机（转机是行李丢失的第一原因）
- 丢了：机场行李柜台立即登记（行李牌号在登机牌上）+航司理赔标准（国内 100 元/kg 封顶；国际蒙特利尔公约 ~1,300 USD 上限）——**保价贵重物**

## 三、手机里的数字清单（现代旅行的真正护身符）

- [ ] 离线地图（Google Maps 离线区域/高德城市包）——没有流量的第一小时
- [ ] 行程单/订单全部截图存相册
- [ ] 证件照片（护照/身份证）存加密相册
- [ ] 翻译 App 下载离线语言包
- [ ] 当地紧急号码（出境：当地 110 等价+**中国领事馆领事保护 12308**）
- [ ] 出境 eSIM/电话卡提前装好（落地即可用——机场买卡是溢价重灾区）

## 四、常见翻车场景对照

| 场景 | 根因 | 防御 |
|---|---|---|
| 护照过期被拒值机 | 有效期不足 6 月 | 出发前查——「还在有效期」≠能用 |
| 充电宝被没收 | >100Wh 或托运 | 随身+查容量标注 |
| 现金不够付小费 | 只带了电子支付 | 小额现钞打底 |
| 行李没到裸奔 | 全部托运 | 随身留一晚物资 |
| 酒店订错日期 | 时差日期混淆 | 订单按当地时区核对 |
| 出境被拒：签证材料假行程单 | 中介包过陷阱 | 自己做真实行程单 |

## 五、真实场景

> 案例：泰国行，护照有效期 5 个月+11 天——值机被拒，改签损失 3,000+。出发前 1 分钟的检查能防 3,000 的损失——**「有效期」要按「+6 个月」读**。

## 红线
> ⚠️ 提醒：旅行准备的公式——「证件有效期+6 个月、证件照存云端、充电宝随身不托运、随身三件套（证件/现金/充电宝）、行李照片是理赔凭据、随身留一晚物资、12308 是出境的紧急后盾、离线地图在流量之前」。旅行的意外不是运气；是「没检查的清单」——出发前 72 小时把清单过一遍，90% 的旅行事故在起飞前就已注定。
