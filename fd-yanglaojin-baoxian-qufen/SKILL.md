# 房屋保险与家财险区别

政策性房屋保险、家庭财产险、业主责任险的保障范围对比与投保选择。

## 操作路径
1. **家财险（自费买）**：保自有房屋主体+装修+室内财产的水灾火灾爆炸水管爆裂盗抢；年保费100-500元保额数十万；高空坠物砸坏自家财物也赔。
2. **三者责任附加**：家里水管爆裂淹了楼下、花盆砸了路人——家财险附加第三者责任险（加50-150元/年保额20-50万），高层住户强烈建议。
3. **政策性房屋保险（政府买单）**：多省市已为居民投保（如台风暴雨地区），灾后倒塌/受损有基础赔付，无需自己操作，出险时问街道查保单。
4. **出险流程**：报案（48小时内）→ 拍照+保留受损物 → 保险公司查勘定损 → 提交发票/清单赔付；水管爆裂需提供维修发票。
5. **常见拒赔点**：慢性渗漏（非突发）、自然磨损、未变更用途（住宅改出租仓库出险要告知）、无产权凭证的附属棚屋。

## 避坑红线 ⚠️
- 家财险≠万能：地震多数需附加险；比特币等虚拟资产不赔；租客自购家财险只保自有财物。
- 出租房东应买「房东责任险」（租客在房内受伤的赔偿责任），租金含金量高的城市100-300元/年。
- 别重复投保超额——赔偿以实际损失为限，多买不多赔。

## 维权阶梯
理赔争议 → 保险公司总部投诉 → 银保监12378 → 金融纠纷调解 → 诉讼。

## 法律效力
保险条款免责事项须明确提示（未提示的免责条款无效）；《保险法》第17条是拒赔争议最常用的抗辩依据。

## 真实价格
家财险100-500元/年；三者附加50-150元/年；房东责任险100-300元/年；常见保额：房屋主体50-200万、室内财产5-20万、三者20-50万。

## 红线
> ⚠️ 提醒：家财险最值的场景是老房+高层——水管爆裂淹楼下和高空坠物两大风险一次覆盖，年保费一顿饭钱。
