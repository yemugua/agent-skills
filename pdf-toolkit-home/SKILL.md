# PDF 家庭工具箱：压缩/转图/扫描件整理一次搞定

一句话：家里交材料90%卡在「文件太大传不上去/照片要转PDF/一堆扫描件乱成一团」——这篇给免费工具路径+参数表+压缩算例。

## 一、工具选择表（全部免费无水印）

| 需求 | 首选 | 关键参数 |
|---|---|---|
| PDF压缩到<2MB | ilovepdf.com/compress_pdf | 文字报告选「强压缩」；压缩后逐页核对 |
| 图片转PDF | 手机自带：相册→更多→打印→保存为PDF | 按拍摄顺序排页；统一竖版对齐A4 |
| PDF合并/拆分 | ilovepdf merge / split | 拆分按材料类别分文件 |
| 扫描件变可复制文字 | 微信「提取文字」/白描App | 表格OCR后必须人工核对数字 |
| PDF转图片 | WPS手机版（免费） | 200dpi够网申用，勿超300dpi |

## 二、系统限制参数（算钱级）

- 社保/公积金/银行/学校网申：普遍**单文件≤2MB**，部分≤1MB——A4照片300dpi约3-5MB必压缩。
- 压缩算例：5.2MB体检报告PDF → ilovepdf强压缩 → 约1.2-1.8MB（一次成功）。若仍超：拆成「首页+异常页」两份分别压，或重新打印导出。
- 压缩后三查：第1页能打开、身份证号清晰可读、总页数不变。**压缩丢页是最高频事故**。

## 三、常见翻车对照表

| 翻车做法 | 后果 | 正确做法 |
|---|---|---|
| 网申截止日才第一次上传 | 超限失败无时间补救 | 提前一天压好试传 |
| 用截图代替PDF页 | 受理方退回「非原件格式」 | 照片→PDF，不是截图 |
| 全部材料合一个PDF | 要求分项材料被退回 | 按类别分文件，命名「姓名_材料名.pdf」 |
| 横竖混排 | 打印裁切缺内容 | 统一竖版A4比例 |

## 四、真实场景

家长报小学：户口本+出生证+疫苗本9张照片被要求「合成一个PDF」——系统打印成PDF合并（约6MB）→强压缩→1.4MB一次通过。

## 红线
> ⚠️ 提醒：含身份证、银行卡、房产证的材料禁止上传来历不明的在线转换网站（部分站点留存文件）——证件类一律走离线方式（WPS手机版/系统打印转PDF）；压缩后必须逐页打开核对。
