# 防盗门选购等级与锁芯账

一句话点题：防盗门看两件事——门的等级（甲乙丙丁）和锁芯的等级（A/B/C），**大多数家庭不用换门，换一个 C 级锁芯就够了**，这笔账能省几千块。

## 一、门等级对照表（GB 17565-2007）

| 等级 | 钢板厚度（门框/门扇） | 防破坏时间 | 参考价（含安装） |
|---|---|---|---|
| 甲级 | ≥2.0mm / ≥1.0mm | ≥30 分钟 | 3,000-8,000 元 |
| 乙级 | ≥2.0mm / ≥1.0mm（略低配置） | ≥15 分钟 | 2,000-4,000 元 |
| 丙级 | ≥1.8mm / ≥0.8mm | ≥10 分钟 | 1,500-2,500 元 |
| 丁级 | ≥1.5mm / ≥0.6mm | ≥6 分钟 | 800-1,500 元 |

- 门内侧有钢印等级标识，验货时要求看**门扇侧面的永久等级钢印**，没有钢印的按丁级砍价；
- 甲乙级还要求锁具防撬、门框有加强筋；日常家庭乙级完全够用，临街低层可上甲级。

## 二、锁芯等级与更换账

| 锁芯级别 | 防技术开启 | 特征 | 参考价 |
|---|---|---|---|
| A 级 | ≥1 分钟 | 一字钥匙、十字钥匙 | 老门原配常见 |
| B 级 | ≥5 分钟 | 弯月/双排弹子钥匙 | 100-200 元 |
| C 级（超 B） | ≥240 分钟 | 双排弹子+叶片、蛇形曲线钥匙 | 150-400 元 |

**成本账**：开发商原配门多为丙/丁级 + A 级锁芯。整门换乙级门约 2,000-5,000 元；只换 C 级锁芯 150-400 元（含上门安装），防盗性能提升最大头就在锁芯。**结论：锁芯是最便宜的大升级**——A 级锁芯对小偷约等于门没锁。

## 三、换锁芯 vs 换门决策

- 门体钢印为丙/丁级但门框牢固、无异响 → **换 C 级锁芯**（400 元内解决）；
- 门体变形、关不严、门框与墙体松动 → 换门（乙级起步，2,500 元左右预算）；
- 钥匙丢失或刚接过二手房 → 必须换锁芯（150-400 元），不必换门；
- 低层临街、已有撬痕小区 → 换乙级门 + C 级锁芯 + 加装门磁报警（几十元）。

## 四、猫眼防护与门中门

- 传统猫眼是**反拆开锁的突破口**：用工具从猫眼伸入可拨室内把手；换**金属后盖/旋转挡板猫眼防护盖**（20-50 元）即可堵死；
- "门中门"（夏季通风的内外双层门）防护性弱于整门，选门中门要确认内门也有锁点；
- 门缝塞纸测试：关门后门缝能抽出纸币说明密封条老化，密封条整圈更换约 30-80 元，隔音防尘立竿见影。

## 五、验货与安装验收清单

1. 门扇侧面有等级钢印，与购买等级一致；
2. 打开猫眼/通风孔看**填充物**：应是发泡水泥或防火岩棉，蜂窝纸填充的是假防盗门；
3. 铰链（合页）为明铰链带防盗轴或暗铰链，用手撼门扇无异响；
4. 锁体为 C 级锁芯 + 多向锁点（关门时上下侧同时出销）；
5. 密封条完整一圈无断点；门铃/猫眼无松动；
6. 安装后灌浆饱满：敲门框听声，空鼓说明水泥灌浆偷工，要求补灌。

## 六、可复制话术

**验货话术**：
"请先把门扇侧面钢印拍给我看，再打开通风孔让我确认填充物是岩棉或发泡水泥。蜂窝纸填充我当场退货，运费安装费全由你方承担。"

**换锁芯比价话术**：
"我只要 C 级锁芯，请报锁芯品牌型号、是否含上门安装费和开孔费。别推整门更换，我今天预算只有 400 元。"

## 红线

> ⚠️ **换锁芯别找贴小广告的"开锁换锁"游击队**：无备案的开锁人员可能留存你家钥匙信息；正规做法是找公安备案的开锁公司（可要求出示备案标识）或品牌授权服务商，换完当场要求销毁旧锁芯。
- 不买"超 B 级/C 级"字样却拿不出检测报告的杂牌锁芯，C 级应有 GA/T 73 检测依据；
- 智能锁再好，机械锁芯仍是兜底——选智能锁也要确认其应急机械锁芯为 C 级；
- 不擅自把防火门换成普通防盗门：入户门兼具防火功能的（尤其高层），擅自换成无防火认证的门违反消防要求，验收和出险理赔都会出问题。
