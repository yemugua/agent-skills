回家过年是一年中最大一笔单笔家庭支出，本文给三张表：抢票时间轴、年货分级预算（按1500/3000/6000元三档）、红包预算公式，最后合成一张「回家总成本单」。

## 一、车票：放票时段与抢票节奏

**放票规则**：12306起售点按车站分时段放票，一般为早8:00-18:00间每整点/半点放新票（如北京西部分车次10:00起售、上海虹桥14:00起售）。查自己车次的起售时间：12306 App→我的→起售提醒。

**春运抢票时间轴（以除夕2/16、预售期15天为例）**：
| 时间 | 动作 |
|---|---|
| 开售前1天 | 加候补订单+开启起售提醒 |
| 起售瞬间 | 首轮抢票（放票最多的一轮） |
| 开售后1-2天 | 第一波退票高峰（行程未定者退票） |
| 开车前15天 | 免退票费节点前，二次退票高峰 |
| 开车前1-3天 | 最后一波捡漏（候补兑现率最高时段） |

**候补成功率数据口径**：12306官方称春运候补兑现率超70%，但热门线路（京广/沪昆方向除夕前2天）实际成功率显著更低。策略：候补要多方案叠加——同一订单可加多个车次+日期；再备一条中转方案（如北京→郑州→武汉），中转票常在直达售罄后仍有余票。**不要买第三方加速包**：它们与12306候补走同一队列，加价不增加队列优先级，属营销话术。

**算例**：北京→武汉，高铁二等座约520元/人。一家三口：直达候补（3人同单）+ 备选中转方案。若直达候补失败转飞机：春运票价上浮，提前3周订约900-1300元/人 vs 临近一周订1800-2400元/人——**机票越早订省下的钱远大于车票差价**，候补失败当天就应锁机票。

## 二、年货分级预算（三档对照）

| 项目 | 基础档1500元 | 标准档3000元 | 体面档6000元 |
|---|---|---|---|
| 给父母现金红包 | 600 | 1200 | 2000 |
| 父母衣物/保健（冬衣/按摩仪） | 300 | 800 | 1500 |
| 走亲戚礼盒（4-6家×150-300） | 450 | 900 | 1800 |
| 给孙辈/侄辈压岁钱（4个×200） | — | 800 | 800 |
| 酒水烟茶（自用+待客） | 150 | 300 | 900 |
| 车票/机票往返 | 计入交通另算 | 同左 | 同左 |

**采购算例（标准档）**：礼盒避开「山珍海味套装」——同样预算，2盒坚果（120×2）+2盒水果（90×2）+2盒牛奶（65×2）+2盒点心（80×2）=710元，比同价的1盒「豪华干货礼盒」(700元)在长辈眼里更实用（干货礼盒常见临期问题，看生产日期：距生产超6个月的坚果礼盒直接放回）。

**年货采购顺序**：耐储的酒水坚果提前2-3周电商下单（大促满减+不占春运运力）；水果走亲礼提前1-2天本地超市/水果店买（新鲜且免快递堆积）。

## 三、红包预算公式

```
拜年红包总预算 = 自家父母X2 + 走亲户数N×单户基准 + 压岁钱人数M×单份
单户基准 = 当地行情（多数地区200-400元；直系叔伯姑姨500-1000元）
压岁钱单份 = 当地行情（普遍200元起，直系侄孙600-1000元）
```

**算例**：走亲5户×300 + 压岁钱6个×200 + 自家父母1200 = 1500+1200+1200 = **3900元**。若预计收入波动，把走亲户基准降到200元、压岁钱维持200（压岁钱降档比走亲礼降档更伤面子），总预算压到3300元。

**记账话术**：收到的压岁钱记「人情收入」，发出的记「人情支出」，两年一比就知道明年该回多少——微信红包记录在「我→服务→钱包→账单」按年筛选可导。

## 四、回家总成本单（直接抄）

| 项目 | 金额 |
|---|---|
| 交通往返（3人） | 3120（高铁） |
| 年货+红包（标准档） | 3000 |
| 在家待客食材 | 600 |
| 给自己的弹性（临时打车/加菜/应付临时人情） | 500 |
| **总计** | **7220元** |

预留「弹性500」是关键：春节最大超支来源不是计划内项目，是临时冒出来的人情（临时来的亲戚、临时组织的聚会）。

## 五、避坑清单

| 坑 | 损失 | 避法 |
|---|---|---|
| 第三方加速包 | 多付10-100元且无效 | 只用12306官方候补 |
| 临近春节才订机票 | 多付近1倍 | 候补失败当天锁票 |
| 礼盒只看包装不看生产日期 | 送出临期品失礼 | 坚果类查生产日期<6个月 |
| 红包金额临时拍脑袋 | 超支20%+ | 按公式先列名单定档 |
| 年夜饭当天抢菜 | 贵且缺货 | 耐储提前2-3周、鲜货提前1-2天 |

> ⚠️ 提醒：12306起售时段与候补规则以官方App实时展示为准，本文时段为春运通用节奏，各站起售时间有差异——出发前以12306「起售提醒」功能查证自己车次的确切时间。红包金额是家庭内部决策参考，量力而行，不要为面子借债营造体面；年货食品送出前务必检查保质期，送出临期/过期食品引发的健康问题送礼人同样难辞其咎。
